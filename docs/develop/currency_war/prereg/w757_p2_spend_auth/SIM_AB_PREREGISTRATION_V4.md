**归因规则(三分支,V3 结构沿用、M0b 语义替换)**:

1. **M0a 不达** = 覆盖修复失败 → 回本设计层查触发判据;
2. **M0a 达 ∧ M0b 不达** = **sink 解锁失败**(D/XP 出口仍未产生窗级消耗:刷新预算残余限制/XP 门过紧/L1×L2 耦合未生效)→ 回本设计调 sink 供给,**不诿上游**;
3. **M0a ∧ M0b 双达 ∧ M1-M3 不达** = 「触达、出手、水位压住,但死亡率不降」→ 归因**上游病灶**(P1 出口形态/血线;或「止血消耗的战力转化率不足」→ P25 证伪方向的实锤输入),兑换目标=上游病灶设计件/命题回炉。

**出手侧 Goodhart 防围(沿 V3)**:「为压水位而乱花」由 纯散件恒不授权 + G1-B 账红线 + M3 形态判据 + P12 EV 门(D)四重合围。
