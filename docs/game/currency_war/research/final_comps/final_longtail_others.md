## 昼神阿雅(V3.7 最强轮椅 → V4.4 降 B;hard)

- 阿格莱雅(1费)速度流 carry;**需反重力皮靴×2 + 速度投资**,试用难玩(V3.8→V4.4 降级主因)。[先验:攻略]
- 3星率 0.88(全场最高档);实战板多为 昼神4 + 量子3/能量 + 治疗混搭(弹性宽)。[社区:plaza]
- 强帖依赖本体/遗器/充能绳(试用面板不足)→ 无完整 box 慎选;**除阿格莱雅/昔涟/银狼外不必追任何三星**(2星收手,10级补罗刹保衣匠)。[社区:plaza 帖文]
- **艾丝妲大招 = 高贵乘区 + 拉条增益**(后期一个大招为阿雅提速 ~2000);角色优先级:阿雅 > 艾丝妲 > 藿藿 > 星期日 > 记忆主 > 罗刹。[社区:plaza 帖文]
- 本体配置:充能绳必带;1命免疫 debuff 顶轴开大;六命连鞋都不急(仅风扇可连胜一层)。[社区:plaza 帖文]
- 装备 key:**反重力皮靴×2 断层第一**(「有鞋跟本输不了」,16 篇)+ 白昼·光速螺旋桨 + 火力风暴潮。[社区:plaza+先验]
- counter:电视机 boss → 避。[先验:攻略]
- **攻略原文细节(2026-08-24 从 git 历史补记;sources/V3.7_阵容_阿雅昼神 存档已删[eb9c72a1],此为仅存记录;信源=过期攻略存档,版本 V3.7→V4.4 评级演化,已被 V4.4 实测部分推翻)**:
  - **机制根因**:CW 的「速度增幅」词条与原面板速度**独立乘算**(大世界/深渊为加算、被超高速稀释)——15% 速度增幅对 100 速角色 +15、对 400 速阿雅 +60 → 全游最快角色吃速度收益最肥。
  - **三乘区闭环**:反重力皮靴(羊刀)每回合开始速度增幅额外 +15%、无限叠加(一回合轻松叠 10 层 ≈ +600 速);速度征服乘算后高达 1000 速**直接进面板**(攻击力基于速度);光速螺旋桨(白昼专属,**激活 3 昼神免费赠**,前期多 1 件装备)按每 ❓速 +2% 前台强度 → 1000 速 = +200% 前台强度。
  - **藿藿 = 滚雪球核心**(3 能量):我方放终结技给藿藿充能 → 满能给全队百分比充能 → 人口越多循环越快,「左脚踩右脚」。
  - 成型阵容:阿雅(双鞋+光速螺旋桨+昼神风扇)+ 缇宝 + 昔涟(永动机顶轴)+ 杨叔 + 主角 + 藿藿 + 刃/花火/符玄。节奏:本体 2 星过渡上 9;试用需找 3 星;迅速上 9 找杨叔+昔涟。
  - 边界:**开局 1-3 起码一双鞋,否则不能玩**;「超光速提拔」投资策略适配(不 D 一键 4 星;场上只能阿雅一张 1 费);V3.8 光盾流 exploit(拉条/推条 bug + 光能盾牌)UP 自言必热修,视为已修,仅「光能盾牌免疫推条」为真实装备机制。

- **景元费用阶梯机制**:映月给出 1费特殊景元;**必须先 3星景元,再追镜流 3星** —— 镜流 3星后景元变 5费,刷取难度大增;「一定在景元 3费时升 3星」。[社区:plaza 帖文]
- 镜流前期放备战席(用 3仙舟+2DOT 过渡),1-7 遭遇前升 6 开 3仙舟3群攻,2-7 遭遇前升 7 大 D 双三星。[社区:plaza 帖文]
- 节奏:7 级搜牌(景元+镜流同 roll)→ 9 级补符玄/彦卿;3星率 0.69。[社区:plaza]
- 停云专家顾问可替换爻光;有星徽转补仙舟或群攻羁绊。[社区:plaza 帖文]

- 入场信号:「飞光·映月/传剑」在手 = 近乎硬绑。[社区:plaza]

## 龙丹战技点(medium / A)

- 4 战技点 + 4 列车同行(周日开);丹恒·饮月(2费)吃点主 C,苍龙濯世破百亿。[先验:攻略]
- 远坂凛(V4.4 新)宝石叠 99 层 → 第二魔法实验拐 198% 爆伤(叠加默认 70% = 268%)。[先验:攻略]
- 杨叔(瓦尔特)+ 记忆主必备;4 列车给 160% 前台强度;刃+符玄补位。[先验:攻略]
- 5 级找花火/凛(2费)→ **6 级停 roll 饮月追 2星** → 7 级继续 → 9 级找瓦尔特/符玄。[先验:攻略]
- **姬子复制变体**:姬子·启行领航员选饮月,复制其首位装备 → **饮月放一号位、电锯放首位**;姬子回合放助战技给饮月供点。[社区:plaza 帖文]
- 经济口径:**利息可以少吃,连胜最好不要断**;蓄能帆越早越好;有多余金升 9/10 补云璃。[社区:plaza 帖文]
- 装备 key:饮月**双高周波电锯** + 动能激发剑 + 火力风暴潮 + 斩首行动。[先验:攻略]
- 过渡:花火/风堇/姬子·启行 过渡;也是火花星间旅人的前期护航体系。[先验:攻略]
