# 远坂凛（量子·智识·5星）

> 按 V4.7 期撰写。宝石能量弹射流：战技点驱动，与Archer专属连携。Fate 联动。

## 一、命途属性与技能说明

**命途**：智识；**属性**：量子

| 技能 | 说明 |
|---|---|
| 普攻 | 单体90%攻击量子伤 |
| 战技「第二魔法实验」 | ≥15宝石能量或≥7战技点时强化：AoE 45% + 弹射循环（每轮耗3能量45%随机单体，最多33轮）——把战技点转成弹射轮数；施放时战技点>2 则消耗至2点、每点换2能量 |
| 终结技 | 消耗能量；单体300%/其他100% + **回1战技点** + 敌方全体受伤+10%（3回合） |
| 天赋【宝石能量】 | 进战20点；**我方每消耗/恢复1战技点→+1能量**；且该目标暴伤+35%（2回合）——SP 流动即全队增益 |
| 【自在远坂流】 | Archer 战技后满足条件（SP≤3 或5次伪螺旋剑）→ 双人连携（各150%）+**回4战技点**（每回合1次） |
| 秘技 | —（以官方文本为准） |
| 额外能力 | C1：进战/强化战技后速度+20%（3回合） |

**资源与循环**：标准能量→充能有效；宝石能量由 SP 流动驱动。

## 二、推荐遗器与原因

**套装**：繁星璀璨的天才4件 + 出云显世与高天神国2件【攻：量子口径】
**主词条**：躯干暴击率/暴伤；脚部速度；球量子伤；绳充能。**副词条**：双暴>攻击>速度。
