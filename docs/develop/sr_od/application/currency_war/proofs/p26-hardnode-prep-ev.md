## 命题

位面 1 硬节点(遭遇/boss,`_hard_node` 口径)备战帧,一笔备战支出 C(围栏内体系件买/carry 装备/放弃利息的支出 D)的期望净值:

```
EV(C) = Δp_prep · G_loss + Δstreak·S_streak − C − I(利息损失)
```

触发判据形式:EV(C)>0 ⇔ Δp_prep > (C+I−Δstreak·S_streak)/G_loss,与 P23 停手窗门式同构(P23.1)。

### 量纲闭合声明(纯金流公理,P51)

**血量不入任何账与自变量**。L_node(条件败面伤害,血量单位)不直接进金账——本式无任何血→金换算因子,hp_to_gold×L 旧形态(P12 判死)违 P15v2/P51 纯金流公理,禁用。金账承载方式:

- **G_loss = λ_death 通道的销毁风险敞口**(风险敞口=可能随死亡整笔销毁的金额;P51 §F.3 底线口径,P48 统一囤钱判据同源形态):败面概率变化 Δp_prep 承载的是「败局 → 局终销毁」事件下的存量金 + 未来基础/利息流风险敞口,即 G_loss = λ_death(板面战力桶×节点类型,剩余轮数近似视界)×(存量金 g + 未来流)。λ_death 生成式待标定(P51 采集 #3 已登记待办)。
- **L_node 的合法位置 = 触发面**〔原 hp 水线形态(水位比较 hp−L_node<emergency_hp,族)已随 hp 判据族删除失去判据合法性——hp 是对局结果不是策略决策输入(2026-10-28 用户裁定,策略正本 00_framework §3);P26 触发面重立须以 λ_death 概率侧/节点类型前置承载,本行按命题成文时点读〕,只判「备战帧是否被该硬节点威胁」,不作数值授权;消费形态=**区间风险敞口比较,禁止边际引用**(P51 消费纪律)。

## 门值带(按真实 L_node 量级的三典型场景)

门值 =(C+I−Δstreak·S_streak)/G_loss;Δstreak 项未标定前取 0 作保守下界,C 组合口径 = P20 成本层 1-2 金/件 × 围栏 2 件 = **2-4 金带**,利息损失 I 并入同一带(取 C+I ∈ [2,4] 金,与 P26_VALIDATION 复算带一致):

| 典型场景 | 敞口/G_loss 量级锚 | 门值带 (C+I)/G_loss |
|---|---|---|
| ① P15v2 encounter 实测带(12.5 级) | G_loss 取 L 量级下界锚 | (2-4)/12.5 ≈ **16-32%** |
| ② 注册表 encounter 均值(rung0=24.32) | 24.32 级 | (2-4)/24.32 ≈ **8-16%** |
| ③ 注册表/P15v2 boss(26.7-27.2) | 27 级 | (2-4)/27 ≈ **7-15%** |

汇总:**门值带 ≈ 7-32%**(分位口径标定后收窄);P26_VALIDATION 同带复算对账。注意 G_loss 真值是 λ_death 风险敞口而非上表 L 量级本身——上表用 L 量级作占位带,L 与销毁风险敞口的换算随 λ_death 标定回填。
