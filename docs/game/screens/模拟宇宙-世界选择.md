# 模拟宇宙-世界选择(sim_uni_entry_world)

经典模拟宇宙的**世界列表页**:进入模拟宇宙后看到的首屏,纵向排列各世界星球(第一~第九世界),滚动浏览、点击选中。左侧为黑塔的商店/技能树菜单,左下角有不可知域入口横幅与「前往模拟宇宙:扩展装置」跳转。本画面与[世界详情页](模拟宇宙-世界详情.md)构成两级结构:列表页选世界,详情页选难度并开始。

## 何时出现 + 状态流转

- **入口(实测 2026-09-26)**:[星际和平指南](星际和平指南.md) → 旷宇纷争 TAB → 差分宇宙分类 → 点「**前往模拟宇宙**」横幅标签(卡片左上角,注意**不是**右下角「前往参与」按钮——后者跳[差分宇宙](差分宇宙.md)大厅)。同一天内两次走同一指南路径落点可能不同(与游戏内上次停留的玩法有关),以「前往模拟宇宙」横幅为准可达本画面。
- **出口(实测)**:点击居中星球 → 进入[世界详情页](模拟宇宙-世界详情.md)。右上 X 关闭 → 回大世界。
- 未验证出口:黑塔的商店 / 技能树 / 图鉴 / 不可知域 / 扩展装置 / 规则说明(均为子页面跳转,待后续建档时补充)。

## automation 要读信息

- **当前世界名**:居中星球旁的「第X世界」标签(area 当前世界名,OCR 单行),bot 据此判断当前选中的世界。
- **进行中标记**:居中世界名上方的「进行中」文字(area 进行中标记)——存在=该世界有未完成进度,详情页将显示「继续进度」;不存在=无进度,详情页显示「下载初始角色」。
