## 结论

**打回（阻断）**。4 阻断 / 4 中 / 1 中低 / 1 低：

- **D6-1 修复的「层归属全域组得分」只定义了层的归属、没定义层的数值**——组得分是否携带 10⁹/10⁶/10² 域缩放、骨架成员垫底计数（基线）的绝对/增量口径全部零文；「未归一化（序等价）」只在组内比较成立，背包 DP 是跨组求和模型，字面实现 = L2 组分（满档 4）与 L3 组分（buff 计数 ≤ 45）同量级互淹、成档核心组（f≤1）被两个万金油（8 分）压过——层序隔离在搜索内整体失效（D7-1）；
- **六轮两个处置在同一段文本内互斥**——D6-4 的近似损失上界「跨组第二贡献 ≤ L3 域 10²、跨层差 ≥ 10³ 不改板面选择」仍按五轮「DP 只含 L3」旧模型推导，被同轮 D6-1 的 L1/L2 域扩展直接击穿：瓦尔特（列车同行+减益，cw_chars.py:190 实存）在锁定姬子线时归核心键组，其减益标签（sub_tiers L2 域）的 10⁶ 级贡献在 DP 零承载——损失上界失实两个数量级以上，可构造 DP 漏最优板的具体反例（D7-2）；
- **相位判定载体「最终板面实测 L1」两读皆败**——按 DP 状态动态判 = 组得分依赖他组选择、背包可分离性破坏；按骨架固定判 = DP-评分偏差未申报（骨架 ×4 + 补人凑档后板面 ×1，过渡件被高估 4 倍挤掉 buff 件）（D7-3）；
- **D6-2 与 D6-3 两处置的载体互打**——级联态被归入「op 内循环（一次识别连续多动作零读屏）」与总纲「逐帧每帧一动作」仍互斥可读，而 D6-3 的「已就位集连续 2 帧不增」判定恰恰需要逐帧实测板面——零读屏循环里「帧」不存在，拖拽未生效时自上报推演会让 diff 收敛清槽（级联误判完成）后真实板面纹丝不动（D7-4）。

按「实现者无需再设计」门槛不可派工。

## 发现清单

### D7-1｜段 2 DP 组得分的数值域映射未定义：层的「归属」有文、层的「数值」零文——背包求和下 L1/L2 域声明整体不进模型，字面实现层序崩坏
- 攻击点：详设 :81「组得分 = 层归属全域（D6-1/D6-7 修复——键在哪层计分组得分就跟到哪层）：核心键组 → L1 域 f 分；sub_tiers 组（锁定窗）→ L2 域 Σw×档位完成度（**未归一化——键集固定 Σw 为常数，序等价**）；其余 → L3 单位序」。三个缺口：① **域缩放缺失**——分值表（:38-44）声明 L1 满分 10⁹ / L2 满分 10⁶ / L3 ≤ ~10²，但组得分公式只写了层内计算形（f、Σw×完成度、计数），没写是否携带域缩放常量。「未归一化」括号注释表明作者在想「平均 vs 求和」，而非「×10⁶」——字面最自然实现 = Σw×完成度 ≤ 4（姬子线 Σw=4）、f ≤ 1、L3 计数 ≤ ~70：背包 DP 是**跨组求和**模型，L2 组分（≤4）与 L3 组分（buff 键 ×3 计数 ≤ 45、万金油 ≤ 8）同量级互淹——sub_tiers 凑档板（评分域 10⁶ 碾压万金油）在 DP 里 4 分 vs 万金油 2 件 4 分平级、4 分 < buff 3 键 9 分——**L2 的 10⁶ 域声明在搜索内失效**；成档核心组 f = 0.25-0.375（无缩放）< 万金油 2 件 8 分——**L1 的 10⁹ 域声明同样失效**。「序等价」论证只在「同组内比较」成立（键集固定），跨组求和需要的量纲统一规则零文。② **骨架基线缺失**——组得分 = 绝对板面分还是增量分？骨架成员可带 sub_tiers/L3 键标签（瓦尔特即实例），L2/L3 键计数有骨架垫底——绝对口径下组得分含骨架贡献（加到哪？总分 = 骨架分 + Σ组分 会双计），增量口径需要基线定义，两者皆无文。③ 骨架成员自身的 L3 分（过渡骨架成员的 ×4/×1 计分）由谁承载零文（分组 = 手牌剩余件 = 骨架外）——若总分 = DP 累计分则过渡骨架板被系统性低估为零。三缺口合流：「DP = 单归属模型的精确解」（:82）与「状态 ≤ 组数 × K × 档阈值 ≈ 10³」建立在一个数值未定义的得分函数上，不可实现也不可验证。
- 证据：详设 :38-44（分值表）/ :79-83（段 2 组得分）/ :85（段 3「全候选集算选人分」——选人分读端亦未写死，见试读补问 1）。
- 严重度：高（**阻断**：核心计算的定义缺口——实现者可落「统一小数标度」而不自知违反层序设计；「精确解/毫秒级」全部声明悬空）。
- 是否阻断：是。
- 处置建议方向：组得分定义补三件——层域缩放常量显式进公式（组得分 = 层内分 × 该层域常量，引用 :48 隔离常量条）；基线口径写死（推荐增量 = 板面层分 − 骨架垫底分，防双计）；骨架成员分承载写死（推荐段 3 全候选重算 §1 评分，DP 仅为搜索中间模型——则全部模型-评分偏差按 D7-2/D7-3 逐项申报）。

### D7-2｜D6-4 损失上界与 D6-1 层归属全域正面冲突：跨组第二贡献可落 L1/L2 域（10⁶-10⁸），「≤ 10² 且不改板面选择」被同轮修复击穿——瓦尔特/三月七实存反例
- 攻击点：详设 :82「模型近似 = 多标签件的跨组第二贡献只计主归属组——损失上界 = L3 域 ≤ 10² 分，**跨层差距 ≥ 10³ 时不改变板面选择**，仅 L3 同层内 ≤ 10² 分差可能翻转」。该上界按「跨组第二贡献只能落 L3」推导——但 :81 同段刚把组得分扩到 L1/L2 域：多标签件的主归属组绑定其最高层键后，**第二标签落在更低层组（含 L2 的 sub_tiers 组）的贡献在 DP 零承载**，损失 = 第二标签所在层的全额。实存反例（注册表件，非构造假设）：锁定姬子线（form_tiers={列车同行:4}、sub_tiers={护盾:2,减益:2}），**瓦尔特**（cw_chars.py:190，factions=「列车同行、星间旅人」flows=「减益」）标签跨 L1（列车同行）/L2（减益=sub_tiers+TIER7）/L3（星间旅人=flex）三域，按「归属最高单位序组」归**核心键组**（L1 域）。局面：场上已有 1 减益件、手有瓦尔特 + 纯减益件 d + 万金油 w1/w2、K 剩 2 席。DP 模型（只计主归属组）：核心组取瓦尔特 → 列车同行未成档 → f=0（乘法制）→ 0 分；sub_tiers 组取 d → 本组贡献减益 1 人未成 2 人档 → 0 分；万金油组 w1+w2 = 4 分 → **DP 最优 = w1+w2**。真实评分：瓦尔特+d → 减益 = 场上 1+瓦尔特+d = 3 ≥ 2 人档 → L2 ≈ 5×10⁵-10⁶ ≫ 4 → **真实最优 = 瓦尔特+d，DP 漏板，损失 10⁶ 级**——超申报上界（10²）四个数量级，「跨层差距 ≥ 10³ 时不改变板面选择」的保证恰被 L2 域损失击穿。三月七（列车同行+护盾，:123）同款形态。这不是边缘：sub_tiers 键与主档键在同一阵容的成员标签上共存（姬子线/DOT 线实存），多标签件是 unit_bond_tags 结构常态（:27 自引）。D6-7②「锁定线 L1 补人贡献 = 核心键组承载」只救了 L1 维，这些件的 L2 维贡献无组承载。
- 证据：详设 :80-82（归属规则 + 近似申报）/ :27（多集自引）；cw_chars.py:190,123（瓦尔特/三月七标签）；cw_comps.py:577-597（姬子线 form_tiers/sub_tiers/flex）；cw_bond_equips.py:105-134（多集单一源）。
- 严重度：高（**阻断**：六轮两个处置在同段文本内互斥——「层归属全域」（D6-1）与「损失上界 ≤ L3 域」（D6-4）不能同时为真；近似边界申报失实 = 实现者带错误保证落地）。
- 是否阻断：是。
- 处置建议方向：损失上界按三域重推导（第二标签落 L2 的损失 = L2 域全额，可达 10⁶——是否可接受需重新申报）；或组得分按成员标签全集跨层计（需重新论证可分离性——组间经共享键耦合）；或归属规则改为「按可实现最高贡献层归属」（件归其第二标签能成档的组）——三选一并同步 :82 申报文本。

### D7-3｜相位判定载体「最终板面实测 L1」两读皆败：动态判 = 背包可分离性破坏；骨架固定判 = DP-评分偏差未申报——组得分行内声明未消歧
- 攻击点：详设 :81「**相位（过渡 ×4 与否）判定载体 = 最终板面实测 L1〔D6-7①：骨架形态只是候选生成，防载体错位〕**」——该句置于组得分 bullet 内，是对组得分中过渡系数（×4/×1）的说明，但 DP 内不存在「最终板面」（DP 是构造中的搜索）。两种读法：**A（组得分动态相位）**——DP 每状态的 ×4/×1 按当前部分板面的锁定线 L1 判 → 相位依赖**其他组**是否凑档（核心键组选件推高 L1）→ 组间耦合 → 背包可分离性破坏，「单归属模型的精确解」（:82）连模型内最优都不再成立；**B（DP 按骨架相位固定、评分按板面实测）**——模型-评分偏差未申报，反例：锁定窗骨架 t=0（空核心，相位 ×4）+ DP 核心键组把主档凑满第一档（板面 L1 > 0）→ 真实评分相位回落 ×1、过渡件 1 分/件，DP 仍按骨架相位给过渡件 4 分/件 → DP 多选过渡件、挤掉 buff 件（真实 3 分/件）→ 板面非评分最优且无边界申报。D6-7① 处置把「载体」从骨架改成板面实测，方向正确（防载体错位），但落在组得分行内就引入了两难——文本没有说明该载体约束的是 DP 组得分还是段 3 评分。
- 证据：详设 :81（相位载体句）/ :44（L3 行相位条件「锁定窗且锁定线 L1 = 0」）/ :82-83（精确解与可分离性声明）。
- 严重度：高（**阻断**：任一读法都击穿一个六轮处置的声明——A 击穿「精确解」、B 击穿「近似申报完备性」；实现者必须自决且两种板面行为不同）。
- 是否阻断：是。
