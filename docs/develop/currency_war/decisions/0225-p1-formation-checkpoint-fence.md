# ADR-0225 P1 成型检查点与集中买配方围栏

## Status

accepted(2026-08-22;r356;核心角色维 r358 进行中)

## Context

局38-45 连败的结构性判读(子代理架构反思 + 用户点破):决策系统对「成型进度」无感知、对「成型 deadline」无响应——配方不满 → 20 金息平台(前置 recipe_tier≥5)不开 → 金留不住 → 买散件 → 更不满的死循环;七局七根因是发散信号(同一缺失控制变量在不同 seed 下的投影)。跨局证据:唯二 HP≥60 局(161509/200035)都是配方 5 档满线(列车3+护盾2 核心);深 15-18 无差异——深度不是 boss 生存线,配方档位才是。

## Decision Drivers

- 用户口述[13]:过渡成型 = lv5-6 + 羁绊够 + 过渡核心 2 星(三元判据,羁绊只是其一)
- combo_methodology:核心三人组(饮月/藿藿/爻光)功能链不可拆,「羁绊档位只是载体,核心角色才是引擎实体」(用户原话)
- sim 战斗层不惩罚散面(桶宽 3),「散面 vs 集中」维度 sim 与实机方向相反——此维度以实机判读为准(ADR-0219 纪律)

## Considered Options

1. 继续逐局修单点 bug:七局七根因=发散,预期收益递减——拒
2. **成型检查点 + 围栏内嵌**(选):cw_line_defs.p1_formation_target(r3 桥2/r6 配方5/r8 配方7/r9 boss 窗)作判据单一源;集中买加配方围栏(recipe_tier<BASE 时只买 RECIPE∩板面);decide_prep 接检查点日志
3. 独立 formation_push 动作支(全预算冲刺):sim 实证 89% 空手+替换掉实战购买反而更差(hp_ge_60 2.2%→0.3%)——撤,围栏内嵌
4. 1-8 全卖过渡吃息(V4.0 知识):P2 转折关键但会裸奔 P1 boss,P1 过线后再做(缓行)

## Decision

选 2(经 3 的模拟先行否决迭代而来)。r358 增量(进行中):检查点加核心角色维——核心三人组 <2 在场时档位打折(空壳档位不算成型),消费方从 deployed 提取 char_id。锁:test_cw_r356_formation_checkpoint.py。
