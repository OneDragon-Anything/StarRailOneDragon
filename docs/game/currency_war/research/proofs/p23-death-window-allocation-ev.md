## 命题

本篇含三个不同强度的陈述,分级标注如下(诚实分级纪律:弱标定不写成强命题):

### 命题 P23.1(结构命题,已证):统一 EV 门式与盈亏平衡判据

在停手窗(成型已达成、直接购买目标件已无意义)语境下,一笔大额升级(lv8→9 / lv9→10,C = 72/84 金)的金当量期望净值为:

```
EV = Δp·L_c·m + w·m − C − I
```

放行判据为 **EV > 0**,等价的盈亏平衡条件为:

```
Δp ≥ Δp* = (C + I − w·m) / (L_c·m)
```

其中各符号见 §符号表。此为期望线性模型的恒等变形,符号推导不依赖任何数值标定(强命题);其**数值裁决**(EV 中心 ≈ −59 金/笔、Δp* ≈ 0.35)依赖下述参数带,为参数化结论。

### 命题 P23.2(参数化结论,弱标定级):停手窗域大额升级 EV 为负

在既有全部单一源标定内(W690 §3 参数表:Δp ∈ [0.03, 0.117]、L_c ∈ {11.3, 15.39}、m ∈ [5,19] 中心 15、w ∈ [0,3] 中心 1.5、C ∈ {72, 84}、I ∈ [0,20] 中心 8),EV 中心估计 **−59 金/笔**,标定区间 **[−97, +19]**;正号角点 +19 需四参数(Δp、L_c、m、w)**同时**取上界,而 Δp ≥ 0.35 的符号逃逸量级(≈ P3 阶梯 e0→e1 整档跳变 0.36)无任何既有标定支持。**本命题的符号结论以 [−97, +19] 带为准——这是弱标定区间,不是强命题**;复判条款见 §4(参数实采落定前不固化)。

### 命题 P23.3(结构命题,已证):死亡域第二账式

死亡域(Tier-2 帧:E[bleed] ≥ hp,即期望上本位面剩余战斗内血量归零)内,当**金零值近似**(引理 P23.4)成立时,机会成本项 C + I ≈ 0、视界截断为 m_eff = min(兑现长, battles_left_plane),统一 EV 门退化为**第二账式**:

```
m_eff × (Δp·L_c + w) > 0    ⟺    Δp·L_c + w > 0
```

即死亡域的放行判据只剩「每场金当量增量为正」——门在死亡域对任何 Δp·L_c + w > 0 的支出提案自动放行,「恒拒」在该域不可表达。

### 引理 P23.4(死亡域攥金优势引理;极限形式严格成立,期望形式为近似)

**(i) 极限形式(严格)**:若帧上确定死亡(P(活过本位面剩余战斗) = 0),则金在此后的终端价值恒为 0(死了后面全零,含利息收益流与出口金),故对任何支出提案 π:攥金(不支出)的收益 ≡ 0,而支出提案 π 的收益 = m_eff·(Δp_π·L_c + w_π)。于是**任何 m_eff·(Δp·L_c+w) > 0 的提案严格优于攥金**,任何 ≥ 0 的提案弱优于攥金——攥金在死亡域无任何优势(攥金死锁 W676 的反命题在极限下成立)。

**(ii) 期望形式(近似,方向已审)**:Tier-2 判据是**期望**死亡而非必然死亡;存活世界(如 hp=20 的帧赢下 boss)里金仍有真实价值,故 C≈0/I≈0 是近似而非定理,近似偏差 ≈ P(survive)·(C+I)(W706 §5-1:边界帧约 25-42 金级期望成本被记为 0)。该偏差方向单一(支出侧偏置,即本架构立项根源 W676 攥金死锁的**矫正项**)、且可经参数集内替换 `c → P(survive)·(c+I)` 收敛(存活加权成本,v6 设计预留出口,W706 §5-2)。引理的严格性只在 (i) 的极限形式上主张,(ii) 不写成强命题。

## 证明

### ① 停手窗域:统一式的正式化重述(W690 模型 → P23.1)

机制链(W690 §1 逐环 文件:符号:行,此处复述结论):lv8→9 / lv9→10 使可上阵数 cap 8→9 / 9→10,lv9→10 是最后一次真实人口增量(lv10 触及棋盘绝对容量 10,等级跨位面持久);板满 ∧ bench 有等待件时升级授权,兑现为该件此后每场战斗的边际贡献(长时域);便宜替代下(换人零成本可上 bench 件)净增量只是填充件级边际。

收益侧:设到账后剩 m 场战斗,第 j 场贡献期望金当量 (Δp·L_c + w)·S(j)。取 S ≡ 1(高估收益侧):

```
Benefit = Σ_{j=1..m} (Δp·L_c + w)·S(j) = Δp·L_c·m + w·m
```

成本侧:经验支出 C(机制常量 72/84)+ 破息损 I。相减即得 P23.1 之式。盈亏平衡条件由 EV > 0 解出 Δp:

```
Δp·L_c·m > C + I − w·m   ⟹   Δp > (C + I − w·m)/(L_c·m)
```

代入中心参数(m=15, I=8, w=1.5, L_c=13.3):Δp* = (92 − 22.5)/(13.3×15) = 69.5/199.5 ≈ **0.35**。□

### ② 数值代入(可复算展示;支撑 P23.2,弱标定级)

统一代入式 `EV = Δp·L_c·m + w·m − C − I`(全部参数出自 §符号表单一源):

| 点位 | 代入 | 结果 |
|---|---|---|
| 中心 | 0.05×13.3×15 + 1.5×15 − 84 − 8 = 9.98 + 22.5 − 92 | **−59.5 金/笔** |
| 标定上界角点 | 0.117×15.39×19 + 3×19 − 72 − 0 = 34.2 + 57 − 72 | **+19.2**(四参数同时顶格才为正) |
| 保底点 | 0.03×11.3×5 + 0 − 84 − 20 = 1.7 − 104 | **−102** |

区间 **[−97, +19]** 为弱标定带:正号域需要 ≥2 参数同时顶格且其中之一(单人口 Δp ≥ 0.35)无任何标定支持,按「结论强度取最弱一环」不构成翻案——但如实报告该角点存在,不复核参数前不把负判写成全域强命题。账本量级:w676 off 臂 200 局合计 6484 金/227 帧行(≈1.14 笔/局)→ 每局约 −52 金期望泄漏(新病灶候选定性,W690 §4)。□

### ③ 死亡域:第二账式的推导(P23.3)

死亡域判据 E[bleed] ≥ hp 下,引理 P23.4(i) 的极限论证给出金终端价值 ≈ 0,故:

1. 机会成本项:C 的机会成本 = 金省下来未来能换的战力 ≈ 0(未来被死亡截断);I 同理(利息收入流同样截断)。⟹ C + I ≈ 0(近似项,见 P23.4(ii))。
2. 视界:长时域计满跨位面的 m 不再合理——期望上活不过本位面,取 m_eff = min(兑现长, battles_left_plane)(截断只缩保证金余量、不翻转 Δp>0 提案的符号,W706 §2-3 方向审计)。
3. 代入统一式:

```
EV = Δp·L_c·m_eff + w·m_eff − 0 − 0 = m_eff·(Δp·L_c + w)
```

m_eff ≥ 1(死亡域内仍有战斗要打,否则提案无从兑现)时,EV > 0 ⟺ Δp·L_c + w > 0,即第二账式。□

### ④ 攥金优势引理的证明(P23.4)

(i) 设定死亡(剩余每场必败或已无剩余战斗可活):此后任何时刻的金对局局结果无贡献(无后续消费场景、无出口金、无利息兑现),故攥金策略的价值 ≡ 0。任一支出提案 π 的价值 = m_eff·(Δp_π·L_c + w_π) ≥ 0(每场增量非负时)。故 V(π) > 0 ⟹ π 严格优于攥金;V(π) = 0 ⟹ 弱优于。「攥金比花掉好」在死亡域无成立条件——这就是 W676 攥金死锁(局面越死越攥金)在死亡域的反命题。(ii) 期望死亡帧的诚实化见引理正文,P23.3 的门在此近似下判出的放行集合是真实放行集合的**超集**(偏差方向 = 支出侧),由存活加权成本参数替换收敛。□

## 适用边界

1. **弱标定区间不固化**:[−97, +19] 的中心负判在 Δp 直接标定落定前是**带内结论**。复判挂账 = 参数集版本化(v6 设计 §4-P5、承 W690 §4-4):Δp 单人口边际实采(sim 放开 LEVEL_CAP 臂后同池 A/B 反推,W690 §5-1)返回 ≥ 0.35 时,本命题 P23.2 必须重开;w 精确表与 P3 节点带收窄相应更新。
2. **辖域边界**:本命题辖「停手窗 + 死亡域」的支出分配;P21 硬停域(hp ≤ 10 濒死连发)不生成本命题提案(P21 判据先行,辖域不相交);早期/中期小档升级(C = 20-52)不受停手窗负判辖(W690 §4-3 的 m 需求分析:同式下 C=20 → m≈7 可达),本命题只辖 lv ≥ 8 大额档在停手窗/末窗的发生。
3. **近似的诚实声明**:死亡域 C≈0/I≈0 在 Tier-2 边界帧(存活概率不可忽略)有 P(survive)·(C+I) 量级偏差(W706 §8-5),方向单一且为设计意图内的矫正项;引理只在必然死亡极限下严格。

5. **不落码声明**:本命题是数学证明,不落任何决策代码;两域门的落码 = v6 设计支出分配器实施批(其量纲定义补全、估计器、锁面增补按 W706 §8 六条实现级瑕疵清单执行)。

## 与 P21 的关系

- **P21 的辖域**:P2 濒死段(hp ≤ H₀ = 10)连发升级,判据形式 = 存活到账(h > d·L_c)∧ 受益覆盖(Δp·Σ L_c·S(b) > C + I),结论 = 濒死域内两条件不可同时满足,EV 严格为负。P21 裁决的是**血量驱动的保血升级雨**。
- **P23 的辖域**:P23 把「受益覆盖」长时域账从濒死语境推广到两个 P21 未覆盖的域——①**停手窗**(成型已达成、非濒死、hp 充裕):存活到账自动满足,只剩受益覆盖账,即 P23.1/P23.2;②**死亡域**(期望死亡、但金价值归零改变了成本侧):成本侧塌缩给出第二账式 P23.3/P23.4。两域合起来覆盖「死亡窗支出分配器」的门数学。
- **关系性质 = 推广,非替代**:P23.1 的统一式在结构上就是 P21 §④「受益覆盖」式的 S≡1 闭式(Σ 退化为 m),P21 的判据形式作为 P23.1 在濒死语境的特例保持成立(其 81-cell 全负结论不变);P23 不触碰 P21 的濒死裁决、H₀ 常数与判据常数。引用纪律:濒死段问题引 P21,停手窗/死亡域支出分配引 P23。
