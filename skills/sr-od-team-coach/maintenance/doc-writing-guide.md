# 知识档填写指南（维护者文档·入口）

> 本文件是维护文档入口。三分结构：

| 文档 | 用途 |
|---|---|
| [templates.md](templates.md) | 各层知识档标准模板与公共红线（写档时查） |
| [methodology.md](methodology.md) | 填写方法论 v1-v12 持续总结（复盘时查） |
| [research-status.md](research-status.md) | 调研覆盖状态与数据管道对账（更新时查） |

维护流程：新档按 templates.md 的对应模板写 → 调研轮次记入档内 → 状态对账更新 research-status.md → 经验教训追加 methodology.md。
