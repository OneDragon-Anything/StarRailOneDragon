# 投资环境「变宝为废」：首次合成垃圾化机制与牺牲合成对策

> 来源：**游戏内明文效果文本**（bot 数据 `affix_effects_data.py` 逐字引用）+ 社区
> 整理（`data/competitors.md`）。

## 机制

**游戏原文**（`affix_effects_data.py`）：

> 变宝为废：每个位面开始时，首次合成的进阶装备会有 50% 的概率变成垃圾袋。

推读条目（非游戏原文，依据上文的解读）：

- **粒度=每位面各一次**：位面 1/2/3 各自的"首次进阶装备合成"各自有 50% 垃圾化
  风险（决策采纳记录见 ADR-0498）；
- 克制关系：克依赖合成的装备流（`data/competitors.md`；`cw_comps.py` 已有映射
  `"变宝为废" → "装备依赖"`）。

## 对策：牺牲合成先行（用户建议策略）

**证据等级：策略命题 [口述]，待证/挂账**（量化命题见下）。

每位面开始时，若计划进行高价值进阶合成（核心件 2★ 等）：

1. 先用**次要材料对**（低价值 1★ 对，不影响主线凑件）做一次牺牲合成——
   消耗掉"该位面首次合成"的垃圾化判定；
2. 再执行真正想保的高价值合成（此时已非"首次"，无垃圾化风险）；
3. 无次要对时：高价值合成接受 50% 风险、或推迟等次要材料。

**待证命题**：「推迟等次要材料的成本 < 50% 垃圾化损失的期望」——未量化，
挂 math_proofs 候补；实现按 strategy-work「决策规则数学先行」评估。
