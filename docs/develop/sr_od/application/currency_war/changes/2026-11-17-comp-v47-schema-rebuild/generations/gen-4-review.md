### 1.2 逐项证据与理由

#### 差异 1：Gate 第三要件「静态求值」 —— 采纳（附理由修正）

**核实结果：反例原文属实，v3 判据确实放行它们。**

- H2 篇（final_feixiao_zhuiji.md）§7 外部条件原文：「**开局无飞霄+无永动机 → 别玩这套路**（帖证明说门槛，本类最强形态门槛最高）」。同篇 §5 又写「**开局信号**：开局商店刷到飞霄+能早出永动机 = 最强形态信号（帖证）；**试用飞霄开局也能玩通**（帖证 2 篇）」。B1 篇（final_yinlang999_huanyue.md）§6 峰 C：「有千星商会转职直接无脑玩」「没有一两个千星转职很难追到 6 千星」——**缺转不开此流**。
- 按 v3 两要件（不可从注册表派生 ∧ 帖间一致「没有就不玩」）验算：两例的措辞都字面满足「没有就不玩」，也不可派生——**v3 判据确实会把它们判为「该登」**。而它们的本质是局内来牌/局内道具状态（飞霄 = 商店刷牌、永动机 = 局内合成、千星转 = 局内星徽），且「试用飞霄开局也能玩通」证明账号层面无硬依赖。
- **理由修正**：gen-4 说原判据「会把它们误登成 gate」——严格说不成立。v3 的 Gate 值域只有三种元组（命座/菜单含/奇缘星魂），来牌条件**登不进去**；真实风险形态是「判据说该登、值域装不下」——落库者遵循判据时发现无处落笔，要么漏登（判据与数据背离、无防线），要么擅扩值域或借用 Cond 强登，后者才构成 gen-4 说的误杀（每局开局飞霄未刷 → 条目永久出局）。第三要件的正确价值 = **判据与值域的一致性补全**：把「开局刷到 X 才玩」显式分流到策略层开局信号旁表，判据、值域、归属三方闭合。
- 附带收益：静态求值恰好是时机二分（账号级可缓存 / 局级每局开局评估）的公共前提——两种时机都要求开局静态可求值；第三要件让时机二分从「事后分类」变成「登记时的前置约束」。

#### 差异 2：Q8 出口站「伤害件 2 星」三级求值 —— 改采

**核实结果：缺口真实、载体真实、第三级举例失准。**

- **缺口属实**：融合谱系（gen-2/gen-3 的 Q8 行，v3 继承）出口站判据 = 「bond 档达 ∧ **engine 2 星** ∧ 保值件 ≥1」。而 engine 的登记判据是「拿掉则线不成立」，据此云五/反击/能量/DOT/击破/奇兽六条线 engine 均留空（云五判据只是云五 ≥2，景元是最便宜引擎非必要件，镜流+白露同样成档——transition_combos §3.3 原文口径；反击、能量同理）。engine 为空时「engine 2 星」无求值对象——出口站三件套之一空转。transition_combos §8 的出口站定义明确这些线都有伤害件要件（「云五 2-3+**2 星景元**+辅助位」「小众四线同构：首档+**2 星伤害件**+一件打工装」「成型判据（通用三件）：主伤害线首档齐+**伤害件 2 星**+至少 1 件合成装」）。缺口不是理论风险。
- **载体属实**：`cw_chars.py` 角色注册表确有 `category_tags` 字段（值域：输出/辅助/治疗/护盾，官方「取首技能标签组」口径）。二级派生验算：云五班底 {景元, 白露}（景元 1 费『输出』、白露 2 费『治疗』）∩ 输出 = {景元}，与 §3.3「引擎要求：景元（1 费输出）+白露（2 费治疗）」及 §8「2 星景元」精确一致；能量班底 {绯英, 知更鸟·晴歌}（『输出』/『辅助』）∩ 输出 = {绯英}；反击班底 {万敌, 云璃}（均『输出』）∩ 输出 = 双候选，由「先选伤害主体、来牌主导」收敛（§7 规则原文用于线间选择，线内双候选收敛是同构复用——transition_combos §4 反击线原文本就「把打工甲给万敌/云璃穿」并提无单点，同构成立）。
- **第三级失准（修正后采纳）**：gen-4 把第三级定义为「仍无（纯计数线如持续伤害）按来牌自适应」——注册表实证不成立：持续伤害线班底 {黑天鹅, 桂乃芬, 海瑟音, 娜塔莎} 中黑天鹅 =（『输出』,『辅助』）、桂乃芬含『输出』、娜塔莎 =（『治疗』,『输出』），**二级派生非空**且给出多候选。当前 10 条体系线中不存在「二级仍无」的实例，原表述使第三级成为死规则。正确重构：第三级 = **候选集多元素时的来牌自适应认定**（候选中谁先到 2 星即认谁为伤害件，与 §7「哪家伤害件先到 2 星就先开哪家线」完全同构）——持续伤害线恰是第三级的正例（非反例）。另须写明二级判据口径 = 「category_tags **包含**『输出』即命中（含兼项角色）」，防消费方误读为「首标签为输出」；当前三线无兼项干扰，但银轨班底的瓦尔特（『输出』,『辅助』）一类兼项未来会进候选。
- **隐式依赖风险核实（gen-4 风险 8）**：属实。二级派生引入了对 category_tags 口径（值域、取值方法）的新依赖，注册表生成器若改口径，Q8 派生静默漂移、库校验无防线。缓解（写进 Q8 消费文档 + 版本重跑前置检查）采纳，并立开放问题 N6。

## 3. 融合方案（v4 = v3 + 修订清单）

骨架不变：**17 字段（条目 3 + 阶段 8 + 过渡 2 + 库级 4）+ 3 构件（Cond/Gate/EquipPool）+ 两库分立 + 消费八问 + 三层归宿 + V1-V11 校验框架**，第四次独立复现一致，全部沿用 v3；以下修订直接改写到 v3 对应位置。

### 修订清单（5 项）

**R1（改 v3 构件 Gate 登记判据行）——补第三要件「静态求值」。**
登记判据从两要件扩为三要件：① 不可从注册表派生；② 帖间一致「没有就不玩/账号限定」（「没有则降级仍可玩」不登）；③ **静态求值——门槛求值只依赖开局即可知的账号持有或今日菜单类信息，不依赖局内来牌与合成随机**。「开局刷到 X 才玩」类条件（H2「开局无飞霄+无永动机别玩」、B1 峰 C「缺千星转不开此流」）文本上过要件②但 X 是来牌/局内道具，归策略层开局信号旁表。理由：v3 两要件下这类条件被判「该登」而 Gate 值域装不下（判据-值域自相矛盾）；第三要件同时是时机二分（账号级缓存/局级开局评估）的公共前提，三方闭环。

**R2（改 v3 过渡条目字段 13 语义 + 库级消费契约区）——Q8 出口站伤害件三级求值（修正版）。**
出口站判据维持三件套（bond 档达 ∧ 伤害件 2 星 ∧ 保值件 ≥1），「伤害件」求值三级：
1. `engine` 非空 → 取 engine（点名伤害件：连击线那刻夏、大黑塔线大黑塔）；
2. engine 为空 → 取派生班底 ∩ 角色注册表输出标签（category_tags **包含**『输出』即命中，含兼项角色；载体口径 = 官方「取首技能标签组」）——单元素即精确认定（云五 {景元}、能量 {绯英}）；
3. 候选集多元素 → 来牌自适应认定（候选中谁先到 2 星即认谁，与 transition_combos §7「哪家伤害件先到 2 星就先开哪家线」同构；反击线 {万敌, 云璃}、持续伤害线多候选均走此级）。
0 字段增删、0 校验增删（纯派生规则，归 Q8 消费文档）。**连带**：Q8 消费文档必须写明二级判据口径（包含即命中）与 category_tags 依赖；版本重跑前置检查增补「category_tags 口径 diff」；对应新开放问题 N6。

**R3（改示意案例谱系）——B4 真珠配方修正。**

## 7. 收敛判断

**本轮变化量：小。** 相对 v3：0 字段增删、0 校验增删、0 构件变更；实质变化 = 2 项判据/消费语义补全（Gate 第三要件、Q8 三级求值——修正后并入）、1 项案例勘误（真珠配方）、1 项形式统一（H1 特设结论撤销）+ 若干注记。对比 gen-3 轮（五项增量含 EXACT 口径、帖量带成文、V11 新校验），分歧面继续收窄，且收窄到「判据边角 + 案例」层。

**连续两轮无结构变化：成立。** gen-3 与 gen-4 两轮均为 0 字段增删、0 校验增删、0 构件变更——17 字段骨架经第四次独立全源复现逐字一致，**结构层面判定收敛**。

**是否继续循环：分层建议。** gen-3 轮评审曾建议停轮、用户裁定多跑几轮——本轮结果证明继续跑有边际价值（4 项差异中 Gate 判据漏洞与 Q8 空转缺口是真实缺口，停轮轮次会带着它们进落库），但同时价值面正在快速枯竭（另 2 项已是勘误与形式统一层）。据此：

1. **结构层面：确认收敛，不再有全源循环的期望产出**——第五次独立复现大概率复述 v4，挖不出第五个结构差异。
2. **若继续跑（用户已要求），价值面在三处，按性价比排序**：① **定向对抗复核而非全源复现**——以 v4 的 R2 修正版三级求值为靶（本轮改采引入的新表述，未经下一轮独立检验，是当前唯一「年轻」的判据文本），连同 N6 依赖做一轮小范围复核，成本远低于全源重读；② **消费方视角反查**——从策略层消费文档侧反向核对消费八问的字段供给（N1/N2 的实跑验证前置），这是纸面循环挖不到、但对落库质量有直接收益的角度；③ 落库批本身——实数据 + V1-V11 实跑会让让位序/ceiling 灰区/快照漂移（开放 3/N1/N3）暴露真差异，是下一个能产生实质分歧的环节。
3. **明说**：再跑一轮全源独立稿的期望增益已低于一轮定向复核；若第五轮仍要跑，建议改形式（定向靶 / 消费方视角），跑完无论结果如何都应转落库批——结构循环到此收官。
