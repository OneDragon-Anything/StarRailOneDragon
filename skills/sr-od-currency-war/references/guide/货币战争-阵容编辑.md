# 货币战争-阵容编辑（我的阵容自定义编辑器）

**识别**：`is_precise` 命中 `货币战争-阵容编辑`（锚：标题「阵容编辑」+ 阶段页签「前期」「中期」「最终」多文本组合）。
**目标**：「我的阵容」的自定义编辑器——三阶段板（前期/中期/最终）+ 角色/装备拖拽编辑；与过渡阵容三段式建模直接对应（最小档建档，深探未做）。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：攻略列表「我的阵容」主页签 → 任一「新建阵容」。
2. **结构**：顶部「角色/装备」两页签；左侧角色面板按费数分组（5 费/4 费/3 费…）；右侧三阶段板各分前台/后台区域（带 n/13 计数），提示「可拖拽角色或装备至对应位置」；底部「简易装备优先度/进阶装备优先度」链 +「运营思路/清空/保存阵容」按钮。
3. **编辑**：拖拽式（角色面板 → 前台/后台槽位），MCP `drag` 看图操作；编辑/保存/发布攻略码流程未深探。
4. **出口**：ESC 回我的阵容列表（实测，无保存确认）。

坑：除识别锚与结构清单外交互未深探，动手前按当帧现读，别按本文档推行为。
