## 一、新问题清单(严重度排序)

### P79-1(中)§4.4「P2 sink 供给」的验收指向按现文不可测——死型无操作化定义、无阈值锚、无批口径

**论断**:登记行(01_strategy_layer.md L118)验收句=「落码后位面 2 不得复现金堆积→战力停滞→被节点税磨死的死型(sim/实机判读可验)」——这是通道指针,不是可执行验收判据。「死型」无判定规则、「不得复现」无对照基线与阈值、判读批无样本量/统计口径。按本设计件自身的合格线惯例(观察键须「有样本量下界」、超标判读须挂可辨成因分键,先例=R76-7/R74-3),该验收指向落码期不可裁决「过/不过」。

**证据**(亲读):
- 01_strategy_layer.md L118:验收句全文如上,机制形式「由落码期设计」已显式开放(这半边合规),但验收半边同样悬空。
- 依据报告 `.debug/temp/currency_war/p2_failure_modes_20260902.md` **已含可直接操作化的验收材料而未被登记行引用**:L77-78 FM-1 定义(死时金 107.7、死时全部 lv9、form 1.0、每轮只买 0-3 张;sim 死亡占 67.8%)、L69 实机死时金均值 72.1/≥50 占 81%(53/65)、L32 P2 帧 spend/income=0.464、L41 sink 枯竭三通道(bench 封顶/lv9 后 XP 通道耗尽/D 受限流)。
- 同节姊妹登记(L119「成型判据失义」)给出了具体挂点指针,对照之下 L118 的验收句确为定性链。

**推理链**:验收判据 = 判定规则 + 对照基线 + 判定通道;现文只有第三件。FM-1 定义本身就是现成的死型操作化(死时金≥50 ∧ 死时满级 ∧ form 达标 ∧ 低买入率四联),基线数(67.8%/81%/0.464)已在报告在册——登记行放着现成锚不引,验收时任何一方都可对「死型是否复现」各执一词。结论强度:论断/证据/推理三件齐,定级「中」(不阻塞落码,但验收门空转)。

**修法指向**:L118 补一句验收锚——「验收判据=FM-1 操作化死型(四联判据,引用 p2_failure_modes 报告 §FM-1)+ 基线对照(sim FM-1 占比 67.8%/实机死时金≥50 81%/spend-income 0.464),阈值与批规模在落码期预注册后定值」。

### P79-2(中低)R77-3 条②与条①计数字径两读互斥,且「费用有效域内误读」通道未申报——按字面落码会复活条①要消灭的断链病

**论断**:R77-3① 钉死「费用维不进判读语义,重现=归一后同名即重现」;R77-3② 却写「**同名同费**多张同帧 multiplicity=计数制(在店计数归 0 才判离店)」。若实现者按字面把计数字径取 (名,费) 二元组,则费用在 1-5 有效域内的 OCR 误读(如 4 读成 1——**不属于** `invalid_cost`)会切键:(名,5) 计数归 0 → 触发离店判定 → 误判离店/误断 streak,恰是①「进匹配会在缺读帧断链」要消灭的病从「缺读」通道换形复发;③只申报了 `None` 退化形态,未申报有效域错值形态。

**证据**(亲读):
- `src/sr_od/application/currency_war/obs/cw_shop_obs.py` L54:``invalid_cost``:费用不在 1-5(OCR 误读/缺读)」——有效域内的错值不判 invalid,会以合法费用入键。
- IMPL_FIX_LEMMAS.md R77 对照表 R77-3 行:①「费用维钉死不进判读语义(键含费用仅身份区分+披露维度,重现=归一后同名)」与②「同名同费多张同帧 multiplicity=计数制(在店计数归 0 才判离店)」并存,②未声明计数字径按名归并。
- R77-5(a):实例账本 entry={name,cost,streak 起讫帧}——cost 进 entry 事实,与①的「仅披露维」相容,但与②的「同费」字样共同诱导 (名,费) 字径读法。

**推理链**:两读各违一条:按 (名,费) 计数 → 有效域费用误读切键=误判离店(违①语义);按名计数 → 「同费」二字冗余误导(措辞病)。结论在「措辞需单义化」层面成立,不定级更高因为判读语义若按①执行、误读通道残余量级=单帧宽判(与③已申报的名-only 碰撞同量级)。三件齐。

**修法指向**:R77-3② 补一句钉死——「计数字径=按归一名聚合(与①判读语义同字径),费用字段仅随 entry 披露;『同费』表述作废」;或显式申报「有效域费用误读 ⇒ entry 分裂」残余(仅披露粒度损失,判读不受影响)。

### P79-3(低中)R77-1 词形变体召回零的残余未申报,且「长尾检视」检出通道与词表同源=循环;{0,6} 窗宽无依据记载
