# DD-012:sim 校准语料伪影治理——Δ池与粗模型直方的结算瞬时 hp=0 伪读数剔除

- Status: accepted(编排者 F6 修复批执行 + 本批 p15 重拟合收尾,2026-09-02)
- 依据: `.debug/temp/f6_delta_pool_report.md`(F6 修复批报告,溯源逐行证据);真值锚 = tools/cw/proofs/p15/(对局档案冻结语料)

## 背景

原批 P1 桶出现单轮深损 -84/-86 的采样值,与玩法文档口径(P1 单轮 40-80 量级损血不可能)量级矛盾,立案排查。

## 溯源结论:伪影,非规则

- **机制**:生产 outcomes 遥测在结算画面过渡帧把血条读成 0,紧随的同轮行恢复到真实血量(84→0→71 型)。配对器按相邻行 hp 差分,把每条伪影拆成两条毒行:一条假深损 `-(hp)`、一条假大回血 `+恢复值`,双双入池。
- 真值上限锚:对局档案真值语料(tools/cw/proofs/p15/,结算屏遥测,P1 n=290)未删失最大单轮 |Δ|=36——P1 单轮 -40 以下不存在,与文档口径互证,排除「存在未记录扣血规则」。
- 排查过的另两个假设均排除:位面错标、桶键缺位面维。

## 决策(根修)

1. **池构建过滤**(`sim/pool.py::_pool_from_replay` + `sim/cw_delta_pool_gen.py::build_pool`):非终局 `hp_after==0` 行判定为伪影,配对前剔除(终局 hp0=真死,保留);剔除计数入 META `hp0_transient_dropped`。
2. **快照重建**:`_DELTA_POOL_FROZEN` 撤销(快照仍辖 reward/supply 池与 delta 对照臂),新指纹 bfaf1c955ccc7752(旧 6400d5d8),剔除 60 条伪影行(30 对毒行)。
3. **粗模型直方治理**(`kernel/cw_coarse_battle.py::_LOSS_HIST`):剔除伪影产物档 battle {±42,±43,−64,+46,+84,+88}/encounter {+45,+83}——剔除判据是真值上限锚(|Δ|≥40 档在 P1 真值语料不存在),非「采样后截断大值」。
4. **_LOSS_FIT 重拟合**(本批收尾):原 intercept/slope 系已删语料(w324)回归值,该语料含同类伪影——拟合依据语料已灭且确认污染,常量不得再以它为锚。改由 p15 真值语料(P1 非删失败局行 battle n=82 / encounter n=66)逐行最小二乘重估:battle (11.32, −0.37, 11.06)→**(11.48, −4.21, 10.45)**;encounter (24.32, −4.53, 18.05)→**(15.06, −3.27, 12.18)**。`COARSE_CALIB_VERSION` 2→3(直方剔档)→4(重拟合)。边界:battle rung2 仅 n=1,斜率主要由 rung0/1 撑起。

## 教训

「面板/读数缺席 ≠ 收入/规则缺席」同族:**遥测伪读数会伪装成游戏规则**。治法 = 用独立真值语料(对局档案结算屏遥测)给任何「疑似新规则」的观测上限锚定,锚不上的量级先按伪影排查,不先按规则立法。
