# 崩铁新手与日常决策（basics 层）

> 按 V4.7 期整理。「会玩崩铁」的日常决策知识——不涉具体角色（角色层查）与特殊玩法（专项 skill 查）。骨架档，随调研轮充实。

## 体力（开拓力）怎么分配

- 每日自然恢复 240（1 小时 10 点；后备开拓力是储备，不进日预算）；**勿溢出**。
- 优先级参考：当日体力本（花萼金/赤 按当前养成缺口）＞ 饰品提取（定向刷核心 C 的位面）＞ 周本（历战余响，每周 3 次×30，留周日打最高难度）。
- 侵蚀隧洞（遗器本）刷取时机：主力队伍成型后再全投入（前期用散件过渡）。

## 养成优先级（先练谁）

1. 一队主C（毕业向五步，负责人裁定 2026-11-15：**等级 → 光锥 → 遗器穿对 → 行迹 → 遗器词条精刷**）
   - 等级与光锥升级快、收益直接，排最前；
   - 遗器分两段，不整体垫底：先「穿对」——主词条对 + 副词条大致有效（挑件判据见 `../mechanics/relic-enhancement.md` §1），穿对即可先穿；「词条精刷」是长线过程，放最后；
   - 行迹夹在两段遗器之间：遗器穿对之后拉行迹，行迹成型后再回头精刷遗器词条。
2. 一队生存位（保证通关）
3. 一队辅助位（拉条/增伤）
4. 第二队（深渊双队伍刚需）——再往后按当期环境补
- 角色具体练度口径（词条/转化上限/毕业面板）查 `../characters/<角色>.md`。

## 角色养成操作（游戏内怎么做）【实测】

### 角色等级线 → 独立档

角色等级线（晋阶升级）已独立成档 `../mechanics/character-enhancement.md`——决策规则（等级排养成第一位、等级是行迹前置、晋阶分段制）、游戏内交互实测（进详情两条路/详情画面结构/列表浮层/晋阶界面与「快速刷取」闭环）、`UpgradeCharacterOp` 操作路由、缺料补齐路径（①②③④，含④用 MCP 改开拓力计划/周本计划排产，**改前必问用户**）、材料查询。本节以下只留光锥/行迹/遗器三线的游戏内实测。

### 光锥养成（升级与晋阶）【实测】

- 入口：光锥页签右下「替换 / 强化」两按钮，「强化」进晋阶界面。
- 光锥晋阶界面与角色晋阶**结构同款**（等级对比/属性预览/快速升级开关/消耗材料栏/信用点），差异：右上角是关闭 X（角色晋阶是返回箭头）。
- **缺材料时按钮三态**（与角色晋阶的两态不同）：
  - 材料足 = 白底「快速升级」可点；
  - 缺专属材料但通用材料够 = 白底「**使用通用材料补全**」可点——点开「材料补全」确认框，以通用材料（梦之珠泪类）合成替代缺口；通用材料非稀缺（负责人裁定：养成路线的最优先选项），量大时留意库存即可；
  - 全缺 = 灰字禁用（推理形态，未实测）。
- 晋阶成功后结果横幅形态未实测（首版 op 按过渡态点空白兜底）。
- 材料来源：专属材料出自拟造花萼 (赤)属性池（与行迹共用）；经验书出自拟造花萼 (金)；查询走 MCP `cone_lookup(光锥名, with_ascension=true)`（分段晋阶表+材料+副本实例一次拿全，同 `character_lookup` 口径；**段名口径：「Y级」=突破段、「X～Y级」=经验段以稀薄以太计，界面按所持书籍折算显示**）；副本归属与缺料刷取同角色线（`FarmLightConeMaterialOp` 跳转路径通用）。

### 技能提升（行迹）【实测】

- 入口链：行迹页签 → 行迹树点目标技能节点（普攻/战技/终结技/天赋/秘技）→ 节点详情面板（同屏面板态，非独立画面）。**节点选择归 agent 读画面完成，程序层不做**——技能树布局随命途不同、同命途不同角色的分支节点数也可能不同（负责人确认），固定坐标不可维护（负责人裁定 2026-11-14）。
- 节点三态（选节点判据【实测】）：
  - 图标黯淡 = 未激活（不是升级目标）；
  - 图标鲜明但下方无数字 = 无需升级（已激活的属性小节点、特殊节点）；
  - 图标鲜明且下方有数字 X/Y = 可升级技能节点，数字 = 当前等级/当前上限（上限随角色晋阶解锁，80 级样本：普攻上限 6、其余 8~10、秘技 1）——先晋阶再拉行迹。
  - 特殊类别：星神★阿哈的树含第六类「欢愉技」与「星神权能」节点（权能 1 级即满）——树形因角色而异，三态判据通用。
- 界面要点：
  - 面板选中态锚 = 「简略描述」开关（常显）；「下一级」按钮在满级面板消失，不可作锚。
  - 面板打开时整棵树向左平移约 413px（1080p 实测，y 不变）——面板开着时点其他节点坐标要带该偏移；点空白处关面板。
  - 实测坑两条：面板关闭后节点保持选中态，再点同一节点是「无操作」，面板不重弹；属性节点的「需解锁前置行迹」提示面板是模态的，不先关掉会吃掉后续所有节点点击——先点面板外空白关闭，再点目标节点。
- 升级执行（按钮四态）：材料足 = 白底「快速升级」可点，点击**无确认弹窗直接消耗**；缺专属材料 = 「使用通用材料补全」（授权后确认弹窗，消耗通用材料合成替代缺口）；全缺 = 灰字禁用；满级 = 按钮消失、显示蓝字「已达最大等级」。快速升级开关默认开（开 = 自动填材料）。「可提升至N级」角标 = 含通用材料补全在内可达的目标等级，可作升级前预期核对。
- 材料来源：行迹与光锥晋阶共用属性材料池（拟造花萼(赤)）——常规刷取一次可补多线缺口；材料清单与刷取点走 MCP `character_lookup('角色名', with_ascension=true)` 的 `trace_materials`，数量缺口以游戏内行迹/晋阶界面实读为准。
- 快速刷取与刷本入口（实测定案 2026-11-14）：面板「快速刷取」→「培养还需获取资源」窗口（**只列缺料行**）。行内橙色快速券按钮直接拉起「快速刷取弹窗」（不进副本，取消后回资源窗口）——拟造花萼(赤)档消耗 = **开拓力 10 + 券 1/次**（弹窗消耗行实读）。行内「进入」按钮 = 手动刷本入口（花萼/周本都有）：进挑战画面（花萼 = 「挑战副本」画面·拟造花萼标题 + 挑战次数滑条 + 左下快速刷取；周本 = 独立画面档「挑战副本-历战余响」·历战余响标题 + 无滑条 + 「剩余次数 N/3」横幅）。**父链只在未真打时完整**：进入即退（关闭副本→资源窗口→关窗→面板态）可原路回；真打后（挑战→编队→战斗→挑战成功画面→退出关卡→挑战画面→关闭副本）直接落大世界，父链断裂，回面板态须整链重导航（周本零消耗样本实测定案）。周本次数耗尽（0/3）时可零开拓力打、无奖励。行识别锚 = 周本行上方「本周可领取奖励次数」文本，读到 0/3 = 周本不可刷（负责人裁定：不打；挑战画面点挑战会弹次数耗尽确认框，取消即可）。挑战画面「快捷补充开拓力」开关默认开——挑战时开拓力不足由备用开拓力补足（不是星琼）。
- 边界与未实测点：升级执行后的反馈形态未实测（横幅或等级直跳未知，自动化按稳定等待收敛）；「快速升级」开关关闭态行为未实测；信用点不足形态未实测（预期判停兜底，报告理由可能误标为材料不足）；材料补全弹窗在通用材料不足时确认按钮形态未实测；升级面板材料徽标计数语义未定案（勿按面板徽标做缺口判定，以补全弹窗「需求数/持有数」与库存实读为准）。

### 遗器提升（强化）【摸底】

- 入口链：遗器页签（着装页）点遗器件 → 「遗器-替换」界面 → 选中遗器右下「强化」按钮 → 「遗器详情」强化页签。
- 界面要点：强化材料 = 吃其他遗器（8 格）+「4星及以下」筛选 +「自动置入」自动填料；经验条（0/560 式读数）= 距下一级所需；右下「强化」大按钮执行；同步消耗信用点。
- 升级执行：「自动置入」填料（默认吃 4 星及以下狗粮）→ 点「强化」执行；无狗粮时卡在填料步（见边界）。
- 材料来源：狗粮 = 4 星及以下遗器库存；5 星遗器属高价值资产，不作默认狗粮。
- 边界与未实测点：
  - 狗粮库存为空时「自动置入」无动作——无狗粮 = 无法强化（常态，非识别异常）。
  - 吃 5 星遗器属高价值消耗，自动化绝不默认；涉及 5 星遗器的消耗须用户明示授权。
  - 遗器强化 op 未实现：暂无实机验证场景，待狗粮库存非空或用户明示消耗授权后落地。

### 材料需求与刷取点查询（缺材料时）

- **材料去哪刷**：按材料的养成线反查——角色线走 MCP `character_lookup('角色名', with_ascension=true)`（`dungeon_by_material` 分类级 + `missions_by_material` 实例级，带区域、与指南关卡同名对齐可直接路由导航），光锥线同口径走 `cone_lookup(光锥名, with_ascension=true)`。通用机制：花萼（金/赤）按命途与属性分、凝滞虚影按 boss 分（例：天人遗垢 → 凝滞虚影·天人之形@丹鼎司；永恒之花 → 拟造花萼（赤）·丰饶之蕾@边缘通路）；晋阶中高级材料（如永寿天华/永寿荣枝）副本线仅差分宇宙，花萼只掉低级档，中高级靠合成机升阶——**常规刷取（自己刷副本）只耗开拓力，不耗快速刷取券**。
- 副本之外的获取途径（合成/置换/商店/任务等）在同一常量文件的 `MATERIAL_EXTRA_SOURCES` 表（材料 → 途径清单），副本表查不到时查它。
- 角色等级线的缺料处理顺序全文（①通用材料补全 → ②快速刷取 → ③手动刷本 → ④转计划排产，含 **④ 用 MCP 改开拓力计划/周本计划的完整操作、「改前必问用户」纪律与次数估算/日预算 240**）在独立档 `../mechanics/character-enhancement.md`（§4 缺料补齐路径、§4.1 改计划操作、§4.2 次数估算与日预算、§5 材料查询）；角色线查询工具（`character_lookup(with_ascension=true)`、`character_ascension_const`）同在该档 §5。

### 已建成的养成 op（agent 可直接运行）

上文交互已固化为可运行 operation（经项目 MCP `run_operation` 调用，op_id 格式 `sr_od.operations.<模块>.<类名>`；同款先例见逐光捡金 skill 的编队与战斗 op 节）：

- `GotoCharacterDetail`（`sr_od.operations.goto_character_detail.GotoCharacterDetail`，无参）：任意画面 → 角色详情画面（大世界右上头像直达，不经列表）。终点 = 详情页·默认角色。
- `SelectCharacterOp`（`sr_od.operations.select_character.SelectCharacterOp`，参数 `cn_name` = 角色中文全名，间隔号两式均可）：详情页打开列表 → 按名选中（头像模板识别+翻页遍历）→ 收列表。终点 = 详情页·目标角色·列表已收。
- `SwitchCharacterTabOp`（`sr_od.operations.switch_character_tab.SwitchCharacterTabOp`，参数 `tab_name` = 详情/光锥/行迹/遗器/星魂/信息）：左侧页签切换。⚠️ 仅无遮挡态（列表浮层开着会显式失败）。
- `UpgradeCharacterOp`（`sr_od.application.cultivation.character.operations.upgrade_character.UpgradeCharacterOp`，参数 `fill_generic` 默认 True / `farm_dungeon` 默认 False / `use_fast_ticket` 默认 True / `farm_times_per_round` / `farm_rounds_max`）：晋阶升级至当前上限。`fill_generic=True`（默认）缺料自动确认「材料补全」弹窗（通用材料合成补齐）；右下全灰「材料不足」时由 `farm_dungeon` 控制：False 判停返回详情（零额外消耗）；True 自动「快速刷取」补材料后继续升级——**每次刷取消耗开拓力 30 + 快速刷取券 3（券不可自然恢复），调用方发起前必须向用户说明预计消耗并获明确同意**。终点三种：`MAX_LEVEL`（已满）/ 升满当前段 / `MATERIAL_CAPPED`（材料或刷取预算耗尽停在当前等级）。手动刷取路线战斗失败自动继续（委托共享件回挑战画面，预算内重发、连败或预算耗尽止损收尾）。执行消耗真实材料与信用点。
- `UpgradeLightConeOp`（`sr_od.application.cultivation.light_cone.operations.upgrade_light_cone.UpgradeLightConeOp`，参数同上结构：`fill_generic` 默认 True / `farm_dungeon` 默认 False / `use_fast_ticket` 默认 True / `farm_times_per_round` 默认 -1（拉满，材料共享库存多余留他用）/ `farm_rounds_max` 默认 1）：光锥晋阶升级至 80 上限。缺料时通用路线自动确认——「使用通用材料补全」与「材料合成」两形态均弹「材料补全」确认框，op 一并支持；`farm_dungeon=True` 走快速刷取链（资源窗口→副本：券路线耗券 1/次、手动路线耗开拓力 10/场），一轮拉满回来不够即判停报告——**发起前须向用户说明并获同意**。终点：`LIGHT_CONE_CAPPED`（满级或材料判停，日志注明）。手动刷取路线战斗失败自动继续（委托共享件回挑战画面，预算内重发、预算耗尽止损收尾）。前置链同样四步,第三步切「光锥」页签。
- `UpgradeTraceOp`（`sr_od.application.cultivation.character.operations.upgrade_trace.UpgradeTraceOp`，参数 `target` = 技能名（普攻/战技/终结技/天赋/秘技等面板分类名，与面板现读等值校验，不设固定枚举），`fill_generic` 默认 True / `farm_dungeon` 默认 False / `farm_times_per_round` 默认 -1（拉满）/ `farm_rounds_max` 默认 1）：**面板态契约（负责人裁定已落地）**——起点 = 角色-行迹·面板态（agent 在树态读节点三态、点开目标技能面板后调 op），起跑闸双锚校验（「简略描述」开关 + 分类读区现读 == `target`，不符显式失败，零消耗拦点错节点）；终点 = 一切出口先关面板回树态（`MAX_LEVEL` / `MATERIAL_CAPPED` / `不在目标技能面板`）。缺料先通用材料补全（双形态：材料补全/材料合成，默认开）；`farm_dungeon=True` 自动花萼券刷（**拟造花萼赤档位，开拓力 10/次 + 券 1**，链路 = 面板快速刷取→资源窗口→花萼行券按钮→共用弹窗连刷→回面板）——发起前须向用户说明并获同意。**手动刷本划出 op 边界**：花萼侧调用方按行迹缺料自行导航至对应副本挑战画面（`FarmTraceMaterialOp` 立项前过渡态，勿套用只认光锥缺料格的 `FarmLightConeMaterialOp`），周本走 `ChallengeEchoOfWarByName`；op 判停交还调用方编排，agent 刷完重选节点开面板再调 op 续跑。循环内画面异动（面板不在/分类不符）显式失败交 agent 重新发起。
- `FarmLightConeMaterialOp`（`sr_od.application.cultivation.light_cone.operations.farm_material.FarmLightConeMaterialOp`，参数 `times`/`team_num`=0/`support`）： **缺料手动刷取（游戏跳转路径，推荐顺位③——只耗开拓力但耗时最长，优先推荐①通用材料补全/②快速刷取）**——起点 = 光锥晋阶画面（调用方经 前往详情→选角色→切光锥→点强化 到达），扫描消耗材料栏计数条红字定位缺料格（「拥有数」不足变红、颜色统计判定，OCR 对红字漏读不可用）→ 点格开材料弹窗 → 弹窗标题 OCR 材料名（difflib 容错误读）按静态表预期取目标 → OCR 定位带【区域】的途径行（ **行 Y 随描述长度漂移，不可固定**；预期行可能在视口下方，列表内拖动重扫有界 3 轮，不用滚轮）→ 点击直达副本挑战画面 → 委托 `UseTrailblazePower(skip_transport=true)` 完成选次数/配队/战斗。导航真相源 = 游戏自己的跳转；静态表 `MATERIAL_MISSIONS` 只用于「有无副本可刷」预期与行定位核对。缺料材料无可刷副本（途径均为敌方掉落/合成类，如实机样本永寿荣枝）→ 显式失败 `MATERIAL_NO_DUNGEON`；无缺料 → `NO_LACKING`。⚠️ `times × mission.power` 开拓力真实消耗，发起前须向用户说明并获同意。战斗失败自动继续（委托共享件回挑战画面，预算内重发）。✅ 全链实机验证通过（花萼×1 实跑 48.5s）；拖动重扫为单元验证（自然样本未现，预期行均在首屏）。
- `ChallengeEchoOfWarByName`（`sr_od.application.echo_of_war.challenge_echo_of_war_by_name.ChallengeEchoOfWarByName`，参数 `mission` = 周本关卡中文名（如「坏灭的喜剧」，与关卡名互相包含即命中）或关卡 ID / `plan_times` 默认 1）：**周本缺料手动刷取（推荐顺位③的周本路线——行迹高级材料出自周本，花萼材料仍走 `FarmLightConeMaterialOp`）**——起点任意（自行回大世界导航，行迹面板态起跑已实测），配队固定取周本计划该关卡项：**计划配队=0 时沿用当前编队并在日志显性提示——当前编队可能是上个玩法残留，周本败场照扣开拓力；换配队去周本计划/GUI 改，无 override 参数**。链路 = 回大世界→指南传送→挑战循环（三弹窗防线/战斗失败自动继续/连败放弃/超时收尾）→收尾回大世界。成功终态恒「已返回大世界」；`本周次数耗尽`（弹确认框自动取消，零消耗零次数）/`开拓力不足`/`连败放弃` 等按 status 如实回报并转告用户；失败原样透传、画面停原地交调用方处置。⚠️ `plan_times × 30` 开拓力 + 周本次数真实消耗，发起前须向用户说明并获同意。✅ 零消耗链实机验证（0/3 面板态起跑→次数耗尽弹窗取消→回大世界，33.8s）；全胜链待周本次数恢复实测。

前置链 = 四 op 依次调用（进详情 → 选角色 → 切目标页签 → 升级）；前置不符各 op 显式失败，不互相补导航，组合编排归调用方。

### MCP 调用与编排建议

- 现状可直调（项目 MCP `run_operation`，op_id = `sr_od.operations.<模块>.<类名>`）：前置链三 op + 等级/光锥/行迹三线 op + 材料刷取 `FarmLightConeMaterialOp`（清单见上节）；遗器强化 op 待建。
- 一次养成 = 调用方按序串联四步（进详情 → 选角色 → 切页签 → 升级 op）；行迹多技能 = 追加多次 `UpgradeTraceOp`。组合编排归调用方是既定约定——各 op 前置不符显式失败、不互相补导航，op 间不做隐式兜底。缺材料时按推荐顺位（负责人定案：通用材料最优先）：① `fill_generic` 默认已开（无需操作）→ ② 授权 `farm_dungeon=true`（快速刷取，报预计消耗并获同意）→ ③ 判停后手动刷——花萼材料切到晋阶画面跑 `FarmLightConeMaterialOp`（跳转手动刷，times = 缺口 ÷ 单次产量估算），周本材料直接 `run_operation(ChallengeEchoOfWarByName)`（起跑画面任意，配队查周本计划）→ 回续升级 → ④ 当期都不方便时挂一条龙开拓力计划（操作见 `../mechanics/character-enhancement.md` §4——**改的是用户常驻计划，改前必问用户**），下次一条龙批量完成。②③ 启用前报预计消耗并获用户同意。
- **换光锥**（配装调整，如刷材料前换辅助光锥）：`EquipLightConeOp(ctx, cone_name='光锥全名')`（前置 = 光锥 TAB，同款四步编排的终点页）。识别用光锥图标模板 SIFT 落格投票定位（卡片上无光锥名，名字只在选中后右侧对比栏可读）；已装备同名光锥幂等成功。⚠️ 替换即时生效无确认弹窗；连续换装时列表重排动画期会漏扫（失败重跑一次即愈，或两次之间留数秒）。
- **换遗器**（配装调整）：`EquipRelicOp(ctx, piece_name='遗器单件名')`（前置 = 遗器着装页；单件名由套装+部位唯一确定，如「先驱的绝热围壳」= 死水头部）。点目标遗器位直达该部位替换界面（部位筛选已锁），部件图模板 SIFT 落格投票定位，选卡后点「替换」即装备（已装备同名件幂等成功）。⚠️ ①替换即时生效且会从其他角色身上换下；②替换后停在替换界面不回着装页（与光锥不同）；③**深排边界**：列表按「遗器建议排序」（对当前角色的推荐度），目标套装非推荐套装时可能排几十屏之外、滚动预算（12 屏）扫不到而显式失败 —— 常用套装件（角色现穿套装的副本件）排前排可正常定位，冷门套装件建议用户先在 GUI 手动定位或等筛选功能。
- 未来可在 MCP 层封装的便捷能力（建议，按价值排序）：
  - 一键「选角色+升级」组合 op：前置链 + 指定养成线封装为单次调用，收敛调用方的编排负担与前置踩错面。
  - 遗器强化 op：入口链已摸底（见遗器节），待实机验证场景（狗粮库存非空或用户明示消耗授权）后落地。
  - 材料缺口自动闭环：读游戏内材料库存 → 自动算缺口与次数 → `FarmLightConeMaterialOp` 刷满 → 回续升级（现在次数仍由调用方估算；单次产量表未固化）。

## 跃迁画面与普通卡池（常驻跃迁）入口【实测 2026-11-15】

- **入口**：大世界右上角「跃迁」进入。
- **找普通卡池**：跃迁画面左侧一列卡池页签，活动池排在前（数量随版本变化）；**常驻跃迁（普通卡池）通常在最后一个页签**——池名「群星跃迁」，页签带「常驻跃迁」标签，永久开启。
