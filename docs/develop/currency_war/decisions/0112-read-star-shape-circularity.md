# 0112 read_star 形状过滤(area100 + 圆度>0.55;治装饰误判,对新角色鲁棒)

Status: accepted
Date: 2026-08-12

## Context
read_star(HSV 数金星)对**立绘金色装饰**误判:立绘库(无金星)6/71 立绘读 ≥2(灵砂/赛飞儿/阿格莱雅等);
实战丹恒1星读2(售价+2=1星cost 实机否证)。装饰被当金星 → star_achievement/acq/star hook 全污染。

用户(2026-08-12)给验证法:立绘库跑 read_star(图库无金星,该全1)→ 暴露装饰误判(6/71)。
根因:read_star 只用 HSV+位置+面积过滤颜色/位置,**装饰同色同位**(丹恒装饰在底部中央 cx0.16-0.5)。

## Decision Drivers
- 金星 vs 装饰的本质区别 = **形状(五角星)**,非颜色/位置/面积。
- 对新角色鲁棒:金星五角星形状固定,装饰各异 → 形状过滤一劳永逸(area 装饰重叠解决不了)。

## Considered Options

### A. area 下限 40→100 —— 部分修(6→3)
金星实心五角星 area 155-230,小装饰 <80。下限100 排小装饰(丹恒装饰46、灵砂93 等)。
但**大装饰 area 重叠金星**(灵砂448/559、赛飞儿108、阿格莱雅285/609)→ 3 个仍误。area 分不开。

### B. 圆度 >0.55(findContours + 4πA/P²)—— **选定,治本**
实测(2026-08-12):金星实心五角星圆度 **0.57-0.65**(后排-3=0.59/备战栏-5=0.65/备战栏-6=0.57);
装饰细长/不规则 **<0.55**(灵砂0.07-0.15、赛飞儿0.04-0.54、阿格莱雅0.03-0.27)。
圆度0.55 分界:金星留,装饰排(含赛飞儿0.54)。**立绘库 6→3→0 误判,真金星全留**。
形状过滤对新角色鲁棒(金星五角星形状固定,装饰各异)。

### C. matchShapes 金星模板(Hu 矩)
最鲁棒(形状匹配),但要金星模板轮廓 + 重构。圆度(B)已 0 误判,无需 C 的复杂度。

## Decision
选 B,叠加 A 的 area100(双重保险):read_star = findContours + 过滤(cy>0.74h 底部 + cx 中央 + area 100-600
+ **圆度>0.55**。connectedComponents→findContours(取轮廓算圆度/moments 中心)。

## Consequences
- 立绘库 6/71 装饰误判 → **0/71**;丹恒1星读2 → 1星(实机售价+2 一致)。
- read_star 准 → hook(检测2星停机不再误触发)+ _reconcile(tracked star 实机准)+ star_achievement/acq 全受益。
- 对新角色鲁棒(金星五角星形状固定);圆度阈 0.55 留余地(金星0.57-0.65),2/3星金星同形状(并排)同圆度。
- 300 测试过。圆度阈待多样本(2星并排 / 不同位置金星)校准,但立绘库 0 误判 + 实战金星准已证。
- **迭代(0113,2026-08-12)**:纯 circ>0.55 后发现实战金星 circ 实测 0.52-0.65(备战栏-2 a142 circ0.52
  被误漏)→ 改三联判据(a>120 + circ>0.45 + aspect0.85-1.15)替纯 circ0.55,立绘库仍 0 误判 + 实战金星全过。
