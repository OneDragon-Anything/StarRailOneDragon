## 一、起草说明(参数推导链)

1. **σ_win 估计器**:定案 = 1.4826×MAD(主)+ 去极值均值 sd(备选,并列报告不参与触发)。选 MAD 的推导:W860 角度三实测含离群窗 sd=4.14 vs 去低洼 2.19——普通 sd 被单窗主导,「噪声带由一个窗背书」是 W860 自批之病;MAD breakdown point=50%,单离群窗免疫;1.4826 是正态一致性常数。校准期回算(附录 A-1):幸存均值 MAD σ=1.19(备选 0.67)、列车锁线 MAD σ=7.41(备选 4.11)。
2. **最小窗数 = 8**:MAD 在 n=6 时仅由半样本锚定(校准期 MAD=0.80 只由 4 个中间值的 2 个决定),抽样不稳;8 窗使 MAD 锚定 ≥5 窗偏差。当前 6 窗 → **数据积累期,再积 2 窗后启用**;不足期间只记值不触发。
3. **阈值映射**:R1 连续两窗越「带沿 ±1σ」、R2 单窗越「带沿 ±2.5σ」。推导:两窗均值噪声 sd=σ/√2,R1 取 1σ 等效均值 z≈1.41(p≈0.16),有意宽松——规则本职是少触发、触发必有戏,治「常触发→常豁免」旧病;R2 取 2.5σ 单窗 p≈0.0124、8 窗滚动族错误率 ≈9.4%,对照 W860 草案的 2σ(p≈0.046、族错误率 ≈31%)过于易响,v1.0 定 2.5。正态近似边界已声明,窗数 ≥8 后用实测分位数替换走修订程序。
4. **锚带再校准裁决序**:分支 A(零成本分段重估,按 W803 前/W803 后/W834 后/W852 后纪元)先做 → 分段后仍系统性越带(用当前纪元窗重估带沿仍满足 R1/R2)才升级分支 B(重放链逐 commit 定位);离线期 B 不可跑 = 明示挂账,禁用 A 冒充 B、禁回退定性豁免。
5. **重放判据**:决策序列(actions/v3_intention/决策金流)逐位一致 = 主判据;显式剥离 W842 实锤的进程哈希随机化开局装备名差异(叶子路径枚举、零行为影响)+ run_id 归一 + schema 默认关新字段;剥离清单受冻结约束,新增 = 修订;主张 pin HEAD。禁「重放差分布测噪声」方向性错误(W860 角度四纠正,写入条款)。
6. **列车份额**:份额 = 列车线数 ÷ 总锁线节点数,次级观察量不独立触发;校准期两点 W844≈58.8%、W858=51.0%。
7. **修订规则**:显式声明 + 版本号 + 理由 + 追加式历史表;触发后处置**当场三选一**(再议/升级/维持,三选一外措辞含「噪声置信」标签废止)。
