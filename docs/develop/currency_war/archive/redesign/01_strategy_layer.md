## 2. 决策问题的形式刻画

每备战期(节点前),状态 S 下从动作空间 A 选一个可负担子集:

- **买**:对商店每槽卡 c,买/不买(含满栏合成例外语义);
- **卖**:对板面/备战每单位,卖/不卖;
- **刷**:刷新(2 金/次,可重复);
- **级**:买经验(**[41] 整买纪律:只以补齐批形态发生**——批 k*=⌈max(0, need−xp_cur−4n̄)/4⌉ 次,p48 整买引理;血本位语境单价 6 血、按 [40]② 安全带检查);
- **锁**:锁商店(跨节点保牌);
- **装备**:穿戴/合成/转移/回收/工具使用;
- **部署**:上场/下场/换位/换排(开拓者形态切换)。

局内事件决策点:**全量进第一版**(用户裁定 2026-08-31:必须全部,不能漏,避免候选推倒重来)——完整目录与机制见 §4.9。

**统一决策程序**(提案,替代旧多仲裁器):每个动作 a 有金当量价值 V(a)(由 §4 各机器按动作类型给出)与成本 C(a);预算与息线约束(§4.4)过滤;可负担动作按 V−C 与优先序执行;「空集」合法(不动——此表述出自 README §4 防回流清单的设计语言,非口述原文)。【已裁定】[36] 未定型期决策单位=件、无默认方向。

### 4.10 机制突变层(改机制的投资策略/环境)【已裁定方向(用户 2026-08-31:设计必须考虑改变游戏机制的投资策略环境);框架=提案待审】

**原则**:决策机器**禁止直接读基础机制事实**——一切机制输入经「基础值 ∘ 已激活突变」解析后消费(resolved input);突变登记=知识层注册表 `INVEST_MUTATIONS`(§5)。**登记三分态**:resolved(可解析)/abandoned(**已裁定放弃建模**——invest_effects §5:desc 无数值一律放弃、不实机查;保可见性,不进 resolved input)/未登记(=知识缺口,采集后入表,不静默忽略)。

**解析语义结构**:每突变登记为(操作数,**合成律**[min/max/add/互斥],**状态依赖**[计数器/条件],**时效**[永久/计数窗/条件移除]);同操作数多突变按合成律合成(例:成长的快乐 −1 + 商业间谍 −1 = add → 经验单价 4→2;长线利好=计数器状态依赖;市场干预=计数窗时效;E2 刷新顶替=条件移除语义,具体规则实机核);**互斥型=登记位声明**(首个生效,后续登记为 suppressed,实机核);**异构操作合成序=按操作数分层**(override 类先于 multiply 类,层内按注册表登记序——例:市场干预 override 概率表 × 轮岗 multiply 概率表,先 override 后 multiply);**未登记态的运行时检出**:resolved 读到未登记突变时保守降级(按基础值消费+告警入日志,不静默);消费点读**合成后的单一 resolved 值**,禁止各机器自选合成方式。

**多源声明**:突变源不止投资卡——池构成族中的银狼升费是**角色固有技能**(economy §8),任务奖励亦可改状态;`INVEST_MUTATIONS` 为**多源效果突变登记**(投资卡/角色技能/任务奖励),辖域不限于投资。
