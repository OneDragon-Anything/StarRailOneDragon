## 门① 内部推导:过(带 2 处措辞级修正)

逐项核:

1. **DP 递推结构**:状态 = owned 向量(Π(n_k+1) 封顶)、转移 = 多项式(槽→费档)× 各档多元超几何(档→卡)× 增量封顶不截断分布。逐步核对 `p38_check.py` 的 `shop_transition`/`exact_dp`:multi-index 枚举系数(∏p^m × 多项式系数)正确、归一化断言在跑(实测全部通过)、封顶质量并入不截断正确、池分类(各件剩余合格副本/非目标)与 A1/A3 假设逐字对应。**推导与实现一致,无结构错误**。
2. **单槽命中公式(①③层)**:q_k = p(L,c) × (|Q∩c|·a_c − j_k)/(v_c·a_c − taken_c),分母 = 同费剩余总副本——与 `_refresh_dist` 的 total = v·a − j − c 同口径。P5 锚点「c=3@L7 单卡 0.1357」**亲跑精确复现**:`_refresh_dist(0.40, 14, 9, 0, 1, 0)` → 1−P(0) = 0.135706…,四位数全对。
3. **②层独立性论证**:负关联分层声明(K=2 可证/K≥3 plausible+数值、衰减情形无定理)是**如实降格**而非过度主张;「独立乘积非严格单侧界、双侧小误差」由表值支撑(亲跑复现全表 ≤0.005;压力用例含微负号)。高密度外推带(探针 K≥4/K=5 同费,边际乘积最大 −1.27pp)在结论强度表已单独声明(~1.3pp 保守向),亲跑探针复现 −0.0127 ✓。
4. **31金→逐位面常数换轨(已裁项复核)**:⑤层 A5 现文 = 「interest 按逐位面常数 {P1:27, P2:35, P3:45}(中位口径)折算 + P1 现实带 18-30 + 旧常数 31=P1 上沿限定 + 精算走⑤层金位递推」——换轨本体已执行、金位递推与 p47 规范递推同构(p47 L208 逐项核对「一致」)。**但「中位口径」标签失真**:P47_VALIDATION 时间面风险一已实证——自由策略位面息流 P1 约 16-27、P2 约 13-23/局,35/45 是**守 50 理想化上界**(满息进场且全程守 50 才可达),不是实证中位;p38 已按 P1 带宽限定但 P2/P3 仍挂「中位」二字,方向 = 消费方高估息收入 → B 偏大 → 概率乐观(与 A5 已声明方向一致,但标签会误导)。**判:换轨正确、标签需修**。
5. **O6 轮岗期望口径混合(逐步核 + 独立数值探针)**:声明「闭式不感知轮岗、混合方向非对称、二阶量级」。本验证自建探针(0.8 基线 + 0.2 均匀掷翻倍档,用注册表 `rotation_probs` 原函数,精确逐店混合卷积 vs 基线二项闭式):4 场景偏差 −0.47 ~ +0.30pp——**量级「二阶」成立(全部 <0.5pp)、「混合方向非对称」成立;但次级断言「二项尾近似保均 → 略偏保守」方向非一致**(4 例中 3 例偏乐观)。量级结论不受影响,方向措辞应弱化为「方向不定、量级 <0.5pp」。
6. **单调性构造**:逐条核(二项尾对 N 单调、K↑ 乘 <1 因子、n_k↑ 尾降、等级条件化 + 预算耦合声明)——数学上全部成立,耦合路径(K↑ 同时压 B)已如实声明。✓
7. **A1 措辞过强(小)**:「槽间档独立有实机概率条支撑」——概率条只给**单槽边际分布**(每行和=100%),边际表不能支撑**槽间独立**;独立是假设,失效方式栏虽已覆盖(同档共现低估、二阶小),但「有支撑」三字应改为「概率条支撑边际,槽间独立为假设」。
