# 用户人玩节奏(口述权威 · 持续追加的唯一入口)

> **性质**:A8 实战玩家(用户)对人怎么打货币战争的口述,是全部策略校准的**最高权威基准**(权威序见 [README](README.md);攻略/社区共识与口述冲突时以口述为准)。
> **条目编号 1-16 为稳定 ID**(历史文档/ADR 以「§7-N」引用,迁移后等价于本文件条 N);新口述按主题归入分组、续号追加。
> 版本基准:V4.4。
> ⚠️ **改任何策略代码前必读本文件全文**(用户 2026-08-20 定调:后续每次改策略之前,
> 都应整体考虑这里记录的原则,而不是逐条打补丁)。

## 开局与奖励节点

- **[1]** 开场 2 个奖励节点基本什么都不做;在不影响吃息的基础上多买牌,方便后续刷出想要的角色。r1/r2 固定奖励节点**不 D 牌**(奖励必过,刷新纯烧金);**保息前提下多买 1星/2星 = 压缩牌库**,池子小了后续轮目标卡浓度升高,更易凑出过渡阵容;过渡阵容**能找到就找、没有也不强求**(可卖 1-2 轮血换经济积累)。
- **[15]** r1/r2 压缩牌库是**全局供给策略**不是本位战力投资:买的 1/2 星既是后续 3合1 的副本素材,也把公共池的噪声牌抽走——自己不买,下轮商店还是这些牌占位。
- **[16]** 必胜节点(奖励)语义:无战斗、连胜白拿、回血白吃——①刷牌的战斗向理由全关(无血可扣、维持连胜不靠刷新);②升级零战损(本轮无战斗成本,人玩倾向在奖励节点买经验);③节点序列每局随机,r1/r2 固定 + 序列内还会再出,以备战顶部节点条为准。

## 经济与利息

- **[28] 位面1 节奏基准:50 金通关 P1**(2026-08-23 看局70 口述,最高权威):
  进 P2 时应带 ~50 金——P1 各轮须守息(息基不因战斗节点破);局70 病例实证:
  r7 金26 没守住→r9 boss 前只剩 5(升级+买牌花光)→赢了 boss 但进 P2 身无分文,
  「打过了也没经济通关」。**boss 轮的高消费必须以「满息结余」为前提**,
  不是把息基花掉凑阵容——[18] 死亡螺旋的入口形态。
- **[29] 定阵容前不浪费装备合成/穿着**(2026-08-23 看局70 口述):过渡期把
  组件(量产型装甲/光能电池类)穿给过渡角色 = 锁死后续合成路线+浪费转移成本;
  与 [9]「不是有装备就用」同源强化:[24] 的装备转移是**过渡期关键装备**(输出装)
  穿上场 5 人,不是**合成组件**提前消耗——组件在最终阵容确定前留在物品栏。

- **[2]** 前期可以**卖血**;**少刷新商店**(刷新 2 金/次),**优先凑息(50 金)**;但也要买**过渡阵容**。
- **[11]** 金 <20(1 息档内)买过渡件**不损息还压缩牌库**——攒息不该拦无损购买。
- **[12]** 连 50 金都没凑到**不急着升级**——追级的前提是息引擎已立;前期收入撑不起边吃息边追级。
- **[6]** 中期凑阵容为主;**偶尔可掉到 40/30 金少要点息**——前提是商店全是想要的;正常情况优先 50 金。
- **[17]** **50金息律,节点无关**(2026-08-20 定调,三次强调):利息 5金/轮 @50 封顶 →
  金 ≤50 攒息;**>50 的每一分都没有存的意义,该升级升级、该买牌买牌、该D牌D牌** ——
  与节点无关,任何位面任何节点满息即花。不存在「金在位面内有保质期」这类二阶概念;
  boss/1-7/1-9 的集中消费只是「到时自然满息 + 花的边际价值高」,不是金本身的属性。
  (攻略 plaza #145「资金超50时,用多余金币升级」同口径;实证 bot 病例:旧 _boss_spend
  把花光通道锁在 boss → 平时 60-70 金闲置。)
- **[18]** **hp 低不是 ALL IN 触发,是运营质量报警**(2026-08-20 定性):血低于安全线
  = 前面的破息决策已经做错了;此时花光挺过这个节点 = 给前面的策略失败擦屁股,
  **断息之后经济可能再也无法支撑完成整局**(死亡螺旋:血低→花光→息断→板半成型→
  又掉血→又花光)。「卖血不低于40」是攻略的运营质量线,没有标准数值,也不是急救触发。
  **目标是长期通关,不是苟住多少个节点**;血低的正确响应 = 最小必要支出止损 +
  息引擎尽量保住;真 ALL IN 只属于位面末最后一战(赢了带血/板进下位面,不存在
  后续经济问题)。
- **[19]** **连胜 vs 保息是有意识的抉择**(2026-08-20 讨论,攻略专题实证):高难节点
  (1-7 遭遇/1-9 boss)前,争取连胜(多花钱凑阵容,可能破 50 少息)与接受扣血断连
  (保息)都是合法选项;裁决变量 = ①连胜是否在手(已连胜值得花保,未连胜不为单场破息)
  ②血量安全边际 ③来牌顺不顺(牌顺小搜争连,不顺果断攒)。(攻略 #205「如果连胜就
  多D几个,利息保3」/#151「卡满50利息,大不了先输着先」/#46/#62 三态谱。)

## 等级与搜牌

- **[3]** 50 息后:主要看**自己核心在几级刷新概率大**;到这个等级就刷新商店买核心;**没到就少刷新、多买经验**。
- **[7]** 不无脑停留概率最高等级:峰值级概率最高,但高一档也没低太多、还提高更高费刷新 → 取决于整个阵容想要的人;原则 = 在「费用段带」内权衡(峰值级查 `cw_shop_odds.REFRESH_PROB`)。

## 阵容与过渡

- **[4]** 核心不只是输出:一套阵容输出和辅助都不可少,中途也要买辅助;辅助 **2 星就够、1 星也没所谓**,能 3 星更好(可囤一下冲 3 星)。
- **[5]** 输出核心若是 4/5 费(需很高等级才买得到)→ **必须有低费输出保证过渡**。
- **[8]** 后期**必须阵容羁绊凑多人效果**才能通关,**散装不可能通关**。
- **[13]** **过渡阵容 lv5-6 + 羁绊凑够 + 过渡核心 2 星 ≈ 能过位面 1**——过渡成型即可停手攒息,不必追高等级。
- **[10]** comp 选型:想先通关,选**当前版本最容易通关的阵容**(评级查 `cw_comps.COMP_LIBRARY` 的 strength/form_difficulty)。
- **[20]** **过渡阵容是有羁绊配方的,不是高频角色乱混**(2026-08-20 定调):P1 玩的是
  **成型的过渡阵容**(如 列车+仙舟),框架就是 P1 的通关阵容本身——成型、能赢、每场
  加深,不是垫脚待换的临时板。配方有结构(3仙舟+2DOT 基础,渐进升级 → +2列车2护盾
  → 4列车保送 P2 等;官方 plaza 1080 帖 Early 阵容统计实证),变体按来牌选
  (2DOT+2贝 / 2DOT+2学者 / 3狼2dot),不随机散买。
- **[21]** **final 件「买而不上」**(2026-08-20 定性,plaza 数据+攻略实证):P1 的问题
  不是「凑 final」,是「让 final 阵容上了场却取不了胜利」——final 核心可以买(囤
  bench,贯穿件/枢纽件买了就是开局),但**不该早上场**;上场等条件窗口:核心等级窗
  (姬子=7级)、羁绊齐窗(白厄=4击破齐)、变阵点窗(万敌=1-9)。官方 API 的位面阵容
- **[22]** **有用就先囤,囤多才排优先级;弃购的真实代价=再遇窗口**(2026-08-23 定调):
  ① 5费出现率最低、**买了再卖不损金**(1星卖出=cost 全额退;1费各星净0)——「觉得
  可能有用,先买囤着应该不会错」;② 唯一稀缺 = bench 槽,**囤得太多(>2-3 张)才需
  要考虑优先级**;③ 弃购期望账:不买这张,再遇它期望要 1/q 轮(q=单店出现率)——
  低费 7-15 轮自然回,**5费在 7-8 级=60-180 轮(整局可能不再遇)/急 D 补救 120-360
  金**;等级升到位(9-10级)窗口才收窄到 8-18 轮。**稀有度越高越该囤**;收集窗口
  (P2 末才收瓦尔特类)不是省钱机制——弃购省的金 < 再遇的期望损失。
  ④ **但要考虑凑息**(用户同日补点):囤的前提是金在息线上方或该笔不破息——
  50 金满息=5金/轮,破息囤件的息差损失要计入第一笔账(与[11][17]联动:
  <20 的 1 息档内随买,>50 随买,贴息线才算账)。**货币战争的玩法本质
  =有限经济内发挥最大价值,经济期望是策略评审的统一标尺**。
  本就按阶段分开建模(Early 与 Final 是两套阵容,Early 平均 3.66-5 人,大量 Early 高频
  角色在 Final 被清场)——P1 的板 = 过渡框架,final 在 bench 等窗口。
- **[22]** **升级为阵容服务**(2026-08-20,演示局 r9 还原):刷出框架阵营单位(开拓者=
  列车)→ 花金升级 → 让它上场增加列车羁绊人数——升级的触发时机包含「有框架单位
  等着上场」(人口位价值),不是独立的追级目标;升级由「要找谁」驱动(carry 费用档
  定等级:1费C 5级/绯英6级/姬子·启行7级),不是固定曲线。
- **[23]** **终局线由贯穿件锁定**(2026-08-20):final 不是预设目标,「拿到什么贯穿件
  (开拓者→列车)走什么线」——被锁定的选择,不是 pivot;P1 不靠分数涌现挑线
  (分数涌现换线在未成型板上是噪声,四线摇摆全输实证)。

## 装备

- **[9]** 装备有策略:部分角色要特定装备才发挥效果,**不是有装备就用**;优先保留输出的装备,阵容有辅助核心装备的次之,有盈余才给其他角色。
- **[14]** 星期日是通用辅助:阵容有缺口暂时用着没所谓——低星低价不挑阵容的填充件是缺位时的最优,成型后自然替换(target/off-target 之外的第三类)。
- **[24]** **装备转移是常态操作**(2026-08-20,攻略实证 #9「龙丹装备转给火花」/#4
  「给景元的装备先让银枝用」):过渡期关键装备穿在当前上场 5 人(未来迁给核心只付
  一次性拆卸成本),核心到场且有空槽 → 迁移;不是「穿了就定终身」。

## 战斗与掉血(机制口述)

- **[27]** **掉血=战斗失败,掉血量取决于敌方剩余血量**(2026-08-22 口述,最高权威;
  调研 bc79676b 与社区/本地存档三方互证,公式结构定谳):
  **扣血 = 节点位置基础扣 B(位面,节点序,难度) + 伤害未达标罚 P(需求伤害,实际伤害)**;
  胜利恒 +2(「挑战进度」奖励,跨 5 节点类型实测恒定)。
  - B 随节点位置递增(必修一「节点越后扣越多」;P3 boss B=35[好游快爆];
    P2r1 实测 B≈10;普通战斗 -7~-13 ≈ B7-10+小额 P);
  - **P ∝ 敌方剩余血量**——「伤害未达标」与口述「敌剩余越多掉越多」是同一机制
    两面:最低伤害需求≈敌总血量,我方输出=达标量;局48 boss -3(核心全 2★+装备
    集中)≈ 清空敌血 → 伤害达标 → 只付位置基础扣;
  - 失败判定 = 行动值耗尽未清场(**含超时**——PTT 实证「时间到没死人也扣血」);
    非 TFT 式「存活单位数×星级」公式(检索未发现该形式);
  - 真值采集点 = **结算屏 OCR 三项拆解**(挑战进度±N/基础伤害-X/未完成进度伤害-Y;
    economy.md:111 已有先例),比间接拟合可靠;
  - 策略含义:每场都是质量战——中期投资(3合1 升星/装备集中)在**全节点持续
    变现**(把未达标罚压到 0),非只 boss 决战才值钱。

## 攻略学习方法论(元原则)

- **[25]** **逐篇精读攻略,别以偏概全**(2026-08-20 定调):官方 plaza API 的攻略带作者
  文本描述(运营思路),**必须逐个逐个看,不能偷懒**——单个攻略的打法(如「1-8 全卖
  过渡」)不能当通用规则引用,要看全部攻略后才提炼;每看一篇记录一篇(标注攻略 id/
  作者/like 数),这是学习这个玩法最好的办法。(产出:`.debug/temp/currency_war/
  plaza/reading_notes/`,663 帖精读笔记 + 专题检索;提炼结论进 plaza_methodology.md。)
- **[26]** **以官方 API 的阶段阵容数据为准**(2026-08-20):plaza 帖的
  `tourn_detail.role_stages` 按阶段(Early/Middle/Final)分开记录阵容——「P1 阵容与
  P2/P3 是分开的不同阵容」是游戏本身的建模,不是玩家习惯;策略设计应对齐这个阶段
  结构(P1 过渡框架 / Middle 半终局 / Final 终局,见 plaza_methodology M3-M5)。
