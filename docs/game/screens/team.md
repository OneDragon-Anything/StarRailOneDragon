# 队伍(team)

编队界面。配置出战队伍(选角色入队 / 快速编队 / 借好友支援角色)。**不锁光标**(`pc_alt=false`)。通用系统,不必先搜玩法。

## 何时出现 + 状态流转

- **入口**:菜单点「编队」(phone_menu_const.TEAM_SETUP)→ 队伍画面;战前(进战斗前)也会进编队。
- **出口**(动作 → 下一态):
  - 角色列表选角色 → 入队 → 替换队伍位(停留队伍画面)。
  - 点「快速编队」→ 快速选择队伍配置。
  - 点「支援」(SUPPORT_BTN)→ 支援态(标题"支援",选好友角色入支援位)→ 选完回队伍态。
  - 按钮-关闭 / ESC → 回菜单(或战前则进战斗)。

## 识别特征(稳定锚点)

- **左上角标题-队伍**(text "队伍",pc_rect 99,37-214,59):队伍态标题锚点(analyze 命中 conf 0.998)。
- **SUPPORT_TITLE**(text "支援",同 pc_rect 99,37-214,59):支援态标题(与队伍标题同位,态切换时替换)。
- `pc_alt=false`。
- 易变:角色名 / 等级 / 命途(欢愉/存护/…)、队伍编号——动态。
