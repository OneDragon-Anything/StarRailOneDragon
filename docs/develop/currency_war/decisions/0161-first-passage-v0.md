# ADR-0161 目标函数层 v0(首达生存概率 + 风险姿态三区律;18 号)

## Status

Accepted(2026-08-16;K1 已过/K2 方向已验;V2 并轨升级[分布 DP 转移/D 牌赌局化]与消费端接线待后续)

## Context

18 号提案诊断:全栈一致用「均值」计价(02 ΔE[生存]/04 血低→悲观分位/ADR-0155 掉血线性插值),期望泛函在劣势局**方向性选错**——教学校验例:两线同 E[掉血]=20,HP=25 该选稳线 A、HP=15 该赌尾线 B,均值计价完全不区分,「血低→悲观」在必死边缘恰好杀死唯一活路(右尾)。姿态(保守/冒进)全部手写门(DEAD_HP=20 三门/ADR-0141 HP<40 分档/danger_d 占位)。

## Decision Drivers

1. **K0 止损门实测通过**(本仓 telemetry 3716 决策点):plane1 掉血 CV=0.62(n=203)/plane2 CV=0.40(n=35)——方差结构显著(非近确定,均值退化为点质量的反例不成立);决策点 hp 分布 0-39 占 43%(三区人群真实存在)。
2. ADR-0155 自己在打均值代偿补丁(hp 残值权重 0.03/线性插值/遍历序 tie-break)——提案"均值近似在自己生成补丁塔"的考古论据实锤。
3. λ_hp 峰形是可检验的形状断言:所有"血低→更保守"规则隐含单调递增假设,与峰形在第三区直接矛盾。

## Considered Options

- **维持均值 + 手写门**:拒绝 —— K0 证明显著方差下均值在劣势局选错方向。
- **全量 V2(分布 DP 转移矩阵/D 牌 Bernoulli/残值删除)**:并轨 ADR-0155 轨道做,本轮先立出口 API(提案自身增量路径)。
- **v0 = 出口 API 纯函数**(采纳):P(win)/λ_hp/posture 三件套,消费端(02 计价乘子/05 触发量/手写门退役)后续逐个接。

## Decision

1. 新增 `cw_first_passage.py`(纯函数):
   - `first_passage_win(board_tier, hp, nodes_left)`:掉血三点离散分布(μ×CV 0.5 先验)卷积 → 生存首达概率(半格 2.5 步长数值积);
   - `p_win_lambda`:`P(win|hp+1) − P(win|hp)`(λ_hp 影子价格采样);
   - `risk_posture`:三区律(**边界由 λ_hp 与 P(win) 联合解出,非手写 hp 阈值**——弱板长程下必死边缘的 hp 绝对值可高达 60+,漂移把屏障推远,正是固定 DEAD_HP=20 要被替代的证据);`posture_guidance` 三区姿态文案(对应散落手写门的统一语义)。
2. **K1 判据过**(测试锁定):同均值异方差选择翻转(gambler's ruin 校验例)/P(win) 单调性/λ_hp 峰形(峰 > 远离区 且 峰 > 漂移深处——**非单调**断言)/三区划分/退化例。
3. **K2 方向验证**:强板(μ=0.8)9 节点全程盈余(P(win)=1.00)——手写 HP<40 分档对强板确属过度反应;弱板 hp=120 处临界(P=0.41)、hp≤60 必死边缘(P≈0)——三区边界随 (μ, hp, nodes) 联合移动。量级对拍(±一档)待 K3 模拟器。

## Consequences

- V2 并轨待办(提案主张三):cw_horizon 掉血插件换实测桶分布(PerformanceTracker 按 (板强档, 节点类型) 聚桶)、D 牌赌局化(Bernoulli by plaza 星率 0.87/0.58/0.37)、hp 残值补丁删除 —— 全离线,K3(500 局 A/B 劣势桶胜率)随后。
- 消费端接线:is_run_dead 三门/ADR-0141/0143 分档/danger_d 退役为对拍锚(各独立灰度);05 号死局触发量 P(win) 有了计算器。
- 锁血机制定案(is_run_dead docstring:阶段 4 实机确认)只改转移矩阵不动框架。
- 提案原文删档;决策单一源移本 ADR。
