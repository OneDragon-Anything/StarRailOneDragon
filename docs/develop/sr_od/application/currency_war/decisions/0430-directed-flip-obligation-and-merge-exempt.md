# ADR-0430:FLIP 义务预算消费定向化与合成豁免完备式——W393 攻击的两处收紧

> **引用勘误(2026-09-04 ADR 存量 review)**:`.debug/` 归档 → 本目录(decisions/)同名 ADR。文内出现处按此对照读取。

- 状态:accepted(编排者裁决;攻击来源 `.debug/temp/currency_war/w393_family_attack2/ATTACK.md` §A1.2/§A4)

## Context(为什么)

W393 全集攻击在 FLIP/W380/W387 修复链上找到两处「放行面宽于可证明 Δp>0」的收紧点:

1. **成型帧泄息的期望收益未论证**:W391 重排把末窗投影臂改为相位无关后,成型(phase≠FORM)帧也承接泄息义务——但该义务的账面论证(§A1.2)只对「保命」成立;成型帧泄息的期望收益(战力已成型,泄息金换战力的边际打折)从未论证。未论证的义务不应允许无差别消费(尤其盲刷)。
2. **合成豁免不完备**(§A4):`not c.merge` 把「会发生合成」当「Δp≥1」——板满且合成 2★ 落 bench 无位可上时 Δp_board=0,按自家符号证明应删的支出被放行;C1 段同款。

## Decision(逐条)

### 1. 义务预算消费定向化(R1 最小版)

FLIP 命中帧在「末窗投影臂 ∧ phase≠FORM(成型帧)」时,`ReleaseDirective` 携带 `directed_only=True`:`authorize_release_refresh` 对该帧**拒盲刷**(店内无上名集件时刷新不放行),找件与升级放行。

- 默认构造(`directed_only=False, find_ok=True`)与既有调用零漂移;
- 第三路径(slot 守卫注入)刻意**不辖**定向化——定向化会在第三路径重新造出「泄息通道静默」面(W378 断点一同型风险)。

### 2. 合成豁免完备式(R4)

新增 `_deploy_free_after_merge`:全场域合成(cw_state._merge_bench,载体=场上优先)下,腾出的上阵位只来自场上同名同星份被消——场上份≥2 净腾 1 位,≤1 净腾 0(2★ 落 bench 无位可上)。濒死带与 C1 两处删除判据统一收紧为:

```
free≥1 或(c.merge 且 合成后腾位≥1)→ 放行;否则删
```

对称义务:滤网只删可证明 Δp=0 的支出,**只放行可证明 Δp>0 的**。EV 层联采的「卖场上件腾位」路径滤网层面不判(数据依赖,留给评分层)。

## Consequences

- **正面**:成型帧泄息从「无账义务」降为「定向消费」;两处豁免恢复「删除集⟹可证明零期望」的谓词性质;默认构造零漂移。
- **负面/边界**:定向化的「店内名集件存在性」判定依赖创建帧快照,名集单一源(filters._refreshable_names)演进时需同步;「卖场上件腾位」路径未判,EV 层定价仍可能高于滤网判定(已知不对称,留 EV 联采演进)。
- **挂账**:成型帧泄息期望收益的完整账面论证(需 Δp(X) 实测,W382 数据缺口①同源);hp_trusted 下行误读守卫(R2,设计级,独立演进)。
