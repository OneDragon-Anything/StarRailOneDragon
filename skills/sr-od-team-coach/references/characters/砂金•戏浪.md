# 砂金•戏浪（量子·欢愉·5星）

> 按 V4.7 期（2026-11）官方文本撰写。热意驱动 AoE 副C/辅助：全队暴伤光环 + 无视防御 + 欢愉度光环。
> 与经典砂金（虚数·存护）是并存独立角色；官方文本中无护盾/治疗机制——**不是生存位**（社区早前「欢愉生存位」的说法与官方文本不符，已按文本修正）。

## 定位

欢愉副C/辅助（AoE 混伤 + 团队增益）。体系骨架见 [欢愉队](../teams/欢愉队.md)。

## 伤害模型

- **混伤**：普攻/战技/终结技为攻击力倍率；持好活时附量子属性欢愉伤害 rider（战技+40%/终结技+72%）【官】。
- 大招资源：标准能量 → 充能有效。

## 机制要点

- 战技：240%攻击力 AoE + 4笑点+4热意；终结技：400%攻击力 AoE + 6笑点+8热意 + 自身速度+30%（4回合）。
- 【热意】循环（天赋）：队友施放攻击后+1热意+1笑点（上限30）；**热意满10 → 立即施放固定计入20笑点的欢愉技**，且下次阿哈时刻的欢愉技强化为 All in（消耗所有热意，每点+1次21%弹射）【官】。
- 欢愉技「举杯！敬炽烈一夏」（参演编号156）：AoE 60% + 10次18%随机弹射。

## 转模行迹与转化上限

- A1「极乐派对」：**速度≥140 → 欢愉度+30%，每超1点+1%（最多计200点）**【官】→ 速度→欢愉度（140~340速线性）。
- A7「纵享惊涛」：**有其他欢愉队友 → 全队欢愉度+20%（自身额外+80%）**；独欢愉时 → 欢愉技视为追加攻击 + 队友攻击后+2好活+1笑点+**阿哈速度+25**【官】——两种分支都强绑定欢愉体系。
- A8「旧梦淘金」：队友攻击后 → **全队暴伤+48% 3回合**（最多6次，自身战技重置次数）——全队暴伤光环。

## 有效词条口径

- 主词条：躯干暴击率/暴伤；脚部**速度**；球攻击%；绳充能/攻击%。
- 副词条：速度 > 攻击% > 双暴。
- 速度三重收益：A1转模 + 终结技加速 + 行动频率。

## 绑定与互斥

- 绑定：欢愉体系（A7 光环/独欢愉分支都围绕欢愉队友）；AoE 环境价值升档。
- E4 起「战技→全队无视18%防御」使辅助价值进一步提升。

## 星魂档位

- E1：全抗穿24%；热意10/20/30三档都触发举杯（爆发频率×3）。
- E2：热意上限50；欢愉技后+4热意。
- E4：战技 → 全队无视18%防御3回合（团队乘区档）。
- E6：增笑25%；2次欢愉技后全部 All in 化。
