## 2. 必花域形式化:G_must = 10 × cap_resolved(零新自由参数)

### 2.1 界的推导(r1 应修-1/低-1/存疑-1 修订)

```
必花域(帧) ⇔ g > G_must,且该帧为有动作决策点的帧(§3.4)
G_must = 10 × cap_resolved_of_session
    ——单一源 = cw_economy.py:107 归一链(interest_cap_resolved),
    与息线 g*、arm2 守息门同源;禁内联裸 cap(cw_economy.py:100-103
    明文纪律,cap 三源归一)
    语境值(【注】):默认 5 ⇒ 50 / 息律投资 10 ⇒ 100 / 开源节流 9 ⇒ 90 /
    买断制 0 ⇒ 0(出辖,见下)
```

**零息边际论证(r1 应修-4 收窄)**:息 = min(⌊g/10⌋, cap_resolved) ⇒ g 越过 10×cap_resolved 后,**超过 G_must 的滞留金**利息收益恒为零——必花域的消费义务对象 = 该滞留段;持有滞留金边际收益为零,任何期望收益非负的消费出口对该滞留段严格占优。**两处如实收窄**:①L2 出口的 s_reserve 金门允许金位落回息帽内,跨档帧 Δ息>0 可达 ⇒ L2 不称「严格优于持有」,沿 17 号稿 N4 定性 =「净成本 ≤1 金(注册表派生界)的有界成本结构改善」,严格支配仅 Δ息=0 帧;②L3 升级收益侧零在册正账且带在册负账(P35 lv9→10 恒负/P39 L9→L10 边际 −11.4),零息论证对 L3 零覆盖——L3 的授权纯凭裁定文号(§1/§3.1-L3),不罩进本论证。

**买断制语境出辖(r1 应修-1)**:interest_cap_resolved = 0 ⇒ G_must = 0 ⇒ 「金>0 即必花」,与「息帽截断点」推导脱钩且逐帧义务荒谬 ⇒ **买断制局(cap_resolved = 0)本篇出辖**:必花域机制不适用,该语境金出口归一般判据(L1 现行面),登记 §7.4(若需专门语义须单独论证,本篇不预支)。

**息结算时点挂注(r1 存疑-1)**:息结算时点在册为 P47 🔴 待标定项;现行实现口径 = 轮初金位结算(shop 阶段花钱不影响本轮已结算利息,只影响下轮)。帧级必花域判定用 shop 帧 g,零边际性质严格说在**下一结算时点**金位上成立(中间有收入注入,方向上无害未证)——挂注如实,不以未定谳时点承重,若 P47 标定推翻时点口径,本节随勘误。

### 2.2 必花域的语义边界(防读偏;阻断-1 选(a) 后重写)

1. **必花 ≠ 乱花,但消费权优先于核算否决(r2 阻断-1 三分类同文)**:义务是「域内至少一个合法出口发生消费」(§3.2)。域内降格辖域按三分类钉死(§1 同文):(i) 资格硬闸照常零解封;(ii) fail-closed 封印(D=∅ 守卫/概率对账)照旧;(iii) 期望核算类(EV/M6 排序/dominance/息线门/U_L)一律降为排序信号——负期望出口不被 (i)(ii) 类拦时排选择序末位、仍可消费。P35/P39 负账属 (iii) 类 = 成本披露,不是否决依据。
2. **零 hp(精确表述)**:新增判据输入零 hp;L3 继承的停付线是既有 hp 族在产件,其域内让位已裁(§3.1-L3/§7.4),域外照旧。
3. **与 P35/P39 负账的关系**:负账 = 该出口的**成本披露**(随批报告),不是否决门——本条是裁定层压命题层的直接消费(r1 攻过未破面 6 确认框架合法),对抗轮一阻断-1 定谳的裁决形态,如实登记。

### 3.3 drought(供给干旱计数)——纯观测/披露维度,不作门(r1 存疑-2 重构)

- **定义**:drought streak = 连续 shop visit「无线内件在售」的结构计数;重置事件沿 ADR-0521 既有分键族(`shop_drought_reset_on_buy`/`..._on_churn_buy`),新增 `..._on_line_member_seen`(店见线内件即重置)。
- **v2 裁决(消解存疑-2 两读法困境)**:streak **不作任何门**(v1「streak≥1 即允许 L2」是空门或隐性阈值,两读法皆废)——L2 的尝试许可完全由资格门自足(必花域 ∧ 锁线 ∧ 垫件在售 ∧ 硬闸),streak 仅两用:①**分桶观测维度**(必花域帧按 streak 分桶计数,给命题批与 sim 判读供给曲线);②**L1→L2 的排序披露**(streak 长的帧 L2 提前,披露性非门)。阈值门(streak≥k 才放宽)整体删除,若命题批证得干旱-购买期望账([22]/P1 族延伸)可支撑阈值,由该命题给出。
