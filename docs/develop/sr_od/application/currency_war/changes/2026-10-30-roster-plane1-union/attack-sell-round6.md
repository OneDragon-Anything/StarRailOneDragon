# 卖出场景块无前提对抗报告（第六轮：五轮处置复核 + 意图槽实现面 + 全量一致性）

## 结论（阻断）

**阻断**：2 阻断 + 2 中 + 4 低。两个阻断项全部落在五轮处置的核心修法上：

- **S6-1**——五轮 S5-2①「已就位集连续 2 帧不增」卡死判定在 as-built 备战决策循环（**循环内零读屏、动作逻辑态自上报直写**）下无真实观察来源：部署详设七轮 D7-4 声称的「每动作一观察帧」是对 cw_screen_prep.py 两 node 结构的误读（实际 = 入口一次 heavy 观察 → 决策动作 node 内 `while True` 多动作推进，真实观察只发生在访问入口 / 策略显式发 CwActionObs / 终结动作后下次访问）。拖拽机械失效时逻辑态已按预期效果直写 → 已就位集照「增」→ 2 帧不增**永不触发** → 卡死检测空转：或按假逻辑态推进到 diff 空误清槽（级联「假完成」、bench 实际未腾），或 diff 恒非空逐帧重发挡第 1-9 步——真实出口只剩外循环 stall 防线（停机级事故，非设计内恢复）。D7-4 自己注明「零读屏形态下该判定不存在、会误判收敛」，却误认备战域非零读屏。
- **S6-2**——级联态卡死出口在总纲与详设间双源矛盾：总纲 :69「V 入黑名单 + 清槽恢复扫描（**X 走机会清单**）」vs 详设 :94 D7-5「拉黑 V 无意义（V 已卖出且卖出经虚拟重验正当）——黑名单对象 = **X 的场上件路径**……重评走**次末位**/机会清单」。黑名单对象（V vs X 路径）与收尾（直接放弃 vs 重评可能继续卖 bench 件凑金）两文档定论相反，行为差异真实；且详设侧「X 的场上件路径」自身载体形态未定义（黑名单是 S5-3 定稿的 victim 累积列表，「路径」存什么值、商店侧重评怎么消费均无解）。

裁定本身（升级凑金删除/统一获取让位/意图槽策略层实现边界/凑息豁免/等钱帧凑息照常/拦因分键）不翻案；攻击面全部落在五轮修法的载体真伪与两文档同步。

## 发现清单

### S6-1｜S5-2① 卡死判定载体失效：级联态逐帧推进依赖逻辑态直写，「已就位集连续 2 帧不增」在零读屏决策循环内无真实观察来源——详设 D7-4「每动作一观察帧」误读代码，卡死检测空转、停摆面经「判定失效」路径回魂
- 攻击点：五轮 S5-2① 修法 = 「已就位集连续 2 帧不增（拖拽未生效/未知件占槽）= 卡死 → 失败记录 + 黑名单 + 清槽恢复扫描」，其成立前提 = 级联态的「帧」能看到**真实板面**。部署详设七轮 D7-4 为此前提背书：「备战 op = 观察节点与决策动作节点交替循环（cw_screen_prep.py:713/:774，**每动作一观察帧**……拖拽未效经真实观察可检出〔零读屏形态下该判定不存在、会误判收敛〕〕」。代码事实与该前提相反：cw_screen_prep.py 的两 node 结构 = 「**入口一次 heavy 观察** → 决策动作 node 内 `while True` 循环逐动作（决策→执行→逻辑态直写），**循环内零读屏**」（:707-708/:776-782/:801）；「per-action heavy 重读契约已灭」（:753-756）；动作逻辑态由动作 op **自上报独占直写**，「假账风险由**下一入口 heavy reconcile** 以实读纠逻辑态承担」（:862-864）；访问内的真实观察唯一例外 = 策略层**显式发出 CwActionObs**（:780-782，in_place 环内重观察/outer_loop 返回主循环两形态，cw_vocab.py:926-947）。级联态按总纲 :69「时点 = 每帧重算」逐帧发统一拖动时：每个拖动执行后容器已按预期效果直写 → decide 重入的 diff 与已就位集读**逻辑态** → **拖拽机械失效时已就位集照常「增」**（推演值）→ 2 帧不增永不触发。两条失效分支：① diff 按假逻辑态推进至空 → 误判「级联完成」清槽 → 开店买 X（终结动作返回主循环后入口观察才暴露真板面）——bench 实际未腾，X 买入受阻重评，级联白跑一轮跨画面往返；② diff 恒非空（target 翻转/未知件占槽——真实板面与逻辑态分叉的形态）→ 前置步逐帧重发动作、第 1-9 步全挡——此时**无任何设计内出口**，真实兜底 = 外循环 stall 防线（cw_screen_prep.py:710/:787-789「无进展治理归外循环 stall 防线」）= 停机级事故，而非 S5-2① 宣称的「清槽恢复扫描」。修复路径机制上存在（级联态每动作后显式发 `CwActionObsParam(scope='in_place')` 环内重观察——现役通道，cw_obs_action.py:56-107），但设计未定义此义务，「时长上界 = diff 深度 ≤ K 帧」的帧口径随之（观察-动作对 = 每动作 2 拍，上界 ×2）未申报。「实现者无需再设计」不成立：按 D7-4 认知落 = 判定失效；按代码现实落 = 需自行设计级联态观察策略。
