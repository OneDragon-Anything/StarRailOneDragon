## 1. 背景与动机

现状的策略层存在四个被深读证据推翻的假设:

1. **终局阵容写死**:现有阵容库枚举每个阵容的固定成员与羁绊档位。
   深读结论:核心角色固定,副羁绊按来牌灵活替换(作者原话级证据)。
2. **过渡与终局割裂**:现有过渡体系与终局阵容库是两套独立数据,
   依赖某时刻"切换"。深读结论:阵容是连续演化的,不存在硬切换点;
   开局引擎选择由来牌决定,不属于任何一条线。
3. **没有阶段概念**:现有策略不知道"当前阵容能不能打过接下来的
   节点",导致买牌/升人口/存利息的时机决策缺乏依据。
4. **装备与站位静态**:装备跟角色绑定、领航员绑定是阵容属性。
   深读结论:装备公式跟核心角色驱动型走且有显式时序,领航员绑定
   是时间函数(前期保命绑生存位,后期输出换绑)。

## 2. 核心洞察

**阵容能否通过接下来的节点,是一切策略决策的根基。**

攻略作者们脑内有"这个阵容能打过哪个节点"的经验查表(「3仙舟足以
碾压整个第一位面」「四人组保持健康血量打到boss关」)。有了这个
判断能力,"战力期还是经济期"的阶段划分、买卖时机、锁线时机全部
退化为查询。784 篇投稿正是这张表的标注数据:每篇的
Early/Middle/Final 阵容+通关事实=该形态在该位面"能过"的下限证据。

已提取的位面级战力基线(幸存者证据,单向):

| 位面 | 人口中位 | 主流验证形态 |
|---|---|---|
| P1 | 3-5 | 仙舟3+DOT2(81篇)/列车4(21)/仙舟3+列车2(16) |
| P2 | 6-7 | 列车4+护盾3(40篇)/圣杯任务形态(13) |
| P3 | 9-10 | 列车6系(18+12篇) |

三连贯通形态唯一:列车4+护盾2(11篇,P1P2P3 全位面可用)。

**先验表的统计缺陷声明**:
- 篇数=流行度≠通过率(没人写失败的投稿)
- 跨版本漂移(入表按版本过滤,只收 4.4)
- 作者练度系统性高于 bot——全表水位偏乐观,**阈值乘保守系数**
  (常量 CONSERVATIVE_FACTOR,粗标定后遥测精标;详见 §7 顺序)

**贯通单点风险声明**:三连贯通形态唯一意味着克制列车系的对局
无贯通级备选——线库换线部分缓解,接受残余风险。

## 3. 总体架构

**每个决策节点 = 查战力表决定「战力 or 经济」+ 查线库决定
「为谁积累」+ 查规则集执行具体动作。**

```
┌────────────────────────────────────────────────────┐
│ 决策循环(每节点执行一次,顺序即仲裁优先序)                │
│  1. 感知:己方(羁绊/人口/等级/金币/商店/手牌/事件/HP)      │
│     + 可得的敌方/词条情报                                │
│  2. 锁线检查(先于模式判定:锁线改变动作象限,               │
│     本节点内锁线则本节点即按新象限裁决)                    │
│  3. 应急检查:危急?→ 应急模式(最高覆盖态)                  │
│  4. 查战力表:下个战斗目标能过吗(三级回退)                  │
│     + 滞回计数(战斗节点为计数单位)                         │
│     → 经济/战力模式                                       │
│  5. 象限仲裁表取动作 → 执行(买/卖/合装/站位/换线)          │
│  覆盖态优先序(严格):应急 > 追赶期修饰 > 模式(经济/战力)     │
└────────────────────────────────────────────────────┘
       │              │             │
  战力表           线库           规则集
       └──── 遥测实跑持续校准(探索局打标隔离) ────┘
```

三个数据层的职责:
- **战力表**回答"现在够不够强"(地基,决定模式)
- **线库**回答"往哪个方向积累"(方向,决定资源倾斜)
- **规则集**回答"这一步具体做什么"(动作)

## 4. 数据层设计

### 4.1 战力表

```
内容:形态 × 战斗目标区间 → 验证篇数(敢用白名单)
形态键:羁绊组合+人口+核心角色在场标记+核心星级
目标区间:P1 前/中/后、P2 三段、P3 两段(投稿只有位面级;
  节点区间初版用位面级+遥测逐段细化)
查询(三级回退,返回带证据等级):
  a) 精确命中且篇数≥阈值 → 过(强证据)
  b) 降维命中(先降星级维,再降区间维回位面级)且篇数≥降维阈值
     → 过(粗证据)  c) 仍无 → 不过(miss)
**miss 与滞回的统一语义(rev8 补复位粒度)**:
  miss 计入滞回计数器(与"不过"同权);
  粗证据的计数语义:**粗证据=过;粗证据连击达 COARSE_TOLERANCE
  → 自此持续改判 miss,直到出现强证据(精确命中)或
  **核心维变化**(核心角色在场标记或核心星级变化)才复位连击**
  ——形态变化的复位粒度=**核心维**(羁绊组合/人口/骨架件的
  变化**不**复位——否则战力模式自己的购买动作会反复冲掉
  改判,死区经由该路径复发);持续粗证据形态稳定累积 miss →
  正常进入战力模式补强
边界声明:
  - 维度交叉后稀疏,回退是主路径;各级阈值独立标定
  - 词条维未入;counter 词条由线库吃怕表在锁线层规避
  - 幸存者偏差单向;作者-试用差由保守系数吸收
  - 版本过滤;遥测聚箱顺序=回退顺序
**双证据源合成(rev6 补输入域与版本边界)**:
```
遥测证据池口径:**含探索局与正常局的全部 bot 实跑**——
  负证据的采集本身依赖探索(正常局策略绕开 miss 形态,不会
  自然积累负样本);探索局的采样有偏性由 NEG_EVIDENCE_MIN
  的更高门槛吸收(否决要求更多次尝试+更高失败率)。
  正证据(判"过")同样全池统计,EXPLORE_REPEAT_MIN 足额即可。
遥测源判定三分态:过(复现数≥EXPLORE_REPEAT_MIN)/弃权(无数据)/
  否决(负证据:尝试≥NEG_EVIDENCE_MIN 且失败率≥阈值)
合成规则:
  投稿过 × 遥测{过|弃权} → 过
  投稿过 × 遥测否决 → 不过(bot 实测证伪优先)
  投稿无 × 遥测过 → 过(遥测解锁,标 source=telemetry)
  其余 → 按投稿源单独判定
保守系数只作用于投稿源阈值(bot 遥测无需作者折扣);
生效折扣=投稿侧 CONSERVATIVE_FACTOR,与 Step0 标定对象一致
**版本生命周期(rev8 补否决撤销与重测引导)**:版本切换(如 4.5)
  时,**遥测源条目全部降级为弃权,但保留「曾有否决」标记**——
  带标记的条目跨版本后仍从正常局白名单中排除,并排入探索局
  重测队列。
  **否决撤销判据(rev8 修死锁)**:重测队列中连续
  VETO_REVIVE_PASS 次探索局通过 → **撤销否决标记,回到弃权态**
  (允许正常局采样;正常局复现满 EXPLORE_REPEAT_MIN 后恢复
  完全判定)——撤销路径闭环:否决(正常局排除)→探索局重测
  (连续通过)→弃权(正常局可采样)→正常局复现→过。
  否决不是永久封禁。
  **重测引导策略(rev8 定义;rev9 补证据口径)**:
  探索局按队列头部的重测目标运行引导:目标形态的核心件在商店
  出现时优先购买(覆盖锁线信号判据——探索局的目标优先);
  引导局自身的锁线/D 牌失败/降级逻辑照常(重测目标 D 卡失败
  计数照攒,失败→该形态的正证据不能确立,等价于一次重测失败);
  引导局打标 exploration=retest(与普通探索局区分,
  过程指标单独口径)。
  **retest 局的证据归因(rev9)**:retest 局的胜负证据
  **只进否决撤销判据,不进通用证据池**(引导加成=对目标形态
  系统性有利偏置,与"探索局打标隔离"纪律对齐;局末形态
  偏离目标时无归属争议——不入池就没有归因对象问题)。
  **撤销连续性的归因判据(rev9)**:清零「连续通过」仅当
  **目标形态的关键战斗节点实际受阻**(该形态的 miss/掉血
  导致失败);其他原因的失败(锁到别的线/其他位面血崩/
  bot 异常)不中断连续计数——防与目标无关的噪声无限推迟撤销。
  source=telemetry 的解锁条目随遥测降级一并失效,同样入重测队列。
  投稿源按版本重提取。
**正证据的探索局偏差(rev7 声明)**:判"过"的正证据若全部
  来自探索局,其代表性存疑——EXPLORE_REPEAT_MIN 之上再加
  要求:**至少一次复现来自正常局**(全探索来源的"过"降级为
  弃权级,不单独解锁形态)
```

### 4.2 引擎池(全局层)

```
成员(按 P1 榜验证):DOT2/仙舟3/列车2+;战技点2 待核
  **待核项处理(rev4)**:核验任务=逐篇读战技点2 主导的 P1 篇目
  (约 31 篇),判据=独立成引擎还是挂件;核验在 Step 2 之前完成,
  不过则不入池
开局逻辑:看前几家商店能凑哪个引擎 → 用它,与线的选择解耦
锁线后:按引擎×线兼容性决定引擎件留或卖
**经济期的通用积累方向(未锁线时)**:通用保值件优先级
  (折价可承受的次优,非零浪费——占用利息/备战席,诚实声明):
    1. 跨线通用骨架件(瓦尔特/星期日/花火/符玄)
    2. 双羁绊引擎件升星  3. 经验/人口
  金币纪律:保值件购买受利息地板约束

### 4.3 线库

每条线包含:

```
身份:line_id/核心角色/驱动型(大招流|受击流|行动流)/信号+层级
形态:P2/P3 目标形态(含人口与羁绊档位)/副羁绊可替换组
装备:驱动型装备公式(含时序)/A·B 双套/领航员后期换绑点
运营:D 牌锚点/备战席规则/多余人口方案/
      降级路径(必填)/换线触发(counter 词条/怪 → 换;
      D 卡失败 N 次 → 走降级路径)
门槛:自动战斗友好度/局外依赖排除/词条吃怕表
```

三条驱动型是线库的脊柱:
- **大招流**(姬子/黄泉/大黑塔/绯英/圣杯Saber):充能件+风暴潮
- **受击流**(万敌/白厄/盾反姬子):反甲+吸伤害位互斥+词条依赖
- **行动流**(希儿/银狼/圣杯Archer):速度件+拉条链

**同层信号冲突仲裁(rev4 补)**:同层多信号命中不同线时,
按「先到先锁」(累计器/出现顺序),且同层冲突时要求信号判据
的完整度更高才锁(保守纪律的具体化:冲突=不确定,不确定不锁,
降级到下一层判据或兜底)。

### 4.4 信号与锁线

```
信号四层:0 策略驱动/1 类专属策略/2 核心卡/3 资源判据/∞ 兜底
锁线时机随层级:0 层开局即锁;2 层看到即锁;∞ 层 P2 按质量锁
感知约束:
  0/1 层:策略名有限枚举,模板匹配;0 层双帧确认+图标交叉验证
  2 层:单帧 OCR,置信下限,未识别不动作
  3 层:跨节点累计器;口径=进店帧可见次数(refresh 波不可见,
    已知遥测边界;**「万敌7只」判据=累计见到万敌 7 次**,
    按可见口径标定);换线时累计器清零
锁线保守纪律:漏锁可接受(退化兜底线),误锁不可接受
```

## 5. 决策循环

### 5.1 主流程(顺序即优先序,rev4 重排)

```
每节点:
  1. 感知
  2. 锁线检查(先于模式——锁线当节点即生效,消歧)
  3. 应急检查(最高覆盖态)
  4. 战力检查(三级回退)+滞回计数 → 经济/战力模式
  5. 象限仲裁表取动作 → 执行
```

**时序消歧(rev4)**:锁线提前到模式判定之前,锁线发生当节点
即按新象限(已锁)裁决——不存在"刚锁线但按未锁线动作"的窗口。

### 5.2 战力模式补强(已锁线×战力象限)

```
优先级 1:目标形态缺失羁绊件  2:通用骨架件
3:引擎补件  4:装备合成
**利息纪律(rev4 明确)**:战力模式保有利息地板(与经济模式同);
  只有应急模式放弃利息——战力≠panic,是"计划内补强"
```

### 5.3 敌方与词条(边界声明)

```
可得:开局词条选项/节点类型/boss 名(部分)
不可得:对手阵容细节/敌方词条实时变化
后果:counter 检测只用可识别信号;P3 决赛圈对手针对不在范围
```

### 5.4 应急模式

```
触发(存量语义):剩余可承受败局数 = HP / 单次战斗典型掉血
  ≤ 危险档(DANGER_ROUNDS)→ 触发
  典型掉血初值与标定:初值来自投稿量化证词+按位面分档保守估计;
  遥测按形态分层标定;**表外形态(miss 形态)的掉血**用
  「低置信形态池」的合并分布(遥测探索局积累),不用全池均值
行为(优先级高于经济/战力模式):
  放弃利息/不升人口买即战力/生存装插队/三星目标临时降二星
  降档语义:应急的降二星是临时目标调整,不是走正式降级路径;
  应急退出后回到线的原目标(已买的二星件保留,按锚点自然处理)
退出(双条件,均以战斗节点计;**游戏机制前提声明**:
  本玩法 HP 非单调递减——节点评价回血(SS 评价补 HP,
  姬子类#46 证词「最终 boss 会 SS 补回 40 点血」)、
  治疗羁绊/装备/事件均可回升,应急退出可达):
  HP 恢复安全档(HEAL_HYSTERESIS,存量档位)持续满足
  **EMERGENCY_EXIT_HOLD 个连续战斗节点**(独立计数器,
  专用于应急退出防抖——应急进出不受"模式滞回"约束,
  但有自己的退出保持计数;常量入附录)
人口追赶期(应急退出后进入):
  - 作为模式修饰态叠加;追赶期内允许**临时下浮利息地板**
    (追赶地板=常规地板×CATCHUP_FLOOR_RELIEF,部分破地板——
    **下浮只覆盖还债动作**(升人口/线内件/引擎补件),
    保值件不享受;追赶退出恢复全地板)
  - 叠加经济:升人口置顶;叠加战力:线内件与升人口按金币分流
  - **追赶期 miss 旁路(rev7 修应急漏斗)**:追赶期滞回计数暂停,
    但**miss 不静默**——追赶期内每次战斗节点采样 miss 时,
    直接执行「追赶×战力」的动作分流(不受当前模式限制:
    滞回暂停的只是模式切换,不是战力响应);消除位面切换后
    「追赶(经济)→miss 无法切战力→掉血→应急」的漏斗
  - 追赶期滞回计数暂停;**追赶退出时强制重采样、streak 从
    当前形态重数**(追赶期形态实质演化,旧 streak 属旧形态——
    与锁线/应急/换线的级联重裁决同规格)
  - 追赶退出判据=人口≥位面基线减容差(CATCHUP_TOLERANCE,
    允许-1)且容差带回滞(防基线±1 摆动)
  - **位面切换的常态化触发(rev6 声明)**:进 P2/P3 时人口
    通常低于新位面基线 → 结构性进入追赶——**这是设计意图**
    (位面切换本来就该升人口),追赶期在遥测中将大量出现
    属正常,非异常信号;判读指标据此口径化
  - 追赶期内应急再触发:追赶态清除;应急再退出后重新评估:
    人口仍低于基线→重进追赶(幂等);已达标→不进
  - 重启恢复:首节点检查人口低于基线→重进追赶(幂等)
优先序(全文唯一真值,rev5):应急 > 追赶修饰 > 模式(经济/战力)
```

### 5.5 模式仲裁与滞回

```
**四象限动作表**:
  未锁×经济:保值件(利息地板内)+人口+引擎维护
  未锁×战力:引擎最优补件(档位提升>骨架>保值)——无目标形态
  已锁×经济:线内件+人口(按线的节奏锚点)
  已锁×战力:§5.2 分层补强
  同节点多来源冲突:按象限表唯一取用

**滞回(rev5 补采样-执行一致性)**:
  - 计数单位=**战斗节点**(战斗前查表采样;商店/refresh 帧不计数)
  - **模式生效时机**:采样结果当节点商店期即生效(战斗前采样→
    紧随的商店期按新模式执行,无滞后——与锁线消歧同规格);
    应急/锁线/追赶退出/换线事件发生时当节点重采样重裁决
    (级联生效)
  - **级联事件对冷却的处置(rev8 声明)**:
    级联重裁决是「事件路径」,**不受 MODE_EXIT_COOLDOWN 约束**
    (该冷却只管滞回路径的模式切换——事件触发的模式重定
    是重采样结果,非切换);级联事件**清零 MODE_EXIT_COOLDOWN
    计数**(旧冷却针对旧象限,象限已变无意义);PIVOT_BAN_K
    与 PIVOT_COOLDOWN **在级联中不清零**(换线保护的目的
    恰是跨事件持续——只有自身的 K 衰减/到期/豁免能解除)
  - 经济→战力:连续 M 个战斗节点 miss(含折算 miss)
  - 战力→经济:连续 M 个战斗节点过阈+冷却期满(**模式退出
    冷却=独立常量 MODE_EXIT_COOLDOWN**,与 PIVOT_COOLDOWN
    正交——rev7 消除悬空引用)
  - 量纲:全程验证篇数
  - **换线保护(rev6 重组)**:
    禁回购:换线后旧线核心件禁购 K 个战斗节点;
    豁免一:降级目标=旧线低配;
    豁免二:应急态内买即战力命中旧线核心件(生存优先,退出即失效)
    定位:**动作级禁令,叠加于真值表任何行之上**
    K 衰减依据=位面固定节点图(游戏常数,入静态配置)
  - **换线自身守卫(rev8 补失败计数边界与防环)**:
    换线事件**两侧 streak 全清+当节点重采样重裁决**(与锁线/
    应急/追赶退出的级联规格完全一致——形态剧变事件一律全清
    重数,消除"只清 miss"的不对称);换线后模式按重采样结果定
    **换线冷却**:PIVOT_COOLDOWN 个战斗节点内不得再次换线;
    **D 卡失败计数与冷却是两个独立计数器,失败计数在降级/
    换线事件触发时清零**(只增=运行期间不衰减;事件边界清零
    ——防「计数≥N 持续满足→冷却期满即连环降级滑到底」);
    **降级路径执行=换线事件**(触发禁令 K、冷却、streak 全清,
    与主动换线同规格——降级就是换线的一种);
    **降级链防环**:每局维护「本局已访问线」集合,降级目标
    已在集合中 → 改走全局兜底线(DOT,无降级路径的终结线);
    **兜底线自身遇险(rev9 声明)**:兜底线的 D 卡失败计数
    照常累积但**无降级出口**——接受(计数饱和无副作用;
    遇险由应急/战力模式应对;兜底线本身选的是最低门槛形态,
    miss 概率最低)
  - 状态真值表(替代散文优先序——全文唯一裁决源;
    换线保护为动作级禁令**叠加于每行之上**,不单列行):
    | 状态组合 | 动作来源 |
    |---|---|
    | 应急(任何) | §5.4 应急行为(追赶清除;旧线件禁令豁免二生效) |
    | 追赶×未锁×经济 | 升人口置顶+保值件(下浮地板仅覆盖升人口) |
    | 追赶×未锁×战力 | 引擎补件+升人口分流(下浮地板覆盖两者) |
    | 追赶×已锁×经济 | 线内件+升人口置顶(下浮地板覆盖两者) |
    | 追赶×已锁×战力 | §5.2+升人口并列(下浮地板覆盖两者) |
    | 非追赶四象限 | §5.5 四象限表 |
    (rev6:下浮地板只给还债动作——升人口/线内件/引擎补件;
    保值件不享受下浮,防人口债未清又积压非定向资产)

**跨节点累积态清单(rev9 补防环集合)**:
  **锁线状态/当前 line_id/引擎选择/装备时序进度/领航员绑定/
  D 卡失败计数/已访问线集合**(session 核心态)+
  滞回计数/换线保护 K 计数/换线冷却计数/粗证据连击计数/
  应急退出保持计数/追赶期状态/信号累计器——全部内存态,
  重启丢失语义统一声明:
  **锁线状态丢失**:重启后按当前 board 重新信号匹配(已成型
    的线可通过已购核心件识别——board 上的姬子3星=姬子线证据;
    无法识别则退化为未锁线态,风险=重复买已有核心件,
    由"已持有检测"拦截,损失有限可接受);
  **引擎选择丢失**:同上按 board 重建;装备时序丢失:按公式
    重新对照已装备状态推演到当前步(时序是确定性的,
    从已完成步骤续跑);领航员绑定丢失:按两层规则重绑
    (全局层规则可即时恢复);
  滞回计数清零=容忍一次额外模式切换(可接受);
  K 计数清零=换线保护提前解除,**重启后首个节点若检测到
  旧线核心件可回购,先检查降级豁免条件再放行**——旧线身份
  按「换线事件前的 line_id」恢复(锁线态丢失时从遥测的
  换线事件记录读取,无记录则禁令作废——最坏情况=容忍一次
  抖动回购,可接受);
  换线冷却清零=冷却提前结束(容忍,低频事件);
  D 卡失败计数清零=降级触发延迟(容忍,重攒即可);
  **已访问线集合丢失**:从遥测换线事件记录重建(线序列可回放);
    无记录则集合作废=接受一次环风险(与 K 计数同规格——
    连败局高发重启的场景,环风险由兜底线的低 miss 概率兜住);
  粗证据连击清零=重数(影响小);
  应急退出保持计数清零=按 HP 当前值幂等归位(§5.4);
  追赶期丢失=人口低于基线→重进追赶(幂等);
  信号累计器丢失=失真 → 该信号判据降级为不可用
```

## 10. 风险与边界

1. 战力表粒度:位面级起步,节点区间长期稀疏(接受);回退主路径,
   各级阈值独立标定
2. 规则即代码:线内判据是代码层,调优动代码(接受,as-built)
3. 换线平滑度:兼容性表+白厄线验证;换线收益指标功效不足(接受,
   低频事件长期积累)
4. 版本漂移:4.5 重提取(生成器可重跑)
5. 统计功效:校准需百局量级;辅助指标(hp 曲线)补偿样本效率
6. 贯通单点:接受(§2 声明)
7. 未覆盖(显式排除):装备配方级选择/事件选项语义/P3 决赛圈针对/
   投资策略通用决策(初版用 0 层信号固定优先序)
