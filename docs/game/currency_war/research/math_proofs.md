## 已证明

### P1 弃购的真实代价 = 再遇窗口(尽早囤的数学基础)
- **命题**:有用件弃购省下的金 < 再遇它的期望损失 → 该囤就囤,越稀有越囤。
- **证明**(playstyle [22],2026-08-23 口述+D 牌期望模型 economy.md §2):
  单店出现率 q → 再遇期望 1/q 轮。1 费 7-15 轮自然回;**5 费在 7-8 级
  = 60-180 轮(整局可能不再遇)/急 D 补救 120-360 金**;9-10 级窗口才收窄
  8-18 轮。卖出全额退(1星=cost)→ 囤的下行风险仅 bench 槽稀缺。
- **策略含义**:囤优先级只在「bench>2-3 张」时才需排序;收集窗口不是
  省钱机制。**约束**:息线上方或该笔不破息(息差损失计入第一笔账,[11][17])。
- **状态**:已证(概率论+池分布;模型=economy.md D 牌期望精确模型)。

### P2 早期铺装满队是正期望
- **命题**:早期把简易装备铺满全队 > 集中给核心(狼狩线实证)。

  不矛盾——[29] 管「合成路线组件」,P2 管「简易成品件」。
- **状态**:已证(该线实证)。
