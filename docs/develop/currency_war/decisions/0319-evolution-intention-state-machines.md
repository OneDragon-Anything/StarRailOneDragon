# ADR-0319: 阵容演进引擎与终局意向的语义定稿(evolution_step 发显式 CompTransaction / 意向锁线只写囤货)

- 状态:accepted(补写;行为已随 W33+W34 批 commit,本篇事后落档)
- 日期:原 commit 2026-08-24(5cb4af2c);补写 2026-08-25
- 背靠:`转型讨论.md`(演进法则)+ `strategy_v4.md` 点0/点6/点11
  (单一源);契约包 C3;教义边界 user_playstyle [21]/[23]。
  落点:`cw_evolution.py`(W33)+ `cw_intention.py`(W34)。
  W53 盘点结论:两模块 ADR+as-built 正文双缺——本篇补 ADR 面,
  as-built 语义正文的欠账另清。

## 背景与动机

decision_v2 重建(ADR-0290/0291)后,「阵容怎么换」「终局线怎么锁」
两个决策面缺独立模块:旧件 `cw_signal_lock`(信号 2 层)与
`cw_line_library_v1` 是 LineV1 载体,语义粒度撑不起 v4 教义(信号
五层/撤销析取/降格终局)。两模块是「新策略三大件」之二(三件:
体系卡/演进/意向),载体批(W35)层1 换源直接消费。

## 决策

### cw_evolution:阵容演进引擎(契约 C3)

**定位**:「任何时刻、任何档位规模的阵容替换通用法则」的决策侧
实现——过渡 1 档换终局 2 档、插件档换副羁绊档、插件换单卡,全部
同构走同一入口(不再为每类换法写特例)。

1. **统一入口四步(冻结)**:`propose_upgrades`(枚举可上新羁绊
   机会)→ `evaluate_upgrade`(三条件:①效果判断[新档成型效果>
   现状,2换1 的具体化]/②核心校验[carry/替班核心在手]/③人口检查
   [信息位——**不阻断**,摆不下也上])→ `execute_replacement`
   (④-1)→ `fill_gap_after`(④-2 数人口缺口按空位规则填位)。
   发令枪 = ①∧②(档齐∧核心到),③只披露不 veto。
2. **执行载体 = 显式 `CompTransaction`(W26 动作集,cw_state 单一
   源)**:模块**不自己迁移状态**,整档替换一次发一条事务(决策在
   执行前一次敲定),全部经 `cw_state.simulate` 应用——演进引擎的
   输出是「显式事务流」,不是散装 Buy/Deploy 流。这使演进行为可
   审计(账本一条事务带 reason 如 `evolve:DOT2→仙舟3`)、可守卫
   (ADR-0317 的同名/代际校验在事务收口统一生效)。
3. **空位规则**:插件优先 / 替班核心例外 / 真核心 bench 等档;
   插件禁用矩阵(PLUGIN_LIBRARY)参与。
4. **中断恢复 + 谷底回滚**:`EvolutionState` 跨步记忆——`pending`
   (遭遇/boss 前 1 轮不启动新替换,冻结待下个非遭遇轮入口三条件
   重校验)/`paused`(谷底回滚后的放缓标志)/`last_deployed`/
   `last_retained`(回滚窗 1-2 轮的消费锚)。
5. **边界(六矛盾裁决 6)**:替换决策不消费 bench 装备字段(按
   角色身份+羁绊档判断,装备只随人走)。

### cw_intention:终局意向分层(strategy_v4 点0)

**定位**:纯逻辑模块,不碰游戏、不改板上——教义 [21] final 件
「买而不上」的直接翻译。

1. **信号五层(①>②>③>④;⑤不产出由解析侧兜底)**:`detect_signals`
   判定①策略驱动(环境/投资策略 affinity)/②类专属羁绊
   (`FAMILY_BOND_SIGNALS`,W47 起从 `Comp.bond_signal` 数据字段
   派生,ADR-0320)/③核心卡/④资源;⑤兜底线 = `FALLBACK_COMP_NAME`
   (绯英档,无信号默认落点——「门槛」是资源锚维度,误解记录 M12)。
2. **锁线/撤销状态机(`IntentionState`:unlocked/locked/weak)+
   降格终局**:教义 [23] 终局线由贯穿件锁定不是 pivot——锁定后
   撤销**只有两个出口(析取)**:①意向核心 N 轮不可得(计数分母
   只计刷新窗已开的轮,**窗口冻结语义**:`LineTrack.miss_count`/
   `frozen_rounds`,窗口未开不计数;冻结超位面剩余节点 → 该线
   移出候选集逐出);②更高层级替代信号且过可达性对照。**分数涌现
   换线不进本模块**。强制锁线(P3 入口)产生 + 降格终局标记
   (demoted_endgame,全不可达时「赢不了就少输」)为 absorbing 态。
3. **锁后效果接口 = 囤货目标集合,不改板上**:`hoard_target_set`
   输出 `HoardTarget`(char_targets + equip_targets[意向线
   equip_assign 派生剔 equip_taboos] + mode)——生产载体
   `decision_v2.update_target` 每轮把它写进 `session.v3_hoard`,
   **买侧唯一消费面**;意向模块自身不产出任何上场/换人动作(与
   cw_evolution 的分工:意向管方向、演进管换档)。
4. 弱意向态撤销后去向:只囤跨线骨架件(`CROSS_LINE_SKELETON`,
   W50 起从 W16 过半统计派生,ADR-0312)。
5. 设计推断常量(`CORE_MISS_N` 等)标注「sim 校准」(strategy_v4
   悬而未决·W10 摆动域),不写死语义。

## Considered Options

- **演进换档走散装动作流(逐 Buy/Deploy,与普通买牌同管线)**——
  被否(事后重构补记;C3 契约面已隐含):整档替换是原子语义(半
  套换一半 = 板面战力谷底),散装流允许中间态被其它决策打断,且
  审计/守卫无法在事务收口统一;显式 CompTransaction 让「决策一次
  敲定、执行原子、失败整拒」(ADR-0317 守卫的语义前提)。
- **人口检查③作硬门(摆不下不上)**——被否(教义原文裁决,历史
  记录):③是信息位不是阻断——人口可随后续卖/升级腾出,硬门会
  让换档死锁在低人口期;发令枪=①∧②。
- **演进决策消费 bench 装备字段**——被否(六矛盾裁决 6,历史
  记录):替换按角色身份+羁绊档判断,装备只随人走;读装备会把
  换档与装备分配两个决策面耦合(装备重分配另有职责)。
- **意向锁线后直接产出上场动作(强一致板面)**——被否(教义
  [21],历史记录):final 件「买而不上」——终局件到位只是囤货,
  板面仍由演进/部署逻辑管;意向越界改板 = 两模块职责互踩。
- **撤销出口加「分数涌现劣势」第三出口(分数差自动换线)**——
  被否(教义 [23],历史记录):终局线由贯穿件锁定;分数涌现换线
  是 v1 时代 M38 振荡族的根因,明确排除在意向模块外。
- **窗口计数按日历轮(每轮都计 miss)**——被否:刷新窗未开的轮
  「核心不可得」不是证据(买不到是结构性的),计入会把低刷新
  可见度误判为核心不可达;冻结计数器+逐出(冻结超位面剩余)是
  点0〔修A1〕原语义。
- **②类信号表手编在 cw_intention 本地**——原批如此,被 W47
  统一化推翻(ADR-0320):crosswalk 迁移为 `Comp.bond_signal`
  数据字段,注册表派生——本篇按现状(as-built)记语义。
- **新模块直接 import 旧件复用(cw_signal_lock)**——被否(新旧
  交替声明,历史记录):旧件不动不 import,接线切换归载体批;
  在旧件上改会造成 LineV1/v4 双语义同体。
