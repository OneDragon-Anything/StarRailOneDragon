# 无名勋礼-扫码支付弹窗(nameless_honor_scan_popup)

无名勋礼付费档位点击后弹出的**白色居中扫码弹窗**,画面归独立屏(从「无名勋礼-购买档位页」屏拆出——拆屏理由:弹窗蒙层盖住档位页 id_mark 锚「无名客的奖章」,宿主屏对弹窗帧必挂,照「商店-购买弹窗」拆屏先例)。背景 = 暗化的档位页(已购/未购态随入口不同,背景 OCR 仍可读)。

## 1. 何时出现 + 出口

- **入口**:[无名勋礼-购买档位页](无名勋礼-购买档位页.md) 点任一档位按钮:￥68(荣勋)/￥128(奖章)/已购态 ￥78(荣勋授章补差价)——金额与商品名随档位变。
- **出口**:右上 ×(1220,285)→ 回档位页;支付完成 → 通用「获得物品」弹窗 → 回无名勋礼主面板;**放弃支付链**(bot 收摊清理):点 X → 弹「确认放弃本次支付?」→ 点「确认放弃」(坐标复用商店屏三 area,见档位页 doc §3)。

## 2. 识别特征

- **id_mark 双锚**:「标题-扫码支付」(890,272-1030,322)+「tab-支付宝」(715,450-940,505,文本 支付宝)。第二锚选 tab 而非渠道标注的理由:**渠道标注同位互斥**(支付宝态「支付宝扫码」/微信态「微信扫码」,锚不定),而支付宝 tab 三种渠道态下都显示「支付宝」二字(2026-11-12 三张 fixture 实证);商店扫码帧在同 rect 为空(商店弹窗该位是二维码图形),不撞车。
- **当前渠道判据 = 文本-支付宝扫码 / 文本-微信扫码 同位互斥**(885,730-1035,768):支付宝态读「支付宝扫码」,微信态读「微信扫码」。
- 文本-商品名(875,392-1045,426):读「商品:无名客的荣勋 / 荣勋授章」——OCR 偶剪首尾字,相似匹配即可。
- tab-微信支付(975,450-1210,505)点击用(切微信渠道)。
- **二维码有时效**:过期态中央出刷新圆钮,点击 (960,625) 重出码。
