## 方案

### 1. 判据总式

```
窗口 W = 按节点类型过滤的最近两场已结算普通战斗（§4）
能力态 κ_S ∈ {足量, 边缘, 不足}（§2，敌方通道标尺）
可及(t) 分域，t 扫描域 = 决策帧实读 options 的 difficulty 值集：
  Δ 有源档（其一~其四）⟺ κ_S ≠ 不足 ∧ (κ_S ≠ 边缘 ∨ t ≤ 其二) ∧ scaling(D_win)/scaling(D_enc(t)) ≥ f_min ∧ 经验档层裁决(t)（§3：同档有数据点 → 需过线证据；无数据点 → 弃权通过）
  Δ 无源档（其五/其六）⟺ κ_S = 足量 ∧ 经验档层该档过线正证据（§3 操作定义）——边缘封顶辖制之，仅足量态可达
选档 = 可及集内 (档位主序, 奖励 tiebreak 次序) 最大者（§6）
可及集 = ∅ → 最低档 + 刷新逃生阀（§5，未用时；∅ 判据统一覆盖不足态与边缘全档不可及）
暗装态（触发全集单一源 = §9：标定门〔三常量 + 条语义 + 环完整性对账〕+ 结构门〔D_enc 无现场真读 / 窗口无可用 D_win 行〕，W4 同锚）→ 恒最低档 + 零刷新（与现行 mandate EV 核 fail 向行为逐位一致）
单卡帧 → 直接选该卡；无选项帧 → idx0 default（与现行 mandate/生产行为一致）
```

### 2. 能力态 κ_S（敌方通道标尺 + 删失归态）

输入 = 窗口 W 内两场的 `killed` 与败局帧 `progress_fill_ratio`（下记 fill）：

| 态 | 判据 | 效果 |
|---|---|---|
| 足量 | 两场全胜（killed=True） | 无档位天花板（可及性由 §3 不等式裁决） |
| 边缘 | 恰一胜 ∧ 另一场 = 败局（fill ≥ 1/2〔待条语义定谳，见下〕∨ fill 删失）或删失局（killed 删失） | 天花板 = 其二（缺口最近出现过，无余量论证，保守向；= 总式第四合取项） |
| 不足 | 恰一胜 ∧ 败局 fill < 1/2〔待条语义定谳〕；∨ 两场全败；∨ **恰一败 ∧ 一场 killed 删失**（一确定败 + 一未知，保守单调指向不足）；∨ 窗口 < 2；∨ 两场均无法判定胜负（killed 全删失） | 可及集 = ∅ |

- **敌方通道授权与选型**：轴授权 = 裁定 2 字面「敌方血量消耗结果」。三量比较：`progress_fill_ratio` → 选为分级量，**但条语义两假设未定谳【拟】**（分层声明：条为连续填充已定谳——读数器 C2；位面累计 vs 节点内归一的**语义归属**未定谳——本条判别式）：(a) 节点内归一（该场需求线填充比例——1/2 阈值论证的前提）；(b) 位面级累计条（读数器注释「每位面满条对应进度上限」「总长 = 位面节点数」`cw_settlement_obs.py:253-256`/`:390-392`；±N 现象学——胜恒 +2 / 败多数大负、位面开局即大负；在册反例 P2r1 败 +2，符号语义未定谳正是 ±N 不进判据的原因——倾向此说）。**方向维度未定谳**：读数器只判「红像素列」，红 = 已推进 / 红 = 未完成未与 combat.md「进度条红→黄」达标反馈对账——方向为反 + 条语义判 (a) → 边缘/不足两档系统性互换（乐观向）。方向判别式（并入 E-3 前置义务）：economy.md:137 在册 P2r1「+2」已知帧实读红段位置（一帧即决），或胜/败 fill 分布对比。定谳前：边缘/不足分级不激活（并入开闸门维持暗装）。**定谳判别式（E-3 前置义务，离线可判）**：同位面连续结算帧 fill 轨迹对逐节点胜负对账（**普通战斗帧、遭遇帧分桶各判**）——每节点独立起落（前后行无关、不延续）= (a)；跨节点延续（本节点值可正可负，但相对前值的变化与该场胜负关联、不归零重启）= (b)。判为 (b) → 败局 fill 分级证据不采信（1/2 与 <1/2 判定同废），恰一胜 + 败局 → 不足（保守回退，W2 边缘态收窄为删失分支），由定谳批回写本节。`damage_dealt` = 绝对量（需敌方血量上下文归一）→ v1 只随行采集，供经验档层与 E-3；`progress_delta` ±N 符号语义两份战败样本相反（M41 −22 vs P2r1 +2，economy.md:137）未定谳 → 不进判据（填充率为幅度通道，与 ±N 增量非同一量）。
- **1/2 阈值零调参论证**：fill ≥ 1/2 ⟺ 已推进进度 ≥ 剩余进度（比值定义的对称中点，零自由常数；与「两游戏定义量同单位比较」同级论证，无拍值）——前提 = 条语义 (a) 节点内归一，未定谳前不激活开闸（见上条）。
- **删失归态**：删失仅对败局帧统计——胜局由 `killed` 承载，胜局帧 fill=None 是结构性删失，不影响归态。败局 fill 删失（进度条未读出）→ 该败局不可作足量证据 → 按边缘计（保守但不过罚）；败局 `killed` 删失（三重兜底后仍 None）按败局删失同法，**且优先于 fill 分支**（整场按删失计——胜负未知时 fill 无判定意义）；窗口 =（败局，删失）→ **不足**（一确定败 + 一未知，保守单调：不优于「恰一胜 + 一删失 → 边缘」的既有取向）；两场全删失 → 不足（数据不可得 = fail-closed 最低档；刷新逃生阀仍可用，非暗装全同）。E-3 量测 fill 读取率（页 1 帧态依赖）；读取率不足 → 判据维持暗装（W4），如实申报。
- **尺度偏差申报**：fill 若为节点内归一（条语义 (a)）则无跨难度漂移（旧 P/B 通道的 P ∝ 敌剩余血量式尺度问题随通道更换消解）；跨节点可比性只由 §3 不等式 + D_win 承担。残余风险 = 条语义未定谳（本节）与各档低保线位置定义差异（游戏校准量），E-3 分级混淆矩阵量测兜底。

### 3. 档位可及性（双值锚 + 值域 + 经验层）

**双值不等式**：窗口内**清场（killed=True）战斗中 difficulty_node 最高者**（同值取较近一场；None 行不候选，见真值缺失分支）为 D_win（现场真读快照，RoundOutcome.difficulty_node），遭遇档 t 的节点难度 D_enc(t) = **决策时备战帧旗牌真值（BoardState.enemy_difficulty）+ Δ_t**。可及 ⟺：

```
scaling(D_win) / scaling(D_enc(t)) ≥ f_min
```

- **同源申报（两层）**：①读值口径层——D_win 与 D_enc 同为备战帧旗牌读值（同读链），两侧口径一致；②成分层——D_enc 读自**前一普通战斗节点**，不含遭遇 −4（该修改器仅遭遇/首领节点生效）、伟大征服连胜项滞后一场；判据用 Δ_t 取**净值语义**（相对 D_enc 读值口的净值 = 档位加成 + 遭遇 −4 + 连胜增量 + 窗间品质/特殊加成增量；economy.md:107 的 {0,10,20,30} 为档位原始加成，仅作量级锚）——定谳前按原始加成取值的方向**有条件**：窗间 Δq + Δs ≤ 4 → 保守向（连败 Δs<0 为最保守；品质只增不减、连胜可增可减）；Δq + Δs > 4（窗间新获彩品质/圣杯 +30 型）→ 转乐观向——E-3 按选档结果标定净值消除该条件依赖、禁把 −4 归并进 f_min。指数模型（HP = c·1.052^D，同难度值同敌血假设）下化简为 `1.052^(D_win − D_enc(t)) ≥ f_min`；同难度值同敌血假设与观测自洽（遭遇比 boss 凶 = 档位加成推高难度值所致，combat.md:32）；模型风险与升级路径见文末。
- **真值缺失分支（live 门）**：判别子 = `enemy_difficulty` Field 的 **`source == 'observation'` ∧ `value is not None`**。代码事实：Field 默认 (None, source='observation')（`cw_game_state.py:407-408`）、carry 对从未写过的字段早退（首值只能由 observe 产生）、写入半 miss 走 carry——故**首枚旗牌真读成功前字段恒为 (None, 'observation')**，仅 source 判别会对该态假阳性放行、D_enc=None+Δ_t 直接进算术；value 非空合取封死该态（旗牌 OCR 常空为在册已知，该态非奇点）。简报恒值（≈108）经 carry 路径写入、source 非 observation，同样被拒——简报毒化正是 ADR-0449/F1 迁移审计治理的形态（92.7% 恒 108）。`enemy_difficulty_live` 是工作帧瞬态字段，非 BoardState 面。门不通过 → 判据弃权 → 暗装行为（最低档 + 零刷新，W4 同锚）。窗口行 `difficulty_node = None`（该场备战帧无现场读）→ 该行不作 D_win 候选；窗口内无可作用行 → 判据弃权暗装（总式触发词已含）。**不做解析合成兜底**：cw_difficulty_account 合成值不可用作 D_enc（成分缺口 + 零现役接线，契约 2），且待接成分含正成分（品质 +3/+6、特殊加成 +30），漏计方向 = D_enc 低估 = 可及性高估 = 偏乐观，方向不可控——v1 整体回避。00 §7 的「公式计算值 = 兜底 + 对账」形态挂升级路径：E-3 量测真值命中率，命中率不足时另批立项合成兜底（届时逐成分标注漏计方向并双侧同源对账）。
- **数量级核对（脚本复算；首句为原始加成口径的 g 换算展示，非判据阈值——判据阈值见句末净值口径）**：Δ=10 → g≈1.660（可及门槛 f_min ≤ 0.602）；Δ=20 → ≈2.756（≤ 0.363）；Δ=30 → ≈4.576（≤ 0.219）。交叉对账：1.052^18 = 2.4905 ≈ 在册口径「三彩 18 难度≈血量×2.5」（economy.md:109）。f_min = 0.5 下最大可及净增量 ≈ 13.7（覆盖其二净值 6、不及其三净值 16）。（**净值口径** = 零增长前提下 net Δ = 档位加成 − 4）：其二门槛 = f_min ≤ 1.052^−6 = 0.738；**其三门槛 = f_min ≤ 0.444——标定批实测落入即开**；其四门槛 ≤ 0.268；f_min ∈ [0.4, 0.6] → 可及其一/其二（[0.4, 0.444] 段并及其三）。（数量级例证以「窗口战斗与遭遇节点间旗牌零增长」为简化前提——品质只增不减、连胜可增可减，比值例证方向随窗间增量符号而定；判据本体消费真实快照不受影响，增长量级随 E-3 配对量测。）
- **其五/其六（词表内、Δ 无源）——与交集语义的域界**：Δ 无源 = 解析链**无估计**（结构性缺数据），非「估计为不可及」；交集语义只辖有估计的 Δ 有源档（其一~其四）。其五/其六由经验层正证据单独裁决：该档本局遭遇行存在 `killed=True` → 可及；否则不可及。**过线操作定义**：killed=True 无条件有效（语义无关——清场必已过该场低保线）；`fill ≥ 1` 为第二判据，挂条语义定谳（仅节点内归一语义 (a) 下启用）。**现势性申报**：正证据无时效门（本局任意时点）——乐观向残余如实申报：有界（证据 = 该档实战过线），不加常数窗（拍值禁）；且该通道被总式第四合取项辖制，仅足量态实际可达其五/六。锁 W11（与 W9 的域界在锁面分档注明）。
- **经验档层（自改进，交集语义）**：每场遭遇战无论成败产出 (档位 t, D_enc 真值, fill, killed) 数据点——载体 = 遭遇战 RoundOutcome 行（扩字段 `encounter_tier` + `difficulty_node`），落 **GameState 遭遇经验表**（建议名 `encounter_log`，本局全量遭遇行，量级 ≤10 行/局；§8，产出端锁 W13）。可及判定（**Δ 有源档其一~其四**）= **解析链与同档经验两法都说可及才可及**（fail 向交集，防解析链高估）；两法冲突以交集为准。**经验侧空证据 = 弃权不否决**：该档本局无遭遇行（表空或无同档行）时交集约束不生效、解析链单独裁决——交集防的是「经验反证解析高估」，无证据不成反证；v1 局内 scope 下本局首个遭遇（P1 1-7）经验表恒空 → 解析单独裁决，design §1.1 所废除的冷启动死锁不复存。其五/其六无解析估计可交，归下条经验正证据单独裁决。v1 经验档 = **当前对局内 scope**（经验表随局生灭）；跨局经验表需持久化载体（§8），挂账另行立项。**盲选行申报**：无选项帧直选等盲选路径 chosen_encounter 不写（cw_screen_encounter.py:217-218）→ encounter_tier=None——该行无档位可归，不参与同档交集与正证据（如实申报；W13 锁面同）。**负证据无时效门**：该档全败行同样本局终身有效——阵容成长后早期败绩仍压档，悲观向残余如实申报（与发展优先有张力）；E-3 分级混淆矩阵顺带量测压制率，实测显著再立回写批，v1 不加时效窗（拍值禁）。
- **模型风险（g 形态的 D 无关性）**：1.052^Δ 蕴含血量对难度值指数增长 → 比值与绝对 D 无关；真实曲线非指数时比值变为 D 相关的 g(Δ; D)，解析链需按各 D 取值——配置表查表升级路径同时解决形态与 D 相关性，判据式不变；经验档层不受此风险影响。

### 4. 窗口规则（按类型过滤，非位置叙事）

**规则**：W = GameState 结算观测环中 `node_type == 普通战斗` 的**最近两场已结算**行（按结算顺序取末二）。**读链申报**：node_type 双重解析失败回退默认「普通战斗」= fail-open 向（遭遇行可能误入窗）——E-3 增节点类型解析率量测点（并入读取率量测）。案例走查：

| 遭遇节点 | 窗口 | 说明 |
|---|---|---|
| P1 1-7 | 1-4、1-6 | 1-5 补给居中（补给后能力以 1-6 为准，1-4 为下界参考） |
| P2 2-5（遭遇） | 2-2、2-4 | 2-3 补给居中（非战斗不入环）；P1 1-7 遭遇数据点（同局跨位面）在经验表可作同档证据 |
| P3 遭遇 | 同法（最近两场普通战斗） | 无特例 |
| 变异位（P1 slot3/5/6 变异） | type-based 自适配 | 不依赖模态节点表位置 |
| 已结算普通战斗 < 2 场 | κ_S = 不足 | fail-closed 最低档 |

冗余 = 2 的依据：单场败可能是词缀克制偶发，两场系统败才支撑「能力不足」（配对抗单点噪声，P15v2 配对口径同构）。

### 5. 刷新（逃生阀）

**可及集 = ∅（无论源自不足态，还是边缘态全档不可及）→ 刷新一次换批（若未用）**——∅ 为唯一触发判据，两分支同口径。刷新整排重置分支档位与奖励（advantage_layouts.md:17）；「刷完是否更优」需 offer 分布，无数据 → 不做刷新 EV（拍分布禁），刷新仅作全不可及逃生；刷新后仍全不可及 → 最低档照选。锁 W5（两分支 + 未用/已用）。
