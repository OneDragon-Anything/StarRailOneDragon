## mm_sp_27 - 翁法罗斯新类型（2026-09-16 实机裁剪）

|序号|来源|说明|
|---|---|---|
|27|翁法罗斯-酣歌海垠·斯缇科西亚1层|时空重叠房间（官方 label 680），裁剪位 (477,860)|

裁剪方式：官方坐标投影（本图点表精度高，投影即 ±5px 内）→ 掩码质心迭代重对齐 → 51×51；
mask = 与四角底色灰度差 >30 + 开运算。同图全图回测：主峰 1.0，次峰 0.32（远低于运行阈值）。

**尺寸例外：mm_sp_27 为 63×63（非 51）**——该图标实机渲染约 58×58（大标记样式，
含下方指针尾），51 窗会切掉菱形左右角；运行时 matchTemplate 无尺寸约束，按真实
尺寸 1:1 裁剪。标准 51 惯例只适用标准尺寸图标；新类型裁剪前先量图标 bbox，
超 51 的一律按真实尺寸裁。

> **label 829「塞壬之形·凝滞虚影」不是新类型**（2026-09-16 裁剪后比对发现，曾误立
> mm_sp_28 已删）：即 mm_tp_06「xx之形·凝滞虚影·角色突破材料」挑战家族（3.x 换名
> 不换图标），原位回测 conf 0.948。**新类型判定必须先全库查重再裁剪**；label→模板
