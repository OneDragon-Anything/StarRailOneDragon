## 背景

ADR-0480/0481/0483 将位面 2 支出授权(W757,两通道 v3.3)落码为
`decision_v2/p2_spend_auth.py`,开关 `p2_spend_auth_enabled` 默认关
(生命周期第 1 态),开臂判据挂账 = 预注册协议 V4 双钥匙(P25 证成 ∧
M0a≥70% ∧ M0b≥50% ∧ M1-M3 达标护栏全绿)。验证链四轮 A/B(报告均在
`.debug/temp/currency_war/`):

| 轮 | 设计版 | M0a 触达 | M0b(口径随版演进) |
|---|---|---|---|
| W762 | v3 两通道 | 高 | 单帧净>0:仅 38/248 高金死亡局有授权帧 |
| W772 | v3.1(重跑) | 98.4% | 单帧净>0:4.1% |
| W779 | v3.2 | 达 | 单帧净>0(穷尽后):≈0-2%(rn5-7);净支出可行性审计 n=4532 P2 帧证明单轮收入中位 23 vs sink rn3+ 全枯竭——**单帧净>0 在 P2 中后段结构性不可达** |
| W785 | v3.3(V4 水位口径) | 98.4%(247/251) | **窗水位不升:0.0%(0/251)**;sink 分解:定向 D 44 帧/502 金、XP 0 帧/0 金、L1 买入 0 帧——D/XP 出口仍未产生窗级消耗,判定分支 2(sink 解锁失败),但回设计再调的边际收益已被 W779 审计封顶 |

四轮的合并读法:M0a(触发面)历版 98%+ 有效,M0b 在**四种口径**
(单帧净>0 → 收入阈值 → 窗级水位不升 → 剔卖对照)下穷尽仍 0-4.1%
——问题不在判据标定,在**授权窗内花费的结构性死路**:收入机制量级
(窗累计收入中位 93)远小于带金死局的水位(窗水位差中位 80+),
任何「窗内多花」的出口设计都无法跨越这个量级鸿沟。

**根因定谳(W801 §3)**:接口/授权类杠杆与「档位累积型目标变量」
**类型错配**——P1 出口 hp 的真决定因素是 r7/r9 的激活羁绊档位与人口
(离散战力阶跃:档≥3→税-13/-8,档≤2→税-32/-24),而支出授权只改
「花金的门开不开」,没有一个把档位完成度设为目标。P2 带金血崩死的
正确解法是**窗前**把金转化为档位战力,不是死亡窗内止血。

## 决策

按策略开关生命周期第 4 态(定谳清理)选**删码留 ADR**:

- 删 `decision_v2/p2_spend_auth.py` 全模块(两通道帧判定/XP sink
  授权/水位观测/预算带/拦截枚举;XP sink 子机制随模块一体清理);
- 删消费点:arbiter 三授权臂(gold_floor 加急预算放宽 / interest_rule
  加急破息豁免 / 非正分门优先级 1 核心必买)、strategy
  `v3_p2_auth_intercept` 披露键写点、remediation 核心必买补偿分数门
  豁免(`_p2_auth_mustbuy_rescue`)、ev.levelup_ev_basis 臂④
  'p2_auth_xp'、registry 五键(enabled/fail_streak_n/reserve_floor/
  reserve_rounds_cap/line_band_floor)、sim 检查器升级授权白名单
  'p2_auth_xp' 项(segments/ledger 两处);
- telemetry 披露键 sess_p2_auth_intercept / sess_p2_auth_water:
  写入面删除,**schema 字段保留只读口径**(存量 runs.jsonl 判读脚本
  消费,新数据恒 None);
- 行为锁 `test_cw_p2_spend_auth.py`(16 锁)随语义删除;
  `test_cw_adr0293_calibration.py` 注册表校准锁同步回卷。

## Considered Options

- **回设计层再调 sink 供给(W785 字面分支 2)**(否决):W779 审计
  已证 sink 枯竭是机制量级问题(D 无界 sink 在 v3.3 已解绑仍 0 窗级
  消耗;XP 供给面开火 0 帧),第四轮换口径仍 0.0%——「继续调参」是
  否决数据面前的无限重试;
- **维持默认关挂账**(否决):开臂前置已兑现且结果为否,悬置默认关
  = 生命周期明文的堆积债(与 ADR-0487 同判例);
- **保留通道 A 定向授权半模块**(否决):通道 A 的「锁定线核心卡
  必买」语义与 W803 P29 囤牌优先级/档位积分方向重叠且更弱(无目标
  变量),半删留残根=第二源。

## 后果

- 默认行为零变更(开关本就默认关,零漂移锚);删除后受影响测试 +
  cw_quick 全绿 + realization 十三锁/96 相邻面零波及为验收线。
- **窗前预转换思想不被本批作废**:W801 §3 的时序修正(遭遇/boss 备
  战前移到普通轮的「为建档专项支出」)与档位完成度目标,已由
  W795/W803 兑现链继承(P29 囤牌优先级/档位积分 Δp_tier/realization
  D2 入口帧,ADR-0474 allocator);重立项走该线,不复活本机制。
- XP sink 的「大额金消耗出口」需求由 W795/W803 的档位积分与 D2 入口
  转化吸收,无悬案移交。
