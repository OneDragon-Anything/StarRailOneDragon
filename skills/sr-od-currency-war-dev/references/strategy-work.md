# 策略工作(思路 / 核心 / 改前 / 验证 / 裁决)

> CW skill 的策略专属说明。读者 = 智能体。入口:SKILL.md 分诊表「策略工作」行 + 必做 checklist 步骤 4(改策略前读文档,判据指向本文 §3)。

## 1. 策略是什么(思路)

CW 的策略 = **决策函数族**(买/上/装备/经济/刷新,`decide_*` 系列):每个回合从 GameState 读取板面/金/血/轮次,发射 Action 列表给执行层。策略不是「配置参数」而是**行为代码**——改策略=改决策逻辑,行为语义变更,走文档三同步。

策略的评判标准只有一条:**长期期望胜出**(多局分布),不是单局结果。所以策略的一切讨论都围绕分布:sim 批量看分布变化,实机多局验收,单局胜负不构成证据。

## 2. 核心(策略的骨架,改动必须对照)

- **数学期望是核心(玩法定义,[22]④)**:「货币战争的玩法本质 = 有限经济内发挥最大价值,经济期望是策略评审的统一标尺」。**一切花钱决策,最终都要折算成期望值(平均来看值多少、亏多少)来比较**,没有例外:
  - **买一张牌** = 它带来的收益,对比为了买它少吃的利息([22]④:50 金满息 = 5 金/轮,破息买件的利息损失要计入);
  - **不买一张牌** = 省下的钱,对比再遇到它平均要等多少轮([22]③:5 费在 7-8 级平均 60-180 轮,可能整局不再遇——越稀有的越该囤);
  - **刷新还是升级** = 看目标卡在哪个等级出现概率大([3]:该级概率大就刷新,但刷完还得保住 50 金;要升级才提概率就升级);
  - **买低费牌压库** = 牌池是共享的,把不相关的小牌买走,自己目标卡的浓度就升高([15]/[30] 成本带买光)。
  **口述条目不是并列的规则清单,而是已经算好的期望结论或边界条件——引用时按「这笔账怎么算的」去理解,不要当口诀背**。
- **50 息律 = 期望值框架在利息机制上的表现现象,不是独立原则**([17] 主条):利息 5金/轮 @50 封顶 → 金 <50 每一金有息机会成本(攒息);**≥50 的溢余零息损失、随时可花,节点无关**——>50 是常态且健康,病根是「花钱的时机判据缺失」,不是金超 50 本身。破档不是禁令是账:[6] 例外(店全是想要的);[11] 同档零息损(不跨 10 的倍数不损息);贴档线 ±2 金按 [22]④ 凑息账算。
- **双层目标体系**:决策→阵容完成度→胜负→hp→通关。过程目标(优化方向)=因果上游(完成度/成型进度/经济纪律);末端量(hp/胜率/出口金)只用于验收与报警,不用于优化方向——[18] hp 低=运营质量报警不是 ALL IN 触发;[28] P1 验收=双指标(息基保住×形态达标),出口金 ~50 只是守息的表征。
- **阵容结构判据(花钱期望值比较之外的硬约束)**:过渡是配方不是乱混([20]);羁绊三级梯队=目标件/羁绊填充/散件垫底([31],硬约束:不为凑数羁绊花金 D 牌);final 买而不上([21],窗口语义=羁绊组齐才替换上场;例外=全局累积型角色越早越好);终局线由贯穿件锁定([23],不做涌现挑线);升级为阵容服务([33],由「要找谁」驱动,不是固定曲线)。

## 4. 验证(策略特有的验证纪律)

验证梯度的完整阶梯(L1/L2/L3/sim/实机)与命令单一源 = SKILL.md「验证工作台」。本文管**策略验证的纪律与出口**;sim 工具本身怎么用/能信什么 → [sim-testing.md](sim-testing.md);实机局怎么判读 → [telemetry-reading.md](telemetry-reading.md)。

- **改前基线→改后对照**:改前先跑 sim 批记下基线,改后再跑同参数对照,分布差异必须解释——没跑基线的「改后达标」不构成证据。
- **验的是分布,不是单局**:达标占比/败场≤2 占比/均值/方向建立率;跨日对照先核对局池一致(池指纹,防拿不同牌池的数据互比)。
- **判读锚点事前写**:实机局开跑前写清「预测什么会变」,跑完核对——事后找解释不是验证。锚点没中 = 改动没生效或假设错,两者都要查。
- **实机验收=连续多局达标**(以当期目标为准),单局胜负不构成证据(§1)。险胜不算过——贴线通过是策略缺陷症状,与明显失败同权重分析;局后判读是必做项,异常条目当场定位,定位不了不进下一局。

### 单帧锁(策略验证的固化出口)

sim 批量或实机发现的异常情况,**固化成单帧锁测试才算回归资产**——「模拟是发现工具,单帧锁是回归工具」:

- 位置:`sr-od-test/test/sr_od/app/currency_war/test_cw_<主题>.py`;模式 = 构造 `GameState`(plane/round/gold/level/board/bench/shop/xp_progress)+ `StrategySession` → 调被测方法 → 断言动作序列。异常局面**不问来源**(sim 随机发现 / 实机判读定位),锁的都是策略决策行为。
- **断言写语义不写巧合**:「配方 gap 时围栏内只买配方件」而非「买了卡 X」(换发牌就碎)——锁的是策略意图,不是当时的牌面。
- 依赖路径:测试仓 gitignored 独立维护,提交在测试仓;锁旧行为副作用的断言要随语义演进而改,改时在 docstring 记一句为什么旧语义过期。

## 5. 策略疑问/分歧的裁决(三滤网,第三滤网才轮到问用户)

1. **经济滤网**:是经济取舍吗(何时花/花多少/刷新还是升级/买不买/留多少)→ **用数学答**——期望值公式/刷新概率表(`REFRESH_PROB`)/动态规划解法/口述已含的经济理论。存在可计算期望答案的问题**不是用户问题**。**输出是命题不是答案**:口述的经济直觉(含新口述)立为命题进 `math_proofs.md` 证明——证明成立=策略质量保证(口述给方向,数学给保证);证伪=回炉口述标注边界(先例:「压库有增益」口述被证伪,口述保留、执行判据修正——对应命题见 math_proofs)。**策略分歧的裁决同走此道:已证的直接引用结论裁决,没证的立项去证(进「待证明」节),证据到位才裁决——先证后裁,不先裁后证**。
2. **事实滤网**:是游戏机制事实吗(掉血公式/奖励结构/概率/交互行为)→ 查注册表/研究文档/图鉴;查不到 = 采集挂账+保守值标注继续推进;口述已有的直接引(口述是最高权威,属本滤网而非第三)。
3. **裁决滤网**:数学等价/多方案均自洽/用户风格偏好 → 才构成用户问题(玩法口述级取舍本就是用户权威域)。

判例(ADR-0019):「boss 前留多少金」被用户反问「为什么要问这种问题」——答案是口述 [3] 的直接应用(该等级概率大→刷新找牌,刷新前提=**花后仍保 50 金**;需升级才提概率→升级);「前两轮买不买」= 期望值自动覆盖(开局金 5-10 无息可损,买=零息损压库,统一经济策略)。反向:「扑满关怎么应对」一句口述(不掉血/没奖励损失大/凑羁绊刷伤害)顶十次推断——但那是机制行为口述,属第二滤网的权威源,不是把经济账外包给直觉。
