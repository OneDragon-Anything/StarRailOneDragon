# 货币战争-选择伙伴(节点级伙伴选择 overlay)

## 何时出现 + 状态流转

对局内**位面推进中**随机出现的「选择伙伴」节点(非每轮必有;出现时机由肉鸽地图节点决定)。玩家从 1-N 个候选角色里**选 1 名**加入其流派羁绊 + 复制其首件装备效果,选完回备战。**单屏单选 + 一次确认**(2026-09-14 建档证据更正,原「两步确认流程」记载系误读,见下方⚠️):

- **入口**:备战 → (地图节点为「选择伙伴」时)→ 本 overlay(叠在备战上,备战 id_mark 仍透出可见)。
- **选伙伴**:点候选立绘选中(选中态 = 「已选择」文字出现 + 立绘高亮边框)→ 点「确认选择」。
- **出口**:确认落地 → overlay 消失 → 回备战(节点完成,进下回合)。

⚠️ **「请选择强化角色」= 确认钮旁伴随文案,不是第二画面**(2026-09-14 建档证据更正):本屏建档仅 `currency_war_partner.yml`(标识-选择伙伴/按钮-确认选择),无强化目标第二画面;「请选择强化角色」区域只存在于巨星档 `currency_war_megastar.yml` 且与「按钮-确认选择」rect 重叠(钮上方伴随文案)。旧记载「step1 确认后转 step2 选强化目标」与旧 handler 的 step2 检测/二次确认序列均系该伴随文案的误读(巨星调研已证同款误读),已随 T-220 删除。

⚠️ **dispatch 时序坑(2026-08-13 实跑)**:本 overlay 可能在**备战 round-start 检测之后**才出现( round-start OCR 见干净备战 → Loop 走备战分支 → BattlePrepCycle → 出战 click 被 overlay 挡 → 出战 retry×3 失败停机)。Loop 0a 分支(`round_by_find_area('货币战争-选择伙伴','标识-选择伙伴')`)在 round-start 单次检测,overlay 后出则漏 → 需 备战分支出战前复查 overlay 或 Loop 出战失败后回检(待修)。

- 底部「确认选择」按钮(pc_rect `[1423,561,1587,616]`)+「详情」(其左)。
- 「请选择强化角色」文本(右下 ~1417,530)= 确认钮旁**伴随文案**(非步骤标志,见上方⚠️更正)。
- ⚠️ 这个弹窗叠在备战上,备战底部的「购买经验」没被挡住、还看得见。但区分不靠这个——靠**备战 id_mark 里有「前台区域」(棋盘前排标签),本弹窗把它盖住**:这帧前台区域被盖 → 备战凑不齐自己的 id_mark → 不是 is_precise → 只有「选择伙伴」is_precise(2026-08-13 live 确认)。bot 也直接查「选择伙伴」标题走分支。
