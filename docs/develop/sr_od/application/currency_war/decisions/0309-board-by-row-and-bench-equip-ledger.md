# ADR-0309 契约 C6 落地:按排聚合单一源 + bench 装备 tracking 对账

- 状态:accepted(2026-08-25)
- 关联:契约包 C6(W24)/W21 观测审计(#13/#17)/ADR-0308(同日校准层)

## 背景

演进引擎与体系卡需要「前后台×羁绊标签」聚合视图,此前各处自聚(口径漂移
风险);bench 装备画面机制不可读(W21 #17:未上阵不显示装备 icon),替换
决策期装备去向只能信账本——账本无对账=静默漂移。

## 决策

1. **board_by_row 聚合单一源**(新 `cw_board_by_row.py`):BoardByRow
   前后台标签计数+合计视图;开拓者按当前排归一、多羁绊每系都计;
   cw_system_cards 换源(契约偏差①闭环),全仓无第二处按排聚合;
2. **bench 装备 tracking 单一源+对账**(新 `cw_bench_equips.py`):
   simulate 五类动作装备守恒对账(mismatch 记 EquipsLedger 账本)+
   deploy_bench 画面交叉校验([cw!] 告警);**演进引擎 v1 零决策面
   消费**(裁决 6:bench 装备只记账不进决策);
3. **顺带修复两处装备守恒漏洞**:SellBench 漏回收装备、3合1 吃装
   消失(标 🟡 待实机核)——对账挂点上线后立即暴露的存量缺陷。

## Considered Options

- A(选):动作级对账+画面交叉双层——账本漂移可发现,成本为每动作
  一次多重集比对(微秒级);
- B:仅画面校验——W21 已证 bench 装备画面机制不可读,单层失效;
- C:不建对账——静默漂移会污染替换决策(虽然 v1 不消费,记账面
  已开始积累回归版训练数据)。

## 影响

- 旧调用点零破坏(聚合 API 新文件;对账是挂点不是改道);
- 装备行为变更两处(SellBench 回收/3合1 保留)待实机核;
- 哨兵停机升级(对账告警→停机)归实机运维批。
