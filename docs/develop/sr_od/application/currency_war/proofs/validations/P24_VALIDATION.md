## 1. 门①:内部推导(逐步核)

### 1.1 EV 门式与支配论证:自洽 ✓

- 门式 `ΔEV = Δp·Σ_j L_c·S(b_j) − C − I` 与 P21 §④「受益覆盖」式(`Δp·Σ_{b≥d} L_c·S(b) > C + I`)及 P23 统一门式**同构**,退化到 C=I=0 域后符号完全由 Δp 决定——推导逐步核无误:L_c>0(两源均正:P2 语料 15.39;registry 拟合 11.32−0.37·rung 在 rung∈[0,3] 恒 >10)、S(b_j)∈[0,1] 非负,故 Δp≥0 ⟹ ΔEV≥0,Δp>0 ⟹ 严格正。代数无瑕疵。
- **C=I=0 的实现级核验(亲读代码)**:`engine_p1._residual_fill_deploy`(engine_p1.py:362-479)动作面 = `deployed_place(st.deployed, bc)` + `st.bench[_slot]=None` + `st.board` 重算;`cw_state.deployed_place`(:424-441)为纯板面落位函数,不触碰 gold/level/streak 任何记账点——金账恒等式各项确实不受影响,I=0(金余额逐轮不变 ⟹ 利息分档不动)成立。金不变另由测试锁 1/锁 3 断言(`st.gold == 20`)钉住。
- 不动点循环(上场后重放围栏至 up 空)是修「单趟遗留」的实现细节,不影响命题。

### 1.2 【实质发现】前提 Δp≥0 的锚点失准:结算键单调 ≠ 胜率单调

命题把 Δp≥0 标注为「粗模型:≥ 0(上阵数↑)」并引「`cw_coarse_battle` 结算键单调依赖板面」为机制事实。**直调复核结果**:

- 结算键 = rung,单一源 `cw_battle_calib._settle_rung`(:179-192)= `_engines_count`(四体系达成数 0-4),输入 = board 全集口径。**rung 对 deployed 集合的包含序确实单调不减**(加分不减档)——这一半成立。
- 但胜率表 `_WIN_TABLE`(cw_coarse_battle.py:75-82)**对 rung 非单调**:battle 0.356(rung1)→0.306(rung2);encounter 0.038(rung0)→0.026(rung1);boss 0.077(rung0)→0.027(rung1)。即按 as-built 粗模型,rung 跨过这些格时 Δp<0——「上阵数↑ ⟹ 胜率↑」**不是粗模型交付的性质**,而是(合理的)真实游戏单调性假设(表中回挫是小样本平滑噪声,battle rung3 n=9 等)。
- 量化:回挫 ≤5pp;按期望掉血口径重算 battle rung1→2:E[损] = (1−p)·dmg ≈ 0.644×10.95=7.05 → 0.694×10.58=7.34 hp,**确有变差格**(量级 +0.3 hp/场;boss rung0→1 约 +1.5 hp/场)。相对 F1 病理代价(样本三轮 −16 hp)差一个量级以上,**不翻转修复决策**,但「ΔEV≥0 恒成立」在 as-built 粗模型内**并非表级可证**。

**判定**:推导链代数正确;单一承重前提(Δp≥0)的证据等级被高标为「机制事实」,实际=真实游戏假设 + 粗模型表值的噪声级反例。属**前提注记缺口,非定理推翻**。

## 理想形态成色评估(消参路径可否推广)

**成色:高(合格范例),但非「无前提」**。本件的消参配方可拆为四步,前三是可推广的工程路径:

1. **辖域收窄到零成本动作域**(C=I=0)——成本侧不再是参数而是**实现不变式**(动作面代码级不触记账点),这是最值得推广的一步:凡「免费动作」类决策(补部署、免费重摆、穿戴装备——p42 ②④⑤「免费+可逆退化为可行性问题」同型),支配性都可零参数获得;
2. **比较臂取「什么都不做」**——收益侧从量级比较退化为**符号判别**,只需 Δp≥0 不需 Δp 标定;
3. **侧约束显式编码**(保留集/围栏 dedup/不动点循环)消解通道冲突与隐性机会成本——「零参数」不是凭空来的,是把潜在参数逐个转成结构约束的成果;且 W748 证明这套约束本身要随实证迭代(本报告发现 2 即其痕迹);
4. **量级数字全部降格为注记**,禁作验收线——防 Goodhart。

**边界(不可推广面)**:任何 C>0 或收益符号依赖标定量级的域(P21/P23/P26 升级/支出分配族)无法走此路;且第 2 步的符号前提本身是**最弱一环**——本件 Δp≥0 恰好挂在一条无法从现有粗模型表证明的假设上(§1.2)。**推广判据一句话**:零成本 + 符号可由机制单调性闭式给出 + 隐性成本可结构消解 ⟹ 可消参;三者缺一,退回参数化证明并带 CI(公理栈「估计必带 CI」纪律仍然管辖第 2 步的例外:凡符号本身需估计(如 p42 ③ 的 partner 门控),即令动作免费也须带 λ 带)。
