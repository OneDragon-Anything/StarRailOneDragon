## 2. 升级决策（最优概率带单判据三分派 + 单帧原子发射；判据单一源 = `criteria/levelup.py::upgrade_gate_verdict`）

- **触发 = 单判据三分派**（`upgrade_trigger`；用户裁定 2026-10-18:升级只保留「目标角色在哪个等级刷出概率最好」一个判据,板面坐满等战力义务触发与期望式判据删除）：
  1. 存在未完成星级目标 ∧ 其最优带下界 > 当前等级 → **升级**（升到带内去刷）,触发键 `stay_gate`；
  2. 存在未完成星级目标 ∧ 当前等级 ∈ 带 ∨ 当前等级 > 带上界（纯状态描述,历史升级/自然经验所致,单调不可降）→ **停留刷新**,不升,无触发命中；
  3. 无未完成星级目标（全部追完,或锁定线无追星目标）→ **自然升级**（不停留）,触发键 `natural`。

  辖域 = **锁定后 ∧ plane2_started 双条件**（P1 与未锁定期零主动升级,阶段保护:P1 经验论证在案、过渡门槛全游戏最低;P2 未锁定窗口靠候选缺件刷新,锁定后带驱动接管）。命中计数键 `levelup_trigger_stay_gate`/`levelup_trigger_natural`（分派 2 停留无键）。
- **停留门与「可达最优等级」模型（等级是受控的搜牌手段，[3]）**：**最优概率带 = 搜索域 1..9 内取概率峰值的等级区间**（带成员由 REFRESH_PROB 直接计算，平顶整段如 1 费带 [1,3]；`peak_refresh_level` 在产表为单点峰形态 = 带上界，作域上限校验非带定义本体；4/5 费全域峰在 lv10〔P35 已证停手窗 lv9→10 恒负〕取域内峰 [9,9]——**禁「全域最高值区间 ∩ ≤9」写法，4/5 费将得空集**）；带费用档 = 当前实费 resolved 口径（银狼系变费后实档，档漂移时带随之重取）。分派：当前停留目标未完成 ∧ 带下界 > 当前等级 → **升级优先**；当前等级 ∈ 带（或已被历史升级/自然经验推过带上界——当前等级即剩余可达最优,单调不可降）→ **停留刷新，延迟升级**；停留目标全部完成 → 自然升级（不停留,触发键 `natural`）。当前停留目标 = 未完成星级目标（知识卡 `need_star`）中费用档最低者，多目标按费用档升序逐个追。
- **支出形态 = 单帧原子整批发射**（P48 整买引理；「付不起整级就一击不买」;判据同帧重评,无跨画面键）：
  - **资格门全链判定**：判定单一源 = `upgrade_gate_verdict` **六道门序**（①奖励帧抑制 → ②等级帽 → ③升级判据三分派 → ④击数 > 0 → ⑤经验批支付门〔币种通式，金本位局直通——金侧守线在门⑥，币种模式解析 = `cw_investments.blood_xp_mode`〕→ ⑥资金线门），逐道拒因计数已登记（键域：levelup_reward_node_defer / levelup_reject_level_cap / levelup_zero_clicks_defer / xp_batch_payment_defer / levelup_fund_line_defer）。**现金足（花后金 ≥ saturation_line）→ 同帧发购买经验整批**(`CwActionLevelUpParam` 携 clicks 整批击数;实付上界 = 发射时授权值,授权不跨帧携带——「买一半」由发射原子性消解,部分购买缺陷机理不复存在)。

## 8. 机制突变层（resolved input 原则）（原 03 §4.10 并入）

**原则**：决策机器**禁止直接读基础机制事实**——一切机制输入经「基础值 ∘ 已激活突变」解析后消费（**resolved input**）。突变登记 = 知识层注册表 INVEST_MUTATIONS。

- **登记三分态**：resolved（可解析）/ abandoned（用户裁定放弃建模——desc 无数值一律放弃不实机查，保可见性不进 resolved input）/ 未登记（=知识缺口，采集后入表，不静默忽略）。
- **解析语义结构**：每突变登记为（操作数，合成律[min/max/add/互斥]，状态依赖[计数器/条件]，时效[永久/计数窗/条件移除]）；同操作数多突变按合成律合成；互斥型登记位声明（首个生效，后续 suppressed）；异构操作合成序按操作数分层（override 先于 multiply，层内按注册序）；未登记态运行时检出 = 保守降级（按基础值消费 + 告警，不静默）；消费点读合成后的单一 resolved 值，禁止各机器自选合成方式。
- **多源声明**：突变源不止投资卡——角色固有技能（银狼升费）、任务奖励皆可改状态；INVEST_MUTATIONS 为多源效果突变登记，适用范围不限于投资。
- **突变分类框架**（按改写的操作数）：经济参数族 / 收入与利息规则族 / 概率表族 / 池构成族 / 板面谓词族 / 商店行为族 / 难度与节点族 / 阵容定义族 / 任务系统族 / 工具发放族 / 战力族（~155 条——不进经济 resolved，E1 定价走权重/克制通道）/ 资产发放族（~60 条——非金流，E1 定价走组件缺口通道）。
- **池结构突变语境**（消费 P38/P40 时按语境重算）：银狼升费（按当前可见档取 q）/飞光·映月变费/晋升名额/**专家解锁入池**（专家顾问初始**不在**基础牌库——不参与普通商店招募，名单权威 = 注册表 `Character.is_expert`；对局中经投资环境/投资策略/装备（分身墨镜族）通道解锁后按名并入专家副本数进入商店发牌空间，状态容器权威状态 = `gs.unlocked_experts`，解锁写端 = 获得链 advisor 道与装备通道；v 值静态口径 = 基础池排除专家，解锁名不进静态分母——偏差 ≤1/13 量级接受）/黑塔纪元（216 张特殊池，P38 全模型降级声明）/昔涟诗篇类非 5 槽商店（SHOP_SLOTS 时变）。**池构成硬突变 ⇒ cw_shop_odds 概率表/V_comp 表/p̄/E[refreshes] 整体重生成，不得沿用突变前表**。
- **E1/E2/E15 选择决策的机制升级**（定价框架；判据状态见 13）：三选一评分 = 台账价值 + 突变价值（对 resolved 输入做差分定价）+ 战力账（→权重/克制通道）+ 资产账（→组件缺口通道）+ 难度账（→环境通道）+ 信号分层（A3）；数值走知识登记与标定批，禁拍值。
- **血本位突变**【已裁定 [40]，同日二次收窄】：主动选择=回避（期望价值依赖板面强度，胜率域做不好；强弱不对称）——**回避已写入代码 = 策略层血本位三态序**（`strategies/impl/mandate_v1/invest_strategy.py`，权威版本 = 29 篇 §3）：判据 = `is_blood_economy`（注册表派生，族={奋斗协议, 不等价交换}），三态触发序（可入选非血集 → 非禁血卡 forced → 全禁退化），OCR 形变名经 `resolve_strategy_canonical` 候选级解析同适用；被动获得=最简安全带（**三次简化，不留安全量**，见 §2）；「账本作为定价通道」作废（[40]③）；「更积极追逐战力以保血」不做（禁域）。
