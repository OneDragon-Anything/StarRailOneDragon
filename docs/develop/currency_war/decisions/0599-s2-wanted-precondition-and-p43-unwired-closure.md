# ADR-0599: T-161 备战攻击中低危修复包(F2 S2 wanted 前件快照化 + F3 P43 激活腿结构性不可接线登记)

日期: 2026-09-08
状态: 已实施(攻击报告 F2/F3 → 方案审修改后放行/拆半裁决 → 实施批交付;commit 候编排者统一门)

## 背景

备战阶段无前提攻击(prep_strategy_attack_20260908,对象 commit 68669549)两项中危发现:

- **F2**:S2 wanted 闭环无「在店 ∧ 可负担」前件——消费臂门 0 只复核「未持有 ∧ 未停手」,腿 2 直接卖燃料腾席重进店,重进后才知道缺员不在店面/金不够买:1★ 全额退金净 0 但件离席(压库+期权损失)+两趟开店/关店动画白烧。缓解边界:节点内重开不刷新店面,重进环自然停,损害有界、非正确性事故。
- **F3**:P43 连胜-息取舍已证未接线 + 处死名单常量 `WIN_STREAK_BREAK_INTEREST=2`(阈值源 auto-chess 常识、货币战争档金真值未核)仍定义在库,与 P43 已证数字(连胜账 1.3-2.8 金量级)冲突。

方案审(T161方案审.md)裁决:**F2 修改后放行**——「在店」判据禁止商店域字段现读(obs 对 spec 无商店域的阶段把 `state.shop` 清空,「没牌」观测真值 = ADR-0462;臂时点现读恒空 = 修复本身杀死闭环,阻断级发现 F2-1),必须置位时点快照 + 可负担臂时点现读;**F3 拆半**——死常量+死句删除放行(零行为),「P43 判据接线」结构性不可执行(§2.2 逐面封锁)。

## 决策

### F2:S2 载体扩四元 + 消费臂门 0′ 前件(方案审 F2-1/2/3/4/6 全落)

1. **载体**:`cw4_shop_wanted_pending` 三元 → 四元 `((位面, 轮次), 买因类, 残差名单元组, 在店快照)`。在店快照 = 置位时点「在店的缺员 (名, 费用)」子集;费用 = 卡面费用(游戏定义量,节点内不变)随置位快照,金**不**快照(节点内会变)。
2. **写点**(shop.py,`bench_full_buy_abandon` 同点):快照由调用位经 `_shop_candidates` **同一闭包**计算(方案审 F2-6:禁在 mandate 侧复刻第二份候选读法);口径 = M2 语义同名最便宜卡(不滤星,区别于 stockpile 1★ 过滤)、cost 假值兜 3(与排序键一致)、空名(识别失败占位)不进集。
3. **消费臂门 0′**(门 0 镜像后、门 1 前):∃m∈still_missing:m 在店快照 ∧ 可负担。可负担复用 `check_affordable` **①号本体**(单一源,禁第二份 affordability 谓词;与闭环最终买入在店内段要过的同一道闸同源——「激活时判得过的,重进后买入也判得过」,方案审 §1.3),金臂时点现读、费用取快照。不满足 = **hold**:零发射返回,S2 保留至节点推进自动失效、不置放弃态、不记重进预算——可负担腿可随节点内金入账翻真,早清错杀(方案审 §1.4 残差处置);「不在店」腿本节点确定性死(备战域无刷新通道)但统一保留零成本,过期规则保持单一 = 键失配(§3.2)。
4. **语义收缩申报**(本 ADR 必须承载面):前件把「不在店 → 不开环」定死,关闭今日的一条隐性通道——现行实现不在店也卖燃料重开,重开 visit 内刷新臂(自己的门)可能刷出新牌碰出缺员。修复后本节点该通道不再存在;跨节点狩猎由刷新臂在下节点常规 visit 自行承接(其门 = P40/P54 已证判据,不依赖 S2)。**S2 语义收窄为「所见义务的买入闭环」**——后续对抗批若重新发现「为什么不开环去刷店找」,以本节为准。
5. **观测配套**:新增 hold 计数键 `wanted_precond_hold`(事件帧粒度,发射位 = 门 0′ 拦截帧),区分「形态未发生」与「前件全拦」(攻击报告 H3 要求的分布面)。
6. **残余窗口如实入册**(方案审 F2-5,接受+遥测):付费刷新是终结 op,存在「置位后同 visit 末帧刷新 → 快照滞后一次牌面」竞态;损害上界 = 原缺陷同型(一次白卖+重进),自愈 = 重开 visit 置位点覆写快照。低危包不加刷新侧失效联动(会把刷新路径卷进批面,违背低危包定位)。

### F3:拆半收口

1. **放行半(零行为)**:删 `WIN_STREAK_BREAK_INTEREST`(cw_economy.py 定义)连同 `economy_score` docstring 内引用已删消费者 `_should_save_for_interest` 的死句(引用已删名的悬挂文档,方案审 F3-2)。验收 = cw_replay --diff 改动前后输出逐位一致 + 全库 grep 零残留。
2. **登记半(本节,不落码)三件**:
   - ①**激活腿结构性不可接线证明链**:P43 判据「破息保连胜 iff ΔV_streak(s,R,Δp) ≥ L」的引擎函数 `delta_v_streak`(statefn/vopt.py)签名硬依赖 Δp 与 p;Δp 通道被 **ADR-0516 禁胜率建模裁定**封锁(Δp/伤害折算因子均统计拟合量,非游戏定义量;V̄ 链已整链退役),全库不存在合法 Δp 生产者——refresh 决策面(R1 形式二可负担性,ADR-0516 后输入全为游戏定义量)/保留决策面(P41 卖出式 ΔP̂ = P38 集齐概率差,不能冒充战斗胜率)/凑息卖资格(bench 域不触板面)/卖牌仲裁(M4/燃料/凑息全 bench 域,唯一卖板面的换血臂 P61 已证严格支配)逐面核对见方案审 §2.2。支配性消参路线亦被 P43 自身数值带封死(P2 表小 Δp 域 ΔV<L,不存在零参数激活腿;可证的零参数结论在现行连胜全盲策略下已 vacuously 成立)。**接线是结构性不可执行,非工程未完成——「已证未接线」缺口以此定性关闭**。
   - ②**默认腿已承载**:P43 默认姿态 = 保息(§③「破息是需要连胜账+战力 EV 双证成的例外」),与现行息线判据方向一致——默认腿由现行息线判据承载 = 证明正确默认,非缺陷滞留。
   - ③**P48 联动登记**:P43 §⑤ 旧口径清算(本常量处死 + 「实现侧替换为本文判据属重构批联动」)按其「消费方引用本文此行即完成登记」条款,以本 ADR 引用落账。
   - **禁**做「等标定后打开」的 fail-closed 接线占位(strategy-work §3:「A/B 已判决却默认关挂起」任何档都禁,悬置占位形态不合法);**连败止血侧本批禁开**(economy.md §6 社区共识未证 = 只能当假设立命题,且涉 hp 通道 = 违宪面)。

### 已考虑选项

- F2 用攻击报告 §5 原案「两布尔」:否——单一布尔丢成员粒度,无法支撑 ∃m 判定;可负担若做置位快照布尔会把「假」钉死在置位时点(节点内金入账翻真被错杀)。改 (名,费用) 子集 + 臂时点金现读(方案审 F2-2 修正)。
- F2 前件用臂时点 `state.shop` 现读:否——obs 备战阶段清空商店域,判定恒假 = 把闭环永久闷死,比原缺陷更重(F2-1 阻断级)。
- F3 按 P43 判据落码接线(攻击报告原案):否——Δp 无合法生产者(登记半①),fail-closed 占位开关违反策略开关生命周期(strategy-work §3)。拆半收口(方案审裁决)。

## 后果

- wanted_* 计数分布预期变化(挂测,攻击报告 H3):`wanted_precond_hold`>0、「不在店/买不起」形态的 `wanted_leg_fuel_sell`/`wanted_reopen` 下降、`wanted_abandon` 不增;末端量(hp/胜率)预期不动(原缺陷损害有界,不构末端量验收线)。sim 计数方向批(n≥30 同池指纹)与实机 wanted_* 分布复核归编排者续派,不在实施批验证面。
- **S2 语义收缩**为「所见义务的买入闭环」(决策 §F2.4);测试面既有直调用例按锁纪律改 helper 种快照转绿(禁绕前件保绿),前件五态单帧锁 = test_cw_prep_flag_machine.py `TestWantedPrecondition`。
- 零行为面申报:F3 删除半经验证逐位一致;F2 对商店域回放不可见(消费臂在备战域,cw_replay 只重放商店决策)——sim 结构性申报 = F2 判据层改动 sim 可见(可 A/B),F3 结构性无行为差异(A/B 无意义)。
- `economy_score` 本体全库零调用者(decision_v2 删除后成死函数)= 死码清理候选**另批**登记,本批不扩批删函数(方案审 F3-3:删函数需独立零消费面复核批)。
- 文档面边界:12 篇 strategy as-built 本批禁碰(批面裁决),as-built 语义同步随编排者统一门处置;本 ADR + 代码注释为当前语义单一源。
