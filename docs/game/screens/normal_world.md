# 大世界(normal_world)

游戏探索主画面。角色在地图上自由移动、与 NPC/物体交互、追踪任务、从这出发进各玩法(战斗 / 菜单 / 传送 / 玩法入口)。**锁光标画面**(`pc_alt=true`,`click_game` 点 UI 需传 `pc_alt=True` 先按 Alt 解锁光标)。

## 何时出现 + 状态流转

- **入口**(从哪来):登录进游戏 / 战斗结束返回 / 菜单(背包/手机/地图)关闭 / 传送落地 → 落到大世界。
- **出口**(动作 → 下一态):
  - 走到 NPC/物体交互范围 → 出现 `> 名字 <` 提示(`移动交互-单行/多行`)→ 按 F 交互 → 进对话/玩法。
  - 遇敌 / 秘技攻击 → 战斗画面 `battle`。
  - 开地图(M)→ 大地图 `large_map`;开手机 → `phone_menu`。
  - `列车补给`弹窗(每日)→ 领取 → 关闭回大世界。
  - 传送(指南/地图)→ 加载 → 落目标地图大世界。

## 识别特征(稳定锚点)

- `pc_alt=true`:大世界锁光标(强判据)。
- **右上角色图标**(template `ui_icon_01`,pc_rect 1800,0-1900,90):稳定模板锚点(analyze 命中 conf 0.89)。
- **右侧队伍栏**:4 角色头像+名称竖排(1770-1873 / 275-655)+ 秘技点数 + `状态效果`(TECH_STATUS text)。
- **左下 UID**(26,1040-160,1063):经 `fill_uid_black` 灰色遮挡(打码),截图看不到数字。
- 易变(勿当特征):角色名/等级、任务文字、地图区名(如"鸽川区")、网络延迟("I 49ms")。
