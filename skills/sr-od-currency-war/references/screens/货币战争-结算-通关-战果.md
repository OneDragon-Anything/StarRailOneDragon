# 货币战争-结算-通关-战果

## 画面简介

通关后终局结算的第一页：在「货币战争-结算-通关」点「前往结算」进来。标题「挑战成功」，下方是结束时的小队生命值；中部左右两栏，左栏「对局评价」和大号评级字母，右栏「当前职级」和晋升后的职级；底部是「下一步」按钮。点「下一步」进入终局结算的下一页（对局详情）。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-挑战成功 | 标题「挑战成功」（画面身份锚） | 纯显示 |
| 文本-小队生命值 | 「小队生命值 N」，对局结束时的小队生命值 | 纯显示 |
| 标识-对局评价 | 「对局评价」栏标题（画面身份锚） | 纯显示 |
| 文本-当前职级 | 「当前职级」栏标题，下方是晋升后的职级 | 纯显示 |
| 按钮-下一步 | 底部「下一步」按钮 | 点击进入终局结算下一页 |
