## 0. 假设

- **H1(主)**:缺口差分项上臂后,P1 出口 hp 分布整体上移。**效应实现折扣预核算(v2)**:+19 血(P32.2)是全部档≤2 局被推过档的 boss 帧下界;可实现均值差 = +19×(1−p_off)×实现折扣,折扣带 [0.5,1],p_off=off 臂 r7+r9 帧成型档组达成占比(实机参考 4/7≈57%,sim 实测跑批时先记)→ **预期均值差带 [+4, +8.2]**。M1 门取带中值 +5(见 §2)。
- **H2(机制,过程量,v2 口径)**:实验臂「达成意向引擎成型档组」的过程量上移——①达成轮次分布(r7 前达成占比↑/达成轮中位数前移);②达标轮占比(r4-r9 各帧已达成的比例)。口径与设计件 §1.2 单一源(成型档组,非 max 档≥3);**按线分层输出**(仙舟/列车/DOT/希儿),兼喂 V_tier 线分权重标定(设计件 §8-6)。
- **H3(传导)**:出口 hp 上移传导为 P2 存活轮中位差 ≥ +1.0(沿 W793 口径;不依赖 W802 成败,W791 深度决定论)。
- **H4(G0 前置,v2 降格)**:所选口径实现无 bug 且在七局实机档案上复现仙舟线的 59-72/9-48 分层。**判定力声明(v2)**:七局成型局全为仙舟3,复合口径 vs max 档口径在七局上结构性不可分辨——G0 通过**不构成**列车/DOT/希儿线口径的验证;该线阶跃位置判前未证,归 H2 过程量 A/B 内观测。
- **H5**:散装守门触发局的板面质量不劣化(不因守门买不到牌而空转)。

## 1. 臂与规模

- **对照臂(off)**= 主仓 HEAD(W802 κ 折扣开关默认关回常数罚;W803 四件零落码)。
- **实验臂(on)**= 伞开关 `p1_tier_push_enabled` 开(设计件 §2 全项:缺口差分项+死线权重+散装门+r6 预算承诺;血线辖域门 = 设计件 §3⑤ 自带最小实现);子旗标消融归因批后置,不进主批。

  **功效重算(v2,面 6.3)**:配对差 σ_d ∈ [20,25] 血(七局出口 1-72 散布/W793 off 臂失血 54.29 同量级)。最劣格 = 门值 4 血、σ_d=25、零差修剪 50%(双臂同达成型档组的局配对差恒 0):n=500 → 有效非零对 250,d=0.16 → 功效 ≈ **72%(不够)**;n=1000 → 有效 500 → 功效 ≈ **94.7%**。故 500 不够,取 1000/臂(最劣格 ≥94%;门值 5/σ_d=20 的有利格 >99%)。

## 4. 失败分流(三选一兑换,禁第四态)

- M1-M3 全过 → 开臂(翻默认值,盘点 hash 锁之外行为锁组)。
- M2 过而 M1/M3 不过 → 方向对量级待定 → 调常量重跑(V_tier 线分权/权重/死线形状标定批),不悬置。
- M1 双败或 M2 不过 → 概念定谳 → 删码留 ADR(记录「存量目标型杠杆在 sim 无改善」证据,与 p1_iface ADR-0487 并列)。

## 5. 单帧锁清单(开臂批落码时一并落)

1. 散装守门:**r4 起**、`max_bond_tier(deployed)<2` 帧拒「对任何意向体系缺口零增量」的纯散件买入——锁语义「[31] 硬约束」非锁具体卡名;首张豁免(与缺口差分同一 dist 函数)锁防自锁;
2. 缺口差分排序:同费档下「使意向引擎缺口缩小的候选」排序高于「线外正增量候选」;**存量差分语义锁**:同帧重复计算 ΔG 幂等(无跨帧累计账本);
3. 死线权重:r6 帧缺口差分项权重 > r3 帧 > r8 帧(r8 残差仅 boss 分量);
4. r6 预算承诺帧:EV 门过时发放建档专项支出授权(EV 门式引 P26/P32.2);血线恶化段(hp<40)授权让位 [18] 止损辖域(设计件 §3⑤ 最小实现);
5. 锁线语义不变:缺口差分项只改排序权重,不改 v3_intention 锁定状态机(锁 ist 快照行为);
6. off-lock 通道零触碰:κ 折扣为 W802 单一实现,本设计锁内不含任何对该常数的改写断言。
