## 背景与问题

planes=2,invest on):**never-2 残差 9 局(3.0%,SE≈0.01)、strict_mal 20
(6.7%)、own_gap 2([136,269])**。逐局归因(exempt 细目 + shop_waves
供给史):

- **门内集错位主灶(230/269/293,次灶 68/136)**:派生配方对(支持度
  top-2)与终局成型体系错位 → 缺件不在门内集(230 r1 青雀金 11-12×3/
  r2 忘归人金 22、269 r2/r6 艾丝妲金 3-20×6、293 r3 姬子·启行金 20/
  r8 姬子金 15、68 r1 艾丝妲金 5);
- 不来牌 F1(43):distinct 缺件全程 0 次出现,供给侧非差分根,不修;
- ≥20 段评分层空轮(82 主灶;68/230/293 次灶):W173 C 形态在门辖域
  外残留,归 W181 方向③(评分谱系)另立批;
- own_gap 2 局(136/269)=**W181 方向⑤复核观察:复活记档**——两局
  target 全程在 pair 辖域内(非 W181-93 的辖域缺失型),机制=演进事务
  CompTransaction 链持续拆板/卖出,板面长期 dep=∅(136 r7 两笔三月七
  卖出走演进事务通道,ADR-0373「不辖」清单明文豁免的通道)——
  归 evolve 谱系统筹,本批不实装(任务书预设);
- cap 先占:n=300 **无直接证据**(274 的「cap 拒」经 at-eval 插桩证伪
  =同卡重复评估,cap 实被目标件自己占用);仅 W181 n=100 证据
  (68 r1 三月七案)。

## 决策

**零修法(策略零改动)**:方向①(门内集扩展)与方向②(cap 体系偏好)
全部可实装变体被 sim A/B 否决(证据全表见下),代码全量回退,不在
registry 留通道。残差 9/300(3.0%)记为门谱系修法的**地板**;后续
批不得在无新证据时重试同族修法。
