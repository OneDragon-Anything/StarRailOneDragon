## 1. 四层结构

```
知识层（资产）：注册表 + research 文档 + 用户裁定 [1]-[42]
数学层：proofs/ 证明集——决策规则的期望保证；未证不落码
```

权限规则：决策层**禁止自带数值假设**——任何「多少算够」必须来自 (a)数学层证明、(b)标定批常量、(c)用户裁定。知识层禁止反向引用决策层。

## 2. 决策问题的形式刻画

每备战期（节点前），状态 S 下从动作空间 A 选一个可负担子集：买（含满栏合成例外语义）/ 卖 / 刷 / 级（[41] 整买纪律：批 k*=⌈max(0, need−xp_cur−4n̄)/4⌉ 次，P48）/ 锁（商店锁，跨节点保牌）/ 装备（穿戴/合成/转移/回收/工具）/ 部署（上场/下场/换位/换排）。

局内事件决策点**全量进第一版**（用户裁定 2026-08-31：必须全部，不能漏，避免候选面推倒重来）——完整目录见 §4.9，规格骨架见 [08_events.md](08_events.md)。

统一决策程序：每个动作 a 有金当量价值 V(a)（由 §4 各机器按动作类型给出）与成本 C(a)；预算与息线约束（§4.4）过滤；可负担动作按 V−C 与优先序执行；空集合法（不动）。【已裁定】[36] 未定型期决策单位=件、无默认方向。

### 4.2 终局证据门（唯一线级选择）【已裁定】——通用目标态定义

score(line) = P_complete(下一成型档缺口 | 剩余回合、金日程、等级场景) × w(line)。

- 完成概率 = **P38** 证明件（五层模型，已对抗收口）；
- 两臂开门：完成概率阈值臂 OR 环境主导比臂（ENV_DOMINANCE_RATIO【拟，标定批】）；
- 权重 w：默认全 1；偏离只经机制层知识（词缀/投资策略的克制亲和，载体 = MECHANIC_SYNERGIES/MECHANIC_COUNTERS 注册表）或用户口述；**频率永不入权**（[38]）；
- 候选侧可达性：COMP_LIBRARY 登记 external_deps（局外依赖形态）；证据门对其作**候选侧可达性软通道**——试用账号零达成的形态在登记位扣减（知识登记，非硬过滤，同 downgrade_paths 先例）；
- 平局：与当前持有重叠件多者 > 现持有 core 数多者 > 注册序（确定性，无随机）。

**目标态的通用定义（R78-2 通用化重写；替代旧「P2 中间形态不定义 + P2 补条」形态）**：

> 证据门的评分对象恒为「**当前生效档表的下一成型档缺口**」。每条线在 COMP_LIBRARY 登记**分段档表**（segment tier tables：每段一个 form_tiers 档集）；**段索引由节点日程派生（查表键），位面只改变档表的来源，不进任何谓词辖域**——宪法第 2 条的执行形态。规则：
>
> 1. 当前段的档表非空 ⇒ 目标态 = 该段下一成型档缺口，P38 五层照常可评；
> 2. 当前段的档表为空（如过渡线在进入下一段前的窗口）⇒ 目标态 = **终局承诺档缺口**：当前线是终局线 ⇒ 该线终局档缺口；当前线是过渡线（无终局段档）⇒ 换线机器产出的终局线承诺档缺口（触发 = §4.3 第四触发）。
>
> 这样定义后，任何段内证据门恒有评分对象，**不存在「目标态无定义」窗口**——旧 R78-2 作为位面特设补条消解为上述两条通用规则。

该重写的证据基础（旧 R78-2 引理，不等式级，登记于 IMPL_FIX_LEMMAS R78 对照表）：若目标态缺口=∅，目标件支出上界塌缩至插件有限项，期收入 ≥ 基础 3 金 ⇒ 金位单调不降，有限期内越过死时金 50 阈线，战力停滞、血量期望按节点税单调降——「金堆积→战力停滞→被节点税磨死」死型（FM-1，证据 = P2 失败模式深潜报告 2026-09-02：sim D 桶 67.8%【拟】/实机死时金≥50 占 81%【拟】/P2 段支出收入比 0.464【拟】）。

挂账（不能证部分，三形态章程三要素全）：分段档位登记批（owner=编排者排期）；「承诺档在本段经济下可达」不预设——不可达时由换线机器既有「不可达→生存模式」兜底；兜底触发载体=换线评估事件（评估间隔由 W 决定，**W=None 期承诺档可达性漂移零检测窗口，该期兜底不生效**，敞口如实申报）。

**开闸顺序约束**（R81-1 同款先例）：分段档位登记批**先于或同批于** W 激活——登记批缺位期「可评目标态缺口集=∅」结构性恒真 ⇒ 第四触发前件恒真 ⇒ 每个命中成型里程碑的局必触发强制换线评估、对终局线反复强产噪声评估 = 零治理价值死规格面，取激活前置条件消解。

### 4.3 换线机器【已裁定】

三触发：

1. **段边界触发**（通用化：原「位面边界」）：日程跨段时强制换线评估——段索引由节点日程派生，位面边界只是最常见段边界，不作谓词辖域；
2. **不可达触发**：当前线 CDF 分位数恶化（P38 输出）；
3. **严格更优触发**：同量纲（切换成本进金日程变薄后仍胜出）。

证伪记忆粒度 = **(line, 触发原因) 分桶**（用户裁定 2026-08-31）：被证伪的组合不再因同因重开；环境变量变化只解锁对应桶。无可达线兜底 = 生存模式（[31] 三级 + 名单件照买），无默认方向。

**第四触发（通用化重写）**：前件 = (当前线命中 [13] 成型里程碑) ∧ (证据门对本线的可评目标态缺口集=∅ 或不可评) 连续 W 备战期；后件 = 以段边界触发同款语义强制产出换线评估（候选 = 终局线承诺档，评估消费 §4.4 消解协议同款为挑战线单独生成 L(r) 日程）。W = 常量 `P_IDLE_SWITCH_W`【拟，带 CI [1,3]，None 不触发】。

覆盖论证（不等式级，沿用 R78-2 引理通用形态）：三触发在「成型→段边界」窗口构造性沉默（边界触发仅边界帧 / 成型后 CDF 单调改善 / 严格更优在目标态不可评时不可求值）；第四触发时刻 t_f+W 在窗口长 >W 的局上严格提前支出恢复、≤W 的局上不早于段边界触发 ⇒ 覆盖单调 ⪰ 三触发、零新增风险。「不可评」分支 fail-closed 声明：不可评分支 = **观察级**（触发计数遥测），其支出恢复兑现待依赖标定齐备，禁与 ∅ 分支共用「覆盖」语义。

P16 换线判据（E_rounds 超几何精确口径 + θ 滞回 + D_min 驻留）是三/四触发后评估的数学载体；`should_switch_e` 结构性休眠（生产零调用点 + 三轮 AB 换线 0 起）⇒ 本机器必须接线（新核落码项），接线载体 = [09_architecture.md](09_architecture.md) 的契约面。

### 4.4 经济引擎【已裁定方向，R14 无预编节奏；数学件 P39/P40/P43/P47/P48】

- **金日程**（gold schedule）：逐轮收入预测（基础分段+连胜档+利息）+ 已承诺支出（件成本/升级计划）→ 每轮可支配预算；供 P38 ⑤层与所有 EV。
- **升级决策**：arm1/arm2 双臂（02 §3 M3 行）；[41] 整买纪律接线（P48）：何时买 = 双臂门过 ∧ 金位 ≥ 动态目标线 **S = 批成本 + floor_resolved + Σ(窗口预留卡价) + E[刷费]×2**【推，P48 ②】（恒>50——超息囤钱是常态路径；资产形态口径：金位按「裸金+活期卡退金」计）；>50 溢余在 S 之上才「随时花」（[17]×[41] 联合口径：汇率判据 V_a > ρ·x/Ī + L，P48 ③）；多目标并队按每金价值率 ρ_i/S_i。
- **刷新决策**：P40 三层门（01 §3.4）；预算前提 = 刷后守息线（[3] 精确化口径；现行落码 = 息线 floor g*+ρ，P54）。消费限制注：E[refreshes] 现仅单卡版、多类合格集 DP = 待办——「差 2 张**不同的卡**」类缺口过证前走单步门 + 保守带。
- **连胜-息取舍**：[19] 收口后变量（连胜在手/来牌/息差，**无血量变量**，[39]②），P43。

### 4.10 机制突变层（改机制的投资策略/环境）【已裁定方向：一等公民】

**原则**：决策机器**禁止直接读基础机制事实**——一切机制输入经「基础值 ∘ 已激活突变」解析后消费（**resolved input**）。突变登记 = 知识层注册表 INVEST_MUTATIONS。

- **登记三分态**：resolved（可解析）/ abandoned（用户裁定放弃建模——desc 无数值一律放弃不实机查，保可见性不进 resolved input）/ 未登记（=知识缺口，采集后入表，不静默忽略）。
- **解析语义结构**：每突变登记为（操作数，合成律[min/max/add/互斥]，状态依赖[计数器/条件]，时效[永久/计数窗/条件移除]）；同操作数多突变按合成律合成；互斥型登记位声明（首个生效，后续 suppressed）；异构操作合成序按操作数分层（override 先于 multiply，层内按注册序）；未登记态运行时检出 = 保守降级（按基础值消费 + 告警，不静默）；消费点读合成后的单一 resolved 值，禁止各机器自选合成方式。
- **多源声明**：突变源不止投资卡——角色固有技能（银狼升费）、任务奖励皆可改状态；INVEST_MUTATIONS 为多源效果突变登记，辖域不限于投资。
- **突变分类框架**（按改写的操作数；消费点 = 本篇机器）：经济参数族 / 收入与息律族 / 概率表族 / 池构成族 / 板面谓词族 / 商店行为族 / 难度与节点族 / comp 定义族 / 任务系统族 / 工具发放族 / 战力族（~155 条——不进经济 resolved，E1 定价走权重/克制通道）/ 资产发放族（~60 条——非金流，E1 定价走组件缺口通道）。逐族在册例与消费机见 01_strategy_layer §4.10（塌缩素材，登记位不变）。
- **池结构突变语境**（消费 P38/P40 时按语境重算）：银狼升费（按当前可见档取 q）/飞光·映月变费/晋升名额/专家解锁入池（v_c 重算）/黑塔纪元（216 张特殊池，P38 全模型降级声明）/昔涟诗篇类非 5 槽商店（SHOP_SLOTS 时变）。**池构成硬突变 ⇒ cw_shop_odds 概率表/V_comp 表/p̄/E[refreshes] 整体重生成，不得沿用突变前表**。
- **E1/E2/E15 选择决策的机制升级**：三选一评分 = 台账价值 + 突变价值（对 resolved 输入做差分定价）+ 战力账（→权重/克制通道）+ 资产账（→组件缺口通道）+ 难度账（→环境臂）+ 信号分层（A3）；数值走知识登记与标定批，禁拍值。
