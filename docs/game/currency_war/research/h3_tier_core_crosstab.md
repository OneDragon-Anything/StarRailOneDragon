# H3 档内交叉表:档位 × 核心在场数 × 败率(实机语料,0305 件1)

> 证据等级:**实机 replay 语料统计**(n=191 行,99 局语料池;含
> node_type 标签)。ADR-0304 悬置「H3 档内细分」的原始理由=「需实机
> core trio 在场×败率交叉表」——本文即该表的首版。结论:**低/中档
> 档内平坦(0304 悬置正确);梯度集中在 tier≥7 高档,core2 相对
> core1 败率减半(50pp),但小样本(n=17)**。

## 口径

- 数据:`.debug/temp/currency_war/replay/outcomes.jsonl` 全量 191 行
  (普通战斗 83 / 奖励 68 / 遭遇 23 / boss 17;弃局 0 行);
- 档位 tier = `recipe_tier(board_before)`(`RECIPE_FACTIONS`
  =仙舟/持续伤害/列车同行/护盾 的档位和),分桶 <5 / 5-6 / 7+
  (配方基础线 5、满线 7);
- **核心在场数 core(代理口径)** = #{f ∈ 核心阵营 : board[f] ≥ 2}。
  核心阵营 = {仙舟, 持续伤害}(基础配方 3仙舟+2DOT 双引擎)
  + 列车同行(仅 tier≥7 计入,渐进引擎);
- **数据边界**:board_before 键=阵营/特色名,**角色不可见**——
  core 是「关键阵营凑档 ≥2」的代理,非真 core trio(爻光/藿藿/
  饮月;三人皆仙舟阵营,但仙舟共 10 角色无法从阵营档数反推角色)。
  trio 语义的强代理需遥测侧补 deployed 角色名(改进方向,见文末);
- 败 = `not killed`;排除 intentional_fold(killed=None)行;
- 各档位桶内轮次均值可比(tier7+ 三格 6.5/6.1/6.0),梯度非轮次
  混杂;plane 1/2 混合(语料池现状,未分层——tier7+ 各格均含两
  位面,方向不受单一位面主导)。

## 判读(对照 0304 的 15pp 判据)

1. **低/中档(tier<5、tier5-6)档内平坦**:同档内 core 差
   10.6pp / 8.0pp(<15pp),且方向不定(core1 略高于 core0,
   噪声带内)——**0304 对低/中档的悬置判断正确**:档间阶梯
   (e0→e1→e2)主导,档内核心维无独立信号;
2. **高档(tier≥7)梯度显著**:core1 100% → core2 50%,
   **差 50pp(>15pp 判据)**,方向与「空壳档位」假设一致——
   tier7+ 但仙舟/DOT(±列车)未凑双档 = 用列车/护盾散件堆出的
   空壳满线,败率最高;core 凑齐则减半。**但 n=4/12/1,小样本**,
   结论强度=方向性旁证,非定论;
3. **消费建议**(供评分层/策略层后续):
   - 档内细分项若实装,应**只挂在 tier≥7 档**(满线空壳惩罚),
     低/中档不加(平坦,加了是噪声);
   - sim 战斗层 Δ 池只按 rung 分桶(ADR-0304 已证),该档内细分
     在 sim 不可验证——消费路径仍是实机判读锚点,或 Δ 池扩
     「tier7+×core」桶(需该桶样本 ≥10/格,当前不足)。

## 真 core 口径首版(2026-08-24 升级;deployed 同轮联结)

「遥测补 deployed 角色名」已核实**不必改采集端**:decisions 行
`state.deployed[].char_id` 历史覆盖 94.1%,按 `(run_id, round_num)`
同轮联结 outcomes 命中 169/170(all)/61/62(battle)——角色名
一直躺在语料里,升级是纯离线活
(脚本 `.debug/temp/currency_war/cw_dev/h3_trio_crosstab.py`,
报告 `h3_trio_report.json`,随语料增长可重跑)。

**口径两版**:①对全体 comp 取 core 最大重叠——**弃用**(任何
阵容都撞得上某个 comp 的 core,指标膨胀:无 core0 格,vs 阵营
代理 core0 n=64);②**主导 comp 锚定**(板面阵营与 comp 声明的
factions 最大重叠者为该局主导 comp,数其 core_chars 在场数)——
正口径,产生 core0 格。

**判读(诚实边界)**:

1. **tier7+ 梯度结论在新口径下证据不足**:battle 口径各格 n≤2,
   阵营代理版的「core1 100% vs core2 50%」在真 core 口径重排为
   core1 n=12(75%)/core2 n=1——**方向不再可叙述**。上文的
   50pp 梯度结论**证据等级降为「未确认」**(两口径的 core 定义
   不同,格子不可直接对照);
2. **意外信号(仅登记)**:tier5-6 出现 core1(78.3%,n=23)>
   core0(57.1%,n=14)的反向差 21pp——与「更多 core 更少损失」
   预期反号;混杂因素未控:同桶内后期轮 core 更全且敌人更强
   (轮次/难度未分层),不构成结论;
3. **结论**:档内 trio 梯度的裁决仍需语料增长,脚本已就绪随局数
   自动收敛;「档内细分只挂 tier≥7」的消费建议维持,但前提
   (tier7+ 有独立梯度)当前未获真 core 口径支持。
