# 设计对抗报告（无前提）

> 攻击对象 = 本目录 design.md / landing.md。判定三档：成立（已吸收进设计）/ 部分成立 / 不成立（附理由）。处置节指针 = 吸收后的 design.md 节号。

## 核一·无前提攻击

### A1 刷新次数闸「剩余 ≥2」令开局单次数帧永不刷
- 攻击：开局帧若剩余次数 = 1，`≥2` 闸使其永不建议刷——比旧判据（零价值槽必刷）更保守，直接弱化本迭代的刷新改进目标，属设计自伤。
- 判定：**成立（已吸收）**。机会成本建模整体删除：同分布假设下未来帧候选分布与当前一致，「留给以后」无期望优势；「局内信号帧刷新价值更高」登记待证假设，不入 v1。闸放宽为 `≥1`。→ design §2.7
- 附带修正：原「33 百分位」阈值在本表上有 29 条 0 分立场值，分位会沉到 0 附近令判据失效（0 值堆积下分位数不稳健）——改为**全表均值**（重掷后帧最好期望 ≥ 单抽期望 = 均值，取均值 = 保守向不高估）。→ design §2.7

### A2 换算率与强度档比例无推导
- 攻击：「1 金 = 1 分」「S=100/A=60/B=30」均无推导，比例改动会翻转全表定序——攻击者可主张标尺任意性。
- 判定：**部分成立（已吸收）**。两项性质不同：1 分 := 1 金等价是**归一化约定**（定义标尺单位，非语义拍值，改它不改变任何序）；S/A/B 比例是**立场拍值**（改它改序），按【拍】形态申报、带锚定理由、用户裁决窗 + 宪法一确认义务（强度类行）。标尺内定序对比例的敏感度 = 立场承担，设计如实申报。→ design §2.2/§2.6

### A3 概念股随机赠卡「平均档」低估
- 攻击：平均档忽略「找牌概率提高」「初始简易装备」，且白得随机卡的价值分布右偏（出核心是大赢），平均口径系统性低估概念股。
- 判定：**部分成立（申报吸收）**。低估向如实申报（design §2.4/§2.11）；不做补偿系数——补偿是第二个拍值，且概念股价值大头由方向分承载，赠卡只是附加项。右偏担忧入「实机判读后调表」池。
- 附带修正：成员集口径固化——该阵营注册成员（`chars_by_faction`，`cw_chars.py:220` 在册）∩ 未排除候选阵容名单（core∪shared∪transition）的档位算术平均；无成员在册 = 0。→ design §2.5

### A4 降格帧语义缺口
- 攻击：旧口径 demoted_endgame 帧强制无对齐（`cw_events.py:150-152`，防已放弃方向经资产信号复活）；新设计未声明降格帧方向分口径，实现者将自行发明。
- 判定：**成立（已吸收）**。降格帧按未锁线先验口径（忽略锁线）：新模型方向分不消费资产信号，「复活」通道结构性不存在，只需忽略已放弃的锁线。→ design §2.4

### A5 全表均值阈值随表漂移
- 攻击：阈值「构建期派生」依赖表内容，手工维护数字必然与表漂移（项目两次实证 design↔landing 失同步）。
- 判定：**不成立（设计已防御）**。阈值 = 表的派生常量（构建期计算，非手维护值），单一源 = 系数/立场表本身；这正是 design §2.7 声明的形态。

### A6 蓝海随机环境期望、概念股找牌加速未计
- 攻击：v1 现金/方向分对这两处确定性低估，均值阈值随之偏低，连锁影响刷新判据。
- 判定：**部分成立（申报吸收）**。低估申报维持（均匀分布假设未证 / 刷牌概率模型未接入，design §2.11）；均值阈值含全部立场与机械分，低估项对其影响 = 二阶小量，不单独修正。

### A7 经济过热族 fail-closed = 0 分低估
- 攻击：扑满化增益真实存在，估算注册表零有效估计 → 现金 0 + 立场 0 = 总分 0，与时代族同级——低估但同口径（未建模 = 不加分）。
- 判定：**不成立（口径一致）**。与时代族裁定同构：未建模项不凭直觉加分是本设计的诚实性纪律；补参后自动进现金分。已在表 3 理由行申报。→ design §2.6

### A8 混轴同序能力丢失
- 攻击：旧设计经济引擎策略卡（S2）与经济环境共享域带 111-119 实现「跨轴同序」，删除后跨轴比较能力丢失。
- 判定：**不成立**。投资环境屏只出环境、投资策略屏只出策略卡（词表按屏拆类，`cw_vocab.py:756/781` 直调），三选一帧内同质，不存在跨轴比较场景；「共享域带」是旧结构的无消费能力。

### A9 `candidate_faction_universe` 成孤儿
- 攻击：删除 env 全集门后该函数唯一消费方消失，删除清单未列。
- 判定：**成立（已吸收）**。全仓 grep 直调核实唯一消费方 = `cw_events.py:278`；随批删除；`candidate_char_universe` 现役消费为零同批查证。→ design §2.10、landing 3.2

### A10 立场表「各 10」粗粒度行
- 攻击：战争边疆（P3 战斗全变遭遇）等 13 条合并赋 10 分，粒度过粗，个别条目可能显著偏离。
- 判定：**部分成立（申报吸收）**。粗粒度 = v1 显式申报的粗化，表行理由已写「逐条重拍留实机判读后」；合并行降低初版裁决负担（29 个数 → 分组），偏离面由实机判读驱动重拍。

### A11 定稿试读（实现者视角逐阶段）
- 攻击：凭 landing 3.1 能否直接开工？——签名、口径、表、校验、测试清单是否全给定。
- 判定：**成立（已吸收）**。三处未定语义在对抗中定死：decide 签名（§2.9，意向解析留 flow 与现役同源）、随机赠卡成员集口径（§2.5）、降格帧口径（§2.4）；构建校验（立场表覆盖判定）补全判定谓词（无阵营 ∧ 不在 ENV_GIFTS ∧ 不在 ENV_ECONOMY，§2.9）。

## 核二·规范遵循

### A12 宪法一（禁战力建模）
- 进化算法/战力飙升/战力提升为强度效果——立场分是对它们的**登记**而非**建模**（bot 不计算强度，用户登记值），且硬闸门义务（逐项用户确认）经 3.1 裁决窗兑现。判定：合规，义务已在 §2.6 显式化。

### A13 宪法二（位面只作参数）
- 现金分的位面到达权重 = 查表键（沿旧，合规）；方向分/赠卡分无比面字面量。判定：合规。

### A14 数字三形态
- 现金分 =【注】+【拟】（沿旧注册表申报）；方向/赠卡系数与立场分 = 【拍】新形态——旧表自称「知识判据定序器」实为拍值未申报，新形态命名更诚实。【拍】为宪法五新立形态，已在 §2.6 申报依据。判定：合规（形态章程增补归正本更新批）。

### A15 引用寿命
- design/landing 引用的符号/路径逐一核存在性（cw_events.py:26/150-152/278/436-437/570-572、cw_investments.py:1003-1006/1472/1607-1610、cw_chars.py:28/220、cw_vocab.py:756/781、cw_comps.py:546/1202/1287、cw_invest_data.py:379-381/392-393/403/412/419/429/445/110/111/112/122/123/124/135）——全部直调核实。判定：合规。

## 核三·治本核验

### A16 归层成立性
- 根因 = 分层语义（policy 驻 kernel，宪法五）+ 表示（多标尺层次压制）。本方案同时动两层：所有权迁移（治分层根）+ 统一标尺（治表示根）。判定：治本，非症状补丁。

### A17 逐件修质疑（跨件半问）
- 「一次只迁一个画面 = 逐件修？」——逐画面节奏是宪法六用户裁定；且本批把跨画面共用面（线价值/赠卡/金换算三模块 + decide 接口）一次定形，投资策略屏批直接复用，不存在同族问题各修一遍的形态。判定：不成立（裁定豁免 + 共用面一次定形）。

### A18 旧「付费期权 < 白得」序丢失
- 攻击：GIFT_FLOOR_ADVISOR_CORE < GIFT_FLOOR_CORE 的序随常数删除而丢。
- 判定：**不成立（已吸收）**。advisor 档分 × 0.5 承载同序。→ design §2.5

## 结论
攻击收敛：11 项核一发现（4 项成立已吸收、4 项部分成立申报吸收、3 项不成立）+ 规范/治本核验通过。设计定稿前置条件：立场系数表（表 1/2/3）用户裁决。
