# 银枝群攻(B 级,贝洛伯格)

> V4.4 合集 76807134:B 级。攻略直读 [77006068](https://www.miyoushe.com/sr/article/77006068)。
> ⚠️ V4.4 贝洛伯格代表 = **银枝**(非布洛妮娅;布洛妮娅/鸭鸭是通用辅助)。

## 机制(怎么 work)
银枝 V4.4 **离开能量羁绊**,只补偿一点攻击力 → 用"**轮椅通拐**"(5 辅助 + 符玄)强行抬。自己银枝带风套频繁自拉条。**群攻保留**(助力球提升能量回转)。

## 成型阵容
银枝(风暴潮+冷笑话+风暴潮/鞋/永动机)+ 杨叔/主角/缇宝/花火/千冶·刃(5 通拐)+ 符玄(绝对热量)+ 翡翠(3 群攻,爆伤+速度)+ 知更鸟(鸟,拉条+加攻+增伤+10% 幸运)。

## 成型节奏
1. 前中期用**椒丘 + 星期日(周日)**替老杨 + 主角;椒丘治疗 + 刃泡泡枪保生存。
2. **必须找到 3 星银枝**(否则后期伤害不够)。
3. 3 星银枝或 7 张+ → 上等级,踢椒丘周日换最终阵容。

## 装备
- 银枝**火力风暴潮 + 冷笑话引擎(+风暴潮/鞋/永动机)**。
- 符玄**绝对热量**;刃 泡泡枪+钻地弹/追逐星辰+胜利之旗。

## 弱点 / 注意
- 失能量羁绊后**几乎没有伤害增幅区** → 阿瓦隆/天地乖离开辟之星/能量转补(或能量转给银枝,鸟换周日)。
- **适合对群;长时间对单输出大幅下降**(助力球也救不回)。
- 自动战斗迷迷可能拉杨叔(需手动)。

## 变体:贝洛伯格核弹流(杰帕德,V3.7,❌娱乐)

> 源:BV1XECQBVEot《一拳超人核弹流杰哥》(发布 2025-11-16 · V3.7)转录。⚠️ **UP 明言「更多娱乐玩法」「上分没阿雅白厄轮椅,但一砸 100 亿很爽解压」—— 非上分,核爆娱乐**。

杰帕德新天赋:敌方每攻击我方任意队员 → 杰帕德 +1 充能,**4 次对敌全体反击,总盾量越厚伤害越高**(= 模拟宇宙琥珀王回归,但这次吃杰帕德面板)。
- ★思路:护盾可由队友提供(等效)→ 队友把全队盾叠上限 → **杰哥全输出装当核爆倍率发射器**(反击只一段 → 暴击 + 幸运往满堆;带诗人套❓补暴击)。
- ★陷阱:**贝洛伯格机器人 / 记忆主 / 星期日 / 鸭鸭❓ 四拉 → 杰哥疯狂掉 buff**(核弹出伤靠怪物攻击打满 4 次反击,不靠跑条,多动 = 亏 buff)。可控拉条(记忆主 / 星期日选不拉杰哥)优于贝洛伯格机器人(不可控)。**四人套❓降速锁面板**让杰哥带满拐力离场 = 外置反击神军。
- 提频:怪物词条 **忍无可忍(受 7 次攻击行动提前 100%)/ 应激反应 / 同步行动** 大幅提反击频率(忍无可忍翻 3 倍)+ 缇宝 / 翡翠凑 3 群攻吃满 80% 独立乘区。
- 内鬼:鸭鸦❓ / 阮梅给对面挂冰弱 / 减攻频 → 降低反击频率。
- 节奏:4 费无前期过渡 → 请阿雅代打 → 3-1 拉 8 开 D 杰哥(1 星可玩 2 星够用),关底上 9 凑队友。
