## 1. 背景与归层

接线批(ADR-0637)后证据门进生产影子路径,但对一切缺口帧恒 `sandwich_unavailable`(成因 delta/e2/o_plus/d_death 四桶)——门数值可评前置 = ①Δ/ε₂ 注入 ②o_plus/d_death 装配(ADR-0637 敞口)。本批 = 前置①,兼试验数升级(接线批静态预算近似 → P38 ⑤层正本)与 T-214 值域守卫。归层 = 决策层·线选择判据(证明层标定);零生产行为变化(门消费面仍被 o_plus/d_death None 结构性封死,分键成因为唯一可观测变化)。

## 2. 落码形态(五件)

1. **Δ = V_C−V_F 注入(值 122 金,CI [0,260])**:显式模型 = Δλ对比 × E × W(P76 D 项 `Δλ·(g+Φ)` 同形在代表视界上的积分)。λ 对比按 P51 §4-B-2 分层读法③「λ 取值必须按节点类型分槽,禁用混合值」取**同节点(battle)对比**:Δλ对比 = 0.341(p8-12×battle)− 0.065(p≤7×battle)= **0.276**;E = 221.7 金(pooled p≤7 财富敞口 g74.4+Φ147.3,P52 对账 1 同源);W = 2 窗(代表视界 6 轮)⇒ 点值 0.276×221.7×2 = 122.4 → **122 金**。观察性对比的桶级存活者组成混杂(P51 §4-B 读法③)与 B3「Δλ 本数据集不可识别,因果化需 A/B」如实入 CI 下端 0;CI 上端 = λ3 上包络 **0.391 = P51 §4-B-2 pooled 分层表最高 95%CI 上端**(p8-12×battle 行;该表观测点值最大 0.341,取 CI 上端系保守选择;cw3 侧明细 p13+ 混合 0.524/p13+×battle CI 上端 1.000 更高但小样本,按「pooled 分层表口径」排除并在此申报)× 221.7 × 3 窗。**消费条件申报(章程 §6.2)**:CI 两端扫描下门判定方向不变的验证 = o_plus/d_death 装配批(首个能算 θ̂ 的批)义务,翻转 = B3 在册 A/B 路径补数据、门维持封印。**同源单标定**:本模型 = V_ms 族成型边际价值的差分面;`V_MS` 槽位本批不注入(P84 在册复观测排期辖换线出口面,不因本批提前),后续 V_ms 消费位必须引本模型禁第二标定。载体 = `audit/calibration.py`(新,标定值+推导指针单一源),生产注入位 = `MandateV1Strategy.__init__` → `apply()`(幂等只填 None 槽,sim A/B 重注入优先)。
2. **ε₂ 注入(值 0.65)+ 全生产域网格**:P76 §3.4 两反向二阶通道在**全生产消费域**网格的闭式包络——m∈{1..6}(注册表 form_tiers needs 全集,20 comp 全扫)、L∈{1..10}、T∈{1..27}(日程全长 (9,9,9))、R∈{0..60 步 2}∪{80..1200 步 20}(全轴数值验证)、全注册表 25 标签域(零樱桃挑选)。通道①池衰减增富全域 max +12.39pp;通道②收入流差(败金差 ≤+2 金/战 × T 战 → +SHOP_SLOTS·T 试验)全域 max +64.29pp(角点 L1/仙舟/m6/T4/R0:R=0 预算饿死域一阶支配优势消失,二阶通道全量显影——P76 丙.4 弱支配域的如实取全量)。逐格和取最大 = 包络 0.6429 → 进位 **0.65**;只抬 θ̂_suff 保守侧,θ̂_nec 不动;域 α 深处 suff_raw<0 截 0 路径不受阻(戊.2 保持)。复现 = `tools/cw/proofs/p76_e2_band_check.py`(确定性,断言包络 ≤ 注入值)。
3. **ε₂ 辖域检查(带外 fail-closed)**:强制辖域只辖**注册表有界维**——needs 上界(6)与日程上界(27),漂移即注册表事件,域外帧装配端判 `band_domain_ok=False` → 门 unavailable[e2_domain],绝不静默消费欠覆盖带值(P76 丙.4「带外不声明」落码)。R 维生产无界(gold 无硬帽 ⇒ 递推 R 随溢余增长)不作强制辖域——其覆盖由全轴数值验证承载(R≤1200 重算包络恒 0.6429,argmax R=0;大 R 双臂概率饱和带差趋零,小 q 长尾峰 ≤0.3)。`LockSandwichFrame` 增 `band_domain_ok`(缺省 True,手工构造帧兼容)。
4. **T-214 值域守卫**:落 `provisional.inject` 通道本体(唯一开闸通道,写入前校验不合法拒绝——消费位校验防不住其他槽位,结构防线只能在通道;T-124-r1 §四.2 建议的落地)。登记两槽:`V_C_MINUS_V_F` value>0(丁.4 引理域)、`E2_CONCENTRATION_BAND` value∈[0,1](概率尺度);其余槽位未登记 = 既有语义不变。门内 `delta_non_positive` 分支保留为纵深防御。
5. **P38 ⑤层金位递推(试验数升级)**:`statefn/budget.py`(新)单一源实现 P38 递推正本式(收入 = round_base_income/streak_gold 注册表源;字面 50 → resolved 息帽链泛化,ADR-0598 同源;升级金 = 日程条件 × 单步 XP 账 × 买牌 XP 抵扣,get_node_goal 先验为日程源;spend 含刷新金 2R/T 均摊 → R 小型不动点,2-循环振荡取保守端);`assemble_lock_frame` 消费之,B<0(购卡买不起域)→ trials=0 且 P:=0(P38「买到即计数前提破产」;刷新预算解耦语义不回归,P76 §5.5.2)。**B<0 域门内落点申报(r1 修正)**:exhausted ⇒ e_p_next=0 ⇒ θ̂_nec=0,`p<th_nec` 恒假 ⇒ 实际落 sandwich_band,典型格(cost ≥ gain+ε₂·Δ)落 suff 截 0=无条件放行锁。

## 3. Considered Options

| 选项 | 裁决 |
|---|---|
| Δ 以点值拍定注入(如「成型值 ~100 金」经验数) | 否决:违数学先行(strategy-work §1:禁拟合常数充当决策闸门);CI 下端必须如实承载 B3 不可识别,禁把观察对比伪装成因果标定 |
| Δ 保留混合桶级对比(0.307−0.061)+ADR 申报偏离 | 否决(r1 改判):P51 §4-B-2 分层读法③明文禁用混合值,同节点(battle)对比(0.276)同表可得且更合规——偏离可申报时,合规重推恒优先(r1 采此,点值 109→122) |
| ε₂ 域缺陷只扩值不设辖域检查(审查二选一之①) | 部分采纳:全 needs 域重算提值 0.65(主修①)——但单靠它对「未来 needs/日程漂移」无防御 |
| ε₂ 只设辖域检查不扩值(m>3 帧带外) | 否决(审查二选一之②单独形态):needs 全集 {2..6} 中 m≥4 档 17 个,只修检查会把多数生产帧打回不可评,影子对照基线过薄;且全量真值 0.65 可得,弃之无据 |
| **并举:全 needs 域重算提值 + 注册表有界维辖域检查**(r1 采纳) | 采纳:值覆盖现生产全域(保守向只抬 suff),辖域检查把「标定域 ⊇ 消费域」变成机器可验证不变量(注册表漂移 → 诚实不可评,非静默 fail-open);R 维以全轴数值验证承载(强制辖域会误伤常规溢余帧 R≈100+) |
| ε₂ 取 P76 玩具带 0.5pp | 否决:玩具带只是通道①玩具网格实测;通道②在 R=0 角点实测 64pp——包络必须覆盖弱支配域,取 0.65(充分侧保守,抬高锁不劣门槛方向安全) |
| 升级金无条件按下一级 XP 全额入账 | 否决:日程不升则不扣(P38「按日程所在轮扣」),无条件记账对已达标级虚增支出 → B 虚低 → spurious exhausted;日程源 = get_node_goal 先验(零新参数) |
| ⑤层递推留在接线批静态口径,标定批只注值 | 否决:T-278 任务卡两段义务①明文「⑤层金位递推(预算递推并入同批)」;静态口径系接线批已申报的临时形态(ADR-0637) |

## 4. 后果与边界

- **行为面**:零生产行为变化(门消费面被 o_plus/d_death None 结构性封死;sim 对 prep 线结构性零覆盖申报维持,分键为唯一可观测)。影子分键变化:unavailable 成因 {delta,e2,o_plus,d_death} → **{o_plus,d_death}**(band_domain_ok 在当前注册表下恒 True,无新增成因),判读禁把 unavailable 读成门判负(ADR-0637 语义不变)。
- **敞口更新(取代 ADR-0637 敞口①)**:Δ/ε₂ 注入已落;门数值可评剩余前置 = **o_plus/d_death 装配(V_ms 侧值因子消费 + Δλ 协议差模型)**,装配批义务含:①CI 两端扫描下门判定方向不变验证(翻转 → B3 A/B 补数据,禁进权威面)②五件套(R4-F6)③**P=0(exhausted)域 suff 放行的显式裁决**(永不完成线的「锁背书」属换线机器领地,P76 夹界模型外,禁靠截 0 语义默认放行;r1 增列)④S1→S3 权威切换另案。
- **方向账本**:⑤层递推较静态口径的 P 方向 = 分域混合(溢余帧 R 升 → P 乐观向;赤贫帧 B<0 → P=0 保守向)——逐向申报取代旧单句「静态近似 = 乐观向」;ε₂ 只影响充分侧(保守);Δ 经夹界分母进入 suff/nec 两侧(端点扫描在装配批定谳)。
- **测试**:新锁 15(r1:+辖域两锁;标定批锁 13:test_cw_evidence_gate_calibration.py——递推公式独立重推/B<0 域/金单调/升级金日程条件与 XP 抵扣/守卫四态/未登记槽语义不变/apply 注入值与 CI/幂等/影子缩桶/辖域谓词与积分/域内对偶/试验数映射/B<0 装配);锁迁移 2(sandwich Δ=0 锁按守卫上移重推语义+纵深分支 monkeypatch 直测;wiring 试验数锁改映射锁,公式锁归新文件);q=0 入表锁改动态选 comp 激活(T-213 修瑕②,全库唯一 = 希儿量子);测试序隔离补 1(statefn 缺省 None 锁加 reset,缘由 = 生产构造位合法注入)。
