## 1. P1 前期骨架(V3.7 → V4.x 演进)

- **V3.7 基线**:桑博+艾丝妲 **2 持续伤害(DOT)** 为核心向外拓展(+佩拉 2 贝洛伯格 / +小黑塔 2 银河学者挖矿 / 5 人口 2 简易 / 挖完换奶 2 治疗)[攻略·必修三]。
- **V4.0+ 口径**:A830+ 不提升羁绊基础伤害 → 怪血翻倍而 DOT 不涨,3 仙舟+2DOT 过渡不稳,顶级过渡改 **3 巡猎**(可叠 2 列车 / 2DOT)[攻略·难度 V4.0]。
- **能打伤害的过渡羁绊五家**:仙舟 / 狼狩 / 持续伤害 / 列车同行 / 贝洛伯格 [攻略·合集直读];学者羁绊(2星小黑塔/艾丝妲/阮梅)+ 公司羁绊(每节点 1 金)给少量经济;圣杯任务(凛/闪闪/Saber → 3 圣杯奖励)给经济/资源。
- **开局过渡分级**:拿到逆天投资策略(娱乐星球 / 不等价交换 / 轮回不止 / 双鞋风扇 / 飞光映月 / 黑塔纪元 / 狸狸的早晨)秒选 = 夯;配队雏形(主c+2拐+1合适装备)= 顶级;能打伤害羁绊×2 = 人上人;纯经济类策略 = NPC(血换经济,1位面boss门口启动);都没有 = 拉完了 [攻略·合集直读]。
- **词条 × 骨架互动**:忍无可忍 / 应激反应 / 同步行动 / 一鼓作气 大幅增强前期 2DOT(怪频动 → DOT 多触发);随从强化 / 第一位面强化 / 彩虹投资策略下 2DOT 仍缺伤 [攻略·必修三] → 词条识别可指导是否走 DOT 过渡。

## 2. 过渡成型判定(停手线)

- **lv5-6 + 羁绊够 + 过渡核心 2 星 → 过渡成型,停手攒息**[口述·13]。
- 1-6 / 1-7 起 2DOT 就连胜不了(V3.7 口径);boss 关前攒到 ~80 金即达成过渡使命 [攻略·必修三]。

## 3. 换血点(1-8 分界)

- 奖励关(1-8)把过渡阵容**全卖吃息** → P2 换血点 [攻略·难度]。

## 4. P2 护航体系

- 三套护航(按最终线系别选):**龙丹护航**(4战技点+3仙舟 → 直伤系)/ **灵砂护航**(4击破 → 击破系)/ **阿雅护航**(3昼神+3能量 → DOT系)[攻略·难度 V4.0-4.4]。
- **2 星护航带队即停手**;分水岭 2-7 / 3-1 结单换最终线 [攻略·难度]。

## 5. 按 comp 选过渡(角色重叠)

- 过渡阵容优先选与最终线**角色重叠**的(买过渡件 = 未来核心件)[口述]。各 comp 过渡角色字段 = `COMP_LIBRARY` 的 `transition_chars`(数据源,sources 阵容文)。

## 6. 买牌纪律(过渡期)

- **通用填充件**(星期日等):阵容有缺口先填,成型后替换 —— target / off-target 之外的第三类 [口述·14]。
- **1 费卡顺手集 2 星**(买卖净 0 = 免费战力);2 费非目标不追星 [攻略·必修三;退金规则 → economy §3]。
- **没过渡牌绝不 D**(「把钱花光了跟死了没区别」)[攻略·必修二]。
- 开局 1-1:清备战只留过渡牌;金 ≥4 留人口吃 1 息;金 <4 点一次升级白嫖 4 级商店刷新 [攻略·必修三]。
- **造假阵容技巧**:婷云后台 + 风套 + 翁瓦克 → 大招全队拉条,所有阵容通用 [攻略·必修三]。
