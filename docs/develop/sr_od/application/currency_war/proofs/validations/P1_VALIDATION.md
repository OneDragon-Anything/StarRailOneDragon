## 2. 五门判定

### 门① 内部推导(逐步核)——**通过(带形式化缺口注记)**

命题拆解为四步:

1. "单店出现率 q → 再遇期望 1/q 轮":几何等待,期望 = 1/q,**数学正确**。前提=每轮恰一次免费整店刷新(节点切换,见门③)。
2. "5费@7-8级 = 60-180 轮":q = P(单次刷新 5 格中≥1 张目标牌)。独立重写超几何式复算(脚本):
   - lv7(p=0.01):q=0.00554 → **180.4 轮**;lv8(p=0.03):q=0.01657 → **60.4 轮**。✓ 落带 60-180。
3. "9-10 级收窄 8-18 轮":lv9 q=0.05445 → 18.4;lv10 q=0.13210 → **7.6**。下端实为 7.6(证明写 8,舍入差,不翻转结论)。✓
4. "急D补救 120-360 金" = 期望刷数 × 刷价:60.4 刷×2金=121,180.4×2=361。✓ 落带 120-360(依赖 SHOP_REFRESH_COST=2,见门⑤)。

**形式化缺口(不翻结论,需注记)**:主命题"有用件弃购省下的金 < 再遇它的期望损失"未写成不等式定理——它是量级比较(5费省 5 金 vs 补救 121-361 金 / 自然窗口 60-180 轮),量级差 1-2 个数量级,量级论证成立;"越稀有越囤"的单调性由 1/q 随 q 递减严格成立。另:"期望损失"的货币化通道取急D(付费刷),自然再遇本身免费——急D成本是"愿意追回的支付意愿"定价,不是自然通道的直接损失;作为上界式比较合法,作为等式不严格。
