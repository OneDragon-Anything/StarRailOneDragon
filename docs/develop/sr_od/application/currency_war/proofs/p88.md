## 命题(形式化)

### 0. 辖域定义(零新域,单一源复用)

- **收窄集 S_spec** = 档 0 dominance 候选 ∪ P86 乙臂 hub 候选 = 买因 {dominance_buy, hub_option_buy}。**hub 空开火面申报[F6 处置,设计 v2 修订 10 折入]**:hub 辖 unlocked 无目标带,与 locked D 域结构性不相交 ⟹ hub 位收窄在 D 域**零开火**(结构事实非辖域错),落码为防御性哨兵(P86 辖域变更监视,独立分键 `press_narrowed_transition_domain_hub`);判读禁把 hub 恒 0 并桶进 dominance 位开火数(防误报回炉)——收窄的实际行为面只有 dominance 位。
- **豁免集** ⇔ reason ∈ LAUNCH_CAUSE_BY_ARM ∖ S_spec(闭集单一源 = `sell_gate.py:114-134`,现值 **15 键**;不复制枚举防漂移,含 m2_line_member / m2_locked_member / m2_stockpile / m2_merge_completion / core_single_card_buy 与 :unlocked / m6_stockpile / press_buy_deployable / ev_buy / transition_component_buy / dead_gold_press_buy / fuel_filler_stall / t3_unlocked_hemostat;④ transition_component_buy 在 P2 恒不发射,列入只为闭集完备[P77 修正 3b 在册];闭集外新键出现 = 锁红)。
- **滞留期**(写死,防宽松读法):= 被压抑件在基线账本中的**实际持有区间**(买入帧 → 离场帧[被卖/上板/合成/局终]);区间口径 = 账本实际持有区间(探针 :71「买入时刻→实际命运时刻」档),**非**探针『滞留型(区间=局终)』下界档,**禁读成「买入→局终」**(术语对账:探针「滞留型」本义 = 局终口径,与本档不同名同形勿混[F4 处置])。机制注:dominance 属 press 类(τ=同轮,`sell_gate.py:104-107` WINDOW_LAUNCH_CAUSES),同轮拒帧的覆盖判定最硬;跨轮后其登记过期、可成 M4 合法燃料被卖腾槽,持有区间随之自然截断——账本区间口径下两场景自洽且偏保守。

### 1. 调和引理(路径级;价值有据——收窄不是对支配性优先序的否决)

dominance 臂的「无条件放行」(`mandate.py:426-432` docstring;01_math_framework §3「净成本≈0 → 无条件放行」)是**金维**论证——1★ 全额退(P76 甲)⟹ 净金成本 0。其成立前提是**席位免费**。D 帧恰是席位最贵态:

- **收益维(≈0)**:D 帧线已锁 ⟹ 线外 1★ 候选的囤积期权 V_opt ≈ 0(线外件不再成为目标)、卖回压缩损失通道净 0(P49 档序对 1★ 恒零损——实码 dominance 候选谓词不查费档,结论由 1★ 全额退兜底,勿引「档外」[F7 处置])、燃料净 0——收窄放弃的持有收益 ≈ 0。**V_opt ≈ 0 的现状前提[F2 处置]**:换线通道 fail-closed 封印(01_math_framework §3.7「标定齐前换线事件恒 0」)——「≈ 0」实为「= 0(换线封印现状)+ 换线解封后 > 0」两态;换线解封批须同步重审本引理收益维(成本维与兑现帧严格性不受影响,弱支配结构不因此翻)。
- **成本维(路径级 ≥ 0,兑现帧严格)**:其占位成本 = **滞留期各帧边际 V_slot 之和,≥ 被阻线内义务净 EV**。点态 V_slot 仅 free≤1 帧非零(P41③;01 §5 状态函数表 free≥2 = 0;生产单一源 `statefn/vopt.py:71-79 v_slot`)——free≥2 的 D 帧买入帧**自身**点态 V_slot = 0,占位成本是**下游轨迹外部性**:t₁ 买入占 1 格,t₂ 帧被阻义务面 V_slot = 被阻动作净 EV > 0(P76 丙槽竞争同锚)。124 拒帧 bench 满 87-90% = 成本兑现实证锚(见数据锚节)。
- **结论**:「净成本 ≈ 0」前提在 D 域的席位维失效,**支配性放行辖域不含 D 帧**;收窄 = V_slot 维的资格修正,与金维支配性论证不冲突。弱支配形态:持有收益 ≈ 0 而路径成本 ≥ 0,被阻义务兑现帧上严格;**反事实分支**:若滞留期内 bench 恒 free≥2 则边际和 = 0,两系统价值等价、主不等式仍成立(此分支下无 bench 满拒帧,压抑量本身为 0)。
- **落码纪律**:批 B 须同步修 `dominance_buy_eligible` docstring 辖域注(引本引理),否则在码支配性论述构成回滚的合法依据。

### 2. 主不等式(不变量,冻结口径可证)

对帧路径 t₁ < t₂(同一锁线段),若 S = ∪S_{tᵢ} 在 D 帧全部停发,则**被压抑类**的备战席占用逐帧满足 **O_t(收窄) ≤ O_t(基线)**(被压抑件不入席;其衍生同轮回卖亦不发生)。

### 3. 解封方向式(非逐帧充分条件)

**解封量 ≥ 压抑量 − 同帧在先臂消耗 − 中间帧出口回填**(压抑量按 §0 滞留期账本区间口径取「持有区间覆盖计数的被压抑件」)。两扣减项机制:

- *同帧在先臂竞争*:单动作契约下逐动作串行发射,位次即优先序(`shop.py:1591`),拒帧同帧若有排序在先的其他候选(m2 族),收窄释放的槽可被其合法吃掉——该 core 顺延后帧;
- *中间帧回填*:D 帧压抑后溢余金改走出口序,其中 M6 店侧臂门 = gold > g* ∧ bench_free > 0(`shop.py:1697`)——压抑帧与拒帧之间任一 D 帧只要有档匹配候选,M6 即回填释放槽。

**三重折扣申报(消费限制行)**:57-63% 是冻结口径上界的**双重高估**(第一重 = 探针「其余决策全冻结」假设,探针报告反事实假设 1/4 自认「上界侧未扣」;第二重 = 本条回填未扣),另叠设计辖域差(locked 转型域 ⊆ 探针 P2 板满全域)——三重折扣合计在 §4.1-⑦ 分解键下实测。**单篇与判读禁把 57-63% 当预期值**。

### 4. 息损不增

被压抑件均为 1★ 全额退(P76 甲),压抑不产生金路径新损;dominance 前件 gold>g*(∩ `mandate.py:437`)⟹ 压抑只发生在溢余段,该段息损 L ≡ 0(P70);带内帧本就不发射。

### 5. 溢余出口守恒(附扣减语义)

D 帧压抑后金仍 >g*,出口序保留(m2/C1 线内买入 → ②(b) 不涉 → **档 2 M6 压库 = 回填主体,合法出口非缺陷** → 档 3 刷新/XP 整买)——与 11_shop_decisions §5「任何段必须供给金支出出口」对表;回填与解封的张力由三分解键显影,**不在命题层消解**。

## 证明

### ① 主不等式(冻结口径,构造性)

冻结口径的反事实 = 同一决策序列减去收窄类买入(被压抑件不入席,其衍生的同轮回卖随之不发生);豁免类买/卖事件两边逐帧相同(决策序列冻结 ⟹ 候选集与卖出序不变)。对任一帧 t:被压抑类占用 O_t(收窄) = Σ_{被压抑件 s: 买帧 ≤ t < 离场帧} 1(收窄) = 0 ≤ 同一和式在基线的取值 = O_t(基线)。逐帧成立,不需要归纳步。∎

### ② 调和引理(路径级弱支配)

金维:两系统在被压抑件上的金账同为「买入支出 + 1★ 全额退款」= 净 0(P76 甲);且 dominance 只在溢余段发射(前件 gold>g*),压抑不新增息损(P70,见 ④)。期权维:D 帧线已锁 ⟹ 候选不入目标集 ⟹ V_opt ≈ 0、P49 档外恒 0、燃料净 0。成本维:对滞留期逐帧取边际占位成本 Δ_t = V_slot(free_base(t), blocked_base(t)) − V_slot(free_narrow(t), blocked_narrow(t)),其中收窄世界少一件占席(free_narrow = free_base + 1)且被阻动作集单调不减(blocked_narrow ⊆ blocked_base,多一格时被阻义务可解封);由 P41③(V_slot 在 free≥2 时为 0、free≤1 时 = max 被阻净 EV)得 Δ_t ≥ 0 逐帧,Σ_t Δ_t ≥ 0;若滞留期含兑现帧(基线拒 core、被阻义务净 EV = e*),该帧 Δ = e* > 0,故 Σ Δ_t ≥ e*(严格);反事实分支(bench 恒 free≥2)Σ Δ_t = 0。合成:收窄臂价值 ≥ 基线臂价值(金维同账 + 放弃期权 ≈ 0 + 免除路径成本 ≥ 0),兑现帧上严格——弱支配成立,收窄价值有据。∎

### ③ 解封方向式(机制直代,非定理)

按 §0 滞留期口径,基线中持有区间覆盖拒帧 r 的被压抑件在收窄世界释放槽;每拒帧 r 的释放槽账 released_r = 被压抑覆盖件数(r) − 已被豁免臂回填吃掉的释放槽(r)(同帧在先臂与中间帧 M6 两来源,单动作契约下逐动作串行发射)。解封(r) ⟺ released_r ≥ 1。逐拒帧的槽位账恒等式与「未解封必可归因(无覆盖 ∨ 槽被耗尽)」由复算脚本在事件序列上逐例核验(§断言 4/5);**聚合量级不可先验**——这正是三重折扣与三分解键(设计 §4.1-⑦)存在的理由。∎(方向性成立;量级 = 实测项)

### ④ 息损不增

压抑件的买入-退款净 0(P76 甲,同 ② 金维);dominance 前件 gold>g* ⟹ 压抑帧全部落在溢出段 D_ovf,P70 已证该段息损 L(g, spend, R, Ī) ≡ 0(全网格 1,698,840 格复算在册,`tools/cw/proofs/p70_check.py`);带内帧 dominance 本就不发射,无压抑事件。∴ 压抑不产生金路径新损。∎

### ⑤ 溢余出口守恒

D 帧压抑后金仍 >g*,出口序(线内买入 → ②(b) → M6 压库 → 档 3)各臂资格门均不含「上一帧是否压抑」,出口集非空(11_shop_decisions §5);M6 压库即 §3 回填主体。出口守恒与解封方向的张力由三分解键实测,命题层不做消解。∎

## 边界与强度分级(如实入册)

1. **主不等式辖冻结口径**(事件级反事实,决策序列冻结):真实收窄会重决策(分支/刷新数/卖出序全变),本命题不保证实现后系统的逐帧占用——非逐帧保证是显式边界(对抗审阻断 2 处置)。
2. **解封方向式非充分条件**:两反例形状(同帧在先臂竞争 / 中间帧回填)已钉进命题,「压抑量 ≥ 缺口」不蕴含该帧可买入。
3. **调和引理为弱支配**(非严格):反事实等价分支(bench 恒 free≥2,压抑量 = 0)在册;点态 V_slot 仅 free≤1 非零,free≥2 帧的成本是路径外部性(R1 形式化已折入)。
4. **解封率量级 = 实测项**:57-63% = 冻结口径上界的双重高估 + 辖域差 = 三重折扣,禁当预期值;实测归因走三分解键(辖域覆盖比 / 解封实测率 vs 上界 / 压抑覆盖型 vs 腾席成功型)。
5. **core 供给按期到达不在命题域**(商店 RNG,P38/P40):收窄只保证「到了买得进」,不保证「按期到」。
6. **V_opt ≈ 0 以换线通道 fail-closed 封印为现状前提**(01_math_framework §3.7;F2 处置辖域注,见 §1 收益维):换线解封批须同步重审本引理收益维。
7. **立不了的三条**(设计 v2 §二,对抗审攻过未破):换血净收益为正(λ_death/板深战力域,宪法 §1 禁战力建模);收窄后 core 供给按期到达;off 件买→换血配对投影(与收窄目标自斥)。
