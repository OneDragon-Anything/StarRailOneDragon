# 升星合成机制:落点规则与连锁合成

> 来源:用户口述·权威(2026-08-28,识别体系讨论中补充;用户=玩法权威)。
> 本文只记机制事实;策略决策(为合成而买/何时追星)归 plaza_methodology「升星经济学」与策略池。

## 1. 买牌落点:先备战,触发合成则改落点

- **正常情况**:商店买到的角色进入**备战栏**(底部储备条)。
- **例外——触发 3 合 1**:若这次购买使同名同星凑满 3 个,合成发生,产物落点按优先级:
  1. 三张里有**在场上(前台或后台)的** → 合成发生在**场上那张的位置**(装备/站位随之继承——场上吸收);
  2. 三张**全在备战栏** → 产物落在**最左边那张**的位置。

## 2. 连锁合成(一次购买可触发多级)

合成产物计入同名同星计数,可触发下一级合成:

- 例:备战栏 2×1星 + 场上 1×2星 → 买 1×1星 → 凑满 3×1星 → 合成,产物 2星**落备战栏**(三张全在备战栏,取最左);
- 续:若备战栏另有 1×2星 → 此刻全场 3×2星(新 2星 + 备战 2星 + 场上 2星)→ **第二次合成自动触发** → 3星;因三张里有场上的 → 3星**落在场上那个 2星的位置**。

## 2.5 备战栏满时的购买(满栏例外,2026-08-28 口述)

- **常态**:备战栏满 → 商店买不进新角色。
- **例外**:点击的牌**能触发合成** → 满栏也买得进。
- **自动多买**:点击一张会**一次性买进凑满一次合成所需的全部张数**——例:备战 1×1星(栏满)+ 商店 2×1星 → 点一张 = 2 张都买入。
- **连升同理**:备战 2×2星(栏满)+ 商店 3×1星 → 缺 3 张 → 3 张全买 → 3×1星合成 2星 → 与备战 2×2星连锁 → 3星。【置信:低——栏满时第一次合成发生在商店语境,产物落点/时序未亲见,可能只能靠对账发现;商店同刷 3 张同牌概率极低,先按此说法实现,由拖动对账网实证修正】
- **上限(绝不多买)**:一次点击只买到**触发一次合成所需的量**,即购买张数 = **min(店内张数, 3 − 已有数 mod 3)**——缺 2 张时店里刷 3 张也只买 2(第 3 张会是无处安放的散牌)。
- **无价格优惠**:自动多买每张都按原价扣金(总价 = 张数 × 单体费用),不是打包价——纯省点击的便利机制,非经济优惠;bot 侧金账按 k×单体费用记全款。

## 2.6 费用倍数体系:费用 = 原费用 × 3^(星级−1)(2026-09-02 口述)

- 角色卡的费用随星级倍增:**1★ = 原费用、2★ = ×3、3★ = ×9**(例:三月七 1★=1/2★=3;丹恒·饮月 1★=2/2★=6;4★=×27 理论值)。
- 本质:2★ = 三个 1★ 合成,费用是三个 1★ 的总和(×3);买价按当前星级费用实付(非打包价,与 §2.5 自动多买金账口径一致)。
- **商店识别推论**:费用徽章数字 ÷ roster 原费用 = 倍数 ∈ {1,3,9} → 直接反推星级——**2星直出识别不必依赖底部星排图标**(§2.7 的星排识别缺口被费用通道覆盖);读数非倍数集 → 按原费用(1★)兜底留证。
- bot 侧消费:read_shop_cards 费用数字识别(2026-09-02 增强,原 roster 查表对 2星直出记错星级的缺口闭环)。

## 2.7 商店牌的两个星标 UI(2026-08-28 口述+画面考古)

- 考古结论:测试仓 3 张开商店帧 × 5 牌 = 15 张全部 1星(无底部星排),**2星直出零样本存档**,概率待实机调研;合成预览 1 例存档(`shop_open_preview_star`)。
- 识别缺口登记:2星直出若出现,`read_shop_cards` 的 SIFT 名字仍读得对(肖像同画),但星级会按 1星 记 → 经济/合成计数错;触发条件=金账对账发现买价≠1星价,届时再建底部星排识别(固定 y 带的小图标检测,量级小)。

## 3. 恒成立约束与待确认细节

- **场上同名同星 ≤1 恒成立**【口述·权威,2026-08-28】:「场上有两张相同的」场景不存在——因此合成落点规则无歧义(场上那张唯一,无前后台之争)。
- 推论:同名同星全局面(场上前台+后台+备战栏)合计 ≤2,第三张出现的瞬间即触发合成;场上同名同星 ≥2 的状态不可达。
- 备战栏满时买牌的行为(是否顶出/禁买)与合成时序的交互,未询问。
