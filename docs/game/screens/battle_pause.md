# 战斗-暂停面板(battle_pause)

回合制战斗中点右上角暂停钮（或客户端重启恢复中断战斗）弹出的关卡信息面板。**与「货币战争-战斗暂停」是同一 UI 家族**（CW 档先建、带 app_id 归 CW 域；本档为通用识别档，覆盖全部玩法形态）。

## 何时出现 + 状态流转

- **入口**：①战斗过程态点右上角暂停钮（II 图标，(1857,47) 一带）；②客户端重启后恢复上次中断的战斗，直接落在本面板（2026-11-16 登录恢复实证）。
- **出口**：
  - 「继续战斗」→ 关面板回战斗过程态；
  - 退出位按钮（见下表，文案随玩法变）→ 确认弹窗（「提示」标题 + 取消/确认，AS 文案「是否结束本场战斗？」）→ 确认 → 节点结算页（AS：挑战结束/积分页，点「退出」回选关；PF：回玩法选关屏）；
  - 右上 × → 关面板回战斗过程态（**不退出战斗**）。

## 识别特征(稳定锚点)

- **id_mark 双锚**：「标识-战斗暂停」(75,40-230,72) + 「标识-关卡信息」(75,68-230,100)，lcs 0.7——双词同屏出现是本面板独有组合。
- 右上角「波次 N/M」文本、顶部 4 个 tab 图标、右上 × 关闭钮 (1830,35-1892,98)。
- 底部按钮行：退出位按钮 + 「继续战斗」，位置跨玩法固定、**文案随玩法变**（见下表）。

## automation 要读信息

- 面板本体即「战斗已暂停/战斗恢复态」信号。
- 退出操作 = 点「退出位」固定区域 → 确认弹窗点「确认」——不需要 OCR 按钮文案（位置固定）。

## 备注 / 待查

- 「货币战争-战斗暂停」(currency_war_battle_pause) 与本档并存：CW 域 op 继续用自己的档；通用兜底（登录恢复场景）用本档。两档同 id_mark 词，CW 档无 id_mark（`id_mark: false`）不会与本档精准识别冲突。
- **关卡信息/首领信息 4 字词 lcs 0.5 撞车**：「末日幻影-首领信息」id_mark 原默认阈值下会被本面板的「关卡信息」误配（2/4=0.5）——已把该 area lcs 收紧到 0.7（2026-11-16 实测：暂停面板帧不再误配，真帧命中不受影响）。
- 忘却之庭(FH)/模拟宇宙等其他战斗的暂停面板形态未实测（预估同族：双标题+底部按钮，退出按钮文案可能各异）——登录恢复兜底按「双 id_mark + 退出位固定区域」设计，不依赖按钮文案，形态差异不阻塞。
