# 末日幻影-终焉公理(tl_as_axiom)

末日幻影编队屏**增益装配弹窗**(「终焉公理」系统):每节点从若干增益(本期 3 项,
名称随期轮换)中选择一项装配。增益选择的真实入口——编队屏行 boss 卡内的
「坚防守备/阵地转移」等按钮是**敌方特性条款查看入口**(点击仅弹说明浮层,
不改变装配),勿混淆。

## 何时出现 + 状态流转

| 态 | 入口 | 出口 |
|---|---|---|
| 弹窗(节点一) | 末日幻影-编队 行 1 右端圆形按钮(`按钮-公理圆圈1`,编入角色后出现) | 点「装配效果」→ 装配生效,**弹窗自动关闭**回末日幻影-编队;右上关闭 X → 回编队屏不装配 |
| 弹窗(节点二) | 末日幻影-编队 行 2 右端圆形按钮(`按钮-公理圆圈2`) | 同上 |

弹窗左栏显示对应节点的首领与当前队伍头像,per 节点独立(点哪行圆圈开哪节点的公理)。

## 识别特征(稳定锚点)

- **标题-终焉公理行**(左上,「末日幻影/终焉公理」两行的第二行):id_mark。
- **文本-选择增益行**(「选择增益效果装配进终焉公理」):id_mark。
- 三张增益卡片纵向排布(位置固定,名称随期轮换);当前装备卡的右上角有黄色
  「装备中」角标(位置随装备卡浮动)。

## 可交互元素

| 元素 | 行为 |
|---|---|
| 卡片-增益1/2/3 | 点击选中该增益(实机验证);名称随期轮换,按位置选择 |
| 按钮-装配效果(右下) | 装配当前选中增益 → 弹窗自动关闭回编队屏 ✓ |
| 关闭 X(右上) | 关闭弹窗回编队屏,不改变装配 |
| 左栏首领特性按钮(坚防守备/阵地转移等) | 弹敌方特性说明浮层(查看用,不影响装配) |

## automation 要读信息

- **节点号与首领名**(左栏「节点一 | 首领名」):确认当前装配作用于哪个节点。
- **三条增益的 名称 / 描述 / 装备态**:选 buff 决策依据;由
  `TlAsAxiomRecognizer` extras 输出(`node_no` / `boss_name` / `buffs[]` 的
  `slot/name/equipped/desc`)。
