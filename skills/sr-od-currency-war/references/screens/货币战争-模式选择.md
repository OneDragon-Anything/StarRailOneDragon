# 货币战争-模式选择

## 画面简介

货币战争的开局 / 续局 / 清档画面。无存档形态（主画面）：左侧「标准博弈 / 超频博弈」模式页签 + 右侧关卡 / 职级信息 + 右下「进入标准博弈」主行动钮；有存档形态是独立子画面「模式选择-进行中」（见下子态章），弃局确认弹窗「模式选择-结束结算确认」亦为独立子画面。教学关阶段只有「启航测试」单一模式。旧实测：带存档的画面变体识别可能 miss（曾模糊命中「模拟宇宙-世界详情」）——该变体已独立建档为「模式选择-进行中」（双锚正面识别，修复批已落地、落地后实测记录待积累），OCR 分流（「进入标准博弈」位置不变）降为兜底手段。

## 识别后要做的决策

按画面上出现的按钮组合分流：

1. 只有「进入标准博弈」= 无存档 → 点它开新局。
2. 「继续进度」+「结束并结算」同时出现（进行中子态）= 有存档 → 续局点「继续进度」；弃局重开点「结束并结算」（确认弹窗点「放弃并结算」）→ 弃局后要走完整三页结算链（挑战失败 → 对局总结 → 战报）才能回大厅重开（实测，操作按「终局结算」卡）。**挂起局正规弃局链（2026-11-21 第十一局再证，登记为挂起处置首选）**：「进行中」形态 → 结束并结算 → 放弃并结算 → 挑战失败结算三页 → 大厅——从大厅进的这条弃局路径是挂起局的正规处置（结算完整、不留残局），比对局内退出再清残局更规范；**自动化对挂起局弃局首选此链**。

## 货币战争-模式选择-结束结算确认

### 画面简介

点「结束并结算」后的确认弹窗（独立画面档，覆盖在模式选择画面上、背景变暗虚化）：标题「提示」+ 确认文案「确定结束进程吗？」+ 当前进度 / 小队生命值 / 持有金币 / 晋升点清单 + 底部「放弃并结算」胶囊钮 + 弹窗右上 × 关闭。

### 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-确认文案 | 「确定结束进程吗」确认文案（画面身份锚） | 纯显示 |
| 按钮-放弃并结算 | 底部「放弃并结算」胶囊钮（画面身份锚）；文案提示「选择放弃并结算将直接结算并重置进度」 | 点击 = 确认弃局：直接结算并重置进度，进挑战失败结算三页链（操作按「终局结算」卡） |
| 按钮-关闭 | 弹窗右上 × 关闭钮 | 关闭弹窗（取消结束进程），回「模式选择-进行中」 |

### 识别后要做的决策

弃局确认：确定要弃局才点「放弃并结算」（不可逆——直接结算并重置进度）；否则点关闭取消。
