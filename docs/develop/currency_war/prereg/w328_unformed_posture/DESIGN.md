## ① 三方 EV 公式

记号:g=金,hp=当前血量,lv=等级,R=跨位面剩余回档轮上界(`registry.vd_p2_recovery_rounds=2.31`;位面中段取 `registry.interest_rounds=5`),b=剩余战斗节点估计(`registry.battles_left_est=5`,骨架初值非测量值,src 注释自认保守侧)。

**k(hp) 定义(W330 攻击①补课,原「见②」空引已废)**:

```
k(hp) = 1    hp≥40 且末窗投影未命中(线性区)
k(hp) = 3    25<hp<40,或末窗投影血量命中(hp−34<25)   —— K_ALERT=3.0
```

- 性质:对线性折价 `0.5 金/hp` 的凸性修正乘子。**出处:非标定设计参数**;动机=语料 66 场 P1 boss 战中战后 hp≤3(近乎全灭)占 43.9%(本语料全量实测,与 W330 的 62 场 44% 一致)——末窗边际 hp 是生死价,线性折价系统性低估其价值。**标定计划**:sim 批在 {1,2,3,5} 网格上以出口 hp/通关率为目标函数定参;**k=3 臂的一切符号结论对该网格不稳,本文只作敏感度呈现,不作裁决依据**。

### EV(持金)

```
EV_hold(g, R') = 0.1 × min(g, 50) × R'     R' = 持有期剩余结算轮数
```

- 出处:息律 0.1×金、50 封顶 = `registry.interest_cap=5`(50 金 5 金/轮);R' 同 `registry.interest_rounds` 口径。R'=0 于位面末窗(sim 收入按节点结算且先于决策,`cw_sim` L1469-1479,W330 攻击⑧-3 核实无击破)。
- **关键推论(参数无关)**:g>50 部分的持有边际恒等于 0(封顶截断)。**预算基准金口径(W333 N6)**:全设计预算/死资本计算的 g 一律取**决策相机 `state.gold`(买相位实读)**;handoff 金(run48 出口 82,死资本 32)是局后参照口径,只作叙事,不进任何预算公式——两口径差 10 金 = 差 5 次刷,必须分流。
- 期权价值定量:持金的期权 = 未来有候选时买得起。该期权已在买侧候选 EV 里逐帧计价(`scoring.py` 的 C_interest 折中视界 `interest_recovery_rounds=3.0`),不在持有侧重复计——显式声明只计一次,防双计。

### EV(D 找件)

```
V_D = P_found(n) × Δhp × b × 0.5 × k(hp) − n × 刷价 − P_found(n) × 买入费
P_found(n) = 1 − (1 − p̄)^n
p̄ = Σ_cost P(单次刷新 ≥1 张目标标签件 | 该费用档)     —— 费用档互斥,可加
P(≥1 | cost) = 1 − Σ_m C(Va−a_tgt, m)/C(Va, m) × B(m; 5, p_cost)
```

- p_cost:`cw_shop_odds.REFRESH_PROB`(2026-08-11 实机 OCR 权威表,即 P5 表)。副本数 a:1/2 费 27、3/4/5 费 9(`POOL_COPIES_PER_CARD`);种类数 v:角色注册表派生(`DISTINCT_CARDS_PER_COST`)。
- 目标标签 = 阵营(factions)∪ 流派(flows)并集(outcomes board 口径)。run48 例:标签「持续伤害」共 6 角色(1 费×3、2 费×1、4 费×1、5 费×1)。
- Δhp(边际战力)= 每场战斗少掉的血,**分语境两套代理**(W330 攻击⑧-1 采纳):末窗用 **boss 层裸差分**(P1 boss 全在 r9,轮次混杂极小;快照值 5→6 人 = +4.30 hp/场);非末窗用普通战轮内去均值代理(快照值 5→6 = +1.96 hp/场)。两套都弱信号,boss 层样本量 n(5 人)=29/n(6 人)=35,置信区间宽——只作敏感度臂。
- 0.5 金/hp = `registry.hp_to_gold`;批口径成本 n×刷价 与 P5 主定理一致(`scoring.vd_refresh_score` 同构,禁单次边际);刷价读 `state.shop_refresh_cost`。

### EV(买经验)

```
V_XP = Δhp_per_battle(cap+1 − cap) × b × 0.5 × k(hp) − ceil(XP_need/4) × 单击价
守卫(前置,先于一切计算):deployed == cap ∧ bench 存在可上阵件 → Δ 才非零;否则 V_XP ≡ −整级单击费
```

- XP 阶梯:`cw_state.XP_TO_NEXT_LEVEL = {3:4, 4:6, 5:20, 6:40, 7:52, 8:72, 9:84}`;每击 +4 经验(`XP_PER_BUY`)、单击价实读 `state.level_up_cost`,缺失兜底 4 金(`XP_CLICK_COST_FALLBACK`,lv5 实测)。
- 升级费阶梯实例:lv5→6 = 5 击×4=20 金;lv6→7 = 10 击×4=40 金;lv7→8 = 18 击×4=72 金。
- **守卫口径统一(W330 缺口B)**:run48 r9 帧 deployed=5 < cap=6 且 bench 非空 → slot 边际恒 0 → **V_XP = −40 金(纯损失)**,且 40 金 > 泄息预算 22(g−50)→ 按预算规则本就不是候选。**该帧裁决 = 不该花经验(确定)**。results.json 的 `ev_xp_lv7=−25.3`(冻结快照值)是未套守卫的裸算,仅存档对照;裁决以 `ev_xp_lv7_guarded=−40` 为准,两口径已在代码内分字段、文档内分列,不再混用。

## ② 翻转条件(攒息 → 花钱)

**未成型判定口径**:决策相机的 `phase=FORM ∧ form_ok=False`(运行时单一源;`handoff.engines<2` 是局后口径,禁混用——W330 攻击②的「run45 反证」即混用了局后口径,已废)。

**翻转谓词(W330 缺口A 补课:hp 绝对阈改投影血量维度,删除 hp<40/hp<45 特化讨论)**:

```
末窗   := boss 首买相位(单臂,W333 N1:进入 boss 战前的最后一次备战买相位,
          锚 = 本轮 node_type==boss 的首个买相位;round 臂「r≥NODES_PER_PLANE−1」废除)
投影命中 := hp − BOSS_TAX_P75 < emergency_hp            BOSS_TAX_P75 = 34(分位锚=p75,median=32 另记)
FLIP = (phase == FORM) ∧ (form_ok == False) ∧ (g > 50)
       ∧ ( hp > 25 )
       ∧ ( 非末窗: hp < 40 )                              —— BLOOD_MARGIN_LOW_HP,持续兑现逻辑
       ∨ ( 末窗: 投影命中,即 hp < 59 )                    —— 战后必入应急带的机制理由
```

- **末窗单臂化依据(W333 N1)**:round 臂(原「r≥8」)实证双失效——①过宽:语料末窗未成型∧g>50∧hp>25 帧中 round 臂独有 14 帧全是 r8 非 boss 轮(r8 后打普通战掉血 5-8,套 boss 税投影语义错误,且提前一轮烧泄息预算致 boss 窗无金);②全盲:2 局 P1 boss 在 r1(税 58/44),短位面局 `r≥8` 永不触发。唯一锚=boss 首买相位后,短位面由 boss 轮位置自适应,无双臂歧义。**latch 窗口单位=boss 窗(单轮)**:boss 首买相位命中即激活,该轮买相位内一次决策,窗口随 boss 战结束关闭——无跨轮语义。
- **BOSS_TAX_P75=34 出处(W333 N5 改名,原 BOSS_TAX_P50 名实不符已废)**:本语料 66 场 P1 boss 战掉血 median=32、p75=34、p90=36、max=58、mean=26.7(results.json `corpus_boss_tax`;W330 独立探针 62 场互证)。取 p75 作分位锚:判据目的是「防战后坠入应急带」,保守侧取更高税;常量名与所装分位严格一致,防下游误读。max=58 的肥尾(贴边带 hp∈[55,58] 当前语料 0 帧、逃逸带 hp≥59 实测漏检 0)声明为遗留风险:sim 标定时 boss 税以**分位数锚组 {P50, P75, P90}** 进 registry,不做单点。
- **数据验证(语料末窗未成型帧,W330 缺口A 表)**:hp<25 的 12 帧归应急(FLIP 设计上让位,非漏检);[25,40) 5 帧、[40,45) 2 帧、hp=54 的 1 帧——投影判据吃下后三组共 8 帧(战后血量 54−34=20<25,同样必入应急带),非末窗帧不受影响。
- **与 emergency_hp=25 的边界(防双触发)**:hp≤25 应急态(`filters._is_emergency`)全权接管,FLIP 让位;末窗投影命中但 hp≤25 的帧同样归应急(彼时清仓/保命优先于找件)。两谓词辖区:[25,∞) 归 FLIP 评估,≤25 归应急,不相交。
- **与守 50 线的边界**:守 50 线(`interest_floor=50`)管「<50 别乱花」;FLIP 管「>50 溢余必须花」。**预算恒 = g − 50(W330 攻击⑥:扩展到 g−30 的说法删除——那是外衣下的新增破息例外,与「不新增例外」自相矛盾,且触 `cw_economy` hp≥30 存金地板零余量)**。位面中段深泄息的利息成本公式仅留作灵敏度参考(results.json `ev_release_deep_to30`,标注非谓词),若 sim 批证明溢余段不够用,深泄息须走独立 ADR 立例外,不在本设计夹带。
- **破息例外关系**:既有例外(r87 位面末追级豁免、boss_floor=10)是「为什么可以破」的列举;FLIP 是「什么时候该破」的谓词,只消费溢余段,不新增例外种类。语义上是 spend_mode 状态机的**新档 `release`**,插入点:`cw_horizon` DP 姿态→spend_mode 映射;与 emergency 的覆盖关系:hp≤25 → emergency > release。
- **release 与 rush_level 的同轮裁决(W330 攻击③,正面裁决)**:实读 `_horizon_node_goal`(cw_horizon L621-656)与 r87 位面末豁免(`_late_plane = round_num ≥ NODES_PER_PLANE−1` → P1 r8/r9 无条件放行 rush_level),按原「interest < release < level」排序,**level 必然在末窗吞掉 release——短路成立,原排序作废**。裁决为**同轮并存 + slot 守卫分流**:
  1. **slot 守卫先于姿态选择**:末窗评估 `deployed < cap`(有空位)时,追级的人口解锁边际本窗 = 0(新槽位下位面才兑现)→ rush_level 豁免**不生效**,姿态输出 release。run48 r9(deployed 5/6)正是此帧——裁决后该帧输出 release 而非 level。
  2. cap 满员且 bench 有可上阵件时,追级有真实 slot 边际 → 追级与泄息**同轮并存,同一笔溢余预算**:金分配顺序 = 先追级(费用 = 整级单击费,受溢余预算硬界约束:level_cost > g−50 时只买部分点击,DP 按 XP 进度分数记账)、剩余溢余归泄息找件。两动作消费同一溢余账,末窗破 50 的利息成本 ≈0(R'=0)由 C_break 公式计价,不新增例外。
  3. **第三路径显式注入(W333 N2)**:DP 姿态可为纯 level_up(动作码 4,`refresh_budget=0`)——slot 守卫压掉 level 后的落点若走默认顺序判,会落 `adaptive`/`interest`(hold),恰复现「泄息通道静默关闭」。规则:slot 守卫压 level 时**显式注入泄息预算** `release_budget = max(g − 50, p.refresh_budget × 刷价)`(DP 已有授权时不缩水,纯 level_up 帧取 g−50),预算>0 → 姿态强制输出 release,不落 hold。
  4. **三方刷金预算合并规则(W333 N2,同一帧三个独立预算来源)**:
     | 来源 | 语义 | 值 |
     |---|---|---|
     | FLIP/release 溢余预算 | **必须花的下界**(地板) | g − 50(折刷数 ÷ 刷价) |
     | DP `refresh_budget` | DP 授权的可刷上界(动作码 1/2/3 = 2/4/6 刷) | 见 `_ROLLS_OF_ACTION` |
     | plan 层 `_refresh_cap`(cw_evaluate L205,cw_plan L586 消费) | 评分层可刷上界(自带 HP-gate 与档金表) | — |
     合并规则:**FLIP 未命中帧维持现状** `budget = min(DP refresh_budget, _refresh_cap)`(既有两方,保守取交);**FLIP 命中帧 release 预算覆盖三方** `budget = max(g−50, DP refresh_budget)`,`_refresh_cap` 的 HP-gate 让位——血量维度已由 FLIP 谓词评估,同一维度只评一次防双主;`_refresh_cap` 的档金表仍作为刷价合法性校验保留。三种来源的优先语义一句话:**release 是义务(下界),DP/plan 是许可(上界),义务激活时义务优先,未激活时许可取交**。
  5. **实现警告区(W333 N2;生产修复归实现批,本设计给合并后语义)**:`cw_horizon._horizon_node_goal` L652-656 的 level_up 分支**即席返回 `NodeGoal(...,'level','rush_level')`,丢弃同帧 `p.refresh_budget`**——DP 明明算了 D 预算却被 level 分支整段吞掉(W154/ADR-0361 并行语义被实现短路)。合并后语义:level_up 分支不再即席返回,先按上表合并三方预算再构造 NodeGoal;`refresh_budget` 字段随 NodeGoal 下传,消费侧(cw_plan)按合并后预算执行。W154 并行先例(动作码 5-7 = 升级+D 并存)是「DP 内部两预算」先例,本设计是「release 外来预算 vs DP vs plan」三方合并——实现时不得套用先例掩盖合并规则缺失。
- **防间隙**:FLIP 为假时维持原姿态(无行为变化)→ 纯增量设计,旧行为是退化输出(A/B 可回归)。hp 读数抖动跨边界:消费 `hp_readable` 假帧不评估(既有 discipline 同守卫);投影判据在末窗只要求一次命中即激活本窗,窗内不回退(latch 窗口单位=boss 窗单轮,见②末窗定义,防 hp 39↔41 抖动造成姿态振荡)。

## ③ 换线判据

对候选线 c(候选集 = 过渡引擎池方向,`research/transition_combos` 口径):

```
distance(c) = need(c) − held(c) − shelf(c)        # 需求张数 − 持有 − 货架可见可买
E_rounds(c) ≈ distance(c) / per_round(c)
per_round(c) = (1 + 可负担刷次数) × p̄(c, lv)      # 自然刷 1 次/轮 + 买刷;截断到 bench 空位
```

- p̄ 同②超几何模型(P5 表实值)。demo(results.json `line_switch_demo`):lv6、distance=2 时「列车同行」E≈4.54 轮、「持续伤害」E≈6.02 轮(1 费件多、p̄ 更高)。
- **切换阈值 θ 与 p̄ 乐观偏差(W330 攻击④补课)**:p̄ 是理论满池值,未扣 NPC 消耗/争夺,系统性偏乐观 10-20%;在 E_rounds≈4.5-6 轮的量级上偏差 ≈ **0.7-0.9 轮,与原 θ=1.0 同数量级——直接比较会被偏差吃掉,产生「该换不换」的系统性假阴性**。修订:
  1. **先修偏再比较**:双线的 E_rounds 同乘 (1+δ),δ=0.15(NPC 消耗上界估计),把系统偏差从判据里消掉;
  2. θ 保留 **1.0 轮**,只承载剩余噪声(去偏后的双向估计误差),不再兼职补偏差;
  3. 切换条件:`E_rounds(alt)×(1+δ) + θ < E_rounds(cur)×(1+δ)` 且当前线驻留 ≥ D_min=2 轮(D_min 压振荡频率硬上限至 1/(2·D_min));
  4. **假阴性率进验证门**(原网格只测振荡率,漏测假阴性):sim 批同时验收「事后回看该换未换」的局占比 ≤10%(定义:弃线时点起 3 轮内原线完成距离无进展 ∧ alt 线可完成)。
- **切换成本显式计价**:1★ 卖出全额退成本(`cw_state.sell_refund`:1★ refund=cost×1 无手续费;手续费只对 star≥2∧cost≥2 −1)→ 凑齐羁绊前换线近乎零成本,唯一真实成本 = 2★ 已合成件折价(−1 金)与 bench 机会成本;D_min 之外无需额外切换税。
- **辖域声明(W330 攻击④)**:末窗(r≥7)D_min=2 驻留等价于禁换——**换线判据有效辖域 = 位面前中段**;末窗的线选择由「当前线在投影血量判据下的找件 EV」接管(②),这是设计内行为而非遗漏。

- **代理估计(语料实测)**:StartBattle 帧上场人数 × 该场 hp_delta,按 (plane, round) 轮内去均值消「人数多的轮=更晚的轮=更强的敌人」混杂。快照值(166 局):`3→4:+2.16, 4→5:−2.73, 5→6:+1.96, 6→7:−3.47, 7→8:+1.23`(正=人数多少掉血,hp/场)。
