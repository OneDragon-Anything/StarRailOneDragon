# 双王圣杯(A 级)

> V4.4 合集 76807134:A 级。攻略直读 [76985789](https://www.miyoushe.com/sr/article/76985789)。
> ⚠️ **调研曾误认"双王=大黑塔+景元群攻"(游侠源),原文核实 = 闪闪(吉尔伽美什)+Saber(Fate 圣杯联动)**,与红A 同属命运圣杯系统。

## 机制(怎么 work)
**吉尔伽美什(闪闪)+ Saber**:每行动 8 次进行一次**连携攻击**并为双方回大量能量。闪闪自加速,后台带鞋快速刷行动次数 → 前台 Saber 高频开大。
**命运圣杯羁绊**给经济 + 改件,加速合成 3 星 + 提升强度。

## 成型阵容
Saber 主 c(风暴潮+冷笑话+永动机)+ 闪闪后台(鞋)+ 杨叔(必备)+ 刃(后台辅助装)+ 缇宝 + 符玄(阿瓦隆+绝对热量)。
- 羁绊:**5 能量**(加快 Saber 回能+伤害增幅)+ 命运圣杯
- 改件:2/3/4 圣杯可能开命运改件(阿瓦隆最适合 Saber,天地乖离开辟之星适合闪闪,没改件也能用圣杯资源)。

## 成型节奏
1. **前期**:体系牌过渡 + 通用花火;也可挂**凛做 3 圣杯任务**。装备不好可用任何高练队过渡(别忘了圣杯任务)。
2. **7/8 级找 3 星 Saber 或 3 星闪闪**;能 3 星一个就上等级,快 3 星了也上。
3. 8 级(无杨叔)就能过关,**上 9 挂杨叔**上限更高。

## 装备
- **Saber:火力风暴潮 + 冷笑话引擎 + 永动机**;**闪闪后台:反重力皮靴**。
- 符玄:**阿瓦隆 + 绝对热量**(邪修:阿瓦隆携带者受伤生命不低于 1 → 符玄前台风阿瓦隆+绝对热量,全队 75% 减伤+回血几乎不死。可能被修复)。

## 变体
- **闪闪 c**:闪闪率先 3 星/高配/有专属改件 → 闪闪前台带 Saber 装,Saber 后台带鞋。
