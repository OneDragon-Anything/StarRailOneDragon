# P58(草案):阶段期望等级日程由游戏定义量派生

> 状态:**草案/证明骨架(未证)**——ADR-0519 组5-A 处置件。按处置规则 A:
> 数值落码须等证明完;证明完成前 `_expected_level`(cw_economy)现行数值
> 维持现状(社区先验,已标【拟】),证明输出落码时按结论重derive 或退役。

## 命题陈述

存在一个仅由游戏定义量构成的函数
`L*(plane, round) → {1..10}`,使得「等级地板策略」(落后 L* 即追级、
达到即停留)在期望金口径下支配任意其他等级日程;`_expected_level` 现行
表(P1 r//2+4 钳 6;P2 2-1→7/2-6→8;P3 3-1→8/3-3→9)与 L* 的偏差
逐格可判(一致 / 保守侧 / 激进侧)。

弱化形态(若支配性不可达):给出 L* 的可计算刻画(如「升级当且仅当
P39 升级 EV 双臂门在该格为正」的日程包络),并声明现行表相对包络的
方向偏差。

## 输入(全部游戏定义量,零拟合)

- XP 费用表 `XP_TO_NEXT_LEVEL`(cw_state,机制真值)+ 单击 XP 价
  `xp_click_cost`(OCR 实读优先,flat-4 兜底,ADR-0275);
- 收入日程 Ī(基础奖励×节点类型表 + 息律 50/10 + 连胜金表
  `STREAK_GOLD_TABLE`,全部注册表真值);
- 商店刷率表 `cw_shop_odds`(等级→各费档出现率;峰值级
  peak_refresh_level 可由该表导出,非独立常数);
- 出战位/人口解锁表(等级→出战上限,注册表);
- 节点日程真值 `nodes_of_plane`(ADR-0366:9/7/7)。

## 证明思路

1. 把等级日程建模为 (plane, round) 格上的序贯决策:每格动作 ∈
   {停留, 升一级},成本 = clicks×单价(P48 整买纪律),收益侧只取
   游戏定义通道(息律可达性 g≥50 的档位、刷率峰值级可达性、人口位
   解锁)——**不引入胜率/伤害换算**(宪法第一条;与 P39 双臂门同构,
   λ_death 敞口只进概率侧)。
2. 对每个格子构造两条日程的期望金差(升 vs 停),用 P47 息账递推 +
   P38 命中概率 DP 计算两侧窗口值,证单调性(收益随剩余轮数衰减)
   ⇒ 逐格阈值形态存在 ⇒ L* 由阈值条件唯一刻画。
3. 数值表:L* 逐格输出与现行 `_expected_level` 对拍,偏差逐格标注
   方向;激进侧格(现行表更早追级)按「未证即退役」处置(地板回退
   L*),保守侧格可维持或收敛到 L*。
4. 检验点:sim 对拍(现行表 vs L* 日程的同池同 seed 臂差,健康带
   刷新率/出口金两指标);实机 replay 的等级轨迹分位核对。

## 边界

- P2/P3 敌强度跳升(「人口不升=硬吃两仗」)若无法用纯金流量化,
  则该侧格维持现行表并显式标注「用户节奏面」(与 _xp_gold_floor
  同类,宪法允许的用户策略面),不冒充推导结论。
- 证明若仅得弱化形态,`_expected_level` 的处置降级为「按包络方向
  逐格复核」,表本身保留并整体标注数据来源分级。
