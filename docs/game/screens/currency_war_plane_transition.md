# 货币战争-位面过渡(位面间推进过渡屏)

每打穿一个位面(击败该位面首领)后、进入下一位面前的全屏过渡屏:展示 3 个位面节点(已完成/当前/未到)的进度,底部「点击空白处继续」推进。

## 何时出现 + 状态流转

- **入口**:击败某位面首领 → 结算 → 本屏(位面过渡)。
- **出口**:点画面空白处(提示「点击空白处继续」)→ 下一位面的**备战**屏。
- **出现时机**:位面1→2 过渡(打穿位面1首领后)、位面2→3 过渡(打穿位面2首领后)。打穿位面3首领后**不出现本屏**(直接进对局结算/match-over)。
- **子态(节点高亮变体,同布局)**:
  - **位面1→2 过渡**:节点1 金色高亮(已完成)、节点2 蓝光(当前)、节点3 深色(未到)。fixture:`plane_1to2.webp`。
  - **位面2→3 过渡**:节点1,2 金色(已完成)、节点3 蓝光(当前)。fixture 待采(`plane_2to3.webp`)。

## 识别特征(稳定锚点)

- **位面节点2「位面」文字**(上中偏右,~(950,376))+ **位面节点3「位面」文字**(上右,~(1475,376))—— **组合 id_mark**(两个都命中才精准)。CW 位面过渡独有:3 个「位面」横排 + 数字编号 1/2/3。模拟宇宙等他屏无此组合。
- **「点击空白处继续」**(下中,~(960,960))—— 推进出口提示,非 id_mark(模拟宇宙等他屏也有同名 area,撞车源,故不单独作锚)。
- ⚠️ **勿单用「点击空白处继续」当 id_mark**:模拟宇宙(`sim_uni.yml`)有同名 area → 两个画面并列 is_precise=false。用位面节点组合锚解决(2026-08-14 建档前此屏 is_precise 恒 false)。

- **当前位面进度**:节点高亮态(金色=已完成 / 蓝光=当前 / 深色=未到)指示打到第几位面。bot 当前直接点空白推进,未细读节点态(位面进度可从 round 数推)。
