# 万敌单C·燃血(B 级,debuff=buff 典型)

> V4.4 合集 76807134:B 级。攻略直读 [77056698](https://www.miyoushe.com/sr/article/77056698)。

## 机制(怎么 work)
万敌每**登神一次永久 +100 生命上限**;充能不受血量提高干扰(解决了"生命 c 越高伤越低"问题)。
V4.4 刃加入 + 敌人伤害速度提升 → 万敌再成可玩。**debuff=buff 典型**:掉血越多登神越快越强。

## 成型阵容
万敌(前台单挂受击)+ 昔涟(永动机,立刻登神启动)+ 刻律(复制登神)+ 娜塔莎(2 治疗+增伤)+ 杨叔 + 符玄/花火/缇宝/刃(通用拐)。

## 成型节奏
1. 前期**万敌前台单挂,其他全后台**(多受击登神);没符玄用周日替。
2. **4/5 级追 3 星万敌**(不像阿雅能靠鞋抹平 2/3 星差距)。
3. 上 8:找杨叔/昔涟上,**不能上符玄**(分摊机制减万敌受伤!)→ 前台保持 1 人,可弃 1 人口。
4. **上 9 同时有杨叔+昔涟才登完整阵容**。自己万敌不上 9 可胜。

## 装备(为什么)
- 万敌**火力风暴潮 + 绝对热量 + 风暴潮/热血沸腾拳**(必备;吃装备,1 位面 boss 门口凑齐)。
- 昔涟**永动机**(立刻登神启动)。

## 弱点 / 注意(debuff=buff)
- **利**:忍无可忍 / 正当防卫 / 灼热轰炸(掉血/AoE/反伤 → 利燃血登神);应激反应/一鼓作气算半个。
- **克**:**永久创伤(掉血削上限)→ 不可玩**。
- 试用需:来牌顺(3 星万敌+上 9 昔涟杨叔)OR 合适负面词缀。
- **超光速提拔**爽局(阿雅/万敌看装备偏哪)。
