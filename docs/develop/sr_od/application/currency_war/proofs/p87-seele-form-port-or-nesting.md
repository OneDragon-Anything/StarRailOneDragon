## 命题(形式化)

对四体系的全部 6 个配方对,记 C_code = 批序 1 改前成型谓词(对方体系满档
∧ 量子同频≥3 ∧ 贝洛伯格≥2,借 cw_recipe 完全体档 AND 账,无 carry 合取
支)、C_doc = 文档口径谓词(希儿在场 ∧ (量子同频≥2 ∨ 贝洛伯格≥2),
transition_combos.md:27 定义表行;combo_methodology.md:133「凑到任一=
成型」/:138「希儿到手 ≠ 希儿线成型」)。事件域 = 「从空场(仅希儿已
部署)出发,T 轮窗口、每轮 ρ 次付费刷新预算内集齐判据件集」。

1. **静态裁决**:三个非希儿对(仙舟3+持续伤害2 / 仙舟3+列车2 /
   持续伤害2+列车2)C_code ≡ C_doc(合取支逐字相同——AND 是文档意图,
   判据不超重);三个希儿对在条件域(希儿已部署)上 **C_doc ⊇ C_code**
   (量≥3∧贝≥2 ⟹ 量≥2∨贝≥2,反向不成立)。
2. **完成率嵌套【推】**:由事件包含 + P38 构造单调性(件数↑/单件需求↑
   → 概率↓),对每个 (T,ρ) 格 P(C_doc) ≥ P(C_code)。推导级结论,零
   数值标定依赖;表值只量化差距,不承方向。
3. **差距集中在残局域**:窗口轮数少 ∧ 付费刷新少的格差距最大;满窗口
   或充足刷新时两判据饱和、差距消失——解释超重判据平时不察觉、恰在
   残局换入场景(批#8 五局 R6-R8 换入全失败观测形态)爆发。

## 证明

### ① 静态包含(条件域)

游戏计数关键事实(注册表直调,data/cw_chars「希儿」行):希儿
`factions=('贝洛伯格',), flows=('量子同频',)`——同时计入两池在场计数
(羁绊按注册表标签逐成员累计,与 `_p1_system_support` 计数口径同式)。
条件于希儿已部署:文档口径剩余需求 = 再任 1 名放大器(8 名池,量/贝
任一);代码口径 = 再 2 名量子池成员 ∧ 再 1 名贝洛伯格池成员。任一
「量池再 2 + 贝池再 1」实现必然含「量池 ≥2 或贝池 ≥2」(≥2∨≥2 被其
超集蕴含),反向不成立(量 2 贝 0 实现不满足量 3)。非希儿对合取支
逐字相等 ≡ 平凡。∎

### ② 嵌套【推】

C_doc ⊇ C_code(①)+ P38 构造单调性(判据件集按格点包含时,「集齐
小集」事件包含「集齐大集」事件)⟹ 全 (T,ρ) 格 P(C_doc) ≥ P(C_code)。
纯集合/概率测度论证,不消费任何估计值。∎

### ③ 数值确认(闭式口径,P38 ③层单槽命中 + 二项尾)

复算配方(`_recalc_por.py` 直调注册表,`_recalc_out.txt` 全格落盘;
P38 假设 A4 等级日程输入显式声明):q̄ = Σ_c p(L,c)·|合格集∩c|/v_c;
P(Bin(5N, q̄) ≥ n),N = T·(1+ρ)。主窗口 T=9 ρ=0:非希儿对 0.83-0.86
(code≡doc),希儿对 code 0.60-0.63 / **doc 0.89-0.94**;残局域 T=4
ρ=0:希儿对 code 0.08-0.10 / **doc 0.45-0.51**。嵌套全格零违反(2 轮序
×2 窗口×4 预算×3 希儿对 = 48 格 P_doc ≥ P_code 全成立);残局域绝对
差距 +0.36~+0.43。

1. **①为条件域结论**:包含论证条件于希儿已部署(F3);全域上 carry
   合取支是新增收紧面——本批预期含「无希儿不再 form_ok」型翻转帧,
   属轴③修复的正确行为,非放宽的面。

   归属挂玩家确认,确认后改 `SEELE_OR_LEGS` 单一源

   影响:嵌套由事件包含独立保证(②),不经积形式。
