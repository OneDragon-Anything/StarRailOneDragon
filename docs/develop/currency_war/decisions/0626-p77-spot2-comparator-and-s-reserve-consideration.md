- 日期:2026-09-10
- 关联:math_proofs **P77**(已收口:无前提对抗审 3 修正+5 备注全折+轻量复核零再修,本批为其指认下游「缺口面1 比较子设计」的落码批)、P01(再遇窗——缺口面3 的量值源)、P76 甲.3(星级费用实付)、ADR-0517(单动作形态/计数键粒度)、ADR-0624(结算线地板,买面判据先例)、merge_mechanics §2.6/§2.7(直出机制×3 律实锤)、T-120 方案 §6.1/§6.2(A/B 载体形状);任务书面 = `.debug/temp/currency_war/T-122-装载设计.md`(先于 A/B 跑批落盘,判据锚见其 §3.3)

## 背景

P77 审计落定:P01 折现项的体系层三处合法消费位在生产全部未装载,其中缺口面三件可动:①j=1 帧同名 2★ 直出现货被 `m2_stockpile` 星过滤单侧拒(`m2_stockpile_star_mismatch`),比较子不存在,现货溢价 = c_eff·E(D|j=1,k=3) − c_base 全档>0(30.9~80.7 金【推】,直调复算);②V_slot 未装载——按 P77 §7【拟】#3 门(u/U_X 未标定,fail-closed = 现行缺省放行维持)**本批不落码**,装载归在册标定批;③s_reserve 拒帧无对价侧——「留保息 vs 收现货」权衡无量值载体(让路裁决归 P56 设计批,P77 明文不裁决)。归层 = 决策层·买面比较子/遥测载体,非识别/路由/执行层。同时,T-120 批 2-3 已交付 prep 域实体化假环境,A/B 载体自该批成立(T-120 批 2 申报),本批为 A/B 编排迁测试仓 runner 的落位批(方案 §6.1)并承载 P77 的确认性对拍。

## 决策

1. **缺口面1 比较子落码**(模块级 `shop.spot2_direct_out_card`,P77 §2.2 原式,零新自由参数):m2_stockpile 臂内,1★ 候选缺席而同名 2★ 直出在售帧,经比较子(DIY 账 = 2×基价 + c_eff·E,现货账 = 徽章实付 card.cost)放行买入;E 单一源 = `expected_refreshes_for_card(level, base_cost, 2, owned=1)`,c_eff = `shop_refresh_cost or REFRESH_COST_BASE`(P77 备注7 基价口径),基价 = `CHARACTERS[name].cost`(roster,与徽章读数解耦)。**fail-closed 边界**:p(level,基价)=0 帧比较子判不可评(E=0 系函数约定非零成本)→ 维持星过滤拒——P77 溢价表覆盖可行 DIY 域,域外延未证不入。席/金交互 = 与 1★ 路径同闸序(金闸前置 → M4 腾席),比较子只裁「值不值」;买入后 cnt2=1 臂触发自灭(既有二-1 守卫防重复)。j=2 维持 M2b 星过滤拒(P77 备注5:DIY 再买 1★ 严格占优,禁重开);j=0 帧归 M2 既有无星过滤臂(不涉)。
2. **遥测分键(零静默;义务 reason 键不扩闭集)**:买入路线计数 `m2_stockpile_spot2_buy` 新增;buy reason **复用 `'m2_stockpile'`**(同一义务通道的达成路线,不新增 LAUNCH_CAUSE 闭集键,P88 豁免集 15 键零扰动);`m2_stockpile_star_mismatch` 语义收窄为「比较子后仍不买」,过比较子后闸失败落既有闸键(`stockpile_unaffordable`/`bench_full`)不再被伞形吞。
3. **缺口面3 对价载体落码**(纯遥测,不改决策):新公开 helper `cw_shop_odds.reencounter_window_frames(level, cost, held)`(1/P(≥1 张/帧),超几何单一源,P77 §1.4「再遇窗 1/q」同式);M6 面 `stockpile_buy` 返回 `s_reserve` 拒帧处,累计被拒现货再遇窗(自然帧 ceil,held 按 1★×1/2★×3/3★×9 折算)入新键 `m6_s_reserve_remeet_frames_sum`(事件键 `m6_s_reserve_reject` 已在)。载体=聚合量(均值=sum/count),逐帧分布与让路裁决归 P56 设计批。
4. **无开关**(strategy-work §3-1 形态):授权来源 = P77 已证命题(丙.3 a=主形态;甲.2 信号价值只在买动作兑现;丁.1 溢价对锁线判据零影响——买面加成不碰 θ\*),A/B 仅为落地后确认面,不构成保留开关的理由。回滚靠 revert。
5. **A/B 载体装载(测试仓)**:`fixtures/cw_ab.py`(加载面 = 逐 (seed, arm) `fake_p1_run` 全链装配;切换面 = 基线臂 monkeypatch 关闭比较子槽位——**对照手段不进生产代码**;对照面 = 同 seed 配对 Δ + 逐臂中位/p90,无数值裁决权)+ `tools/cw_ab_batch.py` 驱动(上下文自建,脱离 pytest 可跑)。
6. **假环境直出 2★ 通道**(否则比较子在 A/B 结构性无帧,违「新机制先验证它会开火」):机制锚 = merge_mechanics §2.6/§2.7 实锤(直出存在、×3 律);频率 = `rules.SHOP_DIRECT_OUT_2STAR_P = 0.05` **校准层演练偏置**(真值「概率待实机调研」零样本存档,禁把该速率下频次读成真值估计;真值随采集批回填并再升 env_version);池余 <3 基础副本不升档;env_version 终态 = **v6 合流**(分布面变更,跨版禁裸串比;终值与语义 = 编排者二次裁决 2026-09-10:v6 = v4 基础 + 直出通道(本批 T-122)+ 投资注入位(T-204)双语义一次升版合流出版,中间态 v5 曾短暂挂直出单语义未出版;投资域由指纹位 `invest_injected` 区分)。

## Considered Options

- **A(取)如上**:比较子 + 对价载体 + V_slot 维持 fail-closed + A/B 载体随批。
- **B(否)为 A/B 加生产开关**:strategy-work §3 明禁(「A/B 判正→落码」旧流程作废,对照手段不进生产代码);测试侧 monkeypatch 槽位等价且零生产债。
- **C(否)本批一并装载 V_slot**:u/U_X 未标定,数值不可申(P77 §7【拟】#3 fail-closed 在册);装载归标定批,本批越权即引入无源数值。
- **D(否)比较子扩 j=2 帧**:P77 备注5 证 M2b 现行拒严格占优,禁对称重开。
- **E(否)s_reserve 让路裁决**:P56 辖域(P77 明文「本命题不裁决」),本批只落量值载体。

- 买面行为变化域 = m2_stockpile 臂 j=1 帧 2★-only 帧(原先恒拒)+ M6 s_reserve 拒帧新增遥测键;其余臂/信念面/锁线判据零改动(丁.1:溢价不进 Γ/O/F/B/C/D 任一项,锁线阈值无影响通道)。
- 计数键登记:模块 docstring 键节已增补(`m2_stockpile_spot2_buy` / `m6_s_reserve_remeet_frames_sum`);拒因枚举面(`cw4_shop_rejects`)零变化。
- 三同步:strategy-docs/11_shop_decisions.md 买面 as-built 行随批更新;math_proofs INDEX 状态列不因本批变更(P77 状态已收口,装载为本批行为,非命题修订)。
