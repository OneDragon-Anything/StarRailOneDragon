# 02 骨架行为层（mandate 层塌缩件）

> 塌缩来源：`archive/design/DESIGN_MANDATE_LAYER.md`（骨架行为层根设计件）——本篇收其现行语义（含 R-SYNC 同步后的 M3/M4/§3.3/§3.4 口径），设计期迁移路径与批注史不搬。落地载体 = `decision/cw4/` 策略包（证明/骨架/判据/状态函数分层），单一核代号 **mandate_v1**。
> 前置阅读：[00_framework.md](00_framework.md)、[01_math_framework.md](01_math_framework.md)。
> 术语：**骨架义务** = 不做会输的动作（无条件执行）；**EV** = 做了更赚的优化动作（只增不减）；**证明层** = 决定为谁做（线选择）。

## 1. 为什么需要骨架层：多代重构失败根因

（出处：DESIGN_MANDATE_LAYER §1，三轮 A/B 归因——s0/r2/r3 批，`archive/redesign/reports/AB_*_ATTRIBUTION.md`）

- 三轮 A/B（新 cw3 vs 旧 decision_v2，同 seed 同池）的失败形态逐一归类：**「没做」占绝对主导**——部署 0/934、卖出 0→43/287、升级金 1940/5792、席满拒买 1163 笔/13 笔、零动作轮 35%/4.5%、花费率 0.384/0.68。没有一项是「执行了但方向错到显著损失」。
- 失活机理三种：①机器整块缺失（部署机不存在）；②**权限错位**（义务被降级为某个 EV 证明的从属品——升级被 P39 臂二「何时升」证明整局否决，是义务与优化器权限混淆的直接证据）；③输入缺失 fail-closed 装错动作。
- 金约束门不是凶手：三轮探针数据金约束门合计 ≈0 次拒——门正确但不起作用；真正杀人的是义务缺位后资产形态劣化，让约束门在劣化态下「正确地」继续关门，形成静默螺旋。修复主向不是拆门，是**把义务立起来**。
- fail-closed 有对有错（r2 H1 散刷事故证明该关的不关会烧钱）：按动作可逆性分（§5）。

## 2. 三层权限模型

```
┌─ 证明层（线选择与终局）────────────────────────────┐
│ 证据门（03 §4.2）/ 换线机器（03 §4.3）/ 停手线（[13]） │
│ 职权:决定骨架为哪条线服务;给 [41] 供给目标线 S         │
│ 无权:否决任何单笔骨架动作                              │
├─ 骨架层（义务,mandate)────────────────────────────┤
│ 每备战期无条件生成动作,只受硬约束（§4）拦截            │
│ 输入缺失 → 按可逆性定向默认（§5）,禁静默跳过          │
├─ EV 层（优化器）──────────────────────────────────┤
│ 刷新/压库/连胜金/装备/事件决策;只增不减:              │
│ 可在骨架之上追加动作,无权否决或改写骨架动作           │
└──────────────────────────────────────────────────┘
```

权限判据一句话：**「不做会输」的是骨架（义务），「做了更赚」的是 EV（优化），「做给谁看」的是证明（线选择）**。

## 4. 硬约束的封闭定义（唯一合法拦截集）

骨架动作只被以下条件拦截，此外任何门（EV、标定、息律、血预算）**无权拦截**：

1. **可负担**：金 ≥ 动作成本；
2. **席位存在**：board/bench 槽位、等级 cap、同名同星≤1；
3. **S 预留保护**（[41]）：待执行整买目标线 S 的预留金不被非 S 组成的骨架动作吃掉——但 M3 升级本身与计入 S 的 M2 买不受此限；
4. **不可逆护栏**（§6）：卖出线内件、无目标刷新不属于骨架动作集。

**HP 不在硬约束里**（[39]；00 §3 硬闸门）。曾有「危局接管门（hp≤40 越权）」提案，本设计**不采纳该形态**：hp 拦截/接管骨架违反硬闸门辖域。现行架构增设**升档器独立薄层**（血线硬地板触发帧解锁包 + λ 顾问只升不降）显式承接危机响应；边界钉死：hp 在新架构中仅作**风险路由键与解锁触发**，**仍不作骨架动作的拦截输入**。骨架常开使席堵/等级落后两类危机成因被 M1-M4 直接消解，濒死转化通道结构性为空的残余帧（R28-2 三合取）由升档器承接——「义务常开 + 升档器兜濒死」优于「危机态特设接管门」。

## 5. 输入缺失时的落点：按动作可逆性定向 fail

（三轮「静默蒸发」的直接修复面；DESIGN_MANDATE_LAYER §3.4 现行口径）

| 缺失输入 | 骨架行为 | 禁止行为 |
|---|---|---|
| 池参数/期望刷新数未标定 | M2 照买（买本身无损，[11]） | 拒买 |
| 板面收敛度/结构可达计数异常 | 退化为「与任一 TRANSITION_SYSTEMS 成员重叠即线内」（executor 内置缺省表明文收录） | 判序 6 停买 |
| M3 触发输入（arm1 结构谓词读数）缺失 | 退「等级落后于上阵人数需求」朴素判据 | 整局 defer（XP 支出不可逆，缺输入默认不触发 ≠ 默认触发，退可观测朴素判据） |
| 线内/线外分类不确定 | 该件**不卖**（可逆方向取保守）+ 记待判 | 卖出 |
| sell_refund 注册表读数缺失（运行时损坏态） | 分面：买侧风险界消费位缺 ⇒ 拒买；卖面消费位缺 ⇒ 拒绝评估、不新增卖出 + 报警（槽位 None + 强制停，与 λ 表损坏态同款守卫；「1★ 全额退」假设的合法辖域收窄为买面/EV 下界场景） | 按「1★ 全额退」假设放行卖出评估 |

**原则：可逆动作（买/部署）缺输入 → 默认做；不可逆动作（卖/刷）缺输入 → 默认不做。** fail-closed 从「全局默认」改为「按动作可逆性定向配置」。数学侧镜像（01 §6）：未标定参数在 EV 层一律 fail-closed（不产生追加动作），**绝不向骨架层渗漏为一个否决**。

## 6. fail-closed 的正确落点（保留清单）

1. **卖出线内件/骨架件/通用插件**：P18（无损卖出证明域）、ADR-0433（form 破坏卖出拦截）；卖出 2★/3★ 有手续费且不可逆。
2. **无合格集刷新**：P40（战斗向刷新收益在无目标时为负）、[1]；刷新是纯成本，无「活期资产」属性。
3. **升级调度门**：现任 = arm2 结构守息门（g*=10×cap_resolved，零 λ 依赖）+ λ 顾问分位触发帧收紧（只延迟 arm2 调度类批，arm1 已触发义务不在延迟对象内）；**只延迟不否决**权限语义不变。
4. **序 6 纯冗余停买**：[13] 三分法第三类（辖域 = 边际贡献 0 的纯冗余）。

## 7. 与决策机器的关系（权限划界）

落地方式 = 新建 cw4 策略包（`decision/cw4/`，证明/骨架/判据/状态函数分层）与冻结基线 decision_v2 并存跑三臂 A/B；A/B 过线 = 整体删除旧决策包的触发门。权限划界（原八台机器的处置语义，仍是权威）：

| 机器 | 处置 |
|---|---|
| buy | 升格骨架（EV 剥离）：序 1/序 2 走 M2 义务通道；序 3-5 留 EV；息律域只对 EV 买生效 |
| sell | 升格骨架（单向）：M4 腾席方向义务化；线内件禁卖护栏保留（只保留「卖杂件」一个义务出口 + 其余 fail-closed） |
| levelup | 升格骨架：M3 arm1 去 board_vacancy 依赖；cap 感知；arm2 降为调度门 |
| opening / deploy | 升格骨架：M5 / M1（deploy 为核心修复位） |
| refresh / streak_money | 保持 EV |
| equipment | 保持 EV + M7 骨架地板 |
| completion（证据门） | 上移证明层：只产出线选择与 L(r) 场景，无单笔否决权 |

## 8. 可测命题（判据骨架）

**命题 A（骨架-only，EV 全关进 sim）**：n=40 同 seed 配对，基线 = legacy_v2。判前锁预期：零动作轮 <5%、花费率 ≥0.6、bench 满拒买 <100 笔、SellBench ≥200 笔、P1 升级投入金 ≥5000、CompTransaction ≥700、成型率（≥2 体系）≥80% 局、P1 末 hp≤40 局 ≤18/40。目标②（过渡阵容稳定过位面 1）：P2 入口率 100% + P1 零死亡 + P1 末双体系 ≥80% + 进 P2 时 hp>40 局 ≥22/40 + 哨兵不越线。未达 = 假设证伪，回 §1 重新归因，禁调参续跑。

**命题 B（骨架+EV 增量对照）**：三臂同 seed（骨架-only / 骨架+EV / legacy_v2）。EV 层存在的合法性检验：骨架+EV 相对骨架-only 无任何主指标增量 ⇒ EV 层降权为可选（优化器必须证明自己值钱）；相对 legacy_v2 过 PREREG 全量判据 ⇒ 批删旧包。

> 注：判前锁版本与判据集的现行态以实现批预注册件为准；本节收设计期判据骨架。
