# 转型域换人通道统一设计 迭代设计（总纲）

## 0. 元信息

- 迭代目标：用户裁定 2026-10-26（登记载体 = 本迭代进度账本 T-1 note）：换人策略按羁绊组双门 + 转型域五层统一收益-安全框架落地（治本方案）；净战力不证明（宪法第 1 条禁战力建模），行为锚点验收；P61 证明退役。
- 状态：对抗审中
- 文档清单：无详设（单文档方案，本篇即完整设计）

## 1. 问题与动机

- 现状症状：sim 局 g_20261026_203023（seed=20261216）复盘立案 C1——2-1 买主线核心 Saber 后 4 个备战期换人卖出 0 发射，板面保持位面 1 过渡配方直到死亡（复盘报告 = `.debug/currency_war/deep_review/g_20261026_203023.md`）。历史同病：strategy-docs/02_mandate_layer.md §1 A/B 归因「没做占绝对主导（部署 0/934）」；2026-09-18 板满换入分支为同病第一件补丁（`kernel/cw_deploy_logic.py` `required_swap_arm_pending` docstring 出处行）。
- 根因归层：**语义层 + 架构层**。语义层 = 换入判据语义单位错置（单件「一步成型」对多成员多档位阵容结构性不可达）。架构层 = 同一换人动作帧上有**五层独立判据**（触发/守恒/素材/放行/窗口）层层封堵，五层各自演化：判定对象不一致（有的看换前 victim 单侧、有的看换后）、守恒对象不一致（守过渡配方还是守终局未统一裁定）、判据折法不一致（✗→✓ 与 Δfp 并存）。**只修触发层不达效**——其余层照样封死同一批 victim（素材守卫拒卖待合成件、守恒门拒卖羁绊承载件、放行门自带第二套折法）。本迭代为同族病第二件，按跨件半问升架构级：公共根 = 五层缺统一「收益-安全」判定原则。
- 解决到哪：五层统一到单一判定原则（§2.0）并逐层重裁定（§2.2–§2.6）；P61 退役（§2.9）。
- 明确不解决：买入面（M2/商店判据）；sim 战斗结算与 hp 校准；净战力强弱证明；经济/升级判据本体（放行层复算接线除外）。

## 2. 方案

### 2.0 统一原则（五层的共同判定动作）

**换人合法性 = 组换后板态 × 当前板面义务阵容。**

- **板面义务阵容**（域参数，判定权威 = `cw_intention.committed_authority` 现行）：双轨期（P1 配方对锁，`ist.p1_pair` 非空且终局未锁定）= 过渡配方；终局锁定生效 = 锁定终局阵容。
- **组换后板态** = 板上单位集合 − 换出 victims + 换入组 的派生视图；档位与支撑计数按 §2.1 在该视图上现算。
- 五层全部消费同一判定函数（单一源），**禁各层自备第二套折法**。

### 2.1 支撑件与档位（口径定义）

- **支撑件 = 终局名单成员（k_members）∪ 羁绊标签命中 `form_tiers` 键集的外部件**（并集）。名单成员无条件计入（瓦尔特/符玄零标签命中仍计入——名单资格即支撑资格）；外部凑档件按标签计入（如任一能量标签单位凑能量档）。
  - 依据：`data/cw_chars.py` 标签实测（吉尔伽美什/Saber=圣杯+能量；开拓者·记忆/藿藿=含能量；瓦尔特/符玄不含）；`data/cw_factions.py` 档位表（命运圣杯 2/3/4/5、能量 3/5/7/10）。
- **终局档位**：板上（或组换后板态上）各终局羁绊人数对照 `form_tiers` 现算激活态。
- 双轨期对应概念沿用现行过渡配方件/配方档位语义（cw_recipe 模块不变量），本迭代不重定义。

### 2.2 触发层：羁绊组双门

- **门 1（收益门，满足任一）**：
  1. 组换后激活终局羁绊新档位；
  2. 组换后支撑件数严格增；
  3. 同名升星横换（换入件星级 > 被换件星级）。
- **门 2（安全门，逐被换件）**：现行 `swap_sell_exclusion_reason` 全链零豁免——义务集、新鲜度排除、资格族（`merge_material_guard` 素材守卫 / `engines_guard` / `star_guard` / `fenced_arm_closed` / `target_keep` / `fp_unreadable` 等拒因面全量保留，D14）。
- 用户三触发条件的映射（换前组形态 → 换后板态）：终局羁绊到二阶 → 门 1①；另一羁绊到一阶 → 门 1① 或 ②；一阶羁绊 + 终局散件 → 门 1②。
- 档位判定的羁绊范围 = 终局阵容 `form_tiers` 键集，不含其他羁绊。

**枚举情形表**（放行/拒绝判定；均为门 1 面，门 2 独立叠加）：

| 情形 | 例子（双王圣杯语境） | 组换后板态 | 判定 |
|---|---|---|---|
| A 终局件进、过渡件出 | Saber 换停云 | 圣杯 2 保持、能量 2→3 新档 | 放行（①） |
| B 外部凑档件进 | 阿格莱雅类换青雀 | 能量 5 新档、支撑数增 | 放行（①②） |
| C 整组换 | 开拓者·记忆+藿藿 进、两过渡件出 | 支撑数 +2、能量新档 | 放行（①②） |
| D 同名升星横换 | 板上 1★ Saber、备战席 2★ Saber | 数量持平、星级升 | 放行（③） |
| E 终局件横换终局件 | 瓦尔特换符玄 | 无任何结构收益 | 拒绝 |
| F 卖终局档位承载件换外部件 | 卖开拓者·记忆换能量件 | 档位降或承载受损 | 拒绝（保护集禁卖 + §2.8 演进排除） |

### 2.3 守恒层：守恒对象域参数化（治本核心）

- **守恒对象 = 板面义务阵容**（§2.0 域参数）：双轨期守过渡配方档位（现行 `engines_guard` 语义与对象不变）；终局锁定生效期守**终局档位**。
- **判定口径从「victim 离场单侧损失」改为「组换后板态净值」**——换入组带来的档位计入判定。锁定域的守恒判定 = 门 1 的档位非降面，**同一函数，不设第二实现**。
- 效果：转型域解锁羁绊承载型 victim（停云/爻光/青雀类——其过渡羁绊掉档由换入组的终局新档覆盖，即用户裁定的「拆掉过渡阵容的羁绊」）；A1 类死局（victim 池被素材+守恒联合清空）由此解除。
- 实现落点：守恒判定收敛为单函数 `f(义务阵容, 组换后板态)`，域由调用方传义务阵容；`engines_guard` 现行调用面迁移到该函数（迁移批零行为差验证：双轨期逐位同旧）。

### 2.4 素材层：零改动

`merge_material_guard` 绝对禁卖不变，不设转型豁免（其关切 = 合成进度的经济价值保护，成立）。转型死局由 §2.3 解除，不需要动本层。C1 帧核验：远坂凛持续受保护（bench 有第二张，`same_star_count=2`），停云/爻光/青雀解锁为合法 victim。

### 2.5 放行层：废弃第二折法，改复算统一门

现行 P79-3 三轴（`mandate.py` 部署执行放行门）废弃：轴② Δfp>0 与门 1② 系统性冲突（Δfp 折法已弃，§2.11）；轴① bench∩membership 使「仅剩外部凑档件待上」帧结构性发不出。改为：**计划落地前对预期组换后板态复算门 1（门 2 已逐件过），一致才放行**——放行层不再是独立判据，是统一门的复算确认（单一源）。

### 2.6 窗口层：零改动，显式声明

方向线成员豁免照旧（`strategies/impl/mandate_v1/entry.py` 现行豁免，实现批核符号锚）；外部凑档件无 `entry_signals` 登记 = 不受窗口辖（辖域定义 = 知识卡 `entry_signals`，22_prep_screen.md §1 第 6 步）。

### 2.7 组配对算法与执行形态

- **最小充分组贪心**：候选换入序 = 名单成员先（星级降序）→ 外部支撑件（星级降序）；victim 序 = 过门 2 的 1★ 过渡件按现行价值升序（2★ 仅演进降级通道，§2.8）。逐个扩组：每入一个换入件从 victim 序配一个；每次扩组对组换后板态算一次门 1（锁定域）或守恒判定（双轨域）；**首个可行组即停**（换最少的件拿到收益，最小化过渡拆解）。无可行组 = 本帧零动作（合法稳态，非缺陷）。
- **执行形态（本迭代新机制，非现状）**：可行组的 |换入|=|换出| 对按同帧原子序逐对（SellDeployed → DeployMove）连发；现行 as-built 为「先卖、上序后续帧重评续发」（mandate.py 上序重评段），本批改为组内同帧连发——帧稳定契约与落位预计算对账 `flow/action_exec.md`（已入正本更新清单）。卖后上序底线照旧（`post_sell_req_missing`）。

### 2.8 收敛不变式（接替 P61 有限触发角色）

- 堵回降口：**演进降级换人 victim 资格增补排除「终局档位承载件」**（其离场使终局掉档，本不应让位）。
- 全局单调论证：终局名单成员受保护集禁卖；外部支撑件属「有效羁绊贡献件」本就不进来金出售候选池（20 号稿无关角色定义）；演进降级排除承载件（本批增补）⇒ **板上支撑数全局单调非降**；门 1 各分支要求某结构量严格增（支撑数/档位/星级），上界有限（板位数、档位组合、同名星级组合）⇒ 触发次数有限、无死循环。纯结构计数论证，零参数，非战力证明。

### 2.10 净战力不证明与行为锚点

- 验收 = 行为锚点（判读锚点事前写）：同 seed=20261216 复测，锚 ①2-1 帧换人发生（Saber 换停云或爻光，1 换 1），换后圣杯 2 不掉、能量激活一阶；②2-2..2-4 换人动作面与 §2.7 算法的推演预期表逐帧对照（实现批跑前先写预测表）。另加单帧测试与既有验收线保全（landing 常规检查 + prereg 实体清单）。

### 2.11 关键取舍

- **Δfp>0 放宽（放弃）**：form_progress 满锚 = 完全成型，多档中盘 Δfp 与档位激活不同构；离散档位判据零调参，且天然守护「哪怕下远坂凛都不能拆能量」教义（拆能量 = 掉档 = 门 1 不过；出处 = cw_comps.py 双王圣杯 branch_key 注记）。
- **登记 required_deployed（放弃）**：字段契约「缺它永不成型」与双王圣杯不符（Saber 有 Archer 替班形态，cw_comps.py special_systems.grail_quest）；且让位检验一步成型折法不动则通道照旧关死。
- **P61 扩展证明（放弃）**：新触发面下「五体系档守恒」不成立（过渡档可掉）；战力面证不了（宪法第 1 条）；用户裁定不证明。
- **守恒域参数化 vs 素材守卫转型豁免（取前者）**：素材守卫关切（合成进度经济价值）成立且豁免有害；守恒门在转型域守错了对象（守过渡配方该守终局）——各层正当关切保留，消除的是对象与口径错位。
- **放行复算 vs 独立放行判据（取复算）**：单一源原则；独立第二折法已被证明与主判据漂移（Δfp 冲突实证）。
- **支撑件并集口径 vs 纯标签口径（取并集）**：纯标签口径把零标签命中的名单成员（瓦尔特/符玄）结构性排除出板，病以新形态复发。
