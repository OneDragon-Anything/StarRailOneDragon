# ADR-0165 阵型层 v0(敌条件化槽位级排布;08 号)

## Status

Accepted(2026-08-16;F1 影响量级审计/PrepDirector 事件点重排接线/影子对拍待后续)

## Context

08 号提案核心发现：上阵「组合」(上谁)有整套决策机制，「排列」(放哪)只是 position_pref 行偏好+按序填槽的副产品；但游戏机制里槽位/前后台有真实数值语义——词缀 ~9 条显式槽位/整排语义（灼热轰炸=前台第一位仇恨集火、前后台熄火系=整排锁伤、坠入陷阱/重症难题/正当防卫=前排负面）、增强侧 1 号位显式绑定（全队的希望/风暴骑士/绕口令）+ 应援团后排≥4 阵型条件。**06 号搁置对位优化的前提「敌方信息暂无观测源」经核实不成立**：state.enemy_affixes（简报词缀链生产在跑）/AFFIX_EFFECTS 原文注册表/已持增强效果全在管线里——缺的只是消费端。cw_comps 注释把灼热轰炸归「无交互」正是阵型层不存在的化石证据。

## Decision Drivers

1. **不花金的战力修正**：买牌/升级/D 牌都要金，阵型重排只花拖拽——裸装/弱板期（战力最缺时）恰是免费杠杆。
2. 机制原文 grounded 无研究债：v0 规则每条指到效果原文，绕开「不建精确战斗模拟器」红线。
3. 新观测源需求为零（历轮唯一）；v0 = S-M 最便宜档。

## Considered Options

- **继续填序巧合**：拒绝 —— 「carry 站错 1 号位吃灼热轰炸集火」是纯可避免误差。
- **v1 telemetry 学习先行**：拒绝 —— 提案自己规定 v0 规则表先行、v1 只做校准器（格子稀疏）。
- **v0 规则表**（采纳）：机制原文落地零学习；无语义触发 → 退化为现状行为（关掉规则=与现状全同，对拍锚点）。

## Decision

1. 新增 `cw_formation.py`：
   - `decide_formation(units, affixes, held_augments) → FormationPlan`（front/back 有序名单 + 1 号位即 front[0] + 触发理由决策迹）；
   - 规则四组（全部效果原文）：**排级响应**（熄火系 → carry 移另一排）/**前排负面**（坠入陷阱/重症难题 → carry 避前排）/**1 号位仇恨**（灼热轰炸 → 最扛者坐 front[0]）/**增强硬约束**（应援团 → 后排≥4，从前排挪最扛的补）；
   - 无触发 → 先验填序（成员集=position_pref 分排；排内按韧性稳定排序保证可复现）。
2. 测试 6 条（词缀/增强锚点 + 退化正确性）：无语义退化=现状/前台熄火移 carry/灼热轰炸 1 号位=坦克/后台熄火反向/应援团后排≥4/slot 查询。
3. 接线待后续：PrepDirector 事件点重排（位面开始/板面变化/新增强入手；拖拽数上限超限弃排）走 move 原语；F1 影响量级审计（全量扫语义词缀×A8 抽 4 条估每局期望触发）作为切流止损门先行。

## Consequences

- 与 06 分工：组合归束优化、排列归阵型层（06 §2.3 预留接口由本层接管）；char_positions（ADR-0139）降为先验之一。
- F2 人类知识对拍（plaza 阵型句：万敌独前排/爻光必后台——已在 char_positions，方向一致性待批量验）。
- plaza 数据边界诚实：攻略不写敌条件下的阵型变化——敌条件阵型是本提案真正的新数据生产（v1 自采）。
- 提案原文删档；决策单一源移本 ADR。
