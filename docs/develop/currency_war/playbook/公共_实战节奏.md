## 1. 经济节奏(单一源:cw_economy)

- **息引擎优先**:50 金封顶吃满息是 P1 主目标;**金<20(1 息档)买过渡件不损息还压牌池**(无损购买窗口,ADR-0149 接线中)。[实战:M22 r4 金21 商店有货空手 + 用户 §7-11]
- **50 金前不追级**:金 < INTEREST_THRESHOLD 时非 boss/锁血不降 xp_floor。[实战:M22 r7-r9 金≤35 零息追级 + 用户 §7-12]
- **P2+ 穷金重建**(ADR-0148):金 <30 降档 interest_first,自愈式。
- **roll 可负担门**(ADR-0147):E[刷到下一张核心]×2金 vs 预算金;lv7 边界金≥35 放行/≤30 拦。

## 2. 过渡阵容(本层最大缺口,ADR-0149 主工程)

**阶段体系(骨架 V3.7→V4.4 全程成立,具体选套按 V4.x 口径)**:
- **P1 前期(1-1~1-5)**:2DOT(桑博+艾丝妲)骨架 + 2 贝洛伯格/2 学者 拓展;V4.0 后 3 仙舟+2DOT/4 列车更稳(3 巡猎是新贵)。[先验:攻略交叉;实战:未验证]
- **P1 中期(1-6~1-8)**:过渡成型判定 = lv5-6 + 羁绊够 + 过渡核心 2 星 → **停手攒息**。[实战:用户 §7-13;模型未建]
- **1-8 分界线**:奖励关把过渡阵容**全卖吃息** → P2 换血点。[先验:攻略 难度:20;模型未建]
- **P2 中期护航**(ADR-0140 EscortComp 已注册,未驱动买牌):龙丹护航(4战技点+3仙舟→直伤系)/ 灵砂护航(4击破→击破系)/ 阿雅护航(3昼神+3能量→DOT系);**2星护航带队即停手**;分水岭 2-7/3-1 结单。[先验:攻略 难度:22-34]
