# ADR-0434:花的时机判据——息线以下支出门与三例外(方向三)

- 日期:2026-09-06
- 状态:accepted(默认关,开臂判据挂账)
- 谱系:形态达标三方向落码批(设计单一源=`.debug/temp/currency_war/w415_form_design/DESIGN.md` §3);实证基线=同 0432(升级真破息 w42 26.3%——其中 100 次在第 9 轮 boss 前、破息笔中位 32 金换 2 档息损;刷新真破息压到 5.5% 但 never_50 涨到 28.7%,破息禁令把花光行为推到息线以下——花的时机判据缺失才是根)
- 关联:ADR-0347(升级 EV 总账单一裁决)、ADR-0349(相位地板/HOARD 摊档)、ADR-0432(E2 与围栏共用名集尺)、W382 账(破息花金胜率传导上界 0.12 < 过账所需 0.30,数学背书)

## Context(为什么)

息线是形态追赶的预算边界,不是竞争对手([28] 双指标=息基×形态,乘法门任一因子归零即全归零)。现状:③ 静态 EV 账在 boss 前冲级语境放行负期望破息花;刷新侧破息禁令把花光行为推到息线以下(never_50 局全程买牌中位 36 金、出口金中位 22),且破息轮买牌只有 30% 是配方件——「真破息买形态」不批不构成形态损失(W410 实证达标局与不达标局买牌总额无差),只消除纯亏。

## Decision(逐条)

1. **默认规则**:金 < interest_floor 时升级/刷新默认拒(删因 `below_floor_spend`),开关 `below_floor_spend_gate_enabled` 默认关,三例外白名单放行:
   - **E1 [33] 人口位**:`ev.levelup_ev_basis` 臂①原样收编(cap 满 ∧ bench 有目标件,当轮战力兑现),零改语义;
   - **E2 [6] 精确化**:店内有配方围栏名集件(`scoring._cand_system_bonds` 单一源,与方向一共用一把尺)→ 刷新放行,上限 1 次/轮(定向刷新语义;session.v3_bf_refresh_* 轮内计数,消耗登记在 refresh 采纳块)。
   - **E3 [11] 零息损显式化**:⌊gold/10⌋ 不变的花/刷息账零成本,放行防误拦(显式写成放行臂,非新授权)。
2. **落点**:升级=`levelup_ev_basis` 前置门(臂①之后②之前——E1 优先级最高;花后 < interest_floor 且破档时仅 E1/E3 可达;② DP 臂本就要求平台未破不动;收窄的是 ③ 静态 EV 账)。刷新=arbiter `gold_floor` HOARD 分支收窄——**落点勘误如实记**:interest_rule 在金<50 时让位 gold_floor(ADR-0347 原辖域保留条款),息线下刷新的实际裁决点是 gold_floor HOARD 分支,设计稿「interest_rule 的息线以下分支」按实际裁决点落码,语义不变。gate 开时 dp_spend 不再单独授权息线下刷新(w43 never_50 病灶载体);cost==1 的 [11] 净0 特例原样保留。
3. **Considered Options**:①前置门+三例外白名单(本批)——逐笔可复算(任何息线以下的花对照三例外,例外外=拒),无口诀空间;②只收紧 ③ 静态账阈值——阈值无出处(拍死值债),否决;③只删升级不辖刷新——never_50 主病灶在刷新侧,否决。
4. **数学背书**(既有账引用不改账):r9 冲级破息笔 32 金换 2 档息损(10 金/轮 × boss 后剩余节点),破息花金对 boss 战胜率传导上界 0.12 < 过账所需 0.30 → 负期望;息线以下散牌买(破息轮 70% 非配方件)零合成路径、战后力≈0,消费有效性判据直接否。放行三例外全部自带兑现路径(E1 当轮上场/E2 定向找配方件/E3 零息损)。
5. **金账单一源不变**:本门是授权边界不是新账。

## Consequences

- 默认关=零漂移锚;开臂判据挂账(registry 注释,不执行):sim A/B 真破息→0 ∧ never_50 ≤基线+2pp ∧ 形态达标不降;验证不过=删码留本 ADR。
- 数据缺口(设计稿 §4.2 继承):方向三判据主要在 sim 侧成立(实机跑完局本就零真破息,实机侧只验「不回退」)。
- 行为锁:`test_cw_form_gates.py`(息线下破档升级/刷新默认拒/E1-E3 三例外放行/E2 轮限 1 次/gate 关零漂移回 HOARD 攒息原文案)。
