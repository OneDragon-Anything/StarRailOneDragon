# 货币战争-优势布局（局外强化树，玩家操作简卡）

**识别**：`is_precise` 命中 `货币战争-优势布局`（锚：标题「优势布局」+ 页签「常驻优势」文本；右上角数字 = 幻乐晶球余量）。
**目标**：用幻乐晶球激活天赋节点，效果对之后每局生效。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：大厅左侧菜单「优势布局」→ 进入强化树画面（screen_info 已建路由 area）。
2. **两棵树**：顶部页签切「常驻优势」（跨赛季，激活永久保留）/「赛季优势」（每赛季重置，主战场，40 节点）。
3. **树可拖拽平移**：节点位置随树滚动变化，**不建节点 area、不做点击 op——看图找节点点击**（向左拖 = 看右侧深处）。
4. **激活循环**：点节点 → 底部详情面板显示名称/效果/消耗 → 点右下「布局」按钮 → 按钮变「已布局」即成功（节点变粉色、晶球数下降、右上「已布局优势 n/40」+1）。
5. **消耗分档（实测）**：小节点（数值强化）×20；「附加机制解锁」大菱形 ×60~100（风险对冲/主角重选/全盘刷新 ×60，大胜表彰 ×100）。锁定节点按钮红字「请先布局前置优势」——顺藤摸瓜先布前置层。

## 保险机制（用户关心的「1 血免死」）

- **效果**：小队生命值首次将要归零时保留 1 点避免游戏结束（每局一次）+ 受伤-10% + 治疗/护盾+10%。注意：此节点锁定未激活时**没有**免死——近期实测连续两局 HP 直接归零终局（详见 mechanics/优势布局.md 口径核对）。
- **位置**：赛季树深处（第一屏向右拖约三屏，带装饰框大菱形）。
- **前置链（实测路径）**：起点 → 生命强化 → 暴击伤害强化 → 主角重选 → 伤害提高 → 大胜表彰（三链汇合件：上链击破强化→风险对冲、下链伤害减免→全盘刷新 也需激活）→ 再往深处（未走通）。
- **本机状态（2026-11-18）**：未激活——前置链走到大胜表彰后晶球耗尽（缺 ≥200），待后续补晶球续布。

## 坑

- 大菱形消耗是大头（60~100），预算紧张时先算链路再动手，别把晶球散在支线小节点上。
- 点「布局」后等约 1 秒再截屏（有激活动画）。
- 全量节点清单与建档细节见 `docs/game/screens/currency_war_advantage_layout.md`。
