## 问题与约束

- 现状三套特殊机器各自回答「谁上场」：部署选人桶（`select_deployments` 七桶系——点火序/成对/引擎对优先等桶本质是给线性序补「羁绊组合效应」的补丁）、kernel 换人臂 + P79 三轴门、配方对选择（原「板面易手」标签失实，D-16 修订）。
- **机制事实**：
  - **交换交互（用户确认 2026-10-30）**：拖 bench 单位到场上被占槽 = 交换（被占者回 bench 源槽，bench 占用不变）；成立前提 = **上场者与场上现存无同名**——由唯一性键不变量结构性保证（§2 段 0）。执行层为机械拖拽零判效，失败形态由动作自上报逻辑推演 + 下帧对账暴露（现行架构常规，D-1 处置）。
  - **无纯「下场」动作——已废除（用户指令 2026-10-30：统一拖动角色 Op）**：新增统一移动动作（源/目标 = 前排 ×4 / 后排 ×6..9 / 备战席 ×9 **全部位置**），拖拽语义全域统一 = 游戏规则（目标空 = 放置，有角色 = 交换）。能力全集：上场（bench→场上空槽）、换人（bench→场上占槽交换）、**纯下场（场上→bench 空槽）**、排错修正（场上→另一排，一步）、备战席内部挪位。`CwActionDeployMoveParam`/`CwActionSwapDeployParam` 随批退役；上报层交换/放置推演扩为全域同款（消费现有 deploy_move report 推演逻辑扩展）。交换同名前提（上场者与场上现存无同名）由唯一性键不变量照旧结构性保证。
  - 交换前提推论：场上人数 ≤ K 恒成立 ⟹ 名字缺位者存在 ⟹ 恒可配对交换。
  - K 口径单一源 = `max_units_of` 现值（= min(等级人口, 4 + 动态后排容量)，后排 6-9 随宝钻/召唤物扩格）——**召唤物占 K（用户确认 2026-10-30）**：真人可上场数 = K − 场上召唤物数，枚举按此扣减。
- **接口契约（总纲划定）**：①**窗口谓词共享、成员域分窗声明**（二轮 D2-5 修订，原「族成员 ⊆ 名单成员展开」作废——该表述把 P1 过渡圈人锁进名单、漏最优板）：三面共用同一窗口谓词（`plane2_started_of` 分域）；**部署枚举池 = 全部真实单位（唯一性键全集）**；候选族结构按注册表——P1 = SYSTEM_CARDS 四体系（成员域 = 手牌全集，名单不辖）；锁定 = Comp 注册表羁绊（与锁定名单同源）；P2+ 未锁 = 候选线（与候选名单同源）。名单只辖买/卖面。②部署定型输出 = target_board（**角色名 → (排, 选定星)**——三轮 D3-3：载荷补星维以承载就位粒度名+排+星），卖出面档 1 按名集消费；③获取让位评估步 3 的部署定型 = 本搜索对虚拟阵容的定型结果；④评分函数纯函数（消费容器状态，sim 可跑，禁 IO）。
- **枚举硬约束**（违反即产出不可执行目标，D-5/D-8 处置）：上阵窗口谓词（现役 `_deploy_window_blocked` 谓词本体保留为唯一源——窗口外成员不入参评全集，例：反甲流全员 `entry_signals=('plane_end',0)` 前中期禁上场）；上场锁（`deploy_lock_block_reason` 现成读口——锁到期前不入目标板，防执行恒拒零推进空转）。
- 约束：单动作契约（每次策略提案恰一个动作；画面 op 内逐动作循环）；部署定型为卖出评估器（档 1 名集）、获取让位评估、出战链、shop 档 1 可上场买（`can_deploy_single`）四处共用输入，替换 = 同步切全部消费端。

## 方案

### 1. 评分函数（数值制；层结构按窗口分域）

总键 = **(选人分, 站位分, 稳定键, 随机尾键) 字典序**。

**两个核心量的定义（D-3 处置；显式选端，单一源纪律）**：
- **档位完成度** = 已达整数档 / **该体系目标档**（锁定线 = `Comp.form_tiers` 单阈值端——显式选端，禁读 FACTIONS 梯末；过渡体系 = 体系成型档）。纯离散，无连续进度分量。
- **角色完成度** = 该羁绊族已上场角色数 / 该羁绊族**目标档激活阈值**所需角色数（阈值 = `FACTIONS.tiers` 档位激活数）。
- **分族计分分支**（D-10/D-11/D-12 处置 + 二轮 D2-3/D2-7 修订）：羁绊体系 = f = a×b 乘法；**单卡体系**（希儿系）= 二元计分对齐现役 `seele_system_formed`（希儿在场 ∧ 放大器 ≥2 → 体系成立 = 1.0，否则 0）；**过渡体系档位完成度 = 二元退化**（体系激活 = `TRANSITION_TRAITS` 阈值 / `seele_system_formed` 单点判据——注册表无「成型档」字段，已达激活 = 1.0 / 未达 = 0；**铁三角空壳约束不进评分**〔评分按羁绊计数 = 机制事实，任意 3 仙舟与铁三角同分——近似边界申报；空壳规避由圈人承载：骨架优先圈 engine_required 铁三角形态〕）；**空羁绊线**（反甲流 `form_tiers={}`、`factions=[]`）= L1 由角色完成度单独承载（b≡1），**分母读端 = `core_chars ∪ shared_chars` 总数、分子 = 其在场数**（D2-3 修订——羁绊族口径对该线无源，改阵容成员口径）；**选边双羁绊**（布洛妮娅）= 计数统一消费现成 `side_pick_bond`（单一源，平局披露键沿用）。
- **羁绊计数口径 = 角色数量 + 星徽**（用户确认 2026-10-30：羁绊不按位置，只按角色数量和星徽）：**计数单一源 = `cw_bond_equips.unit_bond_tags`（已核实，cw_bond_equips.py:105-121）**——每上阵单位羁绊标签多集 = 角色注册表出身（factions+flows+independent）+ 开拓者排形态归一 + 布洛妮娅选边单边化（`side_pick_bond`）+ 装备贡献（星徽「装备者加入羁绊」）四合一；评分直接消费本函数，零新建口径（选边/开拓者/星徽三个口径担忧同源消解）。
- **逐羁绊完成度 = deploy 域新单一源函数**（逐羁绊分项；折法三件：OR 承接组 = 组内取最优可达支〔max〕；**required_deployed 逐名折条**——required 名不在场 → 该线 L1 = 0〔希儿量子例：希儿不在场则成型无从谈起，与 form_progress 逐名折条先例同构〕；空羁绊/单卡分族分支见上）；`form_progress` 保留给成型判据（readiness_form_ok）——两消费域用途分立、各自单一源，互不绕行。
- **星级 = 落场后形态**（D-6 处置）：同键多副本取最高星参与评分，其「星」按**上场后实际形态**取（银狼 LV.999 上阵变换窗：3★ 上场即变下档 1★+费用档+1+合成级联——评分消费上报层同一变换纯函数，评分板面 ≡ 执行后板面）；原「变费卡按 effective_cost」主张撤回（无羁绊消费点）。

**层结构与分值（用户裁定 2026-10-30：落实分数比较；过渡层仅未锁定窗特殊，锁定后降普通层——D-2 的跨层比较对象〔锁定线 vs 过渡层〕不复存在）**：

| 窗口 | 层结构 | 层内形状 |
|---|---|---|
| 未锁定（P1 / P2+） | **L1 主目标羁绊层**（P1 = 4 过渡体系组合；P2+ = 候选线羁绊）> L3 普通层 | L1 = 加权平均 of f（乘法制）；L3 = 计数制 |
| 锁定（P1 锁定 / P2+ 锁定） | **L1 锁定线核心羁绊层 > L2 锁定线非核心羁绊层 > L3 普通层**（过渡体系降 L3——已成型档按「其他羁绊」计分，无特殊分数） | L1 = 加权平均 of f；L2 = 加权平均 of 档位完成度；L3 = 计数制 |

**分值设定（数量级隔离 = 结构编码）**：

| 层 | 分值域 | 计法 |
|---|---|---|
| L1 主目标羁绊 | 满分 10⁹ | 加权平均 of f(角色完成度 × 档位完成度)，权重 = 目标档深 |
| L2 锁定非核心（仅锁定窗） | 满分 10⁶ | 加权平均 of 档位完成度，权重 = 目标档深 |
| L3 普通层 | ≤ ~10²（计数自然有界；**计数单位见段 2 DF-2 口径：羁绊组按档/万金油与希儿系按件**） | **单位序（用户裁定 2026-10-30）：buff/debuff 羁绊(×3) > 万金油角色(×2) > 其他(×1)**；**过渡羁绊档 = 条件两态（用户裁定 2026-10-30 五轮间修订）**：锁定窗且锁定线 L1 = 0（一档未成）期间 → 过渡档 **×4（临时压过 buff/debuff——保板相位）**；锁定线一旦成档（L1 > 0）→ 加分消失，过渡回落其他档 ×1。其他键含 flex_factions、希儿系成型（一律其他档）。**部署与卖出两套独立算法**（用户裁定）：部署零卖出概念——件下板后在 bench 按统一让位序参与卖出评估，其成员保护 = 统一序自身档位输出，非部署侧特殊对待 |

**L3 键源显式声明（二轮 D2-4 + 五轮 D5-10 职责声明更新）**：「buff/debuff 羁绊」闭集 = `TIER7_BOND_NAMES`（priority.py:53-54，策略层常量——FACTIONS category 四类中无此概念，本键即单一源；**在役职责在本迭代扩为「档 7 保护数据源 + L3 评分数据源」双职责，注释随批更新**）；万金油 = `CROSS_LINE_KEEP_NAMES`（protection.py:41，同款双职责声明：档 6 保护源 + L3 评分源）。**评分/搜索代码归属 = `strategies/impl/mandate_v1/` 部署判据件（策略层）**——消费同层常量与 kernel 注册表，依赖方向全部合法（补问 1 同答：非 kernel 反向依赖策略层）。

- **金币维核查（用户裁定 2026-10-30 三）：部署评分零金币交互**——CW 部署免费（上/下场/换位不花金币），金币不进任何评分维度；核查过非漏项（场景×金币核查表见总纲 §2.2）。
- **隔离常量 = 结构编码非标定**：层间隔取 10³ 数量级，语义 = 「高层任意正分 > 低层满分」；常量值在不等式区间内变动行为零变（调参不改变行为 = 非标定参数）。**单位序语义边界（四轮 D4-8）**：×3/×2/×1 表达同数量单位的类间偏好，跨类数量组合可自然越序（2 万金油 4 分 > 1 buff 档 3 分 = 合法），非全序封锁。
- **L2 键集（三轮 D3-1 修正——二轮把 flex_factions 拉进 L2 与注册表语义正面相反）**：锁定窗 L2「锁定线非核心羁绊层」键集 = **仅 `Comp.sub_tiers`**（有档值、字段注释明写「参与完成度」——分母/权重有源）；**`flex_factions` → L3 其他羁绊计分**（注册表白纸黑字「板面不罚但完成度不数」cw_comps.py:1201——正是 L3 语义：给小分、不进完成度层；flex 6-7 键宽集不再稀释/抬高 L2）。
- **层间键归属规则（四轮 D4-3 + 五轮 D5-3 按窗口分域定稿）**：**一键单归属、取当前评估上下文的最高层**——
  - **锁定窗**：L1 键（锁定线 form_tiers/or_reqs）＞ sub_tiers 键（升 L2，同键 L3 计分**抑制**）＞ 其余 L3（TIER7 ×3 / 万金油 ×2 / 其他 ×1）；sub_tiers ∩ flex 同键 sub_tiers 胜；**sub_tiers 值域含区间 tuple 时 L2 读端取下限（五轮 D5-8 申报，落地批核值域）**；
  - **未锁定窗（无 L2 层）**：当前候选线的 form_tiers/or_reqs 键 = L1 键；**其余键一律 L3 单位序**——sub_tiers 键无处可升，按 TIER7 归属（∈ TIER7 → ×3，否则 ×1；**不归零**：注册表「参与完成度」语义辖锁定评估，未锁定窗它就是普通羁绊）；他线的 L1 键（如候选 B 的 form_tiers 减益）在评估候选 A 时同样落 L3 计分——跨线同键不冲突。
  评分函数唯一可实现。
- **区分度不等式（设计验证；二轮 D2-15 修订口径）**：① L1 最小正分按**最坏组合加权**推导——多羁绊加权平均被零分项稀释后（真实注册表复算：欢愉 A 流 ≈ 1.9×10⁸、狼尊欢愉 ≈ 1.2×10⁸），**下界 ≥ ~10⁷ ≫ L2 满分 10⁶** → 主目标一档成型即压倒低层（换防点 = 锁定线第一档成型，结构化可预测）；② L2 最小正分（非核心一档 ≈ 5×10⁵）≫ L3 最大（~40）✓；③ L3 内部：单位序 = buff/debuff(×3) > 万金油(×2) > 其他(×1)（用户裁定 2026-10-30）；④ 层内：f 连续量 × 10⁹，同档板面按角色完成度分差可辨 ✓。
- **换防形态 = 相位切换（用户裁定 2026-10-30）**：锁定线一档未成（L1=0）→ 过渡档 ×4 保板（过渡板维持在场）；锁定线第一档成型（L1>0）→ 加分消失、过渡回落 ×1，L1 压倒 + 剩余席位按 buff/debuff > 万金油 > 其他填充——过渡件自然退板；下板后在 bench 按统一让位序处置，无部署侧特殊对待。
- **层内聚合补定义**（二轮 D2-10 修订）：多羁绊加权平均，**权重 = 该羁绊目标档激活人数**（`FACTIONS.tiers` 阈值——统一人数量纲，档序/人数两可消除）；**单卡体系（希儿系）权重 = 激活所需件数**（希儿 1 + 放大器 2 = 3，`_ACTIVATION_PIECES['seele']` 现成折算）；**OR 承接组**（form_tiers or_reqs）= 组内取最优可达支（max）计完成度，**圈人档位形态索引按最优支的档序**（D2 补问 4：希儿量子 = max(量档序, 贝档序)）。

**站位分** = 锁定阵容站位完成度（`char_positions` 符合数）+ 前后台符合度（`deploy_row_pref` 三级路由输出为判据）。comp 入参三分（二轮 D2-16 补定义）：锁定窗 = 锁定线 comp；**P1 组合板 = None**（组合非单个 Comp，全按注册表偏好级）；L3 板 = None。
- **随机尾键与纯函数契约的相容（三轮 D3-7）**：rng = **局面哈希播种（五轮 S5-2① 同步：同一容器状态 → 同一 target，跨帧稳定——防并列板帧间翻转致级联 diff 恒非空；同帧多次搜索〔含 can_deploy_single 逐牌〕共享同序 rng → 同帧判定确定、局面不变跨帧可复现；级联期间 target 抖动面 = 稳定键抑制（同分偏好现状），2 帧出口误触发残余面申报〔D7-9〕；**对称性破缺申报〔D6-8〕：can_deploy_single 序有关 → 货架重排 = 不同输入 = 不同结果，属输入变化非随机性，帧级播种已保证可复现**）；**稳定键粒度 = 名 + 排**（星维不进——星变更本就该动板）。
- **虚拟面板字段域（三轮 D3-8）**：搜索输入 = 容器读口全列的鸭子面板（board/bench/deployed_rows/max_units/back_capacity/**env_grant_deploy_locks + uid**/窗口谓词输入/选边披露键/银狼变换窗输入/金位）——**锁绑 uid 时虚拟件（uid=None）按 fail-closed**：名命中锁名单即视为锁（D-8 事故复活路径封死），禁缺字段静默放行。**评分粒度 = 排级**（**用户确认 2026-10-30：羁绊不按位置，只按角色数量和星徽**——槽位维度零羁绊消费；boss 技能的「相邻目标」属战斗结果侧，不入评分，见关键取舍 7）。**稳定键** = 与现板面一致数（同分偏好现状，结构化滞回）。

### 2. 搜索算法（三段）

**段 0 · 枚举基本单位与硬约束（全局不变量）**：
- **枚举基本单位 = 唯一性键**（`board_unique_key`：char_id，开拓者各排形态归一）——全管线在键集合上操作，同名重复结构性不可达（用户裁定 2026-10-30）；同键多副本取最高星（按落场后形态，见 §1）；
- 召唤物/系统单位（`is_unsellable_system_unit`，cost=0）固定后台末位、剔除出枚举，占位/占 K 按 `max_units_of` 口径；
- **上阵窗口外成员不入参评全集**（接口契约枚举硬约束）；
- **上场锁到期前不入目标板**（同上）；
- 开拓者 = 前后排两形态变体互斥——**形态选择与排可行性绑定**（D-13 处置：两形态 × 排容量联合枚举，形态的排约束进排分配，禁「选人分取优形态后又被排分配改排」）；
- 变费卡/银狼按落场后形态（§1）。
- **未知身份件（三轮 D3-13 + 五轮 D5-6 与落位规则的合成定稿）**：识别失败件（char_id 空 → 唯一键 None）**不入枚举池、保留现位、不被移动**——其所在槽对落位规则视同已占用（**禁挤**：交换/落位不可选未知件槽——挤它 = 移动它）；与现役「照旧上场」的行为差 = 观察重建后自然收敛，申报。

### 3. 差分执行器（交换制；画面 op 内逐动作循环）

1. diff = 现板面 vs target_board（**就位判定粒度 = 名 + 排 + 星**〔二轮 D2-1 修订——星 = 枚举选定的最高星副本；原「名+排」致同名异星对〔场上 1★ + 手 2★，合成同星才并、异星合法并存〕判「已就位」零动作，重演 entry.py:1013-1021 实锤过的升星换停摆事故〕，槽不进判定）；diff 空 → 显式零动作；
2. 名字缺位者执行目标落位——目标槽空 = 统一拖动直落；被占 = 交换交互。**落位槽选择规则（D-4 处置）**：同排内取「多余者（名字不在 target）> 错位者（在 target 排错）」的槽，**禁占已就位者（名+排皆对）的槽**；同排已就位者满员 ∧ 缺位者需该排 = 容量矛盾，由排分配的容量约束排除（不可达）；
3. **排错修正 = 场上直拖一步**（用户确认 2026-10-30 场上可直拖 + 统一拖动 Op）：原「bench 中转两步 / 排分量挂起」形态废除——统一拖动 Op 全域可达，排错一步修正，无挂起。**同名异星换（D2-1，三轮 D3-3 修正为直卖形态）= 两步且低星不进 bench**：① `SellDeployed` 直卖场上低星副本（对齐现行 bond_gate star 先例——低星**不经 bench 中转**，否则名字 ∈ target 名集 → 档 1 备战位同名牌永不先卖 → bench 席位死锁）；② 高星副本上场（目标槽空 = 直落）。1★ 全额退 = 换星零成本；2★ 以上低星直卖的手续费损失 = 罕见帧申报边界。域界：档 1 保护辖**卖出场景的 victim 取用**（同名牌不进卖出池），部署域换星直卖不经卖出池——两域不打架（现行同款分工）；

5. 执行形态（八轮 D8-1 定稿——**七轮 D7-4 的代码引述失实作废**：cw_screen_prep 决策动作 node = 零读屏多动作循环〔模块注释 :705-711「循环内零读屏」、docstring :779-782「入口 heavy 一次观察 → 逐动作循环」、对账归下一入口 heavy reconcile :862-864——备战与商店同为零读屏会话形态〕）：**计划执行期提案序列 = 拖动与重观察交替**——计划执行每发一个统一拖动后，下一提案返回 `CwActionObsParam`（**in_place 环内重观察**——cw_vocab.py:919-925 现役〔行号勘误 S7-8〕；两文档统一钦定 in_place，outer_loop 不等价〔时长上界/防护层两维差异〕弃用）→ 观察帧对账（自上报推演 vs 实读板面）→ 不符则 diff 重算——「连续 2 帧不增」的数据源 = 观察帧对账后的已就位集（零读屏循环内无取数路径，交替重观察使计划执行实质逐帧化，D7-4 承认的事故形态〔推演收敛误判完成清槽〕封死）；常规部署差分（非计划执行期，第 6 步）维持零读屏循环 + 入口 heavy 对账现状（无卡死判定需求，收敛由下一入口对账兜底；**边界申报〔D9-3〕：假收敛最坏 = 带误差板打完当前节点、战后对账纠回——处置力度不对称的理由 = 级联涉及卖出〔不可逆〕需强校验，常规纯移动可逆故入口对账足够**）；**计划变量与本级联的关系〔PV-6 按总纲终版改口径〕**：**计划游标**（总纲：步骤序列执行态 = 游标，卖 V₁..Vₙ 逐帧执行 → 驱板面至 T → 序列空清槽；**失败即清槽 + X 路径失败标记（独立字段）——无失败态保留**）× **op 内循环**（执行承载：前置步按交替序列提案〔拖动 → obs 重观察，D8-1 形态〕）× **差分执行器**（本节：diff 计算单一来源，**target = 计划内固定 T（写端定型）——非每帧搜索〔备战零搜索申报〕，与第 6 步共用执行器逻辑但 target 来源不同（第 6 步 = 当前搜索，计划 = 写端 T）**）；**执行失败出口（D6-3 + DF-1 按总纲④终版改写——旧「失败态保留至边界/虚拟重验/次末位/待卖态作废」句群整体删除）**：连续 2 次重观察后 diff 无进展（含无动作帧——禁挤/未知件占目标槽形态也计入〔S7-9〕；**计数域〔DF-7 + 复验 DF2-2 精确化〕：被第 0 步自救抢占的帧（前置步未运行、零计划观察）不累加也不清零；计划执行期内的无动作帧〔溢出/fresh——前置步运行但无可发动作〕照常计入〔S7-9 口径——原「同 S6-5」引用为已被推翻的旧豁免口径，撤回〕**）= 卡死 → **清槽 + X 路径失败标记置位（StrategyState 独立节点作用域布尔字段）+ 恢复扫描**；**其余出口补全〔DF2-6——总纲④三出口在本节落点〕：V 不在场 / 卖失败（本节步 3 卖出执行层失败）→ 同款清槽 + 标记置位 + 恢复扫描；三出口记键均按计划语境〔PV-8：席位 → `priority_insufficient` / 纯金 → `priority_insufficient_gold`〕，下轮商店重评走 bench 件路径或机会清单——禁计划执行期永久挡住第 1-9 步〔S8-4〕；**触发序〔D9-8〕：级联 2 帧出口先于外循环 stall 防线（stall 只兜出口失效残余）**；**时长申报（D-17）**：K 满换血最坏 = N×(拖拽 + 2s 徽章动画睡眠 + obs 重观察等待 ~1s) + 入口 heavy 观察成本〔D9-6 随逐帧化更新〕，画面 op 时长预算落地批对照看门狗边界评估；

## 关键取舍

1. 评分搜索 vs 字典序全序（退役）：羁绊 = 组合非线性，线性序表达不了凑档交换；旧桶系 = 补丁史。
2. 乘法合成 vs 加权和（裁定①）：残缺高层自动压 0，防拆板。
3. 羁绊驱动增量圈人 + 档位形态集合（裁定② + D-15 修订）：t=0..可达档各一套形态，空骨架合法。
4. 执行形态 = 画面 op 内逐动作提案 + 自上报推进（用户澄清 2026-10-30 关闭）。
5. 交换交互前提（用户确认 2026-10-30 关闭）：前提条件由唯一性键不变量结构性保证。
6. **层合成（已裁定 2026-10-30：数值制）**：落实分数比较；**过渡层仅未锁定窗特殊，锁定后降普通层**（跨层冲突对象消解）；隔离常量 = 数量级结构编码（区间内变动行为零变，非标定）；换防点 = 锁定线第一档成型，形态 = 渐进混合。
7. **boss「相邻目标」AoE 零建模（纪律申报；五轮 D5-11 合成定稿）**：boss 技能相邻扩散属战斗结果侧，不入评分（「运营对了战力自然对」纪律）；唯一可选项 = 无约束空槽的默认摆位「同排散开」——**落位槽选择规则（D-4）优先，散开摆只作用于规则未约束的剩余空槽**，两者无冲突。落地批可选项，非设计依赖。
