# ADR-0221 boss 窗板面集中买与档位排序

## Status

accepted(2026-08-22;r352/r352b/r352c)

## Context

局38/40 双局实锤:boss 段金 44/77 滞留买 0——r350 锁线门正确拒绝线外件,但 boss 决战质量期线形态不是唯一价值,深 12 进 boss 双局同 -34。局41 复盘:板面 8 阵营各 1-2 人的散面下,「任意板面阵营」的集中买仍买散件。

## Decision Drivers

- 深度杠杆的真实落点是上阵阵营人次(ADR-0219),但散面上无差别堆深=固化散面
- 金滞留与散面固化是两个都要治的病

## Considered Options

1. **只放宽锁线门**(r350 前的引擎∪线形态并集):艾丝妲×4 占部署位的教训证明会放散件占位——拒
2. **板面集中买 + 档位接近度排序**(选):线内 wants 买完后,剩余预算买板面已有阵营件,按「距 3 档缺口小者优先,平局 count 高者先」排序——2→3 档跃迁 > 1→2 档 > 新开 1 档
3. 无围栏任意买:散面固化(后由 ADR-0225 配方围栏补)

## Decision

选 2。细节经三局迭代收敛:r352c(review)修循环 break→continue(排序键跨组无价格序,首张买不起 break 会跳过便宜卡=金滞留复发)+ `_bought` 循环内更新(防同名超 3合1);行为锁见 sr-od-test test_cw_r352_boss_depth_buy.py。
