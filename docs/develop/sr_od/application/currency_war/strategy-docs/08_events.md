# 08 事件面规格骨架（E1-E18）

> 整合来源：01_strategy_layer §4.9（全量目录，用户裁定第一版全覆盖）+ 2026-08-19 用户定调批次（全部 overlay 选卡接入策略模块）后补三接口（E16-E18，见 [13_pick_family.md](13_pick_family.md) §1/§2）。本篇处理设计评审曾识别的完备性空洞之二：事件决策面「**目录全量 / 数学全空**」——18 个决策点中任何一个的实现者都需要判据，而证明集对事件面无专件（相应数学命题登记待立项）。本篇的职责 = 逐项收录现有语义 + 逐项标注数学判据状态（除注明者外全部「待立项推导」）+ 给出每项的立项锚（判据应挂靠的数学命题通道）。

## 0. 章程

- 每项格式：**现有语义**（收录自原 03 §4.9〔已删除〕，用户裁定/知识来源）→ **判据状态**（一律「待立项推导」除非注明）→ **立项锚**（判据该走的数学通道：挂靠哪个已证命题的参数化，或立新命题）。
- 「待立项推导」的含义：该决策点的判据可写成已证命题的参数替换/扩域者，按锚立项推导；无锚者立新命题（P 编号由编排者登记 math_proofs 索引时分配）。**推导完成前，实现按「现有语义」列的知识判据执行**（骨架/知识判据先行，数学判据到位后替换——与 01 §7 待证钩子「结构背书形态，数据到位前不授权数值」同构）。
- 事件面的横切纪律：一切「环境/突变改变机制输入」经 resolved input 原则消费（[11_shop_decisions.md](11_shop_decisions.md) §8）；战力族/资产发放族不进经济 resolved（走权重/克制通道与组件缺口通道）。

### 1.1 E1/E2 行名词速览（每词一句定义 + 一个例子）

评分行的组件名词推表内反复连用，此处逐个展开（只定义不改语义）：

- **统一加法标尺** = 把一张策略/环境卡的各价值维度各算一个分、直接相加取总分的评分形态。例：某卡现金分 30 + 方向分 20 + 赠卡分 10 = 总分 60，与其他卡比总分取最高。
- **现金分量** = 该卡对现金收入的直接增益折算分。例：「每轮进账 +5 金」的卡按收益期望折算现金分。
- **方向分量** = 该卡对目标阵容方向的增益折算分。例：效果点名候选阵容阵营时按命中程度加分。
- **赠卡分量** = 该卡带来的免费卡/折扣价值折算分。例：效果为「赠一张指定费用角色」的卡按该角色获取价值计分。
- **立场分量** = 该卡与当前策略立场（如血本位、开源节流）的匹配折算分。例：立场为「开源节流」局中，减费类效果加分。
- **转向轴** = 用户点名偏好的软加分项（见 [13_pick_family.md](13_pick_family.md) §4：用户点名是偏好不是支配）。例：用户登记过优先某关键词，命中该关键词的卡加一小档分。
- **台账价值** = 旧选卡价值表 PICK_VALUE 的基准分（按效果原文逐条人工判定、一条策略一个基准分；该表已停用，语义由上述组件承接）。
- **经济价值分量（旧称「经济分支」）** = 一张卡推纯经济账上的价值份额。例：提高利息上限或每轮进账的效果，其经济价值分量就是这部分收益的折算分；未建模时按 fail-closed 登记为 0。
- **结构分区（禁选/自拆台/血本位三态/定义型）** = 评分之外的四类结构处理。禁选 = 用户排除名单直接剔除出候选；自拆台 = 效果克制自己已选体系（例：拿减益克制卡对抗自己已选的持续伤害阵容）则剔除；血本位三态 = 血本位局（奋斗协议/不等价交换）下的三档处理：可入选非血集 → 非禁血卡强制入选 → 全禁退化（见 11_shop_decisions.md §8）；定义型 = 黑塔纪元等「拿到即改写本局玩法」的卡单独分区优先处理。
- **帧级门** = 刷新建议先看当前帧状态是否允许刷。例：刷新次数未用完、且本次要换掉的卡是本帧全场最差，才允许建议刷新。
- **槽级动作集** = 刷新按槽位逐个给出动作元组。例：建议刷新输出为「槽 2 重掷、槽 5 保留」这样的逐槽动作清单，而非整屏一刀切。

## 2. 落差管理（本篇的核心职责）

- **现状一句话**：18 项中，E11 已有已证锚可直接消费；E10 大部已证（残余 = 实机采集项）；E13 结构已立（数值待实采）；E14 无数学面；**其余 14 项全部「待立项推导」**（含 E16-E18 三接口：现行实现为知识/结构打分，数学判据无一已证）——这就是「目录全量/数学全空」落差的如实登记。任何「事件面已有数学」的表述推推导落地前禁用。
- **推导优先序建议**（按消费频率 × 录得难度）：E1/E2/E15（每局必遇、台账价值通道现成）> E3（P26 同构）> E4/E9（组件/池通道现成）> E5/E12（供给硬缺前置，先补供给再立判据）> E6/E7/E8（弱数学面，知识判据长期承载）。
- **禁项**：事件判据禁自带数值（宪法第 4 条）；「奖励偏好序」类知识判据须标注知识来源（combo_methodology 等），不得伪装为推导；供给三缺（E12/E10/E5）未补前，对应事件的实现 = 保守跳过 + 计数披露，禁猜测分类（与契约 §3.3 fail-closed 同款纪律）。
