  36px 小球在该帧长于密集簇,无干净裁片源。
- 影响:碎片压低匹配分天花板(真球 0.741 起 vs 假响应 ≤0.652,余量偏薄)。当前实测可用
  (离线 14/15 零误报;实机一次 extras 读出 11 颗含多颗小球)。
- 若实机出现小球漏检/误检,优先排查方向:在其它帧找更干净的 36px 小球实例重裁,
