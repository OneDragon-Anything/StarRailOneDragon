# 漫游签证(support_character)

游戏内标题「**漫游签证 / 角色展示**」(左上两行)。个人主页面板:左侧个人资料卡 + 中央展示台 + 右侧支援角色 / 星海同行卡。入口:`菜单-更多` 子菜单 →「漫游签证」。`SupportCharacterApp` 每日在此领支援奖励。

## 何时出现 + 状态流转

- **入口**:`菜单` → 「⋯」(`菜单-更多`)→「漫游签证」(路由已 goto_screen 实测通)。
- **出口**:右上关闭 X → 回 `菜单`(已实测);esc 同。
- **子态**:顶部三 tab(战绩展示 / **角色展示**(默认) / 收集展示),切换联动中央与右侧内容。

## 识别特征(稳定锚点)

- **id_mark = 标识-漫游签证标题**(左上「漫游签证」文字 ≈(104,41),conf 0.9996)。
- 三 tab 文字常驻;右侧「支援角色」「星海同行」分组标题常驻。
- 易变(勿当特征):角色卡内容/等级/角标数字、个人资料(昵称/签名/漫游动态)、已进行天数。
