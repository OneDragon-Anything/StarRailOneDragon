# P29 · 锁线态囤牌羁绊感知 EV:线内成员买入的期权账(买入+兑现双段)

> 状态:**待证明(结构不等式已证,量级=参数化级)·并入 w795 重推队列**(2026-09-01 五门验证维持结构级;2026-09-01 按验证判决六条修正重推)。方向证据:P1(再遇窗口/卖出全额退)、P6(免费期权)、P20 方向(体系激活有战力通道、散件升星在 sim 模型无通道;倍数带已降级,见下)。来源:用户口述提案(2026-08-30,「囤牌优先买目标 4 羁绊牌」,数学期望明确、超几何可算)。
> 实证背景:w791 局 6「线已锁但买牌不兑现线」——列车同行锁线后 **6 轮停 2 档**(金 45→98 边流血边囤,买牌落备战席未上场/未合成)。该实证在本篇中**不是买入侧动机,而是「买入≠兑现」的边界证据**(见 §兑现折项)。

## 命题

锁定线 L 确立后,商店出现 L 的成员单位(1★,单价 c),在金处于息线上方或该笔不跨息档、且 `R_rest ≥ R_min` 的辖域内,买入的期望净值为双段结构:

```
EV_buy = [买入段] + [兑现段]
       = ( −c·(1 − s(w)) − H )  +  ( Δp_tier · R_rest · δ )
```

- **买入段(期权半截)**:可逆性成本——1★ 卖出全额退,s(w)=1,故 `c·(1−s)≡0`,该段只剩 bench 槽位占用 H;
- **兑现段(折价半截)**:档位收益 `Δp_tier·R_rest` **乘兑现折价 δ**,不是记满的等式——见下。

同费用下,线内成员买入 EV 严格大于线外插件买入 EV。

记号:
- `Δp_tier`:该成员使 L 的羁绊档位前进一步带来的每轮期望收益——**待按档位分解重标定**(w795 观测面:sim A/B 兼标定,见 `w795_realization_design/PREREG_兑现链A_B.md`);原 P3 e-值口径(e0→e1 +1.4金/轮等)**已作废禁引**(P3 索引 2026-09-01:Δp=0.277 作废,数值面证明不成立)。重标定纪律注:P3 旧口径是成型度×连胜金×息的混合净期望,重标定必须按**超额收益隔离公理**拆出连胜分量,不可直接复用口径定义。
- `δ ∈ [0,1]`:兑现折价(联合折项)。羁绊档位由**上场人数**激活(`cw_factions` FactionInfo:tiers=几人激活第 N 层),而买入落点=备战席(merge_mechanics),兑现需「人口位有空(等级人口 cap)+ 上场/合成吸收」两道后续条件成立。形式上 δ = E[χ(兑现时点在 R_rest 内 ∧ 兑现谓词可达)] / R_rest 口径的折价比;**板满 ∧ 上场谓词不成立 ⇒ δ→0**,此时买入只剩期权价值(段一),EV 可能转负。折价模型的具体形式随 w795 兑现链设计件定,本篇只锁「收益项必须乘 δ、现式无 δ 时是上界非等式」的结构约束。w791 局 6 的「锁线 6 轮停 2 档」即 δ 不可近似为 1 的实机反例:买入时点记满 Δp_tier·R_rest 的旧式,被其自引的实证直接证伪。
- `R_rest`:本位面剩余战斗轮数(收益期);辖域门 **R_rest ≥ R_min**(先验带 [3,5],开臂前标定),R_min-only,见辖域门节。
- `s(w)`:星级 w 的卖出退金率(`cw_state.sell_refund`:1★=cost 全额 → s=1;2★=cost×3−1 / 3c → s≈1;仅 cost≥2 减 1 手续费);
- `H`:bench 持有成本(挤占备战席导致弃购其它件的期权成本;bench 有空位时 H≈0,近满时按 [34] 备战席稀缺性上升;[34] 只给定性序,保守处理=bench 占用 ≥ 容量−1 时 H 取禁囤阈值,标定前排他使用)。

## 证明(结构部分)

1. **可逆性(期权成本近零)**:1★ 卖出全额退(P1 已证支柱:卖出全额退=免费期权,P6 同构)。买入线内成员是一枚可免费行权反向的看涨期权:持有成本仅为息损差(若跨息档,由 [22]④/[11] 的既有息账管辖,不在本命题内重复计罚)与 bench 槽位占用 H。故 EV_buy < 0 仅当 `c·(1−s) + H` 压穿息档且无溢余授权——在溢余段(g>50,P11:溢余金的 D 决策机会成本下界=0)恒不成立。
2. **线内 > 线外(同费用)**:线外插件不推进 L 的档位,其 Δp_tier=0,收益只剩压库浓度项(P4 已证方向证伪:单次刷新幅度 ≤1.0pp,量级上不足以与任何正的档位进度项竞争)与 [34] 插件凑 2★ 项(不可量化,排后)。方向背书(P20,**仅方向、非数值阶**):体系激活(e0→1)有次战战力通道,而散件升星效应在唯一数据源 sim 模型内真值为 0——故「同费用下只要 Δp_tier·δ 严格为正,线内>线外」成立;原「2.6-2.9× 量级支配」的数值背书已随 P20_VALIDATION §7 判决(2026-09)降级撤回,不再作为数值阶引用(且 P20 度量口径为胜率/Δhp,与本题金/轮口径跨单位,数值引用本就不合法)。注意:δ 对线内/线外同乘,不影响该方向比较;但 δ→0 时比较退化为「期权价值+压库项」之争,命题辖域收缩到「兑现谓词可达」的局。
3. **超几何可算性(供给侧)**:线内成员单店出现率由 `cw_shop_odds.expected_refreshes` 的既有模型给出(5 格 × 该费用档概率 p,二项;档内目标牌 = 超几何:剩余目标副本 / 剩余同费副本;牌池副本数 1/2费 27、3/4/5费 9)。弃购的真实代价 = 再遇期望轮 1/q(P1 已证),线内成员囤与不囤的差即「现在拿走 + 再遇窗口清零」与「等 1/q 轮」之差。再遇带按 P1 现行口径(带等级辖域):5费 60-180 轮;低费 1费 lv1-4 ≈4-7 轮、lv5-6 ≈9-14、lv7+ 21-80(P1_VALIDATION 修正 1 的新带;原「低费 7-15 轮」旧带已废,不再引用)。

## 辖域门(R_min-only)

- 事前辖域门 = `R_rest ≥ R_min` 单一形式(槽序表派生量,R_min 先验带 [3,5]、开臂前标定)。收益期过短时按宏观均值代回收益项与 `c·(1−s)`+息账同量级,符号不稳健——辖域外本命题不主张。短收益期的数值示意只作量级直觉,**不引用任何已废 P3 锚的数值**(原「≈4-7 金当量」示例系 R_rest 3-5 × 已废 P3 1.4-1.6 的算术,已删除)。
- **[39] 合规声明**:HP 不作为决策依据(经济+阵容=仅有的决策面);hp 仅进判读/复盘。**本辖域门不设 hp 代理门**(原「hp ≥ [18] 报警线 40」已删——[18] 原文明言 40 无标准数值授权,且 hp 作决策门撞 [39])。若策略侧确需血线联动,唯一合法形式是判读侧按「血线→预期轮数→R_rest」换算后仍经 R_rest 门,决策层不直接读 hp。

## 策略含义(证成后的判据形态)

锁定线确立后,买入优先级 = 线内缺档成员(目标件,且兑现谓词可达——板满且无人口位时按 δ 折价后排) > 线内囤件(已持有档内副本,第 2/3 份走 P30 合成完备账) > 压库件([34] 费用档判据;[30] 已被 P4 方向证伪、判据层保留) > 线外插件([31]③ 边际羁绊贡献判据)。这与 [31] 三级梯队同构,补的是**锁定后的量化排序**,取代当前评分层「线内囤件与线外插件不可分辨」的现状(断点证据见设计报告 §2)。
