# 战斗系统(combat)

星穹铁道核心是**回合制战斗**(区别于 ZZZ 动作战斗)。各玩法(花萼/历战/饰品/模拟宇宙/忘却之庭)战斗都走此系统。bot 依赖**自动战斗**等结果,不手动操作技能。

## 机制(回合制,待攻略细化)

- **命途**(角色职业):毁灭 / 存护 / 巡猎 / 智识 / 同谐 / 虚无 / 丰饶 / 记忆 —— 决定角色定位 + 祝福命途(模拟宇宙)。
- **属性 / 元素**:物理 / 火 / 冰 / 雷 / 风 / 量子 / 虚数 / 想象 —— **weakness break**(击破敌方弱点护盾)核心,匹配敌方弱点属性高效。
- **行动条 / 速度**:角色 + 敌方按速度排序行动(回合制顺序)。
- **技能**:普攻 / 战技(战技点消耗)/ 终结技(能量满释放)。
- **战技点**:普攻回 / 战技耗,管理战技点。
- **自动战斗**:游戏自带 auto(全自动 + 倍速),bot 依赖 auto 等结果。

## 流程与决策点

- **进入**:大世界遇敌 / 秘技攻击 / 各玩法挑战(花萼/历战/饰品/忘却之庭/模拟宇宙)→ [战斗画面](../screens/battle.md)。
- **编队**(战前):[队伍](../screens/team.md)配置 4 角色 + 命途 / 属性搭配(weakness 克制)。
- **战斗**:回合制(行动条 → 技能 → 释放)→ 自动战斗 or 手动。
- **结算**:挑战成功 → 领奖励 / 再来一次;战斗失败 → 退出 / 重试。

## bot 行为(各玩法)

- bot **不手动操作战斗**(技能选择 / 时机)—— 依赖游戏 auto。
- 各玩法 challenge op(`challenge_echo_of_war` / `ChallengeOrnamentExtraction` / `sim_uni_fight_elite`)触发战斗 → 等结果(`battle_screen_state` 检测挑战成功/失败)。
- 战前配队:`search_best_mission_team`(忘却之庭)/ 用户预设编队(饰品存档)/ 固定队(花萼/历战)。

## 备注 / 待查

- **自动战斗依赖**:bot 战斗靠游戏 auto,不保证最优(高难忘却之庭可能需手动配队 + auto)。
- **weakness break**:属性克制是战斗核心,bot 配队考虑弱点(忘却之庭 `search_best_mission_team` 按弱点?)。
- **秘技**:大世界用秘技(开战前增益,如银狼植入弱点)—— `normal_world` 秘技 area,战前秘技 op 待确认。
- **待攻略细化**:命途 / 属性 / 击破机制详情,可搜攻略补(本 doc 先框架)。
- **与 ZZZ 区别**:ZZZ 是动作战斗(闪避/连携),SR 是回合制(策略配队 + auto)—— bot 处理差异大(SR bot 靠 auto 等结果)。
