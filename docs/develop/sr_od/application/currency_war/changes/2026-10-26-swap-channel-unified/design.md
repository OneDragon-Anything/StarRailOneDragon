# 转型域换人通道统一设计 迭代设计（总纲）

## 0. 元信息

- 迭代目标：用户裁定 2026-10-26（登记载体 = 本迭代进度账本 T-1 note）：换人策略按羁绊组双门 + 转型域统一收益-安全框架落地（治本方案）；净战力不证明（宪法第 1 条禁战力建模），行为锚点验收；P61 证明退役。
- 状态：对抗审中
- 文档清单：无详设（单文档方案，本篇即完整设计）

## 1. 问题与动机

- 现状症状：sim 局 g_20261026_203023（seed=20261216）复盘立案 C1——2-1 买主线核心 Saber 后 4 个备战期换人卖出 0 发射，板面保持位面 1 过渡配方直到死亡（复盘报告 = `.debug/currency_war/deep_review/g_20261026_203023.md`）。历史同病：strategy-docs/02_mandate_layer.md §1 A/B 归因「没做占绝对主导（部署 0/934）」；2026-09-18 板满换入分支为同病第一件补丁（`kernel/cw_deploy_logic.py` `required_swap_arm_pending` docstring 出处行）。
- 根因归层：**语义层 + 架构层**。语义层 = 换入判据语义单位错置（单件「一步成型」对多成员多档位阵容结构性不可达）。架构层 = 同一换人动作帧上有**多层独立判据**（触发/守恒/素材/放行/窗口）层层封堵，各自演化：判定对象不一致（有的看换前 victim 单侧、有的看换后）、守恒对象与口径不一、判据折法不一（✗→✓ 与 Δfp 并存）。**只修触发层不达效**——其余层照样封死同一批 victim。本迭代为同族病第二件，按跨件半问升架构级：公共根 = 各层缺统一「收益-安全」判定原则。
- 解决到哪：**转型域（终局锁定生效帧）**的五层统一到单一判定原则（§2.0–§2.8）；P61 退役（§2.9）。
- 明确不解决：**双轨域（P1 配方对锁期）换人行为——现行机器原样保留**（2026-09-18 配方完成件通道继续服务其域，本迭代不触碰，见 §2.3）；买入面（M2/商店判据）；sim 战斗结算与 hp 校准；净战力强弱证明；经济/升级判据本体（放行层复算接线与来金资格增补除外，§2.5/§2.8）。

## 2. 方案

### 2.0 统一原则（适用域 = 转型域）

**换人合法性 = 组换后板态 × 锁定终局阵容。**

- **适用域**：终局阵容锁定生效帧（判定权威 = `cw_intention.committed_authority` 现行）。双轨域（P1 配方对锁期）不进统一框架：完成品分支、必需件分支、守恒判定全部现行原样（§2.3）。
- **组换后板态** = 板上单位集合 − 换出 victims + 换入组 的派生视图；档位与支撑计数按 §2.1 在该视图上现算。
- 转型域内五层全部消费同一判定函数（单一源），**禁各层自备第二套折法**。

### 2.1 支撑件与档位（口径定义）

- **支撑件 = 终局名单成员（k_members）∪ 羁绊标签命中 `form_tiers` 键集的外部件**（并集）。名单成员无条件计入（瓦尔特/符玄零标签命中仍计入）；外部凑档件按标签计入。
  - 依据：`data/cw_chars.py` 标签实测（吉尔伽美什/Saber=圣杯+能量；开拓者·记忆/藿藿=含能量；瓦尔特/符玄不含；停云=仙舟+**能量**；远坂凛=圣杯+战技点；爻光/青雀非圣杯非能量）；`data/cw_factions.py` 档位表（命运圣杯 2/3/4/5、能量 3/5/7/10）。
- **终局档位**：组换后板态上各终局羁绊人数对照 `form_tiers` 现算激活态。
- **支撑件身份 ≠ 不可卖**：victim 资格由门 2 与 §2.7 victim 序独立裁定——能量标签过渡件（停云类）既是支撑件也可作 victim，仅由序deprioritize（§2.7）。

### 2.2 触发层：羁绊组双门

- **门 1（收益门，满足任一，对组换后板态判定）**：
  1. 激活终局羁绊新档位；
  2. 支撑件数严格增；
  3. 同名升星横换（换入件星级 > 被换件星级）。
- **门 2（安全门，逐被换件）**：现行 `swap_sell_exclusion_reason` 全链零豁免——义务集、新鲜度排除、资格族（`merge_material_guard` 素材守卫 / `engines_guard` / `star_guard` / `fenced_arm_closed` / `target_keep` / `fp_unreadable` 等拒因面全量保留；其中 `target_keep` 判定口径按 §2.2.1 收窄）。

**§2.2.1 target_keep 判定口径收窄（转型域）**：现行按**阵营视图**命中判 target 单位（`cw_launch_admission.py` target_keep 谓词 + `cw_deploy_logic.py` 让位消费面），会把能量/圣杯标签过渡件（停云/远坂凛类）恒拒出 victim 池——转型域 victim 池被清空，用户裁定的「拆掉过渡阵容的羁绊」不可达。裁定：转型域 target_keep 的 target 判定口径收窄为**终局名单成员 ∪ 保护集**（与保护集语义并集，P78 口径）；标签命中但不在名单的外部件与过渡件不因此恒拒，能否卖由门 1 组态与门 2 其余资格裁定。双轨域 target_keep 口径不动。

**枚举情形表**（门 1 面；门 2 独立叠加；数值按 §2.1 标签直调，C1 帧 2-1 板面 = 吉/远坂凛/青雀/停云/爻光+1，圣杯 2 = 吉+远坂凛、能量 2 = 吉+停云）：

| 情形 | 例子 | 组换后板态 | 判定 |
|---|---|---|---|
| A 终局件进、过渡件出 | **Saber 换爻光（或青雀）** | 圣杯 2→3 **激活二阶**（吉+远坂凛+Saber）∧ 能量 2→3 **激活一阶**（吉+停云+Saber）∧ 支撑数增 | 放行（①②） |
| A′ 换入件与在板能量件同档 | Saber 换停云 | 圣杯 3 激活、能量持平（停云离场−1 能量 +Saber +1） | 放行（①，序上劣于 A——victim 序deprioritize，§2.7） |
| B 外部凑档件进 | 能量标签外部件换爻光类 | 能量档升新档（帧定）、支撑数增 | 放行（①②） |
| C 整组换 | 开拓者·记忆+藿藿 进、两过渡件出 | 支撑数 +2、能量新档 | 放行（①②） |
| D 同名升星横换 | 板上 1★ Saber、备战席 2★ Saber | 数量持平、星级升 | 放行（③） |
| E 终局件横换终局件 | 瓦尔特换符玄 | 无任何结构收益 | 拒绝 |
| F 卖终局档位承载件换外部件 | 卖开拓者·记忆换能量件 | 档位降或承载受损 | 拒绝（保护集禁卖 + §2.8 演进排除） |

- 门 1 判定的羁绊范围 = 终局阵容 `form_tiers` 键集，不含其他羁绊；双轨域无门 1（§2.3）。

### 2.3 守恒层：转型域统一、双轨域原样

- **转型域**：守恒判定 = **终局档位非降（组换后板态口径）**，与门 1 的档位面同一函数，不设第二实现。
- **双轨域**：`engines_guard`（守恒对象 = `SWAP_GUARD_SYSTEMS` 四体系+护盾，victim 离场口径）与配方完成件分支、必需件分支**全部现行原样**——第一件补丁的配方域通道不被本迭代触碰。v2 草稿「双轨期守过渡配方档位」系对现行守恒对象的错误转述，以本节为准。
- 效果：转型域解锁羁绊承载型 victim（爻光/青雀类——其过渡羁绊掉档由换入组的终局新档覆盖，即用户裁定的「拆掉过渡阵容的羁绊」）；C1 帧死局解除（情形 A）。

### 2.4 素材层：零改动

`merge_material_guard` 绝对禁卖不变，不设转型豁免（其关切 = 合成进度的经济价值保护，成立）。C1 帧核验：远坂凛持续受保护（bench 有第二张，`same_star_count=2`），爻光/青雀解锁为合法 victim。

### 2.5 放行层：废弃第二折法，改复算统一门

现行 P79-3 三轴（`mandate.py` 部署执行放行门）在**转型域**废弃：轴② Δfp>0 与门 1② 系统性冲突（Δfp 折法已弃，§2.11）；轴① bench∩membership 使「仅剩外部凑档件待上」帧结构性发不出。改为：**计划落地前对预期组换后板态复算门 1（门 2 已逐件过），一致才放行**——放行层是统一门的复算确认（单一源）。双轨域放行门不动。

### 2.6 窗口层：零改动，显式声明

方向线成员豁免照旧（`strategies/impl/mandate_v1/entry.py` 现行豁免，实现批核符号锚）；外部凑档件无 `entry_signals` 登记 = 不受窗口辖（辖域定义 = 知识卡 `entry_signals`，22_prep_screen.md §1 第 6 步）。

### 2.7 组配对算法与执行形态

- **最小充分组贪心**：候选换入序 = 名单成员先（星级降序）→ 外部支撑件（星级降序）；victim 序单一源 = **现行换人机器 victim 序（档边际贡献, 星级, 槽位——`cw_deploy_logic.py` 现行排序处，实现批核符号锚；非 11 号稿金当量价值序）**，停云类支撑件因档边际贡献高自然靠后。逐个扩组：每入一个换入件从 victim 序配一个；每次扩组对组换后板态算一次门 1；**首个可行组即停**。无可行组 = 本帧零动作（合法稳态，非缺陷）。
- **执行形态（本迭代新机制，非现状）**：可行组的 |换入|=|换出| 对按同帧原子序逐对（SellDeployed → DeployMove）连发。**中途失败语义**：任一对失败（Sell 成功而 Deploy 拖拽失败，动作层零判效契约下可达）→ 帧内停发后续对，已完成对各自保留；下帧换人机器对剩余组重新现算续发（计划无跨帧状态，重算幂等，与现行「先卖后续帧重评续发」同一架构语义）。卖后上序底线照旧（`post_sell_req_missing`）。

### 2.8 收敛不变式（接替 P61 有限触发角色）

- **堵回降口一（演进侧）**：演进降级换人 victim 资格增补排除「终局档位承载件」（其离场使终局掉档）。
- **堵回降口二（来金侧，资格面增补）**：来金族出售候选池（节末凑息/升级凑金/会话内筹资）资格增补排除「离场使终局档位下降的支撑件」。依据链：11 号稿 §4.0 场景表（`criteria/sell_candidates.py` 装配）现行仅把羁绊贡献作**排序项**非资格排除——凑息/凑金可卖外部支撑件，支撑数可回降；「哪怕下远坂凛都不能拆能量」教义（cw_comps.py 双王圣杯 branch_key 注记）裁定拆终局档位承载件换金 = 违反阵容硬约束，故以资格排除闭合。
- 全局单调论证：终局名单成员受保护集禁卖；演进侧与来金侧排除落位后，板上支撑数**全局单调非降**；门 1 各分支要求某结构量严格增（支撑数/档位/星级），上界有限（板位数、档位组合、同名星级组合）⇒ 触发次数有限、无死循环。纯结构计数论证，零参数，非战力证明。

### 2.10 净战力不证明与行为锚点

- 净战力账需战力建模（宪法第 1 条禁）。判据合法性来源 = 注册表档位数据（零调参）+ 用户立场（【拍】类）。

### 2.11 关键取舍

- **Δfp>0 放宽（放弃）**：form_progress 满锚 = 完全成型，多档中盘 Δfp 与档位激活不同构；离散档位判据零调参，且天然守护能量硬约束教义（拆能量 = 掉档 = 门 1 不过）。
- **登记 required_deployed（放弃）**：字段契约「缺它永不成型」与双王圣杯不符（Saber 有 Archer 替班形态，cw_comps.py special_systems.grail_quest）；且让位检验一步成型折法不动则通道照旧关死。
- **P61 扩展证明（放弃）**：新触发面下「五体系档守恒」不成立（过渡档可掉）；战力面证不了（宪法第 1 条）；用户裁定不证明。
- **守恒域切分（转型域统一、双轨域原样） vs 全域口径重裁（放弃后者）**：双轨域机器经实机验证（配方域通道在产），重裁 = 无必要的爆炸半径；统一原则的价值在转型域（C1 病灶域）。
- **target_keep 收窄（名单 ∪ 保护集口径） vs 阵营视图口径保留（放弃保留）**：阵营视图口径把标签过渡件恒拒出 victim 池，转型不可达；名单口径与保护集语义并集后，正当保护（终局件不卖）不损失。
- **来金资格排除 vs 放弃单调论证（取排除）**：排除谓词纯结构（离场后终局档位是否下降），零参数；放弃论证则 P61 退役后通道无终止保证。
- **放行复算 vs 独立放行判据（取复算）**：单一源原则；独立第二折法已被证明与主判据漂移（Δfp 冲突实证）。
- **支撑件并集口径 vs 纯标签口径（取并集）**：纯标签口径把零标签命中的名单成员（瓦尔特/符玄）结构性排除出板，病以新形态复发。
