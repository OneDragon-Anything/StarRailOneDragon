# 投资环境选择决策升级 迭代设计（总纲）

## 0. 元信息

- 迭代目标：投资环境 3 选 1（事件面 E1）决策两块升级——**①候选全集门**：加成阵营不在候选终局阵容全集的环境，注册表裸分失格；**②经济建模**：EnvEconomyEffect 结构化经济通道 + 金等价估值 + S2 同款域带集成 + portal 登记端。两块同属环境选择这一个决策点，合一个迭代（用户裁定 2026-09-12「合到一份，都是投资环境的」）。
- 用户裁定汇编（均为 2026-09-12）：
  - 全集门：「我们有对应的终局阵容定义，才选对应的投资环境……应该避免不在我们候选阵容里的投资环境，选了肯定也没用」；形态 B（裸分失格），否决形态 A（集合级排除）与罚分；flex_factions 不入全集；全集随 evicted 动态收窄；sim A/B 暂缓。

- 状态：定稿[收敛+试读过]（对抗报告 = [attack.md](attack.md)，18 项发现全部修订落稿）
- 文档清单：details/env-value-models.md —— D 类两型（送卡型/品质改写型）估值详设（承接 §2.3 集成次序与 §2.2 经济建模单一入口）

## 1. 问题与动机

### 1.1 现状症状

**症状 a·无用环境占位竞争**：env 打分分支（`kernel/cw_events.py` `if _st is None and _env is not None:`）对 83 条环境一视同仁按 `ENV_PICK_VALUE` 裸分竞争。faction 锚定型（`InvestmentEnv.faction` 非空，派生自 `_derive_env_tables`）直调合计 43 条 = 概念股 ×15 + 邀请 ×20 + 契约 ×7（外加特邀专家:加拉赫例外表 1 条），效果全部服务对应阵营（概念股 = 送该阵营角色 + 刷新率定向；邀请 = 送该阵营星徽；契约 = 送该阵营角色；依据 = `data/cw_invest_data.py` PLAZA_PORTALS 效果原文 id 1001-1016/1101-1120 及契约 125-129/1201-1202）。阵营不在候选终局阵容（`COMP_LIBRARY`，20 套）并集内时增益无消费方，但裸分仍可胜出。实测反例（值直调）：{狼狩概念股 40, 战力提升 38, 成功经验 36} → 现状选狼狩概念股，而「狼狩」不在任何候选阵容 factions 中（20 套逐套核对见 §2.1）。

**症状 b·环境零经济建模（三层缺失，依据直调）**：
1. 决策侧不算：`InvestmentEnv` 无 economy 字段 → 环境进不了 S2 经济引擎档（`is_economy_engine` 仅消费策略卡 `EconomyEffect`）→ 用户裁定 2026-09-08「投资选卡优先经济」在环境轴无法兑现。唯一价值信号 = `ENV_PICK_VALUE` 手工裸分，经济类高分无持久口径出处（ADR-0620 §3 明文）。
2. 运行时不算：效果登记器三来源中环境源未建——`cw_effect_inventory.py` `SOURCE_PORTAL='portal'` 预留值、「登记端未建」（SOURCE_PORTAL 前言注释原文；行号随代码漂移以符号为准）。
3. 缺口连锁：环境侧刷新执行不启用（ADR-0600 §2/§4）理由之一即「环境侧顶级类结构性不可判」。

### 1.2 根因归层

- 症状 a = **语义层**：环境「有用性」判据缺维度——裸分是通用强度先验，不含「本 bot 候选阵容吃不吃得到该环境增益」；既有 D*（locked_comp/资产信号）只辖「对齐提档」（floor），不辖「无用回避」，且 D* 开局通常为空，而环境恰在信息最少的开局三选一——回避判据必须依赖开局已知的候选阵容全集，不依赖 D*。
- 症状 b = **表示层 + 语义层**：`EconomyEffect` 字段结构（per-node/一次性）装不下环境的「整局规则改写」形态（分期发放/费率覆写/条件触发/节点替换/概率结构），且从未定义环境经济价值的估值语义。ADR-0144 决策 3 已点名 6 条防一次性错装警告；08_events E1/E2 挂账「台账价值待 derive」——本迭代即该挂账落地。

### 1.3 解决到哪 / 明确不解决

解决：§2 全部（全集门 + 经济建模 + 汇合集成 + portal 登记端）。

明确不解决（各项自成后续迭代，防范围外溢）：

1. ~~定向送卡型环境~~：用户裁定 2026-09-12 纳入本迭代 → details/env-value-models.md §2.1（结构对齐档：候选角色全集成员性 + 分档 floor，G 组锁）；「全集门只对 faction 非空候选生效」的边界不变。
2. **策略卡同构 gap**（`decide_invest kind='strategy'`）：非对齐策略卡仍走裸分。用户裁定只点了投资环境，另行立项（已立项 = `2026-09-12-strategy-universe-gate`，含 335 卡全量分类盘点与 S1 定义型豁免前提守卫）。**跨迭代契约**：角色全集口径与 `candidate_char_universe` 落码单一源 = details/env-value-models.md §2.1.2/§2.1.3（core∪shared、transition 不计，`char_routes` 同源理由）；该迭代消费同一函数、禁两侧各自实现同名 helper（其「角色全集口径建议」流程改为对本口径确认/回写；cw_comps.py 落码互斥由编排者排序）。
3. **D 类环境价值化**：送卡型与品质改写型已由用户裁定 2026-09-12 纳入 → details/env-value-models.md（品质改写层 E v1 恒 fail-closed 走裸分，转正准入门 = 全通道 μ_E 重算 + 序一致性检验，在册）；仍不入：战力类（进化算法/战力×2）、随机/规则补给类、红钻蓝钻贵族/深井角斗场/命运礼物/英雄登场/三星佩佩等（价值待语义实采；红钻/蓝钻 = 星徽配方材料【注·配方表】，价值锚可部分收敛）。
4. **时间贴现**：早金利息机会成本可算（息律 τ），v1 不加层。
5. **判据消费接线**：portal 登记端只做「登记入账 + 查询口」，现有经济判据暂不接登记数据，按消费需求另批。
6. **全无用帧的选择质量**：三候选全无用时游戏仍强制选一，本迭代只保证无用者垫底（刷新判据 §2.8 缓解：零价值槽刷到计数耗尽）。
7. **全集覆盖质量**：全集由 COMP_LIBRARY（手判层）派生，阵营覆盖责任在 final_comps 研究（唯一源）；研究遗漏导致错杀的修正路径 = 修 COMP_LIBRARY，不是放松门。

## 2. 方案（单文档完整设计）

### 2.1 块一：候选全集门

#### 2.1.1 全集派生

新函数 `candidate_faction_universe(evicted: frozenset[str] | set[str] = frozenset()) -> frozenset[str]`，落点 `kernel/cw_comps.py`（COMP_LIBRARY 派生 helper 区，`get_comp` / `hp_charge_stack_chars` 同区）：

- 全集 = ⋃ `comp.factions`，遍历域 = {comp ∈ COMP_LIBRARY | comp.name ∉ evicted}；
- **flex_factions 不入集**（用户裁定：弹性羁绊是阵容能临时吃的，不是可能玩的方向）；
- evicted 与 D*② 同源同义：意向层判「等同信号未发生」的 comp 名集合——`decide_event` 现有参数（flow.decide_invest 从意向状态传入），**零接口新增**；
- 动态收窄免费获得：阵容被 evicted 后其独占阵营自动退出全集（例：追击飞霄被排除 → 追击概念股/追击邀请失格）。

全集阵营核对表（直调 COMP_LIBRARY factions；落码批在测试模块头做漂移断言，漂移先红）：列车同行 / 命运圣杯 / 减益 / 星核猎手 / 欢愉 / 星间旅人 / 量子同频 / 贝洛伯格 / 巡海游侠 / 击破 / 战技点 / 能量 / 群攻 / 银河学者 / 昼之半神 / 追击 / 夜之半神 / 燃血 / 持续伤害 / 仙舟。全集外 env faction 实测（注册表/对局档案直调核验）：**{公司, 狼狩, 盛会之星}**——门咬合面 = **4 条环境**（狼狩概念股 / 狼狩邀请 / 公司契约 / 盛会之星邀请）；公司与盛会之星仅以 flex_factions 出现于候选套，按「flex 不入全集」裁定落全集外。

#### 2.1.2 落码面（形态 B）

- 门谓词（env 分支内、`env-eval` 裸分支前置）：`_env_in_universe = (not _env.faction) or (_env.faction in _universe)`——faction 空（时代/经济/规则/随机送角色等阵容无关型）恒真；
- 失格语义：非全集内 faction 的环境跳过裸分支，分数维持 0（env 无品质字段，品质回落域在策略分支内，env 本就无回落——落 0 即天然垫底，零新常量）；
- 全集单帧单读：循环外一次 `_universe = candidate_faction_universe(evicted)`（与 D* 快照同款纪律）；
- 归因串：失格候选 reason = `env-off-universe`（全无用帧胜出时可见）；仅观测归因，沿 ADR-0593 C1→D4 口径不进任何检查器白名单；
- steering 次序不变：user-priority/user-forbid 在最后叠加——无用环境被 priority 抬升仍可胜过低裸分有用环境（用户配置最高语义）；
- 不动的面：血本位三态分区（env 结构性非血）；T-162 刷新槽分类（无用槽本就恒在可刷集）；F9 env 帧检测；D* 解析；active_env 写入链；`ENV_PICK_VALUE` 表本身（失格是消费侧谓词，表保持「通用强度先验」语义）。

#### 2.1.3 正交性

D* ⊆ 全集恒成立（D*① locked_comp 与 evicted 互斥；D*② 已按 evicted 过滤，`_invest_d_star` 现行实现）→ 阵营 floor 永不为全集外 faction 触发，全集门与 floor 门无交集，无需交叉处理代码。

#### 2.2.2 schema：EnvEconomyEffect（数据层）

落点 `kernel/cw_investments.py`（EconomyEffect 同区），frozen dataclass，字段按「环境规则改写形态」设计（区别于 EconomyEffect 的 per-node 形态），全部带缺省值（无通道 = 全缺省）：

```
gold_per_plane_start: tuple[int, ...] = ()          # 每位面开局金,元组下标 = 位面−1(增发货币 (6,8,12))
gold_instant: int = 0                               # 获得时一次性金(蓝海 6)
xp_after_level: tuple[int, int, int] | None = None  # (等级, 节点数, 每节点XP)(成功经验 (8,3,12))
gold_per_strategy_coef: int = 0                     # 每取一张策略 +coef×取卡前已持有数(策略大师 2)
gold_after_refreshes: tuple[int, int] | None = None # (刷新阈值, 返金)(长线利好 (30,20)/二手市场 (20,30))
refresh_cost_after: tuple[int, int] | None = None   # (刷新阈值, 新成本)(长线利好 (30,1);基价 2 为游戏定义)
reward_node_bonus: float = 0.0                      # 每奖励节点期望增益(仅 C 类估算条目;值+CI 在估算注册表)
```

- 注册沿 `ENV_PICK_VALUE` 先例：`ENV_ECONOMY: dict[str, EnvEconomyEffect]` 独立常量表，孤儿键 import 即炸，`replace()` 挂 `INVESTMENT_ENVS[name].economy`（`InvestmentEnv` 增 `economy: EnvEconomyEffect | None = None`）。
- **表内条目白名单制**：表外环境一律 None，禁从效果原文自动猜装；ADR-0144 决策 3 的 6 条防错装警告在构建时逐条对账（批报告内留记录）。

#### 2.2.3 价值函数（语义层）

新模块 `kernel/cw_env_economy.py`：

```
env_economy_value(name: str, bs: BoardState) -> tuple[float, bool]
```

- 返回 `(expected_gold, resolved)`；`resolved=False` = 依赖估算参数缺失或 CI 不闭合（§2.2.4）→ 消费端按无经济通道处理（fail-closed）。
- **剩余价值口径**：从 bs 当前位面/轮次起算到局终——开局选卡 = 全局期望，局内重发环境 = 剩余期望，同一函数自然覆盖。
- 位面到达结构：`P(位面 k 可达)` 进估算注册表（遥测统计）；精确通道期望 = Σ(通道金 × 对应位面到达条件概率)。
- 策略大师公式：`Σ_k 2×(k−1) × P(第 k 张策略可取)`，k 遍历位面节点表中的投资策略节点序（节点表单一源 = kernel 位面节点表注册表直调，禁硬编码节点数）。
- XP 通道：`XP × XP_GOLD_RATE`（=1.0，裁定 4 暂定；定谳推翻改一处，按未证即退役处置该折算）。

#### 2.2.4 估算注册表与 fail-closed（【拟】态治理）

- 落点同模块：`ENV_ECONOMY_ESTIMATES: dict[str, ParamSet]`，每参数 = `(值, 置信区间, 数据来源, 统计截止)`，注释按三形态【拟】规范（依据 = strategy-docs 00_framework 数字三形态章程）。
- 需估参数清单：P(位面 2/3 可达)、E(对局总刷新次数分布 → P(达 20)/P(达 30)/E(达 30 后继刷新次数))、经济过热每奖励节点期望增益（普通/超级）。
- 数据源 = 对局档案遥测（`telemetry/cw_replay_reader` 系）：bonus node 收支、逐局刷新计数、位面到达率。数据批产物直接落注册表，禁拍值。
- **fail-closed 门（参数级定义，可实现口径）**：每参数按置信区间两端点重算该环境 `expected_gold`，两端点下「`expected_gold > 0`」方向翻转（即金期望的 CI 含 0）→ `resolved=False` → 该环境按无经济通道处理（退裸分）。补数据缩区间后自动恢复。（帧级跨候选的「决策序翻转」不属本函数辖域——`env_economy_value(name, bs)` 签名无候选集入参；跨候选序稳定性由域带门 `expected_gold > 0` 的方向性承载。）
- 轮岗/人才下沉以「待建模」条目显式在册（无参数 = resolved=False 恒然），区别于「漏登记」。

### 2.3 汇合点：env 分支集成次序（单一真源）

`decide_event` env 分支内各机制按以下次序组合（max() 覆盖定序，高者胜；归因串跟随最终胜出支）：

```
1. 全集门：faction 非空 ∧ faction ∉ 全集 → 跳过裸分支（分数 0，reason=env-off-universe）
2. 裸分（env-eval）：全集内 ∧ pick_value > 0
3. 送卡静态档（详设 details/env-value-models.md §2.1）：ENV_GIFTS 命中 → gift-core 66 / gift-shared 60 /
   advisor-core 54；发卡角色全集外 → 0（env-gift-off-universe，结构性预留）
4. 经济域带（env-econ）：economy 通道 resolved ∧ expected_gold > 0
   → ECON_ENGINE_BAND_BASE + ECON_ENGINE_BAND_SPAN × min(value, ECON_VALUE_NORM)/ECON_VALUE_NORM
   （ENV_POOL_REWRITE 品质改写经同一门入场；层 E v1 resolved=False 恒走裸分，转正准入门见详设 §2.2.2）
5. 阵营 floor（align-locked/signal）：faction ∈ D* → 70/72/78
6. steering：user-priority +30 / user-forbid −10000；DoT 克制惩罚照常
```

- 域带常量**复用**策略卡 S2 的 `ECON_ENGINE_BAND_BASE/SPAN`（111/8）——三选一帧同质（全环境或全策略，F9 已证），两轴不同场竞争，共享域带 = 「优先经济」跨轴同序，零新常数结构；
- `ECON_VALUE_NORM` = 估算注册表值域上界（数据批产出后取实际最大值取整注册，结构同 `ECON_ENGINE_PV_NORM` = 域界非拍值；越界值注册表校验炸出）；
- 次序含义：裸分（0-72）< floor（70-78）< 经济域带（111-119）——「优先经济，然后终局阵容」在环境轴成立：对齐阵营的概念股 floor 让位给有真金流的环境；
- 两块正交的结构保证：全集门只辖 faction 非空候选，经济通道只在 faction 空候选上建模（§2.2.1 注）→ 同一候选永不同时进门 1 与门 3，无交互项需推导；
- 分值域带/全集门/估算皆为消费侧谓词与域带结构，`ENV_PICK_VALUE` 表值零改动。
- 刷新提案与打分次序正交：`PickEvent.refresh_slots` 由环境刷新判据（§2.8）产出——env 帧恒空规则（ADR-0600 F9，其明文「启用前置 = 环境侧顶级类建模」由块二满足）由该判据取代；打分次序不受刷新影响，刷新后以最终名集重走同一入口（flow.decide_invest，沿 ADR-0600 G1 重决策唯一合法入口）。

### 2.5 宪法与纪律对账

- 数字三形态：全集门 = 集合成员存在性谓词（零数值进决策门）；A 类 = 【注】游戏定义值 + 【推】位面到达加权；B/C 类 = 【拟】估算（值+CI+来源，fail-closed 门）；`ECON_VALUE_NORM`/`XP_GOLD_RATE` 为结构常数（域界/兑换率），来源已注（宪法第 4 条数学先行）。
- 位面零字面量：位面仅作查表键（通道按位面索引/到达概率）（宪法第 2 条）。
- 无开关：结构判据直接落码（strategy-work §3），回滚 git revert。
- 归属：全集门、`ENV_PICK_VALUE` 消费、经济模型与估值 = 内置默认策略器评估知识（层级归属声明 = `kernel/cw_investments.py` PICK_VALUE 前言），非框架中立判据。

### 2.8 块三：环境刷新判据（刷新免费，用户裁定 2026-09-12）

**语义基础**：环境刷新零金成本（P40 可负担性恒真对环境轴成立），唯一稀缺资源 = 每槽刷新计数（画面现读，`read_invest_refresh_counts` 的 'env' 通道——T-162 观察通道转正为执行闸）。计数期限语义（visit 内用失即废 vs 跨 offer 池）**待实采**——v1 沿策略侧 ADR-0600 同款假设（visit 内用失即废），实采推翻再改。

**判据（结构判据，零自由参数）**：

- 帧级门：候选恰 3 ∧ 全部精确命中环境注册表（未知名 fail-closed 不刷，同 ADR-0600 G7 轴）；
- 槽级分类与动作集：
  - **顶级** = 经济域带 resolved（≥111）∨ 阵营 floor 命中（D* 非空）→ 保护不刷；
  - **零价值** = 全集外（§2.1.2 门失格）∧ 未被 user-priority 命中 → **恒可刷**；
  - **被禁** = user-forbid 命中 → **恒可刷**（优先于顶级保护；ADR-0600 P5② 同构：被禁者永不被选，保护无对象）；
  - 其余（全集内裸分槽，含送卡档与 unresolved 经济槽）→ **不刷，挂账**（理由见下）。
- 弱占优论证（零价值槽必刷）：当前对我们价值 0（增益无消费方），替换样本来自环境注册表全集——任一环境对我们价值 ≥ 0（D 类裸分 > 0 / 经济 > 0 / 集内 faction > 0 / 集外 = 0）且 P(>0) 显著 → 期望严格不劣；免费 + 计数用失即废 → 不刷 = 白弃改善期权。
- **裸分槽不刷的挂账理由**：刷集内裸分槽有下行风险（可能掷出零价值），「当前裸分 vs 替换期望」需要全体环境的**基数**价值——裸分是定序分（ADR-0524 禁读基数），与金等价不可混算；基数化 = 全环境价值模型，超本迭代范围，挂账至 D 类价值化迭代。

**执行链**（`CwScreenInvestEnv`，镜像 ADR-0600 §3.3 策略侧先例）：读计数 → 槽序循环（计数 >0 ∧ 槽在动作集 → 文本锚定刷新钮 → 等 1.5s → 验效双通道（计数扣减权威/卡名变化兜底，双输即停不重试）→ 重分类）→ 停止条件（无零价值槽 / 计数耗尽 / 不可分类）→ 最终名集重调 `decide_invest`（G1）→ 照常选卡确认。active_env 写入/台账变异窗时序不变。

**行为变更申报**：ADR-0600 §2/§4「env 帧恒不刷（F9 结构检测）」由本判据**取代**——这是既有在册行为的翻转，设计对抗审重点攻击面；同帧类型互斥（全环境帧走环境判据、全策略帧走 T-162 判据，F9 已证不同帧）保证两判据无叠加。
