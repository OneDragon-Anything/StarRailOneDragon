### 3.4 刷新（刷新链三组件）

权威判据 = **三组件链**（判据 → 金线闸 → 发射；判据单一源 = `criteria/refresh.refresh_warranted`，规格见 [11_shop_decisions.md](11_shop_decisions.md) §3）：

- **判据组件 = 三段式查表分派**（结构判据零期望计算）：P1 恒不主动刷新（阶段优先于锁定态，免费刷新不计入判据、无判据门——无条件刷）→ P2 未锁窗口候选缺件驱动 → 锁定后星级目标驱动（值得刷新 ⟺ 存在未完成必要星级目标 ∧ 等级 ∈ 最优概率带 ∨ 被推过带上界；带归属绑定 = 当前停留目标的带）。旧「目标可买三分支并集」预测门已整门删除（刷新时点信息不足、精确不可算，用信息最少的时点否决决策）。P40 原始形态（c_eff·E[refreshes|j] + Σ卡费 + L ≤ V_gap）与「形式二路径总账」（T_stay/T_up 比较）均作历史记录——期望比较判据面已停用，消费面改由星级目标查表承载；P40/P47 的概率与利息模型仍是概率消费面（V_opt/换现账等）与利息账的量化地基（命题本体保留已登记）。
- **金线闸组件**：放行 ⟺ 当前金 − 预留 ≥ 刷价；**预留 = saturation_line(cap_resolved) + 当前停留目标实费档 ρ**（resolved 口径，变费卡随档，与带判据同一目标元组；未锁窗口 ρ = 0——金线 = g* + 刷价）。与 P40 富余段刷窗式（floor 规范口径，P54 已交叉核对）同构；**整级预留分支不存在**（升级触发态与刷新放行态带互斥，凑金等待帧的刷新让位由判据「升级优先」支承载）。
- **发射组件**：免费分支（次数已登记即刷——无条件刷，金线不适用）→ cost=0 发射；付费 → reason `star_target` 发射；刷新负结果记忆 = 拒后关店置标记、无状态变化不重入提刷（免费与付费同闸）。变体①-⑩（淘金客/概率事件/轮岗/市场干预/节点语境等）全部 = 参数替换，骨架不分叉（P40 §④）。
