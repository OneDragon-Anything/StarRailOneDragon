## 命题

给定状态 S = (等级日程 L(·), 当前回合 t, 剩余回合 T, 持有金币 G, 已持卡集 H, 目标里程碑缺口 K 件——每件是一个**合格集**:集合内任一卡都算满足该件,可能有同名多张需求),给出:

**P(K 件全部在 T 回合内、金币预算内买齐 | S)** 的可计算方法——精确 DP(何时可行)+ 便宜闭式近似(误差方向与量级)+ 完整输入配方(每个输入映射到注册表/文档数据源,不明的列 OPEN INPUT)。

精度定位:**证据门只问「过没过阈值」**——本证明的目标是「粗而稳」:近似必须保单调性(预算/回合越多概率越高、缺口越多越低),偏差方向与量级已知即可,不追求精确值。

## 符号

- K 件编号 k=1..K;件 k 的合格集 Q_k(卡的集合,通常同费——由 `form_tiers` 羁绊档拆解而来,如「追击档 +1 人」= 全部带「追击」阵营标签的卡,查 `CHARACTERS[k].factions/flows`);需求张数 n_k(羁绊档件 n_k=1;同名多张件如「飞霄 2 星」= Q_k={飞霄}, n_k=3)。
- 单槽位命中件 k 的概率 q_k(①③层,随等级与池态变化)。
- 一轮 = 一个节点 = 一次自动免费商店刷新(economy.md §2.1「节点切换=自动刷新全店」);付费刷新 2 金/次(`SHOP_REFRESH_COST`)。
- N = 视野内总**轮数** = T(自动)+ R(付费),R 由预算决定(⑤层);总试验数 = 5N(槽)——**记号消歧**:N 全文恒指**轮数**(L83 总试验 = 5N),非槽数;实现者禁把 N 当槽数(那会把试验数放大 5 倍)。

## 推导(五层)

### ①层 单件出现:单槽位命中概率

单槽位出**费用档 c** 的概率 = `REFRESH_PROB[L][c]`(cw_shop_odds 实机 OCR 权威表);出档 c 后,出**特定一张卡** x(费用 c)的概率 = 该卡剩余副本 / 同费剩余总副本 = (a_c − j_x) / (v_c·a_c − taken_c),其中 a_c = `POOL_COPIES_PER_CARD[c]`(1/2费 27、3/4/5费 9),v_c = `DISTINCT_CARDS_PER_COST[c]`(1费20/2费15/3费14/4费14/5费9,`cw_chars` 派生),j_x = 已持有 x 张数,taken_c = 同费已购总数(P5 引用的 `acquirability_factor` 同分母)。

**一轮商店的命中分布**:5 槽 → 该件出现次数 ~ 近似 Binomial(5, q_k),精确 = M~Binomial(5, p_c) 与档内超几何的混合(`cw_shop_odds._refresh_dist` 已实现单件版)。**付费刷新**每次再给 5 个同分布试验(2 金/次,`SHOP_REFRESH_COST`)——试验次数轴上,一轮自动 + r 次付费 = 5(1+r) 个槽。

### ②层 多件收集:共享试验的正确联合模型

**错误模型(点名排除)**:K 件各自独立几何/负二项然后取 max——错在两处:同一轮 5 槽可以**同时**命中多件(不是互斥的轮次竞争),且多件共享同一批槽位试验(一件吃掉槽位,另一件该轮就少机会)。

**正确模型**:把视野内全部槽位(5N 个)看作一批分配试验。对每件 k 定义计数 X_k = 视野内落在 Q_k 剩余副本上的槽位数;目标事件 = ∀k: X_k ≥ n_k。精确分布 = 多项式分配(槽→费用档)× 各档内多元超几何(档→卡)的混合——即下面「精确方法」的 DP。

**结构结果(负关联;适用域分两层)**:
- ①**无自购衰减子模型**(池静态):档内多元超几何负关联 + 多项式类别计数负关联(Joag-Dev/Proschan);跨档逐对协差可证为负(∝ Cov(m_c, m_c′) ≤ 0);但**两两负协差不蕴含 K≥3 递增事件族的乘积上界**(NA 强于逐对负相关;混合结构保 NA 无标准定理可引)——**「严格上界」降格:K=2 可证,K≥3 为结构上 plausible + 数值实证支持**;
- ②**自购衰减情形**(店序贯、池态随购买随机变化):序贯无放回结构不在经典负关联定理覆盖域内,**上界无定理支撑**,只剩下条的数值证据。

**反向效应(池衰减增富)**:件 k 的边际模型里,其他件的合格卡算「非目标」;联合模型里其他件被买走后这些副本**离池**,件 k 在剩余池中相对变密(这就是 `expected_refreshes` 的 c 参数机制——买同费非目标抬高目标密度,economy.md §1)。此效应使联合概率**高于**独立乘积。两个效应方向相反、量级都小(数值自检:总偏差 |边际乘积 − 精确 DP| ≤ 0.005 绝对值,三个用例全表)——**独立乘积不是严格单侧界,是双侧小误差近似**(证据门口径足够;要严格上界需固定「其他件不购买」的反事实,业务上不存在)。

### ③层 合格集并集:单槽位命中概率对集合求和

件 k 的合格集 Q_k 若同费(c 为主档):

q_k = p(L, c) × W_k,其中 W_k = Σ_{x∈Q_k∩c} (a_c − j_x) / (v_c·a_c − taken_c) = (|Q_k∩c|·a_c − j_k) / (v_c·a_c − taken_c)

分母必须是**同费剩余总副本**(v_c·a_c − taken_c),不是全池也不是种类数——这正是 P5 表值的口径(c=3@L7 单卡 0.1357 的计算方式)。

**跨费合格集**(集内卡不同费,如「任意 1费/2费 X 羁绊卡都算」):q_k = Σ_c p(L,c)·W_{k,c} 按费求和。v0 配方建议:**优先按主费档建模**(取该件典型费用,如羁绊档件按其典型成员的费用档),跨费拆分留作精确 DP 的扩展(自检脚本的精确模型当前按单费件实现,配方里声明)。

### ④层 等级分段:日程作为输入场景

REFRESH_PROB 随等级剧烈变化(c=5:L7=0.01 → L10=0.25,25 倍),等级又是花钱决策——v0 不做内生优化(联合优化「升级 vs 刷新 vs 购买」是另一个证明的领地,P5 已给单件口径的 argmin 结构)。**本证明条件于等级日程 L(r)**(来源:调用方传入——重建后由升级 EV 引擎给出,本证明只条件于它):

q_k(r) = q_k(L(r)) 逐轮取表值。视野内件 k 的命中数 = 逐轮 Binomial(5·(1+r_manual(r)), q_k(r)) 的**Poisson-binomial**(成功率逐轮不同的独立和)。闭式实现用逐轮卷积或直接用平均 q̄_k 的 Binomial 近似(误差二阶;自检脚本 tools/cw/proofs/p38_check.py 的变等级混合用例含 ≤0.4pp 断言锁,实测方向保守)。

### ⑤层 金约束:预算 → 试验次数

看得到 ≠ 买得起。**预算日程(v0 解耦口径,A5/A6)**:

- 守 50 线(P13)下,**预算 B = G − 50 + Σ_{r}[base(r)+streak(r)+interest(r)] − Σ_k n_k·cost_k − Σ_ΔL levelup_cost**:
  - **金位递推(显式定义——「逐轮金位模拟」唯一口径)**:
    `g_{r+1} = g_r + base(r) + streak(r) + min(g_r, 50)//10 − spend_r`,
    spend_r = 当轮计划支出【**期末结清口径**:购买按期望到达摊销 Σ_k n_k·cost_k / T;升级金按日程所在轮扣;刷新金 2R/T 均摊】。声明:利息按支出**前**金位计 = 乐观上界(量级 ≤ 单轮支出×10%,封顶 5);**A6 的「预留」只作用于 R 的可用刷金(金位 − 购买预留),不作用于本递推的金位**——两个量分离,假设不再打架;
  - **等级日程的金成本入账**:levelup_cost = ⌈max(0, need − 4·Σn_k)/4⌉×4(cw_state XP 表 ±20%;**买牌同源送 XP 每张 +4**——engine_p1「买牌同源给 XP」/cw_state XP_PER_BUY:忽略抵扣则升级成本高估 0-100%×单级成本,方向=保守,入方向表);
  - 连胜按当前档或中位 2;简化口径:interest 按逐位面常数 **{P1:27, P2:35, P3:45}**(中位口径)折算,残差双向 ≤8 金/位面——**「L 联动批」(p47 已收口):P1 现实带 18-30(旧常数 31 = P1 上沿口径,粗算沿用须声明此限定)、P2/P3 满息进场 35/45;精算一律走⑤层金位递推**(递推本体不动,p47 已证与规范递推逐字同构);
- 可用付费刷新总数 **R = max(0, ⌊B/2⌋)**;**B<0 分支**:总钱付不起 Σ卡费+Σlevelup → P=0**——「买到即计数」前提破产,该域=缺口贵金少的门敏感区,保守处理(可负担子集重算留精确 DP 扩展);
- 总试验 N = T + R(轮)× 5(槽)。

**单调性(证据门硬要求,逐项核)**:
- G↑ / T↑ → R↑、N↑ → 每个 Poisson-binomial 尾 P(X_k≥n_k)↑ → 概率↑ ✓(二项尾对 N 单调不减,n_k 固定时严格);
- K↑(多一件)→ 乘一个 <1 的因子 → 概率↓ ✓(每件边际概率 <1,除非该件已满足——「已满足件」应从 K 中剔除,配方要求);
- n_k↑ → 该件尾概率↓ → 概率↓ ✓;
- 日程等级↑(目标费档概率↑)→ q̄_k↑ → 概率↑ ✓——**前提是金/预算固定**:真实决策里等级不免费(花金→B↓→R↓,与 B1 的预算项耦合),该单调性只在条件化口径内成立。
闭式构造**按构造保单调**——「粗而稳」合格。另注:K↑/n_k↑ 同时抬高 Σcost → B↓ → R↓,与直接效应同向(压概率),结论不变但属耦合路径。

## 精确方法:DP / 马尔可夫链 over 回合 × 收集状态

**状态**:owned 向量 j = (j_1,…,j_K),j_k ∈ [0, n_k] 封顶。**状态空间 S = Π_k (n_k+1)**:
- 典型终局里程碑(P2 成型):4-6 件、各 n_k∈{1,2,3} → S ≤ 4^6 = 4096,**毫秒级可行**;
- 追 3 星件(n_k=9):单件 S=10 无碍;两件 9 张 → S=100 仍可行;K 件全 9 → S=10^K, K≥5 时(10^5 以上)配合逐轮转移枚举开始吃力——**降级判据:S·(每轮转移枚举成本) > 预算时降闭式**。

**转移(一轮 = 自动 1 店 + 该轮预算内付费刷)**:
1. 槽→费档:multi-index (m_1..m_5) ~ Multinomial(5, REFRESH_PROB[L(r)]);
2. 档→卡:各档 m_c 张从剩余池(分类:各件剩余合格副本 / 非目标)多元超几何无放回抽;增量 min(x, n_k − j_k) 封顶(超出部分=浪费,质量并入封顶档,不截断分布);
3. 购买金与刷新金逐轮扣账(A6 预留优先;金维度可选入状态,复杂度 ×金格数——v0 用预留近似把金从状态里消掉)。

逐轮复合转移矩阵,终态 = 全部 j_k = n_k。**何时必须降级**:① S > ~10^5;② 合格集跨费严重(转移枚举指数化);③ 需要建模自适应刷牌策略(A7 放宽)→ 闭式或蒙特卡洛。

## 闭式近似(便宜配方)与误差方向

**公式**:

P̂(集齐) = Π_{k=1}^{K} Tail_k,Tail_k = P(Binomial(N·5, q̄_k) ≥ n_k),q̄_k = 逐轮 q_k(r) 的槽位加权平均(或直接 Poisson 化:Tail_k = Poisson 尾,λ_k = 5N·q̄_k)。

**误差分解(方向 × 量级,数值自检实证)**:
1. **独立性误差**(②层两效应之和):**方向依用例与 N 而变,非单一主导**——跨费对(衰减增富为零)恒正(+0.0~+0.2pp,纯槽位竞争);同费密集用例两效应并存,净号随 N 变(N=6 为 +0.48pp,N≥12 微负);全表 |边际乘积 − 精确 DP| ≤ 0.5pp(三用例 × N∈{6,12,25,50} 共 12 格,审查方全量复核);
2. **忽略自购衰减误差**(闭式用初始 q,精确边际用衰减 q):单卡多张件(n_k≥3 against 9 副本)主导,量级**最大 +7.5pp 绝对**(P2 用例 N=25:0.696 vs 0.621)——中段(N 使概率在 0.3-0.8 带内)最大,两端(N 小概率→0、N 大概率→1)收敛到 0;方向**恒乐观(高估)**(忽略衰减 = 高估后续命中密度);
3. **Poisson vs Binomial(分种类声明)**:q 小(≤0.14/槽)时差 <2pp 于玩具带(K≤3);**高密度 K≥4 同费被探针击穿:Poisson −2.6pp,越出 −2pp 下界(二项仍在带内,全探针 −1.19~+7.48pp)**——**二项优先;Poisson 下界放宽至 −3pp 或限定 K≤3,K≥4 同费禁 Poisson**;
4. **A3-A7 口径误差**(AI 耗池/破息/边买边刷/自适应停刷):方向逐条已知(见假设表),A3/A5/A6 乐观、A7 保守,无界但业务带宽内小。**未入账的保守向偏差源**:买牌送 XP 抵扣升级成本(0-100%×单级成本)、投资策略收益、卖卡收入——三者都使真实预算高于 B,概率被低估;净偏差「乐观主导」不应误读为双侧界**。

**总评**:闭式 ≈ 精确 **−2 ~ +8pp**(二项口径,乐观主导,典型 +1~3pp;Poisson 高密度下界放宽至 −3pp;独立性误差反向时压力形态可微幅保守;两端**渐近**收敛——N=50 仍 +2.1pp,带内),单调性按构造保持——证据门「过阈值」用途合格;**阈值边际须 ≥ 实测最大乐观偏差(≥8-10pp;单卡 need=3 中段场景类(最大偏差带)建议直接走 DP)**。

## sim 对拍清单(模拟器应对比的频率/分位)

1. **单件到达率**:给定 (L, Q_k, n_k, N),件 k 的集齐频率 vs Tail_k(逐 L∈{6,8,9,10} × 费档∈{2,3,4,5} 网格)——校准①③层;
2. **联合集齐率**:K=2-4 件(含同费竞争对)的联合完成频率 vs 精确 DP 与闭式 P̂ 的**相对偏差**——校准②层独立性误差(**玩具带 ≤0.5pp / 高密度带 ≤1.5pp**,统一偏差口径);
3. **完成回合分位数**:集齐时刻分布的 p25/p50/p75 vs DP 的逐轮累积分布(不只对拍终值,对拍时序——证据门的 T 是变量);
4. **预算敏感性曲线**:P̂(G) 对 G 扫 20→120 的单调性与 sim 频率同向(sim 任何非单调点 = 模型 or sim 实现bug);
5. **衰减重尾**:含 n_k=9 单卡件的用例,闭式乐观偏差是否落在 +8pp 带内(超带 = 衰减建模必须升级);
6. **轮岗(ROTATION_CHANCE=0.2)混杂**:sim 开轮岗后重对拍——闭式若不感知轮岗应系统性偏低(轮岗抬高被翻倍档的 q),偏差量 = 该档件专属修正项的标定输入。
