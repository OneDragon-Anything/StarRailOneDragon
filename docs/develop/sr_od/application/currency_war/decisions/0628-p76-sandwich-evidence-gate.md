# ADR-0628: P76 锁线夹界证据门落码(T-124;§5.5 夹界判据替换序数门+no_budget 预算解耦)

- **Status**: 已实施(规约态语义修正,零生产行为变化;落地审由编排者另派,commit 候编排者统一门)
- **命题**: math_proofs **P76**(锁线时机期权定价,已证·阅读门已收口)§5.5 落码含义三条 + §4.4 可计算夹界(落码形态)+ §7 #1 fail-closed 纪律
- **关联**: ADR-0627(锁线转型域收窄,shop 侧买面,与本件零文件交集)、ADR-0585(卖出仲裁,零消费关系)、`strategy-docs/12_line_and_intention.md` §1(证据门设计层,阈值臂指针行)、任务卡 = 进度账本 T-124 行(编排者四问裁决 2026-09-10:Q1 夹界结构+【拟】槽位封印/Q2 A/B 移交接线批/Q3 本批不接线/Q4 判据正本=P76)

## 1. 背景与归层

evidence_gate(`strategies/impl/mandate_v1/proof.py`)为 P76 §0.1 所指「序数证据门」:`pc > 0` 即过门、`refresh_budget ≤ 0` 一票否决(`no_budget`)。P76 戊.2 定位其双域偏差:域 α(金低/席空/板弱/侧线无进展)`no_budget` 门闭系统性偏晚锁(§5.2),域 β(溢余/有空槽/侧线有进展)序数门 θ_c→0⁺ 系统性偏早锁(§5.3)。归层 = 决策层·线选择判据(规约态);**该门全仓零调用点**(P76 修正 5:未接线,封印语义属 `should_switch` 的 θ/U_X/V_MS 前置),本批落码不改任何生产行为。

## 2. 落码形态(三义,与裁决逐条对应)

1. **夹界替换序数**(§5.5.3):`evidence_gate` 判定改为 P76 §4.4 可计算夹界——θ̂_suff = clamp(E[P′] + (O⁺+F⁺+B⁺−C−D)/Δ + ε₂, 0, 1)(右侧全上界,P ≥ θ̂_suff ⇒ 锁不劣);θ̂_nec = clamp(E[P′] − (C+D)/Δ, 0, 1)(右侧下界 O=F=B=0,P < θ̂_nec ⇒ 锁劣);两截断之间 = 夹界未决 ⇒ 不过门(维持现状)。suff 截断前原始值 >1 ⇒ A-丁.2 病态域(夹界空)出口 = 不进单线锁判定,独立分键 `sandwich_pathological`;闭式解 <0(域 α 深处)⇒ 截 0 无条件锁(戊.2「应最早锁」的结构涌现)。
2. **no_budget 预算解耦**(§5.5.2):`refresh_budget ≤ 0` 否决分支删除,预算仅作 `p_complete` 试验数条件——零预算帧与其它帧同走夹界评估,预算的影响流经不等式而非特权否决。
3. **【拟】槽位封印**(§7 #1「θ* 点值与数值门禁消费」):Δ=V_C−V_F 与 ε₂(集中度二阶带,§4.4「并入夹界余量」的落码归宿)入 `audit/provisional` 新槽位 `V_C_MINUS_V_F`/`E2_CONCENTRATION_BAND`,缺省 None;None 或帧项(`LockSandwichFrame` 的 E[P′]/O⁺/F⁺/B⁺/C/D,接线批装配)任一缺 ⇒ 门输出「不可评」+成因分键(`sandwich_unavailable[...]`,仿 theta_unavailable 归因可辨纪律,绝不向骨架层渗漏为否决——NMF §5.3)。丁.4 引理域 V_C>V_F:Δ≤0 系域外输入,同归不可评。C 项载体字段 docstring 钉差分口径 H_{−*}(修正 4)。
