## 机制(怎么 work)

绯英每释放一次大招,**永久获得 2% 伤害增幅**(无限成长)。开大频繁且是二段大招;配**永动机**(每开 3 大招赠 2 大招)+ **火力风暴潮**,高速叠加全局伤害增幅 + 前台强度。

绯英 = CW 后期速度能力最强,尤其擅长**第三位面遭遇四核❓关底 0T 攻坚**;但**前中期扛打❓差,前后期强度差距极大**。绯英是欢愉体系「双鞋爻光 + 风暴潮」的最佳驾驶员 → 有限行动值内叠最多风暴潮乘数 + 最高总伤。

## ★爻光必须永远放后台(debunk 前台爻光)

UP 反向论证「爻光为什么不该放前排」:

- **前台理由 1「提供大量欢愉倍率拐」= 文字游戏**:爻光技能主语是「爻光的耗火当赏❓」→ 吃的是**爻光(远低于绯英)的面板**,换算成吃绯英倍率 **<20% = 残血阴哥版倍率**,且对 5 目标一次只触发一次。实战:风暴潮叠到 10 几层、绯英一大几个亿时,爻光欢愉倍率触发一次只打 **不到 1000 万**(微乎其微)。
- **后台爻光(不带鞋)** 也能 2 星 250% / 3 星 300% 速度跑条 → 给前台**多开 50 个大招** → 触发阿哈❓多打的欢愉技 + 给绯英充大 → **这些才是实打实的满血欢愉倍率** + 叠风暴潮乘区。后台爻光才是绯英最需要的「变相倍率拐」。
- **前台理由 2「欢愉度供养队友」**:3 星小爻光前台只比后台多 ~10% 欢愉度;试用无专武 / 没到 3 星提升更低(后台爻光自带巨额欢愉度提升作补偿)。
- **实测结论**:无论爻光有无鞋 / 装备 / 命座 / 专武 / 带不带花火,无论前中后期 / 前台位置够不够 —— **后台爻光在有限行动内总伤更高**。前台爻光不提高总伤(仅伤害溢出时省点时间)。

## 开局 / debuff 禁忌

- 避开:**能量逃逸 / 时间刺客❓ / 正当防卫 / 忍无可忍 / 战个痛快**(对输出 / 生存 / 能量循环影响大)。
- **局内投资全选装备类**(绯英装备需求大);没装备类投资 → 直接重开。

## ★装备优先级

1. **先给绯英满 3 件:2 火力风暴潮 + 1 永动机**。
2. **大后期**:拆绯英永动机 → 做**冷笑话引擎**;永动机给「装备已满的爻光」(永动机前期给绯英叠层❓,后期爻光用 → 绯英叠满伤害增幅后还能有高暴击率,砍 boss 极疼)。
3. 之后做**藿藿生存装** → 再给**爻光鞋**提上限(爻光没鞋也能靠星期日给后台 1 号位充能 + 藿藿后台充能开稳定大招)。
- **阿哈装备优先级低**:只看阿哈第 1 件;除非第 2 件有用才考虑幻影星辉解锁,否则不把幻影羁绊开到 4/5。阿哈优先**暴击装(暴击刀 / 暴击枪 / 信誉之启❓)**,**不做风暴潮**(3 欢愉阿哈叠风暴潮远没绯英快)。

## 成型阵容(9 人口)

- 前台:绯英(风暴潮 + 永动机 + 冷笑话)+ 杨叔(瓦尔特,后期推条叠层必备)
- 后台:**爻光(鞋,召阿哈)+ 阿哈(风暴潮)+ 花火 / 符玄 / 千冶·刃(开 2 量子 + 2 减益)**
- 羁绊:**3 欢愉 + 3 能量 + 2 量子 + 2 减益**

## ★中期运营(6 人口完整体是关键)

(和灵砂那期几乎一样)第一位面 **3 仙舟❓ + 2 DOT** 过渡 → 1-9 变阵 **D 出 2 星主 C + 6 人口完整体**。6 人口阵容强度决定二位面有无时间给主 C 慢慢 D 到 3 星。

**6 人口阵容**:前台 绯英 + 藿藿 + 缇宝 + 星期日;后台 爻光 + 花火。
- 唯一需自备的是**缇宝**(必带**风扇 + 翁瓦克 + 速度鞋 + 充能绳❓**:绯英对军频率高 + 星期日 / 藿藿给缇宝频繁充能 → 翁瓦克频繁释放)。
- **星期日全程拉条藿藿(不拉绯英)**:星期日战技给被拉条角色增伤,换角色不吃增伤;拉藿藿加速充能循环收益更高。
- **爻光必须后台**吃星期日大招给后台 1 号位充能 → 全队享受藿藿 + 星期日巨额回能。
- 全员猛开战技 → 带**花火**补战技点;花火 + 爻光开 **2 战技点**给爻光 24% 速度增幅。
- 抽了狼尊可上狼尊换星期日(更轻松,但中期变狼尊护航,亏少量叠层❓)。
- 藿藿放 2 号位(星期日战技❓拉条绯英,藿藿 2 号位拖动距离更短,手操更巧❓)。

⚠️ **绯英中期强度确实差**,细节到位也常稳不住连胜。**只有绯英追 3 星**,其他追 3 浪费钱 → 3 星绯英更晚出;**星期日连 2 星都别升**(几乎零提升,浪费钱)。

## D 牌 / 上 9

- 二位面 D 牌:**2 费卡把备战席卡满 → 卡 50 金慢 D**。爻光牌顺可顺手看能否 3 星(6 级 1 费❓概率大)但**别贪**;有投影仪❓别想两个都 3,**绯英能 3 时立马用掉** → 早 3 星早上 9 找杨叔 = 可挂自动。
- 6 级二位面连胜条件:**绯英 2 件装备 + 至少 1 风暴潮** → 打到二位面 boss 没问题。
- 3 星绯英后全力拉人口速 9 找**杨叔**。7/8 人口优先上欢愉组❓ + 符玄;没有就上佩拉。第三位面上九过程中给爻光找鞋 + 给藿藿找生存装。

## 杨叔来了 = 大成

杨叔来了 → 遭遇骑士**只有生存压力无输出压力**(活得下来就打得过 + 溢出大量行动值;杨叔也大幅提生存)。杨叔来后**不开 3 能量了** → **下星期日,后台补佩拉**,减防往满堆,开 **2 减益 → 9% 免伤 + 30% 真伤** = 大成。

## 转值 / 技巧

- 有转 + 绯英做能量化引擎❓ → **旅人转**。**别开群攻转**(绯英是弹射,弹到群攻球亏伤害)。**别做能量转**(格子宝贵,不如风暴潮 / 永动机 / 能量化引擎)。
- 9 级可捏 1 只**希儿** → 3-6 奖励关上去等 3-7 刷**死士❓(诗篇)**。★技巧:刷出希儿死士时**先放希儿 → 买死士再放 → 继续刷** → 原本每节点只能拿 1 次的死士**可无限刷**,拿 2-3 个有效死士体能❓很大;运气好刷到**星徽+1❓ / 特权附忆卡❓** = 起飞。
