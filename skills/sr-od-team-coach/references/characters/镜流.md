# 镜流（冰·毁灭·5星）

> 按 V4.7 期撰写。转魄烧队友血换攻击的冰爆主C。

## 一、命途属性与技能说明

**命途**：毁灭；**属性**：冰

| 技能 | 说明 |
|---|---|
| 普攻 | 单体冰伤 |
| 战技 | 单体冰伤（+1朔望） |
| 强化战技「寒川映月」 | 转魄期间唯一可用：扩散高倍率冰伤 |
| 终结技 | 消耗能量；扩散180%/90% +1朔望 |
| 天赋【转魄】 | 2层朔望进入：行动提前100%+暴击率+40%+战技强化；**攻击时消耗队友4%生命上限 → 按消耗总量540%提高攻击（上限=基础攻击90%）**【官】——队友生命池是她的攻击面板；层数归零退出 |
| 秘技 | 进战回能（以文本为准） |

**资源与循环**：标准能量→充能有效。烧队友血与遐蝶新蕊/万敌充能同族——**掉血即增益**。

## 二、推荐遗器与原因

**套装**：密林卧雪的猎人4件 + 不老者的仙舟2件【攻：经典口径】
- 猎人4：冰伤系；仙舟2：≥120速攻击增益

**主词条**：躯干**暴击伤害**（转魄暴击+40% 自给）；脚部速度；球冰伤；绳充能。
**副词条**：暴伤 > 攻击% > 速度。
**转模与转化上限**：转魄烧血→攻击（540%系数，上限基础攻击90%）——**队友生命上限是事实面板**（练度评价需看全队）。
