## 命题

> **P34-a(牺牲分支)**:变宝为废在场、且同一帧内同时存在高价值合成对与牺牲合成对时,
> 「先牺牲后高价值」的合成序期望严格大于「高价值先行」,期望差 = 0.5·(V_h − V_s) ≥ 0;
> V_h > V_s 由牺牲对判据构造性保证(产物 ∉ key_equips),故恒优。
>
> **P34-b(推迟分支)**:无牺牲对、推迟一帧等牺牲对到场的期望
> E_defer ≈ q·0.5·(V_h − V_s) − c_frame,推迟优于立即合成当且仅当
> c_frame < q·0.5·(V_h − V_s);**q 已得 plaza 先验 ≈0.15(95% 区间 [0.08, 0.30],
> 见文末),c_frame 仍无直接标定**——判据数值化为 c_frame ≲ 0.5·q·(V_h−V_s)

| c_frame | 高价值合成推迟一帧的期望成本(战力延迟 + 组件变动风险) | **未标定(P34-b 剩余卡点)** |

**垃圾化落点规则确认(读游戏文本)**:原文「首次合成的**进阶装备**会有50%的概率变成垃圾袋」
——承担风险的对象是「首个被合成的进阶装备」这一**物品**,不是某个预定槽位。因此:

1. 垃圾化风险落在**先合成的那个**产物上——牺牲合成先行时,风险落在牺牲产物(V_s 侧),
   不落在高价值产物上。⇒ 牺牲件同为进阶件、同样承担 50% 风险,期望模型如实建模(见下)。
2. 「每个位面开始时…首次」的**消耗语义**(每位面仅一次判定,后续合成安全)是推读条目
   (变宝为废-首次合成垃圾化.md 已如此标注,采纳);非逐字。本文对两种读法
   都给结论(鲁棒性,见「读法敏感性」)。

## P34-a 推导(牺牲分支,零自由参数)

**同一动作集对比**(两分支都合成这两对,只差顺序;这是保守口径——不做牺牲合成的变体只会
让先行更优,见注 2):

**分支 A(高价值先行)**:高价值合成是该位面首次合成 → 承担 p=0.5 垃圾化:

```
EV_A = p·(b) + (1−p)·V_h   +   V_s          = 0.5·V_h + 0.5·b + V_s
       └ 首个产物,50% 变袋 ┘    └ 牺牲对后合成,已非「首次」,安全 ┘
```

**分支 B(牺牲先行)**:牺牲合成先消耗首次判定,高价值合成安全:

```
EV_B = p·(b) + (1−p)·V_s   +   V_h          = 0.5·V_s + 0.5·b + V_h
       └ 风险落在牺牲件上 ┘     └ 高价值已非「首次」┘
```

**期望差**:

```
EV_B − EV_A = 0.5·V_h − 0.5·V_s = 0.5·(V_h − V_s)
```

垃圾袋残值 b 两侧各出现一次(概率同为 0.5),**精确相消**——结论对 b 的任何取值
(含 b=0)不变。

### 数字表(示意量级,V 单位=金当量)

| 场景 | V_h | V_s | b | EV_A | EV_B | 差 0.5(V_h−V_s) |
|---|---|---|---|---|---|---|
| 保守:V_h 取散件升星级 | 10 | 4 | 1 | 10.5 | 13.0 | +3.0 |
| 中位:V_h 取激活级(P20 边际) | 25 | 4 | 1 | 17.5 | 27.5 | +10.5 |
| 激进:V_s≈b(产物近零值) | 25 | 0 | 1 | 13.5 | 25.5 | +12.5 |

(V_h/V_s 只为展示量级敏感度,**不进入证明**——证明只用 V_h > V_s 的序关系。)

### 成立条件与边界

1. **V_h > V_s 恒成立**:由牺牲对判据构造保证(`find_sacrifice_pair`:两件均 ∈
   recycle_qualified 且穿者非 core,产物必然 ∉ key_equips——P14 定理 3)。
   故 **EV_B − EV_A > 0 恒真,无参数条件**。
2. 辖域门:同一帧内既有高价值合成又有牺牲对可用(实现里 `sacrifice_first` 动作域);
   无高价值合成时牺牲无意义(`no_high_value`,与证明前提一致)。
3. 合成操作本身零金成本(拖拽合成,组件已持有),无额外成本项。

### 读法敏感性(消耗语义是推读,非逐字)

- **若消耗语义成立**(主流读法):如上,EV 差 = 0.5(V_h−V_s) > 0,牺牲先行严格优。
- **若每次合成各自独立 50%**(最保守反读法):两分支期望完全相等(顺序不改变风险分布),
  牺牲先行**不劣**——代价只是把风险从贵件挪到便宜件的期权作废。
- **两种读法下牺牲先行都不劣,主流读法下严格优** ⇒ 策略对规则解读误差鲁棒。

### 注

1. b 的取值:垃圾袋为固定物品(cw_equipment_data「垃圾袋」6 项 3% 属性),不随被替换
   装备价值缩放——即便它按比例缩放,两侧同概率出现仍相消。
2. 变体(直接合成且**永不**做牺牲合成):EV_A' = 0.5·V_h + 0.5·b,此时 EV 差 =
   0.5(V_h + V_s) > EV 差主口径——保守口径已覆盖,先行只会更优。
3. 残余边界(kernel 模块头已记):排序器视野外的合成事件(C6 转移拖拽等)可能提前消耗
   位面判定——此时牺牲先行退化为无收益无害(风险已不在),不产生负收益。

## P34-b 推导(推迟分支,卡点声明)

无牺牲对时两种选择(位面首次判定尚未消耗):

```
立即合成:EV_now = 0.5·V_h + 0.5·b + (牺牲对日后到场时安全补得 V_s)
推迟一帧:E_defer = q·[V_h + 0.5·V_s + 0.5·b − c_frame] + (1−q)·[EV 同「立即」延后一轮]
```

一阶近似(推迟至多一帧,实现 `JUNK_FIRST_DEFER_BUDGET=1`;q 为一帧到场率):

```
E_defer − EV_now ≈ q·0.5·(V_h − V_s) − c_frame
```

**推迟优 ⇔ c_frame < q·0.5·(V_h−V_s)**。q 的 plaza 先验(文末):中心 0.15、区间
[0.08, 0.30]。代入数字表量级:保守 V_h−V_s=6 → 判据右端 ≈ 0.24~0.90 金当量;
中位 V_h−V_s=21 → ≈ 0.8~3.2 金当量。c_frame(一帧 key 装备战力延迟,Δp·L_c 口径,
P21/P23 同构)方向先验为亚金——**典型参数下推迟分支大概率优,但非恒优**:保守量级
(V_h 取散件升星级)且 c_frame 偏高时判据可翻转,故实现维持保守预算(推迟上限 1 帧)。

### q 的 plaza 先验(间接模型估计,非直接观测)

**估计口径**(与 P34-b 推导分支语义对齐):q = P(defer 决策帧后的一帧内,死库存中
出现回收合格牺牲对 | 该帧前无牺牲对)。结构事实(K8 闭合,`cw_synthesis` 派生):
8 件基础件两两皆成配方(28 交叉 + 8 自配),故「有牺牲对」⟺ 回收合格(RQ)死库存
多重集 ≥2 件;defer 帧无对 → 死库存 ∈ {0, 1} 件。发放流按 P14 λ 口径建模
(每帧 Poisson(λ) 均匀 8 件池);方向分布 = plaza 29 个实战聚类(`cw_plaza_comps`,
Σn_posts=997)按帖数加权,逐帖频次抽 3 件进阶作中局 key 集 → r = |RQ|/8
(实测分布 mean 0.63,[p10 0.50, p90 0.75])。一帧成对概率闭式
q = π1·P(Poi(λr)≥1) + (1−π1)·P(Poi(λr)≥2),对消费策略(成对即牺牲合成消费)
稳态 π1 = 1/2。

**结果**:q 点估计 **0.154**(MC n=1160 个 key 集抽样,Wilson 95% CI
[0.135, 0.176]);**总区间 [0.08, 0.30]** 由 λ 敏感性主导(λ=0.25 → 0.078,
λ=1.0 → 0.297;λ 本身是 P14 粗估),π1∈[0.3,0.7] 再贡献 ±0.05。

**语义一致性核对**:①推导分支的 q 是「一帧内牺牲对到场」的条件概率,与口径一致;
②口径把牺牲对局限在 RQ 死库存(owned 件),实现 `find_sacrifice_pair` 还计入非 core
角色的已穿 RQ 基础件——该侧忽略使估计略偏保守下界;③回收流水线(2合1)会消耗
RQ 单件、压低死库存,使估计略偏乐观上界;④中局 key 集为 Final 套装子集、实际
|RQ| 偏大 → q 偏保守下界侧。三偏置两下一上,区间 [0.08, 0.30] 视为覆盖性区间。

**边界**:λ 未按持牌加权、8 件池均匀性(电池在池)未实测——两者与 P14 共享,
P14 标定后本先验应重算;本先验只支撑「判据量级」结论,直接标定(sim 逐帧 owned
流水)可替换之。

c_frame 直接标定(sim A/B)后本命题升级为全参数已证(q 先验支撑量级判断,非精确
证明);在此之前实现侧保守预算(推迟上限 1 帧)维持现状。
