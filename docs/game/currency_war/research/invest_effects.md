# 投资策略/环境效果全量分类(335 策略 + 83 环境)

> **性质**:对全部投资卡效果的**建模分类知识**——哪类效果可进经济模型、哪类属战力侧/资产侧不进、每张卡的文本数值边界在哪。逐条基于官方效果原文(`cw_invest_data` 注册表,plaza API V4.4),不猜数值。
> 裁定历史见 ADR-0205(落地+纠错)、ADR-0211(砂金流不采纳);**API 裁定**(官方 API 条目只有 id/name/desc/icon/quality 五字段,desc 没写明的数值一律放弃建模,不实机查)见 §5。
> 版本基准:V4.4。

### 0.1 Fate(圣杯)任务链原文细节

**2026-08-24 从 git 历史补记;攻略存档(sources/V4.4_阵容_命运圣杯红A)已删[eb9c72a1],此为仅存记录;信源=过期攻略存档(版本 V4.4,已被 V4.4 实测部分推翻),与官方 API 深读结论分立,勿混写**:

- **触发结构**:任务在 Fate 羁绊展开 **2F/3F/4F/5F 时各触发一次二选一接取**;难度分红(难)/蓝(易),羁绊等级越高越难 + 奖励越好(5F 有概率刷 8 个完美投影仪 +「实现所有愿望的圣杯」)。难度表:2F=2 蓝;3F=2 蓝 或 蓝+红;4F=蓝+红 或 红+红;5F=必红+红。
- **★激活等级门槛**:3F 接的任务至少开 3F 羁绊才算进度,5F 至少开 5F;未激活 → 面板显示「未激活」,做任务全部不算数——**花资源做任务前必确认激活状态**。
- **高难任务样本**:鲜血神殿(后两场战斗额外 -20 小队生命;未激活则每节点固定 -20 + 致命,即使断连胜也应优先处理);5F 令咒协议(凛在场 → 立刻损失 88 小队生命 + 所有金币,换 8 个持续 1 节点的完美投影仪;血 <88 不能接,且当关用完);愿望圣杯(最高奖励,无需做任务,直接完成此前所有 F 任务 + 合成所有 3 星 F 角色 + 圣杯装备进阶版 + 1 个改件);诅咒圣杯(赠全队 50% 暴击 + 100% 暴伤,但清除此前所有 F 任务并替换为诅咒装备任务,「3-4 之后无论如何不要接」)。
- **经济定位**:即使不奔任务去,遇 F 角色顺路买下开任务看奖励(部分直接给且丰厚);圣杯改件(如阿瓦隆)不一定给 Fate 角色,可给任何能量组 C。

## 1. A 类:金/XP 流(按建模难度分批)

### 批 1 等级触发日程(结构最简)
- **成长基金**(银):到 9 级 +40 金 → `calendar_at_level(9)`;9 级是终局等级,收益按残值权重折现。
- **成长的快乐**(银):8 级后购经验单击 −1 金 + 立刻 4XP → 条件突变(状态含等级,DP 可表达)。

### 批 2 时点日程
- **超发货币**(金):失去所有金,5 节点后获「该数+70」→ 负债日程;风险 = 窗口期金为 0 无息,DP 可算精确分界。
- **人才激励/+**(银):投影仪发放(资产类,无数值,§5 裁定放弃)。
- **恢复生机**(银):终 boss 后回 40 血 → 仅影响积分不影响胜率,不建模。
- **偶像经济**(棱):礼盒内容无数值(放弃)。

### 批 3 动态依赖收入(最有建模价值)
- **被动收入**(棱):每节点 XP = 备战席最左角色基础费用 → 板面决策与 XP 流耦合(高费卡放最左)。
- **狸财经狸**(棱):30 本金/每回合息+2/金<20 取 10/P3 首领取全部存款——desc 四数值全明,可建模。
- **星际和平保险**(棱):立刻获 = 已损血数的金 + 战后回 10 血 → 血金互兑。
- **不等价交换**(棱):交换小队生命值和金币 → 血金互兑(λ_hp 定价框架用例;交换后保守 clip)。

### 批 4 行为条件流
- **存款回报**(银):上节点没花钱 → 2 免费刷(期权成本进每回合决策)。
- **招财狗**(银):胜利且无损 → 每佩佩 +1 金(微量,pick_value 层面)。
- **星星相印**(银):每合 3星 +5 金(一局 1-3 次 ≈ 5-15 金)。
- **气氛组/+**(银):战斗后每 2 个零伤角色 +1XP(+即时 8XP)。

### 批 5 期权类(额外选卡权,6 条)
- **黄金/彩虹期货/+**、**白银/黄金投资**:N 节点后(或立刻+延迟)一次不可刷新三选一 → `期权价值 = f(品质池分布, 剩余节点, 已持效果)`。
- **策略大师**(环境):每获策略 +2×已持有数金(累计 ~2n²,n≈6-8 → 40-70 金,被低估的环境)。
- **联席决策**(环境):2-6 节点额外一次策略三选一(位置固定 → 日程确定)。

### 批 6 XP 直给类
经验到账(+10)、孪生素数(首购各费 2/3/5/7/11 XP,一局上限 38)、固定理财/+(位面开始 4/6XP+2/3 刷)。

## 2. B 类:机制突变

- **奋斗协议**(棱):购经验花 6 血非金 + 首领战结束回 50 血 → 成本币种切换(h 转移替代 g)。
- **概率事件**(棱):刷新 45% 概率免费 → 期望刷价 1.1。
- **市场干预**(银):下一次和每 4 刷全 3 费面(与采购专员同构,已有字段)。
- **轮岗**(环境):每备战期一随机费用概率 ×2 → 期望意义有限,信息价值在观测到当期费用后。
- **经济过热/经济严重过热(环境,2026-08-26 补录;断链修复)**:本局**全部奖励节点替换为(超级)次元扑满**——奖励型战斗节点:有战力要求要打、不掉血(扑满关自身机制)、真损失=打不过没奖励;应对=轻投入凑羁绊刷伤害(支出上限 s≤0.277R,采前 ≈2金/节点,math_proofs P8),禁深花保血;bot 侧=ADR-0348(识别按战斗/授权低危)。曾为分类缺口(335 策略+83 环境零记载),本条补齐。
- **晋升名额**(变费三家族之一,2026-08-26 补录):买经验时随机一槽卡变高 1 费(不可控)——变费全集另两家=飞光·映月(镜流星级驱动,确定性)/银狼固有技能(角色侧非策略);建模口径详 economy §2.1「变费全集」。
- 市场活力/人才下沉/概念股 ×15 概率数值:文本无数值(§5 裁定放弃 odds 建模;概念股的价值主体「阵营刷新率↑」留在选卡分)。

## 3. C 类:难度交互

- **简单模式**(银):敌难度 −3(下限 0);**难度修改器**(银):遭遇+首领节点 −4;**退化**(银):最右词缀失效+难度 −5、+8 金。
- **二极管**(银):遭遇只有最低最高两档(+10 血上限+6 金)→ **难度结构改形**(候选空间改写)。
- **伟大征服**(金):连胜金 ×3 + **敌人难度 +N(=连胜数)** + 12XP(难度耦合勿漏)。
- **远见**(金):随机金策略+15 金 + **后续策略节点→随机棱彩(不可刷新)且不增加难度**(品质豁免)。
- **头彩/尾彩、黄金/彩虹时代、银·金·彩**(环境):品质分布日程/全局变化(品质→难度通胀公式无本地记载,§5)。

## 4. D 类:形态约束(挂板面/部署侧)

节省工位(3 节点仅 3 备战位)、人才空洞/济济(bench≤4/≥8 每节点 +3XP)、多元化团队(羁绊封顶 4 人口)、完美开局(进度<40% 强度,战力侧)、规模效应(8 同名→完美投影仪)、人海战术(在场>8 强度)。
**槽位布局约束(2026-08-26 补录,断链修复)**:存在把后台槽位 6→7 的投资环境(2026-08-09 实测+用户确认;候选 8/9/10 上限待图鉴)——槽位数是**环境依赖变量**非常量;详 gameplay「备战棋盘槽位」节,部署侧建模(`max_units` 族)消费。曾为 D 类缺条(只在 gameplay 有载)。

## 5. API 裁定落定(可建模边界)

官方 API `fight_augment_list`/`portal_list` 条目仅 `id/name/desc/icon/quality`,无结构化数值字段。据此:

| 项 | 裁定 | 依据 |
|---|---|---|
| 狸财经狸息机制 | ✅ 可建模 | desc 四数值全明 |
| 品质→难度通胀公式 | ❌ 放弃 | API 无记载(仅白银时代文本侧面证实机制存在) |
| 市场活力/人才下沉/概念股概率数值 | ❌ 放弃 odds 建模 | 文本无数值;保留 pick_value 选卡分 |
| 偶像经济礼盒内容 / 员工投影仪角色分布 | ❌ 放弃 | 文本无数字 |
| 不等价交换 hp 截断细节 | 按字面 swap,保守 clip | 文本只有「交换」 |

**API 顺带发现**:`equipment_list`(101 条)带结构化 `compose_list` 合成图与 `priority`/`category`——装备合成的权威源候选(优于手维护);`trait_info_list` 的 `layers` 字段为空,羁绊阈值仍以 `cw_factions` 为准。
