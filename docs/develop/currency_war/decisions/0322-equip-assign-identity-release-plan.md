# ADR-0322: equip_assign 恒等约束的拆分批放开计划

- 状态:accepted(计划型 ADR——立框架防届时裸拆,放开动作本身归未来拆分批)
- 日期:2026-08-25
- 背靠:W55 R2 数据修正批 §4-3 提案(报告指针:
  `.debug/temp/currency_war/cw_dev/deep_read/W55_报告.md` §1「到人矛盾
  4 处」+ §4-3);R2 审查 §6「恒等绿无法暴露到人错配」判断;C5 契约
  (A/B 兼容)与 ADR-0309(line_v2 回退开关及删除门槛)。
- 落点:计划对象 = `cw_comps.py`(`Comp.key_equips`/`derive_key_equips`)
  + 恒等测试 `test_derive_key_equips_identity_all_comps`(其 docstring
  已被 W55 预埋改写声明)。

## 背景与动机

C5 兼容恒等(`comp.key_equips == derive_key_equips(comp)`,多重集恒等,
恒等测试锁)是 v2 教义迁移的**过渡地基**:W25 落 COMP_LIBRARY v2 时,
`equip_assign`(到人粒度,角色→装备序列)与旧平铺 `key_equips`(线级
命脉件表)并存,恒等保证两口径零漂移。

代价:恒等**锁死了真·教义到人**——v2 教义里「到人且带数量」的条目
进不来:

- 姬子:以牙还牙甲 **×2-3**(数量维度恒等装不下);
- 全队皮靴类(多角色同件,平铺表是去重集合语义);
- W55 四处置换(三月七甲→外骨骼/银狼电锯→皮靴/Archer/闪闪)全是
  「教义件 ↔ 旧平铺残件」的**等量重排**——修的是哪件进表给谁,
  **零新增教义信息**(R2 §6 判断,W55 §4-3 自认)。

即:只要恒等在,equip_assign 的每次「修正」都只是搬运,教义到人粒度
被结构性封顶。

## 决策

**放开时点 = A/B 流建条时点**(comp_definitions_v2 的 A/B 分支拆分批):
恒等约束在单条 Comp 内无法表达分支差异(同一套在不同分支下到人不同),
A/B 拆分必然要动 equip_assign 结构——放开与拆分**同批**做,避免两次
结构变更;在此之前恒等继续冻结(C5 地位不变,W55 式等量置换仍是唯一
合法修正法)。

**放开步骤**(拆分批内序):

1. **`key_equips` 语义降级为参考集**:字段保留,消费定位=「线级命脉件
   参考名单」(补给/宝箱选卡的命脉分、合成材料两跳这类**不需要到人**
   的消费面继续用);`derive_key_equips` **函数不删**——继续为参考集
   供值 + 作对拍锚(见风险)。
2. **`equip_assign` 成为唯一到人源**:穿戴分配(equip_fit/
   equip_allocation)、cw_intention.equip_targets 的到人语义全部改读
   equip_assign;数量维度(×2-3)与多角色同件在此表达。
3. **恒等测试改写为「到人对拍 v2 教义」**:兑现 W55 已预埋的 docstring
   声明(`test_derive_key_equips_identity_all_comps` docstring:「本测试
   锁的是 C5 兼容不变量而非 C4 到人语义……A/B 拆分批放开恒等时须改写
   为『到人对拍 v2 教义』方向」)——改写后的锁:每套 comp 的
   equip_assign 逐条对拍 comp_definitions_v2 教义原文(件名+到人+数量),
   与 W55 新增的 `test_equip_assign_doctrine_v2`(四套到人教义锚)同族
   扩面;恒等断言本身删除或降级为「参考集 ⊇ equip_assign 派生集合」的
   松弛对拍(允许参考集缺数量维)。

**风险与对策**:

- **line_v2 兼容臂的消费**:line_v2(ADR-0309 回退开关)在删除门槛
  (sim A/B 验收通过)之前仍消费 `key_equips`——放开时若 line_v2 未删,
  参考集降级**不删字段不删函数**正是对策:line_v2 继续读
  `derive_key_equips` 派生值,行为零变化(它从来到人粒度就靠
  equip_allocation 兜底);若拆分批时 line_v2 已过删除门槛,随删。
- **到人错配失去恒等护栏**:恒等绿曾无法暴露到人错配(R2 §6),但至少
  锁住两源不漂——放开后唯一防线=教义对拍测试,故步骤 3 的测试改写
  **必须在同批内先于/同步于数据放开**,禁止「先放数据后补测试」。
- **回滚**:参考集降级是语义定位变化,字段与函数都在——回滚=恢复恒等
  断言 + equip_assign 回等量口径(一次数据批可回)。

## Considered Options

- **恒等永久保持(教义到人就此封顶)**——被否:到人是 v2 教义的核心
  粒度(点8「装备配方到人,取代按线映射」),恒等=教义永远只能等量
  置换进表,C4 到人语义名存实亡。
- **立即放开(W55 后下一批就拆)**——被否:A/B 流未建条,单条 Comp 内
  分支差异无处安放,放开后还是要二次结构变更;且 W50/W51 在飞期
  cw_comps 面 reforms 的合并冲突面大。
- **维持 W55 式等量置换滚动(不立计划)**——被否:零新增教义信息的
  搬运做多少次都到不了真教义(W55 四处置换实证);且无计划 = 拆分批
  到时裸拆,恒等测试与 line_v2 消费面都无预案。
- **A/B 拆分批同步放开(选中)**:结构变更一次到位,测试改写与数据
  放大同批,回滚路径明确。

## 影响

- 本 ADR 为计划型:现批零代码变化;W55 四处置换与恒等测试 docstring
  预埋合规(它们正是本计划的执行前态)。
- 未来拆分批(A/B 流建条)的任务书应引本 ADR 的三步骤与风险节;
  INDEX 关联:0309(line_v2 删除门槛)、W55(等量置换期)。
