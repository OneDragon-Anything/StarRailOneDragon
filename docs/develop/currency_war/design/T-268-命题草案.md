## 1. 设定

部署拖拽 g 在时刻 t 将单位 u 落至板面槽 s(游戏真值 `L ∈ {0,1}`,L=1=实际落位)。验证窗 `W = [t, t+2s]`。判据源三个:

- **像素谓词** `P(s,W)`:W 内存在帧使 s 的判定区呈现单位卡像素签名(`slot_occupied`,现行唯一判据);
- **遮蔽谓词** `Occ(s,W)`:decision overlay O 在 W 全程覆盖 s 判定区。**实现探测=presence 近似**(注册表锚在场即判遮蔽;建档数据无 overlay 全幅 rect)——方向保守:把遮蔽域裁决扩到「overlay 在场但未盖该槽」的帧,该扩张无假成功面(遮蔽域裁决源=计数器/UNKNOWN,均可靠),rect 求交精确化留实施批候裁;
- **游戏计数器** `C`(paddle X/Y 直读,`read_deployed_count`):游戏侧权威板面计数。**同源前提(F-2)**:dc 的 before/after 必须同为 C 直读;入口仲裁值=min(paddle, CV) 含 CV 幻影占用面,禁作基线。

## 2. 命题(v3)

**(1) 遮蔽不可靠性引理(双向)**:`Occ(s,W)` 成立时,`P(s,W)` 与 `L` 独立(常数)。常数两方向都可偏:渲染空白 ⇒ 假阴(三例实测);渲染出卡面像 ⇒ 假阳。⇒ 遮蔽域内 P 对 L 无发言权(双向)。

**(2) 计数器引理(等式;双前提)**:取**窗界前提**(dc 测量窗=本拖拽验证窗,窗内本 op 不发卖出/合成/买牌;partner 处置不新增板面单位——机制已核)∧ **同源前提**(before/after 同为 C 直读)⇒ `dc = L`(等式)。推论:`(L=0, dc≥1)` 不可达。**可读性前提(F-1)**:dc 可计算还须 before/after 两端 C 均可读——partner 型遮蔽面板覆盖 C 读区,窗内恒不可得 ⇒ 该族 dc 恒 None ⇒ 走规则(4) UNKNOWN,改判路径对此族**不可达**(如实申报,非缺陷)。

**(3) 分域裁决规则 v4(实施口径;纯 UNKNOWN)**:
- 非遮蔽域:像素独裁(P 真⇒placed / P 假⇒invalid)——现行 1-1 防线语义逐点保留,零放宽;
- 遮蔽域:像素双向无投票权;**恒 UNKNOWN**(实现=STATUS_LANDING_VERDICT_UNKNOWN,槽位不回收、剩余单位留 bench、交 0 系 overlay 分支自愈;不消费计数器)。
- **辅助=计数器改判(v3 规则 3)——分析性存在、未实施**:模型层论证(`dc≥1 ⇒ placed`(引理 2);`dc=0 ⇒ invalid`;`dc<0 ⇒ invalid+分歧留证`)作为已否决备选保留于 §2 记录,不落实现;其可达输入域(非覆盖型遮蔽)实机零观测(R2 §2 证据核查)。

可靠性(实施口径):可达态全域内 placed ⇒ L=1(非遮蔽域由现行语义;遮蔽域恒 UNKNOWN 无 placed 支 ⇒ 假成功全域不可达——v3 §4 该声明在 v4 下内部一致成立)。遮蔽域完备性仅对「分析性改判支」在 v3 模型内成立,非实施承诺。

**(4) 不可作判据**:`Occ ∧ dc 不可得 ⇒ UNKNOWN`(与 L、渲染常数、失读发生在哪一端无关,可判定)——以具名状态上报,禁伪装成功,禁判「无效拖拽」。

## 4. 边界与失效条件(诚实申报)

- **驱动病灶的修复力口径(F-1)**:对 partner 覆盖型,修复力=「假失败 → 诚实 UNKNOWN+0a 自愈」(轮次代价与现状相当,消灭假失败遥测/槽位回收污染/盲拖),**不是**「改判成功」;
- **窗界前提可破面**:验证窗内并发其它入板通道则引理 2 前提破坏(分析性支内;实施口径 v4 遮蔽域不消费计数器,该面不存在);
- **同源前提可破面(F-2)**:基线若取 CV 仲裁值,入口 CV 幻影占用(卖出动画残影族)→ 基线虚高 → 真落地 ΔC=0 误判 invalid / ΔC<0 未定义分支——该面在 v3 模型层以「基线=入口 paddle 直读,失读即 UNKNOWN」钉死,v4 实施口径下遮蔽域不消费计数器,**基准源混用问题消失而非修补**(R2 裁决理由 2);
- **计数器误读代价不对称(分析性支内,未实施)**:误读偏高 → 假改判 → 单位留 bench 一轮(下轮 paddle 仲裁+对账纠漂自愈,二例 deployed_align 补齐实证后盾);失读 → UNKNOWN,不产生假成功;假成功(1-1 类)在实施口径 v4 全域不可达(遮蔽域恒 UNKNOWN 无 placed 支);
