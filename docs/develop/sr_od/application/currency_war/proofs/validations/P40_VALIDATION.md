## 2. 门①:内部推导(逐步核)

**命中率封闭形式**。q = Σ_c p_c·R_c/T_c,R_c=Σ_t(a−j_t)、T_c=v_c·a_c−Σj_t−c_taken 与 `cw_shop_odds._refresh_dist` 的 rem_target/rem_nontarget/total 定义逐项同构(单类退化情形 rem_target=a−j ✓)。两个方向性推论核对:

- 池衰减:g_c≪v_c 时 |ΔR/R|>|ΔT/T| → q 随持有单调降——代数成立(R 与 T 同减一个量,R 基数小,相对变化大);S2 算例即其数值形态(j=7 时剩余副本=2)。
- 压库背书:c_taken 只减 T 不减 R → q 单调升——成立;量级引 economy §3「买 30 张升约 1 个百分点」,与 1费池 ≈500+ 张的量级相符。

**数值复现(亲跑自检脚本)**:S1 P=0.1041/1/P=9.61/E(k=3,j=1)=19.15 次→38.3 金/V*=19.21 金;S2 P=0.0135/1/P=74.20/E(k=9,j=7)=219.8 次→440 金/V*=148.4 金;S2' j=0 P=0.0545;变体② V*=10.57;变体③ 命中率 0.0704→0.1369(×1.94);变体④ V*=74.2/E 刷费 220 金;S3 息档账四行全对——**证明 §③ 表值与脚本输出逐格一致,无抄错**。

**EV 口径切换的正确性**:单步 EV 用期望命中数 5q(线性,无需槽间独立)而 P(≥1) 只进停止语义——这个二分是本篇三轮共修后的形态,内部自洽(V* 表值按更保守的 P 口径,声明方向正确)。

**注记(不翻案)**:①「同档槽间无放回负关联抬高 P(≥1)→独立式低估」给了自引数(0.1039<0.1041)与 ≤0.2pp 量级,但未给一般性证明——按「落地一律走精确超几何」的使用声明,实务上无害;② §② 一致性段(启动门 vs 逐步门 = 不可分性风险溢价)是合理的经济学论证而非命题,证明文本未把它伪装成定理——诚实。
