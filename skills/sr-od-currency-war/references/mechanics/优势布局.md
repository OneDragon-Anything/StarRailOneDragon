# 机制：优势布局（局外成长系统）

> 优势布局 = 货币战争的局外成长系统：在大厅里用专用货币激活节点，为**后续对局**提供额外机制或角色增幅；单个对局内不消耗、不变化。
> 本文为**网络调研**结论（调研于 2026-11-18，v4.7 入画奇航赛季），逐条给出处；§2「1 血免死」定位**已实机核对回填**（同日大厅优势布局实读，节点细节见 `docs/game/screens/currency_war_advantage_layout.md`）。

## 1. 系统官方名称与构成

- 系统官方名「**优势布局**」。官方玩法说明原文：「激活『优势布局』，可为后续的对局提供额外机制，或增幅角色的战斗能力。每场对局结束后，将获得一定的『等价钻钞』，用于激活『优势布局』中的各项机制。」出处：<https://sr.mihoyo.com/news/160700>（S1 时期官方文案；英译对照 "Advantage Layout / Equivalent Banknote"，见 <https://www.reddit.com/r/HonkaiStarRail/comments/1on1iy7/currency_wars_gameplay_guide/>）
- v4.7 起分两区（官方赛季说明原文）：「**赛季优势布局**」——进度每赛季统一重置，用「**幻乐晶球**」激活各项效果；「**常驻优势布局**」——完整保留，此前解锁的节点不受影响。出处：<https://www.miyoushe.com/sr/article/79258376>
- 幻乐晶球为道具，图鉴描述「通过『货币战争』玩法获取，可用于激活【优势布局】」。出处：<https://wiki.biligame.com/sr/幻乐晶球>

## 2. 「1 血免死」类效果的定位

- **官方基础规则没有免死**：玩法说明原文「开拓者拥有初始小队生命值。在多个节点的战斗中，需要在有限行动值内消灭全部敌人，获得战斗胜利。若未在规定行动值前消灭所有敌人，则扣除一定生命值。**当生命值为 0 时，将结束对局**。」——小队生命值归零即对局结束，无保底。出处：<https://sr.mihoyo.com/news/160700>
- 早期本机实测过「生命值首次归零会保底回 1 点、第二次归零才对局结束」（gameplay-basics §1），但**近期连续三局 HP 均直接归零终局、该现象未复现**（实测）——口径来源待核对：若保底存在，对应本档「保险机制」节点的激活效果（相关实测局该节点均处锁定未激活态，与「未复现」吻合；早期实测局当时的节点激活态无法回溯；大厅核对已完成，见下两条）。
- 「1 血免死」节点已实机定名：**保险机制**（赛季优势树带框大菱形，效果含「小队生命值首次将要降低至0时保留1点」全文，详见建档 doc §4.2）；解锁消耗未读出（**锁定态不显示费用**，须先解锁前置才可见，疑 ×100）。线上节点清单仍未公开（BWIKI 货币战争主条目该节为目录占位），节点全量以大厅实读为准；仅旁证节点有专名（米游社官方《列车信箱｜3.7版本意见反馈集中帖》2025-12 提及修复优势布局节点「势力削弱」的失效问题，可按标题检索）。
- **实机核对结论（已完成）**：「1 血免死」落在**赛季优势区**，节点名「保险机制」，激活货币为幻乐晶球；本机该节点未激活（前置 3 个直接依赖未全通，缺口 ≈260~320 晶球），与近期三局「HP 直接归零终局」吻合——**归零即终局口径维持**（gameplay-basics §1），激活保险机制后预期改写，待激活后实测复核。

## 3. 与对局的关系

- 优势布局效果跨局生效：激活一次，之后每局都带；按官方文案其效果分「额外机制」与「角色战斗能力增幅」两类。
- 货币来源：对局结算发放——S1 文案为「每场对局结束后获得等价钻钞」；S2 赛季区为游玩收集幻乐晶球（赛季说明原文「在新赛季中收集幻乐晶球，用以激活各项赛季优势布局效果」）。
- 对局自动化含义：读对局行为（如免死）时不能假设所有账号规则一致——优势布局激活进度是账号级状态，判读免死/初始增益类行为先查大厅优势布局界面。
