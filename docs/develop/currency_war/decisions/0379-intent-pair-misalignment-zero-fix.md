# 0379 — 意向谱系根修(派生对与终局成型体系错位):持有信号信息论不可早期判,零修法裁决

- 日期: 2026-09-01
- 状态: accepted (采纳——裁决=策略零改动)
- 关联: ADR-0374(W188 门内集扩展四格否决)、ADR-0376(W191 评分/候选谱系证伪+亲和放宽否决,移交「意向谱系根修」)、ADR-0357(P1 配方锁/`_derive_p1_pair`)、ADR-0333(engine_seed 板面亲和)、W192/W194(新栈全貌,本批 A 臂锚基准)
- 批: W195(never-2 残差「派生配方对错位」判读+修法批;判读证伪修法前提——持有信号在全部证据轮为空或不占优,零代码收账)

## 背景与问题

ADR-0376 移交:82 型局(供给到位时被亲和拦截)若要根治,靶点=「派生对/
意向与终局成型体系错位」——never-2 残差 9/300 中错位主灶 230/269/293、
次灶 68/82 的派生 top-2 对全程不含终局成型体系,买侧单点放宽已两轮
A/B 否决;本批是意向层的最后一层可修面。

**任务前提的事实修正(判读第一步)**:派生口径 `_p1_system_support`
**已经是持有口径**(bench+deployed 的阵营∪流派计数/体系档),不是
「店面出现频率」——`_derive_p1_pair` 的支持度自 W145 落地起就以
手上资产为输入(「体系对随资产重派生,[20] 变体按来牌选」)。因此
错位的真因不是「供给口径 vs 持有口径」的口径差,而是**目标体系的
持有信号在全部证据轮为空或不占优**——这正是本批判读所证。

## 判读(探针先行,前提证伪)

(池 861fc9f6 导出件重放,never-2 全 9 局逐轮):对每局定义
**证据轮(miss 轮)**=目标体系 distinct 缺件当轮在店(shop_waves
供给史)、**信号轮**=目标体系 distinct 持有距 tier **严格优于**派生
对两体系的首轮(持有信号导向派生应把它排进 top-2 的最早时点)、
**理想修正点**=miss 轮 ∧ 信号已可判(miss 轮 ≥ 信号轮)。

**结论:9/9 局理想修正点为零。**持有信号(owned distinct 距 tier 差)
在全部证据轮要么不存在(230/293/68/82:目标体系 distinct 持有=0,
或已成体系距 ≤0 压平)、要么目标已在派生对内而缺件不来(269/43/136)、
要么平距不占优(102)、要么买不起(274)。

## 决策

**零修法(策略零改动)**。两支证据:

1. **信息论不可判**:错位局翻正的必要条件=目标体系**第一件**在持有
   信号为零时被买入(此后 owned 信号才存在——82 的信号轮 6 恰在首件
   入手后即此结构的实证)。而在 miss 窗内,任何持有导向的派生变体
   (nearest-formable 并入 top-2 / distinct 口径支持度 / 副本折减)
   对目标体系要么恒不覆盖(230/293/68:零持有=任何持有口径都排不进
   top-2,与 ADR-0374「上界1 惰性」同型),要么等价于把 owned=0 的
   体系开进方向——其买侧效应与 ADR-0374 ① 全距版(mal 20→35)和
   ADR-0376 亲和放宽(mal 20→43)同面,已被两轮 A/B 否决。
2. **供给口径派生不在 sanctioned 方向且效应等价已否决变体**:能分辨
   miss 窗的唯一信号是店面出现(supply)——把派生口径换成/并入供给
   频率,等于在 r1-r2 把方向开向 owned=0 的体系(与 ① 全距开向
   距离 2-3 的最近系同构),且方向随 5 张随机牌逐轮摆动=轨迹扰动
   放大器。按 ADR-0374/0376 已有证据面径直弃选,不再付 A/B 成本。

**never-2 残差 9/300 至此在三大谱系(买门 ADR-0374 / 评分-候选
ADR-0376 / 意向本批)全部探尽**,记为策略侧地板;剩余构成=供给侧
(43/269/102/274,非策略可修)与演进事务执行层(136/269,
CompTransaction 链,W192 后辖希儿系但链上守卫待核——唯一遗留
可修面,归 evolve 谱系)。
