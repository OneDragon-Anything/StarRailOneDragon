### 状态词对照（状态列用语速查）

- **已证** = 推导成立，可作策略依据（「结构已证」「站得住」= 结构层面成立）
- **证明不成立** = 推导失败，命题作废（「已推翻」同义）
- **方向证伪** = 结论方向错误
- **待证明** = 有命题、无完整证明（其间数值不得当作授权使用；「草拟」为更早期形态）
- **降级** = 结论范围收窄（如只保留方向）
- **已停用** = 命题随旧架构停用
- **已消解** = 问题随前提变化不复存在
- **禁止引用** = 该数值/推导不得被其他文档消费
