# 角色-行迹(character_traces)

> source_image: sr-od-test/screens/角色-行迹/default.webp(2026-10-17 live 建档,布洛妮娅行迹页)

## 何时出现

角色页左侧「行迹」TAB。独立屏。

## 状态流转

```
详情 TAB → 本屏(星魂树状图) → 节点点击 = 查看单节点详情(子面板,未建档)
右上关闭 X → 离开角色页
```

## 识别特征

- id_mark「标题-行迹」[90,25,160,75](左上标题,仅 2 字——lcs 需注意与他屏短词撞车;live precise 实证,撞车观察留待 id_mark 测试)

## 可交互元素(live 验证 2026-10-17)

| 元素 | 坐标 | 行为 |
|---|---|---|
| 左侧 TAB 5 个 | 同详情页坐标 | 切对应屏(goto_list 已建) |
| 头像条 | 首位 (452-528,28-108) | 切角色保持本 TAB |
| 行迹节点 xN | 树状图各圆点 | 点开单节点详情子面板(未建档) |

## automation 要读信息

- 读区-节点-顶 [1100,565,1190,605]:OCR「12/12」(天赋)
- 读区-节点-左 [1010,590,1105,630]:OCR「7/7」(战技)
- 读区-节点-右 [1240,590,1335,630]:OCR「12/12」(终结技/天赋,按角色)
- 读区-节点-中下 [1100,690,1190,735]:OCR「12/12」
- 读区-节点-底 [1112,830,1185,870]:OCR「1/1」(普攻)
- 节点与技能类型的对应随角色/命途树形而变,扫描只记「5 个 x/x 总和」即可判定行迹养成度(布洛妮娅全满 = 44/44)

## 注意

- 行迹树布局按角色固定(5 大节点 + 小节点枝杈);小节点无数字
- 节点数字「x/y」:x=当前等级,y=满级;全满即 44/44 类总形态
