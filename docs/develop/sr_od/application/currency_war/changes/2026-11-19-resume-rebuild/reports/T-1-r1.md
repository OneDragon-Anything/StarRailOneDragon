## 5. 偏差与未尽事项

1. **重建判据同秒窗口(申报,不改判据)**:`created_run_id` 与「当前 run」都是秒级时间戳字符串。若上一 run 收尾与当前 run 铸造落在**同一秒**,判据退化为同值比对 → 残留容器误判保留(该次不重建)。生产可达性趋零:两 run 之间至少隔一次 app 运行,框架等待下限使上一 run「建立容器 → 收尾 → 下一 run 铸造」全部压缩进同一秒不可达;测试以假钟跨秒显式模拟真实时序(test_stale_container_rebuilt_as_takeover 内 `_AdvancingDatetime` 申报)。**未代改设计**(run_id 加单调后缀属判据变更);建议 T-4 核签时对此窗口复核认定。
2. **`establish_new_match` 的 ensure difficulty 实参捕获位置**:三段式要求「ensure 插槽在吸收段之后」且「旧铸段时点 difficulty 语义保持」——两判据合取下,实参在吸收段取走 ctx 前捕获为局部值、ensure 调用仍在吸收段之后(非「ensure 前置」变体)。函数注释已申报。
3. **handle_init 惰性 import 收拢**:兜底建与重建两分支共用同一处函数内 import(函数内两处 import 同名会把名字绑定为局部,未走首分支即 UnboundLocalError——实现期实证)。落法细节,非判据变体。
4. **接管失效写触达面在 T-1 机械扩容**:b 查分支合并后失效写挂到 b 查入口(先于探针点击,时序不变),1-1 接管局自此也写——「探针分支进入即写」挂点细化与触达面扩大申报注释归 T-2 ①(本报告仅申报现状)。
5. **`resume_candidate` 本体未动**(`obs/cw_resume_lock.py`):prep 调用点已摘除、函数与模块头保持原样——函数删除 + 模块头判据申报归 T-2 ②。
6. **`prep_actions.py:589` 过时注释**(`cw_resume_lock.is_new_match` 引用):未改,归 T-5 清单第 5 项。
7. **探针门测试面分工**:「takeover 必探一次」= 剧本 3(非锁定探后置位)+ 剧本 4(锁定探后置位)+ 新增去重用例(probed=True 不重探)合取锁定;「new_game 永不探」= 剧本 1(候选帧全否,零点击)锁定,未另设重复用例(测试纪律:同一断言面不重复建)。
