# 货币战争-攻略详情

## 画面简介

单篇攻略完整内容页——目标阵容的结构化来源：攻略列表点任意卡片卡身进入。左侧羁绊分级列表 + 前台/后台区域角色卡 + 底部「运营思路」3-4 行过渡节奏/装备优先级叙述；可复制攻略码、应用攻略。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-标题-攻略详情 | 画面标题（身份锚，与「阵容详情」「运营思路」三文本组合判） | 纯显示 |
| 标识-阵容详情 | 区块标题「阵容详情」（身份锚之一） | 纯显示 |
| 标识-运营思路 | 区块标题「运营思路」（身份锚之一） | 纯显示 |
| 区域-标题行 | 攻略标题（羁绊公式）+ 难度副标 + 作者 | 纯显示 |
| 区域-查看攻略详情 | 「查看攻略详情」文字按钮 | 点击无画面变化（未生效占位），别等它响应 |
| 区域-阵容详情-前台 | 前台区域角色卡（横排，带装备槽） | 纯显示 |
| 区域-阵容详情-后台 | 后台区域角色卡（含空位虚线框） | 纯显示 |
| 区域-运营思路 | 运营思路长文 | 纯显示 |
| 区域-热度 | 热度读数 | 纯显示 |
| 标识-应用状态 | 「已应用当前攻略」横幅（应用后出现，横跨前台区上方） | 纯显示 |
| 按钮-复制攻略码 | 复制攻略码（左下） | 点击复制到系统剪贴板（toast「已复制」；可灌进「货币战争-攻略码输入弹窗」分享给他人/自己） |
| 按钮-应用攻略 | 应用该攻略（右下黄色按钮） | 点击应用：按钮变「取消应用」+ 顶部「已应用当前攻略」；应用成功自动弹装备追踪弹窗，应用后备战板面带板面标记 |
| 按钮-关闭面板 | 右上 U 图标 | 点击回攻略列表；ESC 同效 |
| （待建档）左侧羁绊分级列表 | 左侧竖排羁绊列表（已激活数字大字 + 可选档位小字）；**羁绊分级数字 OCR 系统性碎裂**（「3/5/7」易连读成一串）——解析按图例语义（在备战席/在场上/核心角色 = 板面标记）而非裸数字 | 纯显示 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 进入本画面 | MCP `click` | 攻略列表该卡「卡N-卡身」area 中心 | 进攻略详情 | — |
| 复制攻略码 | MCP `click` | 「按钮-复制攻略码」area 中心 | toast「已复制」、码进系统剪贴板 | — |
| 应用攻略 | MCP `click` | 「按钮-应用攻略」area 中心 | 按钮变「取消应用」+「标识-应用状态」横幅出现；自动弹装备追踪弹窗 | 应用后备战板面带板面标记 |
| 关闭回列表 | MCP `click` | 「按钮-关闭面板」area 中心 | 回「货币战争-攻略列表」 | ESC 同效；「查看攻略详情」按钮是未生效占位，别等它响应 |

读阵容详情 + 运营思路定目标阵容方案；应用与否按用户诉求（应用会改备战板面并弹装备追踪）。
