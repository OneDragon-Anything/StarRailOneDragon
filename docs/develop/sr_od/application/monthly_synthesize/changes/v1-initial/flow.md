## 3. 现场发现

- `按钮-最大值` 是零尺寸点区域 (1445,870),对材料合成页的滑条 UI 是误点源(点轨道会跳数量)——plus 模式路径不得触达该区域;该区域为消耗品合成页遗留,本次不动它(零食路径在用)。
- `CATEGORY_2/3/4_BTN` 是无语义的通用点区域,CATEGORY_2 与新 `分类-材料合成` 同 rect;保留不动(最小改动),新代码只用语义名。
- 「+」与「−」按钮外观高度相似(白胶囊+黑符号),模板必须限制在 + 按钮局部区域匹配——全图裸匹配亮态模板会以 0.877 命中「−」(实测)。
- **材料合成列表按「可合成排前、不可用沉底」排序**(实测:额度 2 时自塑尘脂列首;合成拉满额度归零后,自塑尘脂从首屏消失、沉到列表深处)——与兑换商店月限三件套同款排序律。由此 plus 模式选物品改**首屏判定**(首屏未见即本期不可合成,不拖拽深扫),成因裁定(额度用尽 vs 材料不足)按运行记录当月锚区分,见 application-flow.md。
- 页签记忆:手机菜单新开合成页默认落在**消耗品合成**(即使上次离开时在材料合成)——「选择合成类别」的点击回退路径(建档 `分类-材料合成`)实测生效。
- 变量骰子的合成材料含自塑尘脂(15/3),侧面证实合成结果落账(13→15)。
