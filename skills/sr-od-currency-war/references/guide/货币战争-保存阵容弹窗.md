# 货币战争-保存阵容弹窗（攻略存进我的阵容）

**识别**：`is_precise` 命中 `货币战争-保存阵容弹窗`（锚：「保存并收藏」单文本即精准——标题区未设 id_mark，档与 dev doc 的「组合双锚」描述不一致以档为准）。
**目标**：把攻略列表卡片上的阵容存进「我的阵容」（上限 10，标题带 n/10 计数）。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：攻略列表卡片「保存阵容」。
2. **保存**：点「存为新阵容」行选槽位（空槽显示下载图标，行可滚动超过 3 行）→ 右下「保存并收藏」勾选态提交；右上 X 关闭（不保存）。ESC 也可取消（实测关闭回列表未保存）。
3. 槽位选中态未实测（点击会实际写入用户阵容，验证时主动跳过）。
