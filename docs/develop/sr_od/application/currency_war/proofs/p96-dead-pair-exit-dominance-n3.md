## 1. 命题

**P96-a(帧级支配)**:设死锁帧 f(bench 满 ∧ 存在被阻断的 M2 义务买入,其净 EV>0),x 为素材对(bench∪deployed 全场域同名同 1★ 计数恰为 2)的 bench 侧成员,且 x 满足退出判据三合取(§2 判据)。则「卖 x(释放 1 席)」弱支配「持 x」:帧内持有收益 = 0、持有成本 = V_slot(f) > 0;卖出净金 0 且释放被阻义务的兑付通道。

**P96-b(N 唯一性)**:退出判据的时域下界 N(账龄 = 当前轮 − 较晚成员获取账登记轮 ≥ N 才可释放)在两侧边界约束下取唯一值 **N = 3 = `SEED_WINDOW_ROUNDS + 1`**:N<3 撕种子年龄窗在册保护面(P78-7)的辖域语义(禁);N>3 保护一个无任何在册载体的意图(不可证伪的过度保护 = 病灶本体,禁)。

**P96-c(合取不变量)**:退出通道并入后,非重买集名 x 的全场同名同 1★ 计数 C(x) 在购买通道合取下单调不增(吸收类 C∈{0,1}),无 P60 型换手循环。

## 3. 证明

### 3.1 被保护对象的定价与买家空集(V_opt 对偶推演)

素材对成员 x 单卖一张的后果:对 C(x) 为 2→1。金账净 0(前提 D),但「差一张」退化为「差两张」——重建该对需再买 2 张而非 1 张。G-S1 拒卖的隐含定价 = **被毁期权的对偶账**:在需要 2★ 的假想时点,1 张定向再获取成本与 2 张之差 ≈ 一张的 P_miss 加权补救账 = `u(要这张的非重买集 2★) × P_miss(H) × C_rescue(x)`——恰为 P41 ①对 x 的 V_opt 形态。守卫的语义 = 给素材对成员记一笔 V_opt(第三张)> 0 的 fail-closed 持有,与「③④ 件 V_power>0 故非燃料类」(P78-4)是两条不同的保护:前者保护合成进度期权(ADR-0558),后者保护身份资产。

期权要有值,必须存在**会买第三张的通道**。全通道盘点(对退出目标类 name∉base):

| 通道 | 辖域 | 对退出目标类的可用性 |
|---|---|---|
| 义务合成完备购 `m2_merge_completion`(免席门) | 只服务买面重买集 base(`_resolve_base` 输出;11_shop_decisions §2) | **按构造为空**:退出目标类 = name∉base(判据 (b) 同基准) |
| 非定向臂 C=2→3 补买(买侧防线显式放行的「消对修复动作」) | dominance 资格门 = 金 > g* ∧ bench_free > 1(前提 G) | **守卫咬合帧恒不可行使**:G-S1 咬合的帧 bench 满 → bench_free ≤ 1 → 门闭。金宽+席宽帧可行,但席不缺帧守卫无代价(无 V_slot,不构成本命题场景) |
| 买 3 合 2★ 后卖 2★ 的清算链 | 游戏满栏合成例外允许买(merge_mechanics §2.5),bot 侧 `merge_buy_k` 消费点 = 满栏购买门与买入意图记录,**无任何清算卖臂** | 机会成本上界 = P(窗内第三张到店)×(2c−1) ≤ 数金级(1-2 费),量级见 §5,忽略并申报 |

结论:**对 name∉base 的素材对,期权的系统性买家用集合为空**。唯一残余行使路径(非定向臂富余帧顺手消对)的价值主体是「顺带释放 2 席 + 小额清算金」,不是「想要该 2★」。守卫的 fail-closed 假设(意图存在)在这类名字上没有载体——保护收益(2★ 期权)与保护代价(席位占用)辖域错配(ADR-0558 案发对形态的语义层根因,design §1.2)。

### 3.2 帧级支配(P96-a)

设死锁帧 f 与 x 如命题所设。逐项对账:

| 项 | 持(A) | 卖(B) |
|---|---|---|
| 席位 | x 占 1 席,义务买入继续被阻 | 释放 1 席,被阻义务买入获兑付通道 |
| 帧内持有/卖出收益 | 对内期权在帧 f **结构性不可行使**(3.1 表:义务通道按构造排除、非定向臂门闭、清算链无臂)⇒ 收益 = 0 | 义务动作兑现(正 EV 由骨架层权限模型给定,02_mandate_layer §2/§3 M2;V_slot 定义即取被阻断动作 EV,P41 ③) |
| 帧内成本 | V_slot(f) > 0(死锁帧定义) | 0(净金 0,前提 D) |

B 的收益项 ≥ 0(被阻义务 EV>0)> A 的收益项 = 0,且 B 成本 0 < A 成本 V_slot(f)>0 ⇒ **B 弱支配 A,在被阻义务兑付帧上严格**。∎

这是 P41 燃料支配条款在「资格谓词修正后」的直接重放:x 的燃料类资格三条件(前提 C)中,前两条(1★ ∧ 零重叠)帧内可验,第三条(边际≈0)由 3.1 结论成立——非重买集名无买家的 2★ 期权,对板面作战与 bench 后台效果两维的边际贡献均为 0(fuel_sell_candidates 的 R17-2 扩维口径)。

**P41 类资格边界不被撕开**:③④ 件、义务基座件、种子窗内件、囤腿登记件在判据 (b)(c) 的合取结构与下游装配 A 身份段双重排除下不进入实际卖出集合——退出通道只对「P41 类资格本已成立、仅被进度期权账压住」的类恢复判定。跨帧残余(期权在**未来帧**行使的 regret)见 §4 边界 1。

### 3.3 N 唯一性与时钟起点重基(P96-b)

**N 的语义**:退出判据的时域条件 =「跨 N 轮无第三张意图」;「意图」的可操作定义 = 存在会买第三张的**登记载体**(前提 E 闭集)。N 的推导义务 = 找到「载体闭集全闭」的最短评估龄。

瞬态载体(③④)的最大寿命:③当轮窗 = 登记轮==当前轮,寿命 1 个日历轮;④种子窗 = 获取轮 ≤ r ≤ 获取轮+2,寿命 3 个日历轮(F)——**瞬态窗闭集最大寿命 = 3**。释放时点账龄 ≥ 3 ⟺ 两个瞬态窗对两成员**必然全闭**(账龄按较晚成员登记轮计,任一成员的当轮窗/种子窗至多开到登记轮+2)。

- **N < 3 的下界违反**:N=2 时释放可落在账龄恰为 2 的帧——该帧落在此前登记的种子窗内(获取轮 ≤ r ≤ 获取轮+2 含 r−a=2)。对成员含种子获取的名,其种子簿账户仍活跃,而 P78-7 的在册裁定是「获取窗内全通道禁卖,0 容忍」——资格层(释放集)在窗口仍开时宣布「意图已死」,与在册保护窗的辖域语义正面相抵:种子对的非窗口保护腿(名义不在种子簿的孪生腿)无任何窗口段可拦,实际卖出随即发生,对状态在保护窗内被拆——**撕 P78-7 保护面,禁**。
- **N > 3 的上界违反**:账龄 > 3 后,载体闭集内再无任何在册账户指向该对(①②被辖域排除、③④已全闭)——继续持有保护的是一个**无任何登记载体的意图**,不可证伪也无法兑现 = §3.1 结论下的不可证伪过度保护,即病灶本体(阿格莱雅×2 自 R1 锁席至 R9 的形态),禁。
- 两侧边界夹出唯一值 **N = 3**。实现取 `DEAD_PAIR_EXIT_MIN_AGE = SEED_WINDOW_ROUNDS + 1`(零新自由参数:N 值来自在册窗长,索引 +1 是「窗覆盖账龄 0..2、全闭 ⟺ 账龄 ≥ 3」的恒等换算)。

**时钟起点重基声明(显式,防登记时被指偷换起点)**:种子窗的原始标定对象 = 「种子相邻轮回卖封口」,**时钟起点 = 种子获取轮**(种子按定义只记首张——获取资格谓词要求购买时未持有,给不出 max(两获取轮))。本命题**沿用其窗长**(获取轮 ≤ r ≤ 获取轮+2 = F 在册值)为「新购意图的最长在册寿命」,但**起点另立** = 较晚成员的持久获取账登记轮:素材对只在第二张到手那刻才成为「对」,意图假设的钟从那里起走。落码形态 = 获取账同名覆盖写为最新轮(覆盖写即天然取 max(两获取轮)),判据 (c) 单条目读。窗长沿用 + 起点重基两点均在册声明;落地后由遥测对账回检(kept_no_entry/kept_young 子键:窗内被保留对后续是否真的等来合成/转 base;若回检出「过早退出后被义务通道重买的对」,按 P76 甲该 regret 金中性、代价只是再遇等待,备选形式 = 供给统计窗 N ≥ 1/P_shop ≈ 9-21 轮,见 §4 边界 6)。

### 3.4 合取后的结构不变量(P96-c)

非重买集名 x 的 C(x)(全场同名同 1★ 计数)在购买通道合取下的逐值迁移:

- 0→1 可(单张 1★ 全额可退,零锁席);
- 1→2 拒(买侧防线 `dead_stock_pair`,前提 G);
- 2→3 即自动合成净消对(放行禁误伤,merge_mechanics §1);
- **2→1 由本通道释放卖出引入(唯一降向迁移)**。

购买通道下 C(x) 被压入吸收类 {0,1}:对不再新生、既成对确定性排干、排干后的单张不再回 pair。**无换手循环**:P60 型「M4 卖 1 买 1 伪装进展」三要素(卖出对象 ∈ 买面重买集 / 义务重买 / drought 重置)在此不成立——释放名 ∉ base(重买集不重买,判据 (b)),且买侧防线封死非定向臂回 pair(C:1→2 拒)。**例外如实申报**:赠得路径(补给/投资卡发放)不经购买通道判据,理论上可注入 1→2——频率低(事件条件流),残余归 §4 边界 3。∎

## 4. 边界与残余风险界(诚实申报;fail-closed 方向逐条给明)

1. **配方重派生回 base**:P1 配方对逐帧重派生(12_line_and_intention §4),今天的非 base 对可能是明天的义务素材。退出卖掉后若派生翻向,义务通道按同价重买(P76 甲净 0 金),代价 = 再遇等待(1-2 费 ≈ 9-22 轮带,锚点见 §5)。**该风险类不是新造的**:燃料资格集里的单张今天就承担同一风险(单张燃料件被卖后翻 base 重买),本通道只是把「对」并入该既有风险类。缓解 = 判据 (b) 逐帧现读 base——当前帧重买集不要的名字才出集。
2. **3★ 链式合成状态**:非 base 名存在「bench 1★ 对 + 场上同名 2★」链上状态时(merge_mechanics §2 连锁合成),退出会拆掉 3★ 链的 1★ 腿。判据附保守保留(前提 B):释放评估现读全场域同名 2★,命中即不入集(kept_chain)——漏保留 = 漏保护向,故取全场域。
3. **无账写入路径与跨位面携带**:获取账写端 = shop 发射位 `_emit_buy`(全因类);不经发射位的路径(补给/投资卡赠得)无登记 → 判据 (c) fail-closed 不出集 → 这类对继续锁席;跨位面携带对在位面切换帧被位面闭合清账 → 同样永保。两者都是**保守向后果**(过度保护非漏保护),频率低;若遥测显示该类锁席成规模,后续批给发放路径补获取账写点。as-built 已知子型:**混合获取对**(一张买一张赠得)账条目仅承买得张,轮戳早于成对轮,至多提前 N−1 轮释放(赠得为事件条件流低频,本条同族)。
4. **四通道全量放行的对价声明**:释放是资格级旁路,凑息/支付变现通道消费释放成员时各自的对价豁免条款(P78-5/5′ 两腿)照常辖——凑息卖掉意图已死的近零值资产正是燃料类语义,无新增豁免需求;P78-4(③④ 禁卖 = 类资格本义)不触碰(§3.2 末段)。
5. **ADR-0558 原案回归**:原案发形态(2/3 进度素材被燃料资格卖断)若其成员为新购,新购 → 当轮窗在册 → 判据 (c) 的 N=3 保持拒卖(账龄 < 3);行为锁④(`test_cw_dead_pair_exit.py`)把该回归形态钉死。
6. **N 的回检备选(登记防临时拍值)**:若遥测回检证伪 N=3(过早退出率显著),备选形式 = 供给统计推导 N ≥ 1/P_shop ≈ 9-21 轮(「等一个期望再遇窗再判死」)。放弃为主案的理由:它把「第三张到店」(供给)与「有人买」(意图)混为一谈——对无买家类,供给到达也不行使(§3.1),按供给窗等只是把 §3.2 的帧级支配收益推迟 6-18 轮 × V_slot,换来的期权增量(窗内到店且富余帧顺手消对的清算金 ≤ 数金)量级不符。两条推导都在案,防「回检失败临时拍新值」。
