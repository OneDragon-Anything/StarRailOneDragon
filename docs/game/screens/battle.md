# 战斗画面(battle)

回合制战斗。battle screen_info 只建了**结果态**(成功/失败/退出/再来),战斗过程态(回合制技能选择 / 自动战斗 / 行动条)未建 area。`pc_alt=false`。各玩法(花萼/历战/饰品/模拟宇宙/忘却之庭)战斗都进此画面。

## 何时出现 + 状态流转

- **入口**:大世界遇敌 / 秘技攻击 / 各玩法挑战(花萼/历战/饰品/忘却之庭/模拟宇宙)→ 战斗画面(过程态)。
- **过程态**(回合制):角色/敌方行动条 → 技能选择(战技/终结技/普攻)→ 释放 → 下一回合。可自动战斗。
- **出口**(结果态):
  - 胜利 → 「挑战成功」→ 领奖励 / 「再来一次」/ 「退出关卡」。
  - 失败 → 「战斗失败」→ 「退出关卡」/ 「再来一次」。

## 识别特征(稳定锚点)

- **结果态**(battle.yml 4 area):
  - **挑战成功**(text "挑战成功",734,138-1190,400):胜利结果。
  - **战斗失败**(text "战斗失败",同 rect):失败结果。
  - **退出关卡按钮**(text "退出关卡",544,923-880,975)。
  - **再来一次按钮**(text "再来一次",1180,930-1400,1000)。
- **过程态**:`battle_screen_state` 检测(无 area,靠画面特征)。
- `pc_alt=false`(战斗不锁光标)。

## 可交互元素

**结果态**(screen_info area):
| area | 说明 |
|---|---|
| 挑战成功 / 战斗失败 | 结果判定 |
| 退出关卡按钮 | 退出回大世界 / 玩法入口 |
| 再来一次按钮 | 重新挑战(连续刷) |

**过程态**(未建模 area,OCR/特征):
- 行动条(角色/敌方顺序)、技能按钮(战技/终结技/普攻)、自动战斗开关、速度。

## bot 流程(各玩法战斗)

- **战斗触发**:各玩法 challenge op(如 `challenge_echo_of_war` / `ChallengeOrnamentExtraction` / `sim_uni_fight_elite`)。
- **等战斗结束**:bot 检测结果态(挑战成功/战斗失败)—— 战斗过程 bot 不干预(自动战斗 or 游戏自带 auto)。
- **结果处理**:成功 → 领奖励 / 再来一次(连续挑战,如 calyx 次数);失败 → 退出 / 重试。
- `battle_screen_state`:战斗画面状态检测。

## 备注 / 待查

- **待实拍画面 + vision**:战斗过程态(回合制技能 / 行动条 / 自动战斗) + 结果态(成功/失败)实拍归档 + vision(技能图标 / 行动条 / 自动开关)—— 遇敌 / 玩法挑战触发,自主遇敌随机耗时,建议玩法挑战时顺带实拍。
- **过程态未建模**:battle screen_info 只结果态,过程态(技能选择等)无 area —— bot 靠自动战斗 + 等结果,不操作过程(若需手动技能要补过程态 area)。
- **自动战斗**:星铁自带 auto(全自动 / 倍速),bot 依赖 auto 等结果,不手动操作技能。
- **lcs_percent 0.7**:结果态 area 用 LCS 0.7(宽松匹配"挑战成功/战斗失败"文字)。
