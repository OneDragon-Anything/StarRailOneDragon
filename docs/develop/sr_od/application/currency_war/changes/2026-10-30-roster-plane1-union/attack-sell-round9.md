# 卖出场景块无前提对抗报告（第九轮：八轮处置复核 + 语境分/虚拟推演专项 + 全量一致性）

## 结论（阻断）

**阻断**：2 阻断 + 3 中 + 3 低。两个阻断项全部落在**八轮处置的核心修法**上：

- **S9-1**——S8-2 处置（售 V 后受限态虚拟推演）的核心推判谓词第一项「**V ∈ 承重集**」术语全仓无定义源（grep 实锤：代码与全部文档仅在 S8-2 落文与八轮处置记录两处出现），且与同句括号内的翻转让位机制（**V 为最后线外件**）按权威源代码术语互斥：cw_launch_admission 的「承重」语义 = line_weight 计数（核准集 ∨ 羁绊视图内件，:173-183），承重件被售使 line_weight 与 occupied **同减**、load_bearing_full 数学上不可能 False→True（唯一翻转路径 = 移除线外件使 occupied 单减）——「V ∈ 承重集 ∧ 售 V 翻转 armed」按代码语义读是**恒假合取**（推判恒不触发 = S8-2 处置整体空转 = 白卖带全开）；按「板面件全集」读则恒真冗余（谓词退化为后两项）；按「V 为最后线外件」意图读则字面写错。三种读法没有一种使该谓词既准确又非冗余——实现者无论怎么落都可能复活八轮 S8-2 的阻断行为（V 白卖、X 丢货架）。
- **S9-2**——同一推演的「售 V 翻转 armed」**未定义推演载体与推演板面构造**：armed 翻转有两条路径（load_bearing_full 翻转 **∨ ¬deploy_plan_available 翻转**，cw_launch_admission.py:259-261），第二条经级联提位耗尽 bench 真实可达（V 无需线外、板面可仍非零线外——L3 普通件填充的定型板 + plan_available fail-open）；「预判全在商店侧虚拟推演内完成，与统一虚拟评估同源」没有写明推演 = 定型板面上**完整重放 readiness_launch_decision** 还是手搓 load_bearing 单判据——手搓漏 plan 维度路径、完整重放需确认注入参（line_members/has_deployable）在评估帧可调；且 S8-1 语境分后两语境的推演板面构造不同（席位语境 = 定型板面含提位；纯金语境 = 当前 − V 无提位、无级联）未写。推判的封堵面（S8-2 是否真生效）完全取决于这个未定的载体。

裁定本身不翻案（升级凑金删除 / 统一获取让位 / 意图槽策略层实现边界 / 凑息豁免 / 等钱帧凑息照常 / 拦因分键 / 净腾辖域按语境分的**方向** / 虚拟推演的**方向**，均不再攻）；攻击面全部落在八轮处置的落文真伪与建模写法。八轮处置复核的真项：S8-3（总纲计数括号对齐 :69② ✓）、S8-4（详设步域 1-9 ✓ :94）、S8-5（覆写规则精化 :70 ✓）、S8-6（行号 :919-925 ✓ 与 cw_vocab.py:919-925 实读吻合）、S8-8（幂等 + ≤2 次搜索申报 :70 ✓——S8-1 语境分后纯金语境 1 次，上界口径不破）；S8-1 式子本体（:68 净腾式无 X、售 V 后、方向）七轮已验维持 ✓；S7-2 bridge 谓词、S7-5 签名求值点、S7-6 三定稿维持八轮复核结论。

## 发现清单

### S9-1｜S8-2 推判谓词「V ∈ 承重集」术语无定义源且与同句翻转让位机制互斥——按代码语义读为恒假合取（推判空转 = 白卖带全开），按全集读为恒真冗余，按意图读为字面写错；三种读法无一使谓词既准确又非冗余
- 攻击点：S8-2 落文（design.md:65 步 6 尾）「评估步补判——**V ∈ 承重集** ∧ 售 V 翻转 armed ∧ 花后金（gold + V退金 − cost(X)）< saturation_line → 让位不成立」，同句括号写「**V 为最后线外件时**售 V 翻 load_bearing_full → armed → 回店受限」。逐层核实：
  ① **术语无源**：grep 全仓「承重」——代码仅 OCR 识别/sim 呈现集/环境立场等无关语境（cw_megastar_obs.py:81、cw_sim_backend.py:924、invest_env.py:136），cw_launch_admission 全文无「承重集」一词（最接近 = load_bearing_full 键名与「板面支撑满额」docstring）；全部迭代文档仅 S8-2 落文与八轮处置记录两处。承重集的判定读端（成员判据、数据源）无处可查——任务书点名的「承重集判定读端」无源。
  ② **按代码语义读 = 恒假**：「承重」对应 line_weight 计数（支撑计数，:173-183——核准集 ∨ 视图内件），承重件被售 → line_weight 与 occupied 同减 → load_bearing_full 不变（本轮数学封闭性推导，见核实轨迹二）——**售承重件永不翻转 armed**（load_bearing 路径）；「V ∈ 承重集 ∧ 售 V 翻转 armed」恒假 → 推判永不触发 → S8-2 处置空转、八轮阻断的白卖带（V 白卖、X 丢货架）经谓词读法缺口全开。
  ③ **按板面全集读 = 恒真冗余**：V 是场上件必在板面（occupied）——谓词退化为「售 V 翻转 armed ∧ 花后 < g*」两项，「承重集」项无信息量，与八轮处置记录声称的补判三要件不符。
  ④ **按意图读 = 字面写错**：翻转让位 = V 为最后线外件（线外件 ∉ 承重集）——八轮 S8-2 攻击原文自己写的是「V 是最后线外件」（线外），处置转录成「V ∈ 承重集」（若承重 = 线内支撑则方向相反）。
  实现者拿到该谓词：读 ①落 = 机制空转（白卖带复活）；读 ③落 = 翻转带拦住但谓词冗余、plan 路径取决于「翻转」的实现；读 ④落 = 与字面不符需自行改写。修复需设计内重写谓词（建议形态：「V 为线外件 ∧ 虚拟板面售 V + 提位后零线外件或 plan 不可得〔完整重放见 S9-2〕」），非落地批可自行裁定。
- 证据：design.md:65（S8-2 落文全句）；cw_launch_admission.py:171-183（line_weight 计数口径）、:184（occupied）、:199（load_bearing_full）、:144（「⟺ 板面零线外件」docstring）；attack-sell-round8.md:52-62（S8-2 原攻击·「最后线外件」表述）/:122（处置记录·「承重集」表述）
- 严重度：高｜阻断级：**是**（八轮核心修法的判定谓词不可实现——任一读法落地都可能重建八轮阻断行为；「实现者无需再设计」违例的最重形态）
- 处置建议：谓词重写为可计算版——「售 V 后虚拟板面重放 readiness_launch_decision 得 armed=True（评估帧 armed=False 为前提差分）∧ 花后金 < saturation_line → 让位不成立」；「承重集」若另有所指给出定义源（成员判据 + 读端），否则删词。

### S9-2｜同一推演的载体与板面构造未定义：armed 翻转的 plan 维度路径（¬deploy_plan_available fail-open）未点名、完整重放 vs 手搓单判据未选型、席位/纯金两语境的推演板面构造不同（定型板面 vs 当前−V）——S8-2 封堵面取决于此载体
- 攻击点：三个子面：
  ① **翻转有两条路径，处置只点名一条**。armed = form_ok ∧（load_bearing_full **∨ ¬deploy_plan_available**）（cw_launch_admission.py:259-261）。plan 维度路径：级联提位耗尽 bench（has_deployable 输入的 bench 变空/无可上者）→ plan_available 翻 False → armed=True——**板面可以仍非零线外**（定型板含 L3 普通线外件时 line_weight < occupied 但 plan 不可得 → fail-open 发出）。该形态 V 无需是线外件、无需是「最后线外件」——S8-2 括号的机制描述（load_bearing 翻转）与「V 为最后线外件」覆盖不了它；回店受限 → 撞闸 → 白卖带经此路径开放。
  ② **推演载体未选型**。「预判全在商店侧虚拟推演内完成，与统一虚拟评估同源」——「推演」= 定型板面上**完整重放 readiness_launch_decision**（需确认注入参 line_members/has_deployable 在评估帧可调——两者为策略层函数、评估在策略层内，可调 ✓ 本轮核过依赖方向合法）还是**手搓 load_bearing 单判据**（漏 ①路径）。重放形态还须定推演板面用哪个搜索的产出（评估步 3 定型 = 快照+X 定型；重放用其板面还是独立再跑）——复用步 3 定型则搜索成本零增（S8-8 的 ≤2 次申报保持），独立再跑则申报破。文本全无。
  ③ **两语境板面构造不同未写**。S8-1 语境分后：席位语境的售 V 后板面 = 定型板面（含提位链）；纯金语境「无级联态」→ 售 V 后板面 = **当前局面 − V**（无提位、无 X——X 买入后也不自动上场，上场归第 6 步）。同一推判式在两语境的 armed 输入板面不同，翻转判定结果可不同（提位链改变 line_weight/occupied/plan_available 三输入），设计未分叉声明。
- 证据：design.md:65（「预判全在商店侧虚拟推演内完成，与统一虚拟评估同源」）；cw_launch_admission.py:190-198（plan_available = has_deployable 注入）、:259-261（armed 两支）；design.md:68（纯金语境「无级联态」——板面构造差的来源）
