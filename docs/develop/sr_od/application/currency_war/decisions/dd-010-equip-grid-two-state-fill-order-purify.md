# DD-010:装备区识别重构——两态位移+填充序剪枝+画面守卫外移(识别器纯化)

- Status: accepted(用户逐项裁定 2026-09-02:「两种固定网格」「必须是干净备战才识别装备」「外层判干净才调用,识别器不混杂特殊判断」「_panel_open 是旧逻辑可去掉」)
- 依据: 实机效率瓶颈分析(当日两局框架日志逐行计时)+ 11 存档帧 δ 实测对拍 + 建档画面清单核查

## 背景

实机单局 ~65 分钟,备战阶段占 ~43%(每回合平均 96-112s);profile 实测装备区识别
`read_equip_grid` 单帧 7-11s(`.log/mcp_server.log` 逐行时间戳,测试仓 profile 同源),
为备战阶段最大单点。结构成因:每帧 14 档横幅位移(δ)全档扫描(14×15 格×157 模板
≈ 3.3 万次 TM)+ 识别器内混杂画面状态判断(亮度探针 `_panel_open` + occluded 三态),
后者与建档画面识别体系职责重叠。

## 决策

1. **位移两态化**:δ 扫描(每帧全档)→ 候选档 `_EQUIP_DY_CANDIDATES = (0, 24)`
   (右上「装备追踪中」标签出现时装备栏整体下移一档定值;11 存档帧实测旧扫描值
   -8..+28 散布为 TM 分数平台噪声,真实下移态仅 2 帧)。每帧按候选档逐档分类,
   对齐判据 = **占用格峰心垂直偏移中位 ≤ `_EQUIP_DY_ALIGN_TOL`**(分数不能作判据:
   TM 归一化互相关平移不变,错位 28px 帧部分重叠格仍 0.93+,实测);两档皆不对齐才
   回退全档扫描兜底并 `[cw!]` 留痕(`dy_fallback`)。
2. **填充序剪枝**:栏内扫描按填充序(用户口述·权威,知识档
   `docs/game/currency_war/research/equipment_mechanics.md` §5):row1 消耗品带右→左,
   装备区右列自上而下、再左列;两段**独立**「首空即停」(段间不耦合——耦合版曾致
   row1 停连带装备区不扫,回归锁抓出)。row1 只匹配工具模板子集(注册表
   category='工具',约 10 模板 vs 全库 157);owned 快照仍含工具(W209g 采集写端契约)。
3. **画面守卫外移**:识别器内不做任何画面状态判断——干净备战判定统一归建档画面
   识别(调用方 `check_and_update_current_screen` 判「货币战争-备战」;备战 id_mark
   含右下「出战」按钮,恰被角色详情面板覆盖,面板态天然判不出备战;角色详情/装备
   详情/装备浮窗/开商店各有独立建档)。`_panel_open` 亮度探针、`EquipCell.occluded`
   三态、op 层 4 处「出售」OCR 检查全部退役(检查语义由建档判定承接)。

## Considered Options(位移测量)

| 选项 | 裁决 | 理由 |
|---|---|---|
| 缓存全档扫描结果(进程级 + 相邻档峰验证) | 否 | 保留「每帧测量」的旧范式,缓存失效路径复杂;噪声 δ 被固化风险 |
| 显式检测「装备追踪中」标签(OCR/模板) | 否 | 依赖标签视觉样式不变,引入新模板资产;与分数自验等价但多一层 |
| **两态候选 + 峰心自验 + 全档兜底**(选中) | ✅ | 每帧独立无状态;规律来自玩家知识+11 帧实测;兜底保证未知第三态不坏功能 |

对齐判据:TM 分数阈(否,平移不变性)vs **峰心中位偏移**(选中,几何对齐的直接测量)。

## Consequences

- **前置契约**:`read_equip_grid` 输入必须是干净备战画面;违反 = 输出无意义
  (无运行时守卫,职责在调用方);装备期望态对账(`compare_equip_expect`)是
  漏识别/错识别的暴露防线。
- 填充规律若被游戏版本打破(出现空洞形态)→ 剪枝漏格 → 同上由对账防线暴露;
  `[cw!][dy_fallback]` 行 = 未知第三布局态信号。
- 性能:单帧 7-11s → 0.4-1.8s(实测 3 代表帧);实机每局装备识别 ~2 分钟 → ~20s;
  测试 fixture 生成同步受益。
- schema:`EquipCell` 删 `occluded` 字段(两态);`read_equip_grid` 返回按填充序的
  占用格列表(至首空格),消费方(w543 对账/装备 op/recognizer)同步。
- 退役件:`_panel_open`/`_EQUIP_PANEL_*`/`_cell_in_panel`/op 层「出售」OCR 检查。
