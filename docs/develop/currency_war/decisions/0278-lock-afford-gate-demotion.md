# 0278 ⑧-1 锁线可负担门降级为日志观测(批⑨ F2;双侧零咬合)

- 状态: accepted
- 日期: 2026-08-24
- 来源: sim 压测批⑨ F2(批⑥ F2 裁决);worker 任务「sim 侧修复批五件」件4

## 背景

⑧-1 修复(对抗8:金<3 刷出 CARRY 即锁线 → 桥件停买空过挨打)给
锁信号加了「可负担/已持有」门(`owned ∪ affordable` 过滤
`check_core_signal` 输入)。批⑨ F2 复算:实机 18 局 353 个「未过滤
能锁」帧,门拦截 **0 次**;sim 300 局 0/300——**双侧零咬合**:门
从不改变锁线结果,是纯死门;同时保留着未来误拦风险(金暂时低的帧
本可锁线被拦,正是对抗8 想防的镜像形态)。

## 决策

1. **门降级为日志观测(不拦)**:`check_core_signal` 直接吃全量
   可见名单;锁定信号命中但锁定卡不在 `持有∪可负担` 集时记
   `[cw][v2] ⑧-1 可负担门(已降级)观测` 日志——供跨局对照;
2. **观测恢复条件**:日志显示门曾实质拦截(改变了锁线时点/结果)
   时,凭日志恢复门(数据在,决策可逆);
3. `_affordable_cores`/`_owned_names` 保留(观测用;后者另有
   消费)。

行为影响:零(门本来 0 咬合)——本 ADR 是**删死代码风险 + 留观测
通道**的裁决记录,非行为变更。

## Considered Options

- **A. 直接删门与 `_affordable_cores`**:拒绝——对抗8 的担忧形态
  (买不起的 CARRY 锁线后桥件停买)在别的经济条件下可能真实出现,
  删净则无观测面;
- **B. 降级为日志观测(选定)**:行为零变 + 观测留痕 + 恢复条件
  明确;
- **C. 维持门**:拒绝——零咬合死门只贡献误拦风险与阅读负担。

## 影响

- `strategies/line_strategy.py`:update_target 锁线分支(一处);

  (金 1 + 贵核心卡可见 → 仍锁线)。
