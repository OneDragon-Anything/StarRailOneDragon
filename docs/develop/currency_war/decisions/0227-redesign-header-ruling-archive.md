# ADR-0227 redesign 裁定史归档(头部瘦身)

## Status

accepted(2026-08-22;文档治理)

## Context

`redesign.md` 头部堆积 r201-r220 共 20 轮用户裁定/对抗审查的流水记录(143 行),违反 ADR-0210 四禁(历史叙述归 ADR,正文 as-built)。但这些裁定多数没有独立 ADR 条目(如 r205 三层分工/r207 桥线辩论/r208-r220 门槛体系),直接删 = 裁定依据丢失。

## Decision Drivers

- 正文该是干净 as-built;裁定 why 需可追溯
- 不逐条补 20 个 ADR(裁定已融入正文相应节,逐条拆分是搬运不是治理)

## Considered Options

1. 逐裁定拆 20 个 ADR:工作量与价值不匹配,正文已是融合态
2. **单 ADR 归档裁定链**(选):本条 = 裁定史索引;redesign 头部压缩为一段状态声明+指回本条
3. 头部不动:违反 ADR-0210,59KB 文件继续超重

## Decision

选 2。裁定链全文见 `git show` 历史(redesign.md @ 本条提交前 HEAD);关键裁定与正文落点映射:

- r201 星级三档(辅助 opportunistic)→ §4.3 星级三档模型
- r202 牌库操纵融入经济模式 → §4.2 牌库操纵层
- r203 融合总表(26 条口述对账)→ §4.6
- r204 代码级审计 → §6
- r205 DP 退役·三层分工(用户「DP 应该有这个能力吧」)→ §3 总体架构
- r206 规则式≠无概率(用户「牌库概率都会考虑吗」)→ §5.2b
- r207 桥线重构(用户「发起子agent对抗」)→ §4.2
- r208-r220 七轮对抗+门槛体系(开工门槛①②③/状态机 v1-v4/Phase A-B)→ §11
- r213-r220 各门槛实测数字(假阳率/污染率/转移穷举)→ §11 各小节

后续新裁定直接写独立 ADR,不再入 redesign 头部。
