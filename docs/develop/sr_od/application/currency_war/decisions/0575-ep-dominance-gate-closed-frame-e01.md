## 1. 背景与归层结论

- **病灶**(复盘 g_20260907_021326 p2r1,ADR-0572 §1.1 存档帧):锁线「列车同行」缺件断供(drought),店内**无锁线缺件在售**;旧过渡线仙舟 ×2 差 1 件即首档激活(仙舟首档阈值 t₀=3),爻光(仙舟 1 费 1★)在售被 `non_line` 拒。归层与 ADR-0572 §1.1 三层结论一致,本文辖其中**通道缺位**层的门关子域:P74 强开窗(E_rounds=inf)被 N2 判为注册表层面放行集≈空集,门关域(0 < E_rounds ≤ R_rem)才是该病灶的常态帧域——现行 9 个买发射通道枚举(ADR-0572 §1.1,方案审攻过未破)对该域同样零覆盖,禁买是结构缺位而非任何已证判据的输出。
- **本件不辖的相邻病灶**:g_20260907_025608 的锁线选择病(双王圣杯不可达而红 A 可达未选)= 锁线决策层(可达性闸归锁线帧),非线外买入授权层;该局只作「锁线可长期停滞、板面战力真空期金无转化出口」的场域证据。
- **宪法面**:与 ADR-0572 §1.2 同判——线外激活件的正账在 P20 只有方向级(数值倍数辖域严格限位面 1 过渡期),故本件**不放行任何破档支出**(合取钉死 loss_exact==0,§5.1 原子⑦);支配主张的全部成本侧通道闭式为零或结构上界,收益侧只作方向申报。00 §8 死因实证(A1「该买不买」21 局为最大单一主因)给放行方向提供死因级背书:drought 帧「金在库、战力在衰、店里有免费期权件」恰是 A1 族形态。

## 2. 命题 v1

**一句话**:锁线态**门关域**(0 < E_rounds ≤ R_rem,kernel 逐字单一源;E=0 完成态出辖,§3.1)帧中,线外 e0→1 激活件 x 在**租约合取**(§5.1,十二原子)下,买入 = 一张**租金为零、随时可退的免费期权**,弱支配禁买——误差项 ε = 租约成本流(§5.2,六项闭集,全部零自由参数);核心机制 = 可回收论证(N1 零件):1★ 全额退 + 同轮保护过期 + 筹资/M4 通道对被保件转化类降序放行 + 凑息回拉绝对跳过(自旋免疫)+ 轮界销账全通道恢复 ⟹ 金与席位的占用是**租约而非沉没**,锁线侧按需即时还原。

**名词约定**(沿 ADR-0572):门关域 = kernel `e_rounds` 三态中的「关」(0 < E_rounds ≤ R_rem;E_rounds/R_rem 逐字直调,本文不复写任何公式——ADR-0572 §2.1 口径单一源原则继承);e0→1 = x 使板面某未激活体系 f 的成员数跨入首档(n(f)+1 = t₀(f),注册表可算;x 多标签时任一 f 满足即可,每个合格 f 都是真实激活,v1 取并集语义,精确化归证明批);租约 = 「占用了金/席,但可按需原样退还」的占用形态,与「花了就没了」的沉没形态对立。**完成态** = E_rounds = 0(锁线缺件集空、线已成)的帧;**末角** = 终局清仓时仍未卖回的 c_x 沉没——租约唯一可能的不归还尾项(§5.2(v));**弹药效果载体** = bench_effect_qualified 为真的备战席件(后台效果使其被全部卖出通道拒入,现册仅小黑塔「星级供强」例外①语境生效)。

## 3. 与 ADR-0572(P74)的分工与互斥条款

两件是同一扇离线激活放行门的两半,按门态劈分:

1. **辖域轴 1(门态,构造性互斥;三态+完成态出辖)**:kernel `e_rounds` 三态加一条显式出辖构成帧的全覆盖——E_rounds = inf(强开)→ **P74 独辖**(其 §4 强域合取);0 < E_rounds ≤ R_rem(关)→ **本文独辖**(§5.1 租约合取);R_rem < E_rounds < inf(弱开)→ **两件一致 fail-closed**(谁都不放行,P74 §5 弱域占位维持);**E_rounds = 0(完成态)→ 显式出辖**(分键 `line_complete_outofscope`,不发射、不入双计数)。**与 ADR-0572 §2.3 的对齐注**:0572 的「关」定义含 0(E≤R_rem),本文相对其**显式收窄**而非静默分叉——收窄是证明所需(step-3 的租约论证以「锁线仍在竞争金/席」为前提,线完成帧无竞争可言,「锁线侧放弃收益」在该帧不存在);0572 落码批接线时 0 帧路由到出辖分键或保留其关域皆可,两件语义不冲突(本文更严)。互斥在四支划分下无交叠帧(T-103 H1 修正)。
2. **辖域轴 2(档位)**:e1→2+ 候选**两件一致恒禁买**(P20 明文 e1→2 净增量≈0 不外推;P74 §2.3 档位劈分与本文原子④同判同源)。
3. **发射槽同位**:两件共用同一离线激活放行槽——支配族后(C1 邻位后)、M3 前(ADR-0572 §7.2 同位),门态做槽内路由;单动作契约防双发。C1 名单互斥沿用(两件合取都含非 C1 名单原子,ADR-0569 名单单一源)。
4. **证明链互不借用**:P74 强域的 P̂_lock ≡ 0(强开窗结构真值)**在门关域为假**,本文禁止引用它;本文的租约论证不依赖强开窗(N1 明文),也不回填 P74 强开域——N1 修复路径已由 P74 v3 自行吸收(其索引行草案 v3 已带「锁线延迟≤1帧(可回收机制论证)」),本文不反向辖强开帧。P74 的 P38 单调性承重本文同样不需要:线外件不进锁线缺口集(持有 x 对 P̂_lock 无正贡献),本文收益侧只作激活价值方向申报,成本侧由租约闭式承载。
5. **开火性联动(N2 落码前置的执行形态)**:双计数对照即两件辖域划分的运行时审计——`strong_open_seen/hit`(P74 v3 §7.8 命名)**预期 0 命中**(空集命题申报);`lease_admission_*`(本文路由)**预期 >0**(drought 帧族常态,爻光帧形态为正例锚)。sim 批先行;任一预期背离 = 对应命题的证伪信号。判读规则五件(阈值与视界/0 命中降格条款/churn 退化判读/E=0 残余帧归属/owner 与回炉动作)钉在 §7.6(T-103 M3)。

### 5.2 ε 的可判定形式(回答「ε 是什么结构量」;零标定债,禁拍值)

**ε 不是拍出来的数,是租约成本流的闭集包络——每一项要么被合取钉死为恒等,要么是机制规则算术/注册表常数/结构常数:**

| 项 | 量 | 可判定形态 |
|---|---|---|
| (i) 买入帧息损 | **恒等 0** | 合取⑦直接钉死(t5_p1_false 全视界口径),不是上界是等式 |
| (ii) 持有期租金 | ≤ 1 金/帧 | 机制上界 = 息档宽(10 金/档,cap 截断 = 游戏息机制规则【注】;两轨迹金差恒 = c_x,1★ 面值 ≤5<10 ⟹ 至多跨一档 ⟹ 每帧息差 ≤1);帧级值 r_t = loss_exact(g_t, c_x, 1, Ī_t, cap) 单帧退化调用(同一单一源,无第二公式——F4 教训);合取⑦的全视界口径使**预测轨迹内租金恒 0**,实绩轨迹偏差帧逐帧可算;**可还原(通道条件性,T-103 L2 降格措辞)**:凑息回拉在保护期外对被保件恢复资格,只截断未来租金流、已计提帧不退,且回拉在 p1_blood_floor 帧整体停射(sell.py L153-154)——该帧租金价值趋零,包络不破 |
| (iii) 锁线延迟 | ≤ 1 备战轮 | 保护轮结构上界:筹资通道使义务侧金需求当帧还原(末位兜底),M4 腾席末位还原席位,凑息回拉绝对跳过是唯一禁卖面(轮界销账即恢复);visit 内实现时序(截断/排序末位)至多滑 1 帧 |
| (iv) 席位 | 1 槽 | P41③ 语义:空槽期 V_slot = 0(合取⑧下买入帧恒空槽);满栏期 = 被阻断动作净 EV,由 M4 末位还原截断 |
| (v) 末角 | ≤ c_x | 终局清仓通道未覆盖时 c_x 沉没(覆盖面 = 落码批核查项,覆盖则恒 0);c_x = 注册表面值【注】 |
| (vi) 租约冻结分支(T-103 M1b) | 持有期同名同星副本到达(EV/压库面不受 P60 排除集约束地购入第二张)→ x 变合并素材被四卖面拒入(G-S1)→ 租约冻结为合成进度对(两席不可退;第 3 张被原子⑩挡住、合成永不完成;终局清仓若不绕守卫则末角翻倍) | 原子⑩是**时点守卫非持有期不变量**——冻结态如实申报:残值 = 2★ 进度资产(方向非负),还原推迟至合并态消解或终局;观测分键 `lease_frozen_merge_material`;「禁他人购副本」属新授权面,本件出辖 |

账法总述:V(买) ≥ V(禁买) − ε,ε = 上表六项之和。**运行时决策门只消费帧级项(合取逐字),包络只进证明账**——框架里没有任何需要标定的自由数:档位算术是息机制规则【注】,c_x 是注册表【注】,g_t 是单动作循环真值金【注·对拍定谳,R197 症9 口径】,上界是结构常数(1 轮/1 槽/c_x)。P52 的「窗口局部 ε-最优」是本件主张的形态先例:本文不做全视界最优声称,只做逐帧弱支配 + 结构包络。

**「闭集」口径(T-103 §2.3)**:指成本通道**项集**封闭,不指包络总值有常数界——ε(ii) 是流量,偏差帧数先验无界(最坏可积累至 O(R_rem),与 §6 被拒「宽 ε=L」方案的最坏量级同阶);本方案的定性差别在**预测值恒 0(合取⑦)+ 每帧有界 + 通道条件还原**,非总值有界。

**包络-合取依赖表**(T-103 自选角度采纳;防未来修原子时静默破包络——单项原子松动不是「ε 变大一点」而是「缺一条通道」):(i)←⑦;(ii)←⑦ + 回拉/筹资/M4 对 x 的资格开放(⑫ 保证);(iii)←T3 载体生命周期 + 筹资/M4 转化类放行 + ⑥(等额退金);(iv)←⑧ + M4 放行;(v)←⑥+⑩+终局清仓覆盖面;(vi)←⑩ 的时点性(出辖申报);**「付费刷新挤占已消除」←⑪ 带内条款**(付费刷新 R1 预算门需 g−g*≥正预算,带内使该门结构性不可能过——带内松动则 ε 新增刷新挤占通道)。修任何原子必过本表。

### 5.3 支配链(门关域;step-3 换 N1 零件)

1. **金 principal = 0**:registry 1★ 全额退(sell_refund(1,c)=c,本批复算 1/2/3 全过)+ 回收通道在册(§5.1 结构前提)。
2. **息 = 0(买入帧)**:合取⑦等式零损。
3. **锁线侧机会成本 = 租约(核心步,N1 零件落地)**:门关域 P̂_lock > 0,买 x 的金/席与锁线**真实竞争**——但原子⑤使发射帧无在途在售缺件需求;**义务金/席位两侧**(缺件在售、金不足/席满):筹资/M4 转化类降序放行使需求**当帧还原**(0 帧闭合);**升级复活侧**(升级救活锁线、M3 批差 c_x,T-103 §1.3 补写):筹资触发面只挂义务买不挂升级批、凑息回拉保护期内绝对跳过 x——该情形保护窗内唯一还原路径 = 轮界销账后凑息回拉恢复资格,**恰贴 ε(iii) ≤1 备战轮上界(上界是紧的)**;凑息回拉绝对跳过 + 轮界销账使保护期外租约可还原;席位由 M4 末位还原。∴ 竞争的净成本 = 占用期租金流(≤ε),非沉没——P74 强域「P̂_lock ≡ 0 ⟹ 放弃收益 = 0」的承重在门关域不可用也不需要。
4. **收益侧(免费期权形态)**:买入落 bench 不上板,激活**不即时发生**——本件主张的形态是「租金为零、随时可退的期权,行权价 = 一次未来部署」:行权收益 ≥ 0(体系首档激活,P20 方向严格证成;门关帧多在 P2/过渡后,P20 数值倍数辖域外,按 ADR-0572 §4.4④ 同款降级为「机制直读+零成本」,不引数值);不行权则损失 = 持有 carry(≤ε 且随租约还原趋零)。免费期权弱支配不买。**兑现链申报(T-103 M4 卡点点破)**:锚帧形态(p2r1 部署面 run=6+placed=1,带 1 空位)行权走 P24 残余补部署——其候选经**散牌围栏(scatter_fence)趟**,锁线态对线外 e0→1 件是否放行**未核**;若不放行,`lease_admitted>0` 而 activation=0 = 「免费期权但行权不来」的囤新形态风险,以 `deployed_from_lease/activation_from_lease` 观测分键证伪/证实(§7.4);本件只证期权免费,不证行权,围栏放行核查 = 落码批前置(§7.7①,禁虚记已行权收益)。
5. 合取(§5.1)⟹ 买弱支配禁买至 ε(§5.2)。∎
