**属性**：量子

| 技能 | 说明 |
|---|---|
| 普攻 | 单体 25%生命上限量子伤 |
| 战技「缄默，幽蝶之轻抚」 | 消耗全队当前30%生命，单体25%+相邻15%生命上限量子伤；**不耗技能点**（代价是生命） |
| 强化战技「骸爪，冥龙之环拥」 | 死龙在场时替换战技：消耗除死龙外全队40%当前生命，遐蝶与死龙连携 15%+25% 生命上限全体两段；仍不耗点 |
| 终结技「亡喉怒哮，苏生之颂铃」 | **不消耗能量，消耗【新蕊】充满值**：召唤死龙（行动提前100%+遗世冥域：敌方全抗-10%满级22%）；死龙165速，3回合或血尽消失 |
| 天赋「掌心淌过的荒芜」 | 我方全体每损失1点生命 → 遐蝶+1【新蕊】；充满即放大；掉血时遐蝶与死龙伤害+10%叠3层（常态≈60%增伤）【攻】 |
| 秘技「悲鸣，赐死之先声」 | 主动开怪：进场直接召唤死龙+展开冥域+一次性大额新蕊 |
| 额外能力 | 「收容的暗潮」：我方治疗量100%转新蕊（死龙在场转死龙生命），溢出也计；「倒置的火炬」：血量≥50%时速度+40%；「西风的驻足」：死龙每喷+30%叠6层（自爆流最优） |

**资源与循环**：新蕊=全队掉血（战技烧血/受击/治疗转化）。**充能词条零收益**；技能点零消耗——点全留给辅助。场外被动「月茧之庇」：拥有遐蝶即全局生效，我方致命伤延后1回合。

## 二、推荐遗器与光锥（与原因）

**光锥**【官：米游社百科·光锥推荐表，推荐度★5★4】：「让告别，更美一些」(专武池,叠1) → 「多流汗，少流泪」(月卡,1张)。
（满级面板与完整叠影梯度数值见百科/`mechanics/light-cones.md`；渠道口径：专武叠1/4星叠5/月卡1张）

**套装**：哀歌覆国的诗人4件 + 谧宁拾骨地2件【官：套装文本+账号配置口径一致】
- 诗人4：量子伤+10%；**战前速度<95 → 暴击率+32% 且对忆灵（死龙）生效**【官】——遐蝶 92 速是刻意压的，一套解决主C与死龙的双暴击
- 谧宁2：生命上限+12%；**≥5000 → 暴伤+28%（装备者及忆灵）**【官】——生命模型+忆灵双吃

**主词条**：

| 位置 | 推荐 | 原因 |
|---|---|---|
| 躯干 | 暴击伤害/暴击率 | 诗人套补暴击后暴伤优先 |
| 脚部 | **生命%**（非速度！） | 全倍率吃生命上限；战前速度必须<95 |
| 位面球 | 生命%/量子伤 | 生命更稳（死龙面板同源） |
| 连结绳 | 生命% | 不走能量，充能绳零收益 |

**副词条**：暴击伤害≈暴击率 > 生命%。**不堆**：攻击%（零倍率）、充能、速度（战前刻意<95，战内靠 A4 +40%）、效果命中、击破。
**转模与转化上限**：无转模行迹。练度评价看生命面板+双暴；毕业参考【攻：Prydwen】HP7000-8000+/暴率80-100%（含诗人）/暴伤200-220%+。
