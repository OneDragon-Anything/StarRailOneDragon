# 打法卡(我们确认过的 comp 实战知识)

> **本目录 = 经我们整理、确认、用于实战体系调优的单套 comp 打法知识**(层的归位决策见 ADR-0212)。与 [../../sources/](../../sources/)(外部原文)相对:打法卡是我们的消化版,带证据分级,随版本与证据原地更新。
> 结构化字段(停留点 / 星目标 / 核心装备 / form_tiers 等)单一源 = `cw_comps.py COMP_LIBRARY`;打法卡只写字段承载不了的(打法叙事、入场/退场信号、counter 应对、装备分配叙事)。**改 COMP_LIBRARY 不触发改卡义务** —— 卡是游戏知识,不是字段镜像。

## 策展规则

- **有可提炼的打法知识就建卡**:知识源 = sources 攻略转录 + 注册表校准注释(plaza 784 篇对拍);两者皆无的 comp 不建卡(不产空模板)。
- **证据升格是主线**:每条知识标 `[先验:攻略]`(抄自转录未验)/ `[社区:plaza]`(784 篇 V4.4 玩家帖统计)/ `[实战:ADR-NN]`(遥测/复盘证据)。先验 → 实战升格 = 沉淀;整局实战接触后补齐卡内缺口(站位/退场信号等)。
- 系统侧语义(select_comp / pivot / commit / 站位驱动)在 [strategy/02](../../../../develop/currency_war/strategy/02_comp.md),本目录不写 bot 机制。
