# 战斗机制核实(伤害乘区 / 星级 / 血量星 / 连胜)

> 战斗侧机制的核实结论。来源:V3.7 必修一转录交叉核对(原 sources/V3.7_公共_核心机制,存档已删[eb9c72a1],git 历史可查);数值属 V3.7 口径,结构性规则(乘区结构/独立计算)视为跨版本稳定,版本大改时重核。证据分级见 [README](README.md)。

## 1. 伤害公式三乘区

角色伤害 = 既有伤害公式 × 三个货币战争新乘区 [攻略·必修一]:

- **前后台强度**:站前台吃「前台强度」、站后台吃「后台强度」(**只看站位,与角色的前后台定位无关**);倍率贡献 = 强度值 × 1%(前台强度 500 → 伤害 ×5)。
- **伤害征服**:独立乘区(类似增伤,但独立结算)。
- **幸运一击伤害征服**:「幸运一击」= 第二层暴击率,该段伤害触发幸运一击时此乘区才生效。
  - 幸运一击与暴击**独立计算、互不影响**:显示「幸运」= 仅幸运暴;「暴击」= 仅暴击;「幸运暴击」= 双暴;无字 = 双未暴。
  - 幸运一击暴伤基础 **100%**(普通暴击伤害基础仅 50%)→ 有条件把主 C 幸运一击率堆满 + 至少一件暴击装。

**稀释排序**:前后台强度稀释最严重;伤害征服 + 幸运一击稀缺、提升幅度大 → 优先堆后两者 [攻略·必修一]。

→ 解释装备注册表里「火力风暴潮(伤害征服)/ 幸运一击装」为什么是各直伤主 C 的 key_equips 断层第一。

## 2. 星级收益

- 星级提升**技能倍率 + 拐力数值**(速度、盾/奶量)[攻略·必修一]。
- **三星五费特效 ≈ 无敌**:2000 前后台强度 + 300% 速度征服;其他费用三星中规中矩 [攻略·必修一]。

## 3. 血量 → 星(段位星数)

- 队伍血量 **70 → +3 星,40 → +2 星**;血量掉完不加星也不掉星 [攻略·必修一]。
- **HP 只在节点战斗失败时扣**(用户口述 2026-08-22,实跑多局确认:战斗胜利的节点
  HP 不掉,哪怕打得艰难;战斗失血是「节点没打过」的代价)。未完成战斗关卡 →
  按节点位置 + 挑战进度扣血(节点越后、进度越低,扣越多)[攻略·必修一]。
  → 策略含义:HP 曲线 = 战斗胜负率曲线;HP 下降快 = 阵容战力不足的信号,
  不是「慢慢流血」——应急/追赶的触发判据都应按「连续失败」理解。
- **遭遇节点是高危节点(用户口述 2026-08-23,最高权威)**:遭遇三/遭遇四
  的敌人战力要求**甚至比 boss 高**,打输很正常(实跑:局15 r7 遭遇
  -28 —— 方向已立+HP 90 满血仍大掉)。策略含义:
  ① 遭遇前的备战轮应按「boss 级甚至更高」强度补强(不是普通轮);
  ② 复盘遭遇轮的掉血不能归因于「方向没立好」——遭遇本身可能就是恶局;
  ③ 模拟器战斗模型:遭遇轮应单独分档(对齐 boss 或更高)。

## 4. 连胜经济

- **无连败补偿**(vs TFT 有)→ 维持连胜至关重要 [攻略·必修一]。
- 连胜从头到尾 ≈ 多 **100 金币**收益;吃满连胜需 **6 连胜以上**;**奖励关不计入连胜数**(✅ 已裁决 2026-08-26:run13 实机 r2 奖励结算屏 `连胜×0`,r1/r2 全过后计数为 0;sim 的 streak 重放口径与之一致;奖励轮是否照发连胜金待 r3 后结算屏补充观测——批⑱检查器双口径在册)。连胜 vs 利息的取舍边界(A8 高难保血优先)→ [economy §6](economy.md)。

## 5. 练度边界

- 老乘区(双爆/增伤)几乎无稀释,只能靠光追/仪器练度提供;强行玩没有的角色 ≈ 只发挥 **60-70%** → 选自己有完整 box 的阵容 [攻略·必修一]。

## 6. 原文细节补记(必修一未入正文的余量)

**以下为 2026-08-24 从 git 历史补记;攻略存档已删[eb9c72a1],此为仅存记录;信源=过期攻略存档(版本 V3.7,已被 V4.4 实测部分推翻),与官方 API 深读结论(final_comps/plaza_methodology)分立,勿混写**:

- **难度 → 怪物血量**:怪物血量随难度**指数增长**,每 +1 难度较上一档 **+5.2%(×1.052)**(UP 自拟合 R²>0.999);即 `base × 1.052^difficulty`、每 +8 难度 ≈ +50% 血。推论:低难度怪基础血量少,难度 +18 也膨胀不多 → 敢拿高阶投资策略;高难度血量爆炸 → 高阶策略强度追不平膨胀(与 economy §9 品质口径联动)。
- **翁瓦克必备(生存节奏)**:高难不带翁瓦克跑不赢怪第一轮(「怪第一轮直接全队走飞」);辅助优先风套/翁瓦克抢行动值;A7/A8+ 生存压力倍增,把生存位当第二核心养(出满生存装)。
- **段位结构**:8 段位 A1–A8,最高 A8 二十星;拿满 4000 星琼奖励只需打到 A5 + 刷任务;A8-20 boss 至少 80 亿血(V3.7 口径,A830+ 已膨胀至 200 亿起,见难度攻略补记)。
- **升级节奏原则**:熟知阵容核心角色,停留其费用所需等级(如 3 费核心 @7 级)刷够星级再升;等级 = 最低上场人数(10 级 = 10 人口)。(各级找牌口径已被 economy §2 米游社 D 牌期望表取代,以那边为准。)
