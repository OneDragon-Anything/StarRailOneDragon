# 月度限量兑换 app · 流程走查（迭代沉淀版）

> 沉淀自探索目录（2026-11-13 走查），自本目录起为单一源。本文件是事实记录；编排设计稿在 application-flow.md。

## 1. app 四段式结构

| 段 | 内容 | 实现要点 |
|---|---|---|
| ① 导航段 | 从当前画面走到玩法画面 | **简单档**：先统一返回大世界（`BackToNormalWorldPlus`，任意画面可退），再从大世界前往玩法画面。**精细档**：入口先识别当前画面是否在导航路径上（中断恢复）。本 app 选**简单档**（流程短、一条龙起止恒为大世界、单品 op 已实机验证） |
| ② 玩法段 | 真正的玩法操作 | 本 app = 按优先级循环单品兑换（购买 op 自带读数与月限判定，无独立 probe） |
| ③ 领奖/兑换环节 | 玩法后是否有结算领奖 | **无独立领奖段**——兑换即玩法本体，「获得物品奖励弹窗」已在 `ExchangeShopBuyGoods` op 内处理 |
| ④ 返回段 | 返回大世界 | `BackToNormalWorldPlus` 收尾，保证一条龙内 app 间在大世界干净交接 |

## 2. 四段映射（走查核实后定稿）

```
① 导航段: OpenExchangeShop（内部: 画面判定 → 开手机菜单 → 点 入口-商店 → 点 tab-常驻商店）
② 兑换段: 开启项按优先级循环 ExchangeShopBuyGoods(goods, count=None 拉满)
③ 领奖段: 无（获得物品弹窗在兑换 op 内）
④ 返回段: BackToNormalWorldPlus
```

现成 op 复用标注（逐段）：
- ① `OpenPhoneMenu`（复用，内部含兜底回大世界）、菜单入口/商店 tab 点击锚已建档（本段新 op `OpenExchangeShop` 封装，见 operation-flow-1.md）；`BackToNormalWorldPlus` 由 `OpenPhoneMenu` 内部按需调用，app 顶层只在段④显式用。
- ② `ExchangeShopBuyGoods` 全覆盖（内部自动调 `ShopSwitchTabOp` 切余烬 tab，app 无需单独切 tab 节点）；`ShopSwitchTabOp` 锚修复为前置件（见 §4.1-1）。
- ④ `BackToNormalWorldPlus` 全覆盖。

## 4. 走查现场记录（2026-11-13 08:55-09:10）

### 4.1 建档/框架缺陷（实现前置件）

1. **tab 选中态模板互串**：`tab-星芒兑换-选中` 与 `tab-余烬兑换-选中` 两模板任何时候同时命中（选中 1.0 / 未选中 0.998）——模板裁的是白字文本区，亮度归一化后白字灰字相关性 ~1.0；真正的选中判别特征（tab 底部高亮下划线）不在模板里。`ShopSwitchTabOp` 的 until 验证因此空转。**修法**：两模板重裁为含高亮下划线的区域，实拍裁源 = `.debug/sr_od_mcp/screenshot/screenshot_20261113_085952_575024.png`（星芒选中）/ `screenshot_20261113_090339_585937.png`（余烬选中），阈值 0.7 可干净分离。**不修则真实兑换的 tab 切换无验证，属实现前置阻断项。**
2. **大世界无 id_mark（原生设计，非建档漂移）**：normal_world.yml 从未设 id_mark，「无 id_mark 画面无法精准识别」→ 路由图不支持从大世界出发。大世界识别走专用函数 `common_screen_state.is_normal_in_world`（右上角色剪影模板 ui_icon_01，阈值 0.4）。用户裁定 2026-11-13：大世界暂不补 id_mark，维持现状；app 导航自依赖 OpenPhoneMenu 链路。
3. **左上手机图标手点无效**：框架标准开菜单路径 = `OpenPhoneMenu` 的菜单键（op 内实现），app 照用。

### 4.2 玩法知识（随版本变，收尾回填 docs/game/screens/store.md）

1. 三件套双渠道在售：星芒 tab 也售专票 20/通票 20/足迹 50（星芒），各「可兑换: 1/1」+版本倒计时；余烬 tab 专票 90(160)/通票 90(160)/足迹 60(125)，限 5/动态/1。用户星芒余额仅 4，余烬 41562。
2. 期限窗口=版本周（倒计时 17天18小时 ≈12-01，本期恰与月初重合，下期才能分辨口径）；余烬 tab 另有周限档（培育材料 40/40，周一刷新）。app 用 MONTHLY 运行记录 + op 动态读 X>0，两口径下都稳健。
3. 卡面角标体系：可兑换 X/Y → 已售罄（额度尽，灰卡滞留末尾）/ 已达上限（星芒满星魂卡）/ 未解锁（信用点卡带锁）。
4. 菜单→商店过场：实测 ≤9s（建档记 8-10s，维持宽等待）。

### 4.3 时序预算

导航 ~15s + 切 tab ~3s + 每项兑换 20-40s + 返回 ~10s ≈ 全流程 1-2 分钟。
