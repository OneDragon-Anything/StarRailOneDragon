## 定义(用户口述 2026-08-23,最高权威)

**过渡阵容 = 一级羁绊就有较高伤害的 combat 羁绊的组合**——这类羁绊
凑出第 1 档就有真实伤害/召唤物,不吃星级不吃高人口,恰好匹配位面 1
人口被等级压死(lv5-6≈5-6 人)的现实。**最终阵容**要高阶羁绊或多羁绊
叠合(7+ 人口=后期经济),位面 1 做不到也不该做。

## 升级路径(加法不换件;任一步断了停在当前形态照样能打)

```
空窗期: 四体系均未凑成(开局常态)——手上有什么羁绊先上什么,尽量提高
      战斗力(口述 [31] 扩展,2026-08-24;凑最终阵容的未成型期同理)
开局: DOT2(任意2件,开局即战力,门槛最低)
     → +藿藿+爻光+饮月 → 仙舟3 成型(核心三人组到齐)
     → 继续买三月七 → 列车2 挂上(混挂:仙舟3+列车2 同时生效)
     → +姬子·启行+星期日 → 列车4+领航员(继承系,撑到 Final)
     → +姬子·启行 → 切终局线(领航员羁绊:复制三月七首件装备=反震启动)
```
列车可先于仙舟成型(组合判据彼此独立);DOT2 层随意(谁在场买谁)。

**列车4 = 升级层不是过渡起点**(Early 仅 5.1%,Final 40.7%):
- 构成 100% 固定:姬子·启行+星期日+三月七+饮月(33/33 帖)
- **领航员×1 同时激活 100%**(姬子·启行专属:选列车角色获其流派+
  复制首件装备=反震流启动器)——它是列车4 体系的真核心
- 前置:升到 3 费购买力+姬子·启行到手(开局凑不出,故 Early 只 5%)

  是**副产品**——构成与 DOT 挂件层同班底(椒丘=DOT+减益/艾丝妲=DOT+
  学者/千冶·刃=星核+减益),买 DOT/仙舟件顺带激活;49 帖「四种都不含」

  玩法稳定通关后再考虑;本文档不保留其内容,防误采——曾由攻略「五家」

## 直通终局线(自带入场策略;严格说不算"过渡阵容",见裁定)

> **归类裁定(r158)**:过渡阵容 = 为通 P1 搭的临时战力(用完换/升级)。
> 圣杯/希儿这类"直通线"是**终局线**(用到通关),不是过渡阵容——它们的
> 前期战力恰恰来自上面的通用引擎池。直通"省"的是换血成本,不省前期。
> 分节保留在此文档是因为入场策略(信号/留牌/时序)与过渡体系的消费
> 强耦合,拆开反而读不懂。
