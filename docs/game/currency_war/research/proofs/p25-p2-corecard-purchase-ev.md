## 命题(v2 形态)

设位面 2 中段备战帧满足四个前提(即设计件 `w757` REPORT §三的授权辖域):

- ① 线已锁定(意向 locked,pivot 已收敛);
- ② 板面存在形态缺口(未达「本线核心羁绊 2 档 + carry 在板」判据,stage_transitions Q5 口径);
- ③ 金在溢余段(g ≥ 50,贴线带见 §边界点与分带核验);
- ④ 锁定线核心卡(或其凑档件)出现于商店,面值 C_buy。

**判据(P48 统一式实例化)**:购买动作 a(花 x=C_buy)获授权 ⟺

```
V_a > ρ·(C_buy/Ī) + L(g, C_buy, R, Ī) + ΔW_trunc(a)
```

各项定义(门①补全,v2):

| 项 | 定义 | 单一源 |
|---|---|---|
| V_a | 动作 a 的期望价值 = 死亡敞口压降:V_a = λ_death(P桶旧, 视界)·(g+Φ) − λ_death(P桶新, 视界)·(g−C_buy+Φ),其中 P桶新 = 核心卡入手后板面战力桶,Φ = 未来纯金流(基础奖励+息流,P51 口径)。**消费形态=区间敞口比较,禁边际引用**(λ_death 为视界累积危险率,整窗归因;P51 必修 3) | P51 §4-B/§5-11 |
| ρ | 金→进度边际价值率(每金折算的升级后状态每轮价值);门假时 ρ=0([17] 全域) | P48 A7(🔴 待标定 ρ 口径) |
| Ī | 净收入率(金/轮,A5 现算,含基础奖励+连胜档+息) | P48/P47 |
| L | 息档损失(g,d,R,Ī 双轨迹递推;d = min(⌊g/10⌋,5) − min(⌊(g−C_buy)/10⌋,5) 闭式可先算) | P47 |
| ΔW_trunc(a) | 选 a 相对囤积的死亡截断敞口差(把 x 花掉 vs 留在账上被 λ_death 销毁的敞口差;P51 §F.3 底线口径) | P48 修复批/P51 |
| C_buy | 卡面值(金),直接进 ρ·x/Ī 项与 L 项的自变量 | 注册表 cw_chars |

**待证目标**:在四前提下(全息带),V_a 的敞口比较严格成立;且「持息(不买)」对照下,持息侧的 ΔW_trunc(不买)> V_a 侧损失的量级结构使买严格优。**辖域分治结论(见下节)**:该目标的证据支撑在 3 费与 4-5 费核心上不同源——4-5 费另有再遇账论据,3 费完全靠判据逐点账。

## 辖域分治(3费 vs 4-5费;v2 新立,替代旧版统一「弃购代价极高」表述)

再遇账注册表直算(`cw_shop_odds._refresh_dist`,脚本 `.debug/temp/currency_war/redesign/p25_calc.py` 可重跑;入库版随标定回填进 `tools/cw/proofs/`):

| 费档@等级 | 单刷出现率 q | 再遇期望 1/q |
|---|---|---|
| 3费@lv7 | 0.1357 | **7.4 轮** |
| 3费@lv8 | 0.1097 | **9.1 轮** |
| 4费@lv8 | 0.0764 | 13.1 轮 |
| 4费@lv9 | 0.1031 | 9.7 轮 |
| 5费@lv7 | 0.0055 | 180.4 轮 |
| 5费@lv8 | 0.0166 | 60.4 轮 |

- **4-5 费核心**:再遇窗口数十至上百轮,位面 2 剩余节点内大概率不再现——弃购的真实代价极高([22]③/P1 的量化支撑**只辖此域**)。该账进入 V_a 的供给侧(本次不买 → 未来同窗口重开概率低 → 期权价值折损),作方向论据。
- **3 费核心**(恰是局 3 希儿实反例、恰是 P2 概率窗主力费档[3费概率峰 0.40@lv7]):再遇期望仅 7.4-9.1 轮——数轮内高概率自然回。**弃购的供给代价小,购买判据完全由 §命题 的统一式逐点账承载**(息损 L vs V_a 敞口差)。旧版把 5 费数字安到 3 费头上(60-180 轮)使 3 费域论据虚增一个数量级——本版勘误后,3 费域的符号判定是**决定性待标定格**,不得靠再遇账预支方向。

## 已有的方向证据(逐条,机制级;数值锚已废项降级为方向注记)

1. **找件压血的方向(P12 方向注记,数值禁引)**:P12 数值面已废(hp_to_gold×L 形态违纯金流),但其方向注记保留——「找到核心件压低后续掉血」的收益侧方向成立;本版的收益通道改为 λ_death 敞口压降,与 P12 旧收益侧同向(战力到账 → 死亡危险率降),但**不经血换算、不引其数值**。
2. **再遇账(注册表直算,见上表)**:4-5 费域再遇 60-180 轮——弃购代价极高只辖 4-5 费核心;3 费域 7.4-9.1 轮,该论据不成立,转逐点账。
3. **stage_transitions Q4(姬子线内对照)**:核心 Early 到手组全板 E→F 留存 0.83 vs 不在手组 0.43(n=815 帖)——「核心到手使板面围绕它加法生长」的**间接**旁证(留存率口径,非胜率差):支撑「P桶新 > P桶旧」的桶迁移方向为正,方向性强(非「无疑」)。
4. **溢余段成本下界(P11)**:g>50 段决策成本下界=0——**全息带限定下**买牌成本侧只有面值 C_buy 与零息损(d=0 ⇒ L=0);贴线带息损 ≠0,由 §边界点与分带核验 逐点算。

## 卡点(为什么还不能立「已证」)

**Δλ_death(核心卡到手引发的桶迁移危险率差,位面 2 语境)未标定**——λ_death 现有分层表(P51 §4-B-2)是桶×节点粒度的发生率直测,「单张核心卡 1★/2★ 到手 → P桶迁移」的**条件危险率差**没有实采;V_a 的符号与量级均悬置。次级缺口:①C_buy 与凑档件版本(买 carry 本体 vs 买放大器)的桶迁移不同,需分开标定;②ρ 口径未定(P48 A7)——中间带式右端第一项暂不可算,先在 ρ=0([17] 全域门假语境)与 ρ 上界两档间做区间判。

## 边界点与分带核验(义务性内容;判据式逐点)

消费方(w757 v2+)授权判据为分带结构——**证成时必须按 g 分带给结论,禁止单点结论覆盖全 g 域**:

| 分带 | 定义 | 证成义务 |
|---|---|---|
| 全息带 | g − C_buy ≥ 50(花完仍满息,d=0 ⇒ L=0) | 主命题直接覆盖:V_a > ρ·C_buy/Ī + ΔW_trunc 的敞口比较 |
| 贴线带 | 花完 ∈ [45,50) | **逐点算**:息损账面 L(d·R,p47 递推;[11]/[22]④ 凑息账同判)vs V_a 敞口差,给出每 C_buy 档的符号表——**g=50 边界点是必核验点**(局 3 p2r2 实反例:希儿 3 费,g=50,花完 47,d=1,息损 1 金/轮;消费方判据已按「T4≥50+贴线带凑息账」放行该帧,本命题若判负则回炉消费方判据)。**3 费格是符号表关键格**(再遇账不辖,见 §辖域分治),标定与逐点算优先级高于 5 费格(5 费格有再遇账先验占优) |
| 破息带 | 花完 < 45 | 不在本命题辖域(消费方归加急层/保留金下限判据),只须声明辖域排除 |

分带结论与 Δλ_death 标定同时回填;单篇状态改「已证」的前提=三分带各有符号结论(或显式「不可判定带」声明及理由)。
