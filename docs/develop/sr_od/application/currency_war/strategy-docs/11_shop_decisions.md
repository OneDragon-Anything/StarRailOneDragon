## 2. 升级决策（概率主轴五臂 + 单帧原子发射；判据单一源 = `criteria/levelup.py::upgrade_gate_verdict`）

- **触发 = 五臂并集**（`upgrade_trigger`，任一命中即触发；概率账与人口位同帧满足 → 单次判定并集发射）：
  1. **arm0（升级不足机制臂）**：上阵人数需求（need）> 当前等级——等级落后于板面人口需求的朴素判据，未锁定期亦可触发（目标阵容缺件集在未锁定期为空 ⇒ 名义在列实际仅锁定后可触发的臂以锁定线缺件集为载体，arm0 不依赖锁定态）。
  2. **概率账（主判据）**：辖域 = **锁定后 ∧ 第二位面已启动双条件**（P1 硬规则锁定子局不消费——概率账收益 = P2 起未来刷新期望改善，P1 视界内不消费）；载体 = 锁定线缺件集（未锁定期候选集求和为自认放大向，**未锁定期概率主账不消费**）。主式：升一级后「找到缺件的期望刷次下降量」× 单次刷价 c_eff（画面实读）> 升级整级成本 + 期间息损（P47 双轨迹递推 loss_exact，输入面与刷新账同源）；量化地基 = `expected_refreshes`（P40）+ 概率表 + 升级门槛表（`XP_TO_NEXT_LEVEL`）+ 买经验单价（画面实读）。缺件集聚合口径 = 单核代表（缺件集中费用档最低者，与停留目标同序）【拟·LEVELUP_MISSING_SET_AGG，求和/瓶颈切换候选随标定值注入批登记；未决前一律单核代表，禁混用】。
  3. **人口位（arm1 三元谓词）**：板上位置坐满 ∧ 有能进当前阵容羁绊体系的单位在备战席等待上场 ∧ 边际贡献 > 0（[33]；羁绊档已满的零贡献单位不触发）→ 升（战力当轮兑现，不受攒息约束）。

## 3. 刷新决策（三段式星级目标驱动；判据单一源 = `criteria/refresh.refresh_warranted`）

## 8. 机制突变层（resolved input 原则）（原 03 §4.10 并入）

**原则**：决策机器**禁止直接读基础机制事实**——一切机制输入经「基础值 ∘ 已激活突变」解析后消费（**resolved input**）。突变登记 = 知识层注册表 INVEST_MUTATIONS。

- **登记三分态**：resolved（可解析）/ abandoned（用户裁定放弃建模——desc 无数值一律放弃不实机查，保可见性不进 resolved input）/ 未登记（=知识缺口，采集后入表，不静默忽略）。
- **解析语义结构**：每突变登记为（操作数，合成律[min/max/add/互斥]，状态依赖[计数器/条件]，时效[永久/计数窗/条件移除]）；同操作数多突变按合成律合成；互斥型登记位声明（首个生效，后续 suppressed）；异构操作合成序按操作数分层（override 先于 multiply，层内按注册序）；未登记态运行时检出 = 保守降级（按基础值消费 + 告警，不静默）；消费点读合成后的单一 resolved 值，禁止各机器自选合成方式。
- **多源声明**：突变源不止投资卡——角色固有技能（银狼升费）、任务奖励皆可改状态；INVEST_MUTATIONS 为多源效果突变登记，适用范围不限于投资。
- **突变分类框架**（按改写的操作数）：经济参数族 / 收入与利息规则族 / 概率表族 / 池构成族 / 板面谓词族 / 商店行为族 / 难度与节点族 / 阵容定义族 / 任务系统族 / 工具发放族 / 战力族（~155 条——不进经济 resolved，E1 定价走权重/克制通道）/ 资产发放族（~60 条——非金流，E1 定价走组件缺口通道）。
- **池结构突变语境**（消费 P38/P40 时按语境重算）：银狼升费（按当前可见档取 q）/飞光·映月变费/晋升名额/**专家解锁入池**（专家顾问初始**不在**基础牌库——不参与普通商店招募，名单权威 = 注册表 `Character.is_expert`；对局中经投资环境/投资策略/装备（分身墨镜族）通道解锁后按名并入专家副本数进入商店发牌空间，容器权威状态 = `gs.unlocked_experts`，解锁写端 = 获得链 advisor 道与装备通道；v 值静态口径 = 基础池排除专家，解锁名不进静态分母——偏差 ≤1/13 量级接受）/黑塔纪元（216 张特殊池，P38 全模型降级声明）/昔涟诗篇类非 5 槽商店（SHOP_SLOTS 时变）。**池构成硬突变 ⇒ cw_shop_odds 概率表/V_comp 表/p̄/E[refreshes] 整体重生成，不得沿用突变前表**。
- **E1/E2/E15 选择决策的机制升级**（定价框架；判据状态见 13）：三选一评分 = 台账价值 + 突变价值（对 resolved 输入做差分定价）+ 战力账（→权重/克制通道）+ 资产账（→组件缺口通道）+ 难度账（→环境通道）+ 信号分层（A3）；数值走知识登记与标定批，禁拍值。
