## Context(为什么)

CW 有两套互不通气的 P2 损血模型,差 5×:

1. **DP 层**(`cw_horizon`):确定性递推吃 `P2_LOSS_SCALE=6.0` 折中(≈15.0/节点@b=2,CI 下界压必死区)——W371 A1/A2 实证其病灶:每战确定减血把「输了才掉血」的机制拍平成「必输全额」,好板也被悲观灌死(值函数坍缩病理的根),弱板 drop 高到激励清零;
2. **阈值层**(`cw_first_passage.PLANE_LOSS_SCALE={1:1.0,2:1.6,3:1.9}`,0174 v1 弱板先验):μ=tier 先验×位面乘数,喂 `effective_hp_threshold` 五处消费点,锚已过期(「P2 弱板掉 19/节点」的无条件读法在 W371 复算下失真),P2 病灶带血线系统性偏松,且该链无任何锁。

W371 判读:5× 差=语义差为主(确定性期望 vs 分布模型)+阈值层值过期为辅——**直接拉平数值是症状修法**;治本=两态底座落地后双源天然合一。W375 双源重标定已产出两套 estimand(无条件期望 10.16/12.00/15.50 + 条件败面 12.77/13.33/15.50),批 A 已注入 p_win 表——消费口径定稿的前置全部就绪。

## Decision(逐条)

1. **DP 两态化**:`_hp_loss` P2 分支改 `drop(b)=(1−p(rung(b)))·L_cond(kind)`——胜率=registry `p_win_p2_by_rung` 在 b∈{0,1,2} 锚点分段线性插值(b>2 钳 rung2,与表 k3 折叠同口径;DP 板强连续坐标对 `_settle_rung` 离散档的近似,档界附近可差一档,期望差 ≤3,声明);条件败面=registry **新字段 `p2_cond_loss_table`**(normal 12.77/encounter 13.33/boss 15.50);kind=DP 无节点型自由度,boss 端槽(日程位面末槽,ADR-0368)用 boss 档,其余战斗槽按 `_P2_NODE_TEMPLATE` 战斗构成混 normal+encounter(boss 档不进混合防双计)。`P2_LOSS_SCALE` 常量与 difficulty_scale P2 分支退役(P2 槽误用 difficulty_scale 即 raise,防静默吃 P3 曲线)。
2. **双源合一(阈值层)**:`_loss_dist` μ 的 P2+ 分支改两态同构 `(1−p(rung(tier)))·L_cond_mix`(rung=board_tier 0-3 钳 0-2);plane≤1 保留 HP_LOSS_PRIOR 现档(P1 不走 P2 标定,精确零漂移);P3 不在标定域,别名 P2(W405 位面维别名先例)。`PLANE_LOSS_SCALE` 删除,退役锁=not hasattr。**边界声明(「5×=语义差为主」的落点)**:阈值层 estimand=每节点无条件期望掉血的分布模型(CV 0.5 三点离散,喂首达卷积),DP 层 estimand=确定性期望递推——共用同一标定(胜率表+条件败面档)但函数不同,数值对齐 ≠ 函数同一;阈值层自此不持有独立位面乘数自由度,位面维全部来自 registry(版本锚见条 4)。
3. **W375 重标定覆写**:`p2_node_loss_table` = 无条件期望三档 {normal 10.16, encounter 12.00, boss 15.50, reward 0}(挂账自 W412 §③;旧「删失口径条件常数暂抄」20.05/16.67/26.71 退役)。该表**不进任何行为公式**——语义=无条件期望的**标定自洽锚**(对齐锁见条 7);行为公式(两态决策层与阈值层 μ)一律吃 `p2_cond_loss_table`。**两表非双源**:无条件期望 vs 条件败面是同一 W375 标定的两个 estimand,按消费语义分表命名。
4. **版本披露(第三维)**:registry 新字段 `p2_loss_calib_version=1`——P2 损血标定家族(两表+p_win 表+两态递推形态)任一变动必须递增并随批重锁;独立于 `COARSE_CALIB_VERSION`(sim 粗模型)与 economy 收入口径版本;sim 台账 manifest 不承载(cw_sim 禁触,披露面=registry+锁,边界如实声明)。
5. **rounds_alive 幅度源定稿**:消费表改 `p2_cond_loss_table`(无条件期望当条件常数用=系统性低估 1/(1−p̄) 倍,非保守方向,不采)——开关关 M1a=条件败面档常数、开关开=×(1−p_win),两开关仍默认关,零漂移锚结构不变。
6. **阈值链五消费点**(cw_economy 止损门 / cw_evaluate HP_DISTRESS+保血 / cw_comps 保命转型 0.75× / default_strategy 危机+生存 0.75× / cw_plan 刷新帽):本批不改消费点,补静态源级锁(五处全部经 `effective_hp_threshold(state)` 单口消费,无旁路裸算)+ P2+ 现值单帧锁(此前该链无锁,漂移无人报警)。
7. **三表对齐(检查点①裁决,落显式对齐锁)**:「同 rung 恒等式 无条件期望 =(1−p(rung))·条件败面」在 `p_win_p2_by_rung × p2_cond_loss_table × p2_node_loss_table` 三表间**不成立也不应成立**——三表坐标与样本窗均不同:
   - `p_win_p2_by_rung` 是 **rung 坐标**(同战斗节点型内按板强成型度;W346 sim Δ池 battle 样本,0.016/0.413/0.657 单调升=H3 阶梯);
   - 两损血表是 **kind 坐标**(节点型桶;W375 实机深层局样本)。两表比值 1−无条件/条件 隐含 {normal 0.204 / encounter 0.100 / boss 0.000}——这是**各节点型桶上的板强混合平均存活率**,其递减序=节点型难度序(遭遇难于普通战斗、深层局 boss n=4 全败),与 ADR-0424 拟合伤害斜率(遭遇 −23.48 vs 战斗 −12.06)同向;**这是 kind 间难度差,不是 rung 阶梯反向,与 H3「同节点型内 p 随成型单调升」无矛盾**——检查点复算把 kind 桶比值按 rung 序映射属坐标错配,非标定矛盾;
   - 恒等式本身还要求 E[损|胜]=0 严格且桶内板强分布与 p̄ 一致,W375 口径(净负记 0/hp≤1 不删失/死亡行全额)不保证,只具近似意义;
   - 落锁:桶均存活率值锁 {0.204/0.100/0.000}(漂移=重标定随批重锁)+ kind 难度序锁 + **混表禁令静态锁**(三处两态消费文件代码行不得读无条件表;无条件表进行为公式=把桶均存活率错当 rung 胜率,坐标错位=非保守方向)。

## Considered Options

- **直接改 PLANE_LOSS_SCALE[2] 追 DP 层(W412 列为不推荐,弃)**:两 estimand 不同,拉平破坏分布模型语义(强板被打回无谓血恐慌),症状修法。
- **两态消费直接吃无条件期望表(弃)**:`(1−p)·无条件期望` 相对真两态系统性低估损血 ×1/(1−p̄)≈1.6(非保守=P2 存活高估=门偏松),且 W375 条件败面三档现成,无理由引入已知偏差。
- **只退役声明不合一年后做(弃)**:批 A 已给两态通道,消费口径定稿的全部前置就绪,拖批=双源带锁继续漂移。
- **阈值层也走 boss 分档(弃)**:first_passage 只有 plane 粒度无槽序,L_cond_mix 按 P2 节点模板战斗构成加权(boss 含 1/6 权重)是该粒度下的诚实近似,边界已声明。

## Consequences

- **行为变化(本批目的,全部落 P2+)**:DP P2 强板 drop 15.0→4.5(强板悲观/必死区治本,CI 上沿挂账随两态化一并退役——确定性折中前提不再存在);P2 阈值中板 40→74、强板顶 2.0 夹界 80、弱板(tier0)不上浮(P2 无条件期望 13.2 < P1 弱板先验 14,方向反转是标定事实);ADR-0176「强板 ratio→1」主张随 v1 先验退役。
- **P1 零漂移**:P1/P3 损血、first_passage P1、阈值 plane1 逐位不变(代码路径锁);DP 解的 P1 槽姿态可能经值函数(P2 未来存活价值)间接漂移——这是任何 P2 模型改动在逆向 DP 下的结构后果,如实声明,「P1 不走 P2 标定」断言落在标定消费面而非值函数。
- **两开关仍默认关**(C4 门/两态投影):本批清偿的是标定与口径面,开臂 A/B 判据挂账不变(W371 M4:姿态面为主,n≥600 前禁率差主判据);C4 门 sim 辖域空集(W386 撤销出口可达)仍未解,批 B 独立演进。
