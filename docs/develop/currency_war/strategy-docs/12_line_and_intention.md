## 1. 终局证据门（唯一线级选择）【已裁定】——通用目标态定义（原 03 §4.2）

score(line) = P_complete(下一成型档缺口 | 剩余回合、金日程、等级场景) × w(line)。

- 完成概率 = **P38** 证明件（五层模型，已对抗收口）；
- 两臂开门：完成概率阈值臂 OR 环境主导比臂（ENV_DOMINANCE_RATIO【拟，标定批】）；
- 阈值与信号面指针（引用行，§1 本体不动）：完成概率阈值 θ* 的推导见 **P76**（[p76](../proofs/p76-lock-timing-option-pricing.md)；已证·修订版，阅读门已收口（轻量复核 8/8，2026-09-07））；商店当帧可得性信号经 **P77**（[p77](../proofs/p77-shop-spot-availability-signal.md)）裁决为**购买估值面**信号、非方向信念面——证据门不加现货频次臂（P77 = 已证·候对抗审，引用状态按此标注；消费资格以 math_proofs 索引状态列为准）；
- 权重 w：默认全 1；偏离只经机制层知识（词缀/投资策略的克制亲和，载体 = MECHANIC_SYNERGIES/MECHANIC_COUNTERS 注册表）或用户口述；**频率永不入权**（[38]）；
- 候选侧可达性：COMP_LIBRARY 登记 external_deps（局外依赖形态）；证据门对其作**候选侧可达性软通道**——试用账号零达成的形态在登记位扣减（知识登记，非硬过滤，同 downgrade_paths 先例）；
- 平局：与当前持有重叠件多者 > 现持有 core 数多者 > 注册序（确定性，无随机）。

**目标态的通用定义（R78-2 通用化重写；替代旧"P2 中间形态不定义 + P2 补条"形态）**：

> 证据门的评分对象恒为"**当前生效档表的下一成型档缺口**"。每条线在 COMP_LIBRARY 登记**分段档表**（segment tier tables：每段一个 form_tiers 档集）；**段索引由节点日程派生（查表键），位面只改变档表的来源，不进任何谓词辖域**——宪法第 2 条的执行形态。规则：
>
> 1. 当前段的档表非空 ⇒ 目标态 = 该段下一成型档缺口，P38 五层照常可评；
> 2. 当前段的档表为空（如过渡线在进入下一段前的窗口）⇒ 目标态 = **终局承诺档缺口**：当前线是终局线 ⇒ 该线终局档缺口；当前线是过渡线（无终局段档）⇒ 换线机器产出的终局线承诺档缺口（触发 = §3 第四触发）。
>
> 这样定义后，任何段内证据门恒有评分对象，**不存在"目标态无定义"窗口**——旧 R78-2 作为位面特设补条消解为上述两条通用规则。

该重写的证据基础（旧 R78-2 引理，不等式级，登记于 IMPL_FIX_LEMMAS R78 对照表）：若目标态缺口=∅，目标件支出上界塌缩至插件有限项，期收入 ≥ 基础 3 金 ⇒ 金位单调不降，有限期内越过死时金 50 阈线，战力停滞、血量期望按节点税单调降——"金堆积→战力停滞→被节点税磨死"死型（FM-1，证据 = P2 失败模式深潜报告 2026-09-02：sim D 桶 67.8%【拟】/实机死时金≥50 占 81%【拟】/P2 段支出收入比 0.464【拟】）。

挂账（不能证部分，三形态章程三要素全）：分段档位登记批（owner=编排者排期）；"承诺档在本段经济下可达"不预设——不可达时由换线机器既有"不可达→生存模式"兜底；兜底触发载体=换线评估事件（评估间隔由 W 决定，**W=None 期承诺档可达性漂移零检测窗口，该期兜底不生效**，敞口如实申报）。

**开闸顺序约束**（R81-1 同款先例）：分段档位登记批**先于或同批于** W 激活——登记批缺位期"可评目标态缺口集=∅"结构性恒真 ⇒ 第四触发前件恒真 ⇒ 每个命中成型里程碑的局必触发强制换线评估、对终局线反复强产噪声评估 = 零治理价值死规格面，取激活前置条件消解。

- 实现态机 = **S0 / S1(search) / S3(focus) 三态**（S2 编号废弃不复用，防误读）；
- **段推进不切换状态机，只改资源谓词**（等级/人口/收入/敌强度/生效档表——宪法第 2 条）；
- **买面行为律 S0 与 S1 同律**【用户裁定 2026-09-07：终局考量开局即存在】：考量面 = 件级估值 × 全牌池 × 无方向禁令，**终局阵容候选件自 S0 开局就在购买考量内**——候选侧判据与 [11_shop_decisions.md](11_shop_decisions.md) §1 序 1 search 态口径同源（「结构可达终局件」，纯计数、不消费成型 CDF、证据门不预筛）。S0→S1 边（四体系任一成型）只是实现态边界（遥测/占位），**不是购买考量门**，「过渡成型后才考虑终局」的阶段门撤销。让渡前/未定型期的排序输出——[31] 三级降级（目标件>羁绊填充>散件垫底）、[20] 过渡配方不乱混、不为凑数羁绊花金 D 牌——是考量面**内**的排序与构成规则，不收窄考量面；
- **过渡 vs 终局 = 金有限时的购买优先序，不是阶段门**【用户裁定 2026-09-07：终局考量开局即存在】：金紧（购买吃息账，[17] 息线带内）→ 过渡配方件优先——先保 [13] 成型里程碑 ≈ 过位面 1 验收（[28] 双指标）；金宽（溢余段，[17]）→ 终局件照买照囤（[21]/[22]），与过渡件不构成竞争。优先序的裁决尺 = 息律与金日程（[17]/[41]；金约束门见 [11_shop_decisions.md](11_shop_decisions.md) §1），零新常量、零新状态；
- **S1 内 [13] 过渡成型里程碑 = 过渡让出购买优先级的触发**，不是「开始考虑终局」的门【用户裁定 2026-09-07：停手线=优先级让渡】。里程碑判据本体不变：【已裁定】[13] 过渡里程碑 = 四体系组合（羁绊档）+ 过渡核心 2★ + lv5-6（人数描述非独立条件）；
- **[13]「停买过渡件」语义（2026-09-07 重解）**：≠ 对某些牌的无脑禁用；= **过渡阵容失去购买优先级，此后目标类买入（= [31] 降级序第一级「目标件」的买入决策，区别于羁绊填充/散件垫底两级）统一按终局阵容评估**。**过渡∩终局重叠件保持价值**——既是过渡配方件又是终局成员/核心/骨架的件，让渡后按终局件照买照囤，不因「也是过渡件」而停买；纯过渡件（终局评估下边际贡献=0）不再买入，是终局标准下的估值输出，不是禁令。让渡只换「目标」的标准与预算归属；估值机器本体（11 §1 六序、[35] 场况插件纪律、[34] 稀缺性序、M2b 升星合并，见 [11_shop_decisions.md](11_shop_decisions.md) §1-§2）不随让渡关闭；[13] 条目原文的本批重解回写归登记簿回写批统一处置（本篇不直接改 user_playstyle.md，防双源漂移）；
- **④ 转线前瞻放行臂 = 未定型期转型前瞻例外**【已裁定 2026-09-07】：as-built ④ 放行臂（`shop.py:1006-1023`，T-115 规则④/ADR-0580；时间辖域 = `cw_intention.committed_from`，即 S3 锁线前的未定型期）对 TRANSITION_PACK carry/partial 件仅过席/金/1★ 全额退硬闸即买入（买因 `transition_component_buy`，位置先于六序常规买面）——该买入对象 = **候选终局线自身的结构件**，未定型期（S3 锁线前）按终局效用评估照买，是两裁定的直接推论（①「终局考量开局即存在」+ ②「统一按终局阵容评估」）；与「纯过渡件（终局边际贡献=0）不再买入」不矛盾——后者是终局标准估值下的**输出集合**（辖纯过渡件），前者辖的是终局候选线结构件，同一评估尺下两类件结论相反、辖域不相交。**零实现窗口申报（双保险之二，与边界行并存）**：让渡落码对齐前，④ 放行臂按 committed_from 辖域照常放行 = 让渡语义零实现窗口，敞口如实申报（同 §1 W=None 期「敞口如实申报」纪律）；**检查器对齐跟进义务**：`sim/checks/segments.py:278` [13] 成型停手检查器按身份通道（engine/pair）把 ④ 买入判为「成型后仍买过渡件」违例，与本裁定冲突——检查器对齐已立跟进义务（进度账本在记），对齐落地前以本条边界为准；

## 3. 换线机器【已裁定】（原 03 §4.3）

三触发：

1. **段边界触发**（通用化：原"位面边界"）：日程跨段时强制换线评估——段索引由节点日程派生，位面边界只是最常见段边界，不作谓词辖域；
2. **不可达触发**：当前线 CDF 分位数恶化（P38 输出）；
3. **严格更优触发**：同量纲（切换成本进金日程变薄后仍胜出）。

**第四触发（通用化重写）**：前件 = (当前线命中 [13] 成型里程碑) ∧ (证据门对本线的可评目标态缺口集=∅ 或不可评) 连续 W 备战期；后件 = 以段边界触发同款语义强制产出换线评估（候选 = 终局线承诺档，评估消费 [11_shop_decisions.md](11_shop_decisions.md) §5 L(r) 消解协议同款为挑战线单独生成日程）。W = 常量 `P_IDLE_SWITCH_W`【拟，带 CI [1,3]，None 不触发】。

证伪记忆粒度 = **(line, 触发原因) 分桶**（用户裁定 2026-08-31）：被证伪的组合不再因同因重开；环境变量变化只解锁对应桶。无可达线兜底 = 生存模式（[31] 三级 + 名单件照买），无默认方向。

覆盖论证（不等式级，沿用 R78-2 引理通用形态）：三触发在"成型→段边界"窗口构造性沉默（边界触发仅边界帧 / 成型后 CDF 单调改善 / 严格更优在目标态不可评时不可求值）；第四触发时刻 t_f+W 在窗口长 >W 的局上严格提前支出恢复、≤W 的局上不早于段边界触发 ⇒ 覆盖单调 ⪰ 三触发、零新增风险。"不可评"分支 fail-closed 声明：不可评分支 = **观察级**（触发计数遥测），其支出恢复兑现待依赖标定齐备，禁与 ∅ 分支共用"覆盖"语义。

P16 换线判据（E_rounds 超几何精确口径 + θ 滞回 + D_min 驻留，无抖动序列，振荡 ≤1/(2·D_min)）是三/四触发后评估的数学载体；判定 = E(alt)·(1+δ)+θ < E(cur)·(1+δ) ∧ 驻留 ≥ D_min。换线瞬间 P41 卖出不等式自动翻转。实证注（as-built，2026-09-07 核）：`should_switch_e` **已接线**（mandate_v1 证明 pass：`strategies/impl/mandate_v1/entry.py:409` → `proof.should_switch`（`proof.py:247`，内部 :316 直调 kernel/cw_line_switch.should_switch_e））；现行休眠机理 = **fail-closed 槽位封印**（θ/U_X/V_ms【拟】缺省全 None ⇒ `theta_unavailable`/`switchline_exit_blocked` 分键短路）——标定齐前换线事件恒 0，非零接线。§4 实现锚未收录该接线属漏记，收编于此。
