## 1. 命题形式化

> **P37(晚转机会成本不等式)**:健康带帧上,把持金 g 的可转化支出(买 XP/买战力件)
> 推迟一轮的期望净值
>
> **EV(delay) = I_gain − L_defer ≤ I_max − L_defer < 0**(量级代理级)
>
> 其中 I_gain ≤ I_max = 5 金/轮(利息帽,零参数上界);L_defer = 延迟一轮升级的
> hp 期望损失,代理标定 5~8 hp/轮量级(§2,关联级)。

### 结构论证(方向,零参数)

(i) **时间不可逆性**:XP→等级→板深/人数上限的战力兑现是**逐轮结转**的单向过程
(W959 §1.3:大升级轮前一场 vs 后一场 delta 中位 −15、改善占比仅 23.2%——升级当轮
不兑现,滞后 1+ 轮才落板面)。第 r 轮该升未升,第 r+1 轮补升也**追不回第 r 场战斗
的板深差**;利息收益却是可重复流量,晚一轮只少收一轮息,无追回缺口。延迟的成本端
是存量损失、收益端是流量,这是方向不等式的结构根据。

(ii) **收益端上界零参数**:单轮利息 ≤ interest_cap = 5 金(息律常量),且健康带
行末金 ≥50 占比仅 17~25%(W959 §2)——「地板 50 存息」在 r4-r7 多数轮连满息都
没吃到,I_gain 实际远低于帽值。

(iii) **成本端存在性(「没东西买」前提不成立)**:升级轮 92.7%(1631/1759)店内有
买得起却未买的件;**存息轮(行末金 ≥50)r4=100%(61/61)、r5=100%(51/51)、
r6=98.3%、r7=97.3%**——每一轮存息期间店里几乎都摆着可买件。「存息攒到 r8 一次
花」不是「没东西可买」的被动结果,是主动排序(息档保护压过战力转化)。故 P23.1
统一 EV 门 `EV = Δp·L_c·m + w·m − C − I` 的被延迟提案集合在健康带**非空且稠密**,
L_defer 有真实承担者。

(iv) **r8 升级潮的重定位**:r8 大升级本身是健康局的表现而非原因(r8 升级金 <8 的
32 局是崩盘局,hp 中位 5——r8 已没钱升;r8 升得起的 247 局 hp 中位 37)。病灶不在
「r8 升太多」,在「r4-r7 攒太久」——与 (i) 的不可逆性合读:r8 才到账的等级只保护
r8 之后的战斗,r4-r7 的血已经按旧板深扣掉了。□(方向)

## 3. 与既有命题的关系

### 3.1 P21(濒死升级负判)的辖域对照——分界 = 收益视界

P21 辖 **hp≤10 濒死带**:升级的受益覆盖判据 `Δp·Σ L_c·S(b) > C + I` 中,
存活到账项 `h > d·L_c` 不成立(S(b)≈0),升级正经济性的唯一来源(P3 型成型进度
长时域账)在死亡清零前无兑现时刻 ⇒ 升级严格负。P37 辖 **健康带(r4-r7,hp>25)**:
存活视界充裕,受益覆盖条件成立,升级(及其延迟)的经济效应显著为正/负。

**两者不矛盾,且是同一本 EV 账的两个边界**:
- P21 说「濒死带**花钱**升级负」;P37 说「健康带**不花**(攒息)负」。濒死带升级
  仍负、健康带晚升成本为正,共用 P23.1 统一门:EV 符号由收益视界(存活概率 ×
  剩余战斗数 × Δp)决定——视界趋零则一切支出与攥金同归零值(P23.4 死亡域金零值
  近似),视界充裕则支出有正承载、攥金有正机会成本。
- **分界的操作形态**:hp 轴上,P21 辖 [1,10](濒死),P37 辖健康带(hp>25),
  (11,25] 应急带归 P36/P28/P23 危机族辖——三段无缝,无缝隙也无重叠。
- **反向护栏**:P37 不给濒死带/应急带任何升级授权;健康带判据不得越轴套用
  (同 P36 对 P21 的引用方向相反,互相为界)。

### 3.2 与 P36 火力链的口径衔接——同族干预:「攒金早转战力」

- **同族**:P36(危机带火力地板:预算>0 必须出手)+ P36-a′(危机带储备线降档:
  R*_crisis≡0)与 P37(健康带升级时点前置)同属「压缩攥金、把金提前转战力」干预族,
  共用 P23.4 攥金优势引理的反面(攥金的机会成本为正)与 P23.1 统一门。
- **口径差**:P36 的出手通道 = 刷新/购买(当轮兑现型,即时 Δp);P37 的通道 =
  买 XP(滞后兑现型,1+ 轮时滞,§1(i))。**滞后兑现正是「攒到 r8」看似无害的
  错觉来源**——r8 潮是健康局表现,mask 了 r4-r7 的延迟损失;P37 的存在价值就是把
  这条滞后通道的时点成本单独立账。
- **衔接处**:危机臂哑火帧(P36 M1)与存息轮可买件积压(P37)是同一病灶在两条
  hp 轴段上的投影——金在息线上、可转化件在店里、出手/升级不发生。两条命题合读,
  「息档保护」的合法辖域被夹逼到很窄:健康带满息平台上的短期平滑(P13 自身边界内),
  不外溢为跨轮攒钱姿态。
