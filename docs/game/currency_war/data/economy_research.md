## 1. 牌池上限(各费用张数)

### 结论

**两个不同概念被搜索结果混在一起,必须分清:**

| 概念 | 含义 | 数据(V3.7) |
|---|---|---|
| **A. 角色种类数**(每费用有多少个不同角色) | 去重计数 | 1费14种 / 2费13种 / 3费13种 / 4费12种 / 5费9种 = **共 61 种**(V3.7);V4.4 扩充至 **74 种** |
| **B. 牌池副本数**(每个角色在牌池里有几张副本) | 凑星合成用 | **5费 = 9 张/种** 🟢 确认;**1/2/3/4费 = 推测同样 9 张/种** 🟡(见下) |

**B 项(牌池副本数)的依据:**
- 🟢 **5费每种 9 张**:多源确认(NGA `bbs.nga.cn/read.php?tid=45557485` 原文「5费卡在牌库里是每张×9」、NGA `ngabbs.com/read.php?tid=45776649`、现有 strategy_research.md)。9 张正好够 1 个 3 星(9=3×3),**单人模式下刚好够一个人合 3 星**。
- 🟡 **1/2/3/4费推测也 9 张/种**:用户提示「通常是9张」+ **单人模式设计逻辑**(9=正好一个3星,与 5费一致)+ NGA 称「每个同费用的角色牌数量相同」。但**没有任何源直接给出 1/2/3/4费的副本数**(搜索返回的 29/22/18 是 TFT 数据,不适用)。
- 🔴 **精确的 1/2/3/4费副本数**:未找到任何货币战争权威源明确写出。需实机 OCR 或米游社专页确认。

**与现有研究差异**:现有 strategy_research.md「5费每种9张」✅ 正确。但**不能套用 TFT 的 29/22/18/9 分布**——货币战争是单人模式,牌池小得多。

**对 A4 牌池模型的建议**:
- 先按**统一 9 张/种**建模(最可能,符合单人设计 + 用户提示),5费已确认。
- 把副本数做成**可调配置**(`COPIES_PER_CHAR_BY_COST`),实机校准时改。
- 角色种类数用 A 项表(V4.4 = 74 种,从 `characters.md` 读),别写死。
- 牌池操纵(买同费非目标卡)的概率提升计算:`P(目标) = 剩余目标副本 / 剩余同费总副本`,买掉 1 张同费非目标 → 分母减 1 → 目标概率↑。

**各费用该在几级 D 牌**(🟢 [article/77074467](https://www.miyoushe.com/sr/article/77074467) D牌期望表主文,08-01)—— **level_plan 的核心输入**(每 comp 的等级→该 D 几费核心):

| 1费 | 4-5 级 | 赌 1费阵容(阿格莱雅)在低人口 D |
| 2费 | 6-7 级 | |
| 3费 | 7-8 级 | 7级3费刷新概率 p=0.4(40%) |
| 4费 | 8-9 级 | |

**池参数**:

| 参数 | 含义 | 值 |
|---|---|---|
| **a** | 每种牌的**副本数** | **1/2费 = 27 张/种**(可升 4 星:27=3 个 3 星=9×3)、**3/4/5费 = 9 张/种**(最高 3 星)。均 3 的倍数(3合1 升星机制决定)。权威源:V3.7 必修二 + 用户(2026-08-12 ADR-0109);5费=9 与 [NGA tid=45557485](https://bbs.nga.cn/read.php?tid=45557485) 实锤吻合。⚠️ V4.2 银狼档「30/25/18/10/9」含非 3 倍数(25/10)→ 不可信弃用。代码单一源 `cw_shop_odds.POOL_COPIES_PER_CARD` |
| **v** | 同费用的**种类数** | 3费 = 13 种 |
| **p** | 某等级刷新出某费用的**概率** | 7级刷新 3费 = **0.4 (40%)** |

**D牌期望计算方法(77124902 原文)**:找 k 张目标牌(2星 k=3、3星 k=9),一次刷新 5 格各以概率 p 独立出目标费用(二项分布 M~B(5,p)),m 张目标费用里出 x 张目标牌 = 超几何(剩余目标副本 a-j / 剩余同费非目标副本 (v-1)a-c)。状态转移方程算期望刷新次数 E_j。**这正是 A4 D牌蒙特卡洛 `_refresh_expected_delta` 应该用的精确模型**(替代当前 `_sample_shop` 的粗近似)。

**对 A4 的修正**:
- **副本数 a**:**1/2费 = 27 张/种**(可升 4 星)、**3/4/5费 = 9 张/种**(最高 3 星),均 3 的倍数(2026-08-12 ADR-0109 用户确认 + V3.7 必修二;5费=9 NGA 实锤吻合)。代码 `POOL_COPIES_PER_CARD={1:27,2:27,3:9,4:9,5:9}`。
- **刷新概率 p(level, cost)**:🟢 **完整权威表已实机 OCR 落地**(2026-08-11,游戏内"商店刷新概率"表,D-91)—— 入口:备战 shop 开 → 点底部百分比条弹完整 Lv1-10 表;每行和=100%,7级3费=0.4 与旧实测点吻合。**值单一源在 `cw_shop_odds.REFRESH_PROB`**(此处不重贴,避免双源)。规律:随等级升高费概率↑(1-3 级纯 1 费 / 4 级起混 2-3 费 / 7 级起出 5 费)。旧源 [77124902](https://www.miyoushe.com/sr/article/77124902)/[70524990](https://www.miyoushe.com/sr/article/70524990) 与实机一致。
- `_sample_cost`(当前按 level 粗采费用)应换成**真实 p(level,cost) 表**;`_sample_shop` 应按 a/v 精确建模剩余副本。
- 用 a=9/种(5费实锤 + 共识外推);实机核待条件(买光看不再出,难测)。部分场景/效果改副本数(>基础,A4.7 修正)。

## 2. 1星买入卖出无损 → 免费操纵牌池

### 结论:**成立** 🟢(核心机制)

**卖出退金规则:**

| 星级 | 卖出返还 | 依据 |
|---|---|---|
| **1星** | **= 招募费**(1费→1金,2费→2金,…5费→5金) | 🟢 BWIKI「按其费用获得回收金币」+ 4399 + 用户(2026-08-12)权威 |
| **2星** | **= 招募费 × 3**(1费→3金)**;cost≥2 再 −1 手续费**(2费→5金,3费→8金,5费→14金) | 🟢 1费 live 实测 2★1费=**+3**(2026-08-13,VLM 读出售按钮「金币+3」);cost≥2 −1 = 用户「2费开始减1」待核 |
| **3星** | **= 招募费 × 9**(1费→9金)**;cost≥2 再 −1**(3费→26金,5费→44金) | 🟡 同 2星规则外推(1费全额 / cost≥2 −1);待 live 核 |

> ⚠️ **2026-08-13 live 实测修正(推翻 2026-08-12 的 −1 一刀切;ADR-0121)**:2★**1费** 万敌 出售 = **+3 金**(cost×3,无 −1;sell-star 停机钩子 + VLM 客观确认)。用户:**1费不减、2费开始才减1** → 手续费 **cost 相关非纯 star**。故 2026-08-12 的「2★=cost×3−1」(为消解「2星免费 vs 不免费」矛盾)**部分错**:1费 2★ 确实免费(净0),cost≥2 2★ 才亏1。矛盾真相 = 1费/cost≥2 区分,非一刀切 −1。

**关键推论(1费各星免费 / cost≥2 star≥2 亏1):**
- 买 1× 1费(花1金)→ 卖 1星(返1金)= **净 0** → **1星1费买卖 = 零成本操纵牌池**
- 买 3× 1费(花3金)→ 合 2星 → 卖 2星(返 3金,**1费无费**)= **净 0** → **2星1费操纵也免费**(2026-08-13 实测)
- cost≥2 2星:买 3× cost → 合 → 卖(cost×3−1)= **净 −1**(亏1手续费)
- → **牌池操纵用 1费角色(1星或 2星)最干净**(免费);cost≥2 有1金成本

**与现有研究差异**:strategy_research.md line210 已提「买不想要的卡改牌池」,但**没确认 1费买卖净 0**。本核实确认:**1费买卖无损 = 免费牌池操纵**,可放心编码进 A4。

**注意(2星 cost≥2 才有成本)**:1费角色(1星/2星)买卖 break-even 净0 = 免费操纵;cost≥2 2星有1金手续费。所有合成操纵都**占备战格 + 需先凑齐 3 张**(非瞬时);1星1费最瞬时。

### 战术:1费减牌库找目标(2026-08-13,ADR-0121 启用)

**场景**:正在 D 一个特定的 **1费核心**(如 桑博 凑 DOT 过渡 / 绰英 凑欢愉 / 1费追 3星)。每次刷新 5 格,目标只占其中 ~1/v 概率(v=同费用种类数,见 §1)。

**战术**:刷新遇**其他 1费非目标卡**先买下放备战 → 牌库里 1费非目标副本 −1 → 下次刷新出目标概率↑。买错的 1费卡后续原价卖出 = **净 0 金**(1★=cost 全额退、2★1费=cost×3 全额退,ADR-0121),整局操纵**零成本**。

**前提**:
1. **目标必须是 1费卡**(cost=1 各星全额退;cost≥2 star≥2 亏 1 金 → 操纵有成本,非免费,见售价表)。**这是 ADR-0121 启用条件** —— 旧认知「2★一律−1」下,2★操纵有成本战术不干净;1费 exempt 后才真正零成本。
2. **备战栏有格子**(`BENCH_CAPACITY=9` 上限;满 → 强制升级/卖出阻塞买非目标)。建议留 ≥2 空槽再做此操纵;或随买随卖(同回合买→遇目标→卖非目标腾位→买目标)保持净 0 占用。
3. **牌池模型支持**(牌库有限、买掉即减、卖回回池,见 §1 + gameplay §经济「牌库有限」)。NPC 是否消耗共享池未知(保守:只扣自己持有的,见 `acquirability_factor` 注释)。

**量化(用 A4 牌池参数;V4.4 ADR-0109:1/2费=27 张/种;v=1费种类数从 `characters.md` 派生 = `cw_shop_odds.DISTINCT_CARDS_PER_COST[1]`,V4.4 实测 v=19):**
- 1费池总副本 = v × 27(V4.4:19×27=**513**,池很大)。
- P(单格出目标)= p(level,1费) × 27/(v×27) = p × (1/v)(满池未持时)。例:level 4(p=0.65)、v=19 → P(单格)=0.65/19≈3.4% → P(5格≥1张)≈16%。
- **买走 k 张其他 1费非目标** → 分母 v×27−k,P(单格)=p×27/(v×27−k)(实测 `expected_refreshes` 模型,2026-08-13 跑):
  - k=10:513→503,P(单格)≈3.5% → P(5格≥1)≈16.3%;E[刷到 1 张]=6.27→6.15 刷新。
  - k=30(激进):513→483,P(单格)≈3.6% → P(5格≥1)≈16.9%;E[刷到 1 张]=6.27→5.92 刷新。
  - **追 3星(需 9 张)**:E[刷新次数] 45.8(k=0)→ 44.6(k=10)→ 42.2(k=30);减 30 张省 ~3.6 刷新(~8%)。
- **幅度评估**:1费池大(513 张)→ **单次刷新幅度小**(买 30 张只升 P(5格≥1)从 16%→17%);但**追 3星**多次刷新复合,省几刷新 + **净 0 金**故任何正期望都值得做。对比:cost≥2 池小(9 张/种,操纵更显著)但每次亏 1 金 → 非免费,需算账(E[减池收益] vs 1金成本)。

**与现有研究关系**:strategy_research line210「买不想要的卡改牌池」+ gameplay §经济「卡牌池零成本操纵」提了机制,但**未专指 1费 + 未量化**。本战术**只适用 1费目标**(ADR-0121 启用),cost≥2 不免费。`expected_refreshes`(cw_shop_odds)已有 `c`(non_target_taken)参数支持建模,但 `acquirability_factor` 当前传 c=0(未消费此模型,见 A4.4 待办)。

## 3. 电表倒转

### 结论:**特定投资策略 combo,非基础机制** 🟢

**「电表倒转」= 通过「砂里淘金」等投资策略的合成赠送效果,实现金币越滚越多的循环**(「电表倒着转」)。不是游戏基础经济规则,而是**依赖特定投资策略卡**的邪道流派。

**核心 combo(必备条件):**
| 组件 | 作用 |
|---|---|
| **砂里淘金**(金色投资策略,核心) | **每合成 1 个 2星 2费角色 → 免费赠送 1 张「砂金」(2费卡)** |
| **长线利好** 或 **轮岗**(启动条件) | 轮岗:让 2费刷新概率从 40%→80%,大幅提高 2费获取速度 |
| (进阶)**变宝为废 + 轮回不止** | 另一种循环变体 |

**为什么能赚钱(基于第 2 点 break-even):**
1. 买 3× 2费(花6金)→ 合 2星 → **砂里淘金送 1 张砂金**(值2金)
2. 卖掉 2星 2费(返6金)= 买-合-卖 break-even,**净赚 1 张砂金**(2金)
3. 攒 9 张砂金 → 合 3星砂金 → 卖(返18金)或留作战力
4. 循环 → 金币暴涨 → 「1-9 关全员 3星 5费」「财富自由」

**启动条件与难点:**
- **必须 1-2 关刷出「砂里淘金」**(硬性条件),同时要「长线利好/轮岗」之一
- 启动资金约 **500-600 金**开始大规模操作
- **凹开局**(刷不出砂里淘金就无法启动);硬玩易亏钱破产,偏娱乐流
- 「砂金是2费卡可以合成四星」(注:2费可合4星是 4.0+ 特殊规则)

**对策略的意义:**
- 这是**条件触发型 win-con**,不是通用经济策略。bot 应**识别拿到砂里淘金时切换到此流派**,而非默认追求。
- 现有 strategy_research.md **没有**这条,是**新增洞察**。投资策略白名单应加入「砂里淘金」(若搭配轮岗/长线利好拿到则优先)。

## 4. 关键回合多刷(刷新 > 2 次)

### 结论:**「每回合最多刷2次」上限太死,关键回合应放宽** 🟡

**搜索没有给出固定「刷新X次」的统一数值**——所有攻略强调**原则**(卡利息、升8后D、买空法提概率)而非固定次数。但多方确认**关键回合确实会多刷几次**:

**该多刷的情况(攻略共识):**

## 5. 前期保经济 vs 第一位面保血(精确边界)

### 结论:**A8 高难下「保血/保连胜」> 「保经济卖血」;低难可保经济** 🟡

**现有研究矛盾的本质:strategy_research line94(保经济卖血)是 TFT 通用思路,line211(保血>利息)是 A8 高难专项。两者不矛盾,按难度/血量分界:**

**判断逻辑(决策树):**
```
第一位面(plane1):
├─ 高难(A8+) AND 阵容战力不足(预计掉血>15)?
│   └─ YES → 弃息 D 牌,凑伤害羁绊(DOT三件套/3仙舟/贝洛伯格)保血保连胜
│            (理由:A8 血量指数膨胀,前期掉血后期补不回;断连胜亏的钱≥利息)
├─ 有成型连胜阵容(3仙舟/贝洛伯格2人/DOT双)?
│   └─ YES → 停止花费,吃息+连胜滚雪球(双重经济源)
└─ 低难 / 血健康 / 牌差但打得过?
    └─ 保经济(攒20-30吃2-3息,牌差宁输一局,前期扣血少)
```

**精确边界(攻略提炼):**
| 条件 | 选择 | 依据 |
|---|---|---|
| **A8 + 遭遇节点前战力不够** | **D 牌保血**(弃息) | 🟢 巴哈/NGA:断连胜亏的钱 ≥ 利息亏的 |
| **连胜中(已2胜+)** | **保连胜 > 吃息**(凑齐阵容锁血) | 🟢 连胜奖励是额外经济源 |
| **低难(A6以下)/牌不差** | **保经济**(攒50) | 🟡 前期扣血少,经济复利更值 |
| **连败中(卖血流)** | **看血量**:血>50 继续吃息;血<40 止血D牌 | 🟡 TFT 经典,货币战争 A8 下卖血风险大 |

**关键共识(A8 高难专项):**
- 「第一位面最难」🟢(strategy_research line250 多源一致)——A8 一层遭遇常比 boss 凶,战力不够直接崩
- 「断连胜亏的钱比利息亏的还多」🟢(巴哈)——连胜奖励 + 利息 = 双源,断连胜损失大
- 「A8 流程短→拿不到经济赐福时升本与D牌如鱼和熊掌」🟢(strategy_research line97)——核心矛盾

**对策略的建议:**
- evaluate 的前期判断不能一刀切「保经济」。应按:① 当前难度;② 当前 HP%;③ 连胜/连败状态;④ 阵容成型度 → 动态选「保血D牌」or「保经济吃息」。
- A8 默认偏「保血」(HP 权重高),低难偏「保经济」(economy 权重高)。

## 6. 阶段经济权重(给阶段权重校准用)

### 结论:**前期 economy 该 snowball 到 50,不该压到 0.4** 🟡

**攻略对前期/中期/后期 economy 的共识(多源一致):**

| 阶段 | economy 策略 | 权重方向 |
|---|---|---|
| **前期(位面1,1-4关)** | **snowball 到 50 金**(尽早攒满吃5息),连胜利息双源滚雪球 | **economy 权重应高**(0.5-0.6),不是 0.4 |
| **中期(位面2,5-7关)** | **稳定≥50,用利息升人口为主**,少主动刷新 | economy 权重中(0.4-0.5),quality/comp 权重升 |
| **后期(位面3,8-9关)** | **血健康继续吃息上9找5费;血危险果断花光提质量** | economy 权重低(0.2-0.3),quality/comp 主导 |

**关键共识(🟢 多源一致):**
- 「第一要诀:尽早攒 50 金并维持,每回合白拿 5 金息」——**前期 economy 是 snowball 的引擎,不是要压的对象**
- 「中期:稳定≥50,用利息升人口为主,少主动刷新」——中期 economy 维持但不主动刷
- 「后期:血健康继续吃息上9;血危险果断花钱」——后期 economy 让位 quality

**对 `_phase_weights(plane, hp)` 的修正建议:**
- **前期(plane1)economy 权重应上调**(当前 0.4 偏低)。前期攒到 50 = 后期每个回合多 5 金复利,是滚雪球的核心。建议 **0.5-0.55**。
- 但要和第 5 点联动:**A8 高难 + 战力不足时,economy 让位 quality(保血)**。即 `_phase_weights` 不只看 plane,还要看 `hp_pct` 和 `difficulty` 和 `win_streak`:
  - 前期 + HP健康 + 连胜 → economy 高(0.55)
  - 前期 + HP危险(预计掉血大) → economy 降(0.3),quality 升(保血D牌)
- 中期 economy 维持 0.4-0.5(吃息升人口)。
- 后期 economy 降到 0.2-0.3(花钱找质量)。

**注意(用户 snowball 哲学一致性):** 用户 2026-08-03 定调「像人一样玩」+「前期 snowball」,与本核实一致。前期压 economy 到 0.4 与 snowball 哲学矛盾,**应上调**。

## 汇总:对策略的修正建议

### 1. `_phase_weights(plane, hp)` 前期 economy 权重
- **上调前期 economy**(当前 0.4 → 建议 0.5-0.55)。前期 snowball 到 50 是引擎。
- **联动 hp/difficulty/win_streak**:A8+HP危险时 economy 让位 quality(保血);HP健康+连胜时 economy 高(滚雪球)。
- 后期 economy 降到 0.2-0.3。

### 2. A4 牌池模型
- **副本数**:先按**统一 9 张/种**建模(5费确认,其他推测同;符合单人模式设计)。做成可调配置 `COPIES_PER_CHAR_BY_COST`,实机校准。
- **种类数**:从 `characters.md` 读(V4.4=74种),别写死。
- **牌池操纵**:`P(目标) = 剩余目标副本 / 剩余同费总副本`;买同费非目标卡(1星买卖净0)→ 分母减1 → 概率↑。**可零成本编码进 shop_strategy**(买1星非目标→卖出刷新概率)。
- **⚠️ 别套 TFT 的 29/22/18/9 分布**(那是 8 人 TFT,货币战争是单人)。

### 3. D 牌上限
- **「每回合2次」太死**。改动态上限:常规≤2;关键回合(升8后/boss前/锁血/赌阵容关键等级)放宽到 4-6 或按 gold 弹性。
- 拿刷新减费策略(高效决策/采购专员/反利+)时上限再提高。
- 判断信号:刚升目标人口 / HP低 / key牌差1-2张 / 有刷新减费。

### 4. 前期保经济 vs 保血
- **按难度/血量/连胜动态选**,不一刀切。
- A8 + 战力不足 + 遭遇前 → 弃息D牌保血(DOT/贝洛伯格/仙舟过渡)。
- 低难 / 血健康 / 连胜中 → 保经济攒50。
- 连胜中 → 保连胜>吃息(连胜奖励=额外经济源)。

### 5. 电表倒转(新增洞察)
- 拿到「砂里淘金」(+ 轮岗/长线利好)时,**切换到此流派**:买2费合2星→送砂金→卖→循环→攒三星五费。
- 投资策略白名单加入「砂里淘金」(高优先级,若同时见轮岗/长线利好则顶级优先)。
- 这是**条件触发型**,非默认追求;识别到才切。

## 7. 用户人玩节奏口述(2026-08-15,A8 实战玩家,🟢 权威校准)

> 用户对 A8 实际打法的完整口述——「人怎么打」的直接来源,策略层人玩基线(此前 §1-§6 为攻略/实机核实)。重构落地见 ADR-0128(策略重构)。

### 原话要点(逐条,语义未改)
1. **开场 2 个奖励节点基本什么都不做**;在不影响吃息的基础上多买牌,方便后续刷出想要的角色。
2. 前期可以**卖血**;**少刷新商店**(刷新 2 金/次),**优先凑息(50 金)**;但也要买**过渡阵容**。
3. 50 息后:主要看**自己核心在几级刷新概率大**;到这个等级就刷新商店买核心;**没到就少刷新、多买经验**。
4. **核心不只是输出**:一套阵容输出和辅助都不可少,中途也要买辅助;辅助 **2 星就够、1 星也没所谓**,能 3 星更好(可囤一下冲 3 星)。
5. 输出核心若是 **4/5 费**(需很高等级才买得到)→ **必须有低费输出保证过渡**。
6. 中期凑阵容为主;**偶尔可掉到 40/30 金少要点息**——前提是商店全是想要的;正常情况优先 50 金。
7. **不无脑停留概率最高等级**:峰值级概率最高,但高一档也没低太多、还提高更高费刷新 → 取决于整个阵容想要的人。(峰值级以实机 OCR 表 `cw_shop_odds.REFRESH_PROB` 为准:3 费 7 级 p=0.40、8 级接近;原则 = 在「费用段带」内权衡,与 §1 D 牌期望表同构。)
8. 后期**必须阵容羁绊凑多人效果**才能通关,**散装不可能通关**。
11. **(2026-08-15 晚补,M22 复盘对话)** 金 <20(1 息档内)买过渡件**不损息还压缩牌库**——攒息不该拦无损购买。

9. **装备有策略**:部分角色要特定装备才发挥效果,**不是有装备就用**;优先保留输出的装备,阵容有辅助核心装备的次之,有盈余才给其他角色。
