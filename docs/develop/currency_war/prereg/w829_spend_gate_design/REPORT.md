## 1. 语义重建:支出门的精确语义与三方对齐

### 1.1 本质区别(先答,一行)

**W774⑤ 支出门是「收门」——在既有评分-仲裁管线的约束链上,对已经产生的正分候选加逐笔可复算的「不许花」否决谓词(息线/血线/位置),不开源、不设预算、不承诺任何支出量;p2_spend_auth 是「正授权器」——开门+预算带+净支出闭环,要凭空创造窗内花费,而窗内根本没有正-EV 花处(M0b 四口径 0-4.1%,窗收入中位 93 vs 水位差中位 80+,ADR-0492 定谳结构性死路)。**

### 1.2 三方对齐逐条

| 方 | 说了什么 | 对本设计的约束 |
|---|---|---|
| **W774⑤ 原语义**(经 W777 攻击 + v2 修订) | 血线三带:预警带 hp<40([18] 直引)带内买入禁令对象=「非转化∧非压库∧非本线目标件」;应急带 hp≤25 转化性约束,豁免=当轮可转化∨压库([34]①)∨本线稀有件;boss 窗与末窗让位仲裁写死 | 门的三带结构(预警/应急/末窗让位)与豁免面(转化/压库/本线目标件)直接收编为血线臂判据;阈值 40/25 沿用,零新魔数 |
| **ADR-0487 删码边界** | 删的是 p1_iface **判据面实现**(五开关+arbiter 两处授权放行臂+p1_iface_gate 约束分支)——删的是「接口授权臂」,不是「支出门」概念:①门的本体语义(血带梯度)在 W774⑤ 设计 v2 完好;②ADR-0494 明判「授权/方向/时机型杠杆」与档位累积型目标类型错配,而**收门型否决谓词不在该定谳辖域**——它与评分-仲裁正分门同族(负向约束),不是授权杠杆;③ADR-0487 自己保留了正信号记档惯例(锁线质量维),门概念同样可按证据重建 | 门不落成 p1_iface 式「授权帧→放行臂」结构(那是被删的形态);落成 arbiter 约束链上的逐笔拒因(ADR-0434 同款),无授权帧、无放行臂、无拦截枚举披露开关 |
| **ADR-0492 死路教训** | p2_spend_auth 四版迭代的死因链:开门(M0a 98%+)≠出手(M0b 0-4.1%)→ 修出手面(净支出闭环/梯级重排)→ 窗内花费 sink 枯竭是结构性的 → W801 定谳「授权/方向类杠杆与档位累积型目标类型错配」。W795 §4.2 已划界:「授权是门,枯竭是货架空;兑现链买入是货架补给」 | ①门**不承诺支出量**——它只否决,否决空转(店空/全被豁免)是合法态,无出手率红线义务;②门**不造第二账本**——金账单一源不变(ADR-0434 Decision 5 同款);③门不开在「窗」上——辖域是**帧内逐笔候选**,不是时间窗+水位差,天然没有「窗内必须花掉」的死路形态 |

### 1.3 为何前者可重建、后者是死路(机制级)

- **方向相反**:授权器回答「什么时候**要**花」——它需要世界上存在够多的正-EV 花处才能兑现,实证不存在;支出门回答「什么时候**不许**花」——它只需要世界存在够少的负-EV 花处就能兑现,而 W828 的 G7/G4 恰恰证明负-EV 花处存在(破息买入 +2.89pp 息基侵蚀、挤席买入 +2.29pp 满栏帧)。
- **失败模式相反**:授权器的失败是**静默的**(授权了没花,遥测上「开火即不出手」,四轮 A/B 才定位);支出门的失败是**显影的**(拒因枚举直接进决策迹,逐笔可复算——ADR-0434 的设计前提「任何息线以下的花对照三例外,例外外=拒,无口诀空间」)。
- **先例已验证**:ADR-0434 息线以下支出门(P1,升级/刷新侧,默认关+开臂挂账)就是同族落码先例——本设计是把同一范式从「升级/刷新」扩展到「买侧」,不是新范式。

### 1.4 门的判据(触发条件/辖域/豁免)形式化

辖域:买侧 BuyCard 候选,arbiter 约束链(与非正分门/gold_floor/bench 容量同层),帧级逐笔;**让位序**:merge 完成豁免通道(ADR-0437/0438)在前,门辖豁免外候选;ADR-0474 分配器 alloc 域接管帧门整体让位(单一分配器)。三条判据独立否决,任一命中且无豁免 → 拒:

- **D1 息线臂**:花后金 < interest_floor(50) ∧ ⌊gold/10⌋ 下降(真破息,⌊·⌋ 不变=零息损不拦,ADR-0434 E3 同款)→ 拒。
  豁免(全部「自带兑现路径」,收编 ADR-0434 三例外骨架):
  - E-a 合成完备购置(merge 候选,已过豁免通道,门让位——防堵死 ③-a);
  - **E-b(v3 内联解耦,修正攻击 B)**:锁定线缺档成员(`missing_members` 单一源直判)**∧ 非应急带(hp>25)** → 破息放行。**不引用 P29 项**:v2 借「P29 项>0」作判据,而 P29 项内含 hp<40 反向锁与 R_min 条件 → hp<40 带 E-b 恒死(D2 豁免面空集,预警带线内件整段拒买,反向违反 W774⑤「禁令对象=非本线目标件」对齐语义),且门间接消费 R_min 破坏「血线臂只看 hp 梯度」自约束(攻击 B/角度④)。v3 门豁免判定与 P29 加项判定**分属两层、判据各自内联**:门只看「缺档成员∧血带」,P29 项只在评分层决定值多少分——两层在同一候选上可组合出「门放行(预警带线内件)∧P29 项=0(低 R_rest)」状态,合法:门管可买性,评分管排序,防双门不等于共用判据。
  - E-c 人口位(levelup_ev_basis 臂①语义,门不辖升级故仅为对齐登记)。
- **D2 血线臂**(消费既有 is_emergency/blood_margin 谓词,零新状态源):hp < 40(预警带,[18] 直引)→ 豁免面=「转化性(当轮可上场/合成)∨压库∨E-b」(E-b v3 内联后在预警带存活,镜像问题消除);hp ≤ 25(应急带)→ 豁免面收窄为「转化性∨E-b」(压库禁,血紧时压库是奢侈品——W774⑤ v2 显式取舍声明直引)。
  **压库谓词操作化(v3,修正清单⑤;零新魔数)**:压库买入 = 候选费用 ≤2 ∧ 非线内成员 ∧ 帧内压库买入计数 <2——**单一源 = ADR-0494 既有操作化**(「压库 ≤2 费/每帧 ≤2 张不穿透挤占门」),不现造定义;帧内计数为落码批 session 计数器(对齐 ADR-0434 E2 的 v3_bf_refresh_* 轮内计数模式)。
- **D3 位置臂**:bench 占用 ≥ 容量−1 → 拒非(E-a ∪ 当轮可部署)买入。**现行 realization.py `p29_priority_term` 内已有同判据定性门**(L161),本设计将其**上提为全局门**(P29 调用同一门函数,不保留第二实现)——这是 G4 的直接落点。

末窗让位:末窗(r ≥ handoff_gate_min_round)∧ 出口血短帧 → ADR-0451 降格独占,门不新增放行(与 W774⑤ v2 §5-2 同仲裁语义)。

## 2. 缺口形式化:G7/G4 的机制链

### 2.1 G7(息基侵蚀,+2.89pp:81.58%→84.47%)

```
realization on 臂 → 买侧出手结构改变(P29 囤牌加项 94.6% 出手率 + merge 时点项)
  → 全场购入事件 +8.8%(1526→1661)
  → 逐笔买入无「真破息」否决谓词(约束链现有 gold_floor 只辖 HOARD 攒息分支与刷新侧,
     买侧破息逐笔无门;ADR-0434 门辖升级/刷新,不辖买入)
  → 金跌破息线 50 的帧增多 → 金<50 帧占比 +2.89pp(P1 段口径)
  → 每帧息档 ⌊g/10⌋ 下降 → 息流损失(5金/轮 封顶档每掉一档 −1金/轮)
  → 出口金/P2 携金资源侵蚀(G2 终局带金口径边缘 +0.6pp 同源信号)
```

关键点:**on 臂的全部买侧加项都是「排序加项」**(P29/merge 时点改 val),排序层不改变可买性,可买性层对破息买入是敞开的——这正是「缺支出门」的形式化:**买侧候选集上不存在「花后破息且无兑现路径 → 移出候选集」的过滤器**。
**v3 注(攻击 A 证伪 v1 结论,机制预算重算)**:v1 曾断言「E-b 豁免只放线内件,散件与线外插件被 D1 拦下,恰回收 G7 而不伤 M1」——W830-G 复算证伪:on 臂额外买入 +325 笔中 **+322 笔(99.1%)是线内成员**(额外花费线内 +1001 金/线外 +739 金/线外仅 3 笔),即 G7 成因几乎全由 E-b 放行类驱动,D1 对 G7 的可达拦截面≈1%。**G7 与 M1 在当前出手结构下是同一笔钱,门在两者之间没有免费午餐**——推论与判据后果见 §5.1 的 G7 预算重定基与 §5.3 前置件 #1。

  → bench 挤占门现状:P29 项内部有「占用≥容量−1 禁囤」(L161),

### 2.3 门的定位升级:过程→终局传导断链点(v2,依 W830)

W830 攻击证实:M1 的过程加速**没有**传导到终局存活(r=−0.058,0.44 轮≈0.035 轮存活当量;M4 零移位),且中位局零收益、改善全押慢尾。因此门的定位不能只是「息基护栏」(防 G7 侵蚀),必须是**传导断链点的修复候选**——论证「门如何让档位加速传导到终局存活」,机制链两条:

- **断链点一(位置链,G4→档位阶跃不兑现)**:ADR-0494 已证 P1 出口 hp 的决定量是**离散战力档位**(激活档≥3→出口 59-72;≤2→9-48;boss 税阶跃 ~19 血/档),不是过程速度。M1 加速买入只有转化为 **deployed 域档位阶跃**才碰得到这个决定量;而 G4(+2.29pp 满栏帧)显示 on 臂的加速买入正把 bench 填到拥塞——满栏帧里档位件「买到了但落不下/上不了」(G5 部署率读数下行 0.969→0.956 同链旁证),过程加速在最后一厘米泄漏。**D3 位置臂因此是传导修复而非卫生措施**:它把「买得出」与「落得下」绑在同一判据里,拒掉注定无法兑现为档位阶跃的买入,逼支出走「当轮可部署/合成完备」路径——M1 的加速才可能变成 ADR-0494 的 hp 阶跃。
- **断链点二(资源链,G7→P2 起手资源)**:P2 存活对金的弹性经 D2/死亡域账(P12/P23.4:携金进 P2 的可支出语境)传导——G7 息基侵蚀 −2.89pp 帧意味着 P2 进场携金/中途息流的系统性变薄,死亡域「金免费谬误」修复(ADR-0493)已证携金有正边际。D1 息线臂保住的不是「金账好看」,是 P2 侧唯一可转化资源的水位。
- **中位层零收益的门侧解释与修复主张**:W830 分层显示典型局(off=3)本就无改善空间被激活——门不直接创造中位层收益(M1 判据照 W830 建议改分布级),但门通过断链点一保证**已有**的改善(慢尾 −1.4~−3.9)不被 bench 拥塞泄漏、通过断链点二防止残差继续吃掉收益;「门能否让中位层离开零」本身列为重跑观察维度(§5.1 M1-L 格),不自封必达。

边界声明:传导断链的主因按 W830 §3 裁决是 **sim 结构性天花板**(M1↔存活 r≈0 是 off 臂固有属性,P2 结算键 3 维),门修的是「被 G7/G4 吃掉的那部分传导」,不修 sim 结算键——终局传导的定谳归实机锚,门在 sim 侧的可证义务止于「清账门 + 档位阶跃兑现率不降」。

### 2.4 W828 预声明格与本设计的衔接


W828 判前锁:「G7>+1pp 或 G4>+2pp → 机制挂账未清,开臂判据改挂『支出门落地后重跑』」——本设计即该挂账的清算设计;W828 后继路径 #1(W774⑤ 支出门落地=P29 门补第三条件金水位辖域门+尾金处理)与本设计 D1 臂同物,#2 观察点按 W830 v2 改判后由 §5.1 的 M1-L 分布级格承接(原「中位格 3→2」措辞作废,依 W830 分层证据:中位层配对差 −0.019 严格为零,效应在靶点不存在,非灵敏度问题)。

### 5.1.1 G7/G4 预期带的分层口径(v2 立;v3 判据名随 §5.1 同步+警报三修,依 W830-C 核验 B)

W830 分层教训:全臂均值可能掩盖分层结构(M1 的全均值 p=2.6e-6 掩盖了中位层零)。G7/G4 是帧占比指标,分层维度取 **off 臂 M1 轮距层三分**(≤2 / =3 / ≥4,与 W830 分层同源,可逐 seed 复算):

- **预期**:on 臂的额外买入(息侵蚀/挤席来源)在慢尾层(off≥4)最密集,故 G7/G4 残差**预计分层不均**——全臂残差可能主要由 off≥4 层贡献,off≤2 层接近零。分层残差才是门靶点读数。
- **分层警报(v3 三修,替换 v2 单一「2× 全臂」规则)**:
  - **跨零病态修正**:v2 的「任一层 >2× 全臂残差」在 off≤2 与 off=3 层病态——这两层残差期望≈0,任何噪声都是无穷倍数。v3 改**层特定阈值**:off≥4 层(残差基数非零)维持「>2× 全臂残差」;off=3 与 off≤2 层**免倍数警报**,只适用下面的转正判据。
  - **「转正」加负基线锚**:v2 的「off≤2 层转正」无判据(层残差自预期≈0,采样噪声下点估计每批都会随机偏正)。v3 判据=该层残差的 **bootstrap 95% CI(重采样 1 万次)整体位于 0 以上**——显著偏离 0 才算转正,点估计为正不警报。
  - **噪声带**:所有层的倍数警报触发线取 `max(2×全臂残差, 该层 bootstrap 95% CI 半宽)`——CI 半宽以内不警报,防小样本层假触发;CI 半宽随批次落盘,供跨批可比。
- gate-only 消融臂:**选择性恒等**(拒因零命中帧位集)按层核验,防「某层拦、某层漏」被全臂对拍掩盖。

### 5.2 A/B 判前锁草案(**PREREG v4,独立成文,开跑前冻结**;v3:撤销「协议 v3 零改动」声明,主门与定位统一)
