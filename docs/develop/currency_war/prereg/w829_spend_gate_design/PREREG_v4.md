## 3. 开臂主门(单一口径,全过才翻默认=生命周期第 3 态)

**清账门 ∧ 传导格 ∧ 护栏面:**

1. **清账门**:
   - **G4 存活挤席(主格)**:≤ +2pp(W828 基线 +2.29pp 回门;分项读数
     = 纯 `d3_bench` 计数,与既有 bench 容量守卫计数零混账,§3.2 去重)。
   - **G7 息基侵蚀(U 推导带,非硬带)**:≤ on 基线 + (2.89pp − U) +
     2×层 bootstrap 95% CI 半宽;U = 冻结前置件 #1 复算值(§6);
     U ≥ 1.9pp 时带收紧为 ≤ +1pp(与「≤+1pp 回门」原格衔接)。
2. **传导格(至少一肢正证据成立,§0-1)**:
   - M1-L:off=3 中位层(n≈108)配对差均值 <0 ∧ bootstrap 95% CI
     上界 <0(重采样 1 万次);或
   - 阶跃兑现率:M1 改善局「deployed 域激活档 +1 事件数」配对差
     CI>0(显著为正;ADR-0494 口径)。
   - 护栏(非过门肢):阶跃兑现率配对差 ≥0(不降)。
3. **M4 存活轮**:方向非负(否决向护栏,sim 结算键天花板,不作传导证明)。
4. **G2 终局带金**:不升(维持门内)。
5. **gate-only 选择性恒等过**(§1(a);按层核验,防「某层拦某层漏」)。

辅助读数(不判格):全臂 M1/M3 均值与中位照报;M2 延迟/D1 腾席不计格,
归实机锚(W814 修正方向 #2/#4)。旧「M1∧M2∧M3 至少其二」全臂主门作废。

**Goodhart 警报**:任一臂 >30% 帧被门拦(拒因枚举占比)→ 门判据过宽,
回豁免面重审,不调阈值。

**失败分流(禁第四态)**:清账门绿∧传导格双败 → 门维持关、语义按
「清账已证+传导归实机锚」保留;清账门红 → 判据回炉非删伞(D3 拒因
开火不足=触发面问题;G4 红且 d3_bench 计数≈0=上提未生效;G7 超带=
E-b 放行代价被低估,回权衡登记)。

### 分层口径(G7/G4 残差,off 臂 M1 轮距层三分 ≤2/=3/≥4)

- off≥4 层(残差基数非零):「>2× 全臂残差」倍数警报**仅全臂残差为正
  时适用**(W830-F 观察 2 跨零残余修);off=3 与 off≤2 层免倍数警报。
- 「转正」判据:该层残差 bootstrap 95% CI(1 万次)整体位于 0 以上。
- 噪声带:警报触发线 = max(2×全臂残差, 该层 CI 半宽);CI 半宽随批落盘。

## 4. 越权修订显式声明(治理级,W830-F 张力 2)

**本判前锁对 W828 判前锁后继路径 #4 的「未清」定义作窄化修订**:
W828 原文「G7>+1pp 或 G4>+2pp → 机制挂账未清,禁止局部开臂」中,
G7 超出部分自本锁起**二分**——(a) U 覆盖内的残差仍属「未清」(门可达
拦截面,门失职);(b) U 覆盖外的残差(E-b 豁免放行的线内破息买入,实证
占额外买入 99.1%)改判「**已接受取舍**」,非未清挂账——依据 = W830-G
攻击 A 复算(G7 与 M1 在当前出手结构下是同一笔钱,门在两者之间没有
免费午餐)+ v3 §5.1 的取舍登记。取舍翻案条件 = E-b 收窄版(加 R_rest
下限)作为独立消融臂在后续批证明 G7−U 差可回收且 M1-L 不失。两份判前
锁对本条的辖域关系以本声明为准,「挂账」不再各说各话。

## 5. 豁免判据操作化引用(冻结面)

- **E-b(v3 内联)**:锁定线缺档成员(`missing_members` 单一源直判)
  ∧ hp > emergency_hp;不引用 P29 项(循环豁免修)。

  帧内计数在采纳处登记(arbiter 采纳块,ADR-0434 E2 同模式)。

  整体让位;末窗(ADR-0451 降格独占)门不新增放行。
