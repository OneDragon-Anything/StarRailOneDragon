# ADR-0010 子代理对抗审查纪律(方案先攻后信)

## Status

accepted(2026-08-22;用户指令「让子 agent 对抗」;回放对拍器与经济对账两轮实战验证)

## Context

分析类方案(对拍器设计/残差归因)直接实现或直接采信结论,错误会在实现后才暴露——经济对账 v0 的「共因说」被对抗审查一击 falsify(符号方向就错),省掉至少两轮错误方向的归因实验。

## Considered Options

1. 方案写完直接实现:实现错误成本高(对拍器 ~250 行);结论错误更贵(错误归因 → 错误修复 → 污染策略)。
2. 子代理审查(中性 review):确认型审查倾向客气,假说存活率高。
3. **子代理对抗审查(攻击型)**(选):明确指令「攻击它,找概念错误/结论误导,宁可错杀」+ 给实测数据让攻击对准实况 + 中途回传数据追加攻击点。

## Decision

选 3,纪律固化:①方案含归因/结论的,实现或采信前起子代理对抗审查(给完整背景+实测数据+明确攻击任务);②审查回来的攻击点**逐条做裁决实验**(每个攻击假设配一个可证伪实验,如符号检查/子集隔离/开关差分),不整单照收也不整单驳回;③被杀假设的教训进发现记录(防再犯)。

## Consequences

- 两轮实战战果:回放对拍器(4 攻击点全采纳:边界自持/v2_state/分工/最小切片)、经济对账(杀 instant 金假说+帧口径伪影,修息基数语义,发现 BASE_REWARD_GOLD 证据冲突)。
- 成本:一轮审查 ~10-15 分钟(后台并行推进实验);比错误方向实机验证便宜三个数量级。
