# ADR-0531: 装备策略残余落码——opening hold 释放门收窄(逐件判定)+ 工具件消费判据面(G1 准入)

## 背景

21 号稿(`docs/develop/sr_od/application/currency_war/strategy-docs/21_opening_window_and_tool_consume.md`,
as-designed v3,三轮对抗 ATTACK_R1/R2/R3 零发现收口)合并两账本残余(流程:36/流程:126):

1. **opening hold 无条件扣留**(18 号稿判据表 row1 原样):只要 P1 r≤2 且节点非战斗,
   自由件一律囤——但 r≤2 非战斗节点后必跟战斗,装备从判定到落穿只发生在备战帧,扣到
   战斗帧就晚了(病灶 run_20260902_195720 r1–r4 四轮裸奔;run_20260902_181254 13 件滞留
   到死)。缺的是「扣留的资格判据」。
2. **工具件消费语义空缺**:工具 7 件(冶金炉/扳手/精密扳手/投影仪×2/令牌/特权卡)跨局
   恒定滞留(十五~十八局段各局复盘),10 号稿 §2.1 判据在册但无消费位;且「无件可穿」
   死局已由 M7 门①闭账,工具使用语义成为判读噪声源。

## 决策

按 21 号稿 §5 影响面落码,五件:

1. **row1 收窄为逐件判定**(`kernel/cw_equip_env.py`):`resolve_wear_release` 新增
   `battle_precede_release`(O1 战斗前置释放门,输入 = 后随节点 r+1 台账类型)与
   `node_type_unknown`(保留域⑤);新纯函数 `classify_item_hold` 按 21 号稿 §2.3 求值序
   逐件评估——O3 豁免(rust 压倒保留域全体,含 node None 共现帧)→ O1/O2 释放门 →
   保留域①-⑤ → 清单外一律释放。自由件谓词 `is_free_item`(非 key ∧ 非
   RESERVED_COMPONENT ∧ 非工具 ∧ 非唯一件;静态注册表纯函数,sim 可达)。
   **row2(committed)语义零改动**;唯一 key 件在 row1 帧扣留 = §2.5 有意行为变化
   (唯一件不可再生,保守按最强解读;实测定谳后随 §2.5 收窄)。
2. **消费位逐件化**(`cw_op_equip_all.py`,v3,S6/B1):帧级布尔 `hold` 无法表达
   「自由件穿+key 扣留」混合态——分配输入改 = `classify_item_hold` 过滤后的可释放集;
   原「扣留帧只穿 key_equips 命中件」过滤迁移入件级判定;`hold` 属性降格为 row2 遗留
   观测位。词缀优先层在可释放集非空(部分释放帧)即启用。
3. **遥测分键**(§5,v3,B3):stop_reason 新增 `opening_hold(row1):...` 前缀 → 新归域
   `strategy_by_design_opening`(row1 帧数趋零锚与 row2 committed hold 不回归锚对同一
   帧族预期相反,无分键则 O2 实机验收锚不可判读);旧 `过渡期hold` 前缀 →
   `strategy_by_design` 保持兼容。
4. **工具件消费判据面**(全量收编 10 号稿 §2.1 三道门,零改写;增量 = 21 号稿 §3.2/§3.3
   接口):`evaluate_tool_actions` 判据先行(本批只落冷启动分支 = 炉准入
   `recycle_qualified`+`hoard_gaps` m=1 保留 + 扳手闸 fail-closed;投影仪/令牌(R(c)
   缺档)/未建模新工具一律 fail-closed 带拒因分键;特权卡「key 含特权 ∧ 对应进阶成品
   在手」完整落地,「持有不泄」);`admitted_tool_actions` = **G1 发射位准入**(流程:197
   常驻锁)——执行通道未建档(UI 建档前置 + 工具拖曳 op 批未交付)不发射,
   `TOOL_EXEC_CHANNEL_READY=False` fail-closed(合法开关形态:行为输入未就绪 + 开臂
   判据挂账 = 工具拖曳 op 落码批;判据拒与准入拒分键分开可见,禁静默吞)。
   工具消耗确认通道(§3.2 四态副作用登记+三分支)辖执行 op 批,本批不预支。
5. **sim 注入基建最小面**(`sim/engine_p1.py`,§4/§5 声明):`TOOL_GRANT_INJECT_POOL`
   /`TOOL_GRANT_INJECT_P` 追加件通道旁路,**缺省零漂移**(pool 空 ∧ P=0,池指纹不变);
   伴随面 = 工具不进 equip_allocation 可穿池(执行层 wearable 同口径)。

## Considered Options

- **row1 收窄的判据形态**:a) 阈值门「r≥k 才穿」(引入拍定常数,违数学先行);b) 支配性
  论证消参数——opening 帧自由件结构性无合成减向风险(P1 RESERVED 全保留)、穿戴可逆
  暂借错穿成本≈0、滞留暴露词缀罚——穿上弱占优,严格占优在后随战斗时(选定,零新参数);
  c) 全域开 O2(P2 简易不可逆合成风险未证,21 号稿 §6-7 出辖挂账,不预支)。
- **消费位接口**:a) 保持帧级布尔 + op 内补过滤(执行层第二套时机判断,禁);
  b) 逐件判定 kernel 单一源 + op 纯消费(选定);c) 给 WearReleaseDecision 枚举每件
  输出(接口爆炸,件集现读量在执行层)。
- **工具消费落地深度**:a) 全部工具拖曳 op 一起落(UI 建档未交付,发射必落空 = 第四个
  闩同构);b) 判据面先行 + G1 准入 fail-closed(选定,判据可单帧锁,sim 可达);
  c) 全挂账(炉准入冷启动分支已可验,白白延迟)。
- **令牌/新工具**:R(c) 表未采集、注册表扩容未逐件建模 → 一律 fail-closed 带拒因分键
  (门 C 不可逆性:四选一选错整件报废),不预支时机语义(§3.4)。

## 后果

- 正:195720 型「战斗前置帧裸奔」与 181254 型「非 key 滞留到死」的判据根收口;
  row1/row2 遥测可分判读;工具判据可单帧锁/sim 行为分布观测,发射面有准入不变量守门;
  row2 语义与 fill-only 全部零漂移(锁在案)。
- 负/权衡:`hold` 布尔降格为 row2 遗留位(消费面全迁件级,18 号稿两个旧锁按锁的存在性
  纪律改写,r388/18 锁面 docstring 记原因);唯一 key 件 row1 扣留是待实测的保守选择
  (§2.5 挂账);工具执行面(UI 建档+拖曳 op+消耗确认通道)为独立后续批,
  `TOOL_EXEC_CHANNEL_READY` 翻正时须随批准入测试。

## 裁决期限(2026-09-06 补,策略审查第 37 跳)
