# 绯英欢愉(A 级)

> V4.4 合集 76807134:A 级。攻略直读 [76806732](https://www.miyoushe.com/sr/article/76806732)。
> 代码字段:`COMP_LIBRARY["绯英欢愉"]`。

## 机制(怎么 work)
绯英每释放一次大招,**永久获得 2% 伤害增幅**(无限成长)。开大频繁且是二段大招;配**永动机**(每开 3 大招赠 2 大招)+**火力风暴潮**,高速叠加全局伤害增幅 + 前台强度。

- 羁绊:**3 欢愉 + 3 能量 + 2 量子 + 2 减益**
- 阿哈(欢愉召唤)穿风暴潮 = 给绯英第二件风暴潮(需阿哈第一散件是小刀/鞋才能合成);爻光穿鞋频召阿哈帮叠层。

## 成型阵容(9 人口)
前台:绯英(风暴潮+永动机+冷笑话)+ 杨叔(瓦尔特,推条叠层必备)
后台:爻光(鞋,召阿哈)+ 阿哈(风暴潮)+ 花火/符玄/千冶·刃(开 2 量子 + 2 减益)

## 成型节奏
1. **前期(上 8 前)**:挂**狼尊**开 3 欢愉过渡(也可直接狼尊 c)。绯英来得多就追 3 星,不多不追。
2. **上 8**:踢狼尊,换主角。
3. **快速上 9 找杨叔** → 阵容大成。

## 装备(为什么)
- **火力风暴潮 + 永动机 + 冷笑话引擎**(绯英必备三件):永动机赠大招 + 风暴潮叠前台 + 冷笑话回能 → 叠层速度。
- **反重力皮靴**(爻光):频繁召唤阿哈。
- ⚠️ 只有阿哈第一散件是小刀/鞋时才能给它合风暴潮(=绯英第二件风暴潮);有命座可无视。

## 弱点 / 注意
- 不建议把把硬玩(吃阿哈散件条件)。
- 欢愉是 V4.2+ 新羁绊(召唤阿哈,穿装备强化)。
