# 反甲白厄 打法卡(hard / A)

> 结构化字段单一源:`COMP_LIBRARY["反甲白厄"]`;攻略原文见 [sources/V3.7_阵容_反甲白厄](../../sources/V3.7_阵容_反甲白厄.md)。证据分级见 [README](README.md)。
> 本 comp 是**无阵营独立羁绊特例**:白厄无阵营,独立羁绊「救世主」获所有前台非独立羁绊效果 —— 靠 core_char + 装备 + 机制成型,不靠阵营羁绊(factions/form_tiers 刻意为空)。

## 打法主线

- 白厄单核 + **以牙还牙甲×3** 受击反伤;停留 7 级追 3星(整局停 7);**2星白厄也足够通关**(3星非必需,顺带追三星星期日)。[先验:攻略复核+社区:plaza 帖文]
- 高频低单次机制:多段打它 = 反伤频触发(debuff=buff 典型)。[先验:攻略]
- **闪光手榴弹 + 反重力皮靴尽早合成**(白厄自己不会套盾,防被怪物套圈叠不起盾);能量转显著提升反击伤害,优先找提供红蓝宝石的投资。[社区:plaza 帖文]

## 过渡

- early_power 低 → 前期靠通用过渡(DOT/仙舟),白厄到手才转。[先验:攻略]

## 装备分配

- **3 以牙还牙甲是命**(key_equips ×3);拿不到甲 = 战力腰斩 → 装备补给节点权重最高。[先验:攻略]

## 站位

- 白厄独前排(弃 1 人口换受击密度);领航员绑三月七(高额护盾喂白厄);**前台最好都追 3星**(喂白厄前台强度)。[先验:攻略+社区:plaza 帖文]

## 入场/退场信号

- 入场:持「白衣伙伴」(白厄/星期日互升3星);持「轮回不止」(送白厄+轮回者);以牙还牙甲在手 ≥1。[先验:攻略]
- 退场:甲迟迟不刷(装备依赖成型卡死)/「榜样激励」类单核 counter。[先验:攻略]

## counter

- 克我:榜样激励类单核 counter;**红绿灯 = 一生之敌**(多篇一致);**禁忌:不能让白厄吃到燃血**。[先验:攻略+社区:plaza 帖文]
- 利我:正当防卫 / 忍无可忍 / 多段惩罚(敌方反伤与频攻击 = 反甲触发源;同一词缀对常规阵容是克、对反甲是利);开局刷忍无可忍/同步行动(敌快速行动)= 反甲流天胡。[先验:攻略+社区:plaza 帖文]
