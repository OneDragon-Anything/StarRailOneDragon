## 1. 两臂定义

- **对照臂(control)**:HEAD(含 W760 实施但开关 off)。零漂移锚=开关 off 与 HEAD 行为逐位一致。
- **实验臂(treatment)**:同 HEAD + 开关 on(**设计 v3 两通道版**:通道 A 定向授权 + 通道 B 止血授权 + 末窗豁免收窄 + 预算带对齐)。
- **池指纹**:两臂同池;跨日对照先核池指纹,不一致整批作废。建议沿用 W762 池(`6400d5d8edeaf68d+eqg1`)同种子主窗,便于与 v2 结果直接对照。

## 2. 规模与工况(沿 v2,功效核算不变)

- 每臂 **n=500 局**;同种子配对,主检验=配对 McNemar。
- 功效核算(v2 冻结口径):基线 P2 死亡率 76%(W752;W762 实测对照臂 79.0% 同带),最小可检差 **Δ=8pp @ 功效≈80%**(双侧 α=0.05,独立口径 SE≈2.8pp;配对实际更厚)。机制预估:v3 覆盖修复后死亡率降幅预期 >8pp(248 高金死亡局是直接作用面)。
- 开跑前冻结;开跑后判据与 n 均不得改。
- 工况:plane=2 生效,P1 不改(P1 指标=护栏面)。

**归因规则(事前写死,三分支;W758-v3 面④——防第二次失败误归因)**:

1. **M0a 不达** = 覆盖修复失败(谓词仍打不进死亡窗)→ 回本设计层查触发判据,不调占位值;
2. **M0a 达 ∧ M0b 不达** = **通道 B 方向梯级失效**(授权了没花:店态与梯级供给不匹配)→ **回本设计调梯级**(梯级降级/D 门槛/保留金),**不诿上游**;
3. **M0a ∧ M0b 双达 ∧ M1-M3 不达** = 「授权可达且出手但救不动」→ 归因**上游病灶**(P1 出口形态/血线,W762 建议同款),兑换目标=上游病灶设计件。

出手的 Goodhart 反向(为出手而买散件)由三重合围防:「纯散件恒不授权」+G1-B 账红线+M3 形态判据(W758-v3 面④附注确认,非对称漏洞)。
