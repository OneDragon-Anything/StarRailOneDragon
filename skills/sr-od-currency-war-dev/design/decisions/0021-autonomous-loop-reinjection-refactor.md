# ADR-0021: autonomous-loop.md 按「只被读一次」重构——过程纪律迁入再注入通道

- 日期:2026-08-26
- Status:accepted(落位实施分批进行)

## 背景

用户点破关键事实:`references/autonomous-loop.md` 大概率只在**入场时刻**(宣布进入自主推进、走开启 checklist)被完整读一遍;此后上下文被实际任务充斥,agent 不会再回头读它。文件里的过程中条款若没有再注入通道,等于没写。

通用决策(三问判据/三通道)单一源 = `od-dev-agent-autonomous-mode` ADR-0010,本文只记 CW 实例化。

## 决策

autonomous-loop.md 终态定位 = **入场建网配置说明书**(七角色/间隔/提醒词全文)+ **事件触发节**(哨兵报警消费);过程中条款按下表逐条迁入再注入通道:

| 现位置 | 条款 | 通道 | 落位 |
|---|---|---|---|
| 派单硬规范①-④ | 前置阅读/判据来源/动作五查/文档面 | 混合 | ①已在「文档对照」提醒词;②③④为冲动型(顺手派单不等提醒)→ 候选进 AGENTS.local 编排者铁律行;同时提醒侧由「派发盘点/文档对照」行点名 |
| 派发扫描源 C+E | 同根症状/理念核对 | schedule | 并入「派发盘点」行提醒词 |
| 对抗审查两形态 | 后置闸门/决策时对抗 | 混合 | 「结论出来顺手就信」=冲动型 → 候选进 AGENTS.local;触发场景亦可由深度巡检行带 |
| 素材泵·轮转消费 | 局后判读/新问题建档/样本点账 | schedule | 并入「派发盘点」行提醒词(补素材积压问句) |
| 素材泵·默认态 | 实机默认一直跑/暂停判据 | skill 原位 | 决策时刻纪律,建网决策时读(入场即在) |
| 哨兵报警消费 | exit=待验证事件 | skill 原位 | 事件触发,报警到达走分诊表路由到本节 |
| 七角色表/间隔 | 建网配置 | skill 原位 | 入场建网时消费,物化为提醒词后完成使命 |

## Considered Options

1. 保留条款在文件内+要求周期重读——否决(ADR-0010 选项 1);
2. 全部塞进 AGENTS.local——否决:违反六字段最小面;多数条款是动作时刻纪律非冲动型;
3. 逐条三问落位(选)。

## 后果

- 提醒词内容列变厚(派发盘点行吸收 C/E 源+素材问句),须守 ADR-0009(大白话+指针化);
- AGENTS.local 编排者铁律行可能需扩(派单前过①-④、结论采信前对抗)——**该文件改动须用户另行批准,本 ADR 只记候选**;
- 派单硬规范本体留在 autonomous-loop.md 作为提醒词/铁律行的指针目标(单一源,字段与提醒词只点名不复述)。
