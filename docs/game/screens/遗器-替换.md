# 遗器-替换(relic_replace)

> source_image: sr-od-test/screens/遗器-替换/default.webp(2026-10-17 live 建档,黑塔头部遗器详情)
> id_mark lcs 已收紧至 0.7(与「角色-遗器」的「遗器着装」撞车,live 实测并修复)

## 何时出现

「角色-遗器」屏点任一遗器件(或替换按钮)进入。独立屏(整体布局,非 overlay)。
显示:左侧=该部位可用遗器网格(该角色持有+背包),中=选中件大图,右=选中件完整词条。

## 状态流转

```
角色-遗器 点遗器件 → 本屏(默认部位=所点件;顶部部位 TAB 可切 6 部位)
右上返回 → 回「角色-遗器」
卸下/重掷 → 有副作用操作,扫描 app 禁触
左下「遗器建议排序」按钮 → 「排序规则」弹窗(明细见「遗器-排序规则」doc)
弹窗:关「遗器建议排序」开关 + 基础排序选「等级」→「确认」→ 关弹窗,列表转静态排序
重进替换列表 → 排序重置回「建议排序」开;复用已开列表(不重进)则排序保持不变
```

## automation 要读信息

- 读区-遗器名 [1478,158,1905,218]:OCR(如「翔鹰的鹰击指环」)
- 读区-部位等级 [1478,218,1700,300]:部位名+「+N」两行 OCR
- 读区-主词条 [1478,305,1905,360]:主词条名+数值(橙色高亮行)
- 读区-副词条 [1478,360,1905,525]:最多 4 行「词条名 数值 (强化次数)」——绿色小数字=该词条强化次数(OCR 可读)
- 读区-套装效果 [1478,530,1908,705]:套装名(N)+效果全文
- 网格内每件:+等级徽标+锁定锁标+穿戴者头像角标(视觉/模板;穿戴者角标=该件已被其他角色穿)
- 5 星/品级:卡片底色金/紫(视觉)

## 占用者角标识别(2026-11-10 实机审计定案)

- **语义**:列表卡右上角圆形头像角标 = 该件当前穿着者(与「光锥-替换」同语义)。
  穿着中的件必有角标(含该角色自己穿着的置顶件),仓库件无角标。
  旧结论「仓库件也有头像」系早期误读,已推翻(3 帧 40 卡逐卡 VLM 仲裁 +
  mys 全角色明细穿着反向索引双源一致:12 件在穿副本角标齐全,仓库件全无)。
- **识别**:共用 `equip_owner_match.match_owner`(SIFT 双尺度上采样 + 内点阈 +
  直方图排名 + 歧义降级,方法与参数详见该模块 docstring);遗器角标几何
  圆心≈卡内 (x2-19,y1+34)、直径≈40px,阈值与光锥共用 15。
- **实测**:遗器卡角标直径小于光锥(40px vs 44px),真角标内点 16-30、
  无角标卡面 4-8(阈值两侧余量 +1/-7);基准固化 = 测试仓
  `test/sr_od/operations/test_equip_owner_match.py`(relic_page_top +
  relic_page_hawks 两帧,33 用例)。
- **已知边界**:重掷动画遮罩卡(「重掷中」横幅)的卡面不可识别(masked 不猜),
  但角标在横幅上方未被污染,占用者仍可识别;未知角色/皮肤角标缺模板时
  诚实返回 None(装备 op 侧有「抢件确认弹框」兜底防线)。

## 注意

- **卸下/重掷/替换/装备类按钮一律禁触**——本屏存在真实副作用操作,扫描 app 只读不点
- 副词条不足 4 条时行数减少(未满级遗器);词条强化次数绿标 = 判定「歪没歪」的关键数据
- 部位 TAB 图标无文字,固定坐标点击已建档(部位-头部…连结绳 6 区)
- **「遗器建议排序」开 = 列表动态重排**:重掷动画期间评分持续变化 → 持续重排 + 滚动自动回顶,「识别 → 点击」间隔超 2 秒即落空——静态列表是替换扫描可靠性的前提;排序调整入口 = 左下「遗器建议排序」按钮,弹窗行为与判态见「遗器-排序规则」doc
