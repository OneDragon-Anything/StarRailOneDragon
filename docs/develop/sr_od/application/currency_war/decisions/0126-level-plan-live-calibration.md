# ADR-0126 节点等级计划 live 校准:A8 需更高人口节奏

> ⚠️ **部分撤回([ADR-0127](0127-strategy-review-h1-h4.md) H4,2026-08-15)**:P2 r5-9 目标 9→8(M8 lv9 锚点疑幽灵 —— telemetry p2r1 lv10 与收入模型矛盾,均值 ~10/轮收入不支持 lv6→9 的 178 金)。
> ⚠️ **数据基础已被 [ADR-0129](0129-xp-click-model-and-level-from-xp.md) 推翻**(2026-08-15):本校准依据的等级观测来自旧 read_level 启发式兜底(0129 证实污染 telemetry),M8–M11 等级读数不可信。
> ⚠️ **结论存疑(2026-08-18 用户点破「统一信息源」)**:①「P1 末推 7」的依据是 **M8 单局相关当因果**(等级激进 ↔ 走得远,未控板强/经济混杂变量),非人玩基准;②人玩权威基准 = 用户口述 §7-13(economy_research):**过渡阵容 lv5-6 + 羁绊凑够 ≈ 过位面 1,等级不是病根**——P1 停滞的真病是板面冻结 + 息引擎未立(金从未上 50),等级只是症状。P1 r7-9 lv7 保留仅为保守占位;**等级目标应以 §7-3/§7-12 为准(息引擎优先,核心概率级再追级)**,后续等级曲线校准以 XP 反推真值 + 用户节奏为准,不复用本 ADR 数值。

- 日期:2026-08-15
- 状态:已接受(数据:11 局 A8 live)

## 背景

原 _DEFAULT_NODE_PLAN 为 V4.4 先验占位(P1 r7-9 target lv6 / P2 早期 lv7)。live 11 局数据:
- lv6@1-9 boss 稳定掉 34-40 HP(M9 -34 / M10 -34 / M11 -36),进位面 2 即死于 2-1/2-2(3/3 局)
- M8(等级最激进,lv9)是**唯一**破 2-7 boss 进位面 3 的局
- A8 敌难度 108:单位强度随轮增长超过 lv6 人口的板容量上限

## 决策

P1 r7-9: 6→7(boss 保血);P2 r1-4: 7→8;P2 r5-9: 8→9(对齐 M8 成功轨迹)。

## 考虑过的选项

- 维持原值等更多数据:M9-M11 已 3 局同模式一致死亡,证据足
- 更激进(P1 后期直接 8):经济不支持(50 金息引擎会被拆),渐进校准

## 后果

- XP 支出上升 → 中期买牌预算略降(tempo 例外 ADR-0124 补偿:板增强散牌仍会买)
- 预期:1-9 boss 掉血 ≤20,位面 2 进场 HP≥40
- 验证:M13+ 对局 HP 曲线
