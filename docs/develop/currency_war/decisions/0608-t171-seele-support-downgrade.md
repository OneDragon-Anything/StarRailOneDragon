# ADR-0608 — T-171 批序 2:希儿系支持度端口降档(去重成员计数单一源)

## 背景

模拟批证据(账本 T-171 行:锁线对 form_ok 1/11 vs 对照 81/89;批#8/#10/20260909 三批一致)证明希儿系配对的成型判据存在两端口缺陷。设计方案 R2(attacks/t171_xierie_criteria/设计方案.md)定批序 2→1→3:本 ADR 记录批序 2(支持度端口降档)的决策本体。方案审(修改后放行)F5 裁决+落地审(可提交)八条要点为本文依据。

## 决策

希儿系两腿支持度改为单一源分级公式 `_seele_system_support`(kernel/cw_intention.py):

```
support = 0                                  若希儿 ∉ 手上
support = min(1, max(c_量/2, c_贝/2))        否则
```

- **计数原语 = 去重成员计数**(按名 set,不读星级):羁绊激活语义,对合成零扰动。0.5=max(1/2,1/2) 为推导后果非拍定值。
- 替换旧口径「希儿到手即支持度 1.0」(cw_intention.py:526 旧态)。旧语义被本决策取代(ADR-0519 C2 post-state 条款:锁门=满员 1.0 的"post"态由分级支持度+锁门槛共同定义,取代 C2 原文单卡即满的隐含前提)。

## 坐标系声明(同文件两套计数口径并存,设计决定非疏漏)

| 去重成员计数 | 希儿系两腿(_seele_system_support) | 羁绊激活语义,合成零扰动 |
