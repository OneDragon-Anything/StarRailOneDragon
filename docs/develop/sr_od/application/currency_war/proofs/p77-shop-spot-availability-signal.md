## 0. 问题重述与现行形态(代码直读)

### 0.1 用户场景的形式化

一帧商店(5 槽)出现 k 张某候选线的牌。用户直觉两段:①「转型信号」——连出说明该转这条线;②「便宜收集窗口」——现在收便宜。现行申报:评分输入 = 持有(缺口)/牌池(q)/剩余回合/金日程/等级场景,现货视为瞬态。待证问题:

- **甲**:这 k 张对「该线收集成本/时间」的贝叶斯更新量是多少?
- **乙**:现行件级估值/购买判据是否已含「当帧可得」折现(P01 再遇窗口项)?缺口在哪、行为偏差是什么、用户场景会不会复现?

- **丁**:可得性折现项如何嵌入 P76 组合期权模型,对 θ\* 的影响方向?

### 0.2 机制前提(全部【注】,单一源)

1. 每帧 = 一次独立抽样:节点切换自动刷新全店、跨节点零继承、升级不触发(economy §2.1);付费刷新每次再给 5 槽同分布试验(`SHOP_REFRESH_COST=2`)。
2. 槽级模型:槽费用档 ~ `REFRESH_PROB[L]`,档内从剩余同费池**无放回**均匀抽(`_refresh_dist` 超几何;轮岗备战期内某档 ×2,`ROTATION_CHANCE=0.2`,概率条直接印在店面板上)。
3. **不买 = 回池瞬态**:展示不消耗池;只有买入永久离池(持有副本数不变量,economy §1)。卖出还池(往返池中性)。
4. 池态对智能体**已知**:a_c/v_c(注册表)、j_x/taken_c(自己的动作)——先验是点质量,非分布。
5. 概率条直读:生产消费 `effective_refresh_prob`(概率条实读优先,解析失败回退基线表)。

## 1. 命题甲:现货观测的信息含量(零更新定理)

### 1.1 定理 甲.1(零更新)【推】

设池态 s_t=(a_c, v_c, j, taken)与当帧概率条 bar_t 已知。则对任意**以未来抽样为自变量(固定动作轨迹)**的「未来收集时间/成本」泛函 g(T_future):【推·修正 1】

```
E[ g(T_future) | S_t = k 张该线牌 ] = E[ g(T_future) ]
```

即**贝叶斯更新量恒等于 0**。证明:在前提 0.2 下,各帧抽样条件独立同分布(帧内无放回、帧间有放回——未买牌回池),未来抽样的分布是 (s_t, bar_t) 的已知函数(点质量先验);S_t 与未来抽样条件独立,故任何以未来抽样为自变量的泛函的条件分布等于无条件分布。∎

**量词辖域注(修正 1)**:限定词「固定动作轨迹」不可去——反应式策略按 S_t 决定买不买,买下则 j 跳升、T_future 分布严格变(如「见到即买」策略下 S_t=5 张帧 vs S_t=0 帧的完成时间条件分布不同),故「对任意泛函」的全称版本为假;真命题 = 陈述与证明步共用的「以未来抽样为自变量」口径(给定动作轨迹不随 S_t 变,现货观测对未来抽样分布的信念零更新)。下游消费核对:读法一(「连出无前向预测力」)与读法二只谈信念面、丙.1 的 I(S_t;U|状态)=0 中方向效用是状态确定函数(与动作路径无关)、甲.2 本就是动作通道的独立命题——**四处均只消费固定轨迹/信念面版,不受此限定影响,结论不变**。

**读法一(对用户直觉①)**:「连出多张 = 转型信号」在信息论上无支撑——把独立抽样的巧合读成趋势是赌徒谬误形归因。量化:3费@L7 单卡逐帧出现率 q=0.1357【推】,连出 3 帧的先验概率 q³≈0.25%——罕见但绝不不可能,且**零前向预测力**。「连出」的唯一真实跨帧相关源是轮岗翻倍带(备战期内恒定),而它被概率条直读支配(见 甲.3-i)。

**读法二(对任务书「更新量受限于池先验」)**:更新量恰好被池先验的**非退化剩余**决定。注册表模型下先验是点质量 ⇒ 剩余为 0 ⇒ 更新为 0;只剩两条非退化通道,即 甲.3。

### 1.2 定理 甲.2(动作兑现)【推】

现货观测的全部决策内容在**买动作**里兑现,不在信念修正里:买 = 永久离池(进度 j↑ 入账 + 池压缩 taken↑[P49 线性律]);不买 = 下帧回池瞬态蒸发,弃购代价 = P01 再遇窗口 E[1/q 帧](q=该卡逐帧出现率)。买动作的价值判定不需要任何方向信念更新——它是时机比较(现价+携带 vs 再遇窗),P01 已定价其形态。

### 1.3 条件性非零域(甲.1 的两条例外)【拟·条件,fail-closed】

| # | 通道 | 内容 | 为何当前更新仍取 0 |
|---|---|---|---|
| i | 轮岗带 ∧ 概率条不可读 | 现货构成对「翻倍档」携带似然(后验向观测档上移,该档 q 上限 ×2,持续到备战期结束) | 生产概率条实读优先(`effective_refresh_prob`)——同信息存在**更优仪器**,现货计数被 Blackwell 支配;且轮岗信号是**费档级非阵容级**(「3 费翻倍」≠「量子线要来」)——即便消费也只进估值/搜索面,**永不构成方向证据** |
| ii | AI 耗池(P38 O2 未决) | 若池为共享,现货观测 =「该线剩余副本未被搜走」的似然证据,方向真实(未来可得性好于先验) | O2 未决 = 先验带不可申(A3 现行口径:池衰减只计自购)⇒ 更新不可量化 ⇒【拟】不合格禁消费;且其内容仍是 **q 修正(估值面入量)**——要变成方向证据需「AI 购买与阵容相关」的元模型,机制未知不可证,出辖 |

**甲的总结论**:信号价值只在「买」这个动作里兑现(甲.2);对「看不看得出该转线」的更新量在现行机制下恒 0(甲.1+甲.3 两通道均不达方向门)。

## 3. 命题丙:进法裁决(a 购买估值加成 vs b 证据门辅助臂)

### 3.1 定理 丙.1(b 的空域定理)【推】

在前提 0.2 下,S_t ⊥ (未来抽样, 终局价值) | 状态 ⇒ 对任意方向效用 U(选哪条线),互信息 **I(S_t; U | 状态) = 0**。证据门辅助臂的似然比恒等于 1:E[score(line) | S_t] = E[score(line)]——它与现行 P_complete 计算在代数上不可区分。**b 无信息可加**:方向信念的合法更新源只有持有进度 j、池参数、环境知识 w——现货频次不在其中。∎

### 3.2 b 的成立三条件与现行机制对照(如实推导,不预设)

b 非空需要:①存在隐状态 h 使现货观测似然 L(S|h) 非常量;②h 无更优的直读仪器;③h 的先验带可申。现行机制逐条:

- **轮岗档 h₁**:①成立(构成↔翻倍档);②**败**——概率条是近无噪直读且备战期内恒定(一次读覆盖全期),现货计数是被支配的噪声代理;且 h₁ 是费档级非阵容级,内容只达估值/搜索面;
- **AI 耗池 h₂**:①成立;②成立(无仪器);③**败**(挂 P38 O2,先验带不可申)——且即便 O2 判共享池,其信息内容仍是各档 q 的修正(估值面入量);要成为方向证据需「AI 购买偏向哪些线」的对手元模型,机制未知、不可证明,出辖。

**结论**:b 作为**方向臂**在现行机制全域为空(丙.1 结构定理 + 两通道均不达方向门);现货观测一切可信息化的对象(轮岗带、池衰减)都归宿于估值/搜索面——即 candidate a 的辖域。

### 3.3 定理 丙.3(a 的正确性)【推】

现货的价值在买动作里兑现(甲.2),买 vs 不买是**时机比较**不是信念问题(甲.1)——正确的进法 = 把可得性折现加进**买面比较子**(乙.2 三缺口:2★ 现货比较子、V_slot 装载、s_reserve 拒绝对价),锁线判据(方向面)不动。三重背书:①与 甲.1/丙.1 一致(方向面加了也是零项);②不新增常数——比较子输入全为【推】窗口(§1.4 表)+ 在册【拟】(u/U_X),过 §1 零调参门;③与 P76 戊不冲突——戊批判的是方向面的常数阈值,a 不触碰该面。预判「a 是主形态」**成立**;b 的残余价值(概率条不可读帧的轮岗推断、O2 共享池后的 q 修正)即便成立也经 q 进入估值面,不构成独立的证据门臂。

## 4. 命题丁:与 P76 的合流(可得性折现在组合期权模型中的位置)

### 4.1 定理 丁.1(协议不变分解)【推】

**领先线 ℓ\* 的现货溢价对锁/等两协议不变**:两协议都即买 ℓ\* 现货(买到即永久入账,P76 §3.1;义务/支配臂协议无关)。**前提:臂序不变性(备注 6)**——ℓ\* 现货(线内成员)走 M2 义务位,在选择序中先于 discretionary 位(压库/EV 面,shop.py L488-492 选择序「M4 → M2 → dominance → C1 → M3 → M6 → EV 买面 → …」),其可负担门为裸金门(mandate.py L164-170,无息律门)⇒ 预算挤占只能发生在 discretionary 位、不能撤走义务位的 ℓ\* 现货买入;discretionary 位 ℓ\* 购买(支配/EV 面)的挤占残差为二阶量,并入 ε₂ 申报。在此前提下 ⇒ 溢价在锁线不等式 Γ+C+D ≥ O+F+B 的**协议差分中相消** ⇒ 可得性溢价**不进入** Γ/O/F/B/C/D 任一项。推论一:把现货溢价加进锁线判据 = 双计,禁止;推论二:买面加成(丙.3)对 θ\* 数值**无影响**。预算竞争交互(买现货的金两协议下影子价不同)为二阶量,并入 P76 丙.4 的 ε₂ 带申报,不破一阶分解。∎

### 4.2 定理 丁.2(现货流已在 P76 内部)【推】

「当帧现货」(在售个体)与「现货流」(各线逐帧到达率 q_i)是两个对象。P76 不等式的 O 项(反超期权)概率因子 P_i^port 与 F 项 P_miss 消费的正是 **q_i**(P38 闭式/P41)——侧线现货的到达流**已经在 P76 内部定价**,无新项可加;缺的是装载(P_i^port 生产未算、价值因子挂 V_ms【拟】在册)。P77 的辖域 = 前者(个体现货的时机定价),与 P76 正交且互补。

### 4.3 定理 丁.3(θ\* 的唯一通道:稀缺帧经 C_sat,方向向下)【推】

可得性折现影响 θ\* 的唯一一阶通道 = **V_slot 装载**:C_sat = 1{f≤1}·P_block·V_slot(P76 乙.2),V_slot 装载 u·P_miss·C_rescue 后,free≤1 帧的等待成本 C 上升;由 θ\* = E[P′] + [O+F+B−C−D]/(V_C−V_F) 与隐函数定理,∂θ\*/∂C = −1/(V_C−V_F) < 0 ⇒ **稀缺帧 θ\* 下降(偏早买/早锁向)**——与 P76 戊 域 α「现行系统性偏晚锁」的**修正方向**一致(精确表述,备注 8:稀缺帧(f≤1)本身非域 α 帧——α 特征含「备战席空」,与 f≤1 的席位紧张相反;「同向」仅指 θ\*↓ 的纠偏方向重合,非域归属,勿读成「稀缺帧属域 α」);free≥2 帧 V_slot=0 ⇒ θ\* 不动。方向【推】零参数;量级挂 u/U_X【拟】(在册,装载义务同缺口面 2)。∎

## 9. 白话摘要(给用户)

**你的直觉一半对一半不对,而且对的那一半,机器人现在的账本上确实缺一块。**

**「连出 = 转型信号」:数学上不成立。**商店每一轮都是独立抽牌——这轮连出量子牌,不代表下轮更容易出。你自己早期就裁定过一次「商店刷新独立,观察没有预测力」(选阵容可得性那次);这次把它证成了普遍定理:看一帧店面对「该不该转线」的信息量**精确为零**——因为牌池里还剩多少张、各级出什么费,你本来就都知道,店里刷出什么只是把已知概率抽了一次样,不新增任何东西。把「连出」读成趋势,是把巧合当信号。

**「便宜收集窗口」:有一半是真的。**真的部分:①现货本身过了这村没这店——不买,下轮就回池,再见到它平均要等 7 帧上下(3费@7级;5费在低等级要等 60-180 帧,和你最早算的账完全一致);②如果当前备战期正好轮岗翻倍了这个费用档,窗口真的减半(约 4 帧)——但这件事概率条直接写着,不用从出牌频率猜。假的部分:窗口的「便宜」不在价格上(牌价恒定),而在「省掉等待和省掉刷店钱」——这价值只有在**买**这个动作里兑现。

**机器人现在的账本查下来:P01 那笔「弃购代价=再遇窗口」的折现,在体系层面有三个合法落点(最后一个备战席值多少钱、买牌支出的豁免判据、卖牌主不等式),生产层面三个全部没装表(末席缺标定默认放行,另两处整个判据面以 fail-closed 挂起)。**好消息是:大部分买牌臂(线内缺件、核心卡、可退燃料)见到就买,本来就不需要这笔折现——它们靠「买了几乎不亏」的支配性直接放行,数学上是对的。真正的缺口有三处:①**手里已有 1 张、店里直出 2★ 同名卡**——现在被「只收 1★」的过滤直接拒掉,但账面上这一笔等于省 30~80 金的搜卡钱(越贵的卡越值),连比较的算式都不存在;②**只剩最后一个格子时**按固定顺序买,不看「这张的再遇窗口值多少钱」;③**预留金不够被拒时**,拒掉现货的代价(再等多久)没有进账。

**你的场景会复现吗?会,而且范围比初稿写的还大一点。**量子牌如果是线内缺的件、或在「K 空窗回退名单」里、或属于核心卡名单,机器人见到就买,不会漏;漏的是**P2 没定型、金在中段、又不在各兜底名单(回退集/核心卡/1 费垫件)里的线外候选件**——而且初稿以为「转线包有专门买入臂兜着」,复核后发现那个臂只在 P1 开(进 P2 就恒不发射),所以 **P2 的转线包成员同样漏**。这个带里买侧没有折现、等侧的期权价值(P76 那套)也没装载,两边都是裸的,行为就落在几条固定门槛上,连出再多也不收。

**进法裁决:修「买牌时的算账」,不动「转线判据」。**因为现货观测对方向的信息量是零(第一条),给证据门加「现货频次臂」加的是零;而买卖时机是实打实缺账的。这也和 P76 接得上:现货溢价**不会**改变锁线阈值本身——因为不管锁不锁线,领线的现货都会买,两边相消;它影响锁线时机的唯一通道是「最后一个空格值多少钱」——格子紧张时,折现装上后会更早锁。这正好修正 P76 已经指出的「格子紧的局系统性锁太晚」。

**挂账三项(都 fail-closed,不影响结论)**:AI 到底消不消耗公共牌池(若消耗,「连出=还没被搜走」就有了真实的正向含义,但量级要实测);2★ 直出卡的出现频率(现在没有模型,上面 30~80 金是按自己搜卡的下界算的);以及早已在册的末席标定(u/U_X)。
