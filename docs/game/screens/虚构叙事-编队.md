# 虚构叙事-编队(treasures_light_pf_team)

虚构叙事**挑战编队画面**(选关点关卡纸鹤进入):左栏战意效果展示/角色列表(二态),
右栏两行(节点一/节点二)各 4 编队槽 + 荒腔走板装配入口。

## 何时出现 + 状态流转

| 态 | 入口 | 出口 |
|---|---|---|
| 常规态(左栏=战意效果面板) | 逐光捡金选关(虚构叙事视图) 点关卡纸鹤 | 点「进入故事」→ 关卡简报横幅 → 节点画面 |
| 角色列表态(左栏=角色列表/预设编队) | 点任一行槽位 | 右上返回箭头收起 → 常规态 |

## 识别特征(稳定锚点)

- **标题-虚构叙事行 + 标题-编队行**(左上两行,双 id_mark):编队帧双中 → precise;
  选关帧第二行为期名 → 不误命中(2026-11-05 实测互斥干净)。⚠️ 常规态与列表展开态
  标题相同,二态靠「区域-角色网格」是否有识别名区分(展开态可读出角色名)。

## 可交互元素(2026-11-05 实机交互验证)

| 元素 | 行为 |
|---|---|
| 行槽位(菱形空槽/已填头像) | 点 = 展开角色列表 + 选中该行(白框);点角色卡 = 落入当前行下一空槽 |
| **已入队角色(列表中点)** | **= 从编队移除该角色**(填充搜索必须跳过) |
| 行右端「+」/效果图标 | 打开荒腔走板装配弹窗(三选一:触技/笑韵/赋格 → 装配效果);每行独立 |
| 按钮-进入故事(右下) | → 关卡简报横幅(「点击空白处关闭」)→ 节点画面 ✓(点击生效但有弹层延迟) |
| 按钮-角色详情 / 按钮-通关阵容 | 辅助查看 |
| 垃圾桶(「角色编队」标题右侧) | 清空**当前选中行**(⚠️ 非全清——两行需各选中各点一次,2026-11-05 实测) |

## automation 要读信息

- 两行成员落位:行槽位头像识别,area「槽位{行}头像-{1..4}」——圆心霍夫圆检测标定
  (行 1 (1296/1382/1468/1556, 774)、行 2 同 x y=886,间距 86px)。
- 左栏角色列表识别用**等级文本锚驱动**(`read_character_cells_by_level`):OCR 找每张
  卡「等级NN」文本锚,锚上方裁头像区(90x95)做脸库匹配——列表滚动任意停驻都可识别;
  固定网格几何(read_character_grid)在半格停驻时行列偏移裁错位,仅停驻位置与标定帧
  一致时可靠。
- 装配状态(行右端图标)、「进入故事」可点态——area 已建(标题双锚/进入故事/行槽位1/
  行装配加号)。
