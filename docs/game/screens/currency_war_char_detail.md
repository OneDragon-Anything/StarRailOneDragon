# 货币战争-备战-角色详情(点角色弹的详情面板)

## 何时出现 + 状态流转

- **触发**:备战画面**点击一个角色**(前排/后排,有装备的)→ 右侧弹角色详情面板。点空白处关闭回备战。
- **角色详情(信息 tab,默认)**:右侧面板显示 角色名 / 前后台定位 / 阵营 / HP·能量 / 属性数值 / 战技天赋描述 / **装备推荐**按钮 / 详情·出售 / 角色穿戴的装备槽(装备推荐右方)。
- **子态① 装备推荐 tab**:点「装备推荐」→ 面板中部显示 推荐装备 / 次选装备 / 合成(盖住备战后台区域)。
- **子态② 装备详情(角色详情内,live 验 2026-08-13 黑塔生命之花)**:点角色穿戴的**某个装备**(装备槽,需角色有装备)→ 面板左侧弹该装备描述(名/类型/属性)+ **可合成列表**(可合成的进阶装备);点可合成列表某项(如步步生花)→ 显示该合成目标详情(属性/效果/**合成公式**/合成至,与源装备对比)。**点空白 → 关闭整个角色详情回备战**(非只关装备详情)。
- **关闭**:点面板外空白 → 回备战。
- ⚠️ **另一个独立的「装备详情」**:备战画面点击**右侧的装备**(非角色)→ 只描述装备的装备详情(装备-only,无角色信息),**与本角色详情不同**(待建档)。

## 识别特征(稳定锚点)

- **「装备推荐」按钮**(面板中下 ~[1440,788,1565,832],组合 id_mark `按钮-装备推荐` + `备战标识-购买经验`)—— 角色详情打开时稳定出现,干净备战时 sub_state 不可见。
- 角色名(面板顶部 ~1494,216,随角色变)、前后台定位、阵营、HP/能量、属性、战技天赋、详情·出售 按钮、角色装备槽。
- 面板叠在备战右侧(x1400+),**盖住备战「出战」按钮**(出战 sub_state 不可见)→ 备战 id_mark 含「出战」→ 角色详情态备战凑不齐 → 不 is_precise(id_mark 区分,见备注)。
