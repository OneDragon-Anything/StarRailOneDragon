# ADR-0248 开局轮同名副本放行(r383b)

## Status

accepted(2026-08-22;r383b;局58/61 对照驱动;口述[1][15] 依据)

## Context

局58(r3 胜)/局61(r3+r4 双胜)与局59/60(r3 败)的边际差 = **开局第三件聚集**(58 买 3 件方向件 vs 59/60 只 2 件)。r383 原设计「买视角刷新臂」(已买<2 且金够→刷)被铁律一否决:口述[1] 明确「r1/r2 固定奖励节点**不 D 牌**(奖励必过,刷新纯烧金)」——刷新路径违反口述。正道是口述[1] 后半句「**保息前提下多买**」+口述[15]「压缩牌库:买的 1/2 星是 3合1 副本素材+把池噪声抽走」:已拥有同名卡的 1 费副本 = 方向已认的加厚(2★ 前置),非线外散买。

## Considered Options

1. **开局轮放行面扩「同名副本」**(选):`_pair_wants` 冷启动门加 `_has_same_name_copy` 直通(branch/deployed 任一同名即真);副本上限仍归 `_buy_guards` copies<3。账本打专属 reason='copy'——与门失效形态(pair/off)区分,冷启动检查器不空转报警。
2. r383 原案「买视角刷新臂」:违反口述[1](r1/r2 不 D 牌),否决。
3. 不动(等供给运气):局59/60 证明第三件聚集 50% 靠运气,r3 胜率 1-2/5 不稳。

## Decision

选 1。配套:`_want_label` pair 分支对同名副本返 'copy'(检查器合法词表);检查器 docstring 注明 copy 语义。

## Consequences

- 开局轮同名副本可买(3合1 加速+压缩牌库);局49 线外散买病不回归(非同名仍拒,锁测试 4 条);
- 板深增长新通道:局61 实证 3合1 是 r6+ 板面质量来源(藿藿/爻光双 2★);
- 冷启动检查保持门失效检测敏感(copy 与 pair/off 词表分离,变异自检不放松);
- 全量 1031 passed。
