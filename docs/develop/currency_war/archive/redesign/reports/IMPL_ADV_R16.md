## 高-1 R14-3 域外态漏掉 line_switch_sell 的 λ 系数处置:可达的卖面 fail-open 缺口

**位置**:设计 §2.7.1「λ 表域外过渡期覆盖条款」+ 登记表 R14-3 方向证明。

**缺陷**:条款对域外态(K=直通线 ∧ λ 表无该桶标定)只规定了两件事——①floor_eff 守息(XP 面)、②F7 卖面段谓词按 λ>0 假设。但 R14-3 自己的方向证明第 1 步明写:"反向桶错配 ⇒ **卖面 λ 上端不足 = 不可逆卖出 fail-open**"。line_switch_sell 的 V_power 全式 `λ′_U×(refund+Δ息流̂)+d̂×(g+Φ̂)` 中,λ′_U 与 d̂ 都不是段谓词,是门槛数值项——域外帧它们取的是**外推桶端点**,按 R14-3 自己的论证"双向不可信、无方向保证"。若域外帧 line_switch_sell 照常评估,V_power 首项与差分项同时可能系统性低估 ⇒ 卖出门槛下偏 ⇒ 不可逆卖出 fail-open——恰是 L-R3-1 Part 1 要消灭的方向,经"域外态不在任何既有守卫触发条件内"(R14-3 开头自己强调的特征)复活。

**可达性核查(非纸面推演)**:R13-1① 前置门的"出口不可用"= 全🔴延迟态 ∨ λ 表损坏态强制停——**域外态两者都不是**(表加载成功、槽位有值、u/V_ms 可已标定),前置门不拦 ⇒ 域外直通局内换线事件可正常登记 ⇒ line_switch_sell 在 K′ 生效帧照常调用,且卖后桶枚举(板面构成−卖出件+bench 维)大概率同样域外。该通道构造性可达,不是边角。

**为什么现有文本盖不住**:"卖面段谓词按 λ>0 假设(R8-3 同款)"只辖 F7 的段管辖判定;R8-3 的强制停清单(line_switch_sell+凑息面)是**损坏态**专属规格,R14-3 未声明域外态并入。两种读法(并入强制停 / 照常评估)在现行文本下都合法——实现者自造方向,正是 R6-5 当年要消灭的缺口在域外域的复发。

**修法方向**:域外帧 line_switch_sell 处置显式规格化,二选一并论证——(a) 与损坏态同款强制停(最简,方向=不可逆面缺可信输入默认不做;代价=域外期换线塌缩整体冻结,由 R13-1① 前置门对称地冻结 K 即可,退化形态与全🔴延迟期同构);(b) λ 系数取表内最保守已载行的上端(L-R3-4 附注退行手法同款)。倾向 (a):域外值连"保守端"都无定义(R14-3:外推值双向不可信),取端无从谈起。

## 高-2(R16 轮按中-1 计)R15-2 证明①「不可分离」论证在数学上不成立,收口封印结论过强

**位置**:登记表 R15-2 定谳「证明(收口保持)」第 ① 点。

**缺陷**:该证明声称"消费方无法从单一输出反解 Φ̂ 数值(单方程两未知量 d̂·Φ̂ 与 d̂ 不可分离,**d̂ 虽由端点可算**但 Φ̂ 不可)"。这个论证自我拆台:d̂ 的两个端点(λ′_U、λ_L)都在启动必载的 λ 分层表里(R2-4),d̂ 可算已经被承认;g 是板面可观测量。于是 d̂>0 时 **Φ̂ = (d̂×(g+Φ̂) − d̂·g) / d̂**,一行除法即反解。方程只有一个未知量,不是两个。"§5-11 违例复活口仍封死"这句结论建立在"不可分离"上,该前提为假。

**后果评估**:这不直接制造行为 bug(合法消费形态=复合项进求和式,不要求解构),但 (a) 引理登记表的【证明】标签下躺着一段无效论证,违反登记表自己的协议("『保守/方向/有界』类声明一律给不等式级论证,禁裸声明"——本条连论证都不成立);(b) 实际防线只剩 §5.3 静态断言,而静态断言只能拦"源码里出现裸 Φ̂/自算 Φ̂"两种**字面**形态——反解出的 Φ̂ 以中间变量/缓存/派生量形态流通时,静态断言与 code review 都未必覆盖,封印强度被高估,下游(如后续轮次有人引 R15-2 作"类型上安全"依据)会继承这个假保证。

**修法方向**:删掉"不可分离"论证,如实降级——收口的真实保证=静态断言+单一源纪律的过程性防线,非信息论意义上的不可达;或改实现形态为真封印(输出封装类型,禁止在判据侧解构/参与除法,由类型系统而非"无法反解"承重),后者才是与 R5-7「类型上不可达」同强度的承诺。

## 中-2 R15-2 第三口「Φ̂ 差分以敞口差增量形式组装」在唯一权威公式中无对应量,规格二义

**位置**:设计 §2.2 line_switch_sell 行 / §1 horizon 行(R15-2 落位句)+ 登记表 R15-2 定谳。

**缺陷**:V_power 全式的唯一权威式(R14-1/R15-1 定谳)= `λ′_U×(refund+Δ息流̂) + d̂×(g+Φ̂)`,其中 Φ̂ 是**现行基础流下界的水平值**(Ī×R_剩余),公式里**没有任何 Φ̂ 的差分量**——Φ 差分项 `(λ′−λ)(Φ_true−Φ̂)` 恰是被显式登记为"残余、不估计"的那一项。而 R15-2 的落位措辞是"**Φ̂ 差分**以『卖后剩余持有流的敞口差』**增量形式**由 horizon 增量 API 模块内组装"。两种读法:(i) 纯实现细节——模块内部用增量 API 算出 Φ̂ 水平值再乘 d̂(数值与权威式一致);(ii) 字面读——第三口输出含某种 Φ̂ 差分(如 d̂×(Φ̂′−Φ̂) 或 d̂×敞口差),与权威式数值**不同**。按纪律"实现者遇缺输入/歧义禁自造方向",这里恰恰留了自造空间,且落在全设计防护最重的公式上。

**修法方向**:钉死第三口输出 ≡ `d̂×(g + Ī×R_剩余)`(水平值,数值唯一);"增量形式/敞口差"要么删除,要么显式声明为"模块内部计算路径、不影响输出数值"并给一行等式证明两条路径同值。

## 中-3 残余通道清单自相矛盾:「CI 端点交叉 |jump 残差|≤半宽和×g」与 R14-1 步骤 2 的"无带符号残差"互斥

**位置**:登记表 R14 对照表 R14-1 行 + R14-1 引理步骤 2「合成」句 + 设计 §2.2 line_switch_sell 行(三处同款表述)。

**缺陷**:R14-1 步骤 2 差分项 g 主部的证明明写"d̂×g ≥ d_true×g——d_true≥0 时由步骤 1;d_true<0 时真值第二项为负、估计 d̂≥0>d_true ⇒ 不等式同样成立。**逐项覆盖对带负真值差分同样成立,无方向缺口**";R13-2 步骤 2 重写段(R15-1)也说"原稿『残差=…×g、|残差|≤两桶 CI 半宽之和×g』系旧双侧上端取法(已随 R14-1 作废)的产物……残余改述为**代价方向**"。但 R14 对照表行与设计 §2.2 行仍写"残余=Φ 差分分量……**与 CI 端点交叉(|jump 残差|≤CI 半宽和×g,与①同族),并列登记**"。同一引理内:g 主部"无带符号残差"(证明)与"g 主部有 |残差|≤半宽和×g 的 CI 端点交叉残余"(登记)不能同真——后者是被 R14-1/R15-1 双双作废的旧取法残句。若"CI 端点交叉"实指 CI 覆盖失误(通道①)在差分形态的实例,则它与①重复计账,不是新通道,不应并列。

**危害**:残余通道清单是下游"禁当强结论消费"的依据,清单里躺着一条已被自己证明不存在的残余=误导下游对该通道做无谓的对拍/验收,也让清单总数(①②③)在不同消费点数出不同值。

**修法方向**:三处统一——残余清单收敛为 ①CI 覆盖失误 ②λ₃ 视界窗口错配 ③Φ 差分分量;"CI 端点交叉"条删除,或改写为"通道①在差分形态的实例,不单列"。

## 低-1(验证缺口)第三口复合项 `d̂×(g+Φ̂)` 数值无对拍锚

**位置**:§5.3 sim 对拍清单 + R15-2。

**缺陷**:R15-2 封死判据侧自算 Φ̂(静态断言红)——这意味着**判据层没有任何合法途径独立复算复合项数值**;而 §5.3 现有锚只覆盖 λ′ 取值/d̂ 分列/枚举失败(卖后桶对拍行)与 Δ息流̂ (Δ息流对拍行),复合项中 Φ̂=Ī×R_剩余 的组装(īncome 三表 × horizon 真值长度)本身没有任何数值锚。V_power 是 fail-closed 方向论证的核心数值通道(R5-1),它的两个被乘数各有锚、乘积无锚——R6-8 当年给 Δ息流建锚的理由("fail-closed 方向在实现层有锚")对第三口同样成立却未建。

**修法方向**:补一条第三口单测锚——模块内直算 `d̂×(g+Ī×R_剩余)`(测试代码消费 statefn 内部源不受收口辖,或由 horizon 暴露 test-only 通路)vs 第三口输出,断言逐帧相等;顺带覆盖 d̂=0(点估计退化)帧输出=0。
