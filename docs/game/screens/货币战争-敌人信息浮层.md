## 双入口布局差异(area 兼容口径,2026-09-02)

两入口弹出的浮层同族不同构,area 取并集兼容,精确读数按下表入口区分:

| 区域 | 入口②遭遇版实测 | 入口①备战版建档值 |
|---|---|---|
| 波次列表 | 宽格两行,x≈50-1000 | 窄列 25-420 |
| 词缀横条 | 难度值在左(88-317)+词缀 340-1030+翻页箭头 | 横条 500-1430 |
| 详情卡 | 1230-1870, 150-560 | 1240-1560, 120-420 |

遭遇版新增知识:顶部页签切两卡后**难度分随卡变**(实测 108+6 vs 108+16)——策略化选卡的难度差数据源;词缀条带左右翻页箭头(词缀多于可见位时翻页,当前读带只covers首屏)。area 坐标若按单入口精配会错配另一入口——文本-敌人名/文本-敌人难度值/文本-词缀读数带现为**遭遇版坐标**,备战版读数前需复核。

## automation 要读信息(中途接管局补采落点)

- **词缀横条**:OCR 词缀名 → `state.enemy_affixes`(接管局补采主通道=位面详情横条随采,`CollectPlaneBosses` 开详情时同帧读);
- **敌人难度值**:OCR → `state.enemy_difficulty`;
- **波次敌人构成**:敌人名/等级(战斗强度预估,判读用——待消费需求落地再建细 area)。

## 子态归属判定记档(四问,ADR-skill 0021)

①dispatch:接管补采需「开浮层→读→关」独立 handler 链,且浮层开着时备战点击行为不同(先关浮层)→ 指向独立;②遮挡:盖住左面板(羁绊区),备战 id_mark 不受影响但交互语义变;③正交:与商店/弹窗互斥(点别处即关),不否决;④粒度:左侧整块布局新增(波次列表+详情卡),非单元素变化 → 指向独立。**结论①④双指向,独立屏**(初判曾误归备战子态,用户纠正后按四问重判)。
