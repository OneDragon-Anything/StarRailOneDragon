# ADR-0441: P2 boss 税 p75 位面锚暂不激活维持 34 + 位面锚消费点接线兑现

- 日期:2026-08-28
- 状态:accepted
- 关联:ADR-0440(P2 损血两态化与双源合一——本评估在其新框架语义下进行)、registry `boss_tax_p75_by_plane`(plane 2 槽位)、`decision_v2/posture_release.py` FLIP 末窗投影臂消费点、`decision_v2/filters.py` C1 投影安全带消费点

## Context(为什么)

FLIP 末窗投影臂判据 `hp − boss 税位面锚 < emergency_hp(25)`,boss 税 p75=34.0 标定自 P1 语料(66 场 P1 boss 战,median 32/p75 34/p90 36/mean 26.7)。registry 已预埋 `boss_tax_p75_by_plane` 位面锚(plane 1 = 现值零漂移锚,plane 2 槽位默认仍取 34),评估目标是 P2 是否应换值/激活。

证据(P2 直接样本 + 三源一致性):

- P2 boss 直接样本:52 个触及位面 2 的 run 仅 7 局到达 boss;非删失 n=1(掉血 23),地板删失 n=5(下界 5/20/21/26/41),团灭 n=1,胜 0/7。p75 不可估。
- 三源一致性把 P2 boss 损血中心质量放在 [21,26]:sim 粗战斗 manifest P2 boss 无条件期望 −21.63(P1 −19.54);ADR-0440 boss 条件败面 15.50、桶存活率 0.000;删失下界族 [5,41] 与之同向不矛盾。
- 决策敏感度:观测语料内零决策后果——判据即 hp<59 触发,观测 7 帧进场 hp ∈ {3,6,21,22,27,30,42} 全部 <48,锚值在 [23,41] 内任意取值决策不变(7/7)。

## Decision

1. **暂不激活改值**:plane 2 槽位维持 34。理由:样本不足以给出任何建议值(非删失 n=1,p75 无估计量,违反决策规则数学先行硬门);分布等价论证不可证(删失占 6/7,「等价」是伪证,诚实结论是「不足以判定」);现有证据不构成「34 对 P2 系统性低估」的方向性风险,且观测语料内改值零决策后果。
2. **位面锚消费点接线兑现(本批落码,零行为差)**:FLIP 末窗投影臂(posture_release)原消费标量 `registry.boss_tax_p75`,位面锚在主消费点未接线——未来改 plane 2 值会静默不生效。本批投影臂改读 `boss_tax_p75_by_plane`(与 filters 投影安全带同源同款取数;投影臂上游 plane>2 已拒,plane ∈ {1,2} 必有槽位,直接字典访问无需标量兜底)。锚[1]=34.0=标量现值 → plane1 决策序列逐位零漂移;锚[2] 现值仍 34,本批不改值。标量自此无运行时消费点,保留为 sim 标定接口(anchor_group P75 同源值)与零漂移锁底座,退役挂账 sim 标定批裁定。
3. **复核触发(满足其一即重估)**:`p2_loss_calib_version` 递增同批;非删失 P2 boss 帧累计 ≥10;P2 boss 存活率脱离 0(两态结构变,34 届时大概率转为显著高估,随开臂批重估)。

## Considered Options

- **激活且改值(弃)**:非删失 n=1,p75 无估计量,建议值无背书。
- **激活维持 34 并宣称分布等价(弃)**:删失占 6/7,等价是伪证。
- **只暂不激活、消费点接线推迟到未来改值批(弃,原评估稿立场)**:接线本身零行为差(两槽同值),但缺口留一天就多一天「改值静默失效」的陷阱面;接线成本极低且本批既有测试面齐全,当场兑现消缺口,不再挂账。

## Consequences

- 行为零变化(P2 沿用 34;观测语料内本就零敏感度;plane1 由锚[1]=标量同值保证逐位一致)。
- 方向性风险存续但未证实:若真 p75<34,代价 = boss 窗不必要提前破息的利息机会成本;量化依赖未来样本,挂账 Decision 3 触发条件。
- 位面锚槽位 → 两大消费点(filters 投影安全带 / posture_release 末窗投影臂)全量接线,未来改 plane 2 值即生效,静默失效面消除;标量的退役归宿由 registry 字段注释显式挂账,不再是隐式知识。
