# ADR-0468: 溢余消费的息档边界截断+结转(tier_truncated_spend)

## 1. 背景与问题

溢余段(g>R*)的非必要消费(常态刷新逐笔、release 义务预算内的负分搜索刷新)不区分金位:花后可以跨过 10 的倍数的息档边界,造成可避免的利息损失。利息 = `gold//10` cap 5,按节点结算,当轮息损 = interest(轮初金) − interest(轮末金),是首末金量的纯函数、路径无关 → 任何轮内花费顺序重排的息损差恒为 0,不存在「排序修法」;唯一真实增量是把每笔非必要支出截断在档内余量(`gold % 10`)内,不花的余量结转下轮(义务逐帧重算,R* 与 C_t 下帧重出,结转零成本、不产生第二义务)。

## 2. 决策

新增纯函数 `economy_cycle.tier_truncated_spend(gold, want, essential)`(零自由参数:`gold % 10` 是息档结构的直接输出),两个消费点接线:

- 消费点 1:`arbiter` 刷新收尾块 release 义务预算分支——逐笔先过截断门(essential=False),截断返回值 < 刷价时本笔不放行(残差不足一刷,余量结转);
- 消费点 2:`posture_release.authorize_release_refresh` 预算放行处——预算检查后追加同一截断门(纵深防御,两门判据同式)。

essential 分类由消费点显式传参,函数不判车道:

- essential=True 枝①:正账件(跨档/合成件,买账已过 scoring 单一裁决面)——一张牌不可拆,截断即弃购,代价归 P1 再遇窗口口径,不辖;
- essential=True 枝②:M-A 定向刷新车道(arbiter 定向授权分支)——末窗没有下轮重摇,截断后残差不足一刷 = 定向搜索永久丢失,弱占优前提对该车道为假,不截断。

## 3. 数学依据(弱占优论证)

非必要支出截断在档内余量内,花后不跨息档 → 息损 0(同档零息损,P13/[11]);不截断的情形息损 ≥0。截断的代价 = 该笔支出推迟一轮,常态刷新的价值无跨轮衰减(下轮重摇,授权逐帧重出,衰减=0)→ 对常态刷新笔弱占优(留金 ≥0、损上限 0)。定向车道不满足衰减前提(无下轮重摇),豁免。

## 4. 被否决的替代方案

- **轮内花费顺序重排**(提案 v1):交换论证证的是空定理——息损路径无关,任何排序的息损差恒为 0,零值机制;
- **凑档选件语义**(v1 §2):候选选择归 scoring 单一裁决面,预算层只裁金额,越辖;
- **全域截断含定向车道**:对无下轮重摇的车道,截断代价从「推迟一轮」变为「永久丢失」,非弱占优。

## 5. 量级与验证口径(如实降级)

每档息损按严口径 1 金/档(下轮收入即刻补回)报 **1-2 金/局量级**;机会成本口径(interest_recovery_rounds=3.0)3-15 金/局仅作上界披露。效应量低于 sim 功效 → **主判如实降级「方向披露」**(诊断:跨档非必要支出帧占比应降、出口 5 闲置金),非劣 = 成型轮次。
