# 数据管道（官方数据与视频调研怎么来）

> 数据抓取的技术路径与解析坑；状态对账见 [research-status.md](research-status.md)。快照产物在 `references/data/`（skill 自包含）。

## 米游社百科 API

- **角色词条列表**：`home/content/list?app_sn=sr_wiki&channel_id=18`（角色）/ `channel_id=19`（光锥 170）/ `channel_id=30`（遗器 62）。返回 `data.list[0].list[]` = 词条（`title`+`content_id`）。
- **角色详情**：`content/info?content_id=`（takumi-static 域，带 UA）→ `rpg_new_tmp_content.modules` 含 15 模块（角色信息/晋阶/行迹/星魂/**光锥推荐**/**遗器推荐**/**配队推荐**/攻略推荐/故事/语音/关系/解析/考据/画廊）。
  - 行迹数值：`points[i].name / .tableData.rows（等级表，末行=满级）/ .subList[]`
  - 光锥/遗器/配队推荐：`components[].data` JSON 的 `richText` 键（HTML 表格）
- **光锥详情**：`contents[0].text` 的 `data-data` URL 编码 JSON（rpg 模块是空壳）：`career`（命途）/`rate`（星级）/`skill`（特效含叠影梯度【】格式）/竖排键值表（实装版本→获取方式）。
- **同名字条目坑**：列表有重复/同名条目（银狼=经典 1085 / 银狼LV.999=SP 7044）——按 content_id 精确取。

## 百科页面三种模板形态

“无数据”多为解析问题而非真无：
1. **新模板**：rpg 模块 `components[].data` JSON（`richText` 键）
2. **旧模板**：rpg 模块全空，数据在 `contents[]` 页签富文本（如椒丘 3058 的「配装配队」页签里遗器+光锥同表）
3. **形态角色按形态分词条**：开拓者无单词条（•欢愉/•记忆/•同谐/•存护/·毁灭 各自 content_id 且有重复）；三月七（48）与仙舟三月七（3121）分档

供稿攻略组不同排版不同（摸鱼组 vs 银河垃圾桶组）——行解析用「单元格流顺序扫描」（名→面板→推荐度→特效）比状态机稳。

## 前瞻未实装判定

行迹模块名含「前瞻」且 points 全空 = 占位词条（艾莲/耀嘉音/星神★阿哈）——不建档。国内列表为全量基准（HoYoWiki 列表可能滞后）。

## bili cli 视频调研管线

`bili --compact search video "<角色> 培养攻略" --order views` → 选片（攻略向标题+高播放+**desc 预筛**——西川柚季/法拉拉系 UP 的简介常直出全套口径，先看 desc 省 API）→ `bili --compact video summary <bvid>` 拉 AI 总结。无总结/无字幕就换关键词（「<角色> 攻略」/「<角色> 专武」）或换 UP 再搜。管道脚本：`.debug/temp/deepdig_*.py`（search/pull/list/read/apply）。
