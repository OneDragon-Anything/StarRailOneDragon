### F1【阻断】门 2 义务集豁免两读必歧 + 通道 3 理由句与代码体相悖——D 情形与 3(a)/3(b) 按字面不可达

- 位置：design.md:41（§2.2 义务集面域切分）、:44-49（§2.2.1 通道定义）、:60（枚举 D 放行）、:93（名单让位末位语义）、landing.md:35（「名单成员让位通道专项：同名升星让位（3(a)）放行」）。
- 文本两读：headline「拒卖腿在**换血让位路径豁免**」是路径性表述（读 A：三通道 victim 全豁免）；紧随的「§2.2.1 白名单**通道 1/2** 的 victim 豁免义务集拒」是通道枚举（读 B：仅 1/2 豁免）。两读对通道 3 结论相反。
- 代码体实况（直调）：义务集闸 = `swap_sell_exclusion_reason` 首段 `if name in ctx.membership: return 'buy_membership'`（cw_deploy_logic.py:960-963），**先于**一切资格/让位分支；`membership` = `locked_buy_membership`（:1506-1512）本体 = `_line_hoard`（cw_intention.py:1295-1319）= core∪shared∪替班∪终局键集标签成员；容量截断序 core∪shared 恒保首级（cw_intention.py:1715-1716）⇒ **名单成员从不被截出义务集** ⇒ 现行锁定帧名单成员 victim 一律 `buy_membership` 拒。设计句「通道 3 名单成员让位**本不经义务集（现行语义照旧）**」与代码体相反（现行语义里它恰恰经义务集且被拒；未锁帧 membership 空集才放行，而转型域 = 锁定帧）。

### F2【阻断】fenced 关门分支「谓词原样保留、零迁移」与「pair 帧开门照旧」两指令不能同时成立（三处文本互斥）

- 位置：design.md:74（§2.3.1 两处：**「谓词原样保留、零迁移」**与申报④引述）、design.md:121（申报④「pair 帧新判别子 False → 不关门 → 落资格族照旧」）、landing.md:25（3.1 范围同段并置两指令）、landing.md:36（「pair 帧 fenced off-target 路径保持现行（申报④，fenced 关门分支判定迁移到转型域判别子）」）。
- 代码体实况（cw_deploy_logic.py:1023-1032 直调）：关门分支路由键 = `_trans` = 旧混轨域谓词（ENABLED ∧ locked**含 pair** ∧ fp<1.00 ∧ 板满）。pair 板满 pre-form 帧因混轨真**不直达关门分支、落资格族**（现行开）；未锁帧/锁定∧成型帧/锁定∧板不满帧经 :1027-:1031 关门（现行关）。**开门集 = locked ∧ fp<1.00 ∧ 板满（混轨）**——依赖旧谓词的混轨 locked 腿。
- 两读推演：按「迁移到转型域判别子」实现（_trans = 新判别子，排 pair）→ pair 板满 pre-form 帧 :1027 假、:1029 假 → :1031 `fenced_arm_closed` = **关门**，违反申报④与 §2.3.1「pair 双轨帧与转型域帧同此形态」；按「原样保留、零迁移」实现 → 分支继续消费退役符号（违 §2.9 退役义务），或将路由键简化为 `locked` → 锁定∧成型帧由关变开（双轨域行为差未申报）。**不存在能同时保住两个现行行为的单一新路由键而文本又宣称零迁移**。
- 修正方向：§2.3.1 改写为逐帧真值表（转型域帧 / pair 板满 pre-form 帧 / 锁定成型帧 / 未锁帧 × fenced_on 维），每行给唯一实现指令——核心 = 关门分支域腿钉死为**混轨谓词（locked ∧ fp<1.00 ∧ 板满，无 ENABLED 腿、不排 pair）**；删除「零迁移」「迁移到转型域判别子」两处冲突措辞；申报④与 landing 判据行逐字对齐。

### F3【阻断】组构造遍历的**组生长语义**未定稿——多对组如何形成、失败前缀是否保留、守恒判定点三问无答

- 位置：design.md:91（§2.7 组算法段）。
- 现文本已答（复核确认）：门 1 失败先换 victim（内层）→ 再换 up（外层）；「首个可行组」= 换入主序 × victim 辅序字典序第一个可行组。
- 未答三问（实现者必须自行设计，违 iteration-design §5-2）：
  1. **组是否继续生长**：单对判门 1 失败后，是否尝试追加对形成 2 对组？门 1④ 成型腿存在「多对合取才 ✗→✓」形态（如能量 5 硬档需两件同入）——只试单对则该形态结构性不可达，与枚举表 C（整组换放行）矛盾；若生长，失败前缀（已入组的对）保留还是回退？
  2. **内层耗尽外层推进时前缀对的 victim 取值**：u1 配对 victim 耗尽后推进 u2，u1 保留哪个 victim（字典序定义在组维未封闭）。
  3. **守恒面（终局档位非降，§2.3）判定点**：逐次扩组步判定还是仅终组判定（中途掉档、终组回补的组是否合法）未钉。
- 修正方向：以伪代码钉死组空间与枚举序（组 = 变长对序列；生长条件；失败回退规则；守恒判定点），或显式声明组上限/单轮多对触发条件。
