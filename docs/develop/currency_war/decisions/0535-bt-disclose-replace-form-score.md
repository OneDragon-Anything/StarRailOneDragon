# ADR-0535: B_t 替代 form_score 披露口径——form_score 决策关键帧零预测力定谳与观测面换锚

## 背景(病灶)

form_score = `min(2, engines + 0.3×frac)/2` 作为「阵容成型度」遥测观测量,
在决策关键帧上恒为常数:判定批(2026-09-06,sim61/62/63 三批全量样本
n=90 局 / 981 决策帧 / 108 场 boss 战,非抽样)实测——

- boss 前帧 form_score = **108/108 = 1.0**、终局 = 90/90 = 1.0(k=1,零方差);
- 零方差 ⇒ Pearson 相关分母为 0,相关性**不可计算**(nan),与任何
  结局量(boss delta / depth / 终局 hp)的信息量恒为 0——比「相关性为零」
  更强:它是常数函数,不是弱相关。

结论:**现口径预测力为零,定谳成立**。接线批判读门(「boss delta 与
form_score/depth 相关性为零」前置门)通过;该死仪表被 fd3fa99f 落地退役
(写者切 B_t、遥测键切 b_t、form_score 只读历史保留)。

## 决策

**披露口径以 B_t(板面目标线承重计数)替代 form_score**,定位保持
**纯遥测观测面,不进任何判据**(flow.py 观测注记);落地面:

1. **计算单一源**:B_t 复算收 `kernel/cw_deploy_logic.py`
   `board_target_line_weight`(注册表直调:deployed 中羁绊 ∩ 四体系
   线内阵营集,TRANSITION_TRAITS 三羁绊 ∪ 量子同频/贝洛伯格/希儿本人),
   写者与判读同吃,禁第二实现;
2. **纯遥测定位**:消费面 = 写者 + 遥测读写 + 判读显示,决策面零消费;
   B_t 对 boss delta 仅弱正(r=0.174),不构成判据资格;
3. **断链收口**:判读脚本双键回退(b_t 优先 / 旧 form_score 键历史
   回退),form_score 残留消费全部历史只读;
4. **升格闸门**:若未来要把 B_t 拔高进判据(预测 boss delta),当前
   证据不足(r=0.403 显著性仅对 depth),**须过 ADR-0482 两层权威序
   全门**(证明/实证先行,禁口述拔高)——本条为该升格的显式闸门。

判定依据(全量样本,sim61/62/63,批指纹 d643023c/999fb98f/f26e00f8):
B_t 是唯一 p<0.001 显著代理——B_t(boss 前帧)→ boss 轮 depth 的
Pearson r=0.403,t≈4.58,p<0.001(n=108);正式化命题见 math_proofs
P62(饱和零信息)/ P63(B_t 预测力下界)。

## Considered Options

- **方案①(去封顶连续量)**:否决。去封顶 x = engines+0.3×frac 在
  boss 前帧 ≡ 2.30(std=0.0000)——饱和不在封顶口径层,而在「两引擎
  达成 + 配方满档」在 boss 前已结构性全达;任何 g(engines, frac) 族
  指标在该样本上都是常数函数,换公式无效。
- **方案②(披露 engines 原值 + 2★ 数)**:否决。engines 原值 boss 前
  帧恒 2(k=1,零区分度);2★ 数对三个结局量 r ∈ [−0.127, +0.046],
  无一致方向、无显著信号——披露它是噪声不是信息。
- **方案③(B_t 替代)**:选定。B_t 全样本有方差(终帧 [8,9]、boss 前
  帧跨 [3,9])且唯一显著;与 engines_count 同源同辖域,零新增识别面。
- **边界(显式声明)**:B_t 对 boss delta 弱(r=0.174)、对终局 hp 弱
  (r=0.112),显著性集中于 depth——它区分的是「中盘承重积累速度」,
  不是终局胜负;sim63 终帧已趋饱和(恒 9)。故**纯遥测不进判据**;
  弱对照:三批池指纹互异且批间有在飞改动,结论限本三批样本,换池
  复测候回归对账。

## 后果

- 正面:决策关键帧观测面从零信息死仪表换为唯一有方差且显著的代理;
  计算单一源收 kernel;断链窗口由双键回退封闭;form_score 退役显式
  (历史只读)。
- 代价/边界:B_t 不是终局胜负预测子,判读时禁拔高用途(预测力集中
  于 boss 战存活深度);跨批池漂移混杂未除(弱对照);升格判据须过
  ADR-0482 闸门。
