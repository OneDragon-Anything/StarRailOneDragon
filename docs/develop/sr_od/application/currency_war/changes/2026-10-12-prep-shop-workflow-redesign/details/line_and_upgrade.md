# 统一选线函数与升级判据（详设）

## 问题与约束

- 边界：本篇定义三件事——统一选线函数（方向状态唯一来源）、升级判据（概率主轴）、方向签名前置段。备战/商店两域对它们的调用时机见各自详设。

## 方案

### 1. 统一选线函数

用户裁定 2026-10-12：应有一个统一的函数计算应选哪个最终阵容，计算出新的（更好的）就更换目标；贯穿件是强信号之一（非一票定音）。

**1.1 函数形态**

```
f(局面状态) → 「未定型」 | 「目标线 X」
```

**1.2 每条候选线的评分（四维加权求和；权重形态见关键取舍）**

| 维度 | 内容 | 量化地基 |
|---|---|---|
| 完成度 | 该线下一成型档所需成员的持有比例（上阵+备战，按星级折算） | 阵容注册表分档表（`COMP_LIBRARY.form_tiers`，出处 = strategy-docs/10 §5）；完成目标态按下一成型档算（user_playstyle [37]） |
| 获取前景 | 缺的成员按当前等级刷新概率算补齐期望代价，缺得越便宜分越高；缺件此刻在商店牌面上可见 = 加分 | 期望刷新次数模型（`cw_shop_odds.expected_refreshes`，P40 数学件）；概率表 `REFRESH_PROB` |
| 专属资产 | 该线贯穿件在手上（强信号，大权重；user_playstyle [23] 与用户裁定 2026-10-12「强信号之一」）；该线关键装备已持有数 | 装备注册表 `key_equips` |
| 环境 | 投资策略/环境对该线的机制增益；boss 词缀克制 | 投资注册表（`cw_invest_data`）、词缀注册表；环境分化用机制知识不用热度数据（user_playstyle [38]） |

- **缺件集构造**：各线缺件集 = 该线下一成型档成员 − 已持有（每成员按完成档张数口径，k∈{3,9}）；获取前景的期望代价对该集**逐成员求和**。**与现行实现的偏差申报**：现行升级②臂消费单核代表（单目标核心降级申报在案），本设计改为候选集逐成员求和——聚合口径对升级是**放大受益方向**（多缺件同受升级受益帧更易过阈，相对现行更易触发升级，非保守向），标定批对照单核/求和两口径的触发率分布复核该选择（【拟】owner = 编排者，期限 = 一个对局周期）。
- **贯穿件名单的注册表锚**：现行注册表无独立「贯穿件」字段（SIGNAL_REGISTRY 属 10 §5 新建挂账项）——本设计挂账新建 `COMP_LIBRARY` 每线 `key_items` 字段（贯穿件名单单一源），**建表任务归属 = 知识批（owner = 编排者，期限 = 本迭代落地 3.7 前；数据来源 = `final_comps/` 各线贯穿件登记）**；建表前该维取值 None = 未定型 fail 方向（不产生分数）。贯穿件只计持有与否（1★ 即信号），不做星级折算。
- **选线评分函数立项申报**：四维加权评分 = 新判据件（无既有命题覆盖其期望保证）——登记为待证命题（fail 方向 = 缺省恒未定型不消费评分数值，已在 §1.3 声明）；**P76 证据门已落地标定资产处置**：Δ/ε₂ 二阶带/provisional 槽位随证据门退役一并迁移至新函数标定项（provisional 槽位改挂本函数定型门/滞后余量/权重）——**跨语义复用错配申报**：Δ/ε₂ 原语义 = 证据门阈值（证据分带），新消费 = 定型门/滞后余量（评分比较），**数值不可直接复用**，迁移 = 仅槽位结构复用，数值全部重标定。
- **未定型期的升级概率账缺件集** = 未定型买牌策略（search 态候选集）当前想找的缺件——含过渡体系缺件与终局候选线的缺件（用户裁定 2026-10-12 纠正：未定型期不只按过渡体系买，囤终局件是锁线准备的一部分，search 态候选集定义 = shop_session §2.2 序 1）；此时无单一目标线，概率账服务「候选集的补齐期望」。

**1.3 输出裁决**

- 全部线分数低于定型门 → 「未定型」：两域按统一买牌策略的 search 态行动（商店域序 1 = 现行 search 态候选集判据，shop_session §2.2 与 §5 P86 收编行；备战域资格面无线内项）。
- 最高分线 ≥ 定型门 → 目标线 = 最高分线。
- **换目标判据（防摇摆核心）**：当前已有目标线 T，候选线 N ≠ T 更替的条件：
  ```
  score(N) > score(T) + 切换成本(T→N) + 滞后余量
  - 切换成本 = T 线专属持有资产的变现损失（2★/3★ 手续费、囤件再遇期权损失，
    折算式 = §4 统一口径）
              + N 线缺件补齐的期望花费
  - 滞后余量 = 常量（防微弱优势触发换线；「四线摇摆全输」教训的制度化，
    出处 = user_playstyle [36] 注）
  ```
  **挂起槽生命周期（完备定义）**：比较账通过 → 写挂起槽（挂起 ≠ 生效才有意义）；比较账不通过 → **不写挂起槽**（保留原值——无候选换向即无挂起）；挂起 ≡ 生效 → 不登记（无换向发生，不触发清标记空转重开）。提升条件 = 挂起非空 ∧ 挂起 ≠ 生效。
- **换目标的两槽语义（中间态定义）**：方向状态分**生效目标**与**挂起目标**两槽。签名重算只更新评分快照与挂起目标；`line_members_view()` 恒返回**生效目标**的名单——会话内/备战帧内的买牌、置换账、卖出资格全部消费生效目标，无中间态抖动。挂起目标在**下一备战期入口**提升为生效目标（理由 = 备战期边界是买入名单与卖出资格集的一致性断点；与现行 12 号篇滞回/驻留组件无承继关系，见 §1.5），同时清挂起槽。
- 换目标登记时旧线专属件进卖出候选池（按价值让位语义自然排出，无紧急清场动作——塌缩卖出通道退役）。
- 评估时机 = 方向签名变化（§3）；评估本身纯函数（读容器状态算分），无副作用。
- **标定前缺省（fail 方向声明）**：定型门取最高、滞后余量取无穷 → 恒未定型 → 两域全程 search 态件级评估。search 态本身含终局件囤货（shop_session §2.2 序 1：全部候选线含终局库，[21]/[22] 照买照囤）——缺省丢掉的只是「锁定单一终局名单后的 focus 态专注 buying」，囤终局件为后续锁线准备的行为**保留**（用户裁定 2026-10-12）。相对现行的行为差 = 锁定态（focus 态名单）整体延后到标定后打开——「未验证权重不锁线」的 fail 方向选择，如实申报。

**1.4 首次定型**

- 未定型 → 首次某线过定型门：直接锁定（无切换成本、无滞后余量——首次没有旧线资产）。此后适用 §1.3 换目标判据。

### 2. 升级判据

用户裁定 2026-10-12：主轴 = 核心的刷新概率；一次性买齐，不只买一半。

**2.1 触发（两类并列）**

- **概率账（主判据）**：目标缺件集（定型后 = 目标线缺件集；未定型期 = §1.2 未定型缺件集）在当前等级 L 与 L+1 的补齐期望比较：升一级后「找到缺件的期望刷次下降量」折算的金价值（折算式 = 期望刷次下降量 × 单次刷价 c_eff，c_eff 画面实读）> 升级整级成本 + 期间息损 → 该升。期间息损 = P47 双轨迹递推 L 项（输入面 = 金/收入日程/剩余视界，与刷新账同源）；量化地基 = `expected_refreshes`（P40，data/cw_shop_odds.py）+ 概率表 + 升级门槛表（`XP_TO_NEXT_LEVEL`）+ 买经验单价（画面实读）。**双触发合并语义**：概率账与人口位同帧满足 → 单次授权并集发射（一次预授权，不重复）。**触发源并集**：arm0（need > level 升级不足，20 号稿 §3.5 在产臂）∨ 概率账 ∨ 人口位 ∨ 必花域-L3 触发源（20 号稿三源 ∨ 语义完整承继，含 arm0——域内 P21 让位与档位照 20 号稿）。**奖励帧抑制照旧**：reward_node_suppressed 闸照旧消费（抑制帧升级触发不发射，P80 候裁维持挂账申报）。
- **人口位（并列）**：板上位置坐满 ∧ 有能进当前阵容羁绊体系的单位在备战席等待上场 ∧ 该单位边际贡献 > 0（三元谓词完整保留，第三谓词出处 = strategy-docs/02 §3 M3 行与 P39 臂一——羁绊档已满的零贡献单位不触发）→ 升（战力当轮兑现；判定域 = 阵营相关单位不限星级，user_playstyle [33] 与其 2026-09-01 精确化）。人口位不受攒息约束（[12] 的明文例外）。

**2.2 支出形态：一次买齐**

- 满足触发且**攒批资金到位** → **整级预授权，一次买齐**到下一级的全部经验（批大小 = 门槛表差值折击数，现行 P48 整买引理形态保留；实付上界 = 授权批成本——执行形态见下行发射序列）。
- **攒批资金口径 = 裸金 + 非线内 1★ 活期卡退金**（备战席 1★ 全额退且非线内件按退金价计入——与升级变现场景资格面同源：常规面排除线内，卖自己人凑升级金不在语义内；user_playstyle [41]「把超 50 的钱换成压库卡……用时按卖回量最小化变现」的资产形态口径，与现行 P48 资产形态修正注同款）。
- **升级前变现步（跨帧两阶段，单动作契约逐动作发射）**：
  - **授权帧**：升级判据通过 → 置升级预授权键（含授权批成本/授权血成本上界）→ 发卖出动作（评估器升级变现场景，卖到差额闭合即止）；
  - **执行帧**：下一轮升级检查检测预授权键 → 发购买经验整批（实付上界 = 授权值，**执行帧不再重闸**——防「买一半」复发的机制正是预授权跨帧携带）→ 清键。
  - **相邻性语义分域**：会话内（商店循环）严格相邻（卖 → 买，无穿插面）；备战域允许全扫回跳穿插**零金动作**（第 0-2/5/6 步均不花费，不影响预授权资金判断——穿插的买入动作在备战域不存在），预授权键保证穿插期间资金不被花掉。预授权键是唯一的跨帧授权状态（第 3 步「判据不过 = 零动作」指无预授权帧的常规评估；授权帧后由键驱动执行帧，血本位授权的实付上界同键承载）。**失效与异常分支**：① 变现不足（卖出候选穷尽后裸金仍不足整级差额）→ 键保留、执行帧不发射——此后每帧幂等重评（判据过 → 键在；变现无候选 → 零动作），稳态无害；下节点收入使金足后执行帧自然发射（键仍有效，符合整买意图；无抑制键——纯由判据与候选面决定，与「无试错计数」原则一致）；② 变现候选被同 visit 排除/资格面排除尽 → 同①；③ 节点边界重置清键（prep_pipeline §3 清单——节点切换资金面全变，旧授权作废）。
- 攒批资金（含活期口径）不足整级 → 一击不买（攒钱模式，等节点收入；压库买入受整买预留约束不会吃掉攒批资金，shop_session §2.2 序 4）。
- **血本位突变下的支付检查**（user_playstyle [40]②）：血余额 ≥ 下一级血成本才发整级授权，否则零购买。**现状缺陷修正申报**：现行部分购买的真实机理 = 逐帧单击发射形态 × 静态全量阈值逐帧重闸（血支付中血量跌回阈值之下即停止发射，留下部分级；`blood_xp_gate` 本体为全量击数口径，非截断源）——修法 = 整级预授权 + 实付上界（授权血成本），发射粒度整批化后闸本体语义不变（landing §3.4 同步消歧 as-built 表述）。
- 升级执行位置两处：备战工序第 3 步（每轮全扫评估）；商店会话内（购买经验按钮能力面在役，实机帧确认；前置 = 执行链接线批）——会话内评估时机 = 每轮买入评估前（§2.2 前置升级检查，shop_session）。

### 4. 价值评估函数（契约 D 统一口径）

所有卖出场景的「手上牌价值」与本函数一致（单一口径，禁各场景自算）。**量纲统一为金当量**（经济期望是统一标尺，user_playstyle [22]④），可直接参与置换账比较：

```
value(牌) = 变现价 + 再遇期权 + 合成进度   （金当量项）
           ⊕ 羁绊贡献                      （排序规则项，不折金）
- 变现价   = sell_refund(牌)（注册表现读；1★ 全额退、2★×3、3★×9，cost≥2 减 1）
- 再遇期权 = 再遇窗口折算金当量：reencounter_window_frames(等级, 费用档, 已持有数)——候选的费用档 = 注册表 cost 现读、已持有数 = 同名同星持有计数现读
             （参数序照代码；查表单一源 = data/cw_shop_odds.py 的 reencounter_window_frames，
             11 §6.7 P77 行）× 每轮息损上限（= 1 金/轮，息档粒度）
- 合成进度 = 已有同名同星 2 张（差一张合成）→ 按该成员完成档的再遇期权 ×2 计
             （差一张 = 两张的再遇期权沉淀；×2 为结构近似系数【拟】，挂标定对照）；
             零散单张 = 自身再遇期权。
             未定型期「完成档」缺省 = 该成员自身下一星档（2★ 目标 k=3），
             无目标线依赖
- 羁绊贡献 = 排序规则项（非金当量）：卖后当前板面羁绊掉档的牌在让位序中排
   在全部不掉档牌之后（上阵位才有此代价，备战席位天然不掉档）。

```

## 关键取舍

- **加权求和 vs 逐级字典序**：选加权求和。用户裁定贯穿件是「强信号之一」非一票定音，字典序把贯穿件钉死为最高优先级，与裁定冲突；加权求和下贯穿件是大权重项而非绝对项。代价 = 权重与定型门/滞后余量需要标定——按零调参宪法的显式模型路径处理：结构与量纲来自注册表查表（§4 各式，无自由拟合），标定批补置信区间。**四维量纲合成式（归一化与加权合成式）= 标定批交付物**（缺省恒未定型下不消费评分数值，无行为影响）。**标定完成前缺省 = 定型门取最高 + 滞后余量取无穷（恒未定型）**，定型门与滞后余量的产生方式同本条【拟】登记。
- **【拟】三要素登记**：定型门、滞后余量、四维权重——owner = 编排者，期限 = 一个对局周期（超期未决回炉，01 §6 章程）；登记处 = `strategies/impl/mandate_v1/audit/provisional.py`（现行 provisional 注册表，fail-closed 槽位 None 形态沿用）。
- **换目标下一备战期生效 vs 即时生效**：选下一备战期。即时生效会让同帧内买牌判据与卖出资格集抖动；备战期边界是天然的决策一致性断点。
- **濒死破例升级不保留**：见 §2.3 血线地板解锁行；血本位支付检查保留（账户余额检查非质量信号，[40]②）。
