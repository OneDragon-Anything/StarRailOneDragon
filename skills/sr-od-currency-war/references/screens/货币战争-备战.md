# 货币战争-备战（核心画面，每节点停留）

**识别**：`is_precise` 命中 `货币战争-备战`；extras 全量：gold/hp/level/deploy_count+deploy_cap/xp_progress/front_line+back_line（SIFT 在场真值）/bench/armory_boxes/owned_equips/reward_ores。board = 羁绊面板可见行（仅快照）。
**目标**：花金币强化阵容 → 出战。
**能做的事**：
1. 拾晶矿：`CwCollectRewardOres {"max_clicks":6}`（reward_ores 非空时；商店开着会被守卫拒绝）。
2. 开商店：`CwToggleShopPanel {"screen_name":"货币战争-备战"}`（静默失败重跑）→ 买东西见「备战-开商店」卡。
3. 部署：`DragCwChar {"from_row":"bench","from_idx":N,"to_row":"front|back","to_idx":M}`——from_idx 必须来自**刚读过**的 extras.bench（晶矿开箱掉落物会插到非首空位，旧读数缺新单位；槽号 = 物理槽位，空槽以 empty 保留）。
4. 卖角色腾位：`CwSellBenchBySlot {"bench_idx":N}`。
5. 开武装箱：点 extras.armory_boxes 元素的 cx/cy（开启后装备入库，腾出备战席）。
6. 看角色详情：点场上角色卡（属性/技能/装备栏面板，右上 × 关闭）。
7. 出战：`CwStartBattleByClick {}`（自动收店+微距拖拽+未达上限弹窗确认）。
**坑**：开商店态 front_line/deploy_count 为 null（完整读数先收店）；出战 4/5 部署会弹「未达上限」（op 自动确认）；战斗约 60~90 秒后再截图。
