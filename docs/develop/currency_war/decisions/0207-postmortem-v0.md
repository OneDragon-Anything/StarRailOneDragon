# ADR-0207: 反事实复盘层 v0(14 号处置:决策点筛选 + ex-ante 悔恨框架)

## Status

Accepted(2026-08-17;v0 框架,rollout/CRN/前缀保真挂 v1)

## Context

实机局信息萃取率最低却是唯一 ground truth;「次优」(无 bug 无误执行,就是打得差)
只有两条发现路:再打几局(单局方差>>改进量)或人看日志(人工小时计)。轨迹五路
telemetry 落盘但无「回到那一步重问一次」的消费方式。

## Decision Drivers

- 悔恨归因必须防事后偏差(ex-ante 信念条件是 14 号灵魂)
- 「不可归因」须是一等输出(防下游拿噪声当证据)
- 感知毒化下的错动作是状态错不是策略错(路由分离)

## Considered Options

1. **v0 框架层(选)**:筛选器(不可逆/分接近/高杠杆,预算 15/局)+ ex-ante
   判决框架 + 噪声地板判;消费 telemetry 落盘数据,纯函数离线;
2. 直接做全量 rollout:需 02 outcome model 作战斗黑盒(未落地),前缀保真
   校验也未建——一步到位风险高;
3. 不做:复盘继续靠人肉。

## Decision

选 1(分层落地):cw_postmortem.py。rollout/CRN 对齐/前缀保真挂 v1
(数据基础本轮已全绿)。三路回流(→11 知识草稿/→12 复盘问询/→参数修复)挂消费批。

## Consequences

- 败局复盘从「人看日志」升级为「机器筛 top 悔恨点」的第一块;
- 14 号提案删档(INDEX 行已记);与 22 号 playbook 表-实对照天然互补
  (表 = 现成对照组,14 号 §2.3 目标级分支直接可用)。
