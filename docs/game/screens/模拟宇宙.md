# 模拟宇宙(sim_uni)

常驻 Roguelike 玩法。选命途 → 位面探索(蜂巢格子)→ 战斗 / 事件 / 交易 / 休整地块 → 击败首领通关。祝福 + 奇物 + 随机事件强化队伍。**多子态共用本 screen**,`pc_alt=true`(3D 探索锁光标,探索态点击需 `pc_alt=True`;入口/UI 子态 `pc_alt=false`)。玩法机制见 [gameplay/sim_uni](../gameplay/sim_uni.md)。

## 何时出现 + 状态流转

**入口**:黑塔办公室模拟宇宙装置前 `interact F` / 星际和平指南·旷宇纷争·差分宇宙·「前往模拟宇宙」传送 → 选世界主界面。

**子态流转**(2026-08-01 实拍一圈验证):

| 子态 | 入口(从哪来) | 出口(动作→下一态) |
|---|---|---|
| ①入口-选世界主界面 | F 交互 / 传送落地 / 结算后返回 | `CURRENT_BTN`(1276,567) → 选世界详情 |
| ②选世界详情/难度 | ①点选择当前宇宙 | 「下载初始角色」→ 启动信息 |
| ③下载初始角色/启动信息 | ②点下载初始角色 | 「启动「模拟宇宙」」→ 命途选择 |
| ④命途选择 | ③点启动(首次) | 选命途 → 命途详情 |
| ⑤命途详情/确认 | ④选命途 | 「确认命途」→ 起始奖励 |
| ⑥起始奖励选择 | ⑤确认命途 | 选(祝福/破碎/神奇宇宙)+「确认」→ 祝福选择 |
| ⑦祝福选择 | ⑥ / 战斗胜 / 事件 | 选祝福 +「确认」→ 蜂巢探索 |
| ⑧蜂巢探索(楼层类型) | ⑦ / 地块结算后 | `esc` → 退出菜单;移动→地块 |
| ⑨esc 菜单/退出确认 | ⑧按 esc | 「暂离」/「结束并结算」→ 退出对话框 |
| ⑩退出确认对话框 | ⑨点结束并结算 | 「确认」→ 结算报告 |
| ⑪结算/分析报告 | ⑩确认 / 通关 | 「点击空白处继续」→ 回①入口 |

> 通关结算是「探索完成」(有奖励),主动结束是「探索中断」(奖励 0)。⑧蜂巢里战斗胜利→祝福选择、事件地块→事件画面、商店→交易画面(⑲实拍)。

## 识别特征(稳定锚点,screen_info 30 area)

子态判定核心靠 `get_sim_uni_screen_state`:OCR「左上角标题」做 LCS 匹配子态名 + 各专项 area 兜底。

- **左上角标题**(text `''`,100,15-350,100):LCS 匹配子态名(`模拟宇宙`/`选择祝福`/`选择奇物`/`事件`/…)。
- **楼层类型**(text `''`,50,0-330,60):OCR 楼层类型(`区域-战斗`/`区域-事件`/`区域-精英`/…)→ `get_level_type`。
- **大世界返回按钮**(template `normal_world/ui_icon_10`,0,0-115,115):探索态左上退出按钮。
- **入口态**:`宇宙入口-进行中-1/2`、`当前宇宙名称-1/2`、`入口-启动模拟宇宙` / `入口-继续` / `入口-下载初始角色` / `入口-低等级确认` / `入口-命途区域`(134,665-1788,708)/ `入口-确认命途`(1529,957-1869,1006)。
- **结算/退出**:`菜单-结束并结算`、`菜单-暂离`、`终止战斗并结算`、`退出对话框-确认`、`沉浸奖励`、`前往下层-确认`。
- **每周奖励**:`每周奖励红点`(template `phone_menu/ui_alert`)、`每周奖励-一键领取`。
- **战斗失败**:`战斗失败`、`战斗失败-终止战斗并结算` / `战斗失败-确认`、`点击空白处关闭` / `点击空白处关闭2`。
- **事件/结算兜底**:`事件标题`、`点击空白处继续`、`怪物上方等级`。
- **差分宇宙**:`差分宇宙-暂离`、`菜单-暂离`。

### 19. 交易地块(TRANSACTION;2026-08-01 实拍,transaction 优先级跑层触发)
- **探索态**:楼层类型「区域-交易」(`SimUniLevelTypeEnum.TRANSACTION`,模板 `level_type_transaction`,`route_id='event'`),画面同⑧蜂巢探索;bot 用 `SimUniRunEventRouteV2`(与事件/遭遇共用,识别小地图事件图标模板 `mm_sp_event`)。
- **交互后 = 黑塔商店事件**(SIM_EVENT),两子态:
  - **商店对话**(`screens/模拟宇宙/交易-商店对话.webp`):黑塔人偶剧情「你可以拿你的宇宙碎片，跟我换点东西。」+「选择」→ 进商店。
  - **商店选项**(`screens/模拟宇宙/交易-商店选项.webp`):标题「事件」+ 宇宙碎片余额(如 `144`)+「查看已有祝福」+ `OPT_RECT(1335,204,1826,886)` 内 4 选项(`❇` = `event_option_icon`):**购买1个1星祝福(80碎片)/ 购买1个奇物(120碎片)/ 强化2个随机祝福(180碎片)/ 离开**。
- **bot 流程**(`SimUniEvent`):交易 = 商店事件,与纯剧情事件共用 SIM_EVENT 画面 + `OPT_RECT` 选项 UI,仅选项内容不同(商店 = 购买/离开);`_choose_opt_by_priority` 固定选第一个。
- **⚠️ 识别隐患**:商店「离开这里。」选项误命中「菜单-暂离」area(conf 0.9997)——「菜单-暂离」text 区与商店离开选项位置/文字接近,串味;判态勿单凭「菜单-暂离」。
- **触发方式**:默认 `level_type_priority` combat 第一 → v2 算法路线总找战斗、绕开交易;临时改 transaction/event 优先(`config/sim_uni/challenge_config/08.yml`)+ v2 才主动找交易地块(**临时改动,事后回滚**)。

## bot 流程(`application/sim_universe/`,重 app 多 op 编排)

`SimUniApp`:检查运行次数 → 识别初始画面 → 传送(指南·旷宇纷争·差分宇宙·前往模拟宇宙)→ 选择宇宙(`ChooseSimUniNum`)→ 选择难度(`ChooseSimUniDiff`)→ 开始挑战(`SimUniStart`)→ 选择命途(`SimUniChoosePath`)→ 自动宇宙(`SimUniRunWorld`:跑层 `move_v1/v2` + 战斗 + 祝福/奇物/事件)→ [异常 → `SimUniExit`] → 领取每周奖励(`SimUniClaimWeeklyReward`)→ `BackToNormalWorldPlus`。

子 op 分类:`entry`(choose_num/diff/start/claim_weekly)、`bless`(choose/drop/upgrade/path)、`curio`(choose/drop)、`event`、`battle`(enter_fight/fight_elite)、`move_v1`/`move_v2`(跑层路线两套算法)、`auto_run`(run_level/run_world/reset/wait_level_start)、`sim_uni_exit`。

> 详细 `@operation_node` 节点链 + move v1/v2 路线算法见 develop doc([sim_universe.md](../../develop/sr_od/application/sim_universe.md))。
