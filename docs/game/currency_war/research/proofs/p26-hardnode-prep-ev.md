# P26 · P1 硬节点备战支出的 EV 门

状态:**待证明(参数化)**。骨架用已证命题,卡点=Δp_prep 未标定(采集挂账可离线补)。

## 命题

P1 硬节点(遭遇/boss,`_hard_node` 口径)备战帧,一笔备战支出 C(围栏内体系件买/carry 装备/弃息 D)的期望净值:

```
EV(C) = Δp_prep · L_node + Δstreak·S_streak − C − I(息损)
```

触发判据形式:EV(C)>0 ⇔ Δp_prep > (C+I−Δstreak·S_streak)/L_node,与 P23 停手窗门式同构(P23.1)。其中 L_node = 该节点条件败面伤害(已标定单一源 `registry.streak_floor_loss_damage`,带:遭遇 42/boss 39 分位口径;战斗 11.32−0.37·rung,P15)。

- P15:P1 收益侧 L 的条件口径已标定(禁无条件均值双计的教训直接沿用)。

## 卡点与采集挂账

**Δp_prep(备战支出→硬节点胜率)未标定**——P20 给的是「激活 vs 散件升星」的相对边际,不是「该帧花 C 金 vs 不花」的绝对条件胜率差。

采集挂账(可离线补,不需新实机):现 replay 语料(decisions.jsonl+outcomes.jsonl)按备战帧(围栏内支出额,carry 装备数,engines_formed rung)分桶 × 硬节点败率出条件表;样本量足格(≥10/桶)后回填本命题数字表。标定完成前,设计判据(p1_iface_hardnode_prep 的水位比较 hp−L_node<emergency_hp)只作触发面使用,金额侧交既有息账门——**触发不等于数值授权**,零魔数。
