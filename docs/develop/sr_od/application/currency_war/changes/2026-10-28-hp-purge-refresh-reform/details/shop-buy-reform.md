# 买面席位与追星改革（详设）

## 问题与约束

- 边界：本篇管 `shop.py` 合成腿谓词段（:234-266）与买面段（六序/M6:1543-1616/垫件/序 5/序 6/C1，:316-1961）+ `mandate.py::fuel_sell_candidates` 本体（:392，W4 如需调整其行为）+ 会话记忆标记字段（载体 = StrategyState，mandate_state.py 新增字段行）。刷新发射段归 refresh-chain 详设（总纲 §2.1 契约）。
- 接口契约：`fuel_sell_candidates` 资格面为「席可腾」唯一真值源，本篇只消费（W4 若需调整其行为，改动落本篇文件面并锁双消费位等值）；停留目标单一源 = `stay_target_of`。
- 现状锚：本局实证 bench 9/9 反锁刷新（`m6_bench_full=8`）、全场唯一线内件三月七 1★ 四买臂全够不着（追查件 §1.2 r2 帧）、免费刷无界循环形态（`shop.py:1963-1971` + `cw_investments.py:473` 高效决策 9999 次）。

## 方案

### 1. 买臂星级语义统一为 need_star 口径（W5）

- **口径**：成员追星状态唯一口径 = `unfinished_star_targets`（`criteria/levelup.py:174`，need_star 驱动）；缺口计量统一单位 = **1★ 等价张数**（need_star 折算张数 − 已持折算：2★ = 3 张、3★ = 9 张，3 合 1）。
  - 缺口 > 0（未完成）：其商店任意星级副本**照买推进**——买 1★ 副本累积，每满 3 张自动合成晋级（已持 2★ 追 3★ 成员的 1★ 副本同样照买：累积副本经合成链兑现为星级推进，非让渡死库存——目标件的合成链消费义务由 merge_mechanics.md §2「同名 1★ 凑满 3 即合成」机制保证）；
  - 缺口 = 0（已达标）：**显式停买**（拒因 = `star_goal_met`，新键可观测；同名 1★ 副本对达标成员零推进）。
- **买臂可达性矩阵（实现批强制交付物）**：成员状态（未持 / 持 1★ / 持 2★ ∧ 追 3★）× 需求 → 触发买臂逐一枚举成矩阵，作为单帧测试必测行。已知死格风险（直调核验）：M2b 要求「恰 2 张全 1★」、囤货臂门 `_cnt(2★) != 0` 关闭、M6 排除线内——**若某配置（如持 2★ ∧ 0-1 张散 1★）在现行臂集合下无可达臂，扩臂实现以矩阵为准，不以现行臂集合为边界**；序 1 缺件买臂按缺口口径放行任意星级副本（义务面照买照囤语义，`11_shop_decisions.md` §1），M2b 保留为即时合成快路径。
- 实现落点：**缺件集口径分域**——锁定后 = 消费 `unfinished_star_targets`（修 `shop.py:930` 名集星级盲）；**未锁定窗口 = 维持现行候选缺件口径不变**（`unfinished_star_targets` 未锁期恒空集，`levelup.py:193-194`——字面替换会清空未锁窗口 M2，故分域钉死）。行为变化申报仅限锁定后。`_dg_gap`/`missing` 推导域同步换口径。
- 行为变化申报：达标成员（如三月七 2★ 达标）的 1★ 副本从「四臂够不着（拒因混杂）」变为「显式停买（`star_goal_met`）」；未完成成员（如姬子·启行 2★ 追 3★）的 1★ 副本从「部分配置不可达」变为「全配置可达（矩阵锁定）」。

### 2. 停留刷窗口压牌库让位（W4）

- **规则**：停留刷窗口内，M6 压牌库囤货臂停用——窗口内金用途优先级 = 刷新 + 目标卡钱（金线闸 ρ 已预留），富余金留在线上吃息。
- 实现：M6 触发谓词追加窗口否决项（**求值时点 = 每帧决策点即时求值 `refresh_warranted`**，与刷新判定同帧同参——总纲接口契约的判定轴复用，禁第二推导；非帧首快照，防跨帧漂移）。
- 行为变化申报：追星窗口内不再出现非线内囤货买入（本局 P2 段 12 笔 24 金形态消失）；非窗口（无星级目标/未锁定富余段）M6 照常。
- 与免费分支的关系：免费刷不消耗金，窗口内免费刷仍可用（目标可买条件下）——M6 让位不剥夺免费机会。

### 3. 刷新负结果记忆（W11，轻量形态——非期望式，不与 2026-10-12「不用期望价值」裁定冲突）

- **规则**：刷新提案被拒（目标可买 False ∨ 金线不足）→ 本帧直接 `CloseShop` + 会话标记 `refresh_blocked(<节点, 金, 席位快照>)`；外循环重进商店入口观察时，若标记存在且三元组无变化 → **跳过刷新提案**（直接按六序买面/关店走），直至状态变化（节点推进/金变/席位变/星级目标完成）清标记。
- 实现：会话状态载体 = 商店会话状态对象（`shop_session`）新增字段；标记生命周期 = 节点级（跨节点清零）。
- 覆盖免费分支：免费刷拒绝（目标不可买）同样置标记——消灭「高效决策 9999 白给刷」的每刷一重进循环（白给刷在标记存在时同被跳过，免费次数保留不耗）。
- 行为变化申报：本局 r4 形态（3 个收店帧重复提刷 + 1 帧空转）消失——首次拒绝后直接关店，重进零提刷。

### 4. 明确不做（本篇边界）

- 期望式刷新评估（期望刷新次数/再遇窗进判据）：需翻案 2026-10-12 裁定，用户未翻 → 不做。工具保留在 `cw_shop_odds.py`（阵容可得性评估仍消费，不动）。
- 缺件不可达换线出口（W6）、刷新曝光率（W7）：挂账，不在本篇。

## 关键取舍

- **W4 备选 = 弹药位（M6 限额囤货留 1-2 空位）**：放弃。理由：限额是新增数字（strategy-work §1 零调参纪律：来源只能是规则/推导/带区间模型，弹药位数拍不出依据）；全停语义简单且可证（窗口内囤货与刷新争席是支配性互斥——席位是刷新买卡的必要资源）。依据 = 追查件缺陷 #3 归因（M6 灌满反锁刷新）。
- **W11 备选 = 期望式预算包络**：放弃。依据 = 2026-10-12 用户裁定（「期望价值难算不直观，星级目标直接驱动」）未被翻案；轻量记忆达到同等的循环终止效果。
- **W5 备选 = 追加「追星买臂」第四臂**：放弃。理由：新增臂 = 新优先级位次 = 新交互面；统一口径后现有臂自然覆盖（未完成成员 ∈ 义务面 → 序 1 照买），零新增结构。依据 = `11_shop_decisions.md` §1 序 1 语义（义务面照买照囤）。
