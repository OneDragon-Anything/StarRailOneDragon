## 2. 子项 A:开局阶段窗口收窄策略语义(流程账本第 36 行残余)

### 2.1 现行语义与缺口定位

现行(`18_equip_wear_semantics.md` §2.1 判据表 + §6 as-built):开局阶段扣留活跃(r≤2 ∧ 节点非战斗类)→ 非关键件扣留;战斗类节点释放;意向已定型扣留、生锈/输出侧词缀豁免各行照旧。

**缺口**:「r≤2 非战斗节点 → 扣留」是无条件的——只要在开局阶段窗口内且下一节点非战斗,自由件一律囤。但 r≤2 的非战斗节点(奖励/补给/商店类)之后**必然跟着战斗节点**,而装备从判定到落穿只发生在备战帧;等到战斗类节点那个备战帧才释放,遇到动作执行顺序拥挤或标志位跳过(`equip_latch_skip_m7` 实机对局 15–18 号段每局 2–8 次)就会空一拍。195720 的位面 1 第 1–4 轮病灶正是「非战斗节点连扣四轮、战斗帧裸奔」的实证。缺的是**「扣留的资格判据」**——现行语义回答「什么时候不释放」,没回答「什么件在什么帧根本没有资格被扣留」。

### 2.2 成本模型(数学先行,【推】零自由参数;适用范围 = 开局阶段)

> **适用范围声明(v2,对抗审查条目 B2)**:本节论证只适用于**开局阶段帧(位面 1 ∧ r≤2)**——O2 也只在该行帧域生效(§2.3 叠加关系);r>2 的意向已定型扣留帧语义 = `18_equip_wear_semantics.md` 第 2 行原样,本节论证对其零覆盖、零推翻。全域开 O2 的扩展登记待办 §6-7(位面 2 域合成风险另证)。

设开局阶段备战帧 f,owned 中某自由件 e,后随节点 n(f 之后第一个节点)。

**穿戴侧收益(单调 ≥0)**:在开局阶段帧域内,自由件经定义**结构性不含合成减向风险**——位面 1 阶段 RESERVED_COMPONENTS 全量保留 8 基础件(`cw_synthesis.py:78-82`),故开局阶段帧上的自由件只剩进阶系非关键件,而穿着即合成的触发对只存在于简易×简易(机制篇 §1.1「28/28 全为简易对」),进阶件不参与任何配方对 ⇒ 「穿进阶件」不存在被残留件带偏的不可逆合成。战力提升对战斗败北罚是单调减向——boss/遭遇败北罚 P ∝ 敌方剩余血量(user_playstyle [27],玩法立场登记条目:优先当场战力;g_20260831_082322 复盘「最大化当场战力直接折算省血」同源)。故:

```
wear(e, f) 的收益 ≈ ΔP(f→n) ≥ 0,严格 > 0 当且仅当 e 的战力贡献
改变了节点胜负或未达标差额;任何参数下不劣。
```

**持有侧收益(逐项消解为 0,均在开局阶段适用范围内)**:

1. **组件保留价值**:位面 1 内 8 基础件全被 RESERVED_COMPONENTS 排除(`cw_synthesis.py:78-82`)⇒ **开局阶段帧自由件(进阶系非关键件)对「定阵容前不浪费合成素材」([29])的保留承诺为空**——这些帧上根本没有可被误合成的保留素材;唯一件(标记「(唯一装备)」)另由保留域④扣留(§2.3),不入本论证;
2. **目标对位价值**(「攒给对的人」):穿戴是可逆暂借——卖角色装备全额回区(机制篇 §1「卖出角色=装备全量回装备区」,[24] 装备转移是常态),错穿成本 ≈ 0;「攒给成型核心」只在核心**已定时**才有意义,而已定时语义由 `18_equip_wear_semantics.md`「意向已定型扣留」行承载(关键件命中件随时穿)——开局阶段(意向未定型)的对位赌注没有任何支撑结构;
3. **计件封顶内的滞留罚**:库藏生锈类词缀按 owned 滞留计罚,封顶内单调(`18_equip_wear_semantics.md` 生锈豁免行论证已立),自由件滞留同样暴露在承伤侧词缀(如「额外打击」按空装备栏计罚)下——滞留不比穿戴安全。

**支配性结论【推】(适用范围 = 开局阶段帧)**:开局阶段帧上的自由件穿上,弱占优于继续扣留;严格占优在后随节点为战斗类时成立。该论证不含任何待标定常数——**判据可以不引入新数字,这是它优先于任何「r≥k 才穿」阈值门的理由**(strategy-work §1:存在支配性论证时必须用论证消掉参数)。**该结论不对 r>2 帧与位面 2 帧作任何主张**(v2,对抗审查条目 B2:旧稿「任意备战帧」措辞过述,作废)。
