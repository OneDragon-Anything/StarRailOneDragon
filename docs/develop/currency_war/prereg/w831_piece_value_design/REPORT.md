## 1. 架构定位

**一行**:件价值模型 = **买/留/卖/合成时点四类消费点共用的单一估值函数**(输入:件的身份/当前板面/意向线/位置容量/时点 → 输出:统一价值分与分量分解),各消费点消费同一函数,不再各自为政。

### 1.1 共同根(为何是架构件)

W822 §0 判定:F1 残余(κ 只削罚分缺正向估值——target 外体系钥匙件被拒买)+ F3(贯穿件不在任何估值集——千冶·刃 0.95 未买)无辖域且同根。跨件半问判据(同族修法第 2 件即升级)在此已是第 3 件(F1/F2/F3):**「一件非当前 pair 成员的高价值件值多少分」这个问题,在现行代码里没有单一源**——

- 买侧候选评分(scoring.py)只给锁定线成员正加项(P29/Δp_tier/merge 时点),线外件只有 κ 折扣(惩罚侧)与常数罚;
- 留/卖侧(bench 挤占/卖出)没有跨件留存价值账——贯穿件、他体系引擎件在持有判定里与散件同权;
- 合成时点(merge_timing_term)只辖缺件合成的排序显影,不回答「这份组件第二件该不该凑」。

各消费点对「件的价值」各持局部判据,正是 F1/F3 类病灶的结构性温床。治理形态不是给某类件加第 N 个加项(那就是 W822 明令禁止的评分补丁),而是把估值本体抽为单一函数,消费点全部改为消费它。

### 1.2 函数形态(一行签名)

```
evaluate_piece(piece, state) -> PieceValueBreakdown
```

- 输入:件身份(名/费/羁绊/装备/星级)、GameState 当前帧(板面/bench/金/等级/轮次/血)、意向线状态(cw_intention 锁线态/pair)、位置容量与占用;
- 输出:`PieceValueBreakdown`(分量分解对象,§3),消费方可取总分或任一分量;
- **纯函数**:零跨帧账本、零副作用、零决策消费——模型自身不买不卖不排序,行为变更只发生在消费点接入时(分批、各带旗标)。

## 2. 与既有件关系(禁第二分配器/第二罚分器/第二门)

**切分声明一行**:模型 = **估值单一源**;W802 κ 折扣 = 惩罚侧(模型分量的外侧应用);W803 缺口差分 = 档位侧(模型档位分量的应用);W829 支出门 = 约束侧(模型不进门,门用触发判据)。三者均为模型的**消费方或并行层**,不是被替代对象。

### 2.1 重叠面清单与切分

| 既有件 | 层 | 与模型的关系 | 重叠面与防双计 |
|---|---|---|---|
| **W802 κ 折扣**(realization off-lock 比例折扣) | 评分层·惩罚侧(改序不改可买性) | κ 折扣消费**模型输出的正增量**做比例折扣:`val_after = model_val 正部·(1−κ)`——κ 是模型分的**外侧后处理**,不是模型内分量 | 模型不得内嵌任何「线外罚」项(罚的本体归 κ 单一实现);κ 通道语义归 W802 的 A/B 检验,模型只承诺输入兼容。缺件判据单一源 `missing_members` 继续由 W802 持有,模型的线内缺档分量**消费**它,禁另写一套缺件判定 |

### 2.2 辖域外声明(防第二 X 纪律重申)

模型不开源、不否决、不授权、不分配、不造第二账本;金账单一源、Δp_tier 单一源、missing_members 单一源、单分配器纪律(ADR-0474)全部维持,模型只是新增一个**只读的估值服务**。

### 3.3 可加性诚实声明与分量归因通道(v2 修正③)

- **线性可加是近似不是命题**:六分量线性可加(`total = Σ w_i·V_i`)在命题层无背书——各已证命题给的是辖域内的**方向与量级**,不是「分量间无交互项」的证明。已知交互面至少三处:①激活×档位(P20 激活件同时常是缺档成员,A 与 C 非独立——P20 的 e≥1 边际转移本身就是交互项);②留存×位置(B 的持位成本已单列 E,但持位成本对 retention 的反向挤压非线性);③合成×档位(D 的时点价值依赖 C 的缺档状态)。
- **边界声明**:可加性成立的承诺域 = **交互项弱的稀疏帧**(同帧至多一个非零正分量占优);密集交互帧(多分量同显著非零)的总分只作排序参考,不作归因依据。
- **分量归因通道(显式化)**:任何行为判读/A/B 归因**只允许按分量归因,禁止按 total 归因**——Breakdown 逐分量进 telemetry 披露键(纯披露,零决策消费,ADR-0488 范式),判读时先看「哪个分量动了」再看行为变没变;交互项显影时归属规则=归入**触发判读的主分量**(如激活帧缺档件买入 → 归 A,不折半归 C),规则写死防各批自由裁量。

### 3.2 量纲与归一(诚实声明)

- 各已证命题量纲不一:P20 胜率/Δhp 倍数、P32 hp 阶跃、P1 轮数、P14 轮数。**统一基数折算(全部折成金当量或胜率当量)当前不可得**——缺「hp↔金↔胜率」的权威兑换率,拍一个兑换率=魔数。
- V1 形态因此取**序数优先**:总分 = 辖域门内分量的加权和,权重为占位参数(挂标定);模型承诺的三件硬性质是 ①分量可分解(任何断言可归因到分量)②辖域门硬编码(命题辖域外分量恒 0,禁越辖)③单调性锁(§5)。**基数可比性不在 V1 承诺面内**,A/B 判据全部设计为不依赖跨分量基数兑换(§5.3)。
- **不可估维诚实声明**:①Δp_prep(硬节点备战,P26 卡点)不建模——F5 归 P26 前置批;②跨件协同中超出羁绊计数的部分(装备×角色交互、站位乘区)不建模——M12/F10 归各自小件;③P4 证伪的压库收益方向不建模(F8 警示直引);④「装备成套潜力」仅 D 分量的可合成对计数,不做整套期望(P14 的整套纯等不可行结论直引)。

## 4. 落码规格(零落码,规格先行)

### 4.1 模块位置与接口

- 位置:`src/sr_od/application/currency_war/kernel/piece_value.py`(kernel 与 cw_registry/cw_intention 同层,被 scoring/realization 只读消费)。
- 接口(签名显式、全类型注解、构造无 **kwargs,项目规范):

```python
@dataclass
class PieceValueBreakdown:
    activation: float   # 分量A,辖域门=e<2,出处 P20 —— Phase 1 消费面
    retention: float    # 分量B,出处 P1+P11,量占位挂 P34 —— Phase 1 消费面
    tier_gap: float     # 分量C,消费 realization_delta_p_tier 单一源 —— Phase 2-b 进消费面
    merge: float        # 分量D,出处 P14+ADR-0437/0438 豁免通道语义 —— Phase 2-b
    bench_cost: float   # 分量E(负),占位 H 挂标定 —— Phase 2-a
    interest_cost: float# 分量F(负),出处 P13/P33 —— W829 门域,模型侧后置
    @property
    def total(self) -> float: ...  # 辖域门内分量加权和,权重读 registry;Phase 1 仅 w_activation/w_retention 非零

def evaluate_piece(piece: CwPiece, state: GameState, weight: PieceValueWeight) -> PieceValueBreakdown: ...
```

- `PieceValueWeight` 各分量一个权重字段,全部从 registry 读(§4.2);注释按规范写「结论→出处(ADR/命题号)→边界」,禁会话局部标识符。
- **Phase 1 接口收窄(v2 修正④)**:dataclass 六字段齐备作纯披露,但 Phase 1 的 `total` 合成面只启用 A+B 权重,其余权重 registry 恒 0 且消费点禁读取(哨兵锁:非 A+B 分量在 Phase 1 消费面出现非零权重 = 锁红)。

## 5. 判据(判前锁草案)

### 5.1 模型正确性判前锁(结构锁,不锁分布数值,锁契约按测试纪律)

1. **分量可分解性**:Breakdown.total ≡ 辖域门内分量加权和(改任一权重只动对应分量)——锁分解,不锁值;
2. **辖域门锁**:e≥2 帧激活分量恒 0(P20 辖域);非跨线件 retention 恒 0;锁线成员 tier_gap 消费 missing_members 同源(对拍 realization 同帧值相等);
3. **单调性锁**(命题直推):同帧同费,P20 辖域内体系钥匙件 activation > 同名散件(P20 倍数>1);再遇期望轮数越大 retention 单调不减(P1);满息段(g≥50 内)interest_cost≡0(P11);
4. **off 恒等性**:伞+全部子旗标关 → 全部消费点行为逐位等于现行基线(零漂移锚);
5. **纯函数锁**:同输入两次调用输出逐位相等,无跨帧账本、无落盘。
6. **Phase 1 消费面收窄锁(v2 修正④)**:Phase 1 权重面 C/D/E/F 恒 0(哨兵);W802 κ 恒等式锁 #3(on=raw·(1−κ),raw>0)在 Phase 1 交付下原样全绿——κ 通道零改动是断言对象(修正①)。

### 5.2 A/B 判据草案(格式对齐 W829 §5.2 PREREG 范式)

- **臂**:off=registry 缺省全 off / on=Phase 1 伞+buy 子旗标开,分量面仅 A+B(单因子归因,与 W802/W803 开关不同开——ADR-0494 正交性纪律同款)。κ 通道 Phase 1 零改动(修正①),无 κ 前后对照臂;κ 收口归 Phase 1.5 独立 A/B。
- **主判据(Phase 1)**:拒绝买病灶复现率下降——①「他体系钥匙件在 e<2∧溢余段被拒买」事件占比显著下降(单帧锁反演为 sim 计数);②「贯穿件 0.95 贴线未买」同类事件占比下降;③**G7 息基侵蚀判据(v2 修正②,与 W829 v3 的 G7 降格对齐):不再用「≤+1pp 回门」格(W830 已证该格不可达——改善全集中慢尾、侵蚀有 sim 结算键外的固有底)**,改为**复算上界带**:从 on 臂 arms jsonl 离线复算「新增买入笔中破息笔的息档折算损失之和」得上界,判格 = 实测 G7 残差 ≤ 该复算上界(即残差可被本臂买入行为全额解释,无来源不明侵蚀);G4 挤席维持 W829 清账门 ≤+2pp 不变——**买侧加项放宽不得重演 W828 的 G7/G4**(它们将由 W829 门兜底,但模型不得把门当免责)。
- **Phase 2 判据**:留/卖侧=贯穿件持有局的跨线成型率与卖出后回购笔数(再遇账应证 P1 方向);merge 侧=组件拆穿事件清零(P14 方向)。
- **Goodhart 警报**:任一臂线外件买入率 >30% 帧占比 → 权重过宽,回炉重标定,不调命题辖域门。

### 5.3 分阶段判据汇总

## 6. 数学:P20/P1/P11 如何约束模型形态 + 新命题

- **P20(已证)**约束形态:激活贡献必须是**倍数级且辖域 e<2 硬门控**——它证明的是「e0→1 的次战边际 > 散件升星」的方向与倍数带,不是线性可加基数;e≥1 边际转移回核心 2★/目标件囤积 → 模型在 e≥2 时激活分量恒 0,这是命题辖域直接翻译成代码守卫,不许外推。
- **P1(已证)**约束形态:retention 分量必须是**再遇轮数的单调函数**(越稀有越囤),且持有可逆性(卖出全额退)使持有期成本仅为持位成本——不留存惩罚项;5费 60-180 轮的量级说明 retention 对高费跨线件在溢余段可压倒短序排序项,这正是 F3 病灶的数学解释。
- **P11(已证)**约束形态:溢余段(g>50)利息成本分量≡0——**满息段买入零息损**,贯穿件/钥匙件的购买判据在溢余段只剩正向分量与持位成本;P11 同时警戒非溢余段的成本语义(⌊g/10⌋ 档差),与 P33 结构同式,故 F 分量直引 P33 口径。
- **P32(结构已证)**:档位分量以「离散阶跃」而非连续函数进入——tier_gap 只对「使成型档组缺件数下降」的件非零(与 W803 ΔG 差分同构),非缺档件该分量为 0。
- **新命题 P34(立,挂账待证)**:**贯穿件/跨线留存件持有 EV**——EV_hold = P(留存至跨线可用时点)·ΔV(跨线战力贡献) − Σ持位成本,且在溢余段购入时息损项为 0(P11),故 EV_hold>0 的判据可脱利息项独立成立;数据前置=stage_transitions Q1 留存率(现成)+跨线战力贡献下界(可引 P20 族离线复算)。状态=待证明(结构半证,卡点=留存率→跨线时点的条件表);P34 证明前分量 B 以占位进入 Phase 1,开臂判据含 P34 结构证明。
- **不立新命题的项**:F 分量引 P33(W829 已立,不双立);E 分量挂 P29 既有标定卡点(不另立)。
