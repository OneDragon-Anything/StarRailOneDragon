# 货币战争-备战-装备详情(点 owned 装备弹的装备-only 详情)

备战画面点击**右侧 owned 装备列**的某个装备 icon → 右侧弹出该装备的独立详情(装备-only,**无角色信息**)。与「角色详情里的装备子态」(点角色→角色详情→点角色装备)区分:本面板无角色名/阵营/装备推荐,只有装备属性 + 可合成列表。

## 画面归属:备战 overlay 子态(非独立画面)

- 装备详情 overlay 打开时,**备战仍 is_precise=True**(id_mark 购买经验+出战+前台区域+后台区域 全中,出战未被盖住)→ **不单独成画面**,是备战的 overlay 子态。
- 区别于「角色详情」(点角色→右侧面板盖住出战 → 备战缺出战 id_mark → 不 is_precise → 独立画面 货币战争-备战-角色详情)。

## 何时出现 + 状态流转

- **入口**:备战画面点右侧 owned 装备列某装备 icon(`owned_equips` extras 给坐标)→ 本 overlay。
- **子态① 基础装备详情**(默认):右侧面板 = 装备名 + category(简易装备/进阶装备/…) + 属性(速度增幅 等) + **可合成列表**(可合成的进阶装备名 list)。
- **子态② 合成目标详情**(点可合成列表某项):**左侧**追加合成目标面板(目标名/category/属性/效果描述 + 合成公式),右侧源装备详情保留 → 双面板对比。
- **出口**:点画面空白处 → 关闭 overlay 回备战(无关闭按钮;不是 X,不是 ESC)。

## 识别特征

- **备战 id_mark 全中**(overlay 不盖 id_mark)→ 命中 货币战争-备战 is_precise=True。
- overlay 特有 OCR:装备名(动态,如 轮滑鞋/量产型装甲)+ category(简易装备/进阶装备)+ 属性(速度增幅 X%)+ **可合成列表** + 合成目标名(反重力皮靴/火力风暴潮/…)。
- 现有 area 复用:`详情-装备名`(动态 text,纯定位)、`详情-装备类型`(text=简易装备)、`装备详情-合成公式`。

## 可交互元素

## automation 要读信息

- **装备属性**(速度增幅 等):评估装备价值(策略用,EquipAll 穿戴决策)。
- **可合成列表**:合成路径规划(哪些装备能合什么)。
- 当前 bot 未读这些(EquipAll 按 target_comp.key_equips 优先穿戴,不读详情面板);建档供后续策略增强。
