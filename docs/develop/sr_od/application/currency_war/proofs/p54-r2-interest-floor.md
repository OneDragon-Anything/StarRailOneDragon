## 命题

修 A(P53)落码后的 sim 对拍暴露系统性超调:刷新 0.43→77.83 次/局、金被刷到 0-4、买入链饿死。根因定谳(P53 §④ 申报 1):cw4 R2 预算门(`criteria/refresh.r2_budget`)的预留输入在消费位组装为 `b_target(0,0,0)=0`,门退化为 `gold ≥ 2`——**P40 R2 规范口径「溢余段刷窗 `n_max = ⌊(g − 50 − Σ预留卡价)/c_eff⌋` = 息线之上可刷预算」从未落码**。要证:

1. **等价性**:消费位改传预留 `reserve* = g* + ρ`(`g*` = 息线 = `saturation_line(cap_resolved)` = 10×cap_resolved;`ρ` = 合格集最低费卡价)后,现行 `r2_budget(gold, reserve, c_eff)` 判据 `gold − reserve ≥ c_eff` 与 P40 溢余段刷窗公式 `n_max = ⌊(g − 50 − ρ)/c_eff⌋ ≥ 1` **逐位等价**(单刷发射粒度)——修 R2 是把缺位的预留组装补上,**不改判据本体**;
2. **floor 存在性与零新自由参数**:`reserve*` 逐分量锚定注册表/表值,无任何新常数;
3. **floor 的保护语义**:门过 ⇒ 刷后金 ≥ `g* + ρ` ⇒ ①刷后利息恒满档(`min(g'//10, cap) = cap`);②至少一张合格集命中卡可在不破线前提下买入(`ρ` 预留);
4. **健康带判据(对拍前预注册,防事后挪线)**:数值判据 §③,修后对拍须三件全中——刷新回落健康带、金线不破、买入恢复。

## 假设(显式)

- **A1 波粒度发射**:商店线发射粒度 = 每波至多 1 次付费刷新(`RefreshShop` = 契约 v2 §3.1 截断点,shop.py 现行结构)。P40 R2 的逐笔重估在本臂 = 逐波重估(波边界 = 新的启动决策,g/j 已更新)——预算熔断是时序配置不是失败(P40 ⑤「本期刷窗用尽即停,缺口跨节点保留,下期续」),波粒度是该语义的忠实实现粒度。
- **A2 Σ预留卡价的下界口径**:P40 待标定清单给「按合格集最低费卡价 × 期望命中数的保守值」。单刷粒度下一次刷新发射后的可买入命中卡按 1 张计(期望命中数的整数下界——P40 ① 期望命中数 5q 在合格集小、池深时 < 1;预留多计 = 门收紧向,单卡下界即 floor 的最小充分预留)。多命中超出 `ρ` 的买金让渡 = 下一波 R2 重估补足(显式让渡账,非破线刷新)。
- **A3 买入义务不走息律门**(既有设计,[41],shop.py M2 现行):floor 只约束**刷新通道**;买入侧破线是设计内让渡(义务优先),不属本门辖域——对拍口径须区分「刷新波破线」(结构性应为 0)与「全波破线」(买入让渡,只作观测量不作门)。
- **A4 R1 总账的 L 项与 floor 的分工**:跨档破线刷的息损计价通道 = R1 承诺账内 `L(g, spend, R, Ī)`(P47,已落码);本批不加「L 覆盖即破线刷」的旁路通道——理由 = b1 对拍实证(R1 在中低金位持续开门,单靠 L 计价挡不住金刷穿,金 0-4 时买入链饿死使 V̄ 的买量兑现通道关闭)与 [3]「刷新后还能保证 50 金」的金位语义。息损计价(效率面)与金位下界(生存面)是两道独立的门,本批补的是后者。

## 证明

### ① 等价性(修 R2 = 预留组装补位,判据本体不动)

对整数 `g, g*, ρ ≥ 0`、`c_eff ≥ 1`:

```
r2_budget(g, g*+ρ, c_eff) ⟺ g − (g*+ρ) ≥ c_eff ⟺ ⌊(g − g* − ρ)/c_eff⌋ ≥ 1 ⟺ n_max ≥ 1
```

三步均为整数序关系恒等式(末步:非负整数 m,`m ≥ c_eff ⟺ ⌊m/c_eff⌋ ≥ 1`)。P40 R2 溢余段刷窗的完整语义 `n_max = 本期可刷次数`,在 A1 波粒度下退化为判「本期还能不能刷第 1 次」——`n_max ≥ 1` 即完整判据。故修 R2 的落码面 = **消费位预留组装**(`reserve: b_target(0,0,0)=0 → g* + ρ`),`criteria/refresh.r2_budget` 本体与契约(`_gold_minus_reserve_ctx` 先例②)零改动。

### ② floor 存在性与逐分量锚(零新自由参数)

| 分量 | 值 | 出处(锚) |
|---|---|---|
| `g*`(息线) | `10 × cap_resolved` | `saturation_line(cap_resolved)`(statefn/interest 单一源;cap_resolved 经 `interest_cap_resolved`,默认局 = `GOLD_CAP_INTEREST=50`,cw_plane_table 表值) |
| `ρ`(Σ预留卡价) | 合格集(可追成员)最低费卡价 | `CHARACTERS.cost` 注册表 min;可追性 = `refresh_prob(level, cost) > 0 ∧ 无 2★`(与 R1 装配侧 `_r1_member_accounts` 同一过滤,单一源不复制) |
| `c_eff` | `state.shop_refresh_cost`(恒基价 2) | `REFRESH_COST_BASE`(cw_state 建模常量,口径) |

每个分量都是注册表/表值直读或其结构派生(strategy-work §1 两类合法来源),无常数替换常数。合格集空(无可追成员)时 `ρ` 无定义——该帧 R1 门必先以 `no_chaseable_member` 关闭,R2 不可达,`ρ=0` 兜底值不影响任何可达路径。

### ③ floor 的保护语义(门过 ⇒ 两条推论)

门过 ⟹ 刷后金 `g' = g − c_eff ≥ g* + ρ`:

1. **满息保持**:`g' ≥ g* = 10×cap` ⟹ `interest(g') = min(g'//10, cap) = cap`——刷新永不掉息档,息引擎(economy §7「snowball 到 50 金,息引擎是滚雪球核心」)在刷新通道内无条件保持;
2. **命中卡可买不破线**:命中一张费用 ≤ `ρ` 的合格集卡(最低费卡价恒 ≤ ρ)买入后 `g' − 卡价 ≥ g*`——刷新的产出(候选件)至少一张可兑现为持有,刷新-买入链不在金位上自锁(b1 病灶:金刷穿 0-4 ⟹ 见件买不起 ⟹ 刷新纯烧金)。

### ④ 健康带判据(对拍前预注册;修前基线 = 本批 before 臂)

修前基线(同池同 seed,n=30,修 A 后无 floor,落盘 `r2_floor_ab_before.json`):刷新 78.23 次/局、买 14.3/局、全局最小金 **0**、刷新波波末金最小 **0**、破息线(<50)波 445 个、2★ 局 0/30。

健康带推导(判据从锚导出,预注册后对拍):

- **结构带(硬门,验收②)**:刷新波(该波 actions 含 RefreshShop)的波末账本金 ≥ `g*`。由 §③ 这是代码结构性保证,对拍验「违例波 = 0」;全局破线波(含买入让渡,A3)只作观测量不作门。
- **统计带(验收①)**:`refreshes/局 ∈ (0, 30]`。上界推导:守线稳态下每波可花溢余 ≈ 净收入 Ī(线的收入全部积累在线上方,花溢余不破线);Ī 中位 7(P47 口径)、c_eff=2 ⟹ 刷次/波 ≤ ⌊Ī/c_eff⌋ = 3(极限「溢余全刷不买」非健康形态);健康形态要求买刷共摊溢余——REFRESH_CFO §7 健康参照基线 22.9 刷 : 27.9 买 ≈ 1:1.2,给买入留溢余份额 ≥ 1/3 ⟹ 刷带上界 = 48 × (2/3) ≈ 32,取 30(向下整,保守)。下界 > 0:修 A 开门帧(P53 §③ r≥14 全开、j=1 占 87%)在健康金位下应有可刷帧,恒 0 = floor 过紧错误。
- **买入恢复(验收③)**:`buys/局 > 修前基线 14.3`(floor 保住的溢余转入买入;健康参照 27.9)。**2★ 局数 > 0/30 的辖域预判(对拍前写死)**:本臂(cw4 商店线)内 2★ 凑卡的唯一通道 = 买入同名第 3 副本触发合成,而现行买入面只买「未持有」成员首副本(M2 missing 语义)、EV 买面与 M6 压库在 sim 注入态恒 fail-closed(U_X/T_SEARCH_A 未标定,ab_core_swap 申报)——**任何成员的副本数结构性封顶 1,2★ 在本臂不可达,与 floor 无关**(P53 §④ 申报 2/REFRESH_CFO §7 同款申报:2★ 兑现归买入/卖出席位策略批)。故本批对拍对验收③取可辖观测 = buys/局恢复 > 基线;2★ 预期仍 0/30,如实呈报为辖域边界而非本批失败。
- **hp 均值**:参考量,不作门(P53 §④ 同款,验收归正式 A/B)。

## 结论

1. 修 R2 = 消费位预留组装补位:`reserve = g* + ρ`(息线 + 合格集最低费卡价),`r2_budget` 判据本体与契约零改动,与 P40 R2 规范口径逐位等价;
2. 零新自由参数:全部锚 = `cw_plane_table.GOLD_CAP_INTEREST` / `CHARACTERS.cost` / `REFRESH_COST_BASE` 注册表现读;
3. floor 语义:刷新通道永不掉满息档 + 至少一张命中卡可买不破线;跨档破线刷无旁路通道(L 只在 R1 效率面计价,金位生存面由本 floor 硬保证);
4. 预注册健康带:刷新波破线波 = 0(硬)、refreshes/局 ∈ (0,30]、buys/局 > 14.3、2★ = 辖域外(预期 0,结构性不可达归买入批)。

## 对实现的检验点

1. 单测锚:门过帧刷后投影金 ≥ g* + ρ(行为锁,帧级);金贴线帧(g* < g < g*+ρ+c_eff)拒刷 + 分键计数;门过帧发射 RefreshShop(账本级);`ρ` = 注册表派生(非字面量)。
2. sim 对拍:同池同 seed before/after n=30,预注册判据 §④ 三件(数字三件套口径,逐 seed 全量)。
3. 旧行为锁对账:`test_injected_value_opens_r1_into_r2`(gold=60,lv3)在新 floor 下 60 − (50+1) = 9 ≥ 2 仍开门——语义未变,锁不红;`test_injected_value_r2_budget_still_gates`(gold=1)仍关——防线分层保持。

## 边界(本证明不覆盖)

- 波粒度(A1):期内多次续刷不建模(单波单刷发射);若未来发射粒度改多刷,n_max 公式须按 §① 完整式落码(预留 = g* + ρ,判循环)。
- `ρ` 取合格集最低费卡价 = 单卡下界口径(A2):期望命中数 > 1 的帧预留偏紧(门偏收),方向 = 保守(宁少刷不破线),代价 = 刷新量下偏——健康带下界 >0 的判据兜住过紧端。
- 买入侧(EV 买面/M6/凑息卖)的 S 预留同为 0 的姊妹缺口:同根不同消费位,且 sim 注入态下全 fail-closed 不可观测——挂账交编排者裁决,不在本批(辖域 = 刷新门)。
- 2★ 不可达的结构性申报基于现行买入面代码(M2 missing 语义 + EV/M6 fail-closed);买入/卖出席位策略批落码后该边界自动失效,届时 2★ 判据回归正式验收。
