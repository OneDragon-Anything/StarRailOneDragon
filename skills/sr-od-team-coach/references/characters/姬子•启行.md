# 姬子•启行（火·智识·5星）

> 按 V4.7 期撰写。拓星者助战体系：队友呼唤召唤物攻击，全队共享增益；与经典姬子并存独立。

## 一、命途属性与技能说明

**命途**：智识；**属性**：火

| 技能 | 说明 |
|---|---|
| 普攻 | 单体100%攻击火伤 |
| 战技【领航旗语】 | 3回合：全队伤害+10%~22% + 每回合恢复1次助战次数 |
| 终结技 | 消耗能量；操控「拓星者」：6次【超频粒子光束】（全体16%+1源能）或源能驱动的【轨道歼灭脉冲】+ 结尾3×40%随机弹射（单体侧最高381%） |
| 天赋【拓星视界】 | 进战召唤拓星者+全队助战技次数；**队友使用助战技=姬子启行施放战技**：她获全抗穿10%+暴伤40%+无视弱点削韧，助战者回4能量 |
| 秘技 | 同袍领域；进战免费战技 |
| 额外能力 | B1：终结技+3源能；源能≥3歼灭脉冲+30% |

**资源与循环**：标准能量→充能有效。

## 二、推荐遗器与原因

**套装**：熔岩锻铸的火匠4件 + 出云显世与高天神国2件【攻】
**主词条**：躯干暴击率/暴伤；脚部速度；球火伤；绳充能。**副词条**：双暴>攻击>速度。
