# 忘却之庭-编队(treasures_light_team)

逐光捡金**挑战编队画面**(2026-11-04 从 逐光捡金 合并大屏拆出独立建档):左栏角色列表/预设编队 + 右栏关卡信息与两编队槽。入口:选关界面点已解锁关卡水晶。

## 何时出现 + 状态流转

- **入口**:逐光捡金选关点关卡水晶(水晶位置随滚动变化,见 逐光捡金.md 水晶 area)。
- **出口**:右上返回箭头 → 逐光捡金选关(✓实测);按钮-最终开始 → 进入战斗(**不可逆出口,未实测**——启动即打)。

## 识别特征(稳定锚点)

- **标题-忘却之庭行 + 标题-编队行** 双 id_mark(rect 同 逐光捡金 标题族,第二行文字「编队」区分):编队帧两行全中 → 本屏精准;选关帧第二行为 混沌回忆/回忆 → 不误命中(2026-11-04 实测互斥干净)。
- 左栏上方 双 tab:角色列表(默认)/预设编队,选中态白底。

| 元素(area) | 行为 |

## automation 要读信息

- 关卡名文本(如 物竞天择其十)。
- 挑战目标三条(剩余10轮/20轮/无人倒下=星数条件,OCR 可读)。
- 两编队槽:敌人 等级:90 + 建议属性(弱点表,图标)+ 详情入口。
- 记忆紊流 buff 文本(重复展示于本屏顶部)。
- 「3星通关此关卡后,可获得前置关卡的全部奖励」提示条。

## 结构化识别(recognizer,2026-11-04 落地)

⚠️ **适用范围**:本屏建档与识别标定(槽位坐标/建议属性/预设卡/阈值/交互机制)全部基于**混沌回忆**的编队屏;虚构叙事/末日幻影的编队屏布局与交互未探明,不可复用本屏 area 与 `TlFillTeamsOp`/`TlStartChallengeOp`(人类老莫 2026-11-04 明确:其他类型的填充可能不一样),需另行建档。

analyze_screen 精准命中本屏后,`TlTeamRecognizer`(`src/sr_od/application/treasures_lightward/obs/recognizers/tl_team_recognizer.py`)产出 extras,算法与阈值标定见 `obs/tl_team_obs.py` 模块 docstring:

- **关卡信息**:关卡名 / 环境效果全文(大 rect,描述变长不裁切;固定混入的「挑战目标」标题已剔除)/ 挑战目标 3 行。
- **弱点属性**(waves[].weaknesses):每队伍行「建议属性」= 该波敌人弱点图标。OCR 锚「建议属性」定位图块带(布局平移不敏感)→ 色块检测 → 元素模板匹配主判(`assets/template/element_weakness/<元素>/raw.png`,官方元素图标预合成实采底板色)+ 色相域交叉仲裁(紫对 雷 H≈122 / 量子 H≈144 同色异相,TM 色彩主导会互串,按色相纠正)。标定真值:物竞天择其一=[雷]/[虚数,物理],其十=[虚数,火]/[量子,冰];风未采到样本(模板已入库)。
- **波次结构**(waves):波次数按「建议属性」锚行实读(混忆常规 2 波;旧代码称节点,其他模式/回忆章节数量可能不同),每波绑定 {wave_idx, weaknesses, members=该波当前编队}。槽位 area 按行号取(槽位1/2头像-N 已建档;未建档行 members=[] 不编造)。⚠️ 编队画面本身无「波次」字样(行=队伍槽),行序↔波次映射证据 = 每行「建议属性」即该波敌人弱点(两波随关互异)+ 每行敌人预览即该波敌人;「波次」文字实锚于敌方信息浮层(第1波/第2波标签,fixture 可查)与战斗内进度(未实证,候实跑确认)。
- **tab 态判别**:左栏两 tab 标签区亮度判激活(激活 ~178 vs 非激活 ~95-105),驱动左侧分支——角色列表 → 可见网格逐格识别(4列×4行,行/列 0 基);预设编队 → 每卡 4 成员绑组返回(预设卡-1..4)。
- **右侧队伍槽**:槽位1/2 各 4 位头像识别 + 空槽判定;**队伍配置未开打就返回会被游戏丢弃**——识别到的空槽是真实状态,不是识别失败。
- **头像识别**:脸库 `assets/template/character_avatar`(98 角色,选择头像 art)× SIFT(经 TemplateLoader 特征缓存 + `feature_match_for_one`)。诚实歧义:置信 <0.70 或 top1/top2 比 <1.25 时返回候选集不硬猜(槽位头像全可靠;卡内小头像是编队卡图变体,歧义率偏高,真值均落候选前二)。
