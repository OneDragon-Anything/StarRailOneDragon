# 刻律德菈（风·同谐·5星）

> 按 V4.7 期撰写。军功/爵位单体养成：指定队友吃增益，攻击转暴伤。

## 一、命途属性与技能说明

**命途**：同谐；**属性**：风

| 技能 | 说明 |
|---|---|
| 普攻 | 单体风伤 |
| 战技 | 指定单体获得【军功】+自身+1充能（上限8）；军功持有者攻击+（刻律德菈攻击24%）+其攻击时刻律德菈附加60%风伤 |
| 终结技 | 消耗能量；AoE 240% + 2充能；场上无军功时优先给一号位 |
| 天赋 | 充能6点 → 军功升级【爵位】：**战技暴伤+72%+全抗穿10%+战技触发奇袭**；奇袭结束消耗6充能降回【军功】——战技型主C的养成链 |
| 秘技 | —（以官方文本为准） |
| 额外能力 | **E1行迹：攻击>2000 每100点+18%暴伤（上限360%）**——攻击转暴伤 |

**资源与循环**：标准能量→充能有效；军功持有者普攻/战技+1充能。

## 二、推荐遗器与原因

**套装**：野穗伴行的快枪手4件 + 生命的翁瓦克2件【攻：攻击转模口径】
**主词条**：躯干**攻击%**；脚部速度；球风伤/攻击；绳充能。
**副词条**：攻击%（→4000 E1 吃满）> 双暴 > 速度。
**转模与转化上限**：E1 攻击→暴伤，**2000 起步、4000 吃满**（+360%）。

## 三、推荐配队与原因

| 阵容 | 为什么 |
|---|---|
| **战技型主C**（饮月/遐蝶强化战技/青雀等） | 爵位增益全部围绕战技伤害（暴伤+72%+抗穿10%） |
| 高频攻击目标 | 充能获取快 → 爵位覆盖率高 |

**硬否决**：普攻/终结技型主C收益降档。
