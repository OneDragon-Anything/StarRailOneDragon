# 流萤（火·毁灭·5星）

> 按 V4.7 期撰写。完全燃烧超击破主C：战技烧血回能、击破特攻进倍率；体系见 [击破队](../teams/击破队.md)。

## 一、命途属性与技能说明

**命途**：毁灭；**属性**：火

| 技能 | 说明 |
|---|---|
| 普攻 | 单体火伤 |
| 战技「指令-天火轰击」 | **消耗40%生命上限→固定回60%能量**+200%攻击单体（**不耗战技点**） |
| 强化战技「死星过载」 | 完全燃烧时：回25%生命+**添加火弱点**（2回合）+(0.2×击破+200%)攻击单体+0.1×击破+100%相邻——**击破特攻直接进倍率，计至360%**【官】 |
| 终结技「完全燃烧」 | 消耗能量；行动提前100%+速度+60+击破效率+50%+强化普攻/战技；倒计时70速 |
| 天赋 | 血越低减伤越高（≤20% 最大40%）；燃烧状态维持最大减伤+抵抗30%——烧血安全垫 |
| 秘技 | 进战完全燃烧预备 |
| 额外能力 | **B1：攻击>1800 每10点→击破+0.8%**；**D2：燃烧时击破≥200%/360% → 攻击已击破目标削韧转35%/50%超击破**【官】 |

**资源与循环**：标准能量但战技固定回60%——充能绳价值低；战技不耗点（烧血）。

## 二、推荐遗器与原因

**套装**：荡除蠹灾的铁骑4件 + 劫火莲灯铸炼宫2件【攻：击破口径】
- 铁骑4：无视防御+击破——超击破主C套
- 劫火莲灯2：速度+击破位面

**主词条**：躯干攻击%；脚部速度（燃烧+60后再堆）；球攻击%；绳**击破特攻**。
**副词条**：击破特攻（→360% 满档）> 攻击%（>1800 部分）> 速度。
**转模与转化上限**：B1 攻击→击破（1800+线性）；倍率计至 **360% 击破**——毕业线。
**不堆**：双暴（倍率被击破稀释）、充能绳。
