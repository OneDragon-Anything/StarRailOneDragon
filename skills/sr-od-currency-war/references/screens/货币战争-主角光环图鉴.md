# 货币战争-主角光环图鉴

## 画面简介

全部主角光环的图鉴网格 + 右侧详情面板——光环效果文本与适配角色的读数位：数据银行主页下排的「主角光环图鉴」晶石卡进入。左侧网格 7 列（归档帧可见 3 行，底部露出第 4 行上缘；收集 45/82，向下滚动推进），每格 = 光环图标 + 名字，选中格带白色描边；网格上方一条分类计数「全部主角光环 [n/m]」。右侧详情面板随选中格切换：光环名 / 大图标 / 效果说明 / 「适配角色」头像一排。左下「奖励进度 n/m」金条，条右端红色「!」= 奖励可领。顶部有图鉴族共用的图标切换条（9 个无文字图标，本画面第 6 签选中），左上标题「主角光环图鉴」+ 扩充倒计时，右上返回箭头。

离线建档声明：布局与读数来自归档帧（选中「蚁群效应」态）；「数据银行晶石 → 本画面」的进入关系来自实机探索的帧序，切换条各签、返回箭头的点击行为未单独实测。

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 进入本画面 | MCP `click` | 数据银行主页「入口-主角光环图鉴」area 中心（识别返回坐标） | 进主角光环图鉴 | — |
| 选光环 | MCP `click` | 「区域-光环网格」内目标格坐标（自己读图定位：图标或名字处） | 该格出现白描边、右侧详情面板切到该光环 | 网格靠拖拽翻页，目标不在首屏先滚 |
| 读光环效果 | MCP `analyze_screen` / 看图 | 「区域-详情面板」「区域-光环效果说明」「区域-适配角色」 | 读到效果全文与适配角色 | 效果文本随选中格变 |
| 滚动网格 | MCP `drag` | 「区域-光环网格」内拖拽（手指上滑 = 向列表深处翻页） | 网格翻页 | 方向先实机验证再写死 |

| 返回 | MCP `click` | 「按钮-返回」area 中心（模板匹配位置） | 回上级 | 去向待实机核对 |
