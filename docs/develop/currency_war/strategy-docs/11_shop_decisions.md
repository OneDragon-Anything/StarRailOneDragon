## 2. 升级决策(arm1/arm2 双臂;路径总账判据,ADR-0516 形式二)

- **存在性(arm1,阵容驱动)**:谓词三元「板满 ∧ 等待件(阵营相关单位不限星级,玩家裁定)∧ 边际贡献>0」+ 硬可负担——骨架义务 M3,arm2 无权否决存在性(P39 ② 臂一;ΔV_pop = w·1[板满 ∧ 等待域非空 ∧ 边际贡献>0],w 待标定禁计值 ⇒ 臂一只用指示方向)。
- **等级帽资格闸(硬闸,先于双臂账,ADR-0565)**:等级达注册表 `level_max` 即拒发升级——单一源 = `kernel/cw_registry.level_max`(live 机制真值,`cw_state.xp_apply_clicks` 封顶同源);sim 经 `sim_decision_registry` 注入视图保持其建模冻结,策略零感知。判据历史键名 `lv9_stop`(cap=9 旧语义时代命名,键串保留);lv9 是 live 正常付费档,资格过闸后按整买/血预算/预算闸逐帧判。
- **调度门(arm2,搜牌驱动)**现行形态 = **arm2 结构守息门 g\* = 10×cap_resolved**(零 λ 依赖的结构安全阀)+ λ 顾问分位触发帧收紧(只延迟调度类批);「只延迟不否决」权限语义不变。
- **② 臂 U_L 阈值检验(ADR-0516 修正①,落码 = cw_economy.schedule_upgrade ② 臂)**:升级 iff c_eff·(E(D|L) − E(D|L+1)) + ΔV_pop > U_L + C_int——全部游戏定义量:c_eff=刷价现读;E=expected_refreshes_for_card(REFRESH_PROB 池参数);U_L=clicks_to_next_level×xp_click_cost(XP 表/OCR 实读);C_int=息损 P47 L(g,U_L,R_剩余,Ī),cap 参数 = cap_resolved 现读(session resolved 链单一源,ADR-0516 cap 三源归一——裸缺省 5 在息律投资 cap=10 局低估 C_int)。ΔV_pop 按 P39 式指示项(w 禁计值:指示=1 视为翻转项、指示=0 时纯概率账须独自过阈)。**单核代表降级申报(ADR-0516)**:规格的 E 为缺件集 ΣE_i,实现取单目标核心代表(缺件集装配在 strategies 侧,kernel 判据禁 import strategies)——多成员同受升级受益帧检验偏严(保守向);成员在 L+1 概率回落帧单核可能高估净受益(边界注)。**反例(推导批,写入正文的直觉修正)**:希儿 lv7 概率侧省刷费 28 < 升级金 40,纯概率账亏 12——裸「峰值级>当前级」直觉缺此检验会在小移位带过度升级,靠人口位 ΔV_pop 才翻转(数字锚:2 费 lv5→6 benefit≈9.9 < U_L=5击×4金=20;4 费 lv7→8 benefit≈103 > U_L=13击×4金=52。**锚口径(2026-09-06 亲验,production 函数直算)**:三锚均系代码消费档(2★,k=3,ts=2)真值——benefit=c_eff·(E(L)−E(L+1)),E=期望刷次数(未含刷费):2费 E(5)=28.6/E(6)=23.7 ⇒ 2×(28.6−23.7)=9.9;3费 E(6)=38.1/E(7)=23.9 ⇒ 28.4;4费 2×(94.9−43.3)=103.3;3★ 档(k=9)**benefit** 参考:2费 lv5→6 ≈33.7、4费 lv7→8 ≈741.8(同 2★ 锚的 benefit 形态与级对,非 E 值);j 按成员现值入账(j=2 时 3.4,距阈更远,方向不变))。
- **形态**:整买引理(Leontief 互补,P48 ①②):只以补齐批形态发生;触发 iff 双臂门 ∧ g ≥ S。
- **何时买 = 动态目标线 S = 批成本 + floor_resolved + Σ(窗口预留卡价) + E[刷费]×2**【推,P48 ②】(恒>50——超息囤钱是常态路径;资产形态口径:金位按「裸金+活期卡退金」计);>50 溢余在 S 之上才"随时花"([17]×[41] 联合口径:汇率判据 V_a > ρ·x/Ī + L,P48 ③);多目标并队按每金价值率 ρ_i/S_i。
- **路径总账 vs 贪心(ADR-0516 修正②)**:升级与否不按「当前在售件先买」的贪心序裁决,按路径总账 T 取小——反例:缺花火+希儿时,留 lv6 双买账 123 < 买花火升 7 再买账 135,贪心序多付 12(读数分解:stay 侧 123.63=2×(23.7+38.1) 系 j=0 双卡纯刷费项(完整 T_stay 另含 Σ卡费 15 与息损 L ⇒ ≥138.6);up 侧 135.2=2×E₂(6)+U_L(40)+2×E₃(7)(花火 lv6 刷得+升级金+希儿 lv7 刷得,**含 U_L 而 stay 侧不含——两数为各自侧构成读数,非同口径**);「多付 12」为方向性差(不设浮动带——花火 j∈{0,1,2} 只能使 up 侧变小至 100.2,j 不生成上浮动;升档读法变体如「花火也去 lv7 刷」则 150.8,与中心账不同构成));实现承载 = 刷新门 T_stay/T_up 两侧枚举(§3)与本节 U_L 阈值检验。
- **lv9→10 特档**:摊还账闭式;全部标定带内停手窗恒负 → lv9 停留账面正确(P35)。**分层调和(ADR-0565)**:此账面结论 = EV 账「不鼓励」(停手窗内升级账为负的偏好向),非资格闸「硬拒」——lv9 升级资格自等级帽单一源接线后按注册表 `level_max` 逐帧判,行为面归 ADR-0565,本行只辖 EV 偏好账。P35 引用仅作账面出处、不构成 lv9→10 行为面证据:P35_VALIDATION 是 hp→金价值换算的过渡口径挂账,不含 lv10 的直接机制证据(live 封顶 10 的证据链见 ADR-0565 §1)。
- 实现护栏:禁 scoring 小数等级线性计价通道(P48 头注);cap 感知硬约束(消灭 LevelUpRejected)。
- **血本位突变安全带**([40]②):血余额 ≥ 下一级血成本(⌈need/4⌉×6)才买经验,否则停(支付能力检查);升档器血线硬地板触发帧解锁破息批至饱和线下(00 §4)。

## 3. 刷新决策(路径总账·形式二;ADR-0516,V̄ 链退役)

> 判据规格(已裁决 = 形式二「路径总账比较」;用户裁定禁胜率建模——旧 V̄_net/V_GAP 比较项整链退役,ADR-0516 + P53 修订单 R2;判据本体 = criteria/refresh.r1_commitment_account,账项装配 = `shop.py _r1_ledger_terms`(docstring 载口径申报);消费时机(as-built,ADR-0517/0518)= 每次刷新提案以期望态现算(判据层纯函数零改动,从一次判 N 次改逐次各判一次)。

**输入面(全为游戏定义量)**:等级 L / 金 g / 缺件集 D(每卡 → (cost, k, j):费用档、目标张数 k ∈ {3, 9, 1}(2★ 完成档 / 3★ 完成档 / 下一张单卡档;代码消费位取 2★ 档)、已有张数 j;c_taken=同费非目标已拿走数,缺则 0)/ R_剩余(horizon 现算)/ Ī(收入日程现算)/ 语境参数(c_eff 变体 = 免费额度折抵/轮岗翻倍档,池突变 resolved 后整表重生成)。**Σ卡费口径**:每成员按完成路径真实卡费 = (k−j)×cost(k=3 完成档张数)——与 E 的 (k−j) 张折算同档,非单张 cost(单动作语境:账在决策入口现算,持有副本 j 即期望态字段、单处读取——ADR-0517 §消灭的 bug 类·j 低估;flow/screen_op.md §1)。**金基准口径**:R1 刷新提案在买面动作之后评估(单动作选择序:EV 买面 → R1 付费刷新 → 终结,ADR-0517 §与现行架构的映射·选择序),金基准 = 期望态当前值——先前买入已由逐动作纯计算投影扣减,与 R2 同基准;不存在「帧首快照金」口径(「波首金」口径已随 ADR-0516 修正③退役为买后投影金;单动作架构下帧首快照金属结构性不可达,ADR-0517 消灭的 bug 类、ADR-0518 已落码;flow/screen_op.md §1)。

**公式(路径总账)**:

```text
T_stay = c_eff·E(D|L)   + Σ卡费 + L(g, spend_stay, R_剩余, Ī)
T_up   = c_eff·E(D|L+1) + Σ卡费 + U_L + L(g, spend_up, R_剩余, Ī)
E(D|L)   = Σ_{卡∈D} expected_refreshes_for_card(L, cost, target_star, owned=j)
L        = loss_exact(P47 双轨迹递推;g* = 10×cap_resolved)
U_L      = clicks_to_next_level × xp_click_cost(XP 表/OCR 实读)
L* = argmin(T_stay, T_up)        # 形式二的等级选择输出
启动门(R1) = T(L*) ≤ 可用预算 = g − g*
```

**完成账语义(用户裁定 2026-09-04「对整个目标阵容……是不是合适的」读法;ADR-0516;装配承载修正 = ADR-0571)**:E(D|L) 服务的是**整套缺件集**的补齐——E 与 Σ卡费都对合格集整体求和(每成员 (k−j) 张折算 / 真实卡费 (k−j)×cost),与旧「逐成员取 min」账相反:旧账只问最优成员可追与否,完成账把等级视为服务阵容整体的资源。合格集 = 未达 2★ ∧ 该级可追(refresh_prob>0)的成员;该级不可追成员剔出本级合格集(continue 过滤,与 R2 的 r2_card_reserve 同款过滤——ρ 与总账同帧同集合口径),跨级追法由 T_up 承载(L* = T_stay/T_up 取小,T_up 在 L+1 级重估同一成员集,「升 7 搜 5 费」跨级追账结构不受影响)。装配承载勘误(ADR-0570):旧文「不可追成员记 inf、不因其余成员可追而豁免;峰级混杂推向更高可齐级」是 inf 污染缺陷的病理记录而非设计——污染实现里可齐级推不出(lv3-6 的 T_up 在 L+1 仍有 5 费档空缺、同被打 inf),刷新臂 3-6 级结构性恒关(g_20260907_021326 实证 P1 全部 9 个刷新评估帧 0 刷店);修正后 inf 仅由「合格集空」承载(P40 R0-1,边界声明见判据函数 docstring;单成员 j/c_taken 低估的保守向申报同处)。

**决策规则(四条)**:

1. **D = ∅(合格集空)→ 不刷**(P40 R0-1 刷新侧特例,
o_chaseable_member);此帧升级只剩人口臂(§2 arm1)可触发。
2. **金两侧不足(T(L*) > g − g*)→ 暂不动、攒**(息线双侧修正,ADR-0516 修正③:停级买牌也压金破息,两侧都过 L/g* 账;买面侧的攒口径 = P56 可变现口径 gold − x + Σ活期退金 ≥ g*)。

### 6.3 P56：买面可变现息线下界（姊妹缺口收口）

**核心构造**：discretionary 买入支出的金位约束不按裸金、不拍 0：

```
gold − x + Σ(活期卡退金) ≥ g*
活期卡 = bench 中 1★ 全额退件（资格谓词与 funding_support_sell 同一：
        star==1 ∧ 零重叠 ∧ 无后台效果 ∧ 非合成素材[ADR-0558 守卫扩展]）
g* = saturation_line(cap_resolved)   （与刷新门同源，零新常数）
```

与刷新门 g*+ρ 同构但**无 ρ 项**（ρ 预留的是刷出命中卡的买入金，买面支出本身就是那笔买入，重复预留 = 同一笔金留两次）。

**可实现性（条件式引理）**：若 T1 语义重写落地且回拉发射位同批补齐——可变现下界被触（买后金 < g*）即发射凑息卖，目标量语义（缺口驱动、Σrefund ≥ 缺口即止）随同批最小实现——则买后任意帧可回拉满息档。**T1 凑息卖语义重写三项**（"解关闸"≠加开关）：①金位触发（缺口驱动，非门开即全卖）；②目标量止盈（Σrefund ≥ 缺口即止，不多卖一张）；③T_SEARCH_A 裸布尔门退役。**零待证锚**：回拉发射位的存在性由 funding_support 的 remaining 递减贪心模式直接承载（任意确定序贪心都能卖够，序只影响效率）——floor 前件的最小实现 = 该模板同构移植；P49 ⑤ 每金序精确小 DP 与 [11] 卖回量最小化降级为效率升级项独立挂账。

**验收定义（单帧锁三断言）**：①发射帧数 = 缺口帧数；②卖回集合 Σrefund ≥ 缺口且不多卖一张；③非缺口帧零发射。三条全过 = "已落地并可对拍"。**T1 前件已落地（dd-032，2026-09-04 验收采纳；单篇 p56-realizable-interest-floor 与 14 锁+对拍在档）——P56 状态随单篇升档（§6.4 同口径）**，下界最紧性论证：更紧违反 [41] 资产形态、更松留敞口，对拍仅作确认性回填。

**连带卖出损失（账务归属）**：凑息卖选择集 ≠ 买面候选集，回拉不必然卖刚买入件。两层入账：发射约束（目标量卖回优先首卖刚买件，满足资格谓词时连带损失=0）+ 判据层残余分量（逐件按 P49 ① (费档,等级) 表计价，不设全局小上界——域内量级跨 1-2 个数量级）。

## 8. 机制突变层（resolved input 原则）（原 03 §4.10 收编）

**原则**：决策机器**禁止直接读基础机制事实**——一切机制输入经「基础值 ∘ 已激活突变」解析后消费（**resolved input**）。突变登记 = 知识层注册表 INVEST_MUTATIONS。

- **登记三分态**：resolved（可解析）/ abandoned（用户裁定放弃建模——desc 无数值一律放弃不实机查，保可见性不进 resolved input）/ 未登记（=知识缺口，采集后入表，不静默忽略）。
- **解析语义结构**：每突变登记为（操作数，合成律[min/max/add/互斥]，状态依赖[计数器/条件]，时效[永久/计数窗/条件移除]）；同操作数多突变按合成律合成；互斥型登记位声明（首个生效，后续 suppressed）；异构操作合成序按操作数分层（override 先于 multiply，层内按注册序）；未登记态运行时检出 = 保守降级（按基础值消费 + 告警，不静默）；消费点读合成后的单一 resolved 值，禁止各机器自选合成方式。
- **多源声明**：突变源不止投资卡——角色固有技能（银狼升费）、任务奖励皆可改状态；INVEST_MUTATIONS 为多源效果突变登记，辖域不限于投资。
- **突变分类框架**（按改写的操作数）：经济参数族 / 收入与息律族 / 概率表族 / 池构成族 / 板面谓词族 / 商店行为族 / 难度与节点族 / comp 定义族 / 任务系统族 / 工具发放族 / 战力族（~155 条——不进经济 resolved，E1 定价走权重/克制通道）/ 资产发放族（~60 条——非金流，E1 定价走组件缺口通道）。
- **池结构突变语境**（消费 P38/P40 时按语境重算）：银狼升费（按当前可见档取 q）/飞光·映月变费/晋升名额/专家解锁入池（v_c 重算）/黑塔纪元（216 张特殊池，P38 全模型降级声明）/昔涟诗篇类非 5 槽商店（SHOP_SLOTS 时变）。**池构成硬突变 ⇒ cw_shop_odds 概率表/V_comp 表/p̄/E[refreshes] 整体重生成，不得沿用突变前表**。
- **E1/E2/E15 选择决策的机制升级**（定价框架；判据状态见 13）：三选一评分 = 台账价值 + 突变价值（对 resolved 输入做差分定价）+ 战力账（→权重/克制通道）+ 资产账（→组件缺口通道）+ 难度账（→环境臂）+ 信号分层（A3）；数值走知识登记与标定批，禁拍值。
