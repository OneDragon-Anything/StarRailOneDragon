## 一、命途属性与技能说明

**命途**：智识（C1 按智识队友数量增益）；**属性**：风

| 技能 | 说明 |
|---|---|
| 普攻 | 单体风伤 |
| 战技 | 弹射35%×5；**场上每1敌本次伤害+20%**（5敌=+100%） |
| 终结技 | **消耗能量140**；【升华】：敌方全体**同时添加全七系弱点**+无法行动（无控制抵抗者）至其回合开始 + AoE 80% |
| 天赋 | 每击中1敌→+1随机弱点（3回合优先未拥有）；≥5不同弱点目标【质性揭露】：对其+18%~32%伤害+普攻/战技后**额外战技（不耗点）** |
| 秘技 | —（以官方文本为准） |

**资源与循环**：140能量→**充能绳价值高**。

## 二、推荐遗器与原因

**套装**：识海迷坠的学者4件 + 出云显世与高天神国2件【攻】
**主词条**：躯干暴击率/暴伤；脚部速度；球风伤；绳**充能**。**副词条**：双暴>攻击>速度>效果命中（升华禁行动对控制抵抗目标无效）。
