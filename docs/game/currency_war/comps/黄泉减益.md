# 黄泉减益(A 级)

> V4.4 合集 76807134:A 级。攻略直读 [76826405](https://www.miyoushe.com/sr/article/76826405)。
> ⚠️ 与 DOT队(卡芙卡持续伤害)不同 —— 黄泉是**巡海游侠 + 减益**主派,独立拆出。
> 代码字段:`COMP_LIBRARY["黄泉减益"]`。

## 机制(怎么 work)
黄泉有**巡海游侠**羁绊,获大量伤害+速度增幅(稀有);**减益**羁绊开 4 减益 → **60% 真伤 + 降低敌方伤害**(兼顾输出+生存)。

- **2 星乱破 + 3 星不死途 → 黄泉获 280% 伤害和速度增幅**(非常夸张)。
- V4.4 加入**刃**,大幅提升黄泉残梦获取效率。

## 成型阵容(9 人口)
黄泉(风暴潮+冷笑话)+ 乱破 + 不死途 + 刃(减益)+ 花火 + 缇宝 + 符玄(3 量子)+ 椒丘(很硬的甲+蓄能帆,补血+残梦)+ 杨叔(上 9 补)。
- 羁绊:**3 游侠 + 4 减益 + 3 量子**(4 游侠/6 减益太占格子收益低)

## 成型节奏
1. **前期**:没找到符玄时生存压力大,先开 **4 减益降敌伤**过渡(输出通常足够)。
2. **7 级后 d 牌**,同时找黄泉 + 不死途。乱破除非来得多,不追 3。
3. 追到/接近 **3 星黄泉 + 不死途**后**上 9**,补符玄 + 杨叔 → 大成。

## 装备
- 黄泉:**火力风暴潮 + 冷笑话引擎**。
- 椒丘:很硬的甲 + 蓄能帆(补劣势血量 + 提供残梦)。

## 弱点
- 游侠体系**看 d 牌运气**:运气差上不去 9 → 不要杨叔,凭 3 星黄泉+不死途苟胜;运气好上 3 星乱破甚至波提欧。
- **单体 boss 黄泉输出乏力**(最终 boss 单体为主时考虑别的阵容)。
