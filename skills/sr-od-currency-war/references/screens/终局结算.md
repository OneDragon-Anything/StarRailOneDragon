# 终局结算（HP 归零或通关的终局结算流）

走完结算回大厅。整链路（旧实测坐标与各页 area 对应）：战斗内终局页「前往结算」→「挑战失败/成功」页点「下一步」（见「战斗结算」卡）→「对局总结」页点「下一页」→「伤害统计」页点「返回货币战争」落回大厅。

### 画面简介

终局结算流第一页（战斗结束后进全局结算的全屏红标题形态，区别于单场战斗结算画面的「挑战结束」标题变体）：红色「挑战结束」大标题 + 死点节点名（帧例「2-1 ✕ 战斗」/「1-3 ✕ 战斗」）+「挑战进度」进度条 + 生命值变动读数（帧例：-22 / 84）。两种子形态：按钮帧（底部「前往结算」按钮）与演出中帧（底部「点击空白加速」提示，点空白跳过演出）。胜利终局画面同构（见对局详情章决策段）。
