# v4.7 隐藏条目调研：丹恒·腾荒（141402）

> 结论：4.7 赛季「入画奇航」重制中，丹恒·腾荒由独立商店员工改为「丹恒·饮月的专属绑定随从」——官方攻略广场 config（role_list）63 条中唯一 `is_hide=True` 条目。证据分级：一级 = config 数据实测；二级 = 1000 篇攻略文章统计；三级 = 旧赛季对照；四级 = wiki/社区。调研时点 = v4.7 赛季初（2026-11）。

## 1. 结论

腾荒的技能与羁绊全部服务于饮月：由羁绊「双龙吟」（id 300102）在后台召唤、星级自动跟随饮月、可穿戴数量随星级提高——不再是独立入池的商店员工。`is_hide=True` 的语义 = **数据保留（攻略文章渲染需要名字/图标）但剔出玩家可见角色列表**。腾荒实机完全可用，不是未放出，也不是残留废数据。

## 2. 证据

### 2.1 一级：config 数据实测（`.debug/game_data/currency_war/plaza/config_v4.7.json`）

1. 63 条 role_list 中唯一 `is_hide=True` = 141402 腾荒（5 费 Back）；其余 62 条全 False。
2. id「141402」全 JSON 仅出现 1 次（role_list 自身条目）；对照饮月「121302」出现 11 次（被商店/概率等多处结构引用）——腾荒不入任何池结构。
3. 腾荒技能「此身为舟」原文点名饮月（「为丹恒·饮月提供自身所穿戴装备的效果」）。
4. 「双龙吟」羁绊双侧挂载（饮月与腾荒的 trait_details 挂同 id 300102）：「【丹恒·饮月】在后台区域召唤星级相同的【丹恒·腾荒】，并复制其穿戴的装备以获得相应效果，可穿戴数量随星级提高」。
