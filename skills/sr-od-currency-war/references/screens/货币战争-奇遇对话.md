# 货币战争-奇遇对话

## 画面简介

节点间插入的奇遇对话画面：奇遇伙伴立卡 + 对话气泡（画面特征：左下伙伴卡 + 对话文本 + 右下箭头），目标 = 推进对话、完成奇遇选择。归档帧（「醒香猫语」局）：左下伙伴立绘与名牌（姬奇猫）、右侧对话气泡、右下蓝色圆形下箭头、底部提示「点击空白处继续」；对话推进到选择步时右侧纵排奇遇选择卡（如咖啡三选一），选中卡右侧出现「确认」按钮。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-对话箭头 | 右下向下箭头（画面身份锚，模板比对；蓝色圆钮内 V 形箭头） | 点它推进对话；点画面空白无效（画面自带提示「点击空白处继续」，实测以点箭头为准） |
| 读区-伙伴卡区 | 左下奇遇伙伴立绘卡（角色名牌，如「姬奇猫」） | 纯显示 |
| 读区-对话文本 | 右侧对话气泡/文本区 | 纯显示 |
| 读区-奇遇卡按钮区 | 奇遇选择卡区（对话推进到选择步时出现）：纵排选项卡（如「螺丝钉咖啡/无名氏咖啡/返回」），卡带标题与效果文 | 点卡片选中（选中卡蓝紫高亮）；奇遇卡片两段式——点卡片选中 → 再点卡上「确认」执行 |
| 按钮-卡上确认 | 选中卡右侧出现的「确认」按钮 | 点确认执行所选（奇遇效果兑现、对话收尾） |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 推进对话 | MCP `click` | 「标识-对话箭头」area 中心（识别返回坐标） | 对话推进 / 出现选择卡 | 点画面空白无效 |
| 选中奇遇卡 | MCP `click` | 卡中心（自己读图定位「读区-奇遇卡按钮区」内的选项） | 选中卡蓝紫高亮 | 两段式：先选中再执行 |
| 执行选择 | MCP `click` | 「按钮-卡上确认」area 中心 | 所选奇遇效果兑现、对话收尾 | 「确认」在选中卡上出现后才可点 |

## 货币战争-备战-奇遇介绍

### 画面简介

备战界面上叠加的本局奇遇介绍浮层：备战开始时弹出，展示本局奇遇的伙伴与效果说明，点空白继续。归档帧：「本局奇遇」标题 + 伙伴气泡（如「杨叔准备好了机械支援计划。」）+ 奇遇效果说明文 + 底部「点击空白处继续」提示；浮层半透明，透出底下备战界面（备战阶段、购买经验等元素可见）。

### 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 读区-奇遇标题 | 标题「本局奇遇」（画面身份锚） | 纯显示 |
| 读区-奇遇气泡 | 伙伴名 + 气泡文本（如「杨叔准备好了机械支援计划。」） | 纯显示 |
| 读区-奇遇说明 | 奇遇效果说明文（如「召唤以150速度行动的贝洛伯格机器人……」） | 纯显示 |
| 提示-点击空白继续 | 底部「点击空白处继续」提示 | 纯显示 |
| 按钮-空白继续 | 空白点击区（与提示对应的大面积可点区） | 点后浮层关闭、进备战 |
