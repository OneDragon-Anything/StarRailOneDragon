## 背景与动机

五局同型失败:意向状态机在**未持有任何对应投资策略/环境**时,仅凭
②层「家族专属羁绊计数 ≥2」就锁定直通终局线(银河学者×2 → 大黑塔
银河学者 r1-r4;夜之半神×2 → 万敌单C r6;列车同行×2 → 列车同行 r7)。
但实证知识(transition_combos.md):学者2 是买 DOT 件的**经济副产品凑数位**
(53 篇逐读,不贡献输出);燃血2/列车2 同为副产品或过渡形态——羁绊
计数是「开局即战力档」证据,不是直通终局线的入场资格。锁直通却无
资格 → 囤货方向指向终局件、板面由凑数位构成 → P1 零伤害引擎 →
boss/战斗罚款吃满。

文档判据(transitions §1 开局分级):拿到逆天投资策略秒选 = 夯;
直通线的资格 = 持有对应投资策略(黑塔纪元 等)。贯穿件到手锁线
(③核心卡,[23])是另一条**合法**路径,与本修复辨明共存。

## 决策

**②层信号加资格门**:family_bond 信号发射前要求
`_direct_line_qualified(state, comp_name)`——资格单一源 = 既有亲和表
**反查派生**(零手写名单):任一持有策略在 `AUGMENT_COMP_AFFINITY`
中指向该 comp,或 `state.active_env` 在 `ENV_COMP_AFFINITY` 中指向
该 comp。无任何表项的 comp(万敌单C/DOT队/黄泉线等)恒无资格——
其终局线只能走③(贯穿件到手)或后续注册的资格项。

行为变化:无资格 + 羁绊副产品计数 → 不发② → 不锁线(意向 unlocked,
囤货落⑤兜底,P1 板面归四体系过渡逻辑);持资格 → ②照发(①同轮
更强,排序结果不变);③贯穿件到手锁线**不变**([23] 保持);①/④/
P3 强制锁线/撤销析取全部不动。

## Considered Options

- **手写直通资格表(comp → 策略名单)**——被否:与
  AUGMENT/ENV_COMP_AFFINITY 双源漂移;反查派生随注册表演进自动传导
  (ADR-0323 同款「派生优于快照」判例)。
- **②信号保留但降权(不删除,靠排序压制)**——被否:无资格时②常是
  当轮最高可用信号(①未持有),降权仍会在无①/③轮锁线;资格不成立
  时信号本身就不该构成锁线证据,不是排序问题。
- **门放 update_intention(_best_signal 处过滤)**——被否:detect_signals
  是纯函数信号源,过滤放信号发射处语义单一(「无资格=信号未发生」),
  与 evicted 过滤同构;放消费端会漏掉未来其它 ②消费点。
- **仅对表内 comp 加门(万敌单C 等表外 comp 保持②可锁)**——被否:
  003757 r6 万敌锁线正是五局病例之一;[23] 语义下终局线锁线证据只有
  资格与贯穿件两种,表外 comp 没有已知资格项 → ②一律不构成锁线依据。
