## 0. 命题一句话

无目标期帧的资金配置判据 = 三臂比较臂组:**甲臂**(方向化囤货)仅当囤货方向 d 通过**当帧候选机器原门逐字**(G > ε:同一谓词 `line_completion_feasibility` + 同一常量 `revoke_miss_tolerance_eps` + 同一 plane 条件语义);**乙臂**(枢纽期权)按枢纽复用网络(注册表派生量)的「非单线依赖」结构判据(覆盖候选线数 ≥ 2)获取;**丙臂**(换现守息)为缺省(辖买卡买面与卖面资格,不辖升级/刷新既有授权通道)——三臂共享 P41① V_opt 定价形态与支配族零成本合取结构;判据成立则单线硬编码方向(含绯英⑤兜底)在该帧域**无判据位,整体退役而非换一个硬编码**。

## 2. 命题本体(三臂判据)

### 2.1 三臂 EV 账总形(记号与聚合口径)

无目标期帧的边际资金(金位与席位)配置,三臂差分账。记号沿 P41(`proofs/p41-hoard-sell-ev.md` 符号表):u = 使用概率、P_miss = 错过概率、C_rescue = 急救金、L = P47 息损递推、V_slot = P41③ 槽价、refund = P76 甲退货表(1★ 全档净 0)。**聚合口径(方案审 F12)**:方向囤货 = 多件采购集,甲臂 EV 账的 refund/L/V_slot 聚合方式(逐卡求和/逐件取格)是方向级账的规范化问题,证明批须显式定义,防与卡级 P41① 形态口径漂移(§7 必答④)。

### 2.2 甲臂(方向化囤货;候选机器原门逐字资格)

```
EV_hoard(d) = u_d·P_miss(d)·C_rescue(d) + refund(d) − L(carry) − V_slot   ……(P41①② 同形)
```

承重项 = u_d(「d 成为最终锁线目标的概率」)。其唯一机制合法来源 = **候选机器自身**。**甲臂资格钉死(方案审 F1,本次修订核心)**:

> 甲臂候选集 = 当帧候选机器门**原样逐字**放行的方向集——位面 2 移交候选门的判据本体(kernel/cw_intention.py:1562-1569)三要素逐字:**同一谓词** `line_completion_feasibility`、**同一常量** `revoke_miss_tolerance_eps`、**同一 plane 条件语义**(`plane != 2 or G > ε`——位面 3+ 绕 G 门是该机器的原语义,位面 3 强锁/降格终局辖域原行为不因本命题改变,防位面 3 帧域失配)。
>
> 机器判死(G≤ε)的方向在机器语义下不会被锁,u_d 无从来源(全库无 revival 复活概率估计器,方案审独立复算确认)——按 01_math_framework §2 公理 1(未标定 fail-closed)构造性出候选集。**这一步不引入任何新数字**:ε 复用机器既有常量,「判死」的门槛就是机器自己的门槛,不存在第二套阈值。
>
> G=0(如绯英恰 G=0.0000)只是该判死的极端举例,**不是定义**——按 G>0 字面放行会复刻病灶同构(囤一个机器自己拒绝锁的线;命题 v1 缺陷,已废)。
>

### 2.3 乙臂(枢纽期权;非单线依赖解耦判据)

```
EV_hub(h) = u_h·P_miss·C_rescue + refund − L − V_slot,
u_h = Σ_l P(l 为终局目标)·1[h ∈ 成员集(l)]
```

**结构覆盖支配(参数化,消掉「选哪条线」的参数)**:枢纽 h 按定义覆盖多条候选线(char_routes 复用网络,cw_comps.py:457-467 派生自 COMP_LIBRARY,core+shared 计入——注册表派生量,游戏定义值域),故 u_h ≥ 其覆盖集内任一单线的 u,**全参数域成立、不需要任何 P 值估计**(方案审独立复算确认,本命题最干净的一步)。与 P76 丙 组合期权结构同源(「max-期权+近零行权费」)——枢纽 = 天然 max-期权,单线囤货 = 单点押注。

**候选形态(方案审 F2,空洞支配漏洞修复)**:命题 v1 所给「覆盖集 ⊇ 甲臂可达候选集」形态**废弃**——甲臂候选集为空(恰是病灶帧形态)时该条件对任意卡恒真(空集是任何集合的子集),乙臂会退化为「任意 1★ 免费期权皆枢纽」,席位被非枢纽件占据,与立意相反。**修订后主候选 = 枢纽判据与甲臂筛解耦**,取「**非单线依赖**」结构补集形态:枢纽资格 = 该卡覆盖候选线数 ≥ 2(二元结构量,注册表派生可算,非调参阈值——覆盖数 = 单线依赖的否定,与 CORE_SINGLE_CARD_REGISTRY 的单卡依赖入选谓词恰为补集形态);甲臂候选集空帧乙臂**照常按自身判据出手**(不随甲臂空集变空——病灶帧正是 D3 要接枢纽期权的帧,出手机会不可丢)。此形态为**证明批必答项**(§7 必答①):若证明批推翻覆盖数口径,须另立解耦形态并说明,禁回退 v1 已废形态。

**接线判据的宪法形态**:EARLY_CORE_POOL 原名单的 plaza 存活率列**不入判据**(00_framework §1.1);名单本体降级回数据先验,维持「勿删」注释语义。**四谓词合取的先例归属(方案审 F10①)**:合取构成先例 = **支配族合取**(P74 §4.4 放行合取 / P75 §5.1 十二原子/C1 锁线腿:1★ 全额退 refund_full_star_ok ∧ 不破息 t5_p1_false ∧ 席位可容 check_seats ∧ 非 C1 名单)——**不是**未锁定恒买规则③的 unlocked 腿(该腿刻意不继承息纪律与星级判据,shop.py:1162-1167 注释「恒买不限星、息纪律不继承」明载,照「规则③同款」理解会错误放宽乙臂合取);谓词**实现**单一源共享(§4.3 清单)是另一回事,两句分开。

### 6.1 误行权面(空窗期核心期权过早行权)
