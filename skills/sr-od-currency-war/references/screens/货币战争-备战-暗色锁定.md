# 货币战争-备战-暗色锁定（策略锁定/遭遇锁定/补给锁定 同族）

**识别**：备战画面带暗色蒙层的子态，命中三者其一：`货币战争-备战-策略锁定`（锚：按钮-返回投资策略选择）/ `货币战争-备战-遭遇锁定`（锚：按钮-返回遭遇选择）/ `货币战争-备战-补给锁定`（锚：按钮-返回补给阶段）。此态下备战常规识别标志（备战阶段等）仍可能命中——**别当正常备战操作**（读数是暗牌/暗金币，不可信）。**画面档建档状态待实机核对**（本卡动作源码挖掘，未经实机走查）。
**目标**：点「返回XX选择」回到对应选择画面。
**能做的事**：
1. 点右上「返回XX选择」按钮（按命中的锁定画面选：策略锁定 = 按钮-返回投资策略选择；遭遇锁定 = 按钮-返回遭遇选择；补给锁定 = 按钮-返回补给阶段）。
**坑**：来源 = 在投资策略/遭遇/补给浮层上点过「返回备战界面」——游戏把备战置成暗色锁定态而非直接可用；不解锁的话备战读数不可信、出战被抑制，先回浮层做完选择。
