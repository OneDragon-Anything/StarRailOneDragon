# 05 买面设计（13 号件塌缩）

> 塌缩来源：`strategy/13_buy_face_design.md`（买面结构设计：P55/P56/P57 立项 + 姊妹缺口逐位裁定 + U_X/T_SEARCH_A 标定计划）。本篇收其**规格与预注册判据**；现状定谳的代码锚（decision/cw4/shop.py、criteria/{buy,sell,stockpile}.py、audit/provisional.py、statefn/{odds,vbar,vopt}.py）作为史实引用不搬正文。
> 兼容硬边界：买面改动不得重新引入刷穿/破息线刷新——一切设计以 R2 息线 floor 语义（刷新通道 reserve = g*+ρ，P54 A4）为硬边界。
> 前置阅读：[01_math_framework.md](01_math_framework.md) §3.1/§6。

## 1. 三问题定义（设计输入）

1. **2★ 副本购置**：现行买入面对任何成员的副本数结构性封顶 1——M2 义务只买「未持有」首副本（owned 名字集合，纵深信息丢失），其余三个 discretionary 买入位（dominance_buy 零重叠谓词 / EV 买面线内排除 / M6 压库 fail-closed）全部买不到线成员副本 ⇒ 2★ 在 bot 自主买入通道内不可达（R2 对拍 2★ 1/30 全部来自卡池赠送【拟，n=30 sim 对拍】）。合成机制面：3×1★→2★ 自动触发，只买首副本 ⇒ 合成事件结构性零触发。
2. **S 预留姊妹缺口**：EV 买面 / M6 压库 / 凑息卖三个消费位的 S 预留均为 P48 零参退化形（s_reserve=0）——「S 线在买面从未接线」，当前被 U_X/T_SEARCH_A fail-closed 完全掩蔽不可观测；开闸前必须先补金位一致性，否则标定即暴露缺口（开闸与预留补位须同批）。
3. **U_X / T_SEARCH_A 标定**：两槽位均为 provisional 注册表缺省 None 的 fail-closed 开关——但性质不同：T_SEARCH_A 实为**开闸决策**（数值链已存在且零新自由参数），U_X 才是**真标定量**（须显式模型 + 数据估计）。

## 2. 规格

### 2.1 P55：2★ 副本购置政策（EV 域，非义务）

**政策三段**：

1. M2 首副本义务保持不变（线成员缺件必买不走息律门；「missing」辖域=首副本）；
2. 新增第 2/3 副本购置判据（EV pass 新候选类，与 ev_buy 并列，不与压库/插件混账）；
3. 购置张数上限 = min(店内张数, 3−已有数)【注，机制直读，merge §2.5「绝不多买」】——散牌零收益（Leontief 同构 P48 A1），判据逐张评估、批量按上限截断；
4. 双通道辖域裁定：M6 对线内成员的发射以 P55 判据为前置（防「金轴已统一、EV 轴复活第二套语义」）。

**命题草案**：

```
买第 n+1 副本 ⇔ V_dup(n) > ρ·(x/Ī) + L(g,x,R,Ī) + ΔW_trunc     （P48 统一式同构）
V_dup(n) = P_complete(n)·ΔV_2★ + (1−P_complete(n))·V_resid(n)
```

- P_complete(n)：剩余视界内凑满第 3 张的概率（statefn/vopt.p_complete 已落码，分母扣已持有数勘误已在位）；
- ΔV_2★：合成兑现的战力跳升 λ_death 纯金流（P51 §F.3 敞口口径，禁边际引用）——**待标定最大项**（combat.md §2 星级收益仅攻略级定性，无采集无建模）；
- V_resid(n)：未兑现残值下界 = P41 V_opt（线内目标件副本满额再遇账 [22]③；P49 ④ 已排除压缩通道，残值只剩期权与槽位）；
- 右端三项 = P48 原样引用（ρ 摊派 / p47 L / P51 底线），三账不同源防双计。

**结构引理（零参数，可先证）**：L1 两段结构（第 2 副本自身零战力收益 ⇒ 判据天然「兑现期望+残值期权」两段，与 P29 同构；无第 3 副本计划的第 2 张只剩 V_resid 通道，归 P41 ③ 槽价分配辖域）；L2 可逆性下界（1★ 副本全额退 ⇒ 净成本有下界，fail 方向安全）；L3 域门（P20 辖域：e≥1 激活后带正是 2★ 成为下一边际的域；P20 为方向级命题——方向级证据作「序」不作「门」，e<1 帧判据照算但让渡优先级）。

**数值落码门**：卡在四项待标定量（ΔV_2★ / V_resid 的 u,H / ρ 摊派 / L 的 Ī 侧），任何一项缺标定都不授权数值判据落码。**依赖序与所有权**：ΔV_2★ 与 u/H 由本篇 §4 采集计划承载；ρ 摊派批与 p47 Ī 侧批在此立批次、owner=编排者排期——任一项挂账后一个对局周期内未立项/未出值，P55 数值面回炉重裁（01 §6 三要素 3 全栈通则）。

**分阶段兑换路径**：阶段 1（零参数可先行）= 结构面全量——M2 不动 + 判据位 fail-closed 候选类（判据恒拒，拒因 'p55_pending'，按开关生命周期申报「行为输入未就绪+开臂判据挂账」）+ 张数上限随判据同批 + 结构引理与 fail 方向安全域；阶段 2（待四项）= 数值判据全式落码。**部分域先行辖域**：只有结构面可先行；右端三项与左端两项任一缺项时，任何混合形态（部分数值判据）都不得落码。

### 2.2 P56：买面可变现息线下界（姊妹缺口收口）

**核心构造**：discretionary 买入支出的金位约束不按裸金、不拍 0：

```
gold − x + Σ(活期卡退金) ≥ g*
活期卡 = bench 中 1★ 全额退件（资格谓词与 funding_support_sell 同一：
        star==1 ∧ 零重叠 ∧ 无后台效果）
g* = saturation_line(cap_resolved)   （与刷新门同源，零新常数）
```

与刷新门 g*+ρ 同构但**无 ρ 项**（ρ 预留的是刷出命中卡的买入金，买面支出本身就是那笔买入，重复预留 = 同一笔金留两次）。

**可实现性（条件式引理）**：若 T1 语义重写落地且回拉发射位同批补齐——可变现下界被触（买后金 < g*）即发射凑息卖，目标量语义（缺口驱动、Σrefund ≥ 缺口即止）随同批最小实现——则买后任意帧可回拉满息档。**T1 凑息卖语义重写三项**（「解关闸」≠加开关）：①金位触发（缺口驱动，非门开即每波全卖）；②目标量止盈（Σrefund ≥ 缺口即止，不多卖一张）；③T_SEARCH_A 裸布尔门退役。**零待证锚**：回拉发射位的存在性由 funding_support 的 remaining 递减贪心模式直接承载（任意确定序贪心都能卖够，序只影响效率）——floor 前件的最小实现 = 该模板同构移植；P49 ⑤ 每金序精确小 DP 与 [11] 卖回量最小化降级为效率升级项独立挂账。

**验收定义（单帧锁三断言）**：①发射帧数 = 缺口帧数；②卖回集合 Σrefund ≥ 缺口且不多卖一张；③非缺口帧零发射。三条全过 = 「已落地并可对拍」。P56 状态维持「待证明」直至前件落地并可对拍；升档以**证明单篇落成**为准（下界最紧性论证：更紧违反 [41] 资产形态、更松留敞口），对拍仅作确认性回填——A/B 判正不构成「已证」。

**连带卖出损失（账务归属）**：凑息卖选择集 ≠ 买面候选集，回拉不必然卖刚买入件。两层入账：发射约束（目标量卖回优先首卖刚买件，满足资格谓词时连带损失=0）+ 判据层残余分量（逐件按 P49 ① (费档,等级) 表计价，不设全局小上界——域内量级跨 1-2 个数量级）。

**逐消费位裁定**：EV 买面与 M6 压库 = 跟 g* 同构（可变现口径；M6 从「可花穿息线到 0」改为「可越线须有活期背书」——行为变更非形式统一）；凑息卖 = 不设预留（卖面只增金，真实缺口 = 卖回目标量语义 + 回拉发射位缺失）；支付支撑 = 义务让渡辖域（不走息律门，[41] 先例）；M3 升级整批 = 单列「M3 S 线接线批」（先裁升级支出的义务/discretionary 定性，不并入 P56/T1 批）。Floor 兼容性：P56 只收编 discretionary 买面金位下界，零触碰刷新门；义务买入破线让渡保留（P54 A3 辖域）。

### 2.3 U_X / T_SEARCH_A 标定计划

- **T_SEARCH_A 短路径（T1，建议优先批）**：窗口消费位的 V̄ 取值改接 P53 帧级现算链 v_bar_net（与 V_GAP 同裁决先例：比较项换帧级现算、槽位数值降为披露），T_SEARCH_A 槽位退役出窗口消费位；空集语义保留给真无窗口帧。
- **P57（窗口门式 V̄ 粒度命题）**：两读法——①单步兑现价值（斜率量级 ~4.9/轮【推，P53】）②帧级视界价值（r=5 特例 = 旧注入 24.7 连续性锚）。裁决 = sim A/B 双臂预注册（§3），**档 2 时序**（证据来源是经验 A/B，A/B 先行于落码且不留开关，非数学可证级）；裁决前门维持现状（合法开关形态）。
- **U_X 真标定批**：量操作化（u_x = 类别 x 的 bench 1★ 件持有期内被消费的比率；H_x = 持有到消费的期望时距；分桶 = 费用档 × 线内/线外）；数据源 = 对局档案 decisions 迹离线派生（零生产改动、零新钩子；sim 局只作机制对照不作标定源——fail-closed 支配下自举偏置）；采集判据 = 每桶事件数 ≥ 预注册下界（CI 半宽 < 判据翻转裕度反推）；验收门 = 分桶表落盘带 CI / 消费位 CI 两端点扫描方向不变 / CI 验收五件套 / sim A/B 预注册判据判正 ⇒ 落码不留开关。
- **替代路径（同批裁定）**：ev_buy 的 U_X 前置门在 free≥2 域可被支配性论证消掉（候选限定后净成本 ≈ V_slot = 0 ⇒ 弱占优）——两条辖域条款为必要前提：①强制合成退金分支（期望损失 E[损失] = P_forced_merge×(手续费 1 金 + V_slot)，P_forced_merge 用 p_complete 同构现算，**辖域声明：现算只辖付费刷通道 ⇒ 是下界，非保守方向，禁止单独消费——须配粗界上界同报，区间使用**）；②bench_free 逐张现检（同波多候选连续买入可打穿到 free=0，阻断义务买入）。待证点 = 两条款落地后候选集无残余不可逆性（对抗审查）；补不上则撤回替代路径，回归 U_X 主路径。

## 3. sim 验证计划（预注册判据，跑前写死）

判据分档：**门** = 硬约束，未达即触发绑定动作（回滚/下钻/零代码留 ADR）；**方向指标** = 只看方向与量级不作臂裁决，超带触发分析义务。无绑定动作的门状判据一律降为方向指标。

- **P55 A/B**（四项待标定量齐备后，n=30 同池同 seed）：门(兼容)=刷新破线波数 0、刷新数/局不劣化——未达回滚整臂不留部分落地；门(开火)=副本买入数/局>0 且合成事件数/局>0——未达=判据/输入死，零代码留 ADR 下钻；门(机制兑现)=2★ 局数>0（对照 1/30 基线）——未达=合成产出仍非买入产出；方向指标=hp 均值（CI 下沿越带触发分析义务）。单帧锁（验证后）=「线内第 2 副本判据不过不买/过且席位空闲买」。
- **P56+T1 合并 A/B**：双读法臂（读法①/②，两臂除 P57 读法外全同，两臂差分即 P57 决胜）各对 floor 基线。门(兼容)=刷新通道 floor 零违例；门(开火)=M6 买入数/局>0、凑息卖发射帧>0、溢余滞留下降；门(方向预言)=全波破息线波数 < 271【拟，floor 批基线】——未达按预注册归因分键顺序（实现层→P57 读法→P56 下界口径）回炉，零代码留 ADR。**遥测分键落码义务**（拒因计数/发射帧覆盖缺口率/窗口集指纹/金位轨迹四字段随批交付，漏落 = 分键静默失效）。P57 决胜 = 绩效显著优者胜，统计不可分时连续性锚（读法②）只作平局裁决。
- **实机侧护栏（非行为开关）**：sim 臂三面 fail-closed ⇒ 测的是「从全关到半开」跃迁，保真度未经验证——实机首 5 局预注册观察锚（金位轨迹回拉达标率/卖出件资格违例=0/再遇率/连续 3 波回拉失效即停用通道回退 funding_support-only）。
