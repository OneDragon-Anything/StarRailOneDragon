# 无名勋礼-购买档位页(nameless_honor_purchase_page)

无名勋礼**真实购买流程的必经页**:主面板点「解锁无名客的荣勋」后落此页(2026-11-12 实机,不直接弹扫码)。左侧版本宣传图轮播(页码 x/17 自动播),右侧两张付费档位价格卡上下排布:**无名客的荣勋 ￥68.00**(立即获得星琼×680)/ **无名客的奖章 ￥128.00**(划线价 ￥146,立即获得星琼×680 + 立即 +10 级)。底部提示「购买以上任一商品,当期版本登录《云·星穹铁道》,可获赠畅玩卡」+ 右下「请适度娱乐,理性消费」。背景为暗化的无名勋礼面板(非全模糊,背景 OCR 仍可读)。不锁光标(`pc_alt=false`)。

与[无名勋礼-购买推广页](无名勋礼-购买推广页.md)(版本周期首进引导页,「开启无名勋礼」按钮)是**不同画面**:本页无「开启」按钮与剩余时间,主面板/引导页 id_mark 在本页均不命中。

## 1. 何时出现 + 出口

- **入口**:[无名勋礼](无名勋礼.md)主面板(奖励 tab)→ 点「按钮-解锁无名客的荣勋」(**已购态主面板按钮仍在,点击仍进本页**,2026-11-12 已购后实证)。
- **出口**:
  - 未购态:点「￥68.00」(荣勋档)→ 扫码支付弹窗(见 §3);
  - 未购态:点「￥128.00」(奖章档)→ 同款扫码弹窗,金额 ¥128(**更高消费档,op 只建模识别永不点击**);
  - **已购荣勋态(2026-11-12 实证)**:荣勋卡按钮变灰「已购买」(area 标识-已购买,与按钮-购买荣勋68 同 rect 互斥文本),奖章卡按钮变「**￥78.00**」(补差价 = 原价 ￥146 − 已付 ￥68;**动态价格,不作锚**)→ 点它弹「商品:**荣勋授章**」￥78 扫码弹窗(同构)——即规则说明补偿条款里的第三种商品「荣勋授章」= 已购荣勋后的奖章升级件;
  - 右上 ×(1855,65)→ 回主面板。

## 2. 识别特征

- **id_mark 单锚**:「文本-无名客的奖章」(pc_rect 1055,798-1210,835,conf 0.999,本页独有文本——主面板双轨是赠礼/荣勋,无奖章)。**为什么不再双锚**:第二锚曾用「按钮-购买荣勋68」(文本 ￥68.00),但已购态该位文本变形为「已购买」、弹窗态被蒙层盖住,双锚在这些 fixture 上必挂——单锚奖章文本在未购/已购两态都可见,弹窗态归独立屏(见 §3)。
- 按钮-购买荣勋68(1270,385-1700,452,文本 ￥68.00,conf 0.95+)= 未购/已购态判据区(已购态读「已购买」,area 标识-已购买同 rect 互斥)。
- 按钮-购买奖章128(1270,785-1700,855,文本 ￥128.00￥146.00)为纯识别区,无点击路径。
- 按钮-关闭X(1835,40-1890,92)纯定位。

## 3. 扫码支付弹窗(独立屏:[无名勋礼-扫码支付弹窗](无名勋礼-扫码支付弹窗.md))

点任一档位按钮后弹出的**白色居中弹窗**(背景暗化不模糊),画面归独立屏「无名勋礼-扫码支付弹窗」建档,id_mark = 标题「扫码支付」+ 渠道 tab「支付宝」。要点:

- **与商店扫码弹窗不同构**(商店版是「其他支付方式」按钮切换,本页是 tab 直切)——勿混用商店屏的渠道 area,且商店屏「按钮-返回支付宝扫码」的 rect 会把本页「支付宝扫码」标注相似命中,误用会误判渠道态。
- **当前渠道判据 = 二维码下方标注,同位互斥**(2026-11-12 实证):支付宝态 =「支付宝扫码」;微信态 =「微信扫码」(点微信支付 tab 切换,标注区 rect 885,730-1035,768)。
- **二维码有时效**:过期态中央出刷新圆钮 +「二维码已过期,点击刷新」文字,点击 (960,625) 重出码(2026-11-12 实证)。
- 支付完成后落「获得物品:星琼×680」通用弹窗(点击空白处关闭)→ 回主面板即已购买态。
- **放弃支付链(2026-11-12 实证,与商店完全同构)**:点弹窗 × → 弹「确认放弃本次支付?」确认框(标题 770,465-1155,515;按钮-确认放弃 725,538-955,605 白底 / 按钮-继续支付 963,538-1195,605 金色——坐标与商店屏建档的三 area 几乎重合,跨屏复用商店 area 即可)→ 点「确认放弃」→ 两层全关回本页。bot 收摊清理路径:点 X → 点「确认放弃」。该确认框为通用同构组件,画面事实由商店 fixture 覆盖,本页不重复归档(fixture 冗余即测试噪声)。
