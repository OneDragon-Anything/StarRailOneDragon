# P97 刷新预算上限(refresh budget ceiling)

> 命题:全连胜收入日程(效率折扣 η)− 目标等级升级开销 − 终局阵容购置成本 = 可自由支配刷新预算;预算 ÷ 刷新基价 = 刷新次数 N。N 是阈值刷新环境(长线利好「付费刷新 30 次后 +20 金、之后刷价 2→1」/二手市场「总刷新 20 次后 +30 金」)的可达性判据与估值输入。
> 动机:此前的达阈值概率参数取历史频率口径(114 局 0/114 命中 30 次付费刷新 → fail-closed → 长线利好估 0),存在**激励适应偏差**——历史频率反映旧打法不刷新,而持有效应本身改变最优打法。本命题改用**预算推导口径**:按打法适配后的收入上限估 N(用户裁定 2026-09-23 方法;口述直觉「连胜收入上限 − 升到 lv10 开销 − 阵容购置 = 刷新预算」的数学化)。

## 3. 推导

逐节点递推(全连胜):`金_{n+1} = 金_n + round(η×(基础_n + 连胜金_n)) + 息(金_n)`;`XP 累计 += 节点经验_n`。升级开销 = (目标等级所需 XP − 白送 XP)⁺ ÷ 4 XP/击 × 4 金/击(白送 XP 按全期入账,不计时序错配——申明:轻微乐观向,量级 ≤ 白送 XP 的时序滞后部分);目标等级 = 该阵容 level_plan 顶格键。预算 = 总收入 − 升级开销 − 阵容购置;N = ⌊预算/2⌋。

## 5. 未入账项与边界(结果 = 保守下限的方向申报)

**未入账收入(用户点名 2026-09-23,三项都使 N 低估)**:
1. **奖励节点额外金**:节点奖励弹窗的非常规发放(战利品折金)未计——只计了基础奖励 5;
2. **补给角色金等价**:补给节点白送角色可按卖出退金/购置成本折金等价,未计;
3. **遭遇奖励金等价**:遭遇分支奖励有金币等价方法,未计。

**在册申报的【拟】与近似**:
- η=0.8:立场折扣系数,实机校准可改(改值重跑脚本即得新表);
- P3 节点结构:文档无位面 3 行,按 8 战斗 + r9 boss 先验;敏感度 = 每个错记节点 ±2 XP(≈±2 金)与 ±1 基础奖励,对结论不敏感;
- 阵容购置只计 core+shared:板面弹性位(对照成型注释,列车同行实际 8-9 人含记忆主/刻律德菈等)不计 → 购置成本**低估 → N 高估**,方向与非保守相反,消费时须知;
- 白送 XP 全期入账:忽略时序错配(轻微乐观);
- 利息按「不花钱」轨迹现算:真实轨迹因升级/购置支出金位更低、息更少 → 收入**高估**,方向在预算上限语义内(本命题即上限口径)。

**与在册命题的关系**:P5(刷新-升级选择定理)在册注记「长线利好语境下半场刷价假设失效,刷新-升级相对账待补」——本命题的 N 与「30 刷后刷价 1 金」联动时,预算还能多买 50% 的刷,本表未计该联动(继续保守)。P39/P40/P48 的刷新/升级判据消费的是局内现值,不消费本命题的局级预算。
