# 货币战争-中断挑战弹窗

## 何时出现

对局中(备战屏)触发「中断挑战」确认 dialog 的两个入口(2026-08-17 实测):

1. **按 ESC**(无面板开着时;bug#2 历史三次实锤的根因入口,本次建档现场复现);
2. **点左上角**(难度图标附近 ~(100,70);用户指路,实测触发)。

真模态:背景压暗、全屏遮罩,点遮罩空白不关闭。

## 状态流转

- 入口:备战屏 ESC / 点左上角 → 本弹窗。
- 出口(实测):
  - **ESC** → 关闭回备战(无副作用);
  - **右上 X** → 关闭回备战(无副作用);
  - **「暂时离开」** → 保存进度离开对局 → 回货币战争-大厅(进度保留,重新进对局可恢复);
  - **「放弃并结算」** → **不可逆**:放弃当前挑战进度进结算(**bot 永不点**,未实测)。
- 点遮罩空白 → 无效(真模态)。

## 识别特征

- id_mark 组合(双锚,lcs 0.9):`标识-中断挑战`(正文首行「是否中断挑战并保存当前进度」,(700,385-1320,440))+ `按钮-放弃并结算`((680,710-860,775))。
- 弹窗帧父屏(货币战争-备战)完全不命中(`screens=[]`,背景压暗 OCR 全灭)→ 天然区分,无需父屏配合。

## automation 要读信息

- `文本-小队生命值`((1390,505-1500,560)):dialog 内 ❤ 数值为**小队 HP 真值快照**(实测 3;同期备战 reader 的 hp=100 是读不到时的兜底毒化值)——可作 HP 校验源(弹窗出现时顺带对账)。
- 其余数据行(当前进度/金币/晋升点)与备战读取重复,不建 area。

## bot 处理策略

bot 运行中遇到本弹窗 = 误触(ESC 误按 / 点到左上角)→ **点「按钮-关闭」回备战继续**(battle_loop 1g 分支;不点「暂时离开」以免中断对局,更不点「放弃并结算」)。
