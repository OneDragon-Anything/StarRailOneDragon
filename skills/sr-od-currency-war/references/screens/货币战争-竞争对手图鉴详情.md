# 货币战争-竞争对手图鉴详情

## 画面简介

单个 BOSS 的图鉴详情页——对战强度预估的结构化数据源：竞争对手图鉴列表点 BOSS 阵营页签进入。内容 = 代表角色（左上代号为阵营名，右侧为 BOSS 本体角色名+等级）、精英/普通敌人构成与阶段技能表；顶部一排圆形头像导航条可屏内切 BOSS，右上返回箭头。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标题-竞争对手图鉴 | 画面标题（身份锚，与「技能」页签组合判；列表帧无「技能」页签，不会撞列表）。本屏标题 OCR 常误读「竞争对图鉴」——识别锚已放宽吸收属预期，别误判画面识别坏了 | 纯显示 |
| 页签-详情 | 右侧页签「详情」：故事文案 + 精英敌人/普通敌人两排 | 点击切到详情视图 |
| 页签-技能 | 右侧页签「技能」（身份锚之一）：阶段一/阶段二子页签 + 技能列表（名+[标签]+描述） | 点击切到技能视图；屏内切 BOSS 后页签重置回「详情」 |
| 阶段一 | 技能视图子页签：阶段一技能列表 | 点击切阶段一 |
| 阶段二 | 技能视图子页签：阶段二技能列表 | 点击切阶段二 |
| 区域-boss名 | 左上 BOSS 代号名（= 阵营名，如「火线动力机甲」） | 纯显示 |
| 区域-boss立绘与等级 | BOSS 代表角色名+立绘+等级（如「『星核猎手』萨姆 等级90」） | 纯显示 |
| 区域-精英敌人 | 精英敌人排（头像+名字+等级 90） | 纯显示 |
| 区域-普通敌人 | 普通敌人排（头像+名字+等级 90） | 纯显示 |
| 区域-顶部头像导航条 | 顶部一排圆形 BOSS 头像导航 | 点击头像切换 BOSS（切后页签重置回「详情」） |
| 按钮-返回 | 右上返回箭头（与数据银行等图鉴族画面同款图标，共用模板） | 点击回 [货币战争-竞争对手图鉴列表](货币战争-竞争对手图鉴列表.md) |
