# 崩铁新手与日常决策（basics 层）

> 按 V4.7 期整理。「会玩崩铁」的日常决策知识——不涉具体角色（角色层查）与特殊玩法（专项 skill 查）。骨架档，随调研轮充实。

## 体力（开拓力）怎么分配

- 每日自然恢复 240（+后备开拓力）；**勿溢出**。
- 优先级参考：当日体力本（花萼金/赤 按当前养成缺口）＞ 饰品提取（定向刷核心 C 的位面）＞ 周本（历战余响，每周 3 次×30，留周日打最高难度）。
- 侵蚀隧洞（遗器本）刷取时机：主力队伍成型后再全投入（前期用散件过渡）。

## 养成优先级（先练谁）

1. 一队主C（毕业向：等级→光锥→行迹→遗器）
2. 一队生存位（保证通关）
3. 一队辅助位（拉条/增伤）
4. 第二队（深渊双队伍刚需）——再往后按当期环境补
- 角色具体练度口径（词条/转化上限/毕业面板）查 `../characters/<角色>.md`。

## 抽卡规划元规则【攻：B站梦轩口径 2026-11】

- **主推角色两个版本后失去环境优待**（与新主推差距拉开）——强度向抽卡按此排折旧预期。
- **有动画短片 = 版本主推**（官方投入信号）。
- **版本主推的核心辅助必复刻**——错过不必强氪。
- 体系成本高、好用的四星少——优先抽「体系核心」而非「数值散件」。
- 星魂/专武优先级：各角色档「星魂档位」与光锥链（多数角色 E1/E2 或专武单选一优先）。

## 日常清单

每日实训 5 项 → 委托派遣 → 体力清空 → 锄大地（免费，可选）→ 无名客荣光（战令）进度。
周常：历战余响 3 次 / 模拟宇宙周奖励 / 深渊三玩法轮换期结算前打满。
