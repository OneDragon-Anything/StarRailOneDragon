# 货币战争-主角光环选择（一、二位面首领战前）

**识别**：`is_precise` 命中 `货币战争-主角光环选择`（标题锚「选择一个角色获得主角光环」）。
**目标**：选光环 + 指定主角。
**触发时机**（两局实测闭环，详见 [references/mechanics/主角光环.md](../mechanics/主角光环.md)）：默认在一、二位面首领战（节点 1-9/2-7）前的备战期出现（备战识别失配 → 本屏精准命中、出战钮变「选择主角」），位面 3 无此环节；1-9 与 2-7 均实测出现——早前「1-9 未出现」的样本 = 玩法任务「入画奇航」教学引入前的旧档（教学引入时序假设验证成立）。
**能做的事**：
1. 从当前帧读出目标角色预览卡位置（预览卡按前排/后排两行排布（实测），位置随部署数变化，无固定槽位）。
2. `CwSelectProtagonist {"aura_side":"left|right","source_x":N,"source_y":N}`——内部三步：点光环卡选中 → 拖角色入中央主角槽 → 确认微距拖拽兜底（静态确认可先试）。**缺陷申报：拖角色入中央主角槽步骤在本机失败×2（帧号已备档申报）——op 修复归开发者侧，当前手动 drag 更可靠**。
3. **手动操作语义（实测，两局闭环）**：**选主角的实际手势 = 拖角色卡入中央主角槽**（画面档已建「中央主角槽」area）；**点角色卡 = 只开详情面板，不是选中**；**光环卡单击选中有效**（两局复现：虚弱猎手光环 × 藿藿，效果：敌人伤害 -28% / 受伤 +28%）。拖主角预览卡的抓取点经验（实测）：抓预览卡**中心** 3 试 2 败，抓**卡右半部**（实测例 (1010,640)）成功——抓点优先卡右半部，失败别在同一位置连试。
4. 光环池随机（普攻精英/战技精英/枪炮收藏家/邀请函 等），内容读图决策；1 金可刷新（左右卡各有刷新按钮）。
**坑**：点角色卡只会开详情、其余静态点击（槽位/适配头像）不产生选择——选中要靠「点光环卡 + 拖角色入中央槽」两个动作（op 拖拽步骤缺陷申报中，手动 drag 预览卡→中央槽可靠）；确认键置灰 = 三样缺一；「返回备战界面」= 放弃本次选择；非适配角色也可放置。
