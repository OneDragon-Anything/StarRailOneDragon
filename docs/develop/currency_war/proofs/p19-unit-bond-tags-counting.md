## 记号与实现模型

设单位 u:自报标签序列 Self(u)(factions+flows+independent,注册表
`cw_chars`,可含重复);装备序 Equips(u)(`bc.equips` 列表,**处理序=列表序**)。
每件装备按类别解析:卡带 → 授予多重集 T(u)(欢愉系/星核猎手系,每件至多
一个羁绊名);星徽 → 授予集 B(u)(每件至多一个羁绊名)。

实现算法(`cw_bond_equips.py:129-140`)按序构造多集 tags:

```
tags ← Self(u);  seen ← set(tags)
for eq in Equips(u):            # 列表序逐件
    for b in tape_grants(eq):   # 卡带:无条件追加
        tags.append(b); seen.add(b)
    for b in badge_grants(eq):  # 星徽:add-if-absent
        if b ∉ seen: seen.add(b); tags.append(b)
```

对羁绊 x,记 c_x(u)=|{t∈tags: t=x}|,s_x(u)=Self 中的 x 计数,
t_x(u)=T(u) 中的 x 件数(卡带件数),β_x(u)=1 if x∈B(u) else 0。

## ① 计数上界命题(已证)

**命题**:对任意单位 u 与羁绊 x:

```
s_x(u) ≤ c_x(u) ≤ s_x(u) + β_x(u) + t_x(u)
```

且全标签数满足 **|tags(u)| ≤ |Self(u)| + |B(u) ∪ supp(T)| + |T(u)|**。

**证明**:卡带分支每执行一次恰追加一个标签(无条件),共 Σ t_x 次 →
下界由卡带/星徽分支只增不减、上界由每羁绊至多 +1(星徽,add-if-absent)
+t_x(卡带)。星徽贡献对每羁绊 x 全程至多一次:首次 x 入 seen 后,后续
星徽分支对 x 恒走 no-op(seen 单调增长)——即使多张星徽同羁绊也计 1。
归纳于装备处理步数即得。∎

推论(单调面):相对旧「星徽也无条件+1」口径,新计数**只降不升**——
与 W49 已证的「computed_vs_ocr 常态化误报 + 星徽局档位系统性低估」修正
方向同向(旧口径在成员穿星徽时虚加=高估)。

## ② 星徽 add-if-absent 的幂等性(部分证伪:序依赖缺口)

**命题(语义目标,docstring 口径)**:星徽只把没有该羁绊的单位变成成员;
装备者已拥有该羁绊(**自报或其他装备已授**)时不重复计数——即「卡带 X +
星徽 X」组合(非自报成员)计 **1**,与两件装备在 Equips(u) 中的次序无关。

**已证部分**(与装备序无关恒成立):

- 成员自报 x + 任意多张星徽 x → 计 s_x = 1(seen 初始化含 x,星徽恒
  no-op)——「同羁绊多星徽计 1」的幂等核成立;
- 卡带在前:卡带追加 x 后 `seen.add(x)`(W362 审查 C1 修复),后续星徽
  x no-op → 计 1。w50 锁 `equips=['欢愉卡带','欢愉星徽']` 覆盖此序。

**证伪部分(残留缺口,实机探针复核)**:星徽在列表序中**先于**卡带时:

```
unit_bond_tags(符玄, equips=['欢愉卡带','欢愉星徽']) → 欢愉 ×1
unit_bond_tags(符玄, equips=['欢愉星徽','欢愉卡带']) → 欢愉 ×2   ← 违语义
```

机制:星徽先处理时 x∉seen → 追加计 1 且 seen={x};随后卡带**无条件**
追加 → 计 2。根因=「成员资格封闭性」只落了半边:`seen.add` 挡住了
「先授后加」(卡带→星徽),挡不住「先加后授」(星徽→卡带)——卡带
分支的无条件性使**计数结果依赖 Equips(u) 的列表序**,而该序来自画面
读取/上游构造,无契约保证。触发面=单单位同时穿同羁绊星徽+卡带且
非该羁绊自报(注册表真实存在:欢愉卡带+欢愉星徽),w50 锁未覆盖
反序组合。**处置挂账(代码批,本批纯文档不动代码)**:修法=卡带分支
追加前不查 seen(保持无条件 +1)但**成员资格判定独立于处理序**——
两遍法:先扫全装备确定卡带授予集 T̄=set(T(u)),星徽的 add-if-absent
改判 `x ∉ seen ∪ T̄`;修后补 w50 反序组合锁(`equips=['欢愉星徽',
'欢愉卡带']` 计 1)。

## ③ 卡带双计的边界(已证)

**命题**:卡带对羁绊 x 的贡献 = t_x(u)(件数),不查 seen、不互相抑制;
但星徽的幂等判定把「卡带已授」视为已有——于是:

| 组合(非自报单位) | 语义目标 | 现实现 |
|---|---|---|
| 单卡带 x | 1(加入) | 1 ✓ |
| 两张不同名卡带同羁绊 x(欢愉卡带+欢愉卡带Max) | 2(可双计) | 2 ✓(w50 锁:银狼自报时 1+2=3) |
| 卡带 x + 星徽 x(卡带在前) | 1 | 1 ✓ |
| 卡带 x + 星徽 x(星徽在前) | 1 | **2 ✗**(§② 缺口) |
| 成员 + 卡带 x | 自报+1 | ✓(无条件) |

「可双计」的边界=**卡带只与卡带双计**;卡带与星徽同羁绊不双计(星徽
不是「计数+1」而是「成员资格」),该边界现实现仅在有处理序条件下成立。

## 检验点

1. **W362 刚修的「卡带 X + 星徽 X = 1」作检验点**:正序已锁(w50
   `tags_combo`);**反序组合是现行 failing 检验点**(§② 探针输出 ×2)
   ——代码批修复后须补 `equips=['欢愉星徽','欢愉卡带']` 计 1 的对称锁,
   并补「成员自报 + 反序组合」计 = s_x+1 的三阶组合。
2. **序不变性检验(修后)**:对任意 equips 排列 π,`unit_bond_tags(u)` 与
   `unit_bond_tags(u with equips=π(equips))` 逐羁绊计数相等——性质测试
   (3 件以内全排列枚举即可)。
3. **上界抽查**:任取单位,每羁绊计数落入 ① 的闭区间;「多星徽同羁绊
   计 1」以两张同羁绊星徽用例锁(w50 现无此用例,可并入修复批)。
4. **三侧传导**:计数语义变更经三侧单一源自动传导
   (`cw_state`/`cw_observation`/`cw_sim_checks`),修复批后三侧全集断言
