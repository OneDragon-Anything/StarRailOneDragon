### 2.2 统一标尺
- 单位 = 分；**1 分 := 1 金等价**（归一化约定，沿 env 批 §2.2；XP 折算沿 `env_economy.XP_GOLD_RATE = 1.0`——用户裁定暂定值，【拍】族登记非游戏定义，对抗 L6）。
- 总分 = 现金分 + 方向分 + 赠卡分 + 立场分 + 转向轴加分（priority 命中 +30，加法软加分；forbid 为集合排除不入式——对抗 M5，与 env 批 §2.2 总分公式同位同构）；argmax 取最高，平分取先（平分裁决键 = §2.8）。
- 集合级排除不进分值（沿 env 批 §2.2「禁选=排除出候选」形态）：用户 forbid、自拆台、血本位三态、定义型分区——见 §2.7。选卡序 = 分区收缩后的组件加法 argmax，替代旧八族 max() 压制。

### 2.7 结构分区（选卡序；全部零拍值）
1. **禁选排除**：`strategy_forbid` 子串命中 → 排除出候选。禁选排除致候选域全空 → 全体候选（含被禁）按组件总分 argmax 最不负分者（用户「有替代永不选」在无替代帧无对象；沿 env 落地件 all-excluded 先例）。**行为差异申报**（对抗 R12-F2——按代码体核非注释转述）：旧机器全禁帧实况 = 冻结槽 0（`best_score` 初始 −1、全禁帧分数恒更低、strict > 恒假），「全体 argmax 最不负分」仅存在于注释/测试 docstring 转述；本批沿 env 先例实现真 argmax——非对称全禁帧 winner 可能与旧代码体不同（旧恒槽 0、新取组件分最不负者），如实申报。
2. **自拆台排除**：板面 持续伤害+减益 ≥2 时，克制 DoT/减益者排除出候选（沿 env 批 §2.8 形态；申报：该谓词对策略卡名近死区，保留为与 env 屏同构的统一规则，旧 −100 罚值退役）。**辖域护栏**（对抗 R7-F5，forbid 与自拆语义分级）：自拆排除仅作用于**非血非禁候选域**，且排除后该域空 → **自拆卡回归**（自拆是策略回避立场非用户意志，不得制造血卡上位——复合场景与旧机器 L1 行为对齐：1 自拆 + 2 血帧选自拆卡、2 禁 + 1 自拆帧选自拆卡；多候选帧克制卡仍被排除，该非等价已入申报 6；L2 血强制帧的血克制卡旧被罚、新无罚，近死区下趋零——对抗 R8-低9 申报 6 并记）。**共用判据抽离**（对抗 F11 修正，宪法六）：转向轴常数与自拆台谓词已是 env/strategy 两画面共用——本批新增共用模块 `mandate_v1/pick_common.py`（转向轴常数 + 板面 DoT 计数阈值 + 克制判定），`invest_env.py` 现役私有副本改薄委托（第二消费者出现 = env 批 §2.11「第二策略出现时提升」预留判据兑现；env 行为零变化、纯重构），`invest_strategy.py` 直接消费共用件。**文档面同构**（对抗 R13-F11，宪法六「跨画面共用判据归判据本体篇」）：13 号稿增补共用判据节（转向轴 + 自拆台语义单一源），28/29 两篇只留指针——landing 3.3 13 号稿条目在册。
3. **血本位三态序**（[40]① 裁定结构，原样迁移）：可入选非血集非空 → 其内竞争；仅非禁血卡可选 → 血卡间竞争；全禁帧 → 全体竞争。判据 = `is_blood_economy`（kernel，注册表派生零名单）。
4. **定义型分区**：竞争域内存在定义型卡（`augment_affinity` 命中，kernel 表——「拿到即改写本局玩法」机制级声明，16 号稿 §1.4 支配性优先序）→ 竞争域收缩为定义型子集；域内多张时按组件总分 argmax（旧 120 常数与并列取首槽行为一并退役）。定义型分区先于血本位或后于血本位在现注册表下无观察差（两集不相交），落地序 = 禁选 → 自拆（辖域护栏，§2.7-2）→ 血本位 → 定义型（血卡永不进定义型竞争域，对抗 R9-F7 补自拆位次）。**支配性优先的等价性申报**（对抗 R19-F1）：旧机器定义型 120 系 max 阶梯单层（可被 S3@N=3=155/优先级加成 149 越过——§1-3②/N≤3 实证在案），新分区制定义型支配为**无条件**——混合帧 winner 翻转属 16 号稿 §1.4 裁定语义的强化兑现（非行为等价承诺，非等价面见申报 6-②）。
5. 组件总分 argmax（现金+方向+赠卡+立场+转向轴加分——总分定义见 §2.2，对抗 R8-中1）。

### 2.9 刷新判据（P81 承接）
- P81 判据结构原样迁入 `invest_strategy.py`，**帧级门与槽级顶级两谓词分立**（对抗 R5-H-1：旧帧级门只查 S1/S2 两类、对齐保护从来只是槽级保护——三元合一入帧级门会让锁线帧 max_N≥2 帧恒不刷、放弃 P81 已证刷法）：

  - **帧级门** = 候选恰 3 ∧ 全精确分类 ∧ 帧内无帧级顶级卡 ∧（锁线帧 max_N≠1）——帧级门形状与旧门同构（S1/S2→定义型/引擎换称；max_N 口径帧态换基已在册申报）；未锁线帧无 N 语义、门只含前三项。
  - **槽级顶级类** = 帧级顶级类 ∨ 对齐保护（锁线帧 **非血** ∧ N≥2 元素命中 / 未锁线帧 S/A 档触线——槽级保护位，与旧 N≥2 槽保护同位含其非血条件；血∧N≥2 今日不可达[两血卡绑定双空，直调在案]，注册表演化致可达时按旧 J7 申报裁：保护无对象 → 不保护——对抗 R6-L-9 随迁）。帧级门过 → 槽级动作集（非槽级顶级可刷；被禁槽恒入动作集；F2 唯一 L1 槽守卫原样）；帧级门失败（帧内有帧级顶级卡 ∨ 锁线帧 max_N=1）→ 整帧不刷，槽级不评。

  1. **env 帧守卫删除**：旧「三选项全命中环境注册表→走 env 判据」的守卫为共享入口 `decide_event` 而设；迁移后 flow 按 kind 分派（§2.10），策略入口只收策略帧，守卫自然消亡。
  2. **N 口径换基**：旧 N = 绑定∩D* 元素基数。新 N 分帧态定义（防保护面膨胀——触线数口径下 68 张触线卡中 36 张（53%）触线≥2[全部 87 张有绑定卡口径 ≈41%]，顶级保护面膨胀显著 = 刷新判据系统性收紧，语义从「方向证据强度」稀释为「绑定广度」；对抗 R6-L-6 分母口径写明）：
     - **锁线帧**：N = 绑定元素（阵营∪角色）命中锁线单线的元素数（与旧 D*① 同构——锁线帧旧口径本就只对锁线计数，语义保真）；max_N≠1 门与 N≥2 顶级保护仅锁线帧生效。
     - **evicted→线排除像定义**（对抗 R26-中-1/R28-F1 空间统一）：evicted 是 comp 名集合——**线排除 = 该阵营线的全体成员 comp ∈ evicted ⇔ 线排除**（整体死亡判据，COMP_LIBRARY 成员表机器可查，宪法二合法）；「基础集 ∩ {锁线}」在策略屏 = 锁线阵营线的成员 comp 并集（阵营族展开的 comp 空间像），**在构造侧求值后以 comp 集传 `line_value_best` 的 locked_comps 参**（共用入口零 get_comp 依赖；env 委托传 {locked_comp}——R27「[faction]」系笔误，对抗 R28-F2）；两者写入 `line_value_best` 签名契约注释（evicted 不入签名，像在候选集构造侧）。**空间声明**：触线集/基础集/locked 集全在 comp 空间（「线」= 阵营线，以成员 comp 集表示）；刷新 N 计数 = 绑定元素空间（不经触线 comp 集，分开命名——对抗 R28-F1）。**线级口径行为差异申报**（对抗 R31-3）：策略屏 evicted 为线级整体排除（未整死的线中已被 evicted 的成员 comp 仍贡献档分——方向分虚高向），与旧 D*② 逐 comp 过滤可观察不同，系有意选择（线死亡才退场、线活则线价值不受成员逐出影响），如实申报非等价。

### 2.12 关键取舍
- **统一加法标尺 vs 保留层次压制**：沿 env 批 §2.11 论证；策略屏新增证据 = 层间常数「编者预裁」自认（§1-3②）与 align×1/评估分纠缠（§1-3①）。
- **组件化估值 vs 保留 PICK_VALUE 定序器**：拍值表的合法性形态问题（env 批 A14）+ 与裁定漂移实证（§1-4）+ 经济结构值在册而无折算入口（§1-7）；保留定序器 = 保留拍值藏审计。
- **共用模块按契约复用而非公式复用**：字段空间不同构（§2.1）；env 批「直接复用」表述按此收窄，避免为凑复用把两类效果硬装一个公式壳。
- **立场表只收非零行 vs env 批全覆盖行**：335 条规模下强制零值行 = 335 行裁决负担，违背「集中一张表可审计」的初衷；覆盖义务改由通道字段分类校验（§2.3）+ 立场表孤儿校验承载。
- **E15 期权/联席帧共用入口**：`decide_invest_strategy` 同时服务固定节点与额外取卡帧（13 号稿 E15「决策机制同 E2」在册），迁移不分叉。
