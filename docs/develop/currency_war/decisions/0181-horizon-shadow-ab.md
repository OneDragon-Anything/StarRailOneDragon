# ADR-0181: HORIZON 影子离线验证规模化(03 号切流门槛:V3 A/B n=200 + 语料影子 diff)

## Status

Accepted(2026-08-17,策略优化会话;切流本身仍按 47 号发布层灰度走)

## Context

消化终态遗留:「三影子开关切流(HORIZON/BUNDLE)待 V3 离线 A/B」。ADR-0168 V3 预演(n=100)
已示方向;本批规模化(n=200/臂)+ 语料影子对拍(切流影响面预估),全离线不碰游戏。

## Decision Drivers

- 切流决策需要统计功效(预演 n=100 的 18% 存活需复核)与影响面预估(live 改动面)
- 用户指令:只离线,不操作游戏

## Considered Options

1. **规模化 A/B + 影子 diff 双件(选)**:sim 内隔离「节奏」变量(两臂买/deploy 同款,
   只有 level/refresh 节奏不同);
2. 直接切流——未经影响面预估的 90%+ 行为变更不可接受;
3. 等实机窗口——离线证据先行不占窗口。

## Decision

`cw_shadow_ab.py`(离线工具)——

- **V3 规模化 A/B(n=200/臂,配对种子族)**:DP 姿态(与 `_horizon_node_goal` 同源映射)
  vs baseline(现状栈骨架):

  | 指标 | baseline | DP 姿态 |
  |---|---|---|
  | 存活率 | 0.0% | **15.5%** |
  | P3 到达 | 0.5% | **73.5%** |
  | 平均位面 | 1.94 | 2.74 |
  | 终局等级 | 4.0 | **7.0** |
  | 终局金 | 80.0 | 67.2(DP 把金转成了等级/存活) |

- **语料影子 diff(2000 回合)**:DP NodeGoal vs 现表 NodeGoal 语义分歧(target_level 差>1
  或 spend_mode 不同)**90.9%**(P1 98.5%/P2 71.4%/P3 100%)——切流是实质节奏变更非微调。

## Consequences

- V3 预演结论复核成立(方向与量级一致,统计功效加倍);
- **诚实边界**:sim 与 DP 共享物理原语(02 号「对 DP 公平」决策)——本 A/B 是 sim-relative
  证据,绝对胜率增益仍需 34 号 A 臂/实机窗口判定(40 号保真度分区将供给「哪里可信」);
- 影子 diff 90.9% = 切流影响面大 → 切流必须走 47 号发布层灰度(ε% 指派+canary),不做位翻;
- 数据质量旗:corus 存在 plane=9 行(23/2000,OCR 误读存疑)→ 记 04 号可观测性矩阵候选;
- 03 号切流离线门槛兑现,剩 V5 实机 canary(挂实机窗口)。
