## 全局共性(跨类的终局规律,持续累积)

0. **局外依赖=入选门槛**(用户裁定 r176 终版):**货币战争阵容对角色
   属性/装备/星魂等有特殊局外要求的 → 不入选我们最终策略库**
   (不是降权,是直接排除)。bot 全试用(局外中等水平,特殊要求零达成)。
   **调研层照记不误**(完整玩法知识+判读需要——理解作者为什么这么打),
   排除只作用于策略入选。
   判别信号(攻略描述):「刚需 X 魂/命」「局外穿 X」「需要本体」
   「无 X 本体重开」——出现即标注 ⚠️局外门槛,策略候选池剔除。
1. **CARRY 装备由伤害驱动决定**(r169):万敌=输出三件(绝对热量/风暴潮/
   热血拳);罗刹三月七=速度件(一鞋一风扇,吃后台强度);姬子=双风暴+电锯
2. **终局羁绊组合不唯一**(r169 万敌篇作者明说):核心 CARRY 固定,
   副羁绊组可替换(群攻3 ↔ 减益2+量子3+盛会2)
3. **多余人口是显式决策点**(r170 #43):四种方案(联动前替代/赌专家/
   双C/后台辅助)
4. **星徽转职跨羁绊上限**(r170 #49):非成员可计入羁绊计数
5. **环境×阵容适配矩阵**(r170 #50):鞋修刃刚需永久创伤环境
6. **引擎位面时效**(r170 #41):仙舟3 只保 P1,P2 乏力——过渡引擎到期要换
7. **领航员可换绑**(r170 #34):三月七→瓦尔特,终局微调粒度
