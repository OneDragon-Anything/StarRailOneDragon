# ADR-0240 冷启动首购方向门(pair_wants 板面空分支)

## Status

accepted(2026-08-22;r368;局49 判读驱动:开局桥期线外全买根因)

## Context

局49(HP 18 失败):r1 供给无仙舟核心,5 金全买 5 张——其中大丽花(盛会之星)/翡翠(公司)是线外件。机制:`_pair_wants` 的 A5 门在板面空时(owned_factions 空,len<3)放行一切阵营 → r1 的 1 费通道把线外杂卡当"凑对"买进 → 金清空+bench 占位+桥后主线零供给,r6 才锁线已迟(HP 46)。凑对语义本身要求「同阵营已有第一块砖」——板面空时该语义不存在,放行是语义漏洞非设计。

## Considered Options

1. 桥期攒息(r1 不买留金):量化后差距主体不在金量(息差 2-3 金)而在**买的对象**(2/5 张线外=纯浪费);且 playstyle 息律是「配方成立后攒息」,冷启动买种子与息律不冲突。
2. **冷启动首购只放行方向件**(选):板面空+bench 空时,`_pair_wants` 只放行 桥名单(fixed∪core)∪引擎阵营——每一张买进来都是方向件(与 _bridge_seed 同名单语义)。
3. 收紧 A5 阵营上限(空板面也限 3):不解决「前 3 张买什么」的问题。

## Decision

选 2。`_pair_wants` 头部加冷启动分支:owned_factions 为空 → 查 BRIDGE_POOL 名单 ∪ ENGINE_FACTIONS(全羁绊判定,同既有方向门口径);非空板面恢复旧凑对语义(同阵营放行/异阵营拒/A5 上限)。锁测试 4 条(桥件放行/引擎件放行/线外拒/非空恢复旧语义)。

## Consequences

- r1 无方向供给时:金留存(无 1 费线外可买)+ 首购全是方向件;hunt3 供给局(局49 形态)首购=椒丘/飞霄等桥件,杂卡不进。
- 局48 形态(开局仙舟核心)不受影响(那些走 _line_wants/_bridge_seed 本就放行)。
- sim 批量(基线 0.007/33.1)待 A/B 重标(该改动在 sim 的冷启动路径生效)。
