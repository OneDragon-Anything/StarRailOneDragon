### 徽章态出现频率(W236 统计,2026-08-27)

- **数据源**:`.log/mcp_server.log`(app 级 logger)「开局 boss 实采完成(位面序保位…)」行的
  三名列表,None=该位面徽章态采不到身份。保位格式(battle_loop.py 990)落地后共 4 局:
  run31=`['不死者联盟','虫人兵器','火花网络传媒']`(0)、run32=`['钢铁意志集团',None,'智识实验室']`
  (位面2)、run33=`['深穹智械科技','冷锋兵器工业',None]`(位面3)、run34(在跑,实采已完成)=
  `['巨鹿生物制药','增熵能源集团','虫人兵器']`(0)。2026-08-26 23:46 run30 行为旧格式
  (battle_loop.py 989,滤 None 时代,None 语义未保位)**不计入**。
- **频率表**:徽章态位面数/局 → 0 档 2/4、1 档 2/4、2 档 0/4、3 档 0/4;按位面序 →
  位面1 0/4、位面2 1/4、位面3 1/4。位面级发生率 2/12≈16.7%(Wilson 95% CI 约 4.7%-44%,
  n 小区间宽)。每局期望漏 ≈0.5 个位面。
- **「局随机」假设证据强度**:开局时机差鉴别子已被 run32 开局位面2 徽章态证伪(进度树
  run 32 观察项);本批 4 局中徽章出现在不同投资策略下(星星相印+采购专员·金 / 利息上调),
  头像态出现在量子力学及 run34——难度恒为标准 A8+财富造物主40(全样本同值,难度维度
  不可检验)。无任何策略-徽章单调关系可见,与「按位面独立随机」一致;但 n=4 不足以
  排除低频策略相关,**证据强度=中等偏弱,维持「局随机」为工作假设**,n≥10 后可复核。
- **skip 分流漏采率与兜底通道判定(W221 挂账候选裁决)**:漏采=位面级 16.7% 的 boss
  身份条目进 `boss_fit` 时被跳过(`cw_comps.boss_fit` 对 None 项跳过、非 None 位面照常
  参与匹配,位面序由保位写保证不错位);每局期望 0.5 位面中性化,50% 的局损失 ≤1 个
  位面的 boss 维度信息。**判定:暂不需要敌人信息浮层兜底通道**——①`countered_by_bosses`
  数据尚未接通,`boss_fit` 现状基本恒中性(cw_comps.py 注释:暂永不命中),漏采真实影响
  ≈0;②即使接通,W_BOSS=0.10 权重下 16.7% 条目缺失对 comp 排序的扰动有限;③兜底通道
  (敌人信息浮层采集)本身有交互成本与误采风险。**重估触发条件**:`countered_by_bosses`/
  `matchup` 数据接通且 sim 显示 boss 维度实际改变 comp 选择时,按届时漏采率重开评估。
