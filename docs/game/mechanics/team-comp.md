## 0. 战斗底盘(配队判断的物理基础)

回合制自动战斗。bot 不手动操作技能,依赖游戏 auto 等结果【项目文档:docs/game/gameplay/combat.md】。配队评估用到的底层量:

| 机制 | 是什么 | 对配队的含义 | 来源 |
|---|---|---|---|
| 行动条/速度 | 按速度转化的行动值排队行动 | 速度=出手次数=伤害与循环的上限;辅助堆速度抢开手 buff【社区共识,未核实】 | 项目文档 combat.md + 官方信使套装效果佐证速度价值 |
| 轮(周期) | 深渊按行动值推进的计时单位,轮数决定星数【社区共识,未核实每轮行动值】 | 配队目标=「在限轮内清场」,输出不足的表现就是超轮 | 社区共识,未核实 |
| 战技点(SP) | 全队共享的技能资源:普攻回 1 点、战技耗 1 点【项目文档 combat.md】 | 队伍要收支平衡:全队都耗点是崩盘配置;有产点位(普攻工具人/产点辅助)才转得动【社区共识,未核实】 | 项目文档+社区共识 |
| 能量/终结技 | 攻击/受击回能,满 100-130+ 放大招(角色各异,官方示例:希儿 120 点)【官方,角色 80 级属性字段】 | 充能绳(能量恢复效率连结绳,官方词条)与回能辅助决定大招频率 | 官方+社区共识 |
| 削韧/击破 | 攻击削减敌人韧性(白发条),归零触发「击破」:打断+控制+击破伤害;技能削韧值随技能标注【官方,行迹 subTag 字段】 | 配队要能打破韧性;超击破流直接吃削韧量做伤害(§4) | 官方 subTag+项目文档 combat.md(weakness break) |
| 弱点属性 | 敌人只吃被标注的 7 属性(物理/火/冰/雷/风/量子/虚数)的有效削韧与增伤【社区共识,未核实细则;属性表为官方】 | 每期深渊公布弱点,配队先对表再谈强度(§6) | 官方(属性)+社区共识 |
| 命途 | 角色职业 8 种:毁灭/巡猎/智识/同谐/虚无/存护/丰饶/记忆【官方,baseType 字段】 | 命途≈职能先验:同谐/虚无=辅助,存护/丰饶=生存,其余偏输出(有大量例外,按角色具体技能为准) | 官方 |

## 1. 队伍位结构(4 人槽位职能)

官方 wiki 每个角色页的「配队推荐」组件就是按职能分列的——遐蝶页列:**主C / 辅助(副C) / 辅助 / 生存**,希儿页同构【官方,配队推荐组件,实测】。通用分工:

| 槽位 | 职能 | 典型命途 | 规划判据 |
|---|---|---|---|
| 主C(输出核心) | 承担主要伤害,围绕它配 buff | 毁灭/巡猎/智识/记忆为主 | 伤害机制是否吃当期内容(对单/对群/削韧) |
| 副C | 补伤害+兼职功能(挂负面/追击/召唤物输出) | 虚无/智识/同谐 | 与主C 的机制是否同频(§4) |
| 辅助 | 增伤/拉条/回能/减防减抗/产点 | 同谐(增益系)/虚无(减益系) | buff 与主C 的伤害机制适配(§6) |
| 生存位 | 治疗(丰饶)/护盾(存护),保队伍存活 | 丰饶/存护 | **生存位很重要:高难内容不带生存位=翻车率高**【社区共识,未核实】;速通竞速才有「双辅助换掉生存位」的高险玩法【社区共识】 |

- 生存位的重要性随内容压力变化:忘却之庭高层与末日幻影的 boss 秒杀/控制压力大,必带;虚构叙事压力小,生存位可以换成第三辅助换清场速度【社区共识,未核实】。
- 常见结构【社区共识,未核实】:主C+双辅助+生存(标准)/ 主C+副C+辅助+生存(机制队)/ 双C+双辅助(爆发接力,无生存,高风险)。

## 2. 三大深渊(逐光捡金系列)机制差异与配队倾向

| 吃什么配队 | 单体爆发、生存冗余、弱点覆盖广度(两队都要能打) | AoE 清场、行动频率、追击与溅射 | 削韧速度、破韧窗口爆发、单体生存 |

## 3. 主流队伍 archetype(按机制,不按角色)

> 分类是社区长期形成的打法体系,机制描述依据各角色官方技能文本(可经 API 逐角色核实);「必备角色类型」指职能,不是特定卡。全部标【社区共识,未核实】+ 代表角色仅为示例(随版本进出环境)。

### 3.1 直伤爆发队(crit burst)
- **机制协同**:主C 吃暴击/攻击/增伤,辅助提供攻击%+暴伤+拉条(行动提前),生存位保底;伤害集中在主C 回合,靠拉条让 C 多动。
- **必备角色类型**:大数字 C + 增伤/拉条辅助 + 产点工具 + 生存位。
- **代表示例**:希儿(量子单C,官方配队组件列 花火/知更鸟/符玄 等)【官方,配队推荐组件】。
- **适合内容**:MoC(对单)、AP(破韧窗口爆发)。对群弱,PF 不占优【社区共识】。

### 3.2 DOT 队(持续伤害)
- **机制协同**:给敌人挂风化/触电/灼烧等持续伤害状态(虚无系),DOT 引爆者把敌方回合结算的伤害提前引爆/增伤;伤害与敌方行动无关,auto 友好。
- **必备角色类型**:DOT 施加者(最好 AoE 挂)+ 引爆/增伤者 + 生存位。
- **代表示例**:卡芙卡/黑天鹅系【社区共识】。
- **适合内容**:PF(杂兵海吃 AoE DOT)优;MoC 可用但吃机制期 buff。项目 CW 研究同样把 DOT 归为「伤害不依赖我方技能时机」的 auto 友好类【项目文档 final_comps README A2】。

### 3.3 追击队(follow-up attack, FUA)
- **机制协同**:全队技能/受击触发「追加攻击」,行动次数→追加次数→伤害正反馈;追击增伤辅助(知更鸟类全场增益)与追击特化 C(飞霄/托帕&账账/真理医生)互相放大。
- **必备角色类型**:追击 C + 追击触发器(副C)+ 全队增益辅助 + 生存位(护盾型能触发受击追击)。
- **适合内容**:通吃型——对单(叠层打 boss)与对群(多目标各自触发)都行,MoC/PF 双修【社区共识】。

### 3.4 超击破队(super break)
- **机制协同**:「超击破伤害」机制让击破特攻词条直接转化为伤害,同谐开拓者(击破辅助)为核心;队伍目标=最快打空敌人韧性,削韧速度=输出。
- **必备角色类型**:击破 C(流萤/乱破/波提欧类,自带削韧/击破特攻)+ 同谐开拓者 + 击破辅助(阮·梅类)+ 击破向生存位(加拉赫/灵砂类,官方技能同带削韧)。
- **适合内容**:AP 优(削韧需求大)、MoC 看弱点覆盖;对韧性条厚的精英强,对免韧机制吃瘪【社区共识】。

### 3.5 量子队(mono-quantum,历史 archetype)
- **机制协同**:全量子队 + 银狼给敌方「植入」量子弱点,无视弱点表硬打;配希儿/符玄/花火/银狼成型。
- **现状**:版本更迭后纯量子队已非主流,但「弱点植入/无视弱点」的机制思路仍是配队评估维度(§6 弱点覆盖)【社区共识,未核实】。

### 3.6 召唤队(记忆/忆灵系)
- **机制协同**:记忆命途角色的忆灵(召唤物)是独立行动单位,吃召唤物增伤与忆灵拉条(星期日类);伤害=本体+忆灵双线,对单能力强。
- **必备角色类型**:忆灵 C(遐蝶/阿格莱雅类)+ 忆灵辅助(星期日/风堇类)+ 生存位。
- **官方佐证**:套装直接为忆灵设计(凯歌祝捷的英豪 4 件:「忆灵在场时…忆灵攻击时装备者和忆灵暴伤+30%」;哀歌覆国的诗人:「该效果同时对装备者的忆灵生效」)【官方,套装效果原文】;遐蝶官方配队列「开拓者·记忆/星期日/缇宝」【官方,配队推荐组件】。
- **适合内容**:MoC/AP 对单强;PF 视 AoE 覆盖【社区共识】。

### 3.7 减益爆发队(黄泉系,直伤的机制变体)
- **机制协同**:虚无角色快速给敌方叠负面状态层数,主C 的技能按负面层数跳档增伤(官方技能文本闭环:负面→标记→大招消耗标记增伤,同类机制已在项目 CW 研究核实过同构案例)【社区共识+项目文档 final_huangquan_debuff.md(机制链写法)】;配「减防/减抗/挂负面」三件套。
- **适合内容**:MoC 优(对单叠层快),需要生存位让虚无队友活着挂负面【社区共识】。

> **archetype 选用判据**(给 agent):先看当期内容的「伤害形状要求」(对单/对群/削韧),再看账号持有的 C 里哪一只的机制形状匹配,最后按 §4 协同点补齐槽位。不要先选角色再硬凑内容。

## 4. 配队评估维度(agent 的 checklist)

给一支候选队伍打分时逐项过:

1. **属性/弱点覆盖**:两队合计是否覆盖当期敌人弱点表;主力 C 的属性是否打在弱点上(影响削韧效率与伤害)【社区共识,未核实;弱点表每期公开】。
2. **buff 收益适配**:本期记忆紊流/怪诞逸闻的条件(多段攻击/击破/DOT…)与 archetype 是否同频;buff 吃满≈白送一档练度【社区共识】。
3. **行动值/速度轴**:辅助速度≥主C(先上 buff 再输出);拉条技能(行动提前)与期次轮数的配合;多动型队伍(追击/忆灵)天然吃行动值经济【社区共识;官方信使 4 件套「全队速度+12%」佐证速度即全队收益】。
4. **SP 经济**:数一遍技能:全队战技点收支能否平衡——至少 1 个产点位(常普攻工具人/产点辅助),禁止双耗点辅助同时转【社区共识,未核实】。
5. **能量循环**:主C 大招能否按预期频率转起来(充能绳/回能辅助/敌方受击回能);大招流的断档=轮数超限【社区共识;官方连结绳主词条含能量恢复效率】。
6. **生存冗余**:治疗+护盾至少其一;高压期(MoC 11-12 层、AP)建议双保险或带免死/解控;控制(禁锢/纠缠类,官方敌方技能文本示例)是否有人能解【社区共识+官方敌方技能字段】。
7. **伤害形状匹配**:对单/对群光谱与内容匹配(§2 表);削韧能力与敌人韧性条厚度匹配【社区共识】。
8. **auto 适配(项目特有)**:队伍是否依赖手动时机(选特定目标拉条/卡轴放技能)?依赖则 auto 下掉发挥,优先选被动结算类(DOT/追击/反震)【项目文档 final_comps README A2 判据外推,社区共识】。

## 5. 配队决策流程(建议的 agent 伪流程)

```
输入:账号(角色/练度/光锥/遗器)+ 当期内容(MoC 或 PF 或 AP 的弱点表+期次 buff+敌人构成)
1. 读当期:弱点属性表 → 期次 buff 条件 → 敌人形状(对单/对群/韧性)
2. 选 archetype:账号 C 中「机制形状 × 弱点属性 × buff 适配」三重匹配分最高者
3. 排槽位:主C 定死 → 按 §4 协同点补辅助(增伤类型要对主C 的伤害机制:
   吃攻击%的配攻击 buff,吃双暴的配暴伤,吃削韧的配击破辅助)
4. 生存位检查:内容压力档(§2 表)决定带/不带、奶/盾
5. 速度轴与 SP 经济过一遍(§4.3/4.4)→ 违和则换位或换人
6. 输出预案:每队给 1 个替补位建议(按账号剩余卡),防止支援/练度缺口
```
【方法论为社区共识的通用打法流程整合,未核实;槽位结构有官方配队组件佐证】

## 6. 与项目自动化的接口注意

- bot 依赖游戏 auto 战斗,配队时**避免**「胜负手在手动操作」的阵容(指定目标拉条/卡轴大招),宁可选机制自动结算的 archetype【项目文档 combat.md(bot 靠 auto)+ final_comps README A2】。
- 深渊进入后锁配置【项目文档 treasures_lightward.md】→ 配队决策必须在进本前完成,bot 无法中途换装。
- 支援角色:挑战画面已建模支援位(借好友角色)【项目文档:docs/game/screens/challenge_mission.md 相关 area】→ 配队规划可把「支援位」当第 5 张卡,通常补主 C 或生存缺口【社区共识,未核实】。
- 配队知识在项目内的既有沉淀:货币战争终局阵容研究(分类/星级饥渴/装备骨架/降级路径等方法论)【项目文档:docs/game/currency_war/research/final_comps/README.md】——其「开局信号/降级路径/资源门槛」的分析框架可平移到深渊配队规划。

## 7. 术语速查(首次出现定义汇总)

- **archetype**:按伤害机制分类的队伍原型(本文 §3),不绑定具体角色。
- **主C/副C/辅助/生存位**:四槽职能(§1)。**拉条**:使目标行动提前的效果。**产点位**:能净回复战技点的角色。
- **MoC/PF/AP**:忘却之庭·混沌回忆/虚构叙事/末日幻影(§2)。**记忆紊流/怪诞逸闻**:MoC/PF 的期次 buff。
- **击破/削韧**:韧性条机制(§0)。**超击破**:击破特攻转伤害的机制流派。
- **追击(FUA)**:追加攻击。**DOT**:持续伤害。**忆灵**:记忆命途召唤物。
- **弱点植入**:给敌人追加弱点属性的效果(量子队核心机制)。
