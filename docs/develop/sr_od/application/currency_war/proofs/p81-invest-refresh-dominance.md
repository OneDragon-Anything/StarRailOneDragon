## 1. 命题

设投资策略屏三选一帧满足帧级触发(候选恰 3 ∧ 全部精确分类 ∧ 无一达 S1/S2 ∧ max_N≠1,分类谓词全量复用既有体系),槽 i 属动作集(非顶级 ∧ 计数 >0 ∧ 非当前唯一 L1 槽)。则:**刷新槽 i 弱占优不刷**(四支结局逐一核对,无确定损失分支,至少一支确定改进),且此结论对计数授予口径(N 次/口径如何)鲁棒。

## 2. 前提(全部已登记裁定或注册表/机制事实,零自由参数)

- **A(免费性,条件前提)**:事件面刷新免费且不消耗选卡权。机制/先例证据:补给刷新「不耗金」、C10 已证伪标记注「免费刷新」、逐卡刷新 UI 无金费显示(归档帧);实机核验 = V2(对账通道判读式)。
- **B(改进存在性,条件前提)**:刷新后新卡有概率 p>0 达 S1/S2。两环:①池内存在性 = 注册表直调(引擎 38 + 定义型 7,五方复现 `335 38 [] 7 [] False 0 0`);②重掷分布 = 发牌分布(机制前提,刷新与首度发牌走同一发牌 UI;实机核验 = V3)。**p 的量级不入判据**(优势论证只消费 p>0,无标定需求)。
- **C(优先序,编码可兑现口径)**:S1(120) > S2(111-119) > S3 对齐 N=2(110) > S4(≤75);N=1(65)可被 S4 顶部逾越——编码事实;N=1 价值地位未决、登记为待办(投资选卡双分支批/16 号稿批),本命题不裁。
- **D(血本位回避)**:存在 L1(非血∧非禁)替代时永不选血卡(声明性偏好)。
- **E(被禁统一规则)**:被禁卡永不被选 → 不参加达档/顶级判定、被禁槽恒入可刷集(P5;被禁∧N≥2 形态现行不可达——两血卡绑定双空恒 N=0,直调在案)。
- **W(welfare 声明)**:S4 内部评估序与 L2/L3 帧域内评估序同为选择机制不承载福利——S4 分值是定序实现常数禁读基数,域内交换不构成可证损失。

## 3. 证明(四支穷举 + L1=∅ 补全)

设槽 i 满足动作集条件,刷新后按新卡分类穷举四支:

1. **新卡达 S1/S2(顶级)**:按 C 严格优于原任一非顶级卡(S1/S2 压过 S3 N≥2 的 110 与 S4 全域)——改进支。子域限定(J1):对齐卡命中 user priority 时(110+30=140),无 priority 新顶级(≤120)不翻转选卡 → 刷新白耗一次计数、选卡结果与不刷相同(免费 → 零损失),弱占优保持;新卡亦命中 priority(150>140)时回到严格优。
2. **新卡为血/禁**:槽 i 已过唯一 L1 守卫(动作集条件),故 i 非「当前唯一 L1」→ 刷后 L1 至多从非空变空。L1 非空:兜底 = 其余 L1 卡 argmax,与不刷的 L1 兜底同域,按 W 可交换;L1=∅(L2/L3 帧):帧级触发可达(血∩引擎=∅、S1∩血=∅ 直调,全禁帧由 forbid 名单构造),兜底 = 域内 argmax(血卡间常规评估序/全禁全序),按 W 与不刷同域可交换——唯一 L1 守卫在该帧恒空转(无槽被保护),不需例外申报。无确定损失。
3. **新卡非顶级非血非禁**:同支 2 域内交换(W);且此时若原卡为血/禁实为支 4。无确定损失。
4. **原卡血/禁**:新卡非血非禁(本支定义)→ 按 D 有替代时回避血卡为声明性改进;原卡为禁时任何非禁新卡至少解除「永不被选」面——改进支(L2 帧此支 = 逃出血强制)。

支 1/4 为改进分支,支 2/3 无确定损失分支 → 刷新弱支配不刷,∎。上界与终止:每卡计数游戏授予封顶(策略屏实证每卡 1),链遇顶级/不可分类即停(边际为零/分类不可靠 fail-closed),动作发出即记录、防重入。

**max_N=1 排除支(帧级门 4 的理由)**:帧内最高对齐档 = 1 时,刷他槽新卡抽到 S4 顶部(66-75)会翻转最终选卡(65 被逾越在编码上是真实位移);N=1 与 S4 抽样的交换按 C 不可比(N=1 价值未决 → 既不能按声明序算确定跌档,也不能按编码算 W 域内交换)→ 二元尺度(存在不可判定交换 → 保守缺省)整帧不刷。max_N≥2 帧的对齐槽保护同理:刷它 = p×跳档 对 (1−p)×确定优先级跌档,双侧无定价不闭合 → 保护不刷;其余槽刷后 fallback 恒等(110 > S4 75 + priority 30 = 105,任何非顶级新卡不翻对齐卡)——**该不等式适用于旧标尺域,新标尺(组件总分基数)下失效,失效面处置见 §7 必答⑥**。

## 7. 换基增补节(投资策略屏迁移批 3.1;design §2.9-3 必答六件)

> 换基动因:评分模型从「多标尺层次压制」换代为「统一加法标尺」(分 = 金等价,组件总分基数域),旧前提 C 的阶梯(S1 120/S2 111-119/S3 45×N+20/S4 ≤75)随 `PICK_VALUE` 表与 S 族代码一并停用——本节在**新标尺**下重演刷新弱占优,并重建门的依据。§1-§6 保留为旧标尺域的原证明(迁移批 3.2 删除面随其失效)。

### 7.0 证明域与换基后判据结构(与 design §2.9 同口径)

- **证明域 = 终局阵容已锁定带 ∪ 终局阵容未锁定带全体,按并集显式陈述**(不称「同形状」):已锁定带 = 「候选恰 3 ∧ 全精确分类 ∧ 无(非被禁)帧级顶级卡 ∧ max_N≠1」的终局阵容已锁定帧族——帧级门适用的帧族,与已登记域中终局阵容已锁定一侧同形状;未锁定带 = 前两条件相同、无 max_N 子句的全体帧——已登记 P81 域的 max_N≠1 门对一切帧生效(含终局阵容未锁定的 signal 帧),新域终局阵容未锁定一侧**严格大于**已登记域(结构变更已登记申报 = design §2.9-2),故全域按并集陈述。
- 帧级顶级类 = 定义型 ∨ 持续通道引擎(S1/S2 同位换称;E-豁免 = 被禁卡不入判定/不计 max_N);槽级顶级类 = 帧级顶级类 ∨ 对齐保护(终局阵容已锁定帧 = 非血 ∧ N≥2 元素命中;终局阵容未锁定帧 = 非血 ∧ 触 S/A 档线);候选价值 = 组件总分域(现金+方向+赠卡+立场+转向轴,分 = 金等价)。
- 结构分区迁移:血本位三态序原样(§2.7-3)+ F2 唯一 L1 守卫承接;forbid 分值化(−10000)改集合排除;定义型 120 常数改分区收缩(支配无条件化)。

### 7.1 必答① 前提 A/B/D 承接申报 + W 换代重述

- **A(免费性)**:承接,条件形态不变——实机实证为登记待办 V2(owner = 首个实机判读批;证伪回退链 = 判据停用回退恒不刷),随新载体继续有效。
- **B(改进存在性)**:承接并复测——①池内存在性 = 注册表直调复现(335 张;引擎 38 + 定义型 7,与 §4 数字表同值,3.1 换基重演复测在案);②重掷分布 = 发牌分布(机制前提),实机核验为登记待办 V3 不变。p 的量级不入判据(优势论证只消费 p>0)。
- **D(血本位回避)**:承接——血本位三态序结构原样迁移(判据 = `is_blood_economy` 注册表派生零名单),F2 唯一 L1 槽守卫原样承接;血∧N≥2 保护无对象(两血卡不在绑定表 = 双空语义,N 恒 0,3.1 复测维持)。
- **W 换代重述**:旧锚 =「S4 分值是定序实现常数,不得读作基数」——基数不存在,域内交换无基数损失可言,故旧 W 直接声明此类交换不在其判定范围内。新标尺分值**是**金等价基数,旧锚失效;换代重述 =「组件总分域内的交换,其福利后果 = 标尺自身语义的输出(总分差即金等价差),刷新判据的占优主张只适用于**结构风险面**——不对总分抽样方差作主张(前提 B 只证 p>0 存在性,分布形状未入册、不得当作概率来源)」。即:新 W 把「域内交换」从『无基数可损失』改写为『有基数、但基数方差属选卡标尺的管辖面,刷新判据不二次裁定』;两代 W 的共同不变量 = 刷新弱占优的确定性内容全部落在结构支(支2/支4)与偏好一致支(支1-定义型),不依赖分布定价。

### 7.2 必答② 前提 C 换基重述与四支重证(真实 N 域)+ is_economy_engine 终裁

**前提 C 换基重述**:旧 C =「S1(120) > S2(111-119) > S3 N=2(110) > S4(≤75)」的定序阶梯。该阶梯在旧域已自证不自洽——**按真实 N 域**重述:N≤3 实证可达(直调 5 对:双人舞×千冶减益/双人舞×DOT队/借力打力×大黑塔银河学者/燃起来了×万敌单C/飞光·传剑×景元仙舟),S3@N=3 = 45×3+20 = 155 越过 S1 = 120,旧「N=2(110) 上界」系低估——阶梯的层间序靠常数相对位置巧合承载,已被实证戳破,这正是换代的动机面。**新 C**(换基后判据结构内重建的优先序):

- 结构层:定义型卡经分区收缩**无条件**支配竞争域(§2.7-4,旧 120 是可被 S3@N=3/加成帧越过的单层 max,新机支配性强化并如实申报 design 申报 6-②);
- 标尺层:非定义型候选按组件总分(金等价基数)argmax,跨族可比——旧 S2 域带/S4 评估分/S3 对齐分不再各有标尺;
- N 的残留角色仅两处:**max_N≠1 帧级门**(必答③)与 **N≥2 槽级对齐保护**(终局阵容已锁定帧),N 不再进任何分值。

**四支重证**(槽 i 属动作集:非槽级顶级 ∧ 非唯一 L1,或被禁槽;设刷前竞争域 winner 总分 T,刷后按同一策略重评 winner 总分 T′):

1. **新卡为定义型(非被禁)**:分区收缩 → 新卡登帧即 winner,T′ = 其组件总分。总分差可为负(低分定义型帧——必答④张力),**不构成可证损失的判据 = 偏好一致性**:定义型支配系 16 号稿 §1.4 已登记裁定语义,选卡域与刷新域承袭同一裁定(同一策略实现内不存在「选卡要定义型支配、刷新又不认」的第二套福利判据);此支为**偏好一致改进支**,非基数改进支——与旧域支1「严格优于」的论证形态换代如实申报。
2. **新卡为引擎(非被禁,非定义型)**:新帧含引擎卡 → 该帧自此属帧级顶级帧(若再评刷新,门拦——防重复刷,非本决策面);选卡面引擎卡非结构支配,按总分进 argmax → T′ = max(存活候选总分, 新卡总分) ≥ 存活候选总分。总分单调不降(相对刷后帧的存活集);相对 T 的方差属 W 声明的范围外事项。无确定结构损失。
3. **新卡为血/禁**:槽 i 已过唯一 L1 守卫 → L1 至多从非空变空。L1 非空:分区令血/禁新卡不入 L1 竞争 → winner 与刷后存活集的 L1 argmax 同域,T′ = T(新卡血)或 T′ ≥ T(新卡禁而原槽禁移除后 live 扩容,仅当原帧 live 因 i 的禁位收窄——i 被禁时原 winner 本就不含 i)。L1 = ∅(L2/L3 帧,可达:血∩引擎=∅、血∩定义型=∅ 直调维持):血新卡留 L2/L3 域内 argmax(按 W 属范围外交换);非血新卡入 L1 → 以总分登 winner(按 W 属范围外交换)。无确定结构损失。
4. **原卡血/禁**:新卡非血非禁(本支定义)→ 按 D 有替代时回避血卡为声明性改进;原卡为禁时任何非禁新卡解除「永不被选」面——**改进支**(L2 帧此支 = 逃出血强制),与旧域同构。

支4 为结构改进支,支1 为偏好一致支,支2/3 无确定结构损失 → 刷新槽 i 在结构风险面弱占优,∎(条件 = A/B 实机实证为登记待办 + 新 C 结构已登记)。

**is_economy_engine 字段闭集划界终裁(必答②显式对账;建议,本批不执行迁位)**:

- **终裁建议 = ②类留驻 kernel**(随 3.2 默认落位自 `cw_events` 迁 `kernel/cw_investments`,不迁策略层)。
- 依据一(宪法五②类判据线):「效果是否含持续通道」的答案由效果原文结构唯一确定——字段闭集逐字段映射 EconomyEffect 已登记的字段语义(注释已登记),「持续 vs 一次性」是对效果文本结构的直读分类,与「某策略卡的发放角色是谁」「某策略卡的稀有度是什么」同判据形态;换一套策略实现,对同一张卡的引擎/一次性判定不会不同(会不同的是**怎么用**这个判定——那是消费位的事,已随判据本体迁策略层)。
- 依据二(同族张力对称对账):闭集的**成员归属**确有 curated 成分(哪些字段算「持续通道」承载归类判断)——与 `STRATEGY_BINDINGS` 的「逐卡按效果含义手建模」同族张力(design §2.1 张力申报在案)。对账结论:STRATEGY_BINDINGS 援 ENV_FACTION 先例留 kernel 的理由(机制事实可 dump 可逐条纠、判据线②类为主)同样适用于本闭集,且本闭集的字段级粒度比逐卡绑定更机械(每字段语义在 EconomyEffect docstring 单一定义);张力以登记注承载,不构成迁位理由。**张力不对称性如实记录**:闭集新字段默认不入闭集 = 静默判「一次性」,治理上劣于绑定表的孤儿校验——伴随义务(3.2 迁位批):闭集补「字段闭集完备校验」(EconomyEffect 全字段必须显式落 引擎单字段/引擎配对/显式排除 三分类之一,与 strategy_economy 字段三分校验同形),使 curated 成分显式暴露可查。
- 依据三(消费方定性):消费方 = P81 刷新判据链(帧级顶级类,策略域)+ op 层观测位(其 `top` 产物在用代码中无消费方,design §2.1 行号订正已登记)。策略域消费不强制策略层归属(STRATEGY_BINDINGS 的消费方 held_strategy_fit/comp 匹配同为策略域而留 kernel)——「值/序会不会随策略实现变」的判据线优先于「谁消费」。

### 7.3 必答③ max_N≠1 门依据重建

旧依据(P81 §3 排除支):N=1(65) 与 S4(≤75) 的交换按旧 C 不可比(N=1 价值未决 + S4 定序)→ 存在不可判定交换 → 保守缺省整帧不刷。**新标尺下该依据消失**:N=1 槽的线价值与重掷期望在组件总分域均有定义分、可比,「不可判定交换」形态不复存在。重建结论分两层:

- **结构性依据**:新标尺下 max_N=1 帧与 max_N=0 帧无结构差(槽级对齐保护定义为 N≥2,max_N≤1 帧内保护位恒空转;四支重证对两帧族逐字同构闭合)——**保留门无占优论证或结构风险依据**。
- **处置建议**:门放开(终局阵容已锁定帧不再判 max_N)无证明障碍;但放开属行为面变更(新增可刷帧域 =「终局阵容已锁定 ∧ 有单元素命中 ∧ 无顶级卡」帧族,行为变化申报义务随之),按行为变更纪律**随 3.2 原子切换一并裁决与申报**,不在 3.1 单独生效。3.1 写入代码维持保守缺省(design §2.9 已登记口径),本节即「未论证前」的论证补全——3.2 未裁前门保持现状。

### 7.4 必答④ 低分顶级帧显式讨论

张力形态(如实陈述):引擎类顶级卡在刷新通道 fail-closed 下现金可塌至个位数——直调实证:开源节流 = 引擎(interest_cap_override 非空入族)而计分现金仅 10(instant 面值;利息 cap 覆写分支待建模、暂按塌 0 计)——却令整帧不刷(帧级门拦)。该张力是新标尺下的真实语义面,重演处置 = **张力有界且自解**:

- 低分的成因 = 已登记的建模待修问题(申报 7 点名:开源节流剩 10 金、利息上调剩 25 金系利息 cap 分支待建模导致的低估),非引擎卡真实价值低;
- 门的保护方向 = 「低估卡不被刷新弃掉」——在 fail-closed 期,门以结构分类(持续通道在场)代偿标尺的系统性低估,保守向(漏刷)与「刷新错会弃掉真顶级卡、不对称风险取严」的已登记纪律同向;
- 自解机制 = 待建模字段落地后总分上升,张力随建模收窄(门判据不变,分值自愈);
- 残余申报:建模式完成前,含低估引擎卡的帧族系统性漏刷,属已知保守面(与 env 屏 fail-closed 帧族同形),实机判读驱动逐条建模后消解。

### 7.5 必答⑤ E-豁免与两谓词分立同构核对

旧实现(`cw_events.decide_event` 刷新判据段)与迁移实现(`invest_strategy._refresh_slots`)逐谓词核对:

| 谓词 | 旧域实现 | 新域实现 | 同构 |
|---|---|---|---|
| 帧级顶级判定 | `any((not forbid) ∧ (s1 ∨ engine))` 被禁不入 | `any((not c.forbidden) ∧ (c.defining ∨ c.engine))` | ✓ |
| max_N 计数 | 非被禁候选 N 取 max,default=0 | `max((c.align_n for c in cands if not c.forbidden), default=0)` | ✓ |
| 槽级动作集 | `forbid ∨ not(s1 ∨ engine ∨ (非血 ∧ N≥2))` | `c.forbidden or not(defining ∨ engine ∨ (非血 ∧ 对齐保护))` | ✓(对齐保护按帧态分位:终局阵容已锁定按 N≥2、未锁定按触 S/A 线) |
| F2 唯一 L1 守卫 | L1 = 非血∧非禁;恰一且在动作集则移除 | 同式 | ✓ |
| 消费序依赖 | 帧级触发(恰3∧全精确)先判、后取分类 | 同序(G8 纪律注释随迁) | ✓ |

差异面(如实申报,非同构破):①旧 env 帧守卫删除(共享入口消亡,flow 按 kind 分派);②旧 LCS 兜底血分类在 all-exact 门下不可达,迁移实现精确-only(单一源,无行为面);③槽级对齐保护中终局阵容未锁定一侧的分支从「signal 帧 N≥2」改「触 S/A 档线」(结构指示,design §2.9-2 已登记变更,在 7.0 终局阵容未锁定带扩张申报内)。E-豁免两处(不入判定/不计 max_N)与「被禁槽恒入动作集」在新实现逐字保留。

### 7.6 必答⑥ 「fallback 恒等」不等式失效面(保护槽让位)

旧域不等式 110 > 105(§3 排除支)保证:对齐保护槽不刷的前提下,其余槽刷新后的任何非顶级新卡(≤75+30)不翻对齐卡 → 保护槽恒为 winner。**新域该保证失效**(基数域无上界锚):开局帧 R=25 口径,非保护槽可刷出现金 115(买断制 15+4×25)> S 线保护槽 100 → 保护槽让位(winner 翻转)。处置:

- **形态定性 = 改进支或中性支,非损失支**:保护槽本体未被刷新,S/A 线卡仍在帧内(保护语义 = 槽级防弃,非 winner 锁定);winner 翻转的标尺语义 = 新卡组件总分 > 保护槽总分,按新 W(标尺自身语义适用于总分差)该翻转是标尺承认的改进,刷新判据不二次裁定;
- **结构面核对**:翻转不产生结构损失——L1 非空保持(新卡非血才可能以高分登 winner;血新卡入不了非血域)、保护槽不删、三态序不动;
- **反向形态**(新卡低分)→ winner 不变,T′ = T,中性;
- **残余申报**:若用户对「S 线在场时应优先对齐卡」有高于总分的偏好,该偏好属立场域(未登记 = 0 分),不构成判据缺陷;立场分表登记即生效(v1 空表,设计立场)。
