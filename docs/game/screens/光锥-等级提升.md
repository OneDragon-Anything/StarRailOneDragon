# 光锥-等级提升(light_cone_ascend)

> source_image: screens/光锥-等级提升/叠影空态.webp(2026-11-10 实机建档,叠影子态;
> 升级/晋阶子态代表帧候补档)

## 何时出现

光锥详情系画面(「强化」/「晋阶」入口进入,标题「光锥详情」)。独立屏,左列
TAB 切换三个子视图:详情 / 升级(满级形态显示「晋阶」)/ 叠影。入口路径:
- 替换列表(光锥-替换)选中件 → 右下「强化」→ 本屏(升级视图)
- 角色-光锥 TAB「强化」→ 本屏(UpgradeLightConeOp 同款入口)

## 状态流转

```
入口(强化按钮) → 升级视图(默认;右下「快速升级」/「使用通用材料补全」/灰禁用)
左列 TAB-叠影 → 叠影视图(消耗材料槽 + 自动置入 + 叠影按钮)
点材料槽 → 候选选择态(顶部同名候选行;右上按钮「收起」变「当前」)
候选点击(锁定件) → 仅预览 + 右侧详情面板(含锁标,可点解锁)
候选点击(已解锁件) → 置入(候选 ⊖ 角标 + 右侧文案「叠影后效果」+ 叠影按钮亮白)
叠影按钮 → 「提示」确认弹窗(消耗光锥稀有度较高,是否继续?) → 确认 → 结果横幅
结果横幅(光锥叠影 叠影X阶➔Y阶) → 点空白关闭 → 回叠影视图(槽清空、下阶段阶数更新)
右上关闭 X → 回来源页(替换列表 / 角色光锥 TAB)
```

弹窗与结果横幅是**全屏模糊覆盖层**(父屏锚全部糊掉,父屏画面级判定失效),
按规范拆两个独立子屏记 area:`光锥-等级提升-提示弹窗`(通用「提示」组件,
无独有锚不设 id_mark;按钮 y 随文案浮动,交互用区域 OCR 定位)/
`光锥-等级提升-叠影结果横幅`(id_mark = 标题「光锥叠影」)。

## 识别特征(2026-11-10 实证)

- id_mark = 「标题-光锥详情」+「按钮-叠影确认」(右下叠影按钮文字)。
  ⚠️ TAB 文字随光锥状态变体:非满级锥中列 TAB 为「升级」,满级/晋阶语境为
  「晋阶」——两 area 同 rect 不同 text,TAB-晋阶不可作 id_mark(低级锥帧必 miss);
  TAB-叠影也不可作 id_mark(候选选择/详情预览态左列 TAB 被候选行顶掉);
  弹窗标题(材料补全/快速刷取)同样不可作 id_mark(弹窗不在时常驻帧不精准)
- 左列 TAB:详情(y≈153)/ 升级或晋阶(y≈245)/ 叠影(y≈341),图标+文字

## 叠影视图(automation 主视图)

- 右侧面板:当前效果(左)/下阶段效果(右)——「下阶段效果」存在 = 可再叠;
  满叠(5 阶)形态未采样,推测无下阶段标签 + 叠影按钮灰(待现场补)
- 消耗材料 4 槽 + 「自动置入」:**自动置入 = 一次填满全部槽 = 一次跳多阶**
  (弹「是否自动解锁以下高稀有度光锥」确认);受控合成用槽点选,
  每槽一件、阶数 +材料阶
- 材料放置机制(锁定件二态):新获光锥默认锁定(候选卡带锁标)。
  锁定件点击 = 仅选中预览(右侧开详情);详情「等级」行右侧锁标点击 = 解锁
  (无二次确认);解锁后再点候选 = 置入(⊖ 角标 + 文案变「叠影后效果」+
  叠影按钮亮白)。点已置入候选的 ⊖ 或再操作可移除(未实测,候现场)
- 叠影按钮 → 「提示」弹窗(「消耗光锥稀有度较低/较高,是否继续?」文案随
  材料稀有度变,按钮 取消/确认;弹窗高度随文案浮动,按钮 y 不定,
  识别用弹窗区域 OCR 定位)→ 结果横幅「光锥叠影 叠影X阶➔Y阶」→
  点空白关闭

## 叠影规则(用户裁定 2026-11-10,实机验证)

合成后叠影数 = 主件阶数 + 各材料阶数(加法);材料经验等级不继承;
跨阶材料可混用(1+1=2 与 2+1=3 双双实机,低阶材料加高阶主件成立);
满 5 阶后行为未实测。

## automation 要读信息

- 「下阶段效果」在否 = 可叠判定;「叠影后效果」在否 = 材料已置入判定
- 结果横幅「光锥叠影」+「叠影X阶➔Y阶」= 合成成功证据(X/Y 阶数可 OCR 回读)
- 被消耗副本会因锁定被游戏强制解锁——解锁是合成的隐式副作用,不是独立决策

## 可交互元素(点后行为)

| 元素 | 行为 |
|---|---|
| 左列 TAB 详情/升级(晋阶)/叠影 | 切换子视图 |
| 右上关闭 X | 回来源页 |
| 升级视图右下 快速升级/使用通用材料补全/快速刷取 | 升级消耗类,见 UpgradeLightConeOp |
| 叠影视图 自动置入 | 填满全部材料槽(含解锁确认弹窗,一次跳多阶) |
| 叠影视图 材料槽 | 进入候选选择态(顶部同名候选行) |
| 候选格(锁定) | 预览 + 详情面板(不置入) |
| 候选格(解锁) | 置入/移除(⊖ 角标) |
| 详情面板 锁标 | 解锁该件(无二次确认) |
| 右上 当前/收起 | 收起候选行/详情面板,回主卡展示 |
| 叠影按钮 | 触发确认弹窗 → 合成 |
| 结果横幅空白 | 关闭横幅 |
