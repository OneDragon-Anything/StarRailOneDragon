# 货币战争-结算

## 画面简介

单场战斗打赢后的结算画面，两种标题形态同一画面：「挑战成功」（普通胜利）或「挑战结束」（例如 1-9 首领战、小队生命值剩 1）。内容布局：中上标题 + 关卡号/「首领」标签，左侧「小队生命值」读数与等级，左下「获得金币总览」面板（基础奖励/利息/连胜/掉落晶矿 各行 + 总数），右下「数据统计」面板（逐角色伤害列表），右上金币存量，底部居中「继续挑战」按钮。目标：领结算信息回备战。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 按钮-继续挑战 | 底部「继续挑战」按钮（画面身份锚之一） | 点击领结算回备战（静态点击有效） |
| 标识-获得金币总览 | 「获得金币总览」面板标题（画面身份锚之二） | 纯显示 |
| 标识-挑战成功 | 「挑战成功」标题；只在胜利态出现（与「标识-挑战结束」同位置互斥，各自只认自己的词） | 纯显示 |
| 标识-挑战结束 | 「挑战结束」标题；只在本轮战败或平局式结束态出现（仍有「继续挑战」，对局未终） | 纯显示 |
| 标识-首领 | 关卡号旁「首领」标签；出现 = 本场是首领战 | 纯显示 |
| 文本-小队生命值 | 「小队生命值 N」读数（例：20 / 1） | 纯显示 |
| 标识-数据统计 | 右侧「数据统计」面板标题 | 纯显示 |
| 文本-数据统计-伤害 | 逐角色伤害数值区（例：396.3万/6.4万/0，试用角色带「试用」标） | 纯显示 |
| 文本-获得金币总数 | 获得金币总览面板的总数读数（例：10/11） | 纯显示 |
| 结算-金币总览面板带 | 金币明细面板带（基础奖励/利息/连胜各行所在） | 纯显示 |
| 结算-利息行 | 「利息」行读数（例：4/5） | 纯显示 |
| 结算-右上金币存量 | 右上角当前金币存量读数（例：60/73） | 纯显示 |
| 掉落晶矿行（无 area） | 获得金币总览面板内「掉落晶矿」行（例：掉落两种晶矿 2 与 5） | 纯显示 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 领结算回备战 | MCP `click_game` | 「按钮-继续挑战」area 中心（识别返回坐标） | 回备战。回到备战有一段动画，动画走完商店自动展开成「货币战争-备战-开商店」 | 动画没走完时点击不生效，这时画面看着还是商店没展开的备战——等动画走完、`analyze_screen` 确认画面后再操作。点出战后战斗自动运行约 60~90 秒，期间画面为「货币战争-战斗」——等结算画面出现再操作；静态点击有效 |

- 读金币明细与逐角色伤害（判断 comp 表现）：「继续挑战」按钮出现后约 1.5 秒，金币明细才显示全，读之前先等。
- 战斗期操作（自动战斗自愈、点空白加速、倍速、暂停浮层）：见「货币战争-战斗」的画面文档。
- 团灭/位面结束结算链：入口在 [货币战争-挑战失败](货币战争-挑战失败.md)。
- 回备战后商店是展开的。拾晶矿要在商店收起时做：先收店，拾晶矿，再开店。
