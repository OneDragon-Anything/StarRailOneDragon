# 千冶•刃（火·虚无·5星）

> 按 V4.7 期撰写。生命模型·免点战技·结界双态的虚无输出/承伤位；与经典刃（风·毁灭）并存独立。

## 一、命途属性与技能说明

**命途**：虚无（B1 计数：有其他虚无队友→全队终结技伤害+75%）
**属性**：火

| 技能 | 说明 |
|---|---|
| 普攻 | 单体50%生命上限火伤+嘲讽；无量忿怒时强化为100% |
| 战技 | 消耗10%生命上限：AoE 72%+4×24% 生命上限火伤；**不消耗战技点**；仅无量忿怒期间可用 |
| 终结技 | 消耗能量；敌方全体【煞火缠身】（**减防30%+受伤50%**，2回合）+ 消耗20%生命进入【无量忿怒】（暴击+20%/暴伤+60%/解放战技/获得新终结技350%生命上限AoE/免死）+ 倒计时70速 |
| 天赋 | 结界期间**我方每次攻击敌方 → 自动挂煞火缠身+千冶•刃+1充能**；充能9 → 回25能量+额外战技（视为追加攻击） |
| 秘技 | 进战嘲讽全体+受伤-90%（2回合） |
| 额外能力 | **B1「万淬心」：结界全队伤害+50%；有其他虚无→全队终结技伤害+75%**（否则自身+75%）；C1 结界嘲讽+受伤-50%+受治疗+50%+受击充能；E1行迹 溢出能量80+回能至75% |

**资源与循环**：标准能量→**充能绳优先级高**（E1 回能循环+充能9回25能是发动机）。

## 二、推荐遗器与原因

**套装**：叩问天工的名冶4件 + 谧宁拾骨地2件【攻：生命模型口径】
- 名冶4：暴伤/生命/伤害——生命模型输出套
- 谧宁2：生命+12%+暴伤

**主词条**：躯干暴击率/暴伤；脚部速度/生命%；球火伤/生命%；绳**充能**。
**副词条**：生命% > 双暴 > 速度 > 充能。
**转模与转化上限**：无属性转模；无量忿怒自带暴击+20%/暴伤+60%（词条压力降低）。
