## 2. 补强通道接线重估（P26/P40）

### 2.1 原登记待办理由

1. **P26 数值授权待办（主因）**：P26 v2 = 位面 1 硬节点备战支出 EV 门，EV = Δp_prep·G_loss + Δstreak·S_streak − C − I；**Δp_prep 条件表 + L_node 分位口径两项待办均未采**，G_loss = λ_death 销毁敞口（P51 §F.3/P48 同源）未回填——索引明载「λ_death 回填前仅结构背书不作数值授权」。史实：P26_VALIDATION 曾判其量纲断裂（血量直入金账），v2 重推已按纯金流闭合修复，故**待办性质 = 数值授权待办，非结构缺陷待办**。
2. **P40 备战语境无特批位**：P40 刷新门对硬节点语境只有变体③「节点语境 = 参数替换，骨架不分叉」；`01_math_framework.md` §7 待证钩子表对 P26 的默认行为明文 = 「备战支出走常规门，不加码不特批」。
3. **hp 使用边界**：`01_math_framework.md` 公理 3 + `00_framework.md` §3——策略判据禁读 hp（hp 是对局结果不是策略决策输入）；硬节点「更难 ⇒ 需更强」属节点类型前置的阵容管理（[39]，玩法立场登记条目：按节点类型前置管理阵容），禁以 hp 直读触发补强。

### 2.3 结论一：独立补强发出分支不接线；受限陈述 + P26 适用范围收缩重挂

1. **受限陈述（r1 阻断-2 降格，全集断言作废）**：在**现行有规格的支出面**（常规买入/升级/刷新/垫件/补强五通道，§2.2 表前五行）内，「硬节点备战特批」没有剩余的合法动作对象。**不称全集**——事件面为已知破口（§2.2 末行），`17_stall_form_spend_authority.md` §1.3 同源盘点原文「不称全集」对本篇有约束力。在受限域内，接线 = 制造双源加码，违 `01_math_framework.md` §7 与零调参门；D-D ①② 维持「结构门 + 观察级」现态**判定正确**。经对抗审查未被推翻（r1 清单第 5 条）确认：「不接线」核心方向在此降格形态下仍立。
2. **P26/P51 与出口①的合流 = 候选项申报，非本篇预设（r1 应修-6 + 存疑-1 裁决）**：`17_stall_form_spend_authority.md` §2.1 出口①（Φ_stall 帧升级登记待办）未解缺口①「完成提前量折金」的合法化路线二原文标签为「P26 族 λ 纯金流」。**这条路线算的是：升级后死亡风险下降所保住的钱（升级前后死亡率差 × 手上现金与未来收入），与 P12 号命题同一算法；P26 原公式没有死亡率变化项，两者不属同一族**（本批直调 proofs 索引溯源：折金形态 `Δλ_death(战力桶跃迁)×(存量金 g + 未来纯金流 Φ)` 与 math_proofs P12 行「P2 找件收益 λ_death 纯金流重述」逐字同构；P26 形态 `Δp_prep·G_loss + Δstreak − C − I` 无跨格 λ 差分项，G_loss 只是 λ 敞口的同源口径引用）。**族归属改挂 P12 v2**，两套前置随之分立：P12 v2 硬前置 = 结算屏三项 OCR 进遥测（幅度授权禁，方向级现行）＋ λ 表可消费格；P26 三项（Δp_prep/L_node/λ_death 回填）适用于 P26 本体（备战 EV 门）重推，**与本合流形态解耦**。`17_stall_form_spend_authority.md` 的「P26 族」标签**登记为遗留待办**（§5-①，由该稿 owner 批修正，本批不擅改既有篇目）。（升级触发统一批注记:出口①登记待办已关闭〔`17_stall_form_spend_authority.md` §2.1〕,本候选项与未解缺口①草案的裁决场随迁一般命题批队列;折金形态读数指针不变,归档面见该稿关闭声明。）
3. **接线判据（未来若接线；零新自由参数）**：
   - **形态与卡点归属由出口①命题批裁决**（应修-6）：本篇不预设语境键是否入出口①谓词形——HARD_NODE_TYPES 若入形即改变 `17_stall_form_spend_authority.md` 候选授权形态谓词（其 §2.1 谓词无节点维），属该稿不存在的新设计；不入形则语境触发面在合流命题内零消费处。两态均合法，裁决权 = 出口①命题批；本篇只申报候选项与各自前置。
   - **前置（按族归属改挂后）**：① P12 v2 硬前置 = 结算屏三项 OCR 进遥测（已登记待办）；② λ 表 v3.3 可消费格（启动时必然加载，38/48 非空格带置信区间——数据**在案**，非缺位）；③ **跨格差分算子缺口（r1 存疑-3 新登记实现前置）**：现行 `ExposureComposite` 运算白名单仅加法与比较（减法/乘法/除法类型不可达），现存差分算子的合法性依据在「同格平移抵消」（原对抗审查条目 R29-3）；出口①的 Δλ_death 是**跨格差**（升级前后战力桶跃迁，键变），平移抵消论证不适用——需新算子或白名单扩条，其合法形态审批是「零新自由参数」声明之外的一**道独立门**，实现前置在案。
   - **消费形式硬约束三条不变**（P51 验证结论/P26 v2 口径）：区间敞口比较、禁边际引用；L_node（若消费）只适用于触发面水位比较、不入金账；hp 不入任何账与自变量。
   - 谓词面：HARD_NODE_TYPES 节点查表键已存在（零新参数）；**禁止**把「硬节点」升格为任何门的放宽项——它只允许作为命题触发面语境键（且是否入形由出口①命题批定，见上）。
4. **观察级计数位保留，但撤 P26 标定前置资格（r1 应修-1）**：计数位在 `decide_shop_action` 决策链尾部，任何更早分支发出动作（刷新/卖出/买卡）即 return 该帧不入计数；另有契约闸删失（abstain 恒不计数）。实际语义 = 「穷尽全部其他动作后仍持金远超利息线收尾的硬节点帧」的**条件分布**，含双重选择偏倚——凡中途刷了或买了的帧都不计，而那些恰是最该观察的帧，故此计数有系统偏差，只能当参考。处置：①保留计数（与 `14_p1_consume_arms.md` §10 附注一致，零行为差合规）；②语义如实改申报为**尾部帧条件分布**，禁作无条件可达性分布使用；③**撤**其「P26 标定前置样本面」资格——Δp_prep 条件表/L_node 分位口径实采若需备战帧无条件采样，须另立采集点（如 visit 入口逐帧采样），非本计数位；④代码注释自称「逐帧计数」与实现不符，登记为遗留待办（§5-①，禁本批改 src）。

## 3. P51 生存折现消费位重立

### 3.1 定义与原位（r1 阻断-1/应修-2 更正后）

生存折现 = P51 等待代价引理的两通道：W_flow（小项，0-0.5 金/轮）与 **W_floor = λ_death（按 λ 查表键取值，剩余轮数近似视界）×（存量金 g + 未来基础收入/利息流 Φ）− 当轮利息**。原位共四个消费位，**as-built 三层态分列**（一刀切表述作废）：

| 原消费位 | as-built 层 | 现态 |
|---|---|---|
| P48 统一囤钱判据 `ΔW_trunc(a)` 项 | **设计面并入**（全 src 无 W_trunc/W_floor 判据消费位，仅 statefn 层私有算子与 docstring）——「已实现消费」不成立 | 设计并入、代码无消费位 |

## 6. 两件结论（各三行；v2 修订版）

**结论一（补强通道接线）**：在现行有规格的五支出面（常规买入/升级/刷新/垫件/补强）内，原待办理由（P26 数值三项未采 + 刷新判据同判无特批位 + hp 使用边界）仍成立，独立补强动作发出分支无剩余合法动作对象——D-D 维持「结构门 + 观察级计数」现态正确，不接线；**受限声明**：事件面（金→战力花金选项，无规格）是已知破口，事件面规格批生效时触发面强制重核。
P26/P51 与出口①的折金合流降为**候选项申报**：这条路线算的是升级后死亡风险下降所保住的钱（升级前后死亡率差 × 手上现金与未来收入），归属 P12 v2 一族（Δλ_death 战力桶跃迁 ×(g+Φ)），前置 = P12 硬前置（结算屏 OCR 遥测）+ λ 表可消费格 + 跨格差分算子缺口（新登记实现前置）；是否入出口①谓词形由该命题批裁决。
接线形式硬约束三条不变（区间敞口禁边际引用/L_node 只适用于触发面水位/hp 不入账）；观察级计数保留但撤 P26 标定前置资格（双重删失，尾部帧条件分布语义）。

**结论二（P51 生存折现消费位重立）**：生存折现未被取代而是被拆分并入，as-built 三层态 = P48 设计并入（无代码消费位）/ P41 缺省登记待办 / P39 已停用（现行 floor_eff 零 λ，原「唯一实现先例」表述作废）——独立消费位现态无实现消费位，待办是纪律选择非数据缺位（按位面分层的死亡率表 v3.3 启动时必然加载）。
剩余适用范围（hp 判据族删除后重排）：`17_stall_form_spend_authority.md` 出口①折金候选（未立项，族归属 P12 v2）＞ P41 V_power 接管（已登记缺省）。
重立形式 = 二值投影版先行，但以**停用对账声明**换发：不作段路由不作闸门、只作命题内方向判、消费形态 = 区间敞口比较；λ>0/λ≈0 分界写死到表 label 四态（可消费∧ci_lo>0 ⇒ λ>0 支 / 仅方向 ⇒ 方向注记 / 空格·禁用·不可得 ⇒ 数据缺失走保守兜底、不判）；先例收缩至 P52 D_ε 单件，P39 floor_eff 禁引。
