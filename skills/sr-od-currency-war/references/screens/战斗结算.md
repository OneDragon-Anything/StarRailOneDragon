# 战斗结算（挑战成功 / 挑战结束）

**识别**：结算画面（挑战成功/挑战结束 + 继续挑战按钮；含金币明细 基础/利息/连胜 与掉落晶矿、逐角色伤害统计）。
**目标**：领结算信息回备战。
**能做的事**：
1. 点「继续挑战」（约 960,895，静态点击有效）。
2. 读金币明细与逐角色伤害（判断 comp 表现）。
3. 自动战斗自愈：战斗进行中画面右下「我方行动中」待操作帧连续约 5 秒（两个识别标志同帧命中：标识-我方行动待操作 + 标识-回复技能）→ 点右上「按钮-自动战斗开关」开启自动战斗——战斗停在我方回合等操作时的自愈动作（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
4. 点空白加速：结算动画帧/战斗过场屏（总伤害/数据统计页）点空白（约 1505,950，避开中央内容）推进或关叠层（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
5. 团灭/位面结束结算链：OCR 找「前往结算 / 下一页 / 下一步 / 返回货币战争」逐页点进（找到哪个点哪个）；「返回货币战争」落回大厅 = 终局出口，之后按「终局结算」卡口径收尾（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
**坑**：点出战后战斗自动运行约 60~90 秒，期间截屏只会看到战斗画面（不是任何已建档画面，识别全空）——等结算画面出现再操作；回备战后先收晶矿再开店。
