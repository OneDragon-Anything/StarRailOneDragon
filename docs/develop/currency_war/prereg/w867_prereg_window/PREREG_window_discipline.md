## §1 适用范围与角色

- **适用对象**:以 sim 批量(100 局种子连续段)为单位的跨窗指标观测——幸存者均值、hp mean、幸存率、死时带金、battle_losses_le_2、锁线 comp 集中度(列车份额)等进入窗计数表的指标。
- **不适用**:单窗内部判读(对局档案复盘、病灶级单局画像)、实机单局判读——各有自己的协议。
- **执行者**:每窗判读批(worker)按 §4 协议逐条执行;**裁决权与触发处置记录权在编排者**,worker 只产出量化读数与本文件条款的机械对照,不做定性裁量。
- **术语**:「带沿」=锚带(历史窗区间)上/下沿;「越带量」=窗口径值对带沿的有向距离(下越为负、上越为正);σ_win 见 §2。

## §2 σ_win 定案(噪声带估计器)

### 2.1 估计器(定案)

- **主估计器:σ_win = 1.4826 × MAD**(中位数绝对偏差 × 正态一致性常数)。滚动窗口 = 最近 8 个窗的该指标实测值;每窗判读时先把本窗值追加进序列再计算。
- **备选估计器(必须并列报告,不参与触发)**:去极值均值 sd(序列去 max、去 min 后的样本标准差)。
- **选 MAD 为主的理由**(推导,非偏好):校准期 6 窗幸存均值序列含单离群窗(16.9),含离群 sd=4.14 vs 去低洼窗 sd=2.19 差近一倍(W860 角度三)——普通 sd 被单个离群窗主导,拿它定噪声带等于让一个窗背书后续所有豁免。MAD 拆分点(breakdown point)=50%,单个离群窗无论多大都不影响中位数与 MAD;1.4826 为正态假设下 MAD→σ 的无偏常数。代价:n 小时 MAD 效率低于 sd,故备选估计器并列报告供审计,但**触发只认主估计器**——禁「哪个估计器支持我的结论用哪个」的选择性引用。
- **校准期实测(附录 A)**:幸存均值 σ_win(MAD)=1.19(备选 0.67);列车锁线 σ_win(MAD)=7.41(备选 4.11)。

### 2.2 最小窗数(定案)

- **最小窗数 = 8**。序列不足 8 窗时,该指标处于**「数据积累期」**:σ_win 只计算、只记录,**不触发任何条款**(§3/§4 的触发规则不生效),窗计数表照常记值并标注「数据积累期 N/8」。
- 理由:n=6 时 MAD 基于中位数的半样本,抽样波动大(校准期幸存均值 MAD=0.80,仅由 4 个中间值的 2 个决定);8 窗使 MAD 至少锚定 5 个窗的偏差信息。8 不是统计最优,是「估计可用性」与「防 n=6 单点背书(W860 自批的病)」之间的保守折中。
- **当前状态:v1.0 冻结时刻序列为 6 窗(W827/W832/W838/W841/W844/W858)→ 幸存均值与列车锁线均处数据积累期,再积累 2 窗后方触发**。附录 A 的回算全部标注「校准演示,不构成触发」。

### 2.3 阈值映射(定案)与推导依据

| 规则 | 触发条件 | 阈值 |
|---|---|---|
| R1 两窗规则 | **连续两窗**(同向)两窗均值越「带沿 ± 1·σ_win」 | 1.0·σ_win |
| R2 单窗规则 | 单窗越「带沿 ± 2.5·σ_win」 | 2.5·σ_win |

**推导依据(禁后续无修订地改数)**:

- R1 的判据统计量是两窗均值对带沿的超出。纯噪声下两窗均值的 sd = σ_win/√2 ≈ 0.71·σ_win(方差可加:Var(mean of 2)=σ²/2)。取阈值 1.0·σ_win 等效于均值 z = √2 ≈ 1.41,正态两侧 p≈0.16——**这是有意宽松的选点**:窗观测是持续进行的,规则的本职是「很少触发、触发必有戏」;旧规则(带沿裸值,不含 σ)在 σ_win≈4-5 下经常误触、每次靠事后豁免消化(W860 统计近 6 窗 3 次误触),正是本文件要治的病。初值宁松勿紧,窗数 ≥8 后可用实测两窗均值分布的 90 分位替换(替换走 §6)。
- R2 处理单窗极值。正态近似下单窗 |z|>2.5 两侧 p≈0.0124;在 8 窗滚动观测下族错误率 ≈ 1−(1−0.0124)^8 ≈ 9.4%。对照:若取 2.0·σ(W860 草案值),单窗 p≈0.046、族错误率 ≈31%——规则会频繁空响,重演「常触发→常豁免」;故 v1.0 定 2.5 而非 2。R2(2.5σ)与 R1(1σ)的倍差体现证据强度差:单窗证据弱、需保守放大;两窗同向重复证据强、可放宽。
- 两条规则共用正态近似这一假设。**已知边界**:窗级指标分布未必正态(幸存均值右偏、列车份额有界);窗数 ≥8 后应顺手记录分布形态(偏度/极值比),若系统性偏态显著,阈值映射整体进 §6 修订评估——但修订前,正态近似下的冻结值仍然有效。

## §3 锚带再校准裁决序(定案)

σ_win 量化的是窗间波动;若「带」本身错(混入旧代码纪元的波次、或策略/代码相对旧时代有系统性水平移动),则越带标签会高频产生、持续稀释审计信号。因此**任何系统性越带证据,先走分支 A,不准直接跳分支 B**:

- **分支 A(零成本,先做):锚带分段重估**。按代码基线纪元给历史窗分段(当前已知纪元:W803 标定前 / W803 权重标定后 / W834 接线后 / W852 w_act=1.0 标定后,纪元边界以 commit 为准记录),仅用当前纪元的窗重估带沿。分段后当前窗若回带内 → 关案,结论记「锚带混入旧纪元,带已重估(修订记录进 §6)」。
- **分支 B(升级,仅当 A 后仍系统性越带)**:重放链逐 commit 定位——对越带窗按 §4 重放纪律在相邻纪元边界 commit 上做同窗重放,逐 commit 二分行为变化引入点。**明示限制**:离线期(游戏/批量环境不可跑)分支 B 不可执行,此时挂账「分支 B 待环境可跑」,不得用分支 A 的分段重估结果冒充分支 B 结论,也不得因 B 不可跑而回退到定性豁免。
- **切换证据**:「分段后仍越带」= 用当前纪元窗(≥8 窗后含足量样本)重估的带沿,当前窗仍满足 §2.3 R1/R2 —— 满足才升级,不满足即 A 关案。

## §4 同窗重放判据(定案;双向纪律)

- **适用**:任何按 §2.3 触发的窗(R1 或 R2),以及任何「重放主张」(无论用于豁免还是用于立案)。豁免方与申报方同受本节约束(W860 双向纪律:禁豁免方无背书单方关门)。
- **重放配置**:与被重放原批逐项一致(commit 为唯一有意差异),worktree 隔离冻结 HEAD,同种子窗/臂/池指纹/采样口径——模板 = W842 重放配置表,逐项声明一致性。
- **判据(定案)**:
  1. **主判据 = 决策序列逐位一致**(actions / v3_intention / 决策金流,100/100 局);
  2. 账本层 outcomes / shop_snapshots 剥离 schema 新增字段后逐位一致(辅助判据);
  3. **显式剥离的已知非确定性(不算不一致)**:①单局**开局装备名**差异(叶子路径在 `state.deployed.*.equips` / `state.equipped` / `state.owned_equips` / `sim.unworn_equips/rust_units/worn_equips_total`)——W842 实锤为进程级哈希随机化(集合迭代序)所致,先于任何近期 commit 存在、装备效果在 sim 未建模、零行为影响;②账本目录名/run_id 差异(归一后比);③ schema 演进新增的默认关恒 null 字段(剥离后比)。
  4. **剥离清单本身受冻结约束**:新增剥离项 = §6 修订,禁逐次追加。
- **结论映射**:决策序列逐位一致 → 允许按「窗自身噪声」读,回 §2/§3 记账;不一致 → **按行为变化立案**(定位引入 commit),禁「噪声置信」豁免。任何重放主张**必须 pin 其 HEAD commit 短哈希**于结论行。
- **禁项**:禁把「重放差分布」当噪声带用——同窗重放在确定性代码下逐位 0 diff,它测量的是**代码漂移**;种子噪声只能用窗间方差(§2)。两把尺子分立,混用即程序违规。

## §5 次级观察量:列车份额(定案)

- **定义**:列车份额 = 列车同行锁线局数 ÷ 总锁线局数(即当窗有效锁线节点总数,never-lock 局不入分母)× 100%。校准期两点:W844 = 57/97 ≈ 58.8%;W858 = 51/100 = 51.0%(总线数以各窗锁线 comp 明细行累计为准,判读批随值记录分母)。
- **用途**:替代绝对线数作为集中度主观察量——绝对线数受全局面线数增减(次级线轮转)干扰;份额直接度量列车对定向预算的吸收比例。W860 角度二指认的「列车越带顶 + 次级线大轮回补」画像,份额口径下才可判。
- **地位**:次级观察量,**不独立触发**;列车份额与列车绝对线数任一触发 §2.3 时,判读报告必须并列给出份额序列。
