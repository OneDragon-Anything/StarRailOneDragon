# ADR-0443:c1_directed_spend_enabled 破息分支——概念定谳否决,永不实现

## Context(为什么)

C1 通道设计时留了一个破息分支存档:P1 末窗、息线以下(g≤50)跨档破息花 X 金找件,过账判据为

```
Δp(X) × 13.35 > 息损 = Δfloor(g/10) × R̄
```

其中 13.35 = E[损血|boss 败] 26.7 × hp_to_gold 0.5 的金当量系数,R̄ = 花后剩余生息轮数。当时 R̄ 精确期望未标定(保守区间 [4,10]),线性近似 Δp(X)=k·X 给出门槛 k > R̄/133.5 ∈ [0.03, 0.075]/金(区间值),而可证传导链上界(P17 +8 hp 链)k ≤ 0.012/金——账面当时已不成立,但出口挂在「E[R̄] 从语料离线标定到位后重裁」。策略开关生命周期纪律要求默认关必须有出口:该出口要么兑换、要么定谳,禁悬置。

## Decision(逐条)

1. **概念定谳否决:破息分支永不实现。** 判据兑换完成——E[R̄] 双数已从既有语料 runs.jsonl 离线标定(全部档内破息事件):均值 2.26 金(95% CI [1.42, 3.22],n=73),条件口径 E[R̄|刷新过]=6.88 金(n=24)。对应门槛 k* = R̄/133.5 ∈ [0.011, 0.052]/金,全部口径(点估计、CI 全区间、条件口径)均高于可证传导链乐观上界 k ≤ 0.012/金——最乐观口径也仅在上界处打平且零安全边际(乘积链任一级失真真实值更低),条件口径(=本分支真实使用形态「破息去刷新找件」)差 4.3 倍。破息分支在数据可证的任何口径下期望收益为负或至多打平,概念否决。
2. **清理物=注释,不是代码。** 分支从未落码:无代码路径、无测试锁、无链日志字段;删码范围=registry 破息存档注释段(含「待 E[R̄] 标定后重裁」句——标定已到位且判否,挂账出口已兑换),按开关生命周期第 4 态改写为定谳注记。
3. **开关本体不删,并入三臂 A/B 裁决。** `c1_directed_spend_enabled` 辖的是 C1 溢余段定向收窄主通道(已落码,默认关零漂移):溢余段花金零息损(P11 参数无关确定性结论),成本侧账与破息口径无关,不能因破息否决而删。其开臂由三臂 A/B「基线 vs C1 本体臂」对照裁决,判据=出口 hp 与 boss 胜率不降 + 每笔删因(c1_hoard_buy / c1_blind_refresh / c1_levelup_no_deploy)可复算 + 无行为面破坏(判据事前补写,防开臂判据缺口)。
4. **Considered Options**:①兑换出口、概念否决(本条)——双数已算出且全口径不过账;②继续挂「待标定」——标定义务已兑现,继续挂=悬置开关,违生命周期纪律,否决;③落码后 A/B 实证——判据是数学命题(门槛 vs 上界),数学已全口径否决,sim A/B 无法救回一个期望收益为负的分支,白付落码+验证成本,否决。

## Consequences

- registry 破息存档注释段改为定谳注记(引本 ADR);filters 的破息辖域 docstring 同步指向本 ADR。字段面零变化,registry 全字段 hash 锁重算与原锚逐位一致(重锚缘由记于锁注释)。
- 主通道开臂义务移交三臂 A/B 首批(同批执行):臂=全关 / C1 本体 / C1+资产臂,同池同 seed 配对;资产臂带前置自检——触发面帧数 ≈0 则转定谳清理提案,不跑无效 A/B。
- 判读侧如遇历史台账中的破息口径引用,以本 ADR 为准。
