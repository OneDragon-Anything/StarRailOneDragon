# 货币战争-备战-合成确认(装备合成确认浮层)

备战画面**拖拽一件装备到另一件装备上**发起合成后,右上弹出的横向小浮层:
`[材料 icon] + [材料 icon] = [产物 icon]`,下方两颗白底药丸钮(✕ 红叉 / ✓ 绿勾)。
无标题文字(纯图形浮层,OCR 无锚)——识别唯一可行锚型 = ✓/✕ 双模板锚。

## 何时出现 + 状态流转

- **入口**:备战画面把装备栏一件装备拖到另一件装备格上(人工/直调拖拽;框架侧
  「穿着即合成」记账面不弹本浮层)→ 浮层出现并**驻留不自动消失**(实测残留 ≥2min16s,
  期间游戏丢弃浮层外全部输入——含与浮层几何不相交的点击)。
- **出口**:点 ✓ = 完成合成(两件合成一件,产物入装备栏);点 ✕ = 取消(两件回库)。
- 浮层**纵向位置随右侧装备栏内容数浮动**(装备多 → 浮层上移):已观测两态
  y374-430 与 y452-508,x 位恒定(✕ x1657-1758 / ✓ x1772-1871)——两钮 area
  检索域按两态行程覆盖(y364-518)。

## 识别特征(稳定锚点)

- **✓ 绿勾药丸钮**(模板锚 `synthesis_confirm_ok`,检索域 [1762,364,1881,518])+ 
  **✕ 红叉药丸钮**(模板锚 `synthesis_confirm_cancel`,检索域 [1647,364,1768,518])。
  双 id_mark 组合(同帧全中才精准,防单锚与他处绿勾/红叉撞车)。
- conf 实测(框架 crop_and_match_template,阈值 0.8):三张阳性帧 0.995-1.000,
  负例帧(备战基线 233949 / 角色详情面板开 001156)≤0.217——余量大。
- **输入对/产物 icon 是内容位**(随合成对象变,禁作锚);浮层盖住装备栏局部格位
  与右上「奖励待领取」区,不遮备战左/中部 id_mark 锚。
- 浮层在场时备战画面仍可能 is_precise(叠加态,局 B 实测)——运行时消歧靠
  浮层注册表帧态门 + cw_loop 分发(本屏 active 条目),不经 screen 匹配竞争。

## automation 要读信息

- **浮层在场性**(✓/✕ 双锚其一即算在场——守卫判据比分发宽一档,宁误拦):
  drag 类动作发出前的浮层守卫与 cw_loop 身份分发都靠两钮模板锚判定。
- 浮层期 `owned_equips` 会把「=」产物预览框误读为已入库装备——浮层期该字段
  不可信,确认后重读(实测,见备战画面 doc 坑节)。
