## S1 as-built 微调记录（相对 design.md §2.4）

- **「遗器-替换-筛选规则」与背包侧「背包-遗器-筛选规则」为同一游戏组件，像素级同构**（弹窗内无任何可区分文本、弹窗外背景暗化不可读，替换域/背包域弹窗帧对照实证）——两个 screen 均保留建档（id_mark 同为「标题-筛选规则」，area 同位），op 在弹窗内的操作一律用屏名取 area + 区域级 until 锚，不依赖全局画面判定；全局识别在该弹窗态命中背包侧属预期
- **「遗器-替换-筛选」id_mark 为三锚**（快速操作/稀有度/遗器建议）：「遗器建议」按钮是替换域角色行独有（背包侧筛选面板无角色行），排除与背包侧「背包-遗器-筛选」（id_mark=「筛选方案」，替换域面板同样存在）的互判
- **「遗器-替换」id_mark 保持「标题-遗器替换」单锚不变**：曾试加「按钮-重掷」以在筛选面板态排除替换屏，但无主件详情态（「替换装备」按钮态）重掷存在性无帧实证，回滚；筛选面板态的屏区分由 op 入口 `check_and_update_current_screen(screen_name_list=[遗器-替换-筛选, 遗器-替换])` 逐屏判定解决（list 语义 = 逐屏 is_target_screen，无全局早停）
- **排序摘要读区 OCR 逗号为全角「，」**（方向反转帧实测）——S3 摘要全等校验须归一标点（F15 的「半角逗号」形态描述按 OCR 实测修正）
