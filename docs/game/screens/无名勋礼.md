# 无名勋礼(nameless_honor)

战斗通行证面板,**全屏接管**:从手机菜单进入后菜单屏的锚(开拓等级等)不可见,曾因此被错档归档在 `菜单/` 下(2026-08-15 迁出独立建档)。顶部 3 个图标 tab:奖励 / 任务 / 星海珍藏。不锁光标(`pc_alt=false`)。

## 何时出现 + 状态流转

- **入口**:手机菜单 → 点「无名勋礼」菜单项(右列图标区,模板 `phone_menu_item_08_nameless_honor`)→ 本面板(默认奖励 tab)。
- **出口**:右上 ×(1843,46)→ 回手机菜单。
- **tab 态**(顶部图标 tab 切换,选中态白底下划线):
  - 奖励(tab1):等级轨(如 30级~40级)+ 左侧双轨标签(无名客的赠礼 = 免费轨 / 无名客的荣勋 = 付费轨)+「一键领取」。
  - 任务(tab2):「本周任务 / 本期任务」两分节列表,每行任务名 + 进度(n/m)+ 勋礼经验值 +「追踪」按钮。
  - 星海珍藏(tab3):光锥图鉴(选中光锥的等级 / 属性 / 光锥技能详情);上版本 fixture 已存在,非本版本新增。
- **子态**:
  - 规则说明弹窗(点「规则说明」):居中 overlay,盖住面板中央,ESC 关闭回面板。
  - 一键领取后的升级画面 / 选择奖励框(app 代码处理:点「点击空白处关闭」/「取消」,见 NamelessHonorApp `_claim_task` / `_check_screen_after_reward`)。

## 识别特征(稳定锚点)

- **id_mark 组合**:左上标题「无名勋礼」(pc_rect 60,10-340,105)+ 右上「规则说明」(pc_rect 1650,20-1830,100)— **三 tab 态共享的框架元素**,任一 tab 态全命中 → `is_precise`(奖励/任务/星海珍藏三态实测均精准)。
- 标题正下方为当前 tab 名文字(任务 / 奖励 / 星海珍藏),可作 tab 态判读(勿作 id_mark — 随 tab 变)。
- 动态值勿当特征:勋礼等级数字、剩余时间、本周经验上限 x/y、任务进度。
- 与菜单屏互斥:面板全屏接管 → 菜单锚「开拓等级」在面板态不可见,菜单 id_mark 不命中本屏;本屏 id_mark 的 pc_rect 区域在菜单态无对应文字,不误命中菜单。
