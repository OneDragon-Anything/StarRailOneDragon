# 0424 sim 战斗类节点切换粗参数胜负模型(两态离散 + plaza 收缩 + 验证门锚定)

- 状态: **accepted**
- 日期: 2026-09-05
- 来源: 设计提案与冻结语料拟合 `.debug/temp/currency_war/w324_coarse_battle/`(DESIGN.md / fit_coarse_model.py / fit_results.json / corpus/);两轮对抗审计 `.debug/temp/currency_war/w326_adversarial/ATTACK.md` 与 `.debug/temp/currency_war/w334_coarse_second/ATTACK.md`;实现 commit c1288da8;用户裁决链(B 裁决 + 胜侧先验主从裁定)

## 背景

现行 sim 战斗类节点(battle / encounter / boss)的 HP 变化来自 Δ池经验分布采样:`cw_delta_pool_data` 数百桶值 + `cw_sim.live_delta_for` 的分桶/下探/防饥饿守卫。用户裁决原文:「胜负模型过于精细,改按难度+阵容粗略计算」——数百桶值对冻结语料 n≈百级样本(战斗类差分 417 条:battle 278 / encounter 77 / boss 62)过于精细,是典型的小数据过拟合,且缺桶/下探/防饥饿三套补丁路径是结构性负担。

两轮对抗审计进一步确立了「粗」的正确形态约束(数据实证,均可按冻结语料重跑复现):

1. 语料 Δ 值谱高度离散且胜/败双总体混合(battle −13 档占 22.5%、胜态 +2 尖峰占 20.4%;boss −32/−34/−36 成簇 = 败局伤害按敌方伤害档取值)——「均值 + 高斯噪声」把双峰抹平,模型隐含胜率与实际击杀率可差几十个百分点,是结构误差不是系数误差;
2. boss 败局 61 行中 26 行(42.6%)`hp_after` 恰 = 1 的吸收态钳制,且**只发生在低 hp_before**(≤35 时钳制率 92.9%,>35 为 0/33——敌方伤害上限 ≈36 的机制解释),与 hp_before 无关的独立抽签会与 `max(1,·)` 地板叠加成双重钳制(期望钳制率 0.608,超实测 18.2pp,σ 翻倍是确定性结构产物);
3. 全部拟合显著性须按 run 聚类稳健标准误(sandwich)口径;同局聚集的 ICC 在冻结语料上 ≈0 或为负(首轮审计的 m*≈2.7/有效 n≈36 在冻结语料上未复现),但显著性判定一律以 sandwich 口径为准;
4. 验证门若不按各指标真实 p 值锚定,「假打回」(完全等价模型纯因种子噪声挂门)与「漏放」(真实退化稳定过门)两个方向的错误会同时存在。

胜侧先验的主从裁定(用户澄清,最高优先级):模型拟合以我们自己的遥测语料(冻结 `corpus/`)为**主源**;plaza(`cw_plaza_comps`,V4.4 高难玩家帖 784 篇 / carry 槽位 997)只是**从源**——仅注入遥测薄弱区(高 rung 胜侧单元),冲突时遥测赢。官方数据只是补充,以遥测为主。

## 决策

1. **两态离散采样,禁高斯**(战斗类三节点):
   - 胜态(killed=True):delta = +2(语料主型);P(win) 按节点×rung 查找表取(Laplace 平滑 α=1,附聚类 bootstrap CI);
   - 败态:伤害从**节点级败局伤害离散值直方**采样(保留 Δ值谱离散结构;前 12 档覆盖率 battle 87.3% / boss 100%),按 rung 线性均值匹配偏移取整;终态 `hp_after = max(1, hp_before − damage)`;
   - 回测(两态原型 vs 语料逐维,battle/encounter/boss 均值 −9.5/−8.4、−18.4/−18.6、−25.8/−22.6,钳制率 6.5%/10.1%、7.8%/9.1%、41.9%/40.3%)与实现 commit c1288da8 落地一致。
2. **boss 败局钳制按 hp_before 条件化**:`hp_before ≤ 35` 时以实测钳制率 0.929 归 1,>35 不钳(语料 0/33);伤害一律采非钳制行直方、经 `max(1,·)` 地板兜底。**禁止**「与 hp_before 无关的独立抽签」形态——它把高 hp 行也送进吸收态,与地板公式叠加成双重钳制,期望钳制率恒超目标(独立抽签 + 0.426 的版本期望 ~0.61,超实测 18pp;σ 翻倍是结构产物),该形态已在回测中实证并废弃。
3. **聚类稳健拟合(参数 = 原型拟合值,单一源落实现批常量)**:
   - battle Δ = −12.06 + 2.96·rung(CI95 [1.08, 4.84],显著);
   - encounter Δ = −23.48 + 5.47·rung(CI95 [2.27, 8.67],显著);
   - boss Δ = −26.71(常数;斜率 0.79 的 CI95 [−2.80, 4.38] 含 0,退常数是正式裁决;rung=3 桶仅 n=3,新语料扩容后复核);
   - 败局伤害:battle 11.3 − 0.37·rung(斜率不显著)、encounter 24.3 − 4.53·rung(显著——「深板扛遭遇」的强度主通道)。
4. **plaza 先验收缩主从量化**(只进 rung≥2 胜侧单元):
   - 主源 = 遥测冻结语料;从源 = plaza,只承载「该终态结构能打穿」的存在性(prior = 0.35,与语料 rung1 实测同量级的存在性下限,乐观界——plaza 无败例、rung 尺度对燃血/夜之半神等主流体系盲区,三重语义边界见设计文档 §①′ 强制前缀);
   - 权重:先验在单元后验的份额上限 `PLAZA_SHARE_MAX = 0.25`,等效帖数上限 `ALPHA_CAP = 12`,`α_cell = min(12, n_cell/3)`——先验份额恒 ≤25%,任何单元不允许先验主导;裸 α 口径(无帽,α=30 时 boss 单元聚合位移 +4.2 hp、达验证门 40% 量级)一律禁止;
   - 冲突裁决:遥测赢。注入后 `two_state_model.win_p` 高位单元位移 0.009~0.054(如 boss rung2 0.133→0.187、encounter rung3 0.250→0.275,rung0/1 不动),对 sim 聚合期望位移 battle ≈ +0.02 hp / encounter ≈ +0.13 hp / boss ≈ +0.37 hp,比验证门小一个数量级以上;
   - 版本偏移降权双轨:实机局终管线挂游戏版本号检查(版本变更 → `PLAZA_SHARE_MAX` 自动降 0,复验后才可重启用)+ 版本升级 checklist 固定项(重跑 `gen_plaza_comps.py` + 重注入 + 重审)。plaza 冻结 V4.4,对 2026-08-26 补丁后 meta 零覆盖,置信度 🟡。
5. **难度乘子 A8 关闭**:1.052^(Δ难度) 已实现但**默认关闭**——该值出自 V3.7 时代过期攻略存档的旧口径估算,从未裁决(economy.md §9 系统性警告在案),且挂靠对象(敌方血量膨胀 vs 敌方伤害档膨胀)未实证。A8 基准内乘子 = 1,不影响任何拟合值;核验前跨难度(非 A8)策略设计禁用本模型的难度维。
6. **验证门按 p 值锚定(n=1500/臂,等价带 m=4.4pp)**:
   - 通则:基线 p̄ 由 Δ池现行模型预跑(n≥300)估出 → 宣告每指标最小关切退化 δ0 → 样本量按功效公式 `n ≥ 2·p̄(1−p̄)·((z_{1−α/2}+z₀.₈)/δ0)²`(三率门 Bonferroni 族预算 ≤5% → 每门双侧 α=0.017、z=2.39)→ 等价带 `m = 2.39·√(0.5/1500) = 4.4pp`;
   - n=1500 的推导 = 实测成本:sim 单局墙钟 ≈0.12s(`cw_sim batch --n 50` 实测 7.4s 含启动),全流程约 5400 局 ≈ 11 分钟,成本不构成约束,买更窄的等价带(公式最小值 522/臂对应 m=7.4pp);
   - 写死的门:P2 进场率 / P2 core2≥1 率 / P2 star≥2 率(δ0=10pp,|Δ|≤4.4pp 即过);P3 首轮 HP 中位数(δ0=10 hp,**TOST 等价检验**——90% bootstrap CI 须整体落在 [−10,+10] hp 内);HP 分布宽度双向硬门(IQR ∈ [0.67×, 1.5×]×Δ池 IQR,变窄 0.67× 以下打回——高斯化抹平双峰正是本设计要防的失败模式);boss 钳制率单列(与 Δ池差 ≤10pp)。假打回率预算 ≤5%(族)、δ0 处漏放 ≤20%(每指标)写死,不允许为过门调容差。
7. **Δ池两步退役**:
   - 第一步冻结(已随 commit c1288da8 落地):`gen_delta_pool_snapshot.py` 停跑、实机局终自动再生管线摘除、`cw_delta_pool_data.py` 标记退役停更保留、`check_pool_freshness` 冻结态跳过;`cw_sim` 的 `BATTLE_ENGINE_MODE='delta'` 保留 Δ池路径作对照臂;
   - 第二步删除(过验证门后一个清理批):`cw_delta_pool_data.py` / `cw_delta_pool_gen.py` / CLI 壳 / `cw_sim.live_delta_for` 战斗类分支 / 四个桶守卫 check / 指纹校验消费点。reward/supply 节点暂不在粗模型范围(倾向常数 +2、彻底删池),留清理批裁决。

## Considered Options

- **保留 Δ池数百桶值**:拒绝——对 n≈百级样本是过拟合(用户裁决),缺桶/下探/防饥饿三套补丁路径是结构性负担;参数总量 ~20 个 vs 数百桶值,粗模型消除三套补丁路径。
- **二段式胜负(均值+高斯噪声近似)**:拒绝——语料 Δ 值谱离散且胜/败双总体混合,高斯抹平双峰后模型隐含胜率与实际击杀率差几十个百分点(battle rung1 实际 48.2% vs 隐含 11.5%,首轮审计实证);battle 胜率沿 rung 的硬事实只有 rung0 全败(0/106),任何单调连续结构都还原不了这个台阶。两态结构被数据实证否决掉的是连续噪声形态,不是少参数方向。
- **钳制解方程 c≈0.16(全局常数钳制率)**:拒绝——二审曾提出解 `c+(1−c)r=0.426` 得 c≈0.16,但正确修法是**按 hp_before 条件化**(≤35 时 0.929、>35 不钳):语料机制证据(钳制行 hp_before 均值 25.3 vs 非钳制 55.1)表明钳制条件本质上是 hp_before 的函数,全局常数把高 hp 行也送进吸收态;条件化后回测钳制率 40.3% vs 实测 41.9% 对齐,分箱条件化替代了常数解。
- **α=30 裸收缩(无帽)**:拒绝——无帽裸收缩下先验份额随 α 近线性放大,α=30 时 boss 单元聚合位移 +4.2 hp、达验证门 40% 量级;25% 份额帽 + `min(12, n/3)` 等效帖数帽把损害限制在可声明量级,且数据越薄先验越轻。

## Consequences

- **历史 A/B 基线作废**:粗模型转正起,所有基于 Δ池 sim 的历史对比不可与新结果直接对比,未来对比一律粗模型重跑基线。实机锚(实机遥测与实机对拍结论)不受影响——实机是真值源,非 sim 产物。
- **reward supply 池保留**:reward/supply 节点暂不在粗模型范围,继续走 Δ池采样;池是否并入(倾向常数 +2、彻底删池)留清理批裁决——在池删除前该两节点的 Δ池依赖不可摘。
- **跨难度核验挂账**:难度乘子为未核先验(过期估算 + 挂靠对象未实证),核验前跨难度判断禁用本模型难度维;挂账为待少量实机观测实证的第一复核项(与 boss rung=3 桶 n=3、钳制精确阈值 35 同批)。
- **清理批后置**:Δ池删除代码路径(文件/分支/守卫/指纹消费点)全部挂到「过验证门后的清理批」,冻结期 Δ池停更属预期非断裂(`check_pool_freshness` 冻结态跳过);回滚成本 = git revert(待删文件均在 git 追踪内)。
- **语料资产**:replay 语料(decisions/outcomes jsonl)是唯一能重训/重拟合的真值资产,任何退役批不得删除语料文件;模型退役只动代码与快照。
- **转正后须攒新策略语料重拟合一次**:分段斜率 −20.0 ~ +9.0、15 个可拟合 run 中 6 个符号为负——pooled 系数是策略混合比的加权产物,混合语料上的系数不用于机制叙事。

## 判据与验证

- **判据**:冻结语料快照 `corpus/`(decisions 6146 行 / outcomes 751 行;全部数字的复现锚,拟合脚本 `fit_coarse_model.py` 可重跑)+ 用户裁决链(B 裁决 + 胜侧先验主从裁定);
- **三轮对抗审计**:首轮(五项击破:两态结构 / boss 吸收态 / 聚类稳健 / 验证门 / 1.052 引用降级)与二审(11 项修复吸收核对:10 真吸收 1 表面吸收→新猎 boss 双重钳制与验证门成本账,均已按条件化钳制与 n=1500 成本推导吸收;数字清扫 encounter sim σ=14.8、覆盖率口径 87.3%/100%、3星率统一 rung 加权 0.67~0.85 + 聚类最大 0.93)全部闭账;设计文档与 `fit_results.json` 逐格对账一致;
- **实现批测试锁**:commit c1288da8 配套测试仓锁(粗模型切换单帧锁 + Δ池冻结守卫锁,测试仓 commit fc6cfe0);
- **corpus 冻结锚**:生产 replay 目录被实机对局持续追加,一切拟合与验证读冻结快照,不读活目录;
- **验证批(后置)**:按本 ADR §决策 6 的写死门(Δ池对照臂 vs 粗模型,n=1500/臂)跑齐过门后,Δ池进入第二步删除;过不了门按方向判退化打回,不允许为过门调容差。
- **验证门覆盖范围补正(门攻击审计后勘误)**:本节门组实证为**一阶矩等价**检验——IQR 硬门对「逐节点高斯化」实测失效(聚合 HP 多节点求和后近高斯,高斯化 IQR 比仅 1.083,离 0.67 打回线 3 倍余;定量推演可复现,产物 `.debug/temp/currency_war/w342_gate_attack/`),下尾/尾部风险(灾难伤档丢失)无门覆盖(中位/IQR/均值近不动,仅 P5 分位漂 +11 hp 可见);据此 Δ池第二步删除(§决策 7)须在补齐**形状门**(KS/Wasserstein 距离)与**下尾门**(P5 分位/非 boss 钳制率)并复验通过后执行,补门前删除清单挂起(冻结保留对照臂无成本);§决策 6 中「|Δ|≤m 即过」的字面表述按 TOST 等价检验语义执行,三率门与中位数门的判定标准不一致在补门批统一。

## 候选否决补遗

- **plaza 先验直接做主源 / 按 plaza 成型画像定胜率**:拒绝——plaza 无败例(幸存者偏差)、rung 尺度盲区、静态终态 ≠ 动态逐轮(三重语义边界);官方数据只是补充,冲突案例三件(高位递增先验 / 必胜结构 / encounter rung1 单元)均裁决遥测赢,逐件入档备查(设计文档 §①′)。
- **「CI 含 0 即过」的 P3 中位数门**:拒绝——这是差异检验判据,会让 ≈3 hp 级的显著回退也打回,与「δ0 以下不关心」自相矛盾;改 TOST 等价检验兑现假打回率预算。
