# 货币战争-星琼详情（货币图标误触弹窗）

**识别**：`is_precise` 命中 `货币战争-星琼详情`（锚：「星琼」标题 +「稀有货币」双文本；模态盖场时下层画面锚点全部 OCR 失明）。
**目标**：点击任何在场货币图标弹出的货币说明卡（星琼实例）——对局中多由误触打开，页面无策略消费信息，识别即关。

## 怎么操作（看图口径，不写死坐标）

1. **出现**：点货币图标（典型事故位：列车补给弹窗中央徽章饰章内下缘嵌有星琼图标——点中央徽章区领取时命中图标，只开详情不领取）。
2. **关闭**：点弹窗右上角 X 回下层画面。**禁 ESC**（项目禁键令）；点空白遮罩关闭未采样，不作默认手段。
3. 接力：若下层压着未领取的列车补给弹窗，X 关闭后下一轮由补给守卫接住领取。

坑：开局入口链守卫已在四个节点自动识别即关（`cw_entry_start` 星琼详情守卫）；自己手动操作时点到它，直接关 X 即可，别当画面故障排查。
