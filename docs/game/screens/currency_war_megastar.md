# 货币战争-盛会之星(羁绊触发的「选巨星」overlay)

## 何时出现 + 状态流转

- **触发**:对局中**盛会之星羁绊激活时**(≥2 名盛会之星角色上阵前排/后台凑够激活数)弹出,**非固定节点**(每局是否遇、遇几次取决于阵容)。盛会之星阵营 = 花火 / 星期日 / 知更鸟 / 黑天鹅 / 大丽花 / 加拉赫 + 盛会之星星徽。
- **巨星机制**:从持有的盛会之星角色里**选 1 名当巨星** → 给**全队 buff**(各巨星 buff 不同,随羁绊等级 2/3/4/5/6 递增;花火=进战给战技点+普攻/战技增伤,星期日=前后台强度,知更鸟=幸运一击,黑天鹅=5费增伤,大丽花/加拉赫=击破伤害增幅+治疗强度)。
- **流转**:备战 →(盛会之星羁绊激活)→ 本 overlay → 选 1 巨星候选(点卡→金边选中)→ 点「确认选择」→ overlay 关,回备战(节点完成)。
- **出口**:确认选择 → 回备战。

## 识别特征(稳定锚点)

- **标题「盛会之星」**(top-center,pc_rect ~`[987,52,1125,99]`,组合 id_mark `标识-盛会之星` + `备战标识-购买经验`)。
- 指令「请选择1名角色成为巨星」(y~123)。
- **候选带名字**(左右 1-N 个,如「盛会之星—星期日先生！」「盛会之星—花火女士！」)—— ⚠️ 与「选择伙伴」不同,**候选有角色名**(OCR 可识别,非只有流派 label)。
- 「确认选择」按钮(右下 ~1442,548)+「详情」(候选卡下方)。
- 「请选择强化角色」(overlay 内,右下 ~1416,495)+「强化角色未选择」(**出战按钮上方,备战侧** ~1714,676)—— ⚠️ **「强化角色未选择」= 巨星(强化)选择未确认 → 出战被锁的提示**(用户 2026-08-13 澄清:它在出战上方,意思是"由于未选择,所以不能出战"),**不是 overlay 内要再选一个强化角色的必选步骤**。选巨星候选 → 点「确认选择」→ overlay 关、出战恢复。
- overlay 叠备战:备战 id_mark 含「前台区域」被本 overlay 盖住 → 备战不是 is_precise → 只有盛会之星 is_precise(id_mark 区分,见备注)。
