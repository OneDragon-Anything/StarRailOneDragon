# 万敌（虚数·毁灭·5星）

> 按 V4.7 期撰写。烧血充能狂战士：血仇双形态、防御归零换爆发。

## 一、命途属性与技能说明

**命途**：毁灭；**属性**：虚数

| 技能 | 说明 |
|---|---|
| 普攻 | 单体50%生命上限虚数伤+嘲讽 |
| 战技 | 消耗当前生命50%：AoE 72%+4×24% 生命上限；仅无量忿怒期间可用 |
| 终结技 | **消耗充能非能量**：回20%生命+20充能+160%/100%+嘲讽2回合；血仇时替换为【弑神登神】280%/168% |
| 天赋 | **每损失1%生命→+1充能**（上限200）；充能100→【血仇】：回25%血+行动提前100%+生命上限+50%+**防御恒0**+回合自动【弑王成王】；血仇中充能150→额外回合+弑神登神；致命伤免死退出 |
| 秘技 | —（以官方文本为准） |
| 额外能力 | **B1：生命>4000 每100点→暴击率+1.2%+充能比例+2.5%+受治疗+0.75%**（超出计4000）——**8000 生命吃满**三合一 |

**资源与循环**：充能不走能量——**充能词条零收益**；掉血即充能。

## 二、推荐遗器与原因

**套装**：再创天地的救世主4件 + 谧宁拾骨地2件【攻：生命模型口径】
**主词条**：躯干暴击率/暴伤；脚部速度/生命%；球虚数伤/生命%；绳生命%。
**副词条**：生命% > 双暴 > 速度。
**不堆**：充能、防御（血仇防御恒0）。
