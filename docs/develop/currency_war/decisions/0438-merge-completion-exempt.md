# ADR-0438 · 非正分门 merge 完成豁免(第三张副本 3合1 完成素材语义)

> **引用勘误(2026-09-04 ADR 存量 review)**:`.debug/` 归档 → 本目录(decisions/)同名 ADR。文内出现处按此对照读取。

- 状态:accepted(开臂:两开关默认值随本批 A/B 兑现翻 True)
- 日期:2026-08-28
- 批次:W436(定位依据=W431 REPORT `.debug/temp/currency_war/w431_generation_starve/REPORT.md`;复测义务=W429 REPORT)

## 背景

W431 定位:第三张副本「未买」的主体病灶(74/95 笔,77.9%)在 **arbiter 非正分门**——第三张副本买入即合成 2★(`Candidate.merge=True`),但其价值落在星级阶梯(H3:e0/e1/e2 胜率 13.9/41.6/77.8%)而非板面差分;评分维(`scoring._merge_progress_count` 每名只计第 2 份,ADR-0340 W93 断买修复的边界)对它构造性零增量 → `val<=0` 被非正分门结构性拒。既有 C 豁免(arbiter 非正分门,ADR-0405 C 项)只辖 `tag=='copy'` 且末窗 gap>0,第三张人群(`line_opportunistic` 标签、全程轮次)不在辖域。另一窄段(15 笔)是生成层 r410 守卫在 lv7-8/press 关窗无臂接,现成开关 `copy_swap_target_exempt`(ADR-0303/0304,默认关)条件精确命中——本批一并开 A/B 臂复测(W429 挂账的 dup_concentration 协变量复测同批承担)。

## 决策

1. **落码**:`registry.merge_completion_exempt` 开时,arbiter 非正分门对 `merge=True ∧ isinstance(action, BuyCard)` 的候选放行进入约束链——与 C 豁免同为「完成素材放行」语义对称,**无条件于末窗 gap**(完成价值全程存在,非定向授权;W431 实测 74 笔分布 lv5-8/r3-9,gap 条件会漏主体)。初版默认关零漂移,A/B 兑现后随本批开臂翻默认 True。
2. **豁免≠必买**:只跳过非正分门,金_floor/copies_cap/bench 容量/息账(interest_rule EV)照常辖——EV 账不缺第二份授权值,非正分拒对该人群是评分零维测量伪影而非价值裁决。
3. **定向性边界**:synthesize 候选(`merge=True` 但非 BuyCard)不辖,防语义外溢;非 merge 候选不辖。
4. **②通道开臂**:`copy_swap_target_exempt` 同批 A/B 兑现判据(ex_swap vs ex 买率 +9.15pp 显著/守卫全净)→ 翻默认 True;ADR-0304 的旧回退裁决前提(无主病灶语境的三窗小负)被本批取代。
5. **W429 复测义务**:ex_dup 臂(豁免扩+集中度约束双开)复测 dup_concentration 在「候选可买」新前提下的删笔协方差(W429 处置建议第 2 条)。

## Considered Options

1. **豁免扩(本决策,推荐=W431 落点 A)**:最小、语义有 C 豁免先例、`merge` 旗标现成。风险面=放行非必买,约束链兜底;merge 买入不占新 bench(买后即合成)无腾位需求。
2. **评分层根治(W431 落点 B)**:`score_all` 对 merge 候选把合成 2★ deploy 后形态计入 after 差分——改动大、需量级标定,且加项抬 base 压缩其他买(ADR-0300 否决理由 2 同型);留作 A/B 后评估。
3. **共用 ②开关**:①辖仲裁门、②辖生成守卫,是两个截流点——共用会令「只开①」「只开②」两臂不可表达,破坏单因子 A/B;否决。
4. **r410 守卫加 lv7+ 后备臂**:新增条件组合,不如现成臂①语义干净(W431 同判);不推荐。

## Consequences

- A/B 兑现后开臂(默认值翻 True,行为锁组同步:`test_cw_w436_merge_exempt` 默认开语义 + `test_cw_adr0303_merge` 回退态改显式注入关臂 + registry hash 锁重算)。
- W431 §4.3 度量债(tag 级生成账本缺失)不在本批;豁免开臂后「第三张未买」剩余人群收窄,可作账本批的触发证据。
