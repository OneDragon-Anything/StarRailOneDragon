## 1. 五门逐门判定

### 门① 内部推导(保守锚论证逐步核)—— **过(结构面)/ 期望账数值依托已塌(引用面)**

- **逐步核验通过的段**:
  1. 「机制事实(无争议部分)」的内部陈述自洽:保底一次性、耗尽后再次归零=整局结束——作为**假设性机制前提**表述清楚,且明确声明其来源是口述。
  2. F07 修正(双向 ⟺ 收窄为单向保守锚)逻辑正确且必要:HP=1 确实不能区分「恰好剩 1」与「保底后剩 1」;**实测语料直接证实了修正的必要性**——151 局中 100 局出现 hp_after==1,其中 61 局在 hp=1 后继续有战斗行、26 局回血到 >1(如 run_20260823_154910:p2r5F:1 → p2r6W:3)。即 HP=1 大量出现于「保底显然未触发过」或「局远未结束」的语境,⟺ 断言在语料上即伪。
  3. 「候选线非触发线」的定位陈述与实现一致(见门⑤)。
- **数值依托已塌的段(核心发现)**:「期望账」整段数值(H3:e2 77.8%、e1 41.6%、e0 13.9%、剩余节点≥2 时 e0 板全胜 <2%)全部继承自 **P3 胜率阶梯——该阶梯已于 2026-09-01 五门验证判「数值面=证明不成立」**(生成快照+脚本已灭;最新全量语料按文档口径复算阶梯平坦 e0 19.5%/e1 15.2%/e2 16.0%,e1 不可复现;见 math_proofs P3 行 + P3_VALIDATION §4-§5)。P3_VALIDATION 修正建议第 4 条已点名「P32/**P9**/P17 的阶梯引用——同一 Δp,连环失效」,但 p09 单篇与 math_proofs P9 索引行的语料锚「e0 板剩余≥2 全胜 <2%」**至今未随 P3 作废而改写**。按作废后口径重算:e0 全胜(剩余 2 节、独立假设)= 0.195² ≈ 3.8%,不再是 <2%(量级仍小,但数字授权已失源)。
- 判定:保守锚的**结构论证**(单向化、候选非触发、联合板面/日程)过;**期望账的全部具体数字禁引**。

### 门③ 建模对象 vs 玩法文档(0hp 保底机制原文)—— **不过(机制出处错标 + 官方文本反而不含该机制)**

- 判定:建模对象的机制前提(0hp 保底)只有口述级证据,且出处错标为「gameplay 总览」(误导后续读者去官方文本找原文会找不到)——不过。

## 2. 最终判决

**P9(索引真身)= 结构面成立、数值与机制出处双失源的「整理级」命题;按其自我声明的「机制命题(整理,非证明)」档位,五门综合判:维持「整理级·候选线」资格,但索引行语料锚与单篇期望账的全部具体数值禁引,机制前提降档为「口述待玩家确认」。**

分项:
- 结构论证(单向保守锚、候选非触发、联合板面/日程、实现检验点)= 过(F07 修正被 151 局语料直接证实其必要);
- 语料锚「e0 板剩余≥2 全胜 <2%」= 不过(失源:继承已作废 P3 阶梯;无脚本无 CI 不可重跑);
- 机制出处 = 不过(「gameplay 总览」错标,官方原文不含保底且写「归零即结束」;「无争议部分」定性越权,语料仅弱候选支持);
- 实证可达性 = 过(151 局语料在线,hp1 分布方向支持候选线语义);
- 消费角色 = 合规(纯判读披露面,零决策消费;[39] 判读域纪律未破)。

不是证伪:命题的可消费内核(「HP=1 只作早停候选标记,不作触发线,不进决策」)方向正确、实现合规、语料支持。失分全在引用卫生:借了已倒的数值塔(P3)与未在册的机制原文。
