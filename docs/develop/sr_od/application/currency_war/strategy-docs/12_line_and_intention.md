# 12 终局线选择(候选-锁定制)与方向状态载体

> 本篇管**终局线(终局阵容)怎么选、怎么锁、锁定后的名单从哪读**。方向与板面执行分层:P1 板面恒过渡体系(等级人口约束,与方向正交);方向 = 全程线分数评估 + top3 候选管理 + 硬规则锁定;锁定后不设主动换线。流程侧帧声明与黑板 = `../flow/README.md` §2.2、`../flow/prep_visit.md` §1;升级判据(概率主轴,与选线共用锁定态) = [11_shop_decisions.md](11_shop_decisions.md) §2;两域工序 = [22_prep_screen.md](22_prep_screen.md) / [23_shop_screen.md](23_shop_screen.md)。
> 前置阅读:[01_math_framework.md](01_math_framework.md) §3.7(方向判据行)、[02_mandate_layer.md](02_mandate_layer.md) §2(三层权限:证明层)。
> 术语(首现定义):**终局线已锁定**(下文简称「锁定」)= 锁定线槽 `StrategyState.target_comp` 非空(一次性写入,锁后只读;`ist.locked_comp`/`ist.phase` 为其 kernel 派生缓存);**候选**(实候选)= 未锁定期经证据门入选的线分数 top3 线(零证据线不入,§1.2);**过渡候选** = P1 体系对候选机器 top3(§3);**硬规则** = 每线一条显式锁定条件(策略型/角色型,查表判定,零标定参数);**知识卡** = `kernel/cw_comps.py::COMP_LIBRARY` 每线登记的玩法知识字段(lock_rules 锁定条件/need_star 必要星级/key_items 跨阶段体系件名单/entry_signals 上线窗口信号);**帧** = 决策循环的一个观察-动作周期;**单一源** = 某语义在全仓只有一个权威定义处,其余一律引用不复制;**fail 方向** = 判据未验证或输入缺失时缺省行为取保守侧的约定。

## 1. 选线函数(候选-锁定制)

机制形态:`f(局面状态) → 「未锁定(top3 候选已登记)」 | 「锁定线 X」`(一次性决策,锁后不换)。实现载体 = `strategies/impl/mandate_v1/line_select.py`(线分数/候选/锁定判定) + `session_scope.py`(状态重算与锁定写入)。**零标定参数**:硬规则查表判据,无连续加权、无相对幅度、无定型门/滞后余量形态——防摇摆不靠滞后余量靠结构(硬规则锁定 + 锁后不换线,无摇摆形态产生)。

### 1.1 线分数(字典序)

比较序 = **环境分级 → 持有证据级 → 攻略热度**(字典序逐级比较,先高级定序再比下级;`line_score_key`):

| 项 | 算法 | 数据源 |
|---|---|---|
| 环境分级(首键) | 强关联策略命中线 = 最高级、其余普通级(策略型信号门槛级语义,非加数) | 投资注册表(`cw_invest_data`)持有面 + 知识卡 `lock_rules` 策略型(策略-线关联即本字段构成,无独立关联表) |
| 持有证据级 | CARRY 在手 > 骨架计数 > 插件计数(三档序数分;已有越多分越高——替换成本语义由此承载) | CARRY = `carry_set`(`plaza_carry` ∪ `core_chars` 合流,空值线由锚合流承接);骨架 = 知识卡 `key_items`;插件 = 线成员 − CARRY − 骨架余集(派生) |
| 攻略热度(平分裁定) | 线分数平分时按攻略热度定优先级(十类帖数降序;口述条目 38(登记簿已退役) 修订版) | `LINE_HEAT` 常量表(十类帖数→20 线类级映射,长尾八线共享「其他长尾」桶 ~40;未登记线取 0 = 缺表 fail 方向) |

- **热度表落策略层**(`line_select.LINE_HEAT`,排序立场数据——换策略会换值,不落 kernel 玩法知识注册表);桶内热度不可分的终局裁定 = COMP_LIBRARY 注册序首线(显式规则声明,非遍历序隐式定锁)。
- **不设项**:购买力项(按当前可购费用档打分会系统性偏置低费线);时间预算项(期望等待 × 剩余节点难算不直观)。**方向评分零货架不变**——货架信号的装载位 = **单张买入估值**(序 1 义务扩展臂「货架资格臂」,[11_shop_decisions.md](11_shop_decisions.md) §1:货架 CARRY/骨架级牌经虚拟 top3 资格判据义务买入,买入写持有 → 下帧线分数持有证据维自然上升),方向评分面货架零进分,与 P77「方向评分零更新」定理一致(甲修正 1:反应式策略经买动作改进度不在零更新适用范围——零持久化、同帧兑现;math_proofs P77 行)。
- 知识卡 `key_items` 缺行时持有证据仅消费 CARRY 档(fail 方向条件句);`need_star` 与 `star_goals` 双源口径:消费单一源 = `need_star`,`star_goals` 保留为比对基准不进决策链(建表口径 = [10_prep_decisions.md](10_prep_decisions.md) §5)。

### 1.2 候选管理(未锁定期)

- 每帧对全部线算分,**top3 为候选**(候选数量 = `CANDIDATE_TOP_N`,用户立场值);候选快照 = 派生态(每帧随签名重算,非持久状态;锁定写入后清空停算)。**候选入选证据门**:线入选实候选 ⟺ 线分数的证据维非零(`line_score_key` 前四维:环境命中 ∨ CARRY 在手 ∨ 骨架 ≥1 ∨ 插件 ≥1——`compute_candidates` 证据门开启版,候选快照消费;其余调用方缺省全量版)——零证据线不入候选,攻略热度降为**有证据线之间的排序**,不再是入选理由;开局零持有零环境 = 空候选(合法形态,买入/环境/发放逐步点亮入选)。
- **候选双层结构(终局层 + 过渡层)**:终局候选(实候选)= 上述证据门版线候选;过渡候选 = P1 体系对候选机器(`cw_intention.p1_pair_candidates_of`:四体系组合空间按(对级支持度降序,对级声明序)取 top3,对级支持度 = min 席级支持度;希儿系对入候选门槛 = 席级 1.0;无羁绊开局合法空——语义与冻结收敛见 §3)。两层候选分别驱动终局义务面与过渡配方半边,载体 = `line_candidates` 快照与 `transition_candidates` 槽(§2);成员档双层装配 = [32_unified_sell_priority.md](32_unified_sell_priority.md) §2。
- 候选变动:进榜线开始囤件;掉榜线已囤件保留不再新增(1★ 可全额退,不亏);实候选退出 = 证据消失(卖出唯一副本)或被更高证据线挤出 top3。
- 采购纪律(义务面单一面):**义务面** = 实候选(证据门版)三线成员并集 ∪ 过渡候选各对成员并集(与统一价值序成员档族〔档 2/3/4/5/7〕名单同源——买面与优先级面同一份名单,免息待遇 + 获取受阻〔席满 ∨ 金不足〕统一走获取让位评估,原会话内筹资已并入该评估,[11_shop_decisions.md](11_shop_decisions.md) §4.0);非义务面成员商店见到不买(万金油角色只在恰为候选线/锁定线成员时按序 1 买入,手里持有的未到两星前受统一价值序档 8 保护、无自动补货通道;原「保护集囤货面」为期权级囤货——首副本走囤货臂、买因 `protection_hoard`——已随囤货臂退役拆除:囤的换线期权在锁定后不换线制下无兑现通道);+ 候选件没有而金有余时按费用档判据买牌压牌库(不限候选线;[31]②/[34] 既有纪律)。
- P1 板面恒过渡体系(战力资源约束,与方向正交);过渡体系选与榜首候选重叠的(转正不废件)。**P1 锁定局的采购通道**:锁定后序 1 名单 = 过渡候选成员并集 ∪ 锁定线名单**并集**(板面过渡 + 锁定线积累双目的;配方物化链在产,锁定不辖 P1 配方件——物化单对 = 候选首位 ⊆ 候选并集,买面不读物化键);P2 起切锁定线名单单源(退出条件 = `plane2_started` 窗口谓词,非位面字面量)。
- 升级触发口径:锁定后最优概率带单判据三分派([11_shop_decisions.md](11_shop_decisions.md) §2),未锁定期零主动升级(带驱动辖域外,候选缺件刷新承接——原「概率账缺件集并集口径」随概率账臂删除消亡,无聚合消费面);义务面身份判定源 = 候选快照(k_members 未锁定期为空,义务身份集 = 候选 top3 线内成员)。

### 1.3 锁定(双触发,先到先锁)

| 触发 | 判据 | 时点 |
|---|---|---|
| **硬规则·策略型** | 该线强关联策略到手(lock_rules 策略型命中,任一到手即中) | 随时(含 P1) |
| **硬规则·角色型** | 该线关键角色组合到手(每线一条显式条件:CARRY + 攻略明示关键骨架,组合件数由攻略语义查表登记,非连续阈值) | 随时(含 P1) |
| **时点兜底** | 时点后仍无硬条件命中 → 锁定 top3 中分数最高者(平分按攻略热度);**空候选兜底**(证据门下可达,真规则):候选空 → 锁全 20 线全序首名(缺省全量版重算取首;零证据帧首名 = 热度首线,现行全序的退化情形) | 第二位面已启动 ∧ P2 起首次投资策略三选一完成帧 |

- 判定单一源 = 知识卡原语 `char_lock_hit`/`strategy_lock_hit`(`kernel/cw_comps.py`),禁消费位自拼子集判定;硬规则命中线按线分数全序排序,同帧多命中取首(`hard_lock_hit_lines`)。
- **同帧多命中裁决** = 取线分数最高 + 热度 tie-break + 注册序终局(与候选排序同一全序,禁遍历序隐式定锁)。
- 时点兜底触发分支:`plane2_started`(窗口谓词,首入 (2,*) 段置位——P1 内即时/延迟加场卡被结算节点边界锚排除)∧ `p2_strategy_pick_done`(P2 首帧快照 `active_strategies` 基线 + 集合增长侦测;增长来源不区分选卡/节点赠得——对「策略已定 → 可兜底」语义等价;bot 视角完成帧 = 获得后的首个决策帧)。
- **锁定效果**:买牌、升级窗口、装备定向、上场窗口全部围绕锁定线;装备合成材料开始定向留存。锁定写入与连带动作的唯一所有者 = `session_scope.write_line_lock`(§2),禁绕过直写键跳过连带。
- **投资选卡端消费本判定面**:投资环境/策略两屏的阵容冲突护栏,未锁定帧 = 候选与已持有投资(环境+策略)的阵容指向集比对,锁定帧 = 与锁定线 factions 比对(锁后历史误持不入基);护栏只读「锁槽非空 + 锁线 factions + 持有投资名」现值,不读方向层状态、不进 committed 语义,与方向层读口无耦合(正本 = 29/28 号稿 §3)。

### 1.4 锁定后

- **不设主动换线**(用户立场:自己玩都很少中途换——「搜不到 → 转线」类预案已被锁定前评估吸收:搜不到的线分数起不来,兜底锁定时自然不选它)。
- 唯一线内调整 = **星级 = 必要星级表驱动,无降档规则**:每线每角色按攻略登记必要星级(知识卡 `need_star`;CARRY 按星级饥渴数据标 2★/3★,辅助标 1★)。定义 3★ 就追到底,无降档;定义 2★ 的线 2★ 即完成。星级是刷新停留的自然积累(刷新判据 = 星级目标驱动,[11_shop_decisions.md](11_shop_decisions.md) §3),不是独立管理对象。
- 等级被硬需求推过目标最优概率带的形态 = 当前等级即剩余可达最优——照样停留刷新(可达最优等级模型,[11_shop_decisions.md](11_shop_decisions.md) §2 停留门)。

## 2. 方向状态载体与读写接口

方向状态 = 策略器私有状态(StrategyState)上的四键(锁定线槽 / 配方物化键 / 过渡候选槽 / 候选快照)+ 派生缓存:

| 键 | 写者 | 语义 |
|---|---|---|
| `target_comp` | `write_line_lock`(**唯一写者**;锁定线槽,`Comp | None`) | 终局方向,一次性写入锁后只读;键面归一——锁定线终态单写,禁物化链写端覆写 |
| `opening_recipe_comp` | P1 配方物化链(方向节拍贵段;物化源 = 过渡候选槽**无门控首位**——空窗期恒有最强方向,不随 p1_pair 门控变 None) | 开局面数据源(M5/P1 部署);未冻结期每轮随支持度事件可换,冻结后 = 冻结对,进 P2 清空;与锁定线槽互不覆写 |
| `transition_candidates` | 配方链重算(`update_p1_recipe` 的 st 写端,每 game-round 覆写一次;进 P2 `clear_p1_recipe` 同点清空) | 过渡候选槽(体系对 top3 有序元组;序 = 候选排序键;冻结后 = 单元素冻结对;无羁绊开局合法空——冷启动臂承接,[11_shop_decisions.md](11_shop_decisions.md) §1) |
| `line_candidates` | 候选重算(随签名;证据门开启版) | top3 实候选快照(派生);锁定写入后清空停算 |
| `ist.locked_comp` / `ist.phase` | `_sync_derived_lock_cache`(refresh/锁定动作同帧同步) | kernel/跨画面只读消费的派生缓存,非独立状态源 |

- **前置段 `refresh_line_if_needed`**(备战/商店两决策入口各挂同一前置函数):拼证据签名(持有名单 + 装备持有 + 投资效果集 + 等级 + 节点号 + 环境分级 + 锁定态)→ 签名不变幂等跳过 → 变化则重算候选快照并检查锁定条件(未锁定态;命中经 `write_line_lock` 写入)。节点号变化时签名必变 = 节点边界重算入口(边界重置清单 = [22_prep_screen.md](22_prep_screen.md) §3)。
- **读口**:`line_members_view()` = 锁定线名单视图(未锁定返回空名单 + 未锁定旗标,两域据此走件级评估路径);`direction_comp_of()` = 现行方向组合读口(锁定线优先,未锁 = `opening_recipe_comp`;两键都空 = 无方向,K 空窗回退承接)。消费面分派:终局名单消费面 → view;开局面(M5/P1 部署)→ `opening_recipe_comp`;备战工序与商店会话消费同一视图,禁各自维护第二份名单口径。
- **锁定写入连带动作(唯一所有者 = `write_line_lock`)**:①清商店会话标记(`shop_handled`——下一轮按锁定线名单重开会话全量评估);②候选快照清空并停算。装备定向属锁定效果非连带件。(旧「清升级授权键」连带件已随 2026-10-17 迭代 T-4 键退役删除——判据同帧重评后无跨帧授权可清。)
- **committed(已定型/非双轨期)判定** = `cw_intention.committed_authority`(方向层单一派生源):权威序 = ①锁定线槽非空(锁定语义,P1 硬规则锁定与 P2 时点兜底统一承载)②`p1_pair` 配方锁非空(p1_pair = **门控候选首位**:首位对级支持度 ≥ `P1_PAIR_LOCK_MIN_SUPPORT` 才写,否则空对——与旧派生含支持度回落帧逐帧等价,§3);缺供给帧保守侧 False;全部消费点经它或唯一读端 `committed_from` 取值。P2 入口至兜底锁帧之间的短窗 committed = False(双轨期口径)。
- **K 空窗回退**:无方向帧(两键都空)的部署围栏目标供给 = `cw_intention.k_empty_window_fallback`(回退单一源,P1 未锁帧配方方向经 direction 读口承接、P2 未锁短窗 p2plus 带恒合法空集 = 保利息缺省;p1 两带〔p1_gap/p1_lock_band〕回退保留在役——p1_lock_band 支现算源 = 候选首位成员〔候选机器同源,禁双源〕;禁消费位复制兜底逻辑)。
- 框架事实:帧代次双槽(`gs.frame_class_prep`/`frame_class_shop`)写点保留在 operations 侧(方向重估触发标注),读侧消费方向视图。

## 3. P1 配方对链(候选制)

未锁定期的 P1 方向由**体系对候选机器**承载(kernel 驱动 = `cw_intention.update_p1_recipe`,flow 方向节拍贵段调用;`clear_p1_recipe` 进 P2 退场清键——同点清空 `opening_recipe_comp` 与 `transition_candidates` 并置读口守卫)。判据 = **候选排序键纯函数**((对级支持度降序, 对级声明序))——确定性由排序键承载:支持度 = 羁绊计数/档,事件驱动变化(买/卖/合成),帧间稳定无连续值抖动;防摇摆语义 = 支持度不变则序不变(旧四层谓词族〔在任优先单席易手/排序维星级当量选席/渐进 argmin `e_rounds` 估计器/换席可行性门 E≤R_rem〕已随候选制退役——退役登记 = math_proofs P-T166 行,考古走 git 历史)。

- **候选空间与评估**:体系对 = 四体系(`_P1_PAIR_PREF`:仙舟/持续伤害/列车同行/希儿系)的单体系对(4)+ 双体系组合(6);**对级支持度 = min(各席席级支持度)**(木桶语义——和/均值使单席满的对虚高),席级函数现行零口径改动(只吃真实持有);支持度 > 0 的对按候选排序键取 top3(`_P1_PAIR_CANDIDATE_TOP_N`,与终局候选数同值复用【拍】)写 `transition_candidates` 槽;**希儿系对入候选门槛 = 席级支持度 = 1.0**(单卡希儿 0.5 不驱动方向,旧 Q 门槛同值);对级声明序 = 各席体系在 `_P1_PAIR_PREF` 的索引组成元组的字典序(短元组同席补 ∞——同首席的双体系对排在单体系对前,更完整方向优先;零新常数)。无羁绊开局候选空(合法形态,冷启动臂承接,[11_shop_decisions.md](11_shop_decisions.md) §1)。
- **p1_pair = 门控候选首位**(派生态):首位对级支持度 ≥ `P1_PAIR_LOCK_MIN_SUPPORT` 才写,否则空对——committed ⟺ p1_pair 非空 ⟺ 首位支持度满,与旧派生**含支持度回落帧逐帧等价**(§2 committed 行);渐进第二席职能由候选并集承载(第二体系件经候选并集买进,不再产渐进 2 元对)。

- **冻结语义**:「凑齐」= 板面两两组合成型(kernel 成型线 form_ok)达成即事件标志位冻结方向(`p1_pair_frozen`——冻结的是方向不是板面,买入/部署继续服务冻结方向);**冻结评估域 = 全候选空间中对级支持度 ≥ `P1_PAIR_LOCK_MIN_SUPPORT` 的双体系对全扫描**(枚举载体 = 候选机器同源排序函数不截断,超满对先于恰满对;取 form_ok 首个;**单体系对不进冻结域**——「单体系锁停」死锁结构性免疫);冻结后候选槽写单元素(冻结对,读端零特判);解冻闭集恰两项 = 超窗出口(`_p1_pair_overwindow`:E > R_rem,解冻 + 封印该对防逐帧空转环)/位面末(P2 移交);超窗解冻状态机与再闩封印对双体系对零改动。

## 4. 未锁定期买面接线

未锁定期(无目标期)的资金与买面语义:K 名单源 = **实候选(证据门版)三线成员并集 ∪ 过渡候选各对成员并集**(与序 1 义务面同一份名单,判据单一源 = [11_shop_decisions.md](11_shop_decisions.md) §1;P86 三分支判据现状 = math_proofs P86 行退役注记——甲/乙臂退役、丙臂保利息缺省在役):

- **保利息缺省(P86 丙分支,唯一在役分支)**:无候选帧零买入(`k_empty_window_fallback` p2plus 带恒合法空集;p1 两带回退保留在役——防「K 空 → 零买入 → 支持度永不涨」死锁环);付费刷新由三段式刷新判据 fail-closed 拦截(P1/无合格缺口恒不刷);升级既有授权不冻结(辖域切分承继)。
- **锁定帧买侧目标约束基准** = `locked_buy_scope`(P1 配方锁定帧 = **过渡候选并集**〔`transition_candidates` 槽透传——非空边界 = 候选非空(任一体系 >0 即约束),(0,1) 支持度带从无约束翻转为并集约束:有倾向即约束机会买〕∪ 锁定线 `_line_hoard` 角色采购集;两者皆空 = 无锁定帧不约束)与 `locked_buy_membership`(义务面身份判定;配方支**维持 p1_pair 直读**——与 scope 刻意分层:M2 义务面 = 锁局承诺面,p1_pair 单满 1 元对形态使 P1 ①锁局 M2 义务集收窄至冻结方向)。
