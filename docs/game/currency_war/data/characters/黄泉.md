# 黄泉

## 档位 id=1308 3费 Front

![icon](https://act-webstatic.mihoyo.com/darkmatter/hkrpg/prod_gf_cn/item_icon_u47dee/d85b0abd33aa5d505afb2e499dafeed6.png)

- 羁绊【巡海游侠】:【巡海游侠】们获得和。若将【巡海游侠】放置于后台，则位于后台的【巡海游侠】的星级会使前台【巡海游侠】额外获得和。
- 羁绊【减益】:【减益】队员的前/后台强度提高，行动时使敌方陷入负面效果时，为随机目标附加【离火】，使其造成的伤害降低，并且被攻击后受到额外伤害。

#### 技能 飞雷紫(输出)

- ★ 对陷入负面状态的敌人额外施加标记，终结技消耗标记额外造成伤害。
- ★★ 对陷入负面状态的敌人额外施加标记，终结技消耗标记额外造成伤害。
- ★★★ 对陷入负面状态的敌人额外施加标记，终结技消耗标记额外造成伤害。
