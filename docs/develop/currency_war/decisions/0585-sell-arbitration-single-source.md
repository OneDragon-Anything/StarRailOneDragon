## 1. 背景与归层(跨件半问升级)

**归层**:决策层——卖出资格判定的「排除装配」语义;不是识别 / 执行 / 遥测层。

**跨件半问判定**(同族修法出现第 2 件,升级架构级设计件):Z1(ADR-0580 规则②卖出资格集排除)的落地审修复(义务基座宽窄解析单点化)是本族第 1 件;prep_loop 攻击报告 F1(锁线定型清空动态登记)/F2(funding 有意不扩)与 shop_sell 报告 W1(②(b) 买入↔funding 同 visit 卖回)/W3(锁线帧清空→凑息卖回漏口)/W4(M4 可卖③④持有件)为同根四案,W8(prep 域发射载体缺 reason 字段)伴生——同一架构根(排除装配语义不一致)在多通道多点反复发病,按根源两问升级为单一源设计,禁第 3 件症状补丁。

**现状证据**(方案 v3 §1.1 消费位全表;9 发射位+1 投影读位经审查独立重数零漏网):

- 4 个卖出通道函数(`sell_for_interest` / `funding_support_sell` / `fuel_sell_candidates` / `line_switch_sell`)×9 发射位(mandate.py:569/648、shop.py:743/844/1716/1760、entry.py:504/763/800)+投影读 1 位(shop.py:626-636,P56 可变现息线投影);
- 排除装配在 7 个调用点各自手搓,共 5 种互不一致形态(`sell_hold_exclusions` / `buy_members` / 空 / 无参数 / 结构自限);
- 12 个买入臂(BuyCard)发射位中仅 ②(b) 一臂有排除性登记,且只传导到凑息通道——「新买入臂发射不自动传导至全部卖出通道排除面」;
- 发射载体双轨:shop 域四位发 `cw_state.SellBench`(有 reason 字段),prep 域五位发 `kernel/cw_prep_actions.SellBench`(仅 `slot` 字段,cw_prep_actions.py:70-73)。

## 2. Considered Options(关键裁决摘录;全量=方案 v3 三轮审)

- **逐调用点补齐 vs 单一装配**:✓单一装配——排除语义收拢为单一入口 `sell_exclusions(session, k_members, *, channel, current_round)`(新模块 sell_gate.py,现装配点平移+mandate re-export,通道判据本体纯函数零改);逐点补齐=每个新通道/新臂再同步一次,是症状修法。
- **职责切分一句话**:通道保留「何时卖 / 卖多少 / 卖序」(触发、止盈、排序、特有禁令),A 独占「不许卖谁」,投影读端消费「与 interest 同一的全资格面」。
- **Z1 处置=吸收非推翻**:装配点单一性与静态/动态切分原样成为 A 构件;「(b) 买入名永不回卖」的 Early 期意图被 P78-3 精确化为「压库类买入登记轮内不回卖」(supersede 关系,非推翻)。
- **F2「筹资卖出有真实对价、有意不扩」拆三块修订**:原则保留但辖域收窄至「非同 visit ∧ 非压库登记活跃」(同 visit 域被 P78-1 定义性证伪);义务基座必须并入(entry 两处空装配=F2 未辖的未申报面);③④持有件变现保留为显式兜底豁免(P78-5 四条件+P78-5′ 授权),从隐式同池竞争降级为最后手段。
- **P78-5′ 入册形态**:按 V3-04 精化——撤 ⟺ 改条件式重述(必要条件两腿+充分授权分离),达成量化降为 P78-5 条③机制授权条款,M4 腿=实现依赖申报;审查建议「降格为备注性原理」不采纳(精化后命题分层干净:必要条件=概念层【推】,四关系表=应用层)。
- **W5 本体不入本批**:2★ 转线件星过滤属买面门槛;本件只承接登记侧断言(名∈静态持有集 ∧ 该层买入硬闸通过;违例=登记红+拒登记,不拦发射)+矩阵格(通道物理谓词完备性)。
- **发射登记载体**:登记簿合一({名:(买因,轮)});`LaunchCause` 闭集={obligation, hold, press, stall_protect},12 个买入臂逐一映射(ev_buy→press 为补漏修正;非注册表持有臂扩展协议=「扩注册表=扩类」,禁绕断言手登记)。
