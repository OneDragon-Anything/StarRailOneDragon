## 0. 一句话设计

需求驱动的**店条件化买牌信号**:只有当店里出现「能完成/强化已拥有结构」的件时才给该候选一个**金额经过校准的评分抬升**——三形态(配对完成/升星完成/引擎缺口),e<2 辖域,e≥2 熄火,金额=既有成型跳变金账(engine_jump_gold)减真实息损,与 EV 过滤/W471 义务预算按固定合并序消费。

## 1. 信号定义

### 1.1 记号与状态源(全部为 decision_v2 在产字段,零新状态)

- `owned` = deployed ∪ bench(角色名集合);`cnt(name)` = 同名张数(1★ 张数口径)。
- 体系 S 的持有度 `s_S` = owned 中 S 体系成员名的**去重个数**(羁绊按不同单位计数,同副本不叠)。
- 四体系阈值与成员集(单一源 = `transition_combos.md`,实现侧单一源 = `cw_deploy_logic.TRANSITION_TRAITS`,与 `_cand_system_bonds` 同源):
  - 仙舟3:t=3;完成件集 = 功能链三人组 {爻光, 藿藿, 丹恒·饮月}(95% 帖证据);非三人组仙舟名(忘归人/彦卿/景元/符玄/青雀)**不入 S1**,只可入 S3。
  - 列车2:t=2,无人员要求;成员 = 列车同行名(三月七/丹恒·饮月/星期日/姬子·启行)。
  - DOT2:t=2,无人员要求;成员 = {艾丝妲, 椒丘, 卡芙卡, 桑博}。
  - 希儿系:门槛 = 希儿在场 ∧ (量子≥2 ∨ 贝≥2);**前置 = 希儿已持**(单卡依赖,无希儿时量子/贝件不成完成件)。
- `e_cur` = `_engines_formed(state)`(整数引擎数,scoring.py L844,与 board_rung_x 同源)。

### 1.2 三形态触发判定(精确条件)

**S1 配对完成(最高优先)**
```
fire_S1(cand) ⟺ cand 是 BuyCard,cand.name ∉ owned(新成员,非 dup)
  ∧ ∃S: s_S ∈ [1, t_S − 1]  ∧ cand ∈ S 的完成件集
  ∧ 买入后 s'_S = s_S + 1 ≥ t_S          # 本笔金当帧跨档(e_S 0→1 或 1→2)
  ∧ (S = 希儿系 ⟹ '希儿' ∈ owned)
```
语义:已持某过渡体系 1 件、店里出现同体系「补齐档位」的另一件——激活在望且**当帧兑现**。仙舟3 特例:s_仙舟=1 时只有三人组名是完成件(s=2 买第三人跨档);非三人组仙舟名买了不跨档,不 fire。

**S2 升星完成(次优先)**
```
fire_S2(cand) ⟺ cand 是 BuyCard,cnt(cand.name) ≥ 1(已持同名片)
  ∧ cand.name ∈ CORE_NAMES = {爻光, 藿藿, 丹恒·饮月, 希儿}   # 功能链+单卡依赖;列车无核心(用户 2026-08-24 定调)
  ∧ 买入后 cnt ≥ 2(2★ 完成方向)
```
语义:成型三件套的「核心 2★」门([13] 口述,transition_combos §各组合核心);W473 LI-1 实证 r4 前到手 2★ 数 4/4 分离成局与败局。

**S3 引擎缺口兜底(最低优先)**
```
fire_S3(cand) ⟺ e_cur < 2 ∧ _cand_is_engine_piece(cand)(scoring.py L852 同源)
  ∧ ¬fire_S1 ∧ ¬fire_S2
```
语义:engines<2 且店中出现引擎件——不保证当帧跨档,只保证买的是体系件而非散件(⑮ 型散件采购的直接挡板);优先级与金额最低。

### 1.3 优先级与金额排序

同一帧多形态同时 fire 时,按每金期望边际值降序取,单轮消费上界 = 2 笔(容量界,防 W469 式行为漂移广度失控):
```
rank = engine_jump_gold(e_cur, ...)  − real息损(int_emb)     # S1/S2 逐帧金账
S1 > S2 的来源:S1 跨的是引擎档(P20 主对象,e0→1 净增 ≈ 散件升星 2.6-2.9×),
S2 跨的是核心星级门(P20 辖界内的「核心升星」,属成型三件套而非散件升星);
S3 金额 = S1 公式的下界代理,且仅当 val≤0 需要顶正时用(见 §2)。
```

### 1.4 辖域(P1?成型后是否熄火?)

- 位面:P1 专属(P20 辖域 = 位面 1 过渡期;P2 成型语义换血,由终局线辖)。
- **熄火条款(硬性)**:`e_cur ≥ 2` 或 form_ok 三件套为真 ⟹ 三形态全部 off——P20 边界(e≥1 激活边际衰减、e≥2 档位耗尽)+ [13] 过渡成型停手线。成型后由 formed_stop/SPEND 相位接管,信号不得复活(W469 教训:先验成型后仍持续在场推目录放血,⑯ P1r6-r9 金 41→80 的实证病灶)。
- 不越权集(与 early_pace 同例外集):emergency([18] hp 报警覆盖态)、boss 窗不加码、war 模式不辖。

## 2. 优先级幅度推导(数学先行,不给拍值)

### 2.1 每金边际激活概率:信号 vs 先验的一般式

单位金花在一张体系件上的期望边际战力:

```
E[margin] = V × q − C
  V = P20 激活价值(次战胜率跳变的金折算;P20 已证量级阶 2.6-2.9× 于散件升星)
  q = P(这笔金跨越一个激活档 | 买它)
  C = 机会成本(息损或 D 刷金)
```

**catalog 先验(被删链)的 q**:先验对 focus_names 全集候选同价给分。给定一帧店,k = 店中 focus 名件数,c = 其中**当帧跨档**的完成件数。买其中随机一件的 q_cat = c/k。W425 实测每店期望 ≈1 张配方件,而任一时刻 s_S<t_S 的体系通常只有 0-1 个完成位 → c/k 系统性 ≪ 1;买到的非完成件是「未来才兑现的期权」,其兑现概率 = 未来刷新出补齐件的概率 × 未来仍有金买它——而 ADR-0092/P5 已证**刷新独立、观察无预测力**,期权的 q 无信息支撑地接近「平均店况基率」,即又一个 c/k。两级 c/k 相乘,先验金的期望边际被结构性稀释。

**本信号的 q**:fire 条件**按构造**就是「当帧跨档」→ q_signal = 1(S1/S2);S3 诚实标注 q<1(不保证跨档),金额相应取下界代理。每金边际:

```
E[margin | fire_S1] = V × 1 − C  vs  E[margin | 先验买] = V × (c/k) − C
精度比 = 1 / (c/k) = k/c ≥ 1,严格大于当 c < k(几乎恒成立)
```

这不是口号:W469 的守卫(出口金 −1.87,CI [−3.25, −0.51] 显著负)配合主判据三零改善,正是「q_cat 很低时多花的金换不到质量」的实验测量;本设计把 c/k 的损失从机制里按构造拿掉。

### 2.2 bump 量级推导(消费既有校准账,零新常量)

信号抬升只在候选分 `val ≤ 0`(被「非正分」门拒)时施加,金额:

```
B(cand) = max(0, engine_jump_gold(e_cur, state, registry, session) − int_emb(cand))
val' = val + B,仅当 val ≤ 0 ∧ fire;val > 0 的 fire 候选不需要抬升(排序已胜出)
```

- `engine_jump_gold`(scoring.py L537)= 下一档引擎跳变金值(Δrung×跨位面剩余节点 + Δwin×条件败局伤害×hp 金价×剩余战斗节点),已过 ADR-0425/P15 骨架值治理与 P20 量级背书——**bump 的上界=真实成型跳变账**,不是新拍常量。
- `int_emb` = 该候选实际嵌入的息分量(ADR-0332 平滑后的真实档损,scoring.py L1002)——bump 内减息损意味着**净账为正才顶正**:息损 > 跳变值时 val' 仍 ≤ 0,买被正确拒绝(信号不构成破息借口)。
- S3 无独立金额:`B_S3 = 0`(S3 只做层内排序偏置,量级沿用既有 forming_bias/goldrich 偏置的通道语义,不叠加);只有 S1/S2 用金账 bump。理由:S3 的 q 未知,给它金账金额就是把期权按兑现价卖——正是 W469 死因。
- 与 W451 m∈{1.0, 0.5} 的区别:那两个是**符号设计常量**(W469 G2 挂账未标定即死);本 bump 是**逐帧金账输出**,常量只剩一个 A/B 注入开关与单轮笔数上界(结构界,非数值标定)。

### 2.3 与 EV 过滤、金预算(W471 义务)的合并语义

| 层 | 语义 | 信号的角色 |
|---|---|---|
| EV 过滤(非正分门 + interest_rule) | 负 EV 件不买;金账单一源 = arbiter.interest_rule | **不豁免、不覆盖**:bump ≤ 真实跳变账,息损内嵌,净账为正才过门;信号只是把「账为正但差分未显影」的完成件显影(cap 饱和/冗余档位下 base==after 差分恒 0 的 ADR-0301 残余病灶) |
| W471 义务(溢余段强制转化) | 义务 = max(既有臂, min((g−R*)+, C_t));义务管「花不花」 | 信号管「花给谁」:义务帧(g>R*)内息帽截断 → int_emb=0 → 信号件的净账自动最高,**成为买通道内 C_t 的首选消费对象**;非义务帧(g<R*)信号照付息损,息线以内行为零漂移(零漂移锚) |
| ADR-0369 P1 pair 缺件找牌通道(_vd_p1_pair) | 店里没有 → D 找,成本 = E₁×刷价 | 同一完成度账的**买/D 两臂**:店里有(信号,E₁=0 零刷新成本)优先于 D(E₁≥1);合并 = 信号 fire 的缺件从 _vd_p1_pair 的 missing 集中排除,防同一缺件双臂重复计账 |
| ADR-0332 forming_bias | r≥5 引擎件小额常量偏置 | 条件更严(跨档才 fire)、账更准(金账非常量)的上位替代候选;过渡期两者并存时 forming_bias 先行、信号后加(同偏置先行序),A/B 可分臂测替代 vs 叠加 |

### 3.1 逐条对比

### 3.2 诚实面:同型风险(不掩盖)

1. **最深同型点**:两者都是「P1 多买过渡件」干预,方向同源。若 sim 供给使完成件高频出现(W425:每店期望 1 张配方件;四体系成员并集不小),k/c 比可能远小于直觉 → 区分论证退化。**防线**:fire 率 sanity 带(§4.3)——触发帧占比 >35% 判「精度主张失效」,按预注册降级处理,不硬着陆。
2. **q=1 的构造性依赖**:S1 判定依赖体系成员集与 owned 识别正确。sim 内为构造真值;实机落地时 OCR 误判会让假 fire 拿真 bump——落地批须把 fire 判定列入判读面与单帧锁。
3. **P20 V 值的属性**:观测性标定(非随机对照),是量级阶不是精确值;bump 取其金账形式做**上界**使用(净账为正的门槛判断),不依赖其精确倍数——即使 P20 高估,后果只是 bump 不足、买被拒(保守侧失效),不是错误买入。
4. **⑭ 型冻结买入**(FORM 期零买入)是本信号的直接目标病灶之一,但⑭ 的根还含「posture=升级+D6 不产生买候选」的姿态层面——信号只修「候选在而分不正」,不修「候选不在」;若 A/B 显示 fire 率过低,病根在候选生成层,届时按 W473 N1 的候选扩展路线另案。

**硬门结论**:六个维度中 1/2/4/6 是结构性区分(触发条件、概率构造、熄火、可测性),3/5 是强度区分;§3.2 的退化路径已预注册。论证成立,**本设计不降级为数据采集提案**;但 A/B 判据(§4)同时承担「区分论证本身的检验」——fire 率带被突破即视为同型风险坐实。

### 4.3 fire 率 sanity 带(区分论证的运行时检验)

- <3%:机制近乎惰性(≈W461 孤写 nil),判「行为未生效」,不计入主判据成败,报告为候选生成层缺口(§3.2 第 4 条)。
- 3%-35%:有效域。
- >35%:k/c 精度优势不可信(§3.2 同型风险坐实),即使主判据显著也判「同 catalog 同型」,不采纳入产。

### 4.4 统计口径

配对 bootstrap(≥20,000 次)+ McNemar(二值主判据);分位面分层(P1/P2、fire 率分桶);全部逐局数据落台账可复算(W474 手法:第三方可独立重算)。

## 5. 生命周期结论(开关与失败退出)

- **不设生产策略开关**。生命周期门判:唯一合法理由 = 行为输入未就绪——本信号全部输入(owned/bench/shop/engines/概率表/金账函数)已在产且标定,无「待就绪输入」;效应未知走 A/B,不是开关理由(W471 §3.4 同判)。A/B 用 registry 临时注入臂,不进生产;设计本身零落码,失败退出零删码成本。
- **失败退出条件(预注册)**:
  1. 活性惰性(fire 率 <3% 或漂移=0)→ 设计撤回,病根转候选生成层另案;
  2. fire 率 >35% → 同型风险坐实,设计撤回,诚实记「配对完成度在当前供给密度下不构成可区分信号」;
  3. 主判据不显著(451/臂)且兑现率 <50% → 精度主张证伪,设计撤回(§3 硬门结论作废,补记同型风险成立);
  4. 主判据显著但守卫死时带金显著恶化 → 不入产(与 W471 义务模型冲突,义务帧外多花钱=死钱换位非消灭);
  5. 主判据显著、守卫全过、兑现率 ≥50% → 进入落码批(三同步:ADR + as-built 语义 + 代码注释引 ADR)。
- 不与 ADR-0442 复活条件冲突声明:本信号是**采购判据**,不是跨轮终局线信号累积器,不触发 framework_startup 复活前置;立项时须由编排者向 W474 对抗审计方通报,回避「换皮复活」攻面(W473 N1 既定程序)。

## 7. 风险与最弱环声明(结论强度 = 最弱一环)

| # | 环节 | 强度 | 弱点 |
|---|---|---|---|
| 1 | 每金边际概率区分式(§2.1) | 强 | q=1 是构造性结论;c/k 的实际值未从 W469 台账直接数出(可事后复核:焦点买向中跨档占比)——诚实标注为「结构性不等式 + W469 守卫间接测量」 |
| 2 | bump 金账(§2.2) | 强 | 全部消费已校准函数;engine_jump_gold 本身的 Δwin 参数是观测拟合(P15 同源偏差) |
| 3 | 三形态触发判定(§1.2) | 中强 | sim 构造真;实机 OCR 误判风险后置到落地批;希儿系双门槛(希儿+放大器)判定分支最多,是误判概率最高点 |
| 4 | **效应量预估(+10pp)** | **最弱** | 来自 n=4 实机方向级(LI-1 4/4 分离)+P20 倍数外推,非任何 sim 实测;n=451 对 +7pp 仍有 ~80% 功效(n≈372 对应 +10pp@30-35% 基线;+7pp 需 ≈700)——若真实效应 <7pp,本 n 判不出,届时按「效应真实但小于可检域」如实报告,不得用不显著冒充证伪(W474 措辞纪律) |
| 5 | 供给密度假设(fire 率带) | 中 | 每店期望 1 张配方件是 W425 实测,但「完成件子集」的帧级分布无现成统计——这正是 sanity 带要测的量,带界本身(3%/35%)是最弱的拍值,声明为可修订的分析计划参数(修订须在揭盲前) |
| 6 | 与 forming_bias 的叠加/替代关系 | 中 | A/B 分臂可测,但若两者交互抵消,单臂结论归因变复杂——预注册主臂 = 替代(信号 on ∧ forming_bias off),叠加臂为附 |

**全文最弱环 = §7-4 效应量预估**(n=4 方向级外推)。裁决含义:本设计的主张强度是「机制值得一次功效充足的检验」,不是「机制已证有效」——后者正是 §4 A/B 要回答的问题。
