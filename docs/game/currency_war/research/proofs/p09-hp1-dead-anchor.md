# P9 死局判据锚(0hp 保底 1hp)——机制命题

> 状态:**机制命题(整理,非证明)**;⟺ 双向断言已按审后修正收窄为保守锚
> 数据源:gameplay 总览「第一次 0hp 保底 1hp」全局机制(2026-08-25 用户口述)+ cw_first_passage 既有结构
> 提出:2026-08-25;整理=W120 批,修正=W122 批(F07)

## 命题(修正后口径)

早停/死局检测以 **HP=1 为候选锚线**是期望合理的。

~~HP=1 ⟺ 保底已耗尽~~(**2026-08-25 审后修正,原双向断言超出机制事实**:HP=1 不能区分「恰好剩 1」与「保底后剩 1」——普通伤害也可能恰好落 1hp 而保底未用;保底触发后也可回血到 >1。正确的单向陈述见下)。

## 论证

- **机制事实(无争议部分)**:保底一次性——第一次掉到 0hp 剩 1hp;保底已耗尽后,再次归零=整局结束。
- **保守锚**:HP=1 且保底状态未观测到时,按「保底可能已耗尽」处理是**保守侧**(早停候选标记,不是直接停局);若遥测可观测「保底触发事件」,锚线收紧为「HP=1 ∧ 保底已触发」。
- **期望账**:继续局的期望净值 = P(后续全胜)×通关价值 − 时间成本;HP=1 且板面非成型(H3:e2 胜率 77.8%、e1 41.6%、e0 13.9%,剩余节点≥2 时 e0 板全胜概率 <2%)→ 期望趋 0,只剩时间成本 → 早停合理。
- **HP=1 是候选线不是触发线**:HP=2-5 同样濒死,早停判据应联合板面档位与剩余日程(cw_first_passage 已有该结构),本条只锚定「HP=1 时保底资源可能已尽」这一保守下界。

## 对实现的检验点

run 监控侧 HP=1 的局应触发死局/早停**候选标记**(checks 族),不继续按常规节奏跑完整局;标记≠自动停局。
