## 1. 门① 内部推导(卖出主式 + V_opt 结构)

**判定:过(带两条已声明残余张力,不构成推翻)。**

- **V_opt 主式 `u·P_miss·C_rescue` 逐步核**:三通道分解(自然再遇免费/急 D 补救 `c_eff/P_shop`/截止 A7 只声明 ≥0)逻辑自洽;C_rescue 用 k=1 期望刷次 = 1/P_shop 的闭式与 DP 一致(见门②对账)。**独立重算全表命中**:五档 × L7-L10 全 20 格,我方脚本与证明表差 ≤0.05 金(末位舍入级),含非平庸读数(低费随 L 升、L9 全链倒挂 3费 9.4>4费 5.3>5费 3.2)逐一复现。
- **卖出主式** `refund + V_slot > max(V_opt, V_ms·ΔP̂·[x∈K]) + V_power`:三处同形(命题/推导/脚本 S-b2)确认。max 的辩护(「一次弃购 K 内件两账同发,取大者防双计且不低估主项」)成立——max 是保守下界,方向正确;K 外件退化单通道自洽。
- **V_power 项处理**(点名攻击项):证明原文明确「不货币化,只声明 ≥0」,置于不等式右端——**按 0 计价 = 判据偏松(多卖)**,证明自己完成了方向分析(「反了:偏松=多卖→与 [22] 囤件纪律反向」)并用分类护栏(骨架/贯穿不卖)兜住。数学上这是已知缺省而非隐藏缺省,披露合规;公理定性见门⑤。
- **残余张力 A(已声明)**:L7 5费 C_rescue=360.8 超常态金位 6 倍——按证明自己的金可行性截断规则该通道应被剔除、V_opt 塌缩到 A7 下界,但表值 51.2 仍按该通道计并被 p46 消费。A4 双侧声明覆盖了方向(囤侧保守/经 E_rev 传导的经济侧不保守),但「表值依赖不可执行通道」这一点应在消费处显式带截断提示,列为修正建议 3。
