# 真理医生（虚数·巡猎·5星）

> 按 V4.7 期撰写。负面驱动追击：敌人负面越多，追击概率与伤害越高；**绑定负面施加队友**。

## 一、命途属性与技能说明

**命途**：巡猎；**属性**：虚数

| 技能 | 说明 |
|---|---|
| 普攻 | 单体75%攻击虚数伤 |
| 战技 | 单体75%；天赋40%固定概率追击135%（**目标每1负面+20%概率**） |
| 终结技 | 消耗能量；单体144% +【智者的短见】：队友攻击该目标 → 真理追击（2次） |
| 天赋 | 上述概率追击机制——负面越多越稳 |
| 秘技 | 进战挂负面（妨害） |
| 额外能力 | **B1：目标3+负面 → 每负面+10%伤害（上限50%）** |

**资源与循环**：标准能量→充能有效。

## 二、推荐遗器与原因

**套装**：风举云飞的勇烈4件 + 毁烬焚骨的大公2件【攻】
**主词条**：躯干暴击率/暴伤；脚部速度；球虚数伤；绳充能。**副词条**：双暴>攻击>速度。

## 三、推荐配队与原因

| 阵容 | 为什么 |
|---|---|
| **真理 / 托帕 / 佩拉(或银狼) / 生存** | 负面辅助保追击概率+增伤；托帕追击联动 |
| 无负面环境 | 追击概率与增伤双降（净化敌克制） |

**硬否决**：无（但无负面供给时强度打折）。

## 星魂档位

- E1：追击后负面延长；E2 终结技真伤；E6 负面增伤上限提高（质变）。
