# ADR-0217: 过渡框架启动判定纳入商店在售半权(r105)

> 编号注记:本决策原误编 0212/0213(均与既有 ADR 冲突),2026-08-22
> 重编为 0217 让位观测层重构(ADR-0213,代码 14 处引用指向后者)。

## Status

Accepted (2026-08-20)

## Context

局29(run_20260819_202130)判读:用户指出「根本没有过渡阵容」。offer 波实证:
r1-r6 有 4 波商店含框架件(三月七/姬子·启行×2/卡芙卡/爻光),但 bot 全程散买
(11 角色五阵营),hp 45(r7)框架才凑 2 张启动。

根因:`pick_framework` 启动门槛只认**持有件计数 ≥2**。双轨期买牌评分依赖框架
已定(框架='' 时无配方引导)→ 不买框架件 → 持有起不来 → 框架恒''——
**先有鸡还是先有蛋死锁**。死锁期由「压缩买」(cw_plan §7-15 gold 快满买光
便宜牌)接管,板面成大杂烩。

## Decision Drivers

1. P1 前几轮是血线地基(每轮掉 10-13 血的代价)
2. 商店在售件是真实可得信号(买了就持有),不应只在滞后判定里起作用
3. 不能引入 shop 噪声翻转(r72 滞后设计的原语义)

## Considered Options

- **开局固定选主流框架(仙舟)不看成色**:否决——放弃列车/量子局的来牌适配,
  与 r70「按持有计数选」的设计初衷矛盾。
- **降低启动门到持有 1 张**:否决——1 张随机来牌(如单张三月七)就锁框架,
  噪声敏感,锁错方向更贵。
- **shop 在售半权计入启动判定(合并权 ≥2)**:采纳——持有 1+在售 2 即启动;
  纯 shop(1.0)不够格;滞后语义不变(挑战者合并权领先 ≥1 才换,0.5 粒度的
  shop 噪声翻不动持有级差异)。

## Decision

`pick_framework` 的启动门槛从「持有 ≥2」放宽为「持有整权+shop 在售半权
合并 ≥2」;shop 半权从"仅已定框架的滞后判定参与"改为全程计入。滞后门槛
(challenger 领先 ≥1)语义保持。

局29 波次重放:r3 即启动列车(旧 r4),且修正前推演暴露的 r8 现任被仙舟
shop 噪声抢走问题一并消除。
