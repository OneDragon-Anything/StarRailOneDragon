## 1. 背景

T-155(投资选卡重设计)的对抗审查发现两项注册表维护面问题,移交 T-157 注册表维护批定谳:

1. 投资策略卡「大裁员」的免费刷新次数,同一注册表内两个来源互相矛盾:官方效果原文写 6 次,手维护建模字段写 5 次(同表矛盾)。
2. 环境选卡评估头注声称「经济类环境 16/83」(83 个投资环境中 16 个经济类),docs 全树检索不到出处。

## 2. 大裁员 6v5 定谳(结论:免费刷新 = 6)

### 2.1 直调证据链(2026-09-09 注册表 Python 直调)

| 来源 | 层 | 值 |
|---|---|---|
| `data/cw_invest_data.py:134`(base 事实层,`tools/cw/gen_plaza_invest.py` 从米游社攻略广场官方 API 生成,勿手编) | 官方卡文 | 「出售场上和备战席的所有角色，获得双倍价格的金币。获得**6**次免费刷新。」(id=plaza:202101,品质金) |
| `kernel/cw_investments.py:217`(overlay 建模层,手维护) | 结构化字段 | `EconomyEffect(free_refresh_burst=5, sell_price_mult=2.0)` |

单点性核查:free_refresh_burst 的逐卡数值全仓唯一载体 = STRATEGY_ECONOMY(合并层挂载、事件聚合 `cw_events.py:84` 通用求和,均无第二数值源);测试仓无「大裁员=5」锁(仅「乱成一锅粥+=7」锁,test_cw_decisions.py:512,不受纠偏波及)。

### 2.2 定谳与依据

- **结论:大裁员免费刷新 = 6。** 依据 = 数据源权威序 **base 官方文本 > 手工 overlay > 文档转述**(BoardState-修订对照表 G5 行显式化的漂移裁决原则;结构依据 = `cw_investments.py` 模块头两层架构说明——base 层是官方 API 直出的生成物,overlay 层是人工建模)。overlay 的 5 = 手建模漂移;成因(笔误或旧版卡文)不可考(overlay 手填无档案;若系版本漂移,生成器 by-id diff 报告会在下次重跑时暴露卡文侧变化),两种成因下纠偏方向相同。
- **玩法文档对账 = 零冲突**:docs/game 全树无任何「大裁员刷新数」表述(research/data 两面 grep 负验证);`proofs/p40-refresh-ev.md` §10 赠刷族只列卡名不列数值。矛盾只存在于注册表内部,不存在第二矛盾面。
- **在册确认**:BoardState-数据结构设计.md §2.7 burst 行与 §3 已按 G5 反转记 6;本轮直调复核与在册表述一致,正文无需改写,仅补本 ADR 持久锚(G5 是对照表行号,ADR-0620 是决策正本)。**指针勘误(2026-09-09)**:BoardState-修订对照表已删除(迁移文档收口,知识已并入数据结构设计.md §3.3.4 数据源权威序与本文),本文即 G5/F1 相关裁决的持久正本,后续引用以本文行号为准。
- **边界**:本定谳裁决的是「数据源应记什么」,不是「游戏实际发几次」的实证——实机/sim 侧免费刷新计数的分键验证(付费刷新与免费 proc 的金币期望差)是运行时记账层问题,挂任务账本 C4 候裁行,本 ADR 不展开第二口径。实证材料在库:`.debug/currency_war/telemetry/matches/match_g_20260828_161135.json` 曾选大裁员,`telemetry/live/invest_cards.jsonl` 有选卡流水,供该线取用。

## 3. 「经济类环境 16/83」定谳(结论:无出处,清理)

### 3.1 定位与出处核查

- **唯一载体** = `kernel/cw_investments.py:1198` ENV_PICK_VALUE 头注:「环境与策略结构倒挂(评估实证):synergy 主导 47/83(阵营定向),economy 16」。全仓 grep「经济类环境|16/83|economy 16」:docs 零命中,仅此注释与过程档案(攻审报告、进度账本)提及。
- **出处**:数对 (47,16) 出自 ADR-0144 的环境全量评估产物 `env_eval_full.tsv`(TSV 评估口径)。该产物已灭失(仓库与 workspace 均无此文件)。ADR-0144 本文只承「synergy 主导 47/83」与「yes-direct 仅 1 条(蓝海)」;「16」在任何持久文档中无记载。
- **注册表现值(2026-09-09 直调)**:ENV_CATEGORY 分类 = 概念股 15/邀请 20/契约 7/时代 6/**经济 15**/规则 10/专家 10(合计 83)。「经济」类 15 张:二手市场/人才引进/人身意外险/增发货币/成功经验/深井角斗场/火药味/特权阶级/红钻贵族/经济严重过热/经济过热/蓝海/蓝钻贵族/过剩经费/长线利好。带 EconomyEffect 属性的环境 = 0 条(与 ADR-0144「环境效果全是整局规则改写,EconomyEffect 结构性装不下」定谳一致)。
- **口径不可混**:分类表口径(经济 15、阵营定向 42)与 TSV 评估口径(16、47)是两套统计基准,即使找回 TSV 也不能互替。「47/83」有 ADR-0144 持久出处,可继续引用;「16」没有任何持久出处。

### 3.2 处置

补出处不可行(源产物已灭失)→ **清理**。申报 = 删除头注中「,economy 16」(最小面);若要保留经济类计数,必须换成注册表可直调口径并注明分类表基准(现值 15/83),禁沿用 16。归代码批候裁(§5-2)。docs 面零载体,无需勘误。
