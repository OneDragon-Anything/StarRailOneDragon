# 无名勋礼-规则说明(nameless_honor_rules_popup)

无名勋礼主面板点右上「规则说明」后弹出的**居中说明弹窗**:背景整屏高斯模糊(主面板的标题/按钮锚全部不可见),与[商店-购买弹窗](store.md)同构——模糊 overlay 会弄瞎底层画面 id_mark,故拆独立屏。弹窗内容为两段规则文本(内部可滚动):「无名勋礼」机制说明(免费轨默认解锁/付费轨两条解锁途径)+「无名勋礼任务说明」(本周任务每周一 04:00 更新)+「重复购买补偿说明」。不锁光标(`pc_alt=false`)。

## 1. 何时出现 + 出口

- **入口**:[无名勋礼](无名勋礼.md)主面板 → 点「按钮-规则说明」(右上,1738,64)。
- **出口**:点弹窗右上 ×(1460,345 实测点击位)→ 回主面板(保留原 tab 态)。

## 2. 内容要点(2026-11-12 实读全文)

- 每期无名勋礼开启后默认解锁免费轨「无名客的赠礼」;付费轨「无名客的荣勋」可经购买「无名客的荣勋」或「无名客的奖章」解锁。
- 任务分本周任务(每周一 04:00 服务器时间更新)与本期任务;勋礼等级到上限后任务不再产出经验。
- 重复购买补偿:荣勋返古老梦华×750、奖章返×1410、荣勋授章返×860(直接返还,不会白买)。

## 3. 识别特征

- **id_mark**:弹窗标题「规则说明」(pc_rect 435,322-640,365,OCR conf 0.9999)——单锚即可:主面板同位区域是等级轨上方空白,无同名文本冲突;唯一风险是其他未建档画面若也有同位「规则说明」标题弹窗会互判,遇到时再收窄。
- 按钮-关闭X(1425,310-1495,380)为纯定位 no_method 区(× 图标,无文本)。
- 弹窗内部滚动:拖拽内容区(y≈380-780)即可,滚到底后滚动条贴底。
