## 开局过渡分级(攻略 77037489 直读)—— 前期怎么活到成型

| 级 | 条件 | 玩法 |
|---|---|---|
| **夯** | 拿到逆天投资策略 | 娱乐星球 / 不等价交换 / 轮回不止 / 本姑娘就是罗刹(双鞋风扇)/ 飞光映月 / 黑塔纪元 / 狸狸的早晨 → 秒选 |
| **顶级** | 配队雏形(主c+2拐+1合适装备) | 丝滑过渡到该主c阵容,前期连胜,血+经济都好 |
| **人上人** | 能打伤害的羁绊(2 个组合) | **仙舟 / 狼狩 / dot / 列车 / 贝洛伯格**(仙舟+dot、狼狩+dot 有强度,鞋加速神君/造物引擎)|
| **NPC** | 经济不错(无质量) | 经济类投资策略(开源节流/商业间谍/被动收入/利息上调/淘金客/奋斗协议)→ 血换经济,1位面boss门口启动 |
| **拉完了** | 都没 | 多次 d 牌找质量 / 忍受连败 / 重开 |

→ **能打伤害的过渡羁绊 = 仙舟/狼狩/dot/列车/贝洛伯格**(bot 前期凑这些出过渡阵容)。学者羁绊(2星小黑塔/艾丝妲/阮梅)+公司羁绊(每节点1金)给少量经济。圣杯任务(凛/闪闪/Saber → 3圣杯奖励)给经济/资源。

## 通用角色(跨阵容,optionality/过渡基础设施)

- **生存**:符玄(单挂保全队,除"正当防卫"外几乎万能)、罗刹
- **通用拐**:知更鸟(加速+弹射器)、花火(战技点)、缇宝(保生存)、星期日/周日(回能)
- **V4.4 新欢愉**:爻光(欢愉队回能,穿鞋频召阿哈)、绯英、银狼LV.999(狼尊)
- **过渡低费**:艾丝妲/黑塔/阮梅(学者经济)、桑博(DoT 过渡权威,P3 乏力)、娜塔莎(2贝过渡)、刃(万能填空)
- **主角**:记忆主(通用主角位,多个 comp 必备)

→ 这些是 `transition_chars` / `shared_chars` / optionality 的数据源(`optionality_score` 奖属 ≥2 comp 的通用角色,ADR 0096)。

## 通用关键装备(多 comp 共用)

- **火力风暴潮**(风暴潮):多输出主c核心(绯英/希儿/黄泉/饮月/双王 Saber/万敌)—— 最高频
- **高周波电锯**(电锯):输出装(希儿双电锯/饮月双电锯/列车/万敌)
- **反重力皮靴**(鞋):速度/拉条(阿雅×2/爻光/闪闪后台/巡击)—— "找鞋战争"
- **永动机**:大招流(绯英每3大赠2大/双王 Saber)
- **冷笑话引擎**:大招/回能(绯英/黄泉/双王 Saber)
- **以牙还牙甲**:反甲白厄专属(×3);**绝对热量**:符玄(双王阿瓦隆邪修 75% 减伤)

## 成型节奏共性(跨 comp,反哺 node_plan)

- **多数 comp 9 人口成型**(上 9 找杨叔/符玄/5费补全);部分(列车/贝洛伯格)8 人口。
- **7-8 级找 3 星核心**(希儿/饮月/Saber/姬子·启行 等主c 追 2-3 星),攒金冲 9。
- **杨叔(瓦尔特)+ 符玄是万能补位**(多 comp 上 9 补这两个)。
- **前期主目标:尽快 50 金吃满息**(少 D,靠过渡/输出核心稳血存钱);血有压力才花钱补强。
- **装备密度决定上限**(限时 AV:输出低=超时扣血;风暴潮/电锯/鞋 是成型关键)。
