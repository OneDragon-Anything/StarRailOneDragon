# 丹恒•腾荒（物理·存护·5星）

> 按 V4.7 期撰写。攻击模型盾+龙灵召唤的存护；与经典丹恒（风·巡猎）并存独立。

## 一、命途属性与技能说明

**命途**：存护；**属性**：物理

| 技能 | 说明 |
|---|---|
| 普攻 | 单体100%攻击物理伤 |
| 战技 | 指定单体【同袍】+全队盾（20%攻击+400，叠至300%上限）；召唤【龙灵】（165速） |
| 终结技 | 消耗能量；AoE 300% + 全队盾 + 强化龙灵（2次行动：追击80%腾荒+**80%同袍攻击附加伤**） |
| 天赋 | 龙灵行动时：解除全队1负面+全队小盾（10%攻击+200）——**带净化的盾循环** |
| 秘技 | 同袍+晕眩领域；进战免费战技 |
| 额外能力 | 「神秀」：战技使同袍攻击+15%自身攻击（**攻击是增益面板**）；D2 同袍攻击时腾荒回6能+龙灵拉条15% |

**资源与循环**：标准能量→充能有效。盾量与伤害全走**攻击力**（不堆防御）。

## 二、推荐遗器与原因

**套装**：野穗伴行的快枪手4件 + 生命的翁瓦克2件【攻：攻击模型盾口径】
**主词条**：躯干攻击%；脚部速度；球攻击%；绳充能。**副词条**：攻击%>速度>效果抵抗。
**不堆**：防御（盾量按攻击结算）。
