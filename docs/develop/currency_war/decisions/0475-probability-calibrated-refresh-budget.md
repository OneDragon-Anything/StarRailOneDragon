# ADR-0475: 概率校准的刷新预算(塌缩带归零 + 有望帧分位帽)

## 背景

`refresh_ev_budget` 的预算式是纯金量式 `min(6, ⌊(g−R*)/刷价⌋)`,与目标
可寻性无关:当前级对目标费档概率已塌缩(无望刷)的帧,溢余仍按 6 刷帽
纯烧——金花掉即灭,不能留给未来帧任意通道,机会成本无法回收。提案面
原文与对抗修订见 `.debug/temp/currency_war/w645_proposal_v2/SPECS.md`
提案 B-v2;落码前重评判定(W720 重评报告,同目录
`w720_overlay_reeval/REPORT.md`)=「照旧实施」:病灶原样存在、与死亡窗
分配器(ADR-0474)零代码冲突,且分配器为归零帧结转的溢余提供了设计
定稿的出清出口(管线整帧零支出帧落入分配器辖域被 P_t 接管),收益兑现
路径比立项时更完整。本批双臂基线=含分配器的当前 HEAD 冻结 worktree
(W720 锚点注记②)。

## 决策

预算式扩为三分量 `min(6, ⌊(g−R*)/刷价⌋, ⌈−ln(1−q)·E_find⌉)`,前置
塌缩带归零腿(求值次序=先归零后帽):

- **归零腿**:锁定核解析帧上
  `refresh_prob(当前级,目标费)/refresh_prob(峰值级,目标费) <
  registry.omega_collapse_ratio` → 预算 0(refresh_ev_budget 合法 0 帧
  第三类)。比值由 cw_shop_odds.REFRESH_PROB 表逐帧导出,ω 是标定字段
  (初值 0.1 占位;网格 {0.05,0.1,0.2},多臂同过判前锁死取最小者)。
  归零的账=塌缩带留金弱占优纯烧(留金保留全部未来期权),不需要息
  成本参与——溢余段息机会成本≈0。
- **帽腿**:q=registry.refresh_find_quantile 为真分位(v1 的
  「q=0.8 覆盖 80%」系分位语义错位:实际覆盖 1−e^{−k}≈55%;真 q 分位
  乘数=−ln(1−q)),E_find=`expected_refreshes_for_card(level, 目标费,
  target_star=2, owned=j)` 有限池精确期望。j=0 时全部 (level,费档)
  组合帽值 ≥39 > 6 刷帽=不绑定;**实测绑定面=E_find=0 帧**(owned≥k
  目标核心已集齐——第 4 份副本不可用,或该级 p=0 出不了该费档),
  sim n=100 探针 1135 帧全部为此类(集中 P2 lv9 锁定核已 2★ 帧,
  计数器反事实授权刷数 6406/实际刷新支出 −29 刷/局均 16.49→16.2)
  ——「目标搜索价值归零帧不再授权刷新」与归零腿同一账理,如实修正
  提案预判的「结构性不绑定」。
- **空帧豁免**:非锁定核帧(意向走兜底链)归零判据恒 False——兜底
  3 费不是真目标,对假目标算塌缩比会缩假目标供给、可能误杀真目标
  搜索量,D1「空帧不缩供给」契约优先。
- **概率单一址(W720 统一纪律)**:两腿概率源=既有牌池概率符号
  (cw_shop_odds.refresh_prob / expected_refreshes_for_card),零新概率
  常数;与分配器 Π_refresh 估计器同源互指,禁第二概率口径。锁组含
  monkeypatch 单一址行为证明与分配器估计器同址结构锁。

## Considered Options

1. **照旧实施(本 ADR)**——前提零损伤、与分配器零冲突、出口更完整
   (W720 判定);理由如背景。
2. 裸结构阈值归零(「差距 ≥2 级」)——否决:拍值,违反数学先行硬门;
   改 odds 表导出比值+registry 标定字段(裁决:去拍值)。
3. 归零判据辖兜底链空帧——否决:与 D1「空帧不缩供给」契约正面相撞,
   且对假目标算塌缩比无意义(空帧豁免,W648 修订块第 1 条)。
4. 「推迟升级」机制叙述——否决(裁决 B-2):升级费在 R* 储蓄段内部,
   刷溢余碰不到储蓄,已排程升级不可能被推迟;真实代价=机会成本,
   辖域内不设停刷判据,跨通道边际比较归通道排序提案辖,本批只做
   供给量校准。
5. 均值乘数形式 `⌈m·E_find⌉`——否决(二选一裁决):分位式语义自释,
   免「均值乘数」新概念。

## 后果

- 行为面:塌缩带帧(默认 ω=0.1 下:4 费目标@lv≤5、5 费目标@lv≤6 等
  低概率带)刷新供给归零,溢余结转由分配器/义务链逐帧重算接管;帽腿
  零行为增量(结构性不绑定,留作 q 重标定接口)。
- 定向刷新车道同判据辖(arbiter 接线点)**挂账**:decision_v2 属分包
  期 5 在飞面本批禁触,接线留分包期收口后补;判据单一址已落 kernel
  (`cw_economy._omega_collapse_zeroed`),届时零新概率口径。
- 验证:契约锁组 8 锁先红后绿(塌缩归零/ω 严格小于边界/求值次序/
  空帧豁免/帽公式手算/预算值域/概率单一址行为锁/分配器同址结构锁)
  + w633 穿透锁组补第三类与豁免用例 + registry 字段面锁登记;
  sim 双臂绝对指标(n=100/臂,种子窗 640600-640699,off 臂=HEAD
  冻结 worktree)结果与本 ADR 同批归档于实施批报告
  (.debug/temp/currency_war/w721_overlay_b_impl/REPORT.md)。
