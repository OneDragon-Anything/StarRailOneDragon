## 机制(怎么 work)

白厄靠**拉条反复让敌人攻击自己**,触发**以牙还牙甲(反甲)的巨额反伤**。需要敌人**频繁出手**(所以禁用延迟敌人行动的角色如 **阮梅** ❓克律)。

**反甲倍率可叠加、对白厄无稀释**:第 2 件反甲 +100%、第 3 件 +50%。→ **核心出装唯一解:三反甲**,任一件都换不下来。
- **三反甲白厄成装面板参考**(BV1U2y3BdEAd《红绿灯和反甲白厄苦命鸳鸯》V3.7 转录):三星白厄满 3 反甲 = **100% 幸运一击率 + 50% 伤害增幅 + 110% 幸运一击伤害**(「究极完全体三反甲白厄」)。

## 红绿灯 counter 与解法(★关键)

- 白厄反甲**最怕「红绿灯」**(以及「电视机」—— 频率限制类怪)。
- **解法 = 刷开局**:货币战争每局从 7 种小怪里**固定选 3 种**,本局名单在**开局每个 boss 页面点进去就能看到**。若本局刷到红绿灯/电视机 → 直接重开;若开局没看到 → 这把整局都不会有(解释了"有红绿灯的局特别多红绿灯,没有的一只都没有")。

## 羁绊:护盾只需 2

- **2 护盾 ≡ 4 护盾**(等效):护盾上限**只跟对局阶段有关,与护盾羁绊数量无关**。→ 只开 2 护盾,**省出 2 个前台格子**给拐。
- 后台靠**穿反重力皮靴(鞋)的符玄(盾斧)❓** 跑条叠盾,盾量轻松叠满上限。
- **带三月七 / 杰帕德(纯生存)无用** → 不如多带两个拐提伤害。

## 站位 / 前后台

- 白厄**不打主动战技、全程防御(W)** → 不需要战技点相关角色 ❓(不带克律)。
- **前期前台**:花火 / 停云 / 星期日(低费、易追 2 星、快速给白厄叠**火种**)。
- **中后期替换**:花火、停云 → **记忆主 + 知更鸟 + 星期日**。**知更鸟必须占前台**(启动最快);**后台知更鸟是陷阱**。
- 五星补位:优先砂金 ❓(云梨)补尾刀,其次希儿 ❓(西联)。

## 游侠变体(+ 财富宝钻海克斯)

拿到**加财富宝钻的海克斯**时:上 **3 个游侠(悬海游侠)❓**,卡站位让白厄继承游侠全部乘区 —— 游侠的**速度征服 + 伤害征服**是白厄最需要的稀有乘区(呼应 `V3.7_公共_核心机制.md`:伤害征服稀缺、提升大)。约 **+200% 伤害增幅 + 100% 速度增幅**。

**buff 锁定微操(高操作)**:让白厄吃满游侠 buff 同时不亏前台格子 —— ①最高星 2 个游侠放后台、最低星放前台 → 白厄下场进备战再上阵 → 确认面板吃到 buff → 开始 → 进游戏点撤退回货币战争 → 把前台游侠换到后台、正确角色上前台 → 再开始(白厄仍吃满 buff)。
原理:①货币战争**重开可调站位**;②**面板只在进下关或上下场时刷新,其余锁定**。⚠️ **每进下一关必须重复**(白厄是主机板,刷新后 buff 掉)—— 漏一次这关基本炸。

## 成型节奏(7 人口完全体)

- 前期(白厄没来):第一位面用 **3 DOT + 阿格莱雅(昼神)** 过渡;鞋子合给阿格莱雅;可过渡给饮月(龙丹)玩 2 DOT + 仙舟 / 存护(铁骑)阵容。目标:**高连胜、少掉血、带多钱进第二位面**。
- **2-1 直接拉 7 级 → 开 D 找白厄 → 整局待 7 级直到 3 星白厄 → boss 关前吃自然经验升 8 → 上记忆主 + 知更鸟 = 完全体**。
- 补给节点:**关键角色 vs 幸运星/鞋子 → 优先装备**(角色还能再 D,装备错过就没了)。

## 启动(行动值)

星期日带**翁瓦克 + 永动机**,开局冲白厄拉全队。知更鸟 + 翁瓦克(40%)+ 自身大行骑行动体(前 25%)+ 翁瓦克(24% 全队拉条)→ 知更鸟只跑 11% 路程即启动全队;星期日大招冲全队 → 知更鸟 1 能量启动。一般 **~7 行动值**启动全队,之后慢慢上拐,火种充裕。

## 弱点 / 风险

- **红绿灯 / 电视机**(频率限制怪)→ 刷开局规避。
- **忍无可忍(多段惩罚)**克高频低单次 → 反甲多段打触敌频动,被 counter(见 `V4.4_阵容_README.md`)。
- **吃装备**(三反甲 + 后台鞋 + 永动机 + 翁瓦克)→ 强烈建议选**装备相关**的投资环境/策略。
- buff 锁定微操漏一次 → 该关炸(高操作负担)。

### 为什么 V4.4 反甲白厄封神

- 白厄 = 全游戏最适合玩反震的机制 + CW 最牛逼自拐;**没人比白厄更适合三月七领航员的反震**。
- 白厄每次行动**直接拉条对面所有怪物** → 强制吃姬子(原本 50 行动值才吃到)的受力次数 → **一次伤害直接全清屏**。且**白厄不需叠火力风暴潮**(扫荡美杰❓关最多 1 分钟)。
- ★V4.4 加强原理:姬子以**三月七为领航员** → 4 列车给白厄**多送 4 件反甲倍率**;姬子能加入护盾羁绊 → **踢掉旧反甲白厄阵容中作用不大的盾单 → 凑出完美 2 护盾**;**刃**比三月七 / 盾单更适合当主力挂盾盾斧(有本体盾量高得多)。
- 4 金提升大:**0+1 白厄**(没专武跑得慢,中期 3 游侠没开出则行动次数可能不够)/ **0+0 刃**(没本体挂盾少)/ **0+0 星期日**(没本体开局带不了翁瓦克,启动龟速)。

### ★翻车点扫雷(全避掉就稳)

- 反甲白厄对局**不会出现红绿灯**(遇史瓦罗 / 萨姆立刻重开,是开局就该做的事,而非玩到一半发现)。
- 抓普满❓ → 先前两次拉条把所有怪清了 → 再不断弹射对单击破这只普满让它每轮重跑(而非一直给它拉条放生)。
- 九杯怪❓不用刻意刷(概率极低,偶尔遇不影响 3S;这版本够强,遇到也能强杀)。
- **不要开 6 列车、不要开 4 护盾**:带挂件把羁绊开高 = 愚蠢(高羁绊乘区本质是同程序重复堆叠,后面稀释严重,**不如找稀缺乘区**)。三月七领航员的列车撞击 + 姬子助战技叠的盾**不吃姬子面板护盾强度** → 不吃绝对热量 / 重症难题 / 4 护盾强度 → **4 护盾羁绊无意义**。想多上盾 → 给刃找泡泡枪❓,而非再上盾单占人口。
- **不要带克拉拉❓**(主 C 辅助,对反震提升几乎为零 = 浪费格子)。
- ★**前台队友星级极重要**:前台队友每个星级使白厄多 **120% 前台强度** → **前台必须全员追 2 星**(连龙丹星级都顺手升 2 星,后面卖掉换记忆主);但**姬子不用升星**(纯后台挂件,用来开 3 巡猎❓,升星无意义)。
- 试用白厄不推荐:试用带不了**防御绳子 + 防御鞋子**(108% 防御力提升超大)→ 正式开打前必须换(随便扒两件闪击❓)。

### 装备(V4.4)

- 白厄依旧**3 反甲优先**,但 V4.4 **只用 2 件反甲伤害就夸张** → 第 3 件做不出反甲可选**暴击刀 / 进大剑袋❓** 替代。
- 除非三月七有 5 星存护光锥 + 刃没本体,否则**三月七不做上盾装** → 优先做**幸运旗 / 硬甲**给姬子复制提拐力。

### 阵容 / 站位(V4.4)

- 第一位面过渡:3 仙舟 + 2 DOT / 2 列车 + 2 DOT / 4 列车 过渡到 1-8。6 级强势卡:4-13 巡猎黄泉 / 4 列车姬子 / 量子希儿。反甲有几件先合用。
- **6 人口反甲白厄**:白厄 + 龙丹 + 姬子 + 星期日 + 三月七 + 刃(4 列车 + 刃 + 白厄)。要 D 的 3 费卡多 → 前中期遇到顺手买防 6 级不出。
- ★**姬子必须丢后排**:姬子近战自动展开境界❓ → 跟白厄大招境界冲突 → 白厄开不出大。但即使白厄吃不满姬子拐力,输出也足够吊打所有主 C(比上版本挂件盾单强太多)。
- 6 人口前排不够 → **三月七丢前排**(尤其 2 星三月七,前期对面打白厄不掉盾、不需补盾,丢前台白厄伤害高不少)→ **保证前台占满让白厄吃更多前台强度**。所以「姬子后台 + 三月七前台」看似抽象,6 人口最合理。
- **6 人口优先上刃**:白厄很缺减防 + 易伤乘区,刃是最好的盾斧。0+0 有本体 2 星刃带 2+1 泡泡枪❓ → 一次直接上 2 万盾 → A850 白厄打遭遇 4 / 黑草全程满盾。
- 7 人口上**不死途❓(托帕)去前台**:给白厄上循环游侠户口 → 减防拐 + 速度拐 + 伤害增幅拐。7 级狠狠 D 到 3-10❓。升 8 上游侠 + 记忆主。护盾压力大 → 上砂金(云梨);不大 → 直接 3 游侠拉满伤害。
- 打赢遭遇 4 / 多拿宝钻 → 10 人口多上**远坂凛❓(投影形态拐力夸张,过时间节点没了)**。
- 带希儿无意义(肯定能打完全部)。带杨叔有说法但不适合推广:仅 3-7 可能上,等后台盾斧叠满盾 + 列车叠满光轨 + 吃完中立时刻❓开二次行动值 → 拉 3 波大数字(二次行动值出伤 5000 亿观赏性佳),吃思路,不适合前两把。
