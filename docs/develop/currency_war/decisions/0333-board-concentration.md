# 0333 - 体系集中度(d2 意向批;候选层配方亲和)

- **Status**: accepted(2026-08-25;sim 双窗方向一致 + 锁全绿;亲和语义=sim 校准域)
- **Context**:第四局判读收账(run_20260825_051225,W70 评分修复后,P1 末真值
  1/40/13/12 四局同型,r9 boss -34)判定:**买入活跃但买到的是散件不是体系**
  ——W70 锚点①达成(r7/r8 买入恢复)但 r9 板面 11 阵营散(银河学者2 外全
  1 档),成型质量不足以扛 boss。因果链(四局+sim 收敛):意向层方向信号弱
  →评分层买散件(单件正分)→板面 11 阵营无引擎深堆→r7-r9 中型节点掉血
  +boss -34。replay 量化(四局 decisions.jsonl):散买主 tag = **line_
  opportunistic(意向目标件)+ engine_seed(引擎件)**(bond_fallback/pair
  仅 1 次)。
- **诊断修正(实现轮,数据驱动)**:初版设计「评分层集中度加分」(深化件加分)
  sim 验证**证伪**——winA conc0/conc1(1.0/3.0/5.0/8.0 全量级)**全指标零
  差异**:根因=sim 中「深化件 vs 新体系件」**同轮并存轮=0/200**(供给稀疏,
  引擎件店见率低,排序偏好无竞争窗口可作用;3/30 seed 仅顺序变化集合不变)。
  另 sim 锁线分布(n=100)显示锁线**不慢**(100% r4 前锁:r1 65%/r2 26%)但
  **43% 锁非过渡终局线**(万敌单C 33%+大黑塔 5%+反甲白厄 3%+狼尊 1%+
  黄泉 1%)→ hoard 目标集引向非过渡件 → line_opportunistic 买非过渡件
  → 散面。对照任务判读「锁线慢/不锁」修正为「**锁线对象错位**」;散买主
  通道=**engine_seed 跨体系见即买**(sim 实证:476 次 engine_seed 买入中
  100 次=新体系件+板面已有未成型体系,占 21%)。
- **Decision**(候选层配方亲和,落点 `decision_v2/candidates.py` +
  `decision_v2/registry.py` + `cw_line_defs.py` 指标纯函数):
  1. **亲和过滤 `_engine_seed_affinity`**:engine_seed 判定
     (discipline.engine_seed_wants)后叠加**板面配方亲和**——板面已有
     过渡体系(计数≥1)且未成型(存在计数≥1 且 <tier 的体系)时,候选卡
     若属于**新体系**(该体系板面计数=0)则不生成 engine_seed 候选(0 分
     被拒=散买断);**空窗**(板面无任何过渡体系)放行(第一体系要开,[31]);
     **全部成型**(引擎≥2)放行(两两组合可开新体系);深化件放行(配方
     加法);希儿系/非三羁绊件不辖。开关 `engine_affinity_enabled`
     (registry,默认 True,False=回 W70 行为,A/B 通道)。
  2. **新 sim 指标纯函数**(cw_line_defs,先建后用):`board_system_tiers`/
     `board_max_recipe_tier`(深堆度)/`board_recipe_faction_count`(配方
     家数,散面度)/`board_total_faction_count`(全量散面度)——板面集中度
     = 本批测量地基。
- **Considered Options**:
  1. **评分层集中度加分(深化件加分)**:实现后 sim 验证**证伪**(双窗全
     量级零差异)——排序偏好无竞争窗口(零并存轮),结构性无杠杆;不交付
     无效机制,撤销(记录本 ADR);
  2. **锁线加速(bond 2 档即出意向候选)**:sim 数据证伪(100% r4 前已锁,
     不慢);「P1 锁线对象限定(过渡体系优先,终局线留 P2/P3)」=大改(意向
     层锁线对象=COMP_LIBRARY 全部 v2 家族),记后续批——本批以候选层
     亲和(生成时收敛)先行,不改意向层锁线对象;
  3. **候选层硬过滤(所有新体系件在未成型窗全拒)**:过激——杀空窗期
     第二体系开张([20] 两两组合)与 [31] 空窗语义;本批取**亲和过滤**
     (空窗/成型放行,仅未成型窗拒新体系),语义精确;
  4. **engine_affinity_enabled 默认关(回 W70)**:sim 对照否(见验证)——开臂
     engine_seed 散买(新体系+未成型)买入显著下降,板面集中度指标改善。

  - 窗 A(seeds 0-99):aff_off vs aff_on ——(A/B 完成后填);
  - 窗 B(seeds 900000-900099):同上;
  - 检查网:fix 与 baseline 违规集一致(零新增);
  - 测试:ADR-0333 新锁 11 条(亲和判据 6[空窗放行/深化放行/新体系拒/成型

  - engine_seed 不再跨体系见即买:板面已有未成型体系时,新体系引擎件不
