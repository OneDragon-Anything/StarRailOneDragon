# 遗器-替换-筛选规则(relic_replace_filter_rule)

> source_image: sr-od-test/screens/遗器-替换/{筛选规则弹窗,筛选规则弹窗已勾选}.webp(1080p 两态 fixture)
> 识别模型:assets/game_data/screen_info/relic_replace_filter_rule.yml

## 1. 何时出现

「遗器-替换-筛选」面板点「套装」点击选择条弹出的套装勾选弹窗(居中大弹窗,背景暗化)。标题「筛选规则」+「隧洞遗器/位面饰品」双 TAB + 双列套装行(图标+套装名+点赞数+复选框)+ 底部「全部清除/确认」。

## 2. 与背包侧同构(重要)

**本弹窗与背包侧「背包-遗器-筛选规则」是同一游戏组件,像素级同构**——标题/双 TAB/套装行/按钮坐标完全一致(替换域与背包域弹窗帧对照实证),弹窗内不存在任何可区分文本,弹窗外背景暗化不可读。两侧 screen 均已建档且 id_mark 同为「标题-筛选规则」:op 在本弹窗内的操作**用屏名取 area 直接交互(round_by_find_and_click_area / 区域级 until 锚),不依赖全局画面判定**——两个屏的 area 同位,取哪个屏的 area 行为一致。全局识别(无 screen_name_list 的 get_match_screen_name)在本弹窗态命中背包侧属预期,不是建档漂移。

## 3. 行为事实(2026-11-12 摸底帧实证)

- **套装行勾选 = 点行文本中心**(与背包侧 SelectBagRelicOp 同款手法);勾选态 = 复选框橙色 ✓ + 行橙边框 + TAB 图标橙色角标
- **重复运行同参数会反选**:行已勾选时盲点 = 取消勾选——**先点「全部清除」清残留勾选再点目标行**(幂等依据;清除范围含套装勾选以实机验证为准)
- 点「确认」后:弹窗收起、筛选面板保持打开、列表已按筛选刷新
- 弹窗记忆 TAB 状态未实测——操作位面套装前显式点「TAB-位面饰品」,操作隧洞套装前显式点「TAB-隧洞遗器」(两 TAB 均已建档,不赌记忆)

## 5. 注意

- 套装列表内容随 TAB 切换,行文本 OCR 找目标套装时先确认在正确 TAB(位面套装在隧洞 TAB 里找不到)
- 「全部清除」只清当前 TAB 的勾选还是双 TAB 全清未实测——需要双 TAB 全清时逐 TAB 各点一次
- 弹窗右缘有滚动条,目标套装不在首屏时先在「区域-套装列表」内拖拽再 OCR 定位
