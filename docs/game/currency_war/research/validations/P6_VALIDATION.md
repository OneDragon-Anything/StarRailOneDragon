### 门① 内部推导(逐步核)——**通过(含三处勘误级瑕疵)**

命题拆四节,逐节复算(独立重推 + 脚本亲跑,见门②):

**① 三臂推演(上界主张)**:上界主张「零买 r1/r2/r3 末金 ≤26,全部买臂 ≤26,离 50 息基远」——**在所有口径下成立**。但数字表本身内部口径混用:

**② 息损量化**:脚本 P6-2 节亲跑复现全部数字表(金 5/9/11/19/21/25/29 → 1/2/0/0/0/0/0 ✓)。两处文内自相矛盾:

**③ 收益侧支柱改写**:逻辑链 = 命中率增益≈0(引 P4 ≤1.0pp,量级保留可用)→ 战力收益 r3 前不兑现(机制注:r1/r2 无战斗)→ 真支柱 = 零/微息损 + 1费全额退期权(引 P1) + 3合1 素材。结构成立;但引用 P3「e0→e1 +1.4金/轮」为**已作废数值**(P3 索引 2026-09-01 判「作废禁引」)——本处依赖只取其定性面(奖励轮无战斗 ⇒ 买件战力收益为零),该面由机制注独立支撑,删引用不伤论证。

## 2. 最终判决

**维持「已证(支柱改写)」——命题成立,不作降级。**

核心断言「前两轮压库 = 零/微息损 + 1费全额退的免费期权,统一经济策略无需 per-round 特规」是**支配性结论**:全口径(新旧连胜金口径 × 基础奖励 5/3-4)下零买与全买臂轨迹金 ≤26 ≪ 50(息距 ≥24 金),微息损(1-4 金量级,回档 1-2 轮)与期权零成本(1费全额退 live 实测)两条支柱均不依赖任何被勘误的数值细节。

不构成证伪的瑕疵(全部勘误级):① 节数字表口径混用(11/16/26 无单一口径可复算,正确值 = 不发口径 10/16/23 或照发口径 11/18/26);② ②节 bullet 与自身数字表矛盾(当轮/累计口径混写)+「档线 10/20/30 → 3金」仅金 10 成立;③ 连胜金「计 0 发 0」半句被 ADR-0439 推翻(照发),证明自留回改条款应执行;④ 基础奖励 5 → 实测 3/4(强化);⑤ P3 +1.4 作废数值引用须删;⑥ 扑满例外辖域未声明。
