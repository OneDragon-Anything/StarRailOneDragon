# 货币战争-投资策略（三选一，时点出现）

**识别**：`is_precise` 命中 `货币战争-投资策略`；extras.strategies = 候选名列表。
**目标**：三选一选策略。
**能做的事**：
1. 选中并确认一体：`CwPickInvestStrategy {"card_index":1..3}`（内部 = 点卡片**六边形图标区**选中——点标题/文字区不选中——+ 确认微距拖拽）。
2. 跳过本次选择：点右上「返回备战界面」（会带出暗色锁定态，回备战后按「货币战争-备战-暗色锁定」卡先解锁）。
3. 逐卡刷新（每卡独立）：每张策略卡一组「刷新次数N」+ 独立圆钮（圆钮 = 该卡计数文本中心 x−88、y 同高；三卡计数文本 ≈x{477,975,1474}、y≈855 → 圆钮 ≈x{389,887,1386}；识别带「区域-刷新次数行」）。计数逐卡独立扣减，0 = 尽（灰置仍可读）（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
**坑**：确认键置灰 = 未选中（op 重跑仍不行则亲自读图核对点位）；extras.strategies 长度 ≠ 3 时不要用 op（卡数变了，退坐标点击并反馈更新图标区）。效果形态已知条目（实测，均为查证过注册表定义后的实战选择）：双星馈赠 = 商店刷出带星标的 2 星卡（1 金）；健康充值 = 小队生命值 +30 且上限 +30（血线压力大时的直选项）；中产阶级 = 每 2 星单位 +5% 减伤 +15% 强度、再 +3 金币（阵容星级成型后的稳收益型）；星级压制 = 速度 +10%、对低星敌人打 20% 真伤（己方星级领先时的滚雪球型）；特战资金 = 进首领节点时 +7 金（银卡，注册表口径）；无伤通关 = 战斗结束时无角色陷入无法战斗状态则 +1 金并立即获得 1 个【生命之花】（银卡，注册表口径）；固定理财+ = 选中后商店刷新钮变「免费刷新」，每位面 3 次免费刷新额度（2026-11-19 实机实测生效——刷新钮文本直接呈现该态，逐次扣减额度）；胜利还是胜利 = 金卡、效果未采样，**v4.7 注册表未收录该名**（数据缺口已记进度账本待办归数据批）；**公司严选 = 棱彩卡实测（2026-11-19）**：效果原文「现在及每个位面开始时，开启一个由5个独特4费角色组成的商店，并获得3金币」——1-3 购买后**立即生效**实测（3 金即到账+商店当帧开 5 独特 4 费；后续位面开始时的重复触发待后续局复核）；其余策略效果形态待采样。**「每赚 1 利息 15% 概率免费刷新」触发口径实证（2026-11-19，主角光环「富翁的梦泡」持有局）**：3 个收入节点后商店刷新钮均呈「免费刷新」态、全局累计触发 4 次——按「每节点一次 15% 总掷」期望约 0.45 次/节点不可能 3/3 全中，触发率远超单掷预期 = **每 1 利息独立掷骰**口径实证（利 3 ≈ 每节点 3 次掷骰），非每节点一次总掷；效果源为主角光环富翁的梦泡（见 mechanics/主角光环.md），口径记本卡因「免费刷新」按钮语义归此（同款按钮语义见上方固定理财+条）。**候选池出现率数据点（2026-11-19 三局累计 21 候选零命中）**：三局 7 次三选一共翻 21 张候选（15 张白银时代局 + 6 张彩虹时代局），S2 利息帽改写三策略（开源节流 / 利息上调 / 买断制）**零命中**。关键对照：**彩虹时代（策略全棱彩品质）局的候选全为棱彩品质仍零命中**——棱彩（最高品质）池也排除，说明不是「品质池深、出现率低」的问题。**结论升级：利息类策略大概率不在常规随机池**（固定策略 / 特殊途径获取），随机刷新补猎路线**关闭**；新排查方向 = 查官方配置表确认获取途径（待编排侧立项）。利息帽改写实机口径取证改走配置表 → 拿卡后弹窗实读的判据维持（见跨迭代挂账板「策略域待实机确认清单」H1）。**默认利息 cap 5 顶格直读闭环（2026-11-20 第二局四帧）**：战前持金 51/65/69/69 金四个结算帧「利息 5」行直读在案——超 50 金利息不再涨 = 默认上限 5 直读实证（floor 公式全样本吻合维持，详见 gameplay-basics §3.1）；S2 三策略改写口径（9/10/0）候选零命中状态不变，弹窗实读判据维持。「胜利，还是胜利」同局候选再现（上文已录注册表缺口的卡名再遇 1 次）。「简单模式」效果原文「敌人难度降低3，最多降低至0」（候选卡实读，未采样生效）。**天降救兵实测（2026-11-19 第三局）**：效果「随机 3 星 1 费角色」实发 = 忘归人 3★ 直接入席 + 武装箱——「星级×费用」表述口径实证（卡面写几星几费就发几星几费，3★+1费 兑现；入席 = 直接入备战席，无战斗环节）。
