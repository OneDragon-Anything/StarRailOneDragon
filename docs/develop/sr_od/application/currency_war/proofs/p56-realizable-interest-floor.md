## 1. 命题

discretionary 买入(EV 买面、M6 压库)支出的金位约束取**可变现息线下界**

```text
gold − x + Σ(活期卡退金) ≥ g*
活期卡 = bench 中 1★ 全额退件(资格谓词与 funding_support_sell 同一:
         star==1 ∧ 零重叠 ∧ 无后台效果)
g* = saturation_line(cap_resolved) = 10×cap_resolved(与 p54 R2 floor 同源,零新常数)
```

时,在 T1 前件落地的前提下,买后任意帧可通过凑息卖通道回拉满息档;净代价 = Σ被卖件压缩价值(逐件按 p49 ① (费档,等级) 表计价,域内量级跨 1-2 个数量级,不设全局小上界)。

实现落点(P56/T1 批):`decision/cw4/shop.py` 预算投影段 `s_reserve := g* − Σ活期退金投影`(消费位单一源);约束形态 `gold − cost ≥ s_reserve` 于 `criteria/stockpile.stockpile_buy` 与 `criteria/buy.ev_buy_candidates` 检查点③原位生效(判据本体零改动)。

## 2. 可实现性(条件式的「条件」)

买后金跌破 g* 时,回拉通道存在且会被执行,需三件(T1 语义重写,R2-N4;旧代码三项皆缺——funding_support 触发辖义务缺金、sell_for_interest 无金位触发且布尔门全发):

1. **金位触发**:买/花后逻辑态金 < g* 即发射(缺口 = g* − 逻辑态金);逻辑态金 = 容器逻辑态金值(动作执行后不经观察按游戏规则推算直写的预期状态,真值以下一帧观察为准);
2. **目标量止盈**:remaining 递减贪心(funding_support 模板同构移植,零待证依赖;任意确定序贪心都能卖够,序只影响效率),Σrefund ≥ 缺口即止、不多卖一张;
3. **布尔门退役**:T_SEARCH_A 槽位检查退出凑息卖与窗口消费位。

**闭环(R3 攻击复核通过)**:回拉候选集(资格谓词全体)与 P56 约束中的 Σ活期退金投影**同谓词同集合**——P56 约束过的买入,其买后缺口必被资格集退金覆盖(缺口 ≤ Σrefund)。缺口帧发射、Σrefund ≥ 缺口、非缺口帧零发射三条已由单帧锁钉死(`test_cw_p56_t1.py::TestT1PullbackSemantics`,验收定义 = 设计 §2.2 R2-N4)。

## 3. 最紧性论证(升档核心;N9 路径的证明素材)

- **更紧(裸金口径 `gold − x ≥ g*`)会把可逆资产误判为破线**:活期卡 1★ 全额退(sell_refund 注册表口径,零手续费)⇒ 持有活期卡 = 等额即期金([41] 二次精确化的资产形态修正,p48 命题 3 同构)——把可随时变现的等额资产记作零,等于对同一资产在买面按 0 计、在卖面按全额计,自相矛盾。
- **更松(`s_reserve = 0`,旧退化形)保留破线敞口**:与刷新通道 floor(p54:`reserve = g* + ρ`)不对称——刷新位已不破线而买面可任意花穿息线到 0(floor 批对拍前实测形态),floor 的生存面语义在 discretionary 买面缺位。

## 4. 净代价计价与边界

- 回拉不必然卖刚买入件(资格集 ⊃ 候选集差「零重叠∧无后台效果」两条件)——**连带卖出损失分量**按 R2-N1 显式入账:实现层发射约束 = 目标量卖回优先选刚买件(帧级逻辑态直写架构下按名匹配同资格在册件),满足资格则连带损失=0;残余分量逐件按 p49 ① (费档,当前等级) 表计价,与被卖件同表同源,不另立账。
- 帧级静态逻辑态让渡:活期集合以帧首快照计,M4 卖出件即时从逻辑态扣减;帧内回拉/支付支撑卖出发生在全部买入之后,不进本帧金约束比较。
- Σ=0(无活期卡)时约束退化为裸金 ≥ g*(保守端,无声洞)。
- 无 ρ 项防双计:买面支出 x 即刷新门 ρ 预留所指的那笔买入,买面重复预留 ρ = 同一笔金留两次。
