# 货币战争-星徽秘典弹窗

## 何时出现

备战席「秘密典籍」道具点「开启」后弹出(道具来源:投资策略「秘密典典籍」给予,占 1 备战席槽,类补给箱)。2026-08-16 M45 首见完整链路(此前 M33 见过弹窗误以为点击道具误开)。

## 状态流转

- 入口:备战席槽内红金典籍道具(带「开启」字样)→ **点两次同位置**(第一次选中槽位边框高亮,第二次点开启)→ 弹出本屏四选一。
- 出口(四选一决策):点任一星徽卡(银河学者/夜之半神/昼之半神/持续伤害等,**候选随局内已见阵营变**)→ 获得对应星徽(入 owned_equips)→ 弹窗关、回备战、槽腾空。
- 出口(放弃):右上 × 关闭(道具仍在?未验证——保守不关)。
