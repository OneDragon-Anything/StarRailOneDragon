### 0.1 Fate(圣杯)任务链原文细节

**2026-08-24 从 git 历史补记;攻略存档(sources/V4.4_阵容_命运圣杯红A)已删[eb9c72a1],此为仅存记录;信源=过期攻略存档(版本 V4.4,已被 V4.4 实测部分推翻),与官方 API 深读结论分立,勿混写**:
**证据分级更新(2026-09-25)**:触发结构与注册表互证——`src/sr_od/application/currency_war/data/cw_factions.py`「命运圣杯」tiers=(2,3,4,5) + trait「提供祈愿试炼…难度和奖励随羁绊等级提升」,以注册数据为准;首次达档触发(降档再回不弹)= 玩法负责人估计待实机核;难度表/激活门槛/高难任务样本 = 攻略存档孤证(无注册表对应物),消费按此分级:

- **触发结构**:任务在 Fate 羁绊展开 **2F/3F/4F/5F 时各触发一次二选一接取**;难度分红(难)/蓝(易),羁绊等级越高越难 + 奖励越好(5F 有概率刷 8 个完美投影仪 +「实现所有愿望的圣杯」)。难度表:2F=2 蓝;3F=2 蓝 或 蓝+红;4F=蓝+红 或 红+红;5F=必红+红。
- **★激活等级门槛**:3F 接的任务至少开 3F 羁绊才算进度,5F 至少开 5F;未激活 → 面板显示「未激活」,做任务全部不算数——**花资源做任务前必确认激活状态**。

## 7. 金变效果三分归类(登记制)

策略层的金位账面协议(读数与记账,develop 侧 23 号篇)需要知道「哪些效果会改金、何时入账、何时失效」——本节按金变效果的**入账/失效形态**归类。**登记制**:新增卡进 `cw_invest_data.py` 注册表时按本节归类(代码注册表先行,research 同步滞后不失义);漏归类由会话入口再锚定收敛 + 账面-实读偏差侦测暴露——定式层闭合 + 变体卡显式归类 + 组合态兜底 = 协议完整形态,不宣称全闭合。

| 类 | 判据 | 已登记成员 | 协议侧处置 |
|---|---|---|---|
| **单卡伴生入金(记账层,4 张)** | 卡面「X 动作时 +Y 金」型——金额确定、与某类动作帧绑定 | 返利/返利+(每购买 3 个 5 费角色 +3)、合并同类项(刷新出 2 个相同角色 +1)、节节高升(任意升级 +1) | 按 X 动作帧以卡面确定金额直接入账;**合并同类项除外**——金腿已结构化(sim 出对条件金腿 `apply_on_refresh_pair_gold_grant` 挂刷新上报、sim 门控观察笔;live 游戏侧真实加金走下一入口金位实读观察覆盖,策略账面归兜底再锚定吸收,伴生入金函数不立;登记层成员资格本行保留);变体卡含同型卡面文本即入本层。「经验就是财富」(XP→金持续转换)显式归类 = 节点切换失效天然吸收(入金时点 = 自然经验结算 = 节点边界,失效先行) |
| **事件级失效(失效族)** | 金变在特定事件帧发生、金额或时点不完全可预枚举 | **选卡族** = 任何选卡帧(三选一 + 二选一〔令咒协议等含清金类效果〕——选中即失效,不枚举单项效果);**合成族** = 任何 3★ 合成结果帧(星星相印 +5——不分源:买入/消耗品/补给选卡/策略直发任何持有凑三即合);**晶矿族** = 点晶矿(普通金 1-5 随机 + 增发货币金晶矿 6/8/12 逐位面确定 + 三选一);**升级 9 级**(成长基金 +40,非伴生型独立失效);**计数达阈族(2 张)** = 二手市场刷满 20 次 +30 / 长线利好第 30 次付费刷新 +20(计数达阈帧失效,阈值帧兜底) | 事件帧触发账面失效(失效后以实读重锚);计数达阈族按帧计数在阈值帧兜底 |
| **延迟到账观察覆盖型(时点金族)** | 卡面「N 节点后/特定时点条件达成 +Y 金」型——金额确定、入账时点后置(不绑动作帧) | 躺平(禁买禁刷 3 节点后 +20,注册面 `instant_gold=20` 时点型残余)、无伤通关(战斗结算条件达成 +1,`instant_gold=1` 同为残余);已迁专字段成员:尾款交付(`gold_at_final_supply`)、超发货币(`gold_at_node`/`gold_at_node_offset`)、长期主义系(`gold_next_nodes_amount/count`) | 世界面零发放写端(到期/条件帧禁直写金防双计,禁令单一源 = `advance_node` docstring),金真值走观察覆盖兜底(实读重锚);估值面 instant_gold 按即时金口径计分(时点语义误差在册,字段迁移若做自立批位,不并入他批) |
| **组合态(兜底)** | 无单卡卡面「X 动作 +Y 金」文本的组合效果(组合空间不可枚举) | 如 经验财富×孪生素数(买入帧 +2/3/5/7/11)、保险×奋斗协议(血→金转换);「经验财富×淘金客(刷新+2)」两卡面均无单卡动作入金文本,按排除判据同归本层 | 不枚举——归会话入口再锚定 + 账面-实读偏差侦测兜底 |
