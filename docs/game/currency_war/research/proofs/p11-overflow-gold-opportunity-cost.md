## 命题 P11

设金 g、D 支出 s、interest(g)=min(g//10,5)。定义 D 的**决策成本** C_dec(g,s) = 不 D 时该金的期望实现价值与 D 时息损之和(下界口径):

1. **纯溢余段(g−s≥50)**:Δinterest=0 且溢余金的持有边际利息=0(帽满)→ **C_dec 下界=0**;
2. **穿 50 段(g−s<50)**:C_dec ≤ Δ档 × 回档轮(P2 收入 13-19/轮 → 回档 ≤2.31 轮),即 **C_dec ≤ 7 金量级,与 s 无关**;
3. 溢余金的**非息价值**(流动性期权/携带溢价)上界 = P10 ① 公式在 g0≥50 处的利息分量=0,只剩期权项 ρ(g)·s(ρ=流動性影子价,校准层参数;W151 四局实证 ρ 的实现值≈0——金带着 85-160 出局/死亡)。

- 四局 P2 shop 帧金 85-160、批口径 spend 42-135:**全部帧的面值成本都比决策成本高 ≥20×**——W152 观测的「V_D 全负」由该口径差单独即可解释大半(收益 23-38 vs 面值 42-135;vs 决策成本 0-7)。
- [17] 互证:簇主条「>50 的每一分……该 D 牌 D 牌」= C_dec 下界=0 的口述形态(用户权威,2026-08-20 三次强调);[28] 的守息过程纪律辖的是 **<50 攒息段**,不辖溢余段支出。

## 推论(修法②公式;常数归 registry)

V_D 的成本项在 P2 改为**机会成本口径**:

```
V_D^P2 = benefit^P2(state) − C_dec(g, s)
C_dec(g, s) = Δinterest(g, s) × min(R, recovery_rounds_P2) + ρ(g) · s
约束:s ≤ g − boss_floor(P2)(预算硬界,防「C=0 → 无限刷」)
```

- Δinterest 沿用 `ev.interest_cost` 结构;recovery_rounds_P2(≤2.31,P2 高收入下界)与 ρ(g)(溢余金影子价,初值可取 0,P10 ① 上界背书)归 registry 校准;
- **预算硬界必须在**:C_dec→0 后 EV 不再是约束,约束移到预算/授权层(DP `refresh_budget`/gold_floor)——这正是 W152 修法①(窗二分改 DP 姿态授权)与本命题互补的原因:①管「允许多少」,P11 管「每金值多少」。

## 与 P5/P10 的冲突标注

- ⟲ **P5⑤/W126 落地语义**(非定理本体):「spend=批口径面值」在 P2 溢余段作为拒绝依据被 P11 修订;P5 检验点①「禁单次边际口径」**保留**——P11 改的是成本的机会成本折算,不是退回边际概率口径。
- P6(回档账 1-3 金):P2 高收入(13-19/轮)使回档更短,P6 下界仍成立且更紧。
- P10 ①(携带溢价 ≤0.83/金):g0≥50 处利息分量=0,为本命题 ρ 上界背书;不冲突。

## 对实现的检验点

1. `vd_refresh_score` 的 `spend = e × 刷价` 在 P2(state.plane≥2)应替换为 C_dec 口径(公式见推论),P1 段不动(P5 退化语义保留);
2. 预算硬界(s ≤ g − boss_floor)与 DP refresh_budget 的授权消费同时上,缺一即复刻「C=0 无限刷」或「授权被吞」;
3. 溢余判定用 g−s≥50(Δinterest=0)作快路径,P2 无需逐帧算回档。
