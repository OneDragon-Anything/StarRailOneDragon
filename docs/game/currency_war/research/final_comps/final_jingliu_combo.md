# 镜流·连击(A2 · 3 费 carry · 连击 4-6 底盘)

> 一句话定位:以 3 费镜流为唯一主 C 的连击速攻套——前期用 1 费连击前台(那刻夏/瓦尔特/景元)带着镜流的装备打工,7 级慢搜三星镜流接班,靠「火力风暴潮×2 + 高频行动」叠伤害秒图。
>
> 家族注:与「那刻夏·连击」(A1,127 篇)同属连击 turbo 家族,本篇 = 同骨架换 3 费 C 型——功能链与装备签名几乎照搬 A1,差异只在搜牌曲线(1 费 = 5-6 级搜牌,3 费 = 7 级搜牌)与星级线(追三)。

## 1. 骨架

- **主 C**:镜流(3 费,云上五骁 + 连击成员[图鉴] cw_chars.py)——连击流派原生成员,高频行动型输出,帖内黑话「师尊/镜太后」。
- **前期打工组**(不可省,带镜流的装备过渡,后期卖掉换钱):那刻夏(1 费连击)、瓦尔特(1 费开拓银轨,帖内「老杨/杨叔」)、景元(1 费,帖证「前期可玩景元到 7 级找镜流」)——三者任选,都是 1 费连击/工具人前台。
- **功能链常驻**(帖间一致,17 篇高频在场):
  - 刻律德菈(1 费连击,15/17 篇):带电磁弹射器(「战斗开始时,装备者行动提前 100%」[图鉴],帖内「电磁鞋」)——开局启动件;
  - 白露(2 费,云五+治疗,17/17 篇):奶位;
  - 星期日(2 费连击,约 14/17 篇):信心注入器(「施放技能使目标前台强度提高 30% + 10% 伤害减免」[图鉴]);
  - 花火(2 费,蓄能帆承载位)与知更鸟·晴歌(2 费,帖内「水鸟」,蓄能帆另一承载位)——蓄能帆(「每点行动值固定恢复 2 点能量,唯一装备」[图鉴]);
  - 昔涟(4 费):永动机(「进入战斗激活终结技,每 3 个终结技再激活」[图鉴]);
  - 寒鸦(4 费连击,约 11/17 篇):速度补件,人口不够时换上来;
  - 风堇(4 费):第二奶;缇宝/千冶·刃/不死途:高人口补件;知更鸟(2 费):前台;雪衣(5 费):血牛挂件,可有可无。
- **羁绊档位目标**(档位数值 = 注册表原文[图鉴] cw_traits_data.py):
  - 主档:**连击 4-6**(layer4:「后台 1 号位额外生成【连击地格】…额外回合内额外造成 30% 真实伤害,首次施放普攻或战技后必定连击」;layer6:「连击时额外造成 60% 真实伤害」;layer8 存在(90% 真伤)但实战共识档为 4/6);
  - 副档:**小小巨人 2-4**(效果对象 = 敌方全体:受伤提高 + 造成伤害降低,非我方增益)、**云上五骁 3-5**(layer2 起:「五骁连携」造成 300% 基础伤害 + 全队 10% 伤害增幅可叠加;注意云五没有星徽条目,无法星徽转职凑档)、**双龙吟 2**、**治疗 2**(全队常驻 12% 伤害减免;层级效果只给治疗队员)、**召唤 2-4**。
- **自由槽**:寒鸦(速度)、雪衣(血量)、缇宝/不死途(高人口)、阿格莱雅(奇兽花园 3 档挂件,仅 1 篇)。

## 2. 星级目标

- 镜流:**追三线**——17 篇中 12 篇成 3 星;2 星(3 篇)/1 星(2 篇)在多拐或速升节奏下也可当 C。资源全砸镜流一人(「多拐一」=全队资源堆一个镜流)。
- 辅助一律 1-2 星:打工组 1 星即用,功能链成员二星即够,三星锦上添花。

## 3. 装备配方(逐件到人)

- **镜流本人**(核心三件,帖间一致):
  - **火力风暴潮 ×2**(轮滑鞋+折叠小刀[图鉴])——面板强度核心,帖证「镜流很缺前台面板强度,至少装备一个火力风暴潮」;
  - **高周波电锯**(幸运星+折叠小刀[图鉴];「战斗开始时装备者位于前台,幸运一击伤害提高 10%」[图鉴])——帖内「暴击刀」即此件(CW 无暴击,官方词 = 幸运一击),按情况出;
  - 第四件按节奏选:**热血沸腾拳**(「生命上限大于 5000 后每 1000 生命提高 2% 幸运一击率」[图鉴],帖内「拳套」——快攻/爆砍节奏签名件,合成首选出自速升 8 级快攻局)或 **反螺旋舞步**(「每次施放普攻/战技后伤害增幅提高 5%,可叠加」[图鉴]——连击高频行动适配件)或碎星斩舰刀/杀红眼(增伤补);
  - 最优组合帖证:「拳套+双风暴潮」或「风暴潮+杀红眼」。
- **功能链到人**(链条关系:启动件三件套各自独立叠加):
  - 昔涟 = 永动机;刻律德菈 = 电磁弹射器;花火或晴歌 = 蓄能帆——三者构成「辅助三件套」,是成型判据的一部分;
  - 星期日 = 信心注入器/电磁弹射器;晴歌另可带星航履/绝对热量;
  - 白露/风堇 = 生命之环+痛觉阻断芯片/很硬的甲(生存装);
  - 缇宝 = 胜利之旗(全队幸运一击率+12%,可叠加[图鉴]);
  - 千冶·刃 = 行星钻地弹 + 连击星徽(转职件放副 C 位);
  - 刃(副 C 局)= 幻造巨铠 ×2(配方 = 量产型装甲+幸运星[图鉴])+ 热血沸腾拳 + 电锯;
  - 雪衣 = 蓄能帆+永动机;三月七等挂件 = 武器大师(全队前/后台强度+25%[图鉴])。
- **合成顺序**:无跨帖一致的实证顺序,不写死;通用原则帖证「打工期装备先给 1 费前台」。
- **家族禁忌**:无注册表级冲突;帖级注意——多拐满员流不堆暴击刀(伤害已够,装备位让给功能性)。

## 4. 特殊系统件

- **双龙吟**(饮月+腾荒)[图鉴]:丹恒·饮月(5 费)在后台召唤同星级腾荒并复制其装备(★1/2/3 穿 1/2/3 件);帖间一致用法 = **双龙吟强化选连击**,凑「2 双龙吟 + 6 连击 = 8 连击」口径(选连击后龙单位计入连击数——多帖标题互证,机制归 [社区] 待实机)。
- **连击星徽**(蓝钻+折叠小刀[图鉴]):「获得 20% 基础【连击率】,连击的额外回合中造成的伤害提高 50%」[图鉴]——给非连击角色转职凑 6 连(如千冶·刃),也是本篇高频合成首选。
- **梦境交织星徽**(红钻+生命之花[图鉴]):梦转分支核心,给镜流转职(梦境交织原生成员 = 大丽花/花火/长夜月/黄泉/黑天鹅,镜流不在此列,带星徽属转职);多余的第二枚优先给刻律德菈(帖证:与电磁弹射器叠加达成近乎 0 行动值循环)。
- **追击星徽**:追击分支核心——帖证「镜流带一个追击星徽,追击档 6 时无限连、不耗行动值」(搭配 1 巡海游侠 + 追击投资)。
- **主角光环**:速度类(镜流手感向)/C 类(输出向)/战力类,按开局刷到的选。
- **翡翠**:5 费经济件,运营崩盘时入场翻盘(黑市补件)。

## 5. 达成路径(流向知识)

- **开局(位面 1)**:那刻夏/瓦尔特/景元 1 费连击前台 + 刻律 + 星期日 + 白露;装备做给打工位(它们与镜流同吃风暴潮/反螺旋),凑 4 连击。存牌意识:商店见镜流就买。
- **中期(位面 2)**:升 7 级慢搜镜流(本篇主流曲线,7 级搜牌 ×7 篇);打不过先在 7 级小搜出 2 星镜流停手,最晚二阶段 BOSS 前升 8 大搜。速升节奏局(速 8/速 9 ×7 篇)跳过追三直接拉人口吃全队二星。
- **终盘(位面 3)**:三星镜流 + 全队二星;经济好上 9-10 补缇宝/不死途/第三小小巨人/双龙吟。
- **成型判据**:三星镜流 + 风暴潮 ≥1 + 辅助三件套(昔涟永动机/刻律弹射器/花火或晴歌蓄能帆)齐。

## 6. 流派与降级

- **流派判定:单流派,两个节奏档**(装备面一致,差别只在人口/星级曲线):
  - 慢搜三星流(6-7 级搜牌,10 篇):3 星镜流单核 + 标准连击辅,主流;
  - 速上人口流(速 8/速 9,7 篇):镜流 1-2 星即当 C,靠云五增伤/双龙吟/全队二星/多拐一撑输出。
- **变体**(挂节):
  - 梦转流(梦境交织星徽镜流转职;装备优先级:梦转>风暴潮>刻律弹射器>反螺旋);
  - 追击流(1 巡海游侠 + 追击星徽 + 追击投资,追击 6 档无限连);
  - 高速全鞋流(反重力皮靴 ×3-6 + 遐蝶死龙体系,极端速度 = 出手次数口径)。
- **降级路径**(帖证指令级):
  - 三星搜不到 → 2 星镜流 + 多拐一;或主 C 转刃/丹恒·饮月(副 C 已带装,直接接棒);
  - 人口不够 → 卖一星打工件换寒鸦补速度;
  - 花火没本体 → 蓄能帆给晴歌,或先做刻律电磁弹射器;
  - 梦转缺 → 星航履替代;生存压力大 → 刃换藿藿凑 2 治疗;
  - 雪衣可有可无;缇宝/景元可去掉玩 4 云五。

## 7. 外部条件

- **开局信号**:开局拿到镜流牌/连击系门户/连击星徽投资时选本套;前期嫖到镜流 ≥2 张是追三流启动信号。
- **主角光环**:速度类 > C 类 > 战力类;经济光环适配速升节奏。
- **词条吃怕**[社区,待实机]:环境负面词条「能量逃逸/过热保护」类被多帖列为连击系禁玩环境(高频行动流被限制行动/能量的词条克制);官方 portal 配置未收录该批词条,取证后归位。
