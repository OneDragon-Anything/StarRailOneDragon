# 统一阵容评分(unified-line-scoring)迭代设计

> 2026-11-03 立项。四面打分(投资环境/投资策略/敌人词缀/BOSS)统一为
> 一套阵容评分,替代散装硬锁/排除特例。工作底稿 =
> `.debug/temp/cw_score_unification/` 四件(env/strategy/affix×2);
> 本篇 = 正式设计,分析细节以底稿为准,本文档自足收结论。

## 1. 动机与定谳(用户裁定链)

1. **统一一套打分规则**——不要每处定义「遇到 X 就硬选/不选 Y 阵容」;
2. **减分也可以做到排除**——极大减分(数量级压制)自然排除,无排除池/
   锁定档等特殊机制分支;
3. **分数值从效果原文/攻略实证来**——不拍脑袋;克制分档(强吃/怕/重开级)
   对齐攻略原话;
4. **词缀吃怕是阵容特定知识**(深入游戏理解逐线敲定,效果泛化推不出
   方向反转——正当防卫:万敌强吃 vs 姬子直伤怕);
5. 「没有 X 最好别玩」= **条件缺位折扣**(依赖结构,非普通扣分);
6. 流派分开定义(姬子 A/B 拆分首例);不考虑词条触发换线。

## 2. 统一评分框架

```
线分 = 证据分(现行: CARRY/骨架/插件持有 + 攻略热度)
     + 投资环境分(通道派生,纯加分)
     + 投资策略分(通道派生,纯加分)
     + 词缀分(吃怕表: 强吃+/怕−/重开级−极大; 加减双向)
     + BOSS 分(同词缀通道,待设计)
     + 依赖缺位折扣(线声明的外部依赖不在场: 硬依赖−极大/软依赖−中)
```

**四种分数原语**(全框架仅此四种,无第五种):
| 原语 | 数量级 | 语义 |
|---|---|---|
| 加分(在场) | +5000~12000(强)/+500(中)/+50(弱) | 外部条件利好该线 |
| 扣分(怕) | −500 级 | 显著劣势 |
| 极大扣分(重开级) | −10000 | 排除(数量级压制,任何证据追不上) |
| 缺位折扣 | −8000/−10000(硬) −500(软) | 依赖条件不在场 |

> 数值为量级示意,落地定常数(档位→数值一处定义);逐级比(字典序)
> 还是加权和待实现时按「证据分现行结构」对齐——倾向保持现行
> line_score_key 的字典序骨架,外部面作为新维度插入。

## 3. 四面模型

### 3.1 投资环境(83 个,纯加分;底稿 env_channel_table.md)

四通道,效果原文派生(不手拍关联表):
- ①送人(立即)——证据分自动覆盖,不另加分;
- ②定向刷新率(概念股)——强档线加分;
- ③星徽(邀请)——中档;
- ④期货任务链(契约)——强档。
通用类 41 个(经济/时代/规则)线分 0。现 ENV_COMP_AFFINITY 手拍 18 条
退役,被派生规则取代(覆盖缺口 24 个同型环境一并补齐)。

### 3.2 投资策略(335 个,纯加分;底稿 strategy_channel_model.md)

五通道 = 环境四通道 + ⑤**战斗增益×引擎类型**(策略面特有):
「全队速度+X%」对鞋队/拉条线(希儿/阿雅/欢愉)中档加分,对万敌 0。
引擎分类 = final_comps README B1 三驱动型(大招流/受击流/行动流),
与词缀面特征桥共用。模式分布:经济 58/星徽 44/送角色 ~70/装备 26/
战斗 54/商店 15/经验 12/羁绊 10/专家 7——解析规则覆盖后人工补 <30。
现 AUGMENT_COMP_AFFINITY(7 键)退役。

**两面共同结论:投资面无显式减分**(83+335 个效果全判读,「敌方词」
全是我方攻击增益或降难度;全局代价(品质→难度/连胜→难度)不分线)。
相对劣势由加分差自动产生。

### 3.3 敌人词缀(53 个,加减双向;底稿 affix_channel_model.md v2)

**数据源 = 逐线吃怕表**(final_comps 各篇 counter 节攻略实证,20 线
已审 13 线,长尾 7 线版本重跑补),效果原文分档仅作未登记词缀的默认兜底。

关键结构:
- 同词缀方向逐线相反(正当防卫:万敌+12000/姬子直伤−500/其余普遍怕);
- 强吃=燃料词条(万敌双条件依赖见 §4;姬子反震/白厄同构);
- 重开级(−10000):希儿×5 词条/万敌×2/白厄×3(boss)/圣杯满愿/DOT 净化;
- 双面词条(灼热轰炸:万敌低血期怕/成型后吃);
- counter 有解降档(扑满克姬子,瓦尔特延后倒计时是机制解——知识面,
  先登记原话)。

**作用点三分**(词缀是单场,选线是全局):
| 作用点 | 强度 | 形态 |
|---|---|---|
| P1 已见词条入线分(README D3:开局前置决策) | 强 | 吃怕表直查 |
| 遭遇分支选择(词缀已知,当前线已定) | 强 | encounter_pick 词缀轴复活(现死输入):分支成本=难度+词缀×当前线 |
| 选线先验(词缀未遇) | 弱 | 词缀池先验×档位×可回避折扣(轻微档量级) |
| 选卡 | 已有 | counters_dot 保留 |

### 3.4 BOSS(开局简报前置决策;§5 关系表见下)

- **可见性(画面文档实证)**:简报屏(难度确认后、投资环境前)预览本场
  全部 3 boss + 4 词缀——开局全见;3 只都要打(打穿才进下一位面)→
  **开局线分 = Σ 三只对本线的克制**,与词缀 D3 同为前置决策;
- **位面归属是精细档**:简报卡片排列≠位面序(真值 = CollectPlaneIntel
  逐位面实采);位面 1 被克比位面 3 更伤(成型前更脆)——补全后可做
  位面权重差,第一版均权;
- 数据:`BOSS_MECHANICS` 20 只机制 tag 组合 + 俗称映射(蕉研组/电视机
  =造梦互动娱乐/死龙=灰手生命科技/酒杯怪=造梦兄弟影业;红绿灯=小怪
  非 boss 忽略——白厄重开级相应剔红绿灯);
- **boss 面数据底账**(攻略实证,2026-11-03 全扫):4 线记载(姬子 5 只/
  希儿蕉研组/阿雅电视机/白厄史瓦罗+祸源萨姆)、9 个记载名可对应
  (2 个非 boss 定性:红绿灯/扑满)、2 个旧名对不上**不写**(存护星神/
  贝洛伯格加血机器,等下版本攻略统一处理)、**16 线空白**(攻略无
  boss 记载)——boss 面吃怕表初版 = 4 线单向(怕/重开级,无正向记载,
  正向等遥测积累);空白面与长尾词缀补读同批走版本重跑;
- **数据源纪律**:boss×线关系以**攻略实证**为准;bosses.md 的
  「核心机制/克制启示」两行是采图鉴时的人工推断层(非图鉴自带,
  部分带问号推测且从未实机校验)——本迭代删除两行(文档回归纯图鉴
  真值),推断线索不入登记;
- boss 面第一版登记范围(用户裁定):只收可对应者,版本失效项不臆造。
- `BOSS_MECHANICS` tag 注册表同源(图鉴提炼,briefing 观察链路有消费):
  同名 tag 存在两向实例(铁盾反击克高频 vs 纷争剥甲利高频)——tag 只作
  观察分组,**不通用映射**到线方向;boss×线吃怕按逐只攻略记载登记
  (20 只一次登记,含方向翻转与点名 comp);

## 5. 流派拆分(首例:姬子 A/B)

拆分硬证据 = 吃怕方向冲突(反震流吃正当防卫 vs 直伤流怕)。
- **列车同行·反震**(A,152 篇 60%):装备 外骨骼+以牙还牙甲族;副档
  护盾2;吃 正当防卫/忍无可忍/同步行动(万敌同向,万敌篇明文);
- **列车同行·直伤**(B,127 篇 25%):装备 风暴潮+电锯+冷笑话;副档
  减益2;怕 正当防卫/能量逃逸/时间刺客;
- 共享:core 骨架/lock_rules/need_star/知识卡;特化 15% 不拆挂注释。

**白厄吃怕审定**(本次):万敌篇 106 行实锤「白厄=护盾反伤版,万敌=
生命充能版」同构——吃多动类为**结构推定**(注释级,待 sim 验证);
重开级=红绿灯/史瓦罗/祸源萨姆(BOSS 面);忌燃血类/回血减行动值。
