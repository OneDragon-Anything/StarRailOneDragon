# 货币战争-备战-暗色锁定（多画面共文档）

备战画面带暗色蒙层的子态族：在投资策略 / 遭遇 / 补给 / 主角光环选择浮层上点过「返回备战界面」后，游戏把备战置成暗色锁定态而非直接可用。此态下备战常规识别标志（「备战阶段」等）仍可能命中——**别当正常备战操作**（读数是暗牌/暗金币，不可信）；不解锁的话备战读数不可信、出战被抑制，出路 = 点右上「返回XX选择」回到对应浮层做完选择。除遭遇锁定（已有归档帧核对）外，各画面档建档状态待实机核对（动作源码挖掘，未经实机走查）。
