## 二、指定复核点专项裁定

### ① W14 降级后链路闭环性：**基本成立，带三个缺口**

- **归档基准与分母**：对账基准 = 归档对局节点推进记录（`match_<game_id>.json` 在册有节点台账）vs 环行序列（新代码对局的环转储），离线可判，成立。缺口一：**分母定义未写明**——「应产结算行节点集」需排除自述零行的类型（补给/投资），而 M-4 的类型集定义（parse_settlement_node_type 全词表）恰好含补给，照字面实现缺环率恒爆。缺口二：**门槛未操作化**——「缺环率不可忽略」无数值或判定规则（details §8 :119③、§9 :128、W14 :150 三处同措辞），且不在 01_math_framework §6 三常量登记义务内（§9 只登记 f_min/g/Δ_t）——缺环率门槛若临场定性拍定 = 公理 1「无标注数字不进决策门」绕行。修法：E-3 登记该门槛（【拟】+ owner/期限），或改零容忍结构规则显式申报。
- **开闸门成员语义**：§1 :42、§9 :128、W14 :150 三处一致含缺环率 ✓；但 **E-3 阶段文本 :158 与 landing 3.3 :49 的开闸门判据句漏「缺环率」合取项**（见 M-1）——验收照判据句走会漏检该成员。
- **「两构造点均未命中 = bot 非正常态」残余风险申报：实质成立**。结算屏表面被三分支覆盖（「继续挑战」模板 :635 / 1f 模板组合门 :685-691 / 「前往结算」OCR :809-810），全 miss = 未知帧计数链 bail 留证（:874-893），即非正常态；且行不齐的三类形态各有明示兜底（W239 抑制形态→缺环率量测覆盖 :119④；relaunch 残留→开局清空 :119⑥；后到行→同键去重不覆盖先行行）。措辞缺陷：「两构造点」实为单构造点（read_round_outcome，cw_settlement_obs.py:487 全仓唯一）的两写语义三调用位（见 L-4）。
