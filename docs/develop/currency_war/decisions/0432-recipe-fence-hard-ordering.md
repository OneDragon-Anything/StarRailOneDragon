# ADR-0432:购买围栏硬排序——配方件存在性围栏(方向一)

- 日期:2026-09-06
- 状态:accepted(默认关,开臂判据挂账)
- 谱系:形态达标三方向落码批(设计单一源=`docs/develop/currency_war/prereg/w415_form_design/DESIGN.md`,唯一规格已审采纳);实证基线=形态达标改善过程质量报告(实机 34 局形态达标 10%、sim 两臂 0/400,头号缺项=配方件 2★,唯一锐利杠杆=买牌配方件占比 0.6 vs 0.4)
- 关联:ADR-0333(engine_seed 板面配方亲和过滤,同层同形态)、ADR-0359(off_lock 买侧锁定约束,方向相同集合不同)、ADR-0343(成型停手,form_ok 真假互斥衔接)、ADR-0426(C3 覆辙自查对照)

## Context(为什么)

W410 实证:同样花 14-16 金买牌,围栏实际执行只做到 40% 配方占比——既有「偏置加权」路径(forming_bias/goldrich/early_pace 三个加性偏置)不足以把占比抬到 0.6。加权的偏置量级无出处可推(三个先例全是 registry 待标定常量),且四偏置已互相叠加,再加一个边际不可审计。而「配方件 ≥ 散件」本身是**偏序关系**(user_playstyle [31] 三级羁绊梯队:目标件/填充/散件垫底,硬约束;[20] 过渡是配方不是乱混)——权威条目本身就是序,不是数。

## Decision(逐条)

1. **过滤式硬围栏,不加偏置**:与 ADR-0333 同层同形态(层2 过滤),谓词 `filters.recipe_fence_active`(开关 `recipe_fence_enabled` 默认关 + P1 ∧ form_ok 为假)。动作级规则在 `filter_candidates` 第二遍后置步(成型停手/C1 之后):同轮买候选 survivors 中存在配方件(`scoring._cand_system_bonds` 名集单一源,空集=散件)时,删除全部散件买候选,删因 `recipe_fence_scatter`。
2. **Considered Options**:①硬排序过滤(本批)——偏序无需量级标定、逐笔可对账、与层2 结构同构;②再加一个加性偏置——量级无出处、四偏置叠加不可审计,否决;③改 EV 层配方件分数——改配方件之间的相对序(越权,EV 层单一裁决),否决。
3. **存在性围栏非全禁散件**:店为空配方件时散件照旧走原评分链([31] 空窗期语义);存在性按过滤链 survivors 计(C1/成型停手已删的不计,防删无可买空转)。
4. **不新增支出**:金账/息账单一源仍在 arbiter,本围栏只重排同一笔预算内「买谁」——与 C3 覆辙(省金删支出坐等变战力)切割:配方件兑现链=3合1 合成(即时)→ 补完守卫促上场 → 档位进 form_ok,r2 起定向、达标局成型中位 r8,兑现窗 5-6 轮。
5. **正交声明**:C1 只辖 P1 末窗溢余段,本围栏辖 P1 全程未成型段;都开时 C1 先行,C1 未删的候选再过本围栏;删因链日志分列(`c1_directed` 与 `recipe_fence` 独立字段),两开关默认值独立互不为前提。与成型停手以 form_ok 真假互斥,零重叠。

## Consequences

- 默认关=零漂移锚(A/B 基线臂);开臂判据挂账(registry 注释,不执行):sim 同池 A/B n≥300 形态达标率 >0 ∧ 买牌配方件占比中位 ≥0.6 ∧ 息基保住率不劣于基线臂 2pp;验证不过=删码留本 ADR。
- 行为锁:`test_cw_form_gates.py`(围栏删散件/空配方店放行/默认关零漂移/C1 与成型停手正交声明)。
