## 1. 规则形式化(N×G×R 三元判据)

### 1.1 判据式

记备战帧 t 的状态:金 g、等级 L、升级整批金成本 s、部署数 d、部署上限 c、备战席候补集 B。

```
PRE(t) ⟺ N(t) ∧ G(t) ∧ R(t) ∧ 硬约束链

N(t)(节点类型条件):t 所属节点 ∈ D_N(节点类型真值链查表,见 §1.2 N 行)
G(t)(金条件):s ≤ g(整批可负担,P48)∧ 花后保底 = _guarantee_floor_holds 判据本体真
R(t)(满编条件/部署增量兑现条件):板满 ∧ 等待件命中 ∧ 候补件级过围栏
硬约束链(全部不旁路,让位序见 §3):lv9_stop / 血闸链 / 保底金门出辖三支
```

PRE(t) 为真时,升级批**优先于攒息**发射:攒息不再是该帧的默认姿态,量闸的紧带拒绝被本臂替代(替代形态与闸序见 §3.2)。

### 1.3 阈值符号化与标定债线(禁拍值)

①原文「金 ≥ 升级成本**+阈值**」中的阈值,本命题**不引入新常数**,按两类既有来源消解:

1. **θ_G = boss_floor**:花后下界取保底金门同源值(息通道非退化判等式,推导链 判据 docstring 与 P83)。这是**结构推导出的最小绑定下界**,不是标定值——「保一档不多保」:扩档须先补第 2 档转化机会成本的在册账。
2. **一般路径的金下界不变**:非硬节点帧的升级支出仍走 P72 (3a) 闭式 `g − s ≥ 10·τ(g) + ρ + Σ预留`(零新参数,T-63 已落码)。前置臂只是**硬节点帧上的附加放行支**,不改动 (3a) 判据本体。

**标定债线登记**(若 A/B 证明需要):D_N 是否从认证核心 {遭遇, boss} 扩展到普通战斗备战帧(覆盖面缺口实证见 §5.3)、以及 θ_G 之外是否需要更紧的带内约束——两类扩展量均为**候标定项**,A/B 分键数据**背书后候裁**(裁决权在候裁行/编排者,A/B 只供证据,strategy-work §3/§4),裁后按【拟】三要素立条(owner + 期限 + fail-closed 退路,01 §6),**禁在落码批拍数**。θ_G 本体不在标定债上(结构推导量)。

### 1.4 「未满编」语义消歧(防两读法打架)

①原文「且未满编」在项目里有两个可用词源,必须钉死取哪个:

- **cap 口径**(pop_slot/代码词汇):满编 = d == c。若取「未满编 = d < c」,则升级无部署意义(M1 直接部署填空槽),判据荒谬,**排除**;
- **阵容口径**(本命题采用):未满编 = 阵容未完全部署 = 板满(cap 意义)∧ bench 有可上场候补。此时升级是让增量上板的**唯一**通道(无空槽可填),判据自洽。

即:**R 条件 = 「板满」与「阵容未满编」的合取**——两个词各占一半,缺一不可。单侧形态的两个反面教材:①bench 空帧(g_20260907_084421 P2R3,supply 节点,备 0,金 54,XP 缺口 8 → s=8 金)——R 假,升级会造出空槽 = 空升级([32] 玩法纪律:消费有效性,空升级不做),判据正确拦截;②**同名死供给帧(锚局 P2R1/R2 实证)**:R 布尔值为真,但真值由非目标填充件/同名拷贝承载(假阳性形态,§3.3 逐帧对账)——R 后半钉死候补件级语义(§1.2)正是为把这类帧正确判假:同名拷贝 name_dup 恒 held。合成材料的排除是**设计级口径而非现行围栏行为**(对销复核观察项 O2 限定补注):部署围栏拒因闭集没有「材料保留」类拒因——`recipe_floor_holds` 仅辖列车同行配方底线语境,非同名拷贝的合成材料件可无 held 通过 R 后半;其排除归候裁行 5(「等待件」语义三面一并收口),锚局各材料件恰为同名拷贝故实际被 name_dup 拦、档案自证其被合并消费而非上场,均不算可兑现增量。

## 2. 支配性论证(方向级;数值面边界如实申报)

### 2.1 差分账

比较两臂:**A = 本帧升级并部署增量**(硬节点战斗以增强后的板面进入)vs **B = 推迟攒息**(下一备战帧再议)。

收益侧(A − B):

- **R1 部署增量(条件确定项)**:R 真时上场人数 +1。**羁绊计数严格 +1 是条件命题**:当可部署增量 = 阵营相关件时成立(羁绊档贡献按在场人头计数、不按星级,P79-2 机制注,注册表锚 FACTIONS tiers);当增量由非目标填充件承载时羁绊计数增量为 0(锚局假阳性形态实证)——这正是 R 后半必须钉死候补件级语义的原因(§1.2/§3.3)。R(修复后语义)真 ⟹ 增量为阵营相关件 ⟹ 计数 +1 在辖域内成立。
- **R2 战斗结算影响(方向项)**:板面成员与羁绊档弱增 ⟹ 下一场硬节点的条件掉血弱降、胜率弱升。方向依据 = P15v2 冻结语料的节点伤害锚(encounter 12.18 [10.32,14.24] / boss 26.79 [24.25,29.23],约为普通战斗 10.45 的 1.17×/2.56×)——**硬节点正是板面边际变化兑现价值最大的节点(按 P15v2 伤害锚排序)**。方向级,数值禁引。
- **R3 生存通道(方向项)**:胜率弱升 ⟹ λ_death(难度带×血带×位面×节点查表,P51)弱降 ⟹ 等待代价敞口 W_floor = λ×(g+Φ) 弱降。杠杆 = 存量金 + 未来流:金位越高(病灶轮 37→65),推迟的敞口代价越大。方向级,区间敞口口径(P51 消费纪律,禁边际引用)。
- **R4 连胜保持(上行注记)**:胜率弱升 ⟹ 连胜金弱增(P43 上行注记形态;全部论证在连胜=0 底线口径上成立,不依赖本项)。注记级。

成本侧(A − B):

- **C1 息损(有界项)**:ΔL = L(g,s,R,Ī)(P47 双轨迹递推【推】)。G 条件的保底下界把最坏情形封死:花后 g−s ≥ 10(出辖三支外)⟹ 首息档存活,息通道非退化(P83),息损失去「息上生息」的复合通道入口——**θ_G 的作用正是把 C1 从无界复杂账户压缩成一档内的有限损失**。
- **C2 无其他直接成本(结构事实)**:等级与部署上限是**永久状态**,跨节点不清零、不被战斗消耗。升级不是消耗品——败了这场,升了的 cap 和 XP 仍在,下一节点继续可用。所谓「沉没」仅限 C1/C3 的差,不存在「升级本身白花」的吸收态。
- **C3 当帧购买机会挤占(有界注记,方案审 F-10)**:PRE 触发帧花费 s 后,金位落在 [θ_G, θ_G+ρ+Σ预留) 带时,本帧 (3a) 本会保留的 ρ+Σ预留 购买力被放弃——当帧未能入手的牌进入 P01 再遇窗口,该通道不可恢复、不属于「息通道可恢复」的覆盖面;量纲 ≤s,**有界但非零**。削弱面如实申报:R 条件要求板满 ∧ 候补在手,该帧非升级金币支出的当帧战斗贡献 ≈0(bench 购买不打当节点仗),故 C3 在触发帧结构性偏小,方向论证不因此翻;不改变结论强度分级。

### 2.2 方向论证:不对称后果(论证主轴)

两条错误通道的后果结构不对称(00_framework §2 姿态架构的同一论证形态,在升级通道上的镜像):

- **推迟错误**(该升未升):部署增量缺席 → 硬节点败面概率偏高 → 走 λ_death 死亡通道。死亡 = 吸收态,一局清零,**不可恢复**。
- **提前错误**(该攒未攒):息档损失 ΔL(C1,受 G 条件封顶)+ 当帧购买挤占(C3,≤s 有界)。少赚 + 挤占,**可恢复**或有界。

⟹ 在 Δp 增量方向确定(≥0,由 R1 条件命题承载)而**幅度**不确定(校准层,见 §2.3)的情形下,判据应把错误方向压到可恢复侧:硬节点备战帧上,升级先于攒息。这与 00 §4「危险信号只许提前、不许推迟(λ 表错 → 最多早花,绝不会更危险)」是同一条架构逻辑——本命题把该逻辑从 λ 顾问面延伸到升级触发面。

**结论强度(取最弱一环,如实分级)**:本命题证得的是**带域方向命题**——在 N×G×R 域内,升级先于攒息在生存通道上严格不劣(λ 敞口方向)、在经济通道上付出有界代价(C1 被 θ_G 封顶 + C3 ≤s);**无条件弱支配不成立**(C1 > 0 严格,而 R2 在板面已压制的对局上可取 ≈0,EV 符号无法无条件证出)。结论强度 = 方向级 + 后果不对称级,**不是 EV 最优性证明**——这正是 00 §4 安全带「只升不降」的定位:安全带不是最优性声明,是错误方向的结构约束。

### 2.3 校准层一维键边界(如实申报)

「部署增量 → 胜率/掉血变化 Δp」的映射属**校准层**:宪法 00 §1-1 禁战力建模作决策依据,战力-胜负关系的唯一合法入决策通道 = λ_death 概率侧(PL 键 = 难度带×血带×位面×节点查表,00 §6;血带维入场系用户裁定二既裁例外)。因此:

1. 本命题**不建** Δp 映射、**不产**数值授权;R2/R3 只作方向消费(P15v2/P51 的方向结论,数值面按各自索引状态列的禁引范围执行)。
2. λ_death 表的**节点维(一维键)是本命题 N 条件的镜像**:λ 按节点分桶,意味着「同一板面增量在不同节点上的敞口后果不同」已是框架内既定结构——N 条件把触发面限定在 **P15v2 伤害锚最大的两档**(遭遇/boss;λ 表节点维数据面薄,不作「λ 桶值最大」断言),是查表键纪律的自然推论,不是新增建模。
3. 数值实证挂**实机 A/B**(§4):方向若被实机分布证伪(R2 前提不成立),按 §4.4 证伪面回设计层,禁以 sim 战斗表数值补证(00 §7:sim 战斗表与 λ 表同语料 = 循环,sim 只当压力测试,禁当概率来源)。

## 5. 自对抗

### 5.1 误升级面(升级后战力仍不足的「沉没」)

- **最强反驳**:「升级花了 12 金,板面加了个 1★,boss 照样打输——12 金息损白沉。」回应分三层:①**升级不是消耗品**(§2.1-C2):cap 与 XP 是永久状态,这场输了下一场还在,「白花」仅限息差与购买挤占;②**息差有界**:G 条件把最坏情形封在「保底一档」之上,θ_G 的推导(息通道非退化判等式)保证息引擎不被一次性支出杀死;③**后果不对称**(§2.2):反驳隐含地假设「不升则无损失」——推迟的代价不是零(死亡通道敞口),两害相权,错误应落在可恢复侧。残余风险如实申报:在板面已压制、Δp≈0 的对局上,提前错误的代价(息差 + C3 挤占)是纯损——此面由 F2/F3/F6 监控,不由判据消除。
- **空升级**:R 条件的 bench 候补腿直接排除(P2R3 反例,§1.4①)。
- **零羁绊增升级(假阳性形态)**:bench 候补全为同名死供给/填充件时,arm1② 信号真而可兑现增量为零(锚局实证)——R 后半候补件级语义(§1.2)在判据内拦截,锁 9/证伪面 F6 双面守。
