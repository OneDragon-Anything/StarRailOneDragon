# 12 血预算进决策层:P1 保血语义与 P2 血危机停手(设计件,W520)

> **状态声明**(同 08/11 惯例):本文是**设计件**(W520 任务书:纯设计零代码),
> 尚未实现。落地时:行为语义迁入 as-built + 对应 ADR(why)+ 代码注释引 ADR。
> 证据面单一源 = `.debug/temp/currency_war/w520_blood_budget_design/REPORT.md`
> 与其引用的 W516 批(`.debug/temp/currency_war/w516_p2_conversion/REPORT.md`)。
>
> 读者 = 无会话历史的智能体。核心术语:
> - **血预算** = 当前 hp 与「后续全部战斗节点全败累计伤害」之间的余量,单位血。
>   例子:P2 进场 hp=33,后续 5 个战斗类节点全败累计 88 血 → 血预算为负
>   (33−88<0),只有靠胜场减少实际失血才可能活。
> - **追级泵** = 濒死段仍在连发购买经验升级行为(升级经验按钮连点)。
>   例子:实机一局 P2 血线 16/1 时仍升 6/12 次——金换成了人口,人没活到人口生效。
> - **停手线** = 「血 ≤ 此线就拒绝某类未来收益型支出」的血量阈值。只拒
>   「收益在 ≥1 战之后才兑现」的支出;**当轮转化支出不在辖域**([32]:
>   买的件本战能上场兑现战力的,任何血线下都合法)。

## 1. 问题与证据基座

### 1.1 两条独立证据

1. **sim 定谳**(W516,n=200 基线 + n=100 配对,`w516_p2_conversion/REPORT.md`):
   P2 死亡 84% 的主导机理是血预算算术——sim P2 有 5 个战斗类节点、全败累计
   88 血、实测胜率 ~0.25 下期望伤害 ~66 血,而进场血中位仅 31、≥60 只占 15%;
   活局进场血均值 60.7 vs 死局 27.5。四臂 P2 段内采购杠杆(息线降/承接提前/
   DP 窗关/星级加权)配对全不显著;唯一能翻动死亡率的是校准弹性 β
   (form→胜率斜率)×5,而真实 β 未标定。
2. **实机第一票**(⑳+1 局判读):P1 R7 遭遇 −24(最大失血)→ R9 boss 负 →
   P2 进场 33(<60 分界)→ R5 死;P2 R2/R4 在血线 16/1 时追级泵照开
   (升 6/12 次)——**购买有效但战略无效**:每笔金都换到了人口,但血预算撑不到
   人口兑现。

### 1.2 问题结构(根源两问)

- 根在哪一层:**语义层**。策略层的花钱义务由息线(`registry.interest_floor`
  族)单一驱动,血量只进报警(discipline 三臂)不进花钱/停花判据——
  「血预算」作为约束在决策层不存在。
- 本件修的是根:把血预算作为**第二约束**引入决策层(P1 末窗=保血目标语义,
  P2 段内=停手语义),不是逐症状打补丁。与 W516 结论②的「P2 花金义务」
  (金 → 战力方向)互为对偶:本件管「什么时候**不许**为未来花钱」,
  花金义务管「什么时候**必须**花钱」——两者共用同一条血预算判据。

### 1.3 机制事实(以文档+注册表为准,非猜测)

- **遭遇节点不能避战**:节点序列中 encounter 是战斗类节点,掉血结构与
  普通战斗同([27] B+P 公式;economy.md §10.2 节点表;口述 [18]/economy
  「1-7 遭遇」的处理是战前弃息凑伤害,不是绕开)。因此血预算必须把遭遇
  计入战斗节点数。
- **P2 节点数与序列**:sim 注册表 `P2_NODE_SEQUENCE` =
  battle/battle/supply/battle/encounter/reward/boss(5 战斗类);
  实机 economy.md §10.2 仅 1 帧读数(battle/battle/encounter/reward/
  encounter/reward/?/boss@r7,战斗类可能 5-6 个)。**两源战斗类节点数一致
  为 5 上下,全败预算取注册表 88 血口径**;实机序列为单帧待复核
  (W516 对拍项 B 同源,标定核对项见 §5.4)。
- **P1 有 boss 前置遭遇**(1-7),掉血带更宽(A8:一层遭遇常比 boss 凶);
  P1 全败预算远高于 P2,但 P1 有 reward 节点 +2 回血且敌强度低一档,
  保血语义因此落在「末窗」而非「全程」(§2)。

### 2.1 目标线与既有判据的关系(不造第二套阈值)

### 2.2 数学依据:60 线的推导链

输入(registry/cw_sim 既有标定,单一源在代码):

- P2 全败累计伤害预算 `BLOOD_BUDGET_P2_ALLLOSE` = 88 血(cw_sim
  `P2CombatCalib` 五带中点和:21+10+20+13.5+23.5;注册表带为单一源);
- sim P2 实测胜率 w ≈ 0.25(W516);胜率模型钳制上限 0.5
  (`P2CombatCalib.win_p_clip`);β 未标定(W516 最弱一环)。

推导:期望失血 E[失血] = Σ_b (1−w_b)·L̄_b ≈ (1−w)·88。要求「期望伤害
不超过进场血」反解胜率门槛:w* = 1 − h/88。

| 进场血 h | 需要 w* | 可达性(w 钳制 ≤0.5) |
|---|---|---|
| 31(W516 中位) | 0.65 | 不可达(>0.5)——**算术上活不下来**,W516 同款结论 |
| 44 | 0.50 | 仅钳制上限,零余量 |
| **60** | **0.32** | **w≥0.32 即期望活;β 标定后只要 form→胜率不过弱即满足** |
| 84(W516 max) | 0.045 | 全败才接近死 |

结论(修订版,W524 对抗审计后):**60 = 「期望预算线」——使期望伤害不超过
进场血的最低进场线(w*=1−h/88),充分方向,不是存活保证**。对抗审计实测
推翻「分界」表述:n=200 账本 h≥60 的 30 局死 12(存活率仅 0.60)、h<60 有
14 活,分带存活率平滑爬升无崖,Youden 最优切点=44(样本内拟合,仅观测
参考);w=0.32 世界 MC 复算 P(存活|h=60)≈0.42——「期望活」≠「存活」。
w* 诚实区间 [0.31,0.41](88 为删失下界:boss 带真损≥带端+实机战斗节点
可能 6 个),带端逼近钳制 0.5。「实证互洽 60.7」降为旁证(均值≠分界,
正相关预测子必然活局均值>死局,CI [56.3,64.9] 宽);⑳+1 票判别力≈0
(进场 33 基线存活 3.6%,死为高概率自然实现),保留作追级泵反例样本、
不作分界证据。审计出处=`.debug/temp/currency_war/w524_audit_60line/
REPORT.md`;血预算主导的根论断经攻击未破(AUC 0.906 全账本最强,血非
金代理 corr −0.176)。

### 2.3 语义清单(每条:数学依据 / sim 可验性 / 实机验证路径)

#### 语义 P1-a:末窗战败后支出降格(买牌结构)

- **语义**:P1 末窗(`round_num ≥ registry.handoff_gate_min_round`)内,
  hp < `P1_EXIT_BLOOD_TARGET`(60)时,承接门(`handoff_gate_gap` ≥1 的
  定向投资授权)的**支出构成降格**:高分战力件搜索让位于减损型买牌
  (bench 囤件变现上场、同息档羁绊档填充——动作集复用 11 号件 §3.1
  blood_protect 梯度,不新增动作族)。
- **数学依据**:W516 配对排除证据——HG5(板面提前承接)进场血 +3.7 但
  hp0 +8/−7 净零、IF30(金改向板面)hp0 +11/−8:在 β 弱通道下,
  「多买战力件」换回的胜率不足以对冲 15-25 血/败的失血量级
  (板面→胜率→少掉血的间接路径被 β=0.04 钉死);减损路径
  (bench 变现=零金羁绊档增量、同息档买=零息损)是**无 β 依赖**的正账。
- **sim 可验性**:配对 A/B(`simulate_p1_ab` 同池同 seed)段级检查项:
  「末窗 ∧ hp<60 帧 actions 中战力型买(4-5 费/非羁绊件)笔数下降、
  减损型买(blood_protect 类)笔数 ≥1」;P1 早中期零漂移门逐 seed diff={};
  出口 hp 分布向 ≥60 迁移(p2 进场血直方)。
- **实机验证路径**:逐局判读 ①末窗 hp<60 局的买牌构成(战力件 vs 减损件
  比例);②P1 末 hp≥60 占比跨局迁移;⑳+1 型局(遭遇大失血后)复验。

#### 语义 P1-b:追级节奏让位(P1 内血线停追级)

- **语义**:P1 备战帧 hp ≤ ceil(d·L_c_P1)(d=升级收益到账延迟的战斗场次,
  d≥1)时拒绝升级——P21 判据形式(存活到账 h > d·L_c)的 P1 段应用,
  L_c_P1 = `registry.vd_p1_loss_*` 线性拟合(`L_c(rung)=11.32−0.37·rung`,
  rung2≈10.6)→ P1 停追级线 ≈ **11 血(d=1)**。
- **数学依据**:P21(math_proofs 证明集)已证:存活到账判据 h > d·L_c
  在 h ≤ L_c 域内恒假 → 升级收益恒 0、EV = −C − I 严格为负;P1 的
  L_c 由 `vd_p1_loss_*` 遥测拟合单一源给出。数值只写常量名
  (设计参数表 `P1_LEVELUP_STOP_L_C`,取值来源=registry 拟合)。
- **sim 可验性**:段级检查项「plane=1 ∧ hp≤停追级线帧 actions 不含
  LevelUp(plane_last_battle 窗除外)」;异常帧计数归零。
- **实机验证路径**:低血局的升级次数-血量轨迹判读(⑳+1 的 P2 同款检查);
  注意 P1 停线≈11 很深,预期触发少——此语义是**完备性条款**
  (堵死 1 血局仍升级的角案),主杠杆在 P1-a/P1-c。

#### 语义 P1-c:锁线时点前移(血预算不足不再付搜索成本)

- **语义**:末窗 hp<60 且尚未锁定时,**不再为挑线/换线付刷新搜索金**
  (自然刷新便车照搭、锁定动作本身照做);已锁线则维持 [23] 不 pivot 不变。
- **数学依据**:刷新金的合法用途只有两项目标件/保血急救([31]④ 硬约束);
  换线搜索 = 为「找到更优线」付刷新费,而 W516 已证末窗板面改动经 β 弱通道
  兑现不了血(同 P1-a 证据链);搜索期望收益 ∝ Δp(β 未标定)→ 血预算
  不足时收益项不可信、成本项(2 金/次+息损)确定——期望符号为负。
- **sim 可验性**:配对 A/B 段级检查项「末窗 ∧ hp<60 帧 refresh 笔数下降」;
  锁线完成轮次不晚于基线(锁的是「不再追加搜索」,不是「更早锁死」)。
- **实机验证路径**:判读末窗 hp<60 局的 refresh 次数与去向(战力搜索 vs
  保血急救);⑳+1 型局 R8-R9 备战刷新行为复核。

#### 显式不做(P1 段边界,沿 11 号件)

r3-r7 中前段的深亏响应(投资节奏前置)仍归 W248 假设 A 辖域,本件不卷入
(11 号件 §2.3 边界维持);血预算线在 P1 只改**末窗**支出结构,不改
中前段授权——把触发推前会与息纪律正面相撞,须单独经济账裁决。

## 3. P2 血危机停手语义

### 3.1 停升级线(数学推导,可先行)

- **语义**:P2 备战帧 hp ≤ 停升级线时拒绝购买经验(追级泵停转);
  `plane_last_battle` 窗(P2 r7 boss 前唯一 ALL IN 清零窗)让位除外。
- **推导链**(输入=registry/既有标定常数,输出=阈值):
  1. 判据形式单一源 = P21:升级经济性 ⇔ **存活到账** h > d·L_c ∧
     **受益覆盖** Δp·Σ_{b≥d} L_c·S(b) > C+I。P21 已证濒死域内两条件
     联合不可满足,且敏感网格 (p,Δp,d,c) ∈ [0.10,0.30]×[0.05,0.28]×
     {0,1,2}×{4,6,8} 全负域——**结论在 β 未标定期(p≤0.30)与 β 无关**。
  2. L_c 取 `registry.vd_p2_loss`(20.05,P12 收益侧条件败局伤害口径,
     registry 单一源)。诚实边界:P21 实机语料独立估计 15.39(弱板人群),
     两者口径差(收益侧 vs 濒死截断语料)为已知标定核对项(§5.4);
     保守取 registry 值 → 设计参数表 `P2_LEVELUP_STOP_L_C` = 20.05(设计期
     来源标注:registry.vd_p2_loss,P12/ADR 口径)。
  3. d 取 1(升级→人口生效→下一场战斗的最短诚实延迟;P21 证 d=0 亦负,
     取 1 更保守)。停升级线 = ceil(1 × 20.05) = **21 血**;d=2 时为 41 血
     (到账更慢的升级,如跨 2 级或无单位可上,线更深)。
  4. 核对:⑳+1 局血线 16 时追级泵开 6 次——16 < 21,新语义下这些次全被拒;
     血线 1 时开 12 次同理。**该局即为实机第一票反例样本**。
- **cost 侧锚**:升级费 C 由经验表决定(`XP_PER_BUY=4`,
  `XP_TO_NEXT_LEVEL`={5:20,6:40,7:52,8:72})——濒死段升级一次跨级花费
  20-72 金,而 P2 每败失血 15-25:金换不到一场活(P21 ③ 表 EV −19.75 起)。
- **sim 可验性**:段级检查项「plane=2 ∧ hp≤停升级线 ∧ 非 plane_last_battle
  帧 actions 不含 LevelUp」;配对 A/B 看 hp0 率与死时携带金(预测:死时金
  略升、hp0 不劣——本语义省钱不救活,救活的主杠杆是 P1 侧 §2)。
- **实机验证路径**:每局判读第④问(购买有效性)加一栏:血≤21 时升级次数=0;
  结算屏逐轮读数([27] OCR 采集点)攒 hp-升级轨迹。

### 3.2 停刷新线(挂 β 门,不可先行定量)

- **语义(结构部分,可先行)**:血危机下刷新只允许一个用途=**保血急救**
  ([31]④ 硬约束既有归类)——即「刷出的件本战/次战上场能兑现战力或羁绊档」;
  为未来收益的战力搜索型刷新停付。
- **阈值(数学部分,需标定)**:刷新 2 金/次的期望收益 = Δp(刷到目标件
  的概率增量 × 胜率斜率 β)× 剩余场可避免伤害 − 刷新费 − 息损。β 未标定
  → 收益项不可计算 → **停止线数值推导不出,明说「需标定」**,挂开臂判据
  (§4)。结构语义先行(上面一条)即可覆盖 ⑳+1 的主要病灶:血线 16/1 时的
  追级泵与战力搜索刷新都属「非当轮转化」支出。
- **sim 可验性**:标定前只锁结构语义(急救型刷新笔数不变、搜索型归零);
  标定后补数值检查项。
- **实机验证路径**:同 §3.1,血-刷新轨迹 + 刷新去向(目标件 in-board?).

### 3.3 与 P2 花金义务的对偶(边界声明)

W516 结论②的「P2 花金义务」(死时攥 119 金=机制性断供)是本件对偶面:
血危机停手管「hp 低时**不为未来**花钱」,花金义务管「hp 预算尚可时**必须**
把金换成当轮战力」。两者共用 §2.2 同一条预算算术,禁各写一套判据。
花金义务的收益项量级依赖 β → 其立项/开臂同走 §4 门,不在本件辖域
(实现批另行立项时两语义必须同批设计接缝,防一个加义务一个减义务的
双计)。

## 4. β 未标定的处理(策略开关的生命周期)

按 strategy-work「策略开关的生命周期」逐态过:

### 4.1 等 β 标定的臂(开臂判据挂账,默认关+零漂移锚)

| 臂 | 依赖 β 的原因 | 开臂判据(挂账) |
|---|---|---|
| P2 花金义务的收益项量级 | 花金换胜率的斜率未知,买多少才算够不可算 | β 点估计落定且 > 边界 0.04 有显著分离 |
| 停刷新线数值(§3.2) | 收益项 Δp×β 不可算 | 同上 |
| 星级/战力加权类(SW10 族) | W516 已证:不连带 β 标定则 sim 测不出、实机难归因 | β 标定后重跑配对 A/B |
| BETA20 型校准注入 | 是校准臂非策略臂 | 非策略开关,归标定批 |

**标定路径**(单一源=W516 可行动检查项 C):结算画面读数逐局积累——
[27] 结算屏 OCR 三项拆解(挑战进度±N/基础伤害-X/未完成进度伤害-Y)是
既有真值采集点,逐局落盘 hp/胜负面/掉血真值;P2 胜例攒到 n≥10 后做
β 点估计(按 ADR-0377 敏感性口径:修法须在带端点一致翻正才裁分布级)。
与 W517a/W517b 协同:标定批负责采集与点估计,本件的挂账臂在其结论落地后
逐个过开臂判据;**开臂前默认关+零漂移锚,禁悬置不验**——数据齐即跑 A/B,
验证不过的臂进定谳清理态(删码留 ADR),不无限挂起。

### 4.2 不依赖 β、可先行的语义

1. **P1-a 末窗支出降格**:依据是 W516 排除结论(方向性:弱通道换不回血),
   不需要 β 量级;减损路径收益无 β 依赖。
2. **P1-b / P2 停升级线**:P21 敏感网格覆盖 p≤0.30 全负域——β 标定前
   (胜率模型钳在 0.5、观测 ~0.25)结论稳健。
3. **停刷新结构语义 + 当轮转化豁免**([32]):结构判据无数值。
4. **60 线本身作为判读锚**:它是观测分界(活局 60.7)与预算算术
   (w*=0.32)的交点,先做判读与 sim 检查项,落码随实现批。

**重推条件(诚实边界)**:P21 全负域覆盖到 p=0.30;若 β 标定后 P2 常态
胜率 >0.30,§3.1 停升级线与 §2.2 的 w* 表须按新 w 重推(推导链不变,
输入更新)——此条件写进开臂判据的连带义务。

### 5.2 与息线门的关系(AND 串联,血线不新增覆盖态)

息线门(interest_floor 族拒付)与血线门是**独立谓词取与**:任一不过即拒。
冲突裁决由 AND 语义自然给出,无需新优先级:
- 金>50(息线放行)∧ hp≤停手线 → **血线胜,拒付**——依据:W516 死时
  携带金 119 的镜像面:血预算不足时,花金的收益通道(β)弱到兑现不了,
  「息线放行」只是说金侧无息损,不是说这笔花有正期望;
- 金<50 ∧ 血预算充足 → 息线胜(既有纪律不动,[17]);
- 唯一豁免=当轮转化支出与 [11] 同息档零损购买([31] 填充层正当用法),
  与 11 号件 §3.1 口径一致。

### 5.3 与 discipline 覆盖序 / 承接门 / 锁线门 / ALL IN 的优先级

| 既有门 | 关系 | 谁让谁 |
