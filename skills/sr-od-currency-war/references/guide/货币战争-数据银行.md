# 货币战争-数据银行（图鉴分类菜单主页）

**识别**：`is_precise` 命中 `货币战争-数据银行`（锚：标题「数据银行」+ 入口卡「角色图鉴」双文本组合）。
**目标**：六大图鉴（羁绊/角色/装备/投资策略/投资环境/竞争对手）的入口页，也是各图鉴收集进度的读数位。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：大厅右侧「数据银行」按钮（实测过）；或备战顶栏「数据银行」。
2. **主页 2×3 入口卡**：羁绊图鉴/角色图鉴/装备图鉴/投资策略图鉴/投资环境图鉴/竞争对手图鉴，各带收集进度 n/m（动态值）；点卡进对应图鉴（点卡身亦可）。
3. **出口**：ESC 或右上返回箭头回上级（从大厅进回大厅）。

## op 指针与数据通道

- 进入货币战争用 `CwEntryEnter {}`；本页无专 op。
- 采集通道：`HarvestInvestCodex`（投资策略图鉴逐页采集）。其余四张图鉴子画面尚未建档，按采集需求另派建档。
- **查数据优先走 MCP 查询工具**（cw_char_lookup / cw_trait_lookup / cw_equip_lookup），不必进画面翻图鉴；进画面只在核收集进度或截图取证时需要。

坑：扩充倒计时与进度 n/m 是动态值，勿当画面锚。
