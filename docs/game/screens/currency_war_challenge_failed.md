# 货币战争-挑战失败(团灭 match-over 屏)

某轮出战 HP 归 0(团灭)→ 本屏 = **对局失败结束**(match-over)。与「货币战争-结算」(回合结算,继续挑战)**不同屏**:本屏「下一步」(非「继续挑战」),id_mark「挑战失败」(非 继续挑战)。

## 何时出现 + 状态流转

- **入口**:出战 → 战斗 → **小队 HP 归 0(团灭)** → 本屏(挑战失败)。
- **出口**:点「下一步」→ 对局评价页(对局未完成/阵容/积分/投资回顾,「下一页」翻)→ … → 货币战争大厅/新局。
- **与回合结算区别**:回合结算(赢/挑战结束)用「继续挑战」(对局继续,`货币战争-结算`);本屏(团灭)用「下一步」(对局结束,match-over)。bot 据此判**对局是否结束**(继续 vs 下一步)。

## 识别特征(稳定锚点)

- **「挑战失败」标题**(上中,~(960,235))—— id_mark。CW 独有(他屏「战斗失败」≠「挑战失败」,无碰撞)。
- 「小队生命值❤！」(HP 0 标记)+「对局评价」+「下一步」。

## 可交互元素

| 元素 | 位置(中心,1080p) | 说明 |
|---|---|---|
| 「下一步」按钮 | (960, 896) | 推进到对局评价页(→ 大厅/新局) |

## automation 要读信息

- **is_failed(对局失败)**:本屏 = 团灭(match-over)。recognizer `settlement` 的 `is_failed`(_FAIL_MARKER「挑战失败」)在此为 true。但**本屏 ≠ 货币战争-结算**(不同 id_mark)—— bot 须分别识别:结算(继续挑战,对局续)vs 挑战失败(下一步,对局终)。
- 小队生命值(HP 0):团灭确认。
