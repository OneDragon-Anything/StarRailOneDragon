## 术语定义

- **接缝面**:决策层(cw3 壳)与供给/执行层(sim 引擎、生产 operations)之间「谁写、谁读」的交界。本批针对的病灶形态 = 登记面宣称完备、消费面断链且断得无声(审计总评原文)。
- **真值链**:同一语义多个来源按可信度排序的取值链,先命中先用。
- **fail-closed**:输入不可判时选择「关闭行为」(不刷/不卖/不开门),与 fail-open(拍一个值继续开闸)相对。
- **n_planned / n(发射)**:刷新计划账(机器判出的预算型刷数)与实际发射刷数(本帧收敛后)两个记账键。

## Context

cw3 决策薄壳接线上线后,合并接缝审计(`CODE_AUDIT_SEAMS.md`)发现 13 条问题;同批 A/B 第一轮(`AB_FAIL_ATTRIBUTION.md`,cw3 vs legacy_v2 各 40 seed)归因出「新层几乎不出手」的实现层成因,其中刷新预算型多刷 × 引擎逐动作消费(段上限 8)的联锁使 104/277 帧刷新早退、**323 笔已批准买入被推迟/当轮丢失**。本批修复五处行为变更点(下 1-5)加一处归因驱动口径收敛(第 6 点);修复后 20 新锁 + 151 cw3 锁复跑绿,A/B 判据池污染风险解除。

各点的病灶(修复前行为):

1. **节点子门死码(S-2)**:`node_has_combat` 读 `state.node_type`——sim 侧该字段从不赋值(恒 None → 恒 True),生产侧节点行被遮时恒 None(也几乎恒 True)。「奖励/补给节点不刷」这条 p40 变体⑥子门两侧实际都是死码;引擎专门为决策准备的 `session.node_type_current` 真值通道(ADR-0276:sim 每决策前写节点采样词、生产 prep_director 每备战帧写节点行识别词)被闲置。
2. **免费刷额度未进帧(S-5)**:持「每节点免费刷」类注入时,执行层免费刷实付 0,但壳的 R1 门按全价刷成本算预算 → 门偏紧 → 有免费额度时该刷不刷,注入局系统性少刷。
3. **腾席数与买入意图不匹配(S-6)**:卖出腾席循环「腾到 1 席即停」,而发射序仍发全部 BuyCard → 多买入场景第 1 笔成交、后续被 ADR-0283 满栏守卫拒买,`decisions['buys']` 遥测虚高(计划账与实际账系统性不一致)。
4. **概率真值旁路(S-7)**:sim 轮岗注入局引擎已按翻倍表发牌(`state.refresh_probs` 就绪),壳的帧恒传 None 退基线表决策——恰在轮岗建模下基线偏差最大(选了必 100% 重掷)。
5. **fail-closed 双标(M8)**:`calibration.py` 阈值类缺省走 fail-closed(None=关臂),p41 待标定项却给具体拍值直接进 `decide_sell` 定价 → 「几乎恒判卖」实际由拍值驱动,与全套机器纪律自相矛盾。
6. **多刷×段上限联锁(归因驱动)**:薄壳按「刷新发生则本帧止、下一决策环重判」设计,引擎逐动作消费 + 段上限 8 使「重判」成本变成每次一段——预算型多刷(n 实测最大 38)把同帧已批准的买入全部挤出当轮。两侧语义各自成立、组合后互相破坏。

附带修复(同批,行为相关):`cw_paid_refreshes` 生产写点补齐(S-1:生产侧零递增点使 R05 长线利好 30 刷门/派息门实机永不开,sim A/B 结论不可迁移)与计数器生命周期 owner(S-8:`StrategySession.cw_paid_refreshes` 升正式声明字段,`on_match_start` 归零 = 生产侧 owner,sim 侧 owner = 引擎局装配点,跨局复用 session 不滚账)。

## Decision Drivers

- sim 与生产必须同语义(否则 A/B 判据池被「sim 开门/实机关门」的局混入污染,不可事后拆分);
- 每个帧键/计数器/字段必须有 grep 可证的写点与消费点(审计验收门建议);
- fail-closed 统一:未标定量不可定价,禁拍缺省值开闸;
- 决策遥测(`decisions[...]`)必须与实际发射一致(测试对拍与判读的前提);
- 323 笔买入丢失必须治本:消除「刷新与买入争抢同一帧的发射预算」的结构,而非调段上限数值。

## Considered Options

**第 6 点(多刷×段上限收敛,主裁决点):**

1. **预算型多刷一次帧内完成**(审计归因建议的候选 A:全 n 同帧发射,验收按「发射数 = 计划数 ±1 容差」锁):立刻恢复当轮吞吐,但同段多刷定价不重估(S-13 挂账)被放大 n 倍,刷新后的新店面买入不经重判——把「买入被挤掉」换成「按过期店面决策」,方向不对。弃。
2. **只给买入让路、保留刷新早退**(旧口径最小修:先买后刷、刷后仍止帧):修掉 323 笔丢失的主体,但「预算型多刷」仍一次性吞掉 n 段执行预算、每刷不经最新店面重判,只是损失形态变轻。不彻底,弃。
3. **一致性判定口径(选定)**:预算账一次定 = n 全额在本帧判读入账(`decisions['refresh'].n_planned`),**发射收敛到每帧 1 刷**,多刷经执行环逐动作重决策逐帧重判自然展开、执行环段上限兜底;同帧已批准买入**先于刷新发射**(本店合法买入不丢,新店面由下一段重判)。行为正确性判据 = 计划账(n_planned)与发射账(n/逐帧累计)对账一致,而非「发射数 ≈ 计划数 ±1」的容差验收——容差会把「少发」藏进合法带,一致性判定少发即红。取舍 = 预算展开跨多帧(单轮耗时上升)换每刷经最新店面重判 + 决策/遥测/实际三方一致。

**第 1 点(节点子门):** 候选 a = sim/生产各自给 `state.node_type` 补写点(死字段复活)——与 ADR-0276 已建的决策供给位平行再造一条通道,双源漂移风险正是审计指出的「一旦哪天有人填值即静默分叉」。弃。**选定** = 读既有真值链 `node_type_current` → `last_node_type`(shop 关态兜底)→ `state.node_type`(末位兼容),读不到任何真值 = 保守按战斗节点处理(门不开,不静默禁刷;fail 方向与旧兜底一致)。

**第 4 点(概率真值):** 候选 = 壳侧按环境名自行折算基线×2——在决策层复刻引擎翻倍表语义,第二概率源,环境建模一变即双源漂移。弃。**选定** = 帧装配缺省读 `state.refresh_probs` 实读直传 `resolve_prob_table`,无观测退基线(告警按进程去重的既有行为保留);真值单一源仍在供给侧。

**第 5 点(fail-closed 统一):** 候选 = 给 u/H 拍保守缺省值(低价件 u 值)让腾席在未标定期也能开——「保守拍值」仍是拍值,方向保守不改变纪律双标的性质,且腾席卖件是直接销毁资产的动作,拍错代价不可逆。弃。**选定** = `u_by_cost` 缺省 None → `V_opt` 不可定价 → `decide_sell` fail-closed 持有;腾席解锁条件 = 标定批经 `calib_v1()` 单一源注入 u/H(缺省路径锁保留,防回归)。

**第 3 点(腾席数):** 候选 = 保留腾 1 席 + 削减买入发射数到 1 笔——反向削足适履,买入吞吐为腾席逻辑让路。**选定** = 腾席目标数 = `min(买入意图数, bench_cap)`,精确对齐,不引入 ±1 容差(满栏拒买是硬失败,容差无收益只藏问题)。
