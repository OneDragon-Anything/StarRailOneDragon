# 机制：优势布局（局外成长系统）

> 优势布局 = 货币战争的局外成长系统：在大厅里用专用货币激活节点，为**后续对局**提供额外机制或角色增幅；单个对局内不消耗、不变化。
> 本文为**网络调研**结论（调研于 2026-11-18，v4.7 入画奇航赛季），逐条给出处；§2「1 血免死」定位**已定谳回填（2026-11-19 对账：「保险机制」节点当日真实存在并被激活、生效一例后，当日被官方移除——当前版本树无此机制，归零即终局）**，树节点全量官方文案逐字录见 `docs/game/screens/currency_war_advantage_layout.md` §4。

## 1. 系统官方名称与构成

- 系统官方名「**优势布局**」。官方玩法说明原文：「激活『优势布局』，可为后续的对局提供额外机制，或增幅角色的战斗能力。每场对局结束后，将获得一定的『等价钻钞』，用于激活『优势布局』中的各项机制。」出处：<https://sr.mihoyo.com/news/160700>（S1 时期官方文案；英译对照 "Advantage Layout / Equivalent Banknote"，见 <https://www.reddit.com/r/HonkaiStarRail/comments/1on1iy7/currency_wars_gameplay_guide/>）
- v4.7 起分两区（官方赛季说明原文）：「**赛季优势布局**」——进度每赛季统一重置，用「**幻乐晶球**」激活各项效果；「**常驻优势布局**」——完整保留，此前解锁的节点不受影响。出处：<https://www.miyoushe.com/sr/article/79258376>
- 幻乐晶球为道具，图鉴描述「通过『货币战争』玩法获取，可用于激活【优势布局】」。出处：<https://wiki.biligame.com/sr/幻乐晶球>

## 2. 「1 血免死」类效果的定位

- **官方基础规则没有免死**：玩法说明原文「开拓者拥有初始小队生命值。在多个节点的战斗中，需要在有限行动值内消灭全部敌人，获得战斗胜利。若未在规定行动值前消灭所有敌人，则扣除一定生命值。**当生命值为 0 时，将结束对局**。」——小队生命值归零即对局结束，无保底。出处：<https://sr.mihoyo.com/news/160700>
- **当前版本裁定（2026-11-19 全扫）：HP 归零 = 立即终局，无兜底**。优势布局两棵树逐节点详情全扫（常驻 12 节点 + 赛季树全部，帧 `screenshot_20261119_230936~232823` 系列）——**无任何名为「保险机制」或效果为「首归零回 1」的节点**，全部节点官方文案逐字录见建档 doc §4；实机三局 HP 归零（2-1 普通战斗 / 2-7 位面末首领 / 3-5 遭遇三类型）全部直终局。线上节点清单仍未公开（BWIKI 货币战争主条目该节为目录占位），节点全量以大厅实读为准（建档 doc §4）。
- r11 一例「3-7 最终首领战败 HP 8→0→回 1、结局翻转为挑战成功」**已定谳为真实生效（2026-11-19 对账）**：该局发生于「保险机制」节点激活之后，与该节点效果「小队生命值首次将要降低至0时，保留1点生命值以避免游戏结束」逐字吻合——系当时真实存在的保险机制节点生效，非读数误差（早前「读数误差 / 长线作战战后回血叠加」两解作废；长线作战官方文案为战斗后回复 2 点小队生命值，非免死）；该节点当日即被官方移除（下条），此后各局归零直终局与移除时间线自洽。
- **「保险机制」节点完整时间线（2026-11-19 定谳，素材 = 帧 `screenshot_20261119_130942~131830` 系列 + 全扫帧 230936~232823 系列）**：①**当日存在**——2026-11-19 13:17 以 ×100 幻乐晶球激活（四重帧证：详情面板解锁态费用 ×100 / 按钮变「已布局」/ 余额 165→65 / 已布局计数 24→25），官方效果原文「小队生命值首次将要降低至0时，保留1点生命值以避免游戏结束。受到的伤害降低10%。治疗强度和护盾强度提高10%」；②**免死实证一例**——同日 3-7 最终首领战败 HP 8→0→回 1、结局翻转为挑战成功（上条）；③**当日被官方移除**——同日 23:09~23:28 两树全扫无此名无此效果，移除窗口 = 当日 13:18~21:49（下界 = 21:49 一局 HP 归零未触发保底）；非改名（效果与现存节点无一相同），**无 ×100 退费**；④**归零恢复终局**——移除后各局 HP 归零全部直终局（首条）。定谳细节与帧拓扑见建档 doc §3/§4.2/§5。
- **血线规划保守口径维持不变**：按「归零即终局」规划，无兜底无例外（decision-guide §6）——「保险机制」已随官方移除失效，不存在「激活后可放宽」路径；优势布局激活进度是账号级状态，判读 HP 行为前先查大厅优势布局界面（§3）。

## 3. 与对局的关系

- 优势布局效果跨局生效：激活一次，之后每局都带；按官方文案其效果分「额外机制」与「角色战斗能力增幅」两类。
- 货币来源：对局结算发放——S1 文案为「每场对局结束后获得等价钻钞」；S2 赛季区为游玩收集幻乐晶球（赛季说明原文「在新赛季中收集幻乐晶球，用以激活各项赛季优势布局效果」）；**晋升等级奖励也是来源之一**——晋升等级 30 级时一次性奖励 120 幻乐晶球（2026-11-19 实机口径，当时 28/30 待领）。
- 对局自动化含义：读对局行为（如免死）时不能假设所有账号规则一致——优势布局激活进度是账号级状态，判读免死/初始增益类行为先查大厅优势布局界面。
