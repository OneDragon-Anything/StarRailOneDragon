## 0. 为什么前几次重构失败(病理,防止复发)

历次重构改变了**代码结构**,没有改变**决策权限的来源**——决策仍是查表拍值(手调权重/预编时间表/默认方向),错误定价必然长出补丁(仲裁例外/补救轮/豁免通道),补丁堆积回垃圾。本次的差别:

1. **数学先行**:任何决策规则先有证明(或显式声明的待证假设),未证不落码(ADR-0482 纪律在重建中延续);
2. **学说在地基里**:用户口述裁定 [1]-[42](user_playstyle)+ 本会话 14 条阵容选择裁定(comp-selection.md)是设计前提,不是事后校准材料;
3. **资产/垃圾边界预先划定**(见 §2 生死清单):知识层(对游戏的观测)与决策层(对旧代码的决策)分离,推翻后者不伤前者;
4. **防回流清单**(§4):把历史病灶写成禁止形态。

## 1. 目标(用户确认,全程序服务于此三条)

1. **过渡阵容稳定过位面 1**(成型判据 = user_playstyle [13]);
2. **终局阵容稳定通关货币战争**(证据门锁定后不打折地走完满养);
3. **效率**:在不牺牲前两条的前提下,经济期望最大化([22]④ 经济期望是策略评审的统一标尺)。

## 2. 生死清单(什么死、什么活)

### 处死(全部重写,不参考其实现)

- 决策核心:`kernel/cw_intention.py`、`kernel/cw_recipe.py`、`kernel/cw_transition.py`、`kernel/cw_evolution.py`、`decision/` 全部(decision_v2 家族)、`kernel/cw_strategy*.py`、`kernel/cw_line_defs.py`、`kernel/cw_line_switch.py`、`kernel/cw_deploy_logic.py` 中的一切「拍值/配方/围栏」逻辑;
- 依据上述实现的全部 ADR:归档不删(历史可考),**不再构成任何约束**;
- 全部旧证明(P1-P37):命题可参考,**推导与前提不继承**,逐件在新证明树下重推;
- `kernel/cw_comps.py` 的决策函数(`comp_score`/`select_comp` 及其权重族)。

### 保留(资产,重建中不碰)

- **知识层文档**:`docs/game/currency_war/` 全部(research/ + data/)——对游戏的观测,不是对旧代码的决策;
- **数据注册表**:`data/cw_chars.py`、`cw_factions.py`、`cw_equipment_data.py`、`cw_shop_odds.py`(概率表/池参数/期望模型=机制事实)、`cw_invest_data.py`、`cw_enemy_data.py`、`affix_effects_data.py`、`cw_battle_tables.py`;
- **自动化操作层**:`obs/`(画面识别/读数)、ops 链(点击/拖拽/流程)、screen_info 建档;
- **模拟与遥测**:`sim/`(框架保留,策略被测体替换)、`telemetry/`(判读口径保留);
- **`kernel/cw_state.py` 的状态语义**(GameState 字面量保留;字段随新决策需要增删,由设计文档声明)。

### 待判(重建中逐件裁决)

- `kernel/cw_economy.py`:经济**事实函数**(收入/息/卖退金/刷新价)保留;其上的**决策函数**(预算/姿态)死;
- `kernel/cw_comps.py` 的 `COMP_LIBRARY` **数据**:保留为起点,字段按新知识形态增删(§3);
- `kernel/cw_bond_equips.py`(羁绊计数语义,P19 已证)、`kernel/cw_synthesis.py`(合成图谱派生,P14 生产函数):机制事实层,保留——**豁免章程**:机制事实类旧证明(判据=命题只证代码/机制行为、不含策略期望主张)随知识层保留、豁免重推;P19② 两遍法修正落地仍是 Phase 3 前置任务(修正的是已登记实现缺陷,非重推命题);
- 各 `cw_plugins.py`/`cw_effect_*`:按「机制事实 or 决策拍值」逐件分拣。

## 4. 防回流清单(历史病灶 → 禁止形态)

| 历史病灶 | 禁止形态 |
|---|---|
| `FALLBACK_COMP_NAME='绯英欢愉'` 默认方向 | 任何「无决策时的默认阵容/默认动作」;「不动」是合法候选,无候选才不动 |
| `_DEFAULT_LEVEL_GOAL` 双源等级曲线 | 任何形式的预编节奏载体(level_plan/typical_form_round/轮窗/配方围栏)——升级/刷新一律 EV 实时算(Ruling 14) |

| 频率入权(_P1_PAIR_PREF/攻略热度) | 采用频率永不入权(Ruling:权重默认等权,环境分化=机制层知识) |
| 仲裁纪律否决半边 + 补救轮(rule_v2 流水线) | 「例外通道/豁免/补救轮」作为结构性机制;合法的预算序语义可重新设计,但必须单一规则全覆盖 |
| 系数知识洗白(sim-power-model 四形式禁令) | 任何拟合值冒充机制知识进入决策权重 |
| 中间形态预编程(P2 形态表) | P2 中间形态不定义;完成目标按结构里程碑分档(Ruling 13) |
