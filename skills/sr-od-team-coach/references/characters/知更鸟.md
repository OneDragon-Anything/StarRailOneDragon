# 知更鸟（物理·同谐·5星）

> 按 V4.7 期撰写。协奏全队联动攻击：加攻面板吃自身攻击 + 每次攻击追加物理伤害。

## 一、命途属性与技能说明

**命途**：同谐；**属性**：物理

| 技能 | 说明 |
|---|---|
| 普攻 | 单体50%攻击物理伤 |
| 战技 | 全队伤害+25%~55%（3回合） |
| 终结技「千音迭揍」 | **消耗能量160**；进入【协奏】：除自身外队友**立即行动**；协奏期间全队攻击+（知更鸟15.2%攻击+50点）；**我方每次攻击 → 知更鸟追加72%攻击物理伤（暴率100%/暴伤150%固定）**；倒计时90速，期间自身不行动 |
| 天赋 | 全队暴伤+5%~23%；我方攻击后知更鸟回2能量（160能的回能引擎） |
| 秘技 | 领域；每波次回5能 |

**满级数值**【官：米游社百科行迹表】：扑翼白声 110%(Lv7) · 翎之咏叹调 55%(Lv12) · 千音迭奏，群星赋格 24.3%/230/129%(Lv12) · 调性合颂 23.0%(Lv12)。完整等级表见百科。

**资源与循环**：**160能量（同谐最贵）→充能绳刚需**；天赋回能是循环核心。

## 三、推荐配队与原因

| 阵容 | 为什么 | 备注 |
|---|---|---|
| **追击队（飞霄/托帕/真理+砂金）** | 每次追击都触发协奏追加+回能——体系发动机 | 追击队核心 |
| 智识AoE队 | AoE 每段都触发 | 跨体系 |
| 高频攻击任意队 | 协奏收益=攻击次数 | 泛用 |

**硬否决**：加攻对生命/欢愉模型无效；160能启动慢，超短战打折。
