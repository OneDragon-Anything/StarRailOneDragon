# 邮件(email)

游戏内标题为「**邮箱**」(左上角)。手机菜单「邮件」入口打开的收件箱画面:左侧邮件列表 + 右侧详情。`pc_alt=true`(click_game 需带 `pc_alt=True`)。

## 何时出现 + 状态流转

- **入口**:手机菜单(`菜单`)点右侧「邮件」图标(≈1867,272;红点=有可领附件)。
- **出口**:
  - 点右上关闭 X / esc → 回手机菜单 → 再 esc 回大世界。
  - 领取附件成功 → 弹「获得物品」弹窗(点击空白处关闭)。
- **子态**:
  - 列表态(常态):左列表 + 右详情。
  - 规则说明弹窗:点「规则说明」→ 居中弹窗(标题 邮箱 + 容量/删除规则说明),点 X 关闭。
  - 获得物品弹窗:领取成功后出现,「点击空白处关闭」。

## 识别特征(稳定锚点)

- **标识-邮箱标题**:左上「邮箱」文字(≈103,39),全屏独有,id_mark(conf 0.9999)。
- 底部三按钮文字:删除已读 / 全部领取 / 删除(均 OCR 稳定)。
- 邮件列表每封:标题 + 「列车组」+ 剩余天数(如 29天);选中封高亮白框 + 左侧 `▷` 箭头标记。
- 易变(勿当特征):邮件标题/数量/日期/剩余天数、附件内容、容量数字(4/1000)。

## 可交互元素(2026-08-29 现场实锤;删除类不可逆出口未点击,行为依据规则说明弹窗原文)

| 元素 | 位置(1080p) | 行为 |
|---|---|---|
| 邮件列表项 | 列表区 ≈(85,115)-(560,620) | 点选切换:选中封高亮+箭头,右侧详情联动(已实锤点第 2 封) |
| 全部领取 | ≈(409,971) | 一键领取所有可领附件;**无可领时置灰**(按钮灰/实两态=可领判据);成功弹获得物品 |
| 删除已读 | ≈(163,971) | 一键删除已读/已领附件的邮件(**不可逆,bot 不用**) |
| 删除(单封) | ≈(1648,969) | 删除当前选中邮件(**不可逆,bot 不用**;星标邮件不可一键删但可单删) |
| 规则说明 | ≈(1664,50) | 打开规则弹窗(已实锤,X 关闭) |
| 关闭 X | ≈(1863,63) | 关闭邮箱回菜单 |
| 附件图标 | 详情区 ≈(607,690)-(850,830) | 点击领取单封附件;已领取的附件图标带对勾标记 |

## automation 要读信息

- **有无可领**:「全部领取」按钮亮/灰(或邮件红点:菜单里邮件图标 alert)。
- 邮箱容量 `4/1000`(左上,动态值):超 1000 自动清理无附件/已领邮件(规则弹窗原文)。
