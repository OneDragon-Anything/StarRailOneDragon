### 〇C、W779 净支出可行性审计(v3.3 核心输入;设计侧离线复算,零落码)

> 数据面:`../w779_sim_ab_v32/` 双臂账本 data_treatment/data_control.json(各 530 局,P2 帧 2253+2279=4532,含 W779 主窗 20/臂——该轮 n=20 违反协议 n=500 已打回,本审计只消费其**观测面与账本**,不引用其判定);复算口径:单帧收入 = base+interest+streak+event(economy §10 公式),净支出 = 当轮金账下降(gold_before+收入−gold_after)。

#### ① 单轮可花上限 vs 收入分布——净>0 可达率

| 量 | 分布(n=4532 P2 帧,双臂) |
|---|---|

| 单轮实际支出 | 中位 4,p75=9,max 66 |

**死亡窗三轮窗级复核(M0b 的实际计测窗)**:346 个 ≥3 帧 P2 窗(实验臂),窗累计收入**中位 93(min 55,max 102)**,窗累计支出中位 10(max 70),**窗水位下降 0/346;高金子群(窗起点 ≥80)0/137**。
> **errata(W786 攻击批判读)**:上句窗数与收入中位为宽口径——346 窗含 108 个存活局,真死亡窗 = 238 个,窗累计收入 med 82 非 93(0/238);bench 容量真值 = BENCH_CAPACITY 9(本节 6-7 为错值);XP 通道为小通道(4 金/帧、窗级 ~12 金)。勘误全档见 `../w785_sim_ab_v4/REPORT.md` §八勘误节。

**审计结论**:①**单帧净>0 在位面 2 中后段(恰是 M0b 计测窗)结构性难达**——不是 v3.2 梯级排错,而是「花超当轮收入」这一判据隐含要求 sink 供给(每轮 15-31 金的可消化出口),而 buys/D/XP 三类 sink 在 rn3+ 全部枯竭。v3.2 净支出闸把「物理不可达」误读成了「机制不努力」。②判据口径必须从单帧改为**授权窗累计/水位**(见②);③机制侧必须**打开无界 sink**(见 §3.1 v3.3)。

#### ③ L1 供给不足的梯级再校准方向(v3.3 机制侧)

### 1.2 缺口的精确位置

决策链(candidates→filters→scoring→arbiter,上承 dp 姿态)在 P2 中段没有一条「授权定向支出」的判据路径:[17]「>50 即花,节点无关」在决策层只有 P1 侧落点(C1);[18]「最小必要支出止损」无 P2 行为落点;[31]②「目标件刷新出现=唯一最高优先级」在锁定后执行面无强制通道(局3 希儿 g40-90 段两度上架零买)。**命题层无辖域空白(W754 问2),是授权/执行层未对齐。**

### 1.3 与换线摇摆域的切分(不同根,勿并批;v3 随止血通道重声明)

- 摇摆域辖:**锁定判据振荡**(engine_seed 振荡簇、pivot 反复)——「锁哪条线」的**决策权**问题,另有批次。
- 本设计辖:**花钱授权**(何时必须花钱的许可问题)。v1/v2 用「锁定状态位」做机械切分;**v3 起止血通道(§3.1 通道 B)与锁定位解耦,切分语义更新为「决策权 vs 出手权」**:止血通道在未锁定帧也授权花钱,但**花钱方向不做任何选线决策**——未锁定帧的授权目标取既有机制的现成输出(v3 hoard 集若在,否则桥池方向件,否则 [31]① 空窗期语义的现有牌最优羁绊填充件),选线/锁线判据一颗不动。两域交界 = 授权通道只消费方向、不生产方向,与摇摆域无判据交集。
- 锁定后执行缺位(本设计 v1 起的主面)仍由常授权/加急层(通道 A)辖,T1 消费 P16 滞回后 locked 位不变。

## 三、设计:位面 2 支出授权机制

### 3.1 触发判据(v3:**两通道**结构;通道 A = 条件授权,通道 B = 止血授权)

> **v3 重构依据**:W762 归因——T1-T4 合取把死亡窗系统性排除(248 个高金死亡局死前 3 轮内仅 38 局有授权帧)。合取里的「可省」项是 T1/T2:死亡局几乎恒满足「血线恶化 ∧ 溢余在手」(末行金≥80 者 248/248),被拦的恰是锁定前提与形态缺口判据。故 v3 拆两通道:通道 A 保持 v2 的定向授权语义(有明确方向才花);通道 B 是**止血授权**——只要求「在流血 + 有钱」,方向取既有机制现成输出,**与锁定位、形态缺口解耦**。

**共用条件(两通道都要求)**:

- **T4 金水位**:g ≥ 50(溢余含满息点;[17]/P13;v2 定谳的边界口径不变)。g<50 段一律不授权(守息不破,P13 账);
- **帧资格**:非分配器接管帧(v6 inactive;§3.3),非 P1(plane≥2 only)。

**T3 血线恶化(通道 B 的触发维度;通道 A 的加急维度)**:近 2 个战斗节点连败,或 hp ≤ P2 警戒带(占位:P1 出口血目标线;占位值待标定)。

#### 通道 A:定向授权层(v2 原语义,条件授权)

- **A-常授权层**([17] 的 P2 落点):T1∧T2∧T4 → 店内出现授权目标(§3.2)→ **必入买序列**;定向 D 按 P12 批账与预算前提;
- **A-加急授权层**([18] 的 P2 落点):A-常授权 ∧ T3 → 预算上界放宽(允许破息至保留金带,**v3.2 公式化下限**见下);**升级仍禁**(血预算停升级线不豁免,濒死带 P21 不豁免)。
- T1:locked = 经 P16 滞回后的 v3 输出(禁接滞回前原始意向位);T2:形态缺口 = stage_transitions Q5 判据未达。

#### 通道 B:止血授权层(v3 新增;W762 归因的覆盖修复)

- **触发 = T3 ∧ T4 ∧ 帧资格**——**T1 锁定前提与 T2 形态缺口解耦**(锁不锁定次要;hp 恶化维度从「报警面」升为通道 B 的触发条件之一,用户 v3 修订方向①);
- **授权内容**:同 A-加急层的预算放宽(破息至保留金带;D 同限);**升级判据不变**(仅 [33] 人口位/[3] 提概率,血预算门 AND,濒死带 P21 恒禁);出手过**净支出闸**(本节 v3.2);
- **支出方向(未锁定帧的方向来源,不做选线决策)——v3.3 校准:L1 经 D 制造供给,主出口=D/XP**:
  - **L1 高价值定向**(能实质消耗溢余的目标):①锁定线核心卡(贵价 3-5 费);②**2★ 升级凑档件**——为已在板/已在 bench 的同名件买第 2/3 副本,触发 3合1 跳档(合成机制=买一张可连锁升档);③线内高费件(3-5 费终局组件);
  - **L1×L2 耦合(v3.3,W779 审计③)**:L1 供给不再依赖店内自然上架——**L2 定向 D 即 L1 的制造手段**:D 连开直到 L1 上架或窗预算尽(D 无界 sink、P12 批账 j≥1 正 EV);W779 实证 L1 自然上架 0 帧,「等贵货」不可行;
  - **XP sink 授权化(v3.3 新增出口)**:hp>停升级线(ADR-0448 门 AND)∧ 非 P21 濒死带 帧,买经验至 carry 概率窗([3] 提概率:c=4,5→L10)为合法授权出口——大额金消耗通道;授权不新增豁免,既有门全数生效;
  - **L3 低价兜底**(量级诚实化 v3.3):bench 容量封顶使 L3 窗累计消耗上限 ~12-21 金——**只能辅助,不得作为唯一出口**;原 hoard 兜底档→桥池→[31]① 空窗填充序不变;**纯散件恒不授权**([31] 反散件原则,[32] 消费有效性)——不变;
  - 重排依据链:v3.2 排序原则([22]③ 稀有越高越该囤+[17] 边际价值量级匹配)保留;v3.3 追加 W779 审计①(sink 枯竭是净>0 不可达的根,L1 自然供给 0 帧)。
- **窗级水位目标(v3.3,取代 v3.2 单帧净支出闸)**:W779 审计①证单帧净>0 在 P2 中后段结构性难达(可达率 rn5-7≈0-2%,死亡窗累计收入中位 93 vs 可用 sink 支出中位 10)——v3.2 的「单帧预期净支出 ≤0 不出手」闸**废除**(它把物理不可达误当机制失败,且 L1 供给缺失时闸住一切出口=M0b 0/9 的机制侧共犯)。取代者:**授权通道以「窗内金水位不升」为出手计划目标**——窗预算=保留金带(D/XP 消耗至上限),单帧净支出降级为观测面(协议 V4 §5);闸的「同方向多候选选净支出大者」排序语义保留(选择器,非门槛)。
  - **hoard 投影失败帧(v3.1,W758 v3 面①攻击 C)**:`hoard_readable=False` 帧的 prep_brain 保守域(整库)**不得用作通道 B 方向源**(整库域含散件,与「纯散件恒不授权」直接冲突;该保守域语义是给既有买侧用的)——投影失败帧**跳过 hoard 级直接落桥池/[31]①**;
  - **bench 保留约束(v3.1,W758 v3 面①攻击 B)**:通道 B 解耦后 T2 形态缺口天然闸消失,授权出手须带 bench 保留约束——**买入后备战席须保留 ≥1 空槽**;不足时按 [22]② 优先级先卖可弃兜底/垫层件(1★ 卖≈净0,[31]④)腾槽再买,腾不出则本帧买入降额;防「连续止血买入填满 bench → 线随后锁定时核心卡无槽可进」的挤出回声(W754 病灶的买侧变体);
- **通道 B 的 D 与 [31]② 硬约束相容性(v3.1,W758 v3 面①攻击 D)**:通道 B 的 D 消费 [31]② 硬约束明文的**「保血急救」合法用途**——T3 触发即其语境锚(止血授权帧=保血急救进行时),刷新金仍只用于找方向件(梯级内)/保血,不为凑数羁绊 D 牌的禁令原文不变;锁定帧通道 B 的 D 找锁定线目标件,直接在 [31]② 正用域内。
- **口述依据**:[18](血低=报警,**正确响应=最小必要支出止损**——v1/v2 把「响应」绑在定向通道上,W762 证明死亡窗帧常无「定向」可用,止血通道是 [18] 响应义务的直译);[17](溢余即花节点无关);[31]①(空窗期是常态,行为=目标优先、羁绊填充、散件垫底——方向降级不等于不花钱)。

**预算带对齐声明(v3 新增;W762 G1-A 破息反降的修正,用户修订方向②)**:

> **「只开门不收门」**:授权通道的预算判定**复用既有息账门的谓词结论,不得额外收紧**——既有判据放行的笔,授权通道不得以自己的地板拒绝;既有判据拒绝的笔,授权不改判。具体:①v2 常授权层的「贴线带证成前保守=不买」子句**废除**(它是比既有 [22]④ 门更严的收门,G1-A 反降的机制之一);②常授权层地板谓词 = 既有门谓词(D:P5「花完仍≥50」;买:[11]/[22]④ 息账),授权层不再叠加独立地板;③贴线带逐点结论仍进 P25 核验项(数学义务保留),但**判定语义从「授权层自设门槛」改为「与既有门同判」**。验收口径:A/B 重跑时 G1-A 结构性破息应回到对照臂水平(±2pp 内),「授权后破息反降」即对齐失败的信号。

**保留金带公式化(v3.2,W772 修订方向②;取代常数 20 占位)**:

> **下限 = 5 × min(本位面剩余备战轮数, 3)**——P13 息流式的直接截断:保留金的收益上限=每轮息 5 金、封顶 3 轮(位面末守息无意义,P13「r9 C=0」同源截断),即下限 ∈ [5,15],**不再是与局势无关的常数 20**。权衡账:在 T3 活跃帧,多保 10 金的息收益 ≤5 金/轮,而其换到的战力若避免一场败局 = 15.39(P2 条件败局伤害)——「救活优先」在数学上压倒「息基」;W772 实证(1462 加急帧/破息仅 53)证明常数下限把出手力度卡死,囤金原样带到死才是真损失。细则:①该下限是**破息授权的地板**而非出手目标(目标由净支出闸+梯级决定);②濒死带 P21 升级禁与血预算停升级线 **AND 不受影响**(下限只辖买/D 预算);③常数 20 降为**绝对异常地板**(防负值/公式输入异常);④G1-B① 护栏阈值随公式化同步重标(协议观测面注明,判据红线本身不动——阈值替换在协议判读脚本参数,不属判据实质变更)。

**双通道同帧合并语义(v3.1 声明,W758 v3 面②)**:通道 A(加急)与通道 B 同帧双触发时(T1∧T2∧T3∧T4∧非接管帧),授权谓词**取或**、预算**取同值交集**(两通道放宽档为同一数值同一谓词,授权是许可不是资金池,无可叠)、方向**同源**(锁定帧 hoard 输出即通道 A 优先级 1 的同一目标集)、动作**去重**——双触发帧两通道输出恒等,不存在叠加效应。

防读半(对齐 W754 问4 反向警示,**v3 修订表述**):hp 低不是 ALL IN 触发器——通道 B 的支出方向仍由「既有机制现成方向输出」决定(买什么由线/桥/现有牌的羁绊结构决定,不由「血要保命」决定),血线只决定**花不花**、不决定**花哪**;真 ALL IN 窗只在位面末死亡域,归 P23 分配器(v6 active 帧授权禁出手不变)。

### 3.2 支出优先级(花在哪)

**序语义声明(v2 新增,W758 面2 攻击 A 封口)**:下表是**授权辖域声明**(哪些动作类型在本授权的「门与预算」辖域内),**不是动作互斥执行序**——同一授权帧内多类动作各自按自己的判据独立过门,不存在「先花完 1 才轮到 2」的串行读法。与既有四层 candidates/filters/scoring/arbiter 的关系:授权改「门开不开+预算上界」,候选与评分公式不动。

1. **锁定线核心卡(必买,最高优先级)**——[31]②「目标件刷新出现=唯一最高优先级,只买它,无竞争」;子面「锁线核心卡在店 ∧ g≥50 → 必入买序列」(单帧锁①;贴线带子句见 §3.1 常授权层,**P25 待证标注**)。数学依据位 = P25(待证明;证成前为设计占位)。按 [21] 窗口语义:买进 bench/凑档,**不无脑上板**(上场等羁绊齐窗;例外=全局累积型,归阵容知识批,本设计不展开)。
2. **凑档件与压库件**——[31]② 填充优先级=对当前板面的边际羁绊贡献;受 [22]② bench 槽约束。**[34] 子序按原文全语义执行(v2 明确化,W758 面2 攻击 B 封口)**:购买序三层(目标件囤满→不买插件;备战席有空→先压库后插件;无可压费用档→才插件 2 星)中,压库判据是**费用档**——含与锁定线无关的费用档压库件([34]①「想压 X 费就买 X 费」),不只是线内件;前提约束照 [34]/[30] 原文:bench 有余槽 + 息线账(常授权层过 §3.1 地板,加急层过保留金下限)。**[30]「成本带买光适用于中后期」是 agent 泛化、未经验证**,本设计不给它独立通道,压库支出仅按 [34] 购买序的从属地位进入。
3. **定向刷新 D 找核心**——P12 批账(j≥1 翻正才付;3费@lv6 j=0 负例保持拒,单帧锁③)+ P5 预算前提(常授权层花完仍≥50;加急层见 §3.1)。
4. **升级——三个合法判据(v2 修订:显式并入 [3] 提概率路径)**:①[33]/[12] 人口位例外(有框架单位等上场,[32] 当场兑现战力);②**[3] 提概率路径**:锁定线 carry 为 4/5 费且当前等级低于其概率窗(P5:c=2→L6/c=3→L7/c=4,5→L10)时,**先升级提概率优先于在低概率档 D**——[3] 用户原话「要升级后才能提高刷新概率,那就升级」,P5 主定理背书;此场景下升级与 D 不是串行关系而是条件分支(carry 费用档 × 当前等级查 P5 表定分支);③[7] 费用段带权衡。硬边界不变:血预算停升级线帧禁;**濒死带(hp≤10)恒禁**(P21)。

**部署不在序内**:P24 补部署是免费域,照常执行(授权帧内 skip 轮补部署继续,与花钱通道互斥不干扰)。

**口述反例边界**(授权不覆盖的形态):空升级([32])、无强单位可上的腾席([32])、纯散件垫底([31])——三者即使溢余在手也不构成「边际价值高的花处」,T2 缺口判据(以本线形态为参照)天然排除。

### 3.3 与分配器 / 血预算门的交界(显式声明)

- **濒死带(hp≤10)与 P23 分配器同帧双轨(v2 机械消解,W758 面3 攻击 A 封口)**:分配器(v6,ADR-0474)接管是**整帧接管**语义(W752 实测:接管帧 621、出手 10 帧、接管帧内管线 chosen 全空);本授权加急层也是整帧出手语义。两者相遇的机械序写死为:**分配器接管帧(v6 active)内授权通道禁出手,授权只在非接管帧生效**——帧归属二选一,不并存。「大额」边界随之机械化:v6 active 的域谓词(停手窗/死亡域)即接管判据,**授权通道自身不设金额档**——接管帧内无论金额大小一律归分配器(其 P23 EV 门管大额、清算子管分配),非接管帧内授权按 §3.1/§3.2 各自判据与预算上界执行,无独立「大额」概念。单帧锁⑨钉死此序。
- **血预算停升级线(ADR-0448)**:授权谓词与停升级线谓词 **AND**(线不豁免授权);授权放宽的只有「买/D 的预算上界」,永不放宽「升级」。
- **位面末窗豁免收窄(v3 修订;W762 归因:死亡多发生在末窗附近,一刀切豁免把最需要授权的帧排除了)**:v2 的「P2 r7 窗本授权不触发」**废除**;末窗的豁免收窄为**接管帧谓词本身**——v6 active 帧(停手窗/死亡域,ALL IN 族与降格语义)授权禁出手不变(锁⑨);**非接管的末窗帧,通道 B(止血)可达**,通道 A 亦按各自条件照常判定。即:r7 不再是独立豁免维度,豁免统一归 v6 谓词。ADR-0451 降格/刷新停付语义照旧(授权不豁免任何血预算门)。
- **dp 姿态 economy 存息模式的豁免消解(v3 新增;W762 归因:金堆积帧多处于 economy/存息姿态)**:授权帧内,**授权出手权优先于姿态的存息结论**——授权通道开启的帧,dp 姿态不得以 economy/存息模式压过授权买/D 的执行(授权 = 姿态层内的强制 SPEND 许可,姿态仍管其余帧的节奏)。这不是姿态双写:授权判据在姿态判据层内落位(v2 已声明),v3 补的是「授权帧内姿态让位」的优先序。
- **血预算门的层归属机械化(v3.1,W758 v3 面③攻击 B)**:血预算门(ADR-0448 停升级线 / **ADR-0451 停付降格**)一律为 **discipline 层谓词,不受姿态让位条款影响**——姿态让位仅辖 dp 的 economy/存息结论,discipline 谓词在让位后照常拦截。二选一写死为 discipline(与 ADR-0448 的 AND 组合同层),防「刷新停付实现在姿态层被让位条款一起让掉」的实施错。
- **recipe_fence 开臂交互**(W754 问5):目标核心卡=配方件,围栏开臂与本授权同向强化——两件**联合盘点**,实施批须声明 both/on/off 矩阵的验证覆盖。
- **C1 溢余必花**:本授权是 C1 语义的 P2 泛化,实施时按「同通道扩展、不平行新开」落位,防止两处判据漂移。
