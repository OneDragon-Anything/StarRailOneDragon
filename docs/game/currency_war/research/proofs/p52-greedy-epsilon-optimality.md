## 命题(定理陈述)

用户核心观点(学派立场,philosophy §3):「**阵容和经济的决策做好了,战力和 hp 就不是问题**」。本件把它证成带 ∎ 的域定理。

### 0. 形式框架

- **局** = 有限视界 T 的序列决策过程(决策点 = 每备战期,默认局 T ≈ 102-105,P51 §4-C 局长中位)。死亡时点 τ_∂ = inf{t : hp_t ≤ 0} 为**吸收态**:其后一切收益恒 0(gameplay 官方原文「当生命值为 0 时,将结束对局」,P51 数据源同条)。
- **策略值**(P51 §1 同框架「期望总收益 = Σ 生存概率 × 每期收益」的算子形式):

  ```
  V(π)  = E_π[ Σ_{t≤T} 1[t < τ_∂] · r_t ]        r_t = 第 t 期净金流收益(纯金流公理,血禁入账)
  V⁰(π) = 同一过程删去吸收态(假想永不死亡环境)下的值
  ```

- **π_greedy(发展优先策略)的形式定义**,三成分:

  ```
  π_greedy(t) = ① 骨架义务集 O_t(常开,无条件执行)
              ∪ ② 经济判据集 J(P39 双臂门 EV_up / P40 刷新三层门 / P47 息律门 /
                 P48 统一囤钱判据[λ≈0 段退化式])
              ∪ ③ λ 面零消费:不读取任何 λ_death 数值驱动行为
  ```

  ① 义务集 O = M1-M7 方法论的常开动作面(资源入口先行/核心×弹性填充/枢纽件照买/过渡骨架拼装[与终局并行]/等级由 carry 费用档驱动/升星次序经济学/装备优先级序列)+ P24 补部署支配(零支出轮残余补空槽恒执行)。② 判据集 J 中的 λ_death 仅经 P39 臂二 (c) 的 floor_eff 二值投影出现——**在 D_ε 上该投影恒取 λ≈0 分支(=50)**,故 π_greedy 限制在 D_ε 上是 λ-自由的(这条域内等价是「无 λ 干预」的精确含义)。
- **任意策略** π ∈ Π:允许读取 λ_death 全量(分层表/连续模型)并据此干预。
- **安全域 D_ε(三元组条件)**:状态 s ∈ D_ε ⟺

  ```
  λ̄(s) · E(s) · H_eff(s) ≤ η
  ── λ̄(s)   = 分层 λ_death(板面战力桶 × 节点类型) 的 CI 上界(P51 §4-B-2;
               决策时可观测口径:分层表 + 桶构成,禁用事后 R——P51 B3/边界 10 照搬)
  ── E(s)   = 财富敞口 = g + Φ(存量金 + 未来纯金流;P51 W_floor 的同一个量)
  ── H_eff  = 剩余有效视界(危险窗数):未来仍处于 λ>0 可达构型的 3 轮窗数
               (P51 视界参数 = 3 轮;实证形态 = 死亡集中局末,P51 §4-B-3)
  ── η      = 目标精度(定理输出 ε 的死亡通道项预算)
  ```

### 定理(P52 主定理:发展优先 ε-最优性)

设 (i) π_greedy 与 π* = argmax_π V(π) 的可达状态均含于 D_ε;(ii) 引理 2 成立(无死亡环境下每期贪心缺口 ≤ δ̄)。则:

```
0 ≤ V(π*) − V(π_greedy) ≤ ε,   ε = T·δ̄ + η
```

且 ε 的死亡通道项 η = O(λ̄):λ̄ → 0 时 ε → T·δ̄(判据残差带),死亡通道消失——「**死亡项是 λ 的高阶量**」的精确含义。

## 证明

### 引理 1(截断账分解与死亡扰动界)

**V(π) = V⁰(π) − D(π),且 D(π) ≤ P(τ_∂ ≤ T) · E ≤ H_eff · λ̄ · E。**

证:逐条轨迹上,V(π) 与 V⁰(π) 只差死亡后各期收益(吸收 vs 假想存活),故 D(π) = E[Σ_{t≥τ_∂, t≤T} r_t] 是两者差的期望。由 A2,死亡后累计收益 ≤ E(s)。死亡概率按 3 轮窗分组用 union bound:P(τ_∂ ≤ T) ≤ Σ_{w=1}^{H_eff} λ̄_w ≤ H_eff · λ̄。相乘即得。∎

**量级读法**:D(π) ≤ λ̄·E = P51 的 W_floor 单窗敞口同一乘积(P51 §4-B:pooled p≤7 = 0.061 × 221.7 = 13.5 金——本件脚本对账 1 逐位复现该恒等式)。λ̄→0 ⇒ D→0:死亡通道是 λ 的一阶量、对「忽略 λ 的决策」而言是**可忽略的高阶修正**当且仅当 λ̄·E·H_eff ≤ η——这正是 D_ε 的三元组条件(philosophy §3「λ×敞口×剩余视界小到二阶」的形式化)。

### 引理 2(无死亡环境下每期贪心最优性——判据背书,条件引理)

**V⁰(π*) − V⁰(π_greedy) ≤ T·δ̄。**

证:V⁰ 环境无吸收态 ⇒ W_floor 通道整体关闭 ⇒ P48 三段管辖坍缩到 λ≈0 段——该段的统一判据退化为原判据且**原强度**(P48 修复批:λ≈0 段现行判据不改)。该段每期决策 = P39 双臂门(升级)+ P40 三层门(刷新)+ P47 息律门(持有)+ P41(卖出)+ P49(压库)——各件已分别给出其动作类内 EV 最优性或支配性;P39 (c) 的段带 telescoping 使逐级边际可加,**实现按两级枚举覆盖回升形态**(贪心≡全局不依赖无回升假设)。逐期缺口合成即得 T·δ̄,δ̄ 的构成与边界见 A4。∎

强度声明:本引理不新增数学,是**判据证明族(P39/P40/P47/P48/P49)的聚合引用**——其强度=所引证明的最弱一环(P39 边界带 sim 对拍项 2 挂账),如实标**中**。

### 引理 3(骨架义务的衔接:发展优先 ≠ 不发展)

**义务集 O 常开保证:① π_greedy 的状态轨迹具有发展性(板面战力单调不减);② 引理 2 的约束前提成立;③ D_ε 的到达集非退化。**

证:③+①:O 中动作均为不可撤销发展类(A5),且 floor_eff=50 在 D_ε 上只约束挥霍不约束发展(臂一硬可负担 g−U_L ≥ 0 与臂二 (c) 的 50 线约束的是「花到哪」,不是「不发展」;目标件照买照囤/M4 骨架与终局并行/P24 零支出轮补部署恒执行)。若 π_greedy 停滞发展,其板面停留在低战力桶直至局末,桶构成进入濒死带(距终≤6),D_ε 条件 λ̄·E·H_eff 随 H_eff→危险窗而**自身失败**——定理前提 (i) 排除该轨迹;这正是定理的域命题本性,不是缺陷。②:引理 2 的各判据最优性均在「义务动作先行执行」的约束下成立(P24:skip 轮补部署严格支配整轮部署禁运;DEATH_POSTMORTEM:A1「该买不买」+B「反应缺失」= 68% 单一死亡模式,即无义务集时「守息贪心」的每期弃购 EV 为负——**不发展的贪心在 V⁰ 中就不是每期最优**)。∎

### 主定理的合成

```
V(π*) − V(π_greedy)
  = [V⁰(π*) − V⁰(π_greedy)] + [D(π_greedy) − D(π*)]        (引理 1 分解,两项分别重组)
  ≤ T·δ̄ + D(π_greedy)                (引理 2;D(π*) ≥ 0)
  ≤ T·δ̄ + λ̄·E·H_eff ≤ T·δ̄ + η       (引理 1;前提 (i):可达状态 ∈ D_ε)   ∎
```

方向注记:V(π*) ≥ V(π_greedy) 恒立(π* 定义),故绝对值无需单独处理。

## 推论(P52-C:升档器 = 安全带,「只升不降」的亏损截断)

**设置**:σ = 危险信号 wrapper(philosophy §3):在 π_greedy 输出之上,当危险信号触发(分层 λ CI 下界显著 > 0 等)时叠加强制转化(按预注册规则把存量金转为板面战力/当轮兑现);**触发集只升不降**(滞后单调,不因信号消退而回退)。

**命题**:
1. **D_ε 上 σ 不动**(激活率门:正确决策下触发率个位数百分比内,philosophy §3 验收条件②——骨架+EV 臂 sim 实测挂账)⇒ V(π_greedy∘σ) = V(π_greedy),主定理结论原样保留;
2. **D_ε^c 上 V(π_greedy∘σ) ≥ V(π_greedy) − c_σ**,其中

   ```
   c_σ = 息差上界 L(cap=5 金/轮 × 提前轮数,窗口口径 ≤ 15)
       + 转化错配上界(预注册转化规则 vs 最优转化的 EV 差,保守带 12 金,P39 边界带量级)
     ≤ 27 金(默认局窗口口径,脚本对账 4)
   ```

证:σ 的动作集相对 π_greedy **只增「提前转化」类动作**。死亡侧:转化单调降低后续存量金路径 g ⇒ 敞口 E 逐点下降 ⇒ 截断损失 D(π∘σ) ≤ D(π)(W_floor = λ·(g+Φ) 对 g 线性,P51 §2 结构;消费使死亡时携带更少)。收益侧:提前的代价 = 放弃的息票(≤ cap=5/轮,p47)+ 次优转化差(有界带)。两侧相加即 c_σ,方向单侧:**λ 表错 → 至多早花(少赚 ≤ c_σ),永不更危险**(philosophy §3 安全带性质的证明形态)。∎

**亏损截断读法**:D_ε^c 上 π_greedy 的 regret 死亡通道项 = λ·E·H_eff 可无界增长(濒死带分层 λ 0.119-0.341、敞口中位 121-148、H_eff 增大——P51 §4-B);σ 把该项替换为 **c_σ + λ̄·E_σ**,E_σ = 转化后残余敞口(强制消费已压低 g)。数值对照(脚本对账 4):濒死带单窗敞口 59.3 [48.5, 71.7] 金 vs c_σ = 27 金——无界敞口被有界常数截断,截断比 ≈ 2.2:1,且窗口越多差距越大(截断侧不随 H_eff 增长)。

## 边界

1. **域命题性(最重要的边界)**:无条件形态不可证(philosophy §3 吸收态论证;P51 §1 同判)——D_ε 条件失败时 ε 表达式各项仍成立但数值无界;本定理不授权「任何时刻都发展优先」。
2. **引理 2 是条件引理**:判据证明族的固有边界(P39 A2 偏置/边界带翻转/弃搜折减)全部继承,挂各自 sim 对拍;本件不缩小也不放大这些边界。
3. **λ 消费口径**:λ̄ 用分层表 + 桶构成(决策时可观测),禁用事后 R(P51 B3/边界 10 照搬);λ 直测发生率非生成式立证的偏离声明同样继承。
4. **union bound 松**:全局累计口径可 vacuous(对账 3 披露行);定理的实证内容=危险窗稀少(桶构成证据),非不等式本身。
5. **辖域**:承 P51(sim、位面 1-2、两策略臂;实机与位面 3 外推必采);W_ext(对手截胡/商店期权)为下界外未定量,方向=实机 ε 高于本表。
6. **敞口口径**:E 为金流当量;战力/hp 不入账(公理栈,philosophy §2 硬闸门)——「战力和 hp 不是问题」的证明形态正是**把它们排除在价值函数外、只在死亡概率侧进入**(λ 的自变量),与 [39] 决策面纪律一致。
7. **与 P48 三段管辖的层次关系**:本定理 = λ≈0 段的**策略级**(整体 π 的值保证)结论,P48 = 该段的**判据级**(逐决策判据)结论——层次不同、不双计;λ>0 段两者都让渡(P48 让渡给 P51 转化优先,本定理域条件失败、让渡给推论的安全带)。
