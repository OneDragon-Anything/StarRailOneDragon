# 末日幻影-编队(treasures_light_as_team)

末日幻影**挑战编队画面**(首领信息页点「前往编队」进入):左栏难度徽章+通关目标
(击败 2 个首领)+星级目标分数;右栏两行(节点一/节点二)各 4 编队槽 + 终焉公理装配。

## 何时出现 + 状态流转

| 态 | 入口 | 出口 |
|---|---|---|
| 常规态(左栏=难度与目标) | 末日幻影-首领信息 点「前往编队」 | 点「前往挑战」→ 节点画面(未建档) |
| 角色列表态 | 点任一行槽位 | 右上返回箭头收起 |

## 识别特征(稳定锚点)

- **标题-末日幻影行 + 标题-编队行**(左上两行,双 id_mark)。

## 可交互元素(2026-11-05 实机交互验证)

| 元素 | 行为 |
|---|---|
| 行槽位 | 点 = 展开角色列表 + 选中该行;点角色卡 = 落入当前行下一空槽(同虚构叙事编队) |
| **已入队角色(列表中点)** | **= 移除**(同虚构叙事) |
| 行右端「+」(空行) | 选中该行并展开角色列表 |
| 行右端圆形按钮(编入角色后出现,`按钮-公理圆圈1/2`) | 打开**终焉公理增益装配弹窗**(三选一 → 装配效果;独立建档见 [末日幻影-终焉公理](末日幻影-终焉公理.md)) |
| 行 boss 卡内「坚防守备/阵地转移」等按钮 | **敌方特性条款查看入口**:点击仅弹说明浮层,不改变任何装配(勿当 buff 选项) |
| 按钮-前往挑战(右下) | → 首领简报横幅(点击空白关闭或自动消失)→ 节点画面开战;编队不满/含不可用角色时点击无反应;修改已挑战编队会先弹「更换编队确认」 |
| 垃圾桶(角色编队标题右侧) | 清空**当前选中行**(⚠️ 非全清,推断与虚构叙事编队同语义) |

## automation 要读信息

- 星级目标分数(左栏,难度相关)——挑战略输入,未建 area。
- 两节点弱点属性(「建议属性」图标带)与当前编队成员:由 `TlAsTeamRecognizer`
  extras(`waves[].weaknesses`/`members`)输出;弱点主路径 = boss 名查静态表。
- 列表展开态(`列表-角色列表页签` 命中)、难度徽章(难度03/04)。

## 识别快照

- 实拍归档(测试仓 `screens/末日幻影-编队/`):默认(行空)/ 编队屏-有队伍 /
  终焉公理弹窗(2026-11-05;该帧实属终焉公理屏,见其 doc)。
- 编队帧:末日幻影-编队 is_precise(双锚,2026-11-05 实测)。
