- **Decision**(两轮打击,每轮一个域,双窗 30+30 验证):
  1. **strike1(域c 成型进度评分,采纳)**:score_state 新增
     `eng_frac` 项 = 过渡体系进度小数余量(Σ min(加权计数/tier,1) −
     整数引擎数;混合域权重与 board_rung_x 同源)× `engine_frac_unit`。
     与 rung 整数档互补不双计(阈值跨越瞬间余量清零、值转进
     rung_value);希儿系为 deployed 二元判定无小数进度,不参与。
     依据=P3 已证档位边际(e0→e1 +1.4/e1→e2 +1.6 金/轮)——买进度件
     是正期望期权,但原评分只在整数档跨越时显影。双窗网格
     (unit∈{0,1,2,4}×cap∈{0.8,1.0})标定 **unit=1.0 唯一双窗一致**
     (A 窗 hp_ge_60 0→0.167/B 窗 0.2→0.233);unit≥2 在 B 窗翻车
     (进度件挤掉目标件买入);cap_frac 1.0 无单独增益维持 0.8。
  2. **strike2(域b 成型找件刷新,否决)**:未成型(引擎数<2)且店无
     引擎件时刷新按 form_refresh_ev=3.5 计独立通道(轮界 7/金门 30,
     常规 refresh_max_round=6 不辖 r7 找件窗)。双窗 30+30 配对
     **-4.13/-4.70,hp_ge_60 双降**——找件命中率低于常量 EV 假设,
     高分刷新挤掉同轮买入且刷新仅 +0.3 次/局。通道保留注册
     (form_refresh_ev=0 默认关闭,同 refresh_game_cap 模式)。
- **Considered Options**:
  1. **早期经济参数(息引擎门/追级节奏)**:数据排除——诊断金不够
     0 轮、bench 满 0 轮,「评分没买/店里没有」两块都不在经济域。
  2. **抬 target_hold_cap_frac 0.8→1.0**:网格无单独增益(与 unit
     正交),维持 0.8;ADR-0295 的天花板折减语义保留。
  3. **engine_frac_unit 取 2/4(激进)**:否决——B 窗 hp_ge_60 回落
     (0.233→0.133/0.1),高单位下进度件买入挤掉目标件。
  4. **找件刷新扩展(r7 强制刷/更高 EV)**:strike2 数据否定方向
     本身,非参数问题(命中率不足是供给面约束)。
