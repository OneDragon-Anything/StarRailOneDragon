# 黄泉负面队（负面充能体系）

> 按 V4.7 期（2026-11）调研撰写。靠「全队高频挂负面 → 黄泉残梦快速充能 → 插入式终结技爆发」赢。

## 核心思路

- 黄泉终结技消耗 **9点【残梦】**，不走能量【官：终结技标注「消耗残梦9」】；残梦主要靠「我方任意单位施放技能使敌方陷入负面效果」+1（每次施法上限1次）【官：天赋】→ **充能速度 = 全队挂负面频率**。
- 终结技不占行动回合（敌我行动间隙插放），期间无视弱点属性削韧 + 敌方全属性抗性-10%【官：天赋】→ 对无雷弱点敌人不亏，但弱点错配仍影响削韧节奏。
- 伤害放大器【集真赤】：负面触发时叠层，终结技逐段消除层数提高倍率；敌人死亡后层数转移不断档【官】。

## 骨架与绑定规则

```
黄泉(雷·虚无·主C) + 虚无位×N + [同谐位(仅E2+)] + 生存位(优先能挂负面的)
```

- 行迹「奈落」：虚无队友 1名/2名 → 黄泉普攻/战技/终结技伤害成为原伤害的 **115%/160%**【官】（独立乘区【攻：Prydwen，官方无公式文本】）。
- 星魂2「所需虚无人数减1」→ **E2 起单虚无即满乘区**，空位插同谐【官】。
- 队友筛选标准：**每次施放技能都能让敌方陷入新的负面**（技能本体、光锥施加的负面同样触发——专锥【泡影】、「决心」【攻陷】、存护位带「宇宙市场趋势」受击挂灼烧都算充能）。

## 成员要点

- [椒丘](../characters/椒丘.md)：第一虚无——烬煨易伤（每动必挂）+ 终结技结界（敌方受终结技伤害+15%），与黄泉终结技轴咬合。
- [佩拉](../characters/佩拉.md)：第二虚无——通解群体减防30% + 高频挂负面 + 驱散。
- [银狼](../characters/银狼.md)：植入弱点 + 减防（3.4加强后终结技群体减防，单减防功能佩拉可覆盖时为下位平替）。
- [花火](../characters/花火.md)：同谐位——战技暴伤转化 + 拉条50% + 产点，直接补黄泉短板。
- [砂金](../characters/砂金.md)：存护——宇宙市场趋势受击挂灼烧=被动充能位。
- [灵砂](../characters/灵砂.md) / [加拉赫](../characters/加拉赫.md)：丰饶替补——灵砂终结技【醇醉】、加拉赫【酩酊】+强化普攻减攻都是负面源。

## 操作轴

1. **开局秘技**：黄泉秘技起手（普通敌人直接秒、未命中不耗点【官】）；椒丘秘技进战全体挂烬煨；佩拉秘技群体减防。
2. **循环**：黄泉 E-A-E-A 交替（战技+1残梦）；椒丘 EA 为主（烬煨靠击中触发）；砂金开局战技后 E-A-A；花火战技给黄泉、终结技回4点（全队技能点经济来源）。
3. **终结技时机**：黄泉残梦满9即放，但**先确认椒丘结界已开**（结界期间终结技伤害+15%）；3段逐段选【集真赤】最多目标（≥3层消满）。
4. **技能点预算**：花火终结技+4是收入；黄泉/椒丘/砂金战技各耗1——压力期椒丘/砂金转普攻。

- 利好：负面触发型湍流、多波次收割环境（集真赤转移）。
