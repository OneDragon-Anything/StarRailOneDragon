# ADR-0189: 市场清算所 v0 落地(redesign 43 号处置:tâtonnement 撮合+套利预算)

## Status

Accepted(2026-08-17,策略优化会话;真实交易者接线[03/06/38/07/21/08/18 报价适配]为消费批次)

## Context

43 号主张:15 影子模块一遍瀑布级联(上游输出当下游常数),权威自 DP 的错价只能事后审计
(35 号),不能被结构性否决;组合次优无度量。前置(35 提取器)已落地(ADR-0188)。

## Decision Drivers

- J0 零漂移锚(现状级联=π₀ 单轮)与 J3 韧性注入(坏 π₀ 被市场纠正)是生死判据
- Hayek 论证:DP 抽象带装不下局部态(手牌面/刷次史),价格=只传稀缺性的充分统计量

## Considered Options

1. **Trader 注入式撮合先行(选)**:接口(net_demand(π))+ clear(tâtonnement 阻尼+投影+
   振荡检测);生产交易者接线为消费批次,引擎先立并用 mock 验证数学;
2. 直接接 7 个真实模块——接口未验先接全家,回归面大;
3. 维持级联——错价传染与组合次优继续无度量。

## Decision

选 1:`cw_market_clearing.py` v0——

- ``Trader`` Protocol + ``clear``:π←π+η·z(阻尼 0.3 + floor 投影;23 号区间箱投影挂消费批);
  停机:|z_total|<ε / B 耗尽 / 振荡(净需求符号连续翻转 ≥3)→ 取残差最优点;
- ``arbitrage_budget``:**未成交残差 |Σzᵢ|**(修正:个体需求在均衡处非零——撮合成交语义,
  供需相抵;残差才是级联损失代理)——市场存在性判据(J1 自我证伪条款);
- **测试全过**:J0 零漂移(max_iter=0 → π₀ 原值);标准供需均衡收敛(p=2);
  **J3 韧性:坏 π₀(偏离 3×)被拉回均衡带**(权威自一致性而非自 DP 的机器验证);
  套利预算均衡小/偏高大;价格下界投影。

## Consequences

- 清算数学就位;真实交易者接线(每模块报价适配 ~S)与 22 号「可解门族」迁入为消费批次;
- 振荡报告 → 13 号「清算震荡」合约族候选;
- 43 号处置完成(v0),提案文件删档;测试 +5。
