# 货币战争 · 零和博弈(currency_war)

3.7 版上线的**大型常驻玩法**(赛季制,与模拟宇宙交替更新),**类自走棋(auto-battler)+ 肉鸽**。
战斗**自动进行**(非手动操作),玩家专注经济/羁绊策略。⚠️ **每节点战斗有「有限行动值(AV)」限时**(米游社百科 content/6564,存 data/gameplay.md:13;用户 2026-08-11 确认,旧记"非限时"误):未在限内消灭全部敌人 → **扣小队生命值**(非判负)→ **输出不足体现为扣血**(扣血越多越可能输出低/超时,与"扛不住"同表现为 hp 降)。→ 输出能力重要(限时内击杀),hp_trend 已隐含输出信号。🔴 扣血公式 + 结算画面是否显示超时/总伤害字段,待实机核。奖励约 4000 星琼 + 深度沉浸器 + 助燃券,
**周期(双周)积分每双周周一 04:00 重置**。解锁:开拓等级 21+。入口:手机菜单 → 指南(星际和平指南)→ 旷宇纷争 TAB → 货币战争。

## 玩法机制(攻略 + 实机)

- **对局类型**:标准博弈 / 超频博弈;通关奖励 = 周期积分(18000 上限)+ 晋升点(如 2700+1500)。周额外晋升点上限 1500。
- **职级/难度(两阶模型,2026-08-06 核实,详 [strategy/13 §13.7](../currency_war/strategy/13_input_model.md))**:
  - **职级 `selected_difficulty`**:段位 黑铁→青铜→翠钢→钴银→冰肽→紫金→投资大师→资本帝王→**财富造物主(A8,最高)**。V4.0 扩到 **A8-1 ~ A8-50**(子档,如 A8-50)。**决定起始敌人难度** + 是否带额外敌人词缀。选难度在「开对局确认」屏。
  - **敌人难度 `enemy_difficulty`(数值)**:**随节点推进递增**(节点类型不同曲线不同:遭遇/奖励/首领;V3.8 调过 —— 削遭遇敌人攻速攻击、提奖励节点奖励)。**可被投资策略压低**(「难度修改器」银 −4、部分金 −3,**最低降到 0**)。boss 血量 ≈ `base × 1.052^enemy_difficulty`(每 +8 难度 ≈ +50% 血;A8-60+ 血量几十~上百亿)。
  - **难度↑ 的后果**:敌人属性(攻/速/血)↑ + 额外敌人词缀。「第一位面最难」(A8 一层遭遇常比 boss 凶)。
  - 来源:[官方玩法说明](https://sr.mihoyo.com/news/160700)、[V4.0 扩充(A8-30→50)](http://news.17173.com/content/02112026/124720972.shtml)、[V3.8 调整](https://sr.mihoyo.com/news/161414)、[bwiki 投资策略(难度修改器)](https://wiki.biligame.com/sr/投资策略一览)。
- **位面**:每局 3 个位面,每位面多节点 + 首领;第一位面带强化词(如「战个痛快」)。
- **备战阶段(核心循环)**:进度 X-Y(位面-节点);**商店**发 5 张角色牌(各带阵营羁绊 + 技能标签 + 价格)→ 花金币买牌 / **刷新**刷牌 / **购买经验**升队 → 配**前台(作战)/后台(支援)**站位 → **出战** → 自动战斗 → 下一节点。
- **备战棋盘槽位(2026-08-09 实测 + 攻略核实)**:**前台(作战)+ 后台(支援)**两排槽位。**上阵数量上限 = 晋升等级**(level 6→6 人、7→7…;队伍总 8-10 人,来源 [游侠](https://m.ali213.net/news/gl2511/1709345.html)/[bwiki](https://wiki.biligame.com/sr/%E8%B4%A7%E5%B8%81%E6%88%98%E4%BA%89))。**槽位布局随投资环境变**:实测某投资环境把后台 6→7 槽(用户确认),还可能 8/9/10(上限待游戏内图鉴核实)。→ screen_info 固定槽位坐标(`前排-1..4 / 后排-1..6`)不可硬信,需按布局动态推导(见「变槽位角色识别方案」)。
- **阵营羁绊(实测)**:命运圣杯 / 仙舟 / 夜之半神 / 公司 / 银河学者 等;技能标签:战技点 / 能量 / 燃血 / 群攻 / 持续伤害。
- **装备系统(2026-08-10 建档,详 [data/equipment.md](../currency_war/data/equipment.md) + [screens/currency_war_prep.md](../screens/currency_war_prep.md))**:分「简易」(7,基础属性**无特殊效果**→effect 空)/「进阶」(37,**2 件简易合成**,含特殊效果)/「特权」(·特权,数值强化)/「星徽」(加阵营/流派羁绊)/「白昼/命运/骇客」/「工具」(拆装扳手/冶金炉/随便骰子等**消耗品**,非穿戴)。每角色 **4 装备槽**;已穿戴可【拆装扳手】拆。
  - **合成(核心机制)**:**2 件简易(配方配对)→ 1 件进阶**(用户确认:轮滑鞋+生命之花→步步生花)。合成**可被穿戴触发** —— 给已有配方件的角色装第 2 件 → 自动合成(equip_all 给飞霄(滑轮鞋)装生命之花 → 合成步步生花,D-41 实测)。→ equip_all 装备后会改变角色装备态(合成),验穿须读实际装备(avatar-slot ground truth,下方小图标/详情装备槽)。
  - **owned 装备位置**:备战右列**多列规则网格**(从右往左填充,列满溢左;D-40 col1 x1800-1918 + col2 x1660-1800),**无空槽**(「+」=星徽 icon 非 empty,D-38)。识别用 `cw_equip` SIFT(thr7,4/4 click 验名准,D-39)。
  - **合成配方表**:⚠️ **待游戏内图鉴(数据银行→装备图鉴)全量采集**(web bwiki 部分且矛盾:以太钻 类别不一致;只用户确认步步生花 1 条可靠)。采集后入 equipment.md → Equipment class(`recipe` 字段)→ gen_equip_registry 重生成。
- **经济**:战斗结束给基础金币 + 按持有金币给**利息** + **连胜**额外奖励(类自走棋经济)。
- **选择事件**:投资环境(3 选 1,带星徽/羁绊效果)、星徽、羁绊等(类模拟宇宙祝福选择)。
- **巨星(盛会之星羁绊)**:盛会之星是阵营羁绊(成员花火/星期日/知更鸟/黑天鹅/大丽花/加拉赫 + 盛会之星星徽)。「巨星」= 选 1 名盛会之星角色当巨星,**给全队独特 buff**(各巨星不同,随羁绊等级 2/3/4/5/6 递增:花火=进战战技点+普攻/战技增伤、星期日=前台首位前台强度+后台首位后台强度、知更鸟=幸运一击、黑天鹅=5费增伤、大丽花/加拉赫=击破伤害增幅+治疗强度)。
  - **触发条件【假设·待正向验证 TODO,2026-08-07】**:推断 = 玩家持有盛会之星角色时,进入备战回合弹出巨星选择 overlay —— **不是固定节点**。依据:3 观察样本相关(局A 持有盛会之星→开局备战弹 / 局B 全程无盛会之星→全程不弹 / 旧图持有→1-6 弹)+ 攻略未提固定节点;**但未做正向实验**(主动买盛会之星→看出战下关弹)。验证前不当事实用;TODO 在正向验证后删。候选 = 持有的盛会之星角色(每局不同)。
  - overlay 叠在备战屏上(非独立关卡):`请选择1名角色成为巨星` + 候选立绘(左右)+ 可选`请选择强化角色` + `确认选择`。强化角色可选(不选也能确认推进)。
  - 证据:① 开局 `iter=1`(非首领)弹巨星,候选盛会之星 → 持有即弹;② 全程无盛会之星角色的局,9 关全程无巨星;③ 1-6 持有盛会之星 → 1-6 弹。攻略/wiki 均未提「固定节点」→ 支持动态触发。
  - bot dispatch:loop 检测「确认选择」OCR 反应式接(不管何时弹都接得住)。来源:[米游社 wiki 盛会之星 content/6239](https://bbs.mihoyo.com/sr/wiki/content/6239/detail)。
- **失败**:挑战失败扣**小队生命值**(初始 ~80),生命耗尽则结束。
- **run 免费**:不耗开拓力;周期积分满后仍可游玩(只不再得分)。
- **赛季扩充(V4.4)**:新角色千冶·刃 / 姬子·启行 / 远坂凛 / 吉尔伽美什 + 命运圣杯羁绊;晋升上限 170;最高难度 A8财富造物主50。

## bot 流程(`application/currency_war`)

**完整 app(2026-08-03 实机验证,纯代码、无 LLM)**:`run_standalone_app('currency_war')` 自主打完整局。
`CurrencyWarApp` → `_enter_lobby`(`EnterCurrencyWar`)→ `_start_match`(`StartCurrencyWarMatch`)→ `_run_loop`(`CurrencyWarRunLoop`)。

- `EnterCurrencyWar`:打开指南 → 旷宇纷争 → 前往参与 → 大厅(测大厅独有「创业指南」)。
- `StartCurrencyWarMatch`:大厅 → 开始「货币战争」→ 标准博弈 → 开始对局 → 简报(下一步)→ 投资环境(选牌+确认)→ 备战。
- `CurrencyWarRunLoop`(对局内主循环状态机,MAX_ITER=200):
  - **备战阶段**(`BattlePrepCycle`):`BuyShopCards`(bench 满→购买经验升等级 ×8;否则买 5 张)→ `DeployBench`(拖备战栏→舞台前排优先)→ 点「出战」。
  - **战斗/过场**:检测「总伤害」→ 点空白加速(OCR 常漏"点击空白加速")。
  - **挑战成功/结束**→ 继续挑战(过渡屏 active_window 紧贴 click,见备注 bug)→ 结算导航(前往结算/下一页/返回货币战争)→ lobby 收尾(「创业指南」→ 完成)。
  - **选择类事件**(3 选 1 + 确认):投资环境/补给阶段(点卡身选中)、投资策略(点**卡底** y≈815 选中;卡身开详情,详情弹窗「可合成列表」→ ESC)、遭遇节点(2 选 1 难度 + 选择)。

**角色识别**(`currency_war_char_id`):SIFT 特征匹配 `assets/template/character_avatar/` 库(~90 角色);对脸部独特角色可靠(herta)、对配饰/半身角色不可靠(头像脸近景 ≠ 备战半身立绘)。**商店角色 OCR 名字直出**;**购买/deploy 跟踪**是 bot 知角色主路径,char_id 仅兜底。

**实测结果**:naive + 购买经验升等级策略 → **赢下位面 1**(1-1…1-9 首领)→ 位面 2(2-1…2-7 首领输)。完整打完两位面局,晋升等级 141→144。**打赢位面 2 首领需 Strategy 精修**(羁绊/经济/deploy 智能化,见 `.debug/temp/currency_war/design.md`)。
