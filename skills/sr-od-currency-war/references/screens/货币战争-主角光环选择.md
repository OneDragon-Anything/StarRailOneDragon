# 货币战争-主角光环选择（一、二位面首领战前）

**识别**：`is_precise` 命中 `货币战争-主角光环选择`（标题锚「选择一个角色获得主角光环」）。
**目标**：选光环 + 指定主角。
**触发时机**（两局实测闭环，详见 [references/mechanics/主角光环.md](../mechanics/主角光环.md)）：默认在一、二位面首领战（节点 1-9/2-7）前的备战期出现（备战识别失配 → 本屏精准命中、出战钮变「选择主角」），位面 3 无此环节；1-9 与 2-7 均实测出现——早前「1-9 未出现」的样本 = 玩法任务「入画奇航」教学引入前的旧档（教学引入时序假设验证成立）。**2-7 强制环节实拍（2026-11-19）**：点「出战」不出战、强制弹本画面（选择完成前无法开战）；从本画面点「返回备战界面」回备战后，备战右上带「返回主角选择」按钮（可再进本画面）——该态是主角环节的备战锁定变体（暗色锁定族第四变体「备战-主角锁定」形态：锚「返回主角选择」，出战受抑，画面档未建、按文本识别），完成选择后按钮消失、出战恢复。
**能做的事**：
1. 从当前帧读出目标角色预览卡位置（预览卡按前排/后排两行排布（实测），位置随部署数变化，无固定槽位）。
2. `CwSelectProtagonist {"aura_side":"left|right","source_x":N,"source_y":N}`——内部三步：点光环卡选中 → 拖角色入中央主角槽 → 确认微距拖拽兜底（静态确认可先试）。**缺陷申报：拖角色入中央主角槽步骤在本机失败×2（帧号已备档申报）——op 修复归开发者侧，当前手动 drag 更可靠**。
3. **手动操作语义（实测，四局闭环）**：**选主角的实际手势 = 拖角色卡入中央主角槽（中央发光框）再点确认**（画面档已建「中央主角槽」area；拖入后中央卡亮主角标记（黄色星标）+ 提示条消失 + 确认键亮起，点确认完成——1-9 首选 / 2-7 免费重选两次实操均此序成功，**重选场景交互与首选相同**）；**点角色卡 = 只开详情面板，不是选中**；**光环卡单击选中有效**（两局复现：虚弱猎手光环 × 藿藿，效果：敌人伤害 -28% / 受伤 +28%）。拖主角预览卡的抓取点经验（实测）：抓预览卡**中心** 3 试 2 败，抓**卡右半部**（实测例 (1010,640)）成功——抓点优先卡右半部，失败别在同一位置连试；拖拽偶发首次被吞、二次重试成功（既有缺陷数据点）。**预览卡两行布局与抓点修正（2026-11-19 重选场景实测）**：预览卡按前排/后排两行排布，前排行中心 y≈640、**后排行中心 y≈745（按 790 估点会落空）**；拖错角色可**重拖覆盖纠正**（再拖另一角色入中央槽即替换原选择，不必回退重来）。
4. 光环池随机（普攻精英/战技精英/枪炮收藏家/邀请函 等），内容读图决策；1 金可刷新（左右卡各有刷新按钮）。实测候选池新增（2026-11-19）：**富翁的梦泡**（刷新/输出系经济光环，效果全文「利息上限提升至8金币。每赚1利息，有15%概率获得1次免费刷新。每有1金币，该角色的前/后台强度提高1%。当前提高：0%」，代价敌人难度 +3；帧 `screenshot_20261119_205441_649975.png`）与**信心激励**（辅助系，「该角色对我方目标施放技能后，使其前台强度提高70%，获得20%伤害减免，持续2回合」）。**双光环并存实证（2026-11-19）**：富翁的梦泡（1-9 选定）+ 信心激励（2-7 免费重选再选）**并存生效**——终局对局详情页「主角光环」栏双图标在场（帧 `screenshot_20261119_214909_563582.png`），该样本口径 = **重选追加**。**重选语义矛盾样本（2026-11-20 第二局）**：替罪羊（1-9 选定）在 2-1 经重选界面重选新光环后**替罪羊即丢失**（对局单光环，= 替换口径）——两棒样本冲突（追加 vs 替换），**重选语义待样本积累裁定，暂不下结论**（候选方向：替罪羊自带的重选与普通免费重选语义不同 / 部分光环可叠加），详见 mechanics/主角光环.md §2；重选前先记录已选光环、重选后核对光环栏。**富翁的梦泡利息口径（2026-11-19 持有局实测；2026-11-20 第九局三效果全实证）**：持有下利息仍按 floor(持金/10) 照常结算——1-9 收入帧「利息 3」@战前持金 34（帧 `screenshot_20261119_210114_476741.png`，基础 5+利息 3+连胜 1）；**cap 8 顶格直读已取得（⑲k 闭环）**：2-1 持金 89 金「利息 8」直读（floor 8.9=8 顶格，帧 213221；同局 51 金帧「利息 5」= cap5 常规顶格，同局双 cap 跨档互证）；**免刷触发两次**（利息 8/5 掷骰均中，刷新钮「免费刷新」文本）；**战力增幅每金 +1% 首验**（持金 76 金=+76% 战力，BOSS −34 vs 常态 −36+；+3 难度负面被增幅覆盖）——三效果结论与存钱流闭环见 decision-guide §7。**囤金勇者第二样本（2026-11-19 第三局）**：效果「每拥有 1 金币，该角色的前/后台强度提高2%（最多计入60金币）+20%伤害增幅」第二例实读确认，**卡面无负面词条**（对照同池经济光环：富翁的梦泡带敌人难度 +3——囤金勇者是已见经济光环中唯一无代价的；决策口径见 decision-guide §7 存钱流双件套）。
**坑**：点角色卡只会开详情、其余静态点击（槽位/适配头像）不产生选择——选中要靠「点光环卡 + 拖角色入中央槽」两个动作（op 拖拽步骤缺陷申报中，手动 drag 预览卡→中央槽可靠）；确认键置灰 = 三样缺一；「返回备战界面」= 放弃本次选择；非适配角色也可放置。
