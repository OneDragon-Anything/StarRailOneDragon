# ADR-0570: 达标臂 armed 成型质量合取(B_t 通道承重结构维)——配方完备之上的板面承重闸

## Status

accepted(落码批随本 ADR 实施;策略审查打回路由后的落码形态,原候选作废见 Considered Options)

## Context

现行达标臂 armed 判据 = 配方完备单键(`readiness_form_ok` = `cw_comps.form_progress(comp, state) >= 1.0`,ADR-0557 上收 kernel 单一源),只辖配方档齐缺,不辖板面质量:配方成型与板面承重之间缺一道判据(病灶证据:g_20260906_182456 §B2/B4——P1 r8 form_ok=true 后 boss 一战 -32 血;P62 已证 form_score 饱和零信息,math_proofs.md:72;质量面至今只有观测键无判据位)。设计稿《设计-C3成型质量维度.md》v3 经两轮无前提对抗 + 定点复核(spotcheck_v3_C1_C3.md)解锁落码。

**策略审查打回路由(本 ADR 立命题的直接动因)**:原候选「按 2★ 数/装备覆盖重校成型判据」作废——板面强度评分进决策门违 00_framework §1 禁战力建模,且 P62 已证 form_score 饱和零信息、ADR-0535 方案②已证 2★ 数对三个结局量无一致方向。落码 route 改为 **B_t/P42 通道成型质量命题**:armed 合取的「质量维」判据只消费 B_t/P42 通道派生量,禁 2★ 计数/装备覆盖直入;P63(B_t-depth r=0.403 已证,math_proofs.md:73)**禁作判据资格,只作方向**。

按 ADR-0535 升格闸门,B_t 从纯遥测拔高进判据须过 ADR-0482 两层权威序全门(证明/实证先行)——本 ADR 即该闸门的一次行使。

## Decision

### 1. 命题(B_t/P42 通道成型质量维)

**armed ⇔ 配方完备 ∧〔承重满额 ∨ 部署计划不可得〕**,落码位 = kernel `cw_launch_admission.readiness_launch_decision`(消费面 cw_loop/engine_p1 零改,判据单一源随核自动跟随):

- **配方完备** = `readiness_form_ok`(form_progress≥1.0,语义保持,零改);
- **承重满额(load_bearing_full)** = 板面目标线承重计数 ≥ 槽位占用数。承重计数 = deployed 非空件中,**名字 ∈ comp 自家核准集(core_chars∪shared_chars——注册表成员名单是结构量;落地审 F1 修复:白厄类空羁绊单卡(独立羁绊绑死单卡,注册表 factions∪flows 空集)/不死途类视图外 shared 件经此计入,否则 comp 自家核心被误判线外,该线承重支路恒不可达)**或全羁绊(CHARACTERS 注册表 factions∪flows)∩ `comp.all_factions`(核心∪弹性羁绊,ADR-0152「弹性羁绊铺板不算 off-target」板面判定同视图)非空的件数;占用数 = `cw_state.deployed_occupied`(ADR-0392 单一源)。承重计数 ≤ 占用数恒成立(计数域 ⊆ 占用域),下限取该平凡上界 ⇒ 判据 ⟺ 板面零线外件(线外 = 非核准 ∧ 视图外)。**零自由参数**:两端均注册表/机制定义量,无数值标定、无拍定值。四体系线 comp 的该口径与披露 B_t(`board_target_line_weight`,ADR-0535)同族——披露口径本体仍是纯遥测零改,质量报告附 `b_t_disclosure` 供判读对账。
- **部署计划不可得(fail-open 出口)** = kernel `has_deployable` 判空(dd-037 单一源,禁第二套围栏语义)。线外件在场但部署计划不可得 ⇒ 质量目标不可达帧,**降格为配方完备发射**——C3 设计 §2.1/§6「算不出/不可达 → fail-open 降格防死锁」教义在 B_t 轴的移植。输入装配取 mandate 发射门同源缺省:cap = `state.max_units()`(缺读退 10**6,与发射门 None 兜底同口径)、target = `comp.factions`;framework carry/locked factions 在判据核不可得 → 严格子集,**只可能偏「计划不可得」= fail-open 方向**(闸偏开),结构性排除「关闸后无动作 → 环级无进展守卫停摆」的死型。
- **推迟帧语义**(C3 设计 §3.2 的闸侧实现):质量推迟帧(`defer_by_quality` = 线外件在场 ∧ 计划可得)必有部署动作在途——计划存在 ⇒ 下一备战环 RunDeploy 推进换血/填板,承重单调收敛(P61 族:换血 B_t 严格增、触发有限),armed 翻真;换血执行失败走既有 round_fail/守卫链(零新机制);金尽稳态由 ADR-0554 收益耗尽臂兜底(其判据与 armed 零耦合,既有锁族 `test_cw_no_progress_guard.py` 保绿)。推迟上界 = armed 翻真 ∨ 计划耗尽 ∨ 金尽,无无限推迟。
- **fail-closed/fail-open 分界**:逐件承重判定注册表查无/身份未识别 → 按线外计(承重不认,fail-closed);质量维整体评估异常 → armed 维持配方腿结果(fail-open,防死锁优先),报告 `quality=None` 显影异常帧。

### 2. 判据资格声明(ADR-0482 两层权威序)

- **阈值的合法性来源 = 机制定义量结构式**(strategy-work §1 数字来源第 1 类:规则或推导),非经验标定:「全员承重 = 成型质量达标」的结构语义出处 = 承重计数语义本身(P61 支配基座「上场了才算承重」、bench 囤件不计入)+ 过渡配方纪律(user_playstyle [20]「过渡是配方不是散买」,线外件占槽 = 承重缺口)+ 机制面既有先例(`offtarget_sell_allowed` fenced 臂:线成型后 off-line 板件已按让位可卖处置——W209/ADR-0386 系在案)。
- **P63 的角色 = 方向锚,非判据资格**:P63 证「承重轴有信息」(B_t 对 boss 存活深度 r=0.403,p<0.001,唯一显著代理),据此选「结构承重轴」而非「强度评分轴」;P63 的统计数值(r=0.403 等)**不进任何判据式**,其自身「禁作判据资格」的辖域声明(P63 单篇用途定位节)与本闸门不冲突——升格的是轴,不是数。
- **P62 的角色 = 反向锚**:强度类评分(form_score/2★ 计数/装备覆盖)饱和零信息或无定量锚,禁入决策门(00 §1);原候选据此作废。
- **P61 的角色 = 收敛路径在册**:转型臂换血 B_t 严格增(弱支配,零自由参数)⇒ 质量闸关闭帧的解除路径有行为面保证,闸不造死锁。

### 3. 待标定项(显式挂账,不阻塞判据本体)

| 挂账项 | 载体 | 过期/裁决判据 |
|---|---|---|
| 质量闸推迟行为观测(armed 翻真率/推迟帧数/收益耗尽臂触发率) | sim A/B + 实机对拍;观测位 = `quality` 报告(`defer_by_quality`/`line_weight`/`b_t_disclosure`)+ 分键 `launch_quality_defer_frames`(推迟帧计数;写点 = engine_p1 发射判定位与 cw_loop 达标臂判定位,best-effort 双面 sink,落地审 F6 补)+ 既有 `exhaustion_*` 分键;A/B 报告必带 sim 可观测性声明(strategy-work §4) | 判读面,无裁决权(数值合法性已由结构式承载);若实证显示系统性过度推迟(推迟帧占比异常高且翻真率趋零),重标须回本 ADR 重开,禁码内悄悄调参 |

### 4. 消费面与零改动申报

(「零改动」均指**本批**触碰面;工作树中 shop.py/entry.py/engine_p1.py 等存在并行批在飞改动,不属本批申报范围。)

- **停手链零改动**(C3 设计 §3.1 申报的对照面):`proof.stop_buy` 成员齐备谓词(proof.py:116-130)及消费位(shop.py 商店线 stop_flag、entry.py 证明 pass 侧)本批零改——停手纪律维持现行语义,质量不达标 ≠ 恢复买过渡件;既有 stop_buy 链锁保绿即对照证明。
- **镜像写端零改**(C3 设计 §3 表第 2 行):`v3_form_ok` 镜像与 `v3_b_t` 披露写端语义不变;armed=True ⟹ 配方完备仍成立(合取的单向蕴含),engine 发射帧镜像补写语义保持正确。
- **发射帧仲裁(ADR-0566)零改**:仲裁段挂 `if _arm_armed:` 位次之后,armed 收窄使其辖域自然收窄,P70 支配性结论在子辖域保持;既有批 1 哨兵锁语义不受影响。
- **无开关**(C3 设计 §7.3):判据本体行为变更走三同步(本 ADR + as-built + 测试锁),回滚 = git revert 单操作。

## Considered Options

- **原候选:按 2★ 数/装备覆盖重校判据**——作废(策略审查打回):板面强度评分进决策门违 00 §1 禁战力建模;P62 已证 form_score 饱和零信息;2★ 数对结局量无一致方向(ADR-0535 方案②否决记录);装备覆盖无定量锚(sim-design §4.1 效果面禁出 sim)。
- **承重下限取数值阈值(如 B_t ≥ N)**——否决:N 必为拍定值(禁);任何分数比例阈值(如 ≥80% 占用)同罪。
- **承重视图取四体系集(`SYSTEM_LINE_FACTIONS`,即披露 B_t 本体)**——否决:注册表直调实证 COMP_LIBRARY 20 套中 15 套 form_tiers 非空且键集含四体系外阵营(口径 = form_tiers 键集 ⊄ 四体系视图集,直调复算 2026-09-07;反甲白厄 form_tiers 空不计),该视图下这些线的达标板面承重计数恒低于占用数 → armed 永久关闸 → 全量走收益耗尽臂的系统性行为破坏。取 `comp.all_factions` 视图 = 判据随目标线走,与部署围栏/cw_comps 板面判定既有口径一致。(落地审 F1 追加:纯 comp 视图对空羁绊单卡核心〔白厄〕与视图外 shared 件〔不死途/布洛妮娅/刃〕有同型缺口,已并入自家核准集修复,见 §判据承重满额定义。)
- **质量推迟不加 fail-open 出口(纯承重闸)**——否决:板满+bench 无可部署+停手帧族(成员齐/档齐/线外件占槽)下策略层零动作,关闸将复触环级无进展守卫停摆(第七局病灶形态回潮);fail-open 出口使推迟恒有界。
- **换血可行性用 admission 三元(board_full∧bench_core_waiting∧¬victim_missing)表达**——否决:三元是观测位语义,bench 腿(名字/阵营两支)与部署围栏真实接受集存在偏差帧,偏差方向不安全(闸关而无动作);`has_deployable` 判空与实际发射门同源同参(严格子集方向),单一源且偏差方向结构性安全。

## Consequences

- 正面:armed 获得配方之外的结构质量维,「配方成型≠板面扛得住」缺口在结构轴收口;闸零自由参数、推迟恒有界、消费面零改;B_t 轴的判读观测位(`quality` 报告)随判据落地。
- 代价/边界:达标臂发射时点系统性后移(配方完备但板面含线外件的帧族,从「立即发射」改「换血/填板后发射」)——行为变更本体,效果待 sim A/B 确认(改进方向对准过程量:推迟频率/翻真率);fw_carry/locked_factions 严格子集偏差使闸偏开(少推迟不早错杀);P70/ADR-0566 仲裁段辖域随 armed 收窄同步收窄。
- 关联:C3 设计《设计-C3成型质量维度.md》v3(§2.1 原核心 2★ 形态经打回路由由本 ADR 的 B_t 轴替代,§2.1/§3.2/§6 的 fail-open/推迟有界/最弱一环教义全部承继);ADR-0535(升格闸门)、ADR-0557(判据核单一源)、ADR-0554(收益耗尽臂兜底)、ADR-0534/P61(承重收敛路径)、P62/P63(证据锚)。
