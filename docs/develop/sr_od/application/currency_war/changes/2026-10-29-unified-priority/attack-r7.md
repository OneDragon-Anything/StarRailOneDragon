### 中

**R7-01 ｜ 中 ｜ 核二·规则 4（无池子拍板第五触达面漏改）＋核一·依据与权威源不符 ｜ dismantle.md §3 :57**
「`entry.py` 节末凑息阻断（:1165-1207）：凑息身份排除退役（**凑息池 = 备战位全量**按序列，无身份
排除）」——「备战位全量」口径两头失锚：
- 与现行权威源不符：现行凑息候选池 = **备战席 ∪ 场上无关角色**（entry.py :1211-1212 docstring
  自述「候选池 = 备战席 ∪ 场上无关角色〔来金族，用户裁定 2026-10-13〕」；:1167/:1170-1171 同款
  「备战席全量 + 场上无关角色谓词单一源」）——「备战位全量」漏掉场上无关角色分量，非现行描述；
- 与拍板新形态不符：design §2.7 :181 无场景专属池子拍板 =「全部卖出触发（溢出/晶矿/凑钱/筹资）
  统一按部署重排后的**全局面序列**取用」，凑息 ∈ 凑钱类 → 新池 = 全局面序列——「备战位」限定
  与拍板相反。同迭代的 acquisition §3 :75（「无场景专属池子——统一按部署重排后的全局面序列取用」）
  为正确口径，两详设件两答案 = 实现者需自行仲裁（R3-03 同型）。
- 漏网机制：该行不含「无池子」关键词，R6 的四处触达面检查与本轮返工侧 grep 复查（词面「无池子」）
  均未命中——无池子拍板的第五触达面。
- 修正方向：改「凑息身份排除退役（凑息 = 卖出触发之一，池 = 部署重排后的全局面序列，见 design
  §2.7 无场景专属池子拍板；现行候选池 = 备战席 ∪ 场上无关角色，entry.py:1211-1212）」。

**R7-02 ｜ 中 ｜ 核一·表述可歧义（规范硬规则 2：实现者语义选择无答案）｜ design.md §2.2 :105**
「免费次数在册即刷，无阶段/带/目标/目标可买任何判据门（『白给的刷新照用』推到底——免费不耗金，
无理由不刷）」与「金线不足与**记忆机制照旧**」两句并存，免费腿与负结果记忆的**交界面**未裁决：
- 结构事实（shop.py :2018-2023 实读）：记忆检查是整个刷新提案的**外层闸**（键比对清值 :2019-2021
  → 在册即跳过 :2022-2023，免费腿与付费链都在其 else 内）；两处详设执行规格（acquisition §5 :98
  「**分支内**判据整段替换」、dismantle §1 :16「分支（:2025-2047）的……检查删除后改无条件刷」）
  均只动分支内 → 记忆结构保留 → 免费腿在记忆之后。
- 冲突帧族：帧 N（免费次数耗尽 ∧ 金线不足）→ 付费链拒绝置位（:2089 现行，改造后保留）；帧 N+1
  概率补给免费次数在册、块键（节点/金/席位/星级目标）未变 → 记忆在册 → **免费腿被压制**——
  「在册即刷」不成立。免费次数补给若只发生在节点边界则该帧族不可达（节点变化 = 键变 = 清值），
  但「概率补给」（design :105 自述「次数每节点重置/概率补给」）未排除节点内发生，可达性未被
  文本排除。
- 两种读法行为不同：A 按拍板主句（「推到底/无理由不刷」）→ 免费腿应绕过记忆（挪出 else 或记忆
  检查加免费在册例外）——「记忆机制照旧」需修饰为「仅拦付费提案」；B 按执行规格字面（结构不动）
  → 免费腿被记忆拦——「免费次数在册即刷」需加「记忆在册帧除外」注记。设计文本未择一，实现者
  撞上无答案。
- 行为申报覆盖连带：申报句「目标不可买帧从『拦下不耗次数』变『照刷耗次数』」在读法 B 下不成立
  （记忆在册帧照拦不耗）。
- 修正方向：补一句裁决并按其修饰另一句。建议方向 = A（免费腿不受记忆拦——无条件刷后免费腿无
  拒绝形态，记忆「防提案被拒白转帧」的原始动机对免费腿消亡，与「白给照用推到底」拍板意图同轴；
  R6-01 附带核对的结论方向随之成立），按 R6-02 万金油申报同型显式写出推论供过目；若选 B 则如实
  申报「记忆可压制在册免费次数直至块键变化」。

## 四、定稿判定

**判定：需继续返工（最后一轮微幅返工 + 一处语义裁决句）——未达定稿门槛。**

理由：
1. **高阻断清零，核心模型七轮未动摇**。R6 唯一高（R6-01）三处触达面同步闭合，旧口径零残留；
   八档/三触发/接口三分工/遥测隔离经七轮攻击无一被动摇。R6 九条回归 7 条完整、无一条 R6 发现
   本身误报——R6 的收敛预判方向正确。
2. **但「零新发现」未达成，且两个中级为实现歧义级**。R7-01：按 dismantle §3 :57 施工将得到与
   无池子拍板相反的凑息池口径（两详设件两答案）；R7-02：免费腿与负结果记忆的交界面在拍板正文
   与执行规格之间无唯一答案，实现者面临规范硬规则 2 禁止的自行拍板——定稿试读（「凭这份能
   开工吗」）在这两处不过。三个低级各一行（R7-03 叙事残留 / R7-04 行号锚 / R7-05 档 8 键）。
3. **剩余返工面全部单点化**：R7-01 一行改写、R7-02 一句裁决 + 相邻句修饰、R7-03 一行、R7-04
   一处行号 + 锚形态、R7-05 一句——合计约 8–10 行级，无结构性返工。
4. **无硬性用户裁定项**。R7-02 的方向可由拍板意图推定（建议免费腿不受记忆拦，按 R6-02 万金油
   申报同型显式写出推论交用户过目；仅当用户意图相反时回调，不构成阻塞）。
5. **流程级建议（第三次同族复发，规则 4「二次复发即流程级」已触发）**：拍板落稿 → 触达面漏改

   单字级）或按行为申报清单逐场景反查三详设执行规格。
