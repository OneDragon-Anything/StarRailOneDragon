## 命题

把「本备战期要不要手动刷新、刷几次」化为可计算规则。决策变量:n ∈ {0,1,2,...} = 本备战期手动刷新次数(刷价 2 金,可重复;节点自动刷新免费已领,economy.md §2.1「节点切换=整店自动刷新」)。要证:

1. **单步 EV 门**:第 i+1 次刷新的边际期望 = P_i(刷出会买的卡)× V̄_i − c_eff,给出 P_i 的封闭形式(超几何 + 池衰减)与全部语境变体的 c_eff;
2. **完成门**:追缺口是不可分投资,启动判据必须按「闭合整个缺口的承诺账」(期望刷费 × 刷价 ≤ 缺口成型价值),单步门只管启动后的续刷与独立散刷——「把钱花光了跟死了没一样」的数学形态;
3. **预算门**:息线约束形式化为「刷后仍 ≥50 或不跨息档」,溢余段(>50)行为 = 上界松弛;
4. **停止条件(n=0 判据)**:合格集空 / 价值门不过 / 预算门不过,三者任一即 n*=0;
5. 语境变体逐一入模(淘金客 XP 返还 / 概率事件 45% 免费 / 轮岗概率翻倍 / 刷价突变 / 市场干预周期 3 费面 / **节点类型×投资环境**)。

## 假设(显式)

- **A1 槽费用档分布**:5 槽各自独立以 p_c = `REFRESH_PROB[level][cost]` 出费用 c(与代码 `_refresh_dist` 同阶:费用档二项 + 档内超几何)。轮岗语境下 p_c 换成概率条读屏真值(`parse_prob_bar`,读屏即真值,ADR-0091/r77)。
- **A2 档内均匀**:给定费用档,出哪张牌在**该费剩余池**上均匀(超几何无放回)。隐藏权重类效果(概念股 ×15 等)按 invest_effects §5 裁定放弃建模,不在本篇。
- **A3 NPC 不耗池(方向双侧)**:剩余副本只扣玩家自己持有的 j 张(与 `acquirability_factor` 同口径;单人对局,敌 AI 是否耗池未证实)。方向:**NPC 买目标同费卡 → 高估命中率;NPC 买非目标同费卡 → 效果等同 c_taken↑ → q 反而升**(与「压库背书」推论同向)——两向都列边界,量级未知。
- **A4 命中即买**:「会买的卡」按当前缺口定义**合格集 E**(目标阵容件 + 插件,不是任意卡,[31]② 原文「刷新金只用于找**目标件/保血急救**」——后半句由 [39] 裁定不入决策,显式声明非截引;**E 含插件的张力:[31]② 字面是「目标件」,插件入 E 是本设计的扩展读法——登记为口径裁定项,过 p46 预过滤后插件是否算「会买」按 §4.5 板满门联动**);命中 → 购买,卡价计入 spend(息线账),本篇只对**刷费**建 EV。**交互双向声明**:合格集 E 按**期初静态快照**预过滤 p46 可过卡(命中必否决的卡不进 P);**残余白刷三态(p46 §⑤ 限定式的 p40 侧落地)**:①同刷新多命中后金位变化、②累计跨档使后笔落域、③部署位互斥——EV 侧按命中折扣系数或最保守序消化,折扣系数标定挂 sim 对拍;被否决的命中卡不买 → 池不衰减、R1 承诺账不消耗。
- **A5 V̄ 粒度**:V̄ = 命中卡的条件期望净价值(该卡自身的买/不买由其购买 EV 规则判,刷新规则只在「存在会买的卡」意义下取条件)。一次追缺口期内 V̄ 近似恒定(缺口 1-2 张内边际成型价值变化平缓)。
- **A6 期望口径 c_eff**:免费概率(概率事件)与 XP 返还(淘金客)按期望折进刷价;逐次独立 → 大数无偏,方差不改阈值方向(边界注记见 §4②)。
- **A7 刷与自动刷新同分布(待实机核)**:经济 §2.1 实锤的只是「刷新重置=整店 5 槽全换、**无继承偏置**」——同分布(概率条对手动刷后是否同值、轮岗期手动刷是否继承当期翻倍)无直接证据,列为待实机核;轮岗语境下读屏概率条读的是当前生效分布,可部分免责。

## 证明

### ① 命中率的封闭形式(单步 EV 的 P 项)

**合格集 E 的槽级命中概率**。设合格集在费用 c 档含 g_c 种卡,玩家已持有第 t 种 j_t 张(已离池),同费非目标已被买走 c_taken 张(压库量)。该档剩余合格副本 R_c = Σ_t (a_c − j_t),该档剩余总副本 T_c = v_c·a_c − Σ_t j_t − c_taken(a=`POOL_COPIES_PER_CARD`,v=`DISTINCT_CARDS_PER_COST`)。单槽命中概率:

```
q = Σ_c p_c · R_c / T_c
P(本店命中) = 1 − (1−q)^5        (5 槽独立近似——同档槽间无放回**负关联抬高至少一张的概率**,
                                  独立式**低估** P(≥1),自引数即证:0.1039 < 0.1041,量级 ≤0.2pp;
                                  **表值一律走精确超几何**(脚本 hit_prob);多类合格集落地只能用
                                  独立近似——**独立式低估 P(≥1)=偏紧(保守)**,与 A3(NPC 忽略耗池=偏松)
                                  方向**相反、部分对冲**
```

**EV 的价值项用期望命中数(线性口径)**:E[#命中]/店 = 5q(期望线性,无需独立性假设)——单步 EV 定义为 `EV = 5q·V̄ − c_eff`;P(≥1)·V̄ 较之恒为**低估**(一刷多命中未计,合格集越大偏差越大),仅用于停止语义与保守阈值展示(V* 表值按精确 P 计算=更保守一侧)。

精确版 = 把 `_refresh_dist` 的 rem_target 从单类 (a−j) 推广为多类 Σ(a−j_t)(M~B(5,p) 数费用格、档内超几何抽牌,结构不变)。两个方向性推论直接可读:

- **池衰减**:命中并购买后 j↑ → R_c↓ 且 T_c 同步↓,但合格集通常 g_c ≪ v_c,|ΔR_c/R_c| > |ΔT_c/T_c| → **q 随持有单调下降**(追星越深越难刷);
- **压库背书**:买同费非目标 c_taken↑ → 只减 T_c 不减 R_c → q 单调上升([1]/[15]/[30]/[34]① 压库纪律的方向性数学形态;量级小,economy.md §3「买 30 张升约 1 个百分点」)。

**单步 EV**:

```
EV_{i+1} = 5·q_i · V̄_i − c_eff      (期望命中数口径;期内购买发生后 q_i 随池衰减重算)
```

### ② 三层决策规则(核心结论)

**规则 R(刷新决策)** —— 状态输入:金 g、缺口(合格集 E、各自 j)、等级 lv、语境(变体开关)。输出 n。

- **R0 停止条件(n=0 判据,硬)**——三者任一:
  1. **合格集空**:E = ∅(目标件囤满、无插件缺口、或 bench 满到「没过渡牌可买」)→ P=0 → EV = −c_eff < 0 恒负。**刷=纯烧金**。这是 [31]②「不为凑数羁绊花金 D 牌」的数学形态。
     ⚠️ **[1]「奖励节点不 D」不是本条**:[1] 原文=奖励节点**保息前提下多买压库**(持续买卡!)+ 不 D——奖励节点上 E 通常**非空**(过渡配方件属目标侧),不 D 的机制是 **V̄ 的节点依赖**:无战斗节点上「找牌提速」的战斗向边际收益归零([16]①「刷牌的战斗向理由全关」),只剩压库/时序价值撑不起刷价 → 归入 **R0-2 价值门的节点语境特例**(变体⑥)。
  2. **价值门不过**:P>0 但 V̄ < c_eff/P(见 ③ 数值:该阈值在低费场景 ~10-20 金、5费场景 ~150 金,只有「差 1-2 张成型」的高边际缺口才可能过,[economy §5 信号] 的形式化)——**节点语境在此生效**(变体⑥:无战斗节点的战斗向 V̄ 分量=0)。
  3. **预算门不过**(R2 熔断)。
- **R1 完成门(启动判据)**——追缺口是**不可分投资**:刷到一半弃刷 = 沉没刷费 + 缺口未闭(「把钱花光了跟死了没区别」的期望形态)。故「开始 D」必须按承诺账判:
  ```
  启动 iff  c_eff · E[refreshes | j] + Σ卡费 + L(g, spend, R_全局, Ī) ≤ V_gap
                                              (息损项=p47 L 递推,L 联动批;Ī 中位 7 现算;**L 恒入账——p47 三读分带下同档也有带内残损,一律走 L 递推,近 50 同档自然 ≈0,不做条件分支**)
  ```
  (息损是**成本侧负项**,与 R2/P13 符号统一)E[refreshes | j] = `expected_refreshes`(超几何 DP,已实现**单卡版**;多类合格集的推广=待办,见结论)。启动后期内**不再用单步门否决续刷**(沉没成本谬误),但有三类合法退出:
  - **缺口失效即停**(证据门切换目标线/[23] 贯穿件改线——目标没了,继续刷=变相沉没成本谬误,非熔断);
  - **R2 逐笔重估**:期内每次购买后按新金位重算 n_max(预留卡价是期前保守值,购买发生后必须刷新);
  - **独立新缺口**判据:新目标的合格集与原缺口**无交集**(部分重叠按重叠部分折算,不算独立);
  直到缺口闭合/失效或熔断。
- **R2 预算门(息线,规范口径=p47 L 递推)**——spend = **c_eff·n**(c_eff 不写死 2,与 n_max 的 c_eff 口径一致;变体②⑧⑩下同价)+ Σ命中卡价;**息损项 = L(g, spend, R_全局, Ī)(L 联动批正式引用:p47 双轨迹递推为规范单一源,`loss_exact` 可直接 import;Ī 取 [6,8] 带中位 7 现算;R_全局=当前节点+后续位面按实际长度,p47 A6 规范口径)。方向推论(= L 的自然推论声明):小额购买(同档/贴档)门放宽——旧口径 t×min(R,3) 对平台期小额高估至 3×(L=1 vs 旧 3),把它们错杀;深档大额(破 50 追缺口)门收紧——L 对档深超线性(平台期 d=30 → L=9、d=40 → L=14,旧口径 12)**。t×min(R,3) 退役为过渡对拍基准(双侧误差:p47 失效带表)。
  - **溢余段(g > 50)**:n_max = ⌊(g − 50 − Σ预留卡价)/c_eff⌋,段内 t=0 自由([17]「>50 的每一分都没有存的意义」;不强制清空——判据是「当下有没有边际价值高的花处」= R1 的 EV 门,不是金位);
  - **g ≤ 50 跨档(t ≥ 1)**:刷费进买侧总账,**C = L(g, spend, R_全局, Ī) 作负项**(L 联动批;规范单一源=p47,与 p46 两门同步切换防双源)——即「破 50 刷」需要 V_gap 覆盖息损,门槛随轮次收紧(Δp* 表),与 [3]「刷新后还能保证 50 金」**口径对应**(非逐字——[3] 是金位表述,本门是息损账,语义等价非字面);**同档不跨(t=0)不再自动零息损**(L 联动批,按 p47 命题三精确化:同档零息损仅近 50 区(Ī≥6)成立 L=0;低金带同档残损 L=4-10——按 L 现算,不引用旧结论)。
- **联合**:**n = 0 若 R0 命中;否则由 R1 决定是否启动,启动后逐刷至缺口闭合 / R0-2 翻负(独立新缺口场景)/ R2 熔断**。散刷(溢余段无明确缺口的多刷)= 逐次单步门(EV ≥ 0 即刷),因无不可分性,不需要完成门。

**一致性**:V̄ 恒定时,启动门(c_eff·E ≤ V_gap)与「每步 EV ≥ 0 直到闭合」不等价——前者是总账充分条件,后者是逐步条件;差异恰是**不可分性风险溢价**:E 大(缺口深)时逐步 EV 可能每步微正但方差大、中途熔断概率高。完成门选总账 + 熔断线,是对「半途而废」的显式防护。

1. **差 1-2 张才该 D 是数学结果不是手感**(**方向无条件成立,量级是 V̄ 标定前的条件结论**):缺口从「整缺口」到「差 2 张」,5费命中率从 0.054 掉到 0.0135(**池衰减 4 倍**——j=7 已把剩余副本吃到 2 张);反过来说,**j 越深越难刷、但 V̄(最后一张的成型边际)越高**——「该多刷」窗口 = V̄(k 小)×P(j 深)与 c_eff 的赛跑,只有成型前 1-2 张的边际价值可能盖过 V*=c_eff/P ≈ 19-148 金的刷价门槛([economy §5「key 牌差 1-2 张成型」信号]的量化形态)。

### ⑤ 方向自检(三代表场景)

- **低费缺口@低级(S1)**:P=0.104,V*=19.2 金——过渡核心 2★ 差 2 张的成型边际(P3 rung_value 量级 × 位面剩余轮)在 P1 中后段可过门;溢余段(g=62,S1 预留=2×1费卡)刷窗 = ⌊(62−50−2)/2⌋ = **5 次** ≈ E[刷满 19 次] 的一部分,**单期刷不满 19 次是常态** → 完成门应按「跨期持续追」理解:本期刷窗用尽即停(预算熔断),缺口与 j 跨节点保留,下期续——**预算熔断不是失败,是时序配置**(P13① 同构)。
- **高费缺口@高级(S2)**:V*=148.4 金(c_eff=2),440 金期望刷费 —— 除「成型差 1 张 + 终局边际」极端段外不过门,**默认不 D**,靠自然刷新与 [22]① 囤件覆盖;这与 [3]「没到(概率级)就少刷多买经验」的择取公式一致(升级提高 p 的通道与刷新通道共用本 EV 框架,p 换级即重算)。
- **溢余段(S3)**:t=0 自由带 = 50 线上方;刷窗 n_max = ⌊(g−50−Σ预留卡价)/c_eff⌋(**同 R2 公式**,配合 R1 单步门——**溢余不改变 EV 门,只解除预算约束**([17] 防读半:金 >50 不是「必须花」,是「花的时候不用过息线账」)。

## 结论

1. **决策规则(单一结构)**:`n = 0 if R0;elif R1(启动)通过 → 刷至缺口闭合/失效/R0-2 翻负/R2 熔断;散刷 = 逐次单步门 EV ≥ 0`。**可计算性分级(诚实口径)**:P(超几何+池衰减)、c_eff(2−变体折减)、**L(p47 双轨迹递推,Ī=7 现算——L 联动批已落地)**现成;**V̄/V_gap 是最大待标定项**(全部阈值随它缩放;毛/净口径见待标定表);**E[refreshes] 已实现仅单卡版**——多类推广分级:**单步 P 易**(rem_target 换 Σ(a−j_t),结构不变);**E[refreshes] 难**(DP 状态从标量 j 变向量 (j₁..j_g),状态空间随合格集种类数膨胀,需近似或剪枝)=待办。
2. **停止条件**:合格集空 → EV 恒负(n*=0,「没过渡牌绝不 D」的证明);价值门 V̄ < c_eff/P;预算门跨档未过 L 账(p47 规范口径,L 联动批)。
3. **完成门 > 单步门**(不可分投资):启动按 E[refreshes] 承诺账,启动后不受单步门否决——「半途而废 = 烧金无成型」的防护。
4. **语境变体 = 参数替换**(c_eff:淘金客/概率事件/刷价;p_c:轮岗读屏/市场干预),规则骨架不变。
5. **待推翻候选**:无现行代码直接冲突(_refresh_cap 动态上限是本规则的一个实现特例,方向一致);若实现按本规则重写,动态上限应替换为 R0/R1/R2 三门。

## 对实现的检验点

1. **断言锚**(sim/单测):E=∅ 时任何金位 n*=0;轮岗目标档命中率 ≈ ×2;概率事件 D 频次上升 ≈ 刷价比例;c_eff=1 时深缺口启动率上升。
2. **判读锚**:实机/sim 里「金 <50 且无成型缺口的连刷」= R0-2 违例(过程病);「启动追缺口中途停」= 熔断(合法)或单步门误用(病,查是否对承诺期内缺口用了单步门)。
3. **sim 对拍清单**:
   - 固定 2 刷 vs R0/R1/R2 三门:出口金、成型率、破息率三方对比(A/B);
   - 完成门 vs 纯单步门:半途而废率(启动后熔断局占比)与沉没刷费;
   - 预算门 on/off:P1 破息率与 P2 入口金分布([28] 双指标验收口径);
   - 轮岗:读屏真值 vs 基线表的命中率校准(×1.94 邻域);
   - 概率事件/淘金客:c_eff 折减后 D 频次与出口金;
   - 奖励节点 n=0(与现状「不 D」对拍,应零差异——回归锚)。
