## 1. 问题与总纲

机器回答三个问题:**方向怎么选、何时定型、何时换线。**

一句话总纲(全篇的压缩):

> **未定型期的决策单位是「件」不是「线」——一切买入按插件对待,各有替换计算;阵容是积累的涌现结果,不是被选择的目标。线级选择全局只发生一次:终局证据门(分数 = 完成概率 × 权重,槽位候选)。动态是嵌套半活 + 一次满养。**(2026-09 裁定:未定型期无线路选择对象——[23]「P1 不靠分数涌现挑线」由此零冲突保留;历史「四线摇摆」死法是旧机器把线当 pivot 对象的病,件级经济学不产生拆装)

与既有结论的关系:决策层七消费点(买/卖/升星/部署/装备/刷新/换线)全部由「期望数学 + 结构计数 + 知识先验」解决(ADR-0512 裁定链);**本设计覆盖其中「买(阵容侧)」与「换线」两点的机器形态**。期望数学族的证明件(k 缺口成型分布、刷新定价统一式、P3 纯经济重推)另行排队,本文只锚接口。

## 2. 候选模型:槽位结构

**任何候选(过渡阵容或终局阵容)= 一列槽位,每格是两种之一:**

| 槽位类型 | 语义 | 缺口等待模型 |
|---|---|---|
| **指名槽** | 等某张具体的卡(姬子、白厄) | 单卡等待数学(出现率几何族,慢) |
| **合格集槽** | 等任意一张符合条件的牌(「再一件仙舟」) | 并集概率(来牌快) |

两层是**同一种数据结构,不同配比**:P1 偏合格集槽(体系槽为主 + 少数升星指名),终局偏指名槽(core 名单 + flex 摇摆位)。差别是配比,不是结构——选择机器对两者用同一接口。

**候选来源(登记制,用户裁定:与终局同款、带版本纪律):**

- **P1_RECIPES 登记库**:6 套过渡阵容(四体系两两组合),每条 = 体系组合 + 门槛引用 + **强度注记位**(知识注记,见下)+ 版本作用域 + 出处指针(`docs/game/currency_war/research/transition_combos.md`)。
  - **行为消费方声明**:①**过渡成型判定**(读门槛引用:两体系达标 = 过渡阵容成型——§4 生命周期的游戏事实判定);②版本维护(一致性测试 + 强度注记登记)。**不参与候选打分**(裁定 12)。
  - **一致性测试**:`P1_RECIPES == combinations(体系定义, 2)`——**「体系定义」单一源 = 重构批新建的四体系注册常量族**(kernel 侧单一源;现役三形态 `RECIPE_FACTIONS` / `TRANSITION_TRAITS`+`SEELE_SYSTEM_KEY` / 文档描述,在重构批收敛为一,测试对旧形态比对 = 恒真风险);组合结构未被版本破坏期间,登记不许漂移;测试红 = 版本改了组合规则,强制人工审视登记(版本迭代的触发器)。
  - **强度注记位(消费方挂起声明)**:默认等强;改值通道 = 实机战斗真值 / 用户口述,**采用频率永不入权**。注记位当前**无直接消费方**——未定型期是件级决策(裁定 12)、终局门评估 COMP_LIBRARY,都不读它;它是「实战发现某套偏弱」时的登记处,消费通道(如件级估值的体系项折减)待该发现真实发生时按裁定接线,不预建机械。
- **COMP_LIBRARY**(已有):终局配方登记,含 core_chars / flex_factions / 装备位 / 星级路径——不可从更底层推导的具体知识,登记即知识。

## 3. 选择机器(仅终局证据门使用)

```
score(终局候选) = 完成概率(缺口账单 × 池概率 × 金排程)
               × 权重
```

**辖域声明(2026-09 裁定)**:分数选择只在**终局证据门**运行(评估 COMP_LIBRARY 候选、决定点火);**未定型期不跑用于行为决策的候选打分**——那期间的决策是**件级插件经济学**(§7 的估值公式,逐件买/持/换/卖),过渡阵容是涌现描述不是选择对象。**精确化**:证据门自身的逐轮过阈计算是**开门检测**(输出状态转移条件,不产出任何买入/部署指令),是未定型期唯一的候选级计算——与「不跑候选打分」不冲突。逐件说明:

- **完成概率**:缺口账单(逐槽位:指名槽单卡等待 / 合格集槽并集概率)× 出现率(cw_shop_odds 单一源,禁第二把概率尺)× 剩余经济(金排程)。**完成的目标态分档(2026-09 裁定)**:缺口账单按候选的**下一成型里程碑**算,**不按全终局算**——按全形态算读数系统性偏低、门过晚开。**载体裁定(2026-09:预编节奏退役 + P2 形态不定义)**:分档载体 = **逐套派生的结构里程碑**,且仅此——①羁绊档套:`form_tiers` 达标(成型里程碑);②装备流套(`form_tiers` 空,如反甲白厄):核心卡+关键装备到位(自 core/装备位注册数据派生)。**不定义独立的「P2 中间形态」字段或知识批**(手编形态规格 = level_plan 同病);攻略 Early-Middle-Final 数据降级为**校验材料**(对拍派生里程碑与实际中停形态,不对再议);某套门行为异常时**按需单独补**。**禁止**:任何预编时间表(轮次窗/节奏计划)形态的载体。**诚实声明**:现役不可达时钟用的是待退役的 `typical_form_round`,`form_tiers` 在现役只承担成型豁免——新机器的不可达时钟 = CDF 分位数,不改写历史。产出一条 CDF:**分位数读数 = 预计成型回合(取代旧手估常数 `typical_form_round`,随预编节奏退役);截止点读数 = 完成概率**——同一分布两个读数,分别供换线门与证据门使用。证明件(k 缺口推广、等级排程、刷金排程分割)排队中,未证前不落实施。
- **权重**:
  - **默认全 1**(两层同:四体系平权、全部终局阵容等权——攻略热度/帖子数永不入权,采用频率≠强度);
  - **环境分化**:敌人词缀 + 投资策略环境的机制层知识(游戏文本/注册表/口述,非拟合值)使某候选显著优/劣时,权重偏离 1;**环境臂规格**:门第二臂 = 某候选权重 ≥ 显著优势阈(常量名 `ENV_DOMINANCE_RATIO`,值标定批定;**载体 = §3 权重表本身**——环境臂与分数乘法共用同一张权重表,臂是权重的阈值读数,不另设通道);
  - **手动预留**:用户口述裁定可直接改权重表(最高权威);
  - **非法通道**:攻略热度、胜率语料回归、战力模型输出。
- **两臂分工与仲裁**:证据门两臂(完成概率过阈 / 环境主导)是**开门条件**,不各自指认目标——门开了之后,**目标是分数最高的候选**(完成概率 × 权重):完成概率臂先过但另一套因环境权重更高而总分领先 → 承诺总分最高的那套,两臂不冲突(都进了同一个乘法)。**平局规则(确定性,读法钉死)**:总分并列时按「**与当前持有的重叠件多者**(两候选各自与我方持有的共享/成员重叠数——非候选间共享,后者对称恒平)> **现持有 core 数多者** > **注册序**(COMP_LIBRARY 登记顺序)」定序——防并列-非并列的轮间抖动造成承诺目标振荡(证伪记忆只挡试败线,挡不了并列摇摆)。

**刷新接口锚**(证明件排队中):EV_D = 新店满足缺口的期望推进 − 刷新价 ×(1 + 金影子价格);逐回合停时规则;成型估算按「购金+刷金」分割排程。

## 4. 生命周期:嵌套半活 + 一次满养

```
P1:多体系小额半活(按体系门槛计价)
  → 过渡阵容成型(游戏事实,免费,无需门)
  → 重心连续滑动:终局成员资格成为主导价值项(换币是比喻不是事件)
  → 2-3 套可达阵容的核心半活(共享件优先,比 P1 浅)
  → 证据门(完成概率过阈 OR 环境主导)
  → 满养:独占这一套(3★ 路径 + 装备绑定 + 剩余名单 + 回收旧件)
```

**过渡阵容的定型 = 成型**(两体系达标、羁绊亮):**终点线**——过渡阵容没有昂贵尾巴,成型即完成,后续投资属于下一个对象(终局)。成型**不换任何规则**(见 §7)。

**终局的定型 = 承诺**:**中间态**——因为终局的完成本体是一段昂贵尾巴(3★ 多份 + 专属装备 + 剩余核心),这段尾巴必须独占资源;承诺就是为尾巴专门拨款的点火时刻。等完成再承诺无意义,太早承诺则证据不足。**尾巴本身分档**:中间形态(P2 子集,档位链见 §3)→ 全形态——每档自己的缺口账单与成型时点;定型后的满养先补下一档,再到全形态(stage_transitions.md 的阶段模型)。

**承诺是状态机转移,不是数值**(search → focus):

| 规则 | search 态(承诺前,含终局锁定前的终局阶段) | focus 态(承诺后) |
|---|---|---|
| 买什么 | 件级估值买入(无方向禁令) | **只买这套名单(core + flex/插件合格集)+ 升级件;名单外的目标外同名副本,[34] 判定序第 3-5 级照常适用**(通用插件/压库/凑星——[34] 以目标阵容为前提,focus 态名单即目标) |
| 卖不卖 | 永不卖方向件(压力卖出除外) | **旧线件折现回收** |
| 装备 | 攒着不绑 | **绑给核心** |
| 多久重估 | 每轮重排(免费) | **只认事件门(§5)** |

四条规则必须**一捆一起换**(半换状态自相矛盾:绑了装备还在买别方向/卖了旧件还没聚焦)。权重增长是因(连续),门读权重、拨动状态转移(离散)。

## 5. 换线机器(focus 态专用)

- **三个触发**:位面边界重估 / 现线不可达(**CDF 分位数读数**:预计成型回合 > 剩余战场数;已成型豁免)/ 严格更优。
- **比较式(同量纲)**:`新线完成概率(金排程已扣切换损失) > 现线完成概率 + 常量 SWITCH_MARGIN(标定批)`——切换成本**不做跨量纲减法**,以「旧线件回收折价 + 新线再购侵蚀新线购牌预算」的方式进入新线完成概率的输入(金排程变薄 → 缺口填得更慢 → 完成概率变低);成型时钟重置已含在「按当前持有重算新线成型回合」里。账单本体 = 资本方向绑定 + 时钟重置,卖不卖只是零头。
- **整块替换 + 诚实回收 + 证伪记忆**(试败线排除,防反复横跳)。
- **无可达线时的兜底(最小规格)**:三触发开了但候选集内**没有任何线可达**(现线不可达且换线目标全部不可达)→ **维持现形态 + 场况插件纪律**(生存模式:件级估值照常、插件有位即上),不做换线动作;**兜底期名单件照买**(部分完成仍推进羁绊档位/板面结构,停的只是换线);「降格终局」机制(凑不成完整终局时退而求其次的中间形态)深化挂起,实施批前出规格。**search 态同型情形**:若至局末证据门都未开(全候选不过阈且无环境臂),行为 = 维持件级估值与三分法纪律到底(无承诺即无换线问题),不作特殊处理。
- **search 态没有换线问题**——不是「换线便宜」,是**没有线对象**:未定型期按裁定 12 无候选打分、无锁定,不存在「从哪条线换出去」。

**删除 vs 降权(证据门纪律,辖域修正)**:该原则辖于**终局证据门**——门评估全部 COMP_LIBRARY 候选,不设硬过滤/预筛(「可达」是完成概率的软读数,不是准入条件),分数低的候选自然得不到承诺;删除候选会丢失「排名回升」的可见性。**未定型期不适用此原则**(无候选集——件级决策没有可删除的对象;买牌许可 = 全牌池按件级估值,无方向禁令)。**证伪记忆**对试败线的排除是 focus 态换线机器的约束(防横跳第三道闸),与证据门纪律分属两处,不冲突。

## 6. 为什么未定型期不设线路限制(裁定 12 的论证展开)

按方向禁买某些牌 = 对未定型期施加线路约束 = 不可逆动作;**不可逆需要证据**。

1. 未定型期的领先是商店运(六套过渡阵容等权),不是「这条线更好」的证据——按计数禁买其他体系 = 绕过证据门立假设;
2. 再购成本:禁了想回要重买(单卡等待 7-14 回合 + 再付一次钱);
3. 多信贷红利:跨线件一牌两用是切换便宜的机制本身,按体系禁买 = 亲手拆掉它;
4. 集中靠件级估值涌现(台阶正反馈),不靠禁令。

**买入许可集(取代旧「目标集三档」表述)**:未定型期 = 全牌池按件级估值(三分法纪律 §7),无方向禁令;focus 态 = 该阵容名单(core + flex/插件合格集)+ 升级件;换线触发 = 按新目标重算一次。

## 7. 未锁定行为(两层同一套规则)

| 规则 | 内容 |
|---|---|
| 买 | 同一估值公式:**台阶推进 + 骨架 + 核心件等待经济学 + 终局成员资格**,按值/价贪心,金受经济底线约束。**核心件等待经济学 = C_A<C_B 对首件与副本同样适用**(C_A = 立即购买成本——价金+挤占;C_B = 放弃后再遇的总期望成本——再遇概率 × 等待回合 × 错过截止的损失;**副本侧=旧 P1 弃购账——P1 属旧树,域重推件=p41(redesign/01 §6),过证前按待证假设使用;首件推广为待证假设**——两处均列入排队证明件,按 ADR-0482 声明纪律,未证按待证对待;在册 [21] 买而不上/[22] 有用先囤的数学化):过渡凑型期间遇终局核心,「现在买囤着」vs「等再遇」按出现率×剩余回合×错过即截止定夺——单卡再遇期望 7-14 回合,一位面尺度上错过常等于等不回;与过渡件抢金由值/价比较裁断(核心的值含错过成本,等级门槛天然错峰 4-5 费出现窗) |
| 卖 | 同一卖出规则:备战席压力 + 沉没进度保护;纯填充件优先 |
| 装备 | 不绑(过渡装备策略照旧) |
| 重估 | 每轮重排(件级估值随持有/板面滚动更新;无候选打分) |

**件级决策的输入轴(裁定 12 的替换计算四轴)与 §7 估值项的映射**:

| 决策 | 输入轴 | 对应估值项 |
|---|---|---|
| 买 | 再遇成本([22])/座位价值/边际羁绊贡献 | 核心件等待经济学 + 台阶推进 + 终局成员资格 |
| 上/换(部署) | 座位价值 + 点火结构 | 台阶推进(点火档)+ 部署排序不变量(§8) |
| 留(bench 囤) | 稀缺性([34])/再遇成本 | 骨架 + 终局成员资格 |
| 卖(压力) | 沉没进度 + 边际贡献归零 | 纯冗余判据([31]③ 停点) |
| 买(目标外同名副本) | **压库**([15]/[34]① 费用档判据;[30] 方向证伪后判据层保留)+ 插件凑星([34]② 稀缺性) | [34] 两用途与购买序——**独立于 RECIPE 族的三代在册行为,重构时保留** |

**空窗期接入([31]① 降级梯队)**:四体系均未凑成时,件级估值照常运行——此时任何羁绊件的边际贡献都>0,「手上有什么羁绊先上什么」是件级估值的自然输出(边际贡献判据自动实现降级梯队),不设独立模式;终局未成型期同理。

**成型前后规则不变**——变的是估值输入(计数到顶、经济变厚),主导分项从「跨门槛便宜件」**连续滑向**「终局核心」。**成型后的买入分类**(2026-09 裁定;下表为概念类,完整操作判定序见表后,与在册 [13]/[21]/[31]③/[34]/PLUGIN_LIBRARY 咬合):

| 类别 | 判据 | 纪律 |
|---|---|---|
| 目标阵容件 | **结构可达**终局阵容的成员/核心/骨架——「结构可达」= 与当前持有的体系/成员**重叠计数 ≥ 阈值常量**(纯计数判据,不消费成型 CDF;概率折算是证据门专用) | 照买照囤([13]/[21] 买而不上/[22] 先囤),bench 可囤 |

**成型后目标外牌的完整判定序**(与 [34]/PLUGIN_LIBRARY 合并;按序逐级判):

1. **目标阵容件**(结构可达成员/核心/骨架)→ 照买照囤(bench 可囤);
2. **场况插件**(羁绊下一阶段、边际贡献>0)→ 插件纪律:场上空位 ∧ bench 槽,买了即上;
3. **通用插件**(PLUGIN_LIBRARY 对症件,过四层过滤:机制不冲突/非过半线骨架/有位)→ 同插件纪律;
4. **压库件**([34]①:想压的费用档 ∧ 目标件已囤满 ∧ 备战席有空)→ 条件买;
5. **插件凑星件**([34]②:无可压费用档 ∧ 备战席有空 ∧ 板面同系凑星素材)→ 条件买([34] 序末位);
6. 其余 = **纯冗余停买**([13] 辖域,[31]③ 停点判据;口径:板面+备战席合并、按当前可部署机会含座位计算)。

类内按值/价;[31]②「目标件出现=唯一最高优先级无竞争」= 第 1 级对 2-5 级的类间排序在册表述。

「羁绊的下一阶段 = 场况插件」与通用插件(PLUGIN_LIBRARY)相对:前者由板面决定,后者放进任何阵容都生效;过渡阵容的羁绊推进层与终局阵容的 flex 插件层由此同构(final_comps 槽位构造:引擎/载体/插件)。**终局成员资格的范围与特判**:辖域 = 全 COMP_LIBRARY 候选的成员资格(证据门不预筛,§5);件级估值按结构可达集(判定序第 1 级)折算;**装备流 comp 特判**(反甲白厄类,`form_tiers` 空):成员资格照常按 core 名单判,成型里程碑以结构判据(「白厄+以牙还牙甲到位」)替代羁绊档位,缺口账单走指名槽。**bench 满交互(唯一行为 = 资源谓词,非路径枚举)**:插件可买 ⇔ **(场上空位 ≥1) ∧ (bench 槽 ≥1)**(买→上瞬态两资源都要;升级腾席单路只造场上空位不造 bench 槽,囤件上板单路只造 bench 槽——**手段可组合**,谓词判的是组合后的资源态);腾席手段 = [32] 全部路 + 囤件按 [21] 上场窗口已到则上(场况/通用插件算 [32] 的强单位)。谓词经组合仍为假 → **本回合放弃该插件**(明确的不买,不是死局)。囤件的上场窗口语义见 [21]——final 件买而不上,上场随成型档位推进。

## 9. 裁定清单(用户口述,最高权威;2026-09 阵容选择专题轮)

> **登记分工(防双编号误读)**:玩法行为类裁定的单一源 = `user_playstyle.md` 登记簿([35] 场况插件 / [36] 件级决策 / [37] 目标态分档 / [38] 权重语义 / [39] HP 不作决策依据——引用带文件名与编号);架构类裁定(槽位模型/登记制/承诺状态机/换线计费)以本节为单一源,不入 playstyle。本节编号与登记簿编号是两套系统,引用时带文件名。原 [13]/[23] 冲突均已消解(裁定 11/12),在册条目零推翻。

1. 四体系平权,无默认体系;六套过渡阵容等强(帖子统计=采用频率≠强度)。
2. 终局假设 P1 默认不立,除非环境(词缀/投资)给某线显著优势。
3. HP 永不作为决策输入(**唯一豁免=[40]② 血本位突变的被动安全带读血余额做支付能力检查**——账户读数非质量信号,user_playstyle [40]/redesign 01 §4.7);战力模型仅限 sim 结算层(ADR-0512)。
4. 候选规则全羁绊统一,希儿系无特例;跟着持有走,拒绝跟着发牌走。
5. 权重语义:默认全 1(两层同);环境分化(词缀+投资策略,机制知识);手动通道预留;频率永不入权。
6. 槽位模型:两层都是固定位+摇摆位混合(终局 core+flex,过渡阵容体系槽+升星指名)。
7. 不定义 6 张独立配方卡为派生物,**裁定登记为版本作用域知识**(P1_RECIPES + 一致性测试 + 版本纪律);实战强度发现通道开放(证据=实机战斗真值/口述,非频率)。
8. 预设升级顺序错误——加法原则对,顺序是状态的输出不是输入。
9. 承诺 = 状态机转移(四规则换捆),不是数值;成型 = 终点线(无尾巴),承诺 = 中间态(昂贵尾巴的拨款起点)。
10. 换线计费的本体 = 资本方向绑定 + 成型时钟重置,不是卖牌。
11. 场况插件归类与成型后买入三分法(2026-09):羁绊的下一阶段 = 按场上情况的特殊插件(与通用插件相对);三分法 = 目标阵容件(照买照囤)/ 场况插件(有位才买、买了即上、边际贡献、稀缺性序)/ 边际零冗余(停买)。[13] 辖域由此精确化,在册条目零推翻。
12. 未定型期决策单位 = 件(2026-09):终局承诺前一切买入按插件对待(各有替换计算:座位价值/稀缺性/再遇成本/边际贡献),**没有线路选择对象**——阵容是涌现描述;线级选择全局仅一次(终局证据门)。[23] 完整保留零冲突(「四线摇摆」死法=旧机器把线当 pivot 对象,件级经济学不产生拆装);R1 阻断①至此全部关闭。
13. 完成目标态分档(2026-09):证据门与缺口账单按**下一结构里程碑**算(羁绊档套 = `form_tiers` 达标;装备流套 = 核心+关键装备到位——均自注册表派生),不按全终局;**P2 中间形态不定义**(攻略 Middle 数据 = 校验材料;门行为异常的套按需单独补);禁止任何预编时间表形态的载体。
14. 预编节奏全面退役(2026-09):level_plan 节奏表、typical_form_round 手估常数、成型轮窗——全部退役;升级/刷新/稳金决策由期望数学实时计算(等级-出现率表等机制事实保留为输入)。同族清扫含 RECIPE 序列与配方围栏。
