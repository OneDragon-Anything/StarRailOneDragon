## 1. 结构裁决:采纳极简架构(正面回应 W617)

### 1.1 裁决与理由

**裁决判据**:效果上限相同取更简 + 治本深度(哪个真正删除 30+ 补丁的发生机制)。两判据都指向 W617:

1. **效果上限相同**(W617 §2 六出口逐个论证,本审复核通过):六出口的上限全部由「cw_intention 方向质量 + 义务模型 + 排程/EV + 评分语义 + 观察辖域」决定——这五样两案逐字相同;四层管线的「层间结构」与「独立契约传输权」不出现在任何出口的上限决定机制里。前版自己在优化层已做极简裁决(§3 弃 DP 选规则组合,判词「多一层模型误差不因结构精致而消失」)——同一判词适用于架构层,前版没有推广到底,定稿推广到底。
2. **治本深度**(W617 §6 论证成立):现状 30+ 补丁的**发生机制 = 可变共享态 + 边界穿透**——W51 跨局污染、r73 状态机写序脆弱、L374 死分支的共同前置条件是可变共享态;update_target 越权换线、arbiter 硬地板越权全部发生在**既有模块边界之内**(arbiter 越权正是发生在四层结构存在的今天——层边界从未挡住越权)。前版的回答是「更多更细的边界 + 判例表纪律」;极简版把可穿透面压到极限:纯函数 `decide()`、输入输出不可变、无 session 写端、无运行时开关——**删除发生条件,而非管理发生条件**。
3. **迁移风险单调更低**:中间态减半(方向/预算投影在同一装配点一次算完,不存在「先接方向再接预算」的半接线窗口);无新契约 = 无「契约 v2 不兼容」事故面;验证强度不减(行为锁先红后绿 + 冻结基线 A/B 不劣,逐步不变)。

**采纳范围**:TurnState(含 Snapshot 嵌入 + 方向/预算投影)、prep_brain 单模块(四层管线折叠为 `_select()` 内私有函数,语义零损失——测试按行为锁不按层数)、registry 缩为标定常量表、EffectSpec 降为数据平表、迁移三大步。
**不采纳的部分(即保留的边界)**:执行环 DirectorV2+adapter+contracts 原样保留(W617 同判,零新写);观察纪律(W609 辖域表)落 adapter;cw_intention/economy_cycle/posture_release/line_switch 既有件原样复用。**折中方案(保留层骨架 + 契约折叠)被否**:契约折叠后「层」只剩组织命名(W617 §5 判词)——命名不承载验证责任也不承载治本,留下只增加评审话语成本。

### 1.3 数据流

每节点入口 → adapter 按 W609 辖域表产 Snapshot → `assemble()` 同一调用点派生方向/预算投影成 TurnState → `decide()` 产 Decision → DirectorV2 执行并对账。**全程无第二个可变共享态容器**;「越权」无藏身处——跨分区调用在单文件内可见,状态残留因 frozen 不可能存在。

### 1.4 前版层骨架主张的检验记录(为何不保留)

层骨架的正当性候选逐个检验:①「层间独立替换」——从未兑现价值(arbiter 越权发生在四层存在的今天);②「每层可独立测试」——行为锁按行为不按层锁(测试纪律),折叠后私有函数单测照写;③「跨消费者扩展位」——方向/预算投影的消费方全集 = 决策器 + 遥测,遥测由 Decision 附带投影清账(池行 260),无第二消费方,出现时拆出成本 = 改装配点一处(YAGNI);④「评审分工锚点」——真实损失,由 §1.1 判据 2 的治本收益覆盖。结论:保留层骨架 = 保留命名,否。

## 2. TurnState:唯一的「件」

```python
@dataclass(frozen=True)
class TurnState:
    snap: Snapshot            # 已落库 contracts(含 confident 门/schema_version),原样嵌入
    direction: DirectionView  # 方向投影:intent 投影 / hoard 集 / gates 快照 / fallback_comp
                              #   / committed(P1 攒息语义显式化,§4.3-R1)
    budget: BudgetView        # 预算投影:interest_floor / reserve_cap / obligation / schedule / ev_auth
```

纪律(逐字保留前版方向/预算契约的全部条款):幂等重算、单一写端(assemble 装配点)、**派生值一律不落 session**(根治 W51 跨局污染)。投影字段 = 前版契约字段 100% 照搬;丢的只是「独立跨层传输权」(无第二消费方)。

**唯一保留的 session 状态族(R2 裁决)**:`tracked_bench_chars`/`tracked_deployed` 等 **bot 执行记录计数器族**显式归入 session 保留清单——它们不是派生值,是 r114(局32 横跳)用实机败局换来的「识别噪声 → 方向滞回」锚(识别时好时坏时 tracking 优先、fresh read 只补缺)。TurnState 装配时 bench/deployed 读口 **tracking 优先**(语义同老栈 L152-168);识别就绪后再评估弃用的裁决走独立 ADR,不在本战役内。

## 3. 优化层从零设计(W616/W617 双向背书,原样保留)

> 用户 directive 原话:「DP 是很开始的产物,这次重构的目的不是用少量工作提升效果,是要彻底的重新设计,一切以效果为目标,工期再长都没问题。DP 保留与否,是看最终最好的方案是否需要。」前版「DP=咨询输出」的三支论证(唯一全局优化器/删=重建调度器/round_posture 单一源)为资产保存式理由,全部作废。

### 3.1 需求先行

| 需求 | 内容 | 本质 |
|---|---|---|
| N1 经济节奏 | 何时升级 | **确定性费用表排程**——升级费 = XP 表 × 现读单价(确定),收益 = cap+1(确定);查表+阈值,非随机优化 |
| N2 时机窗口 | 刷新几枪/买哪件 | **单步期望计算**——refresh_prob 表已知,边际收益递减,跌破金机会成本即停;闭式,无跨期递推 |
| N3 资源转化 | 溢余转战力、储备留多少 | 义务模型已证弱占优参数无关(ADR-0445);R* = 息线 + 窗口排程升级费 = 查表 |
| N4 存活预算 | 血轨迹下的激进度 | 阈值规则(ADR-0448/0451 血预算判据)+ 两态胜率表(ADR-0440)——维度 (板强档, 节点),非 5 维联合状态 |
| N5 长程耦合 | 板强→连胜金→经济正反馈 | 唯一受益于前瞻的需求;单步规则近似(板强达标→转激进),精度损失由说服包专项出口量化 |

### 3.2 候选对比(按效果上限选,工期不计)

| 候选 | 效果上限 | 复杂度 | 失效模式 |
|---|---|---|---|
| **A. 纯规则+阈值调度**(义务模型为核) | 高:N1-N4 全覆盖,义务核心已数学证明;N5 规则近似 | 低(复用已落/在飞件) | N5 二阶效应盲区——sim A/B 可测可归因 |
| B. 确定性费用表排程 | 对 N1 精确 | 最低 | A 的组件,非独立候选 |
| C. 单步期望值计算器 | 对 N2 精确 | 低 | 短视,由 A 排程补;A 的组件 |
| D. 保留 horizon、重写价值函数 | 名义最高 | 最高 | **重蹈覆辙**:旧 DP 三败因(GOLD_MAX=110 截断/P1 损血手调先验/姿态兜底)全是世界模型与实机错位;重写不消灭标定误差,5 维 3M 每格都是错位点;上限被与 A/B/C 共用的标定数据封顶,却多叠一层模型误差 |

### 3.3 裁决

优化层 = A(义务模型为核)+ B(排程查表)+ C(单步 EV)规则组合;N5 规则近似 + 说服包专项出口(连胜耦合场景局:板强达标局金轨迹/连胜档命中率)。**D 不采,预注册复活条件**:仅当 ①N5 场景显著劣于冻结基线 且 ②缺口归因于缺跨期前瞻而非标定噪声(同标定喂单步 EV 版不劣)才立项重写,旧 DP 代码不复活。**DP 处置**:cw_horizon 退出生产路径,转 prior art;三教训入册:①截断区不可无兜底落决策;②先验手调值进值函数 = 猜测乘以 3M 状态格;③模型输出必须有失效行为出口,否则兜底即隐性权威。

### 3.4 W611 涟漪 + R4 单一址/共表裁决

- `economy_cycle._upgrade_scheduled` 与 `refresh_budget × 刷价` 分量 = **可替换接缝**:落地为 `schedule_upgrade(state)->bool` + `refresh_ev_budget(state)->int` 两个纯函数,消费方接口形状不变。
- 义务核心(优先序 O1-O4/退出链/R*/容量刀法)无冲突,保留不动。
- **R4(采纳)**:①血预算判据单一址——判据函数族单一源化(ADR-0448/0451 现件),`_budget()` 与 `_select()` 守卫共调同一函数,禁两处独立实现;②EV 价值表单一源——刷新边际 EV 与评分 EV 门共用同一张目标件价值表(= EffectSpec 平表,§4.2),禁两处独立标定。

### 4.3 三个语义边界裁决(W616 打穿点)

- **R1 dual_track_phase(P1 攒息语义)**:写入端全集随 update_target 退役消失,10 文件 40 消费点不能靠 getattr 缺省静默得 False(→恒已定型→激进化)。裁决:语义升格为 **DirectionView.committed 显式字段**(装配点单一写端,幂等派生);折叠进 `_select()` 的消费点(cw_plan 买牌放行面/升级姿态压路径)改收**显式函数参数**(折叠时改签名,不读 session);折叠期外的执行体消费点(deploy_bench/equip_all/prep_director)由 adapter 装配时显式传入。禁 getattr 缺省兜底——grep 守卫锁「session.dual_track_phase 读点归零」。
- **R2**:见 §2/§4.2 首行。
- **R3 配方锁断供出口(三选一裁决 = 选 (a))**:给 `p1_pair` 补断供驱逐出口——冻结驱逐语义从 LineTrack 推广到配方对(某体系补不进的新件连续断供 ≥ 阈值轮 → 该体系移出 pair 候选、pair 重派生,同 [修A1] 既有先例);否决 (b)(「永不清靠 P2 退场」放任局18/局20 板面残骸病灶)与 (c)(空窗四体系全集兜底不成立——`locked_buy_scope` 在 p1_pair 非空时确实收窄买面,挡不住断供)。配套变异探针进说服包(§7.3)。驱逐阈值先取保守值 ≥5 轮(同老栈 DROUGHT_BAIL 先验),探针批标定。
- **drought_excluded 语义差(半穿,如实记档)**:老栈供给侧死线名单(断供≥8 入名单防弃后重选)在 P2 后无对应物——影响面小于 R3,处置 = evicted 驱逐语义扩展时一并辖 P2 线(挂本批,不单独立项)。
