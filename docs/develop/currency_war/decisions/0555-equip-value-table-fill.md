# ADR-0555: 装备价值表补值——策略层 key_equips 全量缺值清偿(批㉜ F4 收口)

- 状态:已实施(待落地审)
- 关联:ADR-0130(价值表首建)、ADR-0298(死名清退,键 ⊆ 注册表单一源)、ADR-0294/供给重校准批(供给采样通道与价值表解耦)、批㉜ F4(sim64/66 装备覆盖 0.16 + 价值表缺值)、判读件 `.debug/temp/currency_war/equip_value_gap/REPORT.md`、18/21 号稿(穿戴/工具域,本批零触碰)

## 1. 背景与问题

`_EQUIP_VALUE`(cw_events.py,V4.4 先验)仅 10 键,而 21 套 COMP_LIBRARY 的
key_equips 并集中有策略层自声明的关键装备缺值。缺值的直接行为后果 =
**未锁线局定价失明**:免费拾取仍会拿,但 decide_supply 第 3 分支与
decide_planner 装备档的通用价值打分对缺值件恒 0,key 件必输给任何有值件,
三席全缺值时选装退化为盲选。

检查项 `check_equip_value_strategy_key_coverage` 原判据只披露「引用 ≥3 名」
——实测只看见 2 名(光速螺旋桨 5 comps / 动能激发剑 3 comps);判读件
盘点出盲区 13 名(引用 1-2 次,同样恒 0 分)。**真实缺口不是 2 名。**

## 2. 决策

独立纯数据层小批(不并入 241 供给仲裁行为设计件——数据层先验缺口与
行为层授权缺位根因层不同,并列不嵌套):

1. **件 1(F4 两名)**:光速螺旋桨=5、动能激发剑=4,数学先行对位锚补值;
2. **件 2(盲区收口 + 检查扩全量)**:其余盲区逐名补值;检查项判据去除
   ≥3 阈值,扩为 key_equips 并集 ∩ 注册表 **全量**披露;清偿判据 = 检查归 0;
3. 变体辖域:白昼/特权变体与同名基础件**同值**(见 §4)。

## 4. 变体辖域(白昼/特权)

变体 = 基础件效果的数值强化(注册表 effect 直读为证),消费场景
(羁绊队/特权装备)只强化不改定位;无实测量化依据,**禁拍差异化值**,
统一同值对位底版。

## 5. 检查披露扩全量的直接收益:第 16 名现身

判据去掉 ≥3 阈值后,检查项立即披露 `以牙还牙甲·特权`(反甲流 comp
key_equips 成员,引用 1 次)——判读件 15 名清单漏计。全量披露不是
形式扩面,是清偿完整性的硬前提。

## 6. Considered Options

- **A(采纳)独立纯数据层小批**:零策略语义,decide_supply/planner
  结构零触碰;与 241 并列不嵌套;可先行。
- B 并入 241 供给仲裁设计件:拒绝——把数据治理小件背上行为设计件的
  排位(241 靠后),缺值清偿被无谓延迟;反之 241 落地也治不了 0 分失明。
- C 显式裁决缺值件通用价值 0(ADR-0298 同款语义):拒绝——缺值件多为
  系核心/体系件,0 与策略层自声明矛盾。
- D 检查项保留 ≥3 阈值只补 2 名:拒绝——盲区 13+1 名同样恒 0 分,
  清偿判定本身不完整(实证:第 16 名由此现身)。

## 7. 已知耦合披露(sim 侧,本批禁改面之外)

sim 追加件通道(engine_p1.py `_adv_names` = `_EQUIP_VALUE` ∩ 注册表 −
基础件)的进阶均匀池**派生自本表**——补值后该通道采样集从 8 名扩到
24 名(派生式直跑复核:表内属基础件仅轮滑鞋/光能电池 2 名,旧
10 键→8、补值后 26 键→24;含白昼/特权件,现实分配上羁绊/特权件
不经供给通道)。判读件
「表与采样池已解耦」仅对供给节点通道成立,追加件通道仍耦合。快照池
重放与池指纹不受影响(指纹只含 `+eqg<EQUIP_GRANT_CALIB_VERSION>` 位,
本批不动该常量),但**裸跑批的追加件分布已变,跨批对照须声明本批**。
治本(采样池与价值表解耦 / 变体件出池)属 sim 基建批,本批禁改面
(engine_p1/Δ池)之外,挂账待派。

## 8. 锁面(新增 test_cw_equip_value_table.py)

覆盖锁(key_equips ∩ 注册表全量入表)、死名守卫(表键 ⊆ 注册表)、
对位锚注册表直调锁、F4 锚值锁(5/4)、变体同档锁、清偿归 0 锁、
披露全量锁(单引用键摘除即披露)。smoke 豁免表移出
`equip_value_strategy_key_coverage`,回归 0 容忍。
