# 差分宇宙(div_uni · 千面英雄)

2.3 版本常驻 Roguelike,模拟宇宙迭代版。**方程**(公式)+ 祝福 + 奇物构建,推进位面击败首领。**bot 未覆盖 Roguelike 演算**(`application/div_uni/` 仅实现饰品提取),故本 screen 的 Roguelike 画面**无 screen_info area**;本 doc 基于 `sr-od-test` 测试图离线建档(2026-08-01)。玩法机制见 [gameplay/div_uni](../gameplay/div_uni.md),饰品提取见 [ornamenet_extraction](ornamenet_extraction.md)。`pc_alt=true`(3D 探索)。

## 何时出现 + 状态流转

**入口**(千面英雄主界面:拟合等级 / 稳态数组)→ 「开始游戏」→ 大世界探索(`(N/13)第N位面-区域-XX`)→ 地块(战斗 / 事件 / 奖励)→ 选祝福 / 选奇物 / 选方程 → 获得方程(剧情演绎)→ 继续探索 → 通关结算。

## 可交互元素(OCR,无 area)

- **入口**:拟合等级 / 稳态数组 / 可能性画廊 / 泰坦颂诗 / 灵感回路 / 概率艺术馆 / 运行记录 / 黑塔的商店 / 开始游戏。
