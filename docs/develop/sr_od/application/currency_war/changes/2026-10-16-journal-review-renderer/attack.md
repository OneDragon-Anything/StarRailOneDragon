## A. 开工阻塞（7，核一）

| # | 发现 | 处置 |
|---|---|---|
| 1 | 动作锚未排 `same_value=true` 的 receipts 行，实测 183/524 条 no-op 重写会渲染成幻影动作节（约 35%） | 已修订：锚定义加 `same_value≠true` 过滤 + 单测用例 |
| 2 | 弹层归章证据①②被证伪：回执 screen 恒为底层画面（备战/商店）、sig.screen 对弹层 actor 恒空——唯一可用判据是 actor 映射 | 已修订：画面切分重写——快照章按 current_screen 变化切，弹层行只认 actor 映射；screen/sig.screen 降为章内动作锚定注记 |
| 3 | `--match` 回退 live journal 行域未定义（live 实测 29 run 混合，无窗可用） | 已修订：删除回退——`--match` 只读档案（缺报错 2）；未装配局用 `--journal` 显式指路径 |
| 4 | 档案 end_ts 元数据损坏（实测 end==start，多数行越窗），时间窗兜底判据前提为假 | 已修订：窗改取切片行首末行 ts（不用档案元数据）；`--run` 未知值报错（与旧 None=全渲染的语义变更已申报） |
| 5 | node.kind 组内翻转（备战→战斗窗过渡）无选值规则 | 已修订：标题取组内首行 kind + 单测 |
| 6 | 无 node 行（实测 263 行/3%）三套归属规则打架，虚拟组形态未定义 | 已修订：归属优先级链——首节点组前→开局段；其后有画面证据→「未归节」虚拟组（照常切分）；无画面证据→annex；三类单测 |
| 7 | sim 形态三方不匹配：零 current_screen、sig.screen id 未注册、动作词 7 种长名不在表 | 已修订：动作词表并参数型别名；未注册 screen id 兜底（原样开章/键集空/非决策面）；landing sim 验收判据按实际形状改写 |
