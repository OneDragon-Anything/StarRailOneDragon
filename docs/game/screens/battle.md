# 战斗画面(battle)

回合制战斗。battle screen_info 只建了**结果态 area**(挑战成功/战斗失败/退出关卡/再来一次),战斗过程态(回合制技能选择 / 行动条 / 自动战斗)未建 area。`pc_alt=false`。各玩法(花萼/历战/饰品/模拟宇宙/忘却之庭)战斗都进此画面。

## 何时出现 + 状态流转

- **入口**:大世界遇敌 / 秘技攻击 / 各玩法挑战(花萼/历战/饰品/忘却之庭/模拟宇宙)→ 战斗画面(过程态)。
- **过程态**(回合制):角色/敌方行动条 → 技能选择(战技/终结技/普攻)→ 释放 → 下一回合。可自动战斗。
- **出口**(结果态):
  - 胜利 → 「挑战成功」结算页(本 screen)→ 领奖励 / 「再来一次」/ 「退出关卡」/ 「重新编队」。
  - 失败 → ⚠️ **拟造花萼实测:跳转「大世界-战斗失败」screen(非本 screen,见下「战斗失败归属」)**。

## 识别特征(稳定锚点)

- **挑战成功**(battle.yml,text "挑战成功",pc_rect 734,138-1190,400,lcs 0.7):胜利结算页标题。**2026-07-30 实测**:拟造花萼(金)挑战成功页"挑战成功"文字(831,244)命中此 area,conf 0.9997 ✅。
- **战斗失败**(battle.yml,text "战斗失败",同 rect 734,138-1190,400):⚠️ **拟造花萼战败页不进本 screen**(在「大世界-战斗失败」),此 area 是否被使用待查(疑似死代码)。
- **退出关卡按钮**(text "退出关卡",544,923-880,975)、**再来一次按钮**(text "再来一次",1180,930-1400,1000)。
- **重新编队**(结算页 OCR "重新编队",~1510,957;非 battle.yml area)。
- **过程态**:`battle_screen_state` 检测(无 area,靠画面特征)。
- `pc_alt=false`。

## ⚠️ 战斗失败归属(2026-07-30 实测发现,待其他副本验证)

- **拟造花萼(金)战败**结算页精准命中 screen **「大世界-战斗失败」**(`normal_world_battle_fail.yml`,id_mark "标题-战斗失败" pc_rect 774,206-1152,318 + "点击空白区域继续"),**不是「战斗画面」**。
- 即副本战败 → 跳「大世界-战斗失败」screen(battle.yml 的"战斗失败" area 未被用到)。
- **`is_battle_fail` 代码 bug**:查「战斗画面」screen 的 `战斗失败-有奖励/双倍奖励/无奖励` area(不存在 + 错 screen)→ 恒返 False(`test_is_battle_fail` 失败根因)。
- **已验证(2026-07-30)**:拟造花萼(金)+ 凝滞虚影(溟簇之形)2 种不同副本战败页**都精准命中「大世界-战斗失败」** screen(is_precise,area "标题-战斗失败" conf 0.96~0.99)。→ 副本战败统一进该 screen。饰品提取/历战余响/忘却之庭/模拟宇宙待验证(机制不同,大概率同,但建议补验)。
- **`is_battle_fail` 正确修法**:改查「大世界-战斗失败」screen 的「标题-战斗失败」area(或用 is_target_screen 判定该 screen)。

## bot 流程(各玩法战斗)

- **战斗触发**:各玩法 challenge op(如 `challenge_echo_of_war` / `ChallengeOrnamentExtraction` / `sim_uni_fight_elite`)。
- **等战斗结束**:bot 检测结果态 —— 成功靠 battle.yml"挑战成功" area;**失败检测 `is_battle_fail` 当前有 bug(查错 screen,见上)**。
- **结果处理**:成功 → 领奖励 / 再来一次;失败 → 退出 / 重试。
- `get_tp_battle_screen_state` 也查"战斗画面"战败 area,同样存疑(待验证战败 screen 归属)。

## 备注 / 待查

- **战斗失败 screen 归属(2026-07-30 实测)**:拟造花萼(金)+ 凝滞虚影 战败 → 「大世界-战斗失败」screen(已验证 2 种副本,均 is_precise)。`is_battle_fail` / `get_tp_battle_screen_state` 查「战斗画面」战败 area 失效。**修法**:改查「大世界-战斗失败」(is_target_screen 或 "标题-战斗失败" area)。**调用方**:`world_patrol_screen_state` / `sim_uni_screen_state`(is_battle_fail)—— 大世界遇敌 / 模拟宇宙战败页是否同样进「大世界-战斗失败」待验证(机制不同,可能差异)。
