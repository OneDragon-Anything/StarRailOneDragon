# 货币战争-备战-开商店

## 画面简介

备战画面的商店展开形态：点「按钮-商店开关」展开；战斗结算后自动弹商店是常态（实测）——多数节点回备战直接就是本形态，开店经常是游戏自动的。**自动开店 = 开拓商店横幅的同位陷阱源（2026-11-23 第二十四局 ×3 误购：娜塔莎/长夜月/大黑塔 + 第二十五局第 4 例：波提欧 1金）**：本形态下备战左侧开拓商店横幅「打开商店」文本锚（实测 (550,284)）与「商店牌-1」区域重叠——想点横幅开开拓商店，实际买下了槽 1 的牌；**点横幅前先收店**（extras `shop_cards` 在场 / 画面命中本屏 = 金币店开着），误购可对账卖出回血。analyze 命中本画面时 extras 返回 shop_cards（五槽：名称/阵营/费用/星级）/gold/levelup_cost/refresh_probs。本画面是花金币的地方（买牌/买经验/刷新）；想拖角色上场或出战，先收店——收店（「按钮-收起」）是本画面的收尾动作。

## 识别后要做的决策

花金币的三件事（买牌/买经验/刷新）怎么分配：

- 买牌：星级越高费用 ×3/×9；金币 ≥20 时留钱吃利息（结算按存款给利息）。备战席满时买牌 op 静默失败（实测 2 次）：无报错、金币未扣、牌不入席——买牌前自查 extras.bench 有 empty 槽才买。
- extras.shop_cards 出现 kind=unknown 且 faction='?' = 主角昵称卡（玩家昵称拉丁字母不在中文模板集，实测）——可买，是 3 费主角单位，计入同名合成计数。
- 合成规则（实测收敛，9 组采样定条件）：同名且**同星级**的副本按「场上+席内」全局计数（商店牌内的同名也计入全局计数——场上 1+席内 1 时买第 3 张同名，买入即合成、落点场上份升星（实测）），凑满 **3 张同星级**即合成；落点跟随参与件的场/席分布——三份中有场上份 → **场上升星**（实测：场上 1★ 参与三合一时，2★ 合成品落**场上**），全在席内 → **席内升星，落席内编号最小的占用槽**（全 bench 合成同理，落 bench）。混合星级不合成（2★+1★+1★=3 份无效，双向实测，2026-11-20 局再证）；2 份永不合成；试用标不阻止合成。**场上吸收三例再证 + 装备随单位走（2026-11-23 第二十四局）**：忘归人 / 大黑塔 / 三月七 各 3×1★ 合 2★，自动替换场上同名 1★，忘归人 2★ 上场带着碎星斩舰刀——合成后不用再穿装。**合成判定时刻定谳（2026-11-23 第二十五局，V4.7 修正）**：合成 = **第 3 张同星入队瞬间**自动判定并自动上场（发放时刻判制定谳，机制面见 research/merge_mechanics.md §1）——**席满时第 3 张同星入队 = 合成机会静默丢失**（真珠三连：满席购入未合成，卖卡腾位后也不回补），**「席内拖拽合并」手势 V4.7 失效**（席内拖拽只移卡不合并）；操作纪律 = **买第 3 张同星前必须留 ≥1 备战席空位**。
- 银轨商店购买路径同样过合成检查（2026-11-20 局三例）：经开拓商店买入的同名卡计入全局计数，凑满 3 份即自动合成、升星落**场上份**（三例均场上升星）——「场上升星」口径三例再证，银轨商店与金币商店两条购买路径同规。
- 掉落路径同样过合成检查（2026-11-19 实机）：晶矿开箱掉落的角色也计入同名同星级全局计数，凑满 3 份即自动合成——实测：局内已有 1★ 同名一份 + 拾矿掉落同名 2 份 → 掉落完成即自动合成 2★ 入席，无需任何手动操作。
- 早期「场上不参与/混合也合成」的矛盾观察条件未还原——遇同名未合成时先读图核对三份的**星级是否一致**。
- 买经验：等级 = 部署上限，前期优先；三月兔（奇遇伙伴之一，随开局简报公布）在场时第二位面买经验额外 +1。
- 刷新：各费用卡出现率参考「货币战争-商店刷新概率表」（见同目录卡）。

吞点击纪律（多局实测，跨动作类型）：

- 买牌吞点击间歇模式（多局实测）：同一备战期内仅首次买牌点击生效，后续买牌点击被游戏吞（1-1 教学期例外，无此现象）；收店重开、微距拖拽都解不开；呈间歇性（同一局前期正常、后期复现）——连买多张时每张买入后重读 extras 对账（gold 扣没扣 / bench 入没入），发现未生效别硬重试，先读图确认状态再等恢复。恢复边界 = 自然恢复、不按下个备战期承诺（复现样本：连续两个备战期均吞买牌——金币不扣、牌不消失，此后自然恢复）。
- 吞点击间歇模式（跨动作类型，2026-11-19 单局 6+ 次复现扩充）：既有「买牌吞点击」条扩展为跨动作模式——同局内出战×2 / 买牌×3 / 买经验×1 均复现（点击发出、画面原样、金币不扣动作不生效），间歇出现、原样重发或等恢复后自愈；处置不变：每次点击后对账（读数变了才算生效），未生效别硬连点，先重发一次再不行就等下个动作窗口。
- 三位数金时买经验吞点击异常（2026-11-20 第二局）：gold 三位数（103）时买经验按钮 2 连吞（点击发出画面原样、金币不扣），同局低位数金未见此象——疑 UI 遮挡或金额显示溢出触位（三位数把按钮区挤变形一类），待排查；与既有跨动作吞点击间歇模式区分（本异常与金额位数相关）。遇到时先读图确认按钮形态与金额显示，再重试；连吞两次就等下个窗口，别硬连点。
- 投资策略三选一卡吞点击（2026-11-23 第二十四局）：三选一卡前两次点击未选中、第 3 次点击才选中——跨动作模式再添「投资策略选卡」一类（选卡交互本身见「货币战争-投资策略」卡：点六边形图标区才选中；排除点位因素后仍属间歇吞点击，报告口径）；处置同上，对账重试有效（每次点击后看白框亮没亮，未亮重发一次）。
- 开商店态拖拽静默失败（2026-11-23 第二十五局，吞点击间歇扩展到拖拽域）：开商店态下拖拽部署/合并**静默失败**（拖拽发出、画面原样、动作不生效）——大黑塔双对照实证：开商店态拖拽败、收店后同坐标拖拽成；间歇面扩到拖拽域（刻律德菈#2 六连败 / 三月七 2★ / 真珠合并多例，多因素叠加，报告口径）。**纪律候选（候转正）= 部署/合并等拖拽类操作前必须收商店**（与出战前置收店同族）+ 失败即换目标不硬重试（对账处置同吞点击）。

出战前置与读数口径：

- extras.bench_overflow：「备战席已满」告警横幅在场(True) = 有单位没安置，出战会被游戏忽略——先 `CwSellBenchBySlot` 卖一个腾位再出战。横幅商店态也可见。
- 席满态出战静默忽略（修复前历史行为，2026-11-20 实机，帧 175432 系列）：备战席满时发起出战被游戏静默忽略——无战斗、无结算、金币不变；**现役出战链已带席满自动腾位守卫**（席满态出战先自动卖角色腾位再出战，2026-11-20 落地）——手动先卖腾位由必需降级为可选。
- 开商店态 front_line/deploy_count 为 null（完整读数收店后再取）；商店态 board 子集可能失真（实测偏差 -1：读 击破1/守护1，真值 2/2）——羁绊计数勿用商店态 board，以 units 全局计数为准。
- 晶矿识别在此画面不可用（reward_ores 键省略）——**键省略 ≠ 晶矿消失（2026-11-23 第二十四局）**：商店开启态把 reward_ores 整键省略曾被误读为「晶矿没了」，收店后原样在场（本局 5 颗〔灰 1 蓝 4〕持久在场至局终）。「选择主角」屏态屏蔽晶矿（2026-11-19 实测）：备战处于主角光环选择环节态（右下按钮 = 「选择主角」）时，画面判定仍可能命中「货币战争-备战」（备战锚照常命中）——此态点击晶矿零生效（两次拾矿原样、矿不掉）；先完成主角选择解锁备战再拾矿。
- 战斗结算后自动弹商店是常态（实测）——先 analyze 确认再决定开/收，不要盲目再点开商店。
