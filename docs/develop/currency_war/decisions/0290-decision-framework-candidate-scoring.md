# 0290 - 决策框架治本:候选生成 × 期望评分 × 预算仲裁(取代通道堆叠)

- **Status**: accepted(2026-08-23;对抗审查修订后采纳——报告 audit/adversarial-framework-0290.md,四修订点已并入本文)。
  **迁移机制部分 superseded(2026-08-25,ADR-0310 载体批)**:Decision 里的「渐进迁移:
  ④并行开关+锁迁移(以决策面比例度量)⑤删通道」安排被 ADR-0310 的 registry 双注册
  A/B 窗口+纪律族移植取代(decision_v2 成为唯一策略载体,不再继承 LineStrategy);
  **四层框架本体(层1 候选×层2 过滤×层3 评分×层4 仲裁+完备性审计表)不变,继续有效**。
- **Context**:line_strategy 1868 行 23 方法,decide_prep 分发五通道(emergency/boss_breaker/catchup/economy/war),
  通道内各自 if-else 谓词。29 批压测的症状族全数指向该架构:振荡族(买卖两通道无全局视野)/腾席链烧金
  (升级藏在腾席通道)/carry 躺 bench(买与部署谓词不一致)/死门族(通道可达性靠路由 if 无人全局审计)/
  [31] 需要 else 补丁(谓词制非评分制)。**redesign.md §3 的设计原意(战力表×线库×规则集)从未被
  完整实现——现行代码是它的退化形态**(通道=粗糙的模式仲裁,规则散进通道)。
- **Considered Options**:
  1. **继续通道制点修**——拒绝:29 批实证症状累积,每修一个症状生 1-2 个新互踩面(腾位门→保护集
     窒息;腾席链→boss 轮烧金);框架级症状纪律(≥3 次上升)已触发 3 族。
  2. **纯评分制全重写(单一 decide 循环)**——部分采纳,但拒绝「一步到位全重写」:评分函数的期望值
     本身依赖尚未校准的 sim(奖励胖尾/deploy 时序/EV 单击价族),全重写会把未校准的假设烧进架构;
     且 1700+ 锁测试锁的是通道行为,全重写=全量锁作废,回归风险不可控。
  3. **候选生成 × 期望评分 × 预算仲裁(三层,渐进迁移)**——**采纳**:
     - **层1 候选生成(枚举)**:每个决策点生成全部合法候选动作——买(店内每张卡×语义标签:
       line_carry/line_opportunistic/bridge_core/bond_fallback[31]/carry_gate 腾位)、卖(bench 每件
       ×理由:off_target/for_gold/腾位让位)、LevelUp、Refresh、部署(board∪bench→槽位组合的 top-K)、
       合成(3合1)。候选生成器是**纯函数**(state→candidates),无通道概念。
       **剪枝显式化(对抗修订③)**:预排序与 top-K 本身是决策——K 值/排序键/标签间优先与互斥
       关系全部进注册表(显式可审可 A/B),禁止隐式排序;候选标签仅作**过滤/互斥域标记**,
       不携带优先级语义(通道制的残影清理)。
     - **层2 期望评分(排序依据;对抗修订①)**:评分对象 = **候选后板面**(apply 候选到 state 副本,
       查「板面形态→期望」表),**禁止单卡边际拆分**——档位价值在组成卡间分摊是未证假设(P3 证的
       是 e0→e1 档位边际,非单卡;e2 格 n=9/±30%);查表项 = 成型档位×P3 + 息律/追级 EV + 战力
       (H3 板面查询)。**应急/追赶 = 硬过滤器(对抗修订②,非评分项)**:应急态先过滤候选集再评分
       (可被经济项投票淹死 = 29 批「局部合法组合失明」病的镜像);redesign §3 的覆盖态严格优先序
       语义保留在过滤器层,同步修订 redesign(应急>追赶>模式 三级过滤器链)。
     - **层3 预算仲裁(执行)**:按分排序依次执行,全局约束(金≥地板/bench 容量/同轮互斥 r408 族/
       boss 轮禁令 [32])作为**过滤器**在执行时统一施加——约束一处定义,全部候选受辖(通道制下
       约束散在各通道是漏门根源)。**完备性机制(对抗修订④)**:约束清单建「资源维(金/bench/
       槽位/同轮)×回合态维(boss/应急/窗口)」审计表,与检查网联动——每条检查项映射到至少一个
       约束或披露为「无约束覆盖」;新增动作类型时审计表强制过检(通道制漏门病 r408/[32] 全是
       事后补,新架构必须内生完备性审计)。
     - **渐进迁移**:新框架与旧通道并行(策略开关),旧锁逐批迁移为新框架的候选-评分断言;
       迁移完成度以「锁覆盖的决策面比例」度量,全部迁移后删通道。
  4. **保持现状+约束网兜底**——拒绝:检查网(94 条清偿中)能拦已知症状,拦不住通道组合爆炸的新面。
- **Decision**:采纳方案 3(对抗修订后)。实施序:①候选生成器+查表评分骨架(纯函数+可注入注册表,
  **先行**——不依赖校准)→②仲裁器+约束收口+完备性审计表→③**标定 gate:EARLY_WIN_DELTA 真值化+
  deploy 时序(X 件)落地后才标定权重**(此刻标定=给错误世界校准;对抗轴⑥)→④并行开关+锁迁移
  (38 文件触 decide_prep,锁迁移以决策面比例度量)→⑤删通道。每步独立可验(sim A/B+分辨率底
  ±1.93),不过底即回退;检查网(不变式级)跨框架携带,不随通道删。
- **Consequences**:
  - 正:振荡族/互踩族/漏门族在架构上不可能(候选互斥在仲裁器一处);[22][28][30][31][32] 全部
    评分参数化(口述权威→系数,可调可证);决策可解释(每轮 log=候选×分数表,判读直接读)。
  - 正:与 redesign §3 对齐(战力表=评分的战力项,线库=候选的 line 标签,规则集=仲裁器约束)。
  - 负:迁移期双框架并存(~2-4 worker 批);评分参数标定依赖 sim 校准链完成度(胖尾/时序在修)。
  - 风险:候选组合爆炸(部署组合 top-K 剪枝控制);评分项相关性(成型度与战力非独立——初版接受
    双计,标定期用 A/B 分辨率底(±1.93)检验)。
