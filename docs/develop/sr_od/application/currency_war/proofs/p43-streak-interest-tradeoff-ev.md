## 推导

### ① 连胜金流模型:V(s,R,p) 与 D(s) 分解

**规范解(精确递推,引擎口径)**。连胜 s 进场(上轮非败)、剩余 R 个战斗轮;状态 = (连胜 s, 上轮是否败掉的战斗轮 lost),轮首收入 = loss(若 lost 且 s=0,补发上一败轮金)否则 T[s]:

```
V(s,lost=0,0,p) = V(s,lost=1,0,p) = 0
V(s,lost,R,p) = inc(s,lost) + p·V(s+1,0,R−1,p) + (1−p)·V(0,1,R−1,p)
    其中 inc(s,lost) = loss(lost 且 s=0) 或 T[s]
```

(T/loss 定义见符号表;连胜数 6+ 取表尾,递推内饱和;V(s,R,p) := V(s,0,R,p)。)这是 O(R×s_max) 的精确 DP——**消费者应直接用递推**,下述分解只作结构理解。

**赢/输转移的期望收益差 D(s)**(任务书命题 1 的量):本轮赢(保住连胜走 s+1)vs 本轮输(归零)的全部账差。引擎时序下**本轮轮首收入 T[s] 两分支同得(胜负不改本轮账),即期差恒 0**——差分整体移到从下一状态起的轨迹:

```
D(s,R,p) = V(s+1,0,R−1,p) − V(0,1,R−1,p)
         = [T[s+1] − loss]  +  [续期差]
           └─ 次轮金差 ──┘     (决策的下一轮轮首:胜分支发 T[s+1]、败分支补发 loss)
```

**结构定理(次轮金差有界且常反向,续期差主导)**。次轮金差 = T[s+1] − loss,由表值域 **∈ [−3,+2]**:普通节点次轮金差 ≤ +2(仅 s≥5 才为正);遭遇/boss 节点次轮金差 ≤ 0(s≤5 全非正)——**败轮金(4)≥ 中段连胜金(2),首个金差处输赢账差别小甚至反向**。续期差 = 败后重建账,单调随 s 增、随 R 增。数值(脚本 P1 段,R=9、p=0.7、battle;引擎口径 DP):

|---|---|---|---|---|
| 0 | −1 | +1.11 | +0.11 | −3 |
| 1 | 0 | +1.69 | +1.69 | −2 |
| 2 | 0 | +2.52 | +2.52 | −2 |
| 3 | 0 | +3.71 | +3.71 | −2 |

(续期差 s≥4 饱和:T[5+]=3-4 与重爬期望的组合封顶;断言锁:次轮金差 max=+2/min=−3、s≥2 续期差 >2、R=1 时 V(s,1,p)≡T[s] 与 p 无关即期差恒 0。)

**推论(连胜的价值不在赢的那一轮,在后面)**:引擎时序下本轮账与胜负无关,首个金差量级 ≤2 金且高难节点恒 ≤0——「保连胜」的金账理由**全部**来自续期(维持态未来轮的表金溢价 + 免重建)。这是 [19]「有意识抉择」而非本能反应的数学形态:即期层面输赢零金差,取舍真正对撞的是**续期连胜账 vs 息损**。

**短视界结构(P2 断言)**:R=1 时 V(s,1,p)=T[s] **与 p 无关**(本轮收入轮首已定,ΔV 恒 0);R=2 起可负(**−0.1 量级**——解析 V(0,0,2)=3−p 对 p 斜率 −1(`p43_check.py` 解析断言);机制=下一轮败轮金(2)替换 streak_gold(0)=1 的**下一轮效应**)。长视界(s≥2,R≥6)恢复对 Δp 单调增(断言锁)。含义:**短视界下「多赢一两轮」的金账可以是零或负项**,连胜账的正价值需要视界 ≥3-4 轮才显形——位面末(R≤2)的连胜账趋零,破息保连胜在位面末几乎从金账上证不成(奖励轮口径的尾段带见 §② 读数 3)。

**重建闭式(上界近似,任何视界下均严重高估)**。经典连掷公式:从 0 连拿 s 胜的期望轮数 E[重建](s,p)=Σ_{k=1..s} p^{−k}(p=0.7:s=4 → 10.55 轮)。粗重建账 ≈ E[重建]×每轮溢价上界(T[s+1]−T[1])。对拍精确 DP(脚本 P1b,R=8):s=2 粗 3.47 vs 精确 2.52;s=4 粗 21.10 vs 精确 4.41;s=5 粗 49.50 vs 精确 4.41。**高估的真因=溢价上界恒松**:重建期绝大多数轮处于低连胜段,每轮真实金差远达不到 T[s+1]−T[1],与视界无关——亲算精确续期差在 **R=8 已饱和成常数**(s=2:2.52;s=4/5:4.41,R=20/40 逐位不变),即给粗式无界视界(它本就按无界算),误差照样 1.4×/4.8×/11.2×;长视界不改善闭式。**结论:重建账一律走 DP;闭式只给「重建很贵」的量级直觉,任何视界下都禁作判据输入**(断言锁:精确 ≤ 粗式+ε;R=8 与 R=40 续期差逐位相等)。

### ② 破息保连胜判据(纯连胜账口径)

**判据**。设当前连胜 s、金 g、剩余 R;花 d 金(跨息档,息损 L(g,d,R,Ī))可把胜率从 p 提到 p+Δp。**只以连胜账为理由**的破息:

```
破息保连胜值得(连胜账单独证成)iff   ΔV_streak(s,R,Δp) = V(s,R,p+Δp) − V(s,R,p) ≥ L(g,d,R,Ī)
```

L 是 p47 递推的纯引用(本篇不复推);Δp 外生(A7)。**规范解**:ΔV_streak 由 §① DP 两次求值相减,零新常数。

**单调性(断言锁,数值验证)**:ΔV_streak 对 s 非降、对 R 非降(s≥2;短视界 s=0 有 −0.1 量级下陷,见 §①)、长视界对 Δp 非降。ΔV(0,R,·) < ΔV(s≥2,R,·) 全网格——**未连胜(s=0)的连胜账严格更小**:[19]①「未连胜不为单场破息」的数学形态。

3. **位面末熄火(含奖励轮口径)**:齐次 R≤2 口径全表 ΔV≤0(奖励轮前纯战斗尾段,首个金差还没落地);带奖励轮的位面末尾段(脚本 P6,尾段=遭遇+奖励+boss,Δp=0.10)ΔV = s 2/4/6 → 0.20/0.40/0.60——**含奖励轮上移后仍全域 <1**,任何 L≥1 都难证成——与 [18]「真 ALL IN 留给位面末」的语境互补:位面末的支出理由只能是战力/通关边际(消费方域),不是连胜账(奖励轮照发与熄火带的表面冲突由此消解:照发抬的是绝对账,不抬 ΔV 过 1 金档);
4. **s 的边际递减**:s=5 与 s=6 同值(表饱和)——「连胜 ≥5 后再堆连胜数不增连胜账」,与 STREAK_GOLD_TABLE 6+ 封顶同构。

### ③ 弃连胜保息判据(反向)

**判据**。忍一手不花 d(保住息线),接受胜率 p_lo(花的臂是 p_hi=p_lo+Δp):忍掉的正是连胜账——

```
L(忍)(s,R,Δp) := ΔV_streak(s,R,Δp)     —— 忍的账面代价
忍(保息)合理 iff   L(忍) ≤ L(g,d,R,Ī)   —— 连胜账牺牲 ≤ 保住的息(等价于命题 2 判据取反)
```

**数值带(脚本 P3b,R=9,p_lo=0.55,引擎口径)**:L(忍) ∈ 0.9(s=2,Δp=0.10)— 3.7(s=6,Δp=0.20)。

**读数**:忍的账面代价与「浅破息损」同量级(1-4 金 vs L=1-3)——**贴档浅破带两侧贴线,胜负手在消费方的战力 EV**(ΔV_streak 与 L 都小,谁的边际大谁赢);深破档(L≥9)则**忍是压倒性正确**(连胜账 ≤3.7 金 ≪ 息损 9-20)——**[19] 三态谱的默认姿态=保息,破息是需要连胜账+战力 EV 双证成的例外**,与 [17] 50 金息律主条同向,与 [2][6] 的例外结构一致。

### ④ [19] 三态谱的数学化

三变量(收口后,无血量变量——[39]②)在判据 `ΔV_streak(s,R,Δp) + V_power ≥ L(g,d,R,Ī)` 中的落位:

| 变量 | 进哪一项 | 方向 |
|---|---|---|
| **连胜在手 s** | ΔV_streak 的水平项(对 s 单调非降,s≥5 饱和) | 已连胜 → 花侧加项更大 → 倾向破息保连胜;未连胜(s=0)→ 加项最小 → 不为单场破息([19]① 的退化形式;引擎口径下 s=0/牌顺/Δp=0.15 连 L=1 都不证成,见 P3 表) |
| **来牌好坏** | **Δp 通道**(d→Δp 换算的可行性与效率,消费方域) | 牌顺 → 同样的 d 换到更大 Δp(且 V_power 大)→ 花侧两加项**同向叠加**,更倾向花;牌不顺 → Δp→0,通道关闭 → 判 HOLD(**门控语义**:[19]「牌顺小搜争连,不顺果断攒」——无牌时破息也无处花,连胜账再大也无处变现) |
| **息差** | L(g,d,R,Ī) 成本项(p47 域) | 息差越大(金位贴档线下、剩余轮多)→ 门越高 → 倾向保息 |

**来牌与保连胜的方向判定(任务书之问)**:**同向**。来牌好抬的是花侧价值(Δp 通道效率 + V_power),连胜在手抬的也是花侧加项(ΔV_streak)——两者相加不相消;唯一反向读法是「牌不顺但连胜在手」:连胜账存在但无变现通道,判据自动退回保息(不是反向,是**门控关闭**)。脚本 P3 段判定表锁此结构(s=6/无牌 → 全列 HOLD(no channel))。

**三态谱判定表(脚本 P3 段,R=9、p_lo=0.55、battle;Δp=0.15 代表牌顺)**:

| s=0,牌顺 | 0.85 | 忍 | 忍 | 忍 | 忍 |
| s=4,牌顺 | 2.30 | 花 | 忍 | 忍 | 忍 |

| s=6,无牌 | 0 | 忍(无通道) | 忍 | 忍 | 忍 |

(仅连胜账口径;s=0/牌顺/L=1 格在引擎口径下**翻案为忍**(0.85<1)——未连胜时连胜账单独连贴档浅破都不证成,「未连胜不为单场破息」在此格有了数值形态;加上消费方 V_power 后 L=3 列可翻花——这正是 [6]「店全是想要的(=V_power 大)可掉到 40/30」与 [19] 谱的合流点。)
