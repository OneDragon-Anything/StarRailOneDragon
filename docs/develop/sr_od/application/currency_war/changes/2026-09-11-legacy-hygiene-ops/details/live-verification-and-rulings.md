- **根因归层**：语义层——deploy 围栏视图归属的设计语义二义未定谳（候 ADR 裁决，非实现缺陷）。

## 方案（实施序）
三批互不依赖，各随其外部条件独立推进；实机窗稀缺资源由编排者统一排布（T-13 建档 + T-18 核证 + T-14 验证族 + T-26 样本采集同窗并盘）。三批都只观察/呈报/回写，零落码面（T-26 的申报面勘误与 T-14 的知识勘误除外，均为文档/申报面小改）。

## 关键取舍
- **验证族走集中批盘点制，不逐项立项**：六类项共享同一稀缺资源（实机窗）与同一动作形态（判读 + 回写），拆散立项会让每次实机窗重复盘点成本；批内逐项结论独立登记 criteria，验收粒度不变。
- **用户候裁批只做「呈报材料组装」不预设结论**：二选一裁决权在用户；组装段产出 = 让裁决一次对话可完成的证据包，而非替用户预选。
