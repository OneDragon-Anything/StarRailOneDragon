# P63:B_t 预测力下界(对 depth 严格大于 form_score,取等已否定)

> 状态:**已证(样本统计陈述 + P62 推出的大于关系;显著性仅押跨批泛化;2026-09-06 正式化)**
> 素材出处:同 P62(判定批 2026-09-06,sim61/62/63 三批全量 n=108
> boss 前帧;决策记录 = ADR-0535);B_t 定义 = deployed 中羁绊
> (经 `cw_chars.CHARACTERS` 注册表)∩ 四体系线内阵营集的件数,
> 与 P61 支配基座同语义,复算单一源 =
> `cw_deploy_logic.board_target_line_weight`。

## 命题(形式化)

在 sim61/62/63 全量样本(批指纹 d643023c/999fb98f/f26e00f8,
n=108 boss 前帧,合并检验按帧级处理)上:

1. **统计陈述(全量,无推断)**:B_t(boss 前帧)对 boss 轮
   depth(战斗存活深度)的 Pearson r = 0.403,t = r√(n−2)/√(1−r²)
   ≈ 4.58,p < 0.001(双尾);B_t 全样本有方差(终帧 k=2,[8,9],
   std 0.18~0.31;boss 前帧跨 [3,9])。
2. **支配关系**:B_t 的可达预测力(对 depth)严格大于现口径
   form_score——后者信息量恒 0(P62),非常数函数的可达预测力下界
   为 0,故 B_t ≥ form_score;取等当且仅当 B_t 亦与 Y 零相关,已由
   r = 0.403 ≠ 0 否定。

## 证明

第 1 条是全量样本统计量(枚举非推断);第 2 条由 P62 直接推出:
P62 给出 form_score 对任意 Y 的预测力恒为下界 0(常数函数),而
B_t 与 depth 的样本相关非零 ⇒ 严格大于。∎

## 边界与适用限制(如实入册)

- **辖域绑定 depth**:「≥」命题仅对 depth 达显著;对 boss delta
  (r=0.174)与终局 hp(r=0.112)同型成立但**强度未达显著**——
  引用时须绑定 depth 或加「弱」限定词,禁外推为「B_t 预测终局胜负」;
- **显著性解释**:n=108 为三批全量,检验只对「跨批泛化」有意义;
  弱对照 = 三批池指纹互异且批间有在飞改动,存在池漂移混杂,结论限
  「本三批样本」,换池复测候回归对账;
- **饱和倾向注记**:sim63 终帧 B_t 恒 9(k=1)——B_t 后期同样趋饱和,
  它区分的是「中盘承重积累速度」,不是终局胜负;
- **用途定位**:本命题支撑的是 B_t 作为**披露口径**(观测面选型)的
  合法性,不构成判据资格——升格判据须过 ADR-0482 全门(ADR-0535
  升格闸门)。

## 结论

B_t 对 boss 战存活深度的预测力严格大于已退役的 form_score 现口径
(取等已否定),且是全部候选代理(engines 原值/2★ 数/等级/
deployed_power)中唯一 p<0.001 显著者——披露口径替换的数学依据成立。
