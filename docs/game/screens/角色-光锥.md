# 角色-光锥(character_light_cone)

> source_image: sr-od-test/screens/角色-光锥/default.webp(2026-10-17 live 建档,布洛妮娅光锥页)

## 何时出现

角色页左侧「光锥」TAB;或详情页右下光锥卡点击跳入。独立屏。

## 状态流转

```
详情 TAB/光锥卡 → 本屏(显示当前角色装备的光锥大卡+右侧信息)
替换按钮 → 光锥替换列表(未建档,内部页)
强化按钮 → 光锥强化页(未建档,内部页)
右上关闭 X → 离开角色页
```

| 元素 | 坐标 | 行为 |

- 读区-等级 [1465,222,1665,268]:OCR
- 读区-叠影 [1465,570,1660,618]:OCR「叠影N阶」

- 读区-生命/攻击/防御:光锥提供的三围(x 1770-1895,3 行)
- 光锥技能全文:右栏中部大段文字(全屏 OCR 抓,固定区未建——技能描述非结构化,按需)
