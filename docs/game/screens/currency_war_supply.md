# 货币战争-补给阶段(N 选 1 角色+装备)

补给节点的选择屏:从 N 张(实测 5)纵向卡里选 1 张(每张 = 角色 + 其自带装备)。选完「确认」回备战。

## 何时出现 + 状态流转(live 确认 2026-08-13)

补给节点(如 1-5)的推进方式 = **选补给 → 进下回合**(**非出战**)。live 实测:1-5 补给节点备战(右上「返回补给阶段」按钮)→ 点按钮进本屏 → 选卡 → 确认 → **直接进 1-6 备战**(消耗 1 次补给;选的卡 = 角色+装备,实测选 飞霄/折叠小刀 → 飞霄 入 bench)。**补给节点出战 click 不推进**(实测 manual+op click 均无转场)—— 补给节点没有"出战打怪"这步,确认补给即完成节点。

- **入口**:补给节点备战屏(右上「返回补给阶段」按钮,`货币战争-备战` 的 `按钮-返回补给阶段` area;备战非遮挡子态 —— 商店/购买经验/出战可见但出战不生效)→ 点「返回补给阶段」进本屏。
- **出口**:① 点卡身选中(已选择 +1)→「确认」→ **进下回合备战**(消耗补给,角色+装备入 bench);② 「返回备战界面」(右上)放弃回备战(不消耗,但补给仍未选 → 仍卡补给节点,出战仍不推进)。
- **卡身选中点**:`(装备名 x, 550)`(`read_supply_options` 用 `_SUPPLY_CARD_CLICK_Y=550`;实测 (193,550) 选中、(140,500) 不中 —— x 取装备名非角色名,y=550 卡身中线)。
- **bot 流程(已接线)**:Loop 按 nodeseq 节点类型判补给节点(nodeseq current=supply;不用「返回补给阶段」按钮判——battle 节点也在该按钮,不可靠)→ 点「返回补给阶段」进本屏 → 补给节点画面 op(观察 + 选卡确认)→ 推进。

## 识别特征(稳定锚点)

- **id_mark**:「补给阶段」标题(屏上部居中,screen_info `标识-补给阶段` pc_rect [893,120,1027,230];2026-08-13 设 id_mark=true → `is_precise=true`)。
- 独有文字:「已选择 X/Y」+「剩余次数:N」+ N 张卡(角色名 + 装备名 + 阵营标识)+「确认」+「返回备战界面」。

## 可交互元素

- **N 张补给卡**(纵向,横排,实测 5):每张 = 角色立绘 + 阵营标识 + 角色名 + 装备图标 + 装备名;个别卡带「试用」角标(= 账号未拥有该角色,用 CW 试用版,面板中等;详 [玩法 doc](../../gameplay/currency_war.md))。**点卡身选中**(已选择 +1,「确认」由灰转实)。卡内容每局随机(角色/装备/阵营随牌池)。部分卡附近见数字(如「9」「8」,含义待核:费用?星级?)。
- **「已选择 X/Y」**:(1642,912)右下,选中计数。
- **「剩余次数：N」**:(1347,969)右下,本节点剩余可选次数。
- **「确认」**:(1681,966)右下;未选(0/1)时灰不可点,选满转实,点 = 确认选择回备战(消耗次数,不可逆出口)。
- **「返回备战界面」**:(1717,44)右上,放弃选择回备战(不消耗)。
- **「角色详情」**:(102,970)左下 + Q 键;开角色详情面板(子态待建)。

- **N 张卡的(角色, 装备)**:`read_supply_options` OCR 装备名(定义列)→ 角色按最近 x 配对(`get_char` roster 校验滤噪);钻(红/蓝/财富宝钻)视觉判定 `has_diamond`(SIFT 主通道 + 装备名精确匹配兜底)→ 决策 = 策略层三级字典序(钻 > 终局角色 > 装备;决策本体 = `strategies/impl/mandate_v1/supply.py`,语义单一源(唯一权威出处)= strategy-docs/30_supply_screen.md)。

- 刷新按钮实存:「剩余次数:N」文锚左侧圆钮(画面 op 文本锚定偏移点击;剩余次数 = 本节点剩余刷新机会,刷新判断语义 = strategy-docs/30_supply_screen.md)。
