## 1. 背景与归层结论

### 1.1 病灶与通道缺位(方案审确认存活面)

病灶帧(复盘 g_20260907_021326 p2r1):锁线「列车同行」(羁绊档 ×1,特定缺件整局零出现),板面旧过渡线「仙舟」×2 差 1 件即首档激活(仙舟首档阈值 3);爻光(仙舟 1 费)在售被拒 `non_line`。归层三层:①刷新失能=运行时(ADR-0571 已根修);②EV 买面/换线影子=标定槽 None 设计态 fail-closed(ADR-0571 §1 定谳);③**本 ADR 辖域=通道缺位**——锁线态线外激活件在现行 9 个买发射通道中无一可达(枚举表:v1 版存档;方案审攻过未破#1 确认完备准确——9 处 `_emit_buy` 发射位逐一吻合),禁买是结构缺位而非任何已证判据的输出。

### 1.2 宪法面叙事修正(方案审六.2)

v1「窗内禁买与总纲不变量 2 存在方向级张力」的叙事**作废**:不变量 2 的但书是「**已证有正账**的发展支出」——线外激活件的正账恰恰未证(§5 环节 B 自认),维持禁买不违宪。真正的风险方向是反向的:**用有缺陷的判据放行未证正账的支出**(v1 强域即此形态,已按 §4 v2 收敛)。宪法要求的是证明,不是「冻结 vs 放行」的姿态二选一。

### 1.3 病灶帧改判(F3,阻断级诚实申报)

亲跑复算(`t90_recalc.py`,本批复现):kernel 口径(列车同行 form_tiers={"列车同行":4},p2r1,gold=24)E_rounds=**6.30**(dist=3;dist=4 读法 8.40)vs R_rem=16(生产日程)/18(sim 回退)——**门恒关**;弱开窗需 dist>7.6(lv6)而实际为 3;v1 §7-1 草案公式更关(E=0.63)。结构性原因:「特定缺件整局零出现」是 **drought 型断供**,E_rounds 是 tag 级超几何(列车同行 8 张卡 p̄≈0.48,测量健康),根本不 ingest 特定件断供——`cw_line_switch` 模块注释明文该估计器盲区(「理论可达、实测断供」的线只有经验观测能测)。**处置**:断供型从本门辖域划出;本 ADR 若落码,对触发病例(爻光)的行为改变=**零**(本 Status 级申报由 §8 测试 2 钉成断言)。断供型的观测门(drought/supply 信号消费)另立姊妹命题,登记于 241 供给仲裁设计件的姊妹位(§3.2)。

## 2. 命题 v3

**一句话**:锁线态下,线外激活件的买/留决策经「锁线可达性门」三态处置——门关维持禁买;强开窗(结构不可达)放行 **e0→1** 激活件(零成本合取支配);弱开窗与其余候选 fail-closed 占位待证;断供型出辖。

### 2.1 口径单一源原则(F4 治平)

门全部测量量——E_rounds、缺口距离、rolls(息线内预算语义:affordable 按 `g−息线` 计)——**全部 = `kernel/cw_line_switch.e_rounds` 逐字直调**(内含 `line_distance`/`p_bar_faction`),本文不复写任何公式,杜绝第四版漂移。v1 §2「剩余预算全投」叙事与 §7-1「预留 c_x/丢息线」变体作废。R_rem 语义 = `cw_plane_table.r_remaining`(r_global,到局终节点数;未揭晓位面回退取上端=门偏关,方案审四已核方向保守)。

### 2.2 距离口径钉死(F12)

距离 = `line_distance` 全档求和(**comp.form_tiers 代理**;12 号件 §1 通用目标态的分段档表本身是在册挂账未落地,form_tiers 是现行唯一可算载体,如实声明)。列车同行 faction 阶梯 (2,4,6) 与 comp form_tiers 目标 4 的双读法钉死为后者(dist=3);「下一成型档」语义精确化归证明批 + 分段档表登记批。

### 2.3 门三态与档位劈分

- **关**:E_rounds ≤ R_rem → 现状域(P74-a,禁买维持);
- **弱开**:有限 E_rounds > R_rem(期望超窗)→ §5 弱域;
- **强开**:E_rounds = +inf(kernel 字面条件:dist>0 ∧ p̄(缺口标签,当前等级)=0,即 REFRESH_PROB 对应费用档行零)→ §4 强域。

**放行域按激活档位劈分**(审者自荐采纳):候选 x 须使板面**未激活体系** f 跨入首档(e0→1:n(f)+1 = f 首档阈值 t₀(f),如仙舟 t₀=3)方入强域放行合取;**e1→2+(f 已激活后的后续档)无价值证据**(P20 明文 e1→2 净增量≈0 不外推)→ 恒禁买,入弱域钩子挂账。

**辖域**:锁线态(locked_comp 非空,与 `locked_buy_membership` 同点触发);不辖部署判定(§7.6 兑现链预检)、不辖换线决策(§3.3 测量-决策分界)、不辖未锁帧、**不辖断供型**(§1.3)。

## 4. 强域放行判据与证明链 v3

### 4.1 强开窗的证明语义(F1/F2 治理 + N1 换承重件)

v1 的「E_rounds=inf=静态不可达=结构零」作废——p̄=0 是**等级条件零**(亲跑实证:量子同频 lv3=0.0000/lv6=0.3618;REFRESH_PROB lv1-3 行纯 1 费)。v2 曾以「不升级保守假设」把 p̄=0 抬回结构零去承重支配步骤 3;**v3 按 N1 删除该假设的支配承重**(若升级救活锁线,该假设对支配结论呈反保守面),步骤 3 改**可回收机制论证**(§4.4 ③)。强开窗降格为**开窗判定**(结构型不可达窗口的识别,kernel 字面条件),不承担「P̂_lock≡0」存在性主张。真结构零的仅存形态 = 「标签零卡」独立羁绊(costs=[],7 个标签,对锁线 comp 无意义,不入条件)。**P60 型条件维持删除**(F2):其已证对象是全 buy_members 记持全集非缺口集,且中间档(列车同行 ×2/×4)交付真实战力(cw_comps「战力=列车同行4 档乘区」),锁线侧放弃收益≠0。

### 4.2 金成本 ≈ 0(F11/F7 治理)

出处改准:退金机制事实(注册表 sell_refund,1★ 全额退)+ P47 A5 卖回通道语义(v1 引 P41② 系标签错位——P41② 是卖出侧决策规则)。**售回权语义修正**:售回权在同轮保护期内被冻结(§3.1;时限=1 轮,冻结期息差已由 §4.3 的 L=0 判据覆盖),出轮恢复——不再宣称无条件「随时售回」。

### 4.3 息损 = 0(F6 治理)

前提 = **loss_exact 现算 == 0**(t5_p1_false 精确判据,predicates.py 单一源,与 C1 通道共享)——精确双轨迹递推判定,含未来金位轨迹。P47 命题三明文「同档花费(t=0)仍有非零残损」,故**禁**以「金位不落息档=息流不受损」的跨档散文替代本判据;Ī 的「保守近似」方向声明删除(P47 明文 L 对 Ī 单调性不成立,t5_p1_false 内部取值即其自身语义,本命题不另作声明)。

### 4.4 放行合取与支配链 v2

**合取(全部必要)**:强开窗(§4.1)∧ x∉B ∧ **e0→1 激活件**(§2.3)∧ 1★ 全额退 ∧ loss_exact==0 ∧ 席位可容(bench_free≥1)∧ 帧级不置换(M2 义务集本帧无在售可买缺件;发射位在 M2 后结构保证)∧ 非 C1 名单。

**支配链**:①金成本≈0(§4.2);②息损=0(§4.3);③**锁线侧真实成本上界 = 1 帧延迟**(N1 可回收机制论证):同轮保护 1 轮过期后,`funding_support_sell` 对 1★ 全额退件按转化类降序放行(先例语义,§3.1),金/席按需回收——锁线在缺金/缺席帧回收 x 的代价 = 1 帧延迟(当帧让渡 x 的激活价值),非永久放弃;该论证**不依赖「锁线是否真死」**,升级救活锁线的情形下成本上界同样成立(无反保守面);bench 持有缺口件的 board-only held 口径边缘归证明批钉死;④买 x 收益≥0(P38 单调性,方案审四确认承重)+ e0→1 价值方向 P20 背书(位面1 过渡期辖域内;辖域外帧背书如实降级为「机制直读+零成本」,不再引 P20);⑤合取 → **除「席位占用(P41③ V_slot 语义)+ 未售回角(终局清仓通道未覆盖则损 c_x,落码批核清仓覆盖面)+ 锁线延迟 ≤1 帧(③)」外弱支配**——息差项由 loss_exact==0 判据本体内嵌归零,残余申报三项(方案审「席位+息差+未售回角」要求 + N1 扩项)。∎

## 5. 弱域挂账 v2(F9 治理)

弱开窗 ∧ 非强合取(即**全部 e1→2+ 候选**与其余不合格帧)→ **fail-closed 占位 = 现行禁买维持**。合规面本批认领:

- **01 §7 待证钩子表已登记 P74 行**(本批同步落盘,先例 = P25/P29 行同款);
