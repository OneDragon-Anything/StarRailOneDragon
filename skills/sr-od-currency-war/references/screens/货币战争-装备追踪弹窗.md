# 货币战争-装备追踪弹窗

## 画面简介

应用攻略后自动弹出的装备推荐页——每行一个攻略含角色：头像 +「暂未获取」状态 + 优选装备图标 +「追踪」按钮；行内装备图标 = 该角色推荐装备的结构化来源（与攻略详情页文字互补）。再次打开的入口推断 = 备战右上「装备追踪中」旁铅笔编辑按钮（未实测）。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-标题-装备追踪 | 弹窗标题（身份锚之一） | 纯显示 |
| 标识-优选装备 | 行标签「优选装备」（身份锚之一，每行各一个，带奖杯小图标） | 纯显示 |
| 按钮-追踪-1 / -2 / -3 / -4 | 逐行「追踪」按钮：开启该角色装备追踪 | 点击开启该角色装备追踪（状态改变型，效果未实测） |
| 按钮-关闭 | 弹窗右上 X | 点击关闭（实测回备战，攻略仍应用——应用与追踪独立，关掉不撤应用） |
| （待建档）角色行 | 每行 = 攻略含角色头像 +「暂未获取」状态 + 优选装备图标（推荐装备结构化读数） | 纯显示 |
| （待建档）顶部提示语 | 「当前攻略包含角色装备推荐，请选择要追踪装备的角色」 | 纯显示 |
