## 1. 问题与动机

- 现状症状（实证局 g_20261028_011013，sim seed=20260118，death@P2r5，金 108→142 滞留至死；系统性形态批读数 = 死时金≥50 15/15 局、stay_gate 触发 85/85 帧全拦零发射、终金中位 105，出处 = `strategy-docs/11_shop_decisions.md:186` + 追查件 §4）：
  1. hp 以判据身份渗透策略 11 处（hp 清查件 A 组）：危机带族拦死位面 2 全部升级发射（本局 17/17 帧，`levelup_crisis_defer`）；血预算停升级门、血闸、血预算视界进锁线判据、三处挂空死码；
  2. 刷新链历史残件堆积：路径总账门本体已删但注册行/注释/文档残留（W10 锚 = `criteria/__init__.py:65`）、危机不变式挂空（发射链零消费，追查件 §7 实锤）、整级预留分支不可达（升级触发态与刷新放行态互斥，裁定 #5 推导）、`r0_stop`/`r1_start` 零调用壳、P92 六通道枚举抽象且误拦追星（本局 `p92_no_buy_refresh_blocked=3`）；
  3. 买面配合缺陷：追星窗口被压牌库囤货灌满备战席反锁（本局 bench 9/9、`m6_bench_full=8`）、买臂名单星级盲致唯一进店线内件无人买（追查件 §1.2 r2 帧）、免费刷新分支绕过全部判据（`shop.py:1963-1971`，「高效决策」9999 次白给刷 = 失控循环现实形态）。
- 根因归层：**语义层**——hp 被立为策略输入（「血低 → 停止发展/停止支出」），与用户裁定核心（策略正确 → hp 自然好）冲突；**约定层**——历史迭代残件未按删除纪律清理，判据面文档与代码漂移（23 号稿刷新门行 vs 代码实况）。追查件归因：金滞留 = 升级-刷新互锁（hp 闸为锁链一环）+ 席位/星级配合缺陷，非 hp 单因——故本迭代双线并治。
- 解决到哪：hp 判据族全删（含证明族与正本章）；刷新链收敛为「判据 → 金线闸 → 发射」三组件；买面三缺陷修复；免费分支纳入判据。
- **明确不解决**：缺件不可达换线出口（W6，低优挂账）、刷新发射曝光率（W7，低优挂账）、装备穿戴配对（复盘 A2，挂账候复测）、补给决策链接线（已有独立迭代 `2026-10-28-supply-decision-wiring`，本迭代不并入——边界依据 = 迭代外溢判据，`docs/develop/harness/iteration-design.md` §1.1）。

## 2. 方案

### 2.0 系统级变化（读一遍知全貌）

1. **hp 判据族物理删除**（裁定 #1/#3/#4）：hp 清查件 A 组 11 条 + B 组支撑孤儿 + D 组正本章 + E 组测试锁，按删除纪律连根清。清单单一源 = hp 清查件（落地批开工前按 hp-purge §7 快照抄录至 `details/hp-purge-appendix.md` 作执行单一源，`.debug` 原件转溯源参考），落地批照单执行。
2. **刷新链三组件定型**（裁定 #5/#6/#7，全链无 hp）：
   - **判据**：三段式查表（现行 `refresh_warranted`，不动）＋新增**目标可买**条件：目标卡刷出后买得到 = 有空位 ∨ 已持 2 张买第 3 张直接合成 ∨ 可卖一件备战席燃料腾出位——存在性门整门删除，追星误拦缺陷顺带消除；
   - **金线闸**：`当前金 ≥ saturation_line + 刷新价 + 当前停留目标卡价`——整级预留分支删（裁定 #5，互斥不可达）、卡价预留改锁停留目标（裁定 #6，修「已 2★ 追 3★ 目标被合格集过滤漏留卡价」）；
   - **发射**。免费刷新分支同过「目标可买」条件（金线不适用——免费），消灭「白给刷绕过全部判据」的无界循环。
3. **资金序声明（升级推迟期）**：升级判据命中但被资金线推迟（凑金在途/穷尽）时，刷新判据维持拒绝、**不设解锁支**——解锁支会在凑金在途帧放行刷，而整级预留分支已删（裁定 #5），刷新烧凑金 → 「金被刷到下界、升级永久 defer」饿死环；资金线推迟态 = 攒金收敛态（金上涨吃息，2026-10-18 声明域 `changes/2026-10-18-levelup-band-gate/design.md:156`），hp 闸删除后必收敛、非死锁。原 W2 动机（hp 闸致永久双闭）已被第 1 条消灭。
4. **买面三修复**：停留刷窗口内压牌库囤货臂停用（让位刷新，W4）；买臂星级语义统一为 need_star 口径（未达标成员的副本照买、达标成员停买，W5）；刷新负结果记忆（判据拒绝态直接关店，无状态变化不重入，W11）。
