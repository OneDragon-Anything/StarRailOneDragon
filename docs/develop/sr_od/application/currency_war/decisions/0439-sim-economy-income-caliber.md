# 0439 sim 收入口径修正(败轮节点金 + 奖励轮 base/streak 成对)

- 日期:2026-09-06
- 状态:accepted
- 关联:ADR-0351(奖励/补给轮零发放口径,发金半句被本决策部分推翻)、ADR-0262(STREAK_GOLD_TABLE 真值锁,零触碰)、ADR-0128(连败计分语义,计分侧跟进另裁)、combat.md §4/economy.md(「无连败补偿」表述改「无递增连败金」)

## 背景

实机 gold 差分全量实证(108 局/874 结算行/767 轮差分,2026-08-28)推翻了 sim 收入模型的两处口径:

1. **败轮不是零/弹窗口径**:败轮结算实收残差众数 = 普通战斗 **2**(24/39 严格子集)、遭遇 **4**(18/24)、boss **4**(8/22,散布大置信中)。旧 sim 发 `streak_gold(0)=1`(弹窗预期口径),系统性少发——硬节点败轮少发 3,且位移集中在打不过遭遇/boss 的败局(恰是最需要经济重建的局)。连败长度不改变金额(无递增补偿,项4)。
2. **奖励轮照发连胜金**:奖励 r1 残差 =1(85/85 零散布)、r2 =1(59/79 众数)——ADR-0351「奖励轮不发连胜金」的**发金半句**与全量数据不符(结算屏「连胜×0」是计数不是金额);**计数半句成立**(185/186),结算段不动。

实现陷阱(评估批定名的最重要约束):`BASE_INCOME=5` 对奖励轮 base(实发 r1=3/r2=4)的高估**恰好盖住**缺发的 1 金连胜金——只改 streak 不改 base 会让奖励轮净多发 1。两处必须成对改。

扰动量化(无反馈静态重放,800 局基线台账逐行重放):纯连胜口径修正 ≈ **P1 出口金 +6.6 金/局**(中位 +7,+2~+12;硬节点败轮占近 8 成)。凡以 sim 经济轨迹为输入的历史门结论(典型:粗模型 vs Δ池 P2 进场率差 4.40pp 恰在 ±4.4pp 门界的门 1a)须 regate 后才能引用,挂账 registry 注释。

## 决策

方案取舍取**部分改**(只落强证据项),评估批三方案中 B:

1. **败轮金**:cw_economy 新常量 `LOSS_GOLD_BY_NODE={'battle':2,'encounter':4,'boss':4}`——独立常量,**不动 STREAK_GOLD_TABLE**(表是胜轮弹窗真值,streak≥1 域,ADR-0262 锁零触碰)。cw_sim 收入段:进轮 streak==0 且上一轮为败掉的战斗类节点 → 发 `LOSS_GOLD_BY_NODE[上一轮节点]`(收入在下一轮开头入账,跨位面 P1 末 boss 败 → P2 r1 同规则);否则按表。
2. **奖励轮成对改**:streak 分量照发 `streak_gold(进轮连胜)`(含 counter0=1)+ base 改查表 `REWARD_BASE_GOLD_BY_ROUND={1:3,2:4}`(其余轮/其余节点维持 BASE_INCOME=5;P2 base 未验证挂账)。补给轮不动(仍零 streak + base+利息;实发零发放的证据 n=3 未转正,条件升级挂账)。r8 位面大奖励(少发 ~9)、boss 胜轮 +2、P2 base:未钉死,挂账。
3. **版本披露**:`ECONOMY_CALIB_VERSION=1`(cw_economy 单一源),进 sim manifest `economy_calib_version` 锚——独立于 `COARSE_CALIB_VERSION`(那是粗模型战斗引擎校准的版本,收入口径是另一子系统),跨批次对比先核本值。
4. **检查器重写**(cw_sim_checks.check_streak_combat_only_income):从「奖励/补给轮 income.streak!=0 即违规」改为**精确重算断言**——逐行镜像收入段分支(补给恒 0/奖励照发表/战斗轮含败轮金路径),任一行账本≠重算即违规;`loss_gold_rows`/`supply_rows`/`supply_issued_extra`(补给多发残差=base+利息)为披露面挂账。
5. **判据不改**:本批只落码;W346 门组 regate、基线臂重锚、剂量-响应定锚复跑挂账待执行(registry 注释挂账)。

## Considered Options

- **全量改(A)**:连 r8 位面大奖励、补给零发放一起改——否决:r8(18/22)、补给(n=3)、P2 base 均未到钉死强度,把半成品数值烧进全部基线,直读推翻则二次重锚成本翻倍。
- **不改(C)**:偏差是系统性单向(每败局少发、每局必现),带着已知偏差跑门,门过了也是带病的过——否决。
- 只改败轮、奖励轮暂缓——否决:奖励轮证据零散布最强,且不趁成对改落掉,未来单改 base 会静默多发(耦合写在常量注释+锁里防回归)。
- 败轮金并进 STREAK_GOLD_TABLE(扩 0 档)——否决:表被 ADR-0262 弹窗真值锁辖,败轮实发与弹窗预期系统性差 +1,语义不同源;独立常量+节点键是证据本身的结构(普通/硬节点不同值)。

## 后果

- sim 金轨迹:败局更富(+2/+4 每败轮)、奖励轮净差≈0;策略决策经金位间接受影响,既有全部 sim 经济基线带断链标记(economy_calib_version 区分新旧批)。
- ADR-0128「无连败补偿 → 连败 0 分」的计分前提(收入侧)与实发不符:连败 fold 态经济价值被低估;`STREAK_WEIGHT` 单边语义的 ADR 修订与计分侧是否跟进是独立裁决,挂账。
- 验证:新锁四面(值锁/生产账本败轮路径锁/奖励轮成对锁/版本披露锁)+ 检查器锁重写(合成正例双向/缺键守卫/变异推演)+ 全量回归;生产在飞局不受影响(本批只辖 sim)。
