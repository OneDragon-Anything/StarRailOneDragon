## 1. 动机与定谳(用户裁定链)

1. **统一一套打分规则**——不要每处「遇到 X 就硬选/不选 Y」;
2. **排除=极大减分**(数量级压制,非布尔特判非排除池);
3. 分数值从效果原文/攻略实证来;克制分档(强吃/怕/重开级)对齐攻略
   原话;**直接记载 > 类间概括 > 机制推定**三级证据序;
4. **词缀吃怕是阵容特定知识**(泛化推不出方向反转);
5. 投资定义卡不做缺位特殊处理(在场加分/缺位 0 分,分数自然竞争);
6. 流派分开定义(姬子 A/B 首例);不考虑词条触发换线;
7. **全部即时锁退役**(策略型+角色型,用户 r3「全退役」):拿到什么
   都不直接锁,分数说话,锁定=时点兜底取首名;
8. **defining/顶级标记退役**:卡的价值=它给线的加分(实证覆盖通道
   默认档),选卡方向分从线分引擎派生,「不刷掉」=分数阈值判定。

## 2. 评分框架(纯加权和,一个公式)

```
线分 = 证据分(数值化: carry + 骨架 + 插件 + 热度)
     + 投资环境分 + 投资策略分(通道派生)
     + 词缀分(吃怕表: 强吃+/怕−/重开级−极大)
     + boss 分(Σ 三只克制,含重开级−极大)
```

**数量级表**(层间支配靠数量级实现;示意值,批 1 定常数锁 sim;
r4/R4-1~3 修订:全库自算校准——终局全员构局单线正项上界实测最大
=巡海击破 71530(7 carry+4 骨架+2 插件+词缀+投资+热度),余量 28%):
| 档 | 值(示意) | 语义 |
|---|---|---|
| 重开级(词缀/boss)/万敌无燃料底线 | **−100000** | 排除=极大减分(任何构局追不上) |
| carry·anchor(线锚核心,每名) | +8000 | 锚核心单卡即战力(攻略「希儿到手即开线」);单 anchor 压过一切环境正和 |
| carry·其余 core(每名) | +4000 | 档内分档(r4/R4-3:攻略主次语义——非锚 core 减半;「3 辅助=1 锚」相平,锚+任一辅助即胜) |
| 骨架件(每名) | +2000 | 4 骨架=1 anchor(相平点按 anchor 档重校);层间支配 sim 校验 |
| 插件(每名) | +500 | — |
| 攻略热度 | 每点 +1(274) | r4/R4-2:**<1 插件**(持有实证 > 社区先验,与现行字典序插件>热度一致) |
| 词缀强吃·顶级 | +900 | 万敌×正当防卫 |
| 词缀强吃·燃料 | +750 | 万敌×忍无可忍;姬子A×受击触发类 |
| 投资强档·定义卡 | +500 | 黑塔纪元/专家邀请/飞光 |
| 投资强档(期货/定向刷新) | +300 | 契约/概念股 |
| **实证覆盖升档** | 条目级 | 量子星徽×3→希儿(0.9 近硬绑)/罗刹→列车:通道③默认 +150 **按实证升强档 +750**——实证覆盖通道默认(与吃怕表「直接记载覆盖兜底」同纪律) |
| 投资中档(星徽/引擎匹配) | +150 | 邀请/速度类策略 |
| 软档 | +30 | 弱关联;flex 降档落点 |
| 怕(词缀/boss) | −150 | 正当防卫×直伤系/姬子 A·B |

- **sim 不变量**(r4/R4-1 修订):任意构局任一候选线,其全部正项
  之和上界(sim 实测锁定,自算基线 ~72000)**< |−100000| = 100000**
  ——重开级单条 −100000 → 含重开级命中的线分恒低于无命中线
  (数值上排除);批 1 锁常数时以全库构局自算+sim 实测双验此上界;
- **sim 数值对照场景**(r4/R4-3):①单 anchor vs 多非锚 core
  (希儿独占 vs 花火+符玄+缇宝——攻略语义=希儿胜)②4 骨架 vs
  1 anchor③热度满 vs 单插件——三场景锁层间/层内数量级;
- **空候选/递补/全线排除问题自动消解**(r3/R3-1 随布尔位废除):
  无过滤,只有排序;时点兜底取首名;全线极低分局最劣如实表现;
- 万敌底线:开局 4 词缀 ∩ 燃料集 = 空 → −100000(与重开级同档;
  燃料集定义见 §4)。
