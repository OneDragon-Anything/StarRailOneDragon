# 0342 - 恢复局策略失活早停 + 失活检查项 + hoard 口径单一源(W103 三件)

- 日期:2026-08-25
- 状态:accepted
- 关联:W98_报告 发现1(恢复兜底局污染);ADR-0273(恢复兜底语义);ADR-0329(locked-resume);ADR-0340(merge_progress/溢出金断买检查器);W97_报告 §6.5 / W98_报告 发现2(hoard 口径双源)

## 背景 / 决策驱动

W98 实录:七差局全部是崩溃恢复兜底局,其中两局(003757/011957)decisions 全行
`strategy_id=''`、零策略动作族、P1 全程 0 买(金囤 91/100,店里读到目标件)——
观测层活着、决策层整局未点火,恢复兜底把垃圾局打满 40min。且该形态在
runs 判读里隐匿了 7 局才被自由挖掘批发现,缺生产检查项。

## 决策(三件)

1. **运行期早停**(battle_loop 备战相位入口):连续 **2 个完整轮**无任何带
   `strategy_id` 的决策行 → `stop_running(reason='cw:strategy_dead_early_stop')`
   停局重启加载策略。「重大修复待加载=无条件早停」(skill 实机运维定调)的
   运行期镜像:策略死了,继续跑=零信息量局烧跑道。
   - 结算点=备战入口查**上一轮**(本轮决策发生在本相位内,查本轮恒空会误杀);
     同轮重入(过渡帧/重试)不重复计数(状态机 `dead_streak_transition` 纯函数);
   - telemetry 关闭时让位(无数据=无判据,不误停);
   - locked-resume(ADR-0329)轮次天然无决策行 → 同样被本检查覆盖(锁定局
     本就是「策略不可用」的子集,与其兜底打完不如早停——W98 建议原文)。
2. **生产检查项**(`check_strategy_live_streak`,进 `run_checks_on_replay`,
   **置于判栈之前**):P1 连续 ≥3 轮无 `strategy_id` 行 → 违规行。失活局恰
   `strategy_id=''` 无法判栈,放判栈后会被 continue 连坐跳过。落点在
   cw_telemetry(生产语料消费端)而非 cw_sim_checks:sim 批策略恒在、该检查
   恒绿,不进 sim 批量内嵌;同时避让在飞批对 cw_sim_checks.py 的未提交改动。
3. **hoard「零买」口径单一源 = ADR-0340 检查器语义**(零 BuyCard **且零
   LevelUp**;升级滴漏不算冻结)。W103 对拍实证(n=120, seeds 0-119,
   snapshot 池,逐轮三判定同进程):
   - W97 口径(`sim.spend.buys` 空)与 W98 口径(actions 无 BuyCard)**逐位
     等同**(新旧两版代码树均零分歧轮)——「口径差」假设不成立;
   - LevelUp 滴漏轮是两口径与 canonical 的唯一差集(新树 59→39 轮,
     16.4%→10.8%);
   - **W98 报告的 38%/55% 在其脚本原文+新旧两版树下均不可复现**
     (B 口径实测旧树 18.6%/39.2%、新树 16.4%/37.5%),该数字从对照引用中
     剔除;W97 的 18% = 旧树(merge_progress 前)复现 ✓。
   修复后 canonical 基线:轮 10.8%/局 29.2%(HEAD 86af24cb,含 W96)。

## Considered Options

| 选项 | 结论 |
|---|---|
| **A(选定):备战入口查上一轮完整轮,连击 2 停** | 完整轮语义干净(本轮决策未发生不结算);N=2 = 恢复垃圾局 40min→~8min,且正常局每轮必有 strategy_id 行(shop.py 恒传)零误杀面 |
| B:查本轮(备战入口即时判) | 本轮决策行尚未写,恒空 → 全部局误停,不可用 |
| C:N=1(首空轮即停) | 恢复入口的首轮可能是接管过渡帧(残留结算屏/接管段),单轮证据不足;W98 两局是全程空,N=2 已足够早 |
| D:只加检查项不加运行期早停 | 垃圾局仍烧满 40min 才在事后判读发现——检查项是「被发现」,早停是「不再发生」 |
| E:hoard canonical 取 W97/W98 口径(不排 LevelUp) | LevelUp 滴漏轮金仍在花(4 金/次),不是「金趴着不动」;[17] 违规语义=该花没花,canonical(零买零升)捕捉更准,且与 ADR-0340 检查器同语义免双源 |

## 后果

- 恢复垃圾局从「打满 40min」变「~2 轮即停」;runs.jsonl 该局 result=stopped
  (last_status 带 `cw:strategy_dead_early_stop` 可溯源);
- 检查项与运行期早停阈值不同(3 vs 2):事后判读容忍暂态(≥3 才报),
  运行期求快(2 即停)——两个消费者的噪声/代价权衡不同,有意不等;
- W98 报告的 38%/55% hoard 数字作废(不可复现);后续引用一律走
  `check_overflow_gold_zero_buy_streak` 语义。
