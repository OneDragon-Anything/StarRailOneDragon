# 副本类型：饰品提取（位面饰品提取）

## 定位

自动化挑战**位面饰品提取**：进入副本后在一个差分宇宙式的小地图关卡里找到精英怪并击败，获取位面饰品。执行链为 `ChallengeOrnamentExtraction`（`src/sr_od/application/div_uni/operations/ornamenet_extraction.py`），由开拓力 app 按计划条目构造并调度。

画面建档：`assets/game_data/screen_info/ornamenet_extraction.yml`（screen_name「饰品提取」，含 存档管理 / 预设编队 两个子态）。

## 资源与计次口径

- 单次挑战消耗沉浸器，沉浸器不足时消耗开拓力（app 层 `on_oe_get_reward`：每次奖励优先扣沉浸器，再扣开拓力）。
- **战败不消耗任何资源**，因此战败路径必须有界退出，否则会无限重进（见「战败路径」）。
- 单次「开始挑战」最多选 6 连战（游戏机制，上限见 `ChooseChallengeTimes` 调用处），app 传给 op 的 `run_times` 可大于 6，op 内部按连战折算。

## 计划条目字段在本类型的语义

| 字段 | 语义 |
|---|---|
| `file_num` | 0 = 使用游戏内当前存档；1~4 = 通过「存档管理」切换到对应档案（固定位置行点击，建档 `档案-1`~`档案-4`） |
| `team_name` | 空串 = 默认配队：跳过预设编队选择，直接用该存档当前队伍；非空 = 在预设编队列表里**按名称**匹配并点击。GUI 的「配队N」选项是约定：要求游戏内预设编队就叫这个名字 |
| `support` | 支援角色 id；选择支援后入队替换 4 号位（细节见 `ChooseOeSupport` 与建档） |
| `team_num` / `diff` | 本类型不使用（diff 恒 0，难度选择未实现） |

按名称匹配而非按位置点选的 why：预设编队列表可滚动、顺序会因玩家编辑而变，按位置会静默选错队；按名称匹配（OCR + 相似度匹配，阈值见 op 代码）识别不到时会**大声失败**（重试翻页后仍找不到 → FAIL），不会点错队。

## 节点链

```
传送（is_start_node, GuideTransport 按指南传送）
  → 选择存档（file_num>0 时走 存档管理 切换并确认）
  → 点击预设编队按钮（team_name 为空 → 直接到 选择支援；非空 → 进入预设编队列表）
  → 选择预设编队（OCR 列表区域名称 → 相似度匹配点击；找不到 → 向上滑动翻页重试）
  → 选择支援（support 非 none 时）
  → 选择挑战次数（run_times>1 时按连战选择）
  → 点击挑战（开始挑战）
  → 等待副本加载（处理载入期弹窗，见下；等「大世界」角色图标消失判载入）
  → 向红点移动（SimUniMoveToEnemyByMiniMap：小地图索敌走位，不主动攻击，到位即停）
  → 进入战斗（StartFightForElite 开怪）
  → 等待战斗结果（WaitBattleResult，try_attack 兜底补一次攻击）
  → 处理战斗结果
      ├ 胜利 → 再来一次按钮 / 退出关卡按钮（按剩余次数分流）
      └ 战败 → 「大世界-战斗失败」屏：点空白继续 → 等待退出
  → 等待退出（回大世界校验）
      ├ 未完成次数 → status「重新选择次数」→ 回到 传送，整链重跑
      └ 完成或战败过多 → 结束（战败过多为 FAIL）
```

## 关键设计（why）

- **副本载入后不会自动开战**，必须走位索敌。因此战斗链采用模拟宇宙系的「向红点移动 → 进入战斗」组合；`等待战斗结果` 的 `try_attack` 只作为到位开怪后的兜底补攻击，不能替代走位（原地攻击打不到远处敌人，只会空挥）。
- **载入期提示类弹窗统一在「等待副本加载」处理**：开拓力不足 → 取消；编队角色位空缺、次数用完、角色阵亡等提示 → 点确认继续出战。这里「确认继续出战」是刻意设计：外层计划语义是未完成就重试，点取消会死循环同一弹窗；放行让战斗发生，打不过时战败计数反而成为可靠的中断器（用户定调）。
- **等待战斗结果节点不设节点级 retry 上限**：载入期的画面误判会把正常等待掐死在几次重试内，兜底交给 op 级总超时。
- **战败路径**：战败结算是「大世界-战斗失败」屏，没有 再来一次/退出关卡 按钮，唯一交互是点空白继续 → 落回 位面饰品提取 boss 选择页（全屏 UI）→ 点右上 X 关页回大世界。战败次数达到上限（阈值见 op 代码）时 op FAIL 有界退出，交由外层计划的重试语义整体重进；若不设此出口，打不过的组合会无限「重进 → 败 → 回大世界」循环。

## 边界与已知限制

- 预设编队名必须与游戏内一致才能匹配上；识别不到按名称失败，不会点错队。
- 难度选择未实现（`diff` 恒 0，op 内相关节点停用）。
- 「配队N」GUI 选项只是名称约定，游戏内编队名不同时需手动输入真实名称。
