# 银枝群攻(B 级,贝洛伯格)

> V4.4 合集 76807134:B 级。攻略直读 [77006068](https://www.miyoushe.com/sr/article/77006068)。
> ⚠️ V4.4 贝洛伯格代表 = **银枝**(非布洛妮娅;布洛妮娅/鸭鸭是通用辅助)。代码 `COMP_LIBRARY` 的"贝洛伯格召唤"(布洛妮娅 core)待改"银枝群攻"。
> 代码字段:`COMP_LIBRARY["贝洛伯格召唤"]`(待正名)。

## 机制(怎么 work)
银枝 V4.4 **离开能量羁绊**,只补偿一点攻击力 → 用"**轮椅通拐**"(5 辅助 + 符玄)强行抬。自己银枝带风套频繁自拉条。**群攻保留**(助力球提升能量回转)。

## 成型阵容
银枝(风暴潮+冷笑话+风暴潮/鞋/永动机)+ 杨叔/主角/缇宝/花火/千冶·刃(5 通拐)+ 符玄(绝对热量)+ 翡翠(3 群攻,爆伤+速度)+ 知更鸟(鸟,拉条+加攻+增伤+10% 幸运)。

## 成型节奏
1. 前中期用**椒丘 + 星期日(周日)**替老杨 + 主角;椒丘治疗 + 刃泡泡枪保生存。
2. **必须找到 3 星银枝**(否则后期伤害不够)。
3. 3 星银枝或 7 张+ → 上等级,踢椒丘周日换最终阵容。

## 装备
- 银枝**火力风暴潮 + 冷笑话引擎(+风暴潮/鞋/永动机)**。
- 符玄**绝对热量**;刃 泡泡枪+钻地弹/追逐星辰+胜利之旗。

## 弱点 / 注意
- 失能量羁绊后**几乎没有伤害增幅区** → 阿瓦隆/天地乖离开辟之星/能量转补(或能量转给银枝,鸟换周日)。
- **适合对群;长时间对单输出大幅下降**(助力球也救不回)。
- 自动战斗迷迷可能拉杨叔(需手动)。
