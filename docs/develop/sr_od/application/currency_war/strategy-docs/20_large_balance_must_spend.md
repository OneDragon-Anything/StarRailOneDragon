## 2. 富余段形式化:G_must = 10 × cap_resolved(零新自由参数)

### 2.1 界的推导(r1 应修-1/低-1/存疑-1 修订)

```
富余段(帧) ⇔ g > G_must,且该帧为有动作决策点的帧(§3.4)
G_must = 10 × cap_resolved_of_session
    ——单一源 = cw_economy.py:107 归一链(interest_cap_resolved),
    与利息线 g*、保利息结构门(arm2 参数位)同源;禁内联裸 cap(cw_economy.py:100-103

    买断制 0 ⇒ 0(不在本篇范围,见下)
```

**零利息边际论证(r1 应修-4 收窄)**:利息 = min(⌊g/10⌋, cap_resolved) ⇒ g 越过 10×cap_resolved 后,**超出 G_must 的富余金**利息收益恒为零——富余段的消费义务对象 = 该滞留段;持有富余金边际收益为零,任何期望收益非负的消费出口对该滞留段严格占优。**两处如实收窄**:①出口二层的 s_reserve 金门允许金位落回利息上限内,跨档帧利息增量 >0 可达 ⇒ 出口二层不称「严格优于持有」,沿 `17_stall_form_spend_authority.md` N4 定性 =「净成本 ≤1 金(注册表派生界)的有界成本结构改善」,严格支配仅利息增量 =0 帧;②出口三层升级收益侧零在册正账且带在册负账(P35 lv9→10 恒负/P39 L9→L10 边际 −11.4),零息论证对出口三层零覆盖——出口三层的授权纯凭裁定文号(§1/§3.1-出口三层),不罩进本论证。
