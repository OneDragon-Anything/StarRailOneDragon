# λ 基座与风险架构哲学(CW 策略核心约束,2026-09-01 定谳)

> 地位:与 math_proofs 同级的核心资产。**任何修改 λ_death 表、危险信号、战力建模相关内容的批次,动工前必读本篇**。全文级记录在 `.debug/temp/currency_war/redesign/NEW_MATH_FRAMEWORK.md` 用户裁定节 + `IMPL_LAMBDA_FOUNDATION_ATTACK.md` / `IMPL_LAMBDA_ATTACK_R2.md` / `DEATH_POSTMORTEM.md` / `P51_V3_REBUILD.md`;本篇是持久摘要与约束单一源。

## 1. λ_death 是什么:不是最重要的参数,是唯一"错了就出局"的参数

- 按**决策数量**:阵容知识(约半数决策)+经济数学(纯公式)不依赖 λ;λ 只管少数关键节点(守息 vs 转化的切换);
- 按**错误后果**:其他参数错=少赚(可恢复);λ 错=死亡(吸收态,一局清零)。期望总收益=Σ(活到 t 期概率)×(第 t 期收益)——**不压住死亡概率列,任何"贪心最优"都证不出来**(吸收态论证,先验成立,不依赖语料)。

## 2. 血与战力的关系(用户根因声明,权威口径)

- 原规矩「hp 不作策略入参」的**根本原因=我们无法对战力和胜负做准确建模,hp 只是这个根因的后果**;警惕粗略模型导致策略效果差;
- **硬闸门:仅两处被授权消费 hp/战力数据**——①λ_death 表(血带入键)②P15 掉血公式(结算屏三项)。**其他任何战力相关内容(战力/胜负建模及其衍生量)进入策略,须用户逐项确认后才能实施**;
- 进决策的从来不是"血量数值",是"这局还会不会死"的概率;血量只是它的最佳预测输入之一。

## 3. 姿态架构:发展优先默认 + 危险只升不降(安全带)

- **默认姿态=发展优先**(用户学派):经济+阵容决策做对→自然赢→血不担心。该命题的**可证形态=域命题**:当 λ×敞口×剩余视界小到二阶时,发展优先 ε-最优(ε 由 λ 上界压住);**无条件形态不可证**(吸收态论证反对)。
- **危险信号=只升不降的升档器**:血线规则=硬地板(滞后但零数据);λ 顾问=只允许把反应提前、**禁止把反应推迟**。λ 表错→最多早花(少赚),绝不会更危险。
- **两验收条件(缺一不批)**:①实现不难(独立薄层,不改七面判据本体);②**激活率门**——正确决策下触发率个位数百分比内(骨架+EV 臂 sim 实测,超标=过敏感回炉)。

## 4. 死因实证(57 死局逐局复盘,DEATH_POSTMORTEM.md)

- A 决策质量 54%(最大单一主因,用户假设成立):其中 **A1「该买不买」21 局 ≫ 买而烂 10 局**;
- B 反应缺失 32% 非零;**A1+B 同根(消费被存息/升级姿态压制,无紧急通路)=68% 单一错误模式**;
- C 不可挽 14%=预期地板;保守口径 ≥6 局(11%)"买了就显著改命";
- **设计对照**:68% 形态恰为骨架层 M1-M4 义务动作直接治;**A/B 验证判据基线=同口径复算死因分布,A1+B 塌向 C 地板=骨架生效硬信号**。

## 5. λ 表使用纪律(实证刻度,B1 形态定谳)

- 表=**PL 键(位面键:难度带×血带×位面×节点)**(2×3×2×4=48 格,空格 10 显式标空,以 P51_V3_REBUILD v3.2 主表为准;候选期名「B1」已更名防与板面档 B0/B1/B2 撞名——板面键表降对照存档;A 回归触发器:新策略产生同期板面差异语料时重评);实机刻度 0.34-0.85,**0.1 阈值在实机刻度上是死阈值**(λ≈0 段=空集)——原三段管辖路由按姿态架构替代;
- 消费=区间+保守端+单调约束(PAV);**同格亚组异质性 <0.06**(新键实测);板面维与位面共线是**语料无对照**之病(同进度无厚薄对照),非样本数之病;
- **局数少的质量门与兜底**(用户怀疑常驻记录,解除=质量门实测+用户确认):翻转面扫描带(held-out 误差、阈值扫描而非单分位锚)+四层兜底(结构规则地板/保守端/域外守息/定向补样拨盘)。

## 6. 数据通道纪律

- **实机=点火器不是燃料**:结算屏三项遥测(每局=25 轮样本)+版本更新锚(几局)+最终验收;λ 扩样/标定/sim 三臂全离线;
- **sim 战斗表与 λ 表同语料=循环**,注入对模型风险零信息——sim 只当压力测试,禁当概率来源;
- 难度值=局内读取为准(真值),公式计算值=兜底+对账(**对账持续偏差=版本改难度机制的最早警报**,白送漂移哨兵);
- 运行时监控钩子禁吃审计条件行,必须消费带身份键的必写行(ADR-0514)。
