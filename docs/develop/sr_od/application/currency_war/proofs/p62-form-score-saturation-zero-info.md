## 命题(形式化)

设指标 f: 帧 → [0,1],f(ω) = min(2, E(ω) + 0.3·Φ(ω))/2。设 Ω₀ 为
决策关键帧事件集(boss 前帧全集,n=108,及终局帧集 n=90)。**经验前提
(数据实证,非演绎)**:在 Ω₀ 上恒有 E ≡ 2 ∧ Φ ≡ 1(实测 108/108 与
90/90 帧,k=1)。

**命题**:f 在 Ω₀ 上为常值函数(f ≡ 1),故对任意结局变量 Y:

1. cov(f, Y) = 0;
2. Pearson 相关未定义(分母 √Var(f) = 0),不可计算而非为零;
3. I(f; Y) = 0(互信息恒 0)——f 对任意结局量**零预测力**;
4. 该结论与封顶口径无关:对任意 g(E, Φ),只要 g(2,1) 单点取值,
   同样成立。

## 证明

① Var(f) = 0(f 常值)⇒ cov(f,Y) = E[(f−c)(Y−EY)] = 0;② Pearson
分母 σ_f = 0 ⇒ 相关系数无定义;③ 常值函数与任何随机变量独立 ⇒
I(f;Y) = 0;④ g(2,1) = c 常值 ⇒ 同 ①-③。∎
