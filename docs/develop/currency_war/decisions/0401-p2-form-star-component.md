# 0401 — P2 胜率模型 form 星级分量(ADR-0377 扩展:core2 因果通道补建)

- 状态: accepted
- 日期: 2026-09-02
- 关联: ADR-0377(胜率模型 as-built,本批=其 form 键扩展件)/
  ADR-0399(承接档位,core2 维口径单一源)/ ADR-0400(W227 承接门,
  本批=其「复验挂账」清偿)/ W226 报告 §⑥(board_tier 微反归因)/
  W230 批(`.debug/temp/currency_war/w230_star_form/`)

## 背景(两批实证的同一 sim 建模缺口)

ADR-0377 的 form = engines + level 折算,**星级深度(core2)无因果
通道**——真实游戏星级↑=战力↑(用户口述权威),sim 打不出:

- W226:board_tier(core2 切点维)存活轮/胜场在 sim 面一致微反
  (0/3 端点单调;归因已定位为本缺口);
- W227:承接门主投资方向=星级深度,但 sim 打不出星级收益 →
  A/B outcome 面不可仲裁(ADR-0400 默认关的直接原因)。

## 决策

1. **form 同型扩展**(不改公式结构,只扩 form 键):
   `form = engines + form_level_weight·(level−6)
   + form_star_weight·star_depth`,
   `star_depth = Σ(star−1) over deployed`(上场件全量 star 口径,
   与 ADR-0399 HandoffSnapshot 的 star_sum−deployed_n 同式——纯
   state 可算,生产/sim/离线回放三面同口径,防双口径漂移)。
   线性 star_sum 形态(每颗升星等权)与 engines/level 折算同型;
   core2_count 形态被拒(阶跃语义,2★→3★ 无增量,与「星级↑战力↑」
   口述不符)。
2. **系数标定(ADR-0377 同款:真值分帧校准,方向强制+保守量级
   +敏感性)**:语料=生产 replay plane=2(44 combat 帧/6 胜,
   `calibrate_star.py` 产出 `truth_star.json`)——engines=1 桶内
   star_depth=0 → 0/8 胜,star_depth∈{1,2} → 3/15(0.20):**方向
   为正**(胜例集中于 sd 1-2);sd≥3 零胜但 n≤4 不可辨 → 量级未定,
   取保守 `form_star_weight=0.5`(一颗 2★ 折半台引擎),
   `simulate_p2_sensitivity` 网格增 `form_star_weights` 维
   (端点 0=旧 form 形态/0.25/1.0,与 form_level_weights 同型)。
   β/γ/p0 不动(本批证据不含其重估信息)。
3. **P1 零漂移结构保证维持**:form 只辖 plane≥2 战斗结算,
   P1 段(planes=1)逐位不变(锚回归实测 never2/mal 精确一致)。

## Considered Options

- **core2_count 阶跃形态(≥2 计数)**:拒——阶跃语义,3★ 无增量,
  与「星级↑=战力↑」口述不符;star_depth 线性与既有折算同型。
- **独立 star 系数(β_s·star_depth 而非入 form 键)**:拒——ADR-0377
  的 form 键内加权是单一注入点结构(β 缩放整条 form,敏感性同通道);
  加独立系数=参数族分裂,β 敏感性扫描分辨不了构成比(与
  form_level_weights 入网格同一教训)。
- **用 6 胜例点估计 form_star_weight**:拒(点估计不支持,n 太小;
  方向强制+保守值+端点扫描 = ADR-0377 同款样本贫困期姿势)。
- **等语料攒够再上**:拒——W227 承接门复验被阻塞,星级通道是
  承接门裁决的前置;保守值+敏感性带正是样本贫困期的正确姿势。

## 影响

- W226 声明的 sim 已知边界(core2 无因果通道)解除:board_tier
  维 sim 可仲裁;ADR-0399 切点维持真值面锚定不变。

  上下文随批报告披露);P1 全指标零漂移。
