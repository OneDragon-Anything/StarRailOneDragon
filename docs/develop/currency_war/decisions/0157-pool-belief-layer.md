# ADR-0157 牌池余量信念层 v0(Beta 滤波 + 缺席证据)

## Status

Accepted(2026-08-16;消费端切换待灰度;rival 定案后校准)

## Context

机制早已确认牌库有限(1/2费 27 张、3/4/5费 9 张;买掉即减、卖回回池、NPC 消耗 —— gameplay doc),但策略栈把该事实拆碎扔掉:`cw_shop_odds` 按满池算(`acquirability_factor` 实传 c=0 未接线);drought 用「本回合 shop 有无阵营卡」二值信号(`DROUGHT_BAIL` 3→5 的调参史 = 单观测回答分布问题的信噪比病)。2-2 时 3 费池真实余量可以是满池也可以被 rival 抽半,两局面最优策略不同而系统给相同决策。

## Decision Drivers

1. 同一份池信念该喂四个决策族:D 牌成本(常数 2 金 → 期望曲线)/成型概率(drought 信号)/搜牌窗口(等级 × 池况)/转型时机(沉没 4/9 追 vs 转)。
2. 观测免费:刷面是 bot 每回合已在看的画面;滤波 O(卡种 × 观测)。
3. 「像人一样玩」:人类数牌正是此行为。
4. 用户 2026-08-16 治本指示:按重设计提案 16 号(redesign/16_pool_bayes.md)落地。

## Considered Options

- **继续满池假设**(现状):拒绝 —— 机制确认书躺在 doc 里无人消费。
- **直接换 drought 计数器为后验**(跳级):拒绝 —— 先落地基与恢复精度验证(V1),消费端灰度逐个切(提案自身路径)。
- **联合信道 v1**(池总和守恒+格间竞争):v0 先独立 Beta(简单可解释 O(1)/观测);v1 为增量档。
- rival 显式建模(λ 滤波):按提案风险 1「先定案后上」—— v0 的 β 增长是聚合 rival 抽压的唯象刻画,单/共享池贝叶斯定案(P0)后校准。

## Decision

1. 新增 `cw_pool_belief.py`(纯函数):每卡 Beta(α,β) on ρ=n/a(余量比例);冷启动 = 满池先验(行为=现状,无害启动)。
2. 观测流:刷面 5 格 —— 同名 α+ / 同费他名 β+(弱,÷4)/ **缺席证据**(该费全部注册表已知卡未上镜 → β,权重 = 本刷新「应现未现」质量;目标卡从不上镜本身是余量下行证据 —— 无缺席更新则未见过的卡永远满池,恢复失效)。
3. 自身买/卖 = 确定移出/移回(`removed` 计数);`E[n]`/`P(n≥k)`(正态近似,确定性无采样)/`acquirability_prior`(余量比,消费端输入)。
4. 消费端一(D 期望成本)已给:`expected_refresh_cost` = 满池期望 × 1/余量比 —— 枯池成本爬升,「该换目标了」首次可计算。
5. V1 合成恢复测试过(提案判据:同费聚合余量误差 ≤ 真实变化 20%);枯池 D 成本 > 满池 ×2 测试锁定。

## Consequences

- 待办:drought 重构(P(n≥所需) < 阈值替代计数器)/搜牌窗口×池况/`acquirability_factor` c 通道接线 —— 每个独立灰度;P0 定案(≥5 局 rival 消耗 vs 零消耗贝叶斯因子)后校准 β 权重与 λ。
- 提案原文处理删档(redesign/16_pool_bayes.md);本 ADR 为决策单一源。
