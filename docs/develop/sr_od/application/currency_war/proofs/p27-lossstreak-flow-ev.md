# P27 · 连败期溢余金定向战力支出的 EV 序

状态:**待证明(参数化)**。骨架=P20/P15/P12 已证;卡点=Δp(levelup/囤件,连败语境)未标定。

> **v2 修订注(W774 设计批 v2,承 W777 攻击 §4 裁决)**:v1 设计把「囤件垫底」当结论、本命题补证——顺序颠倒,撤回。v2 命题形态改为**排序比较式**:溢余段支出候选按 EV 排序,囤件腿 EV = 再遇期望损失(1/q,[22]③ 数字表:5费@7-8级 60-180 轮)−息损贴现,与体系激活腿(P20 边际)同表比较;「不买」仅指纯散件([31] 既有硬约束,无需本命题背书)。本线目标件/稀有件照买照囤([21]/[13])是比较式的合法输出,不是例外。

## 命题

P1 连败 ≥2 ∧ 金>50(溢余段,[17])∧ 意向线 form 缺口>0 时:

```
EV(定向体系激活支出) > EV(同额等级支出) 且 > EV(同额囤件支出)
```

即连败期溢余金投向「当场可上场、边际羁绊贡献>0 的围栏内体系件」严格优于投向升级(非人口位例外)与囤件——连败金流重排(p1_iface_lossstreak_flow)的数学形态。

## 已证骨架

- **P20(已证)**:体系激活 e0→1 的次战边际 = 散件 1★→2★ 的 2.6-2.9×(胜率)/2.8-3.5×(Δhp)——「激活腿」的收益侧量级已立。
- **P15(已证)**:P1 V_D 收益侧口径(battle 条件伤害 11.32−0.37·rung)——连败局 hp 预算更紧,每 1 胜率的存活价值更高(收益侧被连败放大,方向有利于战力支出)。
- **P12(已证)**:P2 语境同构命题(掉血大→批口径 V_D 拒绝域收缩),本命题是 P1 连败域的平移。
- **P5(已证)**:等级支出的正道只有「搜牌概率」通道——连败期 form 缺口在意向线低费档时,等级不改当前帧胜率(下一帧才有概率收益,时序贴现)。

## 卡点与采集挂账

1. **Δp(levelup, 连败语境)**:等级在连败局的间接收益(提前 1 轮提概率)与直接收益(人口位)未在条件语域标定——与 P25 的 Δp 卡点同族,同批语料可一并出条件表。
2. **V_P2(囤件侧)**:囤件 EV = S(穿越)·V_inherit(组件/副本位面继承价值)− C;组件跨位面继承是机制事实(equipment_mechanics 卖出回装备区/牌全继承),但 V_inherit 的金当量未标定。连败≥2 局的 S(穿越)由 P28 的 S0 链给上界。

标定前设计约束:p1_iface_lossstreak_flow 只做**优先序重排**(排序判据,不做金额授权),零金额魔数——排序正确性由 P20 的已证倍数背书,金额面留白等标定。

## 检验点

- 若条件表显示连败局等级的人口位例外([33] 框架单位等上场)占比高 → 等级腿从「垫底」上调,排序表回炉。
- 与 交界帧(末窗∧连败)的辖域互斥声明在 A/B G2 护栏里验证(P1 回归不劣)。
