- 状态: accepted

## 背景

sim P2 段(ADR-0362)战斗结算回退档=恒胜率 `P2_BATTLE_WIN_P=0.11`
+ 恒掉血带 15-17;Δ池 plane=2 桶因每桶 n<5 被防饥饿守卫抹平条件性
(ADR-0362 已判「假条件化」)——胜负/掉血既不随轮次也不随板面质量
变化。W183 方向②③(采购执行/意向层修法)的收益全部经「采购→板面→
存活」传导,该链在 sim 断 → 五批(W154/W167/W169/W182/W183)撞墙,
分布裁决被阻塞。

## 决策

1. **参数化结算层**:`P2CombatCalib` 参数族(单一注入点,A/B 与
   敏感性扫描同通道)辖 plane≥2 战斗类结算——
   `win_p = clip(p0 + β·form − γ·drift(round))`,form = engines
   (deployed 口径,`_settle_rung` 同源)+ level 折算;负 = 分段
   掉血带内均匀,battle 按 r1/r2-r3/r4+ 分段,encounter/boss 独立带。
   默认实参 `calibrated=True` 辖全部 plane≥2 战斗结算(绕过 Δ池
   plane=2 合并采样);`calibrated=False` = 逐位回 ADR-0362 路径
   (池优先 + 恒值回退档)——A/B 回退对照臂。**P1 段恒不进本分支
   (planes=1 零漂移是结构保证)**。
2. **案 b 交叉校验臂**:`simulate_p2_replay_entry` + `P2ReplayEntry`
   ——从真值 P2 进场态(decisions plane=2 首行 state)直接跑 P2 段,
   **共享 `simulate_p1` 的 P2 段循环体**(经 `_p2_entry` 注入跳过
   P1 段与开局 bench 采样,单一源零复制,W186 §4 消复制形态)。
3. **headline/账本扩展**(W182/W183 判读同构):金带走量
   (p2_gold_carried)/carry 采购笔数按价格带(p2_buys_by_cost)/
   意向切换事件(p2_switch_events)/lv 到达轮(p2_lv6/lv7_round)
   ——SimResult 字段 + 批报告 headline 双层;账本 P2 战斗行披露
   `sim.p2_win_p`。
4. **事件金双臂**(K3 零样本敏感性):`event_gold='p1'|'zero'`,
   rng 流两臂同耗(同 seed 配对可比)。
5. **敏感性扫描=裁决口径**:`simulate_p2_sensitivity`(β×γ×事件金
   网格)——P2 修法的 sim 分布结论必须呈报本扫描,**带端点一致
   翻正才裁「分布级」**;过拟合警报判据=案 b 锚「贴脸」而非「带内」。
6. **检查网 +2**:`p2_loss_band_anchor`(结算值落参数化带,防结算
   层绕过)/`p2_win_rate_band`(聚合胜率 ∈ [0,0.35],防胜率模型失控)
   ——均辖 calibrated 批,uncalibrated 批恒绿跳过(legacy 档不辖)。
   变异探针锁钉死(结算绕过/胜率爆炸两形态违规必涌现)。

## 校准数字(真值来源:`w193_p2sim/calibrate_truth.py` 复跑,
`truth_bands.json` 单一源;语料=生产 replay plane=2,21 run/63 行
outcomes,未删失差分 46 对,hp_after==1 为败北地板删失样本弃)

| 参数 | 默认值 | 依据 |
|---|---|---|

| β | 0.04 | 方向由胜例 board 强制为正;量级未定(胜例 form 1.25-2.25 vs 全体 ≈1.4 几乎无区分度)→ 保守值 + 敏感性主扫参 |
| γ | 0.02 | 轮梯度未识别(弱);r4 带 > r2 带给量级上界 |
| form_level_weight | 0.25 | level 每级折 0.25 引擎(未标定,保守) |
| band_battle_r1 | (14,28) | 未删失 n=6,实测 14-28(**W186 设计文本的「r1-r2 带 −4~−16」系 r2-vs-r1 相邻差分口径,不含 r1 自身——实测 r1 明显更重,分立成段**) |
| band_battle_early | (4,16) | 设计口径带;未删失样本 15/15 落内 |

| band_encounter | (9,18) | 设计口径带;未删失 18 落内 |
| band_boss | (21,26) | 设计口径带;样本均地板删失(真损 ≥ 带端) |

**诚实边界**:这是参数化校准层不是真战斗机制(sim-testing
「校准层逐步换真机制」);语料只够钉边界不够点估计 β——敏感性带
扫描是裁决口径。Δ池 plane=2 条件化(键 form×round,每桶 n≥5)
留 Phase 3 自动让位(语料阈值触发,非日历)。

## Considered Options

- **直接扩 Δ池 plane=2 条件化分桶**:拒(现语料每桶 n<5,ADR-0362
  已判假条件化;参数化模型顶,Phase 3 语料到量自动让位池采样)。
- **独立 simulate_p2 主入口**:拒(双源漂移;案 b 臂是唯一例外=
  经 `_p2_entry` 注入共享 P2 段循环体的小入口,ADR-0362 预留 M2)。
- **等语料攒够再上**:拒(W183 ②③ 裁决当前被阻塞;参数化+敏感性
  带正是「样本贫困期的正确姿势」,带扫描即裁决纪律)。
- **用 21 run 点估计 β**:拒(点估计不支持;胜例 form 分布与全体
  几乎无区分度;方向性+敏感性带+留出核验)。
- **掉血带沿用 W186 文本的「r1-r2 一段」**:拒(本批实测 r1 跨位面
  差分明显更重于 r2,分立 battle_r1/battle_early 两段;设计文本口径
  系相邻差分不含 r1 自身——实现偏离设计处在此显式记档)。
