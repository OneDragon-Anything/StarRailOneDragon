# 遗器-替换(relic_replace)

> source_image: sr-od-test/screens/遗器-替换/default.webp(2026-10-17 live 建档,黑塔头部遗器详情)
> id_mark lcs 已收紧至 0.7(与「角色-遗器」的「遗器着装」撞车,live 实测并修复)

## 何时出现

「角色-遗器」屏点任一遗器件(或替换按钮)进入。独立屏(整体布局,非 overlay)。
显示:左侧=该部位可用遗器网格(该角色持有+背包),中=选中件大图,右=选中件完整词条。

## 状态流转

```
角色-遗器 点遗器件 → 本屏(默认部位=所点件;顶部部位 TAB 可切 6 部位)
右上返回 → 回「角色-遗器」
卸下/重掷 → 有副作用操作,扫描 app 禁触
```

## 识别特征

- id_mark「标题-遗器替换」[85,25,205,75],lcs_percent=0.7(live precise 实证)

## automation 要读信息

- 读区-遗器名 [1478,158,1905,218]:OCR(如「翔鹰的鹰击指环」)
- 读区-部位等级 [1478,218,1700,300]:部位名+「+N」两行 OCR
- 读区-主词条 [1478,305,1905,360]:主词条名+数值(橙色高亮行)
- 读区-副词条 [1478,360,1905,525]:最多 4 行「词条名 数值 (强化次数)」——绿色小数字=该词条强化次数(OCR 可读)
- 读区-套装效果 [1478,530,1908,705]:套装名(N)+效果全文
- 网格内每件:+等级徽标+锁定锁标+穿戴者头像角标(视觉/模板;穿戴者角标=该件已被其他角色穿)
- 5 星/品级:卡片底色金/紫(视觉)

## 注意

- **卸下/重掷/替换/装备类按钮一律禁触**——本屏存在真实副作用操作,扫描 app 只读不点
- 副词条不足 4 条时行数减少(未满级遗器);词条强化次数绿标 = 判定「歪没歪」的关键数据
- 部位 TAB 图标无文字,固定坐标点击已建档(部位-头部…连结绳 6 区)
