# 战斗结算（挑战成功 / 挑战结束 / 挑战失败）

## 货币战争-结算

### 画面简介

单场战斗打赢后的结算画面，两种标题形态同一画面：「挑战成功」（普通胜利，归档帧 win）或「挑战结束」（帧例 1-9 首领、小队生命值 1）。内容布局（按归档帧）：中上标题 + 关卡号/「首领」标签，左侧「小队生命值」读数与等级，左下「获得金币总览」面板（基础奖励/利息/连胜/掉落晶矿 各行 + 总数），右下「数据统计」面板（逐角色伤害列表），右上金币存量，底部居中「继续挑战」按钮。目标：领结算信息回备战。

### 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 按钮-继续挑战 | 底部「继续挑战」按钮（画面身份锚之一） | 点击领结算回备战（静态点击有效） |
| 标识-获得金币总览 | 「获得金币总览」面板标题（画面身份锚之二） | 纯显示 |
| 标识-挑战成功 | 「挑战成功」标题；只在胜利态出现（与「标识-挑战结束」同位置互斥，各自只认自己的词） | 纯显示 |
| 标识-挑战结束 | 「挑战结束」标题；只在本轮战败或平局式结束态出现（仍有「继续挑战」，对局未终） | 纯显示 |
| 标识-首领 | 关卡号旁「首领」标签；出现 = 本场是首领战 | 纯显示 |

## 货币战争-挑战失败

### 画面简介

单场战斗团灭（小队生命值归零）时的失败结算画面：红色「挑战失败」大标题，标题下「小队生命值」读数（团灭时 0），其下对局评价徽章（终局团灭帧例：C），底部居中「下一步」按钮；本画面无金币明细/数据统计面板（按归档帧）。

### 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-挑战失败 | 红色「挑战失败」大标题（画面身份锚之一） | 纯显示 |
| 按钮-下一步 | 底部「下一步」按钮（画面身份锚之二） | 点击进后续结算页（团灭/位面结束结算链） |
| 文本-小队生命值 | 标题下「小队生命值 N」读数；团灭时为 0 | 纯显示 |
| （待建档）对局评价徽章 | 标题下方菱形评价徽章（帧例：C）；终局团灭帧上出现，单场战败是否恒出现待采样 | 纯显示 |
