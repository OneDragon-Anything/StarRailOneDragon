## 背景

W285 按字段抽样判读 obs_conflict 存证(43 张)定位两类可修病灶:

1. **star 层(724 张)**:read_star 会采在 3合1 合成星爆动画/拖拽合成过渡窗内(抽样 2/2 采新帧全错:a61848f0 星爆窗读 1★ 应保 2★、46d292eb 拖拽过渡同样)。既有「连续 2 次回退才采新」防抖(2026-08-18)管住了单帧疑云,但动画窗**可持续 ≥2 帧**——窗内第 2 帧照样构成假「连续确认」→ 采新 1★ 毒化 tracking。
2. **cap 域(W285 #41)**:e4972b43(2-2,paddle 12/13 + 经验面板 Lv.8/2-72 双读数实锤 + 后台 9 格实画)= diff=5 **真实高档**;旧域 `level ≤ cap ≤ level+2` 把它拒信 → `resolve_back_slots` diff=0 退 **6 槽基线在 9 格板上跑**(W285 指认的「6 槽降级错误兜底」)。

同批布局档复核结论(修订 ADR-0281 复核,不改其幻影清除决策):

- **7 槽 levels 集 = ∅(死档确认)**:lv6/cap6→6 格(2a55bb42)、lv6/cap8→8 格(9d64caf0)、lv7/cap7→6 格(5dd027ab)——三帧无一落 ADR-0281「level 驱动 7 格」预测,全部与 ADR-0385 公式 6+(cap−level) 自洽;7 格档由 cap 差驱动(diff==1)已落地。
- **7 档坐标校正数 = 0**:37fa3b88(1-1,7 格)空槽暗框实测中心 676/960/1244 与已登记 后排7槽-2/4/6 逐位吻合;系统单位狸猫实测 x=1402 vs 7 档右心 1386 差 **16px** ≤ 40 容差。W285 记的「~40px 偏差」对象是当时**运行选档(8 档右心 1458,差 56px)**——属选档瞬时不一致(系统单位自检按设计留证),非坐标错。
- **后台 9 格档暂不登记**:e4972b43 实拍 9 格,几何与居中重排族自洽(暗框/占位 std 剖面峰落 392..1528、pitch 142),但①选档无通路——公式封顶 8、CV 端点探针(464/1458)在居中重排下仍落 8/9 格共有槽带,单值 std 分不开 8/9,外缘探针受占用态干扰单帧不可标;②坐标仅单帧静态剖面、无交互实锤(布局/坐标建档唯一终审=交互实锤)——登记即重蹈 ADR-0281 幻影档覆辙。`_PENDING_7SLOT_LEVELS` 类留证机器确认已随 ADR-0385 清除(grep 零活代码)。

## 决策

1. **合成特效帧态门**(`cw_identity_obs.is_merge_effect_frame`,纯 CV、无 ctx 依赖):星爆粒子签名(前排带严橙金窗口 `_PREVIEW_GOLD` 复用,连通域 ≥9px 计数 ≥3;标定:星爆帧 8 个/负样本 4 帧全 0)+ 满席警告横幅签名(横幅带 R−max(G,B)>40 占比 ≥0.06;标定:拖拽帧 0.138/负样本 ≤0.013)。
2. **与回退防抖合并方式**:`reconcile_tracking` 采新确认分支前置本门——特效帧 → 保旧同首次分支且**防抖计数冻结不推进**(非清零:门后干净回退帧仍可确认);门漏检退化为 W292 前防抖行为(门是加强不是替代),异常 → False 不拦。
3. **cap 域外双帧一致采信**(`read_deploy_cap_debounced`):域外值重读一帧,两帧一致且 `level ≤ cap ≤ DEPLOY_CAP_ABS_MAX=13`(实拍板面上界=前台 4+后台 9)→ 采信 + obs_conflict 留证;cap<level 恒拒、超绝对上界拒、两帧不一致拒(瞬时误读族防线不降级——12 槽误档事故 8a56db39 族无两帧一致实证)。域内直采路径不变。
4. **max_units 封顶 10 不动**(front4+back6 是策略/sim 建模面):cap 采信 13 后 `GameState.max_units` 仍按建模板面封顶——扩板属策略批(sim 须同步建模,新字段三消费面纪律),本批只修观测层降级错误。

## Considered Options

- **帧态门挂 read_star 内部**:拒绝——read_star 是纯函数吃 crop,帧态是全帧行为;挂消费裁决点(reconcile)与 W287 `is_prep_like_frame` 挂裁决位同构。
- **特效帧判据用 OCR(横幅文字)/屏幕判定**:拒绝——贵且「备战席已满」无独立 screen 档案;颜色签名 4.6×-2.3× 双向余量已够「加强门」定位。
- **DEPLOY_CAP_MAX_DIFF 直接 2→5**:拒绝——把历史误读族(8/8→12,ADR-0286 立门对象)放进单帧可入域范围,防线降级;「两帧一致」采信保住瞬时误读拦截,真实高档(e4972b43 形态在备战期静态持续)双帧必一致。
- **登记 后排9槽-1..9**:拒绝——无选档通路 + 无交互实锤(见背景);登记不可选的档 = ADR-0281 幻影档同型。闭合路径(交互实锤 + CV 外缘判别另标)记待办。
- **逐张消化 star 层 724 张**:拒绝——W285 已裁「回退防抖类 verdict 方向正确」,帧态门 + 防抖合并即治本。
