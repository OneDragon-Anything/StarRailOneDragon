## 二、设计件核对结果

### 根因 1:判定 = 已吸收(结构层覆盖;两条条件性退化通道已申报,非缺口)

**条款指针**(均在 IMPL_DESIGN,登记证明在 IMPL_FIX_LEMMAS):

1. **§2.7 换线(P16)落位证明层 `proof/line_selector`**(R1-3:总纲§5.2「证明层:证据门+换线+停手线」)。`should_switch()` 判据式 `E(alt)·(1+δ)+θ < E(cur)·(1+δ) ∧ 驻留≥D_min`,E_rounds=distance/per_round 超几何精确口径。
2. **接线义务(§2.7 第二条)**:「`should_switch_e` 生产零调用点是旧层缺陷」——proof pass 内**每备战期无条件调用一次**,产出换线事件;**不换线也记遥测**。这正是旧病灶「转型从未成为决策对象」的直接反面:转型在新设计是每备战期持续在评的决策对象,P2 r1 备战期即在评估域内,不存在「入口缺位」。
3. **K 变更下一备战期生效**(R1-3)+ 塌缩卖出 `line_switch_sell` 在 K′ 生效帧评——换线动作的时序闭合,消「锁了线但执行脱节」(082322 P2 r1 的 evolve vs locked_comp 脱节形态)。
4. **R9-1(§4.2.1 枚举表补行)+ R11-3(signal_arm 行)**:换线机函数位入唯一权威完备性表,臂①旁路规格显式——「换线机器整块空缺/死参」的旧层形态在设计件里有明确函数位与验收锚(§5.3 P16 双态锚:标定期断言评估调用计数>0)。
5. **初始 K 的产生**:证据门 P38 比较序从 comp 库选 K(§2.9 阵容行/状态机 S0→S1→S3),直通线走信号直锁边(§2.7.1)。即「终局选线」在新设计不是换线机独担——证据门本身就是终局线选择入口,换线机是其后的每期修正。

**覆盖度评估**:结构性覆盖完整——入口存在(证据门初始选线)、持续在评(should_switch 每备战期)、动作可落地(K 切换时序+塌缩出口)、可观测(不换线也记遥测、六因分键)。旧根因「从未成为决策对象」在设计语义下构造性不可达。

**两条条件性退化通道(设计已如实申报,列此供判读,不算缺口)**:

- **θ/D_min 标定前 fail-closed**(R23-5/R24-2):θ 缺省 None ⇒ should_switch 不评估、K 冻结,记 `θ_unavailable` 独立遥测——标定批(对拍 2 θ 通道)完成前,**P2 转型在实跑中仍不会发生**,且这是申报过的设计内退化域(与 R13-1①「出口不可用 ⇒ K 冻结」同构,退化=L-B2 已接受的有界缺件补齐)。判读首批 sim 时须按分键归因,禁读作换线价值证伪。
- **窗口期换线门槛被 R36-1 显式抬高**:P2 属「未揭晓位面窗口」(P3 未揭晓,默认局窗口≈P1+P2 全期,R19-1),窗口帧换线式右端加滞留成本 C_stay——方向与复盘诉求「P2 r1 应尽早开终局线」**相反**(更严不更松)。这是新设计基于 R31-2/R33-2 卖出 fail-closed 定价的主动权衡(窗口换线=必付成本换趋零收益),不是漏吸收;但其后果(P2 内换线事件系统性稀少)与 101653 死因链同域,**建议首批 sim 判读时单列「窗口期 K 冻结与 P2 板面星级停滞」的联合观测**(§5.2 已有域外冻结/滞留槽位遥测,可挂)。

### 根因 2:判定 = 已吸收(且属「旧层 bug、新设计按不同语义处理」)

**条款指针**:

1. **§2.7 `stop_buy()` 行 + §1 line_selector I/O 行(R4-F8 显式函数位)**:成型判定=「**K 目标线**单位齐备 ∧ 无待补缺口」——度量对象**单一锚定当前生效线 K**,不存在旧层的双对象结构(form 度量过渡配方 / gate 作用在终局板面)。
2. **谓词语义钉死(R10-5,IMPL_FIX_LEMMAS 行 393)**:stop_flag=「当前线 K 成型」的分类谓词输出,评估对象恒为当前生效 K、逐备战期随 M2 分类重评;求值时点定死(R11-1)=每备战期证明 pass 后、M2 分类前。**破成型重置条款**:K 不变、外因使单位齐备翻假 ⇒ 重评即归 0(消「锁存恒 1 压制至局终」)。
3. **重置时点定谳(R9-2,修订 R8-7;IMPL_FIX_LEMMAS 行 348/353 引理)**:换线后 K′ 生效帧 line_switch_sell 调用返回即重置(结论∈{卖,不卖,强制停,延迟}任一均算已评估),与塌缩执行解耦;压制窗=仅登记帧(有界=1 帧)。R9-2 修的正是「重置绑在可无限推迟事件上 ⇒ 旧值=1 无限保持 ⇒ 新线买入被无限期压制」——与 101653「满型停手压制后续消费」同族病灶的时序面。
4. **消费语义定谳(R5-6,IMPL_FIX_LEMMAS 行 241)**:stop_flag=**分类谓词输入,非拦截门**——线成型只是把过渡/通用插件**重分类**为非线内、落出 M2 序 1/2 辖域,它们**进入序 3-5 EV 域,受 ev_buy_veto 正常管辖仍可买入**。这正对应复盘建议的「消费 gate 应回落为终局件/星级/装备优先而非停手」:新设计里停手根本不构成对 EV 域的全局消费封锁,M2 义务对线内件的买入也不被任何证明层信号拦截(§3.2 四硬约束封闭集,stop_flag 不构成第五硬约束)。
5. **验证锚(R19-5)**:stop_buy 成型判定本体锚补进 §6.4 测试位(此前只测时序/重分类,不测翻真判定的正确性——R19 攻击发现后已补)。

**覆盖度评估**:覆盖完整。复盘建议的两半(「判据加终局配方前置」「gate 回落而非停手」)分别由「谓词锚定当前 K」与「R5-6 重分类非拦截」承载,且比建议更彻底。

**语义差如实区分**:旧层的病灶载体是「form(过渡配方完成度)独立于锁线存在、并作为 spend gate」——这个对象在新设计里**不存在**:过渡配方只剩 M5 开局形态的消费位(K 未定时按 TRANSITION_SYSTEMS 执行,§2.9),不产出任何 gate 信号;K 是唯一目标线,停手谓词与消费 gate 同锚 K。因此本根因不是「新设计修好了旧判据」,而是**旧判据的度量对象被架构性移除**。残余同构面仅一条:若换线机休眠(θ 未标定/出口不可用)导致 K 长期停在次优线且该线成型,停手重分类仍会压制非线内件的序 1/2 买入——但这在账本上归「K 冻结」(根因 1 的退化通道)承载,不是 stop_flag 自己的病,且窗口期非线内件仍可走序 3-5 EV 域。
