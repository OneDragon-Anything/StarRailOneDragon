## 总模型:羁绊引擎的乐高

过渡阵容 = **羁绊引擎的组合**(凑出≥2 个引擎;单引擎只是"过渡的过渡")。
每个引擎是独立伤害/经济源,凑够人数即转,组合方式自由(加法,不换件)。

### 引擎池(按验证强度排序)

| 引擎 | 门槛 | 机制(羁绊文本) | 数据 |
|---|---|---|---|
| **DOT2** | 2 人 | 敌方行动触发超激发结算持续伤害(敌回合白嫖伤害) | 194 篇 |
| **列车2+** | 2 人 | 召唤星穹列车撞击+光轨全场增益 | 217 篇 |
| **仙舟3** | 3 人 | 召唤神君;仙舟队员行动叠段并提前神君 | 167 篇 |

**三大引擎两两组合都成立**(攻略原文「2DOT+2列车 或 2DOT+2贝洛伯格」
「3仙舟+2DOT / 4列车」):仙舟3+DOT2(81)/仙舟3+列车2(41)/列车2+DOT2(31)。

### 共享核心池(三引擎通用的角色)

| 角色 | 功能 | 机制根据 |
|---|---|---|
| 丹恒·饮月(2费) | **输出+双阵营枢纽**(喂仙舟叠段+列车撞击) | Front 输出;仙舟+列车双阵营 |
| 爻光(1费) | **叠段发动机** | 普攻 200% 速度行动(多动=神君叠段×2)+欢愉技直接拉神君条 10-25%+天赋全队追伤 |
| 藿藿(1费) | **仙舟∩治疗唯一交集**(一人占两功能) | 仙舟阵营+治疗羁绊 |
| 三月七(1费) | 列车+护盾双挂(列车线的"藿藿") | 列车+护盾双阵营;领航员反震体系 |

凑数池(双羁绊挂件,谁在场买谁):椒丘/艾丝妲(DOT+各自第三羁绊)、
腾荒(夜半+护盾)/赛飞儿(夜半+追击+减益)/星期日(列车+盛会+能量)。

### 渐进升级路径(加法不换件)

```
阶段0: DOT2(任意2件,开局即战力——"过渡的过渡")
阶段1: +饮月(双阵营枢纽,两线开喂)
阶段2: +藿藿+爻光 → 仙舟3 成型(神君引擎全速)
阶段3: +三月七 → 列车2 挂上(混挂完全体:仙舟3+列车2)
终局桥: +姬子·启行 → 切终局线(领航员羁绊:复制三月七首件装备=反震启动)
```

### 装备语义(过渡期)

- **简易装备**:随便给(饮月优先)——回收沉没成本≈0
- **合成装备**:不为过渡特意合成;仅当产物 ∈ final key_equips 且过渡能用
  → 提前合成先穿着(合成件跨阶段保值)
- 攒装备(transition_hold)只对**合成材料**成立

## 直通族(终线自带引擎时,终局 core 即过渡件)

三条线三种结构,不能用一个模板套(逐篇读的实证)。

### 希儿线(技能自带输出型)

- **核心 = 希儿一人**(技能层自带顶级倍率:战技+120-600%/终结技+240-1200%;
  斩决处决:敌生命<9-15% 直接触发等同生命的量子伤害)
- **引擎:量子3 或 贝2 都行**(羁绊只是放大器,凑到哪个算哪个,不设完全体门槛)
  - 量子=易伤+同频扩大斩杀线(线性,稳)
  - 贝洛伯格=造物引擎满能拉条"伤害最多者"(=希儿)立即行动——**乘法**
    (拉条正循环),上限更高但 Early 仅 8 篇(贝件贵)
- **成型判定 = 引擎达成**(量子3 或 贝2),**未成型前照常走通用引擎池**
  (希儿在手只是场上强单卡,不算开线)
- 池:量子(缇宝/符玄/花火) 贝(娜塔莎/佩拉/桑博)

### 圣杯线(经济任务系统型,4.4 新)

- **信号**:圣杯契约(**完成两次试炼固定得 Archer**——官方 portal 文本)
  > 圣杯星徽(试炼概率给红A) > 试炼奖励见红A
- **前期无独立战力**:通用过渡 + 圣杯三件**留牌不上场**(各留一张);
  圣杯2 = 开祈愿试炼吃奖励的经济挂件
- **试炼系统**:圣杯2/2 一次、3/3 再一次;任务二选一。
  已知任务:理想乡之庇护(三场无禁战→阿瓦隆)/金色传说(2星闪闪过三场→
  天地乖离)/刷新20次→Archer/金币类/盾丹类。天胡=无限之釜(全奖励)。
  选择优先级:**Archer > 金币 > 星徽**
- **双 C 接力**:Saber 前中期 C(满能自拉条伪永动)→ Archer 到手接棒
- **能量不可拆**:「哪怕下远坂凛都不能拆能量」(能量5 硬约束)
- ⚠️ bot 补档空白:试炼全量枚举/任务条件检测/改件系统/已领奖励进 state
