# 货币战争-投资策略

## 画面简介

投资策略三选一画面，时点出现：v4.7 常规局位面 1 内有 2~3 次（≈1-3 / ≈1-4,5 / ≈1-7,8 时点），位面 2 亦有 2-1 / 2-2 等时点。画面结构（按归档帧）：顶部标题「请选择投资策略」+ 三张策略卡横排（每卡下方独立「刷新次数N」计数 + 圆形刷新钮）+ 底部「确认」+ 右上「返回备战界面」。选一张策略确认后生效整局。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-请选择投资策略 | 画面标题「请选择投资策略」（画面身份锚） | 纯显示 |
| 按钮-确认 | 确认当前选择 | 策略生效、画面关闭；置灰 = 未选中（op 重跑仍不行则亲自读图核对点位） |
| 区域-卡名行 | 三张候选卡的卡名横带；候选名列表另由识别层返回（extras.strategies = 候选名列表） | 纯显示 |
| 区域-刷新次数行 | 每卡独立的「刷新次数N」计数横带（逐卡独立扣减，0 = 尽，灰置仍可读） | 纯显示；刷新点击落在各卡圆钮（见操作） |
| 图标-策略卡1 | 左侧策略卡的六边形图标区——选中点击的有效落点（点标题/文字区不选中） | 点击选中该卡（白框亮起） |
| 图标-策略卡2 | 中间策略卡的六边形图标区（同上） | 点击选中该卡 |
| 图标-策略卡3 | 右侧策略卡的六边形图标区（同上） | 点击选中该卡 |
| （待建档）按钮-返回备战界面 | 右上角「返回备战界面」按钮（归档帧可见，未建 area） | 跳过本次选择回备战；会带出暗色锁定态，回备战后按「货币战争-备战-暗色锁定」卡先解锁 |
| （待建档）候选品质 | 卡框颜色 = 品质档判据：银白/金/棱彩（粉紫渐变）/灰白四档并存，判品质一律以当帧卡框为准 | 纯显示 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 选中并确认一体 | MCP op `CwPickInvestStrategy` | `{"card_index":1..3}` | 卡片白框亮起 → 确认后策略生效、画面关闭 | 内部 = 点卡片**六边形图标区**选中（点标题/文字区不选中）+ 确认微距拖拽；extras.strategies 长度 ≠ 3 时不要用 op（卡数变了，退坐标点击并反馈更新图标区）；确认键置灰 = 未选中（op 重跑仍不行则亲自读图核对点位） |
| 手动选中某卡 | MCP `click_game` | 「图标-策略卡1/2/3」area 中心（识别返回坐标） | 白框亮起 = 选中 | 点六边形图标区才选中；点标题/文字区不选中 |
| 手动确认 | MCP `click_game`（无效时微距拖拽兜底） | 「按钮-确认」area 中心 | 画面关闭、策略生效 | 置灰 = 未选中 |
| 跳过本次选择 | MCP `click_game` | 右上「返回备战界面」（无 area，读图定位；待核对） | 回备战 | 会带出暗色锁定态，回备战后按「货币战争-备战-暗色锁定」卡先解锁 |
| 逐卡刷新（每卡独立） | MCP `click_game` | 圆钮 = 该卡计数文本中心 x−88、y 同高（三卡计数文本 ≈x{477,975,1474}、y≈855 → 圆钮 ≈x{389,887,1386}；圆钮无独立 area，源码挖掘、待实机核对；计数行定位用「区域-刷新次数行」area） | 该卡候选重掷、「刷新次数」减一 | 计数逐卡独立扣减，0 = 尽（灰置仍可读）；flow 层有专用 op，agent 手动等价 |
