# ADR-0436:撤销出口①的意图证据三条件合取——N_req 闭式替代拍死计数

- 日期:2026-08-29
- 状态:accepted(设计=唯一规格:`docs/develop/currency_war/prereg/w396_r2r3_design/DESIGN.md` R3 节;攻击来源=W393 A3)
- 关联:W386(BP1 辖域空集定位)、W379(C4 门 v2 接线)、ADR-0429(C4 门接线与 0 触发诚实结论)、`cw_intention.py`(出口①本体)、`decision_v2/registry.py`(ε/A_min 常量)

## Context(为什么)

W386 BP1 实证:撤销出口①的拍死阈值 `CORE_MISS_N=6` 把「核心短时缺货」的正常噪声成批送进撤销——6 轮缺席在 3 费核心单轮出现率 q≈0.07 下的自然概率 ≈(1−q)^6≈0.65,纯属噪声;一旦阈值降到 P2 可达值,先到达的是出口本身,门放行「活得到但换了更亏」的噪声换线(危害搬家到 C4 门下游)。W379 诚实结论:default 关下撤销出口 0 触发是「锁定即持有」教义的体现;出口的合法形态是「不可得前提被证据否定」,而计数猜测不是证据。

## Decision(逐条)

1. **三条件合取(缺一不开窗)**:出口①开窗须同时满足 ① miss ≥ max(CORE_MISS_N, N_req);② 存在异线 comp 核心可达(复用出口②的 `_core_reachable`,不造第二把尺);③ 该异线资产厚度 ≥ A_min。CORE_MISS_N 保留为上限保险(防牌池数据异常使 N_req 过小)。
2. **N_req 从再遇窗口期望闭式推导**:`N_req = ⌈ln ε / ln(1−q)⌉`,q=1−(1−r)^5、r=refresh_prob(level,cost)/DISTINCT_CARDS_PER_COST[cost](全部复用 `encounter_window_rounds` 既有构件)。ε=5%(「可达却连续缺席」压到二十分之一以下才构成断供证据;sim 扫 {1%,5%,10%} 挂 L2 注入臂)。实表代入:3 费@lv5 q=0.069→N_req=42,3 费@lv7→21,1 费@lv5→27——阈值随核心费用/等级自适应,消除同一名义阈值跨费用的语义漂移。
3. **A_min 用测量而非拍值**:冻结池(snapshot_v11)100 局、P2+ 决策帧分母、异线厚度频率曲线 f0(a) 的 5% 点。实测 f0(4)=7.68%>5%、f0(5)=1.27%≤5% → A_min=5(协议与对照曲线见 registry 注释与 `a_min_measurement.json`)。**分辨力弱声明**:5% 点落在设计预案的「≥4=证据分辨力弱」带,按设计如实降级记档,回炉裁决挂误开窗占比判据(开窗局新线成型 ≥2/3),不调参硬凑。
4. **可测性三层,生产阈值零动**:L1 单帧状态机锁(`test_cw_w423_revoke_evidence.py`:合取四分支/N_req 代入例/A_min 边界/遥测证据字段);L2 registry 注入臂(`dataclasses.replace` 两参数,off 臂与 W379 off 臂逐位=零漂移锚,实测 30 局逐位相等);实机锚点=开窗事件携带证据字段(`IntentionState.revoke_evidence` 经 serialize_intention 落遥测,无证据字段的开窗=守卫失效即报警)。
5. **误开窗操作定义与判据(挂 A/B 注释,不执行)**:开窗局到局末未发生「新线落锁且新线最终成型」=纯扰动;判据=触发率>0 且逐例带证据字段/开窗局新线成型 ≥2/3/开窗局 P2 存活轮数分布不后移(C3 无效判据口径,不后移则如实记结构件)。

## Considered Options

- **保留拍死 CORE_MISS_N 单条件**(W386 的降阈值方向):被否——噪声成批进撤销的病灶本体,6 轮缺席自然概率 0.65 定量坐实。
- **只调小 CORE_MISS_N 对齐位面预算**:同上,危害搬家不消除。
- **单条件 N_req 闭式(无证据组 B)**:不采——统计断供只回答「缺了多久不像噪声」,不回答「有没有另一条线在生长」;后者是换线意图与断供噪声的区分变量(W393 A3.3)。
- **A_min 按「≥2 件当量」直觉拍值**:不采——1 件在场是顺来牌常见事件无证据力,而实测基线曲线 5% 点在 5,直觉值会把纯随机板面当意图。

## Consequences

- **正面**:出口①从计数猜测升级为统计证据+替代资产证据,撤销更难而非更容易(与「锁定即持有」相容方向为正);阈值自适应消除跨费用语义漂移;误开窗有量化判据可回炉。
- **负面/边界**:N_req 在 3 费低星档达 21-42 轮,超出 P2 位面预算——出口①在生产对局中结构性更难触发(与 W379 的 0 触发现状同向,非回归);证据组 B 分辨力弱的回炉悬而未决;L2 全量 A/B(n=300/臂)需牌池 fixture 注入臂使「异线厚度 ≥ A_min」帧可控出现,自然 sim 在 ε=0.9/A_min=3 的注入下仍 0 触发(50 局实测)——fixture 臂挂账。
- **零漂移**:生产路径唯一变化是出口①判别式收窄(触发集 ⊆ 旧触发集);30 局 sim 行为逐位比对相等(剥除本批新增的 `revoke_evidence` 遥测字段后);C4 门及其阈值零改。
