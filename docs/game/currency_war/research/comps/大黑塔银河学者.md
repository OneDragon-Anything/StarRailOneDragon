## 打法主线

- **augment 定义型**:拿到「黑塔纪元」(棱彩:216 张黑塔入商店 + 追击转圈)即玩;无它时靠银河学者羁绊本身(星级总量成长)亦可成型,强度降档。[社区:plaza]
- 大黑塔(4费)carry,3星率 0.82;节奏两派:**1-3 直接 D 干**(见小黑塔全拿)vs **直接上 7 拉人口**(216 张池深,不必低级久留)——共同点是小黑塔必拿、F 键一下都别碰。[社区:plaza 帖文]
- **黑塔纪元特型**:备战席囤小黑塔(强度 = 小黑塔合计星级,「备战席放满越多越好」)—— bench 语义特例。[社区:plaza]
- 记忆主必拿(「记忆主一定要拿,后台花火防战技点不足」);后期可上花火补战技点。[社区:plaza]
- 缇宝/砂金必拿并尽量升 2星(前置生存)。[社区:plaza 帖文]

## 装备分配

- key:高周波电锯 / 永动机 / 蓄能帆 / 电光履。[社区:plaza]
- **分角色**:大黑塔 = 充能三件(永动机+电光履+蓄能帆拉满启动);小黑塔 = 输出(双电锯 + 星级手册)。[社区:plaza 帖文]
- 怪跑得快 → 双电磁枪知更鸟抢启动;双泡泡枪刃/符玄来之前用群攻生存位(丹恒·腾荒/风堇)。[社区:plaza 帖文]
