# 大地图(large_map)

导航地图界面。查看星球 / 区域地图、选传送点传送、星轨航图切星球。**不锁光标**(`pc_alt=false`)。

## 何时出现 + 状态流转

- **入口**:大世界按 `m`(game_config `key_open_map`)→ 大地图(主区域/星球地图态)。
- **出口**(动作 → 下一态):
  - 区域列表 / 地图选传送点 → 「传送」→ 加载 → 落目标大世界。
  - 「星轨航图」→ 切星球(停留大地图,星球名变)。
  - 进子区域(城区)→ 子区域态(出"子区域-返回/关闭")→ 返回回主区域。
  - ESC → 回大世界。

## 识别特征(稳定锚点)

- **标题-导航**(text "导航",pc_rect 98,32-150,64):左上标题锚点(analyze 0.998)。
- **星轨航图**(text "星轨航图",1580,140-1750,180):切星球入口锚点(0.999)。
- **图标-开拓力**(template `tp_icon`,1585,30-1660,106):右上开拓力图标(0.916)。
- `pc_alt=false`。
- 易变:星球名 / 区域名 / 楼层、开拓力数字、传送点解锁状态。
