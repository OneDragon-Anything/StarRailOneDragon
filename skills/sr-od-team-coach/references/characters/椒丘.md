# 椒丘（火·虚无·5星）

> 按 V4.7 期撰写。负面体系第一虚无位：每动必挂负面 + 结界放大终结技；体系见 [黄泉负面队](../teams/黄泉负面队.md)。

## 一、命途属性与技能说明

**命途**：虚无（为黄泉「奈落」计数；自身挂负面频率=黄泉充能速度）
**属性**：火

| 技能 | 说明 |
|---|---|
| 普攻 | 单体火伤（击中挂烬煨） |
| 战技 | 单体+相邻火伤；击中敌人挂【烬煨】 |
| 终结技 | 消耗能量100【官：HoYoWiki 口径】；展开结界——结界期间敌方受到的**终结技伤害+15%**，敌方行动也叠烬煨层 |
| 天赋 | 普攻/战技/终结技击中敌人挂1层【烬煨】（易伤，满层≈35%），有100%基础概率 |
| 秘技 | 进战全体挂烬煨 |
| 额外能力 | 「举炊」：效果命中>80%时每超15%→攻击+60%，上限240%；「爟火」开局回15能 |

**资源与循环**：标准能量→**充能绳有效**（结界覆盖率=黄泉终结技的放大器）。每动必挂负面→负面队永动充能源。

**满级数值**【官：米游社百科·基础信息页签】：满级面板 生命1358/攻击601/防御509/速度98；行迹加成 速度5+效果命中28%+火伤14.4%；**终结技=100点能量**（官方证实）。

## 二、推荐遗器与光锥（与原因）

**光锥**【官：米游社百科·配装配队页签】：专武「那无数个春天」(★5,效果命中60-100%+卸甲易伤) → 「重塑时光之忆」(★5,效果命中40-60%+DoT联动) → 「猎物的视线」(卡芙卡专锥)。渠道口径：专武叠1/4星叠5。

**套装（按阵容选择）**：
- **黄泉负面队**：死水深潜的先驱4件 + 泛银河商业公司2件【攻】——烬煨常驻=对负面增伤全程覆盖；泛银河2命中增益（功能线+转模线双价值）
- **通用/其他队**：晨昏交界的翔鹰4件 或 幽锁深牢的系囚4件 + 翁瓦克/泛银河/格拉默【官：百科通用口径】——非负面特化场景的官方推荐

**官方通用遗器口径**【官：百科遗器推荐】（与上方体系特化口径**按阵容选择，非唯一解**——如击破角色辅助位用钟表匠/输出位用铁骑）：晨昏交界的翔鹰 四件套 或 幽锁深牢的系囚 四件套；位面=生命的翁瓦克 或 泛银河商业公司 或 苍穹战线格拉默；主词条：【躯干】效果命中/攻击力 【脚部】速度/攻击力 【位面球】火属性伤害/攻击力 【连结绳】能量恢复效率/攻击力；副词条：效果命中＞速度＞攻击力。

**主词条**：

| 位置 | 推荐 | 原因 |
|---|---|---|
| 躯干 | **效果命中** | 烬煨100%基础概率需对冲抵抗；命中140%时「举炊」攻击转化吃满【官】 |
| 脚部 | 速度 | 多动=多层烬煨+更多充能触发点 |
| 位面球 | 攻击%（辅助向） | 转化后的攻击再吃球 |
| 连结绳 | **充能** | 结界覆盖率即全队伤害 |

**副词条**：效果命中（→140%）> 速度 > 攻击% > 效果抵抗。
**转模与转化上限**：「举炊」命中→攻击，**140% 命中吃满**（80%+15%×4）——练度评价的机器判据线。
