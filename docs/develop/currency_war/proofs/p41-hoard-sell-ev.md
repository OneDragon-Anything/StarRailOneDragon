给「这张(商店里出现的)牌买不买囤着」「bench 里这张卖不卖」「第 n 个 bench 槽值多少金」三个决策各给出可计算的期望规则:

1. **V_opt(囤件期权价值)= 再遇窗口规避价值**的数学结构:弃购这张后,未来需要它时的期望再获取成本——含 1/q 轮自然等待、错过即截止风险、急 D 补救金;按费用档/等级给可计算式与保守首版序(与 p46 首版序对拍);

3. **bench 槽稀缺性定价**:满栏时第 n 个占用槽的边际价值(用被阻断动作的最大价值近似);[34] 稀缺性序的数学化;

## 推导

### ① V_opt 的数学结构(再遇窗口规避价值)

**情景**:商店刷出件 x(费用 c,当前等级 L),弃购。未来某时刻(期望 H_x 轮后)需要它。弃购的真实代价 = 需要时**再获取的期望成本**,分三条通道:

- **通道甲(自然再遇,免费)**:每轮一次免费商店试验,单轮命中 P_shop → 期望 1/P_shop 轮后再遇,只付卡价(与现在买同价,差项为 0);
- **通道乙(等不到,急 D 补救)**:H 轮内自然再遇的概率 = 1−(1−P_shop)^H;**错过概率 P_miss = (1−P_shop)^H**,此时补救金 C_rescue = c_eff × E[刷次] = **c_eff/P_shop**(k=1 的期望刷次 DP 闭式);
- **通道丙(截止,整局不再遇)**:P_never = (1−P_shop)^(G 剩余轮),损失 V_use(A7,只声明 ≥0)。

**可计算式(本篇核心结果)**:

```
V_opt(x | L, H_x, u_x) = u_x × [ (1−P_shop)^{H_x} × c_eff/P_shop ]  (+ P_never × V_use ≥ 0,略)
                       = u_x × P_miss × C_rescue
其中 P_shop = 1−(1−p(L,c)·(a_c−j)/(v_c·a_c−taken))^5   [满池退化式 P_shop ≈ 1−(1−p/v_c)^5]
```

### ② 卖出决策规则

**主判据(不等式)**:

```
卖(x) ⇔ refund(star_x, cost_x) + V_slot > max(V_opt(x), V_ms·ΔP̂·[x∈K]) + V_power(x)
```

(主式落地 max 双通道,与命题行三处同形——**max 不是「互斥分域/切换」而是「弃购 K 内件同时损失两通道」的保守下界**(严格账=V_opt+V_ms·ΔP̂ 的和式若两损失独立;max 取大者防双计且不低估主项——与 ⑤ 教义的相容读法:⑤ 管通道归属(谁的定价归谁),本式管弃购损失合成(一次弃购两账同发);K 外件 ΔP̂=0,max 自然退化单通道);**K 内件被单通道误卖的形态见自检 S-b2:低 V_opt 的 K 内骨架件(V_opt=2.8 < refund+V_slot=10)单通道判卖、max 通道接管后持有**)。

- **refund**:机制事实(`sell_refund`)——1★=cost 全额(卖 1★ = 无损变现,「活期金」);1费各星净 0;
- **V_slot**:槽位释放价值(③,bench 满时 >0,有空槽时 =0);
- **V_opt(x)**:① 定价(卖掉的镜像 = 弃购:卖了再要,付同样的再遇账)——**K 内件时它与 V_ms·ΔP̂ 取大者进右端**(上式 max 通道,⑤ 互斥分域的判据侧);
- **V_power(x)**:持有收益 = 该件后续上场的边际羁绊/战力现值([31]③ 边际贡献;[35] 场况插件「买了即上」= V_power 当轮兑现特例)。本篇不货币化 V_power,只声明 ≥0——**该「按 0 计价」是缺省项而非长期状态:P51 W 引理接管前的临时缺省(P41 修复批改道声明)**;补账唯一合法通道 = λ_death 概率侧的 W(s) 带项(P51 W_floor 形态:带 CI、作不等式中的比较项不作闸门),**禁 hp_to_gold 换算**(P15v2/P51 裁定:纯金流记账公理);在 W 项落地前,按 0 计价使卖出判据**偏松**(卖多了),方向与 [32] 腾席纪律同向、与 [22] 囤件纪律反向——故对骨架/贯穿件加保护(上表分类判据),不裸用不等式。

**燃料件支配性论证(消 u 的结构性依据,零参数)**:设件 x 满足燃料件类资格(1★ ∧ 与锁线/种子线成员集零重叠 ∧ 边际贡献≈0),则:

2. **持有的净成本 = V_slot**:零重叠 ∧ 边际贡献≈0 → V_power≈0、K 外件 ΔP̂=0,主不等式右端仅剩 V_opt——而 V_opt 加权的是一个净成本已为 0 的再获取账(先卖后买回付 0),按「卖后需买回」通道计 V_opt(净)=0;
3. **故 bench 满(V_slot>0)时卖出弱支配持有,与 u_x 取值无关**——u 只是给「未来需要」加权,而两个分支的差额已经为 0,任何 u∈[0,1] 都改变不了支配方向。主不等式在此退化(refund + V_slot > 0)恒真。

**公理序**:分类定性可支配的决策不进数值标定域(支配性论证 > 带参估计)——燃料类卖出判定绕开 u_by_cost 注入;数值 u 闸门只对中间类件(骨架/邻接,净成本>0:refund 亏手续费 ∨ 重叠件的 ΔP̂ 通道)保留,且标定 CI 落地前 fail-closed。**护栏**:零重叠判定输入缺失时按未定型期条款处理,不回退数值闸门。

**推论与对拍**:

- **[32] 腾席优先级的数学形态**:「杂件卖无可卖才配升级腾席」= 对 bench 全体跑 ② 不等式,若无一件判卖(全部 V_opt+V_power > refund+V_slot),才允许升级腾席通道——「卖无可卖」是不等式组的解集为空,不是计数;

### ③ bench 槽稀缺性定价

**定义**:V_slot = 满栏时释放一个槽的价值 = **被该槽阻断的动作中价值最大者的 EV**(机会成本定价):

```
V_slot(占用态) = max{ EV(a) : a ∈ 被满栏阻断的动作集 B },  有空槽(≥1)时边际槽价 = 0
B = { 插件购(非合成完备), 囤积购(目标外/未定型,V_opt 型), 压库购 }
```

**关键边界(merge §2.5 的定价含义)**:**合成完备购 ∉ B**——满栏也能买(「能触发合成的牌满栏也买得进」+ 自动多买)→ 槽**不阻断**追星/合成链动作,V_slot 只对非完备动作(插件/囤积/压库)定价。这是 bench 稀缺语义的精确版:满栏惩罚的是「宽度动作」(囤广度),不惩罚「深度动作」(合成收口)。

**[34] 稀缺性序的数学化**:购买序 = 按 `EV(a) − V_slot·[bench 将满]` 降序执行。[34] 三层序(目标件囤满→不买插件;有空位→先压库后插件;无可压→才插件)是其特例,条件是 EV(目标件) > EV(压库) > EV(插件) 的口述先验([34] 自述:插件收益无法精确量化 → 排序改用备战席稀缺性 = 承认 EV(插件) 不可标定,用 V_slot 作否决门代替序比较):

```
买插件 ⇔ V_plugin ≥ V_slot(有空槽时 V_slot=0 → 放行;仅剩 1 槽且被更高 EV 囤积候选占位 → 否决)
```

**首版近似(净口径)**:V_slot 分两档——free ≥ 2:V_slot = 0(下一笔非完备购不被阻断);free ≤ 1:V_slot = max{最佳被阻断候选 EV} ≈ max{**V_opt − c(净:弃购再遇的净成本)**, V_plugin − c}(毛口径会把被阻断候选的购价重复计入——自检⑤示例:free=1、插件净 EV=6、可囤 5费 V_opt(净)≈51−5=46 → V_slot=46 → 插件被否决 = [34]「备战席越空,插件机会成本越低」的**重构**([34] 原文是优先级直觉,本式是其**否决门形式**的替代实现,非同一断言))。基准 bench=9 槽([32] 语境);D 类投资环境改槽位数 = 只改 free 的读数,定价式不变。

**满栏 vs 空栏的期权差**:空栏的期权 = 随时可执行 B 中任一动作;满栏的损失 = max B(只能执行最优的那个,且须先卖件付 refund+V_opt 差)。故**满栏不是状态禁忌,是动作集从 |B| 收缩到「卖后再买」复合通道的价格**——与 [22]②「唯一稀缺 = bench 槽,囤 >2-3 张才需排优先级」对拍:囤件数 ≤ 阈值时 V_slot=0(② 不等式右侧无槽项),超过后 V_slot 跳升触发排序。
