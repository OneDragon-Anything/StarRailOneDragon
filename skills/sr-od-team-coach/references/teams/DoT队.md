# DoT队（持续伤害引爆体系）

> 按 V4.7 期（2026-11）调研撰写。靠「多系 DoT 挂载 → 层数积累 → 引爆结算」赢：不依赖暴击、以攻高/命中为口径的慢热体系。

## 核心思路

- DoT（持续伤害：风化/裂伤/灼烧/触电）在敌方回合开始结算，**不能暴击**，按施放者攻击力/命中结算 → 口径=攻击%+效果命中+速度，与传统直伤双暴口径完全不同【官：各 DoT 技能文本】。
- 引擎双层：挂载（每受1次持续伤害→黑天鹅叠奥迹；海瑟音全队攻击挂四系）+ 引爆（卡芙卡终结技立即结算全部 DoT、海瑟音 C1 结算150%）。
- 生存压力低（敌方被 DoT 消耗时我方行动自由），轮次表现依赖 DoT 铺设速度。

## 骨架与绑定规则

```
DoT主C(黑天鹅/海瑟音) + 引爆器(卡芙卡) + 虚无/辅助位 + 生存位
```

- 黑天鹅奥迹按「每受1次持续伤害」叠层 → 队伍 DoT 来源越多叠得越快（绑定多 DoT 队友）。
- 卡芙卡引爆吃「所有持续伤害类负面状态」（行迹解锁后）→ 绑定多系 DoT。
- 全队 DoT 施加均带基础概率 → 效果命中是全队功能线（各自转伤害：黑天鹅/海瑟音命中转伤上限72%/90%）。

## 成员要点

- [黑天鹅](../characters/黑天鹅.md)：主C——奥迹叠层引擎，7层无视防、3层溅射。
- [卡芙卡](../characters/卡芙卡.md)：引爆器——终结技结算全部 DoT；E2 全队 DoT+25%。
- [海瑟音](../characters/海瑟音.md)：四系挂载+命中转伤（120% 上限）+结界回响。
- [桂乃芬](../characters/桂乃芬.md)：4星灼烧+吞火易伤位。
- 生存位：灵砂（醇醉负面+击破副C）/加拉赫（酩酊负面）优先——负面队兼容。

## 操作轴

1. 开局秘技：黑天鹅秘技（概率连叠奥迹）/ 海瑟音秘技（进战挂2种 DoT）。
2. 铺设：黑天鹅战技（挂层+减防）→ 海瑟音/桂乃芬挂系 → 卡芙卡天赋追击自然触发。
3. 引爆时机：敌方身上 DoT 层数最多时放卡芙卡终结技；黑天鹅揭露（防层数重置）后接引爆收益最大。
4. 循环：卡芙卡天赋依赖队友普攻——DoT 队技能点充裕，普攻频率天然高。

## 替补矩阵

## 环境适配

- 利好：多波次/长线战斗（DoT 铺满后每回合白嫖）；频繁行动的敌人（回合开始结算多）。
- 克制：短爆发窗口环境（DoT 未铺满即结束）；高频净化敌方。
