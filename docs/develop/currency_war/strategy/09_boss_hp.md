## 1. 机制取证(boss 伤害分布 + r8→P2 映射)

### 1.1 boss 前后 hp 差分布(n=5,cw_telemetry rounds 视图亲读)

boss Δ = p1r9 决策时 hp − p2r1 决策时 hp(两点之间恰好只有 1-9 boss 一战;
r9 hp 是 boss 前决策快照,p2r1 hp 是 boss 结算后快照):

| run | r9 前 hp(r8 决策) | r9 决策 hp | p2r1 hp | boss Δ | 板面(form/引擎) | 删失判 |
|---|---|---|---|---|---|---|
| run 26(122120) | 76 | 78 | 64 | **-14** | form 1.00 / 双引擎 | 否(深板小额 P 罚) |
| run 28(230940) | 21 | 23 | 1 | **-22** | form 0.09 / 0 引擎 | 疑(hp_after=1 地板) |
| run 31(002018) | 31 | 33 | 1 | **-32** | form 0.12→1.00 / 锁线 | 疑 |
| run 32(010212) | 37 | 39 | 3 | **-36** | form 0.62 / 散件 | 否 |
| run 33(020557) | 20 | 22 | 1 | **-21** | form 0.65 / 散件 | 疑 |

**结论**:

1. **boss 伤害不是固定值,与板面质量强负相关**:深板(run 26,双引擎 form 1.00)
   -14 ≈ 只付位置基础扣;弱板 -21 ~ -36(中位 ≈ -26)。与 [27] 机制一致
   (P 罚 ∝ 敌方剩余血量——板面输出越高,清血越近,罚越小;局48 boss -3 同型)。
   「boss 固定重创」的观察项表述修正为:**弱板条件下近似固定重创**(带宽
   -21~-36,sim 回退档 `BOSS_BY_DIR_ROUND` 36+jitter0-10 与 22/30 档同量级)。
2. **r8→r9 恒 +2**(五局全部:r8 节点典型为奖励节点,胜 +2)——r8 备战时点
   到 P2 起手的映射:**P2 起手 hp ≈ hp(r8 决策) + 2 − E[bossΔ|板面档]**。
   弱板期望下 ≈ hp(r8) − 24:**r8 hp 22-33 → P2 起手 hp 1-9(hp_tier 0),
   零容错进 P2 是算术必然,不是运气**(三局连证的机制解释)。

**数据边界(声明)**:

- hp_after∈{0,1} 属地板删失口径(ADR-0307 同语义):-21/-22/-32 三条是
  **下界**(真实伤害 ≥ 观测);分布统计须剔除/单标删失行。
- n=5 全部来自 2026-08-26/27 同批实机局(A8 难度);run 221255 等 P1 段遥测
  缺失(server 重启断档)不可入样。
- run 32(010212)p2r4 hp=100 异常行(hp 3→100,疑治疗类事件或 OCR 异常,
  未核)——不影响本件结论(该局 boss Δ 取 r9→p2r1 段),记档待查。
- hp 不可回复为机制事实([27] 掉血不可逆;唯一正项 = 胜利 +2)——
  「管理」只能是**事前**(r8 备战前的板面投资压 P 罚 + 进 boss 窗前 hp 账),
  不存在事后手段。

### 1.2 问题本质(为什么三局连证)

r1-r8 无 hp 维管理,P1 逐轮掉血(run28 r6 -26/r7 -28 型深亏)把 hp 磨到
20-33 区间;boss 窗结算期望 -26 一次性归零。策略层现状:ADR-0313 三臂在
hp 已低后**反应**(报警梯度),ADR-0400 承接门在末窗**投影**(但 hp 维取
当前值,见 §2)——中间缺的是「boss 这一已知中间节点的期望结算」没有进
任何一处的账。

## 2. 现状盘点:承接门 hp 维的标定口径错位(缺口定位)

`handoff_gate_gap`(ADR-0400,判据单一源)末窗投影 = `handoff_snapshot`
现算,其中 **hp 维取当前 state.hp**——r8/r9 时点的 hp 是 **boss 前**值。
而档位切点 `HANDOFF_HP_CUTS=(20,50)` 的标定语料(ADR-0399,n=48)是
**P2 进场真值 hp(boss 结算后)**。

→ **末窗用 boss 前 hp 喂 boss 后切点 = 标定口径错位,hp 维系统性高估一档**:
r8 hp 22-33 的局,现投影判 hp_tier=1(>20),而真实承接 hp_tier=0。
后果分两类:

- **弱板局**(run28/31/33 型):board_tier=0 → 总档 min(1,0)=0,gap 已=1,
  门已触发——投影修正**不改变** gap 数值(min 由板面维压死);
- **板面达标、hp 临界局**(engines≥1 ∧ core2≥1 ∧ r8 hp 21~50):现投影
  总档=1 → gap=0,**门不触发**——boss 结算后 hp 归零的盲区正是这一类。
  随 W232 产星通道(star≥2 率 3×)与 W232 C 项(末窗星级定向)落地,
  板面 tier1 局占比上升,该盲区从边缘变主流。

## 3. 干预点设计(挂 08 Phase 1 语义内,零新层)

### 3.1 主修法(裁决):承接门 hp 维投影语义化

**改一处**:`handoff_gate_gap` 内部,快照 hp 维由「当前 hp」换
「**boss 后投影 hp**」:

```
hp_proj(r8) = hp + 2(奖励节点胜) − E[bossΔ | 净星深档]
hp_proj(r9) = hp − E[bossΔ | 净星深档]
```

- `E[bossΔ|净星深档]` = **离线标定的常数表**(源 = Δ池 plane=1 boss 桶按
  净星深分桶的均值,地板删失行剔除),进 registry(A/B 可注入),非运行时预测;
- 净星深档键 = `deployed_star_depth`(上场件 Σ(star−1),W240/ADR-0404
  替旧 Σboard 键——修 §5 缺口②的方向冲突)与 Δ池采样键同源,
  不建第二套分桶;
- **不违反 08 §4.2「不预测」裁决**:被否的选项是「模拟剩余轮资产」的
  预测器(预测板面/血量漂移);本修法是把**已知中间节点(boss,必然发生)**
  的期望结算计入近端投影——与 ADR-0400「近端投影」裁决同族,精度更高
  一步而非换预测范式。

**为什么是它(取舍论证)**:

1. **修的是标定口径错位这一根因**(§2),不是加新阈值——切点 (20,50)
   不动、标定语料口径不动,变的只是「喂给切点的 hp 取哪个时点」;
2. 单一源改在 `handoff_gate_gap` 内部,挂载点 a(formed_stop 承接维)/
   b(EV 缺口项)**零改动自动继承**;辖域(plane==1 ∧ r≥8)不变 →
   「P1 非末窗零漂移门」结构前提天然保持;
3. 增量面精确 = §2 盲区类(板面 tier1 + hp 临界),这类正是 hp 维绑死
   P2 存活的局——与 ADR-0400 A/B 报败的归因(此前门扣住的子群主要靠
   板面维触发,hp 维无独立通道)互补。

### 3.2 候选 b(boss 前 EV 账偏向战力)——裁定:不另立,合流

「hp 低时 r8 投资偏向战力(压 boss 伤害)而非经济」**语义上正确但不需要
新账**:挂载点 b 已在末窗放宽买侧破息授权(缺口越大授权越宽),而买什么
由 scoring/formed_stop 决定——其语义本就偏好板面战力(core 件/补完)。
另立「战力优先 EV 臂」= 双门双计,ADR-0347 明令禁止形态。裁:**合流进
主修法**(投影使 gap 更准 → b 臂授权方向自动更准)。

### 3.3 候选 c(取证后发现的更优位)——r6/r7 深亏上游,裁定:不辖,归位

三局连证的 hp 低不是 boss 造成的,是 r6/r7 深亏(run28 型 -26/-28)磨出来的
——根因是板面不成长(产星通道),已由 W231 诊断/W232 产星通道(✅)与
W232 C 项(末窗星级定向,有据待派)承载。本件辖 **r8 备战时点的账**;
上游成长问题在本件内重复立项 = 跨件半问违例。C 项落地时可复用本投影常数
作判据输入(§4)。

### 3.4 反验收条款

禁止直接优化「boss 后 hp」/「投影 hp」数值本身([28] 镜像病;[18] hp 从来
不是目标函数)——投影只作 gate 输入,验收永远在 outcome 端(P2 存活分布)。

## 5. sim 可验性判定

**判定:主修法可验(部分);星级联动通道存疑(记缺口)。**

已建模(零 sim 基建改动即可 A/B):

- boss 战段 sim 已建模:结算走 Δ池 plane=1 boss 桶(键=板深
  `_deployable_depth`,ADR-0312 同口径;cw_sim.py:1875-1877)/桶不可达
  回退 `boss_settle_delta`(胜面阶梯 0.05 + `boss_delta` dir_round 档
  14/22/30/36+jitter);hp 钳制 `max(0, min(100, ...))`(cw_sim.py:1904)。
- **可验通道**:末窗买件/上场 → 板深↑ → sim boss Δ 采样桶上移 →
  投影门 A/B(`simulate_handoff_ab` 同池同 seed 配对 + P1 非末窗零漂移门,
  现成口径)。
- **缺口①(胜面)**:boss 胜率 0.05 无条件且语料为旧策略病局(ADR-0308
  已声明待重标)——对 hp 管理非阻塞(胜→+2,小额),但 A/B 判读须声明。
- **缺口②(星级通道,实现前必查)**:boss Δ 池键 = Σboard(成员计数),
  **3合1 升星会减件数** → 键值下移——sim 可能判「升星 → boss 伤害↑」,
  与 [27] 机制(升星→输出↑→P 罚↓)方向相反。落地批必须先核 Δ池 boss 桶
  在升星前后的桶迁移方向;若确为反向,W232 C 项(星级定向)与本门联动的
  sim 仲裁失真,须先补键或声明边界——**否则 sim A/B 会系统性低估
  星级投资的 hp 收益**(与 ADR-0400 core2 无通道同族的已知边界)。
