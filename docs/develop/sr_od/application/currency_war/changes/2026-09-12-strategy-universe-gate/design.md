# 投资策略候选全集门 迭代设计（总纲）

## 0. 元信息

- 迭代目标：投资策略 3 选 1（事件面 E2）中，**绑定锚定型策略卡**（绑定阵营/核心角色均不在候选终局阵容全集）的注册表裸分失格——与环境侧全集门（`2026-09-12-invest-env`）同构的「避免无用选卡」语义。主体工作量 = **335 条策略卡全量分类盘点**（用户裁定 2026-09-12「分开一个迭代文档吧，因为要重新判断所有的投资策略」）。

  1. 独立迭代，不并入环境迭代；
  2. **S1 定义型豁免加前提**：定义的阵容 ∈ 候选全集（COMP_LIBRARY 且未被 evicted）——守卫「拿到即改玩库外阵容」的结构性风险（用户质询「我们有这个终局阵容吗」引出；现状 7 张定义型卡绑定的 4 个阵容全部在库，见表 2.2，但绑定表手维护、无守卫）。
- 依赖：`2026-09-12-invest-env` 3.1 的 `candidate_faction_universe`（同一台全集机器的第二个消费位，禁二次建模）；角色维新增 `candidate_core_char_universe`（core-only，同区镜像函数——与 env 送卡型候选角色池 core∪shared 语义分立，两问不同答案，命名禁共用，见 details §8）。
- 状态：定稿[收敛+试读过]（对抗报告 = [attack.md](attack.md)）
- 文档清单：details/gate-and-audit-spec.md —— 门谓词定稿/S1 前提守卫/审计规格/锁表/与环境迭代的机器共享契约

## 1. 问题与动机

### 1.1 现状症状

decide_event 策略分支：S3 终局对齐（45×N+20）只在 D* 非空时激活；开局 D*=∅ → **绑定锚定型卡**（星徽/阵营套组/角色专属卡）与阵容无关卡凭 S4 裸分（12-75）同台竞争。绑定不在候选全集的卡对本局无消费方（星徽 = 给不玩的阵营送羁绊装备；阵营套组 = 定向服务该阵营），但裸分照样可胜出。与环境侧狼狩反例同构（环境门见 `2026-09-12-invest-env` design.md §1.1）。

### 1.2 根因归层

语义层——与环境门同根：「有用性」判据缺「本 bot 候选阵容吃不吃得到」维度。同族第 2 次 = 与环境门共用同一全集机器、一次架构级解决（根源两问「跨件半问」的合规解），非逐件补丁。

### 1.3 解决到哪 / 明确不解决

解决：策略分支全集门 + 335 卡全量分类盘点 + S1 豁免前提守卫。

明确不解决：

1. **S1 定义卡的「意向层转向」**：拿到黑塔纪元后，bot 靠资产信号（黑塔入板 → detect_signals ③core_card）自然移动方向，无显式 pivot——现状即如此，本迭代不动意向层。
2. **T-162 策略侧刷新判据**：现行不动（对账见 §2.3，结构性无冲突）。
3. **环境侧一切**（另一迭代）。

## 2. 方案（门谓词/全集口径/失格域/S1 前提已定稿 = 详设 §2–§5；335 卡盘点为落地 3.1 交付物，非设计待定项）

### 2.1 门谓词

- 锚定源：`strategy_bindings(_st)` = (factions, core_chars)（`STRATEGY_BINDINGS` 表，`kernel/cw_investments.py`）——绑定非空 = 锚定型；bindings 空 = 非锚定（经济/功能/品质类），不触门（保守向：`STRATEGY_BINDINGS` 覆盖缺口 = 门漏放而非错杀，缺口由 §2.2 盘点显式化）。
- 门：绑定锚定 ∧ 非(S1 前提成立 ∨ 经济引擎) ∧ fs ∩ 阵营全集 = ∅ ∧ cs ∩ 角色全集 = ∅ → **S4 全域跳过**（eval / eval-lcs / prior-{rarity} 三支全跳，分数落 0，reason=`strategy-off-universe`）；S3 对齐对失格卡结构不可达（D* ⊆ 全集，无需门辖），steering/DoT/血分区照常（详设 §3.1 逐分支推演）。
- 全集口径（**定稿**，详设 §2）：阵营维 = `candidate_faction_universe` 复用；角色维 = **core_chars only**（非 evicted 并集，不含 shared/transition）。主证 = S3 对齐角色维只数 D*chars = core_chars（`cw_events.py:152/164`），绑定角色出集 ⟹ 对一切可达 D* 恒不 align，留在 S4 = 病灶本体；shared/transition = 角色侧「临时可吃非玩的方向」（与阵营排 flex 同判）；错杀差集实测有界 4 卡（狼狩星徽系效果主体是全集外阵营、锻冶专家:刃/骇客专家:银狼），修正路径 = 修 COMP_LIBRARY 不是放松门，user-priority 留人工兜底。落码 = `candidate_core_char_universe`（命名与 env 送卡型 core∪shared 角色池分立，详设 §8）。
- 豁免面（不触门，优先级高于门判定）：
  1. **S1 定义型**（`augment_affinity` 非空）：豁免前提 = `AUGMENT_COMP_AFFINITY[卡]` 指向的阵容 ∈ COMP_LIBRARY ∧ 非 evicted；前提不成立 → 不豁免（失格）。此前提同时是手维护绑定表的覆盖守卫（现状核对见表 2.2，全部在库）。**定稿（详设 §4）**：前提谓词 = ∃ 亲和 comp 在集（∃ 形态错杀最小化，7/7 单 comp 现状无行为差）；亲和值 {1.0/0.8/0.6} 不进门判定（加阈值 = 拍值 + 分叉 S1 触发语义）；时序 = 选卡时点帧快照，持卡不回溯；守卫辖域恰两处 = S1 分支 + T-162 `_cand_s1` 旗标（前提破缺定义卡不被顶级保护，现行零漂移）。
  2. **S2 经济引擎**（`is_economy_engine`）：阵容无关价值（利息上调谁玩都赚）→ 豁免。
  3. **血本位**（`is_blood_economy`）：走自身三态分区；两血卡 STRATEGY_BINDINGS 双空 → 结构性不触门（与 ADR-0578 对账）。
- OCR 形变名：经 `resolve_strategy_canonical` 解析后进门判定（解析单一源既有）。
- 归因串：`strategy-off-universe`（仅观测，沿 ADR-0593 C1→D4 口径）。
- 集成位：策略分支 S4 裸分支前置门；S1/S2/S3/blood/steering 次序不变。失格语义与环境门同形：分数落 0 垫底，强制选一帧仍可选。

### 2.2 全量盘点：335 条策略卡分类审计（本迭代主体工作量）

逐卡分类，产出审计表（落 `details/strategy-335-audit.md`）：

| 分类 | 判据 | 门行为 |
|---|---|---|
| 绑定锚定型 | STRATEGY_BINDINGS 表内 ∧ 绑定非空 | 触门（绑定 ∩ 全集 = ∅ → 失格） |
| 定义型 | AUGMENT_COMP_AFFINITY 表内 | 豁免（前提守卫：定义阵容 ∈ 非 evicted 候选集） |
| 经济引擎型 | is_economy_engine | 豁免 |
| 血本位 | is_blood_economy | 分区自辖 |
| 非锚定功能型 | bindings 空 | 不触门 |

盘点交付三件（方法论单一源 = 详设 §6：5 步决策树 / 两遍挖掘协议 / 十一列 schema / 机检验收）：①全量分类表（卡名/绑定/分类/门触达/备注，注册表值直调）；②`STRATEGY_BINDINGS` 覆盖缺口清单（应锚定而表外未锚定的卡——按效果原文人工复核，如各阵营星徽/套组/角色专属件）；③「绑定全集外实卡」实测清单（门第一版咬合面，供锁 fixture）。**已预跑：净失格 18 卡**（预 19 − 引擎豁免砂里淘金，逐卡名单 = 详设 §7 D-c），审计表验收含「失格行集合 = D-c 逐卡相等」机检。

### 2.3 与 T-162 刷新判据对账（结构性无冲突，申报即可）

门失格卡的绑定 ∩ D* = ∅ 由门条件直接推出（D* ⊆ 全集）→ 失格卡的 align_n 恒 0 → 在 T-162 槽级分类里本就是非顶级可刷槽：**门只改打分，不改刷新行为**，T-162 零改动，对账申报入批报告。S1 旗标随前提守卫细化（`_cand_s1` = 前提成立 ∧ 在表）：前提破缺的定义卡不被顶级保护、落入可刷集——现行 7/7 定义卡前提全真，**零漂移**（详设 §3.4）。

### 2.4 宪法与纪律对账

- 零自由参数（集合存在性谓词）；位面零字面量；无开关（回滚 git revert）；
- 归属：`STRATEGY_BINDINGS`/`AUGMENT_COMP_AFFINITY`/`PICK_VALUE` 消费同属内置默认策略器评估知识（层级归属声明 = `kernel/cw_investments.py` PICK_VALUE 前言）；
- 未证即退役约束的反向适用：门不是新数值，是结构判据，无退役面。

### 2.5 关键取舍

| 备选 | 为何放弃 |
|---|---|
| 并入环境迭代 | 用户裁定分立（2026-09-12）：335 卡全量盘点主体工作量与环境迭代不同量级 |
| S1 无条件豁免（现状语义平移） | 手维护绑定表无守卫，版本演化会「改玩库外阵容」；用户质询定谳加前提 |
| 角色全集含 shared/transition | **排除（定稿）**：主证 = S3 角色维只数 core，绑定角色出集 = 永不 align（详设 §2 论证 1）；错杀差集实测 4 卡且其中狼狩星徽系阵营维已判死；修正路径 = 修 COMP_LIBRARY 不是放松门（详设 §2 论证 3） |
| 门失格卡同时从 T-162 可刷集剔除 | 无依据——失格槽本就可刷（刷掉它 = 改善支），剔除反方向 |
