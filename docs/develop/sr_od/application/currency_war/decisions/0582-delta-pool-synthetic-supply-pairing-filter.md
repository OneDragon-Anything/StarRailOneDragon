## 1. 背景与问题

Δ池(`cw_delta_pool_data` 快照 + auto 池)的配对口径长期不过滤行来源:补给合成行(`source='synthetic_supply'`,hp 取 `cw_loop._record_supply_outcome` 的 `last_state` **战前快照**,ADR-0577 §3.3 定谳「快照不是事件」)全额入配对端点。后果三件(同根 = 合成行入配对):

- **supply 域整体是伪影集合**:相邻差分把「上一行差分取反」记成补给增益(镜像律 155/170=91.2%),supply P1 n=128 mean +4.29、域 [−4,22],P2 [−3,47]——触发 ADR-0292 伪影哨兵(|Δ|>20)与生产 sim 检查报警;语料中「补给回血」从未被可信观察(ADR-0577 §3.3 旁证:025608 两补给节点 44→44、1→1)。
- **跨合成行的真实战斗差分被顶替**:毒形态「战斗 44 → 合成补给 66 → 战斗 46」产出幻影 +22(supply)并把真实 +2 顶成 −20(battle)。
- **快照生成器与 auto 池镜像循环漂移面**:两处各持一份配对实现,历史上靠人工「镜像同步」(ADR-0407),过滤语义单侧修改即破坏 auto/snapshot 指纹收敛判据(pool.py 无标签行案先例)。

## 2. Considered Options

| 方案 | 裁决 | 理由 |
|---|---|---|
| 只改快照生成器 `build_pool`,不动 auto 池 `_pool_from_replay` | ✗(**方案审阻断-1**) | auto 池是 `simulate_p1_batch` 默认数据源(sim/runner.py `pool='auto'`),不修则默认 sim 路径继续吃毒;且单侧过滤再次打破 pool.py 明文设计判据「两态过滤不同态 → 指纹结构性永不相等,指纹相等性无法用作收敛判据」(无标签行案同款教训) |
| 两处各自加同一谓词(最小面) | ✗(让位于单件) | 谓词同但配对循环仍是两份镜像——第三源漂移面保留;抽成 `pair_outcome_rows_to_pool` 单一实现供两处消费,漂移面归零 |
| conf 门保留并如实披露剔除后果 | ✓ | 与 ADR-0577 装配端判据 `_settlement_hp_usable` 同构(伪值不入链);实益 = 清掉 8 条 loss_page 行被节点兜底误标『补给』的假样本与全部死亡腿伪对;但后果必须显式申报(见下「死亡腿账」),禁「真实行不受影响」的不实表述——conf 门剔除的 101 条全部是真实行(终局 loss_page hp=0),连带配对损失约 75 对 |
| 「第三种毒:真实行但 hp 陈旧」一并设防 | ✗(结构上不存在) | outcomes 流真实行来源枚举(''/recovered/loss_page)都是屏面**当时**读取,全流唯一快照携带写点就是合成行;实测真实行 conf<0.9 且 hp≠0 的行 = 0 条 |
| 「镜像律消失」钉快照值锁 | ✗(**方案审阻断-4**) | 池条目只有 Δ 值不含配对信息,镜像律在快照层不可检验;快照级值锁 = 池耦合 change-detector(局终自动再生即红,ADR-0292 判例)。锁落生成器 fixture 层(毒行注入/桥接恢复/剔除计数),快照层只允许**缺席型**断言(supply 域无 \|Δ\|>20) |
| BATTLE_RUNG_TRUTH 维持旧值硬锁 | ✗(**方案审阻断-2**) | 旧真值表(批⑬ F2:−11.5/−6.3)本身是含毒语料的产物;治理后 rung1 均值 −4.11→−3.24,距旧锚漂移 3.06hp 超 3.0 带,必撞检查项/测试锁/smoke 门。重推 = 锁的存在性纪律的正例(锁红≠改动错,重推语义后更新锚),非机械跟绿 |
| supply P2 域消失走桶贫困披露 | ✗(改 META note 显式声明) | `_poverty_list`/覆盖检查只遍历**存在**的桶,整域消失 = 无披露载体;note 链 v13 显式声明「P2 supply 域清空(n=0)」 |
| 顺手修 supply 域近空后的采样回退语义(+2 幻影) | ✗(登记不修) | `live_delta_for` 缺桶→全池兜底→None→`node_delta` 回退 `EARLY_WIN_DELTA=+2` 是**既有回退语义**,不是本批引入;改 = 策略行为面,须另立批。ADR-0577 实证补给真值≈0,该回退层 +2 幻影如实登记 |

## 3. 已实施架构

- **共享配对件**:`pool.pair_outcome_rows_to_pool`(单一实现)+ `pool.hp_pair_endpoint_admissible`(端点资格谓词,唯一判据闸)。快照生成器 `build_pool` 与 auto 池 `_pool_from_replay` 共同消费,配对循环/桶键逻辑收拢单件,镜像同步纪律终结。行级过滤三步,顺序有语义:①hp0 瞬态剔除(v12,「终局」按原始序列末行判,先于资格过滤);②端点资格过滤——合成行与 `_outcome_hp_trusted` 不可信行**移行桥接**(从序列移除、邻行重配对,v12 先例;断链会丢真实 +2 留 −20 错值);③相邻差分归属后行(节点/位面/桶键)。
- **谓词语义**(= ADR-0577 装配端 `_settlement_hp_usable` 延伸到 Δ池消费面;0577 §3.2 自限「降权只及步进链」,扩面以本 ADR 为据):`source='synthetic_supply'` 恒 False(快照不是事件,先验「陈旧直到证伪」);其余行复用 `telemetry.query._outcome_hp_trusted` 单一源(**缺字段=可信**,边界声明随源);真实结算行(''/recovered)不受 source 过滤影响。惰性 import 防 sim↔telemetry 模块级新环。
- **披露账**(META,与 `hp0_transient_dropped` 并列):`synthetic_supply_dropped`(本语料 256)/`hp_conf_dropped`(101,全部终局 loss_page hp=0 死亡腿)——**死亡腿账如实申报**:conf 门(v1→v2)连带剔除其配对腿合计 −79 对(battle P2 −58、encounter P2 −13、supply P2 −5、boss P2 −2、reward P2 −1);另 boss P1 164→163 为 source 滤的 v0→v1 效应,不计入 conf 门。修复语义内,非「真实行零影响」。(初稿「约 −75 对」构成错位:误纳 boss P1、漏 supply P2——落地审勘误)
- **supply 域后果**:P1 128→1(唯一真实结算行 run_20260906_120036 p1r6,Δ=+2;其『补给』标签本身疑似冷启动表误预测,仅存档不构成补给效应证据);P2 47→**0(整域消失)**,note 链 v13 显式声明。生产伪影哨兵唯一报警源(P1 +22)解除。
- **battle rung 真值锚重推**:`BATTLE_RUNG_TRUTH` = {0: −9.73, 1: −3.24}(过滤后语料同口径实测,n=256/238;快照指纹 a0722904);方向 = 语料演进 + 毒值清除的合成,ADR 在案。
- **存量锚登记**:n300 基线锚(`ANCHOR_REGISTRY_N300['pool_fingerprint_prefix']='0bf6c0d6'` 系 w157_p2 本地导出池,本就非随再生前移的提交快照;invest 锚 1762b1cf 同理)——**旧锚跨批不可比,待下次 n300 重跑换锚**,锚注释已加指针;`pool_fp_match` 为披露字段非违规。

## 4. 边界申报

- **配对逻辑既有残余弱点登记不修**:邻接差分把行间一切未建模 hp 变化记入后行节点(血购 hp_pay 事件行、跨段间隙;ADR-0577 §1 B/§4「中间窗口」明文)——滤 source 不解决也不恶化,本批不声明解决,同口径登记。
- **Δ池消费面现状**:coarse 主路径下池仍辖 delta 对照臂与 reward/supply 两模式结算(ADR-0424/ADR-0512),治理不改消费拓扑;`check_pool_freshness` 在 coarse 模式跳过,新鲜度不辖。
- **测试密闭纪律**:消费提交快照的新锁只做进程内自洽/缺席比较(测试纪律 19),禁「import 时状态 vs 执行时现算」跨时点比较;fixture 锁写 `tmp_path` 合成语料(零真实副作用)。

- conf 门剔除真实死亡腿后,P2 各域 n 缩(≈−18%):桶贫困披露自动跟上,真值方向解释边界照旧申报。

- 旧 n300 锚跨批不可比:跨日对照一律 Path 重放锚池或等 n300 重跑换锚。
