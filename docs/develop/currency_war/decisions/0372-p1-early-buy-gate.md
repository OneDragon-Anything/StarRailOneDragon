# 0372 — P1 早期新件买入门(双条件窗:缺件密度 × 息档口径)

- 日期: 2026-08-30
- 状态: accepted (采纳)
- 关联: ADR-0369(W170 pair 找牌窗=刷门,本批=买门,互斥-互补)、ADR-0356(W139 出口金底线)、ADR-0357(W145 配方锁)、ADR-0359(W150 买侧通道约束)、ADR-0367(W166 transition_pair)、ADR-0371(W174 own-gap 上场层,本批=其残差 pass_buy 买侧层)、W173/W175 判读(证据基准)、P13(hold50 期望账:buy iff V≥t×min(R,3),息档口径=其在 <50 段的载体)
- 批: W175 设计评审批(ADR 草案)→ W179 落地批(参数标定+代码+验证)

## 背景与问题

W174 收账后 never-2 残差 [0,45,65,77,83] 中,65/77/83 三局 pass_buy 形态
(own<门槛=**买少了**)**逐位不动**(sim 明证)——W174 治「拥有≥门槛上不了场」,
治不了「缺的新件曾 2-6 次出现在店里(1-3费,金 7-15 金穷轮)且全放过」。

拦住它们的不是钱(W173:B 形态「裸口径连牌价都不够」=0/99 轮),是:

1. **FORM 相位地板 20 被错误应用到 <20 段**——违反口述 [11]「金 <20 买过渡件
   不损息还压库,攒息不该拦无损购买」(精确口径=购买后同息档才零息损)。
   息档推演(W175 §1):8 病灶轮中 7 轮同档 0 损、1 轮 ≤1 金——被拦买入几乎
   全是 [11] 无损购买;
2. **未锁形态期无任何 target 买入门**——p1_pair/transition_pair 仅锁后非空;
3. W170 pair 窗(ADR-0369)预算前提=50+刷+买([3] 单次口径),金穷轮结构性
   不适用;且窗只辖「主动刷」,不辖「店里已出现的便宜件买不买」。

## 决策

**P1 早期新件买入门**(候选放行层:arbiter.gold_floor 拒绝前的逐笔放行;
轮级窗判据 `discipline.p1_early_gate_open`,逐笔判据
`arbiter._p1_early_buy_exempt`):

- **轮级窗**:P1 ∧ 派生配方对(`cw_intention.p1_early_pair`——支持度 top-2
  `_derive_p1_pair` 同口径,**未锁形态期同样派生**(无 P1_PAIR_LOCK_MIN_SUPPORT
  门槛;这是对 p1_pair/transition_pair 仅锁后非空的语义扩展,读口不落新字段)
  ∧ 未持有 distinct 对成员数 ≥ `p1_early_min_missing` ∧ bench 余槽 ≥ 1
  ([22]② bench 唯一稀缺);
- **逐笔判据**:常态经济态(应急/boss 窗/war 不辖,[18]/[32] 纪律态地板优先)
  ∧ 目标件 ∈ 门内集 ∧ **买入后同息档**([11] 逐字口径
  (gold−cost)//10 == gold//10,**不设第二道金常数门**;跨档购买照旧走
  interest_rule EV 授权)∧ 同名对 working 现持不辖(distinct=逐笔现持判定,
  3合1 素材语境交既有 copy 豁免面)∧ 单轮笔数 < `p1_early_round_cap`;
- **不授权任何刷新金**——买门与 W170 刷门管辖动作不交集([31] 刷门找牌/
  买门接牌);费带不限 1费(息档口径自然辖 1-3费,run77 3费病灶同辖);
- 常量(registry,A/B 通道 `p1_early_gate_enabled` 关=逐位回 W174 后行为):
  - `p1_early_min_missing: int = 6`(缺件密度;标定见下);
  - `p1_early_round_cap: int = 1`([31]②「目标件刷新出现=唯一最高优先级,
    只买它」;标定见下)。
- 授权依据 trace:`auth['p1_early']` 进执行 log(判读「为什么放行」);
  单轮计数 `session.v2_round_p1_early`(轮键重置,strategy.decide_prep)。

### 参数标定(W179,n=100→300,池 861fc9f6,invest on,与 W174 同谱系)

- **k(unheld distinct)**:全体 P1 轮 unheld 分布 [8,16](r1 p10=14/r9 p10=8),
  病灶轮 11-15——k∈[1,8] 对本分布**无区分度**(operative 约束=息档口径+
  单轮上限+层3评分),取 6=「板面远未覆盖配方对」的语义守卫(防未来分布
  漂移把门开进不该开的段);
- **单轮上限**:门内笔数 p50 0-1 / p90 1-3 / max 7,病灶轮 1-2 笔——
  cap 扫描(1 vs 2):cap1 出口金 34.23 vs 基线 34.25(持平=P13 同档零损的
  理论预测逐位兑现),cap2 −2.3 金换 hp +1.3;取 cap=1(出口金口径干净
  + [31]② 逐字口径)。

### 散买边界三条件(W175 §4;任一失守=越界)

1. **target ∈ 配方对成员**:门内集=派生配方对(四体系支持度 top-2)未持有
   distinct 成员,非任意凑羁绊件(bond_fallback 的 [31] 二级语义不辖);
2. **只搭自然刷新便车**:零刷新授权(本门只在 arbiter 的 BuyCard 分支放行,
   RefreshShop 候选不获任何授权);
3. **distinct 未持有**:对 state 与 working(同轮前序买入后)现持双重判定,
   同名重复/扫店不辖。
