# 投资环境 D 类两型估值：送卡型与品质改写型（详设）

> 总纲 §2.2.1 D 类两型的落地详设，承接总纲 §2.3 集成次序。用户裁定 2026-09-12「送卡型/品质改写型估值——这个也要，一次性做完」：两型由总纲 §1.3 的「明确不解决」转入本迭代。
> 辖域：送卡型 = 契约 ×7 + 特邀专家 ×4；品质改写型 = 时代 ×3（彩虹/黄金/白银）+ 头彩/尾彩 + 银·金·彩 + 联席决策，共 12 条环境。其余 D 类（战力 ×2/进化算法/红钻蓝钻贵族/深井角斗场/命运礼物/英雄登场/三星佩佩/粗星佩佩等）维持总纲原处置不入。

## 问题与约束

### 1.1 两型为什么要单独设计

- **送卡型**（效果原文直调 `cw_invest_data.py`）：契约 7 条发放**具体具名角色**（如 持续伤害契约 id 127「获得【椒丘】和【卡芙卡】…计数达到180时，获得【黑天鹅】」）；特邀专家 4 条发放**专家顾问入商店**（如 id 141「获得专家顾问【停云】，并使其在本局游戏中加入商店」）。角色价值 = 阵容进度（战力域，宪法禁建模，依据 00_framework §1.1）还是金等价（卖价是游戏定义残值）——两头都不能直接用，需要第三条结构化路。
- **品质改写型**：改写「本局能取到的投资策略的品质分布」（彩虹时代 id 110「这局的投资策略均为棱彩品质」）。策略池品质结构在注册表可算（`INVESTMENT_STRATEGIES` 335 条含 rarity），品质改写的估值 = 池分布差的期望——但要先回答定序/基数分账（ADR-0524 禁把 pick_value 读基数）与难度侧辖域。

### 1.2 硬约束（全部继承总纲 §2.5，此处只列对本篇有额外咬合面的）

1. **禁战力建模**（00_framework §1.1/§3）：送卡角色的「强度」不可作判据；白银时代「敌人难度不因高品质提高」的收益不可折金。
2. **数字三形态**（01_math_framework §6）：进决策门的每个数字标【注】/【推】/【拟】；【拟】缺 CI = fail-closed 不消费。
3. **定序与基数分账**（ADR-0524，`cw_investments.py` PICK_VALUE 前言）：裸分/品质序/档位 floor 是定序；金流是基数；跨族只允许 max() 覆盖。
4. **开局静态可用**：环境三选一在开局信息最少帧发生，D*（意向方向）通常为空（`cw_events._invest_d_star` ②支依赖 `detect_signals` 的板面信号，开局无板面）——两型判据必须只依赖「候选终局阵容全集 + 注册表」，不依赖局内信号。

### 1.3 总纲接口契约（本篇继承，不改口）

- 经济估值单一入口 `env_economy_value(name, bs) -> (expected_gold, resolved)`（总纲 §2.2.3）；resolved=False = fail-closed，消费端按无经济通道处理。
- 集成次序 = 总纲 §2.3 的 max() 覆盖定序；归因串仅观测（ADR-0593 C1→D4 口径）。
- `evicted` 集合与全集门同源同义（总纲 §2.1.1，`decide_event` 现有参数，零接口新增——直调 `cw_events.py:193` 签名已含）。
- EnvEconomyEffect（总纲 §2.2.2）**不扩字段**承载本篇两型：送卡发放与品质改写都不是金流通，塞进经济通道结构会破坏「通道字段 = 金流语义」的表内一致性；两型各建独立结构（见 §2.1.3/§2.2.5），**消费入口分型**：品质改写型层 E 属金流期望，**经 `env_economy_value` 同一入口分派**（§2.2.5）；送卡型**不经经济入口**——档位是定序实现常数非金流期望（ADR-0524 定序/基数分账：`(expected_gold, resolved)` 契约装不下 66/60/54 档语义），消费位 = `cw_events` env 分支独立 max() 支（§2.1.3），与经济域带在集成次序（总纲 §2.3）中按 max() 汇合。

#### 2.1.2 估值形态推导（为什么是结构集合级，不是 comp 价值也不是金等价）

**候选形态逐一裁决**：

1. **comp 价值 / 战力域**：禁。宪法 00_framework §1.1 排除一切强度拟合进决策门；角色「强度」没有游戏定义值可查。
2. **金等价（卖价残值）**：可算但无判别力，只作注记不入判据。卖价 ≈ 按费用退金（游戏定义，`cw_investments.py` 砂里淘金注释「2费可卖 ≈2 金/张」同源口径），它度量的是**费用**不是阵容价值：同为公司契约赠卡，翡翠 core×2（大黑塔银河学者/银枝群攻）与砂金全集外（本次直调核验：不在任何候选套 core/shared/transition 名单）费用接近，卖价也接近——残值对「送的人有没有人用」零区分度。把残值当价值 = 系统性低估 + 误导性排序。裁决：卖价只在 `GiftGrant` 注释字段记【注】下界，不进任何分值族。
3. **结构对齐（本设计采纳）**：送卡的价值判据 = **所赠角色是否被候选终局阵容使用**，这是集合成员存在性谓词（零数值、零战力、开局静态可用），与总纲全集门（faction ∈ 候选阵营全集）完全同构——「送卡没人用 = 纯浪费」是全集门「加成阵营没人用 = 纯浪费」在角色粒度的镜像。

**结构机器与既有多角色网络同源**：角色→路线复用网络 `char_routes()`（`cw_comps.py`，core+shared 计入、transition 不计，理由原文「transition_chars 不计(那是打工后卖的,不构成路线)」）就是本判据需要的全集。送卡型自己的「全集门」：

```
candidate_char_universe(evicted) = ∪ {core_chars ∪ shared_chars} over {comp ∈ COMP_LIBRARY | comp.name ∉ evicted}
失格谓词 = (即时 ∪ 条件发放角色集) ∩ candidate_char_universe(evicted) = ∅
```

失格 → 分数维持 0（与总纲全集门同款失格语义：落 0 即天然垫底，零新常量），归因 `env-gift-off-universe`。当前注册表下 7 契约 + 4 专家**无一触发**（逐条直调核验见 §2.1.1 表 + 分档表）——门是结构性保障（COMP_LIBRARY 演化时自动咬合），不是现修行为。

**分档阶梯（提档语义）**：命中按命中档最深者定档，档 = 角色在候选套中的身份：

| 档 | 判据（对单张赠卡） | 当前注册表实测（直调） |
|---|---|---|
| core 命中 | char ∈ 某非 evicted 套 core_chars | 卡芙卡 core×3（DOT队/专家桑博DOT/千冶减益）、花火 core×4、符玄 core×6、银狼LV.999 core×2、远坂凛 core×2、吉尔伽美什 core×1、丹恒·饮月 core×1、希儿 core×1、桑博 core×1（专家桑博DOT）、黑天鹅/火花/Archer core×1、开拓者·欢愉 core×3（绯英欢愉/火花星间旅人/狼尊欢愉） |
| shared 命中 | char ∈ 某非 evicted 套 shared_chars（且非 core） | 椒丘 shared×1（千冶减益）、流萤 shared×1（巡海击破）、银狼 shared×2（昼神阿雅/火花星间旅人） |
| transition 命中 | 仅 transition_chars | （条件赠卡候选档，当前无落地条目） |
| 全集外 | 三名单皆不在 | 砂金、托帕&账账、停云、加拉赫、随机战技点角色 |

（直调复核 2026-09-12 对抗批：上两表逐位复算通过；开拓者·欢愉 core×3（绯英欢愉/火花星间旅人/狼尊欢愉），卡芙卡在任何候选套均无 shared/transition 宿——evicted 场景推演见 §2.1.4-5。）

**环境档 = min(赠卡集最优档, 语义折扣)**，三条规则（全部是定序规则，零数值）：

1. **即时优先**：环境档 = 即时发放集的最优命中档；即时集非空时不看条件集（确定性赠卡是估值的承重面）。
2. **advisor 折扣**：特邀专家「顾问入商店」与契约「直接送卡」**分语义建模、共结构**——两者共用同一成员机器（角色全集/三档名单），但顾问不是白得资产而是「创造一个可购买的购买选项」，需再花店价（金）且占购买预算，价值严格低于同档白得。实现 = 同一套档位判定，advisor=True 的条目在档位阶梯上整体降一族（见下表 A 档 < G 档）。分开建模的理由：白得资产改变「已有多少进度」，付费期权改变「能不能买到」——前者是资产账、后者是可得性账，混同会把「送卡」与「入商店」的语义差抹平（契约 conditionally 免费送 Archer = 圣杯线非购买核心卡的额外获取通道，语义上与「商店多一张可买」完全不同量级）。
3. **条件降档**：即时集为空时，取条件集最优档**降一档**（core→shared→transition→全集外）。理由：条件发放的兑现概率 < 1 且依赖后续行为（量子同频契约要先把花火/缇宝升星、星核猎手契约要凑银狼家族同战），定序上只能给「弱一档的确定性」。条件描述文案入 `GiftGrant` 注释字段（可读性 + 实采对账用），不进判据。

**档位 floor 常数（定序实现常数声明，ADR-0524 同族先例）**：`ENV_FACTION_MATCH_FLOOR`（邀请 70/契约 72/概念股 78）的承重语义先例 = 「匹配 ⇒ 提到本档位，压过全体 env 裸分（上界 72），禁读作基数」。本阶梯同法：值只承载档间定序与对既有域带的位次，禁读基数。

| 常数 | 值 | 锚点推导（顺序即设计内容，值是实现载体） |
|---|---|---|
| `GIFT_FLOOR_CORE` | 66 | > 58（契约裸分最大值 战技点契约：白得终局线 core 成员的结构化评估不低于任何契约的历史拍脑分）∧ < 70（最低阵营 floor：静态全集证据弱于 D* 动态对齐）∧ ≤ 72（env 裸分域上界 彩虹时代：不凭结构档推翻 ADR-0144 知识评估的最强项）|
| `GIFT_FLOOR_SHARED` | 60 | < CORE ∧ > 58（shared 白得 > 契约裸分最大值的同理锚）∧ 只作演化结构位（当前无落地条目） |
| `GIFT_FLOOR_ADVISOR_CORE` | 54 | < SHARED（付费期权 < 白得，同档位类）∧ > 52（结构性可比簇上界 = 过剩经费/劳务派遣合同 52，同簇 人才储备 48/敌后破坏 46/深井角斗场 42——经济通道/改写/战力类各属他族不入本簇：阵容线入口型顾问的价值证据 = ENV_COMP_AFFINITY[特邀专家:桑博]={专家桑博DOT:1.0} + 攻略实证「开局必须刷专家邀请环境」，强于裸分 35 的历史拍脑依据）∧ < 55（头彩：单取卡品质升级的结构档让位于其知识评估分） |
| advisor shared/transition、条件降档后非 core/shared | 无 floor | 维持裸分（特邀专家:停云/加拉赫/银狼 全部落此） |

**当前注册表下的落点（直调核验）**：命运圣杯契约/战技点契约/星核猎手契约/持续伤害契约/欢愉契约 → 66（即时 core）；量子同频契约 → 60（即时空，条件 core 降一档）；特邀专家:桑博 → 54（advisor core）；特邀专家:停云/加拉赫/银狼 → 裸分维持（38/42/30）；公司契约 → 阵营全集门先行击杀（faction=公司 ∉ 全集，见 §2.1.4）。**阶梯的现值判别力弱（6/7 契约同为 core 档）是如实观察**：本机器的承重面 = 失格门的结构保障 + COMP_LIBRARY 演化鲁棒性 + 开局帧契约 vs 非发卡环境的位次修正，不是契约间精排（同档并列时 argmax 取左槽，归因串可辨，不作二次分辨）。

#### 2.1.3 结构与落码面

- **数据结构** `GiftGrant`（frozen dataclass，落点 `kernel/cw_investments.py` `InvestmentEnv` 同区）：
  ```python
  @dataclass(frozen=True)
  class GiftGrant:
      chars_immediate: tuple[str, ...] = ()      # 取环境当场发放的具名角色（效果原文「获得【X】」直读）
      chars_conditional: tuple[tuple[str, str], ...] = ()  # (角色, 条件描述原文摘要)——注释性字段,不进判据
      advisor: bool = False                      # True=专家顾问入商店语义(特邀专家);False=直接送卡(契约)
      sell_value_note: str = ''                  # 卖价残值注记(【注】下界;不进分值族,§2.1.2-2)
  ```
- **注册表** `ENV_GIFTS: dict[str, GiftGrant]`：白名单制（表外环境一律无条目，禁从效果原文自动猜装，总纲 §2.2.2 同款纪律）；孤儿键 import 即炸；构建期断言 `set(ENV_GIFTS) ∩ set(ENV_ECONOMY) = ∅` 且 ∩ `ENV_POOL_REWRITE` = ∅（§2.3 单一环境只落一个估值结构，防双通道叠加）。
- **判定 helper**（落点 `kernel/cw_comps.py` `candidate_faction_universe` 同区——全集派生 helper 区，消费同一 COMP_LIBRARY）：
  - `candidate_char_universe(evicted) -> frozenset[str]`：∪(core∪shared)，evicted 过滤与总纲全集门同源同义（零接口新增，`decide_event` 现有参数直通）；
  - `gift_hit_tier(grant: GiftGrant, evicted) -> str`：返回 `'core'|'shared'|'transition'|'off'`，实现 §2.1.2 三规则（即时优先/advisor 标记由调用方换族/条件降档）。单帧单读纪律：`decide_event` env 分支循环外算一次 universe 快照（总纲 §2.1.2 D* 快照同款）。
- **消费位**：`cw_events.py` env 分支内、阵营 floor 判定同层新增 max() 支：
  ```
  grant = ENV_GIFTS.get(_env.name)
  if grant is not None:
      tier = gift_hit_tier(grant, evicted)
      if tier == 'off': 失格(0, reason='env-gift-off-universe')     # 与全集门同款失格
      elif 命中档有 floor 常数: score = max(score, GIFT_FLOOR_x); reason='gift-core'|'gift-shared'|'advisor-core'
  ```
- **次序位次**：静态档（54-66）落在裸分域上段与阵营 floor（70-78）之间——「开局白得候选线成员」强于裸分拍脑、弱于意向对齐。对总纲 §2.3 次序表的插入见 §2.3。
- **fail-closed**：环境不在 `ENV_GIFTS` = 无发放语义 → 走既有分支，行为不变；`GiftGrant` 条目存在但角色名与 `CHARACTERS` 注册表不匹配（版本漂移）→ 构建期孤儿校验炸出（与 ENV_GIFTS 孤儿键同批校验），不静默。

#### 2.1.4 正交性与交互（逐门推导）

#### 2.2.2 两层拆分推导（基数经济层 + 定序残域层）

品质改写改变「我们能取到什么」。一张策略卡的价值有两半：**可算的金流半**（EconomyEffect 注册表数值通道，基数）与**不可算的功能半**（战力/阵容功能/选卡挑选价值，战力域 + 定序域）。拆分公式：

**层 E（基数，拟入经济域带）**——改写后取卡金流期望的抬升：

```
μ_E(q; H) = (1/|S_q|) · Σ_{s ∈ S_q, 品质=q} econ_gold_v1(s; H)      … 品质子池金流均值
ΔV(R)     = Σ_{k ∈ picks(R)} [ μ_E(q_R; H_k) − Σ_q π_offer,k(q) · μ_E(q; H_k) ]   … 改写抬升
```

- `S_q` = 注册表品质子池（实测 |S_银|=77 / |S_金|=135 / |S_棱彩|=123，直调 `INVESTMENT_STRATEGIES`）；子池内均匀随机 = 选卡挑选价值不出现在基数层（挑卡是定序残域，见层 Q）。
- `econ_gold_v1` = **受限直接金流/XP 通道**（与总纲 A 类通道同族的确定性子集）：instant_gold、gold_per_node、interest_flat_per_node、xp_per_node×XP_GOLD_RATE(=1.0，裁定 4 暂定)、gold_per_boss_node×剩余首领数、gold_next_nodes_amount×min(count, H)、gold_at_level、xp_instant×XP_GOLD_RATE。**明确排除**（行为依赖，v1 无参数化）：刷新族（free_refresh_*/概率事件/采购专员/高效决策）、息档覆写（interest_cap_override）、合成/卖价族、血本位族、xp_per_refresh/xp_buy_cost_discount。
- `H_k` = 第 k 次取卡后的剩余节点视界（【推】：`schedule_of` 先验 (9,9,9)=27 节点，首取卡点 = 1-3 节点完成后（`docs/game/currency_war/research/screen_flow_timing.md` #11）→ H_1 ≈ 24 参照；H_2/H_3 需取卡点位实采）。
- `K`（每局固定取卡张数）= **3**【推·效果原文序数】：头彩点名「第一个投资策略」、尾彩点名「第三个投资策略」、银·金·彩把「固定节点」取卡集按银/金/彩三品质槽改写 → 固定取卡集基数 = 3。实采核对挂账（档案 active_strategies 终值未导出，本次直调未取得，见 §2.2.6）。
- `π_offer,k(q)` = 无改写环境时第 k 次取卡的 offer 品质分布，**估算注册表参数【拟】**，入式前按已知三品质份额归一（「未解析」份额不单列建模，归一口径随数据批申报）。本次从对局档案实测的初步读数（123 个非改写环境局，`.debug/currency_war/telemetry/live/invest_cards.jsonl` 直调，仅开局帧有记录；**采样警告**：档案帧未区分「取卡 offer」与「同一次取卡内刷新后的新 offer」，第 2/3 组可能混入刷新帧，数字只证「可测性」不作参数值）：第 1 次取卡 offer 银 22% / 金 41% / 棱彩 18% / 未解析 19%；第 2 组 银 27% / 金 38% / 棱彩 23% / 未解析 12%；第 3 组样本不足（n=23）。默认 offer 不是「三品质各一」（金重仓 40%±），这推翻「银·金·彩只是槽位重排」的轻读法。
- `picks(R)` = 被改写的取卡序号集：时代 = {1,2,3}；头彩 = {1}；尾彩 = {3}。

**实测初步数字（【拟】非决策级，受限通道 + H=24 参照）**：μ_E(银) = 3.31 / μ_E(金) = 2.42 / μ_E(棱彩) = 4.16（对照 instant_gold-only：1.91 / 1.36 / 2.89）。

**关键发现（决定 v1 行为）**：受限通道下 μ_E **不随品质单调**（金 < 银）。金品质池的直接金流均值反而低于银（银池有 特战资金 21-33、成长基金 40、尾款交付 30 等纯金流卡；金/棱彩的价值大头在功能半与被排除的行为依赖通道：棱彩池的引擎密度——高效决策 9999 免费刷、利息上调 cap→10、淘金客、本金充裕系——全部落在排除集）。后果：若 v1 直接把受限 μ_E 的 ΔV 放进经济域带，会得出「白银时代(35) > 黄金时代(55)」的病态序——±1-2 金的池均值噪声翻转功能序，决策被噪声驱动。**裁决：层 E 公式在册、参数在册、v1 恒 resolved=False（fail-closed），时代/头彩/尾彩 v1 维持裸分（现行为零变化）**。层 E 转正的准入门（数据批义务，两条件缺一不入）：

1. 全通道 μ_E 重算：排除集通道用估算注册表既有/新增参数补齐——E(对局刷新次数分布)（总纲 §2.2.4 已列）、息档覆写经 P47 息损递推【推】（`math_proofs.md` P47 已证，零新拟合）、合成/卖价经既有参数；
2. 序一致性检验：全通道 μ_E 的品质序与品质游戏序（棱彩>金>银，【注】）及 pick_value 品质中位序（45>35>32，定序证据）方向一致；不一致 = 基数层测的不是「品质的价值」，维持 fail-closed 并回炉通道定义。

**层 Q（定序残域，维持裸分）**：池内挑卡价值、卡的功能价值（战力/阵容耦合）不可基数化——pick_value 是定序分（ADR-0524 禁读基数），功能价值在战力禁令域（宪法 §1.1）。品质的功能序只剩方向性证据：品质游戏序【注】+ pick_value 品质中位 彩 45 / 金 35 / 银 32（定序）。层 Q 的消费载体 = 环境**裸分维持不变**（彩虹 72 / 黄金 55 / 白银 35 / 头彩 55 / 尾彩 52 / 银·金·彩 62 / 联席决策 50，ADR-0144 知识评估已经对两半作过知识性净评）。两层从不相加：层 E 转正后经 max() 独立进经济域带（总纲 §2.3 门 3），层 Q 留在裸分——max() 结构天然承载「层 E 有值时以域带参与、无值时裸分兜底」。

#### 2.2.3 白银时代难度腿的辖域声明

品质→敌人难度机制 = 游戏定义【注】（白银 +0 / 黄金 +3 / 棱彩 +6（每拥有 1 个）；`docs/game/currency_war/research/economy.md` 难度精确口径行，2026-08-26 用户定谒，溯源 = 米游社攻略+社区截图实证——非遥测对拍，不标【注·对拍】子型）。白银时代第二条效果的收益 = 免去高品质策略的难度抬升。**难度-收益折算出辖**：难度影响胜负需经战力/胜率建模，宪法禁（00_framework §1.1/§3）；难度数值本身可结构化登记（`EconomyEffect.difficulty_delta` 先例，「36 号账本消费」同款——数值在册不折金）。落地：`StrategyPoolRewrite` 带 `difficulty_exempt: bool` 字段如实登记该腿，注释引 economy.md 口径；不产生任何分值。彩虹/黄金时代的 +3/+6 难度成本同理不进层 E（层 E 因此对它们**偏高估**——如实声明，净评由裸分的知识判断承载，这是定序残域的辖域代价，不是遗漏）。

#### 2.2.4 数量通道（联席决策 +1 取卡 / 银·金·彩 刷新 +2）与 A 类策略大师对齐

| 备选 | 为何放弃 |
|---|---|
| 送卡·角色战力/强度估值 | 宪法 00_framework §1.1 禁战力建模；无游戏定义强度值可查（§2.1.2-1） |
