# B1 银狼LV.999·幻月核心(银狼LV.999·欢愉+幻月游戏双核)

> 一句话定位:以银狼LV.999 为核心、欢愉+幻月游戏双羁绊开档的经济速攻队——狼尊既是主 C 又是全队三星加速器,千星商会供钱供星喂星神★阿哈升格;速 8/9 成型后靠「体系滚雪球+阿哈时刻爆发」赢下终局。帖间签名:欢愉 65/68、幻月 64/68、爻光 62/68、阿哈 59/68、真珠 59/68——高度同质,幻月经济家族旗舰成立。
>
> 家族注:同族 B2 绯英/B3 星神★阿哈/B4 砂金各自独立成文;H5 不死途混编终局类的宿主=本板(B1 班底+不死途/帕姆王双 C 变体),本篇不展开。

## 1. 骨架

**具名核心**(不可替换的人 + 功能链位置):

- **银狼LV.999(帖称狼尊,r3 前排)**——主 C + 体系发动机双引擎。输出端:穿核心三件套(见 §3);体系端:自带复制类能力与插件(帖间原话「狼尊的拷贝仪、扑满病毒、幻月卡带可以帮我们更容易三星需要的牌」「银狼选择复制插件帮助自己和队友快速3星」)——它是体系的发动机而不只是输出点:连「阿哈当 C」的局,银狼依然 3 星满配在场[米游社,至少 3 帖同述]。
- **星神★阿哈(r4 买入→r7 升格)**——第二 C/上限件,机制由幻乐之主羁绊承载(见 §4)。没有它的局上限明显低[米游社]。
- **爻光(r3 后排)**——功能主轴(62/68 在场)。反重力皮靴×2-3 专属户;主角光环称号(社交达人/社交大师)的社区指定佩戴者;千星流里可升格当主 C(3 星爻光局存在)。
- **真珠(r1 后排)**——千星链最低费成员+防御功能位+开局启动器(蓄能帆→银狼开局开大)[社区,待实机]。

功能链角色:火花(r1,前期主 C/打工,后期副 C)、花火(r2,前排充能辅助)、砂金·戏浪(r4,第三位面刚需前排副 C,可完整继承狼尊三件套)、千冶·刃(r4,功能位)、翡翠(r5,黑市主理人,三星后刷钱引擎)、不死途(r5,凑 7 幻月挂件)、知更鸟·晴歌(r2,拉条充能启动阿哈)、托帕&账账(r1,千星链/腾位卖件)。

**羁绊档位目标**:

- **欢愉 5/6 档 + 幻月游戏 5 档**=标准双开成型档[米游社,帖间多数;个别 8 欢愉/7 幻月局]。双开的结构原因:幻乐之主升格吃「幻月游戏或欢愉」两侧角色总星级——双开=给阿哈两条供弹线;且两羁绊共享角色(火花/爻光/花火多栖),凑档成本低。7 幻月=胡局变体(加不死途)[米游社]。
- **千星商会 2→4→6 档阶梯**[图鉴,trait 100602]:全表唯一按「场上三星千星牌数」计数激活的羁绊(官方:「每上场1位3星【千星商会】角色,将激活1级羁绊效果」);layer1「每次花费金币刷新商店时,获得1点经验」;layer5「获得【千星·特权赋予卡】。根据本局商店刷新次数充值该卡,每15次可用次数+1」;layer6「商店中的角色随机升星为2/3/4星,但只需要1星的价格即可购买!」——「满级羁绊=结束游戏」是社区叫法[米游社]。成员链真珠/托帕/瓦尔特(1 费)→花火(2 费)→砂金(4 费)→翡翠(5 费),自带低费到高费的三星爬梯[米游社,结构统计]。
- **星核猎手 2/3/5 档**(白嫖剧本装备,见 §4)[图鉴,trait 100802]。
- 变体副档:连击 4(后台 1 号位连击地格+连击额外 30% 真实伤害)[图鉴,trait 200402 layer4];小小巨人 3(敌方全体受伤提高 24%、造成伤害降低 12%——效果对象是敌方,不是我方增益)[图鉴,trait 100902 layer3];守护 3、能量 2(layer2「激活2名【能量】角色的终结技,25%伤害增幅」)[图鉴,trait 200902]。
- **三羁绊飞轮**(本板机制链,各腿出处见上):千星商会出钱出星(刷新经验/免费刷新/1 星价升星商店)→场上欢愉/幻月角色总星级抬升→喂幻乐之主升格(7 费星神+商店神迹+阿哈小道具回流经济与战力)——「经济→星级→升格」闭环,这是千星+幻月+欢愉三羁绊同挂的结构原因。

**自由槽**(带标签即坐的位置):9-10 人口(个别局 11 超编,两帖)给:符玄/藿藿/缇宝(守护/奶)、星期日、开拓者、绯英(2 费可 C)、雪衣/风堇/寒鸦(变体)。最后槽位按缺档羁绊填——凑 8 羁绊任务局的剩余位常塞连击/召唤角色[米游社]。

## 2. 星级目标

- **狼尊按低费追三线定档:3 星=标准成型线,但 3 星不是硬门槛**——68 帖中约 45 帖(67%)三星,约 1/3 的胜利局以 1-2 星狼通关;未三星的局普遍以「满装备+阿哈 C 补偿」取胜(2 星通关与 1 星+满装备通关均帖间多例)。星级资源优先砸狼尊与阿哈。
- 星神★阿哈:4 费买入→升格 7 费后可升星(★2/★3 多帖);经济最好的局追三星阿哈+三星翡翠(双五费三星大满贯形态)。
- 火花:1 费过渡期追三(好三星);千星流:低费千星牌全三星(直接喂 STAR3 激活层数)+五费追三。
- 辅助一律 1-2 星即用:爻光/真珠/花火 1-2 星为常态;三星爻光只在千星流升格主 C 时追。

## 3. 装备配方

逐件到人;件间为独立叠加,无链条合成关系实证。

- **狼尊标准件:高周波电锯 + 火力风暴潮 + 未唱名面具**——核心三件(帖间统计电锯 47/风暴潮 60/面具 47,覆盖绝大多数胜利局)。碎星斩舰刀=第 4 件(×14,明显低频),「有条件」再合;第 5-6 件高配位:斩首行动/杀红眼/反螺旋舞步。
- **阿哈时刻装备**(给欢愉召唤的阿哈,不是星神★阿哈单位——两个实体,装备栏各自独立):3×火力风暴潮[米游社两帖]或 2 电锯+1 风暴潮——纯输出,决定「阿哈时刻」爆发。风暴潮全簇计数第一(×60)的直接原因:阿哈时刻要求一次堆 3 件,单局消耗量大。
- **爻光**:反重力皮靴×2-3+永动机/蓄能帆——攻速/充能专精,不穿输出装;爻光主 C 特例走星航履+皮靴+充能件。
- **真珠**:防御套(痛觉阻断芯片/绝对热量/生命之环/很硬的甲;特权装备可同名重复穿戴,两帖实证)。
- **星神★阿哈**:永动机+胜利之旗+武器大师;经济局带财富宝钻(团队规模上限+1、装备者每 3 备战阶段 1 金[图鉴,config 装备原文])。
- **火花**:高周波电锯+动能激发剑+碎星斩舰刀。
- **星徽当装备**:千星商会/幻月游戏/欢愉/连击/追击/梦境交织星徽可穿在任意单位身上,可多枚分散叠加(官方语义「装备者加入【X】羁绊」[图鉴];多枚叠加帖间多例)。注意:云上五骁与少女乐队无星徽条目——峰 D 少女乐队变体少一张凑档牌。
- 基础件→成装对应(单帖观察,供选秀参考):轮滑鞋/折叠小刀→火力风暴潮;蓝钻→连击星徽;护甲/手枪→未唱名面具(「阿哈装备有护甲或手枪时强烈推荐合成未唱名面具」)。
- 合成顺序:无帖间一致的合成序列实证,不写。

**家族禁忌(机制红线)**:

1. **花火战技不要给狼尊**——狼尊大招只有一动,套了会丢阿哈时刻大量伤害(作者亲测[米游社单帖,后果重故收录])。
2. **星核猎手白嫖的随机剧本装备会与计划合成撞车**——先规划全队装备再让羁绊发装备[米游社]。
3. **「缺鞋」是本簇通病**——鞋类基础件优先级最高,选秀尽量奔着装备拿[米游社]。
4. 次级:连击局留折叠小刀合连击星徽,别乱合基础件;昔涟没永动机别上场(均单帖)。

## 5. 达成路径

从位面 1 长到成型的站点序列(本板流向知识唯一归属地;帖语「D/D牌」=刷新商店搜牌):

1. **开局(位面 1)**:打工体系任选其一——火花+花火平推、瓦尔特(帖称老杨)带狼尊装备打工、二列车、仙舟/DOT 过渡;目标是欢愉+幻月低档双开[米游社]。经济优先:第一位面连败卖血攒经济合法(单帖例);奖励关优先补体系牌(爻光优先)。
2. **中期(位面 2)**:升 7 级或速 8/速 9(帖间主流:速升 9×16 帖/速升 8×11 帖/7 级搜牌×26 帖——节奏与子流派强相关:千星/低费三星局锁 7 级,标准流速 8/9)。卡利息慢 D 狼尊与千星牌;停手信号:D 不到狼尊剩 20 块停、预留 30 块(单帖例:1-9 升 6、2-9 升 8、boss 战前不 D)。狼 3 星前插件用复制(加速全队三星),三星后换脆弱(增伤)[社区]。
3. **阿哈线**:中期买入阿哈→攒幻月之力升费→升格 7 费(帖间站点:虚照类道具点到 7 费后必须上 9,单帖例[社区道具]);充能/拉条件(爻光永动机、知更鸟·晴歌)启动阿哈时刻。
4. **高费补强(位面 3)**:砂金·戏浪=第三位面刚需;翡翠 9 级后追三星(黑市刷钱引擎;单帖例:3-7 前上 9 找 3 星翡翠);不死途凑 7 幻月;9-10 人口满编。
5. **成型判据**:狼尊 3 星+核心三件套;阿哈升格 7 费(进一步 ★2/★3);千星 6 档+低费千星牌全三星;欢愉 5 档+幻月 5 档。满足其一即为成型,按子流派偏重不同。

## 6. 流派与降级

**多峰判定(四峰,一离群)**:

- **峰 A 标准流(绝对主流,约 45 帖)**:狼尊核心三件套,幻月+欢愉双开——本文主体。
- **峰 B 连击狼(4 帖)**:连击星徽+反螺旋舞步+追击/梦境交织星徽全家桶;社区描述「开大自动进入无敌玩家状态,无限叠增伤」「连击 4/3/2 动强普消耗一次」[社区,连击层机制待实机];官方连击 layer4=后台 1 号位连击地格+30% 真伤[图鉴]。
- **峰 C 千星刷钱(5-6 帖)**:千星商会星徽+财富宝钻+翡翠黑市循环,追三星五费;触发变量=开局拿到千星转职(「有千星商会转职直接无脑玩」「没有一两个千星转职很难追到6千星」——缺转不开此流)[米游社]。
- **峰 D 局型特化(6-8 帖,离群)**:火花主 C/少女乐队大合奏/雪衣无限流/8 羁绊任务局/星核猎手成就局——由当局任务、成就或来牌决定,不主动选。

**分岔变量**:①开局/局内星徽(千星转→峰 C;连击星徽→峰 B);②幻月当局规则(战技点奖池→火花无限动[社区]);③翡翠黑市招牌商品(投影仪/复制星神→刷钱)[社区];④局类型(成就/任务→峰 D);⑤星核猎手装备质量→9 级分支[米游社]。

**降级路径(帖间实证的指令级写法)**:

- 经济不足:停 8 级找 3 星银狼稳通关(帖间最明确的低配降级句)。
- 主 C 来牌不顺:火花↔狼尊主 C 互转;或主 C 银狼/绯英二选一。
- 星核猎手装备差:9 级分支——装备好开刃+主角光环,装备差下主角上缇宝藿藿开小小巨人。
- 拿不到星徽:用宝石合转职。
- 生存/人口紧张:知更鸟·晴歌换奶位;下开拓者补生存位;备战席不够卖托帕腾位;人数不够卖星期日。
