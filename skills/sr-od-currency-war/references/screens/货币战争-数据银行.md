# 货币战争-数据银行

## 画面简介

图鉴族的总门户（进各图鉴的入口页），也是各图鉴收集进度的读数位：从大厅右侧进度面板的「数据银行」入口卡进入。主体是横排错位的晶石卡——上排 4 枚（羁绊图鉴 / 装备图鉴 / 投资环境图鉴 / 奇遇图鉴），下排 3 枚（角色图鉴 / 投资策略图鉴 / 主角光环图鉴），每枚晶石下带名字条与收集进度 n/m（动态值），奖励可领的卡带红色「!」角标；上排最右一枚被画面右缘截断，右缘中部有翻页控件。左上标题「数据银行」+ 扩充倒计时，右上返回箭头。本页没有图鉴子页顶部那条切换条。

离线建档声明：布局与读数来自归档帧；「大厅入口卡 → 本页」「晶石 → 装备图鉴 / 主角光环图鉴」的进入关系来自实机探索的帧序（大厅帧 → 数据银行帧 → 装备图鉴帧 → 主角光环图鉴帧），其余晶石与翻页、返回的点击行为未单独实测。

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 进入本页 | MCP `click` | 大厅「入口-数据银行」area 中心（识别返回坐标） | 进数据银行主页 | 入口是面板里的文字卡、非胶囊按钮 |
| 进某图鉴 | MCP `click` | 对应「入口-xxx图鉴」area 中心（识别返回坐标） | 切到对应图鉴画面 | 只有装备图鉴 / 主角光环图鉴两屏已建档并登记了跳转边；其余子画面尚未建档，进去后看图操作 |
| 看下一页晶石 | MCP `click` | 「按钮-翻页右」area 中心 | 翻页 | 点击行为待实机核对；晶石 area 以名字条文字为锚、矩形按本页位置建，翻页后位置变化要重新核对 |
| 返回 | MCP `click` | 「按钮-返回」area 中心（模板匹配位置） | 回上级 | 去向待实机核对 |

查数据优先走 MCP 查询工具（cw_char_lookup / cw_trait_lookup / cw_equip_lookup），不必进画面翻图鉴；进画面只在核收集进度或截图取证时需要。进入货币战争用 `CwEntryEnter {}`；本页无专 op。采集通道：`HarvestInvestCodex`（投资策略图鉴逐页采集）；其余图鉴子画面尚未建档，按采集需求另派建档。
