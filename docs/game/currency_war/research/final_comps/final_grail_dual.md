  连续行动**——速度/拉条堆到极高后,该角色在行动条上永远排第一,
  其他角色永远轮不到,形成「一人无限连动」的时间轴锁定
  (「十万速风扇金闪闪锁轴无限大」「双风扇金闪闪锁轴一大400亿」
  ——金闪闪堆极限速度后独占行动条,无限开大)。⚠️ bot 注意:
  #14「别开自动不然拉条会拉红A 不给saber」——自动模式的拉条目标
  选择会破坏锁轴(把拉条给错人)——**锁轴类阵容的自动战斗风险
  不在「不能锁」而在「拉条目标错误」**;圣杯类 3 篇提及,观察级。
- **六命 Saber 形态**(#76/#82/#89):刚需 6+5(局外门槛,不入选);

### 1. 赢的机制链(羁绊原文→技能→装备)

**第一环:命运圣杯是「经济+战力」双引擎羁绊(官方 layer 原文)**
- L2:「25% 前/后台强度。**开启首个祈愿试炼**」——第一层就是任务系统入口
  (圣杯2=经济挂件的机制根据);
- L3:50%+第二试炼(出现诅咒试炼);L4:100%+第三;L5:180%+最终——
  **强度曲线本身就是全游戏最陡的一档**(对比列车6=60%×3 层)——圣杯高层
  光靠羁绊面板就是主输出来源之一,不只是发任务的工具羁绊。
- 试炼激活判据(⚠️ 史料级):任务进度只在**对应羁绊等级激活**时才计数,
  「未激活→做了不算」——这是「圣杯三件留牌、2 件上场开任务」节奏的机制
  约束:上 2 件开 L2 任务,4 件才开 L4 任务的账。

**第二环:双 C 接力的技能层(API skill 原文 + 底稿星3 文本)**
- Saber 1星(API):「我方小队其他目标施放终结技后,使 Saber 的终结技能弹射
  更多次数」——**别的角色开大=他变强**,注定吃「全队高频开大」环境(能量
  羁绊);星3(底稿 #9)加炉心共鸣回能+满能自拉条→伪永动机。
- Archer 1星(API):「连续施放的第 5 次战技会**消耗所有战技点**并额外造成
  大量伤害,终结技攻击敌方全体」——注定吃「战技点囤积」环境(战技点羁绊
  L4:24% 伤害+24% 速度+上限+3+抽奖)。
- 远坂凛 1星(API):「获取宝石能量额外**召唤 Archer 发动连携攻击**,消耗
  宝石能量提高我方暴击伤害」——凛是 Archer 的触发器/粘合剂(⚠️ 史料级:
  凛必须站前排,联系技触发红A被动最大攻击产点+叠 77% 暴伤)。
- → **两条互斥的燃料线**(能量 vs 战技点)对应 Saber 主 C / Archer 主 C
  两个子形态,阵容构造=选一条燃料线+把生产端和结算端都买齐。

**第三环:燃料生产端(技能原文)**
- 花火(1星):「战技点上限提高。终结技恢复战技点+暴击伤害,前台攻击或

### 5. 装备原理

双 C 的装备路线是**燃料类型的外化**:Saber 线=能量件(永动机/冷笑话/电光履)
——终结技弹射循环;Archer 线=攻击段数件(风暴潮/电锯/动能剑)——战技连发
叠层。底稿三条装备路线的统计(54/41/32 vs 87/38/17)与本文 196 篇口径方向
一致(Archer 风暴潮 98 仍为第一大件)。任务奖励决定专武(阿瓦隆=剑鞘,
底稿 #100「没有剑鞘伤害少 20%」):装备路线与任务选择耦合(「看任务给什么
武器再定谁做」#13)——**装备即入场策略的下游**。
