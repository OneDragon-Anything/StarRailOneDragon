# 希儿量子(A 级,A8-50 最强轮椅)

> V4.4 合集 76807134:A 级。攻略直读 [76802749](https://www.miyoushe.com/sr/article/76802749)。
> ⚠️ 调研摘要曾误标"欢愉",原文核实 = **量子 + 贝城(贝洛伯格)**。
> 代码字段:`COMP_LIBRARY["希儿量子"]`。

## 机制(怎么 work)
希儿 = A8-50 **最强轮椅**:超模斩杀 + 70% 血以下二次战技 + 再现 + 造物引擎。V4.4(A8-50)加强:**2 贝城 = 原来 4 贝效果**,引擎只需贝城角色动 10 下就拉条。

- 羁绊:**4 量子同频 + 贝洛伯格(2 贝)**

## 成型阵容
希儿(双电锯+风暴潮)+ 杨叔(瓦尔特)+ 记忆主 + 知更鸟(鸟)+ 刻律德菈(复制战技,多动)+ 布洛妮娅(鸭鸭,替佩拉)+ 符玄(奶瓶/胜利之旗)。

## 成型节奏
1. **前期强势**(希儿无装备也能换怪/胜)→ **强烈推荐希儿过渡**。
2. 过渡:娜塔莎(开 2 贝)/刃填空位/多上通拐。
3. 希儿多 → **7 级找 3 星**;不多 → 先上 8/9 找 4-5 费同时找希儿;实在 3 星不了就不三。

## 装备
- **希儿:双高周波电锯 + 火力风暴潮**(对装备要求低,可把把硬玩)。
- 符玄:奶瓶(生存压力大)/ 胜利之旗(压力小)。

## 弱点
- 最终 boss 是**剧目 / 蕉研组**时希儿难度大 → 给 2 星鸭鸭带输出装有奇效。
