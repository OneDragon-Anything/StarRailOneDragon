# ADR-0479 段级检查接入生产局遥测路径(P2 血降堆金检查 + 判读 CLI 接线)

## Status
accepted (2026-08-30)

## Context
2026-08-30 跨局复盘(三实机局)证实:P2 段线已锁定、hp 连败、带金 86-113 堆积死亡,而生产检查器(v2 栈)只跑 coldstart 开局检查,段级检查([17] 溢余即花族)只挂在 sim 段级短跑/冷启动路径——同类病理在 sim 早已可抓,实机零标红,只能人工判读发现。复盘立案A 定性为「检查器接线件,低风险先行」:检查器判据已有变异自检锁钉死,只扩覆盖面。

## Decision
1. **新增段级检查 `seg_p2_bleed_gold_stack`**([17] 的 P2 位面延伸),入 `_SEGMENT_CHECKS`(sim 批顺路扫,回灌纪律)。判据:plane≥2 决策轮,决策时点金 > 息线+容忍带(带宽与 P1 [17] 同源,ADR-0478),金较上轮未下降(小买不改堆积趋势——局2 P2 有 2-3 笔小买仍 86→112 堆积,按「零花费动作」判会漏报),hp 较上轮下降(血在掉;血线稳定的攒息是合法面),连续 ≥2 轮才报(防恒触发)。formed_stop 不豁免([13] 成型停手是 P1 过渡段语义)。
2. **生产接线**:`run_checks_on_replay`(判读 CLI `cw_telemetry checks` 的执行体)对每局决策帧做**轮合并适配**(生产一轮 5-12 帧 vs 段级检查一轮一行口径:金/hp 取首帧决策时点,花费动作跨帧并集,`state.board`→`board_factions` 同构映射,`bench_full_flag`→bench 满豁免保守镜像),跑生产可判子集(`seg_overflow_idle_spend` + `seg_p2_bleed_gold_stack`);栈无关(口述判据非栈语义)。
3. **只读报警边界**:事件走 defect 通道供判读消费,不触发任何决策动作、不自动停线。

## Considered Options
- **直接把全部 `_SEGMENT_CHECKS` 跑在生产决策行上**:否——多数段级检查消费 sim 专有键(`shop_waves` 牌面波/income/spend 分解),生产决策迹无同构数据源,接入即失明或误报(如金账恒等式在生产行上必假红)。选「生产可判子集 + 缺口显式声明」,shop_snapshots join 通路后再扩。
- **新检查沿用 P1 [17] 的「零花费动作」判据**:否——实机数据反证(局2 P2 带小买仍堆积),改「金未泄」趋势判据。
- **在生产局战斗环内逐轮跑检查(局中实时报警)**:否——判读是局后消费面,局中报警无消费者且引决策略风险;CLI 按需跑,对局运行时零开销。
- **不动检查网、只靠人工判读**:否——复盘已定性为跨局复发的覆盖缺口,人工判读不具可复现性。

## Consequences
- 重放验收(修前不报→修后报红):局2 `run_20260830_073750` 报 [17] 2 条(P1 溢余 1 + P2 堆金 p2r4);局3 `run_20260830_083542` 报 2 条(P2 堆金 p2r5/p2r6)。
- 语料命中分布(129 局):38 局命中,其中 24 局 P2 loss(病理本体)、其余为 P2/P3 stopped/abandoned 局;**零正常终局误报**。
- hp 可信位口径:生产行 `hp_readable=False` 为 `last_hp_real` 沿用值,下降必是真读,判据可用(沿用停滞只致漏报,保守向)。
- 性能:纯 dict 扫描,百帧局毫秒级,挂在判读 CLI 按需跑;对局运行时零开销,无需采样降频。
- 零决策行为变更:diff 仅触 sim/checks/segments.py(检查网)与 sim/ledger_hooks.py(局后判读),不 import decision 桶;策略/执行层无任何路径变化。

## 验证
- 新检查双向合成锁 + 接线锁(报红/防恒触发/多帧合并口径)入 sr-od-test;
- 受影响测试 48 通过;`cw_quick` L1 全量 1701 passed / 2 skipped / 1 xpassed。
