# 角色养成与升级(character-enhancement)

角色养成四线之一:等级线——升级(经验书+信用点)与晋阶(晋阶材料+信用点,
突破等级上限)。本文是角色等级线的单一入口:决策规则、游戏内实测交互、
操作路由、缺料补齐路径(含④用 MCP 改计划排产)。兄弟分档:光锥线
[light-cone-enhancement.md](light-cone-enhancement.md)、遗器线
[relic-enhancement.md](relic-enhancement.md);行迹线的界面交互与 op 见
basics([../basics/新手与日常决策.md](../basics/新手与日常决策.md))。

## 1. 决策规则

- **等级排养成第一位**(负责人裁定 2026-11-15,全局见 basics「养成优先级」节):
  毕业向五步 = 等级 → 光锥 → 遗器穿对 → 行迹 → 遗器词条精刷——等级与光锥
  升级快、收益直接,排最前。资源有限优先主 C(先练谁:主C → 生存位 → 辅助位
  → 第二队,详见 basics 同节)。
- **等级是行迹的前置**:行迹上限随晋阶解锁(80 级样本:普攻上限 6、其余
  8~10、秘技 1)——先晋阶再拉行迹。
- **晋阶分段制**:等级上限分段提升(60→70→80→…),每段消耗晋阶材料+信用点;
  升满一段后晋阶按钮仍在,需再晋阶开下一段,材料需求逐段递增。
- **满级判定**:满级角色不显示晋阶按钮——按钮存在 = 有升级空间。

## 2. 游戏内交互【实测】

### 2.1. 进角色详情的两条路

- **大世界右上角角色头像直达**——不经角色列表,详情显示头像对应的队伍角色
  (最短路径)。
- 手机菜单 →「角色」→ 角色列表 → 点选角色 → 详情(要挑特定角色时用)。

### 2.2. 角色详情画面结构

- 左栏六页签:详情(等级与属性面板)/ 光锥 / 行迹 / 遗器 / 星魂 / 信息;顶部
  大标题随页签变化(如「角色光锥」「星魂同调」)。
- 顶部头像条 = 最近查看角色的快切,点头像直接切换详情。
- 右上关闭回进入前场景;左下按钮打开角色列表浮层。

### 2.3. 角色列表浮层(挑角色用)

- 列表占左半屏,右侧详情保留显示;网格格子**无名字文本**(只有头像+等级底标)
  ——名字只在选中后右侧详情显示,找特定角色靠头像识别或逐格点选。
- 点格子 = 选中并切换右侧详情,列表保持打开;点浮层外空白 = 收列表且选中保留。
- 注意:列表打开时左下同位置按钮变为「筛选规则」入口(属性/命途筛选 +
  稀有度排序)。

### 2.4. 等级提升(晋阶)界面

- 入口:详情页签右下「晋阶」按钮——**满级角色不显示此按钮**(按钮存在 =
  有升级空间)。
- 界面结构:等级对比(当前等级/目标上限)+ 属性预览 + 「快速升级」开关
  (开 = 自动填材料至可达等级,默认开)+ 消耗材料栏(每格「拥有/所需」)+
  消耗信用点 + 「快速刷取」(材料不够时跳转刷取点)。
- 执行:点「快速升级」**无确认弹窗直接消耗**——点前确认材料栏与信用点充足;
  成功后弹「角色晋阶」结果横幅,点空白关闭。
- **能否升级看按钮文本(两态互斥)**:材料充足 = 白底「快速升级」可点;不足 =
  灰底「材料不足」禁用(不足的材料格数字红色高亮)。
- **缺材料的官方闭环——「快速刷取」**:等级提升界面左下按钮,点击弹窗确认
  (显示缺少的材料与刷取点,如「天人之形·凝滞虚影·难度 IV」),开始后
  **自动连刷直到材料足够**并停止。每次刷取消耗**开拓力 30 + 快速刷取券 3**
  (票为硬消耗,两者都扣;界面右上角显示券库存);开拓力不足时「自动取出后备
  开拓力」开关从后备开拓力自动补。刷完按钮自动变回「快速升级」,即可继续
  升级——升级与刷材料在晋阶界面内自闭环。**刷前检查两项余量:开拓力与
  快速刷取券**。
- 材料来源:晋阶专属材料按材料名反查刷取点(属性池出自拟造花萼(赤),虚影类
  出自凝滞虚影等,逐材料反查为准,见 §5);角色经验书出自拟造花萼(金)。

### 2.5. 老角色加强说明页

- 部分老角色详情带「角色加强」红点提示(版本加强公告),误触点空白即关,
  与养成操作无关。

## 3. 操作路由(已建成 op)

前置链 = 下表依次调用;前置不符各 op 显式失败、不互相补导航,组合编排归
调用方(全部养成 op 的总清单见
[../basics/新手与日常决策.md](../basics/新手与日常决策.md)「已建成的养成 op」节):

| 步骤 | op |
|---|---|
| 导航到角色详情 | `sr_od.operations.goto_character_detail.GotoCharacterDetail`(无参)——任意画面直达详情页·默认角色(大世界右上头像直达路径) |
| 选中目标角色 | `sr_od.operations.select_character.SelectCharacterOp(cn_name='角色中文全名')`(间隔号两式均可)——详情页开列表按名选中(头像模板识别+翻页遍历)→收列表 |
| 切「详情」页签 | `sr_od.operations.switch_character_tab.SwitchCharacterTabOp(tab_name='详情')`——⚠️ 仅无遮挡态(列表浮层开着会显式失败) |
| 晋阶升级至当前上限 | `sr_od.application.cultivation.character.operations.upgrade_character.UpgradeCharacterOp` |

`UpgradeCharacterOp` 参数与消耗门:

- `fill_generic`(默认 True):缺料自动确认「材料补全」弹窗,通用材料合成补齐;
- `farm_dungeon`(默认 False):右下全灰「材料不足」时的快速刷取开关——True
  自动「快速刷取」补材料后继续升级;**每次刷取消耗开拓力 30 + 快速刷取券 3
  (券不可自然恢复),调用方发起前必须向用户说明预计消耗并获明确同意**;
- `use_fast_ticket`(默认 True)/`farm_times_per_round`/`farm_rounds_max`:
  刷取预算控制;
- 终点三种:`MAX_LEVEL`(已满)/ 升满当前段 / `MATERIAL_CAPPED`(材料或刷取
  预算耗尽停在当前等级);手动刷取路线战斗失败自动继续(委托共享件回挑战
  画面,预算内重发、连败或预算耗尽止损收尾);
- 执行消耗真实材料与信用点。

## 4. 缺料补齐路径(①②③当场 → ④转计划排产)

向用户推荐时按此排序(负责人定案 2026-11-14:通用材料最优先;④ 定位修正
2026-11-15:当场补不齐的正式后续路径,不是兜底):

1. **①「使用通用材料补全」**——通用材料非稀缺,最优先路线;升级 op
   `fill_generic` 默认已开,零额外操作。
2. **②晋阶界面内「快速刷取」**——即时完成不跑战斗,每次开拓力+券(券为常态
   囤积资源);op 侧 = 授权 `farm_dungeon=true`。
3. **③跳转/常规刷本**——只耗开拓力不耗券,但要真打战斗(贪饕侵蚀机制下花萼
   单场可达 20 分钟,时间成本最高);晋阶材料的跳转路径复用
   `FarmLightConeMaterialOp`(见光锥档,导航真相源 = 游戏自己的跳转)。
4. **④转计划排产**——①②③都是当场手段,一次补不齐的缺口就转④:典型触发 =
   周本材料缺口超过每周 3 次产出、当天开拓力不够、缺口要跨天补。做法 =
   挂开拓力计划或调周本计划次数(见 §4.1),由之后每天的一条龙按优先级自动
   刷齐。②③路线推荐前报预计消耗(次数 × 单次开拓力/券量)。

### 4.1. 用 MCP 改计划排产(改前必问用户)

**负责人裁定 2026-11-15:改的是用户常驻计划,任何一次改动都必须先向用户
说明改什么、为什么改、预计消耗,获同意后才能执行。**

MCP 通用配置接口已接入,按材料反查到的关卡分类分流:

- **拟造花萼/凝滞虚影等日常体力关卡** →
  `add_config_item(app_id='trailblaze_power', list_field='plan_list', item_dict={...})`
  ——`mission_id` = 「生存索引 分类 关卡 区域」由 `find_missions_by_material`
  三元组拼出(例:永恒之花 → `生存索引 拟造花萼(赤) 丰饶之蕾 边缘通路`);
  `plan_times` = 缺口 ÷ 单次产量估算;`run_times: 0`;`team_num: 0`。
- **历战余响周本关卡(行迹高级材料)** →
  `update_config_item(app_id='echo_of_war', list_field='plan_list', item_id=周本 mission_id, item_dict={同 mission_id, plan_times=次数})`
  ——周本计划全量常驻,只改次数不增删;想重刷传 `run_times: 0`。
- 字段结构可先 `describe_config(app_id)` 查。写入写穿当前实例缓存,**下一次
  一条龙 run 立即生效,无需重启**。

注意事项:

1. 一条龙按 `plan_list` 顺序执行,`add` 的 `idx` 即执行顺位——默认尾部追加,
   缺口急用(赶突破/当期就要)传 `idx: 0` 插最前 = 后续刷取的最高优先级。
2. 完成后计划项残留但会被跳过(run_times=plan_times),GUI 可清理;开拓力删除用
   `delete_config_item`(`item_id` 传下标,连续删除从大到小删);周本改回次数再
   `update_config_item` 一次即可。

## 5. 材料需求与刷取点查询

- **一条链直查(MCP,优先)**:`character_lookup('角色名', with_ascension=true)`
  ——单次调用返回晋阶分段材料表 + 满晋阶总量 + 材料→刷取副本反查(分类级
  `dungeon_by_material` + 实例级 `missions_by_material`:具体虚影/花萼区域,
  与指南关卡同名对齐,可直接规划开拓力刷本)+ 副本外途径,
  「角色→突破材料→所属副本」一次拿全。
- **角色晋阶需要什么**:项目常量 `src/sr_od/config/character_ascension_const.py`
  的 `get_character_ascension('角色名')`——分段材料表(`stages[].name/materials`)
  与满晋阶总量(`total`);解析入口 `find_character_ascension` 额外兼容角色定义
  中文名(开拓者性别后缀归一化匹配)。
- **材料去哪刷**:常量 `src/sr_od/config/dungeon_drop_const.py` 的
  `find_dungeon_by_material('材料名')`(分类级)/ `find_missions_by_material('材料名')`
  (实例级,各养成线通用);副本之外的获取途径(合成/置换/商店/任务)在同文件
  `MATERIAL_EXTRA_SOURCES` 表,副本表查不到时查它。晋阶中高级材料(如永寿天华/
  永寿荣枝)副本线仅差分宇宙,花萼只掉低级档,中高级靠合成机升阶——常规刷取
  只耗开拓力,不耗快速刷取券。
- 数据固化与禁改纪律见 basics「养成游戏数据的固化口径」节(晋阶表由
  `skills/sr-od-dev-character-data/scripts/generate_ascension_const.py` 从官方
  wiki 生成,版本更新重跑刷新,禁手改;表外角色/材料以游戏内界面实读为准)。
