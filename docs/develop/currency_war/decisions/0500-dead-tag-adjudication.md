# ADR-0500 死 tag 判死清理(爆发速杀)

- **Status**: accepted(判死清理批;复活项归另一批)
- **Date**: 2026-09-11(清理落地)

## Context(背景)

W872 攻击发现「死映射」:部分环境词条的 `AFFIX_MECHANIC_MAP → MECHANIC_COUNTERS/SYNERGIES → mechanics_fit` 接线齐全,但 comp 侧 `mechanic_attributes` 零携带对应 tag,求交恒空(评分恒 0.5)——映射行是**空转死重**。W877 对全部死 tag 做「三问分诊」(完整裁决依据 = `docs/develop/currency_war/prereg/w876_deadtag_adjudication/REPORT.md`,自 `.debug/temp/` 迁入):

- **Q1 存在性**:该 tag 对应的玩法概念在终局十类 comp 体系(`docs/game/currency_war/research/final_comps/`)里真实存在吗?
- **Q2 可判性**:comp 侧打 tag 的判据能从现有注册表数据或玩法知识推导吗?
- **Q3 量级匹配**:词条效果量级与 mechanics_fit 的表达粒度(±0.25 counter / 0.20 synergy 步进)匹配吗?

分诊结论:复活 4(单属性队/成型羁绊队/慢速/依赖合成装备)、**判死 1(爆发速杀)+ 连带否决 2 条下游配方(应激反应/一鼓作气复用配方)**、观测 2(高费队/低费队)。本 ADR 只裁决与落地**判死项清理**;复活 4 归独立批次,不在本批文件面内。

## Decision(判死理由)

**爆发速杀**(挂靠词缀:紧急止血——敌进战受 20% 生命上限伤害)判死:

1. **Q1 无对应物**:十类 comp 分类的全部维度(CARRY 主体/核心羁绊/驱动型/节奏/星级饥渴)里没有「开局速杀」原型。D1 的「节奏」是经济搜牌节奏(几级 D 牌),不是战斗内击杀速度;最接近的「高倍率单核」已另有 tag 载体(榜样激励行在用)。
2. **Q2 不可判**:判据需要「comp 平均战斗时长/斩杀轮次」数据,comp 注册表与攻略知识都没有这个维度;静态数据(羁绊/装备/费用)推不出击杀速度。
3. **Q3 不支撑**:紧急止血 -20% 上限是中性偏均摊的环境效果,对「谁速杀谁受益」的区分度本身存疑。

**连带否决**(W877):此前评分补全批中「应激反应/一鼓作气复用爆发速杀 tag」的配方一并否决——复用零载体 tag = 补映射行后仍恒 0.5 空转。二者评分面现状不变(DoT 受益半边已由 `cw_system_cards.affix_likes` 通道覆盖),若未来战斗时长维度在 sim 侧立起来再议。

## 落地清理(本批改动)

- `cw_comps.MECHANIC_SYNERGIES` 删 `"爆发机会": ["爆发速杀"]` 行,留 ADR-0500 指针注释。
- `cw_comps.AFFIX_MECHANIC_MAP` 的 `"紧急止血": "爆发机会"` 行注释置死(保留透传):tag 零 comp 携带故映射后求交恒空=零行为,保留使未知词缀语义不丢,重立时只需回补 synergy 行。
- W875 补全包头注同步:「应激反应/一鼓作气复用配方」标注连带否决(ADR-0500)。

**验证面核对**:grep 全仓,爆发速杀/爆发机会/紧急止血无其他生产消费点(competitors.md 是外部攻略数据文档,记游戏方向真值,不属清理面);受影响测试核对——`sr-od-test` 无锁「爆发机会/紧急止血在表」的用例,`test_cw_w875_env_b_scoring` 的 degraded 断言(应激反应/一鼓作气不得入映射)与本批方向一致,零锁改动。

## Considered Options(观测对处置:高费队/低费队)

| 选项 | 裁决 |
|---|---|
| 连带删除「高费/低费审美」map 行 | **不采纳**。词条方向真实(4 费+/3 费- ±5%,V4.4),删行丢失方向信息;量级不配粒度≠概念被否决。 |
| 保留行 + comp 侧立项建模 | **不采纳**。「多高算高费队」阈值无权威出处(违反决策规则数学先行);±5% 差异配 0.2 步进 = 离散 tag 系统性放大 4 倍,会把近中性扰动变成硬 flip(过反应)。 |
| **保留 map 行,挂重审条件注释(采纳)** | 词缀→tag 透传无害;comp 侧不建模。重审条件:①出现费用差异化幅度 ≥15% 的词条;②comp_score 引入连续费用分布通道使粒度错配消失——届时阈值推导按「决策规则数学先行」补出处。 |

## Consequences

- 紧急止血词缀出现时 mechanics_fit 恒中性 0.5(与清理前实际行为逐位一致——原本就是死映射空转,本批是删除死重而非行为变更)。
- 复活 4(单属性队/成型羁绊队/慢速/依赖合成装备)归独立复活批,与本批 commit 物理分离;其验证设计(L1 单帧锁 + sim A/B 条件可测)见裁决报告 §4。
- 判死 tag 复活的唯一合法路径:战斗时长维度(若做)先在 sim 侧建立数据源,再按三问重审——禁直接补映射行空转立项。
