# 练度评估标准（星魂视角）

> 用途：配队/养成决策的练度判据——「够不够格进队」「这支队伍练度成色如何」类问题的统一口径。评估对象以**主力输出**为先——辅助/生存位的星魂收益通常是次要项。适用于米哈游系五星级角色，任何玩法场景通用（逐光捡金/货币战争/日常养成）。

## 分层标准（账号主人裁定）

- **0 魂 = 平民配置**。分两类，评估前先定性：
  - **0 魂机制完整型**：星魂只提升数值，0 魂即可当主C 用；
  - **0 魂机制残缺型**：关键机制锁在星魂里，0 魂强度打折——硬凑不如换体系。
- **2 魂 = 小康玩家水平（公认线）**：部分角色恰在 2 魂达成机制完整、数值同步走强，这类角色的 2 魂是性价比档。
- **高魂（4/6）= 重投**：配队按「有则按实测强度用，无不强求」。

## 金数记法对接（攻略通用）

攻略标注「21」= 2魂+1叠影、「2+1」= 2魂+1专。对比参考阵容金数时，**先比主C 魂数，再比光锥**。

## 数据源（mys MCP 直拉，无需中间层）

- `mys_get_characters` = **概况**（等级/星魂数/命途/光锥摘要）——配队选人、练度成色初判；
- `mys_get_roster_detail` = **全量**（遗器词条/星魂解锁状态/行迹等级/属性面板）——缺口分析、毕业面板对照。
- 会话失效时按工具返回的 `session_expired` 重登即可；状态分支在工具描述里自足，会话备份/恢复与验证环节的坑见 `docs/develop/sr_od/backend/mys.md`（账号数据能力随 MCP 工具走，不设独立 skill）。
