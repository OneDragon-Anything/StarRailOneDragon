# DD-005:买牌期望态落点判据对齐「真实空槽优先」——快照过期不再误停线

> 状态:已落地(2026-09-02;受影响测试全绿)。

## 背景

安灯 L0 停线(p2r2,run_20260902_014515;判读 =
`.debug/temp/currency_war/replay/andon_p2r2_diagnosis_20260902.md`):买牌期望态的
购买前 bench 快照缺「那刻夏@槽9」→ 落点模型(`compute_buy_expect` 经
`bench_place` 取首空槽)把槽9 当空槽、期望卡芙卡@9;游戏实际把卡芙卡放进槽1-8 的
真实空槽 → 定型帧对账「槽9 期望卡芙卡 / 实读那刻夏」→ `buy_expect_mismatch`
复现升 L0 停线。根因在观测模型层:快照来源 = `session.tracked_bench_chars`
(执行侧计数器族,非观察真值),其空槽表可能相对真实板面过期。

## 裁决(两案取舍)

- **案A(快照换源:买入点现读 bench)**——否决为主修:换用 SIFT 现读同样无法
  保证真值(「SIFT 未识别 ≠ 空槽」是该层已知缺口,漏读被占槽会以同形态复发
  误停线);且 shop overlay 期间的读数还叠加遮挡/动画滞后维度。换源只是把
  「不可保证的前提」从一个不可靠源换到另一个不可靠源,属数据质量补丁。
- **案B(判据语义对齐游戏契约)**——采纳:游戏买牌落点契约 =「放进板面真实
  空槽」,模型对落点的槽位断言只在空槽表为真时成立。`compare_buy_expect`
  增加两条「快照前提失效」降级(不评,不算一致也不算不一致):
  1. 期望实体(买入牌/合成产物,含星级)在实读**其他**槽位出现 → 游戏放进
     了真实空槽,模型空槽表过期;
  2. 实读身份属于本期望态的**终态新实体**(增量槽位期望实体集;不含被合并
     消耗的原始购买名)→ 同因。
  不可降级形态照旧落不一致:期望实体全场缺席(买牌丢失)、期望空槽被非终态
  新实体占用(合成未发生,实读=同名 1★ 不降级)、星级不符(2★直出)。

## Considered Options(最值钱栏)

| 方案 | 结论 | 理由 |
|---|---|---|
| A 快照换现读 | 否 | SIFT 漏读/遮挡使空槽表仍不可保证;同一误停线可复发 |
| B 判据降级(采纳) | 是 | 槽位级断言超出了游戏契约的保证范围——游戏不存在「落错槽」的违约形态,槽位级假阳性只能来自模型侧前提失效;降级后保留的判据(实体在场/腾槽/星级)才是游戏可能真违约的面 |
| C 保留语义+只删台账升级 | 否 | 掩盖缺陷不修根,存量漂移误报持续污染台账 |
| D 降级后feed reconcile_tracking | 否(未加) | 对账用的同一帧本就被 tracking 通道消费,漂移天然由既有通道承接,零新增接线 |
