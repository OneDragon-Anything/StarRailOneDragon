# ADR-0636: T-32 空板止损守卫——「待卖后 deployed 为空 ⇒ 拒卖」后态单条件判定

## 状态

已实施(工作树;入库走 committer 不自带 commit;落地审由编排者另派)

## 背景

T-32 供给可达性仲裁层旧设计(241,supply_arbitration_design/DESIGN.md)经总图对账重审(reviews/出口族对账重审.md,T-32 节 9 行)定谳:六形态缺口大半被总图演进收编(ADR-0616 四层谓词/档 0-3/C1 直通/④臂/P76 甲/濒死闩),**唯一现在可落的行为件 = 空板止损**(旧设计 §6.4 v2 应修-3 单条件后态判定版,已过对抗 R1-R3+复核)。

病灶实证(旧设计 §2.2 形态④):sim65 局 s7022 r1-r3 `phase=unlocked`、`board={}`,策略逐个卖空初始 4 张 bench 牌(income 1×4),空板挨打 3 轮 hp 84→52,金堆积至 47,空转占比 0.33(批最差)。卖出的收益侧(凑息/筹资)由既有通道各自的资格面管辖,但**没有任何一层判定「卖出发生时的板面状态」**——板空帧卖储备换金 = 挨打失血换零净金。

附带约束(账本在案):ADR-0616 1b 闭集「连续 N 轮」计数阈值禁用(零调参)——守卫判据不得引入计数阈值新参数。

## 决策

**守卫谓词(零自由参数)**:待卖后 deployed 占用数为 0 ⇒ 拒卖该笔,拒因分键 `empty_board_sell_guard`(`sell_gate.EMPTY_BOARD_SELL_GUARD_KEY` 单一源)。

1. **后态单条件判定**(旧设计 §6.4 v2 应修-3,取代 v1「板空 ∧ 卖后仍空」前置形态):谓词输入 = 该笔卖出执行后的上场占用数。前置形态对「从有板逐个卖穿到空」路径每次卖出瞬间恒假,最后一卖照常放行,守卫目标(不进空板态)失守;后态判定自然覆盖「板已空连卖 bench」(s7022 型)与「卖掉仅存部署位」(卖穿型)两类路径。现行策略面唯一卖类 = SellBench(不改变 deployed)⇒ 后态占用数 = 现占用数;取后态形态是为辖未来卖 deployed 类通道的接线对账,谓词本体零改。

2. **数学地基(支配性结构判据,数学先行)**:空板帧任意 bench 卖出相对不卖弱劣——1★ 全额退净金 0(P76 甲)+ 部署/合成期权损失 ≥0(P41① V_opt≥0);2★+ 卖出净损金(P76 甲:refund−全成本∈{0,−1},手续费)+ 期权损失。存在支配性论证 ⇒ 零参数(Strategy-work §1 骨架:论证消掉参数)。守卫非消费授权、零 hp、零发射位(旧设计红线 1/2/5 全过)。

3. **接线面 = 五个卖出候选单一源,覆盖全部 15 个卖出发射位**:crit_sell.sell_for_interest / crit_sell.funding_support_sell / crit_sell.line_switch_sell(返回归因键 `empty_board_sell_guard`,与血线禁令 `blood_floor` 帧级整通道禁令同构形态)/ mandate.fuel_sell_candidates(返空)/ sell_gate.funding_hold_fallback(返空,新增 `deployed` 形参)。新发射位消费同源判据即自动被辖,零逐位接线遗漏面。deployed 缺读(None)= fail-closed 拒(资格判据禁缺读放行,与 hold 登记星/费缺读同纪律)。

4. **复合事务(M4 腾席/funding 筹资)卖出腿在空板帧同被辖** = 资格面收窄,消费位走各自既有「无候选」诚实停摆路径(m2_retry_exhausted / bench_full / {prefix}_no_fuel / 空发射)——先例 = W4/P78-4 燃料资格收窄 → 诚实停摆在册可接受形态。恢复正路 = 部署(P24 零支出严格支配,守卫零辖)与买面(守卫零辖)。若观测证明腾席抑制代价超界,回本 ADR 对表加显式豁免(闭集增项),禁消费位手搓绕行。

5. **不立开关**(strategy-work §3:数学可证 → 直接落码,无开关;回滚靠 git revert)。

## Considered Options

- **前置形态守卫(v1)**:否决——对逐个卖穿路径恒假(旧设计对抗 R1 应修-3 实证),守卫目标失守。
- **仅辖凑息通道(最小面)**:否决——守卫合法性是逐候选的支配性论证,与通道无关;funding 兜底(2★ 净损+期权损失)弱劣更甚,辖域收窄=保留已知弱劣动作。
- **M4/funding 腾席筹资腿豁免(保留复合事务)**:否决——空板帧腾席卖燃料件买 bench 件的复合收益在 bench 域(不直接上板),板空帧保留 bench 储备的部署期权优先;豁免须观测证据支撑后闭集增项回 ADR 对表,禁本批预设(与 ADR-0616 命题 3 断供晚触发「唯一出口诚实申报」同处置纪律)。
- **发射位逐点接线(15 处)**:否决——重复接线 15 处、漏一处即守卫破洞,与装配 A「单一入口」哲学相悖;候选单一源接线 5 处覆盖完备。
- **计数阈值形态(连续 N 轮空板才禁卖)**:否决——ADR-0616 1b 闭集「连续 N 轮」计数阈值禁用(零调参),且支配性论证不需要时间维。
