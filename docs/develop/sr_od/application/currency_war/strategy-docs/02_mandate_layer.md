## 1. 为什么需要骨架层：多代重构失败根因

（出处：DESIGN_MANDATE_LAYER §1，三轮 A/B 归因——s0/r2/r3 批，`archive/redesign/reports/AB_*_ATTRIBUTION.md`——已删除的旧文档树，git 历史可溯）

- 三轮 A/B（新 cw3 vs 旧 decision_v2，同 seed 同池）的失败形态逐一归类：**「没做」占绝对主导**——部署 0/934、卖出 0→43/287、升级金 1940/5792、席满拒买 1163 笔/13 笔、零动作轮 35%/4.5%、花费率 0.384/0.68。没有一项是「执行了但方向错到显著损失」。
- 失活机理三种：①机器整块缺失（部署机不存在）；②**权限错位**（义务被降级为某个 EV 证明的从属品——升级被 P39 分支二「何时升」证明整局否决，是义务与优化器权限混淆的直接证据）；③输入缺失 fail-closed（=读不到数据/条件不满足时默认走保守分支不动作）装错动作。
- 金约束门不是凶手：三轮探针数据金约束门合计 ≈0 次拒——门正确但不起作用；真正杀人的是义务缺位后资产形态劣化，让约束门在劣化态下「正确地」继续关门，形成静默螺旋。修复主向不是拆门，是**把义务立起来**。
- fail-closed 有对有错（旧迭代散刷事故证明该关的不关会烧钱，git 历史可溯）：按动作可逆性分（§5）。

## 2. 三层权限模型

```
┌─ 证明层（终局阵容选择与承诺）──────────────────────┐
│ 选线函数（候选-锁定制,12 §1）/ 成型停买线（[13] 成型后停买过渡件） │
│ 职权:决定骨架为哪个终局阵容服务;给 [41]（经验整买纪律）供给整批预留金 S │
│ 无权:否决任何单笔骨架动作                              │
├─ 骨架层（义务,mandate)────────────────────────────┤
│ 每备战期无条件生成动作,只受硬约束（§4）拦截            │
│ 输入缺失 → 按可逆性定向默认（§5）,禁静默跳过          │
├─ EV 层（优化器）──────────────────────────────────┤
│ 刷新/压牌库/连胜金/装备/事件决策;只增不减:              │
│ 可在骨架之上追加动作,无权否决或改写骨架动作           │
└──────────────────────────────────────────────────┘
```

权限判据一句话：**「不做会输」的是骨架（义务），「做了更赚」的是 EV（优化），「做给谁看」的是证明（终局阵容选择）**。

## 4. 硬约束的封闭定义（唯一合法拦截集）

骨架动作只被以下条件拦截，此外任何门（EV、标定、利息规则、血预算）**无权拦截**：

1. **可负担**：金 ≥ 动作成本；
2. **席位存在**：board/bench 槽位、等级 cap、同名同星≤1；
3. **S 预留保护**（[41]）：待执行整买的终局阵容 S 的预留金不被非 S 组成的骨架动作吃掉——但 M3 升级本身与计入 S 的 M2 买不受此限；
4. **不可逆护栏**（§6）：卖出终局阵容内件、无目标刷新不属于骨架动作集。

**HP 不在硬约束里**（[39]；00 §3 硬闸门）。曾有「危局接管门（hp≤40 越权）」提案，本设计**不采纳该形态**：hp 拦截/接管骨架超出硬闸门适用范围。危机响应的拦截层形态（升档器血线硬地板解锁包 + λ 顾问延迟 + 调度利息保全门 + 全段式支出预算闸）已全部删除——升级支出改由最优概率带单判据与升级资金线门（现金口径花后守 saturation_line,凑金域凑至守线发射,[11_shop_decisions.md](11_shop_decisions.md) §2 资金线门行）承载；hp 维持「仅作风险路由键与观测输入,**不作骨架动作的拦截输入**」的边界（p1/p2 血带谓词保留为纯观测消费）。骨架常开使席堵/等级落后两类危机成因被 M1-M4 直接消解;死亡风险承接面的架构裁决记录 = [00_framework.md](00_framework.md) §4。

## 5. 输入缺失时的落点：按动作可逆性定向 fail

（三轮「静默蒸发」的直接修复面；DESIGN_MANDATE_LAYER §3.4 现行口径，git 历史可溯）

| 缺失输入 | 骨架行为 | 禁止行为 |
|---|---|---|
| 池参数/期望刷新数未标定 | M2 照买（买本身无损，[11]） | 拒买 |
| 板面收敛度/结构可达计数异常 | 退化为「与任一 TRANSITION_SYSTEMS 成员重叠即终局阵容内」（executor 内置缺省表明文收录） | 判序 6 停买 |
| M3 触发输入（存在性分支结构谓词读数）缺失 | 退「等级落后于上阵人数需求」朴素判据 | 整局 defer（XP 支出不可逆，缺输入默认不触发 ≠ 默认触发，退可观测朴素判据） |
| 终局阵容内/外分类不确定 | 该件**不卖**（可逆方向取保守）+ 记待判 | 卖出 |
| sell_refund 注册表读数缺失（运行时损坏态） | 分面：买侧风险界消费位缺 ⇒ 拒买；卖面消费位缺 ⇒ 拒绝评估、不新增卖出 + 报警（槽位 None + 强制停，与 λ 表损坏态同款守卫；「1★ 全额退」假设的合法适用范围收窄为买面/EV 下界场景） | 按「1★ 全额退」假设放行卖出评估 |

**原则：可逆动作（买/部署）缺输入 → 默认做；不可逆动作（卖/刷）缺输入 → 默认不做。** fail-closed 从「全局默认」改为「按动作可逆性定向配置」。数学侧镜像（01 §6）：未标定参数在 EV 层一律 fail-closed（不产生追加动作），**绝不向骨架层渗漏为一个否决**。
