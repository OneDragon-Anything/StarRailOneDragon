# 景元（雷·智识·5星）

> 按 V4.7 期撰写。神君叠段追击：技能叠段、神君自动弹射。

## 一、命途属性与技能说明

**命途**：智识；**属性**：雷

| 技能 | 说明 |
|---|---|
| 普攻 | 单体雷伤 |
| 战技 | AoE 50% + 神君+2段 |
| 终结技 | **消耗能量130**；AoE 120% + 神君+3段 |
| 天赋【神君】 | 进战召唤（60速起，3段起）；行动时按段数弹射追击（33%/段+溅射25%）；**战技/终结技叠段（上限10），每段速度+10**——段数即速度即伤害；景元受控时神君也无法行动 |
| 秘技 | 进战神君+段（以文本为准） |
| 额外能力 | E1行迹：神君≥6段暴伤+25% |

**资源与循环**：130能量→充能有效。

## 二、推荐遗器与原因

**套装**：激奏雷电的乐队4件 + 毁烬焚骨的大公2件【攻】
**主词条**：躯干暴击率/暴伤；脚部速度；球雷伤；绳**充能**。**副词条**：双暴>攻击>速度>充能。
