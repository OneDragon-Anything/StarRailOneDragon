# 未达上限弹窗

**识别**：「可出战角色人数未达上限，是否确认出战？」+ 取消/确认。
**目标**：确认出战。
**能做的事**：
1. 点「确认」（实测 (1187,670)——2026-11-19 实机；建档「按钮-确认」，早期估算坐标 ≈1170,672 可作兜底，静态点击有效）。动作 op 不处理弹窗——弹窗确认是你的责任。
2. 「本局不再提示」勾选框（建档「勾选-本局不再提示」，约 912,589）：框架流程 op 处理本弹窗时会自动勾选再确认；玩家 skill 默认不代点（玩家偏好），勾不勾自行决定。
**坑**：「本局不再提示」勾选框不代点（玩家偏好）；区分另一相似弹窗「前台区域无角色，无法出战」= 还没部署任何角色，先买牌部署再出战。另：extras.bench_overflow=True（「备战席已满」红警横幅）时出战会被游戏直接忽略（无弹窗），必须先卖角色腾位。
**识别消解（2026-11-21）**：本弹窗帧由本屏唯一精准命中——原通用屏「战斗-退出确认弹窗」（「提示+确认」位置双锚）已退役拆分为正文锚窄口径屏「逐光捡金-战斗退出确认弹窗」，对本弹窗帧不再 is_precise 抢命中（历史撞车机理与增锚证伪过程见主仓 `docs/game/screens/treasures_light_battle_exit_confirm.md` 备注）。**「读到通用屏名先看正文」的人肉消歧口径作废**：建档命中即可信，`analyze_screen` 报本屏名即按本卡操作。
