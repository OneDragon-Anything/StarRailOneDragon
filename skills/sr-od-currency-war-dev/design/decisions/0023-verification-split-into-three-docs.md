# 0023 - 验证细则按验证手段拆三文档(verification.md 拆解)

- **Status**: accepted(2026-08-27;用户定调「策略部分说策略的怎么验证,模拟测试说模拟测试的,遥测的说遥测的,三个文档互相引用」)
- **Context**:verification.md 是逐 ADR 追加式生长(0009 加深度挖掘、0012 加分诊回灌、0014 加压测官、后续又加灵活使用/验收纪律),症状:①武器库在「深度挖掘方向」与「灵活使用」两节重复枚举(且存在双 3 编号断口);②同一验证手段的内容散在 5 节;③文件一半按工具分一半按流程角色分,两套轴交叠。用户裁决:不重组为单文件多章,而是**按验证手段拆成三个独立文档,各自讲透,互相只留作用引用**。
- **Considered Options**:
  1. 原地重排为单文件两大块七节——保单文件入口,但读者(改策略/跑批/判读)仍要在一篇里翻找自己的章。
  2. **按手段拆三文档**(选):strategy-work §4 扩成完整策略验证章(吸收原「实机验证」节);新建 sim-testing.md(sim 全部内容);telemetry-reading.md 已存在,吸收缺条目。verification.md 删除。
- **Decision**:
  1. **单帧锁归策略文档**(用户裁决「来源可能是实机或者模拟随机发现的」——按被验证对象归档:锁的是策略决策行为,不问局面来源;它是策略验证链的固化出口)。
  2. 三文档互相引用模型:策略→sim(分布数据怎么跑)/遥测(局后怎么读);sim→遥测(语料与校准从实机来)/策略(发现物固化);遥测→sim(判读结论回灌)/策略(行为锁定)。
  3. 旧 verification.md 的指针迁移:SKILL.md 三处、overview 一处;0009/0012/0016 等 ADR 中的「落 verification.md」表述是历史记录,不改写(ADR 论据豁免)。
- **Consequences**:
  - 正:每个读者只读自己那章;武器枚举单一源(修掉双 3);「模拟是发现工具,单帧锁是回归工具」的对偶落在策略文档显眼处。
  - 负:三文档互引多一层跳转;SKILL.md「验证工作台」从「细则在一个文件」变为按层分指。
  - 后续 verification.md 的内容不再回建;sim 相关新增落 sim-testing.md,策略验证新增落 strategy-work §4,判读新增落 telemetry-reading。
