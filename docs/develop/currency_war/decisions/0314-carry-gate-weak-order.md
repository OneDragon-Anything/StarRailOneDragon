# ADR-0314: carry_gate 卖弱序定稿(absent_mergeable 判据适配 + 种子死锁豁免 + 保护集口径修正)

- 状态:accepted
- 日期:2026-08-25
- 背靠:R1 语义保真审查 leader 裁决之项 5(carry_gate docstring 与实现
  不符 + r416b absent_mergeable 移植缺位);W51 语义修复批执行,指挥官
  亲验通过。落点:`decision_v2/discipline.py` `carry_gate_actions`。

术语:carry 腾位门 = bench 满且意向核心(carry)在店、金足时,降保护集
卖最弱件再买核心的纪律通道(v1 ADR-0280 r416 移植);保护集 = 腾位时
不卖的正料名单;弱序 = 候选件「谁最该被卖」的排序键;种子 = engine_seed
通道买入的体系方向件(ADR-0289 §5 给 ≤2 轮年龄保护)。

## 背景与动机

R1 条 4 存疑 + 移植缺位,三件事:

1. **docstring 与实现不符**:门 docstring 声称「保护集从桥池名单换
   hoard 目标集(`session.v3_hoard`)」,实现实际是 `_line_protect_set`
   = core_chars ∪ shared_chars ∪ 替班者 ∪ 引擎件(`engine_char_names`)。
   `v3_hoard` 全集含跨线骨架/装备材料,口径更宽——声明照抄了载体批
   交接文档的预期,没对实现。
2. **r416b absent_mergeable 弱序缺位**:v1 有「缺席场冗余副本弱序升最弱
   级」的卖序规则,v2 移植时漏了——纯 bench 合成素材(该角色上场份
   缺席、架内加权副本 ≥2,卖 1 份仍留副本)不享受最弱级,会被排在
   散件之后晚卖。
3. **种子死锁豁免缺位**:v1 `_seed_cands` 把年龄窗内种子单列、`cands`
   空时兜底接管(唯一可卖=种子仍腾位防 carry 死锁);v2 漏了——
   ADR-0289 §5 年龄保护在降保护集阶段全拦时,bench 真满+唯一可卖=
   种子 → carry 永远买不进(死锁)。

## 决策

1. **保护集口径修正为实际语义**(docstring 改对,不改实现):意向线
   正料派生 = core_chars ∪ shared_chars ∪ 替班者 ∪ 引擎件——非
   `session.v3_hoard` 全集;跨线囤件不在保护集,可被降级卖出腾位买核心。
2. **absent_mergeable 弱序(W51 判据适配)**:该角色**上场份缺席**
   (deployed 无同名)且架内星级加权副本 ≥2 → 「合成份缺席场」冗余,
   弱序与超上限冗余(cp>3)同档置最弱级。**适配推理链**(worker 推导、
   指挥官批准的裁决,必须留档):v1 r416b 原条件是「carry 在场」,与本
   门②的前置「carry 未持有」**互斥** = 死码——直接照抄则该弱序级在 v2
   永不触发(假移植);r416b 的意图是「缺席场的冗余副本」(合成素材份
   缺席其上场份,卖 1 份仍留副本),故改判「该角色上场份缺席」。裁决
   只令移植弱序,未令移植死码——意图保留、字面弃置。
3. **种子死锁豁免(v1 `_seed_cands` 移植)**:④候选循环双列表——种子
   (ADR-0289 §5 年龄窗)单列 `seed_cands`,`cands` 空时兜底接管(唯一
   可卖=种子仍腾位防 carry 死锁,仍选最弱);有非种子可卖件时③直接
   通道判定不变。年龄保护在降保护集阶段让位于 carry(不腾则死锁)。

## Considered Options

- **absent_mergeable 照抄 v1 字面(条件「carry 在场」)**——被否:与本门
  ②「carry 未持有」前置互斥 = 死码,永不触发;「移植了」但语义为零,
  比不移植更危险(读者以为有该弱序级)。这正是「单源直通不复制判据」
  的反例教训:跨载体移植必须验证前提条件在新载体可达。
- **保留死码+注释说明**——被否:死码双源心智(读者要维护一条永不走
  的分支);意图(缺席场冗余)可以直达,不需要绕道死条件。
- **不移植该弱序级**——被否:缺席场冗余副本确实是最该先卖的件
  (合成素材性质,卖 1 份仍留副本),v1 有此弱序是行为资产非包袱;
  R1 裁决也点名移植。
- **种子豁免:carry 硬禁卖种子(年龄保护无让位)**——被否(同 v1
  ADR-0294 件1 判据):bench 真满+唯一可卖=种子时,保护成立=carry
  死锁——年龄保护保护的是「种子归零=白烧预算」,死锁代价更大;
  豁免让位+仍选最弱,两头兼顾。
- **种子豁免进 ③直接通道(种子与散件同序竞争)**——被否:③的语义是
  「有不需降保护的可卖件」;种子进③等于年龄保护整体失效,豁免只该在
  「无任何其他选项」的兜底位触发。
- **保护集:把 docstring 改成 v3_hoard 全集口径并改实现**——被否:
  hoard 全集含跨线骨架/装备材料,按它保护会把「可降级腾位的件」也
  锁死,重新制造批⑯ F3 的保护集窒息问题(ADR-0280 根因);正料派生
  口径是实现里被 A/B 验证过的行为,声明应服从实现。
- **docstring 不修(留不符)**——被否:声明与实现不符是 ADR-0210
  as-built 纪律违例,未来读者(含 review)会按声明推断行为。
