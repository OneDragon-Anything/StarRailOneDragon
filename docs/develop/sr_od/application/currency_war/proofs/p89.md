## 命题(形式化)

**带源**:真人尺保留率带 **[0.59, 0.74]**(stage_transitions Q2 Early→Middle,∣E∣≈4.7 板数据,`stage_transitions.md:195`;保留率为「卖没卖过渡」的正确读数,`:92-93`),对应卖出率带 [0.26, 0.41](互补恒等)。sim 侧分母 = 板 9 件(BENCH_CAPACITY = 9,`cw_state.py:32`);过渡件分母 = 线外 8 件。

1. **正典式(卖出率)**:n_swap/9 ∈ [0.26, 0.41] ⟹ n_swap ∈ [2.34, 3.69] ⟹ **n_swap = {3}**(整数唯一解)。
2. **等价形(保留率)**:(9 − n_swap)/9 ∈ [0.59, 0.74] ⟹ **n_swap = {3}**(两带互补恒等:1 − [0.26, 0.41] = [0.59, 0.74],同解集)。
3. **交叉核(过渡件分母,探针双读法)**:n_swap/8 ∈ [0.26, 0.41] ⟹ n_swap ∈ [2.08, 3.28] ⟹ **n_swap = {3}**——板分母与过渡件分母两读法收敛于 3 件。
4. **折算**:3 件 / R1-R4 共 4 轮 = **0.75 次/轮**(A/B 预注册线:R1-R4 SellDeployed ≥ 0.75 次/轮 + 末轮保留率带内占比)。
5. **逐例分数(写准)**:换 3 件 = 卖 3/9 ≈ 0.33(带内)、留 6/9 ≈ 0.67(带内);换 2 件 = 留 7/9 ≈ 0.78(超 0.74 上限);换 4 件 = 留 5/9 ≈ 0.56(破 0.59 下缘)。
6. **反例自检(批 A 验收锚④)**:n = 3 两正形式皆过;n = 6 两正形式皆拒(卖 6/9 ≈ 0.67 ∉ 卖出率带、留 3/9 ≈ 0.33 ∉ 保留率带);v1 已废错误式的整数解恰为 {6},与结论 {3} 自斥(见勘误注)。

## 证明(带内离散算术直算;零自由参数)

### ① 正典式

0.26 ≤ n/9 ≤ 0.41 ⟺ 0.26×9 ≤ n ≤ 0.41×9 ⟺ 2.34 ≤ n ≤ 3.69;n 为整数 ⟹ n = 3,且仅 n = 3(2 与 4 均出带)。∎

### ② 等价形(保留率)

0.59 ≤ (9−n)/9 ≤ 0.74 ⟺ 5.31 ≤ 9−n ≤ 6.66 ⟺ 2.34 ≤ n ≤ 3.69 ⟹ n = {3}——与 ① 同区间,因两带互补恒等 1 − [0.26, 0.41] = [0.59, 0.74](区间减法逐端点)。∎

### ③ 交叉核(过渡件分母)

0.26 ≤ n/8 ≤ 0.41 ⟺ 2.08 ≤ n ≤ 3.28 ⟹ n = {3}。3/8 = 0.375 ∈ [0.26, 0.41](与探针实测 37.5% 一致)。板分母(9)与过渡件分母(8)两读法收敛于 3 件。∎

### ④ 折算与逐例

3 件 / 4 轮 = 0.75 次/轮;逐例分数 3/9、6/9、7/9、5/9 的带内性见命题 5(脚本逐位复算)。∎

## 勘误注(随命题入库,防同型错误回归)

v1 曾写「∣9−n∣/9 ∈ [0.26, 0.41]」——保留率公式配卖出率带,照式解得 n ∈ [5.31, 6.66] ⟹ **{6}**,与结论 {3} 自斥(对抗审阻断 1);括号内「3/9=0.67」系把保留率 6/9 误写成卖出率分数。探针报告 `findprob_probe_20260910_012328/report.md:80` 同有该分数笔误(其推导链「卖 2.34-3.69 件 ⟹ n=3」与两读法收敛结论**不受影响**)——引用探针数值只引区间与结论,**禁转述该分数行**(探针报告归探针批所有,勘误路由见设计 v2 文首申报)。本单篇主式已改写为正典/等价双形,验收锚④把该错误钉成回归自检(脚本断言 6/7)。
