# ADR-0524: 评估表体系定序改形落地(16 号稿相位 2b)

- 状态:已实施(代码+测试;A_min 重测 §3 不在本批,另批辖)
- 日期:2026-09-06
- 关联:ADR-0519(经验量退役,本批辖其「维持项·评估表体系」的定形)、ADR-0143/0144/0144b(评估表与守卫)、ADR-0152(定义型 augment)、16 号稿 `docs/develop/currency_war/strategy-docs/16_evaluation_tables_reassessment.md`(规格层定稿,本批即其 §4「各改形项落码」执行批;§1.8 边界件不动)

## 背景与动机

16 号稿按 ADR-0519 尺度对评估表体系逐表过堂:必选面不可退役、结构方向有出处者保留为知识判据、无推导幅度只可承载同族定序语义。本批把规格落码:六表改形,其中五表为纯声明降格(行为不变),一表(品质回落)为申报过的行为翻转。

## 决策(逐表)

| 表 | 处置 | 行为 |

### 品质回落翻转面(如实披露)

- **域内翻转**:金无经济(旧 30)vs 银有经济(旧 30)旧制平手取前者 → 新制品质序定序(金 > 银有经济);16 号稿申报例「金有经济 vs 棱彩无经济」在现行注册表无实例(回落集 20 条:棱彩无经济×9、棱彩有经济×1、金无经济×9、银有经济×1),等价的银+经济反例已入翻转锁。
- **跨域降位(16 号稿申报例的推广)**:回落域(0-5)不再与评估分域(12-75)可比——旧制棱彩+经济回落 70 曾压过评估分 12-65 段,新制一律评估分优先。方向 = 向「知识判据优先于无依据先验」收敛,保守化。
- steering +30 叠在回落分上的绝对位次随之变化(软加分的域内排序作用不变)。

### 决策边界说明

comp-hit「N≥1 域压过基准域」按 16 号稿 §1.4 augment 锚位(「comp-hit 上限 110」)实现为:域下界 65 压过纯基准分域(品质回落/未注册),保留现行 max() 覆盖结构——单命中仍可被顶级评估分(75)压制,这与 §1.1 ②「仅保留现行覆盖结构、禁新增跨族语义」一致;若按「N=1 压过含评估分全基准域」解读则须抬常数且破坏 110 锚位,取前者并在域声明中写明。

## 后果

- 必选面决策结构不变(始终选最高分项);零新增自由参数;λ_death/hp 域未触碰。
- 评估表升级通道:台账价值(ΔP̂ 完成概率增量参数化)挂账归事件面命题批(08 E1/E2),ENV_PICK_VALUE 的 EnvEconomyEffect 扩字段缺口随挂账登记。
