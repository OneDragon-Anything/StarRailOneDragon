# ADR-0593: 自证循环迁移——检查器豁免边自算复核 + 可疑项检测器集 + 生成侧三披露键

- 状态: Accepted(实施批,用户已批准方案 2026-09-08;commit 候编排者统一门)
- 关联: ADR-0267 系(同轮买卖检查器豁免边族,本批为该族豁免边的信任面重构)、ADR-0589(dec_board_full 执行点披露先例,三披露键同构)、ADR-0591 §4(line_switch_collapse 写端证明义务,本批补检查端复核)、ADR-0564 §G4(roster-diff 差分自算正面先例)、ADR-0584 §2.4-1(复盘 op 边界,骨架 op 占位的对齐口径);方案正本 = T-153 自证循环排查报告(2026-09-08 干净上下文审计,其持久语义全部吸收于本 ADR,后续注释一律引 ADR-0593 不引报告路径)。

## 背景

T-153 排查定谳:检查器/审计消费「被检方(策略器)自己写入的字段」作放行、豁免或判真依据 = Actor 自证、Auditor 采信。全量清点 = **7 组循环(C1-C7)、涉及检查器函数 14 个**,全部集中在经济纪律豁免域;信任字段四类——`BuyCard.reason`、`SellBench.sell_reason`、`LevelUp.auth_basis`、`formed_stop`,写入层全部是策略发射位(A 类),引擎只做转录。典型形态:词表白名单采信自述(C1 冷启动 reason 白名单可被任意合法词绕过)、豁免吃自报臂名不复核前置(C2 升级授权)、三连豁免吃自报分键(C4 同轮买卖 copy/engine_seed/转化类)、自报停手短路发生在自算成型之前(C5 溢金,「成型谎报」恰好不可见)、辖域由自报圈定(C7 种子,改标即脱离检查网)。

用户裁定架构(2026-09-08):检测的归宿 = **复盘模板生成器**——机械事实留检查器、结构合法留生成侧、需语境裁决的豁免边改为「检测器自算复核 + 可疑项条目嵌对应节点小节判定三槽之前、复盘者带全局上下文逐项裁决」;**禁独立附录清单**、禁改变逐节点结论结构。

## 决策

三层落地,生产行为约束 = **决策路径零变化**(迁移只改检查/披露/复盘面):

1. **检查器迁移(兼容降级,9 判定核)**:C1/C2/C4/C5/C7 的「自述豁免→continue」分支降级为「**自算复核通过才豁免**」——复核判定核单一源 = 新件 `sim/checks/selfcalc.py`(复核三态:`ok` 豁免照旧 / `mismatch` 可疑项条目+不豁免 / `unverifiable` 豁免照旧);C3 预算闸判据本体保留机械检查器,辖域缺口由 D3 前置失配检测补位;C6 时序歧义理由成立(机械不复算定型位),豁免面不变,语境条目归 D6。失配产出 = 可疑项条目(自报值 vs 自算值对照+裁决问句),机械判违面照旧(双条目各司其职)。**unverifiable 豁免照旧是兼容策略的关键**:旧账本无披露键、名册不可解析(未锁线)一律不定罪——无键回退先例 = ADR-0589,避免一刀切翻旧案(实证边界:seed4 r3 arm1 未锁期合法发射、seed18 p1r1 孤儿清算,均为语境缺失非谎报)。
2. **检测器集(新件 `sim/checks/suspects.py`,D1-D11)**:每检测器 = 模式检测函数 + 条目形态(「可疑项(模式):pXrY …;自报=…;自算=…——请裁决:A / B」)。判定核单一源:D1/D3/D4/D5 吃 selfcalc(与检查器迁移面同函数),D2/D7/D8/D9 直接包装段级检查器(现函数逻辑即检测器),D10/D11 吃披露键/注册表现读;跨轮 streak 类锚 = 达成阈值触发轮,被跨越轮加「↗ 连击(锚 r{n})」交叉引用行。生产数据入口 = `ledger_hooks.merge_round_rows`(SellBench 并入合并行动作并集,生产卖出行缺 name/sell_reason 键按缺键跳过 = 声明缺口)。
3. **生成侧自算披露三键(engine_p1 执行点,ADR-0589 同构,零 rng/零状态写入)**:`dec_engines_count`(BuyCard 执行点成型度现读)、`dec_sell_in_line`(SellBench 执行点被卖件线名册成员现读;**未锁线期名册不可解析 → 恒 False = 语境缺失非证据**,复核面按 unverifiable 处置)、`dec_bench_wait_member`(LevelUp 执行点 bench 持线名册成员;与 dec_board_full 合成 pop_slot/m3_batch 存在性腿)。
4. **复盘骨架生成器(新件 `tools/cw/review_skeleton.py`)**:输入形状自适应(sim 账本行直用 / 生产帧经 merge_round_rows),按 match-review 协议 §阶段 2 节点结构生成骨架,检测器条目预填插对应节点小节判定三槽之前(顺序:入口观察→决策循环→可疑项预填→判定三槽);op 粒度完整渲染仍归 replay_to_md.py(本工具只辖骨架+预填,不重做 op 重建)。

### Considered Options

| 方向 | 裁决 | 理由 |
|---|---|---|
| 自算复核降级豁免(失配产条目+不豁免,unverifiable 照旧) | **采纳** | 治本(豁免边不再静默采信自述)且兼容(旧案不翻、真失配才显形);三态显式区分「证据反驳」与「证据缺失」,防历史批次全量假红 |
| 一刀切删除自述豁免分支 | 否决 | 历史批次/无披露键账本全量假红;真前置未遂形态(static_ev/dp 决策期中间量)无从自算,硬删=把不可复核误判为违规 |
| 全部迁成复盘条目(废机械检查器) | 否决 | 报告 §4.3:账本守恒/逐击预算闸重演/统计校准族是机械检查器本职,模板化只会刷屏;机械面批量哨兵职能不变 |
| 独立附录清单(检测器结果汇总成节) | 否决 | 用户裁定明令禁止——条目脱离节点语境即失去裁决上下文 |
| 披露键复核在空名册语境按 False 定罪 | 否决 | seed4/seed18 实证:未锁线期键值恒 False 是语境缺失;据键定罪 = 新假阳源 |

## 后果

1. **检查器输出语义变化(判读面须知)**:迁移核的输出列表可含「可疑项」条目——批报告 `checks_violations` 计数(非空即计违规局)自此对可疑项敏感;可疑项是「请裁决」不是定谳违规,逐字读 detail 区分。已声明的边界:dp/static_ev 臂、无披露键旧账本不可复核(豁免照旧);未锁线语境的**待上场腿**不可得,但板满腿是名册无关真值——`dec_board_full=False` 的反驳证据在场仍产失配(落地审 L6 裁决,封死「不锁线即豁免谎报」后门;板满=True/不可得才落 unverifiable),故完全不可见的谎报面收窄为「未锁线 ∧ 板满宣称与真值一致」的组合。可观测性缺口如实存在,残余面补位归 D3 语境条目(交复盘者)。
2. **锁变化**:test_cw_sim_suite 的 seg_overflow_idle_spend 双向锁按新语义重推改写(「formed_stop 行→豁免」退役,改为谎报显形+自洽停手豁免双断言);新锁面 = test_cw_suspect_review.py(9 判定核锁+三披露键供给半环锁+检测器登记门+骨架输出锁+生产 grep 守卫)+落地审修复锁(L1 copy 对可达/L2 净持有销账/L3 D5 跨面窗口/L4 seg 金门/L5 谎报辖域/L6 板满反证)。
3. **行为零漂移申报**:三披露键零 rng/零状态写入;行为投影 digest 只取动作 `(__type__,reason,result)`(test_cw_w614_sim_fidelity 锚),键零位移;merge_round_rows 动作并集扩 SellBench 经段级消费面核对(`_seg_spent` 白名单与溢金 streak 判定均不含 SellBench,零影响)。
4. 验证锚:快速层全量(基线红全在 delta_pool/fake_game/progression_ops/telemetry_collect 在飞批域 = 并行池再生与 ops 改写竞态环境抖动,非本批);seed18 端到端 = T-141 豁免在复核机制下保持(未锁线口径)+人为失配红证(可解析名册+键 False → 可疑项+判违产出);模板生成器真实档案**结构**实证(节点结构/三槽前序/禁附录)+带条目渲染由合成锁面验证(真实档案扫描为 0 命中,表述按落地审 Q4 收窄)。
5. **落地审修复批**(同日;报告 = 审查工件,语义吸收于本节):L1 copy 买入进 bought(纯 copy 买→同轮卖对在机械面可达复核,申报与实码对齐);L2 持有语境改净持有(买入入集/卖出台账销账,首行末态扣首行动作名作开局种子,「终身持有通行证」形态封死);L3 D5「≤2 轮」窗口改行序单调轴(round_num 是位面内编号跨位面重启,行下标差=全局轮距,跨面紧邻不漏报/远距不假阳;pool 旧检查器同病属存量另案);L4 seg 级 C2 复核补批版同款金门(<interest_floor,注册表现读)且文案由金门现值渲染;L5 批级 C5-b 谎报条目辖域收溢金未泄轮(非溢金谎报只剥夺豁免不产越辖条目);L6 见后果.1;注释级「排查报告 §」引用全部改 ADR-0593 指针。
