## 推导

### ① 三谓词的精确数学

**P1 真破息**:

```
过渡式(历史对拍保留):P1(g, c) ⟺ t(g,c) ≥ 1,  t(g,c) = I(g) − I(g−c),  I(x) = min(⌊x/10⌋, 5)
规范式(L 联动批,P1 基判据换轨):
P1(g, c) ⟺ L(g, c, R_全局, Ī) > 0     (Ī = [6,8] 带中位 7 现算;p47 双轨迹递推)
```

**L 基判据的行为(亲算,Ī=7)**:同档近 50 自然出域(L(41,1,·)=L(45,4,·)=0);低金带同档自然进域(L(9,8,R,Ī=4)=10、Ī=7 时 2-5 > 0);**分带标签退役**——过渡口径下的「t≥1 ∨ (t=0 ∧ 低金带 ∧ 无卖回计划)」扩域条款被 L>0 基判据自然吸收,中带 [20,30) 角消解(L(29,9,9,Ī=4)=5 > 0 自然进域);与过渡式的差异集中在 t=0 带(同档残损)——**「有卖回计划」分支保留**(下④ [11] 行:p47 命题三动态修正)。与提案字面式「g−c<50 且 ⌊g/10⌋ 下降」在 g ≤ 59 逐点等价(g≤50 时两式同义;50<g≤59 时 ⌊g/10⌋=5,档降 ⟺ g−c<50 且 ⌊(g−c)/10⌋≤4)。两处必须修正/声明的边角(**L 基判据下自动吸收**:L 递推内部即封顶息函数、溢余段先扣 d_eff——注记保留作实现对照):

- **封顶口径**:t 必须用封顶息函数 I 差分。`ev.interest_cost` 的档差用**未封顶** `g//10 − (g−c)//10`:g≥60 段花金仍 ≥50 时它计 t≥1 而物理息损 t=0(息已封顶,60→52 不损息)。二值否决判定上等价(都触发/都不触发的界在 50 线),但**入账的 C 在 g≥60 穿透段被高估**(如 65 花 25→40:未封顶 t=2,封顶 t=1)——实现消费 C 数值时须换封顶口径。
- **溢余穿透**:g>50 的支出分两段——**不穿透**(c ≤ g−50,花后 ≥50):I(g)=I(g−c)=5,t=0,**不在域**([17] 溢余段自由的数学形态);**穿透**(c > g−50):t = 5 − ⌊(g−c)/10⌋ ∈ [1,5],物理息损为真(54 花 8→46,损 1 金/轮直至回档)。见 ④ 与 [17] 的一致性裁定。

**P2 无当轮兑现路径**(可观测判据,A3):

```
P2(g, c, 板面态) ⟺ ¬[升级 ∧ 部署空位 ∧ 有成型单位待上([33] 人口位)]
                  ∧ ¬[买入 ∧ (部署空位 ∨ 换下弱件) ∧ 边际羁绊贡献 > 0]
                  ∧ ¬[合成完备(本笔使同名同星计数 ≥3,merge)]
```

三支对应 [33]/[31]③/[32] 的当轮战力通道;**边际贡献 > 0 是硬条件**——空升级、无强单位可上的腾席、纯散件垫底([32] 列举的三类无效开支)全部不构成兑现路径。

**P3 非豁免类**:豁免类 E = E_rev ∨ E_line,**均为条件判据**(③ 推导),不是类型标签:

```
E_rev ⇔ V_opt(件) ≥ L(g, c, R_全局, Ī) + fee       (规范式,L 联动批;fee = 回程不可逆差额,见 ③-1;
                                                    过渡式 t×min(R,3) 并列保留历史对拍)
E_line ⇔ V_ms × ΔP̂(买后|买前) ≥ L(g, c, R_全局, Ī)  (ΔP̂ 走 P38 通道,见 ③-2;同上换轨)
P3 ⟺ ¬E_rev ∧ ¬E_line
```

**否决域 D = P1 ∧ P2 ∧ P3。**

### ② 域内期望净损(息档损失结构)

**平台轮口径(定义与辩护)**。息损不是「跨档瞬间」的一次性事件,是**金位停留在低档期间每轮少吃的息差**:

```
C_过渡 = t × min(R_全局, 3)      (过渡口径,保历史对拍;L 联动批)
C_规范 = L(g, d, R_全局, Ī)      (p47 双轨迹递推,Ī 中位 7 现算——L 联动批;数值表已加 L 列)
```

- **C 的轴=R_全局**(主式即全局轴,位面轴辩护作废——位面边界是节点序产物不是经济边界,金跨位面继承则息损轨迹跨位面延伸):过渡式 C = t × min(R_全局, 3);规范式 C = L(g,d,R_全局,Ī)(p47 递推——**p47 A6 已裁双轴:全局轴=规范口径、位面内=下界,R_全局 代入是其声明内的正规用法**;数值重算挂五方联动批);
- 回档轮 cap 3:破 1 档 = 金位距档线 <10 金,每轮净收入 ≥6 金(A1)→ 1-2 轮回档;ADR-0352 折中口径取 3(P6 回档账下界 1-3 与平面上界的中点偏保守侧)——**过渡式专属参数:L 口径下无 cap,回档轮由递推内生**(L 联动批;cap 保留作历史对拍与 ADR 出处);
- **利息封顶后的衰减不存在于本式**:损失项只在低于原档期间累积,回档即止;封顶(g≥50)段本身 t=0 无损失可衰减;
- **跨位面继承不延长 R_pl 的旧说法作废**:全局轴下,位面末花金的息损延伸到下位面前几轮——**「不存在 R=0 出域」的前提 = p47 A2 结算时点按「轮初金位」口径(待实机核)**;若实测为「行动后不结算」形态,末节点出域恢复——三处无条件陈述现挂 A2 依赖;「位面末自由 allin」只在 t=0 时成立,R_全局 ≥1(含当前节点)。

**期望净损封闭式**(支出 c ∈ D):

```
E[净损] = C + O − V
        = L(g,d,R_全局,Ī) + O − V_deferred      (规范式,L 联动批;过渡式 t×min(R,3) 并列保留)
```

- **C = L(g,d,R_全局,Ī)(规范,p47 递推)**:息档损失,唯一货币化主项;量级参考(Ī=7 亲算,p47 失效带表):平台期 d≤10 → L=1、d=20 → 3、d=40 → 14;爬坡深花 (30,25,R=9) → 15;低金带同档 (9,8,R=9,Ī=4) → 10——**形态对 d/R 超线性、对 g/Ī 非单调**(p47 勘误:不得假设单调,一律走递推);过渡口径「C ≤ 15 金、常态 3」的常数形态作废;
- **O ≥ 0**:零当轮战力的机会成本(同金换当轮战力的反事实差)——**符号与量级声明**:不货币化([39] 禁 HP 入账——辖域:非血本位语境;[40]② 血本位激活时血是经济账户读数,但 [40]③ 定价通道已作废,血仍不进本域,O 的处理不变);略去它使净损被**低估**,否决结论对略 O 稳健(A4);
- **V_deferred**:延迟价值(囤件期权/未来上场/压库)。域内由 P3(非豁免)保证 V_deferred < 豁免阈值 ≤ C——**这正是域的定义把净损压到非正的机制**:E[净损] ≥ C − V_deferred > 0 ⇒ 该笔支出期望上烧金。

### ③ 豁免类的边界条件(两个都不是无条件)

**③-1 资产可逆(E_rev):期权价值 ≥ 持有成本 + 回程摩擦**

`sell_refund` 事实(ADR-0121):1★ 卖出 = cost 全额退(买卖净 0);1费各星净 0(cost≥2 且 star≥2 才有 −1 手续费);cost≥2 的 2★/3★ 合成再卖亏 1(推测待 live 核)。推出:

- **可逆性把沉没成本转为持有成本**:破息买 1★ 件,本金可全额收回——真实损失只剩**持有期间的息差**(= L(g,d,R_全局,Ī) 在持有期内截断——规范式,L 联动批;过渡口径 t×min(R,3) 并列),不是 c 本身。这是「1★ = 活期金」(P6/P10④)在破息段的推广;
- **期权价值** V_opt = 再遇窗口规避价值([22]③:不买这张,再遇期望 1/q 轮):5费在 7-8 级 = 60-180 轮(整局可能不再遇)/急 D 补救 120-360 金 → V_opt 量级 ≥ 数十金 ≫ C(常态 3);1费 7-15 轮自然回 → V_opt ≈ 1-2 金量级 < C;
- **判据(条件豁免)**:

```
E_rev ⇔ V_opt(件) ≥ L(g,c,R_全局,Ī) + fee,  fee = 0(1★任意费 / 1费各星);1(cost≥2 合成回卖)
       (规范式,L 联动批;过渡式 t×min(R,3) 并列保留历史对拍)
```

购买线内缺档件 = 把 P38 的件 k 从缺口集**确定性消除**(而非等未来刷新命中)。判据:

```
E_line ⇔ V_ms × ΔP̂ ≥ L(g,c,R_全局,Ī)      (规范式,L 联动批;过渡式 t×min(R,3) 并列保留)
ΔP̂ = P̂(集齐 | H ∪ {件k}, B − c) − P̂(集齐 | H, B)
```

- P̂ 走 P38 闭式(Π Binomial 尾,单调性构造保证);预算 B 用 P38 公式(金/回合/等级日程入账)——注意**耦合**:买这件同时使 B 减 c(钱花掉了)与缺口减一(件填上了),ΔP̂ 是两效应的净额,P38 单调性(预算↓概率↓、缺口↓概率↑)给出 ΔP̂ 符号不定、由「差 1-2 张成型」段(V_ms 高边际)主导的形态(p40 ③ 同构:只有最后 1-2 张的边际可能盖过门槛);
- **非无条件**:线内件但缺口深(K 大/n_k 大 → ΔP̂ ≈ 0)或里程碑价值低(过渡期非关键档)→ 不豁免。[37] 的「门与账单按下一成型档位算」正是 V_ms 取值粒度的规格(不按全终局,避免 ΔP̂ 系统性偏低导致豁免过少)。

### ⑤ 与 [17] 的一致性裁定(唯一的字面张力点)+ p40 R2 分工声明

**[17] 张力裁定**:提案字面读法「真破息(g−c<50 ∧ 档降)∧ 无兑现 ∧ 非豁免」会把**溢余穿透但有兑现的支出**(g=54 花 8 升级人口位)也否决吗?不会——P2 假即出域。真正会被字面否决的是「溢余穿透 + 无兑现 + 非豁免」(g=54 无目的花到 46):此时 [17] 的授权也**不覆盖**它——[17] 防读半明文:「决策判据是当下有没有边际价值高的花处,没有就留着」= P2;[32] 消费有效性(「换不来战力的开支不做」)同样禁它。**结论:提案与 [17] 无实质冲突,条件是 P1 必须按封顶息函数差分定义(① 的两处修正),且否决是三谓词合取而非「破息即否」**。反方向(口述禁止但提案放行)未发现:[1] r1/r2 不 D 牌属刷新通道(p40 R0),非购买域。

**与 p40 R2 门分工声明(不双计不冲突)**:

- **p46 = 购买通道**:单笔卡价 c 的否决域(本篇);辖「这笔买不买」;
- **p40 R2 = 刷新通道**:刷费 2n 的息线预算(溢余段自由 / 跨档进 P13 账);辖「这轮刷不刷、刷几次」;
- **同一 C 单一源**:过渡单一源 = P13(t×min(R,3)),**规范单一源 = p47 L(递推)——两门(p46/p40)同步切换,防换轨不同步产生新双源;
- **不双计**:同一备战期内刷费与已采纳买价必须**并入同一 spend 再算 t**(合成引理 A6 同式)——p40 R2 已把 Σ命中卡价计入 spend,p46 判定时 spend = 本轮已花累计 + 本笔。t 对总 spend 只算一次,C 只入一次账;**XP 通道例外**:经验购买**不进 A6 逐笔判读**——Leontief 互补品([41]/p48 整买引理)使逐笔读法会产生「部分批」最差结局,XP 批按**整批总额**判(实现侧 `steady_state_levelup_group` 即整批总额判,证明侧声明同构);臂一 floor_pop<50 时的**批破息**走 p47 命题四 V≥L 直接定价(p48 已声明,p46 侧已接通);
- **不冲突**:p40 R1 完成门管「追缺口的启动」(承诺账),p46 管「启动后命中即买(p40 A4)的每笔卡价是否被否决」——刷的启动与买的否决是两层门,判定序 = p40 R1(要不要 D)→ 命中 → p46(这张买不买)→ p40 R2 熔断(还能刷几轮)。**交互裁定**:p40 刷新 EV 的合格集 E 按**期初静态快照**预过滤 p46 可过卡的集合(白刷在「单笔判据、期初快照」口径下消解);**残余白刷(诚实声明)**:①同刷新多命中各笔判定后金位变化;②累计跨档使后笔落域;③部署位互斥(买了 A 上不了场,B 才是兑现路径)——三态下仍可能有「刷出而不买」的期望损耗,p40 EV 侧应按命中折扣或最保守序消化。
