# ADR-0592: P1 升级视界支A 兑现链谓词收敛(T-139)——[33] 板面域不限星级 + 配方缺口成员 + 谓词单一源下沉 kernel

## 背景(病灶与归层)

t120 24 局假局双跑(找问题-校准后首跑/第二跑):r6-r8 中段 24/24 局冻结
lv4、form_ok 0/24、升级集中位面末 ALL IN 爆发。根因链(P82-a 带内等价
引理,零参数):lv4→5 升级批 xp_cur=0 域 s=8,s+2ρ∈{10,12}≥10 ⟹ 带内
通过集空,推迟目标 = 不动点 F=g*+s+2ρ∈{60,62},高于 P1 中段金位带
29-52——P72 全段预算闸对 arm1 帧构成**量闸否决存在性**,形态的战场
兑现窗结构性 forfeit。归层 = 决策层判据面(升级支A 兑现链谓词)。

支A 谓词「板满 ∧ bench 有 2★ 等待件」系 ADR-0576 落码批(2026-09-07,
T-63/T-79)在 **[33] 精确化裁定(2026-09-01)之后新写入**的收窄形态——
裁定原文判废「star≥2 ∧ 目标线名单」双收窄,判定域 = 阵营相关单位、
不限星级、不限锁定线名单:**落码违裁**(P82-e 定性;非旧谓词残留)。
设计 = T-139 方案 v3(`.debug/temp/currency_war/t139_p1_upgrade_horizon/
方案.md`,三轮无前提对抗零阻断收口;命题族 = math_proofs P82-a~e,
单篇候证明批入册)。批序前置:ADR-0590(T-127 R2)已落地(2718e681)。

## 决策

1. **谓词对齐(P82-c,双向差分)**:支A 兑现链从「板满 ∧ bench 任意
   2★」收敛到「板满 ∧ 配方等待件(arm1_existence ② 板面域,不限星级)
   ∧ 边际贡献>0」。放行域变化是**对称差**非超集:放宽 = bench 1★
   配方缺口件(star 合取无兑现链依据——兑现链三件[人口位增量/羁绊档
   按在场人头计数/部署合格拒因闭集]均无星级依赖,t120 病灶即 1 费
   仙舟成员买得到上不满);收窄 = 线外 2★ 与纯冗余件(无 [33] 域与
   [35]③ 排除依据;P1 环境预期稀少,计数申报而非假设为零)。
   语义单一源 = `kernel/cw_waiting_piece.recipe_waiting`。
2. **谓词单一源下沉 kernel(ADR-0516 下沉先例,编排者 C2 裁决)**:
   `arm1_existence` 实现自 statefn/predicates 迁
   `kernel/cw_waiting_piece`(逐字同体),statefn 位改 import 重定向、
   三在役消费位(mandate/shop/entry M3 触发面)调用零改;kernel
   `schedule_upgrade` ①臂与 `_upgrade_ul_threshold_ok` ΔV_pop 指示项、
   criteria `_realize_chain_ready`(委托)、引擎披露、检查器镜像五面
   同源——ADR-0576「三副本逐字一致、改谓词三处同改」的登记面随
   单一源化终结。
3. **C1 等待件收紧显式参数(候裁挂账,翻常量即切)**:模块常量
   `RECIPE_WAITING_MODE`,缺省 `'gap'`(口径 B「配方缺口成员」:候选件
   共享键中任一键板面计数 < `FACTIONS[key].tiers[0]` 基础激活档;任一/
   全部量词与 [35]③ 全档饱和排除对偶自洽),`'ignition'`(口径 b:
   上阵恰达激活档)/`'board'`(口径 c:纯板面域)候选如实保留。候裁行 =
   进度账本 T-139(用户候裁中);ADR-0590 `REDEPLOY_TRANSITION_ENABLED`
   同款生命周期:裁决落地翻常量+本 ADR 候裁节回写,无悬置态。档位
   单一源 = FACTIONS 注册表首档(N6;kernel/cw_deploy_logic 的
   TRANSITION_TRAITS 挂账副本禁 import)。
4. **C2 裁决落位:轻量合取先行,完整接线挂账**:`char_id∉deployed_cids`
   同名排除(E1)随本批落码——候选件与场上同名时部署被围栏拦,当帧
   不可兑现;零参数、检查器可镜像。完整 `has_deployable` 部署语境接线
   (C_realize 完整评价面)候后续批,owner/期限承继 ADR-0576 §判据
   (01 §6 三要素 3);R2 装配面已落地(2718e681),避让理由随批序消失,
   时点归编排者排期。
5. **检查器镜像与披露扩键(ADR-0589 模式)**:引擎 LevelUp 执行点新增
   `dec_recipe_waiting` 披露键(发射帧收敛谓词现值;零 rng/零状态
   写入,digest 口径不受影响),检查器 `check_levelup_budget_gate` 支A
   按击豁免三级优先:dec_recipe_waiting(现役权威)→
   dec_board_full/dec_bench_2star(ADR-0589 旧谓词形态键,辖跨版本
   账本近似)→ 无披露键行末回退(近似**经同一单一源谓词**现算——
   谓词同源,近似仅在帧时点;历史批次在新镜下的误报窗 = 旧行为线外
   2★ 旁路帧,双向申报)。契约锚
   `CONTRACTS[('levelup','levelup_budget_gate')]` 追加 ADR-0592。
6. **闸本体零改申报**:(3a) 强读式、τ/ρ/Σ预留三分量、ALL IN 豁免、
   (1)(2)(4) 合取、P48 整批、血面合取、奖励帧辖域注(ADR-0580 抑制
   先辖)逐字不动;溢余段退化一致性保持。姿态扩张承继申报(P72 边界
   3):支A 是「显式姿态声明非已证支配命题」,谓词人群从 2★ 扩到 [33]
   域的同比例敞口由既有挂账观察「升 cap 后 K 轮空置率」承继,本批
   A/B 回填。
7. **批序与 ALL IN 语义划界**:A/B 基线 = R2 落地后重跑同池同 seed
   配对批(t120 双跑只作环境参照,防归因混杂);T-143 清算臂若先于
   批 3 落地则同模式重跑,息基护栏读数显式申报混杂。本批可执行帧集
   元素「位面末 ALL IN 帧(R=0 机会成本恒零)」照 P72 §2.5 在册形态
   消费,不预支 math_proofs P81 行(T-143)候裁收窄面「R=0 恒零表述
   过强」——裁定前不约束现行为,两批互引。

## Considered Options

- **域来源(方案 §3.3 三选一)**:a) 板面域 = 复用 arm1_existence
  (选定——与 [33] 字面「能加入当前阵容羁绊体系」最贴,与生产既有
  单一源合流,未定型期/P2+ 天然有定义);b) 方向键域(_pair_bond_keys
  +line_members)——名单 tuple 充当羁绊键集类型错位、exit_p1 清空致
  P2+ 放行域坍缩,否;c) 四体系 TRANSITION_TRAITS 域——比裁定字面更宽
  且弃既有单一源再造分歧,否。
- **放宽路径**:a) 支A 谓词收敛(选定——零新自由参数、不碰 ΔV_band
  闸门位);b) P1 升级视界参数——视界阈值无推导源且与 ADR-0576 决策 4
  「ΔV_band 禁单独作闸门」同形,否;c) 形态驱动豁免——缺口计数无兑现
  链合取会放行 C_realize=0 帧(P71 73002 病灶类),否。
- **下沉路线**:kernel 单一源下沉+消费位零改(选定,ADR-0516 先例);
  kernel 侧同义实现+对拍锁——双源漂移面,否。
- **C1 收紧候选**:a) 任一档缺口(缺省,推荐)/b) ignition 收窄
  (首件帧不解冻,解冻残留)/c) 纯板面域(与 [35]③ 冲突)——候裁
  挂账,常量切换。
- **支A② 接线形态**:a) char_id∉deployed_cids 轻量合取先行(选定,
  C2);b) has_deployable 完整语境随批——撞 R2 装配面(已落地)且波及
  面×5,候后续批。

## prereg 判据节(批 3 跑批前写死;先 commit 后跑批,禁看完数据挪线)

主判据(双向申报;预期值仅对「线外 2★ 稀缺 ∧ 1★ 缺口件常见」的
t120 型 P1 环境成立,条件随线声明):

1. **主判据 = r6-r8 决策帧 lv≥5 局占比**(快照+帧内升级后双列口径):
   改后 ≥60%,且较同口径重跑基线上行 ≥25pp。基线以批 3 重跑基线批
   同口径实测为唯一对拍腿;历史读数存在口径差不入判据(首跑决策帧
   口径 24/24 冻结;二跑快照口径 14/24 系 **cal1 窗复算值,cal2 主批
   实为 10/24**、冻结中位曲线 r6-r8=[4,4,4] 亦 cal1 窗、cal2=[4,4,4.5])。
2. **升级时点分布读数**(方向线;分布披露——无显著性阈值,与读数 4
   同款标注):r9 落点占比(基线 cal1 37%/cal2 39%)下降、r6-r8 落点
   占比(cal2 29%)上升。**计数口径钉 `LevelUpShop` token**,判读脚本
   禁按 `LevelUp` 计数(117/143≈5-6 次/局 vs 伪影 0.25 的 token 伪影
   勘误在案)。
3. **真实终级(双列口径)不低于重跑基线**(单读表述;历史参考:
   cal1=5 / cal2 帧内升级后=6——改动价值在时序前移,不在终级抬升)。
4. **中段解冻帧定位**:首帧 lv≥5 的轮号中位从 r9 前移至 r5-r7
   (方向线;分布披露)。
5. 形态读数(deployed 名单重算口径,趋势对照):仙舟≥2 在场 8/24 →
   上升;仙舟3 达成 1/24 → 上升;B4 缺键 = 无数据非 0%。
6. 息基护栏(病理计数,不设拟合百分线):贴死线死金局(终局 hp=1 ∧
   终金 **≥42**,第二跑档案口径;首跑窄段 46-49 系首跑档案自记,出处
   随注)**不增**;空转轮占比(基线 0.28,**轮**口径;「空转帧」47 帧
   系另一口径不入本线)不升;利息收集总量与破息深度并列披露,系统性
   恶化回 C4 候裁;T-143 清算臂先落则本读数混杂自动降级方向观察。
7. 观察族承继(注明出处):升 cap 后 K 轮空置率 = ADR-0576 边界 3
   既有挂账观察;1★ 等待件帧升级推迟率 = 01_math_framework §7 P72
   收尾支在册观察族(本批直接靶,预期大幅下降)。
8. 判读前置:B3——r6-r8 逐轮双列读数需批 3 判读脚本扩展(现产只落
   等级末值双列);E14——sim XP 通道保真度对账完成前,xp 通道读数
   不作判读主读数;单面批 planes=1,L2/锁线族辖域不可达禁当行为信号。

## 后果

- 正面:t120 中段冻结形态的解冻通道打开(bench 1★ 配方缺口件帧支A
  放行),[13]/[28] 形态达成的结构性 forfeit 解除;文档-实现分歧
  (01 §3.3 不限星级 vs 落码 2★)随单一源收敛消灭;五消费位+引擎披露
  +检查器镜像同源,谓词漂移不可能。
- 代价/边界:①收窄向真实存在——线外 2★ 与纯冗余件不再旁路(计数
  申报,P1 预期稀少);②行末回退分支对历史批次可能出现「旧合法批
  新镜违规」误报窗(披露键现役批不受辖,近似声明在案);③C1 缺省口径
  B 系候裁默认非裁决——用户裁决翻转时行为随 `RECIPE_WAITING_MODE`
  变;④E6 二级联动:①臂变宽 → R* 储蓄更多激活 → 刷新预算挤占,
  A/B 观察刷新次数/搜索量,超预期回设计层;⑤检查器旧键分支辖跨版本
  账本,与生产谓词的形态差在旧键上保留(近似,非同源)。
- 编号更正申报:本 ADR 拟号 0591 与并行 T-141(线账闭合豁免键批,
  文件已落盘+7 处接线)撞号,编排者裁决改 **0592** 让位;方法论 =
  方案 §7.3 编号核查三修正(核查附时间戳/落盘前对 INDEX 再核/并行期
  取「当前最大+1 以上」缓冲)——P80/P81/ADR-0591 三连同型竞态,后续
  批按缓冲准则执行。
