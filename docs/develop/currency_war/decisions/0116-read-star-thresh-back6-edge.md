# ADR-0116:read_star TM thresh 0.50→0.45 解后排-6 边槽第2星漏(迭代 ADR-0114)

- **Status**:Accepted(2026-08-13)
- **迭代**:迭代 ADR-0114(TM thresh 0.55→0.50 解后排-3);0116 再降 0.50→0.45 解后排-6
- **纠正(2026-08-13 实测)**:初稿猜「各排金星透视尺寸不同 → 多模板 per 排根治」。**实测推翻**:各排金星 bbox
  17-19px 基本相同(前排 19×18 / 后排 19×19 / 备战 18×18),**非缩放失配**,多模板 per 排无用。真因 = **紧贴遮挡**(下述)。

## Context

「各槽位覆盖」(用 ``DragCwChar`` op 拖 2★ 角色遍历各排边槽)发现 **后排-6(右边槽)假阴**:椒丘(2★)在后排-6 读 1。
逐 peak 追踪:第2星**不是**被形状拒,是**根本没检测到 peak**(TM top-8 全聚在第1星)。多 region/thresh 诊断:**第2星
TM val ~0.45-0.50**(thresh 0.50 滤掉);放宽 region 不解(非裁剪),降 thresh 到 0.45 才检出第2星;0.40 过数噪声。

**真因(实测)**:2★ 两颗金星**紧贴**,第2星被第1星**部分遮挡** → 其 mask 不完整 → TM val 偏低。各排一致(星尺寸相同,
非缩放)。第2星 val 普遍低于第1星(实测 第1 0.62-0.69 / 第2 0.45-0.58),val 随紧贴程度变(后排-6 最紧 ~0.45 / 后排-3 0.51)。
**thresh 0.45 = 真第2星(≥0.45)与噪声装饰(<0.40)的分界**,余量 ~0.05。

## Decision Drivers

- 用户要求「各槽位 1★/2★ 都准」—— 边槽覆盖暴露第2星紧贴遮挡致 val 偏低
- 实测确认非缩放 → 多模板无用;thresh 0.45 正确分界真星/噪声 → 务实采用

## Considered Options

### A. 降 thresh 0.50→0.45(采用)
验证(2026-08-13):立绘库 71 张 **0/71**(0.50/0.47/0.45 都 0)+ 全 fixture 无新 FP + 所有边槽 fixture(bench1/front1/
front4/back1)thr0.45 仍读 2 + **后排-6 读回 2**。0.40 才过数噪声 → 0.45 余量 ~0.05。

### B. 多模板 per 排(**否决:实测非缩放**)
初稿假设「各排金星透视尺寸不同」→ 实测各排星 bbox 17-19px 相同 → 多模板 per 排无用。**不考虑**(假设已推翻)。
(注:多**尺度** TM ADR-0114 也否决过 —— 连续 resize 引 9/71 误判;本处是离散 per 排,但因尺寸同也无意义。)

### C. 放宽 region(0.65h→0.50h)
**否决**:诊断证后排-6 第2星不在 region 外(放宽 region 仍 count=1),是 TM val 低非裁剪。

## Decision

**A**。``_STAR_TM_THRESH`` 0.50 → 0.45(``cw_identity_obs.py``)。

**0.45 是正确分界,非打地鼠补丁**:真第2星 val ≥0.45(紧贴遮挡下限),噪声 <0.40,0.45 居中分开。除非出现紧贴更甚的
第2星(val<0.45),否则稳定;若出现,考虑**紧贴分离**(形态学腐蚀分开两星再各匹配,治本于遮挡)而非再降 thresh。
