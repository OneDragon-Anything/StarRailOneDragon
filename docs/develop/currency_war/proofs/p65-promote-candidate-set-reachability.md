## 1. 命题(形式化)

设 v2 候选域 = `_v2_comps()`(12 线,`COMP_LIBRARY` 按 `V2_FAMILIES` 过滤),
pair = `p1_pair_frozen_obs`(P1 配方对退场前冻结快照,体系键二元组,键域 =
`TRANSITION_TRAITS` 三羁绊键 ∪ {希儿系})。记:

- **移交候选集** H(state, ist, visible)= {c ∈ v2 域 : c ∉ ist.evicted ∧
  plane ∉ weak_planes(c) ∧ _core_reachable(c, state, visible) ∧
  (plane ≠ 2 ∨ G(c) > ε)}(生产原式,移交候选段 `cands` 列表推导);
- **晋升候选集** P = `promote_candidates(state, ist, ...)`(生产实装):
  H 的判据合取 ∧ **体系键交集支**:((form_tiers ∪ sub_tiers) ∩
  `_pair_bond_keys`(pair) ≠ ∅)。

**定理 1(集合包含)**:对任意合法输入,P ⊆ H。

**定理 2(v2,生产展开语义的结构性非空判据)**:记结构面 S(pair, plane,
evicted)= {c ∈ v2 域 :(form_tiers ∪ sub_tiers) ∩ `_pair_bond_keys`(pair)
≠ ∅ ∧ plane ∉ weak_planes(c) ∧ c ∉ evicted}。则对全部六类可达 pair,S ≠ ∅
**无条件成立**(evicted = ∅ 时)——每个体系键(含希儿系的展开键)在 v2
集合内都有非弱面活载体(§3 尾表);S = ∅ 仅当 evicted 清空某 pair 全部
活载体(§4.2)。**v1 的「pair=(仙舟,希儿系) 反例洞」在生产展开语义下
不存在**:希儿系展开键 {量子同频, 贝洛伯格} 被希儿量子线档键承接
(§4.1 假想例留档)。

**推论(非空率真驱动)**:P 非空率的数据面驱动 = `_core_reachable ∧
G>ε`(核心可见性/再遇窗/G,逐帧状态量);结构面在 evicted 常规形态下
恒非空。与设计稿 §6「①前置观测」申报一致。

## 2. 定理 1 证明(逐合取项直证;合取项语义按生产实装对齐)

P 的定义(`promote_candidates` 逐行)是 H 的判据合取再加一条合取支。逐项对照:

| 合取项 | P(`promote_candidates`) | H(移交 `cands`) | 关系 |
|---|---|---|---|
| 候选域 | `_v2_comps()` | `_v2_comps()` | 同一函数(同一 12 线域) |
| 驱逐 | c ∉ ist.evicted | 同 | 同一字段同一谓词 |
| 弱面 | plane ∉ weak_planes(c) | 同 | 同一字段同一谓词 |
| 可达 | `_core_reachable(c, state, visible)` | 同 | 同一函数同入参 |
| 可行 | plane ≠ 2 ∨ G(c) > ε | 同(G = `line_completion_feasibility`,ε = 同一注册表源) | 同一函数同一阈值 |
| 体系键 | 档键 ∩ `_pair_bond_keys`(pair) ≠ ∅ | (无此项) | **P 多出的纯限制** |

每个 P 成员满足 H 的全部合取项 ⇒ P ⊆ H。体系键支在展开语义下仍是纯限制
(只减不增,相对 H 无任何放松)。排序沿用移交候选既有键(资产厚度降序 →
再遇窗升序,`_asset_thickness`/`encounter_window_rounds`),零新排序键零新
自由参数。∎

经验面复核:状态网格 plane×level×hp×round×pair×visible×evicted 共
**10368 格**,逐格直调生产 `promote_candidates` 断言 P ⊆ H
(`tools/cw/proofs/p65_check.py` 断言 2,全过;快照锁测试另含 144 格抽样)。

## 4. 反例搜索(v2)

### 4.1 仙舟-希儿洞:撤回,降为字面口径假想例(出辖)

v1 曾按设计稿公式**字面口径**(档键直接 ∩ pair 键,不做希儿系展开)
判定 pair=(仙舟, 希儿系) 结构性空,并据此收窄 R2 结论适用域。
**v2 裁决撤回**:生产实装 `promote_candidates` 消费 `_pair_bond_keys`
键侧展开,希儿量子线承接展开键——生产语义下该 pair 的非弱面活载体 =
{希儿量子, 专家桑博DOT},**恒非空**(直跑实证:`promote_candidates`
吃冻结快照 ('仙舟','希儿系') + 希儿可见,候选含希儿量子线,
`p65_check.py` 断言 3 / 测试仓直跑锁)。R2「pair 恒含列车同行/持续伤害
活载体键」的**更强原结论在生产展开语义下恢复成立**(六 pair 全部结构性
非空,§4.3 表);其字面口径表述(「pair 必含列车同行或持续伤害至少一键」)
作为键频陈述仍真,但已不承重——非空性由展开载体表直接保证。
字面键口径的「洞」仅作假想例留档:若将来有人改生产判据为字面键消费,
该洞将复活(届时须回炉本命题)。

### 4.2 evicted 反例(保留,仍可能的反例形态)

evicted 清空某 pair 的全部活载体时结构面空:列车键需 evicted ⊇
{列车同行};持续伤害键需 ⊇ {DOT队, 专家桑博DOT};希儿系键需 ⊇
{希儿量子, 专家桑博DOT}(与持续伤害键部分共载);六键合取的全掏空
形态 = evicted ⊇ {列车同行, DOT队, 专家桑博DOT, 希儿量子}。evicted
单帧全局纪律下四线同遭驱逐罕见但可能(复算脚本断言 3 / 测试仓直跑锁:
全驱逐形态下六 pair 候选全空)。

### 4.4 状态面(非反例,申报为真驱动)

结构面非空不保证 P 非空——剩余合取 `_core_reachable ∧ G>ε` 是逐帧
状态量(核心可见性/等级再遇窗/血预算视界)。此即设计稿 §6「①前置
观测」须以纯函数计数非空率的依据,本命题不替它给数。
