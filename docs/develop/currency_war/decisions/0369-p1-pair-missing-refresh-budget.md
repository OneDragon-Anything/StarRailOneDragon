# ADR-0369:P1 体系对缺件找牌预算(候选 b:pair 缺件驱动)

- 日期:2026-08-29
- 状态:accepted
- 批:W170(设计报告 `.debug/temp/currency_war/cw_dev/deep_read/W170_报告.md`)
- 前置:ADR-0361(P2 同款机制参照)/ ADR-0367(transition_pair 契约)/
  W166 残差定性(strict_mal 13 局中 8 局=never-2-engine 成型局)/
  W161(P1 刷新归零三机制)

## 背景与问题

W166 治好「有引擎被拆」后,strict_mal 残差主体=never-2 成型局(8/100,
inject on 口径):①锁局/配方锁局副方向都在、体系件见即买,但「目标体系件
店不出→从不主动刷」——P1 的 V_D 找牌只有 comp core 一个对象,且
level_plan 硬门(W154 只改了 P2 分叉)把窗外帧全部拦死;实机侧
W161 实证 5 个「该刷未刷」帧全被 P1 窗拦。

## 决策驱动因素(判据链探针,W170 §0.1)

- **候选 a(P1 也消费 DP refresh_budget,与 P2 同款)弃选**:①sim 窗全开
  后 0 帧通过 [3] 预算前提(旁路假设探针:never-2 局窗帧旁路后正分仅 3 帧
  且花后全穿 50;DP rb>0 的 147 帧全部死在 V_D 自身);②对象错位——a 的
  找件对象仍是 comp core,never-2 局 core 从未入手(copies0 占 None 主因
  127/342 帧),a 与该残差无因果;③「让位给升」非纯损失(这些帧实机把
  钱花在 LevelUp,W161)。
- **候选 b 采纳(单次预算前提口径)**:[3] 用户原话「刷新的预算前提=花完
  仍守 50 息线」的逐字载体=**金 ≥ interest_floor(50)+刷价+缺件买价**
  (一次刷新+买入后仍守满息地板);批口径期望刷金留在 EV 侧裁决。字面宽读
  (批口径预算前提 50+2E₁+买价)弃选:E₁ 高费/错等级时阈值抬至 60-70,
  sim 全拒(探针 0 放行)——双口径叠加过紧到空转。
- **EV 成本保持 P5 批口径面值**(jump(e_cur) − E₁×刷价),不换 P11 溢余
  机会成本口径:E₁ 的概率表本身即 [3]「到概率等级才 D」的载体(1费@lv6
  E₁≈13.7 → 账自然负 →「没到就少刷新」);溢余段 C→0 的口径会把溢余金
  grind 在低概率搜刮上=为刷而刷,违反 [31]「刷新金只用于找目标件」。

## 决策

1. P1 找牌增加 **pair 缺件通道**(scoring._vd_p1_pair):
   - 窗:`transition_pair`/`p1_pair` 非空 ∧ 缺件 ≥1(对成员集有未持有者)
     ∧ 金 ≥ interest_floor + 刷价 + 缺件买价([3] 单次口径);
   - 收益:e_cur<2 时=下一档引擎跳变金值(engine_jump_gold 同式同源,
     [13] 过渡成型≈过 P1);e_cur≥2 → 无对象;
   - 成本:批口径 E₁×刷价(E₁=当前等级刷出 1 张该缺件的期望刷新数,k=1);
   - 缺件取账最大者;每次放行答得出「找什么」=具名缺件([31] 硬约束;
     锁定帧体系对成员=二级目标件,ADR-0367)。
2. 接入 `vd_refresh_score` P1 分叉:core 通道**逐位不动**(level_plan 窗
   只辖 core);core 无对象(配方锁局 p1_pair 帧/core copies0)、core 窗外、
   core 窗内三种态下 pair 账参与(无对象/窗外=pair 独任,窗内=取大)。
   P2 分支(W154)逐位不动(plane≠1 恒不辖)。
3. 常数:registry `vd_p1_pair_enabled: bool = True`(A/B 注入;False=
   逐位回 W166)。

## Considered Options

| 选项 | 结论 | 理由 |
|---|---|---|
| a:P1 消费 DP refresh_budget(替换 level_plan 硬门) | ✗ 弃 | sim 零放行(0 帧过 [3] 预算前提)+对象错位(core copies0)+让位给升有对价;live 窄帧(core 差一张 j=2 溢余)记档残差,不与本批混裁 |
| b:pair 缺件驱动,批口径预算前提(50+2E₁+买价) | ✗ 弃 | 阈值随 E₁ 抬至 60-70,sim 全拒(探针 0 放行)=空转 |
| **b′:pair 缺件驱动,单次预算前提(50+刷价+买价)+ 批口径 EV** | ✓ 采纳 | [3] 逐字口径;概率窗语义由 E₁ 承载;窄条件、可答「找什么」 |
| b″:b′ + 溢余段机会成本口径(P11 式 C_dec) | ✗ 弃 | 溢余金被低概率搜刮 grind=为刷而刷([31] 纪律);P1 攒本金期保持保守 |
| 不动(纯记档) | ✗ 弃 | 配方锁局帧 core 恒空 → P1 找牌结构性无对象;授权语义缺件应补齐 |
