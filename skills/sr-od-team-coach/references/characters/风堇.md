> 按 V4.7 期撰写。速度转治疗的生命模型忆灵奶妈；遐蝶体系最重要辅助（Prydwen 口径）。

## 一、命途属性与技能说明

**命途**：记忆（长夜月 B4 计数+1）
**属性**：风

| 技能 | 说明 |
|---|---|
| 普攻 | 单体风伤 |
| 战技 | 召唤忆灵**小伊卡**/群奶（4%生命上限+40）；伊卡看到掉血就奶 |
| 终结技 | 消耗能量；【雨过天晴】：全队生命上限提高（直接增伤遐蝶/缇宝/长夜月）+受治疗量提高 |
| 天赋 | 伊卡：任意目标回合开始/行动后，看到掉血就奶——**遐蝶烧血的永动奶源** |
| 秘技 | 进战全队回30%上限+600并+20%上限2回合（垫血池） |
| 额外能力 | 「暴风停歇」：**速度>200 每超1点治疗量+1%（最多计200点）**；D2：风堇与小伊卡**暴击率固定+100%**；星魂2：我方掉血时速度+30% |

**资源与循环**：标准能量→充能有效。奶量经遐蝶 A2 行迹转新蕊/死龙生命——治疗=充能。
