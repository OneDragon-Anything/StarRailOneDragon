# 商店(store)

商店界面。多子商店入口(兑换 / 外观 / 协议 / 星琼购买 / 列车补给…) + 商品购买。**不锁光标**(`pc_alt=false`)。通用系统,不必先搜玩法。

## 何时出现 + 状态流转

- **入口**:菜单点「商店」(phone_menu_const.STORE)→ 商店主页。
- **出口**(动作 → 下一态):
  - 点分类标签(银河风尚 / 开拓助力 / 特惠车票 / 专票礼盒)→ 切分类(停留主页)。
  - 点左侧商店入口(列车补给 / 兑换商店 / 聚灵铸星 / 外观商店 / 协议商店 / 捕获梦华 / 星琼购买)→ 进对应子商店画面。
  - 点商品 → 购买弹窗(选数量 + 确认/取消;已售罄 / 材料不足提示)→ 确认购买。
  - 右上返回 / ESC → 回菜单。

## 识别特征(稳定锚点)

- **主页态无精准匹配**(`screens=[]`):store.yml 的 area 是**购买弹窗态**(商品列表 + 购买按钮),主页态(分类 + 商店入口)无 id_mark → analyze 不命中。靠 OCR「商店」标题 + 布局判主页态。
- **购买弹窗态**(store.yml area):商品列表(290,110-1790,817)、按钮-购买最大值(template `store_buy_max`)、BUY_DIALOG_ADD_BTN(template `store_buy_add`)、购买-已售罄 / 兑换材料不足(text)、按钮-购买取消 / 确认(text)、点击空白处关闭。
- `pc_alt=false`。
- 易变:货币数(星琼 / 专票)、商品 / 价格、活动倒计时(28天5小时)。
