# 货币战争-阵容编辑

## 画面简介

「我的阵容」的自定义编辑器：攻略列表「我的阵容」主页签 → 任一「新建阵容」进入。顶部「角色/装备」两页签 + 左侧角色面板按费数分组（5 费/4 费/3 费…）+ 右侧三阶段板（前期/中期/最终）各分前台/后台区域（带 n/13 计数）+ 底部装备优先度链与运营思路/清空/保存按钮；拖拽式编辑。与过渡阵容三段式建模直接对应（最小档建档，深探未做）。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-标题-阵容编辑 | 画面标题（身份锚，与阶段页签「前期」「中期」「最终」组合判） | 纯显示 |
| 标识-阶段-前期 | 阶段页签「前期」（身份锚之一） | 点击切前期阶段板 |
| 标识-阶段-中期 | 阶段页签「中期」（身份锚之一） | 点击切中期阶段板 |
| 标识-阶段-最终 | 阶段页签「最终」（身份锚之一） | 点击切最终阶段板 |
| 按钮-tab-角色 | 顶部「角色」页签：左侧角色面板按费数分组（5 费/4 费/3 费…） | 点击切角色编辑 |
| 按钮-tab-装备 | 顶部「装备」页签 | 点击切装备编辑 |
| 区域-阵容名 | 顶部阵容名（默认「自定义阵容N」，旁带铅笔编辑图标；改名交互未实测） | 纯显示 |
| （待建档）前台/后台槽位区 | 阶段板内前台/后台区域（各带 n/13 计数），提示「可拖拽角色或装备至对应位置」 | 拖拽落子（编辑主体，未深探） |
| （待建档）底部功能区 | 「简易装备优先度/进阶装备优先度」链 +「运营思路/清空/保存阵容」按钮 | 未深探 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 进入本画面 | MCP `click_game` | 攻略列表「我的阵容」主页签 → 任一「按钮-新建阵容-N」area 中心 | 进阵容编辑 | — |
| 切阶段板 | MCP `click_game` | 「标识-阶段-前期」/「-中期」/「-最终」area 中心 | 阶段板切换 | — |
| 切角色/装备面板 | MCP `click_game` | 「按钮-tab-角色」/「按钮-tab-装备」area 中心 | 左侧面板切换 | — |
| 编辑（拖角色/装备入槽） | MCP `drag` | 左侧面板角色卡 → 前台/后台槽位（坐标当帧看图定位） | 落子进对应位置、计数变化 | 编辑/保存/发布攻略码流程未深探；除识别锚与结构清单外交互未深探，按当帧现读 |
| 返回列表 | MCP 键盘 | ESC（实测，无保存确认） | 回我的阵容列表 | 退出无保存确认，未保存的编辑会丢，退出前先保存 |

编辑类画面——除识别锚与结构清单外交互未深探，动手前按当帧现读，别按本文档推行为。
