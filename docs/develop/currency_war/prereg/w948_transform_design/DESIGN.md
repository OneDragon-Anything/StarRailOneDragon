  - `propose_upgrades`(:775-826)枚举三类机会(C2 体系卡/C4 Comp 档/当前板加深),**枚举本身不含换线语义**;
  - 锁定帧下 off-lock 提案(目标体系 ∉ locked_faction_scope)在最优序中被 `off_lock_penalty` 降级(ADR-0360,:1312-1316)——减分非禁换,但方向锚仍是锁线;

## 1. 三候选方向评估与主方向选定

### 1.1 评估(辖域 / 既有机制冲突 / 实现代价 / 可验证性)

|---|---|---|---|
| **辖域** | 形态 A(锁后停滞)。补的正是缺位的第二种锁语义本体:锁后携带「与实证对照并允许改判」义务 | 形态 B(P2 入口空位)。只解决「没有评估对象」,不提供评估与改判通道——弱目标若无停滞评估配对,锁死后退化为另一种承诺语义 | 两形态的**下游兜底**。自身无触发面:无甲则「重估后无更优线」这一前置永不出现在 P2 |

### 1.2 主方向:**甲(停滞评估臂)**,乙为同件伴生入口、丙为甲的出口分支

**论证**:

1. **根源两问**:根在语义层——「锁」只实现了承诺语义,缺「当前最优假设」语义。假设语义 = **入场时的可推翻(乙)+ 持有期的可改判(甲)** 两半。其中**可改判是本体**:没有甲,乙派生的弱目标只是一个没有评估义务的占位,语义上仍是承诺;有了甲,乙的弱目标才真正成为「初始假设」。故甲是语义缺位的治本落点,乙是甲在入场侧的同语义投影,丙是甲无替代线时的出口分支——三者不是并列候选,是一个机制的三个面。
2. **触发面唯一性**:甲是唯一自带触发面的方向(停滞计数器);乙的触发(进 P2)和丙的触发(重估失败)都依赖上游。以甲为主干,三面共用一条数据流、一个开关族,避免三开关互锁的校准地狱。
3. **ADR-0429 的 0 触发教训直接背书**:门有消费点无触发面的根因是上游撤销出口零触发——任何只动下游(丙单独立、或只调 C4 门)的方案都会复现「门空转」。甲在下游门的**上游**制造触发面,这正是 ADR-0429 增补「若要 v2 具备换线纠错能力,归撤销出口灵敏度独立演进」所指的演进,本件即其设计。
4. **代价/收益**:甲的中等代价换来的是唯一能同时解释并消解两局病灶的核心机制;乙、丙搭甲的车,边际代价趋零。

## 2. 正式设计:停滞评估臂(W948 转型臂)

### 2.1 机制定义

**一句话**:锁定态下,当「线进展」连续 N 个评估窗无收敛且战力侧持续失血时,把该线降为弱意向(携带停滞证据),复用既有撤销下游(异线信号 + C4 门 + 回锁闩)完成重估;无替代线时转入 salvage 续命态(丙)。

- **辖域声明**:仅 P2(位面 2)锁定态;P1 过渡对有自有滞回重派生(w919 观测面所辖),P3 有强制锁线/降格既有通道,均不入本臂辖域。
- **停滞判据(过程量选型,回应审视件「需裁」)**:
  - 进展量 = **锁线采购集缺口收敛度**:每评估窗比较 `gap_t` 与 `gap_{t-W}`(`gap` = 锁线 hoard 采购集中尚未 owned 的目标件数,存量单一源 = `hoard_target_set` 输出;不选 form_score 作判据——它是 ADR-0353 裁定的纯遥测口径,重新升格为判据 = 推翻既有裁决,且其 0.65 恒值恰证明它对停滞不敏感;不选失血率——strategy-work §4:hp 侧是末端量,只作验收报警,不作改进方向触发)。
  - 伴随条件 = `form_ok 恒 False 贯穿评估窗`(当帧谓词,当帧读,不做计数)∧ 评估窗内 `hp` 净下降(战力侧确证,防「金筹措期」误判)。
  - 停滞 = 连续 `STAGNATE_WINDOWS` 个评估窗(W 轮/窗,registry 常量,sim 校准,初值挂 §2.5)全部满足上两条。
- **触发动作**(单回合一次转移,与状态机既有约束一致):`phase: locked → weak`、`weak_comp = 原线`、`revoke_evidence = {'kind': 'stagnate', 'windows': N, 'gap_from': g0, 'gap_to': g1, 'hp_from': h0, 'hp_to': h1}`、`prev_lock_layer` 暂存——**完全复用出口①的降级形态与字段契约**,使遥测/下游零新增面。
- **与门闩对账**(核对②新事实):停滞转移不走 `_switch_gate_open` 的门拦截路径(那是 weak→异线锁的事),不受闩抑制;但停滞降级后当轮 `revoked` 置位同款语义(撤后当轮不重锁),且**本位面内同线只触发一次**(冷却驻留,见下)。
- **防振荡(与 ADR-0319 排除项划界)**:
  - 单向降级:停滞臂只做 locked→weak,不做反向「升级回锁」;原线回锁仅可经既有回锁信号通道(layer 恢复语义不变)。
  - 冷却驻留:同线触发一次后,`evicted` 之外的 `stagnate_cool` 记录(线名 → 位面号),本位面内该线不再重触发——每线每位面至多一次改判,事件频率上界 = 线数,结构性排除逐帧摇摆;P16 已证的 θ 滞回 + D_min 单调性论证同构背书。
  - 与 ADR-0319 排除的「分数涌现换线」的本质区别:排除的是**按逐帧分数差**摇摆(高频、双向、无证据门槛);本臂是**按低频窗级进展证据**单向降级(每线每位面 ≤1 次、带 gap/hp 双证据、下游仍需过 C4 门与信号门槛才落新线)。不同构,排除令不覆盖。
- **出口分支·丙(salvage 续命态)**:停滞降级后,若到本位面剩余节点 ≤ `SALVAGE_DEADLINE`(或弱态持续超 `SALVAGE_WINDOW` 轮)仍无新线落锁,`hoard_target_set` 对该 weak 态返回 `mode='salvage'` 采购集:**通用骨架 + 当帧战力散件,停止购入原线终局件**(「停止给死线供血」)。salvage 是 weak 的子模式,**非 absorbing**——新信号仍可照常落新线救回;P3 入口 demoted_endgame(absorbing)语义零改动,其判定条件(`plane>=3 ∧ 非 locked`)不被本臂触碰。
- **伴生入口·乙(P2 弱目标接管)**:进 P2 清 p1_pair 的同一处(`update_intention:1220-1223`),若清场后 `phase in ('unlocked','weak')` 且无即时信号,按带入资产(transition 组合存活度 + 终局件持有度,数据地基 = stage_transitions Q3/Q4)派生一个**弱占位目标**写入 `session` 观测字段(占位线名的 hoard 方向),使方向门不空转。弱占位 = 可被任何 ≥③ 层信号推翻的初始假设;停滞臂对它同样辖(它锁不住——它根本不进 locked 态,只写 hoard 方向,这是它天然无承诺语义的原因,也是把它作为乙的落点而非 locked 的原因)。

### 2.2 数据流

```
每轮 update_intention(P2, phase=locked):
  gap_t ← hoard_target_set(锁定线) 未满足件数   [执行期现读]
  窗口边界轮: 对照 gap_{t-W}, hp_{t-W}(session 暂存)
  连续 STAGNATE_WINDOWS 窗 无收敛 ∧ form_ok 恒 False ∧ hp 净降
    → 降级 weak + revoke_evidence(kind=stagnate) + stagnate_cool[线]=plane
  ↓ (下游全复用,零新增)
weak 态: 新信号(异线) → _switch_gate_open(C4, 关=放行) → _lock 落新线
       → (锁后若再停滞 → 同机制再来一次, 每线每位面一次)
无新线 + 超 salvage 阈 → hoard mode='salvage'(停止线内投入, 金流改道危机臂/存活投影)
P2→P3: 位面切换清 stagnate_cool 与计数(P3 有强制锁线/降格既有通道)
```

### 2.3 边界(明确不做清单)

1. **不做分数涌现换线**(ADR-0319 排除维持)——本臂判据是窗级进展证据,不是分数差;
2. **不提高撤销出口①灵敏度**(ADR-0436 已证其噪声机制,方向反向);
3. **不动门闩语义**(w665 设计件):停滞臂不新增闩置位点、不受闩辖的路径显式声明(§2.1);
4. **不动 demoted_endgame absorbing 语义与 P3 入口判定**——salvage 是 weak 子模式,不是新吸收态;
5. **不动演进保护组**(ADR-0360/0363/0371/0382)——salvage 只改买侧采购集,不授权拆在场件;1★ 填充件的处置仍归卖侧既有守卫;
6. **不授权任何支出数值**——金流「改道危机臂」指危机臂(P36 草案)按其自身判据正常开火,salvage 不改其预算;
7. **不扩 P1**——P1 过渡对自有滞回重派生与 w919 观测面,辖域不重叠。

| 形态 | 验证手段 | 锁什么 |
|---|---|---|
| 停滞计数与降级转移、冷却驻留、salvage 采购集转向、门闩不受扰、缺省关零漂移 | **sim 可锁(单帧锁)**:构造 GameState + StrategySession,直接调 `update_intention` / `hoard_target_set`,断言状态转移与动作序列(断言语义不锁巧合:如「停滞降级后 weak_comp=原线且 evidence.kind='stagnate'」) | 行为意图 |
| N/W 阈值下的整局演化、形态 A/B 占比、A/B 分布改善 | **构造账本锁 + sim 批**:账本注入「连续 W×N 轮缺口不降」的合成局断言触发一次且仅一次;sim n≥300 臂间分布对照(§2.4 验收线) | 分布与频率 |
| gap/hp 观测在实机 OCR 观测噪声下的判据稳健性、实机重估改善是否兑现 | **只能实机**:N/W 终值校准(实机 gap 读数受 OCR/观测口径影响,sim 读数是模拟真值,不可互换)、连续多局达标验收(按当期目标行判据) | 参数终值与真实收益 |

诚实声明:`STAGNATE_WINDOWS`/`W`/`SALVAGE_DEADLINE` 全部是 sim 校准常量(同 ADR-0319 对 CORE_MISS_N 的「设计推断常量,不写死语义」惯例),本件不授权数值。

### 2.6 与 W945 P36(危机火力阶梯)的辖域划界

同属 P2 深危机域,分工一句话:**P36 管火力(花多少、往哪花是买侧授权),本件管转型(方向假设何时改判、方向侧采购集指向哪)**。

| 交叠点 | 裁定 |
|---|---|
| 危机帧金流 | salvage 态「金流改道危机臂」= 危机臂(P36 的 B(d)/`B>0⟹n≥1` 通道不变式)按其自身判据开火;本件只负责让方向门不再抽走预算(停止线内目标件采购),**不写任何支出数值** |
| 存活投影 | `P(survive\|d)` / rounds_alive 是共享只读组件:本件的重估/salvage 判定消费它;P36 的火力阶梯标定消费它。双方都只读,投影单一源不变 |
| 命名归属 | 失血/死亡域的支出响应(危机臂哑火、预算帽)= P36(its 辖域,W945 第一件);线持有但停滞/无线空转的方向响应 = 本件。P36 不授权方向切换,本件不授权危机支出 |
| 合批 | 两件行为面不相交(卖侧/方向侧 vs 买侧/支出侧),不合批;实施顺序无依赖,可并行落开关 |
