按终局类分层(w4_stats.txt Q1 表,n≥10 格)呈现清晰三档:

1. **真贯穿层**(所有线都留):千冶•刃 / 三月七 / 花火 / 星期日——
   E→F 0.66-0.95,与 M3「早期核心」一致。
2. **线内终局件层**(本线留、别线清):爻光(欢愉 0.98/姬子 0.23)、
   饮月(姬子 0.53/DOT 0.25)、椒丘(黄泉 0.78/DOT 0.69/其余 0)、
   卡芙卡(DOT 0.92)、藿藿(圣杯 0.79/姬子 0.32)——「换不换」取决于
   该角色是否是本线的终局组件,不是角色属性。
3. **纯过渡消耗层**(全线清场):**艾丝妲**(E→F 0.05,十个类中八个为 0,
   仅希儿线 0.23)——DOT 挂件层的典型下场,印证 transition_combos
   「DOT2 层随意(谁在场买谁)」的可替换性。

**加法不换件的真实边界**:每帖 Early 板面在 Final 的留存率均值
0.53-0.76(中位 0.60-0.80,w4_stats.txt)——**大约六成 Early 板面活到
终局**;「不换件」严格成立的只有贯穿层+本线终局件;DOT 填充件(艾丝妲
为代表)与仙舟三人组的大部分(爻光/藿藿)在非本线是**被换掉的垫层**。
这与 [20]「配方有结构、渐进升级」不冲突:加法发生在**核心链**上
(饮月→列车4 / 三月七→领航员 / 千冶•刃全程),填充层按 [31] 垫层语义
回收。

**裁决:「全卖过渡吃息」不是主流**——全换血帖占比中位约 10%,主流
行为 = 保留 60-70% 板面 + 换入本线 Middle 件。分布两端:
- **希儿量子线全换血率最高(29%)且分布双峰**(0 档 29% + ≥0.8 档 57%,
  中间档几乎空):与希儿系「信号驱动直通」同构——希儿在板则全留
  (量子放大器即终局件),不在板则 Early 过渡整板清掉重开;
- **姬子/欢愉/黄泉线全换血 4-7%**:加法不换件在这些线最强
  (列车4 本身消费三月七/饮月;欢愉铁三角消费爻光);
- 圣杯/白埃保留率均值最低段(<0.4 档占 21%/26%):圣杯的三件留牌
  「留牌不上场」与本口径(板面)正交,白厄的 Final 反甲板大量换装。

注意口径:Jaccard 天然低于保留率(分母含 M 新增件,|E|均值 4.7→|M| 6.7
本就是人口扩张),**保留率才是「卖没卖过渡」的正确读数**。

  且 1 星为主——「买到就上/囤」,转型从 P1 就开始,**资源解锁型**;

  购买力」的合取**,且核心到手的影响更大(姬子 3 费但 Early 在板率
  0.42,非纯等级问题)。

## 结论一览(策略层消费点)

1. 加法不换件成立域 = 贯穿层(千冶•刃/三月七/花火/星期日)+本线终局件;
   DOT 填充件(艾丝妲)是全线消耗品,P2 卖掉是数据常态不是失误。
2. 换血主发生在 Early→Middle(保留率 0.59-0.74),Middle→Final 只微调
   (留存 ≥0.8)——**P1 末的板面结构决定 P2 成本,转型预算应压在 P2 前**。
3. P2 没有统一桥:按本线终局羁绊的低档形态走(列车线除外——列车4 即
   其 P2 形态)。搜牌/人口决策在 P2 应指向本线核心件而非通用件。
4. 转型触发 = 核心到手(信号)× 等级购买力(资源)合取;核心 Early
   在板使全板保留率翻倍——「见核心即锁线、围绕它买」有数据支撑。
5. Middle 成型判据(停手线):本线核心羁绊 2 档 + carry 2 星在场 +
   通用辅助骨架就位;此形态下 Middle 板 ~85% 会原样长成 Final。

## 疑点与数据边界(leader 裁决用)

1. **bench 不可见**:消失≠卖(可能买而不上),[21] 的直接验证缺数据;
   本文所有「换血/留存」都是**板面**口径。
2. **Early 空板 179 帖**(22%):E 统计实际样本 636;希儿/DOT/白厄类
   小 n(14-33)结论稳定性弱。
3. **与旧口径出入**:plaza_methodology M3「Middle→Final ≥0.9」在本文
   均值口径下为 0.75-0.93(中位 ≥0.86);M5 上场规模 5→7→9/10 复现
   (E 众数 5 / M 众数 7 / F 众数 9)。
4. star=星级、无等级字段——「资源解锁」只能用费级代理;人口/等级驱动
   假设的严格检验需等遥测(实机局带等级序列)。
5. 「护盾3 桥」无法检验(护盾非阵营羁绊,板面数据不含 flow 聚合)。
