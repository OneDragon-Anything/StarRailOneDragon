# 知更鸟•晴歌（风·记忆·5星）

> 按 V4.7 期（2026-11）官方文本撰写。气氛值驱动的忆灵乐队辅助：智能增益（攻击/暴伤自适应）+ 拉条回能 + 无视防御结界。
> 与知更鸟（物理·同谐）是并存独立形态。

## 定位

记忆命途辅助（增益/拉条/结界）。适配忆灵体系与多攻击频率队伍。

## 伤害模型

- 倍率基于**生命上限**（普攻50%/忆灵技150%乐手生命）——本体输出占比低【官】。
- 大招资源：标准能量（乐手被召唤+20能量、A2 律动回能、E6 Fever 回140能量）→ 充能有效。

## 机制要点

- **气氛值**：我方施放攻击 / 任意回合首次治疗或护盾 → +1（上限50）；≥6/12 依次召唤乐手啾米/派丁；**全员登台 → 【Fever】状态**：知更鸟不进入自己回合，自身与乐手伤害+60%+气氛值×2%，敌方全体受伤+8%/12%/16%（按乐手数），结界内无视防御 15%+气氛值×0.5%【官】。
- 战技：召唤/满血治疗贝茜 +6气氛值。
- 终结技：指定单体**行动提前100% + 回20%能量** + 【特邀嘉宾】（其攻击时知更鸟+2气氛值；无法被其他拉条）——强制指定主C吃拉条【官】。
- 乐手：生命=知更鸟70%生命上限，**速度=知更鸟180%速度**；Fever 倒计时（140速）每回合扣气氛值，归零退场。

## 转模行迹与转化上限

- **D2「偏离和弦」：队友获得气氛值时，攻击力高于知更鸟者 → 攻击力+知更鸟生命上限的(16%+气氛值×0.4%)；否则暴伤+40%+气氛值×1.5%**【官】→ **生命上限是增益面板**（智能分流：攻击系吃攻击、其他吃暴伤）。
- B4「重构谐乐」：自身与乐手暴击率固定+50%。
- A2「即兴蓝调」：受治疗/护盾获12层【律动】，每层回3能量。

## 有效词条口径

- 主词条：躯干生命%/暴伤；脚部**速度**；球生命%；绳充能。
- 副词条：**速度 > 生命% > 充能**。
- 速度三重收益：乐手速度180%折算 + Fever 期间忆灵技频率 + 自身行动。

## 绑定与互斥

- 泛用增益辅助：忆灵体系（气氛值来源多）与高频攻击队收益最大。
- 【特邀嘉宾】与其他拉条辅助互斥（被指定者无法再被拉条）。

## 星魂档位

- E1：乐手记录全队非真伤，忆灵技释放时按记录额+气氛值结算真伤。
- E2：全队全抗穿+18%；气氛上限70。
- E4：进 Fever +12气氛值，乐手提速。
- E6：忆灵技倍率×2；Fever 期间终结技可储存2次。
