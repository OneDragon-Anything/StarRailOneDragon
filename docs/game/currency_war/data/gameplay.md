## 玩法说明(原文)

- 每局「货币战争」中,开拓者需要在 **3 个位面**,分别面对不同的敌人与首领。随着对局进程逐步**获取资源**、**组建团队**、**提升实力**,最终**击败首领**,取得胜利。
- 开拓者拥有**初始小队生命值**。在多个节点的战斗中,需要在**有限行动值**内消灭全部敌人获得战斗胜利。若未在规定行动值前消灭所有敌人,则扣除一定生命值。当生命值为 0 时,将结束对局。
- 首个赛季「零和博弈」将进行**多次扩充**,每次扩充更新时可能会有新角色加入、部分角色更替、羁绊构成及效果调整等。在**未来赛季**,还将计划重新划分角色定位(前后台、羁绊、赋能、费用)及调整投资策略,让每个赛季呈现独特玩法风貌。

## 全新角色玩法能力(原文)

- 加入「货币战争」的角色将获得「站位」「角色赋能」「羁绊」「星级」等全新玩法专属能力。
- **站位**:角色分为「前台」「后台」,部分角色是「前后台」。战斗开始前,角色被放置在**正确位置**时,会激活该角色的专属能力「角色赋能」,带来不同的战斗体验。
- **角色赋能**:使角色本体技能得到**强化**,或获得**全新**的战斗技能。
- **羁绊**:角色均有其所属的「羁绊」。上阵一定数量的相同羁绊角色后可**激活对应羁绊效果**。羁绊成员越多,羁绊等级提升,效果越强。
- **星级**:角色初始 1 星。招募 3 个相同星级的角色将**自动升星**,大幅提升战斗能力。**3 星通常是角色的最强形态**。

## 角色招募规则(原文)

- 若开拓者已拥有「货币战争」内的对应角色,则继承该角色的全部养成数据。
- 若未拥有,将提供该角色的试用版本。
- 若拥有的角色(等级、行迹、遗器、星魂)及光锥等级未达成养成标准时,将被系统自动强化为映射版本,仅在「货币战争」中生效。
- 「后台」角色的星魂与专属光锥,在「货币战争」中将得到一定程度的调整与强化。

## 金币,等级与商店(原文)

- **金币**是核心经济资源,可用于招募角色、升级团队规模、刷新商店。
- 每场战斗结束时获得一定**基础金币奖励**;按拥有的金币数量获得**金币利息**;连续获胜还能获得**额外金币奖励**。
- 金币可用于招募不同「费用」的角色,分别为 **1费、2费、3费、4费、5费**。角色费用越高战斗能力越强,相同费用间战斗能力近似。随等级提升,商店逐步提升高费用角色的刷新概率。
- 可使用金币**购买经验提升等级**,以提升团队规模。**等级对应可上阵角色数量**。
- 每个节点会自动刷新 1 次商店,可消耗金币刷新商店。也可以**锁定商店**,此时商店不会自动刷新。

## 装备(原文)

- 穿戴装备可为角色**提供各项属性**以及**特殊战斗效果**。
- 装备主要通过**奖励节点、补给节点**获取。
- 装备分为「简易装备」与「进阶装备」。**2 件简易装备可合成为 1 件进阶装备**。进阶装备将获得简易装备的全部数值属性,以及独特战斗效果。
- 已穿戴在角色身上的装备,可以使用「**拆装扳手**」进行拆取。

## 投资环境与投资策略(原文)

- 在对局中,开拓者可在固定节点选择「投资环境」与「投资策略」。
- 「投资环境」与「投资策略」均可为**整局**提供一定增益效果。

## 攻略(原文)

- 在对局中打开「攻略」,将根据当前场上及备战席中的角色推荐攻略。
- 应用攻略后,将在商店及备战席中高亮提示推荐使用的角色。对应的推荐装备也将在对局内提示。

## 优势布局(原文)

- 激活「优势布局」,可为后续对局提供**额外机制**,或增幅角色的战斗能力。
- 每场对局结束后,将获得一定的「**等价钻钞**」,用于激活「优势布局」中的各项机制。

## 标准博弈(原文)

- 「标准博弈」中,玩家可根据当前**最高职级**,挑战对应的职级难度。职级提高时难度大幅提升。
- 胜利结算后,依据剩余小队生命值获得对局评价,**提升职级**并解锁新难度。难度提升时敌人难度增加,并获得敌人词缀。
- 胜利结算可获得「货币战争」积分以及晋升点。难度越高通关时晋升点越多。
- 晋升至对应职级时,可获得星琼与晋升点。**对局失败时不会降低当前职级**。

## 超频博弈(原文)

- 「超频博弈」是所需**游玩时间更短**的快速模式,可用于完成「货币战争」积分奖励。
- 可选择难度依据「标准博弈」达到的最高职级。
- 胜利结算获得积分、晋升点、等价钻钞。相同难度下,晋升点和等价钻钞获取略少于「标准博弈」。

## 奖励说明(原文)

- 结算时根据挑战进度获得「货币战争」积分,并获得积分奖励。奖励每**双周周一 04:00**(服务器时间)重置。
- 完成对局获得晋升点提升晋升等级,可获得晋升等级奖励。
- 以**不同羁绊阵容**通关对局,可获得羁绊链路挑战奖励。
- 首次晋升对应职级,可获得职级奖励。
- 收集投资环境、投资策略图鉴,可获得收集奖励。
- 每双周首次通关「标准博弈」或「超频博弈」,可获得额外晋升点奖励。
- 通过完成「创业指南」与「预期收益」中指定的目标,可获得对应奖励。

## 机制框架速查(基于原文 + 实机交叉)

| 项 | 内容 |
|---|---|
| 对局结构 | 3 位面 × 6 关(第 6 关=首领巨星),共 18 关 |
| 对局类型 | 标准博弈 / 超频博弈 |
| 战斗 | 自动进行(auto-battler),玩家只做经济/羁绊/站位决策 |
| 生命值 | 小队共享,初始~80;未在行动值内取胜扣血,归零出局 |
| 角色费用 | 1~5 费;5 费卡池每种有限 |
| 星级合成 | 3×1星→2星;3×2星→3星(通常最强) |
| 上阵规模 | 等级=可上阵数;至多 10 人(4 前台 + 6 后台) |
| 站位 | 前台/后台/前后台;放对激活「角色赋能」,放错仍触发羁绊但无角色加成 |
| 经济 | 基础金币 + 利息(每 10 金→下回合 +1 金,上限 5/50 金)+ 连胜奖励 |
| 商店 | 每节点自动刷新 1 次;可花金刷新;可锁定 |
| 装备 | 简易 + 简易 → 进阶;每角色最多 3 件;拆装扳手拆取 |
| 投资环境 | 固定节点整局增益 |
| 投资策略 | 局内 3 选 1(可刷新) |
| 优势布局 | 用等价钻钞激活,跨局增益 |
| 难度段位 | 黑铁→…→财富造物主;失败不降级 |
| 周期 | 积分每双周周一 04:00 重置;run 不耗开拓力 |
