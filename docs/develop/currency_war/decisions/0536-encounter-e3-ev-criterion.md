# ADR-0536: 遭遇核 E3 判据替换——EV(b)=V_r−Δλ_death·G_loss(mandate_v1.decide_encounter 覆写,基线核零触碰)

## 背景

遭遇节点二选一(08 号稿事件面 E3「遭遇分支难度/奖励(可刷 1 次)」)的判据自 E3 立项起「待 derive」:基线 `cw_events.decide_encounter` 按 comp 成型度评分选支(未成型→低难保生存/成型 dare→高难/全克词缀→刷新),奖励价值恒中性、无 λ 生存代价维——08 号稿 E3 锚申报的判据形态「奖励增量 vs λ_death 敞口增量」(P26 硬节点备战 EV 门同构)未落码。

本判据形态经不入库设计稿(含两轮无前提对抗,R2 零阻断收口)定形后落码;**设计稿原件存于工作区临时目录、不入 git,其接死语义全部收编入本 ADR**——本文即判据语义的持久单一源。

## 决策

### §1 落码位与分发关系

- 判据本体 = `strategies/impl/mandate_v1/encounter.py.decide_encounter_ev`(纯函数);消费位 = `bridge.py.MandateV1Strategy.decide_encounter` 覆写(零逻辑,仅委托)。
- 基线 `cw_events.decide_encounter` 与 `flow.py` 委托链**零触碰**:其他策略核与 sim 基线行为不变;handler(`cw_screen_encounter.py`)经策略多态分发自然切换,`refresh_used` 位置参数序与基类 LSP 兼容。
- mandate_v1 自身 sim/实机行为变化 = 判据接线预期申报(非回归)。

### §2 判据形态(四件必改的接死语义)

对实际读到的每分支 b(按实例对评估,子型与难度档独立组合——金子型在高难支实录在案):

**EV(b) = V_r(r_b) − Δλ_death(b)·G_loss**(P26/E3 锚同构;λ 项按 P51 折现口径入负项,W_floor = λ×(存量金 g+未来纯金流),消费形态 = 区间敞口比较,P51 §5-11)。

- ① **奖励子型分立**:4费×3 ⇒ 清算下界 3×sell_refund(1★,4)=12(P41 全类成立,持有增值 fail-closed 不计);金币×2 ⇒ 金额经槽位(§3);5费/投影仪/读空 ⇒ 未立(**未立 ≠ 0**,禁置零续比)。
- ② **数值 fail-closed + fail 向**:fail 向 = 选低难度支(并列取先读支),保守少掉血;与现行「未成型→低难保生存」零冲突(未成型帧动作序列 diff 空),formed 态 dare→高难被 fail 向覆盖 = 接线预期差——**验收门 = 动作序列级**(选卡 idx 序列),拒因串从难度评分格式改 EV 格式为预期遥测差。
- ③ **λ label 四态接死**:「不可判」≡ 任一分支 λ 键为 None/域外/损坏态,或格 label ≠ 可消费(仅方向/禁用/空格)⇒ 放弃 argmax、整体 fail 向选低难;「负项置零继续比较」是禁止实现(与现态申报行为相反,落码第一行即踩的分叉)。仅方向格只作方向注记分键,不作数值。
- ④ **刷新肢非免费期权**:生产执行链语义 = 刷新生效后原对弃用、强制从重掷对中选,重掷分布未建模、期望可为负。故刷新建议仅在「双支 λ 可消费 ∧ EV 比较不稳健(保守端 d̂=CI 宽度与乐观端 d̂=0 胜者不一致 = EV 差落入不可判带)」时作为探索性建议;**EV 精确并列**(双支 V_r 与复合项全等,典型 = 标定后同难度双卡帧)走并列出口 fail 向(决策树第 5 肢),不构成胜者翻转、不给刷新(三审定谳:并列曾误入翻转支);λ 整体不可判帧不刷新(fail 向已知安全选项,不赌重掷);refresh_used=True 不再建议。刷新消费仍走既有分支刷新执行链,零新执行面。
- 数值算子唯一 = `lambda_death.differential_composite`(第三口,d̂=同格 CI 宽度,两支公共 λ_L 在差分中抵消;敞口 = g+Ī×R_剩余);判据零端点自持(R19-3)。零 hp 直读自变量(hp 只入 λ 路由键);不建胜率阶梯、不评单位强弱、不新增排序键。

### §3 数值开闸链:双槽互锁

数值 argmax 臂要求 **两个 provisional 槽都在场**(任一 None ⇒ fail 向,单槽注入 = 半标定不开闸):

| 槽 | 载体 | None 期语义 | 开闸判据 |
|---|---|---|---|
| `ENCOUNTER_DSTAT_MAP` | dict[旗牌→敌难度 stat 真值] | λ 键观测量缺失 = 域外同判(禁拿旗牌 1-6 冒充 stat 假真值,R29-6 同款) | 遭遇分支敌难度条件表实采(随 P26 采集批并账) |
| `ENCOUNTER_G_GOLD` | 金币×2 金额标定值 | 金币支 V_r 未立 → fail 向(未立 ≠ 0) | ≥3 局观察值定带(先判读历史 event_choice 帧 ["10"] 读数 OCR 存疑,再开新采集) |

动机:防「标定批只注 λ 侧映射即半标定全开闸、单例金额 8 直接进承重比较位」的越线形态——观察值是单例非机制定义,定带前不得产出「高难更优」类结论。代码常量 8 已随槽位化退役(落地审建议-1 治本采纳,方案=槽位化而非文档互锁,理由:开闸判据进类型系统,比注入前置清单文档约束强)。

### §4 现态行为申报与验收口径

- **现态生产 = 双槽 None 期恒 fail 向选低难、零刷新建议**(刷新建议结构性不可触发:其前置 = 双支 λ 可消费 + 胜者翻转,现态不成立)。真表 encounter 12 格仅 3 格可消费(D0|hp>40|P1、D1|hp>40|P1、D0|hp≤15|P2+),标定注入后 flip 带亦为窄域——刷新建议作**条件触发观察位**,验收勿按「应见到刷新建议」判接线。
- 分键 10+1:`encounter_ev_fail_low`(总出口)/`encounter_ev_fail_low_tie`(EV 精确并列出口)/`encounter_ev_pick`/`encounter_ev_fail_low_lambda_undecidable`/`encounter_ev_fail_low_reward_unmodeled`/`encounter_ev_undecidable_band_flip`/`encounter_ev_refresh_suggested`/`encounter_ev_reward_gold`/`encounter_ev_reward_4fee`/`encounter_ev_lambda_direction_note`;拒因串 `e3_*` 经既有 `record_event_choice`(event_choice)透传。

### §5 辖域与未建模面

- boss 战前 P26 补强维持既有「不接线」裁决,零落码位;08 号稿 E3 行入册归 08 号件批 owner,不在本 ADR 义务内。
- 未建模:重掷分布(可为负,故刷新仅探索性建议);5 费子型(独立下界形态 3×sell_refund(1,5)=15,标定轮首扩展对象);3×4费 grant 的 bench 满伴随行为;发放均匀性(仅未来持有上行侧参数化用,现态 fail-closed)。

## Considered Options

1. **维持基线成型度评分**(现状):无 λ 生存代价维,与 E3 锚「待 derive」挂账状态一致——被否:遭遇战败是 HP 损耗主通道之一,λ 敞口差是决策的真实代价维,定性申报会把主导代价项永久留在式外。
2. **λ 不可判时负项置零续比**:实现最短——被否:与「标定前不产出高难更优结论」申报相反(12>8 ⇒ 恒选高难),且把「无数据」伪装成「无代价」。
3. **G_gold 文档面互锁**(注入前置清单申报,数值仍走常量):工程量最小——被否:开闸约束靠文档纪律,槽位化把约束进类型系统(None 期结构性不可达数值臂),防半标定的强度更高且增量成本小。
4. **双槽互锁槽位化(本文)**:采纳。

## 后果与退役条件

- 正面:遭遇决策补上 λ 生存代价维;fail 向现态与既有低难保生存语义动作序列零冲突;开闸链显式化,标定批任务书可直接对准双槽。
- 代价/风险:formed dare 帧行为变化(恒 fail 向覆盖 dare 通道)= 显式战术权衡(标定前不产出高难更优结论),λ 表标定后由数值臂接管;拒因串格式变更需判读侧知悉。
- 退役/强制重核条件:①遭遇池奖励构成改版(子型表失效);②λ PL 键结构或难度带界改版;③G_gold 定带推翻观察值带。任一命中强制重核本判据;λ 表重标定致真实表锁红 = 表态变化信号,先判表再判码。

## 辖域补声明(整改批,与 ADR-0554 同批三审整改):并列判定只辖「全等型」

- 本判据的并列(`encounter_ev_tied`)辖域 = **全等型**:双支 `V_r` 精确相等 ∧ 复合项相等(实现 = encounter.py `_ev_tied`,≤ 双向)。**数值互补型不辖**——`V_a−V_b = −(d̂_a−d̂_b)·X`(V 差恰被 λ 敞口差抵消、复合项+奖励项各自不等但 EV 相等)的分支对,按「非并列」进 `_ev_beats` 严格比较通道(≤ 双向不成立 → 不判并列),比较结果由浮点加法次序定,零预期翻转语义。
- 依据:互补型要求两独立有理量(V 差与敞口差)精确互抵,在注册表有理值域内为 measure-zero 事件;且此时两支 EV 在模型内本就无差异,进翻转通道或并列通道的处置差异(记不记翻转)无决策后果——fail 向低难两通道可达同一支。显式化声明以免「并列判据漏互补型」被误读为缺陷;若未来标定出真互补形态(离散格点下 V 差=敞口差非零倍数),须回本 ADR 重开辖域。
