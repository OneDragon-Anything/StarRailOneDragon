# 货币战争-攻略详情（单篇攻略内容页）

**识别**：`is_precise` 命中 `货币战争-攻略详情`（锚：标题「攻略详情」+「阵容详情」+「运营思路」三文本组合）。
**目标**：单篇攻略完整内容——阵容详情（前台/后台 + 羁绊分级数字）+ 运营思路长文，目标阵容的结构化来源。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：攻略列表点任意卡片卡身。
2. **读数**：左侧羁绊分级列表 + 前台/后台区域角色卡；底部「运营思路」3-4 行过渡节奏/装备优先级叙述。
3. **两个动作**：「复制攻略码」→ 复制到系统剪贴板（toast「已复制」；可灌进「攻略码输入弹窗」分享给他人/自己）；「应用攻略」→ 应用该攻略（按钮变「取消应用」+ 顶部「已应用当前攻略」；应用成功自动弹装备追踪弹窗，应用后备战板面带板面标记）。
4. **出口**：右上 U 图标 / ESC 回攻略列表。

坑：羁绊分级数字 OCR 系统性碎裂（「3/5/7」易连读成一串）——解析按图例语义（在备战席/在场上/核心角色 = 板面标记）而非裸数字；「查看攻略详情」按钮点击无画面变化（未生效占位），别等它响应。
