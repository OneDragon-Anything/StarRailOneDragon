## 1. 选线函数(统一阵容评分)

机制形态:`f(局面状态) → 「未锁定(top3 候选已登记)」 | 「锁定线 X」`(一次性决策,锁后不换)。实现载体 = `strategies/impl/mandate_v1/line_select.py`(线分数/候选/锁定判定) + `session_scope.py`(状态重算与锁定写入)。**纯加权和一个公式**(2026-11-03 用户裁定:特殊处理全退役——排除位/角色硬锁/策略即时锁/defining 标记/counters_dot 排除;排除 = 极大减分,非布尔特判):防摇摆不靠滞后余量靠结构(锁后不换线 + 数量级支配)。

```
     + 敌情克制分(boss 分 = Σ三只克制,均权 + 非 boss 强敌分,§1.1 末条)
```

- **数量级表**(层间支配靠数量级实现;常数单一源 = `kernel/cw_line_scales.py`,本篇只写常量名):重开级 `RESTART_PENALTY`/万敌无燃料底线同档;carry·anchor `CARRY_ANCHOR`(线攻略引用核心,`LINE_ANCHOR` 表 21 线逐线登记,姬子 A/B 两套同引用)/carry·其余 core `CARRY_CORE`(攻略主次语义:非引用 core 减半)/骨架件 `SKELETON_BONUS`(4 骨架 = 1 anchor 相平)/插件 `PLUGIN_BONUS`/**装备件同插件档**(批 3:key_equips 逐件持有 `PLUGIN_BONUS`——同为「线构成件的持有实证」,装备证据只排序不点亮,证据门不含装备分量)/攻略热度每点 `HEAT_PER_POINT`(满热度 274 < 1 插件——持有实证 > 社区先验)/词缀强吃顶级 `AFFIX_STRONG_TOP`·燃料 `AFFIX_STRONG_FUEL`/投资定义卡 `INVEST_DEFINING`·强档 `INVEST_STRONG`·实证覆盖升档 `EVIDENCE_UPGRADE_BONUS`(量子星徽×3→希儿/罗刹→列车 A/B 两套)·中档 `INVEST_MID`/软档 `INVEST_SOFT`(flex 降档落点:强→+30/中→0)/怕 `FEAR_PENALTY`。

### 1.2 候选管理(未锁定期)

- 每帧对全部线算分,**top3 为候选**(候选数量 = `CANDIDATE_TOP_N`,用户立场值);候选快照 = 派生态(每帧随签名重算,非持久状态;锁定写入后清空停算)。**候选入选证据门**:线入选实候选 ⟺ 线分数的证据门分量为正(env〔投资通道〕∨ carry ∨ 骨架 ∨ 插件 > 0——`LineScore.gate_positive` 命名访问,**不含热度**;`compute_candidates` 证据门开启版,候选快照消费;其余调用方缺省全量版)——零证据线不入候选,攻略热度降为**有证据线之间的排序**,不再是入选理由;开局零持有零投资 = 空候选(合法形态,买入/环境/发放逐步点亮入选)。
- **候选双层结构(终局层 + 过渡层)**:终局候选(实候选)= 上述证据门版线候选;过渡候选 = P1 体系对候选机器(`cw_intention.p1_pair_candidates_of`:四体系组合空间按(对级支持度降序,对级声明序)取 top3,对级支持度 = min 席级支持度;希儿系对入候选门槛 = 席级 1.0;无羁绊开局合法空——语义与冻结收敛见 §3)。两层候选分别驱动终局义务面与过渡配方半边,载体 = `line_candidates` 快照与 `transition_candidates` 槽(§2);成员档双层装配 = [32_unified_sell_priority.md](32_unified_sell_priority.md) §2。
- 候选变动:进榜线开始囤件;掉榜线已囤件保留不再新增(1★ 可全额退,不亏);实候选退出 = 证据消失(卖出唯一副本)或被更高证据线挤出 top3。
- 采购纪律(义务面单一面):**义务面** = 实候选(证据门版)三线成员并集 ∪ 过渡候选各对成员并集(与统一价值序成员档族〔档 2/3/4/5/7〕名单同源——买面与优先级面同一份名单,免息待遇 + 获取受阻〔席满 ∨ 金不足〕统一走获取让位评估,原会话内筹资已并入该评估,[11_shop_decisions.md](11_shop_decisions.md) §4.0);非义务面成员商店见到不买(万金油角色只在恰为候选线/锁定线成员时按序 1 买入,手里持有的未到两星前受统一价值序档 8 保护、无自动补货通道;原「保护集囤货面」为期权级囤货——首副本走囤货臂、买因 `protection_hoard`——已随囤货臂退役拆除:囤的换线期权在锁定后不换线制下无兑现通道);+ 候选件没有而金有余时按费用档判据买牌压牌库(不限候选线;[31]②/[34] 既有纪律)。
- P1 板面恒过渡体系(战力资源约束,与方向正交);过渡体系选与榜首候选重叠的(转正不废件)。**P1 锁定局的采购通道**:锁定后序 1 名单 = 过渡候选成员并集 ∪ 锁定线名单**并集**(板面过渡 + 锁定线积累双目的;配方物化链在产,锁定不辖 P1 配方件——物化单对 = 候选首位 ⊆ 候选并集,买面不读物化键);P2 起切锁定线名单单源(退出条件 = `plane2_started` 窗口谓词,非位面字面量)。
- 升级触发口径:锁定后最优概率带单判据三分派([11_shop_decisions.md](11_shop_decisions.md) §2),未锁定期零主动升级(带驱动辖域外,候选缺件刷新承接——原「概率账缺件集并集口径」随概率账臂删除消亡,无聚合消费面);义务面身份判定源 = 候选快照(k_members 未锁定期为空,义务身份集 = 候选 top3 线内成员)。

### 1.3 锁定(P2 时点兜底唯一路径)

| 触发 | 判据 | 时点 |
|---|---|---|
| **时点兜底(唯一路径)** | 时点到 → 锁定 top3 中分数最高者(候选元组已按全序降序,取首);**空候选兜底**(证据门下可达,真规则):候选空 → 锁全 21 线全序首名(缺省全量版重算取首;零证据帧首名 = 热度首线,现行全序的退化情形) | 第二位面已启动 ∧ P2 起首次投资策略三选一完成帧 |

- **硬规则/即时锁全退役**(2026-11-03 用户裁定「全退役」:拿到什么都不直接锁,分数说话):角色型硬锁废(核心在手 = carry 证据分 `CARRY_ANCHOR`/`CARRY_CORE`,数值必然性替代);策略型即时锁废(强关联投资 = 通道派生加分进线分);知识卡 `lock_rules` 字段随之整字段退役(值并入通道派生/证据分,git 历史可溯)。候选构造 = 证据门 + 线分排序,**无排除过滤**——重开级已数值化(含重开级命中的线分恒低于无命中线)。
- 时点兜底触发分支:`plane2_started`(窗口谓词,首入 (2,*) 段置位——P1 内即时/延迟加场卡被结算节点边界引用排除)∧ `p2_strategy_pick_done`(P1 滑动基线 + P2 集合增长侦测;增长来源不区分选卡/节点赠得——对「策略已定 → 可兜底」语义等价;bot 视角完成帧 = 获得后的首个决策帧)。
- **锁定效果**:买牌、升级窗口、装备定向、上场窗口全部围绕锁定线;装备合成材料开始定向留存。锁定写入与连带动作的唯一所有者 = `session_scope.write_line_lock`(§2),禁绕过直写键跳过连带。
- **投资选卡端消费本判定面**:投资环境/策略两屏的阵容冲突护栏,未锁定帧 = 候选与已持有投资(环境+策略)的阵容指向集比对,锁定帧 = 与锁定线 factions 比对(锁后历史误持不入基);护栏只读「锁槽非空 + 锁线 factions + 持有投资名」现值,不读方向层状态、不进 committed 语义,与方向层读口无耦合(权威版本 = 29/28 号稿 §3)。

### 1.4 锁定后

- **不设主动换线**(用户立场:自己玩都很少中途换——「搜不到 → 转线」类预案已被锁定前评估吸收:搜不到的线分数起不来,兜底锁定时自然不选它)。
- 唯一线内调整 = **星级 = 必要星级表驱动,无降档规则**:每线每角色按攻略登记必要星级(知识卡 `need_star`;CARRY 按星级饥渴数据标 2★/3★,辅助标 1★)。定义 3★ 就追到底,无降档;定义 2★ 的线 2★ 即完成。星级是刷新停留的自然积累(刷新判据 = 星级目标驱动,[11_shop_decisions.md](11_shop_decisions.md) §3),不是独立管理对象。
- 等级被硬需求推过目标最优概率带的形态 = 当前等级即剩余可达最优——照样停留刷新(可达最优等级模型,[11_shop_decisions.md](11_shop_decisions.md) §2 停留门)。

## 2. 方向状态载体与读写接口

方向状态 = 策略器私有状态(StrategyState)上的四键(锁定线槽 / 配方物化键 / 过渡候选槽 / 候选快照)+ 派生缓存:

| 键 | 写者 | 语义 |

## 3. P1 配方对链(候选制)

未锁定期的 P1 方向由**体系对候选机器**承载(kernel 驱动 = `cw_intention.update_p1_recipe`,flow 方向节拍贵段调用;`clear_p1_recipe` 进 P2 退场清键——同点清空 `opening_recipe_comp` 与 `transition_candidates` 并置读口守卫)。判据 = **候选排序键纯函数**((对级支持度降序, 对级声明序))——确定性由排序键承载:支持度 = 羁绊计数/档,事件驱动变化(买/卖/合成),帧间稳定无连续值抖动;防摇摆语义 = 支持度不变则序不变(旧四层谓词族〔在任优先单席易手/排序维星级当量选席/渐进 argmin `e_rounds` 估计器/换席可行性门 E≤R_rem〕已随候选制退役——退役登记 = math_proofs P-T166 行,考古走 git 历史)。

- **候选空间与评估**:体系对 = 四体系(`_P1_PAIR_PREF`:仙舟/持续伤害/列车同行/希儿系)的单体系对(4)+ 双体系组合(6);**对级支持度 = min(各席席级支持度)**(木桶语义——和/均值使单席满的对虚高),席级函数现行零口径改动(只吃真实持有);支持度 > 0 的对按候选排序键取 top3(`_P1_PAIR_CANDIDATE_TOP_N`,与终局候选数同值复用【拍】)写 `transition_candidates` 槽;**希儿系对入候选门槛 = 席级支持度 = 1.0**(单卡希儿 0.5 不驱动方向,旧 Q 门槛同值);对级声明序 = 各席体系在 `_P1_PAIR_PREF` 的索引组成元组的字典序(短元组同席补 ∞——同首席的双体系对排在单体系对前,更完整方向优先;零新常数)。无羁绊开局候选空(合法形态,冷启动臂承接,[11_shop_decisions.md](11_shop_decisions.md) §1)。
- **p1_pair = 门控候选首位**(派生态):首位对级支持度 ≥ `P1_PAIR_LOCK_MIN_SUPPORT` 才写,否则空对——committed ⟺ p1_pair 非空 ⟺ 首位支持度满,与旧派生**含支持度回落帧逐帧等价**(§2 committed 行);渐进第二席职能由候选并集承载(第二体系件经候选并集买进,不再产渐进 2 元对)。
- **配方物化**:`opening_recipe_comp` = **无门控候选首位**物化(候选空窗期同样有方向——部署开局面恒有最强方向,不随门控变 None;无方向帧消费者全盲 0 买 0 刷经济冻结的防线由此承接);未冻结期每轮随支持度事件可换(部署搜索每帧现算重搜,无沉淀状态),冻结后 = 冻结对。位面辖域 = `plane2_started` 窗口谓词(物化与消费两端,非位面字面量)。
- **冻结语义**:「凑齐」= 板面两两组合成型(kernel 成型线 form_ok)达成即事件标志位冻结方向(`p1_pair_frozen`——冻结的是方向不是板面,买入/部署继续服务冻结方向);**冻结评估域 = 全候选空间中对级支持度 ≥ `P1_PAIR_LOCK_MIN_SUPPORT` 的双体系对全扫描**(枚举载体 = 候选机器同源排序函数不截断,超满对先于恰满对;取 form_ok 首个;**单体系对不进冻结域**——「单体系锁停」死锁结构性免疫);冻结后候选槽写单元素(冻结对,读端零特判);解冻闭集恰两项 = 超窗出口(`_p1_pair_overwindow`:E > R_rem,解冻 + 封印该对防逐帧空转环)/位面末(P2 移交);超窗解冻状态机与再一次性标志位封印对双体系对零改动。
- **板面执行分立(部署统一批收编)**:配方对链是**方向层产出**——`p1_pair` 决定 P1 朝哪个体系买/攒,不直接驱动板面;「谁上场」= 统一部署搜索评分定型([24_deploy_segment.md](24_deploy_segment.md) §1),板面不消费候选序——部署侧的同分防摇摆由搜索的稳定键(与现板面一致数)承载。
- 配方对评估数据表引用已收尾(统一保护集迭代末阶段):TRANSITION_PACK 候选体系表及档位标签符号已删除(`knowledge/cw_line_facts`,design §2.4 三判据清点裁决)——身份消费面已全部迁保护集/注册表现算(买面序 1/囤货臂/D7 拒因/hold 登记档位);非身份档位消费迁 `framework_members` 注册表现算(bond_members 派生;原部署围栏 fw_carry 消费面已随部署统一批收编删除);零生产消费方的休眠框架选线判据族(`cw_transition.pick_framework`/`transition_score` 等)随符号退役。投资选卡帧喂入 CommitSignals 保留(纯遥测,决策面零消费)。
- P1 锁定局配方链继续运行:`update_p1_recipe` 不受锁定辖(P1 并集消费 = 过渡候选成员并集 ∪ 锁定线名单);退场清空只在进 P2(`clear_p1_recipe`)。

- **锁定帧买侧目标约束基准** = `locked_buy_scope`(P1 配方锁定帧 = **过渡候选并集**〔`transition_candidates` 槽透传——非空边界 = 候选非空(任一体系 >0 即约束),(0,1) 支持度带从无约束翻转为并集约束:有倾向即约束机会买〕∪ 锁定线 `_line_hoard` 角色采购集;两者皆空 = 无锁定帧不约束)与 `locked_buy_membership`(义务面身份判定;配方支**维持 p1_pair 直读**——与 scope 刻意分层:M2 义务面 = 锁局承诺面,p1_pair 单满 1 元对形态使 P1 ①锁局 M2 义务集收窄至冻结方向)。
