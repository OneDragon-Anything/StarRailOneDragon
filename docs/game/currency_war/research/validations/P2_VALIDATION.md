## 1. 命题与推导现状(门①:内部推导)

**判定:不过——推导面不存在(佚失),现存内容非数学证明。**

- 单篇「证明」节全文一句话:「plaza_methodology M16 装备-经验耦合推导:……推导见该节」——**推导外包给 M16,而 M16 现行文本(2026-08-24 封存时)已把推导段删除**,只留封存注记。现行文档面上无任何可逐步核的推导。
- git 考古复原(`git show 122e3621`,第三刀归位版)的原始 M16 推导全文为:「步离人战斗后得 4 经验;**我方每件简易装备 +1 经验**(进阶/特权算 2)→ 装备穿戴总数 = 狼狩队的隐性 XP 引擎(8 件简易 = 每战 +8 XP)」+ 策略点一句。**这不是期望账**:
  - 没有「铺满 vs 集中给核心」的双臂比较——集中的机会成本(核心位战力集中收益)从未建模,收益侧只算了铺满的 XP 增量;
  - 没有 EV 式:XP→步离人升级→强度提升→胜率/掉血的换算链一环未量化;
  - 「正期望」三字无任何数值支撑,连符号论证(收益>0 即正,忽略对照臂)都不完整。
- 结论:该件从立项起就是**机制直觉的登记**,不是证明;索引「已证(边界受限)」的状态标注高于实际强度。

## 3. 建模对象 vs 玩法文档(门③:机制原文对照)

**判定:狼狩辖域内机制方向一致;但命题被消费为通用倾向时,辖域错位——不过(声明诚实度尚可)。**

- 机制原文(注册表 desc):「召唤【步离人】协同战斗,其在参与战斗后可以获得经验并升级。我方队员携带更多装备会使其额外获得经验。」——「装备-经验耦合」建模对象与原文一致,狼狩语境内该机制真实存在 ✓。

- 单篇与索引均自知declared此边界(「适用性未重验」「强度待重验」「狼狩封存后无新语料」),且 2026-08-26 已修正过一次封存对象误写(四体系↔狼狩,commit 5e7cf8c0)——声明诚实,但「作为通用倾向保留」这句话本身无任何四体系内证据支撑,是一个悬空的遗产断言。

## 5. 参数溯源(门⑤:常量分类与公理判定)

**判定:不过(公理栈对照)。**

  - 零调参 ✓(无拟合参数——因为根本没有模型);

## 6. 最终判决

**P2 = 「无证明的命题登记件」:推导佚失(git 可考但非数学)、量值锚断链、消费辖域内机制不存在、零实证。**

- **状态修正建议**(由编排者裁决后落档):`已证(源体系封存,强度待重验)` → **`待证明(推导佚失+辖域封存;方向保留为待证假设,禁作策略授权;非狼狩辖域无机制依托)`**。理由:「已证」二字不成立——该件从未做过期望账;与 P3/P12 的「作废禁引」不同级(那两件是**错的数学**,本件是**没有数学**),故处置=待证明而非作废,方向(狼狩 XP 引擎)未被证伪。
- 严重度:低。生产代码未消费其期望主张;唯一消费点(wear_discipline_alert)走的是独立的有效路径(积压报警),但其 +1/+2 常量需补锚(见下)。
