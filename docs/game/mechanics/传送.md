# 传送机制(mechanics)

通用跨玩法机制:大世界传送点 / 指南传送 / 星轨航图切星球。各体力玩法(花萼/历战/饰品/忘却之庭)经传送到达。

## 传送类型

- **大世界传送点**:大世界分布的传送点(解锁后可传送),`large_map` 选点 → 传送。
- **指南传送**:`星际和平指南` → 生存索引 → 选 mission → `GuideTransport` 传送(各玩法入口)。
- **星轨航图**:`large_map` 星轨航图 → 切星球(星穹列车/喜笑/二维市…)。

## 机制

- **传送点解锁 = 地图探索**:新地图 / 新城区需先跑图探索,传送点才解锁;未解锁不可传送。
- **朝向继承**(同地图):传送后角色朝向继承传送前(若同地图);跨地图传送重置朝向到默认。
- **加载**:传送后 loading 画面 → 落目标大世界。

## bot:`GuideTransport`

- `interastral_peace_guide/guide_transport.py`:指南传送(选 mission → 确认 → 等加载-XX → 落目标)。
- `GuideCheckPower`:传送前检查体力(不足跳过)。
- 关联:[guide](../gameplay/guide.md) 玩法 + [large_map](../screens/large_map.md) 画面。

## Transport 失败排查(screen-onboarding 固化)

`GuideTransport` / 大地图传送失败(选不中目标点 / 超时),常见根因:

1. **目标地图未探索 / 传送点未解锁**(最常见):新版本玩法 / 新城区需先跑图解锁。判据:Transport 打开地图但选不中目标 → 先确认目标地图已探索。
2. OCR 识别地图区域 / 目标名不匹配。
3. 地图加载慢 / 超时。
4. 目标名版本变化(改名)。

排查:结合地图截图 + server 日志(`.debug/sr_od_mcp/main_server.log`,看「执行传送」节点 OCR 内容)+ 超时节点确认,**勿唯一归因**未探索(OCR/加载/改名也同状)。

## 朝向重置(手动复现 app 路线用)

传送后角色朝向继承传送前(同地图)。手动复现 app 的 `move_w`+`interact` 前,**先传送去别的地图、再传送回目标地图**,朝向重置到默认(screen-onboarding「transport 复现」)。
