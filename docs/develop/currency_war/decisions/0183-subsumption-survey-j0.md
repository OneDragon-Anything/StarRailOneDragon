# ADR-0183: 子承普查落地(redesign 49 号 J0):单一源缺口检出 + HP_LOSS 双源统一 + CI 护栏

## Status

Accepted(2026-08-17,策略优化会话;49 号退役/合并状态机为后续治理批次)

## Context

49 号 J0 判据:子承普查 ≥2 对合并候选,零对收缩护栏档。43 号自认「35/43 共享提取器」
是现成候选。普查须把「自认重叠」变「客观测量」。

## Decision Drivers

- 52 号审计:模块只增不减(53 个 cw_*.py)正在成为胜率敌人;双源漂移是静默 bug 源
- 普查必须防巧合碰撞误报(短标量 2.0 跨域常见)

## Considered Options

1. **AST 级普查 + 巧合过滤(选)**:同名同值/同签名/同值异名(排除短标量与空容器占位);
2. 语义嵌入比对——维护成本高,先静态;
3. 不做——双源静默漂移无守卫。

## Decision

选 1:`cw_subsumption_survey.py`——

- **首跑命中(收紧过滤后)1 对真双源**:HP_LOSS_MU(cw_first_passage)× HP_LOSS_PRIOR
  (cw_horizon)同值异名——18 号与 03 号各自维护掉血先验(0176 引入,本批即修):
  **统一为 cw_horizon 持有**(物理原语层,被 sim_env/economy 同源消费),first_passage
  引用之并定义分布语义(CV/位面乘数);
- 次命中 REFRESH_TABLE × _PAIRS 查实为空容器 lazy 占位(运行时同源自 cw_shop_odds 填充)
  → 非双源,收紧过滤规则(空容器不算);
- 统一后重跑:**零对** → 按 49 号 J0 预注册条款转护栏档;
- CI 护栏测试:全包普查零同值异名常量(新双源引入即 fail)+ 命中语义 + 巧合免疫验证。

## Consequences

- 单一源纪律获得机器守卫(49 号复杂度预算的软档落地);
- 49 号其余机制(租金计量/退役状态机/合并管线)为治理批次,依赖 24/40/42 的 sim 记分门;
- 49 号处置完成(v0),提案文件删档;测试 +3。
