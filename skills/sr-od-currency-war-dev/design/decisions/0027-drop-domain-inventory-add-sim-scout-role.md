# ADR-0027: 撤领域版派发盘点,新增「模拟找问题」独立角色(两形态)

- 日期: 2026-09-01
- Status: accepted

## 背景

公共仓 od-dev-agent-autonomous-mode ADR-0007 将定时任务分为两触发形态(形态 A 定时提醒编排者/形态 B 定时直启子 agent,按环境能力选),并为找活盘点提供了形态 B 任务书。CW 领域版派发盘点(autonomous-loop.md §2)面临重审:其内容=通用盘点+两项 CW 叠加(账本检索措辞、sim 产能兜底步),其中找活职能已被通用层两形态完整覆盖。

## Considered Options

1. **保留领域版盘点并补形态 B 领域任务书**:否决——账本结构/状态词/检索规范与通用一致,领域任务书=纯双源;领域版继续存在则每次通用层演进都要对表(ADR-0025 记录的维护负担)。
2. **只撤领域版,不补 sim 角色**:否决——sim 产能兜底是编排者派单决策,直启找活子 agent 只产候选不派活,撤掉领域版后该职能无处安放,「模拟常开」只剩事件驱动一条腿。
3. **撤领域版 + sim 兜底升格为独立角色「模拟找问题」(两形态)**(选中):找活全归通用层;CW 只留自己真正特有的职能,并给它独立的触发节奏。

## Decision

- **撤「派发盘点·CW 领域版」整节**(模板+改动说明+对表规则):形态 A 用通用「派发盘点」提醒模板、形态 B 用通用「找活盘点」任务书,均逐字照抄,CW 零叠加。领域封条「禁止以等实机为由不找活」的承载面迁回 AGENTS.local「不干等实机」纪律行(指令文件常驻,冲动时刻在场)。
- **新增「模拟找问题」角色(~15min,登记时刻与盘点错开防齐发;两形态)**:模拟常开纪律的周期兜底——形态 A=提醒编排者查额度/在飞后派 sim 找问题子 agent(派单决策留编排者);形态 B=到点直启 sim 找问题子 agent 本身(任务书自包含,判据单一源=sim-testing「找问题」三步主线+「先知道边界」)。产出=问题结论+候选修复项,交付合同含「sim 边界现象不立为策略病灶」。
- **角色归属登记**:实机监控只有形态 A(会话内状态+派单权);策略审查暂形态 A(与通用层代码/文档审计同节奏,待盘点直启试点验证后按同框架补);派发盘点与模拟找问题两形态齐备。
- **形态 B 采用通用找活盘点任务书不写领域版的边界澄清**:ADR-0025(领域版重读锚=CW 自身)管的是「领域版与通用版结构分叉后」的重读锚定;全盘采用无分叉,不存在带偏问题——该 ADR 原则仍约束其余模板与新模板,其盘点适用面随领域版撤销消失。
- 机制归属说明(形态 B 下 sim 兜底的消费时机)属运行期方法论,住 autonomous-loop.md,不进 AGENTS.local 镜像(指令文件「不放运行机制说明」);「模拟常开」纪律行本身不变。

## Consequences

- 正:领域版盘点撤销=最大一块对表负担消失;CW 自主模块收敛为「通用层基线+三个真领域角色(实机监控/策略审查/模拟找问题)」;sim 找问题获得独立触发节奏,不再挂在盘点节奏上。
- 负/取舍:形态 B 盘点只扫账本,领域版第 3 步多来源发散不入任务书(v1 范围,与通用层同判;sim 常开兜底产能,回顾换地复核与代码/文档审计保留其余来源覆盖);形态 B 直启不查槽位,并发冲突由编排者在收账时处置。
- 「等实机不找活」封条从模板面退到指令文件面——若运行数据显示编排者仍以此为由空转,再评估回模板(须同时答「指令文件为何不够」)。
