# ADR-0195: 策略发布层 v0 落地(redesign 47 号处置:PVS 世代戳+发布注册表+世代分层估计)

## Status

Accepted(2026-08-17,策略优化会话;灰度协议执行侧[指派随机化/两级 canary/tripwire
自动回滚]挂实机批次;37/05/20 的 PVS 分层消费端升级为接线批次)

## Context

47 号诊断:切流=位翻(无灰度/回滚/隔离);15 seam 各自独立翻互相拆台(并发位翻污染彼此
判据);语料无世代戳 → 线强度被「驾驶技术代际差」混杂毒化(不报错,只产生系统性偏置
结论——比 46 的功效稀释更糟)。

## Decision Drivers

- J0 混杂恢复(合成注入→分层恢复真排序)是核心可证伪判据
- J1 考古:语料实际跨越世代数 ≥10 才主张成立(<3 降级打戳护栏)

## Considered Options

1. **PVS+注册表+分层估计器先行(选)**:统计语义与状态机纯函数落地,执行侧(实际灰度)
   挂批次;
2. 直接建 canary 执行链——指派权威与 tripwire 需实机窗口;
3. 不做——世代混杂继续静默偏置 37/05/20/42。

## Decision

选 1:`cw_release_layer.py` v0——

- ``PolicyVersionStamp``(代码哈希+seam 向量+权重哈希+配置快照;强制 join 键)+
  ``ReleaseRegistry``(五态机:shadow/canary/promoted/rolled_back/quarantined+证据包);
- ``generation_stratified_estimate``:世代偏移两层收缩估计 + 去偏线强度——「线强度 vs
  驾驶技术」不可分问题变显式可估分解;
- **J0 过(测试)**:合成注入(旧代 −15pp 且与线指派相关:A 多旧代/C 多新代)→
  **naive top-3 排序翻转(A 压到 C 下)、分层恢复真序 A>B>C**——混杂毒化与解药
  双向机器验证;
- **J1 考古:CW 目录 543 个 commit**(≥10 预注册线 54 倍)——重构期高频换代,
  语料混杂现实存量为大,主体主张成立不降级。

## Consequences

- 「未打戳记录=0」审计查询、37 分层版 vs 不分层版的 top-3 差异表(被纠正偏置量即
  交付物)挂消费端接线;
- 灰度协议(发布层独占指派随机化=世代效应唯一干净工具变量;两级 canary;35 式回滚
  代价定价)语义就位,执行挂实机;
- 47 号处置完成(v0),提案文件删档;测试 +4。
