# 过渡侧货架资格虚拟评估（详设）

## 问题与约束

- 边界：给过渡买面补「货架虚拟评估」资格臂（行为增强）；**不动**终局侧货架资格臂（shop.py `shelf_qualify_buy` 现行实现）、不动过渡锁定机器、不动冷启动回退。
- 总纲契约 B：虚拟帧与实机帧共用 `transition_scores` 纯函数。
- 现状不对称（动机）：终局侧买牌已有虚拟评估——货架资格臂对「在手 ∪ 货架」虚拟算终局候选 top3，「买这张牌点亮哪条线」决定资格买入；过渡侧买面 = 实候选条目成员并集 + 冷启动见即买并集（候选空时），买牌时不预演「这张牌让哪个组合接近成型」。用户裁定（2026-11-05）：过渡候选实时跟着虚拟阵容计算变化，与终局同构。

## 方案

### 1. 资格判据（与终局侧同构的窄门）

货架上的牌 X 是过渡资格买入，当且仅当：

```
X ∈ 货架可见 ∧ X ∈ 某虚拟过渡候选组合（top3）的计分成员域
```

- **虚拟计分**：`transition_scores(在手 ∪ 货架全体牌, 开局简报克制源)` → 返回有序全序列表（计分+过滤+排序在函数内，契约 B），切片取前 `_TRANSITION_CANDIDATE_TOP_N`——与实机帧同函数同排序，仅持有集换为虚拟集。
- 虚拟候选的语义 = 「把货架全买了之后的过渡候选」——X 在其 top3 组合的计分域内 = X 参与点亮某个当下最强的过渡方向。
- 买入写持有 → 下一帧实机 `update_transition_candidates` 重算 → 候选真实跟随——「信号进 → 买入 → 候选点亮」闭环（终局侧同款，shop.py 货架资格臂注释的过渡侧对应）。

### 2. 接入位置（shop.py，货架资格臂同层）

- 挂载点 = 现行终局货架资格臂（`shelf_qualify_buy`）的同层序位之后、序 1 层内殿后——同帧多资格件按货架槽序（与终局侧一致）。
- 买因标记 = `'transition_shelf_qualify_buy'`（对齐终局侧 `'shelf_qualify_buy'` 命名式，经 `_emit_buy` 买因通道落遥测）；**遥测零新增键**——资格臂的买入动作经现行 buy_card 动作遥测通道自然记录（买因字段区分两臂），`sess_p1_pair` 等会话键不动。
- 触发窗 = **过渡层活跃**（未终局锁定）且**过渡未锁定**——过渡锁定后买面 = 锁定组合的成员域（现行 `locked_buy_scope`/`locked_buy_membership` 语义），资格臂退役（终局锁定时整层退役照旧）。
- 资格名单 = `transition_scores(held ∪ shelf, sources)` 前 3 名组合的 `transition_member_set` 并集（经单一读口，禁内联展开）。
- 金不足/备战席满的处理：与终局侧资格臂同款（`_acquire_yield` 让位/跳过），复用现有分支骨架。

### 3. 与终局资格臂的并存序

同帧两张资格判定并存（终局资格臂在前、过渡资格臂在后）：

- 终局资格臂现行窄门不动（CARRY/骨架级 ∪ 虚拟 top3 线）；
- 过渡资格臂是**追加面**：终局侧不点亮的牌（如 1 费过渡件爻光/藿藿）经组合计分域点亮——两层信号互补，不互斥。
- 位面语义自然分工：位面 1 过渡计分天然占优（低费羁绊件进组合计分域）；终局锁定后过渡臂退役、终局臂独走——无需位面特判（生命周期挂钩 = 终局锁定事件，沿 3.3 换轴裁定）。

### 4. 行为变化申报

1. 买面新增过渡资格通道：货架上的过渡组合计分域成员（含 1 费件），在手 ∪ 货架虚拟计分下进 top3 组合即资格买入——此前这些牌只在「实候选成员并集/冷启动并集」里被买，虚拟评估让「差一张点亮组合」的牌可见（例：手握铁三角二人 + 货架有藿藿 → 仙舟系组合虚拟分抬升，藿藿资格买入）；
2. 资格臂触发帧 = 过渡未锁定 ∧ 未终局锁定；两锁定态下零行为变化。

## 关键取舍

- **放弃「过渡候选槽直接存虚拟评估结果」**：实机候选槽（`transition_candidates`）语义 = 实持有证据的方向（锁定评估域依赖它防偶然锁定）；虚拟结果只是买牌决策的瞬态投影，落状态会污染锁定域语义。虚拟帧即算即用、零持久化（终局侧同款声明）。
- **放弃「资格门加成型进度预演」（买了这张后组合 fp 变化量）**：计分域资格已承载「点亮哪条线」；fp 预演引入 form_progress 的第二消费语境（虚拟板面），复杂度不成比例——组合成型仍由实机帧判定。留作实机遥测观察项：若资格买入过多「点亮后仍长期不成型」的牌，再议收紧。
- **词缀/boss 面经 `opening_ctx_of` 同源现读**（终局侧同款声明）：简报未观察帧外部分自然 0，虚拟排位与主链一致，不构成虚拟偏差。
