# 大地图录制 skill · 设计总览

## 定位

为锄大地(world_patrol)产出"官方 srmap 底图 + 实机定标"的地图资产（raw/mask/锚点坐标/门测），
覆盖：新版本缺失区域的首次录制、已有区域的重录、录制失败的排查路由。

## 边界

- 不管：小地图(minimap)识别、巡访自动化 op、sp yml 正式落位与 uid 命名、路线绘制。
- 巡访（cn/tp_pos 采集）在本 skill 只沉淀"锚点图标参照法"等手工原型经验；op 化归玩法应用开发。

## 构成

- `scripts/gen_map.py`：一级定标（SIFT 多 ratio + RANSAC + 平移投票分簇）→ raw(噪声背景)/mask/lm_pos。
- `scripts/calib_affine_gen.py`：二级仿射兜底（6dof，容旋转/剪切/非等比；ratio 0.75、RANSAC 阈值 6.0、内点 ≥10）→ 自带贴回与门测。
- `scripts/calib_by_anchors.py`：三级锚点对应兜底（可见图标 2 点拟合 + 第 3 点校验）。
- `scripts/verify_gen.py`：纯官方门 / 锚点真值（掩码模板裁判）/ 贴回 / 复测，一跑出全部判定数。

## 机制结论（定标模型选择与判定阈值的依据）

以下结论均来自 2026-09 实机实验（斯缇科西亚/行政区/奥赫玛/主控舱段等约 15 层），
细节与证据链在锄大地迭代过程区 design.md §2.5：

- **分层渲染**：实机大地图 = 当前层深色实体 + 其他层淡显幽灵；官方切片是全层深色的页面
  合成图。二者渲染语义的差异是"纯官方纹理匹配门"的上限来源（单层 ~0.89，多层 0.6~0.8），
  线性调色无法修复（归一化相关不变性吸收）；实机贴回把覆盖区修正为运行时渲染，门 ≥0.99。
- **跨层对齐**：同区域各层共享官方页面坐标系（双层同机位截图互投影实测 1~7px）；
  但各层实机缩放档有微小差异（0.1%~0.5%），跨层共享定标变换实测不成立 → 逐层独立定标。
- **缩放档连续分布**：实测 0.17~3.4（小区域底图分辨率低 → 实机放大渲染 s>1；大区域高分辨率
  → s<1），scale 不能作为护栏主判据；质量判据 = rot、残差、内点数。
- **底图艺术倾斜**：个别区域官方切片相对实机渲染有 ~2° 旋转 + 轻微剪切（哀丽秘榭实测，
  相似变换残差 11px、仿射 1.4px）→ 需要仿射级模型。
- **点表手标抖动**：官方 point 坐标为编辑者手标（逐点 ±7~25px，部分区域准到 ±5px），
  运行时点击不受影响（±100px 图标模板窗兜底）；巡访精修 lm_pos 是精度根治手段。
- **未探索区域不可录**：实机只渲染已走路径，无地形可与全地形底图对应。

## 动机

- 为什么三级降级而非单一模型：不同区域的失败形态不同（合成页混层位移簇、艺术倾斜、
  特征稀少），单模型护栏放宽会放进错误共识；分级 + 各自严格护栏（rot/残差/内点）实测
  零误放行。
- 为什么贴回是"修正"而非"增强"：运行时匹配的对象是实机分层渲染，底图合成渲染语义
  与其不一致；贴回后的 raw 与运行时画面逐像素一致（门 1.0 实测）。
