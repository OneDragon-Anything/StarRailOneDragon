# 货币战争-备战-免战(跳过子态)

## 何时出现

备战屏持有「免战牌」道具时,出战按钮位置显示「跳过(N/N)」(N=剩余免战次数)替待「出战」。
M72 活体建档;↺ 2026-08-17 r34 勘定独立子屏(原 r32 决策"元素级不建屏+撤出战 id_mark 保备战精准"
在角色详情帧撞车——出战 id_mark 恢复后备战在本帧自然不精准,按 screen-onboarding 场景①④
归独立屏;叠加态判定见下)。

## 状态流转

- 入口:持有免战牌进备战 → 出战位变「跳过」。
- 出口:点「跳过」(= 备战屏 按钮-跳过 area,与出战同位)→ 直进下下节点补给(M72 实证 2-3)。
- **免战×商店开叠加态**:识别为「货币战争-备战-开商店」(前台区域被商店牌盖 → 本屏不精准;
  开商店 id_mark[购买经验+收起]全中)——叠加帧归开商店处理,本屏只认单免战态。

## 识别特征

- id_mark 组合(双锚):`标识-跳过`(text 跳过 lcs 0.9,(1700,710-1900,775))+ `标识-前台区域`
  ((850,275-1070,340);叠加帧被商店牌盖 → 与开商店正交)。
- 备战屏自身的 `按钮-出战` id_mark 在本帧不命中(跳过替换)→ 备战不 is_precise(场景④:
  一个被替/被盖元素同时解 详情面板/免战 两类子态撞车)。
