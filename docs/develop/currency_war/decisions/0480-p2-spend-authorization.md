# ADR-0480: 位面 2 支出授权(W757 v2 设计落码;默认关+双钥匙开臂挂账)

> **版本界碑(2026-09-04 ADR 存量 review;对象属 decision_v2 栈或旧策略代,现行权威 = strategy-docs/flow/proofs + dd-NNN 系)**:本 ADR 裁决的对象已亡——decision/ 整包(含 decision_v2 各模块)已随 b94e9cfb(dd-038)删除,现行唯一策略载体 = mandate_v1(kernel 吸收下沉判据)。本件仅存史料价值(记录设计 why/翻案史);**文内一切「后续应做 X/须换成 Y」类前瞻指令一律视为已亡,勿执行**。

## 背景

W754 跨局复盘立案 B 的主病灶:位面 2 板面冻结在过渡形态、带金 86-113
血崩死、血线恶化无支出响应、锁线后目标核心卡不买(局 3 希儿两度上架
零买)——决策链(candidates→filters→scoring→arbiter)在 P2 中段没有
一条「授权定向支出」的判据路径:[17]「>50 即花,节点无关」只有 P1 侧
落点(C1),[18]「最小必要支出止损」无 P2 行为落点,[31]②「目标件
刷新出现=唯一最高优先级」在锁定后执行面无强制通道。**命题层无辖域
空白(W754 问 2),是授权/执行层未对齐。**

W757 设计批(v2,经 W758 攻击批 9 条修正)给出完整设计:四条件合取
触发 + 两层强度 + 支出优先级辖域声明 + 分配器/血预算/末窗交界 + 单帧
锁九条 + sim A/B 预注册协议 v2 + P25 待证命题(含 g 分带核验义务)。
本批 = 该设计的落码实施批。

## 决策

1. **新模块 `decision_v2/p2_spend_auth.py` = 授权谓词与预算带单一源**:
   - 触发 = T1∧T2∧T4 合取(缺一不授权):T1 线锁定(消费
     `session.v3_intention` 的 locked 位——该位本身是经 P16 滞回后的
     v3 状态机输出,满足「禁接滞回前原始意向位」);T2 形态缺口
     (`phase.form_ok` 锁定线分支取反——stage_transitions Q5 口径映射
     到既有单一源,不立第二口径);T4 金水位 g≥息线(W758 攻击 A
     实反例封口:边界点取 ≥);
   - T3 血线恶化 = 加急层升级开关(报警面,非单变量触发器):连败
     ≥N_fail(占位 2,带符号 streak 单一源)∨ hp≤P2 警戒带(占位=
     `p1_exit_blood_target`,hp 可信位守卫);
   - 两层强度:常授权层预算地板=「花完仍≥息线」(P5 前提的买牌推广);
     贴线带 [45,息线) 逐点判是 P25 待证项,**证成前保守=不买**(设计
     占位子句,不做生产决策);加急层允许破息至保留金占位下限([18]
     止损的机械化);
   - 授权目标辖域 = 核心名(优先级 1)∪ 买标签集
     `{line_carry, line_opportunistic, bridge_core, plugin, copy_press}`
     (优先级 2 凑档/压库的辖域映射)+ 定向刷新(全辖)。**授权是辖域
     声明不是动作互斥执行序**(W758 面2 攻击 A 封口)——各动作类各自
     按自己判据独立过门;升级永不在辖。
2. **arbiter 三消费点(门开不开+预算上界,候选/评分公式零触碰)**:
   - gold_floor 顶部授权臂:授权帧内授权目标买/定向刷新按层预算带
     放行金地板;
   - interest_rule EV≤0 拒绝点的加急层豁免:常授权层在此不可达放行
     (花完≥息线已 early-return;贴线带 EV≤0 维持拒=P25 占位期保守),
     加急层凭保留金下限放行;
   - arbitrate 非正分门的优先级 1 必买豁免:授权帧内锁定线核心卡买
     候选越过非正分门([31]②;局 3 希儿型弃购的反向锁;豁免≠无条件
     采纳,约束链照常辖)。
3. **交界(全部显式)**:分配器接管帧(`allocator.alloc_domain` 现值)
   内授权禁出手——帧归属二选一(单帧锁⑨);授权通道自身不设金额档
   (「大额」边界随接管判据机械化);末窗(boss 窗)与覆盖纪律态
   (应急/war)归既有族,授权不触发;血预算停升级线/P21 与授权 AND
   (授权只放宽买/D 预算,永不放宽升级);P12 j=0 负例在评分层不动。
4. **开关 `p2_spend_auth_enabled` 默认关 = 策略开关生命周期第 1 态**
   (准入理由=行为输入未就绪:P25 的 Δp 未标定、T3/保留金为占位值)。
   **开臂判据挂账(双钥匙,缺一不开)**:①P25 证成(g 分带各给符号
   结论;采集死线=60 局实机或 1 次 sim 注入批先到,到期未证成=按证伪
   分支当场兑换);②sim A/B 预注册协议 v2 主判据达标且护栏全绿
   (n=500/臂配对 McNemar,主判据 M1-M3,护栏 G1-G6)。验证不过的
   出口=删码留本 ADR(第 4 态),禁悬置默认关。
5. **P25 前提③措辞封口**(W758 复核非阻塞瑕疵):「g>50」改
   「g≥50(贴线带见 §边界点与分带核验)」。

## Considered Options

- **平行新开一条 P2 花费通道(自算优先级串行执行)** — 否决:与四层
  管线/分配器三裁决者并存必造同帧双花与判据漂移;设计件明文「授权改
  门与预算上界,候选与评分公式不动」,且 W758 面2 攻击 A 已封死「串行
  优先级链」读法。
- **把 [3] 提概率升级在授权层重新实现** — 否决:升级授权单一裁决点
  已在 `ev.levelup_ev_basis`([33] 人口位/DP/静态 EV 三臂,P5 概率窗
  在 level_plan/EV 账内),授权层重写=双判定源;授权对升级零触碰
  (放宽它违反血预算 AND,收紧它违反 [3])。
- **常授权层贴线带按 [22]④ 凑息账直接放行(不等 P25)** — 否决:
  EV 符号未证(恰是 P25 卡点),拍值参与生产决策违反数学先行硬门;
  取保守不买占位,开臂判据挂账。
- **接管帧语义反向(授权优先、分配器让位)** — 否决:分配器接管是
  W752 实测的整帧语义(接管帧管线 chosen 全空,同帧双花检查闭环),
  撕开帧归属会破坏该不变量;且濒死/停手窗域内授权的加急账(P25 未证)
  弱于分配器的 P23 已证 EV 门。

## 后果

- 默认关下全部消费点恒短路,行为与 HEAD 逐位一致(零漂移锚=单帧锁
  测试 off 臂);开臂后行为面=授权帧内的核心卡必买、授权目标买/D 的
  预算带放行(常授权地板=息线,加急=保留金下限)。
- 验证义务:受影响测试+cw_quick+九锁;A/B 按预注册协议归后续专批,
  本批不跑 A/B。
- 遗留挂账:P25 采集死线(60 局/1 批)由编排者排程;贴线带占位锁随
  P25 证成重推;开臂翻默认时须盘点「断言授权关闭行为」的锁组(生命
  周期第 3 态义务)。
