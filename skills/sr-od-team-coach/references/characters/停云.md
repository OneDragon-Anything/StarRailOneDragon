# 停云（雷·同谐·4星）

> 按 V4.7 期撰写。能量电池+攻击拐：回能50对能量系主C价值极高。

## 一、命途属性与技能说明

**命途**：同谐；**属性**：雷

| 技能 | 说明 |
|---|---|
| 普攻 | 单体雷伤 |
| 战技【赐福】 | 3回合：目标攻击+25%（上限=停云攻击15%）+ 目标攻击后附加20%**目标**攻击力雷伤（按目标面板结算） |
| 终结技 | **消耗能量130**；为目标恢复50能量 + 伤害+20%（2回合） |
| 天赋 | 停云攻击后，赐福目标附加30%停云攻击雷伤 |
| 秘技 | 自回50能量 |

**资源与循环**：标准能量→充能绳有效（秘技+130能量循环）。

## 二、推荐遗器与原因

**套装**：野穗伴行的快枪手4件 + 生命的翁瓦克2件【攻：经典口径】
**主词条**：躯干**攻击%**；脚部速度；球攻击%；绳充能。
**副词条**：攻击% > 速度 > 充能。
**转模与转化上限**：战技加攻上限=停云攻击15%（超过目标后封顶）——攻击收益有界。
