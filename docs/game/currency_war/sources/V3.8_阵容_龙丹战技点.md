## 机制(怎么 work)

**丹恒·饮月**:无限耗点强化普攻;3 星每消耗 1 点 +180% 对单 / +90% 对群倍率。**靠战技点羁绊抽奖**获取大量额外战技点。

**凛(远坂凛)V4.4 新**:战技点羁绊,宝石叠 99 层以上 → 释放「第二魔法实验」拐 **198% 爆伤**(+默认 70% = **268% 爆伤**)。

## ★6 战技点是陷阱,3 量子同频最优

- **6 战技点是陷阱**:描述「更容易抽到更好奖励」**不包括最关键大奖**。UP 统计 1 万次:4 战技点与 6 战技点**大奖暴率都趋于 5%** → 6 战技点成型苛刻(需转职 + 2 挂件)且伤害提升微乎其微。
- **饮月最合羁绊 = 3 量子同频**(不是 6 战技点 / 6 列车):3 量子提供远不止纸面 30% 易伤 —— 符玄 / 银狼 / 花火按量子数量提供大量**减防 / 易伤 / 行迹级伤害 / 暴伤** → 饮月从「倍率拉满」变「多乘区拐力拉满」。

## ★花火「人造大奖」手法(核爆核心)

抽额外回合大奖本是赌运,但可**人造**:花火充满能量后立即大招回海量战技点 → 控花火能量「将满未满」→ 抽空战技点后插入花火大招 → 瞬间补满 → **一轮吃两倍战技点 = 两轮伤害量**。

花火充能四法:
1. 角色吃点给花火回能 —— 但饮月回合内拿不到(得等回合结束)。
2. 我方任意攻击敌方 → 花火 +4% 大招能量(太少,不好卡)。
3. **花火后台 1 号位 + 星期日大招**(给后台 1 号位大量充能)→ 花火能量 >65% 即可在饮月回合内充满(最常用)。
4. ★**饮月「献予苍龙之诗」七连大**(未写在文本上):不只给前台充能,**后台同样充满**;一次性充到满,不需刻意卡花火能量。虽只 1 次充能,但全队回能 → 到顶再充满一次 → 吃回合结束花火大招 → 再打一轮 → 饮月轮转拉到恐怖高度 → 走顶顺秒。
- ⚠️ 七连是**后期追求核爆上限**才带;正常用星期日大招或攻击型大招卡花火大。卡花火双大 = 非常难得的上限素材,实战难复现。试用饮月也能玩(素材即试用)。

## 出装

- 饮月推荐直接 **3 把暴击刀**(近战就能满暴击率)。
- **后期「激光剑(高周波电锯)」完全没用**:满战技点开始抽奖会吞掉激光剑 / 战技点羁绊的回点 → 少 1 个被动。前期有可先用。
- (旧)饮月:双高周波电锯 + 火力风暴潮 —— 与上面冲突,V3.8 实测 3 暴击刀更优(满爆)。

## 成型阵容

## ★手法两原则

1. **饮月回合内至少触发 1 次花火大招**。
2. **卡好击破❓轴**:克拉拉❓击破进绝位❓这次爆发内留够更多战技点。
- 比无脑「一字星吃光战技点」收益更高。
- 细节:饮月没进绝位、这轮只想多抽大奖(不爆发)→ 卡击破轴:**抽出大奖后立刻停手,把普攻打出去再接着抽**(饮月抽奖机制:抽大奖后的额外回合会替换原本普通回合、挤到额外回合后;及时打掉额外回合让饮月始终在自己回合 → 卡花火大招更方便)。

## 弱点

- 手法门槛高(卡花火能量 / 击破轴),熟练度直接决定收益。
