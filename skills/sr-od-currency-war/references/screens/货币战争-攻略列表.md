# 货币战争-攻略列表

## 画面简介

官方推荐阵容的活数据源——游戏内攻略面板主屏：备战顶栏「攻略」按钮进入（对局内非破坏性 overlay，关闭回备战不丢局）。条目带版本标记 + 羁绊公式标题 + 热度 + 作者；可应用/保存阵容、输入攻略码；「我的阵容」主页签进已保存阵容列表与阵容编辑。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-主tab-热门攻略 | 顶部主页签「热门攻略」（身份锚）：推荐/热门/收藏三子页签的宿主 | 点击切到攻略列表主视图 |
| 标识-主tab-我的阵容 | 顶部主页签「我的阵容」（身份锚） | 点击切到已保存阵容列表视图 |
| 按钮-子tab-推荐攻略 | 子页签：官方 curated 推荐 | 点击切推荐列表 |
| 按钮-子tab-热门攻略 | 子页签：按热度排序 | 点击切热门列表 |
| 按钮-子tab-收藏 | 子页签：收藏列表；「收藏(n/20)」计数动态，OCR 匹配注意 | 点击切收藏列表 |
| 按钮-图例 | 右上「图例」帮助按钮 | 点击开「货币战争-攻略图例」overlay |
| 按钮-关闭面板 | 右上 U 图标 | 点击回备战（关闭 overlay 不丢局） |
| 按钮-输入攻略码 | 页脚按钮 | 点击开「货币战争-攻略码输入弹窗」 |
| 按钮-前往攻略广场 | 页脚按钮 | 点击**外开浏览器新标签页**（米游社活动页）——自动化场景慎点 |
| 区域-列表滚动区 | 攻略卡片列表滚动带 | 拖拽滚动列表 |
| 区域-已保存计数 | 右上「已保存 n/10」计数（我的阵容视图） | 纯显示 |
| 按钮-新建阵容-1 / -2 / -3 | 「我的阵容」视图的新建阵容占位行 + 圆钮（行可超过 3 行滚动） | 点击进「货币战争-阵容编辑」 |
| 卡1/卡2/卡3-标题行 | 各卡标题（羁绊公式标题，一屏最多 3 张卡） | 点卡身进详情（见卡N-卡身） |
| 卡1/卡2/卡3-版本 | 各卡版本标记（如 V4.4） | 纯显示 |
| 卡1/卡2/卡3-热度行 | 各卡热度读数 | 纯显示 |
| 卡1/卡2/卡3-作者 | 各卡作者名 | 纯显示 |
| 卡1/卡2/卡3-保存阵容 | 各卡右侧按钮 | 点击开「货币战争-保存阵容弹窗」 |
| 卡1/卡2/卡3-应用攻略 | 各卡右侧按钮 | 直接应用：卡片出现「应用中」徽标；应用成功会弹「货币战争-装备追踪弹窗」 |
| 卡1/卡2/卡3-卡身 | 各卡本体（立绘 + 角色头像排） | 点击进「货币战争-攻略详情」 |
| （待建档）搜索框 | **无搜索 UI**（OCR+视觉双验）——按羁绊/作者过滤 = 滚动列表读标题自己匹配 | 不存在，别找 |

## 识别后要做的决策

浏览/选用攻略类页面——按用户诉求选子页签（推荐/热门/收藏）与条目；目标阵容的结构化来源在攻略详情页；无搜索 UI，过滤靠滚动读标题。
