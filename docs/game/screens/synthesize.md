# 合成(synthesize)

合成台界面。消耗品 / 遗器等分类合成(用材料合成道具)。**不锁光标**(`pc_alt=false`)。通用系统,不必先搜玩法。

## 何时出现 + 状态流转

- **入口**:菜单点「合成」(phone_menu_const.SYNTHESIZE)→ 合成画面(默认消耗品合成分类)。
- **出口**(动作 → 下一态):
  - 点分类标签(消耗品合成 / CATEGORY_2-4)→ 切分类(停留合成画面)。
  - 物品列表选物品 → 右侧显示详情 + 所需材料 + 合成数量。
  - 点「合成」→ 合成确认弹窗 → 「确认」→ 合成 → (材料不足则提示)。
  - 右上返回 / ESC → 回菜单。

## 识别特征(稳定锚点)

- **标题-合成**(text "合成",pc_rect 100,38-223,65):画面标题锚点(analyze 命中 conf 0.9999)。
- **按钮-合成**(text "合成",pc_rect 1015,963-1347,1005):底部合成按钮锚点(conf 0.9999)。
- `pc_alt=false`。
- 易变:物品名、持有数、所需材料数、合成数量——动态。
