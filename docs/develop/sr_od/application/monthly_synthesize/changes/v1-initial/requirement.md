# 需求:每月合成 app(monthly_synthesize)

## 1. 目标

每月自动把「每月限量合成」的物品合成拉满——当前唯一项:自塑尘脂(材料合成分类)。周期型 app,运行记录按**自然月**重置:每月首跑合成完毕标「本月已完成」,月内一条龙跳过,下月自动重跑。

合格判据:开关开启时,一条龙跑到本 app → 进入合成 → 材料合成 → 自塑尘脂 → 数量拉满 → 合成确认 → 回大世界 → 运行记录标本月完成;本月额度已用完时直接标完成不空跑;材料不足时判失败不标完成(下个周期补跑)。

## 2. 范围

- **做**:材料合成分类下、带每月合成上限的物品合成(当前仅自塑尘脂);导航、数量拉满、合成确认、返回大世界全流程自动化。
- **不做**:
  - 不碰遗器合成(自定义主词条)与消耗品合成的日常合成——那是奇巧零食 app 的领地;
  - 不读、不记录具体合成个数(用户裁定:拉满即可,不关注具体个数);
  - 不碰真实货币充值。

## 3. 配置模型

| 配置项 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `synthesize_resin_enabled` | 开关 | 开(用户裁定 3) | 合成自塑尘脂 |

未来新增每月限量物品时,追加同名模式开关(参考 monthly_embers_exchange 的 `{goods}_enabled` 模式)。

## 4. 使用与运行

- 进一条龙默认组(用户裁定 4,DEFAULT_GROUP=True),随日常批量跑;
- 也可 `run_standalone_app` 单独触发;
- 运行结束发通知(NEED_NOTIFY=True)。

## 5. 运行记录

- 周期:**MONTHLY**(自然月;自塑尘脂的每月合成上限按自然月刷新——与兑换商店月限口径一致,权威玩家知识,待跑过一个完整月界后复核)。
- 周期标记裁定:
  - 合成成功(或本月额度已用完、或开关全关)= 预期内完成 → 标「本月已完成」;
  - **材料不足 = 失败(用户裁定 2)** → 不标完成,一条龙下个周期(日批)重跑补做——今天残骸不够,过几天分解遗器后就够了,语义成立;
  - 其他非预期失败 → 同样不标完成。
- 业务字段:`resin_quota_confirmed`(当月额度耗尽锚,裁定「首屏未见物品」的成因)——数量数值不留痕(用户裁定 1:不关注具体个数)。诊断信息走通知。

## 6. 用户裁定(逐条)

1. **数量拉满,不关注具体个数**——不读不记合成数量数值,把本月额度合完即可(2026-11-15)。
2. **材料不够 = 失败**——遗器残骸不足 800 时本 app 判失败、不标本月完成,让一条龙后续补跑;不是预期内跳过(2026-11-15)。
3. **开关默认开**——`self_modeling_resin_enabled` 默认 True(2026-11-15)。
4. **进一条龙默认组**(2026-11-15)。
5. **首屏判定确认**——自塑尘脂能合成时恒居材料合成列表左上首位(不可用沉底),像每月灰烬兑换一样偷懒只识别第一屏,不滚动深扫(2026-11-15)。

## 7. 玩法知识

- 自塑尘脂:合成遗器时消耗 1 个可指定部位与主词条;获取途径 = 万能合成机·材料合成,每月有合成上限(画面文本「本月还可合成: N」);单价 = 遗器残骸 ×800。
- 合成入口:手机菜单 → 合成 → 材料合成分类;数量用滑条(1~N)调节,上限同时受材料量与每月额度约束。
- **材料合成列表排序律**(用户裁定 5 确认):可合成排前、不可用沉底——能合成时自塑尘脂恒居列表左上首位。
- 画面与操作的事实记录:flow.md(走查后回填)。
