# P64: 遭遇分支旗牌→敌难度 stat 的**静态映射**标定域为空(ENCOUNTER_DSTAT_MAP 不可标定命题)

## 状态

**已证(结构命题;辖域 = 静态 `dict[旗牌→stat]` 形态,条件表形态不在辖域;2026-09-06 正式化,判定批 = 补强通道标定批 ENCOUNTER_DSTAT_MAP/ENCOUNTER_G_GOLD 标定注入)。**

## 命题

遭遇节点二选一判据(E3)的 λ 项需要分支敌难度 stat 相对带界 108 的分带(`lambda_death.difficulty_band`,界 = `DIFFICULTY_BAND_BOUND = 108`);旗牌读数(`EncounterOption.difficulty` ∈ 1-6,即「遭遇其X」)不携带 stat 的构成分量。**在现机制公式下,任何非空的静态 `dict[旗牌→stat]` 注入都会产出假真值**——即对每个旗牌 x 与每个候选静态值 v,存在合法运行时状态使真 stat 落 D0 带而 v 给出 D1(或反之)。故 `ENCOUNTER_DSTAT_MAP` 的可标定子集 = ∅,数值 argmax 臂在本批后保持结构性不可达(双槽互锁 fail-closed)。

## 证明

**机制公式**(单一源 = `docs/game/currency_war/research/economy.md` §9,2026-08-26 用户定谳+米游社数值,社区🟢截图实证;负项 m 实源 = `docs/game/currency_war/research/invest_effects.md` §3——economy.md 该处已作废,负项清单以投资策略实采篇为单一源):

> 敌人难度 = 基础难度 B + 策略加成 q(白 0 / 金 3 / 彩 6,每个投资) + 遭遇等级加成 L(其 X:一 0 / 二 10 / 三 20 / 四 30) + 特殊加成 s(伟大征服 + 当前连胜数;圣杯羁绊试炼 + 30);另可被投资策略负项 m 压低(难度修改器银 −4,简单模式银 −3,退化银 −5 等——现行录档负项均银档,无金档)。

**逐项论证自由项**(经验锚:同文档 §9 观测行,备战帧 stat 实测值域 39-211;敌方信息浮层难度条实测 `108+6` vs `108+16` 与公式自洽——+6 = 特殊项 s 的合法取值,佐证公式、同时证明 stat 由非旗牌分量决定):

1. **B 是局级自由项**:随所选模式职级变(39/42 为低职级局完整旗牌实测),非注册表常量;
2. **q、s 是局内运行时项**:由已选投资品质与连胜数决定,决策点旗牌读数不携带;
3. **m 叠加上界未建模**:`economy.md` §9 明载「完整规则未建模……不预设公式」,负项可叠到多深无界;
4. **L 表本身不完备**:机制表只录一~四(0/10/20/30),而读数器标题正则容纳其五/其六(`cw_node_obs._TITLE_RE`),五/六的 L 未录入册。

对任意旗牌 x:取 L(x) ∈ {0,10,20,30}(或未录档位),由 1-3,q+s+m 的合法取值区间两端未定界 ⇒ stat = B+L+q+s+m 可跨 108 两侧取值。而 λ 分带只依赖 stat 相对 108 的侧别——**带别不是 x 的函数**。静态映射把带别伪装成 x 的函数 = 假真值(禁,R29-6 同款;与该槽开闸判据「遭遇分支敌难度条件表实采」一致)。∎

**G_gold 同判定**(金额侧):「金币×2」金额非机制定义常量——节点收入 = 基础奖励(按轮分段)+ 利息 + 连胜,均为运行时量;存量观察值仅 1 个可信单例(+8)+ 2 帧 OCR 存疑读数(["10"]), 开闸判据「≥3 局观察值定带」未过 ⇒ `ENCOUNTER_G_GOLD` 保持 None。
