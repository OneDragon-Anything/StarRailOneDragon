# 角色-遗器(character_relic)

> source_image: sr-od-test/screens/角色-遗器/default.webp(2026-10-17 live 建档,布洛妮娅遗器着装页)

## 何时出现

角色页左侧「遗器」TAB。独立屏。展示该角色当前装备的 6 件遗器环绕图 + 套装效果。

## 状态流转

```
详情 TAB → 本屏(6 件遗器环绕 + 右侧套装效果)
点任一遗器 → 「遗器-替换」屏(该部位遗器列表+选中件详情)
替换按钮 → 遗器替换总入口(同上,默认部位)
智能装配 → 一键配装(内部页,未建档)
右上关闭 X → 离开角色页
```

## 识别特征

- id_mark「标题-遗器着装」[85,25,205,75],**lcs_percent=0.7**(与兄弟屏「遗器替换」共享「遗器」子序列,默认 0.5 会撞车——live 实测撞过,收紧解决)

## 可交互元素(live 验证 2026-10-17)

| 元素 | 坐标 | 行为 |
|---|---|---|
| 左侧 TAB 5 个 | 同详情页坐标 | 切对应屏(goto_list 已建) |
| 头像条 | 首位 (452-528,28-108) | 切角色保持本 TAB |
| 遗器位-上/右上/中绳/左下/下中/右下 | 6 个固定圆位(区已建) | 点进「遗器-替换」屏看该件详情 |
| 智能装配 | (1495-1672,962-1022) | 一键配装(内部页) |
| 替换 | (1738-1905,962-1022) | 进替换入口 |

## automation 要读信息

- 读区-套装效果 [1480,290,1908,710]:OCR 套装名+件数+效果全文(如「生命的翁瓦克 二件套…」「晨昏交界的翔鹰 二件套…四件套…」)
- 6 件遗器的等级(+15):环绕图各件下方的「+N」徽标(视觉/OCR,位置同遗器位 6 区下缘)
- 遗器套装名图标:模板匹配(与遗器位图标对比 assets 模板库,后续建模)
- 单件词条明细不在本屏——进「遗器-替换」屏读

## 注意

- 6 件遗器摆位固定(头/手/躯干/脚/位面球/连结绳的槽位映射按图标形状辨认)
- 空槽(未穿遗器)显示空圆——扫描时按槽位有无图标判断
