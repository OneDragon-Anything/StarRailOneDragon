# 货币战争-优势布局

货币战争的**局外强化树**(元系统):对局外用「布局代币」激活天赋节点,效果在之后的每局对局中生效。用户口语中的「强化/激活系统」「1 血免死」即本系统(免死节点名 = **保险机制**)。

## 1. 何时出现 + 状态流转

- **入口**:大厅左侧菜单「优势布局」(screen_info 已建 `按钮-优势布局` area,goto 本屏)。
- **出口**:右上「返回」箭头 → 大厅(`按钮-返回` template area,goto 已建)。
- 画面内两页签切换:「常驻优势」/「赛季优势」,树各自独立、坐标同构。

## 2. 系统结构(实测)

- **两棵树**:
  - **常驻优势**:跨赛季永久,本号已全布局(节点全亮、详情按钮「已布局」)。数值强化 + 5 个机制节点。
  - **赛季优势**:本赛季(入画奇航)专属,每赛季重置;「已布局优势 1/40」计数器只在本页签显示,40 = 赛季树节点总数,起点菱形默认算 1。
- **树可横向拖拽滚动**(赛季树约 4 屏宽,约 40 节点;拖拽方向:向左拖 = 看右侧深处)。
- **激活消耗**:布局代币 ×20/节点(右上角计数,本号 410;来源含晋升等级奖励)。锁定节点按钮显示红字「请先布局前置优势」——需先激活前置链上的节点。

## 3. 激活路径链(goto_list 语义)

大厅 →(点左侧菜单「优势布局」)→ 货币战争-优势布局(默认赛季优势页签)→ 点节点看详情 → 点右下「布局」按钮激活。切树点顶部页签。

分类标签两种:「战斗能力增幅」(数值)与「附加机制解锁」(机制)。

## 5. 「1 血免死」= 保险机制(悬案结论)

- 用户记忆的「激活后 1 血免死一次」= 赛季优势树「**保险机制**」:小队生命值**首次**将归零时保留 1 点,避免游戏结束(每局至多触发一次)。
- **本号当前未激活**(锁定态,「请先布局前置优势」)——第 4 局 3-7 BOSS 战败时 HP 40 结束,**与保险机制无关**(若触发免死,HP 应显示 1 而非 40)。
- **激活裁定:未执行**。激活需先布局前置链(路径未知,锁定提示「请先布局前置优势」)+ 消耗布局代币 ×N(≥20,含前置链总计更多)——属消耗稀缺代币,按红线只记录不执行,待用户裁定。
- 详见 BOSS 简报 doc 的败因分析(`currency_war_boss_briefing.md`)。
