> 画面 = 货币战争-备战-开商店(建档 `assets/game_data/screen_info/currency_war_battle_prep_shop_open.yml`);**能力面** = [../screens/README.md](../screens/README.md) §5.4。本篇 = 该画面的**策略面**:策略思路概述 + 会执行的动作清单(按用户裁定 2026-09-14 策略收缩后的目标形态)+ 形式判据指针 + 在案判例。

> 判据权威定义的唯一权威文档 = [11_shop_decisions.md](11_shop_decisions.md)(六序/买面/卖出/刷新/升级),**引用不重复**;数值单一源在代码(常量名形态)。流程编排 = `../screens/shop.md`;决策本体 = `strategies/impl/mandate_v1/shop.py::decide_shop_action`(全函数:f(期望态)→恰一个动作),商店画面 op = `operations/cw_screen/cw_screen_shop.py::CwScreenShop`(两 node;决策动作 node = 单动作 round_wait 循环)。

## 1. 策略思路/算法概述

- **候选买入评估**:对店面每张牌先判类再过金约束门——件级买入判定序(六序)与 M2 义务通道语义 = `11_shop_decisions.md` §1(序 1/序 2 = 骨架义务 M2,不走利息规则门;序 3-5 = EV 买面,判据 = `criteria/buy.py::ev_buy_candidates`/`ev_buy_veto`);合成完成买入 M2b = `11_shop_decisions.md` §1/§2 在案通道;席满买入走六步流程(§1 满席买入行);拒因分类单一源 = `shop.py::shop_unbought_reasons`。
- **刷新放行条件（刷新链三组件，2026-10-28 定型）**：判据 = 三段式查表分派（`criteria/refresh.py::refresh_warranted`——P1 恒不刷 / P2 未锁窗口候选缺件 / 锁定后星级目标驱动）→ 金线闸（`r2_budget`，预留 = saturation_line + 停留目标实费档 `r2_card_reserve`；未锁窗口 ρ=0，`../proofs/p54-r2-interest-floor.md` floor 口径，利息损失递推 = P47 `../proofs/p47-interest-account.md`）→ 发射（免费分支 = 次数在册即刷——**无条件刷**,无判据门,金线不适用;付费 reason `star_target`；判据权威定义 = `11_shop_decisions.md` §3）。刷新 = **结束本次访问**(刷后返回主循环(重新识别画面),重进 = 入口观察重建期望态;次数无硬墙,无限刷新环 = 策略实现 bug 框架不兜底)。刷新提案被拒（金线不足）→ 本帧关店置负结果记忆标记,无状态变化重入帧跳过刷新提案（观测键 `shop_refresh_blocked_memory_skip`,免费与付费同闸）。
- **收工判定**:「无动作可做」= 主动提案 `CloseShop`(恒可用的结束动作,全函数契约);牌面含未识别槽(失读窗)→ 花钱动作全禁、仅关店收工(能力矩阵篇 §3.5/§4)。
- **升级意图出口**(2026-10-17 迭代 T-1,design §2.1):每轮买入评估前执行升级资格门判定(升级触发 = 最优概率带单判据三分派,判定单一源 = `criteria/levelup.upgrade_gate_verdict` 资格门六道门序,同帧一次评估);**命中 ∧ 可发射 → 转场关店**(不置会话标记——升级执行位 = 备战画面,转场后升级先落地,重开时概率档已新档);命中 ∧ 待付窗/未命中 → 会话照常(买牌六序 + 刷新判据;凑金 = 备战侧场景;升级推迟期刷新维持拒绝——资金序声明,11 §3 判据组件行)。
- **席满买入(六步流程)**:商店会话内备战位满时,过判类与金约束的买入牌走**席满买入六步流程**——虚拟置入 + 升星连锁模拟 + 部署重排 + 统一价值序定位,末位为存量牌则店内卖旧、下帧重入买入(单动作契约卖买分两帧);末位为新牌则放弃买入(拦因键 `priority_insufficient`)。判据权威定义 = `11_shop_decisions.md` §4.0;场上角色店内仍禁卖(能力面边界)。

## 2. 会执行的动作清单(收缩后目标形态)

| 动作 | 动作类型/op 载体 | 触发判据(指针) |
|---|---|---|
| 买牌 | `BuyCard` → `operations/cw_op/cw_buy_card_action.py::CwActionBuyCardOp` | 六序判类 + M2 义务 + M2b + EV 买面(§1 候选买入评估行);席满 = 六步流程(§1 席满买入行) |
| 卖备战 | `SellBench` → 卖备战动作 op | 六步流程卖旧(末位 = 存量牌)/会话内筹资伴生卖出(§1 席满买入行;判据 = 11 §4.0) |

| 关商店 | `CloseShop` → `cw_close_shop_action.py::CwActionCloseShopOp`(**结束本次访问**) | 收工判定(§1);升级转场关店(§1 升级意图出口行) |

## 3. 能力 vs 策略(在案判例)

- **判例(用户裁定 2026-09-14;2026-10-17 迭代申报;收缩判例废止见 11 §4.0 通道重映射行)**:「卖备战收缩至备战期」的 2026-09-14 判例**已废止**——店内卖备战席为在产动作(席满买入六步流程的卖旧与会话内筹资伴生卖出都在店内发生,§1/§2);买经验的商店域**发射面已随 2026-10-17 迭代 T-1/T-4 退役**(升级执行位 = 备战画面;商店会话保留升级意图出口转场关店,§1;注册表双类型行退役,单一备战注册行)。场上角色店内仍禁卖(能力面边界)。
