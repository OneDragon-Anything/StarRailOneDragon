# 货币战争-投资环境(3 选 1)

简报后的第一个策略决策点:从 3 个投资环境里选 1,决定本局阵营/角色走向。

## 何时出现 + 状态流转

- **入口**:简报「下一步」→ 位面教程叠层(「点击空白处继续」点空白)→ 本屏。
- **出口**:点一张卡选中 →「确认」→ 备战阶段(Plane 1 Round 1)。
- 每个位面开始可能再出现(剩余次数 = 本局还可选几次)。

## 识别特征(稳定锚点)

- 独有文字:「投资环境」标题 + 3 张卡(概念股 / 特邀专家)+「剩余次数」+「确认」。
- 卡片标题如「XX 概念股」「特邀专家：XX」。

## 可交互元素

- 3 张卡:左(≈x347)/ 中(≈x868)/ 右(≈x1388),卡身点击选中。OCR 读卡标题 + 描述。
- 「确认」按钮:(1055,968)底部。OCR 可读。
- 「剩余次数：N」(本场 N=1)。

> 全文字(卡标题/描述/确认),OCR 可读,无 screen_info / 模板需求。`battle_loop` 的 `INVEST_ENV_CARD` 点中牌(朴素)。

## 关键数据(策略相关 —— bot 当前朴素选,是策略缺口)

> **策略缺口**:bot 现在固定点**中牌**(`INVEST_ENV_CARD=(900,700)`)。应读 3 张卡 → 按 `faction_priority` / `target_comp` 选最强阵营概念股或关键角色专家(`select_comp` / `decide_event` 白名单待接)。

- **3 选项(本场实例)**:
  1. **昼之半神概念股** — 开局得【昼之半神】角色 + 初始简易装备,昼之半神角色刷新率提高。(阵营 buff)
  2. **特邀专家：银狼** — 首次得【银狼LV.999】时,银狼以专家顾问加入商店。(关键角色)
  3. **列车同行概念股** — 开局得【列车同行】角色 + 装备,列车同行刷新率提高。(阵营 buff)
- **投资环境池**:米游社 V4.4 共 74 个(详 `docs/game/currency_war/data/investment_envs.md`),每场随机出 3。
- **剩余次数**:本局还可选次数(本场 = 1)。
