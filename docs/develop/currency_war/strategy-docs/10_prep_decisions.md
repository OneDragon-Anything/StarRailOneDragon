- **M5 开局板面部署**：开局四人组按过渡体系上架；开局形态按 K 分流——K=直通线 ⇒ 按该线开局配方执行，K 未定 ⇒ 四体系过渡配方不变。

- 部署候选排除"场上已有同名同星"（不可达状态）。
- 吸伤害位互斥（符玄分摊 vs 万敌独占 vs 反震载体）——comp 知识声明，站位机执行。
- **残余补部署（P24）**：空 cap 槽上任意合法单位 ΔEV≥0（"有羁绊的板 > 空槽"）——零支出严格支配整轮禁运，无条件先于一切 EV（01 §3.8）。

### 2.1 工具使用判据（7 件；收编自原 11 号件——需求定义，自动化未实现）

> **状态：需求定义稿**——工具消费的自动化现状为零（执行链只有识别与记账：owned 快照含工具、发放埋点在；无拖曳/使用判定/消耗对账）。本节为未来实现批的定义。

**三道门（所有工具共用的统一账）：**
- **门 A 到货不规划**：工具一律来自投资牌/门户/奖励发放，发放时刻不受控 → 只在「读板发现 owned」那一拍评估一次，不进跨轮计划（与 P14 定理 4「不可规划」同一结构性理由）。
- **门 B 价值面唯一账**：工具动作不花金 → 金面（凑息账）恒空转，不过破息门；经济审只查一件事——被操作/产出的装备在不在目标需求向量（key_equips 命中或 component_demand 正份额；「连组件都当不上」= recycle_qualified）。派生金（如持有精密扳手后再获普通扳手改得 1 金）按息律通则搭车，不影响操作本身。
- **门 C 不可逆性分级**：六件一次性、精密扳手无限次；一次性工具证据要求更高，实现必须带执行后验证（sim 行为锁 + 实机遥测各一道）。

| 工具 | 何时用 | 何时不用 |
|---|---|---|
| 冶金炉 | owned 基础件 ∈ recycle_qualified（死库存换 1/36 机会，P14③ 严格不亏）；回收流水线终段：3 件无用进阶穿在死库存工具人身上一次「同刷+全拆」（P14②，吞吐 3:1）。触发预期极低——炉不是获取通道只做转化 | 件在任何目标配方内（component_demand 正份额→留作合成）；key_equips 空（None→空集，一律不动）；被拖角色有 [24] 待迁资产（先扳手后炉）；凑息账不拦（门 B） |
| 拆装扳手 | 重摆迁移：过渡退场装迁核心（[24] 常态）；**去向登记制**——每件取下物须落位 ①重穿给需求向量内角色 ②回 owned 囤，无去向 = 不拆 | 被拆者是核心/key 持有者（r70 过渡持有）；去向登记不满足；单件且角色可卖时卖角色更省（装备无角色间直拖通道——机制实锤，转移唯一途径=卖人重穿或扳手批量） |
| 精密扳手 | 拆装扳手判据的超集——取下成本 ≈ 0 后宽用（错排纠正随手修、迭代型重摆全程免费） | 同「还需不需要」唯一闸；1 金红利不构成用/不用的理由 |
| 员工/完美投影仪 | 配方对上的低费缺件且商店再遇期望高（[22]③ 弃购账镜像：低费自然回 7-15 轮可等则不复制，3 星线关键低费再遇 q 低则复制赢）；完美版专用面=高费贯穿件被锁线点名但未刷出，复制进 bench 吃升星/羁绊进度。**前提三件**：bench 有槽、目标在需求向量内、星级未满 | bench 满（或腾挪挤掉更高价值囤件）；商店常见低费散件（买了可压库，复制不压库）；目标不在需求向量（复制散件=制造死库存，污染回收准入账） |
| 好运令牌 | 缺件 y ∈ K ∩ R(c) 时 0 轮定向白拿，支配一切通道（P14④ 支配序之首，等效价 13.3-23.3 轮）；**R(c) 表未实测前不自动拖**，保持人工/哨兵核对档 | y ∉ K；R(c) 未建档宁不用不猜（门 C：四选一选错整件报废） |
| 特权赋予卡 | key_equips 显式含特权件（特权类无常规获取通道——P14 Q4，合成/炉/令牌均不可达，特权卡是唯一通道）且对应进阶成品在手（装备栏拖法精确配对）；或已穿目标进阶就地升特 | key_equips 无特权目标（留着不衰减）；阵容定型前进化非目标进阶（[29] 同源：锁线前不耗不可再生资源） |

**sim 红线**：sim 不建模装备战斗效果且补给池不含工具 → 工具件的一切 sim 判据只能是**行为/账面指标**（是否按判据动、owned 流向符合去向登记），严禁用 hp/胜率/出口金评价（对装备操作天然无感，假阴性）。实现准入顺序建议：UI 建档（工具 icon 拖曳）→ 炉准入+扳手闸（sim 可验先行）→ 投影仪/特权卡 → 令牌（等 R(c) 采集）。
