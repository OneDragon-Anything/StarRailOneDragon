## 2. 样本量与 seed 策略

- **双侧同 seed 配对矩阵:40 seed/侧**(seed = 0..39,`--pool snapshot` 同池)。40 > 30 下限:主指标含 4 个率类指标,非劣界 −5pp 下配对设计 40 对约 80% 功效检出 15pp 以上真实劣化;配对消 seed 间方差,残余方差来自决策分支分叉。
- **重放要件缺一不可**:两侧 `pool_fingerprint` 一致(manifest 逐字核对,跨日必核);digest/轨迹级两侧钉 `PYTHONHASHSEED=0`。批次 run_id 后缀 `_s<seed>` 即配对键。
- **统计口径**:每指标算配对差 `Δ = 新层值 − 旧层值`(逐 seed 配对;率类指标 Δ 为配对差比例)。**非劣判定 = Δ 的 95% 置信下界 ≥ −δ**(δ 见 §3;正态近似,率类用配对 bootstrap 1000 次取 2.5 分位)。两侧同 seed、判据对称,无单侧 I 类膨胀问题——6 指标全部过才算过。

## 3. 通过线(「不劣」的量化定义)

**判总则:6 个主指标全部满足非劣界 → 过线;任一不过 → 不过线,无综合折算、无补救重跑换样本。**

| 指标 | 非劣界 δ(允许新层比旧层差的幅度) | 小劣理由 |
|---|---|---|
| M1 存活通关率 | −5 个百分点 | sim 战斗结算为校准层(cw_battle_calib 参数注入),单局方差大;5pp 内不构成实质倒退证据 |
| M2 P2 入口率 | −5 个百分点 | 同上;P2 备战 sim 结算键仅 3 维(边界声明),低精度指标放宽 |
| M3 成型达成率 | −5 个百分点 | 新层事件面/换线机全量启用(01 §4.9),初期行为搜索期允许小幅成型让步 |
| M4 末轮成型度 | −0.05(0..1 量纲) | 同 M3 |
| M5 花费率 | −0.05(新层不得比旧层低超 0.05;升高是好事) | 经济纪律重构期允许小幅回落 |
| M6 空转轮占比 | +0.05(升高不得超 5pp) | 同 M5 |

**「险胜不算过」同样适用**:某主指标 95% CI 下界落在 [−δ, −δ+0.3δ] 贴线带内 → 该指标记「贴线通过」,呈报必须单列,不得写成干净通过。

## 4. 哨兵红线效力

任一哨兵(S1–S5)越线 = **A/B 不通过**,无论主指标多好。哨兵不设 δ 折中、不看分布尾部修饰。哨兵越线时流程:按 sim-testing「找问题」三步挑最差局归因,修的是实现缺陷还是建模边界,结论写进度账本;归因不清不得重跑换样本。

## 5. 过程纪律(A/B 期间)

1. **双侧策略代码冻结**:从本锁钉死到 A/B 出数,`decision/decision_v2/` 与 `cw3/`(含其共享 kernel 消费面)禁改;sim 基建非改不可时(如发现崩溃级 bug)= 本锁作废,修完重新锁、两侧同新环境重跑全量,**不得只重跑单侧或单 seed**。
2. **指标定义歧义 = 作废重锁**:中途发现任一指标字段口径有歧义(如 form_ok 语义两侧不同源),当场停跑,修订定义、更新本锁版本号(文末修订表),全量重跑;禁止边跑边改口径、禁止对已出数据补丁式重算。
3. **判读脚本先于数据落盘**:A/B 启动前把 §1–§3 口径固化为统计脚本并提交到批目录旁(非生产代码路径),跑完只执行不修改。
4. **结论兑换(strategy-work §4)**:出数即裁——过线→批 1b 删除旧包放行;不过线→定位归因或声明该维度 sim 不可信(查不清=不进批 1b)。
5. 禁跑完看数据后以任何理由追加/替换指标、改 δ、改 seed 数;本文件为唯一判据源,判读引用一律指向本文档条目编号。
