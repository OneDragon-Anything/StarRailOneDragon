# 补给统一优先级（supply-unified）设计总纲

## 0. 目标与裁定

**用户裁定（2026-11-01，裁定五）：补给不能搞自己的特殊逻辑，要沿用统一优先级。**

铲除补给域三件耦合遗留（母迭代 attack-x-tail-fix.md XT-3/XT-5 + 根治 agent 上报件申报）：

1. **传参断线**（supply.py:190-197）：补给评估构造 v_frame（候选牌置入虚拟备战位）后调 `select_deployment(v_frame, prep)` **未传 virtual 参** → 部署定型读真实容器、虚拟局面被静默忽略——「买下候选后板面会怎样」从未算过候选。与模块「与商店牌同一逻辑」声明矛盾。
2. **同名凑星候选优先 = 域特例**：候选牌借档 1 按名命中排高位（出处 = 已退役旧迭代凭据⑦，现行正本无人认领）。按裁定五退役——候选 = 假设性入场者，与商店 X 同款不进档 1 保护（母迭代 1c8efbfb0 已立商店侧先例；XT-7 实证减名对存量件无操作）；**同名凑星的价值由档 2 升星主线承载**（候选是成员星目标推进件 → 按卡面落档 2，天然排高——特例退役不丢价值）。
3. **两域分叉申报作废**：母迭代 30 号篇「同源禁分叉」条文的分叉申报（XT-3 承载）随本迭代替换为**统一语义**——两域同一条优先级装配路径。

## 1. 改动点

1. **supply.py 传参修复**：`select_deployment` 调用正确传虚拟参——统一评估链真实消费候选置入的虚拟局面。
2. **统一装配 = 候选评估装配整函数提取〔SU-1 定切面〕**：v_copies 构造（supply.py:200-204 ≈ shop.py:1192-1196 逐行拷贝段）+ 部署外全集池构造 + deployed_names 减候选名——三段一体提取为共用入口，两域调同一实现；**域参数仅两枚 = 候选费用（商店 X 带费 / 补给零成本）与触发语境**，其余语义一律同源。**补给池从「只扫 bench」统一为部署外全集**〔SU-3 比较域缺口闭合：field 撤下件入池，与商店同款——「只扫 bench」本身即域特例〕；supply.py:206 dict 冒 frozenset 注解随提取自然修复〔SU-信息〕。
3. **特例退役 + 行为变化申报〔SU-2 两口如实申报，撤回「不丢价值」全称〕**：候选档 1 按名命中路径随统一装配自然失效；供给侧排序/淘汰判定全链按卡面八档。**申报一**：非成员/已 2★ 候选的凑星优先无承载（档 8 键无聚合星级分量，priority.py:460-462）——裁定五后果：统一序下非成员凑星不优先（成员星目标推进件经档 2 承载的口径不变，档 2 用例须用成员名接线〔SU-5〕）。**申报二**：席满全好牌帧，同名第 2 张候选与在手件全子键并列（1★ 全额退 → 退金损失恒 0）时被 in_hand 旗标压末位淘汰——「攒素材」行为翻转，方向可辩护（避开溢出席记账黑洞），申报不回避。
4. **测试**：`test_merge_star_tiebreak_spans_bench_and_rows`（旧凭据⑦语义）期望翻转——同名候选不再因同名排高，按卡面档定序（凑星价值经档 2 承载的用例保留/改写）；新增反例：候选被虚拟定型收编仍可淘汰（母迭代 X 反例的补给镜像）；传参修复后「虚拟定型含候选」前置断言。
5. **正本**：30 号篇 §2.1 分叉申报 → 统一语义声明（含凭据⑦出处勘正：旧迭代验收凭据已退役，现行权威 = 裁定五 + 档 2 承载）；母迭代 XT-2 附带（八档逐档表 01↔11 落点互指）顺带清定。

## 2. 边界

- 补给画面流程/场景/动作零改（只动评估的优先级消费面）；
- 统一优先级本体（priority.py 八档）零改——减名装配是评估输入侧既有模式（1c8efbfb0 先例），非新机制；
- 商店侧行为零变（提取共用件为纯重构，shop.py 现行测试全绿为验收）；传参修复后补给评估比较域扩为部署外全集（field 撤下件入池——行为面申报）；帧 A 现行绿机制（飞霄候选档 1 命中，reason 键首档=1）随特例退役〔SU-3 实证〕；虚拟面板无系统件过滤 = 商店既有相邻面，补给继承，登记不立案〔SU-信息〕。

## 3. 验收

- 补给与商店评估对同一虚拟局面产出同一排序序（**行为断言**——「单一实现结构性检查」撤销〔SU-4：源码扫描禁令无合法测试形态〕）；
- 同名候选按卡面定序（档 2 承载凑星价值的用例绿）；候选可被淘汰（反例绿）；
- 商店侧既有测试全绿（重构零行为变）；CW 快速集零非申报面红；
- 30 号篇统一语义声明入档。

## 4. 关键取舍

- **备选：补给候选保留同名优先、仅修传参** —— 放弃：修传参而不退役特例 = 商店侧 X 收编 bug 在补给侧原样复发（候选进虚拟定型 → 档 1 自我保护 → 永不淘汰），与裁定五相抵。
