# 白厄（物理·毁灭·5星）

> 按 V4.7 期撰写。变身单挑王：终结技变卡厄斯兰那，队友离场独享战场。

## 一、命途属性与技能说明

**命途**：毁灭（黄金裔——昔涟 A2 计数含黄金裔）；**属性**：物理

| 技能 | 说明 |
|---|---|
| 普攻 | 单体150%攻击物理伤 |
| 战技 | 扩散150%/60% +2火种 |
| 终结技 | **消耗12点【火种】（不走能量；成为任意技能目标+1——队友「传球」充能）**：变身卡厄斯兰那——队友离场、8个额外回合（60%基础速度）、攻击+40%/生命上限+135%/攻击后回20%生命/免控；最后回合480% AoE 均分 |
| 强化战技【弑魂之炽】 | 变身期：敌方全体**立即行动**→每次行动叠层触发反击（20%+4×15%，每层+20%倍率）——逼敌行动的反击流 |
| 天赋 | 火种获取+变身增益（详见终结技） |
| 秘技 | —（以官方文本为准） |

**资源与循环**：火种不走能量——**充能词条零收益**；队友对他用技能=充能。

## 二、推荐遗器与原因

**套装**：贪噬禁果的异端4件 + 坠星启航地2件【攻：直伤口径】
**主词条**：躯干暴击率/暴伤；脚部速度；球物理伤；绳攻击%。
**副词条**：双暴 > 攻击% > 速度。
**变身期吃不到队友增益（队友离场）——开大前先铺 buff。**

## 三、推荐配队与原因

| 阵容 | 为什么 |
|---|---|
| 白厄 / 增幅位×2 / 生存 | 变身前铺 buff、变身后独享输出 |
| 黄金裔体系 | 昔涟 A2 计数（黄金裔队友开战+追忆） |

**硬否决**：变身期与「队友行动期增益」体系天然错开（辅助增益需前置）。
