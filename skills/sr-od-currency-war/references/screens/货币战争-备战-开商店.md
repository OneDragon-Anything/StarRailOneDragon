# 货币战争-备战-开商店

**识别**：`is_precise` 命中 `货币战争-备战-开商店`；extras：shop_cards（五槽：名称/阵营/费用/星级）/gold/levelup_cost/refresh_probs。
**目标**：花金币（买牌/买经验/刷新）。
**能做的事**：
1. 买牌：`CwBuyShopCardBySlot {"slot":1..5}`（星级越高费用 ×3/×9）。**备战席满时本 op 静默失败（实测 2 次）**：无报错、金币未扣、牌不入席——买牌前自查 extras.bench 有 empty 槽才买。**合成规则——两次实测观察矛盾，双记不单边采信**：观察 A（上一局）——场上同名不参与合成（场上桂乃芬 + 买 2 张同名 = 不合成；拖备战席同名到场上同名 = 无反应），仅备战席内集齐 3 张同名才合成升星（1★/2★混合疑似也合成），落点 = 备战席内；观察 B（本局）——同名副本按「场上+席内」全局计数，3 张合 1，**合成落点跟随最高星单位位置**（场上 1 + 席内 2 → 场上升 2★；席内 3 → 席内升 2★）。两次观察矛盾，条件差异未定位（疑与星级/主角标/试用标有关）——遇同名未合成时按「席内集齐 3 张」操作再验，并读图确认落点。拖备战席角色到场上已占用槽 = 换位（两局一致）。
2. 买经验：`CwBuyXpRepeat {"times":1..10}`（等级 = 部署上限，前期优先；三月兔(奇遇伙伴之一,随开局简报公布)在场时第二位面买经验额外 +1）。
3. 刷新商店：`CwRefreshShopByClick {"times":1}`。
4. 收店：`CwToggleShopPanel {"screen_name":"货币战争-备战-开商店"}`。
5. 看 extras.bench_overflow：「备战席已满」告警横幅在场(True)= 有单位没安置，出战会被游戏忽略——先 CwSellBenchBySlot 卖一个腾位再出战。横幅商店态也可见。
6. **想拖角色上场或出战，先收店**——商店开着时：点击出战只收店；晶矿识别在此画面不可用（reward_ores 键省略）。收店是本画面的收尾动作。
7. 看商店牌详情：点商店牌弹「货币战争-商店卡牌详情」（识别锚 = 「按钮-购买」+「按钮-角色详情」双识别标志同帧）→ 点「按钮-关闭」（×）关回商店；买不买回商店牌操作，弹窗内不代买（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
8. 免战跳过：免战牌激活时「跳过(N/N)」按钮在本画面同位可见——商店开着也能直接点它进战斗（不必先收店）（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
**坑**：战斗结算后自动弹商店是常态（实测）——多数节点回备战直接就是「备战-开商店」态，开店经常是游戏自动的；先 analyze 确认再决定开/收，不要盲目再点开商店。开商店态 front_line/deploy_count 为 null（完整读数收店后再取）；商店态 board 子集可能失真（实测偏差 -1：读 击破1/守护1，真值 2/2）——羁绊计数勿用商店态 board，以 units 全局计数为准。金币 ≥20 时留钱吃利息（结算按存款给利息）。
