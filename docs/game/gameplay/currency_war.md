## 一段概览:一局怎么打(从 research 提炼)

一局 = 3 个位面、每位面多个节点。核心循环:备战阶段商店发 5 张牌 → 花金币买牌 / 刷新 / 买经验升等级(**等级 = 上阵人数上限**)→ 配前台(作战)/ 后台(支援)站位 → 出战自动战斗 → 按节点结果扣血推进。水平的分水岭在**经济**:利息按金币档位(10 的倍数)结算、50 金封顶 5 金/轮([user_playstyle](../currency_war/research/user_playstyle.md) [17]),「守息」与「该花就花」的节奏纪律贯穿全局(同篇);**位面 1 靠过渡阵容**——四种过渡体系两两组合,活到成型即停手攒息([transitions](../currency_war/research/transitions.md) / [transition_combos](../currency_war/research/transition_combos.md));P2/P3 逐步换向**终局阵容**([final_comps](../currency_war/research/final_comps/README.md) 十类)。验收口径不是满血而是「**带经济过位面**」:P1 健康态 = 息基保住 × 形态达标双指标([user_playstyle](../currency_war/research/user_playstyle.md) [28]);血量掉光 = 整局失败(首次归零有保底剩 1hp,见下机制节),第三位面一次遭遇最多扣 70 血(见下机制速查)。

3.7 版上线的**大型常驻玩法**(赛季制,与模拟宇宙交替更新),**类自走棋(auto-battler)+ 肉鸽**。
战斗**自动进行**(非手动操作),玩家专注经济/羁绊策略。⚠️ **每节点战斗有「有限行动值(AV)」限时**(米游社百科 content/6564,用户 2026-08-11 确认,旧记"非限时"误):未在限内消灭全部敌人 → **扣小队生命值**(非判负)→ **输出不足体现为扣血**(扣血越多越可能输出低/超时,与"扛不住"同表现为 hp 降)。→ 输出能力重要(限时内击杀),hp_trend 已隐含输出信号。✅ **结算画面仍显示「通过」该节点**(用户 2026-08-12 确认:超时**仅扣血、结算仍显示通过**,**无节点级失败态**;HP 耗尽才整局结束 —— 见下「失败」)。奖励约 4000 星琼 + 深度沉浸器 + 助燃券。

**★结算屏「通过质量」有带符号记录(用户 2026-08-18 点破:「扣血其实就是战斗失败,这个玩法里应该有记录的」)**:每轮结算屏记录该轮打得怎么样,是胜负+扣血的**游戏内真值源**:
- **「挑战进度 ±N」带符号值**:正 = 完成度高(干净赢,如遭遇 +2);负 = 未完成(输出不足被扣,如 2-1 -22)。注意「挑战成功」屏另有**无符号累计值**形态(「挑战进度 46」= 总进度,非本轮 delta)。
- **扣血明细**:「基础伤害 -N」(敌方存活单位)+「未完成进度伤害 -N」(进度未完成的惩罚)—— 扣血公式实锤(live 2026-08-18 11:32 OCR:遭遇轮 基础伤害-5 + 未完成进度伤害-2)。
**周期(双周)积分每双周周一 04:00 重置**。解锁:开拓等级 21+。入口:手机菜单 → 指南(星际和平指南)→ 旷宇纷争 TAB → 货币战争。

## 玩法机制(攻略 + 实机)

### ★核心伤害与数值机制(UP 必修一 + 阵容档交叉核实,2026-08-12)

- **伤害公式 = 既有公式 × 三个 CW 新乘区**(详 [公共_核心机制](../currency_war/sources/V3.7_公共_核心机制.md)):
  1. **前后台强度**:站前台吃「前台强度」、站后台吃「后台强度」(**只看站位,与角色前后台定位无关**);伤害倍率贡献 = `强度值 × 1%`(前台强度 500 → 该角色伤害 ×5)。
  2. **伤害征服**:独立增伤乘区(类似增伤但独立结算)。
  3. **幸运一击伤害征服**:「幸运一击」类似第二层暴击率,触发时此乘区生效。**幸运一击与暴击独立计算**(显示「幸运」= 幸运暴、暴击没暴;「暴击」反之;「幸运暴击」双暴;无字双都没暴)。**幸运一击暴伤基础 100%**(普通暴击仅 50%)→ 收益更高。
  - **稀释**:前后台强度稀释最重;**伤害征服 + 幸运一击稀缺、提升大** → 优先堆后两者。→ 解释「火力风暴潮(伤害征服装)/ 幸运一击装」是各主 C 核心。
- **★CW 速度增幅独立乘算(非加算)**:大世界/深渊速度词条加算(被高速稀释),CW 中速度增幅独立乘算 → 高速角色(阿雅 400 速)吃等额比例加成。是 CW 全模式底层规则,解释双鞋风扇 / 高速流(阿雅/流萤/海瑟音)强度([阵容_阿雅昼神](../currency_war/sources/V3.7_阵容_阿雅昼神.md),🔴 跨阵容规则)。
- **★CW 后台仪器/光追/行迹不生效**:后台角色只吃「后台强度」+ 羁绊,**自身仪器/光追/行迹全不生效** → 决定谁能后台(需自带面板/被动)谁能前台(吃仪器)。停云等「必须前台才能神力解放」即此理([阵容_波提欧击破](../currency_war/sources/V3.8_阵容_波提欧击破.md),🔴 底层规则)。
- **血量与星**:**70 血 +3 星、40 血 +2 星**(血掉完不加也不掉)→ 高血量 = 多拿星 = 快上分,呼应「100 血通关」目标。未完成战斗 → 按节点位置 + 挑战进度扣血(节点越后、进度越低扣越多)。⚠️ **第三位面遭遇关勿逞强打 7-3/7-4:一次扣 70 血**。

- **对局类型**:标准博弈 / 超频博弈;通关奖励 = 周期积分(18000 上限)+ 晋升点(如 2700+1500)。周额外晋升点上限 1500。(⚠️ 易混口径:此处「晋升点」= **单局结算的段位分数**;与大厅「晋升等级」(段位刻度 A1-A8,亦由晋升点累积而来,赛季 V4.4 上限 170)是两个物——前者是分数、后者是刻度,bot 特征面均不消费(易变值)。)
- **职级/难度(两阶模型;详 [strategy/06 信息模型](../../develop/currency_war/strategy/06_input_model.md))**:
  - **职级 `selected_difficulty`**:段位 黑铁→青铜→翠钢→钴银→冰肽→紫金→投资大师→资本帝王→**财富造物主(A8,最高)**。V4.0 扩到 **A8-1 ~ A8-50**(子档,如 A8-50)。**决定起始敌人难度** + 是否带额外敌人词缀。选难度在「开对局确认」屏。
  - **敌人难度 `enemy_difficulty`(数值)**:**随节点推进递增**(节点类型不同曲线不同:遭遇/奖励/首领;V3.8 调过 —— 削遭遇敌人攻速攻击、提奖励节点奖励)。**可被投资策略压低**(「难度修改器」银 −4、部分金 −3,**最低降到 0**)。boss 血量 ≈ `base × 1.052^enemy_difficulty`(每 +8 难度 ≈ +50% 血;A8-60+ 血量几十~上百亿)。
  - **难度↑ 的后果**:敌人属性(攻/速/血)↑ + 额外敌人词缀。「第一位面最难」(A8 一层遭遇常比 boss 凶)。
  - **★节点类型 × 战力要求(2026-08-12 用户知识)**:**奖励节点 = 无战力要求,出战必过(白嫖奖励)** —— 不需为奖励关堆战力/买牌,该把金币省给成型节点。⚠️ **例外:经济过热/严重过热投资环境把奖励节点 → 次元/超级次元扑满**(扑满关**有**战力要求,要打;且**不掉血**——扑满关自身机制,与 0hp 保底无关,应对口述见 user_playstyle [16] 注记)。其余节点(战斗/遭遇/首领)均有战力要求(限时 AV 内击杀,输出不足扣血)。
  - **★奖励节点清关奖励 = 奖励球(晶矿)面板(2026-08-14 live 建档)**:通关奖励节点后,备战右侧「区域-奖励」面板出现球形奖励(实测 1-8 清关:1 大金球 + 5 蓝球 + 2 灰球;球色疑=晶矿档位 ——「黄晶矿工」策略提「低一档晶矿」,大金球开出了工具「员工投影仪」,蓝球开出进阶装备「以太钻头」)。**点球即开启,内容即时入账**:金币/装备直接加;**角色或补给箱落备战席占 1 槽**。⚠️ **备战席满时球点不动**(球可能给角色/箱都要占席)→ 顺序 = **先开补给箱腾席 → 再点球**。晶矿条目见 `cw_factions.FACTIONS` 注册表(「开启后可能获取金币、角色、装备或其它稀有物品」)。
  - **★难度 200+ overflow bug(2026-08-12 UP 实测,[BV1wE3g6cEuU](../currency_war/sources/公共_视频目录.md)V4.4)**:难度可被投资策略/海克斯推高(伟大征服 / 万敌·无废帝 各 **+30** 敌人难度 + 连胜 + 三彩等)→ **超过 200 触发溢出 bug:敌方「攻击/防御/生命值/速度/热性 提高 -100%」→ 怪变脆皮一撞就死**。实测 A850 + 各种加成推到 **211 难度**= 当前版本难度上限。属可利用的边界 bug(非稳定机制,可能随版本修)。
  - 来源:[官方玩法说明](https://sr.mihoyo.com/news/160700)、[V4.0 扩充(A8-30→50)](http://news.17173.com/content/02112026/124720972.shtml)、[V3.8 调整](https://sr.mihoyo.com/news/161414)、[bwiki 投资策略(难度修改器)](https://wiki.biligame.com/sr/投资策略一览)。
- **⚖️ 机制硬约束(全局不变量)**:
  - **场上同名角色禁双**(游戏规则 5.1.7 实测):任何「把角色放上场」的路径必须过同名守卫(单一守卫函数,见 develop 侧);同名在场 → 留备战席待 3合1(合并域=全场 bench+deployed)。
- **★第一次 0hp 保底 1hp(2026-08-25 用户口述,最高权威)**:全局机制——小队生命值**首次**打到 0 时不会直接整局失败,保底剩 **1hp** 继续(仅首次;再次归零=整局结束)。→ ①「打不过的关卡」最坏损失是一大段血而非立即死亡;②策略侧「真死局」判据锚=HP=1(已耗尽保底,再输即终局)——早停/死局检测以 HP=1 为候选线的机制根据。(勿与扑满关「不掉血」混淆——两条独立机制,见上「节点类型×战力要求」例外。)
- **位面**:每局 3 个位面,每位面多节点 + 首领;第一位面带强化词(如「战个痛快」)。
- **备战阶段(核心循环)**:进度 X-Y(位面-节点);**商店**发 5 张角色牌(各带阵营羁绊 + 技能标签 + 价格)→ 花金币买牌 / **刷新**刷牌 / **购买经验**升队 → 配**前台(作战)/后台(支援)**站位 → **出战** → 自动战斗 → 下一节点。
- **备战棋盘槽位(2026-08-09 实测 + 攻略核实)**:**前台(作战)+ 后台(支援)**两排槽位。**上阵数量上限 = 晋升等级**(level 6→6 人、7→7…;队伍总 8-10 人,来源 [游侠](https://m.ali213.net/news/gl2511/1709345.html)/[bwiki](https://wiki.biligame.com/sr/%E8%B4%A7%E5%B8%81%E6%88%98%E4%BA%89))。**槽位布局随投资环境变**:实测某投资环境把后台 6→7 槽(用户确认),还可能 8/9/10(上限待游戏内图鉴核实)。
- **角色升星(自动合成,2026-08-12 官方核实)**:角色初始 1 星;**招募 3 个相同星级的同名角色 → 自动升 1 星**(1→2→3 星;3 星=角色最强形态,大幅提战力)。**自动触发无需手动**(凑齐即合,场+备战合计)。来源:[官方玩法说明](https://sr.mihoyo.com/news/160700)。→ 买重复角色凑升星是核心策略(3 张 1 星 → 1 张 2 星;3 张 2 星 → 1 张 3 星);⚠️ 需判「场上有同名(可能已高星)+ bench 不够凑齐(需 3 张**同星**)」时该买**新角色**补板,非重复占 bench。
  - **★三星五费 ≈ 无敌**:直接给 **2000 前后台强度 + 300% 速度征服**(其他费用三星中规中矩),但需特定投资环境/策略、手低几乎不可能([公共_核心机制](../currency_war/sources/V3.7_公共_核心机制.md))。
  - **★银狼LV.999 升星升费(2026-08-15 用户口述 + 攻略广场数据佐证)**:【银狼LV.999】**初始 3 费**;升到 **3 星后拖到场上 → 变 4 费 1 星**,4 费升满同理再变 **5 费**;**备战栏中不升费**(拖上场才触发)。游戏数据侧佐证:攻略广场 config 的 role_list 里银狼LV.999 有**三条档位条目**(id 15061/15062/15063 = 3/4/5 费)。→ 银狼是**成长型滚动投资**(低费买入 → 升星 → 升费滚强度),备战栏囤多张时费用不升。(变费同型异源:投资策略「飞光·映月」也驱动费用变换——特殊 1 费景元随镜流星级变 3/5 费,属**策略赋予**非角色固有,详 research/economy §2.1。)
  - **★银狼「我来当策划」策划事件(2026-08-20 用户口述,局29 P2r6 实证)**:银狼**首次升 2 星**时触发「我来当策划」overlay(标题+「请选择一个骇入效果」二选一卡):
    - 选项内容随事件变:**首次(2星)**=「升费(提升费用至 4 费,变为 1 星银狼)」vs「其他(如破解芯片=后续节点弱化/专属装备)」;**5费升 2 星也会触发**,但两个选项**都是装备**(费用封顶,无法再升)。
    - **升费选择后,新费用的银狼会刷新在商店里**;若未选升费,银狼**停留在当前费用档**(此机会只在首次升 2 星出现,错过不补)。
    - **识别侧**:overlay 标题「我来当策划」+「请选择一个骇入效果」(画面 货币战争-骇入策划 已建档);选项文字 OCR 读卡内容判「升费 vs 其他」——「提升费用」字样=升费卡。选卡后可能自动弹「属性详情」面板(银狼详情),需关掉(右上 ×)。
  - **★开拓者双形态(同一角色·两种形态·位置决定生效,2026-08-15 用户口述)**:开拓者是 CW **最独特的存在** —— **前台形态=「开拓者·记忆」、后台形态=「开拓者·欢愉」**,同一角色的两种形态在**不同位置下生效**(拖到前排走记忆形态/放后排走欢愉形态),不是两个独立角色。欢愉形态特征:技能「喜剧开场」、召唤【阿哈】(欢愉羁绊描述:备战阶段召唤阿哈为小队提供增益,装备最多的欢愉队员在阿哈时刻的欢愉技会立即重复施放一次)。游戏数据侧佐证:攻略广场 config 把两个形态建为**两条目**(id 8007=前台「欧拉!」is_hide / 8009=后台「喜剧开场」可见),trait 同为 列车同行+能量+欢愉(共享模板,位置决定生效);bwiki 分立「开拓者•欢愉」」(V4.2 实装,4费/后台/输出辅助)与「开拓者•记忆」(V3.7 实装,4费/前后台/辅助输出)两页。
- **试用角色(角标「试用」,2026-08-13 用户确认)**:角色牌/补给/场上带「试用」角标 = 当前游戏账号**未拥有**该角色 → 用 CW 提供的**试用版**(**面板中等**,非账号自有角色的满练面板)。商店、补给、场上都可能出试用角色。
- **备战席溢出(奖励给角色,2026-08-16 用户实证 + star2__540a8be3 实测)**:奖励(如奖励球开出的角色)在**备战席 9 槽全满**时,角色**不消失而是悬浮挂在备战席最右槽上方**(实测:赛飞儿立绘悬于备战-9 正上方 x~1362-1430,y~700-845 带)。→ 机制含义:①席满时收奖励**不会丢**,溢出角色待席腾空后落位;②「卖一个角色 → 溢出的落进空槽 → 席仍满」是**常态**(卖出 1 + 溢出落位 1 = 净空位 0),破满需 卖 ≥(溢出数+1) 或升级扩容;③识别侧:溢出立绘在常规备战栏 rect **外**,9 槽读数不含它 —— 腾席决策需感知溢出数(画面:备战上方带的立绘数)。
- **阵营羁绊(实测)**:命运圣杯 / 仙舟 / 夜之半神 / 公司 / 银河学者 / 量子 / 击破 / 追击 / 减益 / 欢愉 / 星间旅人 等;技能标签:战技点 / 能量 / 燃血 / 群攻 / 持续伤害。**关键羁绊机制(跨阵容核实)**:
  - **3 量子同屏(花火/银狼/符玄)= 直伤暴击阵容最泛用极高强度插件**(减防/易伤/暴伤/幸运一击全有,3 卡拉满 5 乘区)→ 几乎所有直伤阵容可把不关键牌换 3 量子。
- **deploy / sell 交互机制(2026-08-08 多源实测,玩法地基)**:
  - **deploy = drag(非 click)**:click 备战角色开详情面板(非选中);**长按 drag(hold 0.5s)才拾取**→拖到舞台槽 deploy(注:后续实测中心拖+hold 0 即拾取,见 develop 侧 ADR;此处记「drag 非 click」的交互本质)。
  - **deployed 可卖(纠正「deployed-lock 永锁」误判;D-2 实测)**:deployed 角色可经 **drag→出售区** 卖(含佩佩);详情面板无出售按钮(只能 drag 卖)。→ deployed **非永锁,可 redeploy**(卖 off-target deployed → 腾位),但有代价(失该角色 + 需 bench 有替换)。
  - **board = deployed**(左面板阵营计数 = 上阵羁绊;非 owned);**max_units = level**(deploy 上限,购买经验升级)。**后排>6 条件(D-50,攻略+装备图鉴)**:① **level 9 → 财富宝石 +1 团队槽**;② **财富宝钻(装备,无论是否穿戴)+1**(可叠加);③ **诅咒·宝石剑泽尔里奇 -1**。佩佩/投资策略/环境 = 获取财富宝钻途径 → 后排槽位 6/7/8/9/10 随 level+宝钻动态。
  - sell 途径:备战席角色 → 拖到左下出售区。
- **角色详情面板 = ground truth 身份源(2026-08-09 实测)**:备战屏**点已部署角色** → 右侧弹详情面板,显示**角色名 + 阵营 + 星级 + 携带装备**(实测佩佩:双阵营 击破+夜之半神、3★、「特殊角色携带的装备无法拆除」)。可逐个点开读 deployed 身份。出口:点面板外空白处关闭(⚠️ 勿 ESC——备战屏 ESC 弹「中断挑战」)。子态建档详 [screens/currency_war_prep.md](../screens/currency_war_prep.md)。
