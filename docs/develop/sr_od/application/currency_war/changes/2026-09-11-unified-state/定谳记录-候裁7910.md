## 候裁 7:模块文件名随正名改(cw_board_state.py→cw_game_state.py)vs 只改类名留旧文件名

### ① 候选案

- **案 A(计划倾向)= 文件名随正名改**:类名 BoardState→GameState(正名,W8 名段既定)
  的同时,`kernel/cw_board_state.py` 更名 `kernel/cw_game_state.py`(git mv)。
- **案 B = 只改类名,留旧文件名**:GameState 类住在 cw_board_state.py 里。

### ② 攻击过程与结果:案 A survived

**攻击线一:审查噪声——改名 diff 会混进删除波污染逐 hunk 归属。**
量了:改名机械面 = src 130 行/55 文件 + 测试仓 116 行/48 文件 + docs 133 行/26 文件,
约 380 行。攻击是否成立,取决于它是否**新增量级**——对照同段既定对象:类名正名
BoardState 符号本身 = src 269 行/52 文件 + 测试仓 287 行(git grep -w / Select-String
现读)。模块名面与类名面**同量级、同性质**(纯机械字符串替换,零行为),且 r5 §3 已把
W8 定为「先删后名」两段——两段结构就是为隔离这类机械大 diff 设计的,改名归「名段」,
与删除段审查隔离。攻击提出的风险已被既有波次结构吸收,**未破**。

**攻击线二:在飞批冲突——T-56 测试仓归并批、T-86/T-90 前置设计与 W8 同文件域。**
属实但被时序门挡住:W8 进入门 = T-6 验收绿 + 全仓 GameState 零引用锁(r5 §2 W8 行),
后者只有在 W6 尾波(决策面切换)落地后才可能绿——即 W8 开工时同文件域在飞批已落定。
残余的时序冲突只有一处:测试仓文件名改名(batch3/batch4 是 T-56 归并批对象)→ 不阻塞
W8 主体(文件名≠运行时语义),执行口径给顺延规则(见⑥)。**未破,转化为执行口径。**

**攻击线三:git 考古断裂。** 同目录改名用 git mv,历史随文件走(rename detection);
import 行的 blame 噪声一次性付清。反向核:留旧名不是没有代价,而是把代价改成年金——
每个未来读者「搜 GameState 定义 → 跳到 cw_board_state.py」的错位税,永久收。**未破。**

**攻击线四:「名字不算语义,不值得 380 行」。** 语义检查:仓内既有约定 = 文件名随主类名
(cw_state.py↔GameState、cw_board_state.py↔BoardState、cw_effect_inventory.py↔
EffectLedger 等,全仓一致)。T-7 正名的语义动机 = GameState 成为唯一正名(r5 §3 论证
三条;ADR-0630 后果节逐字锚「迁移完之后将 BoardState 改名成 GameState」)。类名改而
文件名留 = 正名做一半,且**主动破仓内命名约定**——这不是审美,是可检索性:日后按文件
名找类、按类名猜文件的全部直觉都失效。治本核验:错位是约定层根,改名是治本;留旧名
是用「省一次机械改动」换永久错位。**未破。**

**攻击线五:命名撞车。** `cw_game_state` 全仓零占用(git ls-files + src 树 glob 实测);
`game_state/` 是 docs 目录名,不是 Python 包,无模块名冲突。**未破。**

### ③ 案 B 死因记录(先攻后裁,如实记)

案 B 的全部收益 = 省 ~380 行机械 diff(一次性);代价 = 符号/文件永久错位 + 破命名约定
(年金)。攻击未找到案 B 的隐藏收益(无工具链/外部契约依赖旧文件名:grep 全仓,
cw_board_state 无 config/脚本/screen_info 引用;测试三处字符串锚随批更新即可)。
**案 B 被攻破,死因:一次性成本换永久语义错位,方向与正名裁定相反。**

### ④ 定谳结论

**裁案 A:文件名随正名改,cw_board_state.py → cw_game_state.py(git mv,历史保留)。**
