## 一、发现的问题(按严重度排序)

### R6-1(高)R5-5 端点纪律两处方向错误:F7 被归入 CI 下端组;P1 窗口「一律下端」越界覆盖卖面

**位置**:IMPL_DESIGN §2.10 第 3 条(R5-5 段)——「不可逆 XP 面(M3 破息批解锁 floor_eff=0、**F7 禁令反转**)判『λ>0 段』须用 CI **下端**」;同段 P1 期对策「P1 窗口内段分类**一律**用 CI 下端」。

**缺陷**:F7(sell_for_interest 的 λ>0 段凑息禁令,§2.2)不是 XP 面,是**卖面门**——把它放进「取下端」组,方向恰好反了。

**论证**:F7 的形态是「λ>0 ⇒ 禁止为凑息档卖出」。设段分类判定量 λ̂,禁令触发集 = {λ̂ 判入 λ>0}。取 CI 下端 ⇒ 判入 λ>0 更难 ⇒ **禁令触发更少 ⇒ 更多凑息档卖出被放行**。而凑息档卖出是**不可逆卖出**,且 P51 §7-1 定谳「濒死带卖资产囤金等息是方向性损失姿态」(转化下界 5.8 金/轮 ≫ 息差 cap=5)——真值 λ>0 的状态下放行该卖出正是 P51 判定的损失姿态 = **fail-open 向**。设计自己的分面判据写着「卖面/域修饰沿用 CI 上端(收紧向)」,sell_for_interest 就在卖面,两条规则在同一段落内自相矛盾。按设计自己的单调性论证格式:禁令是卖出闸门的收紧项,保守端 = 使禁令更易触发的端 = CI **上端**;把 F7 列入下端组与「不可逆面取保守端」的判据反面。

同理,P1 窗口对策的「**一律**用 CI 下端」:其正当化句只论证了「不可逆 XP 面按已知偏差方向取保守端」,但「一律」把卖面上端消费(F7 禁令、λ>0 域修饰收紧、L-R3-1 推论 2 的 V_power λ̂ 上端)在 P1 窗口内也压到下端——先验偏差方向(λ 高估)对卖面本该与 XP 面反向取端(卖面保守=高估 λ),一律下端把卖面的保守端丢掉了。

**修法方向**:①把「F7 禁令反转」从下端组移到上端组(卖面),§2.2 F7 行同步标注取端;②P1 窗口对策改为「P1 窗口内**不可逆 XP 面**用 CI 下端,卖面上端消费不变」,删「一律」;③§5.2 注②与 §5.3 floor_eff 投影行的 P1 场景描述同步收口。

### R6-2(高)dominance_buy 落位三处漂移:§2.1/§3.1 仍把支配族放 criteria/EV pass,§4.2.1 已移 mandate 邻接位

**位置**:§2.1 买表首行 `dominance_buy()`(标注「最先执行」,无 mandate 邻接说明);§3.1 执行序 EV pass 行「criteria/* 按 §2 映射逐面追加(**支配族最先**)」;§4.2.1 枚举表 `buy.dominance_buy` 行「**不旁路,移 mandate 邻接位**(M2 前置支配买入结构位,**发射标 mandate=true**)」。

**缺陷**:同一函数在文档内有两个互斥落位——§2.1/§3.1 说它在 criteria 层、EV pass 内最先执行;§4.2.1(R5-4)说它已移入骨架侧、mandate=true、臂①不旁路。

**论证**:这不是表述瑕疵,是实现分叉点。实现者按 §1 模块树 + §2.1 映射表落码(这两处是「落码映射」的权威表),dominance_buy 会留在 criteria/buy.py、随 EV pass 在臂①被旁路;而 §4.2.1/§4.2 明确要求臂①保留支配买入(R1-11:旁路它 = 臂①濒死段失去 L-R3-4 命题 3 声明的转化通道、命题 A 判读被污染)。两个权威表指向不同行为 ⇒ 臂①要么错误旁路支配买入(命题 A 被污染),要么 mandate 遥测标记错位(L-B5(a)「臂①行内 mandate=false 计数=0」的哨兵语义随之漂移)。fuel_sell 的同类迁移(R2-2)在 §2.2 行内显式写了「落位 mandate 邻接位,非 criteria 项」,dominance_buy 的 §2.1 行缺同款同步——R5-4 改了枚举表没回写映射表。

**修法方向**:§2.1 dominance_buy 行补「落位 mandate 邻接位(M2 前置,mandate=true,R5-4),criteria/buy.py 不实现」;§3.1 EV pass 行「支配族最先」删除或改为「(支配族已移骨架 pass)」;§1 模块树 criteria/buy.py 注释同步。

### R6-3(中)L-R3-1「fail-closed 恢复」的真值口径停留在 λ₃ 模型内:P51 自标「视界 3 = 下界方向」,V_power 对真实死亡敞口仍是下界 = 残余 fail-open 通道未声明

**位置**:IMPL_FIX_LEMMAS L-R3-1 Part 2 恢复证明及推论 2;IMPL_DESIGN §2.2 line_switch_sell 行「fail-closed 恢复」。

**论证**:恢复证明的结构是 λ̂(CI 上端)≥λ_true ∧ Δ息流̂≥Δ息流_true ⇒ RHS(估计)≥RHS(真值)⇒ 估计卖集⊆真值卖集。这里的「真值」是 **W_floor=λ₃×(g+Φ) 模型内**的比较式真值。但 P51 溯源表明文:「视界=3 轮 |【拟】声明参数 | 敏感性:**λ 随视界单调不减,短视界=下界方向**」。V_power=λ₃×(refund+Δ息流) 中 Δ息流 按 R_截 求和(默认局最长 27 轮),而危险率系数只覆盖 3 轮窗——对跨越 27 轮的息流,真实死亡风险加权应累加后续窗口的危险率(单调不减 ⇒ 更大)。即:即便 λ̂ 取到 λ₃ 的 CI 上端、Δ息流取到闭式上界,V_power 相对**实际过程的卖出惩罚**仍是下界 ⇒ 右端低估 ⇒ 卖出偏易 ⇒ fail-open 残余。推论 3 的「窗口一致性条款」只把 Δ息流与 ΔW_trunc 互锁(算子间同宽),没有对齐「系数窗口 vs 流窗口」的错配。恢复证明把「CI 覆盖失误」列为残余通道,却漏列了这条模型自身声明过的下界偏差通道——「fail-closed 恢复」的结论强度被高估。

**修法方向**:不必改公式(λ 分层表是启动必载的权威,P51 纪律强制分层消费);改**声明**:在 L-R3-1 恢复证明末尾把「λ₃ 视界截断=下界方向(P51 溯源表)」与「CI 覆盖失误」并列为残余通道,§2.2 line_switch_sell 的「fail-closed 恢复」措辞降为「对估计通道恢复 fail-closed;视界截断偏差仍为下界方向」;若要真正封死,可给 Δ息流 乘窗因子上界(如按 λ 单调性外推的多窗口复合上界)或把 Δ息流 截到 3 轮窗内(与 λ₃ 同宽,代价是低估息流项——需重新推单调方向,二者取一,显式论证)。

### R6-4(中)§1 horizon 行自相矛盾:输出列仍把 Φ(未来纯金流)列为对外输出,与同行 R5-7「Φ 数值类型上不可达」冲突;R2-8 Φ̂ 估计器收口后失去消费位

**位置**:IMPL_DESIGN §1 模块表 horizon.py 行——输出列写「R_全局(实际长度)/Φ(未来纯金流)」,同行中段又写「本模块与 lambda_death 对外只暴露①增量算子②区间敞口比较 API——全量 W_floor/W_flow/Φ 数值在类型上不可达(模块私有)」。

**论证**:同一行的 I/O 契约两次陈述互斥。§1 表是实现者建模块接口的依据(「各模块输入输出与单一源指针」),按输出列实现会直接外露 Φ 数值——正是 §5.3「全量 W 不可达断言」要抓红的形态,设计件自己预言了自己的静态断言失败。连带问题:R5-1 把 R09 三表降格为「Φ̂ 的基础流组成下界」,但收口后**没有任何判据消费 Φ̂**(Δ息流走息律递推、敞口比较 API 在模块内部自算)——该估计器的消费位悬空,留着会诱导实现者开一个非法输出口去喂它。

**修法方向**:horizon 行输出列改为「R_全局;Φ 仅模块内部(敞口比较 API/增量算子内部用);对外无 Φ 数值输出」;R2-8/基础流下界的表述改为「Φ̂ 组成说明(内部实现细节),无外部消费位」,或删。

### R6-5(中)line_switch_sell 缺「u/V_ms/V_slot 未标定时」的 fail 方向规格:F6 端点纪律只覆盖标定后

**位置**:§2.2 line_switch_sell 行(消费列含 V_slot/V_opt/V_ms·ΔP̂;fail 列只写了 λ 取端与 λ 表损坏态);§2.10 F6 段(u 双消费位分端——全部预设标定已完成)。

**论证**:比较式右端 max(V_opt, V_ms·ΔP̂·[x∈K′]) 中 V_opt=u·P_miss·C_rescue 依赖 u🔴、左端 V_slot 在 free≤1 时 = max 被阻断动作净 EV(同样依赖未标定量)。当前标定成熟度下(V_ms/u/V_gap 全🔴,§5.2 自己声明开闸数=0 是大概率态)该比较式的两个输入均无载——设计没有规定此时行为:按 0 处理(右端塌缩 ⇒ 系统性多卖 = fail-open)、抛错、还是整体 fail-closed 不卖?对照 §2.1 对 E_rev/E_line 的对称 fail-closed 显式声明和 L-R3-4 附注对 λ 损坏的覆盖,**卖面主不等式的「u 不可算」分支是唯一没有 fail 方向声明的输入缺失面**——而它恰是不可逆动作,是 fail 方向纪律最要紧的位置。实现者落码时必然遇到,遇错即自造方向。

**修法方向**:§2.2 line_switch_sell fail 列补一行「V_opt/V_ms/V_slot 任一输入未标定 ⇒ 该件不新增卖出 + 记遥测(不可逆面缺输入默认不做,骨架层§3.4 镜像;换线塌缩出口整体延迟至标定后)」;并在 §5.2/对拍 2 的开闸条件里把「line_switch_sell 可用」挂到 u 标定完成上。

### R6-6(中)L-B1 步骤 2「机会单调不增」前提未证:部署可创造新配对伙伴,单次极大匹配 ≠ 不动点

**位置**:IMPL_FIX_LEMMAS L-B1(M1′ 定点单次重评终止性)步骤 2:「两分量在 M1′ 过程中都只朝『机会单调不增』方向变化 ⇒ 匹配机会集单调不增」。

**论证**:M1/M1′ 的配对谓词是「能否**与现有件**成对上阵」(骨架层§3.2 M1 原文)。该谓词的伙伴集 = 当前 board 成员;M1′ 部署 A 入板使 A 成为「现有件」⇒ 剩余 bench 中原本无伙伴的 B 可能因此获得伙伴 ⇒ **B 的部署机会被创造,机会集朝不增方向变化的断言对配对型谓词不成立**(W 缩减与 board 填充各朝一个方向走,净效应不定)。于是步骤 3「一轮极大匹配后机会集=∅ ⇒ D(D(s))=D(s)」失效:若匹配器只做一遍基于初始 board 的极大匹配,第二轮在新增伙伴下还能匹配(幂等性破);若匹配器内部把 bench∪board 联合成对考虑,结论才可救——但设计没有钉死匹配器语义,引理前提「在设计真满足」不成立。后果有限(最多漏部署,下帧补上),但该引理打的是【证明】标,证明体有洞。

**修法方向**:二选一并写进引理:①钉死匹配器语义 = 对 (bench∪board)×空位 的联合配对图求极大匹配(证明联合图下单轮即定点);②改结论为「定点需迭代至机会集空,M1′ 限 ⟨E₀, 等待件⟩ 内有界轮迭代」,补迭代终止界(每轮至少部署 1 件或终止,部署总数 ≤ E₀+等待件数 ⇒ 有限)。

### R6-7(低中)L-B5(b) 发散形态②(mandate 标记不同)不蕴含状态分叉,「分歧位之后两臂状态分叉」过度声明

**位置**:L-B5 第 3(b) 步(R5-2 重写):发散判定含三类形态,其中②=「mandate 标记不同的动作位」;随后断言「发散位之后两臂状态分叉(EV 买入改 g/bench/持有、M3 批门/K 轨迹差异改下游)」。

**论证**:mandate 标记是遥测注记,不进状态转移函数。若首个分歧位是「同一动作、两臂标记不同」(形态②),则按 (动作,标记) 对定义的前缀在此截断,但**状态并未分叉**——后续「骨架计数合法地不相等,跨臂计数断言不再成立」的授权在该情形下被错误发放(状态仍相同,逐类计数断言本可继续成立)。前缀段判据因此偏保守(不误报)但「分歧 ⇒ 状态分叉 ⇒ 计数断言失效」的因果链在形态②下是假命题。当前两臂配置下形态②难以构造(臂间差都改动作对象或存在性),但判据是按定义域全称声明的。

**修法方向**:发散判定改为**按动作序列(不含标记)定义**;标记差异单独记一类「标记分歧位」进遥测(L-B5(a) 哨兵本就需要它),不触发「状态分叉」结论。

### R6-8(低)验证计划缺口:Δ息流增量算子(R5-1 核心数值)无对拍锚

**位置**:§5.3 sim 对拍清单(9 项);对照 L-R3-1 Part 2 新增的 Δ息_t 闭式、复合安全界 cap×R_截、执行期现算路径。

**论证**:R5-1 把 V_power 的数值形态整个换成了 λ×(refund+Δ息流),Δ息流 递推(含 e_t 息滚息)是这个新形态里唯一的新数值通道;对拍清单新增过 p̄/V_comp 两锚(R2-11)、加了 W 不可达断言(R5-7),却没有 Δ息流 的对拍项(闭式 vs 逐轮模拟轨迹、复合界 vs 非复合界的保守性方向)。按本项目「证明+脚本锚」的纪律(总纲公理 4/攻击纪律:数值锚点直调复核),该算子无锚 = fail-closed 声明(取上界 ⇒ 估计卖集⊆真值)在实现层无人验证方向。

**修法方向**:§5.3 加一行「Δ息流对拍:增量算子闭式 vs 模拟轨迹逐轮息账(含息滚息场景),断言 估计值 ≥ 轨迹真值 且 复合界 ≥ 非复合界」;锚脚本入 tools/cw/proofs 与 p47_check 同级。
