# ADR-0559: 开局血量初值表——遥测实证先验替代开局 hp=None

## 状态
已实施

## 背景
ADR-0491 废止了「开局兜底 100」假值:开局 hp=None(诚实未知),消费点对 None 一律保守(血线触发不触发/授权位门 fail-closed)。代价是开局若干帧血量决策全盲——而开局血量其实是**可实证的确定值**,不是未知量。

hp0_survey 普查(2026-09-06,`.debug/temp/currency_war/hp0_survey/报告.md`;数据 = 133 局对局档案逐局 p1-r1 读数,主源 settlement,hp_confidence=1.0,decisions.jsonl 2803 帧交叉验证)结论:

1. **基础值恒定**:A8/数值难度 108 下,无修正词缀时开局 hp 恒为 **82**(109 局零方差,覆盖各随机词缀组合);
2. **「开局不利」是唯一实测的确定性修正**:恒 −20 → **62**(7/7 局;效果原文「游戏开始时,小队生命值减少20点」与实测一致);
3. **「时间刺客」不改初值**(仍 82):它经局内周期扣血污染 1-1 读数(实测 r1=44/46,r2 回 84/86),读数污染由既有 hp 下行拒信/复现确认通道(ADR-0431)兜住,不需要新判读面;
4. **难度维度无数据**:133 局全为 A8/108,其他难度是否改变基础值无法验证——诚实标未知,禁外推。

## 决策
开局 hp 初值 = f(词缀集) 的查表先验,接入对账层 `cw_reconcile.reconcile_hp` 的开局分支(读不到 ∧ session 无真值,唯一天然「尚未有真值读数」点):

- 实证档(职级 A8 ∧ 数值难度 108):默认 82;词缀含「开局不利」→ 62;含「时间刺客」→ 82(不另设值);
- 无实证档(其他职级/数值难度,含未读到):维持 None(ADR-0491 口径不变);
- 先验以 `readable=False` 返回(非真读),**不写 session.last_hp_real**——首个真值帧经既有采新路径写回后自然取代先验,禁覆盖真读;
- 词缀识别键 = 简报 OCR 原名(session.briefing_affixes,与 affix_effects_data 注册表同名键);
- 表载体 = 新模块 `kernel/cw_opening_hp.py`(常量 + `opening_hp_prior()`),值单一源在代码。

## Considered Options
- **查表先验接对账层开局分支(选定)**:实证值替代盲区,真读零覆盖,接点天然幂等(分支只在无真值时走)。
- 恢复「兜底 100」式常量:被 ADR-0491 正式废止的假值形态(实测定值非 100 且毒化遥测),禁。
- 接简报屏/GameState 首建等更早点:开局分支前的写入点要么早于词缀读链产生,要么绕过对账层单源,多一处 hp 写入端=双源漂移面。
- 按「词缀组合」分档:同一组合几乎不重复(133 局实证),样本不支持,按「含某词缀」归组是数据支持的唯一粒度。
- 给「时间刺客」设初值 44/46:1-1 读数被周期扣血污染,不是更低的初值(r2 回 84/86 实证),照抄读数 = 把污染固化成先验。

## 后果
- 开局帧血量决策从全盲(None 保守)变为先验驱动(82/62 足够准:零方差实证档);
- 遥测侧开局帧 hp=82/62 且 hp_readable=False,判读口径不变(沿用值/先验均以 readable 位分字段);
- 难度维度仍开放:未来若实跑其他难度,按本表结构补实证档,无数据档持续 None。
