# 对话(dialog)

与 NPC 交谈的画面(**模态**,背景 3D 场景暗化,对话框浮于上层)。底部右侧显示 NPC 名 + 台词 + 若干选项(如「都有些什么好东西 / 我想和你随便聊聊 / 不打扰你啦」)。**不锁光标**(`pc_alt=false`)。通用流程,任何需要与 NPC 交互的 app(trick_snack 购买前 interact NPC、world_patrol 等)都会经过。代码侧又称「交谈」(`TalkInteract` 操作名)。

## 何时出现 + 状态流转

- **入口**:大世界对 NPC 按 F(交互)→ NPC 对话框打开(带选项);或在已有对话中选某项进入下一段。
- **出口**(动作 → 下一态):
  - 选某选项 → 该选项对应结果(如「都有些什么好东西」→ 开商店;「不打扰你啦」→ 退出对话回大世界)。
  - `ESC` → 退出对话 → 大世界。
  - ⚠️ 点右上角图标区(`菜单-右上角返回` pc_rect `1840,25-1895,80`)**不会**正确退出对话(见备注)。

## 识别特征(稳定锚点)

- **无精准匹配**(`screens=[]`):对话画面**未在 screen_info 建模**,analyze 不命中。
- 稳定特征:右下侧 `INTERACT_RECT = 1292,560 - 1878,802` 内有选项文本(NPC 交互选项区);NPC 名 + 台词在底部;背景模态暗化。
- 代码侧:`TalkInteract` 在 `INTERACT_RECT` 内 OCR 匹配选项文本来点击(`src/sr_od/operations/interact/talk_interact.py:17,43`);匹配不到则点屏幕中下方"空白继续"。
- `pc_alt=false`。
- 易变:NPC 名 / 台词 / 选项文本(随 NPC 和上下文变)。

## 可交互元素

| 元素 | 位置 / 说明 |
|---|---|
| 选项 ×N(文本) | 右侧 `INTERACT_RECT(1292,560-1878,802)`,如「都有些什么好东西」「我想和你随便聊聊」「不打扰你啦」;`TalkInteract` OCR 匹配后 interact 点击 |
| NPC 名 + 台词 | 底部(如「货全」+「机会不是天天有…买的越多,实惠越多!」) |
| 右上角图标(白色 X + 金色菱形) | `菜单-右上角返回` area(pc_rect `1840,25-1895,80`);⚠️ 对话画面点此**不退出**对话(见备注) |
| `ESC` | 退出对话(标准) |

## vision 补充(analyze 后多模态看图,OCR 盲区)

- 模态:背景 3D 场景(摊位 / 建筑)暗化,对话框浮于上层。
- 选项带图标(购物袋 / 对话框 / 方形 等)+ 编号标记(1/2/3)。
- 右上角两个图标(白色 X + 金色菱形)—— 即 `菜单-右上角返回` area 覆盖的位置。
- 无 NPC 立绘(仅文字名)。

## 备注 / 待查

- **⚠️ `BackToNormalWorldPlus` 不识别对话画面 → 兜底误点右上角 → 死循环(2026-07-30 实测)**:对话画面未在 screen_info,`back_to_world_plus`(`src/sr_od/operations/back_to_normal_world_plus.py`)的画面分流(模拟宇宙 / 大世界 / 菜单 / 逐光捡金 / 列车补给 / 战斗)**不含对话** → 全部不匹配走 fallback(line 140)点 `菜单-右上角返回`(pc_rect `1840,25-1895,80`)。对话画面点这个**不会退出对话**(用户实测:点右上角「眼睛」图标会让对话 UI 消失 → OCR 全空 → back_to_world_plus 更识别不到 → 死循环重试 → app 挂起)。**这是 trick_snack 等「先 interact NPC → back_to_world_plus」型 app 挂起的根因**(trick_snack 2026-07-30 实测卡在货全对话、人工停止)。正确退出 = `ESC` 或选「不打扰你啦」类离开选项。
- **待补 screen_info**:对话画面建议加 id_mark(如选项区 / NPC 名)让 `back_to_world_plus` 能识别,并给 `back_to_world_plus` 补「对话画面 → ESC 退出」分支。
- **interact 失败也可能卡此画面**:`TalkInteract` OCR 匹配选项文本,匹配不到(如选项文字带「?」等差异)就点屏幕中下方"空白继续"——若选项一直匹配不上,会卡在对话画面到超时。
- **变体**:NPC 选项对话(本档);剧情对话(无选项、点击推进,`TalkInteract` 的"空白继续"逻辑覆盖);两者是否归同一 screen 待确认。
