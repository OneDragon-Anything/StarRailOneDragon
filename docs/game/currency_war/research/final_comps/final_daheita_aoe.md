## 类本质:策略驱动的直通线(黑塔纪元 32/38 篇)

```
开局策略「黑塔纪元」(棱彩):牌库加 216 张小黑塔
  → 32/38 篇用它开局——没有黑塔纪元,这条线基本不存在
  (#27 是例外:非纪元版的追击大黑塔变体)
大黑塔(4费 Front,学者+群攻):
  装备=充能三件套:高周波电锯(24)+永动机(16)+电光履(14)+蓄能帆(13)
  ——「保证开大效率」(#3)——大招流C(与黄泉同型)
小黑塔(黑塔,1费):双电锯+星级手册(#3「小黑塔需要输出」);
  ⚠️ #32 三连强调:「小黑塔一定要四星!」——备战席堆小黑塔星级
  =阵容强度(#2「阵容强度在于小黑塔的合计总星级」)
```

## 独特机制:备战席经济学

```
「备战席放满小黑塔,越多越好!」(#2/#11)
- 小黑塔(1费)不计入阵容但在备战席供星级/前后台强度
- 216 张库容 → 低等级 D 一费概率高 → 「不要升级!先出小黑塔」(#20)
- 节奏反常识:别人升人口,这线压等级猛 D 一费
  (#6「别攒利息,趁等级低猛猛梭哈小黑塔」#26「无需升本」)
- 转折点:大黑塔 3星+群攻5 成型后正常上人口(#15「先升四级同时
  升三星小黑塔,后面再分配钱升队伍」)
```
