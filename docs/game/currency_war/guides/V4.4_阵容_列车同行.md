## 机制(★领航员 = 核心独有机制)

姬子·启行专属羁绊「领航员」:**指定一位列车同行队友成为领航员 → 加入其原生流派羁绊(击破 / 追击 / 能量 / 群攻等玩法羁绊),该羁绊人数 +1,并获取该队友的第 1 件装备**。= **偷装备 + 偷羁绊**。阵营羁绊(星核猎手 / 贝洛伯格 / 巡猎游侠)偷不了。领航员效果**后台也生效**。

不同领航员不同效果,无脑上分只需学会 **三月七领航员**:

- **三月七领航员 = 最强最稳定**:
  1. **生存**:姬子每次发动助战技 → 我方全体前排获 **20% 生命上限护盾**;2 护盾大幅提盾量上限。姬子助战技频率极高 → 前排盾轻松叠 **2 万 +** → 顶着 A850 狂化三星黑草❓遭遇 4 **全程不破盾**(坦度吊打所有生存位)。
  2. **输出**:每层光轨给我方全体前台多 **500% 护盾量的反伤倍率** → 开出 4 列车 = 给全体前台套 **4 件反甲** → boss 碰一下姬子就血掉消失(解决姬子不好处理纯对单环境)。

## ★助战技模式跟随领航员 + 放弃星期日

- 三月七 / 杨叔领航员 → 挂自动 AI 切**坚破❓模式**;星期日领航员 → 切**裁决**。**坚破 >> 裁决**(前期队友开大频率不够,裁决次数打不完;坚破后台队友攻击目标也能叠层 → 全程稳定打光次数 → 多叠很多风暴潮 + 优化能量循环)。

## 装备

三月七领航员最大优点 = **不用做生存装备**(最多后期补 1 件硬甲)→ 所有装备优先**姬子 4 件输出装 + 花火蓄能翻**。姬子前排刚需多拉条(甚至 3 拉条)→ **风套翁瓦克蓄能翻花火是底层逻辑**。

- 姬子输出装标配:**双火力风暴潮 + 电锯 + 冷笑话引擎**。首件风暴潮优先级最高,其余 3 件次优先。
- **冷笑话引擎实际打不赢第 2 把电锯**(姬子大招频率慢,正常战斗官打不满 5 大)—— 但还得出:杨叔没来前中期不得不带星期日,冷笑话引擎白值自带 60 基础能量 → 装星期日身上当永动机 → 帮星期日开满能量提前挂拐。
- **双暴击刀 + 双风暴潮 / 三风暴潮 + 冷笑话 / 三风暴潮 + 追击转** 都行,有什么做什么。

### ★「双偷」技巧(进阶)

领航员技能可**退出重调**:先把冷笑话引擎放星期日身上 → 选星期日领航员进战印到自己身上 → 退出重开切**三月七领航员** → 局外偷来的冷笑话引擎消失但**局内仍生效** = 同时偷星期日装备 + 三月七羁绊。
- ⚠️ 风险:每进下一关得把领航员切回星期日再开战,忘切就**放生 1 件冷笑话引擎**。怕麻烦 → 直接把第 4 件装备给三月七保管(最好风暴潮,给三月七 +10% 速度征服;**三月七启动速度决定姬子启动速度**),局内顺手追 2 星、仪器找全速度 2+2+2 闪击❓。
- 姬子选冷笑话引擎另一原因:剩丝血用姬子大招收尾 → 大招不鞭尸 → 转阶段立刻再放没打完的大 = 视为放 2 次大招 → 叠 2 层冷笑话引擎。
