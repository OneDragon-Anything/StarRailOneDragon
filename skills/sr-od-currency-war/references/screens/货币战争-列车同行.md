# 货币战争-列车同行

## 画面简介

选择伙伴浮层（叠在备战上）：选择伙伴（选 1 个候选「列车同行」成员入队获得强化——加入该成员的流派羁绊 + 复制其首件装备效果），浮层挡出战，必须处理完才能出战。归档帧：顶部「选择伙伴」标题 + 副题（效果说明原文）+ 中央候选立绘卡（卡带阵营标签与「详情」按钮）+ 右侧「确认选择」按钮与「请选择强化角色」提示，左侧透出备战流派列表。**本卡动作源码挖掘，未经实机走查**（画面形态有归档帧）。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-选择伙伴 | 顶部标题「选择伙伴」（画面身份锚） | 纯显示 |
| 标识-列车同行副题 | 副题说明文「选择1名「列车同行」成员，加入该成员的流派羁绊，并复制其首件装备效果。」（画面身份锚） | 纯显示 |
| 候选-卡区 | 中央候选立绘卡区（候选 1~N 张）：卡带为立绘区（点带中心落立绘区内），卡下阵营标签行（2-4 字、左→右排布）与「详情」按钮 | 点候选卡选中；点「详情」弹角色详情 |
| 提示-请选择强化角色 | 右侧「请选择强化角色」提示（未选中时在场） | 纯显示；提示仍在 = 没选中 |
| 按钮-确认选择 | 右侧「确认选择」按钮 | 确认选中候选：浮层收起、回备战，所选伙伴入队获得强化；未选中时置灰，点候选后确认才亮 |
| 备战标识-购买经验 | 底部透出的备战「购买经验」卡（画面身份锚，用于确认浮层叠在备战上） | 纯显示（透出的备战元素，非本浮层控件） |
| （待建档）左侧流派列表 | 左侧备战面板透出的阵营 label（列车同行/能量/仙舟等）——不是候选 | 点它们无效；候选只在中央「候选-卡区」；点面板外空白无效 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 选中候选 | MCP `click_game` | 卡带中心（「候选-卡区」内自己读图定位候选，点立绘区内） | 候选高亮、「按钮-确认选择」亮起 | 左侧透出的阵营 label 不是候选，点它们无效 |
| 确认选择 | MCP `click_game` | 「按钮-确认选择」area 中心 | 浮层收起、回备战、伙伴入队 | 确认被拒（提示仍在）= 没选中，重点候选再确认 |

副题明示收益 = 加入该成员的流派羁绊 + 复制其首件装备效果；候选阵营标签从卡下标签行读出。
