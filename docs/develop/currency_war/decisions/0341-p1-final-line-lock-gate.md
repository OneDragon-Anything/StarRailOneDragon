# ADR-0341: P1 锁线资格门(终局专属线的③/④证据收紧)

- 状态:accepted
- 日期:2026-08-25
- 背靠:W97 §5 P0-1 诊断(万敌单C 被③锁 30.5%、hp 19.7 vs DOT 类
  过渡线 28.5-30.7,三线合计 36.5% 局)+ transitions §1 开局分级
  (「拿到逆天投资策略才配锁直通线」)+ transition_combos 四体系封闭
  (仙舟3/列车2/DOT2/希儿系两两组合)+ 口述 [20](过渡是配方)/[21]
  (final 买而不上)/[23](终局线由贯穿件锁定)。前件:ADR-0338(W85
  清②层非法锁定);ADR-0340(W96 merge_progress,同批前序)。

## 背景与动机

W85 后非法锁定率 0,但 W97 sim 基线(n=200)显示剩余锁定分布中
**终局专属线被③核心卡路径锁走 36.5%**(万敌单C 30.5%/双王圣杯 3.5%/
黄泉减益 2.5%)——这些线的锁线方向(囤货目标集=意向线主/副档羁绊,
discipline 方向期阵营门的消费对象)**不含任何过渡引擎件**,锁定即把
P1 买侧从四体系引擎上引开 → 板面零伤害引擎 → boss/遭遇罚款吃满
(该组 hp 比过渡线差 9-11)。

机制定性(transitions/transition_combos 语义,统计只作佐证):
万敌燃血/黄泉减益/圣杯双C/大黑塔群攻的前期战力来自**通用引擎池**
而非自身目标件(「直通终局线」节:前期战力恰恰来自过渡引擎,直通
「省」的是换血成本,不省前期);P1 锁它们 = 贯穿件还没到上场窗口
([21]:姬子=7 级/万敌=1-9 变阵点)就提前把经济锁进终局件。

## 决策

**③核心卡/④资源信号在 P1 对终局专属线加资格门**(信号发射处过滤,
与 ADR-0338 ②门同构):门开 ∧ plane==1 ∧ 非过渡线 ∧ 无①类资格
(策略/环境亲和,`_direct_line_qualified` 同源)→ ③/④不发(意向
保持 unlocked,囤货落⑤兜底,P1 板面归四体系过渡逻辑;**贯穿件照买
照囤**——[21] 买而不上由买侧 targets 消费,本门只辖锁线证据)。

**过渡线判定 = 三支派生(无手写线名表)**:
- ⑤兜底线(绯英欢愉)恒过(未锁分支囤货=同线采购集,门 no-op);
- 希儿 ∈ core(希儿系=四体系之一,单卡即战力,伤害在技能层);
- 主/副档 form_tiers/sub_tiers ∩ 三羁绊体系键(TRANSITION_TRAITS
  派生,与 scoring/cw_sim/deploy_logic 体系判定同源)≠ ∅
  ——锁线方向=阵营门消费对象,档位即体系则锁了仍在买引擎件
  (DOT队/专家桑博DOT/列车同行;[20] 过渡是配方,4列车保送 P2
  即列车体系的升级层)。

`P1_FINAL_LINE_GATE` 常量 = sim A/B 通道(False=基线臂)。

行为变化:P1 无资格时③/④被拦([23] 路径在 P2/P3 照旧);①/②/
强制锁线/撤销析取全部不动;P2/P3 完全不辖。

## Considered Options

- **这是 W85(ADR-0338)的重复?**——否:W85 清的是②层「羁绊副产品
  计数」冒充资格(无资格发②锁线),本件清的是③层「贯穿件在手」
  本身合法但在 P1 **时机**不对([23] 语义=终局线由贯穿件锁定,但
  [21] 上场窗口在 P1 后;W97 实证③是剩余锁定的主通道 30.5%)。
  两门同资格源(亲和表反查)不同证据层。
- **为什么 P2/P3 不辖**——[21] 明写上场窗口(核心等级窗/羁绊齐窗/
  变阵点窗)与 transitions §3 的 1-8 换血点都在 P1 之后;P2 起锁
  终局线是 [23] 全文语义,门辖全局会砍掉合法路径。
- **手写终局线名单**——被否:与 COMP_LIBRARY 演进漂移(ADR-0338
  「派生优于快照」同款判例);三支派生在 12 条 v2 线上完整复现
  W97 分组(快照锁 test_derived_classification_snapshot 钉死)。
- **靠评分层压低终局线分而非信号门**——被否:锁线后方向门
  (discipline)按意向线羁绊过滤,评分层看不到「锁线方向喂不喂
  引擎」;病根在信号层发证据,不在分数高低(ADR-0338 同款论证)。
- **直接砍③层(全游戏禁③锁终局线)**——被否:P2/P3 的③是 [23]
  合法主力路径,砍掉伤终局;问题是 P1 时机不是③本身。
