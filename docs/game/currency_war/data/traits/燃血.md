## 效果(官方全文,自 effect_rich 渲染)

【燃血】队员的生命增幅和伤害增幅提高。战斗开始时，激活会记录【燃血】队员消耗生命值并在行动时攻击敌方全体的【燃血角斗场】。
【燃血】队员无法获得护盾，受到护盾时会回复2%生命上限+1000生命值。

## 分层效果

- **第2人**:10%生命增幅，10%伤害增幅。可记录40000点。
- **第4人**:20%，25%。可记录100000点，伤害倍率提高为1000%。
- **第6人**:30%，40%。可记录240000点，伤害倍率提高为2000%，行动后返还消耗量的30%。
- **第8人**:45%，60%。可记录720000点，伤害倍率提高为4000%，行动后返还消耗量的50%。
