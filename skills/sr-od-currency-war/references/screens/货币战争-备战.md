# 货币战争-备战

## 画面简介

货币战争对局的核心操作画面（每个节点停留）：节点结算后在此花金币买人、买经验、穿装备强化阵容再出战，是循环中停留最久、操作最多的一屏。`analyze_screen` 在此 `is_precise` 精准命中，并产出全量 extras 读数（gold/hp/level/deploy_count+deploy_cap/xp_progress/front_line+back_line（SIFT 在场真值）/bench/armory_boxes/owned_equips/reward_ores/bench_overflow/aura_slot/board = 羁绊面板可见行仅快照，逐键语义见下表对应行）。一、二位面首领战前备战期为独立子屏「货币战争-备战-选择主角」（见文末子态节）；位面 3 首领战前无此屏。本画面另有 5 个子态（选择主角/角色详情/角色信息提示/装备详情浮窗/合成确认），均作为本文档子章节。

## 识别后要做的决策

花金币强化阵容 → 出战。

## 操作

1. 拾晶矿：`CwCollectRewardOres {"max_clicks":6}`（reward_ores 非空时；只应在收店后的备战画面用——商店态晶矿不可见，reward_ores 键不出现）。**点击后重读一次 analyze**——采到的奖励开箱可能入席，改变备战席占用；**掉落物过合成检查（2026-11-19 实机）**：掉落角色计入同名同星级全局计数，凑满 3 份直接自动合成升星——入席的掉落物星级与落点按合成结果读，别按掉落帧硬记。拾矿/拖拽/合成后 deploy_count/deploy_cap 可能连续数帧瞬态 null（实测：识别对「个位/个位」短文本间歇失读，画面可见真值）——读图对账勿当真值，等几帧重读。**晶矿坐标带与右上退出入口相邻（实测）**：点击可能误触「中断挑战」弹窗——误触后点「暂时离开」→ 回大厅 → 点「继续进度」可无损续局。晶矿识别可能误判：**点击后仍然存在的晶球 = 幻晶矿（点了无效的假目标），对照自己读图确认后忽略即可，不要反复点**（2026-11-20 局复现——跨局稳定形态，非单局偶发）。
2. 开商店：`CwToggleShopPanel {"screen_name":"货币战争-备战"}`（静默失败重跑）→ 买东西见「备战-开商店」卡。
3. 部署：`DragCwChar {"from_row":"bench","from_idx":N,"to_row":"front|back","to_idx":M}`——from_idx 必须来自**刚读过**的 extras.bench（晶矿开箱掉落物会插到非首空位，旧读数缺新单位；槽号 = 物理槽位，空槽以 empty 保留）。**to_row="back" 必须声明后排档**：先读当帧 extras.deploy_cap，二选一传 `"back_slot_count":C`（C = deploy_cap − 4，6-9）或 `"back_centers":[[x,y],...]`（当帧实测的后排槽位中心，不推荐，仅兼容保留）；两个都不带会被 op **显式拒绝**（不再静默落 6 格基线——后排槽数随局变化，6 格坐标在 7+ 格局骑在真实槽位边界上，拖不进）。to_row 为 front/bench 不受影响照旧。**同名第二张无法上场（实测）**：拖备战席同名到场上空槽 = 静默无反应——op 无错误返回，无法区分吞点击与规则拒绝；遇到时读图确认场上/席内实际状态，勿反复拖。拖备战席角色到场上已占用槽 = 换位。合成规则实测收敛（同名+**同星级**全局计数 3 合 1，详见「备战-开商店」卡条目 1）——同名第二张无法上场与这条规则同源：凑满同星级 3 份会直接合成而非上新场。
4. 卖角色腾位：`CwSellBenchBySlot {"slot":N}`（实测：参数名 = slot，传 bench_idx 会报错）。
5. 开武装箱：点 extras.armory_boxes 元素的 cx/cy（开启后装备入库，腾出备战席）。**开箱需备战席有空位（2026-11-19 实机）**：武装箱占备战席槽，席满时开不了箱——先卖角色腾位再开。**右上『×N』计数是冶金炉消耗品计数，不是武装箱（实测修正）——armory_boxes 只读备战栏内的简易武装箱占位。**
6. 看角色详情：点场上角色卡（属性/技能/装备栏面板，右上 × 关闭）——详见「货币战争-备战-角色详情」节。
