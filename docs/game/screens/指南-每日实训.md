# 指南-每日实训(guide_daily_training)

星际和平指南 5 个 per-tab 屏之一(拆屏架构与公共 area 归属见 [星际和平指南](星际和平指南.md)),`DailyTrainingApp` 的核心工作画面:实训任务列表 + 活跃度里程碑奖励轨。玩法机制见 [gameplay/daily_training](../gameplay/daily_training.md)。

## 何时出现 + 状态流转

- **入口**(两条,落点不同):
  - 手机菜单 →「指南」→ 落在**上次使用的 tab**(2026-09-01 实测:上午 bot 跑完每日实训后,经菜单进入直接落在每日实训 tab);
  - 大世界右上「按钮-指南」图标(pc_alt 需 Alt)→ 落在**生存索引**(默认 tab,非上次使用的 tab——实测 2026-09-01,与菜单路径行为不同)。
  - 两条路径都到了 per-tab 屏后,tab 互切一致(见下)。
- **出口**:右上 X。**落点依赖入口路径**(2026-09-01 双路径实测):菜单入口 → X → 回「菜单」;右上图标入口 → X → 回「大世界-普通」。esc 同效(项目规则:操作走点击,不 ESC)。
- **tab 切换**:顶部 5 个 tab 图标(y≈180-248),点击即切换到对应 per-tab 屏(实测:每日实训 ↔ 生存索引 双向)。

## 布局(自上而下)

1. **顶部 TAB 条**(y≈180-248):5 个 tab 图标 = 指南(每日实训)/生存索引/旷宇纷争/逐光捡金/开拓历程,对应 5 个 per-tab 屏;当前 tab 高亮底色。
2. **活跃度里程碑奖励轨**(y≈270-380):左侧圆徽 = 当前活跃度数字(三位数,如 500);轨道 0/100/200/300/400/500 六档,每档一个礼物圆钮。礼物三态:**灰礼盒**(未达标)/ **金礼盒+红!角标**(可领取)/ **橙对勾**(已领取,轨道线全橙)。
3. **实训任务卡横向滚动行**(y≈400-890):≥8 张任务卡(累计消灭敌人/使用万能合成机/完成差分宇宙或货币战争/累计消耗开拓力/支援角色获胜/助燃券或深度沉浸器/登录游戏/派遣委托…),每卡 = 进度 X/Y + 任务描述 + 活跃度奖励(+100/+200/+500)+ 底部按钮。**横向拖拽滚动**(右侧卡半露提示可滚)。
4. **右下刷新时间**:「刷新时间 N 小时 M 分钟」,每日 04:00 重置。

## 任务卡按钮态机(2026-09-01 实测五态)

| 态 | 外观 | 语义 |
|---|---|---|
| 领取 | 亮黄胶囊钮 | 任务完成且活跃度未满,点击领活跃度 |
| 前往 | 白胶囊钮 | 任务未完成,点击跳转对应玩法入口(跳转目标随任务不同,未逐个验证) |
| 进行中 | 暗色文字 | 任务未完成且无可跳转(或条件未到) |
| 本日活跃度已满 | 暗色文字(全卡统一切换) | **活跃度满(500)后全部任务卡统一切到此态,含未完成卡**——前往/进行中/领取都不再出现 |
| 灰化+对勾 | 整卡灰化 + 大对勾 | 已完成(此形态与「本日活跃度已满」可叠加出现) |

**领取交互行为**(实测):点击「领取」→ 活跃度到账(+100/+200/+500)→ **任务卡行自动向左滚动对齐到下一张未领卡**(被领卡移出视野左侧)→ 里程碑达标时对应礼物变金可领。

## 里程碑礼物交互(实测)

- 点击金礼盒(红!)→ 弹全屏「获得物品」弹窗(背景暗化模糊,内容 = 星琼/材料/信用点,底部「点击空白处关闭」)→ 点空白关闭。
- ⚠️ **待核(2026-09-01 单次观察)**:活跃度满后 300/400/500 三档同时金可领,点击 300 一档、弹窗只显示一档内容,关闭后三档**全部**变对勾——疑似「点一档连领全部可领档」或游戏连领,单次观察未复核。
- 灰礼盒(未达标)点击行为未验证(本场次结束时已无可领前的灰态可点;下轮可领前补)。

## automation 要读信息(消费点)

- **是否已完成**:`is_training_reward_completed`(裁 `GUIDE_TRAINING_REWARD_CLAIM_RECT` 匹配模板 `training_reward_completed` ≥5)——「已完成」判据,注意模板对灰态礼盒也命中(2026-08-27 实证,消费方 `DailyTrainingApp.claim_reward` 用跳过语义兜底)。
- **领取按钮位置**:`get_training_reward_claim_btn_pos`(同区匹配 `training_reward_gift`,多命中取最右)。
- **所在页验证**:`in_secondary_ui('指南'/'每日实训')`(左上角标题两行,走 `通用画面/左上角标题` area + OCR)。
- **活跃度当前值**:未接(可建 OCR area 读取,备未来策略用)。

## 可交互元素(screen_info area,坐标见 yml)

- 「按钮-关闭」右上 X(goto 菜单;从右上图标入口进时落大世界,见上出口双态)。
- 「标签-指南TAB / 标签-生存索引TAB」等 5 tab(goto 对应 per-tab 屏;旷宇纷争/逐光捡金/开拓历程 tab 未单独建 area,按需补)。
- 「礼物-100..500档」五个圆钮(no_method 定位区;点击前须按三态确认可领)。
- 「任务卡-首卡按钮」:滚动对齐机制下首卡按钮位(280,790-545,865)恒为当前可操作卡(实测 3 次领取同坐标命中)。
- 「任务卡-滚动区」:横向拖拽区(拖右→左滚动)。
- 「活跃度-当前值」「文本-刷新时间」:只读。

## 跳转边(goto_list,实测)

- 按钮-关闭 → 菜单(菜单入口路径实测;右上图标入口落大世界——goto 寻路只用「菜单」边,大世界侧出口不进路由图,见 doc 上文出口双态)。
- 标签-生存索引TAB → 指南-生存索引(实测)。
- 标签-指南TAB → 指南-每日实训(自环,从别的 tab 切回用)。
