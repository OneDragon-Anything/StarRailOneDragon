# 无名勋礼-购买推广页(nameless_honor_promo)

无名勋礼的**版本周期首进推广页**(整屏广告画面):2026-08-26 版本周期内第一次进无名勋礼时,先落在本页而非主面板(用户口述,最高权威)。右侧为无名勋礼标题 + 剩余时间 + 本期奖励图标陈列,右下「开启无名勋礼」大按钮,底部解锁说明文案与「请适度娱乐,理性消费」提示。不锁光标(`pc_alt=false`)。

## 何时出现 + 状态流转

- **入口**:手机菜单 → 点「无名勋礼」菜单项;**周期内第一次**进 → 本页(非首次直接进[主面板](无名勋礼.md))。
- **出口(实证退出链,编排者 2026-08-27 live 四步全走通)**:
  1. 点「开启无名勋礼」→ 弹「无名勋礼等级加速」说明弹窗([等级加速弹窗](无名勋礼-等级加速弹窗.md));
  2. 点弹窗内部/「点击空白处关闭」提示位 → 关弹窗进[无名勋礼主面板](无名勋礼.md)(点弹窗外部无效);
  3. 主面板点右上角「按钮-关闭」→ 菜单页(既有菜单分支接管:开拓等级→右上角返回→大世界)。
- **付费语义(用户裁决)**:点「开启无名勋礼」是查看/继续语义,**不会付费**,bot 可安全点击。

## 识别特征(稳定锚点)
