## 门① 内部推导健全性:**不过**(1 实质缺陷 + 3 次级)

### ①-1 🔴 Q1 全部轮期望数值 = 积分截断伪影(实质缺陷,可行性判定翻转)

被审脚本 `tools/cw/proofs/equip_expectation.py` `wait_rounds_for_demand`(:117)`scale = max(k)/rate` 作积分上界——注释写「均值最大分量的 ~3 倍覆盖」但**代码没有任何 3× 余量**。E[max] 类量需要的上界 ≫ 最大分量均值,截断使结果系统性偏低。

独立复算(闭式 + 充分上界数值积分,两者互证一致;截断复刻=按被审代码逻辑重写):

| λ | 交叉件 文档/截断复刻 | 交叉件 **真值**(闭式 12/λ) | 自配 文档/截断复刻 | 自配 **真值**(闭式 16/λ) |
|---|---|---|---|---|
| 0.25 | 26.6 / 26.62 | **48.0** | 46.7 / 46.68 | **64.0** |
| 0.5 | 13.3 / 13.31 | **24.0** | 23.3 / 23.34 | **32.0** |
| 1.0 | 6.7 / 6.66 | **12.0** | 11.7 / 11.67 | **16.0** |

- 截断复刻与文档值**逐位吻合**(26.62/13.31/6.66;46.68/23.34/11.67)——证明文档数字确由该截断积分产出,非誊录错。
- **单篇内部自相矛盾**:文中自写正确闭式「自配件 E[T_b]=16/λ」(L45),其表格 23.3@λ=0.5 ≠ 16/0.5=32——公式与表打架,审查期未被发现。
