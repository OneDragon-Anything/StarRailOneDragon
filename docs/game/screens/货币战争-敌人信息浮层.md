# 货币战争-敌人信息浮层

> 性质:画面档(screen_onboarding 产物;只写画面本身事实)。建档:2026-08-26(佩佩局实拍)。
> source_image:`sr-od-test/screens/货币战争-位面详情/敌人信息浮层.png`。

## 何时出现 / 状态流转

- **入口**:备战画面点击左上「文本-难度」框(按钮-敌人难度,95-180, 20-120)弹出本浮层;
- **出口**:点击浮层外任意处(画面空白)关闭回备战(实测 ✓)。

## 画面结构

- **标题**:「敌方信息」(id_mark 锚,90-215, 40-90);
- **敌方波次列表**(左侧,25-420, 120-700):按波次分组(如「小型企业·第1波」),每波 1-3 个敌人头像+等级(如 等级90);点击敌人头像 → 右侧详情卡联动(实测选中态);
- **敌人详情卡**(中右,1240-1560, 120-420):敌人名(如 鸣雷造物)+等级+技能+故事文案;
- **词缀横条**(底部,500-1430, 970-1015):「敌人难度108」+全部词缀标签——**备战画面同位置同条**(常驻 UI,不随浮层出现/消失);
- ⚠️ 备战主体 UI(羁绊面板/备战栏/商店按钮)在浮层下仍部分可见,但左面板(羁绊区)被浮层盖住。

## 识别特征

- id_mark = 「敌方信息」标题文字(备战画面无此词);
- 浮层开着时备战 id_mark(购买经验等)仍可见——**两屏锚共存**,analyze 按注册序先中备战 → 消费侧需先查本屏浮层(与「货币战争-中断挑战弹窗」同款上层屏处理,见 cw_obs_core.UPPER_SCREENS)。

## 可交互元素与行为

| 元素 | 坐标 | 点后行为 | 实测 |
|---|---|---|---|
| 敌人头像(波次列表) | 25-420, 120-700 内 | 右侧详情卡切换该敌人 | ✓(选中态联动) |
| 浮层外空白 | — | 关闭浮层回备战 | ✓ |

## automation 要读信息(中途接管局补采落点)

- **词缀横条**:OCR 词缀名 → `state.enemy_affixes`(常驻,不必开浮层也能读);
- **敌人难度值**:OCR → `state.enemy_difficulty`;
- **波次敌人构成**:敌人名/等级(战斗强度预估,判读用——待消费需求落地再建细 area)。

## 子态归属判定记档(四问,ADR-skill 0021)

①dispatch:接管补采需「开浮层→读→关」独立 handler 链,且浮层开着时备战点击行为不同(先关浮层)→ 指向独立;②遮挡:盖住左面板(羁绊区),备战 id_mark 不受影响但交互语义变;③正交:与商店/弹窗互斥(点别处即关),不否决;④粒度:左侧整块布局新增(波次列表+详情卡),非单元素变化 → 指向独立。**结论①④双指向,独立屏**(初判曾误归备战子态,用户纠正后按四问重判)。
