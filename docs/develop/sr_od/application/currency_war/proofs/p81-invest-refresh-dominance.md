## 1. 命题

设投资策略屏三选一帧满足帧级触发(候选恰 3 ∧ 全部精确分类 ∧ 无一达 S1/S2 ∧ max_N≠1,分类谓词全量复用 ADR-0597 体系),槽 i 属动作集(非顶级 ∧ 计数 >0 ∧ 非当前唯一 L1 槽)。则:**刷新槽 i 弱占优不刷**(四支结局逐一核对,无确定损失分支,至少一支确定改进),且此结论对计数授予口径(N 次/口径如何)鲁棒。

## 2. 前提(全部在册裁定或注册表/机制事实,零自由参数)

- **A(免费性,条件前提)**:事件面刷新免费且不消耗选卡权。机制/先例证据:补给刷新 ADR-0394「不耗金」、C10 墓碑注「免费刷新」、逐卡刷新 UI 无金费显示(归档帧);实机核验 = V2(对账通道判读式,ADR-0600 §4)。
- **B(改进存在性,条件前提)**:刷新后新卡有概率 p>0 达 S1/S2。两环:①池内存在性 = 注册表直调(引擎 38 + 定义型 7,五方复现 `335 38 [] 7 [] False 0 0`);②重掷分布 = 发牌分布(机制前提,刷新与首度发牌走同一发牌 UI;实机核验 = V3)。**p 的量级不入判据**(优势论证只消费 p>0,无标定需求)。
- **C(优先序,编码可兑现口径)**:S1(120) > S2(111-119) > S3 对齐 N=2(110) > S4(≤75);N=1(65)可被 S4 顶部逾越——ADR-0597 编码事实;N=1 价值地位未决挂账 T-155/16 号稿批,本命题不裁。
- **D(血本位回避)**:存在 L1(非血∧非禁)替代时永不选血卡(ADR-0578 声明性偏好)。
- **E(被禁统一规则)**:被禁卡永不被选 → 不参加达档/顶级判定、被禁槽恒入可刷集(P5;被禁∧N≥2 形态现行不可达——两血卡绑定双空恒 N=0,直调在案)。
- **W(welfare 声明)**:S4 内部评估序与 L2/L3 帧域内评估序同为选择机制不承载福利——S4 分值是定序实现常数禁读基数(ADR-0524),域内交换不构成可证损失。

## 3. 证明(四支穷举 + L1=∅ 补全)

设槽 i 满足动作集条件,刷新后按新卡分类穷举四支:

1. **新卡达 S1/S2(顶级)**:按 C 严格优于原任一非顶级卡(S1/S2 压过 S3 N≥2 的 110 与 S4 全域)——改进支。子域限定(J1):对齐卡命中 user priority 时(110+30=140),无 priority 新顶级(≤120)不翻转选卡 → 刷新白耗一次计数、选卡结果与不刷相同(免费 → 零损失),弱占优保持;新卡亦命中 priority(150>140)时回到严格优。
2. **新卡为血/禁**:槽 i 已过唯一 L1 守卫(动作集条件),故 i 非「当前唯一 L1」→ 刷后 L1 至多从非空变空。L1 非空:兜底 = 其余 L1 卡 argmax,与不刷的 L1 兜底同域,按 W 可交换;L1=∅(L2/L3 帧):帧级触发可达(血∩引擎=∅、S1∩血=∅ 直调,全禁帧由 forbid 名单构造),兜底 = 域内 argmax(血卡间常规评估序/全禁全序),按 W 与不刷同域可交换——唯一 L1 守卫在该帧恒空转(无槽被保护),不需例外申报。无确定损失。
3. **新卡非顶级非血非禁**:同支 2 域内交换(W);且此时若原卡为血/禁实为支 4。无确定损失。
4. **原卡血/禁**:新卡非血非禁(本支定义)→ 按 D 有替代时回避血卡为声明性改进;原卡为禁时任何非禁新卡至少解除「永不被选」面——改进支(L2 帧此支 = 逃出血强制)。

支 1/4 为改进分支,支 2/3 无确定损失分支 → 刷新弱支配不刷,∎。上界与终止:每卡计数游戏授予封顶(策略屏实证每卡 1),链遇顶级/不可分类即停(边际为零/分类不可靠 fail-closed),发射即记防重入(ADR-0600 §3.3)。

**max_N=1 排除支(帧级门 4 的理由)**:帧内最高对齐档 = 1 时,刷他槽新卡抽到 S4 顶部(66-75)会翻转最终选卡(65 被逾越在编码上是真实位移);N=1 与 S4 抽样的交换按 C 不可比(N=1 价值未决 → 既不能按声明序算确定跌档,也不能按编码算 W 域内交换)→ 二元尺度(存在不可判定交换 → 保守缺省)整帧不刷。max_N≥2 帧的对齐槽保护同理:刷它 = p×跳档 对 (1−p)×确定优先级跌档,双侧无定价不闭合 → 保护不刷;其余槽刷后 fallback 恒等(110 > S4 75 + priority 30 = 105,任何非顶级新卡不翻对齐卡)。
