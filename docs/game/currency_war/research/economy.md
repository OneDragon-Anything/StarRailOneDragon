- **版本冲突已裁定(用户 2026-08-19:按 V3.7 为准;2026-08-28 最终收案:27 张为准,异值攻略帖一律讹误勿采,不收录对照)**:V4.2 银狼帖旧口径(单源 🟡)不采纳;注册表按 V3.7 口径 27/9 建模即正确口径。检索结论留档=27 的公开独立文本源未找到(必修二为 B 站视频无文本,NGA 拒访客),以用户口述为最高权威收案。
- V4.2 补充机制 [攻略·银狼;**张数经用户口述裁定 2026-08-28:为 ≥9 张**,「90」系攻略转写讹误]:手上持有某牌 **≥9 张 → 立刻清空该牌在商店的库存**;商店剩余牌**只算场上+备战席**,藏在聘用书/投影仪/金矿里的牌不计 → 藏牌降低显性持有数、提高刷目标概率。自洽解释:9 张=一个 3 星的量,凑出 3 星该牌即从商店消失 → **普通牌经 D 牌追 4 星(27 张)不可达**,「三星后想再 D 四星以上 D 不出来」即此机制;黑塔纪元(216 张特殊池)效果明文「商店能继续刷新【黑塔】」为明示例外。
- **专家顾问**[官方🟢:bwiki 转录 4.0 版本调整公告]:初始**不参与普通商店招募**;对局中经【投资环境】/【投资策略】/战利品【专家邀请函】三通道解锁后,本局内与其他员工一样可在商店被购买/升星/穿戴装备,**并拥有之前所属的羁绊**;当局生效、不跨局(用户口述 2026-08-28 确认)。V4.0 首批=加拉赫/停云/青雀;V4.4 专家名单以 plaza `is_expert` 字段为准。

- **种类数**:从 `cw_chars.CHARACTERS` 派生(`DISTINCT_CARDS_PER_COST`),V4.4 现口径 = 注册表 75 条目(费用角色 72 + 召唤 3;DISTINCT 派生=72),别写死(旧写「74 种」已过期,2026-08-31 勘误)。
- 部分场景/效果改副本数(>基础值),版本敏感,效果侧建模时单独核。
- **卖回还池**[用户确认 2026-08-31;**同日二次精确化(建模指令)**]:**r=3 不是独立机制参数,是不变量的自动推论——建模上不设「卖出回池」事件处理,池量一律派生**:**剩余牌库 = 解析后固定牌库 − 手上持有的副本总数**(合成不销毁副本:2★ 计 3 张、3★ 计 9 张);买/卖/合成只改持有计数,池随不变量自动正确(卖 2★ ⇒ 持有 −3 ⇒ 池 +3,「回 3 张」无需单独编码,原「r 待实测」撤销)。⚠️ 「固定牌库」是 resolved 值:专家顾问族(「使其在本局游戏中加入商店」——特邀专家:银狼/停云/加拉赫/桑博/佩拉/姬子/青雀等十余张)、黑塔纪元(216 特殊池)、人才下沉、二/三/四费援军等**池构成族突变改 v_c/a_c**(设计 §4.10 resolved input;概率表/压缩价值表在池突变语境下整体重生成)。推论:①买→卖回往返池中性(退金按 §3 表,1★/1费净 0);②持有 2★ 期间压缩 3 张等效,卖出一瞬全释放——**[11] 凑息卖回序更不该先卖 2★**;③「≥9 张清空商店」按同一副本计数(3★=9 即清空,自洽);④压库期望价值按「持续持有的副本总数」计(p49 O-1 由不变量收口)。

## 2. 刷新概率

- **单一源 `cw_shop_odds.REFRESH_PROB`**(Lv1-10 × 1-5费 完整表,游戏内「商店刷新概率」弹窗实机 OCR + VLM 双源一致,每行和=100%;ADR-0091)。规律:1-3 级纯 1 费 / 4 级起混 2-3 费 / 7 级起出 5 费;7级3费 p=0.40。
- **各费用该在几级 D**[米游社🟢 D牌期望表]:1费→4-5级 / 2费→6-7级 / 3费→7-8级 / 4费→8-9级 / 5费→9-10级(有命运卜者·黑鹅时 5 费概率提高)。**等级由「要找谁」驱动,不是固定曲线**——升级是搜牌手段。
- **D 牌期望的精确模型**:找 k 张目标(2星 k=3 / 3星 k=9),5 格各以 p 独立出目标费用(二项),目标费用里出目标牌 = 超几何(剩余目标副本 / 剩余同费副本);`expected_refreshes`(`cw_shop_odds`)按此实现。

### 2.1 商店槽位语义与锁(2026-08-25 W60 调研;同晚 F8 实机对拍闭环)

- **买后槽位布局 = 留空不紧缩**(2026-08-25 实机实锤 🟢):买槽 3 后仅该槽变空槽占位,右邻槽(4/5)像素级零变化(OpenCV 帧对拍;`.debug/temp/currency_war/cw_dev/f8_shop_slot_check.py` 可重跑)。含义:同轮多笔买按固定 x 逐张点击是安全的(槽位在面板实例内稳定)——生产 100+ 局无买错的间接佐证升级为直接证据。原「紧缩 or 留空待画面核实」结案=留空。[来源:实机帧级取证;等级:实机 🟢]
- **刷新重置 = 整店 5 槽全换**(2026-08-25 实机实锤 🟢):手动刷新后 5/5 槽全部显著变化、新牌全非旧牌(非逐槽补空);「买空后刷新」极端边角随之闭环(全换必然含空槽重填)。原 🟡 升 🟢。锁定态下刷新行为仍无载(低优,恢复局本身禁商店交互)。
- **节点切换 = 自动刷新全店,不继承**(2026-08-25 用户口述最高权威 + 实机互证):进入下一节点商店自动刷新全部 5 槽,跨节点零继承(1-1→1-2 实测旧牌全消)。⚠️ 判读坑:新刷牌面恰与旧牌部分相同时,像素对拍会误判「继承」——判「是否刷新」以节点推进事件为锚。
- **升级不触发商店刷新**(基础机制,2026-08-25 定谒):基础刷新触发只有「节点切换」+手动;V3.7 攻略「升级白嫖刷新」是持「商业间谍」棱彩语境(效果三段:购经验费−1/**升级时刷新商店并偷取最贵 3 张**,cw_invest_data id 300201 原文——费−1 段已进台账,刷新+偷卡两段未建模)。**变费效果全集**亦核(同日):投资策略侧只有「飞光·映月」(镜流星级驱动特殊 1 费景元变 3/5 费,确定性)+「晋升名额」(买经验时随机一槽变高 1 费,不可控);银狼升费是**角色固有技能**(config 三条目),与此不同源。
- **商店锁**:整店级——锁定后商店不随节点自动刷新(跨节点保牌);无「单卡锁」任何记载,默认不存在。生产链路当前未建模锁(无识别/无动作),有需求先建锁按钮档。[来源:官方玩法说明+bwiki 逐字复核+社区攻略用法佐证;等级:官方 🟢(原文已随 data 文档删除收编,见 git 历史 `docs/game/data/gameplay.md`)]
- **恢复局商店锁死**(2026-08-25 用户口述+实机实锤):对局中进过战斗后 exe 异常退出,重新继续回备战时商店交互被游戏侧禁用(只能出战)——与「商店锁」无关,是恢复态限制(详 `docs/game/screens/currency_war_prep.md` 恢复局锁定态节)。

## 3. 卖出退金与免费牌池操纵

- **退金规则单一源 = `cw_state.sell_refund`**(ADR-0121 定稿):1星=cost 全额;2星=cost×3、3星=cost×9,**仅 cost≥2 减 1 手续费,1费各星无手续费**。证据:1星 `[社区🟢]` BWIKI;2★1费=+3 为 live 实测 `[图鉴]`(ADR-0121);3星=cost×9−1 推测 `[🟡待 live 核]`。
- **推论(免费操纵)**:1星1费买卖净 0、2星1费(3张合成再卖)也净 0 → **1费各星 = 零成本压缩牌库**;cost≥2 的 2星合成再卖亏 1 手续费,操纵非免费需算账。
- **幅度**[🟡量化]:1费池大(种类×27 ≈ 500+ 张)→ 单次刷新幅度小(买 30 张只升 P(5格≥1) 约 1 个百分点);但追 3星 多次刷新复合 + 净 0 金,任何正期望都值得做。压缩买链实现见设计篇(姿态/战术)。
- **前提**:目标必须是 1费(cost≥2 有成本);备战栏有空槽;操纵占格非瞬时。

## 4. 电表倒转(砂里淘金流)

- **机制**[社区🟢多源]:「砂里淘金」合成 2星2费 免费赠 1 张砂金(2费)+「轮岗/长线利好」提高 2费刷新率 → 买3合2星→送砂金→卖 break-even 净赚砂金 → 循环滚金。启动需 1-2 关刷出砂里淘金 + ~500-600 金启动资金,成型晚过程脆。(勘误 2026-08-31:「长线利好」注册表原文=30 次付费刷新后本局 1 金/刷——是**刷价减免**非 2费刷新率提升,与轮岗不同源;本条语义按注册表口径修正,组合滚金的结论不受影响,刷成本侧数值随之下修)
- **裁定:不采纳**(ADR-0211)——选卡照常评估,不建触发线、不围绕它改打法。通用教训:**均值好看 ≠ 时序可达**。

## 5. 关键回合多刷(社区共识)

「每回合固定 2 次」上限太死,该多刷的场合[社区🟢多源一致]:
- 升 8 人口后(P2 2-7 关左右)搜 4/5费核心,连刷 3-5 次;
- 赌 1费阵容(如阿雅)在低人口主动刷找 1费追 3星;
- 位面1 遭遇前战力不足 → 弃息 D 出伤害羁绊(四体系内,如 DOT)保血;
- 血危险锁血急救 → 花光提质量;
- boss 前 / P3 成型期刷关键高费。

不该多刷:前期牌差宁输保经济(A8 高难除外,见 §6)、中期稳定吃息升人口期。
**信号**:刚升到目标人口 / HP 低于阈值 / key 牌差 1-2 张成型 / 有刷新减费策略(采购专员等)。
当前 bot 实现:动态上限 `_refresh_cap`(设计篇)。

## 6. 保血 vs 保经济(A8 边界)

**A8 高难下「保血/保连胜」>「保经济卖血」;低难可保经济**[社区🟢+口述]:

```
第一位面:
├─ 高难 + 阵容战力不足(预计掉血大)→ 弃息 D 牌凑伤害羁绊保血保连胜
├─ 有成型连胜阵容 → 停止花费,吃息+连胜滚雪球(双经济源)
└─ 低难/血健康/打得过 → 保经济(攒息)
```

关键共识:
- 「第一位面最难」——A8 一层遭遇常比 boss 凶(详 competitors.md 节点表);
- 「断连胜亏的钱 ≥ 利息亏的」——连胜是资产,有意识维护;
- 连败卖血流:血>50 继续吃息;血<40 止血 D(A8 慎用卖血);
- 奖励/补给节点不花钱,留息白嫖[社区🟢](⚠️ 例外:经济过热类环境奖励节点变扑满=奖励型战斗,按 [16] 应对口述轻投入凑羁绊刷伤害,详 gameplay「节点类型×战力要求」与 ADR-0348——本条默认无环境状态)。

## 7. 阶段经济共识
