> 定位:landing §3.3「估算注册表逐参数落表(值/CI/来源/截止)+ 统计口径说明随批」的口径申报面。
> **值只在代码**(单一源 = `kernel/cw_env_economy.ENV_ECONOMY_ESTIMATES`,00_framework 数字三形态【拟】条目);本文只记「凭什么信」与怎么重采,**禁从这里抄值进任何消费面**。
> 数据批脚本(重采入口):`uv run python tools/cw/env_economy_estimates.py`——重跑输出与在册值对照,演化时手工更新注册表(脚本不回写源码,防自动改行为面)。

## 1. 数据源与样本

- **来源**:对局档案遥测(`.debug/currency_war/telemetry/matches/match_g_*.json`,装配器 = `telemetry/match_archive.py`,终局旁路纯读产物)。
- **样本量**:真实档案 146 局(文件名不含 `fake`;sim 段排除)。其中**完成局**(`endgame.result ∈ {win, loss}`)114 局参与全部比例/分布统计;弃局 32 局(崩溃/停机截断局 horizon,计入会系统性低估整局行为量)不参与统计,其选择环境计数仍可观测。
- **时间范围**:2026-08-27 ~ 2026-09-11。
- **难度分布**:A8 ×136,早期档案难度字段缺读 ×10(按缺读申报,不剔除——行为分布与难度相关性未建模,v1 全池混合)。

## 2. 滤波规则

| 规则 | 判据 | 理由 |
|---|---|---|
| fake/sim 排除 | 文件名含 `fake` 剔除 | sim 合成局行为分布与实机不同源 |
| 完成局过滤 | `endgame.result ∈ {win, loss}` | 败局 = 完整 horizon(死亡即终点)保留;弃局 horizon 被外因截断 |
| 位面到达 | `endgame.plane_reached` | 装配器终局域字段,单局单值 |
| 刷新计数 | 逐局 `rounds[].actions` 中 `RefreshShop` 动作计数;**付费口径 = `cost > 0`**,总口径 = 全部 RefreshShop;`cost is None`(旧 schema)该动作剔除 | 长线利好阈值 = 付费刷新(统一 state `paid_refresh_count` §3.3.7 载体);二手市场阈值 = 总刷新(`total_refresh_count` §3.3.8 载体) |

**采样警告(申报)**:免费刷新若以陈旧 cost(>0)落账会并入付费计数。当前语料 `cost` 分布 = {2:417, 3:1, 4:3, 5:79, 10:1},**零 cost=0 行**(高效决策持卡局仅 1 局、零免费刷记录)——付费/总两口径本批数值相同,分型风险暂无实证;重采时持免费刷策略的局需复核 cost 分型。cost=5 批次集中于 08-27~08-29 旧策略版本段(疑似当时 cost 读数噪声或旧记录路径),不影响 cost>0 的付费判定。

## 3. 统计方法与舍入

- 比例参数(P(位面可达)/P(刷新达阈)):Wilson 95% 区间(小样本比例标准选择,下界不塌 0)。
- 条件期望(E[(N−阈值)+ | N≥阈值]):条件子样本均值 + percentile bootstrap 95% 区间(2000 次重采样,固定种子 20260912 可复现)。
- 注册表落表值 = 4 位小数舍入(点值与 CI 端点同);测试消费注册表现参现算期望,不硬锁数据值,重采改参后锁照常可跑。

## 6. π_offer 归一口径申报(landing §3.3 判据①随批义务)

π_offer,k(q) = 无改写环境时第 k 次取卡的 offer 品质分布(品质改写型层 E 的估算参数,**本批不落参**——层 E 转正数据批另行立项,landing §3.6 边界行)。归一口径约定(层 E 转正批照此执行):「未解析」品质份额不单列建模,**按已知三品质份额等比例摊入归一**(归一后 Σ_q π_offer,k(q) = 1)。初测读数与采样警告(档案帧未区分取卡 offer 与刷新后新 offer)在册 = env-value-models.md §2.2.2,不作为本批参数。

层 E 转正批已按本节归一口径执行(判定 = 准入门第 2 条未过,维持 fail-closed 不落参;读数/样本量/回炉候选 = [layer-e-promotion-batch.md](layer-e-promotion-batch.md))。

## 7. 奖励槽位结构先验(C 类视界因子)

`_REWARD_SLOTS = ((1,1),(1,2),(1,8),(2,6))` = 档案节点类型众数表(P1 r1/r2/r8 众数「奖励」n=133/135/127;P2 r6 众数「奖励」n=31/32)。已知变异:p1r7 有 5 局「奖励」、p2r4 有 3 局「奖励」(位面内槽位变异位,与 economy.md §10.2「节点基本固定、策略才改」口径相容);P3 结构零样本(到达即死的样本 10 局未及奖励槽)→ 不计 = 视界保守低估。位面内槽位变异 v1 不建模(增益参数缺位期无消费面,落参批连同复核)。

## 8. ECON_VALUE_NORM 推导

落地参数下全表开局期望最大 = 成功经验 36(3×12×XP_GOLD_RATE=1.0),次大 = 增发货币 14.77 → 取整上界 **40** 注册(域界非拍值;越界由 `_validate_estimates_governance` 构建校验炸出,强制重新注册)。XP_GOLD_RATE 改判或重采推高参数即触发该闸,属设计内演化路径。
