# 货币战争 Playbook(实战玩法知识层)

> **性质**:实战沉淀的打法知识,**用于调优决策的单一文本源**。与攻略调研(`docs/game/currency_war/guides/`,来源留档)分离:攻略是原始转录,本层是我们消化过、验证过、要用于实战的内容。

## 维护约定(用户 2026-08-15 定)

- **纯手工维护,无生成脚本**。字段值(停留点/星目标/核心装备/绑定)单一源在 `cw_comps.py COMP_LIBRARY`,**本文档只写代码字段承载不了的**(打法叙事、过渡方案、装备分配细节、站位原因、入场/退场信号、counter 应对)。
- **双向同步注释**:改 COMP_LIBRARY 某条目 → 同步改对应 playbook 文档(代码条目注释已标 playbook 路径);改 playbook 涉及字段语义 → 同步改代码。两处都有提醒。
- **证据状态标注**:每条知识点标源 —— `[先验:攻略X]`(抄的未验)/ `[实战:run_xxx + ADR-NNN]`(遥测证据)。先验→实战升格是沉淀的主线。
- **实战记录节**:每局 telemetry 发现的打法修正追加(带 run_id/ADR 指针);稳定规律升格进字段或正文主线。
