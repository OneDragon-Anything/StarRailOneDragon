## 机制(怎么 work)

花火主伤 = **吃点打的巧普攻** + **R 回合小幻语记接大幻语记**(大幻语记 = CW 专属技能,倍率随花火天赋等级提升 → **升星 + 开金矿升等级**)。

**R 时刻跑条速度与我方幻语角色速度正相关**(后台爻光速度也记录)→ **爻光标准出装 = 三鞋**(跑越快越好,给花火更多 R 回合出手 + 产足够耗火当赏❓)。鞋不够才考虑电光旅❓ / 永动机 / 绝对热量 / 能量转给爻光开大频率。

## 出装(固定 + 需求大,绑定装备投资)

- **花火**:R 回合大小幻语记每个视为花火攻击一次 → 叠风暴潮快 + 战技点容易展开平面直角坐标系连 A 七八下 → **火力风暴潮必出**。但风暴潮吃鞋 → 没足够鞋给爻光三鞋时,花火**只做 1 风暴潮 + 2 暴击刀**(做不出暴击刀用红绿灯❓下位)。花火开大频率高 → 较快吃满 60% 幸运几率。
- **不做伤害征服装**:花火被动打幻语记给 200% 伤害征服 + 巧普攻给 150-200%(各管各、加不到一起,否则还能再翻倍)。
- ★**好运令牌**:别给爻光 / 花火 → 商店有**阿雅顺手买一张**(阿雅装备最顶级:风暴潮 / 暴击刀 / 反重力鞋,六选四至少出 1)。

## ★星间旅人(新年旅人)羁绊正确玩法

- 羁绊内**唯一有效应 = 旅人转职** → 局内尽可能多做**旅人转职**:1 个转职章给花火 **43.2% 幸运暴伤**(≈ 1 个 2 星符玄的拐力)。
- 有「有人在旅途」金投资 → 旅人转数值最大化。
- 花火抽到加幸运暴伤 + 2 转职 → 可能 **100% 幸运几率 + 600% 幸运暴伤** 超级面板数值怪。

## 配队(击破思路同饮月)

- **6 战技点不提升大奖概率** → 带 2 挂件开 6 战技点 = 负提升 → 最优**带银狼 / 符玄凑 3 量子**(提升最明显)。
- 8 战技点成型难(开局凹战技点专家 + 局内 6 不同费用角色 + 2 转职)→ 不考虑。
