## 0. 证明一句话

无目标期帧的资金配置三臂判据成立:**甲臂**(方向化囤货)的资格判据逐字继承候选机器**强锁门**(G>ε),是公理 1 的 fail-closed 直推——机器缓锁门的 core 可见豁免角构成「判死方向可被锁」的构造可达路径,甲臂在该角漏授(保守向),由机器锁线后的 M2 义务买入自纠,作为已知缺口显式申报;**乙臂**(枢纽期权)的「覆盖数 ≥ 2 ∧ 非单卡注册身份」判据(五前件合取,含非合并素材时点守卫)对任意终局目标分布满足覆盖支配定理(u_h = P(C_h) ≥ 任一被覆盖单线的 u,零 P 值估计),且与甲臂筛结构独立(判据输入不含 G,病灶帧构造性非空);**丙臂**(换现守息)是两臂皆空帧的缺省姿态,其正当性 = 发展优先但书(01 §8-2)加 P83 息档效用,非数学支配——结论强度取最弱一环如实分级;判据成立则 FALLBACK_COMP_NAME 在 p2plus 无目标带无判据位,四面同批退役。

## 3. 命题本体证明

### 3.1 甲臂:强锁门逐字资格(fail-closed 公理直推;漏授角已知缺口申报)

**定理 A(甲臂资格判据的合法性)**:在活跃域(引理 Z)帧 f,记强锁判活集 `D_pass(f) = {d : R1 四合取全过}`。甲臂候选集 = D_pass(f) 是「方向化囤货」在公理 1 下可构造的判据形态;其承重前提「机器判活 ⟸ 过强锁门」在缓锁豁免角上有一个构造可达的反例域,按 fail-closed 极性申报为已知缺口(本定理第 4 步)。

证:
1. **承重项分析**:EV_hoard(d) = u_d·P_miss·C_rescue + refund − L − V_slot(正本 §2.2,P41① 同形)。该账能否支撑「向 d 囤货」完全取决于 u_d = P(d 成为终局锁线目标)是否有合法来源(01 §6:无合法来源的数字禁入决策门)。
2. **机制分析(R2 双门)**:现行代码中「一条线成为锁线目标」的通道有二。强锁门按 R1 四合取判线,是**逐线、逐帧无条件求值**的方向谓词;缓锁门按「core 在店/在手 ∨ G>ε」判**信号**(方向须先持有意向信号才入该门),core 可见支短路 G。强锁门的 G>ε 是「该方向可被机器锁下」的**充分结构令牌**;缓锁门的 core 可见是另一条充分令牌,但它以信号在场为前提(事件给定量),不是逐帧方向谓词。
3. **fail-closed 直推(01 §2 公理 1)**:对 G(d) ≤ ε 的方向,强锁门判其不可锁;若该方向无信号,缓锁门亦不可达——此域内 u_d 无任何机制来源(R3),公理 1 执行形态 = fail-closed:不给囤货授权,留遥测,不猜缺省放行。甲臂候选集 = D_pass(f) 逐字继承强锁门(同谓词/同常量 ε/同 plane 条件,:1600-1607),零新数字;G=0(绯英 G=0.0000,P35 §6-5 在档)是判死的极端实例不是定义——按 G>0 字面放行会复刻「囤一个机器自己拒绝锁的线」的病灶同构(正本 §2.2 已废形态)。
4. **已知缺口(应修①申报;对抗审发现)——缓锁豁免角的构造可达漏授**:「core 可见 ∧ G≤ε」帧上(可能持信号的),机器会经缓锁门锁下 d(:1109-1110 短路),而甲臂按 G>ε 拒绝授权囤 d——「机器判死 ⟹ 不可锁」在该角不成立,且它是**当下可达的代码路径**,不是假想前提。处置与定性:
   - **极性 = 保守向漏授**:甲臂少授了一个囤货授权(方向 = d 的成员少买),不发生多授;fail-closed 纪律下漏授是安全侧错误(公理 1 的缺省方向即拒)。
   - **自纠通道 = 机器自身**:缓锁锁下 d 后 phase 转 locked,买面切换为锁定采购集 M2 义务(shop.py:686-687 路径),d 的成员恢复买入;缓锁消费位注的机制根据(「当轮可买……买入后缺件集即缩」,:1497-1498)正是该自纠的机制面。漏授面 = 锁定前若干帧的积累延迟,暂态有界。
   - **审方三选项裁决**:选 (a) 措辞精确化 + 缺口申报。(b) 甲臂补「core 在店 ∨ G>ε」被拒:该式不带缓锁的信号前件时会**比机器自己的双门并集更宽**(缓锁 = 信号 ∧ (core∨G),无信号的方向机器根本不入缓锁),带上信号前件则判据依赖事件给定量、不再是逐帧方向谓词——两条都破坏「机器原门逐字 + 零新数字」的资格结构,且属判据本体变更须重走对抗。(c) 论证乙臂覆盖该角被拒:d 的核心卡不必是枢纽(cov 可为 1),覆盖关系不一般成立,不能默认。(a) 的漏授角登记为构造可达路径,见 §6 锁增量 7。
5. **实现面**:直调 `line_completion_feasibility`,不消费 `promote_candidates`(该函数是 G8 观测载体,码内明文禁入任何行为消费点,cw_intention.py:1211)。

**强度分级**:本定理证的是「无信号 ∧ 判死方向当帧不可获囤货授权」的结构必然性(公理 1 直推)与「有信号 ∧ 判死 ∧ core 可见」角的已知漏授缺口(保守向、自纠、构造可达——如实申报);**不证**「判死方向永不可锁」。正本 §5.3-4 的证伪面(判活线大量未锁/判死线被锁的**系统性**背离 → 代理失效换源重立)维持:单点漏授角不触发换源,系统性背离才触发。∎

### 3.2 乙臂:覆盖支配定理与解耦形态终裁

**定义(结构候选线集与覆盖)**:帧 f 的候选线集

```
𝕃(f) = { l ∈ COMP_LIBRARY : l.name ∉ ist.evicted ∧ f.plane ∉ l.weak_planes }
```

只施加两类排除:**意图稳定排除**(evicted,意向层显式出局的线)与**注册表静态排除**(weak_planes,注册表数据)。**不施加**任何供给筛(`_core_reachable`)或概率筛(G)——理由在定理 B2 证明第 3 步。覆盖集 C_h(f) = {l ∈ 𝕃(f) : h ∈ core(l) ∪ shared(l)},覆盖数 cov(h) = |C_h(f)|(成员集口径 = char_routes,R4)。

**乙臂资格判据(终裁形态;五前件合取)**:

```
HUB(h) :⟺ cov(h) ≥ 2  ∧  h ∉ CORE_SINGLE_CARD_REGISTRY   (资格核)
          ∧ 非合并素材(发射时点:bench 无 h 的同名同星可合并副本)   (第五前件,P75 §5.1 原子⑩同款)
```

四谓词核(refund_full_star_ok / check_seats / t5_p1_false / check_affordable)+ 本资格核 + 第五前件构成乙臂发射合取。四谓词核的实现单一源与支配族合取先例归属(P74 §4.4/P75 §5.1 C1)承正本 §2.3 F10① 口径不变;第五前件 = P75 原子⑩语义在乙臂合取上的组合,**实现单一源义务现登记**:P75 自身落码批必须与本臂共享同一非合并素材谓词实现,禁第二实现。

**引理 B0(概率形)**:设 {P(l)} 是候选线上任意一个终局目标分布(条件于「最终有线被锁」;「终局无锁」事件把全部 u 等比缩减,不影响任何比较),则

```
u_h = Σ_{l∈𝕃} P(l)·1[h ∈ core(l)∪shared(l)] = P(C_h)
```

∎(指示函数求和即集合概率,定义改写)

**定理 B1(覆盖支配,全参数域)**:若 C_d ⊆ C_h,则 u_h ≥ u_d;且 P(C_h ∖ C_d) > 0 时严格。

证:概率测度对集合包含的单调性。∎ **零估计**:对任意分布成立,不需要任何 P 值输入——这是把「选哪条线」的参数用量词消掉的支配性论证(strategy-work §1「存在支配性论证时必须消掉参数」的执行)。

**推论 B1.1(对单线件的支配)**:单线件 d(C_d = {l0})且 l0 ∈ C_h 时,u_h ≥ u_d = P(l0)。**授权面注(存疑-2 处置)**:B1.1 只对**单线件**成立;多线件 x(C_x ⊄ {l_d})的 u_x = P(C_x) ≥ u_d 且可 > u_h,B1 不给出 u_h ≥ u_x——件级授权不得引用方向级定理,仲裁序按此收窄(§4.4 第一层)。

**定理 B2(与甲臂筛的解耦独立性)**:资格核 HUB(h) 只是 (注册表, ist.evicted, f.plane) 的函数,与 G 的取值及甲臂候选集基数无关;且在「机器全判死帧」(D_pass(f)=∅ 的病灶帧形态)上资格核非空**条件成立**(见第 2 步的逐帧条件性)。

4. **病灶帧的消解路径(关键)**:病灶形态「拒买期权却烧刷新费」不由本三选一消除,而由正本 §4.6 k_members 换源 + 本裁决**联合**消除:落码后 R1 合格集 = 判据臂输出,两臂皆空帧合格集空 → `no_chaseable_member`((ii) 类 fail-closed,域内照旧保留,R9)→ 刷新 fail-closed,烧费路径消失;必花域剩余活跃通道 = 升级 L3(方向中性发展支出,受域内预算闸收窄)与支配性买(有候选时)——发展优先不变量(01 §8-2)在带内继续成立。落码前后过渡期该病灶形态照常入遥测判读(正本 §6.2-5 占位纪律)。
5. **残余与回锅点**:两臂皆空帧若升级亦不可发射(cap 顶/不可负担),残余死金以零携带成本(P70)持有为购买力(P83)——这不是守息指令(该带丙臂不出指令),是授权面内无合法支出对象的自然 residue。判读回锅点 = 在案死角观测分键 `budget_gate_must_spend_deadend`:若实机/sim 判读显示入域帧金滞留恶化,回锅该节重裁(在案钩子,非新增挂账)。判读基线关联:`must_spend_r1_account_yielded` 在 p2plus 无目标帧族的计数落码后预期显著下降(方向预言,入 A/B 判读键,无裁决权)。

### 4.4 必答④(方案审 F6):同帧多臂仲裁序——**裁:三层序(支配序 → 机器原生序 → 注册表声明序),零参数**

**问题面**:甲乙两臂同帧并存(或乙臂多枢纽并存)且席位/金竞争时,发射序决定资源归属;落码前禁隐式定序(防实现顺序代替判据序)。

**先决澄清(竞争域收窄)**:三臂输出是**资格面**(哪些店面卡可买),不是整批支出指令——实际发射 = 店面存货 ∩ 资格面,逐件过各自合取(check_seats/check_affordable 在发射时点逐件判)。故:两件都能过合取且资源足够时序不承载行为(双发射,序无关);仲裁序只在「各自合取都过但资源只承其一」的竞争帧介入,且逐帧重评(竞错代价有界:两臂产物皆 1★ 全退可逆,次帧重裁)。

**裁决(候选级序,非臂级序)**:
1. **第一层·支配序(定理承载;存疑-2 收窄)**:覆盖甲臂方向所在线 l_d 的枢纽 h({l_d} ⊆ C_h)**先于该方向的单线方向件**(C_x = {l_d} 的待购件)——推论 B1.1 直接给出 u_h ≥ u_d,全参数域;**授权限单线方向件**:多线方向件(自身覆盖多线,C_x ⊄ {l_d})的件级 u_x 可 > u_h,B1.1 不供给件级授权,该类竞争**降第三层**。无覆盖关系时本层不介入(禁超纲:定理只授权包含关系,不授权跨覆盖比较)。
2. **第二层·机器原生序(甲臂内部/无支配覆盖时的甲方向)**:甲臂方向 = 机器强锁判活集上机器自身选择序的首方向(`sorted(-资产厚度, encounter_window_rounds)[0]`,cw_intention.py:1609-1613)——机器语义的一部分,同源零新键;其成员件的内部序 = 店面槽位序(确定性,零语义)。
3. **第三层·注册表声明序(确定性兜底)**:剩余并列(互不覆盖的多枢纽之间、枢纽与多线方向件之间、枢纽与无覆盖甲方向件之间)按注册表声明序(char_routes/COMP_LIBRARY 派生序)——纯确定性、零语义承载。

**显式否决记录**:**覆盖数降序否决**为仲裁键——覆盖支配定理是集合包含单调性,不是基数单调性(|C_h| ≥ |C_h'| 推不出 P(C_h) ≥ P(C_h'),非嵌套集合无授权比较);以计数排序会把未经定理授权的排序语义偷渡进竞争帧,是伪装参数(零调参纪律同判)。**席位数序否决**:竞争帧上两臂候选皆为 1★ 单件单位购(边际一席),该键在竞争域内无区分域。

**附带条款**:①各件合取不过 = 该件本帧不出手,不因序获得挤占权;②落码批发射序必须消费本序(单帧锁增量见 §6),禁实现遍历顺序;③枢纽 ∩ TRANSITION_PACK 交集成员在活跃域无双通道问题(规则④开域 ∩ p2plus = ∅,§4.1-4),该禁令保留为未来扩展守卫。

### 4.5 必答⑤(方案审 F12):方向级 EV 账聚合口径——**裁:refund 线性和 / L 整批一次 / V_slot 发射时点状态计价**

方向 d 的采购集 B_d = {x_1..x_n}(角色件;装备件零金币不入金账,P42 ⑥ 装备域与卡池 disjoint)。方向级账对卡级 P41① 形态的规范化:

1. **refund(d) := Σ_i refund(x_i)**——逐卡线性求和。依据:退货按件独立结算(P76 甲退货表逐件,1★ 全档净 0),卖整集 = Σ 独立卖出动作,线性精确。
2. **L(carry) := L(g, s_d, R, Ī, cap)**——整批一次,以方向批支出 s_d = Σ_i s_{x_i} 为**金位跃迁输入**求 P47 双轨迹递推,**禁** Σ_i L(·, s_i, ·) 逐卡分解:息档损失是金位阶梯函数 τ 的差分,τ 凹步进使逐卡分解既不独立可加又路径重复计账(P48 整批纪律同源);同帧多臂支出时,L 在各臂差分账内按**各自分配案**的批支出求值——臂间比较是分配案比较,不是逐卡份额分摊。
3. **V_slot(d) := 发射时点状态计价(存疑-1 钉死,禁跃迁读法)**——对每件:**该件发射时点的 free 状态**计价,free ≤ 1 的件按 V_slot(被阻断动作净 EV)计一次,free ≥ 2 的件计 0——与 P41③ 逐件状态判逐字等价,不按「使 free 落入 ≤1 的跃迁」读法(该读法会把 free=2 时点的单件购置误计价,与 P41③ free≥2 ⟹ 0 矛盾)。多件批的 free 状态按 §4.4 仲裁发射序逐件推进(序确定 ⟹ 状态序列确定);free = 0 时 check_seats 先拦,不产生计价格。**n=1 退化自检例**:free≥2 帧单件购 → 0(与卡级 P41① 恒等);free=1 帧单件购 → V_slot(与卡级形态恒等)。
4. **期权项不聚合**:u_d·P_miss·C_rescue 的承重是方向概率 u_d(机器来源,定理 A),保持方向级;不逐卡求和(防与 P41① 卡级口径混写)。
5. **消费授权声明**:本口径是账骨架的**定义**(正本 §2.1 的规范化义务兑现),当前零数值消费——u 系在册【拟】无点值授权(R3),甲臂资格门不消费 EV 账数值(资格 = 机器门);口径在未来任何标定消费位启用时按本节执行,防落码批自造第二口径。

### 4.6 必答⑥(方案审 F10③):契约带维度——**裁:拆键(带维度非对称期待),不弱化**

**现状**:契约谓词 `_k_projection_domain_full`(mandate_v1/criteria/contracts.py:150-154)无带感知:供给在场 ∧ 解析空 = 违例。翻标需求:p2plus 带落码后空集合法(两臂皆空 → 丙臂守息帧),p1 两带回退集注册表派生**构造性非空**(p1_gap = 四体系全集,p1_lock_band = 体系对成员集或链全集兜底,cw_intention.py:1727-1732;全带不消费退役常量,§4.1-2)——空集在 p1 带仍只能是「回退字面量空元组」复发缺陷。

**裁决**:按带拆期待,单一源不破:
1. **带 token 零新派生**:分带 token 已由 `k_empty_window_fallback` 第二返回值给出并在消费位现成(shop.py:660-661 `_tok`/`k_band`)——ContractCtx 增加 `k_fallback_band` 字段直传该 token,零第二派生。
2. **非对称期待**:p1 带(p1_gap/p1_lock_band)维持非空期待(空 = 违例弃权+计数,检测力保留);p2plus 带空集合法,**但**合法空必须携带来源证据——ctx 增 `k_fallback_source` 字段,p2plus 空集仅在 source 标明判据臂评估产出时放行;无来源标记的空 = 违例(复发形态守卫不松动)。
3. **分期接线**:退役常量在位期(现行为),p2plus 解析恒非空(绯英采购集),空集仍违例——契约行为零变化;退役落码批同批翻 p2plus 支(带 source 字段),防「先放宽契约后等实现」的悬空窗。
4. **测试重推**(sr-od-test/test_cw4_contracts.py:245-258 现行四例随批改六例;低-6 补全处置):①k_target 非 None → 过(不变);②供给在场 + 解析非空 → 过(不变,现行 :245-248 例,两带皆然);③供给缺帧 → 过(不变);④供给在场 + p1 带空 → 违例(原「解析空」例收窄至 p1 带,保留);⑤供给在场 + p2plus 空 + source=判据臂 → 过(新);⑥供给在场 + p2plus 空 + 无 source → 违例(新,复发守卫)。:330 的 `shop_k_fallback_p1_gap` 计数锚随带语义复核(p1 带行为零变化,锚应保绿;红则按锁的存在性纪律重推,禁机械跟绿)。
5. **遥测分键**:p2plus 合法空帧(丙臂缺省帧)发射独立分键(独立计数键先例 = `core_unlocked_buy_hit`),禁混入历史 token `shop_k_fallback_p2plus`(该 token 语义 = 回退采用,混桶会毁判读,正本 §4.4 行 1 同纪律)。
