# ADR-0415: sim 段级检验形态——轮数窗口 + 段级检查表(`_SEGMENT_CHECKS`)

## 状态

Accepted(2026-08-27,W278 sim 段级短跑批)

## 背景

实机一局几十分钟,B 类策略行为病(金滞留/成型后仍买过渡件/无依据追级/无依据破息)暴露太慢。sim 只能给出「跑完整局后的终态分布」:`cw_sim batch` 只有局级统计,过程病在 sim 里天天发生却没有任何机制在**轮级**把它们抓出来——这正是 sim-testing.md §6 明文承认的 B 类病三缺口之①「过程不可观测」。

## 决策

1. **轮数窗口 = 账本前缀切片**,不是真的中断模拟循环。`simulate_p1_batch(max_rounds=K)` 把各局账本的前 K 轮行作为段级检查的输入。依据:逐轮执行是因果序的(轮 k 的 state 与决策只依赖轮 <k;节点序列虽开局一次性预采样,但不改变「逐轮决策流 = 全量账本前缀」),同 seed 同池下,前缀切片与「真跑到第 K 轮停下」的逐轮决策流零差异。报告带 `max_rounds` 键披露窗口(None=整局);**不传参数时全链路逐位不变**(零漂移门,n=40 快照对拍实证:除两个新增披露键外全部字段含 seed42 逐轮轨迹完全一致)。
2. **段级检查表 `_SEGMENT_CHECKS` 与 `_BATCH_CHECKS` 平行**,输出粒度不同:批次表给「违规局数+局索引」,段级表给**带定位的事件列表**(哪局·哪轮·违反哪条·当时 state 关键值),事件自带 game_idx/seed(check 契约:seed 重放 `cw_sim replay --seed N --pool snapshot` 可还原现场)。batch 默认内嵌、独立于 `checks` 开关辖域(只增报不改行为,纯账本消费零 rng)。
3. **首批检查项全部单轮可判**,例外条件编进断言(对齐口述 [6][11][12][13][16][17][19]):
   - `seg_gold_identity`:金账恒等式链式版(上轮末金+收入−支出=本轮金);
   - `seg_overflow_idle_spend`([17]):金>50 零花未成型;成型停手/bench 满拦截豁免;
   - `seg_lossless_buy_missed`([11]):金<20 同息档有过渡带件未买(跨档有息损不断言,[11] 只锁零息损形态);
   - `seg_break_interest_exception`([6]/[19]):破息轮必须落在例外内——店全想要代理(买入≥2 笔无一 off)/连胜保(进轮重算连胜≥2)/奖励节点买经验([16]②);事件带店面板与最终选择供归因;
   - `seg_formed_still_buying_transition`([13]):成型判据复用现有单一源(`_engines_count≥2`),只断言过渡填充件(engine/pair 身份且不在 bridge/目标 comp 名册且非同名副本升星路径);
   - `seg_unjustified_levelup`([12]/[33]):授权依据观测(LevelUp.auth_basis ∉ {pop_slot,dp,static_ev}),奖励节点豁免。
   部分「该不该买」判据是**代理口径**(如店全想要用买入 channel 纯度代理),违规率按诊断量级读、不作达标线——这是段级扫描仪不是验收器,P1 验收仍归 strategy-work §2 双指标。

## Considered Options

- **真中断模拟(max_rounds 断循环)** vs **账本前缀切片**:前者要改 simulate_p1 循环体与 rng 流语义、多一条回归面且无行为差异收益(RNG 前缀一致已证明等价);取后者。
- **检查输出并进 _BATCH_CHECKS(复用 violations/games 形态)** vs **平行表事件粒度**:段级病的归因需要轮级现场,「违规局数+局索引」会丢失可定位性,重放成本转嫁给每个消费者;取平行表。
- **一刀切断言(金>50 零花即报)** vs **例外条件内嵌**:口述条目的价值就在例外边([6] 店全想要/[19] 连胜保/[16] 奖励节点),一刀切=误报泛滥=检查被忽略;取例外内嵌(docstring 记来源与边界)。
- **每条新检查都设计「该买的件」完整语义模型** vs **单轮可判的代理口径**:P1 先行的目标是把过程病扫出来,代理口径+量级说明够用且诚实;语义模型归后续按实际误报率迭代。

## 后果

- sim 批从此顺路扫过程病;报告新增 `max_rounds`/`segment_checks` 两键(纯增量)。
- CLI 新增 `--max-rounds K`;不传时既有命令逐字节同结果。
- 零漂移证据:n=40 pool='snapshot' 改动前后对拍 diff=仅新增键;池指纹 fbbc4a406fdb7d6d 两侧一致。变异探针:registry 注入臂去 `interest_rule` 约束后经济类段级违规涌现(数据见当批进度登记)。
- 已知边界:「该买的件」判定是代理口径,误报率随策略演进需复查;段级事件 `events` 报告侧截断 20 条(count 是真值)。
