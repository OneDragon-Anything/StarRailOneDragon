## 5. 偏差申报与边界声明

1. **W11 标记键为四元组而非三元组**：设计原文标记 = `refresh_blocked(<节点, 金, 席位快照>)`，清除条件含第四项「星级目标完成」。实现把第四项并入比对键（星级目标键 = `unfinished_star_targets` 名-必要星级序元组），节点推进与星级目标完成两条件均经键分量比对承载——语义覆盖设计全部清除条件，载体结构申报如上。
2. **W11 标记不进 `_NODE_SCOPE_RESET_TABLE`**：登记表在 `session_scope.py`（非本批文件面）。节点级生命周期经键内节点序位分量比对承载（失配即失效并清值），语义与表登记等价；`mandate_state.py` 字段注释已声明该读法。
3. **W11 记忆拒因闭集 = 设计两键**（`target_unbuyable` / 金线不足）：判据族其余拒绝键（`stay_gate_upgrade_first`/`p1_no_refresh`/`unlocked_no_qualified_gap`/`no_star_target`）不置标记——升级优先与阶段语义的循环终止由资金序声明自身承载（refresh-chain §2 资金序声明），扩入记忆会掩盖「攒金收敛态」的正当重入。
4. **W4 否决联动边界**：窗口否决只作用于 M6 臂（触发谓词否决，含其席满置换支）。垫件补位支触发式含 `_m6_exhausted`——否决帧 M6 未耗尽（`_m6_exhausted` 保持 `gold <= g_star` 的假值），垫件支结构性不发射，方向与让位目标一致；`m6_bench_full`/`m6_overflow_strand` 观测键在否决帧不计数（臂未触达）。设计原文只点名 M6，垫件支的连带行为在此如实申报。
5. **W5 序 2 场况插件臂不在停买辖**：达标成员的同名副本仍可能被序 2 按羁绊差一判据正当买入（臂语义 = 羁绊激活，与追星正交；星间旅人系档表自 1 起，空板帧恒命中）。矩阵行 7 测试为此改用命运圣杯红A 线（远坂凛，档表自 2 起）隔离序 2 干扰——测试帧构造申报，生产行为无对应改动。
6. **M2b 未锁窗口扩面**：谓词机制全集重写后，未锁窗口 M2b 对「2×1★ + 已持同名 2★」形态的候选线成员同样承接合成完成买入（旧口径跳过）。属机制全集消费的连带扩面，方向 = 合成推进，非锁定面行为变化（未锁窗口缺件集/囤臂判据零变化）。
7. **测试镜像命名**：`shop/test_decide_shop_action.py` 规范名已被统一保护集迭代占用，本批落位 `shop/test_decide_shop_action_star_arms.py`（方法目录 + 主题后缀）。
