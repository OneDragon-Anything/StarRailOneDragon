# 商店(store)

商店界面。**2026-11-12 UI 改版后为双层结构**:顶层 tab「推荐商店 / 常驻商店」;推荐商店挂商品推广页(列车补给凭证/开拓助力等直购商品),常驻商店挂兑换类子商店(星芒/余烬兑换、外观、星琼购买等)。真实货币购买(月卡/星琼)的入口都在这里。**不锁光标**(`pc_alt=false`)。

> 2026-11-12 实机核对:本档为**新版 UI** 全量重写。旧版 UI(左上面包屑「商店/推荐」+ 左侧 7 入口平铺:推荐/列车补给/兑换商店/聚灵铸星/外观商店/协议商店/捕获梦华/星琼购买)已整体过期,对应旧 fixture(原 推荐/光锥呈现/戏言成真.webp)已换成新版实拍。

## 1. 何时出现 + 状态流转

- **入口**:手机菜单点「商店」图标(`ClickPhoneMenuItem(STORE)` 模板匹配,语言无关)→ 商店,默认落**推荐商店**页。⚠️ 菜单→商店开屏有**较长过场动画**(黑屏加载,实测 ~8-10s),自动化要宽等待。另一入口:逐光捡金选关屏「奇珍琳琅」→ 商店(旧 UI 观察落子商店页;新版落点待复核,见 §7)。
- **状态流转**(动作 → 下一态,全部为商店屏内子态切换):

| 当前态 | 动作 | 下一态 |
|---|---|---|
| 推荐商店-活动推广 | 点左侧栏商品项(寰宇美学/万象和鸣/**列车补给凭证**/开拓助力/特惠车票/专票礼盒) | 对应商品详情页(左侧栏保持可见) |
| 推荐商店-活动推广 | 点 tab-常驻商店 | 常驻商店 |
| 常驻商店 | 点 tab-推荐商店 | 推荐商店(记住上次选中的左侧栏项) |
| 常驻商店 | 点左侧菜单(兑换商店/聚灵铸星/外观商店/协议商店/捕获梦华/星琼购买) | 切子商店 |
| 常驻商店 | 点顶部分类 tab(星芒兑换/余烬兑换/星尘之礼/光锥呈现/戏言成真) | 切商品网格 |
| 常驻商店 | 点商品卡 | 购买弹窗(独立屏 `商店-购买弹窗`:数量加减/取消/确认;布局与旧版一致) |
| 商品详情页(列车补给凭证) | 点「购买 ¥30.00」(无生效凭证)/「续订 ¥30.00」(生效中) | **扫码支付弹窗**(默认支付宝二维码) |
| 扫码支付弹窗 | 点「其他支付方式」 | 微信支付二维码(按钮变「返回支付宝扫码」,再点切回支付宝) |
| 扫码支付弹窗 | 点右上 X | **确认放弃本次支付?** 弹窗 |
| 确认放弃本次支付? | 点「确认放弃」 | 两层弹窗全关,回商品详情页 |
| 确认放弃本次支付? | 点「继续支付」 | 回扫码支付弹窗 |
| 任意态 | 点右上关闭 X | 回进入前画面(菜单入口实测回手机菜单;goto_list 按入口记双边:菜单/末日幻影-选关) |

- **商品详情页 → 扫码支付 = 真实货币出口**:`¥30.00` 由用户扫码支付,bot 止步于扫码弹窗,永不代付(消耗门,见 §5)。

## 2. 识别特征(稳定锚点)

- **id_mark = tab 双锚**:`tab-推荐商店` + `tab-常驻商店`(text)——顶栏 tab 行在商店**所有子态**(推荐/常驻/商品详情/扫码弹窗/放弃确认/购买弹窗)都可见,一次建锚全态识别。商店内任何帧都是 `商店 is_precise`,子态区分靠 area 命中(子态 area 挂本屏,框架精准早停语义下这是有意设计:遮罩层不遮顶栏,拆独立屏反而抢不到识别)。
- **推荐商店-商品详情态**(列车补给凭证):`标题-列车补给凭证`(右上大标题,text)+ `入口-列车补给凭证`(左侧栏选中项,text,与标题同文不同位)。
- **扫码支付态**:`标题-扫码支付`(text)。
- **放弃确认态**:`弹窗-确认放弃支付`(text「确认放弃本次支付」)。
- **常驻商店态**:`tab-光锥呈现` / `tab-戏言成真`(顶部分类 tab,text;仅常驻商店可见,可作「在常驻商店」的判据)。
- `pc_alt=false`。
- 易变:货币数(古老梦华/星琼/专票)、活动推广内容与倒计时(幻乐秀场/40天14小时,随版本轮换)、商品价格与限购角标。**左侧栏商品项与活动推广内容随版本轮换**,勿当永久锚。

**扫码支付弹窗态**:
| 元素 | 行为 |
|---|---|
| 「其他支付方式」/「返回支付宝扫码」 | 支付宝↔微信 二维码切换(同槽位二态) |

## 5. 消耗红线(真实货币)

- 「购买 ¥30.00」= **真实货币出口**。bot 的职责止步于**摆好二维码**(扫码支付弹窗),支付由用户扫码完成;**任何情况下不点「确认放弃本次支付?」以外的支付确认类控件,不代付**。
- 商品详情页浏览(点左侧栏、读规则)零消耗;「打开二维码」本身零消耗,但语义=发起购买,调用方(agent)须先向用户确认购买意愿再走到这一步。

### 2. 推荐商店-列车补给凭证详情(本档 source_image)

- 何时出现:推荐商店点左侧栏「列车补给凭证」。
- 匹配画面:`商店` is_precise;命中 tab 双锚 + `入口-列车补给凭证` + `标题-列车补给凭证` + `按钮-购买`(OCR「购买￥30.00」)。
- 内容:购买即可获得 300 **古老梦华**;30 日内每日赠送 90 星琼(最高 2700);规则说明(i)。
- 机制(规则说明实测):¥30 → 立即 300 古老梦华 + 生效延长 30 日;生效期间每日登录领 90 星琼(凌晨 4 点重置,未登录不补);生效时间 <179 天才可继续购买,≥179 天禁购;异常重复购买返还 330 古老梦华。
- 关联:生效期每日登录的「列车补给」领取弹窗是独立 screen `列车补给`(express_supply,「点击领取今日补给」)——该建档录于旧版,新版是否漂移待有生效月卡时复核。

### 2b. 推荐商店-列车补给凭证详情-生效中(`source_image: screens/商店/推荐商店-列车补给凭证-生效中.webp`,2026-11-12 实购后实拍)
