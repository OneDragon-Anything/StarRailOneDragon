# 货币战争-难度确认

## 画面简介

职级难度画面（开始对局）：从模式选择点「进入标准博弈」后出现，确认难度档位并开局。画面特征：左侧职级列表（纵向大数字档位、可上下滚动，当前职级如 A5 紫金高亮）+ 右侧「当前职级难度效果」区 + 底部晋升点 / 积分 / 敌人难度 / 词缀数量 + 右下「开始对局」按钮。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-当前职级难度效果 | 右侧「当前职级难度效果」区标题（画面身份锚），下方列各档叠加生效的难度效果 | 纯显示 |
| 按钮-返回最高职级 | 右下「返回最高职级」钮。只在选中档不是最高已解锁档时出现；选中档已在最高已解锁档时，该位置没有这个钮 | 点击跳回最高已解锁档 |
| 按钮-开始对局 | 右下「开始对局」主钮 | 点击确认难度并开局（静态点击；无效时微距拖拽兜底） |
| 标识-当前难度职级 | 左侧当前选中职级的标记位置 | 纯显示 |
| 区域-职级列表滚动区 | 左侧纵向档位转轮：居中的焦点带显示选中档的大数字（白色发光，嵌在三角徽章底座上），焦点带上方露出 1 档、下方露出 2 档，离焦点越远越暗越小。屏幕上自上而下档位数字递减（更高档在上）。未解锁档的数字左侧叠一个锁图标（纯图标，旁边没有解锁条件文字）。顶部、底部中央各有一个翻页箭头，右缘有随滚动位置移动的菱形位标（这三者没有 area） | 拖拽滚动列表 |
| 文本-当前档位 | 焦点带大数字 = 当前选中档的序号。读数须裁剪后 OCR：全帧 OCR 对这个大数字会偶发漏检 | 纯显示 |
| 标识-当前档位锁定 | 焦点带大数字左侧的锁图标。出现 = 选中档未解锁，此时「开始对局」置灰 | 纯显示 |
| 标识-上方档位锁定 | 焦点带上一档（屏幕上方紧邻的那一档）数字左侧的锁图标。出现 = 上一档未解锁 | 纯显示 |
| 底部信息条（无 area） | 底部晋升点 / 积分 / 敌人难度 / 词缀数量读数（例：晋升点 2700(+80%)、积分 18000、敌人难度 35 或 36、词缀数量 2；同一职级的敌人难度会随局浮动，开局读数以当帧为准） | 纯显示 |
| 文本-敌人难度 | 底部「敌人难度」标签上方的数值 = 当前选中档的敌人难度，随选中档变化（例：第 3 / 4 / 5 档 = 34 / 35 / 36） | 纯显示 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 确认难度并开局 | MCP `click_game`（无效时微距拖拽兜底） | 「按钮-开始对局」area 中心（识别返回坐标） | 进对局开局，下一个画面是简报 | — |
| 上下滚动查看其他职级档位 | MCP `drag` | 在「区域-职级列表滚动区」内纵向拖拽。**手指下滑 = 列表内容上滚**（焦点带下方的那一档升入焦点位，选中档序号变小，如第 4 档 → 第 3 档）。反向拖拽 = 列表内容下滚（上方那一档落入焦点位，选中档序号变大，如第 4 档 → 第 5 档）。拖完列表按档位吸附停靠，焦点带始终对齐一个档位 | 焦点带换成新档位的大数字；底部敌人难度数值同步变化 | 停在未解锁档时「开始对局」置灰 |
| 跳回最高已解锁档 | MCP `click_game` | 「按钮-返回最高职级」area 中心（钮只在选中档不是最高已解锁档时出现） | 列表跳回最高**已解锁**档（如停在第 5 档带锁时点击 → 回到第 4 档），「开始对局」恢复可点，钮本身随之隐藏 | A5 紫金 = 80 血开局 + 敌人难度 +3 + 升级需更多经验，属当前职级正常配置（非异常） |

开局难度默认规范按「最高可达档」执行（当前 = A5 紫金 4）；选档以本画面列表为准，别按晋升等级数字推可达档位。
