# 腾席资格面与代理收窄（详设：T-18 / T-20）

## 问题与约束
本篇辖两批，共享 mandate_v1 腾席（卖出换金）资格语义；单源契约按总纲 IC-1（T-18 定谳的资格面 = T-20 收窄基准）。域边界：mandate_v1 决策面为 unified-state W6 统一容器对象，本篇只做资格面点状修复，禁动决策链结构。

### T-18 腾席卖出上游滤占位件（旧账 T-294）
- **根因归层**：语义层——腾席卖出资格面缺占位件语义（生产资格面未建模「占席非角色物品不可变现」），非流程/表示缺陷。
- **症状**：腾席卖出通道不滤箱占位件——系策略资格面缺陷：既有修复只做了假环境侧对账，生产资格面 `fuel_sell_candidates` 仍会把占位件列为候选（依据 = 旧账 T-294 卡，T-216 落地审未尽①维持立项）。占位件语义 = 备战槽非角色占席物品（补给箱/星徽秘典/典籍书册等，知识锚 = docs/game/currency_war/research/board_structure.md §备战栏「备战槽可被非角色物品占据」）。
- **分段结构（核证先行，禁跳段）**：
  1. **核证段（候实机窗）**：实机核证「箱可卖真值」——占席物品在卖出交互里是否可作为卖出对象（交互实锤：实机窗对占席物品执行卖出尝试，采集画面证据）。结论先行落档 docs/game/currency_war/research/board_structure.md §备战栏（带证据分级）。复查时机 = 随实机窗（与 T-13 建档、T-14 验证族同窗盘点）。
  2. **定谳段**：按核证结论定修法——若箱不可卖，`fuel_sell_candidates` 生产资格面滤 `BenchChar.is_item_slot`（识别防线已有，实机识别批落地，依据 = board_structure.md §备战栏 bot 识别防线条）；若部分可卖，资格面按可卖子类建模。
  3. **落码段**：生产资格面落码 + 行为锁 + CW 子集绿。改动面 = mandate_v1/mandate.py（fuel_sell_candidates 及其调用点）、mandate_v1/shop.py（卖出通道装配）、mandate_v1/entry.py（发射面）。
- **约束**：文件面与 T-24（shop.py 悬空引用清理）、T-20（shop.py P92 段）互斥；**与 T-16 共 mandate.py 互斥（fuel_sell_candidates 及其调用点 × m3_levelup_batch 段，两段同文件，编排者控制在飞互斥——总纲 §1 症状 3）**，均按 landing.md 排布串行。

### T-20 seat_recoverable 代理收窄（旧账 T-316）
- **根因归层**：语义层——「席可落」判定语义用宽代理近似（`liquid_refund > 0` ≠ 存在可变现对象），判定语义失真非实现缺陷。
- **症状**：P92 全通道可实现买入集存在性门的「席可落」判定用宽代理——调用方传 `liquid_refund > 0`（P56 投影清算值）作 `seat_recoverable`，docstring 已申报代理偏宽：高估腾席可达 ⇒ 门偏不拦 ⇒ 保守端（依据 = shop.py:2728-2729 注释申报 + criteria/refresh.py:196-199 代理偏宽申报）。T-313 落地审发现 B 的对拍面已闭环，**代理收窄维持在册**（旧账 T-313 note）。
- **分段结构（诊断 → 方案 → 落码，独立三段）**：
  1. **诊断段（可先行）**：量化代理偏宽面——枚举 `liquid_refund > 0` 为真但实际无可卖对象的帧形态（含占位件被当候选的形态，与 T-18 症状同源），产出偏宽清单。
  2. **方案段（候 IC-1 单源）**：收窄基准 = T-18 定谳的 `fuel_sell_candidates` 资格面——`seat_recoverable` 改为引用该资格面（存在可变现 1★ 燃料件 = 资格面非空），禁平行第二实现。T-18 未定谳期间方案段挂起；若编排者裁决先行，只允许「与现行资格面同源化」的机械段，箱语义修正随 T-18 结论复验。
  3. **落码段**：mandate_v1/shop.py（P92 装配点）+ criteria/refresh.py（判定尺签名与 docstring）+ 行为锁（代理收窄后拦刷行为对照：偏宽帧从「不拦」翻「拦」的样本锁）。
- **约束**：行为面属策略门（P92 拦刷），落码批必过方案审 + 落地审双审；判定尺 docstring 的代理偏宽申报段随批更新为收窄后语义。

## 方案（实施序）

## 关键取舍
- **核证先行，不先写修法**：箱可卖真值未核证前任何资格面修法都是猜（旧账 T-294 卡明文「先实机核证再定修法」）；宁挂 wait 不虚设开工。
- **T-20 不抢跑**：代理收窄若先于 T-18 落码，收窄结果继承占位件误列缺陷，T-18 定谳后必须返工——同源依赖显式排为依赖边，而非侥幸并行。
