# 0211 玩法方向裁定:优势布局钻钞 farming 与砂里淘金电表流均不采纳(用户裁定)

- **Status**: accepted
- **Date**: 2026-08-17(补录 2026-08-18,原记录在 strategy/19 号 P5/P7)
- **Context**: 两项社区/攻略验证过的"高收益"玩法方向被提出:①优势布局跨局钻钞经济学(farming 超频局刷钻→喂优势布局→降 A8 门槛);②砂里淘金电表倒转流(合 2星2费 白得砂金,金币越滚越多)。两者都需要 bot 围绕它改变打法。
- **Decision Drivers**: A8 生存时序门(成型晚/过程脆的流派撑不到兑现);跨局持久化状态默认不碰的用户方向盘;ROI。
- **Considered Options**:
  1. **建触发线,识别到即切流** —— 两者均成型晚、过程脆;砂金流需 500-600 金启动资金 + 凹开局;钻钞 farming 与砂金流同类,跨局性价比低。
  2. **不采纳,选卡照常评估**(采纳) —— 砂里淘金作为一张卡,若阵容本就用砂金(护盾/追击组件)则白捡,pick_value 正常评估,不压不抬;优势布局维持 `manage_meta_run` 默认 false 不碰。
- **Decision**:
  1. **砂里淘金(P7)**:不建触发线、不围绕它改打法;选卡按正常价值评估。
  2. **优势布局钻钞 farming(P5)**:不建跨局钻钞预算分配/元循环;优势布局保持默认不碰(README 配置口 `manage_meta_run=false`)。
- **Consequences**: 后续 agent 不再提案这两方向的打法改造;若版本改动使其成型提前/变稳,须新 ADR 推翻本条再动。通用教训(随 P7 记):均值好看 ≠ 时序可达,「围绕卡改打法」类提案一律先过 A8 生存时序门。
