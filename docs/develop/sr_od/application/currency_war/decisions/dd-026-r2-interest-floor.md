# DD-026:R2 预算门息线 floor 落码(修 R2)——刷新门预留组装补位 P40 规范口径,b_target 零参退化退役出刷新消费位

- Status: accepted
- 日期: 2026-09-12
- 出处: P54-r2-interest-floor + P53 §④ 申报 1(挂账交互)+ REFRESH_CFO_REPORT(`.debug/temp/currency_war/ab_run_20260903_r2/`)§6/§7 + horizon_vgap_b1 对拍(修 A 后刷新 77.83 次/局、金刷穿 0-4、2★ 0/30)

## Context(背景与问题)

修 A(DD-025)解除 R1 拒刷后,sim 对拍暴露刷新系统性超调:78 次/局,金被刷穿到 0-4,买入链饿死(见件买不起),2★ 0/30。根因 = cw4 R2 预算门(`criteria/refresh.r2_budget`)的预留输入在消费位组装为 `b_target(0,0,0)=0`(P48 整买目标零参退化形),门退化为 `gold ≥ 2`——P40 R2 规范口径「溢余段刷窗 `n_max = ⌊(g − 50 − Σ预留卡价)/c_eff⌋`」从未落码;修 A 之前被 R1 全拦掩蔽,修 A 解蔽。REFRESH_CFO_REPORT §6 当时明令「不要动 R2 预算门」,其语境是修 A 批辖域(R2 非彼批病灶);修 A 后的 b1 对拍使该交互成为独立病灶,本批解除该明令并治本。

## Decision(决策)

`shop.py` R2 消费位的预留组装改为 **`reserve = g* + ρ`**:

- `g*` = `saturation_line(cap_resolved)` = 10×cap_resolved(默认局 50,`GOLD_CAP_INTEREST` 表值派生;与守息线同源派生,不新增第二源);
- `ρ` = 合格集(可追成员,与 R1 装配侧同一过滤)最低费卡价(`CHARACTERS` 注册表派生;单卡下界口径,P40 待标定清单「最低费卡价 × 期望命中数」的 A2 整数下界);

`criteria/refresh.r2_budget` 判据本体与契约(先例②)零改动——`gold − (g*+ρ) ≥ c_eff` 与 P40 规范式逐位等价(P54 §①)。跨档破线刷不加「L 覆盖即放行」旁路:息损计价(L,效率面)在 R1 账内已有,金位下界(生存面)由本 floor 硬保证,两道门独立(P54 A4)。

零新自由参数:全部分量 = 注册表/表值直读或结构派生。

## Considered Options(备选与取舍)

1. **预留组装补位(采纳)**:判据不动、消费位补规范值——与 P40 逐位等价,零新参数,数学可证级(strategy-work §3 档 1 直接落码无开关)。
2. 拍预留常数(如 reserve=50):禁——常数与 cap_resolved 脱钩(息律投资 cap=10 局息线 100),且无 Σ预留卡价分量,复发即下一个域错位。
3. R2 加「L 覆盖即破线刷」通道:禁——b1 实证 R1 在中低金位持续开门,单靠 L 计价挡不住金刷穿;破线刷新与「把金花光」(P40 R1 立论原文)同向,生存面必须硬下界。
4. 同批修 EV 买面/M6 的 S 预留零退化(姊妹缺口):不同消费位且 sim 注入态下全 fail-closed 不可观测——挂账交编排者裁决,本批辖域限刷新门。
5. 修 R1 的 L 项让跨档刷自平衡:错误方向——b1 病灶是金位生存面缺下界,不是息损计价不准。

## Consequences(后果)

- 正面:刷新通道结构性永不掉满息档(`g' ≥ g*`)且至少一张命中卡可买不破线(`ρ` 预留);金刷穿(0-4)与买入饿死消除;刷新回落健康带(P54 §④ 预注册:0 < r/局 ≤ 30,刷新波破线 = 0)。
- 代价/边界:跨档破线刷在 cw4 被完全禁止(带宽 = 效率换生存);`ρ` 单卡下界口径在期望命中 >1 帧偏紧(门偏收,保守端);2★ 兑现仍辖买入/卖出席位策略批(本臂副本数结构性封顶 1,P53 §④ 申报 2 继承)。
- 测试面:旧行为锁(gold=60 开门 / gold=1 关门)在新 floor 下语义不变、不红;新增帧级/账本级行为锁(贴线拒刷分键 + 门过帧刷后投影金 ≥ g*+ρ)。
