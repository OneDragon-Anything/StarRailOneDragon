# 角色-光锥(character_light_cone)

> source_image: sr-od-test/screens/角色-光锥/default.webp(2026-10-17 live 建档,布洛妮娅光锥页)

## 何时出现

角色页左侧「光锥」TAB;或详情页右下光锥卡点击跳入。独立屏。

## 状态流转

```
详情 TAB/光锥卡 → 本屏(显示当前角色装备的光锥大卡+右侧信息)
替换按钮 → 光锥-替换列表(已建档[light_cone_replace.yml];多屏可滚动,见该 doc)
强化按钮 → 光锥强化页(未建档,内部页;强化走晋阶材料)
右上关闭 X → 离开角色页
```

## 未装备态(实机实证 2026-11-13,星神★阿哈)

角色无光锥时本屏为空态子态,与已装备态差异:

- 中部显示空光锥占位卡(+号),右栏「未装备」、等级 0/0、三围「-」;
- 底部按钮**只剩「装备」**(1465-1880,963-1018,带红点提示)——「替换」
  「强化」按钮在本子态不存在,已装备态的按钮坐标全部不可用;
- 「装备」点击同样进入「光锥-替换」列表(与「替换」同屏,见该 doc)。
