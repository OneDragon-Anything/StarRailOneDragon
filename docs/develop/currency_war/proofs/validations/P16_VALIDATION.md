## 1. 五门判定

### 门① 内部推导 —— **需修(两处实质瑕疵,主线成立)**

逐段核:

- **超几何 p̄ 构型**:per-tier 全概率展开 `P(≥1|cost)=Σ_m B(m;5,p_cost)×[1−C(T−A,m)/C(T,m)]` 与 `p_bar_faction`(cw_line_switch.py L83-90)逐项一致,与 `cw_shop_odds._refresh_dist`(L120-143)/`ev_proto.p_at_least_one` 同构、与 P5 ①的表同源(REFRESH_PROB 同表)✓。多标签并 `1−∏(1−p̄_f)` 高估方向已在 DESIGN §附5 诚实列表 ✓。
- **【瑕疵 A(实质)】「费用档互斥,故各档概率可加」——论证错误,且数值影响非微量**。每格恰属一档(格互斥)推不出「各档 ≥1 目标事件互斥」:同一次刷新可以同时在不同档各出 ≥1 目标件。`p̄ = Σ_cost P(≥1|cost)` 是**并集上界(union bound)**,非精确式。独立重算(持续伤害,lv6):代码/证明锁定值 0.3502 = Σ P(≥1|cost);按格 iid 精确值 `1−(1−Σ_c p_c·n_c/v_c)^5` = **0.3237**(同档格间不放回略抬高真值,真值 ∈ [0.3237, 0.3502])——**相对高估 0~8.2%,证明自己的锁定锚就带着这个偏差**。方向与「p̄ 满池乐观」一致(δ 部分吸收),但证明把它写成「精确式/正确读法」是错误声明;该误差是**可解析修正的**(并集换精确式零成本),不该混进 δ 的经验修偏里。
- **【瑕疵 B(措辞级)】「已见牌扣除……等价于按可见库存修正牌池,与 cw_shop_odds 的池模型同口径」——不成立**。实现里 held/shelf 只修分子 distance(L94-111),`p_bar_faction` 的分母恒用**满池 T=v·a**(L76-80,不减 held/NPC 消耗);而 cw_shop_odds 的池模型(`_refresh_dist` 的 rem_target=a−j)是真减池的。两者不是同口径,是「分子修正+分母满池」的保守简化。方向保守(乐观)且被 δ 声明覆盖,但「等价/同口径」字面为假。
- **θ 滞回代数**:切+切回两式相加得 2θ<0 与 θ>0 矛盾,δ 同乘不破坏——逐步核 ✓(经典 shifted-threshold 构造,正确)。退化双 inf 维持原线与实现一致(L163-164)✓。振荡频率 ≤1/(2·D_min) 的口径 = 完整周期(A→B→A 需 2 次切换、≥2·D_min 轮),推导成立;命题措辞「每次切换间隔 ≥D_min → 频率 ≤1/(2·D_min)」跳了一步(切换率上界是 1/D_min,周期率才是 1/(2·D_min)),可读性瑕疵非数学错。
- **误差界**:更新不等式 `d/λ ≤ E[T_d] ≤ d/λ + E[X²]/(E[X]·P(X≥1))`,X≤c_max=5 ⇒ E[X²]≤5λ ⇒ 加性界 ≤ 5/P(X≥1) ≤ 5/p̄(P(X≥1)≥单次自然刷命中概率 p̄)✓;自认「松包」诚实。「双线共模相消」的定性论证(δ/θ/快照漂移对双线同施)方向正确,但注意瑕疵 A 的档间并集偏差**不是严格共模**(两线费用档构成不同,偏差比例不同),残差进 θ——量级(单线 ≤0.4 轮)在 θ=1.0 预算内,可接受但未在证明中显式记账。
