# 转型域换人通道统一设计 迭代设计（总纲）

## 0. 元信息

- 迭代目标：用户裁定 2026-10-26（登记载体 = 本迭代进度账本 T-1 note）：换人策略按羁绊组双门 + 转型域统一收益-安全框架落地（治本方案）；净战力不证明（宪法第 1 条禁战力建模），行为锚点验收；P61 证明退役。
- 状态：对抗审中
- 文档清单：无详设（单文档方案，本篇即完整设计）

## 1. 问题与动机

- 现状症状：sim 局 g_20261026_203023（seed=20261216）复盘立案 C1——2-1 买主线核心 Saber 后 4 个备战期换人卖出 0 发射，板面保持位面 1 过渡配方直到死亡（复盘报告 = `.debug/currency_war/deep_review/g_20261026_203023.md`）。历史同病：strategy-docs/02_mandate_layer.md §1 A/B 归因「没做占绝对主导（部署 0/934）」；2026-09-18 板满换入分支为同病第一件补丁（`kernel/cw_deploy_logic.py` `required_swap_arm_pending` docstring 出处行）。
- 根因归层：**语义层 + 约定层**。语义层 = 换入判据语义单位错置（单件「一步成型」对多成员多档位阵容结构性不可达）。约定层 = 同一换人动作帧上**多层独立判据**（触发/守恒/素材/放行/窗口）层层封堵，各自演化：判定对象不一致、守恒对象与口径不一、判据折法不一（✗→✓ 与 Δfp 并存）——多层协作无统一「收益-安全」判定约定。**只修触发层不达效**——其余层照样封死同一批 victim。本迭代为同族病第二件，按跨件半问升架构级：公共根 = 协作约定缺失。
- 解决到哪：**转型域**的五层判据统一治理——触发/守恒/放行/换人让位四层归一判定原则，素材/窗口两层裁定保留各自折法（§2.0）；P61 退役（§2.9）；现行转型分支机器（`SWAP_TRANSITION_ARM_ENABLED` 族）归宿裁定（§2.3.1）。
- 明确不解决：**双轨域（P1 配方对锁期）换人行为——现行机器原样保留**（2026-09-18 配方完成件通道继续服务其域，本迭代不触碰，§2.3）；买入面（M2/商店判据）；sim 战斗结算与 hp 校准；净战力强弱证明；经济/升级判据本体（放行层复算接线与来金资格增补除外，§2.5/§2.8）。

## 2. 方案

### 2.0 统一原则（适用域 = 转型域）

**换人合法性 = 组换后板态 × 锁定终局阵容。**

- **转型域判别子（单一源，钉死，三合取全继承现行语义）**：①锁定线槽非空（`locked_comp`/`target_comp` 腿①，`cw_intention.py` 判定权威腿①）**且显式排除 p1_pair 腿②**——`committed_authority` 全值（含配方对锁腿②）在配方锁帧也返 True，不可作本判别子；②**板满**（现行换人只在板满帧发，`cw_deploy_logic.py` `:775`/`:1666-1668`——不继承则与 M1 直上通道抢活白卖）；③**fp < 1.00**（成型帧不进换人域，现行键集回全量语义 `:545-547`/`:991`——丢弃则成型帧行为差未申报）。现行 `ctx.locked`/`_swap_transition_domain` 混轨不可用，本迭代新增专用判别子并让消费位迁移（§2.3.1）。
- **组换后板态** = 板上单位集合 − 换出 victims + 换入组 的派生视图；档位与支撑计数按 §2.1 在该视图上现算。
- 转型域内**统一判定函数辖域 = 触发/守恒/放行/换人让位四层**（同一函数，禁各层自备第二套折法）；素材层与窗口层保留各自折法——理由显式裁定：素材守卫 = 经济价值保护独立关切（非收益-安全判定）、窗口 = 上阵资格辖域（非收益-安全判定），两层的保留是裁定而非统一遗漏。

### 2.1 支撑件与档位（口径定义）

- **支撑件 = 终局名单成员（k_members）∪ 羁绊标签命中终局键集的外部件**（并集）。名单成员无条件计入；外部凑档件按标签计入。
  - 依据：`data/cw_chars.py` 标签实测（吉尔伽美什/Saber=圣杯+能量；开拓者·记忆/藿藿=含能量；瓦尔特/符玄不含；停云=仙舟+**能量**；远坂凛=圣杯+战技点；**青雀=仙舟+战技点**（:112）——战技点档已激活事实的承重标签；爻光非圣杯非能量）；键集 = `kernel/cw_comps.py` 双王圣杯 `form_tiers` 的键集 {命运圣杯, 能量}。
- **k_members 单一源** = `predicates.line_members`（core ∪ shared）；`required_deployed` 名（希儿腿）属 core ⊆ k_members。
- **档位语义源（显式切分，防值对标签错）**：`Comp.form_tiers` = **单阈值成型判据**（两键同时达标 = 阵容成型），**不是档位梯子**；本设计的「一阶/二阶/档位非降」语义源 = `data/cw_factions.py` 档位表**逐档计数**（命运圣杯 2/3/4/5 档、能量 3/5/7/10 档）。form_tiers 在本设计中承担三职：键集来源（支撑件判定）、成型判据（`readiness_form_ok` 现行，不动）、门 1④ 成品腿的 ✗→✓ 判据（§2.2）。
- **支撑件身份 ≠ 不可卖**：victim 资格由门 2 与 §2.7 victim 序独立裁定（§2.2.1 让位语义）——终局标签过渡件（停云/远坂凛类）既是支撑件也可作 victim，序上二级deprioritize（§2.7）；来金/演进侧的排除见 §2.8。

### 2.2 触发层：羁绊组双门

- **门 1（收益门，满足任一，对组换后板态判定）**：
  1. 激活终局羁绊新档位（§2.1 档位梯逐档计数）；
  2. 支撑件数严格增；
  3. 同名升星横换（换入件星级 > 被换件星级）；
  4. **成品腿**：组换后成型判据达成（`form_progress` ✗→✓，折法单一源 = `cw_comps.form_progress` 现行契约含 OR 组承接/required 腿）。
- **门 2（安全门，逐被换件）**：现行 `swap_sell_exclusion_reason` 资格面——新鲜度排除、资格族（`merge_material_guard` 素材守卫 / `star_guard` / `fp_unreadable` 等拒因面保留；`target_keep` 按 §2.2.1 口径收窄；`fenced_arm_closed` 语义原样（混轨域腿），表达式脱钩退役符号，见 §2.3.1）。**义务集面域切分（转型域，路径域豁免）**：`locked_buy_membership`（本体 = `_line_hoard` = **名单 ∪ 替班 ∪ 终局键集标签命中件 ∪ sub_tiers 键**并集，`cw_intention.py:1295-1319`〔sub_tiers 键在 :1306；锚阵容无 sub_tiers，辖域内等价〕；承重结论「名单成员 ⊆ hoard」不受影响）的拒卖腿在**换人让位路径整体豁免**——§2.2.1 白名单全部三通道（1 纯过渡件 / 2 终局标签支撑件 / 3 名单成员 3(a)3(b)）的 victim 均豁免义务集拒。代码体依据：义务集闸先于一切让位分支（`cw_deploy_logic.py:960-963`），名单成员 ⊆ hoard 恒在闸内——按通道枚举豁免（仅 1/2）会使 D/3(a)/3(b) 不可达，与枚举表 D、§2.7 矛盾，故裁路径域豁免。豁免依据 = 四腿各自蕴含的净非降（见 §2.8 段一逐腿推导）；来金/演进/普通卖出通道的义务集拒照旧不豁免。**守恒面域切分**：`engines_guard` 的守恒职在转型域由 §2.3 终局档位非降（=门 1① 档位面同一函数）承接，双轨域原样——门 2 的守恒面以本切分为准（交叉引用 §2.3）。

**§2.2.1 target_keep 口径收窄与让位语义（转型域）**：
- **身份保护面**：target 身份集 = **终局名单成员 ∪ 保护集 ∪ 替班契约件**（现行 P78 保护语义 + 「替班=不卖」契约 C4 照旧——现行 `cw_deploy_logic.py` `:1004-1022` 替班/protect_names 检查保留，替班件不因白名单沦为 victim）。

  1. **纯过渡件**（终局键集零标签命中）：一级 victim，序优先（§2.7）；
  2. **终局标签支撑件**（非名单，如停云）：二级 victim，序deprioritize（§2.7）；

### 2.3 守恒层：转型域统一、双轨域原样

- **转型域**：守恒判定 = **终局档位非降（组换后板态口径）**，与门 1① 的档位面同一函数，不设第二实现。
- **双轨域**：`engines_guard`（守恒对象 = `SWAP_GUARD_SYSTEMS` 四体系+护盾，victim 离场口径）、配方完成件分支、必需件分支**全部现行原样**。**完成品分支收窄点钉死（判据域参数化）**：`_completion_swap_ins` 单点门保留（三消费位——触发/让位检验/上序底线——零签名变化，守「禁第二份门」契约），内部按域分派：双轨域 = 现行 fp✗→✓ 折法；转型域 = 门 1④ 同源折法（`cw_comps.form_progress` 同一函数），禁复制第二实现。
- **双轨残域处置预期（申报）**：双轨域（P1 配方对锁期）保留同族多层结构属显式权衡（实机验证充分，重裁 = 无必要爆炸半径）；若双轨域同族病灶复发（pair 帧换人零发射形态），按同一跨件半问升格双轨域统一设计件，当前不排期。
- 效果：转型域解锁纯过渡件 victim（爻光/青雀类——其 `SWAP_GUARD_SYSTEMS` 守恒体系承载〔仙舟档〕的掉档由换入组的终局新档覆盖，即用户裁定的「拆掉过渡阵容的羁绊」）；C1 帧死局解除（情形 A，经 §2.7 两级序选纯过渡件为 victim）。
- **过渡侧掉档语义申报**：转型域不设过渡阵容完整性的独立守卫——过渡侧损失由 victim 序自然最小化（档边际贡献高者靠后，成型过渡结构如希儿系仅在无可替代 victim 时被拆），终局侧收益由门 1 保证（用户裁定【拍】+行为锚点验收）。

**§2.3.1 现行转型分支机器与 fenced 关门分支归宿**：`SWAP_TRANSITION_ARM_ENABLED`/`_swap_transition_domain`/五消费位键集收窄/transition_domain 快照——**转型域由双门取代**（该分支的 fenced victim 键集收窄与门 1 受让判定合并进 §2.2/§2.7，禁双轨并行双判据）；双轨域照旧。**`fenced` 关门分支：域腿钉死（逐帧真值表 + 表达式脱钩退役符号）**——关门判定 = 混轨 locked（腿①∨p1_pair 腿②）∧ fp<1.00 ∧ 板满（**无 ENABLED 腿**），与现行逐帧等价：未锁帧 → 关门（fenced 件为未来换人货币受保护）；锁定 ∧ fp<1.00 ∧ 板满 → 开门落资格族/让位检验（pair 双轨帧与转型域帧同此形态）；锁定 ∧ fp≥1.00（成型帧）→ 关门（现行）；**锁定 ∧ fp 缺读 → 关门（现行产 `fp_unreadable`，fail-closed 同向）**。**表达式脱离退役符号**（内联 locked 两腿，禁引 `SWAP_TRANSITION_ARM_ENABLED`/`_swap_transition_domain`——语义原样，符号按 §2.9 退役）。转型域内 fenced 件的 victim 合法性由门 1（组态收益）与门 2 其余资格面裁定（锁定帧行为延续）。**「零行为差」声明限域 = fenced gating 面逐帧真值表等价**；ENABLED 腿退役属转型分支退役（申报④范围），非 fenced 面。`fenced_arm_closed` 拒因键保留（未锁帧、成型帧与 fp 缺读帧仍产）；projection 判读面随正本更新（已入清单）。**`swap_transition_narrow_frame` 归宿**（`mandate.py:732-777`；消费 `shop.py:979`/`mandate.py:1134`）：该函数 = **P88 买侧收窄的终局锁定域谓词**（docstring 自声明刻意不含 pair），非配方域语义——谓词源随退役符号迁移**改挂新判别子全合取（入参同现行：腿① ∧ 板满 ∧ fp<1.00，禁只挂腿①丢 fp/板满腿）**，两消费位保留（均为买侧/转型消费，非双轨域），P88 登记域不倒转（retirement face 入 landing 3.1）。**`mandate.py:1495` 发出闸 arm 路由**：双轨域完成品分支保留 arm='transition' 标注（双轨语义不变），转型域换新键族（bond_gate_*，见 arm 分键归宿）。退役面（五消费位 + 快照 + narrow_frame 谓词源迁移）入 landing 3.1 文件面；§2.9 grep 词表补 `SWAP_TRANSITION_ARM_ENABLED`/`_swap_transition_domain`（P88 命题引用同谓词，随引用改写）；**`evolution_swap_arm_trigger` 域腿对账目标值（钉死）**：**维持现行混轨语义不迁移**（该谓词非退役符号，准入三元含 pair 帧为现行已验证形态，迁移 = 未申报行为差）——申报为「并存已申报形态」，零行为差。**arm 标注分键归宿**：转型分键随分支退役换新键族（accept 侧 = `bond_gate_tier`/`bond_gate_support`/`bond_gate_star`/`bond_gate_completion` + victim 层来源键 `bond_gate_victim_tier`（值域 = 一级/二级/名单末位）；**拒绝侧分键闭集（钉死）** = `bond_gate_reject_nogain`（四腿全不中）/`bond_gate_conservation_reject`（守恒拦）/`bond_gate_novictim`（无可行组零动作）——3.5 预测表依赖此闭集；白名单/素材等门 2 拒因沿用既有键）；写点含 `mandate.py` 发出段；`cw4_m1p_arm_pending` 归因透传载体保留；projection_contract §4.3 判读面随正本更新（已入清单）。

**pair 帧（双轨域）逐消费位路由钉死**（判别子排除 pair 后，pair 帧不再落转型分支——五个面的路由逐一钉死，全部 = 现行原样，路由键 = p1_pair 腿②非空，禁引退役符号）：

1. **转型域触发判据整体替换（总括）+ 完成品分支收窄至双轨域** = 转型域触发面行为变化。现行转型域可发「零组态收益」换人（一步成型判据外的让位路径——退役后废除）；双门后仅四腿收益形态可发。完成品覆盖性论证（触发轴 + victim 轴两轴）：触发轴——现行锁定帧完成品换入 = 单件入板 fp ✗→✓（前提 fp<1.0）→ 门 1④ 对同动作必然成立（同一折法同一判据）；victim 轴——现行完成品换人的 victim hold（`_swap_victim_yields_for_swap_in` 含量席/标签余量件让位）承接归属：量席/标签余量件（银狼/佩拉/桑博类，非希儿 comp core∪shared）= **通道 2**（义务集豁免后可达）；名单成员让位 = **通道 3(b)**（分支 hold 原样）——两通道覆盖现行 victim 轴，无遗漏。
2. **来金/演进资格排除** = 卖出行为变化（**终局标签件禁换金，bench 侧含内**——装配 A 机制两侧一致生效），申报为设计裁定（【拍】，依据 = 能量硬约束教义）。
3. **同帧逐对连发** = 执行形态变化（现行先卖后续帧续发），失败语义与竞速申报见 §2.7。
4. **转型域判别子三合取** = 板满与 fp<1.00 两合取为现行继承（显式钉死）；腿①排除 p1_pair 的行为差 = **pair 帧 fenced 通路显式保持**：fenced 关门分支域腿钉死为混轨语义（locked 腿①∨腿② ∧ fp<1.00 ∧ 板满，无 ENABLED 腿、不排 pair——design §2.3.1），pair 帧 locked → 开门落资格族照旧，无静默收窄；退役符号经表达式内联脱钩（语义原样，见 §2.3.1）。
5. **target_keep 收窄 + 让位白名单** = 转型域 victim 池行为变化（非名单标签件解锁、名单成员让位收敛为两通道）；量席让位现行语义保留（申报保留非新增）。
6. **过渡侧掉档最小化语义** = 转型域不设过渡阵容完整性守卫（engines_guard 守恒职移除含护盾/希儿系腿），成型过渡结构仅在其他 victim 耗尽时被拆（序语义），申报为设计裁定（【拍】）。
7. **义务集让位豁免** = 转型域换人路径卖出行为变化（`locked_buy_membership` 拒卖腿在**换人让位路径整体豁免**——§2.2.1 白名单全部三通道的 victim 均豁免，标签支撑件如停云与名单成员让位均可经换人离场），豁免依据 = 配对骨架 + 四腿蕴含的净非降承接义务集保护意图（§2.8 段一）；来金/演进/普通通道义务集拒不豁免。申报为设计裁定（【拍】）。

**关键取舍**：
- **Δfp>0 放宽（放弃）**：多档中盘 Δfp 与档位激活不同构；离散档位判据零调参，天然守护能量硬约束教义；成品语义由门 1④ 以现行 fp 折法承接（不引入 Δfp）。
- **登记 required_deployed（放弃）**：字段契约与双王圣杯不符；让位检验一步成型折法不动则通道照旧关死。
- **P61 扩展证明（放弃）**：新触发面下档守恒不成立；战力面证不了（宪法第 1 条）；用户裁定不证明。
- **守恒域切分（转型域统一、双轨域原样）vs 全域口径重裁（放弃后者）**：双轨域机器经实机验证（载体 = 2026-09-18 配方域通道上线后的实机局在产运行，`required_swap_arm_pending` docstring 出处行），重裁 = 无必要的爆炸半径。
- **target_keep 身份面收窄+让位白名单 vs 阵营视图恒拒（放弃恒拒）**：阵营视图恒拒把标签过渡件与量席让位全封死，转型不可达且违反现行已背书让位语义；白名单保各分支正当让位、只杀阵营视图误保护。
- **来金标签命中排除 vs 仅承载件排除（取前者）**：承载件版是 no-op（`is_field_irrelevant_unit` 已覆盖有档件），真实泄露在无档标签件；教义指向标签命中一律排除；bench 侧含内由装配 A 机制决定（单点口径，禁两派分叉）。
- **门 1 纳入成品腿 vs 独立保留完成品分支（取纳入）**：OR 承接阵容成型不跨档位梯（门 1① 常不中；② 通常亦中——名单件入板支撑数增，④ 兜底完全不跨梯的形态），独立分支=双判据并行（违单一源）；④以现行 fp 折法统一承接，语义零新增参数。
- **victim 两级序+让位白名单 vs 单层现行序（取两级+白名单）**：单层序在锚帧会选出终局标签件为 victim；白名单保量席让位现行语义。
- **贪心宿主 kernel vs 策略层（取 kernel）**：依赖方向禁反向；单对现行形态升格多对为本迭代新建（kernel 侧）。
- **放行复算 vs 独立放行判据（取复算）**：单一源原则。
- **支撑件并集口径 vs 纯标签口径（取并集）**：纯标签口径把零标签名单成员结构性排除出板。
- **【拍】裁定持久登记落点**：义务集让位豁免、来金排除、掉档最小化、target_keep 让位白名单四项【拍】裁定的持久登记面 = 正本更新批写入 strategy-docs/24_deploy_segment.md 换人节 as-built（迭代收尾义务承载，见 landing 正本清单）；迭代期临时载体 = 进度账本 T-1 note。
