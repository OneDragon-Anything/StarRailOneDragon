# 星际和平指南(guide)

游戏内右上角「指南」入口的攻略面板,**多 tab 单屏族**:顶部 5 个 tab(每日实训 / 生存索引 / 旷宇纷争 / 逐光捡金 / 开拓历程),切 tab = 同一面板换内容。玩法机制见 [gameplay/guide](../gameplay/guide.md)。

## Per-tab 精准识别屏(2026-08-29 建)

每个 tab 一个独立 screen,**id_mark = 左上第二行标题文字**(rect (95,62)-(230,96);第一行「星际和平指南」公共无区分度):

| screen_name | id_mark 文本 | 主要内容 / 消费方 |
|---|---|---|
| 指南-每日实训 | 每日实训 | 实训任务列表 + 活跃度(`DailyTrainingApp`) |
| 指南-生存索引 | 生存索引 | 分类:培养目标 / 饰品提取 / 拟造花萼(金/赤) / 凝滞虚影 / 侵蚀隧洞 / 历战余响;开拓力体力 OCR(`生存索引-完整体力`,guide.yml area,`GuideCheckPower`/`TrailblazePowerApp`/`EchoOfWarApp` 消费) |
| 指南-旷宇纷争 | 旷宇纷争 | 分类:货币战争 / 差分宇宙(CW / div_uni 入口) |
| 指南-逐光捡金 | 逐光捡金 | 分类:忘却之庭·混沌回忆 / 虚构叙事 / 末日幻影 / 异相仲裁(右下 传送 / 前往挑战,`TreasuresLightwardApp` 路径) |
| 指南-开拓历程 | 开拓历程 | 剧情进度(幕/节;bot 不用) |

**为什么拆屏**(实证):指南 tab 帧无 per-tab id_mark 时走模糊匹配,曾把「逐光捡金」tab 误认成 `背包-光锥`(其二级标题 area 恰好压在标题位置,conf 0.997);拆屏后同帧精准命中 `指南-逐光捡金`。第一行公共标题无区分度,判别子只有第二行 tab 名。

## 何时出现 + 状态流转

- **入口**:大世界右上指南图标(`按钮-指南`) / 菜单「指南」。
- **出口**:右上 X / esc → 回大世界。
- **tab 切换**:顶部 5 图标(每 tab 内再选左侧分类条目联动右侧内容)。

## area 归属约定(防双源)

- `guide.yml`(screen 星际和平指南,**无 id_mark 走模糊**):TAB-* 按钮(切 tab 用)、生存索引-完整体力 / 沉浸器数量、`等待加载-*` 等跨 tab 公共 area —— **现有 op 的 area 引用不动**。
- 各 tab 屏(per-tab)目前只放 id_mark 标题;后续某 tab 专属 area 应进对应 per-tab 屏,不再往 guide.yml 堆。
