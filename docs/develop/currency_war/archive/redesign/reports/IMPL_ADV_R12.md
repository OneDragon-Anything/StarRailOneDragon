## 高-1【内部矛盾】R7-5②「P1 窗口 arm2 守息替代」与 R10-1「单投影喂两门、禁各自取端」在 P1 窗口 λ_L>0.1 场景直接互斥,且替代覆盖错位——它修的门(arm2,只延迟)不是残余 fail-open 的所在门(M3 破息解锁,不可逆)

**位置**:IMPL_DESIGN §2.10「P1 窗口对策闭合声明」②(「窗口内保守替代=窗口期 arm2 按 λ≈0 段处理(守息)」)+ §2.10 R10-1 段(「两门(M3 破息批解锁/arm2 守息门)消费同一投影输出,禁各自取端」)+ §5.3 floor_eff 对拍行(「禁出现一门 0 一门 10×cap 的分裂行为」);登记表 R10-1 引理步骤 1、R10 零冲突自查(「R7-5 ②…与 R 同向且更严…窗口期替代保留」)。

**缺陷**:两条现行规则在同一个帧上给出互斥的 arm2 消费值。

**论证**:R7-5① 自己登记的残余场景=「CI 下端>0.1 而真值 λ≈0 时误解锁破息批」——即 P1 窗口内先验平移把整个 CI 抬到 λ_L>0.1。该场景下:
- 按 R10-1 单规则(现行):λ_L>0.1 ⇒ 投影 floor_eff=0,**两门都消费 0**(M3 破息批解锁 + arm2 守息门失效);
- 按 R7-5②(现行):arm2「按 λ≈0 段处理」= floor_eff=10×cap_resolved。

两规则同帧对 arm2 给 0 与 10×cap 两个值——这恰是 R10-1 定谳要消灭的「一门 0 一门 10×cap 分裂行为」的门级复发。R10 零冲突自查的「同向且更严」只在 λ_L≤0.1 的跨界带成立(R10-1 本就已落守息,替代 vacuous);在 λ_L>0.1 带两规则方向相反,「更严」不成立。且方向上替代修错了对象:R7-5① 点名的残余是 **M3 破息批误解锁(不可逆 XP 支出)**,而 arm2 是「只延迟不否决」的调度门——把窗口期守息只安在 arm2 上,M3 解锁侧的误解锁(真正 fail-open 通道)原样敞开;把替代安在投影上(两门都守息)则与 R7-5② 现文「arm2 的 floor_eff 消费」字面不符,且需要在 R10-1 之上显式声明窗口期覆盖。§5.3 的两门同侧断言又只构造了跨界带 CI=[0.05,0.2] 场景,P1 窗口 λ_L>0.1 场景无对拍锚——验证计划对该矛盾盲。

**修法方向**:P1 窗口替代上移到**投影层**——「P1 窗口内 floor_eff 投影强制 10×cap_resolved(两门同侧)」,显式声明为 R10-1 单规则的窗口期覆盖条款;§5.3 对拍补「P1 窗口 ∧ λ_L>0.1」场景的两门同侧断言;R7-5② 落位行与 R10 零冲突自查句同步改写。若不愿覆盖投影(担心压制真濒死直通线的解锁),则须显式接受 M3 误解锁残余并登记量级,禁保留现文的「已闭合」姿态。

## 高-2【引理缺口】R8-8/R11-5「可腾席件单调耗竭」的前提「环内 M2 触发重试的买入是线内件」未覆盖同环的支配买意图——dominance_buy(M2 前置结构位)的席位失败行为无规格,其买件恰是 fuel_sell 的正对象,不变量在支配买进环形态下为假

**位置**:IMPL_DESIGN §3.1 M2 要点(「M2 生成买入意图 → 席位检查失败 → 现场调 M4 → 重试」+「M2 前置支配买入判据 = dominance_buy」);登记表 R8-8 引理/R11-5(「环内 M2 触发重试的买入是线内件(序 1/2)⇒ 线内禁卖 ⇒ E 不被环内买入补充」)。

**缺陷**:重试环的买入意图流里是否含 dominance_buy 意图,设计未定谳;引理只对「环内买入均为线内件」证明了 E 单调耗竭。

**论证**:dominance_buy 落位=「M2 前置支配买入结构位」——按执行序它先于 M2 序 1/2 发射,但其买件与 M2 买件同走「买入意图 → 席位检查 → 现场调 M4 → 重试」机制与否,文本无规格。取支配买进环形态推演:支配买件=1★ 燃料/可退资产、与锁线零重叠、边际贡献≈0——这正是 fuel_sell 判据的**全集正对象**(fuel_sell:「1★ ∧ 零重叠 ∧ 边际贡献≈0 → 卖,bench 满时弱支配持有」)。于是每次「M4 腾席卖出旧燃料件 → 重试买入新燃料件回填席位」环走一圈,E(可腾席件集)卖一件、进一件,**基数不减**——「每次腾席 E 严格减 1、E 不被环内买入补充」为假(「M4 永不卖出刚买件」只对线内件封死,对支配买件恰不成立)。后果:①引理结论「成功腾席次数 ≤E₀≤B 在上述论证下不可达超限,若达=实现缺陷」会把该形态下可脚本化复现的正常振荡误判为实现缺陷;②触顶「立即放弃该买入意图」丢弃的是 mandate=true 的支配买入(零参数严格支配结论,P24),违反「义务不被 EV/工程机制吞掉」的骨架权限结构;③每次环 1★ 买/卖净 0,不亏金,但重试计数与告警遥测语义全错。

**修法方向**:显式定谳支配买的席位失败行为,二选一:(a) 支配买意图不入 M2 重试环——席位不足时单独处理(先执行一次 M4 或显式跳过+记遥测),引理域保持「环内仅线内件」;(b) 若入环,引理按混合意图重证:耗竭不变量改挂「线内意图的腾席消费」并把支配买环单列为有界振荡(净 0 现金流、≤B 计数截断),触顶放弃对象改判「非实现缺陷的可达态」。

## 高-3【规格缺口】R11-2 星级发射纪律(1★ 限定/2★+ 不发射)只上提到 stockpile_buy 全辖域,未覆盖同一档匹配谓词的另一消费位 M6——M6(mandate 侧)在「金>50 ∧ 无 S 目标 ∧ T_search 活跃」域可发射无背书的 2★+ 档内单

**位置**:IMPL_DESIGN §2.5(R11-2:「发射限定『T_search 活跃窗口档内 ∧ 1★』与『2★+ 档内单不发射+记遥测』上提为 stockpile_buy 全辖域(**案①②同规**)」;M6 行:「M6=骨架义务序位(存在性=金>50 ∧ 无 S 目标…发射 mandate=true)」,无星级限定)。

**缺陷**:档匹配谓词是 statefn/vopt 单源、M6 与 stockpile_buy 双消费(R8-5),但 R11-2 的星级纪律写在 stockpile_buy 的**发射限定**层(案①②③),没有进入共享谓词、也没有延伸到 M6 的发射规格。

**论证**:M6 与 stockpile_buy 的辖域按「金>50 ∧ 有无 S 目标」互斥划分(M6=无 S 目标段)。取帧:金>50、无 S 目标、T_search 活跃、店面有 2★ 档内卡——按 §2.5 现文,M6 义务存在性成立且档匹配命中 ⇒ mandate 发射买入;同一张卡在 stockpile_buy 案①(有 S 目标段)却被 R11-2 判「2★+ 无 EV 背书不发射」。R11-2 自己的论证(「[11] 动态无损与 P49 线性律的背书仅对 1★ 成立;2★+ 手续费 1 金 ⇒ fail-closed 不买」)对 M6 同样成立——M6 买 2★+ 档内单同样只有 1 金净差的卖回通道与未标定的压缩值背书,而 M6 是 mandate(更强通道),无背书发射的量级只大不小。顺带核对单一源:P49 本身(P49 行,math_proofs)的卖回档序是显式含 2★ 的(「2★ 每金损失高于 1★ 排同档最后」)——若按「P49 线性律只背书 1★」读,R11-2 对 P49 的引用口径与 P49 原文存在张力,两消费位至少有一侧的星级规格与所引证明不符。

**修法方向**:把 1★/refund_full 限定下沉进 statefn/vopt 的共享档匹配发射谓词(单源双消费自动同规),或在 M6 行显式补同款星级纪律+遥测;同时复核 R11-2 对 P49 线性律星级辖域的引用(P49 卖回序含 2★ 与「线性律背书仅 1★」的表述需要一篇口径注记对齐)。
