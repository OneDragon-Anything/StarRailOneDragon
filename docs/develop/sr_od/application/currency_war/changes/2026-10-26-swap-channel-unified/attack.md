### N1【阻断】bench 侧标签件来金资格：设计内三处文本两派矛盾

- **文本 A（§2.8 括注，design.md:91）**：「bench 侧标签件仍可来金卖出——不在板上，不影响板面单调性」。
- **文本 B（landing 3.3 测试锚，landing.md:55）**：不变式固化含「bench 侧标签件仍可来金卖出」边界锚。
- **文本 C（§2.11 申报②，design.md:109）**：「来金/演进资格排除 = 卖出行为变化（终局标签件禁换金，**bench 侧含内**）」。
- **机制裁决（直调）**：§2.8 落点钉死 = `sell_gate.identity_exclusions`（装配 A 身份段，name 集合）；FACE_REGULAR 全部场景（含来金族 node_end_interest/levelup_liquidate_prep，池 = bench ∪ field_irrelevant）经 `sell_exclusions`（sell_candidates:559-564）消费装配 A → 把标签命中件名加入 identity_exclusions **必然同时封 bench 侧**。即按落点实现 = 文本 C 成立、文本 A/B 为假；若按文本 A/B 实现（仅排板上件）则落点不成立、申报②失实。两条实现路径互斥，landing 的测试锚按任一写法必有一侧挂掉。
- **规范判定**：iteration-design §5 规则 4（修订后全量同步复查——design↔landing 失同步）+ 规则 2（无需再设计：实现者遇到的语义选择无答案）。文本 A/B 是上一轮 F9 修复的残留半句与新钉落点未对齐。
- **修正方向**：三处统一为同一语义（建议从落点与申报②：bench 侧含内，§2.8 括注与 landing 测试锚改「bench 侧标签件同禁来金族常规面（自救豁免面除外）」，单调性论证同步改述——板上单调性论证本就只需板上排除，改动不伤论证）；或反向：落点改板上限定并改申报②。禁三处并存。

### N2【阻断】枚举表 D 与「名单成员恒拒」冲突，门 1③ 名单同名升星语义未钉

- **枚举表 D（design.md:52）**：「D 同名升星横换 | 板上 1★ Saber、备战席 2★ Saber | 数量持平、星级升 | **放行（③）**」。
- **门 2 口径（§2.2.1 design.md:42 + landing.md:35 判据）**：「target_keep 口径收窄的单帧测试（标签过渡件可入 victim 池、**名单成员仍恒拒**）」——板上 Saber 是名单成员 → 门 2 恒拒 → D 情形按设计自身口径**不可达**。组算法 victim 池同样不含名单成员（§2.7 两级序），同名升星配对无处取 victim。
- **连带语义缺口**：门 1③ 对「名单成员同名升星」（核心 carry 星级升级：卖板上 1★ Saber 上备战席 2★ Saber）是豁免 target_keep 还是禁止，设计未答——这是实现者必答的选择（iteration-design §5 规则 2）。现行机器同样关死该通道（target_keep），不构成回归，但枚举表把 D 列为「放行」即宣示开通道，与门 2 矛盾。
- **规范判定**：landing 3.1 完成判据「单帧测试覆盖枚举表 A/A′/B/C/D/G/E/F 全情形」按现稿**不可写**（D 写不出能过的断言）= 定稿试读卡点。
- **修正方向**：二选一并全量同步——①显式豁免：同名升星横换的 victim（= 换入件同名板件）不受 target_keep 名单恒拒辖，§2.2.1/§2.7 补 carve-out，D 保留；②D 改为非名单同名对（如板上 1★ 远坂凛/外部标签件 ↔ 备战席同名 2★），③ 腿适用范围收窄声明，§2.10 锚②预测表规则同步。两案均须在 §2.11 行为差申报补对应行（①案=新开行为，②案=显式不开）。

### N3【应修】申报④「无行为差」与 pair 帧资格族路径翻转相抵

- 现行域谓词含 pair 帧：`locked` 双腿推广（cw_deploy_logic:1479-1480）→ `_swap_transition_domain_of(ENABLED, locked, fp, board_full)` 对配方对锁帧返 True → fenced off-target 过渡件（如仙舟标签件 ∉ pair 键集）在 :1025 `elif not _trans:` 跳过、落资格族（engines_guard/star/merge 后可卖）。
- §2.3.1 退役面含 `_swap_transition_domain` 本体、§2.0 判别子腿①显式排除 p1_pair：实现者把消费位迁新判别子后，pair 帧 `_trans=False` → 同一板面同一件改落 :1027-1031 `fenced_arm_closed` → **双轨域卖出资格收紧 = 行为差**，与申报④「双轨域行为由 §2.3 原样保证，无行为差」直接相抵（2026-09-18 sim 实证只证 pair 帧 plan_empty 主导，不证资格族路径从未放行）。
- **修正方向**：设计补一句域谓词切分钉死——资格族落管（:979-1032 的分流）保留「方向锁在效（两腿）∧ fp<1 ∧ 板满」旧口径承载双轨域，仅双门触发/守恒切分消费新判别子；或实证 pair 帧资格族路径恒空后显式申报该收紧为可接受行为差。

### N4【应修】申报①覆盖性论证缺 victim 腿：现行背书的「冗余 core 件让位」被禁

- 现行机器在锁定转型域允许卖**名单成员**为必需件/完成件让位：:999-1003 明文「core 成员…判据必需件优先的本体 = 冗余 core 件让位（20260915 sim 找问题报告问题 2 形态：量3 过剩档，卖一量席换入希儿 = form ✗→✓ 严格优）」；`_swap_victim_yields_for_swap_in`（:871-894）不排除 core。
- 希儿量子 core 五人（cw_comps:824 = 希儿/花火/符玄/缇宝/刻律德菈）多含量/贝标签，「量席」常即名单成员。新设计门 2 名单恒拒（§2.2.1）→ 该明文背书的现行行为在转型域被禁。
- §2.11 申报①「覆盖性论证（四腿后成立）…无遗漏」只论证换入侧（fp ✗→✓ ⟹ 门 1④ 必中，同一折法亲验成立），未论证 victim 侧——上一轮 F1 的同构缺口在 victim 轴复发（触发腿修了、组合动作的另一半没查），违反 strategy-work §6「修复方不得只改被点名处不看同类」。
- **修正方向**：申报①补 victim 腿论证：量出「冗余 core 让位」场景在门 2 下有非名单替代 victim 的可达性（板上存在纯过渡件/非名单标签件时两级序自然先取），剩余窄域（板全 core/保护成员 + 过剩档）显式申报为行为差并论证可接受，或加「同名/过剩档 core 冗余让位」豁免腿。禁保留「无遗漏」字样。

### N5【应修】键集收窄退役后 up 侧三消费位视图口径未钉

- 现行 `ctx.target_factions` 转型域收窄（:1545-1548）同喂五消费位（:1539-1541 自列）：victim 侧（offtarget-②/宽口径归因）由 §2.2.1 接管 ✓；**up 侧** `select_up(..., target_factions=ctx.target_factions...)`（:1726-1727）、`_bench_is_target`（:1712-1713）、`post_sell_offline` 底线（:1750-1751）消费同一字段——收窄退役后该字段回全量 all_factions，底线判定放宽（未达成 flex 标签件如花火将从「不算 target 视图」变「算」），转型域计划过底线面变化 = 未申报行为差。
- §2.7「换入部署仍逐对过现行全套上序裁判…select_deployments **裁判域单一源不动**」与 §2.3.1 收窄退役在 up 侧互相矛盾：视图输入变了，裁判域就不「不动」。
- **修正方向**：钉死 up 侧视图口径（建议 = §2.2.1 同口径 名单 ∪ 保护集，或全量并申报底线放宽的边界），§2.3.1 退役清单逐消费位标注去向（victim 侧→门 2 口径；up 侧→X），landing 3.1 完成判据补 up 侧底线口径单帧测试。

### N6【存疑】护盾/希儿系守恒腿随 engines_guard 移除消失，formed 希儿沦为一级 victim
