# 爻光（物理·欢愉·5星）

> 按 V4.7 期撰写。欢愉体系核心光环辅助（「欢愉的阮梅」位）：欢愉度光环+阿哈额外回合+易伤+追击。

## 一、命途属性与技能说明

**命途**：欢愉
**属性**：物理

| 技能 | 说明 |
|---|---|
| 普攻 | 单体物理伤 |
| 战技 | 结界3回合：**全队欢愉度提高=爻光欢愉度的20%**【攻：实测口径】；普攻/战技后+3笑点 |
| 终结技 | 消耗能量（高上限，「充能卡得很死」【攻】）；+5笑点 + **阿哈立即获得1个固定计入20笑点的额外回合**（E1→40）+ 全队全抗穿20%（3回合）——体系唯一强制触发阿哈时刻的手段 |
| 天赋【大吉大利】 | 持好活时我方每次攻击触发追击（20%欢愉伤害，耗点攻击×2次）；攻击者欢愉度低于爻光时按爻光的算 |
| 欢愉技 | 敌方全体【凶星低语】受伤+16%（3回合）+ 群伤 + 回1战技点 |
| 秘技 | 开战自动放1次战技 |
| 额外能力 | **A1：速度≥120 → 欢愉度+30%，每超1点+1%（计200点）**；A2 自身暴伤+60% |

**资源与循环**：标准能量→**充能绳必要**（终结技=阿哈额外回合触发器，回能节奏即全队多一轮齐射）。

## 二、推荐遗器与光锥（与原因）

**光锥**：专武为毕业位（专武名以米游社百科/游戏内为准）；下位替代链 B站视频未提供——【待补：后续攻略轮补齐】。

**套装**：应天涉远的卜者4件 + 沉陆海域露莎卡2件【官：wiki 遗器推荐+账号现配口径】
- 卜者4：速度阈值120/160 给暴击率——速度口径契合 A1 转模
- 露莎卡2：攻击增益——辅助面板

**主词条**：

| 位置 | 推荐 | 原因 |
|---|---|---|
| 躯干 | 暴击率/暴伤 | 追击与欢愉技吃双暴 |
| 脚部 | **速度** | A1 转模（120起步）+ 阿哈公式 0.2 系数 |
| 位面球 | 生命/防御 | 欢愉伤害不吃攻 |
| 连结绳 | **充能** | 终结技驱动阿哈 |

**副词条**：速度 > 暴击率 > 暴伤。
**转模与转化上限**：A1 速度→欢愉度，**120 起步、320 吃满**（+230%）。
**不堆**：攻击%、物理伤球。

## 三、推荐配队与原因

| 阵容 | 为什么 | 备注 |

| **任何欢愉队必带** | 欢愉度光环/阿哈额外回合/易伤/追击乘区覆盖最全【攻：游民星空「必备辅助」】 | 几乎绑定欢愉体系 |
