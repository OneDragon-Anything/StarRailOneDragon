## 1. 命题 P12v2(方向级)

**P2 段找件(e1→e2 战力桶跃迁)的 V_D 收益侧,按 λ_death 纯金流通道承载**:

```
benefit^P2 = Δλ_death(战力桶跃迁 e1→e2 × 节点类型, P2 regime)
             × (存量金 g + 未来纯金流 Φ(P桶, 视界))
```

- **量纲**:Δλ_death 为无量纲死亡危险率差(P51 v3:视界累积口径,自变量=板面战力桶×节点类型×剩余轮数近似视界,hp 不入自变量);(g+Φ) 为金。乘积=金,**全式无任何换算链**——伤害带与胜率差不再是收益侧参数,而是 λ_death 概率侧的生成输入(叙述位,见 §3)。
- **方向结论(已证,不依赖未标定幅度)**:P2 掉血贵于 P1(三源:P15v2 下界/registry 20.05/实机存活局 −15.3)⇒ 同一 e1→e2 跃迁在 P2 regime 压低的死亡危险率大于 P1 regime ⇒ **Δλ_death(e1→e2, P2) > 0 且 > Δλ_death(e1→e2, P1)** ⇒ P2 段找件收益的方向注记=**收益账相对 P1 骨架上调**(方向注记,承 v1 保留项①)。
- **幅度结论:挂账禁引**。Δλ_death 的 P2 分桶标定缺前置(§4),在标定前任何「benefit=X 金 ⇒ j≥k 翻正」的幅度断言均不合法(v1 正死于此)。

## 2. P2 语境入域声明(P48 统一判据 / P51 三段管辖)

P2 段找件决策进 P48 统一囤钱判据的哪一段,由 λ_death 分桶实测裁决,不预先指定:

- **λ≈0 段**(若 P2 regime 实测 λ_death≈0):P48 现行判据不改,收益侧本命题的敞口比较退化为小项,V_D 主判据回到批账 spend vs ρ·x/Ī+L;
- **中间带/λ>0 段**:统一式消费——`花_a ⇔ V_a(x) > ρ·x/Ī + L + ΔW_trunc(a)`,其中找件收益项即本篇 benefit^P2(λ_death 销毁敞口,**敞口比较,禁边际引用**,P51 §5-11);λ 取值一律按**桶×节点类型分层**(P51 §4-B-2),禁混合桶级值;
- 息账 L(P47 域)与 W_floor 并存不双计;连胜金只作上行注记(超额收益隔离)。
