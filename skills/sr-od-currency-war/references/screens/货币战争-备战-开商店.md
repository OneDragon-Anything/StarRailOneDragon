# 货币战争-备战-开商店

**识别**：`is_precise` 命中 `货币战争-备战-开商店`；extras：shop_cards（五槽：名称/阵营/费用/星级）/gold/levelup_cost/refresh_probs。
**目标**：花金币（买牌/买经验/刷新）。
**能做的事**：
1. 买牌：`CwBuyShopCardBySlot {"slot":1..5}`（星级越高费用 ×3/×9）。**备战席满时本 op 静默失败（实测 2 次）**：无报错、金币未扣、牌不入席——买牌前自查 extras.bench 有 empty 槽才买。**买牌吞点击间歇模式（多局实测）**：同一备战期内仅首次买牌点击生效，后续买牌点击被游戏吞（1-1 教学期例外，无此现象）；收店重开、微距拖拽都解不开；呈间歇性（同一局前期正常、后期复现）——连买多张时每张买入后重读 extras 对账（gold 扣没扣 / bench 入没入），发现未生效别硬重试，先读图确认状态再等恢复。恢复边界 = 自然恢复、不按下个备战期承诺（复现样本：连续两个备战期均吞买牌——金币不扣、牌不消失，此后自然恢复）。**extras.shop_cards 出现 kind=unknown 且 faction='?' = 主角昵称卡（玩家昵称拉丁字母不在中文模板集，实测）——可买，是 3 费主角单位，计入同名合成计数**。**合成规则（实测收敛，6 组采样定条件）**：同名且**同星级**的副本按「场上+席内」全局计数（商店牌内的同名也计入全局计数——场上 1+席内 1 时买第 3 张同名，买入即合成、落点场上份升星（实测）），凑满 **3 张同星级**即合成；落点跟随参与件的场/席分布——三份中有场上份 → **场上升星**（实测：场上 1★ 参与三合一时，2★ 合成品落**场上**），全在席内 → **席内升星，落席内编号最小的占用槽**（全 bench 合成同理，落 bench）。混合星级不合成（2★+1★+1★=3 份无效，双向实测）；2 份永不合成；试用标不阻止合成。**掉落路径同样过合成检查（2026-11-19 实机）**：晶矿开箱掉落的角色也计入同名同星级全局计数，凑满 3 份即自动合成——实测：局内已有 1★ 同名一份 + 拾矿掉落同名 2 份 → 掉落完成即自动合成 2★ 入席，无需任何手动操作。早期「场上不参与/混合也合成」的矛盾观察条件未还原——遇同名未合成时先读图核对三份的**星级是否一致**。拖备战席角色到场上已占用槽 = 换位（多局一致）。
2. 买经验：`CwBuyXpRepeat {"times":1..10}`（等级 = 部署上限，前期优先；三月兔(奇遇伙伴之一,随开局简报公布)在场时第二位面买经验额外 +1）。
3. 刷新商店：`CwRefreshShopByClick {"times":1}`。
4. 收店：`CwToggleShopPanel {"screen_name":"货币战争-备战-开商店"}`。
5. 看 extras.bench_overflow：「备战席已满」告警横幅在场(True)= 有单位没安置，出战会被游戏忽略——先 CwSellBenchBySlot 卖一个腾位再出战。横幅商店态也可见。
6. **想拖角色上场或出战，先收店**——商店开着时：点击出战只收店；晶矿识别在此画面不可用（reward_ores 键省略）。收店是本画面的收尾动作。
7. 看商店牌详情：点商店牌弹「货币战争-商店卡牌详情」（识别锚 = 「按钮-购买」+「按钮-角色详情」双识别标志同帧）→ 点「按钮-关闭」（×）关回商店；买不买回商店牌操作，弹窗内不代买（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
8. 免战跳过：免战牌激活时「跳过(N/N)」按钮在本画面同位可见——商店开着也能直接点它进战斗（不必先收店）（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
**坑**：战斗结算后自动弹商店是常态（实测）——多数节点回备战直接就是「备战-开商店」态，开店经常是游戏自动的；先 analyze 确认再决定开/收，不要盲目再点开商店。开商店态 front_line/deploy_count 为 null（完整读数收店后再取）；商店态 board 子集可能失真（实测偏差 -1：读 击破1/守护1，真值 2/2）——羁绊计数勿用商店态 board，以 units 全局计数为准。金币 ≥20 时留钱吃利息（结算按存款给利息）。
