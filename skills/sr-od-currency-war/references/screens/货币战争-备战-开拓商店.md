# 货币战争-备战-开拓商店（开拓银轨商店，知识层俗称「银轨商店」）

**识别**：`is_precise` 命中 `货币战争-备战-开拓商店`（id_mark 双锚：标题「【开拓商店】」+ 底部「购买经验」——商店是备战画面的浮层，下半仍是备战）。知识层文档（gameplay-basics §3.4 / decision-guide §2.3 / comps-codex E 节）说的「银轨商店」就是这个画面。

## 入口（备战画面左缘徽记，实机实测建档）

- **入口/出口 = 金菱形徽记，toggle 双向语义：商店关闭态点击 = 打开面板，面板开启态点击 = 关闭回备战（实机实测）**——修正此前「单击即开」的单向描述。画面档已建「标识-银轨商店徽记」（模板 `cw_rail_shop_badge`，带状搜索域 [230,220,310,580]，非 id_mark——在场性随状态变化，不得参与画面精准判定）。
- **在场性（实测）**：开拓银轨 ≥2（商店开张）→ 在场，且备战态 / 商店面板开启态 / 消费后回备战均**在场**；银轨 1/2（2-1 样本）→ 不在场。**例外（2026-11-19 实机两例）：首次开张自动弹面板的态下徽记不渲染**（空池软锁态，见坑节）——完成首次消费解锁后徽记才出现，别把徽记缺席当商店未开张。**整局跟踪实测：徽记全程在场，与节点推进无关，消失条件未复现**——语义 = 商店开张指示已稳定成立，**不是**「未查看商品」提示（消费后仍在场 = 反证）。
- **y 位置随羁绊面板布局浮动**（实测多例：中心 y=262 / 346 / 515，x 恒 ≈267）——**y 锚定 = 羁绊面板开拓银轨行的位置（位移同步实证）**：某局羁绊面板重排（新羁绊行插入）时，徽记 y 262→346 与开拓银轨行 y≈272→350 同步位移（Δ+78 与 +84 同步），锚定关系由单点强对齐升级为位移同步；羁绊行挪位时徽记跟着挪。这是建档用带状搜索域的原因；点徽记坐标以识别命中位置为准，勿写死 y。
- 右侧配套状态指示两条：横幅「打开商店 ×N」（开拓力余额实时值，x≈330-620，y 随局浮动带内 ~270-470）——**这是打开商店面板的真正入口按钮区（点它开面板）**；「有商品可购买」黄胶囊条（y≈445-470）——**纯视觉提示条非按钮：点击零反应（实机实测）**。
- **胶囊语义终判（双态实测收敛，替换此前「未收敛维持」）**：胶囊 = 「当前开拓力余额 ≥ 池内最低商品价」的持续状态指示——余额 0（池内全不可负担）→ 无胶囊；余额 20≥15（有可负担商品）→ 胶囊出现。池 4 槽固定买一补一，胶囊状态随余额变化、不随刷新变化——「商品池刚刷新」假设正式否定。**历史矛盾样本如实并档**：早期样本「备战态余额 330（多卡可负担）胶囊不在场」与本终判矛盾、未解释，保留观察，不强行圆——遇新样本继续采。第三局银轨未开张（徽记全程不在场）胶囊也全程未出现——「胶囊以商店开张为前提」与终判相容（未开张则无池无价格可谈）。**首开空池态并档（2026-11-19 实机）**：银轨首开余额 0 且池内无可负担商品时，徽记与胶囊**同时缺席**——入口指示组（徽记+胶囊）在「无可负担商品」的首开态整体熄灭；与既有「余额 < 池内最低价 → 无胶囊」语义相容，并档为同一状态源。
- 左上伙伴头像红点（≈182,187）是另一上下文元素（伙伴待办提示），与商店入口无关——别归错主。

**机制（实机说明面板实拍+实测）**：
- **货币名 = 开拓力**（游戏面板口径；早期文档/建档称「列车币 / 星穹列车币」，同物异名——建档 area 名「读区-星穹列车币」沿用不改，语义以本条为准）。每战斗阶段后积攒（1-2 节点一场 +20 实测）。
- **开张条件**：场上开拓银轨 ≥2（extras rail_shop.present 口径与游戏行为一致，多局验证）；**首次开张自动弹出面板**（银轨达成时自动开+弹，后续开/关都需手动点徽记）。**首开面板态是特殊态（2026-11-19 实机两例）**：徽记不渲染 + 面板无关闭钮 + 遮罩锁掉全部面板外点击——常规 toggle 与连续重试均无法关闭，曾软锁约 10 分钟；完成首次消费即解锁回常规态（两条实证解锁路径见坑节）。
- **消费档位表**（说明面板实拍）：羁绊层 ② 20 开张 → ④ 45 商品更好 → ⑥ 75 商品更好+**羁绊专属改件** → ⑧ 125 → ⑩ 225 **列车进化**。
- **商品池结构**：3 属性加成 + 1 银轨角色轮换，4 槽买一补一；**可负担态可视化** = 余额 ≥ 最低价时首个可购商品亮白框（与胶囊同一状态源）。

**目标**：把攒下的开拓力换成资源/角色/属性，同时盯帕姆王进度别越线。
**能做的事**：
1. 读余额：顶部「读区-星穹列车币」（约 547,110；area 名沿用建档，货币名 = 开拓力，见机制节）——购买消耗开拓力。
2. 买商品：点「区域-商品卡区」（约 922,281）内的商品卡直接购买；先看效果可点各卡下方「详情」按钮（4 张卡各一个，y≈443 一排）。**商品区机制（实测）**：4 槽买一补一——买走一张立刻补新卡，槽位常满；「全部刷新」按钮 1 开拓力/次（与备战金币商店 2 金/次是两种货币、两个价）。**累计消费本身是投资**：商品「星穹列车，前进II」的召唤物伤害随本局累计消费成长（实测读数 262%→358%）——花的每一笔开拓力都在同时喂养它。
3. 读帕姆王进度：右侧「读区-帕姆王进度」（约 1552,357）——累计消费满 500 会送帕姆王；消费到 480-495 就收手别再买（除非铁了心走 10 银轨线，见 comps-codex E 节帕姆王线）。进度条实测可读可守（历局样本：431/500 按线收手未越线；355/500 全程未到收手线；140/500 正常累计——均 2026-11-19 实机）。**计数口径实证（2026-11-19 实机相邻局对照）**：「累计消耗」= **本局内**累计消费，**每局从 0 重起**——前局终读 130/500，下一局开局读数 0/500 重新累计（本局样本 0/500@1-2 → 65/500@3-1）；跨局不累计，收手线按本局实时读数守，别把上局余量当本局进度。
4. 买经验：底部「购买经验」按钮仍在（与备战画面同位）。
5. 关闭商店回备战：收店 `CwToggleShopPanel {"screen_name":"货币战争-备战-开拓商店"}`（徽记带内模板定位；失败显式报错带原因）；或点左侧开拓银轨徽记（toggle 开态点 = 关，见入口节）。
**坑**：
- **首开空池软锁（2026-11-19 实机两例，首例软锁约 10 分钟）**：银轨首次开张自动弹出的面板态——徽记不渲染（无 toggle 出口）+ 面板无关闭钮 + 遮罩锁掉全部面板外点击（备战操作/买经验全不可点）。**两条已实证解锁口径**：①买池内任意可负担商品（含 0 价赠送品）——消费动作本身解锁，徽记随即出现、toggle 恢复；②点中央展示卡（第二例实证）。解锁后面板回常规态（徽记恢复渲染、可正常开关）。遇到该态别硬找关闭钮，直接走两条解锁路径。
- **面板打开时锁定出战按钮（面板遮罩吃点击）——出战前必须收店**（备战卡出战前置「先收店」的机制根源）。
- 消费优先级与收手纪律的决策依据在 decision-guide §2.3 与 comps-codex E 节，本卡只管操作。
- 帕姆王进度读数是「累计消费」口径——买得越勤越线越快，别无脑清空开拓力。
- **Momojie（银轨商店专属卡，50 开拓力）买了不能上场**：3 费前后台辅助（开拓银轨 + 星核猎手 + 能量，技能「人气主播」）——**购入后拖上场多次系统性失败**（同局对照：普通角色三月七拖上场成功；该卡在备战席内拖动正常）——归纳判定：专家/顾问类单位不可上场，**别把它当可部署单位买**（要的是它的辅助/羁绊价值）。识别缺口：SIFT 立绘库无此卡模板 → extras 备战席把它读作 empty（申报不修，模板修复归开发者侧）——买到后备战席「少一个可见占位」属预期，别当识别故障反复排查。
