## 2. 门①:内部推导

**自洽部分**:
- 损失结构正确且符合纯金流公理:扑满关血损恒 0 → 损失函数=期望奖励差,不涉任何血→金换算(同树 P12 因 hp_to_gold 违公理作废,P8 无此病)。
- 两臂账:零投入 E₀=P₀R;投 s 凑羁绊 E₁=P₁R−s;正期望 ⇔ s<(P₁−P₀)·R——不等式推导无误;41.6%−13.9%=27.7pp 换算无误;0.277×(6,9)=(1.66,2.49)→「≈2 金」取整保守方向无误。
- 数据缺口三条(R 真值/伤害门槛阶梯/成本 s 分布)P8 如实自列,无隐瞒。

**不完备部分(推导层,非算术层)**:
1. **成本口径漏「卖出全额退」期权**:同树 P1(卖出全额退)与 P6(压库=免费期权)已证买入的羁绊件可全额卖回——凑羁绊的真实净成本 < s(近似只担破息差与机会成本)。P8 把 s 记为纯消耗,高估成本;两证明同批(W120 前后)却未联动。
2. **漏息损项**:买入若使金跌破息档,产生 d·R 息损(P33/p47 L 递推口径),P8 账内无此项(小额但同树已有精确工具)。
3. 两臂只取 e0 vs e1,无更高档——「轻投入」口径下合理裁剪,可接受。

判定:**部分过**——结构正确、算术自洽;成本模型对同代已证机制(P1/P6)未联动,净效果=保守偏置(高估门槛、低估期权),不翻转方向但非完整账。

## 7. 最终判决

**P8:数值面 = 证明不成立(核心常量随 P3 作废);结构面 = 降级维持(零参数段+口述级方向);生产闸门 = 数值依托失效,随旧树 Phase 3 消亡。**

1. **数值面不成立**:s<0.277R 的 0.277 溯源自 P3 阶梯,P3 已判「语料灭、复算不复现、实测反梯」作废禁引;实测带下 e0→e1 胜率边际 ≈0 甚至为负,则 s* 上限可能退到 0 附近——「轻投入凑羁绊有正期望」的数值授权整体失去依托。R 端(6-9金口径漂移、扑满奖励零观测)同样未采。索引行「参数化已证(R 待采)」**不再成立**。
2. **结构面降级维持**(不依赖已废数值):①损失=期望奖励差、血损恒 0(纯金流合规);②「扑满不适用深花保血授权」——深花保血的收益端(掉血)在扑满语境结构性不存在,此段零参数、由 [16] 口述+机制结构支撑;③两臂 EV 门式 s<(P₁−P₀)·R 本身作为参数化骨架可复用。三项以「方向性/结构背书」级(ADR-0482 分级)保留,禁引具体数值。
3. **下游连带**:与 TUNING_INVENTORY #25/P3_VALIDATION §7.2 同根(同一 Δp 注入链),不另立根因;`cw_registry`/`scoring.py`/`ev.py` 的扑满闸门属旧树死刑名单,Phase 3 绿地重写时由 p40 变体⑥ 重推承接,无需单独修码。
