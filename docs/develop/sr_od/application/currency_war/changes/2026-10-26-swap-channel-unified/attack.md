## 一、发现清单

### A1【阻断】双轨域（P1 配方对锁帧）在退役迁移后的路由未钉死——「双轨域照旧」缺逐消费位保留机制，landing 回归判据覆盖不到

- 位置：design.md:14（「双轨域换人行为——现行机器原样保留」）、:69-70（§2.3 守恒域切分）、:74（§2.3.1）、:92（§2.7 新旧视图辖域）、:121（申报④）；landing.md:25、:36。
- 事实（代码体直调）：现行 pair 帧经混轨 `locked`（cw_deploy_logic.py:1479-1480）落入 `_swap_transition_domain=True`，五个消费位在 pair 帧的**现行行为全部是转型分支行为**：①资格分流——非 fenced off-target victim 落守恒门/星级/素材守卫资格族（:986-991 `not _trans: return ''` 不触发）、target 件落让位检验；②门② skip（:1657-1662）；③victim 序 = P79-4 让渡序（:1695-1708，度量非零）；④arm='transition' → :1495 P79-3 放行门适用 + :1750 transition 底线（`_bench_is_target` × ctx.target_factions）适用；⑤装配收窄适用（:1530-1548）。新判别子腿①**显式排除 p1_pair**（design §2.0），而 §2.3.1 只钉死了四处 pair 帧归宿：fenced 关门分支（混轨真值表）、`swap_transition_narrow_frame`（买侧，现行已刻意不含 pair）、`evolution_swap_arm_trigger`（维持混轨）、**完成品分支**的 arm='transition' 标注。其余位点两读：
  - 读法一（新判别子机械换入消费位）：pair 帧落「域外」——非 fenced off-target victim 在 :990 `not _trans → return ''` **跳过守恒门/星级/素材守卫直接可卖**（2★ 填充件在 pair 帧从 star_guard 拒变为可卖，与「engines_guard…全部现行原样」:69 直接矛盾）；victim 序退 1★ 桶域外序（换 victim）；门②在 pair 帧生效（可新增 plan 级弃权）；非完成品 victim arm 退 'base'/'formed' → :1495 放行门对 pair 帧停用（违「双轨域放行门不动」§2.5）。
  - 读法二（pair 帧内联保留现行路径）：语义对，但设计只给 fenced 分支写了内联式样，资格分流/序/门②/arm/底线四处无文字。
  - 加重项：up 侧三消费位（is_tgt/_bench_is_target/post_sell_offline）的视图——§2.7 说「键集收窄退役后三消费位 = 支撑件并集口径」且「新旧两视图并存各有辖域」，pair 帧取旧视图还是新视图、旧视图的本体（pair 期 tgt_comp 装配链上 recipe 伪阵容与终局 comp 的取法，:1440-1453 `committed_from` 短路语义）×收窄退役三者的交互未钉死——配方期非终局支撑件的配方 up 在新视图下会被 `post_sell_offline` 拒，「配方完成件通道继续服务其域」（:14）自断。
- landing.md:36 的 pair 帧回归判据只覆盖「完成品分支/必需件分支/守恒照旧 + fenced off-target 路径」——①②③④的四个路由面不在判据内，回归测试不会兜住。
- 修正方向：§2.3.1 增补「pair 帧逐消费位路由钉死」段——逐位声明 pair 帧走现行路径（资格分流落资格族/P79-4 序/arm='transition' 全 victim/门② skip/底线视图取旧），同款表达式脱钩退役符号；或显式申报 pair 帧行为差。landing 3.1 判据按位点补 pair 帧回归项。

### A2【应修·依据标注失准】design.md:82 §2.5 两处论证引用不实

- ①「轴② Δfp>0 与门 1②/**④** 冲突」：④（fp ✗→✓）与轴②**不冲突**——fp 为各键进度分量的均值结构（cw_comps.py:1792-1813 直调），✗→✓ 必有某键计数跨档，贡献该跨档的换入件单独入板即 Δfp>0，轴②的 ∃ 量词必过；轴②的**真实冲突腿是门 1③**（D 同名升星横换：羁绊计数不变 → Δfp=0 → `_deploy_advances_form` :806-835 判 False → D 被堵），设计未引。门 1② 的冲突形态成立（键已封顶时支撑数增而 Δfp=0）。

- 修正方向：①冲突腿改「门 1②（键封顶形态）与门 1③（D 星级横换）」；②「零键标签名单 shared 件」改「视图外 shared 件」。
