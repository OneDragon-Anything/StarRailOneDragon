## 3. 换阵容机器【已裁定】（原 03 §4.3）

三触发：

1. **段边界触发**（通用化：原"位面边界"）：日程跨段时强制换阵容评估——段索引由节点日程派生，位面边界只是最常见段边界，不作谓词适用范围；
2. **不可达触发**：当前目标阵容 CDF 分位数恶化（P38 输出）；
3. **严格更优触发**：同量纲（切换成本进金日程变薄后仍胜出）。
