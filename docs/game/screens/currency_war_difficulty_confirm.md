# 货币战争-难度确认(开始对局前)

「进入标准博弈」后、「开始对局」前的难度确认画面。展示当前选择难度的效果,并允许切到最高职级。

## 何时出现 + 状态流转

- **入口**:大厅 → 点「开始「货币战争」」→「进入标准博弈」(模式选择屏)→ 本屏。
- **出口**:点「开始对局」→ 简报(下一步)→ 投资环境(3 选 1)→ 备战阶段。
- **两子态**(同一屏,差异 = 是否在最高职级):
  - **未在最高(默认)**:显示当前选择难度(本号 = A5 紫金)+ 底部有「返回最高职级」按钮。入口 = 进本屏默认态;出口 = 点「返回最高职级」→ 切最高子态,或直接「开始对局」开当前难度局。
  - **在最高**:显示最高职级(本号 = A8 财富造物主),底部「返回最高职级」**消失**,仅「开始对局」。入口 = 上一子态点「返回最高职级」;出口 = 点「开始对局」开最高难度局。

> **建档发现(2026-08-03)**:bot 此前 op(`StartCurrencyWarMatch`)直接点「开始对局」→ 一直打默认 A5,而非目标的最高难度。「返回最高职级」= 切到玩家最高职级(= 能打的最高难度,目标)。**修复**:op 先检测「返回最高职级」并点它(切最高)再「开始对局」。

## 识别特征(稳定锚点)

- 独有文字:「开始对局」+「当前职级难度效果」+「*效果叠加生效中」(三联在本屏同现,区别于模式选择屏)。
- 难度标识:「A5 紫金」/「A8 财富造物主」(职级名 + 颜色段);A8 子态有「财富造物主」+ 难度数值更高(敌人难度 108 / 词缀 4 vs A5 的 36 / 2)。
- 易变值勿当特征:敌人难度数值、晋升点、积分(随职级 / 赛季变)。

## 可交互元素

- 「返回最高职级」按钮:底部右区、白色圆角、带房屋图标,**仅"未在最高"子态出现**。OCR 可读。点 → 切最高职级子态。
- 「开始对局」按钮:底部最右、白色圆角。OCR 可读。点 → 开局(按当前选择难度)。
- (中部难度效果行、中上部圆形选项 —— bot 不需操作,仅展示。)
