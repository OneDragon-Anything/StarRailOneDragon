# ADR-0197: 形态包络层 v0 落地(redesign 32 号处置:plaza 总体统计作局内诊断参照)

## Status

Accepted(2026-08-17,策略优化会话;消费端[13 形态合约族/22 触发源/14 筛选/03 涌现对拍
持续化]增量接线;31 journal 投影源待 31 号)

## Context

32 号诊断:M7(级板配比)/M24(bench 囤积)/M25(spread 合法化)三类失败**单局内部无
参照**——判形态离群必须有赢家群体分布;784 篇×三阶段 roster 在手但「总体统计作诊断
参照」是历轮 plaza 用法空白。

## Decision Drivers

- 认识论安全(§2.4):包络是参照不是目标——离群=「解释或修」义务路由,非自动压制
- 幸存者偏差显式语义:作诊断参照是特性(要的恰是赢家形态)

## Considered Options

1. **包络构建+离群向量+路由先行(选)**:六维度(规模/羁绊散度/星级/carry 在场等),
   use 加权双口径挂批次;
2. 全八维(过渡池/bench 重合度/装备时点锚)——需文本时点句编译,批次;
3. 不做——三类缝内失败继续无检测通道。

## Decision

选 1:`cw_traj_envelope.py` v0——build_envelope(jsonl→每阶段分位表,**排序修正**:值表
有序是百分位二分前提,开发中抓到未排序 bug)/outlier_vector(p<2.5% 或 >97.5%)/
route(白名单豁免→调查队列→证伪降权三路)。

**真数据首产(1000 行 HotHard)**:

| 阶段 | board p10/50/90 | trait p10/50/90 |
|---|---|---|
| Early | 0/5/5 | 0/2/4 |
| Middle | 0/7/7 | 0/3/5 |
| Final | 8/9/10 | 4/6/8 |

- M25 判据基就位:Early 8 羁绊激活远超 p90=4 → 离群检出(测试验证);
- Early board 的 0 分位 = 空阶段帖子(部分攻略只填后期),消费端用分位时须知此点。

## Consequences

- 三类缝内失败获得检测通道的统计基;M24 bench 维度挂批次(bench 重合度需 roster 外
  的局内数据);
- 13 号合约族扩「形态合约」候选;03 涌现对拍的持续化锚就位;
- 32 号处置完成(v0),提案文件删档;测试 +4。
