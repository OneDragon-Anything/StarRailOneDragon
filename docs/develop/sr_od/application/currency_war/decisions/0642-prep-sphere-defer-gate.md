# ADR-0642: T-297 备战环席满让路门——奖励球活锁修复落码(方案正本 T-281 修复方案稿 v2.1 逐条照落)

## 状态

已实施(工作树;入库走 committer 不自带 commit;落地审由编排者另派)

## 背景

货币战争备战环,奖励节点清关后右侧面板出现晶矿球。游戏机制:**备战席满时球点不动**(2026-09-11 实机 12 击零消失实证,与 `cw_identity_obs.py` 建档注释一致;色→内容映射未实证——金球内容=金币/装备即时入账不需席的假设在案,ADR-0596 §4.9③)。当形态为「席满(9/9)+上场满编+无补给箱」时,旧两腿谓词(`bench_free>0 ∨ 球均不占席`,第二腿占席色集 `SPHERE_OCCUPYING_COLORS` 现役缺省空集 → `not occupied` 恒真)无条件提前 return 发射 ClickSpheres:决策管线每环首动作恒点球、后续 pass 全被抢占,其后编码的腾席臂与 `sphere_blocked_bench_full` 计数为结构性死码;执行器每环机械点击球不消失,恒指纹 3 环后无进展守卫停机留证——整局终止(实际损失:一局 1543s 预算 + 全部后续球与结算)。历史止损面(点后验效半+幻球黑名单写端)已随 2026-09-10 A2 拆除,现行树对该形态零局部止损。

方案稿经两轮对抗审收口(v1 4 阻断 → v2 修订 → r2 重审 → v2.1 编排者验收,§0 修订对照表 B1-B10 + §7 四决策点终态在案),本批按 v2.1 逐条落码。

## 决策

1. **门显式条件化(B5)**:`entry.py` 球分支重写为三分支——席自由(free>0)照常收球(格3 自愈形态,行为等价,screen_flow_timing #16);席满(free==0)才计数与让路(格1/格2 机制性拒绝形态)。
2. **单探针 K=1 预注册(B3)**:席满形态每搁浅情节恰 1 次探针点击,次环起让路。K 非自由调参:由守卫常量(阈值 3,竞速约束 → K≤2)与在册机制假设(单帧偶发落空探针可区分 + 「席满全阻断」注释假设最小实证敞口 → K≥1)夹逼出可行域 {0,1,2} 取 1(常量 `entry.SPHERE_DEFER_PROBE_K`)。
3. **让路 = 纯 fall-through(B1)**:探针预算耗尽后球分支零发射、不 return,落入 emit 编排后续步骤(①′ wanted 闭环 → ② 证明 pass → ③⑤ → ⑥ 空批 ⇒ StartBattle)。批内零 DeferSpheres(其终结语义与让路不相容);director/cw_loop/cw_screen_prep 零改动;让路环发射批 = 下游常规链自然产出,三 SellBench 发射位(entry.py line_switch_sell/funding_support_sell/兜底)恢复在席满帧求值,受既有 sell_gate 契约核验与息线冻结门辖域——非新判据。排除族零联动(B6):资格门先于排除族,窗口并集含 ClickSpheres 恒不过资格门,残余角落(让路后仅 {OpenShop, RunDeploy} 稳态)由守卫按设计停机,退出质量不劣于现状。
4. **成效重置载体三元组(§7.3 授权实施批终定)**:签名 = `(round_num, len(bench_chars), len(obs.spheres))` 压缩整型(`_sphere_progress_sig`,保持 cw4_counters 数值账本面,sim 轮差分逐值 int() 算术兼容;席/球计数 4 bit 装箱,>15 回绕 = 多一环探针的良性偏置)。任一分量变化或首见 → streak 重开(「席满可点开」若真实存在,每次成功点开必减球计数 → 连续收球不被打断——宁多收球在门语义层保住)。刻意不采 raw gold(OCR 噪声误复位,ADR-0554 修订节 5 同源教训);Hough 球计数抖动每次误变只多一环探针,守卫仍兜底。计数载体单一 = `cw4_counters['sphere_defer_streak']`(会话级=局级;接管局冷建=保守侧恢复点击),遥测键 `sphere_defer_yield`/`sphere_defer_progress_sig` 登记于 entry.py 球分支写点旁(design_telemetry.md 已随文档树重组灭失)。
5. **旧谓词第二腿 + 腾席臂 = 保留原位 + 不可达标注(§7.1 终态,采纳 r2 审建议,与 v2 推荐的退役相反)**:腾席臂(m4_fuel 卖燃料)整块保留原位,触发条件 `_sf_occupied` 要求占席色集非空(现役空集)→ 结构性死码,以标注注释显影读者陷阱;备选A(晶矿 odds 采集批登记占席色)激活时恢复可达。ADR-0596 §4.9③「结构保活」原案不动,非退役申报(退役-复活双倍审面)。
6. **defer_count 纠偏(B7/r2-P3)**:`cw_exec_state.py` 注释覆写两处失实(①「门=2 防空转环」——全库无比较消费点;②「环级——Director 每次环入口清零」——无环级清零写点,唯一复位 = 战斗结算写端),ExecState 类头生命周期分级的 defer 门括注同步。新门与 defer_count 零读写关系(DeferSpheres/defer_count 为既有死词汇,全库零发射者;不退役字段——退役需随删两 director 分支+复位点,归死词汇清理批)。

## Considered Options

- **备选A(v1 保留,条件化挂账)**:登记 `SPHERE_OCCUPYING_COLORS={'blue'}` 激活腾席臂(卖 1 fuel 腾席收球)。适用格 = 格2(席满∧无免卖腾席动作);格1 中 A 会先卖燃料而放过免卖合成(B10 严格劣关系成立)。挂账解锁 = 晶矿 odds 采集批(缺内容分布数据时 fuel 卖出最坏 ~6 次换球收益不确定,不满足宪法量化优先),激活时走独立方案审。
- **备选B(v1 全色登记)**:撤回——金球内容=金币/装备即时入账不需席(B8 反例成立),全色登记会对「本可零代价收的金球」先卖燃料 = ADR-0596 缺省方向所防的误卖形态。
- **腾席臂随批退役(v2 推荐)**:否决(r2 §4.1,编排者裁)——ADR-0596「结构保活」明文在案、备选A 激活路径在册,退役-复活双倍审面;读者陷阱以标注显影缓解,零行为代价。
- **严格闭形终止性证明(v1 §3.2 引理)**:撤回(B3 证伪:让路后 OpenShop 纯读/RunDeploy no-op 稳态可延续恒指纹)——改弱判据(席满形态连续 ClickSpheres 决策批 ≤ K < 守卫阈值,球分支垄断性活锁消除),恒指纹残余由守卫按设计停机留证,非回归。
- **K=0(零探针直让路)**:否决——单帧偶发落空(坐标抖动/过渡帧)与机制性拒绝不可区分,且对「席满全阻断」假设失去最小实证敞口;K=2 无信息增益仅多 1 环延迟。

## 后果

- 席满+球在场形态退出质量:球垄断 ≥4 环恒指纹停机(整局终止)→ ≤1 探针 + 让路环常规链真实进展/出战/短尾守卫停机——退出双口径:垄断退出(决策批不再含 ClickSpheres)≤2 环;形态退出含守卫停机 ≤4 环且属锚点2 合法退出(短尾角落 = 探针 1 环 + 让路零变换 3 环 = 4 环;守卫常量与触发 = cw_loop.py:896/:224-226/:2361)。
- 席自由形态(free>0)零行为变更(动作序列与状态迁移不变,测试锁承载)。
- 让路使常规链在席满帧恢复求值:金账轨迹可能出现判据内卖出(修复意图面),由实机锚点判读(prereg §5.2 五锚:sim 引擎零球建模,本批 sim 结构性不可见,禁 A/B 假阴性)。
- 结构保活面(旧谓词第二腿+腾席臂)现状不可达,删除必须先走退役申报;`test_cw_t297_sphere_defer_gate.py` 死码保留结构锁承载(守卫移除变异红证在案)。

## 验证

- 新锁 18(test_cw_t297_sphere_defer_gate.py):席满让路行为锁(首环探针/次环让路/连击 ≤K<守卫 3)/席自由行为等价锁(逐帧恒 ClickSpheres+streak 归零+席自由化重置腿)/批构成锁(格1 让路批含 M4 腾席卖出腿 m4_fuel_sell——明文禁锁死「零 SellBench」r2-P1;格2 稳态 = StartBattle)/成效载体三元组重置两腿(球计数/轮次变化重开,不变爬升,sig 载体 int 面)/K 预注册锁(K==1+K∈{1,2} 竞速安全侧+K=3 反事实触守卫)/死码保留结构锁(第二腿+腾席臂+不可达标注在案,旧无条件两腿 OR 不得回归)。
