# 货币战争-补给阶段(列表选 N)

备战触发的补给:从一列物品(角色 + 装备)里选 N 个。"已选择 X/Y" 计数。

## 何时出现 + 状态流转

- **入口**:备战阶段(特定轮次 / 条件)触发 → 本屏(遮罩在备战上)。
- **出口**:点物品选中(已选择 +1)→「确认」→ 回备战。或「返回备战界面」(右上)取消。

## 识别特征(稳定锚点)

- 独有文字:「补给阶段」+ 物品列表(角色名 + 装备名)+「已选择 X/Y」+「剩余次数」+「确认」。

## 可交互元素

- 物品列表(本场 5 项):横向排列,每项 = 角色立绘 + 阵营标识 + 装备图标 + 名字。点击选中。
- 「已选择 X/Y」:(1642,912)右下计数。
- 「确认」:(1681,966)右下。「剩余次数：N」其左。
- 「返回备战界面」:(1717,44)右上。

> 全文字(OCR 读角色/装备名),无 screen_info / 模板需求。`battle_loop` 用 `INVEST_CARD=(900,550)` 点 body 朴素选一张。

## 关键数据(策略相关 —— bot 当前朴素选,缺口)

> **策略缺口**:bot 固定点中意 body。应读物品 → 按 `target_comp` 选需要的角色 / 装备(`equip_fit` / `char_quality`)。`decide_event` 待接。

- **物品(本场实例)**:5 项,各 = 角色 + 阵营 + 装备:
  - 银枝(星间旅人 / 群攻)+ 光能电池
  - 希儿(贝洛伯格 / 量子同频)+ 量产型装甲
  - 丹恒·腾荒(夜之半神 / 护盾)+ 轮滑鞋
  - 飞霄(狼狩 / 追击)+ 幸运星
  - 忘归人(仙舟 / 击破)+ 和平手枪
- **已选择 / 剩余次数**:本场 0/1 已选,剩余 1(可选 1 个)。

## 识别快照

- 匹配画面:`screens=[]`(OCR 关键词检测;误命中挑战副本/模拟宇宙确认 area,忽略)。
- 关键 OCR:「补给阶段」(908,137)、5 角色 + 5 装备名(125-1544,546-680)、「已选择0/1」(1642,912)、「剩余次数：1」(1347,969)、「确认」(1681,966)。
