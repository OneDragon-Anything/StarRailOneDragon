# 货币战争-结算(挑战成功 / 失败 结算页)

每轮战斗(auto-battle)结束后的结算页:展示小队生命值 + 获得金币明细 + 掉落 + 数据统计,点「继续挑战」进下一轮备战。

## 何时出现 + 状态流转

- **入口**:备战点「出战」→(deploy<cap 则弹「未达上限警告」确认)→ 自动战斗 → 本屏(结算)。
- **出口**:点「继续挑战」→ 下一轮备战(或下个节点 intro,如「强敌来袭」)。
- **子态**:**挑战成功**(赢,有奖励)/ **挑战失败**(输,推测 —— 待 fixture 核;失败态布局/标题待现场快照)。本档 fixture 为成功态。

## 识别特征(稳定锚点)

- **「继续挑战」按钮**(画面下中,~(960,893))—— id_mark。CW 结算独有(他屏无此按钮),成功/失败态都在(赢/输都继续)。
- 标题「挑战成功」/「挑战失败」(上中,~(960,229))—— 子态判据(非 id_mark:成功文字与战斗/逐光捡金屏共有,但配合「继续挑战」+金币明细可唯一定位 CW 结算)。
- ⚠️ 勿单用「挑战成功」当锚(撞 battle/treasures_light 屏)。

## 可交互元素

| 元素 | 位置(中心,1080p) | 说明 |
|---|---|---|
| 「继续挑战」按钮 | (960, 893) | **id_mark** + 推进出口:点 → 下一轮(备战/节点 intro) |
| 「数据统计」(放大镜) | (~1175, 575) | 点开数据统计子面板(角色伤害明细);可返回 |

## automation 要读信息

- **小队生命值(hp_after)**:结算时剩余 HP(`文本-小队生命值`,动态值)。recognizer 产 `hp_after`。
- **胜负(is_failed)**:标题「挑战成功」→ is_failed=false;「挑战失败」→ true。recognizer 产 `is_failed`。
- **获得金币总数 + 明细**(基础奖励/利息/连胜):本轮金币收益(`文本-获得金币总数`,动态)。
- **掉落晶矿**:本轮掉落(晶矿,动态;非穿戴装备 —— combat 掉晶矿,装备由补给节点出)。
