## 1. 命题(摊还定理形式)

设决策帧:等级 9,板满(deployed = cap),备战席有等待上场件(pop_slot 授权语境,P23 §① 机制链),升级 lv9→10 经验成本 **C = 84 金**(`cw_state.py:XP_TO_NEXT_LEVEL[9]=84` XP;XP_PER_BUY=4;单击价 `XP_CLICK_COST_FALLBACK=4` 金/击,21 击 × 4 = 84)。**付清形态适用范围(§1.1)**:本篇主式以「一次付清 C=84」为口径上界,实际执行为逐击 4 金的跨帧分期(实证对照实验账本,单帧最多 16 击、典型 ≤8 击),分期修正项 Δ 的闭式与修正数字表见 §1.1/§3.1——该修正不动任何分域裁决(g≥134 域两口径精确同为零)。记:

- **v = Δp·L_c + w**:升级后每场战斗的金当量边际(人口增量战力项 Δp·L_c + 胜负金差项 w);
- **r**:升级到账后的剩余战斗数(等级跨位面持久 → 计满位面 2 尾 + 位面 3,见 §2.2 视界);
- **R**:升级到账后的剩余计息轮数(备战节点数;与 r 同源,近似 R ≈ r,见 §4 边界);
- **d(g; C)**:该笔支出的**利息档损失深度**,闭式(利息 = min(⌊g/10⌋, 5) 金/轮,economy.md §10.1):

```
d(g; C) = min(⌊g/10⌋, 5) − min(⌊(g−C)/10⌋, 5)
```

**命题 P35-a(摊还判据,闭式)**:升级相对不升的期望净值为

```
EV = v·r − C − d(g; C)·R
```

在 R ≈ r 近似下,EV > 0 的充分必要条件为

```
v > d(g; C)   且   r > C / (v − d(g; C))
```

即「每场人口边际须先压过每轮利息损失深度,再摊还本金」。**恒负充分条件:v ≤ d(g; C)**——此时无论剩余轮数多长 EV 严格为负(不升级的利息流永不停止,升级本金永无摊还完的一刻)。

### 1.1 付清形态适用范围声明(一次付清 vs 分期,实证定案:结论不变)

**机制事实**:游戏侧「购买经验」为逐击小额(每击 +XP_PER_BUY=4 经验、−单击价 4 金,`cw_state.py` 语义);**单帧内可连点任意次数(游戏机制无每帧击数上限)——决策层按每帧支出预算发组**。执行链实证(`remediation.py` 稳态分支/补偿分支①:`[LevelUp]*n` 整组按 EV 总账单次判、arbiter 逐动作扣金;`cw_state.py:1343` simulate 逐击 `s.gold -= action.cost`)。

**金流形态实证(对照实验 off 分支主窗账本,n=200 局/2655 帧)**:含 LevelUp 的 1157 帧共 6855 击,**单帧击数分布众数 8(524 帧)、最大 16**,无任何 ≥21 击单帧——lv9→10 的 21 击必跨 ≥2 帧、典型 3 帧(8+8+5)分期完成;另一实机账本 1621 击/227 帧 = 7.1 击/帧同形态。⇒ **实际金流 = 跨帧分期付清,不是单帧一次付清**;但每帧 ≤32 金的节流是决策层支出预算的产物(策略工件),非游戏机制约束。

**分期利息损失闭式**:设 k 帧付清、第 j 帧付 S_j−S_{j−1} 金(累计 S_k=C),利息规则结算取自上轮末金(支出先于下一轮结算,对照实验帧 `sim.income.interest=⌊gold_before/10⌋` 实证),则 R 轮视界内利息损失合计

```
L_inst = Σ_{j=1..k} d(g; S_j) + d(g; C)·(R − k),   Δ = L_1shot − L_inst = Σ_{j=1..k−1} [d(g;C) − d(g; S_j)] ∈ [0, d(g;C)·(k−1)]
```

一次付清式 d(g;C)·R 是 L_inst 的**上界**(d 对已付额单调,Δ≥0;金再生的二阶保守性与 P35 原式同向,两口径同受)。实证 k=3 下 Δ 上界 = 2d:逐域实算(g=90/100/110/120/130,d=5/4/3/2/1)Δ = 7/6/5/4/2,**g ≥ 134 域两口径精确同为 0**(付清前后金均在利息线上)。

**对两个命题条件的传导(零新参数)**:
- 恒负条件**原样存活**:v ≤ d 时 EV_inst ≤ (v−d)·r − (C−Δ) < 0 对一切 r>0 成立(C−Δ ≥ 84−10 = 74 > 0)——流竞争 v vs d 与付清形态无关(付清完成后终局利息差恒为 d),分期只削一次性 lump 不削渐近流差。**对抗评审担心的「分帧下恒负反转」在其假设形态(逐击逐帧,k=21,Δ 可达 74)下对四参数角点会成立(d=1 域 r\*≈16.8 入界),但被实证形态排除:k≤4(单帧支出预算,众数 8 击/32 金),Δ ≤ 7**。
- 摊还条件修正为 **(v − d)·r > C − Δ**,取保守 Δ = 2d(k=3):修正后 r\* 见 §3.1——全部 d≥1 域仍 > 19,g≥134 域 r\* 不变(d=0 时 Δ=0,该域纯本金摊还、与付清形态无关)。

**裁决**:中心结论(全部标定带内恒负)在两口径下均成立;「一次付清」由口径上界声明取代无条件假设,对抗评审攻击意见 4 指出的适用范围缺口由此闭合。

**命题 P35-b(利息线分域,闭式)**:g ≥ C = 84(可负担前提)时,d(g; 84) 只取 {5,4,3,2,1,0},分段边界为 g ∈ [84,94)→5 / [94,104)→4 / [104,114)→3 / [114,124)→2 / [124,134)→1 / g ≥ 134→0。注意 d 被**利息上限 5 封顶**——早期分析用的带 I∈[0,20] 在单笔一次性付清口径下过宽;且金在利息线以上(g ≥ 134)时跌破利息档项**精确为零**,升级只与本金摊还竞争。

**利息上限 5 的实际生效适用范围声明(2026-09-01 勘误批)**:本篇 d 闭式的利息上限 5 仅适用「无利息规则类投资修改的默认利息局」。利息规则投资在场帧(开源节流 cap→9 / 利息上调 cap→10 / 狸财经息+2 / 买断制利息关闭 L≡0),d 须按实际生效利息上限(resolved interest_cap,基础值与已激活投资叠加)现算或该帧排除出适用范围:cap 9/10 下负判走强但上列分段边界表全部失效;狸财经使利息规则离开 ⌊g/10⌋ 形,d 闭式结构性失效;**买断制利息关闭局 d≡0,恒负充分条件 v≤d 的通道消失**——该局型 g<134 域全部落入 d=0 列,裁决只剩纯本金摊还判据(中心 r\*=38.8>19 的不可达论证幸存,但「全部标定点恒负」不再由恒负充分条件承载)。P47/P39 均已按实际生效输入(resolved-input)纪律处理,本声明即对齐新证明体系。

**命题 P35-c(D 侧概率红利,结构项)**:lv10 相对 lv9 的商店概率提升(`cw_shop_odds.REFRESH_PROB`,实机 OCR 权威表)对 4/5 费猎取是正项:目标费用 c 的期望刷新次数按 P16 超几何模型**精确地**按 p(9,c)/p(10,c) 缩放(费用档内超几何因子相消),即 5 费猎取提速 1 − 0.10/0.25 = **60%**、4 费提速 1 − 0.30/0.40 = **25%**。等价金当量红利 B = Σ_j ρ_c·D_j(ρ_5=0.6、ρ_4=0.25,D_j = 剩余视界内对 c 档的刷新支出),方向恒正;量级卡点见 §6。

## 2. 推导

### 2.1 三项账的分解(P23.1 同构,符号沿用其符号表)

P23.1 已证统一门式 EV = Δp·L_c·m + w·m − C − I。本篇做两处精化:

1. **利息损失项 I 精确化**:P23 取带 I∈[0,20](账本金分布实标的粗口径)。单笔 84 金一次付清时,利息规则是确定机制(economy.md §10.1):每轮利息 min(⌊g/10⌋,5),支出把金从 g 压到 g−84,此后 R 轮每轮少收 d(g;84) 金,合计 d·R。d 只依赖 g(状态可读量)与机制常量,零自由参数——与 P33 的 d·R 零参数利息损失项同款。g ≥ 84 > 50 前提下跌破利息档至多跨 5 档(利息上限封顶),d ≤ 5。一次付清是利息损失**上界口径**(实际执行为跨帧分期,修正闭式与实证见 §1.1)。**与 P47 的接口声明(2026-09-01 勘误批)**:本篇 d·R 是**静态金近似**(付清后金位不动,此后 R 轮每轮少 d)下的上界闭式,即 P47 双轨迹 L 递推 L(g,U,R,Ī)(利息损失规范口径,P39 A4 已换轨)在静态金假设下的**闭式特例/上界**;金再生(基础+连胜收入使两轨同向逼近利息上限、缩小利息差)的二阶保守性两口径同受(§1.1 已声明),方向不变;
2. **摊还形式化**:把 P23.1 的 m 视角换成每场边际视角,v·r 与 C + d·R 相除即得 P35-a 的两个条件——第一个条件(v > d)是**流量竞争**(人口边际每场挣的须多于不升级每轮白得的利息),第二个条件(r > C/(v−d))是**本金摊还**(净流量差多少轮填平 84 金)。

### 2.2 视界 r 与位面 2=7 的语义

- **位面 2=7 不是机制上限**:定案报告 §1.2 已裁决「位面 2=7 槽」是 power_baseline 的描述性人口口径(位面 2 中位 6-7 人),非封顶常量;棋盘绝对容量 10(`cw_state.py` front_max+back_max=4+6)——**适用范围限定(值源切换批勘误):该 10 仅「无扩展局面」成立**;宝钻/召唤物扩展局后台格数 7-9(back_max 动态真值 = BoardState.back_layout),棋盘容量可至 13,「lv9→10 是最后一次真实人口增量」在扩展局不成立。常态基线局(无扩展,占绝对多数)结论不变,边际人口价值不为零(「人口价值因封顶而归零」的论证不适用)。本命题沿用该裁决,不再重证。
- **r 的取值域(账本实测)**:对照实验 off 分支 227 停手窗 LevelUp 帧行逐帧实数,位面 1+2 视野 min/p25/中位/p75/max = 1/5/7/8/9;加位面 3 节点带 8-10(`cw_node_reader`)→ **r ∈ [5, 19],中心 15**(P23 §2.2 同源)。位面 2 内升级的 r 至多 7 + 位面 3 带 ≈ 17;末窗(r9/boss 帧)的 r ≤ 3。

### 2.3 P35-c 的超几何缩放(零参数)

P16 模型:找一张目标牌的期望刷新次数 E ∝ 1/(p(level,c)·q),q 为「目标费用槽内出目标牌」的超几何因子(只依赖牌池副本数与目标数,与等级无关)。故 E(9,c)/E(10,c) = p(10,c)/p(9,c) **精确成立**,提速比 1 − p(9,c)/p(10,c) 由 `cw_shop_odds.REFRESH_PROB`(实机 OCR 权威表)直接读出,零新常数。红利只兑现于「确实在刷 4/5 费」的帧(位面 3 型语境);停手窗不刷时红利为零,本项是**上界型正项**(有利于升级侧,计入后负判更保守)。
