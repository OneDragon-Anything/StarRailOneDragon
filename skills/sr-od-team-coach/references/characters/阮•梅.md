# 阮•梅（冰·同谐·5星）

> 按 V4.7 期撰写。通用增伤+击破体系万金油。

## 一、命途属性与技能说明

**命途**：同谐；**属性**：冰

| 技能 | 说明 |
|---|---|
| 普攻 | 单体50%攻击冰伤 |
| 战技【弦外音】 | 3回合：全队伤害+16%~35% + **弱点击破效率+50%** |
| 终结技 | 消耗能量；结界2回合：全队全抗穿+15% + 敌方被攻击挂【残梅绽】——从击破恢复时**延长击破+行动延后（20%击破+10%）**+30%冰击破伤 |
| 天赋 | 除自身外队友速度+8%；我方击破弱点时附加60%冰击破伤害 |
| 秘技 | 下战自动触发1次战技（不耗点）；模拟宇宙特殊效果 |

**资源与循环**：标准能量→充能有效。

## 二、推荐遗器与原因

**套装**：机心戏梦的钟表匠4件 + 盗贼公国塔利亚2件【攻：击破向口径】
- 钟表匠4：击破辅助套；塔利亚2：≥145速击破增益

**主词条**：躯干攻击%/效果抵抗；脚部速度；球攻击%；绳**击破特攻**/充能。
**副词条**：击破特攻（→240% B1 吃满）> 速度 > 攻击%。
**转模与转化上限**：B1「落烛照水燃」击破→战技增伤，**120% 起步、240% 吃满**（+36%）。
