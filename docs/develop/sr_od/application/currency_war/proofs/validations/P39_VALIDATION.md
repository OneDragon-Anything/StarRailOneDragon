## 门① 内部推导健全性 —— **部分过(可复算自洽;两处结构性缺位)**

### 1.1 逐项重推(全部亲跑复现)

- **EV 结构 EV_up = ΔV_band + ΔV_pop − U_L − C_int**:四项分解成立。ΔV_band 的推导链「概率表移位 → 只有被搜牌窗口消费才变现 → 窗口级求和(低费负窗口如实入账,不以件数加权=防双计)」逐步核对无 leaps;A1 可加性假设声明了失效方式 ✓。
- **E 关于 p 严格递减**:数值逐表验证(如 3费2星:L6 p=0.25 E=38.1 → L7 p=0.40 E=23.9 → L8 p=0.32 E=29.8 回升),「峰值级=argmax p=argmin E」成立,臂二 (a) 的推导基础成立。
- **telescoping 引理 + 段带例**:亲跑脚本复算 ΣE(L7)=118.9/ΣE(L8)=73.1/ΣE(L9)=69.9/L10=71.5,边际 +91.5/+6.4/−3.2 全对,断言锁通过;「贪心停 L8,L8 非任何单费峰」的 [7] 论证成立;「贪心≡全局需无回升」的条件声明正确(实现按两级枚举覆盖,不依赖等价)✓。
- **数值自检表六行 + L 联动门**:亲跑 `p39_levelup_ev_check.py` 全部断言绿(段带锁/翻转点 g≥78/L 带锁);5费单张 L8→L9 的「R≥6 全带不过、常态不升」复算成立。
- **A4/P5/P35 命题域重推状态核查**(任务点名):P39 自含重建、未引已作废的 p05/p35/p11/p22(单篇第 8 行声明,正文无引用,核实属实);P5 域的重推分工=p39(升级支)+p40(刷新支)(p38 索引行背书),P13 域重推=p47 已收口且 A4 已换轨 L 递推——**新树地基健康**。唯一残留:臂二 (c) 的「守 50」是旧 P13 口径在结构上的唯一幸存位点(P13 已推翻,P47 只供 L 函数不供「floor=50 作必要条件」的推导,见 1.3)。

### 1.2 结构缺位一:比较基准里「持有」的定价不完整(与 P51 的接口缺位)

EV_up 的隐含比较对象是「把钱用于刷新/买牌/持有」;「持有」侧只计了 C_int(息损)。按 P51 §F/§Λ 已立的 W_floor = λ_death(战力桶,R)·(存量金+未来 base+interest 流) − 当轮息票:**λ_death>0 段等待的期望销毁金为正**——持有侧的代价不只是利息账,还有截断敞口。P39 单篇成文早于 P51,缺这一项不是推导错误而是**证明族分工时序问题**,但按 P51 §F.4 公理(所有证明必须在连胜=0 底线上成立),正式修订时升级-vs-持有的比较必须显式并入 W_floor 或声明消费其结论——当前版本没有这个接口,判缺位。实证面即攻击 3/5a(新侧终局携金中位 197 全损)。

### 1.3 结构缺位二:臂二 (c) 的 floor=50 是「引入口述」而非「推导出」

(c)「升级+完成搜牌窗口(含卡价)仍守 50」在单篇内没有从 P47 L 递推出的必要性证明——它的来源是 [3] 口述前半的「刷后保 50」**外延到升级通道**([3] 原文只说刷新臂保 50,user_playstyle L90)。这个外延在单篇里以「([3]『保 50』;卡价入账对齐 p40 R2/P38 A5,R5)」一句带过,没有独立论证。数据(门④)显示赢家侧 89% 的升级发生在金<50——该外延被实证推翻。**这不是数值错,是把口述规则当成了公理**;修法见门⑤/修正建议。

### 1.4 次级口径项

- A2(全窗口上界)+ 多窗口共享 5 槽高估 = 双重反保守偏置——单篇已声明且点名列 sim 对拍项 2 为裁决项 ✓(诚实);但两个边界带案例恰在敏感区,该偏置的量化至今无 sim 对拍回填(对拍清单 2 未执行)。
- A6(NPC 池消耗未知)在 sim 单人池语境下恒无影响、实机有偏——单篇声明了方向 ✓。
- ΔV_pop「当轮兑现」假设与 [32](人口 cap 当场生效)一致 ✓,但 XP 通道本身滞后 1+ 轮兑现(P37(i) 实测)——人口位价值的兑现前提是**当轮有等待单位可上**,这在臂一谓词里有;臂二路径升级若无人可上,移位价值的兑现同样有时滞,单篇未计滞后的折价(与 P51 门③修正同款:按通道分到账延迟 d)。量级小、方向偏乐观,记次级。

**门①判定:部分过**。可算的部分全对且可复现;两处结构性缺位(持有侧缺 W_floor 接口;臂二(c) floor=50 无推导、系口述外延)需修。

## 最终判决:**需修后站得住**

**站得住**(判据=可复算+机制忠实):EV 四项分解与窗口级求和的数学结构;全部数值锚(亲跑逐位复现);E 单调性/段带例/贪心停点;[3]/[7]/[12]/[33] 的退化形式判定;新树地基(p47 换轨、不依赖已推翻的 P13/P5/P35 旧件);语境变体的参数替换形态。XP 表定谒后数值结论整体走强。

**必须修**(阻断项,按优先序):

1. **臂二 (c) 的 floor=50 退役**(实证推翻,门④A):它是 [3] 口述的外延而非推导,把赢家侧 89% 的升级判非法。不得用「调低到 ≤20 的拟合值」替代——那是把一个拍值换成另一个拍值(违反零调参);正确形态=视界分层现算(见相容方案②)。
2. **ΔV_band 的窗口条件性重锚**(实证推翻,门④B):「无目标线→ΔV_band≈0→金再多不升」在 80% 未成型局是死亡螺旋一环。方向选项(需单独立证,非本件静默改):a) 移位价值无条件小正值(等级期权价值);b) 以板面深度/费用档结构为锚(如「当前 carry 费档 p 表全档扫描的期望节省」不依赖已立窗口);c) 并入 W_floor 使「不升级」侧付费(λ_death>0 段不升级=持有=承担截断敞口),由比较基准翻转而非 ΔV_band 自身膨胀。**推荐 c+a 组合**:c 保纯金流公理,a 的量级必须有独立证据(米游社带表可作外部锚),禁拍值。
3. **持有侧并入 W_floor 接口**(门① 1.2):EV 比较的「持有」分支 = 息票 − λ_death·(存量金+未来流);按 P51 §F.4,升级判据必须在连胜=0 底线上成立。
4. **臂一谓词给操作性定义**(门③/④C):「可上场成型单位」的域(何种 bench 成员计数:锁定线 ∨ 种子并集 ∨ 结构方向可达)写进证明,防实现写窄重演(101/158 饿死实证)。
5. **声明勘误**(门②):XP 表状态从「±20% 待标定」改「已确认按表值(2026-08-31)」;对拍清单①改「已完成」;翻转阈值 13.6%/29% 行退役。索引行同步加注(先例:P13 行加推翻注的格式)。
6. **Ī 消参 + calib_v1 解耦**(门⑤):L 递推的 Ī 改收入日程现算。
7. **滞后折价 d**(次级):臂二路径的板深收益按 P37 时滞折后计(与 P51 门③修正同参)。

**与 P51 视界分层的相容方案**(任务点名风险⑤,必须显式给出):

P51 已立的分层律:**λ_death(板面战力桶, R)>0 段(掉血期/未成型局)→ W_floor>0 支配「该花就花」;λ_death≈0 段(健康带早段、距终>6 轮)→ 守息**。本件的升级时机判据按此改写为**视界条件门**,与 P51 不是竞争关系而是「P51 供持有侧代价项 + 本件供升级侧收益项」的合成:

```
买经验升级 iff(双臂或,视界分层版):

臂一(人口位,不动,微调):
    有可上场成型单位(操作性域见修4) ∧ 硬可负担(g ≥ U_L)
    ∧ R_remaining > d(XP 通道滞后)          —— 新增:距终不足 d 轮时人口位无从兑现
    —— floor_pop 消参(TUNING #4 路径),原 g−U_L ≥ floor_pop 的数值下限删除

臂二(搜牌驱动,视界版):
    (a) 非峰值级(不动,注册表派生)
    (b) ΔV_band ≥ U_L + C_int               —— C_int = L(g,U_L,R_全局,Ī 现算),不动
        (ΔV_band 的窗口口径按修2 重锚后取值)
    (c) g − U_L − Σ窗口预留 − E×2 ≥ floor_eff(R, 桶):
        floor_eff = 50   当 λ_death(桶, R) ≈ 0(健康/距终>6 轮——守息,与 P51 分层律一致)
        floor_eff = 0    当 W_floor = λ_death·(g+未来流) − 息票 > 0(截断敞口盖过息票
                          ——该花就花;数据反演的 floor*≤20 是这个条件的实证投影,
                          但门本身由 λ_death 现算,不引入拟合常数)
        (硬可负担 g ≥ U_L 恒保留;floor_eff 不下穿 0)
```

相容性论证:①臂二 (c) 的 50/0 二值不是新参数——它是 P51 W_floor>0 与否的**决策投影**,λ_death 按战力桶×节点分层现算(P51 §Λ.1 生成式),零拟合常数;②健康带守息与 P37(健康带晚升为负)方向互补不冲突——P37 说「该升不升亏存量」,本方案说「健康且视界充裕时破息升级需 ΔV 门背书」,两者合读=「健康带升级要走 (b) 量级门而非踩线抢跑」;③濒死/掉血段 floor_eff→0 与 P21/P37 辖域三段无缝结构(P37 §3.1)一致——P21 域已随 P21/P23 退役改由 λ_death R→0 推论承载(P51 §Λ.2),升级门不再有 hp 入参,符合 [39]/纯金流;④W_floor 进的是**比较基准**而非 EV_up 加式(持有侧),与 P43 连胜上行注记的分层(P51 §F.3)不重叠、无双计。
