# 逐光捡金(treasures_light)

忘却之庭**选关界面**及其弹窗子态的总 screen(`treasures_light.yml`,51 area):三视图选关 + 记忆紊流弹窗 / 规则说明弹窗 / 馈赠弹窗 / 战斗后结算等 in-mode 画面。入口与出口见下方状态流转。`pc_alt=true`。

## 何时出现 + 状态流转

**本画面 = 三视图选关(互斥,顶部图标切换)+ 弹窗子态(父屏加 area 建模)**:

| 子态/视图 | 入口 | 出口 |
|---|---|---|
| 混沌回忆视图(默认) | 分类页点「传送」;或切换器左图标 | 关闭X→**大世界**(2026-11 实测,旧档「回指南」已过时) |
| 回忆·天艟求仙迷航录视图 | 切换器中图标 | 同上;或切换器切回 |
| 回忆·永屹之城遗秘视图 | 切换器右图标 | 同上 |
| 记忆紊流更新弹窗 | 每期首次传送进入时自动弹(带「已更新」角标);点词条-记忆紊流(无角标版) | 点击空白处关闭 |
| 规则说明弹窗 | 点按钮-规则说明 | 弹窗-规则说明-关闭X;可滚动,内容含 轮/快速解锁/星启模式 规则 |
| 馈赠弹窗(印记馈赠/回忆馈赠) | 点按钮-星芒礼包 | 弹窗-馈赠-关闭X;tab 互切 |
| 商店(独立 screen) | 点入口-奇珍琳琅 | 商店右上X → 回本画面 |
| 编队屏(未独立建档) | 点已解锁关卡水晶 | 编队返回箭头 → 回本画面 |

## 识别特征(稳定锚点)

- **FH_TITLE**(左上「忘却之庭」,rect (85,25)-(215,78),id_mark,conf≈0.99)。⚠️ 三视图共享——单锚不能区分视图,需组合第二行文字(见下)。⚠️ 弹窗(紊流/规则/馈赠)压暗使检测级失败(OCR 空返回),弹窗帧父屏不 is_precise,靠弹窗专属 area 识别。
- **标题-混沌回忆行**(rect (90,55)-(215,100),text 混沌回忆,**lcs_percent=0.7**):混沌回忆视图专属。⚠️ 必须收紧阈值——默认 0.5 时「回忆」是「混沌回忆」子序列会反向误命中(2026-11-04 实测踩坑,已修)。
- **章节名-天艟求仙迷航录 / 章节名-永屹之城遗秘**(rect (110,115)-(430,175),conf≈0.97/0.99):回忆两视图判别锚(长独有文本;同位置在混沌回忆视图为期名「物竞天择」等,**内容每期轮换不作锚**)。
- 期名/倒计时/快速解锁条文字:常驻但**内容每期轮换 → 不作锚**。

## automation 要读信息

- **当前视图**:标题-混沌回忆行 / 章节名-天艟求仙迷航录 / 章节名-永屹之城遗秘 三选一命中即视图判定(防 bot 落错视图)。
- 期名文本 / 倒计时文本:本期期次与剩余时间。
- FH_TOTAL_STAR:星芒计数(0/36)。
- 提示-快速解锁:文本含「历史最高3星关卡 N」= 账号进度;「已自动解锁关卡 01~N」= 本期解锁范围。
- 词条-记忆紊流命中 = 本画面且紊流词条可读;紊流 buff 全文在弹窗(首期自动弹,机会态需捕获)。
- 编队屏(未建档)信息:挑战目标三条(星数条件)、敌人等级、「建议属性」弱点表、「通关阵容」入口——建档时落 area。
