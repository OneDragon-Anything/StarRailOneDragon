# 0291 - 决策框架 v2 骨架落地(ADR-0290 四层实现 + 0/N 买入根因修复)

- **Status**: accepted(2026-08-24;worker 续批——骨架七文件成形后被中断,本批补行为)
- **Context**:ADR-0290 定稿四层框架(候选生成→硬过滤→板面查表评分→预算仲裁)。骨架批被中断时
  `src/sr_od/application/currency_war/decision_v2/` 七文件已成形(candidates/filters/scoring/arbiter/
  registry/strategy/__init__),sim 10 局(900000-900009)跑通无崩但战力崩:**mean=6.0 vs v1 30.4,
  团灭 5/10**;日志中后期大量轮「买入 0/N 候选」——四层都在跑但几乎不执行。
- **根因诊断**(逐局决策日志实证,非叙述):
  1. **候选层缺种子语义**:`_target_names` 未锁线未成桥时返回空集 → 无方向期零买候选 →
     `update_target` 永远锁不上线(dir_round=99 实证)→ 板面永远空 → 团灭。v1 有 `_bridge_seed`
     (r234:未锁线时卡∈当前位面任一桥 fixed∪core 即买——桥选择要求 owned 已有 fixed 是鸡生蛋,
     种子件先入手才能成桥),v2 骨架漏了这一分支。
  2. **仲裁层地板误用**:economy 地板恒 50(`registry.interest_floor`)→ 金 < cost+50 时一切买入
     被 `gold_floor` 拒。v1 是阶梯地板(`_economy_actions`:≥50→50 / ≥10→gold%10 档内全花 /
     <10→0,「配方未满,息让位」)。
  3. **过滤层标签集缺漏**:`bond_fallback` 不在 `economy_tags`([31] 凑档降级通道在默认模式下死)。
  4. **评分层活性死结**(三连环):①`depth=min(level, deployed)`——cap 饱和后囤 bench 的买恒 0 分
     被「非正分」拒;②LevelUp 单击=部分经验(ADR-0129)不整级,整级制评分恒 0 → 升级通道死 →
     cap 恒 5 → 一切买入板面价值归零;③息 EV 对 <50 金的档位跨越扣分(满息×轮数=-25 级),
     与地板政策双重计罚;④形态域只看 deployed,buy 触发 3合1 合并(3 副本→1 件)时引擎/配方
     计数反降,合并买被评 -13 分全弃(星级未建模的代理伪影)。
- **Considered Options**:
  1. **仅修约束(1-3),评分保持纯 deployed 整级制**——拒绝:cap 饱和后买入/升级恒 0 分,活性
     仍死(实测 r3-r6 全空转攒金,lv 恒 5 团灭);评分是 ADR-0290 的执行依据,评不出价值=框架空转。
  2. **改用 v1 式规则通道在层4 强制执行**——拒绝:那是通道制回潮(ADR-0290 否决的形态),骨架
     交付的就是「评分排序 + 约束收口」结构。
  3. **评分层补齐形态维(采纳)**:全部以「板面形态维」落表,不做单卡边际拆分(对抗修订①边界
     内):`depth=min(level, deployed+bench)`(持有件对 cap 的覆盖)、追级 EV=小数等级×单位值
     (level+xp 进度比,单击经验即分数性推进;ADR-0290 层2 查表项「追级 EV」骨架漏项)、息 EV
     只在满息平台(≥interest_floor)计值(与地板政策单一源对齐)、形态域=持有域(deployed∪bench,
     星级加权展开——2★ 计 2 份,合并的战力显影为计数)、目标件持有进度项(集合隶属计数/基线,
     封顶计值——cap 饱和时目标件的持有期权在此显影)。
  4. **LevelUp 息引擎门([12])不放宽**——部分采纳:保留 [12] 全门(lv≥5),仅补 v1 的 P1 lv<5
     宽松(gate=10,`_economy_actions _lvl_gate` 同式镜像;否则开局等级恒 1-2,cap 窒息)。
- **Decision**:采纳 3+4,连同根因 1-3 的分支/标签/阶梯地板修复,全部落 `decision_v2/` 七文件
  (骨架语义:未标定——标定 gate 见 ADR-0290 实施序③;数值只求结构正确与决策活性,不求胜率)。
  同时补 `interest_rule` 的辖权让位(金<50 时阶梯地板管辖,息档约束只保护「从 ≥50 跌破 50」)。
- **验证**(sim smoke 30 局配对,900000-900029,snapshot 池,单进程,同池同 seed):
  - v1:mean=30.7,团灭 1/30,HP≥60 3/30;
  - v2 修复前(骨架原版 10 局):mean=6.0,团灭 5/10,dir_never 高发;
  - v2 修复后:mean=20.0,**团灭 0/30**,dir_never=0——决策活性恢复(1-8 轮持续买入/升级/部署),
    团灭率从 50% 降至正常域(≤v1 的 1/30);mean 仍低于 v1(20.0 vs 30.7)= 未标定预期
    (评分权重全为骨架初值,标定 gate 后 A/B)。
  - 定向测试:`sr-od-test/test/sr_od/app/currency_war/test_cw_adr0291_decision_v2.py` 14 通过
    (候选覆盖/无方向种子回归锁/过滤三态/评分形态维/阶梯地板回归锁/审计表无空格/端到端 3 局活性)。
- **Consequences**:
  - 正:四层结构按 ADR-0290 全通(候选覆盖全部动作类、过滤三级、查表评分、仲裁矩阵审计);
    每轮候选×分数 log 可判读;团灭病根除(结构层,非点修)。
  - 负/风险:评分权重未标定(形态域=持有域高估 bench 价值、目标进度项系数先验)——预期 v2 胜率
    低于 v1,标定 gate(EARLY_WIN_DELTA 真值化+deploy 时序)后重标;refresh_ev=0 骨架不主动刷新
    (v1 的 r258 早期方向刷新未迁移,种子语义已覆盖大半场景,标定期评估)。
  - 默认不切换:LineStrategy 仍是默认策略,DecisionV2Strategy 经注入/sim A/B 验证(ADR-0290
    渐进迁移②→④)。
