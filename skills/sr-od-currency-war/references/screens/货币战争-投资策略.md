# 货币战争-投资策略（三选一，时点出现）

**识别**：`is_precise` 命中 `货币战争-投资策略`；extras.strategies = 候选名列表。
**目标**：三选一选策略。
**能做的事**：
1. 选中并确认一体：`CwPickInvestStrategy {"card_index":1..3}`（内部 = 点卡片**六边形图标区**选中——点标题/文字区不选中——+ 确认微距拖拽）。
2. 跳过本次选择：点右上「返回备战界面」（会带出暗色锁定态，回备战后按「货币战争-备战-暗色锁定」卡先解锁）。
3. 逐卡刷新（每卡独立）：每张策略卡一组「刷新次数N」+ 独立圆钮（圆钮 = 该卡计数文本中心 x−88、y 同高；三卡计数文本 ≈x{477,975,1474}、y≈855 → 圆钮 ≈x{389,887,1386}；识别带「区域-刷新次数行」）。计数逐卡独立扣减，0 = 尽（灰置仍可读）（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
**坑**：确认键置灰 = 未选中（op 重跑仍不行则亲自读图核对点位）；extras.strategies 长度 ≠ 3 时不要用 op（卡数变了，退坐标点击并反馈更新图标区）。效果形态已知条目（实测，均为查证过注册表定义后的实战选择）：双星馈赠 = 商店刷出带星标的 2 星卡（1 金）；健康充值 = 小队生命值 +30 且上限 +30（血线压力大时的直选项）；中产阶级 = 每 2 星单位 +5% 减伤 +15% 强度、再 +3 金币（阵容星级成型后的稳收益型）；星级压制 = 速度 +10%、对低星敌人打 20% 真伤（己方星级领先时的滚雪球型）；特战资金 = 进首领节点时 +7 金（银卡，注册表口径）；无伤通关 = 战斗结束时无角色陷入无法战斗状态则 +1 金并立即获得 1 个【生命之花】（银卡，注册表口径）；固定理财+ = 选中后商店刷新钮变「免费刷新」，每位面 3
