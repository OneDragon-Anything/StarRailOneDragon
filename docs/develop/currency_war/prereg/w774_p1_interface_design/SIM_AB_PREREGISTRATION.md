## 1. 双臂定义

- **对照臂**:HEAD `8c1839c7` registry 缺省(五开关全关)。
- **实验臂**:同进程 registry 注入五开关 on。主批五开关同开(接口族整体为设计单元);**分臂诊断批**(①单开优先)用于锁线质量维归因——W777 §6.1 指出五开时错锁损害经②③④兑现而单开①可分离测得。

## 2. 主判据(阈值事前写死)

- **M1 P2 存活轮数分布移位**:配对局 P2 存活轮数中位差 ≥ +1.0 轮且配对 Wilcoxon p<0.05。量化锚=W764(P1 失血每降 10 血↔P2 多活约 1.3 轮);对照臂基线分布跑批时实测冻结。
- **M2 P1 总失血**:实验臂均值 ≤ 对照臂均值 −15 血(W764 最优局 -28 为锚;sim/实机口径差冻结基线时声明)。
- **M3 锁线判据(v2 重定义,双维)**:
  - **M3-计数维**:触发摇摆代价门(degrade≥2 ∨ 连败≥2)后仍持续摇摆(门后再发 degrade/连败恶化)的局占比 ≤ 2%;
  - **M3-质量维(新增,测「锁了但锁错」)**:锁定局的 p1_pair 与该局 P1 出口 form 的阵营交叠——主档成员交叠 ≥1 的局占比 ≥90%;交叠=0 的局记为**锁错局**,是分支 D 归因的唯一数据源。
  - locked 占比 / 换线次数:降为**分层读数**(v2 语义下未锁=合法探索,不再是红线)。
- 分层读数(记录不判):五开关各自触发帧占比/触发面构成;P1 出口 form 与锁定线的一致性分布。

## 3. 出手率红线 R 族(v2 新增;W772 M0b 教训判定化)

| # | 对象 | 判定线 | 判定方式 |
|---|---|---|---|
| R-② | ②分配义务帧 | 净分配率 ≥50%(义务帧中动作序列含装备分配) | M2/M1 败且②触发面可疑时作归因输入;R 败且 M 达标=记录 |
| R-③ | ③备战授权帧 | 净出手率(金账下降)≥50% | 围栏∩店空=合法零出手,单独披露为「供给型空转」 |
| R-④ | ④重排触发帧 | 重排出手率 ≥50% | 空转归因分「店中无①类目标(合法)」vs「有目标未买(违判据,单帧锁④兜底)」 |

R 族不是全局不合格线:**M 判定失败时 R 是归因判据**(R 败→触发面/供给问题回本设计调,不诿执行层);M 达标时 R 只记录。

## 4. 护栏(任一红 = 实验臂不合格)

- **G1 经济面**:(a) 非加急破息帧占比双向对称 |差|>2pp 红;(b) P1 出口金均值劣化 >2pp 或配对显著劣化红;(c) 死时带金 p50/mean 上移 >2σ 红。
- **G2 P1 回归**:P1 通关率/成型率劣化 >2pp 红。
- **G3 Goodhart**:胜局占比差 ≥ −2pp 且 M1 达标,否则红。
- **G4 结构红线**(单帧锁族,批级 0 例):濒死带 LevelUp(P21)仍 0;j=0 负例仍 0;off 臂逐位零漂移;**新增**:一致性验证失败帧不得出现②③④触发(门语义锁,见 §6-锁⑥)。

## 6. 单帧锁清单(v2;锁语义不锁牌名/seed)

1. 锁①(v2):贯穿件信号在手 → 意向锁定(现状行为确认锁);摇摆代价门触发 ∧ 板面交叠 ≥2 → 锁交叠最大线;交叠全不达 → **不锁**(且②③④该帧不触发);off 臂逐位 HEAD。
2. 锁②:硬节点帧 carry 裸装 ∧ 一致性过 ∧ 有简易非组件 → 动作含分配;「无接收者卸装」拒绝(卖 carry 致装备回栏闲置=0 例);转移给更高星在场者放行([24]);off 臂无动作。
3. 锁③:水位判据真 ∧ 花后金 ≥ rebirth_floor → 授权帧动作非空且金账下降;花后金 < rebirth_floor → 不授权;水位足帧不授权。
4. 锁④:触发帧 → 买序列含围栏内体系件(有货时);纯散件不在序列;本线稀有件囤买放行([22] 语义,v1 的禁囤行为锁**撤除**)。
5. 锁⑤:预警带(<40)非转化∧非压库∧非本线目标件买入拒绝;压库买入放行([34]①);应急带转化型放行/非转化拒绝;boss 帧 ALL IN 窗既有行为逐位不动。
6. 锁⑥(v2 新增):意向线与板面一致性验证失败的帧,②③④动作序列与 off 臂逐位一致(门语义零泄漏)。
