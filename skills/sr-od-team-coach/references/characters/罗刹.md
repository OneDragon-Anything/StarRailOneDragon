# 罗刹（虚数·丰饶·5星）

> 按 V4.7 期撰写。攻击模型结界奶：白花之刻自动结界+战技自动触发。

## 一、命途属性与技能说明

**命途**：丰饶；**属性**：虚数

| 技能 | 说明 |
|---|---|
| 普攻 | 单体50%攻击虚数伤 |
| 战技 | 单体40%攻击+200；队友≤50%血免费自动触发（2回合CD） |
| 终结技 | 消耗能量；AoE 120% + **解除敌方全体1个增益**（驱散）+1层白花之刻 |
| 天赋 | 白花之刻2层 → 结界2回合：**结界内敌方受攻击→攻击者回血**（12%攻击+60） |
| 秘技 | 开战自动触发天赋结界 |

**资源与循环**：标准能量→充能有效。

## 二、推荐遗器与原因

**套装**：云无留迹的过客4件 + 泛银河商业公司2件【攻：攻击模型口径】
**主词条**：躯干攻击%/治疗加成；脚部速度；球攻击%；绳充能。
**副词条**：攻击% > 速度 > 效果抵抗。

## 三、推荐配队与原因

| 阵容 | 为什么 |
