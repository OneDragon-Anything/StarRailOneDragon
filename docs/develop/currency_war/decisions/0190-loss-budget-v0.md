# ADR-0190: 损失预算引擎 v0 落地(redesign 34 号处置:四差距分解+地板上界)

## Status

Accepted(2026-08-17,策略优化会话;B 臂真局版/E 执行臂不立项——45 号 J1 已证死局份额 0%)

## Context

34 号诊断:33 轮各自论证 gap 存在零尺寸测量;四套审计量纲不通约;A8 可达上限无人知道。
四臂配对重放(种子对齐干预消融)把败率拆成共通量纲桶。

## Decision Drivers

- 「下一个 10pp 从哪来」需要一张表;全工程停止线需要地板
- sim 内 B 臂(揭示)天然免费(重放时真值本就可知)→ A/C/D 三臂即完整 sim 版

## Considered Options

1. **sim 三臂配对先行(选)**:A(as-played)vs C(DP 姿态接管,0181 同款策略)配对种子族,
   符号检验;
2. 等真局 B 臂/27 号 E 臂——45 号已证执行差当前无测量面,挂起;
3. 不做——投资方向盘继续定性。

## Decision

选 1:`cw_loss_budget.py`(loss_budget + _sign_test)——

**首份预算(n=100,配对种子 2000-2099)**:

| 桶 | 值 |
|---|---|
| as-played 胜率(A) | 0% |
| DP 接管胜率(C) | 10% |
| **决策差(C−A)** | **+10pp(符号检验 p=0.002,显著)** |
| 可行动上界(D−A) | +10pp(sim 内 D=C,揭示免费) |
| **地板上界(1−P[win|D])** | **90%** |

- 与 0181 A/B 独立种子族结论一致(存活 0→10-15%),交叉验证;
- **战略读数**:当前 sim 世界里 90% 的败率是「地板」形态(解法不足只会高估地板,此为上界)
  ——「下一个 10pp 来自节奏决策」是显著且有据的;继续磨同维收益递减,加维度(如 38 号
  搜牌会话的停止规则)才是下一步杠杆;
- 诚实边界:sim-relative(DP 与 sim 共享物理),绝对地板待 40 号保真度分区按区判。

## Consequences

- 29 号「信息价值」权重获得首个测量供给(决策差 10pp 为 sim 侧锚);
- 24 号 CEM 的可回收空间上界 = decision_gap(sim 内已含);
- 34 号处置完成(v0),提案文件删档;测试 +2。
