# ADR-0478: 段级检查器边界两修——[6] boss 窗地板授权豁免 + [17] 溢余容忍带

## 背景

两起检查器误报批(W751 检查器边界小批)同根:**段级检查器的断言边界窄于
决策层的授权语义**——决策层已显式授权的花费被检查器按「无例外」计入
违规,产生恒红噪声,稀释真破息/真堆积候选的判读价值。

1. **[6] 破息例外记账**(`seg_check_break_interest_exception`):seed
   642780(r9)/642808(r9)两窗各 1 起,形态相同——boss 节点单笔
   engine 渠道买入(d2_line_carry / d2_line_carry_merge)破息 51→47 /
   50→47。但 boss 节点本就是 interest_rule 的旁路窗:窗内息律不参与
   裁决,唯一授权器 = boss_floor 破息地板 10(ADR-0310 war 模式 +
   ADR-0356 阶梯地板裁决「boss_floor 10 = 期望账输出」;ADR-0426 边界
   原文:「授权范围内合法跌破息基、下探至 boss_floor 属设计内行为,
   跌破 boss_floor 才是越权信号」)。检查器例外谱(ADR-0415 立、
   ADR-0471 收编升级/刷新通道)从未收编 boss 窗旁路语义 → 授权行为
   被误标为真破息候选。
2. **[17] 溢余即花**(`seg_check_overflow_idle_spend`):n=300 全量
   普查 + 历史 5 起,事件形态全部同一:g0 恰 51(息线 50 邻近 +1)、
   未成型、整轮零花费。机制:51 带内无同息档 discharge 时,任何 ≥2 费
   买入都跨档跌破息线 → below_floor_spend 门默认拒(ADR-0434)→
   「空坐 1 死金」是该域设计内最优(1 死金的机会成本 ≈0.1/轮,
   ADR-0443 同一笔账;跨档息损 ≥2/轮)。检查器 g0>50 即报,把容忍带
   内的最优静默误报为溢余滞花。

## 决策

1. **[6] 例外谱补 ⑥ boss 窗地板授权**:boss 节点(读
   `DEFAULT_REGISTRY.boss_round_node_types` 单一源,不造第二把尺)
   且花后金 ≥ `boss_floor`(10)→ 豁免(`boss_floor_authorized`);
   跌破 boss_floor → 不豁免照报,detail 带越权标注(保留 ADR-0426
   「跌破地板才是越权信号」的检查面)。经济窗(r4 型战斗节点)engine
   渠道破息不受本豁免,仍红——真破息候选面不扩。
2. **[17] 息线邻近容忍带**:常量 `_OVERFLOW_TOLERANCE = 2`(segments
   模块级,g0 ≤ interest_floor()+容差豁免)。边界依据:51-52 带内
   同息档 discharge 依赖店里恰有 1-2 费件,店里没有时空坐是设计内
   最优(见背景 2 的账);真堆积(≥53)不受影响仍红。检查器的诊断
   目标是系统性囤金(数十金量级),±2 容差不掩盖该信号。
3. **辖域只动诊断谱系**:决策/执行层零触碰(ADR-0471 同一边界)。

## Considered Options

1. ⑥豁免以「节点=boss ∧ 花后 ≥ boss_floor」双条件收窄(本 ADR)——
   保留 boss 窗内的越权检查面。
2. 豁免整个 boss 节点破息(不带地板下界)——否决:丢 ADR-0426 明文
   的越权信号面。
3. 豁免 engine 渠道单笔破息(按渠道豁免)——否决:engine 渠道在
   经济窗的破息正是 ADR-0332 只辖 r≥5 破息窗的评分偏置辖域之外,
   按渠道一刀切把真破息候选一并洗白。
4. [17] 改为「店里有同息档件才报」(查店面板精确化)——否决:与本
   检查器的姊妹检查 `seg_lossless_buy_missed`([11] 无损购买)职责
   重叠,双检查同判据=双源漂移;容忍带以常数表达边界、零店面板耦合。
5. 维持现状(把两窗事件当噪声人工判读)——否决:恒红噪声常驻报告,
   每次 A/B 守卫「不升」判读都要人工排除,判读成本持续支付。

## 后果

- 修正后重放:seed 642780/642808 [6] 事件 1+1 → 0+0;n=300 普查
  seg_overflow 2 → 0(两事件均 gold=51 容忍带内),[6] 残留 1 起
  (r4 战斗节点 engine 渠道破息,经济窗真候选,按设计保留)。
- 锁组:`test_cw_sim_segment_checks` 双向断言补容忍带三例(51/52 过、
  53 报)与 boss 窗两例(≥地板过、跌破地板报);既有违规臂(gold=55)
  不受影响仍红。
