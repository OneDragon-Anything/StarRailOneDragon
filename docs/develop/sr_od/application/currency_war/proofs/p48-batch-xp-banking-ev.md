## 推导

### ① 整买引理(Leontief 互补结构)

**严格表述**。设状态 s = (g, xp_cur, level, board, …)。把经验购买建模为决策序列:{在轮 t 花 4 金换 +4 XP}。定义 k* = ⌈(need−xp_cur)/4⌉。

**引理**:对任意策略 σ 与其中任一「在轮 t 购买 j < k*_t 次经验」的片段(j 次后仍未升级),存在策略 σ′——除把这次 j 击**延迟到批补齐时刻**(价格不变,A2)外与 σ 逐点相同——使 σ′ 弱占优 σ;且当延迟期间金位轨迹 <50(跨息档)或存在任何正 EV 边际动作时**严格**占优。

**证明**。拆三步:

1. **零收益(Leontief 上半)**:j < k* 次购买后 xp_cur + 4j < need(取整定义),升级事件不发生。由 A1,xp_cur 是唯一被该购买改变的状态分量,而一切收益通道(战力/概率/人口/利息/商店)都不读 xp_cur——所以这 j 击的即期收益 = 0,且不改变任何未来转移。经验点击的价值函数因此呈 **U(x; k*) = V_级·1[x ≥ k*]** 形态:等值线 L 形、点击间完美互补——**XP 与升级事件是 Leontief 互补品**。对照:买牌即使暂不上场也压库([1]/[15]/[30] 在册,p41 V_opt 定价其再遇规避价值),经验购买**没有任何此类持有价值**(不占 bench、不占池、不生息)。∎(结构步)
2. **持金占优(机会成本步)**:把 j 击换成持金 4j。两条轨迹的金位差 = p47 的双轨迹差:持金轨迹逐轮 ≥ 花后轨迹(B≥A 恒立,p47 命题二已证)。金在 50 以下生息(利息差 = L(g,4j,R,Ī) ≥ 0)、在 50 以上零成本(A4)且保留全部期权(可后补同样的 j 击——价格不变,A2;可转投任何正 EV 动作)。故持金弱占优,占优严格当且仅当:轨迹跨息档(息差>0)或存在正 EV 边际动作。∎
3. **推论(整买形态)**:对 σ 中任何零散片段重复步骤 1-2 的交换,得到:最优策略中经验购买只发生在「补齐批」时刻——即 xp_cur + 4·clicks ≥ need 的最小购买集,批大小 k*_eff = ⌈max(0, need−xp_cur−4n̄)/4⌉(n̄ = 储蓄期内期望自然 XP,A3——买牌本身在送 XP,批只需补缺口)。**含溢出注记**:need−xp_cur ≢ 0 (mod 4) 时批的最后一击溢出结转到下一级(`xp_apply_clicks` 同规则),溢出 XP 非浪费但仍以升级事件为变现前提。∎

**数值面(自检①;金/息两记账只计其一,防加式复计)**:同升级轮下「持金延迟」相对「零散提前买」的死库存成本——**恒等式:两策略总收支相同 ⇒ 升级轮金差 ≡ 累计息差**(同一笔损失的金+息两种记账,加式复计会翻倍);24 格网格:严格为正在 14/24(**最高 12 金**,lv7 g0=30 Ī=7 每轮 3 击),其余 10 格全在 5 金/轮满息平台——**平台态零散买的息损恰为零**([41] 的机会成本在此退化为纯期权价值,与 A4 的「超额持币零成本」自洽:两部分成本都不大,但严格占优仍成立,因为持金期权非负)。

### ② 买齐时点与动态目标线 S

**命题**:批购买在轮 t 触发 iff:

```
触发(t) ⇔ [p39 双臂门(t) 为真]  ∧  [g_t ≥ S(t) = B(t) + floor_resolved]
   B(t)  = 4·⌈max(0, need−xp_cur(t)−4n̄(t))/4⌉     (批成本,resolved 自然 XP 总流抵扣)
   floor_resolved = 50(默认局,臂二,[3]「刷后保 50」同款保息下限)
                  | 100/90(息律投资上调/开源节流局,p47 A1 resolved cap)
                  | 0(买断制局,息通道消解,floor 不适用——批触发金位约束只剩门)
                  | floor_pop(臂一,p39 待标定;血本位语境 = [40]②同构)
```

**论证**:门的必要性是 p39 的直接引用(臂一/臂二条件不变,本文不重推升级 EV;**S 的下限不止 floor_resolved——臂二(c) 的窗口卡价预留与搜牌金必须并入目标线,且 p39 (c) 的 E_{L+1}^band×2 是**无条件扣项**(臂二=搜牌驱动,窗口恒同步启动,无「若同步」条件式)**:**S = B + floor_resolved + Σ_w(窗口预留卡价_w) + E[刷费]×2**——**E[刷费] 口径对齐 p39:段带级求和 E[刷费] = Σ_w E_{L+1}^band(w)(各窗口期望刷次逐段带相加,非单窗口值——单窗口读法会少预留)**,刷价单价按 resolved 投资修正(`refresh_cost_effective`:商业间谍等投资变体改单价,基准 2=`REFRESH_COST_BASE` ADR-0456;免费刷/长线利好折价同源入账)**;U_L 与 B 的口径差(B 含 n̄ 自然 XP 抵扣,U_L 不含)在此声明:门侧用 U_L 定 EV、线侧用 B 定触发金位,两量同源不同维);金位条件的必要性 = 触发时批支出 B 必须不击穿保息下限——否则触发即破息,破息的合法性要走 p47 命题四的 V ≥ L 门(那是对批本身的定价,归 p47/p39 域;**死亡截断域下该门须按 §③(b) 升级为 V ≥ L + W_trunc,主改在 p47 件,本文声明依赖**)。B > 0 时 S > floor_resolved:**目标线恒在息线上方**——这就是「大于 50 金的时候也有场景要囤钱」的形式([41] 原文;默认局=floor 50)。

**S 的动态性**:储蓄期内每买一张牌 +4 XP(A3)→ xp_cur 单调升 → B(t) 单调降 → **S(t) 单调不增**(自检③断言锁)。数值例(自检③,Ī=7,期望每轮买 1 张):

| 场景 | 轨迹 | 触发 |
|---|---|---|
| lv6(need 40,g0=50) | S: 86→82→78 | r3:g=86 ≥ 78,买 28 金,余 58 ≥ 50 ✓ |
| lv8(need 72,g0=50) | S: 118→114→110→106→102 | r5:g=110 ≥ 102,买 52 金,余 58 ✓ |

注意 lv8 例:**纯零散视角需 18 击(72 金)、目标线一度到 118**——远超 50 息线,即超息囤钱不是边角而是高级升级的常态路径;自然 XP 抵扣把 72 压到 52(5 轮 20 XP),**B 对 n̄ 的弹性是 S 轨迹的主导项**。

### ③ 超息线囤钱定理

**两半结构**:

**(a) 超额持币零成本(地基引 p47)**。interest(g)=min(⌊g/10⌋,5) 只依赖 min(g,cap_resolved),cap_resolved ∈ {50 默认,100 息律上调局,90 开源节流局}(p47 A1+命题一递推);故金位从 cap_resolved 升到 S 的持有期**不放弃任何息**。形式化:∀d ≤ g−cap_resolved,L(g,d,R,Ī)=0(p47 溢余段,已证)。「囤到 S」因此**无息账持币成本**——这是超息囤钱可行的机制前提([41]「利息在 50 已封顶,超额囤金无持币成本」的引用态)。**⚠️ 息账零成本 ≠ 总账零成本(2026-09-07 修复批)**:死亡截断敞口 W_trunc(λ_death·存量金+底线流)在息账之外——「超额囤金无持币成本」只在 λ≈0 段成立为总账命题,λ>0 段见 (b) 管辖表。**⚠️ 域限定**:命题 3 全部结论是**不破息域的约束最优**(「囤到 S iff 判据」在「期间花销不落破 cap」的域内);**高 ρ 带的破息提前批可能占优**(自身数值:ρ=47/轮 vs 破息 L≤20——一个量级的差),该域的正确判定走 p47 命题四升级门 V ≥ L + W_trunc 对「提前批 vs 攒到 S」的直接比较,挂 sim 对拍 2 裁决。

**(b) 统一判据(何时该囤;2026-09-07 修复批:补死亡截断项)**。囤不是默认:囤的语义 = 放弃当期边际支出、把金导向 S。设边际动作 a 花 x 金、价值 V_a(x);把 x 导向储蓄使到达 S 延迟 δ = x/Ī 轮(Ī=净收入率,A5)。延迟的代价 = 少享受 δ 轮的升级后状态 = ρ·δ。**统一判据(中间带式,λ_death 项连续写入右端)**:

```
花(a) ⇔ V_a(x) > ρ·(x/Ī) + L(g, x, R,Ī) + ΔW_trunc(a)
囤    ⇔ ¬∃a: V_a(x) > ρ·(x/Ī) + L(g,x,R,Ī) + ΔW_trunc(a)

ρ = (ΔV_band + ΔV_pop)/R          (A7 保守首版:毛移位价值按剩余轮均匀摊)
   — 仅当 p39 双臂门为真时 ρ > 0;门为假 → 无待执行整买 → ρ = 0(纯囤无目标,
     退化为 [17] 原文形态:>cap_resolved 的每一分都该花/不存在囤钱理由)
L 项:仅 g<cap_resolved 的花销产生(p47 递推;囤钱不豁免息损账——期间把金花到
     cap 以下同样按 p47 定价,小额同档残损近 cap 区 ≤2、低金带 5-10,p47 命题三)
ΔW_trunc(a):动作 a 相对囤积的死亡敞口差 = λ_death(战力桶,节点类型)×(两路径
     的存量金+未来底线流敞口差)——P51 §F.3 金流底线口径(连胜=0;血只进
     λ_death 自变量)。敞口为总量比较,禁边际一阶引用(λ>0 段敞口曲线非线性,
     小步边际近似会漏掉存量清零主体)——每步决策重比总量敞口。
```

**三段管辖表(P48×P51 边界,离散版先行;连续式等 P51 采集 #3 λ 连续模型到位后替换)**:

| 段 | 判入 | 管辖 | 判据形态 |

### ④ 多目标排队(交换论证)

**命题**:n 个整买目标并队(升级批 + D 牌缺口承诺 S_gap + ……,**金支付目标**;装备不在域——装备无金币获取通道(p42 结构事实)),目标 i 有批成本 S_i、每轮价值率 ρ_i(>0 仅当其门为真)。单一储蓄池 + 收入率 Ī 下,**在「全部目标按一切序视界内可完成」的前提下(域的读法=对任意完成序截断都不起作用;该域的验证=解原问题的可行性检查,故比较器在该域内是精确的、域外退化为首序启发)**,储蓄分配的比较器是每金价值率 ρ_i/S_i——依次攒齐 argmax 开始的目标,总价值 Σρ_i·max(0, T−C_i) 最大(C_i=攒齐轮)。
**⚠️ 视界截断域修正**:交换代数只在无截断(max(0,·) 不起作用)时成立。**截断反例(亲算)**:Ī=1, T=7, T1(S=6, ρ=10)/T2(S=4, ρ=6.5)——每金率序(1.67 vs 1.63)选 T1 → 总值 10;**T2 先 = 19.5(严格更优)**。截断域(有目标在 T 内攒不齐)的正确解法 = **小规模枚举/DP**(目标数≤3 时枚举序即可),每金率序仅作无截断域的精确比较器与截断域的首序启发式。

**证明(两目标交换论证)**:目标 1、2,p_i=S_i/Ī 为攒齐耗时。先 1 后 2 的总价值 − 先 2 后 1 的总价值 = ρ_1·p_2 − ρ_2·p_1 = (Ī·p_1·p_2)·(ρ_1/S_1 − ρ_2/S_2)。故先 1 占优 ⇔ ρ_1/S_1 > ρ_2/S_2。n 目标由相邻交换归纳(Smith rule 形态)。∎

**与口述形态的对拍**:任务书命题 4 原表述「储蓄分配给每轮价值率高者」——**方向正确、比较器需精确化为每金率**:数值例(自检④ case B)目标 T1(S=72, ρ=17.2)/ T2(S=12, ρ=10):裸 ρ 序选 T1,每金率序(0.239 vs 0.833)选 T2;总价值 T2 先 = 72.9 vs T1 先 = 0(T=9 内 T1 根本攒不齐)——**裸 ρ 序在成本差大时严重选错**。两者在 S 相近时同序(case A:T1-first 56.5 > 37.7,两序一致)。实现语义:堆顶 = argmax ρ_i/S_i(「小顶堆语义」的边权精确化);堆顶目标的 ρ 进入命题 3 的汇率判据。

**边界**:①目标门为假时其 ρ=0,自动沉底;②多目标共享同一收入池的前提是批成本不重叠抵扣(升级批与装备批确实独立;两个升级批不存在——串行);③C_i 线性折算忽略息收入(Ī 不含息,保守侧)。
