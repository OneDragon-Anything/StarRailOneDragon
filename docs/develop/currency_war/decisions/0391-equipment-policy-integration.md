## 背景与问题

P14 证明了四通道期望账但停留在文档;策略层(M7 装备分配)与口述装备纪律
之间存在三个未接线缺口:

1. **穿着即合成的误触发风险**(口述:「穿着触发会被角色身上的残留件带偏,
   可能合出非预期产物」):P2/P3 基础件可穿(ADR-0265 只辖 P1),同一角色
   身上两件互为配方 → 游戏自动合成,**不可逆消耗两件组件**,无确认无日志。
2. **死库存无识别无去向**:回收流水线(口述:无用简易 2合1 到工具人 →
   3 件进阶同刷)需要「回收合格」判据(P14 定理 3 已证)与去向规则;
   现状 P2/P3 兜底 core 优先吃死库存 = 合成产物落 core 的转移摩擦。
3. **λ 无数据**:P14 最大不确定参数(每节点发放基础件数,现粗估 0.5)
   标定需要逐节点发放计数;runs.jsonl 无逐轮数据,日志无 owned 快照。

## 决策

1. **图谱纯函数三件**(cw_synthesis,与证明脚本共享图谱单一源):
   - `component_demand(K)`:K → 基础件需求向量(交叉件=两基础/自配件=×2/
     无配方件跳过)——P14 决策表输入;
   - `recycle_qualified(K)`:回收合格集 = 全 8 基础件 − K 的组件并集
     (定理 3:b 能合成可接受进阶 ⟺ 回收严格劣);K=None → 空集(保守);
   - `hoard_gaps(K, owned)`:成品 1:1 抵扣后组件需求 − 库存正差
     =「缺什么囤什么」判读锚点(P14 检验点 2)。
2. **防误合成配对守卫**(equip_allocation,全 plane):基础件发给角色前查
   其已穿基础件,互为配方 → 拒,除非 ①产物 ∈ key_equips 且穿者是 core
   (想要的配对,穿着触发=合成+穿着一次完成的快路径)或 ②两件均回收合格
   且穿者非 core(回收线有意 2合1;产物 ∉ K 由定理 3 反证,无价值销毁风险)。
   基础件判定 = RESERVED_COMPONENTS(恰全 8 件;SYNTHESIS_BASES 漏光能电池
   ——开发中自造 bug 被测试锚抓回)。
3. **死库存回收去向**(equip_allocation 兜底段,P2/P3 生效):回收合格件
   先于 core 兜底抽取,发非 core 工具人每人 ≤2 件(触发回收 2合1);发不完
   留 owned(囤积口述「没什么用就先不装备囤着」);core 不吃死库存。
4. **λ 埋点**(equip_all):每轮备战首次读板记 `[cw!][grant]` owned 全量
   快照(含工具;相邻轮快照离线 diff = 各节点发放件数 → λ 与事件条件化
   修正);同点 `[cw!][hoard]` gaps 行(判读锚点)。

## Considered Options

- **禁止一切基础件穿着**(合成前零穿着):与 ADR-0265 的 P2/P3 穿着语义
  冲突且无口述背书;守卫只禁「危险配对」,单件无配对风险穿着自由——否决。
- **想要配对也走装备栏主动合成**(口述精确控制路径):合成 op 不存在
  (需 UI 交互建档);穿着快路径在「产物∈K+穿者=目标 core」时等价精确
  (配对即意图)——op 建档后再评估精确控制场景。
- **死库存也发 core(兜底顺序不变)**:合成产物落 core 身上,换血时逐件
  拆(r134 摩擦判据);工具人承接收纳,摩擦最小。
- **λ 依赖识别发放事件**(奖励面板/补给选择逐事件计数):每种事件需
  建档,成本高;快照 diff 法零额外识别成本,节点归属可离线对账——先快照。

## 后果

- 行为变化面:P2/P3 基础件分配(危险配对拒/死库存改道非 core);P1 零变化
  (ADR-0265 辖域不动,回归锁钉死)。
- 装备栏主动合成 op / 冶金炉与扳手工具 op / R(c) 采集 = 后续批
  (equipment_mechanics 欠账节);λ 数值回填 P14 待若干局 [cw!][grant] 攒数。
- 测试:test_cw_w211_equip_policy(12 锁:图谱对拍 P14 例 1/2 / 守卫三态 /
  死库存去向与回收对 / P1 回归);旧装备锁 84 全绿(无一破坏)。

## 增补(磨损标定仪:「简易件默认穿」作为测量仪器)

- 日期:2026-08-28;关联:ADR-0265 增补(穿戴可逆,简易件默认穿)。
- 背景:用户裁决「简易件效果不大,穿不穿随策略定」→ 编排者采纳默认穿,
  同时把该行为当作**测量仪器**——默认穿制造了「组件在身上」的持续状态,
  实机遥测与 sim 对照因此能持续读到简易件穿戴的真实期望收益,而非停在
  口述定性。

### 量什么(观测量)

1. **穿戴暴露量**:逐轮已穿基础件数/局(P1 段与全局分列)——仪器的
   「剂量」项,读数必须带剂量才可解释(零暴露 = 仪器空转)。
2. **收益读数(sim 侧)**:on/off(保留过滤开/关)配对差的 P1 出口 hp
   与败场伤害,在 `equip_wear_effect` 灵敏度带({0, 半权假设值})下呈报
   ——sim 装备效应是校准假设层,读数=假设层灵敏度,不是已标定期望。
3. **收益读数(实机侧,标定目标)**:穿戴暴露量分桶的逐轮掉血分布
   (`outcomes` 掉血带),对照裸装期历史基线——这是校准 `equip_wear_effect`
   半权假设的实机锚点来源。
4. **损耗读数**:配对守卫拦截计数(该穿被拦)与穿着组件被取回次数
   (锁线回收)——仪器的「成本」项;成本项持续为零说明默认穿无代价,
   持续偏高则重新评估「转移成本可忽略」前提。

### 怎么读(判读规则)

- 结论强度 = 最弱一环:sim 读数是假设层灵敏度(方向性证据),实机
  分桶对照是标定证据;两者方向相反时以实机为准并记偏差。
- 剂量为零的窗口不构成证据(仪器空转 ≠ 无效应)。
- 读数经批间互证(可推翻假设),单批数字不立结论。

### 何时拆(退役判据)

仪器使命 = 校准「简易件穿戴的期望收益」并回填 `equip_wear_effect` 量级
锚点(现无实机定量锚点,代码注释已声明)。满足以下任一即拆:
1. `equip_wear_effect` 获实机标定值且两带 A/B 收敛(读数不再提供信息);
2. 实机分桶对照连续多批证明效应在噪声底以下(概念定谳:默认穿保留为
   零成本行为,仪器拆除,结论记 ADR);
3. 读数证明默认穿净劣(收益 < 成本)→ 回退默认穿(不是拆仪器,是
   仪器给出否定读数,走 ADR-0265 增补的回退通道)。

### 实现(P1 批)

- sim 侧:off/on 两臂 × wear_eff 两带的预登记 A/B
  (`.debug/temp/currency_war/w491_c_arm/PRE_REGISTRATION.md`)给出首批读数;
- 实机侧:逐轮已穿基础件数可由现有 `[cw!][grant]` 快照 + equipped 遥测
  离线 diff 得到,无需新埋点(缺项时再补)。
