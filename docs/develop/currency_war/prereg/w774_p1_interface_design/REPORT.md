## 2. 设计 v2(五项;各 v1 版骨架对齐细节见本文件历史版)

### ① 锁线(p1_iface_lockline_deadline → v2 重设计)

- **[23] 锚语义(主机制,现状确认)**:贯穿件/信号件在手即视为线锁定——cw_intention 信号驱动锁线是主体,v2 **不新增时间驱动触发源**。锁线时机问题重定义为「摇摆探索的代价管理」,不是「到点必须锁」。
- **摇摆探索期不强制**:信号未至时板面按 [31] 扩展定调运行(目标/填充/散件三级),p1_early_pair 派生配方对只作观测面——局 3 型「摇摆探索产出最优 P1」在此语义下合法存活(W764 反例被判据吸收而非排除)。
- **摇摆代价门(唯一 FALLBACK 触发面)**:同位面内 degrade_recover_mutex 事件计数 ≥2 **或** 连败 ≥2 且仍未锁 → 进入 FALLBACK 评估。依据:degrade 事件是摇摆的直接可测信号(已知清单内=换线摇摆);连败≥2 与④触发面同源;阈值粒度对齐,精确值挂 A/B 标定(§2 阈值清单)。
- **FALLBACK 锁前板面一致性验证(堵错锁,横切污染防护的源头)**:取当前板面与候选线集(p1_early_pair 派生集 ∪ FALLBACK)逐一算阵营交叠,交叠最大者且**板面该线成员数 ≥2**(各体系最低激活档 2-3 人的下界)才锁该线;全部不达 → **不锁**(未锁=方向集空,P2 侧至少不被误导;错锁=主动把 P2 搜牌方向钉在板面为零的线上,更糟——W772 M0b 失效的一半归因即方向供给)。锁后仍走既有 E_rounds 门换线(P16 滞回零改动)。
- **换线定义(写死,v1 缺陷消除)**:locked 后 p1_pair 变更事件 = cw_line_switch 门通过;ADR-0451 支出降格不改变 p1_pair,**不计入换线**——两事件不同层(方向层/支出层)。v1 的 ≤1 计数上限撤回(循环论证,无推导),换线次数降为分层读数。

### ② carry 装备(p1_iface_carry_equip_v2)

- **分配义务**(保留):硬节点备战帧 ∧ 意向核心上场 ∧ equips=0 → 简易非组件件必分配 ≥1;**输入前置门=①板面一致性验证**(意向线与板面不匹配的帧不触发——堵「错锁 carry 吃装」的串联污染);去向=意向核心优先、伤害向简易件优先(combat §1 稀释排序);豁免=owned 全为 RESERVED_COMPONENTS([29])或空。
- **卸装禁令 v2**:硬节点帧禁「**无接收者的卸装**」(卖出/弃置致装备回栏闲置);转移合法 ⇔ 接收者=当前意向核心 **或** 接收者在场星数 ≥ 被卸者([24]「装备转移是常态操作」语义保全;操作化只用既有 deployed 星级字段,不新增评估器)。v1 的「仅同线新核心」窄例外废弃——它与 [24] 冲突,且在①错锁时把装焊死在错线 carry 上(串联放大点,已断)。
- **空转挂账**:触发帧无可分配(供给面)→ 合法空转;空转率作 R-② 归因输入。

### ③ 遭遇备战(p1_iface_hardnode_prep_v2)

- **触发面**(保留):硬节点备战帧,`hp − L_node(rung) < emergency_hp(25)`。
- **口径边界声明(v2 新增)**:`streak_floor_loss_damage` 是 w324 冻结语料 417 条拟合的**条件败局伤害均值**(encounter=24.32−4.53×rung,斜率 SE 2.41;boss 退常数 26.71)——拿均值当生存阈值系统性低估尾部风险(局 2 -34 型 boss 税在 boss 均值可信区间外的行为未建模)。本判据**只作触发面使用,不作安全保证**;遭遇失血分布尾部(分位口径)与 rung 斜率敏感性(SE 2.41 下 hp−L 判定在 rung 1/2 翻转的稳健性)挂 P26 采集账,标定后回填。
- **金下限(v2 新增)**:授权仅当花后金 ≥ `rebirth_floor`(既有重生基数常量,[18])——低金局不授权,堵「20 金局被授权花到破息」(W777 §3.3);护栏 G1 退为批级兜底而非唯一防线。
- **出手率红线 R-③**:授权帧净出手率(金账下降)判定线 50%(M0b 同式)——围栏∩店空=合法零出手但计入 R 归因;「只开门不收门」的 M0b 等价漏洞判定化。
- **遭遇选难度联动**:`decide_encounter` 既有血量比/斩杀压力判据不动(避战辖域正交,v1 声明保留)。

### ④ 连败金流(p1_iface_lossstreak_flow_v2)

- **触发面**(保留):P1 ∧ 连败≥2 ∧ 金>50([17] 息律背书,W777 确认合格)∧ 意向线 form 缺口>0。
- **v2 排序判据**:溢余段支出候选全过 **[22]④ 再遇账比较式**——EV 排序 = 当场可上场体系件(P20 激活边际+L 收益侧)vs 囤件(再遇期望损失 1/q −息损贴现;**本线目标件/稀有件照买照囤**,[21]/[13] 定调的正常行为)vs 等级(仅 [33] 人口位例外)。v1 的「囤件垫底/默认不买」**废弃**——v2 的「不买」仅指**纯散件**([31] 既有硬约束「不为凑数羁绊花金 D 牌」,有出处非自创)。
- **排序非义务([19] 关系声明)**:重排只决定「有多个合法花处时谁优先」;来牌差(围栏∩店空)→ 自然空转照旧攒息,不强制花金。不辖刷新频率(P15 薄 EV 结论不变)。
- **出手率红线 R-④**:触发帧重排出手率 ≥50% 判定线;持续空转高 → 缺口判据过宽,回本设计。

### ⑤ 血线三带(p1_iface_blood_bands_v2;重推)

- **预警带 hp<40**([18] 质量线**直引**;v1 的 2×25=50 废弃):带内①②③的备战/装备授权升格为默认评估(「达标即复核」);买入禁令对象收窄为「非转化 ∧ 非压库 ∧ 非本线目标件」。

## 4. 与位面 2 支出授权(v3.1)的正交性声明(v2 增补)

- **输入耦合注记(v2 新增)**:②③④的意向线输入统一经①板面一致性门——①输出质量决定②③④判据有效性;错锁时②③④宁可漏触发(验证失败→该帧不触发),不错花。p2_spend_auth 通道 B 方向梯级同样消费意向线投影(`hoard_target_set`),上游一致性对 P2 侧同向利好,无辖域交叠。**互补关系(W764 组合判据)不变**:接口到位,授权才有商品可买;P1 失血下降(每 10 血↔P2 约 1.3 轮)决定 P2 有多少时间消费授权;开臂后重跑协议 V3 主判据。

## 5. 横切裁决(v2 写死)

1. **同帧多判据优先序**:⑤禁令 > ④排序 > ③授权;①一致性门是②③④的输入前置。③与④同帧组合(硬节点∧连败):③是开门(授权)、④是选花处(排序),不同层,授权动作在④排序框架内执行。
2. **末窗层归属仲裁**:末窗(r≥handoff_gate_min_round)∧ p1_exit_blood_short → ADR-0451 降格独占(减支出方向);③授权与⑤预警带升格在该帧不触发(加支出方向让位)。血线既有谓词(停级/停刷/ALL IN 窗/terminal_release)全在 discipline 层原样,本设计零触碰(层归属:①=方向层输入治理;②=执行/分配层判据;③④=授权/排序层;⑤=判据面扩展)。
3. **归因树加分支 D**:M3 计数绿 ∧ M1/M2 败 ∧ 锁线一致性读数差(锁定线与出口 form 阵营交叠低)→ **锁错方向**,回①板面一致性/锁线质量重设计,不诿备战/血线判据(v1 归因树会把此格误归分支 A)。
