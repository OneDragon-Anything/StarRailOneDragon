# 云璃

## 档位 id=1221 5费 Back

![icon](https://act-webstatic.mihoyo.com/darkmatter/hkrpg/prod_gf_cn/item_icon_u47dee/ba99454008b0427fa521b11a19f7926c.png)

- 羁绊【狼狩】:召唤【步离人】协同战斗，其在参与战斗后可以获得经验并升级。我方队员携带更多装备会使其额外获得经验。\n【狼狩】队员的前/后台强度提高，【步离人】每次升级后使该加成提高50%。
- 羁绊【能量】:【能量】队员的提高。在场上生成【能量地块】，可提供和能量恢复。

- ★ 我方攻击或受到攻击后为云璃恢复能量，施放终结技攻击敌人后获得【剑盾】以保护我方前台并发动反击。
- ★★ 我方攻击或受到攻击后为云璃恢复能量，施放终结技攻击敌人后获得【剑盾】以保护我方前台并发动反击。
