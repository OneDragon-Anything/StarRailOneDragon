## 附加机制解锁(高价值,大钻钞)

| 布局 | 效果 | 等价钻钞 |
|---|---|---|
| **大胜表彰** | 战斗开始获1战技点;击败最终首领时,若剩余≥1轮,恢复40点小队生命值 | 20 |
| **投资经验** | 第二/第三位面开始时,获得2经验 | 60 |
| **势力削弱** | 奖励节点战斗中,敌方目标在战斗开始时受到等同于生命上限99%的伤害(特殊投资环境不生效) | 60 |
| **钻石闪耀** | 补给阶段的可选项中有概率出现钻石装备 | 60 |
| **攻守自如** | 连胜数为0时仍获1金币连胜奖励;遭遇节点出现难度级别4敌人;治疗/护盾强度+10% | 100 |
| **环境刷新** | 选择投资环境时,可刷新1次(重置所有投资环境选项) | 60 |
| **分支刷新** | 选择遭遇节点分支时,可刷新1次(重置所有分支难度和奖励) | 60 |
| **补给刷新** | 选择补给阶段补给时,可刷新1次(重置所有可选角色和装备) | 60 |

> bot 决策优先级建议:势力削弱(奖励节点秒杀,A8 高血 boss 关)= 投资经验(经济节奏)> 钻石闪耀(补给出钻)> 环境/分支/补给刷新(灵活)> 攻守自如(连败保经济)> 大胜表彰(便宜战力)> 战斗能力增幅(填空)。

## 职级 / 晋升(bwiki 同页)
- 职级段位:黑铁→青铜→翠钢→钴银→冰肽→紫金→投资大师→资本帝王→财富造物主。
- 职级奖励:黑铁/青铜(晋升点×500+遗失晶块×6);翠钢~投资大师(星琼×100+晋升点×1000);资本帝王/财富造物主(星琼×50+晋升点×500)。
- 羁绊挑战:激活 N 个某羁绊(如 7 仙舟/6 昼神/5 盛会之星)→ 星琼×20+晋升点×200(紫金+限定)。
- 通关奖励:等级10/3星各费角色/15连胜/8人全装备 → 星琼+材料。
