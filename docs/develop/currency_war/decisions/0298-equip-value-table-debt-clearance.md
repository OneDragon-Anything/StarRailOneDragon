# 0298. 装备价值表数据债清偿(批㉛ F2):3 死名裁决为表残留并删除

- 日期: 2026-08-25
- 状态: accepted

## 背景与动机

批㉛ 压测 F2 披露:`_EQUIP_VALUE`(cw_events,V4.4 先验)12 键中
**超级电池/能量饮料/翁瓦克** 3 个不在 EQUIPMENT_ROSTER(158 实体注册表),
被 ADR-0294 件2 的采样过滤静默剔出 sim 供给池(表值质量 20% 被滤);
生产侧对偶:若真名供给出现,`decide_supply` 查表恒 0 分。检查项
`equip_value_table_roster_coherence` 以预期红灯披露(每批 ~100 条)。

## 裁决(先查证后动刀:历史改名残留 vs 注册表漏收)

全语料 grep(docs/sources、实机 replay OCR、攻略语料、plaza API 抓取):

| 死名 | 语料证据 | 裁决 |
|---|---|---|
| 超级电池 | 仅以超充站投资卡效果文本的 buff 词【超级电池】出现(实机 replay `invest_cards.jsonl` 3 次,kind=strategy);**从未作为供给装备名** | 表残留(与 buff 词撞名的幻影键) |
| 能量饮料 | 全语料零出现(仅代码/sim 自产物循环自证) | 表残留(纯幻影名) |
| 翁瓦克 | 仅以局外遗器名出现(风套/翁瓦克,攻略语料明确标注「局外!」;plaza lineup 语料同)——ADR-0130 补缺时把局外遗器误收为模式内装备 | 表残留(ADR-0130 误收,↺ 其「翁瓦克 4」项) |

对照面:实机 replay decisions.jsonl 中**真实供给装备名**(反重力皮靴/
火力风暴潮/光能电池等)均有出现——语料对装备名有捕获力,三死名的
缺席是真缺席,不是采样盲区。**三键均为删,注册表无漏收。**

## 决策

1. 删 `_EQUIP_VALUE` 3 死名(超级电池 3/能量饮料 2/翁瓦克 4);
2. 价值重分配(死名质量回活名,按功能对位):
   - **翁瓦克 4 → 蓄能帆 4**:同为充能系(行动值回能 vs 遗器充能拉条),
     且语料实证其为高分装(final_comps「蓄能帆(优先级=希儿第一件)」、
     plaza lineup「花火的蓄能帆」)——此前表内缺键 = 同病 0 分盲区,
     转投即清;
   - 超级电池 3 的电池族角色已由光能电池 3 同值覆盖;能量饮料 2 的
     回能角色已由绝对热量 2 同值覆盖——无需重复计分(防双计)。
3. 检查项 `equip_value_table_roster_coherence` 预期红 100/批 → **0**
   (验收硬指标;docstring 标注已清偿);
4. 生产侧 `decide_supply` 无代码改动——它读同一张表,死名删除后
   表键全集可查,蓄能帆从 0 分升 4 分;
5. 定向锁 `test_cw_adr0298_equip_value_debt.py`:表键⊂roster 名(死名
   不得回归)/ sim 采样池与表键恒等(ADR-0294 过滤不再静默剔名)/
   蓄能帆价值可读且参与决策排序 / 检查项恒绿。

## Considered Options(最值钱栏)

- **补 roster(按「注册表漏收」方向)**:拒绝——语料核证三名均无
  模式内装备实体证据(超级电池是 buff 词、能量饮料零出现、翁瓦克是
  局外遗器),补进去 = 把幻影键升格为假实体,污染 158 实体注册表;
- **死名改映射到新名(游戏改名假设)**:拒绝——无任何改名证据
  (roster 的电池/回能族实名齐全且各有其键),凭空映射 = 双源;
- **只删键不重分配**:拒绝——翁瓦克 4 分承载 ADR-0130「核心装补缺」
  的意图,蓄能帆有语料实证优先级,0 分盲区正是本债要清的病;
- **3 死名分值全转蓄能帆(4→9)**:拒绝——超级电池/能量饮料的角色
  已有同值活键覆盖,累加 = 同一功能双计,抬高先验无证据。

## 后果

- sim 供给采样池 12→10 键,池=表恒等(ADR-0294 过滤从「剔 20%」
  变恒等);sim 供给分布小改(蓄能帆入池),属校准层代理边界内的
  既知近似(批㉛ F5);
- 批㉛验收:`equip_value_table_roster_coherence` 红灯清零,每批 sim
  报告信噪回收 ~100 条;
- 生产 `decide_supply` 对真名蓄能帆供给从 0 分升 4 分;
- ↺ ADR-0130 的「翁瓦克 4」补项(其余三项火力风暴潮/高周波电锯/
  冷笑话引擎为真名,维持)。
