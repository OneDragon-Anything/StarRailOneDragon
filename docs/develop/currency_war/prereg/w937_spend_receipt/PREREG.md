## v1 口径的缺陷披露(诚实记录,原数字降级)

v1 主判据「授权未兑现帧占比(帧级零花费动作)5.37%→1.89%」存在两洞:

1. **分子粒度错位**:分子 = 帧级「无任何花费动作」,而契约/回执是渠道级
   ——升级授权未兑现但同帧买了牌的帧被计「已兑现」,恰漏 13-2 型病灶;
2. **分母共动**:on 臂产出侧拒发把 43 帧改 tag='存息' 移出分母——
   分母收窄是**处理机制本身**,原占比差不可解读为「同批授权兑现率提升」
   (部分是重分类效应)。v1 数字仅保留作历史记录,不进开臂量化判断。

## 主判据 v2(判前锁定)

- **口径A(渠道级,处理效果)**:渠道授权帧 = 账本 dp_posture tag 含
  '升级'(levelup 渠道)/ 含 '+D'(refresh 渠道);渠道未兑现 = 授权 ∧
  该渠道无采纳动作(LevelUp / RefreshShop);占比 = 未兑现渠道帧 /
  授权渠道帧。判定:on < off。
  **披露**:on 臂分母收窄(产出侧拒发)是处理机制本身;占比差 = 「不再
  发不可兑现的授权」的效果,不是「同批授权兑现率提升」——后者由口径B回答。
- **口径B(同帧集配对,兑现无损)**:两臂同 (plane, round_num) 且同渠道
  都发授权的帧集上,渠道兑现差异。判定:on 不劣于 off(该子集上唯一行为
  差 = 执行侧 no_premise 纵深防线)。
- **主判据 = A(on<off)∧ B(不劣化)**。
