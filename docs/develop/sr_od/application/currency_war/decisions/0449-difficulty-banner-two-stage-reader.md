# ADR-0449: 备战难度旗牌读数器两级管线(W526)

## 背景

难度数字为 stylized 艺术字,直读 OCR 系统性失败:84 决策帧仅 2 帧 live 且读出
0/1(全错),cw_difficulty_account 曾以「可算不可读」立论绕开、全链路退简报先验
108。用户发起识别体系重审(视觉大模型可作真值)后,编排者裁片实证推翻旧定性:
①区域框 [116,28,156,113] 正确——战斗类节点的备战帧旗牌完整在框内;补给节点的
备战帧**本来就不显示旗牌**,空读回退是正确行为;②真因 = 白色艺术字/深色纹理
旗底/顶部徽记贴边,文档型 paddle 直读必死;③4x 放大 + OTSU + 反转后数字清晰
(117/114 实证可读)。

## 决策

`read_enemy_difficulty` 升级两级管线:**裁片 → 4x(INTER_CUBIC)→ OTSU →
反转 → 徽记 y 分带剔除(徽记 y0-45、数字带 y≥55)→ paddle**;二值化为主
(41/41)、4x 放大为辅,两级形状与 `read_level_up_cost`(W332)一致。
合理带守卫落地 **[20,300]**:任务书预设 [50,200] 被实证否决——最小真值 39
(低职级局完整旗牌)、>200 为合法游戏态(OVERFLOW_THRESHOLD=200,实测 211);
推导写常量注释。消费端/live 标记/回退语义零改动。

## 效果

58 帧生产路径对拍(PYTHONHASHSEED=0):**41 个有旗牌帧 100% 读对、零带内
错值;17 个无旗牌帧 100% 正确 None;旧管线 0/58**。值域发现:
39×3/42×2/108×8/111×24/114×3/117×2/120×1——难度逐局逐位面变化(非恒 108,
难度修改器事件与位面递进都会改),逐帧读通有真实决策价值。主备裁决:难度
主源 = 备战旗牌管线(用户裁定:难度随节点变、规则未知);位面详情明文
(1-1 采集)与简报值降为参考基线,session 恒值为兜底。

## 边界与后续

- \>200 溢出区零真值样本:实机遇溢出局后补帧锁。
- 线上 live 命中率实机复核待 ⑳+2。
- VLM 真值对拍方法论与 W531 SIFT 基准批同款(标注一致性自检+无法建真值不评)。
- cw_state 字段注释「stylized OCR 常空」已随本 ADR 更新。
