## 门① 内部推导健全性 —— **基本过(结构成立;两处口径缺陷,一处需修)**

### 通过项

1. **γ 全出局、无血差分消费(修复项 #1/#10 复核)**:脚本逐行核实——`flow_diff = streak_gold(st) − LOSS_GOLD_BY_NODE[node]`,纯注册表金流;`hp` 字段虽载入但只用于终局死亡判定(`hp_after ≤ 0`),不进任何差分、任何换算。W_upside/W_floor 全链路无血当量。v1 的双计链(γ_hp·L_c 与 γ_win 互证)因结构移除而消失。✓
2. **W = W_flow + W_floor + W_ext 分解推导**:W_flow(胜败金流差通道)与 W_floor(死亡截断通道)机制上不相交——前者是「同一轮内胜负两态的金流差」,后者是「死亡清零的存量+未来流」,无同一笔金双计;W_ext ≥ 0 只声明不定量,下界方向安全。✓
3. **存量+未来流一次计入(修复项 #2/#8 复核)**:D = g + (final − g) = final_gold,分解恒等且只计一次;g 不再出现在任何其它通道。✓
4. **λ3 定义与估计一致性**:§2 定义 λ_death(P桶,R) = P(距局终 ≤ 视界 | 处于 P桶),实现为桶内轮次 `(died ∧ dist_end≤3)` 均值,定义—实现相符;关联级身份在 B3 如实声明(Δλ 不可识别挂 A/B)。✓

### 缺陷(需修)

- **A1(需修)「视界分层 λ3=0.000」是构造性恒真,不是实证**。距终>6 轮的轮次按定义不可能在 3 轮内死亡(dist_end 以已实现轨迹的末轮为锚),该条件期望恒 0、与数据无关——`n=1080/1080` 的「双侧一致」零信息量。§4-B 视界分层、推论 3、§7-6 把它当「实测直读」证据引用,论证不成立。结论本身(早期段守息不翻转)可用非循环证据另立(见门⑤),但**这根论据腿必须换**。
- **A2(注记)λ3 是 3 轮累积危险率,却整窗归因到窗口内每一轮**:濒死带每轮 W_floor = λ3×D 实为「整个 3 轮窗口的总敞口」,逐轮边际成本被夸大约视界倍(≈3×)。方向性结论不受影响(即便缩 3-10 倍仍 ≫ 息差 cap=5),但 §4-B 的 17-90 金/轮**数值**因此不可作边际量引用——「禁作闸门」条款应加严为「数值不作边际成本引用,仅作敞口注记」。
- **A3(注记)R=距局终是事后量**:s=(g,P,R) 中的 R 在决策时不可观测(它是本局剩余寿命)。λ(P,R) 作为状态函数只具描述/注记意义,不能直接进决策时的 EV 比较;此点 v2 未声明(B3 只声明了视界参数),应补。
