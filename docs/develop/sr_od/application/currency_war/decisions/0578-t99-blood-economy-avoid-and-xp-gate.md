## 1. 背景与问题

[40] 裁定(2026-08-31 OPEN-6,同日二次收窄)两支此前均无落码:

- **[40]① 主动选择=回避**:E1/E2/E15 三选一不选血本位卡(期望价值依赖板面强度,胜率域建模做不好且强弱不对称)。`decide_event` 评分链上没有任何血本位判别读点——奋斗协议按普通评估卡拿 `PICK_VALUE=45`,当帧候选最高分直接入选(g_20260907_025608 P1 r2 病灶帧实证:候选 爆晶矿工/数值碾压/奋斗协议,45 分 argmax 入选,后续 XP 血购烧血 ≈62,复盘 §锚⑦ 败因链第①环)。识别所需的 `EconomyEffect.xp_buy_hp_cost=6` 早已在册,唯一消费点却是遥测写点而非选择器。
- **[40]② 被动获得=最简安全带**:血余额 ≥ 下一级血成本(⌈need/4⌉×6)才买经验,否则停(三次简化,不留安全量)。grep 全零落码;实际防线 = 更严的血预算线族(`level_spend_blocked` = P21 停升级线 ∪ P2 危机带,语义不同源:血线内升级 EV 严格负,非支付能力检查)。

## 2. Considered Options

| 方案 | 裁决 | 理由 |
|---|---|---|
| ①A 强降权(加罚 N 分) | ✗ | 罚值无推导=拍值(ADR-0519);给血计分触 [40]③ 定价禁域;新增加减叠加消费点违 ADR-0524 |
| ①B 候选排除 + 分区触发序 | ✓ | 「主动选择=不选」字面实现;零新常数;不触定价禁域 |
| ①C config `strategy_forbid` 填名单 | ✗ | 策略层裁定降级为用户可选偏好(缺省空=不生效);名单不自动覆盖新卡;reason 归因混线 |
| ①D 调低 `PICK_VALUE['奋斗协议']` | ✗ | PICK_VALUE 是 ADR-0143 知识判据定序器,混两族语义;调分仍是定价不是回避 |
| ①resolve 挂点 = eval-lcs 分支内(方案 v2) | ✗(N2 升候选级) | 分支仅在 PICK_VALUE 命中时可达,未评估血卡 × 形变名永不到达分类点(今日不可达但埋同型盲区);候选级先分类后进分值支,四形态全覆盖 |
| ②闸阈值口径 = 剩余击数 ⌈(need−cur)/4⌉(v1/v2 曾误绑 clicks_to_next_level) | ✗(N1 拍板全量) | 裁定字面「下一级血成本(⌈need/4⌉×6)…只看下一级所需」即全量;cur>0 是常态(买牌 XP 直抬 + 购经验溢出结转),剩余口径系统性压低门槛、方向恒向放行,与「否则停」反向(lv7→8 极端例:cur=48 时剩余口径门槛 6 血 vs 全量 78 血,13 倍欠检);全量先例在册 = cw_plane_table.clicks_to_level |
| ②消费位 = 只接 prep 批入口 | ✗(三消费位同构) | 店通道 M3 发射位/授权面镜像不接 = 同帧双栈语义断层(候选③ 先例:decision_v2 侧停、cw4 侧照发) |

**三态触发序裁决(F1)**:L1 可入选非血集(非血 ∧ 非 forbid)非空 → 其 argmax;L2 其空 ∧ 非禁血卡非空 → 血卡间常规评估序 argmax;L3 全禁帧(含混合全禁)→ 全体 argmax 现状退化零漂移。血卡排位于「可入选非血卡」之后、「被禁非血卡」之前——user-forbid「有替代永不选」的血卡替代在 L2 兑现;L1 内 priority +30 不能把血卡救回(排除是集合级结构规则,分值族软加分不可逾越)。

**回避授权路径申报(用户 2026-09-07 授权书)**:授权允许「若正确处理的成本过高,策略层面直接避免主动选择该选项」。裁决 = **保留机制 + N1 修复**,未启用回避整段简化——二轮审实证除 N1 外零结构级纠缠;授权书辖域自认主要影响低/中等级成本取舍,而低中等级(lv3→6,血成本 6-60)恰是 62 血级损失的实际发生域;砍掉件二 = 被动获得局 XP 购买通道零支付检查,与 [40]②「否则停」方向相反。回退条件:实现批发现 N1 之外新结构纠缠 → 重开方案审(未触发)。

## 3. 已实施架构

### 3.1 件一:选择层候选排除([40]①)

- **判别谓词 `cw_investments.is_blood_economy`**:效果把 HP 写进经济循环的字段(xp_buy_hp_cost>0 ∨ hp_gold_swap)即入族,注册表派生零名单零常数;当前族集 = {奋斗协议, 不等价交换} 与裁定原文点名一致。名字含「血」不可作判据(反例:鲜血阶梯 = 75 分顶分战力卡,economy=None);补偿型字段(gold_per_20hp_lost/gold_per_hp_lost_now)不改支付币种不入族。
- **`resolve_strategy_canonical`**:归一 + LCS 解析(阈值 0.6 + |Δlen|≤3 与 pick_value_of 现参数同源,逐字搬家);pick_value_of 重构为消费它,全注册表 335 名逐个对拍零漂移。
- **`decide_event` 分区**:单次评分循环内随算随记(得分/归因/血本位/被禁),循环后三态触发序收口;L1 帧存在血卡候选时 winner reason 附 `+blood-avoided`(观测锚),L2 reason 显影 `blood-forced(…)`;零新遥测通道。PICK_VALUE['奋斗协议']=45 语义保留(知识定序器),其选择域生效面被排除支覆盖。
- **候选级解析挂点(N2)**:精确名 miss 且非 env 的候选,进任何分值支之前先 resolve 分类——不依赖后续分值支可达性;env 名禁进策略解析(ADR-0144b 同款守卫,29/83 env 名会 LCS 误中策略名,误分类会错杀 env 选项)。

### 3.2 件二:[40]② 血闸(执行通道)

- **判据 `cw_economy.blood_xp_gate(hp_trusted, hp_readable, level, cost)`(纯函数)**:`hp_trusted ≥ blood_xp_full_clicks(level) × cost`;全量击数 = ⌈XP_TO_NEXT_LEVEL.get(level, 4)/XP_PER_BUY⌉,闸内直算权威表逐字(不消费剩余口径的 clicks_to_next_level,不借 cw_plane_table 的 1/2 级先验);**满级分支在公式本体**(R1):level≥10 → 0 击恒放行。hp 不可信帧 fail-closed 返 False(沿 blood_budget_levelup_blocked 同面同论证:误放=血线内追级、误拦=少升一级,非对称)。
- **模式解析单一源 `cw_investments.blood_xp_mode(session)`**:(卡名, 每击血价) | None;[40]② 闸与 ADR-0577 遥测写点同源消费(record_hp_pay_event refactor 消费之,零行为变化);金本位(None)全链直通零改动。
- **消费位(与 level_spend_blocked 三消费位同构)**:①prep 通道批入口 `_level_up` 循环前整级授权检(拒 → 与「level 基线读不到」同返回路径);②店通道 M3(shop.py,与 crisis_level_spend_defer 同点,拒因分键 `blood_xp_gate_defer`);③mandate.py M3(闸拒先于必花域豁免判定——支付能力检查不可被域/地板豁免)+ entry.py 授权面镜像(`blood_xp_gate_blocked` → crisis_yield 同款让位,分键 `posture_blood_xp_gate_defer`)。
- **prep 逐击双检(血模式限定)**:①支付能力地板 modeled_hp(= hp_trusted − 已击数×单价)≥ 单价;②过冲 fail-closed——已击数 ≥ 入口授权击数(全量口径)而级未验证成功 → 停点(授权级界已买满而级界不可验证,文义公式对「下一级」无法 affirm;P21「证据缺失时禁令保持」同款);自愈 = 下一动作批入口重授权。实付上界 = 授权击数 × 单价 = 裁定授权血成本,复盘实证的「授权 24 血、验级失败实付至 72 血」过冲(LEVEL_MAX_CLICKS=12)结构性消灭;cur>0 帧验级成功路径实付 = 剩余击数 × 单价 < 授权血成本(正常省钱路径,非口径混算——授权界全量与实付自然剩余是两个显式量)。
- **与既有防线关系**:与 level_spend_blocked 串联(AND)不替换,拒因分键各自保留;解锁包件①交互(N5/R2 辖域收窄):`p1_blood_floor` 近死帧解锁(死亡线转化优先)与新闸 AND 后,真实收窄域 = lv≥5(血成本 ≥30 > 近死带 hp≤15)——lv≥5 近死帧血模式购经验被闸拦属预期;lv3→4/lv4→5 近死带内双过 = 两授权交集(成本 6/12 ≤ 15),判读为合法帧,禁按「双栈语义断层」误报。

## 4. 边界申报

- **授权链与 [39] 辖域分界**:闸读 hp 的授权 = [40]② 本身即用户逐项确认(2026-08-31 OPEN-6 + 同日三次简化收窄)+ 00_framework §3 硬闸门条款。[39] 禁 hp 作运营质量信号驱动决策;本闸是支付能力检查(买不买得起下一级),不回答该不该转型/止损——mandate「HP 不进任何检查点」辖域是 [39] 质量信号面,本闸是 [40]② 裁定面,后者立法在后且更具体。闸禁读 hp_pay 遥测(ADR-0577 隔离申报辖域不变),消费最近可信备战帧值(与 P21 同输入)。
- **退化区间(lv≥8 观测域内不可满足,R3 措辞)**:全量血成本 lv7→8=78(临界可达,需 hp≥78)、lv8→9=108、lv9→10=126——hp 观测域(≤100,实采历史)内 lv≥8 结构性不可满足 = 裁定字面自带后果(「只看下一级所需…升级走买牌送的自然 XP」),预期行为非 bug(T10 锁);若未来实采证得 hp>108 帧,闸按公式正确放行,不得按旧「恒不可满足」口径误判闸故障。血池实际上限未证(economy.md:134 的 100 是 read_hp miss 默认值),挂实采验证项。
- **授权书括号注勘误挂账(R4)**:授权书「lv≥7 血成本 78-126 > 血池上限」被数学证伪——78 ≤ 100(观测域上界),「恒超池」边界实为 lv≥8;「两种口径下行为一致:自动不选」亦仅 cur=0 帧真(cur>0 高位帧剩余口径门槛趋低)。§5.6 结论(成本取舍集中低中等级)不依赖该括号注,裁决不摇;本条即「待玩家确认」记录,编排者批回写 11_shop 时顺带澄清。
- **sim 零影响**:sim 不建模三选一(件一)且 XP 通道为建模层(件二闸属执行通道),零 sim 改动零 sim 锁。
- **prep 金门错币种(ADR-0577 §4 登记项)部分收口**:本闸逐击支付地板使血模式 XP 通道获得血排干保护;金门(`gold<4`)现行为保留不动(血模式下该门不构成危害面,金不由 XP 点击消耗)。
- **no-OCR 盲点**(两 handler OCR 全空时盲点中卡)属构造性血盲(信息不存在无从解析),登记不修,修法方向 = 零命中走 retry 重读(执行层行为变更,不在本批)。

## 6. 风险与后果

- LCS 假阳性残余:形变名误解析到血卡名 → 错失一张好卡(投资三选一局内多次出现可再生);血卡漏选 = 62 血级局级损失,非对称代价结构支持当前取向;实机录得误排除再调。
- 新血本位卡建模滞后:EconomyEffect 未建模则谓词不可达(全注册表采集渐进补全同面,未注册名告警已在 op 落盘)。
- 店通道 hp/level 陈旧偏差:店开态 hp 结构性不可见,闸消费最近备战帧值(hp 偏差上界 = 本店访期血购击数);全量口径下闸公式不依赖 xp_progress,xp 快照漂移面结构性消失,level 单调缓变偏差随 hp 一并判读观察(P21 同面同语义)。
- lv≥8 停购判读风险:首个被动获得局 lv8 停购按 T10 申报判读为设计行为,禁当故障排查。
