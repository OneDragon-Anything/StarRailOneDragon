# ADR-0356:出口金底线=P10 状态函数判定;连胜破息地板保留+口径标定挂账

- 状态:accepted(2026-08-27,W137)
- 判据:math_proofs P10(`research/proofs/p10-exit-gold-floor.md`,计算脚本
  `tools/cw/proofs/w137_p10_exit_gold_floor.py`);用户定谒 2026-08-27 凌晨
  (「出口金 27 肯定太穷,但底线数值该用期望账算,有人提过 40+」;
  「不是算过数学期望吗?又做成 if else 判断了?」);
  sim 账本 w135(seeds 0-99,池 bab146c68c5df11a)与 W128 口径 27.3;
  口述 [17]/[28](50 息律/双指标验收)/[19]①(连胜在手破息)/[18](hp=报警)。
- 影响:docs(game 侧 P10+索引);`decision_v2/discipline.py`
  `_streak_floor` **注释升级(零行为变更)**;**不改任何常量/分支/地板值,
  无 sim 对照义务**(行为面逐位不动)。

## 背景(两个命题)

1. **出口金底线**:sim 均值 27.3(W128)/21.95(w135)被用户判「太穷」,
   有「40+」提案;P1 出口金 ~50 的 [28] 表征被部分读成「可独立优化的验收目标」。
2. **连胜破息 if-else**:`discipline._streak_floor`(boss 窗 + 连胜≥2 + 硬节点
   + EV(连胜金×剩余)>0.25 → 地板 10→5)是 W113 §8-2 已标「收编」的
   覆盖态残留;用户质疑连胜取舍已 EV 化为何还有手搓 if-else。

## 决策

### 1. 出口金底线:不立常数(40+ 证伪;现行阶梯=期望账输出)

P10 已证:G* 是**状态函数**——常态溢价 <0.5金/金(利息通道)叠 P2 流动性
保险(假设项,15-20 金=「首窗能动作」)→ form_floor 20;硬节点 V(免掉血
8.8-12.4 金)≫C(≤3 金)→ boss_floor 10/连胜地板 5;位面末 → allin 0。
**与现行阶梯一致,维持;「40+」无账面支持(溢价 0.12-0.17/金@40;
sim exit≥50 桶 hp0 率最高 0.31、r(exit,hp)≈−0.05)**。sim 出口金穷=
失败线症状(form_ok 3%/p1_pass 2%,中途破息),修复面在成型过程,
验收继续走 [28] 双指标,出口金作表征量。

### 2. `_streak_floor`:保留 + 注释升级,标定挂账(不删、不改行为)

- **为何不删**:boss/遭遇窗是**旁路**(`arbiter.interest_rule` 对
  boss_window 明确豁免),窗内唯一授权器=地板——「连胜在手深花授权」
  语义**没有现成 EV 账本路径可承载**;W113 §8-2 的收编方案
  (「F5 → SPEND 段节点级授权加成,V 按 [27] 掉血期望加权」)依赖的
  SPEND 段参数化架构未建,ADR-0352 又冻结旁路逐位不动。此刻删除=
  丢 [19]① 口述语义且无账本兜底。
- **为何不改标定(挂账)**:P10 ④ 已证旧账口径错档——cost 侧 0.25 魔数
  无来源(真值 0-3 金,回档口径)、reward 侧平面全胜上界(视界错档,
  ADR-0352 在买侧修过的同病)、漏计真支柱(免掉血 8.8-12.4 金)。
  但补上免掉血项后 fire 带更宽(③ V≫C),单改 0.25 会把 fire 收窄到
  错的方向;正确修法=随 W113 收编批把 V 侧按 [27] 掉血期望+连胜金
  胜率加权整体重写。本批只把上述口径写进注释(判读不再误读 0.25
  为「已标定值」),行为零变更。

## Considered Options

- **删 `_streak_floor`(地板回 boss_floor 10)**:否决——boss 窗旁路无
  EV 门,删除即无补偿地丢 [19]① 语义;P10 ③ 表明方向(深花授权)期望正。
- **本批重写为「免掉血+连胜金」标定账**:否决——fire 带重标需要
  sim A/B + 锁更新,而正确载体是 W113 收编的节点级授权(V 进候选账),
  提前在覆盖态里重标=又一轮打补丁;且 ADR-0352 冻结旁路。
- **立「出口金 ≥40」新地板**:否决——P10 ①⑤ 证伪(溢价与 hp 桶分布
  双向不支持),且复刻 [28] 明令防的「金 92 板面弱」镜像。
- **P1 出口金遥测补「可回收 1★ 值」口径**:挂账不落码(判读口径项,
  归遥测批;P10 ④ 依据:1★=活期金,袋穷≠穷)。

## Consequences

- 行为零变更:无 sim 对照义务、无锁更新;CW 全量测试不受影响。
- 挂账两笔:① `_streak_floor` 标定重写(W113 收编批);② 出口金
  双口径遥测(遥测批)。
- 后续判读出口金时引 P10:袋子金均值不作健康指标,改看
  「双指标 + 袋子金/可回收 1★ 值」。
