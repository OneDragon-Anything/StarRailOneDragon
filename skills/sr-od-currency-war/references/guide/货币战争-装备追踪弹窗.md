# 货币战争-装备追踪弹窗（攻略装备推荐逐角色追踪）

**识别**：`is_precise` 命中 `货币战争-装备追踪弹窗`（锚：标题「装备追踪」+ 行标签「优选装备」双文本组合）。
**目标**：应用攻略后自动弹出的装备推荐页——每行一个攻略含角色：头像 +「暂未获取」状态 + 优选装备图标 +「追踪」按钮；行内装备图标 = 该角色推荐装备的结构化来源（与详情页文字互补）。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：「应用攻略」成功自动弹出；再次打开的入口推断 = 备战右上「装备追踪中」旁铅笔编辑按钮（未实测）。
2. **追踪**：逐行点「追踪」开启该角色装备追踪（状态改变型，效果未实测）。
3. **出口**：右上 X 关闭（实测回备战，攻略仍应用——应用与追踪独立，关掉不撤应用）。
