# ADR-0556: 未锁线转换通道 T5 纯结构判据——垫底级消费位第五触发源(结构层)

- 状态:已实施(四轮对抗设计收敛后直核收口;落地审阻-1 修复+观察 6 条处置完毕)
- 关联:ADR-0288(凑档降级「有比没有强」接受形态在册先例,辖域限定见 §4)、ADR-0525(出口③有界成本授权,同消费位锁线支)、17 号稿(N2 can_deploy_single 围栏单一源/N3 登记契约/§4 自检⑥)、20 号稿(必花域/L2 触发源/单源纪律)、11 号稿 §7.3(垫底级消费位单一源宿主)、p46/p47(P1 谓词原式与 loss_exact 规范式,math_proofs)、00_framework §1/§3(结构判据合法类与硬闸门辖域)

## 1. 背景与问题

未锁线期(r1-r4 主窗)金→板面战力的转换出口在册而未达:垫底级消费位(11 号稿 §7.3)原生触发核只辖「全店无链内候选」,与「板面空」正交;sim 实测门槛死区(金 40-49 整轮零动作)与冷启动囤金薄板(开局连轮空转)同根——板空槽现时贡献恒为零,持币无息账罚则覆盖的金位段存在结构性空转。病灶证据帧族 = P1 假帧(g≈22-52 含病灶旗舰金 47;g>52 溢余段经实测同样 L=0,判据自然覆盖)。

## 2. 决策(结构层,无开关)

商店线垫底级消费位(出口③同位,物理位次在 M6 之后、EV/R1 之前)增补第五触发源 T5,判据全为注册表派生量,零 hp/胜率/掉血先验/板面评分消费——不在 00_framework §3 硬闸门辖域,不设开关(回滚 = revert):

触发核七条件(逐笔发射 ⇔ 全合取):

1. 未锁线(单一源锚 = `cw_intention.locked_buy_membership` 返回 None);
2. P1(g,1) 假 = `loss_exact(gold,1,R_全局,Ī,cap_resolved) == 0` 现算(判据走现算,不按帧集清单;cap=0 买断制局 L≡0 ⇒ 全帧 P1 假,方向安全);Ī 消费 streak_pre=0 恒定近似(与 R1 段同口径,收入低估 ⇒ L 偏大 ⇒ 发射收窄,方向保守);
3. vacancy ≥ 1 且 vacancy > 当前可部署 bench 件数(假想部署预检的结构前置:买后须仍有空槽可落);
4. 部署可行性预检通过(单一源 = `can_deploy_single`,禁第二套围栏语义;查询不可得 fail 向);
5. 候选资格 C2 = 1★ ∧ 与目标线零重叠 ∧ 全额可退出口开放(`refund_full_star_ok`);
6. 金 ≥ 卡价;
7. 金 − 卡价 ≥ s_reserve(P56 可变现息线下界,守息线不破)。

cost-1 收窄 = 有意辖域:候选限 1 费(注册表事实 lv1-3 全店 cost-1);已知漏触发形态 = 店内仅 2/3 费零重叠垫件的帧,无病灶证据支撑,禁自行扩域。

部署腿不占发射位:单动作契约下买入落 bench,垫件上板由部署侧残余补部署既有语义承接(空 cap 槽任意合法单位 ΔEV≥0)。

## 3. 五触发源与级内序

垫底级消费位触发源全集五支:T1 原生(全店无候选)/ T2 出口③ Φ_stall(锁线)/ T3 必花域 L2(锁线)/ T4 危机带 (b)2(锁线后,挂账)/ **T5 本件(未锁线)**。T5 与 T4 辖域不相交(未锁 vs 锁后),锁线交接时 T5 出辖、T4 为接盘源之一。

级内序(同帧单次消费):降级 1(羁绊填充,在册)→ 降级 2 止血变体(T5,本件)→ 降级 2 囤形态(在册,回退位)。梯宿主 = 11 号稿 §7.3 owner;同帧双真单次消费由物理位次保证(囤臂 gold>g* 现行序先行)。锁线布尔边缘双开形态(locked_comp 非空而采购集解析为空的注册表脏态):出口③与 T5 同帧双开,出口③物理先行、先到先发射,T5 仅承接其未消费帧。

## 4. 正当性论证与先例辖域

P1 假 ⇒ 否决域合取 D=P1∧P2∧P3 恒假 ⇒ 该帧族整体出否决域,无需 E_rev、无需 V_deploy、无需 P2 分析。止血买的正当性由三结构量的支配论证独立承载:板空槽现时贡献恒为零;买入使板面占用集合严格扩、无减向通道(羁绊贡献非负、1★ 全额退金可逆、P1 假 ⇒ 息账零损)⇒ 弱占优于持币。ADR-0288 仅作「有比没有强」接受形态的在册先例——其凑档通道硬条件(凑 2 档羁绊贡献)与 T5 的零重叠资格不重合,零重叠件的正当性不依赖 0288。

锚帧数值(loss_exact 实测,cap=5/Ī=net_income(2,0)=5/R=13 病灶窗代表值):g=47 ⇒ L=0(开火,结构层发射);g=23 ⇒ L=1(熄火,落行为层挂起显影)。判据以现算为准,帧集清单仅为验算展示,禁据表外推(Ī/R 网格外帧有翻真形态)。

## 5. 分键族(t3 族)

t3_available / t3_buy / t3_no_candidate(店无 cost-1 垫件,有意收窄帧归因显影)/ t3_fenced(+kernel 五拒因动态后缀透传)/ t3_precheck_bench_full / **t3_precheck_no_vacancy**(vacancy ≤ 可部署 bench 件数,与 bench 满拆键,两因判读可辨——落地审观察④)/ t3_precheck_unavailable / t3_unaffordable / t3_below_reserve / t3_p1_true_blocked(P1 真帧行为层挂起显影)。

held 闭环归并申报(落地审阻-1):不设独立 t3_held_postbuy 键——T5 垫件买入走出口③同款 N3 登记(`cw4_fuel_filler_stall_buys` 单一载体),部署侧 held 显影并入 `fuel_filler_stall_held_postbuy` 口径;两触发源同垫件语义,禁第二登记集。t3_calib_blocked 归行为层授权批(未实施)。

## 6. Considered Options

- **A(采纳)纯结构判据限 P1 假帧族**:零战力量、不在硬闸门辖域、无开关可实施——四轮对抗收敛的诚实落点。
- B 无条件止血(不判 P1):拒绝——P1 真帧买入落否决域,需 V_deploy 类构造(掉血先验×板面增量),属 00 §3 硬闸门辖域。
- C 行为层随批落码(V_deploy 标定):拒绝——V_deploy 属用户逐项授权前置(见 §7 挂账),禁自裁。
- D 席位拒单键合并(落地审前实现):拒绝——bench 满与 vacancy 不足两因判读不可辨,拆键归因。
- E 部署口扩 t3 分键(阻-1 备选):拒绝——出口③ N3 名集已是垫件 held 显影的单一载体,T5 并入即闭环,第二登记集/第二键为双源。

## 7. 挂账条目

1. **行为层挂起**:P1 真帧止血(V_deploy 路径)候用户逐项授权(00 §3 硬闸门,授权申报独立呈报)+ V_deploy 显式标定;期限未决 = 退役关 + ADR,结构层不受影响。
2. p46 豁免面辖域扩展候选(E_rev V 侧扩「部署止血期望价值」支;「空部署槽语境 P2 兑现通道扩『板面战力存量严格增』支」)——分别立 ADR + p46 owner 对账,裁决前按未证假设对待。
3. 11 号稿 §7.3 降级 2 囤形态的 p46×P41 张力对账——归该号稿 owner 下轮策略批。
4. **效果验证前置**:同池改前基线须在独立工作树 checkout 落码前 commit 补拍(当前工作树含本批未提交改动,在飞 sim 批非干净基线);基线补拍批交付并同指纹同 seed 成对重跑前,禁出本通道「改善/不劣」类效果断言(对照锚 = sim60 门槛死区 / sim62 死区前移与换信道存活基线)。
