## 2. 补强通道接线重估（P26/P40）

### 2.1 原挂账理由

1. **P26 数值授权挂账（主因）**：P26 v2 = P1 硬节点备战支出 EV 门，EV = Δp_prep·G_loss + Δstreak·S_streak − C − I；**双挂账 Δp_prep 条件表 + L_node 分位口径均未采**，G_loss = λ_death 销毁敞口（P51 §F.3/P48 同源）未回填——索引明载「λ_death 回填前仅结构背书不作数值授权」。史实：P26_VALIDATION 曾判其量纲断裂（血量直入金账），v2 重推已按纯金流闭合修复，故**挂账性质 = 数值授权挂账，非结构缺陷挂账**。
2. **P40 备战语境无特批位**：P40 刷新门对硬节点语境只有变体③「节点语境 = 参数替换，骨架不分叉」；01 §7 待证钩子表对 P26 的默认行为明文 = 「备战支出走常规门，不加码不特批」。
3. **hp 红线**：01 公理 3 + 00 §3——硬节点「更难 ⇒ 需更强」属节点类型前置的阵容管理（[39]），禁以 hp 直读触发补强；14 号稿 Z1 裁定后全篇 hp 直读件统一「在册三件 + 逐项确认」单一标准。

### 2.2 现架构（14 号稿 v4.2.2 + 17 号稿 + ADR-0516）下的逐面重估

| 支出面 | 现架构承载件 | 补强语境还需 P26 特批吗 |
|---|---|---|
| 刷新 | R1 形式二可负担性门（ADR-0516）：`c_eff·E(D\|L*) + Σ卡费 + L ≤ g − g*`；硬节点语境经 P40 变体③作查表键参数替换进入 E/卡费/L | **不需要**。V̄ 链退役后 R1 判据全为游戏定义量，「备战期搜牌动机」已被可负担性门内生化；P26 若作刷新加码 = 在 R1 之上特批放宽，无授权文号，违 01 §7 默认行为 |
| 买（卡牌） | M2/臂①/M2b 义务通道（14 号稿 §3）+ P46 EV 买 + 17 号稿出口③垫件填板 | **不需要**。定向补强买（缺档件/羁绊件）与义务面/ EV 面对象集重合；P26 成本围栏（C = 2-4 金，P20 成本层）无独立动作对象可授权 |
| 装备 | `wear_release` ③支（已落，结构判据零金支出） | **不需要**。这是补强语境在现行架构下的合法落点，且已接线 |
| 危局帧 | P36-a 危机直通（D≠∅）+ (b)2 垫底级（Z1 挂空） | **禁接**。hp 族通道挂账态，P26 接线不得借危局通道复活（14 号稿 §5.4 红线段单一标准） |
| 升级 | arm0/arm1（M3 双臂）+ 17 号稿出口①挂账 | **唯一真缺口**，见 §2.3 |

### 2.3 结论一：独立补强发射臂不接线；P26 辖域收缩重挂

1. **原挂账理由在数值面成立**（Δp_prep/L_node/λ_death 三件均未采），且**结构面已被五类既有臂分割覆盖**（§2.2 表）——「硬节点备战特批」作为独立发射臂在现架构下**没有剩余的合法动作对象**，接线 = 制造双源加码，违 01 §7 与零调参门。维持 D-D ①② 的「结构门 + 观察级」现态**判定正确**。
2. **P26 的真实剩余辖域 = 17 号稿出口①的合法化路线**：17 号稿 §2.1（Φ_stall 帧升级挂账）的未解缺口①「完成提前量折金」明文只有两条合法化路线——支配性消去 ∨ **P26 族 λ 纯金流（卡点同 P26，Δp_prep 待标定）**。即 P26 的价值不在「备战帧多买多刷」，而在**为升级使零档集合（该级刷新概率为零的缺口成员集）变非空这件事折金**：Δλ_death（缺口可追 ⇒ 战力桶跃迁）×（存量金 g + 未来纯金流 Φ）的敞口差，供给 17 号稿出口①命题的 ΔE_trunc 折金项。**接线位唯一候选 = 该命题内，不立独立发射臂。**
3. **接线判据（未来若接线；零新自由参数）**：
   - 前置（全部在册挂账，无新拍定值）：P26 证明闭合 = Δp_prep 条件表实采 + L_node 分位口径实采 + λ_death 回填（P51 采集 #3）；
   - 消费形式三条硬约束（P51 验证结论/P26 v2 口径）：①区间敞口比较、禁边际引用；②L_node 只辖触发面水位比较、不入金账；③hp 不入任何账与自变量；
   - 谓词面复用 `HARD_NODE_TYPES` 节点查表键（已存在，零新参数）；**禁止**把「硬节点」升格为任何门的放宽项——它只允许作为 P26 命题的触发面语境键。
4. **观察级计数位保留**：`shop_hard_node_gate_open` 计数继续作标定前置观测（硬节点帧富金可达性分布），挂账期零行为差——与 14 号稿 §10 附注一致，登记为 §2.3 的 as-built 确认而非待修项。

## 3. P51 生存折现消费位重立

### 3.1 定义与原位

生存折现 = P51 等待代价引理的两通道：W_flow（小项，0-0.5 金/轮）与 **W_floor = λ_death（板面战力桶×节点类型，剩余轮数近似视界）×（存量金 g + 未来基础/息流 Φ）− 当轮息票**。原位（v4.2.2 之前的设计意图）共四个消费位：

| 原消费位 | 现态 |
|---|---|
| P41 卖出主不等式 `V_power` 项 | 仍挂「待 P51 W 接管的缺省项」（现值 = 0，fail-closed 缺省）——**未变** |
| P48 统一囤钱判据 `ΔW_trunc(a)` 项 | **已并入**（花 a ⇔ V_a > ρ·x/Ī + L + ΔW_trunc；三账不同源防双计） |
| P39 臂二 `floor_eff`（λ_death 桶×节点 50/0 二值投影，零拟合常数） | **已并入且落码**——现行 λ 消费的唯一落码先例 |
| P35 持有侧 W_floor 接口（P35_VALIDATION 门①1.3） | 挂账（λ_death>0 段「不升级 = 无风险吃息」口径须并入或声明辖域排除） |

### 3.2 判定：未被取代，被拆分并入；独立消费位现态 = 全量 fail-closed

P51 生存折现**没有被某个新件取代**，而是被拆成各判据的加性项（P48 ΔW_trunc / P41 V_power / P39 floor_eff）后，作为**独立消费位**失去了载体——其连续模型输入（λ_death 生成式，P51 采集 #3）未标定，故所有原位均处 fail-closed/挂账态。这是诚实态，不是缺陷：01 §6 三要素（挂账登记 + CI 方向不变 + owner/期限）覆盖在案。

### 3.3 v4.2.2 + 17 号稿后的剩余辖域（重立候选，按优先序）

1. **17 号稿出口①截断账折金项（唯一新增候选位）**：出口①（Φ_stall 帧升级）命题草案的未解缺口①「完成提前量折金」——合法化路线二 = P26 族 λ 纯金流。重立形态 = `Δλ_death(升级 ⇒ 零档集合非空 ⇒ 缺口成员可追) × (g + Φ)` 的区间敞口差。与 §2.3-2 是同一枚硬币的两面：**P26 供语境触发面，P51 供折现形态**，二者在出口①命题内合流。
2. **04 号稿 §2 收益侧过渡口径重锚债**：P35_VALIDATION:116 挂账「L_c 的 hp→金 1:1 直换须经 λ_death 重锚或明示永久过渡」——重锚的目标形态正是 P51 纯金流敞口（λ 概率侧进、金量纲出、零换算链）。本项 owner = 04 号稿 §7 #4 确认通道，不另立。
3. **P41 V_power 接管（卖出面，在册待标定）**：形态 = 卖出候选件的 λ_death 敞口差（λ_death 概率侧，禁 hp_to_gold）；标定链同采集 #3。

### 3.4 重立判据与形式（零新自由参数）

- **输入面**：λ_death 取 PL 键分层表带 CI；决策时可观测量 = 分层胜率 × 槽序表剩余战斗数（P51 Λ.1 生成式）；hp 不入自变量；板面/bench 维不入键；连胜 = 0 底线（超额收益隔离，01 公理 2）。
- **消费形态**：区间敞口比较、禁边际引用（P51 验证结论）；每个【拟】量过 01 §6 三要素（挂账登记/CI 两端扫描方向不变/owner + 期限，超一个对局周期未决 = 回炉）。
- **合法先行起步形态 = 二值投影版**：λ>0/λ≈0 两分支（零拟合常数），先例 = P39 floor_eff 的 50/0 投影与 P52 D_ε 安全域的 λ̄ CI 上界消费；连续版待采集 #3 到位后替换分层表（01 §5 λ 行在册路径）。二值版足以承载 §3.3-1 的方向判（缺口可追 ⇒ λ 支路非零），连续版才承载幅度。
- **禁区三条**：①禁作收益乘法折扣因子复活 P28 期权存活贴现的旧通道形态（胜率/战力建模禁域，宪法第 1 条）；②禁 hp 直读触发（00 §3 红线；Z1 单一标准）；③禁入 04 §7 hp 授权对账表之外的新 hp 面——生存折现的输入是 λ（概率侧），不是血量。

## 5. 验证锚与开放问题

- **验证锚（观察级，零行为差）**：`shop_hard_node_gate_open` 计数随批披露（硬节点帧 ∧ 金 ≥ g* 的可达性分布）——它是 P26 标定批（Δp_prep/L_node 实采）的前置样本面，挂账期禁据以调参。
- **开放问题**：①P26 数值三件（Δp_prep 条件表/L_node 分位口径/λ_death 回填）与 P51 采集 #3 同链，标定批排期合并申报（禁两批各采一遍同源语料）；②17 号稿出口① owner 期限（下轮策略批队列）内，若「支配性消去」路线先闭合，则本篇 §2.3-2/§3.3-1 的 λ 路线作废，P26 剩余辖域清空为「仅观察级」——该分支无需回炉本篇（结论形态已是条件式）；③二值投影版若先于连续版被出口①命题消费，须在命题单篇内声明「方向判授权、幅度不授权」，防二值结果被读成量级。

## 6. 两件结论（各三行）

**结论一（补强通道接线）**：原挂账理由（P26 数值三件未采 + P40 无特批位 + hp 红线）在现架构下仍然成立，且结构面已被 R1 形式二/义务买/装备三态门/危局臂五路分割，独立补强发射臂没有剩余合法动作对象——D-D 维持「结构门 + 观察级计数」现态是正确落点，不接线。
P26 的唯一合法接线位收缩为 17 号稿出口①「完成提前量折金」的合法化路线二（P26 族 λ 纯金流），消费形态 = 区间敞口比较、L_node 只辖触发面水位、禁边际引用。
接线前置 = Δp_prep 条件表 + L_node 分位口径实采 + λ_death 回填（与 P51 采集 #3 同链合并申报），零新自由参数。

**结论二（P51 生存折现消费位重立）**：生存折现未被取代而是被拆分并入（P48 ΔW_trunc / P41 V_power / P39 floor_eff），独立消费位现态 = 全量 fail-closed 挂账（卡点 = λ_death 生成式，P51 采集 #3）。
剩余辖域三项按优先序：17 号稿出口①截断账折金项（Δλ_death×(g+Φ)，与 P26 合流）＞ 04 号稿收益侧 hp→金过渡口径的 λ 重锚债（owner = 04 §7 #4）＞ P41 V_power 接管。
重立形式 = 二值投影版先行（λ>0/λ≈0 分支，零拟合常数，先例 P39 floor_eff/P52 D_ε），连续版待采集 #3；禁区 = 收益乘法贴现旧通道、hp 直读触发、04 §7 表外新 hp 面。
