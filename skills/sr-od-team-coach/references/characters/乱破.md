# 乱破（虚数·智识·5星）

> 按 V4.7 期撰写。结印强化普攻+充能转击破伤害的智识击破位。

## 一、命途属性与技能说明

**命途**：智识；**属性**：虚数

| 技能 | 说明 |
|---|---|
| 普攻 | 单体虚数伤 |
| 战技 | AoE 60%攻击 |
| 终结技【结印】 | **消耗能量140**；+1额外回合+3【彩墨】+击破效率50%+击破特攻10%~34%；期间普攻强化、无法战技/终结技；强化普攻耗1彩墨 |
| 天赋 | 敌方弱点被击破→+1充能（max10）；忍具第3段消耗所有充能：30%虚数击破伤害+每点25%+无视弱点削韧 |
| 秘技 | —（以官方文本为准） |
| 额外能力 | **C1：结印强化普攻打已击破目标→削韧转60%超击破**；**B1：攻击>2400 每100点→敌方受击破伤害+1%（上限8%）** |

**资源与循环**：140能量→充能有效。
