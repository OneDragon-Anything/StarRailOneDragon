# ADR-0491: hp 真值来源语义(真读/结算/规则)与 r1 备战行规则标注

## 状态
accepted (2026-08-30)

## 背景
ADR-0282 建 hp 三层读链时规定:备战屏 HP 读不到 → 沿用
`last_hp_real`,开局全无真值才兜底 100,以 `hp_readable/hp_trusted`
两位保真。该兜底隐含前提「r1(位面1轮次1)开局恒满血 100」。两个后续
事实推翻了前提:

1. **r1 血量不恒为 100**:开局血量随当局难度/词缀变(实证:56 局档案
   P1 r1 结算屏真值 53 局 82、3 局 62;ADR-0490 进一步实证位面2 r1
   画面血量可见却因读链门条件从未 OCR)。因此 r1 帧的 100+两位 False
   是兜底毒化候选值,不是「诚实标注的未知」。
2. **档案回看需可追溯语义**:存量档案里 16 条 r1 备战行(8 局,均为
   2026-08-30)带 hp=100+readable/trusted=False,判读侧无法区分
   「兜底毒化」与「真实满血」,需要一条持久语义锚。

## 决策
hp 真值**三来源语义**,可信度等同真读:

| 来源 | 语义 | 写入点 |
|---|---|---|
| 真读 | OCR 备战 HP 区读数(`read_hp_opt` 两级放大管线) | shop.py 买前读/`read_game_state` |
| 结算 | 结算屏「小队生命值」经新鲜度门(ADR-0431)写入 | shop.py 结算真值臂 |
| 规则 | r1 备战帧的游戏规则固定值,**仅用于历史档案修数标注**(值保持档案原样,不回填新值) | W807-B 修数脚本(archive 旁路,非运行时) |

配套裁定(用户裁决,2026-08-30):

1. **运行时前向口径**:r1 备战帧以画面读数值为准;miss=时序抖动重试
   (`shop._r1_retry_read_hp`,至多 2 次);穷尽 miss=诚实未知
   (recorder 对 r1 且两位皆 False 的帧写 `trace.hp=None`),**禁止**
   落 100 兜底——ADR-0282 的「开局兜底 100」在 r1 语境由本 ADR 取代
   (r2+ 沿用/结算语义不变,兜底值仍作对账层占位但永不进决策语料)。
2. **历史档案回向修数**(replay/matches 56 局):r1 备战行
   hp=100+两位 False 者共 16 条(8 局)均无图可依(buy_expect webp/
   帧图证据缺),按「无图不猜」保持 hp=100,加 additive 标注字段
   `hp_repair={source:'rule', note:'规则修正:r1 固定值,来源=规则',
   repaired_at, evidence:'none', old_bits}`;index.jsonl 同步加
   `r1_hp_rule_annotated` 计数。仅动 r1 备战行,其余轮次零触碰。
3. **结构零破坏**:修数只加键不改键,消费方(`--match` 切片物化/
   query_*)按 `.get` 读已知键,additive 字段透明。

## Considered Options
- **A(采纳)三来源语义+档案旁路标注**:来源语义一次定清,存量档案
  不改值只加锚,判读侧可区分兜底毒化;运行时诚实未知不产新毒化。
- B(拒)运行时对 r1 miss 直接赋「规则值 100」并置两位 True:前提已
  被证伪(r1 不恒 100),会把错误值洗成可信值(W807 前批
  39e6d9ba 即此形态,已由 dfac2c6e 作废重做)。
- C(拒)无图候选行 hp 置 None:改写存量档案值破坏「档案=当时事实
  存证」性质,且违反用户裁定(无图保持原值+标注)。
- D(拒)只改运行时不动档案:16 条候选行继续以「可信度未知」形态
  混在语料里,判读侧每局重复人工甄别。

## 后果
- r1 备战行判读口径:hp=100+`hp_repair.source='rule'`=规则固定值
  (可信);无标注的 100+两位 False(若有)=兜底毒化候选;None=
  诚实未知;其余按 hp_source/hp_trusted 既有语义。
- 运行时 r1 miss 极端情形下血线决策 fail-closed 拒评估(与 ADR-0428
  取向一致);ADR-0490 修复全量路径 hp 真读后,该情形只剩 HP 区物理
  不可见帧。
- 修数仅覆盖 56 局既有档案;水位线后新装配局不再产 r1 兜底行
  (recorder None 口径),无需持续回填。
- 验证:定向 `test_cw_hp_trust_defense.py` 29 例(组7=画面读值口径
  6 锁)+ cw_quick 全绿;修数复扫 0 残留候选、56 档案结构断言全过
  (脚本与清单:`.debug/temp/currency_war/w807_r1_hp_rule/`)。
