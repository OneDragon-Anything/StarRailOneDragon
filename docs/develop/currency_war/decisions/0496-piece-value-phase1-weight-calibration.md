# ADR-0496 · 件价值 Phase 1 权重标定(w_activation=1.0 / w_retention=0.0 定谳;B 分量无可行标定值,位置成本硬门挂账)

> **引用勘误(2026-09-04 ADR 存量 review)**:`.debug/` 归档 → 本目录(decisions/)同名 ADR;`prereg/` → `docs/develop/currency_war/proofs/`(math_proofs 索引)。文内出现处按此对照读取。

## 背景与问题

件价值模型 Phase 1(设计单一源 `docs/develop/currency_war/prereg/w831_piece_value_design/REPORT.md` v2;买侧试点 A/B 判据 `docs/develop/currency_war/prereg/w836_piece_value_p1/PREREG.md`)的首次 A/B(`.debug/temp/currency_war/w846_piece_value_p1_ab/REPORT.md`)在单位权重(w_activation=1.0 ∧ w_retention=1.0,标定批未偿时的判前登记点位)下判定 B:**机制工作但剂量不足**——主门病灶②显著下降但效应量 5.5% ≪ 判前下界 30%,护栏 G4 满栏帧差 +11.03pp(cap ≤+2pp)远超红线。PREREG §2 自带分支:回标定批,不开臂。本 ADR 记录标定批(`.debug/temp/currency_war/w852_weight_calibration/REPORT.md`)的方法、结果与定谳。

## 标定方法(两路)

1. **数学先行(w_activation)**:分量 A 的原值 = `engine_jump_gold(e)`,即 e→e+1 激活跳变的金值(ADR-0352 量纲);P20 已证 e0→1 次战边际战力为散件 1★→2★ 的 2.6-2.9 倍、辖域(e<2)内排序首位。权重取 1.0 保持「分量值=命题值」映射,无自由参数——数学先行路线直接给出,无需数据标定。
2. **数据标定(w_retention)**:W846 双臂数据分量归因(判前冻结归因规则)→ 扫参(dev 窗 seeds 3_100_000..3_100_199,n=200/臂,w_retention∈{0.2,0.4,0.7,1.0},w_activation 固定 1.0)→ 分量隔离扫参((1.0,0)/(0,0.2)/(1.0,0.05)/(0,0) 四点)→ 候选点 dev 窗病灶判读 → 主窗 n=1000 确认。

## 证据链(标定批关键读数)

- **W846 归因**:w=1.0 时新增买入 14,210 笔中,A(激活)直接归因仅 41 笔;B(留存)3,129 笔,其中 56.7% 为 ≤2 费件(P1:低费再遇 7-15 轮,囤积期权近零)、35% 破息;B 买入的 41% 发生在 bench 占用 7-8 的最后两空位。剂量根因 = B 分量,不在 A。
- **扫参不敏感**:w_retention 0.2→1.0 全程 G4 ≈+10pp、病灶②效应 ≤6.6%——权重量级不是可行标定维度。
- **分量隔离(定谳证据)**:(0,0.2) → G4 +10.33pp;**w_retention=0.05 仍 G4 +10.06pp**——B 的剂量响应是「全有全无」离散型:买入翻转发生在近零分候选密集带,任何非零加项都开火。(1.0,0) → G4 −0.50pp(A 单独无剂量病灶);(0,0) → 200/200 局序列与 off 逐位一致(哨兵,同时交叉复核跨进程确定性)。
- **主窗确认(n=1000,点位 1.0/0.0)**:见 REPORT §重跑对照两格表。

## 决策

1. `piece_value_w_activation = 1.0` 落码为标定值(出处=P20+ADR-0352,注释带推导);
2. `piece_value_w_retention = 0.0` 为**标定定谳值(结论,非占位)**:现行辖域条件下无可行标定值——权重量级失效,根因是 B 辖域缺位置成本约束,即 W846 G4 满栏红读出的「E 位置成本分量缺位」信号;
3. **不开臂**(PREREG 主门在 B=0 下病灶②必无效应),伞旗标保持默认关;开臂前置改为:B 辖域位置成本约束(硬门批)落地后按同格 PREREG 重验。

## Considered Options(B 分量的处置)

- **(采纳)权重保持 0.0 + 硬门挂账**:0.0 是当前辖域下唯一两格可行值;治本层是给 B 辖域补位置成本约束。
- **(否决)取小权重(如 0.05-0.2)折中**:隔离扫参证明无剂量改善(G4 +10pp 不随权重下降),纯 symptom 调参。
- **(评估后挂账)「买前 bench 容量预检」硬门**:数据方向支持——B 买入 22.6% 发生在占用=8 的最后空位,W846 on 臂病灶②合格事件被满栏拒绝 4,143 次;预检(reserve≥1,只收紧 B 辖域门、不进评分,与 Phase 1「E 禁进评分」边界相容)可直接消掉满栏帧。挂账原因:①属消费面逻辑改动,超出标定批文件面(registry 权重字段+测试仓);②reserve 值的数学推导缺位(P29 持位成本 H 未标定)。后继批需带文件面授权,建议含 reserve sim 扫描与 P29 H 卡点推进,own A/B。
- **(否决)删码留 ADR(生命周期第 4 态)**:机制侧正信号仍在(W846:病灶②排序效应存在、G7 无来源不明侵蚀、M4 非劣化),剂量根因已定位到结构缺位而非概念错误,不满足删码判据。

## Consequences

- off 臂零漂移不受影响(伞旗标默认关;锁 4 已锁「权重非零伞关仍零漂移」)。
- 锁组:test_cw_piece_value 锁 0 按「锁的存在性纪律」重推语义(旧「占位缺省 0」语义被标定定谳取代);test_cw_adr0293_calibration 回显锁同步。
- 开臂判据挂账更新:PREREG 同格重验的前置从「权重标定批」改为「B 辖域位置成本约束批」。
