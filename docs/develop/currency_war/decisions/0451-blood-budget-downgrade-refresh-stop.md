# ADR-0451: 血预算停手·第二波(P1 末窗支出降格 + 搜索型刷新停付)进决策层(W532)

## 背景

设计件 12(`docs/develop/currency_war/strategy/12_blood_budget_semantics.md`)
§4.2 先行清单的剩余两项(β 无关部分;第一波 P2 停升级/P1-b 停追级见
ADR-0448):①P1-a 末窗支出降格——P1 末窗血预算不足时,承接门定向投资
授权的支出结构降格(战力投资 → 减损保血);②P1-c 锁线前移 + §3.2 停刷新
结构语义——血预算不足局不付搜索型刷新费,急救型保留。证据基座 = W516
排除证据(HG5/IF30:β 弱通道下战力投资换不回 15-25 血/败)与 [31]④
刷新金合法用途硬约束(只有目标件/保血急救两项目标)。

## 决策

### 触发面与常量(单一源 registry)

- `p1_exit_blood_target = 60`(设计 §6 P1_EXIT_BLOOD_TARGET;语义 =
  **期望预算线**——w*=1−h/88=0.32 可达的最低进场线,充分不必要、
  非存活保证,W524 对抗审计后「分界」表述已废);
- `p1_exit_downgrade_enabled`(P1-a 总开关)/`blood_budget_refresh_stop_enabled`
  (P1-c/停刷新总开关)——默认 True 非悬置开关(W516 方向性排除证据不依赖
  β 量级;[31]④ 是硬约束归位),False = A/B 对照臂注入面,两臂独立可注入。
- 触发谓词 `discipline.p1_exit_blood_short`:plane=1 ∧ r ≥
  `handoff_gate_min_round`(末窗语境单一源)∧ hp < 60;纯辖域不带开关。

### P1-a 末窗支出降格:授权豁免通道降格(非覆盖态)

降格只停**承接门定向投资授权的豁免通道**,减损型动作族不动(动作族复用
11 号件 blood_protect 梯度既有语义,不新增动作)。接线四面:

1. `candidates._buy_tag` gap>0 定向 'copy' 臂(星级投资授权)——血预算
   不足帧不再经 gap 豁免生成定向副本候选;
2. `candidates._copy_swap_blocked` C 臂(副本换卡豁免)——同帧不豁免;
3. `arbiter` 非正分门 'copy' 豁免(评分零维补通道)——同帧不豁免;
4. `arbiter.interest_rule` 买侧承接缺口项(`handoff_ev_gap_bonus×gap`,
   破息投资授权的放宽面)——同帧不加成。

降格后自然涌现的支出 = bond_fallback([11] 同息档羁绊档填充)、pair、
plugin(上场即转化)、deploy——即设计 §2.3-P1-a 的「减损保血」构成,
无需新增动作语义。

### P1-c/停刷新结构:refresh 收尾授权前置拒付

`discipline.blood_budget_refresh_blocked`(纯函数)+ arbiter refresh 收尾
块(单一收口)前置拒付:血预算不足帧(急救豁免/ALL IN 豁免在谓词内)
所有刷新授权面(V_D 正分搜索/M-A 定向/release 泄息)一律停付,拒付计数
`session.v3_blood_budget_refresh_rejects` → sim 账本逐轮差分
`sim.blood_budget_refresh_rejects` + 批聚合(披露模式对齐第一波)。

**刷新分型**(结构语义,设计 §3.2):

- **搜索型停付**:为找件/挑线付刷新费的授权通道(上列三类)在
  p1_exit_blood_short 帧停付;
- **急救型保留**:应急带(hp≤`emergency_hp`)内刷新授权语义 = 搜牌
  补板当轮转化变现(filters emergency_tags 既有归类)——「血线内的
  当轮转化豁免」由该豁免面承载,谓词显式放行;
- **数值停刷新线不落**(明说需标定):收益项 = Δp×β 不可算,挂 β 开臂
  判据(设计 §4.1);P2 辖域在标定前为空——P2 血危机带(应急带)已在
  急救豁免面,非应急 P2 帧的血预算判据无数值,本批只落结构不落数值。

### 接缝(设计 §5 逐条)

- 息线×血线 = 独立谓词 AND,血线胜:release 泄息刷新在血预算不足帧同停
  (§5.2 第一行,M-A 预算不消耗);
- 授权通道前置拒付过滤(与第一波 level_cap_rejects/blood_budget_stop
  同型),**非第五覆盖态**:discipline 覆盖序不动,emergency 态内降格
  语义同样在(应急带内定向授权豁免通道被 `p1_directed_downgrade_active`
  拦——应急梯度给「怎么花」,降格给「授权豁免不再开」;应急带内刷新
  走急救豁免不受停刷新拦);
- 承接门授权不豁免停手(§5.3):gap 大只说明板面缺,血预算撑不到收益兑现;
- `plane_last_battle` ALL IN 窗停手让位(两谓词同款豁免);
- 11 号件应急梯度不动:预算线触发早、动作是授权结构降格,tier0 触发晚、
  动作是应急支出梯度,两线不互代。

## Considered Options

1. **停手写成第五覆盖态** — 拒:设计 §5.3 明文排除;拒付过滤已覆盖全部
   授权面,覆盖态反而扰动 emergency 梯度。
2. **降格拦全部买候选(含目标件)** — 拒:超设计辖域;设计辖域 = 承接门
   **定向投资授权**(授权豁免通道),目标件买入本就走息线 EV 总账,停它
   属另一笔账(花金义务对偶面,设计 §3.3 声明另批同缝设计)。
3. **刷新停付按「店内有可上件」逐帧分型搜索/急救** — 拒:刷新决策帧无法
   从店内容量可信分型(刷后才见新店);分型挂在授权通道上与既有授权面
   一一对应,可判读可验锁。
4. **P2 结构停刷新用停升级线 21 当锚** — 拒:21 ⊂ 应急带(25),该域已在
   急救豁免面,落了也是死代码;诚实选择 = 数值线挂 β 门(设计 §3.2
   明文「需标定」),结构面只落 P1 辖域 + 分型豁免表。
5. **「尚未锁定」条件照设计字面实现** — 拒(收窄未实现,如实记):锁线
   状态不是刷新授权的既有输入;血预算不足时已锁线的目标件搜索同样兑不回
   血(W516 同链);如需收窄留标定批复核。
