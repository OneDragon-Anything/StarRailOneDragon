## ② 扩展设计(P2 形态修订,待确认后实施)

### 修订 1:form 伴随条件的 P2 假绿修正(治触发面空洞,改判据式一处)

`form 未成型` 谓词从 `not form_ok` 扩为:

```
form_weak = (not form_ok)                                    # 假红:match4 形态
          or (form_ok ∧ 意向核心到手副本数 < STAGNATE_CORE_MIN_COPIES)   # 假绿:W957 支B 形态
```

- 意向核心 = `intention_core(locked_comp)`(既有单一源);到手副本数 = bench/deployed 中该角色 star 之和(星级当量,与 `_asset_thickness` 同口径)。
- 新 registry 常量 `stagnate_core_min_copies`(默认 2,设计推断初值,sim 校准不授权终值)。
- 语义:form 绿只说明「阵容档位成型」,核心没到 2★ 当量 = 锁线战力没兑现 = 假绿计入未成型。三合取其余两项(hp 净降 + gap 无收敛)不变——支B 形态下 gap=0 平、hp 降、假绿 → **触发面打开**;金筹措期误判防护不变(hp 门)。
- 防振荡/冷却/salvage/字段契约全部不动(纯判据输入修正,状态机与下游零改动)。
