## 7. 修正建议(均非改判级;证明文件本验证未改,禁改)

1. **帧数口径对账**(证据表述瑕疵):索引行与证明 §4.3 称「68 帧零残差」,本次重跑同一 run_id 得 79 帧、17 个非零转移、零残差——疑为证明写作时 decisions.jsonl 尚未追齐或口径为当时子集。建议:在证明 §4.3 补一句帧数口径(如「截至写作时 68 帧;全量 79 帧复跑结论不变」)或直接更新为全量复跑数字。结论不受影响。
2. **长线利好(环境 120)交互未入 §2.1 例外/强化表**:30 次付费刷新后刷价 1 金(`cw_invest_data.py:389`),仍是「消耗金币刷新」⟹ r_refresh = 2/1 = 2.00,刷新优势扩大——属强化域,建议补一行(补强非反例;与淘金客同持时是现实可出现组合)。
3. **买牌也给 XP 未提**:`engine_p1` 注释「与买牌同源」——买角色每次也 +4 XP,是比买断制更常触发的第三 XP 通道。不破两汇率比较(买牌有自身产出),但 §2.1「第三 XP 通道」仅列买断制,建议补一句买牌通道,防读者误以为 XP 只有刷/买两源。
4. **消费端两处与 P22 通式的偏差**(策略侧,非证明错,转策略面处理):
   - `refresh_invest_active()` 对 `free_refresh_per_node > 0`(加油站/搜打撤族)同样返回 True ⟹ 升级通道退役,但免费刷新策略**不给 XP**(xp_per_refresh=0),P22 定理不覆盖此情形——该臂的正当性需另有证据(免费刷新省金≠汇率占优),建议拆谓词或补论证。
   - 谓词未实现 P22 §5.2 唯一回退条件(`xp_click_cost() < 4` 商业间谍并持时恢复买经验):淘金客+商业间谍同持时现行代码仍全退役买经验,与命题例外域相悖(并持概率低,影响小,但通式判据应按证明建议接入 `xp_click_cost()`)。
