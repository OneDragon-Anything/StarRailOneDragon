# W920 · R-B 统一设计:商店件定价(target 外件 + 线内囤牌)

> 根设计件,归并 W908 R-B(F1/F2/F3/13-4 四条候选)。读者=后续落码/标定批的干净智能体。
> 前置考证与证据强度见同目录 REPORT.md(F1 未证环定谳、F2 归并精度修正、W902 旁件约束)。
> 术语:线内=当前 target 配方体系成员;线外件=target 外商店件;贯穿件=跨阶段留存率高的通用件(Q1 留存率口径);压库=买走公共池某费用档的牌提高目标档浓度([34])。

## 0. 病灶陈述(统一)

评分/购买层对商店件没有一套与 target 标签解耦的稳定定价:线外好件(F1 卡芙卡、F3 千冶·刃)与线内囤牌核心(F2 姬子·启行)无价可依被拒买(F1 r4→r8 同卡价值随 target 标签从 0 跳正),线外随机插件(13-4 夜之半神件)却无据得 2.0 分照买。**同一判据面,两个失败方向**——单边修法(放宽或收紧)在对方侧各制造一次失败,故必须一件统一。

## 1. 设计总纲

**给每个商店件一个由已证命题支撑的价格,而不是给某类件开一扇单边门。**

定价 = 既有板面差分评分(base) + 外件期权加项(本设计新增,S1/S2/S3 三信号,可负) − 方向折扣(既有 off_lock κ 通道,不动) − 息成本(既有 int_emb/P13,P33 豁免类扩展,不动机制只扩豁免名单的结构来源)。

三个硬原则:

1. **不新立通道**:加项落在既有 `score_candidate` 的既有加项位(W803 `tp_gap` 同位,off_lock 降级之前,自动随 κ 比例折扣),生成层通道标签(candidates.py)不动。
2. **不复活加权模型**:三信号各自独立披露(`bd['rb_*']` 判读键),各自可被单独否决——piece_value 的死因(ADR-0497/W902:黑盒加权总分零疗效+54% 破息)不许以新形态回归。
3. **无拍死值**:所有权重/阈值默认关进 registry,标定走 sim A/B(§5);A/B 无正向 = 整件清理(策略开关生命周期第 4 态),不留悬置。

## 2. 每个设计决策的三件套(病灶证据/命题依据/标定路径)

### D1 判据面统一为「商店件定价」,范围含线内囤牌

- **病灶证据**:REPORT.md §1.5 总图——F1/F3(线外拒买)、13-4(线外照买)、F2(线内囤牌拒买)四条同面两向。
- **命题依据**:math_proofs 对照——[31] 羁绊降级梯队(user_playstyle,口述,方向)+P29(锁线态囤牌羁绊感知,待证明,结构不等式已证)本就是「件按层级定价」的命题化;统一判据面是该命题族的实现面。ADR-0482 权威序:口述给方向,数值以证明与实证为准。
- **标定路径**:无需标定(范围裁定)。

### D2 定价结构:加法期权项 + 既有折扣通道,不立独立外件通道

- **病灶证据**:F1 同卡 r4 拒/r8 买——行为随 target 标签裸翻,说明缺的是**与标签解耦的稳定加项**,不是缺一扇新门;13-4 的 2.0 分来自 plugin/line_opportunistic 通道的无据底分,说明修法是**修分值来源**而非加过滤器(过滤器是 D5 的锁线分支,不是常态机制)。
- **命题依据**:W802 realization chain(κ 比例折扣,「降级非禁绝」)已是该面的方向罚单一源(W789 定谳修法);W803 tp_gap 提供了「加项落在 off_lock 之前、随 κ 折扣」的成熟落位先例(ADR-0494)。P18(集合过滤不变式)提示纯过滤式修复会破坏既有门辖域语义——加法式优于过滤式。
- **标定路径**:结构决策无参数;行为漂移验证用 `cw_replay --diff` 首发点核对(开关关=零漂移)。

### D3 信号组(定价的三个正项来源)

**S1 激活信号(可激活钥匙件)**:买入后板面将凑成**新羁绊档**(某体系人数从档位下界−1 跨到下界,即 e0→1 或 e1→2)时,按 P20 激活边际给正项。

- **病灶证据**:F1 原报告称 r4 买卡芙卡「即凑 DOT2」——**被本批证伪**(档案亲查:板面无第二 DOT 件,REPORT.md §1.1)。S1 的条件化正是对此教训的结构化:激活项只在「本帧真凑成档」时开火,卡芙卡@r4 信号=0,由 S3 接手定价——修复 F1 类帧不再依赖复盘员的机制误判。
- **命题依据**:P20 已证(体系激活 e0→1 次战边际 > 散件升星,倍数带 2.6-2.9×;辖域严格限 e<2);P19(unit_bond_tags 计数语义,①③已证)提供凑档判定的计数基础。[31]③ 扩展定调(填充件不改变目标方向)保证 S1 对线外可激活件给价不违反方向纪律——激活≠换线。
- **标定路径**:触发条件 sim 可标(构造含凑档帧的 sim 批,验证开火率>0——新机制先验证它会开火,strategy-work §4);数值权重 P20 已给倍数带,sim A/B 内扫(不做实机精调,弹平判据按 strategy-work「参数精调用敏感度」)。

**S2 贯穿信号(通用贯穿件)**:按卡的跨阶段留存率(Q1 E→F 口径)字段化进注册表,留存率≥阈值的件在线外也持正价。

- **病灶证据**:F3 千冶·刃(51/52 帖在板、E→F 0.95)拒买;F2 姬子·启行(列车线 100% 固定成员、E→F 0.88)因不在当前配方 core 名单被拒——两例同根:**贯穿性是卡的属性,不随 target 变,而当前判据只认 target 归属**。
- **命题依据**:stage_transitions Q1(加法不换件,实机语料统计,数据已有);transition_combos(通用引擎池/贯穿插件层,「千冶·刃高价值来自通用插件身份,与羁绊无关」);[21]/[22](买而不上/有用先囤,囤牌语义的口述基座);P1 已证(弃购真实代价=再遇窗口,越稀有越囤——给「囤」提供数学保证);M3(plaza_methodology 早期核心,E→F 0.93 同族证据)。
- **标定路径**:阈值(如 0.85/0.90)sim A/B 扫描;字段化数据源=stage_transitions 现有 Q1 表(无需新采集);**不做逐卡名单**(注册表字段化,防名单腐化——W908 F3 波及面项要求)。

**S3 囤牌期权信号(费级再遇窗口)**:线外件按其费用档的再遇窗口给小额期权价,窗口长(高费/低出现率)价高,窗口短(1-2 费)价趋零。

- **病灶证据**:F1 降档后的正面机制——卡芙卡 2 费再遇窗口短,按本信号 r4 定价趋零,**r4 拒买可能本来就对**(REPORT.md §1.1.2);F8(1 费零息损压库)同一费级逻辑的对称端。S3 保证信号组不会把「什么线外件都捡」变成新过反应。
- **命题依据**:P1 已证(5 费@7-8 级再遇 60-180 轮,费级-窗口单调);P16 已证(E_rounds 超几何口径,供给率可直接推导窗口);[34](目标外副本两用途与购买序,压库费用档判据)提供「价趋零时不硬买」的口述边界。
- **标定路径**:窗口值从 P16 模型按等级/牌池解析推导(零采集);期权价权重 sim A/B;与 P4 教训对齐(W908 F8 审查:压库增益 ≤1.0pp,不为压库花息)——S3 上限应小,防免费期权变破息理由。

**成本侧(不做新机制,只扩豁免结构来源)**:

- **病灶证据**:F3 千冶·刃 g48 满息买入是伪破息(d=0),本就不入 P33 否决域;真正需要的是「豁免类判定有结构来源」而非逐例口ertia。
- **命题依据**:P33 已证(结构,豁免类=合成完备/线内缺档件;卡点=V_hold 散件上界未标定,replay 可离线补)。
- **标定路径**:P33 卡点(replay 离线条件表)与本设计共轨但不阻塞——S2/S3 正项先按「息成本由既有 int_emb 全额计入」落地,P33 豁免扩展作为独立标定挂账。

### D4 与 P20 激活、息律的接口(显式声明)

- **P20 接口**:S1 是 P20 的唯一消费面;激活判定用 `_cand_system_bonds` 单一源名集 + P19 计数语义,凑档判定必须基于**当前 deployed+bench 闭包**(REPORT.md §1.1 采集口径:bench 字段缺位期间用动作链闭包,闭包不可得时信号置 0 不猜)。
- **息律接口**(任务书「P14 息律」系编号笔误,息律=P13/P33,REPORT.md §3 勘误):息成本不进新信号——既有 int_emb/息崖平滑(ADR-0332)照旧全额计入外件买入;S1/S2/S3 只给收益侧正项,买不买仍由「正项−息成本」的代数和过非正分门裁决。破息帧的外件买入由 P33 否决域辖(豁免扩展挂账,见 D3 成本侧)。这保证新定价**永远不会为买外件而建议破息**——54% 破息正是 piece_value 的死因之一。
- **病灶证据**:F2(4 金刷新产出被拒=净损失,刷新侧预算不归本设计改,靠购买侧认价消解脱节)。
- **命题依据**:P13 已证(守 50 息律精确 DP,息成本闭式);P17 已证(A/B 主门=带金占比∧形态达标,验收口径)。
- **标定路径**:接口无新参数;A/B 验收主判据必须含息基(§5)。

### D5 锁线态收紧分支(13-4 的修法位)

- **病灶证据**:13-4——锁 DOT 队后夜之半神件以 2.0 底分照买×2,战力零增长;复盘建议「阵营过滤或大幅提分门槛」。
- **命题依据**:[31]③④(填充件不改变目标方向/边际羁绊贡献零=垫底)+[34] 购买序总则(非目标开支服从可量化收益优先)+[23](分数涌现=噪声,四线摇摆全输实证——锁线态尤其不许噪声分买入)。**裁定:不做独立阵营过滤器**——过滤是单边门,与 D2 加法结构冲突;正确形态是**定价归零**:锁定帧 ∧ 线外候选 ∧ S1=S2=S3=0 ⇒ 加项后总分必然≤底分来源可解释的水平,底分(plugin 通道的构成需在落码批核查:若 2.0 来自无据常数偏置,该偏置在锁线态置 0)。既有 final_fence(位面末轮线外 opportunistic 直拒)更严,保留不冲突——分层:常态靠定价,末轮靠围栏。
- **标定路径**:sim A/B 同伞开关;判读键记录「锁线态归零」触发数(触发 0 次=输入死,先补观测再测,strategy-work §4)。

### D6 piece_value 空缺的回答(旁件对账)

- **病灶证据**:W902 终裁——buy 子机制活而无效(行为差 31.4% 但病灶② +0.019pp 噪声带内,54% 破息);删码范围表已立未执行。
- **命题依据**:ADR-0497(删码留档);本设计 D3 三信号每个单独挂在一条已证/可证命题上,可独立否决——**这是与 piece_value 加权总量的本质区别**,也是空缺的答案:空缺由「S1(条件化 P20)+S2(Q1 字段化)+S3(P1/P16 解析)」补,不引入任何新的自由权重超过三者的结构。
- **标定路径**:排期前置=删码批先落(W902 §4 范围表 + W908 §4 警告的 registry 注释重写与 pv_bench_reserve/audit_matrix 悬空核对),避免同区双机制。

## 4. 验证设计与标定路径(汇总)

1. **阶 0(秒级)**:`cw_replay --diff` 对历史局(局 9/局 13 档案)看首发分歧点是否落在 F1/F2/F3/13-4 对应帧——分歧=漂移≠好坏,核对开火位置对不对。
2. **阶 1(sim A/B,n≥300/臂,同池指纹)**:改前基线→开臂对照。达标线**跑前写死**:主判据=形态达标率(ADR-0432 族既有口径);守门判据=息基不劣(带金占比,P17 主门)∧ 买入破息率不升(≥2pp 升即打回——piece_value 死因防复发)。三选一兑换照 strategy-work §4。
3. **sim 可标**:S1 开火率与权重、S2 阈值、S3 权重、D5 归零触发率——全部同池 sim 扫描可完成(供给分布同池)。
4. **必须实机**:①外件购买行为与息纪律的冲突率在真实节奏下的复核(sim 节奏可能低估遭遇/补给节点的支出竞争);②F1 型帧(线外体系件在店)的实机判读复现——开臂后首 2-3 实机局判读必查 `rb_*` 披露键。
5. **挂账命题**:P29(线内囤牌羁绊感知,待证明)是 F2 侧的完整数学化;本设计 S2 先以 Q1 实证数据给线内贯穿件结构价,P29 证明落地后如与其冲突,以证明为准回炉 S2。

## 5. 「不做什么」清单(防设计件膨胀)

1. **不改刷新预算层**:F2 的刷新侧(花金刷出好件)语义不动,脱节靠购买侧认价消解;刷新止损/预算归 P16/R-E 共轨(20-3)。
2. **不改方向重估/锁线判据**:target 换向、最小持有期、供给感知归 R-A/P31 设计件;本设计只保证「定价不随标签裸翻」,不管线怎么选。
3. **不立逐卡名单**:贯穿度=注册表字段(Q1 数据),禁手写「千冶·刃/姬子·启行」式名单。
4. **不碰装备分配、部署、升级授权**:归 R-C/R-G/F4 各自批次。
5. **不复活任何 piece_value 符号/字段/遥测键**:新命名空间 `rb_*`,旧键随删码批消失。
6. **不加独立过滤器通道**(13-4 的「阵营过滤」修法否决,归 D5 定价归零)。
7. **不拍任何生产数值**:阈值/权重全部默认占位+开臂判据挂账,禁悬置默认关无限期(开关生命周期)。
