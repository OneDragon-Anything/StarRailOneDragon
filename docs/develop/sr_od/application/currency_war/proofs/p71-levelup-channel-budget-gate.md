## 命题(形式化)

记 `g* = saturation_line(cap)`(默认 50)、`U_L = ⌈(need_L − xp_cur)/4⌉×4`(整批升一级成本,flat-4 上界口径,P39 A3)、`L(g,s,R,Ī)` = p47 双轨迹递推息损、`dep_cap(L) = L`(等级=可上阵人数,gameplay.md「等级对应可上阵角色数量;至多 10 人」机制直读)。

### P71-a(dep 满等级 cap 边际分域直证)

**dep 满** := deployed == deploy_cap ∧ bench 无线内候补(判据单一源 = `criteria/levelup.pop_slot` 拒因 `no_bench_candidate`,含「买得起候补」放宽支)。则:

1. **人口位边际恒零**:升级的战力边际按 P39 A1 分解为 ΔV_pop + ΔV_band。dep 满时新 slot 只能由后续买入填充;无候补(现持与可即买皆无)时本帧 ΔV_pop = w·1[等待件] = 0,且该零是**构造性精确零**,非近似——「lv8→9 等级 cap 边际在 dep 满时≈0」在人口通道上是**恰为 0**,不是 ≈0。
2. **「cap 边际=0 ⇒ 升级零战力收益」全域命题不成立**:仅存通道 ΔV_band(概率移位)非零,且其形状由 `REFRESH_PROB` 决定、对费档**符号分化**(表值直调,见数字表):lv8→9 使 1-3 费概率全降(3 费 0.32→0.25)、4-5 费全升(5 费 0.03→0.10)。故 dep 满时升级战力收益按费档分域:
   - **恒负域**:dep 满 ∧ 移位项非正(充分条件:锁定线核心费档 c*≤3 且当前级已达该档峰值级——p(c*,L) 在 L 过峰值级后单调降,表值单调性保证)⇒ EV_up = ΔV_band + 0 − U_L − L < 0 **严格**;
   - **待比较域**:dep 满 ∧ 存在 4-5 费搜窗需求 ⇒ ΔV_band > 0,是否升级让渡 P39 双臂门逐帧判定,本命题不预设。

### P71-b(升级通道预算闸判据式)

**闸辖域 = 溢余段帧 g > g\***(落码时显式化,2026-09-06):g ≤ g\* 帧不存在
「溢余段预算」可言——(3) 不适用,该帧升级支出由既有 (1)(2)(4) 辖;无此
限定则开局追级帧(lv3/g=8 形态)被负闸值恒拒,造成臂语义断层。本限定是
推导前提的显式化而非语义变更:§P71-b 全部推导(必要性两子情形/规范性)
本就只在 g 相对充足语境成立。

升级支出 s 合法 ⟺ 四合取:

```
(1) P48 整买    s = U_L(恰够一级;散买零收益拦截——spend_unified 已落地)
(2) 兑现视界    存活到账 h > d·L_c(P21;hp=0 死亡域升级零到账闸恒闭,
                ALL IN 位面末战豁免同 P21 先例;零 hp 直读不入比较式)
(3) 溢余段预算  g − s ≥ g* + ρ + Σ_w 窗口预留卡费(P54 息线 floor 同源;
                等价第一形式 s ≤ g − g* − ρ − Σ预留。穿线部分息损未单独
                计价时由一般式 ΔV_band + ΔV_pop ≥ s + L(g,s,R,Ī) 兜底
                ——溢余段内 L≡0(P70 侧 1 零息死仓),一般式退化为 P39 门)
(4) 通道比较    EV_up = ΔV_band + ΔV_pop − s − L ≥ EV_buy(同金买卡臂,
                P40 三层门产出;每金价值率比较,升级不因「能付」而豁免竞争)
```

其中 (3) 是本命题新增的**预算闸**:(1) 只保批内无零收益击,(2) 只辖血面,(4) 是比较判据——三者都不给单轮升级支出设上限;闸缺位时整批 U_L(lv8→9 上界 72 金)可单帧穿息线。

### P71-c(单轮连发 LevelUp 形态判读)

XP 是 Leontief 完美互补品(P48):不够升级的 XP 零收益零压库,末击承载整批价值——**「每次升级单看边际非负」不是良构命题**(前击离开批次无独立价值),良构评估单位 = 批。连发形态的定性由批账给出:

```
EV(批) = ΔV_band + ΔV_pop − s − L(g, s, R, Ī)
```

单帧连发合法的必要条件即 P71-b 四合取;**预算闸(3)是连发倾泻与分轮整批的唯一区分项**——整批金额一致时,连发把息损与时点敞口一次性吃到最大(穿线量最大);分轮形态指跨帧整批计划(P48 S 线语义:本帧部分击入 XP 库存、后续帧在各自溢余段内续齐完成),每帧支出 ≤ 该帧溢余量则全程 L≡0——分轮不是散买,散买(无完成计划的零收益库存)仍被 (1) 拦截。

## 证明

### P71-a 证明

1. ΔV_pop 的可观测二元结构是 P39 推导 2 的既有结论(w ≥ 0,符号由「备战席有无候补」决定)。dep 满 ∧ 无候补 ⟹ 指示变量取 0 ⟹ ΔV_pop = 0。若允许「买得起候补」支(bench_free ≥ 1 ∧ affordable),则该支出属买卡臂账,不改变人口位本身为零。
2. ΔV_band = Σ_c q_c·(E_L^c − E_{L+1}^c)·V_c(P39 段带口径)。E 单调性与 p(level,cost) 同向:refuse_prob 表 lv8→9 各档差 (−0.03, −0.05, −0.07, +0.08, +0.07),超几何 E[refreshes] 3 费 2 星 29.8→38.1(恶化 +28%)、4 费 43.3→31.8、5 费 202.2→60.8(脚本断言直调)。核心费档 c*≤3 时 q_{c*} 项符号为负;若同时无 4-5 费搜窗需求(其余 q_c 项为 0 或被 V̄ 加权后不主导),Σ ≤ 0。此时 EV_up = Σ(≤0) + 0 − U_L − L,U_L > 0、L ≥ 0 ⟹ 严格 < 0。∎
3. 反例方向(防过度声明):5 费核心线 lv8→9 的 E 缩至 1/3.3,移位项为正且量级大——故分域而非全域命题。∎

### P71-b 证明

(1)(2)(4) 分别是 P48/P21/P39-P40 已证判据的引用(辖域与边界随原命题),本命题只证 (3) 的必要性与规范性:

- **必要性**:s > g − g* − ρ − Σ预留 ⟹ 花后金位低于「满息档 + 至少一张命中卡可买」的 P54 floor。两种子情形:①花后仍 ≥ g*:穿线段 s' = s − (g − g*) 落入带内,由 P70 侧 1 对照(带内格 L > 0)知息损 L(g,s,R,Ī) > 0,而该息损在现行发射位(`mandate.py` M3 批位)未入账——只查可负担性 `check_affordable`,成本侧少一项,判据不完备;②花后 < g*:买卡臂在同一轮至少失去一次「满息档上买命中卡」的执行资格,EV_buy 的可行域被升级挤占——(4) 的比较在可行域被单臂吃掉时退化,须由 (3) 先保两边可行。
- **规范性(零新自由参数)**:闸值 B_L = min(U_L, g − g* − ρ − Σ预留) 的每个分量都是已证单一源(saturation_line / P54 ρ / P40 窗口预留),无拟合常数。
- **(3) 的一般式归约**:任意 s 的完备成本侧是 s + L(g,s,R,Ī)(p47 递推);溢余段内 L≡0(P70 断言 1 全网格),故 (3) 是一般式在零息段上的等价简化;穿线段必须回到一般式逐帧现算(边界 1)。∎

### P71-c 证明(73002 个案定性)

**帧事实**(decisions.jsonl 局 s73002 p2r3 + 批 checks):g=82 起手,15 连 `LevelUp cost=4` = 60 金(xp_cur=12 携带,72−60=12,与 `XP_TO_NEXT_LEVEL[8]=72` 自洽),夹 1 买 + 多次 must_spend 刷新;`seg_p2_blood_budget_levelup`=0。

1. **批账**:溢出量 = 82 − 50 = 32 < 60 ⟹ 穿线 28 金,L(82,60,R,Ī) ∈ [3,9](R∈{1,3,6}×Ī∈{5,7,9} 网格直调)> 0 未入账;对照:若分轮发放且每轮守 32 金溢余段,则 L≡0。形态定性 = **预算闸 (3) 缺位下的合规倾泻**:15 击逐击通过 (1) 整批语义(同一次批授权的执行展开)与可负担性检查,但 (3) 在该帧给 60 ≤ 32 = 假,闸存在即拦截。
2. **恒负域实例**:该局 p2r3 锁定「专家桑博DOT」,核心桑博 = 3 费档;3 费 p(lv8→9) 0.32→0.25 单调降、E[ref] 29.8→38.1 恶化——升级对本线搜窗是**负移位**;dep 已满(level=8,bench 全 1★ 线外件,无候补)⟹ ΔV_pop = 0。EV(批) < 0 属 P71-a 恒负域,非边界格。
3. **闸缺失的机制定位**:血预算停付 `level_spend_blocked` 双支(blood_budget_levelup_blocked ∪ p2_crisis_band)在 hp=46 帧不触发(非危机带);must_spend 域闩的域内豁免把停付支压掉(`must_spend_zone_defer_overridden` 语义)——域闩辖域是「本备战期已赚金的出口」,不辖「新增大额单通道支出的量」;g=82 起手即域内,域豁免 + 无 (3) ⟹ 批全额放行。两道既有闸(血预算、整买)各辖其面,**唯独没有量闸** = 「升级通道无预算约束」的精确定位。
4. **阈值骨架(A/B 方案)**:
   - **方案 A(每轮升级预算 = 溢余段约束)**:B_L = min(U_L, g − g* − ρ − Σ预留)。状态函数、零新自由参数、与 P54/P70 单一源同基——**数学规范形式**。
   - **方案 B(XP 占金比 s/g ≤ α)**:规范阈值 α*(g) = 1 − (g* + ρ + Σ预留)/g,是状态的函数非常数;任何常数 α 无规范依据(在 g 大时过松、g 贴 g* 时过紧),只能作 sim A/B 的粗闸对照臂。故 A/B 的数学含义 = **规范形式(A) vs 常数近似(B)**,B 方案退化极限即 A。∎

## 边界(什么情况失效,如实入册)

1. **穿线段必须回一般式**:闸 (3) 的 L≡0 简化只在溢余段内成立;闸放行的最大支出恰触线,穿线评估(若闸被显式放宽)须逐帧现算 L(p47),禁复用零息简化;
2. **sim/live 等级帽分歧**:live 封顶 10 级、sim `LEVEL_CAP=9`(`cw_state` 已声明建模分歧)——lv9→10 档(84 金)的数字面只对 live 语义有效,sim 批判读按帽 9 截断,禁跨语义引数值;
3. **flat-4 单价覆盖面**:单击 4 金 lv6/8/9 无实机实测(P39 A3 既有边界);单价随级上浮则 U_L 低估、恒负域更负(方向保守),但 (3) 的闸值随之偏松,须随实采复核;
4. **ΔV_pop 的 w 量级未标定**:本命题只用 w·1[等待件] 的符号结构(P39 同款),恒负域结论不依赖 w 值;待比较域的量级裁决仍归 P39 双臂门与 sim 对拍;
5. **峰值级随版本变**:REFRESH_PROB 表为 V4.4 权威采集,游戏改概率表即失效须重验(P10 教训:禁字面量第二份,脚本直调注册表);
6. **域闩交互未裁**:域内豁免与本闸 (3) 的优先序——本命题数学面只证 (3) 的必要性;域内帧是否豁免 (3) 是设计裁决(sim A/B 同批定),数学上域内豁免 = 接受 L>0 入账,不得免账。
