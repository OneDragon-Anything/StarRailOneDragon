# 终局阵容 · 万敌燃血类(CARRY=万敌;燃血2-6+群攻3/夜半2;~37 篇)

> 已深读:「万敌无脑单挂」(use 112577,r169)。累积理解。

## 类结构:单C 前排独挂(与双 CARRY 类对照)

```
Final: 前排只有万敌×3(CARRY);后排 7 人全辅助
羁绊: 群攻3+夜半2+燃血2+量子2+战技点2
```
机制:燃血记录-返还(挨打记账→1000%-4000% 倍率反打)与万敌
「一人扛线」完美契合——**万敌既是坦克又是 C**(伤害来源=挨打记录)。

## 装备链

- 万敌:**绝对热量+火力风暴潮+热血沸腾拳**(纯输出三件——对比罗刹
  三月七的速度件:CARRY 装备由伤害驱动类型决定)
- 刻律×3(第二核心):电磁弹射器+靴×2
- 翡翠:群攻增益件(追逐星辰/钻地弹/闪光手榴弹)

## 终局可替换组(作者明说)

群攻3(缇宝/那刻夏/翡翠)↔ 减益2(彦卿)+量子3(符玄)+盛会2(大丽花)
——**核心 CARRY 固定,副羁绊按来牌替换**(对建模:final comp 不写死)。
