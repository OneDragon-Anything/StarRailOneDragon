# 00 哲学与约束（λ 哲学塌缩件）

> 本篇是 CW 策略的**第一性约束层**：后面各篇（= 本目录全部现行篇，篇目索引见 [README](README.md) §2）的任何判据与本篇冲突时，以本篇为准。
> 术语：**λ_death** = 死亡危险率（在「当前难度带 × 血带 × 位面 × 节点」条件下打输下一场战斗、进而威胁存活的概率估计），是策略里唯一「错了就出局」的参数。

## 1. 宪法四条（用户裁定，最高权威）

1. **策略不依赖战力建模**。决策依据 = 游戏定义值或核心已定义规则；经验拟合/采样分布不得作决策依据。
   - 判读：任何判据若消费「胜率映射表 / 掉血先验 / 板面强度评分」这类拟合产物作闸门，即违例（旧 strategy/01_posture §6-§7 的 `HP_LOSS_MU`/`p_win_p2`/`effective_hp_threshold` 是违例史实，见 REVIEW §2.4）。
   - 合法例外 = §3 硬闸门授权的两件，且例外扩大须用户逐项确认。
2. **位面只能作参数**。位面进通用模型的方式只有一种：作（节点数表/伤害锚表/档位表）的**查表键**。按位面枚举机制辖域的门（如「只在位面 2 生效的模块」）= 设计缺陷，必须通用化重写。
3. **姿态 = 发展优先默认，危险信号只升不降**。压制发展的机制不得出现（详见 §4）。
4. **数学先行**。每个机制规格必须可证明或显式登记待证假设；数字三形态（【注】/【推】/【拟】）章程见 [01_math_framework.md](01_math_framework.md) §6。

## 2. λ_death 的地位：不是最重要的参数，是唯一「错了就出局」的参数

（出处：lambda-risk-philosophy §1）

- 按**决策数量**：约半数决策走阵容知识、纯公式走经济数学，不依赖 λ；λ 只管少数关键节点（守息 vs 转化的切换）。
- 按**错误后果**：其他参数错 = 少赚（可恢复）；λ 错 = 死亡（吸收态，一局清零）。期望总收益 = Σ(活到 t 期概率)×(第 t 期收益)——不压住死亡概率列，任何「贪心最优」都证不出来（吸收态论证，先验成立，不依赖语料）。
- 由此推出本链的姿态架构（§4）：死亡风险只由**只升不降的升档器**承接，不做主姿态。

## 3. 血与战力的关系：hp/战力辖域硬闸门（用户根因声明，权威口径）

（出处：lambda-risk-philosophy §2；NMF 裁定二，NEW_MATH_FRAMEWORK:335）

- 原规矩「hp 不作策略入参」的**根本原因 = 我们无法对战力和胜负做准确建模，hp 只是这个根因的后果**（不是 hp 本身有问题）；用户对粗略模型导致策略效果差保持警惕。
- **硬闸门：仅两处被授权消费 hp/战力数据**——
  1. **λ_death 表**（血带作为查表键的维之一，PL 键 = 难度带×血带×位面×节点）；
  2. **P15 掉血公式**（结算屏三项中的 hp 分量）。
- **此两件之外**，任何战力相关内容（战力/胜负建模及其衍生量；hp 仅为其后果之一）进入策略，**须用户逐项确认后才能实施**。
- 进决策的从来不是「血量数值」，而是「这局还会不会死」的概率；血量只是它的最佳预测输入之一。
- 在册挂账（待玩家确认，行为按现状运行不改）：血线硬地板 hp 直接触发支出解锁的授权（NMF:337 R32-中② 挂账，2026-09-01 用户已按「只要不影响以发展为主线就没问题」条件确认形态/阈值域 ≤15/解锁包三件，NMF「血线硬地板三件挂账·确认回写」节）；12 号件停手线的 hp 直读（见 [04_survival_budget.md](04_survival_budget.md) §7）。

## 4. 姿态架构：发展优先默认 + 危险只升不降（安全带）

（出处：lambda-risk-philosophy §3；NMF 安全带架构裁定 341-371）

- **默认姿态 = 发展优先**（用户学派）：经济 + 阵容决策做对 → 自然赢 → 血不担心。该命题的**可证形态 = 域命题**：当 λ×敞口×剩余视界小到二阶时，发展优先 ε-最优（ε 由 λ 上界压住，P52 已证）；**无条件形态不可证**（吸收态论证反对）。
- **危险信号 = 只升不降的升档器**：
  - **血线硬地板**（hp < 阈值【拟】≤15 触发「解锁包」：M3 破息批解锁至饱和线下 + 凑息禁令 + 转化优先）——滞后但零数据；
  - **λ 顾问**（PL 键查表相对分位）——只允许把反应**提前**，**禁止把反应推迟**。
  - λ 表错 → 最多早花（少赚），绝不会更危险。
- **两验收条件（缺一不批）**：
  1. **实现不难**：升档器是判据外的独立薄层（消费既有 λ 表 + 血线，不改七面判据本体）；
  2. **激活率门**：正确决策下触发率个位数百分比内（骨架 + EV 臂 sim 实测，超标 = 过敏感回炉）。
- **绑定约束（写入验收）**：血线地板的一切行为**不得在安全域内推迟或抑制发展动作**（P52 定理的安全域 D_ε 上顾问/地板不动作）；任何实现或标定违反此约束 = 全架构回炉。

## 6. λ 表使用纪律（实证刻度）

（出处：lambda-risk-philosophy §5；裁定一：PL 键选型 B1，NMF:333）

- **表键 = PL 键**（难度带 × 血带 × 位面 × 节点，2×3×2×4=48 格，空格 10 显式标空）。位面在键中 = 查表键，正是宪法第 2 条要求的形态；板面/bench 战力桶**不入键**。
- 消费纪律：区间 + 保守端 + 单调约束（PAA 等保序回归；血带方向 = 血越低危越高，脚本内方向断言护栏）；同格亚组异质性 <0.05。
- 实机刻度 0.34-0.85；λ≈0 段在实机刻度上是空集——旧「三段管辖（λ 分段路由）」已整体退役（R26-H1 supersede，NMF:41），现行 = 本篇 §4 姿态架构。
- 局数少的质量门与兜底：翻转面扫描带（held-out 误差、阈值扫描）+ 四层兜底（结构规则地板/保守端/域外守息/定向补样）。**状态 = 后续待观察，非稳定**（用户 2026-09-02 带条件解除质疑登记：以发展主线不受影响为前提；禁终态表述；观察载体 = 漂移哨兵/键重估触发器/标定批质量门/激活率基线）。

## 7. 数据通道纪律

（出处：lambda-risk-philosophy §6）

- **实机 = 点火器不是燃料**：结算屏三项遥测（每局 ≈25 轮样本）+ 版本更新锚 + 最终验收；λ 扩样/标定/sim 三臂全离线。
- **sim 战斗表与 λ 表同语料 = 循环**：注入对模型风险零信息——sim 只当压力测试，禁当概率来源。
- 难度值 = 局内读取为准（真值），公式计算值 = 兜底 + 对账（对账持续偏差 = 版本改难度机制的最早警报）。
- 运行时监控钩子禁吃审计条件行，必须消费带身份键的必写行。

## 8. 死因实证背书（为什么默认姿态是发展优先）

（出处：lambda-risk-philosophy §4，DEATH_POSTMORTEM.md 57 死局逐局复盘——该复盘文件属已删除的旧文档树，git 历史可溯）

- A 决策质量 54%（最大单一主因）：其中 A1「该买不买」21 局 ≫ 买而烂 10 局；
- B 反应缺失 32% 非零；**A1+B 同根（消费被存息/升级姿态压制，无紧急通路）= 68% 单一错误模式**；
- C 不可挽 14% = 预期地板。
- 设计对照：68% 形态恰为骨架层 M1-M4 义务动作直接治（[02_mandate_layer.md](02_mandate_layer.md)）；B 类真实存在 = 安全带（升档器）非死重。验证判据基线 = 同口径复算死因分布，A1+B 塌向 C 地板 = 骨架生效硬信号。

## 9. 机会性精修道（资源分配）

战力建模工作**不封账**——有并行闲槽即继续（精益求精），两条件：①不影响主体（主流程判据/落码/sim 不等精修结果，PL 键薄层按既定设计消费）；②新产出进策略仍过硬闸门（逐项用户确认）。精修项池：λ 尾部标定/bench 维扩展/候选形态升级/词缀-λ 交互等，按闲槽派批，主流程优先级恒高。
