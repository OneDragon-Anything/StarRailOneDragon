## 装备来源模型(与卡池分源,单独建模)

**结构性事实:装备不进商店卡池**。卡池决策域(p38/p40/p41)的全部通道——槽级刷新概率 `REFRESH_PROB`、付费刷新、超几何池衰减——对装备**不存在**;装备到达通道为(economy.md §8 + equipment_mechanics §3/§5 + §10.2):

| 流 s | 内容 | 强度/定向 | 证据与状态 |
|---|---|---|---|
| 投资环境概念股 | 送**指定**基础件:昼神/追击→轮滑鞋、仙舟→折叠小刀、列车→幸运星 | 半可控(选环境时定向) | economy.md §8 [图鉴] |
| 投资策略牌发放 | 工具 7 件为主(冶金炉/扳手/令牌等,`cw_invest_data.py:50-364` 大量条目) | 随发牌 | equipment_mechanics §5 获取通道【代码实锤】 |
| 门户二手市场 | 投影仪(:375) | 随门户 | 同上 |
| 补给节点 | P1 r5 = supply(economy.md §10.2 位面节点表);**给什么无实测记载** | 未知 🔴 | 待标定 |
| 角色自带装备 | 买商店角色可能附已穿装备 | 规律未建模 🔴 | equipment_mechanics §3 |
| 冶金炉刷出 | 同类随机变换(内生流) | 见 ③ | equipment_mechanics §5 |

**模型**:λ_x = Σ_s λ_s · ρ_s(x),各流按节点事件条件化(发放集中在奖励/补给/投资环境节点,非均匀流——equipment_mechanics 待实测边角明言 P14 均匀假设需事件条件化改造,本篇从之)。**全部 λ_s / ρ_s 待标定 🔴**;本篇只消费 λ 带做**序**结论(对带内取值稳健,自检③),绝对 EV 空转待标定(math_proofs 纪律)。

**与卡池的关键结构差(本篇一切结论的支点)**:装备域**不存在付费补救通道**——p41 的通道乙(急 D 补救 = c_eff/P_shop)在装备域没有对应物;唯一的定向通道是**好运令牌**,且它作用在**进阶层**(直接给推荐进阶件),不在基础件层。因此:

- 基础件层的再遇 = 纯等待(几何分布,期望 1/λ_x 轮);
- 进阶层有两条获取路径:合成(2 基础件,受流约束)或令牌(定向但令牌有限);
- 这使组件的「错过成本」结构比卡池**更陡**:错过无补救,只能靠窗口内自然到件或令牌兜底。

## 推导

### ① 组件保留决策(囤积价值结构)

**情景**:基础件 x 在手(发放/自带/炉子刷出),当前线 K(或未锁线)。三个竞争用途:囤(等合成)、穿(过渡,含误合成风险)、回收(炉子饲料)。

**净缺口与逐配方价值口径(R3 重推)**:

n_y = max(0, m_y − inv_y)——持有(含同名成品 1:1 抵扣,`hoard_gaps` 口径)**超出需求的部分不是缺口件**(处置走 ②③)。在此语义上定义两层价值:

- **线级稀缺(整线视角,④ 令牌同口径)**:S_line(y) = P(Bin(W, λ_y) < n_y)——窗口内来源流凑不齐剩余需求的概率,随残深 n_y **升**(深需求线整体更难自凑);
- **边际件值(单张视角,囤/喂决策用,R3 逐配方)**:

**价值实现单元 = 单条配方的兑现**(A11,游戏事实:合成即可穿、equip_assign 逐件分配、穿着即战力)。持有张跨配方**不可重复消费**——j 张 x 能兑现的是「含 x 配方的一个子集」:

```
f_x(j) = max_{S ⊆ R(x), Σ_{A∈S} t_A(x) ≤ j} Σ_{A∈S} g_A(x)        (子集背包,配方数 ≤6 时精确枚举)
V_comp(x | K) = Σ_k P(Bin(W,λ_x)=k) · [f_x(inv_x+k) − f_x(inv_x+k−1)]   (单张边际,流期望口径)
```

**望远镜恒等式的重证与降级(R3)**:持有维差分望远镜 **精确**——Σ_{h=0}^{m−1} marginal(h) = Σ_k P(Bin=k)·[f(m−1+k) − f(max(k−1,0))],同维直读,脚本锁(狼尊鞋 6 张联合价值 2.1814 逐项吻合);**跨件维降级**:partner 到位率 g_A 按各 partner 流独立连乘,是 A10 同型独立性近似(带内偏差 ~0.3%),partner 跨配方共享的耦合未计。**旧组件级形式「边际 = P(Bin(W,λ_x)=n_x)」撤销**:该形式隐含「整线全齐才算数」的 all-or-nothing 账,与「合成即可穿」相悖——组件级聚合把多条配方叠在同一基础件上(狼尊鞋 n_x=5 实为「2 份自配(确定距离 2)+ 2 份交叉(距离 1)」),近兑现张损失被低估 **4~8 个数量级**(狼尊第 1 张鞋:ℓ_old = P(Bin=5) ∈ [1.2e-9, 8.0e-6] vs ℓ_new ∈ [0.10, 0.40],带内全程比值 ≥ 10⁴,脚本 3 锁)。**降级条款**:若某线战力为纯 all-or-nothing(无中间兑现),组件级账对该线仍对(A11 边界;本库 20 comp 均非此形态)。

C_re(x) = x 经配方兑现的延迟成本(延迟轮数 × V_adv 边际,⚪ 未货币化)。**消去辖域(N5,R1 扩展)**:C_re 齐一(逐件兑现等价,或 V_adv 档间齐一假设 A5)时线内比较可消去 C_re;多目标线下 V_adv(A) 档间序与稀缺序可倒挂,消去不成立,倒挂场景下须带 C_re 权重比较。

**可计算的首版序(保留序,R3 重写——分层维度 = 最近兑现距离 × partner 到位率)**:

```
保留优先级(x) ∝ V_comp(x|K) = 流期望 × f_x 边际,由 (d*, g*) 二维分层:
  d*(x) = min_A max(0, t_A(x) − inv_x)(最近兑现距离:再几张 x 可合出一件进阶)
  g*(x) = 对应最近配方的 partner 到位率(自配 g=1;交叉 = Π P(Bin ≥ 伙伴净缺口))
```

四条直接读数(R3 替换旧「残深」三条):

- **近兑现张最贵**:d*=1(自配对子的第 2 张 / 交叉张且 partner 在手)时单张边际损失 ℓ_new ∈ [0.10, 0.40](带内,狼尊第 1 张鞋 0.103~0.396)——喂掉它 = 放弃一桩大概率到手的一件进阶;
- **自配对子的第 2 张 = 确定兑现**:g=1(伙伴是自己的另一张),f_x 在 j=t_self 处跳到 1(狼尊鞋 f(1)=0.16 → f(2)=1.00,脚本锁)——全谱最贵的张是这类;
- **partner 未卜的关张张便宜**:满需后边际张的兑现被 partner 到位率门控(g ∈ [0.05, 0.16] 带内深缺口角),单张边际值可低于喂炉收益——这是 ③ 推论1' 的可违来源(81 格),价值轮廓 = 「近兑现张最贵、伙伴未卜的关张张便宜」,与组件级「关张张最贵」方向相反(后者是聚合假象);
- **超出需求(inv > m)对本线 V_comp = 0**:其处置走 ②(换线残值)/③(回收流水线)——这正是 `recycle_qualified`(:253)的语义边界(机制事实层,豁免消费)。

### ② 合成配对决策(哪两件、何时合)

**硬约束层(先于一切 EV,feasibility)**:

  (§结构差),若 A ∈ R(chosen) 且令牌在手/可期,先合成 A、后令牌定向再得 A = 重复获取

### ⑤ 分配规则([9] 三级序的数学化)

**形式化**:[9]「优先保留输出的,阵容有辅助核心装备的次之,有盈余才给其他」= 装备→槽位的**字典序加权匹配**:

```
约束(硬):容量 3 槽/人;row(e) 相容;taboo 删域;唯一件全局 ≤1;配对守卫(②)
目标(字典序):max (m1, m2, m3)
  m1 = carry 关键装备匹配数(equip_assign[carry] 按序,multiplicity 消费)
  m2 = 其余 core 关键装备匹配数
  m3 = 盈余填充数(兜底)
```

**边际读数**:tier-3 填充件的价值 = ε(兜底防裸奔),其机会成本 = 同件在 tier-1/2 缺口上的价值(V_adv 档)——「有盈余才给其他」= 匹配可行性:m1/m2 饱和后剩余件才进 m3。**穿戴可逆(A7)使分配无资源承诺**:错配的代价只是战力差与转移摩擦,不是资产损失——所以三级序管的是**当轮战力期望**而非资产保护;资产保护由 ② 的配对守卫单独承担(两层职责正交,与 ADR-0265 增补后的代码结构一致:分配器 :1854-1877 注释明言两条防线分工)。

**接口(equip_assign 知识 → 本规则的输入)**:`equip_assign`(:141,EquipChoice fixed/pool 两档)提供 tier 内的优先序与候选池;`derive_key_equips`(:172)保证 K 与 assign 恒等(C5 锁)——即**分配的权重知识全部来自 comp 注册表,本篇只供数学骨架(字典序匹配 + 硬约束集),不发明权重**。pool 档(黄泉第四件类)= m1 内的子字典序(候选按序)。

## 边界(本证明不覆盖)

- V_adv 未货币化(⚪):③④⑤ 的不等式在 V_adv 只能消去或作序主导项时给结论;V_adv 档间序与稀缺序倒挂场景(A5,辖域已扩 ①③④)待标定后复检;
- 装备来源流全部待标定:本篇一切**绝对 EV** 空转,只有**序**与**支配关系**(近兑现张不喂(硬结论);其余缺口件默认不喂(软例外:残深≥2/近关张带内可违格收益 +0.003~+0.315/次,不立规)、满需关张件按 partner 状态分流——伙伴到位不喂/**伙伴未到位带内亦可违(带内 lo 33/mid 30/带顶 22 格,非仅对抗角 81 格)**、锁线前合成严格后悔)是带内结论——落码禁拍 λ 死值,挂清单;**「缺口组件不喂」口述的例外条款待玩家确认(已挂当前迭代账本候裁行)**;
- 投影仪复制的角色价值不重推(消费 p38/p41,本篇只给槽约束接口);投资牌购买的金账不推(投资域);
- 特权卡的「期间战力差」未货币化(等待成本 ⚪):规则退化为「carry 首件即用」的保守序;
- 冶金炉变换池分布未实测:池口径 = 8 均匀是**承重假设 A9**(逐配方口径下 pool=7 只放大违例幅度 +0.327→+0.379、不翻方向);池内分布用均匀上界/下界夹逼,精确分布待标定;
- 逐配方账的独立性边界:partner 到位率连乘与跨配方持有分配按独立近似(A10/A11;partner 跨配方共享的耦合未计,子集背包在独立因子下精确);若某线战力为纯 all-or-nothing(无中间兑现),该线须退回组件级账(A11 降级条款,本库 20 comp 均非此形态);
- 多套合成并发(同轮多个凑齐目标)的调度次序 = 字典序直读,未做运输问题最优(② 声明);
- 星徽/卡带的羁绊计数语义(add-if-absent/+1)不属决策域(cw_bond_equips 机制层已建模),本篇不经手。
