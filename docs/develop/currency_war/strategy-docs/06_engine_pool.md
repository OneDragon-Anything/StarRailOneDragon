## 1. 问题定义

- **辖域**：S0（空窗期）与 S1（search 态）的**引擎件获取**——「未锁线期，bot 依据什么把四体系/通用插件的件渐进搬上板面」。focus 态（S3）的线成员买入归 M2 义务（02 §3），不在本篇。
- **要回答的三问**：①哪些件算「引擎件」（候选集定义）；②按什么判据/节奏买（渐进规则）；③买不到/不该买时的行为（空候选帧防死锁）。
- **为什么是策略问题而非已解决**：六序的序 1 在 search 态判「结构可达终局件」（全 COMP_LIBRARY 重叠计数），是**终局导向**的粗筛；过渡引擎（四体系）与通用插件的**渐进组合**（谁先到、和谁搭、补到第几个）没有独立规格——第 10 局死锁证明缺位有实害。

## 2. 知识地基（transition_combos 结论，引用不复制）

- **四过渡体系**（用户定调 2026-08-23/08-24 封闭裁定）：仙舟3（藿藿+饮月+爻光三人组，功能链）/ 列车2（无人员要求）/ DOT2（任意 2 DOT 件）/ 希儿系（希儿单卡依赖 + 量子3 ∨ 贝2 放大器）。两两组合过位面 1。
- **加法不换件原则**：升级 = 在成型形态上添件，任一步断了停在当前形态照样能打；组合判据彼此独立；**下一步添什么由当前持有状态决定（状态驱动，无预设顺序）**——语料的常见次序是统计描述非执行规则。
- **副产品挂件层**：学者2/星核2/减益2/燃血2 等是买 DOT/通用件顺带激活的凑数位，不独立成线；凑数池（双羁绊挂件，谁在场买谁）。
- **直通终局线**自带入场策略（信号谱：策略驱动 > 核心到手 > 环境），未成型前照常走通用引擎池。
- **通用插件池**（PLUGIN_LIBRARY 载体）：跨线骨架（千冶·刃/符玄/瓦尔特/星期日/花火/开拓者等）。

## 3. 提案规格

### 3.1 引擎池候选集（注册表载体）

```
ENGINE_POOL = TRANSITION_SYSTEMS 成员 ∪ PLUGIN_LIBRARY ∪ 凑数挂件池
```

三注册表即 03 §5 已登记的新建件（TRANSITION_SYSTEMS/PLUGIN_LIBRARY 本就为过渡知识而设）——本篇为其补**消费判据**，不建第四张表。每件登记：所属体系、功能角色（核心/放大器/凑数/插件）、费用档。

### 3.2 渐进买进规则（判据链，按序评估）

对商店每张卡，未锁线期判据链（先于六序的金约束门，消费同一过滤器）：

1. **体系成员（含放大器）**：c ∈ 任一在建体系的成员/放大器名单 ∧ 当前该体系**未封口**（详见 3.3 节奏）⇒ **走 M2 义务通道照买不走息律门**（[2] 攒息期也要买过渡、[11] 攒息不拦无损购买、[6] 破档例外——文档依据链与 M2 同源；1★ 全额退 = 活期资产，P41 ① 支配性：净成本 ≈ 0 ⇒ 无条件放行，支配性优先序先于一切带参 EV 比较）。
2. **通用插件**：c ∈ PLUGIN_LIBRARY ⇒ 过 P41 V_opt 通道（囤件期权 EV；u_x/H_x 未标定 ⇒ 燃料类消参支配放行、中间类 fail-closed 持有评估——01 §6 章程）。
3. **凑数挂件**：c ∈ 凑数池 ∧ 边际羁绊贡献>0（[31]③）∧ 场况插件资源合取（场上空位≥1 ∧ bench 槽≥1）⇒ 按 [34] 稀缺性序。
4. **其余**：退六序常规判（压库档匹配 P49 / 纯冗余停买）。

**席位与预算约束**：全部走 02 §4 硬约束（可负担/席位/S 预留/不可逆护栏）；bench 稀缺按 [34] 序定价（free≤1 时过 V_slot 净门，P41 ③）。

### 3.3 渐进节奏（状态驱动，无预编顺序）

- **节奏判据 = 当前持有状态**（transition_combos 加法原则）：每备战期对四体系各算「成型距离」（缺口件数），**优先补缺口最小且人员要求已满足的体系**（DOT2 门槛最低常先亮是涌现结果不是规则——禁把统计次序反写为执行序）；
- **封口规则**：体系已成型（羁绊档达标）⇒ 该体系成员降级为「场况插件」类（[35] 边际羁绊贡献>0 才买）；过渡成型里程碑命中（[13]）⇒ S1 停手线生效，过渡件停买（辖域 = 边际贡献 0 的纯冗余）；
- **直通线分流**：入场信号命中（策略驱动/核心到手/环境）⇒ 开局按该线配方执行（M5 的 K 分流）；未命中 ⇒ 四体系过渡配方不变；
- **重心滑动**：S1 相位 B（终局件入场、燃料件回收）= §4.5 卖出规则的输出在统计上的表现，非独立相位规则（03 §3）。

### 3.4 空候选帧防死锁（第 10 局死锁教训的直接修复面）

**规则**：未锁线期任一备战期，若判据链对全店 5 槽均无买入候选（全店 non_line），**禁零动作**——降级到 [31] 三级降级的下一级：

1. 目标件级无候选 ⇒ 降**羁绊填充**级：任一在建体系/在场羁绊的下一档填充件（边际贡献>0）；
2. 仍无候选 ⇒ 降**散件垫底**级：买 1★ 全额退垫件（活期资产，净成本 ≈ 0，P41 支配性——「买垫件囤着」严格不劣于持币，且压缩牌库 P49）；
3. 连续 N 个备战期落在降级 2（`ENGINE_STALL_N`【拟，标定批，fail-closed：None ⇒ 只记遥测不触发】）⇒ 触发换线评估事件（消费 §4.3 机器，S0 态无线路对象时退 survival 模式判读）+ 遥测键计数（观察级）。

**骨架命题 A 的对齐**：零动作轮 <5% 是判前锁指标（02 §8）——本节是其未锁线期承载面；死锁帧计数进 sim 检查项。

### 3.5 验证面（预注册，随对抗审查定稿）

- **sim 可验**：①判据链行为分布（各降级级触发率、死锁帧=0）；②S0→S1 成型速度（对照四体系组合的涌现次序分布，不锁平均次序）；③零动作轮占比 <5%；④早中期零漂移门逐 seed diff={}。
- **实机判读锚点**：①全店 non_line 帧的动作率（对照第 10 局死锁基线=0）；②过渡成型时点分布（对照 [13] 里程碑）；③P1 过段率（目标②判据族）。
- **对抗审查要点（审查者按此攻击）**：①判据链与六序的辖域分界是否有缝（两套「买什么」判据并存的双源风险）；②封口规则与 S1 停手线的辖域重叠；③降级 2「买垫件严格不劣」的支配性论证是否依赖未声明的席位前提（bench_free 逐张现检，同 05 §2.3 辖域条款②）；④ENGINE_STALL_N 的 fail-closed 退路是否完备。
