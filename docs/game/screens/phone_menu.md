# 菜单(phone_menu)

手机主菜单(开拓者手机界面)。从这进入各子玩法(委托/合成/角色/指南/编队/背包/任务/邮件/无名勋礼/…),以及返回登录/退出。**不锁光标**(`pc_alt=false`,`click_game` 无需 `pc_alt`)。

## 何时出现 + 状态流转

- **入口**:大世界按 `ESC` → 菜单(`OpenPhoneMenu` op:ESC + 找"开拓等级"验证)。各子玩法/弹窗关闭后也回此画面。
- **出口**(动作 → 下一态):
  - 点菜单项图标(商店/委托/合成/角色/指南/编队/背包/任务/邮件/无名勋礼/跃迁/…)→ 进对应子画面。
  - `委托`弹窗(领取/派遣)→ 完成 → 关闭回菜单。
  - `无名勋礼`面板(全屏接管,一键领取/开启)→ 完成 → 关闭回菜单(独立屏,见 [无名勋礼.md](无名勋礼.md))。
  - `邮件`全部领取 → 完成。
  - 右上角返回 / 再 ESC → 回大世界。
  - 按键-返回登录 → 返回登录确认弹窗 → 确认 → 登录界面。

## 识别特征(稳定锚点)

- **开拓等级**(text "开拓等级",pc_rect 1280,230-1380,290,`id_mark=true`):菜单主态的精准识别锚点(analyze 命中 conf 0.999)。
- `pc_alt=false`:菜单不锁光标(与大世界区分)。
- 右上角返回(1840,25-1895,80)、更多按钮(1390,50-1810,350)。
- 易变:开拓等级数字、均衡等级、UID、菜单项红点/奖励提示。
