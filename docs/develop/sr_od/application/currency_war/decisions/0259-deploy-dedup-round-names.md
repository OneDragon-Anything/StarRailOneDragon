# ADR-0259: deploy 同名去重扩到本轮已上名单(重复件占位根修;r404-A2)

- **Status**: accepted
- **Date**: 2026-08-23

## Context

A1(ADR-0258)落地后 sim engines2_by_r6 仍 0.433 不动——诊断链深挖破案:
60 局未成型 43 局中 **40 局 = 重复件占位 + cap 满无换人**。机制:旧同名
去重只查传入的 deployed_cids(实机=开局读一次屏幕、sim=恒空集),本轮内
第二张同名 cid 不在名单里 → 照样上场。局12 实证:deployed=爻光×3+藿藿×2
(6/6 满),第 2 张起对体系计数零增益(5.1.7 游戏规则:同角色在场只允许
1),白占 cap,bench 点火件永远进不来。

## Considered Options

1. **去重名单扩到本轮已上(_up_names)**——5.1.7 不变量的真守卫;同名
   副本留 bench(3合1 素材囤件语义无损:r383b 囤的是 bench 不是上场)。
2. 购买侧禁买第 2 张同名——伤 r383b 囤件语义(囤 bench 是合法且恒优,
   口述[22] 三笔账);且已买的存量副本仍需 deploy 侧处理。
3. cap 满换人 swap(点火件换下最弱非体系件)——正交补充,后续 A3 批
  (交接文件「下一步」第 2 项)。

## Decision

选 1:select_deployments 去重条件 `cid in deployed_cids or cid in
_up_names`(本轮已上名单,逐张累加),命中者 held 留 bench。op 侧同洞
同源修复(读屏后不更新名单)。连带:check_deploy_fills_cap 检查项同步
(同名副本=合法囤,不算「可上货」),误报 19→0,锁测试补同名不报例。

## Consequences

- **sim engines2 0.433→0.100 是挤掉非法水分**(旧 sim 同名多张上场虚增
  阵营计数,旧行为本身违反 5.1.7)——0.100 才是合法部署的真实成型率,
  **历史所有 sim 指标都部分建立在非法部署上,引用旧数字前须验此边界**;
- HP 三指标大涨(loss≤2 0.017→0.233 / hp≥60 0.017→0.067 / avg 17.9→
  41.8)——合法部署下板面多样性反而更好;
- 全量 1063 绿(子目录口径;根级 9 失败与本改动无关,见进度树「全量红
  发现」),四检查网零违规;
- 设计意图与 sim 数字源:交接文档(作者会话末交接);本 ADR 由主会话
  按交接记载补写(作者会话已结束)。
