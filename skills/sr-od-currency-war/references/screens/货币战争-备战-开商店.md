# 货币战争-备战-开商店

## 画面简介

备战画面的商店展开形态。两条路进来：点「按钮-商店开关」展开，或者游戏自动展开。游戏自动展开发生在这些时候：战斗结算、投资策略、补给、遭遇选择做完之后，BOSS 简报、位面过渡点掉之后——回到备战后商店自己展开成本形态，开店经常是游戏自动的；开局 1-1 不展开，中途离开后又回来继续的局，商店可能被游戏锁住，不展开也打不开。回到备战有一段动画，商店是动画走完时展开的；动画没走完时画面看着还是商店没展开的备战，这时点击不生效。**自动开店 = 开拓商店横幅的同位陷阱源**：本形态下备战左侧开拓商店横幅「打开商店」文本锚（约 (550,284)）与「商店牌-1」区域重叠——想点横幅开开拓商店，实际买下了槽 1 的牌；**点横幅前先收店**（extras `shop_cards` 在场 / 画面命中本屏 = 金币店开着），误购可对账卖出回血。analyze 命中本画面时 extras 返回 shop_cards（五槽：名称/阵营/费用/星级）/gold/levelup_cost/refresh_probs。本画面是花金币的地方（买牌/买经验/刷新）；想拖角色上场或出战，先收店——收店（「按钮-收起」）是本画面的收尾动作。

- 备战席满时买牌 op 静默失败：无报错、金币未扣、牌不入席——买牌前自查 extras.bench 有 empty 槽才买。
- extras.shop_cards 出现 kind=unknown 且 faction='?' = 主角昵称卡（这类卡识别认不出名字）——可买，是 3 费主角单位，计入同名合成计数。
- **席满时第 3 张同星入队 = 合成机会静默丢失**（真珠三连：满席购入未合成，卖卡腾位后也不回补），**「席内拖拽合并」手势 V4.7 失效**（席内拖拽只移卡不合并）；操作纪律 = **买第 3 张同星前必须留 ≥1 备战席空位**。
- 遇同名未合成时先读图核对三份的**星级是否一致**。
- 可合成或可升级的商店牌：牌顶的金色✦上下浮动，牌框带金边。
- 刷新：各费用卡出现率参考「货币战争-商店刷新概率表」（见同目录的画面文档）。

吞点击纪律（跨动作类型）：

- 买牌吞点击间歇模式：同一备战期内仅首次买牌点击生效，后续买牌点击被游戏吞（1-1 教学期例外，无此现象）；收店重开、微距拖拽都解不开；呈间歇性（同一局前期正常、后期出现）——连买多张时每张买入后重读 extras 对账（gold 扣没扣 / bench 入没入），发现未生效别硬重试，先读图确认状态再等恢复。恢复边界 = 自然恢复、不按下个备战期承诺（可能连续两个备战期都吞买牌——金币不扣、牌不消失，之后自然恢复）。
- 吞点击间歇模式（跨动作类型）：出战没反应，先查本篇的三个已知原因——商店其实开着（点出战只是收店）、「备战席已满」横幅在场（出战被忽略）、回备战的动画没走完（点击不生效）；都不是，再按间歇模式处理。出战、买牌、买经验都会被吞（点击发出、画面原样、金币不扣动作不生效），间歇出现、原样重发或等恢复后自愈；处置不变：每次点击后对账（读数变了才算生效），未生效别硬连点，先重发一次再不行就等下个动作窗口。
- 三位数金时买经验吞点击异常：gold 三位数（如 103）时买经验按钮可能连吞（点击发出画面原样、金币不扣），低位数金未见此象——可能是 UI 遮挡或金额显示溢出触位（三位数把按钮区挤变形一类）；与跨动作吞点击间歇模式区分（本异常与金额位数相关）。遇到时先读图确认按钮形态与金额显示，再重试；连吞两次就等下个窗口，别硬连点。
- 投资策略三选一卡吞点击：三选一卡可能前几次点击不选中、再点才选中（选卡交互本身见「货币战争-投资策略」画面文档：点六边形图标区才选中）；处置同上，对账重试有效（每次点击后看白框亮没亮，未亮重发一次）。
- 开商店态拖拽静默失败：开商店态下拖拽部署/合并**静默失败**（拖拽发出、画面原样、动作不生效）——同一坐标，开商店态拖拽失败、收店后成功。**部署/合并等拖拽类操作前必须收商店**（与出战前置收店同族）+ 失败即换目标不硬重试（对账处置同吞点击）。

出战前置与读数口径：

- extras.bench_overflow：「备战席已满」告警横幅在场(True) = 拒收队列非空（有单位被游戏拒收、排队未入席），出战会被游戏忽略——先 `CwSellBenchBySlot` 卖角色腾位，**横幅消失后**再出战（卖一格可能被排队角色补位回填，机制见「货币战争-备战」画面文档「告警-备战席已满」行）。备战席 9/9 但横幅不在场 = 可正常出战。横幅商店态也可见。
- 横幅在场时出战静默忽略（例：备战席 9/9、横幅在场、lv5 部署 4/5，点出战后仅按钮按压高亮、画面零变化）：无战斗、无结算、金币不变；横幅在场时先卖角色腾位，横幅消失后再出战。
- 开商店态 front_line/deploy_count 为 null（完整读数收店后再取）；商店态 board 子集可能失真（例：读 击破1/守护1，真值 2/2）——羁绊计数勿用商店态 board，以 units 全局计数为准。
- 晶矿识别在此画面不可用（reward_ores 键省略）——**键省略 ≠ 晶矿消失**：商店开启态的读数省略 reward_ores 整键，不是晶矿没了，收店后原样在场。「选择主角」屏态屏蔽晶矿：备战处于主角光环选择环节态（右下按钮 = 「选择主角」）时，画面判定仍可能命中「货币战争-备战」（备战锚照常命中）——此态点击晶矿零生效；先完成主角选择解锁备战再拾矿。
- 回备战后商店会自动展开（哪些时候会，见「画面简介」）——等回备战的那段动画走完、analyze 确认画面以后，再决定开/收，不要盲目再点开商店。
