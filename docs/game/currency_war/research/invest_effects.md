### 0.1 Fate(圣杯)任务链原文细节

**2026-08-24 从 git 历史补记;攻略存档(sources/V4.4_阵容_命运圣杯红A)已删[eb9c72a1],此为仅存记录;信源=过期攻略存档(版本 V4.4,已被 V4.4 实测部分推翻),与官方 API 深读结论分立,勿混写**:
**证据分级更新(2026-09-25)**:触发结构与注册表互证——`src/sr_od/application/currency_war/data/cw_factions.py`「命运圣杯」tiers=(2,3,4,5) + trait「提供祈愿试炼…难度和奖励随羁绊等级提升」,以注册数据为准;首次达档触发(降档再回不弹)= 玩法负责人估计待实机核;难度表/激活门槛/高难任务样本 = 攻略存档孤证(无注册表对应物),消费按此分级:

- **触发结构**:任务在 Fate 羁绊展开 **2F/3F/4F/5F 时各触发一次二选一接取**;难度分红(难)/蓝(易),羁绊等级越高越难 + 奖励越好(5F 有概率刷 8 个完美投影仪 +「实现所有愿望的圣杯」)。难度表:2F=2 蓝;3F=2 蓝 或 蓝+红;4F=蓝+红 或 红+红;5F=必红+红。
- **★激活等级门槛**:3F 接的任务至少开 3F 羁绊才算进度,5F 至少开 5F;未激活 → 面板显示「未激活」,做任务全部不算数——**花资源做任务前必确认激活状态**。
- **高难任务样本**:鲜血神殿(后两场战斗额外 -20 小队生命;未激活则每节点固定 -20 + 致命,即使断连胜也应优先处理);5F 令咒协议(凛在场 → 立刻损失 88 小队生命 + 所有金币,换 8 个持续 1 节点的完美投影仪;血 <88 不能接,且当关用完);愿望圣杯(最高奖励,无需做任务,直接完成此前所有 F 任务 + 合成所有 3 星 F 角色 + 圣杯装备进阶版 + 1 个改件);诅咒圣杯(赠全队 50% 暴击 + 100% 暴伤,但清除此前所有 F 任务并替换为诅咒装备任务,「3-4 之后无论如何不要接」)。
- **经济定位**:即使不奔任务去,遇 F 角色顺路买下开任务看奖励(部分直接给且丰厚);圣杯改件(如阿瓦隆)不一定给 Fate 角色,可给任何能量组 C。

## 1. A 类:金/XP 流(按建模难度分批)

### 批 1 等级触发日程(结构最简)
- **成长基金**(银):到 9 级 +40 金 → `calendar_at_level(9)`;9 级是终局等级,收益按残值权重折现。
- **成长的快乐**(银):8 级后购经验单击 −1 金 + 立刻 4XP → 条件突变(状态含等级,DP 可表达)。

### 批 2 时点日程
- **超发货币**(金):失去所有金,5 节点后获「该数+70」→ 负债日程;风险 = 窗口期金为 0 无息,DP 可算精确分界。
- **增发货币**(金,环境 id 103):「第一/二/三位面开始时,获得一个 6/8/12 金币的晶矿」(原文直读)→ **位面开局声明矿流程模型**(与超发货币为两张不同卡):每位面开局金晶矿经声明矿通道(`cw_investments.ENV_ORE_GRANTS`,世界发放域)声明 → 矿进入世界时附着(`ore_rewards` 随机态域,占哪个矿归属 rng 掷)→ 点击兑现入账;估值面 `ENV_ECONOMY.gold_per_plane_start=(6,8,12)` 同出卡面(双源同值校验防漂移)。呈现面(晶矿色档/自动开启与否)未实采,sim 按「呈现可点」建模,披露键已登记(`ORE_PLANE_START_PENDING`)实机首遇校;策略面按「晶矿自动开启」假设已登记(证非自动 → bot 具备开矿动作前该通道 fail-closed,`env_economy.ENV_ECONOMY_PENDING_VERIFICATION`)。
- **二手市场**(环境 id 106,B 类通道):「商店刷新20次后,获得30金币和【员工投影仪】。」(原文直读)→ **刷新次数触发器世界发放**:计数域 = 全量(免费+付费,desc 无「花费金币」限定词,与长线利好 id 120 显式「花费金币进行30次刷新」构成官方文本两域对照);一次性(达标发放一次,`env_grants_done` 封账,条件键 `refresh_threshold`,域规格 = fields.md §3.5.5);世界发放 = 模拟器与实机在每次商店刷新上报的末尾统一检查触发(登记表 `cw_investments.ENV_REFRESH_GRANTS` + `kernel/cw_env_grants.check_env_refresh_grants`);达成时同一窗口内记三笔账:金币(`write_logic`)、装备(随机,`write_logic_rand`)、完成标记(`env_grants_done`);估值面 `ENV_ECONOMY.gold_after_refreshes=(20,30)` 同出卡面(双源同值校验防漂移);【员工投影仪】投放使用效果维持 §5 放弃(本条只管道具入世界)。
- **人才激励/+**(银):投影仪发放(资产类,无数值,§5 裁定放弃)。
- **恢复生机**(银):终 boss 后回 40 血 → 仅影响积分不影响胜率,不建模。
- **偶像经济**(棱):礼盒内容无数值(放弃)。

### 批 3 动态依赖收入(最有建模价值)
- **被动收入**(棱):每节点 XP = 备战席最左角色基础费用 → 板面决策与 XP 流耦合(高费卡放最左)。
- **狸财经狸**(棱):30 本金/每回合利息 +2/金<20 取 10/位面 3 首次领取全部存款——desc 四数值全明,可建模。
- **星际和平保险**(棱):立刻获 = 已损血数的金 + 战后回 10 血 → 血金互兑。
- **不等价交换**(棱):交换小队生命值和金币 → 血金互兑(勘误 2026-08-31,血金互兑定价通道裁定:原「λ_hp 定价框架用例」口径作废——按 [40] 裁定 hp 定价通道作废,血金互兑类按公理 3 出域、选卡评估分覆盖,交换后保守 clip)。

### 批 4 行为条件流
- **存款回报**(银):上节点没花钱 → 2 免费刷(期权成本进每回合决策)。
- **招财狗**(银):胜利且无损 → 每佩佩 +1 金(微量,策略层现金分未建模登记,量级在此声明)。
- **星星相印**(银):每合 3星 +5 金(一局 1-3 次 ≈ 5-15 金)。
- **气氛组/+**(银):战斗后每 2 个零伤角色 +1XP(+即时 8XP)。
- **深井角斗场**(环境 id 104):本局首次达成 5 连胜时获得 1 个财富宝钻 → **结算连胜触发器**(`cw_investments.ENV_STREAK_GRANTS` 白名单首例):条件判定在战斗结算时点(连胜真值落账后 `kernel/cw_env_grants.check_env_streak_grants`,live/sim 结算接线同调),「本局首次」一次性由 `env_grants_done` 标记承担(域规格 = fields.md §3.5.5)。发放 = 财富宝钻进装备库存(随机态写——宝钻落位不可观察,`write_logic_rand` 可能世界快照;实机由下一备战帧 equips 观察覆盖差异自动纠偏,**呈现面无新增**);宝钻获得的世界数值联动 = diamond_count +1 / deploy_cap 重算(level+财富宝钻数)/ back_layout +1,仅 sim 侧回调(`on_diamond_acquired`),live 归观察域。

### 批 5 期权类(额外选卡权,6 条)
- **黄金/彩虹期货/+**、**白银/黄金投资**:N 节点后(或立刻+延迟)一次不可刷新三选一 → `期权价值 = f(品质池分布, 剩余节点, 已持效果)`。
- **策略大师**(环境):每获策略 +2×已持有数金(累计 ~2n²,n≈6-8 → 40-70 金,被低估的环境)。
- **联席决策**(环境):2-6 节点额外一次策略三选一(位置固定 → 日程确定)。

### 批 6 XP 直给类
经验到账(+10)、孪生素数(首购各费 2/3/5/7/11 XP,一局上限 38)、固定理财/+(位面开始 4/6XP+2/3 刷)。

## 2. B 类:机制突变

- **人身意外险**(环境 id 107,**节点序列修饰类首例**,2026-10-12 已建模):「所有首领节点前都加入一个额外补给阶段。」→ **节点插入型结构效果**:每个 boss 位前插一个 supply(位面 1 9→10、位面 2 7→8、位面 3 7→8;规则单一源 = `cw_node_schedule.ENV_NODE_REWRITE_RULES` 统一注册表插入型规则 + `resolve_plane_node_seqs`,2026-10-15 起插入/替换两类共用一张表),插入的补给是备战画面可观察的真实节点——修饰结果在环境注册时落 GameState 场字段 `node_seq_by_plane`(写点唯一 = 获得链尾段),节点序坐标系改按局修饰变长制(正反解/next_screen/观察锚定/效果账本登记快照全量读场字段,round 读数上限随场字段放宽到 10/8/8),插入节点全链走现役 supply 通道零新行为分支;「N 节点后」类效果差值在修饰制下 = 真实节点数,与游戏语义一致。
- **战争边疆**(环境 id 117,**节点替换类首例**,2026-10-15 已建模):「第三位面的所有战斗节点都替换为遭遇节点。」→ **节点替换型结构效果**(与插入型同挂统一注册表 `ENV_NODE_REWRITE_RULES`,规则 = `('replace', 3, 'battle', 'encounter')`):位面 3 的 battle 槽 1:1 换 encounter(默认 P3 = 战斗→战斗→补给→战斗→遭遇→奖励→boss,替换后 3-1/3-2/3-4 = 遭遇,节点总数不变);位面 3 默认序列已随用户裁定入代码真值表(2026-10-15,`PLANE_NODE_TABLES` 增 P3 行,证据与边界 = [plane_schedule_observed.md](plane_schedule_observed.md)「裁定记录(用户,2026-10-15)」),本卡替换**真激活**——非「域外登记」形态。**词义边界(用户裁定 = 类型读法)**:「战斗节点」= 节点类型词表中的普通战斗,奖励/首领/补给/遭遇四类不在替换域(四轴论证 = 投资环境迭代设计 T-18 §2.3:卡文体系「战斗/奖励/遭遇/首领」分立用词互证)。**申报与复核义务**:①证据链上 3-4 格存在单局结算标「遭遇」vs 节点条读「战斗」的冲突(疑骇入干扰),按裁决取节点条读法 = battle 入真值,后续实机位面 3 局逐格复核义务随 [plane_schedule_observed.md](plane_schedule_observed.md)「位面 3 观测现状」在册;②替换后 P3 遭遇(高危节点,combat.md §3)数量大增而遭遇战力标定无 P3 档,标定缺位在册不建模。bot 侧处理:解析单点 = `resolve_plane_node_seqs` 规则解释器,环境注册时落场字段,观察/live/sim 全消费面读场字段自动跟随,零新流程分支;sim 走完位面 3 = 胜利终局(披露键 `run_complete`)。原设计披露键 6(P3 支持落地时的复核义务)与 7(live P3「声明恒局终」怪现状)已随本批闭环。

## 7. 金变效果三分归类(登记制)

策略层的金位账面协议(读数与记账,develop 侧 23 号篇)需要知道「哪些效果会改金、何时入账、何时失效」——本节按金变效果的**入账/失效形态**归类。**登记制**:新增卡进 `cw_invest_data.py` 注册表时按本节归类(代码注册表先行,research 同步滞后不失义);漏归类由会话入口再锚定收敛 + 账面-实读偏差侦测暴露——定式层闭合 + 变体卡显式归类 + 组合态兜底 = 协议完整形态,不宣称全闭合。

| 类 | 判据 | 已登记成员 | 协议侧处置 |
|---|---|---|---|
| **单卡伴生入金(记账层,4 张)** | 卡面「X 动作时 +Y 金」型——金额确定、与某类动作帧绑定 | 返利/返利+(每购买 3 个 5 费角色 +3)、合并同类项(刷新出 2 个相同角色 +1)、节节高升(任意升级 +1) | 按 X 动作帧以卡面确定金额直接入账;变体卡含同型卡面文本即入本层。「经验就是财富」(XP→金持续转换)显式归类 = 节点切换失效天然吸收(入金时点 = 自然经验结算 = 节点边界,失效先行) |
| **事件级失效(失效族)** | 金变在特定事件帧发生、金额或时点不完全可预枚举 | **选卡族** = 任何选卡帧(三选一 + 二选一〔令咒协议等含清金类效果〕——选中即失效,不枚举单项效果);**合成族** = 任何 3★ 合成结果帧(星星相印 +5——不分源:买入/消耗品/补给选卡/策略直发任何持有凑三即合);**晶矿族** = 点晶矿(普通金 1-5 随机 + 增发货币金晶矿 6/8/12 逐位面确定 + 三选一);**升级 9 级**(成长基金 +40,非伴生型独立失效);**计数达阈族(2 张)** = 二手市场刷满 20 次 +30 / 长线利好第 30 次付费刷新 +20(计数达阈帧失效,阈值帧兜底) | 事件帧触发账面失效(失效后以实读重锚);计数达阈族按帧计数在阈值帧兜底 |
| **组合态(兜底)** | 无单卡卡面「X 动作 +Y 金」文本的组合效果(组合空间不可枚举) | 如 经验财富×孪生素数(买入帧 +2/3/5/7/11)、保险×奋斗协议(血→金转换);「经验财富×淘金客(刷新+2)」两卡面均无单卡动作入金文本,按排除判据同归本层 | 不枚举——归会话入口再锚定 + 账面-实读偏差侦测兜底 |
