# 战斗结算（挑战成功 / 挑战结束）

**识别**：结算画面（挑战成功/挑战结束 + 继续挑战按钮；含金币明细 基础/利息/连胜 与掉落晶矿、逐角色伤害统计）。
**目标**：领结算信息回备战。
**能做的事**：
1. 点「继续挑战」（约 960,895，静态点击有效）。
2. 读金币明细与逐角色伤害（判断 comp 表现）。
3. 战斗期操作（自动战斗自愈、点空白加速、倍速、暂停浮层）：已迁至「货币战争-战斗」卡,从那里查。
4. 团灭/位面结束结算链：OCR 找「前往结算 / 下一页 / 下一步 / 返回货币战争」逐页点进（找到哪个点哪个）；「返回货币战争」落回大厅 = 终局出口，之后按「终局结算」卡口径收尾（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。战报页（含「返回货币战争」的结算末页）为锁光标画面——analyze 返回 pc_alt=true，点击需带 pc_alt=True 否则落空（实测）。
**坑**：点出战后战斗自动运行约 60~90 秒，期间画面为 `货币战争-战斗`（已建档）——等结算画面出现再操作；回备战后先收晶矿再开店。
