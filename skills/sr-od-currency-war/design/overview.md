# overview：sr-od-currency-war

## 是什么

教一个全新上下文的 agent 通过项目 MCP server 玩货币战争（v4.7 入画奇航赛季）的玩家 skill：进大厅 → 开局 → 节点循环（备战/商店/遭遇/补给/BOSS/主角光环）→ 终局结算，全流程 observe→act。

## 状态

draft（操作部分已按三局实机走查沉淀成文；未做干净子 agent 实测）

## 动机与关键决策

- **按画面组织操作参考**（用户定）：每个画面一张卡——识别什么/做什么/用哪个 op/怎么验证/坑。样式对标 sr-od-game-coach 的操作路由风格（触发条件 + op + 参数 + 验证）。
- **全局交互铁律放 SKILL.md 正文不放 references**：胶囊按钮微距拖拽、卡片图标点击、op 静默失败重跑等坑的触发条件 agent 自己认不出（它们跨画面出现），按需文件会想不起来读；画面专属的坑随画面卡走。
- **op 只封装动作不封装决策**：actions 包 op 参数为简单类型（槽位/次数/坐标），「买什么/选哪个」的决策留给 agent 读 extras 后自行判断；skill 相应地只教「怎么操作 + 判据」，策略深度（经济曲线/comp 运营）刻意从简——首版以操作可玩为目标，策略迭代留给后续版本。
- **主角光环的拖拽源用坐标参数**：光环画面的角色预览槽居中排布、位置随部署数变化，无固定槽位 area——源坐标由 agent 从当前帧读出后传参（观察即输入）；槽/卡/确认的目标坐标走画面档 area（坐标单一真相源）。
- **命名**：sr-od-currency-war（用户定）。与 sr-od-dev-currency-war（开发 skill）分界：玩家 skill 不谈代码与流程改造，只谈怎么玩。

## 实测教训（已沉淀进 skill 的坑）

- 胶囊形按钮（出战/各类确认/开始对局）对静态点击免疫，微距拖拽才生效（双局交叉实证）
- 投资策略卡片要点图标区才选中，标题/文字区点击无效
- 主角光环画面三步交互（点卡/拖槽/确认微距拖拽），静态点击大面积无效
- 羁绊面板 OCR 只是滚动窗口的可见子集，决策以 SIFT 单位表为准
- 晶矿掉落物会使备战席槽位位移，拖拽部署前必须重读
- op 偶发静默失败（商店开关），动作后下一帧对账
