# 阿格莱雅·连击奇兽(A4 · 5 费 carry · 双 C 制 + 奇兽花园双核)

> 一句话定位:5 费阿格莱雅(奇兽花园+连击成员[图鉴],帖内「阿雅/金织爵」)与 1 费那刻夏组成前后期双 C,靠「反螺旋堆叠 + 反重力双鞋」的速度连击链输出;奇兽花园(11/11 篇 Final 在场)是与连击并列的第二核——两个角色池高度重叠,凑双羁绊几乎不额外付人口成本。
>
> 家族注:与「那刻夏·连击」(A1)同属连击 turbo 家族 5 费档——搜牌曲线同为速升 9 级(1-2 星即用线);本篇那刻夏双属(奇兽花园+连击)一鱼两吃,既是 A1 的旗舰 C 也是本篇的前期主 C/双核另一端。

## 1. 骨架

- **双 C 制**(本篇签名结构):
  - 阿格莱雅(5 费,前排输出[图鉴]):终盘主 C,1-2 星即当 C,3 星锦上添花;
  - 那刻夏(1 费,前排输出[图鉴]):**前期主 C/保命位**——带主 C 装备打工过渡,10/11 篇在场、常并行追三,后期与阿格莱雅并列双核。
- **功能链常驻**(帖间一致):星期日(2 费连击,9/11 篇)+刻律德菈(1 费连击,信心注入器+电磁弹射器)+白露(2 费,奶)+风堇(4 费奇兽花园成员,奶,9/11 篇)+知更鸟·晴歌(2 费)+花火(2 费前台)+昔涟(4 费,永动机)+寒鸦(4 费连击,速度补)+缇宝(4 费)+藿藿/符玄;镜流(3 费)兼任中期过渡 C/副 C(6/11 篇);赛飞儿(3 费奇兽,翻飞之币承载位)。
- **奇兽花园件**(原生成员 7 人 = 注册表 members[图鉴]):阿格莱雅(5 费)/那刻夏(1 费)/风堇(4 费)/万敌(2 费)/海瑟音(2 费)/长夜月(1 费)/赛飞儿(3 费)。克拉拉/昔涟/遐蝶等非原生成员靠**奇兽花园星徽**转职凑档(帖证)。
- **羁绊档位目标**(档位数值 = 注册表原文[图鉴] cw_traits_data.py,奇兽花园 trait 100202,layers 3/5/7/10):
  - **奇兽花园 3**:「30% 前/后台强度。每 4 点【奇美能量】可招聘奇美拉」;**5 档**:「60%。每 3 点…招聘更多种奇美拉,并可刷新 1 次」;**7 档**:「120%。每 2 点…每个奇美拉星级额外提高倍率和速度」;**10 档**:「300%。奇美拉全体集结!」。奇美拉是召唤物,不算羁绊成员;专属奇美拉可二合一升星;
  - 主档:**连击 6-8** + 奇兽花园 3 标配;副档:云五 2-3(「五骁连携」+10% 伤害增幅可叠加)、治疗 2(全队 12% 伤害减免)、召唤、小小巨人、开拓银轨 2、仙舟舰队 2;
  - 奇兽主轴变体:奇兽 5/6/7/10(见 §6)。
- **自由槽**:镜流(过渡)、克拉拉(10 奇兽变体副 C)、翡翠(黑市经济件)。

## 2. 星级目标

- 阿格莱雅:**1-2 星即用线**(5 费高费口径)——3 星率 0.41 为连击家族最低,「找鞋,前期升一星」「实在不行前期升一星」帖证;3 星是锦上添花不是门槛。
- 那刻夏:**追三线**(1 费低费池)——前期主 C 需要三星撑中期强度。
- 辅助一律 1-2 星:「辅助二星即可过渡,不追求三星」「全队二星 11 人口即成型」帖证。

## 3. 装备配方(逐件到人)

- **阿格莱雅本人**(速度敏感特化,帖间一致):
  - **反螺旋舞步堆叠**(「每次施放普攻/战技后伤害增幅提高 5%,可叠加」[图鉴];特权版 +10%)——多件叠加是本篇装备面特征(单篇最高 4-6 件含特权);
  - **反重力皮靴 1-2 双**(轮滑鞋+轮滑鞋[图鉴];「每回合速度增幅提高 12%」,可叠层)——**刚需件而非散件**:帖证「还是得双鞋」「找鞋」;
  - 火力风暴潮(轮滑鞋+折叠小刀[图鉴])补面板;光速螺旋桨(「每 10 点速度获得 2% 前台强度 + 1% 后台强度」[图鉴]——速度转强度,与双鞋联动);虫洞掘进钻头等散件按情况;
  - 满配特权形态(帖证):反重力皮靴·特权 + 反螺旋舞步·特权 + 火力风暴潮·特权 各一双,双 C 成对配置;
  - 速度依据(帖级口径[米游社]):作者实测「阿雅初始 500-900 速」浮动很大——速度决定出手次数,出手次数即连击收益(社区口径),双鞋压平速度下限。
- **那刻夏(双 C 另一端)**:火力风暴潮 ×2-3 + 反螺旋舞步 + 高周波电锯 + 武器大师 + 光速螺旋桨;特权堆叠与阿格莱雅同构成对。
- **镜流(过渡/副 C)**:火力风暴潮(·特权)或 热血沸腾拳+反卫星狙击枪——打工期装备与终盘装备同链,交接平滑。
- **功能链到人**(各件独立叠加):刻律=信心注入器+电磁弹射器(+胜利之旗/武器大师/财富宝钻);风堇=痛觉阻断芯片+生命之环/掩体生成枪+流星飞翼;晴歌=胜利之旗+流星飞翼+绝对热量;昔涟=永动机(+胜利之旗/奇兽花园星徽);白露=绝对热量+财富宝钻(经济装备:团队规模 +1、每 3 备战阶段 1 金[图鉴])/生命之环+掩体生成枪;星期日=胜利之旗+武器大师;缇宝=行星钻地弹+胜利之旗+闪光手榴弹;寒鸦=物质分解液+武器大师+胜利之旗;克拉拉(10 奇兽变体)=奇兽花园星徽+闪光手榴弹+行星钻地弹;遐蝶=奇兽花园星徽+生命之环+很硬的甲;赛飞儿=翻飞之币。
- **合成顺序**:鞋系基础件**轮滑鞋**是本篇高频优先合成方向(3 篇记录为开局基础件)——先鞋后装,鞋够再合成进阶件(帖证口径)。
- **家族禁忌**:无注册表级冲突。

## 5. 达成路径(流向知识)

- **节奏:速升流单峰**(速升 9 级 ×6 / 速升 8 ×1 / 7 级 ×2 / 6 级 ×1 / 5 级 ×1)——5 费 carry = 速升 9 的家族曲线。
- **开局(位面 1)**:那刻夏(1 费)+刻律+星期日+白露(+晴歌)保命起步——帖证「前期那刻夏保命」;装备先做鞋与反螺旋给那刻夏;顺手凑奇兽花园 3(那刻夏自带奇兽属性,不额外付人口)。
- **中期(位面 2)**:镜流作过渡 C(「夏老师起步→镜流流过渡→金织爵带飞」帖证三段时序);风堇/寒鸦/知更鸟二星过渡;「找鞋」贯穿全程。
- **阿格莱雅到手即定阵**:1-2 星直接落位前排吃满装备,那刻夏转双核另一端(或按人口卖一星换速度件)。
- **终盘(位面 3)**:9-12 人口;连击 6-8 + 奇兽花园 3 起步,能量富余升 5/7 档;双 C 满装收割。
- **成型判据**:阿格莱雅到场 + 奇兽花园 3 + 连击 6 + 阿格莱雅至少一双反重力皮靴。

## 6. 流派与降级

- **流派判定:单流派(节奏不双峰),三种羁绊底盘**(奇兽花园在底盘间是可调主轴,与连击互为双核):
  - 底盘 1 连击主奇兽辅:「6 连击 + 3 奇兽花园」(4 篇)——主流;
  - 底盘 2 奇兽主连击辅:奇兽 5/6/7/10 为主轴(3 篇)——10 奇兽 + 4 召唤时连击只剩 4,奇美拉军团当输出;
  - 底盘 3 双龙吟凑 8 连击:「2 双龙吟 6 连击 + 奇兽 3」(3 篇)——连击原生 7 人[图鉴],第 8 人靠双龙吟选连击或连击星徽(雪衣转职帖证)。
- **降级路径**(帖证指令级):
  - 阿格莱雅 5 费搜不到 3 星 → 1-2 星照打(即用线本来就是低星口径);
  - 前后期衔接:那刻夏与阿格莱雅互为前后期主 C,前期装平滑交接,无断档;
  - 人口不够全上 → 卖一星阿雅/那刻夏换寒鸦补速度(连击家族通用手法,镜流簇同款);
  - 知更鸟抓不到三星 → 两星兜底;辅助全队二星即成型,不强求三星;
  - 奇兽档位按能量与人口缩放:3 档保底必开,档位不足时用奇兽花园星徽转职补;
  - 10 奇兽变体缺件 → 退 7 奇兽(原生 7 人满编,无需星徽)。
