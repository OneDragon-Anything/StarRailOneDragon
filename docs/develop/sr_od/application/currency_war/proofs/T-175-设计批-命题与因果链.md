### P90(=v3 A1) 前窗奖励帧体系件买入的成本上界与可逆期权(弱支配的界形态)

**命题**:P1 前窗奖励帧(r1/r2,节点表 economy §10.2:P1 = reward/reward/battle/…)上,**零成型域**(目标体系激活档 e=0,与行为面谓词 e<1 对齐)内,买入 1-2 费目标体系件/凑羁绊压库件相对纯攒息**弱支配**,精确形态:
(i) 成本面:单笔买入的全程息损 ∈ [0,3] 金一次性(跨档最坏;档内与金<10 帧恒 0;现注册表口径直算更紧,见 ①);
(ii) 可逆面:1★ 件卖出全额退(无手续费)⇒ 净金成本可归零,买入 = 免费期权;
(iii) 收益面:体系激活进度方向严格正(P20 方向级,e0→1 直辖域,零成型域整体落入)。
合取 ⇒ 最坏格成本有界且可逆(不劣于攒息),激活兑现格严格优。**明示不主张金量纲 EV 不等式**(激活收益的金值化无在册通道;P27 证伪先例——胜率×血计价形态已死)。
**辖域注(轮三中 3 收窄)**:e=1 帧(一档已激活)买入推进 2 档的收益面**不在本命题辖域**——P20 激活边际严格限 e0→1 且明文「e≥1 边际转移回核心 2★/目标件囤积」;e=1→2 推进格的收益载体(羁绊档效果非负机制事实 + 囤积通道替代)**本批不主张**,出辖候单篇补载体。行为面不受影响:面①(a) 谓词为 e<1(零成型),与本命题收窄后辖域重合。

**证明**:
① 成本面:息档 interest(g)=min(⌊g/10⌋, cap)【注,cw_economy】。买入卡价 c 使 g→g−c:g<10 帧两端息档恒 0 ⇒ 损 0;⌊g/10⌋=⌊(g−c)/10⌋(档内)⇒ 损 0([11] 同档零息损);跨档 d≥1 档 ⇒ 息损 d 金/轮。**现注册表口径(轮三低 1 对齐,本批直调)**:P1 基础奖励 r1=3/r2=4/其余 5(REWARD_BASE_GOLD_BY_ROUND,cw_economy :401)+ 连胜成分 streak_gold(0)=1 照发(ADR-0439)⇒ 净收入 r1=4/r2=5/r3+=6(net_income 直算)。1-2 费单价下单笔最多穿 1 档;息档-bearing 跨档最早发生于 r2-r3 帧(此前金<10 恒无息),该窗净收入 5-6(+息)⇒ 1-2 轮回档 ⇒ **单笔一次性总息损 ≤2 金(现口径直算)**,P6 ② 旧界 ≤3 金(其 2026-08-25 收入口径「6-7/轮」)作为保守上界继续引用。窗内总息损有界:零买 r3 末金 ≈20(开局金 5+4+5+6 直算;P6 ① 旧值 26 系旧收入口径,其自注「连胜金是否照发未裁」已被 2026-08-31 裁决覆盖——P6 口径注回改属在册件修正,归文档同步批),笔数天然有界。
② 可逆面:sell_refund(star=1)=面值全额、无手续费【注,cw_state.py :1133-1134 亲读「if star >= 2 and cost >= 2: refund -= 1」即 1★ 无手续费;P76 甲「1★ 全档净 0」】。故 1★ 买入持有成本 = ①的有界息损 + 席位占用(V_slot,P41③;前窗板/席未满为松约束,实现面由现行 V_slot 门兜底),卖出本金全额回收。
③ 收益面:P20(已证·方向级,辖域严格限 e0→1):体系激活 e0→1 次战边际战力 > 散件 1★→2★。零成型域(e=0)内买目标体系件单调不减激活进度且兑现格恰为 e0→1(P20 直辖);零成型域的结构常态性 = 开局板 4-6 混色件、四体系激活档计数全 0(v3 面①(b) per-体系谓词语义)。
④ 合取:攒息收益 = 0(金<10 帧)/息流(两动作同享,买入超出①上界的息损不存在)。买:成本 ≤[0,3]一次性且可逆,收益 ≥0 且激活兑现格 >0(③)。故买 ≽ 攒息(弱),兑现格严格优。∎

### P91(=v3 C1 可证核) 定向刷新方向通道单调性引理(压库同轴 + 刷-升;排序通道出辖)

**命题**:
(a) **同轴引理**:活跃搜索目标(费档 c*,缺口 a−j 张)的每刷命中率对同费非目标已拿走数 c 单调不减——当 a−j ≥ 1 时每因子严格;k=1 格 E[refreshes] = 1/P(hit) 相应单调不增且严格格反号。
(b) **刷-升消费**(引用已证):P5 给出目标费档的搜窗等级(C_interest 边界:c=2→L6/c=3→L7/c=4,5→L10,基价语境)——升级当且仅当更高级 p(c,L) 更大使刷新-升级账占优。
(c) **合取(条件弱支配)**:同预算、同合格集、同息律纪律(P54 floor/R1 账)下,「压库预算同轴买 c* 档 + 刷在 P5 搜窗等级」相对「异轴压库/非搜窗等级刷」在活跃方向命中概率维严格不优者劣——异轴压库对活跃方向 E[refreshes] 恒零影响(P49 跨档压缩恒 0,结构事实),同轴严格降(①)。
**多目标排序通道显式出辖**:「合格集按 E[refreshes] 升序消费预算」需「目标间完成价值可比」前提,该前提非游戏定义量(目标价值差无 λ 纯金流在册账;排序键隐含等价值前提——便宜的低价值目标排前可劣于先追高价目标)→ 卡点 = λ 形态重述候单篇(P51 §F.3 Δλ_death 销毁敞口口径)或支配性论证消参;在此之前多目标帧只做 (a)(b) 两通道,排序语义 = R0 合格集等权,不新设排序键。**调和注(轮三中 1)**:v3 §4.3(a)「升序消费」表述与 §5 C1 行状态已随本批修订同步为本出辖口径(见 §8 修订记录),C1 可证域收窄 = 本命题 (a)(b) 两通道;落码批以本命题与 v3 修订注为准,两处无矛盾。

**证明**:
① 模型(单一源 cw_shop_odds,【注】):两段式——槽费用档数 M~B(5, p(level,c*))【注,REFRESH_PROB 表,与池态无关】;给定 M=m,目标牌数 X~超几何(目标剩余 a−j;同费非目标剩余 (v−1)a−c;m 次不放回)【注,cw_shop_odds.py :123-126「rem_nontarget = (v-1)*a - c」】。
② 单调性:P(X=0|m)=Π_{t=0}^{m−1}(A−t)/(B−t),A=(v−1)a−c,B=va−j−c。∂/∂c[(A−t)/(B−t)] = (A−B)/(B−t)² = −(a−j)/(B−t)² < 0(当 a−j≥1)——每因子随 c 严格递减 ⇒ P(X=0|m) 严格递减 ⇒ P(X≥1|m) 严格递增;全概率 P(hit)=Σ_m P(M=m)·P(X≥1|m) 逐项非负权单调 ⇒ 单调不减,k=1 主格严格。E[refreshes](几何等待)=1/P(hit) ⇒ 单调不增、严格格反号。k≥2 的 DP 期望方向同(注册表派生注 :153「买同费非目标 → c↑ → 目标相对更密 → 期望↓」),完整 DP 论证候单篇。
