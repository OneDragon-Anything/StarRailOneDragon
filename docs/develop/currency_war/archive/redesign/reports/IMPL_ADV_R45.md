## R45-1(高)【证明】χ 缺项的「项级 fail-closed」在换线不可逆面上是判据级 fail-open——方向标签与自家 fail 方向公理矛盾,且标定后取端规格缺失

**位置**:设计 §2.7 修法② 比较式 R44-2 段(「生产口径 C_stay/χ 项缺输入 fail-closed(None 期窗口帧不消费该项,按未定价缺输入申报)」);登记表 R44 对照表 R44-2 证明节步骤 2/3;§5.3 C_stay 对拍锚④ R44-1 修订段(「None 期断言窗口帧比较式不消费 C_stay/χ 项(fail-closed 行为锚)」);§2.10 第 3/4 条与组-端表(χ 无取端行)。

**缺陷**:

1. **方向标签错**。C_stay/χ 是换线比较式**换线臂(右端)的加性成本项**:`E(alt)·(1+δ)+θ+C_stay/χ < E(cur)·(1+δ)`。「χ None ⇒ 不消费该项」= 该项按 0 计 = 换线臂成本取下界 = 换线门槛系统性下偏 = **多换线向**。R44-2 证明节步骤 2 自己的反号构造写得明明白白:「若消费帧 r_true<χ,则 C_stay/χ<真等效轮数=换线臂成本低估=多换线向=换线面 fail-open」——χ_consumed 取 0 是该不等式的极值形态(0≤任何正 χ_consumed,低估最甚)。把一个 fail-open 方向的行为标注为「fail-closed」,是把 fail-closed 公理的对象从**判据/动作面**偷换成**比较式单项**。同构对照:θ/D_min None ⇒ should_switch **整体不评估**(R23-5)才是该公理在本判据上的既有兑现;对「不可逆面的加性成本项」,「不消费该项」与「消费 0」数学等价,方向由自家论证判死为 fail-open。
2. **可达且长期**。前置门(R13-1①)只拦「出口确定性关闭」(输入缺失),不拦「成本低估」——对拍 2 完成(u/V_ms 标定 ⇒ 塌缩出口可用)∧ θ 标定后,窗口帧(默认局 ≈P1+P2 全期,R25-1)should_switch 恢复评估,缺项形态即生产可达。而 χ 的 v3.3 重推导**挂账、落地前槽位 None**(R44-1)⇒ 该态横跨整个「θ 已标定、χ 未重推导」窗口期,不是短暂过渡。R36-1 已定性窗口换线=「必付成本换趋零收益」(必付=L-B2 未变现分支+瘫痪+槽位机会成本;趋零=R31-2 首项=1 使塌缩近封)——C_stay 正是给这笔交易定价、阻止其发生的项;缺项=should_switch 在窗口帧回退到 R36-1 治前的「消费定义域外的判据输出」形态。违 R40-5 自立纪律「不可逆面禁下偏填充」。
3. **标定后取端规格缺失**。即便 χ 标定开闸,其消费端点未入组-端表(§2.10 表无 χ 行)、F6 端点纪律清单不含 χ。方向推导:C_stay/χ_consumed ≥ C_stay/r_true ⟺ χ_consumed ≤ r_true ⇒ 保守端=CI **下端**(且需 r_true≥χ_L 的覆盖语义)。这是每个标定开闸量(V_ms/V_gap/u/V_slot)都有显式行的面,χ 是唯一例外 ⇒ R6-5「实现者遇缺输入自造方向」在换算率维的复发——R43-1 堵的正是这个缺口,堵到 None 期和取端两半都留了口。

**修法方向**(三选一,禁维持现状):① χ None ∧ 窗口帧 ⇒ should_switch 整体不评估,并入「判据未标定」成因族,独立遥测键 `chi_unavailable`(θ 同款,R24-2 分键纪律);② 项级保守等价形态=窗口帧换线臂按不可过处理(与①行为等价,实现形态不同);③ 给金→线推进兑换率一个健康/中血带可证的保守下界(新证明件,过阅读门)。另:χ 标定后取端行(=CI 下端+单调性理由「成本端随 χ 单调减」)补入组-端表与 F6 清单。

## R45-2(中高)【证明+工程裁量】R44-4 第三检测面在 η None 期=合取门恒真元,R40-2「不可判=红」聚合规则未覆盖该面;η 开闸顺序未入 v6 单一源清单(R44-7 同批自律违例)

**位置**:§2.0-3 规格④(「进验收级门三面合取(速率+有效性+域非作用)」「None 期遥测按候选 η 扫描报分布(观察级,不进门)」);§5.1 v6 挂账单一源清单(七行,无 η/D_ε 行)。

**缺陷**:

1. 验收级门改三面合取,但 D_ε 面在 η None 期「不进门」——合取语义下无输出的分判据=恒真元。这正是 R40-2 给有效性判据定性的病(「合取门退化仅速率门的恒绿盲区……层内禁默认无关联、门级却因缺聚合规则事实默认了无关联」),在 R44-4 自己扩出的合取门上原样复发且未带 R40-2 的门级聚合规则。后果:p/θ 先标定而 η 后标定的排期下,顾问可在「用户绑定约束(D_ε 上不动作)完全未验证」的状态过两门生产启用——而该约束是用户确认条件(R44-4 自己定性:授权账性质,降级语义需用户裁定)。R40-2 的处置先例是「不可判=红(禁生产启用)」,本面应同判或显式声明 η 先于 p 开闸,两者都没有。
2. R44-7 同批立「新增挂账一律入本表禁再散落」的单一源纪律,v6 清单七行无 η——R44-4 引入的这条门前置(η/θ 标定先于顾问生产启用)即是漏登的第一例,纪律成立当批即被自家兄弟条目违反(与 R9-1 权威表缺行病同型)。

**修法方向**:D_ε 面聚合规则按 R40-2 同款补齐:η(及 H_eff 所依 θ,见 R45-3)None ⇒ 该面「不可判」,要么「不可判=红」禁生产启用,要么「η+θ 先于或同批于 p 开闸」入 v6 清单行 8 并打空窗申报。二选一显式裁决留痕。

## R45-3(中)【证明】D_ε 逐帧谓词的输入可达性与求值载体未闭合:E=g+Φ̂ 与 Φ̂ 收口(R5-7/R15-2/R19-3)冲突未声明;H_eff 无归宿且依赖 θ,使承诺的「None 期按候选 η 扫描报分布」不可实现

**位置**:§2.0-3 规格④(λ̄_frame·E_frame·H_eff_frame≤η;E_frame=g+Φ̂ 现读;H_eff=血线敞度量(结构观测,θ 同源标定域);η 归宿【拟】)。

**缺陷**:

1. **Φ̂ 收口冲突未声明**。裸 Φ̂ 在判据侧类型不可达是 R5-7/R15-2 的封闭集结论(对外仅①增量算子②布尔敞口比较③差分复合项;R15-2 扩第三口时专门做过与收口的互斥消解),§5.3 模式审计断言明文「裸 Φ̂……不出现在任何判据比较位;判据模块自算 Φ̂=Ī×R_剩余 均红」。D_ε 谓词=对 λ̄·(g+Φ̂)·H_eff 与 η 的**比较**,每帧求值。R44-4 未声明求值落位:(a) 若落升档器/判据侧,直接踩模式审计红线、且构成 R15-2 封闭集的第四口未登记开孔;(b) 若落遥测侧(§5.2 判停门槛消费 Φ̂_nl 有 R38-1 先例),则规格④通篇「守卫」「守卫偏宽」「判定用下端与消费用上端分工」的措辞误导(守卫辖行为面,检测谓词辖观测面),实现者按「守卫」落行为门=越权拦截,与「HP 不进任何检查点/升档器只升不降」的动作面纪律冲突面未划清。
2. **H_eff 双重空窗未申报**。H_eff「θ 同源标定域」且无 provisional 槽位声明——θ=None 期 H_eff 无定义。此时「None 期按候选 η 扫描报分布」扫任何 η 都得不出谓词值(承诺的观察通道在其声称覆盖的整个 None 期不可实现,是「正确实现也跑不出数据」的死规格,R14-2 定性过的错误红线形态);η 与 θ 的双重 None 叠加态无空窗申报。另 λ̄ 判定端=同格 CI 下端:域外/空格回退格帧 λ̄ 无表值——规格④按「触发(保守)」处理过的只是动作面,谓词侧 D_ε 在这些帧的可判性未声明(第三面在这些帧=又一个恒真元)。

**修法方向**:D_ε 谓词收进 horizon/lambda_death 模块内(与敞口比较 API 同位,输出布尔,Φ̂ 不出模块,封闭集只开一个布尔口);H_eff 归宿显式(独立槽位或声明=θ 派生量随批),「θ∧η 双 None 空窗」与「域外/第四态帧该面不可判」按 R24-2 空窗纪律申报;「守卫」措辞全部改「检测谓词」,行为面/观测面分工一句钉死。

**缺陷**:用户确认约束的是**标定域**(θ 候选值上界 ≤15),不构成「hp>15 帧非真濒死」的世界断言。R40-1 的 gap 分键(`advisor_gap_delay_1534`)原设计正是监督 θ=None 期 hp∈(15,40]∧键∈C 的不确定带——该期支①(θ≠None∧hp<θ)不可判、支③只辖 hp≤15,这些帧全部按帧 1 处理、arm2 延迟被放行,恰是残余账成因③(R39-1「λ 顾问自身延迟」)最需要独立归因的子域。R42-2 打「待确认后生效,当前按 ≤15 ⇒ gap 键恒 0」把该带的分键摘掉:主联合键(`advisor_lambda_armed`×arm2 延迟×死亡事件)仍在、风险可观测,但该子域与普通健康帧延迟混计,归因面粗化(与 R24-2 分键纪律的方向性冲突,非正确性错误——正确性由主键承载)。
