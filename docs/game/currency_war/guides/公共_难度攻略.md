## 跨难度总则(选择 >> 努力)

UP 测了 ~50 把不同主 C 通 A830 后的核心结论:**选择远大于努力** —— 很多角色 / 阵容选出来就注定只能上一分,跟发挥无关。每版「试用能玩」的阵容在缩小,需本体 / 关键命座的在增加。**选对主 C 比操作重要。**

## 中期过渡框架(V4.0 选修一,通用)

**前期(第一位面)**:1-3/1-4 开 **2DOT + 2 列车** 或 **2DOT + 2 贝洛伯格**;1-6 前开 **3 仙舟 + 2DOT / 4 列车** 能跟 1-7 掰手腕。靠**拉满基础伤害**过渡(只有 1-7 有翻车风险)。

**1-8 分界线**:奖励关**把前期过渡阵容全卖吃利息**(过渡阵容打不过 1-9,早卖发挥剩余价值)。第一位面不硬 D 到破产 → 连胜每段经济不差 → **不卡利息把经验点到 5 级 18-20** → boss 关**免费白嫖一次 6 级商店刷新**。

### ★中期护航三套(6 级正式构筑,无需本体 + 极低造价 + 第二位面稳定连胜)

| 护航阵容 | 羁绊 | 关键配置 | 服务对象 |
|---|---|---|---|
| **龙丹护航** | 4 战技点 + 3 仙舟 | 吃前台花火风套翁瓦克;1-9 D 2 星龙丹 + 花火/克拉拉/爻光/藿藿 + 任意生存 | 直伤(速 8 找火花 / 速 9 找红 A❓) |
| **灵砂护航** | 4 击破 | 吃缇宝风套翁瓦克;6 级 D 2 星灵砂 + 1 星星期日/缇宝/阮梅/万敌❓/大丽花;有钻头就能玩 | 击破(转流萤合风暴潮 / 转波提欧合风扇) |
| **阿雅护航** | 3 昼神 + 3 能量 | 吃缇宝风套翁瓦克;2 星阿雅 + 双鞋 → 稳定打穿第二位面 | 邪修(DOT 队前期强度需阿雅过渡) |

**核心要领**:1-9 后组出 **2 星护航带队完全体 → 不再为这阵容花钱** → 攒钱速 8/9 找真主 C(多打性价比)。

**分水岭 = 2-7 / 3-1**(护航护到这节点结单)。护航 2-7 前没炸单 + 攒了经济装备但换阵容就输 → 要么第一排运气差,要么该换阵容上分了。

**不适合这 3 套过渡**:黑霄❓ / 万敌 / 狼队 / 夜神 / 学者(成长型角色 / 羁绊,需叠被动 / 升等级从头到场)。其他阵容都可用这 3 套过渡,熬过中期 2-7 变阵 → 正常有配置的主 C 就稳定通关。

## A830(V4.0)—— 最纯粹血量膨胀

- **boss 血量**:最少 200 亿;有首领强化等 → 400 亿起;拉满 → **1000-1500 亿**总血量。
- **斩杀线**:血量膨胀全局 → 一关输出不够 → 断连胜 → 断经济 → 触发斩杀 → 没钱 D 大成 → 被 boss 踹飞。→ **刚需高质量开局**提高斩杀预值(只刷转职开局完全打不过;刷新投资环境一整把顺很多,如惊喜礼盒通用开局 / 火花队战技点契约 / 波提欧加拉赫专家)。
- **前期过渡变化**:3 仙舟 + 2DOT **不稳**(A830 不提升羁绊基础伤害 → 怪血翻倍但 DOT 伤害就那点)。最顶级过渡 = **3 巡猎**(龙丹变巡猎羁绊 + 藿藿变伊费卡❓),可叠开 2 列车 / 2DOT。
- **新 boss 基础血量远高老 boss**(金血一铃❓/莱古士❓肉没边)+ 狂化框 / 首领强化 / 第三位面强化 → 尽早决定跑路。
- **灵砂加强到点**:兔子保人从一次三只 → 三次一只,奶量大加强 + 户口优秀 → **优质通用生存位**。
- **试用能玩只剩 阿格莱雅 + 火花**;之前试用能玩的需本体,之前需本体的需关键命座。
- **★3 量子 = 直伤暴击阵容最泛用极高强度插件**(花火加强后 +30% 易伤 → 花火/银狼/符玄 3 量子同屏全员恶人:暴伤/易伤/减抗/减防/幸运一击全有,3 张卡拉满 5 乘区)→ 基本所有直伤阵容可把不关键牌换 3 量子。
- **不推荐 3 费主 C**:追 3 无奖励、不追 3 有惩罚;0+1 2 星 7 人口 3 费主 C 第二位面连胜极难 → 斩杀效果在 3 费主 C 最显著。
- **DOT 队不推荐**:4DOT 第一位面连胜都做不到,第二位面被抽陀螺;V4.0 修复海瑟音深海回响 bug + boss 转阶段清空层数 → 雪上加霜。

### 阿雅 A830 标准配置

不带 C 本身拉个下❓;前期 3 能量 3 昼神 + 空位上拐打 N 拐 1(如阮梅克小电视❓);**不把羁绊往高开**(4 昼神 / 5 能量对阿雅提升极小)。**可不硬 D 3 星**(2 星牌顺顺手追 3,不顺放弃)→ 斩前猛拉人口速 9 → 全部斩得上 9 D 找**饮月 + 银狼❓**(这 2 张齐 = 阿雅随便 0T 平推)。银狼❓手捏 12 层大招(羁绊死了阿雅再召唤立刻补满被动);银狼大招尽量全给阿雅;需永动机多次开大。

### 负面词条放大

- **正当防卫**:A830 怪攻比 A820 +15% → 生存压力极大活不了 → 见就跑。
- **首领强化**:尾王速度达 1615 ≈ 6 行动值一动 → 生存拉满。
- **时间刺客**:战斗官概率出黑厄中期分身,每次行动扣 7 行动值,速度跟小怪提升,第三位面 7 行动值移动一次扣 7 行动值,需优先集火。
- **变宝为废**:每位面第一次合装备拿电子小装备把 50% 概率电掉(别拿暴击刀 / 鞋赌)。

## A840(V4.2)—— 小怪血量涨幅明显,压力在道中

- 血量提升 = A820→A830 的 **1.93 倍**;与 A830 不同:**小怪血量涨幅比 boss 更明显** → 有试用本体的强势阵容都难做到 15 连胜。但**初见没 A830 难**(角色加强幅度比怪多)。
- **A840 基本没阵容稳定 15 连胜** → **稳心态,知道阵容 / 词条何时吃连败,别慌别一输拉低杆。想赢的秘密 = 别怕输**(力气还在就还有机会)。

### 关键加强

- **★希儿最夸张**:CW 内只需对面掉到 70% 血以下触发额外战技 → 大幅加快连击❓+ 点风暴潮 + 点贝洛伯格机器人速度 → 素质翻倍、触手次数翻倍不止。
- **欢愉 C 排序**:火花单 C > 5 欢愉银狼 C > 飞霄单 C > 银狼单 C。**欢愉队底层逻辑 = 双鞋爻光(非阿哈)** → 阿哈唯一有效装备 = 火力风暴潮(别听官方做双鞋风扇);鞋尽量让给爻光。
- **游侠体系加强真点 = 不死途(托帕)**:可前台同时被巡猎游侠❓放后台 + 在场提供 40% 减防 + 40% 通用暴伤 + 80% 追击暴伤 → 3 游侠由带 2 挂件变带 1 个。
- **追击羁绊负伤倍率翻倍**:3 追击每次攻击附带 150 → **300** 倍率随机属性追加攻击。飞霄变 1 费 + 不死途替貊泽 → 飞霄大涨(2 星后猛拉人口,不再需追 3)。

### 阿雅 A840 配置(5 版本没加强仍强度 70)

前期带**花火 / 缇宝 / 星期日当拐牌**(缇宝花火尽量全带翁瓦克给阿雅拉条)+ 一位面尽量有鞋出门 + 2-3 补给拿双鞋 → 2 星阿雅第二位面 boss 稳定百亿总伤。第三位面取决于**杨叔何时来**(上 9 晚 → 3-1/3-2 稳定吃连败,第三位面减 30 行动值对阿雅致命;杨叔来 → 随便)。
- ★**带前台花火原因**:花火前期帮阿雅多叠非常多层鞋(阿雅主消耗行动值来源 = 鞋没叠起来的前 10 动;前 10 动跑越快 → 后期更多层鞋)。前台花火帮阿雅叠鞋比星期日还夸张(2 位面 boss 从 20 层 → 40 层)。

### 后期通用:杨叔 + 佩拉 2 减益

杨叔 + 减益羁绊都加强(策划通过加强减益降低刚需银狼 / 记忆主)→ 杨叔佩拉自带 80% 减防 + 30% 增伤,随便拐就溢出 → **4-1 不带记忆主完全正确**。时刻思考哪些角色后台放前排带翁瓦克更好(克拉拉 / 花火 / 缇宝 = 最好翁瓦克发射器)。

**试用档推荐**:阿雅 / 火花 / 龙丹 / 狼尊;有本体推荐希儿 / 飞霄。

## A850(V4.4)—— 有史以来最简单

生存压力略 > A840,但**输出压力显著 < A840**。**核心:所有阵容只需思考一件事 —— 如何上场千冶·刃。**

### ★千冶·刃 = CW 有史以来最牛逼通用插件

- 试用就有 **30 减防 / 50 易伤 / 50 增伤 / 75 终结技增伤❓**(对绝大多数主 C 极其夸张的拐力)+ 户口优秀 + 机制强大 + 后期跟杨叔组 2 减益 = **地表最强通用插件**。基本所有阵容无脑带刃。
- ★**印装备机制**:装备格没出满 → 从 6 件推荐出装随机印一件穿上;3 格出满 → 随机将一件进阶装备变**特选装备**。**星徽 / 简易装备占格也算** → 局内用小件填满刃的格子 → 特选能指定给行星抓地❓ / 特选泡泡枪 / 特选鞋子等超模装。垃圾袋不能占格(会被刃变成金垃圾袋)。
- **有刃本体 → 刃还能当主力生存位**(后台刃常驻血量 >2 万,适合出泡泡枪 + 生命衣/球/绳 → 满盾覆盖前台)。

### 其他加强

- **姬子**:主 C 超一流;也是牛逼拐(无列车转:前台 170 增伤 + 100 暴伤;有列车转:+80 前台强度 + 108% 幸运及暴伤 + 人数 +1)。缺点:当拐与前台没空位阵容兼容性差。
- **★杨叔继承星间旅人羁绊**:给基本所有队伍免费发 **10% 幸运几率**;杨叔自己 + 星间旅人队友多 20% 幸运。一星杨叔随便抽。
- **希儿**:贝洛伯格低费全进专家 → 体验是**加强**(后期强度比上版再夸张 1 倍:贝洛伯格机器人拉小所需行动次数下调 → 成员行动 10 次就能拉小希儿,常能锁轴清两波小怪)。思路:优先找转 + 备转,踢娜塔莎多上拐(2 贝洛伯格 = 原 4 贝洛伯格)。
- **星期日后台削弱**:后台学了知更鸟美德(1 星 100% / 2 星 125% 速度,非 200/250%)+ 失去开局回能 → 后台动得比前台少。**前台没位置 → 星期日该去商店而非后台**(必须上场时才放后台 1 号位吃自己充能)。
- **流萤**:每次更新都加强 → 超一流。标准出装 = **双鞋风扇**(叠风暴潮慢 + 击破效率自拐高 → 钻头稀释严重;5 费巨额基础速度征服 × 鞋速度征服乘算 → 双鞋风扇远超传统出装)。
- **阿格莱雅**:强化普攻视为终结技伤害 → 吃满刃给的全部拐力 → 补强中期(7 人口记忆主没来时)。高难主要压力来自生存(没高压词条 + 黑哨怪开局玩阿雅舒服)。

### 阵容推荐 / 开局

- 试用档无脑**姬子**;有本体优先**希儿**;其他万敌 / 流萤 / 欢愉都不错。能上 A840 就能上 A850。
- **概念股开局强度夸张**(贝洛伯格概念股送希儿 + 娜塔莎;命运圣杯❓概念股送黄泉 + 刃)。不玩姬子主 C 也可**列车转 / 列车概念股开**(前期 4 列车 + 三月七领航员反震随便护航第一位面)。
- **「成长的烦恼」词条**:每次买经验额外 -1 金。干拉上 9 可先买满备战席 → 卖 4 块出去点经验(扣 5 块不扣到负数)→ 无视词条升级。
