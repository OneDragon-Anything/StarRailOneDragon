## 2. F1(高·翻案级)hp 血带轴的单调方向在拟合器中与全链文档语义**相反**——主表数值面系错误方向的产物

**位置**:`p51_v3_rebuild.py` L308/L403-405:板面键与 PL 键的拟合 dims 均为 `[(难度, True), (3, True), (位面/板面, …), (节点, None)]`——血带维 `up=True`。血带下标序 = `HB = ['hp<=15','hp15-40','hp>40']`(hp 升序),PAV 的 `up=True` 语义 = 沿下标非降 ⇒ 拟合约束为 **λ(hp≤15) ≤ λ(hp15-40) ≤ λ(hp>40),即「血越高越危险」**。

**为什么错(证据链,全部实证)**:

1. **全链文档语义是「血↓危↑」**:P51 证明件(`docs/game/currency_war/research/proofs/p51-waiting-cost-lemma.md` L271)「单调性约束估计(**血↓危↑**/难度↑危↑/板面↑危↓)」;`P51_V3_REBUILD.md` L20 同;**脚本自己的 Part 3A/3M 输出头也印着「血↓危↑」**;Part 8 空格外推的支配偏序 `dominates_pl`(L673-674)用「血带≤(血更低更危)⇒ λ(nb)≥λ(c)」——**同一脚本内,表头/偏序用正确语义,拟合器用反向语义**。
2. **算术实锤(不需要跑代码)**:D0×P1×noncombat 列原始率 0.500(n=2)/0.750(n=20)/0.277(n=231),官方拟合三格全 =0.316 =(1+15+64)/251(全列合并均值)。在正确方向(hp≤15 最高)下,该列只会池化前两格(→0.727),hp>40 无任何约束可把它拖上去,0.750→0.316 **不可能**;只有反向约束(要求 hp>40 ≥ 前两格)才强制全列合并。
3. **独立重拟合对拍**(a1_dir_check.py,装载/分带/PAV 全部独立重写):`up=False`(血↓危↑)与官方 `up=True` 在 **35/38 非空格**上数值不同。官方方向系统性:压低濒死格(D1×hp≤15×P2+×battle 0.970→0.877;D0 同列 0.901→0.805)、抬高健康格(D1×hp>40×P2+×battle 0.500→0.877,+0.377;D0 同列 0.667→0.805)。正确方向下拟合值基本贴原始率(0.901/0.759/0.600 等,梯度保留)。
4. **反向约束在统计上也是劣的**(a2_loo_correct.py):改回血↓危↑ 后,板面键 LOO log-loss 0.6810→0.6596、PL 键 0.6653→0.6387,AIC 双降——错误方向不是「保守选择」,是纯损失(约束强迫拟合逆着数据最強梯度走)。
5. **病源传播路径(推导)**:R30 批文档(IMPL_DESIGN L66「单调方向=难度↑/**血带↑**/位面↑」、IMPL_FIX_LEMMAS L1335 同)首次把「血带↑」写成与代码一致的三连「↑」——系对代码行为的照抄转录,与证明件/脚本表头的「血↓危↑」并存至今无人对账。**方向反了不是 v3.2 引入:同一 dims 自 v3.0 起就在**,两轮基座攻击(R1/R2)、R26-R31 六轮对抗、以及「受污格标签体系」全部围绕它的产物打转而未触及。

**后果(实证,按消费面)**:

- **主表战斗列的血量梯度被抹平**:D1×P2+×battle 三血带拟合值全 =0.877,D0×P2+×battle 全 =0.805——「hp 入路由键」(第一轮 R1 修复的核心收益,消掉 0.000→0.904 亚组梯度)在拟合层被反向约束部分回收:同列内查 hp>40 与 hp≤15 得到同一个数。
- **两类受污标签的病因诊断错误**:「仅方向(hp≤15 单调低估)」与「D0×hp>40 池化抬高」不是 PAV+正确单调约束的固有代价——正确方向下 hp≤15 不会被压低(它只在违反时被池化上抬)、hp>40 不会被拖上去。**整个受污格分类学是在给一个 bug 写 taxonomy**。
- **C 集合 λ_U 序、top-k、激活率锚是反向产物**:正确方向下(72 局口径)top-k 变为 D1×hp15-40×P2+×battle / D1×hp15-40×P1×boss / D1×hp15-40×P1×noncombat,top-2 访问率 29/926≈**3.1%**(非 1.9%);#4/#5/#6 的 λ_U 全部打到 1.000。λ 顾问分位触发的**触发集组成**随方向改变。
- **Part 8 支配偏序与表值互相矛盾**:外推上界按「血更低更危」借幅,表值按「血更高更危」拟合——空格回退的「有界外推 λ≤0.667」借的是反向表的值。
- **不受波及的面(推导)**:①键选型裁定(PL 键 vs 板面键)对方向稳健——修正后 PL 仍全面占优且差距更大(AIC 1125 vs 1165,LOO 0.6387 vs 0.6596),**选型不翻案**;②空格坐标/标签的 n 类判据(n<5 禁用等)与拟合值无关,不动;③难度轴、位面轴方向无争议。

**修法(极小改动,大面重报)**:dims 血带维改 `False`(或 HB 倒序),全量重跑:主表格值/CI/C 集合 λ_U/top-k/激活率锚/Part 8 受污标签体系(两类「受污」标签预计大面积消失,改为如实报告梯度保留)全量重报;设计件 §2.0-3 规格① 的 |C| 触发集、§5.2 验收级锚(1.9%/3.6%)、philosophy「同格亚组极差」数字按新表重引;R30/R31 文档链的「血带↑」措辞统一回「血↓危↑」并加一处方向断言(拟合后校验 λ(hp≤15 列)≥λ(hp>40 列)的逐列不违反,防再翻转)。
