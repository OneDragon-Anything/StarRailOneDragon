## 命题(形式化)

设锁线转型帧满足转型臂触发域():locked ∧ fp<1.00 ∧
板满 ∧ 存在逐件守卫合格的 fenced victim v ∧ 卖出后假想态上序 ∩
target 视图 ≠ ∅。臂发射 = 卖 v + 上板一个 target 视图成员。记:

- B_t = Σ_{b∈deployed}[b ∈ target 视图](板面目标线承重计数);
- T_s(σ) = 体系 s 的 achieved 档数(卖出前 σ_pre / 卖出后 σ_post);
- G(σ) = 金量。

**命题**:换血后

1. **B_t 严格增**:B_t(σ_post) ≥ B_t(σ_pre) + 1;
2. **体系档守恒**:∀体系 s ∈ SWAP_GUARD_SYSTEMS:
   T_s(σ_post) ≥ T_s(σ_pre);
3. **金不减**:G(σ_post) = G(σ_pre)(1★ 卖出全额退);

即臂触发是状态空间上的**弱支配转移**。**推论(有限触发)**:每帧
B_t 为整数且 B_t ≤ |deployed ∩ target 视图| ≤ min(cap, |target 视图|),
严格增 ⇒ 转型臂触发次数有限,臂自带收敛上界,无换血死循环。

## 证明

### ① B_t 严格增

v 经资格族放行 ⇒ v ∈ fenced 臂可卖集 = off-line(目标线外)∧ 非
core∪shared 保护(§3.2 守卫链);故 [v ∈ target 视图] = 0,卖出不降
B_t。触发域第 4 合取项(卖出后假想态上序 ∩ target 视图 ≠ ∅,拒因
`post_sell_offline`)保证至少一个 target 成员上板 ⇒ B_t 计数 +≥1。
两项相加严格增。∎

### ② 体系档守恒

`engines_guard` 逐体系判定卖出前后 achieved 档数不减(AIX 逐件求值,
);希儿系取 `seele_system_formed` 单卡二元判定(自
engines_count 提出,禁第二实现);体系集 = GUARD_SYSTEM_TIERS ∪ 护盾
(注册表消费,零硬编码档),模块级断言 ⊇ DEPLOY_FENCE。守卫拒绝帧
臂不发射 ⇒ 发射帧守恒成立。∎

### ③ 金不减

v 为 1★(资格族 `star_guard` 限卖),1★ 卖出全额退(sell_refund
cost-based:1★ = cost)⇒ 卖出回金恰抵,金量不变。∎

### ④ 支配论证的隐藏成本项三层封闭(B_t 增量是定义量,全域成立)

竞争问:转型臂卖掉的 fenced v 若同时是买/演进层候选需求,①-③前提
是否被挖?逐层裁决(设计 v5 §3.3b):

- **锁线期买面**:无竞争,结构上不存在——买面循环集合 =
  `locked_buy_membership` 单一源(全为 target 视图成员),v 不在任何
  锁线期买面候选集内;
- **演进层(合成素材面)**:存在真竞争,守卫封闭——v 同名同星副本
  可能被积累为 2★ 合成素材;可达受损态 = 含 v 计数恰为 2(2/3 未完态,
  合成定义值 3−1,注册表派生零自由参数),卖 v 使进度退 1/3 并挖「金
  不减」⇒ `merge_material_guard` 拒卖;计数 ≤1 帧的进度损失是概率事件,
  不构成在册机制破坏(显式模型缺口,fail 向 = 不换);计数 = 3 在合成
  恒律下不可达(达 3 即合成);
- **出口③垫件买面 / M4 燃料卖**:无同轮竞争,单向弱交互——垫件候选
  性来自在售帧,卖出后回流由既有观测覆盖;M4 与本臂同向。

推论(有限触发):①严格增 + 值域有界整数 ⇒ 触发次数 ≤ min(cap,
|target 视图|) − 初始 B_t。∎

## 边界(如实入册)

1. **单位级面板残差**:1★ 限卖,星级不可读帧 fail 向 = 不换——
   带残差的 victim 不进支配转移(保守方向);
2. **B_t 无权重**:支配论证只数承重件数,不比较件间战力差——「B_t
   相同但战力更弱」的换血不在本命题辖域;
3. **素材概率性残差**:计数 <2 帧卖 v 的未来合成风险不在守卫辖域
   (概率事件,非在册机制破坏);
4. 依赖锁线正确性(locked 判定正确是 target 视图语义的前提)。
