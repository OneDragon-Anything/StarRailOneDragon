# 2026-10-18-levelup-band-gate 迭代设计(总纲)

## 0. 元信息

- 迭代目标:升级触发统一与资金门重定义。裁定来源 = 2026-10-18 用户裁定四条(§1.3);实证来源 = sim 局复盘报告 `.debug/currency_war/deep_review/g_20261018_204854.md` 复盘者附加 C1 条(seed=42 局,死于 P2-R7 boss)。
- 状态:对抗审中

## 1. 问题与动机

### 1.1 现状症状

seed=42 sim 局:P2-R2 金 59,升级整批花 52,花后现金 7——利息收入(每轮 5 金)归零,后续四轮刷新金前提(R2 预算线 50+)不可达,等级 8 的概率收益零兑现,死亡螺旋至 P2-R7。

### 1.2 根因归层(语义层)

1. **触发面多源**:升级触发 = 五臂并集(`criteria/levelup.py::upgrade_trigger`:人口位/arm0/富余段-L3/停留门/概率账),四个非带驱动臂都能绕过「等级该不该升」的核心判据(最优概率带);
2. **资金面失真**:保底金门下界取 `DEFAULT_REGISTRY.boss_floor`=10(「保一档不多保」论证),且放行算术预支备战席活期退金(`entry.py` `_levelup_floor_ok` after_gold = 现金+liquid−批)——发射分支不消费活期资产,预支永不兑现。

### 1.3 用户裁定(2026-10-18,授权文号)

1. 资金底线:升级整批花完后,金位不得跌破**当前局最高利息线**(saturation_line(cap_resolved);默认局 50、利息上限翻倍局 100、买断制自动不设限)。不写死 50,不使用旧保底口径(boss_floor=10)。
2. 触发统一:升级只保留「目标角色在哪个等级刷出概率最好」一个判据(最优概率带驱动);板面坐满等战力义务触发删除。
3. 无目标默认动作:没有未完成星级目标时,自然买经验升级(不停留);停留的唯一理由 = 当前等级正在追星带内。
4. 全量清理:与统一后策略冲突的旧文档、代码注释、死代码全部修订(含「钱多必须花→升级」授权链)。

### 1.4 解决到哪 / 明确不解决

- 解决:升级触发收敛、资金门重定义、凑金衔接、旧语义全量清理(文档+注释+死代码)。
- 明确不解决:**C2(卖出资格仲裁对 obligation 类失效)**——独立缺陷(P78 装配漏拦,复盘报告 C2 条),与本迭代无因果关系;本迭代动机只涉及「低金为 C2 提供了触发场景」,根因处置自成后续迭代(外溢登记,见 §5.6)。

## 2. 方案

### 2.1 升级触发(单判据)

以锁定线星级目标(知识卡 `need_star`)的**最优概率带**(REFRESH_PROB 峰值等级区间,现有 `stay_gate_upgrade_first` 带模型不变)为唯一升级判据,三分派(11 号稿 §2 停留门「可达最优等级」模型承接,依据 = `strategy-docs/11_shop_decisions.md` §2):

1. 存在未完成星级目标 ∧ 其最优带下界 > 当前等级 → **升级**(升到带内),触发键 `stay_gate`;
2. 存在未完成星级目标 ∧ 当前等级 ∈ 带 ∨ 当前等级 > 带上界(纯状态描述,历史升级/自然经验所致)→ **停留刷新**,不升,无触发命中;
3. 无未完成星级目标(全部追完,或锁定线无追星目标)→ **自然升级**(不停留),触发键 `natural`。

辖域 = 锁定后 ∧ 位面 2 已启动(与现行带驱动臂同辖域,依据 = 11 号稿 §2 停留门辖域行)。位面 1 与未锁定期:零主动升级(阶段保护维持:P1 经验自然 5 级、过渡门槛全游戏最低,依据 = 11 号稿 §3 P1 恒不刷辖域注;P2 未锁定窗口靠候选缺件刷新,锁定后带驱动接管)。

### 2.2 资金门(统一)

- **下界单一源** = saturation_line(cap_resolved)(`cw_economy.py`,既有 resolved 链)。买断制 cap=0 ⇒ 下界=0 ⇒ 门恒过,无特判分支。
- **口径 = 现金**:花后金 = 当前现金 − 整批成本。活期退金(liquid)不进放行算术。
- **凑金域判定式**(写死):`凑金域 ⟺ (现金−批 < 下界) ∧ (现金+_bench_liquid_gold−批 ≥ 下界)`。凑金走既有升级凑金场景(备战侧,活期任意星级可卖,依据 = 11 号稿 §4.0 升级凑金行),每帧一卖、重扫续卖,凑至「现金−批 ≥ 下界」发射;候选穷尽 → 整批推迟(帧零动作,拒因键 `levelup_fund_line_defer`)。
- **凑金可达性判定与凑金可卖池的口径分立(申报)**:判定式用 `_bench_liquid_gold`(bench-only 口径,§2.4 保留项),凑金场景可卖池 = 备战席 ∪ 场上无关角色(11 号稿 §4.0)——继承现状两口径分立(行为不变),后果 = 判定不可达但宽池可卖帧 defer,保守向,不做口径合并。
- **豁免**:位面末 boss 决战 ALL IN 花光(`terminal_all_in` 单一源,保留);买断制经下界=0 自动失效。P21 血预算线/危机带(`level_spend_blocked`)**全域恢复**——富余段域内让位授权(20 号稿「无论什么 hp」对出口三层)随出口三层删除而消亡(让位对象不存在),判定不再有 zone_hit 短路,`cw4_must_spend_phase` 相位标志机制一并删除。P21 为已证 EV 判据(11 号稿 §2 拦截层处置行),全域判定与其正本一致。
- 血本位局:资金门无对象(花血非花金),既有血闸(`blood_xp_gate` + P21 串联)保留。

## 3. 关键取舍(备选与放弃理由)

- **富余段域内豁免资金门**(20 号稿方向):放弃——本局实证花穿金后等级收益零兑现,「消费权优先」把本金变成无法兑现的等级;且与买牌面「跌破利息线要例外理由」纪律(11 号稿 §1 金约束门)不一致。
- **发射后强制变现**(先花钱再卖牌):放弃——卖出被 P78 资格拦时金已花穿,不闭合。
- **保留人口位臂作战力兜底**:放弃——用户裁定 2 明确删除;锁定后「等级∈带+板满+等待件」帧旧策略升级开位、新策略停留刷新,等待件滞留为接受的代价(§5.3)。
- **凑金域读法 (a) 仅现金<批才凑**:放弃——发射可达性丧失(现金 60/批 20/线 50 帧本可卖牌守线发射);采用读法 (b)(§2.2 判定式)。
- **凑金可达性判定并入宽池(备战席∪场上无关角色)**:放弃——两口径分立为现状,合并属口径重构非本批语义,保守 defer 可接受(§2.2 申报)。
