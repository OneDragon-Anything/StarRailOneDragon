## 全局规律(跨家族)

1. **追星策略三型**:低费追三线(云璃/绯英/流萤/海瑟音)、商店供给线(开拓家族/经济家族)、不追星装备集中线(击破/DOT——五费只求 2 星)。
2. **跨家族通用件**:千冶·刃(启动引擎/旗手,各体系用法不同)、永动机(全局启动资源,昔涟第一优先)、不死途(巡海游侠任命器)、翡翠(黑市经济)、拉条辅三件套(胜利之旗/蓄能帆/电磁弹射器)。
3. **装备转移链**(打工装预留去向)是通用过渡手法:那刻夏→阿格莱雅/饮月;风堇装→长夜月;万敌巨铠→云璃代穿。
4. **经济开局同构**:老杨(瓦尔特)+列车+打钱保连胜速 8/9 是多个家族的标准开局。
5. **挂机羁绊奖励流**是独立大类(目标=领奖励不吃鸡),自动化建模须与吃分流分开。
