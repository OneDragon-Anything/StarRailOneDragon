# 货币战争-积分奖励（局末达标奖励弹窗）

**识别**：`is_precise` 命中 `货币战争-积分奖励`（锚：「积分奖励」+「本期剩余时间」双文本组合——单「一键领取」会与同类奖励页撞车，别拆单锚用）。
**目标**：局末积分达标时自动弹出的档位奖励页（如 9600/18000 达 8/12 档）——挡在回大厅路径上，识别不出会干等超时。

## 怎么操作（看图口径，不写死坐标）

1. **出现**：上一局结束回大厅途中自动弹（积分达标时）。
2. **领取**：点右下「一键领取」领达标档 → 奖励动画约 1.5 秒 → 点右上角 X 关回大厅。
3. 当前积分 n/18000 与档位 n/12 页内可读（跨局进度遥测，暂无消费方）。

坑：右上 X 的建档 area 坐标与在档帧不符（跨迭代挂账板登记待实机复核）——关闭按钮以当帧看图定位为准，别按档内矩形盲点。
