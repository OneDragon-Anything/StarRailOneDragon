# ADR-0167 认知主权层 v0(认知地图 + 主权混合;09 号)

## Status

Accepted(2026-08-16;K0 前提验证[telemetry 密度-残差分桶]/决策消费端接线/telemetry cell_id 字段待后续)

## Context

09 号提案诊断:每个学习/估值组件都自带局部「低置信→回退」补丁（01 检索置信回退/02 超支撑集退先验/04 不可逆门/06 弱先验不入表/07 低置信回退静态表）——五处各自为政、二值开关、阈值语义不同;且手写 eval 从不被治理（它只是行为已知的兜底,不是无条件正确的兜底）。这与 04 号的观察噪声补丁族同病,没人认领「模型无知」这支。goal 轮次已落地十一个新子系统,多个带学习/先验成分（pool_belief/formation_cost/damage_ledger 的 scale 参数）——治理层时机成熟。

## Decision Drivers

1. 05 号自诊断的死锁（bot 集中玩姬子 → telemetry 全姬子局 → 模型对没玩过的 comp 外推失真 → eval 更不敢选）正是认知缺口的系统性制造机。
2. M1-M22 共同病理之一:自信地在陌生局面用错估值——手写与学习犯同一种错（都不知道自己不知道）。
3. 幸存者偏差防线:plaza 只有成功轨迹,人类没走过的格子 ≠ 不可行。

## Considered Options

- **继续各组件自带补丁**:拒绝 —— 补丁增殖是 03 号诊断的规则栈病程在学习组件时代重演。
- **贝叶斯全家桶**:拒绝 —— 分桶计数 + 分桶残差即可起步（提案 C1）。
- **v0 认知地图纯函数**（采纳）:格子定义/主权/边际/探索价/off-map 分诊;telemetry join 是 v1 数据灌入口。

## Decision

1. 新增 `cw_competence.py`:
   - `cell_id(comp_family, plane, hp, equip)`:四维粗格子（家族×阶段×HP 档×装备档,约百格;数据量解锁细化）;
   - `CompetenceMap.sovereignty`:连续主权 [0,1]（高密度→学习全权;空白→0.2 手写主导不零权;**残差恶化降权——手写引擎同样被治理**）;**密度只降置信不降估值**（未知≠差,只是不稳）;
   - 权重:自家样本 2×、plaza 先验半权×1（幸存者偏差;亲历>攻略）;
   - `irreversible_gate`:认知安全边际（低密度格需 advantage ≥ 1.5×(1+无知度)×stakes;**显著优势 ≥2.5 任何格放行**——边际内保守、显著优势放行,防全局僵死）;stakes（low_hp/boss_pre）再收紧;
   - `exploration_bonus`:富余+低覆盖 → +0.3（活局零头样本,与 05 死局全价互补）;非富余 → 负;
   - `off_map`:低密度标记（[cw!] 独立日志维度;复盘「已知区 vs 未知区」分诊轴——改策略代码 vs 喂数据,修复资源完全不同）。
2. 测试 6 条:格子稳定/主权单调（空白 0.2 < 连续 < 1.0）/权重（prior 半权 own 双权）/边际（同优势已知放行未知拦+显著优势放行+stakes 收紧）/探索价符号/off-map 翻转。
3. 与 04 号正交叠加:04 管「读得准不准」（感知置信）,本层管「这类局面懂不懂」（覆盖置信）。

## Consequences

- K0 前提验证待 telemetry ≥30 局（低密度桶残差应显著大于高密度桶;不成立则撤销只留 C5 分诊）。
- 消费端接线（cw_plan 连续混合权重/telemetry cell_id 字段 schema_version+1）排后;v0 价值立即项 = off_map 分诊（不依赖门控生效）。
- 保守化坍缩防线:探索项反压/惩罚封顶/熵检查（K3）随 K2 校准环境。
- 提案原文删档;决策单一源移本 ADR。
