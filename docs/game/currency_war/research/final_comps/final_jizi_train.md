## 类结构

### 两种驱动(按开局信号分)

1. **罗刹策略驱动**(r167):开局「本姑娘就是罗刹」(三月七白送+化身罗刹
   主C,后台强度驱动)→ 双 CARRY(姬子输出+三月七罗刹)——**信号改变
   三月七身份**才成立
2. **姬子本体驱动**(无特殊策略):姬子3费到手即开线(领航员羁绊=选列车
   队友复制其装备+获其羁绊)——Final 姬子 274 CARRY 的主体

### 标准形态(罗刹篇 Final 实例)

```
前排: 瓦尔特(蓄能帆+永动机) 姬子×2(CARRY: 风暴潮×2+电锯+冷笑话)
      椒丘×2(生命之环+痛觉) 开拓者
后排: 彦卿 三月七×3(CARRY: 靴×2+螺旋桨) 千冶·刃(钻地弹)
      花火(蓄能帆) 缇宝(武器大师)
羁绊: 领航员1+列车4+减益4+量子2+星间1
```

### 装备链(该类共识)

- 姬子:**双火力风暴潮+高周波电锯**(核心三件,采购序直排)
- 三月七(罗刹形态):**一鞋一风扇**(反重力皮靴+光速螺旋桨)——
  速度/行动件,伤害吃后台强度不缺
- 瓦尔特/花火:回能件(蓄能帆/永动机)——推条引擎
- 姬子无罗刹时:领航员可换绑瓦尔特(#34)

### 演化路径(与过渡模型衔接)

```
P1 通用引擎(DOT2/列车2/仙舟3) → P2 姬子到手=开线(列车4 主体+
领航员绑定三月七/开拓者) → P3 补减益4/瓦尔特/符玄,微调粒度到
单羁绊(领航员换绑/多余人口四方案)
```
