# 大地图录制（官方底图 + 实机定标）

没做完下面 6 步不算完成：

1. ☐ 拉取区域元数据：`scripts/gen_map.py` 首跑会自动缓存 `map_info_<id>.json` / `map_point_<id>.json`；先确认 map_id（官方树节点 id，多层区域取各层节点 id）——必做
2. ☐ 实机定标截图：星轨航图进到目标区域（多层先选层），缩放条拖到最小，等 ≥2s 静置后全屏截图——必做（飞行动画/缩放变化期间截图必失败）
3. ☐ 定标 + 生成：`uv run scripts/gen_map.py <map_id> <截图> gen_<id>`，失败按 §3 降级链依次尝试——必做
4. ☐ 验证：`uv run scripts/verify_gen.py gen_<id>`，读三个数：纯官方 CUT 门 / 锚点真值误差 / 贴回后 CUT 门——必做
5. ☐ 判定产物：贴回后门 <0.75 即视为不可用（需排查定标）；纯官方门 <0.75 时**必须以 raw_overlaid.png（贴回版）作为交付物**——必做
6. ☐ sp 草稿与登记：锚点 lm_pos 在 calib.json 的 `sp` 行；新图标类型先全库查重再裁剪并登记 `assets/template/mm_icon/README.md`——必做

## 1. 前置与语义

- 底图/锚点来自官方接口 `api-static.mihoyo.com/common/srmap/sr_map/v1`（`map/info`、`map/point/list`，带 `app_sn=sr_map`），无需登录态；脚本已内置缓存与 APP_VERSION。
- 坐标三层：**点坐标**（point/list 原始值）→ **切片像素**（点坐标 + info.origin）→ **游戏帧/画布**（定标变换后，1:1 对应实机最小缩放截图）。sp 的 lm_pos 一律产出画布坐标。
- 官方点坐标是米游社编辑者手标，逐点误差可达 ±25px；运行时点击靠 ±100px 窗口内图标模板匹配兜底，故可用，但**锚点巡访时应做精修**（掩码模板对齐实机渲染位）。

## 2. 定标三级降级链（§3 步骤 3 的分支完备表）

按顺序尝试，成功（护栏过）即停：

| 级 | 工具 | 模型 | 适用 |
|---|---|---|---|
| 1 | `gen_map.py` | 相似变换（多 ratio 重试 + 平移投票分簇） | 绝大多数区域 |
| 2 | `calib_affine_gen.py` | 6dof 仿射（容旋转/剪切/非等比） | 底图艺术相对实机有旋转/倾斜的区域；稀疏特征（内点阈值已放宽到 10） |
| 3 | `calib_by_anchors.py` | 可见锚点图标 ↔ 官方坐标 2 点拟合 + 第 3 点校验 | SIFT 完全无对、但锚点图标 ≥3 个可见且可目读屏幕坐标 |

- 级 3 的屏幕坐标用视觉直读锚点图标中心；候选漩涡位不确定时穷举分配（参考 scripts/search_512.py 的写法），保留 rot≈0 且 scale 合理的自洽解。
- 全部失败的已知根因与去向见 §5。

## 3. 产物判定与贴回

- **纯官方纹理 vs 实机视图存在渲染语义差**：实机大地图按"当前层深色 + 其他层淡显"分层渲染，官方切片是页面合成图。多层区域纯官方门普遍 0.7~0.8，被幽灵主导的楼层可低到 0.6。
- 实机贴回（把定标截图按变换平移回 raw）把覆盖区修正为运行时逐层渲染，门普遍 ≥0.99。**规则：纯官方门 <0.75 → 交付物必须是贴回版**。
- 单视角可覆盖全层的区域，定标截图一帧即完成全覆盖贴回；大区域按蛇形拖动多帧贴回（拖动终点必须留在地图区 x<1430 且 y 100~1015，游标越界面板地图会停止接收拖动）。
- 位置不确定的帧宁可不贴：错位贴回会把官方全细节内容洗成实机空背景。

## 4. sp 草稿与新图标

- calib.json 的 `sp` 行即锚点 lm_pos（画布坐标）；cn/tp_pos 需巡访产出（点图标 → 弹窗读名 → 传送 → 开图以该锚点图标 lm_pos 为参照反推玩家标记位）。重合点位会弹多选列表，按名字二次选择。
- 渲染核查：把全部 point 投影画到截图上逐点放大目检——只有实机渲染的类型进 sp；wiki-only 类型（任务/书籍/收集标记）不渲染，不进。
- 新图标类型（模板库 `assets/template/mm_icon/` 没有的）：**先全库查重再裁剪**（同型多 label 常见，如"xx之形"挑战家族共用一个模板）；裁剪 = 投影粗定位 → 掩码质心迭代对齐 → 按图标真实尺寸裁（大标记可 >51px，运行时匹配无尺寸约束）→ 同图回测主峰 1.0/次峰低 → 登记 `assets/template/mm_icon/README.md`。

## 5. 已知失败形态（定标排障路由）

- **区域未探索**（宝箱计数 0/N）：实机只渲染已走路径丝带，官方底图是全地形——无对应地形可定标，**先在游戏内探索再录**。
- **多层幽灵主导**（本层实体少）：相似/仿射内点不足 → 降级链 3；或等探索更充分。
- **平滑无特征**（大片均匀色块/水面）：SIFT 天生无特征 → 需 blob 对齐法（内容质心+面积定 scale、PCA 主轴定 rot、掩码 NCC 精修；未实装）。
- **scale 超出直觉**：实测范围 0.17~3.4 连续分布，勿设窄护栏；护栏靠 rot、残差、内点数把质量，不靠 scale 区间。
- **同区域各层**：逐层独立定标（各层缩放档有微小差异，跨层共享变换实测不成立）；若要统一画布，区域尺度取最优一次定标，各层钉死 scale 只拟合平移，画布同尺寸同公共原点。
