# 崩铁新手与日常决策（basics 层）

> 按 V4.7 期整理。「会玩崩铁」的日常决策知识——不涉具体角色（角色层查）与特殊玩法（专项 skill 查）。骨架档，随调研轮充实。

## 体力（开拓力）怎么分配

- 每日自然恢复 240（+后备开拓力）；**勿溢出**。
- 优先级参考：当日体力本（花萼金/赤 按当前养成缺口）＞ 饰品提取（定向刷核心 C 的位面）＞ 周本（历战余响，每周 3 次×30，留周日打最高难度）。
- 侵蚀隧洞（遗器本）刷取时机：主力队伍成型后再全投入（前期用散件过渡）。

## 养成优先级（先练谁）

1. 一队主C（毕业向：等级→光锥→行迹→遗器）
2. 一队生存位（保证通关）
3. 一队辅助位（拉条/增伤）
4. 第二队（深渊双队伍刚需）——再往后按当期环境补
- 角色具体练度口径（词条/转化上限/毕业面板）查 `../characters/<角色>.md`。

## 角色养成操作（游戏内怎么做）【实测】

### 进角色详情的两条路

- **大世界右上角角色头像直达**——不经角色列表，详情显示头像对应的队伍角色（最短路径）。
- 手机菜单 →「角色」→ 角色列表 → 点选角色 → 详情（要挑特定角色时用）。

### 角色详情画面结构

- 左栏六页签：详情（等级与属性面板）/ 光锥 / 行迹 / 遗器 / 星魂 / 信息；顶部大标题随页签变化（如「角色光锥」「星魂同调」）。
- 顶部头像条 = 最近查看角色的快切，点头像直接切换详情。
- 右上关闭回进入前场景；左下按钮打开角色列表浮层。

### 角色列表浮层（挑角色用）

- 列表占左半屏，右侧详情保留显示；网格格子**无名字文本**（只有头像+等级底标）——名字只在选中后右侧详情显示，找特定角色靠头像识别或逐格点选。
- 点格子 = 选中并切换右侧详情，列表保持打开；点浮层外空白 = 收列表且选中保留。
- 注意：列表打开时左下同位置按钮变为「筛选规则」入口（属性/命途筛选 + 稀有度排序）。

### 等级提升（晋阶）【实测】

- 入口：详情页签右下「晋阶」按钮——**满级角色不显示此按钮**（按钮存在 = 有升级空间）。
- 等级提升界面：等级对比（当前等级/目标上限）+ 属性预览 + 「快速升级」开关（开 = 自动填材料至可达等级，默认开）+ 消耗材料栏（每格「拥有/所需」）+ 消耗信用点 + 「快速刷取」（材料不够时跳转刷取点）。
- 执行：点「快速升级」**无确认弹窗直接消耗**——点前确认材料栏与信用点充足；成功后弹「角色晋阶」结果横幅，点空白关闭。
- **能否升级看按钮文本（两态互斥）**：材料充足 = 白底「快速升级」可点；不足 = 灰底「材料不足」禁用（不足的材料格数字红色高亮）。
- **缺材料的官方闭环——「快速刷取」**：等级提升界面左下按钮，点击弹窗确认（显示缺少的材料与刷取点，如「天人之形·凝滞虚影·难度 IV」），开始后**自动连刷直到材料足够**并停止。每次刷取消耗**开拓力 30 + 快速刷取券 3**（票为硬消耗，两者都扣；界面右上角显示券库存）；开拓力不足时「自动取出后备开拓力」开关从后备开拓力自动补。刷完按钮自动变回「快速升级」，即可继续升级——升级与刷材料在晋阶界面内自闭环。**刷前检查两项余量：开拓力与快速刷取券**。
- 晋阶分段制：等级上限分段提升（60→70→80→…），每段消耗晋阶材料+信用点；升满一段后晋阶按钮仍在，需再晋阶开下一段（材料需求逐段递增）。
- 材料来源：晋阶专属材料按材料名反查刷取点（属性池出自拟造花萼(赤)，虚影类出自凝滞虚影等，逐材料反查为准，见下「材料需求与刷取点查询」节）；角色/光锥经验书出自拟造花萼(金)。

### 光锥养成（升级与晋阶）【实测】

- 入口：光锥页签右下「替换 / 强化」两按钮，「强化」进晋阶界面。
- 光锥晋阶界面与角色晋阶**结构同款**（等级对比/属性预览/快速升级开关/消耗材料栏/信用点），差异：右上角是关闭 X（角色晋阶是返回箭头）。
- **缺材料时按钮三态**（与角色晋阶的两态不同）：
  - 材料足 = 白底「快速升级」可点；
  - 缺专属材料但通用材料够 = 白底「**使用通用材料补全**」可点——点开「材料补全」确认框，以通用材料（梦之珠泪类）合成替代缺口；通用材料是稀缺消耗品（锄大地/活动来源），消耗量可能很大（实测方案：159 个梦之珠泪换永恒之花×15 + 生命之芽×8），**确认前算清账**；
  - 全缺 = 灰字禁用（推理形态，未实测）。
- 晋阶成功后结果横幅形态未实测（首版 op 按过渡态点空白兜底）。
- 材料来源：专属材料出自拟造花萼(赤)属性池（与行迹共用）；经验书出自拟造花萼(金)；分段晋阶表已固化（`src/sr_od/config/light_cone_ascension_const.py`，BWIKI 逐光锥页生成，惊魂夜实机锚：60+70 级段累计 永恒之花15/永寿荣枝14；**段名口径：「Y级」=突破段、「X～Y级」=经验段以稀薄以太计，界面按所持书籍折算显示**）——查询走 MCP `cone_lookup(光锥名, with_ascension=true)`（材料+副本实例一次拿全，同 `character_lookup` 口径）；副本归属与缺料刷取同角色线（`FarmMaterialOp` 跳转路径通用）。历史注意：BWIKI 的「材料→光锥」聚合反查页是旧口径无数量，勿与逐光锥分段表混用（旧强标注仅针对该页，分段表已实机对账）。

### 技能提升（行迹）【实测】

- 入口链：行迹页签 → 行迹树点目标技能节点（普攻/战技/终结技/天赋/秘技）→ 节点详情面板（同屏面板态，非独立画面）。
- 界面要点：
  - 行迹等级上限随角色晋阶解锁（80 级样本：普攻上限 6、其余 8~10、秘技 1）——先晋阶再拉行迹。
  - 面板选中态锚 = 「简略描述」开关（常显）；「下一级」按钮在满级面板消失，不可作锚。
  - 实测坑两条：面板关闭后节点保持选中态，再点同一节点是「无操作」，面板不重弹；属性节点的「需解锁前置行迹」提示面板是模态的，不先关掉会吃掉后续所有节点点击——先点面板外空白关闭，再点目标节点。
  - 节点点击坐标按角色逐个建档校准（样本角色实测，逐角色一致性未验；布局不同的角色按角色实测修正）。
- 升级执行（按钮四态）：材料足 = 白底「快速升级」可点，点击**无确认弹窗直接消耗**；缺专属材料 = 「使用通用材料补全」（授权后确认弹窗，消耗通用材料合成替代缺口）；全缺 = 灰字禁用；满级 = 按钮消失、显示蓝字「已达最大等级」。快速升级开关默认开（开 = 自动填材料）。
- 材料来源：行迹与光锥晋阶共用属性材料池（拟造花萼(赤)）——常规刷取一次可补多线缺口；材料数量表已固化（`src/sr_od/config/trace_levelup_const.py`，5 星角色统一表，1→10 分九段；查询 `total_cost(from, to)`），缺口判定可离线算也可面板实读。
- 边界与未实测点：升级执行后的反馈形态未实测（横幅或等级直跳未知，自动化按稳定等待收敛）；「快速升级」开关关闭态行为未实测；信用点不足形态未实测（预期判停兜底，报告理由可能误标为材料不足）；快速刷取的券消耗未实测定案（按同款先例计）。

### 遗器提升（强化）【摸底】

- 入口链：遗器页签（着装页）点遗器件 → 「遗器-替换」界面 → 选中遗器右下「强化」按钮 → 「遗器详情」强化页签。
- 界面要点：强化材料 = 吃其他遗器（8 格）+「4星及以下」筛选 +「自动置入」自动填料；经验条（0/560 式读数）= 距下一级所需；右下「强化」大按钮执行；同步消耗信用点。
- 升级执行：「自动置入」填料（默认吃 4 星及以下狗粮）→ 点「强化」执行；无狗粮时卡在填料步（见边界）。
- 材料来源：狗粮 = 4 星及以下遗器库存；5 星遗器属高价值资产，不作默认狗粮。
- 边界与未实测点：
  - 狗粮库存为空时「自动置入」无动作——无狗粮 = 无法强化（常态，非识别异常）。
  - 吃 5 星遗器属高价值消耗，自动化绝不默认；涉及 5 星遗器的消耗须用户明示授权。
  - 遗器强化 op 未实现：暂无实机验证场景，待狗粮库存非空或用户明示消耗授权后落地。

### 材料需求与刷取点查询（缺材料时）

- **一条链直查（MCP，优先）**：`character_lookup('角色名', with_ascension=true)`——单次调用返回晋阶分段材料表 + 满晋阶总量 + 材料→刷取副本反查（分类级 `dungeon_by_material` + 实例级 `missions_by_material`：具体虚影/历战余响 boss/花萼区域，与指南关卡同名对齐，可直接规划开拓力刷本）+ 副本外途径，「角色→突破材料→所属副本」一次拿全。
- **角色晋阶需要什么**：项目代码常量 `src/sr_od/config/character_ascension_const.py` 的 `get_character_ascension('角色名')`——返回分段材料表（`stages[].name/materials`）与满晋阶总量（`total`）；解析入口 `find_character_ascension` 额外兼容角色定义中文名（开拓者性别后缀归一化匹配）。
- **材料去哪刷**：常量 `src/sr_od/config/dungeon_drop_const.py` 的 `find_dungeon_by_material('材料名')`（分类级）与 `find_missions_by_material('材料名')`（实例级，返回 `{category, mission, region}`）——反查可刷取的指南分类/具体关卡，键对齐指南数据可直接路由导航。例：天人遗垢 → 凝滞虚影·天人之形@丹鼎司；永恒之花 → 拟造花萼（赤）·丰饶之蕾@边缘通路；晋阶中高级材料（如永寿天华/永寿荣枝）副本线仅差分宇宙，花萼只掉低级档，中高级靠合成机升阶——**常规刷取（自己刷副本）只耗开拓力，不耗快速刷取券**。
- 表由 `tools/game_data/generate_ascension_const.py` 从官方 wiki 生成（版本更新重跑刷新）；表外角色/材料 = 官方无结构化源，以游戏内界面实读为准。
- 副本之外的获取途径（合成/置换/商店/任务等）在同一常量文件的 `MATERIAL_EXTRA_SOURCES` 表（材料 → 途径清单），副本表查不到时查它。
- 缺材料处理顺序（负责人定案的推荐优先级，向用户推荐时按此排序）：**①晋阶界面内「快速刷取」**（即时完成不跑战斗，每次开拓力+券；券为常态囤积资源，自动化省时首选）→ **②「使用通用材料补全」**（不跑战斗但消耗稀缺通用材料，如梦之珠泪系）→ **③跳转/常规刷本**（只耗开拓力不耗券，但要真打战斗——贪饕侵蚀机制下花萼单场可达 20 分钟，时间成本最高）→ **④挂进一条龙开拓力计划**（前三档都不可用时兜底：把刷取排进每日一条龙批量完成）。两条界面内路线均有自动化入口（升级 op 的 `auto_farm` / `fill_generic` 参数，启用前须向用户说明消耗并获同意）；③ 走 `FarmMaterialOp` 跳转路径。任一路线推荐前报预计消耗（次数 × 单次开拓力/券量）。
- **④ 挂开拓力计划的操作**（MCP 通用配置接口已接入该 app）：`add_config_item(app_id='trailblaze_power', list_field='plan_list', item_dict={...})` —— `mission_id` = 「生存索引 分类 关卡 区域」由 `find_missions_by_material` 三元组直接拼出（例：永恒之花 → `生存索引 拟造花萼（赤） 丰饶之蕾 边缘通路`），`plan_times` = 缺口 ÷ 单次产量估算，`run_times: 0`，`team_num: 0`（游戏内当前配队）；字段结构可先 `describe_config('trailblaze_power')` 查。写入写穿当前实例缓存，**下一次一条龙 run 立即生效，无需重启**。注意事项：①改的是用户常驻计划，须向用户说明并获同意；②完成后计划项残留但会被跳过（run_times=plan_times），GUI 可清理；删除用 `delete_config_item`，`item_id` 传计划项下标（`get_config` 读 `data.plan_list` 顺序，0 基）。

### 已建成的养成 op（agent 可直接运行）

上文交互已固化为可运行 operation（经项目 MCP `run_operation` 调用，op_id 格式 `sr_od.operations.<模块>.<类名>`；同款先例见逐光捡金 skill 的编队与战斗 op 节）：

- `GotoCharacterDetail`（`sr_od.operations.goto_character_detail.GotoCharacterDetail`，无参）：任意画面 → 角色详情画面（大世界右上头像直达，不经列表）。终点 = 详情页·默认角色。
- `SelectCharacterOp`（`sr_od.operations.select_character.SelectCharacterOp`，参数 `cn_name` = 角色中文全名，间隔号两式均可）：详情页打开列表 → 按名选中（头像模板识别+翻页遍历）→ 收列表。终点 = 详情页·目标角色·列表已收。
- `SwitchCharacterTabOp`（`sr_od.operations.switch_character_tab.SwitchCharacterTabOp`，参数 `tab_name` = 详情/光锥/行迹/遗器/星魂/信息）：左侧页签切换。⚠️ 仅无遮挡态（列表浮层开着会显式失败）。
- `UpgradeCharacterOp`（`sr_od.operations.upgrade_character.UpgradeCharacterOp`，参数 `auto_farm` 默认 False）：晋阶升级至当前上限。`auto_farm=False` 材料不足判停返回详情（零额外消耗）；`auto_farm=True` 材料不足自动「快速刷取」补材料后继续升级——**每次刷取消耗开拓力 30 + 快速刷取券 3（券不可自然恢复），调用方发起前必须向用户说明预计消耗并获明确同意**。终点三种：`MAX_LEVEL`（已满）/ 升满当前段 / `MATERIAL_CAPPED`（材料或刷取预算耗尽停在当前等级）。执行消耗真实材料与信用点。⚠️ auto_farm 全链尚未经真实缺料场景实测（首次使用时留意日志）。
- `UpgradeLightConeOp`（`sr_od.operations.upgrade_light_cone.UpgradeLightConeOp`，参数 `fill_generic` / `auto_farm` 均默认 False）：光锥晋阶升级至 80 上限。缺材料时三路分流：`auto_farm=True` 优先自动「快速刷取」(**每次开拓力 30 + 券 3,券不可自然恢复**)；刷取预算耗尽或未授权时 `fill_generic=True` 可转「通用材料补全」(**消耗稀缺通用材料如梦之珠泪,量可能很大**)；均未授权判停返回光锥页。**任一消耗路线启用前,调用方必须向用户说明并获同意**。终点：`MAX_LEVEL` / 升满 / `LIGHT_CONE_CAPPED`（停在当前等级）。前置链同样四步,第三步切「光锥」页签。⚠️ 两条消耗路线的全链均未经真实消耗实测(首次使用时留意日志)。
- `UpgradeTraceOp`（`sr_od.operations.upgrade_trace.UpgradeTraceOp`，参数 `target` = 技能名（普攻/战技/终结技/天赋/秘技），`fill_generic` / `auto_farm` 均默认 False）：目标主技能升到当前上限（上限随角色晋阶解锁）。缺料分流与光锥线同构：`auto_farm=True` 自动「快速刷取」（**拟造花萼赤档位，开拓力 10/次 + 券 3，券数未实测定案**）；刷取预算耗尽或未授权时 `fill_generic=True` 转「通用材料补全」（**消耗稀缺通用材料**）；均未授权判停回行迹树。**任一消耗路线启用前，调用方必须向用户说明并获同意**。终点：`MAX_LEVEL` / 升满当前上限 / `MATERIAL_CAPPED`（停在当前等级）。前置链四步，第三步切「行迹」页签。⚠️ 升级反馈形态未实测（首版按稳定等待收敛）；节点点击坐标逐角色一致性未验。
- `FarmMaterialOp`（`sr_od.operations.farm_material.FarmMaterialOp`，参数 `times`/`team_num`=0/`support`）：**缺料手动刷取（游戏跳转路径，推荐顺位③——只耗开拓力但耗时最长，优先推荐①快速刷取/②通用材料补全）**——起点 = 光锥晋阶画面（调用方经 前往详情→选角色→切光锥→点强化 到达），扫描消耗材料栏计数条红字定位缺料格（「拥有数」不足变红、颜色统计判定，OCR 对红字漏读不可用）→ 点格开材料弹窗 → 弹窗标题 OCR 材料名（difflib 容错误读）按静态表预期取目标 → OCR 定位带【区域】的途径行（**行 Y 随描述长度漂移，不可固定**；预期行可能在视口下方，列表内拖动重扫有界 3 轮，不用滚轮）→ 点击直达副本挑战画面 → 委托 `UseTrailblazePower(skip_transport=true)` 完成选次数/配队/战斗。导航真相源 = 游戏自己的跳转；静态表 `MATERIAL_MISSIONS` 只用于「有无副本可刷」预期与行定位核对。缺料材料无可刷副本（途径均为敌方掉落/合成类，如实机样本永寿荣枝）→ 显式失败 `MATERIAL_NO_DUNGEON`；无缺料 → `NO_LACKING`。⚠️ `times × mission.power` 开拓力真实消耗，发起前须向用户说明并获同意。✅ 全链实机验证通过（花萼×1 实跑 48.5s）；拖动重扫为单元验证（自然样本未现，预期行均在首屏）。

前置链 = 四 op 依次调用（进详情 → 选角色 → 切目标页签 → 升级）；前置不符各 op 显式失败，不互相补导航，组合编排归调用方。

### MCP 调用与编排建议

- 现状可直调（项目 MCP `run_operation`，op_id = `sr_od.operations.<模块>.<类名>`）：前置链三 op + 等级/光锥/行迹三线 op + 材料刷取 `FarmMaterialOp`（清单见上节）；遗器强化 op 待建。
- 一次养成 = 调用方按序串联四步（进详情 → 选角色 → 切页签 → 升级 op）；行迹多技能 = 追加多次 `UpgradeTraceOp`。组合编排归调用方是既定约定——各 op 前置不符显式失败、不互相补导航，op 间不做隐式兜底。缺材料时按推荐顺位（见上节）：① 升级 op 授权 `auto_farm=true`（快速刷取）→ ② `fill_generic=true`（通用材料）→ ③ 判停后切到晋阶画面跑 `FarmMaterialOp`（跳转手动刷，times = 缺口 ÷ 单次产量估算）→ 回续升级 → ④ 当期都不方便时挂一条龙开拓力计划（操作见上节），下次一条龙批量完成。任一顺位启用前报预计消耗并获用户同意。
- 未来可在 MCP 层封装的便捷能力（建议，按价值排序）：
  - 一键「选角色+升级」组合 op：前置链 + 指定养成线封装为单次调用，收敛调用方的编排负担与前置踩错面。
  - 遗器强化 op：入口链已摸底（见遗器节），待实机验证场景（狗粮库存非空或用户明示消耗授权）后落地。
  - 材料缺口自动闭环：读游戏内材料库存 → 自动算缺口与次数 → `FarmMaterialOp` 刷满 → 回续升级（现在次数仍由调用方估算；单次产量表未固化）。
