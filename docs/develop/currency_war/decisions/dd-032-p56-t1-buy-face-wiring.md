# DD-032:P56 可变现息线下界 + T1 凑息卖语义重写落码(姊妹缺口收口)

## 背景(问题)

买面三消费位(EV 买面/M6 压库/凑息卖)的 S 预留均为零参退化形,「S 线在买面从未接线」,被失活门 fail-closed 掩蔽(设计:`docs/develop/currency_war/strategy/13_buy_face_design.md`,经三轮对抗修订定稿;根因定谳与方案论证见该篇 §1/§2)。凑息卖旧语义 = T_SEARCH_A 注入态资格全集无差别全发,与息线无耦合。

## 决策

1. **P56 落码**:`s_reserve := g* − Σ活期退金投影`(可变现口径;活期卡资格谓词与 funding_support_sell 同一,单一源 `mandate.fuel_sell_candidates`),原位生效于 `stockpile_buy` 与 `ev_buy_candidates` 检查点③;M4 卖出件即时扣减投影(帧首快照重复计入的非保守修正)。
2. **T1 凑息卖语义重写**(`criteria/sell.sell_for_interest`):①金位触发(投影金 < g* 才发射,缺口驱动,非缺口帧零发射);②目标量止盈(remaining 递减贪心,funding_support 模板同构零待证;Σrefund ≥ 缺口即止;序 = 刚买件名优先(R2-N1 发射约束)+ (star, slot) 确定序);③T_SEARCH_A 布尔门退役出凑息/压库/EV 三消费位(窗口改 `vbar.window_vbar` 帧级现算传入,空集=真无窗口帧非门控)。
3. **P57 双读法参数化**:`window_vbar(reg, r, reading)` 支持 per_step(读法①)/frame_horizon(读法②),生产默认读法②,`config.cw4_vbar_reading` 供 sim 双臂切换。
4. **分键遥测四字段**(R3-R5 交付义务):发射帧数/缺口累计与卖回累计(覆盖缺口率)/回拉金位轨迹/拒因计数(复用 's_reserve' 串)。
5. **P55 不在本批**(阶段 2 待标定;判据位 fail-closed 候选类挂 §4.3①)。

## 理由(Considered Options)

- **回拉发射位并入本批 vs 独立前置批**:并入。回拉发射位与 P56 互为前件(引理条件式的前项),拆批则两批互相阻塞且归因分键更难。
- **P57 单臂 vs 双臂预注册**:双臂。单臂下另一读法只有窗口集差异指纹无绩效读数,决胜判据悬空;双臂差分即决胜,顺带强化归因(R2-N3)。
- **设计文本语义澄清(如实申报)**:设计 §2.2 重写注①的缺口公式按字面读法在算术上不可满足(Σrefund ≤ Σ投影 < 缺口),按其自身验收定义实现为「缺口 = g* − 买后投影金」;「Σ活期退金投影」的闭环角色 = P56 约束保证缺口 ≤ 资格集退金和。澄清已录 `proofs/p56-realizable-interest-floor.md`。
