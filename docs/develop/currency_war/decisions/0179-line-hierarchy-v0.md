# ADR-0179: 线强度层级池化引擎 v0 落地(redesign 37 号处置)

## Status

Accepted(2026-08-17,策略优化会话;三消费端换源走影子开关批次)

## Context

37 号诊断:线强度(全栈核心潜变量)由 05(臂 Beta)/20(预注册先验)/21(Line 后验)三处独立
维护、逐线独立更新——A8 一局 25-35min、20 条线 = 每线永远小样本;plaza 先验靠「封顶 ≤8」
钝器压制;版本 bump 全清零重积。「别的线的观测也能约束这条线」的跨线联合估计零投入。

## Decision Drivers

- 小 n 线向结构原型借等效样本(3-5 局 → 原型几十局),线选择边际决策(21/05 的工作面)直接受益
- 版本恢复从「全清零」变「叶收缩重校」
- 哲学红线:分布参数+收缩规则(经验贝叶斯),非学习模型,不碰「ML 只采集」

## Considered Options

1. **经验贝叶斯两级层级(选)**:原型(trait 网格分组)超先验 + 线 Beta-Binomial 收缩,
   方法矩估 τ,~150 行纯函数;
2. 全贝叶斯 MCMC——统计上更优但维护成本高、统计增益边际(方向与量级正确即可用);
3. 维持三处独立(现状)——小 n 线永远欠估、版本 bump 清零重积。

## Decision

选 1:`cw_line_hierarchy.py` v0——

- ``HierarchySpec``(L1 原型分组,挂 trait 网格不挂聚类 id)+ ``fit_tau``(矩估计:组间方差
  减二项噪声修正;**单线原型不登记超先验**——借自己=虚增置信,该线走独立模式);
- ``pooled_posterior``:κ = 8/(τ×10) 等效借力样本(夹 ≤60),按原型均值方向分配;
  adherence 加权;无登记/无组数据 → 独立模式 = 现状(降级链);
- ``version_shock``:叶按 decay 收缩 + 结构借力重注(非清零)。

## Consequences

- **J1 合成恢复过**(测试):8 世界平均 RMSE 池化/独立 ≤0.85(20 线世界 3-8 局/线);
  大 n 锚(50 局)扰动 <0.08;10 世界 95% 覆盖率 ≥0.85;τ=0/单线降级 = 现状;
  版本冲击收缩方向验证(0.55<μ<0.85 且非平先验);
- 三消费端换源(05 臂先验/20 预注册先验/21 Line init)为影子开关批次(对拍后切);
- J2(版本恢复局数减半)/J3(runs.jsonl LOO log-score)/J4(影子 diff)待消费端接线后跑;
- 37 号处置完成,提案文件删档;测试 +5。
