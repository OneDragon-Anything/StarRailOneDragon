# DD-002:轮岗突变语义勘误——选择后每备战阶段 100% 生效;20% 是观测频率不是机制概率

> 状态:已裁决(2026-08-31 用户方法论裁定「结合游戏效果数据验证」首战命中;DESIGN_FINAL_ATTACK 阻断-2 处置)。
> 晋升来源:原裁决记录于 `docs/develop/currency_war/redesign/reports/DESIGN_FINAL_ATTACK.md` 及其补强攻击节(临时文件,已清理)——本件为其持久化。

## 背景

游戏原文(`cw_invest_data.py:383`,环境 id 114 轮岗):「备战阶段开始时,使一个随机费用的刷新概率翻倍,**每个备战阶段重新随机**」——环境一旦被选,每个备战阶段 100% 生效,只随机翻倍哪一档。而 sim 侧(`cw_shop_odds.py:96` `ROTATION_CHANCE=0.2`;`sim/engine_p1.py:776` 每备战期无条件 20% 掷事件)把「触发率」与「激活语义」压缩进一个常量:已选轮岗的局 80% 备战期环境不生效,未选的局 20% 凭空生效。**20% 实为 replay 观测在场频率(361/1806 决策行带轮岗概率条),不是机制概率。** sim 建模对象与游戏机制不符(实证方法论事故先例:公式与断言自洽但建模对象错)。

## 裁决

1. **机制语义(正确口径)**:active_strategies 含 id 114 ⇒ 每个备战阶段强制重掷翻倍档(翻倍档分布 = 1/5 均匀系建模假设,实机待核)。
2. **20% 的身份**:replay 人口频率先验,仅可作无注入运行的环境采样参数;禁再当作机制触发率引用。
3. **sim 修复为 Phase 4 必修**(被测体替换时对已选轮岗的环境条件化);「触发率」与「激活语义」两个概念分离建模。
4. **决策定价口径**:E1/E15 对轮岗的差分定价必须条件于「玩家主动选了轮岗」——p38 O6「期望口径混合方向近零」的混合是按 20% 在场率算的,修正口径下该结论需复核(挂账项,见消费点)。
5. resolved 特例不变:概率条直印商店面板的画面读屏即真值(`parse_prob_bar`),无需建模翻倍档。

## 约束范围

- sim 引擎(engine_p1 / cw_shop_odds)Phase 4 被测体替换;
- redesign/01 §4.10 概率表族行、02 R03 轮岗条目的语义登记(20% 改标频率先验);
- p38 O6 / E15 轮岗差分定价的复核挂账。
