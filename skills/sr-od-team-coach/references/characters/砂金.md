# 砂金（虚数·存护·5星）

> 按 V4.7 期撰写。防御转暴击的存护输出位 + 受击挂灼烧光锥的充能型生存；体系见 [黄泉负面队](../teams/黄泉负面队.md)。

## 一、命途属性与技能说明

**命途**：存护
**属性**：虚数

| 技能 | 说明 |
|---|---|
| 普攻 | 单体 50%防御力虚数伤 |
| 战技 | 全队盾（3回合）+ 命中挂【惊惶】易伤 |
| 终结技 | 消耗能量110；162%防御力 AoE + 挂【惊惶】（终结技易伤9%） |
| 天赋 | 受击/追加攻击积攒盲注；满层 7 段追击（12%防御×7）——被打越多输出越高 |
| 秘技 | 开局盾 |
| 额外能力 | 「杠杆」：**防御>1600 每超100点暴击率+2%，上限48%**（4000防御吃满）；天赋给筹码持有者效果抵抗+25%+免控 |

**资源与循环**：标准能量→充能有效。追击依赖受击频率——嘲讽/多段敌方环境输出最高。

## 二、推荐遗器与原因

**套装**：筑城者的贝洛伯格4件 + 不老者的仙舟2件【攻：社区口径】
- 贝洛伯格4：防御系套装——盾量、追击、普攻终结技全部按防御结算，防御是三合一属性
- 仙舟2：≥120速 攻击/生命增益——副属性堆速度兼顾循环

**主词条**：

| 位置 | 推荐 | 原因 |
|---|---|---|
| 躯干 | 防御% | 防御=生存+输出+暴击三合一（杠杆转化）【官】 |
| 脚部 | 速度 | 盲注积攒与终结技循环 |
| 位面球 | 防御% | 输出走防御倍率 |
| 连结绳 | 防御% | 同上 |

**副词条**：防御% > 速度 > 效果抵抗 > 双暴（E0不追——杠杆上限48%暴击需4000防御支撑，防御优先级绝对更高）。
**转模与转化上限**：「杠杆」防御→暴击，**4000 防御吃满**（1600+100×24）。

## 三、推荐配队与原因

| 阵容 | 为什么 | 备注 |
|---|---|---|
| **黄泉 / 椒丘 / 花火 / 砂金** | 光锥「宇宙市场趋势」受击挂灼烧=被动充能位（存护位挂负面最优解【攻：Prydwen】） | 黄泉队标准生存 |
| 追击队（飞霄/托帕/知更鸟） | 追击也攒盲注，吃体系转速 | 泛用 |

**硬否决**：**遐蝶生命记忆队**——护盾掐死新蕊收入（敌方不掉血→无新蕊无治疗转化）【官：行迹推论】。
**通用性**：高（盾+输出+暴击增益）；但一切护盾体系与烧血流互斥。
