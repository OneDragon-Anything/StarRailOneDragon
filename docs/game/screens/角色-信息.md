# 角色-信息(character_info)

> source_image: sr-od-test/screens/角色-信息/default.webp(2026-10-17 live 建档,布洛妮娅信息页)

## 何时出现

角色页左侧「信息」TAB。独立屏。

## 状态流转

```
详情 TAB → 本屏(角色立绘+阵营/邂逅/简介) → 语音/故事按钮开子面板
右上关闭 X → 离开角色页
```

## 识别特征

- id_mark「标题-信息」[90,25,155,75](左上标题,仅 2 字——lcs 撞车风险同行迹页,留 id_mark 测试观察)

## 可交互元素(live 验证 2026-10-17)

| 元素 | 坐标 | 行为 |
|---|---|---|
| 左侧 TAB 5 个 | 同详情页坐标 | 切对应屏(goto_list 已建) |
| 头像条 | 首位 (452-528,28-108) | 切角色保持本 TAB |
| 语音 | (1490-1675,962-1022) | 语音列表子面板 |
| 故事 | (1700-1880,962-1022) | 角色故事子面板 |

## automation 要读信息

- 读区-阵营 [1700,262,1905,302]:OCR(贝洛伯格/星穹列车/仙舟联盟…)
- 读区-首次邂逅 [1630,305,1905,348]:获得日期 OCR
- 养成规划价值低,主要作为 TAB 路由的过路屏

## 注意

- 「信息」2 字标题撞车风险(菜单页等其他屏可能含「信息」文本),id_mark 测试需覆盖
