# 0266 - 升级门息引擎前置(追级资格 = 息引擎已立)

- 日期:2026-08-24
- 状态:accepted
- 关联:r406;压测经济批 [12]+①残差(`sim_压力测试_经济批_2026-08-23.md`);口述 [12]/[17]/[28];ADR-0223(r354 总成本门)、ADR-0260(engine_seed 经济安全)

## 背景 / 决策驱动

sim 压力测试经济批实锤两条同根残差:

1. **p1_exit_gold<50 = 25.9%**(15/60 局 r9 结束金 <50);解剖 15 局中 **14 局 `last>=50@r0`——从未攒到过 50**,不是「守了又破」。整局 LevelUp 花销 40-56 金(追级局)。
2. **LevelUp 时点金 <50 占 13.3%**(78/586 次;<30 已被 r354 前的门消灭)。

形态:边缘局每轮金在 40-50 徘徊、反复够升级门槛(boss-breaker 窗 r5+ 地板仅 10,总成本门过即升),50 永远攒不满。[28]「50 金通关 P1」基准不达。

口述权威 [12]:「连 50 金都没凑到不急着升级——**追级的前提是息引擎已立**;前期收入撑不起边吃息边追级」——该判据此前从未进代码(升级资格只看时点金)。

## 决策

LevelUp 资格(lv≥5 追级段)= 原有门(时点金/总成本)**且** 息引擎已立:

```
息引擎已立 = 本局曾达满息(session.v2_ever_full_interest latch)
             或 本笔升级总成本花完后金仍 ≥50(_INTEREST_FLOOR)
```

落点(`line_strategy.py`):

- **boss_breaker 窗(r5+,主漏点)**:r354 总成本门之上加引擎门;未立且花完 <50 → 拒 LevelUp,金攒息(日志 `[cw][boss-breaker] LevelUp ... 息引擎未立 → 拒`)。
- **追赶(catchup)升人口**:同辖;拒升时形态件购买照跑(war 地板自守),st2 只扣真实提案的花销(修复随带的账务一致性问题)。
- **经济象限 lv≥5**:原门 `gold - xp ≥ 50` 即「单击花完 ≥50」,**按构造已满足引擎条件**,零改动;lv<5 的 r263 宽松门([13] lv5 过渡成型基线)不受辖——豁免边界。

### latch 语义(取舍点)

「曾达满息」采样在 **decide_prep 分发之后**(薄包装):本笔决策的升级门读的是「**此前**是否曾达」——首次到 56 的当轮(56-20=36<50)不被自家采样解锁,拒;该轮若守住 ≥50,latch 置位,后续轮放行。理由:若采样在分发前,任何一轮金到 50+ 都立即解锁「花光到 10」的整段追级,门形同虚设;「曾达」的从严解读 = 引擎必须**站住过一轮**,与 [12]「凑到 50」语义一致。

[17](满息即花,节点无关)由第二臂保住:花完仍 ≥50 的富余升级任何时候放行(gold-total≥50);被挡的只有「花掉息基本体」的追级。

## Considered Options

| 选项 | 结论 |
|---|---|
| **A(选定):曾达满息 latch ∨ 花完≥50** | 双臂覆盖 [12] 字面与 [17] 富余语义;latch 局内单调,重启丢 session 与 v2_state 同语义(保守回 False) |
| B:连续满息轮数门(如连续 2 轮 ≥50) | 更严但样本边缘局可能永远凑不齐连续窗 → 升级永久冻死,人口杠杆丢失;压测未支持需要这么强 |
| C:只加「花完 ≥50」单臂(无 latch) | 56→36 的首达轮被挡 ✓,但之后每轮富余反复被挡,升级节奏比 A 慢;latch 表达「引擎已立」的直接语义 |
| D:lv<5 也辖 | 与 r263(攻略[13] lv5 基线,局15 判读)冲突——早期到 lv5 是过渡成型的一部分不是追级;旧锁 test_early_low_level_relaxed_gate 锁的就是该语义 |
| E:只在 boss_breaker 加,catchup 不动 | catchup 罕见但同属追级形态(_CATCHUP_MIN_LEVEL=6);一致性优先,成本近零 |

## 后果

- **预期**:40-49 桶追级局的升级花销被挡 → 金积累 → 过 50 → latch 放行;`p1_exit_gold_ge_50` 违规率从 25.9% 下降(目标 <15%)。
- **权衡(如实报)**:追级变慢可能推迟成型(等级→人口→板深链路),hp 指标可能受压——sim A/B 的 hp_ge_60/avg_final_hp 对照为准,恶化如实记进度树;若恶化显著,回旋余地是 latch 臂放宽(如「曾达 45」)或仅辖 boss 窗。
- 检查项 `levelup_interest_engine_gate` 入 sim 批量检查集(锁 15% 报警线);账本近似声明:升级前等级用上一轮账本 level、时点金用 shop_waves 首波金,「gold-cost≥50 但时点金<50」的合法升级会被保守误报,高发时按 seed 重放精查。
- 锁更新:`test_cw_r354_levelup_total_cost` 的 allows 用例(金 30→55)——旧断言的「升得完就升」在新门下补了息引擎维(r354 总成本语义不变,锁改用双门皆过的参数)。
