# ADR-0421: 无名勋礼购买推广页建档与返回大世界退出分支(W293)

## 背景

2026-08-26 版本更新后,无名勋礼新增**版本周期首进购买推广页**(整屏广告):周期内第一次进无名勋礼先落该页而非主面板(用户口述,最高权威)。编排者 2026-08-27 实机 live 实证完整退出链四步全走通:

1. 推广页 → 点「开启无名勋礼」(**查看/继续语义,不付费**,用户裁决)→ 弹「无名勋礼等级加速」说明弹窗;
2. 弹窗 → 点弹窗内「点击空白处关闭」提示位关闭(点弹窗外部无效)→ 无名勋礼主面板;
3. 主面板 → 点右上角「按钮-关闭」→ 菜单页(既有「菜单」分支接管:开拓等级 → 右上角返回 → 大世界)。

此前 `BackToNormalWorldPlus.check_screen` 无这三屏的分支:推广页/弹窗帧前序分支全不命中 → 落兜底点「菜单-右上角返回」。推广页该坐标无对应控件(点击无效)→ 与 W0824/W286 同型的 WAIT 兜底死循环风险;弹窗帧则可能误触模糊命中的他屏「点击空白处关闭」area。

## 决策

**建档(三件套)**:按 od-dev-screen-onboarding §3 子态归属判据,弹窗为全屏遮蔽 overlay(盖灭父屏 id_mark)→ 各建独立 screen_info:

- `nameless_honor_promo`(无名勋礼-购买推广页):id_mark 组合 = 「开启无名勋礼」按钮文字 + 「请适度娱乐,理性消费」提示(本页独有长文本,双锚增强区分)。
- `nameless_honor_levelup_popup`(无名勋礼-等级加速弹窗):id_mark = 标题「无名勋礼等级加速」(独有);交互区「按钮-点击空白处关闭」pc_rect [850,708,1070,765]——与主面板领取弹窗同名 area(y≈945)坐标不同,必须独立建模。
- fixture 各一张归档测试仓 `screens/`(2026-08-27 live 截图);画面 doc ×2 + 主面板 doc 入口流转更新 + 玩法 doc 补版本首进机制 [口述] 条目。

**退出分支**:`check_screen` 在货币战争-大厅分支后、对话守卫前补三支(W286 大厅分支同构):id_mark 命中即正面识别 → `round_by_find_and_click_area` 点该屏退出 area → `round_retry` 逐帧重识别。中间态(弹窗/主面板)无跨轮状态,靠逐帧重识别天然容忍;点击不落地时 RETRY 计入 `node_max_retry_times=20` 有界 FAIL(拒绝 WAIT——框架语义 WAIT 不消耗 retry,见 W0824/W286 判例)。项目规则:零 ESC 键输入,关闭一律 screen_info area 点击。

## Considered Options

1. **采纳:两独立 screen + 三连 retry 分支**(本批)——id_mark 精确命中即退出,无识别歧义;与 W286 已验证结构同构,维护面一致。
2. 拒:弹窗/推广页挂 nameless_honor 主屏 area——弹窗模糊背景可能残留父屏可匹配文本,独立 id_mark 更稳;且主屏 yml 已有同名「点击空白处关闭」area(y≈945)会与弹窗提示位(y≈737)撞坐标语义。
3. 拒:推广页点坐标 (1520,778) 裸点——W286 裸坐标邻点教训(1857,63 误开攻略详情页),坐标必须进 screen_info area。
4. 拒:分支放对话守卫之后——守卫对推广页右侧面板文字有「未知对话选项」误判风险(run 46 同型),画面专属分支必须在守卫之前正面接管。

## Consequences

- 周期首进无名勋礼后遗留的推广页/弹窗不再卡一条龙;测试锁 3 条(推广页分支有界 FAIL + 弹窗/主面板两中间态各锁点击 area)。
- id_mark 全集测试绿(121 passed / 81 skipped,新增 2 fixture 定向复核真阳性 + 无碰撞 2 passed);直测 10/10。
- 实机回归不需要:退出链已由编排者 live 走通,本批为建档 + 分支落地 + 结构锁。

## 判据与验证

- 判据:用户口述(版本首进机制 + 点开启不付费)+ 编排者 live 退出链实证(2026-08-27,截图存档 `.debug/sr_od_mcp/screenshot/screenshot_20260827_185941_767254.png` / `..._190554_379781.png`)。
- 验证:ruff(主仓 op + 测试仓测试文件);直测 `test_back_to_normal_world_plus.py` 10/10;id_mark 全集 `test_id_mark.py` 0 failed。

## Scope 扩充:app 领取后同款弹窗候选(2026-08-27 run 48 实证补充)

run 48 实机:无名勋礼 app 领取奖励(`按钮-奖励-一键领取` 点击成功)后也会弹同一张「无名勋礼等级加速」说明弹窗(标题 (834,378) + 提示 (875,723)),`_check_screen_after_reward` 旧三候选(secondary UI/奖励-取消/主面板「点击空白处关闭」)全不命中 → 「未知画面状态」×4 → op 失败(组自愈继续)。修法:`_check_screen_after_reward` 补第四候选——命中「无名勋礼-等级加速弹窗/按钮-点击空白处关闭」(独立屏 area,提示位 ≈(960,737),点外部无效)→ 点关闭 → `round_wait` 重跑本节点等回主界面。同屏建档零新增,复用本 ADR 的弹窗 screen_info。测试锁 +2(弹窗帧走新候选 WAIT 且不触旧候选 / 主面板帧 secondary UI 路径不变)+ 契约引用 +1。
