# ADR-0450: 备战 x/y 读数器位置感知解析 + 语义约束验证器(W529)

> **引用勘误(2026-09-04 ADR 存量 review)**:`.debug/` 归档 → 本目录(decisions/)同名 ADR。文内出现处按此对照读取。

## 背景

「X/Y(上场数/上限)」指示(``区域-部署数``,``_read_deploy_paddle``)旧解析层 =
整块 OCR → 文本拼接 → 正则提取。两个实证死穴(58 帧 fixture 逐框 OCR,
``.debug/temp/currency_war/w529_xy_reader_impl/``):①斜杠被 OCR 读成数字时拼接串
成纯数字,正则全崩返 None(实拍 ``攻略已应用`` 帧 '717'=7/7);②左侧人形图标紧贴
数字被并入('10/3'=0/3、'18/8'=8/8,'i'/'1' 前缀),旧 X>Y 守卫只能部分兜。
固定偏移蒙版方案被编排者蒙版实验证伪:图标/数字起点逐帧漂移,[0:55] 条带在 0/3
帧切掉 '0' 左缘且留图标残余。

## 决策

解析层升级为**位置感知解析 + 约束验证**(守卫层全保留作第二层):

1. **几何字形分割**(剔图标):OTSU 二值化 + 连通域,h≥45 留数字/斜杠字形
   (图标头 h≈19/身 h≈39 恒低于线,58 帧亲测),细长字形(面积<450,实测
   356-370;数字含 '1' 均 ≥550)判斜杠 —— 形状过滤而非固定偏移。
2. **对齐候选 + 歧义裁决**:OCR 文本数字串按「斜杠位」与字形对齐,三种对齐
   (直接/去首/去斜杠位)生成候选,过语义约束验证器(x≤y、1≤y≤13、y≥level,
   level 由 ``read_deploy_cap`` 可选参数传入);有直接对齐候选取之,否则候选
   唯一才采,多候选歧义 → None + ``obs_conflict`` 留证。零重帧:解析失败不重截,
   重帧仍归 ``read_deploy_cap_debounced`` 域外防抖(瞬时误读须跨帧识别,同帧源
   不可替代 —— 评估结论:维持现状)。
3. **两级 OCR**:一级原生裁片 OCR;解析失败 → 二值化抹图标重 OCR(图标移除后
   rec 斜杠还原率显著提升,'717'→'7/7' 实测),同帧源内重试。

## 效果

58 帧全量对拍(真值 = VLM 逐帧亲读,2 帧遮挡不评):新管线可判帧 56/56 全对
(含旧层死穴 '717'=7/7 帧旧层返 None);旧管线 55/56。约束验证器另在构造
真值表锁定歧义拒('317' 双候选)与 level 滤选。发现并修正编排者锚点偏差:
``补给节点.webp`` 备战帧 paddle 实际显示 4/4(VLM 亲读),「无 x/y 显示」
结论不成立。

## 边界与后续

- 二级 OCR 对空心字形(0/6/8)会加幻影前缀 '1'('16/7'=6/7 实测),已并入
  「去首对齐」候选吸收;若未来出现系统性新形变,先补 fixture 再扩对齐规则。
- overlay 遮 Y 帧(equip_detail_synth_target)双级皆 None + 留证,语义正确。
- 真值标注(VLM 亲读)与 W526/W531 批同款方法论;无既有 ADR 引用变化。
