# 货币战争-模式选择(进入标准博弈)

大厅点「开始」后的模式选择屏(标准博弈 / 超频博弈),确认后进难度确认。

## 何时出现 + 状态流转

- **入口**:大厅「开始「货币战争」」→ 本屏。
- **出口**:点「进入标准博弈」→ 难度确认屏(开始对局前)。

## 识别特征(稳定锚点)

- 独有文字:「进入标准博弈」+「超频博弈」(模式 tab,大厅 / 难度屏都没有)+「当前职级 A8 财富造物主」。
- 易变值:周额外晋升点、通关奖励数值、连胜次数。

## 可交互元素

- 「进入标准博弈」按钮:右下,圆角矩形。OCR 可读。点 → 难度确认屏。
- 顶部 tab:「标准博弈」「超频博弈」(bot 走标准)。
- 底部:「对局记录」「职级奖励」(bot 不操作)。

> 全文字,OCR 够,无 screen_info / 模板需求。`StartCurrencyWarMatch` 用「进入标准博弈」OCR 检测 + 点击。

## 识别快照

- 匹配画面:`screens=[]`(OCR 关键词检测)。
- 关键 OCR:「进入标准博弈」(1564,946)、「标准博弈」「超频博弈」tab、「当前职级 A8」「财富造物主40」、「周额外晋升点：1500/1500」、「通关可获得积分 18000」「通关可获得晋升点 2700」、「连胜次数：0」。
- 视觉大模型(主观):深蓝背景,左模式列 + 右详情 + 底按钮栏;进入标准博弈按钮右下圆角。
