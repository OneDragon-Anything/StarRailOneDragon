## 0. 依赖链的实然形态(先纠正一个前提)

登记里的依赖链图写「实机语料(151局)→标定→λ_death 分层表」。**实然链路是三段、两跳,不是一段直标**:

```
实机语料(冻结时点 417 条战斗差分;P2 段 21 run 语料)
   │ 拟合
   ▼
sim 战斗表(coarse_battle P1 两态表 + P2CombatCalib 参数族)
   │ 引擎跑 A/B 批(40 seed × 两臂)
   ▼
AB sim 账本(=P51 标定的直接数据源)
   │ 标定
   ▼
λ_death 分层表(P51 §4-B-2)→ 三段管辖/P51 等待代价/卖面惩罚/floor_eff 投影(P48/R2)
```

证据:P51 标定脚本 `p51_v2_calib.py` 读的是 `AB_{cw3,legacy_v2}_n40_*` 目录(脚本头自注「120 局 = 6 数据集 × 40 run」;`run_ab_batch.py` 证实这些是 `engine_p1.simulate_p1` 的 **sim 产物**);P51 边界 4 自认「辖域:sim、位面 1-2、两策略臂」。sim 战斗表本身来自冻结实机语料(`cw_coarse_battle.py` 模块头:「全部出自生产 replay 冻结语料 417 条战斗类差分」;P2 段来自 `w193_p2sim/` 的 **21 run** 语料,`cw_battle_tables.py` P2CombatCalib 注释自认「21 run 语料只够钉边界不够点估计 β」)。

**含义(推导)**:λ_death 不是实机死亡的直接统计量,而是「sim 战斗模型参数的确定性函数 + 40 个 seed 的蒙特卡洛噪声」。它的 CI 覆盖什么、不覆盖什么,是第 3 问的核心,见 §3。

## 1. 问一:保守性声明的反面——「λ 错=少赚不送死」闭环吗?

**判决:不闭环。反例形态存在且有语料实证——但精确的失效机制不是「λ 数值偏小」,而是「λ 的自变量缺了承重维」,方向恰好制造守息致死螺旋。(强度:实证+推导)**

### 1.1 反例的构造(推导)

λ_death 以 (战力桶, 节点类型, 视界) 为自变量,§R.3 明令 hp 不入自变量([39] 纪律:hp 是运营质量下游表征,不作因果输入)。等待成本 W_floor=λ×(g+Φ) 在「λ≈0 段」路由为守息。若真实危险率主要由 hp/进程承载(下证:同桶内 hp 分层 λ 差 0.000→0.904),则:

> 早期轮 λ 查表≈0 → 守息 → 金囤而战力停滞、hp 被磨到地板 → 进 P2 时已处必败态 → 死时携金全损。

「保守」(少消费)在这里不是少赚,是**把转化窗口错过到不可逆**。死亡是延迟兑现的,查表那一刻 λ 显 0,闭环声明成立;死亡兑现那一刻,它不成立。闭环只在「λ 误差=同状态内数值小幅扰动」的窄假设下成立,对「自变量缺失型误差」开环。

### 1.2 语料实证

**sim(cw3 r3 臂,P51 标定语料本身)**:
- 35/40 死亡;**死时金中位 194、均值 193**(legacy 对照臂 95/106)——保守臂死得更富,携金全损量 ~2 倍;
- **22/35 死亡局死前 5 轮买/合并/升级动作数=0**(完全零动作),17/35 死在 P2r1(进 P2 第一战)——死局在 P1 已经定型;
- 死亡局数:保守臂 cw3 s0=40/40、r3=35/40,**多于**消费臂 legacy 30/40——「保守不送死」在自家标定语料上方向就是反的(35>30,幅度不大但绝不是「只少赚」)。

**实机(154 可判局)**:
- 52 局死亡(全部死于 P2/P3,末行节点 53 普通战斗+1 boss;死前一行 hp 分布:1×32、3×7、0×6——死前普遍贴地板);
- 死时金中位 60,p75=76,**35/49 死时金≥50**(≈可买 3-5 张牌的量没花出去);
- **52/52 死亡局死前 5 轮零买卖/升级动作**(注:此处含 telemetry 可能在濒死段丢决策行的备选解释,方向证据与 sim 侧一致但不单独立证)。

**P10_VALIDATION 独立复核同方向**:现行 AB 账本上「死亡局出口金均值 ≥ 存活局」(cw3 r3:死 157.9 vs 活 106.8)。

### 1.3 诚实的反方向披露

- 死得富 ≠ 「当时花钱能活」:sim 的 P2 模型 β=0.04(保守取值,未点估计)下,花钱升 form 对胜率边际极小,反事实「若当时消费」在 sim 内也大概率仍死——**「守息致死的因果性」与「消费本可救」是两个命题,后者在现语料不可识别**(P51 自己的 B3/Δλ 不可识别声明与此一致)。
- 但闭环声明的举证责任在声明方:「λ 错=少赚不送死」需要证明保守误差不增加死亡,而 35/40 vs 30/40 + 死时金 194 的形态至少证明**该命题未证且方向存疑**。结论:保守性声明必须降格为「未证假设」,禁止在设计件中当既成防御引用。

## 2. 问二:桶可交换性——桶内状态真的近似同分布吗?

**判决:不成立,且不是边缘性不成立。P51 用的三桶(deployed_power ≤7/8-12/13+)桶内,危险率与胜率按可观测亚组分层差 3-25 倍;桶可交换性作为「近似」都不够格。(强度:实证)**

### 2.2 机制注(推导,部分实证)

- P1 行 λ3 恒 0 有双重成因:①实机/游戏侧 P1 确实几乎不死(实机 54 死局全在 P2/P3——真实成分);②sim 侧 P1 coarse 模型败局地板钳 hp≥1(`cw_coarse_battle.py` `CLAMP_HP=1`),P1 结构性不可能死,**P1 段的 λ≈0 在 sim 里是构造性恒真**(与 P51 v3 已废掉的「距终>6 轮 λ3=0.000」同型问题,只是从视界维挪到了位面维)。两者叠加,「早期段 λ≈0」的实证强度被 sim 结构虚增。
- star_depth 在 p13+ 桶内把 λ 从 0.000(0 星深)切到 0.283(1+ 星深)——**装备/星级维正是登记疑问里点的「同桶有无装备差异巨大」**,直测成立(实机侧同板深桶内按装备数分层胜率差较小:9-11 桶 0.289 vs 0.290,但那是 P1 胜率口径、装备数≠星级深度;sim 侧星级深度信号强)。
- §R.3「hp 不入自变量」的因果论证(用表征预测表征的循环)对**因果解释**成立,但 λ 表的用途是**风险路由的状态函数**——预测器禁用 hp 等于主动放弃表中 25 倍的信息梯度。「hp 不能当原因」推不出「hp 不能当风险分层键」,这是本设计中代价最大的一步推理跳跃。

## 3. 问三:sim 循环性——注入扩样是零信息还是有信息?CI 计价了模型风险吗?

**判决:注入扩样对「桶内异质性」与「版本漂移」严格零信息;CI 计价的是「模型参数固定不变」前提下的 seed 噪声,模型风险(参数不确定+结构不确定)完全在账外。(强度:实证+代码直读)**

### 3.1 循环结构(代码直读)

- sim 战斗表 P1 层:`cw_coarse_battle._WIN_TABLE`(冻结语料 417 差分拟合)+ plaza Beta 收缩(先验 0.35,份额硬顶 25%);
- P2 层(AB 批里**所有死亡的发生器**——P1 被钳在 hp≥1,死亡只能由 P2 结算产生):`P2CombatCalib`,参数 p0=0.11(语料边际 1胜8败的下沿)、**β=0.04(自认「量级未定→保守值」)、γ=0.02(「轮梯度未识别」)**,败局掉血带(带内均匀 randint),掉血带校准自 21 run P2 语料且 **hp_after==1 的删失样本被弃**(`cw_battle_tables.py` 注释:「hp_after==1 为败北地板删失样本弃」——濒死带观测被系统性剔除后拟合「濒死带伤害」,方向性偏置);
- 胜率钳制 win_p_clip=(0.0, **0.5**):无论板面多强 P2 胜率封顶 50%。

所以 λ_death 的数值大体上是这样一个函数:**λ ≈ P(P2 均匀掉血带抽签在 3 轮内置你于死地 | p0+β·form−γ·drift 决定的胜率)**。β、γ、带宽、clip 四个自由参数里两个自认未点估计、一个建立在删失样本上——λ 表的「带 CI 的实证外观」下面是 4 个半猜参数。

### 3.2 注入扩样的信息含量(推导)

「注入扩样」= 用同一战斗模型换 seed 多跑。它增加的是蒙特卡洛样本量,**不增加任何关于以下两者的信息**:
1. **桶内异质性**(模型里危险率的全部条件结构就是 (node, rung, plane, form, round) 的查表/参数式——hp/gold/星级对危险率的影响在生成机制里不存在或仅经 form 弱耦合,扩样一万倍也不会冒出来);
2. **版本漂移**(冻结语料时点后实机胜率在动,见 3.3)。

唯一注入的「新信息」是 plaza 先验 0.35(外部攻略统计)——一个上限 25% 份额的外部收缩,算一点独立信息,量级杯水车薪。

### 3.3 版本漂移的实测(实机语料直查)

实机 P1 战斗胜率按日期段:**08-22~24: 0.227 → 08-25~27: 0.214 → 08-28~31: 0.296 → 09-01: 0.500(n=12,小样本)**;P1 板深桶 12-14 内:前半(≤08-27)0.216 vs 后半 **0.382**。语料是多版本策略混合(P9_VALIDATION 已登记),同板深桶内前后半胜率差 +17pp——冻结于早期时点的 sim 表对当前策略是**系统性低估胜率=高估死亡危险率**的漂移方向。没有任何自动化的 λ/胜率漂移检查在运行(全仓 grep 无 held-out 验证 λ_death 的工件;总纲声称的「held-out 验证/漂移检查」两项防御**查无对应物**,是登记里的虚防御)。

### 3.4 CI 口径(复算)

P51 的 run 级 cluster bootstrap CI:重抽的单元是「40 个 seed 轨迹」,模型参数不动。实测 p8-12×battle×P2 格:λ3=0.610,seed 噪声 CI=[0.528, 0.697](带宽 0.17);同一格只要叠加 ±0.03 的系统性模型偏移(β 从 0.04→0.05 量级即可产生),CI 带宽翻倍到 [0.419, 0.731]。而 §2 实测的亚组异质性是 ±0.3-0.9 量级——**比 CI 带宽大一个数量级**。结论:CI 把模型风险当成了不存在的东西,不是「当成了采样噪声」,是根本没进账。

## 4. 问四:尾部可靠性——濒死带样本与 0.1 阈值附近的翻转敏感度

**判决:尾部样本绝对量勉强够撑「方向」,远不够撑「路由」;决策翻转余量实测为 CI 下界的 9%,而亚组/模型扰动量级是其 3-10 倍——0.1 阈值带内的翻转不是边缘风险,是常态。(强度:实证复算)**

### 4.1 样本清点

- P51 分层表最消费敏感的格子:濒死带 p13+ 桶 pooled n=311 轮,其中 **λ3=1(实际 3 轮内死)的行仅 60(43+10+7),分别由 21/10/7 个 run 贡献**;p13+×boss 格 59 轮里只有 7 行支撑。cw3 侧 p13+ 全桶仅 21 轮(P51 自表)。
- 实机濒死带:P2+ 战斗行 hp_after≤10 共 **94 行**;P3 战斗行 **8 行、0 胜**(位面 3 的 λ 真值=不可估);P2 战斗 killed 已知值 26 胜/188 败(胜率 12%)。
- w193 P2 校准语料:21 run;P2 掉血带拟合时 hp_after==1 删失行被弃(濒死带最关键的观测被剔除)。

### 4.2 翻转敏感度复算(独立复算,P51 §4-B-2 全表逐格复现一致:0.065/0.042/0.021、0.341/0.266/0.151、0.223/0.169/0.119;混合 p13+ 0.193×132.3=25.5 与文档 25.5 逐位一致)

- **§7-1 最弱结论(濒死带转化优先)的余量**:翻转条件 λ3<15/D=0.113(pooled p13+ 格);点估 0.193 裕度 41%,但 P51 自己引用的是 CI 下界 16.5 → **CI 裕度仅 9%**。而同一格内 hp>40 亚组 λ3=**0.000**(n=173):决策状态若落在该亚组,「濒死带转化优先」整条翻转、守息支配。也就是说:**9% 的名义安全边际面对的是同格内 0.19→0.00 的真实离散**。
- **行级翻转面(桶混合 λ vs hp 亚组 λ,W/3 对 cap=5 的路由比较)**:p≤7 桶 P2 行 **55%** 翻转、p8-12 桶 19%、p13+ 桶 28%。总纲防御清单里的「粗桶二值路由」恰是翻转损伤的落点:粗桶路由不是防御,是把 25 倍亚组差平均掉的噪声注入器。
- 早期段 0.1 阈值(p≤7 分层 CI 上界 ≤0.091):±0.05 的 λ 扰动(亚组差/漂移量级)足以把整段判定翻面——该阈值的支撑带(0.021~0.091)整体住在亚组异质性的阴影里。

## 5. 问五:替代姿态——不依赖 λ 标定质量的方案各自代价收益

**判决:三条替代线各有真实代价,但「hp/进程键的结构化分段」不是外来的新方案——生产代码里已经存在,且它捕获的正是 λ 表丢掉的那 25 倍梯度。推荐 posture:结构规则为主干 + λ 表降格为敞口注记 + 局内序贯示警为补充。(强度:推导,部分实证)**

| 姿态 | 收益(实证面) | 代价 | 可否作兜底 |
|---|---|---|---|
| **minimax(按最坏情况)** | 对 λ 模型风险免疫(不消费其数值);不可逆决策本就 fail-closed,方向一致 | 最坏情形下 P2 死亡率≈1(40/40 都死过)→ 全程激进消费,息账/攒 S 全废;sim 里「最坏=必死」使 minimax 退化为「反正要死不如花光」,与守息纪律直接冲突 | ❌ 不可作主姿态;只宜在不可逆决策上沿用现有 fail-closed |
| **纯结构规则(手写纪律,不查表)** | 生产已存在并运行:`cw_economy` hp<30 急救门、hp≤25 只升不买、blood_margin_low_hp=40、boss 税 p75 分位锚——这些 hp/进程键规则捕获了 §2 实测的最强危险率梯度(hp 分层 λ 0.000→0.904);零标定依赖、零循环 | 失去中段的 EV 精细优化(何时破息、卖面定价),判据间可能互相打架;阈值本身也是拍的(40/30/25)——但它们的「拍」是直接对观测形态的拍,不经过一层会放大偏置的参数化 sim | ✅ **事实上已是现行生产的主干,推荐正式确认为兜底** |

## 6. 总判决

**λ_death 基座 = 「需兜底」,不可按当前形态作三段管辖的路由权威。** 具体拆三句:

1. **λ 表作为「方向/量级注记」可用**(P51 v3 自己已降格到区间敞口、禁边际引用、禁闸门——这个自我降格是对的,应保持):「囤金随死清零是等待代价第一载体」「存量占比 63-78%」这类方向结论,在 sim 与实机两侧形态一致(死时金≥50:实机 35/49,sim 35/35),作为 EV 里的定性成本项站得住。
2. **λ 表作为「路由/翻转敏感判据」不可用**:①桶可交换性被直证证伪(同桶亚组 λ 0.000~0.904,§2);②CI 只计 seed 噪声,模型风险(β 未点估计/掉血带删失拟合/胜率 clip 0.5/P2=P1 别名)完全账外(§3);③最弱结论的 CI 裕度 9%,面对的扰动量级是它的 3-10 倍(§4);④「保守不送死」闭环被自家标定语料方向性证伪(35/40 vs 30/40,死时金 194,§1)。
3. **兜底形态(强化清单,按优先级)**:
   - **R1(必做,零新标定)**:三段管辖的路由键改为决策时可观测的 hp 带 × 位面/轮序 × 节点类型——即把生产已有的 hp 结构规则(hp<30 急救/40 血线/25 只升不买)升格为三段管辖的正式分段面;λ 表降格为该分段面之上的敞口注记(修正 §R.3 的过度推广:「hp 不作因果输入」≠「hp 不作风险路由键」,分两条写);
   - **R2(必做)**:撤回总纲防御清单中的「held-out 验证/漂移检查」两项虚防御,补真工件:冻结表 vs 滚动近 N 局实机的胜率/危险率漂移哨兵(§3.3 的 17pp 漂移应能在 3-5 局内报警);
   - **R3(应做)**:P2 掉血带重拟合,恢复 hp_after==1 删失行(濒死带最关键观测);β 至少给敏感性带端点扫描而非单值;

- **P37v2 复算**:E[I_gain]=q_full×5,q_full 原标定=W959 **sim 批**(n=300,无 CI)。本批实机 154 局健康带(r4-r7 ∧ hp>25)465 轮:**q_full=0.269**(前半 0.259/后半 0.278——版本间稳定,说明是 sim-vs-实机校准差不是漂移;P1 0.261/P2 0.375)。→ E[I_gain]=**1.34 金/轮 > 带上沿 1.25**。「最劣格 L_min/E[I]max=1.25/1.25=1.0× 恰闭合」在实机 q_full 下变成 1.25/1.34=0.93×——**闭合阈值 ρ* 从 0.25 升到 ~0.28**,「2.0×/4.7× 裕度」的下端格不成立。P37v2 自我定位是保守折价假设+不授权数值(ADR-0482 形式上吸收此击穿),但其裕度叙述需按实机 q_full 重标。
- **P35**:摊还账结构(v>d 恒负、息线分域闭式、付清形态实证 k≤4)全部机制级/注册表级,零语料拟合;参数带(Δp/w/L_c)全部显式未标定或挂账(卡点①②⑤),结论以「结构背书,不作数值授权」形态消费——**同病暴露低的原因是它自己把数值面全关了**。侧注:总纲全景表给 P35 标的「0.78-1.48 金/轮」在 P35 正文查无此数(P35 用 v=Δp·L_c+w 的四标定点,非该区间)——**全景表该格数字无来源,建议修表**。
