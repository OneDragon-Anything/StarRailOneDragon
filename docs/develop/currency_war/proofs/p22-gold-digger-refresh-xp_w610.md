> 口述来源(最高权威):用户 2026-08-30 实机发现「当前局拿到淘金客后,完全不用买经验了,一直刷新商店就好」。

## 1. 命题

**P22 主命题**:持有淘金客(一般化:聚效果 `xp_per_refresh>0`)时,设

- 刷新的每金经验汇率 `r_refresh = xp_per_refresh / 刷新实付金`
- 买经验的每金经验汇率 `r_buy = XP_PER_BUY / xp_click_cost`

则 **`r_refresh ≥ r_buy` 当且仅当 `xp_click_cost ≥ REFRESH_COST_BASE × XP_PER_BUY / xp_per_refresh`(基参数下 = 4金)**;在等号成立时刷新**弱占优**(附加免费重掷价值 ≥0,期望严格优),在 `xp_click_cost > 4` 时刷新**强占优**;`xp_click_cost < 4` 时命题**失效**(买经验汇率反超),此为唯一例外域。

## 3. 严格占优的重掷侧(平汇率下打破平局的论证)

汇率相等时,刷新相对买经验的净优势 = **免费重掷期权价值**:

1. 每次 2 金刷新除 +2 XP 外,重掷 5 格商店——对任意「存在想要卡片」的目标分布,重掷的搜索价值 ≥0;[31] 刷新金只用于找目标件的既有语义下该价值在实际对局恒 >0。
2. 买经验无任何附加产出。故同金支出下刷新的收益向量 = 买经验收益向量 ⊕ 重掷价值 ⇒ **弱占优;重掷价值>0 的帧上严格占优**。
3. 反向顾虑(刷新销毁当前店内可买牌)被**动作次序不变式**消解:先买后刷,可买牌不因刷新损失——刷新从不比「买经验+不刷」差。
4. 息账两侧同构:每金对息线的影响相同(同为现金支出),利息机会成本在两通道间无差异,不改变比较。

**边界(非经济面,如实记)**:执行层每刷一次有 ~1-2.5s 动画/两帧一致等待(shop.py 刷新分支),大量刷新有真实时间成本——是吞吐边界不是期望边界。

### 4.2 免费刷新是否计 XP

注册表原文限定「**消耗金币**刷新」⇒ 免费刷新(概率事件 300401 / 本金充裕 301001 / 及时雨 300701 / 搜打撤 303701 等来源)**不计 XP**——文本证据充分。局23 无任何免费刷新来源在场,**遥测无法独立验证此边界**(数据边界如实声明);消费侧按 `cw_economy._refresh_cost` 的免费额度先行语义处理,XP 采集/reconciliation 只认 `Δgold=−2` 的付费刷(ADR-0456 `free_refresh_proc` 判据:牌面变∧Δgold=0 ⇒ 免费,不记 XP 事件)。

### 4.3 数据边界声明

- 局23 = `run_20260829_130420`(任务书口语「1303xx」为约记;该时段唯一在飞 run)。

## 5. 策略含义(供规则规格引用,细则归 REPORT)

1. 淘金客在场(通式条件成立)时,**买经验通道整体退役**——升级推进改由 2 金刷新承担;`clicks_to_next_level` 的预算位置换成 `ceil(Δxp/2)` 次刷新。
2. 唯一回退条件 = `xp_click_cost() < 4`(商业间谍折扣),届时恢复买经验优先。
3. 刷新同时供给 XP 与搜索,定向买牌(W578 评分)与找件刷新(ADR-0409 M-A)在「先买后刷」次序不变式下协同,不新增授权通道竞争。
