# DD-021: board 阵营计数系统性低估修复——计数源五级优先(徽标>XY>容错>徽标重读>身份底座)

Status: accepted
日期: 2026-09-03

## Context(背景与证据)

备战画面 board 阵营计数(左面板)存在**系统性低估**:识别修复池 G 挂账 90+ 条
`obs_conflict('board', ...)` 冲突,典型形态 = OCR 读数恒低于身份 computed
(持续伤害 ocr=1~2 vs computed=2~3;狼狩 1 vs 2;仙舟 2 vs 3)。W287 裁决
(采新-badge)使备战帧直接采信 OCR 读数 → 低估直通 `state.board` → 羁绊激活档
判定错档 → form_progress/评分污染。

对冲突帧离线对拍(整面板裁切 OCR 原始行 + 视觉判读)定位到**三个独立低估源**:

1. **档位链误配**(f1173e2d 等):部分阵营(持续伤害 2/4/6、护盾 2/4 等 tiers≤3
   的阵营)面板显示的是**档位链**而非 "X/Y",计数在图标旁的**徽标数字**里
   (徽标"3" + 链"2/4/6")。旧解析的 `(\d+)\s*/\s*(\d+)` 正则把链中前两档
   "2/4" 当 count=2;链整体失读时兜底 count=1。
2. **斜杠丢失**(3db91784):小字 "X/Y" 的 '/' 被 OCR 丢读或误读成 '1'
   ("2/3"→"213"、"1/2"→"11"),正则不命中 → 兜底 count=1(真值 2)。
3. **徽标整体失读**(86ce9fd1/9c9e174d/d8018638):整面板原生分辨率 det 漏检
   小徽标(3db91784 持续伤害徽标"3"完全无读数),OCR 侧证据穷尽后旧链恒 1。

## Decision(裁决)

`_board_pairs`(obs/cw_observation.py)计数源改**五级优先**,逐级兜住上述三源:

1. **徽标数字**:名称列左侧(x<104)的纯数字小 token(徽标几何位置固定);
2. **"X/Y" 正则 X**(斜杠读全时,原行为);
3. **斜杠丢失容错**:纯数字 token 原串直拆/删一个 '1' 后拆 (X,Y),硬校验
   X∈[1,level] 且 Y∈该阵营注册表 tiers 且 Y>X(档位链 "21416"/"246" 拆不出
   合法对,自然拒绝,不误配);
4. **徽标小格放大重读**:仅对 1-3 全 miss 的兜底行,裁徽标小格
   (66,row±10..58) 3x 放大 OCR(失读根因与手法同 `_ocr_upscaled` 的
   det 天花板;3db91784 实帧对拍 3x 读 '3' conf=1.0),5x 重试;干净帧零额外开销;
5. **expected(身份 computed)底座**:4 仍 miss 时取调用方传入的身份推算值,
   不再恒 1——徽标失读帧无画面事实反证,身份推算即最优估计。**恒 1 是低估
   最后一环**(86ce9fd1:持续伤害/护盾真值 2,旧链读 1)。

配套两处语义修正:

- **next_tier 基于合并后最终计数**(原 bug:从 computed 底座算,徽标纠正上行时
  next_tier 停在前一档);
- next_tier 在无 Y 读数时由注册表 tiers 推(>count 的最小档),替代旧 "0=未知"。

honest(r319 语义保持):仅 1-4 级算 OCR 真解析;expected 兜底不算。

## Considered Options

- **A. 只调 OCR 预处理(放大/二值化整面板)**:拒——整条放大成本×N 且 det 对
  小徽标仍不稳(3db91784 徽标整格读空),不治本。
- **B. 徽标模板化(数字模板匹配)**:缓——需采 0-9 模板资产,当前容错+小格重读
  已覆盖实挂账形态;留作 4 级仍失读时的升级路径。
- **C. W287 裁决回退(改采 computed)**:拒——W285 实证 computed 3/6 采错,
  徽标可读时画面事实优先正确;问题在徽标**读不到**而非读错,分级兜底才对症。
- **D. expected 兜底(采纳,第 5 级)**:OCR 证据穷尽时的最优估计;风险 =
  computed 虚高时(SIFT 重复认人)board 跟着虚高——该风险属身份链(SIFT)
  责任面,由 computed_vs_ocr 冲突留证继续暴露,不在本批强修。

## Consequences

- 三低估源分别被 3/2/5 级兜住;8 帧离线对拍(≥5 帧含低估场景)全部对齐视觉真值
  (纯 OCR 链即对齐 6 帧,徽标失读 2 帧靠 expected 底座对齐);
- board 冲突 journal 的「频发 >10 行/时→排查对账纠漂链」触发线自此应大幅降噪,
  残余冲突行聚焦身份链问题(SIFT 漏认/重认),可作身份链修复批的输入;
- 测试:实帧回归 ×3(f1173e2d/3db91784/b6fc9934)+ mock 语义锁 ×5
  (sr-od-test test_cw_obs_chain.py / test_cw_obs_gates.py)。
