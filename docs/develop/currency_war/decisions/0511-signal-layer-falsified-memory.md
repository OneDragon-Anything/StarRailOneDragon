# ADR-0511: 信号层判死记忆契约(falsified)——缓期挂账,随首个判死写入端批次落地

## 状态(Status)

deferred(挂账缓期,编排者裁决采纳「方案 1」;交付=零码,本 ADR 即挂账记录)

## 背景(Context)

设计件:`docs/develop/currency_war/prereg/w961_exemption_conflict/DESIGN.md`(W961 架构反思批,含冲突形式化/解法对比/波及面/规格 §4 六条)。

语义冲突(形式化结论,两侧意图均带表达式级锚):同线重锁豁免(`kernel/cw_intention.py::_switch_gate_open`,「同线重锁(weak_comp==候选线)不辖」)的前提是「weak=暂时失向,原线仍是可退回的最优方向」——w665 换线门设计件 §3-3 R2「纠错通道饿死」教训的产物;假设失效评估(ADR-0509)则要求「锁线=可证伪假设,判死须能改判」。两者辖域重叠、前提互斥:停滞降级完全复用出口①字段契约,判死结论在层间接口处被压扁成与「暂时失向」同形的 weak 状态,信号层无失效记忆。实证 = ADR-0509 §Evidence 联合 A/B 负结果:33 例停滞降级的次日走向为回原线 12 / 落新线 8 / 次战即死 13,已判死原线被自家同线信号复活占可判读例 60%。

裁决要点(DESIGN §1.2):生存优先不作无条件压倒(判死后其守护对象已不在),降为高优先级例外;判死置信度必须落在信号层可见状态上。

## 决策(Decision)

**主推解法 A(判死记忆标记)缓期执行**:falsified 契约不单独落码,随**第一个带判死写入端的批次**同批落地——停滞臂重启批或 P1 pair 假设生命周期批,以先到者为准。本批交付 = 零码 + 本挂账记录。

**缓期理由**:方向侧判死机制(W948 停滞臂)已随 sim A/B 判负整机制删码(ADR-0509,开关生命周期第 4 态),falsified 的唯一合法写入端(判死评估触发分支)已离场;消费壳单独落地 = falsified 恒空、守卫永不开火,构成「有消费点无触发面空转」(ADR-0429 教训)与 strategy-work §4「新机制先验证它会开火」的违规形态,故消费端不先于写入端落地。

**随批平移的契约模块(实施批直接引用,免重设计)**:

1. 规格 = W961 DESIGN §4 六条(字段坐标系/写入端/消费点/过期点/验证阶梯/文档同步),要点:`IntentionState.falsified: dict[str,int]`(线名→判死位面,判死帧快照);守卫条件 = 候选线==weak_comp ∧ falsified[线]==当前位面 ∧ hp>`emergency_hp`(registry 既有常量,生存临界例外=快死了不挑方向,w665「锁线保生存」重新接管);出口①/②不写入(供给侧证据≠判死,w665「回程免费」前提在其辖域内原样成立);位面切换逐帧剪除过期条目;serialize_intention 全量序列化自动携带,零新增 schema 面。
2. 插入点坐标(当前树已核对,行号为实施批开工时重核基准):
   - 同线直落拦截:`update_intention` 弱意向解析 `_best_signal` 命中后、`_switch_gate_open` 调用**之前**(同线豁免在门内早退,守卫须置于门外层);
   - 闩回锁拦截:门拦分支的闩置位一次性回锁处(**判死胜出优先序**:判死证据后于闩产生且更具体,已判死原线不得经闩复活绕过冷却;闩保持置位、状态停 weak=合法终态);
   - 过期:update_intention 入口段落闩/miss_count/prev_lock_layer 位面清理同点。
3. 验证阶梯 = 单帧锁 ≥4(同线拦/异线不辖/生存例外/闩优先序+空对照)+ 位面过期锁 + 零漂移锚 + 守卫移除红检 + 邻锁(w665 域/w611/w633/w917)+ L1 + ruff。

## 与「W948 复活批」候选的关系

本设计已打开停滞臂重启的门(ADR-0509 复活前提「先裁决信号层失效记忆问题」由 W961 完成);重启批落地时写入端(falsified 写入分支)与本契约消费端**同批落地、同批过 A/B**(防振荡线沿用 ADR-0509 prereg 的换线/摇摆不升,新增「falsified_block 后同线零重锁」判据)。是否重启排当前实机证据波(match 7 P2 走向)之后,由编排者定。
