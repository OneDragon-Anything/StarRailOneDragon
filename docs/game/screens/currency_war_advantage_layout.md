# 货币战争-优势布局

货币战争的**局外强化树**(元系统):对局外用「幻乐晶球」激活天赋节点,效果在之后的每局对局中生效。用户口语中的「强化/激活系统」「1 血免死」曾归到本系统一个登记为「保险机制」的节点——**裁定(2026-11-19 两树全扫):优势树无此名、无「首归零回 1」效果,HP 归零=立即终局**,历史条目真实身份待对账(§3/§4.2/§5,挂账板 ⑲p)。分两区:**赛季优势**(每赛季重置)与**常驻优势**(完整保留)——与官方命名一致。

## 1. 何时出现 + 状态流转

- **入口**:大厅左侧菜单「优势布局」(screen_info 已建 `按钮-优势布局` area,goto 本屏)。
- **出口**:右上「返回」箭头 → 大厅(`按钮-返回` template area,goto 已建)。
- 画面内两页签切换:「常驻优势」/「赛季优势」,树各自独立、坐标同构。

## 2. 系统结构(实测)

- **两棵树**:
  - **常驻优势**:跨赛季永久,本号已全布局(节点全亮、详情按钮「已布局」)。r13 全扫口径 = 12 节点:根节点战前动员 + 数值 7 + 机制 4(长线作战/简易武装/策略刷新/额外补给)。
  - **赛季优势**:本赛季(入画奇航)专属,每赛季重置;「已布局优势 1/40」计数器只在本页签显示,40 = 赛季树节点总数,起点菱形默认算 1。
- **树可横向拖拽滚动**(赛季树实测约 **2.4 屏宽**——两次拖拽到右端复核,早期「约 4 屏宽」估计作废,当年在深层找不到登记为「保险机制」的节点即此因;该节点今已裁定不存在,见 §5,树宽实测数据仍有效;约 40 节点;拖拽方向:向左拖 = 看右侧深处)。
- **激活消耗（实测分档）**:小节点(数值强化)×20;「附加机制解锁」大菱形 ×60(风险对冲/主角重选/全盘刷新 = r13 全扫确认的赛季树三机制节点;钻石闪耀/理赔业务/光环优选为历史实读登记)与 ×100(大胜表彰,历史实读;另有一笔按「保险机制」登记的 ×100 激活——该名经全扫证实不存在,身份待对账 §4.2);画面按钮字面为「×N 布局」,右上角计数即幻乐晶球余量(来源含晋升等级奖励;**晶球余额仅本画面右上角 (1650,45)-(1810,85) 显示,大厅无余额显示位**——大厅右上角数字 = 晋升等级,别归错主)。锁定节点按钮显示红字「请先布局前置优势」——需先激活前置链上的节点;**锁定态不显示费用**,须先解锁前置才可见费率。

## 3. 激活路径链(goto_list 语义)与操作口径

大厅 →(点左侧菜单「优势布局」)→ 货币战争-优势布局(默认赛季优势页签)→ 点节点看详情 → 点右下「布局」按钮激活。切树点顶部页签。

**操作口径(看图,不建节点 area/不做点击 op)**:树可拖拽平移,节点坐标随滚动变——看图找节点点击;点「布局」后等约 1 秒(激活动画)再截图;成功判据 = 详情按钮变「已布局」+ 晶球数下降 + 计数 +1(**「节点变粉」不可作已布局判据**——未激活的深层小节点也是粉色;节点状态可靠判据 = 详情按钮三态 + 锁定节点挂锁角标)。**拖拽惯性坑(实测)**:常规拖拽会甩过头(一次常规拖拽把视图从最右端甩回起点 ~2700px)——每拖后必用固定地标核对视图位置。详见 skill 卡 `references/screens/货币战争-优势布局.md`。

**前置结构(主链 = 2026-11-18 首布实录)**:主链(已走通):起点 → 生命强化 → (暴击伤害强化/伤害减免) → (击破强化/效果抵抗强化 解锁两侧汇合件) → 主角重选 → 伤害提高 → 三链汇合件(风险对冲+全盘刷新) → 大胜表彰。左下支线防御强化(锁定 ← 暴伤 ×20 可布局 + 至少 1 个未探明锁定前置)。

**2026-11-19 r11 激活实录(节点身份待对账)**:当日按详情面板实读布 6 节点:理赔业务 ×60 → 心形生命 ×20 → 光环优选 ×60 → 当时登记为「保险机制」的节点 ×100 → 深层暴伤 ×20 → 深层减免 ×20(晶球 305→25,计数 21/40 → 27/40)。前置拓扑当时实录 = 「保险机制」**2 个直接前置**(连线箭头尖指向依赖节点):①伤害减免(花瓣形 ×20 ← 理赔业务)/②光环优选(← 心形生命),深层暴伤/深层减免为其下游(激活后解锁)。**裁定(2026-11-19 r13 两树全扫):优势树无「保险机制」名、无「首归零回 1」效果(§4/§5)**——该 ×100 支出的真实节点身份待对账(素材 = r11 帧 `.debug/sr_od_mcp/screenshot/screenshot_20261119_130942~131830` 系列,挂账板 ⑲p;上列 r11 拓扑中各历史节点的真实身份随对账一并复核)。**钻石闪耀(大菱形 ×60,已布局;在补给阶段的可选项中有概率出现钻石装备)**当年按「保险机制前置链中继」登记,归属随对账复核。r13 全扫快读:晶球余额 **310**、已布局 **27/40**(帧 230936~232823 每帧右上角双读数在案)。

## 5. 「1 血免死」排查线(已裁定:机制不存在,归零=立即终局)

- **裁定(2026-11-19)**:用户记忆的「激活后 1 血免死一次」**无对应机制**——优势布局两棵树逐节点详情全扫(常驻 12 节点+赛季树全部)无任何名为「保险机制」或效果为「首归零回 1」的节点(官方文案逐字录见 §4,全扫帧段 230936~232823);实机三局 HP 归零(2-1 普通战斗/2-7 位面末首领/3-5 遭遇三类型)**全部直终局,无兜底**。官方基础规则同口径:「当生命值为 0 时,将结束对局」(玩法说明 <https://sr.mihoyo.com/news/160700>)。
- r11 一例「3-7 最终首领战败 HP 8→0→回 1、结局翻转为挑战成功」报告**存疑未采信**:最可能 = HP 读数误差(实际 HP 1)或常驻树「长线作战」(官方文案:在节点发生战斗后回复2点小队生命值,常驻树已全布局常驻生效)的战后回血叠加——如实记录存疑,不下最终定论;对账批(挂账板 ⑲p,r11 帧 130942~131830 系列)复核后回写。
- **本机激活消费记录(2026-11-19,r11)**:305 晶球起步布 6 节点共 280,余 25(明细见 §3);其中登记为「保险机制」的 ×100 支出对应真实节点身份待对账。消费真实性无争议(晶球余额与 27/40 计数双读数自洽,r13 快读 310/27-40 正常),争议只在节点身份。
- **血线规划保守口径维持不变**:按「归零即终局」规划血量,无兜底、无例外(decision-guide §6 同口径;机制不存在,不存在「激活后可放宽」)。
- 第 4 局 3-7 BOSS 战败 HP 40 结束 = 位面 3 收束(已裁定),与免死无关(该裁定先于本条且独立成立)。
