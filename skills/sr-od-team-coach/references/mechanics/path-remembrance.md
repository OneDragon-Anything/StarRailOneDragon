# 记忆命途机制（忆灵系统）

记忆命途的公共规则（对任意记忆角色成立的机制层知识；角色个人机制见各自角色档）。
按 V4.7 期（2026-11）调研撰写；记忆命途 3.x 上线。

## 忆灵（memosprite，召唤物系统）

记忆命途角色各自携带忆灵——独立的召唤物单位，不是 buff 也不是宠物挂件：

- **独立行动**：忆灵有自己的速度、行动条位置、生命值；每回合自行行动施放**忆灵技**。
- **独立生命**：忆灵有生命上限（通常按本体属性折算，如「迷迷生命=开拓者50%生命+400」【官】）；可被治疗、可死亡（血尽或持续回合结束消失）。
- **伤害与增益双向**：忆灵造成伤害（忆灵技倍率基于本体或自身面板，各角色不同）；部分增益「对忆灵生效」或「由忆灵辐射全队」。

## 忆灵相关的公共判定规则

- **套装与增益对忆灵的生效**：部分套装效果明写「对忆灵生效」（例：哀歌覆国的诗人4件「战前速度<95 → 暴击率+32%，对忆灵生效」）【官】——给忆灵吃增益是记忆体系的配装自由度来源。
- **计数绑定**：「队伍中记忆命途角色数量」类行迹按全体记忆角色计数（例：长夜月行迹「记忆角色 1/2/3/4 时，我方全体忆灵暴击伤害+5%/15%/50%/65%」）【官】——记忆体系倾向多记忆互绑。
- **忆灵继承类增益**：本体给忆灵的增益（遐蝶天赋增伤扩散至死龙、长夜月战技按自身暴伤给全体忆灵暴伤）使「本体的词条」成为「全队忆灵的词条」——练度收益放大。
- **召唤物行动条地位**：忆灵与特殊行动单位（如欢愉的阿哈）同在行动条；速度配速要计入门像。

## 记忆体系与生命模型的亲缘

当前记忆角色的伤害/治疗/增益面板普遍基于**生命上限**（遐蝶全技能、风堇治疗、长夜月输出、缇宝虽为同谐但同走生命模型）——「生命体系」与「记忆体系」高度重叠但不是同一概念：

- 生命模型 = 伤害模型（词条口径层）
- 记忆命途 = 召唤物体系（行动/增益/计数绑定层）

配队时两层各自判定：非记忆的生命模型角色可以进生命队；非生命的记忆角色理论上也吃忆灵计数（以计数行迹原文为准）。
