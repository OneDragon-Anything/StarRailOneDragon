# ADR-0589: budget-gate 检查器支A realize 决策帧真值披露(行末快照假阳修复)

- 状态: Accepted(策略审查确认定性正确;落地审三文件零阻断;commit 候 T-136 可见性批提交序)
- 关联: ADR-0576(§2.5 支A 兑现链谓词与检查器三处对齐,本批为其后继修正)、ADR-0580(检查器可见性对齐,本红形的引入面)、ADR-0587(生产侧 node_type 台账制;sim 侧可见性属独立可见性批,见后果 2);T-133 假阳定谳的调查报告为易失产物,其持久语义摘要吸收于本 ADR,代码注释一律引本 ADR 不再引该报告路径。

## 背景

T-133 定谳:slow 锁 `test_ci_smoke_snapshot_batch` 的 `levelup_budget_gate` 红为**既有假阳**——生产闸与豁免行为完全符合 ADR-0576 设计,未发生绕闸;与同期提交零传导。机制链(单局内确定性序列):

1. 帧内低价买入合成出第 3 张同名牌 → 投影 bench 出现 2★ 等待件,板满;
2. 生产闸支A(ADR-0576 §2.5 `_realize_chain_ready`)合法豁免整批升级;
3. 升级腾出人口位后 2★ **当帧上板**(引擎部署块在买/升级后执行);
4. 检查器支A镜像读**行末快照**,bench 已无 2★ → realize=False → 误报「P72 (3a) 绕闸升级」。

红形 seeds [18,22](并行在飞批前为 [10,18,19,22]),单跑确定性复现;逐击重放自认的「行末快照 ±1 件漂移窗口」被上述序列确定性打穿。根因归层 = 检查器观测面(行末快照近似),非生产闸、非策略行为——修检查器,不修闸,不扩豁免。

## 决策

按击读决策帧真值 + 行末回退 + 两观测键:

1. **引擎披露**(`sim/engine_p1.py` LevelUp 执行分支):升级动作条目新增 `dec_board_full`(执行点板满;cap 缺读对齐生产谓词 fail-closed=False,非恒真)与 `dec_bench_2star`(执行点 bench 有 ≥2★)两 bool。单动作架构(ADR-0517)下动作执行点状态 = 发射帧状态,与生产闸判定同帧。观测非指令:零 rng 消耗、零状态写入;行为投影 digest 只取动作 `(__type__, reason, result)` 三元组(test_cw_w614_sim_fidelity 零漂移锚),新键零位移。
2. **检查器按击判定**(`sim/checks/ledger.py` check_levelup_budget_gate):m3_batch 升级击全部携键时,逐击 `dec_board_full ∧ dec_bench_2star` 豁免(与生产闸同谓词同帧);任一键缺失的账本(生产回放/历史批次)整行回退旧行末近似(cap 按轮内升级量回退式),既有检查器直调单测零改动兼容。
3. **供给半环锁**(`test_cw_infra_locks.py`):写端在位锁钉引擎披露写点(探针 seed 18,基线 22 击 m3_batch)——写端断线时检查器静默回退,假阳只在 slow 锁显形;该锁让断线在快速层直接红。
4. 路线取舍见 Considered Options;禁扩豁免白名单(T-133 裁决),修复后回归 0 容忍。

### Considered Options

| 方向 | 裁决 | 理由 |
|---|---|---|
| 路线一:决策帧披露 + 检查器按击读 | **采纳** | 真值载体修正(治本):镜像读生产闸判定时所见的同一状态;单一源不破;引擎本持该态落账成本低(`bench_delta` 执行点真值披露先例同款) |
| 路线二:回放轮内「合成→升级批→上板」形态识别 | 否决 | 检查器内重演合成/上板语义 = 生产逻辑第二实现(违本检查器单一源对拍纪律);启发式只堵单一种序列,其余轮内演化(卖出/事务通道)是后续假阳候选 |
| 豁免表扩白名单 | 否决 | 定谳裁决明令禁止;豁免 = 掩蔽非修复,且修复后 0 容忍可回归 |

## 后果

1. **闸 0 判读语义变化(重要)**:修复后 `levelup_budget_gate violations=0` 不再携带「奖励帧支A批不存在」的信息——奖励帧上的支A大额升级批自此静默通过且无任何检查器信号;这是假阳清除的必然代价,判读面须知。
2. **掩蔽三件套关系**:本批(检查器假阳清除,红归零)→ **sim 决策帧 node_type 可见性批**(独立批:sim 子树零 `.node_type` 写点为批内亲证事实,策略决策帧读该值恒 None;该批落地前奖励帧张力的可观测性 = 零)→ **策略域候裁**(支A 奖励帧豁免 vs T-115/ADR-0580 奖励帧升级抑制意图的张力,归编排者账本候裁行)。本批不裁张力、不填可见性。
3. 行为零漂移实证:闸拒计数探针(经生产链路 simulate_p1 → M3 发射位 → `obs.cw4_counters.levelup_budget_gate_blocked`)批前/批后逐位一致(seed18=14/22=8/10=8,含逐局终局 HP 全同);p71 检查器直调 28 锁全绿(无键回退路径行为不变)。
4. 验证锚:slow 锁修复前红 `{'violations': 2, 'games': [18, 22], 'seed_base': 0}`(单跑 4.47s,与定谳复现逐字同形)→ 修复后 0;红证 = 检查器消费面临时还原旧行为翻红同形,复原复绿;快速层全仓 3668 过(1 存量红在画面建档 fixture 面,import 零耦合)、慢桶全仓 33 过(1 存量红在 form_ok 写端面,还原本批改动后同字面复现 = 存量,归其属批)。
