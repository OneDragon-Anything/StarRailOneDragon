# 验证工作台细则(sim / telemetry / 单帧锁 / 实机判读)

> SKILL.md §验证工作台 的展开。读者 = 智能体;本文全是操作判据,不是说明文档。

## sim 批量对照(反馈梯度第 2 层)

- 入口:`src/sr_od/application/currency_war/cw_sim.py` 的 P1 批量模拟函数;跑法 `PYTHONPATH=src` 下 uv 调用(项目 Python 一律 `uv run python`,不用裸 python)。
- **A/B 纪律**:改前跑基线 → 改后同参数再跑 → 对照分布再上实机。指标看:验收线达标占比 / 末态均值 / 方向建立率(r1-r4 建立方向的局占比)/ 刷新次数——最后一个常暴露「买了件就不刷」类金闲置回归。
- **差异必须解释**:改后指标变差不是「sim 不准」的免死金牌——要么定位机制(如围栏把刷新门挡了),要么声明该维度 sim 不可信的已知边界并给实机判读锚点补偿;两者都做不到 = 别上实机。
- **代理语义自检**:任何 sim 结论上实机前,核对该结论依赖的代理量与实机语义一致(曾因代理量与实机语义错位得出增益伪影——bench 计数不等于上阵人数)。新增 sim 观测口径时同步查遥测视图是否同构。

### sim 的诚实性分层(架构;深度挖掘的立足点)

- **真代码层**(与生产同源,结论可信):策略决策(`update_target`+`decide_prep` 直接跑)、发牌概率(`REFRESH_PROB` 实机 OCR 表)、有限牌池(27/27/9/9/9,买走减/卖回池)、角色注册表、XP 升级表、**板深条件化实机 Δ 池**(31 局 645 轮 {节点:深度桶:Δ} 经验分布重放,lazy 加载冻结——新遥测要重跑进程)。
- **校准模拟层**(参数可注入覆盖,改进方向):开局 bench 构成/收入模型/战斗结算(方向二元模型 + Δ 池回退)/节点序列(25 帧众数表 + 变异位采样)。
- **未建模(已知缺口)**:板深→胜率转化(Δ 池部分补)、deploy 上阵语义(bench 代理,ADR-0219 教训)、装备效果、星级、词条/boss 克制、P2/P3。

### 深度挖掘方向(当前只用了一小部分;按杠杆排序)

1. **遥测回放对拍**(sim↔实机互相校准):用真实局的关键帧 state 喂 sim 决策,对拍实机 actions——发现「同局面不同决策」的回归/漂移;反向用实机 Δ 分布持续喂校准层(池已在做,扩维度:节点类型×深度×**方向态**)。
2. **压力/边界态批量**:稀有态系统扫描(金 0-100×等级 3-9×板面形态网格)——单帧测试想不到的输入空间;连刷语义/金尽未升级/席满链等边界的行为锁。
3. **策略 A/B 之外的第 3 用途——**参数敏感度**:同一策略扫参数(阈值/预算分配),看指标对参数的弹性——弹性大 = 该参数值得实机精调;弹性平坦 = 别花实机局数调它。
4. **校准层升级路径**(每一步都换真机制,Δ 池模式可复制):星级→Δ(遥测 star 字段已采)/装备分配质量→Δ(equips 已采)/词条→Δ 修正。升级一维 = 跑一次 sim vs 实机残差对比验证增益。
5. **种子化复现**:同 seed 同局——bug 报告带 seed,任何人可重放该局逐步看决策(配合单帧锁固化)。
- 判据:sim 能模拟到的维度**别拿实机试错**;sim 不能模拟的维度(散面 vs 集中方向相反的已知边界)以实机判读为准并记录偏差。

## telemetry 判读(反馈梯度第 3 层)

- 查询即判读,入口见 SKILL.md §判读;`--view hp` 看逐轮掉血×板深,`--view economy` 看金轨迹滞留轮,`--view supply` 对账「牌面 vs 买了什么」。
- **跨局对照表**是判读主力:把近 N 局的同维数据并列(逐轮 HP 轨迹/购买明细/板面构成),找共线与反例——单局归因是判读大忌(单局相关≠因果的教训在 design/ ADR 存档)。
- 判读锚点(实机第 5 层的前置):改动上线前写下「预测 X 会变」;局后核对。锚点没中 = 改动没生效或假设错,两者都要查。

## 单帧锁测试(反馈梯度第 4 层)

- 位置:`sr-od-test/test/sr_od/app/currency_war/test_cw_<主题>.py`;模式 = 构造 `GameState`(plane/round/gold/level/board/bench/shop/xp_progress)+ `StrategySession` → 调被测方法 → 断言动作序列。
- 模拟器批量跑出的异常情况(稀有态/边界态)**固化成单帧锁**才算回归资产——模拟是发现工具,不是回归工具。
- 断言写**语义**不写巧合:「配方 gap 时围栏内只买配方件」而非「买了卡 X」(换发牌就碎)。
- 依赖路径:测试仓 gitignored 独立维护,提交在测试仓;锁旧行为副作用的断言要随语义演进而改,改时在 docstring 记一句为什么旧语义过期。

## 实机验证(反馈梯度第 5 层)

- 验收以当期目标为准(进度树/goal 里有),不是固定数值;险胜不算过——贴线通过是策略缺陷症状,与明显失败同权重分析。
- 局中巡检看**轨迹**不只看卡死:中期掉血轨迹已注定不达验收线即早停(SKILL.md §实机运维),别陪跑到局终。
- 每局跑完的局后判读是**必做项**不是可选:异常条目当场定位;定位不了不准进下一局。
