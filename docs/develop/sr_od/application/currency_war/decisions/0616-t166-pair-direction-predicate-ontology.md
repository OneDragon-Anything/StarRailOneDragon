## 2. 决策本体(六命题全收)

### 2.1 命题 1a 在任优先(面①·排序谓词,支配性论证)

在任对(重评时刻 `ist.p1_pair`/`ist.transition_pair` 现值 I)的席位体系只在挑战者**排序维支持度严格大于**该席时易手;支持度相等一律保持或在非在任体系间按 `_P1_PAIR_PREF` 注册表声明序定序。依据 = 支配性论证消参数:平手 = 零优势证据,换席成本确定(囤货集作废、跟线投资重置),不换席弱支配换席——零新数字,与 P84 P-G2「正裕度才换」同极性。

夺席算子 T(ord, I, Q)(门槛维过滤先行的合格集 Q 内工作):|I∩Q|=0 空窗进入按 (−ord, PREF) 取前 min(2,|Q|) 席;|I∩Q|=1 留任席无条件保持、最佳挑战者填空席;|I∩Q|=2 只换最弱席,**每帧至多一席易手**,换席条件 = ord(最佳挑战者) > ord(最弱席) 严格大于。「单席易手」与「并集 top-2(一帧双换)」两读法钉死前者——单席易手是支配性论证的直接闭包,并集读法无独立辩护且放大振荡自由度。引理链:良定义(全严格不等式零参数)/静态无环·至多 2 次易手收敛(支持度和严格递增封环,无 A→B→A 振荡;不动点 = Q 内平手偏在任的 top-2)/退化帧 parity 收窄域为 |Q|≠1 帧/参照系完备性(K(I)=注册表标签扫描,名级零重叠⟺标签级不交)。

边缘帧申报:|Q|=1 帧 → 派生 **1 元对**(恒自洽式「pair≠() ⟺ Q≠∅ ⟺ gap_window=False」强迫,禁改 gap_window 构造回避);第二席 sub-gate 帧 → **门槛过滤先行是有意行为变更**(现行码只查 ranked[0],零在册资格的第二席不再入对,宁缺勿滥保守向),锁线时点分布漂移登记。

### 2.2 命题 1b form_ok 冻结(面①·投入保护不变式)

状态变量 F∈{0,1} 与 frozen_pair 身份按域(p1_pair/transition_pair)独立持有。**置位 = 事件闩**:F=0 ∧ 当前重派生对非空 ∧ fp(pair)≥1.0(board-only 口径单一源 `form_progress`,cw_comps.py)⟹ F:=1;空对永不置位;fp 回落不自动清位。F=1 期间重派生抑制(冻结的是**方向**不是板面,买入/部署继续服务该 pair)。

**解冻闭集(分字段;p1_pair 域恰三项)**:
- **transition_pair(locked 域)四类全活**:撤销/驱逐机(出口①②③+窗口冻结驱逐,均清 transition_pair 并改 phase)/位面末(出 P1 退场)/面③超窗出口/P16 换线事件(层解封后)。
- **p1_pair(unlocked/weak 域)活面恰三项 = {面③超窗出口, 位面末(exit_p1), comp 锁定取代(`_lock` 内 `ist.p1_pair = ()`)}**。撤销①②③结构性不可达(全部位于 `phase=='locked'` 分支、对象 locked_comp;出口③另带 plane==2 卫而两域 pair 仅 plane==1 派生存活)——对 p1_pair 是死项,不并入。**comp 锁定取代 = 域退出类清除**(①类直通信号触发 `_lock` 就地清空并切 phase;方向替代语义,ADR-0357 ①资格通道既有语义零改动——冻结保护配方方向不被噪声重派生,不保护已被合法方向替代取代的承诺)。**禁闭集之外任何解冻事件**。
- **外部清除 ⟹ F 同帧归 0**(二选一裁决,裁「F 归 0」;拒绝「空对帧出口按 E=+inf 判」= 拒绝为空对新造比较语义)。由此状态机获得不变式 **F=1 ⟹ frozen_pair ≠ ()**(置位需非空+清除事件全部同帧清 F)⟹ 出口永不对空对求值,「comp 锁后方向真空直到位面末」的孤儿态从构造上不可达(命题方案审 F1,本件最重要修复)。
- **清除后**:本帧重派生按 1a/§2.3 执行;新对以 F=0 起步;派生对=frozen_pair(在任保持)**不再位**,直至新 form_ok 帧再闩——防超窗在任对陷入「出口→解冻→保持→复位→再触发」逐帧空转环。域切换不继承冻结(撤销降级/comp 锁定为合法换向)。`p1_pair_frozen_obs` 观测快照是遥测身份,零触碰。

覆盖论证(分字段,写点全集直读):transition_pair 写者全集 = {_lock 派生/出 P1 退场/窗口冻结驱逐/出口①②③/locked 域重评/初始化},非重评写者全落闭集类,p1_pair 写者全集 = {重评/exit_p1/_lock 清空/新增超窗出口}——**写点完备断言按全集建,按任何真子集建 = 假红源**。form_ok 后板面退化帧四分支穷尽:可回复(再闩)/方向仍可达(冻结无害=本命题目的)/超窗(出口解冻重选)/字面零(出口同帧触发,+inf > 任意有限 R_rem)。

**p1_pair 域单点兜底充分性(承重项)**:健康域(E≤R_rem)无需出口;超窗/字面零域出口按构造触发(与门同一比较,单一源);**断供盲区 ⟹ 晚触发是唯一出口,早退通道 = 空集(诚实申报,见 §2.4)**。

边界申报:[23] 冻结语义原辖终局线不辖 P1 配方(12 号件 §4 注),扩展到配方对层属语义扩展,须 ADR+12 号件 §4 三同步(§10 挂账);与 P16 D_min 驻留**同构**(冻结 = 驻留的结构化形态,振荡 ≤1/(2·D_min) 已证形态在 P84 P-G3 继承链上),非数值滞回带,零 θ_pair/D_min_pair 类第二参数族。

### 2.3 命题 2 计票封闭(面②·方向计票证据不变式)

**排除谓词 Ex_I(x)(P41② 燃料类单一源复用,禁第二燃料名单)**,参照系 = 重评时刻在任对现值 I(先于本次计票,非循环):前置卫语句 **I=() ⟹ Ex≡False**(卫语句是谓词定义组成部分——无此卫则 1★ 全额可退件在空窗被误排除,与空窗语义相反;命题方案审 F11 折入);I≠() 时 Ex_I(x) ⟺ char_id≠''(件型适用面:装备/纯标签件无星级与卖出语义,三条件不可判 → 不排除,保留计票,fail 向保守)∧ star(x)=1 ∧ refund_full(x)(1★ 下机械恒真,按 P41② 类资格条款显式保留,防退金表改动时静默失配)∧ name(x)∉K(I)(零重叠,与 dominance 买入端同函数同参照系)。

**双量纲(门槛过滤先行,组合谓词)**:
- **门槛维(过滤,现行语义零变化)**:gate(f) = 现行 `_p1_system_support` 值(三羁绊系 = 逐副本实例数÷体系档;**希儿系腿门槛维 = 分级公式值 ≥1.0**,去重成员计数原语——希儿系的「体系档」不存在于 TRANSITION_TRAITS,落码禁臆测档位;ADR-0608 坐标系继承,两维计数原语禁互换)。合格集 Q = {f∈四体系: gate(f) ≥ P1_PAIR_LOCK_MIN_SUPPORT=1.0}。
- **排序维(排序,新定义随本 ADR 入册)**:sup_units(f) = Σ(非燃料成员星级当量 3^(star−1))/tier_f,tier_f = TRANSITION_TRAITS tiers[0]——**归一化比值**(满档=1.0 跨体系可比,消「绝对当量偏向高档体系」偏置;合成中性:3×1★→1×2★ 分子不变;无帽,超满档可 >1.0)。**第④格换算式(排序维×希儿系腿)**:sup_units(希儿系) = min(1.0, max(u_量/2, u_贝/2)),u_X = 该腿去重成员星级当量之和;推导链五项:÷2 = 文档 OR 腿档位(量≥2 ∨ 贝≥2,transition_combos.md 定义行)/max = 文档 OR 结构/min(1.0,·) = 满档封顶(继承现行分级公式值域)/u = 计数原语从去重成员数换为星级当量(合成规则【注】厚度语义)/希儿单卡 1★ = 0.5(与 ADR-0608 推导后果一致)。三羁绊系无帽/希儿系有帽的不对称 = 现行码既有形态继承声明,非静默统一。
- **四象限行为钉死**:①排序第一∧门槛达标 → 锁第一席;②星级当量第一∧门槛不达标 → **被门槛过滤剔除不入对**(宁可空窗不提前承诺,ADR-0519 C2 保守方向同向;单帧锁钉死);③排序第二∧门槛达标 → 入第二席;④全不达标 → 空窗 (),gap_window=True 行为不变。恒自洽式「pair≠() ⟺ Q≠∅ ⟺ gap_window=False」矛盾帧不存在。

**命题 2(封闭性)**:设帧含在任对 I≠(),一轮资产变动每一进出件满足 Ex_I,则:(i) 排序维逐系不变(Ex 件贡献恒 0,逐系计数对燃料类增量封闭,代数命题零自由参数);(ii) 在任系门槛维不变(Ex 件不携带在任系标签);(iii) 双席在任帧派生对不变(s661 型「dominance 离对买入推高挑战系支持度致翻席」的因果链在计票端切断);(iv) 单席帧空席填充可变(燃料计入门槛维可送候选跨 1.0 入空席——继承现行门槛语义,申报帧类非回归,因其不触动已占用席);(v) 空窗帧出辖(Ex≡False,行为=现状)。**边界节**:在任对存在期,新方向的 1★ 燃料类资产不计入方向证据,换向须走真证据通道(非燃料成员经 1a 严格超出 **∧ 门后置合取 E(N)≤R_rem 通过**)或面③超窗出口/撤销机器;「燃料辅助翻转」唯一合法路径钉死 = 挑战者非燃料成员已严格超出(排序维真证据)+燃料到货补足在册资格(门槛维),与四象限第①格同构,设计内行为非副作用。`_update_pair_drought` 断供计数器保持遥测身份(ADR-0519 C3 永不驱逐),本面零触碰。

**T-171 坐标系双口径卡口随本件入册闭合**:消费位分配四格 = ①门槛维 = 实例计数(羁绊人数语义)②排序维 = 星级当量∧燃料剔除 ③希儿系腿内部 = 去重成员计数(T-171 既有声明不变)④排序维×希儿系腿 = 第④格换算式(上)——推导链经命题批出全链并随本 ADR 入册,任一侧禁私自换用另一原语。

### 2.4 命题 3 可行性门(面③·翻转前置合法性,断供出口同帧同闸)

**命题 3:配方对席位翻转合法 ⟺ 命题 1a/1b/2 通过 ∧ E(alt_pair) ≤ R_rem。** E(·) = kernel `e_rounds`(cw_line_switch.py)**逐字直调**,消费对象 = `pair_target_comp` 现行物化产物(form_tiers 单一源 = BRIDGE_POOL:桥池精确匹配→逐体系兜底→希儿系 OR 腿结构;Z3 承接:零新构造零第二档源,E(inc) 与 E(alt) 同物化器同源,超窗判定不失真);R_rem = `cw_plane_table.r_remaining` 单一源读法。**零新常量**,三态词汇(可达/超窗/字面零)沿用 P84 §3.1。

- **辖域(比较器侧后置合取)**:门辖占用席易手帧与解冻后重选的换对帧——1a 先产换席候选 N,门判 E(N)≤R_rem,不过 ⟹ **保持原对 + `pair_gate` 拒因分键**。不辖空窗首进帧。**超窗保持帧类**:出口触发(F=1)→解冻重选→1a 判在任保持 ⟹ 对保持且 F=0;F=0 期超窗在任同型保持(保持+`pair_gate` 路由读数,如实显影)。非活锁(状态机静止,出口不逐帧重触发,遥测可观测);EV 最优性未证(与 P84 §5.1 同族,按待证假设对待,A/B 无裁决权);**禁落码批静默改为可行性支配选择**——1a 方向证据优先于可行性偏置是本件裁决。
- **断供型降格申报(诚实路线)**:门辖域 = 「超窗型换向出口」;**断供型 = 已知晚触发域,且 p1_pair 域无早退通道**——R2 旧文本「断供早退合法通道 = 撤销出口③证据合取」系空集引证,本批勘误(出口①②③全辖 locked 分支+出口③ plane==2 卫+两域 pair 仅 plane 1 存活,冻结 operative 窗内出口③任何域都不可能触发)。`PAIR_SUPPLY_CONFIRM_ROUNDS`(=2【拟】)保持其既有身份 = plane 2 锁线撤销出口③的证据合取阈值,**非本域早退通道**;若未来确需 p1_pair 域早退 = 闭集增项,属设计变更须回本件对表立项,禁命题批/落码批静默扩权。
- **持守代价核算(命题 3 覆盖论证显式组成项)**:晚触发期每帧持守代价 ≈ 刷新金烧(锚 = s995 的 8 刷 71 金空转)+席位机会成本;总上界 = 直至 R_rem<E(inc) 的帧数(r_remaining 随节点推进单调不增,有穷保证)。架构后果如实入账,不作否决项;量级复验挂 §5 s995 行。

### 2.5 命题 4 V_slot>0 席位外部性否决(面④·买侧限域收口)
