## 一、命途属性与技能说明

**命途**：虚无
**属性**：风

| 技能 | 说明 |
|---|---|
| 普攻 | 单体30%攻击风伤；50%概率+1奥迹；对四系DoT目标各50%概率再+1 |
| 战技 | 扩散45%攻击 + 100%概率目标与相邻+1奥迹+减防14.8%（3回合） |
| 终结技 | 消耗能量；【揭露】2回合：敌方回合内受伤+15% + **奥迹目标视为同时陷入四系DoT** + 揭露期间奥迹不重置层数；AoE 72% |
| 天赋 | 敌方每回合每受1次持续伤害 → 50%概率+1层【奥迹】（上限50）；奥迹每回合结算96%攻击+每层4.8%，结算后重置1层；**≥3层溅射相邻（72%+50%扩散）、≥7层无视20%防御** |
| 秘技 | 进战概率连叠奥迹（递减概率重复） |
| 额外能力 | **B1「烛影朕兆」：效果命中的60%转伤害提高，上限72%**（→120% 吃满）；C1 敌方进战65%概率+1奥迹+受DoT时65%概率再+1（单次攻击上限3层） |

**资源与循环**：标准能量→充能有效。奥迹叠层速度=队伍 DoT 频率。
