# 商店(store)

商店界面。多子商店入口(兑换 / 外观 / 协议 / 星琼购买 / 列车补给…) + 商品购买。**不锁光标**(`pc_alt=false`)。通用系统,不必先搜玩法。

## 何时出现 + 状态流转

- **入口**:菜单点「商店」(phone_menu_const.STORE)→ 商店主页。
- **出口**(动作 → 下一态):
  - 点分类标签(银河风尚 / 开拓助力 / 特惠车票 / 专票礼盒)→ 切分类(停留主页)。
  - 点左侧商店入口(列车补给 / 兑换商店 / 聚灵铸星 / 外观商店 / 协议商店 / 捕获梦华 / 星琼购买)→ 进对应子商店画面。
  - 点商品 → 购买弹窗(选数量 + 确认/取消;已售罄 / 材料不足提示)→ 确认购买。
  - 右上返回 / ESC → 回菜单。

## 识别特征(稳定锚点)

- **主页态无精准匹配**(`screens=[]`):store.yml 的 area 是**购买弹窗态**(商品列表 + 购买按钮),主页态(分类 + 商店入口)无 id_mark → analyze 不命中。靠 OCR「商店」标题 + 布局判主页态。
- **购买弹窗态**(store.yml area):商品列表(290,110-1790,817)、按钮-购买最大值(template `store_buy_max`)、BUY_DIALOG_ADD_BTN(template `store_buy_add`)、购买-已售罄 / 兑换材料不足(text)、按钮-购买取消 / 确认(text)、点击空白处关闭。
- `pc_alt=false`。
- 易变:货币数(星琼 / 专票)、商品 / 价格、活动倒计时(28天5小时)。

### 购买弹窗(售罄)子态(`source_image: screens/商店/购买弹窗-售罄.webp`,2026-07-30 货全·杂货小摊实拍)

- **何时出现**:在商品列表点一个**已售罄**商品 → 购买弹窗(模态,背景暗化)。NPC 杂货摊(货全 / 罗纳德 等)与菜单商店共用此弹窗 UI。
- **匹配画面**:`商店`(is_precise=false)—— 命中 `购买-已售罄` / `按钮-购买取消` / `按钮-购买确认` area(text)。非售罄商品点开是同结构弹窗,只是状态位是「可购买」(无已售罄红字)。
- OCR(节选):商品名(气态流体)/ 描述(1级合成材料)+ 风味文字 / 兑换数量:1 / 价格 260 / **已售罄** / 取消 / 确认 / 刷新倒计时(C4小时53分钟)。
- 视觉大模型:模态暗化;左侧商品图标(圆形 / 带光晕);**已售罄 = 红色字**(中部偏下,显眼);底部 取消(灰白)/ 确认(蓝)按钮;兑换数量 + 价格在右侧;背景是暗化的商品列表。
- **出口**:点「取消」/ 点空白处关闭 → 回商品列表。售罄时点「确认」无效(仍售罄)—— `BuyStoreItem.buy_confirm` 检测到 `购买-已售罄` / `购买-兑换材料不足` 会主动点「按钮-购买取消」退出。
