## 一、命途属性与技能说明

**命途**：虚无（吃「奈落」计数：虚无队友1/2名 → 普攻/战技/终结技伤害×115%/160%【官】）
**属性**：雷

| 技能 | 说明 |
|---|---|
| 普攻 | 单体雷伤（普攻回1战技点） |
| 战技「八雷飞渡」 | 单体+相邻雷伤，+1【残梦】 |
| 终结技「残梦尽染，一刀缭断」 | **消耗残梦9（不走能量）**；3段【啼泽雨斩】+1段【黄泉返渡】，逐段选【集真赤】最多目标（每段最多消3层，消层提倍率至36%/层）；期间无视弱点削韧+敌方全属性抗性-10%；不占行动回合，随时插放 |
| 天赋「红叶时雨，万倾一空」 | 任意单位施放技能使敌方陷入负面 → 黄泉+1残梦+1层集真赤（每次施法上限1次）；敌人死亡后集真赤转移 |
| 秘技「四相断我」 | 主动开怪，普通敌人直接消灭不进战斗；未命中不耗点 |
| 额外能力 | 「赤鬼」：开局+5残梦，溢出转四相断我层；「雷心」：啼泽雨斩命中带层目标+30%伤害叠3层 |

**资源与循环**：残梦来源=全队挂负面（主）+战技+开局5点+E2回合+1。**终结技资源不是能量——充能词条零收益；配队核心逻辑=全队挂负面频率**。

**满级数值**【官：米游社百科行迹表】：三途枯榷 110%(Lv7) · 八雷飞渡 176%/66%(Lv12) · 残梦尽染，一刀缭断 401%/324%/25.9%/16.2%/64.8%/129%(Lv12) · 红叶时雨，万倾一空 22%(Lv12)。完整等级表见百科。
