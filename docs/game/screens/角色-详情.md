# 角色-详情(character_detail)

> source_image: sr-od-test/screens/角色-详情/default.webp(2026-10-17 live 建档,布洛妮娅详情页);
> 属性详情弹窗为父屏子态(见「注意」),未单独建档。

## 何时出现

菜单 →「角色」图标进入,默认落在详情 TAB;角色页内点左侧「详情」TAB 也回本屏。
独立屏(整体布局,非 overlay)。

## 状态流转

```
菜单/角色 → 详情 TAB(默认) → 左侧 TAB 切换(光锥/行迹/遗器/星魂/信息,各为独立屏)
                            → 顶部头像条点头像 = 切换角色(保持当前 TAB)
属性详情按钮 → 属性详情弹窗(模态子态,ESC/点 X 关闭回本屏)
右上关闭 X → 返回大世界/菜单来源页
```

## 识别特征

- id_mark「标题-角色详情」[85,25,195,75](左上标题,OCR 全字;lcs 默认)

## automation 要读信息

- 读区-角色名 [1480,105,1740,165]:OCR 角色名
- 读区-命途图标:命途 icon(视觉/模板,无文字)
- 读区-等级 [1465,222,1665,268]:OCR「等级80/80」
- 读区-星魂格 [1465,190,1615,228]:6 钻石格(亮=已解锁;视觉判读,OCR 无文字)
- 读区-生命/攻击/防御/速度/暴击率/暴击伤害:右侧属性面板 6 行数值 OCR(区已建,x 1770-1895)
- 「属性详情」弹窗:进阶属性全文 OCR(低优先,主面板 6 项够养成规划用)

## 注意

- 左上标题「角色详情」固定(不随角色变),是本屏 id_mark;角色名在右侧面板(变量,勿当锚)
- 头像条首位点击 = 切到**列表中下一个角色**(实测点首位从头像条左端起切);逐角色扫描即:点首位→读→点下一位…
- 星魂格亮暗判定需视觉/模板,OCR 读不到;详情页星魂数也可去「角色-星魂」屏数名字数
