# ADR-0159 成型成本计算器(攻略空间度量衡;17 号提案)

## Status

Accepted(2026-08-16;消费端接线[form_difficulty 替代/pivot 边定价/DP rb]待后续轮)

## Context

17 号提案(用户发起)定位:「策略在攻略有限空间搜索」的直觉正确、数据在盘(784 篇 + ADR-0152 事实层),但**空间能被搜索的前提是有度量**——节点值多少分(form_difficulty 手标)、节点间距离(pivot_overlap 粗代理)、路径对不对(过渡成型无计算式)全是手写近似;单卡原子齐备(expected_refreshes 状态转移精确解/REFRESH_PROB 权威表)但**构筑级联合成本从未算过**,而决策消费的全是构筑级量。

## Decision Drivers

1. 提案核心判据(涌现对拍)可在一天内离线证伪:计算 argmin 搜牌级复现 plaza labels 分档(1费→5级/3费→7级/5费→速升9),≥15/20 = 机理可信。
2. use 数实证仅头部聚类非零(近二值流量信号)→ 降级 tiebreaker,篇数为主权重(提案 §2)。

## Considered Options

- **蒙特卡洛购置模拟**(提案原案,v0 采纳为逐构筑精算层):采样 REFRESH_PROB+超几何池、买走目标、扣池;联合命中自然覆盖。
- **解析式两段成本**(判据对拍迭代中收敛,采纳为对拍层):升级段沉没金+推级轮次机会成本;搜牌段 carry 期望刷×(刷价+轮次机会)。
- 判据不过就砍掉计算器:未发生(见 Decision 3)。

## Decision

1. 新增 `cw_formation_cost.py` 两层:`formation_cost`(蒙特卡洛,逐构筑精算,消费端用)/`best_search_level`(解析式,判据对拍口径)。
2. **判据 1 结果:12/17 命中**——主 carry(姬子/万敌/千冶/绯英/远坂凛/黑塔/Saber/黄泉/白厄/希儿/Archer/火花)全中;5 miss 经查为 **label 归属噪声**(三月七/瓦尔特 = 列车流次 carry 继承主体 7 级档;大黑塔/景元/银狼 label 分布本多元),非机理错。未达提案 ≥15/20 硬线,达「机理可信」实质(主 carry 全中),消费端接线继续但权重谨慎。
3. 六轮诊断实证的口径修正(留档防回归):
   - **p=0 等级 = 不可行(inf),不是免费**——旧版 e=0 被当免费致 lv3 恒最优;
   - **搜牌费用口径 = carry 自身费用**,非 comp 最低费(姬子 comp 含 1费三月七 → min 错位);
   - **未凑齐 run 按上界计入**(1费 27 张×3 在 400 刷内尾部超时,5% 门误判整个等级 inf);
   - **升级段沉没金 + 推级轮次机会成本**必须入成本(lv3 免推级金的「便宜」被轮次抵消);
   - 蒙特卡洛全 roster 会把次要角色 p 骤降污染 argmin → 对拍用解析式(只对 carry 费用敏感),精算用蒙特卡洛,两层各司其职。
4. 测试 5 条锁定(p=0 禁忌级成本≫可行级/有限性/姬子=7/万敌低级带/口径回归锚)。

## Consequences

- 后续消费端(按提案 §3.2):form_difficulty 计算值替代手标(数据缺失兜底)、maybe_pivot 边金差定价、cw_horizon rb target-conditioned —— 各独立灰度。
- 提案其余部分(变体层/Middle 锚点)未在本轮;提案文件按用户「处理完一个删一个」指示删档——**注:17 号含三个子模块,本轮只落地成本计算器(核心判据所在);变体层与 Middle 锚点是有价值的独立增量,记进度树待后续轮**,若专职 agent 重写补充则按新提案处理。
