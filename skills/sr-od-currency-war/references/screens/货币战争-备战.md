# 货币战争-备战（核心画面，每节点停留）

**识别**：`is_precise` 命中 `货币战争-备战`；extras 全量：gold/hp/level/deploy_count+deploy_cap/xp_progress/front_line+back_line（SIFT 在场真值）/bench/armory_boxes/owned_equips/reward_ores/**bench_overflow**。board = 羁绊面板可见行（仅快照）。
**目标**：花金币强化阵容 → 出战。
**能做的事**：
1. 拾晶矿：`CwCollectRewardOres {"max_clicks":6}`（reward_ores 非空时；只应在收店后的备战画面用——商店态晶矿不可见，reward_ores 键不出现）。**点击后重读一次 analyze**——采到的奖励开箱可能入席，改变备战席占用；拾矿/拖拽/合成后 deploy_count/deploy_cap 可能连续数帧瞬态 null（实测：识别对「个位/个位」短文本间歇失读，画面可见真值）——读图对账勿当真值，等几帧重读。**晶矿坐标带与右上退出入口相邻（实测）**：点击可能误触「中断挑战」弹窗——误触后点「暂时离开」→ 回大厅 → 点「继续进度」可无损续局。晶矿识别可能误判：**点击后仍然存在的晶球 = 幻晶矿（点了无效的假目标），对照自己读图确认后忽略即可，不要反复点**。
2. 开商店：`CwToggleShopPanel {"screen_name":"货币战争-备战"}`（静默失败重跑）→ 买东西见「备战-开商店」卡。
3. 部署：`DragCwChar {"from_row":"bench","from_idx":N,"to_row":"front|back","to_idx":M}`——from_idx 必须来自**刚读过**的 extras.bench（晶矿开箱掉落物会插到非首空位，旧读数缺新单位；槽号 = 物理槽位，空槽以 empty 保留）。**同名第二张无法上场（实测）**：拖备战席同名到场上空槽 = 静默无反应——op 无错误返回，无法区分吞点击与规则拒绝；遇到时读图确认场上/席内实际状态，勿反复拖。拖备战席角色到场上已占用槽 = 换位。合成规则实测收敛（同名+**同星级**全局计数 3 合 1，详见「备战-开商店」卡条目 1）——同名第二张无法上场与这条规则同源：凑满同星级 3 份会直接合成而非上新场。
4. 卖角色腾位：`CwSellBenchBySlot {"slot":N}`（实测：参数名 = slot，传 bench_idx 会报错）。
5. 开武装箱：点 extras.armory_boxes 元素的 cx/cy（开启后装备入库，腾出备战席）。**右上『×N』计数是冶金炉消耗品计数，不是武装箱（实测修正）——armory_boxes 只读备战栏内的简易武装箱占位。**
6. 看角色详情：点场上角色卡（属性/技能/装备栏面板，右上 × 关闭）。
7. 出战：`CwStartBattleByClick {}`（纯机械点击出战按钮）。**状态前置自查**：商店开着先收店（第 2 步）；部署未满会弹「未达上限」→ 点确认；投资策略未选完时出战被抑制——op 只管机械执行，前置由你负责。bench_overflow=True（「备战席已满」红警横幅）= 出战会被游戏忽略——先卖角色腾位再出战。**席满（9/9）≠溢出——bench_overflow 只反映告警横幅在场；晶矿掉落顶入售出腾出的空槽后横幅消失即 False（实测）。**溢出态的视觉判据不止横幅（实测）：全场槽位红斜线覆盖 + 掉落单位卡片浮在场地无位可放，同为溢出（extras 不可用时据此判断）。**点击后进入战斗画面 `货币战争-战斗`（已建档，战斗期操作与自愈见该卡）——出现「挑战成功/挑战结束」结算画面即战斗结束**（约 60~90 秒）。
8. 穿装备：`CwActionWearEquipOp {"src_cx":N,"src_cy":N,"row":"front|back","slot":M,"back_slot_count":6,"item_name":"件名","char_name":"角色名"}`——拖装备栏指定装备到场上角色槽位。`src_cx/src_cy` = extras.owned_equips 里目标件元素的 cx/cy（**读最新一帧 extras 就传**——记账按坐标反查，陈旧坐标会记账拒单）；`slot` = 目标排槽位 1 基（前排 1-4 / 后排 1-N），`back_slot_count` = 后排槽数（extras deploy_cap−4，front 行可省）；`item_name`/`char_name` 可省（纯日志）。**按单件会话使用**：一次调用穿一件，穿完重读一次 analyze 对账（owned 少一件 / 目标角色详情装备栏多一件；穿着即合成时合成产物入角色装备栏）；要连穿多件就每件走一轮「读 extras → 调用 → 重读对账」，下一件的坐标必须来自穿完并**经框架重观察刷新后**的读数——round detail 出现「记账拒单:wear_item_xy_unresolved」= 拖拽已发生但账未落，**禁止补拖**（再拖 = 二次拖拽），交还框架决策循环重派即可。**agent 手动拖拽等价路径实测可通（op 仍是主路径）**：装备栏图标拖到场上单位槽中心 = 穿装（实测多次成功）；拖到另一件装备图标上 = 合成（弹 ✓/✕ 确认浮层，点 ✓ 确认）——同一手势落点决定穿装还是合成，拖前想清落点。**合成配方以确认浮层实读为准**（`cw_equip_lookup` 的配方表与实机浮层不一致过：表记「永动机=电池+电池」实测未复现出该浮层）；落点受装备栏重排影响（图标位置会漂），拖前重读 owned_equips 取最新坐标。
9. 卖场上角色：拖场上角色（前排/后排槽位中心）→ 出售区（左下「区域-出售区」，拖到即卖、无按钮）——买牌缺钱或缺位时换人用（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
10. 使用消耗品道具：`CwActionToolUseOp {"target_kind":"equip|char","tool_cx":N,"tool_cy":N,...}`——拖装备栏工具图标到目标上消耗。七种工具：冶金炉、特权赋予卡（双模 = `target_kind` 选 "equip" 拖装备或 "char" 拖角色）；拆装扳手、精密拆装扳手、员工投影仪、完美投影仪、好运令牌（只 "char" 拖角色槽位）。**坐标形态调用法**：`tool_cx/tool_cy` = extras.owned_equips 里工具元素的 cx/cy（**读最新一帧 extras 就传**——记账按坐标反查，陈旧坐标会记账拒单）；equip 模式再加 `tgt_cx/tgt_cy` = 目标装备元素 cx/cy（冶金炉拖「要变异的死库存件」、特权卡拖「key 对应进阶成品件」）+ 可选 `item_name`；char 模式传 `row:"front|back"` + `slot`（目标排槽位 1 基）+ `back_slot_count`（extras deploy_cap−4，front 行可省）+ 可选 `char_name`。**按单件会话使用**：一次调用用一件，用完重读一次 analyze 对账（owned 少工具件；equip 模式目标件变异/替换，char 模式目标角色装备栏变化）——连用/连穿交还框架决策循环（对照表刷新它管）；round detail 出现「记账拒单:tool_xy_unresolved」= 拖拽已发生但账未落，**禁止补拖**，交还框架重派即可。
11. 开秘密典籍：点备战席典籍占槽物一次 → 弹「货币战争-星徽秘典弹窗」四选一（单击即弹，不要双击——第二击会落在已弹出的弹窗上）（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
12. 开书册卡：点备战席书册卡占槽物（青蓝卡）→ 弹「货币战争-备战-专家邀请函」四选一（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
13. 免战跳过：免战牌激活时出战按钮变「跳过(N/N)」——点「按钮-跳过」直接进战斗（免战 2 次，语义同出战）；与开商店态可叠加（商店牌区展开时跳过按钮同位可见，两屏都查得到）（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
14. 处理「阿哈大悦」装备选择浮层（选投资策略「阿哈大悦」后自动弹出，盖在备战上不处理会一直卡备战）：点「按钮-简易装备首件」（约 626,250）即自动关闭浮层（框架固定选首件）（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
15. **左侧上下文区（探索反馈规则）**：左缘绶带区随局内内容显示不同的上下文入口/提示。已知形态：**开拓商店入口徽记**（金菱形，单击即开，建档「标识-银轨商店徽记」，在场性/坐标细节见「备战-开拓商店」卡入口节）。形态不可事先穷举：**见到左侧未建档的新元素，存帧申报（全帧 + 元素位置 + 提示文字内容），不要盲点也不要忽略**；建档与 extras 扩展由开发者侧跟进（目标态 = 识别层 extras 产出「在场性+坐标+提示文本」）。
**坑**：开商店态 front_line/deploy_count 为 null（完整读数先收店）；**extras 曾整体 null 的两类状态现均已接识别**：①一、二位面首领战前备战期 = 独立屏「货币战争-备战-选择主角」（出战钮文本变「选择主角」，据此精准命中、extras 全量照常产出；位面 3 首领战前无此屏，默认触发点 1-9/2-7——网络调研（待实机复核），实测 1-9 未出现疑为玩法任务「入画奇航」教学引入时序，见 references/mechanics/主角光环.md）——点「按钮-选择主角」进主角光环选择流程，选定后回备战；②装备合成确认浮层（右上小浮层：材料+材料=产物，✕/✓ 钮）**不影响识别**（浮层在场 extras 实测正常），但浮层期 owned_equips 会把「=」结果框预览图标误读为已入库装备——浮层期该字段不可信，确认后重读；两类都按下述降级口径：存图+读图继续对局，事后上报；front_line.star 两类失真（实测）：选为主角的单位恒读 1★（多单位复现）；合成升星当帧也可能误读 1★（同族失稳）——主角与刚升星单位的实际星级读图确认；出战 4/5 部署会弹「未达上限」（op 自动确认）；战斗约 60~90 秒后再截图。
