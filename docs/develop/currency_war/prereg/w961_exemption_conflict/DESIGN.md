# W961 架构反思批:信号层同线豁免 vs 假设失效评估——语义层冲突的形式化与解法设计

> 纯设计批,零代码/文档/测试改动,零 commit。读者 = 编排者与后续实施批。
> 证据链输入:W954 REPORT §8(联合 A/B 负结果 + 33 例降级次日走向)、W957 REPORT(P2 无决策环节)、w665 设计件 v3(保生存回锁)、ADR-0509(锁线可改判语义)、ADR-0353(防第二把尺)。

---

## 0. 现象(冲突的实证面)

W958 联合 A/B(sim n=300/臂,同 seed 配对,池指纹 6400d5d8)中,停滞判据臂触发 33 例降级(locked→weak,证据 kind='stagnate'),次日走向三分为:

| 走向 | 例数 | 机制 |
|---|---|---|
| **回原线**(已判死线被复活) | 12 | 次帧真实③信号(店内核心可见高频在场)指向 weak_comp==原线 → 同线重锁不辖 C4 门 → 直接落锁 |
| 落新线 | 8 | 异线信号经 `_switch_gate_open` 正常门控落锁 |
| 次战即死 | 13 | 降级后未及改判即 hp 归零 |

回原线占可判读例(20)的 60%。判据层刚以 gap/hp/form 三合取证据宣告「此线已死」,信号层下一帧就把它当「暂时失向」原样复活——**改判机制在信号高频域结构性失效**。任何方向侧生命周期机制(含未来 P1 pair 假设生命周期,W954 §7)只要落在这个状态机上,都会被同一个洞吞掉。

## 1. 冲突形式化

### 1.1 两侧设计意图及其合法性来源

**侧 A:信号层同线豁免(现状,先于停滞臂存在)**

- 表达式级锚(`kernel/cw_intention.py::_switch_gate_open`,辖域声明 L1021-1024 + 放行逻辑 L1032-1034):

  ```
  辖域 = 撤销出口①/②降级弱意向后、新信号锁「另一条线」(weak_comp ≠ 候选线)
  if not (ist.phase == 'weak' and ist.weak_comp and sig.comp_name != ist.weak_comp):
      return True          # ← 同线重锁(weak_comp == 候选线)不辖门,直接放行
  ```

- 配套的回锁闩(w665 DESIGN v3 §3-3 R-A;`cw_intention.py` L1460-1483):本位面首次门拦截置闩 → 闩置位帧**一次性回锁原线**(「锁线保生存」),闩存续期抑制撤销出口①②,locked 为吸收态。
- **合法性来源**:w665 设计件 §3-3 R2「纠错通道饿死」的反面教训——撤销出口把线降级后,若回程不免费,持续异线信号会让原线方向永久丢失(永久 weak、囤货中断)。所以豁免的前提假设是:**weak = 暂时失向,原线仍是可退回的最优方向,撤线只是惩罚性的暂停承诺**。R2 修法原文:「被拦连续 N=2 帧后原线 E 有限 → 回锁原线(经既有同线豁免,状态机内单址)」。
- **守护目标**:方向不丢(纠错通道可达性)+ 生存优先(锁住能活的线,不为方向理想主义送死)。

**侧 B:假设失效评估(W948 转型臂,ADR-0509)**

- 表达式级锚(ADR-0509 §决策 + `_stagnation_tick` L1062-1088):连续 `stagnate_windows` 个停滞窗(gap 未降 ∧ hp 净降 ∧ form 恒假红/假绿)→ 降级 weak,证据 kind='stagnate';`stagnate_cool[线]=位面`(同线每位面至多一次改判,L1100);撤后当轮不重锁(revoked 语义,L1081)。
- **合法性来源**:ADR-0509 背景——「锁」在 v2 只实现了**承诺语义**,缺「当前最优假设」语义的持有期半边。两局实证(g_20260831_053546 等:锁后 form 恒 0.65 达 7 轮、每战掉血、零重估)证明锁死后无任何重估通道。锁线因此应是一个**可评估、可证伪的假设**:证据齐了必须能改判。
- **守护目标**:不被死线锁死——停止给已证伪的假设供血,保留换线/升格的决策空间。

### 1.2 冲突的本质

两个机制各自治守一条真命题,但**辖域重叠、前提互斥**:

| | 侧 A(同线豁免) | 侧 B(失效评估) |
|---|---|---|
| weak 态的语义 | 暂时失向(方向信息暂时缺失) | 假设已判死(方向信息被证据否定) |
| 信号到达同线时 | 回程免费,应复活 | 判死须能改判,复活=推翻自己的证据 |
| 隐含的真理标准 | 信号在场 = 线仍是好方向 | 过程证据 = 线不是好方向 |

降级动作完全复用出口①的字段契约(ADR-0509 §机制明文「完全复用撤销出口①的降级形态与 revoke_evidence 字段契约」)——**这正是洞的根**:复用让停滞降级在状态机上与出口①不可区分,而信号层的豁免语义是按出口①的「暂时失向」前提写的。停滞臂改了 weak 的语义,却让 weak 换了一种进法,下游(信号解析)毫无感知。

**对「冲突本质两问」的回答**(任务书原问):

1. **生存优先是否应无条件高于假设评估?** 否。w665 的生存优先辖的是「门拦去程后的回程保证」——它的前提是原线**仍被相信**是活路。当判据层已经以证据判死原线,「锁线保生存」守护的对象(被相信的方向)已不存在;此时无条件让信号复活死线,守护的不再是生存而是**承诺惯性**。生存优先应作为**高优先级例外**(见 §2 解法 A 的豁免条件),不是无条件压倒。
2. **判死的置信度是否应分级?** 是,且分级必须落在**信号层可见的状态**上。三合取判据本身就是分级证据(gap 不收敛=低置信,hp 净降+持续=高置信),但这个分级目前只活在判据层内部,信号层只看到一个布尔(phase=='weak')。**冲突的可操作表述:判死结论没有在信号层留任何记忆,置信度信息在层间接口处被压扁成一枚与出口①同形的 weak 状态。**

### 1.3 为什么这不是两批各自的 bug,而是层间契约缺失

- w665 批在其前提(weak=暂时失向)下是**自洽的**——它写豁免时,唯一能进 weak 的通道是出口①/②(供给侧证据:miss 连败、门拦截),这些证据都不否定原线本身的质量。
- ADR-0509 批自己声明「不走门拦截路径、不受闩抑制」(L1080-1081),只管了**降级时刻**,没管**降级之后信号层如何对待这条线**——它假设「撤后当轮不重锁」足够,实测只挡住 1 帧。
- W958 升格批已经局部打补丁(「门拦不置回锁闩:停滞已判死的原线不得经闩复活」,W954 REPORT §8)——只堵了闩这一条复活路径,没堵占 60% 的主路径(同线真实信号直落)。**跨件半问判据命中:同族第 2 件补丁,根是同一个层间契约缺位。**

## 2. 候选解法(≥3,各带辖域/代价/风险)

### 解法 A:判死记忆标记(信号层尊重判死,生存临界例外)——**主推**

**机制**:停滞降级触发时,除复用出口①契约外,额外写 `ist.falsified[line] = state.plane`(判死记忆,坐标系:线名 → 判死位面)。信号解析落锁路径(_lock 入口前)增加一道检查:

- 候选线 ∈ falsified 且 `falsified[line] == 当前位面` → **拒绝同线复活**,信号按无信号处理(weak 续持,囤货停供语义照旧);
- **生存临界例外**:hp ≤ 生存临界阈值(复用既有 emergency_hp 族常量,不新造尺)时豁免记忆放行——此时 w665「锁线保生存」重新接管:快死了就不挑方向,能锁谁的件就锁谁;
- 位面切换清 falsified(与 stagnate_cool 清理同点)——新位面=新 shop 池/新节点结构,旧判死证据过期,假设可以重新登记;
- 异线信号照常经 C4 门落锁(不新增抑制面)。

**辖域**:只动「信号→落锁」单点 + 一个状态字段;判据层零改动。
**代价**:1 个状态字段 + 落锁路径 1 个守卫分支 + 单帧锁 2-3 条(判死拦同线复活/生存临界放行/位面切换清记忆)。
**风险**:判死误判时会错过真信号——但冷却驻留(`stagnate_cool`)已把同线改判限为每位面一次,误判代价上界=该位面该线失去一次机会,与现防振荡代价同量级;③信号高频在场恰恰说明「信号在场≠线好」(店里来核心是常态事件,不是质量证明),拒绝它不是丢信息而是拒绝把高频事件当裁决权。

**为什么主推**:它是三个解法里唯一**在洞的位置**(信号层)修的——洞的本质是层间契约缺失,A 就是把契约补上(信号层获得读判死记忆的权利);B 是消解触发结构,C 是用时间近似记忆,都是绕开信号层或在别处补偿。

### 解法 B:降级动作下沉信号层(取消两段式)

**机制**:取消「判据层先降级、信号层后解析」的两段式——停滞判据满足时**不降级**,而是给意向状态打 `falsifying` 标,信号解析时一并执行:若下一真实信号指向原线 → 执行「确认死」(降级+记判死);指向异线 → 直接落新线(降级与新锁合并为一次转移)。即判死在信号消费时才生效,天然不存在「复活」窗口。

**辖域**:意向状态机转移语义重构(转移一回合一次的不变量要重推),判据层与信号层耦合加深。
**代价**:重构面大——update_intention 的转移表、出口①的既有语义、单帧锁约 6-8 条重写;两段式取消后「停滞 weak 期间的停供/salvage」语义需要重新安置(现在 salvage 挂在 weak 子模式上)。
**风险**:高。停滞臂本身联合 A/B 判负(P2 存活无改善,W954 §8),为它重构状态机转移表违反「工作量不是决策主因」但更违反「长期价值」——重构收益完全寄生于一个尚未证明有效的机制。**判:不采,留档**。若未来方向侧机制被证明有效且需要更深的重构,再回收此形态。

### 解法 C:置信分级——判死带冷却期,期内信号豁免失效

**机制**:降级写 `stagnate_death_until[line] = 当前轮 + registry.stagnate_death_cooldown`(时间维记忆);冷却期内同线信号不落锁,期满后豁免自然恢复。

**辖域**:同 A(信号解析单点守卫),只是记忆键从「位面」换成「轮数窗」。
**代价**:与 A 几乎相同,多一个常量校准负担。
**风险**:冷却窗长度是新自由度——太短=洞没堵住(33 例的复活就发生在次帧),太长=真复活被压死;而 A 的「位面」界已有先例(stagnate_cool、闩的位面内滞回都定位面),位面切换即证据过期有结构依据(shop 池刷新),冷却窗没有。**判:是 A 的劣化变体,并入 A 不单列。**

### 解法 D(本批发现):信号强度分级——仅高层信号可复活死线

**机制**:信号已有 layer 维(①②③…,layer 越高证据越强)。死线记忆存在时,仅 layer≥某阈值(如最强层)的信号可复活,低层信号照常被拒。

**风险**:③信号(店内核心可见)正是本案 12 例复活的信号层——它是日常高频层,把它当「复活资格」等于没有门槛;调到更高层则复活面趋零,等价于 A 但多一个无校准依据的常量。另信号 layer 语义是「证据来源强度」不是「线质量证明」,借它当质量裁决是语义错位。**判:不采。**

### 解法互斥性/完备性检查

- **互斥性**:A/C 同点(信号解析守卫)互斥,C 已并入 A;B 是转移结构层面的不同范式,与 A 互斥(取一);D 是守卫条件维度的变体,与 A 可叠加但无独立价值。实现时取 A 单方案。
- **完备性**:任何修法必须回答三问——①信号层凭什么知道线被判死(**记忆**:A 的 falsified 字段/C 的冷却窗/D 的借用 layer);②记忆何时过期(**位面切换**/时间窗/永不过期);③什么能压倒判死(**生存临界**/超高层信号/无)。A 对三问各取一个有先例锚的答案;未列出的解法必然是这三个维度的其它取值组合,主要组合已覆盖。剩余取值(如「永不过期」)与位面结构矛盾(新位面 shop 池不同,判死证据必过期),不留候选。

### 与 ADR-0353(防第二把尺)对账

- ADR-0353 裁定 form_score 为纯遥测口径、不进任何判据;兜底门走结构判据(有效体系数),防「分数可达」假绿。本设计**不新增任何分数/连续量尺**:判死记忆是布尔状态位(判据层的既判事实在层间的搬运),不是第二把成型尺;生存临界例外复用既有 emergency_hp 族常量,不新造血量阈值。守 ADR-0353 ✅。
- 判据本体(gap/hp/form 恒假+核心当量)仍是 ADR-0509 修订后的既有判据,本批不碰其定义——只把**判过的结论**送到下游,不重算。

## 3. 波及面(按解法 A)

| 既有机制 | 影响 |
|---|---|
| **w665 保生存回锁闩** | 职责收窄但不冲突:闩继续辖「门拦去程后的回程保证」(其前提=原线未被证伪);falsified 记忆辖「已证伪线的复活拦截」。两 gate 相遇时(闩回锁帧恰逢死线信号)——闩回锁目标即原线,若原线在 falsified:判死证据**后于**闩语义产生且更具体,判死胜出(闩是滞回惯性,判死是证据);实施时在闩回锁路径同样过 falsified 守卫,并在单帧锁钉死这个优先序。 |
| **W948 停滞臂语义(ADR-0509)** | 补全其「撤后当轮不重锁」未竟的后半程:从挡 1 帧升级为挡满位面(除生存临界)。停滞臂开关仍默认关,本守卫随同开关门控(零漂移锚语义不变);若 stagnation 臂最终进清理批删除,falsified 记忆随载体同删,不独立存活。 |
| **出口①/②(撤销出口)** | 零改动——出口①降级不写 falsified(出口①是供给侧证据:miss 连败,不构成对线质量的判死;只有 stagnate kind 写)。这保证 w665 的「回程免费」前提在其自身辖域内原样成立。 |
| **W958 升格批(promote)** | 已打的「门拦不置闩」补丁被 A 覆盖且更完整(升格候选域本就排除原线);若 stagnation 臂清理,W958 同批清,无残留耦合。 |
| **未来 P1 pair 假设生命周期(W954 §7)** | 直接受益者:P1 pair 换线机制若落地,其「失效评估→改判」需要同一个层间契约,否则换出的线会被 pair 重派生或信号高频复活。A 的 falsified 字段是线名索引,P1 pair 线同域可复用;W954 §7 已声明 P1 独立立 ADR、不搬 P2 判据——A 提供的是**共享的层间接口**而非判据搬移,与其辖域声明不冲突。 |
| **salvage/弱占位(ADR-0509 丙/乙)** | 零改动:salvage 是 weak 子模式,不涉落锁路径;弱占位在 unlocked 域,falsified 只辖 locked→weak 后的落锁守卫。 |
| **检查器/账本面** | falsified 事件可经 last_event/serialize_intention 携带(同停滞臂先例,零新增 schema 面);ledger 的 relapse 检查(切线 ≤3 轮回锁原线)语义自然收紧,判断线=锁红时按「被锁语义已被新设计取代」重推,禁机械跟绿。 |

## 4. 建议

**主推解法 A:判死记忆标记 + 生存临界例外 + 位面切换过期。**

理由(三条,结论强度取最弱一环):

1. **修在洞的位置**:冲突根因是「判死结论没有层间记忆」,A 把记忆补在信号层读取的唯一入口(落锁路径),其余解法都在别处补偿。60% 复活例直接被拦,机制面完备。
2. **波及面最小且各归其位**:w665 辖生存、ADR-0509 辖改判、A 辖两者的层间接口——三个机制的前提假设互不侵犯;实现面 = 1 字段 + 1 守卫 + 位面清理,不动转移表、不动判据、不动支出数值。
3. **它是清理/重启决策的前置件而非新承诺**:联合 A/B 判负的裁定是「重启前提=先裁决信号层失效记忆问题」(ADR-0509 §Evidence 末条)。本设计正是该裁决的执行;它不预设停滞臂开臂——先修契约,方向侧机制(停滞臂重启或 P1 pair 生命周期)再各自过自己的 A/B 关。

**落码形态概述(给后续实施批的规格级输入,不落码)**:

- 状态:`IntentionState.falsified: dict[str, int]`(线名 → 判死位面;坐标系注释:键=COMP_LIBRARY 线名,值=判死发生时的 `state.plane`,取值时机=降级帧快照;写入端=仅 `_stagnation_tick` 触发分支)。
- 写入:停滞降级触发帧,与出口①契约复用并列,随 `intention_stagnation_arm_enabled` 开关门控。
- 消费:落锁路径(`_lock` 调用前,含同线直落与闩回锁两条)守卫——`falsified.get(候选线) == state.plane` 且 `state.hp > 生存临界阈值` → 拒绝落锁,按无信号处理;`last_event='falsified_block:<线>'` 记账。
- 过期:位面切换清理段(与 stagnate_cool/闩清理同点,入口段)整字典清空。
- 常量:生存临界阈值复用既有 emergency_hp 族 registry 常量,**禁止新造阈值**;无新常量。
- 验证阶梯:单帧锁 ≥4(降级帧次帧同线信号被拒/异线信号正常过门落锁/hp≤临界时同线放行且闩语义接管/位面切换后同线可重锁)+ off 臂零漂移锚 + ledger relapse 检查重推;若 stagnation 臂重启,sim A/B 判据沿用 W954 prereg 的防振荡线(换线次数/摇摆占比不升)加「falsified_block 事件后同线零重锁」新增判据。
- 文档:独立 ADR(语义=层间契约,标题建议「信号层判死记忆与生存临界豁免」),ADR-0509 补指针,不动 ADR-0353。

## 5. 编排者裁决与挂账(批末补记)

裁决 = **方案 1(改判缓期)采纳**:falsified 契约随第一个带判死写入端的批次同批落地(停滞臂重启批或 P1 pair 生命周期批,先到者为准);本 §4 规格六条 + 插入点核对结论作为契约模块随批平移。本批交付 = 零码 + 挂账记录(ADR-0511,deferred 态)。

缓期理由:方向侧判死机制已随 ADR-0509 判负删码,写入端离场;消费壳单独落地 = falsified 恒空、守卫永不开火,撞 ADR-0429「有消费点无触发面空转」与 strategy-work §4「新机制先验证它会开火」。
