# CV 投影峰值法:信号 / 参数选择依据 + 踩坑

> 本文件记密集规则网格「投影峰值法」的**信号与参数选择理由**(为什么标准差、为什么 slot_w//4、
> 为什么 median)+ 实测踩坑。属调参 / 实现级论据,不配 ADR(见 `sr-od-dev-skill-guide`
> 硬规范 1 门槛:调参 → 实现论据,不单列 ADR)。
> **方法步骤**(裁行带 → 逐列信号 → 平滑 → 阈值 → 局部极大 + NMS)见 [`../SKILL.md`](../SKILL.md)
> 「CV 路径:密集规则网格用投影峰值法」;本文件只记「为什么是这些参数」+ 踩坑,不重复步骤。

## 1. CV 用「投影 + 局部极大 + NMS」,不用「边缘配对」

踩坑:第一版用 Canny 边缘列投影 + 把相邻边配对成卡 —— 槽间距(~12px)< 配对阈值 → 相邻槽并成
一段,数量减半 + 偏移。

改法:**逐列标准差** → 局部极大(窗口 `±slot_w*0.4`,每槽至多一峰)+ NMS(限距 `slot_w*0.7`)
→ 一个槽稳抓一个峰,不受槽间距影响。

## 2. 信号用「灰度标准差」,不用「框色」

踩坑:实测某备战栏边框 BGR ~[45,34,33],**槽间缝隙 BGR ~[47,30,30] —— 同色**,HSV 阈值分不开。

改法:标准差看「槽内有别于缝隙的任何信号」(立绘 / 边框 / 阴影都行),内容无关,连空槽
(微弱信号)都能抓。框色法只在框色与背景**明显可分**时用(如某些画面框是亮色)。

## 3. 平滑核 slot_w//4、阈值 median

- **平滑核 `slot_w//4`**:重了(`slot_w//2`)会把密集相邻槽桥接(实测 pitch~125 时平滑核 56
  就开始糊),数量掉到 5/9。轻平滑刚好去毛刺又不桥接。
- **阈值 `median`**:高了会滤掉空槽(实测空槽峰高仅 ~4.5,远低于有立绘槽的 ~65–85)。median
  低到能保留空槽的微弱峰。
