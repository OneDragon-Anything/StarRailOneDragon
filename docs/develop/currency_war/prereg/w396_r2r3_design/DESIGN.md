# R2 设计稿:hp_trusted 下行误读守卫

## R2.0 问题重述(W393 A2 / S5)

- 派生式 `hp_trusted = 现读非 None ∨ last_hp_real 存在`(`cw_observation.py` L1115-1120)把「曾存在真值」等价于「当前值可信」。
- 对账层(`cw_reconcile.reconcile_hp` L258-266)只有**上行** ≥ `HP_REAL_JUMP_CONFLICT=30` 留证(仍采新);**下行无任何守卫**——OCR 读低(数字缺位/遮挡)直接采新写回 `last_hp_real`。
- 后果链(A2.2 反例帧):误读 60→20 被采新 → 后续所有帧 `hp_trusted=True` → 毒值被 FLIP 持续臂(应急清仓)、C3 濒死带收窄、C1 当**可信值**消费——ADR-0428 的守卫放宽把错误真值的作用面从零放大到全谓词。ADR-0428 Decision 4 的「无误触发面」论证只对**兜底 100** 成立,对**沿用毒值**不成立,须单独重写(见 R2.6)。

## R2.1 根因分层与治本定位

- 根在对账层语义:HP 的合法变化只有三种物理来源——①败战损血(幅度 ≤ 单战损血谱上界)、②胜战回血/零损(encounter 回血)、③什么都没发生(帧间无战斗)。误读读低**不属于任何一类**。
- 治本 = 把「真值帧的合法性」从单一幅度判据升级为**幅度 × 战斗事实**联合判据:只在本帧与上一真值帧之间「物理上可能发生该幅度下行」时才采新。这不是给决策层加补丁(那会把毒值拦截散进每个谓词),而是修复对账层自己的缺口——与 ADR-0282「session 更新只在合法帧」的既有语义同层补全。

## R2.2 守卫判据(可复算)

> ⚠️ 本节判据已被 ADR-0431 修订(2026-09-02)部分取代:`fact='none'`(无战斗事实)分支从「一律拒信」改「跨节点采新+留证」,守卫判据按「hp 节点内恒定/跨节点结算才变化」机制重推导为五分支——现行权威见 [ADR-0431 修订记录](../../redesign/decisions/adr-0431-hp-down-guard-battle-fact.md)。下文保留原设计稿历史原貌。

记:上一真值 `o = session.last_hp_real`,本帧现读 `n`(非 None),下行幅度 `Δ = o − n`。引入两个 registry 级锚常量(值单一源 = 既有标定,不新拍):

- `L_cap(node_type)`:**单战损血谱 p100 上界**,按节点型分档。来源 = 既有 registry 损血表与语料:`boss` 档取 P1 语料 boss 税 p100 = 58(ADR-0426 §1「max=58」);`normal`/`encounter` 档取对应损血表上界(W370 重校后的 P2 粗档表,现值 normal 20.05 / encounter 16.67 为期望值,上界另取各档样本 max——**上界标定是本批落码前的采集前置**,见 R2.8 前置①)。P2 boss 上界无语料,挂账待标定,过渡取「P1 boss p100 与 P2 损血谱上界的较大者」并在常量注释声明置信级别。
- `H_cap`:单战**回血**上界(encounter 回血期望 + 余量;同表派生)。

对账判别式(`reconcile_hp` 内,新增下行分支):

```
若 n ≥ o:  现行上行守卫不变(≥ HP_REAL_JUMP_CONFLICT 留证、仍采新)。
若 n < o:  按「帧间战斗事实」三分:
  (a) 帧间有已观测战斗且 outcome=win/零损节点(reward/supply):
        合法下行仅可能是回血记账误差 → Δ ≤ H_cap 采新;Δ > H_cap → 拒信+留证。
  (b) 帧间有已观测战斗且 outcome=loss,节点型已知:
        Δ ≤ L_cap(node_type) → 采新;Δ > L_cap(node_type) → 拒信+留证。
  (c) 帧间无已观测战斗(结算漏采/telemetry 断/本帧为 shop 开态 OCR 恢复):
        一律拒信+留证(物理上不存在合法下行)。
拒信语义:本帧返回 (o, False)——沿用旧值,不写 last_hp_real,发 obs_conflict
        留证(verdict='下行拒信-疑OCR读低',与上行留证同通道、方向字段区分),
        并写入 session.hp_suspect = (值=n, 节点号, 计数) 进入复现确认通道(R2.3)。
```

**为什么 60→20(Δ=40)能被拦**:A2.2 反例帧是「战斗结算帧」——分支 (a) 或 (b) 必然适用。若该战 outcome=win,win 不损血是机制事实,Δ=40 > H_cap → 拒;若 outcome=loss 且为 boss,Δ=40 ≤ 58 在谱内——**此时 40 的下行是真损血,本来就不该拦**。W393 A2 说「先验救不了」针对的是纯幅度判据;本设计的关键是把判据从「幅度像不像误读」换成「这次下行有没有战斗事实背书」——误读与真掉血的区分变量不是幅度,是**帧间发生了什么**。纯幅度判据(单腿 D1)只作粗滤兜底保留在 (c) 支:无战斗事实时任何下行都不可信,无需幅度阈值。

## R2.3 毒化窗界定与自愈(复现确认通道)

- **窗的起点**:拒信帧。**窗的语义**:期间 `state.hp = o`(沿用),`hp_trusted` 按 R2.5 沿用态口径;拒信值 `n` 不消失,挂在 `session.hp_suspect`。
- **自愈判据(二选一即出窗)**:
  1. **误读确认**:后续任一真值帧读数回到 `o` 的合法带内(|读数 − o| ≤ OCR 容差;容差 = 同域数字 OCR 单字符误读界,复用 hp 读数历史形变先验,无先验档取逐位相等)→ 确认 `n` 是误读,丢弃 suspect,一切如旧。
  2. **真掉血确认**:后续连续 2 个真值帧读数与 `n` 一致(或相互一致且远离 `o`)→ 确认真掉血,采新并出窗。2 帧 = 最小独立复现数:1 帧可能是同一遮挡形态的系统性误读复现,2 帧要求误读源跨帧稳定存在,而实机遮挡(shop 开态血量区)是**开态特有**,结算/备战帧不复现同一遮挡。**不取 1 帧**:那等于放弃守卫;**不取 3+ 帧**:每多一帧确认期,真掉血场景的决策滞后多一个节点,代价见 R2.4。
- **窗长上界**:每节点至少一个真值帧(结算/备战帧血量区可读;shop 开态才是 None),故窗长 ≤ 1 节点 + 确认期 ≤ 2 节点。窗内**同轮 latch**:`hp_suspect` 活跃期间,对同一毒值来源的拒信只发一次留证(计数节流,同 `_conflict` 既有每 5 次口径),防遥测刷屏;决策侧无需 latch——因为窗内决策用的是旧值 `o`(被守卫保护过的值),不是毒值。
- **留证 ≠ 纠错的缺口闭合**:W393 A2 指认「留证不拦决策」。本设计把留证与拦解决策绑在同一分支:拒信分支同时完成留证与返回旧值,不存在「留了证仍采新」的形态(与上行分支「留证仍采新」刻意不对称——上行的物理先验是 HP 只降不升,读高必是误读或特殊回复,采新是物理读数优先;下行的读低既可能是误读也可能是真损血,事实核对说了算)。

## R2.4 误报代价分析(把真掉血误判为误读)

**误报定义**:守卫拒信了一次真下行。逐分支界:

- 分支 (a)(win/零损帧):误报 ⟺ 结算 outcome 被误记(win 判定 = 结算屏 killed 信号,v5 权威口径,ADR-0306 谱系)但实际败战。代价传导:决策沿用高值 → 错过应急带 → 下一战败且 `hp ≤ L_cap` → 死。**发生概率上界 = 结算 outcome 误读率 × P(真值 ≤ 下一战 L_cap)**。第二因子是濒死帧才危险,第一因子是全部——所以误报率的实际控制变量是结算判定准确率,这是**可测的现有量**(遥测 killed 字段与血量轨迹对拍历史;落码前用既有遥测回放统计,见 R2.8 前置②)。
- 分支 (b)(loss 帧):误报 ⟺ 真损血 > `L_cap`,按 p100 定义样本内概率 = 0;残余风险 = 语料外肥尾(P2 boss 无标定)。
- 分支 (c)(无战斗事实):合法下行不存在,误报率构造性为 0;风险移到「结算漏采率」——漏采把 (b) 降级成 (c),此时真掉血被拒 1 帧,下一真值帧进复现通道,1 帧后自愈。漏采率的现状量 = 遥测结算帧覆盖率(W40 damage_dealt 生产链),可查。

**权衡曲线(灵敏度档位)**:把守卫灵敏度想成 `L_cap` 取哪一档——p50 / p75 / p100:

| 档位 | 拦截误读能力(以 Δ=40 为例) | 真掉血误报率(boss 败战场次) |
|---|---|---|
| p50(≈26.7) | 拦 | ≈50%(p50 定义) |
| p75(=34,ADR-0426 boss_tax_p75 同源) | 拦 | ≈25% |
| p100(=58) | 拦(boss 档) | 0(样本内) |

误报代价不是线性恶化的「少省一笔金」,而是**跳过应急→死**(单局全损),误报率 25% 完全不可接受——**这从数学上排除了中低分位档,`L_cap` 必须取 p100 上界**;灵敏度不足的部分(Δ 落在谱内的读低)交给分支 (a)/(c) 的战斗事实判据补,不靠压幅度阈值。这条曲线同时回答「为什么不能顺手把阈值调低换灵敏度」。

**与不修的对照(毒化代价)**:现状误读 60→20 的代价 = 应急清仓(不可逆卖板)+ C3 收窄删投资,清仓本身在真值 60 的帧上就是负期望动作(W393 A2.2 已推演,重一个量级);守卫的误报代价是尾部概率事件。两害的期望比较:误读触发条件 = OCR 读低(血量区有遮挡史,ADR-0426 §A 实证 26/26 帧血量区异常形态)× 读数恰好落入毒带;守卫误报条件 = 结算误记 × 濒死。前者频度由实机 OCR 形态史背书,后者有上界可测——修的期望收益为正。

## R2.5 与 hp_readable / hp_trusted 的终态关系(三态?)

**结论:GameState 公开面维持两位不加第三位;三态落在对账层内部。**

理由:全部谓词消费面(FLIP `posture_release.py` L131、C1 `filters.py` L181、第三路径、濒死带)读的都是 `readable or trusted` 的布尔合取(ADR-0428/W393 S1 的统一守卫问题归 R5 批,本稿不改口径);加第三个公开位意味着每个消费点都要重答「suspect 时放不放」,而 R2.2 的拒信语义已经把 suspect 帧的返回值折叠成「沿用旧值」——对消费面它**就是**一个普通沿用帧,无需新语义。三态的完整判定:

| 对账层状态 | hp 值 | hp_readable | hp_trusted | 依据 |
|---|---|---|---|---|
| VERIFIED(真读且过守卫) | n | True | True | 现读合法 |
| STALE(沿用真值) | o | False | True(仅当 o 写入于**同节点内**) | ADR-0428 沿用放行,R2 收紧帧龄 |
| SUSPECT(真读被拒信) | o | False | True(同 STALE 帧龄口径) | 拒信 = 折叠回沿用 |
| FALLBACK(开局兜底) | 100 | False | False | ADR-0428 不变 |

**`hp_trusted` 派生收紧(帧龄语义,修「曾存在真值 ≠ 当前可信」)**:`hp_trusted = (n 非 None ∧ 过守卫) ∨ (had_real ∧ last_hp_real 写入帧的节点号 == 当前节点号)`。跨节点沿用(stale 且帧龄 > 1 节点)→ trusted 降 False。推导:沿用值的可信度随时间衰减的唯一物理来源是「期间可能发生了未被观测的战斗」;帧龄 = 节点号差就是对「漏采了多少次战斗」的直接计数;同节点内(shop 开态帧,ADR-0428 要救的主场景)帧间无战斗,值必然未变——帧龄门恰好放行 ADR-0428 要救的帧、拦住「隔了 N 个节点还信旧值」的形态,不是新拍阈值而是从「可信」的物理定义直接读出。落点 = `read_game_state` 写入端一行派生式 + session 记 `last_hp_real_node`。

## R2.6 安全论证重写(ADR-0428 Decision 4 的补丁)

ADR-0428 的「无误触发面」论证(「兜底帧 hp=100 两臂天然不命中」)**只覆盖 FALLBACK 态**。R2 落码时,该论证须按本稿重写为分态版本:VERIFIED 态 = 值是物理读数,谓词命中即真实危险,无误触发问题;STALE 同节点态 = 值必然未变(帧间无战斗),等价于真值帧;SUSPECT 态 = 值是被战斗事实否定了下行的旧值,毒化方向(读低)已被拦截,残留方向(沿用偏高)的代价即 R2.4 的误报账。任何引用「守卫放宽无误触发」的后续设计,必须声明它讨论的是哪一态。

## R2.8 实机验证判据与前置

**落码前置(采集/测量,不拍值)**:
1. 损血表各档 p100 上界标定:从既有 sim 冻结池 + 实机遥测血量轨迹提取各节点型单战损血 max(现成数据,`cw_delta_pool`/遥测回放可算);P2 boss 缺口显式挂账。
2. 结算 outcome 判定准确率:遥测回放统计 killed 判读与血量轨迹的矛盾率(即 R2.4 分支 (a) 误报率的第一因子)。

**单帧锁清单(可复算,帧字段齐全)**——`test_cw_reconcile` 下行守卫用例:
- win 帧 Δ=40 → 拒信,返回 (o, False),`last_hp_real` 不写,conflict 留证行方向='down'。
- loss 帧(boss)Δ=40 ≤ 58 → 采新(真掉血,毒化窗不误开)。
- 无战斗事实帧 Δ=5 → 拒信(分支 (c) 无幅度豁免)。
- 复现确认:拒信后连续 2 真值帧低位 → 采新出窗;1 帧低位 + 1 帧回归 → 丢弃 suspect。
- 帧龄门:跨节点沿用帧 trusted=False,同节点沿用帧 trusted=True(ADR-0428 r9 帧形态 fixture 不回归)。
- FALLBACK 帧(无真值)行为逐位不变。

**sim 零漂移声明**:sim 帧 hp 恒真读、结算 outcome 恒已观测且自洽 → 守卫全过、帧龄门全过 → 逐位等价;源级锁钉住(同 ADR-0428 Decision 5 惯例),不另跑对拍。

**实机锚点(事前写)**:观测 K 局(K ≥ 含血量区遮挡形态的历史频度所定的最小样本,前置②产出),判据:①零「真掉血被拒」事件(判别法:拒信帧的下一真值帧读数**回归旧值带** = 误读确认,应占拒信事件 100%);②每条 'down' 留证行都能在对应帧截图复判中指认误读形态(缺位/遮挡);③复现确认通道每次触发都有完整 2 帧证据链。锚点没中 = 守卫没生效或判据错,两者都要查。

# R3 设计稿:撤销出口意图证据

## R3.0 问题重述(W393 A3)

- W386 BP1(降 `CORE_MISS_N` 对齐位面预算)被推翻:阈值降到 P2 可达值后,先到达的是出口①本身——miss 计数把「核心短时缺货」的正常噪声成批送进撤销,门放行了「活得到但换了更亏」的噪声换线(危害搬家到门下游)。
- W379 诚实结论(ADR-0429 增补):v2 sim 下撤销出口 0 触发——「锁定即持有」([23])下换线帧结构性缺位,出口的不可达是教义的体现,不是接线 bug。治本方向 = 出口加**意图证据**:只在「锁定教义的前提被证据否定、且存在已在生长的替代资产」时才允许撤销。

## R3.1 「换线意图」的可观测证据定义

核心区分:真换线意图 vs 核心缺货噪声的差别,不在「本线缺了多久」(那是噪声与断供共有的),而在**有没有另一条线正在实际生长**。证据分两组,出口①开窗须同时满足:

**证据组 A——本线断供的强度(必要条件,替代拍死计数)**:

- 现状 `CORE_MISS_N=6` 是拍死值(模块注释自认「设计推断,sim 校准」)。改为从再遇窗口期望推导:`N_req(core, level) = ⌈ln(ε) / ln(1 − q)⌉`,其中 `q = 1 − (1 − r)^5`、`r = refresh_prob(level, cost) / DISTINCT_CARDS_PER_COST[cost]`(全部复用 `encounter_window_rounds` 既有构件,`cw_intention.py` L274-291),`ε` = 「核心实际可达但连续 N 轮未现」的容忍概率。推导:P(N 轮未现 | 单轮出现率 q) = (1−q)^N ≤ ε。ε 取 5%(「可达却连续缺席」压到二十分之一以下才构成断供证据;ε 是唯一待校准量,落码前 sim 扫 ε ∈ {1%, 5%, 10%} 看出口触发率与换线收益的权衡,见 R3.5)——阈值随核心费用/当前等级自适应,3 费低星档自动要求更多轮,1 费核心几轮即达,消除「同一名义阈值跨费用语义漂移」。
- 复算例(仅示意量级,以 `cw_shop_odds` 实表为准):3 费核心 @7 级,r ≈ p/v,q = 1−(1−r)^5,若 q ≈ 0.22 则 N_req = ⌈ln0.05/ln0.78⌉ = ⌈12.6⌉ = 13 轮——远大于现值 6,定量呈现「6 是多容易误触发」。

**证据组 B——替代落点的在场资产(意图证据本体,W393 A3.3 方向)**:

- `I_evidence = ∃ 异线 comp: _core_reachable(comp) ∧ _asset_thickness(comp) ≥ A_min`
  - `_core_reachable`:出口②既有可达对照(核心在手或再遇窗口 ≤ 全局剩余节点),直接复用,不造第二把尺。
  - `_asset_thickness ≥ A_min`:该线终局件(星级当量)+ 骨架件 × `SKELETON_ASSET_WEIGHT`(0.5,既有派生)≥ `A_min`。
  - **`A_min` 的推导而非拍值**:「≥2 件当量」的依据是——1 件在场对任何线都是顺来牌常见事件,无方向证据力(P1 配方锁的 `P1_PAIR_LOCK_MIN_SUPPORT=0.5` 恰好=单件即可立方向,说明单件是「方向候选」不是「意图」;意图要求跨过随机来牌基线)。随机基线的测量协议:**落码前从 sim 冻结池统计「任一 v2 线厚度 ≥ a」的无条件频率曲线 f0(a)**,取 `A_min` = 使 f0(a) ≤ 5% 的最小整数 a(即「同一局里随便长出这么厚的异线资产」是小概率事件时,它才构成意图证据)。这是可复算的测量门,不是魔数;若曲线平缓到 5% 点过厚(如 ≥4),说明该证据在本牌池分辨力弱,如实降级并回炉(证据组 A 单独撑或换证据形态),不硬凑。

**出口①新判别式**:`phase=='locked' ∧ miss_count ≥ max(CORE_MISS_N, N_req) ∧ I_evidence → weak`。`CORE_MISS_N` 保留为上限保险(防御 N_req 因牌池数据异常而过小),两者取 max。

**出口②不动**:其「更高层级信号 ∧ 可达对照」本身就是意图证据形态(层级信号 = 外部背书,可达 = 落点存在),W393 实录的噪声例(`revoke:higher:列车同行`)的噪声源在信号层,归信号质量批,不在本稿辖域。

## R3.2 误开窗率的量化目标

- **误开窗操作定义**:出口①开窗(`last_event='revoke:miss…'`)且其后到局末**未发生**「新线落锁且新线最终成型(form_score 达标)」。即:开窗既没换来换线、也没换来成型 = 纯扰动(weak 态下 transition_pair 退场、P1 过渡对派生脱锚,W393 A3.2 已推演其代价)。
- **量化目标(sim 口径,n=300/臂,池指纹锚)**:
  1. 出口①触发率:off 臂(现状)应 ≈ 0(W379 实测 0);evidence 臂触发率须 **> 0 且逐局可解释**(每例都带证据字段,见 R3.6)——目标是「门有可辖对象且对象皆有意向」,不是触发量。
  2. 误开窗占比 ≤ 1/3:开窗局中「新线成型」局 ≥ 2/3。低于此线 = 证据组 B 分辨力不足,回炉 `A_min`/`ε`。
  3. 开窗局 P2 存活轮数分布不后移(C3 同款概念无效判据,ADR-0426 增补 B):换线若真救局,存活应后移;不后移 = 出口在 sim 牌池里概念无效,如实记「结构件」,不硬开臂。
- 生产阈值零改动是硬约束:上表全部数字来自**注入臂**(R3.5),off 臂与 W379 off 臂逐位相等作零漂移锚。

## R3.3 与 [23]「锁定即持有」教义的相容性

- [23] 禁的是**涌现挑线**(分数驱动的 pivot)与轻率弃线;出口①的合法形态从来是「贯穿件不可得」这一前提被否定时的止损。本设计把「不可得」从计数猜测升级为**统计证据 + 替代资产证据**,是让撤销更难、而不是更容易——相容性方向为正。
- 撤销后的路径不变:weak 态囤跨线骨架,新锁仍走 `_best_signal` 分层序(①-④),**新线必须来自既有信号层,不是意图证据自己选线**——证据只回答「可不可以撤」,不回答「撤向哪」,选线权仍在信号分层,涌现挑线零新增面。
- 资产连续性视角:证据组 B 要求替代线已有在场资产,换线被约束为「资产迁移」而非「推倒重来」——这与 P2 中段重建成本吃存活余量的攻击点(A3.2 推演 3)正面相抵。

## R3.4 C4 门在意图证据后的可测性重设计

W386 的测法(降生产阈值制造门流量)被推翻;替代方案按验证阶梯三层,生产阈值全程不动:

- **L1 单帧状态机锁**(沿用 W386 §2.1 模板,但测的是新判别式):构造帧逐条锁——miss 达标 ∧ 证据齐 → 出口开窗;miss 达标 ∧ 无异线资产 → 不开窗(新);miss 未达 ∧ 证据齐 → 不开窗;开窗后同线重锁不辖门 / 异线重锁经门放行/拦截两分支(ADR-0429 五锁不回归)。
- **L2 sim 注入臂(有效性结论的唯一来源)**:A/B 对照手段经 registry 注入,不进生产代码(strategy-work §4 纪律;「默认关的悬置开关」禁)。注入面 = 牌池 fixture 使「异线厚度 ≥ A_min」帧可控出现(如注入低费核心提高 encounter 频率),从而出口①在 sim 有确定性流量、门有可辖对象。判据 = R3.2 三条;off 臂与 W379 off 臂逐位锚。
- **叙事修正(对齐 W393 S3)**:在注入臂结论出来前,C4 家族一律记「结构件,零行为证据」;ADR-0429 增补节的「待真实换线帧出现才可测」由本稿落地为「待**注入臂**或实机证据帧出现」,可测性的定义从等流量变为可制造流量。

## R3.5 实机验证判据

- **遥测面**:出口①开窗事件行携带证据字段(miss_count、N_req、q、异线 comp 名、e_alt、asset_thickness)——无证据字段的开窗 = 守卫失效,判读即报警。
- **判读锚点(事前写)**:实机每例开窗局逐局四问:①证据字段是否齐全且成立;②开窗后是否落锁新线/新线是否成型;③被门拦的例,拦截理由与存活账是否自洽;④开窗局结局 vs 同画像 off 历史局(小样本只作哨兵,不作效果结论——W393 A5 功效账:n<60 的实机序列检验力为零)。
- **噪声回灌**:实机若出现「证据成立但判读否决」的例(如厚度来自即将被卖的对子),该例回灌为单帧锁 + 证据判据修订候选,进下一轮设计批。
