# ADR-0483: 位面 2 支出授权 v3.2(W772 判定分支 2 后出手面修正:梯级重排+净支出闸+保留金公式化)

> **版本界碑(2026-09-04 ADR 存量 review;对象属 decision_v2 栈或旧策略代,现行权威 = strategy-docs/flow/proofs + dd-NNN 系)**:本 ADR 裁决的对象已亡——decision/ 整包(含 decision_v2 各模块)已随 b94e9cfb(dd-038)删除,现行唯一策略载体 = mandate_v1(kernel 吸收下沉判据)。本件仅存史料价值(记录设计 why/翻案史);**文内一切「后续应做 X/须换成 Y」类前瞻指令一律视为已亡,勿执行**。

## 背景

ADR-0481 落码的 v3.1 两通道版按预注册协议 v3.1 完成 A/B(W772):M0a
判定触达 98.4% ✓(v3 覆盖修复被实证有效),但 M0b 出手有效性 10/246
= 4.1% ✗——513 个授权帧中 503 帧毛支出>0 却低于当轮收入,金账不降、
囤金原样带到死。按协议 §3 事前写死的三分支归因规则判**分支 2:通道 B
方向梯级失效**(授权了没花:店态与梯级供给不匹配)→ 回设计层调梯级,
不诿上游。另有出手力度旁证:1462 个加急帧仅 53 个破息——常数保留金
下限(20)疑似卡死力度。W757 设计件据此升 **v3.2**(附录 D,协议判据
零改动:重跑沿 SIM_AB_PREREGISTRATION_V3 现行版,无需换编号)。

## 决策

1. **通道 B 方向梯级重排(v3.2;W772 修订方向①)**:v3.1 梯级
   (hoard→桥池→[31]①)给出的买目标太便宜,与 [22]③(稀有度越高越
   该囤)/[17](溢余花在边际价值高处,量级应与溢余量级匹配)相悖——
   用 1-2 费填充件消耗 80+ 金溢余是量级错配。重排为:
   - **L1 高价值定向**:①锁定线核心卡(贵价 3-5 费);②2★ 升级凑档
     件(同名第 2/3 副本买即 3合1 跳档,判据经 ``merge_buy_completes``
     单一源);③线内 3-5 费终局件(方向源集 ∩ 费 3-5);
   - **L2 定向 D 找 L1 目标**:P12 批账不动(j≥1 翻正才付,j=0 负例
     保持);
   - **L3 低价兜底**:仅当 L1 全部过不了净支出闸(选中集为空)时,
     v3.1 原梯级照旧放行(兜底层接受小额净支出);L1 过闸存在时 L3 件
     不获授权放行(单帧锁⑮)。
2. **净支出闭环闸(v3.2;修订方向③,单帧锁⑭)**:通道 B 授权帧的
   L1 选中集按单笔预期支出**降序累计**,累计 Σ支出 > 本轮预期收入的
   前缀才获授权放行——「净支出 ≤0 的候选不出手,直接上更强目标」。
   预期收入 = 基础奖励 + 连胜档 + 息(economy §10 备战帧口径,三分量
   全为既有单一源转发:``BASE_INCOME``/``streak_gold``/``interest``,
   零新常量)。「高价值」**不设新魔数**——排序与过闸全由本闸机械化。
   校验是**目标选择器不是新收门**:既有息账门放行的笔授权不拒(False
   即回落既有裁决),与「只开门不收门」相容。
3. **保留金下限公式化(v3.2;修订方向②)**:加急层破息地板从常数 20
   占位改为 **5 × min(本位面剩余备战轮数, cap)**(P13 息流式直接截
   断:保留金收益上限 = 每轮息 5 金、位面末守息无意义封顶 cap 轮,
   取值域 [5,15]);常数 20 降为**绝对异常地板**(仅公式输入异常回落);
   权衡账 = T3 帧多保金息收益 ≤5/轮 vs 救活一场败局 15.39(P2 条件败
   局伤害)。P21 濒死禁 / ADR-0448 停升级线 AND 不变(下限只辖买/D
   预算)。G1-B① 护栏阈值随公式同步重标(协议判读脚本参数,红线语义
   不动)。新 registry 字段 ``p2_spend_auth_reserve_rounds_cap=3``。
4. **触发判据与豁免结构零改动**:M0a 98.4% 实证 v3 覆盖修复有效——
   两通道触发/末窗收窄/姿态让位/接管序全部保持;本批只修出手面。
5. **开关生命周期:仍第 1 态(重挂延续)**:梯级/净支出闸/保留金公式
   为新机制未经 A/B;开臂判据=协议 V3 双钥匙(判据零改动重跑),三分
   支归因规则不变。默认关零漂移(全部新路径在授权帧判定之后,开关关
   时 frame=None 恒短路)。

## Considered Options

- **单笔逐个过净支出闸**(否决):g≥50 帧收入 ≥11(息 5 封顶),单
  笔最高 5 费永不>收入 → L1 结构性恒不过闸 = v3.2 退化为空转。降序
  累计 Σ>收入 是「Σ候选支出−收入>0」判据的机械化实现,也正是 W772
  失败形态(多笔小额合计仍<收入)的对面。
- **保留金下限调常数**(否决):换一个魔数仍是与局势无关的常数,P13
  息流截断有公式可依,能算能证的一律优于拍死值。
- **净支出闸做成硬收门**(否决):违反「只开门不收门」——既有门放行
  的笔授权不改判;闸只决定授权放行给谁(L1),不拒绝任何笔。
- **采纳**:梯级重排+净支出闸+保留金公式化(本 ADR 决策 1-3)。
