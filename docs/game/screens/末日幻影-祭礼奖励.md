# 末日幻影-祭礼奖励(treasures_light_as_gift)

末日幻影选关屏左下**礼物盒**打开的期次奖励领取弹窗(模态,背景暗化)。
两个 tab:**永劫祭礼** = 期次星数累计奖励(按累计星数分档);**终局祭礼** = 各难度
首通奖励(每难度一行)。忘却之庭/虚构叙事选关屏也有同构礼物盒入口(待建档),
弹窗 UI 与领取机制预期同构。

## 何时出现 + 状态流转

| 态 | 入口 | 出口 |
|---|---|---|
| 永劫祭礼(默认 tab) | 选关屏点左下礼物盒 | 点「领取」→ 获得物品覆盖页 → 点空白回本态;切 tab;点关闭X → 末日幻影-选关 |
| 终局祭礼 | 点「终局祭礼」tab | 同上;切回 tab |
| 获得物品(覆盖页) | 点任一「领取」按钮 | 点空白处关闭 → 回领取前 tab 态 |

- 领取**无确认弹窗**,点击即发放。
- 领取后列表滚动位置重置回顶部;tab 红点(有可领时)消失,选关屏礼物盒红点随之消失。
- 终局祭礼各难度行的可领条件 = 该难度首通;星启(难度04)未通时恒「进行中」。

## 识别特征(稳定锚点)

- **双 tab 文字组合**「永劫祭礼」+「终局祭礼」(顶部,两态恒在):id_mark 双锚。
  「获得物品」覆盖页盖住标题栏(tab 不可读)→ 覆盖页帧本屏不 is_precise,
  靠「按钮-点击空白处关闭」area 识别,与弹窗态天然区分。
- 「永劫祭礼」「终局祭礼」为逐光捡金奖励弹窗专属词,他屏无此文本。

## 可交互元素

| 元素 | 行为 |
|---|---|
| tab-永劫祭礼 / tab-终局祭礼 | 切换奖励列表(停留弹窗) |
| 按钮-领取(金色,行右端) | **一键发放本 tab 全部可领档位**(无确认弹窗)→ 获得物品覆盖页 |
| 按钮-点击空白处关闭(获得物品页底部文字) | 关闭获得物品页 → 回弹窗 |
| 按钮-关闭X(右上) | → 末日幻影-选关 ✓(2026-11-07 实测) |
| 奖励列表 | 可滚动;领取前自动定位到第一个可领行,领取后回顶部 |

**领取形态(2026-11-07 实机验证)**:一键全领,非逐条——点一个「领取」按钮即发放
该 tab 全部可领档(当时可领 10 档,发放星琼 640 = 多档 60/80 混合、擎羽 400、
信用点 200000 = 10 档 × 20000,单档展示值 80/100/20000 的整数倍)。
同 tab 无需循环点击;**两个 tab 需分别各领一次**。

**行状态三种呈现**:可领 = 金色「领取」按钮;已领取 = 灰色圆圈对勾(无文字);
未达成 = 「进行中」文字。无可领判定 = 列表内无「领取」文本。

## automation 要读信息

- 「领取」按钮是否出现 = 本 tab 有无可领(唯一的可领信号;红点只提示,不作判定)。
- 「按钮-点击空白处关闭」出现 = 获得物品覆盖页在显示(领取成功信号)。
- 行状态(已领取/进行中)仅供展示,领取策略无需读取。
