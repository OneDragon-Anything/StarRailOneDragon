## 击破体系的根本问题(★为什么流萤不行、波提欧/灵砂行)

- 货币战争**没有同谐组** → 超击破倍率稀缺。
- **流萤不行**:装备给的「击破效率提升」反而暴露她**自身超击破倍率 + 基础血刃值极低**,且**大招血刃吃不到击破效率提升形迹** → 战技/大招都没伤害。缺稀有机型 + 5 费前期 D 不到,才是她最大问题之外更根本的毛病。
- **波提欧行**:全身缺点,唯一优点 = **伤害够高**:提供慷慨巨额且稀缺的**基础血刃值 + 击破倍率**(不像流萤被装备稀释)。
- **代价**:波提欧比其他击破 C 更需韧性条/虚韧性叠**优势口袋**,但多击破角色上阵 → 轮到波提欧时场上几乎没韧性条 → 打完整局可能抢不到 1 层优势口袋。

## 波提欧玩法(V3.8)

**核心 = 2 星版 + 巡猎游侠(乱破 + 黄泉 替换 姬子 + 流萤)** → 连锁反应:队友削韧充能的忘归人开局不满大,但**吃到巡猎游侠 200+ 速度征服的波提欧能赶在怪物行动前完成暖机**。

**记忆主适配问题**:波提欧速度太快(近千速),记忆主 buff 对他转瞬即逝 + 跑条跟不上 → 强化普攻(依赖自身行动速度)断档。解法 = **二命忘归人**(超模群体拉条),但要抽。

**阵容底线**:6 人 4 击破 3 巡猎游侠(不带生存位,纯输出)。

### ★前台停云 = 关键最后一位(2.7 上半 UP)

最后一个位置既要补记忆主 + 绝命能量缺口、拉条、产点、补波提欧每回合「绝命对峙」战技点消耗 → **停云**。
- CW 中**后台角色的仪器/光追/行迹不生效** → **停云必须前台**才能"神力解放"成**完美风套 + 翁瓦克发射器**。
- 蓄能翻❓ + 任一回能装 → 停云每回合**平 A 也能开大**。2 星停云带全队跟上近千速波提欧(波提欧动 3 次 → 停云动 3 次开 3 大 → 每循环 **72% 全队拉条 + ~400 能量周转**)→ 补记忆主 + 绝命能量缺口还有余。
- 停云单卡强度 **>> 二命忘归人**。

### 波提欧加强幅度(V3.8)

总伤翻 **≥5 倍**:自身血量 + 巡猎游侠 + 击破面板超击破倍率 + 击破神装大战斗 + 击破特攻全面加强。「最牢的体系获得最夸张加强」。波提欧 **0+1**、全员 2 星即可踹飞遭遇骑士(但适用起来仍偏牢,勉强能玩)。
- 不硬凑 6 击破:**仅在有击破转时**考虑上灵砂凑 6 击破;否则上**绝对热量 + 符玄**当生存位(灵砂高压保人冒汗)。

## 灵砂击破(V4.0 版本答案)

试用灵砂也能踹飞 A830 遭遇骑士。**灵砂 2 星 6 人口就能让整个第二位面甚至 3-1 怪全飞起来** = 目前全 CW **唯一稳定 A830 不炸单的第二位面护航**(「曾经最没用的四费卡翻身」)。

### 构筑基盘:4 击破 + 3 能量(学者)❓ + 3 群攻

- 缇宝需自己有(其余灵砂/忘归人/大丽花/星期日全试用)。有缇宝就能 A830 把把 3S。
- **缇宝装备:风扇 + 翁瓦克 + 速度鞋 + 充能绳**。灵砂对决频率猛 → 缇宝大招频繁触发 555 → 带龟兽❓的星期日 + 灵砂跑起来 → 给灵砂叠火力风暴潮。
- V4.0 灵砂无瑕❓ 4 击破全拐阵容完美,**不需要生存位**。1-29❓升 6 开出灵砂 4 击破 → 连胜不断 → 平推到 boss。

### 开局禁忌 / 节奏

- **负面词条禁忌**:能量逃逸 / 忽快忽慢 / 承受脚步❓ / 时间刺客❓。低配(只有缇宝)避开百万激烈❓ / 战个痛快。**忽快忽慢会乱轴**(试用灵砂+星期日轴配好:2 星灵砂配 1 星星期日、3 星灵砂配 2 星星期日,都是「灵砂-星期日-灵砂」轴)。
- 投资环境:群攻转 / 财富宝钻 / 机械礼盒❓ 最好。**重点刷开局避难词条 + 看 1-4 到 2DOT 连胜没断前能否开出 3 星星期日**。
- 1-8 奖励关卖固定阵容吃利息。卡 50 慢 D 3 星灵砂(6 级 D,大丽花顺手捏);忘归人/阮梅/缇宝不追 3。全程连胜经济 **2-7 左右追出 3 星灵砂**。
- 早期 2 星灵砂 + 1 星星期日;**缇宝 + 大丽花 + 阮梅 + 忘归人需放前台**(大丽花前台吃大招 15% 减防 + 行迹击破特攻提升)。灵砂有第 1 件钻头 → 一路平推到 2-7。

### 升人口

3 星灵砂后猛上:7 级上**记忆主**(换大丽花到后台)→ 8 级上**银枝/霍霍**开 3 能量 → 9 级上**银枝 + 群攻角色**开 3 群攻 = 大成。7 级没记忆主 → 上击破拐(摇光/佩拉/银狼);**有转子优先做群攻转** → 8 级开 3 群攻 + 9 级上银狼(伤害夸张)。

### ★出装(钻头 > 风暴潮)

- 灵砂必须 **1 火力风暴潮 + 钻头**。**第 3 件永远出钻头更好**:第 2 件风暴潮收益 ~50%(略低);**第 2 件钻头收益 ~95%**;第 3 件钻头 ~54% > 风暴潮。
- **例外**:击破效率有上限 —— 忘归人有 **1 命** → 第 3 件钻头击破效率溢出 → 此时特权卡让给火力风暴潮。
- 队友:灵砂毕业后给缇宝回能装(绝对热量 / 血能翻❓ / 电光旅❓ / 能量转❓)+ 全队拉条;星期日什么装备都不用做;忘归人一件**追逐星辰**。**不做升等装**(适当生存压力 → 灵砂更多次扣到 50% 以下 → 更多次被动 → 多放兔子)。

### 局内操作:控兔子轴

判断大招对星期日是否「无效拉条」。例:3 只兔子离行动值有距离但能在星期日前行动 = **有效兔子** → 等兔子动完 → 星期日前按灵砂大招 → 星期日拉条 → **3 连兔子 combo**。

## 弱点 / 上限

- **下限极高**(流程固定、稳定 → 凹完开局连胜没断 ≈ 提前锁定 3S),**上限一般**(后期前台 + 老杨兼容性差)。
- 加金点多:1 命缇宝 / 1 命阮梅 / 1 命大丽花 / 1 命忘归人。
- 波提欧(V3.8)仍偏牢(勉强能玩);记忆主适配靠二命忘归人或前台停云补。
- 装备门槛:需多个钻头散件 + 鞋(第一个投资策略选完确定能凑再定阵容)。
