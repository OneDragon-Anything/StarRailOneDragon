# 版本公告轮播(version_announcement_carousel)

**游戏级版本公告弹窗**(非任何 app 触发):新版本(本期 2026-08-26,主题「贪饕」侵蚀)上线后待机自动弹出,整屏盖在任意画面上(大世界 / 玩法画面均可能被盖),背景为模糊遮罩。内容为两页横版轮播:标题 + 中央演示图 + 底部说明文字 + 左右翻页箭头 + 页码圆点(左点=第 1 页,右点=第 2 页)。不锁光标(`pc_alt=false`)。

## 何时出现 + 状态流转

- **入口**:游戏客户端待机时自动弹出(一次性,关掉后同版本不再弹)。
- **子态(两页)**:
  - **第 1 页**:「贪饕」侵蚀介绍。**无任何出口**——没有关闭钮,唯一前进方式是右箭头翻页(左箭头置灰)。
  - **第 2 页**:贪饕机制说明(侵蚀敌人受致命伤不灭、压制生命上限后可彻底消灭)。底部中央出「关闭」钮,右箭头置灰。
- **出口(实证,编排者 2026-08-27 live 走通)**:第 2 页点「关闭」→ 弹窗消失,露出底下原画面(原画面是什么就回什么,由各自的既有分支接管)。
- **实锤后果**:bot 无此画面分支时,公告弹出后前序分支全不命中 → 兜底空转耗尽(CW 独立 app 首跑 52s 失败实录)。

## 识别特征(稳定锚点)

- **id_mark**:标题「贪饕」侵蚀(pc_rect 830,185-1090,270),两页共享、OCR 高置信(0.99+)。本词为 2026-08-26 版本新内容独有,别屏不出现。
- **子态区分**:「按钮-关闭」(pc_rect 810,855-1110,925,文字「关闭」)仅第 2 页可见——第 1 页命中标题后以该 area 缺席判定为第 1 页。
- 版本号会变:未来版本公告主题不同,标题 id_mark 需随版本补新锚(旧锚保留至版本过期清理)。

## 可交互元素(行为实证,2026-08-27 编排者 live)

| 元素 | 坐标(中心) | 行为 |
|---|---|---|
| 按钮-下一页(右箭头) | (1840,508),仅第 1 页可点 | 翻到第 2 页。纯图形无文字,area 只建 pc_rect 定位区 |
| 按钮-关闭 | (960,889),仅第 2 页 | 关闭弹窗,露出底下原画面。实锤 |
| 左箭头 | (78,508) | 第 1 页置灰;第 2 页可回第 1 页(bot 无需使用) |
| 演示图 / 文字区 | 中央 | 纯展示,点击无反应(未逐个实锤) |

## automation 要读信息

- bot 只需识别本屏(id_mark)并按子态点击(第 1 页翻页 / 第 2 页关闭),无需读页面数值。
- 消费点:`BackToNormalWorldPlus.check_screen`(W301 分支)与 `CwEntryEnter.wait_lobby`(入口流程同款点击链,替代旧 ESC 关公告)。

## 识别快照(analyze_screen 实测,2026-08-27)

- 第 1 页 fixture **精准命中**本屏(is_precise);关键 OCR:「贪饕」侵蚀(877,206,conf 0.995)/ 旧日星神「贪饕」渐趋苏醒…(658,702)/ 该世界一部分敌人受此侵染…(657,731);「按钮-关闭」缺席(sub_state)、右箭头为纯定位区(no_method)。
- 第 2 页:同标题;说明文字变为 被侵蚀的敌人受到致命伤害时不会被消灭…(压制生命上限/彻底消灭);底部「关闭」钮(960,889)。离线 analyze 对该帧触发后端内部错误,识别验证走测试仓 id_mark 全集(真阳性 + 无碰撞)与 op 真帧分支测试。
