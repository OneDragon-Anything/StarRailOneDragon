## 打法主线

- 银枝 V4.4 **离开能量羁绊**,只补偿一点攻击力 → 「轮椅通拐」(杨叔/主角/缇宝/花火/千冶刃 + 符玄)强行抬;自己带风套频繁自拉条,群攻保留。[先验:攻略]
- **必须 3 星银枝**(5-7 级连 roll);适合对群,**对单大降**。[先验:攻略]
- 银枝 = 星间旅人阵营(2费),非贝洛伯格;核心只有群攻(翡翠 3 群攻 + 知更鸟)。[社区:plaza]

## 装备分配

- 银枝:火力风暴潮 + 冷笑话引擎;符玄带绝对热量。[先验:攻略]
- 知更鸟:拉条加攻增伤 + 10% 幸运位。[先验:攻略]

## counter

- 克我:单体长战 boss → 避。[先验:攻略]
