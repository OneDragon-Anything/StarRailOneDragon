# ADR-0201: 策略知识编译层 v0 落地(redesign 11 号处置:规则数据模型+确定性编译管线)

## Status

Accepted(2026-08-17,策略优化会话;①LLM 抽取工具链/⑤人审门/首批 user-tier 口述迁移
为后续批次——11 号为主开发暂存件,本批落其确定性骨架)

## Context

11 号诊断:87 条语义绑定等知识表是三无产品(无出处/无证据/无生命周期);「知识=代码」
让每条经验永久且不可检验;消费端越建越强,供给侧(文本+用户口述)没动。

## Decision Drivers

- 「知识=数据」:可追溯/可触发统计/可被模型推导检验推翻——推翻是降级一条数据而非返工
- 确定性部分(②③④ 归并/冲突/分层)先立,LLM 抽取与 user-tier 通道挂批次

## Considered Options

1. **数据模型+确定性管线先行(选)**:StrategyRule(八域+DSL 白名单校验+五类处方+
   出处/证据/分层/生命周期)+ compile_rules;
2. 直接上 LLM 批处理抽取——工具链性质,先立目标 schema;
3. 不做——知识继续活在代码里不可检验。

## Decision

选 1:`cw_knowledge_compiler.py` v0——

- ``StrategyRule``:受限条件 DSL(**编译期静态校验**:引不到 GameState 字段/注册表
  实体的条件直接拒绝)+ 逐条出处(引文必带)+ 证据(篇数/credibility/反例/版本戳)+
  四层 TrustTier + 生命周期;
- ``compile_rules``:同条件跨篇归并(证据累计)→ **冲突不平均**(同条件反处方各自
  保留进人审队列;上下文标签分叉不算冲突)→ 分层(user 直入最高层/≥3 篇+credibility
  达阈 guide_high/单帖 guide_low 只候选);
- 测试 5 过:DSL 白名单拒绝非法字段算子;跨篇归并升层;a/b 冲突保留待审+c 分叉独立;
  user 顶层;单帖低位。

## Consequences

- ADR-0149 类用户指导的落点从「代码硬编码」变「规则条目」的容器就位(迁移挂批次);
- ①抽取工具链(descriptions.json 648 文本批处理)与 ⑤人审门(100 条 precision ≥90%)
  为后续批次;
- 11 号处置完成(v0,确定性骨架),提案文件删档;测试 +5。
