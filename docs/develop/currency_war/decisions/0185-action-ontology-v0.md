# ADR-0185: 动作本体注册表 v0 落地(redesign 26 号处置:六元语义+完备性审计)

## Status

Accepted(2026-08-17,策略优化会话;消费端投影切流[06 候选/14 备选/22 宏校验]为增量批次)

## Context

26 号诊断:cw_state 的 6 类 Action 是裸种子(只有名与参数,无语义元数据);前置合法性散在
cw_plan 100+ 行分支;13/14/22 各自维护动作假设。「我们能做什么」零声明零审计——候选完备性
从未成为可审计对象。26 号已预验 2 个 guides 实证动作不在任何决策候选集(特选填格 grep 全库
零命中;池操纵数学存在零调用方)。

## Decision Drivers

- J1 判据:静态普查未定义缝 ≥6(预列 7 候选,已预验 2)
- 14 号反事实在缺维候选集上「输在没考虑 X」结构上不可归因——本体是其正确性的前置

## Considered Options

1. **声明式注册表 + 完备性审计(选)**:六元语义(前置/效应/成本/可逆性/随机性/观测验证)
   + 23 式证据状态 + 无主动作登记(盲区一等输出);
2. 直接改写 cw_plan 门族为投影消费——切流批次,先立单源;
3. 维持散落分支——完备性继续不可审计。

## Decision

选 1:`cw_action_ontology.py` v0——

- 8 动作登记:6 类既有 Action + 2 无主动作(特选填格/池操纵,registered=False 显式标盲区);
  成本字段引 23 号注册表名(不内嵌数值);可逆性封闭词汇+note 分离;条件效应(开拓者位置
  形态/银狼升费时相)effect_note 溯源;
- ``legal_actions``:状态 → 合法动作名投影(v0 前置谓词粗判);
- ``completeness_audit``:J1 审计——unregistered(完全盲区)与 unowned(已登记无候选)
  分列,verdict=gaps_found;
- **J1 结果:2 无主动作确认 + 6 已注册动作语义收编**(26 号预验的 2 缝维持,余 5 待核
  候选[银狼费档分离/开箱序/面板微操等]挂 v1 逐项核)。

## Consequences

- 决策栈的结构性盲区首次成为数据(2 无主动作 → 04 可观测性矩阵/27 能力矩阵候选);
- 消费端投影切流(06 候选集换源/14 备选枚举/22 宏校验)为下批——先立语义单源;
- 26 号处置完成(v0),提案文件删档;测试 +3。
