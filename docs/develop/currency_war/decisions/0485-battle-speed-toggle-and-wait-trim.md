# ADR-0485: 实机效率双杠杆——战斗倍速自动开关与固定等待压缩

> **引用勘误(2026-09-04 ADR 存量 review)**:`.debug/` 归档 → 本目录(decisions/)同名 ADR。文内出现处按此对照读取。

> ⚠️ **裁决修订(2026-08-30 用户亲自确认)**:游戏内战斗倍速已是自动/最快档——**杠杆 A 取消**,实现已 revert(取证/建档/实现全部撤除,「下局时长 −10min」目标随之下调,以决策段压缩数字为准;战斗播放 46–57% 属游戏固有节奏,bot 侧无可为)。本 ADR 保留杠杆 B 决策与 A 取证过程记录(过程仅存档,不是现行行为)。

## 背景

W765 实机效率剖析(`.debug/temp/currency_war/w765_efficiency_profile/REPORT.md`)定位 54 分钟局的两大可优化项:战斗播放段占 46–57%(bot 侧零动作)、备战决策占 32–34%。战斗段此前从未被 bot 施加任何加速输入(仓库零倍速模板/按键;备战期「点击空白加速」分支只覆盖结算页)。第七局实机在跑,取证走观察类工具,交互验证单次就地完成。

## 决策

### 杠杆 A:战斗倍速开关(可用,已实现)

- **取证结论:可用。** 货币战争战斗画面右上角存在倍速切换按钮(1920×1080 实拍,几何中心 ≈ (1662, 48);同排还有自动作战开关 ≈ (1770, 48) 与暂停 ≈ (1862, 48))。实机点击后按钮图标状态改变——1x 档模板匹配得分 1.000 → 点击后同位置 0.622(另一场战斗帧 0.666),证明点击生效、档位图形可区分。取证物:`.debug/temp/currency_war/w781_efficiency_impl/`(截图 + 前后图标裁片 + 模板对拍)。
- **实现:模板门控幂等点击。** 新增 screen_info area(货币战争-战斗,此前空壳):`按钮-战斗倍速`(点击位)与 `标识-倍速一倍档`(1x 档图标模板,阈值 0.85;实拍对拍 1x=1.000 / 非 1x=0.62-0.67,余量充足)。battle_loop 新增 1e 分支:战斗窗口内(出战成功后 `_battle_ts` 开窗)模板命中 1x 档才点击,每场战斗一次预算;模板 miss 放行(fail-open,零行为变更)——已 2x 时图形不同不命中,不会误切回。
- **边界与待验证:** ①「2x 是否真的缩短战斗时长」与「倍速设置是否跨战斗/跨启动持久」需下一实机局对比战斗段时长验收(若持久,则每次游戏冷启动只需切一次;模板门控对两种情形都正确)。② 本批取证期间的交互验证在第七局 P2r1 战斗中段就地完成(单次点击),未重启 server。

### 杠杆 B:固定等待压缩(3 项,判读正确性零变更)

| 项 | 改动 | 依据与预估 |
|---|---|---|
| 分支3 结算页链 | sleep 0.5→0.2、success_wait 2→1、过渡 wait 3→1.5×2 | 半开帧防护主防线 = 备战分支双锚 + PREP_SETTLE_S 3s 稳定门 + 0e 系 overlay 分支前置;本链只是首拍缓冲。预估 20–50s/局(10–14 轮 × 2–4s) |
| 分支1f 败局页 | wait 2→1(按钮点击与点空白两处) | 结算各页静态,SETTLEMENT_NEXT 同位连点幂等(与分支 3b wait=1 同语义)。预估 1–6s/局 |
| 节点行探针复用 gate 帧 | `_probe_node_type` 接收 screen 参数;v2 环 EnsureShopClosed 后的 gate 稳定帧透传 | 省一次截图 + 节点行 OCR(gate 稳定帧全图 OCR 按 id(image) 缓存命中;OCR 缓存贯穿纪律同 r344)。预估 6–24s/局(12–16 轮 × 0.5–1.5s) |
| 操作段预估等待核减(收窄令后追加) | `_OP_SETTLE_S` 1.5→1.2 | 买牌特效实测 0.5–1s 上限 + 0.2s 余量;**低估由指纹重置机制兜底**(特效尾帧当基线 → 下一 poll 指纹变化即重置,仅多付一次 poll),正确性由机制保证非由余量保证。预估 15–24s/局(3–5 个 settle 门/轮 × 12–16 轮 × 0.3s) |

合计预估 **55–100s/局**。未落地的更大空间(决策周期整体 30% 压缩,大头 = d2 买后重读 ~9s/次)需要实机 A/B 才能保证遥测字段产出不变,归下一批;本批所有改动不触碰任何遥测写入点/字段/对账族。

## Considered Options(杠杆 A 实现形态)

1. **出战后无条件盲点倍速按钮** —— 拒:若游戏跨战斗记忆 2x 档,盲点会切回 1x(反向减速);不可接受。
2. **模板门控幂等点击(选定)** —— 只在可见证据(1x 档图形)支持时动作;miss = 放行,不新增判读面;坐标进 screen_info 单一源。
3. **只靠既有「点击空白加速」分支** —— 拒:实机日志证实该提示文本只在结算页出现、战斗中段零命中(13:30 段逐 2.3s OCR 全空),战斗中段加速当前完全缺位。

## 后果

- 下一实机局验收:总时长对比基线(局 5 = 54min / 局 6 = 74.9min 同机位,目标 −10min 起);战斗段时长单独对比(倍速效果归因);决策周期 p50/p95 对比(B 杠杆效果)。
- 重启排期:改动已 commit,**下一局边界后重启 MCP server 生效**(对局运行中禁止重启)。
