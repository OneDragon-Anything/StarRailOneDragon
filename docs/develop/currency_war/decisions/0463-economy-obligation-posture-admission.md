# ADR-0463:经济循环总模型——O1 备战空位填补通道 + 存息姿态准入门

- 日期:2026-08-30
- 状态:accepted(落码;设计单一源=`.debug/temp/currency_war/w611_econ_cycle/DESIGN.md`;sim A/B 预注册见该设计 §6.2,复用 `w482_merged_ab` 同 seed 协议)
- 谱系:ADR-0445(储备制 A 面)的通道/姿态层扩展。同族病灶第三次复发(局20 支出冻结 → W586 B2 延续 P2 → 局23 g=100+备战空+`spend_mode='interest'` 死守)触发架构级治本;用户 directive(2026-08-30,最高权威):「无目标阵容,随便买也应该填满备战」。

## Context(为什么)

ADR-0445 落码后仍有两洞,五局实机(⑳+2/局20/21/22/23)无人读取其挂的验证队列即为征兆:

1. **义务接错通道+通道枚举缺项**:义务只接在姿态选择下游的 release 预算,且容量 `C_t` 的可买账以「当帧跨档 ∪ 3合1」为前提——**无目标帧(comp 空)结构性 C_t=0 → 义务恒 0 → DP 解出存息姿态后义务机制永不开工**。局23 是该退化路径现行犯。
2. **A/B 验证队列登记不吃**:ADR-0445 终裁挂「⑳起死时带金/闲置金对六局基线(47-125),劣化即回退」,无消费制度,局20 死攥 62 无人判。

数学根(参数无关):溢余段(g≥息帽 50)边际利息恒 0(息帽截断),买 1★ 退全款+利息不减 → 已实现成本 0、收益≥0(压库+bench 期权)→ **备战填补严格弱占优**——ADR-0445 溢余弱占优证明在一条新通道(唯一不依赖目标的通道)上的应用。

## Decision(逐条)

1. **O1 备战空位填补通道**:`economy_cycle.bench_fill_account` 计入 C_t——溢余帧备战有空位时,店内非跨档非合成件按费用升序取「剩余空槽」件计容量;与跨档件共享同一份槽位账(单次扫描防双计),A-1/A-2 在满槽帧原样(期权泵防线=槽位约束,非废除)。
2. **E1 存息姿态准入门**:`posture_release.release_directive` 末段新增准入分支——g>R* ∧ DP 存息姿态(level_up/D 预算全空)∧ 非应急 → 零预算 `ReleaseDirective(reason='reserve_admission')`:姿态 wrap 为 tag='release'(局23 型标签死守帧消失,`_release_frame_counts` 口径自然覆盖)+ spend_gate 接线;预算=0 时 `authorize_release_refresh` 恒拒=容量不足的合法结转(量经遥测披露)。**两案对比**:选姿态层准入门(「义务(下界)优先于 DP 许可(上界)」合并规则从预算域推广到姿态域;单 choke point 可单帧锁;不进 solve),ADR-0445 拒绝的 DP 罚项案(选项②)留作退化路径——校正覆盖不到的路径仍现姿态-义务脱钩时另批升级。
3. **守息线≡封顶线恒等式**:reserve_cap 息线分量改取 `interest_cap×10`(息帽同源派生;基参数 5×10=50==interest_floor 零漂移)——「守息线 ≤ 封顶线」结构性成立;策略级息帽 override 走 ledger/DP 通道,与 registry 分离时以封顶线为准(分离面挂账)。
4. **义务清单优先序**(语义裁定,落码面=本条 1/2 + 后续 candidates/scoring 限域放行):O1 备战填补 > O2 目标件即买 > O3 排程升级 > O4 刷新消费(W610 交接:W611 定优先序与共享溢余预算不双计,W610 定刷新规则本体);清单空才允许存息。
5. **验证队列消费制度化**(ADR-0445 队列升级,设计 §2.3):编排者局后判读固定第 5 问「死时带金/闲置金对基线在哪」;回退触发=连续 3 局死时带金>125 → 重跑 w482 同协议判据,sim 复现才真回退;本批落码后队列语义升级为义务模型验证队列(出口=备战空位率[局23 锚 100%]/攥金死亡局数/成型轮次/息基非劣/转化率非劣,HP 只作度量仪)。
6. **不新增开关**(ADR-0445 §3.4 同判:行为输入全已标定、弱占优已证、无待就绪假设);被 O1 取代辖域的 A-1 旧锁按锁存在性纪律重推(test_cw_economy_cycle 期权件锁改辖满槽帧,docstring 记出处)。

## Considered Options

- 通道缺口修法:①补 O1 通道+准入门(选)②逐件补丁(局20/23 各修一层,三次同根实证否决)③DP 罚项(退化路径挂账,见 Decision 2)。
- 散件放行辖域:仅「g≥R* ∧ 备战空位≥1」帧(directive 限域取代 [31]);凑息期与满槽帧 [31] 原样。
- 消费优先级归属:W611 定序、W610 定刷新规则本体——两批交接面单列(共享溢余预算不双计,循 ADR-0409 M-A 互斥判例)。
