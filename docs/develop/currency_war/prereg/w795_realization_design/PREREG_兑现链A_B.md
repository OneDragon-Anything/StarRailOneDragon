## 0. 假设(事前写死,跑完对账)

- H1(搜牌侧):锁定后刷新由缺件驱动+金水位辖域门(P5 自洽:预算≈0 帧不驱动)→ 3-4 费缺件集结加速(低费缺件不在主张域)。
- H2(买入侧):罚分常数 3.0 改比例折扣制(κ 占位,sim 标定)+ P29 羁绊感知囤牌优先级(带 hp/R_rest 事前辖域门)→ 线内买入占比上升、档位进度加快。
- H3(合成侧,v2):merge 候选排序加「合成时点价值」显影(标定批之后)→ 第三张购置时点前移、「第 3 张购入→deployed★★」延迟轮数缩短(对照局 6 型:p2r7 买→p3r1 ★★)。
- H4(方向侧):support′ 供给感知+衰减 → 方向死守消除、真摇摆(P16 口径)不增。
- H5(v3 并入,W797 D1,上阵侧):腾席选件按统一弱序价值键取最弱(income 纳入键)→ 席满腾席不再卖高价值件(局 6 p2r7 型反向消失)。
- H6(v3 并入,W797 D2,方向/血线侧):跨位面入口帧并入死亡窗分配器辖域+一次性转化授权 → 入口帧携金死(局 6 P3r1 型)消除;辖域协调=窗口判定归本设计、分配账式复用 ADR-0474、报警源消费 W774⑤。

## 1. 臂与规模

## 3. 机制判(过程面,解释归因用)

- G1 「刷 N 次 0 买」帧占比(局 7 型;**v3 口径勘误**:局 7 p2r1 档案实为 3 刷+5 买,该帧不再作 0 买锚——G1 只计真实 0 买帧,来源=actions 逐笔对账非 shop 波判读面)与「线外/半线外买入笔数」(局 7 p2r1 真实形态,归 M3/G1 联合观测):实验臂应显著下降;
- G2 死时带金 >125 局占比:不升(囤金恶化=失败信号);
- G3 方向翻转次数/摇摆形态占比:不升(P31 滞回生效;升=供给项噪声臂);
- **G6(v2 补,该翻不翻检出——W777 教训的方向侧防线)**:锁线前探索期,「零供给差异帧的方向停滞轮数」上界——对照臂与实验臂同帧位比较,实验臂停滞轮数中位数不得高于对照臂(检 support′ 衰减把所有线拉平后退化为静态偏好序的「软粘性」形态;G3 只防翻转变多,本条防翻转变少);
- G4 bench 满栏帧占比:不持续上升(囤牌挤槽的 H 项现实化警报);
- G5 线内部署率:锁定线成员上场人数/持有数,应上升(部署面);
- **G7(v2 补,息基保住)**:金 <50 帧的息基侵蚀占比([28] 双指标口径的息基维;P13 的 31金/位面息流平台为参照)——实验臂不劣于对照臂(四侧提高 <50 帧花费倾向的过程面检出,补 G2 只看死时金的缺口;与 [28]「息基保住×形态达标」验收口径对齐)。

## 4. Goodhart 警报与失败分流(事前写死)

- **过度锁死警报**:M3→占比≈0 同时 form 达标率/胜率下降 = 罚分修正过度或囤牌挤槽,判「收紧过度」,回调试 κ/γ 量级而非整体回退;
- **供给项退化警报**:G3 升 + 方向翻转在零供给差异帧发生 = ρ 窗口噪声,判 λ/窗口标定失败,非概念否决;
- **分流规则**:主判不过但 M2/M3 单独达标 → 逐侧消融定位(子旗标臂),只回退未证侧;全败 → 概念定谳否决,删码留 ADR(策略开关生命周期第 4 态)。
- 结论兑换:跑完当场三选一(改行为/不合入/调常量),禁悬置。

## 5. 单帧锁清单(事前写死;落码批验收物)

位置 `sr-od-test/test/sr_od/app/currency_war/test_cw_realization_chain.py`,断言写语义不写牌面:

1. (v2 重写)回归锁:merge 完成豁免通道(ADR-0437/0438 现行态)——线内单位已持 2 份 1★、商店再现同卡 → 该买入候选**不被非正分门拒**(豁免越门;钉现行行为防回归)。排序断言(时点显影后排序位随持有份数递增)在 V(2★) 标定批之后另批落锁——**标定前不把未证不等式钉进锁**。
2. (v2 重写)档位未满守卫:已满档贡献成员的第 3 份 → 不获得合成时点排序显影(与侧一缺档加权同一判据单一源);混合星级态(1×2★+2×1★)第 3 份 1★ → 不获购置判据加分(不可达合成)。
3. 锁线帧:线外成员板面增量 ≥ θ_off 的候选 → 评分不被一票罚负(比例折扣制;κ 写入注册表常量,标定值)。
4. 锁线帧 ∧ hp ≥ 报警线(P29 事前辖域门):同等板面增量下,线内缺档成员买入分 > 线外插件买入分。**反向锁**:hp < 报警线帧 → 囤牌优先级不启用(辖域门生效)。
5. 方向层:某体系连续 N 轮零在店 → support′ 严格递减(γ 衰减)。
6. 方向层:窗口内体系成员在店 → support′ 上跳有界(≤ β·1)。
7. 方向层:support′ 差 < 滞回带 δ → 不切换(P16 防振荡)。
8. (v2 重写)金水位辖域门:金 ≤ 利息线+刷新成本帧 → 定向刷新臂不生成(缺件感知不驱动刷新);金充裕帧 ∧ 缺件费用档 3-4 费 → 刷新臂账含 `Δp_tier·P(本刷出缺件)` 项。
9. bench 2★ 线内件、cap 未满 → deploy 候选集必含该件(部署兑现)。
10. (v3 并入,W797 D1)席满帧腾席 → 卖出件为 bench 全件弱序价值键的**最弱**(income 含装备残值入键);局 6 p2r7 型(卖 income 最高件留 1★ 散件)为反例锁。前置=现行选择键输入序核查(挂账 §7-6)。
11. (v3 并入,W797 D2)跨位面入口帧 hp 落死亡带 ∧ 金>授权下限 → 入口帧转化授权生成(窗口判定);授权动作走 ADR-0474 分配器(账式复用,单帧锁只锁「授权发生+分配器接管」两事实,分配正确性归 ADR-0474 既有锁组)。
