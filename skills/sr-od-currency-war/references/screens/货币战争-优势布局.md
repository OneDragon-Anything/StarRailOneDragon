# 货币战争-优势布局（局外强化树，玩家操作简卡）

**识别**：`is_precise` 命中 `货币战争-优势布局`（锚：标题「优势布局」+ 页签「常驻优势」文本；右上角数字 = 幻乐晶球余量）。
**目标**：用幻乐晶球激活天赋节点，效果对之后每局生效。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：大厅左侧菜单「优势布局」→ 进入强化树画面（screen_info 已建路由 area）。
2. **两棵树**：顶部页签切「常驻优势」（跨赛季，激活永久保留）/「赛季优势」（每赛季重置，主战场，40 节点）。
3. **树可拖拽平移**：节点位置随树滚动变化，**不建节点 area、不做点击 op——看图找节点点击**（向左拖 = 看右侧深处）。
4. **激活循环**：点节点 → 底部详情面板显示名称/效果/消耗 → 点右下「布局」按钮 → 按钮变「已布局」即成功（晶球数下降、右上「已布局优势 n/40」+1）。**「节点变粉」不可作已布局判据**——未激活的深层小节点也是粉色；节点状态可靠判据 = 详情按钮三态（可布局「×N 布局」/灰「已布局」/红「请先布局前置优势」）+ 锁定节点挂锁角标。
5. **消耗分档（实测）**：小节点（数值强化）×20；「附加机制解锁」大菱形 ×60~100（风险对冲/主角重选/全盘刷新/钻石闪耀/理赔业务/光环优选 ×60，大胜表彰/保险机制 ×100）。锁定节点按钮红字「请先布局前置优势」且**不显示费用**——须先解锁前置才可见费率，顺藤摸瓜先布前置层。

## 保险机制（用户关心的「1 血免死」）

- **效果**：小队生命值首次将要归零时保留 1 点避免游戏结束（每局一次）+ 受伤-10% + 治疗/护盾+10%。此节点未激活时**没有**免死（HP 归零即终局，历史实测多局吻合）；**2026-11-19 起本机已激活**——免死在激活态下的实际触发待 HP 归零窗实测（标记见 gameplay-basics §1），实测前血量规划仍按「归零即终局」。
- **位置**：赛季树**最右视口左缘**（第三屏位置；树实宽约 2.4 屏——早期「约三屏深处且没找到」即因把它当主链延长线找；带装饰框大菱形）。
- **前置结构（2026-11-19 激活实录，单链假设作废）**：主链（已走通）起点 → 生命强化 → 暴击伤害强化 → 主角重选 → 伤害提高 → 大胜表彰（三链汇合件：上链击破强化→风险对冲、下链伤害减免→全盘刷新 也需激活）。**保险机制不在主链延长线上**——**2 个直接前置**（连线箭头尖指向依赖节点）：①伤害减免（花瓣形 ×20 ← 理赔业务[HP 首次<50 得 5 金币；连胜 0 仍有 1 金币连胜奖励，×60]）/②光环优选（选主角光环时 1 金币价格刷新次数额外增加 2 次，×60 ← 心形生命 ×20）。**深层暴伤（×20）与深层减免（×20）是保险下游**——激活保险后才解锁，别当前置布。左下支线防御强化（锁定 ← 暴伤 ×20 + 至少 1 个未探明锁定前置）；钻石闪耀（×60；在补给阶段的可选项中有概率出现钻石装备）= 前置链中继。
- **本机状态**：**已激活**（2026-11-19：305 晶球起步，布完前置链+本体+下游共 280，余 25；已布局 **27/40**）。

## 坑

- 大菱形消耗是大头（60~100），预算紧张时先算链路再动手，别把晶球散在支线小节点上。
- **拖拽惯性坑（实测）**：常规拖拽会甩过头（一次常规拖拽把视图从最右端甩回起点 ~2700px）——每拖后必用固定地标核对视图位置，别信「拖一下就该到」。
- 点「布局」后等约 1 秒再截屏（有激活动画）。
- 全量节点清单与建档细节见 `docs/game/screens/currency_war_advantage_layout.md`。
