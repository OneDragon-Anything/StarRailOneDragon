# 战斗基础

回合制战斗的公共规则，跨命途/跨角色成立。理解配队与操作轴的前提。

## 行动条与速度

- 每个单位（我方角色、敌方、召唤物、特殊单位）有速度值；行动条按速度决定行动顺序，速度越高单位时间行动越多。
- **行动提前/延迟**：百分比拉条（如「行动提前100%」）改变当前行动进度，是配速核心手段。
- 部分体系的资源或增益与速度挂钩（转模行迹、套装速度阈值、行动条特殊单位速度公式）——速度不只是「快」，还是体系燃料。

## 回合与轮次

- 「回合」以单个单位计（角色自己的 buff 持续回合按该角色行动次数消耗）；「轮次/波次」以全队计。
- 忘却之庭等玩法以**轮次数**计分（越少轮次星数越高）——配队的爆发密度直接决定轮次表现。

## 技能点（SP）

- 队伍共享池（上限 5）：普攻 +1，战技 -1（个别角色例外）。
- 技能点预算是配队硬约束：多战技角色互斥（抢点）；不耗点/产点角色（同谐产点、特殊机制免点）提升全队上限。
- 个别角色的战技代价不走技能点而走其他资源（生命值等）——读角色档的「机制要点」。

## 弱点、韧性与击破

- 敌人有弱点属性列表（血条旁图标）与韧性条（白条）。
- 用弱点属性攻击削韧；韧性归零 = **弱点击破**（打断行动 + 击破伤害/效果），之后韧性恢复。
- 「无视弱点属性削韧」类效果允许非弱点属性削韧；「击破特攻」提高击破伤害与削韧值。
- 配队第一问永远是「敌人弱点是什么」——弱点错配的队伍伤害再高也削不动韧性。

## 伤害类型

- 按来源：普攻/战技/终结技/追加攻击/持续伤害（DoT）。
- 按体系：常规伤害（吃面板攻击/生命/防御 + 增伤乘区）与**特殊伤害体系**（欢愉伤害等独立乘区，见 path-joy.md）——特殊体系的传统增益无效，这是配队绑定的重要根因。
- 属性（物理/火/冰/雷/风/量子/虚数）决定是否吃弱点削韧与属性增伤。

## 秘技

进战斗前在大世界施放，效果各异（先手攻击/垫 buff/回资源）。开局秘技顺序是操作轴的一部分——多数体系的爆发窗口从秘技铺垫开始。

## 效果命中与效果抵抗

- 负面效果施加按「基础概率 × (1+施放者效果命中) × (1-受击者效果抵抗)」结算（确定性效果无此判定，文本无「基础概率」字样即确定命中）。
- 挂负面频率 = 负面体系的充能速度 → 负面系角色的效果命中是功能词条（详见 damage-and-affix.md 转模与 ult-resources.md 资源判定）。
