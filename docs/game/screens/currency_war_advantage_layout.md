# 货币战争-优势布局

货币战争的**局外强化树**(元系统):对局外用「幻乐晶球」激活天赋节点,效果在之后的每局对局中生效。用户口语中的「强化/激活系统」「1 血免死」即本系统(免死节点名 = **保险机制**)。分两区:**赛季优势**(每赛季重置)与**常驻优势**(完整保留)——与官方命名一致。

## 1. 何时出现 + 状态流转

- **入口**:大厅左侧菜单「优势布局」(screen_info 已建 `按钮-优势布局` area,goto 本屏)。
- **出口**:右上「返回」箭头 → 大厅(`按钮-返回` template area,goto 已建)。
- 画面内两页签切换:「常驻优势」/「赛季优势」,树各自独立、坐标同构。

## 2. 系统结构(实测)

- **两棵树**:
  - **常驻优势**:跨赛季永久,本号已全布局(节点全亮、详情按钮「已布局」)。数值强化 + 5 个机制节点。
  - **赛季优势**:本赛季(入画奇航)专属,每赛季重置;「已布局优势 1/40」计数器只在本页签显示,40 = 赛季树节点总数,起点菱形默认算 1。
- **树可横向拖拽滚动**(赛季树实测约 **2.4 屏宽**——两次拖拽到右端复核,早期「约 4 屏宽」估计作废,此前在深层找不到保险机制即此因;约 40 节点;拖拽方向:向左拖 = 看右侧深处)。
- **激活消耗（实测分档）**:小节点(数值强化)×20;「附加机制解锁」大菱形 ×60(风险对冲/主角重选/全盘刷新/钻石闪耀/理赔业务/光环优选)与 ×100(大胜表彰/保险机制);画面按钮字面为「×N 布局」,右上角计数即幻乐晶球余量(来源含晋升等级奖励;**晶球余额仅本画面右上角 (1650,45)-(1810,85) 显示,大厅无余额显示位**——大厅右上角数字 = 晋升等级,别归错主)。锁定节点按钮显示红字「请先布局前置优势」——需先激活前置链上的节点;**锁定态不显示费用**,须先解锁前置才可见费率。

## 3. 激活路径链(goto_list 语义)与操作口径

大厅 →(点左侧菜单「优势布局」)→ 货币战争-优势布局(默认赛季优势页签)→ 点节点看详情 → 点右下「布局」按钮激活。切树点顶部页签。

**操作口径(看图,不建节点 area/不做点击 op)**:树可拖拽平移,节点坐标随滚动变——看图找节点点击;点「布局」后等约 1 秒(激活动画)再截图;成功判据 = 详情按钮变「已布局」+ 晶球数下降 + 计数 +1(**「节点变粉」不可作已布局判据**——未激活的深层小节点也是粉色;节点状态可靠判据 = 详情按钮三态 + 锁定节点挂锁角标)。**拖拽惯性坑(实测)**:常规拖拽会甩过头(一次常规拖拽把视图从最右端甩回起点 ~2700px)——每拖后必用固定地标核对视图位置。详见 skill 卡 `references/screens/货币战争-优势布局.md`。

**前置结构(主链 = 2026-11-18 首布实录;保险机制分支 = 2026-11-19 激活实录)**:主链(已走通):起点 → 生命强化 → (暴击伤害强化/伤害减免) → (击破强化/效果抵抗强化 解锁两侧汇合件) → 主角重选 → 伤害提高 → 三链汇合件(风险对冲+全盘刷新) → 大胜表彰。**保险机制不在主链延长线上(单链假设作废)**——它有 **2 个直接前置**(连线箭头尖指向依赖节点):①伤害减免(花瓣形,受伤-5%,×20 ← 理赔业务[附加机制:小队HP首次<50得5金币;连胜0仍有1金币连胜奖励,×60])/②光环优选(附加机制:选主角光环时,1金币价格刷新次数额外增加2次,×60 ← 生命强化[心形 ×20])——四节点均已于 2026-11-19 布局。**深层暴伤(炸弹形,暴伤+12%,×20)与深层减免(×20)为保险下游**:保险激活后才解锁,已随后布局。左下支线防御强化(锁定 ← 暴伤 ×20 可布局 + 至少 1 个未探明锁定前置);**钻石闪耀(大菱形 ×60,已布局;在补给阶段的可选项中有概率出现钻石装备)= 保险机制前置链中继**。

## 5. 「1 血免死」= 保险机制(已激活)

- 用户记忆的「激活后 1 血免死一次」= 赛季优势树「**保险机制**」:小队生命值**首次**将归零时保留 1 点,避免游戏结束(每局至多触发一次)。
- **本机已激活(2026-11-19 实布)**:305 晶球起步,按序理赔业务 ×60 → 心形生命 ×20 → 光环优选 ×60 → 保险机制 ×100 → 深层暴伤 ×20 → 深层减免 ×20(共 280),余 25,计数 21/40 → **27/40**。激活效果含免死与受伤-10%/治疗护盾+10%;免死实际触发效果待对局中 HP 归零窗实测(gameplay-basics §1 等五处「未复现」标记已改「保险激活态下窗实测回填」,实测前血量规划仍按「归零即终局」)。
- **拓扑(实机修正)**:保险 **2 个直接前置** = 伤害减免(花瓣形 ← 理赔业务)+ 光环优选(← 心形生命),见 §3;深层暴伤/深层减免为保险下游(激活后才解锁)。
- 第 4 局 3-7 BOSS 战败 HP 40 结束 = 位面 3 收束(已裁定),与保险机制无关(当时该节点未激活)。
- 详见 BOSS 简报 doc 的败因分析(`currency_war_boss_briefing.md`)。
