# DD-007:P2 回退先验端点纪律对称化——未揭晓位面回退统一取结构上端(9)

- Status: accepted(编排者裁量,依据=IMPL_DESIGN §6.1 R46-1/R49-6 与登记表 R60-2 逐轮重推;待用户追认)
- 日期: 2026-09-02
- 取代: commit a642d28c 的「P2 回退=语料定谳值 7(16 局语料 boss@r7)」口径(该口径的语料统计基座与完整局观测基座混淆,见「语料口径调和」)

## 决策

`PLANE_FALLBACK_PRIORS` 由 `(9, 7, 9)` 改为 `(9, 9, 9)`:未揭晓位面的回退长度统一取**结构上端**(位面长度上限,`NODES_PER_PLANE=9`),不再对 P2 使用语料众数 7。

## Why(单侧误差支配性论证)

回退先验只被 horizon 消费(未揭晓位面的期望轮数估计)。设真值 ℓ∈[1,9] 不可判(该位面未打完),回退值 f 与真值的偏差方向决定失效模式:

- **f < ℓ(低回退,如 7 vs 真值 8/9)**:horizon 低估 → Δ息流̂/Φ̂ 下偏 → 不可逆卖面门槛被压低 → **多换线向 fail-open**(不可逆面,违反 R44-2/R45-1 已立的「不可逆面禁下偏填充」纪律);
- **f > ℓ(高回退,统一取 9)**:horizon 高估 → 门槛上偏 → 换线/卖出变保守 → 代价=少换线的机 {-会错} 会成本,但方向是 fail-closed,且可量化(P1 期双未揭晓面高估 ≤(9−ℓ₂)+(9−ℓ₃)≤16 轮,登记表 R51-4)。

单侧误差安全性:fail-open 不可逆 vs fail-closed 可定价残余——取后者。

## 语料口径调和(消除 a642d28c 与 R46-1 的「矛盾」)

两处陈述不矛盾,是**观测基不同**:

- 「16 局语料 boss@r7」:16 局在 P2 第 7 轮击杀 boss 后进入 P3——这些局的 P2 **没有完整观测**(第 7 轮被打断),只证明「P2 ≥7 轮」;
- 「6 完整局=7×5+6×1」:仅 6 局把 P2 打完进入 P3(完整观测),其中 5 局 7 轮、1 局 6 轮——众数 7 只在**完整局子样**(n=6)内成立,且 1/6 局为 6;

由此:①「P2 真值=7 定谳」的完整局子样支持度仅 5/6,非「16 局实证」;②被 16 局截断观测支持的只有下界 ℓ≥7,这恰恰排除不了 ℓ∈{8,9}——用 7 做回退**没有任何观测**排除低估;③结构上端 9 是唯一被「局外事实」(位面槽位上限)支持的不依赖子样的取值。

## 与 R49-6/R60-2 的衔接

- 上端选择单一公式=结构上端(R49-6 定谳;「众数+余量 2」降为观测记录);
- 减项侧 Δstreak_down 的 s_min_round=min(2,m) 按 R60-2 逐轮注册表重推(败轮金 2/4/4,sim 不乘 win_reward_mult),与本决策互不覆盖(本决策管回退上端,R60-2 管下界修正项)。

## Consequences

- 未揭晓 P2 的 horizon +2 轮(保守代价,P1 期 ≈36% 局长;残余账 R51-4 已定价);
- 行为面:换线/卖出判据更保守(少换线向),与 R38-2/R44-2 保守方向复合;
- 旧口径「语料定谳值 7」正式退役:一切持久引用以本 ADR 为准;
- 过渡态:本 ADR 落地于 redesign 迭代期;落码批将把本 rationale 迁入 `docs/develop/sr_od/application/currency_war/decisions/` 正式编号体系。

## SUPERSEDED(用户裁定 2026-09-02:回退先验概念整体废弃)

本 ADR 全文作废(含 9 与 7 两种主张)。用户机制知识:
1. 投资策略环境不变时,三位面节点数量与类型序列**固定**(可实录);
2. 默认环境(无投资策略影响)的节点类型,**实机采集一次即为客观默认值**——不需要也不应该发明任何回退先验;
3. 运行时自观测通道存在:备战后位面详情画面可见全 3 位面节点类型。

替代设计:节点信息获取优先级 = 在线读位面详情画面 → 按投资策略环境查实录表 → 默认环境实录序列;`PLANE_FALLBACK_PRIORS` 概念退役(代码替换随落码批,测试锁 test_cw_plane_p2 跟改)。实证记录:`docs/game/currency_war/research/plane_schedule_observed.md`(节点序列记录批产出)。
