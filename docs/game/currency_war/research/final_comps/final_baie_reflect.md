## 白厄本体(技能/羁绊,官方文本)

```
羁绊【救世主】:白厄和卡厄斯兰那获得【所有前台角色已激活的
非独立羁绊效果】(不影响人数计数)——白厄是「羁绊聚合器」:
前台有 4列车+4护盾+3巡海,他全吃!
站位 Front,3费
```
**类的本质**:白厄不靠自己的羁绊——**他复制全前台的羁绊效果**,
所以阵容设计=给前排铺满高质量羁绊,白厄一人全享。

## 核心装备链(38 篇高度一致的公式)

```
白厄×3(CARRY): 以牙还牙甲×3          ← 反甲三连(24/38 篇的标准式)
  以牙还牙甲效果:开战全体前台获 300%防御护盾;受击后对攻击者
  造成 250%【受击前护盾量】的物理反伤——盾越厚反越痛
三月七(副C/装备载体): 反重力皮靴×2+光能盾牌/胜利之旗/很硬的甲
  (给白厄叠盾的「盾量供给站」;姬子领航员复制三月七首件装备)
千冶·刃: 掩体生成枪×3   ← 每回合 30%生命前台群盾(持续供盾引擎)
姬子(后台!): 必须后排——「姬子开领域后白厄无法变身」(#16/#17,
  境界冲突)——领航员绑三月七,复制其装备给白厄增益
```
**装备体系的闭环**:以牙还牙甲(爆发护盾)+掩体生成枪(持续护盾)+
光能盾牌(斩杀线护盾)三源供盾 → 盾量=反伤倍率基数 → 白厄反弹一切。
