## 7. API 裁定落定(2026-08-17 晚)

官方 API config 全量核查:`fight_augment_list`/`portal_list` 条目仅
`id/name/desc/icon/quality`,**无结构化数值字段**。据此:

| 原待核项 | 裁定 | 依据 |
|---|---|---|
| 狸财经狸息机制 | ✅ **可建模**(文本全明) | API 全文:30 本金/每回合息+2 金/**金<20 取 10**/**P3 首领节点取全部存款**——四个数值全在 desc 里,此前是我调研没读全文,非数据缺失 |
| 品质→难度通胀公式 | ❌ 放弃建模 | API 无记载(仅白银时代文本侧面证实机制存在);C 类品质环境只建「品质分布变化」(文本明说的部分),通胀量级不建 |
| 市场活力/人才下沉/概念股 ×15 概率数值 | ❌ 放弃 odds 建模 | 文本只说「有概率/概率提高」,无数值;保留 pick_value 选卡分(选这张卡本身划算与否与精确概率可解耦) |
| 偶像经济礼盒内容 | ❌ 放弃(「大量奖励」无数值) | 文本无数字 |
| 员工投影仪角色分布 | ❌ 放弃资产估值 | 文本无分布 |
| 不等价交换 hp 上限截断细节 | ❌ 按字面建模(swap),截断行为保守处理(交换后 clip 到 [HP_MIN, HP_MAX]) | 文本只有「交换」 |

**API 顺带发现(非投资域,记录备查)**:`equipment_list`(101 条)带结构化
`compose_list` 合成图与 `priority`/`category`——7 号装备规划的合成数据有比
`cw_synthesis` 手维护更权威的源;`label_list` 即 plaza 节奏五档(已消费);
`trait_info_list`(33 条)`layers` 字段为空,羁绊阈值仍以 `cw_factions` 为准。
