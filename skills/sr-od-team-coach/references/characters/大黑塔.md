## 一、命途属性与技能说明

**命途**：智识（C1 计数：≥2智识全队暴伤+80%）；**属性**：冰

| 技能 | 说明 |
|---|---|
| 普攻 | 单体冰伤 |
| 战技「格局打开」 | 扩散35%×3段 + 挂1层【解读】 |
| 强化战技「我有一个大胆的想法」 | 消耗1【灵感】：弹射40%×多次+全体20% |
| 终结技 | 消耗能量；**解读层数重排**（高层数优先转移到精英）+ AoE 100% + 攻击+40%（3回合）+ 立即行动 +1灵感 |
| 天赋 | 敌方进战前+1层【解读】；**每波次开始随机+25层（优先精英）**；强化战技倍率每层对主目标4%/其他2%（2智识翻倍）；上限42层；使用强化战技消耗主目标层数；敌人死亡层数转移 |
| 秘技 | —（以官方文本为准） |
| 额外能力 | **C1：≥2智识→全队暴伤+80%**+攻击后续层 |

**资源与循环**：标准能量→充能有效。灵感（上限4）由终结技/受击获取（以文本为准）。
