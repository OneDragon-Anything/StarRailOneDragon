## 结论

**非阻断收敛**。10 项发现（中高 1 / 中 3 / 中低 1 / 低中 1 / 低 2 / 信息 3），零阻断项。

设计方向（特例退役 + 传参修复 + 统一装配）与裁定五一致，攻击不触及方向本身；
发现集中在三类：①「统一装配路径 = 一条代码路径」的提取切面与声明不匹配
（SU-1，核心卖点空心化风险）；②「特例退役不丢价值」论证过强——档 2 承载
有明确适用域边界与席满行为翻转面，设计未申报（SU-2）；③传参修复的行为
变化面大于 §2「只动优先级消费面」申报（SU-3）。全部为设计内可修，无一需
新裁定（行为翻转面 SU-2b 已被裁定五的「候选 = 假设性入场者」定性覆盖，
缺的是申报不是授权）。

动态实证（python -B 内联，零落盘）：

1. **帧A（凭据⑦跨域凑星帧）现行绿机制**：`reason='第2级角色:虚拟全局评估幸存 飞霄 键首档=1'`，ranked = [(飞霄, **档 1**), (希儿, 档 7)]——飞霄胜出靠档 1 按名命中（特例本体实证）。
2. **帧B（单张阴性对照）机制**：ranked = [(希儿, 档 7), (飞霄, 档 8)]——希儿量子同频羁绊档 7 压飞霄档 8，**与测试注释声称的「装备比」机制无关**（角色级已分胜负）。
3. **传参断线实证**：同帧不传 virtual → target = {'飞霄': ('front', 1)}（真实容器定型，1★）；传 virtual → {'飞霄': ('front', **2**)}（升星连锁合成 2★ 被感知）。
4. **档 2 承载实证（T1）**：line_candidates=('列车同行',)，候选花火（1 张在手）vs 候选姬子·启行（0 张在手）→ ranked = [(花火, 档 2), (姬子, 档 2)]，花火先——档 2 内 -total_star 聚合（含置入新牌）承载凑星排序成立。
5. **席满同名第 2 张（T2）**：席满 9 单位帧候选花火幸存（键首档 2）——池中存在档 8 垫件（丹恒·饮月非线内成员）时候选非末位；结合 sell_refund 实读（1★ 全额退 → refund_loss(1★)=0 恒）推得：仅当全池无更低优先级件时，候选与同名在手件全子键并列、in_hand 旗标使候选恒为末位（推演 + 数值域支撑）。

## 发现清单

### SU-1 ｜ 中高 ｜ 非阻断 ｜ 统一装配的提取切面与「单一实现」声明不匹配——真正的大段拷贝不在提取面

- 位置：design.md §1.2（改动点 2）对照 supply.py:200-229 vs shop.py:1192-1239。
- 实读两域装配三段：
  - **v_copies 构造**：supply.py:200-204 与 shop.py:1192-1196 逐行同构拷贝（仅变量名差）；
  - **ctx 装配**：supply.py:205-207 vs shop.py:1203-1207——唯一实质差异 = 减名（`deployed_names=target`〔dict，且冒 frozenset[str] 注解，见 SU-8〕vs `frozenset(target_plus) - {_name}`）；
  - **units 池构造**：supply.py:214-229 与 shop.py:1212-1238 同构拷贝但**语义分叉**——shop 池含场上部署外件（:1229-1238 扫 sim.field）并排除 in-target 档 1 件（:1224/:1234）；supply 池只扫 sim.bench（:215）、不排除 in-target、不含 field 件。
- 攻击：设计改动点 2 的提取对象 = 「评估装配 deployed_names 减候选名」——**实质是提取一行表达式 `frozenset(target) - {name}`**，逻辑收敛收益趋零、反加一层间接；而两域真正的大段重复（v_copies ~6 行 × 2、HeldUnit 池构造 ~15 行 × 2）不在提取面。按此切面，验收 §3「单一实现结构性检查」无法成立——「一条代码路径，非两份拷贝」名不副实，两份拷贝的漂移风险（本次实证的池构成差异正是拷贝漂移的现役证据）原样保留。反向扩大提取面到池构造，则两域池语义必须参数化（victim 试探语境要部署外全集 vs 末位判定语境只扫 bench）——分叉参数本身即承认语义分叉，「统一」退化为词藻。
- 严重度：中高（设计核心卖点「沿用统一优先级 = 一条代码路径」的落地形态空心化）；**非阻断**。
- 分级建议：**设计内可修**——三选一并写实：①缩小声明（「统一 = 减名语义统一 + 排序键单一源」，删「单一实现结构性检查」验收）；②提取面扩到 v_copies + 池构造、显式申报池构成分叉参数及其语义（须答 SU-3 的比较域问题）；③维持窄提取但在设计里如实声明「拷贝面残留 + 漂移防线 = 行为断言测试」。

### SU-2 ｜ 中 ｜ 非阻断 ｜ 「档 2 承载凑星价值、特例退役不丢价值」论证过强——档 8 子域无承载 + 席满攒素材行为翻转未申报

- 位置：design.md §0.2 对照 priority.py:436-462（八档判定）、:418（in_hand）、凭据⑦原文（landing.md:14）。
- **承载成立部分（实证 T1）**：候选 = 成员 ∧ need≥2 ∧ 未达标 → 档 2（:436-439），档内 -total_star 聚合读 v_copies（含置入新牌）→ 凑星候选（聚合大）键小排先；need=1 成员落档 5、万金油档 6、羁绊档 7——三档同样携带 -total_star（:449-457），承载等价。
- **缺口 a（档 8 子域丢承载，未申报）**：非成员 ∧ 非万金油 ∧ 非羁绊的同名候选（以及已到 2★ 掉出档 6/7 的万金油/羁绊件，priority.py:410-415 落档边界自证）落**档 8**——档 8 键（:460-462）为 (8, prob, -cost, -unit_star, refund_loss, in_hand, tail)，**无聚合星级分量** → 凑星优先在档 8 帧面完全无承载。凭据⑦原文语义域（「同名 1★ 恰 2 张时该角色候选先于不凑星的终局成员候选」）不限定候选是成员——特例退役在档 8 子域丢凭据⑦语义，设计「特例退役不丢价值」未申报该子域。（辩方：档 8 杂件凑星价值本身低；但「丢」要说，不能说「不丢」。）
- **缺口 b（席满攒素材行为翻转，未申报）**：席满 + 全池好牌（无档 8 件）帧，同名第 2 张候选与同名在手 1★ 件在档 2 内全子键并列（聚合同源、-unit_star 同为 -1、refund_loss 按 sell_refund 实读 1★ = cost 全额退 → 恒 0）→ in_hand 旗标（手持 0 / 将获取 1，:418）使候选键恒大 → 末位 = 候选 → 淘汰。旧档 1 按名命中使该帧幸存买入；新语义不买——「攒第 2 张素材」的期权价值丢失（注意：手里 2 张 + 候选 = 合成闭环走净释放直幸存，supply.py:186-188 + :239，不受影响；丢的仅是 2/3 素材态）。辩方：席满买入的角色入溢出席、记账零写（30_supply_screen.md:67-68 失真申报）→ 不买反而避开记账黑洞——行为方向可辩护，但这是**行为翻转**，设计应申报为「接受的变化」而非断言「不丢价值」。
- 严重度：中（论证失实面，非行为缺陷——两造方向均可辩护）；**非阻断**。
- 分级建议：**设计内可修**——§0.2 论证改写为分域陈述：「非席满帧经位移判空直幸存承载；席满帧经档 2/5/6/7 聚合承载；档 8 子域与席满全好牌帧行为翻转，申报为裁定五（候选 = 假设性入场者）的接受变化」。

### SU-3 ｜ 中 ｜ 非阻断 ｜ 传参修复的行为变化面大于 §2「只动优先级消费面」——虚拟定型激活排序池比较域缺口

- 位置：design.md §2 对照 supply.py:215（池只扫 sim.bench）、shop.py:1229-1238（池含 field 件）、deploy_search.py:890-1043 / :1064-1140。
- 实证：select_deployment 未传 virtual → build_deploy_panel(session, gs, frame) **函数体不消费 frame 参数**（:890-1043 全从 gs 现读：:949 deployed_rows_of(gs)、:1004 bench_entries_of(gs)）→ 现状 target = 真实容器定型；传 virtual → 虚拟定型感知升星连锁（实证 1★→2★）。「未传 virtual 参 → 虚拟局面被静默忽略」断言成立 ✓（同时证实 v_frame 是双重死参：select_deployment 第一参与 assemble_prep_context 第三参（mandate.py:1248-1252 函数体不消费 frame）均被忽略）。
- 攻击：传参修复使 target 从「真实容器定型」变「虚拟局面定型」，变化面三处：
  1. 档 1 名集变化（设计已知，改动点 3/4 承载）；
  2. **虚拟定型可换人 → sim.field 中不在 target 的撤下件真实存在**。这些件是让位池成员（shop 侧入池，shop.py:1229-1238），supply 排序池不含它们（supply.py:215 只扫 bench）→ 末位判定的比较域比 shop 缺 field 撤下件 → 候选更易成末位（淘汰偏严）。现状该缺口近似休眠（真实容器定型 ≈ 当前部署，撤下件罕见）；**传参修复将其激活**。模块头「与商店牌同一逻辑」声明（supply.py:8-11）在池构成面本就不成立，修复后差异面放大，设计未申报。
  3. reason 串「键首档」数值变化（帧A 1→卡面档）——属申报面内的测试翻转连带。
- 严重度：中；**非阻断**。
- 分级建议：**设计内可修**——§2 边界补行为变化申报（虚拟定型激活池比较域差异）；池构成是否统一进 SU-1 切面一并裁（若 supply 维持 bench-only 池，须给出补给语境的独立语义申报——补给买入入溢出席、无 victim 试探，池目的只是候选价值定位，可辩，但要写成文字）。

### SU-5 ｜ 低中 ｜ 非阻断 ｜ 测试翻转的检定力结构：翻转后阳/阴对照塌缩 + 帧B 注释失实 + 翻转锁形态间接

- 位置：test_supply.py:355-374（test_merge_star_tiebreak_spans_bench_and_rows）。
- 实证拆解：
  - 帧A 绿机制 = 飞霄候选命中档 1（reason 键首档=1，实证 1）；翻转后（减名）飞霄落档 8（实证 2 帧B 同构）vs 希儿档 7 → 帧A 断言翻为 idx=1——**与帧B 断言同值，阳/阴对照塌缩**为两条同构断言（按测试纪律「两条测同一件事 = 冗余」应合并或差异化改写）。
  - 帧B docstring「阴性对照:同名仅 1 张(count 1 ≠ 2)→ 不凑星 → 装备比 → 希儿胜」**失实**：实证希儿以档 7 羁绊（量子同频，cw_chars.py:148）压飞霄档 8 在角色级分出胜负，根本未到装备比。翻转改写时应一并修正注释，否则新读者按注释理解翻转原因会得错误因果。
  - 翻转行为锁的正确形态 = 直接断言「键首档 ≠ 1」（reason 或 ranked 键首分量）或「同名候选不再因部署同名命中档 1」；胜出 idx 断言依赖对位候选的档位（希儿恰为羁绊件才压得住），对位换名即漂移——间接证据。
  - 「档 2 承载用例改写」构造可行（实证 T1：state_of(gs).line_candidates 接线先例 :293/:329 + need≥2 成员 + 非席满直幸存路径），但**现行测试的飞霄/希儿凑不出成员帧**（飞霄狼狩/追击，希儿贝洛伯格/量子同频，不同线；cw_chars.py:113/:148）——改写须换成员名并接线活跃线，设计「保留/改写」未提示该构帧前提。
  - 设计改动点 4「新增反例：候选被虚拟定型收编仍可淘汰」依赖传参修复先落地（现状收编不可达，实证 3）且构帧须用**杂件候选**——panel_from_virtual 的 bench 侧窗口谓词（deploy_search.py:1120）会挡终局库成员候选（entry.py:347-367 未开窗口即 blocked），杂件不挡才可被收编（shop 反例娜塔莎同款）。前置断言形态照 XT-4（`assert 候选名 in target` 响亮红）✓ 可行。
