## 核心逻辑:最终目标 = 100 血通关

快速上分的基础是**维持更高血量**,而不是凹多高星级的五费。经济学的本质 = 怎么攒得多、花得值 = **开源 + 节流**。

## 开源(赚钱):连胜 >> 利息

- 高段位前期小怪就很有难度,往往**做不到「快速存钱」的同时「一直打得过小怪」** → 利息和血量只能二选一。
- 此时 **血量 + 连胜的重要性 >> 利息**。理由:
  1. 连胜奖励给得非常多(满息 + 满连胜一关 = **13 金币**收益,滚雪球极快);
  2. 利息没了两三把就能攒回来;**连胜断了需要更漫长的时间 + 更高难度才能打回来**;
  3. **血量恢复非常缓慢**,不能当格挡条玩 —— 多提前期强度、少卖血。
- **操作**:局内感受到压力时(如上一关走到底才杀完怪)→ 打完不要犹豫,**直接破利息拉阵容质量保连胜**;但凡察觉一点断连胜风险,就去 D 牌或升人口拉质量。
- **★永远不打右边遭遇**(第三位面):除非 100% 确定能打 300 亿+ 输出且无生存压力。右边遭遇**无任何收益、不会让结果更好,反而大幅增加翻车 + 扫身心(烧心?)风险**。能打过左边遭遇 + 吃完奖励关 + boss 关前把钱花完 = 能打赢 boss(本模式 boss 没比遭遇其一其二难多少)。

## 节流(花钱):升本 vs D 牌

- **升人口**:在该等级所需核心牌都找齐、能追购了再升。升法 = 钱卡够 50 利息的同时**一次性升到下一级**;钱不够就攒够再升。**最忌讳**:攒着准备升本的钱中途跑去大量 D 牌(「把准备结婚买房的钱拿去赌了」)。
- **D 牌等级表**:**5/6/7/8/9 级分别找 1/2/3/4/5 费角色**(与 `cw_shop_odds.REFRESH_PROB` 一致)。

## ★卡牌池(牌库)—— 精确副本数(修正 economy_research 的 🔴 缺口)

UP 用实机素材论证牌库有限、可操纵:

| 费用 | 可合最高星 | 商店每种副本数 |
|---|---|---|
| **1 / 2 费** | 四星 | **27 张 / 种** |
| **3 / 4 / 5 费** | 三星 | **9 张 / 种** |

> **vs [research/economy §1](../research/economy.md)**:早前只确认「5 费 = 9 张」,1/2/3/4 费推测 9、搜索摘要「30/25/18」存疑未用。**必修二给出权威值:1/2 费 = 27 张(因可合四星),3/4/5 费 = 9 张(三星)。** → 应据此更新 economy_research §1 与 `_sample_shop` 的 `a`(副本数)建模。

**卡牌池操作(零成本操纵)**:要 D 某 3 费目标(如白厄)→ 商店遇其他 3 费牌时**先买下放备战席**(降低 3 费库存分母)→ 遇到白厄时**原价卖掉那些 3 费卡**再买白厄 → **无成本小幅拉高 D 到目标牌的概率**。(= economy_research §2「1 星买卖净 0 = 免费牌池操纵」,UP 实证确认)

## 低费 = 不赌,高费 = 赌(与铲/TFT 相反)

- **这套经济学更适合 3 费及以下核心的打法**:用尽可能少的赌博争取最高胜率。
- **货币战争与铲(TFT)相反**:**低费核心阵容 = 不赌;高费核心阵容 = 赌**。前期抢能连胜、顺利过渡到大后期的阵容才是真强。
