# 游戏内消费路由（sr-od-game-consume）

真实货币消费的操作路由知识：怎么走到付款、bot 在哪止步、怎么读消费状态。

## 消耗红线（任何消费项通用，不可协商）

1. **bot 永不代付**：真实货币支付的终点 = 摆好付款码，扫码由用户完成；支付确认类控件(「继续支付」/二维码本身)bot 不触碰，唯一例外是「确认放弃本次支付？」(收尾清理用)。
2. **开付款码 = 发起购买**：调用前必须已获用户明确同意(用户开口要求买 = 已同意；agent 主动建议后须等用户点头)；浏览商品页/读规则/查剩余天数零消耗，无此限制。
3. **止步即成功**：付款码摆好就收尾并转告用户扫码，不轮询支付结果、不自动关弹窗(除非用户要求收摊)。

## 各消费项通用的验证纪律

- 付款码摆好后，用画面截图确认「扫码支付」弹窗在、渠道正确(支付宝态=「其他支付方式」按钮可见；微信态=「返回支付宝扫码」按钮可见)，再转告用户。
- 消费状态读取(剩余天数等)以画面建档的 area 为准，别凭记忆报数字。
