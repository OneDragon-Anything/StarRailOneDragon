# 持续伤害 DOT 队(B 级)

> V4.4 合集 76807134:B 级。攻略直读 [77026641](https://www.miyoushe.com/sr/article/77026641)。
> 代码字段:`COMP_LIBRARY["DOT队"]`(V4.4 刃回归后 core 该加 黑天鹅+刃)。

## 机制(怎么 work)
A8-30 曾强势 → A8-40 银狼成顾问、卡芙卡失星核猎手队友一度不可玩 → **V4.4 刃加入,卡芙卡实力部分回归**(刃比普通狼行动频繁,多触发星核猎手额外战技)。
DOT 不吃幸运乘区 → 卡芙卡**带 3 个风暴潮**。

## 成型阵容
卡芙卡(3 风暴潮)+ 黑天鹅(鹅,后台 2 dot)+ 刃(2 星核猎手)+ 刻律(复制战技,配刃让卡芙卡连动)+ 知更鸟(鸟,攻击力+启动)+ 杨叔/主角/缇宝/符玄。刃带钻地弹+泡泡枪(+流星飞翼/散件)。

## 成型节奏
1. 前中期**椒丘**(2 dot 2 减益)+ 风堇生存 / 无生存靠椒丘治疗+刃+泡泡枪。
2. **6/7 级找卡芙卡 3 星**(来多直接 3 星,少则 2 星上 9)。
3. **上 9 找杨叔 + 鹅(黑天鹅)**:3 星卡芙卡 + 1 星鹅够;2 星卡芙卡 → 鹅必须 2 星(分 1-2 风暴潮给鹅,鹅卡双 c)。
4. 上 10 挂周日/昔涟/花火/2 忘。

## 装备
- 卡芙卡 **3 × 火力风暴潮**(DOT 不吃幸运乘区)。
- 黑天鹅(2 星时)分风暴潮,余出轨道炮/蓄能帆/鞋。

## 弱点 / 变体
- **需自己卡芙卡**(局外带风套;星核猎手+刻律双复制回能快高频开大)。
- **dot 转**给刃 → 下鸟换椒丘/海瑟音开 4 dot。
- P1 强 / P2 乏力 / P3 需转(低费过渡保血权威)。
