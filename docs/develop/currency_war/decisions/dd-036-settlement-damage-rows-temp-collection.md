# dd-036 结算屏逐角色伤害行临时采集链路(ΔV_2★ 数据面)——立撤完整周期

> Status:**superseded/已撤**。采集链代码已整体 revert(主仓 58d65d51,含 SCHEMA_VERSION 回 2→1、测试锁同步删);本文保留完整决策周期供追溯,重启采集时从 git 历史回溯本条与 ebd1bc96,不留死码。

## 背景(为什么立)

P55 阶段 2(ΔV_2★ 逐角色伤害份额判据)此前依赖**被动观测**加量:从既有实机 outcomes 里攒「场上恰有恰好 2 个 2★ 角色」的行,用每局该角色的伤害份额做方差估计。被动批复核(`.debug/temp/currency_war/delta_v2star/REPORT.md`)结论为**结构性不足**:917 行样本的置信区间仍跨 0——份额本身接近均分(方差天然小),被动采样永远等不到能解锁判据的精度。

补样本的模拟(sim)路径在当时也被认定不可行:逐角色伤害份额的模拟真值依赖敌方血量演化,而敌方血量演化又由伤害份额决定——本项目证据体系内是循环依赖;星敏化(让 sim 直接吐逐角色份额)需要给模拟器注入没有出处的社区先验,违反 ADR-0482(策略命题权威 = 数学证明与实证,未证口述按待证假设对待)。

于是落了临时采集钩子(commit ebd1bc96):实机结算屏数据统计面板的逐角色伤害行,在既有结算屏读取(`read_round_outcome`)的同帧 OCR items 上解析,落 `RoundOutcome.damage_rows` / `OutcomeRecord.damage_rows`(outcomes.jsonl 原通道),`parse_settlement_damage_rows` 纯函数,fail-closed 整体读不到 → None 诚实删失禁冒认 0,无条件触发、零新增截图/OCR/点击,SCHEMA_VERSION 1→2。

## 撤销(为什么撤)

用户裁定:**ΔV_2★ 经验标定属战力建模,策略核心不依赖它**——2★ 相关决策已由既有核心规则覆盖:

- 2★ 合成买入:M2b 合并完成买入(dd-034);
- 2★ 角色选取:P20 方向序;
- 线内件买入义务:M2。

逐角色伤害份额采集是为 ΔV_2★ 判据解锁服务的专用数据面;前提(策略核心需要该判据)被裁撤后,采集本身失去目的。**边界**:Δλ_death(P12/P25 的死亡价值货币)是既有自有价值体系的组成部分,**不受本裁定影响,保留**。

## Considered Options

- **被动观测继续加量**:否——917 行 CI 跨 0 是结构性不足(份额近均分,方差下界决定样本量需求超出现实可攒量),不是样本不够久的问题。(立时裁决)
- **sim 星敏化**:否——循环依赖在本项目证据体系内不可破;注入社区先验违 ADR-0482。(立时裁决)
- **实机结算屏逐角色行采集**:采纳落地(ebd1bc96),后因前提裁撤而撤销。(完整周期)
- **保留钩子零成本被动采**(撤时候选):否——采集的目的面已随裁定消失,「零成本」不构成继续存在的理由;且违临时钩子「采够/终止即删整段,不留开关/死码」纪律。
- **留待将来重启**(撤时候选):否——git 历史可完整回溯(ebd1bc96 落码 + 58d65d51 撤销 + 本文),需要时按原文重立,无需在主干留死码。
