## 后果

### 行为变更影响面(方向声明二分,非 unintended drift)

**保守方向语义差(C1/C2/C3/C10/C12/C14,各一句依据)**:

- C1:厚度口径收紧(骨架件不计)→ 撤销证据更难凑齐,证据门更保守。
- C2:锁线门槛 0.5→1.0(游戏定义羁绊满员当量)→ 方向承诺延后、不提前。
- C3:驱逐退役 → 不再由未证阈值触发换向动作,降级仍可逆。
- C10:refresh 建议恒 False → 不弃当前手牌。
- C12:奖励阶梯恒中性 → 选档不因奖励文本冒险。
- C14:升级曲线退役 → 不再未证推级,升级冒险面收紧。

**未证即退役、方向不可声明(C6/C7/C8/C9/C11)**:这五项退役后,其原本载有的难度/死亡敞口定价随之消失——定价依据(「难度边际价值」/血锚换算通道)缺位,退役合规(见处置通则)但「变保守/变激进」不可声明,敞口变化如实披露:低血帧生存加分(C6)与环境生存钩子(C7)失效、P2 军火加分失效(C8)、品质难度惩罚失效(C9)、P1 尖峰放大失效(C11)——上述面向的难度敞口不再被补偿定价。

逐项影响面:

1. P1 锁线门槛 0.5→1.0(C2):锁线延后、空窗囤跨线骨架更长、K 投影回退 hoard 全集更频(sim 零漂移锚按本批重锚,种子 42/43 两局全程无锁线行为已实证锁线延后)。
2. 断供驱逐关闭(C3):死方向逃逸改由撤销出口①/③(证据机器)承载;缺口披露:断供死方向不再被计数驱逐(设计明示接受,同 04_survival §7 #7/#8 先例形态)。
3. 事件面加减分族置 0(C6/C7/C8/C9/C10):选卡回到纯评估分+用户转向轴;低血/P2 装备流/品质惩罚/刷新建议全部失效(C6-C9 方向不可声明,见上二分)。
4. 通用升级曲线退役(C14):多数 comp(无 level_plan)的 5-7 级强制推级消失,升压仅剩节点地板。
5. 遭遇选档:奖励中性(C12)+ P1 尖峰退役(C11,方向不可声明),选档只按词缀契合与成型度。
6. P1 平手序更迭(C4):社区占比序→注册表声明序后,平手帧的 pair 集合实质翻转(反例:仙舟 2/3、列车 1/2、DOT 1/2 → 旧选(仙舟,列车)、新选(仙舟,DOT)),`p1_early_pair` 无门槛派生辖的空窗期囤货方向随之改变;声明序为确定性约定而非经验/游戏定义依据,两序孰更保守**不可断言**(旧序的社区占比数据属已退役经验量,不构成保守性论证依据)——本条只声明「序更迭有方向性后果+翻转已披露」,不承诺方向。
