# 0345 - reward/supply Δ池锁 regen-robust 化(W111)

- 状态: accepted
- 日期: 2026-08-26
- 关联: ADR-0292(reward/supply Δ池采样)/0343(成型停手)/0344(局终自动再生)

## 背景与问题

W109(ADR-0344)后 Δ池快照每次实机局终自动再生,池内容随语料演化。
快速集 3 处失败全部是**池耦合锁锁了池的瞬时内容**:

1. `test_snapshot_reward_pool_matches_corpus_truth`:supply 桶首现真实样本
   (同 run 差分 Δ=0,n=1),检查项把 reward 的 +2.0 真值锚外推套到 supply
   → 均值 0.0 距 +2.0 漂移>1.0 报违规;
2. `test_ci_smoke_snapshot_batch`:同检查项内嵌于批 checks,同因;
3. `test_sim_seed33_ledger_flag_and_no_buy`:seed 33 的成型停手触发面随
   池内容漂移(池 4d28822c 下 0-79 窗口仅 seed 20 触发)。

supply 锚的定性:批㉗ 落地时语料 supply **零样本**,「非空时同判 reward」
是无数据支撑的外推假设;W109 再生后语料首现真实 supply 样本 Δ=0——
数据证伪该锚。根因层=**约定层**(检查项判据外推越过了证据边界),
不是生成器或语料问题。

## 决策

1. **检查项判据修正(supply 无真值锚)**:
   `check_reward_delta_pool_bucket_lock` 中 supply 只辖**伪影哨兵带**
   (|Δ|>20 的跨 run 量大跳变,符号不敏感——无真值锚时负值不能直接判
   伪影),样本量入 stats 披露不设门(n 不足=证据不足非违规,同空池
   语义)。reward 判据完整保留(n≥30 + 均值±1hp 带 + [0,20] 哨兵带)。
2. **adr0292 快照对拍锁改容差形态**:ADR-0292 规格原文即「均值**≈**语料
   真值」,锁从等值改 ±1hp 带(经检查项 violations==0 + 显式带断言);
   n≥30 结构断言保留。新增 supply 双向变异锁(合法 Δ=0 不辖 / 大跳变
   伪影必报)。
3. **w107 sim 端到端锁改存在性语义**:固定 seed 触发面锁改小窗 seed
   扫描(0-79):窗口内必有「成型停手触发局」否则红(成型停手在 sim
   真实轨迹失活=锁住的真风险)。「门咬住」从 r7+ 买入总数对比(分歧后
   轨迹分叉,总数不再可比——seed 20 实证 on 5 > off 3 而门确实咬了)
   改为**轨迹因果不变式**:开/关臂同 seed 同 RNG 流,闸门不拦截时两臂
   逐位相同 → 账本**首个分歧行=闸门首次实际拦截处**,该行必为成型
   停手轮且关臂该轮买入严格多于开臂。

## Considered Options

- **每次再生后重锚锁值**:被否——把「刷锁」塞进局终链=锁值追着池跑,
  检测价值归零(change-detector 反面:锁永远绿)。
- **裸放宽(删 supply 判据)**:被否——跨 run 配对伪影(批㉗ F4 的
  +41 形态)在 supply 侧同样可能涌现,哨兵带必须保留。
- **fixture 固定池**:适用于 cli_smoke 类链路锁;本三把锁的 owner 语义
  (ADR-0292 语料真值对拍 / ADR-0343 真实轨迹触发面)就是要对拍**当前
  语料池**,固定池=锁语义丢失,不取。

## 后果

- regen-robust 判定性验证:手动 `regenerate_snapshot()` 后快速集仍绿
  (W111_报告.md 记录)。
- supply 语料样本量增长后(n≥30 量级)可再评估是否建 supply 真值锚
  (届时按数据治理纪律先核 run 边界)。
