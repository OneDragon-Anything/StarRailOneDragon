## 推导

### ① 边际压缩价值(线性律 + 二维表)

买走一张同费杂牌 = taken_c ↑ 1:目标牌在剩余同费池中的密度 (a−j)/(v·a−taken_c) 上升,`expected_refreshes` 的 DP 直接给出全窗口累计节省。**核心数值形态(自检 ③)**:

> **线性律**:在 taken ∈ [0,24] 全程,3费@L7 的每张边际恒 = 0.2678 金(±0.01%)——E(taken) 在该带内是 taken 的仿射函数。直观:小缺口(q ≪ 1)时 E ≈ n_need·T/(5·p·(a−j)),T = v·a−taken 线性进 E。**失效边界(DP 越界伪影警示)**:亲跑 taken=60-71 边际 19.9→19.04 平滑无跳升——`_refresh_dist` 在 rem_n<0 下 dist 全零→E 退化 1,taken=73 超池容量 72,该读数是伪值不可用;**真实耗尽行为 = 仿射保持到最后一张**(rem_nontarget 近耗尽处轻微弯折,非跳变);3费@L7 与 1费@L4/L5 在 taken=100 仍偏 ≤0.711%。3-5费小池经 [30] 买光+合成理论上可推到该区(bench+合成约束下实务难达),带外不可外推。

### ② 窗口量聚合(激活门——「未来窗口数」已被 DP 积分)

**关键结构观察**:`expected_refreshes` 的 taken 差分**本身就是当前活跃搜牌窗口的累计节省**——DP 从当前状态积到缺口闭合,「当前窗口内节省 × 窗口数」的窗口数因子已被积分掉,**当前窗口内不需要再乘**(独立近似按窗口叠乘才是重复计算)。但**未来同档新窗口**(下一个目标 2星→3星加深、再遇同档新缺口)不在这个 DP 里——压缩持续持有期内它们各自再享受 Δ金,本式**不含这些项,故为下界**(方向:低估;sim 对拍 1/2 用作期望值校准会系统性偏低,如实声明)。需要乘的只有**激活概率**:

```
V_comp(杂牌 | 档c, 等级L) = A(该缺口实际进入付费 D 到闭合) × Δ金(c, L)
```

- 不 D 的窗口:节省的刷次是自然刷新(免费),金节省 = 0(只有时间价值,归 p38 完成日程,不货币化——A2);
- A 的物理来源 = p40 R1 完成门(c_eff·E[refreshes] ≤ V_gap);单步价值门阈值 = p40 ③ V* = c_eff/P(表值 19.2/148.4):1-4费差 2 张窗口成型边际可过 → A 量级 0.3-1;5费深缺口常态不过 → A ≈ 0(首版上界 0.05,自检 ⑥/⑦)。

**量级结论(自检 ⑥;辖域澄清 2026-08-31 用户勘误×2)**:**活跃窗口**(档匹配规则所及,压档跟随当时刷牌策略——确定性):一张 3费杂牌的窗口内价值 = 付费份额×0.27(≈全额 0.27×付费占比,不赌激活概率);未来同档新窗口的增值序列(各窗口自己的激活概率×Δ金)为首版略去的**下界项**;**「5费压库伪命题」的辖域=深缺口(3星差 3 张)窗口**:该搜索 733 刷/门 148 金**不会启动**(窗口本身不激活——不是折扣问题)→ 20 金/张的条件值挂在不存在的事件上。**浅 5费窗口(2星差 1-2 张,L9-10)照常适用档匹配规则**——池更小(81)每张相对效果更大(≈0.4 金/张量级),成本≈0 → **正在找 5费时买 5费杂牌压库是对的**。5费杂牌在窗口外的持有理由仍是 V_opt(p41:≈51 金,再遇规避)而非压缩。
### ③ [34] 判据数学化(「想压 X 费才买 X 费」= 必要条件 + 序辩护)

**判据一(档匹配 = 必要条件,结构证明)**:目标档 X 的单槽密度 q_X = p(L,X)·(a_X−j)/(v_X·a_X−taken_X) **不含 taken_Y**(Y≠X;`_refresh_dist` 的 c 参数只扣同费池)——买 Y 费杂牌对 X 档密度的提升**恒等于 0**。所以「不是要压的费用档就完全没必要买」([34]① 原话)不是启发式,是模型结构事实:跨档购入的压缩价值 = 0,只剩纯消耗(占用金/槽)。数学化:

```
买压库件(费用 c) ⇔ c ∈ T_search(当前/即将进入付费 D 的目标档集合) ∧ V_comp(c) > 持有净成本(≈0,见判据二)
```

**判据二(成本侧 ≈ 0,分两档)**:1★ 买入全额退(`sell_refund`)→ 净成本 = 持有期息差敞口(A6:同档近 50 + [11] 卖回计划 ≈ 0,p46 挂起注)+ bench 槽价 V_slot——引 **p41 ③ N2 规范两档**:**free ≥ 2 → V_slot = 0**,档匹配即买(任意小的正 V_comp 都该买,1费白压 0.07 金也买——economy §3「任何正期望都值得做」的精确化);**free = 1 → V_comp ≥ V_slot = max{V_opt−c, V_plugin−c}**(净口径:最后一槽上的买入会阻断一个净 EV 可达数十金的囤件/插件候选,0.1 金级 V_comp 过不了这扇门——「即买」域比旧版声明的窄)。bench 紧张时按 V_comp 降序保留——**非固定序**:按当前 (L, T_search) 查二维表取(L7 邻域 3费>2费>1费;L10 翻转为 1费 0.63 > 3费 0.54,与 p41 带序随等级漂移同构互证)。

目标件期权价值全面压倒杂牌压缩(8-30 倍)——**囤目标件优先于压库**是数学结果,对应六序第 1 类 > 第 4 类。**压库(第 4)排在插件凑星(第 5)之前**的理由不是 EV 更大,而是 [34] 总则「可量化收益优先」:压库 EV 可计算且 ≥0,凑星收益不可量化([34] 自认)→ 取保守下界 0 → 压库 ≥ 凑星——**保守序,非 EV 序**(插件真实 EV 完全可能高于 0.27,如实声明)。第 2/3 类(场况/通用插件)在六序中高于压库是用户裁定序,本篇不推翻,只给其 EV 参照值。

### ④ 2★ 合成 tradeoff(槽位 vs 流动性 vs 压缩保留)

合成 3×1★ → 1×2★ 的三本账(自检 ⑧):

- **槽位(收益)**:释放 2 个 bench 槽 → 2×V_slot(bench 空 = 0;满栏 = p41 ③ 的 max 被阻断 EV,量级可达数十金)——合成是「深度动作不受满栏惩罚」(merge §2.5)的同一结构;
- **流动性(成本)**:cost≥2 卖 2★ = 3c−1,往返净 **−1** 手续费;**1费 = 3,往返净 0 → 1费 2★ 合成无摩擦**(economy §3 推论的复算确认)。另有**粒度损失**:1★ 可单张卖([11] 卖回量最小化 = 卖到刚好够息线),2★ 只能 3c 一坨——凑息精度从 1 金档变 3c 金档,可能过冲息线;
- **压缩保留(r=3 收口,2026-08-31 用户裁定;economy §1 二次确认版)**:普适不变量 = 剩余池 − resolved 固定池 − 持有副本总数(合成不销毁副本,2★ 计 3 张)。买入时 3 张已离池(压缩发生在买,不在合);**持有 2★ 期间压缩 3 张等效**;**卖 2★ 回池 3 张 1★,一次性释放全部压缩**(cost≥2 另 −1 手续费)→ (3−r) 项 = 0,**「合成后卖出保留压缩」通道死**:merge-then-sell 与卖 3×1★ 的压缩账完全相同再加手续费——**任何窗口下都不为保留压缩而合成**(旧 r=0/1 分支的阈值表作废),合成的理由只剩槽位(上条)。
- **卖回序推论**:卖 2★ 释放全部 3 张压缩 + 手续费 → **卖回序更不该先卖 2★**(与 ⑤ 新档序兼容:2★ 的每金压缩损失 = 3Δ/(3c−1) = 0.1004 **> 同档 1★ 的 0.0893(refund=3c−1,「相同」仅 1费特例),再加粒度粗(3c 一坨,可能过冲息线)+ cost≥2 手续费 → 排同档最后)。

### ⑤ 与 [11] 动态无损的联合最优(方向性首版)

给定结算前需卖回凑息的概率 π(A5):每张持有牌的期望保留压缩 = (1−π)×Δ金(自检 ⑨:π=0.3 → 3费 0.19/张;π=0.6 → 0.11)。方向性结论:

1. **卖回档序(每金目标函数)**:凑息约束是 **Σrefund ≥ G(金计)**,正确目标函数 = 最小化**每金压缩损失 Δ金/refund(1★ 即 Δ金/c)**,不是每张 V_comp——同一 G 所需张数差 3 倍(3费杂牌退 3 金、1费退 1 金),每张口径的排序在双窗同活时系统性错。L7 每金表(亲算):1费 0.165 > 3费 0.089 > 2费 0.052(4费 0.268 最差)——双窗同活(1费/3费都在 T_search)时序翻转为 **2费→3费→1费**:凑 3 金卖 3×1费损失 0.50,卖 1×3费仅 0.27。规则两段:
   - **第一优先:V_comp=0 的档恒先卖**——∉T_search 的持有杂牌零压缩损失,白卖(旧「1费先卖」仅在该分支成立:低费档 ∉T_search 时的推论,非每张 V_comp 排序);
   - **第二优先:T_search ∩ bench 可卖集按 Δ金/c 升序贪心 + 尾差贴线**;1费(粒度 1 金)做**尾差贴息线**([11]「卖到刚好够息线」的正确落点——最后一项,非主序);最优档随等级漂移(L5-9 首选 2费,**L10 首选 4费**——L9 每金 2费 0.0785 < 4费 0.0893,首选仍 2费),按当前 (L, T_search) 现算,非固定序;**贪心序的 ε-次优性**:G=3 时规则序(2费+1费尾差)损失 0.2698 vs 精确最优 1×3费 0.2678(ε≈0.7%)——G 小、档少,**实现走精确小 DP**(枚举各档张数组合,G ≤ 20、档 ≤5 时平凡);2★ 排同档最后(每金损失**高于**同档 1★:3Δ/(3c−1)=0.1004 > 0.0893——refund=3c−1(sell_refund 源码),「与同档 1★ 相同」仅 1费特例取等;加粒度粗+手续费,方向不变),见 ④;
   - 脚本自检 ⑨ 含翻转断言(凑 3 金两方案损失对比),此规则直接喂 sim 对拍 4 与实现。
2. **1★ 活期 vs 2★ 定期**:1费 2★ 仍活期(往返净 0);cost≥2 2★ = 定期(exit fee 1;r=3 已收口——退出即全释放压缩,见 ④)。最优结构 = 活期总量 ≈ 期望凑息缺口(π×息差),**不要把活期全合定期**——粒度损失会迫使过冲卖出(④);bench 紧张才合(槽价 > 粒度价值);
3. 压缩视角下 [1] 奖励节点多买的边界:奖励节点买压库件无战斗向机会成本,V_comp 同式——多买的量上限 = bench 槽预算,档选择同判据一。

## 边界(本证明不覆盖)

- Δ金是**条件值**(A2):只 D 自然刷的玩家真实收益 < 表值(时间节省不货币化);
- 深缺口/整缺口场景未全枚举(Δ金 ∝ 搜牌量/池,按同式重算;5费 3星整缺口等极端窗口 E→∞ 边界与 p41 A4 同判);
- NPC 耗池未证实(与 p40 A3 同源,方向双侧);
- 多个并行搜牌窗口(同时在追两个档)的交互压缩——各档 taken 独立线性(① 线性律),但共享 bench 槽的分配是 p41 ③ 的辖域;
- 锁店/市场干预赠刷;**池构成族突变(专家顾问族/黑塔纪元/人才下沉/二/三/四费援军等)改 v_c/a_c → 概率表/压缩表整体重生成**(resolved 口径,economy §1 二次确认版 + 设计 §4.10 resolved input;与 p40/p38 共同边界)——本篇全表按注册表基线生成,池突变语境须重算后方可消费。
