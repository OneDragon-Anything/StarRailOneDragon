# ADR-0487: P1→P2 接口机制五开关定谳清理(W793 判定②确认无效,删码留档)

> **版本界碑(2026-09-04 ADR 存量 review;对象属 decision_v2 栈或旧策略代,现行权威 = strategy-docs/flow/proofs + dd-NNN 系)**:本 ADR 裁决的对象已亡——decision/ 整包(含 decision_v2 各模块)已随 b94e9cfb(dd-038)删除,现行唯一策略载体 = mandate_v1(kernel 吸收下沉判据)。本件仅存史料价值(记录设计 why/翻案史);**文内一切「后续应做 X/须换成 Y」类前瞻指令一律视为已亡,勿执行**。

## 背景

ADR-0484 将 W774 v2 五项接口判据面落码为 `decision_v2/p1_iface.py`
五开关默认关(生命周期第 1 态,开臂判据挂账 = 预注册协议 v2 M1-M3 +
R 族 + G1-G4)。验证链两批:

- **W790 首轮 A/B**(`.debug/temp/currency_war/w790_p1_iface_ab/REPORT.md`,
  主窗 n=500/臂,池指纹 `6400d5d8edeaf68d+eqg1`,off 臂零漂移 30/30):
  主判据双败(M1 P2 存活轮中位差 0.0 / M2 P1 失血差 +0.01),但归因
  树判「触发面未开火」——`state.streak` 备战帧恒 None(①连败门/④
  死输入)、`hp_decision_trusted` 口径疑云(⑤)、②duty 谓词消费点在
  生产 op 结构性不可测。兑换为「数据不足,补 sim 观测态后重跑」。
- **W793 补齐重跑**(`.debug/temp/currency_war/w793_sim_enable_rerun/
  REPORT.md`,同协议零改动,off 臂 vs W790 off 500/500 逐位一致):
  三个死输入补齐后触发面全面开火——①代价门触发局 14→397(FALLBACK
  锁定 397 局)、②duty 义务帧 1169(R-② 转为可测)、③授权帧 40
  (出手率 77.5%)、④授权帧 112(触发轮买入率 93.8%)、⑤血带帧 80。
  R 族全绿(出手率 77-94%,排除「授权≠出手」等价病)与分支 D(数据
  不足)后,**主判据仍双败**:M1 中位差 0.0(均值 −0.080,p=0.2297);
  M2 P1 失血 **+0.81(方向反向**,p_less=0.964)。anchor 异族窗
  (150 对)同形态。护栏 G1/G2/G4 绿,G3 红为 M1 败的协议字面衍生。

## 决策

按 sim-testing §5 兑换纪律选 **②确认无效——不合入**:五开关与
`p1_iface` 判据面整体删码,本 ADR 留档定谳证据链。清理面:

- 删 `decision_v2/p1_iface.py` 全模块(①锁线 v2 后处理/②carry duty
  谓词与卸装禁令/③遭遇备战授权/④连败金流/⑤血线三带 + 帧判定核 +
  拦截枚举);
- 删消费点:arbiter 两处授权放行臂与 `p1_iface_gate` 约束分支、
  strategy 锁线后处理调用与 `v3_p1_iface_intercept` 披露键、
  `equip_all` hold 豁免 duty 臂(恢复无条件过滤)、registry 五开关 +
  三阈值 + constraints 项 + 审计矩阵 ('gold','emergency'/'mode') 格
  扩格回卷;
- sim 侧:engine_p1 装备段 duty 观测桩摘除,账本行 `p1_duty` 键按
  披露稳定保留恒 False(历史数据只读口径);W793 的 sim 观测态补齐
  资产(带符号 streak / hp_trusted 真值帧 / 检查 `streak_propagation_
  live`)**保留**——它们是 sim 保真资产,off 臂逐位零漂移,与开关
  去留无关;
- 行为锁 `test_cw_p1_iface.py`(六锁+开关合规)随语义删除;
  `test_cw_adr0293_calibration.py` 注册表校准锁同步回卷。

## Considered Options

- **维持默认关挂账**(否决):开臂前置(协议重跑)已兑现且结果为
  否——「概念已被否决的默认关」是策略开关生命周期明文的堆积债;
- **按 W790 判定③继续补测**(否决):补测已完成(W793),「输入就绪
  后的零/负效应」不得再叙述为数据不足;
- **只删判据面保留①锁线 FALLBACK**(否决):①与②③④④共享一致性
  门与拦截面,半删留半模块=第二源残根;锁线语义的正信号单独记档
  (见下),复活走重立项而非留死码。

## 后果

- 默认行为零变更(五开关本就默认关,off 臂=HEAD 逐位);删除后
  受影响测试与 cw_quick 全绿为验收线。
- **M3 质量维正信号单独记档**:锁定局锁错率 **2.02%**(397 局中 8 局
  板面交叠=0),交叠达标率 **97.98% ≥ 90% 线**,交叠均值 2.64——
  「锁前板面一致性验证、锁错不如不锁」的锁线质量语义在成规模样本上
  成立。该语义不随本批删除作废:锁线主机制 = [23] 锚(cw_intention
  信号驱动,ADR-0357 P1 配方锁),不在本批辖域;若未来重立项接口
  判据面,板面一致性门按本证据直接复活,不必重证。
- 未兑换残余移交(不另立开关):①M3 计数维红(门后再摇摆 70%)暴露
  的指标构型对连败门适配不良问题;②duty 行为面(义务豁免 hold 的
  战力差异)sim 结构性不可测,归实机判读。
