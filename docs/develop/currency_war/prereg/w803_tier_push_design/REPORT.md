## 1. 骨架对齐

### 1.1 现行评分主轴与「档位积分」的关系:**加权融合,不替换主轴**

现行 P1 评分主轴 = 配方完成度(`cw_recipe` 配方伪 comp 令 plan/deploy 评分自动转向配方完成度,strategy README 02 篇;ADR-0225/0243)+ 九维板面差分(`scoring.score_state`)+ 方向约束(`locked_buy_scope`/`_off_lock_demotion`)。配方完成度本身已是「战力积分类」量,但它度量的是**线的组成进度**(成员凑齐没有),不是**离散战力档位**——局 7/8 型「买了线内件但不上场/不凑档」时配方维度与档位维度脱钩(买而不上、上了不凑)。W801 证明出口 hp 的决定量是后者。

因此:配方完成度**保留**(它回答「买哪条线」,是方向输入);档位推进**新增为缺口差分项**(它回答「这条线的离散战力兑现到哪一档」),以加权和进入买牌/升级/刷新/部署评分。替换式改造(删配方轴)无必要也无证据支持——W801 七局里成型局全部同时是配方局,两轴在正样本共线;脱钩只发生在负样本(档 0 散装),缺口差分项正为负样本设计。

### 1.2 「激活档」的精确定义(口径)

- **计入哪些羁绊**:当前意向辖域内的羁绊 = `p1_pair`(v3_intention 派生的双体系)∪ 其成员的 flows(DOT 票语义,W789 问题 0:椒丘 faction 标签「狼狩」但 flows 带持续伤害,计算必须走注册表 factions∪flows,不能只看首阵营)。未锁线探索期:计四体系(transition_combos 封闭裁定)。
- **面板档 vs 有效档**:**用 deployed 域注册表自算口径**——`tier(b) = #{u ∈ deployed : factions(u)∪flows(u) ∋ b}`,不用游戏羁绊面板快照(滞后一拍,W789 问题 0 实证);bench 上的件不计入当帧档(经部署才兑现——这是缺口差分项给部署侧加权的理由,§3-③)。
- **「推过 3」的档位计算口径**:目标不是统一的「3」,是**意向引擎的成型最小档组**(transition_combos 逐线):仙舟线=仙舟≥3;列车线=列车≥2∧(DOT≥2 或希儿系);即「任一计数羁绊达其成型档」。**判定力声明(v2,面 2)**:W801 的观测口径(max 单羁绊档 ≥3)是仙舟线实例;七局成型局全为仙舟3,**复合口径与 max 档口径在七局档案上结构性不可分辨**——G0 只能验证口径实现无 bug + 仙舟线复现;列车/DOT/希儿线的阶跃位置**判前未证**,归 A/B 内过程量(M2 v2 口径)观测、失败分流调常量分支兜底;**V_tier 按线分权首版**:仙舟线=锚定值(+19 血当量),列车/DOT 线=占位降权 0.5(2 人档线增量小、可能在更低档完成阶跃,统一 +19 当量会过量投资),希儿系=最低权(伤害在希儿技能层,羁绊只是放大器,档位阶跃可能不存在)——三分权全部 sim 标定批重标,首版权值不做生产决策之外的解读。
- **探索期(四体系均未成型)**:缺口差分项退化为「距最近成型档组的缺口」(最小缺件数),与 [31]① 空窗填充语义对齐。

## 2. 命题(P32,单篇 = proofs/p32-p1-tier-push-ev.md)

- **P32.1 阶跃**:档≥3 → 出口 59-72;档≤2 → 9-48;boss 税 -13(档3,三局精确同值)vs -32/-34(档≤2);遭遇 ~15 血阶跃;r6 普通 ~20 血阶跃(先于 r7);≥85% 出口落差归档位,装备/星级无贡献。

## 3. 设计(四件)

### ① 缺口差分项:权重与形状

- **ΔG 语义定稿(v2,存量差分读法,面 3.1)**:「积分型」是**杠杆类型学称谓**(目标对象 = 逐帧累积的存量状态变量——当前板面档位,与授权/方向/时机型一次性杠杆相对,沿用 W801 §3 类型学);**计算形态 = 逐帧存量差分,非流量入账**:每帧重算存量缺口 `G(t) = dist(deployed(t), 最近成型档组)`,候选分 = `G(before) − G(after)`(该候选使缺口缩小多少),无跨帧累计账本、无「一帧误买入正账后卖出不回滚」的误差累积。同函数单一源:散装门豁免判据(§3④)消费同一 `dist` 函数。
- **形状 = 阶跃+边际递减,非线性**。依据:H3 阶梯 e0→e1→e2 胜率 13.9/41.6/77.8%(档间阶梯主导、档内平坦,ADR-0304)+ W801 阶跃集中在引擎成型档。候选档位分 = `ΔG(c) · W(r) · V_tier(线)`;`V_tier` 按线分权首版(§1.2),量级由 P32.2 锚定,精确常数 = sim 标定卡点(设计批不拍值)。
- **人口-档位捆绑声明(v2 补,面 1.3)**:W801 归因是「档位/**人口**」双变量(V_tier 全部锚自档位帧差,人口帧差无标定);升级候选的缺口差分项只在「升人口使引擎件得以上场凑档」时给分(与 [33] 人口位语义一致),纯人口战力增量**不在本项辖域**(由既有升级 EV 账承载);人口作为独立混杂入 G-RC 回归项(协议 §3)。
- **进哪些评分**:买牌(经 W802 已落库的 κ 折扣通道,见 §3③)、部署(线上 2★/合成产物对 deployed 档位的边际作为 sort_key 一等输入,与 W802 ④-a 同构、抽同一函数分位面参数)、升级(人口位升级在「有引擎件等上场」时给分)、刷新(缺档成员的 `Δp_tier · P(本刷出缺件)` 超几何项,沿 W795 侧一机制,**金水位辖域门同样适用**(P5「花完仍≥50」边界,不另造)。
- **与息律的关系**:缺口差分项不改息线门——破息买件的息损照记([17]/[22]④),EV 账里 V_tier 对冲息损,P32.2 已证量级差一个数量级以上。

### ② 「r7 死线」:时间维进评分

- **死线权重 `W(r)` 单调递增**(r1-r5 平缓, r6 陡升),**r7 后坍缩为 boss 残差分量**(只剩 r9 boss 帧 ~19 血档差可兑现,且新增档位只经 r8-r9 两个购买窗,兑现概率打折)。形状参数(陡度)sim 标定;方向性(前重后轻)由「掉血帧 71% 集中 r7+r9」直接导出(W801 §3),非自由参数。拖延/押注两向有界:r7 后残差折扣压住推迟投入,r6 预算承诺(§3⑤)兑现 W(r6) 陡升;G3 事后探测(面 3.2 确认)。
- **机制含义**:死线不是硬截止,是评分的时效折价。

### ③ 与既有机制的关系

- **off-lock 罚分:引用 W802 已落库实现,零新增(v2 修正,面 4.1)**:W802 已把 `off_lock_buy_penalty` 常数罚替换为机会成本制 κ 比例折扣落库(scoring.py;负分不洗白;开关默认关回常数罚 3.0)——本设计**不重复落改**,P1 侧买牌评分经既有 κ 通道获得「降级非禁绝」语义;W789 Q1 的量级失配判决归 W802 的 A/B,本设计零主张。重叠面清单:①Δp_tier 标定单一源;②部署边际 sort_key 抽同一函数;③**off-lock 罚分本体 = W802 单一实现**,W803 只消费。**W802 A/B 失败分支声明(v2 补,面 4.2)**:若 W802 定谳清理(κ 删码),P1 侧退回常数罚 3.0 运行(W789 Q1 量级失配作为已知受限缺陷继续存在,如实承接受限);本设计的缺口差分项是**独立加分项、不依赖 κ 形态**——M3 可测性不受影响(W791 深度决定论,P1 出口质量决定 P2 深度,W802 缺位下传导依然可测)。
- **方向锁线(v3_intention)保留、降权为输入**:锁定状态机零触碰;方向决定哪些羁绊计入档位,档位决定这些羁绊值多少分——方向是坐标,档位是标尺。
- **与 P29 囤牌的关系:P29 是本设计的子集/特例**:囤牌羁绊感知 EV 正是缺口差分项在「买入时点、收益跨期」情形的账式;Δp_tier 标定单一源三处消费(P1 缺口差分/P29 命题/W802 侧一、二),禁第二源。
- **与 W802 兑现链的正交性声明(v2 修订后表述)**:W802 辖**位面 2 侧、线锁定后**的搜牌→买入→合成→上阵兑现链;W803 辖**位面 1 侧、锁线前后全程**的评分目标函数补项(缺口差分+死线+散装门+r6 预算)。时间轴上游/下游;重叠面三条已收口(上段),**新增机制零重叠**——W803 四件没有任何一件复刻 W802 断点(⑤支出门/D1/D2)的修复主张。
- **与 p1_iface 的区别声明(ADR-0487)**:五项接口全部是**授权/方向/时机型杠杆**;出口 hp 是「离散战力逐轮累积」的存量状态变量,五项没有一个把档位完成度设为目标函数(W801 §3 逐项断链)。本设计是**存量目标型杠杆**:不改「让不让花/何时花」的门,改「花在什么上值多少分」的标尺——类型学正交,恰补其缺位。W793「触发面全开火仍双败」是本设计的存在依据。

### ④ 散装板守门([31] 硬约束落码形态;v2 规格补全)

- **门,不是分**:`max_bond_tier(deployed) < 2`(无任何 ≥2 羁绊)的帧,线外散件买入候选被 filter 层硬拒。判定时点 = 备战决策帧的 deployed 现值(生成候选前的快照,执行期现读)。
- **生效轮次域(v2 显式化,面 5.1)**:**r4 起**。r1-r3 是 transition_combos 明文的空窗期常态(「手上有什么羁绊先上什么」,[31]①),门不生效——开局自由买战力件是唯一正确策略,不定义成违禁。
- **豁免判据(v2 单一句化,面 5.2)**:「候选使 deployed∪bench 任一意向体系向其成型档组前进的最小增量 > 0」——与缺口差分项消费**同一 dist 函数**(单一源);宽松+方向性:从档 0 板买某体系第一张也豁免(它使该线缺口减小),防「永远到不了档 1」的自锁;门拒的是「对任何意向体系缺口都零增量」的纯散件。与 [31] 既有豁免的消歧:[31]① 空窗期豁免由生效域(r4 起)承载,[31]②③ 凑档/填充豁免由本判据承载,压库豁免见下条——三入口无重叠。
- **压库豁免收口(v2,面 5.3)**:压库豁免加**费用档 ≤2 费硬上界 + 每帧 ≤2 张上限**([34] 费用档判据保留);**豁免不穿透 bench 挤占门**——豁免只作用于「买什么」(散装门层),「还能不能买」由既有 bench 保留空槽/[32] 腾席判据独立前置判定,散装门不提供绕过挤占门的路径(旁路检查:豁免→买入的路径上,挤占门在散装门**之前**判定);压库借口滥用由 G3 v2 观测项检出(协议 §3:压库豁免帧的买入构成抽样)。
- 守门只拒**买入**,不拒卖出/部署——2★ 强力单卡不会被卖;希儿型「在手不算开线」的放大器件按豁免判据处理(量子/贝成员使希儿系缺口减小 → 豁免),不误伤。

### ⑤ r6 建档轮预算前移(W801 三位干预)

- r6 普通战斗轮 = 遭遇/boss 的真实备战窗(其备战帧量级失配,W801 §3③)。落码形态:r6 备战帧发放**建档专项支出授权**——EV 门式(引 P26 形态):`EV = Δtier·V_tier + Δstreak − C − I > 0` 即放行。
