## 高-1:「生产 P2 回退先验=7」的现行口径声明与注册表相反(R23-7 / R24-3 / R22次3 链)

**位置**:登记表 R23-7(「生产 cw_plane_table 未揭晓 P2 的回退先验**已改用**语料定谳值 7」)、R24-3(「生产路径未揭晓 P2 的回退先验=7 ⇒ P2 分量平移=0」)、R12-1 步骤 4 R22-1 修订段(「现行窗口 δ=P3 分量单一构成」);设计件 §5.3 floor_eff 对拍行 R24-3 打标、§6.1 R23-7 打标。

**缺陷(注册表直调实证)**:`kernel/cw_plane_table.py` 的 `schedule_of`(第 61-74 行)对一切未揭晓位面回退 `NODES_PER_PLANE`——P1 期返回 `(9, 9, 9)`,**未揭晓 P2 的回退是 9,不是 7**。`DEFAULT_PLANE_LENGTHS=(9,9,9)`(第 41-42 行),注释明写「P2 真值 7 但以 session 表为准」——即 7 只是揭晓后真值,回退先验从未改。全仓 grep 无任何「未揭晓 P2 回退 7」的实现载体。

**为什么错**:R22次3 的治本条款本系 prospective(「P2 零成本治随首批 sim 前落地」),R23-7/R24-3 把它提前记成「已落地/已改用」,制造了登记表自己的「权威叙述与现状错位」——R9-1 定性过、R24-3 自己正在治的同型病。实质后果三笔:

1. **§5.3 floor_eff 对拍行 P2 场景被错误降格为「fixture 专用路径、非生产口径」**(R24-3:保留 P2 场景断言须显式声明 fixture 注入回退 9 系测试专用)。生产真象恰相反:P1 期 P2 分量 +2 平移**在生产路径可达且必然发生**,按 R24-3 打标落测试的实现者会把这个真实生产路径当测试专用假场景处理——主场景错标,验证计划对生产 P1 期的窗口行为(P2+P3 叠加平移)零覆盖。
2. **R22-1 的「现行窗口 δ=P3 分量单一构成」错**:P1 期 δ=P2(+2,生产存在)∧P3([0,8]) 叠加。λ_L:=0 回退的量级、残余登记(不可判子态「未修正口径量级 δ」)在 P1 期被低估 2 轮折算量;R20-5 可判/不可判分列中「P2 分量可判」在现行生产码下**仍可判且非零**——「按修正后取端」在 P1 期对 P2 分量有定义,R22-1 把整个窗口判成不可判子态是过度回退(多付少卖保守代价,方向不翻案但规格与真态不符)。
3. **R23-7 的双源消解只消了一半**:打标消了叙述双源,却立了一个新的错误现行口径(「P2 回退=7」),双源病换了个方向复发。

**修法方向(二选一,禁再悬置)**:①真落地治本——`schedule_of`/`DEFAULT_PLANE_LENGTHS` 的 P2 回退改用语料定谳值 7(【注】/先验标注随 ADR),落地后 R23-7/R24-3 断言才为真;②回滚三处「已落地」断言为「治本挂账、生产现行=P2 回退 9」,§5.3 P2 场景恢复生产主场景地位(与 P3 场景并列),R22-1 分列恢复「P1 期两分量叠加」现行口径。①是 R19-1④ 已排期的零成本治本,应直接做;做完前②是唯一诚实态。

## 中-1:R23-1「切离残留帧构造性可达」的构造与 R13-1①+R16-1 前置门互斥;域外期 K 永久冻结的战略代价未申报

**位置**:登记表 R23-1 补充论证「可达性构造(切离直通线的塌缩残留帧)」;互斥对象=同表 R16-1(「R13-1① 前置门同步认域外态为『出口不可用』,域外期换线不登记、K 冻结」)+ R13-1① 引理;设计件 §2.7.1 注记 2(「换线照走 P16,θ 滞回+D_min 对直通线同样适用」)、§5.2/§5.3 无冻结时长归因行。

**缺陷**:R23-1 的可达性构造是「直通信号锁线→**P16 换线**→残留件(bench 后台效果件)未及塌缩卖出,其卖前桶键落域外」。但按本设计自己的规则链:卖前桶含后台效果件 ⇒ 桶键域外(R23-1)⇒ line_switch_sell 强制停(R16-1)⇒ 前置门认「出口不可用」⇒ **should_switch 不登记换线**(R13-1①)。即:直通线自己的后台件在场时,切离直通线的换线事件根本不会登记——R23-1 描述的构造(直通线残留后台件等待塌缩)在规则链下不可达,引理内「构造性可达」断言与它引用的两条既有条款不能同真。该帧真正可达的唯一形态是:登记帧卖前桶无后台件(出口可用、换线登记),**K′ 生效帧骨架 pass M2 买入 K′ 线自己的 bench 常驻件后**同帧 EV pass 塌缩遇域外强制停——与 R23-1 写的构造(直通线的件在等)对象不同,§5.3 切离残留帧断言按 R23-1 字面构造会造不出场景或测错对象。

**为什么错(更深层)**:前置门+域外条款的合成后果是——采集 #3 补标定完成前,凡线内件含 bench 后台效果件的线(直通线为典型:小黑塔一旦买入),K 即冻结、换线判据对该线空转至局终。这是**整局锁死次优线**的战略代价(次优线期望机会差无既有数值界,R18-5 自己声明只由遥测监督),而:①§2.7.1 注记 2「换线照走 P16(直通线同样适用)」在过渡期对该族线是空话,无任何注记申报;②§5.2「换线事件数/批」在直通局恒 0,无「禁读作换线价值证伪」的归因条款(现有三因归因只盖臂①旁路/出口不可用/判据未标定,域外冻结在 switchline_exit_blocked 里与全🔴延迟态混计,量级完全不同:后者帧级、前者局级)。

**修法方向**:①R23-1 可达性构造改写为「K′ 线自购后台件」形态,与规则链同真;②§2.7.1 注记 2 补过渡期限定(后台件-bearing 线过渡期换线构造性不可登记,K 冻结=接受的退化域);③§5.2 补「域外冻结局占比/冻结帧数」遥测行并与 switchline_exit_blocked 分键或分层,判读层声明直通局换线事件数=0 系条款设计内行为。

## 低-1:R24-1 引理推导 1 的真实总敞口增量式不严格(系数 λ vs λ′;Σr 集合口径未定义)

**位置**:登记表 R24-1 引理「推导 1」:「真实总敞口增量=λ×Δ息流+(λ′−λ)×(g+Φ+Σr)」。

**缺陷**:按律文 T:=λ×(g+Φ)+λ×Σ_held r_i 精确展开,卖出 x 的 ΔT=(λ′−λ)×(g+Φ+Σ_held r)+**λ′**×Δ息流。引理首项用卖前系数 λ——λ′≥λ 域(桶弱化)内该式系低估;且「Σr」未定义是卖出前持有全集还是含已卖件(两口径差一个 r 进第二项系数)。定性结论(两口径之差 λr=入账时点差、c 分量形式中性)不翻案,但本登记表协议明文「『保守/方向/有界』类声明一律给不等式级论证,禁裸声明」,载重恒等式自身应严格——λ′−λ 在濒死带可达 ~0.3,首项系数误差与被申报的偏置量级同阶。

**修法方向**:推导 1 改精确式(λ′ 首项 + Σ_held 口径显式),或声明「下界形态」并入账。

## 低-2:V_slot 的逐格分端在「被阻断动作集」聚合语义下选格无定义

**位置**:设计件 §2.10 F6 段 V_slot 条目 + 组-端表 V_slot 两行(R22-3/R23-2);消费 R17-4「按消费位当前槽/等级选格」。

**缺陷**:「当前槽/等级」预设消费位有唯一格;但 V_slot=被阻断动作(总纲 §2:「free≤1 = **max** 被阻断动作净 EV」)的聚合量——bench 满时被阻断买入动作可多件、分属不同(槽位×等级)格。「逐动作按其卡的目标格取端后取 max」「先取 max 再按某格取端」「sum」三种组装在文本下都合法=R6-5 要消灭的实现者自造方向缺口在**派生量标定后**(开闸后)的残留形态;R22-3 只钉了「分端随消费位走」,没钉「格随动作走还是随帧走」。

**修法方向**:V_slot 组装规格补一句「逐阻断动作按该动作目标卡的格取该消费位端点后取 max(与总纲 §2 max 语义对齐),禁止帧级单格聚合」;§5.3 标定后取端断言(R22-3)补多格并存的构造场景。
