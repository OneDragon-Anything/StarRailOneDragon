# 持续伤害 DOT 队(B 级)

> V4.4 合集 76807134:B 级。攻略直读 [77026641](https://www.miyoushe.com/sr/article/77026641)。
> 代码字段:`COMP_LIBRARY["DOT队"]`(V4.4 刃回归后 core 该加 黑天鹅+刃)。

## 机制(怎么 work)
A8-30 曾强势 → A8-40 银狼成顾问、卡芙卡失星核猎手队友一度不可玩 → **V4.4 刃加入,卡芙卡实力部分回归**(刃比普通狼行动频繁,多触发星核猎手额外战技)。
DOT 不吃幸运乘区 → 卡芙卡**带 3 个风暴潮**。

## 成型阵容
卡芙卡(3 风暴潮)+ 黑天鹅(鹅,后台 2 dot)+ 刃(2 星核猎手)+ 刻律(复制战技,配刃让卡芙卡连动)+ 知更鸟(鸟,攻击力+启动)+ 杨叔/主角/缇宝/符玄。刃带钻地弹+泡泡枪(+流星飞翼/散件)。

## 成型节奏
1. 前中期**椒丘**(2 dot 2 减益)+ 风堇生存 / 无生存靠椒丘治疗+刃+泡泡枪。
2. **6/7 级找卡芙卡 3 星**(来多直接 3 星,少则 2 星上 9)。
3. **上 9 找杨叔 + 鹅(黑天鹅)**:3 星卡芙卡 + 1 星鹅够;2 星卡芙卡 → 鹅必须 2 星(分 1-2 风暴潮给鹅,鹅卡双 c)。
4. 上 10 挂周日/昔涟/花火/2 忘。

## 装备
- 卡芙卡 **3 × 火力风暴潮**(DOT 不吃幸运乘区)。
- 黑天鹅(2 星时)分风暴潮,余出轨道炮/蓄能帆/鞋。

## 弱点 / 变体
- **需自己卡芙卡**(局外带风套;星核猎手+刻律双复制回能快高频开大)。
- **dot 转**给刃 → 下鸟换椒丘/海瑟音开 4 dot。
- P1 强 / P2 乏力 / P3 需转(低费过渡保血权威)。

## ★海瑟音(V3.8):双鞋风扇 = 速度转化 DOT(关键出装纠错)

> 源:BV1SeBeBrEnM《海刻是对的!试用海瑟音 A820 游龙》(发布 2025-12-26 · V3.8)转录。**UP 推荐强度:★★ 半推荐**(偏手法 / 理解;试用勉强能玩,需"狠胡"才能过遭遇骑士)。非娱乐,游戏理解拉满的科研。

- ★海瑟音有**和阿格莱雅几乎等价的速度转化机制**:天赋「深海回响」乘数可叠加(只能靠海瑟音攻击叠层 → 攻击次数依赖跑条 → 吃速度)→ **本质 = 速度转倍率**。
- V3.8 **DOT 不能暴击** → DOT 队出装只能加伤害增幅 + 前台强度;暴击刀(第一输出装)吃不到 → 直接伤害亏模。
- ★**正确出装 = 双鞋风扇(双反重力皮靴 + 风扇)**:前台强度爆杀碎心斩刀(CW 最垃圾装备之一)+ 跑条大涨 → 深海回响从 <10 层提至 **30 层**(每单体 ~4500 倍率 ≈ 300 层 DOT)。配永远在场的群攻球 → 转波次不掉层。
- **翡翠**完美适配(对群海瑟音战技 / 大招给翡翠叠 7 层 ≈ 一动力追击,引爆频率远超试用卡芙卡;V3.8 修复了后台不引爆深海回响的 bug)。
- **克拉拉** = 完美拼图:双战技让海瑟音每回合攻击频率 +50% + 回能补大招缺口 + 每行动提前产战技点;克拉拉击破**精准挂海瑟音**(海瑟音在场时)。
- **为什么不出爆发装**:同阿格莱雅不出双电锯 —— 试用 / 高难爆发不够不能秒 → 战线拉长 → 双鞋风扇(前台强度分配更合理:小×小 + 大×大)收益 > 爆发装。
- **双鞋风扇只有自带速度转化的角色能出**(阿格莱雅 / 海瑟音;白厄 / 黄泉 / 希儿硬出不行)。
- 节奏:2-5 前保连胜(DOT 转 / 4DOT / 3 狼 2DOT 养狼都可)→ 一二位面攒钱 → 第三位面**直接升 9**(不停 8,本质九五阵容)→ D 饮月(老羊❓)+ 黑天鹅 + 希儿❓。**黑天鹅绝对优化不掉**(2DOT / 2 甚为之心❓给 ≥35% 伤害增幅,否则海瑟音增幅乘区空白)。
- debuff 禁忌:能量逃逸 / 正当防卫(净化身心勉强能玩)。
