# sim 战斗结算机制化(战力模型 v1)迭代设计(总纲)

## 0. 元信息

- 迭代目标:用户 2026-10-19 立项「sim 战斗结果预估重建」,方案骨架 = 阵容达成度+难度的预估函数。需求定义正本 = [sim-power-model.md](../../sim/sim-power-model.md)(设计件,未实施),本迭代 = 其首期落地;对正本的全部显式偏离集中申报于 §2.8。
- 状态:对抗审中
- 文档清单:无详设(单文档方案,本文件即完整设计)

## 1. 问题与动机

- 现状症状:sim 战斗结算 = 随机输出面——胜负 = 均匀伯努利 P(win)=0.5,败局扣血 = 区间 [23,70] 均匀采样,单一源 `sim/cw_sim_battle.py`;结算面不消费任何板面/战力/敌人特征,按 sim-design.md 校准层申报「战力相关判读禁出」。实证:2026-10-19 sim 局复盘(g_20261019_142001,seed 777,报告在 `.debug/currency_war/deep_review/`)——5 场结算战斗 1 胜 4 败,公平硬币下「至多 1 胜」概率 18.75%(恰 1 胜 15.625%),普通方差,死亡通道零策略信息量。
- 根因归层:语义层——战斗输出面是「诚实随机」而非「机制化预测」。机制化需求已定义(sim-power-model.md,现状注记 = 设计件未实施);前代实现 `cw_coarse_battle` 随 sim 重做整删(commit 8c9e8aafc,2026-09-15),sim-design §8.2 现值行明写「机制化重建需求件 = sim-power-model.md」,重建路径已裁定,非新立项。
- 解决到哪:①胜负层逻辑回归(§2.2);②幅度层条件化恢复(§2.4);③训练与校准管线(§2.3);④sim 接入与隔离护栏(§2.5);⑤采集通道 journal 增量抽取(§2.7);⑥语料盘点与预算重钉门(§2.1)。
- 明确不解决:词缀/boss 身份特征(首期冻结,放开触发线见 sim-power-model §4.3);对手板面读取管线;hp 类读数解禁(幅度层过校准验收前,A/B 判据仍以实机为准);P3 位面细分(并入非P1,低置信披露);策略层对模型的任何消费(sim-power-model 铁律 1,永久禁止);实机局自身行为(本迭代改动纯 sim 侧 + 离线管线)。

设计位合计 14;**预算不足以装全部设计位时,按「裁剪序」从尾裁起,受保护集不裁**:

- 受保护(不可裁,用户 2026-10-19 裁定 + 信号主体):截距、过渡分档(3)、终局达成度、核心星深——最小可行动集 = 6 参数;
- 裁剪序(预算 < 14 时依次裁去):难度缺失指示 → 上场数 − 人口等级 → round 序位 → node_type(2) → 位面二值 → 敌方难度 → 总星深。前两口为用户裁定④的原序;③以后的扩序为本设计申报(design §2.8-1)。

**取大定义**(特征 4/6 的形式化,双侧同源的关键):对任意板面 B,`best_line(B) = argmax_{comp ∈ COMP_LIBRARY} form_progress(comp, B)`,**平局破缺 = COMP_LIBRARY 注册序首个最大值**(确定性,两侧一致);终局达成度 = 该最大值;核心集合 = `best_line(B).core_chars`。COMP_LIBRARY 与 form_progress 均为注册表纯函数,实机行与 sim GameState 两侧同构可算;对齐测试 = 同一板面输入 → 两侧同一特征向量。**关于锁定线(target_comp)的事实与升级通道**:旧流 86.5% 行携带顶层 target_comp;值域构成 = 「过渡配方·X(+Y)」组合标签 498 行(80.8%)+ 注册套名 ≈118 行——升级通道前置 = 标签→套名归一规则。sim 侧消费锁定线需策略会话状态过桥(特征语义与策略器耦合,违铁律 1 隔离精神),故**首期维持取大定义**;抽取器统计并报告 target_comp 覆盖率与值域构成,「真锁定线版本」登记为语料升级通道(升级 = 显式评审策略状态过桥的隔离方案,不在本迭代)。

**符号约束**:单调特征施加方向约束——过渡分档 ≥ 0、总星深 ≥ 0、核心星深 ≥ 0、难度 ≤ 0;终局取大完成度**不加单调约束**(取大线可中途切换,存在合法的小非单调段);node_type/round 自由估计。

### 2.3 训练与验收

- 参数预算:有效参数数 ≤ 胜事件数/10(重钉实数);测法 = df=tr(Ĥ)。装配按 §2.2 保留序;重钉 < 7 触发 §2.1 预算重钉门。依据 = sim-power-model §4.3。
- 验证:LOCO(留一语料源交叉验证)防泄漏;校准曲线只在实机语料上做;样本量不足下限的桶只披露不判(分位带按二项重复抽样);外推段可见性对照表。依据 = sim-power-model §5.3。
- 标签缺失:killed=None 丢弃率按 source 分桶披露(MNAR,缺失与败局路径相关);低胜率带结论带敏感性免责。依据 = sim-power-model §7-8。
- **转正量化门**(影子期收敛判据,基线重钉后口径):①LOCO 校准达标(分节点类,达标桶数与分位带按 §5.3);②**判别力存在性**(量纲钉死):主判据 = LOCO 折外 log-loss(模型)< 折外 log-loss(常量基线,基线概率 = 训练集胜率先验 p̂);辅判据 = 池化折外 AUC 的分层 bootstrap 95% CI 下限 > 0.5;阈值与置信水平落代码常量。常量基线无判别力,「非劣性 vs 现任」随基线退化不可比,此为 §2.8-2 申报的显式重定义;③分歧分布 + 外推段对照表产出并判读。依据 = sim-power-model §5.3 双判据(基线语义重钉见 §2.8-2)。

### 2.4 幅度层条件化

- 现状:U01 败局扣血 = 全局均匀 [SIM_HP_LOSS_MIN, SIM_HP_LOSS_MAX] = [23,70](cw_sim_battle.py;区间界锚自实测散点 P2r1 −23/遭遇 −28/P3 遭遇 −70——散点跨度本身即上下文规律的实证)。
- 恢复形态(前代 cw_coarse_battle 同构,见 `git show 8c9e8aafc~1` 的直方/_LOSS_FIT/boss 钳制段;系数从现存语料重估):
  1. 位面×节点类型离散直方(保留伤害谱离散/双峰形状);删失纪律照前代——截断/钳制观测不入直方(boss 行截断观测单独钳制建模);
  2. 达成度线性均值匹配:直方采样 + (fit(达成度) − 池均值) 偏移。**协变量契约 = 过渡达成度分档**(`_settle_rung`;终局取大腿不作幅度协变量——幅度样本主要产自 P1,双轨在幅度层只用有样本支撑的一轨);每节点类型一组 (intercept, slope, 池均值);斜率 CI 含 0 退常数;非P1 位面直方按位面分层、斜率样本不足同退常数;
  3. 伤害地板与伪影伤害档剔除纪律照前代(语料治理递增纪律,版本常量随重估递增)。
- 样本来源:3.1 抽取器增出「幅度样本表」(败局 hp 结算行 + 协变量 + 删失标记)。删失标记口径 = 观测伤害量 == 结算前 hp(伤害被血量截断,真实采样值 ≥ 观测值)的败局行,可计算判定 = 差分 == −hp_before 且 hp_after ∈ {0,1};旧流无保底事件行,按此式计算;删失行不入直方主体,入截断统计(照前代钳制行纪律)。
- 辖域与红线:幅度层与胜负模型互不喂——P(win) 不见任何 HP 量;扣血分布不以模型输出为条件;幅度层系数入版本常量表(CALIB 语义版本随重估递增);hp 类读数继续禁作 A/B 判据,直至幅度层过校准验收(sim-testing 在册裁定,本迭代不解禁)。

### 2.5 sim 接入与隔离护栏

- 接线点:`settle_battle` 的胜负常量 0.5 换为调用方注入的 win_p 浮点(注入物 = sim 桶现算,先例 = P2CombatCalib 传值形态;查询函数签名缺省 None = 完整旧行为);**全域接管,不设覆盖不足回退分支**(依据 sim-power-model §6.1)。胜负掷点仍走 `M13/{plane}/{round}` 流键,seed 可复现性与随机量消耗序纪律不变(sim-design §7)。幅度层接线同批,伤害随机量消耗序的重排按流键纪律申报。
- 模块落点:sim 桶 `power_model/` 子包(查询面+抽取器+训练脚本+权重常量表);权重入库形态 = 代码常量表(先例 `cw_battle_tables`);**data/ 桶禁落任何模型产物**;AST 静态白名单断言集 + 重导出审计 + sim/replay 目录隔离测试。依据 = sim-power-model §6.2。
- 难度特征供给(无新生成面):v1 难度特征直读 RunConfig 现值——enemy_difficulty 为 match 级常量,现役装配已写入 GameState(写点 = `enemy_difficulty`/`enemy_difficulty_live` 双槽,在位),查询面直读即可,缺失指示仅真缺失行置位。**逐战斗难度采样(位面×轮次耦合)推迟**:装配期喂 RunConfig 无法逐战斗变化,战斗期直写 = 另立写点(排除形态)——该面随正本 §6.7 生成器需求 defer,与记账语义的协调方案留特征开放层评审(§2.8-6)。输入分布监控的「结构性缺失」判定随之收窄:新生成对局缺省路径难度恒在。依据 = sim-power-model §6.5/§6.7。
- 输入分布监控:结构性缺失(已知不可达)与真漂移(超阈报警)两类分开,落位与归属见 landing 3.6/3.9。依据 = §6.5。

### 2.6 边界与已知风险(正本 §7 全文适用,本文列首期特有)

- 取大定义的换线噪声:取大线中途切换时终局达成度有小幅跳变——首期接受;3.8 通道起量后可登记 locked_comp 字段,新语料逐步换真值锁定线(§2.7 升级通道的数据前提)。
- 双轨达成度的统计支持不均:过渡分档腿在 P1 语料厚、终局取大腿在 P2/P3 语料薄——预期终局腿首期学出弱系数,如实披露;「分档×P1、完成度×非P1」交互项为语料增长后第一个放开候选(参数翻倍,首期不做)。
- 首期参数受预算硬约束:重钉实数可能显著低于设计期快照(§2.1),保留序装配 + 重钉门保障不越预算硬行。
- 其余(B0/对手板面/版本漂移/样本爬坡/域差/共生/冻结/MNAR/词缀映射)照 sim-power-model §7 全文适用。

### 2.7 采集通道(journal 增量抽取)

- 动机:旧流 2026-09-15 停写(现盘仅 live 残量),训练集冻结;新实机局只写 kernel journal。本通道让模型随实机局持续演进。
- 形态:journal 写行 → 训练样本行抽取器。字段映射(2026-10-19 实测):胜负标签 = 结算 `field=hp` 写行差分**与 `hp_floor` 事件行并读**(首保底败局会写等值 hp 行,单看差分误判为胜;`hp_floor_triggered` 翻真即该结算为败且 hp=1);板面特征从 `state.values.deployed` 重计(journal 无 `board`/`board_factions` 字段);`field=streak`/`node` 上下文辅助对局切分(run_id 水位)。
- 阶段交付含「字段映射规格」小节(随抽取器入库):对局边界切分、多局文件幂等、标签推导与 hp_floor 交互、丢弃分桶——规格是验收对象之一,不是实现自由裁量区。
- 测试纪律:journal fixture(自造或脱敏小样本)入测试仓,**禁在测试中读本机易失产物**(项目测试规范)。
- 产物带源指纹(journal 文件集哈希 + 抽取器版本),与旧流产物同表结构,训练脚本无差别消费。

### 2.8 对需求正本的差异申报清单
