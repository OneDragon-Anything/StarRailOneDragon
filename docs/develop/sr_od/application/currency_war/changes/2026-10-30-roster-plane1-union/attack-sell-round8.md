# 卖出场景块无前提对抗报告（第八轮：七轮处置复核 + 意图槽全口径两文档对照 + 新角度）

## 结论（阻断）

**阻断**：2 阻断 + 2 中 + 4 低。两个阻断项全部落在**七轮处置的复核**上——处置不是虚报，就是半修：

- **S8-1**——七轮 S7-1 处置（净腾式方向 + 语境双修正）修对了式子本身（无 X、售 V、方向已验：canonical 席满形态净腾 = 1），但**没修式子的适用域**：`design.md:65` 步 6 让位成立条件是「席位受阻 ∨ 金受阻」两支析取，「级联可达性」按句法只挂在席位支；而 `design.md:68` 待卖态重验把「净腾 ≥ 1」写成与语境无关的统一条件——**纯金受阻语境（bench 未满）的场上件 victim 在步 6 按金受阻支成立、在待卖态被席位式净腾拦下**，两端读法都坏：判定端分叉则两端不一致（店内成立、备战作废 + V 入黑名单）；判定端统一挂则金受阻让位系统性误拦（卖 V 退金买 X 的正当路径被「真实 bench 件会上移」的席位校验错误附加）。处置声明「bench 无可上者 → 净腾 0 → 作废不卖，**正确拦截**」在纯金受阻半域失实——bench 未满时搜索不上移任何人（diff 空、卖 V 后无需级联）本是合法快路径，净腾却判 0 作废。与 S7-7 处置（「净腾校验本就是席位可行性——语义自洽」）互锁：该论证恰好依赖净腾全语境统一挂；若按语境分叉，金受阻级联失败又落席满键 `priority_insufficient`（S7-7 原攻击回魂）——**设计被逼进二选一洞，两侧都有毛病**。
- **S8-2**——七轮 S7-4 处置（非受限会话前置）只挡住了**评估帧自身受限**的形态，挡不住跨帧翻转变体：质量推迟帧（armed=False，板面有线外件）非受限 → 统一评估进（叠加态：席满 ∧ 金不足）→ 场上件 victim V 写槽 → 备战净腾过（S8-1 不拦叠加态）→ `SellDeployed(V)` 退金 + 级联提位 → **V 是最后线外件时 load_bearing_full 翻转 → armed=True** → 回店帧 gold（原金 + V 退金）≥ g* → 受限会话（`launch_restricted_session_active` 现算，shop.py:755）→ X 买入提案经闸 `gold − cost ≥ saturation_line`——花后落在 [0, g*) 带 → **拒 → CloseShop → V 白卖、X 本货架丢失**。数值例：gold 38 / g* 40 / V 退金 5 / X cost 40 → 回店 43，闸算 43−40=3 < 40 拒。处置申报的「受限帧获取延后，**回非受限帧再评**」在该形态**无驱动机制**（节点内受限不买金不降、板面已零线外 armed 保持）——与七轮 S7-2 定性的「无机制裸断言」同型，处置申报保证与真实机制矛盾。armed 翻转由级联自身造成（拖完线外件 = S7-2 原文点名的常态后果），受害主形态恰是本迭代新机制（场上件 victim + 意图槽）的 canonical 输入。

裁定本身不翻案（升级凑金删除 / 统一获取让位 / 意图槽策略层实现边界 / 凑息豁免 / 等钱帧凑息照常 / 拦因分键 / 非受限前置方向 / bridge 让位谓词方向，均不再攻）。七轮处置复核的**真**项：S7-2（bridge 谓词落文 + 代码结构核实：`_launch_front_check` 先于十段扫描属实、bridge.py 属策略层包改动合法、失败态抑制短路后第 9 步 emit 照常可发不延迟）、S7-5（签名求值点 = 重开店帧首评，关门态不读货架，自洽）、S7-6 主体（X 路径失败标记载体/消费点/作用域三定稿落文）、S7-10（D9-6/D9-8 文本确认在详设 :94 现文，本轮复核属实）。半修/残留项见 S8-1~S8-8。

## 发现清单

### S8-1｜净腾式适用域未定义：步 6 金受阻支不要求级联 vs 待卖态统一要求净腾——纯金受阻语境的场上件 victim 两端必有一处坏；S7-1 处置声明「正确拦截」半域失实，与 S7-7「语义自洽」论证互锁成二选一洞
- 攻击点：三个子面。
  **① 两端口径不一致**。`design.md:65` 步 6：让位成立条件 = 「席位受阻 ∧ 它腾出席位」**∨**「金受阻 ∧ 让位前缀可足（虚拟金币 ≥ 0）」——析取句法下「级联可达性判定」挂在席位支（「**场上件的席位成立** = 级联腾位，可达性由意图槽虚拟级联校验判定」）；`design.md:68` 待卖态重验：通过条件 = 「重放通过 ∧ V 仍在场上 ∧ **虚拟级联可达（净腾式 ≥ 1）**」——无条件统一挂。纯金受阻语境（bench 未满、X 贵、场上杂件退金可足）：步 6 按金受阻支成立（前缀可足，卖 V 退金与级联无关——卖场上件物理上零前置、bench 有空位 X 直接入）→ 写槽关店 → 待卖态被净腾拦（bench 未满时搜索无义务上移，净腾 0）→ **作废 + V 入黑名单**——店内判成立、备战判作废，正当退金让位整体退化为黑名单累积 + 机会清单。
  **② 处置声明半域失实**。S7-1 处置记录（round7.md:127）写「bench 无可上者 → 净腾 0 → **正确拦截**」——该判断只在席位受阻语境成立（席位受阻 + 无可上者 = 卖 V 无法腾位，该拦）；纯金受阻语境下「无可上者/bench 未满 → 定型不上移 → diff 空」是合法快路径（卖 V 后零级联、立即清槽开店买 X），净腾判 0 = **误拦**。S7-1 修正了式子的方向与语境（无 X 自举），没有修式子**对哪些 victim 生效**——实现者必遇「金受阻的场上件 victim 过不过净腾」这一语义选择，正文无答案（「实现者无需再设计」违例）。
  **③ 与 S7-7 互锁**。S7-7 处置（round7.md:133）以「净腾校验本就是席位可行性——语义自洽非硬编码」辩护级联失败记席满键 `priority_insufficient`——该论证**恰好依赖净腾全语境统一挂**（能走到级联的必是席位语境）；若按①分叉（金受阻支免净腾），金受阻语境同样走场上件 victim + 意图槽 + 级联（卖 V 后板面重整 diff），其级联失败落席满键 = S7-7 原攻击（金语境挂席位解拦轴）原样回魂。设计被逼进二选一：统一挂 → 误拦（本条①）；按语境分 → 错键（S7-7 回魂）。两侧都没有正文支撑。
  附带：净腾式「当前 bench 占用」的计数口径（物理件数 vs 名字集——同名多副本时 bench 占用怎么数）未写死；效应枚举「上移 −，下场 +」中「下场 +」只在 bench 未满（金受阻）语境可达（席满时被容量挡），恰是误拦场景——效应表与适用域互相暴露同一缺口。
- 证据：design.md:65（两支析取 + 可达性句法）vs :68（统一条件 + 「bench 无可上者 → 净腾 0 → 作废不卖，正确拦截」）；design.md:69（S7-7 括号「净腾校验本就是席位可行性」）；attack-sell-round7.md:127/:133（两条处置记录）
- 严重度：高｜阻断级：**是**（核心校验的适用域分叉未定义——按正文任一读法落，纯金受阻半域的场上件让位或整体空转（误拦+黑名单累积）或两端互相打架；修复需设计内裁定语境分叉与记键联动，非落地批可自行裁定）
- 处置建议：意图槽条明写净腾式的语境辖域——建议「净腾校验仅辖席位受阻支（含叠加态）；纯金受阻支的物理校验 = V 可卖出本身（恒真）」，同时 S7-7 联动改「级联失败记键按受阻语境分（席位 → `priority_insufficient` / 金 → `priority_insufficient_gold`）」；「bench 占用」计数口径（物理件数）与「下场 + 效应仅金受阻语境可达」随批入文。

### S8-2｜S7-4 处置半修：「非受限会话前置」挡不住跨帧翻转——级联清完线外件翻 armed、退金抬金过线，回店帧受限撞闸（花后 < g* 带）拒买入 → V 白卖、X 本货架丢失；「回非受限帧再评」在该形态无驱动机制 = 裸断言复发
- 攻击点：链路逐步（全部环节已对代码核实）：
  1. **评估帧**：质量推迟帧 armed=False（cw_launch_admission.py:259-261——配方完备 ∧ 板面非零线外 ∧ 计划可得）→ `launch_restricted_session_active` = False → 非受限 → S7-4 前置放行 → 统一评估进。叠加态（席满 ∧ 金不足）下净腾过（S8-1 不拦叠加态：bench 满、V 售后有上移）。
  2. **写槽 + 执行**：victim = 场上线外件 V（七轮 S7-2 原文：「线外场上件恰是统一序末位 victim 的主力来源」）→ 意图槽 → 备战待卖态重验过 → `SellDeployed(V)` 退金 r → 级联提位。
  3. **armed 翻转**：V 是最后线外件时，V 售出 + 线内件提位 → 板面零线外 → `load_bearing_full` = True（cw_launch_admission.py:199）→ armed = True——**翻转由级联自身造成**（S7-2 已点名的常态后果；S7-2 的 bridge 谓词只防短路抢先，不防受限判定翻转）。
  4. **回店撞闸**：级联完成清槽 → 扫描第 5 步开店 → visit 入口现算受限（shop.py:755）：armed=True ∧ gold（原金 + r）≥ g* → 受限 → X 买入提案（此时金够位有，不走让位评估，直接提案）→ 闸 `gold − cost ≥ saturation_line`（flow.py:802-804，cw_launch_arbitration.py 同式）：花后 ∈ [0, g*) → **拒 → CloseShop**。数值例：gold 38 / g* 40 / V 退金 5 / X cost 40 → 回店 43 ≥ 40 受限、闸算 43−40=3 < 40 拒。
  5. **白卖定型**：节点内金不降（受限买不进）、板面已零线外（armed 保持）→ 恒受限 → 该节点 X 永不可买 → 出战 → 下节点新货架 → **X 丢失、V 白卖**（V 资产等价转金，但卖 V 的动机〔买 X〕落空且不可再达成）。S7-4 处置申报「受限帧获取延后，**回非受限帧再评**」——该形态下「回非受限帧」没有任何驱动机制（金位轴要求金降、节点边界才换货架），与五轮 S5-8「bridge 短路不触发」（七轮 S7-2 定性为无机制裸断言、阻断）同型：**申报的结构保证与真实机制矛盾**。
