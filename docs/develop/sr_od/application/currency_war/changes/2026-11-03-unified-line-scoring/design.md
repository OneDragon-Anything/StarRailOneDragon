## 1. 动机与定谳(用户裁定链)

1. **统一一套打分规则**——不要每处定义「遇到 X 就硬选/不选 Y 阵容」;
2. **排除也用分数/评分结构表达**——无排除池等独立机制分支;
3. **分数值从效果原文/攻略实证来**——不拍脑袋;克制分档(强吃/怕/重开级)
   对齐攻略原话;**直接记载 > 类间概括**(r1/R3 判例:万敌篇「词条矩阵
   同向」概括句与姬子篇 A 节直接清单冲突,取直接清单);
4. **词缀吃怕是阵容特定知识**(深入游戏理解逐线敲定,效果泛化推不出
   方向反转);
5. 「没有 X 最好别玩」= 依赖结构的缺位表达;
6. 流派分开定义(姬子 A/B 拆分首例);不考虑词条触发换线。

## 2. 评分框架(裁决结构 r1 定稿)

**裁决结构 = 字典序 + 最高维排除位**(R1:加权和与排除语义互斥——
强吃可翻盘重开级,弃加权和;万级数值在字典序下无意义,排除类布尔化)。

```
线分裁决序(高维先比;高级定序后低维不再参与):
  第 0 维 排除位(布尔): 重开级词条/boss 命中 ∨ 硬依赖缺位
          → 命中 = 不入候选;任何加分不可翻盘(sim 锁不变量)
  第 1 维 外部分(整数,百级): 投资环境+策略+词缀吃怕+boss 克制 之和
  第 2..N 维 现行 line_score_key 五维原序(carry/骨架/插件/热度)
```

**数量级对照表**(跨面定死;档位→数值一处常数,落地时定值锁 sim):
| 档 | 值(示意) | 例 |
|---|---|---|
| 词缀强吃(顶级燃料) | +900 | 万敌×正当防卫 |
| 词缀强吃(燃料) | +600~750 | 万敌×忍无可忍/应激 |
| 投资强档(定义型/期货/定向刷新) | +300 | 黑塔纪元/契约/概念股 |
| 投资中档(星徽/引擎匹配) | +150 | 邀请/速度类策略 |
| 软档 | +30 | 弱关联 |
| 怕(词缀/boss) | −150 | 正当防卫×直伤线 |
| 软依赖缺位 | −30(限时机,见 §4) | — |
| 重开级/硬缺位 | 不走数值——第 0 维排除位 | 希儿×量子熄火 |

- 同维内部加权和(外部分求和),维间字典序——单一常数表管全部跨面倍率;
- boss 多只命中同维求和(开局 Σ三只克制,均权;位面权重差是精细档);
- 「排除位不可被外部分之和翻盘」为 sim 验证不变量。

## 3. 四面模型

### 3.1 投资环境(83 个,纯加分;底稿 env_channel_table.md)

四通道,效果原文派生(不手拍关联表):
- ①送人(立即)——证据分自动覆盖,不另加分;
- ②定向刷新率(概念股)——强档线加分;
- ③星徽(邀请)——中档;
- ④期货任务链(契约)——强档。
通用类 41 个(经济/时代/规则)线分 0。现 ENV_COMP_AFFINITY(15 键
18 条目)退役,被派生规则取代(覆盖缺口同型环境一并补齐)。

**加分目标规则(r1/R4 修订)**:通道②③④的目标线 = **form_tiers/or_reqs
(核心羁绊)命中**;flex_factions 命中降两档(近硬绑不稀释——「量子星徽
→希儿量子 0.9 单线」语义保持;万敌的量子填充位不再同档吃分)。

### 3.2 投资策略(335 个,纯加分;底稿 strategy_channel_model.md)

五通道 = 环境四通道 + ⑤战斗增益×引擎类型:
「全队速度+X%」对鞋队/拉条线(希儿/阿雅/欢愉)中档加分,对万敌 0。
模式分布:经济 58/星徽 44/送角色 ~70/装备 26/战斗 54/商店 15/经验 12/
羁绊 10/专家 7——宽松关键词模拟 44 条不可直接判定,补规则后人工补
约 20-30 条。现 AUGMENT_COMP_AFFINITY(7 键)退役。

**r1 修订**:
- 引擎匹配表**承认为手编知识表**(「前排主力线/后排增益线/暴击引擎」
  是 B1 三驱动型之外的多轴扩展——大黑塔跨「大招流+后排增益」双轴,
  承认手编而非声称派生);
- 人工补表**必查源 = lock_rules 现登记 + README A3 类专属策略**(攻略
  实证优先于句式复杂度;超光速提拔被现行裁决排除是先例);
- 随机类(随机星徽/随机角色/随机费援军,约 16 条)不可定向,期望均摊
  ≈ 噪声 → **记 0 不加分**。

**两面共同结论:投资面无显式减分**(83+335 效果全判读;全局代价不分线)。

### 3.3 敌人词缀(52 个,加减双向;底稿 affix_channel_model.md v2)

长尾 8 线——含追击飞霄,r1 补账——版本重跑补),效果原文分档仅作

兜底层默认只给「怕」不给「吃」——方向保守)。

关键结构:
- 同词缀方向逐线相反(正当防卫:万敌+900/A 反震姬子−150/B 直伤−150/

### 3.4 BOSS(开局简报前置决策)

- **可见性**:简报屏开局预览全部 3 boss + 4 词缀——开局全见;3 只都要
  打 → 开局外部分含 **Σ 三只 boss 克制**(均权;位面归属精细档,真值 =
  CollectPlaneIntel 实采);
- **数据源纪律**:boss×线以**攻略实证**为准;bosses.md「核心机制/克制
  启示」两行是采图鉴时的人工推断层(从未实机校验)——本迭代删除,
  文档回归图鉴真值;BOSS_MECHANICS tag 只作观察分组不通用映射(同名
  tag 两向实例:铁盾反击克高频 vs 纷争剥甲利高频);

- **与现行 boss_fit/matchup 的关系(r1/R5)**:该链路函数已删、消费点

  **本设计 boss 面替代之**,悬空注释随批清理入退役清单;
- **非 boss 强敌小节(r1/R7)**:红绿灯(白厄重开级,攻略多帖共识,
  已定性小怪)/扑满(姬子拖时间克,定性出处待补查)——不入 boss 20 只

- **旧名处理(r1/R7)**:存护星神/贝洛伯格加血机器入「攻略名→疑似

- **全排除兜底(r1/Y7)**:多线同时命中排除位时,排除位内按外部分
  降序取(负最少者);全线排除 → 取消候选(现行时点兜底空候选分支
  承接)——「重开」动作不在本框架(bot 不重开),最劣选局如实表现。

## 5. 流派拆分(首例:姬子 A/B;r1 终裁)

拆分证据 = **装备/副档分岔**(无冲突的硬证据:外骨骼+以牙还牙甲族+护盾2
vs 风暴潮+电锯+冷笑话+减益2);词条方向两分支**相同**(r1/R3 终裁后
拆分证据不再挂词条)。

- **列车同行·反震**(A):装备 外骨骼+以牙还牙甲族;副档 护盾2;
  词条 吃 忍无可忍/同步行动/怪物提速(受击触发类——敌方攻击=反震+盾
  循环燃料);**怕 正当防卫**(格挡类——反伤磨盾削反震基数)+能量逃逸
  +时间刺客(姬子篇 A 节直接记载,r1 终裁);
- **列车同行·直伤**(B):装备 风暴潮+电锯+冷笑话;副档 减益2;
  怕 正当防卫/能量逃逸/时间刺客(高频直伤被反);
- 共享:core 骨架/lock_rules/need_star/知识卡;特化 15% 不拆。
- **万敌篇「词条矩阵同向」句**:过度泛化错句(只对受击触发类成立,
  对格挡类方向相反——万敌以生命消耗为基数吃反伤、姬子以护盾量为基数
  被反伤磨)——随批在万敌篇标注勘误;
- **篇数口径(r1/Y1)**:双口径并注——描述口径 274 篇中 ~60%/~25%
  (final_jizi L17/L33),plaza 装备分支口径 152/127(cw_comps 注释);
  姬子篇内部 A/B 标签前后有互换(L20「A.反震」vs L203「B 套反震件」),
  随批正名(以 L20 小节标题为准);
- **拆分连带(r1/Y9)**:LINE_HEAT 274 按描述口径比例拆(A 165/B 70
  示意,落地校准);**同帧 A/B 双高分互斥裁决 = 词条面分化**(燃料词条
  局 A 上位、怕词条局 B 上位——流派切换的分数化表达,词条面同档时
  按注册序 A 先);

**白厄吃怕审定**:同构(护盾反伤版)——吃受击触发类为**结构推定**
(注释级待 sim 验证);**怕正当防卫按姬子 A 同构推定**(同以护盾/反伤
为基数);重开级 = boss 面三条(红绿灯剔后:史瓦罗/祸源萨姆,均待
映射校验);忌燃血类/回血减行动值。
