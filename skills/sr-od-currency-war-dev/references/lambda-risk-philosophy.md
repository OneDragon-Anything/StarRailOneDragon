# λ 基座与风险架构——核心观点(skill 摘要)

> **全文在 `docs/develop/currency_war/lambda-risk-philosophy.md`**(与 math_proofs 同级的核心约束)。改任何 λ_death/危险信号/战力建模相关内容前必读全文;本页只留判断要点。

1. **λ 是唯一"错了就出局"的参数**(吸收态:死=一局清零;其他参数错=少赚可恢复)。不压死亡概率,任何"贪心最优"证不出来——切换信号的存在性是数学结构要求,不依赖语料。
2. **硬闸门(用户裁定)**:仅 λ 表(血带入键)与 P15 掉血公式两处被授权消费 hp/战力数据;**其他任何战力相关内容进策略,须用户逐项确认**。
3. **姿态架构**:发展优先=默认(可证的域命题);危险信号=只升不降的升档器(血线=硬地板,λ=顾问只许提前反应禁推迟)。安全带两验收条件:①薄层不改判据本体;②**激活率门**(正确决策下触发率个位数百分比内,sim 实测)。
4. **死因实证**:旧死局 68%=「该买不买+攥钱」同根(消费被姿态压制),恰为骨架 M1-M4 义务动作直接治;A/B 验证判据基线=A1+B 塌向 C 地板。
5. **表纪律**:B1 钥匙(难度带×血带×位面×节点)定谳;实机刻度 0.34-0.85,0.1 是死阈值(原三段管辖路由由姿态架构替代);消费=区间+保守端+单调;质量门(held-out+翻转面扫描带)+四层兜底。
6. **数据通道**:实机=点火器不是燃料(结算屏遥测=每局 25 轮样本);sim 与 λ 同语料=循环,只当压力测试禁当概率来源;难度=局内读取为准+公式对账(对账偏差=漂移哨兵);监控钩子必吃带身份键的必写行。
7. **资源分配**:战力建模=机会性精修道(闲槽即做,不影响主体、新产出过硬闸门)。
