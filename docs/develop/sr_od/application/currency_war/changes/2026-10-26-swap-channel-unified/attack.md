  4. landing 3.1 完成判据「双轨域零行为差回归」在该判别子缺位时不可验收（无法陈述「双轨域」的验证域）。

### F4【应修】§2.8 来金侧「堵回降口二」前提错误：现行来金池已有资格级排除，设计的增补谓词是其真子集（no-op），真实泄露口未被盖住

- 位置：design.md:83（§2.8 口二）、landing.md:51（3.3「现行羁绊贡献仅为排序项非资格排除，需新增资格面」）
- 事实链（直调）：
  1. 来金族池（节末凑息/升级凑金，`SCENE_SPECS` 均 `POOL_BENCH_FIELD_IRRELEVANT`，`sell_candidates.py:185-191`）的**场上支准入** = `is_field_irrelevant_unit` = 非锁定线成员 ∧ **非有效羁绊贡献件**（:385-396）；`is_effective_bond_contributor` = 上场单位任一标签已有激活档（:347-364，对照 `FACTIONS` tiers）。这是**资格级排除**，不是排序项。
  2. 包含关系：「离场使终局档位下降」⟹ 该标签卖前已有激活档 ⟹ 已是贡献件 ⟹ **已被现行准入排除**。设计的增补谓词 ⊆ 现行排除 = no-op（bench 侧天然不掉档，同样无事可堵）。
  3. 设计依据链错在只读了 `11_shop_decisions.md` §4.0 的**排序项**（:144「卖后掉档置后」，代码 = `bond_tier_drops_if_sold` :367-382 排序腿），漏读同表**候选池列**的「场上无关角色」——其代码定义正是上述资格谓词（契约 D/2026-10-13 裁定，:351-356 口径申报明载）。
  4. 真实泄露口：**无任何已达成档的支撑标签件**（如能量<3 帧板上的能量标签外部件）经来金池可卖 → 支撑数可回降——这正是设计自己陈述的病灶，但其谓词（档位下降才排除）按构造盖不住它（无档可掉）。其引用的教义（「哪怕下远坂凛都不能拆能量」，`cw_comps.py:1034` 实证）指向的谓词是**终局键集标签命中件一律排除**，而非「档位下降」。
- 修正方向：依据链改为 `sell_candidates.py` 装配实证；谓词改为「终局 form_tiers 键集标签命中的场上件不入来金池」（零参数、与教义同向、兼修 F5），或如实申报现行已覆盖面并把口二改指向真实泄露；landing 3.3 范围句与 prereg 清单 FM-1 行（「来金资格排除可能减少卖出收入」——no-op 下无收入变化）随之改写。

### F5【应修】§2.8 全局单调论证前提为假，P61 接替的终止保证按文不成立

- 位置：design.md:84（「板上支撑数全局单调非降……纯结构计数论证，零参数」）、design.md:105
- 事实链：换人通道内支撑数非降成立（换入恒支撑件、victim 非名单），但跨通道不成立——① F4 的泄露口：无已达成档支撑件经凑息/凑金可卖，支撑数 −1 且档位不变；② 升级凑金「活期任意星级可卖」（`11_shop_decisions.md:128`）可卖 2★ 非承载件，星级势可降。门 1 各支的严格增势函数（支撑数/档位/星级）均可被来金通道往复消解，「全局单调非降 + 上界有限 ⇒ 触发有限」的三段论前提为假；「纯结构计数论证」实际需要跨通道有界性（轮次/金），已非纯结构。
- 修正方向：与 F4 合并修——排除谓词加宽到终局标签命中件后来金通道不再动支撑数，单调论证即可在真前提上重述；星级面单独处理（升级凑金的 2★ 支撑标签件同入排除，或如实申报该支的有界性依据）。
