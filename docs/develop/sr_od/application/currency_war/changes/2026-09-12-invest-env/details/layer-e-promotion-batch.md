## 1. 判定结论(先读这节)

**准入门第 1 条(全通道重算)完成;第 2 条(序一致性检验)未通过 → 维持 fail-closed,`STRAT_POOL_ECON_MEANS` / `OFFER_QUALITY_DIST` 继续哨兵不落,现行为零变化。**

- 净帧全通道 μ_E 点估计:棱彩明确居首;银 ≥ 金 残差未翻转(H=23 差 +0.0155,H=15 差 +0.1004),详设 §2.2.2 要求的品质序(棱彩>金>银)方向不一致。
- 统计辨析(如实申报,凭据出自重采入口输出):残差深居卡池抽样噪声内——三组成对差值 bootstrap 95% CI 全部含 0(μ_棱彩−μ_金 H=23 = [−1.3295, +4.3074],μ_金−μ_银 H=23 = [−2.1610, +2.1337],μ_棱彩−μ_银 H=23 = [−1.1403, +4.2334]);「违序」是点估计层面的判定,严格按设计条文执行。若改用「统计不可分辨 ≠ 违序」的宽读法,属设计裁决变更,归设计批/编排者裁定,本数据批不代裁。
- 与详设初测(受限通道 银 3.31/金 2.42/棱彩 4.16 @H=24)对照:全通道补参把 金−银 差从 −0.92 收敛到 −0.02(H=23),方向修正幅度 +0.90,但未翻转;净帧相对 r1 混帧读数仅微移(银−金 +0.0101 → +0.0155),采样面缺陷不是判定翻转项。

**落参前置门(两件同时满足后随批落参)**:①序一致性复过(全通道净帧口径);②取卡序 3 的视界 H_3 与 π_offer,3 缺位补齐(当前有效样本 n=3)。缺任一件,时代(彩虹/黄金/白银)/尾彩通道结构性缺参 fail-closed;头彩(k=1)虽参数在案,同受准入门约束不单飞。

## 4. 全通道口径(μ_E 公式的通道集)

μ_E(q; H) = 品质子池内逐卡全通道金流期望的均值;子池 = `INVESTMENT_STRATEGIES` 按 rarity 分键(实测 |S_银|=77 / |S_金|=135 / |S_棱彩|=123)。v1 受限八通道(详设 §2.2.2 `econ_gold_v1`)原样保留,排除集按准入门第 1 条补参:

| 通道 | 公式(窗口 = 取卡后 H 节) | 参数源 |
|---|---|---|
| instant_gold / gold_per_node×H / interest_flat×H / xp_per_node×H / xp_instant | 线性,零参数 | 注册表值 |
| gold_per_boss_node | × 窗口内首领槽数(结构 {9,16,25}) | §3 |
| gold_next_nodes_amount | × min(count, H) | 注册表值 |
| gold_at_level | × P(等级≥9 @ 窗末)——语料未达尾段冻结在最大观测节点值(0.333) | 档案逐轮 level |
| gold_at_node(超发货币 +70) | 时点金,offset ≤ H 全额(负债腿按注册表既有口径由消费端记) | 注册表值 |
| 免费刷新 burst / 每节点 / 条件族(50/10/3) / 概率事件 45% | 节金 = min(可发次数, **E(窗口总刷新次数)**) × 基价 2 | 档案逐轮 RefreshShop;条件族授予按观测金路径逐节点 E[授予数] |

## 8. 序一致性检验:逐通道残差诊断(回炉候选清单)

净帧银−金 池均值逐通道分解(H=23,+ = 拉高银;表列主要通道,合计以 μ 差为准,未列小通道合计约 −0.0001):

|---|---|---|---|

| instant_gold | 1.9091 | 1.3556 | **+0.5535** |
| 免费刷新 burst | 0.4434 | 0.1481 | +0.2952 |
| xp_instant | 0.1818 | 0 | +0.1818 |
| at_level(成长基金,银) | 0.1732 | 0 | +0.1732 |
| gold_per_node(定期福利等) | 0 | 0.6815 | −0.6815 |
| at_node(超发货币) | 0 | 0.5185 | −0.5185 |
| next_nodes(长期主义系) | 0 | 0.3556 | −0.3556 |
| sell_mult(大裁员/降本增效) | 0 | 0.2103 | −0.2103 |
| 每节点免费刷(加油站族) | 0 | 0.1196 | −0.1196 |
| **合计** | **3.4167** | **3.4012** | **+0.0155** |

诊断:restricted 面的原发病(银池纯金流卡 vs 金/棱彩价值在功能半与被排除通道)在全通道补参后大幅收敛(金−银 从 −0.92 到 −0.02),**残差主体 = 银池特战资金系的首领槽通道(+0.70,3 槽口径)对金池时点/流式卡(+0.52 超发 + 0.68 每节点 + 0.36 分期)**;净帧剔除扑满局后残差仅从 +0.0101 微移到 +0.0155,采样面缺陷不是判定翻转项。回炉候选(归设计批裁定,本批不代改):

1. **特战资金系首领槽口径**:窗口含 P3 末槽(node 25,语料零观测纯结构外推)与 P2 末槽;若首领槽先验收窄(如只计已实证槽 {9,16}),银 −0.23/槽,残差翻转——但这是「为过门而调口径」,须先有独立证据定 P3 槽结构,禁倒因为果。
2. **纯金流卡的功能半不可基数化**:尾款交付/成长基金/特战资金的裸分(知识评估)已承载其功能价值,层 E 再计其全额金流 = 两层重复计价的结构性问题(层 Q 与层 E 的分账边界),回炉方向 = 层 E 是否只辖「品质差异量」而非「卡的全额金流」。
3. **截断误差分布不均**(§5):补齐 P2 末段/P3 语料(通关局)后重采,金池流式通道的低估会缓解。
4. **层 Q 残域通道**(采购专员/连胜倍率/远见期权)继续按 0 申报,除非出现可参数化的金流口径。
