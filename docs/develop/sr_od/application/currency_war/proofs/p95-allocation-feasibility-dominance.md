## 1. 命题

设备战帧 f 上的分配对 (e, c)(装备 e ∈ owned,角色 c ∈ deployed)。若游戏对 (e, c) 的穿戴请求**以概率 1 拒收**(拖拽物理成功但游戏拒绝写入,icon 区零变化),则:「分配前把 (e, c) 排除出候选(件 e 留 owned)」严格支配「照常分配 + 拖拽失败后补救链重试 + 失败拉黑」——排除支无任何收益损失,重试支有时间成本与记忆污染,且不存在补偿收益路径。

## 2. 前提(全部机制事实或已证结构,零自由参数)

- **A(必拒判定可前置)**:三类拒收机制的判据全部是分配时点可计算的游戏定义量(证据分级:【直证】=原始日志/注册表直读;【推断】=反推,定谳前保守拦截,见边界②)——
  - W1 同名不可合成对拒收:c 身上已穿(含穿着即合成产物展开,`cw_synthesis` 配方图【注】)含与 e 同名**且 (e, 同名件) ∉ 配方图对集**的件 → 游戏拒【推断级:#8 永动机→三月七 diff=0.0 为同名+槽满混叠,同名单因未直证;定谳前按必拒保守拦截】。**辖域收窄(R1-F1)**:同名对 ∈ 配方图(8 基础件全有自配配方)时**不属本谓词**——那是「穿着即合成」的合法同名自配穿入通道(实机活体:17:06 光能电池×2→三月七两次「穿了」、08:38 生命之花→丹恒·饮月身上已有生命之花仍穿上合成生命之环),归 `_pairing_guard_ok` 例外①(core 快路径)②(回收线 2合1)既有辖域;W1 拦域(同名∧非配方对,全为非基础件)与该两例外域(基础件配对)**交集为空 = 显式互斥**,落码不拦合法合成通道(P95 §5「零该穿未穿」验收线保全);
  - W2 前置拒收:件 effect 明文穿戴前置(注册表 :93/:163「需要空装备栏才能装备」)不满足 → 游戏拒【直证:随便骰子·特权→希儿 2 件 diff=0.1,前置原文白纸黑字;精确读法(全空 vs ≥2 空槽)待实测,定谳前取最保守「有任意件即拒」】;
  - W3 目标类拒收:骇客改件对非相容目标恒拒(实机:欢愉卡带Max×4 跨 2 角色跨槽态全败;具体合法装备者待实测定谳,定谳前 fail-closed 收窄不改变支配结构——排除支损失面只会更小);

- **B(拖拽失败成本,实机实证)**:必拒不因重试消失(游戏规则拒绝 vs 拾取间歇漏识的区分:本命题辖前者;后者由补救链参数升级对抗——**现存可复算口径:保留窗补救链挽回 0/10**【直证,阶梯执行报告 §L3 量化总表+T40_l3_log_extract.txt 复算命令】,即全部进补救链的规则性拒收无一挽回;代码注释所载历史台账「retry 仍败 6/6」(`cw_op_equip_all.py:123-126` 历史批注)系已灭失台账的转写值【转写来源=引文链,原始行不可复算】,仅作方向旁证不入数字表)。每对失败走补救链三档(`_WEAR_RETRY_PARAMS`,hold 0.5→0.8→1.1s + duration 逐档 + 两次稳帧)= 日志实测 ~13-18s/对;拖拽失败拉黑(连败 2)后该对局内永久剔除。
- **C(排除支成本下界)**:排除后件 e 留 owned,机会成本 = 滞留至下一合法目标出现的间隔。该间隔与重试支的失败序列出现在**同一帧域**:重试支的 ~18s 白拖本身消耗同一备战帧预算(发射序拥挤/闩跳风险随执行时长上升),且白拖后件同样滞留 owned(拖不上)。故滞留成本两支相等,差项只剩白拖时间与记忆污染。
- **D(无补偿收益路径)**:必拒对的拖拽无任何信息增益(CV-diff 判「落空」是二值,重试不改变判定;拉黑记忆在排除支同样可由谓词直接给出)。

## 3. 证明

两支逐项对账(同帧域、同件、同目标):

| 项 | 排除支 | 重试支 |
|---|---|---|
| 件 e 帧末位置 | owned(滞留) | owned(拖不上,滞留)——**相等** |
| 帧内时间消耗 | 0 | ~13-18s 补救链三档——**排除支严格小** |
| 拖拽失败拉黑记忆 | 不产生(谓词即知) | 2 败后产生;且失败前 1 败的对保留重试资格(下一帧再白拖一次)——**排除支严格小** |
| 帧/执行预算副作用 | 无 | 补救链延长装备 pass,挤压同帧其他动作窗口(CwScreenPrep 单轮),跨帧重派次数上升——**排除支严格小** |
| 收益 | 无 | 无(必拒不产生穿戴)——**相等** |

排除支在全部差项上不劣、至少三项严格优,且 D 消除补偿路径 → 严格支配,∎。

**边界声明(辖域)**:①本命题只辖「分配时点可前置判定的必拒」(前提 A 三谓词);执行期偶发拒收(拾取间歇漏识/动画未收尾)不可前置判定,归补救链/拖拽失败拉黑既有兜底,本命题对其零主张。②推断级谓词(W1 同名单因/W2 精确读法/W3 装备者真值)定谳前的 fail-closed 扩大排除域(疑似必拒也排除):由 A 的分类讨论,扩大只会增加「件滞留 owned」面(C 项两支相等的前提仍成立——被排除的疑似对若实为可穿,其真实拖拽收益损失属错杀成本,须在谓词收窄时对账;实测定谳是唯一消除法,故 W1/W2/W3 各带定谳义务挂账 T-13 §6-1/§6-2/§6-3,定谳前统一保守拦截,与 W3 同款处置无双标)。③W1 的收窄辖域(同名∧非配方对)与 回收线/core 快路径(`_pairing_guard_ok` 例外①②)显式互斥(两域交=空),落码不产生「该穿未穿」新增——这是本命题实机锚(§5)的前置保全。
