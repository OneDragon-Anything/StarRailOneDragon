# DD-003:跨位面剩余节点数实现缺陷登记——`total_remaining_nodes` 对全部位面写死 9,L 换轨前必修

> 状态:已登记的实现缺陷(2026-09-01 亲跑证伪;P46_ADV_R3 Z1)。
> 晋升来源:原裁决记录于 `docs/develop/currency_war/proofs/validations/P46_ADV_R3*.md`(临时文件,已清理)——本件为其持久化,p46/p40/p47 的「Z1」引用以本件为准。

## 背景

`ev.cross_plane_remaining_nodes` 现行实现经 `total_remaining_nodes` 对**全部位面写死 9**,与位面实际长度(P1=9/P2=7/P3=9)不符。亲跑证伪数据:P1r9 → 19(真值 17);P2r7 → 12(真值 10,P2=7 未进计算)。文档侧的 R_全局 口径(当前节点 + 后续位面按实际长度求和)是正确口径;实现是**待修缺陷**,非同口径。

## 裁决

1. 规范口径 = 位面实际长度(`schedule_of` 生产自适应,P1=9/P2=7/P3=9);`NODES_PER_PLANE=9` 仅是 P1 值,不得作全局常数。
2. 过渡式 C = t×min(R_全局, 3) 下 cap=3 吸收该偏差(约 +2 节点),可容忍至过渡期结束;
3. **硬门:p47 L 递推换轨(无 cap)前必须先修该函数**,否则 +2 节点偏差焊进 L。Phase 3 新实现按 `schedule_of` 实际长度重写(cw3/math/node_schedule.py 已按此实现)。

## 约束范围

- p47 L 全消费方(p38/p39/p40/p41/p46/p48)的换轨前置条件;
- 旧树 `ev.py` 的死亡条件登记(修复或随新层替换)。

## 出处

- 亲跑证伪:P1r9→19 vs 17、P2r7→12 vs 10(P46_ADV_R3 Z1,脚本口径);
- 消费点:proofs/p46(A1 行)、p40(R2 预算门)、p47(A6)。
