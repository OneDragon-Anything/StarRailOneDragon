# ADR-0370: 升级相对账零修法裁决(never-2 残差非升级授权滥用)

- 状态: accepted
- 日期: 2026-08-29
- 关联: W170 §5(残差移交:「never-2 局金穷态,LevelUp 吞噬找牌预算,
  归升级相对账批」)/ ADR-0347(W119 升级门 EV 总账)/ ADR-0349(W126
  保险丝)/ ADR-0354(授权依据观测)/ ADR-0369(前批,残差定性出处)

## 背景与问题

W170 将 never-2 成型局(两套引擎到死没凑齐第二套)定性为「金穷态:
金 11-53,r2 连升 lv3→6 常态——升级花的钱把找牌预算系统性吃掉」,
移交本批修「升级(LevelUp)与找牌/买入的相对期望账」。三个候选修法:
a) 人口位判据收紧(bench 件须∈锁定目标集,散件不算「等着上场」);
b) 升级 EV 化(与买入/找牌同账比较);c) 早期升级节奏窗(r1-r4 上限)。

## 判据探针(W172,monkeypatch `ev.levelup_ev_basis`/`arbiter.levelup_ev_basis`,
零行为改动;seeds 0-99,inject on,planes=2,池指纹 861fc9f67964a8d4,
never-2=11/100,4865 次授权调用全量快照;数据
`.debug/temp/currency_war/w172_lv_probe/`)

| 判据 | never-2 局(P1) | 其他局(P1) | 裁决 |
|---|---|---|---|
| 升级总花费 lv_spend | 44.4(中位 48) | 47.6(中位 48) | **never-2 花得更少,非差分根** |
| 升级次数 n_levelups | 11.1 | 11.9 | 同上 |
| 早期连升(r1-3 ≥6 击)占比 | 3/11(27%) | 30/89(34%) | 早期连升不预测 never-2 |
| pop_slot 授权帧 cap 满 | 113/113(100%) | 1015/1015 | [33] 字面前提全成立 |
| pop_slot bench 命中件=目标件(engine/core/pair) | 80%(纯散件触发仅 20%) | 70%(纯散件 30%) | never-2 判据**更干净**,收紧 a 打不中残差 |
| pop_slot 花后 <50 | 99% | 99% | 全局常态(W126 保险丝语义),非差分 |
| 授权时金 <20 占比 | 55% | 58% | 无差分 |
| dp/static_ev 授权时金 | 全部 ≥55 | — | 平台未破,无滥用 |
| P1 总收入 income | 91.5 | 88.2 | never-2 收入还略高 |
| P1 买入花费 buy_spend | 23.4 | 17.3 | never-2 买得**更多**(在追件仍凑不齐) |
| hp_loss | 62.2 | 57.5 | 板弱流血多=症状非根 |

**结论:升级授权在 never-2 局没有滥用**——[33] 人口位判据字面成立
(cap 满 ∧ bench 有 engine/core/pair 目标件等着),升级花费与全池持平
甚至略低,dp/static_ev 臂全在息平台上。「金穷」与 never-2 共存但
升级不是差分根:never-2 局收入不低、买牌花费更高仍凑不齐第二引擎,
指向**供给/来牌运气形态**(W170 probe4 旁证:eng 卡 1 缺第二引擎、
core copies0=从未入手)。W170 §5「升级吞噬找牌预算」的因果表述据此
修正为「金穷与升级共存,升级花费非差分根」。

## 决策(Decision)

1. **零修法收批**:三候选全部否决,策略行为零改动,不立新 flag。
2. never-2 残差的后续方向=供给侧(来牌/池可见性),不是升级通道;
   归编排者按 W143 §7.2 供给域另行立项。
3. 人口位判据维持 ADR-0347/0349 现语义(cap 满 ∧ bench∈
   engine∪hoard char_targets);纯散件触发 pop_slot 的帧在全池占
   20-30%,为已知观测面,无差分证据前不动(见 Considered Options)。

## Considered Options(否决)

| 选项 | 否决理由 |
|---|---|
| a) pop_slot 目标集收紧(散件不算「等着上场」) | never-2 局纯散件触发 20% **低于**其他局 30%——收紧对残差无因果链,反先打中良性局;人口位判据实况(cap 满 100%+目标件 80%)与 [33] 口径相符 |
| b) 升级 EV 化(与买入/找牌同账) | 升级花费非差分(44.4 vs 47.6),且 never-2 局买入已更高(23.4 vs 17.3)——把预算从升级改道买入没有可挪的钱差 |
| c) 早期升级节奏窗(r1-r4 上限/间隔) | 早期连升(r1-3 ≥6 击)在 never-2 占 27% vs 其他 34%——不预测残差;全池级节奏压缩是无差分证据的行为变更 |
| 顺手收紧「纯散件 pop_slot」(全池卫生视角) | 全池 20-30% 帧但无出口指标差分;并行期禁无证据行为变更,涌现差分证据再裁 |

## 影响(Implication)
