## 1. 动机与定谳(用户裁定链)

1. **统一一套打分规则**——不要每处定义「遇到 X 就硬选/不选 Y 阵容」;
2. **排除也用评分结构表达**——无排除池等独立机制分支;
3. **分数值从效果原文/攻略实证来**;克制分档(强吃/怕/重开级)对齐攻略
   原话;**直接记载 > 类间概括 > 机制推定**(三级证据序,r1/R3 判例);
4. **词缀吃怕是阵容特定知识**(效果泛化推不出方向反转);
5. **依赖不特殊处理**(r2 用户裁定):投资定义卡在场加分、缺位 0 分,
   分数自然竞争——无缺位折扣、无排除位特判(万敌词缀底线式为独例,
   区别=攻略语义强度:万敌「无环境不选」引擎空转 vs 大黑塔
   「基本不存在但有 6/38 变体例外」);
6. 流派分开定义(姬子 A/B 拆分首例);不考虑词条触发换线;
7. **策略即时锁退役**(r2 用户裁定:接受)——现行「定义卡到手 P1 即锁」
   改为加分+P2 时点兜底。

## 2. 评分框架(裁决结构)

**裁决结构 = 字典序 + 最高维排除位**(r1/R1 定稿:加权和与排除语义
互斥,弃加权和)。

```
线分裁决序(高维先比;高级定序后低维不再参与):
  第 0 维 排除位(布尔): 重开级词缀/boss 命中 ∨ 万敌燃料底线缺位
          → 不入候选、不被硬锁返回;任何加分不可翻盘(sim 不变量)
  第 1 维 外部分(整数): 投资环境+策略+词缀吃怕+boss 克制 之和
  第 2..N 维 现行 line_score_key 证据五维原序(carry/骨架/插件/热度)
```

**数量级对照表**(跨面定死;落地一处常数,sim 锁值):
| 档 | 值 | 例 |
|---|---|---|
| 词缀强吃·顶级燃料 | +900 | 万敌×正当防卫 |
| 词缀强吃·燃料 | +750 | 万敌×忍无可忍;姬子A×受击触发类 |
| 投资强档·定义型 | +500 | 黑塔纪元/专家邀请/飞光 |
| 投资强档(期货/定向刷新) | +300 | 契约/概念股 |
| 投资中档(星徽/引擎匹配) | +150 | 邀请/速度类策略 |
| 软档 | +30 | 弱关联;flex 命中降档落点 |
| 怕(词缀/boss) | −150 | 正当防卫×直伤系/姬子 A·B |

- 排除类不走数值(第 0 维);重开级/底线缺位唯一;
- **flex 降档边界**(r2/Y2-9):强→软(+30)/中→0/软→0,只降不入负;
- 同维内部加权和(外部分求和),维间字典序;
- boss 多只命中同维求和(开局 Σ三只克制均权;位面权重差=精细档)。

## 3. 四面模型

### 3.1 投资环境(83 个,纯加分)

四通道,效果原文派生:①送人(立即)——证据分自动覆盖不另加分;②定向
刷新率(概念股)——强档;③星徽(邀请)——中档;④期货任务链(契约)——
强档。通用类 41 个线分 0。现 ENV_COMP_AFFINITY(15 键 18 条目)退役。

**加分目标规则**:通道②③④目标线 = form_tiers/or_reqs(核心羁绊)
命中;flex_factions 命中按 §2 降档表(强→+30/中→0)——「量子星徽→
希儿量子单线 0.9」近硬绑语义保持,填充位不再同档吃分。底稿生成逻辑
按本规则重写(仅去截断不够,r2/Y2-8)。

### 3.2 投资策略(335 个,纯加分)

五通道 = 环境四通道 + ⑤战斗增益×引擎类型。引擎匹配表为**手编知识表**
(B1 三驱动型的多轴扩展:大招流/受击流/行动流/前排主力/后排增益/暴击
引擎——大黑塔跨双轴);人工补表必查源 = lock_rules 现登记 + README
A3 类专属策略;**随机类(随机星徽/随机角色/援军,约 16 条)记 0**
(期望均摊≈噪声)。现 AUGMENT_COMP_AFFINITY(7 键)退役(消费点迁移
见 §6)。

**两面共同结论:投资面无显式减分**;相对劣势由加分差自动产生。

  A 节直接记载);

  **无吃档**;

  在手→B 证据分高→B 上位)——攻略作者语义:装备决定流派,词条只
  决定 A 上不上;「怕词条局 B 上位」「A 怕加权」两案废弃;

## 6. 锁定语义承接与落地接口(r2 新增——二轮 5🔴 的共同根)

**锁定流程改造**(R2-1):
```
候选构造 = compute_candidates(现行) → 排除位过滤(第 0 维命中剔除)
硬锁 = hard_lock_hit_lines 仅剩角色型命中(策略型退役)
       ∧ 排除位过滤后返回(排除线不被硬锁救回)
时点兜底 = P2 触发后候选首名(空候选→现行空候选分支承接)
```
- 策略即时锁退役:现行「定义卡到手 P1 即锁」→「加分+P2 兜底」,
  sim 必测(见下);
- 排除位优先于角色硬锁(被克死的线核心在手也不锁——攻略语义
  重开级=别玩)。

  单一源双端消费;
- ENV_COMP_AFFINITY 的 invest_env/gift_value 侧消费同批迁移。

**批 1 接口**(Y2-7):

  plane_bosses,开局简报已写入)现读,证据五维改**命名访问**
  (evidence_gate 的 `[:4]` 切片随批重定义——插维后切片错位);
- **sim 必测场景**:①定义卡到手后锁点推迟至 P2(即时锁消失)②排除位

  入选(大黑塔变体路径)⑤fuel/affix 表键全命中(无死键)。
