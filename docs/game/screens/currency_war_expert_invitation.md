# 货币战争-备战-专家邀请函

## 何时出现

备战席「书册卡」道具(青蓝卡+白色书册 icon+「开启」,占 1 备战席槽)点开后弹出。2026-08-30 停机钩子首捕实机帧(slot5 书册卡,点槽中心开启)。

## 状态流转

- 入口:备战席槽内书册卡 → 点槽位中心(选中即开启,单次点击,与典籍「点两次」不同)→ 弹出本屏。
- 出口(选择):点任一角色卡(候选 4 角色,带 流派+阵营 双标签)→ 该角色入商店(由正常商店逻辑接管购买)→ 弹窗关、回备战、槽腾空。
- 出口(经济兜底):点「现金为王」卡(金项,+4 金)→ 弹窗关、回备战。
- 放弃出口:未见可见关闭按钮(建档帧右上 × 区域属底层备战屏按钮);**不建关闭路径**——本弹窗必须选一项推进。

## 识别特征

- id_mark:`标识-专家邀请函`(950,40-1100,80,lcs 0.9;**组合辅助**:`提示-请选择1个` 780,82-1270,114)。
- 弹窗为居中横幅 modal:盖住备战中上部(节点条/前台区域),**左侧羁绊面板与底部备战栏仍透出可读**(羁绊面板 OCR 正常命中,选卡决策的 board 输入在本帧可读)。

## 可交互元素

| 元素 | 位置(pc_rect) | 行为 |
|---|---|---|
| 卡-1..卡-4 | (368/637/906/1175, 140-405) 四卡等距(pitch 269) | 点卡选择该专家 → 入商店,关弹窗回备战 |
| 卡-现金为王 | (1444,140-1682,405) | 点选 → +4 金,关弹窗回备战 |

## automation 要读信息

- 每张角色卡的**阵营标签**(卡下部标签行,y≈332-360:贝洛伯格/星核猎手/仙舟等)与**角色名**(名字条 y≈364-398)→ 选卡决策输入:选与当前主力阵营(羁绊面板 OCR,`cw_observation.read_board`)同线的角色;无同线 → 现金为王(经济兜底)。判据实现见 `operations/handlers/handle_bookcard.py` 的 `choose_expert_index`。
