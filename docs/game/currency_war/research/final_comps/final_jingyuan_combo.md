# 景元·连击召唤(A3 · 1 费 carry · 双峰流派)

> 一句话定位:1 费景元(云上五骁+召唤成员[图鉴])靠队友拉条多动叠「神君」层数打爆发的低费套,帖内黑话「牢景/超模哥」;存在两个构成、节奏都不同的流派——低费赌狗流(奇缘星魂刚需)与速升体系流(真 C 常是丹恒·饮月),共享同一条功能链。
>
> 家族注:与「那刻夏·连击」(A1)同属连击 turbo 家族的 1 费档——搜牌曲线同为 5-6 级低费搜牌;但景元装备面(电锯+斩舰刀+斩首行动)与那刻夏签名(风暴潮+反螺旋)分化最大,是家族内差异最大的换 C。

## 1. 骨架

- **主 C**:景元(1 费,后排输出[图鉴];17/27 篇成 3 星,1 星仍标【C】的 8 篇多为速升峰挂角局)。
- **前期过渡**(帖间一致):瓦尔特(开拓银轨+伤害,帖内「老杨」)、那刻夏、3 持续伤害+2 仙舟舰队 组合,任选。
- **功能链常驻**(拉条链为核心):
  - 知更鸟·晴歌(2 费,帖内「水鸟」,22/27 篇在场,本篇最高频辅助):拉条链成员 + 辅助装备承载位(电磁弹射器/蓄能帆/信心注入器);
  - 星期日(2 费连击,20/27 篇):信心注入器/电磁弹射器/反重力皮靴(拉条鞋);
  - 花火(2 费):前台拉条 + 蓄能帆;寒鸦(4 费连击):拉条 + 反重力皮靴 ×2;
  - 白露(2 费,25/27 篇):奶位;风堇/藿藿:第二奶;
  - 刻律德菈(1 费连击):电磁弹射器;昔涟(4 费):永动机;知更鸟(2 费):前台;
  - 三月七(1 费):武器大师 ×3——提供前台强度,低费池里易自然三星;长夜月(1 费):胜利之旗;
  - 丹恒·饮月(5 费)+丹恒·腾荒:双龙吟 2,强化选连击(帖证「双龙 buff 选连击」),速升峰常任真 C;
  - 镜流/刃:三星景元失败时的接棒 C;雪衣:血牛;星神★阿哈/翡翠/真珠+托帕:赌狗经济件;希露瓦:帖内「人形装备」口径。
- **羁绊档位目标**(数值 = 注册表原文[图鉴]):两大底盘对应两大流派(见 §6);公共副档:小小巨人 2-3(敌方全体易伤+减其输出)、治疗 2(全队 12% 伤害减免)、云五 2-4(「五骁连携」300% 基础伤害 + 全队 10% 伤害增幅可叠加)。
- **自由槽**:雪衣、遐蝶、翡翠、开拓者。

## 2. 星级目标

- 低费赌狗流(峰 A):景元**追三线**(1 费低费池概率支撑;「5 级慢搜到三星为止」),三月七顺带自然三星;辅助 1-2 星。
- 速升体系流(峰 B):景元 **2 星即用**线(「二星牢景直接干拔上九」帖证),星级资源转投全队二星/三星海或饮月;辅助 1-2 星。

## 3. 装备配方(逐件到人)

- **景元本人**(「暴击三件套」,帖间一致):
  - **高周波电锯**(幸运星+折叠小刀[图鉴];「战斗开始时装备者位于前台,幸运一击伤害提高 10%」[图鉴])——帖内「暴击刀」正名即此件,样本近乎篇篇;
  - **碎星斩舰刀**(折叠小刀×2[图鉴];大幅提高前台强度,伤害变为原 115%[图鉴]);
  - **斩首行动**(以太钻头+和平手枪[图鉴];「伤害增幅提高 30%,遭遇和首领节点额外获得 30%」[图鉴])——**本篇签名装**:样本 10 篇全部挂在景元装备栏,对照镜流簇仅 2 篇挂件、阿格莱雅簇 0 篇;契合神君爆发(遭遇/首领节点增伤与快攻节奏对口);
  - **火力风暴潮**(轮滑鞋+折叠小刀[图鉴]):常见但非本体刚需——有三月七武器大师兜底前台强度的局可省(帖证口径);底盘/召唤局更常用;
  - 踩地格流:**连击星徽**(蓝钻+折叠小刀[图鉴];+20% 基础连击率,连击额外回合伤害+50%[图鉴])给景元、站位放连击地格侧,配合拉条多动——该形态下为刚需(帖级标题口径);
  - 速度散件:星航履/反重力皮靴/冷笑话引擎/光速螺旋桨;特权形态见 §6 变体。
- **丹恒·饮月(峰 B 真 C 局)**:动能激发剑 ×2 + 高周波电锯 + 火力风暴潮。
- **功能链到人**(各件独立叠加):昔涟=永动机;刻律=电磁弹射器;花火=蓄能帆;晴歌=电磁弹射器+蓄能帆(开局开技能)/信心注入器;星期日=信心注入器/蓄能帆/反重力皮靴 ×2;三月七=武器大师 ×3;长夜月=胜利之旗 ×3;寒鸦=反重力皮靴 ×2;白露/风堇=生命之环+痛觉阻断芯片等生存装;雪衣=蓄能帆+永动机;不死途(副 C 位)=行星钻地弹/胜利之旗。
- **家族禁忌**:无注册表级冲突;帖级注意——特权装堆叠流(见 §6 大运变体)同一人身上普通版与特权版同名件并存属极端形态,非常规配法。

## 4. 特殊系统件

- **奇缘星魂**:景元的账号级强化星魂(游戏内配置,plaza 数据源无注册表)——多帖标题口径「刚需/没有不建议尝试」[米游社];其增益效果描述(0T 回血/无限追击等)官方配置未收录 [社区,待实机验证]。
- **神君叠层链**(本篇核心机制口径,帖间一致):连击星徽 + 站位踩连击地格 + 多个拉条队友(晴歌/星期日/花火/寒鸦)让景元多次行动 → 神君层数拉满 → 爆发(「景元多动神君层数容易拉满,伤害很暴」帖证)。叠层的游戏内细节为社区转述,待实机核。
- **千星商会**(赌狗变体)[图鉴]:全表唯一按三星数激活的羁绊(count_mode=STAR3;「每上场 1 位 3 星千星商会角色,激活 1 级羁绊效果」)——玩法帖证:真珠+托帕平时存备战席,D 牌时上阵吃激活;三星 4 费比三星 5 费简单,商会 D 出后可卖换阵。
- **翡翠黑市**:经济件——炉子/黑市补装备与商城位(多帖跨簇一致用法)。
- **开拓银轨 2**(峰 B 配件):开拓力只买角色,不需要的角色换钱运营(帖证)。
- **主角光环**:经济类(峰 A 攒息)/战力类/连击户口(帖证「尽量拿连击户口」);「大刀主角光环需要很多小刀装备」——折叠小刀是高频基础件。

## 5. 达成路径(流向知识)

- **峰 A 低费赌狗流**(5-6 级搜牌 ×10 篇,4 连击 4 召唤底盘):
  - 位面 1:**不升人口攒利息**,5 级(激进者四级末/6 级)慢搜三星景元——帖证「不升人口是防上人口后搜不到」;前期不带生存位(输出秒杀即生存,快攻口径),压力大才带白露;最晚第二位面前段(约 2-2/2-3 节点)完成三星;
  - 位面 2:三星后正常吃利息上本,补 4 连击 + 4 召唤 + 小小巨人;
  - 位面 3:阵容大成,神君爆发收割。
- **峰 B 速升体系流**(速升 8/9 ×14 篇,2 双龙吟 5 云五底盘):
  - 前期:2 星景元 + 云五过渡,能攒钱就攒钱,连胜滚雪球(「人齐先升人口保连胜,利息吃满后余钱升本」帖证);
  - 中期:2 星景元直接干拔上 8/9 躺连胜;双龙吟选连击,饮月到场接装备;
  - 终盘:全队二星/三星海,双龙吟 8 口径底盘成型。
- **成型判据**:峰 A = 三星景元 + 高周波电锯;峰 B = 景元 2 星 + 云五开 + 全队二星(或饮月真 C 接棒)。

## 6. 流派与降级

- **双峰流派判定**(构成不同+节奏不同,判为两个流派,分节定义):
  - **峰 1 低费赌狗流**:底盘 4 连击 + 4 召唤(+小小巨人 2-3+云五 2-4+治疗 2);节奏 5-6 级搜牌追三星;前置 = 奇缘星魂;强度来源 = 三星景元神君爆发;
  - **峰 2 速升体系流**:底盘 2 双龙吟 + 5 云上五骁(+连击/召唤/小小巨人/开拓银轨 2);节奏速升 8/9,2 星即上;强度来源 = 云五增伤 + 全队二星 + 饮月真 C——**此峰约 5 篇真 C 实为丹恒·饮月,景元挂角**。
- **与 H4「丹恒·饮月·双龙吟」簇的边界**(成文边界约定):判据 = 谁拿核心装备与星级资源。景元本人持电锯/斩首行动且为主要输出 → 归本篇;饮月持动能激发剑套且景元仅提供云五羁绊位 → 内容按 H4 饮月篇口径处理,本篇只保留「景元挂角」的过渡形态描述。两簇在峰 2 重叠,检索时按此分流。
- **变体**(标注帖数,强度自判):
  - 千星商会赌狗(低难向,2 篇):翡翠 20 炉子/钻石都拿,经济滚动 6 级搜;
  - 翡翠星徽链路(高难 A6+ 向,1 篇):翡翠/阿哈「电表倒转」,景元作连击+击破+追击星徽载体,一次解锁 7 羁绊——此形态强度来源非景元,归批属聚类口径;
  - 大运特权堆叠流(1 篇):景元穿风暴潮·特权×2+冷笑话引擎·特权,依赖特权获取组合(本金充裕+/爆晶矿·彩等投资门户);
  - 低难 5 人速刷(1 篇):不加人口省动画时间,一位面奖励关后 D 三星;
  - 暴杀流(1 篇):5 级全队三星海(含 2 费牌全三星),低费池+经济投资极限形态。
- **降级路径**(帖证指令级):
  - 三星景元失败 → 主 C 转镜流 + 刃(与镜流簇互为过渡,双向帖证);或丹恒·饮月接棒(峰 B 常态);
  - 没有奇缘星魂 → 不建议玩本篇(多帖一致);
  - 雪衣抓不到 → 瓦尔特顶替;缇宝↔星期日(没连击户口时);水鸟非刚需可省;遐蝶↔三月七;瓦尔特后期伤害不够就卖;
  - 生存压力大 → 水鸟+风堇 换 星期日+寒鸦 组 4 召唤 2 连击;优先拿符玄。
