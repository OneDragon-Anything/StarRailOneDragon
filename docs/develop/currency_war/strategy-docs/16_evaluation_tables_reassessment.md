# 16 评估表体系重估（ADR-0519 维持项条款的另批辖落定）

> 体例：按 ADR-0519（`../decisions/0519-empirical-scores-retirement.md`）的处置三分类（保留/改形/退役）+ 逐项依据 + 影响面 + 重derive 挂账格式书写。

> 判据源：00_framework §1 宪法四条 / §6 数字三形态（01_math_framework §6）；01 §4 无数学待立项面（事件决策行）；13_pick_family（pick 族知识判据定位 + §3「事件判据禁自带数值」纪律）；14_p1_consume_arms v4.2.2（消费臂新架构对照基准，落码检查点 1-2 = commit 635a6235）；ADR-0519 维持项节（评估表体系划归本批）。
> 术语：**评估表体系** = 选卡/选项决策面上以「分数」形态存在的常量族总称；**知识判据** = 来自玩法研究/comp 知识/机制原文的非数学判据（13 号篇 §1 判据状态列的「有规格（知识判据）」）；**定序形态** = 分数只用于同族选项间排大小、不承载跨族基数语义的改形目标形态；**消费点** = 消费该表的在产代码位置。

## 0. 重估通则（先立尺，再逐表过堂）

1. **消费点是否仍活**是存废前提：消费点已死或被消费臂取代 → 退役；活 → 进入合规审。
2. **合规审的尺**不是「分数是经验值就退役」，而是三问：
   - 该决策面是否**必选面**（UI 强制三选一/二选一，无「不选」动作）？必选面不能 fail-closed 到不选——退役必须以替代判据承接，否则无从退役；
   - 该分数的**结构方向**是否有出处（玩法机制原文/注册表结构/用户偏好轴/comp 知识）？方向有出处的部分可保留为知识判据；
   - 该分数的**幅度**是否有推导？无推导的幅度不得承载基数语义（与其它分值族相加/相减、被阈值比较），只可承载同族定序语义——这是「改形」的统一落点。
3. **与消费臂 v4.2.2 的关系**：消费臂（14 号稿）辖的是买/升/刷三类发射位（§3-§6），事件/选项决策面（pick 族）不在其辖域——评估表体系是证明层 target 选择与持卡登记的**上游输入**，未被消费臂取代；全部消费点 grep 复核为活（§2 逐表列锚）。
4. **归属对账**：事件面数学规格在 01 §4 显式登记「无数学待立项面」（08_events E1-E18 逐项「待 derive」）。评估表体系的最终归宿 = 事件面命题批；本批裁定的是过渡期的**合法形态与挂账**，不预支数值结论。
5. **13 §3 纪律衔接**：「事件判据禁自带数值」在本批的执行口径 = 禁**新增/上调**幅度值；既有幅度的存续以「定序实现常数」的显式降格为条件（见 §1 各表改形条），禁伪装为推导。

## 3. A_min 重测口径设计（本相位定稿）

- **厚度口径（已定，随 C1）**：`_asset_thickness`（cw_intention.py:822）= 纯终局件星级当量，骨架件不计（ADR-0519 C1）。
- **测量协议（保留不变）**：池 = `w250_delta_pool/snapshot_v11`（100 局 planes=2）；分母 = 逐策略决策帧（P2+ 段）；统计量 = 「任一异线（除当轮锁定线）厚度 ≥ a」的无条件频率曲线 f0(a)；**A_min = 最小整数 a 使 f0(a) ≤ ε（ε = revoke_miss_tolerance_eps = 5%）**。
- **决策规则（本批定稿）**：
  1. 新 A_min 按新口径 f0 的 5% 点定谳，回写 `revoke_evidence_min_thickness` 并重写注释（校准失效披露段落替换为新口径实测记录 + ADR 登记）；
  2. **分辨力弱预案（R3.1）**：若 5% 点落在 a ≥ 4 带 → 触发如实降级回炉（证据组 B 降权/换证据形态），裁决挂 L2 注入臂误开窗占比判据（开窗局新线成型 ≥2/3）；
  3. **单调性护栏**：C1 只删项 ⇒ 新口径厚度逐点 ≤ 旧口径 ⇒ 合法结果域为新 A_min ≤ 5；若测得 > 5，优先排查测量/口径 bug（单调性反证），禁直接采信；
  4. 对照曲线（任一 v2 线含锁定线 / 全帧口径，旧 f0(4)=3.68%）同批重出，供分辨力对读；
  5. 现行值 5.0 在重测完成前按旧口径校准服役（既有披露维持）；**重测未按期完成 = 按 ADR-0519「未证即退役」处置本值**（期限条款随 §4 任务书申报 owner/期限）。
- **前置检查（新增，执行批第一步）**：snapshot_v11 逐帧快照须含 C1 口径重算所需字段（终局件星级/骨架件标记可区分）。若旧池快照字段不足以支撑重算，先重采池（走 data-collection 版本重采流程），重测顺延并在任务书挂账——禁用残缺字段硬算。
