# P28 · 应急带非转化型支出的期权折扣上界

状态:**待证明(参数化)**;结构不等式与 P23.4 金零值引理同构,可半证;数值=参数化级。

## 命题

应急带(hp ≤ emergency_hp,现推导值 25)备战帧,一笔**非转化型**支出 C(买入后不解决问题:不新增上场、不合成、不构成任何羁绊激活边;含奖励轮囤件):

```
EV(C) ≤ S0_pass · V_inherit − C
```

其中 S0_pass = 应急带状态穿越本位面剩余硬节点的存活概率**上界**(口径 = `terminal_survival_upper_bound` 既有机械化链:单发穿透 K 链上界,fail-safe——上界低才触发,误放方向被压住);V_inherit = 该件跨位面继承价值的金当量。

推论:当 S0_pass·V_inherit < C 时,非转化支出**严格负 EV**,而转化型支出(当轮上场/合成/激活)凭 P20 激活边际与 P15 收益侧可独立为正——**应急带豁免必须带「当轮转化」约束**(设计 p1_iface_blood_bands 的堵洞判据;局4 实证:hp16 奖励轮买 8 张囤件+升级,全从「急救型豁免无转化约束」漏网)。

## 已证骨架(半证部分)

- **P23.4(金零值引理)**:死亡域金留到死=零价值——本命题是其前窗推广:死亡域 S0→0 则 EV≤−C 严格负;应急带是同一不等式的中间带(S0∈(0,1)),结构同构,不需新数学。
- **S0 链已机械化**:`discipline.terminal_survival_upper_bound`(ADR-0470)逐场 L/p 用既有标定单一源,本命题直接复用,不建第二账。
- **[22]④ 期权框架**:囤件的正价值=期权;期权被存活折现是标准贴现,方向无争议。

## 卡点与采集挂账

1. **S0_pass 的应急带取值**:现函数为 terminal_release(死亡域)服务;应急带需重取穿透链(hp=25 时 L≥25 的场集),表已就绪,取值是采集/离线复算活。
2. **V_inherit**:组件/副本位面继承价值的金当量未标定(与 P27 卡点 2 同账,合并采集);保守下界=卖出退金(1星=cost 全额,economy §3),上界=再遇期望损失(P1 账)。用下界时命题更强(更易证负),按 fail-safe 取下界即可先行使用。

## 检验点

- 条件复算后若应急带常规局 S0_pass 普遍 >0.8(罕见真危险)→ 「应急带禁囤件」的实际触发面趋零,设计保留但标记低收益(诚实声明,不为存在感加行为)。
- 预警带(40-50)不受本命题辖(无存活折扣争议),其禁囤件判据由 [32] 消费有效性纪律直接背书,不依赖本命题。
