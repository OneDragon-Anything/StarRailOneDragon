# 战斗-退出确认弹窗(battle_exit_confirm)

战斗暂停面板点退出位按钮后弹出的退出确认弹窗（「提示」标题 + 取消/确认双按钮，AS 文案「是否结束本场战斗？/结束后，将直接进行结算。」）。**与通用「提示弹框」族同构**（标题「提示」同位、确认/取消按钮同位——「模拟宇宙-离开楼层确认」等档同坐标），本档是**战斗退出语境**的独立识别档，供 `EnterGame` 登录恢复退出链消费。

## 何时出现 + 状态流转

- **入口**：战斗-暂停面板点「退出位」按钮（AS「结束战斗并结算」/PF「返回虚构叙事」/CW「撤退」，位置固定文案随玩法变）→ 弹出本弹窗；客户端重启恢复到暂停面板态时走同一链。
- **出口**：
  - 「确认」→ AS：节点结算页（「挑战结束/积分」页，点「退出」回选关）；PF：回玩法选关屏；
  - 「取消」→ 关弹窗回战斗-暂停面板。

## 识别特征(稳定锚点)

- **id_mark 双锚**（单词区分度差，双锚同时命中才算精准）：「标识-提示」(890,375-1030,450) + 「按钮-确认」(980,635-1360,712)，均 lcs 0.7——「提示」「确认」均为 2 字词，单锚默认阈值下 1 字子序列即 0.5 会误配，双锚组合 + 收紧阈值防御。
- 弹窗本体约 (475,360-1440,725)，模态遮罩盖住背景战斗画面。
- 红色警示行「结束后，将直接进行结算。」为 AS 形态文案，PF/CW 形态可能不同，不作为锚点。

| 按钮-取消 | 文字 (743,655-796,686)，按钮约 (573,645-928,702) | 关弹窗回战斗-暂停面板（EnterGame 不消费，未建 area） |

## automation 要读信息

- 弹窗本体即「退出操作已受理、等待确认」信号；确认动作 = 点「按钮-确认」area 中心。
- 恢复态光标可能锁定，点击带 `pc_alt=True`（自由光标下 Alt+点击无害）。

## 备注 / 待查

- **与暂停面板互不误配**（2026-11-16 实测）：暂停面板两形态帧（末日幻影/虚构叙事）均只精准命中「战斗-暂停面板」，不命中本档；本弹窗帧只精准命中本档。弹窗帧上暂停面板左上「战斗暂停」标题被遮罩模糊后 OCR 不可读——设计按「弹窗分支先于面板分支」防御性排序（design），顺序保持不变。
- FH(忘却之庭)/模拟宇宙/CW 形态的弹窗文案未实测——AS/PF 已证同构（同位取消/确认），本档按位置锚定不依赖正文文案；CW 形态（「放弃并结算」按钮）本期明确不覆盖（design §1.3），遇上有界失败。
- 本档与「模拟宇宙-离开楼层确认」等通用提示弹窗族同坐标同构：那些帧上本档双锚也会命中（is_precise）。`EnterGame` 的分支顺序（模拟宇宙/登录分支先于本档）保证语境正确消费。
