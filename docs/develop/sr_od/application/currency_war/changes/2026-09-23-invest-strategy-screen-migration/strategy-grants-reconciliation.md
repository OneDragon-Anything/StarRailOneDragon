- **本姑娘就是罗刹**：「进入战斗前，这位姑娘化身【罗刹】」系变身机制非发放，只入三月七即时腿；绑定角色罗刹不等于发放罗刹。
- **黑塔纪元**：「将216张【黑塔】加入商店」系可购买供给非发放，黑塔不入册；条件腿 = 3 星黑塔时再得大黑塔（兼有档示例，design §2.5）。
- **盗用身份**：「和1个【开拓者】」腿——开拓者 ∉ CHARACTER_ROSTER，roster-外自动排除（统一口径辖未来同类）。
- **轮回不止**：「进入第二/三位面时，再获得一次」系同角色（白厄）重复发放腿，角色集不变不入条件集。
- **月光宝盒**：「领取夜之半神奖励时，也会获得一名夜之半神角色」系随机发放不可具名，不入全集机（GiftGrant.chars_conditional 注释性字段同款纪律）；具名即时腿 = 赛飞儿/万敌。
- **梦境大舞台**：「盛会之星羁绊激活时…获得【盛会之星星徽】」系道具（星徽）发放非角色，不入角色腿；角色腿 = 花火即时。
- **迷之旅人**：「激活4【巡海游侠】时」为条件腿黄泉的触发条件（效果原文直读），两腿均条件档。

## 3. 排除清单（记因归档）

### 3.1 反扫命中而排除（3 张；反扫闭集防线的白名单半边）

| 卡名 | 记因 |
|---|---|
| 孪生姵姵 | 发放对象「姵姵」∉ CHARACTER_ROSTER（roster-外自动排除口径）；反扫命中的「佩佩」系「它看起来和你的佩佩一模一样」对比句，非发放 |
| 溜佩佩 | 「获得9金币，什么都没带的佩佩会在你的后排逛街」——佩佩系效果实现发放但**无「获得」直读引导**（「获得」govern 金币），统一排除口径的代表例；今日 off 档 0 分影响如实申报 |
| 溜佩佩+ | 同上（加强值 15） |

### 3.2 绑定母体中未入白得档（12 张——「68」数定谳的对账半边）

| 卡名 | 处置 |
|---|---|
| 停云顾问/加拉赫顾问/战术专家:佩拉/潜行专家:貊泽/琼玉专家:青雀/调饮专家:加拉赫/贸易专家:停云/锻冶专家:刃/领航专家:姬子/骇客专家:银狼/摸个鱼吧I（11 张） | 入**顾问档**（advisor=True，×0.5 折减），不占白得 68 数 |

80 = 68（白得）+ 11（顾问档）+ 1（排除）对账闭合。

### 3.3 非扫描命名的注册外观察记录（design §2.5 排除记因 4 张卡 3 类的余量）

- **快请专家·金**：「获得1个【】，4个节点后，获得2个【员工投影仪】」——空名不可具名（排除；不产反扫命中，白名单防未来文本演化后命中）。
- **快请专家·彩**：「获得2个【】，1个【好运令牌】和1个【进阶武装箱】」——同上（独立注册键，单独记因）。
- **佩佩客串/这么大的钻石**：效果提及佩佩（客串机制/携带财宝钻出现）但无「获得…」直读、非入队发放，不产反扫命中亦不入册（观察记录，非白名单成员）。

统一排除口径辖未来同类：roster-外目标与空名发放自动排除、不逐条记因（构建校验自动化判定）；现存例外已逐条记因如上。**非「获得」引导的实发放不入**（溜佩佩/溜佩佩+ 代表例已记因）。
