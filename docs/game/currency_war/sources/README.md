# 货币战争 · 外部原文存档(sources/)

> **本目录 = 外部攻略/资料的保真存档**:从米游社、B 站视频等采集的**原文内容**,按采集时的游戏版本冻结。保真纪律与管线(与 research 的关系)见 [docs/game/README.md](../../README.md)「玩法知识分层」。

## 存档纪律

- **只带来源元数据头**:每篇头部标注源链接 / BV 号 / 版本 / 日期 / 转录方式 / 已知转写误差,以及版本时效注;**原文内容一字不动**。
- **我们的批注不进存档**:代码指针、对账表、实现待办、bot 行为叙述一律不写在这里 —— 经我们提炼/核实的知识在 [../research/](../research/README.md),实现设计在 [docs/develop/currency_war/](../../../develop/currency_war/README.md)。
- **单向管线**:`sources(原文)→ research(我们的知识)→ 代码注册表 / strategy`。认知演进只改 research,不回流存档;发现存档内容有误或互相冲突,在 research 记修正/冲突 + 证据,存档保持原样。
- **版本冻结**:新版本素材 = 新文件进档(文件名带版本前缀),旧档不覆盖、不改写。

## 命名规约

- `V<版本>_阵容_<阵容名>.md` —— 单套阵容攻略(玩家视角)
- `V<版本>_公共_<主题>.md` —— 跨阵容公共知识(UP 视频课/合集直读)
- `公共_视频目录.md` —— 外部视频合集编目(来源索引 + 转录状态,存档自带的目录)

## 版本基线

现行版本 = **V4.4**(本目录 V4.4 各篇);V3.7-V4.2 各篇为历史版本存档,数值/评级随版本演化,引用前注意各篇头部时效注。经我们核实后的现行结论以 [../research/](../research/README.md) 为准。
