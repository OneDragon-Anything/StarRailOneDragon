- 三指令互斥推演（本轮独立重推，与上轮结论一致）：
  1. 按 landing「迁移到转型域判别子」实现（路由键 = 新判别子，排 pair）→ pair 板满 pre-form 帧判别子 False → :1031 关门 → **违反申报④**（该帧现行开）；
