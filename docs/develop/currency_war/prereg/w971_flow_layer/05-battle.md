## 1. 战斗等待 op

```
战斗等待 op:
  前置 = 出战后(战斗/加载画面)
  ① 等待结算画面出现(战斗结束标志;轮询结算锚;自动战斗进行中等待,检测见 §2)
  ② 结算处理:遥测读点(结算 hp 真值链/outcome/页间暂存,结算链 op 化)

    · 「备战阶段」文本(回备战;覆盖商店自动开/纯备战/列车同行 overlay 场景——
      其面板盖中上部不盖左上锚,交回后循环分发 cw_screen_partner)
    · 全屏 overlay 锚:补给「标识-补给阶段」/遭遇「标识-遭遇节点」/投资策略标题/
      BOSS 简报「标识-强敌来袭」/位面过渡(boss 局,每位面开始出现一次;
      **位面简报不在切换链上**——仅入场出现一次,用户裁决 2026-09-02)
    任一出现 = op 完成,交回循环分发。
  **终局分叉(第三出口,对抗轮 1 补)**:「前往结算」链的另一个终态 = 团灭终局
    (多页链 → 「返回货币战争」→ 3c 大局终收口)——非回备战方向;本 op 检测团灭链
    (状态机:_saw_defeat_settlement/_last_outcome_hp=0 补录随迁)→ 走终局结算读点
    → 交整局退出(CwEntryExit)。

  点击可靠性:M39 长按兜底随迁(「继续挑战」点击不响应 → 结算屏停留 ≥3 轮 →
    长按 (960,898) 兜底推进)。

```
