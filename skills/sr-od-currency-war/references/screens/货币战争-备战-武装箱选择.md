# 货币战争-备战-武装箱选择

## 画面简介

备战席开武装箱后的装备四选一画面：完整链 = 备战席箱槽点「开启」→（前置弹窗见 [货币战争-武装箱弹窗.md](货币战争-武装箱弹窗.md)）→ 本画面四候选（每卡带「查看详情」钮）→ 选卡落地；开箱需备战席有空位（箱占备战席槽，见 [货币战争-备战.md](货币战争-备战.md) 条目 5）。`is_precise` 命中本画面（建档锚：标识-武装箱 / 标识-请选择 / 装备卡-1..装备卡-4 / 区域-卡名行）。实机走查样本已补：2026-11-19（2-1 简易武装箱完整交互一例，帧 `screenshot_20261119_210314_474205.png`）；2026-11-20 局第三次完整走查 ✓——晶矿掉箱占席 → 需席空位 → 四选一全链复验（三条交互语义均再证，交互链无需改动）；画面档建档状态仍待识别批核对。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-武装箱 | 顶部标题（归档帧例「简易武装箱」）；画面身份锚之一 | 纯显示 |
| 标识-请选择 | 标题下「请选择1个」提示；画面身份锚之一 | 纯显示 |
| 装备卡-1～4 | 四个候选卡槽（x 升序 = 左→右）；卡可能同名（同装备多张，合法）；开出物样本（2026-11-19 实机）：一箱见幸运星、以太钻头；另一箱（2-1 简易武装箱）四候选 = 折叠小刀/生命之花/和平手枪/光能电池（全基础件） | 点卡**选中即确认（单步）**，无独立确认钮；选卡落地，回备战看下一帧 |
| 区域-卡名行 | 卡名行 OCR 建档带（读候选名，x 升序 = 左→右）；实测点击点 y≈337——早期建档写 y≈290 与实际不符，但按 y≈290 点击仍有效 | 选卡点击落点用此行（按卡 x 定位对应段） |
| （待建档）查看详情 | 每张卡一个「查看详情」按钮（归档帧核对在场：卡名下方、卡片底部） | 弹详情、**不选中**——选卡别点它 |

## 识别后要做的决策

四选一拿装备：读卡名行候选、按当前阵容装备需求选一张（卡可能同名——同装备多张，合法）。

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 读候选 | OCR | 「区域-卡名行」建档带 | 候选卡名列表（x 升序 = 左→右） | 卡可能同名（同装备多张，合法） |
| 选一张 | MCP `click` | 点击点 = 「区域-卡名行」对应卡段中心（实测 y≈337；旧建档 y≈290 与实际不符，但按其点击仍有效） | 选中即确认落地，回备战看下一帧 | 单步无确认钮；别点「查看详情」（弹详情不选中）；本画面由开武装箱进入（备战点箱槽，前置弹窗见 [货币战争-武装箱弹窗.md](货币战争-武装箱弹窗.md)） |
