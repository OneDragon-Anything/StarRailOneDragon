# ADR-0433:成型后过渡件不拆——[13] 停手线的卖/下场侧缺口径(方向二)

- 日期:2026-09-06
- 状态:accepted(默认关,开臂判据挂账)
- 谱系:形态达标三方向落码批(设计单一源=`.debug/temp/currency_war/w415_form_design/DESIGN.md` §2);实证基线=同 0432(「中途达过成型而最终帧不满足」拆队局实机 9 局)
- 关联:ADR-0343(成型停手,买侧)、ADR-0363(引擎下界守卫,演进事务)、ADR-0373(卖侧唯一体系引擎守卫——本批挂点面完全同构)、ADR-0400(承接口,未达时自动不辖)

## Context(为什么)

「成型后不拆」守卫已有四道(ADR-0360 保留序/ADR-0363 引擎下界/ADR-0373 唯一体系引擎/ADR-0410 买侧白名单),拆队局落在缝隙里:配方档 5→4 型(某体系冗余 1 份恰是档位构成,ADR-0373 明文「冗余件照旧」不辖)与上场人数 5→4 型(undeploy/SwapDeploy 换下场无回场窗,ADR-0363 只辖演进事务)。

## Decision(逐条)

1. **缺口径,不是新守卫族**:ADR-0373 已有先例判定(辖域缺位而非执行缺口)。做法=新谓词 `discipline.form_break_sell_blocked`(与 `sole_engine_sell_blocked` 并列):触发=`filters.formed_stop_active` 单一源(承接口未达时 formed_stop 为假,本守卫自动不辖,「继续投资」语义天然优先);规则=卖/下场候选的事务净效果使 `phase.form_ok` 翻假的,拒(判据单一源=form_ok,禁第二把成型尺;净效果=移除该件后按 `cw_state._recount_board` 派生单一源重算阵营计数再评 form_ok,与 sim 卖出执行同口径)。
2. **Considered Options**:①同纪律族补口径(本批)——[13] 停手语义本来是「成型后停手攒息」,买侧已停、卖侧允许拆=同一句话的半边执行,补齐后 [13] 三件套(买侧停/卖侧不拆/目标件照买)语义闭合;②另立「成型保护」新守卫族——与 0363/0373 判据重叠、开关面翻倍,否决;③只辖演进事务(ADR-0363 扩域)——非演进路径的常规评分卖同样拆队,辖域不足,否决。
3. **挂点面与 ADR-0373 完全同构**:`discipline.sell_priority_key`(carry_gate/两补偿器统一卖件弱序)+ `candidates._sell_tag`(三卖 tag 生成过滤)+ arbiter 卖候选采纳点对 working 复检(同批聚合净效果)。
4. **例外保留**:卖了不破 form_ok 的件(纯冗余、真垫层)照旧可卖——补偿卖序的腾位/换金通道不堵死([22] 净0 件最先卖的既有弱序保留)。
5. **辖域边界(如实记)**:现行候选流的卖通道均为 bench 位(bench 移除不改变 board/deployed,form_ok 判据面),谓词对 deployed 位件同样成立(净效果判据通用);undeploy/SwapDeploy 通道接入时本谓词即辖,无需改判据。这是「守卫口径先立、通道随接入逐个咬合」的形态,与 ADR-0373 先例(谓词先行、复检点后补)同构。

## Consequences

- 默认关=零漂移锚;开臂判据挂账(registry 注释,不执行):sim A/B 拆队局 0 ∧ benign→mal 不增 ∧ strict_mal 不升(ADR-0373 先例:卖侧守卫曾有 benign→mal 回归,回归面必查);验证不过=删码留本 ADR。
- 行为锁:`test_cw_form_gates.py`(核心移除拒/冗余份放行/默认关与承接未达帧不辖/弱序挂点通道不堵)。
