# 知识档填写指南（维护者文档·入口）

> 本文件是维护文档入口。四分结构：

| 文档 | 用途 |
|---|---|
| [templates.md](templates.md) | 各层知识档标准模板与公共红线（写档时查） |
| [methodology.md](methodology.md) | 写档判断规则，按主题分组（复盘时查） |
| [data-pipeline.md](data-pipeline.md) | 官方数据与视频调研的抓取技术路径、解析坑、ASR 归一表（跑数据时查） |
| [research-status.md](research-status.md) | 调研覆盖状态与数据快照对账（更新时查） |

维护流程：新档按 templates.md 模板写 → 判断规则对照 methodology.md → 调研轮次记入档内 → 数据重跑按 data-pipeline.md → 状态对账更新 research-status.md。
