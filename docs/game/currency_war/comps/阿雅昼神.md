# 阿雅昼神(B 级,V3.8 轮椅→V4.4 降 B)

> V4.4 合集 76807134:B 级(试用难玩)。攻略直读 [76839619](https://www.miyoushe.com/sr/article/76839619)。
> 代码字段:`COMP_LIBRARY["昼神阿雅"]`。

## 机制(怎么 work)
阿雅(阿格莱雅)速度快,**攻击力随速度提高**。**双鞋 + 风扇** → 鞋迅速叠层转前台强度 + 巨量攻击力(轻松破万)。
**昼神羁绊 3 昼神赠送一个风扇** → 完美闭环(鞋叠层+风扇=攻击力)。

## 成型阵容
阿雅(双鞋+昼神风扇)+ 缇宝 + 昔涟(3 昼神)+ 杨叔 + 主角(帮前期叠层)+ 霍霍(3 能量)+ 刃/花火/缇宝/符玄(3 量子 2 减益)。昔涟带永动机顶轴启动。

## 成型节奏
1. 自己有阿雅 → 2 星过渡上 9;试用 → 需找 3 星(运气,否则过渡压力太大)。
2. 前期没昔涟用风堇替,没主角用周日替;**队友齐全才转阿雅**,否则先别的护航。
3. **迅速上 9**,中后期偶尔赢不了没事,上 9 找杨叔+昔涟稳。

## 装备(为什么)
- 阿雅**双鞋 + 昼神风扇**(3 昼神赠)= 攻击力闭环。
- 昔涟**永动机**(顶轴启动)。

## 弱点 / 注意
- **开局 1-3 起码一双鞋,否则不能玩阿雅**(强鞋依赖)。适合"有鞋没小刀(做不了风暴潮)"的开局。
- **超光速提拔**(投资策略)很适合阿雅(不 d 一键 4 星;注意场上只能阿雅一张 1 费)。
- **电视机 boss**(禁速)克速度依赖。
- 试用难,最好用自己的阿雅。
