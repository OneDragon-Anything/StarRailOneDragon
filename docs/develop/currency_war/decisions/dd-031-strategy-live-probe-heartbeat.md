# dd-031: 策略失活早停误杀定谳与判据重写(心跳 = sid 行或载体行)

## 状态

已采纳(2026-09-04,运行 bug 修复批)

## 背景

ADR-0342 的「策略失活早停」探针(cw_loop.py 备战入口)连续 2 局误杀健康局:

- g_20260904_022537:P1-r7/r8 被「该轮无 strategy_id 决策行」判死连击 2 →
  `cw:strategy_dead_early_stop` 停局,终局 hp=73/100(复盘 g_20260904_022537.md 重点 1);
- g_20260904_010335:r8/r9 同形态,同日早局同死。

达「跨 2 局治本」门槛,本批落判据重写。

## 根因

`strategy_id` 行的唯一写点在店内决策(cw_op_buy_cards.py:658——只有开了店才有
sid 行)。mandate_v1 的开店发射需要理由(`_emit_open_shop` 仅三站:M2 缺件 /
dominance_buy / m6_stock);当三开店站全关(M2 缺件空 / 金<饱和线 / arm1 未武装)
时,策略按设计合法跳过开店——整轮只有备战载体行(sid='',如 StartBattle)。
旧判据「无 sid 行 = 策略失活」把这一合法输出形态读成死亡,连续 2 轮即停机。

## 判据重写

新判据(单一源 `query._row_heartbeat`):一行有**非空 strategy_id(店内决策行)
或非空 actions(备战载体/步进行)**即策略心跳;某 (plane, round) 无任何心跳行
= 失活候选。运行探针阈值维持 2,离线检查网(check_strategy_live_streak)阈值
维持 3,两处同源同一谓词。

**阈值 2 的依据(误杀/漏报平衡)**:修复后「失活候选」的形态只剩「整轮零心跳行」
——观测面每轮必有载体行(外环在转就连 StartBattle 都会发),零心跳 = 外环级
停转,不存在已知的合法单轮形态(r5 补给轮哑行是孤立单轮,被前后健康轮隔离,
两局实录均如此);连续 2 轮零心跳即进程级异常,维持 2 保留 ADR-0342 原响应性,
不新开漏报窗。

## Considered Options

1. **【采纳】探针判据改「策略心跳」**:治本——判据对齐观测面真相(sid 行是
   开店的下游产物,不是策略活性的充分证据)。
2. mandate 在三开店站全关时发一条带 sid 的 read_only 观察帧:表达力补丁,
   为探针造数据是写端迁就读端的症状修法,弃。
3. 维持旧判据 + 提高 streak 阈值:误杀形态(跳店可连续任意多轮,hoard 姿态
   常态)下任何阈值都可能误杀,治标,弃。

## 显式权衡:辖域收敛(漏报声明)

兜底/策略内容性死亡形态(迁移审计 w98 崩溃恢复局:决策层不点火、兜底打满
40min 垃圾局)在决策行面**不可判**——兜底路径与健康策略路径发的都是载体动作
(StartBattle 等),行面无字段能区分「策略选的」与「兜底发的」。故重写后探针
辖域收敛为「外环停转」(进程级失活);w98 形态的检测归离线检查网与复盘判读
(判栈/经济视图),不再由本运行探针承诺。这是接受已知漏报换取消灭实测误杀源
的显式取舍;若未来需要运行期兜底检测,须新增观测面字段(如兜底路径打独立标),
不是回调本判据。
