# P7 攒息线对基础奖励的不敏感性(按 5 处理的安全性)

> 状态:**已证(结构不变性)**
> 数据源:`cw_horizon.interest`(弹窗实测,economy.md §10.1)+ 纯推导
> 提出:2026-08-25(五问事件产物);证明=W120 批

## 命题

50 息线的最优策略不随基础奖励(3-8)变;「先一律按 5 处理」安全。

## 证明

1. **结构不变性**:利息 = min(5, gold//10)——**基础奖励不进利息公式**,收入平移只改金轨迹的斜率,不改「>50 每分无存价 / <50 每低一档损 1金/轮」的边际结构(息损 C_interest = 跨档数×R 与收入项独立)。
2. **敏感性量级**(零花口径,连胜档递增):从金 40 回 50:base=3/4→2 轮,base=5-8→1 轮;从 30 回 50:base=3→3 轮,base=8→2 轮。**恢复轮数差 ≤1-2 轮,任何值都不翻转「攒到 50 再花」的取向**——翻转需 base→0 极端(回 50 时间成本>息差本身),[3,8] 全程安全。

## 策略含义

P2/P3 位面基础奖励按 5 处理是安全的(plane≥2 采集钩子采到真值后只改 DP 数值精度,不改策略结构);**无需为它提采集优先级**(维持现有在途钩子即可)。

## 对实现的检验点

EV 授权决策对 BASE_REWARD_GOLD 注入 3/4/6/8 的 A/B 中,同帧决策(买/升/D 的放行集)应逐位一致(只差 DP 期望值数值,不差方向)。
