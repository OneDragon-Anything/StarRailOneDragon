# ADR-0168 02 号处置:主体被取代(superseded),salvage 校准环境落地 v0

## Status

Accepted(2026-08-16;02 号提案文件处置删档;校准环境战斗 stub 升级待 ledger 实测数据)

## Context

02 号三主张逐条处置判定(按 od-dev-deciding-a-fix 前提验证):
- **主张一(统计 outcome model:局面×对手→掉血分布,~540 样本)**:被 19 号取代——ADR-0166 伤害双账本(测量优先+不等式括号法,十几战定参、版本鲁棒、逐角色归因板级标签给不出)。02 的残差层角色保留:强交互局(反伤类)主效应失真时,统计层接管该桶——已写入 ADR-0166。
- **主张二(决策统一 ΔE[生存] 计价)**:被 18 号修正——ADR-0161 论证期望泛函在劣势局方向性选错(同均值异方差,K0 实测 CV 0.4-0.6),消费泛函应为路径首达概率;02 的分位族(P25/50/75)降为信念层(ADR-0163)的数据输入。
- **主张三(校准环境 = 规则引擎 + 战斗模型)**:**未被取代,且是多层共同依赖**(ADR-0155 V3 切流 A/B/ADR-0166 L2-L3/ADR-0167 K2),零件现已齐(simulate 规则引擎/REFRESH_PROB/掉血先验)——salvage 落地。

## Considered Options

- 02 原案独立落地(统计模型):拒绝 —— 同槽位 19 号已给更优答案(样本效率差一个量级)。
- 整案否决(含校准环境):拒绝 —— 环境是独立基建,拖住三层切流验证。
- salvage 环境落地(采纳)。

## Decision

1. 新增 `cw_sim_env.py` 校准环境 v0:
   - `SimEnv.run(policy)`:GameState 驱动对局(shop 按 REFRESH_PROB 采样/战斗 = cw_horizon 掉血先验 × 对数正态噪声[与 DP 同源 → A/B 公平]/收入 = node_income[连胜-板强耦合]+interest;位面推进);种子确定性(F-4);
   - `run_batch(policy, n)`:结果指标(存活率/位面到达/P3 率/终局金/等级);
   - `baseline_policy`:现状栈近似(攒息→买 target→按金升级)。
2. **V3 预演实测**(100 局 A/B):基线启发式 vs DP 姿态策略——存活率 0.00→0.18、P3 到达 0.00→0.94、终局等级 4.2→7.2;且基线 dying-with-gold 79.7 复现病理(死亡时剩余金)——**校准环境第一跑就分辨策略优劣并复现 DP 价值主张**。
3. 诚实边界:v0 战斗 = 掉血先验(ledger 实测数据到位后替换 stub 即升级为 L2 校准环境);装备/事件/遭遇不建模。

## Consequences

- ADR-0155 V3(DP 切流)的正式跑法:用真实 plan()(非启发式近似)作对照臂——待现状栈在环境中可驱动(需 mock OCR 层的 GameState 全字段),启发式对照已是有效下界。
  **✅ V3 扩样完成(2026-08-16 轮18,N=400)**:基线启发式存活 0.000 [0,0.010] vs DP 姿态 **0.052 [0.035,0.079]**(Wilson 95% CI,**区间不重叠=统计显著**);P3 到达 0.00 vs **0.90**;终局等级 4.0 vs **7.4**;基线 dying-with-gold 80 复现。DP 优势在扩样下稳定成立(V3 切流判据的证据基础;正式切流仍待真实 plan() 对照臂)。
