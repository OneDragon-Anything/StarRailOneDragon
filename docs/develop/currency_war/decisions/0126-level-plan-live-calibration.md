# ADR-0126 节点等级计划 live 校准:A8 需更高人口节奏

- 日期:2026-08-15
- 状态:已接受(数据:11 局 A8 live)

## 背景

原 _DEFAULT_NODE_PLAN 为 V4.4 先验占位(P1 r7-9 target lv6 / P2 早期 lv7)。live 11 局数据:
- lv6@1-9 boss 稳定掉 34-40 HP(M9 -34 / M10 -34 / M11 -36),进位面 2 即死于 2-1/2-2(3/3 局)
- M8(等级最激进,lv9)是**唯一**破 2-7 boss 进位面 3 的局
- A8 敌难度 108:单位强度随轮增长超过 lv6 人口的板容量上限

## 决策

P1 r7-9: 6→7(boss 保血);P2 r1-4: 7→8;P2 r5-9: 8→9(对齐 M8 成功轨迹)。

## 考虑过的选项

- 维持原值等更多数据:M9-M11 已 3 局同模式一致死亡,证据足
- 更激进(P1 后期直接 8):经济不支持(50 金息引擎会被拆),渐进校准

## 后果

- XP 支出上升 → 中期买牌预算略降(tempo 例外 ADR-0124 补偿:板增强散牌仍会买)
- 预期:1-9 boss 掉血 ≤20,位面 2 进场 HP≥40
- 验证:M13+ 对局 HP 曲线
