# 忘却之庭-编队(treasures_light_team)

逐光捡金**挑战编队画面**(2026-11-04 从 逐光捡金 合并大屏拆出独立建档):左栏角色列表/预设编队 + 右栏关卡信息与两编队槽。入口:选关界面点已解锁关卡水晶。

## 何时出现 + 状态流转

- **入口**:逐光捡金选关点关卡水晶(水晶位置随滚动变化,见 逐光捡金.md 水晶 area)。
- **出口**:右上返回箭头 → 逐光捡金选关(✓实测);按钮-最终开始 → 进入战斗(**不可逆出口,未实测**——启动即打)。

## 识别特征(稳定锚点)

- **标题-忘却之庭行 + 标题-编队行** 双 id_mark(rect 同 逐光捡金 标题族,第二行文字「编队」区分):编队帧两行全中 → 本屏精准;选关帧第二行为 混沌回忆/回忆 → 不误命中(2026-11-04 实测互斥干净)。
- 左栏上方 双 tab:角色列表(默认)/预设编队,选中态白底。

## 可交互元素(2026-11-04 click 实锤)

| 元素(area) | 行为 |
|---|---|
| tab-角色列表 / tab-预设编队 | 左栏切换:角色列表=全角色网格(等级80+,可滚动,点角色加入编队=改状态未实测);预设编队=已存预设队伍列表(队伍1-4,点套用=改状态未实测) |
| 按钮-通关阵容 | 弹「推荐阵容/好友通关阵容」双tab弹窗:推荐=全服统计(新期显示 数据统计中,来自近期活跃玩家);好友=好友满星记录(节点一/二各4人+星数+**一键上阵**按钮=套用改状态未实测);显示我的持有情况 开关 |
| 按钮-队伍1详情 / 按钮-队伍2详情 | 打开**敌方信息浮层**(共享画面 货币战争-敌人信息浮层,精准复用):逐波敌人清单+每敌弱点图标+详情/技能页签——逐关敌人构成与弱点表的第一手数据源 |
| 按钮-角色详情 | → 角色详情检视(未实测) |
| 按钮-最终开始「混沌回忆」 | 进入战斗(**不可逆**;行为按流程推断,未点击) |
| 按钮-返回箭头 | → 逐光捡金选关 ✓ |

## automation 要读信息

- 关卡名文本(如 物竞天择其十)。
- 挑战目标三条(剩余10轮/20轮/无人倒下=星数条件,OCR 可读)。
- 两编队槽:敌人 等级:90 + 建议属性(弱点表,图标)+ 详情入口。
- 记忆紊流 buff 文本(重复展示于本屏顶部)。
- 「3星通关此关卡后,可获得前置关卡的全部奖励」提示条。
