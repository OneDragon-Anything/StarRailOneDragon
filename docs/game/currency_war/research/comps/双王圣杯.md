## 打法主线

- 双王 = 闪闪(吉尔伽米什,2费,后台带鞋自加速)+ Saber(3费,主c);每 8 行动连携 + 回能;5 能量。[先验:攻略]
- **Saber 1Q1Q 循环机制**:能量满(含炉心能量)自拉条 → 打强化普攻解锁限制 → 下次满能继续自拉条,形成伪永动并叠风暴潮;充能源 = 能量格 / 金闪闪 / 缇宝 / 藿藿 / 停云。[社区:plaza 帖文]
- 圣杯羁绊给经济 + 改件加速 3 星(任务线顺手做);**有红A任务选红A,次选星徽**。[先验:攻略+社区:plaza 帖文]
- 节奏:体系牌+花火/凛过渡(做 3 圣杯任务)→ **7-8 级找 3星 Saber 或闪闪** → 上 9 挂杨叔。[先验:攻略]
- 云璃上手前用**前台周日**(后台周日动太慢);记忆主手操注意拉条别喂错人。[社区:plaza 帖文]

## 装备分配

- Saber:火力风暴潮 / 永动机 / 冷笑话引擎 / 高周波电锯(56/44/36/31 篇);符玄阿瓦隆 + 绝对热量 = 75% 减伤邪修。[社区:plaza+先验]
- 出装序:永动机(Saber)→ 电光履 → 绝对热量×2(刃/缇)→ 永动机(藿藿);**行星钻地弹 ≡ 追逐星辰效果一致,合成一个即可**。[社区:plaza 帖文]

## 过渡

- 花火/远坂凛/刃 过渡;杨叔必备位。[先验:攻略]
