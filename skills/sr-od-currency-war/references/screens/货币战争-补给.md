# 货币战争-补给

## 画面简介

备战流程的 5 选 1 补给节点画面：轮到补给节点时弹出；「自动弹」形态（上节点结算确认后直接弹补给屏、没经过备战）下它是判断当前节点位置的唯一画面。候选卡 = 角色 + 绑定装备（教学关形态为武装箱 5 选 1）。选一张确认后直接进入下一个节点的备战画面，所选角色入备战席（不自动上场）。回到备战有一段动画，动画走完商店自动展开。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-补给阶段 | 画面标题「补给阶段」（画面身份锚） | 纯显示 |
| 标识-备战阶段 | 当前位面-节点序（如「1-3」）；自动弹形态下是判断当前节点的唯一读数（源码推断） | 纯显示 |
| 文本-剩余次数 | 剩余刷新次数；读不到 = 本局没有刷新可用 | 纯显示 |
| 文本-已选择 | 已选中候选的标记（选中后出现） | 纯显示 |
| 按钮-确认 | 确认当前选择 | 补给屏关闭、回备战、所选角色入备战席；未选时置灰 |
| 按钮-返回备战界面 | 中途放弃补给 | 回备战，带出暗色锁定态（按 [货币战争-备战](货币战争-备战.md) 的「货币战争-备战-补给锁定」一节处理） |
| 候选列数（无 area） | 动态 3~5 列（「全都要」类效果减列、「人身意外险」类加列），以画面实际列数为准，别写死 5 | 纯显示；选中操作点卡片本体 |
| 卡面钻标记（无 area） | 红/蓝/财富宝钻 = 收益类型，有钻的候选金币收益优先级更高 | 纯显示 |
| 试用标/紫底（无 area） | 红「试用」角标 = 试用单位（局末不移除）；无试用标的同类单位名字带紫底高亮 = 自有单位 | 纯显示 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 选中一张卡 | MCP `click_game` | 卡中心坐标（自己读图定位候选列） | 「文本-已选择」出现、白框亮起 | 静态点击有效 |
| 确认选择 | MCP `click_game` | 「按钮-确认」area 中心（识别返回坐标） | 补给屏关闭、直接进入下一个节点的备战画面，所选角色入备战席；回到备战有一段动画，动画走完商店自动展开成「货币战争-备战-开商店」 | 入席**不自动上场**，上场还要在备战画面部署；点击无效时微距拖拽兜底。动画没走完时点击不生效，这时画面看着还是商店没展开的备战——等动画走完、`analyze_screen` 确认画面后再操作 |
| 刷新候选 | MCP `click_game` | 圆钮 ≈「文本-剩余次数」中心 x−100 同高 | 候选变化、「文本-剩余次数」数字减一 | 点后约 2 秒画面稳定再读；读不到「剩余次数」时不要盲点 |
| 中途返回备战 | MCP `click_game` | 「按钮-返回备战界面」area 中心 | 回备战 | 与投资策略/遭遇节点同款按钮，返回后都带出暗色锁定态 |
