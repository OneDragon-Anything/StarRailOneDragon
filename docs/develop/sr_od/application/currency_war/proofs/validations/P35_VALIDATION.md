## 门① 内部推导健全性 —— **部分过(可复算自洽;一处标签错位 + 两处结构缺位)**

### 1.1 逐项重推(全部亲算复现)

- **EV = v·r − C − d(g;C)·R 的三项分解**:承 P23.1 统一门式的恒等变形(m 视角→每场边际视角),代数无 leaps ✓。R≈r 近似下两条件(v>d ∧ r>C/(v−d))的充要推导正确;恒负充分条件 v≤d 的论证(不升级息流不停止、本金永无摊还完时刻)逻辑成立 ✓。
- **d(g;C) 闭式与 P35-b 分域**:d = min(⌊g/10⌋,5) − min(⌊(g−84)/10⌋,5),分段边界 [84,94)/[94,104)/[104,114)/[114,124)/[124,134)/≥134 → 5/4/3/2/1/0,逐档手算全对 ✓;息帽封顶与 g≥134 精确为零的论断成立 ✓。
- **表 1 数值**:中心行 v=0.05×13.3+1.5=2.165 ✓,r\* 各档 38.8/72/509/NEVER 复算一致;下界角 0.339 → 247.8≈248 ✓;四参数全顶格 4.80 → 17.5/22.1/30.0/46.7/105 复算一致 ✓。
- **§1.1 分期修正**:Δ = Σ\_{j=1..k−1}[d(g;C) − d(g;S\_j)] ∈ [0, d·(k−1)] 的界正确;逐域实算 Δ=7/6/5/4/2(g=90/100/110/120/130,k=3,S=32/64)亲算逐位复现 ✓;恒负存活论证(C−Δ ≥ 84−10=74>0)成立 ✓;表 3.1 各格(含舍入口径 v=2.17)复算一致 ✓。
- **P35-c 超几何缩放**:E(9,c)/E(10,c)=p(10,c)/p(9,c) 精确成立(费用档内超几何因子与等级无关)、提速 60%/25% 由概率表直读——推导与数值均 ✓(锚点见门②)。

### 1.2 标签错位(必勘误):表 1「P20 上界」行参数标定与所用数值不符

行标签 (0.117, **15.39**, 1.5),但 v=2.82 = 0.117×**11.3**+1.5——若按标签 L=15.39 应得 v=3.30(该行全部 r\* 29.8/46/102 与 v=2.82 自洽,与 3.30 不自洽)。同表其他三行(中心 13.3/下界 11.3/四参数 15.39)标签与数值均一致,唯此行错位。**后果不翻案**:按 15.39 重算 r\*(d=0)=25.5、(d=1)=36.5,仍全部 >19 或 NEVER,分域裁决不变;但该行数值的参数溯源链断裂(读者无法按行内标签复现 29.8),违反「数字表可按 §3 公式逐格复算」的自声明。可能成因:0.117 是 P20 的 P1 域体系激活边际,配 P1 的 L=11.3 域一致而标签误抄 15.39——无论哪种,标签与数值必须择一修正。

### 1.3 结构缺位一:比较基准缺 P51 W_floor 接口(与 P39 门①1.2 同款)

EV 的「不升级」分支被计为无风险吃息 d·R。按 P51 §F/§Λ 已立的 W_floor = λ_death(战力桶,R)·(存量金+未来流) − 当轮息票:**λ_death>0 段不升级 ≠ 无风险**,持有的金与息流本身承担截断敞口**且该敞口不因升级消失、只是形态改变**。P35 成文早于 P51,辖域(停手窗=后期掉血高发段)恰是 λ_death>0 主体段——「恒负」判在掉血期是**偏向负判的口径**(把不升级侧的息流当成必然落袋)。按 P51 §F.4 公理(所有证明必须在连胜=0 底线上成立),正式修订时持有侧必须显式并入 W_floor 或声明辖域排除 λ_death>0 段。量级上这不必然翻案(W_floor 进的是比较基准,主判 v<d 的流量竞争不受影响),但「任何可负担金位、任何可达剩余轮数上 EV 严格为负」的全称表述在掉血期不再成立。

### 1.4 结构缺位二:息口径与新树(P47)的接口未声明

P35 的 d·R 是**静态金近似**(付清后金位不动,此后 R 轮每轮少 d);实际金每轮有基础+连胜收入再生,再生会缩小两轨息差(两轨同向逼近息帽)——单篇已声明「金再生的二阶保守性与 P35 原式同向」✓ 诚实,方向正确(d·R 确为上界)。但 P39 验证件已确认息损规范口径换轨为 **p47 双轨迹 L 递推**(P39 A4 已执行换轨);P35 作为同族件未声明与 L(g,U,R,Ī) 的关系(是其闭式特例/上界)。非推导错误,是证明族接口缺位,修正建议⑤登记。

**门①判定:部分过**。可算部分全对且逐位可复现;表 1 标签错位必勘误;W_floor 接口与 P47 接口两处缺位须修。
