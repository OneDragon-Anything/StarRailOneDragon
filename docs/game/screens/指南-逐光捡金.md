# 指南-逐光捡金(guide_treasures)

星际和平指南「逐光捡金」tab 的**分类选择页**:左侧五分类列表 + 右侧所选分类的详情面板。是进入逐光捡金系列(混沌回忆/虚构叙事/末日幻影/异相仲裁)的唯一入口页。

## 何时出现 + 状态流转

- **入口**:大世界 →(右上指南)→ 星际和平指南 →(第 4 个 tab 图标 ≈725,217)→ 本页;或从选关界面关闭 X → 大世界(不回本页,2026-11 实测)。
- **出口**:右上关闭 X → 大世界-普通;分类条目选中后右侧面板按钮(传送/前往挑战)→ 对应玩法画面。

## 状态流转(右面板随左侧选中项切换)

| 选中分类 | 右面板内容 | 按钮 |
|---|---|---|
| 异相仲裁 | 当期 boss 横幅(期名 落叶归根)+倒计时+挑战状态 | **前往挑战**(→异相仲裁玩法,未建档) |
| 最近更新 | 最新一期单横幅(混沌回忆·物竞天择 + 查看详情) | **传送**(→逐光捡金选关) |
| 忘却之庭 | **总览**:混沌回忆 banner+物竞天择卡(进度/星数/传送)+回忆 banner+永屹/天艟卡(各带传送),可滚动 | **传送**(逐卡) |
| 虚构叙事 | 当期单横幅(取象为文,进度 0/4,星数 0/12,4.x 为 4 关制) | **传送**(→虚构叙事画面) |
| 末日幻影 | 当期单横幅(支配遗忘,指标=最高难度 00+星数 0/12,难度阶梯制) | **传送**(→末日幻影画面) |

⚠️ **默认选中项不固定**(2026-11-04 两次进入实测:一次最近更新、一次异相仲裁)——bot 读右面板前必须先显式点目标分类,勿假设默认态。

## 识别特征(稳定锚点)

- **标识-标题-逐光捡金**(左上第二行,rect (95,62)-(230,96),id_mark,conf≈0.999);第一行「星际和平指南」为兄弟 tab 共享,不作锚。
- 分类条目文本(异相仲裁/最近更新/忘却之庭/虚构叙事/末日幻影)左侧列表常驻;⚠️ OCR 曾把「异相仲裁」识别为繁体「異相仲裁」,LCS 吸收(conf 0.91 可用)。
- 右面板按钮文案随分类变(传送/前往挑战),不作锚。

## 可交互元素(2026-11-04 click 实锤)

| 元素(area) | 行为 |
|---|---|
| 分类-异相仲裁 / 最近更新 / 忘却之庭 / 虚构叙事 / 末日幻影 | 选中分类,右面板切换(同屏) |
| 按钮-传送-单期横幅(最近更新/虚构/末日面板) | → 对应玩法画面;混沌回忆卡实测 goto 逐光捡金 ✓ |

| 按钮-关闭X | → 大世界-普通 ✓ |
| 商店袋图标(面板内,带角标) | → 商店(同选关入口目标;位置随面板布局变,未逐位实测) |

## automation 要读信息

- 分类条目的「尚未挑战」角标(本期是否已挑战,OCR 可读)。
- 右面板:期名/倒计时/进度/星数(如 物竞天择 进度 0/12 星数 0/36;异相仲裁 落叶归根 6天16小时)。
- 忘却之庭总览卡片:混沌回忆进度/星数、永屹之城遗秘 15/15·45/45、天艟求仙迷航录(逐卡读取,滚动位置相关)。
