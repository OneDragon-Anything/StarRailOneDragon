# 寒鸦（物理·同谐·4星）

> 按 V4.7 期撰写。承负产点机：全队攻击节奏越密战技点经济越好。

## 一、命途属性与技能说明

**命途**：同谐；**属性**：物理

| 技能 | 说明 |
|---|---|
| 普攻 | 单体50%攻击物理伤 |
| 战技【承负】 | 单体120%攻击；对承负目标每2次普攻/战技/终结技 → **恢复1战技点**（触发2次解除，仅最新目标）——产点引擎 |
| 终结技 | 消耗能量；单体速度+（寒鸦速度15%）+攻击+36%（2回合）——速度是转化属性 |
| 天赋 | 对承负目标攻击伤害+15%~26% |
| 秘技 | 进战挂承负 |

**资源与循环**：标准能量→充能有效。

## 二、推荐遗器与原因

**套装**：野穗伴行的快枪手4件 + 生命的翁瓦克2件【攻】
**主词条**：躯干攻击%；脚部**速度**（终结技15%转化）；球攻击%；绳充能。
**副词条**：速度 > 攻击% > 充能。

## 三、推荐配队与原因

| 阵容 | 为什么 |
|---|---|
| SP 饥渴队（饮月/青雀/多战技体系） | 产点引擎直接供血 |
| 高攻击频率队 | 承负触发快=产点快 |

**硬否决**：加攻对生命/欢愉模型无效。
