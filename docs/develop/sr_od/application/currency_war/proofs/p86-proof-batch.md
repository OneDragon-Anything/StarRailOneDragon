### 3.3 丙分支:缺省保利息的正当性(宪法论证,如实非数学)

证(论证链,非支配定理):
1. **发展优先但书**(01 §8-2):停手族只许否决已证无生存意义的支出,不许以未标定为由冻结已证有正账的发展支出。无目标帧的买面上**不存在**已证有正账的发展对象(候选集空 = 没有可发展之物;退役前该前提为帧条件——甲乙分支非空帧由其直接出手,现役甲乙已退役,前提全域成立)——保利息否决的是一个空集,不落入但书禁止域。
2. **持金非毁值**(P83):非末位面利息档结构上的持金未来效用严格正(下位面首期利息 + 购买力通道);保利息是保住正效用资产,不是死握。
3. **等待优于坏方向囤积**(P76 丙 集中度引理 + P76 戊 域 α):无目标帧上任何非判据选择的方向押注都被集中度引理支配;等是 θ* 判据下游消费环境的正确缺省。
4. **换现面纪律**:一切卖出资格消费统一让位序列(循环防线经装配 A 循环防线段承载;身份段已随统一让位优先级迭代 3.4 退役),本命题零新增卖出通道、零改豁免谱。

### 4.3 必答③(方案审 F5):富余段权威冲突三选一——**裁:选项②(富余段维持,丙分支只管非必花带)**

**冲突面重述**:无目标帧 ∧ gold > g*(富余段)时,丙分支保利息(不买)与富余段(要花,用户裁定「无论什么 hp,金这么多都是要花的」)给出相反指令;P35 帧 14:18:21 形态(拒买期权却烧刷新费,RefreshShop×4 reason=must_spend_r1_yielded)是冲突的病灶暴露。

**裁决与论证**:

### 4.4 必答④(方案审 F6):同帧多分支仲裁序——**裁:三层序(支配序 → 机器原生序 → 注册表声明序),零参数**

**问题面**:甲乙两分支同帧并存(或乙分支多枢纽并存)且席位/金竞争时,动作发出序决定资源归属;实现前禁隐式定序(防实现顺序代替判据序)。

**先决澄清(竞争域收窄)**:三分支输出是**资格面**(哪些店面卡可买),不是整批支出指令——实际动作发出 = 店面存货 ∩ 资格面,逐件过各自合取(check_seats/check_affordable 在动作发出时点逐件判)。故:两件都能过合取且资源足够时序不承载行为(双方各自发出动作,序无关);仲裁序只在「各自合取都过但资源只承其一」的竞争帧介入,且逐帧重评(竞错代价有界:两分支产物皆 1★ 全退可逆,次帧重裁)。

**裁决(候选级序,非分支级序)**:
1. **第一层·支配序(定理承载;存疑-2 收窄)**:覆盖甲分支方向所在线 l_d 的枢纽 h({l_d} ⊆ C_h)**先于该方向的单线方向件**(C_x = {l_d} 的待购件)——推论 B1.1 直接给出 u_h ≥ u_d,全参数域;**授权限单线方向件**:多线方向件(自身覆盖多线,C_x ⊄ {l_d})的件级 u_x 可 > u_h,B1.1 不供给件级授权,该类竞争**降第三层**。无覆盖关系时本层不介入(禁超纲:定理只授权包含关系,不授权跨覆盖比较)。
2. **第二层·机器原生序(甲分支内部/无支配覆盖时的甲方向)**:甲分支方向 = 机器强锁判活集上机器自身选择序的首方向(`sorted(-资产厚度, encounter_window_rounds)[0]`,cw_intention.py:1609-1613)——机器语义的一部分,同源零新键;其成员件的内部序 = 店面槽位序(确定性,零语义)。
3. **第三层·注册表声明序(确定性兜底)**:剩余并列(互不覆盖的多枢纽之间、枢纽与多线方向件之间、枢纽与无覆盖甲方向件之间)按注册表声明序(char_routes/COMP_LIBRARY 派生序)——纯确定性、零语义承载。

**显式否决记录**:**覆盖数降序否决**为仲裁键——覆盖支配定理是集合包含单调性,不是基数单调性(|C_h| ≥ |C_h'| 推不出 P(C_h) ≥ P(C_h'),非嵌套集合无授权比较);以计数排序会把未经定理授权的排序语义偷渡进竞争帧,是伪装参数(零调参纪律同判)。**席位数序否决**:竞争帧上两分支候选皆为 1★ 单件单位购(边际一席),该键在竞争域内无区分域。

**附带条款**:①各件合取不过 = 该件本帧不出手,不因序获得挤占权;②实现批动作发出序必须消费本序(单帧测试增量见 §6),禁实现遍历顺序;③枢纽 ∩ TRANSITION_PACK 交集成员在活跃域无双通道问题(规则④开域 ∩ p2plus = ∅,§4.1-4),该禁令保留为未来扩展守卫。(退役勘误:守卫对象 ④分支/TRANSITION_PACK 已随统一保护集迭代退役,交集双通道注册面已不存在——条款存历史记录。)

### 4.5 必答⑤(方案审 F12):方向级 EV 账聚合口径——**裁:refund 线性和 / L 整批一次 / V_slot 动作发出时点状态计价**

方向 d 的采购集 B_d = {x_1..x_n}(角色件;装备件零金币不入金账,P42 ⑥ 装备域与卡池 disjoint)。方向级账对卡级 P41① 形态的规范化:

1. **refund(d) := Σ_i refund(x_i)**——逐卡线性求和。依据:退货按件独立结算(P76 甲退货表逐件,1★ 全档净 0),卖整集 = Σ 独立卖出动作,线性精确。
2. **L(carry) := L(g, s_d, R, Ī, cap)**——整批一次,以方向批支出 s_d = Σ_i s_{x_i} 为**金位跃迁输入**求 P47 双轨迹递推,**禁** Σ_i L(·, s_i, ·) 逐卡分解:利息档损失是金位阶梯函数 τ 的差分,τ 凹步进使逐卡分解既不独立可加又路径重复计账(P48 整批纪律同源);同帧多分支支出时,L 在各分支差分账内按**各自分配案**的批支出求值——分支间比较是分配案比较,不是逐卡份额分摊。
3. **V_slot(d) := 动作发出时点状态计价(存疑-1 钉死,禁跃迁读法)**——对每件:**该件动作发出时点的 free 状态**计价,free ≤ 1 的件按 V_slot(被阻断动作净 EV)计一次,free ≥ 2 的件计 0——与 P41③ 逐件状态判逐字等价,不按「使 free 落入 ≤1 的跃迁」读法(该读法会把 free=2 时点的单件购置误计价,与 P41③ free≥2 ⟹ 0 矛盾)。多件批的 free 状态按 §4.4 仲裁动作发出序逐件推进(序确定 ⟹ 状态序列确定);free = 0 时 check_seats 先拦,不产生计价格。**n=1 退化自检例**:free≥2 帧单件购 → 0(与卡级 P41① 恒等);free=1 帧单件购 → V_slot(与卡级形态恒等)。
4. **期权项不聚合**:u_d·P_miss·C_rescue 的支撑是方向概率 u_d(机器来源,定理 A),保持方向级;不逐卡求和(防与 P41① 卡级口径混写)。
5. **消费授权声明**:本口径是账骨架的**定义**(权威版本 §2.1 的规范化义务兑现),当前零数值消费——u 系已登记【拟】无点值授权(R3),甲分支资格门不消费 EV 账数值(资格 = 机器门);口径在未来任何标定消费位启用时按本节执行,防实现批自造第二口径。
