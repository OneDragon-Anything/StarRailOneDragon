worker 选择「内联段删除、处置语义整体迁入注册表」，弃选「内联段改调注册表」。独立验证：

1. **不可达论证成立**：守卫调用点（`advance_to_prep` L319）与本轮所有状态分支消费同一张 `self.last_screenshot`（L312，round 开头一次截取）；内联 3b 分支的识别谓词（`货币战争-积分奖励`/`标识-积分奖励`）与守卫项 `identify_area_names` 完全相同 = 同帧同谓词。守卫命中即 `round_retry` 返回（无论点击是否落地），本轮不再下行；节点内守卫位置与旧 3b 位之间所有会改画面的点击路径（难度确认/模式选择/简报/投资环境等）均点击后立即 return，不存在「守卫未命中、行进中弹窗出现」的窗口 → 3b 位谓词若命中则守卫必先命中并已返回，内联分支结构性不可达。保留即死代码 + 第二测试面，删除正确。
