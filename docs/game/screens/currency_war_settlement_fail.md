# 货币战争-结算-失败

## 何时出现

一轮战斗战败后(小队 HP 归零)的结算页。**注意与「货币战争-挑战失败」屏区分**(那是局终评价页,见下方「状态流转」);本屏是战斗结束的即时结算。

## 状态流转

- 入口:任一节点战斗中 HP 归零(轮败/局终败同屏)。
- **两步序贯出口**(用户实证 2026-08-16):
  1. **步骤 1「点击空白加速」**:战斗演出未完 → 「挑战结束 + X-Y 战斗 + 点击空白加速」→ 点空白加速动画;
  2. **步骤 2「前往结算」按钮**:动画完 → 同屏出现「前往结算」(底部中央)→ 点 → 局终多页结算(「货币战争-挑战失败」评价页)→ 下一步 → 返回货币战争大厅。
  - M41 帧(P3-4 局终)停在步骤 1、M44 帧(P2-1 轮败)停在步骤 2 —— 同屏两步,非两个子态。
- 后继屏:货币战争-挑战失败(评价页)→ 货币战争-大厅。

## 识别特征

- **组合 id_mark**(2026-08-16 归位;此前单锚「挑战结束」三连撞车——首领胜利屏也显示它):
  - `标识-挑战结束`(820,186-1098,272,lcs 0.9)
  - `标识-挑战进度`(860,362-1060,410,lcs 0.9;战败独有——掉血进度显示)
  - 两锚全中才算 is_precise;首领胜利帧(挑战结束+继续挑战,无挑战进度)不命中。
- 辅助:`标识-节点名`(X-Y 战斗);`提示-点击空白加速`(步骤 1);`按钮-前往结算`(步骤 2)。
- 与「挑战成功」屏互斥:结构判据「无按钮-继续挑战」(loop 1f 第三重保险)。

## 可交互元素

| 元素 | 位置 | 行为 |
|---|---|---|
| 提示-点击空白加速(步骤 1) | 底部中央 | 加速战斗演出 → 翻到步骤 2 |
| 按钮-前往结算(步骤 2) | 底部中央 (960,898)± | 推进到局终结算下一页 |

## automation 要读信息

- 挑战进度掉血(「-N」文本,Y≈697-774 区域)——战败掉血量(伤害账本的对账输入,L1 接线候选)。
