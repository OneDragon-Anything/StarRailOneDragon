## 开局与奖励节点

- **[1]** 开场 2 个奖励节点基本什么都不做;在不影响吃息的基础上多买牌,方便后续刷出想要的角色。r1/r2 固定奖励节点**不 D 牌**(奖励必过,刷新纯烧金);**保息前提下多买 1星/2星 = 压缩牌库**,池子小了后续轮目标卡浓度升高,更易凑出过渡阵容;过渡阵容**能找到就找、没有也不强求**(可卖 1-2 轮血换经济积累)。
  (购买要不要让位于息线,账见 [22]④;「卖血换经济」以血量安全边际为前提,联动 [18]/[19]。)
- **[15]** r1/r2 压缩牌库是**全局供给策略**不是本位战力投资:买的 1/2 星既是后续 3合1 的副本素材,也把公共池的噪声牌抽走——自己不买,下轮商店还是这些牌占位。
- **[16]** 必胜节点(奖励)语义:无战斗、连胜白拿、回血白吃——①刷牌的战斗向理由全关(无血可扣、维持连胜不靠刷新);③节点序列每局随机,r1/r2 固定 + 序列内还会再出,以备战顶部节点条为准。(原②「升级零战损/奖励节点买经验」已删——勘误见下。)
  (⚠️ 例外注记 2026-08-25:持「经济过热/严重过热」类投资环境时,奖励节点会变**次元/超级次元扑满**,本条①的「无战斗」前提失效(机制详 gameplay 总览)。**应对口述(同日)**:扑满关**不掉血**(扑满关自身机制,与 0hp 保底无关——两条独立机制,2026-08-26 用户纠正),真损失=**打不过就没奖励**(损失很大)——正确姿势是**怎么都要凑一个羁绊来刷伤害**拿奖励,不是深花保血。)
  (⚠️ 勘误 2026-09-07 用户裁定:原②「升级零战损/人玩倾向在奖励节点买经验」**删除**——前提「奖励节点无战力要求」下,统一经济考量=**压池优先**([1]/[15]);就算下个节点需要战力,也可卖备战件提升,资产可逆。实证=1-1 升级/1-2 金 9 死囤/1-3 希儿不买三病灶(T-115① 立案)。sim 检查器三处 [16]② 豁免引用(sim/checks/segments.py、sim/checks/ledger.py、ADR-0560)由 T-115 实施批同步对齐:奖励节点买经验从豁免改为抑制对象。)

## 经济与利息

> **50 金息律簇**(2026-08-26 合并去重;核心只在此说一次):利息 5金/轮 @50 封顶 → **金 <50 攒息,破档要有例外理由;≥50 的溢余随时花**。主条 **[17]** 是唯一全表述;其余条目各只讲一个例外或细化,读时取差异勿重读核心——**[2]** 前期形态+卖血 · **[6]** 破档例外(店全是想要的) · **[11]** 零息损技术口径 · **[12]** 息律对升级的应用 · **[28]** P1 验收框架。

- **[2]** 前期可以**卖血**;**少刷新商店**(刷新 2 金/次),**优先凑息(50 金)**;但也要买**过渡阵容**。(簇定位:[17] 的前期形态;独有点=卖血/少刷)
- **[6]** 中期凑阵容为主;**偶尔可掉到 40/30 金少要点息**——前提是商店全是想要的;正常情况优先 50 金。(簇定位:[17] 的破档例外;独有点=例外条件)
- **[11]** 金 <20(1 息档内)买过渡件**不损息还压缩牌库**——攒息不该拦无损购买。
  **动态无损机制(2026-08-31 用户精确化,口述原话)**:「节点1不够凑息,买了,是为了压牌库;节点2
  发现有凑息的可能,是可以将备战卖回去来凑息的——这就是无损的原因」。零息损不是静态轨迹断言,而是
  **含卖回恢复通道的动态断言**:1★ 买牌全额退(往返净 0,cw_state.sell_refund),备战席里的牌是
  「可随时变现回息档的活期资产」——节点内金不够凑线时压库,临结算可卖回补线。静态双轨迹模型
  (禁卖)测出的 5-10 金残损=p47 的**上界口径**,不是实践口径。残余非零项(如实登记):①star≥2 且
  cost≥2 卖回有 −1 手续费;②息结算时点若计窗口中段金位则有一个结算周期的敞口(待实机核,p47 A2);
  ③**卖回还池(用户确认 2026-08-31,机制事实)**:卖出的牌回到池中,压缩解除、往返池中性——零损不变,
  但压库收益只保留在「没卖回的牌」上 ⇒ 凑息时**卖回量最小化**(卖到刚好够线)是对的习惯。
  精确口径:**购买后仍在同一息档**(不跨 10 的倍数)才零息损;跨档最多损 1 金
  (如 11 金买 2 费降到 0 息档,损 1 金);贴档线(10/20/30/40/50 的 ±2 金内)时按 [22]④ 凑息账算。
  (簇定位:[17] 的零息损技术口径——「攒息」不拦不破档的购买)
- **[12]** 连 50 金都没凑到**不急着升级**——追级的前提是息引擎已立;前期收入撑不起边吃息边追级。
  例外:人口位升级([33],有框架单位等着上场)不受本条约束——上场单位立即产生战力/羁绊收益,
  按该单位的战力期望单独算账。
  (簇定位:[17] 对升级通道的应用;独有点=息引擎前提+[33] 例外)
- **[17]** **50金息律,节点无关**(2026-08-20 定调,三次强调;**簇主条**):利息 5金/轮 @50 封顶 →
  金 ≤50 攒息;**>50 的每一分都没有存的意义,该升级升级、该买牌买牌、该D牌D牌** ——
  与节点无关,任何位面任何节点满息即花。不存在「金在位面内有保质期」这类二阶概念;
  boss/1-7/1-9 的集中消费只是「到时自然满息 + 花的边际价值高」,不是金本身的属性。
  防读半:**金 >50 是常态且健康,不必刻意清空**——超过 50 的部分不再生息但随时可花,
  留着到 boss 轮/成型窗口集中用是合理的;决策判据是「当下有没有边际价值高的花处」,
  没有就留着,不是「金不该超 50」。旧 _boss_spend 病例的病根是**花钱的时机判据缺失**
  (平时 60-70 金闲置),不是金超 50 本身。
  (攻略 plaza #145「资金超50时,用多余金币升级」同口径;实证 bot 病例:旧 _boss_spend
  把花光通道锁在 boss → 平时 60-70 金闲置。)
- **[28] P1 经济纪律:守息过程 + 双指标验收**(2026-08-23 看局70 口述;2026-08-25 W94 修正口径;簇定位:[17] 在 P1 的验收框架):
  进 P2 时带 ~50 金是**健康经济的表征**(P1 各轮守息的自然结果),**不是可独立优化的验收目标**。
  - 过程纪律 = [17] 在 P1 的逐轮应用(守息不破;必要的小额破息按 [19] 三态谱裁决);
  - **验收 = 双指标:息基保住 × P1 形态达标([13] 成型停手线 / 过渡配方=transition_combos 四体系)**;出口金单独不作验收
    ——单指标优化「出口金 ≥50」会复刻「金 92 过线但板面弱打不动」的假达标(第六局实证:钱在卡上
    和袋子里,不在战力上);
  - 病例实证(局70):r7 金 26 没守住 → r9 boss 前只剩 5(升级+买牌花光)→ 赢了 boss 但进 P2
    身无分文,「打过了也没经济通关」——病根在中途破息,不在 boss 轮消费本身。
- **[41]** **经验整买纪律 + 超息线囤钱**(2026-08-31 口述;血本位([40]②)与金本位同规则):
  买经验 = **需要升级的时候一次买齐**这一级——零散买 XP 完全无效益:不够升级的 XP 既不产生任何效果,
  **也不能压缩牌库**(买牌才压库,买经验不压),是纯零收益的库存;故购买策略 = 攒够(need−自然 XP)的整批
  一次性买入,触发即升级。
  **推论(对 [17] 的精确化):>50 金也有场景要囤钱**——[17]「>50 每一分都没有存的意义」的前提是
  **无待执行的整买目标**;当升级时机临近(p39 双臂门将过)且当下无必要刷新(合格集空/EV 为负)时,
  超过 50 继续攒到「整批成本+保息下限」是最优——利息在 50 已封顶,超额囤金**无持币成本**,代价只是
  放弃当前无正 EV 的边际支出(数学证明件=p48,重推域=[3]/[17]/[12] 的储蓄-整买交互)。
  **二次精确化(2026-08-31 同日,用户原话——「攒钱模式 vs 花钱模式」二分作废)**:「超 50 随便花」
  的真实含义 = **尽量压牌库**(买可退的卡),不是消费掉;买来的卡 1★ 全额退 = **随时可变现的活期资产**;
  **升级需要、或凑息需要时,把备战里(非上阵)的卡卖掉**筹资。故「囤钱等待升级」的形态不是裸金也不是
  不花,而是**把超 50 的钱换成压库卡(零成本可逆+赚压缩价值 p49),用时按 [11] 卖回量最小化变现**——
  金、息、库三账统一(p48 的 S 判定按「裸金+活期卡退金」口径,见其资产形态修正注)。

## 等级与搜牌

- **[3]** 50 息后:主要看**自己核心在几级刷新概率大**;到这个等级就刷新商店买核心;**没到就少刷新、多买经验**。
  (精确化 2026-08-25,用户原话——此条是经济理论的直接应用,刷新/升级的择取由概率表与期望算出,不靠手感:「如果目标费用在这个等级刷新概率最大,那就是刷新找牌,**但注意是刷新后还能买之后保证 50 金**的情况。如果目标费用要升级后才能提高刷新概率,那就升级」。刷新的预算前提=花完仍守 50 息线。)
- **[7]** 不无脑停留概率最高等级:峰值级概率最高,但高一档也没低太多、还提高更高费刷新 → 取决于整个阵容想要的人;原则 = 在「费用段带」内权衡(峰值级查 `cw_shop_odds.REFRESH_PROB`)。
- **[30] 成本带聚焦买光(2026-08-23 口述,原理泛化)**:「买光商店的 1-2 费」
  的原理是**过渡阵容羁绊件基本都在 1-2 费带**——该带全买 = 对过渡体系的
  定向压缩牌库;**同样适用于中期/后期**:每阶段都有「当前阵容羁绊件的
  主要成本带」,带内买光 = 定向压库 + 零和博弈防对手截胡(池共享)。
  判据演进:「买不买」从单卡价值 → 「成本带 × 阶段」矩阵。
  ⚠️ 「同样适用于中期/后期」是 agent 推理泛化,**未经验证**;适用前提 = 息线上方有余金
  ([17]/[22]④)+ bench 有余槽([22]②)——中后期成本带上移(3/4 费)后买光金量大,
  须先过息线账,且囤件挤 bench 有前科([32] 病例诱因之一)。
- **[32] 消费有效性与腾席优先级(全程通用纪律;2026-08-23 看局72 口述,2026-08-27 口径定稿)**:
  **消费有效性(全程通用,节点无关)**:花出去的金必须转化为战力——买的件上场或有效囤着才算数;换不来战力的开支不做:空升级、无强单位可上的腾席、纯散件垫底。人口 cap 提升当场生效:升 5→6 若**立刻**多上一个成型单位,战力增益当轮兑现,是合法开支([27] 投资全节点变现,花钱判据同 [17] 节点无关)。
  **腾席优先级(全程通用)**:bench 满 → 先卖杂件;升级腾席只在「杂件卖无可卖且确有强单位等待上场」时考虑;人口有余量(cap−deployed≥1)时再升纯浪费。
  留钱吃息的纪律统一归 [28]/[17],本条不另设「禁止花光」禁令。
  病例注(局72,保留为提醒):r9 腾席链连升 5→6→7、进 boss 剩 4 金——真病是升完没有能上场的强单位(钱换成空 cap),不是「升级」这个动作本身;该局当时也完全没有存钱吃息意识,提醒的是「留钱吃息」,不是一条独立的禁令。

## 阵容与过渡

- **[4]** 核心不只是输出:一套阵容输出和辅助都不可少,中途也要买辅助;辅助 **2 星就够、1 星也没所谓**,能 3 星更好(可囤一下冲 3 星)。
- **[5]** 输出核心若是 4/5 费(需很高等级才买得到)→ **必须有低费输出保证过渡**。
- **[8]** 后期**必须阵容羁绊凑多人效果**才能通关,**散装不可能通关**。

  - B 随节点位置递增(必修一「节点越后扣越多」;P3 boss B=35[好游快爆];
    P2r1 实测 B≈10;普通战斗 -7~-13 ≈ B7-10+小额 P);
  - **P ∝ 敌方剩余血量**——「伤害未达标」与口述「敌剩余越多掉越多」是同一机制
    两面:最低伤害需求≈敌总血量,我方输出=达标量;局48 boss -3(核心全 2★+装备
    集中)≈ 清空敌血 → 伤害达标 → 只付位置基础扣;
  - 失败判定 = 行动值耗尽未清场(**含超时**——PTT 实证「时间到没死人也扣血」);
    非 TFT 式「存活单位数×星级」公式(检索未发现该形式);
  - 真值采集点 = **结算屏 OCR 三项拆解**(挑战进度±N/基础伤害-X/未完成进度伤害-Y;
    economy.md:111 已有先例),比间接拟合可靠;
  - 策略含义:每场都是质量战——中期投资(3合1 升星/装备集中)在**全节点持续
    变现**(把未达标罚压到 0),非只 boss 决战才值钱。
- **[39]** **HP 不作为决策依据;经济与阵容是仅有的两个决策面**(2026-09 重建专题轮定调,用户原话:「只要经济和阵容把控好了,hp 自然就会是健康,自然就可以通关」):HP 是运营质量的**下游表征**——判读/复盘用它评估一局打得好不好,决策层**禁止**读它(禁 HP 触发的应急支出/危机分层/止损姿态切换)。强敌节点(遭遇/boss 级)的备战加强按**节点类型**前置(即将到来的节点更难 → 成型强度要求更高),属阵容管理,非 HP 反应式。
  收口与推论:①[18] 保留「报警=质量信号」语义,其「止损」的正确实现 = 回头修经济/阵容决策本身(它们才是因),不是 HP 驱动的应急通道;②(推论)[19] 的「血量安全边际」裁决变量随之退役——连胜-息取舍按经济账算(连胜在手/来牌/息差);③[27] 掉血公式服务判读归因,不进决策;④旧证明族的 HP 驱动决策域(濒死升级/死亡窗分配/危机火力阶梯)不再重推。
- **[40]** **血账本规则**(2026-08-31,OPEN-6 裁定;**同日二次收窄**):血本位突变(奋斗协议/不等价交换等)的处置——
  ①**主动选择=回避**:E1/E2/E15 三选一**不选血本位卡**——其期望价值依赖板面强度(战力→胜率域,建模做不好且强弱不对称:强局省金边际低/弱局致命),回避≈保守最优;
  ②**被动获得=最简安全带**(远见随机棱彩/不可刷新期权避不开;2026-08-31 三次简化:**不留安全量**):血余额 ≥ **下一级血成本**(⌈need/4⌉×6)才买经验,否则停(升级走买牌送的自然 XP)——只看下一级所需,不设单场最大掉血/安全系数等缓冲常量;
  ③血**仍不作运营质量信号**([39] 判读域不变);「账本作为启用该类策略的定价通道」**作废**(一次裁定曾允许,二次收窄撤销)。
  附:「更积极追逐战力以保血」不做(需胜率模型进决策层=ADR-0512 禁域)。

## 攻略学习方法论(元原则)

- **[25]** **逐篇精读攻略,别以偏概全**(2026-08-20 定调):官方 plaza API 的攻略带作者
  文本描述(运营思路),**必须逐个逐个看,不能偷懒**——单个攻略的打法(如「1-8 全卖
  过渡」)不能当通用规则引用,要看全部攻略后才提炼;每看一篇记录一篇(标注攻略 id/
  作者/like 数),这是学习这个玩法最好的办法。(产出:`.debug/temp/currency_war/
  plaza/reading_notes/`,663 帖精读笔记 + 专题检索;提炼结论进 plaza_methodology.md。)
- **[26]** **以官方 API 的阶段阵容数据为准**(2026-08-20):plaza 帖的
  `tourn_detail.role_stages` 按阶段(Early/Middle/Final)分开记录阵容——「P1 阵容与
  P2/P3 是分开的不同阵容」是游戏本身的建模,不是玩家习惯;策略设计应对齐这个阶段
  结构(P1 过渡框架 / Middle 半终局 / Final 终局,见 plaza_methodology M3-M5)。
  **修正(用户 2026-08-24)**:分阶段=**对应游戏内 3 个位面**的显示映射,非额外
  的「游戏建模」;三段阵容不同的**根本原因=等级/人口/累积经济随位面推进 →
  各位面可选阵容集不同**:P1 等级压死人口,凑不出高阶羁绊 → 只能选**低阶激活
  就有战斗力**的羁绊过渡(过渡阵容=资源受限阶段的最优解);P2 起人口等级上去,
  能买高费角色、凑高阶羁绊 → **转型开始,并持续到 P3**(连续的资源驱动演进,
  非三套离散阵容;P1 过渡与终局阵容是同一策略在资源解锁下的不同阶段形态)。
