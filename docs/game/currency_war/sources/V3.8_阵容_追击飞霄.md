## 机制(怎么 work)

飞霄(大飞老师):后台攻击也叠**飞黄**(加速大招);**每天赋追击永久 +6% 追击增伤**(正常打一把 **700~1000** 追击增伤,不需刻意叠)。**追击羁绊 ≥3 → 攻击附加 150❓/300% 倍率伤害**(追加攻击伤害)。

**核心思路**:多触发任意形式的攻击 → 让 3 追击的 150 倍率多打几次(双战技 + 3 追击 ≈ 多 2 个大招伤害)。

## 仪器 / 专武(★)

- **风套 + 攻击球**(增伤区全由天赋买单 → 不带风伤球)。有条件推荐**真理专武 > 飞霄自己专武**:飞霄主要倍率 = 星级相关的天赋追击倍率 + 追击羁绊 150 倍率,都是**追加攻击伤害**,吃不到飞霄专武的终结技词条;真理专武词条可全吃。
- 开局「480 真伤魔戒流」❓ —— 可以但没必要(正常打强度充足)。

## 阵容(格子多)

**只需开 3 巡猎 + 3 追击,剩下随便带高拐**。
- 前期 3 巡猎 3 追击:飞霄 + 貊泽 + 娇秋❓ + 猫❓。
- 后期:飞霄 + 貊泽 + 砂金 + 知更鸟(鸟)。
- 高配:飞霄 + 砂金 + 灵砂 + 托帕 + 知更鸟。
- **飞级半辅助**(低成本拐):记忆主 + 克律❓ + 缇宝 + 阮梅。**克律❓ 对飞霄重要**:复制飞黄加快大招循环 + 多触发攻击。
- V3.8 巡猎(狼尊)和大飞前期强度都高:**3 追击 3 巡猎 2 减益开出来就守血**。

## 开局 / debuff 禁忌

- 开局推荐:三星装备开 / 初心开❓;狼尊徽章 / 追击徽章 / 护盾徽章 / 贝洛伯格徽章 / 开❓ —— 来一个都舒服。**飞霄带贝洛伯格转很强**(靠 2 贝洛伯格高频拉条刷新飞霄追击次数,类似真理)。
- **debuff 一定不能有「正当防卫」**;最好没有第三位面**「盗火行者」**(飞霄难打)。
- 第一二位面可打遭遇骑二甚至骑三(多叠被动),前提**连胜不断**。高配(1 鸟 1 缇宝 1 飞)可直接逮遭遇骑士开创。

## 生存位(按 debuff + 转职灵活)

砂金 / 灵砂 / 杰帕德 / 符玄(盾丹)。**优先前台生存位**(后台可操作性低、急救不稳)。
- 有**灼热轰炸** → 砂金 1 号位(无脑选)。
- 无灼热轰炸 → 砂金需做生存装(反甲/光盾)。
- 生存压力小(永久创伤 / 复仇心切❓ + 无拉条 debuff + 生存装好 + 无黑草❓)→ 飞霄队可上**灵砂**(不当生存位,当输出/功能;刚续续能翻❓;有财富宝钻 / 4 星回能光❓ 最好)。

## ★出装:2 暴击刀 + 1 火力风暴潮

最优 = **2 把暴击刀 + 1 火力风暴潮**(不是双 / 三风暴潮)。理由:**5 级狼 35% 暴击率 + 2 暴击刀 = 刚好满爆**;双风暴潮装备压力大(鞋得让给队友)。
- **永动机非最优**(过渡用):一把最多激活一次,提升小;且合成占两把小刀,出大刀后再无小刀。

## 成型节奏

1. **第一位面**:开 **2 DOT** 慢慢过渡 → 等第一只飞霄 → 伤害留给飞霄打(多叠被动)→ **保连胜**(收 3 星飞霄或上 9 的本钱)。装备太好导致被动叠不起来 → 手操少开大、走到底多叠。
2. **第二位面**:6 级找 **2 星飞霄** → **卡 50 金**,把 2 费牌放备战(不 D 不合)看牌顺不顺 → 决策追 3:
   - 没 D 牌飞霄自然 5-6 张 → 二位面 boss 关前大量 D 追 3。
   - 6 级提前出记忆主 / 知更鸟(支撑中后期)→ 可追 3。
   - 过一整位面飞霄还只 3-10❓ 张 → 直接升人口到 **8 找记忆主 / 知更鸟**。
   - 条件允许**上 9 找托帕 / 砂金换貊泽**大成。

## 小技巧

- 大招留到 **12 层快满**再放 → 吃更多层风暴潮前台强度,大招伤害更高。
- 永动机飞霄诀窍:大招卡在**永动机 1 层 + 12 层飞黄**时开 → 连续 4 大 + 翁瓦克 100% 拉条再次拉回走顶。

## 弱点

- **刚需练度**(自有飞霄 + 风套,试用基本玩不了)。
- 怕「正当防卫」「盗火行者」debuff。
- 装备:需暴击刀 ×2 + 风暴潮 + 鞋(给队友)。
