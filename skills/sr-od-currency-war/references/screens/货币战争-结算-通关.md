# 货币战争-结算-通关

## 画面简介

第三位面首领（节点 3-7）打赢后的战果页：标题「挑战成功」，标题下方一行是节点名与连胜数，中部是「挑战进度」和大号进度数值，底部是「前往结算」按钮。点「前往结算」进入终局结算链（对局详情 → 战报 → 回大厅）。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-挑战成功 | 标题「挑战成功」（画面身份锚） | 纯显示 |
| 标识-挑战进度 | 「挑战进度」标题（画面身份锚；与「结算-失败」同名区域靠标题「挑战成功 / 挑战失败」区分） | 纯显示 |
| 文本-节点与连胜 | 标题下方的节点名与连胜数一行（如「3-7首领 火热连胜×10」，内容随局变化） | 纯显示 |
| 区域-挑战进度数值 | 「挑战进度」下方的大号数值（随局变化，OCR 读数） | 纯显示 |
| 按钮-前往结算 | 底部「前往结算」按钮 | 点击进入终局结算链 |
