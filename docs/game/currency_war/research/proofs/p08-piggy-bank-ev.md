## 命题(重述,零参数形态)

扑满关(经济过热环境的奖励型战斗节点)血损恒 0 → 损失=期望奖励差(非 HP);「怎么都要凑一个羁绊来刷伤害」是参数化条件命题,**是否正期望取决于实采参数**(达标概率增量 × 奖励值 vs 净成本),数值授权在参数采到前不存在。

## 证明(结构段,零参数)

**S1 损失结构(维持)**:扑满关败=0 奖励;扑满关本身不掉血([16] 口述,2026-08-26 纠正:系扑满自身机制,与 0hp 保底无关)→ **血损恒 0,损失函数=期望奖励差**。全账无血变量,纯金流公理(P51 公理栈)合规。

**S2 两臂 EV 门式(参数化骨架,系数待实采)**:零投入(板面 e0)期望 = q₀·R;净投 c 金凑 1 羁绊(e1)期望 = q₁·R − c。**凑羁绊正期望 ⇔ c < Δq·R**,其中:
- **q = P(伤害达标 | 羁绊档)**——伤害阈值/限时口径(机制原文「跑得超快」=要在扑满逃走前打出足够伤害),**禁用战斗胜负口径阶梯代理**(旧版借 H3 胜率阶梯即此错;且最新全量语料 e0→e1 胜率边际实测 ≈0 甚至为负,即便胜负口径也无正增量可借——两口径不同物,胜负数据无论新旧均不可灌入 Δq);
- **R = 扑满关战利品折金**——原文「掉落更多**战利品**」,是否等价金收入未采,禁按普通奖励节点收入折算(旧版 R=6-9金 系无溯源合成值,撤回);
- **c = 净成本**(见 §2 成本账,≠ 面板支出 s)。

**S3 深花保血辖域(维持,零参数)**:boss/遭遇窗的深花下探授权对扑满**不适用(禁深花保血)**——深花保血的收益端(掉血)在扑满语境结构性不存在(S1 血损恒 0 ⇒ 保血收益端无处兑现),由 [16] 口述+机制结构支撑,不依赖任何数值。

## §2 成本账(重推修正:净成本 c,替代旧版纯消耗口径 s)

旧版把面板支出 s 记为纯消耗,**高估成本、低估期权**。净成本三件:

1. **卖出全额退期权(P1/P6 联动,旧版漏)**:买入的羁绊件可全额卖回(`sell_refund` 无手续费)→ 凑羁绊的真实净支出 = 破息差 + 机会成本,面值 s 中可退回部分是**押金不是费用**;持有期内它近似免费期权(P6:压库=零/微息损+免费期权)。
2. **息损项(旧版漏)**:买入若使金跨息档下穿,息损按 **p47 规范形式 L(g, d, R_全局, Ī) 双轨迹递推现算**(禁旧式 t×min(R,3),双侧证伪);且卖回通道使该账为**上界口径**——羁绊件临结算原价卖回则净 d→0、息损消失(p47 A5 边界)。
3. **机会成本**:占用的刷费/档位预算按 p40 框架同帧比价,不在本篇展开。
