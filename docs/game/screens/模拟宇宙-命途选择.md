# 模拟宇宙-命途选择(sim_uni_choose_path)

经典模拟宇宙**开局选择命途的页面**(游戏内标题「命途」):在[初始配队页](模拟宇宙-初始配队.md)点「启动「模拟宇宙」」后进入。横排展示 8 个命途图标(存护/记忆/虚无/丰饶/巡猎/毁灭/欢愉/繁育),点击命途后展开该命途的增益详情与底部确认按钮。选择类画面:选中态=中央图标金色高亮+右侧详情面板,未选中态=仅横排图标+提示文字。

## 何时出现 + 状态流转

- **入口(实测 2026-09-26)**:[初始配队页](模拟宇宙-初始配队.md) → 点「启动「模拟宇宙」」(等级不足时先弹通用确认框)。
- **子态(实测)**:
  - **未选择**(主态,bot 识别锚所在):8 命途横排+顶部提示「请选择想要踏上的命途」,无确认按钮。
  - **已选择**(点击任一命途后):中央该命途图标金色高亮+增益详情面板(命途增益/命途回响/回响构音),底部出现「禁用命途」槽位×2 与「确认命途」按钮。已选态为秒级过渡帧(bot 选完即确认),不独立归档 fixture。
- **出口(实测)**:点「确认命途」→ [宇宙选择页](模拟宇宙-宇宙选择.md)(开局宇宙类型三选一)。

## 识别特征(稳定锚点)

- **id_mark**:提示文字「请选择想要踏上的命途」(pc_rect 790,108-1120,168,OCR conf 0.99)——未选择态独有长文本。已选态此文字消失(过渡帧,不设锚,运行时靠流程位置识别)。
- 命途图标本身为灰白图形,OCR 只能读到下方名称文字(存护/记忆/…),图形选中高亮不可 OCR。

## automation 要读信息

- **目标命途选择**:bot 按配置的命途名在命途名称区(横排 y 650-715)做 OCR 匹配并点击(旧代码 `SimUniChoosePath` 用 area「入口-命途区域」整条 OCR;新档按单命途 area 粒度建模,可精确点击)。
- ⚠️ OCR 噪声:「毁灭」会被读成异体字「毀」(conf≈0.85,2026-09-26 实证)——匹配需容错(LCS 相似度),勿做全等判断。

## 识别快照(analyze_screen 实测,2026-09-26)

- 未选择 fixture **精准命中**(is_precise=true,8 命途名称全命中)。已选态帧 id_mark 消失(过渡态,符合预期)。
- 未选态布局:星空背景,命途图标横排居中(y≈470-620),名称文字在图标下方(y≈667-700);右上规则说明+↩。
- 已选态布局:中央金色命途大图标+左右切换箭头,右侧详情面板(增益/回响/构音),底部禁用槽×2+确认命途。
