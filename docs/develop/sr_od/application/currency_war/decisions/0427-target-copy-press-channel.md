## Context(为什么)

目标外同名副本被候选守卫一律拦成「无效换卡」,但段级检验实证其中相当比例是按口述裁决**该买的压库件**:W281 批披露的真拦形态中,压库带副本与无损买被地板拦是主形态,而既有检查器把它们计入违规。口述裁决给出了完备规则(压库判据按费用档、bench 余槽硬门、插件末位),但落码前经两轮对抗审计暴露:真实生成拦截点与设计假设不符、副本评分结构性零分使通道近乎空臂、A/B 无注入点等阻塞项——v3(V-B0~V-B9)逐条给出可落码修法后实现(`66ddeed1`),A/B 按 R2 判「有效收敛」后开臂(`cb7688d4`)。

## Decision(逐条)

### 1. 内联块收拢为唯一守卫合成点

对抗复审实证:真实生成拦截是 `candidates.py` 的**内联五臂块**(直呼 `copy_swap_useless` + 目标件豁免 + filler/star 各臂),它不调用 `_copy_swap_blocked`;后者全仓消费点仅供给一致性探针。按旧方案落码 = 生成层零行为 + 探针红灯的假绿。修法:

- 内联守卫块收拢为一行 `if _copy_swap_blocked(...)`,该函数扩为**唯一守卫合成点**,臂序 = ① target-exempt ② filler_star ③ sd_gap ④ press 豁免臂(本通道);
- 收拢本身行为保持:重构前后 `generate_candidates` 输出逐位对拍(n=40,v11 池,ADR-0415 零漂移门),对拍红先修对拍再加新臂;
- 生成层与探针共同调用同一函数,双源以「内联块消失」的方式收敛(sim-testing「单源直通」纪律)。

### 2. press 标签臂与评分域

- 生成守卫放行后的副本仍会死在 `_buy_tag` 返回 None 与层3非正分拒两道门(W231 已证副本评分结构性零分)。修法:`_buy_tag` 加 press 臂产出具名标签 `copy_press`(置于既有 `copy` 之后,不抢语义);registry 新增 `press_copy_unit`/`press_core_mirror_bonus` 独立给分域(不改 `filler_star_unit` 默认值,既有 A/B 通道零波及),core-mirror 前置落为评分分量而非平行排序键(arbiter 分数贪心是唯一跨候选序,禁止第二序)。
- **band 推导与权威序**:`press_band(level, probs)` 由 `REFRESH_PROB` 前缀累计 ≥ `press_band_cum_threshold` 推导,叠加轮岗 observed 概率优先(读屏真值,取不到退基线);P1 开域(lv ≤ `press_channel_max_level` ∧ plane==1)内 band 强制并入 {1,2}——**口述锚([30])为最高权威,推导为下位证据**,0.50 阈值降级为中后段守卫参数而非行为旋钮。
- **方向外副本语义(实现发现)**:落码后确认「方向内/既有通道优先」——press 形态副本经守卫放行后,凡属方向内语义的由既有标签(`d2_line_opportunistic`/`d2_pair`/`d2_copy`/`d2_engine_seed`)消费,`copy_press` 标签只兜既有通道不覆盖的残余。通道价值主体在守卫放行与地板豁免,不在新标签(见 Consequences 悬置声明)。

### 3. [11] 地板裁决(地板击穿显式声明)

FORM 段金地板与 [11]「同息档购买不损息」冲突是 W281 主根因。裁决:**[11] 同息档/1 费豁免臂升为三相位共用前置臂,保息档线、不保 form_floor 本金**——FORM 段允许击穿 20 地板至息档线。理由:金 <20 时 after ≥ floor 恒假,加本金条件则主修归零;form_floor 的「本金下限」语义让位于 [11] 最高权威口述。防线 = 逐轮 cap(下条)+ 经济卫生副锚(破息轮次)A/B 兜底;HOARD 段既有同款豁免是已验证行为,不变。

### 4. 逐轮 cap(豁免量控)

registry 两个量控字段:`press_copy_round_cap`(press 候选逐轮采纳笔数,=1)与 `press_exempt_round_cap`([11] 豁免臂逐轮放行笔数,=2,因该臂辖方向内+press 两股)。arbiter 采纳循环内计数,超 cap 后豁免失效、回落现行约束裁决——「同息档即量控」只对息损成立,不量控本金,故需显式 cap。W368 验证:cap 未引入破息涟漪(破息率反而下降)。

### 5. V-A3 撤销(插件臂不实现)

v2 曾把「插件 2 星」实现为末位买臂,v3 撤销:① 其前提需全店扫描,与逐卡谓词签名不动矛盾;② 死臂——层3评分对副本结构性零分(W231),触发条件在本批评分域外几乎恒假;③ 口述「才考虑」的正性无证据(P4 已证伪浓度增益、插件收益自认无法量化),在 press 通道待验证的批次并行开第二条未证通道违反 A/B 单变量纪律。表树同步:E05/E07 维持「不买」,枚举完备性不受影响。

### 6. 验证与开臂(W368,`.debug/temp/currency_war/w368_press_ab/`,n=300/臂,同池同 seed)

按 V-B4 统一兑换映射 R2 判定「有效收敛」落码:

- **seg 真拦 0.3233→0.0467(−85.6%)**,残留 ≤ 0.15 线内;通道关闭披露键 `copy_press_channel_closed` 41→**0**(通道开通的直接证据);
- **core2≥1 进场率 24.3%→49.0%(+24.7pp,CI 不跨零,三窗全部复现)**;成型率 +6.0pp 显著;主指标 star≥2 +3.0pp 未达 MDE(+7.2pp)——按 R2 预定条款,收益主体落在 sim 局级二项指标无法分辨的面(过程行为收敛 + 3合1 期权,merge 总数 +76% 互证),P4 张力已向用户呈报观测极限;
- 副指标无任何一项劣化(破息 0.0567→0.0300、溢余滞花下降、线外填充买入不升反降),无回退候选 → `cb7688d4` 开臂 `press_channel_enabled=True`。

## Consequences

- **copy_press 标签 0 买入 = 评分路由悬置声明**:600 局中 `copy_press` 标签买入为 0——行为增量全部经守卫放行 + [11] 豁免臂兑现,`press_copy_unit`/`press_core_mirror_bonus` 的注入取值(0.5/0.5)**未被行为兑现,本批数据不能作为该评分路由有效或无效的证据**。其网格标定无观测支点,路由去留留待未来单独裁决(A/B 布尔转正判据照 ADR-0411 先例)。
- **方向外限定的影响面**:通道停机条件 = plane==1 ∧ 带自洽闸(推导带 ⊆ 过渡带集合)——P2 起/level≥7 整通道退场,买家不再发 press 买、检查器不再发 C-B/C-C 事件;中后段费用带扩展「只加数据不动结构」,但当前无通路。
- **双 cap 残留 14 例 = 设计内声明**:开臂后 seg 真拦残留 14/300(0.0467,≤0.15 验收线)属 cap 量控与误报残基(engine_affinity_off 类)的设计内余量,不是缺陷;披露键(`copy_out_of_band_skipped`/`copy_bench_only_skipped`)归零/低量维持可证收口。
- **与 ADR-0426 的互补关系**:本通道治「凑档」的买侧(压库带副本从「无效换卡」转放行),ADR-0426 的 release 门治其卖侧(FLIP 帧不卖息凑档);两侧共用「不新增破息例外」纪律——本通道消费的是 [11] 无损购买面与逐轮 cap 量控,不触息律公式(与 ADR-0426 Decision 2 同一语义:破息只经显式裁决的例外列举)。
- **挂账**:E08「core 同名副本但 ∉ band」的防御性红利豁免维持不能(sim 无对手模型,永久以口述原文为准);`press_band_cum_threshold` 敏感性扫描降级为守卫验证,敏感再立项。

## 增补(2026-09-06):copy_press 评分子路由定谳清理(删码留档;策略开关生命周期第 4 态)

Consequences 第 1 条的悬置声明(「路由去留留待未来单独裁决」)经审计裁决为**定谳清理**:评分路由在现行标签裁决序下没有属于它的行为面——0 买入 = 「生产默认 `press_copy_unit=0.0` 构造性恒零(死于 arbiter 非正分门)」∧「生成域被上游臂(engine_seed/plugin/copy/pair)截流至近空(W368 显式注入 0.5/0.5 后 600 局仍 0 买入,注入也救不回)」的叠加,不是「标定值没调好」。保留挂起不可选(自然观测支点不存在,开臂判据挂账写不出来=生命周期门定义的已判决未执行悬案禁形态);定向验证价值被双重封顶(行为增量已被守卫放行 + [11] 豁免臂兑现,残余域副本无独立收益机制,3合1 已被 copy/pair 通道覆盖)。审计证据链(悬置实证、生成截流逐臂覆盖面、三选一评估)见 `.debug/temp/currency_war/w419_copypress_audit/REPORT.md`。清理批执行时的一处口径修正:审计的「默认态构造性恒零」在探针帧不严格成立——copy_press 候选的板面差分含 depth 维正分量(bench 余槽代理),默认态并非逐帧非正分;但该正分不改变定谳结论(600 局 0 买入由生成截流主导,偏置无独立行为兑现),删除的零漂移不变量照常成立。

### 行为不变量与复活条件

- **零漂移不变量**:被删偏置生产默认恒 0.0,删除=恒 0 分支移除——默认行为逐位一致(全集回归验证,hash 锁同步)。删除后 copy_press 候选照常生成,评分只由通用板面维决定,与删除前默认态一致。
- **复活条件(显式)**:仅当未来标签裁决序重构使「非体系 ∧ 非插件 ∧ 非成对 ∧ deployed 同名 ∧ 1-2 费」残余域变宽(上游臂变动有实证)时才可重新立项;届时从本 ADR 正文 + 增补节 + git 历史重建,不复用删除前代码。另:与 W416 配方围栏(ADR-0432)的「开臂态单向压制」交互面随本路由删除而消失,围栏开臂批无需再为本路由做共存分析。
