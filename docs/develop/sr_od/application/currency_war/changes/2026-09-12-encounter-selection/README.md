# 2026-09-12-encounter-selection（遭遇选档简化）

> 状态：**对抗审中**（无前提攻击循环）。
>
> ## 用户裁定汇编（均为 2026-09-12）
> 1. **遭遇奖励 = 伤害进度达标制**：战斗上方进度条打够最低进度（红→黄）即拿奖励，非清场制、非二元胜负（外部攻略 [vgover](https://www.vgover.com/zh-tw/news/188183) 实证 + [27] 掉血结构互证，已录 `research/combat.md`）；
> 2. **选档判据轴 = 我方输出估计 vs 各档需求线**（用户方案）：用前两场普通战斗的敌方血量消耗结果估计输出能力，比需求线选最高可及档；
> 3. **HP 的未来影响不进遭遇决策**（用户原话：「不需要考虑 hp 对后面的影响的，我的策略核心是发展为主，只要发展好了，我相信是必然通关的」）——λ_death 复利/胜率合成不入遭遇选档；mandate EV 核（原 ADR-0536 生产轨）的存在前提随之否定，处置 = 搁置让位；**ADR-0536 已退役删除**（用户命令 2026-09-12，decisions/INDEX 留墓碑行，编号不复活）；
> 4. **刷新保留**（换批语义：全档需求线都够不着 → 换一批）；
> 5. **奖励 tiebreak 补消费端**：选卡屏奖励预览**读数已在**（`read_encounter_options` 2026-08-07 baseline，每卡单项文本）——缺的是 tiebreak 消费端与多件结构化；
> 6. **结算屏现成读数（含我方掉血分量 B/P）授权进遭遇决策 + 观测数据入 GameState 持久化**（2026-09-12 用户裁定——01 §2 公理 3/[39] 收口③ 的例外扩大程序完成）：结算观测环深度 = 10（环行模型已知下限 5〔跨位面窗；同位面 2〕+ 工程余量，论证 details §8）；v1 判据仍用敌方通道（裁定 2 字面），P/B 为已授权升级量；
>
> ## 机制事实（文档/代码直调）
> - 难度值游戏定义可算：遭遇等级加成 其一0/其二10/其三20/其四30（economy.md:107），bot 逐帧读旗牌值；
> - 输出估计的输入数据现役归宿 = `session.performance.history`（RoundOutcome）；outcomes.jsonl 写端已随删除波 1 退役——**跨局持久化缺位**：判据同会话闭环零新采集，跨局标定/经验需新增采集面（details §8）；
> - 分级信号 = 敌方侧结算观测（killed / 进度填充率 / 伤害求和，生产写端在册）；我方掉血分量（基础伤害/未完成进度伤害）已授权进决策（裁定 6），v1 不消费、入环保存；
> - 结算观测数据归宿 = **GameState 结算观测环（深度 10，E-2 建）+ 遭遇经验表**（判据/经验层读源）+ `performance.history`（观测分析层全量账本，不动）；
> - 判据 D 值 = 备战帧旗牌读值（逐帧真读在册；旗牌语义 = 该节点自身合成真值——遭遇·首领节点才含 −4；**遭遇决策读点 = 前一普通战斗节点写入值**，Δ_t 取净值，details §3）；解析合成兜底 v1 不建；
> - 战斗中百分比条**未采集**（离线零战斗帧、战中不读屏）——v1 不需要它（结算观测已构成分级信号）；
> - 掉血量已测（P15v2：P1 遭遇败局 ~12.2 [10.32,14.24]；P2 遭遇 33.2 薄桶方向性参考）；低保线数值定义（进度百分比/奖励分段）无载，实采定谳点 = 结算屏三项。
> - 现状：mandate EV 核双 provisional 槽 None 期 → 恒选最低难度、零刷新（实机行为）；基线核（知识判据）在册。
