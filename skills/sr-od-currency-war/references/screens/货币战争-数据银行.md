# 货币战争-数据银行

## 画面简介

六大图鉴（羁绊/角色/装备/投资策略/投资环境/竞争对手）的入口主页，也是各图鉴收集进度的读数位：大厅右侧「数据银行」按钮（实测过）或备战顶栏「数据银行」进入。主页 2×3 入口卡，各带收集进度 n/m（动态值）；已全领取的图鉴卡带「奖励已全领取」横幅。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标题-数据银行 | 画面标题「数据银行」（身份锚，与「角色图鉴」入口卡文本组合判） | 纯显示 |
| 入口-羁绊图鉴 | 羁绊图鉴入口卡（2×3 上排左），带收集进度 n/m | 点击进羁绊图鉴（子画面尚未建档） |
| 入口-角色图鉴 | 角色图鉴入口卡（上排中，身份锚之一），带收集进度 n/m | 点击进角色图鉴（子画面尚未建档） |
| 入口-装备图鉴 | 装备图鉴入口卡（上排右），带收集进度 n/m | 点击进「货币战争-装备图鉴」 |
| 入口-投资策略图鉴 | 投资策略图鉴入口卡（下排左），带收集进度 n/m | 点击进投资策略图鉴（子画面尚未建档） |
| 入口-投资环境图鉴 | 投资环境图鉴入口卡（下排中），带收集进度 n/m | 点击进投资环境图鉴（子画面尚未建档） |
| 入口-竞争对手图鉴 | 竞争对手图鉴入口卡（下排右），带收集进度 n/m | 点击进「货币战争-竞争对手图鉴列表」 |
| 区域-图鉴进度带 | 2×3 入口卡整体带（进度读数区） | 点卡身亦可进入对应图鉴 |
| （待建档）扩充倒计时 | 标题下方倒计时（如「76天6小时」）；动态值勿当画面锚 | 纯显示 |
| （待建档）返回按钮 | 右上角返回箭头 | 点击回上级（从大厅进回大厅） |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 进入本页 | MCP `click` | 大厅右侧「数据银行」按钮（实测过）；或备战顶栏「数据银行」 | 进数据银行主页 | — |
| 进某图鉴 | MCP `click` | 对应「入口-xxx图鉴」area 中心（识别返回坐标） | 切到对应图鉴画面 | 除装备图鉴/竞争对手图鉴外，其余子画面尚未建档，进去后看图操作 |
| 返回上级 | MCP `click` | 右上返回箭头（当帧看图定位，未建档） | 回上级（从大厅进回大厅） | ESC 同效；扩充倒计时与进度 n/m 是动态值，勿当画面锚 |

查数据优先走 MCP 查询工具（cw_char_lookup / cw_trait_lookup / cw_equip_lookup），不必进画面翻图鉴；进画面只在核收集进度或截图取证时需要。进入货币战争用 `CwEntryEnter {}`；本页无专 op。采集通道：`HarvestInvestCodex`（投资策略图鉴逐页采集）；其余四张图鉴子画面尚未建档，按采集需求另派建档。
