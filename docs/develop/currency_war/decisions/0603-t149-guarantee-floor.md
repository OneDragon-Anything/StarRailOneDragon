## 1. 背景与病理(归层:决策层)

史实链:T-126 验证局 P1 出口金=0(HP=60 健康)→ 策略审查把 [28] 出口金 50 定性「旧囤金纪元标记」候裁降级 → **用户直接指令推翻降级** → T-139/T-143 四提交回滚(d15ce341)。

归层结论(方案稿复核成立):**决策层**。缺陷 = `levelup_budget_gate` 的两条豁免支(支A 兑现链放行 / ALL IN 位面末豁免)只有「放行谓词」没有「花后下界」,豁免支可把金花穿到 0——息通道死(0 金位利息恒 0)+ 购买力通道死(p10 §② 局70 同型)。T-139 升级视界/续批只是把该缺口放大成 0 金过 P1 的放大器;回滚拆了放大器,缺口本体在豁免支结构里。修 = 豁免支加「花后 ≥ 保底线」下界;保底线由命题推演,禁拍值。门在支出侧、不在产生它的臂上——对一切续批形态(升级续批类级联)结构性免疫。

## 3. 已实施架构

1. **保底金门**(`criteria/levelup.levelup_budget_gate` + 私有判据 `_guarantee_floor_holds`):ALL IN/支A 两豁免支的放行输出上追加第二条件「花后金 g−s ≥ B」;出辖三支先行让位——
   - **终局域**:位面末战 ∧ R_全局 ≤ 1(`r_remaining` 单一源查表;R 含当前节点,决策帧最小值 = 末位面末战的 1)——域③前提失效,ALL IN 维持花光原语义;
   - **生存域**:`p1_blood_floor`(≤15 族在册授权)——死亡带转化优先,真花光唯一合法通道;
   - **买断制**:cap_resolved = 0 ⇒ 息账整体消解(p47 A1),下界失去推导基座。
   判定挂发射帧现读金 g(决策帧真值);推迟 = 整批推迟(P48 整买辖域,禁按闸值截断击数);推迟终止性 = 定性申报非定理(g 非单调,M2/E_rev/funding/P36-a 均可合法减 g;三条退出路径 = 谓词消失/g−s 越线/减通道在册有界;位面末帧 defer = 跨位面兑现),持续 defer 由分键显影。
2. **拒因分键**:`guarantee_floor_defer`(新,与 `levelup_budget_gate_blocked` 分键区分)——mandate prep 与 shop M3 两发射位及 entry posture 镜像通用转发拒因,零改动自动流通;**shop 必花域 L3 位例外已补转发(落地审中-1)**:该位原固定计 `budget_gate_must_spend_defer`,新拒因会被误归——补 `must_spend_guarantee_floor_defer` 独立分键(域内 XP 花穿推迟与量闸拒分离,禁混键;顺带修该位 `_gate3_why` 契约失败路径未初始化的潜在 NameError),行为锁 = test_cw_guarantee_floor.TestMustSpendForwarding 双支(新键计数 + 量闸拒旧键不迁移)。
3. **推导摘要(数学先行;逐项系数出处 = 方案稿 §1.6 表)**:域③声明(P83,权威 = 用户指令 + P47 A6)⇒ B>0 且取值形态须落在息档结构 ⇒ **g ≥ 10 是「下一向位面首息存在」的机制判等式**(interest 的 10 = 息档宽 = 利息斜率倒数;【注】economy.md §10.1 + `cw_plane_table`)⇒ 第一档边际 ∈[6,10](p47 命题一规范递推:P1 出口语境 band1 = 10/6/6/9,Ī=6..9;**实现批勘误:方案稿「band1 ∈ 全档最大」声明在 Ī=8 反例不成立**[T∈{7,9} band2=8>band1=6]——本门承重 = 判等式 + 最小绑定论证,不在边际最大序,承重不受影响,降格记录见方案 §5-A1 与复算锁 docstring)⇒ **最小绑定支配论证取 B=10**(k≥2 抑制的对象 = 支A 转化支出,而支A 在库身份 =「非已证支配」,第 k 档息价值对转化的机会成本无在册账可计价——扩档的合法性条件 = 先补该账,禁静默蠕升)。首窗一致性校验(非承重):B=10 时 P2r1 备战帧金 = 17..20,落入 p10 §②「能动作」带 15-20——两起点自洽,【拟】级不入判据。
4. **同值异据声明(方案稿 §6-6)**:本门 B=10 与 release 泄息通道 `boss_floor=10`(彼据 = P1 出口金生存边际,ADR-0426,`sim/checks/segments.py` 同值消费)是**两条独立推导的巧合收敛点**——断言只锁同值不锁同据;任一据修订(如生存边际重标)必须过另一消费位重推;两消费位互指本声明(levelup 侧注释已落;segments.py 侧在 sim/ 禁碰面,候 T-169 重锚批补注)。
5. **[28] 裁决落地(三层拆开)**:①恢复 [28] 出口金 ~50 的**表征/验收地位**(非闸门);②B=10(保底)与 50(过程目标 g*)两层并存;③验收读数 = `handoff.gold` 与 `salvageable_1star_value` **双字段并读**(p10 检验点 3 + 结论节实机锚点;§④ 1★卡=活期金「钱在卡上」语源)——防「金在卡上」被误读回穷。
6. **文档三同步**:域③重入册 = math_proofs **P83**(新单篇 + 索引行;编号避让 P81[现被 T-162 占用]/P82[T-139 占用史已回滚],旧指针「P81 域③」不得解析到现 P81);收入修饰三行收窄指针落位(P72 §2.5 ALL IN 前提全局轴收窄/P80 保链前提适配注/P68 阅读门收窄指针);p10 单篇行内注(结论表末行+§③ 的 XP/ALL IN 通道辖域收窄,末位面域内维持;§③ 深花 EV 账对买入/刷新通道仍有效,禁整行作废;消费 p10 刀刃先验取修正值 V 12.2/13.4);残扫 2 低项随批勘误(设计方案 §1.1/§1.2「P10 §④」→「§②」、§2.4-3 跨段混引改双源锚、engine_p1.py 进场继承块注改**纯语义定位**——原 :794-798 陈旧,直调现行实位 :932-937,轻确认审所报 :871-875 亦漂移,防再漂移一律语义定位);strategy as-built(`11_shop_decisions.md` 升级支出量闸段)同步;代码注释引 ADR-0603。
