# ADR-0510 · 必死子带机会成本重定价(死亡域 I 项退役)

> **引用勘误(2026-09-04 ADR 存量 review)**:`prereg/` → `docs/develop/currency_war/proofs/`(math_proofs 索引)。文内出现处按此对照读取。

## 背景

death 域分配器结构性出清失败(W933「并联缺位」裁决;W951/W955 sim
chosen=[] 恒空,频次 7→15/300 上行)。W956 治本设计
(`docs/develop/currency_war/prereg/w956_death_allocator/DESIGN.md`)实施两步后
实测确认:供给解锁(E1/A′,守卫退役+刷新估计器保底)不等于出清——
death 帧 chosen 仍 22/22 空(实施批 REPORT §2),出清卡在机会成本侧
O:面值账 V = m_eff·Δp_eff − (c+I) 在必死帧恒负。

## 决策

`hp ≤ L_c`(`must_die_band`,「再败一场必死」)子带内,机会成本项 I
退役:V = m_eff·Δp_eff − c(面值直出)。c 面值保留(金不为负的记账下界,
出清仍需 Δp 侧正贡献)。谓词单一源复用 `must_die_band`(n=60 标定,与
应急带完全重合、零带外,w956 目录 CALIBRATION.md)。

### 论证链(同一数学论证的逐段落地)

P23.4(i) 极限形式(带内 P(存活)≈0 → 金终端价值≈0 → 任何非负板面提案
弱优于攥金)→ W907(应急带金全通道生存价值≈0,支出占优)→ ADR-0503
(危机臂开臂)→ ADR-0508/P36-a′(R*_crisis≡0,储备无保护对象)→ E1
(W956,w-only 拒供退役)→ 本步(成本侧 I 项同理退役)。息档保护对象
(未来收入流)在带内被死亡截断,I 无保护语义。

### 与 ADR-0493 的关系:子带收窄,非回退

ADR-0493 以 W810 反事实(携金进 P2 三局 3/3 到达可支出语境)退役 S0
折价、全 death 域按面值计。本决策把面值+I 语义**收窄到子带外**;子带内
I 退役。W810 三局形态均在子带外(hp 高于单场败局伤害估计),其证据面
与本收窄不冲突——收窄细则见 ADR-0493 文末增补节。

## 考虑过的选项

1. **全 death 域 I 退役**(否决):W810 证明带外金有真实存活增益,全面
   退役重复「金必死」前提错误,且丢失息档保护的面;
2. **c 一并退役(V_gold≡0,第二账式)**(暂缓):清零最彻底但「金不为
   负」记账下界丢失,负金路径需预算门重审;先落 I 退役观察出清率,不足
   再议(渐进收窄,每步单变量);
3. **必死子带 I 退役(本决策)**(采纳):前提可证(P23.4(i))、辖域
   最小、谓词已标定;
4. **维持现状不接手**(否决):与 P36-a 刷新通道已兑付的设计事实矛盾
   (半途声明不接手逻辑不自洽),且残留面在恶化。

## 后果与验证

- 影响:`_opportunity_cost` 单点(谓词单一址 `must_die_band`);停手窗域
  与子带外 death 帧行为逐位不变。
- 锁:必死带 opp==c 面值锁 / 带外面值语义不变锁(原缺陷③锁换带外帧)/
  必死带刷新提案出清锁(V>0)/守卫移除红检保持。
- 方案 B 复活前提:授权层非正分门在 V≥0 下的放行以小 A/B 复验
  (PREREG v2,种子窗 959xxx),复活则兜底集一并翻正。
