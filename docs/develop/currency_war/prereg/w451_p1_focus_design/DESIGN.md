# W451 · P1 过渡体系收敛机制设计(design-only,零代码改动)

- 日期:2026-08-28(批 W451);文件面:仅本目录;不改 src;不 git。
- 用户裁决(最高权威):「主要还是 P1 太差,才连带影响 P2」——P1 出口质量是主线杠杆。
- 结论强度声明:本设计每节末标「最弱一环」;全文结论强度 = 各节最弱一环(§2.6)。

## 0. 结论摘要

1. **方向命题可立**:过渡期「协同包(过渡体系)激活」的边际战力价值 > 「散件单卡升星」,在体系达成数 e<2 段严格成立(P3 已证阶梯 + 机制层 + ⑬ 反例三方互证);**量级倍数未标定**(缺单卡 2★ 直接 Δ 数据,挂账 G1)。
2. **根因层定位成立**:⑬ 的散件堆板不是「买牌排序」病(W422 已证排序非杠杆),是**过渡期没有「往哪个体系收敛」的可计算目标**——既有 pick_framework(r70)已有框架选择单一源,但其输出未贯彻为买/留/上三层的名集判据;state.focus_factions(ADR-0209 flex 白名单)是终局线载体,双轨期恒空,过渡期收敛缺位是**设计缺口**,不是字段 bug。
3. **修法方向**:引入过渡收敛目标载体 `transition_focus`(主框架 F + 配对体系 + 名集),由既有 pick_framework 锁定,向三层(买牌评分先验 / bench 卖序 / deploy 替换)贯彻;与 W436 豁免臂、W431 仲裁门、配方围栏(ADR-0432)辖域正交(§3.4)。
4. 落码排程归编排者;本文档 + `CRITERIA.md`(可计算判据清单)+ `DATA_GAPS.md`(采集挂账)+ ADR-0442 草案(§5)为全部产出。

## 2. 数学先行:过渡体系价值量化

### 2.1 命题表述(提案 P20,进 math_proofs 索引待立单篇)

> **P20(提案)**:位面 1 过渡期、体系达成数 e<2 时,把 1 单位金花在「使某过渡体系跨越激活阈值」上的边际战力期望,严格大于把同 1 单位金花在「任一非核心散件 1★→2★」上。

注:数学命题编号顺延 math_proofs 现有 P19 之后为 P20 提案;本批 design-only,不写 proofs/ 单篇(立命题与证明归后续策略批,数据需求见 DATA_GAPS G1)。

### 2.2 收益侧:体系激活的增量(已证部分)

- P3 已证胜率阶梯:e0=13.9% / e1=41.6% / e2=77.8%。**首次激活(+e0→e1)= +27.7pp,二次 = +36.2pp**——这是过渡期可买到的最大单步离散增量;P3 同时给出收入侧 e0→e1 +1.4金/轮(连胜金+息的净期望曲线,已证)。
- hp 传导(P15):条件败面伤害随 rung 每档 −0.37 hp/战;体系激活使 rung 跨整数档(rung x 封顶 2.0,engines 整数档),**跨档瞬间兑现**;并经掉血机制([27]:P ∝ 敌方剩余血量)二次兑现——体系伤害源(神君/列车撞击/超激发 DOT)压低敌剩余血 → 未达标罚 P 变小 → hp 保存 → 息引擎与连胜金复利([27]「中期投资全节点变现」)。
- 机制层(transition_combos 定义):四体系判据均为「一级羁绊即有较高伤害,不吃星级不吃高人口」——体系伤害是**跨单位、跨回合的全队伤害源**;其激活与成员星级解耦。

### 2.3 成本侧

- 体系激活成本 = 买到 1 张该体系的阈值缺口件:1-2 费带(W425 §4:配方基础线主力 1 费,5 种,每槽出现概率 0.075-0.16@lv4-6),金成本 1-2,且 1★ 卖出全额退([22]①/P1 已证)→ **沉没成本 ≈ 0,期望成本 = 1-2 金 + 等待一次 offer**。
- 散件 1★→2★ 成本 = 同名第 2、3 张,即 2-4 金 + 两次 offer;再遇窗口(W425 实测口径换算):特定 1 费配方名单店出现率 ≈0.015-0.032/槽 → 每店 0.075-0.16 → **期望 6-13 店才再遇一次同名**——升星的期望时间成本是激活缺口件的数倍(同带内任一缺口件即可激活时,命中率 = 带内名集并集,高一个数量级)。
- 压库注意:P4 已证成本带买光的池浓度增益 ≤1.0pp——**集中度不能靠压池获得,只能靠「锁定名集后对名集 offer 全收」获得**(W425 §2:实机错过 99.5% 是买得起没买,转化率是策略可动变量,w43 新臂 51.2%→73.2% 实证)。

### 2.4 组合论证(推理链)

1. 体系激活:离散阈值增量(+27.7pp 等价,P3)× 低成本(1-2 金,沉没≈0)× 全队伤害源(机制层)→ 单位金边际高。
2. 散件升星:连续面板增量(单卡乘区,局部)× 高成本(2-4 金 + 6-13 店再遇)× 对 rung 增量≈0(engines 封顶结构,scoring.board_rung_x 语义)→ 单位金边际低。
3. 反例锚(⑬):5×2★、7 阵营、零协同 → 仍弱——星级维拉满不能替代协同维,方向一致性三方互证。
4. 边界:e≥2 后(engines 封顶 2.0)体系档增量耗尽,边际转移回核心 2★([13] 成型三件套的「过渡核心 2★」门)与目标件囤积([21]/[22])——**本命题辖域严格限 e<2,不外推**。

### 2.5 与「核心 2★」的相容声明

[13] 成型三件套要求过渡核心 2★,故「单卡升星」内部要分层:**核心名升星是成型门(必做)**,本命题打击的只是**非核心散件**的升星。收敛目标名集(§3)恰好把「核心名」显式化——这是收敛机制顺带修掉的歧义:散件心态(W425 §2「1 费转化最差 47%」的注释)源于「哪张是核心」不可见。

### 2.6 最弱一环

- 单卡 2★ 的直接 Δ胜率/Δhp 标定缺失(现有数据只能给上界代理:run ⑬ 反例 + rung 结构零增量)→ 结论取「方向已证、量级未标定」;量级采集方案见 DATA_GAPS G1(sim 逐帧台账 w42/w43 可离线复算,零新增实机成本)。
- P3 阶梯的数据源是成型度分档观测(非随机对照),体系激活的净效应含选择偏差;已在 P3 单篇标注,此处沿用其结论强度。

## 3. 收敛目标怎么选(可计算规则)

### 3.1 设计原则

**不新造选择器**——pick_framework(cw_transition.py r70-r107)已是过渡框架选定的单一源(持有整权 + shop 半权 + portal 偏置 +3 + 滞回 + 预囤 + 断供清框架),其输出 `session.transition_framework` 已经存在。缺的是:(a)框架只定主体系,**没有配对体系**(四体系是两两组合,transition_combos 定稿);(b)框架名没有展开为**可计算名集**贯彻到三层。

### 3.2 锁定判据(全可计算,信号源皆为既有量)

```
F       = pick_framework(board, bench, shop, current, portal)   # 既有单一源,不动
# 收敛目标 = (F, P) 二元组,P = 配对体系:
w(P)    = owned(P)                       # 持有整权(板面+bench 的 P 体系件数)
        + 0.5 * shop_cnt(P)              # 店内在售半权(与 pick_framework 同权口径)
        + 3 * portal_hit(P)              # 投资环境偏置(active_env 名含体系名,同 r100e 口径)
        + recipe_overlap(P, stash)       # 终局信号重叠:CommitSignals.leader 的线与 P 共享角色数(配方 transition 段信号,弱证据 ×0.5/角色)
P*      = argmax_{P ∈ PAIRS[F]} w(P)     # PAIRS = transition_combos 两两组合表的合法配对集
tie-break = w 相等取「人员要求更松」者(列车2/DOT2 无人员要求 > 仙舟3 三人组 > 希儿系单卡依赖)——
            依据 = transition_combos 人员要求列(可计算:要求枚举长度)
锁定时机 = F 非空(既有启动门 1.5 合并权)即锁定 P*;F 变(断供清框架/滞回翻转)→ P* 重算,
            滞回继承 pick_framework 的「挑战者持有领先 ≥1 才换」,P* 层不再另设阈值(防双源漂移)。
希儿系特例:P=希儿系 需希儿在手(持有≥1)才可入 PAIRS 候选(单卡依赖,transition_combos 定稿)。
```

信号-辖域对照(任务书四信号全覆盖):已有对子 = owned;前期掉落分布 = shop 半权累积(每轮重算,无需独立累积器);投资协同 = portal_hit(active_env 既有链路);配方 transition 段 = recipe_overlap(CommitSignals 既有 leader)。

### 3.3 展开为名集(focus_names)

```
focus_names = ⋃ 体系阈值缺口名的最小组:
  主体系 F:按 FRAMEWORK_FACTIONS[F] 阵营池 × TRANSITION_PACK 策展名(carry/partial 优先,drop 档不入名集——r107 审计B 口径)
  配对体系 P*:同上
  核心子集 core_names(F,P*):仙舟3=三人组(爻光/藿藿/饮月);列车=无核心(用户 2026-08-24 定调);
        DOT2=无核心;希儿系={希儿}
```

### 3.4 辖域关系(不冲突声明)

| 既有机制 | 辖域 | 与收敛层的关系 |
|---|---|---|
| W436 merge 完成豁免/copy_swap(ADR-0438) | 非正分门对 merge=True 买放行 | **正交且互补**:豁免管「第三张能过门」,收敛名集管「该追哪个名的第三张」;豁免臂是收敛层买侧的执行通道,收敛层不另开删笔(ADR-0437 定谳:硬删排序层已否决,不得复活) |
| W431 仲裁门(arbiter 非正分门) | EV 正负裁决 | 收敛层只提供**评分输入**(隶属度先验,§4.1),不覆盖门的裁决权 |
| 配方围栏 ADR-0432 | P1 未成型段,存在性围栏(有任一配方件则删散件) | 收敛是**围栏名集的收窄候选**:`_cand_system_bonds` 现为「任一体系」,锁定后可收窄为 focus_names;**设计裁决:围栏硬删层保持现辖域不动(未锁定/断供期防饿死),收窄只落在评分先验层**——零漂移,不与围栏开关耦合 |
| C1 末窗 / 成型停手 ADR-0343 | 时窗正交(P1 末窗 / form_ok 后) | 不变;form_ok 与收敛层共享 phase 单一源,无新谓词 |
| state.focus_factions(ADR-0209) | 终局线 flex 白名单 | **不复用不混淆**:过渡收敛用新载体 `session.transition_focus`;⑬ 的 focus_factions=None 是双轨期无 flex 的正常表现,不是 bug(诊断时防误判) |

## 4. 三层贯彻设计(伪代码级,不写真码)

### 4.1 买牌层(scoring 先验 + 既有豁免通道)

```
# 候选评分(score_candidate)加先验项,不设硬删:
m(c) = 1.0   if c.name ∈ focus_names              # 收敛目标名(含核心子集)
     = 0.5   if c 与 focus 体系同阵营(r137 阵营兜底口径)
     = 0.0   otherwise(散件,现状分不变——降低而非归零,保持空窗期 [31] 语义)
# 「差一张」加速:某 focus 名已持 2 份同名 1★ 时,该名 offer 的评分增量走
# ADR-0438 豁免通道(已开臂,第三张被买走=集中度自动兑现),收敛层零新增逻辑。
# 刷新/升级不打折不加分(概率级择取归 P5 已证判据,收敛层不越权)。
```

### 4.2 留牌层(bench 卖序,bench 满触发)

```
# bench 满 → 卖序(从先到后;与 [32] 腾席优先级、2★ 压 bench 修复同族,合并设计):
sell_priority = [
  零羁绊散件(板面+bench 均无任何羁绊贡献,1★ 优先),      # [31] 散件垫底
  非收敛体系的囤件(owned 体系 ∉ {F,P*},carry 档除外),     # 收敛后降级
  收敛体系 drop 档(fw 框架变过后的遗留),                  # r107 审计B 口径
  收敛体系 partial / carry(保护,最后卖;core_names 永不主动卖),
]
# 2★ 素材保护:focus 名已持 2 份同名的,第 3 名素材位永不进入卖序
# (与 ADR-0437 定谳一致:素材保护是留侧规则,不是买侧删笔)。
```

### 4.3 换装层(deploy 1★/2★ 替换)

```
# 空位 >0:按 [31]③ 摆板——收敛体系板 > 其他羁绊板 > 散件;core_names 有 2★ 即上(成型门)。
# 空位 ==0 且店/手有 focus 件可上:替换候选 = 场上「零羁绊 1★ 散件」最优先,
#   其次「非收敛体系 1★」;场上 2★ 仅在两种情况让位:
#     a) 同名 2★ 焦点件(星级不降、羁绊升档);
#     b) 焦点 2★ 可入场且被替者是零羁绊 1★(2★ 降 1★ 换引擎跨档——P20 方向命题的直接应用,e<2 时合法)。
# 被替换下的 1★ 散件即卖(净 0,[22]①)——与 2★ 压 bench 的腾席链共用同一卖序(4.2)。
# e≥2 后本层退化:过渡件停手([13])由 formed_stop 接管,收敛层不再驱动替换。
```

### 4.4 行为不变量(可测试断言)

- 未锁定(F='')时三层全部零漂移(现状行为);锁定后仅评分序/卖序/替换序变化,金账与息账单一源不动。
- core_names 任何情况下不进主动卖序。
- 收敛层不产生新的刷新/升级动作(概率级判据归 P5/[3])。

## 5. ADR 草案(编号顺延:ADR-0442;落码批正式化)

> **ADR-0442(草案)· P1 过渡收敛目标载体(transition_focus)** — 状态:proposed(design-only,落码归编排者排程)
>
> **Context**:⑬ 实证 P1 出口 5×2★ 散布 7 阵营零协同;W425 证供给非瓶颈、转化与集中是;W422 证排序非杠杆;W436 豁免臂打通买侧执行但「往哪个体系收敛」的目标层缺位(P20 提案,方向已证)。pick_framework 已是框架选择单一源,但无配对体系、无名集贯彻。
>
> **Decision**:引入 `session.transition_focus` = (F, P*, focus_names, core_names),F 沿用 pick_framework,P* 按 §3.2 可计算规则选定;向买(评分先验 m)/留(bench 卖序)/上(deploy 替换序)三层贯彻;不新开任何硬删删笔。
>
> **Considered Options**:
> - A. 维持现状(仅 pick_framework 框架名,无配对无名集)——拒:⑬ 根因即此态。
> - B. 收敛目标载体+三层评分/排序贯彻(本文)——采:治本在目标层,复用全部既有门与豁免,零漂移边界清晰。
> - C. focus 硬删式过滤(锁定后非 focus 名买候选全删)——拒:未锁定/断供期饿死(围栏 ADR-0432 已辖存在性硬删,双硬删层冲突);P4 教训(压池无效≠删笔有效);ADR-0437 定谳明确否决排序删笔路线。
>
> **Consequences**:正(方向命题落地、散件堆板有可计算治法、与 W436/W431/围栏正交);负/挂账(P20 量级未标定 G1;P* 平局规则的人员要求松紧为定性排序,待 sim A/B 观察翻转率;三层数值权重 m=1.0/0.5 为符号设计,量级待标定 G2)。零漂移验证口径:未锁定帧行为逐位相等(sim 同 seed off 臂)。

## 6. 结论

- 方向命题(P20 提案)立:体系激活 > 散件升星(e<2 辖域),证据三方互证,量级挂 G1。
