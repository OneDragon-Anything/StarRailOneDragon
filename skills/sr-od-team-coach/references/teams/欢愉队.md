# 欢愉队（银狼LV.999体系）

> 按 V4.7 期（2026-11）调研撰写。靠「全队产笑点→阿哈时刻结算→欢愉伤害齐射」赢的共享资源池体系；对单天花板口径【攻：2026-09 配队共识】。

## 核心思路

- 欢愉命途三层资源循环（笑点→阿哈时刻→好活当赏）与欢愉伤害独立乘区规则见 [path-joy](../mechanics/path-joy.md)。
- 体系根因：**欢愉伤害不吃攻击/生命/防御/常规增伤** → 传统同谐辅助大半无效 → 欢愉角色互绑（真珠星魂1按欢愉人数 2/3/4 给全队欢愉度+10%/20%/60%【官】）。
- 银狼LV.999 是体系当前的对单主C：笑点→等量隐藏分→满60分开大进【无敌玩家】→3次强化普攻（100段弹射，欢愉伤害）为主力输出窗口。

## 骨架与绑定规则

```
欢愉主C + 欢愉光环辅助 + 欢愉资源/功能辅助 + 欢愉生存位 —— 倾向满编4欢愉
```

- 计数档位：真珠E1（欢愉2/3/4→欢愉度+10/20/60%）、真珠终结技（4人+给底本额外回合+60笑点）【官】——掉到3欢愉损失约一档增益。
- 阿哈速度公式吃全队欢愉角色速度 → **速度是全队第一词条**【攻】。
- 混编代价：非欢愉辅助不产笑点、不进阿哈轴、吃不到欢愉度增益——只在前置体系不全时过渡（如花火产点喂盲盒但产不了笑点）。

## 成员池（机制细节以各角色档为准，此处只记体系定位）

- [银狼LV.999](../characters/银狼LV.999.md)：主C——隐藏分链条（笑点等量→隐藏分，每点+0.4%暴击，满暴后+0.8%暴伤）；大招耗隐藏分不耗能量（充能无效）；E2 质变（每120隐藏分+1额外回合并恢复强化普攻次数）。
- [爻光](../characters/爻光.md)：核心光环辅助（体系的「阮梅」位）——结界全队欢愉度=自身欢愉度20%、终结技给阿哈额外回合、大吉大利追击；乘区覆盖最全，几乎绑定欢愉体系。
- [开拓者•欢愉](../characters/开拓者.md)：资源电池——每次攻击+10能量+3笑点、战技+20好活、终结技强制主C再放一次欢愉技；E6 白送副C输出。
- [真珠](../characters/真珠.md)：欢愉生存位——好活当赏直接当抵御值挡伤（每点200抵御值）；「欢愉人数越多越强」的生存位；4欢愉时终结技=给主C带60笑点的额外回合。
- [火花](../characters/火花.md)：主C/双发电机——战技一次产出大量笑点+战技点；爆点抵扣战技点消耗且视为耗点（触发银狼盲盒）；A3 把共享笑点池变成全队暴伤光环（每笑点+8%，上限80%）。
- [绯英](../characters/绯英.md)：对群主C——战技+10笑点；能量↔好活双向转换；狐狸老师能量追击；敌方越少弹射越多（对单自适应）。
- [砂金•戏浪](../characters/砂金•戏浪.md)：AoE 副C/辅助——热意满10自动放固定20笑点欢愉技；全队暴伤+48%光环；速度转欢愉度。**注意非生存位**（官方文本无护盾/治疗）。
- 替补生存：藿藿/灵砂/加拉赫/风堇/符玄/砂金（均掉3欢愉档）。

## 环境适配

- 利好：笑点/欢愉向湍流（例：V4.0 混沌「每轮次/波次+5笑点→真伤充能」=欢愉主场【攻：湍流原文】）；末日幻影连续欢愉增益期。
- 湍流按期轮换，非每期利欢愉——**进本先读当期湍流再定是否上欢愉队**。
- 银狼启动依赖笑点产量（队友+环境），无笑点环境的裸循环强度明显下降【攻】。
