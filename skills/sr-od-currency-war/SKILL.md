# 货币战争游玩指导

通过项目 MCP server 的 `analyze_screen`（画面识别 + 结构化读数）与 `run_operation`（动作 op）玩货币战争。核心循环 = **观察（读 extras）→ 决策（花金币强化阵容）→ 执行（动作 op）→ 再观察对账**。

**每个 op 执行后，必做一次画面识别**：用 `analyze_screen` 确定新画面是什么（命中的画面名直接查 `references/screens/<画面名>.md`），再决定下一步。识别不命中只有两种解释：①上一动作的过渡还没结束（等几秒重新识别；各动作的典型过渡时长见对应画面文档）②进入了未建档画面（自己读图判断当前状态）。

## 1. 全局交互铁律（所有画面通用，先读这节）

1. **按钮点击失败时，先查状态再怪手势**：按钮点击无效几乎都是**状态问题**，不是点击方式——①引导气泡挡着（首见引导，完成引导动作即消失）②按钮置灰（前置条件没满足，如投资策略未选卡）③对局软锁（投资策略未选完时出战被抑制）④商店面板开着（第一下点击只收店）。逐一排除后默认 0.1 秒的静态点击对所有按钮（含胶囊形）有效；**微距拖拽（按下→横移→抬起）仅作最后兜底**（MCP `drag` 工具，duration 0.35）。
2. **卡片选中点图标区**：投资策略三选一的卡片，点标题/文字区不选中，**点六边形图标区（卡片上部约 1/3 处）才选中**；选中态 = 卡片白框亮起。确认键置灰 = 还没选中。用 op `...actions.cw_pick_invest_strategy.CwPickInvestStrategy` 可跳过此坑（内部已按图标区实现）。
3. **op 偶发静默失败**：商店面板开关这类 op 可能返回成功但画面没变——每次动作后用下一帧 `analyze_screen` 对账，没生效就原样重跑一次。
4. **拖拽部署前必须重读；点击晶矿后也要重读**：晶矿开箱掉落的单位会插到备战席**非首空位**（实证：槽 1、2 占用时掉落物插进槽 4，跳过空槽 3）——旧读数不含新插入的单位，按旧槽号拖拽会扑空；点击晶矿采到奖励后同样重读一次再决策（奖励入席会改变备战席占用）。`DragCwChar` 的 from_idx 必须来自**最新一帧**的 extras.bench（备战席槽号 = 物理槽位，空槽以 empty 保留，不压缩）。
5. **analyze 的 board 字段只是面板可见行**：v4.7 羁绊面板会滚动+重排，OCR 只读到可视子集；羁绊计数决策以 SIFT 识别的 front_line/back_line 单位表为准，board 仅作快照参考。
6. **开商店画面不提供行读数（键都不出现）**：商店面板开着时，analyze 的返回里**没有** front_line / back_line / deploy_count / deploy_cap / hp / reward_ores 这几个键（商店牌行盖住计数、面板遮挡使角色识别不可靠——设计性省略，不是识别坏了）。要这四项就收商店后用备战画面读；商店画面自己的强项（shop_cards 商店牌、refresh_probs 刷新概率、bench 备战席、gold 金币、board 羁绊面板行、owned_equips 装备栏）照常返回。
7. **动作 op 只管机械执行**：出战/拾矿等 op 不做任何校验与特殊情况处理——收店前置、未达上限弹窗确认、部署未满/席满等状态前置全部由你负责（按各画面文档自查）。部署未满时点出战会弹「可出战角色人数未达上限」→ 点「确认」（约 1170,672）；「本局不再提示」勾选框不代点（玩家偏好）。

## 2. 一局的标准流程

1. ☐ 进大厅：`CwEntryEnter {}`（全自动，约 15~30 秒）→ 完成判据：run_status「已在货币战争大厅」
2. ☐ 开局：点「开始货币战争」（胶囊，微距拖拽）→ 模式选择点「进入标准博弈」→ 职级难度点「开始对局」（胶囊）→ 简报点「下一步」翻页 → 位面过渡点空白 → 完成判据：analyze 命中 货币战争-备战
3. ☐ 节点循环（每位面约 9 节点）：备战画面按 §references/operations.md 的备战卡操作（拾矿→开店→买牌买经验→部署→出战）→ 战斗等约 90 秒 → 结算点「继续挑战」→ 循环
4. ☐ 位面末 BOSS：出战按钮变「选择主角」→ 按主角光环选择卡操作（选光环+拖主角+确认）→ BOSS 战 → 位面过渡点空白进下一位面
5. ☐ 终局（HP 归零或通关）：按结算卡走完四页结算回大厅
6. ☐ 自我验证：终局后 analyze 命中 货币战争-大厅（锚齐全）才算一局完整收尾；中途退出则确认停在安全画面
