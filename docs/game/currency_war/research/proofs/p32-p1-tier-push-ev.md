# P32 · P1 档位推进目标函数:激活档→出口 hp 的阶跃期望与因果方向

> 状态:**结构已证(实证阶跃 + EV 下界推导);量级参数待 sim A/B 兑现**。
> 证据源:W801 七局 P1 逐节点失血表(docs/develop/currency_war/prereg/w801_p1_exit_quality/REPORT.md,21 个掉血帧真值;自 `.debug/temp/` 迁入);H3 阶梯(p03,e0/e1/e2 胜率 13.9/41.6/77.8%);P20(体系激活边际 2.6-2.9×);P29(档位进度项 Δp_tier·R_rest 结构)。
> 本篇 = W803 设计件的命题基础(设计批纪律:零落码)。

## 命题

**P32.1(阶跃实证)**:P1 出口 hp 对「r7 遭遇与 r9 boss 帧的激活羁绊档位」呈离散阶跃而非连续关系——档≥3 的局出口 59-72,档≤2 的局出口 9-48;boss 帧税 档3→-13(三局精确相同,方差≤±2) vs 档≤2→-32/-34(阶跃差 ~19 血);遭遇帧阶跃差 ~15 血;r6 普通战斗阶跃差 ~20 血。出口总落差 63 血中 ≥85% 归档位/人口这一离散战力量,装备与星级无实证贡献(局 5 卸装 -13 = 局 6 满配 -13)。

**P32.2(EV 下界)**:把激活档从 ≤2 推过引擎成型档(下界只计 boss 帧)= **+19 hp ≈ +2.7 个 P2 缓血轮**(W801 深度表 7-8 血/轮)。对照成本:破息买件的机会成本 ~0.5 金/轮利息(P11/P13 口径),一张牌的再遇窗口账(P1)——收益比成本高一个量级以上,**在 P1 常规金位(g≥30)区间 EV 符号稳健为正**。形式:P32.2 的结构即 P29 的 Δp_tier·R_rest−c·(1−s)−H 在 P1 位面的实例化,R_rest = r7/r9 剩余掉血帧数,共享同一 Δp_tier 标定卡点(不造第二源)。

**P32.3(因果方向,硬门)**:阶跃的因果方向是「档位高 → 少掉血」,不是「活到后期 → 档位高」。排查见 §2;结论:现有七局证据一致支持档位→税方向,反向因果(时间/财富混杂)未获支持;最终因果裁决由预注册 sim A/B 的干预性证据兑现(只改目标函数、同 seed 同池,是比观察性排查更强的因果工具)。

## §1 阶跃的形式化

设帧 t 的激活档 `tier(t) = max_bond_tier(deployed(t))`(口径与边界见设计件 §1,面板快照滞后一拍不用,W789 问题 0 实证)。节点基础税 B(t) 由节点位置定(A8 曲线七局恒定),失败罚 P ∝ 敌方剩余血量([27] 机制)。档位的作用通道 = 战斗胜率与伤害达标率:

- H3 阶梯(p03):档间 e0→e1→e2 胜率 13.9%→41.6%→77.8%——档间阶梯主导,档内平坦(ADR-0304 悬置成立);
- W801 七局:同档位税额方差 ≤±2(boss@档3 = -13×3、-17),而无条件税额分布跨 -5~-34——**条件方差远小于无条件方差 = 档位解释了税额的主部分**;
- r6 普通战斗(先于 r7)已现 ~20 血阶跃:档位在 r6 帧对 r6 帧税生效,不存在「先活到后期才攒出档位」的时间余地。

## §2 反向因果排查(命题 P32.3,逐条)

混杂假说 H_alt:「活到后期 → 金多/投入多 → 档位高 → 出口 hp 高」,即档位只是时间/财富的代理。逐条检验:

1. **财富混杂被排除**:重金低档三局(局 2 boss 帧 75 金/局 7 62 金/局 8 72 金,全档≤2,出口 9-48)vs 局 6(金 45,档 3,出口 72)——金量与档位不共线,「财富→档位→少掉血」的链条在财富一环即断。缺口是**金→档位转化率**(决策质量),不是投入量。
2. **时间混杂被排除**:局 8 r8-r9 买 8 张+升 2 级仍档 0——时间和支出不机械地产出档位(转化动作=合成/凑档/弃散装缺失);r6 帧税阶跃发生在「后期」到来之前。
3. **共因混杂(部分成立,但不翻转结论)**:「决策质量高」同时导致早凑档与少掉血,是真实共因——但共因是**策略的因变量**,恰是本设计要干预的杠杆;对「该不该把档位设为目标函数」这一问题,需要的是干预性证据:同 seed 同池下只改目标函数、观察出口 hp 是否上移,由预注册 sim A/B 直接回答(协议见设计件 §5)。观察性排查的作用 = 确认 A/B 的预期方向与判据量级(+19 血下界)不是混杂伪影。
4. **条件方差检验(预注册保留项)**:对照臂 replay 语料上做条件检验——帧税 ~ tier + hp(t) + gold(t) + round 分层回归,档位系数应显著且吸收主方差;lead-lag:tier(r6) 应预测 tax(r7/r9) 残差。未跑前 A/B 判读时先核此表(协议 G-RC)。

**结论一行**:档位→税因果方向可采;+19 血 EV 下界成立;干预性终审 = sim A/B 主判据(P32.2 预言:实验臂出口 hp 均值差 ≥ +8,p<0.05,且档≥3 占比显著上移)。

## §3 边界

- 阶跃数字来自 n=7 局实机语料(同 A8、同版本);档≤2 桶 n=3、档≥3 桶 n=4,方差估计弱——量级带 ±2~5,**精确量级归 sim 标定批,不固化进常量**;
- 列车2+DOT2 型成型局(最高单羁绊档=2 但配方成立)在七局样本中不存在,阶跃在该线型上的位置未观测——「引擎成型档组」的逐线阈值按 transition_combos 定义(仙舟3 / 列车2+DOT2 / …),G0 口径复现检查预注册在协议(设计件 §5);
- 装备无贡献的结论辖 P1 税,不外推 P2(P2 战力面装备仍有效,W801 干预排序④)。
