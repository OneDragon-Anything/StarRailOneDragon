# DD-001:旧决策包删除时序——A/B 过线前不得物理删除(批 1 拆 1a/1b 两段)

> 状态:已裁决(2026-09-01 用户裁定,DESIGN_FINAL_ATTACK 阻断-1 处置)。
> 晋升来源:原裁决记录于 `docs/develop/currency_war/archive/redesign/reports/DESIGN_FINAL_ATTACK.md`(临时文件,已清理)——本件为其持久化,redesign 01/03 的引用以本件为准。

## 背景

01 §7「共存策略」裁定的「sim 内新旧并行对拍」要求旧决策包(decision_v2,约 1.1 万行)在 sim 中仍可运行;而 03 §3 批 1 原口径「decision_v2 全部删除」的执行时点在新包就位即删——「旧」侧先死,A/B 对拍退化为「新跑 vs 历史数据回放」,与用户裁定的「并行对拍」(两个活被测体同场)语义不符,且两种语义结论强度不同。

## 裁决

批 1 拆两段,时序为硬约束:

- **批 1a**:决策调用点改接新接口 + sim 新旧双被测体并存 selectable——**不删**,旧包作 A/B 基线(sim 专用,不再接线实机);
- **批 1b**:**「sim A/B 过线(新层不劣)」裁决后**才物理删除旧决策包。A/B 过线 = 整体删除旧决策包的触发门。

## 约束范围

- 03 处死批 1 的执行序(1a 先行,1b 挂 A/B 门);
- 01 §7 共存策略的实现形态(活双被测体,非数据回放);
- 任何「删除旧决策包」的操作必须先出示 A/B 过线裁决记录。
