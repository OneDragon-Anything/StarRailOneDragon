# 遐蝶生命记忆队（生命烧血充能体系）

> 按 V4.7 期（2026-11）调研撰写。靠「全队掉血→新蕊充能→死龙爆发+后援保命」赢：越敢掉血越强。

## 核心思路

- 遐蝶全部伤害倍率基于**生命上限**（零攻击倍率）【官：全技能文本】→ 词条=双暴+生命%。
- 终结技不走能量，走【新蕊】：**我方全体每损失1点生命，遐蝶+1新蕊**；充满即放【官：天赋】→ **全队掉血就是充能**。
- 治疗转化：行迹「收容的暗潮」——我方接受治疗后治疗量100%转化为新蕊（死龙在场则转死龙生命），溢出治疗也计入【官】→ 持续群奶=持续充能。
- 死龙（忆灵）在场=全队后援（我方生命最多降到1，超出由死龙按500%承担）+全队10%增伤+22%全抗穿【官】→ 生存下限自带。

## 骨架与绑定规则

```
遐蝶(量子·记忆·主C) + 记忆/生命辅助×2 + 治疗/生命系生存位
```

- **硬否决：护盾生存位**——护盾既不产生生命损失也不算治疗，掐死新蕊收入；死龙后援已保生存下限，护盾纯负收益【官：行迹文本推论；攻：Prydwen「与非护盾生存完全冲突」】。
- 计数绑定：长夜月行迹「队伍中记忆角色 1/2/3/4 → 全体忆灵暴伤+5%/15%/50%/65%」【官】→ 倾向 3+ 记忆互绑。
- 攻击增益对遐蝶零收益（知更鸟/布洛妮娅/停云的加攻、充能均无效）【官：技能文本对照】。

## 成员要点

- [遐蝶](../characters/遐蝶.md)：主C，不耗技能点（代价是烧全队当前生命30%/40%）——技能点全留给辅助。
- [长夜月](../characters/长夜月.md)：忆灵暴伤放大器——战技给全体忆灵暴伤（自身暴伤12%转化）+B4计数；「长夜」忆灵攒忆质爆发。
- [风堇](../characters/风堇.md)：核心治疗——小伊卡看到掉血就奶，奶量经遐蝶行迹转新蕊；雨过天晴加全队生命上限=直接增伤。
- [缇宝](../characters/缇宝.md)：结界易伤+全抗穿+E1真伤，生命模型同队。
- [灵砂](../characters/灵砂.md)：B阵治疗——浮元追击奶机制上与烧血体系天然咬合。
- 记忆开拓者：替补——迷迷声援（暴伤+真伤，星魂1对忆灵生效），免费满魂。

## 操作轴

1. **开局秘技**：风堇秘技垫血池（全队回30%上限+20%上限2回合）→ 遐蝶秘技主动开怪（进场直接召死龙+遗世冥域+一次性大额新蕊）【官】。
2. **循环**：遐蝶死龙在场时每回合强化战技（不耗点，烧全队40%当前生命）；死龙喷焰到自爆（B4行迹每喷+30%叠6层，自爆流伤害最优【攻：Prydwen 同结论】）；死龙消失窗口期治疗全转新蕊→快速充满→再召龙。
3. **终结技时机**：新蕊满就放；缇宝结界卡在死龙出场后再开（覆盖爆发窗口）。
4. **技能点**：遐蝶零消耗；点花在风堇/长夜月/缇宝的战技上，富余普攻攒点。

- 利好：持续伤害环境（掉血=充能）、长线高压（死龙后援+治疗循环）。
