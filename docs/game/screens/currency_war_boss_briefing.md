# 货币战争-BOSS简报(强敌来袭横幅)

位面首领(boss)关开打前的全屏横幅简报:横幅带展示 boss 立绘(左)、名称/等级/词缀(右),底部「点击空白处继续」推进。注意与「货币战争-简报」(开局前的三位面首领阵容页)是两个不同画面。

## 何时出现 + 状态流转

- **入口**:每个 boss 位面的 boss 关开打前(奖励关结算后)。第五局 1-9 实锤帧即位面 1 boss 关前。
- **出口**:点画面空白处 → **boss 战自动开打**(勘误:曾误判「关闭后自动开店」,实为直接进 boss 战,商店永不开——07/08 局接管实录)。
- 横幅为转场演出(立绘/光效动画),入场/退场相位期文字与徽记位置不稳,不该在相位期识别。

## 识别特征(稳定锚点)

- **阵营徽记模板**(横幅左段红旗标上的白色翼形徽记,area `标识-阵营徽记` (842,378)-(910,453),模板 `cw_boss_brief_emblem`,二值化模板匹配)——组合 id_mark 之一。
- **「点击空白处继续」**(下中,~(960,790) 波段,area `提示-点击空白处继续` (860,770)-(1060,815))——组合 id_mark 之二。两个 id_mark 都命中才精准。

### ⚠️ 为什么徽记用模板、不用文字:文字容易被识别错

- 标题「强敌来袭」是美术字,**OCR 易误读**——实锤两种形态:读成「强敌米」(来袭→米)、读成「強敌来袭」(繁首)。文字锚被误读击穿 → 本屏阶段一身份 miss,曾引发「帧被误派位面过渡 → 过渡 op 空 fail 循环」故障(第五局 1-9 实锤,2026-09-16 根修)。
- 徽记是**固定资产**,对 OCR 误读完全免疫:简报屏三家**不同阵营**卡片与横幅旗标是同一资产(matchTemplate 对齐后 0.97+ 实证),横幅自帧回放置信 0.995。2026-09-16 标题 OCR 锚正式换装为徽记模板锚。
- 徽记裁剪窗紧贴旗标内部:左侧深色面板、下方 boss 名/词缀行(逐 boss 变化)都不进窗。

- ⚠️ **「点击空白处继续」与位面过渡屏共享文案但位置不同**(本屏 y≈790 / 位面过渡 y≈960)——共享文案不作跨画面判据,两屏排他靠位面节点锚(位面过渡)/徽记锚(本屏)。
