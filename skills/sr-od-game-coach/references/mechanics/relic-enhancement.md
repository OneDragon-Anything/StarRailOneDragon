# 遗器养成与装备(relic-enhancement)

遗器养成三件事:强化(经验材料+信用点)/ 更换(把件穿到角色部位上)/
取舍(分解废弃件换强化材料)。本文给决策规则与操作路由;词条口径的
推导见 [damage-and-affix.md](damage-and-affix.md) 与对应角色档的
「有效词条」节——**每个角色的有效词条集合不同**,具体词条名单查角色档。

## 1. 决策规则:怎么挑一件值得穿的

1. **主词条必须对**。各部位的有效主词条由角色伤害模型决定(输出位躯干=
   双暴/攻击%、脚部=速度/攻击%、位面球=属性伤/攻击%,生存位=生命%/
   防御%/治疗%——逐部位名单查角色档)。
2. **副词条门槛(后期口径)**:至少有 **2 条不同的有效副词条**才值得强化
   投入——只有 1 条有效词条的件,强化 5 次里 4 次歪,期望收益不划算。
3. 套装对不对是**穿戴层**的事(先凑 2/4 件套效果,见
   [relic-sets.md](relic-sets.md)),词条好不好是**强化层**的事——两步分开
   判断:套装对的散件可以留着当「词条坯子」,词条好的散件可以当
   「2+2 过渡」。

## 2. 强化路线:两条路线怎么选

游戏内「自动置入」的实际语义是**一键填满**(填入筛选出的经验材料堆,
+0 件一次拉满到 +15)。实机确认强化界面没有「每次+3」独立置入档位控件
——按 +3 步进强化需要逐槽手动置入材料控制经验总量,自动化暂不支持,
路线 A 目前只能人工执行。强化节点机制:每 +3 激活/提升一条副词条,提升
到哪条是**随机的**——「歪」= 本次提升落在无效词条上。

**先定目标角色**:强化永远是为某个角色服务的——先查该角色档的有效词条
集合,再谈哪条路线。

### 2.1. 路线 A:省材料(练度已高 / 材料紧)

按 +3 节点**逐节点验收**(当前需人工,自动化候逐槽置入改造):

1. 强化到下一个 +3 → 看本次提升/激活了哪条词条。
2. **歪了就停**:本次提升全是无效词条 → 总有效词条数没有超过强化前 →
   这件到此为止(+3 件也有局部价值:第 4 词条若已激活且有效,可当过渡件)。
3. 没歪 → 继续下一个 +3,重复验收。

适合:材料存量紧、练度接近毕业(边际收益低,材料优先给新角色)、或这件
只是「试试运气」的坯子。

### 2.2. 路线 B:豪横(材料富余 / 省时间)

用「自动置入」一键填满直通满级,强化完统一看结果。适合:材料存量高(长草
期囤了大量星方镝)、目标角色是主力主 C、或这件起步就有 3-4 条有效词条
(歪的概率被基数摊薄)。

### 2.3. 期望口径(为什么不心疼歪)

满级共 5 次词条节点(+3/+6/+9/+12/+15)+ 起步 2 条副词条:起步 4 条有效
词条的「完美坯子」满级后期望约 3-4 条有效词条满级度;起步 2 条有效的及格
坯子期望约 1-2 条有效——**及格坯子不值得豪横**(期望产出低),这正是
路线 A 的适用判据。

## 3. 装备与更换(操作路由)

公共前置(装备与浏览都从这里开始):

| 步骤 | 用什么 |
|---|---|
| 导航到角色详情 | MCP `goto_screen(target_screen_name='角色-详情')`——从大世界/菜单/任意已建档屏自动路由 |
| 选中目标角色 | op `sr_od.operations.select_character.SelectCharacterOp(cn_name='角色名')` |
| 切到遗器 TAB | op `sr_od.operations.switch_character_tab.SwitchCharacterTabOp(tab_name='遗器')` |
| 查看当前穿着 | 优先米游社 API `mys_get_roster_detail`(每角色六件明细);要实时确认用 MCP `analyze_screen`——画面为「角色-遗器」时读着装页六个遗器位 |

换遗器按意图分两种情况,路由不同:

### 3.1. 情况 1:不知道要换什么——先浏览账号遗器清单

公共前置之后,打开替换列表看清单再决定:

| 步骤 | 用什么 |
|---|---|
| 打开替换列表 | op `sr_od.operations.open_relic_replace.OpenRelicReplaceOp(pos=部位号)`(1头 2手 3躯干 4脚 5位面球 6连结绳)→ 成功状态 OPENED(列表已开、部位筛选正确、滚回顶部) |
| 读清单 | MCP `analyze_screen`——画面为「遗器-替换」时 extras.items 返回该部位全清单,每件含 件名/套装/部位/强化等级/穿着者(owner)/识别来源 |
| 决策 | 结合「决策规则」与角色档有效词条从清单里选定目标;穿着者 owner≠null 的件已被他人穿着,选出后走 3.2 由 op 自动避开 |
| 执行更换 | 走情况 2 的路由;或收尾:点列表右上返回回着装页(画面「按钮-返回」) |

浏览是按部位的:换部位重复调 `OpenRelicReplaceOp(pos=新部位)` 即可
(op 自动处理「当前列表部位不符 → 返回 → 重进目标部位」)。

### 3.2. 情况 2:知道要换什么——直接换

op `sr_od.operations.equip_relic.EquipRelicOp(piece_name='单件名',
expected_character='角色名', allow_take_over=False)`(expected_character 可选,
做目标角色核对防在错误角色上换装;allow_take_over 见下)。单件名 = 套装+部位
唯一确定(如「先驱的绝热围壳」),同名多副本任意一件均满足意图。结果解读:

- 成功(ALREADY_EQUIPPED / RELIC_EQUIPPED)= 目标已装备当前角色;
- 失败「滚动 12 屏未找到」= 账号没有此件(或识别失败)。

**抢件语义(allow_take_over,与光锥同构)**:遗器装备 = 交换——目标件在他人
身上时,对方拿到当前角色脱下的件,不产生空手。

- `allow_take_over=False`(默认):候选只取无主件;万一因穿着者角标漏检点到
  被穿着件,游戏弹「是否替换」确认框时 op 一律取消并记录该格不再点击。
  不确定要不要抢时用这个。
- `allow_take_over=True`:被穿着件也作候选(无主件仍优先尝试),弹框点确认
  完成交换。**会改变对方配装,发起前必须向用户确认**(如「把停云的风帽换给
  布洛妮娅」)。⚠️ 交换确认按钮的实机坐标尚未建档,True 遇弹框会显式失败
  保护双方配装,候实机补档后可用。

- op 经 MCP `run_operation(op_id='sr_od.operations.equip_relic.EquipRelicOp',
  args={...})` 调用;op 幂等:当前角色已装备目标件时直接成功;内置滚动
  扫描(12 屏预算)、部位先验整屏识别定位与替换后套装核对;已在正确部位的
  替换列表时直接复用该列表(不重进——重进会重置手动切换的排序设置,
  实机复现:动态「建议排序」下卡面识别会大面积漂移)。**重进路径 op 已
  内置「关建议排序」前置**:进列表后先打开排序弹窗,关闭「遗器建议排序」
  开关、基础排序选「等级」再确认,把列表转静态后才开始扫描(建议排序按
  匹配度动态重排,重掷动画期间「识别→点击」间隔超 2 秒即落空);复用
  列表路径排序已静态,不重复执行前置。排序弹窗交互已正式建档(开关/
  等级 radio 模板判态),前置链全链实机验证候实机窗。

## 4. 强化遗器(操作路由)

强化 = 提升遗器等级(+15 满级,每 +3 激活/提升一条副词条)。两步:
先选件(导航 op 把目标件在背包里选中),再强化:

| 步骤 | 用什么 |
|---|---|
| 选件导航 | op `sr_od.operations.select_bag_relic.SelectBagRelicOp(pos=部位号, set_name='套装名')`(1头 2手 3躯干 4脚 5位面球 6连结绳)——部位筛选 + 套装筛选(走筛选面板与筛选规则弹窗,按常量表套装类别自动切 tab),选中首个匹配件,终点 = 背包-遗器且目标件选中;`set_name` 可省(不筛套装直接选首件);`main_stat` 参数暂未实现(主属性选择弹窗未实机摸底,传入显式失败) |
| 执行强化 | op `sr_od.operations.equip_relic_enhance.EquipRelicEnhanceOp(auto_insert='max', target_level=None)`——进强化页、读强化前词条基线、自动置入材料、执行、关结果横幅,终点回背包-遗器 |

背包筛选交互要点(实测行为,影响选件链的判断):

- **筛选面板开着时点列表卡不刷新右侧详情**——选件链必须走完筛选确认
  (弹窗与面板同时收起)再选卡,否则详情件名核对读到的是旧选中件;
- **背包筛选状态跨屏持久**(替换列表也继承):进入背包时漏斗若已带
  「筛选中」角标,是历史筛选,导航 op 不清除——历史筛选与意图叠加时
  op 以件名核对诚实失败暴露,人工处理时先点筛选方案/重置再筛;
- **筛选规则弹窗滚动列表后点击会系统性偏移一行**:op 只点识别命中的
  行文本中心;人工代跑时滚动后先点一张卡核对该行再勾选。

档位参数(对应第 2 节路线):

- `auto_insert='max'`(默认)= 一键填满直通 +15(实机验证:+0 件一次到位,
  消耗信用点 11.4 万量级)= 路线 B;
- `auto_insert='plus3'` = 路线 A 的 +3 步进档,**当前不可用**:实机确认
  强化界面没有「每次+3」置入档位控件,传入显式失败不误跑;plus3 语义
  需 op 改造为逐槽手动置入算量才能支撑(候排期);
- `auto_insert='off'` = 不自动置入(手动放材料交互未摸底,当前显式失败)。

结果解读:MAX_LEVEL(强化至满级)/ REACHED_TARGET(达 target_level 停)/
ALREADY_MAX(起点已满,零消耗)。

**消耗说明**:经验材料按「4星及以下」筛选自动置入(只喂低星废弃料,
不碰高星件)+ 信用点(满强化 11 万+/件)——常规养成路径,不涉及稀缺
资源,发起前自行确认即可。

**材料来源**:强化材料主要来自分解废弃遗器——一条龙组的
relic_salvage(遗器分解)应用负责批量分解;强化页材料不足时先跑分解。

## 5. 与光锥养成的机制差异(防串用)

- **升级入口**:光锥升级从角色 TAB 点「强化」直达当前光锥;遗器强化唯一
  入口 = 背包-遗器选中件——「给某角色的某件遗器强化」需要先在背包定位
  那件(按部位/套装筛选),这步选件导航已交付
  (`SelectBagRelicOp`,见第 4 节);
- **合成**:光锥有叠影(同名合成,SuperimposeLightConeOp);遗器没有
  同名合成——游戏内 3 件同部位合成随机新件,产出不可控,自动化价值低,
  未做 op;
- **抢件语义**:与光锥同构,`allow_take_over` 参数控制(装备 = 交换,见 3.2)。
  ⚠️ True 路径依赖的交换确认按钮坐标未建档,当前遇弹框显式失败保护双方
  配装,补档前抢件场景请人工操作。
