# 0332 - 成型评分活性(d2 评分批;P1 boss 转化)

- **Status**: accepted(2026-08-25;sim 双窗方向一致 + 锁全绿;偏置量级=sim 校准域)
- **Context**:三局实机判读收敛(P1 末真值 1/40/13,r9 boss -24~-34 三局同型)=
  **P1 boss 转化是稳定主病灶**(进度.md「第三局判读收账」);第三局 r7 后金
  42→71 攒息期 0 买疑「成型停手线触发过早或 boss 轮守息」。sim 诊断
  (n=100,snapshot 池,当前树):**r7/r8/r9 零买轮占比 0.38/0.37/0.39,零买轮
  100% 由「全非正分」驱动**——决策层无显式停手门,停手=仲裁器对买候选的
  0/负分拒绝;**r9 未成型率(引擎<2)0.51**。0 分候选 breakdown 解剖:主因
  (≈85%)=cap 饱和(77-87%)时买入不改评分维(base==after,与 ADR-0301 二级
  解剖同族,eng_frac 已缓解未根治);次因(≈15%)=**-25 息崖**:gold 50-53 带
  买入(50→49 破平台)扣全息 EV,而同一窗口纪律侧(boss_breaker r≥5 P1,
  地板 10)授权破 50 花费——**评分与约束双重计罚**。boss 轮守息假设证伪:
  r9 allin 地板 0,金 71 零买=评分 0 差分非守息门。
- **Decision**(两处评分活性修复,落点 `decision_v2/scoring.py`):
  1. **息崖平滑(war 破息窗)**:P1 r≥5 非应急买入跌破 50 满息平台时,息损
     修正为**真实档位损失**(跨档数×interest_rounds;50→49 只付 -5),不再
     扣全平台消失(-25)——消除与层4 boss_breaker 地板(10)授权的双重计罚
     ([19] 高难节点前破 50 是合法抉择;[13] 未成型应继续买配方件)。emergency
     保持 -25([18] 不为苟住破息,ADR-0302 锁)+经济态保持 -25([17] 平台)。
  2. **成型补充偏置(成型度权重)**:未成型(引擎<2,[13] 成型即停手的前提
     不满足=应继续买)+ 引擎件候选(factions∪flows∩TRANSITION_TRAITS 或
     希儿,与 `cw_sim._engines_count` 体系判定同源)在破息窗的 0/小负分
     买入顶成正分(`forming_bias`=5.0,带上下沿 `[-interest_rounds, +0.5]`
     ——单档真实息损内顶;emergency 的 -25 息崖与深负分不被翻越;已正分
     (>+0.5)不叠加防 ADR-0301「高单位挤掉目标件」过冲)。量级依据=[27]
     每场质量战:引擎完成(1→2)win 0.416→0.778(+0.36)×单场掉血 10×hp→金
     0.5×剩余战斗(窗内 2-3)≈ +4.5~5.4,偏置取完成期权保守下限。
- **Considered Options**:
  1. **全量 tiered 息 EV(war 窗 sub-50 按真实档位计息)**:否决——绝对
     值语义大改(gold 35 → 息 EV 15),低金(10-19)跨档买入恒 -5 杀死
     目标件/补偿通道,blast radius 大(0291/0305/w35 三族锁冲突);
     本批采**手术式平滑**(只改 50→49 跨平台差分,sub-50 绝对值不动)。
  2. **攒息期例外窗口(boss 前 1-2 轮特判)**:否决——对照 user_playstyle
     [15]/[16] 无教义支撑([15]=r1/r2 压库,[16]=必胜节点);[19] 破息抉择
     由息崖平滑承载,[13] 成型前继续买由成型偏置承载——不另造节点特例
     (违反「节点无关」元原则)。
  3. **找件刷新(form_refresh_ev)重启**:否决——ADR-0301 strike2 双窗
     否决(命中率不足是供给面约束,非评分域),诊断同证:未成型局引擎件
     店见率低(希儿 r7-r9 仅 16/51 局)但见即买转化好(11/16)。
  4. **targets cap 放宽(0.8→1.0)**:否决——ADR-0301 网格无单独增益。
  5. **forming_bias 取 0(通道关)**:sim 对照否(见验证)——偏置开臂
     engine_bought 249→300(+20%),r9 零买轮 39→34,r9 引擎-0 7→3。
- **验证**(snapshot 池,双窗 100+100;hp 只作验收——sim 战斗层对引擎数
  不敏感,r9 delta 引擎 0/1/2 → -22/-24/-24 持平,已知边界):
  - 窗 A(seeds 0-99):r9 未成型 0.51→0.47;r9 引擎分布 {0:7,1:44,2:47,3:2}
    → {0:3,1:44,2:51,3:2};零买轮 r7 38→27/r8 37→30/r9 39→34;
    hp_ge_60 0.01→0.01/avg 24.68→24.68(验收持平,sim 战斗层不敏感);
  - 窗 B(seeds 900000-900099):r9 未成型 0.51→0.50;引擎-0 10→6
    (两窗同向 -4);hp 持平;
  - 检查网:fix 与 baseline 违规集完全一致(零新增);
  - 测试:ADR-0332 新锁 7 条(息崖平滑三守卫[war 正分/emergency 保持/
    经济态保持]+成型偏置四守卫[加性/成型后不顶/已正分不叠加/常量]);
    直接影响 94 条全绿;全量见批收账。
- **Consequences**:
  - r7-r9 破息窗的引擎件买入活性恢复(转金为成型,[13]/[20]);成型后
    (引擎≥2)偏置关闭 → 停手攒息([13] 成型即停手 + [28] 保息);
  - 息崖平滑只辖 war 破息窗;emergency([18])/经济态([17])的 -25 平台
    保护语义不变(ADR-0302 锁不动);
  - 残余(诊断重跑):未成型局供给面约束(店见率低)非评分域可解——
    下一杠杆=供给侧/成型检查点显式状态量(挂后续批);
  - 偏置量级(5.0)与上下沿为设计推断,sim 校准域(A/B 通道保留)。
