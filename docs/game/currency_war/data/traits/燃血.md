## 效果(官方全文)

【燃血】队员的和提高。战斗开始时，激活会记录【燃血】队员消耗生命值并在行动时攻击敌方全体的【燃血角斗场】。\n【燃血】队员无法获得护盾，受到护盾时会回复2%生命上限+1000生命值。
