# 货币战争-列车同行(选择伙伴 overlay;原「货币战争-选择伙伴」,2026-09-02 画面改名,UI 标题仍为「选择伙伴」)

## 何时出现 + 状态流转

对局内出现的「选择伙伴」节点 overlay(V4.4 触发时机 = 备战时列车同行羁绊阶级改变,与盛会之星同族)。玩家从 1-N 个候选角色里**选 1 名**加入其流派羁绊 + 复制其首件装备效果,选完回备战。**单屏单选 + 一次确认**:

- **入口**:备战 → 本 overlay 叠在备战上(备战 id_mark 仍透出可见)。
- **选伙伴**:点候选卡选中 → 点「确认选择」→ overlay 消失回备战(节点完成)。
- **出口**:确认落地 → overlay 消失 → 回备战。

### 选中态呈现(2026-09-15 更正)

**选中态呈现在档材料零实拍**。旧记载「选中态 = 「已选择」文字出现 + 立绘高亮边框」经复查证伪:文档所引 2026-08-13「选中态」截图与明确的未选中帧(2026-09-15 事故帧)像素比对逐区域一致(卡区/确认钮区均 diff≈2/255),帧内全量 OCR 无「已选择」——该帧本身不是选中态。选中时确认钮由灰变实(提示文案消失与否未实锤,交互验证待现场补)。

**未选中态正判定 = 「请选择强化角色」提示在场**(橙色,确认钮旁伴随文案,确认钮置灰态必现;所有在档未选中帧全数命中)。

### ⚠️ 选选流序事故记录(2026-09-15,P1-r1)

旧 op 的选中态判定 = 全屏 OCR 找「已选择」,LCS 阈值按**关键词长度**归一(3 字词与本屏常驻的指令长句、「请选择强化角色」提示共享子序列「选择」即达 0.5)→ 本屏**恒误命中** → op 恒跳过点选候选、每轮只点置灰确认钮 → 游戏拒绝,节点重试预算耗尽 fail,主循环重派无限循环(实机十八连 fail,~12 分钟零推进,哨兵 NODE-DWELL 报警停局)。

历史为何未暴露:2026-09-14 前的旧 op 带「step2 检测(巨星档提示 area 跨屏误用)→ 点画面中央立绘 (960,300) → 再确认」序列——该 step2 语义虽系误读,但其**每轮的卡体点击恰好承担了选中动作**,2026-09-08 及以前的端到端成功经此路径达成;该序列删除(删得对)后,坏的选中态 gate 失去遮掩,首次 P1-r1 选择伙伴即卡死。

修后 op 形态:废除选中态读数;「点选候选 → 确认」脉冲(未选中提示在场 = 点选实证,每轮先点选后确认);确认被拒形态(提示持续在场)有界重试(4 脉冲)后显式 fail;完成门 = overlay 标识消失。
