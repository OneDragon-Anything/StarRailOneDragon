## 门① 内部推导(超几何口径/池演化)——逐逐步核

**判定:通过(1 处建模选择需注记,不阻断)。**

逐步核对(`cw_shop_odds._refresh_dist` / `expected_refreshes`):

1. **槽位费用层**:M ~ Binomial(5, p),p = `REFRESH_PROB[L][c]`。数学正确;机制上"每次刷新整店 5 槽全换"(economy §2.1 实机实锤 🟢)支撑逐次独立。
2. **档内抽卡层**:给定 m 格该费用,出 x 张目标牌 = 超几何,分母 C(total, m),total = v·a − j − c(rem_target = a−j,rem_nontarget = (v−1)·a − c)。代数核:**total = (a−j) + (v−1)a − c = v·a − j − c ✓**,与"剩余牌库 = 固定牌库 − 持有副本总数"(economy §1 池量派生不变量)一致。
3. **池演化关键点(本门最值得记录的正确性)**:DP 中每次刷新用**同一分布**迭代——这不是把"跨刷新不放回"误用成池随刷新递减:刷新只展示不消耗,池只经购买变动(j↑ 只在买到目标时、c 只在买同费非目标时)。失败刷新不改池 → 跨次刷新 iid 在该模型下**自洽**。与 economy §1「买/卖/合成只改持有计数,池随不变量自动正确」严格同构。
4. **DP 边界**:E_j = (1 + Σ_{x≥1}P(x)E_{j+x})/(1−P(0)),E_k=0;x 超出 k_need 的质量按"已完成、零追加成本"处理(E[j+x>k]≡E[k]=0)——语义正确(刷出超额目标张数不多花钱)。k_need 截断只影响 dist[x>need] 不入 numer,P(0) 仍精确。
5. **需注记的建模选择**:`expected_refreshes` 全程把 c(同费非目标已购数)当**常数**——搜索期间不再买同费非目标。这是建模指令而非缺陷,但证明单篇未声明此假设(见门③修正建议)。
6. **证明正文推导**:①表 = `p_at_least_one` 输出逐位一致(L1-3 c=1 = 0.2270:p=1 → 1−C(513,5)/C(540,5) ✓;c=3@L7=0.1357 与 P38 引用值同源 ✓);②③④数字全部与脚本输出一致;④三例(c=3@L4 升 L5 省 28g;c=5@L7→L9 省 200g、@L8 省 12g;峰值级停留)逐个复算 ✓;边界格 (a) k=1 留 24.8 vs 升 L6 净 43.8(EV 留)、k=3 恰 75.4 打平 ✓;(b) 峰值以上 p 降留本级 ✓。
7. **⑤ C_interest 推导**:G=50 刷 2g → 48 跨 50 档 → 每轮息损 1(50 档息 5 → 48 档息 4)×R 剩余轮——上界口径已诚实声明(P6 回档账真实 1-3 金),口径注记到位。
