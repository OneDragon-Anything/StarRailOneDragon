# 货币战争-攻略列表（游戏内攻略面板主屏）

**识别**：`is_precise` 命中 `货币战争-攻略列表`（锚：主页签「热门攻略」+「我的阵容」双文本组合）。
**目标**：官方推荐阵容活数据源——条目带版本标记 + 羁绊公式标题 + 热度 + 作者；可应用/保存阵容、输入攻略码。

## 怎么操作（看图口径，不写死坐标）

1. **入口**：备战顶栏「攻略」按钮（对局内非破坏性 overlay，关闭回备战不丢局）。
2. **三个子页签**：推荐攻略（官方 curated）/热门攻略（按热度）/收藏；点卡片卡身 → 攻略详情。
3. **卡片右侧按钮**：「保存阵容」→ 保存阵容弹窗；「应用攻略」→ 直接应用（卡片出现「应用中」徽标，应用成功会弹装备追踪弹窗）。
4. **页脚**：「输入攻略码」→ 攻略码输入弹窗；「前往攻略广场」**外开浏览器新标签页**（米游社活动页）——自动化场景慎点。
5. **「我的阵容」主页签** → 已保存阵容列表，「新建阵容」→ 阵容编辑。
6. **出口**：右上 U 图标 / ESC 回备战。

坑：**无搜索 UI**（OCR+视觉双验）——按羁绊/作者过滤 = 滚动列表读标题自己匹配；「收藏(n/20)」计数动态，OCR 匹配注意。
