## 3. 命题（形式化）

### 3.1 可达性三态谓词（零标定债定义）

对线 c 与帧状态 s，记（全部单一源，**零新常量**）：

- `d(c)` = `line_distance(c,s)`（kernel/cw_line_switch.py :97-114）；`E(c)` = `e_rounds(c,s)`（kernel :117-160；d=0→0.0；p̄=0∧d>0→+inf）；
- `R_rem` = `cw_plane_table.r_remaining`（r_global 到局终；未揭晓位面回退取上端——**读法与姊妹门 P74 同源，不另立第二时域**。方向判词不跨门移植：同一回退在 P74 关侧缺省极性下偏关，在本门放行式极性下**偏开（反保守向）**，偏差申报见 §4.7 第三项）。

三态谓词 **ρ(c)**：

| 态 | 条件 | 语义 |
|---|---|---|
| **可达** | E(c) ≤ R_rem（含 E=0 已成型特例） | 期望完成轮数在局终视界内 |
| **超窗** | R_rem < E(c) < +inf | 期望完成超出局终视界（025608 病灶型） |
| **字面零** | E(c) = +inf（kernel 字面条件：d>0 ∧ 当前等级 p̄=0） | 当前等级刷不出缺口费用档（零窗上界 = 逐标签注册表核查量 L0(tag)，见 P-G5；当前注册表全标签零窗 ≤ lv3，注册表演化须重核） |

### 3.2 换线可达性门（判据本体）

**换线 cur → alt 合法 ⟺ (P16 判据通过) ∧ (ρ(alt)=可达)**，即：

```
E(alt) 有限 ∧ E(alt)·(1+δ) + θ < E(cur)·(1+δ) ∧ dwell ≥ D_min    (P16 判据，kernel should_switch_e 逐字)
∧ E(alt) ≤ R_rem                                                  (可达性门，本命题新增的唯一合取项)
```

零可达候选帧（候选集内无 ρ=可达 者）→ 不换线，**路由生存模式**（12 号篇 §3 既有兜底语义，[31] 三级，无新通道）。

### 3.3 与 P16 滞回的并轨关系（单一源归行）

1. **并轨非并立**：门是 P16 判据上的**纯合取过滤器**，与滞回共享同一次评估、同一 kernel 单一源、同一 registry 参数族（`line_switch_theta=1.0 / line_switch_debias_delta=0.15 / line_switch_min_dwell=2`，现行 `kernel/cw_registry.py:908-913`，2026-09-09 亲核）——**禁第二套阈值族**：门引入的新约束项 `E ≤ R_rem` 的两个词项均为既有单一源（kernel `e_rounds` + `plane_table`），零新可调常量、零新单一源。
2. **归行声明**（00_framework §5「新约束必须声明归入表内某一行或为新立单一源」）：本门约束归 **01_math_framework §3.7（判据数学之家，P16 所在行）+ 12_line_and_intention §3（换线机器语义行，P16 判据作为三/四触发后评估载体的判据扩展）** 双行，不新立单一源；已随登记批双锚落地（本单篇入 math_proofs 索引 + 12 §3 语义行更新，2026-09-09）。

## 4. 证明（闭式部分）

记 k = 1+δ > 0（δ=0.15，k=1.15），θ = 1.0 > 0，D_min = 2（P16 已证常量域；定理对 θ>0 ∧ D_min≥1 全域成立）。

### P-G1（谓词良定义）

ρ(c) 由 kernel 两个已证函数（`line_distance`/`p_bar_faction`→`e_rounds`）与游戏定义量 `r_remaining` 逐字决定，无自由参数、无拟合量；三态对任意 E∈[0,+inf] 互斥且穷尽（E=0 已成型归可达；「d>0」只出现在字面零的 kernel 字面条件内，不缩穷尽性）。∎（构造性：kernel :134-135/:145-146 的分支即定义）

### P-G2（可达域零干涉定理）

**若 E(cur) ≤ R_rem 且 P16 判据通过，则 ρ(alt)=可达自动成立**——门在 cur 可达域恒空转，不拒绝任何滞回合法换线。

证：判据通过 ⟹ E(alt)·k + θ < E(cur)·k ⟹ E(alt) < E(cur) − θ/k。由 θ=1.0，k=1.15：θ/k = 0.870（由 P16 已证常量直算，**非拍值**）。故 E(alt) < E(cur) − 0.87 < E(cur) ≤ R_rem。∎

推论 1：门的全部约束力集中在 cur 超窗/字面零域；健康域（锁线可达）行为与无门逐位恒等。
推论 2：门加于滞回之上还有一个**正裕度** θ/k ≈ 0.87 轮——凡换出可达线，落点不仅可达而且期望完成裕量严格正。

### P-G3（振荡界继承定理）

**门下换线决策序列仍无抖动，振荡频率硬上界仍为 1/(2·D_min) 次/轮。**

证：门是合取项，门合法序列 ⊆ 无门合法序列（过滤器只删不增）。P16 振荡界的证明材料只有两件——双向切换条件的代数不相容（两式相加得 2θ<0 矛盾）与 D_min 时间硬约束——均对序列集合的**子集**封闭：子集内任一往复对仍须满足无门双向条件与 D_min 间隔，故无抖动性与频率上界逐字继承。∎

### P-G4（字面零区救援资格定理）

**E(cur)=+inf 时，无门判据的 kernel 比较分支对任一有限 E(alt) 恒通过（kernel :190 rhs=inf），判据仅余 dwell 项；故在 dwell ≥ D_min 域内，门是唯一附加约束，放行集恰为 {alt : E(alt) ≤ R_rem}（dwell < D_min 帧判据本体已拒，与门无关）。**

证：kernel `should_switch_e` :183-184 先拒 alt=inf；:190-191 中有限 lhs < inf 恒真，即比较分支恒过；dwell ≥ D_min 时 :193-194 不拒，判据余项为空。叠加门合取后，放行集 = 有限 E 且 ≤ R_rem。∎（事件侧另有回锁禁止窗 D-P4，proof.py:325-329，属事件登记层附加约束，不入 kernel 判据本体，本定理辖 kernel 层。）

推论（025608 型病灶的治理语义）：封印解除后，超窗/字面零锁线的换线评估一旦开火，**逃逸落点必为可达线**；字面零区门即救援资格判定本体。本命题对 025608 病灶的诚实申报与姊妹门 P74 同款：**门不自行解封通道（发射依赖标定槽，§6），对病灶帧的行为改变在封印期 = 零**；门保证的是解封后救援的落点质量。

### P-G5（字面零窗口刻画引理·两层形态）

**表层恒真式（纯表读法）**：记 L0(tag) = min{ c 档首正等级 : c ∈ tag 成员费档 }，首正等级由 REFRESH_PROB 表逐档直读（1 费→1、2/3 费→4、4 费→5、5 费→7；`data/cw_shop_odds.py:42-53`）。则 **p̄(tag,lv)=0 ⟺ lv < L0(tag)**。

**注册表层归约（游戏数据事实，非表推论）**：若**当前注册表每个标签（阵营∪流派）都含 ≤3 费成员**，则 L0(tag) ≤ 3，字面零窗口退化为 lv1-3。该前提已由方案审直调核查成立（2026-09-09：全标签 p̄=0 窗口枚举，lv1-10 × 全标签，0 个标签零窗超出 lv1-3）——但它随注册表演化可破（新增纯高费标签即破），非结构恒真；**核查义务随批存档**（脚本锚：全标签 × p_bar_faction 逐级枚举断言零窗 ≤ lv3，随登记/落码批入库，注册表变更即重跑）。

证（表层）：p̄ 按 tag 的费用档并集聚合（kernel :71-94），全档零 ⟺ 每个含目标件的费档在 lv 行为零 ⟺ lv < 该 tag 最低成员费档的首正等级 = L0(tag)。∎（「成员费档」口径与 kernel `p_bar_faction` 标签成员级聚合语义逐字一致——对销复核亲读 kernel :60-164 确认。）

治理推论：
- **字面零 ≠ 永久不可达**（F1「等级条件零」同源治理）：本门禁消费「inf=死线」语义，升级杠杆归 P39 升级门辖域，不入本门；
- **lv ≥ 7 的锁线病灶必为超窗型，无条件成立**（lv7 行五档全正 ⟹ L0(tag) ≤ 7 对任意非空标签 ⟹ lv≥7 时 p̄>0）——025608 @lv7 的超窗型分类不依赖注册表前提；lv4-6 的字面零可能性纯系注册表前提波及面，由前提核查脚本守卫；
- 投资环境轮岗的概率翻倍不改变零判定（0×2=0），本引理辖 kernel 模型（kernel 不建模轮岗，P16 单篇数据源行同口径）。

### P-G6（门位等价引理）

**候选侧预过滤（仅 ρ=可达 者入候选）与比较器侧合取（对 argmin-E 的 alt* 判 ρ）的放行集恒等**（相对同一基础候选集）。

证：设 alt* = argmin E（候选集有限）。若 E(alt*) > R_rem，则 ∀候选 c：E(c) ≥ E(alt*) > R_rem，候选侧滤空——两侧同拒；若 E(alt*) ≤ R_rem，两侧同放。∎ 差异仅在归因分键（拒因记 `no_alt` 还是 `alt_over_window`），落码批择一，申报即可。

## 5. 未证部分（如实申报，按待证假设对待）

1. **超窗区拒绝的 EV 最优性未证**。门在超窗域拒绝「换向期望完成轮数更短但仍超窗的线」；F2 已证**中间档交付真实战力**（P60 型教训），故不存在「超窗线无价值」的支配论证。拒缺省的合法性依据只有两条：**零回归**（与现状逐位恒等）+**决策语义守恒**（完成期望比较的胜者不兑现完成时，该比较失去它广告给决策者的对象；价值轴换到中间档/生存模式，后者在 E_rounds 辖域之外）。其 EV 是否最优 = 待证假设，检验面见 §8.5（确认性 A/B，无裁决权）。

3. **CDF 细化臂挂账**：以 P38 五层完成概率替代序数判据属标定债面（阈值 θ* 需标定），与本命题分离申报（§6），不在本命题辖域。

## 8. 可检验推论与证伪面（验收声明）

1. **零干涉预测（最强证伪面；判读键 = 状态匹配离线复判）**：sim A/B（门 on vs off）中，**cur 可达域行为逐位恒等**（P-G2）。判读协议：门裁决是录制状态的纯函数，两臂全量记录 (E(cur), E(alt), R_rem, dwell, 裁决) 五元组，**按状态匹配帧**后断言「E(cur) ≤ R_rem 的匹配帧上两臂裁决恒等」——**禁轨迹位置配对**（两臂一旦在超窗/字面零域出现合法分歧，后续状态分叉，位置配对的级联差异会被误读为零干涉违例 = 假证伪，反之也可能掩盖真违例）。状态匹配下的可达域裁决差异 = 证伪本命题实现；差异只允许出现在超窗/字面零域。
2. **振荡界预测**：P16 检验点 4 参数网格（θ×D_min×δ）在门 on 下扩展复跑，任意网格点振荡率 ≤ 1/(2·D_min) 的局占比上限预测成立；违例 = 证伪 P-G3。
3. **单帧锁五件**（落码批验收锚，登记批仅声明）：
   - 零干涉锁：cur 可达 + 判据过帧，门 on/off 输出恒等；
   - 救援锁：构造帧须显式满足 **dwell ≥ D_min**（否则 kernel 正确的 dwell 拒绝会造成假红）：E(cur)=inf + 可达 alt + dwell≥D_min → 放行（`reach_admitted`）；E(cur)=inf + 超窗 alt + dwell≥D_min → 拒（`reach_refused_over_window`）；
   - 超窗互斥锁：cur 超窗 + alt 超窗 + 判据过 → 拒并路由读数显影；
   - 病灶锚：025608 p2 第 1 轮形态帧（cur 超窗型）读数 = ∃可达 alt 时门输出「可逃逸」、零可达时生存模式路由读数——**挂点 = 门谓词单帧直锁**（构造态直调门函数本体，不经 `should_switch` 全链；封印期全链在 :277-284 即短路，全链评估型锁永不评估）；
   - 字面零窗口锁（动态派生）：测试内由 REFRESH_PROB 表 + 注册表**现算**各标签 L0(tag)，断言 E=+inf ⟺ lv < L0（该线标签集）——**禁静态钉「仅 lv≤3」快照**（注册表演化新增纯高费标签时，静态锁会错怪正确测试，违锁的存在性纪律）；「零窗 ≤ lv3」的当前归约由 P-G5 前提核查脚本单独守卫（§9.7）。
4. **分键语义锁**：「E(alt) ≤ R_rem 被拒」或「E(alt) > R_rem 且判据过被放行」的任一单帧反例 = 证伪门定义实现。
5. **确认性 A/B（无裁决权）**：超窗域门 on/off 的结局对比（form_ok 达成率/生存/通关），回答 §5.1 待证假设的方向；**sim 结果不构成门的数值合法性来源**（合法性 = 本命题结构证明 + 零回归缺省）。
