## 1. 命题(摊还定理形式)

设决策帧:等级 9,板满(deployed = cap),bench 有等待上场件(pop_slot 授权语境,P23 §① 机制链),升级 lv9→10 一次付清经验成本 **C = 84 金**(`cw_state.py:XP_TO_NEXT_LEVEL[9]=84` XP;XP_PER_BUY=4;单击价 `XP_CLICK_COST_FALLBACK=4` 金/击,21 击 × 4 = 84——见 §6 卡点④)。记:

- **v = Δp·L_c + w**:升级后每场战斗的金当量边际(人口增量战力项 Δp·L_c + 胜负金差项 w);
- **r**:升级到账后的剩余战斗数(等级跨位面持久 → 计满 P2 尾 + P3,见 §2.2 视界);
- **R**:升级到账后的剩余计息轮数(备战节点数;与 r 同源,近似 R ≈ r,见 §4 边界);
- **d(g; C)**:该笔支出的**息档损失深度**,闭式(利息 = min(⌊g/10⌋, 5) 金/轮,economy.md §10.1):

```
d(g; C) = min(⌊g/10⌋, 5) − min(⌊(g−C)/10⌋, 5)
```

**命题 P35-a(摊还判据,闭式)**:升级相对不升的期望净值为

```
EV = v·r − C − d(g; C)·R
```

在 R ≈ r 近似下,EV > 0 的充分必要条件为

```
v > d(g; C)   且   r > C / (v − d(g; C))
```

即「每场人口边际须先压过每轮息损深度,再摊还本金」。**恒负充分条件:v ≤ d(g; C)**——此时无论剩余轮数多长 EV 严格为负(不升级的息流永不停止,升级本金永无摊还完的一刻)。

**命题 P35-b(息线分域,闭式)**:g ≥ C = 84(可负担前提)时,d(g; 84) 只取 {5,4,3,2,1,0},分段边界为 g ∈ [84,94)→5 / [94,104)→4 / [104,114)→3 / [114,124)→2 / [124,134)→1 / g ≥ 134→0。注意 d 被**息帽 5 封顶**——W687 用的带 I∈[0,20] 在单笔一次性付清口径下过宽;且金在息线以上(g ≥ 134)时破息项**精确为零**,升级只与本金摊还竞争。

**命题 P35-c(D 侧概率红利,结构项)**:lv10 相对 lv9 的商店概率提升(`cw_shop_odds.REFRESH_PROB`,实机 OCR 权威表)对 4/5 费猎取是正项:目标费用 c 的期望刷新次数按 P16 超几何模型**精确地**按 p(9,c)/p(10,c) 缩放(费用档内超几何因子相消),即 5 费猎取提速 1 − 0.10/0.25 = **60%**、4 费提速 1 − 0.30/0.40 = **25%**。等价金当量红利 B = Σ_j ρ_c·D_j(ρ_5=0.6、ρ_4=0.25,D_j = 剩余视界内对 c 档的刷新支出),方向恒正;量级卡点见 §6。

## 2. 推导

### 2.1 三项账的分解(P23.1 同构,符号沿用其符号表)

P23.1 已证统一门式 EV = Δp·L_c·m + w·m − C − I。本篇做两处精化:

1. **息损项 I 精确化**:P23 取带 I∈[0,20](账本金分布实标的粗口径)。单笔 84 金一次付清时,息律是确定机制(P13):每轮利息 min(⌊g/10⌋,5),支出把金从 g 压到 g−84,此后 R 轮每轮少收 d(g;84) 金,合计 d·R。d 只依赖 g(状态可读量)与机制常量,零自由参数——与 P33 的 d·R 零参数息损项同款。g ≥ 84 > 50 前提下破息至多跨 5 档(息帽封顶),d ≤ 5。
2. **摊还形式化**:把 P23.1 的 m 视角换成每场边际视角,v·r 与 C + d·R 相除即得 P35-a 的两个条件——第一个条件(v > d)是**流量竞争**(人口边际每场挣的须多于不升级每轮白得的息),第二个条件(r > C/(v−d))是**本金摊还**(净流量差多少轮填平 84 金)。

### 2.2 视界 r 与 P2=7 的语义

- **P2=7 不是机制上限**:W690 §1.2 已裁决「P2=7 槽」是 power_baseline 的描述性人口口径(P2 中位 6-7 人),非封顶常量;棋盘绝对容量 10(`cw_state.py` front_max+back_max=4+6),lv9→10 是**最后一次真实人口增量**,边际人口价值不为零(封顶塌缩论不适用)。本命题沿用该裁决,不再重证。
- **r 的取值域(账本实测)**:w676 off 臂 227 停手窗 LevelUp 帧行逐帧实数,P1+P2 视野 min/p25/中位/p75/max = 1/5/7/8/9;加 P3 节点带 8-10(`cw_node_reader`)→ **r ∈ [5, 19],中心 15**(P23 §2.2 同源)。P2 内升级的 r 至多 7 + P3 带 ≈ 17;末窗(r9/boss 帧)的 r ≤ 3。

### 2.3 P35-c 的超几何缩放(零参数)

P16 模型:找一张目标牌的期望刷新次数 E ∝ 1/(p(level,c)·q),q 为「目标费用槽内出目标牌」的超几何因子(只依赖牌池副本数与目标数,与等级无关)。故 E(9,c)/E(10,c) = p(10,c)/p(9,c) **精确成立**,提速比 1 − p(9,c)/p(10,c) 由 `cw_shop_odds.REFRESH_PROB`(实机 OCR 权威表)直接读出,零新常数。红利只兑现于「确实在 D 4/5 费」的帧(P3 型语境);停手窗不 D 时红利为零,本项是**上界型正项**(有利于升级侧,计入后负判更保守)。

## 6. 策略含义(消费点)

1. **lv9 停留的合法性闭合**:W687 挂账的「停手窗 77 帧 lv9 帧行从未被证明」——本命题证明在全部标定带内**停留就是账面正确**,无行为改动需求;翻案唯一通道 = 卡点①的 Δp 实采(P23 挂账共轨,不另立采集)。
