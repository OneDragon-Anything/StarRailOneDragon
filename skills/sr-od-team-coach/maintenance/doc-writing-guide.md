# 知识档填写指南（维护者文档）

给维护本 skill 知识库的 agent/人：角色档、体系档、机制档的模板、填写方法论与纪律。随填写经验持续修订本文档。

## 公共红线（所有档）

- **零账号关联**：任何档不得出现特定账号信息（BOX、练度数值、持有星魂数）。星魂档位只写「E几质变+为什么」，不写「某人有没有」。
- **证据层级必标**：【官】= 官方技能/星魂/行迹/光锥文本（最优先）；【攻】= 攻略交叉验证（必须标时效，如「2026-02 攻略口径」）；官方文本拿不到的点进「信息缺口」，禁止用攻略冒充官方。
- **版本可追溯**：档案开头标注「按 V<版本> 期撰写」；平衡性改动过的角色在档内注明以最新官方文本为准。
- **术语白话**：游戏内名词可用（湍流/残梦/忆灵），自造缩写禁用；机制词首次出现给一句定义。

## 角色档模板（一人一档，v2 三段式）

> v2 结构（用户裁定）：按「用户问题」组织——这是什么角色 / 穿什么 / 配什么队；推导内容收编为各段的「原因」。v1 的转模/词条/绑定内容不丢，位置见对照。

```markdown
## 一、命途属性与技能说明

**命途**：<命途>（<计数/资源绑定一句>）

| 战技 | <要点> |

## 二、推荐遗器与原因
```

## 阵容档模板（lineups/，一队一档）

```markdown
# <阵容名>（<锚点角色>队）

> 按 V<版本> 期整理。<一句话：靠什么赢>。

## 成员与定位
| 位 | 角色 | 一句话分工 | 链接角色档 |

## 为什么是这四个人（绑定逻辑）
<资源/计数/乘区的咬合；缺一人损什么>

## 攻略参考轴（参考向，非强制——按实际练度与手感调整）
- 开局秘技序
- 回合轴/循环（T1... T2...）
- 配速参考【攻】（速度档位表）
```

> 配速与回合轴一律标注【攻】并声明「参考向，非强制」（用户裁定）。

## 体系档模板（一类一档）

```markdown
# <体系名>（<锚点角色>体系）

> 按 V<版本> 期撰写。<一句话：靠什么赢>。

## 核心思路
资源循环 + 伤害逻辑 + 生存逻辑，为什么这套绑定成立。

## 骨架与绑定规则
槽位结构（主C/N辅/生存）+ 计数/资源绑定规则原文（谁要求队友是什么命途/什么行为）。

## 标准阵容与变体
按主C星魂档位/环境（对单/对群）列阵容变体；每队一句核心逻辑。

## 成员要点
链接各成员角色档 + 每人一句「为什么在位」。

## 操作轴
开局秘技顺序 / 循环分工 / 技能点分配 / 终结技时机。只写影响胜负的节点。

## 替补矩阵
缺谁 → 换谁 → 损失什么。表格式。

## 环境适配
哪类玩法/环境增益利好；被什么环境克制。

## 信息缺口
```

## 机制档模板（一条机制一档）

```markdown
# <机制名>
定义（是什么）→ 运作规则（怎么转）→ 影响面（影响哪些配队/词条判断）→ 证据层级。
只收「跨角色成立」的规则；单角色机制归角色档。
```

## 填写方法论（持续总结区）

### v1（初始，来自首批三体系调研的总结）

1. **词条口径的推导链**：伤害模型（倍率吃什么属性）→ 大招资源（充能是否有效）→ 转模行迹（什么属性有双重收益）→ 转化上限（毕业线在哪）→ 套装条件（速度阈值类）。五步走完口径自然出来，不要跳步直接抄攻略结论。
2. **绑定规则找原文**：队友计数/行为绑定的原文在行迹、星魂、天赋里（「队伍中XX命途角色数量…」句式）；配队骨架改动（如黄泉 E2 减员需求）通常在星魂文本。
3. **硬否决要给机制理由**：不是「不推荐」，是「体系失效」（例：护盾位使烧血充能体系的收入归零）。硬否决与偏好推荐分开写。
4. **攻略数值必须时效标注**：公式系数、面板目标（如「190速/80暴」）都是攻略实测归纳，写【攻】+日期；官方文本只锚机制不锚数值。
5. **去账号化改写**：调研笔记里「账号现状/本账号主推」等内容转化时删除；阵容变体改写为「按星魂档位」的条件式表述。

### v2（V4.7 期，欢愉/记忆/虚无扩展批总结）

6. **混伤模型要显式标注**：部分欢愉角色（火花/绯英/砂金•戏浪）普攻/战技/终结技是攻击力直伤 + 天赋 rider 是欢愉伤害——攻击%/传统攻击增益对其直伤部分有效，与纯欢愉角色（银狼LV.999）口径不同。角色档「伤害模型」节必须写清哪些技能走哪个体系。
7. **DoT 是无暴击口径**：持续伤害不能暴击——DoT 主C 的双暴词条无效，口径=攻击%+效果命中+速度；命中还常带转伤（黑天鹅 120%/海瑟音 120% 吃满线）。「不堆什么」一栏对 DoT 角色必须写双暴无效。
8. **官方 wiki 文本的陷阱**：①模板变量偶尔未渲染（如忘归人战技减防概率显示 `#3[i]%`）——遇到占位符记入信息缺口，以游戏内文本为准；②社区对**形态角色**（X•Y 命名）的定位传闻不可靠（砂金•戏浪曾被传「欢愉生存位」，官方文本无任何生存机制）——形态角色一律以拉到的官方文本重判定位；③基本信息里命途/阵营字段是嵌 JSON 的富文本，解析时取 `name` 键。
9. **计数绑定的句式扫描法**：搜「队伍中.*命途角色数量」「存在.*角色时」句式可穷举计数绑定行迹（奈落/真珠E1/长夜月B4/火花A2/千冶•刃B1/昔涟A2 均为该句式）——建角色档时先扫这类句式，绑定关系不会漏。
10. **速度阈值型转模的共性**：欢愉系（银狼999:160/爻光:120/砂金•戏浪:140）、记忆系（昔涟:180/阿格莱雅 E6:160/240/320）、击破系（忘归人 220% 击破）都有「阈值起步+超额线性+计点上限」三段式——转化上限节写清「阈值/斜率/计点上限」三件套，练度评价直接可算。

### v3（V4.7 期，毁灭/巡猎/智识/收尾批总结）

11. **前瞻未实装的判定**：国内 wiki 行迹模块名为「角色行迹前瞻【请以正式版本为准】」且 points 全空 = 未实装占位词条（实测：艾莲/耀嘉音/星神★阿哈）——这类**不建档**，INDEX 记前瞻占位，实装后再补。HoYoWiki 列表可能滞后于国内列表（93 vs 96），以国内列表为全量基准。
12. **形态角色（X•Y 命名）双站异名**：仙舟三月七在国内列表叫「仙舟三月七」、HoYoWiki 叫「三月七•巡猎」；文件名以国内官方名为准，抓取时两个名字都试。
13. **烧血体系的家族判定**：掉血即资源的角色家族（遐蝶新蕊/万敌充能/镜流烧队友转攻/刃已损失结算/千冶•刃生命成本）——它们与护盾位一律冲突（挡掉血=断粮）、与丰饶奶/烧血协同位互亲；这个「资源家族」判定比命途更能预测配队兼容性。
14. **「视为消耗战技点」类机制清单化**：饮月逆鳞、火花爆点等「视为消耗战技点」效果与「消耗战技点触发」类机制（银狼盲盒/青雀摸牌）联动——角色档机制要点里出现该句式时，在绑定节写明联动对象。
15. **覆盖核对收口**：建档完成后跑「官方列表去重 - 前瞻」对「档目录」的差集核对（开拓者形态做合并映射）；INDEX 的覆盖数字以核对脚本结果为准，不手数。

### v4（V4.7 期，二期三段式重构总结）

16. **角色档三段式 = 用户问题视角**（用户裁定）：「这是什么角色（技能说明）/ 穿什么（推荐遗器+原因）/ 配什么队（推荐配队+原因）」；推导内容（伤害模型/转模/上限表）收编为二、三段的「原因」——**不是删掉推导，是把推导挂在结论下面**。技能表要完整到普攻/战技/终结技/天赋/秘技/额外能力（此前机制要点只写配队相关的一半）。
17. **遗器推荐三要素**：套装（4+2，标【官/攻】）+ 主词条表（带原因）+ 转化上限（阈值/斜率/计点三件套）——套装选择逻辑锚定角色机制（如诗人套<95速对忆灵生效、卜者速度阈值、魔法少女欢愉无视防御），参考 mechanics/relic-sets.md 的效果标签选型。
18. **阵容档与体系档的分工**（方案二）：体系档写引擎与替补（换人不换打法逻辑），阵容档写确切四人的打法（秘技序/回合轴/配速/SP预算）——同一套机制解释只写一次在体系档，阵容档只链不抄。
19. **配速/回合轴的口径纪律**（用户裁定）：一律标【攻】+「参考向，非强制——按实际练度与手感调整」声明；不给「必须 XX 速」的硬指令。
20. **遗器套装官方数据源**：国内 wiki channel_id=30 是遗器套装频道（62套：名单+效果分类标签）；详情页多为空壳——效果数值以调研验证的【官】+套装标签推断+攻略【攻】三层标注；HoYoWiki menu 117 是音乐（OST）不是遗器，channel 21/22/24 等为空。

### v5（V4.7 期，三期多轮调研启动）

21. **调研轮次制**（用户裁定）：每个角色档/体系档显式记录轮次——R1=官方文本+首轮社区调研；R2=米游社+B站（社区共识层：使用率/配队变体/装备替代/常见误区）；R3+=使用率面板等数据源。**调研源限定米游社（miyoushe/bbs.mihoyo.com/sr.mihoyo.com）与B站（bilibili.com + B站系 BWIKI）**——其他源（Prydwen/taptap 等）只作为 R1 历史存量，不再新增。
22. **玩法层建层**（用户裁定）：modes/ 一玩法一档，头部标注受众定位（主流/较新/小众/一次性）——**小众玩法明确标注**（货币战争·活动期、锄大地、回忆持久层），提示「不必为其优化配队」。玩法档的适配体系节链接体系/阵容档，与角色层互链。
23. **前瞻角色的跟踪口径**：前瞻未实装角色（艾莲/耀嘉音/星神★阿哈）在对应体系档的「调研轮次」节记前瞻情报（如 4.7 虚照星神阿哈=欢愉队售后、愿力机制、伶人4效果）——不建角色档，但情报不丢，实装后转正。
24. **社区实证的采信标准**：B站实战视频（如「00泉刃队 5T 通关 4.6 混沌」）可作阵容可行性实证（标【攻：B站+日期】）；UP 名与 BV 号可留检索线索但档内只写结论+来源平台，不依赖单一 UP。
