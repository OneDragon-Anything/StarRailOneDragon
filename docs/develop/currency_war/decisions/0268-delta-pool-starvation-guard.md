## 背景

批③ 池桶审计实锤:snapshot 池(指纹 942d3f79)battle 桶6 **n=1**(恒 -11)、
encounter 各桶 n≤1、桶 3/0 无数据。sim 深度=可 deploy 件数——任何把早期板深推过
桶 6 边界的策略臂(B/B1/C),都会从「方向模型均值 ≈0」摔进「恒 -11」确定性悬崖
→ snapshot 口径 hp 降幅大半是**采样伪影**,不是策略效应。**sim 的策略 A/B 方向
判断在守卫落地前不可信**(批①②③多结论受波及)。

## 决策

### 1. 防饥饿守卫(live_delta_for)

命中桶 n < `_BUCKET_MIN_N`(=5)时不裸采样,降级三候选取**方差最小**者采样:

- 本桶 ∪ 浅邻桶(合并天然加权——样本多的邻桶主导);
- 本桶 ∪ 深邻桶;
- 该节点全池均匀。

候选并列按 浅邻→深邻→全池 序(确定性);无任何可合并邻桶(极端小池)退回裸
样本;**「缺桶 → None(调用方走旧模型)」两态语义不变**(r340 锁)。
饥饿样本以合并权重参与(如桶6 n=1 并入桶9 n=19 → -11 以 1/20 权重出现),
不是剔除——合并非否认该样本,只是不再让它独裁整个深度带。

`_SAMPLER_VERSION` 1→2(采样语义入指纹):旧报告对旧池重放须用导出 JSON 快照
(v1 指纹 942d3f79c09e2eb5 不再可命中,属预期)。

### 2. 快照补样结论:**battle 桶6 真值不可得,守卫是唯一解**

生产 replay 语料(16 局,全量重生成)battle 桶6 仍 **n=1**——补样不可得。
其余桶已补:battle 桶9 9→19 / 桶12 3→21 / 桶15 0→6,boss 桶12/15 各 4/6。
新指纹 **e19afdfa4173077e**。桶6 的深[6-8] Δ 真值须等生产局自然积累(需
n≥5 才可撤守卫——`delta_pool_bucket_min_n` 检查项即撤守判据)。

### 3. 检查项 3 条入 cw_sim_checks(批③ 设计落地)

| 名称 | 判据 | 备注 |
|---|---|---|
| `delta_pool_bucket_min_n` | 任一节点任一桶 n<5 → 违规披露 | 池级检查(batch 内嵌);**数据披露非策略断言**——语料饥饿时恒非零是目的,smoke 测试按披露豁免 0 容忍 |
| `depth_cliff_monotonicity` | 可信桶(n≥5)均值随深度单调不减血;违 = 池不可用于方向判断 | 饥饿桶不参评(检查项 1 辖);均值含回合混杂声明(深桶样本多来自晚轮,违反先查桶×轮分布) |
| `sim_ab_depth_boundary_confound` | 两臂战斗轮深度桶占用不对称 → 打「池混杂」标 | 吃两臂账本(A/B 对照调用方使用;纯 dict/list 入参,不 import cw_sim) |

前两条池级检查挂在 `checks_violations` 下(带 violations 计数+明细,非 games)。

### 4. 附带发现(新语料的深崖方向反转,需重验)

新 16 局语料 battle 可信桶均值:桶9 **-6.6** → 桶12 **-8.4** → 桶15 **-11.7**
——**更深反而更痛**,与 r343 建池依据(深[6-8] -1.0 vs [3-5] -11.3,「深=掉血
少」)方向相反,`depth_cliff_monotonicity` 现报 2 对违规。桶6 n=1 的 -11 很可能
与 r343 的 深[6-8] -1.0 同属小样本噪声;**板深效应的真实方向本身是未决问题**
(疑回合混杂:深桶样本多来自晚轮)。重验路径:桶×轮联合分布审计后再谈板深
条件化是否保留。

## Considered Options(取舍存档)

- **A. 裸采样 + K 不足直接 None(退旧模型)**:拒绝——饥饿桶整深度带退方向二元
  模型,等于把板深条件化在该带静默拆除(⓪ 纪律禁止隐式回退);
- **B. 相邻桶合并(加权)+ 全池均匀,选方差最小(选定)**:无参数假设、样本量
  自然加权、确定性;方差最小 = 在「贴近邻桶经验」与「不引入离群悬崖」间取
  最稳的候选;比固定方向合并(只浅/只深)少一层偏乐观/偏悲观假设;
- **C. 只向浅侧合并(沿 r343 回退方向)**:拒绝——新语料显示深侧可能才是
  「更痛」方向(见 §4),固定浅侧会系统性偏乐观;
- **D. 均值插值(桶间线性)**:拒绝——引入参数假设且饥饿桶均值本身不可信
  (n=1 的「均值」就是那个唯一样本)。
