## 推导

### ① 吞吐账:每炉命中率 vs 每件命中率(口述问题的精确回答)

**机制展开**(注册表 :182 直读):角色用法 = 取下全部(≤3)+ 每件**各自**独立变为同类型随机。所以 1 炉 = r = min(d,3) 次独立重掷,每次命中目标(可接受集 m/N)概率 = m/N。

**每炉命中率**(≥1 件命中):

```
P(≥1 | r 次重掷) = 1 − (1 − m/N)^r        E[命中数 | r] = r·m/N
r=1: m/N                     (单件用法)
r=3: 1 − (1 − m/N)^3         (角色用法满批)
```

**数值表(m=1;脚本 §2 精确分数锁)**:

| r | 简易目标 P(≥1) | 进阶目标 P(≥1) | E[命中] 简易 | E[命中] 进阶 |
|---|---|---|---|---|
| 1 | 1/8 = 12.50% | 1/36 = 2.78% | 0.125 | 0.0278 |
| 2 | 15/64 = 23.44% | 71/1296 = 5.48% | 0.250 | 0.0556 |
| **3** | **169/512 = 33.01%** | **3781/46656 = 8.10%** | 0.375 | 0.0833 |

**口述回答(锁)**:「冶金炉用到角色身上,同时随机 3 个,这种获得目标的几率会高一点吗」——
- **每炉:是**。简易 12.5% → 33.0%、进阶 2.78% → 8.10%,近似 3 倍但有**非线性折扣**:P(≥1) = 33.0% < 3×12.5% = 37.5%(E[命中数] 恰 3 倍,但「至少一件」口径下三事件有重叠——同炉双中是浪费,若目标只需一份,超过一份的部分无增量价值);
- **每件:不变**。每件的边际命中率恒 = m/N(池密度),与烧法无关——**角色用法不提高单件质量,只提高每炉吞吐**。∎(定义直读 + 脚本断言)

**可接受集泛化(m = 1..4;脚本 §3 全表锁)**:每炉命中率 1−((N−m)/N)³,进阶 m=4 时 29.8%——「回收流水线瞄准一组可接受进阶(不止一件有用)」时批量模式的每炉命中率显著抬升;m 是策略侧可设计变量(目标集的宽容度),量级见下表。

**口径分层声明**:「3 倍」只在**线性口径**(E[命中数/炉] = 3m/N vs m/N,恰 3 倍;E[重掷数→首中] 两模式同为 N/m,每件命中率不变)下成立;**E[炉→首中] 是炉次口径**——批量列是 q = 1−(1−m/N)³ 的几何分布期望 1/q,**不是** N/(3m)(后者把线性口径的数误配到炉次口径,对几何分布不可乘除;① 正文 L68 已声明非线性折扣,线性 m 表与之不相容)。两口径的比:

```
E[炉→首中]:单件 = N/m;角色 = 1/(1−((N−m)/N)³)
炉次口径批量/单件比 = (N/m)·(1−((N−m)/N)³) < 3(恒,非线性折扣)
  进阶 m=1:36 ÷ (46656/3781) = 3781/1296 ≈ 2.918
  简易 m=1: 8 ÷ (512/169)   = 169/64   ≈ 2.641
```

|---|---|---|---|---|---|---|---|
| 1 | 0.330 | 0.081 | 36.0 | **46656/3781 ≈ 12.340** | 8.0 | 512/169 ≈ 3.030 | 2.918 / 2.641 |
| 2 | 0.578 | 0.158 | 18.0 | **5832/919 ≈ 6.346** | 4.0 | 64/37 ≈ 1.730 | 2.836 / 2.312 |
| 3 | 0.756 | 0.230 | 12.0 | **1728/397 ≈ 4.353** | 2.667 | 512/387 ≈ 1.323 | 2.757 / 2.016 |
| 4 | 0.875 | 0.298 | 9.0 | **729/217 ≈ 3.359** | 2.0 | 8/7 ≈ 1.143 | 2.679 / 1.750 |

(角色列 = 1/(1−((N−m)/N)³),N=进阶 36/简易 8;炉次比 = 单件 ÷ 角色真值,恒 < 3 且随 m 递减——批量模式的炉效优势在宽容目标集下被非线性折扣侵蚀,方向仍严格占优。线性近似 N/(3m)(进阶 12.0/6.0/4.0/3.0)系统低估批量所需炉数 2.8%~11.9%,断言锁按 1/q 精确分数。)

### ② 炉子机会成本:省的是炉不是概率(交换论证)

**批量账**(脚本 §4):d 件死库存的角色模式炉耗 = ⌈d/3⌉,**每件炉耗** = ⌈d/3⌉/d:d=1→1.00、d=2→0.50、d=3→**0.333**、d=4→0.50、d=5→0.40、d=6→0.333……最小值 1/3 在 d ≡ 0 (mod 3) 取到;d≥2 即严格 <1。

**机会成本模型**:炉是**稀缺一次性道具**——获取流 = 投资策略牌发放(买彩票+ 1 炉、升级锅炉自给 +2、精密拆装·金 1、琼玉专家 2 等,`cw_invest_data.py`)与门户,无直接金币购买通道;装备域无付费补救通道(p42 结构差)。因此炉的边际价值 = 其最优替代用途的期望产出,而**所有炉用途的结构同质**(每次重掷价值 ≈ v,同池独立同分布)→ **每炉重掷数最大化 = 弱占优**:

> **交换论证(脚本 §8 枚举锁)**:对任意固定到达流(炉到货事件 F 与合格件到库事件 I 的任意序列),策略 B(凑满 min(3,pool) 批烧)的炉耗 ≤ 策略 S(见炉即单件烧),完整清算流上掷数相等、炉耗严格低(9 件流:S=9 炉 vs B=3 炉,各 9 掷)。等号仅当合格池从未达到 2。∎

**推论(与 p42 ④ N4 合流)**:p42 在册的「数学条件 d≥2 / 保守代理 d≥3」由本节每件炉耗表独立复证:d=2 即省一半炉,d=3 达满效率 1/3;**d≥2 的部分批已严格优于单件**,d=3 只是效率顶点而非门槛——p42 的 ≥3 安全带是「误扫损失未标定」下的保守代理,本篇吞吐侧无新门槛,维持 p42 口径。

### ③ 准入判据(终版):逐件门(p42 消费)+ 批量捆绑约束(本篇)

**两层结构**:

**层 1(逐件,消费 p42 ③ 不重推;[42] 消费注)**:件 x 可入回收池 iff 过 p42 逐件支配门——**[42] 裁定(2026-08-31 玩家)在层 1 的叠加:默认保留不喂(λ 难预知,软例外不立规);「inv>m 默认喂」的固定 K 口径受 [42] 时序口径约束——生效前提=掉落流仍活;P3 boss 窗口分支(掉落流终止,W=0):[42] 唯一确凿例外开放——超需冗余件喂入无未来损失(确定),批量侧=「P3 boss 备战期,批量池准入放宽到全部超需冗余件;近兑现张仍绝不喂(其价值在最终战武装,不因 W=0 归零)」**;
- `recycle_qualified` 边界(x ∉ supp(需求向量),inv > m)= **默认喂**(边际损失 0;P3 boss 窗口外按 [42] 保留——冗余件的期权>0);
- 近兑现张(d*=1,① 分层)= **绝不喂**(硬结论,全库全带含对抗角);
- 其余缺口件 = 默认不喂;带内软例外(残深≥2/近关张)按 p42 收益量级 0.02~0.36/次不立规;满需关张件按 **partner 状态分流**(到位不喂/未到位逐状态过 p42 ③ 原式)。

**层 2(批量,本篇新增——捆绑约束)**:角色用法**取下全部、无选择烧**——3 件一起掷,不能保护其中任何一件。

> **退化定理(两支)**:批量混入 u 件有用件(各损失 ℓᵢ > 0)的 EV 退化按合格池规模分两支:
>
> **(a) 合格池 ≥ 3(替换式)**:混入 = 用有用件换掉本可入池的合格件,同 d 同 r = 3——EV 退化 = **−Σℓᵢ,线性、零吞吐补偿**(每炉重掷数 r = min(d,3) 与装备内容无关,替换不改变掷数),纯粹把「本可留着合成的组件」按 1/概率变成随机件 → **剔除严格占优**;批量池必须在**穿戴前**保证 ⊆ 层 1 合格集(准入是预承诺,不是事后拆救——全拆发生在重掷之前,无中途取出通道)。
>
> **(b) 合格池 < 3(增量式,R1 补)**:混入有用件恰好**增大 d** → r 从池大小升到 3,多出的掷是真实吞吐增益(池=2 混 1:2 掷 → 3 掷)。净账 = 边际掷期望价值 w − ℓᵢ,「混批更优 ⟺ w > ℓᵢ」——**这一支不能经「r 与内容无关」论证**(该事实只切 (a) 支),占优性由 **p42 ③ 逐件支配不等式**承接:对未过层 1 门的件 x,p42 ③ 的支配条件(回收通道:喂 x 的期望损失 ℓ_new(x) 支配其期望收益,即 ℓ(x) ≥ w(x) 形)判定喂入被支配——近兑现张全带被支配(p42 ③ 硬结论,含对抗角)、满需关张·伙伴到位全库全带严格支配。**未闭合边角(显式声明)**:p42 ③ 报告的带内可违格(残深≥2/近关张层,收益 +0.003~+0.315/次)处 ℓ(x) < w(x) 成立,增量混入该类件**不被本定理支配**——但该件的「喂」判归 p42 ③ 单一源(层 1 已按其分流,可违格不立规默认不喂),本篇不推翻、只声明批量侧的占优论证在该格不闭合,待 p42 λ 标定后随彼收敛。∎(脚本 §7 显式建模 min(d,3) + 两支断言)

**降级处置**(任务书③的「整批降级」精确化):候选批中一件有用 → 两种处置,均为剔除后重算:
- **拆出该件单件处理**:该件回到 p42 ③ 逐件判定(可能默认不喂/等待 partner),其余合格件照常组批(d 减 1,每件炉耗按 ⌈(d−1)/3⌉/(d−1) 重查);
- **等凑齐**:池 <3 时持币等待(⑤ 证明等待零成本),或以 d=2 部分批先烧(仍严格省炉,②)。

### ④ 升级锅炉变体:炉自给定理 + 三通道资源账单

**炉自给**(脚本 §6 库存路径断言):锅炉生效期内对简易使用的净炉增量 = −1+2 = **+1/用** → 炉库存单调不降(F₀ ≥ 1 永不枯竭)。**含义:锅炉把「炉稀缺」翻转为「基础死库存稀缺」**——约束资源从炉转移到原料。

**目标 = 特定进阶 A 时的三通道账单**(合成免费,A4;每件命中独立同分布,A1):

| 通道 | 机制 | 期望资源账单(到首中) | 输入前提 |
|---|---|---|---|
| 进阶直取(无锅炉) | 炉拖进阶件 → 随机进阶(1/36) | **36 炉**,0 件库存销毁(循环喂) | ≥1 件进阶死库存 |
| 组件路径(无锅炉) | 炉拖简易件 → 随机简易(1/8),集齐 b₁+b₂ 合成 | **12 炉(交叉)/ 16 炉(自配)** + 2 件基础死库存(合成消耗) | ≥2 件基础死库存 |
| 锅炉简易通道 | 炉拖简易件 → 随机进阶(1/36)+ 净 +1 炉 | **0 净炉** + **期望 36 件基础死库存**(每用销毁 1 件) | 充足基础死库存 |

**组件路径期望的精确推导**(脚本 §5 线性方程组精确解):交叉(b₁,b₂)——E_b = 8(持其一待另一,几何期望),E₀ = (1 + 2·E_b/8)/(1 − 6/8) = **12**;自配(b×2)——负二项 r=2, p=1/8,E = 2/(1/8) = **16**;进阶直取 = 36。**组件路径炉效优势 = 3 倍(交叉)/ 2.25 倍(自配)**——「合成免费但需两件都中」的账:交叉只要求「两件各中一次」(首次有用件 1/4 概率、随后指定件 1/8),远易于直取的 1/36。

**盈亏平衡(锅炉 vs 组件路径)**:设 v_F = 炉边际机会价值、v_B = 基础死库存边际价值、锅炉产物残值 salvage ≥ 0(35/36 的失败产物是随机进阶——无用则回流批量池,③;有用则入 hoard_gaps,⑥):

```
锅炉优 ⟺ 36·v_B − salvage < 12·v_F + 2·v_B
⟺ v_F/v_B > (34 − salvage/v_B)/12 ≤ 34/12 = 17/6(salvage ≥ 0 ⟹ 阈值随 salvage 升高而降低,更利好锅炉)
```

**方向声明**:不等号链为「≤」——salvage ≥ 0 ⟹ (34 − s/v_B)/12 **≤** 34/12,即 **17/6 是阈值的上确界(salvage=0 取到)**,故「v_F/v_B > 17/6 ⟹ 锅炉占优」是**保守充分条件**(不等号方向为「≤」,17/6 是上确界而非下界)。阈值还随通道变化:组件路径交叉 12 炉/自配 16 炉对应 (34−s)/12 与 (34−s)/16(自配阈值 ≈ 34/16 = 2.125 更低),17/6 为两通道最保守值(脚本锁)。

**读数**:炉稀缺(v_F 高,无锅炉期攒下的目标多)→ 锅炉通道把炉账清零,只要基础死库存充裕就占优;基础死库存本身是稀缺资源(装备来源流全部待标定,p42 🔴)→ 36 件/命中的消耗速率放大稀缺。**方向性结论(中强,依赖 v_F/v_B 未货币化)**:锅炉在场时(a)炉不再是回收流水线的约束资源,组批门槛从「炉够不够」退化为「原料够不够」;(b)失败产物(随机进阶)直接回流批量池——锅炉通道与回收流水线**天然复合**(每次用炉 = 一次批量池的预充值)。与 ② 的交换论证不冲突:炉过剩时每件炉耗的优化目标失效,按原料吞吐重新对齐即可(每件基础死库存 1 次重掷,效率 1)。

### ⑤ 时机:「不规划攒炉时机」的数学形态 = 纯期权

**口述**(equipment_mechanics :130【口述·权威】):「到货随机 → 有炉才考虑刷什么,不规划攒炉时机」。

**数学形态**(脚本 §8 交换论证 + ② 每件炉耗表):

1. **外生性**(A3;辖域 = 非锅炉局):炉到货流 = 投资牌发放的搭车物,条件化在投资决策(投资域)后与烧炉时点/内容**无关**——任何「提前烧以加速炉到货」的通道不存在(反向也不存在:攒着不烧不影响炉何时来)。**锅炉边界声明(R3,与 ④ 矛盾消解)**:升级锅炉生效期内本腿**失效**——烧炉(锅炉通道)产 2 炉(净 +1),炉到货含**内生成分**且由烧炉时点决定;④ 的炉自给定理(净 +1/用)与本腿的「外生」并不冲突,而是划定其辖域:⑤ 的纯期权形态与弱占优结论**只在非锅炉局(外生到达流)成立**;锅炉期内「见炉即烧锅炉通道」反而加速炉再生,时机决策归 ④ 的锅炉复合场景(该场景未做动态规划,边界节在册),⑤ 不覆盖;
2. **持有零成本**:合格死库存的持有边际成本 = 0——不占金(无息账耦合,p47 域无关)、不占 bench 槽卡(装备栏独立)、无过期、无卖金通道的机会成本(A4:装备无金币获取通道 → 不存在「卖了换息」的替代收益被放弃);
3. **等待的边际价值 ≥ 0**:多持一件合格件 → 未来凑批的炉节省期望(② 每件炉耗 1 → 1/3)与目标命中率不变——**攒件等待 = 零成本、非负收益的纯期权**;
4. **弱占优**:对任意到达流,「等凑批」策略炉耗 ≤ 「见炉即单烧」(② 交换论证)——**「不规划攒炉时机」≠「不优化烧法」**:时点不规划(外生无控制),但**到货时刻的烧法**(批 vs 单、烧谁)是本篇 ②③ 的决策域。「有炉才考虑刷什么」= 决策正确地挂在炉到货事件上,而非挂在日历/攒件计数上。∎

**与 [41] 的对齐与差异**(任务书⑤):[41] 的资产形态 = 「零成本持有 + 期权 + 可逆变现」(超 50 金换成可退卡 = 活期资产)。合格死库存同构**前两项**但**缺第三项**——装备无卖金通道(A4),持有期权只能经炉(随机兑现)或合成(定向兑现)变现,不可退金。∴ 装备域的囤积**不是** [41] 意义上的活期资产,是**不可逆期权**(p42 ①「有用先囤」装备域辖域的吞吐侧对应物)。

## 边界(本证明不覆盖)

- 绝对 EV 空转:ℓ(x)/v_F/v_B 全部未货币化(p42 A5 辖域)——本篇一切结论是**结构/序/吞吐级**(省炉倍数、退化线性、占优方向),禁拍死值;
- 池均匀假设(A1)下的一切**幅度**(33.0%/8.10% 等)待实测分布复核;**序结论**(批量省炉 3 倍、组件路径优、剔除占优、等待零成本)对任意同池独立同分布鲁棒;
- 炉到货的内生成分两源归域外(R3):①买牌攒炉(A3)归投资域;②升级锅炉「烧炉产炉」内生成分归 ④ 的锅炉复合场景(未做动态规划)——⑤ 的纯期权形态辖域 = 非锅炉局的外生到达流;
- 装备可否卖金未实测(A4);若可卖,⑤ 的资产形态收窄、⑥ 分类加第三支;
- 升级锅炉与批量池复合后的最优原料调度(④ 只给通道账单与平衡式,未做动态规划);
- 特权装备/星徽是否入变换池(p42 A9 的池口径族,8 vs 7 与特权均在册)——A1 承重声明覆盖。
