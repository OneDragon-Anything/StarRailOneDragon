## Fate 角色(红A / 闪闪 / 凛)

- **试用都没主 C 能力**:想 C 至少需 **2 星 + 专属圣杯装备 + 有命(本体)**。
- ★**红 A = 无脑首选**:原坂凛(凛)这版本对红 A 提示超级大;圣杯任务会在第一位面给很多图形让你拿到红 A。**没 6 命顶级护航 → 找强力打手做任务直接无脑选能送红 A 的**。
- 凛 / 闪闪定位:平民配置下是红 A / 主 C 的**专属强力辅助 + 强力拐**(要当主 C 需一定配置)。
- ★**辅助站位**:不当主 C 时 → **凛必须站前排,闪闪必须站后排**。
  - 红A+凛联系技 = 视为红A+凛各发动一次攻击 → **凛站前台**触发红A被动最大攻击产点 + 多次叠远坂凛天赋 77% 暴伤。
  - 金闪闪前后台差距不大 → **站后台**好。
- **星级 × 站位 × 联系技**:
  - 前台星级提升 → 联系技后主 C 下次伤害变 **200%/300%/400%** → 主 C 单次大招比后台高。
  - 后台无论几星固定 200%,但后台双倍速度能出鞋 + 闪闪自加速 → 跑条叠鞋快 → 更多次联系技 → 主 C 叠更多风暴潮 + 更多大招。
  - **总结:前台数字大,后台总伤高**。
- ★**最终阵容只上各自双人组强度最高**(红A单C 或 主C单C)—— 没必要把废角色全上(另两人几乎无提升)。只有做任务时才 4 人全上。

## ★圣杯(Fate)任务系统(V4.4)

> **机制权威总结已移至 [玩法 doc · 命运圣杯任务系统](../../../gameplay/currency_war.md)(单一源)**;下方为本 comp 实玩速查(激活等级 / 高难任务 / 圣杯装备)。

任务在展开 **2F/3F/4F/5F 羁绊时各触发一次二选一接取**。难度分红(难)/蓝(易),羁绊等级越高越难 + 奖励越好(5F 有概率刷 **8 个完美投影仪 + 实现所有愿望的圣杯**)。

| 羁绊 | 任务难度 |
|---|---|
| 2F | 2 蓝 |
| 3F | 2 蓝 / 蓝+红 |
| 4F | 蓝+红 / 红+红 |
| 5F | 必红+红 |

### ★★★必须激活对应等级才算进度

3F 接的任务至少开 **3F 羁绊**才算进度,5F 至少开 **5F**。没开到对应等级 → 任务面板显示**「未激活」→ 做任务全部不算数**。**准备花资源做任务前一定确认激活状态。**

**通用建议**:即使正常打不是奔着做任务,遇见所有 F 角色**顺路买下开任务看看**(很多任务奖励直接给且丰厚,如不占装备格、效果=金垃圾袋的「罪恶王冠❓」)。没能做的任务选没诅咒的、当没这 F 就行。

### 高难度任务

- **鲜血神殿(鲜血献祭)**:后两场战斗额外损失 20 小队生命。必须**激活状态**下打完才算一场;不激活则**每节点固定扣 20 小队生命 + 致命(弄爆明刀 + 挑战失败)** → 即使断连胜也应优先处理。
- **5F 令咒协议**:凛在场 → 立刻损失 **88 小队生命 + 所有金币** → 获 8 个持续 1 节点的完美投影仪。⚠️ **没 88 血量不能接取** → 手上已有 5F 且血离 88 差不多 → 小留等血自然回 88 以上再开;且**这一关把所有投影仪用掉合 3 星 5F 出来**,别留下一关发现不见了。
- **愿望圣杯任务(最高奖励)**:像模拟宇宙阮梅事件,**无需做任务** → 立刻实现所有愿望:完成之前接的所有 F 任务 + 合成所有 3 星 F 角色(含红 A)+ 专属圣杯装备进阶版 + 1 个圣杯装备改件(属性 ≈ 3 星 5 费狼尊的密霸手套)。圣杯装备以**改件**形式装备,**一人最多 1 个圣杯改件**;与狼尊骇客组件改件冲突,**但不与姬子领航员改件冲突 → 只有姬子能最多出 5 件装备**。
- **诅咒圣杯任务(5F 最难)**:直接赠全队 **50% 暴击 + 100% 暴伤**,但清除之前所有 F 任务 → 全替换为圣杯装备诅咒任务,完成所有诅咒装备才获最终圣杯。诅咒一个比一个狠,没做完**负面效果一直存在**(无论佩戴 / 开不开 F 羁绊)。**建议**:不是奔着这任务来的就别做(难度巨大);**3-4 之后无论如何不要接(一定做不完)**;有三星 1 费角色拿去给怪力剑❓降星数,最晚 3-2 开始做才做得完。

## 圣杯装备(改件)

- **不一定要给 Fate 角色戴,其他角色也能佩戴**。
- ★**阿瓦隆 = 普通改件里强度最高**,非常值得顺手拿(给任何能量组 C 如姬子 / 大黑塔 / 阿格莱雅提升巨大)。
- 其他组件只有**进阶改变**才能发挥大作用。

## 成型阵容(红A单C)

Archer(双电锯 + 风暴潮)+ 远坂凛 + 瓦尔特(杨叔)+ 开拓者·记忆 + 4 战技点(花火 / 刻律德菈)+ 刃(2 减益)+ 缇宝 / 符玄 / 知更鸟。

## 成型节奏(4 个 5 费,成型难)

- 前期:低费过渡保血(远坂凛 2 费先找)。
- 升 8-9 找 5 费核心(Archer / 远坂凛),Archer 追 2 星。
- 命运改件由圣杯祈愿自动给,不需商店 find。

## 装备

- Archer:**双高周波电锯 + 火力风暴潮**(通用 find 装;命运改件自动给,非 find gate)。

## 弱点

- **榜样激励**词缀克(伤害第一的 75% → 克高倍率单核;MECHANIC counter)。
- 4 个 5 费成型难(form_difficulty=medium 但吃发牌)。
- 圣杯任务系统复杂,做错(未激活 / 接诅咒圣杯太晚)可直接崩盘。
