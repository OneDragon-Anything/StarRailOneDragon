# DD-015:装备拖拽失败降级——失败件局内拉黑 + 跳过继续 + 后排拖点随布局档修正

## Status
accepted

## 背景
复盘 g_20260902_181254(`.debug/temp/currency_war/replay/matches/reviews/run_20260902_181254.md`)修复项 A:
日志 18:18:53 / 18:22:20 / 18:26:30 / 18:31:32 四轮同一形态——`M7 drag 列车同行星徽 → 补救链仍败
(diff=0.0) → 停`,单件拖败中止整个装备步骤(当轮其余 8–10 件全不穿),且无跨轮记忆,每轮重试同一
失败动作(各耗 ~18s)。整局 0 件穿着、栏内积压 11–13 件。

## 根因(两层)
1. **流程层**:`EquipAll` M7 主循环拖败即 `break`,无失败记忆;补救链(bug#1 根治批)解决
   「同帧相关失败」,不解决「落点本身错误时的重复尝试」。
2. **坐标层**:`EquipAll._slot_drag_point` 后排 area 前缀硬编码「后排」(6 槽档),而占用读侧
   (M7 `_row_specs`)与部署侧均走 `select_back_layout` 档位前缀(「后排7槽/8槽」,ADR-0385)。
   布局非 6 槽时槽号→rect 错配半个槽位,拖点落邻槽——装备穿到别人身上或落空,below-icon
   CV-diff 恒 0.0 假失败。前排推导式本身与建档自洽(drag y1+21 / verify y2+14,与前排实测
   350/479 同式),screen_info 后排-1..6 建档坐标无需修。

## 决策
1. **失败拉黑**:同一(源件→目标角色)拖拽失败 ≥2 次(`DRAG_FAIL_BLACKLIST_LIMIT`)→ 该对拉黑,
   登记处 = `session.equip_drag_fail_counts`(局级持久,跨轮存活;键 = (件名, 角色名),与分配
   候选过滤面同构)。已拉黑对从 alloc 生成后立即剔除,不再重试。
2. **失败继续**:单件拖败不中止整批——登记后跳过继续穿下一件(原 `break` 废弃);失败 1 次保留
   一次补救链重试(≥2 才拉黑);真持续失败由拉黑过滤自然收敛(全部拉黑 → 停),主循环另有
   硬上限 `_EQUIP_MAX_WEAR_ITERS=20` 兜底防异常态空转。front-only 回退路径同纪律(键=(件名,''),
   与主路径键空间不交——两路径互斥)。
3. **坐标修正**:`_slot_drag_point` 后排前缀改走 `select_back_layout` 单一入口(与占用读侧同源),
   选档失败退 6 槽基线。

## Considered Options
- **仅加跨轮拉黑、保留 break**:止损 18s/轮但整批不穿依旧(8–10 件连带损失),不取。
- **失败继续但无记忆**:同失败对每轮白烧 ~18s 依旧(g_181254 实证形态),不取。
- **拉黑粒度=件×槽位**:分配候选(alloc)只携带 角色+件名,槽位拖前才解析,粒度无法在
  过滤面生效;件×角色对与 alloc 同构且角色在场槽位一轮内稳定,取。
- **拉黑粒度=件(不分角色)**:换目标角色即可自愈的偶发失败被过度拉黑,不取。

## Consequences
- 正面:单点拖拽故障最多损失该(件,角色)对,不再瘫痪整链;跨轮记忆消除重复白烧;
  布局非 6 槽时后排拖点与占用读侧对齐。
- 边界/失效:6 槽档下拖点仍败的形态(diff=0.0,前排推导自洽)未离线证实——留待实机局
  验证;拉黑按局重置(新局新 session),持续性坐标错误靠实机排障而非拉黑掩盖。
