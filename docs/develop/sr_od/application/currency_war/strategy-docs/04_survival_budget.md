# 04 生存预算统一件（12 号件塌缩）

> 塌缩来源：`strategy/12_blood_budget_semantics.md`（血预算设计件 W520）+ 01_strategy_layer §4.7 的 λ 口径重述。本篇是**生存域的唯一模型家**：血预算数学 h > d·L_c 为唯一模型；损伤锚（P1/P2 的 L_c、段全败预算）作**参数**进通用模型（宪法第 2 条——通用式不含位面/段字面量，位面/段只是伤害锚表与节点数表的查表键）；00 §5 指定的 **hp 进决策授权对账表单一源在本篇 §7**。
> 前置阅读：[00_framework.md](00_framework.md) §3（硬闸门）、[01_math_framework.md](01_math_framework.md) §6（三形态章程）。
> 术语：**血预算** = 当前 hp 与「后续全部战斗节点全败累计伤害」之间的余量；**追级泵** = 濒死段仍连发购买经验的行为；**停手线** = 血 ≤ 此线就拒绝某类未来收益型支出的阈值（只拒收益在 ≥1 战之后才兑现的支出，当轮转化支出不在辖域，[32]）。

## 1. 证据基座

1. **sim 定谳**（W516，n=200 基线 + n=100 配对）：死亡 84% 的主导机理是血预算算术——战斗类节点 5 个、全败累计 88 血【拟，sim 带中点和】、实测胜率 ~0.25【拟】下期望伤害 ~66 血，进场血中位 31、≥60 只占 15%【拟】；活局进场血均值 60.7 vs 死局 27.5【拟】。段内采购杠杆四臂配对全不显著；唯一能翻动死亡率的是校准弹性 β（form→胜率斜率）×5，而真实 β 未标定。
2. **实机第一票**（⑳+1 局判读）：大失血后进场血 33 → 死；血线 16/1 时追级泵照开（升 6/12 次）——购买有效但战略无效：每笔金换到了人口，血预算撑不到人口兑现。
3. **死因实证**（DEATH_POSTMORTEM，已删除的旧文档树复盘件，git 历史可溯）：B 类反应缺失 32% 非零——安全带（升档器 + 本篇停手线族）非死重。

**问题结构（根源两问）**：根在语义层——花钱义务由息线单一驱动、「血预算」作为约束在决策层不存在。本件修根：把血预算作为**第二约束**引入决策层（段末窗=保血目标语义，段内=停手语义）；与「花金义务」（金→战力方向，[11_shop_decisions.md](11_shop_decisions.md) §8 sink 要求）互为对偶：本件管「什么时候**不许**为未来花钱」，花金义务管「什么时候**必须**花钱」，两者共用同一条血预算算术，禁各写一套判据。

## 2. 唯一模型：血预算算术（通用式，段只作查表键）

**判据形式单一源 = P21**：升级（及一切未来收益型支出）的经济性 ⇔

- **存活到账（停手侧）**：h > d·L_c^stop（d = 收益到账延迟的战斗场次，d≥1；L_c^stop = 单败条件伤害·停手侧取值 = **CI 上缘**——线更深、更多拒付；按下一节点类型查锚表，见 §2 解析规则）。**方向边界**：定理只覆盖 h ≤ d·L_c真 恒负；上缘使线落入定理沉默带（h∈(真值,上缘]）时，拒付不是数学背书而是发展压制姿态选择，受宪法第 3 条辖，随 §7 #4 一并确认；
- **受益覆盖（收益侧）**：Δp·Σ_{b≥d} L_c^ben·S(b) > C+I。**L_c^ben 与 L_c^stop 是同一锚的两个方向取值，禁混用**：收益侧上缘会把收益抬大 → 反保守放行；故 L_c^ben = **CI 下缘**（低估收益、少放行 = 保守）。**口径声明（过渡口径 + 重锚债，对齐 P35_VALIDATION:116 挂账）**：本式含 hp→金 1:1 直换（承 P21 口径）= 价值换算形态——不在 P26 水位比较辖内，§2 表「禁价值换算」限制辖停手侧；收益侧以本过渡口径运行，重锚债 = 经 λ_death 重锚或明示永久过渡（P35 挂账通道）。

P21 已证：h ≤ d·L_c 域内存活到账恒假 → 收益恒 0、EV = −C−I 严格为负；敏感网格 (p,Δp,d,c) 全负域——**结论在 β 未标定期（p≤0.30）与 β 无关**。**裁定语境注（并陈原文，防双源）**：2026-09-01 流水原文「P21/P23 裁退役（[39]4 点名的 HP 驱动决策域，死亡床升级/死亡窗分配），不重写」；[39]④ 原文「旧证明族的 HP 驱动决策域…不再重推」——退役对象 = **决策域（命题层）**。本篇读法 = 证明本体持续有效（索引「已证」）；本篇的停手侧水位比较形态是否属已退役决策域的复活，由 §7 #4 确认通道一并裁决，本篇不作单边调和。

## 3. 段末窗保血语义（原 P1 侧，通用化）

**出口血目标线（60 的推导链）**：期望失血 E[失血] = Σ_b (1−w_b)·L̄_b ≈ (1−w)·BLOOD_BUDGET_ALLLOSE[next_seg]。要求「期望伤害不超过进场血」反解胜率门槛 w* = 1 − h/B_alllose。代入：h=31 ⇒ w*=0.65（不可达，钳制 ≤0.5）；h=44 ⇒ 0.50（零余量）；**h=60 ⇒ w*=0.32（w≥0.32 即期望活）**；h=84 ⇒ 0.045。

**结论（W524 对抗审计后修订）**：60 = **「期望预算线」**——使期望伤害不超过进场血的最低进场线，**充分方向，不是存活保证**（n=200 账本 h≥60 的 30 局死 12、分带存活率平滑爬升无崖；w=0.32 世界 MC 复算 P(存活|h=60)≈0.42——「期望活」≠「存活」）。血预算主导的根论断经攻击未破（AUC 0.906 全账本最强【拟】，血非金代理 corr −0.176【拟】）。

**与既有单发穿透防线的分层**（禁双计；按现行真载体重写）：应急线 25 = `registry.emergency_hp`（亲验，cw_registry.py）；诊断线 40 = `cw_economy.HP_QUALITY_ALARM`（运营质量报警线，判读域——口径见 [10_prep_decisions.md](10_prep_decisions.md) §4）。旧载体已退役：HANDOFF_HP_CUTS / 报警降档线（40）与「11 号件与 discipline 覆盖」均属已删旧栈（decision_v2 栈随 b94e9cfb 删除；掉血三臂已 §7 #8 退役；旧 11 号件属已删除的旧文档树，git 历史可溯）——历史语义仅作分层出处注记，不再是现行载体。出口血目标线是「战略线」——hp < 60 时哪怕逻辑态血量够不着应急带，段末窗的支出结构也要从「战力投资」降格为「减损保血」。两线不互相替代。

**语义三条**（每条 = 触发面 + 动作族复用，不新增动作族）：

- **末窗支出降格（P1-a）**：段末窗（round_num ≥ 6，末窗起点=定窗；原 registry 旋钮已随承接门家族死链删除，2026-09-04 用户裁定清理）内 hp < EXIT_BLOOD_TARGET 时，承接门的支出构成降格：高分战力件搜索让位于减损型买牌（bench 囤件变现上场、同息档羁绊档填充——原动作集锚 = 旧 11 号件 blood_protect 动作族，**该动作族已随 decision_v2 删除（b94e9cfb），重设计批另立；§7 #4 确认前不落码的口径不变**）。依据：W516 配对排除证据（板面→胜率→少掉血的间接路径被 β=0.04 钉死；减损路径是**无 β 依赖**的正账）。
- **段内血线停追级（P1-b）**：备战帧 hp ≤ ceil(d·L_c) 时拒绝升级——P21 判据的通用段内应用；段 1 停追级线（d=1，按下一节点类型查表取 CI 上缘，§2 解析规则）：battle≈12 / encounter≈15 / boss≈30。完备性条款（堵死 1 血局仍升级的角案），主杠杆在上一条。
- **锁线时点前移（P1-c）**：末窗 hp<60 且尚未锁定时，不再为挑线/换线付刷新搜索金（自然刷新便车照搭、锁定动作照做）；已锁线维持 [23] 不 pivot。依据：搜索期望收益 ∝ Δp（β 未标定）不可信、成本项确定——期望符号为负。

**显式不做**：段中前段的深亏响应仍归 W248 假设 A 辖域；血预算线只改末窗支出结构——把触发推前会与息纪律正面相撞，须单独经济账裁决。

## 4. 段内血危机停手语义（原 P2 侧，通用化）

1. **停升级线（可先行）**：备战帧 hp ≤ ceil(d·L_c^stop) 时拒绝购买经验（追级泵停转）；**段末 ALL IN 清零窗让位除外**。推导链：P21 判据（§2）+ L_c^stop 按 §2 解析规则两支取值（P1=逐节点型 CI 上缘；P2=registry 20.05 段单值临时锚豁免）+ d 取 1（最短诚实延迟；d=2 时线更深，到账更慢的升级类适用）。核对：⑳+1局血线 16 时追级泵开 6 次——16 < 21（段 2 线），新语义下全被拒（实机第一票反例样本）。cost 侧锚：濒死段升级一次跨级花费 20-84 金【注，XP 表 {3:4…9:84} 跨级求和口径】，每败失血 15-25【拟】——金换不到一场活（P21 表 EV −19.75 起【推】）。
2. **停刷新线（挂 β 门，不可先行定量）**：血危机下刷新只允许一个用途 = **保血急救**（刷出的件本战/次战上场能兑现战力或羁绊档，[31]④ 硬约束既有归类）；为未来收益的战力搜索型刷新停付——**结构语义先行**（无数值）。阈值数值：收益项 Δp×β 不可算（β 未标定）→ **明说需标定**，挂开臂判据（§5）。
3. **与花金义务的对偶（边界声明）**：血危机停手管「hp 低时不为未来花钱」，花金义务管「hp 预算尚可时必须把金换成当轮战力」——共用 §2 同一条预算算术，禁各写一套；花金义务的收益项量级依赖 β ⇒ 立项/开臂同走 §5 门；两语义实现批必须同批设计接缝，防一个加义务一个减义务的双计。

## 5. β 未标定的处理（策略开关生命周期）

**等 β 标定的臂（默认关 + 零漂移锚 + 开臂判据挂账）**：①花金义务收益项量级（开臂判据：β 点估计落定且 > 边界 0.04 有显著分离）；②停刷新线数值（同上）；③星级/战力加权类（β 标定后重跑配对 A/B）；④BETA20 型校准注入（归标定批非策略开关）。**标定路径** = 结算屏 OCR 三项逐局积累（[27] 采集点）；胜例 n≥10 后做 β 点估计（敏感性口径）。开臂前默认关 + 零漂移锚，禁悬置不验；数据齐即跑 A/B，不过的臂进定谳清理态（删码留档）。

**不依赖 β、可先行的语义**：①末窗支出降格（W516 排除结论是方向性）；②停升级线（P21 全负域覆盖 p≤0.30——β 标定前结论稳健）；③停刷新结构语义 + 当轮转化豁免；④60 线本身作判读锚（先做判读与 sim 检查项）。**重推条件（诚实边界）**：P21 全负域覆盖到 p=0.30；β 标定后若段内常态胜率 >0.30，停升级线与 w* 表须按新 w 重推（推导链不变，输入更新）——写进开臂判据的连带义务。

## 6. 与既有栈的接缝

1. **L_c 口径差核对**：registry.vd_p2_loss（20.05，收益侧）vs P21 语料 P2 全量条件败局伤害 15.39（其濒死桶死亡截断不可用）vs sim 带中点（13.5-23.5）——带内一致量级，停升级线对 L_c 线性敏感（d=1 时线=L_c）；落码以 registry 单一源，实机真值到位后复核。**注（§2 重校债同步）**：registry 的 vd_p1_loss_* 现值为作废系数、报警三臂注释直引作废式——重校前 registry 侧 P1 锚不可信，P1 消费以 §2 表 P15v2 锚为准。
2. **节点序列单帧问题**：段 2 实机序列仅 1 帧读数（战斗类节点可能 6 个）——若实为 6，全败预算上修，w* 门槛下移（更严），同式重算。
3. **信号读取（零新字段）**：血预算全部由既有 state 派生（state.hp、boss_projected_hp/handoff_hp_tier 纯函数快照、节点类型既有观测）；段预算从注册表带表派生，设计不另造数。
4. **与息线门 AND 串联**（血线不新增覆盖态）：金>g*（息线放行；g\*=saturation_line=10×cap_resolved,resolved 单一源——默认局 cap=5 即 50,息律投资局 cap=10 即 100,禁裸写 50,M6 同款口径）∧ hp≤停手线 → **血线胜，拒付**（血预算不足时花金收益通道弱到兑现不了，「息线放行」只说金侧无息损）；金<g\* ∧ 血预算充足 → 息线胜；唯一豁免 = 当轮转化支出与 [11] 同息档零损购买。
5. **优先级表**：discipline 覆盖序不动（停手门 = 授权通道前置拒付过滤，非第五种覆盖态；应急梯度给「怎么花」，停手给「不许为未来花」，作用在不同切面）；承接门不豁免停手（gap 大只说明板面缺，不说明血预算撑得到兑现）；锁线门同向不冲突；**段末 ALL IN 窗停手线全部失效让位**（位面末最后一战是损失最小的花光时机，[18]）；与 11 号件末窗保血的关系 = 触发面扩展（血预算线触发 vs 逻辑态血量触发），动作族复用不新增，禁写第二份保血判断。

## 8. 终止分支语义：止损转支出

死亡已不可避免（守钱世界存活概率上界 S0 ≤ terminal_survival_eps【拟】）的帧内，金留到死 = 零价值，停付防线让位给「当轮转化」支出：

- **判据面**：terminal_release——段内硬门 ∧ hp_decision_trusted fail-closed ∧ 非段末 ALL IN ∧ S0≤ε；S0 = Π 单发穿透场条件胜率（L_i/p_i 单一源 = 段伤害锚表 + streak_floor 族注册表）；段内触发闩（session 载体，首触发后恒释放，防 S0 邻域抖动半释放）。
- **释放范围**：搜索型刷新停付（须过当轮转化双门：bench 空槽 ∧ [deploy 空位 ∨ 存在 1★ 板面垫底件]——板满帧不进释放辖域）与末窗支出降格（终止短路）；**停升级门不豁免**（P21 数学与金零价值无关；适用边界与越界翻正点）。
- **记账面**：闩位单一址进 sim 账本位与遥测；检查器只验位与行为一致，不复算 S0（S0 公式正确性由测试仓闭式对拍单帧锁承载）。

## 9. 验证设计汇总

- **sim 配对**：同池同 seed；主指标 = 出口 hp≥60 占比、下段 hp0 率、死时携带金；段级检查项 = §3/§4 结构断言；早中期零漂移门逐 seed diff={} 每批必附。
- **诚实预期**：停手语义的成本面（金留存）立即可见，收益面（救活）在 β 弱通道下 sim 测不出显著——sim 数字不作成败判，主证据 = 结构断言 + 实机配对局（阶梯终点）。
- **实机判读锚点（事前写）**：①血 ≤ 停升级线的备战帧升级次数 = 0（⑳+1 反例复验）；②末窗 hp<60 局的 refresh/战力买笔数下降、减损买出现；③跨局段末 hp 分布右移（60 线仅作趋势观测——期望预算线非存活保证）；④下段进场血分布右移。
