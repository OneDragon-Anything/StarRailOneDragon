# ADR-0422: 版本公告轮播建档 + BackToNormalWorldPlus/入口流程补退出分支(W301)

## 背景

游戏级**版本公告轮播**(2026-08-26 版本,主题「贪饕」侵蚀)会在待机时自动弹出、整屏盖在任意画面上,非任何 app 触发。编排者 2026-08-27 live 实证结构:两页轮播——第 1 页无任何出口(只有右箭头 (1840,508) 翻页);第 2 页底部中央出「关闭」钮 (960,889),点关闭露出底下原画面。实锤后果:CW 独立 app 首跑 52s 失败(公告盖住画面,`BackToNormalWorldPlus.check_screen` 无此页分支,兜底空转耗尽)。

同型第二现场:`EnterCurrencyWar.wait_lobby` 的公告类弹窗分支(L90-94)按 **ESC** 关公告——项目新规禁键输入(前向兼容手机模拟器端),必须改为同款点击链。

## 决策

**建档(单 screen 两子态)**:两页共享稳定标题锚「贪饕」侵蚀(2026-08-26 版本新内容独有,别屏不出现),子态仅差一个 area(第 2 页独有「按钮-关闭」)——按 od-dev-screen-onboarding §3 归属判据,拆双屏无区分收益,建单 screen `version_announcement_carousel`(版本公告轮播):

- `标识-贪饕侵蚀`(id_mark,pc_rect 830,185-1090,270):两页共享,OCR conf 0.99+;
- `按钮-关闭`(pc_rect 810,855-1110,925):仅第 2 页可见,兼作子态判别 area;
- `按钮-下一页`(pc_rect 1780,445-1895,570):右箭头纯图形无文字,no_method 纯定位区,`round_by_click_area` 直接点中心。

fixture 两页各一张(测试仓 `screens/版本公告轮播/贪饕侵蚀-第1页/第2页.webp`,2026-08-27 实拍);画面 doc + 玩法 doc(`docs/game/gameplay/version_announcement.md`,游戏级公告知识)。

**退出分支**:`check_screen` 在无名勋礼分支后、对话守卫前补一支(W286/W293 同构):标题 id_mark 命中即正面识别 → 以「按钮-关闭」可见与否区分子态(可见→find_and_click 关闭;缺席→click 右箭头翻页)→ `round_retry` 逐帧重识别(点击可能不落地,RETRY 计入 `node_max_retry_times=20` 有界 FAIL,拒 WAIT 永动——W0824/W286/W293 同判例;第 2 页点掉后逐帧重识别露出原画面,由既有分支接管,无跨轮状态)。项目规则:零 ESC 键输入。

**入口流程**:删 `EnterCurrencyWar.wait_lobby` 的 ESC 公告分支(赛季扩充/新内容解禁 OCR 词,2026-08-26 版本已过期为死条件),替换为同款点击链(识别公告屏 → 翻页/关闭 → retry);「点击空白处关闭」类弹窗分支(新内容解禁所属类)不动。

## Considered Options

1. **采纳:单 screen 两子态 + 关闭可见性分支**(本批)——标题锚两页共享稳定,子态仅差一个 area;与 W286/W293 已验证结构同构,维护面一致。
2. 拒:两页拆双独立 screen——id_mark 相同(同标题)拆开无区分收益,反增维护面;子态区分本来就要靠「关闭」area 可见性。
3. 拒:公告分支用「关闭」area 直接判定(无标题 id_mark)——「关闭」二字常见于各屏,脱离标题锚的裸判定有误吸风险;标题独有长文本正面识别后才进入子态判别。
4. 拒:入口流程保留 ESC——项目新规禁键输入;且旧 OCR 词(赛季扩充等)为 V4.4 时代死条件,2026-08-26 版本公告已换贪饕主题,保留即双重过期。
5. 拒:分支放对话守卫之后——公告为全屏遮罩,底下画面的文字可能被守卫误判(.run 46 同型教训),画面专属分支必须在守卫之前正面接管。

## Consequences

- 版本公告弹出后不再卡一条龙:`BackToNormalWorldPlus` 与 CW 入口流程均能消化(翻页→关闭→逐帧重识别回原画面链)。
- 版本更替后标题锚失配:新版本首跑前需按新公告 fixture 补 id_mark(旧锚清理);已知时效性记入画面 doc。
- 测试锁 2 条(真帧输入:页 1 走翻页分支 + 页 2 走关闭分支,识别走 session 真模型,只记录点击层)。

## 判据与验证

- 判据:编排者 2026-08-27 live 退出链实证(fixture `.debug/sr_od_mcp/screenshot/screenshot_20260827_193514_509992.png` 页1 / `..._194020_524477.png` 页2);CW 首跑 52s 失败实录为无分支后果。
- 验证:ruff(主仓 op×2 + 测试仓测试文件)过;id_mark 全集 `test_id_mark.py` 129 passed / 81 skipped(新 fixture 2 张自动收录,真阳性 + 无碰撞);直测 `test_back_to_normal_world_plus.py` 12/12(新锁 2:页 1 真帧翻页分支 + 页 2 真帧关闭分支);L1 `cw_quick` 全集 0 failed。实机验证不需要(退出链已 live 走通)。
