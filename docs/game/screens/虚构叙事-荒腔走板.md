# 虚构叙事-荒腔走板(treasures_light_pf_cacophony)

虚构叙事编队屏**增益装配弹窗**(游戏内系统名「荒腔走板」):行右端圆形加号
(编入角色后出现)点击弹出,per 行(节点)从三个增益效果(本期:触技/笑韵/赋格,
名称随期轮换)中选一个装配。与末日幻影的终焉公理弹窗同构(三卡+装备中角标+
装配效果按钮),但 id_mark 文本不同(「荒腔走板」/「装配进荒腔走板」),独立建档。

⚠️ 虚构叙事的增益是**双层系统**,本屏只是其中一层:
① 左栏「战意效果」列表——编队屏内直接点选(无弹窗),全局单选(两节点共用),
   金色名称条 = 当前装配;建在「虚构叙事-编队」档(`战意效果-槽1/槽2`);
② 本屏「荒腔走板」——per 行三选一,行右端加号弹窗。

## 何时出现 + 状态流转

| 态 | 入口 | 出口 |
|---|---|---|
| 弹窗(节点 1/2 通用,左栏显示当前行队伍) | 虚构叙事-编队 行右端加号(`行1/行2-装配加号`) | 点「装配效果」→ 装配生效,**弹窗自动关闭**回编队屏(实机验证);右上关闭 X → 回编队屏不装配 |

## 识别特征(稳定锚点)

- **标题-荒腔走板行**(左上):id_mark。
- **文本-选择增益行**(「选择增益效果装配进荒腔走板」):id_mark。
- 三张增益效果卡纵向排布(位置固定,名称随期轮换);当前装备卡的右上角有
  黄色「装备中」角标(实测 (1779,179),随装备卡浮动)。

## 可交互元素

| 元素 | 行为 |
|---|---|
| 卡片-增益1/2/3 | 点击选中该增益;名称随期轮换,按位置选择 |
| 按钮-装配效果(右下,实测 (1642,968)) | 装配当前选中增益 → 弹窗自动关闭回编队屏 |
| 右上关闭 X | 关闭弹窗回编队屏,不改变装配 |
