## 1. 问题与动机

### 1.1 现状症状

### 1.2 根因归层(表示/约定/流程/语义)

**语义层**。G-S1 守卫的判据是纯结构谓词(全场同名同 1★ 计数 ≥2 即拒卖),其隐含语义假设 =「该对是**有购买意图的** 2/3 合成进度」(ADR-0558 案发形态:线内素材对差一张成 2★,被燃料通道卖断升级路径)。对**义务重买集之外**的名字,该假设恒真而无载体——义务通道(M2/m2_merge_completion)按构造不买重买集之外的名字(重买集单一源 = `sell_gate._resolve_base` 输出,锁线态 = `locked_buy_membership` 截断集 B′),第三张没有系统性买家;守卫退化为对无意图对的**不可证伪的永久保护**,保护收益(2★ 期权)与保护代价(席位占用)的辖域错配。这是判据语义与决策语义的错位,不是流程或表示缺陷——修法 = 给守卫补上「意图载体存在性」的语义边界(方向③),并评估另一类静态保护(方向④)是否同病。

### 1.3 解决到哪 / 明确不解决什么

- **解决**:①方向③ = 素材对的退出通道(意图载体死后的降级燃料资格),数学重推过 P41 类资格语义;②方向④ = TRANSITION_PACK 静态持有保护在配方锁帧的辖域评估,给维持/收窄裁决及论证。

### 2.1 方向③:G-S1 死库存退出通道(数学重推 + 判据规格)

#### 2.1.1 被保护对象与保护语义重推(G-S1 在 P41 框架中的位置)

G-S1 保护的**不是件,是状态**:「距 2★ 差一张」的合成进度。用 P41 卖出主不等式(`sell ⇔ refund + V_slot > max(V_opt, V_ms·ΔP̂) + V_power`,p41 ②)对照:

- 素材对成员 x 单卖一张的后果 = 对状态 C(同名同 1★ 计数)2→1。卖出金账净 0(1★ 全额退,`cw_state.sell_refund`;卖回还池,A8/economy §1),但「差一张」退化为「差两张」——重建该对需再买 2 张而非 1 张。
- 故被毁期权的定价 = **在需要 2★ 的假想时点,1 张定向再获取成本与 2 张之差** ≈ 一张的 P_miss 加权补救账 = `u(要这张的非重买集 2★) × P_miss(H) × C_rescue(x)`——恰为 P41 ①对 x 的 V_opt 形态。**守卫在 P41 框架中的语义 = 给素材对成员记一笔 V_opt(第三张)> 0 的 fail-closed 持有**,与「③④ 件 V_power>0 故非燃料类」(P78-4)是**两条不同的保护**:前者保护合成进度期权(G-S1/ADR-0558),后者保护身份资产(装配 A 身份段)。本方向③只动前者,后者原样(P41 类资格边界不被撕开的论证见 2.1.3 末)。

#### 2.1.2 期权何时有值:行使通道清单(结构事实,逐条带出处)

「2/3 进度」要变成价值,必须存在**会买第三张的通道**。全通道盘点:

| 通道 | 辖域 | 对退出目标类的可用性 |
|---|---|---|
| 义务合成完备购 `m2_merge_completion`(免席门) | 只服务买面重买集 base(`_resolve_base` 输出;11_shop_decisions §「2★ 决策现行覆盖」①) | **按构造为空**:退出目标类 = name∉base(判据 (b) 同基准,§2.1.5) |
| 非定向臂 C=2→3 补买(买侧防线显式放行的「消对修复动作」,`dead_stock_pair` 判据 C=2 分支) | dominance 需 bench_free>1 且金>饱和线(`dominance_buy_eligible` 本体,ADR-0616 命题 4 收紧口径) | **在守卫咬合的帧恒不可行使**:死锁帧 bench 满 → 门闭。金宽+席宽帧可行,但那不是本通道保护的场景(席不缺,守卫无代价) |
| 买 3 合 2★ 后卖 2★ 的清算链 | 游戏满栏合成例外允许买(merge_mechanics §2.5),但 bot 无任何清算卖臂(`merge_buy_k` 消费点 = 候选/arbiter 满栏购买门与买入意图记录) | 机会成本上界 = P(窗内第三张到店)×(2c−1) ≤ 数金级(1-2费),忽略并申报 |

结论:对「name∉重买集」的素材对,期权的**系统性买家用集合为空**;唯一残余行使路径(非定向臂富余帧顺手消对)的价值主体是「顺带释放 2 席 + 小额清算金」,不是「想要该 2★」。守卫的 fail-closed 假设(意图存在)在这类上没有载体。

#### 2.1.3 帧级支配论证(退出通道的合法性主证)

设死锁帧 f:bench 满(∃ 被阻断的 M2 义务买入,其 EV>0——义务动作正 EV 由骨架层权限模型给定,02_mandate_layer §2/§3 M2;V_slot 定义即取被阻断动作 EV,P41 ③)。x = 素材对的 bench 侧成员,过 2.1.4 全部辖域合取。比较:

- **持(A)**:x 占 1 席,义务买入继续被阻;对内期权在帧 f **结构性不可行使**(2.1.2 表:义务通道排除、非定向臂门闭、清算链无臂)——帧内持有收益 = 0,帧内持有成本 = V_slot(f) > 0。
- **卖(B)**:释放 1 席(义务买入获兑付通道);金净 0;留场单张 C=1 **无守卫**(G-S1 辖「计数−1≥1」)且被买侧防线封死重建对的路(C:1→2 拒,`dead_stock_pair`)——见 2.1.6 单调性。

**帧内:B 弱支配 A**(A 收益 0 成本 >0,B 释放被阻义务的兑付通道)。这是 P41 燃料支配条款在「资格谓词修正后」的直接重放:该成员的燃料类资格三条件(1★ ∧ 零重叠 ∧ 边际≈0)中,前两条帧内可验,第三条在 2.1.2 结论下成立(非重买集名无买家的 2★ 期权对板面作战与 bench 后台效果两维的边际贡献均为 0——fuel_sell_candidates 的 R17-2 扩维口径,mandate.py docstring)。**P41 类资格边界不被撕开**:③④ 件、义务基座件、种子窗内件、囤腿登记件在 2.1.4 谓词的合取结构与下游装配 A 身份段双重排除下**不进入实际卖出集合**——退出通道只对「P41 类资格本已成立、仅被进度期权账压住」的类恢复判定,不触碰 P78-4 圈定的身份保护面。跨帧残余风险(期权在**未来帧**行使的 regret)见 2.1.7 边界申报。

#### 2.1.4 N 的推导(意图载体寿命;值推导零新常量)

退出判据的时域条件 =「跨 N 轮无第三张意图」。**「意图」在本系统中的可操作定义 = 存在会买第三张的登记载体**。载体闭集及其寿命(载体排除面全部为在册单一源):

| 载体 | 寿命 | 出处 |
|---|---|---|
| 义务面成员资格(base/B′) | 与线账同寿 | `_resolve_base`/`locked_buy_membership`;本方向辖域外(退出目标类先排除) |
| 囤腿/枢纽持有登记(乙臂 hub_acquired、line_hoard 腿) | 账闭合事件前恒活 | P86 乙臂持有语义三面承载;装配 A 身份段承载 |
| 当轮买入窗(fresh/press) | 同轮(τ=登记轮==当前轮;P78-3 锁线定型非账闭合事件,压库·垫保类轮界过期) | sell_gate 统一装配 A 窗口段 |
| **种子年龄窗** | **获取轮 ≤ r ≤ 获取轮+2,即至多 3 轮**(`SEED_WINDOW_ROUNDS=2`) | sell_gate `seed_exclusions`,全通道硬禁 |

前两类被辖域排除(不在退出目标类内);后两类是瞬态窗。**N := 3 = 载体闭集的最大寿命(种子窗在册窗长),自「较晚成员的持久获取账登记轮」起计**——素材对只在第二张到手那刻才成为「对」,意图假设的钟从那里起走。两侧边界条件锁定唯一性:**N<3 会卖掉种子窗仍开的对**(撕 P78-7 保护面,禁);**N>3 保护一个无任何载体的意图**(不可证伪的过度保护 = 病灶本体,禁)。故 N=3 是与两侧边界一致的唯一值,推导得出、非拍定。

诚实申报(最弱环,两条):

1. **结构类比与起点重基**:种子窗的原始标定对象是「种子相邻轮回卖封口」,本设计**沿用其窗长**(获取轮 ≤ r ≤ 获取轮+2)为「新购意图的最长在册寿命」,**时钟起点另立**为「较晚成员的获取账登记轮」(非种子簿原义的种子获取轮——种子按定义只记首张,给不出 max(两获取轮))。窗长沿用 + 起点重基在命题单篇显式声明,防登记时被指偷换起点。落地后由遥测对账(`dead_pair_exit_guard_kept` 的 kept_age 子键:窗内被保留对后续是否真的等来合成/转 base)回检;若回检出「过早退出后被义务通道重买的对」,按 P76 甲该 regret 是金中性的、代价只是再遇等待,重推备选形式见 2.1.8。
2. **获取轮可观测性**:获取轮读源 = §2.0 持久获取账(唯一新增登记面;发射登记簿因四出口易失不可作读源——press 对在 R2 首个窗口读即被轮界销、孤儿对在换线帧被闭合销、单腿上板对被部署销,任何 N≥3 评估帧都会扑空,判据按旧读源实现为 no-op)。账的覆盖边界与保守后果见 2.1.7-3。

#### 2.1.5 判据规格(实现者无需再设计)

**释放集谓词**(帧级,纯函数):

```
dead_pair_exit_release(session, base, bench, deployed, current_round) → frozenset[str]
  name 入集 ⟺ 全部合取:
  (a) 素材对在位:same_star_count(name, 1, bench, deployed) ≥ 2   [计数单一源 = kernel same_star_count,G-S1 同源]
  (b) name ∉ base                                                [重买集 = _resolve_base 输出,§2.0 定义;与装配 A 身份段第 1 构件/买面 exclude_names 注入物同基准,同键族防双源]
  (c) 对的两成员在持久获取账均有登记 ∧ 账位面 == 当前位面 ∧
      current_round − max(两登记轮) ≥ 3                          [读源 = §2.0 持久获取账;任一成员缺登记或位面失配 → 不入集(fail-closed 保守向)]
```

(b) 用 base 而非 k_members 的理由:重买集真值 = base(锁线态 B′ ⊋ k_members,mandate.py fuel docstring 明文)。若用窄口径,B′∖k_members 上的素材对会被释放而义务通道仍会重买它——「买家空集」论证(2.1.2 行 1)在该名集上不成立,且凑息/支付变现卖出 → M2 重买 → C:1→2 重建对 → 再等 N → 再释放,构成 P60 型换手循环。base 基准下判据与「买家空集」同构;P1 配方锁帧(base 解析 None → base=k_members)行为不变。

**持久获取账规格**:载体 = session 属性(duck-typed 属性契约,与种子簿同纪律,改名 = 静默断供给);写端 = `shop._emit_buy` 发射位,全因类无条件写(A4 硬闸 `launch_cause_of` None 抛错已保证一切臂经发射位;与 `register_seed_acquisition` 同位先例),同名重获取覆盖为最新轮;闭合 = 位面闭合(账位面 ≠ 当前位面即销)+ 活性闭合(名不在 bench∪deployed 全场域即销——卖出/部署/合成的件离场机械判;域取全场域因单腿上板的对仍有一腿在场,账须活)。轮算术 = 位面本地轮号,账内条目恒同位面(跨位面条目被位面闭合清除)。空名/位面缺读拒登记(fail-closed,与种子簿同纪律)。

#### 2.1.6 与买侧死库存防线的关系声明(防线上游 vs 退出下游)

- **分工**:买侧防线(`dead_stock_pair_buy_reject_reason`)辖**买入侧**,拒「将新生对」的买入(C:1→2),切断死库存的**来源**;本方向辖**卖出侧**,给**既成对**(换线/配方重派生导致的 base 退出孤儿对、赠得成对)开**出口**。两案正交不互斥(防线谓词 docstring 在册申报「正交不互斥」;构造性论证以代码路径为准,docstring 仅线索)。
- **合取后的结构不变量(购买通道合取下的单调性)**:非重买集名 x 的全场同名同 1★ 计数 C(x) 在**购买通道合取**下单调不增——0→1 可(单张零锁席)、1→2 拒(买侧防线)、2→3 即合成净消对(放行禁误伤)、**2→1 由本方向释放卖出引入(唯一的降向迁移)**。合取效果 = 购买通道下非重买集死库存被压入吸收类 C∈{0,1}:对不再新生、既成对确定性排干、排干后的单张不再回 pair。**例外如实申报**:赠得路径(补给/投资卡发放)不经购买通道判据,理论上可注入 1→2——频率低(事件条件流,P14 口径),残余归 2.1.7-3。**无换手循环**:P60 型「M4 卖 1 买 1 伪装进展」的三要素(卖出对象 ∈ 买面重买集 / 义务重买 / drought 重置)在此不成立——释放名 ∉ base(重买集不重买),且买侧防线封死非定向臂回 pair;P60 修法「燃料排除 buy_members」与本设计同参照系无冲突。
- **落地顺序与批序**:买侧防线谓词本体已入库;其 shop.py 消费位接线(账本任务在飞中)为本方向落地批的**文件冲突前置**(landing §3.2 依赖申报)。本方向资格谓词层与接线互不触碰、可并行实现;A/B 批序在接线之后。A/B 观测面申报(strategy-work §4 sim 可观测性声明):本批改资格谓词层 + 新增获取账写端,sim 可见可 A/B;**效应量预期与有效总体**——买侧防线(含接线)落地后,press/dominance 新生对断源,前瞻 sim 不存在「存量对」;有效总体 = **base 退出孤儿对**(配方换型/换线场景,s77013 型换型局为已知高产出载体)+ **赠得对**(低频)。预期释放频次显著低于病灶局量级;A/B 角色 = 落地后确认(实现 bug/量级意外),合法性来源 = 2.1.3 支配论证(strategy-work §3 档 1:数学可证 → 直接落码无开关)。若批内有效总体稀薄致 `dead_pair_exit_released`≈0,判读 = 总体稀薄非设计失效;设计价值案例 = 行为锁①-⑤ + 孤儿/赠得对兑现。

#### 2.1.7 边界与残余风险(诚实申报;fail-closed 方向逐条给明)

1. **配方重派生回 base 风险**:P1 配方对逐帧重派生(12_line_and_intention §4),今天的非 base 对可能是明天的义务素材。退出卖掉后若派生翻向,义务通道按同价重买(P76 甲净 0 金),代价 = 再遇等待(1-2费 ≈ 9-22 轮带;锚点 = P41 ① 表 1费@L5=9.3 / 2费@L7=10.4 / 1费@L7=21.5,`expected_refreshes` 单一源)。**该风险类不是新造的**:燃料资格集里的单张今天就承担同一风险(单张燃料件被卖后翻 base 重买),本方向只是把「对」并入该既有风险类。缓解 = 判据 (b) 逐帧现读 base,当前帧重买集不要的名字才出集。
2. **3★ 链式合成状态**:非 base 名存在「bench 1★ 对 + 场上同 2★」的链上状态时(merge_mechanics §2 连锁合成),退出会拆掉 3★ 链的 1★ 腿。该状态对退出目标类(非 base ∧ 非③④)可达性低(2★ 非 base 件本无可保护面——系统现状对非 base 2★ 无任何守卫,refund 3c−1 可卖),释放评估时现读场上同名 2★,命中则保留入 `kept_chain`(一次注册表读,随批并入,保守向)。
3. **无账写入路径与跨位面携带**:获取账写端 = 发射位;不经发射位的路径(补给/投资卡赠得)无登记 → 判据 (c) fail-closed 不出集 → 这类对继续锁席;跨位面携带对在位面切换帧被位面闭合清账 → 同样永保。两者都是**保守向后果**(过度保护非漏保护),频率低(发放为事件条件流;跨位面非 base 对在买侧防线落地后趋零),如实申报;若遥测显示该类锁席成规模,后续批给发放路径补获取账写点,本批不做。
4. **四通道全量放行的对价声明**:释放是资格级旁路,凑息/支付变现通道消费释放成员时各自的对价豁免条款(P78-5/5′ 两腿)照常辖——凑息卖掉意图已死的近零值资产正是燃料类语义,无新增豁免需求;P78-4(③④ 禁卖 = 类资格本义)不触碰(2.1.3 末段)。
5. **ADR-0558 原案回归**:原案发形态(2/3 进度素材被燃料资格卖断)若其成员为新购(新购 → 当轮窗/种子窗在册),判据 (c) 的 N=3 与窗口合取保持拒卖;行为锁④把该回归形态钉死。

#### 2.1.8 关键取舍(备选与为何放弃)

- **备选一:N 由供给统计推导(≥ 1/P_shop ≈ 9-21 轮)**——「等一个期望再遇窗再判死」。放弃为主案的理由:它把「第三张到店」(供给)与「有人买」(意图)混为一谈;对无买家类,供给到达也不行使(2.1.2),按供给窗等只是把 2.1.3 的帧级支配收益推迟 6-18 轮 × V_slot,而其换来的期权增量(窗内到店且富余帧顺手消对的清算金 ≤ 数金)量级不符。保留为回检备选:若 2.1.4 遥测回检证伪 N=3(过早退出率显著),供给窗形式是下一候选——两条推导都在案,防「回检失败临时拍新值」。
- **备选二:只在 M4 腾席帧放行(帧辖域收窄而非资格级旁路)**——放弃理由:四通道共享资格谓词是装配单一源既有结构(11_shop_decisions §仲裁单一源),按通道复制 G-S1 旁路 = 判据本体裂第二源;通道各自的触发条件(M4 席满 / 凑息缺口 / 换线塌缩)本身就是「V_slot>0 型」语境,资格级放行不会产生无触发卖出(P41 支配仅在 V_slot>0 帧咬合)。
- **备选三:改 G-S1 本体语义(把意图判据并入 merge_material_reject_reason)**——放弃理由:G-S1 是 kernel 与部署侧同名同键的共享守卫(部署面 `swap_sell_exclusion_reason` 同键),本体语义是「进度保护」不含决策语境;意图载体是 session 级状态(获取账/窗口),注入 kernel 判据会破坏 kernel 输入纯度。旁路形态保住「守卫判据纯结构、决策语境在策略层」的分层。
- **备选四:获取轮读源沿用发射登记簿**——放弃(对抗阻断项):登记簿为易失账,窗口类轮界销/义务类换线闭合销/部署销/合成销四出口把目标总体轮戳在评估前销尽,判据按该读源实现为 no-op(病灶对阿格莱雅×2 = press 类,R2 即销账,永不满足 N≥3)。修法 = 新建持久获取账(§2.0/§2.1.5),与登记簿生命周期解耦(行为锁⑤)。

### 2.2 方向④:TRANSITION_PACK 持有保护辖域评估(数学重推 + 裁决)

#### 2.2.1 现状保护结构与其本义

- 本义(P78-4 + ADR-0580 Z1 修法):③④ 件 V_power>0(④ 件 = 候选终局线自身的结构件,12_line_and_intention §2「④ 转线前瞻放行臂」边界行),非燃料类,禁卖 = P41 类资格本义。静态全集排除的「取窄形态」是 ADR-0580 攻击点①(name 型零重叠语义下排除集过大会掏空全部 1★ 燃料资格)的收敛产物(cw_card_identity docstring)。

#### 2.2.2 收益-成本重推(缇宝型帧:配方已锁 ∧ ④ 件线外 ∧ bench 满)

保护收益 B(x) 的通道分解(④ 件 x = 缇宝,锁线 = 仙舟+持续伤害,x 的服务对象 = 量子框架→希儿系,与锁线零交集):

1. **部署服务**:备战件不参战不减节点税、战力产出恒 0(P79-2 收益侧①);死锁帧板满无空槽,P24 补部署通道同闭。**死锁帧内部署收益 = 0**。
2. **转线对冲服务(期权主体)**:行使唯一通道 = 换线机器(P16 滞回 + P84 可达性门)。**现行封印结构事实**:θ/U_X/V_ms【拟】槽位 None 期 fail-closed 封印,「标定齐前换线事件恒 0」(12_line_and_intention §3 as-built 实证注)。期权现值 = P(换线到 x 的体系) × 对冲价值 = **0(封印期,结构性)**;解封后受 P84 门辖(E(alt) ≤ R_rem)。
3. **再获取溢价(卖出的真实期权代价)**:x 卖出后再需要时按同价重买(1★ 净 0 金,P76 甲),代价 = 再遇搜索。缇宝 2费:C_rescue(2费@L7) ≈ 20.8 金(p41 二维表)——**量级中等,非 4-5 费 carry 的 31-51 金带**,但非零。

保护成本 C(x):死锁帧逐帧 V_slot = 被阻义务净 EV > 0(P88 调和引理的占位成本形态:滞留期各帧边际 V_slot 之和 ≥ 被阻线内义务净 EV)。诊断报告病灶局实证:缇宝占席 9 轮,form 缺口同期无兑付。

**判定**:B 的两个活通道在死锁帧同时为 0(板满闭部署、封印闭转线),唯一非零项是跨帧再获取溢价;C 帧帧兑现。**死锁帧内 C > B 成立**——但这不足以直接推翻静态保护,因为:(i) 溢价与对冲价值都不可定价(转线价值随解封未知;义务 EV 的 Δλ_death 侧未标定,P25 族卡点),两侧都不满足「显式模型+区间+方向不变」的合法判据形态(strategy-work §1 第 2 类);(ii) 卖出对身份资产是**不可逆方向**的动作语义(02_mandate_layer §5:分类不确定 → 不卖),fail-closed 默认在持有侧。

#### 2.2.3 裁决:**维持现状**(静态持有保护不收窄),附条件化后续门

三理由(逐条带依据):

1. **代价侧已有替代兑付(时序依赖如实申报)**:病灶局的可通行 victim 由方向③(素材对,4 席)供给,缇宝的 1 席非必需——方向③落地且修好获取账读源后,死锁帧燃料候选集非空,④ 件持有的席位外部性不再咬合(它只在「全部其余资格面皆空」的帧才成为约束集)。反事实:s77091 R6w1 忘归人拒买帧,仅释放阿格莱雅对即有 victim。反向组合(④ 收窄而③未落地)不构成充分修复——1 席救不了 4 席缺口,故「不收窄」的裁决对③落地失败的情形依然成立。
2. **收益侧是暂时封印而非永久为零**:转线期权随 P16/P84 解封复活(在册工作线),解封后 ④ 持有恰是「P2 无统一桥、按线终局羁绊低档过渡」(stage_transitions Q3)对冲策略的载体现货。此时点收窄 = 在期权复活前夜清仓对冲库存,再获取溢价与时机成本双输。维持现状把裁决权留给解封批,不在信息最少的时点锁死决策。
3. **购买入口关闭,赠得入口低频存在**:④ 买入臂时间辖域 = 未定型期(`committed_from`,12 §2 ④ 边界行),锁线后停购;P88 收窄断绝 D 帧非定向补库;买侧防线断 pair 化。④ 线外持有存量的**购买**进入通道全部关闭(赠得路径低频存在,P14 事件条件流),存量只减不增(部署/换线闭合/合成是既有出口),「单向积累占席」的恶化路径不存在。

**条件化后续门(登记,不立项;触发谓词钉死)**:同时满足——

- ① P16/P84 解封已落地(代码态事实)且换线事件计数非恒零(遥测读数);
- ② 遥测(下表)显示约束帧非零。两键触发谓词:
  - `transition_hold_locked_frame`:**配方锁帧** := P1 配方对物化帧(`pair_target_comp` 非空,cw_intention 单一源——配方锁局无 locked_comp,伪 comp 物化路径即锁帧形态),键值 = 该帧 bench 上 ④ 件名数;
  - `deadlock_only_transition_victim`:**死锁帧** := M2 缺员买入评估帧 ∧ `m2_retry_exhausted` 段内增量 > 0(轮级差分);键值 = 该帧**唯一可动 victim 反事实**判定(释放集并入候选后燃料资格面仍空 ∧ bench 存在 ④ 件;帧内纯读现算,零行为面)。

届时收窄设计(配方锁帧 ∧ 席位获取需求 ∧ 与锁线零转线交集 ∧ P84 门判不可达的四合取)才是良构问题,走独立设计批。

#### 2.2.4 与 ADR-0580 攻击点①张力的消解声明

攻击点①防的是「排除集过大掏空燃料资格」;方向④的收窄方向 = **缩小排除集**(把部分 ④ 件还给燃料池),与攻击点①同向而非相抵——诊断报告所称「张力」实为与 **P78-4**(③④ 禁卖 = 类资格本义)的张力。本裁决维持现状,该张力不发生;若后续门触发走收窄批,其论证义务 = 对 P78-4 的类先验做帧级修正(「类先验在该帧的前提——活期权——已灭」),举证责任在收窄批,本设计只预留接口(遥测子键 `kept_identity` 已在方向③ telemetry 中为 ④ 对保 Volume 观察位)。
