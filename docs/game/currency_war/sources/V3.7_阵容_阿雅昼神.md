## 机制(★为什么阿雅在 CW 变强)

阿格莱雅在 CW 几乎没新技能(普攻视为终结技伤害 + 天赋少量增伤),加强很少。**变强的根因 = CW 的「速度增幅」词条与原面板速度独立乘算**:

- 大世界 / 深渊 / 模拟宇宙:速度词条**加算**,被超高速阿雅过量稀释(同样速度词条对其他主 C +10%,对阿雅只 +3%)。
- **货币战争:速度增幅独立乘算** —— 15% 速度增幅对 100 速角色 = +15 速,对 **400 速阿雅 = +60 速**。

→ 全游最快 + 最多回合的阿雅,带**反重力皮靴(羊刀)**收益夸张。

## 羊刀(反重力皮靴)+ 光速螺旋桨 = 三乘区闭环

- **羊刀**:被动每回合开始**速度增幅额外 +15%、无限叠加**。阿雅一回合靠自身跑条轻松叠 10 层 += **600+ 速度**(≈多穿 30 只速度鞋)。
- **★速度征服进面板**:速度征服乘算后高达 **1000 速度直接进角色面板** → 全吃阿雅自拐(攻击力基于速度)。
- **光速螺旋桨**(进阶装备):我方目标每 ❓ 速度获 2% 前台强度 → 对 1000 速阿雅 = **+200% 前台强度**(≈3 把 60% 前台强度的碎心斩刀❓)。
- 闭环:**羊刀↑ → 速度↑ → 羊刀叠更快 → 速度转攻击力 / 转前台强度** = 三乘区不断吃到的究极主 C。
- **★光速螺旋桨免费**:激活**白昼 3 昼神**(前期拿阿雅 + 2 费缇宝 / 风景❓)→ 直接获白昼专属装备光速螺旋桨 → 前期天生比其他主 C **多 1 件装备**。

## 成型极早 + 重开不掉分(★上分逻辑)

- 全员 1/2 费超低造价 → 阿雅**超大前期**(刚出 2 个奖励关的 **1-3**)就能组 **3 能量 + 3 昼神**杀穿 1/2 位面的「超级银河战舰」。
- **货币战争重开不掉分** → 阿雅成型极早、时间沉没成本低;倒霉开不出 3 昼神 3 能量 / 拿不到光速螺旋桨 → **直接下一把**(比 boss 关刷不出 5 费坠机输分强)。
- 前期极高强度 → 吃满连胜报酬 + 利息 → **大量升人口** → 人口是阿雅中后期发力底牌。

## ★藿藿 = 最弱生存位 + 最强充能拐(滚雪球核心)

藿藿天赋:我方释放终结技 → 给藿藿充能;满能 → 给我方全体终结技**百分比充能**。
- 人口越多 → 释放终结技频率越高 → 藿藿充能越快 → 藿藿大招越多 → 充能更多终结技 → **无限「左脚踩右脚」循环**。
- 前期战力优势 → 经济 → 人口 → 藿藿 → 战力,**全流程滚雪球**。第二三位面怪物血量膨胀,发育正常的阿雅都能 **3S 碾压**完整对局。

## 上限(阿雅「使出全力」的舞台)

理论上两回合羊刀可叠 50 层+,但**最高难度 A8-20 怪也扛不住阿雅伤害**(羊刀大部分只叠 10 层就结束,大数字连 10 位都没)。UP 选择去打 **A8-20 三人彩遭遇骑士精英怪**(比普通 A8-3 高 48 个难题等级;尾王有放水机制但遭遇关不放水 = 真正公平决斗)让阿雅使出全力。

## 历史 exploit:光盾流(V3.8,几乎肯定已修)

> 源:BV13t26BJE6U《最逆天 BUG!一件装备做出来直接判赢》(2025-12-08 · V3.8)转录。⚠️ UP 明言「百分之一万就是这两天修」,现已是 V4.4 → **几乎肯定已热修**,仅作历史记录(其中「光能盾牌免疫推条」是真实装备机制,独立于 bug 仍成立)。

- **光能盾牌**:前台角色身上有护盾 → **免疫推条效果**(真实装备机制)。
- **阿雅「先拉条后推条」代码 bug**:配合光能盾牌,推条部分被免疫、只让拉条生效 → 每次行动拉条 96%(一降 48%)。拉条与速度一个是除数一个是被除数、**不互相稀释** → 相当于速度持久翻倍(单鞋当双鞋、双鞋当四鞋、双特写鞋当八字鞋)。
- **成装**:前期三能量直接不要 → 开「二护盾击败」(护盾无限时长 + 无限叠加)→ 开局把「正当防卫同步行动」刷掉 → 局内只做 **反动力皮鞋 + 光能护盾** 两件,**螺旋桨**装阿雅。
- 一次解决阿雅的启动 / 生存 / 后期输出上限 / 低费经济 全部痛点;~11 块阵容可一路赢到遭遇骑士关,二星试用阿雅也能一脚踢死 A820 遭遇骑士。
