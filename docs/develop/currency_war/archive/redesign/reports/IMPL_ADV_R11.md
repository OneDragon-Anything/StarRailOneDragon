## P1(实质)stop_flag 在生效帧骨架 pass 的取值:谓词语义与 R9-2「保持旧值」互斥

**位置**:IMPL_FIX_LEMMAS R9-2 引理「R8-7 收益保持核查」段(「生效帧骨架 pass 先于 EV pass 评估,同帧内旧值仍在骨架 pass 生效」);IMPL_DESIGN §2.7 stop_buy 行 R10-5 钉死条款①(「登记帧→生效帧评估返回前 K 仍=旧线 ⇒ 谓词按旧线取值」);§6.4 测试位③(「stop_flag=0 断言最早出现在生效帧 line_switch_sell 调用返回后」)。

**缺陷**:三处文本要求生效帧骨架 pass 期间 stop_flag=旧值(旧线成型 ⇒ 1);但 R10-5 自己钉死的语义是「stop_flag=当前线 K 成型的分类谓词,评估对象恒为当前生效线 K、逐备战期随 M2 分类重评」。按 R1-3/§2.2,K 在生效帧的证明 pass 即已翻为 K′(「K 已按新线 K′ 更新后的下一备战期」),生效帧骨架 pass 消费的当前线就是 K′;K′ 未成型 ⇒ 纯谓词取值=0,**不是**旧值 1。R10-5 条款①用「评估返回前 K 仍=旧线」来把「保持旧值」说成谓词推论,这个前提在生效帧骨架 pass 时点为假——K 何时切换由 R1-3 定死在生效帧证明 pass,不依赖 line_switch_sell 的 EV pass 评估时点。两种读法只能活一个:

- 谓词读法(与 R10-5 钉死一致):生效帧骨架 pass stop_flag=0,M2 立即按 K′ 分类、当帧即可买新线过渡件。压制窗=仅登记帧,比 R9-2 引理的界更小(界仍真),但 R8-7「消浪费窗」的收益只覆盖登记帧,「生效帧骨架 pass 旧值仍生效」句作废。
- 锁存读法(与 R9-2 引理文本一致):生效帧骨架 pass 值=1——那 stop_flag 就不是「当前线 K 的分类谓词」,R10-5 的钉死失败,退回它自己要消灭的锁存两可。

**为什么错**:谓词的值是其自变量(当前 K)的确定函数;生效帧骨架 pass 时当前 K 已=K′,谓词只能取 0。R9-2 引理和测试位③却断言该时点值为 1 且「stop_flag=0 最早出现在 line_switch_sell 调用返回后」——按谓词语义实现的正确代码会在这条测试上红,按测试实现的代码则违反 R10-5 钉死。这是「实现后必错」规格:两份权威文本给出互斥的期望值。

**修法方向**:显式定死谓词求值时点=每备战期证明 pass 之后、M2 分类之前,对象=该帧生效 K。由此:登记帧值=1(旧 K 成型,浪费窗收益在登记帧保真)、生效帧值=0(新线过渡件当帧可买,压制窗=1 帧,≤R9-2 界);删去 R9-2「生效帧骨架 pass 旧值仍生效」句与 R10-5 条款①的「评估返回前 K 仍=旧线」前提;§6.4 测试位③改断言「stop_flag=0 最早出现在生效帧证明 pass 后的 M2 分类(而非 line_switch_sell 返回后)」,并同步核 R9-2 引理「额外恢复延迟 ≤1 帧」措辞(实际=0 帧额外延迟,界不破)。

## P2(实质)stockpile_buy 案②缺星级发射限定,与案①星级纪律互相矛盾

**位置**:IMPL_DESIGN §2.5 辖域三段:案①(金>50∧有 S 目标)带发射限定「T_search 活跃窗口档内 ∧ 1★(refund_full)」,并明文「2★+ 档内单无 EV 背书不发射+记遥测」;案②(金≤50)只有「放行依据=[11] 动态无损(小额可逆、有卖回计划)+P49 全段辖域(线性律不设金位门槛)」,无 1★/refund_full 限定、无 2★+ 禁发条款。

**缺陷**:两段对同一判据(c∈T_search)下的 2★+ 档内单给出矛盾的纪律:

- 案① 的立场:2★+ 档内单「无 EV 背书不发射」——其风险背书链(1★=P41 全额可退支配+L-R3-4 命题 1 有界风险)对 2★+ 不成立(卖出手续费 1 金,命题 3 明文「无证明其 EV 为正 ⇒ fail-closed 不买」)。
- 案② 的立场:P49 线性律「不设金位门槛」全段辖 ⇒ 金≤50 时档内单(含 2★+,文本未排除)放行;而其引用的 [11]「动态无损」对 2★+ 同样不成立(1 金手续费非无损)。

若 P49 线性律足以为 2★+ 档内买入背书,则案① 的「2★+ 无 EV 背书」为假;若不足,则案② 在金≤50 放行 2★+ 档内单是无背书发射。R8-6→R9-4 的收窄条件「随辖域平移」只平移到了案①,案② 漏接——这是 R9-4 裁决(「2★+ 档内单无 EV 背书不发射」应是辖域级纪律,不是金位条件分支)在落地行上的半截执行。

**为什么错**:R9-4 的裁决依据是「EV 背书按星级与可退性判,与金位无关」;案② 恰好以金位(≤50)为分段界把星级限定丢掉了。同帧同卡下,g=49 与 g=51 的同张 2★+ 档内卡一个可发一个禁发,而两段的判据式(c∈T_search)与背书引据([11]/P49/P41)完全同源——分歧行为无任何数学理由。

**修法方向**:二选一并全文统一——①把「档内 ∧ 1★(refund_full)」发射限定与「2★+ 不发射+遥测」条款上提为 stockpile_buy 全辖域(两案同规);②若认定 P49 线性律对档内 2★+ 目标卡(向 S 压缩的在窗卡)本身即足额背书,则改案① 的「2★+ 无 EV 背书」措辞,给出 2★+ 档内的显式风险账(fee=1 有界)并同样上提全辖域。禁维持现状(两段异规)。

## P3(实质)直通线并入批给 line_selector 增设第三函数位,§4.2.1 完备性全称失守且臂①形态未定义

**位置**:IMPL_DESIGN §2.7.1(「开局信号由 obs 层登记,进 proof/line_selector 的**信号臂**——与证据门 P_complete 臂同层同权,产出同一个 K」;S0──信号──▶S3 直锁边)× §4.2.1 完备性口径(「proof/line_selector 的 should_switch 与 stop_buy 双函数位均在表……**line_selector 仅此两函数**」)。

**缺陷**:R9-1 的完备性声明是「line_selector 仅此两函数」的**全称断言**,而直通线并入批(自称「本批纯追加注记,不改任何既有判据行语义,与 R1-R10 修复零冲突」)在 line_selector 内新增了一个有独立输入(obs 层信号谱)、独立动作(直接锁线产出 K,跳过证据门比较序)的**函数位**:信号臂。它不是 should_switch 也不是 stop_buy,枚举表无行,于是:

1. **完备性全称被自家文本证伪**——「逐函数全表、每行有归属」的二分全称在 line_selector 域不再成立,而这正是 R9-1/R10-3 两轮补行要守的性质(「唯一权威表缺行、真实规格散落别处」的病在直通线域复发:信号臂的规格只活在 §2.7.1 注记,不在权威枚举表)。
2. **臂①形态未定义**——旁路集以枚举表为唯一权威;信号臂无行 ⇒ 臂①是否锁线未在权威表定义。§4.2 臂①行只说「证据门默认线」,未提信号臂。若臂①不实现信号臂而臂②实现,则两臂 K 轨迹自首个信号起发散=L-B5(b) 形态②(mandate=true 臂间差)被**非实验因子**(实现面不一致)污染,命题 A/B 归因受损——恰是 R9-1 补 should_switch 行要防的同型病。

并入批的自洽声明只核对了「与 R1-R10 各修复行语义零改动」,漏核「与 §4.2.1 完备性口径的字面互斥」。

**修法方向**:§4.2.1 补 `line_selector.signal_arm` 行:类别=发射位(产出锁线事件/K);臂①形态=不旁路(信号臂属证明层状态驱动、非 criteria EV 项,两臂同开——K 判定路径在「信号是否到」上同构,臂间差仍收敛于 should_switch 单因子);完备性口径改「line_selector 三函数位」。

## P4(证明本体)R7-2 的「被阻断动作集=∅」前提与 R8-8 的存在前提冲突

**位置**:IMPL_FIX_LEMMAS R7-2 证明要点①(i):「board free>0 时存在空位 ⇒ 不存在因席位被阻断的动作 ⇒ 被阻断动作集=∅ ⇒ 净 EV=0——V_slot=0 是空槽的可观测真值」;同表 R8-8 引理与设计 §3.1:M2 买入遇 **bench 满**触发 M4 腾席重试(重试上限 ≤B),即买入动作的席位阻断源是 bench,与 board 是否有空位无关。

**缺陷**:R7-2 把「席位阻断」只读成 board 槽位阻断;但设计的执行序里存在第二类阻断——bench 满阻断买入(R8-8 整条引理为其而生)。在「bench 满 ∧ board free>0」态:按 R7-2 (i) V_slot=0 被标为「定义级真值/非虚拟数值」;按实际语义,卖出腾出的 bench 席位使一笔被阻断的买入解阻,其净 EV(哪怕依赖未标定量而无载)在定义上>0 不是 ∅。即 V_slot=0 在该域是**保守端代入**,不是可观测真值——R7-2 用「真值」措辞证明了它想只用「方向保守」就能证的事,前提却错了一半域。

**为什么错**:「被阻断动作集=∅」当且仅当 board 与 bench 均有自由席位;R7-2 的 free 只直读 board 面。同表 R8-8 的前提(bench 满阻塞买入、board 无关)与 R7-2 (i) 的全称「free>0 ⇒ 无阻断」在同帧可同真(bench 满 ∧ board free),直接互斥。

**修法方向**:R7-2 措辞收窄——(i) 改「board free>0 ∧ bench free>0 ⇒ 被阻断集=∅ ⇒ 0 为真值」;bench 满 ∧ board free 态的 V_slot=0 归入 (ii) 同款「未标定阻断按保守端 0 载入」。方向结论(左端 0 合法)不受影响,但「可观测真值」的声明域必须收窄,否则 §2.2.1 行「定义级真值,非虚拟数值」成为实现者拒绝保守端标记的错依据。

## P5(证明本体)R8-8 引理所述不变量与重试环的真实状态轨迹不符

**位置**:IMPL_FIX_LEMMAS R8-8 引理:「每次 M4 成功腾席 bench 占用严格减 1(M4 动作集只含支配性卖出、不新增 bench 件)⇒ 成功腾席次数 ≤ bench 占用初值 ≤B」。

**缺陷**:重试环是「M4 腾席(占用−1)→ M2 买入(占用+1)→ 席位检查再失败 → M4 再调」——在各次 M4 调用时点回看,bench 占用已回到初值,**并非严格递减**;所述不变量「M4 动作集不新增 bench 件」挡不住环内 M2 的回填。结论(≤B 次/帧)本身仍真,但载重不变量是另一条:M4 只卖「与锁线零重叠 ∧ 边际贡献≈0」的件,而 M2 触发重试买入的件是线内件(序 1/2),fuel_sell 线内禁卖 ⇒ 已售可腾席件集合单调不减且不被环内买入补充 ⇒ 成功腾席次数 ≤ 初始可腾席件数 ≤ B。原措辞的不变量在环状轨迹上是假命题。

**修法方向**:引理改写为可腾席件单调耗竭论证(需显式引 fuel_sell 判据的「与锁线零重叠」条件挡住「卖出刚买件」的反例环),结论与上限不变;否则实现者按字面「占用递减」做断言/计数会数错。

## P6(证明本体)R10-1 引理步骤 1 的「放行方向相反」句自相矛盾

**位置**:IMPL_FIX_LEMMAS R10-1 引理步骤 1:「『使门放行更难=保守端』的统一判据在二值投影上只能落一侧(两门的『放行』方向相反:甲的放行=floor_eff 变 0,乙的放行=floor_eff 变 0——同一枚币的两面)」。

**缺陷**:冒号后的两个分句写的是**同一方向**(两门放行都对应 floor_eff→0),与冠词「方向相反」直接矛盾。且论证真正依赖的不是方向相反——是**两条旧规则是不同的分类测试**(甲按 CI 下端、乙按 CI 上界),在跨界带上输出不同投影值,故不可实现。若两门放行方向真的相反,逐门取保守端反而可同时满足、R10-1 的「必须上游单规则」论证会塌。现文本让读者无法重建论证链。

**修法方向**:该句改为「两门的放行方向相同(均=floor_eff→0),但旧的两条段分类测试(甲=CI 下端、乙=CI 上界)在跨界带给出互斥投影值,单投影不可同真,故必须上游单规则定谳」。

## P7(验证缺口)辖域仲裁条款无行为级测试位

**位置**:IMPL_DESIGN §2.5 仲裁条款泛化(R9-4/R10-4:同帧同卡辖域并出 ⇒ 执行序先者归属、同层重叠丢弃+告警、禁靠硬约束②兜底)+ §5.3 对拍清单 + §6.4 测试位。

**缺陷**:R8-5/R9-4/R10-4 三轮为一个「同判据双消费不双发」的辖域纪律堆了大量裁决文本,但验证面零锚——§5.3 无对拍项、§6.4 五类测试位无一条断言「同帧同卡发射位唯一/并出时按先序归属/同层并出丢弃且告警」。辖域互斥是纯设计层约定,§2.1/§2.5 两处辖域文本已经历三轮改写(R7-1→R8-6→R9-4),每轮都在动定义域边界——恰是最容易被后续批次改漏的面,却没有任何回归锁。对照:行为远小于它的 stop_flag 重分类、M1′ 收敛性都有测试位。

**修法方向**:§6.4 补一条:构造 dominance_buy↔M6 benign 并出场景与一个(人为注入的)同层并出场景,断言前者双发不丢弃仅遥测归属=dominance、后者丢弃+告警遥测、硬约束②不吞告警。
