## 命题(形式化)

**开战帧**(即点开战、战斗随即结算的那一帧;适用范围前提,三合取,判据单一源 = `readiness_launch_decision`):

```
armed(= form_progress(comp, state) ≥ 1.0)∧ node_type ∈ {battle, encounter, boss}
```

且处于**本回合备战阶段的最后一帧**(点开战即战斗:点开战后战斗立即结算;商店每节点自动刷新 1 次、金与经验均在战斗结算后变动——`docs/game/currency_war/data/gameplay.md` 商店/结算两条机制直读)。设:

- `cap = cap_resolved_of_session(session)`,g* = `saturation_line(cap)` = 10×cap(默认局 50);
- **溢出段** D_ovf = {(g, spend) : g > g*, 1 ≤ spend ≤ g − g*},spend 为**阵容内 offer/升级类即时消费**(消费点对象复用 shop 出口③同族既有评估栈——R1/L2/L3/EV 降排序,不新造第二套评估语义);
- 轨迹 B(留存):不花;轨迹 A(花 spend 后维持利息线)。EV(·) = 花费决策后的未来期望总收益(纯金流口径,血不入账,P51 公理栈)。

**命题 L1-a**:对任意 (g, spend) ∈ D_ovf,任一使战力边际 ΔV ≥ 0 的合法花费满足

```
EV(spend 轨迹) ≥ EV(留存轨迹)        (弱支配)
```

且花费侧是**零利息损失构造**:利息账项 L(g, spend, R, Ī) ≡ 0 在全域 D_ovf 上恒成立,零新自由参数。

**带内段声明(不在适用范围)**:g − spend < g* 时 L > 0 可能,判据式 `spend ⇔ S(n)·Δp_win ≥ L(g−spend, R_rest, Ī) + 摩擦` 登记为 **L1'** 独立命题,证不出 = 带内维持现状不花(fail-closed)。本命题与 P68(boss 前置帧 r=0 特例)文号独立、触发面独立、禁止并案;与 P69(备战等待零收益支配)互补:P69 证「出战支配等待」,本命题证该帧上的**金出口**方向。

## 证明

### 侧 1:溢出段利息损失恒零(零利息死仓〔不生息的死钱〕构造)

由 P47 命题 2 双轨迹递推(代码单一源 = `loss_exact`):

```
B₀ = min(g, g*) = g*                        (g > g* ⇒ 利息线截断)
A₀ = max(g − spend, 0) ≥ g*                 (spend ≤ g − g* ⇒ 花后仍 ≥ 线)
  ⇒ min(A₀, g*) = g* = B₀
```

两轨迹初始金位相等,且其后每轮同收入演化、同利息线递推 ⇒ 逐轮金位恒等 ⇒ 每轮利息差 `interest(B_k) − interest(A_k) = 0` ⇒

```
L(g, spend, R, Ī) = 0    ∀ R ≥ 0, ∀ Ī        (对 R、Ī 全域恒零,连参数都不需要)
```

即:**溢出段的金是零利息死仓**——花掉它的机会成本(利息侧)精确为 0,不是近似。∎(脚本对账:`p70_check.py` 全域网格直调 `loss_exact` 断言 L=0;对照断言:带内同参数格 L>0,划出适用范围边界。)

### 侧 2:留存收益通道在开战帧恒零

留存的金在开战帧之后、下一次经济事件之前的窗口内没有任何收益通道:

1. **利息侧已被侧 1 封死**:两轨迹都钉在利息上限 g* 上,利息流恒 `cap`/轮,花不花都一样——留存的边际利息收益 = 0;
2. **备战决策数 = 0**:开战帧是本回合备战最后一帧(点开战即战斗,见适用范围前提),窗内不存在第二次买/刷/升决策——金留在手里没有下一个决策点可消费(`in_must_spend_zone` 适用范围 = 有动作决策点帧,开战帧决策段数 = 0,即 35/109 帧金 ≥ g* 从未被任何判据看见的适用范围缺口);与 P52 窗口局部 ε-最优形态同构:窗内剩余备战决策数 = 0 ⇒ 留存收益项恒 0;
3. **战斗结算时点隔离**:金与经验均在战斗结算后变动、商店按节点自动刷新(gameplay.md 机制直读,P69 同源前提)——留存金在「本帧」不产生任何中间收益。

### 侧 3:消费侧战力边际非负

开战帧消费即时转化为**本场战斗**战力(买牌 → 上阵 → 开战)。对阵容内 offer/升级类消费,更强板面 ⇒ 胜率不降且条件败局伤害不升(掉血锚,注册表 `streak_floor_loss_damage`:encounter 截距 24.32 / boss 常数 26.71;boss P15v2 冻结语料锚 26.79 [24.25, 29.23]——均 ≥ 0)。故战力边际 ΔV ≥ 0。∎

### 合成

```
EV(spend) − EV(留存) = ΔV − L(g, spend, R, Ī) − 摩擦
                     = ΔV − 0 − 0 ≥ 0         (侧 3 − 侧 1 − 摩擦侧)
```

**摩擦项 = 0 的适用范围依据**:本命题适用于「买来上本场板」的即时战力消费——买入件即上场、不在当帧卖出,卖出退金折损(P47 命题三 fee:cost≥2 合成件卖回 −1)不进入本帧账;消费选择次优性由消费点复用既有评估栈(只产 ΔV ≥ 0 候选,且零花是退化成员)排除。因此合成式右端 ≥ 0:**花费弱支配留存**。∎

**严格性注记**:弱支配,非严格——ΔV = 0 的格(消费与不消费战力等价)两轨迹恒等;格 ΔV > 0 时严格优。

## 边界(什么情况失效,如实入册)

1. **超出溢出段即失效**:spend > g − g*(把金花到利息线以下)或 g ≤ g* 时 A₀ < g*,侧 1 不再恒零——带内判据登记为 L1',fail-closed 维持现状不花;
2. **消费对象超出适用范围而失效**:适用范围内的消费 = 阵容内 offer/升级类即时战力消费。阵容外囤件、3★ 深度凑件等非即时战力消费不在本命题背书(其 ΔV 未必 ≥ 0);**计划卖回型消费也不在适用范围**(其净账含卖回摩擦与时点敞口〔敞口=可能随死亡销毁的金额〕,归 P47 命题三动态修正口径——ΔV=0 的卖回计划件可因 fee ≤ −1 金严格劣于留存);
3. **cap_resolved ≤ 0(买断制利息关闭)**:g* = 0,利息账整体消解(L ≡ 0 平凡成立),命题数学上仍真但 g* 语义退化——谓词层沿用 `in_must_spend_zone` 同款「cap ≤ 0 即视为不在范围内」的工程保守选择,非命题失效(显式声明,防止被误并案);
4. **开战帧定义失效**:若机制变化使点开战后仍有备战决策(或商店刷新/金经验结算时点改变),侧 2 的「窗内决策数 = 0」前提破,留存收益通道重现 → 本命题须重验;
5. **掉血锚过期**:侧 3 的 ΔV ≥ 0 只依赖「更强板面不掉血变多」的单调性,锚值(24.32/26.71/26.79)只作适用范围声明不入推导——锚过期不破命题,但 S(n) 数值面(带内段 L1' 判据输入)须随注册表重锚(P10 教训:禁字面量第二份)。
