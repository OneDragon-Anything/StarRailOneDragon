# 大月卡(无名勋礼/无名客的荣勋)购买路由

> 画面细节见 `docs/game/screens/无名勋礼.md`(主面板/购买推广页/等级加速弹窗/规则说明)与 `docs/game/screens/无名勋礼-购买档位页.md`(档位页+扫码弹窗);本文管操作路由与状态解读。

## 1. 机制(游戏内规则说明实读 + 2026-11-12 实购实证)

- 无名勋礼 = 战令(玩家称「大月卡」),**每版本一期**(本期为 5 周缩短版,剩余时间在主面板顶部),满 70 级,解锁需开拓等级 13+。
- 双轨奖励:免费轨「无名客的赠礼」每期默认解锁;付费轨「无名客的荣勋」需购买解锁。
- **付费档位两条**(档位页两卡并排):「无名客的荣勋」**￥68.00**(标准档)与「无名客的奖章」**￥128.00**(划线价 ￥146,立即 +10 级);解锁荣勋立即返 **680 星琼**(实购到账实证);重复购买返古老梦华(750/1410/860)不白买。
- 付费轨 + 勋礼等级达 30 → [星海珍藏](../../docs/game/screens/无名勋礼.md) tab 任选一个本期光锥(购买入口不在该 tab,唯一入口在奖励 tab 右下)。
- 任务分本周任务(每周一 04:00 服务器时间更新)与本期任务;勋礼等级到上限后任务不再产出经验。
- 版本周期内**第一次**进无名勋礼先落整屏「购买推广页」:点「开启无名勋礼」是查看/继续语义**不会付费**(用户裁决),经「等级加速弹窗」后才到主面板——op 已自动处理该前置链。
- **已购买态**(实购后实证):主面板「解锁无名客的荣勋」按钮仍在(可再去档位页,推测升奖章档),「解锁立即获得」提示条消失;付费轨奖励解锁;等级不变(靠任务升)。

## 2. 操作路由

| 步骤 | 用什么 |
|---|---|
| 查状态/看购买入口 | op `BuyNamelessHonorPassOp(open_pay=False)` —— 从任意画面到主面板并确认未购买态,成功状态 `AT_ENTRY`,零消耗;已购买态显式失败报告。主面板可读 勋礼等级/剩余时间/本周经验上限 |
| 确认购买意愿 | 与用户确认(消耗门,见 SKILL.md 红线);顺带确认支付渠道偏好(支付宝/微信) |
| 打开付款码 | op `BuyNamelessHonorPassOp(open_pay=True, pay_channel='alipay'或'wechat')` —— 自动导航 → 主面板点「解锁无名客的荣勋」→ 购买档位页点「￥68.00」(荣勋档;奖章档 ￥128 只识别永不点击)→ 扫码弹窗 → 按渠道就位,成功状态 `PAY_OPENED`(2026-11-12 全链实机走通) |
| 交还用户 | 告知「扫码弹窗已就绪(渠道 X,￥68.00,商品无名客的荣勋),请扫码」;bot 止步 |

- op 源文件:`src/sr_od/application/cultivation/account/operations/buy_nameless_honor_pass.py`。
  MCP `run_operation` 的 `op_id` 直接用类名短名 `BuyNamelessHonorPassOp`(短名全库唯一即运行)。
- **判「本期是否已购买」**:看「解锁立即获得」提示条(在 = 未购买;消失 = 已购买,
  按钮不作判据——已购态按钮仍在)。已购态跑 op 会显式失败并注明,不误发起。
- **二维码有时效**:过期态中央出刷新钮,点击重出码(实机实证);弹窗上手动点
  「微信支付」tab 也可切渠道(op 的 check_channel 幂等,重跑可校正渠道)。
- 收尾清理(用户放弃支付):点扫码弹窗右上 X(1195,258-1248,312)——之后是否弹
  「确认放弃本次支付?」待下次实际放弃时观察(本次实购未触发该链)。

## 3. op 状态与失败去向

- `AT_ENTRY` = 已到主面板且未购买态(open_pay=False);
- `PAY_OPENED` = 扫码弹窗已打开且渠道就绪(open_pay=True);
- 失败:导航失败/周期首进退出链异常/**已购买态**(按钮在但提示条消失)/扫码弹窗
  未出现或渠道标注异常(现场核查)。
