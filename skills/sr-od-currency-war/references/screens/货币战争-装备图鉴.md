# 货币战争-装备图鉴

## 画面简介

全量装备的图鉴网格 + 右侧详情面板画面——装备效果文本的权威读数位：数据银行主页上排的「装备图鉴」晶石卡进入。左上标题「装备图鉴」+ 扩充倒计时；顶部是图鉴族共用的图标切换条（9 个无文字图标，本画面第 3 签「装备」选中），其下第二排小图标是装备分类过滤行（归档帧 7 个，第 1 个选中），再下一行是分类计数「<当前分类> [n/m]」。左侧网格 7 列（归档帧可见 3 行，底部露出第 4 行上缘），每格 = 装备图标 + 名字，选中格带白色描边，滚动推进。右侧详情面板：装备大图标 / 名称 / 分类 / 属性标签 / 属性行 / 「合成公式」列表（每行一个配方，归档帧可见 8 行、第 9 行被底缘截断）。

离线建档声明：布局与读数来自归档帧（选中「轮滑鞋」态）；「数据银行晶石 → 本画面」的进入关系来自实机探索的帧序，切换条各签、返回箭头的点击行为未单独实测。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标题-装备图鉴 | 画面标题「装备图鉴」（身份锚，单文本即精准） | 纯显示 |
| 区域-顶部图鉴切换条 | 图鉴族共用切换条：9 个无文字图标签（自左至右 链 / 人 / 装备 / 方形 / 星球 / 星徽 / 骰 / 武 / 卡片），选中签 = 白色圆底 + 下方白色下划线；本画面第 3 签（装备）选中 | 点某签切到对应图鉴画面；各签去向待实机核对（选中态实证：第 3 签 ↔ 本画面、第 6 签 ↔ 主角光环图鉴、第 8 签 ↔ 竞争对手图鉴列表） |
| 区域-分类页签行 | 切换条下方的分类过滤行：一排灰色小图标（归档帧 7 个，第 1 个选中、此时分类计数显示「全部装备」；其余各对应一个分类），图形按钮 OCR 读不出 | 点击切换装备分类 → 网格与分类计数跟着切 |
| 分类计数条 | 过滤行下方的分类计数「<当前分类> [n/m]」：分类名随选中过滤变（归档帧「全部装备」，旧档出现过「其他装备」），识别锚只取两屏共有的「装备」二字；n/m = 该分类收集进度（归档帧 53/154） | 纯显示 |
| 区域-左侧网格名带 | 左侧装备网格整体带（7 列装备卡：图标 + 名字，选中格白描边；部分卡图标左下有黑色小数字角标） | 点某件装备 → 右侧详情面板切到该装备；拖拽翻页 |
| 区域-右侧详情面板 | 详情面板整体：装备大图标 / 名称 / 分类 / 属性标签 / 属性行 / 合成公式 | 纯显示 |
| 文本-合成公式标题 | 详情面板中段的小标题「合成公式」 | 纯显示 |
| 区域-合成公式列表 | 「合成公式」下的配方列表：每行 = 「+」材料图标 = 成品图标 + 成品名（见操作表「读合成公式」）；归档帧可见 8 行、第 9 行被底缘截断 | 纯显示；列表长时在面板内拖拽 |
| 按钮-返回 | 右上返回箭头（与优势布局等画面同款图标，共用模板） | 点击行为待实机核对（去向未实测） |
| （待建档）扩充倒计时 | 标题下方倒计时（如「68天12小时」）；动态值勿当画面锚 | 纯显示 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 进入本画面 | MCP `click_game` | 数据银行主页「入口-装备图鉴」area 中心 | 进装备图鉴 | — |
| 切到别的图鉴 | MCP `click_game` | 「区域-顶部图鉴切换条」内目标签坐标（看图点：9 签自左至右 链 / 人 / 装备 / 方形 / 星球 / 星徽 / 骰 / 武 / 卡片） | 切到对应图鉴画面 | 各签去向待实机核对；图形签 OCR 读不出 |
| 切分类 | MCP `click_game` | 「区域-分类页签行」内目标分类小图标（看图点，归档帧 7 个） | 网格切到该分类、分类计数条更新 | 图形按钮 OCR 读不出 |
| 读某件装备 | MCP `click_game` | 网格内该装备卡坐标（自己读图定位，「区域-左侧网格名带」内） | 该卡白描边、右侧详情面板切到该装备 | 网格靠拖拽翻页 |
| 读合成公式 | 看图（`analyze_screen` 辅助取文字坐标） | 「区域-合成公式列表」逐行读：行 = 「+」材料图标 「=」成品图标 + 成品名，含义 = 当前选中的装备 + 材料图标 = 成品（归档帧选中「轮滑鞋」：两行读作 轮滑鞋 + 轮滑鞋 = 反重力皮靴、轮滑鞋 + 折叠小刀 = 火力风暴潮，与 MCP `cw_equip_lookup` 的配方一致） | 读到该装备作为材料参与的全部配方 | 材料只有图标没有文字，材料名查 MCP `cw_equip_lookup`（配方以它为准，画面只作核对）；行数多时面板内拖拽 |
| 滚动网格 | MCP `drag` | 网格内拖拽（手指上滑 = 向列表深处翻页） | 网格翻页 | — |
| 返回 | MCP `click_game` | 「按钮-返回」area 中心（模板匹配位置） | 回上级 | 去向待实机核对（历史实录：ESC×2 经数据银行主页回备战） |

查装备数据优先 MCP `cw_equip_lookup`（效果/配方/分类），进画面只在截图取证或核进度时需要；采集 op `HarvestEquipCodex` 在册但已挂账退役中（待跟进事项「图鉴采集链退役」）。
