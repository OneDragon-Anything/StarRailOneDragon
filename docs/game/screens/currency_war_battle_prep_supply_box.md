# 货币战争-备战-武装箱选择(开补给箱装备 4 选 1 overlay)

点备战席补给箱槽位内「开启」文字区弹出的装备选择 overlay:标题「<档位>武装箱」(如「简易武装箱」)+ 副题「请选择1个」+ 4 张装备卡横排。

## 何时出现 + 状态流转

- **入口**:备战席补给箱(奖励球掉落,占 1 槽)→ 点箱内「开启」文字区(箱 icon 下方,~箱槽中下部)→ 本 overlay。
- **出口**:点 4 张装备卡任意一张 = **选中即确认**(单步,无二次确认按钮)→ overlay 关,装备入 owned,箱槽腾空。
- **父子画面**:备战 overlay 子态(非独立画面)。overlay 盖住备战 id_mark(购买经验/出战)→ 备战不 is_precise,不撞车。
- **档位变体**:标题随箱档位变(实测「简易武装箱」=4 张简易装备;进阶箱待采样)。id_mark 用「武装箱」LCS 覆盖前缀变体。

## 识别特征(稳定锚点)

- **标识-武装箱**(id_mark,text=武装箱,rect [940,25,1200,80]):OCR 实读「简易武装箱」@~(1098,57),LCS 武装箱 3/3=1.0。
- **标识-请选择**(id_mark,text=请选择,rect [960,70,1180,115]):OCR 实读「请选择1个」@~(1095,98)。⚠️ rect 纵向 padding 要 ≥45px(30px 紧裁 paddle 检测不到,建档实测)。
- 组合 id_mark(两锚全中才精准):备战的「请选择」类文字不在此位置,不撞车。

## 可交互元素

| 元素 | 位置(中心,1080p) | 说明 |
|---|---|---|
| 装备卡-1..4 | x≈620/900/1180/1460,y≈285 | 点卡 = 选中+确认一步完成 → 关 overlay 入 owned。卡含 icon + 装备名(y~276)+ 查看详情(y~328) |
| 查看详情 | 卡内 y≈328 | 点弹该装备详情(信息浏览,非选卡;与备战装备详情面板同机制) |

## automation 要读信息

- **4 张卡装备名**(区域-卡名行 [545,255,1545,300]):OCR → 装备规范名 → 选择策略(合成材料通用性/comp key_equips 命中优先)。选卡即决策点(缺 handler,bot 暂无自动开箱)。
