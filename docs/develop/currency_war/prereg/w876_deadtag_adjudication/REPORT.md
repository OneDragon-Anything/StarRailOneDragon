# 货币战争 · 死 tag 复活裁决设计批（w876）

> 裁决对象 = W872 攻击发现的「死映射」分叉：9-10 条环境词条的 `AFFIX_MECHANIC_MAP → MECHANIC_COUNTERS/SYNERGIES → mechanics_fit` 接线齐全，但 comp 侧 `mechanic_attributes` 零携带 tag，求交恒空（cw_comps.py:1182-1191，`comp.mechanic_attributes` 为空或无交集 → 恒 0.5/None）。
> 输入：`sr-od-currency-war-dev` skill strategy-work（决策规则数学先行 / 策略开关的生命周期）、W872 REPORT（7 死 tag 清单）、W868 REPORT（被降级词条清单）、`kernel/cw_comps.py`（:208-256 三表、:475-1032 全部 20 套 comp 的 mechanic_attributes 声明、:1174 mechanics_fit）、`data/cw_plaza_comps.py`（29 聚类结构）、`docs/game/currency_war/research/final_comps/`（十类分类，README 全文）。
> 离线只读分析，未改任何生产文件。

## 0. 判据框架

每个死 tag 依次过三问：

- **Q1 存在性**：该 tag 对应的玩法概念，在终局十类 comp 体系（final_comps README 十类 + B/C/D 节全局规律）里真实存在吗？有攻略实证/聚类数据支撑吗？
- **Q2 可判性**：若存在，comp 侧打 tag 的判据是什么（名字 / 羁绊结构 / 装备特征 / 其他字段）？能从现有 registry 数据自动推导或一次性人工标注吗？误判风险多大？
- **Q3 量级匹配**：词条效果量级与 mechanics_fit 的表达粒度（±0.25 counter / +0.20 synergy 步进，clamp 0..1）匹配吗？5% 级效果配 0.2 级步进 = 离散 tag 系统性过反应（W872 角度④同款问题）。

三问答案组合 → 三桶：复活（Q1 有 + Q2 可判 + Q3 值得）/ 判死（Q1 无 或 Q2 不可判，且 Q3 也不支撑）/ 观测（方向真实但量级或判据证据不足，留 map 行不删、不立项建模）。

## 1. 逐 tag 分诊表

### 1.1 单属性队（挂靠：属性熄火 ×7 词条——风/火/冰/雷/物理/量子/虚数）

| 问 | 结论 |
|---|---|
| Q1 存在性 | **存在（强证据）**。final_comps README D3 原文：「硬 counter……**希儿怕量子熄火**」——玩法知识层已承认「单属性主档队怕对应属性熄火」这一关系；希儿量子类 38 篇中 36 篇核心羁绊=量子同频（cw_plaza_comps.py:106）。其余六属性熄火在当前 comp 库无纯色主档对应（COMP_LIBRARY 无火/冰/雷纯色队），对它们恒中性是**正确行为**而非缺口。 |
| Q2 可判性 | **可自动判**。判据=「comp 的 form_tiers/factions 以**属性型羁绊**为主档且档深 ≥4」（当前即 量子同频）。对 COMP_LIBRARY 做一次性标注：希儿量子套（602 行 quantum 拉条套 + 同家族分支）打 `单属性队`；其余套不打。纯 grep form_tiers 键即可机械化，误判风险低（属性型羁绊键名唯一可辨）。 |
| Q3 量级 | 熄火效果=对应属性伤害 1 点 ×4 次——对纯色队是**主输出瘫痪级**，配 -0.25 步进甚至偏保守，方向与量级都匹配。 |

**裁决：复活**。这是 7 个死 tag 中证据最硬的一个（玩法文档明文 + 聚类数据 + 效果量级三重支撑）。

### 1.2 高费队 / 低费队（挂靠：高费审美 / 低费审美）

| 问 | 结论 |
|---|---|
| Q1 存在性 | **部分存在**。费用档差异真实：高费核心线（姬子/希儿/黄泉 7级D三星）vs 低费核心线（万敌 1费C 5级、大黑塔压等级 D 一费、银狼升费链）——A4 星级饥渴两档表与 D1 节奏锚点都是按费用档分的。但「高费队/低费队」是**节奏/经济概念**，不是「整队伤害随费用分布」的战力概念。 |
| Q2 可判性 | 可半自动判（core_chars 费用均值查 cw_chars 注册表），但「多高算高费队」无既有判据，需新拍阈值——按 strategy-work「决策规则数学先行」硬门，该阈值推导不出权威出处。 |
| Q3 量级 | **不匹配（关键否决项）**。词条效果=4费+ / 3费- 各 **±5%**（V4.4 口径，w868 §1 C 类表）。mechanics_fit 最细步进 0.20 ≈ 20% 级战力差——5% 的真实差异被打成 0.2 评分步进，**离散 tag 系统性放大 4 倍**，会把本该近似中性的选型扰动成硬 flip。 |

**裁决：观测**。概念半真但量级远低于表达粒度，此时建模=拍脑袋阈值 + 过反应双重违规。map 行保留（不删，词条方向真实），comp 侧不立项；挂账条件=未来出现费用差异化幅度 ≥15% 的词条，或 comp_score 引入连续费用分布通道时重审。

### 1.3 成型羁绊队（挂靠：形单影只——1/2/3 未激活羁绊 → 85%/60%/30%）

| 问 | 结论 |
|---|---|
| Q1 存在性 | **存在（结构性证据）**。十类 comp 在「羁绊完成度依赖」上真实两极：羁绊驱动型（姬子列车 4、欢愉 5-7、减益 4-6、群攻 5+学者 4——战力来自羁绊乘区）vs 非羁绊驱动型（白厄反甲**装备**流、高倍率**单核**红A、榜样激励克的单核路数——羁绊不满也有战力）。B1 CARRY 三驱动型（大招/受击/行动）本质上都是羁绊协同型，反甲流是显式例外。形单影只罚的正是「羁绊没成型的板」——同一词缀对两类 comp 方向相反，正 mechanics_fit 设计意图（cw_comps.py:1177「同一词缀对不同 comp 方向相反」）。 |
| Q2 可判性 | **可判，人工一次性标注为主**。判据=「终局战力主要来自羁绊档位乘区」：form_tiers 主档 ≥2 键且无「装备流/单核」family 标记 → 打 `成型羁绊队`；白厄反甲族、圣杯单核族不打。可先按 `family` 字段（v2 九家族）+ branch_key 机械过滤再人工复核，约 20 套 comp 半天内标完。误判风险中等（个别套介于两者之间，如 万敌单C 前期强但终局也吃夜半/燃血档）——标注注释里逐套记一句理由。 |
| Q3 量级 | **最大量级的一条**：3 个未激活羁绊 = 伤害 **-70%**。这是全部死映射词条里唯一接近「步进粒度甚至超粒度」的，0.20 synergy 步进方向正确且偏保守。 |

**裁决：复活**。量级最大、概念结构真实、判据可从既有 family/form_tiers 字段推导。

### 1.4 爆发速杀（挂靠：紧急止血——敌进战 -20% 上限；下游连带：w868 的应激反应/一鼓作气「复用既有 tag」配方）

| 问 | 结论 |
|---|---|
| Q1 存在性 | **不存在**。十类分类的全部维度（CARRY 主体/核心羁绊/驱动型/节奏/星级饥渴）里没有「开局速杀」原型——D1 的「节奏」是**经济搜牌节奏**（几级 D 牌），不是**战斗内击杀速度**。最接近的「高倍率单核」是爆发伤害概念，但已另有 tag 载体（榜样激励行在用）；把它二次标注成「速杀」是概念偷换。 |
| Q2 可判性 | **不可判**。判据需要「comp 平均战斗时长/斩杀轮次」数据，comp 注册表与攻略知识都没有这个维度；静态数据（羁绊/装备/费用）推不出击杀速度。自动判不可行，人工判无知识源。 |
| Q3 量级 | 紧急止血 -20% 上限是中性偏均摊的环境效果，对「谁速杀谁受益」的区分度本身存疑。 |

**裁决：判死**。概念在 comp 体系中无对应物、判据无数据源、下游 w868「应激反应/一鼓作气复用爆发速杀 tag」的配方连带否决（复用零载体 tag = 补行后仍恒 0.5 空转，W872 角度③已点名）。清理=MECHANIC_SYNERGIES「爆发机会」行加「无载体」标记或删除 map 行留 ADR；若未来做战斗时长建模（sim 侧），再从观测数据重立。

### 1.5 慢速（挂靠：冻结族——极速制冷/坠入陷阱/冷冻冬眠；半死：战技点依赖半边有载体、慢速半边无）

| 问 | 结论 |
|---|---|
| Q1 存在性 | **存在（明确原型）**。DOT 卡芙卡类（叠层×引爆，20 篇）是教科书式慢热磨血线；冻结族的机制（每耗战技点冻结/受致命冻结 2 回合）惩罚的正是「战斗拖得久 + 战技点消耗大」的队。战技点半边已被 战技点依赖 tag 覆盖（678 行套），慢速半边缺的正是 DOT 这类载体。 |
| Q2 可判性 | **可判，人工一次性标注**。判据=「胜利条件为跨回合叠层/磨血」——DOT 套（978/1032 行 DoT tag 持有者）打 `慢速`。属性明确、套数少（1-2 套）、玩法知识单源（final_dot_kafka.md）支撑，误判风险低。大招流（姬子等）不算慢速（D 三星成型后一波清，战斗内不慢）。 |
| Q3 量级 | 冻结使单位整回合无法行动 ≈ 该单位 DPS 归零一回合，对慢热队是战力腰斩级——量级匹配。 |

**裁决：复活**。三个冻结词条从「只影响 1 套 comp」扩为「影响战技点依赖 + 慢速两族」，接线零改动，只补 comp 侧 tag。

### 1.6 依赖合成装备（挂靠：变宝为废——「装备依赖」tag 半边；词条整体已由 junk_first 排序器真处理）

| 问 | 结论 |
|---|---|
| Q1 存在性 | **存在（文档明文）**。final_baie_reflect（白厄，38 篇）类名即「反甲**装备流**」；C4 特权装备体系、C2 A/B 双套语义都是装备依赖概念的直接证据。 |
| Q2 可判性 | **可判，一行标注**。白厄反甲族 comp 打 `依赖合成装备`（其核心战力=以牙还牙甲 93/38 帖 + 掩体生成枪，装备即胜利条件）。机械判据可用 key_equips 中「装备本体名」（以牙还牙甲/掩体生成枪类防具）出现作代理，但直接人工标注更稳。 |
| Q3 量级 | 变宝为废=每位面首次进阶合成 50% 垃圾袋——对「全部预算砸一两件核心装」的白厄流是成型路径破坏级。已有 junk_first 处理合成侧，comp 侧 tag 补上**选型侧**（comp_score 在该词缀下给白厄流降分），两半合起来才是完整处理。 |

**裁决：复活**。成本最低（一行 tag）、概念文档明文、与既有 junk_first 通道互补不冲突。

### 1.7 「装备依赖」半死说明（W872 表内 tag 半死项）

变宝为废词条整体存活（junk_first），tag 半边的复活价值见 1.6；两事独立记账，勿因词条存活而漏掉选型侧缺口，也勿因 tag 复活而重复建合成侧处理。

## 3. 三桶裁决

### 复活（4 tag，带方案）

| tag | 建模方案 | 判据类型 | 出处 |
|---|---|---|---|
| 单属性队 | 希儿量子族 comp.mechanic_attributes += "单属性队"；可在 COMP_LIBRARY 标注处注释引 final_comps README D3 | 羁绊（属性型羁绊主档 ≥4） | README D3 + plaza 聚类 36/38 |
| 成型羁绊队 | 羁绊驱动型 comp 逐套打 tag（form_tiers 主档 ≥2 键且非装备流/单核家族）；每套标注一句判型理由 | 羁绊 + family 字段 | README B1/B5/C4、形单影只词条原文 |
| 慢速 | DOT 族 comp += "慢速" | 玩法概念（叠层磨血胜利条件） | final_dot_kafka.md |
| 依赖合成装备 | 白厄反甲族 += "依赖合成装备" | 装备（装备即胜利条件） | final_baie_reflect.md + C4 |

共同注意：tag 一旦打上，mechanics_fit 对**所有**已映射词条生效（不只目标词条）——落码前 grep MECHANIC 表确认新 tag 不会意外命中其他 counter/synergy 值（如「慢速」不在任何其他表值里，安全；「成型羁绊队」同查）。

### 判死（1 tag + 1 配方连带，带理由）

- **爆发速杀**：十类 comp 体系无「战斗内速杀」原型（Q1 无）、判据无数据源（Q2 不可判）。清理批次：MECHANIC_SYNERGIES「爆发机会」行与 AFFIX_MECHANIC_MAP「紧急止血」行删除（或注释降为观测），删码留 ADR（策略开关生命周期第 4 态：概念被证据否决，代码+锁组是死重）。**连带**：w868 评分补全包中「应激反应/一鼓作气复用爆发速杀 tag」两条配方一并否决——等战斗时长维度（若做）在 sim 侧立起来再议。
- 「高费/低费审美」不进判死桶的原因：词条方向真实、map 行无害，只是量级不配粒度——删了反而丢失方向信息，归观测。

### 观测（1 组，数据不足）

- **高费队 / 低费队**：留 map 行不删（词缀→tag 透传正确），comp 侧不建模。挂账重审条件（写进 ADR）：①出现费用差异化 ≥15% 的词条；②comp_score 引入连续费用/战力通道使粒度问题消失。届时阈值推导按「决策规则数学先行」补出处。

## 4. 开关与验证面

### 复活项验证设计

1. **L1 单帧锁（必做，sim 无关）**：每 tag 一组 `test_cw_mechanics_fit_tags.py` 用例——构造 GameState（enemy_affixes=目标词条）+ 打 tag comp / 不打 tag comp → 断言 mechanics_fit 方向（打 tag 的 counter 降 / synergy 升，未打 tag 的恒 0.5）。docstring 引出处（README D3 / final 篇名），符合「新锁必须引设计出处」纪律。这是**接线正确性**验证，成本分钟级。
2. **sim A/B（条件可测）**：mechanics_fit 影响 comp_score → select_comp。sim 侧若已向 GameState 注入 enemy_affixes（cw_state.py:220 字段在，注入器待核），则跑同池 batch 对比「选型分布是否在熄火/形单影只局系统性偏移」；若 sim 不发词缀 → 该项挂账「sim 不可测，观测层验证」，不阻塞单帧锁合入。
3. **实机锚点（事后核对）**：开跑前写锚点「含量子熄火简报的局，select_comp 应给希儿线降分/转线」；出现对应词缀的局后按单局复盘核对。复活项属行为语义变更 → 三同步（ADR + as-built 语义 + 注释引 ADR）。

### 判死项清理批次建议

- 单独一个清理 commit：删「爆发机会」synergy 行 + 紧急止血 map 行（或降注释）+ 相关单帧锁（若有锁此行为的）逐个四分类（保留/改写/合并/删除），ADR 记否决理由（本报告 §1.4）。与复活项**分开提交**——复活与判死混在一个 commit 会把「加行为」和「删行为」的验证面搅在一起。
- w868 评分补全包同步收窄（引 W872 角度③修正排序）：只保留已证实成立的「同步行动」（速度抑制有载体 886 行）与「成长的烦恼」（ledger 框架现成）；星级族/减伤族/羁绊依赖族先做各自的 comp 侧 tag 建模设计（本报告同款三问），不许「补 map 行」式空转立项。

## 5. 结论

7 死 tag → **复活 4（单属性队/成型羁绊队/慢速/依赖合成装备）/ 判死 1（爆发速杀，连带否决 2 条下游配方）/ 观测 2（高费队/低费队，1 组挂账）**。关键裁决理由：复活与否由「概念在十类体系真实存在 × 判据可从现有数据推导 × 词条量级匹配 mechanics_fit 离散粒度」三问共同决定——单属性队有玩法文档明文（D3）是最硬证据，形单影只 -70% 是最大量级，而 ±5% 的费用审美配 0.2 步进是量级错配、无战斗时长数据的速杀是无源之水。
