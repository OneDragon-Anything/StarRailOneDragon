# 货币战争-盛会之星

## 画面简介

巨星强化浮层（叠在备战上）：羁绊激活时弹出（非固定节点），选 1 名盛会之星角色当巨星，给全队独特 buff；一局可多次——每次弹出都要重新选，别按上次的选中态跳过。归档帧：金色标题「盛会之星」+ 提示「请选择1名角色成为巨星」+ 候选立绘卡（带「盛会之星—XX」名条与「详情」按钮）+ 右侧「确认选择」按钮与「请选择强化角色」提示。**本卡动作源码挖掘，未经实机走查**（画面形态有归档帧）。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-盛会之星 | 顶部金色标题「盛会之星」（画面身份锚；下方提示「请选择1名角色成为巨星」） | 纯显示 |
| 候选标签带 | 候选名条带（OCR 锚「盛会之星一」= 名条「盛会之星—」短横的误读形态；归档帧如「盛会之星—星期日先生！」「盛会之星—花火女士！」）——候选阵营/身份标签可从这条 OCR 读出 | 纯显示；选中操作点候选立绘本体 |
| 按钮-请选择强化角色 | 右侧「请选择强化角色」提示条（area 名带「按钮-」前缀，实为置灰提示，不是按钮；未选中时在场） | 纯显示（不可点） |
| 按钮-确认选择 | 右侧「确认选择」按钮（约右上确认钮位） | 确认巨星选择、浮层收起；未选中时置灰 |
| 备战标识-购买经验 | 底部透出的备战「购买经验」卡（画面身份锚） | 纯显示（透出的备战元素，非本浮层控件） |
| （待建档）候选立绘区 | 候选立绘居中排布，位置随候选数变化无固定槽位 | 点立绘选中 |
