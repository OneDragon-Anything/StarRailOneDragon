# 货币战争-大厅

## 画面简介

货币战争的入口大厅：左上角玩法名（赛季名随版本变，归档帧为「零和博弈」，旧档「入画奇航」），左侧竖排菜单（创业指南 / 优势布局 / 攻略大全），右侧只读进度面板（晋升等级 / 羁绊链路% / 数据银行% / 预期收益），左下本期剩余时间与积分，右下「开始「货币战争」」胶囊按钮，右上「更新内容」（打开 [货币战争-更新内容弹窗](货币战争-更新内容弹窗.md)）与 ×。从这里开局；结算流末页「返回货币战争」也落回本画面（残留态帧见「大厅-残留态-run49」，与常规态同构，仅角标提示不同）。

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 开局 | MCP `run_operation` | `CwCapsuleDragClick {"screen_name":"货币战争-大厅","area_name":"按钮-开始货币战争"}` | 进入对局开局流程 | 胶囊按钮静态点击不稳，走拖拽点击 op；按钮点了没反应先看有无引导气泡挡住 |
| 进优势布局 | MCP `click` | 「按钮-优势布局」area 中心（识别返回坐标） | 进「货币战争-优势布局」 | 布局动作（选节点、点「布局」）在优势布局画面内操作 |
| 看更新内容 | MCP `click` | 「按钮-更新内容」area 中心（识别返回坐标） | 进「货币战争-更新内容弹窗」 | 查阅用；看完点浮窗的 × 回大厅 |

- 开局：从本画面点「开始「货币战争」」进入对局流程。
- 看进度：晋升等级 / 积分 / 羁绊链路 / 数据银行百分比显示在大厅（只读，无 op）。
- 优势布局（局外成长）：左侧菜单「优势布局」→ 选节点 → 点「布局」（消耗布局代币 ×20；锁定节点需先布局前置优势）。
- 攻略大全 / 创业指南：左侧菜单入口（查阅用，不影响开局）。
- 更新内容：右上角按钮，打开赛季更新说明浮窗（查阅用，不影响开局）；浮窗开着时大厅画面识别不到，点浮窗的 × 关掉再继续。
