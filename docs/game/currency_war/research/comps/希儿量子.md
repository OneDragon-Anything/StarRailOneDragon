# 希儿量子 打法卡(medium / A)

## 打法主线

- 4量子 + 2贝洛伯格(2贝 = 原4贝引擎拉条);斩杀+70% 下二战技+再现+造物引擎。[先验:攻略]
- **前期强势**(希儿无装也能换怪)→ 可当过渡顺势转正;7级找希儿3星 或 先上8/9 找4-5费同时找希儿(两条线,看金)。[先验:攻略]

## 过渡

- 希儿自己就是最强过渡;刃/符玄补位。[先验:攻略]
- 「量子力学」(累计星数额外同频层)/「钢铁美学」(造物引擎400%)在手 = 质变信号。[先验:攻略]

## 装备分配

- 希儿:双高周波电锯 + 火力风暴潮;瓦尔特(杨叔)辅助装。[先验:攻略]

## 入场/退场信号

- 入场:量子同频概念股/邀请;持「量子同频星徽套组」(送希儿+反重力皮靴);前期希儿连出(板已有 ≥2 量子)。[先验:攻略]
- 退场:剧目/蕉研组 boss 克制。[先验:攻略]

## counter

- 克我:剧目/蕉研组 boss(蕉研组开局 = 直接重开的量级);应对 = 转线或提前保血。[先验:攻略+社区:plaza 帖文]
- 利我:量子拉条机制对速度抑制部分免疫(再动)。[先验:攻略]
