## 全局规律(十类深读后的完整总结;按主题分组)

### A. 选型门槛与加分(bot 视角,硬约束优先)

- **A1 局外依赖=排除项**(r176):阵容对角色属性/装备/星魂有特殊
  局外要求 → 不入选策略库(试用账号零达成)。已触发:姬子类局外速度
  灰档、万敌#38(1魂)/#35(6+5)、希儿#32(攻击鞋充能绳风套)、
  DOT#13(卡芙卡本体+风套)、圣杯#76(6+5)/#29(凛高配)。
  **反向:全试用可玩的类=DOT/绯英/大黑塔(38篇全试用)——低门槛首选档**
- **A2 自动战斗适配**(r182):自动化注定自动战斗。多篇独立报告同一
  缺陷才排除(当前无);观察级:圣杯拉条目标(#14 类)。
  **正向档(挂机/轮椅标记 50 篇):盾反姬子/万敌/白厄/DOT——
  共同点=伤害不依赖我方技能时机(反震被动/DOT敌回合结算)**
- **A3 开局信号分层**(十类归纳):
  ```
  策略驱动(最强):圣杯契约(固定红A)>圣杯星徽>黑塔纪元(32/38)>
    罗刹开局(改变三月七身份)
  类专属策略:量子力学/钢铁美学(希儿)/骇客专家银狼/超光速提拔(万敌)
  核心卡到手:姬子/希儿/绯英/黄泉(单卡即战力型)
  资源信号:万敌7只判据/银狼升费资源/白厄可得性
  无信号兜底:DOT2 起手/欢愉通用开局(绯英线)——门槛最低
  ```

### B. 阵容结构规律(怎么搭)

- **B1 CARRY 的三种驱动型**(十类归纳,决定装备/站位/节奏):
  ```
  大招流(能量循环):姬子/黄泉/大黑塔/绯英/Saber——装备=充能件
    (永动机/蓄能帆/电光履)+风暴潮;站位自由;节奏=D三星
  受击流(被动结算):万敌(受伤充能)/白厄(反甲)/盾反姬子——
    装备=反甲/热量+盾供给;吸伤害位互斥(符玄分摊 vs 独占前排);
    词条依赖(敌方多动=燃料)
  行动流(多动叠层):希儿(拉条链)/银狼(升费)/Archer(战技点)——
    装备=速度件(靴/风扇);拉条链即输出
  ```
- **B2 双C结构常见**:姬子+三月七(领航员)/圣杯 Saber→Archer 接力/
  黄泉+不死途(充能对)/绯英×银狼(星魂分流)/卡芙卡×黑天鹅(叠层×引爆)
  ——主C+副C 的关系类型:接力型/互补型/备份型
- **B3 领航员是身份级绑定**(与站位无关,板凳也生效):绑谁=复制谁的
  装备+吃谁的羁绊效果——三月七(盾反)/饮月(电锯)/瓦尔特(永动机)/
  开拓者(欢愉虚数)/刃(特权);**且是时间函数**(前期保命绑三月,
  后期输出换绑老杨/开拓者)
- **B4 星徽(转职徽章)是微调万能件**:换徽章≈换副羁绊;驾驶员选择
  是显式决策(贝转给刃/刻律/不死途;DOT转给阮梅);满编后期辅助位
  人手 1-3 个星徽堆羁绊虚数
- **B5 副羁绊可替换**(万敌篇明说):核心 CARRY 固定,副羁绊组按
  来牌灵活(群攻3↔减益2+量子3+盛会2)——final comp 不写死
- **B6 生存位的标准答案**:符玄(分摊+免死,出现率 407/784)≥
  罗刹/娜塔莎>藿藿(仙舟兼);装备=绝对热量(保人刚需件)
- **B7 通用辅助骨架**:瓦尔特(推条+延后倒计时,529/784 第一) +
  星期日(拉条+蒙福者)+花火(战技点/拉条)+开拓者(双形态切换)——
  跨类通用四件套

### C. 装备规律(怎么做)

- **C1 风暴潮是全场通货**:几乎每个输出位都吃(希儿64/姬子325/
  卡芙卡风暴潮×3/银狼86)——「叠层型」输出件的垄断地位;
  对应合成材料(小刀/电池/鞋)永远不嫌多
- **C2 A/B 双套语义**:B=第二配装方案——生存备选(姬子三月七)/
  流派特化(击破全套)/特权升级版(白厄反甲)——读 A+B 才完整
- **C3 装备的显式时序**:生命之环前期给万敌→双奶瓶后转移;
  姬子装备先给罗刹三月七(领航员复制);「合完核心件再想其他」
  (多篇共识的优先级语言)
- **C4 特权装备体系**:特权阶级环境+千冶·刃(打造装备技能)是
  特权化主路径;白厄 B 套特权反甲=满编后期的常态

### D. 节奏与运营规律(怎么打)

- **D1 D 牌节奏锚点**:7级 D 三星核心(姬子/希儿/万敌/黄泉/卡芙卡
  通用);6级 D 三星(绯英/万敌低费版);**大黑塔反常识——压等级
  猛 D 一费**(备战席经济学)
- **D2 降级路径每类都有**:姬子没3星→杨叔主C;卡芙卡没3星→鹅卡双C;
  白厄搜不到→转姬子线(类间切换预案);**没有降级路径的线不选**
- **D3 词条矩阵是开局前置决策**:正吃(反震/万敌吃敌方多动类:
  忍无可忍/正当防卫)与硬 counter(希儿怕量子熄火/圣杯怕满愿/
  DOT 怕风套缺失)——**读词条决定开哪条线**
- **D4 counter boss 清单**:红绿灯(反甲系)/扑满(拖时间)/死龙/
  酒杯怪/电视机/存护星神/蕉研组——遇之换线或重开
- **D5 多余人口四方案**(r170):联动前替代/赌专家/双C/后台辅助
