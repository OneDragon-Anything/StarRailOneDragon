## 结论（阻断）

**阻断**：2 阻断 + 4 中 + 4 低。两个阻断项：

- **S7-1**——净腾校验式（六轮 S6-3 处置「式入正文」的成果）**方向反转、不可实现**：正文式「虚拟定型后 bench 占用 − 当前 bench 占用（全效应合计）≥ 1」在 canonical 成功形态（席满 9 → 卖 V → 提升 1 件 → 买 X → bench 仍 9）下恒为 0/负 → **核心校验恒拒、意图槽机制整体空转**；唯一能让式子取正的形态是「净上移 0 件、板面越腾越满」的退化形态。同时双源声明的必然性论证「卖 V 腾场位 → 搜索补位上移 → bench 空 1，**不依赖 X**」在 **bench 无可上者**形态被证伪：含 X 虚拟定型的唯一上移者就是 X 自己（自举），无 X 执行搜索无人上移 → 校验假阳性 → 白卖一轮 + 重评再选下一个场上件 → **S3-1③ 要防的「逐件卖光场上件」经校验盲区回魂**。S6-3 的「已修」= 把 D5-7 处置记录里的原式（为无 X 语境写的）搬进正文，载体换含 X 后从未重推。
- **S7-2**——「bridge 出战就绪短路不触发」（:69② 括号断言 + 五轮 S5-8 处置原文）是**无机制支撑的裸断言**：`_launch_front_check` 在十段扫描之上、每次 decide 先行（bridge.py:237-239）；armed 翻转帧上 StartBattle/OpenShop 先于前置步发出——级联半途弃置（V 已卖、X 未买、板面半换）或完成帧被短路（清槽/开店步永远不跑、槽带级联态死到节点边界）。可达链完整：质量推迟帧（配方完备 ∧ 板面非零线外件 → armed=False → 扫描照跑、商店不受限）正是「线已成形但板上有线外件」的节点——线外场上件恰是统一序末位 victim 的主力来源；级联把最后一件线外件拖下场 = load_bearing_full 翻转 = 下一 decide 短路。「级联未完成不出战」（S5-8）只在扫描内（第 9 步）成立，跨层短路无任何设计机制（改动点清单无 bridge 项）。

## 发现清单

### S7-1｜净腾校验式方向反转不可实现 + 双源声明「补位上移不依赖 X」被 bench 无可上者形态证伪——S6-3 处置把为无 X 语境写的式子搬进含 X 载体，意图槽核心校验按正文落则恒拒、按直觉落则假阳性放行「逐件卖光」
- 攻击点：三个子面：
  **① 正文式在 canonical 成功形态下恒假**。席满场景（bench 9 满，这正是「席位受阻」的定义形态）：虚拟阵容 = 9 + X；虚拟定型把 V 的场位交给某 bench 池件（含 X 自身）→ 虚拟定型后 bench 占用 = 10 − 净上移数。canonical（净上移 1，无下场无合成）：10−1 = 9；正文式 = 9 − 9 = 0 < 1 → **拒**。而该形态的真实结局成立：卖 V → 无 X 搜索提升同件 → bench 8 → 买 X → bench 9。含合成（X 与同名合成释放 1 席）：10−1−1 = 8 → 式值 −1 → 仍拒。式子取正 ⟺ 净上移 ≤ 0 且下场步 ≥ 上移——恰是「板面越腾越满、bench 不腾反占」的退化形态。**方向反转 + 含 X 的 +1 基线未扣除**，任何按正文字面实现的校验都会让场上件 victim 全部作废（机制空转），而实现者「显然该」翻成的方向（当前 − 虚拟后 ≥ 1）在含 X 载体下同样错（canonical 算 0）——必须再减 X 席位（当前 −（虚拟后 − 1）≥ 1 ⟺ 真实件净上移 ≥ 1）才自洽，这一步正文完全没有。
  **② 必然性断言被证伪（任务点名攻击面）**。双源声明：「净腾机制层同源：卖 V 腾场位 → 搜索补位上移 → bench 空 1，**不依赖 X**」。bench 无可上者形态（详设 :14 枚举硬约束——上阵窗口/上场锁挡尽全部 bench 件，S3-1③/S4-3 两轮点名的反例形态）：含 X 虚拟定型的**唯一上移者就是 X 自己**（自举——X 可上场而 bench 件全被挡）；按①的修正式「真实件净上移 ≥ 1」计为 0 → 该形态本应被拒；但按设计选定的含 X 口径，X 的上移计入净腾 → 校验**假阳性通过** → 执行端（无 X 搜索）无人上移 → 场位空置、bench 不腾 → 级联 diff 空「完成」→ 开店 → X 仍席满受阻 → 重评选下一个场上件 → **白卖一轮 + 逐件卖光场上部署外件**——S3-1③ 设校验要防的行为经校验自身的口径缝隙回魂；victim 黑名单防不住（victim 卖出成功、自然出池）。四轮 S4-3① 把「级联恒可达」改为「可达性由虚拟级联校验判定」——校验器的判定式正是本轮断点。
  **③ 效应枚举仍缺**。「全效应合计」含哪些效应（卖 V 退金计入何处？升星连锁释放 ± 几？定型外场上件下场 +1？）S6-3② 攻过、处置只搬式子未列效应——即便方向修对，实现者仍需自行定义每一效应的符号与计数。
- 证据：design.md:68（正文式 + 双源声明）；attack-deploy-round5.md:68-69（D5-7 原攻击·无 X 语境）/ :133（原式出处）；详设 unified-deploy-order.md:94（「target = 当前搜索定型」= 无 X 执行口径）/ :14（窗口/锁硬约束——bench 无可上者实存）；cw_launch_admission 无关、核在本条的设计文本推导
- 严重度：高｜阻断级：**是**（核心校验谓词不可实现：字面落 = 机制整体空转，直觉落 = 假阳性放行规模变卖；修复需设计内重推式子并效应枚举，非落地批可自行裁定）
- 处置建议：净腾式重写为可计算版本并给 canonical 数值例——建议「真实件净上移 ≥ 1」：当前 bench 占用 −（虚拟定型后 bench 占用 − 1〔X 席位〕）≥ 1，效应枚举（上移 −1/下场 +1/合成释放 −1/其余 0）入正文；bench 无可上者形态按此式正确被拒（是否接受通过率收紧请申报）；或校验的净腾部分改用无 X 定型推演（S6-3 未选的方案①，与执行同源、无自举盲区）。
