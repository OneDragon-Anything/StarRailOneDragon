# W921 · R-D 根设计：姿态-执行断裂的统一设计（预算-回执契约）

> 承接：W908 审查 R-D 归并节（成员 13-2/20-5/20-7）；考证半件 = 同目录 REPORT.md（病灶证据/分叉机制/v6 输入面考证，本设计不重复取证，只引结论）。
> 模型边界：W684 DESIGN v6 反补丁退出协议生效——本设计**不设 v7、不改 P_t 模型本体**，全部增量表述为 Π_t 供给算子与辖域通道位的既有结构扩展；全帧类的断裂收拢走独立契约件（本设计），死亡窗与危机帧由既有实例承载（§3）。

## 0. 一行结论

姿态-执行断裂的根在契约层：姿态是「无回执的单向许可」。统一修法 = 立**预算-回执契约**——姿态层输出带预算与成立前提的支出授权，执行层消费后必须按渠道回执（花了什么 / 为何没花），对账门在「授权未兑现」时执行三选一：替代消费（分配器/release 通道）、姿态降级、显式声明归档。死亡窗分配器（ADR-0474）与危机 release 臂（ADR-0503）是同一契约在两个帧类的既有实例，本契约把它们一般化到全帧类，不重造其通道。

## 1. 断裂收拢的契约面（统一设计本体）

### 1.1 三段契约

```
姿态层(授权方)                执行层(消费方)                 对账门(闭环方)
Posture+支出授权包    ──▶     逐动作过滤管线          ──▶   授权-回执对账
(SpendAuthorization)          (层1-层4 现状不动)             (本设计新增的唯一新机制)
```

**A. 姿态层输出（授权包，改造 Posture 载体而非另立）**——现状 `Posture(save/level_up/refresh_budget/v/tag)` 已是半个授权包，缺三样：

1. **前提位**（`premises`）：每项授权带成立前提枚举——升级授权的前提 = pop_slot（bench 有等待件 ∨ cap 有空位）；刷新授权前提 = 执行通道存在（该节点类型的商店循环已接线）；前提不成立的授权**在产出侧就不发**（治 13-2 的「判升级但无 slot」与 20-5 的「无通道帧照产授权」）。
2. **买侧预算位**（`buy_budget`）：奖励节点扩张档（[1]/[15] 已证语义）与储备段溢余段（ADR-0463 O1 通道已有账）的买侧预算载体——现在 Posture 只有 level_up 布尔与 refresh 整数，买侧无授权面（治 20-7 的语义缺位）。
3. **授权号**（`auth_id`）：轮内唯一，供执行回执与遥测对账挂接。

**B. 执行层回执（SpendReceipt，新数据面，不改过滤逻辑）**——决策主链出动作后，按渠道汇回执：`{buy: 金额与笔数, levelup: …, refresh: …}` 或每渠道的「未兑现原因」枚举：

```
no_premise(实体前提不成立) / no_channel(节点无执行通道)
/ no_candidate(候选全滤空: 附滤光原因 Top1) / no_budget(授权预算 0)
```

现状 `pipeline_spent` 布尔门（strategy.py L486）是一般化前的二值残形，回执是其替换面；`equip_alloc_empty_reason`（C3）已证明「未兑现原因枚举」在本仓有先例与判读价值。

**C. 对账门（授权-回执对账，唯一新增决策机制）**——每轮收口一次，判定 `授权 ∧ 回执`：

| 授权 | 回执 | 对账动作 |
|---|---|---|
| 支出授权 | 已兑现 | 无动作（记录） |
| 支出授权 | 未兑现，辖域落死亡窗/停手窗 | 交分配器（既有 allocator_run 接管，现路径不变） |
| 支出授权 | 未兑现，危机帧 ∧ 溢余>0 | 交 crisis release 臂（ADR-0503 既有通道） |
| 支出授权 | 未兑现，其余帧 | **降级姿态 + 显式声明归档**（tag→'存息'附 reason；写遥测 `posture_unfulfilled`），**不在常规帧新造消费通道**（理由见 §4 不做什么） |
| 无授权 | 已大额支出 | 无强制（执行层 EV 越过姿态是合法面，息档门已辖） |

对账门是**记账+降级**机制，不是新的花钱通道——「13-2 修法=执行一致性门（dp 判花→动作层必须消费或显式声明无可花处）」的 W908 原文语义，兑现为「显式声明」而非「必须消费」，与 [18] 口述权威（hp 低不是 ALL IN 触发）不冲突。

### 1.2 为什么收拢面在契约层而非某一层内

- **病灶三面分别落在姿态输入（前提缺）、姿态词汇（买侧预算缺）、执行输出（回执缺）**——任何单层内修只能盖住一面（这正是 31 条候选里「各修一头必打架」的成因，W908 对 R-A/R-B 同判）；
- 数学上：姿态层是「日程核在任意帧恒有定义」（ADR-0465 D0），执行层是「逐提案独立出清」——两层的定义域不相交，**没有中间量**把「授权」与「兑现」绑在一起；契约层的对账门补的正是这个缺失的中间量。

## 2. 逐设计决策三件套（病灶证据 / 命题依据 / 标定路径）

### D1 授权包加前提位（premises），前提不成立在产出侧拒发

- **病灶证据**：13-2 p2r4 dp=升级但板满∧板凳空（复盘 §p2r4）；F4 boss 前空升级同判据面（pop_slot 前提未校验，[32] 消费有效性门明文）；W908 §13-2「真实病灶是姿态-执行断裂」。
- **命题依据**：[32] 消费有效性门（空 cap 支出拒绝，economy §10 全程通用）；F4 审查裁定的正确锚=[32] 而非 P35（小档升级不受停手窗负判辖，P23 §适用边界）；实体前提作为 Π_comp 前置边（buy→lu）的否定前提，是 W684 v6 §2.1 交互边集的既有结构扩展，非新机制。
- **标定路径**：零新常数（前提=既有单一源符号：bench/cap 现读）；验证=单帧锁「板满∧bench 空 → 无升级授权发出」（对 13-2 p2r4 形态）+ 回放 13-2/局20 核对授权面逐帧复算。

### D2 买侧预算位（buy_budget）：奖励节点扩张档 + 溢余段账

- **病灶证据**：20-7 p1r1/r2 只买 3 人（复盘 §p1r3「供给转化太慢」）；20-5 r5/r8 金滞留同根（审查自注）。
- **命题依据**：[1]/[15] 已证（奖励节点保息多买压库）；[22] 囤牌账（5 费级才强）为剂量上界；ADR-0463 义务清单（O1 备战填补>O2 目标件>O3 排程升级>O4 刷新）是预算分配序的既有单一源——buy_budget 是把该义务序里买侧的量显式化，不立新序。
- **标定路径**：扩张档预算量**不拍死**——以「压库费用档 × 奖励节点剩余窗口」从 [1]/[15] 账式推导，量级经 sim A/B 敏感度扫描定（strategy-work §4 参数精调判据：弹性大才实机精调）；与 [16] 扑满例外联动（经济过热环境奖励节点变扑满 → 轻投入纪律 P8）按环境分支。

### D3 执行回执（SpendReceipt）+ 未兑现原因枚举

- **病灶证据**：三案的共同形态「检查器报『钱变不成板』但无归因」——判读只能事后人肉回放；C3 的 `equip_alloc_empty_reason=unknown` 是同型观察债（已定谳要补分类）。
- **命题依据**：观察面无数学命题，判据=telemetry-reading「观察面全量」的完备性要求（未兑现原因必须可从遥测直接判读，禁止事后回放归因）；W908 §13-2 修法原文「执行一致性门……或显式声明无可花处」。
- **标定路径**：枚举集以三案回放实测为准先定四值（no_premise/no_channel/no_candidate/no_budget），新形态先入 unknown 再定谳增补（沿用 C3 处置先例）；锁面=sim 构造帧逐枚举触发。

### D4 对账门：替代消费走既有实例，常规帧只降级+声明

- **病灶证据**：13-2 p2r4（死亡临近帧 0 花 → 次轮死）；W907 危机局金 27→180 零兑换（ADR-0503 Context）——「授权悬空帧金静默滞留」跨帧类复现。
- **命题依据**：死亡域放行=P23.3/P23.4 已证（金零值近似下 Δp·L_c+w>0 提案严格优于攥金，ADR-0493 重标定后参数集 P23.4R）；危机帧=ADR-0503 义务模型（「存是为了关键时刻能花」）；常规帧**不放行强制消费**——[18] 口述权威（最高级证据，ADR-0482 权威序）明文「hp 低不是 ALL IN 触发，是运营质量报警」，且 P13 息律下常规帧金有正机会成本（c+I），强制清仓无证明支持。
- **标定路径**：对账门零新数值常数（辖域谓词全部复用既有单一源：is_emergency/overflow/分配器 D 谓词）；A/B 主判据=「授权未兑现帧占比」下降 + 出口 hp/残金分布不劣化（过程量方向，末端量验收，strategy-work §4）；13-2 p2r4 帧是否落分配器辖域以 `v3_alloc_frame` 回放核（REPORT 证据缺口）。

### D5 v6 增量输入 I1-I4：并入分配器供给面，不动 P_t 本体

- **病灶证据**：REPORT §3.2 核实——分配器辖域外帧类（20-5/20-7）不受 v6 管辖；辖域内帧缺实体前提/姿态预算输入。
- **命题依据**：I1-I4 逐项核验为既有模型结构的扩展：I1=Π 三元组 c/m_eff 的输入同源化（W684 v6 §2.1「帽与预算=R 的分量」的自然延伸）；I2=前置边的否定前提（交互边集既有结构）；I3=D 的通道位（辖域谓词输入扩展，§0 核实③「记录通路+断言核验」同法）；I4=`pipeline_spent` 门的一般化（接线帧归一化金流守卫 FM-A6 口径保留）。反补丁退出协议核验：无一改动 O 的量纲/出清算子/D 的谓词定义式——**不构成 v7**。
- **标定路径**：I1-I4 随分配器实施批判前重放定量（W684 §4-P4 判前管线截面重放通道）；帧类覆盖率以探针辖域帧统计（ADR-0474 验证同法：196 辖域帧接管 7 的统计口径）。

## 4. 「不做什么」清单

1. **不新立 hp 阈值强制清金**（13-2 原修法已被 W908 打回；25 为拍死值，违反数学先行硬门；[18] 权威冲突）。
2. **不动 P_t 模型本体 / 不设 v7**（W684 反补丁退出协议；I1-I4 均为供给面与辖域输入扩展，§2-D5 逐项核验）。
3. **不在常规帧新造消费通道**：对账门常规帧分支只降级+声明，不兜底花钱——常规帧强制消费无命题支持（P13 息律机会成本为正），且会造出「把花变倒」的语义（ADR-0503 已否决同型选项）。
4. **不重造指令通道**：危机/死亡窗替代消费全部复用 ReleaseDirective 与 allocator_run，禁第二通道。
5. **不给姿态词汇表加离散动作码**（词汇表 v2 已退役离散码，`w623_batch3_pre-mortem/` D2：连续值域形状）；扩张档用预算数值不用新 tag。
6. **不修供给节点执行通道本身**（R-F 辖域；本设计只定义 no_channel 契约位）。
7. **不引入新开关**：对账门内记账+声明部分为纯观测+降级（行为面=姿态 tag 变化，须走开关生命周期第 1 态默认关落地——开关一个：`spend_receipt_gate_enabled`，开臂判据挂账见 §5）。

## 5. 验证设计与标定路径（汇总）

**验证阶梯**（strategy-work §4，全部走既有阶梯，无新工具）：

1. **单帧锁**（sr-od-test，构造 GameState+StrategySession）：
   - 授权包锁：板满∧bench 空 → 无升级授权（13-2 形态）；无通道节点 → 无支出授权（20-5 形态）；奖励帧 → buy_budget>0 且随窗口衰减（20-7 形态）；
   - 回执锁：四枚举各一构造帧触发；
   - 对账锁：授权未兑现 → tag 降级 + `posture_unfulfilled` 遥测字段；开关关零漂移。
2. **行为漂移**：`cw_replay --diff`（秒级）看首发分歧点——预期分歧只在「授权未兑现帧的姿态 tag 与声明字段」，无动作序列漂移（对账门不开臂时零动作差异=设计声明，diff 可证伪）。
3. **sim A/B**：同池同 seed（W910 后确定性语境已恢复：跨进程 digest 8 进程逐位一致、A/B 对照跨该修复后不受历史重锚影响——同 commit 内 A/B 不受 §五影响面条款波及）；n≥300/臂，判前锁定主判据=授权未兑现帧占比下降 + 死亡域兑换率（与 ADR-0503 §5 主判据同口径，开臂后两判据可合读），次要=出口残金中位/存活率不劣化；**线跑前写死**。
4. **实机验收**：连续多局达标（当期目标判据），锚点事前写=「dp 判花帧的滞留金占轮均金比下降」；判读消费 `posture_unfulfilled` 枚举分布（no_candidate 的 Top1 滤光原因直接喂 R-B 定价件）。

**标定路径汇总**：本设计零新数值常数（D1 前提=现读符号、D4 辖域=既有谓词）；唯一待标定量=D2 扩张档预算量级（推导式 + sim 敏感度扫描，弹性大才实机精调）与 D3 枚举集扩充（实测驱动）。

## 6. 立项形态建议（编排者裁量输入）

1. **形态**：一个根设计件（本文件）+ 两个实施批：
   - **批 1（契约面，小件）**：Posture 扩展（premises/auth_id）+ SpendReceipt + 对账门（开关默认关）+ 遥测字段 + 单帧锁组。零分配器/零 release 触碰，独立可 A/B。
   - **批 2（v6 输入 I1-I4，随分配器实施批合并）**：归 W684 实施批判前重放通道，不独立排期（反补丁协议：分配器结构性可靠即设计毕，经验问题迭代里修——I 系列属输入面补全，按此归位）。
2. **排期接口**：批 1 与 W917（危机臂 A/B）并行不相交（对账门危机分支以其开臂为前置，代码上只读其开关）；与 R-F 行为批共享 20-5 回放证据，先到先得、互不阻塞。
3. **ADR 归位**：批 1 落地时立 ADR（决策 why=本设计 §1-§2）；strategy as-built 正文增「预算-回执契约」语义节（值只写常量名）。
4. **验证义务声明**：批 1 提交前 L1+cw 域受影响点名；全量 L3 仅 commit 前；改 Posture 载体前 grep 消费点与锁组预盘点（arbiter/scoring/posture_release/telemetry 四消费方 + posture 词汇表判前锁）。
