# 货币战争-优势布局

货币战争的**局外强化树**(元系统):对局外用「幻乐晶球」激活天赋节点,效果在之后的每局对局中生效。用户口语中的「强化/激活系统」「1 血免死」曾归到本系统一个登记为「保险机制」的节点——r13 定向核查定谳(帧 2026-11-20 030648~031105):**节点在场、已布局**——位于赛季优势树横向滚动后的第二段屏幕最右(带框大菱形 ≈1855,528),分类「附加机制解锁」,官方三段文案三帧稳定实拍(§4.2 逐字);此前「当日存在后被官方移除」「树中无此节点」定性作废——依据 = 树为横向多屏布局(§2),当时全扫拖拽失败未到达第二段(漏扫勘误见 §2/§5)。**节点已布局但 6 个 HP 归零样本全部直终局无一触发——触发矛盾维持开放(三候选并列,§5)**;bot 口径 = 归零按终局流程走(§5,挂账板 ⑲l/⑲p)。分两区:**赛季优势**(每赛季重置)与**常驻优势**(完整保留)——与官方命名一致。

## 1. 何时出现 + 状态流转

- **入口**:大厅左侧菜单「优势布局」(screen_info 已建 `按钮-优势布局` area,goto 本屏)。
- **出口**:右上「返回」箭头 → 大厅(`按钮-返回` template area,goto 已建)。
- 画面内两页签切换:「常驻优势」/「赛季优势」,树各自独立、坐标同构。

## 2. 系统结构(实测)

- **两棵树**:
  - **常驻优势**:跨赛季永久,本号已全布局(节点全亮、详情按钮「已布局」)。r13 全扫口径 = 12 节点:根节点战前动员 + 数值 7 + 机制 4(长线作战/简易武装/策略刷新/额外补给)。
  - **赛季优势**:本赛季(入画奇航)专属,每赛季重置;「已布局优势 1/40」计数器只在本页签显示,40 = 赛季树节点总数,起点菱形默认算 1。
- **树为横向多屏布局,拖拽滚动查看**(约 40 节点;拖拽方向:向左拖 = 看右侧深处)。**树页分段(r13 定向核查实证)**:第一屏 = 根段(起点/生命强化/暴伤减免等前期链);拖拽后第二段(中后段) = 理赔业务/光环优选/钻石闪耀/深层数值节点;「保险机制」带框大菱形在第二段屏幕最右(≈1855,528)。**拖拽手法(成功实录)**:起拖点必须在树区空隙(如 (1500,620))——抓到节点会变「选中」不滚动;落点避开底部详情面板区;参考向量 (1500,620)→(300,620),duration 1.5;多屏树页逐屏拖扫取证。「约 2.4 屏宽」为 2026-11-19 读数,当时拖拽未稳定到达第二段,宽度数据存疑待复核;早期「约 4 屏宽」估计同因作废待复核。
- **激活消耗（实测分档）**:小节点(数值强化)×20;「附加机制解锁」大菱形 ×60(风险对冲/主角重选/全盘刷新;钻石闪耀/理赔业务/光环优选/保险机制——r13 全扫「赛季树三机制节点」口径作废:全扫拖拽未达第二段漏扫,在场清单见 §3 中后段与 §4.2 末行)与 ×100(大胜表彰,历史实读;保险机制 ×100 = 独立节点本体消费,记账无错位,节点在场已布局见 §4.2);画面按钮字面为「×N 布局」,右上角计数即幻乐晶球余量(来源含晋升等级奖励;**晶球余额仅本画面右上角 (1650,45)-(1810,85) 显示,大厅无余额显示位**——大厅右上角数字 = 晋升等级,别归错主)。锁定节点按钮显示红字「请先布局前置优势」——需先激活前置链上的节点;**锁定态不显示费用**,须先解锁前置才可见费率。

## 3. 激活路径链(goto_list 语义)与操作口径

大厅 →(点左侧菜单「优势布局」)→ 货币战争-优势布局(默认赛季优势页签)→ 点节点看详情 → 点右下「布局」按钮激活。切树点顶部页签。
