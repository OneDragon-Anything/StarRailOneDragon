# ADR-0576: P72 全段预算闸落码(升级支出量闸全段化 + 检查器三处对齐)

## 状态:已实施(T-63/T-79 落码批;commit 待编排者统一门)

## Context(为什么改)

P71-b 溢余段预算闸(ADR-0560)的辖域限定 `g ≤ g* 空过` 被实证打穿:
「义务买牌先花钱 + 逐击发射」组合在同一商店访问内把金先花到息线下方再
逐击潜行(T-93 ci_smoke 活跑 18/25 局红的三分类之一 = 签名 A 真洞,30 局
插桩 20% 局息损潜行;诊断与插装重放证据 = fix_p71_bypass/方案设计.md §2)。
另两类红 = 检查器假阳性(签名 B:检查器读账本 `state.cap` 部署人口 cap 当
息帽推 g*=40~90;签名 C:生产闸与检查器都缺 ALL IN 位面末 boss 节豁免支)。
P72(docs/develop/sr_od/application/currency_war/proofs/p72-full-band-budget-gate.md,已过审
T-81)作为 P71-b 辖域的全段推广证明在库,本批落码并同步检查器。

## 决策(Decisions)

1. **生产闸换装 P72 (3a) 全段强读式**(`criteria/levelup.levelup_budget_gate`):
   `g − s ≥ 10·τ(g) + ρ + Σ预留`,τ(g)=min(⌊g/10⌋, cap_resolved) 经 kernel
   `interest()` 单一源直消费;删 `gold <= g_star` 空过分支。退化一致性
   (证明 §1):g > g* 帧逐字退化回 P71-b (3),溢余段零漂移;中间段从
   「不辖」改「息档零侵蚀 + 购买力保底」。拒 = 整批推迟语义不变。
2. **ALL IN 豁免支新增**(P72 §2.5):位面末 boss 末战帧 R=0 机会成本恒零,
   闸前提不成立——`plane_last_battle` 单一源,与 (2) 血面豁免同谓词同帧
   (禁「(2) 豁免了 (3) 还拦」分裂);闸签名新增 `session`(nodes_of_plane
   真值链),三发射位(shop M3 / shop 必花域 / mandate prep)与 entry posture
   镜像四处调用同步。
3. **支A 兑现链放行落地**:板满 ∧ bench 有 2★ 等待件 ⇒ 放行——谓词与
   `schedule_upgrade` ①臂 / `_upgrade_ul_threshold_ok` ΔV_pop 指示项成
   同步锚对(同一 P39 指示项第三消费位);全段化若缺本支,arm1 帧会被
   量闸否决存在性(违 P39 ②「骨架义务 M3,arm2 无权否决存在性」)。
   (支A辖域声明,ADR-0589 落库批补:豁免谓词**节点无关**——奖励帧
   同样适用,与 ADR-0580 奖励帧升级抑制意图的策略张力归策略域候裁
   行,非 ADR 层裁决;sim 侧该张力可观测性系于决策帧 node_type 可见
   性——生产侧 = ADR-0587 台账制,sim 侧 = 可见性批;检查器面 =
   ADR-0589。)
4. **P39 接缝处置(核对点 B,本 ADR 核心)——承担项换位 + 缺位挂账**:
   (3b) 数值完备账支(`ΔV_band ≥ s + L + 尖括号欠账`,C_realize=0 帧)
   **不落码**——math_proofs P39 明载 ΔV_band「窗口前提证伪的重锚未完成
   ……禁单独作闸门」,该支在 C_realize=0 帧的收益侧承担项正是 ΔV_band
   独自,落码即以边界带未裁决量作决定性闸门。替代构造:全段化放行域由
   (3a)(注册表量)∪ 支A(零标定构造谓词)承载,证明辖域内其余帧
   fail-closed 推迟(缺支B 只收窄放行域、永不放宽;防恒拒由 (3a) 开局
   结构性宽松承载,证明 §3)。**支B + 支A②支(has_deployable 部署面
   接线)挂账**:owner=编排者,期限=一个对局周期(01 §6 三要素 3 /
   01 §8-2 硬时限),裁决载体 = P39 sim 对拍项 2 + P72 §5 边界 3/5
   观察族;登记位 = 01_math_framework §7 钩子表。
5. **检查器三处对齐**(`sim/checks/ledger.check_levelup_budget_gate` 重写):
   - g* 单一源:息帽 cap_resolved 缺省口径(kernel 单一源),禁读
     `state.cap`(签名 B 根因);
   - 金基准 = 决策帧现读金:自 waves[0] gold 逐动作重放净额(动作行
     cost/income 单一源),逐击判定(签名 A 观测面修复);
   - ρ 名册:生产 k_members 同源解析(过渡配方标签走 `pair_target_comp`
     + `predicates.line_members`,D3 修复);
   - ALL IN 豁免镜像:位面末 boss 节,位面长度由本 run rows 现推
     max(round_num);支A 镜像同谓词;reward/supply 豁免承继。
     (后继修正:支A realize 改按击读引擎披露的决策帧真值,行末快照
     自此仅辖无披露键账本回退——ADR-0589。)
6. 契约锁(`contracts.CONTRACTS[('levelup','levelup_budget_gate')]`)辖域
   与锚更新指 P72 + 本 ADR(前提谓词 gold+cap 在场不变;ALL IN/支A 在
   判据体内自判不另设前提)。

## Considered Options(替代方案与否决理由)

- **检查器豁免登记了事**:3 处真洞是真实息损病灶,豁免 = 放任;且 D1
  修正后豁免清单随等级动态变,不可维护(方案设计 §3.1 否决,承继)。
- **只修检查器不动闸**:修完 D1/D2 后真洞帧照报 → 被迫走豁免 → 同上。
- **(3b) 数值支随批落码**:P39 边界禁令在案(ΔV_band 窗口前提 A2
  证伪未重锚、边界带结论 sim 对拍项 2 未裁),C_realize=0 帧 ΔV_band
  独自承担收益侧 = 以未裁决量作决定性闸门,违 P39;否决,换承担项
  构造(决策 4)。
- **(3a) 弱读式**(允许蚀一档):破坏 (3a) 溢余段逐字退化回 P71-b (3)
  的退化一致性(证明 §5 边界 5:强读由退化一致性唯一选定);否决,
  强读落码,强/弱分岔留 sim A/B 观察族。
- **支A-② 单独先行接线**(has_deployable):谓词真源在 kernel,但闸+
  检查器双面重建部署语境的离线镜像面缺观测键,单独接线会造成生产/
  检查器评价面分裂;随支B 同批落码(决策 4 挂账)。

## Consequences(后果)

- 行为面:中间段升级批从「空过放行」改「逐帧管账」——sim 预期升级批
  推迟、息损潜行清零;ci_smoke `levelup_budget_gate` 检查项回归 0 容忍
  (T-93 验收线:违规面 18/25 局 → 复绿;不收敛 = 闸修复不彻底观察键)。
- 必花域闩延命残金帧(ADR-0528)的发射语义被全段化取代(残金帧落入
  中间段辖域,拒=推迟);闩的显影分键(帧绑定)不变。既有锁按存在性
  纪律重推:test_cw_l3_prep_must_spend_latch 2 例、test_cw_p71_budget_gate
  整体重推(旧「g≤g* vacuous」锁语义随批作废,docstring 记录出处)。
- 新锁:全段判据锁(73002 退化/签名 A 真洞形/开局防恒拒/贴线边界)、
  ALL IN 豁免锁(纯函数+检查器镜像+发射面同步)、支A 兑现链锁、检查器
  三处对齐锁(D1/D2/D3)、契约锚锁。
- 挂账:支B + 支A②(01 §7 钩子表登记,owner+期限见决策 4);
  词缀局血面口径缺口(P72 §5 边界 8,原样承继不在本批辖域)。
