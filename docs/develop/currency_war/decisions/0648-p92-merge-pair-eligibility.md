## 背景与动机

P92 门拦刷的合法性前提 = 判定尺判空 ⇔ 四买入通道实际触发全假。病灶 = ④通道(合成完备购)的候选装配面高估:C_④(F) ⊋ T_④(F)。旧装配遍历 bench∪deployed 全体角色名取「同名副本恰 2 张全 1★」形态对,**不滤买入资格**——∉buy_members 名的 1★×2 对(dominance 线外凑对/换线遗留/散件凑对,锁线语义上永不进 M2b 合成完备购采购域)被算「④可达」→ 全通道死帧族被门判「非空」放行刷新,刷新后④名即使命中第三张 M2b 也不买(∉采购集,循环 skip)→ 白刷,净差 = −(c_eff+L) < 0 严格而未拦(s10003 p2r1 实形态锚:bench 4 对中 3 对线外假可达,lv8 三费档刷新概率全开,门恒真,p92_blk 键恒缺)。

第二病灶 = 形态条件「恰 2 张全 1★」在 M2b 循环与 P92 装配两处复述——Y4(同名异星)演进史证明复述必漂移。

## 决策

**装配面对齐(非判定域扩展),资格∧形态两维单一源:**

1. **资格维**:`n in set(buy_members)`,与 M2b 合成完备购循环头同函数同一变量 = 同一单源(T-295 对抗审问题 6 转正);未锁帧 buy_members = k_members 回退,线外对同样不算④可达,与 M2b 未锁实现一致(语义对齐非新增限制)。
2. **形态维单一源**:模块级 `_merge_pair_names(bench, deployed)` 返回形态对名集(全局面同名副本恰 2 张 ∧ 全 1★),M2b 循环与 P92 装配两处共吃,禁第二实现;归一化/计数键逐字符同 `decide_shop_action` 内 `_cnt`(星级 `(c.star or 1)` None 视同 1★、键 `(c.char_id or '')`、计数宇宙 bench∪deployed)。**局部 def → 模块级偏差**(相对方案稿落点 1):锁 D star=None 单变量真值表须直调被测谓词,局部闭包不可导入;模块级私有 helper 测试直引有 `_r2_card_reserve` 在册先例。
3. **M2b 循环头等价改写**:循环前置 `_pairs` 求值一次,旧「copies/len/any」三行过滤改一行守卫 `if m not in _pairs: continue`——对 buy_members 域内名「恰 2 张 ∧ 无 ≥2★ 副本 ⇔ ∈ 形态对名集」逐条等价(经 `or 1` 归一化,None/0 同 1★),行为零变;M2b 三点论证与满栏例外注释零触碰。
4. **行为变化两条,均单向收窄放行面**:①资格维主修——∉采购集 1★×2 对不再喂④,全通道死帧族由「恒放行」变「四通道合取判定」(拦刷分键 `p92_no_buy_refresh_blocked` 由历史恒缺变按真开火);②形态维边角——1★×2 + 3★×1 并存形态(全局面 3 副本)原被装配算可达、M2b 实现从不触发(len==3 skip),修复后排除;其余形态(1★×3、1★×2+2★×1)两口径本就一致排除零漂移。放行帧族至少一通道真实可达(P92「全通道集非空帧不作断言」,决策交还上层账);零误杀方向由锁 B 承载。

## 修订承载的语境边界(落地审发现 A 吸收)

实施段曾以「到 P92 位必过 r1 账(ledger ≤ gold − g*)与 r2 预算门(gold ≥ g* + ρ + 2),g* = 10×cap ≥ 10 > 任意 cost(注册表值域 1-5)」论证「集成面 gold<min(cost) 不可构造」。该论断有两处语境缺口,复用者须按下述边界引用:

- **缺口①:必花域 r1 账可被合法绕过。** 必花域帧 `_zone_hit ∧ rkey == 'account_over_budget'` 时 `ok_r1` 被覆写 True(yielded 支,shop.py r1 段 2688-2695 区,工作树坐标系;R1 域内残形切分线,ADR-0528)——r1 账在该域降为期望核算排序信号,「必过 r1 账」不成立;r2 预算门(`crit_refresh.r2_budget`,reserve = g* + ρ)才是 P92 位唯一必经硬闸。
- **缺口②:买断制局 g* = 0。** `interest_cap_resolved` 明文「0 是有效覆写(买断制)」(kernel/cw_economy.py:79-91),g* = saturation_line = 10×cap_resolved(同文件 124-126 区)⇒ cap=0 时 g*=0,「g* ≥ 10」前提失效;此时窄带帧(gold ≥ ρ+2 ∧ gold < m ∧ m ≥ ρ+3,如 4-5 费对+低费合格成员+席满无燃料)可同时过 r2 门并满足 gold<min(cost)。
- **边界结论:「不相容」论断只在非买断制局(cap ≥ 1)严格成立;买断制局该论断失效。** 本件修订构造本身在两语境下均合法——锁 A 的④死条件用「X 费档该级不可刷」承载(refresh_prob(level,cost)=0 注册表现查;lv4 行 {1:0.65, 2:0.25, 3:0.10} 即锁帧前提断言的注册表锚,cw_shop_odds.py:42-53),金维死条件以判定尺直调补钉(gold=1 < base=2 ⇒ False;gold=2 边界 ⇒ True;判定尺④通道仅「刷新概率>0 ∧ gold≥base」合取、无 g* 条件,criteria/refresh.py:235-238)——该构造只锁「④对全部候选名死」与判定尺金维行为,不依赖金位窄带不可构造论证,比字面条件更稳健。

## Considered Options

- **P92 判定域扩展(判定尺签名下沉 buy_members)**:被否——违反 T-263 在册分工「调用方装配候选,判定尺只做通道合取判定」(判定尺 docstring 明文),牵动判定尺签名/两把在册锁/契约注册,收益为零。
- **只补资格维行内过滤,形态条件保留两处复述**:被否——形态条件第三次复述(M2b 循环一次/装配一次/新过滤再写一次),Y4 演进史证明复述必漂移;按跨件半问,两消费位同吃同一谓词,单一源提取才是治本。
- **helper 局部 def(方案稿初版)**:被否——锁 D star=None 单变量真值表须直调被测谓词,局部闭包不可导入;行为面与方案稿规格逐字一致,仅作用域移动。
- **维持旧装配不修**:被否——全通道死帧族恒放行白刷,净差严格负未拦;s10003 p2r1 实形态在案。
