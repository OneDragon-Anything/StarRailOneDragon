# 逐光捡金-战斗退出确认弹窗(treasures_light_battle_exit_confirm)

逐光捡金系列玩法（末日幻影/虚构叙事/忘却之庭）战斗暂停面板点退出位按钮后弹出的退出确认弹窗。窄口径建档：识别锚用**弹窗正文专属文案**「是否结束本场战斗」，与通用「提示」弹窗族的其他成员弹窗严格区分。供 `EnterGame` 登录恢复退出链消费。

## 何时出现 + 状态流转

- **入口**：逐光捡金系战斗-暂停面板点「退出位」按钮（末日幻影「结束战斗并结算」/虚构叙事「返回虚构叙事」，位置固定文案随玩法变）→ 弹出本弹窗；客户端重启恢复到暂停面板态时走同一链。
- **出口**：
  - 「确认」→ 节点结算页（点「退出」回选关）；
  - 「取消」→ 关弹窗回战斗-暂停面板。

## 识别特征(稳定锚点)

- **id_mark 正文锚**：「正文-是否结束本场战斗」(700,490-1320,535) lcs 0.7——弹窗正文是该弹窗的专属文案，通用「提示」弹窗族成员（未达上限警告/跃迁兑换确认等）标题「提示」与确认按钮同位同文，位置锚无法区分族员，以正文区分。
- 「按钮-确认」(980,635-1360,712) lcs 0.7 为普通 area（非 id_mark），供 EnterGame 取中心点击；与正文锚组成双命中判据。
- 弹窗本体约 (475,360-1440,725)，模态遮罩盖住背景战斗画面；红色警示行「结束后，将直接进行结算。」为末日幻影形态文案，不作锚点。

## 备注 / 待查

- **与通用「提示」弹窗族的分界**：该族成员（货币战争-未达上限警告/跃迁-兑换确认/跃迁-梦华兑换/历战余响次数耗尽弹窗等）各自以正文专属词独立建档——本档正文锚对族员帧不命中，族员锚对本弹窗帧不命中，互不干扰。原「战斗-退出确认弹窗」通用屏（「提示+确认」位置双锚）已退役拆分为本档（2026-11-21），消解其对族员弹窗帧的 is_precise 抢命中。
- **CW 形态不在覆盖范围**：货币战争弹窗按钮「放弃并结算」非「确认」文案且正文不同，本档不命中（遇上有界失败，CW 对局恢复由 CW app 自己的恢复链负责）。
- **PF(虚构叙事)/FH(忘却之庭) 形态正文未实拍**：本档正文锚「是否结束本场战斗」是否覆盖两形态待实机补拍验证——若正文不同，登录恢复链在该形态下从「接住」变有界失败（风险已登记 CW 待跟进事项，补拍后裁决并入或分档）。
