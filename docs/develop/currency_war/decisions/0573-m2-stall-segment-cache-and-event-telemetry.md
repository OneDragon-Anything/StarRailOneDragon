# ADR-0573 — M2 停摆续段缓存与停摆计数事件粒度(T-82 必花臂重试风暴治本)

- **Status**: accepted
- **Date**: 2026-09-07
- **关联**: ADR-0521(P60 锁线换手收敛与诚实停摆语义——本批修复的计数语义源头)、ADR-0517(单动作决策核——帧循环承载结构)、ADR-0558(合成素材守卫 G-S1——`merge_material_guard_blocked` 键语义)、ADR-0563(MandateState 职责分离——新字段落位面)
- **方案与审**: `.debug/temp/currency_war/t82_retry_storm/方案.md` v3(实施唯一口径;同目录方案审/定点复核两轮零阻断收口)
- **触发证据**: sim68 批 s7514 r9(单轮 `m2_retry_exhausted`=15,档案已清理,引文在案)+ 234813 批 s110 p1r9(19/19 逐帧直算;档案随 sim_runs 滚动清理,形态由同池同 seed 重放再生)

## 1. 背景与问题(归层:决策层·判据实现)

锁线/大配方态下 bench 满仓 ∧ 缺员 ∧ 腾席燃料集空(P60 排除集 + 合成守卫 + 非 1★ 的合法产物)时,腾席拒绝的全部输入在 LevelUpShop/RefreshShop 帧间**构造性不变**(两动作执行语义只动 gold/spend/xp/商店牌面,不触 bench/deployed/k/敌缀/意图集),而商店线 M4 块与备战线 M2 块把「每帧重新推导同一拒绝」当「每次新的义务尝试」计数——**重试风暴 = 帧循环对状态不变拒绝的无记忆重推导,计数器把一次停摆事件放大成 N 个事件帧**(一次停摆 ×20 帧被读作 19 次独立停摆)。行为无损失(帧本就落 L3/刷新继续泄金,支出轨迹无损失),代价 = ①每帧无信息量扫描(计算浪费,轻微)②计数事件语义被逐帧计数破坏(P60「诚实停摆事件」判读伤害,主要)。

根不在判据语义(腾席拒绝按 P60 正确工作:该停摆就停摆),不在数据流/执行层,也不纯是遥测层(只挪计数器不停掉重推导,浪费仍在)——根在判据**实现结构**缺「输入不变 ⇒ 结果不变」的记忆。

## 2. 决策(裁决)

### 2.1 单槽续段 token 缓存(白名单唯一实现路径)

- **缓存形态**:会话态单槽(MandateState 具名字段)`cw4_m2_stall_latch`(腾席无候选结论 + 段序号),非 φ 字典。
- **段标识三行**:①构成 = `cw4_segment_serial`(会话态单调递增 int,只作相等比较不作阈值,递增不承载决策量);②置位 = 各段入口 +1(商店 visit 开始[cw_op_buy_cards.run_buy_waves 入口,普通 visit 与发射帧仲裁段共用]/bridge.decide_shop_screen 入口[sim/replay]/备战期开始[生产 prep 访问循环入口]);③比较 = token 序号 == 当前段序号 ∧ 闩序号 == 当前段序号才命中。
- **非变异动作白名单**(跳过条件 = 可判定谓词,零参数,非计数阈值):商店域 `M2_STALL_NONVARIANT_SHOP_ACTIONS = {LevelUpShop, RefreshShop}`,备战域 `M2_STALL_NONVARIANT_PREP_ACTIONS = {LevelUp}`;白名单外动作(含未知新动作型)一律视为变异 ⇒ 失效重推导(保守端 = 现行为)。守卫:加入前须验证执行语义不动 bench/deployed/k/敌缀/意图集。
- **token 载体与读清**:会话态单槽 `cw4_frame_action_record`(动作型名 + 段序号);写入点 = 动作执行/投影层确认已执行后(三处接线:生产商店循环执行位/sim-replay 驱动器投影位/生产 prep 循环执行位);读清协议 = `decide_shop_action` 入口读取后立即清除。**伪命中防线承重 = 段标识比较而非读清**(读清防重复消费,段标识防首次误消费,两道独立)。
- **命中语义**:命中 ⇒ 跳过燃料扫描(商店)/腾席 while 环(备战),发射序列逐位一致(弱支配:两域 M4/M2 拒路径零 return 截流,后续臂不消费扫描结果);计数见 §2.2。闩只承载「腾席无候选」结论(有候选但不可逆护栏拒 ≠ 本结论,不写闩)。

### 2.2 停摆计数改事件粒度

`m2_retry_exhausted` / `bench_full_buy_abandon` 从「每决策帧一次」改**事件粒度**(同停摆段命中帧不增,段首/失效后重推导帧 +1);新增观测对 `m2_stall_cache_hit`(命中帧)/ `m2_stall_cache_rederive`(重推导得出无候选帧)与重复帧键 `m2_stall_repeat_frame`(风暴帧量级保留可见,零静默)。**判读协议:事件粒度下 m2 键量级骤降 ≠ 风暴消失**;按旧帧量级设阈的检查器须随批重推。

### 2.3 零变化申报(正交面,防伪问题重提)

`merge_material_guard_blocked` **两域触达拓扑分述**(三审 C1 修订:两域不相同,禁合并申报):

- **商店域 = 不受本批影响、行为零变化**:帧首 P56 投影位(shop.py 预算投影段,无条件先于 M4 位触达)独立承载首计,帧级 `_mm_dedup` 使 M4 扫描触达对计数域恒惰性——跳过 M4 扫描后该键仍逐帧每素材 +1(T7 商店域恒等锁:缓存命中帧断言前提 + 键值逐位 == 2)。「凑息卖/支付支撑卖同帧多计」机制不存在(三臂传同一去重集,首计恒被 P56 占先)。M4 缓存的计算收益因此收窄为「每帧省 M4 位一次扫描」,遥测保真收益不变。不迁承载、不写「只计 1 次」判读粒度声明。
- **备战域 = 随本批变更为事件粒度(计数粒度变更的组成部分,非零变化)**:该键在 prep 域的唯一触达 = 腾席环内 `fuel_sell_candidates`(mandate.py;无 P56 式独立承载),续段命中帧跳过腾席环 ⇒ 素材触达不再发生 ⇒ 该键零增量,与两事件键同粒度。粒度一致性由 T7 prep 域镜像锁承载(命中帧 `cache_hit`=1 前提断言 + 素材键零增量断言),禁「事件键事件粒度 + 素材键帧粒度」混计形态。判读面:prep 域该键量级随停摆段数收敛(与 m2 键同协议:量级骤降 ≠ 风暴/素材滞留消失;素材滞留的帧级观测另有 `count_material_stale` 既有载体不受影响)。

### 2.4 隐含假设申报

①跨 RefreshShop 段命中依赖「重观察不改变停摆结论输入」——观察层读数抖动时现行为可能翻转结论而缓存行为静默跳过;既有投影对账防线(`guard_proposal_vs_expected`)兜底,缓存放大噪声静默面,如实申报。②缓存跨轮失效依赖「轮界必有白名单外动作」(当前成立:CloseShop/战斗/部署均在白名单外),白名单常量处守卫注释防静默扩集。

### 2.5 无开关

缓存是判据实现结构的记忆化(跳过条件 = 可判定谓词),非策略开关;白名单外动作保守端 = 现行为,回滚靠 git revert 或白名单置空(等效禁缓存,红证①即此形态)。

## 3. 验收(锁与红证与零漂移锚)

- **T1-T7**(`test_cw_m2_stall_cache.py`,15 条):T1 风暴不变性(命中帧两事件键零增量 + repeat/hit +1 + 发射动作与无缓存世界逐位一致)/ T2 变异失效 + 燃料恢复卖出 / T3 未知动作型保守端 / T4 备战线镜像(含跨域闩序号拦截)/ T5 计数语义(段内恰 +1、跨段再 +1)+ 命中帧键面形状 / T6 跨调用方失效(残留 token 读清 + 段序号比较承重 + 闩/token 两道独立)/ T7 双域恒等锁(商店域:帧2 走缓存路径而 P56 承载键仍逐帧 +1;备战域镜像:命中帧素材键零增量=随事件粒度)。
- **写点活性锁**(三审 T4;`TestTokenWritePointLiveness`):bridge 驱动器写点 + prep 主环写点两条行为锁(桩化首帧终结动作使 token 保留可断言 / 备战单轮 op harness),各自带变异自检(临时禁用写点 → 锁红,已复跑恢复)。run_buy_waves 写点与破墙段写点因执行环境 mock 成本未立行为锁,挂账 §5(两处与已锁写点同批同形三行,主环锁红时同文件同形写点同步暴露)。
- **红证双探针**:①两域白名单 monkeypatch 置空(等效禁缓存)→ T1/T4/T5×2/T7 五条命中类断言红(失效类 T2/T3/T6 保持绿,分界正确);②临时去掉命中谓词两处段序号比较 → T6 两条商店域锁红(hit +1 而非重推导 = 伪命中被捕获)。
- **零漂移锚**:①同池同 seed 成对 sim 局(8 风暴局 seeds 11/13/20/24/31/37/41/42,圈选=snapshot 池 seeds 10-49 扫描 hit>0 局,圈选记录落盘)缓存开 vs 白名单置空 actions/gold/hp 轨迹逐位恒等,分歧行 = 0,合计 `m2_stall_cache_hit` = 90(两要素同池同时成立);②历史局快照重放(实机 replay 语料 29 轮,含 19/22 动作长序列轮)缓存开 vs 禁逐位恒等,分歧行 = 0(hit 承重在 sim 半边,该语料无风暴轮);③运行证据落盘 `.debug/temp/currency_war/t82_retry_storm/锚运行记录-*.log` 与 `圈选扫描-seeds10-49.log`(锚达成申报可盘面复核)。

## 4. Considered Options

| 方案 | 裁决 | 理由 |
|---|---|---|
| φ 元组字典作缓存键(帧间指纹成键) | ✗ | ctx 两实读分量(敌缀/意图集经 state 现读)无法廉价成键,任何折叠构成「用旧结论回答新输入」的伪命中漂移面(方案审 A2 废除) |
| 读清协议单独承重(无段标识) | ✗ | 商店 visit 末帧 LevelUp 残留 token → 战斗 → 仲裁段首帧首次消费,读清防重复消费不防首次误消费;段标识比较才是承重防线(定点复核 N2 钉死) |
| 只挪计数器到「环终止」位,保留每帧重推导 | ✗ | 计算浪费仍在;计数粒度扭曲是重推导结构的下游投影,随同一处修法收编 |
| ≥3 帧计数阈值闸(停摆 3 帧后切通道) | ✗ | 阈值闸违零参数宪法(审查 40 打回,维持作废);跳过条件 = 指纹相等可判定谓词,不是任何计数 |
| 挪「缺员在售检查」到腾席之前 | ✗ | 改变「投机腾席」既有语义,行为漂移,非本批最小面(登记相邻观察) |
| 开新卖权扩域(卖 2★/线内件)缓解停摆 | ✗ | 新授权域归 M4 N_crisis 命题批;风暴态帧本就落 L3/刷新泄金,支出轨迹无损失,无效果缺口 |
| B1 同构键(stockpile 臂 bench_full / L3 域内闸拒键)随批收编 | ✗ | 同构逐帧计数形态在案,但 hunk 面外;挂账候同构收编批(M4 位续段结构可直接复用) |
