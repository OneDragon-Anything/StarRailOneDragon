# P33 · 支出门否决域期望负性(利息线以下真跌破利息档买入的条件定理)

> 状态:**结构已证(条件定理;利息损失项零参数)。卡点显式化:散件残余价值上界 V_hold(散件)<d·R 下界(1 金当量)未标定,replay 语料可离线补——补齐前本命题作否决域设计判据的结构背书,不作数值授权。**
> 命题来源:支出门(买侧收紧门)设计批(设计正文 REPORT §6,原 prereg 路径已从仓库删除,git 提交 84370361 可溯;本篇即其持久化单篇);同族先例=(利息线以下支出门,升级/刷新侧)。
> 背书命题:P47(利息账 L——利息损失项的规范单一源;机制分段函数 = economy.md §10.1)、P1(卖出全额退)、P6(免费期权)、P11(富余段零利息损失口径)、判据栏的跌破利息档传导账(32 金换 2 档利息损失、胜率传导上界 0.12<过账所需 0.30)。

## 1. 命题(条件定理形式)

设买入候选 x,价格 C,花后金 g′=g−C。定义:

- **真实跌破利息档深度** d = ⌊g/10⌋ − ⌊g′/10⌋(利息档下降档数);
- **剩余平台轮** R = 本位面剩余的、利息档产生收益的轮数(P13 记号 R/t;决策帧状态可读量,非待标定参数);
- **V_hold(x)** = x 持有至终局的残余期望价值(后续战力兑现 + 终局残值,金当量)。

**主定理(负性充分条件)**:当

1. d ≥ 1(真实跌破利息档,区别于花后仍留在同一档的情形);
2. R ≥ 1(适用范围门:收官轮利息损失项归零,否决域不适用,见 §4 边界);
3. x 无当轮兑现路径(当轮战斗生效面为零或对当轮胜率无一阶贡献);
4. x ∉ 豁免类(E-a 合成完备对 / E-b 阵容内缺档件,定义见 §3);

时,该笔买入相对「不买」的期望差为

```
EV(买) − EV(不买) = −d·R + V_hold(x)
```

且当 **V_hold(x) < d·R**(充分条件的可检验形式:d·R 下界=1 金当量,故 V_hold(x)<1 金当量即充分)时**严格为负**。

利息损失项 −d·R 是**确定性项**(利息规则为游戏明文机制,economy.md §10.1),不含任何待标定参数——这是本命题「结构已证」部分的全部内容。

## 2. 推导

跌破利息档的买入相对不买的账,按资金流与战力流分解:

1. **利息档损失(精确)**:利息规则每档每轮 1 金(economy.md §10.1)。档位从 k 降到 k−d 后,后续 R 轮每轮少收 d 金,合计 d·R。此项只依赖 g、C 与状态变量 R,零自由参数。
2. **当轮战力(由适用范围定义归零)**:条件 3 直接给出当轮 Δp 项 = 0——这是**否决域的定义**而非实证结论;有当轮兑现路径的买入本来就不进否决域。
3. **持有残值 V_hold(x)**:买入金 C 沉淀为资产。散件(不在配方围栏名集、非阵容内成员)无计划兑现路径,其残值只剩意外合成/临时上场等二阶期权,上界待实证(§4 卡点)。

三项相加即主定理等式。负性判定只剩单标量比较 V_hold(x) vs d·R。

## 3. 豁免类的结构性排除(为何不在否决域)

豁免类的共同构造:**存在确定性兑现路径,使 V_hold 有正的下界**——

- **E-a 合成完备对**:买入即合成,产物为体系件,P20 背书其战力边际为激活阶(散件升星的 2.6-2.9×);即使暂不上场,P1 卖出全额退保证退出成本为零(P6 免费期权)。
- **E-b 阵容内缺档件**:终局阵容已锁定,再遇账(P1:越稀有越囤,5 费再遇 60-180 轮)给出「错过即长窗口」的机会成本;持有期利息损失被兑现期望覆盖。

两类都不满足「无兑现路径」前提,故**定义上**不在否决域——这不是豁免是恩赦,是否决域谓词的完备面:门只拒「跌破利息档 ∧ 无兑现路径」的交集。

## 4. 边界与卡点(显式化,不闭题)

| 项 | 性质 | 处置 |
|---|---|---|
| R=0(收官轮) | 利息损失项归零,负性不成立 | 适用范围门:R≥1 才进门(实现侧触发判据天然含此,收官轮无「剩余轮」) |
| 同档无损(d=0,利息档未降) | 利息损失项=0,本命题不适用 | 门谓词只对 d≥1 生效;同档支出走既有利息账/评分轨 |
| **卡点:V_hold(散件) 上界** | 「不在名集」≠「残值恰零」(意外合成/临时上场等二阶期权非负) | **采集待办(可离线)**:replay 语料统计名集外散件买入的后续兑现率与终局处置分布,估 V_hold 上界;V_hold<1 金当量成立则命题升全参数已证 |
| 口述直觉「跌破利息档买入亏」的方向背书 | 判据栏已账:跌破利息档笔 32 金换 2 档利息损失,所需胜率传导 0.30 vs 实际上界 0.12 | 作方向证据,不替代上述标定 |

## 5. 检验点

- 利息损失项复核:任取一局遥测,跌破利息档买入帧对照 ⌊g/10⌋ 前后差与后续利息收入差,应精确等于 d(逐轮)——利息规则机制(economy.md §10.1)的直接推论,抽样即验。
- 豁免完备性:否决域谓词上线后,拒因枚举中不应出现名集内件(出现=谓词实现漏豁免,非命题问题)。

## 6. 策略含义(消费点)

1. 买侧支出门(利息线分支)的否决域谓词由本命题结构背书:拒「真实跌破利息档 ∧ 无当轮兑现 ∧ 非豁免类」三条件交集。
2. 门是**触发面判据**(逐笔可复算的否决),不作金额授权;开实验分支与 A/B 终局定性见 (默认关维持=合格利息保护器、传导归实机锚)。
