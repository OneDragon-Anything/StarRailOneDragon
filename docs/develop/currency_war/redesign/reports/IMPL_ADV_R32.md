## 高-1 R24-1 危局阀/F7 放宽净代价科目与统一记账律的推导自相矛盾(λr 分量双计)

**位置**:登记表 R24-1 引理(推导 1 + R25-低1 精确式, vs 裁决 2 净代价科目);消费位=设计 §3.1 M4 行 R24-1 重写段、§5.2 危局阀遥测行、§2.0-4 F7 行②(R28-3)、§5.2 `f7_uncovered_interest_sell` 量级行。

**缺陷**:R24-1 自己立了统一记账律 `T := λ×(g+Φ) + λ×Σ_held r_i`(金与件同 λ、形式不变),并在推导 1(R25-低1 精确式)给出卖出 x 的真实总敞口增量:

```
ΔT = λ′×Δ息流 + (λ′−λ)×(g+Φ+Σ_held r)
```

B1 键下 λ′=λ 构造性恒成立(R27-2,且危局阀对象在 B1 下全部是「桶不动件」)⇒ **ΔT = λ×Δ息流**——λr 分量被律文精确消去(件敞口 λr 出盲区 = 金敞口 λr 入账,R24-1 自己定性为「入账时点差,非真实敞口变化」)。但裁决 2 给危局阀桶不动件开出的净代价科目却把死亡敞口变化量计为 **λ×(r+Δ息流)** 并「按真惩罚定性入账」,上界=λ̂_U×(r+Δ息流̂),数值声明「数金~十余金/件」。同一引理内,推导说 ΔT=λΔ息流,科目计 λ(r+Δ息流)——这正是 R16-4/R18-1 反复定性并治理的「同一引理内证明与登记不能同真」在同批新增账目上的复发。

**为什么错**:
1. 裁决 3(买侧)用同一条律把 λc 分量消去了(「真实总敞口变化=−λ₃×Δ息流_buy≤0,c 分量形式中性」);裁决 2(卖侧绝对成本账)却保留 λr——律的应用不对称,无原则依据。
2. 裁决 1 的不对称辩护(「保留臂未做死亡折价而所得金做了 ⇒ 比较式偏保守」)只辖 line_switch_sell 的**比较式内部**;危局阀与 F7-uncovered 是**无条件卖出**(危局阀绕过比较式,F7-uncovered 是禁令未覆盖帧的档序发射),不存在可援引的不对称结构。
3. 方向后果:净代价系统性高估 ⇒ N_crisis 标定批验收阈值偏高(R24-1 明文「N_crisis 标定批验收阈值按新上界口径核」)⇒ 安全阀延迟触发 ⇒ 滞留螺旋治理 **fail-open**;F7 放宽代价量级同步虚高,污染 §5.2 判读。

**修法方向**:危局阀/F7-uncovered 成本科目的死亡敞口分量改 `λ̂_U×Δ息流̂`(Δ息流̂ 用 R8-2/R9-3 组装上界,同源零新参);若坚持「框架可见敞口」口径(W 因卖出显形、即刻进下游 λ 消费),须两套账并列显式申报并声明 N_crisis 验收用哪套(显式战术权衡),消除同引理双真相。窗口帧同款:该科目用表值 λ̂_U,而窗口 λ_true^oper 可超表值(R31-2 自己的论证)——若 line_switch_sell 首项取 1,成本账的 λ 维也应同步窗口口径,否则账与判据窗口处理不一致。

## 高-2 λ 表第四态(空格回退格)对 λ 数值消费位无取值规格——「不是什么」定了,「是什么」没给

**位置**:设计 §1 lambda_death 行四态判定、§2.0-2 第 3 条、§2.0-4 域外行 R31-1 辖域钉死(「濒死带空格回退格的处置=血线地板触发帧解锁包+转化优先(非守息非强制停……显式覆盖本行守息/强制停在空格回退格上的辖域)」);登记表 R31-1。

**缺陷**:第四态把空格回退格从域外/损坏中分出,并**显式撤销**了域外强制停条款对濒死空格子集的辖域——但 line_switch_sell 的 V_power 首项系数(λ_U)与差分项(λ_L/d̂,经第三口以桶观测量键查表构造)在空格回退格上没有任何取值规则:

- 濒死空格(7 格)→「转化优先段语义」:不是数,无法进比较式;
- 有界外推格(1 格)→「敞口上界」:只覆盖这 1 格,且未声明该上界值如何进 d̂ 的两个端点;
- 守息空格(2 格)→「守息」:对卖面数值输入无意义。

三读全部撞条款:(a) 按域外同款强制停——违反 R31-1 自己的显式覆盖声明;(b) 外推/回退值代入——R23-1 禁投影外推的 carve-out 仅辖「表侧区域分化回退」,而濒死/守息格没有回退**数值**;(c) 缺输入默认不评——文本未写,落回 R6-5 定性过的「实现者遇缺输入自造方向」在最新批次上的复发。可达性不弱:血带 hp≤15 的换线塌缩评估帧在 sim/实机常态出现,10/48 格占比不低。

**附带缺陷(同根)**:濒死空格「转化优先」的唯一行为载体=血线地板(hp 键触发,与该格是否空格无关),血线阈值 None 期连载体也空转——第四态在濒死空格子集上的**行为增量=0**,现文本暗示第四态带来差异化处置,名实不符。

**为什么错**:line_switch_sell 是全设计防护最重的不可逆卖面,其 fail 方向纪律要求一切 λ 输入有唯一规格;第四态只完成了「空格≠域外≠损坏」的区分,没有完成「λ 数值消费位在该格取什么」的定谳。区间敞口比较 API 同问(空格回退格的 CI 从何而来)。

**修法方向**:补显式规格行——空格回退格上 line_switch_sell/第三口/敞口比较 API 的 λ 输入取值。候选:(i) 并入卖面强制停清单并显式登记代价(与域外同款,撤销 R31-1 的覆盖声明中「非强制停」半边);(ii) 空格格给确定性上界回退值=1(与 R31-2 首项=1 同源、零数据依赖),d̂ 端点同款处理。二选一,禁悬置。同时对「濒死空格行为载体=血线地板、None 期空转」如实打标。

## 高-3 §3.2 检查点②③的穷举列漏 dominance_buy——封闭声明与自身行为规格互斥

**位置**:设计 §3.2 四硬约束检查点表 + R21-4 注(「②的拦截对象=一切落 board/bench 席的骨架动作,上表列为穷举」;③拦截对象=「EV 买入面(序 3-5 追加支出,stockpile 等)+ M6」)。

**缺陷**:dominance_buy 自 R5-4/R6-2 起就是骨架 pass 内、落 bench 席、mandate=true、消耗真金的买入位——早于 R21-4 补 M6 之前就已存在。但②的对象列(M1/M2/M3/M5/M6)与③的对象列(EV 买入面+M6)均不含它。两读互斥:

- **穷举读**(R21-4 自己钉死的读法):dominance_buy 不受②席位检查与③ S 预留拦截——一个非 S 组成(与锁线零重叠)、每件消耗 c≤5 真金、量可达 9 件的骨架买入,可以吃掉 [41] 的 S 整批预留金、绕开席位硬约束;
- **行为规格读**:R12-2 明文「dominance_buy 意图……席位检查失败(bench 满)时不现场调 M4」——即预设它**受②辖**。

列(穷举、不含)与 R12-2(预设受辖)不能同真;这正是 R21-4 要治的「列非穷举形态下全称句两读」病,在它自己修补时又漏了一个更早入列候补的位。

**为什么错**:「①-④=唯一合法拦截集」的封闭声明依赖列穷举;[41] 推论的 S 预留保护对象正是「非 S 组成的动作吃掉预留金」。「净成本≈0」不构成豁免依据——金→可退资产变换的回收须经 fuel_sell(bench 满/危局触发)或塌缩出口,非任意帧可逆,S 批当帧的预留金可用性确实被侵占(有界:≤9×c≤45,但设计未声明该界为接受账)。

**修法方向**:②③对象列补 dominance_buy 入列(与 R12-2 行为规格对齐);或显式声明其豁免③并登记有界金额上界为接受代价。§6.4 测试位⑤(辖域唯一性静态断言)顺带核对硬约束对象列与发射位全集的对拍——当前静态断言对象只含判据函数发射位,不含硬约束拦截列。

**位置**:设计 §2.0-3 规格②、§2.0-4 M3 行、§3.1 求值位;登记表 R28-2/R31-4/R31-5;总纲裁定二。

**缺陷**:血线硬地板以 hp 观测量直接作触发,解锁 M3 破息批(支出决策)+F7+转化优先。裁定二明文:「当前仅两处数学件被授权开此缺口(λ_death 表血带入键/P15 掉血公式)……此二件之外,任何其他战力相关内容(hp 仅为其后果之一)进入策略,须用户逐项确认后才能实施——本条为硬闸门」。设计把权威挂在「用户已裁三件」之②,但总纲所录安全带裁定用户原话只点名「薄 λ 顾问」;「升档器=血线硬地板+λ 顾问」的扩展形态出自 lambda-risk-philosophy.md(设计产物)。hp<阈值→解锁支出是 hp **直接**进决策(非经 λ 间接、非支付通道类同构),不在两处授权缺口内,也无「待玩家确认」挂账(对照:R24 附带核对盲区走了挂账纪律,血线地板没有)。

**修法方向**:按项目纪律(口述被数学证伪=当场修+挂确认的同款手法)在当前迭代账本补一条「待玩家确认」记录(血线硬地板 hp 触发形态+阈值【拟】+解锁包清单),确认后回写归属;或给出「结构安全阀不属裁定二辖域」的论证入档。另注:「已裁三件」中③(0.1 死阈值)的出处系攻击报告实证而非用户裁定文本,授权归因同款偏弱,建议一并核。

## 中-3 窗口期换线的真实成本账与验收锚未建模危局阀/N_crisis 瘫痪交互

**位置**:设计 §2.7 接受裁决锚(R29-3 窗口/非窗口分列)、§2.7 R13-1① 挂钩条款;登记表 R13-1① 净损推导 (a) 支、R29-3 步骤 3、R31-2 连锁节。

**缺陷**:R31-2 后窗口帧(默认局 ≈P1+P2 全期 ≈64% 局长)塌缩构造性近不可过,前置门按「可用性≠可通过性」放行换线登记。但每次窗口换线的真实代价链未被任何账承接:①换线生效后旧线 2★+ 件滞留占 bench → 新线 M2 买入被硬约束②拦截 → 至少 N_crisis 个备战期的买入瘫痪后才触发危局阀;②危局阀强制卖出旧线件(它们在 K′ 下就是线外垫件)按三科目付费;③瘫痪期机会成本。三项均不进 should_switch 的 E(alt)/E(cur) 比较;R29-3 的窗口验收锚=L-B2 未变现分支界(假设件**未**卖出、按沉没全额计)——危局阀卖出后账目变为 fee+息差+死亡敞口(远小于沉没口径),锚与实际行为脱节。且 R13-1① (a) 支「旧线 2★+ 件无任何出口」与其配套②(危局阀卖线外垫件)**同批矛盾**——(a) 支的枚举漏了危局阀这个出口,前置门的净损推导建立在对出口集的过时枚举上(定谳依据取结构论证故不翻案,但推导文本与设计现状不同真)。

**为什么错**:θ 滞回只限频度;窗口期每次换线的边际成本(瘫痪帧数×M2 意图价值+强制卖出三科目)可达数十金+多帧机会,与非窗口的 L-B2 期望形态(≤14 金)差一个量级以上,E 比较对此盲——「判据消费定义域内输出」的辩护只覆盖出口不可用态,不覆盖「出口开而不可过」态的代价放大。

**修法方向**:①R13-1① (a) 支出口枚举补危局阀,净损推导按新枚举重述;②窗口期换线事件成本账补危局阀交互分列(瘫痪帧数遥测+卖出三科目),验收锚按「危局阀变现/未变现」两分支分列;③或把窗口期 2★+ 滞留负载显式并入 θ/滞回的放宽方向申报(显式战术权衡)。

## 中-4 λ 顾问触发集由薄格 bootstrap 饱和上端决定——排序键=截断形态,非危险度

**位置**:设计 §2.0-3 规格①;登记表 R28-1 步骤 2、R29-2/R30-1 数据直读、R31-6;§5.2 触发有效性检验位。

**缺陷**:触发谓词排序键=λ_U(CI 上端)。v3.2 触发集 top-2(D1×hp>40×P1×boss n=12、D1×hp15-40×P1×boss n=5)的 λ_U=1.000 均系 cluster bootstrap 上端打满的**截断产物**——在高分段,λ_U 排序≈「样本量/截断形态」排序而非危险度排序(n=5 的格 CI 上端 saturate 至 1 的概率远高于 n 大的格)。R31-6 只修并列计数与打破次键,不修「上端=截断值使排序失真」;R29-4 的 p 维带扫也只在截断值集合内部选位。设计在 R30-5(c)/R29-2 已如实承认「触发与危险脱钩」并加了有效性下限第二判据——但那是事后门;通过速率门+有效性门后生产启用的,仍可能是「按 (D1,P1,boss) 键组合定期收紧」的组件,其全部产出=R29-5 已证的不可逆 XP 本金净损加无收益收紧。

**为什么错**:对收紧向动作用 CI 上端是保守方向(只升不降),这个辩护成立;但「保守」不等于「有信息」——当上端由截断决定时,分位序传递的是格的样本量与坐标,不是 λ 的高低。规格层无点估计参与、无 CI 宽度惩罚,是已知局限未进规格只进判读。

**修法方向**:标定批加排序键敏感性对照(λ_U 序 vs 点估计序的触发集重合度,入验收报告);或在触发谓词加「CI 宽度惩罚/饱和格(λ_U=截断上界)降权」条款;至少在验收级第二判据处申报「排序键=截断形态」的局限与重估触发条件(主表样本增厚即重扫)。

## 中-5 R17-2/R24 附带核的资格谓词:载体不存在、迁移序与测试位均无建设项
