# 货币战争-遭遇节点(二选一遭遇选择)

## 何时出现 + 状态流转

对局内**位面推进中**随机出现的「遭遇节点」选择屏(非每轮必有;出现时机由肉鸽地图节点决定)。玩家从两张遭遇卡中**二选一**,确认后进入该遭遇的战斗(或效果),打完回备战。

- **入口**:备战 → (地图节点为遭遇时) → 本屏;或从备战点「返回遭遇选择」(右上,遭遇未结算时出现)回本屏。
- **出口**:点一张卡选中 → 点「选择」→ 进入对应遭遇(战斗)→ 结算 → 回备战。
- **放弃(可逆,实测 2026-08-11)**:「返回备战界面」(右上)退回备战 —— **不扣「剩余次数」、不放弃遭遇**:备战屏右上出现「返回遭遇选择」,可随时回到本屏继续选。故本屏与备战间可往返,只有「选择」才真正消耗本次遭遇进入战斗。
- **查看详情(子屏)**:「查看详情」(上中)→ 弹「敌方信息」全屏覆盖层(见下「敌方信息覆盖层」)。

## 识别特征(稳定锚点)

- **标题「遭遇节点」**(画面正上方,x≈900 y80)—— 画面独有,可作 id_mark。
- 「遭遇其一」「遭遇其四」(两张卡标题)—— 出现哪几个「其X」视当前遭遇池而定(不一定固定是一/四;检测用「遭遇其」前缀更稳)。
- 底部「选择」按钮 + 「剩余次数：N」+ 圆箭头钮(分支刷新,见下表)。
- ⚠️ 勿用「难度」「奖励预览」等作特征(多屏共有 / 易变)。

**难度标记(实测)**:每张卡标题下「-难度-」旁有 **V 形图标**,数量 = 难度等级。颜色随难度档变(低档蓝 V / 高档红 V,实测:1V 蓝 / 2V 蓝 / 4V 红)。⚠️ **OCR 读 V 不稳**(常误读成 M)→ 难度计数靠视觉大模型 / CV,不靠 OCR。

**两张卡内容(实测两例,随遭遇池变化)**:
- 例 1(2026-08-04):左「遭遇其一」1V 蓝 + 金币×2;右「遭遇其四」4V 红 + 随机 4 费角色×3。
- 例 2(2026-08-11):左「遭遇其一」1V 蓝 + 金币×2;右「遭遇其二」2V 蓝 + 员工投影仪×1。

(难度越高敌人越强、奖励越好,「难度越高敌人越强大,请谨慎选择」。)

## 交互模型(实测 2026-08-04,**踩坑固化**)

正确序列 = **① 点卡身(选中)→ ② 点「选择」(确认)**。

⚠️ **两步之间不要插任何点击**:旧实现插了一个「空白点击 (960,540)」想关详情,实际会**取消选中** → 「选择」时无选中 → 不推进 → 死循环(plane1 round6 后卡死 7 分钟,OCR 反复见同一屏,根因)。点卡身是「选中」不是「开详情」,无需关。

bug#1 缓解:关键 click 前 `mouse_move`(零移动 click 不被框架 before_screenshot 判成拖拽)。

### 穷举交互验证(2026-08-11,补建档漏的 onboarding §4)

逐个交互确认每个元素行为(可逆先、不可逆出口最后):

| 交互 | 行为(实测) | 可逆? |
|---|---|---|
| 点左卡身 (622,530) | 选中左卡(选中态从右→左,蓝发光边框移动) | 可逆(再点右卡即改选) |
| 点右卡身 (1257,530) | 选中右卡(选中态→右) | 可逆 |
| 点「查看详情」 (960,278) | 弹「敌方信息」覆盖层(见下节) | 可逆(X 关闭回本屏) |
| 点「返回备战界面」 (1790,80) | 回备战,右上出现「返回遭遇选择」可回本屏;**不扣剩余次数** | 可逆 |
| 点「选择」 (1082,898) | 消耗本次遭遇、推进对局(2026-08-11 测:选其一→遭遇选择消失、回备战;遭遇节点为战斗类,选择后进战斗流程) | **不可逆**(出口) |

选中态 = **视觉(蓝色发光边框),非 OCR**;默认进屏时已有一张卡选中(非无选中)。「选择」未选中时灰、选中后亮 —— 但因默认总有选中,实战少见灰态。
