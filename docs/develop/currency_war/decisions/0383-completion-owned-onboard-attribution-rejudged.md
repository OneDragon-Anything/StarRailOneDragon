# 0383 — 144 归因重判:补完触发口径无 bug,零修法 + ADR-0381 不变量表述修订

- 日期: 2026-09-01
- 状态: accepted (采纳)
- 关联: ADR-0381(不变量表述由本批修订)、ADR-0382(持续门——144 残差的机制归属)、W203(③A 移交①:归因重判+不变量张力裁决)、ADR-0374(零修法模式与「无新证据不得重试同族」条款)、ADR-0379(意向派生谱系探尽)
- 批: W205(件①)

## 背景与问题

W203 探针证伪 W201 对 144 的供给侧归因:r7 起桑博+椒丘两个 distinct
DOT 成员连续 3 轮在手(owned distinct=2=tier 达标),dot_ob 恒 0 终局
搁浅。W203 移交时的候选归因:「真实残差=缺口谓词可能是 owned<tier
触发,owned=2=tier 时不再触发,件躺 bench 无人上场」——即假设现行
`_engine_completion_tx` 只查 owned 不足、不查 on_board 不足;并要求
裁决与 ADR-0381 语义不变量「owned≥tier ⇔ 存在≥tier 不同成员可
同时上场」的张力(144:owned 达标但从未同时上场=不变量活反例)。

## 证据(W205 探针,HEAD=59a33d2a,池 861fc9f6 重放)

1. **前提证伪(代码亲读)**:`_engine_completion_tx` 缺口谓词现行即
   `owned >= tier > on_board`(cw_evolution.py `_owned_cnt` 后的
   deficits 构造)——「owned 达标∧on_board 不足」**正是现行触发
   口径**,W203 候选归因(谓词只查 owned 不足)不成立。
2. **触发实证(逐次调用探针,w205_probe144)**:144 的 DOT 缺口在
   r7(3 次)/r8(5 次)每次 tx 调用都被判定为 deficit 并参与选择
   ——谓词确实触发,件不是「无人过问」。
3. **None 归因(状态捕获探针,w205_none_reason)**:DOT 缺口轮
   built=None 的完整状态=r7/r8 `room=0`(deployed 满员:
   缇宝/翡翠/银枝/藿藿/三月七/停云(+姬子)),undeploy 常规候选
   枯竭(全保护),分级降级(`grade_down`)被**持续门
   `_GRADE_PERSIST_ROUNDS`=4** 挡住——DOT 缺口存续仅 r7-r8 共 2 轮
   <4。即 144 残差 = **ADR-0382 已记档的「68/144 留=缺口持续<4 轮,
   门收窄的已知代价」的具体机制形态**,与 136 同族(构造闭死)不同
   例(门内窗短),不是独立 bug。
4. **终局链**:r8 列车缺口(选择序比率 1/2 > DOT 0/2)优先被构造
   并 applied(该轮补完活性正常);r9 派生对换窗(pair 消失)→
   DOT 退出补完辖域——末因是意向派生谱系,该谱系已被 ADR-0379
   探尽(策略侧地板)。
5. **形态分布(n=300 全扫,w205_scan)**:「owned 曾达标 ∧ 全程
   ob<tier」= 列车 28 局/仙舟 19 局/持续伤害 16 局(多局分布非单
   局);但绝大多数 deficit_rounds≤2(暂时性缺口,供给时序/换窗
   自愈面),与 W202 形态扫描(undeploy 全保护 91 局、持续 ≥4 仅
   12 局)同构——宽激活面的代价已被门值标定三跑否决。

## 决策

**零修法(ADR-0374 模式),ADR-0381 不变量表述修订:**

1. 不改缺口谓词(现行口径已正确)、不改持续门、不改选择序。
   不修判据:唯一能救 144 形态的杠杆=持续门放宽(4→2/3),已被
   W202 门值标定 A/B 硬门否决(门 2 benign→mal=[65,119,172]、
   门 3=[119] 坏翻转);ADR-0374 条款「无新证据不得重试同族」适用。
   选择序改 DOT 优先无据(现序=最接近成型优先,列车 r8 ob=1/2
   优先于 DOT 0/2 合理;若倒置则列车被推迟、r9 换窗后两者皆空)。
2. **不变量表述修订(ADR-0381 张力裁决)**:「owned≥tier ⇔ 存在
   ≥tier 个不同成员可同时上场」的「可同时上场」=**结构性可能**
   (板面容量/同名唯一约束下可构成的场上集合),**不含「补完通道
   当场构造成功」**——后者受保护集(ADR-0371/0375)与持续门
   (ADR-0382)的策略权衡约束。144 在修订口径下不构成违反:
   owned=2 结构性可上,补完通道因保护集+门闭死 2 轮后派生对换窗,
   是策略代价不是口径裂缝。

## Considered Options

- **按移交稿改谓词为 on_board 口径**:前提不成立——现行谓词已含
  on_board 维(证据 1/2),无可改之处;「现在可能只查了 owned
  不足」的猜测被代码与探针双重证伪。
- **持续门放宽到 2/3 救 144 形态**:同族重试,ADR-0374 条款禁;
  W202 三跑证据(坏翻转)直接适用。
- **多体系并行补完(一轮补列车+DOT)**:越界——CompTransaction
  单体系契约,多体系=执行层契约改动,且 r9 换窗后仍救不了 DOT。
- **零修法+不变量修订(采纳)**:证据链闭合(触发✓/None 归因✓/
  分布✓/终因谱系探尽✓),残差归位「门收窄已知代价+意向谱系地板」。
