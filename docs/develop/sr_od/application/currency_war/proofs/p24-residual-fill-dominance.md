# P24:残余补部署支配定理——零支出域(C=I=0)下围栏认可件补空槽严格支配整轮部署禁运

> 状态:**已证(结构命题,方向严格;量级=粗战力模型级,如实分级见 §命题分级)**
> 立题来源:围栏互斥辖域收窄设计(W716 F1 修复设计;skip_fence 轮级禁运的病理立案与逐帧账本证据见该设计 §一)——F1 病理:skip 轮轮末整轮禁运自动部署,演进换阵/3合1 吞副本造成的板面空槽连续过夜(样本 seed 640247 r5-r7 deployed 缩退 6→3→2,hp 67→63→51),欠载打仗掉血。
> 方法承:P21(`proofs/p21-p2-deathbed-levelup-ev.md`)§④「受益覆盖」EV 门式与 P23(`proofs/p23-death-window-allocation-ev.md`)统一门式——本命题是两者在 **C=I=0 零支出域**的退化形;辖域关系见 §5(不触碰 P21/P23 判据常数与结论)。

## 命题

### 命题 P24.1(结构命题,已证):残余补部署严格支配整轮禁运

设某轮全部显式动作应用完毕后的轮末状态:vacancy = v > 0(板上空槽),bench 中「围栏认可且不在显式保留集」的件 u > 0。比较两策略:

- **A(整轮禁运)**:skip 轮不执行任何自动部署,板面维持现状;
- **B(残余补部署)**:对候选集执行 bench→空槽(pop-append)上场,不买卖不刷新不 swap。

则 B 支配 A:板强 S_B = S_A + Δ(u 件上阵),Δ > 0;成本侧 B 的金支出、卖出收入、利息扰动均为零。

### 命题 P24.2(量级,粗模型级):单例收益为两位数金当量级,方向恒正

按粗战力模型(`cw_coarse_battle` 结算键对上阵数单调;欠载 2-6 单位 × 2-4 轮;样本 skip 段 hp 跌幅 640247 三轮 −16),单例代价两位数金当量(1 hp ≈ 1 金,P21 口径);合并四波狩猎频率 ~1.5-3% ⟹ 批级期望亚金/局。修复的主要收益不在期望增益本身,而在 **sim 分布保真**(欠载局的 P1 板深/血样本系统性偏差,波及一切 sim 判读)。

## 证明(P24.1)

**收益侧**:u 件上阵后板强增 Δ > 0(粗战力模型下板强对上阵数单调;`cw_coarse_battle` 结算键单调依赖板面)。按 P21/P23 的统一 EV 门式,B 相对 A 的期望净值变化:

```
ΔEV = Δp·Σ_j L_c·S(b_j) − C − I
```

B 臂 C = 0(无现金支出:bench→空槽 pop-append 不触碰金)、I = 0(无破息:金余额逐轮不变,利息分档不动)。故:

```
ΔEV = Δp·Σ_j L_c·S(b_j) ≥ 0  恒成立;且 Δp > 0 时严格 > 0
```

即**任何非负受益在 C+I=0 域内都不可能为负**——不存在使 A 优超 B 的参数点,B 弱支配 A;u > 0 且 Δp > 0 时严格支配。□

**A 的唯一名义优势已消解**:A 的全部理由 = 裁决1「显式>围栏,同轮互斥」(防同一部署通道双写)。该保护由**显式保留集**编码进候选集:显式通道刻意留在 bench 的件(3合1 素材副本 + locked 持有名单的 final 买而不上件)从 up 集显式扣除后,补部署与显式动作不再有通道冲突——A 相对 B 无残余差异。□

**成本侧零性核验(实现级)**:补部署动作面 = `deployed_place` + bench 置 None,不经过任何 spend 记账点(金账恒等式 gold_before + inc − buys − levelup − refresh + income 各项均不受影响);回归锁 `test_cw_f1_residual_fill.py` 锁 1/锁 3 断言金不变。

## 与 P21/P23 的关系(辖域不触碰声明)

- **P21 辖** P2 濒死段(hp ≤ 10)**支出**(升级雨 EV < 0);**P23 辖**死亡窗**支出分配**(停手窗/死亡域两域门)。本命题辖**零支出域的部署行为**,不辖任何支出决策——残余补部署不在两者的辖域内,不触碰其判据常数(H₀、L_c 系、Δp*)与结论。
- **不解除任何血预算停手门**:停升级门、刷新停付、终止降格短路全部照旧——本命题只作用于轮末部署块,不进任何支出决策位。
- **濒死域兼容**:濒死帧若发生显式动作轮,残余补部署仍执行——这是正确的:它不上新件不花钱,只是把已购件摆上空槽;P23.4 引理下 V(π) > 0 ⟹ 严格不劣于攥着。濒死止损的语义是「别再花钱」,不是「把买好的人摁在 bench 上」。
