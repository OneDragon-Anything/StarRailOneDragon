## 2. 公理栈五条（框架地基，不再论证）

（出处：旧总纲 §0，git 历史可溯；编号沿用）

1. **零调参**：禁拍死值顶替未标定参数；数值判据必须可溯源（注册表/推导/带 CI 的估计）；未标定项 fail-closed（=读不到数据/条件不满足时默认走保守分支不动作）或走支配性结构判据，不塞拟合常数。
2. **超额收益隔离**：一切证明在「连胜 = 0」的底线口径上成立；连胜成长价值是上行注记，只增不改向（P51 §F.4 / P43 §⑥）。
3. **纯金流记账**：血（hp）不入任何账与自变量——hp=0 仅是死亡事件定义；胜率/掉血只经 λ_death 的概率侧进入决策（P51 §R.3 / P15v2 消费限制 / [39]（HP 不作决策依据）裁定）。适用范围注记：经 λ_death 的概率路由键（λ 查表键血带维）间接入场系用户裁定二既裁例外——概率侧非价值侧（00 §3 硬闸门口径）。
4. **阅读门**：证明件须过无偏对抗审查后方可消费；命题可否引用以 `math_proofs.md` 索引状态列为准（站住者可消费，作废/不成立者禁引，待证明者按 §7 钩子处置——结构占位，默认行为退常规门/骨架义务）。
5. **参数溯源**：框架内每个数字标来源（四种：【注】/【推】/【拟】/【拍】，见 §6 章程）。

**玩家裁定三条**（2026-09-01，最高权威；见已删除旧总纲 §0，git 历史可溯）：

后续关键裁定（正典化收录）：λ 查表键选型 = B1（数学优劣全口径占优，旧总纲裁定一，git 历史可溯）；安全带架构 + 两验收条件（00 §4）；λ 基座转入观察名单（禁稳态表述，00 §6）；度量家族冻结为当前形态（旧审查件裁定，git 历史可溯；不确定性帧一律默认安全，维持发展主线；只许修正错误记录，禁新增验证装置）。

### 3.4 刷新

## 8. 两条总纲级不变量（旧审查件要求落地，git 历史可溯；本链一切判据的审查尺）

1. **位面参数化不变量**：任何机制谓词的适用范围条件中**不得出现位面字面量**；位面只允许作为（节点数表/伤害锚表/档位表）的查表键进通用模型。逐格扫判据表，违例格按通用化重写（先例：p2_spend_auth 位面适用范围门废除 → 支出授权谓词 + sink 缺口参数；「位面 2 中间段」补条 → 通用目标态定义，见 [12_line_and_intention.md](12_line_and_intention.md) §1/§3 与 [11_shop_decisions.md](11_shop_decisions.md) §5）。
