# 大月卡(无名勋礼/无名客的荣勋)购买路由

> 画面细节见 `docs/game/screens/无名勋礼.md`(主面板/购买推广页/等级加速弹窗/规则说明四屏);本文管操作路由与状态解读。

## 1. 机制(游戏内规则说明 2026-11-12 实读)

- 无名勋礼 = 战令(玩家称「大月卡」),**每版本一期**(本期为 5 周缩短版,剩余时间在主面板顶部),满 70 级,解锁需开拓等级 13+。
- 双轨奖励:免费轨「无名客的赠礼」每期默认解锁;付费轨「无名客的荣勋」需购买解锁。
- **付费档位两条**:「无名客的荣勋」(标准档,解锁立即返 **680 星琼**)与「无名客的奖章」(更高档,立即 +10 级);价格人民币金额以付款弹窗实显为准(重复购买补偿换算:荣勋返古老梦华×750、奖章×1410、荣勋授章×860——重复买不白买,直接返还)。
- 付费轨 + 勋礼等级达 30 → [星海珍藏](../docs/game/screens/无名勋礼.md) tab 任选一个本期光锥(购买入口不在该 tab,唯一入口在奖励 tab 右下)。
- 任务分本周任务(每周一 04:00 服务器时间更新)与本期任务;勋礼等级到上限后任务不再产出经验。
- 版本周期内**第一次**进无名勋礼先落整屏「购买推广页」:点「开启无名勋礼」是查看/继续语义**不会付费**(用户裁决),经「等级加速弹窗」后才到主面板——op 已自动处理该前置链。

## 2. 操作路由

| 步骤 | 用什么 |
|---|---|
| 查状态/看购买入口 | op `BuyNamelessHonorPassOp(open_pay=False)` —— 从任意画面到主面板并确认未购买态入口可见,成功状态 `AT_ENTRY`,零消耗;主面板可读 勋礼等级/剩余时间/本周经验上限/「解锁立即获得×680」 |
| 确认购买意愿 | 与用户确认(消耗门,见 SKILL.md 红线);顺带确认支付渠道偏好(支付宝/微信) |
| 打开付款码 | op `BuyNamelessHonorPassOp(open_pay=True, pay_channel='alipay'或'wechat')` —— 自动重新导航(幂等)→ 点「解锁无名客的荣勋」→ 付款弹窗 → 按渠道就位,成功状态 `PAY_OPENED`。⚠️ **支付弹窗段待实机验证**(见 §4),首次实跑须在现场核对弹窗形态 |
| 交还用户 | 告知「付款弹窗已就绪(渠道 X),请扫码完成支付」;bot 止步 |

- op 源文件:`src/sr_od/application/cultivation/account/operations/buy_nameless_honor_pass.py`。
  MCP `run_operation` 的 `op_id` 直接用类名短名 `BuyNamelessHonorPassOp`(短名全库唯一即运行)。
- 判「本期是否已购买」:未购买态 = 购买按钮 +「解锁立即获得」提示条双锚可见;两锚均消失 =
  可能已购买(op 显式失败报告,勿凭猜断言已购——也可能是面板异常)。
- 收尾清理(用户放弃支付):预计与商店扫码弹窗同款(右上 X → 「确认放弃本次支付?」→
  确认放弃),坐标与是否同弹窗待实机验证后回填。

## 3. op 状态与失败去向

- `AT_ENTRY` = 已到主面板且未购买态购买入口可见(open_pay=False);
- `PAY_OPENED` = 付款弹窗已打开且渠道就绪(open_pay=True);
- 失败:导航失败/周期首进退出链异常/购买入口缺失(可能本期已解锁付费轨)/付款弹窗渠道
  按钮未命中(弹窗形态待实机核查或异常)。

## 4. 待条件(未实证,如实告知用户)
