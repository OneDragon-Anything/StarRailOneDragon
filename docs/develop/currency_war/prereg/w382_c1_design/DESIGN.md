## 0. 一句话结论

**末窗「金该花还是攒」的期望账在当前标定下单向倾斜:溢余段(g>50)花金零息损(P11 已证),必花且定向投 boss 战力;息线以下的破息花金,其利息成本(≈1.5~10 金/轮折算)远大于可证的 boss 胜率收益(Δp×13.35 金/单位胜率),破息分支按账默认不触发。** 因此 C1 不引入新的预算通道,裁决为**与 FLIP 末窗投影臂同锚两分支的正交补集**:FLIP 管「投影必入应急带」的强制泄息(d<25),C1 管投影安全带(d≥25)内「溢余定向 + 破息过账」的取舍;破息分支挂 Δp(X) 实测缺口,数据到位前不落码。

## 1. 问题定义与辖域

### 1.1 设计问题

P1 末窗(boss 前窗,锚 = 本轮 node_type==boss 的首个买相位,单轮 latch,同 ADR-0426 末窗定义)出现「金多血少」帧时:金该花(找件/升级 → boss 战胜率↑ → 少吃 boss 税)还是攒(守息线 → 利息收益)?现状缺血量维度的主动取舍:FLIP 末窗投影臂只在「hp−boss_tax_p75<25」(战后必坠应急带)时强制泄息溢余,投影安全带内没有任何血量维度的决策,W350 §7 指认 P1 出口血量管理为第一杠杆(W377 量化:前 5 轮胜场 0/1/2 → 出口 hp 中位 21/35/48,+13~15 hp/胜)。

### 1.2 C1 不是连胜规则

W377 §5 已裁:「花保连胜」不立(连胜局无额外投入,投入产出比 >9:1 来自既有溢余自然滚),且触发条件禁用「前 5 轮连胜≥3」(sim/实机两侧覆盖率均 0%,规则永不生效)。C1 的裁决变量是 **boss 战胜率的金边际**,与连胜标签解耦——见 §4 口述对照。

## 2. 量化骨架(可复算)

### 2.1 收益侧:花金 X 的 hp 期望

花金 X → boss 胜率提升 Δp(X) → 期望少吃的 boss 税:

```
Hp_gain(X) = Δp(X) × E[损血 | boss 败]
```

- **E[损血 | boss 败]**:registry `boss_tax` 组(P1 语料 66 场掉血事件;掉血只在败场发生,组内即条件口径——落码时须复核此点,见 §5 缺口②)。代入 mean=26.7 hp。按 P15 纪律必须配**条件**胜率:Δp 定义为「同板面、花 X 与不花 X 的条件胜率差」,禁用无条件均值与 Δp 双计(P15 口径命题,`docs/game/currency_war/research/proofs/p15-p1-vd-benefit-calibration.md`)。
- **后继链**:省下的 hp 带进 P2 → 折金按单一源 `hp_to_gold`=0.5 金/血(registry;W377 §1 同源引用)。链价值 = Hp_gain × 0.5 金。**注意这是收益折算口径,不是「hp 值多少钱」的绝对声明**(P17 教训:末端量只作度量仪读数)。

```
Gold_gain(X) = Δp(X) × 26.7 × 0.5 = Δp(X) × 13.35   [金当量]
```

### 2.2 成本侧:利息账

P1 boss 是位面末战;末窗花金后,金跨位面继承,利息在 P2 继续按轮结算(5 金/轮 @50 封顶,1 金/轮 per 10 金档)。分两段:

- **溢余段(g>50)**:持有边际恒 0,花金**零息损**——P11 已证(参数无关确定性结论,ADR-0426 引)。成本 ≡ 0。
- **息线以下(g≤50)**:花 X 金破息,息损 = Δfloor(g/10) × R̄,R̄ = 花后剩余生息轮数(≤50 封顶内每掉一档损 1 金/轮;[11] 同档零息损,贴档线 ±2 金按 [22]④ 凑息账)。R̄ 的期望受 P2 死亡率压制:实机 P2 死亡率 93%(W350 §2),死亡路径典型「中段砍到 hp=1 再被收尾」(W350 §4),**期望生息轮数有限**,保守区间 R̄ ∈ [4, 10](下界≈存活到中段,上界≈满轮;精确值未标定,§5 缺口③)。

### 2.3 取舍阈值 X* 与判定式

```
花 X 当且仅当:Δp(X) × 13.35 > 息损(X, g, R̄)
线性近似 Δp(X)=k·X 时:k > 息损 / (13.35 × X)
```

**代入验证(破息分支)**:从 45 金花 15 金(45→30,跨一档)= 息损 1×R̄ = 4~10 金。要求 Δp(15) > 4~10 / 13.35 ≈ **0.30~0.75**——即花 15 金须把 boss 胜率抬 30~75 个百分点,量级不可信。

对照现有最乐观的传导链 proxy(P17 的 +8 hp 推导:22 金 → 11 刷 → p̄0.35 × 11 ≈ 3.9 件 → 形态一档 → 减税期望 [2,7] hp/场 × 末窗剩余战斗 1-2 场):其中 boss 项上限 7 hp → 隐含 Δp(22) ≤ 7/26.7 ≈ 0.26,k ≤ 0.26/22 ≈ 0.012/金。门槛 k* = R̄/(10×13.35) = R̄/133.5 ≈ **0.03~0.075/金**(R̄=4~10)。**proxy 上界比门槛低 2.5~6 倍 → 破息分支当前账面不成立**,且该 proxy 还是偏乐观的上界(P17 自声明 ±5 容差、乘积链任一级失真即失真)。

**溢余段**:成本 ≡ 0,任何 Δp>0 的定向花费都过账 → 规则退化为「必花 + 定向 boss 战力(找件/升级优先于无差别购买)」——这大半已被 [17](>50 即花)+ FLIP 持续兑现臂(hp<40)覆盖;C1 的增量只是**花处优先级**(末窗帧内把溢余优先投向找件/升级而非囤积向买),不是新预算。

### 2.4 骨架结论

| 花金区间 | 利息成本 | 判定 | 规则含义 |
|---|---|---|---|
| g>50 溢余段 | 0(P11) | 恒过账 | 必花,定向 boss 战力(增量=优先级声明) |
| g≤50 同档内([11] 口径) | 0 | 恒过账 | 既有零息损购买,不变 |
| g≤50 跨档破息 | Δ档×R̄ 金 | k 须 >0.03~0.075/金,当前 proxy 不达 | **默认不触发**,挂 Δp 实测(§5)后重裁 |

## 3. 规则形式与辖域裁决

### 3.1 候选与裁决

| 候选 | 裁决 | 理由 |
|---|---|---|
| A. 独立阈值规则(末窗内 g、hp 双阈值直接花) | 否 | 阈值无推导出处(数学先行硬门),且与 FLIP 同谓词空间会造成双触发 |
| B. 分段规则:按投影残差 d = hp − boss_tax_p75 分带 | **采纳** | 与 FLIP 共享同一锚(boss_tax_p75 投影语义),带间互斥,可证 |
| C. 并入 FLIP 投影臂(放宽谓词) | 否 | FLIP 是**泄息义务**(无账、预算恒 = 溢余段);C1 是**期望账取舍**(有账、含破息候选)。语义不同,合并会把「义务优先」的防双主机制(ADR-0426 Decision 2)搅浑 |

### 3.2 裁决:B,与 FLIP 末窗投影臂 = 同锚两分支的正交补集

末窗帧按投影残差 d = hp − boss_tax_p75 分两个互斥分支:

- **d < emergency_hp(25)**:战后必坠应急带 → FLIP 投影臂强制泄息(既有,义务,不动);
- **d ≥ 25**:投影安全带 → C1 辖区:溢余必花且定向(§2.4 第一行);破息候选须过 §2.3 账,当前默认不触发。

裁决要点:①**正交**(辖域按 d 一刀切,不重不漏)而非合并;②**同锚**(两分支共用 boss_tax_p75 单一源,末窗定义/单轮 latch/hp_trusted 可信位均沿用 ADR-0426 既有语义,不造第二判定源——ADR-0426 §3 死分支教训的辖域面推论:C1 未来落码必须挂 `v3_release` 同级的活判定源,禁在评分层重算末窗谓词);③预算仍走 ADR-0426 三方合并表,C1 不新增第四预算源——其「定向」语义落**花处优先级**(候选评分的末窗权重),不落预算下界。

### 3.3 无重叠声明

| 既有辖域 | 条件 | 与 C1 关系 |
|---|---|---|
| 应急清仓 | hp ≤ emergency_hp(25) | C1 显式让位(filters._is_emergency 接管,d<25 分支由 FLIP/应急分层消化) |
| FLIP 末窗投影臂 | 末窗 ∧ 未成型 ∧ g>50 ∧ hp>25 ∧ d<25 | d 边界互斥;FLIP 命中帧 C1 不评估 |
| FLIP 持续兑现臂 | 非末窗 ∧ hp<40 | 帧集合互斥(C1 仅末窗) |
| press 通道(ADR-0427) | 目标外同名副本购买序 | 维度不同(买侧副本序 vs 预算取舍),帧可重叠但决策不重叠 |
| 攒息规则 [17]/[28] | g≤50 守息 | C1 破息分支是其**显式例外**,须过账,当前默认不触发 |

## 4. 口述对照

- **[28] 双指标目标函数(息基保住 × 形态达标)**:相容。C1 溢余段分支不动息基(>50 本就在息基外);破息分支本质是「息基 ↔ 形态/boss 胜率」两指标间的显式交换,正是 [28] 过程纪律所要求的「必要的小额破息按 [19] 三态谱裁决」的末窗特例——账不过 = 不必要 = 不破。C1 不把 hp 或出口金立为验收目标([18]/[28] 禁),只作决策输入。
- **[19] 花保连胜裁决变量**:相容且被精化。[19] 三态谱的裁决变量 = ①连胜在手 ②血量安全边际 ③来牌顺不顺;W377 已裁「花保连胜」无正收益(变量①在 P1 末窗无兑现面——末窗是 boss 战,连胜金意义止于本窗)。C1 把裁决变量收敛为「boss 战胜率的金边际 vs 息损」,即 [19] 变量②③在末窗的期望值形式;连胜触发条件全面回避(W377 陷阱:「前 5 轮连胜≥3」两侧 0% 覆盖,禁用;本设计触发条件只用 d 投影残差,与连胜计数零耦合)。
- **[11] 无损购买**:直接继承——C1 各分支均不拦同档零息损购买(d≥25 辖区内照常)。

## 5. 数据缺口声明(挂账,落码前置)

1. **Δp(X) 无实测**(核心缺口):末窗投入 → boss 胜率的关系目前只有 P17 传导链 proxy(偏乐观上界)。需采集:末窗买相位帧的投入台账(买/刷/升级分项金额)× 赛前板面强度评分(形态档/核心星级)× boss 战胜负,按投入分组估条件胜率曲线;建议挂 data-collection(语料 outcomes 已有逐轮 hp/node,缺末窗投入分项与板面快照的关联字段)。Δp 到位前 §2.4 第三行「默认不触发」不得翻案。
2. **E[损血 | boss 败] 口径复核**:registry boss_tax mean=26.7(p75=34/p90=36/max=58)推定组内即败场条件口径,落码前须用语料显式验证(混入胜场 0 掉血会把均值稀释、收益侧低估)。
3. **E[R̄](期望生息轮数)未标定**:P2 死亡率 93% 下存活轮分布可直接从既有语料 runs.jsonl 离线统计,低本钱,建议下一分析批补;本设计用保守区间 [4,10],结论(破息不立)对区间两端均稳健(§2.3)。
4. **「花保连胜」实机覆盖未决**(W377 遗留):与 C1 无耦合(触发条件已解耦连胜),仅记录——若未来任何连胜类候选复活,触发条件用「前 5 轮胜场 ≥1」或「全 P1 max_streak ≥2」(覆盖 12.8%~18.2%),禁用「前 5 轮连胜 ≥3」(0% 覆盖,永不生效)。
