# 投资环境策略层迁移 迭代设计（总纲）

## 0. 元信息
- 迭代目标：宪法第五条（框架层/策略层所有权边界）与第六条（一画面一策略文件、一画面一文档）的**首批兑现**——投资环境画面策略从 kernel 迁入策略层，评分模型从「多标尺层次压制」换代为「统一加法标尺」。
  裁定指针：宪法五/六（`strategy-docs/00_framework.md` §1 第 5/6 条，用户裁定 2026-09-23）；时代族零分裁定（用户 2026-09-23：品质重排只是换随机方式，整体期望不变）。
- 状态：定稿（对抗收敛，报告 = [attack.md](attack.md)；立场系数表初值经裁决窗生效，见 §2.6）
- 文档清单：无详设（单文档方案，§2 即完整设计，深度 = 详设级）

## 1. 问题与动机
- 现状症状：
  1. 评分本体驻 kernel（`kernel/cw_events.py::decide_event` env 分支 + `cw_investments.ENV_PICK_VALUE` 环境条目 + `ENV_FACTION_MATCH_FLOOR` + `GIFT_FLOOR_*`）= 宪法五违例存量；`cw_investments.py:1003-1006` 旧归属声明（「用户裁定:保留 kernel」）与新宪法正面冲突。
  2. 异标尺七层 max() 硬压：裸分（0-72）/送卡档（54-66）/阵营 floor（70-78）/经济域带（111-119）各标尺不可比，全靠层次常数定先后；已实证一处语义矛盾——`cw_events.py:436-437` 注释声称 floor「压过全体 env 裸分(上界 72)」，但邀请 floor=70 < 彩虹时代裸分 72。
  3. 开局方向盲区：开局帧无锁线无信号（D*=∅），阵营 floor 层整层不触发，整局最影响走向的环境选择完全由拍值裸分承载；`cw_comps.ENV_COMP_AFFINITY`（环境→线亲和）只喂意向机（`cw_intention.py:1210`），不参与环境选择本身。
  4. 刷新判据不看次数：仅「全集门失格 ∧ 非 priority」的零价值槽建议刷（`cw_events.py:570-572`）；刷新剩余次数的机会成本、重掷的期望提升均不入式。
  5. 文档面：`strategy-docs/25_event_overlays.md` 打包约十个画面（宪法六违例存量）。
- 根因归层：**分层语义**（判据原语与策略 policy 未分离，宪法五）+ **表示**（评分用多标尺层次压制而非单一可比标尺）。
- 解决到哪：环境画面一个迁移批——新画面策略文件 + 三个共用模块 + kernel 剪除 env 轴 + 文档拆分（28 号稿新建）。
- 明确不解决：投资策略屏/补给/遭遇等其余画面的迁移（后续批，共用模块为其预留复用形态）；时代族等未建模环境的估值建模（立场=0 已裁定）；蓝海「随机环境」期望（均匀分布假设未证，登记待证）；`cw_events` 策略轴与评估表 335 条（投资策略屏迁移批）；`ENV_ECONOMY_PENDING_MODELING`（轮岗/人才下沉）参数化。

## 2. 方案

### 2.1 文件组织（宪法六）
- 新增画面策略文件 `strategies/impl/mandate_v1/invest_env.py`：决策入口 + 四价值组件 + 立场分表 + 刷新判据 + 交互规则，全在本文件。
- 新增共用模块（与 `deploy_plan.py` 同级，mandate_v1 内跨画面共用；跨策略提升留第二个策略出现时，取舍见 §2.11）：
  - `strategies/impl/mandate_v1/line_value.py` —— 线的价值（§2.4）
  - `strategies/impl/mandate_v1/gift_value.py` —— 赠卡价值（§2.5）
  - `strategies/impl/mandate_v1/env_economy.py` —— 环境经济通道折算（自 `kernel/cw_env_economy.py` 整体迁入，§2.3）
- 迁移后依赖方向：`strategies/impl/*` → kernel（`cw_comps`/`cw_investments`/`cw_chars`/`cw_game_state`/`cw_vocab`）单向；kernel 无任何指向 strategies 的 import（env 轴剪除后自然成立，`cw_events.py:26` 是现役唯一 kernel→cw_env_economy 边，随剪除断开）。

### 2.2 统一标尺
- 单位 = 分；**1 分 := 1 金等价**（归一化约定，非语义拍值；XP 折算沿 `cw_env_economy.XP_GOLD_RATE = 1.0` 承载）。
- 总分 = 现金分 + 方向分 + 赠卡分 + 立场分 + 转向轴加分；argmax 取最高，平分取先。
- 禁选（config env_forbid 命中）= 排除出候选；自拆台（§2.8）= 排除出候选。
- 加法合法的前提纪律：所有分值声明为同一标尺上的量，分差有含义；立场表按「分值思维」维护（拍的是量级与差距，不是名次）。旧表名次思维值全部作废，不复用。

### 2.3 现金分（`env_economy.py`，自 kernel 迁入）
- `kernel/cw_env_economy.py` 整体迁 `strategies/impl/mandate_v1/env_economy.py`：A/B/C 通道公式、fail-closed 门（缺参/CI 方向不闭合 → 现金分 0）、估算注册表（`ENV_ECONOMY_ESTIMATES`，值/CI/来源/截止申报）、治理构建校验，全部原样保留——这部分纪律经审评确认健全（数据批 2026-09-12，Wilson 95%，n=114 完成局）。
- **阈值刷新环境拍平价**（用户裁定 2026-09-23：证明归证明，实现按 P97 均值刷新次数拍定固定价值，不建运行时预算器）：`gold_after_refreshes` 系（长线利好/二手市场）估值 = **无条件拍值注册**（策略层 `env_economy.py` 内拍值表，P97 为锚定依据 = `proofs/p97-refresh-budget.md`）：
  - 二手市场 = **30 金**（用户拍定；阈值 20 次总刷新，P97 实证 20/20 阵容可达 → 全局兑现，价值 = 返金 30）；
  - 长线利好 = **50 金**（建议值，3.1 裁决窗确认；阈值 30 次付费刷新，P97 均值 60.5 次/19-20 阵容可达 → 价值 ≈ 返金 20 + 过阈值节省 ×(均值 60−30) ≈ 50）。
  - 拍值无条件计（可达性已由 P97 确立），不读局内刷新计数、不做按阵容预算分支。
- 迁移中变更其余两处：
  1. 删 `ECON_VALUE_NORM` 域带归一（现金分直接按金等价计，不再进 111-119 带）；
  2. 治理校验删除「域带上界越界」项（无域带则该项无语义），保留 C 类变体映射校验与「待建模/ENV_ECONOMY 双登记」校验。
- 留 kernel 不迁：`cw_investments.ENV_ECONOMY`（通道结构 = 游戏效果原文的结构化，【注】）与 `ENV_ECONOMY_PENDING_MODELING`。
- `tools/cw/env_economy_estimates.py`（重采入口脚本）与 `tools/cw/env_pool_rewrite_estimates.py` 的 import 路径随迁更新；刷新分布两参数的重采面随退役删除。

### 2.4 方向分（`line_value.py`，新）
- 定义：**方向分 = 线价值**，其中候选线集按以下口径确定（依据 = 阵容库 `kernel/cw_comps.py::COMP_LIBRARY`（20 条，S×2/A×10/B×8，字段 factions/strength 直调））：
  1. 基础集 = 未被 evicted 排除 ∧ `comp.factions` 含该环境阵营的阵容；
  2. 意向已锁线 ∧ 非降格帧 → 基础集 ∩ {锁线阵容}（锁线不含该阵营 → 空）；
  3. 未锁线 **或降格帧** → 基础集全体取 `max(线价值)`。
- 降格帧（demoted_endgame）按未锁线口径：旧口径在此帧强制无对齐（防已放弃方向经资产信号复活，`cw_events.py:150-152`）；新模型方向分不消费资产信号，复活通道不存在，只需忽略锁线（降格 = 终局锁线已放弃）。
- 线价值 = 强度档分（§2.6 表 1）。未锁线时按版本先验取 max，不做信号加权（申报：信号精细化挂账，v1 先验口径对开局帧正确、对局内未锁线帧偏宽松——旧口径此时只有信号线计分，新口径所有兼容线计入，见 §2.10 行为申报）。
- 适用面：概念股 15 条与邀请 20 条（阵营来源 = `cw_investments.ENV_FACTION`，名字派生 + 例外表，直调）。概念股额外加赠卡分（§2.5 随机口径，承载「白得该阵营角色」；「找牌概率提高」与「初始简易装备」v1 不计，申报低估向）；邀请只计方向分（效果原文 = 获得该阵营星徽，`cw_invest_data.py:1115` 等）。
- 数据依赖已核：角色阵营注册 = `data/cw_chars.py` CHARACTERS.factions + `chars_by_faction()`（`cw_chars.py:28/220`）。

### 2.5 赠卡分（`gift_value.py`）
- 具名赠卡（契约 ×7 + 特邀专家 ×4，结构 = `cw_investments.ENV_GIFTS` 留 kernel）：档位判定复用 `kernel/cw_comps.gift_hit_tier`（角色在候选套中的身份档 = 机制事实判定，按宪法五判据线留 kernel；本模块只做「档→分」映射）。即时集取最高档，条件集降一档——机器现状，不改。
- 档→分（§2.6 表 2）；advisor（付费顾问期权，特邀专家 ×4）按同档分 × 0.5（「付费期权 < 白得」语义，承载旧 `GIFT_FLOOR_ADVISOR_CORE < GIFT_FLOOR_CORE` 的序）。
- 随机阵营赠卡（概念股「获得【某阵营】角色」）：该阵营注册成员（`chars_by_faction`）在未排除候选阵容名单（core∪shared∪transition）中出现者的档位**算术平均**（随机发放取无偏口径；具名发放取最高档的口径差异 = 确定性赠卡承重面，沿旧机器 §2.1.2 规则①）。无成员在册 → 0。
- 赠卡失格删除：白得卡全员集外 → 赠卡分自然 0，不再把整环境清零（旧 `env-gift-off-universe` 整体失格规则删除；环境其余成分照常计分）。

### 2.6 立场系数与立场分表（全部【拍】形态，每条带理由；初值 = 本设计建议值，用户裁决窗 = 落地阶段 3.1 验收）
- 形态申报：立场分是用户策略立场的登记值（宪法五：策略立场归策略层），不是【注】/【推】/【拟】任一形态的推导产物；合法性来自裁定本身，表行必须带理由。

### 2.7 刷新判据（invest_env.py）
- 建议刷 = 帧内存在禁选槽 ∨ 帧最好总分 < 刷新阈值。
- 刷新阈值 = 全部 83 条环境总分的**均值**，构建期由注册表+系数+立场表派生为常量（单一源 = 表，不手维护数字；表改则阈值自动随动）。依据：重掷免费，重掷后帧最好的期望 ≥ 单抽期望 = 全表均值（实际 E[max of 3] > 均值，取均值 = 保守向，不高估重掷收益）。不取「下三分之一分位」——立场 0 值条目多（29 条），分位阈值会沉到 0 附近令判据失效，均值对 0 值堆积稳健。
- 次数闸 = `gs.env_refresh_left ≥ 1`。**机会成本 v1 不建模**：同分布假设下未来帧的候选分布与当前帧一致，「留着以后刷」无期望优势；「局内有信号后刷新的价值更高」（方向分可判）登记为待证假设，归后续数据批，v1 不入式。
- 输出契约不变：建议刷 = `CwActionRefreshInvestCardsParam`（handler 的 obs.refresh 现读闸 + 容器 `env_refresh_left` 对照闸原样，op 层零改动）。

### 2.8 交互规则（invest_env.py）
- 自拆台排除：板面 持续伤害+减益 ≥2（`gs.board` 计数，沿旧口径）→ 候选中克制 DoT/减益者排除（机制归一 = `AFFIX_MECHANIC_MAP`/`MECHANIC_COUNTERS`，kernel 表调用——「某选项是否克制某机制」是事实判定，留 kernel；「排除它」是策略，在画面文件）。
- 用户轴：forbid = 排除；priority = +30（固定偏好分，立场系数；软偏好，压不过 S 线方向分，符合「用户点名是偏好不是支配」语义）。

### 2.9 接口契约（跨批定死，投资策略屏迁移批复用）

### 2.11 关键取舍
- **统一加法标尺 vs 保留层次压制**：加法要求全部成分可比，换算锚（1 分=1 金等价）与档间系数成为显式拍值点；选它因为拍值从 83 条裸分缩到约 20 个系数/立场值、集中一张表、可审计可版本重拍。层次压制的「严谨感」来自把拍值藏进层次结构，审计面更大（邀请 floor 语义矛盾即实证）。
- **共用模块落 mandate_v1 内 vs 跨策略共用包**：第二策略不存在，提前抽公共包 = 无消费者的抽象；与 `deploy_plan.py` 先例同构（mandate_v1 内多画面共用），第二策略出现时提升。宪法六「抽离到合适的文件」在当前语境的合适位 = mandate_v1。
- **随机赠卡期望平均 vs 最高档**：随机发放无偏口径取平均；具名赠卡（确定发放）取最高档沿旧机器规则①。两者口径差异 = 确定性差异，非双重标准。
- **蓝海「随机环境」期望不计**：均匀分布假设未证（游戏随机池构成未知），登记待证；现金分只记 6 金（`ENV_ECONOMY` gold_instant，原文直读）。
- **概念股「找牌概率提高」「初始简易装备」不计**：找牌加速的换算需要刷牌概率模型（`cw_shop_odds` 在册但未接入估值），装备域无估值模块；均登记低估向，v1 申报。
