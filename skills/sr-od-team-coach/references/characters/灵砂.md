# 灵砂（火·丰饶·5星）

> 按 V4.7 期撰写。击破转治疗的攻击模型丰饶；浮元追击奶与烧血体系天然咬合。

## 一、命途属性与技能说明

**命途**：丰饶
**属性**：火

| 技能 | 说明 |
|---|---|
| 普攻 | 单体火伤 |
| 战技 | 治疗单体（10%攻击+105）+ 召唤/联动浮元 |
| 终结技 | 消耗能量；AoE + 治疗（8%攻击+90）+【醇醉】敌方受击破伤害+15%（负面→黄泉充能源） |
| 天赋 | 召唤浮元（初始90速）：本体行动越多浮元越频繁；「遗爇」：**队友扣血且有人≤60%血时浮元立即追击+群奶**【官】——与烧血体系天然咬合 |
| 秘技 | 进战召唤浮元+挂醇醉 |
| 额外能力 | 「朱燎」：击破特攻的25%/10%转攻击/治疗（上限+50%/20%） |

**资源与循环**：标准能量→充能有效。

## 二、推荐遗器与光锥（与原因）

**光锥**：专武为毕业位（专武名以米游社百科/游戏内为准）；下位替代链 B站视频未提供——【待补：后续攻略轮补齐】。

**套装**：云无留迹的过客4件 + 盗贼公国塔利亚2件【攻：社区口径】
- 过客4：治疗系套装+开局+1战技点（团队经济）
- 塔利亚2：≥145速击破增益——击破转化的源头属性；速度也喂浮元频率

**主词条**：

| 位置 | 推荐 | 原因 |
|---|---|---|
| 躯干 | 治疗量加成/攻击% | 治疗按攻击结算 |
| 脚部 | **速度** | 浮元频率（本体回合→浮元召唤） |
| 位面球 | 攻击% | 治疗与伤害双源 |
| 连结绳 | **击破特攻** | 「朱燎」转化源头 |

**副词条**：击破特攻（→200% 吃满转化）> 速度 > 攻击%。
**转模与转化上限**：「朱燎」击破→攻击/治疗，**200% 击破吃满**（+50%攻/+20%治疗）。
**不堆**：生命%（治疗不吃生命）。
