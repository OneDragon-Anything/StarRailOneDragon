# 逐光捡金(treasures_light)

末世模式选关画面族的总 screen(`treasures_light.yml`,32 area):忘却之庭·混沌回忆 / 虚构叙事 / 末日幻影 / 异相仲裁 四分类的**内部选关与节点画面**。入口:星际和平指南 →「逐光捡金」tab → 选分类 →「传送 / 前往挑战」。`pc_alt=true`。

## 何时出现 + 状态流转

- **入口**:指南「逐光捡金」tab,点分类条目(忘却之庭·混沌回忆 等)→ 右下「传送」(忘却之庭)/「前往挑战」(异相仲裁,按钮文案随分类不同)。
- **出口**:右上关闭 X / esc → 回指南(已实测 esc 链)。
- **子态**:
  - **记忆紊流更新弹窗**:进入忘却之庭先弹(本期效果说明 + 「点击空白处关闭」,即 `NODE_FIRST_CLICK_EMPTY`)——每期一次。
  - **选关主界面**(忘却之庭):左上「忘却之庭」标题 + 期名(如 扫除风暴)+ 倒计时 + 记忆紊流;关卡水晶 07-12(3 星角标 / 未解锁);右上「快速解锁」提示条;左下 奇珍琳琅 商店;右下 星芒计数 0/36 + 礼包。
  - 异相仲裁大厅:骑士(一/二/三)棋盘选关 + 接受试炼 + 战绩回顾 + 星尘之礼(未建档候选,见备注)。

## 识别特征(稳定锚点)

- **FH_TITLE**(左上「忘却之庭」文字,rect (85,25)-(215,78),id_mark,conf 0.993)。
- 期名 / 倒计时 / 记忆紊流名(左上第二行,常驻但**内容每期轮换 → 不作 id_mark**,ADR-0023 流程实例)。
- 关卡水晶编号 / 星标 / 未解锁态(动态)。

## 可交互元素(2026-08-29 实锤:入口链 + 弹窗关闭;关卡点击未探——会进挑战准备)

| 元素 | 行为 |
|---|---|
| 分类条目(指南 tab 内) | 选中分类,右下按钮变化(忘却之庭=传送;异相仲裁=前往挑战) |
| 记忆紊流更新弹窗 | 点空白处关闭(已实锤) |
| 关卡水晶 | 进挑战准备(不点;消耗判断在挑战确认层) |
| 快速解锁 | 按历史最高自动解锁已达成关卡(提示条,非按钮) |
| 奇珍琳琅 / 星尘礼包 | 兑换商店(未探) |
| 规则说明 / 关闭 X | 弹窗 / 回指南 |

## automation 要读信息

- 本期是否已挑战:分类条目「尚未挑战」角标(指南侧)。
- 期剩余时间;星芒计数 0/36。
