# 货币战争 · 零和博弈(currency_war)

3.7 版上线的**大型常驻玩法**(赛季制,与模拟宇宙交替更新),**类自走棋(auto-battler)+ 肉鸽**。
战斗**自动进行**(非手动操作),玩家专注经济/羁绊策略。⚠️ **每节点战斗有「有限行动值(AV)」限时**(米游社百科 content/6564,存 data/gameplay.md:13;用户 2026-08-11 确认,旧记"非限时"误):未在限内消灭全部敌人 → **扣小队生命值**(非判负)→ **输出不足体现为扣血**(扣血越多越可能输出低/超时,与"扛不住"同表现为 hp 降)。→ 输出能力重要(限时内击杀),hp_trend 已隐含输出信号。✅ **结算画面仍显示「通过」该节点**(用户 2026-08-12 确认:超时**仅扣血、结算仍显示通过**,**无节点级失败态**;HP 耗尽才整局结束 —— 见下「失败」)。奖励约 4000 星琼 + 深度沉浸器 + 助燃券,

**★结算屏「通过质量」有带符号记录(用户 2026-08-18 点破:「扣血其实就是战斗失败,这个玩法里应该有记录的」)**:每轮结算屏记录该轮打得怎么样,是胜负+扣血的**游戏内真值源**:
- **「挑战进度 ±N」带符号值**:正 = 完成度高(干净赢,如遭遇 +2);负 = 未完成(输出不足被扣,如 2-1 -22)。注意「挑战成功」屏另有**无符号累计值**形态(「挑战进度 46」= 总进度,非本轮 delta)。
- **扣血明细**:「基础伤害 -N」(敌方存活单位)+「未完成进度伤害 -N」(进度未完成的惩罚)—— 扣血公式实锤(live 2026-08-18 11:32 OCR:遭遇轮 基础伤害-5 + 未完成进度伤害-2)。
- **胜负判定链**(代码 `cw_settlement_obs.parse_settlement_won`):「挑战成功」文本 > 「挑战失败」(团灭终局)> 挑战进度符号。「挑战结束」文本出现在**胜利屏与轮败屏两者**(位面结束语义),不能单独当胜负标志。
- **策略/遥测含义**:输的轮(扣血过)走 loop 3b 分支(「前往结算」),旧版从不产生 outcome 行 →「P2 输给谁/扣多少」全盲;2026-08-18 起输轮也记 outcome(killed/progress_delta)。
**周期(双周)积分每双周周一 04:00 重置**。解锁:开拓等级 21+。入口:手机菜单 → 指南(星际和平指南)→ 旷宇纷争 TAB → 货币战争。

## 玩法机制(攻略 + 实机)

### ★核心伤害与数值机制(UP 必修一 + 阵容档交叉核实,2026-08-12)

- **伤害公式 = 既有公式 × 三个 CW 新乘区**(详 [公共_核心机制](../currency_war/guides/V3.7_公共_核心机制.md)):
  1. **前后台强度**:站前台吃「前台强度」、站后台吃「后台强度」(**只看站位,与角色前后台定位无关**);伤害倍率贡献 = `强度值 × 1%`(前台强度 500 → 该角色伤害 ×5)。
  2. **伤害征服**:独立增伤乘区(类似增伤但独立结算)。
  3. **幸运一击伤害征服**:「幸运一击」类似第二层暴击率,触发时此乘区生效。**幸运一击与暴击独立计算**(显示「幸运」= 幸运暴、暴击没暴;「暴击」反之;「幸运暴击」双暴;无字双都没暴)。**幸运一击暴伤基础 100%**(普通暴击仅 50%)→ 收益更高。
  - **稀释**:前后台强度稀释最重;**伤害征服 + 幸运一击稀缺、提升大** → 优先堆后两者。→ 解释「火力风暴潮(伤害征服装)/ 幸运一击装」是各主 C 核心。
- **★CW 速度增幅独立乘算(非加算)**:大世界/深渊速度词条加算(被高速稀释),CW 中速度增幅独立乘算 → 高速角色(阿雅 400 速)吃等额比例加成。是 CW 全模式底层规则,解释双鞋风扇 / 高速流(阿雅/流萤/海瑟音)强度([阵容_阿雅昼神](../currency_war/guides/V3.7_阵容_阿雅昼神.md),🔴 跨阵容规则)。
- **★CW 后台仪器/光追/行迹不生效**:后台角色只吃「后台强度」+ 羁绊,**自身仪器/光追/行迹全不生效** → 决定谁能后台(需自带面板/被动)谁能前台(吃仪器)。停云等「必须前台才能神力解放」即此理([阵容_波提欧击破](../currency_war/guides/V3.8_阵容_波提欧击破.md),🔴 底层规则)。
- **血量与星**:**70 血 +3 星、40 血 +2 星**(血掉完不加也不掉)→ 高血量 = 多拿星 = 快上分,呼应「100 血通关」目标。未完成战斗 → 按节点位置 + 挑战进度扣血(节点越后、进度越低扣越多)。⚠️ **第三位面遭遇关勿逞强打 7-3/7-4:一次扣 70 血**。

- **对局类型**:标准博弈 / 超频博弈;通关奖励 = 周期积分(18000 上限)+ 晋升点(如 2700+1500)。周额外晋升点上限 1500。
- **职级/难度(两阶模型,2026-08-06 核实,详 [strategy/13 §13.7](../currency_war/strategy/13_input_model.md))**:
  - **职级 `selected_difficulty`**:段位 黑铁→青铜→翠钢→钴银→冰肽→紫金→投资大师→资本帝王→**财富造物主(A8,最高)**。V4.0 扩到 **A8-1 ~ A8-50**(子档,如 A8-50)。**决定起始敌人难度** + 是否带额外敌人词缀。选难度在「开对局确认」屏。
  - **敌人难度 `enemy_difficulty`(数值)**:**随节点推进递增**(节点类型不同曲线不同:遭遇/奖励/首领;V3.8 调过 —— 削遭遇敌人攻速攻击、提奖励节点奖励)。**可被投资策略压低**(「难度修改器」银 −4、部分金 −3,**最低降到 0**)。boss 血量 ≈ `base × 1.052^enemy_difficulty`(每 +8 难度 ≈ +50% 血;A8-60+ 血量几十~上百亿)。
  - **难度↑ 的后果**:敌人属性(攻/速/血)↑ + 额外敌人词缀。「第一位面最难」(A8 一层遭遇常比 boss 凶)。
  - **★节点类型 × 战力要求(2026-08-12 用户知识)**:**奖励节点 = 无战力要求,出战必过(白嫖奖励)** —— 不需为奖励关堆战力/买牌,该把金币省给成型节点。⚠️ **例外:经济过热/严重过热投资环境把奖励节点 → 次元/超级次元扑满**(扑满关**有**战力要求,要打)。其余节点(战斗/遭遇/首领)均有战力要求(限时 AV 内击杀,输出不足扣血)。→ 策略含义(node_plan / danger_d,阶段7):**奖励关白嫖省钱**(经济档 saving/interest,不堆战力)/ **扑满关要打**(经济过热时奖励关变扑满,按战斗关对待)。前置 = 下节点类型识别(3.5.5 reader 就绪:未来节点 Hu + 当前 OCR;扑满图标待经济过热样本)。
  - **★奖励节点清关奖励 = 奖励球(晶矿)面板(2026-08-14 live 建档)**:通关奖励节点后,备战右侧「区域-奖励」面板出现球形奖励(实测 1-8 清关:1 大金球 + 5 蓝球 + 2 灰球;球色疑=晶矿档位 ——「黄晶矿工」策略提「低一档晶矿」,大金球开出了工具「员工投影仪」,蓝球开出进阶装备「以太钻头」)。**点球即开启,内容即时入账**:金币/装备直接加;**角色或补给箱落备战席占 1 槽**。⚠️ **备战席满时球点不动**(球可能给角色/箱都要占席,实测 1-9 槽1 箱 + 槽2-9 共 8 角色 = 满,剩 5 球点不动)→ bot 顺序 = **先开补给箱腾席 → 再点球**。晶矿条目见 [factions.md](../currency_war/data/factions.md)(「开启后可能获取金币、角色、装备或其它稀有物品」);战斗结算的「掉落晶矿」即此类。
  - **★难度 200+ overflow bug(2026-08-12 UP 实测,[BV1wE3g6cEuU](../currency_war/guides/公共_视频目录.md)V4.4)**:难度可被投资策略/海克斯推高(伟大征服 / 万敌·无废帝 各 **+30** 敌人难度 + 连胜 + 三彩等)→ **超过 200 触发溢出 bug:敌方「攻击/防御/生命值/速度/热性 提高 -100%」→ 怪变脆皮一撞就死**。实测 A850 + 各种加成推到 **211 难度**= 当前版本难度上限。属可利用的边界 bug(非稳定机制,可能随版本修)。

- **位面**:每局 3 个位面,每位面多节点 + 首领;第一位面带强化词(如「战个痛快」)。

  - **★银狼LV.999 升星升费(2026-08-15 用户口述 + 攻略广场数据佐证)**:【银狼LV.999】**初始 3 费**;升到 **3 星后拖到场上 → 变 4 费 1 星**,4 费升满同理再变 **5 费**;**备战栏中不升费**(拖上场才触发)。游戏数据侧佐证:攻略广场 config 的 role_list 里银狼LV.999 有**三条档位条目**(id 15061/15062/15063 = 3/4/5 费)。→ 策略含义:银狼是**成长型滚动投资**(低费买入 → 升星 → 升费滚强度),备战栏囤多张时费用不升,buy/hold 决策要把"场上那张的当前费档"与"备战新买 3 费"分开算。

- **阵营羁绊(实测)**:命运圣杯 / 仙舟 / 夜之半神 / 公司 / 银河学者 / 量子 / 击破 / 追击 / 减益 / 欢愉 / 星间旅人 等;技能标签:战技点 / 能量 / 燃血 / 群攻 / 持续伤害。**关键羁绊机制(跨阵容核实)**:

- **D 牌等级表**:5/6/7/8/9 级分别找 1/2/3/4/5 费(= `cw_shop_odds.REFRESH_PROB`)。

  非目标卡,保息(利息档不降)买入压池 → 降分母提命中率 → 卖出净损 0-1
  (1 星买卖净 0)。
- **位面末**:boss 前奖励关把过渡阵容全卖吃息;进下一位面保 ≥20 金。

### S2 阵容结构(双轨模型)

- **P1 过渡阵容与最终 comp 很少重叠**(重叠双峰:38% 一条线/22% 完全换阵):
  纯过渡牌(艾丝妲 31%→2%/椒丘 31%→8%/爻光 35%→16%/饮月 44%→20%/藿藿 44%→22%);
  贯穿牌(三月七 36%→36%/千冶·刃 29%→64%/姬子/花火 24%→48%)。
- **过渡双框架**(主流仅两种):仙舟系 32%(3仙舟+2DOT 挂件)/列车系 29%(4 列车);
  V4.4 无纯 DOT 过渡(退化为 28% 的 2DOT 挂件形态)。
- **comp 二分法**(core 费级谱):可一条线(命运圣杯 61%/群攻/量子/仙舟 ≥50%,低费)
  vs 需过渡包(战技点 11%/追击 29%,高费);希儿量子 = 条件式一条线(Early 拿到才成立)。
- **双轨并行**:场上打过渡包保血(5 人口),bench 囤最终线牌(不上场,兼压池);
  定型后卖过渡(drop 档)→ 最终线上场 → 攒的钱一次拉人口+D 核心。

### S3 目标牌(动态,非静态名单)

- ①**缺谁追谁**:target/stash(过渡与最终两边)的 core 未到 2★ → 在追;
- ②**基本目标 2★**:核心输出 3★ 难凑,2★ 为主;辅助 2★ 快速完成也算;
- ③**牌运追猎**:场上已 2★ 的角色费级入追猎集(3费辅助 2★×2 → 商店 3 费
  概率最高时有几率追 3★)。
- 3合1 合并域 = **全场**(bench+deployed);场上同名卡是合并载体。

### S4 定型信号(「当前局的整体观察」)

词缀(1.5)→ P1 投资策略(2.0)→ P1 投资环境(1.0)→ 商店供给(0.5/回合持续)
→ 补给产出(0.8)→ 遭遇选卡(0.6)→ 奖励节点(0.4);累积到领先线 ≥3.0 → 定型;
**最晚 P2-3 投资选择**(最后一次有经济量转型的节点),之后锁死。低费线可早定型
(信号确认即 commit),高费线走完整双轨到 deadline。

### S5 装备模型

- 装备**角色特定**(M7):carry 先拿 key_equips 按序,其余 core 次之。
- **过渡期持有**(form < 0.4):小件乱穿 = 浪费容量+拆卸成本 → 只穿 key 命中件,
  其余攒给成型核心;成型后全投。装备 1+1 远大于 2(开局能合直接合)。
- 双鞋类机制(2 速度鞋超线性)保留 guide 语义(API 单件统计是盲区)。

### S6 站位与细节
