# 货币战争-投资策略(3 选 1)

备战内触发的投资策略选择(区别于开局"投资环境"):从 3 个策略祝福里选 1,给小队 buff。

## 何时出现 + 状态流转

- **入口**:备战阶段触发(特定轮次 / 条件)→ 本屏(遮罩在备战之上)。
- **出口**:点一张卡选中 →「确认」→ 回备战。或「返回备战界面」(右上)取消。
- 与"投资环境"(开局 74 选 1,定阵营走向)不同:投资策略是**过程中**的策略 buff(216 个池,详 `docs/game/currency_war/data/investment_strategies.md`)。

## 识别特征(稳定锚点)

- 独有文字:「请选择投资策略」+ 卡标题(XX 祝福 / XX 星徽)+「刷新次数」+「确认」+「返回备战界面」。
- 区别于投资环境:标题"投资策略"非"投资环境";有"返回备战界面"。

## 可交互元素

- 3 张策略卡:左/中/右,卡身点击选中。OCR 读卡标题 + 描述。
- 「确认」:(950,967)底部。OCR 可读。
- 「刷新次数：N」:每卡底部(可刷新该卡选项?)。
- 「返回备战界面」:(1717,44)右上。

> 全文字(OCR),无 screen_info / 模板需求。`battle_loop` 用 `INVEST_CARD_BOTTOM=(920,815)` 点中卡底选中(朴素)。

## 关键数据(策略相关 —— bot 当前朴素选,缺口)

> **策略缺口**:bot 固定点中卡底(`INVEST_CARD_BOTTOM`)。应读 3 卡 → 按 `target_comp` / 当前需求选(如缺治疗选治疗星徽、缺暴击选幸运星)。`decide_event` 白名单待接。

- **3 选项(本场实例)**:
  1. **幸运星祝福** — 得【幸运星】;小队 +15% 幸运一击率 + 5% 速度。
  2. **生命之花祝福** — 得【生命之花】;小队 +15% 生命增幅 + 5% 治疗强度。
  3. **治疗星徽** — 得【治疗星徽】+ 1 个【风堇】。
- **投资策略池**:米游社 V4.4 共 216 个(详 investment_strategies.md),每场随机出 3。
