# 货币战争-保存阵容弹窗

## 画面简介

把攻略列表卡片上的阵容存进「我的阵容」的弹窗：攻略列表卡片「保存阵容」按钮打开。上限 10，标题带 n/10 计数；主体为「存为新阵容」槽位行（空槽显示下载图标，行可滚动超过 3 行），右下「保存并收藏」勾选态提交。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标识-标题-保存阵容 | 弹窗标题「保存阵容(n/10)」（标题区未设 id_mark——档与 dev doc 的「组合双锚」描述不一致以档为准） | 纯显示 |
| 标识-保存并收藏 | 右下提交按钮（身份锚；橙色勾选框，勾选态提交 = 保存同时收藏） | 点击提交保存（存进我的阵容） |
| 按钮-存为新阵容-1 / -2 / -3 | 「存为新阵容」槽位行（空槽显示下载图标；行可滚动超过 3 行） | 点击选槽位；槽位选中态未实测（点击会实际写入用户阵容，验证时主动跳过） |
| （待建档）右上 X | 标题栏右上 X | 点击关闭（不保存）；ESC 也可取消（实测关闭回列表未保存） |
| （待建档）槽位行滚动条 | 槽位行列表右侧滚动条（10 槽超过一屏） | 拖拽滚动槽位列表 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 打开弹窗 | MCP `click_game` | 攻略列表该卡「卡N-保存阵容」area 中心 | 弹窗出现 | — |
| 选槽位 | MCP `click_game` | 目标「按钮-存为新阵容-N」area 中心 | 选中该槽位 | 槽位选中态未实测（点击会实际写入用户阵容，验证时主动跳过）；超过 3 行时先拖拽滚动 |
| 提交保存 | MCP `click_game` | 「标识-保存并收藏」area 中心 | 阵容存进我的阵容（收藏勾选态） | — |
| 关闭不保存 | MCP `click_game` | 右上 X（看图定位，未建档）；ESC 同效（实测） | 关闭回攻略列表、不保存 | — |

保存类弹窗——选槽位 + 提交；会实际写入用户阵容，按用户诉求操作。
