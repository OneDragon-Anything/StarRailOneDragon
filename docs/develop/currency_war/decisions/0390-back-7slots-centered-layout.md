# ADR-0390:后排 7 格几何勘误——整排居中重排(推翻「6 格右扩」登记)

- 日期:2026-08-26
- 状态:已实施(佩佩局交互实锤 + 覆盖拖测批)
- 上下文:ADR-0385(双通道选档,公式不变)/ ADR-0389(识别层,其「假阳带」
  量证被本篇勘误为错位伪影);本篇辖**几何登记**,与公式/识别解耦

## 背景与问题

当日早批把 7 格档登记为「槽 1-6 同 6 格坐标 + 槽 7 右扩 1387-1529
(佩佩中心 1458)」——**整体错位 +71px**。错位登记下每个窗口只盖住真台座
右半片+列间空隙,产生一族系统性伪象:

1. **身份读数=编号巧合**:立绘越界残影恰好按「窗口=N+1」读出用户口述的
   「N 号位角色」,双帧「全 PASS」实为数字学;用户三次质疑(「坐标是错的」
   「中心可以点」「佩佩图也截错了」)全部命中。
2. **假阳带/弱命中**:「空槽背景 11-26 假阳带」「万敌 8 内点漏读」全是
   错位窗口截到邻卡残影/半片立绘的伪影——真窗口下空槽全库 0 分、plaza
   主档也能 33 分命中(ADR-0389 该部分量证作废)。
3. **拖拽/点击全灭**:点旧记中心(604/746/1458)无响应;板内拖拽拾取失败。

## 勘误证据(交互实锤链)

- **点击面板探针**(用户判据:点真中心必开详情):点 537/1390 开万敌/佩佩
  详情面板(OCR 确认),点 604/746/1458 全无响应 → 真中心含 534/1386。
- **占用台座扫峰**:空槽台座模板全带匹配,峰位 -70 校正后 = 534/818/1102/1386
  (四占用位),无峰于 606/890/1174(三空位)。
- **居中重排规律**:6 格 604..1316 / 7 格 534..1386 / 8 格 464..1458——
  **排中心恒 960,三档各自居中,不共享列位**(推翻「共享中段+右扩」假设)。
- **覆盖拖测**:真中心拾取,万敌 534→676→960→1244 逐位读对(s2/s4/s6
  覆盖),还原 534 后全板 {1:万敌,3:风堇,5:艾丝妲,7:佩佩}。

## 决策

1. **screen_info `后排7槽-1..7` 重登记**:x1 序列 463/605/747/889/1031/
   1173/1315(宽 142,y 600-739),中心 534..1386。
2. **模板全量重采**:7 件 raw_board/raw 以真窗口裁片替换(万敌/风堇/艾丝妲/
   佩佩=当前帧,乱破/卡芙卡=15:04 帧,爻光=黄金帧);**变体必须真窗口采**
   (错位残片变体在正位帧输给 plaza 主档 → live_only 假阴,万敌@s2 丢读实证)。
3. **CV 通道机理勘误(参数不动)**:464 探针三值的「羁绊面板渗入」解释作废
   ——实测是「7 格真 s1 左半覆盖」(std 26-44,随立绘浮动)与「8 格真左1
   格」(62.5-148/空槽 38.8)在 [26,48] 带重叠 → 佩佩帧 CV 返 None 退公式
   (diff=1→7,公式侧等级漏读已由经验条反推修复,ADR-0389 后批)。
4. **公式不变**:6+(cap−level) 与档位映射无涉几何,不受本勘误影响。
5. 部署拾取/点击坐标随 screen_info 自动归位(read_deployed_id 的
   (1390,668) 当即验证为真 s7 中心,历史无误)。

## Considered Options

- **维持旧登记+读数后处理纠偏**(识别层抵消错位):治标,拖拽/点击仍全灭,
  交互面无法绕;否决。
- **CV 探针改三探针判 6/7/8**:可判但复杂;现三值退公式已安全(公式经
  level 反推修复后权威),留 CV 简化;不做。
- **live_only 关闭**(假阳带已消):plaza 跨域弱命中风险仍在(域差距真实
  存在,run20 先例),保留作防线;否决关闭。

## 后果

- 识别(真窗口)空槽全库 0 假阳;占用位 plaza 主档亦可命中(33),变体更强;
  板内拖拽/点击按 screen_info 全部归位。
- ADR-0389 中「假阳带 11-26 无阈值可分」的量证结论**作废**(错位伪影),
  其 live_only/门槛/去重机制保留(防线语义,注释已勘误)。
- 拖拽机制补证:cap 满时 bench→板空位被拒(用户确认)、板内→空位可拖
  (本次三连实证)、bench→占用位=换位(乱破/卡芙卡两例)、系统单位不可换
  (佩佩挡黑塔一例)。
