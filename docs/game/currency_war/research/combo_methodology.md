## 最终模型(r148+r149 合并,取代"三套组合")

```
羁绊引擎池(每个都是独立伤害源,凑够人数即转):
  大引擎: 仙舟3(神君叠段) 列车2+(撞击+光轨) DOT2(敌回合超激发)
  中引擎: 贝洛伯格2 减益2 燃血2 战技点2(拉条/资源型)
  直通引擎: 终线自带(量子易伤/圣杯经济/学者挖矿...)
过渡阵容 = 引擎的组合(1+1 起步:DOT2 先行 + 任意第二引擎)
  核心池(共享): 饮月(喂仙舟+列车)/三月七(列车+护盾)/藿藿(仙舟+治疗)
               /爻光(仙舟+叠段加速)
  凑数池: 各引擎的双羁绊挂件(椒丘/艾丝妲/腾荒/赛飞儿/星期日...)
升级路径 = 渐进加法(DOT2→+饮月→+藿藿爻光=仙舟3→+三月七=列车2 混挂
           →+姬子=终局桥),不换件
```
TRANSITION_COMBOS 落码按此模型:不是 3 个组合对象,是**引擎池+共享
核心池+组合判定(已达成引擎数 ≥2 且含至少一个大引擎)**。

用户指出:列车和仙舟的羁绊伤害都属于「靠羁绊可通关」级——所以过渡不是
框架二选一,另一种过渡就是**列车+仙舟混挂**。

数据核验(784 篇):仙舟≥2 且列车≥2 的混挂组合 **41 篇**,阵容高度一致:
```
[饮月, 藿藿, 爻光, 三月七]            ← 最小形态(4人)
[饮月, 藿藿, 爻光, 三月七, 花火/千冶·刃] ← +通用件
```
结构解读:**仙舟DOT 三人组 + 三月七(列车+护盾)**——饮月双阵营同时喂
仙舟(叠段)和列车(撞击),三月七补第 2 列车;羁绊达成 = 仙舟3+列车2+DOT0-2。

**修正组合模型**:不是「仙舟DOT 或 列车 二选一」,而是**同一核心池的
渐进形态**:
```
阶段0: DOT2(任意2件,开局即战力)
阶段1: +饮月(双阵营枢纽,仙舟/列车双线开喂)
阶段2: +藿藿+爻光 → 仙舟3 成型(神君引擎全速)
阶段3: +三月七 → 列车2 挂上(第二引擎,混挂完全体)
终局桥: +姬子·启行 → 切终局线(她复制三月七装备=反震启动)
```
每个增量都是**加法**(不换件)——这就是官方数据里两阵营系高度共存的
机制原因:共享核心池(饮月/三月七/藿藿/爻光),只是凑够的先后不同。
