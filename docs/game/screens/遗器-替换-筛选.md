## 1. 何时出现

「遗器-替换」屏点左下「筛选漏斗」([30,78,968,1014] 纯坐标区)打开的筛选面板。**toggle 语义**:再点漏斗关回详情面板。面板占据右半屏,替换详情面板(两者互斥、同位置)。屏判定:筛选漏斗只在本面板替换详情面板后出现——id_mark 三锚(快速操作/稀有度/遗器建议)全部命中才算精准,「遗器-替换」与背包侧「背包-遗器-筛选」的互判由「遗器建议」(角色行按钮,背包侧无角色行)排除。

## 2. 面板结构(自上而下)

- 顶部「属性/状态」双 TAB(默认属性;「TAB-状态」[1700,86,1820,124] 已建档)
- 角色行:头像 + 角色名 + 右端「遗器建议」按钮([1740,168,1850,206])
- 「套装」标签 + 点击选择条([1382,283,1810,337]「按钮-套装选择」)——已选套装在此条下方以 chip 行展示(chip 帧 [1382,352,1878,407],红 ✕ 即时删除)
- 「稀有度」标签 + 2/3/4/5 星切换行
- 「主属性」标签 + 点击选择条
- 「副属性」标签 + 点击选择条
- 「快速操作」标签 + 切换锁定/切换弃置两按钮
- 底部按钮带:重置(圆形箭头 [1378,964,1432,1018])/「筛选方案」([1446,966,1640,1018])/「保存」([1652,966,1882,1018])

## 3. 行为事实(2026-11-12 摸底帧实证)

- **点套装「点击选择」→「筛选规则」弹窗**(明细见 [遗器-替换-筛选规则](遗器-替换-筛选规则.md));弹窗点「确认」后弹窗收起、**本面板保持打开**、列表已按筛选刷新
- **删除已选套装 chip(红 ✕)= 即时生效**,列表即时刷新,无需确认/保存
- **「保存」= 存筛选方案预设,不是应用**:无未保存的方案修改时按钮灰态(删除 chip 后仍灰)
- **筛选生效时**,替换屏漏斗上方出现橙色「筛选中」角标([30,912,112,950],OCR 区)
- **当前穿着件不受套装筛选影响、恒置顶**(chip 帧:密林卧雪筛选下列表首位仍是穿着件)
- **筛选状态跨屏持久**:本面板与背包侧筛选面板共享同一持久状态——此处设置的筛选,背包列表继承;反之亦然
- **chip 态面板中段下移**:已选套装 chip 行把「稀有度」及以下区块整体下移约 75px,底部按钮带位置不变;「按钮-套装选择」条位置恒定(chip 只加在其下方),静态 area 按无 chip 态建档即可

## 4. automation 要读信息

- 标识-筛选中(属「遗器-替换」屏 [30,912,112,950]):筛选是否生效的判定读数
- 本面板目前只建了结构 area(套装选择/保存/重置/筛选方案/状态 TAB);稀有度星级、主属性、副属性选择条未建档——需要操作时先补 area

## 5. 注意

- 本面板无「应用」按钮语义:套装勾选在弹窗内确认后即生效,chip 删除亦即时生效;唯一「保存」是方案预设语义,勿误当应用按钮
- 「切换锁定/切换弃置」有副作用(改锁定/弃置标记),扫描类 op 禁触
