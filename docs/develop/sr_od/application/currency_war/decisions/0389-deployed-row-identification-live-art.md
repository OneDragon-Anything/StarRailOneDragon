# ADR-0389:部署排识别「现场 art 才可信」+ CV 左端三值判据

- 日期:2026-08-26
- 状态:已实施(佩佩局 7 格档闭环批)
- 上下文:ADR-0385(双通道布局)/ ADR-0281(系统单位模型);本决策辖**识别层**,与布局选档层解耦

## 背景与问题

佩佩局(diff=1 真 7 格)实机读板暴露部署排(前/后排)身份识别三类缺陷,
全部由 `analyze_screen` 15:04 实拍 + 黄金样本(拖测前用户口述真值)双帧量证:

1. **plaza 官方 art 跨域弱命中**:官方立绘(插画)对棋盘站立小人 SIFT 内点
   万敌 8(漏读)/卡芙卡 0(零信号)—— 与 run20 商店卡问题同构(彼时以
   现场变体机制解决,但只给开拓者·欢愉采过样)。
2. **空槽背景假阳带**:空槽背景山水对 plaza art 有 11-26 内点本底
   (乱破:19@s2、爻光:26@s4),与占用位 plaza 对本人分(10-27)三带重叠,
   **无阈值可分**(实测扫过窗口裁高 100-139px、std 预检均重叠)。
3. **佩佩无模板**:plaza API 不列召唤单位 → 最近猫科模板(狸小虎:10)顶名。

## 决策

1. **现场变体通道扩展**(治本):部署排识别用「棋盘站立小人」现场裁片入库
   (`portrait_plaza/<名>/raw_board.png`,键 `<名>#k`,run20 变体机制)。
   本批收割 5 件(万敌/卡芙卡/乱破/爻光=黄金/当前帧真值标注裁片;佩佩无
   官方 art → raw.png 主档,狸猫对同款先例)。真命中 34-86 内点。
2. **live_only 规则**(部署排专用):plaza 主档命中且该角色存在现场变体 →
   判跨域假阳拒(`identify_slots(live_only=True)`,read_deployed_chars 前后排
   启用;备战栏卡槽背景干净不启用)。取舍:**漏读代价(未知位,对账可见)
   < 假阳代价(幻觉角色毒化策略决策)**。未采变体的新角色上板走漏读 →
   经 MCP 交互收割补变体(本批流程已验证)。
3. **部署排门槛 15**(`_DEPLOYED_MIN_INLIERS`):拦现场 art 低分噪声
   (空槽 ≤11),真命中 ≥26。
4. **相邻幽灵去重**(`_GHOST_RATIO=0.5`):立绘比槽窗宽,单只向邻窗渗出 →
   同名相邻双命中低分 < 高分×0.5 判残影剔低分(实测真身 86 vs 残影 19;
   真双副本分数相近不受影响)。
5. **CV 左端三值判据**(ADR-0385 W209k 盲区修正):464 位 std ≥48 有左格 /
   ≤12 无左格 / **中间带 [12,48] 不可判 → cv_back_slots 返 None 退公式**。
   量证:「8 格左1 空槽」(P3 局 38.8)与「6/7 格羁绊面板渗入」(26.2-40.2)
   std 重叠,单阈值无解;7/8 靠 cap 差公式(paddle 直读权威)兜底。
6. **佩佩 roster 建档**:cost=0 系统召唤单位(同狸猫对),deploy 候选剔除/
   恒最右自检自动生效。

## Considered Options

- **调单一 min_inliers 阈值分离真假**:假阳带 11-26 与占用 plaza 分 10-27
  三带重叠,不存在可行阈值(量证否决)。
- **窗口 std 空槽预检**:空槽背景 std 43-58 与占用 39-58 重叠(量证否决)。
- **裁 raw_board 台座带**:空槽本底不随裁高坠落(100-139px 恒 19),本底
  源是背景山水非台座(量证否决)。
- **CV 优先 + 留证(维持 W209k 单阈值 48)**:7 格建档后 CV=7 与公式=8 冲突
  采 CV → P3 局(8 格左1 空槽)真误档(既有 fixture 直接抓红)。

## 后果

- 部署排识别可靠性:佩佩局双帧逐位对用户口述真值全 PASS(含幽灵/假阳/
  误名三缺陷消失);测试锁 `test_pepe_board_truth_*`。
- 识别 API:`identify_character(return_key=True)` 返回原始模板键(带 #k),
  默认行为不变(存量消费方无感)。
- 后排7槽 area 建档时「区域-出售区」被吞 → 本批自 HEAD 回补(附注在 yml)。
- 遗留:未采 raw_board 的角色上板会漏读(如未来新角色)——属预期行为
  (对账可见),采集流程 = 本批模式。
