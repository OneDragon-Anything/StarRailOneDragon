# 货币战争-遭遇节点（二选一）

**识别**：`is_precise` 命中 `货币战争-遭遇节点`。
**目标**：二选一（难度星级 × 奖励预览）。
**能做的事**：
1. 点目标卡选中（低难度卡约 660,530；静态点击有效，白框 = 选中）。
2. 点「选择」（约 960,899，静态点击；无效时微距拖拽兜底）。
3. 分支刷新（优势布局「分支刷新」授予的能力，每局 1 次）：点「剩余次数:N」文本左侧圆钮（圆钮 = 文本中心 x−100、y 同高；文本 ≈(771,899) → 圆钮 ≈(671,899)）。刷新重置两卡难度与奖励，点后约 2 秒画面稳定再读；画面上没有「剩余次数」行 = 本局未激活该布局、无刷新可用（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
4. 看敌人信息：点遭遇卡弹「货币战争-敌人信息浮层」（页签切遭遇其一/其二，词缀横条 OCR 可读——难度星级之外的词缀细节在这里）→ 点「按钮-关闭」关（flow 层有专用 op，agent 手动等价；源码挖掘，待实机核对）。
5. 中途退出选择：点「按钮-返回备战界面」回备战——会带出暗色锁定态（备战蒙层、读数不可信），需按「货币战争-备战-暗色锁定」卡点「按钮-返回遭遇选择」回本画面；退出后该节点如何结算待实机核对。
6. **即时结算形态（变体，实测样本 1）**：选难度确认后无战斗直接回备战，收益入账、连胜不变——难度×奖励的真实机制待核。遇此形态属正常推进，勿当流程卡死重试。
奖励/遭遇节点通关固定 +2HP/+2XP（连续 5 次实测一致）；遭遇奖励预览以卡面为准，随局变化。
**坑**：奖励预览以卡面为准，随局变化（实测：难度 3 也刷出过奖励 = 免费刷新 ×5 的卡面）——HP 危急选低难保命。点卡选中后点确认，**中间不要点空白**（空白点击会取消选中 → 死循环）。
