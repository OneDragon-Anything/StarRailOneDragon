## 2. 伤害锚注册表孤儿申报

`kernel/cw_registry` 的伤害锚数据行 `vd_p1_loss_intercept`（11.32）/`vd_p1_loss_slope_rung`（−0.37）/`vd_p2_loss`（20.05）**保留、决策消费面为零**（定义行之外全仓无消费——孤儿申报）：它们原作「血预算停升级线/危机带血线」的分母（该判据族已删），现值 = 位面条件败局伤害的标定数据，保留为概率侧标定输入候选（λ_death 概率侧、掉血分布标定新立项的取数候选）；作废系数披露照旧——`vd_p1_loss_*` 现值系作废回归式（11.32−0.37·rung，禁引）的遗留系数，重校须以 P15v2 逐节点型锚（p15 单篇，sha 848dc1aa）为基准另立标定批。

原「registry.vd_p2_loss（20.05）vs P21 语料 15.39 vs sim 带中点」的 L_c 口径差核对项**失去消费对象**（核对对象 = 停升级线 L_c，该判据已删），核对项随判据族删除终结；伤害锚若未来重入概率侧标定，口径核对在新立项内重开。

**禁入面（重申）**：hp 作质量信号/运营表征、战力/胜负建模及其衍生量入策略判据——hp 使用边界 = 00 §3，出集须用户逐项确认。
