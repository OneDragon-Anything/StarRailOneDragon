# 菜单-更多(menu_more)

手机菜单右上头像横幅「⋯」点开的**小型子菜单 overlay**(漫游签证 / 手机装饰 / 开拓穿搭 / 兑换码 四项)。菜单底图仍完整可见 → 与 `菜单` 双精准命中属画面事实(测试已登记合法双命中)。

## 何时出现 + 状态流转

- **入口**:`菜单` 点头像横幅右侧「⋯」(≈1748,104)。
- **出口**:点任一项进对应功能(漫游签证 → `漫游签证` 面板);点空白/Esc → 收起回 `菜单`。

## 识别特征

- **id_mark = 按钮-漫游签证**(text「漫游签证」,rect (1420,110)-(1750,172);四项白底胶囊按钮竖排)。
- ⚠️ 候选筛选教训(ADR-0023 流程实例):四项文字均会同时出现在别处(漫游签证面板标题等),作 id_mark 依赖 **pc_rect 限定位置**——同文本不同位置不互撞。
