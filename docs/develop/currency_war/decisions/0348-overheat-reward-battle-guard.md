# ADR-0348:扑满守卫(离线可做部分)——「经济过热」类环境 reward 节点按**低危战斗**处理

- 状态:accepted(2026-08-26,W119;口述定谒修正 2026-08-26 编排者补充——初版「按战斗节点处理」收窄为「低危战斗」,见决策节)
- 判据:**用户口述定谒(2026-08-26,最高权威)**——扑满关**不掉血**(游戏全局机制:第一次掉到 0hp 保底剩 1hp,本条为机制真值非未知项),真损失是**打不过就没奖励**(损失很大);正确处理不是「按战斗节点深花保血」,而是「确保有羁绊/伤害阵容上阵去拿奖励」。附:W113 §8-5(E1,W115 对抗审计);口述 [16] 2026-08-25 例外注记(「经济过热」类环境奖励节点变次元扑满,有战力要求)
- 影响:decision_v2 新增 ev.REWARD_BATTLE_ENVS/reward_node_is_battle;scoring refresh 轮界豁免(战斗向刷新理由开放);单帧锁(test_cw_w119 ⑥);**地板不降**(discipline._hard_node 不辖扑满)

## 背景

`cw_invest_data.PLAZA_PORTALS` id 105「经济过热」/119「经济严重过热」:
「本局的全部奖励节点替换为(超级)次元扑满主题」——扑满要打且跑得快
(掉更多战利品)。决策层此前零消费:reward 节点被无条件当作零战斗
(「必胜、无血可扣」),持过热局时该攒的伤害没攒、该 D 的轮没 D。

W119 初版把扑满节点接进 `_hard_node`(连胜 EV 地板/保血通道 hard
判定)=「深花保血」语义;**口述定谒后收窄**——扑满不掉血,深花保血
没有对象;要保的是奖励(伤害阵容)。

## 决策

- 环境名单 `REWARD_BATTLE_ENVS` 从 `cw_invest_data.PLAZA_PORTALS`
  按**效果文本派生**(含「奖励节点替换」;单一源,版本重跑自动跟上;
  锁测试断言 == {'经济过热','经济严重过热'})。
- `reward_node_is_battle(state)`:`node_type=='reward' ∧ active_env ∈
  名单` → 扑满节点。**按「低危战斗」处理**:
  1. **战斗向买/刷理由开放**(scoring 侧):refresh 轮界门
     (`refresh_max_round`,r>6 恒负分)对扑满节点豁免——为凑伤害
     D 牌在后期扑满轮合法;金保底门(`refresh_min_gold`)保留
     (金保底防抽干与节点类型无关);买牌通道本就开放(economy 模式)。
  2. **地板不降**(discipline 侧):扑满节点**不进** `_hard_node`
     ——连胜 EV 地板(降 5)与掉血报警保血通道的 hard 判定都不辖
     (无掉血之虞;深花保血没有对象)。
- **掉血三臂(BloodAlarmTracker._BATTLE_NODES)不辖**——三臂是用户
  定调的不可回归旁路,语义逐位不动(扑满不掉血,本就无入臂依据)。
- **0hp 保底 1hp 是全局机制真值**(用户口述,2026-08-26),不做建模
  (任何 hp 风险控制都据此理解为有保底);本 ADR 不把它当未知项。

### 挂账项(本批不做,W115 E1 四处跟进的其余三项)

1. 投资效果表(cw_investments/cw_effect_ledger)加「reward 节点变
   战斗(低危,不掉血)」机制突变项;
2. DP 台账指纹纳入该突变重解;
3. 节点识别扑满模板档(cw_node_reader 自陈未建,采集 hook 已有)——
   留实机(模板建档走画面建档流程,非离线可做)。

default 栈的 `_is_reward` 类守卫(cw_evaluate.py:215 族)**冻结不动**
(回退保险+基线臂),两栈同病的 default 侧修复随 default 解冻批次。

## Considered Options

- **按战斗节点处理(进 `_hard_node`,W119 初版)**:口述定谒否决——
  硬节点分类服务「深花保血/保连胜」(有掉血风险的节点才配),扑满
  不掉血,降地板=无对象的花费授权;正确目标是伤害阵容→奖励。
- **手写环境名常量**:否决——cw_invest_data 是生成文件(勿手编),
  名单派生自效果文本随版本重跑传导;
- **奖励节点进 BloodAlarmTracker._BATTLE_NODES**:否决——旁路铁律,
  且扑满不掉血本就无入臂依据(定谒后此选项双重不成立);
- **效果表突变项同批落**:否决——台账突变影响 DP 世界模型,与 DP
  姿态标定(②b)耦合,归后续批一起裁。

## Consequences

- 行为面:持过热局的 reward 节点上,r>6 的刷新不再恒负分(为凑伤害
  D 牌开放,金保底仍辖);地板/模式/报警一切照旧(低危)。
- 实机验证锚点:持「经济过热」局进 reward 节点时,伤害不足的轮应见
  刷新/买牌动作(凑羁绊伤害),而地板无降级动作;节点模板建档后
  (node_type 读出非 reward)本守卫自然退化为兜底。
- 刷新轮界豁免的刷新 EV 仍是常量口径(refresh_ev=2.5,ADR-0293 标定
  未含扑满语境)——若 ②b 观测到扑满轮过度刷新,标定域=扑满语境的
  refresh_ev,不回退豁免。
