## 命题 P12

V_D 收益侧按 P2 存活语境计值——掉血期望用 P2 实测带(15-17/败)而非 P1 骨架(10),战斗数用本位面剩余节点(3-9)而非 registry 缺省(5)——则拒绝域 `benefit < spend` 从「全部 j」(W152 实测:14 帧全负)移动为:

**2 费核心 @lv6-7:仅 j=0 仍负;j≥1 全部翻正(批口径不变的前提下)。**

即修法②的收益侧修订单独(不动成本侧)已能解开大部分 P2 帧;与 P11(成本侧)叠加后 j=0 的高费帧也进入可判域。

## 推论(修法公式;常数归 registry)

```
benefit^P2 = Δrung(e1→e2) × R + Δh3_win(e1→e2) × loss_p2 × hp_to_gold × battles_left_p2(state)
loss_p2        —— P2 掉血期望(带 15-17,真值采集点=[27] 结算屏 OCR 三项拆解;归 registry)
battles_left_p2(state) —— 本位面剩余战斗节点(由 cw_horizon 节点表推导,非缺省 5)
```

- P1 段不动(现行式即 P1 校准);P2 段两参数按上式替换,`expected_battle_loss=10/battles_left_est=5` 保留为 P1 骨架值;
- 与 P11 叠加:`V_D^P2 = benefit^P2 − C_dec(g,s)`,j=0 高费帧的可判性由成本侧给(P11),j≥1 帧由收益侧给(本篇);
- [18] 纪律不破:hp 不作触发器,掉血只进收益计价(每败期望掉的 7.5-8.5 金是 [27] 公式的金值投影);[28] 双指标验收继续作局末验收,hp0 率作 sim 观测项。

## 冲突标注

- ⟲ **W126/ADR-0349 的收益侧参数**:expected_battle_loss/battles_left_est 是 P1 骨架初值(registry 自注「未标定」),P2 语境被本篇修订——不是推翻 P5 定理(P5 收益侧=「成型跳变金值」的抽象结构,参数本就是校准层);
- P9(hp1 死局锚)/W151 互证:hp 出口与 P2 存活轮单调正相关 = ③ 中带 battles=7-9 的实证背书;
- 数据边界:P2 掉血带 15-17 来自 **4 局 8 败**的小样本(每败 B≈10+P),P 项随敌方剩余血量波动;lossp 真值采集点=[27] 结算屏 OCR,采前 16 为保守中值。
