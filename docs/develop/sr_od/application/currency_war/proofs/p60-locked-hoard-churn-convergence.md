## 命题(形式化)

锁线帧序列 t=0,1,2,…,记:

- B = buy_members(锁定采购集,|B| = hoard 角色数),k = core∪shared;
- C = BENCH_CAPACITY + 板槽位(占用容量上界;P2 = 9 + 7 = 16);
- owned(t) = bench∪deployed 上的角色名集(name 记持,一张即算);
- missing(t) = B ∖ owned(t);
- 燃料集 Fuel(t) = { bench 1★ 件 : 名 ∉ k ∧ 无后台效果资格 }。

**循环机制(代码事实)**:missing ≠ ∅ ∧ bench 满 ∧ Fuel ≠ ∅ 时,
M4 卖 1 燃料件(1★ 全额退)+ 下一缺员到店即 M2 义务买入;每次买入
将 `cw4_line_state.drought` 重置 0(shop.py:504-505)。

**收敛性命题**:该循环收敛,即 ①∃T: missing(T) = ∅(循环自带出口),
且 ②Φ(t) = |owned(t) ∩ B| 单调不减(换手不倒退,板深/战力不降)。

## 证明(证伪)

### ① 出口 missing=∅ 结构性不可达(|B| > C 时)

missing = ∅ ⟺ B ⊆ owned ⟹ |B| ≤ |owned| ≤ C。注册表直调
(`prop_repro.py` 输出):|B| 对 20 comp 为 5~20,其中
黄泉减益 20 / 万敌单C 19 / 列车同行 18 / 千冶减益 17 / DOT队 17,
均 > C=16。对这些锁线,**无论行为如何,missing 恒非空**——循环的
出口条件在容量计数层面不可达。∎(命题① 证伪)

### ② Φ 非单调:燃料集与买入集相交

Fuel 的排除集是 k(core∪shared),而 B ⊋ k(hoard − core∪shared 达
2~14 名/comp,黄泉减益 13 名)。故 bench 上的 hoard 非核心件是合法
燃料——**帧 t 买入的缺员可在帧 t′>t 被 M4 卖出**以腾席给另一缺员,
Φ 可降。M4 取 `cands[0]`(slot 升序,mandate.py:178)无任何
价值序/买入序/合成进度保护,方向随机。

帧级复现(列车同行,B=18,初始板 7 hoard 成员 + bench 9 燃料,
商店每帧供一缺员):200 帧内 buys=100 / sells=100 / **净金=0**
(1★ 全额退对称)/**missing 末值=10 恒非空**/**换手事件 91 次**
(曾买入成员再被卖:丹恒·腾荒/千冶·刃/开拓者·欢愉/星期日/丹恒·饮月…)。
Φ 在带宽内振荡,无收敛趋势。∎(命题② 证伪)

### ③ 伪装进展通道(前提逐条核实)

- 「净金≈0」:复现净金恰为 0(1★ 卖出全额退 + 买入等量对冲)——
  经济面无报警信号;
- 「drought 被买动作重置」:每次 M2/M2b 买入调 `_on_target_buy`
  (shop.py:496-506)将 drought 清 0——断供/停摆探针被循环自身的
  副作用持续灭活;
- 板面/战力:换手只发生在 bench,板上成分不变——过程量零进展,
  而买动作计数与 drought 重置呈现「持续买入」的活动表象。

### ④ 反方向排除(诚实申报)

- 收敛**在特例下成立**:|B| ≤ C 且 Fuel ∩ (B∖k) = ∅(如 B ⊆ k 的
  小 hoard comp)时 Φ 单调不减、≤|B∖k| 次买入后循环自熄。注册表 20
  comp 中 5 个大 hoard comp 违反前者、全部 comp 违反后者,特例不覆盖
  现行锁线族。
- 「永恒」非绝对:金耗(买入卡费 > 1★ 退款时)或燃料集耗竭(bench
  恰全为核心∪shared/2★/后台效果件)可使循环意外停——存在吸收态,
  但 M4 无向吸收态走的排序力,循环出口(missing=∅)又不可达,
  故**无收敛保证**是结构结论,非测度结论。
- 合成进度倒退(同名第 2 张被当燃料卖)机制上存在(燃料判据不查
  同名张数),本轮复现未采样到(随机轮转未产生双张),不作观测
  断言,列风险项。

## 结论

**证伪**:锁线 hoard 换手循环对现行注册表的大 hoard 锁线族
(|B|>C 的 5 comp)出口结构性不可达,且 Φ 无单调性保证(燃料集与
买入集相交 + M4 零排序保护)——循环可为**永恒换手(伪装进展)**:
净金≈0 + drought 持续被重置 + 板面零变化,买动作表象与实际进展脱钩。

## 工程后果(修法路由)

1. **治本候选(单点改动,恢复单调性)**:M4 燃料候选排除 buy_members
   (`fuel_sell_candidates` 增排除集参,消费端与 EV 排除集同款注入
   `locked_buy_membership`,shop.py:651-654 已有同型先例)。改后
   Fuel ∩ B = ∅ ⟹ Φ 单调不减、循环 ≤|B∖k| 次收敛;|B|>C 时行为
   变为诚实停摆(m2_retry_exhausted / bench_full_buy_abandon 计数,
   金开始累积)——停摆可见、可判读,优于不可见换手。需重推:
   排除后 M4 腾席能力收窄是否使缺员买入延迟(实证 = 帧级对拍)。
2. **义务分级候选(设计层,需 ADR)**:M2 义务序 core∪shared 优先、
   hoard 其余成员降机会性(EV 域)——从源头收窄 B,使义务集容量
   可满足;与「替班者语义」「P48 统一支出判据」对表后立项。
3. **伪装进展的遥测门(不论修法先落)**:换手对计数(sell 后 N 帧
   内 buy 同源循环)独立分键 + 「|buy_members| > 容量 C」帧级告警
   计数;drought 重置区分「缺员买入」与「义务换手买入」分键,
   防探针继续被循环副作用灭活。
4. 原挂账收敛性问题由本篇回写:结构级定谳为证伪,
   「sim 定谳」不再需要(帧级构造已充分;sim 批仅作修法落地后
   确认性对拍)。
