# 货币战争-大厅（入口）

**识别**：`is_precise` 命中 `货币战争-大厅`（锚：赛季名「入画奇航」+ 开始按钮模板）。
**目标**：从这里开局。
**能做的事**：
1. 开局 → 点「开始「货币战争」」（胶囊按钮，静态点击不稳）→ `CwCapsuleDragClick {"screen_name":"货币战争-大厅","area_name":"按钮-开始货币战争"}`。
2. 看进度：晋升等级/积分/羁绊链路/数据银行百分比显示在大厅（只读，无 op）。
3. 优势布局（局外成长）：左侧菜单「优势布局」→ 选节点 → 点「布局」（消耗布局代币 ×20；锁定节点需先布局前置优势）。全量建档见 `docs/game/screens/currency_war_advantage_layout.md`（两棵树节点清单、「保险机制」=1 血免死、激活路径；遭遇节点「分支刷新」等对局能力均来源于此树的激活）。
4. 攻略大全/创业指南：左侧菜单入口（查阅用，不影响开局）。
**坑**：首见引导气泡（新系统首次解锁/新版本更新时弹一次，如优势布局引导）会挡按钮——按钮点了没反应时先看有无气泡，点气泡本体推进或完成引导指向的动作（如去优势布局点「布局」），完成后气泡永久消失。非首次场景无此坑。
