# 无名勋礼-购买档位页(nameless_honor_purchase_page)

无名勋礼**真实购买流程的必经页**:主面板点「解锁无名客的荣勋」后落此页(2026-11-12 实机,不直接弹扫码)。左侧版本宣传图轮播(页码 x/17 自动播),右侧两张付费档位价格卡上下排布:**无名客的荣勋 ￥68.00**(立即获得星琼×680)/ **无名客的奖章 ￥128.00**(划线价 ￥146,立即获得星琼×680 + 立即 +10 级)。底部提示「购买以上任一商品,当期版本登录《云·星穹铁道》,可获赠畅玩卡」+ 右下「请适度娱乐,理性消费」。背景为暗化的无名勋礼面板(非全模糊,背景 OCR 仍可读)。不锁光标(`pc_alt=false`)。

与[无名勋礼-购买推广页](无名勋礼-购买推广页.md)(版本周期首进引导页,「开启无名勋礼」按钮)是**不同画面**:本页无「开启」按钮与剩余时间,主面板/引导页 id_mark 在本页均不命中。

## 1. 何时出现 + 出口

- **入口**:[无名勋礼](无名勋礼.md)主面板(奖励 tab)→ 点「按钮-解锁无名客的荣勋」。
- **出口**:
  - 点「￥68.00」(荣勋档)→ 扫码支付弹窗(见 §3);
  - 点「￥128.00」(奖章档)→ 同款扫码弹窗,金额 ¥128(**更高消费档,op 只建模识别永不点击**);
  - 右上 ×(1855,65)→ 回主面板。

## 2. 识别特征

- **id_mark 双锚**:「文本-无名客的奖章」(pc_rect 1055,798-1210,835,conf 0.999,本页独有文本——主面板双轨是赠礼/荣勋,无奖章)+「按钮-购买荣勋68」(1270,385-1700,452,文本 ￥68.00,conf 0.95+)。
- 按钮-购买奖章128(1270,785-1700,855,文本 ￥128.00￥146.00)为纯识别区,无点击路径。
- 按钮-关闭X(1835,40-1890,92)纯定位。

## 3. 扫码支付弹窗(挂本屏建档的子态)

点任一档位按钮后弹出的**白色居中弹窗**(背景暗化不模糊):标题「扫码支付」+ 金额大字(￥68.00)+「商品:无名客的荣勋」+ **渠道并排 tab(支付宝[推荐] | 微信支付)** + 二维码 + 二维码下方标注。

- **与商店扫码弹窗不同构**(商店版是「其他支付方式」按钮切换,本页是 tab 直切)——勿混用商店屏的渠道 area,且商店屏「按钮-返回支付宝扫码」的 rect 会把本页「支付宝扫码」标注相似命中,误用会误判渠道态。
- **当前渠道判据 = 二维码下方标注,同位互斥**(2026-11-12 实证):支付宝态 =「支付宝扫码」;微信态 =「微信扫码」(点微信支付 tab 切换,标注区 rect 885,730-1035,768)。
- **二维码有时效**:过期态中央出刷新圆钮 +「二维码已过期,点击刷新」文字,点击 (960,625) 重出码(2026-11-12 实证)。
- 弹窗子态 area(挂本屏):标题-扫码支付(890,272-1030,322)/ tab-支付宝(715,450-940,505)/ tab-微信支付(975,450-1210,505)/ 文本-支付宝扫码 + 文本-微信扫码(885,730-1035,768 互斥)/ 按钮-关闭扫码X(1195,258-1248,312)。
- 支付完成后落「获得物品:星琼×680」通用弹窗(点击空白处关闭)→ 回主面板即已购买态。
