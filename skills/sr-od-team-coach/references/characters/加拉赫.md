# 加拉赫（火·丰饶·4星）

> 按 V4.7 期撰写。击破转治疗的高速负面机奶爸；平民负面体系生存优选。

## 一、命途属性与技能说明

**命途**：丰饶
**属性**：火

| 技能 | 说明 |
|---|---|
| 普攻 | 单体火伤 |
| 战技 | 治疗单体 |
| 终结技 | 消耗能量110（E1进战+20）；AoE +【酩酊】（负面→黄泉充能源+受击回复）+ 行动提前100%（行迹「天然酵母」） |
| 天赋 | 受击回80生命×被攻击目标数（受击/群攻环境奶量放大）；强化普攻【酒花奔涌】挂减攻10%（负面） |
| 秘技 | 进战挂酩酊 |
| 额外能力 | 「崭新配方」：击破特攻的50%转治疗量（上限75%）——**150% 击破吃满**（E6再+20%） |

**资源与循环**：标准能量→充能有效。终结技后拉条100%→高速轴持续挂酩酊。

## 二、推荐遗器与原因

**套装**：云无留迹的过客4件 + 盗贼公国塔利亚2件【攻：社区口径】

| 位置 | 推荐 | 原因 |
|---|---|---|
| 躯干 | 生命%/治疗加成 | 生存底线 |
| 脚部 | **速度** | 酩酊轴与浮元式追击奶节奏 |
| 位面球 | 生命%/攻击% | |

**不堆**：攻击%、双暴（4星词条效率让位）。
