## 问题与约束

- 边界：本篇定义三件事——终局线选择（候选管理与锁定规则，方向状态唯一来源）、升级判据（概率主轴）、锁定状态的载体。备战/商店两域对它们的调用时机见各自详设。
- 总纲契约引用：契约 B（方向状态读写接口）、契约 D（价值评估函数的统一口径归本篇 §4）。

- 选线机制 = 候选-锁定制（用户裁定 2026-10-12 选线专题定稿：硬规则查表判据 + 零标定参数——加权评分/定型门/滞后余量形态的作废依据〔需标定参数方可消费、购买力维偏置低费线、时间维难算不直观〕归 git 历史）。

## 方案

### 1. 终局线选择（候选-锁定制）

用户裁定 2026-10-12（选线专题定稿）：方向与板面执行分层——P1 板面恒过渡体系（等级人口压死终局羁绊的战力资源约束，与方向正交）；方向 = 全程线分数评估 + top3 候选管理 + 硬规则锁定；锁定后不设主动换线。

**1.1 机制形态**

```
f(局面状态) → 「未锁定（top3 候选在册）」 | 「锁定线 X」（一次性决策，锁后不换）
```

**1.2 线分数（两项 + 平分规则；零拟合参数；合成式 = 字典序——用户裁定模型的可实现化）**：**比较序 = 环境分级 → 持有证据级 → 攻略热度**（字典序逐级比较，先高级定序再比下级）：环境分级 = 强关联策略命中线为最高级、其余为普通级（策略型信号门槛级语义——非加数）；持有证据级 = CARRY 在手 > 骨架计数 > 插件计数（先比 CARRY 有无，同再比骨架数，同再比插件数）；攻略热度 = 十类帖数映射（终局裁定见下）。无连续加权、无相对幅度参数——纯字典序 + 计数。

| 项 | 算法 | 数据源 |
|---|---|---|
| 持有证据 | 该线已有件计分：**CARRY 在手 = 大头、骨架件 = 次之、插件 = 小头**（三档序数分，非连续加权）；已有越多分越高——替换成本语义由此承载（囤得越多越不会换走） | `COMP_LIBRARY` **派生口径**：CARRY = `plaza_carry`（聚类 CARRY 注册表锚，20 条 17 非空）∪ `core_chars`（核心角色另册）合流，空值线（3 条）知识批逐线补全——无单一直接字段，派生申报；骨架 = `key_items`（3.0b 已交付——缺行时持有证据仅消费 CARRY 档为 fail 方向条件句）；插件 = 成员 − CARRY − 骨架余集（派生） |
| 环境分 | 投资策略/词条对该线的**明文机制加成**；强关联策略给高分（策略-线关联 = `lock_rules` 策略型的构成，无独立关联表——3.0b 单一源） | 投资注册表（`cw_invest_data`）+ lock_rules（3.0b） |
| 平分裁定 | 按攻略热度定优先级（十类线帖子数降序）——[38] 修订版（用户裁定 2026-10-12）；**共享热度的终局裁定 = COMP_LIBRARY 注册序首线（显式规则声明，非遍历序隐式定锁——稳定且可实现）**；热度映射表（十类帖数→20 线）= **排序立场数据（换策略会换值）——落策略层 mandate_v1 侧常量表，不落 kernel（宪 5：玩法知识四字段清单不含它）**；建表归属 = 3.7（消费方） | 十类线帖子数（final_comps 在册）→ 3.7 策略层常量（mandate_v1 侧，不落 kernel） |

**不设项（用户裁定 2026-10-12）**：购买力项（按当前可购费用档打分会系统性偏置低费 CARRY 线——万敌 1 费早可买就早锁，但不代表最优）；时间预算项（期望等待 × 剩余节点的算式难算且不直观）。**商店货架不进线分数**——货架影响方向的通道 = 买入评估（候选件在售 → 买 → 变持有证据 → 下帧线分数上升），与 P77 零更新定理一致（差分节）。

- **贯穿件名单的注册表锚**：挂账新建 `COMP_LIBRARY` 每线 `key_items` 字段（贯穿件/骨架件名单单一源），建表任务归属 = **知识卡批 3.0b**（owner = 编排者，期限 = 3.4 开工前全组统一——3.4/3.6/3.7 三批消费；数据来源 = `final_comps/` 各线登记）。建表前持有证据分仅消费 CARRY 字段（骨架档缺省 0——fail 方向声明）。**宪法第 5 条对账申报**：lock_rules/need_star/key_items/entry_signals 四字段 = 玩法知识（终局阵容的客观定义——攻略数据，换策略不变其值），非策略层立场数据；字段落 kernel/cw_comps.py（玩法注册表）合宪。**角色型组合件数判据线**：件数由攻略语义定（「核心到手」的组合定义——CARRY + 攻略明示的关键骨架，查表登记非连续阈值调参；知识批逐线登记依据）。
**need_star 与 star_goals 双源申报**：`star_goals` 为 level_plan 字段在产字段、全 20 线普遍存在（「成型档显式星级要求」）；`need_star` = 本设计消费层新字段（3.0b）——建表时**逐线对拍 star_goals**（冲突以攻略重述为准），消费单一源 = need_star（star_goals 保留为对拍基准不进决策链）。
- **策略-线关联** = lock_rules 策略型字段的构成（3.0b 单一源，无独立表——概念股/黑塔纪元/圣杯契约等映射随 lock_rules 建表交付）；建表前环境分仅消费通用加减（fail 方向 = 强关联分缺失，保守侧）。
- **未锁定期的升级概率账缺件集** = 候选 top3 线的缺件并集（用户裁定 2026-10-12：囤终局件是锁线准备）；此时无单一锁定线，概率账服务「候选集的补齐期望」——**禁消费（§2.1 裁决：并集求和为自认放大向，未锁定期概率主账不消费；本句仅为缺件集口径定义非授权）**。**未锁定期线内/④身份判定源申报**：k_members 未锁定期为空 → 线内身份集 = **候选 top3 线内成员**（判定源 = 候选快照，替代 k_members 的线内判定职责）；④身份 = 候选集成员（重定义）；P78-4 核心与④身份段禁卖辖域不变——候选囤件在筹资/凑息场景的卖出资格 = 按④身份可卖（筹资场景线内判定 = 候选成员判定）；**升级攒批口径申报**：攒批缺件集 ⊋ 实际可卖集（核心/④禁卖部分不计可卖变现）——口径差异如实申报，攒批目标的可变现下界按可卖子集算。


**1.3 候选管理（未锁定期）**

- 每帧对全部线算分，**top 3 为候选**（用户裁定 2026-10-12：候选数量 = 3）；
- 候选变动：进榜线开始囤件；掉榜线已囤件**保留不再新增**（1★ 可全额退，不亏）；
- 囤积纪律：候选线成员照买照囤 + 全线路通用贯穿件（千冶·刃/三月七/花火/星期日——真贯穿层，出处 = stage_transitions Q1）恒囤 + **候选件没有而金有余时尽量买牌压库**（压库按费用档判据选，不限于候选线——用户裁定 2026-10-12 纠正「非候选的线不囤」：囤牌/压库有优先级，候选件优先，都没有时金有余照样买牌压库，[31]②/[34] 既有纪律）；
- P1 板面恒过渡体系（战力资源约束，与方向正交）；**过渡体系选与榜首候选重叠的**（转正不废件，transitions §5 角色重叠纪律）。**P1 锁定局的过渡件采购通道**：锁定后序 1 名单 = `opening_recipe_comp` ∪ 锁定线名单**并集**（P1 板面需配方过渡件〔配方物化链在产，锁定不辖 P1 配方件〕且锁定线缺件照囤——并集双目的：板面过渡 + 锁定线积累），P2 起切锁定线名单单源（**退出条件载体 = `plane2_started` 窗口谓词**〔3.1 已交付——非位面字面量自写，宪 2 合规与 p1_pair 整改同构〕；契约 E/shop_session 序 1 同口径——「替换」措辞废除，三处统一并集语义）。

### 4. 价值评估函数（契约 D 统一口径）

所有卖出场景的「手上牌价值」与本函数一致（单一口径，禁各场景自算）。**量纲统一为金当量**（经济期望是统一标尺，user_playstyle [22]④），可直接参与置换账比较：

```
value(牌) = 变现价 + 再遇期权 + 合成进度   （金当量项）
           ⊕ 羁绊贡献                      （排序规则项，不折金）
- 变现价   = sell_refund(牌)（注册表现读；1★ 全额退、2★×3、3★×9，cost≥2 减 1）
- 再遇期权 = 再遇窗口折算金当量：reencounter_window_frames(等级, 费用档, 已持有数)——候选的费用档 = 注册表 cost 现读、已持有数 = 同名同星持有计数现读
             （参数序照代码；查表单一源 = data/cw_shop_odds.py 的 reencounter_window_frames，
             11 §6.7 P77 行）× 每轮息损（= 每息档边际率 1 金/轮【注·息档粒度定义值】；
             真值上限 = cap 金/轮【注·默认局 5、息律局 10，随 cap 查表】，消费口径 = 边际率）
- 合成进度 = 已有同名同星 2 张（差一张合成）→ 按该成员完成档的再遇期权 ×2 计
             （差一张 = 两张的再遇期权沉淀；×2 为结构近似系数【拟·owner = 编排者、期限 = 一个对局周期；**fail-closed 形态 = 标定对照完成前以 ×1 线性运行**——不放大持有期权 = 保守侧，标定后切 ×2】）；
             零散单张 = 自身再遇期权。
             未锁定期「完成档」缺省 = 该成员自身下一星档（2★ 目标 k=3），
             无目标线依赖
- 羁绊贡献 = 排序规则项（非金当量）：卖后当前板面羁绊掉档的牌在让位序中排
   在全部不掉档牌之后（上阵位才有此代价，备战席位天然不掉档）。
   不折算金当量的原因：每档羁绊的金当量数值依赖 math_proofs P3，该命题
   数值面证明不成立、方向面降级维持（math_proofs P3 行在册——操作结论 = 禁引其数值〔Δp=0.277 作废〕，方向面照常消费。）**处理取向（用户意向
   2026-10-12：失效的旧证明随其简化判据，不为保留证明而保留复杂度）**：
   羁绊项维持排序规则形态即为终态，P3 重证非义务——若将来新证明入册，
   可再评估升格为金当量项。
```

- 金当量三项全部为注册表查表确定式，**无自由拟合参数**（已标注项除外：合成进度 ×2 结构近似系数【拟·owner = 编排者、期限 = 一个对局周期】、每息档边际率 1 金【注·息档粒度定义值】）；置换账比较使用金当量三项（X 的价格与 Y 的 value 比较），羁绊规则项作为候选资格过滤（掉档牌不进置换让位候选——该过滤在仅备战席候选池下恒不触发，为场上候选预留规则；自救扩展面除外——自救场景排序仍由让位序承载）。
