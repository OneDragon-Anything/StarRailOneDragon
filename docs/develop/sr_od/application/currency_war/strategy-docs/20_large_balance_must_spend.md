## 2. 富余段形式化:G_must = 10 × cap_resolved(零新自由参数)

### 2.1 界的推导(r1 应修-1/低-1/存疑-1 修订)

```
富余段(帧) ⇔ g > G_must,且该帧为有动作决策点的帧(§3.4)
G_must = 10 × cap_resolved_of_session
    ——单一源 = cw_economy.py:107 归一链(interest_cap_resolved),
    与利息线 g*、保利息结构门(arm2 参数位)同源;禁内联裸 cap(cw_economy.py:100-103
    明文纪律,cap 三源归一)
    语境值(【注】):默认 5 ⇒ 50 / 利息规则投资 10 ⇒ 100 / 开源节流 9 ⇒ 90 /
    买断制 0 ⇒ 0(不在本篇范围,见下)
```

**零利息边际论证(r1 应修-4 收窄)**:利息 = min(⌊g/10⌋, cap_resolved) ⇒ g 越过 10×cap_resolved 后,**超出 G_must 的富余金**利息收益恒为零——富余段的消费义务对象 = 该滞留段;持有富余金边际收益为零,任何期望收益非负的消费出口对该滞留段严格占优。**如实收窄(v2.3 起;原收窄②——零息论证对出口三层零覆盖——随出口三层删除失效)**:出口二层的 s_reserve 金门允许金位落回利息上限内,跨档帧利息增量 >0 可达 ⇒ 出口二层不称「严格优于持有」,沿 `17_stall_form_spend_authority.md` N4 定性 =「净成本 ≤1 金(注册表派生界)的有界成本结构改善」,严格支配仅利息增量 =0 帧。

**买断制语境不在本篇范围(r1 应修-1)**:interest_cap_resolved = 0 ⇒ G_must = 0 ⇒ 「金>0 即必花」,与「利息上限截断点」推导脱钩且逐帧义务荒谬 ⇒ **买断制局(cap_resolved = 0)本篇不在范围内**:富余段机制不适用,该语境金出口归一般判据(出口一层现行面),登记 §7.4(若需专门语义须单独论证,本篇不预支)。
