# ADR-0499: 支出门（买侧收门）落码与三轮 A/B 终局定性

日期：2026-08-30。状态：已定谳（默认关维持）。

## 背景

W774⑤ 立项的支出门（买侧收门）经设计链（W829 v1→攻击→v2→双批核验→v3→终核验）后由
W834 落码（commit aeec5209，registry 伞 `spend_gate_enabled`+两子旗标默认关第 1 态）。
判前锁 PREREG v4（独立成文，含三处终核验修正）冻结后执行三轮 A/B：

- 第一轮 W840（三臂 off/on/gate-only，n=500/臂）：清账门绿（G4 −0.02pp/G7 −0.31pp，
  W828 的 +2.89/+2.29pp 残差被门清零）；传导格双败（M1-L +0.029 与阶跃肢 +0.073
  CI 均骑零）；Goodhart 警报触发（62.3% P1 帧被拦＞30% 容差）；G2 终局带金 +9.6pp 红。
- 第二轮 W848（PREREG v4.1：E-g 低位豁免）：拦截率与第一轮逐位同值——帧级拦截率对
  "花后金阈值型豁免"结构性钝感（首拦候选花后金通常仍保有 ≥2 息档），E-g 实测否决。
- 伴随分析：W847（拦截构成：d1_interest 占 89%，65.4% 在金<40 深低位，重拦层 M1
  收益归零）与 W850（G2 归因：恒等式分解残差 0，G2 红=门过激伴生症状随豁免消解；
  门在 P2 也开火=W840 口径盲区；on vs off 混入兑现链效应须 gate-only 隔离）。

## 决策

1. **不开臂，默认关维持**。按 PREREG v4 §3 事前分流条款执行：「清账门绿 ∧ 传导格
   双败 → 门维持关、语义按清账已证+传导归实机锚保留、禁第四态」。三轮传导格均双败，
   该条款即其执行结果，非悬置。
2. **门定性**：合格的息保护器（清账门三轮全绿），非档位传导器。
3. **E-g 判据不采纳落码**（帧级口径结构性钝感，W848 实测；monkeypatch 仅限验证批）。
4. **选项 B（拦截面收窄为线内档满件）暂不派**：深度手术+重跑周期的 ROI 与三度传导
   失败不成比例；如未来实机锚显示息保护单独有价值，再议。

## Considered Options

- 开臂（拒：传导格三度双败，判前锁未过）；
- E-g 低位豁免后开臂（拒：实测对帧级拦截率无效）；
- 选项 B 收窄拦截面（缓：ROI 不成立，挂起待证据）；
- 维持默认关+语义分流（采纳）。

## 后果

- registry 保持 `spend_gate_enabled=False` 第 1 态；拒因遥测三键保留（离线分析资产）。
- 开臂前置=传导格实机锚证据（量化判据挂账，W851 审查要求：无量化判据则退化为
  无限期借口——补判据为待办）。
- PREREG v4/v4.1 归档为判前锁历史；`docs/develop/currency_war/prereg/w829_spend_gate_design/`。
- 遗留挂账：Goodhart 豁免面（W847 选项 B 方向）、G2 终局带金（W850 已定性随豁免
  消解）、实机锚量化判据。
