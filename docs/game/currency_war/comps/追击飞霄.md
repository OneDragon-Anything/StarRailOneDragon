# 追击飞霄(B 级)

> V4.4 合集 76807134:B 级。攻略直读 [76883466](https://www.miyoushe.com/sr/article/76883466)。
> V4.4 追击 = **飞霄(大飞老师)领**(纯追击,非旧"巡击青雀"仙舟+追击 hybrid —— 已对齐)。
> 代码字段:`COMP_LIBRARY["追击飞霄"]`。

## 机制(怎么 work)
飞霄(大飞老师):后台攻击也叠飞黄(1/4 层,前台半层)→ 加快大招;**每天赋追击永久 +6% 追击增伤**(后期 600% 自拐)。风套频繁拉条大量触发天赋追击。
**追击羁绊 ≥3 → 攻击附加 300% 倍率伤害**。

## 成型阵容
飞霄(双风暴潮+永动机/冷笑话)+ 缇宝/不死途/刃(hit+拐)+ 知更鸟(鸟,3 追击关键 300%)+ 记忆主(真伤)+ 杨叔 + 花火/符玄。
需自己飞霄+风套;缇宝带 555 减跑条。

## 成型节奏
1. 前期赛飞儿后台(3 追击 2 减益)+ 风堇生存。
2. 上 8:风堇→符玄,赛飞儿→鸟,上记忆主。
3. 继续拉等级,**9 级挂杨叔大成**。2 星飞霄即可上 9(3 星锁血反降)。

## 装备
- 飞霄**双火力风暴潮 + 永动机/冷笑话引擎**。

## 弱点 / 变体
- **邪修**:关奖励关 99% 伤害强化,1-1/1-2 磨血多次追击叠层。
- 不死途 c 变体(飞霄换托帕补 3 追击)。
- **追击转/貘泽专家**:缇宝换托帕开 5 追击(60% 真伤 + 50% 增幅);追击转给花火爆伤翻倍;转通用(黄泉/大黑塔可带)。
