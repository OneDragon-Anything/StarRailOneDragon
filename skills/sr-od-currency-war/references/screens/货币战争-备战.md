# 货币战争-备战（核心画面，每节点停留）

**识别**：`is_precise` 命中 `货币战争-备战`；extras 全量：gold/hp/level/deploy_count+deploy_cap/xp_progress/front_line+back_line（SIFT 在场真值）/bench/armory_boxes/owned_equips/reward_ores/**bench_overflow**。board = 羁绊面板可见行（仅快照）。
**目标**：花金币强化阵容 → 出战。
**能做的事**：
1. 拾晶矿：`CwCollectRewardOres {"max_clicks":6}`（reward_ores 非空时；商店开着会被守卫拒绝）。**点击后重读一次 analyze**——采到的奖励开箱可能入席，改变备战席占用。
2. 开商店：`CwToggleShopPanel {"screen_name":"货币战争-备战"}`（静默失败重跑）→ 买东西见「备战-开商店」卡。
3. 部署：`DragCwChar {"from_row":"bench","from_idx":N,"to_row":"front|back","to_idx":M}`——from_idx 必须来自**刚读过**的 extras.bench（晶矿开箱掉落物会插到非首空位，旧读数缺新单位；槽号 = 物理槽位，空槽以 empty 保留）。
4. 卖角色腾位：`CwSellBenchBySlot {"bench_idx":N}`。
5. 开武装箱：点 extras.armory_boxes 元素的 cx/cy（开启后装备入库，腾出备战席）。
6. 看角色详情：点场上角色卡（属性/技能/装备栏面板，右上 × 关闭）。
7. 出战：`CwStartBattleByClick {}`（纯机械点击出战按钮）。**状态前置自查**：商店开着先收店（第 2 步）；部署未满会弹「未达上限」→ 点确认；投资策略未选完时出战被抑制——op 只管机械执行，前置由你负责。bench_overflow=True（「备战席已满」红警横幅）= 出战会被游戏忽略——先卖角色腾位再出战。**点击后进入战斗画面（未建档，analyze 不命中、识别全空）——战斗进度与是否结束由你自己读图判断，出现「挑战成功/挑战结束」结算画面即战斗结束**（约 60~90 秒）。
**坑**：开商店态 front_line/deploy_count 为 null（完整读数先收店）；出战 4/5 部署会弹「未达上限」（op 自动确认）；战斗约 60~90 秒后再截图。
