# PREREG:W958 P2 升格批(stagnate-weak 派生升格候选)sim A/B 预注册

> 状态=判前写死。前置=W954 修订 1 交付;机制出处=`CHECKPOINT_w957_reconcile.md` ②修订 2(W957 候选#1 的降级后半程:降级后不止 salvage,还能向战力投影最优的可达成 v2 终局 comp 升格,经既有 C4 门与回锁闩)。

## 命题

stagnate 降级后,若仅靠真实异线信号(P2 板面冻结下罕见),多数局落 salvage 只停供不换线;派生升格候选(层 3,过 C4 门)把「锁线战力不足」转为实际换线/升格,提升 P2 存活。

## 臂与注入

- 开关 `p2_promote_enabled`(W958 新增,默认关):on=sim 注入臂(同 W954 手法);基线=修订 1 on 臂(升格 off)——**两批共享修订 1 的 on 臂作对照,新增维度单变量**。
- `--planes 2 --pool snapshot --n 300` 同 seed 配对,池指纹双臂必同。

## 验收线(跑前写死)

- **G1 落线面**:on 臂 stagnate 降级局中经 C4 门落新线(非 salvage 终态)占比 >0,逐例带 gate 评估位;off 臂该路径恒 0。
- **G2 主判据**:P2 段存活率较修订 1 on 臂改善 ≥3pp,或死时攥金中位再降 ≥20%。
- **G3 防振荡**:回锁闩零漂移(闩计数分布 off 逐位);局均换线数 ≤ off+0.2;摇摆形态局(同局 ≥2 次方向改判)占比不升。
- **G4 抑制哨兵**:升格落线局的落线对象 90%+ 为 COMP_LIBRARY v2 终局档(非过渡线)——派生器若大量落过渡线=设计偏航,回炉。
