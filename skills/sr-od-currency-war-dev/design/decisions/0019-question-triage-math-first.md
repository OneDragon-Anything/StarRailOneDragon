# ADR-0019:玩法疑问分流三滤网(问用户前先过数学/事实滤网)

- 状态:已接受(2026-08-25,用户点名沉淀)
- 背景:步②实现批派发后,编排者向用户提出 5 个玩法问题(boss 前留金/前两轮买牌/P2P3 基础奖励/扑满应对/HP 危险线),其中 4 个属经济或事实类。用户反问:「前4个问题都是经济的问题,是可以用数学来解答的,不应该问我,为什么不会用数学来分析?这种方法论是否应该沉淀到 cw skill 中」。
- 决策:SKILL.md 新增「玩法疑问分流」节——问用户前按序过三滤网:①经济滤网(存在可计算期望答案的问题不是用户问题,用 EV/概率表/DP/口述经济理论自答)②事实滤网(机制事实查注册表/文档/图鉴,查不到=采集挂账+保守值,口述属本滤网权威源)③裁决滤网(数学等价/风格偏好才问用户)。
- Considered Options:
  - 不沉淀,仅当事纠正——否决:同类犯法已有前科(判读只盯代码不看口述文档的反例存档同型——工具箱里有权威源却伸手要答案);判例不进 skill = 下次自主会话零记忆。
  - 沉淀到公共 skill(od-dev-gameplay-automation)——暂缓:目前仅 CW 单项目判例,按泛化纪律(第二玩法踩同坑再升格)先落项目 skill。
  - 全文细则进 SKILL.md 正文——调整:正文只留三滤网判据+判例一行(符合 ADR-0016 准入门槛:高频判据留当场);本 ADR 承载完整判例与 why。
- 后果:五问的正确去向成为模板——boss 留金=口述 [3] 直接应用(含新精确化:刷新前提=花后仍保 50 金,已补 [3] 注记);前两轮买牌=EV 零息损自动覆盖(开局金 5-10 无息可损,已补 math_proofs P3/P4 边界注);P2/P3 奖励=事实滤网(用户定调先按 5,采集在途,economy §10.1 已注);扑满应对=机制口述(不掉血/0hp 保底 1hp/凑羁绊刷伤害,已进 gameplay+user_playstyle);HP 危险线=机制真值锚(0hp 保底 1hp,已进 gameplay)。
- 关联:user_playstyle [22]④(「经济期望是策略评审的统一标尺」——本 ADR 是该纲领在「提问纪律」上的落地);sr-od-currency-war-dev SKILL.md「玩法疑问分流」节。
