## 0.5 公理栈(重推遵守;单一源=P51 v3 §公理栈 + MATH_REVALIDATION_PLAN v3)

- **纯金流记账**:血禁入账——hp 量只进 λ_death 的概率侧与机制叙述,禁 `hp_to_gold × L_c` 形态的直接价值换算入 EV 主通道(P15v2 §0/P51 §R.2 同源裁决);金当量带(§1-C)是**显式声明的模型参数形态**(带 CI/敏感性、禁当闸门),非换算公理的复活。
- **连胜置零底线(超额收益隔离)**:败局纯金流差只计当轮连胜表差 vs 败轮底金,不计连胜链未来成长期权与断连胜重爬成本——成本通道的**下界注记**形态;连胜成长价值若入账只增 L_defer,不翻转方向。
- **调参最小化**:估计必带 CI/敏感性带 + 稳健性划分,禁点值当闸门;ρ、q_full、λ3、L(τ) 逐项溯源见 §1-D。

### 1-A. 升级链三层精确化(替代 v1「滞后 1+ 轮」单层表述)

XP 支出到战力兑现是**三层链**,滞后只在第 3 层,且第 3 层存在 d=0 机制可达形态:

1. **XP→升级事件:即时,无滞后**。攒够门槛即升(生产语义,ADR-0129);升级不触发商店刷新(economy §2.1,2026-08-25 定谳)。
2. **level→上阵人数上限:即时当场生效,无滞后**。gameplay.md 官方原文「金币购买经验提升等级,等级对应可上阵角色数量」;user_playstyle **[32] 人口 cap 提升当场生效**(经 P37_VALIDATION/P51_VALIDATION 转引)。
3. **上限→实际板深:典型滞后,需买入/部署填充**——除非备战席已有等待件:**d=0 形态机制可达**(P39 臂一谓词「当轮有等待单位可上」正是该形态;P48_VALIDATION 修正③-4 的正确口径本篇回写)。

**正确表述**:「升级的**战力兑现**典型滞后(板深填充跨轮,金/备战位约束),存在 d=0 形态(bench 有等待件时机制 [32] 支持)」——不是「升级事件滞后 1+ 轮」。**「d≥1」在本 v2 及下游消费中降格为保守折价假设**:按 d≥1 折价方向保守(低估 XP 当轮收益),实证支持=关联级——W959 同局配对(大升级轮前后场,n=738,后−前中位 −15,改善 23.2%)是**与滞后一致的关联证据,含 boss/敌难爬升混杂**(r8 后一场多即 boss),非滞后的隔离测量;因果裁决挂早升臂 A/B(§4-1)。

(i)**时间不可逆性(结构论证,保留)**:板深兑现逐轮结转、第 r 轮该升未升则第 r 场战斗的板深差不可追回(存量损失),利息收益是可重复流量(晚一轮只少收一轮息,无追回缺口)——成本端存量 vs 收益端流量的对比作为**定性框架**成立;它证明两通道都存在与方向倾向,**符号闭合由 §1-B/C 的量级比较承载**(v1 把定性框架直接当「方向已证」是缺口,v2 修正)。

(ii)**收益端期望口径(替代 v1 上界式;v2.1 改实机 q_full)**:单轮利息≤cap=5 是**上界**而非期望——健康带满息轮占比实机 26.9%(§2A),多数轮连满息都未吃到;期望口径 E[I_gain]=q_full×cap=**1.34 金/轮(点,CI [1.06, 1.64])**。**部分息敏感项(显式声明)**:非满息轮(g∈[10,50))的部分息未计入——实机口径下该成分只会**再推高** E[I_gain](方向上加剧下端格翻转);使 ρ=0.5 最劣格也翻(E[I]≥2.5)在点估计口径下需要非满息轮平均附加息 ≥1.58 金/轮(g≈16+ 持续,CI 上端口径 ≥1.17)——聚合佐证反向:利息仅占总收入 7.4%、每局中位 18 金、达帽轮集中 r8-r9(74/120 帧),健康带利息总量与本期望口径互恰;该成分无分布数据,列敏感项(§6 检验点 4)。

(iii)**成本端存在性(「没东西买」前提不成立;保留,计数事实)**:升级轮 92.7%(1631/1759)店内有买得起却未买的件;存息轮(行末金≥50)r4=100%(61/61)、r5=100%(51/51)、r6=98.3%、r7=97.3%——存息是主动排序而非被动无货。故 P23.1 统一 EV 门 `EV = Δp·L_c·m + w·m − C − I` 的被延迟提案集合在健康带**非空且稠密**,L_defer 有真实承担者。

(iv)**r8 升级潮重定位(保留,描述性)**:r8 大升级是健康局表现非原因(r8 升级金<8 的 32 局 hp 中位 5;r8 升得起的 247 局中位 37);病灶在 r4-r7 攒太久——r8 才到账的等级只保护 r8 之后的战斗,r4-r7 的血已按旧板深扣掉。

### 1-B. L_defer 纯金流通道(公理主通道,同向交叉验证)

延迟转化一轮的金侧成本,不涉血量换算,两通道:

1. **死亡清零通道(λ_death×存量敞口,P51 同源)**:延迟=存量金多暴露一轮死亡清零。取 P51 §4-B-2 分层 λ3(p≤7×battle=0.065 [0.046,0.086])折每轮边际危险率 h=1−(1−λ3)^(1/3)∈[0.0156, 0.0295];存息帧 g≥50(定义下界)→ **h×g ∈ [0.78, 1.48] 金/轮(点 1.11)**。**口径注**:P51 §5-11 敞口量级比较形态、禁作闸门;R=距局终为事后量,λ(P,R) 只作描述注记;p≤7 战力桶与健康带(r4-r7,hp>25)非同一划分,取其作低-中战力中期帧的最近可用分层,偏差声明。
2. **败局纯金流差通道(连胜置零底线)**:板深差使当轮战斗多败一次的概率增量 Δp_extra>0 时,每次额外败局的当轮纯金流差 = 连胜表值 − 败轮底金 = **+3~+8 金/次**(STREAK_GOLD_TABLE (1,1,2,2,2,3,4) vs LOSS_GOLD_BY_NODE {battle:2, encounter:4, boss:4};不计断链重爬=下界)。Δp_extra 无独立估计(板深差→胜率差的直接证据缺位,最弱环节);闭合所需量(实机 E 点 1.34):**点估计下 Δp_extra≥0.08,CI 极端下(E 高 1.64 vs λ 低 0.78)≥0.29**(v2 sim 口径为 0.05/0.16)。

**通道合读(v2.1 实机口径)**:死亡清零通道与 E[I_gain] 同量级([0.78,1.48] vs 点 1.34),但**点估计 1.11 已低于收益端点 1.34**——v2「点估计略低 vs 带上沿」的措辞不再够,死亡通道单独不再覆盖收益端点估计,「L_defer ≥ E[I_gain] 上带」必须依赖败局金差通道(Δp_extra≥0.08)补足;纯金流通道整体降为「同量级、方向支撑但点估计侧不再单独闭合」——**符号闭合比 v2 更依赖 §1-C 金当量带承载**,两通道方向仍一致。P15v2 条件败局伤害带(P1 battle 10.35 [9.43,11.18])在本通道只作机制叙述与 λ 概率侧输入(败局更痛→危险率抬升),不作价值换算(公理)。

## 3. 与既有命题的关系

### 3.1 P21(濒死升级负判)的辖域对照——分界 = 收益视界

P21 辖 **hp≤10 濒死带**:升级的受益覆盖判据 `Δp·Σ L_c·S(b) > C + I` 中,存活到账项 `h > d·L_c` 不成立(S(b)≈0),升级正经济性的唯一来源(P3 型成型进度长时域账)在死亡清零前无兑现时刻 ⇒ 升级严格负。P37 辖 **健康带(r4-r7,hp>25)**:存活视界充裕,受益覆盖条件成立,升级(及其延迟)的经济效应显著为正/负。

**两者不矛盾,且是同一本 EV 账的两个边界**:
- P21 说「濒死带**花钱**升级负」;P37 说「健康带**不花**(攒息)负」。共用 P23.1 统一门:EV 符号由收益视界(存活概率 × 剩余战斗数 × Δp)决定——视界趋零则一切支出与攥金同归零值(P23.4 死亡域金零值近似),视界充裕则支出有正承载、攥金有正机会成本。
- **分界的操作形态**:hp 轴上,P21 辖 [1,10](濒死),P37 辖健康带(hp>25),(11,25] 应急带归 P36/P28/P23 危机族辖——三段无缝。
- **反向护栏**:P37 不给濒死带/应急带任何升级授权;健康带判据不得越轴套用(同 P36 对 P21 的引用方向相反,互相为界)。

### 3.2 与 P36 火力链的口径衔接——同族干预:「攒金早转战力」

- **同族**:P36(危机带火力地板:预算>0 必须出手)+ P36-a′(危机带储备线降档)与 P37(健康带升级时点前置)同属「压缩攥金、把金提前转战力」干预族,共用 P23.4 攥金优势引理的反面(攥金的机会成本为正)与 P23.1 统一门。
- **口径差**:P36 的出手通道=刷新/购买(当轮兑现型,即时 Δp);P37 的通道=买 XP(**战力兑现典型滞后、d=0 机制可达**,§1-A 三层口径)——v2 修正后两通道的差别不再是「即时 vs 必然滞后」,而是「即时 vs 典型滞后且存在即时形态」;晚转的成本由期望口径主式承载。
- **衔接处**:危机臂哑火帧(P36 M1)与存息轮可买件积压(P37)是同一病灶在两条 hp 轴段上的投影;两命题合读,「息档保护」的合法辖域被夹逼到健康带满息平台上的短期平滑(P13 自身边界内)。

### 3.3 社区侧锚(v2 补,验证建议 5)

economy §7 阶段共识:**中期(P2)「稳定 ≥50,用利息升人口为主,少主动刷新」**——与 P37 方向同向:中期金的默认去向是人口(战力转化),息线是底线不是目标;「攒息」本身从不是共识姿态。此为社区共识侧锚(非实证),与 §1 主式互证。

## 4. 落地建议(只给方向与数据依据,不落码)

按 strategy-work §3 分档:本命题符号闭合=模型级(期望口径+显式参数带)、量级=保守折价假设级,落「A/B 先行于落码」档;不保留开关,判正即落、判负只留 ADR。

1. **A/B 臂形态**:早升臂 vs 现状臂——臂 = r5-r7 帧把息线以上存金优先转 XP/买入(强制排序:升级/战力件优先于守息)。判据预注册写死(终局 hp 中位差为主判据、首达 lv7 回合分布前移为过程量校验、r8 升级金总量为守门量——预期 r8 潮前移而非消失);持久位=prereg 目录新建件(编号按当时窗口,本批不建)。A/B 同时裁决两件事:量级因果身份(L(τ) 选择效应)与 ρ 的真值带。
2. **升级时点判据的方向形态**(供后续批设计):健康带帧上,XP 支出与战力件买入的排序优先级应高于息档保护的判据形态 = 「剩余视界 × 板深差的存量成本 > 期望口径息差收益(E[I_gain]≈1.3 金/轮量级(实机点 1.34),非帽值 5)」。数据依据:§2 存息轮 ~100% 有可买件 + E[I_gain]=1.34 金/轮(实机点,CI [1.06,1.64]) vs L_defer 纯金流通道 [0.78,1.48]+ 金当量带 [1.25,4.00](ρ=0.5 时 1.86-3.77× 裕度(点);ρ∈[0.25,0.269) 段不闭合,§0A 对照表)。**注意方向强度变化**:收益端上移后本判据的裕度变薄——方向仍由 ρ≥0.269 闭合承载,但消费方不得再引「2× 裕度」。
3. **不动的部分**:濒死带(P21)/应急带(P36、P28)判据不因本命题松动;r8 升级本身不设限;r8 升不起的崩盘局由上游治理。
4. **与 interest_rule 的关系**:仲裁门的代价侧首次有直接计数(§2 存息轮可买件占比)——调 interest_rule 阈值时引用;**息律投资局(cap9/10)阈值单独评估**(§1-E 降格域),不继承默认域结论。
