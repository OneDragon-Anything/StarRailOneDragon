## 1. 何时出现 + 状态流转

- **入口**:手机菜单点「商店」图标(`ClickPhoneMenuItem(STORE)` 模板匹配,语言无关)→ 商店,默认落**推荐商店**页。⚠️ 菜单→商店开屏有**较长过场动画**(黑屏加载,实测 ~8-10s),自动化要宽等待。另一入口:逐光捡金选关屏「奇珍琳琅」→ 商店(旧 UI 观察落子商店页;新版落点待复核,见 §7)。
- **状态流转**(动作 → 下一态,全部为商店屏内子态切换):

| 当前态 | 动作 | 下一态 |
|---|---|---|

| 常驻商店 | 点 tab-推荐商店 | 推荐商店(记住上次选中的左侧栏项) |
| 常驻商店 | 点左侧菜单(兑换商店/聚灵铸星/外观商店/协议商店/捕获梦华/星琼购买) | 切子商店 |

## 5. 消耗红线(真实货币)

- 「购买 ¥30.00」= **真实货币出口**。bot 的职责止步于**摆好二维码**(扫码支付弹窗),支付由用户扫码完成;**任何情况下不点「确认放弃本次支付?」以外的支付确认类控件,不代付**。
- 商品详情页浏览(点左侧栏、读规则)零消耗;「打开二维码」本身零消耗,但语义=发起购买,调用方(agent)须先向用户确认购买意愿再走到这一步。
