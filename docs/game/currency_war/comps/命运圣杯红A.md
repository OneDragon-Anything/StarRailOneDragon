# 命运圣杯·红A(Archer)(S 级真神)

> V4.4 合集 76807134:**S 级真神**(Archer 95)。攻略 [76924524](https://www.miyoushe.com/sr/article/76924524)。

## 机制(怎么 work)
Archer = **高倍率九五单核**;加**远坂凛 + 命运圣杯** → +150% 攻击 + 战技点。
命运圣杯羁绊给**命运改件**(祈愿自动给,非商店 find gate),加速成型。

## 成型阵容
Archer(双电锯+风暴潮)+ 远坂凛 + 瓦尔特(杨叔)+ 开拓者·记忆 + 4 战技点(花火/刻律德菈)+ 刃(2 减益)+ 缇宝/符玄/知更鸟。

## 成型节奏(4 个 5 费,成型难)
- 前期:低费过渡保血(远坂凛 2 费先找)。
- 升 8-9 找 5 费核心(Archer / 远坂凛),Archer 追 2 星。
- 命运改件由圣杯祈愿自动给,不需商店 find。

## 装备
