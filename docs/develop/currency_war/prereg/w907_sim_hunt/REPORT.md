## 3. 决策级归因（两局，均为 r9 abandoned 终局）

### 局 907288（seed；花费率 0.28 / 停滞 7 / 等级爬升 2 / 危局空转 2）

- **r3** hp 82→1（连败），此后 6 轮 hp 在 1–5 徘徊，金却单调上涨：27→50→81→99→130→169→180。
- **r5（决策证据）**：hp=1、金=81、phase=SPEND、form_ok=true，但 `dp_posture=存息`、`reserve_overflow=31`、`release_budget=0` → `actions=[]`。商店 5 张全部离线（Saber/花火/加拉赫/阮·梅/风堇），过滤本身合理，但**危机态 posture 仍是「存息」**。
- **r7（决策证据）**：hp=3、金=130、`reserve_overflow=80`、`release_budget=0` → 又一整轮 `actions=[]`。
- **r5/r6/r7/r8（结构证据）**：`alloc_frame` domain=`death` 每轮 active、budget 31→49→80→79，但 `chosen=[]`、`alloc_gold` 全 0——**death 域预算池每轮重算、从未支出**。
- `blood_budget_levelup_rejects` 在 r5/r7 反复出现：血量预算门把升级拦住，但没有等价的「买入保命」通道接住这笔金。

**结论**：危机态（hp≈1）下存息 posture 不降级，利息规则（每轮 +5）与事件收入把金滚到 180，而 release（预算释放）通道条件恒不满足（`release_budget` 全程=0）——金在死亡门口持续增值、零兑换。这是「利息纪律」在危机态未让位给生存目标的 posture 切换缺失，不是某轮手滑。

### 局 907106（seed；空转占比 0.44 / 危局空转 2）

- **r2–r3（早期空转证据）**：FORM 态、核=0、深度停在 6，金 20→41 连续两轮 `买0`；r4 一次补爆（买10/升8/D5）。早期「等引擎」的等待策略在核心数 0 时过长空转。
- **r7–r8（危机空转证据）**：hp=1/3、金 65→112、`dp_posture=升级`、`reserve_cap=102`、`overflow=10`，`actions=[]` 两整轮；此时 bench 已 8/8 满、商店全离线卡——buy 通道被 bench+过滤双堵，levelup/refresh 通道又不被允许（`blood_budget_levelup_rejects=1`）。
- **r9（终局挥霍证据）**：boss 轮一次连打 7×LevelUp 花金 32（auth=pop_slot），hp=1 下把等级从 7 抬到 8——危机金出口只在最后 boss 轮以「堆等级」单点释放，且 boss 仍败（delta=-2）。

**结论**：与 907288 同根（危机态金无出口），叠加一个早期子问题：核=0 的 FORM 空转窗口偏长（2 轮），金闲置到 r4 才集中兑付。

### sim 边界声明（哪些不能立为病灶）

- **商店离线卡不买 ≠ 错**：战斗结算是粗两态深度模型，买离线单位对 sim 存活无收益；「拒绝离线卡」本身可能实机正确。立病灶的依据是**持金于 hp=1 的零价值**（模型无关），不是「该买而未买」。
- **deployed 名单是代理**、装备效果/星级未建模：`deployed_power` 恒 10 不涨的现象不能直接推「战力卡死」。
- Δ 池 ±2 深度测不出，「散面 vs 集中」维度以实机为准。
- 检查器红项（degrade_recover_mutex 等）属基建/契约层，本批只记录不归因。

## 4. 候选修复项（诊断结论，供策略审查角色裁决；本批不改 src）

1. **危机态 posture 降级缺失**（轮证据：907288 r5/r7，907106 r7/r8）：hp ≤ 危机阈值时 `dp_posture` 应从「存息/升级」切换到「清金」，reserve_overflow>0 必须触发 release_budget>0。当前 release 通道条件疑似恒假（4 个危机轮 reserve_overflow 31/80/10/103 全部 release_budget=0）——修 release 触发条件而非加特例。
2. **death 域 alloc_frame「只算不用」**（轮证据：907288 r4–r8 chosen=[] 恒空）：预算池有 proposal 无 chosen，需查 alloc 的候选选择条件在 sim/通用路径下是否永远不满足——同型结构问题，可与 1 合并根治（同属「危机金出口」一个总模型）。
3. **核=0 FORM 空转窗口**（轮证据：907106 r2–r3）：等待上限（核=0 连续 N 轮零买入后强制降门槛买入）可作次级候选，频次上 0.44 仅 2/250 局离群，先随 1/2 修复复测再定。
