## 1. 背景与决策 why

P2 转化期 86-87% 买入件滞留备战席(919 买/130 上板),滞留源 60% = 档 0 dominance_buy(资格门 `gold>g* ∧ bench_free>0`,无板位检查),锁线 core 到店买不进(124 拒帧 87-90% bench 满,金≥30 全帧 = 不是没钱是没格子)。P88 调和引理定谳:dominance「无条件放行」是**金维**论证(1★ 全额退 ⟹ 净金成本 0),成立前提 = 席位免费;锁线转型域 D 帧(armed ∧ locked ∧ fp<1.00 ∧ 板满)是席位最贵态——线外 1★ 候选占位成本 = 被阻线内义务净 EV>0(P41③/P76 丙),「净成本≈0」前提在 D 域席位维失效,**支配性放行辖域不含 D 帧**。

**决策:收窄 = V_slot 维的资格修正,非对支配性优先序的否决**——在两 S_spec 发射位(dominance_buy/hub_option_buy)加 D 帧辖域前置,豁免臂(m2 族/C1/M6/ev_buy 等 13 买因)零触碰;收窄谓词 = 结构布尔合取(**域谓词单一源** ∧ 买因 ∈ S_spec),零新参数;fail 方向 = 不收窄 = 保守可逆;不引开关直接落码(ADR-0604 档 0 摘旗先例)。

## 2. 决策本体(落码形态)

1. **域谓词单一源**:`mandate.swap_transition_narrow_frame(state, session)` = kernel `cw_deploy_logic._swap_transition_domain_of` **同一谓词**,mandate 侧只做店侧输入装配(locked 单源 = `ist.locked_comp` 非空;fp 单一源 = `cw_comps.form_progress`,锁线帧 committed ⟹ tgt = `target_comp` 同装配双轨分支;板满 = `deployed_occupied ≥ state.max_units()`)——禁第二份合取(第二源 = 与部署域 M1″ 转型域分裂),单一源锁以谓词翻转双向断言承载。
2. **收窄集与豁免闭集**:`mandate.PRESS_NARROWED_ARMS = {dominance_buy, hub_option_buy}`(必须 ⊆ `sell_gate.LAUNCH_CAUSE_BY_ARM` 15 键);豁免 ⇔ reason ∈ 闭集 ∖ S_spec,**结构性承载 = 仅两 S_spec 发射位挂前置、他臂零消费**(防复制枚举漂移;闭集锁按 13 键差集断言,新买入臂入映射表即红强制分类)。
3. **dominance 位**(shop 臂内,结算线地板检查之后):D 帧停发 + 分键 `press_narrowed_transition_domain`(帧级,「将发射笔」口径 = 候选全门通过后首见笔计数一次——防 §4.1-⑦① 辖域覆盖比 = 开火数/全部 dominance 买入数出现 >1 的判读畸变;T-193 结算线地板分键为候选级事件,先于本检查照常显影,零扰动)。
4. **hub 位**(同谓词收窄):结构性空开火面(hub 辖 unlocked 与 locked D 域不相交,设计 v2 修订 10),独立分键 `press_narrowed_transition_domain_hub`,判读禁并桶;活性 = P86 辖域变更哨兵。
5. **prep 位**(设计修订 3):dominance OpenShop 发射位**仅登记对称观测** `press_narrowed_transition_domain_prep_seen`,零行为收窄——prep emit 只是开店载体,真实收窄面 = 店侧谓词。
6. **M6 两域零触碰**:prep `_emit_open_shop('m6_stock')` 与 shop M6 臂均不挂收窄(ADR-0604 档 2 语义不动;P88 §5 溢余出口守恒:M6 压库 = 解封回填主体的合法出口,收窄不得连坐档 2 支出出口)。
7. **docstring 辖域注(双引注,P88 落码纪律)**:`mandate.dominance_buy_eligible` docstring 增辖域注——金维支配性论述的席位维两处辖域修正(①ADR-0616 命题 4:bench_free≤1 带,本体收紧候 T-166 批 2;②P88 调和引理:D 帧,落码在消费位侧)+ 域语义声明(本函数本体 = 金维+席物理维资格门,不辖 D 域判定;两域修正叠加合取)——缺本注则在码支配性论述构成收窄回滚的合法依据。

## 3. Considered Options

| 选项 | 裁决 | 理由 |
|---|---|---|
| 宽口径收窄(P2 板满全 off 停买) | 否决 | 解封下界虽高(73-74%)但切断 m2 合成素材供给腿,转化链自伤(设计 §3.1) |
| 档 1 接投影 / off 件配对投影 | 否决 | 档 1 板满帧恒不发射 = 打空靶;配对投影防御代价不可测且与收窄目标自斥 |
| 分键取「D 帧资格门过即计」(门级口径) | 否决 | 无候选帧照计开火 ⟹ 辖域覆盖比分母畸变;取「将发射笔」帧级口径(设计与判读消费面 §4.1-⑦①) |
| 收窄谓词在 shop 臂内联第二份合取 | 否决 | 域谓词第二源 = 与部署域 M1″ 转型域分裂;单一源锁(谓词翻转双向断言)钉死 |
| 收窄谓词引开关 | 否决 | fail 方向 = 不买 = 保守可逆,无悬置态;ADR-0604 档 0 无开关先例 |
| T-166 批 2 的 bench_free>1 收紧并入本批 | 否决 | 跨批夹带:命题 4 有独立验收面(A/B dominance 发射频次对照),其 ADR 实施序批 2 候派;本批 docstring 双引注已声明叠加关系防误读 |
