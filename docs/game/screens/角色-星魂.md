# 角色-星魂(character_eidolon)

> source_image: sr-od-test/screens/角色-星魂/default.webp(2026-10-17 live 建档,布洛妮娅满魂页)

## 何时出现

角色页左侧「星魂」TAB。独立屏。

## 状态流转

```
详情 TAB → 本屏(6 星魂碎片拼图展示,已解锁的亮显+名称,未解锁暗显)
右上关闭 X → 离开角色页
```

## 识别特征

- id_mark「标题-星魂同调」[85,25,200,75](左上标题,4 字全称;live precise 实证)

## 可交互元素(live 验证 2026-10-17)

| 元素 | 坐标 | 行为 |
|---|---|---|
| 左侧 TAB 5 个 | 同详情页坐标 | 切对应屏(goto_list 已建) |
| 头像条 | 首位 (452-528,28-108) | 切角色保持本 TAB |
| 星魂碎片 | 6 块固定位 | 点开单星魂描述(子面板,未建档) |

## automation 要读信息

- 读区-星魂1-6名:6 个固定位置的星魂名 OCR([670,220,840,275]/[1085,200,1255,255]/[1525,405,1695,460]/[1325,880,1495,935]/[840,845,1010,900]/[385,765,555,820])
- **星魂数判定**:OCR 命中几个名字 = 已解锁几魂(实测满魂 6 个名字全可 OCR;未解锁星魂是否仍显示名称待扫描时对 0 魂角色实测——若暗格也显示名字,则改用亮暗视觉判定)

## 注意

- 6 块碎片位置固定(布局不随角色变);中间大图为角色特写
- 满魂 vs 0 魂的亮暗对比明显,视觉/模板判定兜底
