# 货币战争-星琼详情

## 何时出现

游戏全局「点货币图标 → 开详情」行为的星琼实例:点击任何在场货币图标即弹本详情(2026-09-07 实机事故入口:列车补给每日弹窗中央徽章饰章内下缘嵌有星琼图标,点击中央徽章区领取时命中图标 → 弹出本弹窗,S1 两次活体复现,ADR-0574 §5)。模态弹窗:居中卡片(约 x393-1521,y292-790),背景压暗+模糊——盖场时下层画面全部锚点 OCR 失明。

## 状态流转

- 入口:点货币图标(含列车补给弹窗中央徽章内的星琼图标——「点中央 = 只开详情不领取」,即 T-98 级联事故上游)。
- 出口:右上角 X 关回下层画面。**禁 ESC**(项目禁键令,前向兼容手机模拟器);点空白遮罩关闭未采样,不作默认手段(ADR-0574 §5 S3 挂账)。
- 接力:若下层压着未领取的列车补给弹窗,X 关闭后下一轮由补给守卫接住领取,两守卫交替收敛(ADR-0574 §2.2)。

## 识别特征

- id_mark 组合:`标识-星琼标题`(778,318-872,372,text=星琼,lcs 0.5)+ `标识-稀有货币`(539,686-647,727,text=稀有货币,lcs 0.75)。双 id_mark 全中才算画面精准匹配,入口链守卫触发同判据(不发明第二套识别语义)。
- 锚强度分层:「星琼」2 字 @0.5 是全家族最弱配置(含任一字符即命中),单锚不可触发,靠「稀有货币」4 字 @0.75 管精度;锚避开动态值——「当前持有」数字行不入锚。

## 可交互元素

| 元素 | 位置 | 行为 |
|---|---|---|
| 按钮-关闭X | 弹窗右上角 (1437,321-1489,373),中心 (1463,347) | 关弹窗回下层 |
| 当前持有数字行 | 弹窗内 | 纯展示(数字变动,不入锚) |

## automation 要读信息

- 无需读——弹窗本身无策略消费信息,入口链守卫识别即关。

## 守卫挂点与决策指针

- 入口链守卫:注册表 `cw_entry_start._JADE_DETAIL_GUARD`(识别=上述双锚 AND,动作=点 `按钮-关闭X`,具名状态 `星琼详情弹窗关闭中`),四挂点 = app `_enter_lobby` 首节点 / `CwEntryEnter.wait_lobby` / `CwEntryStart.click_start` / `advance_to_prep`,守卫列各节点一切既有分支之前。
- 决策依据:ADR-0574(守卫引入+交替循环上界闭合)→ ADR-0607(守卫族注册表化)。
