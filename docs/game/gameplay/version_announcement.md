# 版本公告(游戏级弹窗)

新版本上线后,游戏客户端会在**待机时自动弹出整屏版本公告轮播**,介绍本期版本主题与机制(本期 2026-08-26:「贪饕」侵蚀——部分敌人被侵蚀,受致命伤不灭并回复生命,需压制其生命上限到一定比例才可彻底消灭 [实机公告原文])。它**不属于任何玩法 app**,会盖在任意画面上(大世界 / 玩法画面 / 加载后的入口均可能),是所有自动化流程共有的「半路杀出」画面。

## 机制事实(实证)

- **两页轮播**:第 1 页只有右箭头翻页(无出口);第 2 页才出「关闭」钮。直接找关闭钮在第 1 页必然扑空。
- **一次性**:同版本关掉后不再自动弹出。
- **关闭后无副作用**:露出底下原画面,不改变任何游戏状态 [编排者 2026-08-27 live 实证]。
- 画面识别与交互建模见[版本公告轮播](../screens/版本公告轮播.md)。

## 对自动化的影响

- 任何长时间运行的流程都可能被它打断:返回大世界的兜底 op(`BackToNormalWorldPlus`)与 CW 入口流程(`CwEntryEnter.wait_lobby`)均已建分支——识别公告屏 → 第 1 页翻页 / 第 2 页点关闭(零 ESC 键输入,项目规则)。
- 版本更替后公告主题变化,标题 id_mark(「贪饕」侵蚀)会失配:新版本首跑前需按新公告 fixture 补锚。
