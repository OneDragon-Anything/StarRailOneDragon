# 委托(assignments)

游戏内标题「**委托**」(左上角)。手机菜单「委托」入口打开的派遣管理画面:左侧材料分类 tab + 委托列表,右侧委托进度与领取。`pc_alt=true`。

## 何时出现 + 状态流转

- **入口**:手机菜单(`菜单`)点「委托」图标(≈1732,375,红点=有可领奖励)。
- **出口**:右上关闭 X / esc → 回手机菜单。
- **子态**:
  - 三个材料分类 tab:专属材料 / 经验材料·信用点 / 合成材料(选中 tab 白底高亮,列表联动;已实锤切换)。
  - 领取奖励 → 「获得物品」通用弹窗(点击空白处关闭;已实锤)。
  - 派遣中提示:右侧气泡「委托正在进行中,请等待奖励帕!」——⚠️ 气泡与可领态**并存**(2026-07-29 委托可领.webp 实拍:气泡在挂 + 「领取奖励」金黄亮起),气泡非「无可领」专属标志,可领判据只看「领取奖励」亮/灰。

## 识别特征(稳定锚点)

- **标识-委托标题**:左上「委托」文字(≈102,50),id_mark(conf 0.9995)。
- 三个 tab 文字:专属材料 / 经验材料/信用点 / 合成材料(常驻,带角标数字=可领项数)。
- 底部「进行中的委托 4/4」+ 委托槽图标行 + 变更委托按钮。
- 易变(勿当特征):委托项名称/持有数、已进行小时数、奖励图标、角标数字。

## automation 要读信息

- **有无可领**:「领取奖励」亮/灰;菜单委托图标红点。
- 派遣状态:「委托正在进行中」气泡 / 各 tab 内委托项「进行中」角标 / 已进行 x/30小时。
