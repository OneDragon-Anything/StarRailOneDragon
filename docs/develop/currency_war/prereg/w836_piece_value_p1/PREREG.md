## 1. 臂定义(单因子)

- **off 臂** = registry 缺省:piece_value 伞+全部子旗标关(零漂移锚);
- **on 臂** = piece_value_enabled=True ∧ piece_value_buy_enabled=True,
  分量面仅 A+B(w_activation/w_retention 注入标定值);
- 与 realization_*(W802)/p1_tier_push_*(W803)开关**不同开**
  (ADR-0494 正交性纪律);κ 通道 Phase 1 零改动,无 κ 对照臂
  (κ 收口归 Phase 1.5 独立 A/B,见 §5)。

## 2. 主门:M1-L 传导格(W829 v3 §5 对齐分布级分层格)

- 指标:P1 出口健康传导 = 锁定局中「拒买病灶复现率」
  (①他体系钥匙件在 e<2∧溢余段被拒买事件占比;②贯穿件贴线未买
  同类事件占比)——事件定义在 arms jsonl 判读脚本中按 sim 计数
  反演,口径随本文件冻结;
- 分布级分层格(W829 v3 M1-L 同式):off 臂按 M1 轮距层三分
  (≤2/=3/≥4),主格 = **off=3 中位层配对差**(同 seed 配对),
  判格 = 配对差均值方向为病灶下降 ∧ bootstrap 95% CI(重采样
  1 万次)不含零;全臂均值只报不判格(W830 分层教训:全均值可
  掩盖中位层零);
- **效应量下界(判前定,防「显著但无临床意义」)**:病灶①占比
  相对下降 ≥30% 且绝对差 ≥3pp;病灶②同式。低于下界的显著 =
  判「机制工作但剂量不足」,回标定批不开臂。

## 3. G7 复算上界带(W833 补丁②三件套,全部判前写死)

1. **折算式写死(量纲:两边统一为 pp)**:逐局复算该臂买入序列
   下的金轨迹——对每局,以 on 臂实际买入笔序列为准,逐笔扣除
   费用后重放 ⌊g/10⌋ 档位轨迹,得「该局新增买入造成的金<50 帧数
   增量 Δf_i」;折算 = Δf_i / 该局总帧数 × 100(pp),以局为单元
   折算后跨局求和取均值 = 上界 U(pp)。禁后改口径;复算脚本随
   判读批入库可复查。
2. **逐局差集配对(「新增买入笔」定义)**:同 seed on/off 两局
   配对;新增买入笔 = on 局买入事件序列相对 off 局的逐笔差集
   (按「轮次×卡名」键对齐,同一键两臂都有 → 非新增)。破息笔
   判据 = 该笔支付后金 < registry.interest_floor()。
3. **效应量下界**:G7 残差(实测 on−off 金<50 帧占比差,同 seed
   配对)> U + 0.5pp = 上界带破 → 判「存在来源不明侵蚀」,回炉;
   残差 ≤ U = 残差可被本臂买入行为全额解释,无来源不明侵蚀,格绿。
   U 的定带前置:复算先跑,若 U < 0.5pp(机制预算不足)→ 本格
   判「G7 无预算」记挂账,与 W829 v3 §5.1 的 U<1.9pp 分支同型处置
   (显式登记取舍,不当未清挂账)。

## 4. 护栏格

- **G4 存活挤席**:≤ +2pp(W829 清账门,原样继承);买侧加项放宽
  不得重演 W828 的 G7/G4——门由 W829 兜底,但模型不得把门当免责;
- **Goodhart 警报**:任一臂线外件买入率 >30% 帧占比 → 权重过宽,
  回炉重标定,不调命题辖域门(W831 v2 §5.2);
- **M4 方向非负**:终局存活方向不劣化(读数格,不单独判格)。
