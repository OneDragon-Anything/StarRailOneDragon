# ADR-0187: 时间经济台账 J0 落地(redesign 45 号处置:吞吐首产 + J1 供给审计)

## Status

Accepted(2026-08-17,策略优化会话;J1 判读=主杠杆失效,层按预注册条款降级为吞吐报表;
认输 op/ρ 估计器不立项)

## Context

45 号主张:wall-clock 是 44 轮以来唯一从未被定价的资源;「判死→照打完」是无人决策过的
隐式默认。J0=吞吐台账首产(零行为),J1=死局打完份额 ≥15% 预测(<5% 主杠杆失效层降级)。

## Decision Drivers

- J1 预注册可证伪:死局份额是「认输 op/ρ 估计器」值不值得建的唯一依据
- 零行为离线可先行

## Considered Options

1. **台账先行 + J1 机器判读(选)**:先测再建,预注册条款自动执行;
2. 直接建认输 op(三重门控)——若死局份额≈0 则纯增风险零收益;
3. 不做——「局/小时」继续不是被管理资产。

## Decision

选 1:`cw_time_ledger.py`(run_wallclock 重建 + throughput_ledger)——

**J0 真实首产(17 局,outcomes.jsonl ts)**:

| 指标 | 值 |
|---|---|
| 平均局时长 | 11.8 min(1.1-30.1) |
| 吞吐 | **5.07 局/小时** |
| 死局打完份额(wall-clock) | **0%** |
| 节点间隔均值 | 191 秒 |
| 长间隔(≥60s 战斗主导)占比 | 100% |

- **J1 判读:主杠杆失效(0% < 5%)→ 按 45 号自我证伪条款,层降级为吞吐报表**;
  认输 op 与 ρ 估计器**不立项**(当前语料无死局打完浪费——bot 死前都在打，或局在
  记录窗口内未到判死态)；
- 44 J4 交叉验证：节点间隔战斗主导(长间隔 100%),「战斗占大头」方向性佐证(段级
  精分解待 44 hook);
- 吞吐 5.07 局/时成为 29 号队列仿真的输入常数(降级后保留的报表价值)。

## Consequences

- 45 号按预注册条款处置完成(降级不是失败——是判据在正确工作)；
- 认输 op/观测-时间仲裁/复杂度预算随降级不立项；若未来胜率结构变化(死局增多)，
  台账会先看见(J1 重跑即一条命令);
- 45 号提案文件删档;测试 +3。
