# 模拟宇宙-世界详情(sim_uni_world_detail)

经典模拟宇宙的**世界详情页**:在[世界选择页](模拟宇宙-世界选择.md)点击居中星球后进入,左侧为难度 I~V 竖排选择,中央为世界星球大图,右侧为难度/积分/奖励信息,底部为开始按钮。**按钮随进度状态切换**(见下),是开局流程(选难度→启动)与续跑流程(继续进度)的分叉点。

## 何时出现 + 状态流转

- **入口(实测 2026-09-26)**:[世界选择页](模拟宇宙-世界选择.md) → 点击居中星球。
- **两个子态(实测)**:
  - **有进度态**(该世界存在未完成探索):难度列表**锁定**(点击不切换,实测点难度 II 无反应),显示探索进度 N/13,按钮=「继续进度」+「结束并结算」。
  - **无进度态**:难度**可选**(点击即切换,标题与积分/推荐等级联动),显示推荐队伍等级,按钮=「下载初始角色」。
- **出口(实测)**:
  - 有进度态:「继续进度」→ 直接进入楼层(跳过命途选择);「结束并结算」→ 确认弹窗(「结束「模拟宇宙」将结算奖励并重置进度」)→ [结算页](模拟宇宙.md)(探索中断,积分入账)→ 回世界选择页,进度清零。
  - 无进度态:「下载初始角色」→ [初始配队页](模拟宇宙-初始配队.md)。
  - 右上 ↩ 返回列表(未点击验证,位置实测)。

## 识别特征(稳定锚点)

- **id_mark**:「通关可获得积分」(pc_rect 1140,138-1420,185,OCR conf 0.99)——详情页独有文本,两种进度态均显示(后随数字为动态值)。
- 世界难度标题(「第X世界|难度N」)为动态组合值,勿整体当锚。
- 与[世界选择页](模拟宇宙-世界选择.md)共享标题「模拟宇宙」,靠 id_mark 区分。

## automation 要读信息

- **进度状态判定**:「继续进度」area 命中=有进度态;「下载初始角色」area 命中=无进度态。bot 据此分叉续跑/开局流程。
- **探索进度数值**:area 探索进度(OCR「N/13」),有进度态显示。
- **当前难度**:area 世界难度标题(OCR 含「难度N」)。

## 识别快照(analyze_screen 实测,2026-09-26)

- 有进度 fixture **精准命中**(is_precise=true);无进度帧同样命中 id_mark(两态共享锚)。
