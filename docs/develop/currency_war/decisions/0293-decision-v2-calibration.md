# 0293 - 决策框架 v2 首轮标定(诊断先于调参;刷新双门/目标件爬坡/弱件换金)

- **Status**: accepted(2026-08-24;标定批——部分达标,残差定位到结构层)
- **Context**:ADR-0291 骨架活性达标(mean 20.0 vs v1 30.7,团灭 0/30),
  指挥官定标定方案:分域锁死(P3 期望系数/H3 阶梯/息律 EV 公式)、
  诊断先于调参、每轮 1-2 参数、30 局配对(分辨率底 ±1.93)、
  n=100 终验。可调域=registry 形态进度权重/追级单位值/刷新 EV/
  卖出偏置,全部集中 registry。
- **诊断**(20 局配对 900000-900019,按形态段分解 v2-v1):
  早期买入 3.6 vs 11.6(欠买,金滞留 +11)、refresh=0(骨架遗留)、
  卖=0;中期掉血 -10.95 是早期欠账因变量。评分层根因(逐轮裁决
  dump 实证):①refresh_ev=0 恒负分不刷;②持有域形态代理早顶格
  (rung/targets/depth 全封顶)→ 买/卖候选 0 分被「非正分」拒。
- **Considered Options**(调参轨迹,每轮 1-2 参,30 局配对,
  seed 900000-900029,池 fp 066c4185,基线 v1=30.67/团灭1):
  1. **R1 refresh_ev=2.5 + target_hold_base=4** → 24.07 但团灭 2;
     拆分归因:增益全在 refresh(+5.76),target_hold_base=4 单动无效。
  2. **R2 +refresh_max_round=3**(轮界门,v1 r258 早期方向刷新语义)
     → 27.87/团灭0——原窗达标;但诊断揭示刷后 re-decide 链 r1-3 刷
     11.7 次、金抽干 0.6 → [12] 息引擎门锁死晚期升级(0.45 vs 6.25)。
  3. **R3 +refresh_min_gold=20**(金保底门)→ 30.70/团灭1,配对差
     +0.03 平局带;**但 n=100 揭穿 30 局窗口过拟合**:24.08/-7.07
     (新 seed 段 900030-900079 诊断:弱段移到成型期 r7-9,Δhp -9.52,
     滞金 +18.9;v1 中期 refresh 1.76 次/局找件,v2 门控 r3 后断供)。
  4. **R5 rung_frac 0.3→0.5 / R8 target_hold_value 3→4**:双窗逐位
     同分,零行为差(0→正门槛未变)——判无效,回退。
  5. **R6 target_hold_base=9** → 原窗 31.37/团灭0(第 7-9 件目标件
     显影正分);新窗 16.73/团灭4——同过拟合,n=100 24.08。
  6. **R7 refresh_max_round 3→6**(中期找件窗口)→ 双窗 28.6/24.1,
     n=100 27.74/团灭4(差 -3.41)。
  7. **R9/R10 +off_target_sell_bias(0.5≡1.0 双窗逐位同分)** →
     双窗 27.9/27.57,**n=100 终验 28.26/团灭6(=v1)/配对差 -2.89**。
     ——采纳。
- **Decision**:采纳 R10 参数组为 DEFAULT_REGISTRY 默认:
  refresh_ev=2.5 / refresh_max_round=6 / refresh_min_gold=20 /
  target_hold_base=9 / off_target_sell_bias=0.5(全在 registry,
  scoring 仅消费参数)。新增两个 registry 参数(refresh_max_round/
  refresh_min_gold)与一个卖出偏置参数——「刷新 EV 域」与「卖出
  偏置域」的参数化完成,代码零散硬编码为零。
  回归锁:`test_cw_adr0293_calibration.py`(标定五参逐值 +
  registry 全字段 hash cf2bc084… 防漂移 + 刷新双门/弱件换金行为锁)。
- **验证**(sim 配对,单进程,snapshot 池 fp 066c4185):
  - 调参窗口(900000-900029):v1 30.67/团灭1,v2 27.90/团灭3;
    按窗口线 mean ≥ v1-3=27.67 ✓,团灭 0 未保持(v1 同窗也 1)。
  - 持出窗(900030-900059):v1 29.4/团灭1,v2 27.57/团灭2,差 -1.83
    平局带内。
  - **n=100 终验(900000-900099)**:v1 31.15/团灭6/ge60 13,
    v2 28.26/团灭6/ge60 6,配对差 -2.89(SE 2.46)——**未达平局线
    1.93,部分达标**:mean 线过(≥27.7),团灭率追平 v1,但成型
    转化(ge60 6 vs 13)差距残留。
- **Consequences**:
  - 正:决策差从 -10.7(骨架)收敛到 -2.89;团灭率=v1 水平;ADR-0291
    遗留项(refresh_ev=0/off_target 卖 0 分)清偿;标定参数全注册表
    化+hash 锁,后续标定批可增量推进。
  - 负/风险:**残差 -2.89 定位到结构层而非参数层**——持有域形态代理
    在 r7-r8 全顶格(rung/targets/depth 封顶)而真实战力弱(bench 囤
    种子件撑满代理;seed 900032 裁决 dump 实证一切买入 0.00),即
    ADR-0291 已登记「形态域=持有域高估 bench 价值」风险的显影;
    参数域已无杠杆(本轮 R5/R8 无效臂证明)。**下一批方向:形态域
    换 deployed 域或混合域(scoring.board_rung_x 已留注),属结构
    变更,须重过骨架活性验证**。
  - 教训入档:**30 局窗口标定过拟合实证**(R6 原窗 31.37/团灭0 →
    n=100 24.08)——标定循环必须双窗(训练窗+持出窗)验证后才可
    进终验;单窗达标不可采信。
