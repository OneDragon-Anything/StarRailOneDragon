# ADR-0512: 战力模型范围——唯一消费者=sim 战斗结算层,决策层永不消费

> **引用勘误(2026-09-04 ADR 存量 review)**:`.debug/` 归档 → 本目录(decisions/)同名 ADR。文内出现处按此对照读取。

## 状态(Status)

accepted(2026-09 战力建模专题讨论轮,用户逐项裁定;设计件=[../sim-power-model.md](../sim-power-model.md))

## 背景(Context)

hp 门控家族关闭(ADR-0503/0508/0510 链)后遗留前提问题:战斗能力没有经过验证的模型,战力模型建不建、建了用在哪。用户裁定方向:**模型要建,但战力模型导出的 hp 变动偏差很大,不能作为策略依据**;随后对七个决策消费点(买/卖/升星/部署/装备/刷新/换线)逐项核查,确认全部可由「期望数学(经济常数+池概率)+结构计数+知识先验」解决——决策层对战力模型不存在未满足的需求。

## 决策(Decision)

1. 战力模型 = P(win | 我方板面快照, 战斗上下文) 的统计模型;**唯一确认的消费者 = sim 战斗结算层的胜负面**(默认主路径 `kernel/cw_coarse_battle.py` 的掷定点与 P2 参数层,经注入契约接入;接线细节见设计件 §6)。
2. **决策层永不消费**:任何策略模块(decision_v2/ev/scoring/arbiter/intention/economy 等)禁止直接或间接读模型输出——间接形态含「Δwin_p 折算金当量进 EV 总账」一类接口,一并否决。决策侧的「结构→强度」关系继续用**实机真值统计**(如成型度×胜率阶梯,docs/game/currency_war/research/proofs/p03);统计与拟合外推以「是否已发生事实的分布」分界。
3. **训练真值唯一来源 = 实机战斗语料**(telemetry decisions 行快照 + 二值胜负);sim 永不进训练集——现结算层胜负面与板面结构几乎无关(回退阶梯=节点×轮次边际;P2 参数层=3 个聚合键),自产样本只会学回自身系数(循环)。
4. **HP 不作训练目标、不作特征、不作校验主量**;二值胜负是唯一标签(HP Δ 只许作辅助校验量)。
5. 数值与实施细节不落本 ADR;单一源 = 设计件 + 将来的代码注册表/校准表。

## 判据与验证(Evidence)

本 ADR 为范围裁定,零码。七消费点核查的期望数学族证据(买=目标集单源+缺口账单+核心加权;升星=等待期望;刷新=统一 EV 式等)在讨论工作档 `.debug/temp/currency_war/`,随收口 ADR 批正式归档。

## 边界(Constraints)

- 认识论全量裁定(可信/不可信分层、HP 禁令全文、阵容框架六裁定)归后续收口 ADR,本篇只钉战力模型范围。
- 不动:Δ池管线(对照臂与 reward/supply 路径)与幅度层(胜负各自的 HP 分布采样);战斗类默认主路径(coarse)胜负面的替换在本裁定范围内。不新增决策层模型消费点。
- 设计件落地实施前须过独立对抗审查(档 2 攻击,每条意见落文件:行)。
