## 2. 对局循环新要素(与 v4.4 差异)

### 2.1 奇遇伙伴(新机制)

- 每局随机一名奇遇伙伴同行,开局简报展示(「本局奇遇」框);本局实测 = **绷带猫**:「把所有补给阶段【角色奖励】替换为【武装箱】」。
- 伙伴在备战画面左上有头像 + 两个沙漏图标(语义待查:推测奇遇触发倒计时/次数);位面内触发时伙伴揭晓「专属奇遇效果」(官方说明,未实测到触发帧)。
- 简报画面新增「本局奇遇」框(伙伴名 + 效果一句话),已建档(标识-本局奇遇 + 读区-奇遇伙伴名)。

### 2.2 补给节点 = 武装箱 5 选 1(绷带猫局)

- 补给画面变为 5 个「简易武装箱」并列,每箱内 1 件简易装备(实测:量产型装甲/折叠小刀/和平手枪/幸运星/轮滑鞋),选 1 领取(点箱体选中 → ✓ 角标 → 确认)。
- 首次点卡片无反应、第二次才选中(疑似首击为焦点移动);「已选择 N/1」文本随选中变化。
- 补给画面建档已是 v4.7 形态(标识-补给阶段/按钮-确认/文本-已选择/按钮-返回备战界面),离线回验精准命中。

### 2.3 跳过类按钮(新)

- 投资环境/投资策略/补给画面顶部新增 **「返回备战界面」按钮**(跳过选择直接回备战);投资策略仍可「确认」。
- 简报画面为「下一步」翻页式(奇遇伙伴介绍 → 首领展示 → 开战)。

### 2.4 结算经济实证(新手局读数)

- 节点胜利结算屏分行展示:基础奖励 / 利息(🔄 图标)/ 连胜×N;实测 1-3 战斗胜 = 基础 5 + 利息 1 + 连胜 1 = 7 金。
- 败局结算:小队生命值扣减(实测 1-4 败 -7),连胜清零,仍有基础奖励 + 利息(1-4 败 = 5+1=6 金)。
- 奖励节点胜利额外掉落晶矿(场上可点拾取;实测蓝球/灰球,开出简易装备:幸运星/以太钻头等)。
- 购买经验按钮:实测 Lv.4→5 花 4 金;经验面板「N/M」(Lv.4 档 0/6,Lv.5 档 0/16)。

### 2.5 机制核实结论与待查项

- **买牌合成规则(v4.7 实测定论,升级为结论)**:**三张同名合成两星**——两张(场上一张+买入一张)不触发;第三张买入后立即合成,合成落点在场上同名单位(场上 1星→2星,备战席复制被吞;三张含试用牌)。v4.4「买两张即合成」语义失效(merge_mechanics.md 待按此重写)。拖拽备战复制→场上同名 = 交换非合成。
- **试用角色**:商店牌与场上角色出现「试用」红标(新手局特征;正式局是否出现、是否局末移除待查)。试用牌同样计入合成(第三张试用牌触发了场上合成)。
- **备战羁绊面板语义**:面板行 = 羁绊名 + 徽章数 + 阈值文案(如 连击 3「2/4/6/8」、奇兽花园 2「2/3」);`read_board` 的解析(读数与在场人数的对应)在 v4.7 需重核——实测同一帧识别出面板上不持有的羁绊行(梦境交织/召唤/小小巨人),疑面板含「攻略目标羁绊」展示或阈值文案误读,待重采。
- **右侧道具栏新栏位**:金锤子(∞ 角标)与武装箱图标出现在右栏顶部,`owned_equips` SIFT 未识别(模板库缺这两类);武装箱可从右栏开启,备战席武装箱自带「开启」按钮(v4.7 新增)。
