# 货币战争-投资环境

## 画面简介

位面 1 开场弹出的环境三选一画面（进位面 1 后、1-1 开局前出现）；选定环境影响整局（开局包 / 策略品质池 / 节点替换等）。画面结构（按归档帧）：顶部标题「投资环境」+ 三张环境卡横排 + 底部「剩余次数」文本（左侧圆钮 = 整组刷新）+「确认」。确认后进 1-1 开局补给动画（长约 10 秒，期间 analyze 不命中属正常——备战面板「备战阶段」文本出现才算就绪）。

## 识别后要做的决策

选哪个环境：环境池随局随机三选一，遇清单外的以卡面文本决策。已知效果形态：群攻概念股 = 开局送角色+装备、火药味 = 开局 2 武装箱、彩虹时代 = 策略全棱彩品质、**白银时代 = 策略全白银品质（当局候选实拍灰白卡框）+ 敌人难度不因品质提高**、人生意义 = 随机装备 3 件、仙舟舰队概念股 = 送角色+装备+仙舟系刷新概率提升。**千星商会概念股开局包实测（2026-11-19）**：到手 = 托帕&账账（2★）+ 忘归人 + 真珠 + 轮滑鞋——开局包构成 = 羁绊成员（托帕&账账/真珠）+ 通用辅助（忘归人，1 费非千星成员）+ 基础装备各 1，**成员不严格=羁绊成员**，读开局包时别按「发的人都进该羁绊」推断阵容方向。**环境池已知 ≥10 种（2026-11-19 三局 + 2026-11-20 第二/八局 + 2026-11-21 第十一局 + 2026-11-22 第十六局累计实机见过）**：白银时代（默认环境）/ 千星商会概念股 / 召唤概念股 / 成功经验 / 青梅牛马 / 人身意外险 / 彩虹时代 / **过剩经费** / **经济过热** / **开拓银轨概念股**——环境池随局随机三选一，遇清单外的以卡面文本决策；**彩虹时代实测注记（2026-11-19 第三局）**：「策略全棱彩品质」兑现 = 该局投资策略三选一候选全为棱彩品质（最高品质档），环境对策略品质池的改写是全局的。**过剩经费实测（2026-11-20 第二局，第十四/十五局再见复证）**：效果兑现 = 补给节点给的角色入手时自带 2 件装备（补给角色即插即用装）——开局装候选环境，省合成材料，效果语义以当局卡面全文为准（两局样本口径一致）。**经济过热实测（2026-11-20 第八局）**：奖励节点全替换为次元扑满、掉更多战利品——本局 1-9 前奖励球 16 颗（约常规局 2 倍），战利品收益以当局实读为准，效果语义以当局卡面全文为准。**开拓银轨概念股实测（2026-11-21 第十一局首遇）**：开局送瓦尔特 + 三月七（双银轨成员）+ 光能电池——开局即达开拓银轨 2 开张线，**商店开张零等待**（无需对局中自然凑 2 银轨），首次开张自动弹面板（开拓商店「首次开张自动弹出」机制在本环境实证，操作见「备战-开拓商店」卡）；银轨经济开局即开，详细商店机制按「备战-开拓商店」卡操作。**白银时代实测（2026-11-22 第十六局，环境卡面全文首读，帧 `screenshot_20261122_122546_182850.png`）**：卡面原文「这局的投资策略均为白银品质，因此敌人难度不会由于选择高品质投资策略而提高。」——效果语义 = 当局投资策略候选全部压到官方所称「白银品质」档，且**敌人难度不因品质补偿**（纯降档环境，不会因拿不到高品质策略遇到更强的敌人）；当局实拍候选为灰白卡框（≈2-1/2-2 三选一三卡全灰白，帧 `screenshot_20261122_133305_871835.png`）——「白银品质」的实机卡框在 r13 白银时代局读作银色卡框、本局读作灰白卡框，两读并档（官方命名「白银品质」，倾向同档异读），判品质仍以当帧卡框为准，品质-环境映射详见「货币战争-投资策略」卡。**人身意外险实测（2026-11-23 第十九局，环境名在册首次实机选中实测）**：效果兑现 = **BOSS 战前追加一个补给阶段**——流程实拍为「首领横幅 → 补给阶段 → 主角光环选择 → 首领战」（帧链：1-9 横幅 `screenshot_20261123_010053_135260.png` → 1-9 补给阶段 5 列 `screenshot_20261123_010145_789001.png`〔顶部节点条 1-9 首领位〕→ 主角光环 `010505_699213`）——BOSS 战前战力窗口（多一次 5 选 1 补给入备战席再打首领）；补给画面复用「货币战争-补给」本体（标题「补给阶段」同构）；「每位面 BOSS 前各 +1」为环境卡面语义口径（本局仅位面 1 实证，位面 2 候后续局）；效果语义以当局卡面全文为准。
