## 发现 1(高·证明)R52-2「λ̄_gate 上端 ⇒ 绑定违例面小=保守 / 两半边同保守」方向反号,且该取端在无授权账情况下重新引入 R51-2 案 B 被处死的「行为面结构性违反用户绑定约束」形态

**位置**:IMPL_DESIGN §2.0-3 规格④ λ̄_frame 条款 R52-2 段;IMPL_FIX_LEMMAS R52 对照表 R52-2 论证节步骤 2;连带 R53-1(门内三因子同侧收窄)、R54-2(检测域∖门域动作帧「按设计内残余分账,不进门判红」)。

**缺陷与数学论证**:

用户绑定约束(总纲「血线硬地板三件挂账·确认回写」原文,framework L371):**安全域 D_ε 上顾问/地板不动作**,违反(「安全域内频繁触发」)按 R36-3(d) 全架构回炉。此处的「安全域」= 真值域(真值三元组 λ_true·E_true·H_true ≤ η)。

记号:门域 = 用门端点(λ̄_gate 上端、E_gate 上端、H_eff_gate 偏大侧)判出的 D_ε 集;检测域 = 用检测端点(λ̄ 下端、E_LB、H_eff 偏小侧)判出的集。非窗口帧 + CI 覆盖成立时,逐因子「门端 ≥ 真值 ≥ 检测端」⇒ **门域 ⊆ 真域 ⊆ 检测域**(pointwise:门端乘积 ≥ 真乘积,故 门域成员 ⇒ 真域成员)。

1. **「绑定违例面小=保守」反号**。真实违例集 = 顾问动作发射的帧 ∩ 真域 = (门域的补集上发生动作的帧)∩ 真域 = **真域∖门域**(门域内动作被前置谓词抑制)。该集合随门域收缩而**严格增大**:
   - 门端取上端(现设计):门域 ⊆ 真域 ⇒ 真域∖门域 ≠ ∅(端点差不平凡即非空)⇒ 结构性违例非空,且是三个因子同侧收窄(R53-1)后的**最大**形态;
   - 门端取检测端:门域 = 检测域 ⊇ 真域 ⇒ 真域∖门域 = **∅**,绑定约束在机制上零违例。
   即:在「绑定约束」语义下,现取端使违例面达到两选项中的**最大**,R52-2 括号里写的「违例面小」恰好写反。计数口径同样反号:计数键 = 动作发射∧检测域,检测端门下动作只发生在检测域之外 ⇒ 计数恒 0;上端门下计数 = 检测域∖门域上动作 > 0。
2. **「两半边同保守,无 fail-open 通道」与自家步骤 1 直接矛盾**。R52-2 论证节步骤 1 白纸黑字:「两端各违一项承诺,**不存在对两消费位同时保守的单一取端**」——这正是正确的定性:检测端门 = 绑定约束零违例、但抑制面扩到检测域∖真域(真危险格被误判安全而晚触发);上端门 = 晚触发通道闭合(被抑制者必真安全)、但绑定约束结构性违例。两目标在端点不确定下严格对立,步骤 2 却宣布「与检测半边同保守」——同一论证节内先证不可能、再声称做到,是 R27-1① 治过的「一句之内混用两个比较基准」病在新面上的复发。
3. **与 R51-2 案 B 处死立据的冲突未过授权账**。R51-2 以「行为面构造性违规(用户明文禁止的形态)+ 靠自家门事后判红再回炉,与 R44-4 选① 立据方向相反」为由处死案 B;R52-2 的取端选择在正确实现中重新产生真域上的顾问动作(量级更小、机制同型),R54-2 再把这部分计数**降为「设计内残余,不进门判红」**——正是案 B 立据否定掉的「放任违例+门不判红」形态。对照 R52-1:地板半边的同等豁免走了「本批裁量,待用户追认」授权账;顾问半边经端点选择产生的豁免没有任何授权账/知情裁定,而是包在反号的「保守」标签里通过。按 framework L371 的原文,安全域内触发属「违反约束 ⇒ R36-3(d) 回炉」事项,不是可自行分账的残余。

**修法方向**(二选一,均须消掉反号论证):
- **案 A(约束硬优先)**:门端 = 检测端(λ̄ 下端、E_LB、H_eff 偏小侧)——绑定约束在机制上零违例(与 R51-1「机制性兑现用户绑定约束」的立据真正对齐);代价 = 检测域∖真域上真危险格晚触发,按 R19-1 吸收态式入成因④显式定价(该残余与「最多早花」哲学相容:被误抑制的动作对象恰是低敞口帧)。R53-1 的「同侧收窄」全文按此重推。
- **案 B(危险响应硬优先,维持现取端)**:必须走 R52-1 同款授权账——「顾问半边在真域∖门域上的结构性动作 = 工程裁量,待用户知情裁定」,并把 R54-2 的「不进门判红」改为「进门但阈值为零容差」或显式声明「绑定约束按门域近似执行」的降级留痕;R52-2 步骤 2 的「违例面小/两半边同保守」两句作废改述(打标不删史)。

## 发现 2(中)E_gate 规范式漏 g 项两读:最新修复链(R53-1/R54-1)的权威公式行不含当前金 g,而论证式含——按字面落码 = 门乘积丢最大精确观测分量 = R53-1/R54-1 要封的 fail-open 向

**位置**:IMPL_DESIGN §2.0-3 规格④ R53-1 段规范句「**E_gate** 取上端形态——Φ̂ 分量=Ī×R_剩余 上端(未揭晓面按保守回退 9…)+**cap×R_截**(…)+Σ_held r(g、Σ_held r 精确观测)」;IMPL_FIX_LEMMAS R54 对照表 R54-1 缺陷栏「E_gate=Ī×R_剩余 上端+Σ_held r 不是上界」。

**缺陷与论证**:同一修复链内 E_gate 有两个不同式:
- 规范式(设计件,实现者的落码权威):E_gate = Ī×R_剩余上端 + cap×R_截 + Σ_held r —— **无 g 项**(g 只出现在「精确观测」括注里,不是求和项);
- 论证式(R54-1 证明、R47-3 上端式):E_gate = g + Ī×R_剩余上端 + cap×R_截 + Σ_held r —— 含 g。

按规范式落码 ⇒ E_gate 系统性少 g(精确观测、P1 早期即数十金、局中可达数百金,是三元乘积中数值最大的单一分量)⇒ λ̄_gate·E_gate·H_eff_gate 系统性低估 ⇒ ≤η 更易成立 ⇒ 门域扩大 ⇒ 顾问抑制面扩大 ⇒ 真值危险格晚触发 = **fail-open**——恰是 R53-1 立项、R54-1 补项要封死的方向,经被漏掉的 g 项原样存活,且量级(≈g×λ̄_gate×H_eff_gate)远大于 R54-1 刚补的 cap×R_截 项。§6.4⑱(f)「E_gate≥E_true 上界性」静态锚能否兜住取决于锚的「真值对照」是否含 g,两处同源漏 g 则恒过。这是 R6-5「实现者遇缺输入/歧义自造方向」族在最新链上的规格两读(与 R53-2 自己引的 R11-1 先例同型:权威句必须写到不可两读)。

**修法方向**:规范句显式改为 **E_gate = g + Ī×R_剩余 上端(未揭晓面回退 9) + cap×R_截 + Σ_held r**,四项各标来源(g/Σ_held r 精确观测、余两项上界);R54 对照表缺陷栏同步勘误;⑱(f) 锚补「含 g 项」断言(锚与实现任一侧漏 g 即红)。

## 发现 3(中低)域外/损坏帧上「缺输入=触发」与绑定约束两条确认级承诺正面冲突,既无机制载体也无检测载体,且未走授权账——R52-3 自立纪律的同型违例

**位置**:IMPL_DESIGN §2.0-3 规格③(损坏/域外态=λ 顾问按触发处理,收紧动作照 R8-3/R14-3 生效)+ 规格④ R52-4 段(域外语义优先:前置谓词第一合取项假 ⇒ 谓词不成立,触发处置保持;该帧 D_ε 检测面记「不可判」**不产违例计数**)。

**缺陷与论证**:绑定约束原文无任何域外/损坏限定词。R52-4a 定谳后,域外/损坏帧上:顾问动作面 = 触发(收紧动作照发),不过 D_ε 前置门;检测面 = 「不可判」不计数。即在该帧集上,「安全域 D_ε 上顾问不动作」**既无机制载体(门被绕过)也无检测载体(不产计数)**——帧内的低敞口安全帧触发收紧动作,按 framework L371 属违反约束事项,但门与遥测都看不见。R52-3 自立纪律明言「约束无限定而执行有限定、无人对差集负责的形态禁存」,R52-1 给地板半边的小豁免建了授权账;顾问半边在域外/损坏帧集上的整段豁免只以一条工程裁量定谳滑过,冲突的两端(「缺输入=最保守触发」的 fail-closed 老纪律 vs 绑定约束)都各有确认级出处,未裁定先後。量级上现行表域外帧罕见(fixture 截表构造覆盖),故定中低;但 R23-1 已声明键结构可再扩维、A 回归触发器可重评键,域外帧集不是永久空集。

**修法方向**:二选一——①域外/损坏帧动作面降为 signal-only(只产信号+强制停报警,R8-3 的 F7/守息「保持生效」半边是结构安全阀、不属顾问动作集,可保留),绑定约束全帧域机制兑现;②维持现行为但补 R52-1 同款授权账(「域外帧顾问动作豁免=工程裁量待用户追认」)+ 检测面产「不可判」分键计数(至少可观测)。
