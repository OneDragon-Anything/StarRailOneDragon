## 命题

**非末位面(R_全局 > 0,P47 A6 全局轴)上,位面末/任意帧的持金具有严格正的未来效用;其治理纪律 = 息档纪律(即 [17]/p47 的 50 金息律族,不是新纪律)。**

## 证明结构(声明 + 两条直代推论)

本件是声明件:存在性与方向由裁定层指令钉死(禁止 0 金过位面 = 效用不可为 0),机制内容不另起证明,全部直代 P47 A6 在库结论:

- **推论 A(效用方向——两条通道)**:非末位面持金的未来效用有两条通道——
  - **息通道(下位面首息)**:出口金位 g 在下一向位面每次节点结算按 `interest(g) = min(⌊g/10⌋, cap)` 付息;「首息」= 该息流的第 1 期。机制真值:每节点收入 = 基础奖励 + 利息 + 连胜(economy.md §10.1 收入公式行,弹窗实测;样本 13→1/2X→2/3X→3 全吻合;注册表 `cw_plane_table`)。
  - **购买力通道**:出口金资助下一向位面首窗的动作能力(p10 单篇 §②:「P2 首窗流动性(局70 病理:出口身无分文 → P2-1 零响应)」;P2 开局即战斗,economy.md §10.2 P2 行)。
- **推论 B(轴)**:金跨位面继承 ⇒ 上述效用按 **P47 A6 全局轴**计(「金跨位面继承 ⇒ 息损轨迹跨位面延伸;位面内 R 口径只作下界」)。推论:B 在全局轴上,「位面末 R=0 ⟹ 机会成本恒零」形态的论证**只在末位面末战帧成立**——非末位面位面末的金在全局轴上 R>0,该前提不成立。这是 P72 §2.5 ALL IN 豁免前提的全局轴收窄来源(见 §4 消费位)。

**0 金过 P1 的缺陷定性**:豁免支(支A/ALL IN)在推论 A 的两条通道上把未来效用清零——息通道死(0 金位利息恒 0)、购买力通道死(局70 同型:「打过了也没经济通关」,[28] 病例原文)。
