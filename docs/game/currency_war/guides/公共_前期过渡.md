# 公共知识 · 前期过渡公式化打法

> **源**:B 站 UP「甘泽成谣雨成诗」必修三《前期丝滑过渡运营思路》([BV1RjUDBWE2n](https://www.bilibili.com/video/BV1RjUDBWE2n/) · 发布 **2025-11-25** · **V3.7「成为昨日的明天」**)Whisper 转录整理(2026-08-12)。同音误差:小黑塔→小野塔、加拉赫→风景霍霍附近、婷云→婷云、翁瓦克→温瓦克/五五。
> 核心:靠**高额持续伤害(DOT)**低费过渡,无需阿格莱雅也能在 A8-20 前期攒 70–80 金币启动资金,够爽完任何一套阵容的前期。

## 过渡阵容核心(2DOT)

- **桑博 + 艾斯达 = 2 持续伤害(DOT)** 为核心,向外拓展:
  - +佩拉(与桑博)= **2 贝洛伯格** → 提前期输出
  - +小黑塔(与艾斯达)= **2 银河学者** → 挖矿提发育
  - 5 人口后再上佩拉 + 娇羞/猫猫 = **2 简易** → 多拐伤害
  - 挖矿挖完 → 下小黑塔 → 换奶(加拉赫 / 霍霍)+ 娇幽凑 **2 治疗**(保 1-5 后关卡不掉人扣行动值)

## 开局禁忌与省时

- 开局 buff **不能有「进化身心」**(主力是 DOT,被 counter)。
- debuff 不能玩 → **进棋盘狂点 ESC**,在商店界面蹦出前结束当前对局,省 2 秒商店动画(快速刷开局)。
- **刷开局不掉分**,建议刷个好开局再打(呼应 `公共_核心机制.md`「拿满只需 A5 + 刷任务」)。

## 分阶段操作

- **1-1**:清备战 + 商店,只留过渡牌,其他全卖。
  - **金币 ≥4 → 不剩人口,吃 1 块利息**;**金币 <4 → 点一下升级直接到 4 级**(白嫖一次 4 级商店刷新)。
  - 能上 2 DOT + 2 学者就直接上 → 1-3 挖满第一波矿 +3 块。
  - 没有这些牌 → **绝不 D 牌**,大不了下一把(目的是攒钱,「把钱花光了跟死了没区别」)。
- **1-1 / 1-2**:不选「经济过热」、不抓猪的关随便打;抓猪以 2DOT 为先(非挖矿)。
- **装备过渡**:开局有后期阵容能合的装备**直接合**(这游戏 1+1 远大于 2)。否则:鞋给桑博去后台,花/甲给中间角色,星星刀/钻头给艾斯达,电池给娇秋。
- **1-2**:自动升 5 人口。矿挖完 → 下小黑塔 → 上加拉赫/霍霍抽 2 治疗(防狂化战斗官扣行动值)。
  - **1 费卡**:不卡利息就顺手升 2 星(卖了不亏钱)。
  - **2 费卡**:不是等会要玩的就不升 2。

## ★怪物词条 × DOT 互动(词条系统早期信号)

- **大幅增强前期 2DOT 输出**(怪频动 → DOT 多触发):`忍无可忍` / `应激反应` / `同步行动` / `一鼓作气`。
- **前期即使凑足 2DOT 仍可能缺伤害**:`随从强化` / `第一位面强化` / 选了 `彩虹投资策略`。
- → 词条识别可指导是否走 DOT 过渡(词条好 → DOT 过渡更稳)。

## 造假阵容技巧(通用)

商店买**婷云** → 备战席 → 放前台 → 装风套 + 翁瓦克 → 大招冲自己拉条全队 → 大幅提高全队出手次数。仙洲/三星洲过渡好用,**所有阵容通用**。

## 节奏

一般 **1-6 / 1-7 起 2DOT 就连胜不了**了;只要到 boss 关前能攒 **~80 金币**,无论是速升人口还是直接开始 D 牌都非常舒服。
