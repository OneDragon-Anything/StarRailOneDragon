## 2. 命题

**等待成本的状态函数分解(§R.3 路径)**:

```
W(s) = W_flow(s) + W_floor(s) + W_ext(s)        s = (g, P, R)

W_flow(P) = Δp(P桶) × Δflow_reg(P桶)                     —— 小项,带内 ≈0-0.5 金/轮
    Δp(P桶)   = E[胜率 | g>50, P桶] − E[胜率 | g≤50, P桶]  (囤金轮 vs 非囤金轮,桶内对照)
    Δflow_reg = E_rounds[ streak_gold(连胜级) − LOSS_GOLD_BY_NODE[节点] | P桶 ]
                (注册表锚:胜轮连胜金 vs 败轮底金的纯金流差;基础金/息/事件金两侧对消)

W_floor(s) = λ_death(P桶, R) × ( g + Φ(P桶, R) )          —— 主通道,存量金 g 为核心项
    λ_death(P桶, R) = P(距局终 ≤ 视界 | 处于 P桶)          (死亡危险率;hp 不入自变量,§R.3)
    Φ(P桶, R)      = E[局终金 − g | s]                     (未来纯金流净额:后续收支累加减当轮存量)
    # v3 口径注:λ_death 是「视界(3 轮)累积危险率」⇒ W_floor 值 = 整个 3 轮窗口的
    # 总敞口,不是每轮边际成本(整窗归因到每轮会夸大约视界倍 ≈3×,§5-11);
    # R=距局终是事后量(决策时不可观测),λ(P,R) 只作状态描述注记(§3-B3/§5-10)

W_ext(s) ≥ 0:下界外成本(商店期权/对手截胡),只声明不定量(§5)
```

推论:

1. **(量级分离,W_flow 是小项)** W_flow 带内 0-0.5 金/轮、多桶 CI 触零(§4-A)——按 §R.1 如实标注:**连胜金通道是二阶小项,单通道不支撑任何转化判据**;W 的量级由 W_floor 决定;
2. **(存量金核心)** 在决策相关的濒死带(p8-12/p13+ 桶,λ_death 高),局终销毁量中**存量金占比 63-78%**(§4-B)——「等待的代价」首先是自己手里囤的金随死亡清零,未来流是次级成分;低战力早期桶存量占比低(34%)是因 g 尚小,不构成对核心地位的反驳(彼时 λ≈0,W_floor 本身≈0);
3. **(视界二分,§R.4)** W 的行为含义按视界分两段:λ≈0 段(早期轮,**实证论据见 §4-B-3:桶构成 + 桶级 λ 直读**——v2 曾引「距终>6 轮 λ3=0.000」,该量为构造性恒真,v3 已弃用)W≈W_flow≈二阶小量,**守息>转化的既有结论不翻转**;λ>0 段(濒死带)W_floor 主导,转化优先;
4. **(连胜置零底线 = 超额收益隔离)** W_flow 只计当轮连胜表差,不计连胜链未来成长期权与断连胜重爬成本——上行通道的**下界注记**形态;连胜成长价值若入账只增 W,不翻转方向;
5. **(W 是状态函数,禁全局常数)** v1「W=2.5 金/轮」全局常数形态废止(§R.2,作废禁引);下游 EV 比较按 (P桶, R) 状态取值;W 只作比较项、不作闸门(公理)。
