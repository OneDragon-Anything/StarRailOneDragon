# 货币战争-装备图鉴

## 画面简介

全量装备的图鉴网格 + 右侧详情面板画面——装备效果文本的权威读数位：数据银行主页点「装备图鉴」入口卡进入。左侧网格 7 列装备卡（图标+名字，滚动推进），右侧详情面板显示名称/类别/前后台强度/效果全文/适配角色/收集状态。

## 建档 area 说明

| area | 游戏语义 | 交互效果 |
| --- | --- | --- |
| 标题-装备图鉴 | 画面标题「装备图鉴」（身份锚，单文本即精准） | 纯显示 |
| 分类计数条 | 行首分类计数「分类名 [n/m]」（当前分类与收集进度） | 纯显示 |
| 区域-分类页签行 | 下方页签行切分类（图形按钮，OCR 读不出，看图点） | 点击切换装备分类 |
| 区域-左侧网格名带 | 左侧装备网格整体带（7 列装备卡） | 点某件装备 → 右侧详情面板切到该装备 |
| 区域-右侧详情面板 | 详情面板：名称/类别/前台强度/后台强度/效果全文/适配角色/收集状态（如「尚未收集」） | 纯显示 |
| （待建档）顶部圆形图鉴切换图标 | 顶部一排圆形图标（疑为图鉴互切导航） | 点前先看图确认落点 |
| （待建档）扩充倒计时 | 标题下方倒计时（如「96天10小时」）；动态值勿当画面锚 | 纯显示 |

## 操作

| 目标 | 用什么 | 参数（从哪来、怎么传） | 效果与确认 | 注意 |
| --- | --- | --- | --- | --- |
| 进入本画面 | MCP `click` | 数据银行主页「入口-装备图鉴」area 中心 | 进装备图鉴 | — |
| 读某件装备 | MCP `click` | 网格内该装备卡坐标（自己读图定位，「区域-左侧网格名带」内） | 右侧详情面板切到该装备 | 网格靠滚动推进 |
| 切分类 | MCP `click` | 「区域-分类页签行」内目标分类图形按钮（看图点） | 网格切到该分类、分类计数条更新 | 图形按钮 OCR 读不出 |
| 滚动网格 | MCP `drag` | 网格内拖拽（手指上滑 = 向列表深处翻页） | 网格翻页 | — |
| 返回上级 | MCP 键盘 / `click` | ESC（历史实录：ESC×2 经数据银行主页回备战）；右上返回箭头行为未实测 | 回上级 | 右上返回箭头未实测，别默认它可用 |
