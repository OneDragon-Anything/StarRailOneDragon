# ADR-0613 — T-171 批序 1:希儿系形态端口 OR 语义(成型判据按文档口径放宽)

## 背景

设计方案(attacks/t171_xierie_criteria/设计方案.md)与命题(同目录 命题_批序1_形态端口OR.md,方案审放行附 5 低项 F1-F5)定批序 2→1→3;批序 2(支持度端口降档)已落地(ADR-0608)。本 ADR 记录批序 1(形态端口)的决策本体。

病灶 = `pair_target_comp`(kernel/cw_intention.py)把已锁体系对物化为配方伪 comp 时,希儿系对的 form_tiers 借量子配方完全体档(cw_recipe.py:53 `{'量子同频': 3, '贝洛伯格': 2}`),成型判据塌成 AND 全档且无 carry 合取支;文档口径 =「**希儿在场 ∧ (量子同频≥2 ∨ 贝洛伯格≥2),不设完全体门槛**」(transition_combos.md:27 定义表行,用户口述最高权威;combo_methodology.md:133「凑到任一=成型」/:138「希儿到手 ≠ 希儿线成型」/:143「放大器不需要最大档,有就行」)。三轴超重:①OR 塌成 AND;②量子腿档 3(应 2);③缺「希儿在场」合取支。模拟证据:批#8 锁线希儿系对 form_ok 1/11 vs 对照 81/89;本批改前 n100 复证 1/3 vs 89/97(§验收)。

## 决策

**Comp 双字段 + 虚拟腿折法 + 希儿对重构(单一源契约保持)**:

1. `Comp` 增两个缺省空字段:`or_legs: list[tuple[str, int]]`(析取档组,组内任一 (羁绊, 档) 达成即该组满)与 `required_deployed: tuple[str, ...]`(carry 在板条件)。缺省空 = 行为不变(全 COMP_LIBRARY 与非希儿配方对产物逐字节不变)。
2. `form_progress`(kernel/cw_comps.py,成型判定单一源)折法:OR 组折叠为**一条虚拟腿**,腿值 = 组内各腿进度 **max**(取最好腿非均值——「凑到任一即成型」的进度语义;换最好腿只单调抬升无重置);carry 条件逐名折 **0/1 虚拟腿**(在板=1;state 无 deployed 视图的轻量假想面板按 0 计=保守向)。**fp=1.0 ⟺ 成型谓词**「form_tiers 全档 ∧ OR 组任一满 ∧ carry 全在板」的单一源契约保持,四观测面(生产镜像 flow / sim 发射帧镜像 / armed 闸 readiness_launch_decision / [28] 出口读数)全经 `readiness_form_ok`→`form_progress` 一条链,零第二判定。字段经 `getattr` 缺省空读(真实 Comp 恒有;测试鸭型桩/旧序列化载体按「无 OR/carry」同值解释)。
3. `pair_target_comp` 希儿系对分支重构:form_tiers 只放**他体系档**(桥池同源派生);放大器两腿挂 `or_legs = SEELE_OR_LEGS = (('量子同频', 2), ('贝洛伯格', 2))`(模块常量单一源,零新参数:档位 = transition_combos.md:27/103 文档定义行);carry 挂 `required_deployed = ('希儿',)`。跨体系 AND 保留(他体系档仍是 AND 腿,OR 只辖放大器组,防半对冒充);armed 质量合取(ADR-0570)在其上二次把关不变。
4. 全仓 form_ok 内联位收口:`cw_evolution._comp_formed`(唯一绕过单一源的自写 `min(board,tier)≥tier` 型 comp 成型判定)改委托 `readiness_form_ok`;空 form_tiers(反甲白厄类)保留「无档=视同已成型」注册表惯例短路(与 form_progress 空档 0.0 约定不同,不委托防翻面)。grep 复核:其余 `board≥tier` 型站点均为逐羁绊计数/距离折算/战斗校准层(engines_count 族、line_distance、shop_supply core 读数),非 comp 成型谓词,不在取代面。
5. 两端口切分(机械可检验,批序 2 ADR-0608 坐标系不触):形态端口读**板面羁绊计数**(board→form_progress),支持度端口读 **owned 去重成员计数**(`_seele_system_support`,512-555 区);form 链禁出现支持度消费——测试锁 `TestPortSeparation` 以函数源码 grep 断言钉死。「单卡不算开线」(combo_methodology.md:138)语义两端口各自独立投影:支持度 0.5<1.0 不即锁(批 2 已落)、形态端零放大器腿 fp<1.0 不成型(本批)。

**取代记录(F5)**:本决策取代 ADR-0459 Decision 节伪 comp 口径中「无桥条目(希儿系组合)逐体系取桥池档+量子配方档」条款(借完全体档正是 0459 的单一源决定);取代先例 = ADR-0608 对 ADR-0519 post-state 条款。0459 其余内容(写端单点物化/桥池取档/level_plan 不设)不变;cw_recipe 量子配方注册表保留(其「框架单独成型档」辖域不变,生产消费计数 1→0 如实申报,消费位即本批删除的调用)。

**零新参数声明**:输入数 = 文档档位(量 2/贝 2,定义表行)+ 注册表结构(希儿双标签计入两池,CHARACTERS['希儿'] 行)+ 桥池既有档。无拟合常数。候玩家确认项不阻塞:①量 2 vs 量 3(combo_methodology.md:133/170 写量 3)——主窗口 T=9 两读法完成率差 ≤0.03、与 P38 闭式 ±8pp 误差带同量级,数值不可分辨**限主窗口**;残局域 T=4 模型可分辨(表观差 0.04~0.18)但读法归属是语义问题(方案审 F2 限定),确认后改 `SEELE_OR_LEGS` 单一源常量即全链生效;②放大器计数口径(希儿计入两池=主口径,机制真值可实机一帧面板读数收口)——确认结果同落该常量。

## 方案审 5 低项随批吸收(F1-F5)

- **F1(P38 A2 不交性缺席申报)**:命题 §5 积形式联合近似的两腿共享成员(桑博=持续伤害∩贝池、符玄=仙舟∩量池、丹恒·饮月=仙舟∩列车),联合近似落在 A2 合格集不交性失效域,误差方向未声明(量级预期小)。承重结论不受影响:嵌套由事件包含独立保证、不经积形式,同对两判据共享他体系因子。
- **F2(表述限定)**:「数值不可分辨」限定主窗口 T=9(见上「零新参数声明」节);残局域改述为「模型可分辨,读法归属候玩家」。
- **F3(条件限定词)**:「文档口径完成率 ≥ 代码口径」的包含论证**条件于希儿已部署**;全域上轴③是新增合取支(收紧面)非纯放宽——本批预期含「无希儿不再 form_ok」型翻转帧,属轴③修复的正确行为。
- **F4(归因降格)**:T=4 与 R2 发表表的格值差异归因(放大器池是否含希儿/轮序起点)降格为「候选来源,未定谳」(方向检验存在反向格:DOT+希儿 发表 0.42 < 复算 0.51);绝对值本就不作裁决。
- **F5(取代记录)**:见上「取代记录」节。
- **批外随批件(C1,前批遗留)**:支持度公式 docstring 补量 2/量 3 张力挂账指针(`_seele_system_support` docstring「挂账指针」条),与 `SEELE_OR_LEGS` 单一源互指,禁两端口各自为政。

## 中间态申报(F9 延续)

- 批 2→1 窗口随本批落地关闭;**批 1→批 3 窗口开启**(前置 = T-166 R2 冻结条款):OR 口径使 form_ok 更早达成,而「form_ok 达成即冻结目标至位面末」尚未落地——该窗口内 pivot/切对摇摆可能压低 form_ok 保持读数,验收判读须按此分层,禁把接缝缺位误读为「OR 修了没用」。本批 n100 实测残留失败局(见 §验收 seed 1588:锁定仅 5 轮的晚换入局)正属该形态,候选下钻载体 = 设计方案 §4.3 换入侧可行性门 + 批 3 冻结接缝,均不在本批任务书辖域,未随批落码。
- 换入侧可行性门(设计 §4.3)与 replay-diff 零漂移自检未含在本批任务书实施清单,留待派单方裁量;本批 A/B 以同 seed 配对批承载零漂移观察(非希儿对凑齐率不劣化实测 §验收)。
- **已知折算残差申报(随门批处置)**:`line_distance`/`e_rounds`(cw_line_switch)只读 comp.form_tiers——本批后希儿对伪 comp 的 form_tiers 只剩他体系档,对希儿系挑战者的期望距离折算系统性漏计 carry+放大器件(方案 §4.3 F2 已预见的形态;改前借完全体档为 量3∧贝2 AND 账,同为错折、方向相反)。正确折算(投影 comp + carry 距离加项)随换入门批落地;shop_supply 两个 `<=0` 消费位(cw_line_switch 备选线供给门/proof 换线供给门)均只迭代 COMP_LIBRARY 候选、不吃伪 comp,本批零波及(已核)。

## 验收

**行为锁(测试仓 test_cw_t171_form_or.py,16 条全绿;变异红证亲测)**:单帧锁按设计方案 §6.3-1/2/3——①伪 comp 构造(form_tiers 只含他体系档 + or_legs + required_deployed;非希儿对逐字段零漂移锚);②form_ok 四象限连同 fp 值(希儿+量2+他档满→True fp=1.0;量1贝1→False fp=5/6;放大器齐希儿缺席→False fp=2/3;他档未达即便 OR 满→False);③半成品/换最好腿单调无重置 + fp=1.0⟺form_ok 全格不变式 + 单卡不算开线保持锁(希儿单卡 fp=2/3)+ 条件域嵌套包含网格锁(旧 AND ⟹ 新 OR,严格反向格在)+ 两端口切分机械锁。

## Considered Options

1. **Comp 双字段 + 虚拟腿折法(本策)**——单一源契约保持,四观测面自动跟随,零状态纯派生(方案 §4.1 定谳)。
2. readiness_form_ok 正文加合取——四消费面绕过 form_progress 者不可见,双源风险,否决。
3. 动态选腿(按进度把量/贝之一写进 form_tiers)——换腿重置进度、破坏冻结与遥测连续性、引入隐式状态,否决。
4. 仅把量子腿降档为 2 仍留 AND——只修轴②,轴①③不动,半截修,否决。
5. 内联位不动(_comp_formed 留旧式)——留第二份 AND 判定,registry comp 未来携带 OR/carry 字段时静默分歧,违单一源,否决(委托空档短路保反甲白厄语义)。
