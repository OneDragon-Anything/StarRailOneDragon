# BWIKI·光锥晋阶材料页

> 官方 wiki 光锥页实证无结构化突破材料组件(只有等级属性模板);BWIKI 逐光锥页的分段表与实机对账吻合(实机锚:惊魂夜 60+70 级段累计 永恒之花 15/永寿荣枝 14)。需要光锥晋阶材料明细时以 BWIKI 为源。固化后的日常查询走 MCP `cone_lookup(光锥名, with_ascension=true)`。

## 页面与口径

- 逐光锥页:`https://wiki.biligame.com/sr/<光锥中文名>`(页面名 = 官方中文名,URL 编码);页内晋阶材料表解析为 `{段名: {材料: 数量}}`,无晋阶表的页面 = 该页无此数据。
- 段名口径:「Y级」= 突破段、「X～Y级」= 经验段(以稀薄以太计,游戏内界面按所持书籍折算显示)。
- **「光锥晋阶材料一览」聚合页是旧口径无数量,勿与逐光锥页分段表混用**。

## 抓取坑

- BWIKI 有边缘防护,HTTP 567(临时封禁)/5xx 常见——退避重试约 3 次即过;别把 567 当「页面不存在」。
