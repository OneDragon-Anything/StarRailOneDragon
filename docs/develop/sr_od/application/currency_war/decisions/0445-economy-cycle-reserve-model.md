## Context(为什么)

用户裁决(最高权威):金只有两个正当去处——利息线以内的储备、即刻换成战力;**无论什么血量都不应持有超过储备需要的金**。现行政策是「地板制」:SPEND 相位只有花后下限,对「该不该花、花多少」零约束——金 58→80 在 SPEND 姿态下是完全合法轨迹;FLIP 泄息通道只辖「低血∧高金∧未成型」的危局交集(触发面 9%),与已成型 SPEND 帧互为死钱盲区;P2 收入 13-19/轮 > 刷新帽 12,死时带金实测 85-160(W151 四局)、125@hp1 存息至死(⑯ 局)。数学根:溢余段(g≥50)每金边际利息恒 0(息帽截断),持有期望损益=0,而任一通道转化的收益 ≥0(EV 过滤保证)——**强制转化弱占优,参数无关**(依赖声明:该「≥0」继承 EV 过滤口径,W481 A-1 把单位金战力转化率升格为共同主判据兜住该依赖)。

## Decision(逐条)

1. **储备制**:任何时刻金 g 与储备上限 R* 的差 `(g−R*)+` 是负有转化义务的死钱。`R* = interest_floor(50) + 窗口(≤3 轮)内排程升级费`;窗口 h=min(3, 到位面末节点轮数);排程判据=DP 姿态 level_up;升级费逐帧现读(OCR 单击价优先)。息线以内持有弱占优(0.1/轮 vs 战力链 ≤0.012,ADR-0443 同一笔账反向使用)——义务只在溢余段激活,**不新增破息例外**。
2. **义务公式**:`义务 = max(既有臂义务, min((g−R*)+, C_t))`;`C_t = 升级计划费 + 非期权可买账 + 刷价×min(6, DP 授权刷数)`。f=min 非 f=r 的理由:义务不能废 EV 过滤,容量外余量结转并进评估罚项。**A-1 修复**:C_t 排除未跨档期权件(formation_gold_account 的 d_rem 分支同型——W469 已实测「按兑现价卖期权」死法);**A-2 修复**:bench 槽机会成本入账(满槽时非合成件不计容量)。
3. **落点=谓词替换(非 DP 罚项)**:FLIP 简化为溢余判定(ADR-0426 增补 D),release 臂预算改义务基;DP 值函数不动(GOLD_MAX=110 截断盲区如实挂账——义务压力只经 release 通道传导)。选型依据=W481 A-3:谓词替换结构已在、行为面可单帧锁;DP 罚项要动 solve、引入二阶行为风险。
4. **g≥0 硬钳制**:authorize_release_refresh 增加金账户非负最后防线(W477 披露的执行层透支修复)。
5. **守卫重设计(§3.3)**:废「出口金不劣」存量守卫(与强制花钱方向相反),立流量守卫——溢余滞留率下降、义务帧兑现率分布、息基守卫收窄只辖 g≤R* 常态帧;出口金降级为披露面。**P2 刷新容量 12<收入 13-19 的扩容评估=披露面**,本批不改刷新帽。
6. **生命周期**:不设生产开关(行为输入全部已标定,溢余弱占优是已证结论,无「待就绪输入」);被吞并的 `release_enabled`/`release_spend_gate_enabled` 按第 4 态清理(删字段+消费门恒接线+锁面重推,ADR-0426 增补 D)。

## Considered Options

- ①谓词替换(选)②DP 值函数溢余罚项(治本但动 solve+二阶风险,挂账为义务通道不足时的退化路径,设计 §5 已声明)③维持地板制+逐件打补丁(四次同根实证否决)。
- C_t 含/不含期权件:不含(W481 A-1/A-2;含=义务泵把死钱流向期权,W469 复演且流量守卫全绿)。
