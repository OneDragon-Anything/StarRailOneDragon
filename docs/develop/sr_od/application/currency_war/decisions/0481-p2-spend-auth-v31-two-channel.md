# ADR-0481: 位面 2 支出授权 v3.1 重挂(W762 判定②后调判据;两通道+预算带对齐+末窗收窄)

> **版本界碑(2026-09-04 ADR 存量 review;对象属 decision_v2 栈或旧策略代,现行权威 = strategy-docs/flow/proofs)**:本 ADR 裁决的对象已亡——decision/ 整包(含 decision_v2 各模块)已随 b94e9cfb 删除,现行唯一策略载体 = mandate_v1(kernel 吸收下沉判据)。本件仅存史料价值(记录设计 why/翻案史);**文内一切「后续应做 X/须换成 Y」类前瞻指令一律视为已亡,勿执行**。

## 背景

ADR-0480 落码的位面 2 支出授权按预注册协议 v2 完成 A/B(W762):主判据
M1-M3 全不达(M1 配对差 −0.4pp/p=0.90、M2 死时金>80 局型 249→248、
M3 +0.5pp),判定②不达标不开臂。机制归因给出精确修正方向——**开关
生效而覆盖不足**:仅 296/530 局出现过授权帧;248 个死时金>80 死亡局
中死前 3 轮内有授权帧的仅 38 局(15.3%);金堆积发生在授权谓词不触发
的帧(T1 锁定∧T2 形态缺口合取、末窗/接管帧/覆盖纪律态豁免系统性排除
死亡窗)。另 G1-A 破息反降(0.93%→0.14%)=常授权层预算带比既有息账
门更严,违反「只开门不收门」。

W757 设计件按归因升 **v3**(两通道/末窗收窄/预算带对齐/拦断面普查),
再经 W758-v3 攻击复核修订为 **v3.1**(M0a/M0b 拆分、bench 保留槽、
hoard 投影失败帧、[31]② 相容声明、双通道合并语义+血预算门层归属机械
化,5 条修正全采纳)。本批 = v3.1 落码 + 开关按生命周期「调判据重挂第
1 态」。

## 决策

1. **两通道触发结构(v3;覆盖修复)**:
   - 通道 A 定向授权(v2 语义保留):T1∧T2∧T4;T3 升格加急层;
   - **通道 B 止血授权(新)**:T3∧T4∧帧资格即触发,与 T1 锁定位/
     T2 形态缺口解耦——死亡局几乎恒满足「血线恶化∧溢余在手」,被拦
     的恰是锁定前提与形态缺口判据([18] 响应义务的直译);支出方向取
     既有机制现成输出,只消费方向不生产方向(与换线摇摆域「决策权 vs
     出手权」切分);
   - 方向梯级(v3.1):hoard 集(投影成功∧非空)→ 桥池
     (`cw_bridge_pool.BRIDGE_POOL_P2` 现成输出)→ [31]① 空窗期语义
     (过渡体系键非空=非纯散件,排序归评分层);**投影失败帧跳 hoard
     级,禁用 prep_brain 整库保守域作方向源**(整库含散件,与「纯散件
     恒不授权」直接冲突);**bench 保留槽**:通道 B 买入后备战席保
     ≥1 空槽,不足则本帧授权降额(授权通道只开门不发射动作);「先卖
     可弃垫层件腾槽再买」的腾位腿由既有补偿趟 S6 承接——W766 注入批
     附带发现(核心卡保证上架成交率仅 50-70%,无授权基线)核查后,
     `remediation` 的 `remedy_min_score` 分数门对授权帧核心必买候选
     开豁免(`_p2_auth_mustbuy_rescue`:负分核心卡满栏帧不再被补偿层
     二次拒;其余守卫照旧,卖序仍是可弃垫层件);
   - 通道 B 的 D 消费 [31]②「保血急救」合法用途(T3 触发即语境锚);
     评分不动即凑数羁绊 D 禁令的机械化(P12 j=0 负例保持);
   - 双通道同帧合并语义:谓词取或、预算同值交集(同一放宽档)、方向
     同源、动作去重(单门单裁决,结构性成立)。
2. **预算带对齐(「只开门不收门」;G1-A 反降修正)**:常授权层废除
   独立地板与「贴线带证成前保守不买」子句(比既有 [22]④ 门更严的收
   门),判定语义=「与既有门同判」——授权臂只做额外放行,从不拒绝;
   加急层(通道 A 加急/通道 B 共档)破息至保留金占位下限。P25 分带
   核验数学义务保留。
3. **末窗豁免收窄**:v2 的 r7/boss 窗整体豁免废除,豁免统一归分配器
   接管帧谓词(`alloc_domain` 现值)——v6 active 帧授权禁出手不变
   (锁⑨),非接管末窗帧通道 B 可达(锁⑦改写);覆盖纪律态独立豁免
   (应急/war 模式)随两通道重构撤销。
4. **economy 存息姿态让位序 + 血预算门层归属机械化(v3.1)**:授权帧
   内授权出手权优先于存息结论(帧资格不再要求 economy 模式);血预算
   门(ADR-0448 停升级线/ADR-0451 刷新停付降格)机械定为 **discipline
   层谓词,不受姿态让位条款影响**(arbiter 刷新收尾的停付检查先于一切
   授权臂,结构保持)。
5. **拦断面普查(实施批义务;协议 M0 分层唯一数据源)**:金堆积候选帧
   逐帧拦截原因枚举(`p2_spend_auth_intercept`:t1_locked/t2_form/
   no_t3/t4_gold/v6_active/authorized/hoard_invalid)经 decide_prep
   写 session 披露键,telemetry 决策迹新字段 `sess_p2_auth_intercept`
   接出;纯观测零决策行为。注:no_t3 分支在两通道取或结构下不可达
   (通道 A 不需要 T3),保留枚举兼容协议词汇表。
6. **开关生命周期:v3 判据重挂第 1 态**(准入理由=通道 B 行为未经
   A/B 验证+T3/保留金占位+P25 Δp 未标定)。**开臂判据=协议 V3 双钥匙
   缺一不开**:①P25 证成(采集死线自本批落码重计:60 局实机或 1 次
   sim 注入批先到);②协议 V3(`SIM_AB_PREREGISTRATION_V3.md`)主判据
   达标且护栏全绿——M0a 判定触达≥70% ∧ M0b 出手有效性≥50% ∧ M1-M3,
   护栏 G1-G6(G1-A 双向对称);三分支归因写死(M0a 败/M0b 败→本设计
   层,M0 双达而 M1-M3 败→上游病灶)。默认关=零行为变更;验证不过的
   出口=删码留 ADR(第 4 态),禁悬置默认关。

## Considered Options

- **保留 v2 单通道调占位值**(否决):W762 归因证明病灶在覆盖不在
  预算数值——死亡窗被合取+豁免系统性排除,调阈值不改变可达性。
- **删码留 ADR(第 4 态)**(否决):归因给出可修的精确方向(通道 B
  对症 15.3%→覆盖缺口),骨架护栏(G2/G3/G4/G6)全绿,设计未被判死。
- **授权通道内实现卖出腾槽**(否决,战术权衡):授权=门与预算语义,
  发射卖出动作越辖;保留槽不足走降额分支(设计明示出口),卖出腾槽
  归既有补偿/演进机制。若 A/B 的 M0b 失败归因到保留槽过严,再回设计
  层评估。
- **采纳**:两通道+对齐+收窄+普查(本 ADR 决策 1-6)。
