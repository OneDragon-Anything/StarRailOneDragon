# ADR-0409 M-A 定向 D 牌授权窗(W249 诊断修法:刷新维的搜索成本授权)

- 日期:2026-08-27
- 状态:accepted(默认关;A/B 数字见 Consequences)
- 谱系:W249 双核心可达性诊断 §4 修法 M-A;ADR-0405(C 项,copy 授权,
  同族同窗)先例;设计件 08 §4.2 承接门家族
- 任务:W252

## Context(为什么)

W249 n=141 进场局四假设检验裁决:**双核心(core2≥2)不可达的主导约束
=「特定名的有效刷新吞吐不足」的组合,其中最病态的成分是——策略从不
支付搜索成本**(H3):失败局 P1 出口金中位 ~30(够付),仅 13.5% 局
金≤10,但 P1 全程每局平均只刷 **0.44 次** RefreshShop;追名(最接近
2★ 的目标名)见到即买的执行没有问题(见即购率 72-78%),问题在曝光
本身太稀(~2.6 次/局/名)而定向刷新分配为零 ⇒ peak 恒卡死在 2 张
(127/141),第二颗 2★ 的收集线刚起步窗口就关闭。关键算术:peak=2 时
补最后一跳只需期望 ~6-17 次定点刷新(E 随费用档,超几何 DP 单一源)
≈ 13-35 金,**恰落在中位 30 金余量的可支付尾部窗口内**,只是策略从不
这么花。

买牌维的两条授权(candidates 生成放行 + arbiter 非正分门 copy 定向
放行,ADR-0405)已通,但它们只提高「第三张见面必买」的面——解决不了
「见不到」。刷新维需要一个显式的、有界的搜索预算授权。

## Decision

**flag:`handoff_refresh_directed=False` 默认关;与
`handoff_gate_enabled`/`handoff_boss_project` 三 flag 正交**(只在门开
路径内被消费,单独开=零行为,W242 C 项/ADR-0403 投影同式)。

**授权判据三条件缺一即零**(`handoff.directed_refresh_budget`,0=不授权):

1. flag 开;
2. `handoff_gate_gap > 0`(缺口单一源复用,P1 末窗 r≥8 才会 >0);
3. **追名 peak≥2**:锁定采购目标名集(`_target_names`,candidates 层
   单一源)内某名的全场在手副本(star 加权,`star_weighted_copies`)
   ∈ [2,3) ——距 3合1 只差最后一张。实测口径修正(W252 探针,n=30):
   comp 核心名(`_core_names`)peak=2 在末窗决策帧近乎不出现(4/210),
   而目标件集 132/210——「追名」的本体是正在收集的锁定线件,不是
   comp 核心。

**预算额 = min(directed_refresh_per_round=2, directed_refresh_game_cap−
已耗)(=6)**。两常量 registry 单一源;初值=W249 白盒估算(每合资格轮
≤2 次、每局 ≤6 次 ≈ 覆盖一颗 2★ 的第二跳;量够不够看 AB 分布再调,
非本批标的)。

**挂载点论证(为什么是 arbiter 刷新收尾,不是评分/scoring)**:

- V_D 批口径(W126/ADR-0349)对负 EV 刷新恒拒是**正确的经济账**——
  W249 说的是「这个尾窗里该有一笔例外授权」,不是「把 D 的账改到恒
  正」(那等于废除 P5 检验点①)。授权=结构门的定向豁免+独立额度,
  不改分数。
- 候选能到达收尾块的前提是越过**顶层非正分门**(arbiter 主循环 L528)。
  该门原本直接丢负分候选,首版挂在收尾块的 M-A 分支永远收不到候选
  (实测 sim 全程 dir_refresh=0 后探针定位)——所以豁免必须在顶层门
  与 `_copy_ok` 同位(W242 先例),消耗与计数在收尾块逐笔扣。
- 收尾处 M-A 授权面**取代两道息纪律门**(gold_floor 的 HOARD 攒息拒 /
  interest_rule 的 EV≤0 拒):这两道正是「从不支付搜索成本」的纪律
  载体,不清除它们预算就不流动。代价兜底两道仍在:①绝对可负担性下限
  (花后 ≥ boss_floor=10,P1 出口金生存边际);②局级/轮级次数封顶
  (每次照付刷价,simulate 真值扣金——授权给的是「花的许可」,不是
  免费刷新)。

### 防双计:四件互斥边界(买牌三件各辖买维,M-A 辖刷新维)

| 通道 | 辖域 | 授权载体 | registry 数值 |
|---|---|---|---|
| W232 filler_star(方案A)/pair_copy(方案B) | 全轮域产星买入 | 评分期权分/r410 方向门豁免 | filler_star_unit |
| W227 缺口项(gate 家族 a/b) | 末窗承接买入 | interest_rule EV 缺口项 | handoff_ev_gap_bonus |
| W242 C 项 | 末窗同名副本**买**入 | candidates 放行 + 非正分门 'copy' 放行 | (零新增,随 gap) |
| **M-A(本批)** | **末窗有界 RefreshShop** | 结构门豁免 + 预算次数额度 | per_round/game_cap(**次数,非分数**) |

互斥保证:同一动作只有一条授权来源——BuyCard 的任何分支不消费 M-A
预算;RefreshShop 若走 V_D 正分路径则预算计数不动(auth 不带
dir_refresh);M-A 放行的刷新不再过息两道门(不存在叠加);regression
锁钉死 registry 无 M-A 分数 bonus 字段。

**域声明**:plane==1 即辖,应急态(hp≤25)**不排除**——低 hp 出口局
恰是 W249 病灶人群,[27] 星级投资的危机授权先例(ADR-0302 危机买偏置)
同族,且金代价由可负担性下限+次数封顶兜住。r8(奖励节点)是主窗;
r9 直面 boss 轮 gap 依 gate 定义仍可为正但 boss_floor 地板语义与
[18] ALL IN 由剩余窗口吸收(边界同 ADR-0405 表末行)。

### Considered Options(取舍)

| 选项 | 裁决 | 理由 |
|---|---|---|
| V_D 公式加「gap 加分项」让负账翻正 | 否 | 打破 P5 经济账单一性,等于全实例重标定;W249 病灶是「分配为零」不是「EVP 错」——例外的显式额度比污染总账精确 |
| 预算常量放 filters/discipline | 否 | 承接门家族常量已全部在 registry(W238/W242 先例),散落=双源 |
| 只辖 boss 窗外(r8 专属)/排除应急态 | 否 | r9 差最后一张同样成立;应急态是病灶人群主体(W249 失败局多 hp 低),排除它修不了主导人群 |
| 金额上限(金预算)替代次数上限 | 否 | 次数更贴「吞吐」病灶本体(W249 H4 时间维度);金额对刷价波动敏感,等价换算 under 不确定性引入第二个自由度 |

## Consequences

- **默认关**:A/B outcome 与主指标未达解锁线(ADR-0400/0402/0403/0405
  四连先例一致口径:部分正方向不足以裁默认开),通道保留待复验。
- **三臂 A/B**(n=300,v11 池 7af81977 冻结导出件 seeds 0-299 配对,
  planes=2,`.debug/temp/currency_war/w252_ma_directed_refresh/
  ab_summary.json`;臂=off 全关 / full 三 flag 无 M-A / ma 全开):

  | 指标 | off | full(C 项现状) | ma(full+M-A) |
  |---|---|---|---|
  | star≥2 率(handoff core2≥2,进场分母) | 0.33% | 0.67% | **0.67%** |
  | core2≥1 率(进场局) | 2.11% | 10.18% | **14.13%**(+3.95pp) |
  | merges 总数(avg/局) | 60(0.200) | 59(0.197) | **87(0.290,+47%)** |
  | 有 merge 局 | 53 | 48 | **72** |
  | P2 hp0 率 | 89.12% | 89.82% | **88.69%**(−1.13pp) |
  | P2 进场率 | 95.00% | 95.00% | 94.33% |
  | avg P2 存活轮 | 4.45 | 4.31 | 4.52 |
  | avg 终局 hp | 1.79 | 1.54 | 1.73 |
  - 配对(ma vs full,同 seed):merges Δsum=+28;hp0 翻转 22 好 /
    17 坏;star2 flip 1上/1下;进场率 −4 局。
  - 行为面:M-A 授权刷新 440 次/300 局(n=100 补采臂数据同量级),
    触达面真实存在。
  - 读法:merges/hp0/存活轮方向为正且量级超出配对噪声带(hp0 22:17、
    merges +47%),star≥2(core2≥2)仍近零——预算 6 次/局的量级

    的独立决策(需先核金代价曲线),本批不解锁默认开。

  ma 对照)**:M-A 授权刷新 159 次/100 局(1.59 次/局);承接入口金
  (P2 进场承接口径)均值 46.87→**39.57**(−7.3,中位 43→35)——
  搜索成本真实支付;P2 段末金均值 11.01→10.95(持平,主消耗在
  P1 末窗而非透支进 P2)、P2 终局穷金(<10)占比 64%→**56%**
  (反降——merges 变多节省了后续买牌开销的方向性信号,如实记不裁);
  结合三臂批 hp0 不恶化(88.69%),boss_floor 下限+次数封顶的兜底
  有效的行为证据成立。
