## ★伤害公式(新增 —— 原 docs 缺这条核心)

货币战争角色伤害 = (深渊/大世界同类公式) × **三个新乘区**:

1. **前后台强度**:角色站前台→吃「前台强度」,站后台→吃「后台强度」(与角色本身是前后台定位**无关**,只看站位)。伤害倍率贡献 = `强度值 × 1%`。例:前台强度 500 → 该角色伤害 ×5。
2. **伤害征服**:新独立乘区(类似增伤,但独立结算)。
3. **幸运一击伤害征服**:「幸运一击」类似第二层暴击率;该段伤害触发幸运一击时此乘区生效,否则不生效。
   - **幸运一击 与 暴击 独立计算、互不影响**。显示「幸运」= 幸运暴了(暴击没暴);「暴击」= 反之;「幸运暴击」= 双暴;无字 = 双都没暴。
   - **幸运一击暴伤基础 100%**(普通暴击伤害基础仅 50%)→ 幸运一击基础收益更高;有条件把主 C 幸运一击率往满堆 + 至少一件暴击装。

**稀释排序**:前后台强度稀释最严重;**伤害征服 + 幸运一击稀缺、提升幅度大** → 优先堆后两者。

> 这条解释了为什么「火力风暴潮(伤害征服)/ 幸运一击装」是各主 C 的核心(见 `V4.4_阵容_README.md` 通用关键装备)。

## 段位 / 血量 / 星(确认 + 新数据)

- 8 段位 A1–A8,每段位有星数(读法 A 几 + 星:如 A4 五星、A7 八星);最高 **A8 二十星**。4000 星琼奖励,**拿满只需打到 A5 + 刷任务**。A8-20 boss 至少 **80 亿血**。
- **队伍血量加星**:**70 血 +3 星,40 血 +2 星**,血量掉完不加星也不掉星。(连胜/血量保星的阈值 —— 高血量 = 多拿星 = 快上分,呼应「100 血通关」目标)
- 未完成战斗关卡 → 按节点位置 + 挑战进度扣血(节点越后、挑战进度越低,扣越多)。
- ⚠️ **第三位面遭遇关勿逞强打 7-3 / 7-4:一次扣 70 血**(与必修二「永远不打右边遭遇」一致)。
- **货币战争无连败补偿**(vs TFT 有)→ 维持连胜至关重要;连胜从头到尾 ≈ 多 **100 金币**收益;吃满连胜需 **6 连胜以上**,奖励关不计入连胜数。

## ★难度 → 怪物血量(精确确认)

- 怪物血量随难度**指数增长**:难度每 +1,血量较上一难度 **+5.2%**(即 ×1.052;UP 自拟合 R²>0.999,称数值策划敲的就是这式子)。
- → 精确确认 `data/gameplay.md` 的 `base × 1.052^enemy_difficulty`(每 +8 难度 ≈ +50% 血)。
- 推论:低难度时怪基础血量少,难度 +18 也膨胀不多 → 敢拿高阶;高难度时血量爆炸 → 高阶投资策略的强度追不平膨胀。

## 投资策略(海克斯)与难度

- 开局选投资环境;每位面第 3 节点选投资策略(海克斯)。品质:白银 / 黄金 / 人彩(彩)。
- **投资策略影响怪物难度**:黄金 **+3**、人彩 **+6**(高品质 = 高风险高回报)。
- **选择建议**:低难度无脑选能拿人彩的投资环境(血少,+18 也膨胀不多);高难度(吃力分段)避免高品质策略(追不平血量膨胀,boss 反而更难)。

## 等级 → 商店费用概率

队伍等级越高,商店高费角色概率越高:**2 费 6 级最高、3 费 7 级最高、4/5 费随等级升**。等级 = 最低上场人数(10 级 = 10 人口)。

## 升级与星级

- 不是越快升满越好:熟知阵容核心角色,停留其费用所需等级(如 3 费核心白厄 @7 级),刷够星级再升。
- **星级影响**:技能倍率 + 拐力数值(速度、盾/奶量)。
- **★三星五费 ≈ 无敌**:直接给 **2000 前后台强度 + 300% 速度征服**(其他费用三星中规中矩)。但手低几乎不可能,需特定投资环境/策略。

## 装备 / 练度

- 优先主 C 三件输出装;A7/A8+ 生存压力倍增,把生存位当第二核心养(出满生存装)。
- **练度极重要**:老乘区(双爆/增伤)几乎无稀释,只能靠光追/仪器练度提供。强行玩没有的角色 ≈ 只发挥 **60–70%**。→ 选自己有完整 box 的阵容。
- **★翁瓦克必备**:高难不带翁瓦克跑不赢怪第一轮,怪第一轮直接全队走飞。辅助优先风套 / 翁瓦克抢行动值。

## 五种运营玩法(底层逻辑,详 `V3.7_公共_经济运营.md`)

「五六七级收牌」「速八速九」五种玩法 = 核心角色是 1/2/3 费 vs 4/5 费。底层两条:① boss 时等级越高越好,但不是越快升满越好;② 多余的 50 金利息存着没意义,花出去提升战力才对。核心角色是谁决定「多余钱先 D 牌还是先升人口」。
