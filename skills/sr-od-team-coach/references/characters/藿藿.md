# 藿藿（风·丰饶·5星）

> 按 V4.7 期撰写。禳命群疗+全队回能加攻的丰饶。

## 一、命途属性与技能说明

**命途**：丰饶；**属性**：风

| 技能 | 说明 |
|---|---|
| 普攻 | 单体25%生命上限风伤 |
| 战技 | 单体14%+140 + 相邻11.2%+112 |
| 终结技 | 消耗能量130；**除自身外全队回15%能量上限能量+攻击+24%**（2回合）——回能版停云 |
| 天赋【禳命】 | 战技后2回合：我方回合开始/终结技回血3%+30；≤50%血追加治疗+解负面（6次刷新） |
| 秘技 | 恐吓领域；进战敌方全体攻击-25% |

**资源与循环**：标准能量→充能有效（130偏贵）。

## 二、推荐遗器与原因

**套装**：云无留迹的过客4件 + 生命的翁瓦克2件【攻】
**主词条**：躯干生命%/治疗加成；脚部速度；球生命%；绳充能。
**副词条**：生命% > 速度 > 效果抵抗。
